# 合租室友不对劲

<p>六月的阳光毒辣得像要烤化柏油路面，夏芒拖着行李箱站在小别墅门口，额头上的汗珠顺着下巴滴落在手机屏幕上，模糊了那个大红薯平台拼单成功的通知。</p><p>他擦了擦汗，又确认了一遍地址：梧桐路188号，没错。</p><p>“高考完了，考了650分，一个人出来旅游散心，找两个网友合租——听起来像什么恐怖片开头。”夏芒自言自语着，推开了别墅的院门。</p><p>院子不大，几盆绿植随意地摆在角落，一把躺椅放在阳光下，上面还搭着件灰色T恤，看得出是有人随手脱下来晾晒的。夏芒下意识扫了一眼那件T恤，脑子里蹦出一个念头：这料子至少有10%的化纤成分。</p><p>他愣了一下。这念头来得莫名其妙，但他已经习惯了——从记事起，他看任何东西都会自动冒出一些奇怪的信息，像是有什么东西在脑子里给他念旁白。他管这叫“词条癖”，总是能在看一眼之后，对目标得到一个类似标签的评价，比如“耐用性+3”、“手感粗糙-2”这样的东西。</p><p>“挺好的，至少说明我的大脑还在正常工作。”夏芒耸耸肩，拉着箱子进了别墅大门。</p><p>客厅比他想象的要大一些，装修很普通，米色的沙发，深色的茶几，墙上挂着一幅不知道从哪个家居店买来的风景画。茶几上摆满了零食袋子，薯片、辣条、奥利奥，种类丰富得像是要开超市。</p><p>“来了？”一个声音从沙发后面传来。</p><p>夏芒还没反应过来，一颗脑袋就从沙发靠背上探了出来——那是个约莫二十出头的男生，头发有些乱，戴着一副黑框眼镜，嘴里还叼着半根辣条。他冲夏芒咧嘴一笑，露出一排被辣得通红的牙齿：“我叫冯海天，就是你那个拼单的网友，欢迎欢迎！快进来，空调开着呢。”</p><p>夏芒点点头，放下行李箱，正要自我介绍，冯海天已经缩回沙发里去了，只留下一句：“花鱼在楼上收拾房间，晚点下来。你先随便坐，我这把马上打完，对面快被我秀吐了。”</p><p>夏芒走到沙发旁边，往茶几上一看，冯海天正用手机打着一款MOBA游戏，手速飞快地在屏幕上点来点去。夏芒瞄了一眼手机屏幕，脑子里自动弹出一个词条：手速评级B+级，反应速度高于平均水平，但显然不是职业选手级别。</p><p>“算了，这玩意儿不是我能控制的。”夏芒在心里吐槽了一句，坐到沙发另一头，拿出手机刷起了大红薯平台。</p><p>他没打字，只是默默翻着冯海天和花鱼的账号信息。冯海天发的内容很杂，有打游戏的，有吐槽生活的，偶尔还会发一些让人摸不着头脑的哲理句子，比如“人生就像一局杀戮游戏，你不杀别人，别人也会杀你”这种，底下评论区全是“大佬说得好有道理”和“这兄弟是不是最近压力太大了”。</p><p>花鱼的账号则精致得多，全是些风景照和手工作品，偶尔还会发一些奇怪的半成品新发明，比如“智能猫砂盆·不用电版”，点进去一看是一个漏斗状的装置，评论区有人说“这不就是个普通漏斗吗”，花鱼回复说“对啊，它的原理就是利用重力”。</p><p>两人都是大红薯平台上的大V，粉丝不少，但夏芒没多想。他觉得这很正常，现在这年头，网上有点才华的人太多了，合个租还能碰上两个网红，挺有意思的。</p><p>没过多久，楼梯上传来了脚步声。夏芒抬头一看，一个穿着白色衬衫、梳着整齐短发的女生走了下来，看起来二十出头，不算特别漂亮，但有一种很舒服的气质，像是在某个公园里遇到的热心导游。她冲夏芒笑了笑，声音很平：“夏芒？我是花鱼，来，喝点冰镇绿豆汤，我刚才煮的。”</p><p>夏芒接过玻璃碗，绿豆汤冒着凉气，上面还飘着几粒碎冰。他道了声谢，喝了一口，冰凉甘甜，整个人瞬间舒服了不少。</p><p>“今天高考刚结束吧？考得怎么样？”花鱼坐到另一侧的沙发上，用遥控器打开了电视。</p><p>“还行，650分。”夏芒随口答道。</p><p>冯海天一愣，手机差点掉地上：“650？我操，兄弟，你这是要上清华啊！”</p><p>“没有，就是随便考考，运气好。”夏芒笑了笑，没多解释，但心里很清楚，这650分全靠他那二十个绿词条——他看东西时总是能触发一些提示信息，比如语文阅读理解的文章底下，会冒出“主题思想：对现实的讽刺和自我救赎”这样的字样，数学题旁边会弹“注意这里要用余弦定理”，英语作文会自动给他补上高级词汇。</p><p>这能力说强不强，说弱不弱，但用来考试确实好用。</p><p>三个人看了一部喜剧片，电影评分不高，但胜在够搞笑，夏芒笑得前仰后合，冯海天一边吃薯片一边吐槽剧情，花鱼则安安静静地看，偶尔跟着笑一笑。夏芒觉得这样的气氛挺好的，两个室友看起来都挺正常，没什么奇怪的。</p><p>电影播放到最搞笑的一段，主角被一群鸭子追着满院子跑，夏芒笑得眼泪都快出来了，一边笑一边转头去看花鱼的反应。花鱼的表情很平淡，只是嘴角微微勾着，但眼神却很专注。</p><p>就在这时，夏芒的视线无意间从花鱼的脸滑过——然后他的世界，毫无预兆地，裂开了。</p><p>花鱼头顶凭空出现了一行字，像是用金色墨水写在虚空中的大字，字体古朴而庄严，散发着一种说不清道不明的压迫感：</p><p>【星海旅者·橙】</p><p>夏芒的大脑瞬间一片空白，电影的笑声变成了遥远的风声。他机械地扭过头，看向沙发另一头的冯海天，那个刚才还叼着辣条、打着游戏的普通室友，此刻头顶也悬着一行字，字体的气息更加锋利，像是一把悬在头顶的剑。</p><p>【混元无极剑仙·橙】</p><p>橙级。</p><p>夏芒清楚记得，他这辈子见过的最高级别的词条，也就是绿色。绿色之上是什么，他只在大红薯平台的某些帖子里看到过有人瞎编，说绿色之后是蓝色、紫色、金色、红色。但从没有人提过橙色。</p><p>他腾地一下站了起来，把两人都吓了一跳。</p><p>“怎么了？”冯海天抬起头，一脸茫然。</p><p>“没事，我去喝口水。”夏芒的声音有些发抖，但他尽量让语气听起来正常。他快步走向厨房，路过窗户的时候，他停下脚步，拉开窗帘的一角，看向外面的街道。</p><p>梧桐路上人来人往，卖烤串的小贩、遛狗的居民、骑着电动车的外卖员——所有人头顶，都是他熟悉的词条：【普通人·白】。</p><p>夏芒的手心全是汗。他用力掐了一下自己的大腿，疼痛是真实的。他闭上眼睛，再睁开，花鱼头顶的金色字仍在那里，冯海天头顶的剑意字仍悬在那里，像是两块钉子一样钉在他的认知世界里。</p><p>“这不对。”夏芒在心里疯狂地念叨，“这不科学，这不科学，这不科学——”</p><p>他从小就有这个破能力，能看到词条，但这破能力从来就没出过错。绿色就是绿色，白色就是白色，等级分明，从不含糊。那凭什么这两个室友就是橙级？橙级不是他见过的任何级别的颜色，他甚至不知道这级别的词条到底代表着什么。</p><p>但脑子里有个声音告诉他：这能力至今为止都是靠谱的。</p><p>那意味着，他面前这两个室友，是远超普通人理解范围内的存在。</p><p>“冷静，冷静，冷静。”夏芒深吸一口气，努力让自己的思维恢复正常，“也许是我的能力变异了，也许是我高考压力太大，出现了幻觉，也许——”</p><p>他打开冰箱，拿出冰水，灌了一大口。冷水顺着喉咙滑下去，像是浇灭了一些胡思乱想。他重新审视了一下自己的能力：从小到大，他看到的词条都是比较底层、现实的东西，比如看到一件衣服会冒出“舒适度+2”这样的信息，看到一个人会冒出“社恐+5”这样的标签。这些词条都符合常识，只是增强了他的观察力。</p><p>但今天不一样。</p><p>今天他看到的是“混元无极剑仙”和“星海旅者”，这两个名字听起来就像是从科幻小说里蹦出来的，而且标签的颜色还是他从未见过的橙。</p><p>“难道我穿越了？”夏芒脑子里冒出这个念头，但很快又否定了，“不对，我昨天还在家吃妈妈做的红烧肉，不可能穿越。除非是平行宇宙重叠了，或者其他维度的力量强行降低了门槛...”</p><p>他越想越乱，脑子里各种念头像乱麻一样缠在一起。他下意识地看向窗外，街对面有个大妈正在遛狗，狗屎拉在路边，大妈低头清理，嘴里还在碎碎念，典型的日常居民。白板词条，毫无波澜。</p><p>夏芒看了一眼那狗屎，脑子里自动弹出词条：【泰迪犬·白，排泄物气味度+7，清理难度+2】</p><p>“连这个都能看到，说明我的能力确实还在正常工作。”夏芒苦笑了一下，“那只能说明一个事实——”</p><p>他转身，透过玻璃窗的倒影，看着客厅里还在打游戏的冯海天和看书的花鱼，两人头顶那两行金色大字像是两个太阳一样刺眼。</p><p>他的新室友，一个自称游戏主播的宅男，一个热爱手工美食的文艺女青年，实际身份分别是：混元无极剑仙，以及星海旅者。</p><p>而他夏芒，一个刚高考完、勉强用绿词条考了650分的普通高中生，就这么稀里糊涂地住进了这两个人的房子里。</p><p>夏芒靠在冰箱门上，仰头看着天花板，发出了灵魂深处的疑问：</p><p>“我是不是应该连夜逃离地球？”</p><p>他认真地思考着可行性。去香港或者澳门？不行，太近了。出国？护照还没办下来。去火星？马斯克还没开团。</p><p>“不对，”他自言自语，“我得先搞清楚他们来这里干什么。这两个橙级的大佬，为什么会跑来这么个三四线小城市，和一个普通高中生合租？”</p><p>夏芒走到窗边，看着渐渐暗下来的天色，心里涌起一阵强烈的不安。</p><p>他本应该是个普普通通的高中生，高考结束，旅游散心，找两个网友拼单住几天，然后就回家等录取通知书。</p><p>但现在，他面前站着一个剑仙和一个旅者，而他们头顶的词条，都是橙。</p><p>橙级。</p><p>他从来没见过的颜色。</p><p>他从来没听人提过的等级。</p><p>一种说不清道不明的恐惧感从心底升起，像是有什么东西在黑暗中慢慢苏醒。夏芒握紧了手中冰冷的玻璃杯，低声说了一句：</p><p>“这房子，有问题。”</p>
