# 第7章 第30天

第29天。

杜煌醒来的时候，感觉到了明显的变化。

不是力量的增长——力量的增长对他来说已经像呼吸一样自然了。他感觉到的是另一种变化——他的身体变轻了。

他坐起来，低头看着自己的手。皮肤没有变，肌肉没有变，但他能感觉到自己和这个世界之间的联系正在减弱。脚下的地板、周围的空气、透过通风口传来的轰鸣声……一切都变得有些"遥远"。

像是隔着一层薄薄的玻璃在看世界。

"我已经不属于这里了。"他轻声说。

这一天，他什么都没做。没有训练，没有测试，没有冥想。他只是坐在训练场中央，安静地等待着。

他能"看到"那扇门了。

闭上眼的时候，光门就悬浮在他面前。和之前冥想时看到的轮廓不同，这一次他看得清清楚楚——银白色的光纹在门上游走，发出微弱的光芒。门的中央是一片纯粹的白色，看不清里面有什么，但他能感觉到一股强大的吸引力。

他在等第30天的零点。

晚上，他拿起手机，拨通了林筱雨的电话。

嘟——嘟——嘟——

电话响了很久才接通。

"喂？"林筱雨的声音有些沙哑，像是刚哭过。

"筱雨，是我。"杜煌说。

"我知道。"

两个人沉默了几秒。

"我要走了。"杜煌说，"明天零点。"

电话那头传来一声很轻的吸气声。然后林筱雨的声音恢复了平时的冷静："你确定安全吗？"

"确定。"杜煌说，"我感觉到了。那不是危险，那是……归属。"

林筱雨沉默了很久。

"你还回来吗？"

杜煌想了想，笑了笑："我不知道。但我希望可以。"

"那你记得回来取那半盒牛奶。"林筱雨说，"我会帮你保鲜的。"

杜煌愣了一下，然后笑了。

"好，一言为定。"

他挂断电话，又拨通了秦伯的号码。

"喂？"秦伯的声音很平静，像是早就知道他会打来。

"秦伯，明天零点。"

电话那头沉默了几秒，然后秦伯叹了口气："我等你这句话等了三十年。去吧，别回头。"

"秦伯，你后悔过吗？"

"后悔什么？"

"后悔当初没有走到第30天。"

秦伯沉默了很久，久到杜煌以为他挂断了电话。然后他的声音传来，比平时低沉了许多：

"我每天都在后悔。"

杜煌握着手机，没有说话。

"但我没有那个命。"秦伯说，"你有。所以别浪费了。"

"明白了。"杜煌说。

他挂断电话，把手机放在桌上，看着墙上的时钟。时针慢慢走向11点50分。

还有十分钟。

第30天，零点。

地下训练场的灯光突然全部熄灭。

不是停电——所有的应急灯和备用电源也同时熄灭了。整个地下空间陷入了一片彻底的黑暗。

然后，光出现了。

没有来源，没有方向。光是从空气中凭空浮现的，像是有无数微小的光点同时在空间中点亮。这些光点迅速汇聚、旋转、凝聚，在训练场中央形成了一道巨大的光门。

门高三米，宽两米，由银白色的光线编织而成。门表面流动着复杂的光纹，像是某种古老的文字，又像是一幅不断变化的星图。光芒照亮了整个地下空间，将所有的阴影都驱散了。

杜煌站在光门前，感受到了一股强大的吸引力，像是在风中站立，衣角被吹得猎猎作响。

但他没有急着走进去。

他转过身，看着头顶墙角的摄像头——那个红色的指示灯还在闪烁，证明监控系统还在运行，只是他的画面可能已经变成了满屏的白光。

杜煌对着摄像头，轻轻点了一下头。

不是道谢，不是告别——只是一个确认：我已经准备好。

然后他转身，抬起脚，一步迈进了光门。

光门内的时间是流动的，又像是静止的。

杜煌感觉自己走了很长很长的一段路。他的脚下是光，头顶是光，四面八方都是纯净的白色。没有声音，没有气味，没有任何感官上的刺激，只有一种深沉的宁静。

他不知道走了多久——可能是几秒钟，可能是几个小时。

然后，白色的光逐渐消散，他发现自己站在一片无边无际的空间中。

这里的"地面"是由某种半透明的物质构成的，像是凝固的光。抬头望去，天空中没有任何星辰，只有一种柔和的光芒，均匀地洒落在整个空间。

然后他听到了那个声音。

不是从外部传来的，而是在他的脑海中直接响起——那个他已经无比熟悉的、低沉而缓慢的声音。

"欢迎回家，第137位翻倍者。"

杜煌愣了一下。

他低下头，发现自己手里不知什么时候多了一样东西——那块黑色的石头。不同的是，它正在发光。银白色的光从石头内部透出来，像是一颗跳动的心脏。

他抬起头，看到一个身影向他走来。

那个人穿着一件白色长袍，身形模糊，看不清面容。但从轮廓来看，那是一个人类。

"这里是源域。"那个身影说，"翻倍者的终点。也是起点。"

杜煌张了张嘴，有很多问题想问，但最终只问了一个：

"上一个翻倍者，那个叫陆远的，他还在这里吗？"

身影停了下来。

然后，那个身影缓缓抬手指向远处。

杜煌顺着那个方向看去，看到了光。

无数道光。

每一道光都是一个模糊的人形，站在那片无尽的白色空间中，像是等待了很久很久。

"每一位翻倍者都在这里。"声音说，"他们等了你很久。"

杜煌站在源域的地面上，看着那些遥远的光影，心里涌起一种复杂的情绪。

不是恐惧，不是兴奋，不是悲伤。

是一种深沉的宁静。

他回过头，看了一眼来时的方向。

那里什么都没有，只有无尽的白色。

但他知道，在那个方向，在某个遥远的维度里，有一个出租屋，有一个修鞋摊，有一张写给他的纸条，还有半盒在冰箱里等待着他的牛奶。

"我会回来的。"他轻声说。

然后他转过身，朝着那些光芒，迈出了第一步。

出租屋的客厅里，林筱雨坐在沙发上，手里捏着一封信。信纸有些湿了，但她脸上没有泪痕。

她把信收好，起身走到厨房，打开冰箱。

那半盒牛奶还放在原来的位置。

她拿出来看了看保质期，拧开盖子闻了闻。

"还没过期。"她轻声说，然后把牛奶放回冰箱，关上了门。

清晨，秦伯如往常一样出摊。他坐在修鞋摊前，戴上老花镜，拿出今天要修的第一双鞋。

他低头穿针的时候，忽然感觉到有一阵风吹过。很轻，像是什么东西从他身边经过。

他抬起头，看了看空无一人的街道。

然后他低下头，继续穿他的针，嘴角微微弯了一下。

归零社的办公室里，宋明远站在电脑前，反复回放着零点时的监控画面。

画面上，杜煌站在光门前，对着摄像头点了点头，然后转身走进了那道光里。

光消失了。

杜煌也消失了。

他盯着那个画面看了很久，然后点击了"存档"按钮。

在文件名一栏，他输入了一行字：

"第137位翻倍者——已完成跨越。"

他靠在椅背上，看着窗外的晨光，不知道在想什么。

源域中，杜煌继续向前走去。

远处的那些光影越来越近。他逐渐能看清了——每一个光影都是一个真实的人，穿着不同时代的衣服，有着不同的面孔。

他们都在看着他。

不是审视，不是在评判。

是在欢迎。

杜煌停下脚步，看着面前这片无边无际的光之世界，心里最后一丝不安也消散了。

他不是在消失。

他是终于回家了。
