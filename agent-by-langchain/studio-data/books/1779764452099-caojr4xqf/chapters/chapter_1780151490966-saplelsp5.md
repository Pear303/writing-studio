# 命运的终极宿命

/p><p>“唰——！”</p><p>泥水贴着他鼻尖飞过，狠狠拍在身后墙上。眼镜男毫发无损。</p><p>他吓傻了，看着干干净净的衣服满脸茫然：“我……我什么时候练会这招？我难道真是鸠摩智转世？”</p><p>龙佑握紧拳头。</p><p>“既然是修改命运……那我以前那百分之百输钱的霉运，是不是也可以……”</p><p>低头看向手心，脑海中浮现简单想法——抛硬币猜正反。</p><p>【龙佑猜“正”，结果为“反”：91%】</p><p>【龙佑猜“反”，结果为“正”：78%】</p><p>【历史惯性，你运气极差，蒙啥啥错。】</p><p>“去你的历史惯性，给我正。”</p><p>【抛硬币，结果为“正”的概率：100%】</p><p>龙佑从口袋里摸出硬币向上一抛。</p><p>落地，正面。</p><p>从此那个逢赌必输的倒霉蛋龙佑，彻底死去。</p><p>他收起硬币，看向天空。</p><p>视线拉高，信息流变得宏大抽象，意识向苍穹攀升。</p><p>【今日傍晚市区降下暴雨的概率：92.22%】</p><p>【积雨云正在三十公里外集结。】</p><p>【人类在未来十年内发现外星文明确切证据的概率：0.001555%】</p><p>【这片寂静的森林里，大家都藏得很好。】</p><p>符号变得更加晦涩，涉及超越人类现有物理法则的领域，但龙佑仍能瞬间洞悉其含义。</p><p>目光穿透大气层，穿透行星轨道，直视深邃宇宙。</p><p>【太阳系奥尔特云结构在未来一万年内发生引力崩塌的概率：0.003111%】</p><p>【局部宇宙空间发生熵增逆转，如破碎的杯子自动复原的概率：1/(10^10^120)】</p><p>【这并非绝对不可能，只是要等到宇宙间所有粒子，在一场近乎神迹的偶然里尽数回溯。时间漫长到足以让星辰黯淡、万物归零。】</p><p>“这些概念都太宏大，有没有一些贴近日常生活的概率？”</p><p>【有的，兄弟有的。】</p><p>【新长出的智齿刚好填补蛀牙位置：4.444%】</p><p>【抽卡10连3金：0.0008111%】</p><p>【一年内发生希克苏鲁伯级别的天体撞击：0.0008112%】</p><p>【恐龙灭绝的概率高于10连3金的概率，这或许就是人类的力量！】</p><p>【海啸袭击稷海市：0.05555%】</p><p>【暗色岩事件级别的全球气候灾难：0.0000001111%】</p><p>【地球爆炸：0.00000000002222%】</p><p>【太阳耀斑爆发：0.1566%】</p><p>【扔出一块石头摧毁三体星系：1.145e-55】</p><p>【树上荔枝发生真空衰变：4.514e-1925】</p><p>【面前这只猫在空中向后翻滚八周半平稳落地：0.008888%】</p><p>最后，龙佑感到脑海中，出现一道不可逾越的黑色高墙。</p><p>所有概率的终点——所有线条、符号、数字最终汇聚成冰冷而绝望的数值。</p><p>【宇宙毁灭的概率：100%】</p><p>【一切终将归于虚无，这是命运自身的终极宿命，无一幸免。】</p><p>……</p><p>（纯无敌，嘎嘎起飞不废话！）</p>
