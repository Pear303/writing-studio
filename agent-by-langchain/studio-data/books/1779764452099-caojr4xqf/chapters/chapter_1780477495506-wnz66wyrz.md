# 第3章 暗影与地图

<p>入住听澜别墅的第五天，夏芒终于意识到一个问题——那两个橙色词条的室友，是真的把他当普通租客对待的。</p><p>冯海天每天的作息极其规律：睡到中午十二点，起来吃个外卖，躺在沙发上刷手机到下午四点，然后出去"遛弯"到半夜才回来。花鱼则更安静，除了吃饭时间几乎见不到人，大部分时候都待在二楼的房间里，门关得严严实实。</p><p>夏芒试着和冯海天聊过几次，想问清楚关于词条的事情，但每次都被对方用各种话术轻描淡写地挡了回来。冯海天的态度很明确——你刚觉醒，还太弱，知道太多对你没好处。</p><p>高考成绩要到六月二十几号才出，夏芒每天闲着没事，就在别墅周围转悠，熟悉听澜别墅区的环境。这片区域的绿化做得极好，到处都是高大的树木和精心修剪的灌木丛，走在小路上几乎晒不到太阳。别墅区背后是一座不高的小山，翻过山就是一片老旧的工业园区，据说几年前就搬迁得差不多了，只剩下一些废弃的厂房。</p><p>第五天傍晚，夏芒像往常一样出门散步。</p><p>太阳西沉，天边烧着一片橘红色的晚霞。他沿着别墅区的主干道一路往北走，穿过那片小山包上的林荫道，来到了后山的工业园区。</p><p>说是工业园区，其实更像是一片废墟。生锈的铁门歪歪扭扭地挂着，围墙上爬满了疯长的藤蔓，水泥路面裂开了缝，缝隙里长出半人高的野草。几栋灰扑扑的厂房错落在夕阳里，玻璃窗碎了大半，黑洞洞的像一只只空洞的眼睛。</p><p>夏芒本来打算转一圈就回去，但他走了大约两百米后，忽然生出一种奇怪的感觉——有人在看他。</p><p>那是一种很微妙的直觉，像是背后有一道目光黏在他的后颈上。他停下脚步，假装在看手机，余光扫向身后。</p><p>没有人。</p><p>空旷的街道上只有他自己的影子被夕阳拉得老长。</p><p>夏芒皱了皱眉，继续往前走。但他留了个心眼，放慢了脚步，仔细留意周围的动静。</p><p>大约走了五十米，他又感觉到了那种被注视的异样感。这一次更强烈了，他甚至能隐约感觉到那道目光是从右侧的一栋废弃厂房二楼传来的。</p><p>他猛地转头看过去。</p><p>二楼的窗户后面，一个黑影一闪而过。</p><p>夏芒的心脏狠狠跳了一下。他没有犹豫，拔腿就跑。</p><p>他沿着来时的路往回狂奔，但跑出不到一百米，他就发现前面的路被堵住了——一辆报废的面包车横在路中间，把原本就不宽的巷子堵得死死的。</p><p>夏芒暗骂一声，转身钻进旁边一栋废弃的纺织厂厂房。</p><p>厂房里光线昏暗，空气中弥漫着一股霉味和机油味。地上散落着破碎的纺织机和生锈的零件，头顶的铁架子上挂着几条破布，在穿堂风中轻轻摇晃。夏芒猫着腰，在机器和杂物之间穿行，尽量不发出声音。</p><p>他躲到一台大型纺织机的后面，屏住呼吸，竖起耳朵听外面的动静。</p><p>脚步声。</p><p>很轻，但很稳，正在靠近厂房门口。</p><p>夏芒的心提到了嗓子眼。他悄悄探出头，看向厂房大门的方向。</p><p>一个人影站在门口，逆着光，看不清脸。但夏芒能看见那个人头顶的词条——【暗影追踪者·深绿】。</p><p>深绿色的字。</p><p>比绿色的颜色更深，像是快要蜕变成蓝色的那种绿。夏芒之前没见过这种颜色，但他能感觉到这个词条散发出的气息和那些普通绿色词条完全不同，带着一种压迫感。</p><p>那个人的身形很瘦，穿着一件深色的风衣，站在门口一动不动，像是在确认夏芒的位置。几秒钟后，他迈步走进了厂房。</p><p>夏芒握紧了拳头。他环顾四周，寻找其他的出口。厂房的后方有一扇小门，但门板上挂着一把生锈的铁锁。头顶上方有一排天窗，但距离地面至少有六七米，根本够不着。</p><p>没路可逃了。</p><p>脚步声越来越近。</p><p>夏芒躲在纺织机后面，大脑飞快运转。他有二十个词条，但都是绿色和白色的学习型词条，在这种生死关头毫无用处。他没有学过格斗，没有经历过任何实战训练，就是一个普通的高中生。</p><p>但那个【暗影追踪者】不一样。深绿色的词条，带着追踪和战斗的属性，一看就是实战型能力者。</p><p>硬碰硬绝对是找死。</p><p>夏芒强迫自己冷静下来。他仔细观察周围的环境，看到脚边有一根生锈的铁管，大概手臂那么粗。他捡起来握在手里，虽然知道这东西对能力者恐怕没什么用，但手里有件武器总比空手强。</p><p>脚步声停在了距离他大约五米的位置。</p><p>"别躲了。"一个沙哑的声音说，"我看到你了。"</p><p>夏芒没有动。他在赌——赌对方是在诈他。</p><p>沉默了几秒钟。然后那个脚步声又响了起来，拐向了左边，朝厂房的另一个方向走去。</p><p>夏芒松了一口气，但他不敢放松警惕。他小心翼翼地探出头，看到那个人影正在厂房另一侧翻找着什么，背对着他。</p><p>好机会。</p><p>夏芒猫着腰，悄悄往厂房后门移动。他尽量放轻脚步，每一个落点都经过精心选择，避开地上的碎玻璃和金属片。</p><p>就在他距离后门不到三米的时候，脚下踩到了一块松动的铁皮。</p><p>哐当一声，在空旷的厂房里回荡开来。</p><p>"操。"夏芒骂了一声，不再管什么隐蔽了，直接冲向那扇后门。</p><p>身后的脚步声骤然加速，带着一股风声追了过来。</p><p>夏芒冲到后门前，用力拽了一下门锁。铁锁哐啷响了一声，但没有断开。他又拽了两下，锁链纹丝不动。</p><p>身后的脚步声越来越近。</p><p>夏芒转过身，举起手中的铁管，准备拼命。</p><p>就在这时，他的目光越过那个追踪者的肩膀，落在了厂房墙壁上。墙上刻着一排奇怪的符号——方方正正的，像是一个个方块堆叠在一起，线条简洁而规整，带着一种说不出的诡异感。</p><p>那些符号不是随便涂鸦的。它们排列得很有规律，像是一种文字，或者说某种图案。</p><p>追踪者顺着他的目光回头看了一眼墙上的符号，发出一声低沉的笑声："看到了不该看的东西啊，小子。"</p><p>夏芒握紧铁管，脑子里却在飞速思考。那些符号是什么？为什么刻在这里？这个追踪者又是什么人？</p><p>追踪者不再废话，迈步向他走来。他的步伐很快，几乎是一瞬间就跨过了三米的距离，一只手朝夏芒的脖子抓来。</p><p>夏芒本能地挥起铁管砸向那只手。</p><p>铁管砸在对方的手臂上，发出沉闷的声响。但对方的手臂纹丝不动，甚至眉头都没皱一下。夏芒感觉自己砸中的不是血肉之躯，而是一根实心钢管。</p><p>"就这？"追踪者的嘴角勾起一个嘲讽的弧度。</p><p>下一秒，夏芒感到手腕一麻，铁管就被对方夺了过去，扔到了墙角。紧接着，一只冰凉的手掐住了他的脖子，把他按在了墙上。</p><p>夏芒的后脑勺撞在墙壁上，眼前一阵发黑。他抓住那只掐住自己脖子的手，拼命想掰开，但对方的力量太大，他根本挣脱不了。</p><p>"不过是个刚觉醒的小鬼。"追踪者凑近他，露出一张瘦削的脸，眼窝深陷，眼神阴鸷，"放心，我不杀你。主人要活的。"</p><p>夏芒从喉咙里挤出几个字："你……主人是谁……"</p><p>追踪者没有回答，另一只手从口袋里掏出一枚灰色的东西，像是一块小石头，方方正正的，上面刻着那种方块符号。</p><p>就在这时，厂房外面忽然传来一声清亮的剑鸣。</p><p>追踪者的动作瞬间僵住了。他猛地转头看向厂房门口，眼神里闪过一丝惊恐。</p><p>一道银白色的剑气从门口飞进来，精准地斩断了追踪者掐住夏芒脖子的那只手——不，不是斩断，是从他的手和夏芒脖子之间穿过，把两人分开了。</p><p>追踪者发出一声闷哼，后退了几步，捂着鲜血直流的手腕。他那只手还完好无损，但手腕上多了一条深深的剑痕，几乎能看到白骨。</p><p>"谁？"追踪者咬牙切齿地问。</p><p>没有人回答。</p><p>但夏芒知道是谁。</p><p>他撑起身体，看向厂房门口。果然，冯海天站在那里，还是那副懒散的样子，穿着一双人字拖和宽松的短裤，手里什么都没有。</p><p>但他的头顶，那行橙色的字正在微微发光。</p><p>"我说你这小孩。"冯海天打了个哈欠，"怎么走到这么远的地方来了？害我找了你半天。"</p><p>追踪者看到冯海天头顶的橙色词条，脸色瞬间变得惨白。他二话不说，转身就往厂房的另一边跑去，速度比追夏芒时快了好几倍。</p><p>冯海天没有追。他只是抬起右手，食指和中指并拢，轻轻一划。</p><p>一道无形的剑气飞出，在追踪者前方的地面上留下一道深达半米的裂缝。</p><p>追踪者猛地刹住脚步，差点栽进裂缝里。</p><p>"别急着走嘛。"冯海天慢悠悠地说，"我问你几个问题，问完就放你走。"</p><p>追踪者转过身，脸色难看极了。他看了一眼冯海天，又看了一眼地上的裂缝，最终低下头，不再动弹。</p><p>"谁派你来的？"冯海天问。</p><p>"……不知道。"</p><p>"不知道？"</p><p>"我只接到任务指令，不知道雇主是谁。"追踪者的声音很沙哑，"任务是跟踪和活捉最近觉醒的人，带到北郊那个地方。"</p><p>"北郊哪里？"</p><p>"废弃化工厂的地下室。"</p><p>冯海天眯了眯眼睛，若有所思地点了点头："那些方块符号，你们的人画的？"</p><p>追踪者犹豫了一下，点了点头。</p><p>"你们有多少人？"</p><p>"不清楚。我只是外围成员，核心的事接触不到。"</p><p>冯海天盯着他看了几秒钟，似乎在判断他有没有说谎。然后他摆了摆手："滚吧。回去告诉你上头的人，听澜别墅区的人别碰。"</p><p>追踪者如获大赦，转身就跑，眨眼间消失在厂房外的暮色中。</p><p>夏芒靠在墙上，大口喘着气。等呼吸稍微平稳了一些，他才开口："你怎么知道我在这里？"</p><p>"花鱼说你的气息从别墅区北边消失了。"冯海天走过来，蹲下身子，看了看地上那块灰色的方块石头——那是追踪者逃跑时掉落的。"我就过来看看。"</p><p>他捡起那块石头，翻来覆去看了看，眉头微微皱起。</p><p>"这是什么？"夏芒问。</p><p>"标记。"冯海天把石头递给他，"你被他们盯上了。"</p><p>夏芒接过石头，入手冰凉，像一块普通的鹅卵石，但表面刻着的方块符号让他莫名地感到不安。</p><p>"先回去再说。"冯海天站起来，拍了拍手上的灰。</p><p>夏芒跟着他走出厂房。天已经彻底黑了，工业园区笼罩在一片暗蓝色的夜幕中。他回头看了一眼那栋废弃的纺织厂，墙上那些方块符号在月光下若隐若现，像是一双双沉默的眼睛。</p><p>两人回到别墅时，花鱼正坐在客厅的沙发上，手里捧着一杯冒着热气的茶。她看到冯海天和夏芒进门，目光在夏芒身上停留了几秒，然后微微皱起了眉。</p><p>"他被标记了。"花鱼说。</p><p>夏芒一愣："什么？"</p><p>花鱼站起来，走到夏芒面前。她伸出手，示意夏芒把手臂伸出来。</p><p>夏芒犹豫了一下，还是挽起袖子，伸出右手臂。</p><p>花鱼的手指轻轻按在他的前臂上，沿着一条无形的轨迹划过。几秒钟后，夏芒的手臂上浮现出一片灰白色的印记——那是几个方块符号组成的图案，和他在厂房墙上看到的一模一样。</p><p>夏芒倒吸一口凉气："这什么东西？什么时候弄上去的？"</p><p>"那个追踪者掐你脖子的时候。"冯海天靠在门框上，双手抱胸，"他用那块石头碰过你了吧？标记就是这么下的。"</p><p>"那现在怎么办？"</p><p>花鱼没有说话。她转身走到茶几前，把摊开的几本书和纸张推到一边，然后从茶几底下的夹层里取出一个卷轴。</p><p>那是一张地图。</p><p>花鱼把地图在茶几上展开。地图上标注的是稷海市的全境，但不是普通的地图——上面用蓝色和红色的线条标注了许多奇怪的位置，有些地方还画着那种方块符号。</p><p>夏芒数了一下，地图上总共有七个方块符号标注点。</p><p>"七个。"花鱼轻声说，"加上今天发现的那个废弃厂房，我们已经确认了五个。还有两个不知道具体位置。"</p><p>"这些标记是什么？"夏芒问。</p><p>冯海天走过来，居高临下地看着地图。他的表情难得地认真了起来。</p><p>"一个邪教的据点。"他说，"不知道从哪冒出来的，崇拜方块雕像，信奉某种……很古老的东西。他们最近在稷海市活动频繁，似乎在找什么东西或者什么人。"</p><p>"找我？"</p><p>"可能是。"冯海天看了他一眼，"也可能不是。但既然他们盯上你了，你就已经卷进来了。"</p><p>夏芒盯着地图上的七个方块符号，脑海里浮现出那个废弃厂房墙上的符号，和手臂上浮现的灰色印记。他感觉自己像是被一张无形的网兜住了，而这张网的源头就在地图上的某个位置。</p><p>"那个废弃化工厂的地下室。"他说，"那个追踪者提到过。"</p><p>花鱼抬起头，看了冯海天一眼。</p><p>冯海天沉思了几秒钟，然后说："明天我去看看。"</p><p>"我也去。"夏芒说。</p><p>"你去干什么？送死？"</p><p>"我能看到词条。"夏芒说，"如果那里有其他人，我能提前知道他们的能力和等级。这对你有用。"</p><p>冯海天盯着他看了几秒钟，然后忽然笑了："行，有胆量。不过明天我先去探路，你待在家里。等我摸清楚了，再决定要不要带你去。"</p><p>夏芒还想说什么，但花鱼按住了他的手臂。她轻轻摇了摇头，示意他不要争辩。</p><p>"听他的。"花鱼说，"那个人说得没错，你还太弱。"</p><p>夏芒沉默了。</p><p>他看着地图上那些方块符号，又低头看了看手臂上灰色的印记。印记还在微微发亮，像是一个无声的倒计时。</p><p>他不知道自己卷入了什么，但他知道一件事——从今天开始，他已经无法回头了。</p>
