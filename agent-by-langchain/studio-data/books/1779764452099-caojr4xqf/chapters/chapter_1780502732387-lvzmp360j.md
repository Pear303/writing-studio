# 1

<p>夏芒拖着行李箱站在别墅门前的时候，根本不知道自己即将面临什么。</p><p>高考结束后的第三天，他查到了成绩。650分。</p><p>二十个绿色词条保驾护航的结果，比他自己预估的还高了十分。但这并不重要。</p><p>重要的是——他要离开家。</p><p>他妈已经在家门口挂上了“庆贺吾儿考入重点大学”的横幅，他爸的微信头像换成了他穿学士服的P图照，七大姑八大姨已经开始研究哪个专业的女生好找对象。</p><p>夏芒受不了。他用高三暑假打工攒的三千块钱，在大红薯平台上找了个合租帖子，说去苏州散散心。</p><p>帖子内容很简单：三室一厅小别墅，月租平摊，只租一个月。</p><p>发帖人是个叫“花鱼”的女生，头像是一只布偶猫。评论区有人说这个价格太便宜了，问是不是骗子。花鱼回复：家里房子多，没人住，就当交个朋友。</p><p>夏芒觉得这话挺离谱。但他还是来了。</p><p>两个小时的高铁，从四线小城到了苏州。根据花鱼发来的定位，他找到了这个小区。</p><p>不是什么豪华别墅区，就是普通的小洋楼，墙角爬满了青苔，有一棵歪脖子枇杷树。环境还行，安静，整洁。</p><p>夏芒按响门铃。</p><p>开门的是个男的。</p><p>穿着白T恤大裤衩，脚踩一双人字拖，手里端着一桶薯片。看起来二十出头，头发乱糟糟的，睡眼惺忪。</p><p>“你是夏芒？”他打了个哈欠，“进来吧。”</p><p>夏芒迟疑了一下：“你是……”</p><p>“冯海天。”那人侧身让开门口，“花鱼在楼上收拾屋子，你先坐。”</p><p>客厅挺大，布艺沙发，茶几上摆着游戏的界面，屏幕上显示着《永劫无间》的角色选择页面。电视墙旁边是个书架，但上面没几本书，全是手办和模型。</p><p>夏芒把行李箱放在玄关，坐到沙发上。</p><p>气氛有点尴尬。</p><p>冯海天坐回沙发上，抓起手柄，噼里啪啦开始打游戏。屏幕上的人影飞来飞去，刀光剑影，他把所有的零食全堆在茶几上，薯片渣子掉了一地。</p><p>他不说话，夏芒也不好意思说话。</p><p>过了大概十分钟，楼梯上传来脚步声。</p><p>一个女生走了下来。</p><p>短发，碎花连衣裙，看着比夏芒大两三岁。她的眼睛很亮，笑起来的时候有两颗小虎牙。</p><p>“你就是夏芒吧？我叫花鱼。”她走过来，坐到冯海天旁边，“怎么样，环境还满意吧？”</p><p>夏芒点点头：“挺好的，谢谢。”</p><p>“别客气，就是个落脚的地方。”花鱼说，“我跟冯海天都是自由职业，平时也不怎么出门。你想去哪玩就自己去，不用管我们。”</p><p>夏芒看了看四周，问了一个他很在意的问题：“你们在这里住多久了？”</p><p>“两个月吧。”冯海天头也不回地说。</p><p>“那这房子……”</p><p>“我家的。”花鱼笑了笑，“我爸妈在别的城市住，这房子空着也是空着，不如租出去。”</p><p>夏芒点点头，没再追问。</p><p>他总觉得这两个人有点奇怪。但具体哪里奇怪，他说不上来。</p><p>三点多的时候，夏芒出去买生活用品。回来的时候已经快六点了。</p><p>客厅的电视开着，投屏放着电影。冯海天盘腿坐在沙发上，薯片旁边多了两罐可乐。</p><p>花鱼从厨房探出头：“回来了？我煮了面，吃不吃？”</p><p>夏芒本来想去外面吃，但闻到了辣酱的香味，肚子不争气地叫了一声。</p><p>“好，谢谢。”</p><p>花鱼煮的是酸辣粉。红油浮在碗面上，花生碎洒在粉条上，酸味和辣味融合在一起，非常开胃。</p><p>夏芒坐在餐厅吃粉，花鱼把电视调成了电影，放在茶几上。</p><p>“《星际穿越》。”冯海天看了看屏幕，“你挺会选。”</p><p>花鱼笑了笑：“经典片子，适合晚上看。”</p><p>夏芒吃完了粉，也坐到了沙发上。</p><p>他平时不怎么爱看电影。但这会儿闲着，看着画面里那个星际飞船在宇宙中无声地飞行，他突然觉得有点出神。</p><p>宇宙很大，他很渺小。</p><p>生活很普通，高考成绩虽然不错，但他根本没想好要学什么专业。他妈想让他学医，他爸想让他学法，他自己的想法是——什么都不想干。</p><p>“你知道吗，”花鱼突然开口，“宇宙里最美的其实是星云，但人类永远看不到它的全貌。”</p><p>夏芒回过神来：“为什么？”</p><p>“因为我们在里面。”冯海天接了话，但没转头，目光还盯着电视，“你站在一片森林里，能看到一棵树两棵树，但你永远不知道自己站在哪片森林里。”</p><p>夏芒觉得这句话有点意思。</p><p>他想说什么，但突然间——</p><p>他的眼睛开始发烫。</p><p>那种感觉很熟悉。这几天每次他观察物体的时候，只要集中注意力，眼前就会出现各种词条。</p><p>但这次不一样。这次不是他主动触发的。</p><p>一种冰凉的感觉，从眼睛深处渗透出来，像是有什么东西在翻转。</p><p>他不由自主地转向冯海天。</p><p>【冯海天】</p><p>【份混元无极剑仙·深橙】</p><p>【万剑归宗·橙】【剑心通明·橙】【亿万星辰·橙】</p><p>【不死不灭·深紫】【天道化身·深紫】</p><p>夏芒愣住了。</p><p>他下意识地转动目光，看向花鱼。</p><p>【花鱼】</p><p>【星海旅者·深橙】</p><p>【空间穿梭·橙】【星海漫步·橙】【多维感知·橙】</p><p>【时间弹性·深紫】【记忆继承·深紫】</p><p>夏芒的大脑一片空白。</p><p>他猛地站起来。</p><p>冯海天和花鱼同时看向他。</p><p>“怎么了？”</p><p>“没事，”夏芒说，声音发紧，“我去窗边透透气。”</p><p>他快步走到窗边，猛地拉开纱帘。</p><p>外面是暮色中的小区，路灯刚从黄色转为白色，有几个老人在楼下散步，有孩子在骑自行车，有狗在草坪上撒欢。</p><p>夏芒深吸一口气，看向外面的每个人。</p><p>【王建国】</p><p>【退休教师·白】</p><p>【张子轩】</p><p>【粗心大意·白】</p><p>【赵丽】</p><p>【精于计算·白】</p><p>全都是白板。</p><p>全都是普通人。</p><p>夏芒的手在微微发抖。</p><p>他闭上眼睛，深吸了几口气。他告诉自己，这一定是最近压力太大，出现了幻觉。高考刚结束，他累了，需要休息。</p><p>但他知道不是这样。</p><p>词条视觉从未出错过。从来都没有。</p><p>从最初的【性格随和·白】到高考卷子上的题目，每一个词条都在告诉他一个事实：他看到的东西，就是真相。</p><p>那……这个真相是什么意思？</p><p>他的室友，一个游戏宅男，一个穿碎花裙的女生，是两个橙色等级的存在？</p><p>剑仙？星海旅者？</p><p>这他妈是什么？</p><p>夏芒感觉自己的世界观正在崩塌。不是慢慢裂开的那种，而是被人用大锤砸成粉末的那种。</p><p>他刚才还坐在两个大佬旁边，吃了花鱼亲手做的酸辣粉。</p><p>那碗粉里会不会有什么问题？</p><p>不对，如果他们想对他做什么，根本不需要用毒。光是那个【万剑归宗·S级】和【空间穿梭·S级】就够他死一万次了。</p><p>但他们为什么在这里？</p><p>为什么在这种小城市？为什么要跟一个刚高考完的普通学生合租？</p><p>夏芒的CPU彻底烧了。</p><p>他站在窗边，后背紧贴着墙，感觉心跳快得像是要从嗓子眼里蹦出来。</p><p>他脑子里只剩下一个想法：</p><p>要不……</p><p>连夜逃离地球？</p>
