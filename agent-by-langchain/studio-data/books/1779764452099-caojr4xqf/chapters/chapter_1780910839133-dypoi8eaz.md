# 第5章 失控前夜

<p></p><p>第十一天，力量翻到两千零四十八倍。</p><p>杜煌的生活已经彻底没法正常过了。</p><p>早上他起床去卫生间，伸手拧门把手，门把手直接从门上被拧了下来。他愣在原地，看着手里那个变形的金属把手，叹了口气，把它放在桌上，出门的时候只能从门框上的洞里伸手进去拉开门。</p><p>刷牙的时候他不敢用杯子了——怕捏碎。他直接用嘴接水龙头的水，电动牙刷的震动对他来说像按摩，刷毛在他手里攥了不到十秒就变形了。</p><p>吃早饭的时候，他用塑料勺子喝粥。勺子在他手里弯成了九十度，他只能勉强用弯曲的勺沿把粥舀起来。林筱雨坐在对面看着他，欲言又止。</p><p>"没事，勺子质量不行。"杜煌面不改色地说。</p><p>林筱雨没接话，低头继续吃自己的早餐。</p><p>吃完早饭，杜煌出门去上班。地铁他是坐不了了——人挤人的车厢里，他随便一个不小心就会碰到别人，以他现在的力量，轻轻一碰可能就是骨折级别的伤害。</p><p>他选择了步行。</p><p>从出租屋到公司大约五公里，他走路过去大概用了十五分钟。不是走得快，是他刻意放慢了速度。如果他想快走，大概三分钟就到了，但那太显眼了。</p><p>到了公司，他发现自己的工位已经被调整过了——原来的椅子换成了加固型的金属椅，键盘换成了机械键盘，鼠标也换成了更大更重的型号。</p><p>主管把他叫到办公室，关上门，小心翼翼地问："杜煌啊，你是不是……遇到什么事了？"</p><p>杜煌看着主管那张有些紧张的脸，大概猜到了——宋明远可能已经跟公司打过招呼了。</p><p>"我没事。"他说。</p><p>主管显然不太信，但也没追问，只说了一句："有什么需要帮助的，你跟我说。"</p><p>杜煌点了点头，回了工位。</p><p>他打开电脑，开始处理手头的工作。打字的时候他必须用很轻的力道，指尖敲在键盘上的力度要控制在刚好触发按键的程度。几行字打下来，他感觉比跑了一百米还累——精神上的累。</p><p>下午的时候，林筱雨发来一条微信：</p><p>"我今天看到新闻了，有人在讨论你那段视频。虽然没指名道姓，但评论区已经有人在猜了。你得小心。"</p><p>杜煌看完消息，把手机揣进口袋，靠在椅背上看着天花板。</p><p>他知道自己不可能继续这样下去了。</p><p>第十二天，四千零九十六倍。</p><p>零点刚过，杜煌在房间里测了一下自己的力量。他拿出一个备用的金属门把手——特意从五金店买来测试用的——握在手心，轻轻一用力。</p><p>金属在他手里像是橡皮泥一样，直接变了形。</p><p>他又试了试其他东西。一根实心的铁棍，他双手一掰，弯成了U形。一块一厘米厚的钢板，他用力一拳打上去，钢板上出现了一个明显的拳印。</p><p>他坐在满地的"测试品"中间，看着自己的双手，心里说不出是什么滋味。</p><p>他现在有四千倍于常人的力量。一拳可以打穿墙壁，一脚可以踩裂地面。以他现在的能力，如果他想，他可以把这栋楼拆了。</p><p>而且这才第十二天。</p><p>到了第三十天……他不敢想了。</p><p>第十三天，宋明远来了。</p><p>他开着一辆黑色的商务车，停在出租屋楼下，亲自上来敲杜煌的门。</p><p>"杜先生，你今天翻到八千一百九十二倍了，对吧？"宋明远站在门口，语气很客气，但表情很认真，"以你现在的能力，继续住在这种普通居民楼里，已经不安全了——对你不安全，对楼里的其他人也不安全。"</p><p>杜煌知道他说的是实话。</p><p>"你想让我去哪？"</p><p>"我们有一个地下训练场，完全封闭，防护等级足够承受你现在这个级别的力量。"宋明远说，"你可以住在那里，自由使用设施，我们只做一件事——监测你的身体数据。"</p><p>杜煌回头看了看客厅里正在看书的林筱雨。</p><p>林筱雨合上书，站起来："我跟你一起去。"</p><p>宋明远看了她一眼，点了点头："可以。"</p><p>杜煌收拾了几件衣服，带上手机和充电器，最后看了一眼自己住了快一年的出租屋。</p><p>他不知道这一走，还会不会再回来。</p><p>归零社的地下训练场比他想象的要大得多。</p><p>这是一座建在地下三十米的设施，面积大概有两个篮球场那么大，层高超过十米。四周的墙壁是厚实的合金板，地面铺着特制的高强度复合材料，角落里堆着各种测试设备和训练器材。</p><p>杜煌被安排住进了一间单独的套间，里面有床、桌、椅和独立卫生间，虽然不大，但该有的都有了。</p><p>技术人员在他身上贴了几个监测芯片——贴在胸口、后背和手臂上，实时读取他的心率、肌电、骨密度等数据。</p><p>"这些数据会直接传到我们的分析系统，"一个戴眼镜的技术员说，"我们发现你的身体数据每天都在以固定的比例增长，非常规律，我们从来没有见过这么完美的指数增长曲线。"</p><p>杜煌看了一眼屏幕上的图表——一条笔直向上的曲线，像一座陡峭的山峰。</p><p>第十四天。</p><p>林筱雨来探视的时候，杜煌正穿着一件背心，在地下训练场里做测试。</p><p>他面前放着一台特制的测力器——一种用高强度合金制造的设备，专门用来测量超常能力者的力量数值。他深吸一口气，一拳打在测力器的靶面上。</p><p>显示屏上跳出一个数字：七十八万公斤。</p><p>大约相当于七百八十吨。</p><p>林筱雨站在场边，看着这个数字，沉默了好一会儿。</p><p>她走进场，在杜煌旁边的椅子上坐下，沉默了几秒后开口："我在想一件事。"</p><p>"你说。"</p><p>"你的力量每天翻倍，但从逻辑上讲，你的身体不可能凭空产生这么多能量。"林筱雨说，"你每天摄入的食物热量最多几千卡路里，不可能支撑这种级别的能量输出。"</p><p>杜煌想了想："所以你的意思是……"</p><p>"我的意思是，你的力量来源可能不是你自己。"林筱雨说，"你的身体更像是一个接收器，能量是从外部注入的。"</p><p>"外部？从哪注入？"</p><p>林筱雨摇了摇头："我不知道。但如果我的假说成立，那就意味着有一个外部能量场在持续地、有规律地向你输送能量。而且这个能量场的强度，大到难以想象。"</p><p>杜煌沉默了。</p><p>他想起秦伯说过的话——"你不是在变强，你是在被召唤。"</p><p>第十五天。</p><p>零点刚过，杜煌正在训练场里做力量测试，突然，他听到了一个声音。</p><p>那声音不是从耳朵听到的，而是直接出现在脑子里的。像是一个人在非常遥远的地方说话，声音模糊不清，断断续续。</p><p>"……第三十天……门……等待……"</p><p>杜煌猛地停下动作，环顾四周。训练场里只有他一个人，监控摄像头在头顶亮着红灯。</p><p>"谁？"他问。</p><p>没有人回答。</p><p>那个声音消失了，就像从来没有出现过一样。</p><p>第十六天，声音又来了。</p><p>这一次比上一次更清晰一些。他听出那是一个男人的声音，低沉而缓慢，像是隔着很远的距离在说话。</p><p>"……不要害怕……你是被选中的……"</p><p>杜煌捂住耳朵，但声音不是从耳朵进来的，捂耳朵没用。他大声问："你是谁？你在哪？"</p><p>"……第137位……"</p><p>声音又消失了。</p><p>杜煌去找秦伯。秦伯听完他的描述，沉默了很久，然后说了一句让杜煌后背发凉的话：</p><p>"你现在听到的不是幻听。那是跨越信号——你正在接收来自其他维度的信息。翻倍者的力量增长到一定程度，就会开始接收到那些信息。"</p><p>"其他维度？"杜煌的声音有些发紧。</p><p>"你以为这世界只有我们看到的这一个层面？"秦伯笑了笑，"小伙子，你才刚入门。到了第三十天，你会看到的东西，比你现在能想象的多得多。"</p><p>杜煌回到训练场，看着自己的双手。</p><p>今天他做了新的测试——一拳打在三十厘米厚的混凝土墙上。</p><p>拳头穿过了墙壁。</p><p>不是打裂，不是打碎，是直接穿了过去。他的拳头像是穿过了一层薄纸一样，在墙上留下了一个光滑的圆形孔洞。</p><p>更重要的是，在拳头穿过墙壁的那一瞬间，周围的空间出现了轻微的波动——空气像是被扭曲了一样，变得模糊不清。</p><p>监测设备的数据也证实了这一点。</p><p>技术员盯着屏幕上的读数，脸色发白："空间波动……他的力量已经开始影响空间结构了。"</p><p>杜煌站在那面被打穿的墙前，看着自己毫发无伤的手，心里涌起一种前所未有的感觉。</p><p>不是恐惧。</p><p>是一种说不清的期待。</p><p>他抬起头，看着天花板上那盏白色的大灯，脑子里又响起了那个声音。</p><p>这一次，声音比之前清晰了很多：</p><p>"……等待……就要到了……"</p>
