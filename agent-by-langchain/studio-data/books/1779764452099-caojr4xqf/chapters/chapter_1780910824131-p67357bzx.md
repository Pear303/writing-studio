# 第4章 归零社

<p></p><p>第八天，力量翻到二百五十六倍。</p><p>杜煌早上醒来的时候，明显感觉到身体和前几天又不一样了。那股暖流在零点时分准时出现，这一次的冲击比他预期的更强烈——他感觉自己的心脏像是被一只无形的手握了一下，然后一股巨大的能量从心脏向外迸发，沿着血管涌遍全身。</p><p>他躺在床上缓了好几分钟，等身体适应了这股新力量，才慢慢坐起来。</p><p>下床的时候，他一只脚踩在地砖上，瓷砖发出"咔嚓"一声——裂了。</p><p>杜煌低头看着脚下那块裂成两半的地砖，沉默了两秒，然后小心翼翼地把脚挪开。他蹲下来摸了摸裂缝，边缘很整齐，是被他的体重硬生生压裂的。</p><p>他叹了口气。</p><p>连正常走路都成问题了。</p><p>他尽量放轻脚步走进卫生间，用最轻的力气拧开水龙头洗漱。刷牙的时候，牙刷柄在他手里发出细微的吱嘎声，像是随时会被捏碎。他赶紧放松了手指的力道。</p><p>出门的时候，他特意换了一双软底的运动鞋，走路的时候像猫一样轻手轻脚。但即便如此，走廊上的地砖还是被他踩出了几道新的裂纹。</p><p>上班的路上，他全程紧绷着神经，生怕一不小心就弄坏什么东西。坐地铁的时候，他不敢拉扶手——怕把金属杆捏变形。他只能靠在车厢角落，双脚微微分开，尽量减小对地板的压强。</p><p>这种小心翼翼的感觉让他很憋屈。</p><p>但更让他不安的，是秦伯说的那些话。</p><p>他决定中午去一趟修鞋摊。</p><p>中午休息时间，杜煌走出公司大楼，快步往小区方向走。他远远就看到秦伯坐在修鞋摊前，正拿着一只皮鞋在打磨鞋底。</p><p>秦伯看到他的时候，一点都不意外，只是招了招手让他坐下。</p><p>"来了？坐。"</p><p>杜煌在马扎上坐下来，开门见山："秦伯，你说的那扇门，到底是什么？"</p><p>秦伯手上的活儿没停，一边打磨一边说："我也没见过。走到第三十天的人，没有一个回来的。"</p><p>"一个都没有？"</p><p>"没有。"</p><p>杜煌的心沉了沉："那我……"</p><p>"你先别想那么远的事。"秦伯打断他，"你现在才第八天，后面还有大把时间。你现在最应该担心的，不是第三十天，而是盯上你的人。"</p><p>"盯上我的人？"杜煌一愣。</p><p>"你以为你是第一个？"秦伯放下手里的鞋，摘下老花镜，"历史上出现过至少三个翻倍者，每一个都在中途消失了。不是自己消失的，是被人带走的。"</p><p>杜煌的心脏猛地一跳："谁？"</p><p>"一个叫'归零社'的组织。"秦伯说这个名词的时候，语气很平静，但眼神里透着一丝复杂，"他们专门处理超常能力者。有危险的，控制起来。有潜力的，带走研究。翻倍者这种级别的，他们绝对不会放过。"</p><p>杜煌张了张嘴，还没来得及追问，口袋里的手机突然震了一下。</p><p>他掏出来一看，是一条陌生号码发来的短信：</p><p>"你好，杜先生。我是归零社的特派员，想和你聊聊。今天下午三点，你公司楼下的快餐店见。不来也没关系，我会一直等。——宋明远。"</p><p>杜煌盯着屏幕上的字，后背一阵发凉。</p><p>他把手机递给秦伯看。秦伯扫了一眼，把手机推回来。</p><p>"去不去你自己决定。"秦伯说，"不过我提醒你——归零社的人，你躲不掉的。他们能找到你第一次，就能找到你第二次。"</p><p>杜煌在公司楼下的快餐店见到了宋明远。</p><p>这个男人看起来四十岁左右，穿着一件深灰色的夹克，头发梳得整齐，脸上带着温和的笑容。他坐在靠窗的位置，面前放着一杯没怎么喝的美式咖啡，看到杜煌走进来，朝他招了招手。</p><p>"杜先生，这边坐。"</p><p>杜煌在他对面坐下，没有点东西，直接说："你是怎么找到我的？"</p><p>"视频。"宋明远笑了笑，"你追摩托车的那段视频，虽然拍得不清楚，但你的身形特征和发力方式，稍微分析一下就能和你对上。何况……"他顿了顿，"你这个小区附近，我们已经关注了一段时间了。"</p><p>"关注什么？"</p><p>"异常能量波动。"宋明远从公文包里拿出一份文件夹，翻开推到杜煌面前，"从第五天开始，我们就在你的活动区域检测到了规律性的空间波动。每天同一时间，强度翻倍。非常明显的翻倍者特征。"</p><p>杜煌低头看着文件夹里的数据图表，上面画着一条完美的指数曲线，和他自己在笔记本上画的一模一样。</p><p>"你既然都知道了，那我想问一个问题。"杜煌抬起头，直视着宋明远的眼睛，"上一个翻倍者，去了哪里？"</p><p>宋明远的笑容微微收敛了一些。</p><p>他沉默了几秒，然后说："消失了。"</p><p>"消失是什么意思？"</p><p>"字面意思。"宋明远端起咖啡喝了一口，"上一个翻倍者，我们代号'预言者'，在第二十三天的时候，从我们的监控设施里消失了。没有留下任何痕迹，没有能量波动，没有打斗迹象。就是在零点翻倍的那一刻，人不见了。"</p><p>"不见了？"杜煌皱眉，"他是不是自己走了？"</p><p>"不可能。"宋明远摇头，"我们的设施有最高级别的防护，普通人不可能进出。而且监控画面显示，他就是在原地消失的——零点零分零秒，人还在；零点零分一秒，人没了。"</p><p>杜煌靠在椅背上，脑子里飞速运转。</p><p>"你们归零社，把我叫过去做什么？"他问，"控制我？研究我？"</p><p>宋明远笑了笑："我要是说'保护你'，你信吗？"</p><p>"不太信。"</p><p>"那就对了。"宋明远站起来，拿起桌上的文件夹，"我不强迫你跟我走。但你得明白一件事——你的力量每天都在翻倍，第八天你还能正常生活，但到了第十五天、第二十天，你一个人在外面，可能会伤到别人，也可能伤到自己。"</p><p>他把一张名片放在桌上，推到杜煌面前。</p><p>"想好了，随时给我打电话。"</p><p>宋明远走了以后，杜煌一个人在快餐店里坐了很久。</p><p>他把那张名片翻来覆去看了好几遍。名片很简洁，只有"宋明远"三个字和一个电话号码，没有任何公司名称和头衔。</p><p>他把名片揣进口袋，起身回了公司。</p><p>晚上回到出租屋，他把今天的事跟林筱雨说了一遍。</p><p>林筱雨听完，没有急着表态。她坐在沙发上，一只手托着下巴，沉默了好一会儿才开口："这个归零社，你有没有想过一个问题？"</p><p>"什么问题？"</p><p>"他们既然能监测到你的能量波动，说明他们的技术远超普通人的认知。"林筱雨说，"那他们为什么不直接把你带走？为什么还要派一个人来跟你'聊聊'？"</p><p>杜煌一愣。</p><p>"要么他们没你想的那么厉害，要么……"林筱雨的目光沉了沉，"他们在你身上另有所图，不想用强的手段，怕把你逼急了。"</p><p>杜煌想了想，觉得林筱雨说得有道理。</p><p>"那你的建议是？"</p><p>"去找那个修鞋的老爷子再聊聊。"林筱雨说，"他才是真正经历过翻倍的人。归零社说的那些话，是真是假，只有他能帮你判断。"</p><p>杜煌点了点头。</p><p>第二天一早，他又去了秦伯的修鞋摊。</p><p>这一次，秦伯没有让他坐，而是直接收起了摊子，对他说了一句："跟我来。"</p><p>秦伯带着他拐进了一条小巷，七拐八绕之后，来到一栋老旧居民楼的背面。秦伯从口袋里掏出一把钥匙，打开了一扇锈迹斑斑的铁门。</p><p>门后是一条通往地下的楼梯。</p><p>"下来吧。"秦伯率先走了下去。</p><p>杜煌跟着他往下走。楼梯很长，灯光昏暗，墙上都是潮湿的水渍。走到最底层，是一间大约二十平米的地下室。</p><p>秦伯打开灯，杜煌看到了这间地下室的摆设——一张木桌，几把椅子，一个书架上摆满了各种旧书和笔记，墙上挂着一张手绘的地图，上面标着一些他看不懂的符号。</p><p>秦伯在木桌前坐下，从抽屉里拿出一包烟，抽出一根点上。</p><p>"你知道我为什么在这里修鞋吗？"他吐出一口烟，问道。</p><p>杜煌摇头。</p><p>"因为我不想被归零社找到。"秦伯说，"我也是翻倍者。第十七天的时候，他们找到了我，把我带走了。后来我跑了，在这个小区隐姓埋名住了十几年，再也没用过那股力量。"</p><p>杜煌盯着秦伯，心里涌起一股寒意："你是说，归零社封印了你的力量？"</p><p>"封印？"秦伯笑了笑，笑容有些苦涩，"不是封印，是截断。他们用一种设备打断了我的翻倍周期，我的力量就停在了第十七天的水平，不再增长，但也……没消失。"</p><p>秦伯掐灭了烟，看着杜煌的眼睛：</p><p>"小伙子，归零社说的那些话，你信一半就行。但他们有一件事没骗你——上一个翻倍者，确实消失了。而我告诉你，他不是消失，他是……被带走了。"</p><p>"被谁带走？"</p><p>秦伯摇了摇头："我不知道。我只知道，在那个人消失的前一天晚上，他用某种方式给我传了一条消息。"</p><p>他从抽屉里拿出一张泛黄的纸条，推到杜煌面前。</p><p>纸条上只写了一行字：</p><p>"不要相信归零社。他们不是想保护你，他们是想阻止那扇门打开。"</p><p>杜煌看完这句话，掏出手机，拨通了宋明远的电话。</p><p>电话响了两声就接通了。</p><p>"宋先生，我想跟你确认一件事。"</p><p>"请说。"</p><p>"我要知道上一个翻倍者去了哪里。不是'消失'那种说法，是真正的答案。"</p><p>电话那头沉默了几秒。</p><p>然后宋明远的声音传来，比之前低沉了许多：</p><p>"你来我办公室，我当面跟你说。"</p>
