# 第一次接触

<p>六月清晨的阳光透过梧桐路188号二楼的窗户洒进来，在白色的床单上投下斑驳的光影。</p><p>夏芒从床上坐起来，揉着太阳穴，感觉脑袋里像是塞了一团浆糊。</p><p>昨晚他从厨房回到自己房间之后，翻来覆去地睡不着，脑子里全是怎么逃离地球的方案——A计划，连夜买票回老家；B计划，装病住院躲两天；C计划，干脆去西藏支教个一年半载。</p><p>结果他一个计划都没实施。因为半夜两点他偷偷打开房门的时候，听见楼下传来冯海天和花鱼联机打游戏的声音。</p><p>“花鱼你踏马别送！”</p><p>“我这是战术性撤退！”</p><p>“撤你妈，你撤到对面泉水里去了！”</p><p>“我迷路了嘛……”</p><p>夏芒默默关上了房门。</p><p>凌晨三点，他终于在无穷无尽的“为什么要和两个橙级大佬合租”这个问题中昏睡过去。</p><p>坐在床边，他决定今天必须主动出击，不能被恐惧捆绑。</p><p>早晨的事物，尤其是热气腾腾的早餐，天然具有缓解焦虑的功效。</p><p>夏芒下楼的时候，餐桌上已经摆好了：一锅白粥，几个水煮蛋，两碟咸菜，还有一屉刚买回来的小笼包。</p><p>花鱼坐在餐桌前，端着一碗粥，眼睛却盯着手机屏幕，时不时发出“鹅鹅鹅”的傻笑。冯海天还没起床，楼梯口传来他均匀的呼噜声。</p><p>“早啊，夏芒。”花鱼头也不抬地说，“粥在锅里，鸡蛋自己剥。”</p><p>“谢谢。”</p><p>夏芒给自己盛了一碗粥，坐下吃起来。白粥熬得恰到好处，浓稠绵密，小笼包皮薄馅足，一口咬下去汁水在嘴里炸开。</p><p>这个味道。这个平凡而美好的早餐的味道。</p><p>两个室友明明都是足以毁灭星球的大佬，为什么在日常生活里这么正常？</p><p>夏芒突然意识到一个更可怕的问题：也许他们太正常了，这才是最大的不正常。</p><p>一个剑仙为什么要住在三线小城的合租别墅里？一个星海旅者为什么要每天蒸包子、煮绿豆汤？</p><p>他们到底在图什么？</p><p>夏芒咽下最后一口粥，擦了擦嘴：“我出去逛会儿。”</p><p>“嗯嗯。”花鱼仍然头也不抬。</p><p>出了门，六月的阳光立刻热情地包裹住他。</p><p>梧桐路是一条老街区，两侧种满梧桐树，树荫遮天蔽日。夏芒沿着街道漫无目的地走着，目光掠过街道两侧的那些店铺：老字号的烧腊店、修自行车的摊子、卖凉茶的铺子。</p><p>他的脑子试图理清昨晚的冲击。</p><p>词条系统，他觉醒三个月了。普通人的极限是淡蓝色，爱因斯坦【相对论奠基者·淡蓝】、尼尔斯·玻尔【原子结构洞察者·淡蓝】。</p><p>橙色那是什么概念？</p><p>系统在他觉醒第一天就给过一个清晰的等级说明：白色是普通人，绿色是经过训练的优秀者，蓝色是人类极限天才，紫色则是传说中的超凡入圣者。</p><p>而橙色，等级说明只有一行字：“超出本世界认知极限，无法评估”。</p><p>一个超出地球认知极限的存在，现在正在二楼打呼噜，枕头边上可能还放着半袋没吃完的薯片。</p><p>这个设定，世界意识们看了都得摇头。</p><p>他路过了小镇的菜市场，路过了摆地摊卖二手书的老头，路过了正在下象棋的两个大爷。</p><p>一切都很正常。</p><p>头顶飘着的词条都是【买菜小能手·白】、【下棋爱好者·白】、【遛弯达人·白】。</p><p>夏芒忽然想起自己三个月前获得的一个特殊词条。</p><p>那是一个闷热的下午，他在城中村的一条小巷子里，遇到了一只猫。</p><p>那只猫浑身脏兮兮的，蹲在一个垃圾桶旁边，对着路过的流浪狗哈气，发出嘶嘶的声音。</p><p>哈气。哈气。哈气。</p><p>那只猫的头顶，飘着【哈气王者·淡绿】。</p><p>夏芒当时手贱，走过去想逗逗它，结果那只猫直接把目标对准了他，开始了疯狂哈气模式。</p><p>“哈——”</p><p>“哈——”</p><p>“哈——”</p><p>每一口都带着呲牙咧嘴的表情，尾巴炸成一根扫把。</p><p>夏芒蹲在地上，和那只猫对视了整整十五分钟。</p><p>他不动。</p><p>猫也不动，就一直哈气，哈到嗓子都要冒烟了。</p><p>最后那只猫气得转头就跑，跑出三米还回头哈了他最后一下：“哈！”</p><p>那也是夏芒最后一次获得词条的机会。</p><p>那天晚上，他在家尝试复制了这只猫的词条。因为【野兽直觉·淡绿】，虽然等级不高，但这个能力在危险预警方面是顶尖的。</p><p>那场复制花了整整四十分钟，差点把他的精神力榨干。</p><p>但现在，【野兽直觉·淡绿】已经安静地躺在他的词条库中，成为他重要的感知工具。</p><p>刚想到这个词条的时候，夏芒脑子里忽然闪过一丝异样的感觉。</p><p>不是冷。不是热。不是眼睛能看到，不是耳朵能听到。</p><p>纯粹是一种直觉。</p><p>有人在看他。</p><p>夏芒不动声色地继续往前走，余光扫视四周。</p><p>街道拐角处的便利店门口，一个穿黑色衣服的男人正在抽烟，目光若有若无地落在他身上。</p><p>词条浮现在那男人头顶：【胎膜侍者·深绿】。</p><p>深绿。</p><p>那意味着这个人在绿色等级中属于高阶，比普通优秀者还要高一个档次。</p><p>夏芒心往下沉。他一个刚高考完的高中生，何德何能被这种深绿色的家伙盯上？</p><p>他压低鸭舌帽的帽檐，加快脚步，拐进一条小吃街。穿过羊肉串摊子，绕过臭豆腐的小推车，在炸鸡排的摊位前停留两秒，假装看菜单，余光扫向后方。</p><p>黑衣男人还跟着他。保持着大约三十米的距离，假装在买烤冷面。</p><p>夏芒深吸一口气，继续往前走。他要找个适合动手的地方。</p><p>镇子东边有一片正在拆迁的老城区，平时没什么人。他记得那边有一条废弃的道路，来往的重型卡车很多，道路尽头是一个急转弯。</p><p>二十分钟后，夏芒站在拆迁区的一条巷子尽头。</p><p>这是一条死胡同。两侧是半拆的墙壁，前方是砖墙挡着。</p><p>他故意把自己逼入绝境。</p><p>果然，脚步声从巷口传来。</p><p>黑衣男人不紧不慢地走进巷子，嘴角挂着一丝微笑：“小朋友，往哪儿跑呢？”</p><p>夏芒转过身，脸上露出恰到好处的惊恐：“你、你是谁？”</p><p>“你不用知道我是谁。”男人从口袋里掏出一根烟，叼在嘴上，“你只需要跟我走一趟。”</p><p>“为什么？”</p><p>“这个问题，你到了地方自然会知道。”男人舔了舔嘴唇，“我建议你配合一点，免得吃苦头。”</p><p>夏芒咽了口唾沫：“我不会跟你走的。”</p><p>他的目光暗暗瞥向巷口的侧面，那条废弃的公路正好从侧面横穿过去。他计算过时间，每天上午九点四十分左右，会有一辆满载水泥的重型卡车经过那条路，车速很快。</p><p>而现在，四辆卡车缓缓驶过。最近的是一辆水泥搅拌车，稳稳地行驶在街道上，没有任何异常。</p><p>夏芒的计划很简单——让这辆车成为他的“帮手”。</p><p>他慢悠悠地后退，嘴里念叨着：“我跟你拼了！”然后突然转身，朝着死胡同的砖墙冲刺。</p><p>黑衣男人轻蔑地一笑，也跟着冲刺。</p><p>夏芒在距离砖墙还有两米的时候，猛地往侧面一扑，跳进了一个早就看好的豁口——那是一扇半拆的窗户，通向旁边的废弃建筑。</p><p>黑衣男人扑了个空，还没反应过来，夏芒已经钻进了窗户，再从另一侧冲了出去。</p><p>等黑衣男人追上来的时候，夏芒已经跑到了废弃公路上。</p><p>他看到那辆水泥搅拌车正以稳定的速度开过来。</p><p>“快来啊，大兄弟！”夏芒一边跑，一边故意朝着大卡车冲过去。</p><p>黑衣男人追得急，完全没有注意到那辆卡车。</p><p>就在卡车即将靠近的刹那，夏芒猛地向道路另一侧扑倒，翻滚躲进旁边的排水沟里。</p><p>卡车司机显然也没想到会有人在公路上玩这种把戏。他猛地踩下刹车，按响了巨大的喇叭！</p><p>“叭————！！”</p><p>黑衣男人被这突如其来的一幕惊呆了，下意识往旁边躲。</p><p>但他没注意到的是，卡车后面还拖着一根不起眼的铁链。</p><p>那铁链原本是搁在路边的，因为卡车急刹车，铁链猛地弹起，像条鞭子一样抽向黑衣男人！</p><p>“啪！”</p><p>铁链正中黑衣男人的腿骨，他惨叫一声，一个趔趄。</p><p>紧随其后的是卡车的一个急转弯。司机的方向拉得急，后车厢的尾部直接甩了过来，重重撞在黑衣男人身上。</p><p>“咚！”</p><p>那声音沉闷得像一袋水泥摔在地上。</p><p>黑衣男人连哼都没哼一声，直接软倒在地，昏死过去。</p><p>司机下车查看，骂骂咧咧：“卧槽，你他妈不要命了！大白天的跑公路上——”</p><p>“对不起对不起！”夏芒一骨碌爬起来，满脸诚恳地说，“我朋友喝多了，我拦不住他，他非要在公路上跑。”</p><p>“喝多了？我看他是磕了！”</p><p>司机骂骂咧咧一阵，估摸着也没出大事，又赶着送货，上车走了。</p><p>等卡车的轰鸣声远去，夏芒才走到昏迷的黑影前蹲下来。</p><p>黑衣男人肩上的武器早已脱手，身上的装备也摔得七零八落。夏芒小心翼翼地检查了他的口袋。</p><p>一个钱包。里面只有几百块钱，几张名片。</p><p>一张地图。地图上标着小镇西边的区域，其中一个位置用红笔圈了出来，旁边写着奇怪的符号。</p><p>一张船票。那是一张很破旧的船票，纸张发黄，烫金文字已经模糊不清，只能依稀看到几个字：“深蓝……号……午夜……”</p><p>夏芒皱起眉头。船票上印着一段代码：“24.5°N, 118.3°E”。</p><p>那是海上坐标。</p><p>他拿出手机搜索了一下，这个坐标的位置……距离他现在站的地方，直线距离不过两公里。</p><p>不远。</p><p>真的不远。</p><p>一股寒意顺着脊背爬上脑门。这意味着那个地方就在小镇的范围之内，随时都可以抵达。</p><p>他收起地图和船票，站起身，看了一眼地上还在昏迷的袭击者。</p><p>然后转身离开。</p><p>走出巷子的时候，夏芒的手在发抖。</p><p>不是因为恐惧，而是因为亢奋。</p><p>他已经本能地完成了危险评估：如果这个袭击者真的来源于某个势力，而那个势力就在两公里外，那么逃避没有任何意义。</p><p>他要知道为什么。</p><p>他要知道，一个普通的高考生，为什么会被深绿色的【胎膜侍者】盯上。</p><p>这一切，和那两个住在别墅里的橙级大佬有什么关系？</p><p>夏芒深吸一口气，走向手机地图上那个坐标标记的位置。</p><p>身后，昏迷男人的眼皮忽然微微颤动了一下。</p><p>但没有苏醒。</p>
