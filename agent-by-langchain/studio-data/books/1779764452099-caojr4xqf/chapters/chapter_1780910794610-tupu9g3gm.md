# 第2章 测试边界

<p></p><p>第三天零点到来的时候，杜煌已经做好了准备。</p><p>他坐在床边，手机屏幕亮着，倒计时归零的那一刻，那股暖流再次涌来。这一次的冲击比前两次都要猛烈，他感觉胸口像是被人猛推了一把，整个人往后仰倒在床上。</p><p>力量像是涨潮的海水，从心脏的位置向外翻涌。他能清晰地听到自己的心跳声，砰、砰、砰，每一次跳动都带着更强的力量感。手指不自觉地握紧，床单被他攥出了褶皱，几根线头直接崩断。</p><p>他躺了大概五分钟，等那股暖流完全融入身体，才慢慢坐起来。</p><p>看了看自己的手——指节比以前更突出了一些，手背上的青筋也更明显了。他用手指捏了捏床头的金属台灯底座，稍微一用力，金属表面就出现了一个浅浅的凹痕。</p><p>八倍力量了。</p><p>杜煌深吸一口气，起身换了一套深色衣服，把手机和钥匙揣进口袋，轻手轻脚地推开了房门。</p><p>客厅的灯已经关了，林筱雨的房门紧闭，里面没有声音。他踮着脚尖穿过客厅，拉开大门，闪身出去。</p><p>深夜的街道很安静，路灯把影子拉得很长。他快步走了大概二十分钟，来到一片废弃的建筑工地。这里原本是要建商品房的，开发商资金链断裂，停工了大半年，只剩下几栋没封顶的灰色楼体和满地钢筋碎石。</p><p>杜煌翻过围栏，踩着一地的碎砖走进去。</p><p>他先找了根钢筋。裸露在外的螺纹钢大概有小指粗，他单手握住一端，用力一掰——钢筋弯了。不是那种费尽全力才弯了一点的弯，而是像掰铁丝一样，轻松地弯成了一个U形。</p><p>他又找了根更粗的，拇指粗的螺纹钢。双手握住，发力，同样弯了，虽然比刚才费了点劲，但也远没到他的极限。</p><p>杜煌把弯掉的钢筋扔在地上，退后两步，然后突然发力冲刺。他本来只是想试试速度，但脚步刚一蹬地，整个人像是被弹射出去一样，几秒钟就冲到了二十米外。</p><p>他惊得赶紧刹住，脚底在碎石地上滑了老长一段才停下。</p><p>回头看了看刚才起跑的位置，他估算了一下，这段距离他平时跑大概需要五秒左右，刚才可能三秒都不到。</p><p>这不是八倍速度，他想，力量翻倍可能让肌肉的整体输出能力都提升了，包括爆发力。</p><p>他抬头看了看面前那堵两米多高的围墙。以前想翻过去得助跑加双手攀爬，现在他退了两步，轻轻一跃，手掌在墙头一撑，整个人就像跨过一道门槛一样翻了过去。</p><p>落地的时候他故意放轻了脚步，但还是在地面上踩出了两个浅浅的脚印——这里是泥土地，没铺水泥。</p><p>杜煌站在原地，环顾四周空旷的工地，心里涌起一种复杂的情绪。</p><p>兴奋肯定有。任何人突然获得这种力量都不可能不兴奋。但更多的是一种说不清的不安——这种力量来得太莫名其妙了，他不知道上限在哪里，也不知道代价是什么。</p><p>他掏出手机，打开备忘录，在上面写了一行字：</p><p>"初始力量值乘2的n次方，n为天数。"</p><p>按照这个公式，第1天是2倍，第2天是4倍，第3天是8倍，第4天是16倍。他盯着这行公式看了很久，直到手机屏幕自动熄灭。</p><p>回家的路上，他刻意放慢了脚步，尽量让自己看起来正常。路过一家二十四小时便利店时，他透过玻璃门看了一眼自己的倒影——看起来和平时没什么区别，没有变大只，也没有变壮。力量的增长似乎只体现在内部，外表没有明显变化。</p><p>这个发现让他稍微安心了一些。</p><p>第四天。</p><p>清晨六点，林筱雨难得出现在厨房。她穿着一件白色实验服外面套的灰色开衫，头发随意扎在脑后，正站在灶台前煮咖啡。</p><p>杜煌走进厨房的时候，她正端着咖啡杯转身，两个人差点撞上。</p><p>"早。"杜煌侧身让了让。</p><p>"早。"林筱雨看了他一眼，目光在他脸上停了一瞬，然后往下扫了扫，最后落在他露在外面的前臂上。</p><p>杜煌顺着她的视线看了看自己的胳膊。他穿了一件短袖T恤，胳膊上的肌肉线条确实比以前明显了一些。昨天还没这么明显，但今天翻到十六倍力量后，肌肉的紧实度肉眼可见地提升了。</p><p>"你最近在健身？"林筱雨问，语气平淡，听不出是在闲聊还是真的好奇。</p><p>"嗯，稍微练了练。"杜煌面不改色地撒了个谎。</p><p>林筱雨没再多问，端着咖啡回了自己房间。但她关门之前又回头看了他一眼，那个眼神让杜煌心里有点发毛——那不是单纯的打量，更像是在观察什么不寻常的东西。</p><p>白天上班的时候，杜煌比以前更小心了。开门的时候轻手轻脚，拿东西的时候控制力度，签字的时候生怕把笔按断。他发现自己对力度的控制能力也在提升——虽然力量变大了，但精细动作没有明显退步，只要他集中注意力，还是能像正常人一样做事。</p><p>这个发现让他松了口气。</p><p>下班后他又去了那个废弃工地。这次他打算做更多的测试。</p><p>他先用脚步丈量了一块平整的空地，量出大概一百米的距离。然后站在起点，深吸一口气，全力冲刺。</p><p>风在耳边呼啸，脚步落地的节奏快得像鼓点。他跑完一百米用了大概……他看了看手机计时器——六点八秒。</p><p>这个数字让他半天说不出话。</p><p>世界纪录是九秒五八。他一个没受过专业训练的人，随便一跑就是六秒八，而且是穿着普通运动鞋、在凹凸不平的泥土地上跑的。</p><p>如果他穿钉鞋，在标准跑道上，认真跑一次呢？</p><p>杜煌不敢继续想了。</p><p>他又测试了跳跃、投掷和反应速度。跳跃高度接近三米，能轻松摸到三楼阳台；随手扔出去的砖块飞出去一百多米远，砸在对面墙上碎成了粉末；反应速度快到能伸手抓住从高处掉落的碎石。</p><p>每一项测试结果都在告诉他同一个事实：他的力量正在以前所未有的速度增长。</p><p>第五天。</p><p>三十二倍力量。</p><p>这天晚上，杜煌又在废弃工地进行测试。他用脚踩了一下地面上的红砖——砖碎了，不是裂开，而是碎成了好几块。他只是正常踩了一脚，没用多大力。</p><p>他蹲下来看了看碎砖的截面，上面的裂纹是笔直的，像是被什么重物砸碎的。</p><p>"你最近经常晚归。"一个声音突然从他背后传来。</p><p>杜煌猛地转身，看到林筱雨站在工地围栏的缺口处，穿着一件深色外套，双手插在口袋里，正平静地看着他。</p><p>"你怎么……你跟踪我？"杜煌皱眉。</p><p>"你连续三天凌晨两三点出门，回来的时候一身灰和汗，我很难不注意。"林筱雨走进来，踩过地上的碎砖和钢筋，在他面前停下，"你在这做什么？"</p><p>杜煌沉默了几秒。他不知道该怎么解释，也不确定该不该解释。</p><p>林筱雨等了他几秒，见他不说话，弯下腰捡起地上那块被踩碎的红砖，看了看断裂面，又看了看杜煌的鞋底。</p><p>"你踩碎的？"</p><p>杜煌没说话。</p><p>林筱雨把碎砖放在手里掂了掂，然后抬头看着他，表情很认真："杜煌，你是遇到什么事了，还是……你身上发生了什么变化？"</p><p>她的措辞很谨慎，像是怕吓到他，但语气里透着一种笃定——她已经知道了什么，或者至少猜到了。</p><p>杜煌和她对视了几秒，最终移开了目光："我还不确定。"</p><p>"那你确定了再告诉我。"林筱雨没有逼问，转身往围栏方向走，走了几步又停下来，"对了，你最近最好不要在公共场所表现得太异常。网上已经有人在讨论一段视频了，虽然画质很差，但如果你继续这样下去，迟早会被人认出来。"</p><p>她说完就走了，丢下杜煌一个人站在满地碎砖的工地上。</p><p>杜煌掏出手机，打开计算器，输入：2的30次方。</p><p>屏幕上跳出一个数字：十亿七千三百七十四万一千八百二十四。</p><p>十亿倍。</p><p>他盯着这串数字，手心全是汗。</p><p>深夜回到房间，他坐在床边，把计算器上的数字又看了一遍。十亿倍。他想象不出来那是什么概念——如果现在的他就能轻松掰弯钢筋、跑进七秒以内，那十亿倍之后呢？</p><p>他关掉手机，躺下来，闭上眼睛。</p><p>但脑子里完全静不下来。那个公式像魔咒一样在他脑海里打转——初始值乘以2的n次方。指数级增长。每天翻倍。</p><p>他翻了个身，又翻了个身，最后索性坐起来，打开床头灯。</p><p>笔记本摊开在桌上，他拿起笔，在上面画了一个坐标轴。横轴是天数，纵轴是力量倍数。从第1天到第5天，曲线看起来还比较平缓——2、4、8、16、32，还在可以理解的范围内。</p><p>但当他继续往下画的时候，曲线在第10天开始陡然上升——1024倍。第15天是三万两千七百六十八倍。第20天已经超过了一百万倍。</p><p>他画不下去了。</p><p>笔尖停在坐标纸的第30天位置，那里没有任何标注，因为十亿倍这个数字大到已经超出了他对"力量"这个概念的认知范围。</p><p>杜煌合上笔记本，关了灯，在黑暗中睁着眼睛。</p><p>窗外路灯的光透过窗帘缝隙照进来，在天花板上投下一道细长的光影。他就那样躺着，看着那道光影，直到天亮。</p>
