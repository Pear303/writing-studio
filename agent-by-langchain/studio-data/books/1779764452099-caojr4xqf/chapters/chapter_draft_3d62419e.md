# 第5章 方块与噩梦

回到别墅的时候天已经黑了。

花鱼坐在客厅的沙发上，手里拿着那枚拉莱耶雕像的碎片，指尖轻轻摩挲着光滑的表面。她的表情很少见地出现了一丝凝重。

冯海天靠在厨房的门框上，端着一杯凉白开慢慢喝着，没有说话。

夏芒坐在花鱼对面，把那天在废弃厂房被追踪、今天在地下室看到的一切都讲了一遍。花鱼听完之后沉默了很久，然后把那枚碎片放到了茶几上。

"拉莱耶。"她轻声说。

"那是什么？"夏芒问。

花鱼抬起头，目光穿过窗户看向远方的夜空。她的眼神像是在看很远很远的东西。

"一个名字。"她说，"一个不应该出现在地球上的名字。我曾在星图中看到过它的残影——在宇宙深处某个坐标，有一片被遗忘的领域。那里有一座城市，建筑不符合任何几何学规则，街道转折的角度在三维空间中无法闭合。整座城市被墨绿色的海洋包围，永远沉在黑暗之中。"

夏芒听得头皮发麻。花鱼的描述和他在地下室看到雕像碎片时脑海中闪过的画面一模一样。

"那个邪教在崇拜它？"他问。

"不是崇拜。"花鱼纠正他，"是在试图唤醒它。拉莱耶的状态很特殊——它不在我们的维度，但又和我们的世界有某种联系。那些方块符号是一种坐标，用来标记两个维度之间的薄弱点。他们把符号刻在建筑物上，用来扩大这种联系。"

"那他们抓觉醒者干什么？"

"觉醒者的灵魂能量可以用来加固维度通道。"花鱼说，"拉莱耶需要足够的能量才能从沉睡中苏醒。"

夏芒沉默了几秒钟，然后问出了那个最关键的问题："它醒了会怎么样？"

花鱼没有回答。

但她的沉默本身就是一个答案。

那天晚上，夏芒躺在床上，脑子里反复回放着花鱼说的话。窗外传来夏夜的虫鸣声，偶尔有一阵凉风吹进来，但他总觉得房间里闷得透不过气来。

他翻了个身，闭上了眼睛。

然后他做了一个梦。

梦里他站在一片无尽的墨绿色海洋中央。没有陆地，没有天空，只有浓稠的绿色海水和灰蒙蒙的雾气。海水在缓慢地流动，像是某种活着的生物在呼吸。

海面上浮着一座城市。

那是一座黑色的城市，所有建筑都由不规则的几何体构成——有些建筑的角度向内折叠，有些建筑的墙壁同时朝两个方向弯曲，有些建筑看起来是立方体，但转一个角度就变成了完全不同的形状。街道在三维空间中扭曲折叠，像是某种诡异的谜题。

夏芒尝试着向前走了一步。脚下的海水冰冷刺骨，像无数根针扎进他的脚底。但一股无形的力量推着他的后背，逼着他继续往前走。

城市的入口是一道巨大的拱门，拱门的形状不是半圆形，而是一种他无法用语言描述的形状——每次他试图记住那个形状，脑子就会产生一阵刺痛。

拱门两侧刻着密密麻麻的方块符号，和他在废弃厂房墙上看到的一模一样。

夏芒想停下来，但他的身体不听使唤。他一步一步地走向那道拱门，海水越来越深，从脚踝漫到膝盖，再漫到大腿。

冰冷的海水像是有生命一样，贴着他的皮肤向上攀爬，试图把他整个人吞没。

就在这时，他听到了声音。

低沉的、含混的、从深海传来的声音。像是一百个人在同时低语，又像是一只巨大的生物在深海中呼吸。那些声音重叠在一起，汇聚成一个模糊的词——拉莱耶。

拉莱耶。

拉莱耶。

那个名字一遍又一遍地回荡在他的脑海里，像咒语一样纠缠着他的意识。

夏芒猛地睁开眼睛。

天花板。吊灯。熟悉的卧室。

他大口喘着气，后背的衣服已经被冷汗浸透了。他的心脏在胸腔里疯狂跳动，像是一只被困住的鸟。

他坐起来，伸手去拿床头柜上的水杯。

但他停住了。

他的右手臂上，那个灰色的方块印记扩大了。原本只有硬币大小的印记已经扩散到了整个前臂，而且颜色从灰色变成了紫色。暗紫色的线条像是某种血管网络，沿着他的手臂向上蔓延。

夏芒盯着自己的手臂，呼吸变得急促起来。

他试着用手去触碰那些紫色的纹路，指尖刚一接触，一种尖锐的刺痛感从手臂传来，像是有无数根细针在皮肤下面游走。

他咬紧牙关，没有叫出声。

第二天早上，夏芒发现自己的精神状态明显变差了。他的注意力无法集中，脑子里时不时会出现一些奇怪的画面——墨绿色的海，黑色的城市，扭曲的拱门。那些画面一闪而过，但每次都让他心跳加速，手心冒汗。

他试着用那些学习型词条来对抗这种状态，但他发现词条的效果越来越弱，像是被什么东西压制住了。

第三天晚上，噩梦再次降临。

这一次的梦境比之前更加清晰。

夏芒站在那座黑色城市的主干道上，周围是高耸的不规则建筑。天空中没有星星，只有一片混沌的灰绿色。城市的尽头是一座巨大的方形建筑，像是一座庙宇，庙宇的门楣上刻着一行巨大的方块符号。

他知道那些符号的意思——拉莱耶。

他走向那座庙宇，脚下的石板路在诡异的角度上拐弯，每走一步都会穿过一个不可能存在的几何转角。他的大脑在尖叫着告诉他这些角度是错误的，但他的眼睛告诉他它们确实存在。

这种矛盾感让他几乎要呕吐。

庙宇的大门敞开着，里面漆黑一片。但黑暗之中有东西在动。

夏芒站在门口，浑身僵硬。他不想走进去，但他控制不了自己的身体。

就在他一只脚跨过门槛的瞬间——

一只手从黑暗中伸出来，握住了他的手腕。

那是一只白皙的手，手指修长，带着一种冰凉的温度。

夏芒猛地回过头，看到了花鱼的脸。

她站在他身后，穿着一件简单的白色衬衫，头发在梦境的风中轻轻飘动。她的表情很平静，但夏芒能看到她眼底深处有一丝紧绷。

"别进去。"花鱼说。

她的声音直接穿透了梦境的迷雾，像一盏灯照进了夏芒混乱的意识里。

夏芒张了张嘴，想说什么，但花鱼已经拉着他转身往回走。她的步伐不快，但每一步都很坚定，带着一种不容置疑的力量。

周围的黑色建筑在后退，墨绿色的天空在变淡，那些低语声在逐渐消失。

花鱼拉着夏芒穿过扭曲的街道，穿过那道拱门，走出城市，走回墨绿色的海面上。

然后她用力推了他一把。

夏芒感到一阵强烈的失重感，仿佛从高处坠落——

他猛地睁开了眼睛。

这一次他醒来的地方是自己的卧室。天已经蒙蒙亮了，窗外传来清脆的鸟鸣声。晨光透过窗帘的缝隙洒进来，在地板上画出一道淡金色的光带。

夏芒喘着粗气，浑身都被冷汗浸透了。他低头看了一眼自己的手臂——紫色的印记已经蔓延到了肩膀的位置，颜色比昨天更深了。

但他更惊讶地发现，花鱼站在他的房间里。

她靠在窗边，晨光照在她的侧脸上，轮廓柔和。她手里捏着一枚小小的蓝色晶体，晶体正在发出微弱的光芒。

"你进到我梦里了？"夏芒哑着嗓子问。

花鱼点了点头。

"那些墨绿色的海和黑色的城——"

"是拉莱耶。"花鱼说，"碎片在影响你。你接触了那个雕像，你的意识已经和它建立了连接。每次你入睡，连接就会加深一次。"

她走到床边，俯下身，把蓝色晶体按在夏芒手臂上的印记上。

晶体碰到印记的瞬间，夏芒感到一阵灼烧般的疼痛。他咬紧牙关，看着那些紫色的纹路在蓝色光芒的照射下开始收缩、变淡。

花鱼闭着眼睛，嘴唇轻轻动着，像是在念什么。那种语言古老而悠远，和夏芒之前在邪教地下室里听到的诵念声有些相似，但给人的感觉完全不同——花鱼的声音清澈而宁静，像是夜空中遥远的星光。

大约过了一分钟，花鱼睁开眼睛，收起了蓝色晶体。

夏芒手臂上的紫色印记缩小了一半，颜色也从深紫色变成了浅灰色。

"暂时压制住了。"花鱼说，"但根源没有解决。"

"什么意思？"

"碎片还在你身上。"花鱼看着他，"那些邪教成员虽然死的死逃的逃，但他们已经完成了最关键的仪式——坐标标记。你现在就是一个活的坐标，拉莱耶可以通过你定位到这个世界。"

夏芒感到一股寒意从脊背升起。

"那怎么办？"

花鱼没有回答。她看向窗外，目光落在别墅外面的庭院里。

"它来了。"她说。

夏芒一愣："什么？"

花鱼的表情变了。

那不是恐惧，更准确地说是一种警觉——就像一只猫突然竖起耳朵，感觉到了某种看不见的威胁。

她快步走到窗边，拉开窗帘。

窗外，天已经亮了。太阳从东边的地平线上升起，把整片天空染成了淡金色。庭院里的桂花树在微风中轻轻摇晃，一切都显得安静而祥和。

但花鱼的目光没有停留在庭院里。她抬着头，看向天空。

夏芒顺着她的目光看去，什么都没看到。但他能感觉到——空气中有一种说不出的变化。温度没有变，风没有变，阳光也没有变，但有什么东西变得不一样了。

花鱼的声音很轻："我们在被注视。"

"被谁？"

花鱼没有回答。但她的目光始终没有从天空中移开。

几秒钟后，夏芒也感觉到了。不是看，是一种更原始的感觉——像是有某种巨大的、超乎人类认知范围的存在，正从遥远的地方注视着这里。

不是注视他，不是注视花鱼，也不是注视这栋别墅。

而是注视这一整片区域。

整栋别墅，连同庭院和周围的树木，都被那道目光笼罩在内。

夏芒感到一股强烈的压迫感，像是空气突然变得粘稠了。他想动，却发现自己的四肢变得僵硬，连抬一根手指头都困难。

花鱼站在原地，一动不动。她的手指握紧了那枚蓝色晶体，指节泛白。

客厅的门忽然被推开了。冯海天快步走了进来，他的脸色是夏芒从未见过的严肃。他的手里握着那柄透明长剑，剑身在白天的阳光下依然清晰可见，流转着幽蓝色的光芒。

"感觉到了？"冯海天问花鱼。

"感觉到了。"花鱼说。

"多久了？"

"大约三十秒。"

冯海天走到窗边，和花鱼并肩站立，同样抬头看向天空。他的表情凝重，但他的握剑的手很稳。

"妈的。"他说，"这一眼不是冲我们来的。"

"那是冲谁？"

冯海天转过头，看了一眼坐在床上的夏芒。

夏芒的瞳孔微微收缩。他低头看向自己的手臂——那些刚刚被花鱼压制下去的紫色印记，又重新浮现出来了，而且颜色比之前更深，蔓延的速度更快。

几乎是在同一瞬间，一道灰绿色的光芒从天际落下，穿透屋顶、穿透天花板、穿透夏芒卧室的天花板，照在他的身上。

夏芒感到一阵撕裂般的剧痛，从身体的每一个角落同时涌来。

他听到了那个声音——

拉莱耶。

拉莱耶。

拉莱耶。

三个音节，像是三记重锤砸在他的灵魂上。

然后他失去了意识。
