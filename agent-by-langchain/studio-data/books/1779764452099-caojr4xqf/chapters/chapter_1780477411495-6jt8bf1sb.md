# 第2章 别墅与橙光

<p>高考结束后的第三天下午，夏芒拖着一个行李箱，站在稷海市西郊听澜别墅区的大门口。</p><p>说是别墅区，其实更像是一个隐藏在闹市边缘的秘境。高大的法国梧桐沿着街道两侧排开，浓密的树荫把盛夏的烈日过滤成斑驳的光点。街道干净得几乎一尘不染，两侧是一栋栋风格各异的独栋别墅，欧式的、现代简约的、中式园林的，错落有致地分布在绿植之间。</p><p>夏芒低头看了一眼手机上的地址：听澜路188号。</p><p>他沿着街道走了大约五分钟，在一栋米白色外墙的独栋别墅前停了下来。这栋别墅不算太大，但设计得很精致，门口种着一棵桂花树，院子里有几株修剪整齐的月季。围墙上爬满了常青藤，给这栋别墅增添了几分年代感。</p><p>月租八百块。</p><p>夏芒站在门口，怎么也想不通这个价格是怎么来的。就算是在稷海市这种二线城市，西郊别墅区的单间月租也至少三千起步，整栋别墅怎么也得七八千。八百块——这跟白住有什么区别？</p><p>他按了按门铃。</p><p>等了大约十秒钟，门开了。</p><p>开门的是一个看起来二十出头的年轻人，穿着一件松松垮垮的白色T恤和灰色短裤，头发有点乱，像是刚睡醒的样子。他靠在门框上，懒洋洋地打量了夏芒一眼，打了个哈欠。</p><p>"你就是夏芒？我妈说有个小孩要来合租，就是你吧。"</p><p>夏芒点点头："你好，我是夏芒。请问你是……"</p><p>"冯海天。"年轻人侧身让开一条路，"进来吧，二楼左手边那间空着，你自己收拾。水电燃气平摊，网费我出。"</p><p>说完他就转身走了，拖鞋在木地板上啪嗒啪嗒响，往客厅的沙发上一倒，继续看手机。</p><p>夏芒拖着行李箱进了门。</p><p>玄关不大，但收拾得很干净。换了拖鞋走进去，客厅比他想象的要大得多，落地窗外是一个小院子，阳光透过玻璃洒在木地板上。沙发上除了冯海天，还坐着一个人。</p><p>那是一个看起来比冯海天还小的年轻人，大概也就十八九岁的样子，穿着一件深蓝色的卫衣，戴着兜帽，低着头在翻一本很旧的书。他长得很清秀，皮肤白皙，五官精致得像是从画里走出来的。</p><p>听到脚步声，他抬起头看了夏芒一眼，微微点了点头，算是打过招呼，然后又低下头继续看书。</p><p>"那是花鱼。"冯海天躺在沙发上头也不抬地说，"也住这儿。平时不怎么说话，你别介意。"</p><p>"花鱼？"夏芒愣了一下，"这名字……"</p><p>"真名。"花鱼头也不抬，声音很轻，像是怕吵到谁似的。</p><p>夏芒点点头，拉着行李箱往二楼走。路过客厅的时候，他下意识地看了一眼冯海天。</p><p>然后他愣住了。</p><p>冯海天头顶，赫然飘着一行字——</p><p>【混元无极剑仙·橙】</p><p>橙色的字。</p><p>不是白色，不是绿色，而是橙色的。</p><p>夏芒的眼睛瞬间瞪大了。他使劲眨了眨眼睛，但那行字纹丝不动地悬浮在冯海天头顶，橙色的光芒在阳光下微微闪烁，透着一股说不出的压迫感。</p><p>等等。</p><p>夏芒猛地转头看向花鱼。</p><p>花鱼头顶也有一行字——</p><p>【星海旅者·橙】</p><p>同样是橙色。</p><p>两个橙色词条。</p><p>夏芒的大脑在那一瞬间几乎停止了运转。他今天早上还在想要怎么完成那个"找到第二位词条持有者"的任务，结果现在眼前就出现了两个拥有橙色词条的人。</p><p>白色是最低级的，绿色是普通，橙色……他之前完全没见过这个颜色。按直觉来判断，白&lt;绿&lt;蓝&lt;紫&lt;橙&lt;红，橙色应该已经是非常高的品质了。</p><p>也就是说，他的两个合租室友，拥有他完全看不懂等级的词条。</p><p>而且——混元无极剑仙？星海旅者？</p><p>这他妈的是什么词条？</p><p>夏芒站在原地，保持着拉着行李箱的姿势，整个人像被施了定身术一样。</p><p>冯海天似乎察觉到了什么，从手机屏幕上抬起目光，斜着眼睛看了夏芒一眼。他的眼神和刚才不一样了，刚才是一副懒散的、爱答不理的样子，但现在那双眼睛里多了一丝审视的光芒。</p><p>"怎么了？"冯海天问。</p><p>"没、没什么。"夏芒赶紧收回目光，"房间是二楼左手边那间对吧？我先上去收拾。"</p><p>"嗯。"</p><p>夏芒几乎是逃也似的上了二楼。</p><p>他推开左手边那间房的门，把行李箱拖进去，关上门，靠着门板大口喘气。</p><p>刚才那是什么？</p><p>两个橙色词条的人，和他合租在一栋月租八百块的别墅里？</p><p>夏芒的脑子里乱成一团。他走到窗边，深呼吸了几口气，试图让自己冷静下来。但那两个橙色的词条像烙印一样刻在他的视网膜上，挥之不去。</p><p>混元无极剑仙。</p><p>星海旅者。</p><p>这根本就不是正常人该有的词条。这两个人到底是什么来历？他们为什么会在稷海市？</p><p>夏芒忽然意识到一件事——他这次搬家，恐怕不是什么普通的合租。</p><p>他深吸一口气，打开房门，走下楼去。</p><p>客厅里，冯海天还是那副懒散的样子窝在沙发上刷手机，花鱼依旧在低着头看书。一切都和刚才一模一样，仿佛什么都没发生过。</p><p>但夏芒知道，不一样了。</p><p>他走到客厅，在另一侧的沙发上坐下来。花鱼抬头看了他一眼，又低下头。冯海天倒是把手机放下，伸了个懒腰。</p><p>"你那房间还行吧？空调是新的，WiFi密码贴在路由器上。"冯海天说。</p><p>"挺好的，谢谢。"夏芒点点头。</p><p>沉默了几秒钟。</p><p>冯海天忽然开口："夏芒，我问你个问题。"</p><p>"什么问题？"</p><p>"你刚才……看到什么奇怪的东西了吗？"</p><p>夏芒的心脏猛地一跳。</p><p>冯海天的语气很随意，像是随口问问，但那双眼睛一直在看着他，目光锐利得像刀子。</p><p>"奇怪的东西？"夏芒努力让自己的语气显得正常，"你是指什么？"</p><p>"没什么。"冯海天笑了笑，重新躺回沙发上，"就是随便问问。对了，提醒你一件事。"</p><p>"什么事？"</p><p>"晚上别上三楼。"</p><p>夏芒一愣："为什么？"</p><p>"三楼是我和花鱼放东西的地方，有些东西比较……危险。"冯海天说得很轻松，但语气里带着一种不容置疑的意味，"你要是上去了，出了什么事我可不负责。"</p><p>夏芒看着冯海天那张似笑非笑的脸，心里涌起一股说不清道不明的感觉。</p><p>"知道了，我不会上去的。"他说。</p><p>"那就好。"</p><p>花鱼这时候忽然合上了书，抬起头来。她的目光落在夏芒身上，上上下下打量了一番，最后停留在他脸上。</p><p>"你刚觉醒？"</p><p>夏芒愣住了。</p><p>花鱼的声音很轻，但每一个字都清清楚楚地砸进了夏芒的耳朵里。</p><p>"你、你说什么？"夏芒下意识地问。</p><p>花鱼没有重复，只是看了他一眼，然后站起来，拿着书往楼上走去。走了几步，她停下来，侧过头说了一句："他身上的词条是空白的。"</p><p>这句话是对冯海天说的。</p><p>冯海天挑了挑眉，看了夏芒一眼，若有所思地点了点头："知道了。"</p><p>花鱼上楼去了，客厅里只剩下夏芒和冯海天两个人。</p><p>夏芒感觉自己像是被扒光了一样站在这里。花鱼那句话——"你刚觉醒？"——就像是直接看穿了他的底牌。</p><p>"别紧张。"冯海天忽然笑了，拍了拍沙发旁边的位置，"过来坐。"</p><p>夏芒犹豫了一下，还是走了过去坐下。</p><p>冯海天看着他，眼神里带着一丝戏谑，但更多的是一种说不清的意味。他沉默了几秒钟，然后说道："你能看到词条，对吧？"</p><p>夏芒的身体僵住了。</p><p>"别紧张，我不是在诈你。"冯海天摆了摆手，"花鱼说你是空白的，那就说明你确实觉醒了词条系统，但还没生成自己的词条。这种情况我见过一次，不过那是很多年前的事了。"</p><p>夏芒张了张嘴，想说什么，但最终只是问了一句："你们……到底是什么人？"</p><p>冯海天笑了笑，站起来走到落地窗前，看着外面被夕阳染红的院子。</p><p>"这个问题说来话长。"他说，"不过既然你已经觉醒了，而且恰好搬到了这里，那说明有些事情是躲不开的。你以后会慢慢知道的。"</p><p>他转过身来，看着夏芒，表情难得地变得认真了一些。</p><p>"今天先好好休息。晚上不管听到什么声音，都不要出来。明天我带你熟悉一下这边的情况。"</p><p>夏芒点了点头，但心里却翻涌着无数的疑问。</p><p>那天晚上，夏芒躺在二楼的房间里，翻来覆去睡不着。</p><p>大约凌晨一点钟的时候，他听到楼下院子里传来一声轻微的呼啸声，像是有什么东西划过空气。</p><p>他犹豫了一下，还是走到窗边，拉开窗帘的一角往外看。</p><p>然后他看到了让他终生难忘的画面。</p><p>院子里，冯海天站在月光下，手里握着一柄剑——不，那不能叫"握"，那柄剑是凭空出现在他手中的，从虚空中缓缓抽出，剑身透明如水，在月光下泛着幽蓝色的光芒。</p><p>冯海天轻轻挥了一剑。</p><p>一道银白色的剑气从剑尖飞出，划过夜空，在百米外的湖面上切开一道细长的水痕，然后消失不见。水痕缓缓合拢，就像什么都没发生过一样。</p><p>夏芒几乎忘了呼吸。</p><p>他看向另一个方向——别墅的屋顶上，花鱼坐在那里，仰头看着星空。她的手里捏着一枚很小的东西，像是某种晶体，在月光下闪烁着微弱的星光。她的嘴唇在动，像是在念着什么，声音太低听不清，但那语调古老而悠远，不像任何一种夏芒听过的语言。</p><p>夏芒缓缓放下窗帘，坐回床上。</p><p>他低头看着自己的手。二十个词条还在，他还能清晰地感知到它们的存在。但和院子里的那两个人比起来，他这二十个绿色和白色的词条，简直就像是蚂蚁在仰望大象。</p><p>他想起系统界面上的那行字——"找到第二位词条持有者"。</p><p>他找到了。而且不只一位，是两位。</p><p>但他们和他完全不是一个级别的存在。</p><p>混元无极剑仙。</p><p>星海旅者。</p><p>夏芒躺回床上，盯着天花板。窗外又传来一声轻微的剑鸣，然后归于寂静。</p><p>他知道，从今天开始，他的生活将彻底不同。</p><p>这栋月租八百块的别墅，是他踏入另一个世界的入口。</p>
