# 第6章 翻倍者的遗产

第十七天。

杜煌的力量已经增长到了一个难以测量的程度。地下训练场里的测力器在昨天就达到了上限，显示屏上只显示"超量程"三个字。

技术员们已经放弃了对力量数值的直接测量，转而监测其他的参数——空间波动频率、能量辐射强度、以及杜煌身体周围的"场"的变化。

"他的身体周围出现了一种我们从未见过的能量场，"技术员向宋明远汇报，"像是一层看不见的屏障，半径大约一米左右。而且这个范围每天在扩大。"

宋明远站在监控室里，隔着玻璃看着训练场里的杜煌。他正在做冥想——这是秦伯教他的方法，通过控制呼吸来压制脑子里的"声音"。

"让他继续。"宋明远说。

这天下午，秦伯来了。

他穿着一件旧棉袄，背着手走进训练场，看了看四周那些高科技设备，不屑地哼了一声。

"这些东西测不出什么。"他说，"翻倍者真正的力量，不在肌肉里。"

杜煌睁开眼睛："秦伯，你来了。"

"跟我走一趟。"秦伯说，"我带你去个地方。"

秦伯带着杜煌离开了地下训练场，开车去了老城区。

车子在一栋老旧的居民楼前停下。杜煌看了看这栋楼——至少有三四十年历史了，外墙的涂料斑驳脱落，楼道里堆满了杂物。

"这是我以前的房子。"秦伯说，"你跟我来。"

他们上了三楼，秦伯掏出钥匙打开一扇铁门。屋里很暗，窗帘拉得严严实实，家具上都盖着白布，像是很久没人住了。

秦伯走到客厅的角落，蹲下来，用手指敲了敲地板。那里有一块地板砖的声音和别处不一样——是空心的。

他用手轻轻一扣，地板砖被撬了起来，露出下面的一个暗格。

暗格里放着一本手写的笔记本，和一块黑色的小石头。

秦伯把这两样东西拿出来，递给杜煌。

"这是上一个翻倍者的遗物。"他说，"我藏了三十年。"

杜煌接过笔记本，小心翼翼地翻开。纸张已经泛黄，边角有些破损，但上面的字迹依然清晰可辨。字体很工整，看得出写字的人很认真。

他翻到第一页，上面写着：

"我叫陆远，今年三十一岁。如果有人在读这本笔记，说明翻倍者又出现了，而我已经不在这个世界了。"

杜煌抬起头看了秦伯一眼。

"继续往下看。"秦伯说。

杜煌低下头，继续翻阅。

陆远的笔记详细记录了他作为翻倍者的每一天——从第1天到第23天。杜煌一页一页地翻过去，越看越心惊。

在第5天的记录里，陆远写道："我发现力量的增长不是线性的。不仅是肌肉力量，感知力、反应速度、甚至直觉都在提升。我开始能'感觉'到一些不存在的东西。"

第10天："能量场的存在被我证实了。我把一块金属放在身边，它会在零点时微微发热。翻倍者的能量不是来自体内，而是来自外部某个'场'。"

第15天："我开始做同一个梦。梦里有一扇发光的门，门后面是白色的光，有人在光里说话。我听不清他在说什么，但我能感觉到——那不是恶意。"

第18天："我的身体开始发生奇怪的变化。不是变强壮，而是变得……轻。像是我的身体和这个世界之间的某种联系正在减弱。我开始觉得自己不属于这里。"

第22天："今天，我在零点的那一刻，看到了那扇门。它没有打开，但我看到了它的轮廓——悬在半空中，由光线构成。归零社的人没有发现。他们检测不到那扇门。"

最后一页，第23天：

"明天，我会主动打开那扇门。归零社想阻止我，但我知道他们错了。这扇门不是危险的来源，而是出口。翻倍者的终点不是强大，是离开。

如果你正在读这段文字，请你记住一件事：不要害怕第三十天。那不是终点，那是开始。门后的世界，才是我们真正的归属。"

杜煌合上笔记本，手心微微出汗。

他拿起那块黑色石头，翻来覆去地看了看。石头大约有鸡蛋大小，表面光滑，呈深黑色，在光线下微微反射出一种金属般的光泽。

"这是什么？"他问秦伯。

"我不知道。陆远留下的，说这是'钥匙'。"秦伯说，"我研究了很多年，没有研究出什么。但我觉得，它不是给这个世界的。"

杜煌把石头握在手里，突然感觉到一阵微弱的震动——不是石头在震，是他的皮肤在接触到石头时产生了一种共鸣。

他愣了一下，把石头握得更紧了一些。

震动变得更明显了。

"你感觉到了？"秦伯看着他。

"感觉到了。"杜煌说，"它在……跟我呼应。"

回到地下训练场后，杜煌把黑色石头交给了林筱雨。

林筱雨把它带到了自己的实验室，用各种仪器做了扫描分析。结果让她大为震惊——这块石头不是由任何已知元素构成的。

"它的原子结构很特殊，"林筱雨在电话里说，"常规的光谱分析完全失效。我换了一种方法，用非热辐射检测仪去扫描它——结果发现它在持续发出一种微弱的信号。"

"什么信号？"

"频率……和你身体周围的空间波动频率完全一致。"林筱雨的声音里带着一丝压抑不住的兴奋，"杜煌，这块石头和你的能量场是同源的。它来自同一个来源。"

杜煌盯着桌上那块黑色的石头，沉默了很长时间。

第21天到第28天，杜煌没有再做任何力量测试。

他不再关心自己现在有多少倍力量——反正已经大到测不出来了。他把所有的精力都放在了冥想上。

秦伯说，那些"声音"不是干扰，而是指引。他越抵抗那些声音，声音就会越强烈。但如果他学会倾听，学会接纳，那些声音会告诉他该怎么做。

杜煌每天花至少八个小时进行冥想。他盘腿坐在地下训练场的中央，闭上眼睛，放空大脑，让那些"声音"自然流进他的意识。

起初很难。那些声音断断续续，像是收音机没调好频道，夹杂着噪音和杂音。但随着时间推移，他越来越能抓住那些声音的规律。

到了第24天，他第一次"看"到了门。

那是一扇由纯粹的光构成的巨门，悬浮在一片白色的虚空之中。门的高度目测超过十米，表面流动着银白色的光纹，像是活着的生物。

杜煌在看到它的瞬间，心里涌起一种说不清的熟悉感。

这种感觉很奇怪。他明明从未见过这扇门，但它给他的感觉却像是阔别多年的老朋友。

他想靠近它，但刚迈出一步，意识就断了——他被弹回了现实。

第28天晚上，杜煌从冥想中睁开眼，眼眶有些发红。

他已经能够清晰地听到那个声音了。那个低沉而缓慢的声音，说的每一句话他都能听懂。

那个声音告诉他：第30天零点，门会打开。他只需要走进去。

没有恐惧，没有犹豫。

他坐在桌前，拿出一支笔和三张纸。

第一封信是写给林筱雨的。他在信里感谢她这段时间的信任和帮助，告诉她那扇门不是危险，他会没事的。他在信尾写道："冰箱里还有半盒牛奶，记得喝了，别放过期。"

第二封信是写给秦伯的。他感谢秦伯在他最迷茫的时候给出了指引，说自己会完成翻倍者的使命。他在信尾写道："你的修鞋摊别搬走，也许有一天我会回来找你修鞋。"

第三封信是写给他自己的。

他只在信纸上写了一行字：

"你不是在变强，你是在被召唤。第30天，你会和源头重合。"

他把三封信叠好，放进抽屉里。

然后他躺下来，闭上眼睛，等待第29天的到来。
