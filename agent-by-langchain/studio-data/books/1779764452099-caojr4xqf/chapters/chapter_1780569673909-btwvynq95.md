# 1

<p>夏芒看着镜子里的自己，三个淡绿色的词条悬浮在头顶：</p><p>【强健体魄·淡绿】</p><p>【卓越理智·淡绿】</p><p>【思维敏捷·淡绿】</p><p>这只是他二十个绿色词条中的冰山一角。</p><p>三个月前，夏芒觉醒了“词条信息系统”。从那一刻起，他眼中的世界变成了标签的海洋。品质从低到高：白、绿、蓝、紫、橙、红。</p><p>普通人满大街都是灰白色的【迟缓·白】、【老寒腿·白】。</p><p>夏芒的系统能力很单纯：完全无限制、无限额地查看他人词条。</p><p>也可以消耗精神力，复制他人的词条。</p><p>复制一个淡绿色的词条，他需要半小时的高强度专注，事后还要昏睡两天才能恢复精神。</p><p>但幸好，查看词条是完全免费无限额的！</p><p>这三个月，夏芒像个疯子。</p><p>他穿梭在城市的大街小巷，物色那些百中无一的浅绿色词条拥有者。</p><p>公园里的退役老兵【格斗专家·绿】，图书馆里的考研党【过目不忘·淡绿】，工地上的搬砖大叔【耐力非凡·绿】。</p><p>压抑着，积累着。</p><p>直到高考那天。</p><p>在别人眼里，夏芒是个整天到处逛街压马路的学渣。但考场上，夏芒只觉得题目简直像白开水一样无味！</p><p>整整二十个绿色词条在他的大脑和身体中疯狂运转，他甚至需要刻意收敛，生怕一个不小心把答题卡戳穿！</p><p>他游刃有余地控制着分数，考了个650分，够上中上游985，不多不少，绝不引人瞩目。</p><p>收笔的那一刻，夏芒的人生才刚刚开始。</p><p>“事已至此，来场说走就走的毕业旅行！”</p><p>大红薯平台上找的合租别墅，可以说是这次旅行最正确的决定。</p><p>一个月前，大红薯上有个帖子叫“高考完想死，有没有便宜别墅合租”，发帖人ID叫“海天一色”。</p><p>夏芒当时刚查完分，正琢磨着出去散心，就顺手加了楼主拉的群。</p><p>群名叫“毕业合租不卷不gang”。</p><p>夏芒进群的第一眼，消息记录已经刷了九百多条。</p><p>他往上一翻——全是史图。</p><p>从互联网最底层挖出来的远古史图，什么“老师你的大宝贝掉了”，什么“今天也是充满屎的一天”，配图是一个3D渲染的微笑大便。</p><p>发图最疯的就是冯海天，这哥们像是有个无限容量的史图数据库，各种刁钻角度、各种像素模糊的陈年老图，源源不断地往外掏。你骂他一句，他能用十二张不同语种的史图回复你，排版之精美，情绪之饱满，堪称行为艺术。</p><p>花鱼是后来进群的。</p><p>她刚加进来的时候还装了五分钟淑女，发了个可爱的猫猫打招呼。</p><p>然后冯海天回了一张史图。</p><p>花鱼不演了，反手甩出一张更炸裂的一只巨大的史戴着皇冠，配字‘朕的王朝’。</p><p>群聊变成了两个史图大佬的军备竞赛。</p><p>你来我往地发图，这就是青春啊。</p><p>对于毕业旅行，夏芒还是比较期待的。</p><p>自己觉醒词条系统的几个月以来，他一直在高强度物色强者和疯狂刷题，硬生生把曾经500多分拉到650。</p><p>现在有两个沙雕的普通同龄人陪伴左右，倒是件乐事。</p><p>发史图之余，三人规划行程，讨论更具体的生活习惯。</p><p>冯海天说自己打游戏声音大，但十二点以后绝对闭嘴。花鱼说自己追剧会发出鹅叫，但可以用被子闷住。</p><p>两个人都强调自己“很正常，非常正常，正常人一个”。</p><p>夏芒问：没有其他什么奇怪的癖好了？</p><p>冯海天：我泡面调料包只放三分之一。</p><p>花鱼：我睡觉必须抱着海星枕头。</p><p>　　</p><p>见面的那天，在小镇的火车站。</p><p>冯海天穿着一件洗得发白的格子衬衫，头发乱得像刚被雷劈过，拖着一个巨大的行李箱。</p><p>花鱼扎着马尾，穿着碎花裙子，笑起来眼睛弯成月牙，手里拎着两大袋零食。</p><p>两个人普通得不能再普通。</p><p>所以当夏芒看到冯海天的头顶，悬浮着一个仿佛燃烧着烈焰的词条【混元无极剑仙·橙】！</p><p>的时候。</p><p>他。</p><p>几乎像个多汁的菠萝被扔进液压机，心脏几乎要爆浆炸开！</p><p>但他的脸仍然如液压机般绷住。</p><p>夏芒缓缓转头看向花鱼，那女孩头顶同样光芒大作，赫然是【星海旅者·橙】！</p><p>我一定绷住！</p><p>橙级！！</p><p>全地球普通人类的极限是淡蓝色，比如爱因斯坦，比如拉马努金，那是人类群星闪耀的巅峰。</p><p>而橙色，那是只存在于系统理论推演中的神话级！这俩人随便拎出一个，理论上都能一巴掌把地球拍成肉饼！</p><p>熙熙攘攘的夜市，小贩和路人穿梭。在夏芒眼中，那是一片灰白色的词海【迟缓·白】、【亚健康·白】，偶尔有几个百里挑一的淡绿色，比如【长跑健将·淡绿】。</p><p>这才是正常的世界！</p><p>夏芒脸上仍然绷住。</p><p>但世界观碎了一地。这两个橙级大佬，为什么要在这种偏僻小城和普通人合租？</p><p>这特么是扫地僧来渡假了吗？</p><p>那个存了巨量史图的男生是什么比剑仙？</p><p>那个魂斗罗第三关都过不去的姑娘是什么什么旅者？</p><p>他认真思考了一个极其现实的问题：现在连夜买站票逃离地球还来得及吗？</p>
