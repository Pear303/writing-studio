# 第1章 零点零一

杜煌二十六岁的生日，过得很平淡。

早上八点四十五分，他从出租屋那张吱嘎作响的单人床上爬起来，拿起手机看了一眼——没有生日祝福短信，连他爸妈似乎都忘了这件事。微信上只有工作群的消息和两条广告推送。

他叹了口气，趿拉着拖鞋走进卫生间。

洗漱的时候，他脑子里还在想上个月的绩效考核。主管在会上点名说他"缺乏突破性思维"，暗示今年的晋升名额可能没他的份。二十六岁了，在一家不大不小的公司干了三年，工资涨了两千，职位纹丝不动。

牙膏管被他习惯性地从底部往上挤，然后拧开盖子往牙刷上挤了一条。他拧回盖子的时候，手指不知怎么用了点力，金属盖子发出"嘎吱"一声，直接变了形。

杜煌愣了下，看着手里拧歪的牙膏管盖，拧了拧眉毛。

"便宜货。"他嘀咕了一句，没当回事，把变形的盖子重新拧回去，开始刷牙。

刷完牙洗完脸，他泡了杯速溶咖啡。陶瓷杯子的手柄被他捏住端起来的时候，指尖传来一声细微的碎裂声。他低头一看，手柄上赫然出现了几道细纹，像是被什么力量从内部撑裂了。

杜煌盯着那道裂纹看了两秒，用手摸了摸。裂纹是真的，不是眼花。

"这杯子也太脆了吧。"他把杯子放回桌上，换了另一个杯子。

上午九点半到公司，一切如常。打卡、开电脑、查看邮件、打开Excel表格。周报的数据还没整理完，主管早上十点要开会，他又得临时抱佛脚。

杜煌揉了揉太阳穴，手指按在太阳穴上的触感比平时更清晰，他甚至能感觉到皮肤下血管的微弱跳动。

开会的时候他有些心不在焉。主管在台上讲下个季度的目标，他在下面盯着自己的手指看。说不上来哪里不对，但总觉得今天的手指比以前更……有力？他握了握拳，骨节发出清脆的响声。

"杜煌，你觉得呢？"

主管的声音把他拉回现实。他抬头，发现全会议室的人都在看他。

"啊，我觉得……方案挺好的，"他本能地应付了一句，"就是执行层面可能需要再细化一下，时间节点上可以再紧凑一点。"

主管点了点头，似乎满意这个回答，转头继续讲别的了。

杜煌松了口气，低头继续盯着自己的手指。

下班后他去了公司附近的健身房。这是他保持了两年的习惯，一周去三次，每次练一个小时左右。不是因为多喜欢健身，纯粹是上班坐太久，腰背扛不住。

他走进器械区，先做了几组热身，然后走向卧推架。

上周他的极限是四十公斤，推五个就很吃力了。今天他按照惯例先把杠铃片加到四十公斤，躺下，双手握杠。

深呼吸，推出。

杠铃很轻松地离开了胸前的支架，像是只推了十公斤一样。他愣了一下，差点没拿稳，赶紧把杠铃放回架上。

不对劲。

他坐起来，看了看杠铃片。确实是四十公斤，没错。他又看了看自己的胳膊，看起来没什么变化。

可能是今天状态好吧，他想。

他把重量加到了六十公斤。躺下，推出。还是轻松得离谱。

再加到八十公斤。这是他平时根本不敢挑战的重量，健身房里那些练了很久的肌肉男才用这个重量做组。

躺下，双手握杠。他深吸一口气，用力推出。

八十公斤的杠铃平稳上升，没有丝毫卡顿。他甚至觉得自己还能再加二十公斤。

杜煌把杠铃放回架上，坐起来，额头上没有一丝汗。

他环顾四周，旁边正在练器械的人没人注意他。他慢慢从卧推架上站起来，心里有种说不出的感觉。不是兴奋，更像是……困惑。

他收拾好东西，头也不回地离开了健身房。

回到出租屋已经晚上九点多了。他一进门就看到客厅的灯还亮着，室友林筱雨的房门关着，门缝里透出光。她应该还在做实验，或者写论文。

杜煌跟林筱雨合租快一年了，两个人的作息基本错开。她是生物医药的研究员，经常早出晚归，有时候周末也泡在实验室里。他们平时交集不多，偶尔在客厅碰上了聊几句，关系算是和谐的合租室友。

他没多在意，回了自己房间，关上门。

坐在床边，他又开始回想今天发生的那些怪事。拧弯的牙膏管盖、碎裂的陶瓷杯柄、轻松推起的八十公斤杠铃……这些事单独看都能找到解释，但串在一起，总让人心里不踏实。

他拿起手机，看了眼日历。今天是他的生日，3月15日。

零点的时候他在做什么来着？哦，他躺在床上刷短视频，准备睡觉。然后胸口突然涌过一阵暖流，像是喝了一口温水，从胸口往四肢扩散开。他当时觉得挺舒服的，翻了个身就睡着了。

会是这个原因吗？

杜煌摇了摇头，觉得自己想太多了。可能就是今天状态好，仅此而已。他洗了个澡，躺下睡觉。

深夜十一点五十分，他翻了个身，迷迷糊糊中感觉到手机屏幕亮了。他瞥了一眼，是零点倒计时的闹钟提醒——这是他之前设的，提醒自己第二天要早起开会。

他正要关掉闹钟，突然，那股暖流又来了。

这一次比昨夜更强烈。胸口像是被温热的潮水冲刷过，一股明显的力量感从心脏部位向外扩散，沿着血管涌向四肢百骸。他能清晰地感知到这股"暖流"的路径，像是体内有一条隐形的水流正在冲刷他的每一块肌肉、每一根骨骼。

杜煌猛地睁大眼睛，困意全无。

他坐起来，低头看着自己的胸口，用手摸了摸。体温正常，没有发热，但那股力量感是真实存在的。他能感觉到身体内部的某种变化——肌肉更紧了，骨骼更沉了，甚至连呼吸都比平时更深。

他握了握拳头，指节间发出比以前更清脆的响声。

"这不是错觉。"他低声说，声音在安静的房间里显得格外清晰。

他拿起手机看了一眼时间。零点零一分。

3月16日，他的力量翻倍了。

这个念头突然出现在脑子里，没有来由，但他就是知道。今天的自己是昨天的两倍，昨天他拧弯了牙膏管盖今天就能拧断它，昨天他推起了八十公斤今天就能推一百六十公斤。

这个想法让他后背一阵发凉。

他放下手机，双手撑在膝盖上，深呼吸了好几口。理智告诉他这种事不可能发生，但今天发生的所有事都在指向同一个方向。

他想到了今晚——不对，是昨晚推起的八十公斤杠铃。上周他的极限还是四十公斤，今天就翻了一倍。如果用翻倍的逻辑来解释，那就说得通了：生日那夜的力量翻倍，让他的基础力量变成了两倍，所以他才能轻松推起八十公斤。

那今晚又翻了一次，明天他会变成什么样？

杜煌不敢继续想下去。

他躺回床上，盯着天花板，完全睡不着。脑子里翻来覆去都是今天发生的怪事，越想越清醒。

不知过了多久，他拿起手机看了眼时间。凌晨两点四十七分。

他索性不睡了，坐起来打开手机的计算器，在上面胡乱按了几个数字。如果按照每天翻倍来算，第一天是两倍，第二天是四倍，第三天是八倍……到了第十天会是多少？

他算了算：2的10次方，1024倍。

也就是说，如果今天是力量的起点，十天之后他会有一千倍于现在的力量。那一个月呢？2的30次方，超过十亿倍。

杜煌看着计算器屏幕上的数字，手心全是汗。

他把手机屏幕按灭，在黑暗中坐了很久，直到窗外的天色从漆黑变成深蓝，再从深蓝变成浅灰。

清晨六点，他拿起手机，打开了闹钟应用，把每天零点倒计时的闹钟设置成了永久循环。

他需要一个答案。

而答案，就在三天后的零点。
