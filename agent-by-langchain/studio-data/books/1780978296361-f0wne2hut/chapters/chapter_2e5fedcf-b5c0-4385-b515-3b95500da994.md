# 回村与父亲

<p>阿牛拎着兔子走进村子的时候，天已经快黑了。</p><p>穷山村坐落在半山腰上，拢共也就二三十户人家。土坯墙，茅草顶，炊烟从各家的烟囱里飘出来，空气里弥漫着柴火味和饭香。</p><p>“哟，阿牛回来了？”</p><p>一个驼背老汉蹲在路边劈柴，抬头看见他手里的兔子，眼睛一亮。</p><p>“你小子行啊，打了这么大一只？”</p><p>阿牛咧着嘴笑：“运气好，捡了一只撞树上的。”</p><p>老汉嘿嘿笑了两声，显然不太信，但也没往下问。</p><p>阿牛快步往家走，拐过村口的老槐树，就看见自家的破院子。父亲老牛正坐在门槛上编草鞋，手里攥着一把稻草，枯瘦的指头很利索地翻来绕去。</p><p>“爹。”</p><p>老牛听到声音抬起头，目光落在儿子身上，先是一愣，随即看到那只肥兔子，脸上露出惊讶的表情。</p><p>“你……打来的？”</p><p>阿牛得意地晃了晃手中的兔子：“怎么样？够炖一锅的了。”</p><p>老牛放下手中的草鞋，慢慢站起来。他比阿牛矮半个头，背有点驼，脸上的皱纹像是刀刻的一样深。</p><p>他没接兔子，只是上下打量着阿牛，目光从儿子脸上扫到身上，再从身上扫到脸上。</p><p>“你没事吧？昨晚上回来说掉悬崖了，摔哪儿了？”老牛伸手扒开阿牛的袖子看。</p><p>“没事，真没事，就擦破点皮。”阿牛把手抽回来，把兔子举到父亲面前，“看这个，肥得很。今晚炖了，咱爷俩改善改善伙食。”</p><p>老牛盯着兔子看了好一会儿，点了点头，嘴角终于露出点笑模样：“行，我去杀兔子，你去烧火。”</p><p>晚饭炖了一锅兔肉汤。山里人调味简单，就放点盐和野葱，但肉香飘了满屋。阿牛狼吞虎咽地连啃了两碗肉，又灌了一大碗汤，这才心满意足地打了个饱嗝。</p><p>老牛坐在对面，慢悠悠地喝着汤，筷子夹起一块兔肉放进嘴里嚼了嚼，点了点头。</p><p>“手艺还行吧？”阿牛问。</p><p>“比你娘炖的差远了。”老牛说了句，又低头喝汤。</p><p>阿牛没接话。他知道娘在他三岁的时候就没了，发高烧没的。那会儿村里的赤脚大夫不在，等人从镇上赶回来，人已经凉了。</p><p>沉默了一会儿，老牛放下碗，看着儿子说：“你小子今天不对劲。”</p><p>阿牛一愣：“啥不对劲？”</p><p>“你那力气。”老牛眯着眼睛，“打兔子是一回事，可你今天回来的脚步声不一样。轻了，也快了。以前你进门的时候，隔老远我就能听见你那沉重的脚步。”</p><p>阿牛摸了摸后脑勺：“可能……摔悬崖撞运气了？”</p><p>老牛没说话，只是看着他，目光里带着点说不清道不明的东西。</p><p>阿牛被看得有点发毛，低头扒饭。</p><p>脊椎在体内警惕起来。不对，这个老头的眼神有问题。他不是在高兴儿子变强了，他在……审视？</p><p>那一瞬间，脊椎感觉到一股极其微弱的波动，是从老牛身上散发出来的。</p><p>这股波动很淡，淡到几乎察觉不到，但六万年轮回的记忆让它瞬间辨认出来——这不是普通村民该有的气息。</p><p>老牛低头喝汤，没有说话。</p><p>阿牛把碗筷收拾了，站起来说：“爹，我去刷碗。”</p><p>“嗯。”</p><p>阿牛端着碗往后院走，嘴里哼着歌，完全没注意到父亲的目光一直追着他的背影。</p><p>直到他的身影消失在门帘后面，老牛才放下碗。</p><p>他看着桌面上剩下的半碗兔汤，眼神变了。不再是刚才那个慈祥朴素的农民父亲，而是一双异常清醒、异常冷静的眼睛。</p><p>“阿牛……”他极轻地说了两个字，没有说下去。</p><p>脊椎在他体内沉默着。</p><p>一个偏远穷山村的编草鞋老汉，身上有真气波动？这他妈的绝对不对劲。</p>
