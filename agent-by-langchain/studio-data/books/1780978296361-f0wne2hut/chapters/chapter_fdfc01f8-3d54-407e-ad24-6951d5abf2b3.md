# 重生之我是脊椎

<p>我在纯粹黑暗中苏醒。</p><p>不对，不是苏醒。我根本没有睡去过的记忆，甚至连“记忆”这个概念都感觉陌生。我只知道自己存在，就在这片无边的黑暗里。没光、没声音、没有触感，只有一种意识缓缓流动。</p><p>或者说，一根神经在蠕动。</p><p>我试着活动，或者说“思考”怎么活动。意识往下沉，模糊间感觉到自己有一条细长的身体——不对，是脊椎。一根完整的、洁白的脊椎骨，每一节骨骼都清晰可辨，骨刺和棘突完整无缺。但这不是普通的死骨头，它活着，骨腔里流淌着某种温热的东西，像骨髓，又不像。</p><p>更奇怪的是，我能控制它。</p><p>脊椎缓慢弓起，像一条蛇般扭动。我发现自己侧躺在一个湿润的洞穴里，周身是黏滑的岩壁，洞穴顶部偶尔有水珠滴落，砸在地面上发出清脆的回响。可我看不见——我没有眼睛，或者说，这根脊椎没有配备视觉系统。</p><p>但我能“感知”。</p><p>我用意识去触碰脊椎的一端，从那个位置伸出一些纤细的神经索，像无数根天线探入黑暗。通过它们，我能“触摸”到周围的空间：岩壁的粗糙纹理、滴水的声音形成的小小涟漪、甚至空气中飘浮的细微尘埃。这是一种陌生的、纯粹的感知，不需要眼睛，不需要耳朵，直接用神经去体认这个世界。</p><p>我的过往是一片空白。</p><p>我不知道自己从何而来。不知道为什么会是一根有意识的脊椎。不知道这根脊椎之前属于谁，或者为什么单独躺在这个洞穴里。每一段神经都干干净净，没有存下任何记忆。我只知道存在本身，以及一个越来越清晰的念头：饥饿。</p><p>是的，我饿了。</p><p>这根脊椎需要营养。没有血液、没有肌肉包裹，单凭一根骨头想要存活，简直是荒谬。但饥饿的感觉真实不虚，像一把小刀在骨缝间刮擦。</p><p>神经索开始自主蠕动，像饥饿的触手向四周探去。它们触碰到石壁上的苔藓、湿润的泥土、细小的昆虫尸体，然后神经末梢像吸盘一样吸附上去，一点点汲取养分。效率很低，但勉强能维持。</p><p>这算什么？光合作用？不对，我是骨头，又不是植物。但现实就是如此荒诞——一根有意识的脊椎正在靠“吃掉”周围的微生物苟活。如果上辈子的自己看到这一幕，大概会以为在做噩梦。</p><p>等等，“上辈子”？</p><p>某种模糊的记忆碎片在意识深处闪了一下——办公室格子间、永远响个不停的钉钉消息、凌晨两点的外卖、僵硬酸痛的颈椎。996。社畜。猝死。车祸。</p><p>然后就没有了。</p><p>那些碎片像泡影一样迅速消散，只留下一个空壳般的概念：我曾是个人，现在不是了。</p><p>我懒得去深究。996那辈子已经过去，现在我是根会自己捕食的脊椎，与其纠结人生意义，不如先想想怎么填饱肚子。这很“社畜”——活着就行，别想太多。</p><p>我继续用神经索在四壁搜寻食物。洞口有风声灌入，带着泥土和草木的气息。我大概在某个悬崖下的洞穴，离地面不高，否则风声不会这么清晰。但感知到这一点对我没什么帮助，我动不了，只能像一条盲眼的蚯蚓，在这弹丸之地蠕动。</p><p>然后我听到了声音。</p><p>不是水滴，不是风声。是重物疾速下坠撕裂空气的呼啸，然后“砰”的一声巨响，距离我不过几米的地面猛地震颤，碎石飞溅。我的神经索清晰地感受到——有什么东西砸了进来，而且是个活物。</p><p>一只野兔？掉下来的？</p><p>我犹豫了一下，用神经索探向声音的来源。触感反馈回来的信息让我愣住：那是一具人类的躯体。十六七岁的少年，瘦削，穿着粗布短衣，周身是碎裂的草叶和泥土，显然是从上方的悬崖坠落。他仰面躺着，胸口微微起伏，还活着——但脊柱的位置，触感惊心动魄。</p><p>一团混乱的碎片。</p><p>他的脊椎断了。</p><p>第三节和第四节腰椎完全粉碎，断骨甚至刺穿了皮肤，温热的血液正在向外渗，染红了身下的碎石。神经索触碰到的每一处反馈都在宣告死讯——这个人活不了多久，脊髓神经大面积撕裂，腹腔内部有暗红色的液体缓慢渗出，呼吸越来越微弱。</p><p>我应该做什么？救他？怎么救？我只是根骨头。</p><p>但一个念头悄然升起，像本能的呼救：我能不能钻进去？那具身体断了一截脊椎，而我刚好是根脊椎。就像拼图缺了一块，而我的形状正好吻合。这太巧了，巧得让人毛骨悚然。</p><p>我的意识在黑暗里沉默了两秒钟。犹豫？可能有一点。但那具身体的主人正在死去，他昏迷不醒，意识像风中的烛火一样摇曳。而我在这个洞穴里找不到更多食物，继续待下去也撑不了几天。饥饿感像鞭子一样抽打着神经。</p><p>躺平。</p><p>我忽然想到这个词。上辈子挂在嘴边的人生理想——找个地方躺平，不卷了。现在不正有个现成的“位置”吗？这具少年身体里刚好空着那么一截脊椎，我钻进去，完美契合。以后他养活我，我挺直他的脊梁，双赢。</p><p>挺好。</p><p>神经索开始行动。它们像细小的触手向前蔓延，从脊椎的末端伸出，一厘米一厘米地爬过湿冷的岩石，攀上少年温热的手指、手臂、肩膀，最后停留在他的后颈。我能“看到”他断裂处的伤口，血肉模糊，但对我来说就像一扇敞开的门。</p><p>我蜷紧骨节，像一根弹簧般猛然弓起，跳了进去。</p><p>剧痛。不是我的，是那少年的。</p><p>就在我的骨节嵌入他断裂脊椎的刹那，他猛地抽搐了一下，喉咙里发出一声短促的惨叫。我能感受到他身体里每一个细胞的排斥——外来者的入侵、陌生组织的融合、神经接驳的撕裂感，仿佛刀劈斧剁。他的心脏狂跳，血压飙升，每一根肌肉纤维都在痉挛。</p><p>但我没有停。</p><p>我像蛇一样向他的脊柱深处钻去，骨骼与骨骼摩擦、融合、生长。我的每一节椎骨都与他原有的脊椎骨对接，骨刺伸出，像根系般扎进他的椎间盘，神经索从末端探出，沿着他的脊髓向上、向下蔓延，接管他身体的每一段神经信号。</p><p>这个过程不知道持续了多久，我的意识渐渐模糊。</p><p>最后一次清醒时，我感受到少年的心脏猛地一缩，随即重新恢复跳动。他的肺部开始自主呼吸，一下，两下，像老旧的泵重新启动。血液涌过我新生的骨骼，带着热度和氧气，我第一次不再是单纯的骨头，而是有了血肉、肌肉、内脏。</p><p>我……成为他的一部分了。</p><p>视野忽然亮起。</p><p>少年猛地睁开了眼睛。</p><p>他躺在洞穴冰冷的地面上，后背被冷汗浸透，剧痛像潮水一样退去，留下一种奇异的温热感和麻木感。他大口喘着气，瞳孔好一会儿才对焦。</p><p>发生了什么？</p><p>他记得自己在崖边采药，脚下踩空的瞬间，身体失去平衡，风声呼啸，天地翻转，然后是背脊处传出的那声清脆的碎裂——咔嚓。那一刻他知道完了。村里最好的药郎也接不好断掉的脊梁。</p><p>但他现在活着。</p><p>阿牛缓缓抬起一只手，看着沾满泥土和血污的掌心，五指能活动，关节灵活。他又试着撑起身体，后背那种骨折的断裂感消失了，腰杆笔直，甚至比坠落前还要有力量。他愣愣地坐起来，伸手摸向后腰——皮肤完好，没有伤口，骨头完整。</p><p>简直像一场梦。</p><p>他跌跌撞撞站起来，环顾洞口的阳光。。</p><p>阿牛蹒跚着向外走，步伐很快恢复平稳，甚至比从前更稳。他走出山洞，阳光刺得他眯起眼睛，前方是熟悉的村庄轮廓，青瓦的屋顶上冒着袅袅炊烟。</p><p>他不知道怎么活下来的，也不打算深究。活着就好哈哈哈！</p>
