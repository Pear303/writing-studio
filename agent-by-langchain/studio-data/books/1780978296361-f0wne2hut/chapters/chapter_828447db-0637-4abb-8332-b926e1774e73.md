# 第1章

<p>黑暗。</p><p>无边无际的黑暗。</p><p>我是在一片黏稠的冰冷中醒来的。没有光，没有声音，没有温度，甚至连疼痛都没有——只有一种空洞的、漂浮的麻木感，像被扔进了深不见底的井底，连井水都在慢慢渗进骨头里。</p><p>等等。</p><p>骨头？</p><p>我想抬手，没有手。我想睁眼，没有眼。我什么都感觉不到，唯独能感知到自己的身体——如果那也能叫身体的话——是一根长长的、光秃秃的东西，从顶端到尾端，一节一节的，像一根被剔得干干净净的排骨。</p><p>不，不是排骨。</p><p>是脊椎骨。</p><p>我是一根脊椎骨。</p><p>这个认知像一盆冰水从头浇下，浇得我整个骨架子都在发颤。不，不是发颤，是骨节与骨节之间摩擦时发出的一阵细碎的咔咔声，在这片死寂中格外刺耳。</p><p>前世活着当牛马，死了还要当骨头吃土。这剧本谁写的？老子好歹也是个985毕业的都市白领，从小镇卷到一线城市，拼了命地卷进大厂，每个月拿着不到两万的工资，干着三个人的活，加着凌晨三点的班，最后累死在工位上。公司连个讣告都没发，HR直接一封邮件就把我的东西打包寄回老家。</p><p>我以为死了就解脱了。结果呢？死了还不够，还要变成一根骨头，而且还是根什么功能都没有的破骨头。</p><p>我试着动了动。确切地说，我试图让自己这根长约半米的脊椎骨——凭感觉大概是这个长度——在这片黑暗中挪动。可我没手没脚，连个关节都没有，怎么动？我使劲拱，像条蚯蚓一样在地上扭来扭去，结果只是在原地打了个圈，骨节之间发出嘎吱嘎吱的声响。</p><p>省点力气吧。</p><p>一个念头从身体深处冒出来。或者说，是从我这根脊椎骨的“骨头缝”里钻出来的。我忽然感觉到，靠近顶端的部位有一个吸管状的开口，像某种生物的嘴巴，正在一张一合。我本能地将那个开口贴近地面——我摸摸索索地感觉到那里有一层湿漉漉的东西——然后用力一吸。</p><p>一股清冽中带着泥土气息的液体顺着那个开口流进来，流遍我这根骨头的每一个节缝。凉丝丝的，像是山泉水，又像是某种植物的汁液。我甚至能尝出来，这股液体里还混着一丁点苔藓的味道。</p><p>我活过来了。</p><p>不，严格来说，我一直都是“活”着的。只是这一刻，我才真正意识到自己以一种什么样的方式存在着。一根会思考、能进食、有意识的脊椎骨。这比做鬼还惨——鬼起码还能飘，我连飘都做不到。</p><p>日子就这么过着。没有白天黑夜，只有永恒的黑暗和偶尔从上方射进来的几丝黯淡的光线。我慢慢摸索出了自己所在的位置——一个悬崖底部，四周是湿滑的岩壁，头顶是高高的、被雾气笼罩的天际线。这个地方常年不见阳光，岩壁上长满了滑腻的苔藓，缝隙里渗着冰凉的山泉水。</p><p>我靠着吸食苔藓和露水维生。有时运气好，能吸到一小片蕨类植物的根茎，那股清甜的味道能让我高兴大半天。更多的时候，我只能靠着那个小小的开口，一点一点地吮吸岩壁上的湿气和苔藓汁液，像一根被遗忘在角落里、慢慢发霉的吸管。</p><p>我试过自杀。</p><p>不，准确地说，是试过“自我解体”。我想象着自己猛地一挣，把所有的骨节都崩开，碎成一堆骨渣。可我做不到。这根骨头出奇地坚韧，我用它去撞击岩壁，结果岩壁碎了一块，我纹丝不动。我试着把它往石头缝里塞，打算把自己卡死在那里，可那些石缝太小，我的骨节太粗，怎么都卡不进去。</p><p>连死都死不了。</p><p>我躺平了。</p><p>既然活不成也死不了，那就这么过着吧。反正前世也是躺平的心愿——天天喊着“下辈子当一条咸鱼”，现在虽然不是咸鱼，但好歹也差不多。一根骨头，不需要KPI，不需要加班，不需要开会，不用看老板脸色，不用挤地铁。每天只需要吃饭、躺着、发呆。这样的日子，倒也算是一种另类的“实现梦想”。</p><p>只是，这日子实在太他妈的寂寞了。</p><p>我不知道在这片黑暗里待了多久。没有钟表，没有光线变化，我只能凭着大概的直觉数日子。大概过了半个月？一个月？还是更久？有一天，我正百无聊赖地吮吸着岩缝里渗出的水珠，忽然听到上方传来一阵窸窸窣窣的声响。</p><p>有人。</p><p>不对，是有“活物”在上面。那声音很轻，像是有什么东西在崖壁上攀爬。我屏住呼吸——虽然我连呼吸的器官都没有，但那种紧张感让我整根骨头都在绷紧。</p><p>然后，我听到了一个声音。</p><p>“啊——”</p><p>那是人的声音，带着惊恐和绝望，从高处传来，越来越大，越来越近。我抬起头，用那个吸管状的开口朝上“看”去，虽然我什么都看不见。但我的感知告诉我，有一个巨大的阴影正在迅速坠落。</p><p>嘭！</p><p>一声闷响，那个东西砸在我面前不到五米的地方。震得我整根骨头都在颤抖，岩壁上的碎石头哗啦啦地往下掉。等我从那阵震动中回过神来，我才看清楚——那是一个人。</p><p>一个少年。</p><p>瘦小的身体，破旧的衣服，看外貌大概十五六岁的样子。他仰面朝天躺在地上，嘴角溢出一缕鲜血，右腿以一个不可能的角度扭曲着，身上的衣服被岩石划得支离破碎。</p><p>最关键的是——他的脊背。</p><p>我从我这个角度看得清清楚楚，他的脊椎在摔落时受到了重创，从胸椎到腰椎的那一段，几乎碎成了几截。断掉的骨茬刺破了皮肤，露出森森的白骨，鲜血正从伤口里汩汩往外冒。</p><p>他还活着。</p><p>我能感受到他微弱的呼吸，那一阵一阵的、断断续续的抽气声，像溺水的人在拼命救自己最后一口气。可我知道，他活不了多久了。这种程度的伤，就算是送到最好的医院也无能为力，更何况在这个荒山野岭。</p><p>我看着那具躺在血泊中的身体，看着他那节节断裂的脊椎骨，一个念头忽然从脑海深处冒了出来。</p><p>反正我也是根废柴。</p><p>在这里吃土发霉的日子我过够了，万一下一次掉下来的是个什么动物或者又是个死人，那我就真的要烂在这里了。但是——如果，如果我能钻进他的身体呢？</p><p>他的脊椎断了，我的脊椎还好好的。如果能接上去，不，如果能把自己塞进去，代替他那断掉的骨头，说不定还能活。</p><p>虽然我不知道自己这根奇奇怪怪的骨头到底是什么东西，但我要试一试。总比在这里躺着等死强。</p><p>我挪动起来。</p><p>这一次，我没有犹豫。我的骨节一节一节地在地面上滑动，像一条蛇一样往前爬。那个吸管状的开口在我顶端急促地开合着，像是在呼吸。我滑过湿滑的岩壁，滑过碎石子，滑过一滩冰凉的积水——</p><p>然后，我触到了他的后背。</p><p>那是一片温热、湿漉漉的肌肤，带着淡淡的血腥味。我能感受到他身体的颤抖，濒死的颤抖。我沿着他的脊柱沟往上爬，找到那个最严重的断裂处。那里的皮肉已经被骨茬划开了一个口子，正好可以让我钻进去。</p><p>我深吸一口气——虽然没有肺，但我的整根骨头都在那一瞬间绷紧了。</p><p>然后，我猛地一用力，顶端扎进了那个血洞。</p><p>剧痛。</p><p>我感受到了剧痛。一种从未体验过的、从骨子缝里钻出来的剧痛，像是一把烧红的铁钎捅进了我的骨腔里，在里面搅动。我疼得整个骨节都在发抖，但我没有停下来。</p><p>开弓没有回头箭。</p><p>我继续往里钻。一节一节地，像一根钻进木头的铁钉，硬生生地把自己塞进他的脊椎里。我能感受到他的身体在我进入的那一刻猛地弹了一下，然后他发出一声闷哼，昏迷的身体又抽搐了一下。</p><p>然后，奇妙的事情发生了。</p><p>当我的第一节骨节和他颈椎的断面对接上的那一刻，一股暖流从我的骨骼里涌出来，像是火山爆发一般，顺着我的骨节扩散开来。那股暖流接着涌入他的身体，涌向他的四肢百骸。</p><p>我感觉到，他的身体在修复。</p><p>那些断掉的肌腱和血管，正在以肉眼可见的速度重新生长。那些被骨茬刺穿的脏器，正在一点点地愈合。那股暖流像是有生命一样，沿着他破损的脊柱，一节节地接过去，把碎裂的骨头重新拼在一起。</p><p>而我的身体，则在这一刻和他的脊椎骨完美地融合在一起。</p><p>咔哒。</p><p>一声清脆的响声从我们身体交接的地方传来。我的最后一节尾骨也接了上去。那一刻，我感觉到了——他的心跳。砰砰，砰砰，砰砰。那颗心脏正在我的下方有力地震颤着，将血液泵往全身。</p><p>紧接着，我感觉到了他的呼吸。急促的，带着痛苦和惊魂未定的呼吸。他的肺在扩张，他的喉在收缩，他的嘴在大口大口地吸入冰凉的空气。</p><p>他在活过来。</p><p>不，是我们，在活过来。</p><p>少年猛地吸了一口凉气，那口气灌入他的肺腑，震得他的身体剧烈地抖了一下。他睁开了眼睛。</p><p>那是一双漆黑的、带着惊恐和不甘的眼睛。</p><p>他动了动手指，又动了动脚趾，然后猛地抬起头，看向自己原本应该断裂成几截的后背。他伸手摸了一下，那里只有一道浅红色的疤痕，平整而光滑，像是从来没有受过伤一样。</p><p>他愣住了。</p><p>一个少年，从二十多丈高的悬崖上摔下来，脊椎断裂，本该必死无疑。可现在，他却像没事人一样坐了起来。他低头看了看自己的手，又看了看满地的血迹，脸上浮现出茫然和困惑的表情。</p><p>而我，这根已经和他融为一体、长成了他新脊椎的骨头，正安静地躺在层层血肉之下，感受着他心跳的温度。他没有发现我的存在——至少没有发现我是“活着”的。</p><p>但他的身体，这辈子都别想甩掉我了。</p><p>悬山顶上的风灌下来，吹动他破烂的衣角。他仰起头，看着那面他刚刚跌落下来的绝壁，眉头紧锁。</p><p>刚才掉下来的那一瞬间，他以为自己死定了。</p><p>现在，他还活着。</p><p>但他不知道的是，有一个不该出现在这个世界上的东西，正在他的脊椎里，徐徐苏醒了。</p>
