# 入职新身体

<p>少年阿牛花了整整一个上午，才勉强学会直立行走。</p><p>他在悬崖底的一片碎石上练习，从扶着岩壁到双手离开，从一步三晃到踉跄走三步——每一步都像是在用膝盖捅自己的下巴。我作为他的脊椎，能清晰地感受到每一块骨骼、每一根肌肉的发力过程，以及他那糟糕到无可救药的身体控制力。</p><p>你这走路姿势，村口的鹅都比你优雅。我在心里发出一声叹息。</p><p>阿牛完全没察觉到我的存在，他大声喘着气，抹了把脸上的汗，踌躇满志地看向上方：“我一定能爬上去！”</p><p>我沉默了一秒。这小子说的爬上去，是爬上这片至少八十丈高的悬崖吗？</p><p>他的脑子是不是摔坏了？</p><p>阿牛已经开始找着手点了。他抓着岩壁上一块凸起的石头，用力一蹬——身体往上蹿了足足三尺。他愣了一下，看看自己的手：“我……力气怎么这么大？”</p><p>废话，老子在你体内待着，帮你稳固骨骼，这些许增长是理所当然的。我暗中得意，但还是有些担忧——这力气增长太快，怕不是要露馅。</p><p>阿牛没多想，像打了鸡血一样继续爬。他双手交替抓岩壁，两脚蹬在凸起的石头上，整个人像壁虎一样紧贴着崖壁往上攀爬。我不得不暗中帮他发力，在每一次手臂上拉时，用能量辅助他的肌肉收缩。</p><p>他越来越快。从最初的笨拙，到后来如同一只山猫，攀爬的动作流畅得令人吃惊。不过一个小时，他就爬上了崖顶，浑身大汗，却满脸兴奋地举起双手：“哈哈哈哈！我阿牛大难不死，必有后福！”</p><p>我默默翻了个白眼——哦对了，我现在没有眼珠，翻不了。那我在心里翻一个。</p><p>阿牛站在崖顶大口喘气，双手撑膝，汗水滴在地上。他环顾四周，目光落在远处一片树林的方向。“饿了。”他的肚子应景地发出一声巨大的咕噜声。</p><p>我心想，爬了这么久的山，你饿了也正常，但不着急，先搞清楚自己身在何处。我的感知顺着他的脊椎延伸出去，隐约能感受到附近有野兽的气息——不是大型猛兽，但足够当食物。</p><p>阿牛拍拍手上的灰，大步朝树林走去。</p><p>他走路的姿势依然古怪——像一只试图优雅滑行的鸭子。我再次确认，这货的平衡系统绝对有问题。不过，至少能走了，比上午还是进步了不少。</p><p>“咦，后背怎么凉飕飕的？”阿牛突然停下脚步，扭头看看背后。</p><p>我心头一紧。他该不会发现我了？</p><p>“算了，没感觉。”阿牛挠挠头，继续走。</p><p>我松了口气。好险。</p><p>“以前听村里老人说，人撞了邪身体会发凉。我该不会撞鬼了吧？”他又自言自语。</p><p>我忍不住在心里哈哈大笑：你不是撞鬼，你是撞上老子这根骨头了。</p><p>树林里很安静，偶尔有鸟叫声和昆虫的嗡嗡声。阿牛走了半个时辰，在一片矮灌木丛里发现了一条小溪。他趴下去喝了几口，然后坐在岸边休息。</p><p>我趁机仔细探查他的身体。这具身体虽然瘦削，但底子不错，骨骼结实，筋脉通畅。最关键的是，他丹田里那股稀薄的灵气虽然微弱，但确实存在着。我试着引导那股灵气在他体内循环——它顺着经脉缓缓流淌，每游走一圈，身体就微微温热一点。</p><p>有戏。</p><p>我暗喜。如果这小子有修仙资质，哪怕只是最普通的那一档，我也能让他走上修炼之路。只要他入了门，我就能借助他的真气修复自己，慢慢恢复修为。</p><p>阿牛打了个哈欠，躺在地上睡觉。</p><p>我守着他的身体，暗中观察四周。这是一片原始山林，附近有野鹿和兔子的气息，偶尔能听到远处传来野兽的低吼。不安全。</p><p>但我现在无能为力。这具身体太弱了，连个像样的攻击手段都没有。要想让他变强，得从最基础的开始——先抓点野味填肚子，再引导他学会吸收灵气。</p><p>这小子睡得真香。</p><p>我看着他安静的脸庞，突然想到一个问题：如果他问起自己怎么突然恢复了怎么办？如果他发现自己体内住着一根有意识的骨头，会是什么反应？</p><p>算了，走一步看一步。先让他通过打猎找到自信，然后我再慢慢引导他进入修炼。有我在，这小子这辈子注定不会平凡。</p>
