# 日常修炼

<p>天还没亮，阿牛就醒了。</p><p>他本来没打算起这么早，但后脊梁骨那股热气老是翻腾，把他给煨醒了。自从得到那根骨头之后，他睡觉老是觉得背上发烫，翻来覆去整晚都在做奇怪的梦——全是关于奔跑、跳跃、撕裂的梦，醒过来身上汗涔涔的，却没有疲惫，反而精神抖擞。</p><p>“算了，起来练练。”</p><p>阿牛爬起来就往外走。院子里还黑着，露水打湿了石板。他伸了个懒腰，骨节噼里啪啦地响了一串。</p><p>“先练拳。李叔教过我一招崩拳……”</p><p>阿牛深吸一口气，沉腰坐马，一个冲拳打出去。</p><p>噗———</p><p>拳风穿过空气，发出沉闷的一声响。</p><p>阿牛自己都愣了一下。这速度比昨天更快了。他接着又打了十几拳，越打越顺，拳头像是自己长了眼睛，每一拳都找准了发力的方向和角度。</p><p>脊椎在他体内默默看着，打了个哈欠（如果它有嘴的话）。这傻小子倒是有点天赋，普通人对力量的感知需要三个月才能上道，他三天就摸到门路了。不过嘛……主要还是老子厉害。</p><p>阿牛打完拳，感觉不过瘾，又抄起斧头劈柴。院子里堆着一人多高的木桩子，老牛本来打算慢慢劈，阿牛一斧头下去，木桩子齐刷刷地裂成两半，碎屑飞了一地。</p><p>“咦？”</p><p>他又劈了几根，每一斧头都稳稳当当，力道精准得吓人。以前他劈柴总要两三斧头才能劈开一根，现在一斧下去，稳准狠。</p><p>劈完一半的柴，阿牛又去挑水。两只大木桶，装满水少说七八十斤，以前他挑着都晃悠，现在轻轻松松，一路小跑着从井边回来，水没洒出一滴。</p><p>老牛不知道什么时候起来了，蹲在门槛上抽烟袋，眯眼看着儿子一趟趟地挑水劈柴打拳。</p><p>阿牛累了，坐在地上喘气，感觉浑身舒畅。</p><p>“爹，我是不是变厉害了？”</p><p>老牛吐了口烟：“还行。”</p><p>“还行？”阿牛站起来，走到院子里立着的一根手腕粗的木桩前，“你看着啊。”</p><p>他深吸一口气，一拳砸下去。</p><p>咔嚓！</p><p>木桩应声而断。</p><p>阿牛自己都吓了一跳，退了两步看着断裂的木桩，再看看自己的拳头，拳头红红的，但骨头一点事没有。</p><p>“我操……”</p><p>老牛抽烟的手停了一下，眼神微微一缩，但很快恢复了正常。</p><p>“行了行了，别把拳头打烂了。”他站起来，把烟袋锅往鞋底上磕了磕，“吃早饭。”</p><p>早饭很简单，昨晚剩下的兔汤热了热，加上两个硬馒头。阿牛吃得狼吞虎咽，老牛慢慢地嚼着馒头，眼睛时不时地往儿子身上瞟。</p><p>阿牛没注意到这些细节，只顾着兴奋地念叨：“爹，你说我要是照这么练下去，以后是不是能去镇上当护院？那一个月能挣不少银子呢。”</p><p>“别老想着出去。”老牛说了句。</p><p>“为啥？在村里守着几亩地有啥出息？”</p><p>老牛没搭话，低头喝汤。</p><p>吃完早饭，阿牛去村里转了一圈。他到井边打水的时候，几个正在洗衣服的婶子看见他，都笑着打招呼。</p><p>“阿牛，听说你昨儿打了一只大兔子？”</p><p>“哟，有出息了嘛。”</p><p>“可不是嘛，以前懒洋洋的，现在看这精气神都不一样了。”</p><p>阿牛嘿嘿笑着，跟她们聊了几句，心里美滋滋的。</p><p>但等他走了以后，那几个婶子的笑声就变成了窃窃私语。</p><p>“你说这小子是不是摔了一跤，把脑子摔开窍了？”</p><p>“可不是嘛，以前多笨的人。”</p><p>“不过也奇怪，怎么一下子就变得这么有气力？”</p><p>“不会是中了什么邪吧？”</p><p>“呸呸呸，别瞎说。</p><p>阿牛自然没听到这些议论。他回院子的时候，看到老牛正在修补院墙，搬着一块大石头，额头青筋暴起，显然是费了大力气。</p><p>“爹，我来。”</p><p>阿牛几步走过去，单手就把那块大石头拎了起来，稳稳地放到墙头上。</p><p>老牛看着他，眼神有点复杂，但又什么都没说，只是低声说了句：“好。”</p><p>当天夜里，老牛又趁阿牛睡着，悄悄走进他的房间。他揭开阿牛后背的衣裳，手指轻轻按在脊椎骨上。</p><p>黑暗中，老人的眼神异常清醒。</p><p>他摸到了什么——骨节比普通人粗大一圈，还微微发烫。</p><p>老牛的手停在半空中，半天没动。</p><p>最后，他缓缓起身，走出房间，轻轻关上门。</p><p>院子里月光如霜，老牛蹲在墙角，抽了一夜的烟。</p><p>脊椎在他体内感应到了外面的动静，沉默地想：这老家伙到底什么来历？他怎么知道我在这里？他不是普通的父亲。</p><p>阿牛翻了个身，梦中还在打兔子，完全不知道深夜发生了什么。</p>
