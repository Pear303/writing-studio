# 第一次打猎

<p>阿牛一路狂奔，像被鬼追着似的冲进了村子。</p><p>夜色已经完全暗下来了，村里的老槐树下坐着几个乘凉的老头，看见阿牛这个狼狈样子，都笑呵呵地打趣他：“阿牛，你这是被野兽撵了？”“你小子咋横着跑？螃蟹精上身了？”</p><p>阿牛没理会他们，一口气冲回了家。</p><p>他家在村子最西边，三间土坯房，院子里的篱笆歪歪扭扭地倒了大半边，门口挂着一盏昏黄的油灯。他爹李天成正坐在门槛上，手里捏着一根旱烟袋，烟雾在灯光里缭绕。</p><p>“爹！”阿牛冲进院子。</p><p>李天成抬起头，看了他一眼，然后又吸了一口烟：“回来了？”</p><p>“回来了。”</p><p>“药采到了？”</p><p>“采到了。”</p><p>李天成点点头，没多问。他向来话少，阿牛都习惯了。他把背篓卸下来，从里面掏出几株草药，递给李天成。李天成接过来，借着灯光看了看，又闻了闻，点了点头：“还行，嫩了点，但能入药。”</p><p>阿牛松了口气，转身进屋。</p><p>厨房里冷锅冷灶的，灶台上放着一个半凉的窝头，还有一碗咸菜。阿牛的肚子“咕噜”一声叫了起来，他这才想起来自己一整天都没吃东西了。</p><p>他拿起窝头咬了一口，硬邦邦的，像是放了两天的。他嚼了两下，又喝了一口凉水，勉强咽下去。窝头在胃里一沉，不但没填饱肚子，反而把他的饿劲彻底勾上来了。他的胃开始火烧火燎地疼，整个人的食欲像一头饿疯了的野兽，在他的五脏六腑里横冲直撞。</p><p>一个窝头根本不够。</p><p>他把剩下的半个也吃了，把一碗咸菜全扒拉干净，又灌了一肚子凉水，垫了个半饱。肚子不叫了，但胃里还是空空的，总觉得缺了点什么。</p><p>他想吃肉。</p><p>阿牛舔了舔嘴唇，脑子里浮现出村里张屠户家灶台上挂着的几块腊肉，那油光锃亮的肥膘，那红褐色的瘦肉，切下一块来煮熟了，咬一口，满嘴都是肉的香气。</p><p>不行，不能想，越想越饿。</p><p>阿牛咽了口唾沫，看了看锅台，又看了看墙角那个空荡荡的米缸，心里有些发愁。他爹病了大半年，家里的积蓄早就花光了，地里的农活也没人干，收成差得很。这一个月他靠在山里打点野味、采点草药卖钱，勉强维持着两个人的生活。</p><p>但最近山里的野物越来越少，他有时候在山里转一整天，连一只野鸡都逮不着。今天要不是运气好采到了几株好药，他爹明天的药钱都没着落。</p><p>“得弄点肉回来。”阿牛自言自语道。</p><p>他想了想，决定明天一早就进山，去他经常去的那片林子看看。那片林子里野兔多，虽然跑得快，但他以前也逮到过几只。只要运气好，说不定能弄到一只。</p><p>第二天天还没亮，阿牛就醒了。</p><p>他翻身起来，感觉后背那个怪异的感觉又弱了一些。他已经渐渐摸到了和那个“东西”相处的诀窍——只要他放松身体，别刻意去对抗，它就不会闹腾。</p><p>他随便洗了把脸，从灶台上摸了一个窝头揣在怀里，拎着一把破柴刀，就出了门。</p><p>天边刚露出鱼肚白，村子里静悄悄的，只有几声狗叫。阿牛沿着村后的小路一路往山里走，穿过一片晨雾弥漫的稻田，进了那片他经常去的老林子。</p><p>林子里露水很重，他的裤腿很快就湿透了。他沿着一条熟悉的小路往前走，眼睛紧紧盯着地面，寻找野兔的踪迹。</p><p>他找了半个时辰，一无所获。</p><p>他换了一个方向，又找了半个时辰，还是一无所获。</p><p>阿牛蹲在一块大石头上，咬了一口怀里的窝头，嚼着嚼着，心里越来越烦躁。这片林子他来过很多次，以前虽说猎物不多，但好歹也能碰上一两只。今天倒好，连个兔子影都没见着。</p><p>“算了。”他把最后一口窝头塞进嘴里，站起来，拍拍手，“去烂泥地那边看看。”</p><p>烂泥地在林子深处的一片低洼地，那里常年潮湿，长满了野草和灌木。野兔最喜欢这种地方，因为草密，容易藏身。</p><p>阿牛走了两里地，总算到了那片烂泥地。他放轻脚步，猫着腰，小心翼翼地靠近。他以前跟村里的老猎户学过一点潜伏的技巧——脚步要轻，呼吸要匀，不能急，要等。</p><p>他找了一丛齐腰高的灌木，蹲在后面，一动不动地等着。</p><p>太阳从东边升起来，穿过树叶的缝隙，在地上洒下斑驳的光影。露水开始蒸发，空气变得闷热起来，蚊子在他周围“嗡嗡”地转着，叮了他好几个包。他忍着不动，连拍都不敢拍。</p><p>他等了快一个时辰，腿都麻了。</p><p>就在他快要放弃的时候，前面那片草丛里传来一阵悉悉索索的声音。</p><p>阿牛的心一下子提了起来。他屏住呼吸，一动不动地盯着那个方向。</p><p>草叶晃了晃，然后一只灰褐色的野兔从草丛里探出脑袋来，警惕地东张西望。它的耳朵竖得直直的，鼻子一抽一抽的，似乎在嗅空气中的味道。</p><p>阿牛的心狂跳起来。他死死地盯着那只兔子，那只兔子又往前跳了两步，低头开始啃地上的草根。它完全没发现阿牛。</p><p>机会来了。</p><p>阿牛慢慢地把柴刀放下，免得反光暴露自己，然后悄悄地调整了一下姿势，把重心压到脚尖。他的眼睛一眨不眨地盯着那只兔子，距离大约有十几步远。只要他能再靠近五步，就有把握扑过去抓住它。</p><p>他开始往前挪。</p><p>一寸一寸地，像个虫子似的，在烂泥里趴着前进。泥浆沾了他一身，糊了他满脸，他也顾不上擦。他的目光紧紧锁定那只兔子，那只兔子还在埋头吃草，浑然不觉危险正在靠近。</p><p>十步。</p><p>八步。</p><p>七步。</p><p>阿牛的心跳越来越快，手心全是汗。他深吸一口气，准备扑过去。</p><p>就在他即将发力的一刹那，那只兔子突然抬起头来，耳朵猛地向后一甩，后腿蹬地，“嗖”地一下窜了出去。</p><p>跑了！</p><p>“靠！”阿牛骂了一句，一个翻身从地上爬起来，撒腿就追。但兔子跑得太快了，四腿翻飞，像一道灰光在草地里穿梭，转眼就跑出去了几十步远。</p><p>阿牛追了几步就停下了。他追不上。他两条腿的人，怎么可能跑得过四条腿的兔子？那只兔子跑得比风还快，眨眼就钻进了远处的一片灌木丛里，连影子都看不到了。</p><p>“跑了就跑了吧。”阿牛喘着粗气，不甘心地跺了一下脚。他在烂泥地里蹲了大半天，一身泥一身汗，被蚊子叮了二十多个包，最后连根兔子毛都没摸着。</p><p>他正要转身离开，突然看到那只兔子的身影又从灌木丛里窜了出来，朝另一个方向跑了。</p><p>阿牛眼睛一亮，拔腿就追。</p><p>那只兔子似乎也发现了他在追，更拼命地跑，尾巴一颠一颠的，在草丛里忽隐忽现。阿牛咬着牙追，跑得上气不接下气，脚下的烂泥溅了他一身。</p><p>眼看着那只兔子越跑越远，马上就要钻进一片密林里去了，阿牛心里一急，脑子里只有一个念头在回荡。</p><p>“别跑！”</p><p>那一瞬间，他的身体像是被什么东西点着了。</p><p>一股热浪从他的后背猛地炸开，顺着脊柱一路冲向四肢百骸，像是有一条火龙在他的血管里狂奔。他的肌肉瞬间绷紧，每一根骨头都在发烫，整个人像是被人从后面推了一把，身体猛地往前一窜。</p><p>他跑起来了。</p><p>不是他平时的速度，而是一种他从未体验过的快。他的双腿像装了弹簧似的，每一步都在地上踩出一个深深的脚印，身体破开空气，耳边的风声呼呼作响。周围的树木飞速地向后退去，草丛被他带起的风吹得东倒西歪。</p><p>那只兔子还在跑，但它的速度在阿牛眼里突然变得好慢。他甚至能看清兔子耳朵上每一根毛的抖动，看清它后腿蹬地时泥土飞溅的细节。</p><p>他追上了。</p><p>他甚至没来得及多想，右手本能地往前一伸，一把抓住了兔子的后腿。</p><p>兔子发出一声尖叫，拼命挣扎，后腿乱蹬。但阿牛的手像一把铁钳似的死死攥住它，任它怎么蹬都挣不脱。</p><p>他停了下来。</p><p>气喘吁吁地站在一片杂草丛里，手里拎着一只还在挣扎的野兔。他低头看了看兔子，又抬头看了看周围的林子。</p><p>我刚才……</p><p>他低头又看了看手里的兔子。兔子还在挣扎，但力气越来越小了。他捏了捏兔子的后腿，嗯，又肥又壮，少说也有三斤重。</p><p>“哈哈！”阿牛忍不住笑出声来，拎着兔子在手里掂了掂，“我运气也太好了！差点就让它跑了。”</p><p>他回味着刚才追兔子的经过，越想越觉得自己走运。那只兔子本来都跑远了，不知道怎么回事又折回来了，他又正好跑快了两步，一把就抓住了。要是再慢一眨眼，那兔子肯定钻到林子里去了，他连根毛都抓不着。</p><p>“今天运气不错。”阿牛把兔子夹在胳膊底下，拍了拍身上的泥。虽然浑身湿漉漉的，衣服上全是烂泥和草籽，但他心情大好。</p><p>他又把兔子拎到眼前看了看，肚子里“咕噜”一声响了起来。他已经能想象到这只兔子变成一锅香喷喷的兔肉汤的样子了——兔肉炖得烂烂的，汤面上漂着一层金黄的油花，放点盐和姜，再放几片葱……</p><p>“够我和老爹吃两顿了。”阿牛满意地估算着，“这皮子剥下来，还能做个小钱包，冬天放点碎银子正好。”</p><p>他拎着兔子，兴冲冲地往村里走。</p><p>走了几步，他突然想起刚才追兔子时的速度。那个速度，好像有点太快了？他从那个位置窜出去，到抓住兔子，感觉也就一眨眼的工夫。他以前从来没跑这么快过。</p><p>“可能是饿急了吧。”阿牛没多想，耸了耸肩，“饿极了的人什么干不出来？”</p><p>他继续往前走，心情好得不得了。晚风从山间吹过来，吹在他脸上，凉丝丝的。夕阳把天边染成了橘红色，远远的村子已经亮起点点灯火，炊烟袅袅升起。周围的一切都显得那么平和，那么美好。</p><p>他完全不知道，在他身体里，那根不属于他的骨头，正在安静地吸收着刚才激发出的力量，像一头蛰伏的兽，在黑暗中缓缓收起了爪牙。</p><p>阿牛只顾着高兴，只顾着盘算这顿肉怎么吃。</p><p>他没有想过：一个追不上兔子的少年，凭什么能在那一瞬间跑得比兔子还快？</p><p>他也不知道，命运给他的第一个惊喜，才刚刚开始。</p><p>等他翻过最后一个小山包，远远看见自家院子里亮着的油灯时，他加快了脚步。那只野兔已经被他颠得晕头转向，耷拉着脑袋不动了。</p><p>他正要跨进院子，后背突然传来一阵轻微的酸胀感。</p><p>他顿了一下，伸手摸了摸后背。那股感觉很快就消失了，好像只是错觉。</p><p>阿牛甩了甩脑袋，迈步跨进了门槛。</p><p>他爹还在屋里等着他。他今天晚上有肉吃了。</p><p>只是他并不知道，当他跨进门槛的那一刻，他后背那根沉睡的骨头，第一次，轻轻地，动了一下。</p>
