# 第一次打猎

<p>阿牛蹲在山洞口，肚子咕咕叫。</p><p>他在怀里摸索了半天，只找到两块干硬的饼子。昨晚上啃了一块，剩下这块够干啥的？</p><p>“得弄点肉吃。”</p><p>站起来拍拍屁股上的土，阿牛眯眼望向不远处的林子。这山他熟，小时候跟村里的猎户李叔进去过几回，知道林子里有野兔和山鸡。</p><p>他刚迈出一步，就感觉后脊梁骨一热。</p><p>那股暖流从尾椎骨窜上来，顺着脊柱一路冲到后脑勺，浑身的毛孔都张开了。阿牛深吸一口气，闻到了林子里飘来的各种气味——松针的清香，泥土的湿气，还有一股淡淡的腥臊味。</p><p>是兔子。</p><p>“这感觉……也太爽了吧？”阿牛捏了捏拳头，感觉胳膊里的力量像是泉眼一样往外冒。</p><p>他抬脚就冲了出去。</p><p>一步跨出去就是三米多远，阿牛差点没站稳，踉跄了两步又往前扑。速度快得带起一阵风，吹得路边的草叶哗哗响。</p><p>“我操！”</p><p>阿牛自己都吓一跳。他收不住脚步，眼看要撞上一棵老松树，本能地一扭腰，身子擦着树干擦了过去，后背的衣服蹭掉了一块皮。</p><p>脊椎在体内疯狂吐槽：你是不是傻？照直跑啊！躲什么树！</p><p>阿牛哪知道脊椎在心里骂他，只顾着兴奋地往前冲。脚底生风，越来越稳，踩在碎石和落叶上像踩在棉絮上一样轻巧。</p><p>前方三十米处，一只灰毛野兔正探着脑袋啃草根。</p><p>兔子耳朵一动，察觉到了动静，撒腿就跑。</p><p>“别跑！”</p><p>阿牛喊了一声，脚下猛蹬，整个人像炮弹一样射了出去。</p><p>草丛刷地分开，两道虚影在林间穿梭。兔子跑得贼快，四腿翻飞，左右乱窜，一会儿钻灌木，一会儿拐弯。阿牛紧追不舍，眼看要撞上一棵歪脖子树，他一掌拍在树干上，借力变向，身体贴着一丛荆棘窜过去，衣摆被刮出几道口子。</p><p>“你给我站住！”</p><p>兔子哪听他的，跑得更欢了。</p><p>但阿牛的速度还在加速。他的腿像是装了弹簧，每一次蹬地都把他往前弹出四五米。脊椎之力源源不断地灌入四肢，协调性暴涨，他觉得自己像是在水面上滑行。</p><p>兔子急了，一头扎进一个矮洞里。</p><p>阿牛想都没想，一个飞扑，手伸进洞里去捞。手指抓住了什么东西，毛茸茸的，一拽，兔子腿被他死死攥在手里。</p><p>“逮着了！”</p><p>兔子拼命蹬腿，但阿牛的力气太大了，铁钳一样箍着不放，把整只兔子从洞里拖了出来。灰毛野兔有三斤多重，肥嘟嘟的，四腿乱蹬，两眼又圆又亮。</p><p>阿牛拎着兔子站起来，衣服上全是泥和草屑，脸上却笑开了花。</p><p>“天助我也！今晚炖兔汤！”</p><p>脊椎在他体内翻了个白眼。我堂堂长生种，活了不知道多少万年的存在，现在居然变成一个打猎工具？帮人抓兔子？这叫什么？猫粮提取器？</p><p>还天助我也……要不是老子给你加力，你连兔子毛都摸不到。</p><p>阿牛完全没感觉到脊椎的内心戏，只顾着乐呵呵地用草绳把兔子腿绑了，挂在腰带上。他又在林子里转了一圈，运气好捡到几颗野山菇，顺便又吓跑了一只山鸡——这次没追，因为跑太快差点撞树上。</p><p>“够了够了，一只兔子够吃两顿了。”</p><p>阿牛拎着战利品往山下走。夕阳把云染成金红色，山风一吹，凉飕飕的。他心情大好，嘴里哼起了不知从哪儿学来的小调。</p><p>脊椎冷冷地想：这日子什么时候是个头？堂堂长生种，沦落到给一个十五岁的傻小子当外挂。而且这小子还不知道我的存在，只以为自己是天赋异禀。</p><p>等等。</p><p>脊椎忽然警觉起来。不对，我得藏着点。不能让他知道我的存在。万一他到处嚷嚷“我捡到一根神骨”，被人发现了怎么办？</p><p>我得低调，低调才是王道。</p><p>阿牛吹着口哨走过山间小路，脚步轻快，腰杆挺得笔直。他觉得今天自己帅呆了，简直是天命之子。</p><p>只是他不知道，自己的天命，全在一根骨头里。</p>
