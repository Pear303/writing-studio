# 入职新身体

<p>他以为自己死定了。</p><p>那一瞬间，身体失重的感觉还没消散，整个人像是被一只无形的大手从崖顶掀下去，在半空中翻了两圈，后背重重地砸在一块凸起的岩石上——咔嚓一声，他的脑袋里清清楚楚地听见了骨头断裂的声音。</p><p>然后就是无止境的下坠。</p><p>风声灌进耳朵，尖叫被堵在喉咙里出不来。他眼睁睁地看着天空变成了一个越来越小的光点，头顶的云雾像一层又一层的幕布，将他吞没。</p><p>最后撞到地面的那一刹那，他甚至没来得及感觉到疼，眼前就黑了。</p><p>不知道过了多久。</p><p>也许是一炷香，也许是半天。</p><p>阿牛猛地吸了一口凉气，像是溺水的人终于浮出水面，整个胸腔都在剧烈地起伏。他的眼睛猛地睁开，瞳孔里倒映着灰蒙蒙的天空，周围是散落的碎石和齐腰深的草丛。</p><p>他没死。</p><p>这个认知让他愣了好几秒。他缓缓地眨了一下眼睛，又眨了一下，然后慢慢地抬起右手，举到自己眼前。手指能动，关节灵活，上面沾满了干涸的血迹，但每一根手指都完整地存在着。</p><p>他动了动腿。右腿传来一阵酸痛，但没有断。左腿也好好的。</p><p>然后他试着坐起来。</p><p>就在他准备把上半身撑起来的那一刻，一种怪异的感觉从他的后背升起。像是有什么东西在他脊椎里活动了一下——不是疼，也不是痒，而是一种从未体验过的、说不上来的“不对劲”。他的后背像是多了一根不属于自己的骨头，沉甸甸地压着他的脊柱，手感上明明还是自己的后背，但意识里却觉得那里多了一大坨东西。</p><p>“什么情况？”</p><p>阿牛嘟囔了一句，双手撑地，试图站起来。他用力一撑，身体从地上弹起来——然后整个人歪歪扭扭地向左边栽了过去。</p><p>“啊！”他惊叫一声，手忙脚乱地扶住旁边的一棵树，稳住了身体。他低头看了看自己的脚，又扭头看了看自己的后背，满脸茫然。</p><p>怎么回事？他的腿不是好好的吗？怎么站起来的时候左腿不听使唤？</p><p>他又试着站直，这一次他小心翼翼地、慢慢地从弯腰状态直起身来。当他站到一半的时候，后背那个怪异的感觉又出现了。他的身体像是被一根看不见的铁丝从后面扯了一把，整个人不受控制地向后仰去，差点又摔了个四脚朝天。</p><p>“靠！”</p><p>阿牛一头撞在旁边的树干上，疼得龇牙咧嘴。他揉着额头，终于开始认真面对一个问题——他的身体不受控制了。</p><p>准确地说，是后背那一段不受控制。</p><p>阿牛琢磨了半天，最后得出一个结论：可能是摔下来的时候伤到了筋骨，还没完全恢复。他以前听村里的老中医说过，有的人摔断了腰，就算是好了也会有一段时间走路不太得劲。他现在大概就是这种状况。</p><p>他没往别的方向想。</p><p>毕竟，谁会想到自己的脊椎里多了一根来自另一个世界的骨头呢？</p><p>阿牛深吸一口气，拍了拍手，开始正式尝试站起来。</p><p>他先把双手撑在膝盖上，然后慢慢地、一点一点地直起腰杆。他的双腿倒是没什么大碍，爆发力还在，就是后背那股说不清的劲儿总在跟他作对。他明明想让身体往前倾，后背却猛地往后一收，害得他整个人像个跷跷板似的，前前后后摇晃个不停。</p><p>“我叫你跟我对着干！”</p><p>阿牛咬着牙，使劲稳住核心，用了全身力气往前一顶——他终于站直了。</p><p>然而这个姿势维持了不到两秒钟。他刚想把左腿抬起来迈一步，后背又是一阵不受控制的扭曲，整个人的重心往右边一歪，他又摔了。</p><p>这一次他摔得比较惨，整个人扑在了一片荆棘丛里，脸上和胳膊上被划了好几道口子，火辣辣地疼。</p><p>“嘶——你这个死背！”</p><p>阿牛趴在地上，用拳头砸了一下地面。他不知道自己在骂谁，反正就是觉得憋屈。明明身上一点外伤都没有，连骨头都好好的，怎么就走路这么费劲呢？</p><p>他咬咬牙，从荆棘丛里爬起来，继续。</p><p>第二次尝试，他走了三步，然后左脚勾到右脚，像个陀螺一样转了两圈，又一屁股坐在地上。</p><p>第三次，他走了五步，后背又开始作妖。他感觉有什么东西在他的脊柱里蠕动了一下，然后整个人的躯干像是被一只看不见的手拧了一把，左扭右扭的，他赶紧抱住旁边的一块大石头才没有摔倒。</p><p>第四次，第五次，第六次。</p><p>太阳从头顶移到西边，又从西边沉下山头。</p><p>阿牛摔了不下三十次。衣服刮破了好几处，膝盖和手肘全是淤青，脸上也挂了彩。整个人灰头土脸的，像个在泥地里打滚的泥鳅。</p><p>但好消息是，他开始摸到一点门道了。</p><p>他发现，那个怪异的感觉并不是随时随地都会发作的。只有当他想做某些动作的时候——比如弯腰、转身、或者用力的时候——后背才会突然“闹情绪”。如果他慢一点，注意力高度集中，不让身体有任何“走神”的间隙，那么他能勉强走上一段路。</p><p>他摸索出了一套走路的技巧。</p><p>先把重心压低，两条腿微微分开，双手张开保持平衡。然后，像螃蟹一样横着走。没错，横着走。因为他发现横着走的时候，后背的失控感会减弱很多，至少不会把他掀翻在地。</p><p>于是太阳快下山的时候，一个瘦弱的少年，在杂草丛生的荒山野岭里，正用一种极其滑稽的姿势横着走路。他弓着背，叉着腿，双手像稻草人一样伸着，一步一步地挪动，像一只喝醉了的螃蟹在沙滩上乱爬。</p><p>好在周围没人看到，不然他这张脸就丢光了。</p><p>“这也算是大难不死，必有后福吧。”阿牛一边横着走，一边自言自语。他回想起从崖顶掉下来的那一瞬间，后背撞击岩石的剧痛，以及身体失重的恐惧，忍不住打了个冷颤。</p><p>他从那个地方摔下来，居然还能活着，还能走，还能自己爬起来。这在任何人看来都是一件不可思议的事。镇上的老猎户说过，那座悬山摔死过好几个人，有一个是从半山腰滚下来的，都摔成了肉泥。</p><p>他阿牛是从最顶上摔下来的，高度是那个人的两倍还多。</p><p>没死，就是万幸。</p><p>“算你命大。”阿牛拍了拍自己的胸口，又往自己后背拍了一下，“争气点啊兄弟，咱们还得回家呢。”</p><p>后背没有回应他。</p><p>但阿牛觉得，后背好像听懂了。那股怪异的劲儿在他的脊椎里滑了一下，像是在回应他。</p><p>他愣了一下，摇摇头，把这个念头甩到脑后。</p><p>他得赶紧回家。他爹还在家等着他采药回来。他都出去大半天了，再晚一点，他爹肯定要出来找他了。</p><p>阿牛调整了一下呼吸，继续横着走。这一次他走得稍微顺了一点，横着的速度竟然比之前竖着走还要快。他一路穿过了荒草坡，越过一条干涸的溪沟，渐渐看到了远处的烟火气。</p><p>就在他要翻过最后一个山头的时候，他的后背突然传来一阵凉意。</p><p>不是那种风吹的凉，而是从骨头缝里渗出来的凉，像是有什么东西在他的脊柱里游走，从尾椎一路爬到后颈，最后停在后脑勺的位置。</p><p>阿牛打了个激灵，停下脚步，下意识地抬手摸了摸后颈。</p><p>什么都没有。</p><p>但他清清楚楚地感觉到，那一瞬间，他的身体像是被什么东西“扫描”了一遍。从上到下，从里到外，每一个关节，每一寸肌肉，都被那阵凉意摸了个清清楚楚。</p><p>“什么东西？”阿牛缩了缩脖子，警惕地环顾四周。</p><p>荒山野岭，除了风声和鸟叫，什么都没有。</p><p>他皱着眉头，又摸了摸后颈，那里还是什么都没有。凉意已经消失了，仿佛从未出现过。</p><p>他放下手，正要继续往前走，却猛然发现——</p><p>他的身体，好像听使唤了。</p><p>不是完全正常，但至少能站直了。他试着迈了一步左脚，脚步稳稳当当的，没有歪。他又迈了一步右脚，还是稳的。他加快步子，走了五步，走了十步，走了二十步，整个过程稳如老狗。</p><p>“咦？”</p><p>阿牛停下脚步，满脸惊讶。他试着弯了一下腰，又直起来，还顺手做了一套极其丑陋的伸展运动。</p><p>乖了？</p><p>他不敢置信地拍了拍自己的后背，那块之前一直跟他作对的骨头，现在安静得像个老实孩子。</p><p>“原来是间歇性抽风。”阿牛嘀咕了一句。他没往别的地方想。他只当是伤筋动骨的正常反应——过一阵子就好了。</p><p>但他在即将转身的那一瞬间，眼角余光瞥见了路边的一块大石头。那块石头大概有磨盘那么大，半埋在泥土里，看起来很沉。</p><p>鬼使神差地，他弯下腰，单手抓住石头的一角，用力一掀。</p><p>那块磨盘大小的石头，竟然被他轻飘飘地掀了起来，翻了个身，轰隆一声滚到了旁边的草丛里，砸出一个大坑。</p><p>阿牛愣住了。</p><p>他低头看着自己的手，手掌上没有任何异样。那块石头少说也有好几百斤，就算是村里的壮汉也得两个人抬才能搬动。他一个连一百斤都不到的少年，居然一只手就掀起来了？</p><p>这是他干的？</p><p>阿牛咽了口唾沫，看着那棵被石头砸断的树苗，又看了看自己的手，后背那阵沉寂许久的凉意又涌了上来。</p><p>这一次，它停在了他的后脑勺，像是有什么东西，正趴在他的肩膀上，看着他。</p><p>夜风呼呼地刮过来，吹得阿牛起了一身鸡皮疙瘩。</p><p>他朝着家的方向迈开步子。这一次，他的步伐比任何时候都稳。</p><p>只是每一步迈出去，他都觉得后背有什么东西跟着他一起走，安安静静的，像一个沉默的影子。</p><p>他跑了起来。他不敢回头。</p>
