# 入职新身体

<p>山风裹着草木的气息扑在脸上，阿牛眯着眼看向远处的村庄。</p><p>炊烟从青瓦屋顶袅袅升起，熟悉的轮廓让他心里一块石头落了地。他深吸一口气，准备往家走——然后整个人僵住了。</p><p>不对。</p><p>不对不对不对。</p><p>他刚才怎么站起来的？</p><p>阿牛低头看了看自己的两条腿，又摸了摸后腰。坠落时那声“咔嚓”声响在耳边，腰椎碎裂的剧痛他现在还记得清清楚楚。那种伤，别说站起来，连翻身都做不到。可现在他站得笔直，腰杆挺得像根旗杆，完全不像是受过伤的样子。</p><p>“见鬼了。”</p><p>他喃喃念叨了一句，抬腿走了两步，然后立刻发现问题。</p><p>左腿迈出去，右腿跟上，动作倒是没错——但每一步踩下去，膝盖和髋骨都会发出一声轻微的咔嗒声，像某处关节没对齐。他试着加快脚步，那声音就更明显，膝盖一顿一顿的，手臂摆动的节奏也跟不上腿，整个人走起路来就像一个还没调试好的木偶。</p><p>阿牛停了下来，眉头拧成疙瘩。</p><p>他又试了一次，这次刻意放慢速度，一步一顿地走。脚掌踩实地面，大腿带动小腿，膝盖自然弯曲——咔嗒。</p><p>又来了。</p><p>他能感觉到腰腹间有一处隐隐的僵硬，像是被什么东西顶住一样。用力挺直腰杆的时候，有根骨头会在皮肤下滑动一段，然后卡在某个位置才停下来。那种感觉很怪，不是疼，而是一种生涩的错位感，像穿了别人的鞋。</p><p>阿牛蹲下身，伸手在地上摸索了一阵，捡起一根手指粗的树枝，拄着站起来。他试着把重心分担到树枝上，步子果然稳了些。虽然骨头还是咔咔作响，但至少不会东倒西歪了。</p><p>“摔断腰还能活着，已经够走运了。”</p><p>他拍了拍身上的土和碎石，决定不再纠结这些小事。父亲还在家躺着，自己出来采药大半天没回去，指不定急成什么样。至于这别扭的走路姿势……也许是伤还没好利索，过两天就能恢复正常。</p><p>他拄着树枝，一步一步朝家的方向走去。</p><p>但在他不知道的地方，一件事正在发生。</p><p>脊椎内部，那些新生的神经索正在悄然蔓延。它们从腰椎向上，沿着脊髓两侧的分支，缓慢而坚定地探入他的胸腔、腹腔，像细密的根系扎进肥沃的土壤。每一根神经末梢都找到对应的肌肉组织，试探性地发出微弱的电信号——收缩、放松、再收缩、再放松。</p><p>阿牛感觉后腰处传来一阵温热，像是有只看不见的手在轻轻揉按。他不自觉地挺了挺腰，那一瞬间，走路变得顺畅了许多。咔嗒声消失了，步伐也变得稳健，甚至比受伤前还要有力。他愣了一下，以为是心理作用，没多想就继续走。</p><p>树林间的小路弯弯曲曲，绕过几块大石头后就豁然开朗。前面是一条被踩实的土路，路两边是开垦好的农田，地里的麦苗已经抽出了青穗，风一吹沙沙作响。阿牛远远看见村口的大槐树下坐着几个人影，心里安定了不少。</p><p>“牛子！你咋才回来？”</p><p>一个粗犷的声音从前面传来。阿牛抬起头，看见村里的猎户孙大柱蹲在田埂边磨镰刀，见他走近，咧嘴笑了起来。</p><p>“采个药采大半天，你爹都让我捎了三回话了，问我有没有见你人影。”</p><p>“我……”</p><p>阿牛张了张嘴，不知道该怎么说。他被野兽追着掉下悬崖、摔断了腰、然后莫名其妙活过来——这种事说出来，别人肯定会以为他被摔坏了脑子。</p><p>“我多转了两圈，找一味草药。”他含糊地应道。</p><p>孙大柱也没追问，只是上上下下打量了他几眼，目光在他腰背上多停留了一瞬。</p><p>“你走路咋怪怪的？腰不舒服？”</p><p>“没……扭了一下，不碍事。”</p><p>孙大柱“嗯”了一声，也没多说什么，低头继续磨镰刀。阿牛松了一口气，正要加紧脚步往家赶，身后孙大柱忽然又开口。</p><p>“对了，这两天山里不太平，昨天有人在西岭那边听见虎啸，你没事别乱跑。”</p><p>“知道了，多谢柱叔。”</p><p>阿牛应了一声，脚步却没停。他现在只想着快点回家，给父亲煎碗药，就一切安好了。</p><p>但他没注意到，刚才挺腰的那一刻，后腰处的皮肤微微隆起，随即又沉了下去，像是有东西在其中蠕动了一下，然后安静下来。而那一瞬间，阿牛感觉一股热流从脊椎涌上头顶，四肢百骸都暖洋洋的，疲惫感一扫而空。</p><p>他感觉自己前所未有的好。</p><p>甚至好得不太正常。</p><p>村口的景象越来越近。</p><p>大槐树下坐着几个老人，有的在捡豆子，有的倚着墙打盹。几只土狗趴在路边，见到阿牛只是耷拉着眼皮看了一眼，连尾巴都懒得摇。一切都是熟悉的模样，和他离开时一样安静。</p><p>阿牛远远就看见自家那扇破旧木门半掩着，门缝里透出昏黄的油灯光亮。他心里一揪，加快脚步走了过去。推开木门，一股浓重的药味扑面而来。屋里光线昏暗，土炕上蜷缩着一个瘦削的身影，正咳嗽得厉害。</p><p>“爹，我回来了。”</p><p>阿牛快步走到炕边，伸手扶住父亲的肩膀。老人瘦得只剩一把骨头，咳嗽声像破风箱一样嘶哑。看见儿子回来，他勉强挤出一个笑容，嘴唇翕动了几下，声音微弱得几乎听不见。</p><p>“牛子……药……采到了？”</p><p>“采到了采到了，爹你别说话，先歇着。”</p><p>阿牛赶紧从怀里掏出草药，手忙脚乱地生火煎药。柴火噼啪作响，火光映在他脸上，他低头看着药罐里翻滚的水泡，心里一阵发酸。</p><p>自打娘走得早，爹一个人把他拉扯大。前两年爹身子还硬朗，能下地干活，可去年冬天一场大病后，人就彻底垮了。肺里的毛病，村医说治不了根，只能用药吊着。阿牛每天上山采药，想尽办法凑钱买药，可爹还是一天比一天瘦。</p><p>他用力吸了吸鼻子，把翻涌的情绪压下去。</p><p>罐里的药汤咕嘟咕嘟冒着泡，散发出一股苦涩的气味。阿牛正盯着药罐出神，忽然感觉后背一阵发紧，像是有什么东西从腰椎那里往上窜了一下，又消失了。</p><p>他下意识地挺了挺腰。</p><p>那一瞬间，周围的空气似乎不一样了。他能感觉到灶台里火的温度、门缝外吹进来的凉风、甚至院子里土墙上的苔藓散发出的潮湿气味——所有的感官像是被人猛地拧开了阀门，清晰得有些离谱。</p><p>“怎么了？”</p><p>他愣了一下，回头看了看自己的后背，什么都没看见。那股感觉来得很突然，去得也快，就像打了个寒颤。</p><p>“怕是太累了。”</p><p>他揉了揉后腰，端起煎好的药，小心翼翼地扶着父亲坐起来，一勺一勺地喂他喝下去。老人喝了几口，又咳了起来，浑浊的眼睛里满是疲惫和愧疚。</p><p>“牛子……爹拖累你了。”</p><p>“说什么呢爹，你养好身子就行，别的不用管。”</p><p>阿牛把药碗放在桌上，扶着父亲躺好。老人闭上眼睛，呼吸渐渐平稳下来，很快就沉沉睡去。阿牛坐在炕边，看着他爹花白的头发和凹陷下去的脸颊，心里闷得发慌。</p><p>要是能有什么办法治好爹就好了。</p><p>他攥紧拳头，指甲掐进掌心。</p><p>屋外又传来虎啸声，远远的，低沉而压抑。阿牛抬起头，望向窗外漆黑的山林，心里忽然冒出一个念头。</p><p>明天进山，再去去碰碰运气。</p><p>说不定，能打到什么值钱的东西。</p>
