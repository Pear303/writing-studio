# 第一次打猎

<p>清晨的阳光透过窗棂的缝隙洒进来，阿牛睁开眼时，感觉浑身暖洋洋的。</p><p>他翻了个身，坐起来伸了个懒腰。手臂举过头顶那一瞬间，腰背处传来一声轻微的“咔嗒”，骨骼松开又合上，像是什么零件终于卡对了位置。他愣了一下，低头看了看自己的身体——确实，昨天晚上那种浑身别扭的感觉，现在消失得一干二净。走路时咔咔作响的膝盖不再闹脾气，后腰那块僵硬的部位也像被热水泡过一样，舒坦得很。</p><p>“这恢复得也太快了。”</p><p>阿牛嘀咕了一句，跳下床。光脚踩在泥地上，脚趾头下意识地抓了抓地面，感觉比以往任何时候都稳当。他试着蹦了两下，膝盖有力地弯曲再弹起，落地时几乎没有声响。</p><p>灶房里传来父亲压抑的咳嗽声。</p><p>阿牛顾不上琢磨身体的事，快步走进灶房。父亲已经醒了，正坐在灶台边的小凳上，弓着背往灶膛里添柴。火光映着他消瘦的脸庞，颧骨高高凸起，眼眶深深凹陷下去。</p><p>“爹，你咋起来了？我来弄。”</p><p>阿牛抢上前，接过父亲手里的柴火。老人抬起头，浑浊的眼睛看了他一眼，嘴唇哆嗦了一下，却没说话。阿牛知道，他爹是心疼他，心里有话说不出口。</p><p>他手脚麻利地生了火，锅里下了米，又切了几片前几日晒干的萝卜干丢进去。粥在锅里咕嘟咕嘟冒着泡，香气慢慢散开。阿牛摸了摸肚子，肚子立刻发出一连串响亮的咕噜声——从昨天到现在，他就吃了一顿野菜糊糊。</p><p>粥煮好了，阿牛先给父亲盛了一碗，剩下的连锅底刮干净，也才半碗。他几口喝完，米粒在舌尖滚了一圈就没了，胃里依然是空的。</p><p>“得找点吃的。”</p><p>阿牛洗了碗，跟父亲说了一声，就出了门。</p><p>村子不大，从东头走到西头也就一炷香的功夫。眼下正是青黄不接的时候，地里的庄稼还没熟，家家户户的存粮都见了底。阿牛去村口借了一把弹弓，又在地上捡了几颗圆溜溜的小石子，决定进山碰碰运气。</p><p>山林里静悄悄的，只有风穿过树叶的沙沙声。清晨的露水打湿了裤腿，空气里弥漫着草木和泥土混合的气息。阿牛沿着一条羊肠小道往林子深处走，眼睛四处搜寻，耳朵竖起来听着周围的动静。</p><p>走了大约半个时辰，什么都没碰到。连鸟叫声都很稀疏，偶尔听见几声，也是远远的，像是故意躲着他。</p><p>“今天运气也太背了。”</p><p>阿牛靠在一棵大松树上，拧开水囊灌了一口水。肚子里空荡荡的，饿得有些发慌。他揉了揉胃，抬头看向林子上方的天空，阳光从叶子缝隙里洒下来，在地面上投出一片斑驳的光影。</p><p>忽然，他的耳朵动了动。</p><p>右边灌木丛里传来一阵细微的骚动声，像是有什么东西在拨弄枯叶。阿牛立刻屏住呼吸，握紧弹弓，蹑手蹑脚地靠过去。他拨开一丛矮灌木，心脏猛地跳了一下——一只灰毛兔子蹲在那儿，正低头啃着一根草茎。</p><p>那兔子肥得很，脊背圆滚滚的，目测少说也有三四斤。</p><p>阿牛舔了舔嘴唇，缓缓举起了弹弓。</p><p>他屏气凝神，把石子扣在皮筋上，慢慢拉开。瞄准兔子脑袋的时候，他的手臂很稳，连一丝颤抖都没有。他咬紧牙关，手指一松——咻的一声，石子飞出去，打在兔子旁边的一块石头上，弹开了。</p><p>兔子被吓了一跳，猛地跳起来，撒腿就往林子深处跑。</p><p>“别跑！”</p><p>阿牛根本来不及多想，身体已经动了起来。</p><p>他猛蹬地面，整个人像箭一样窜了出去。风吹过耳边，树木飞快地向后退去，脚下的泥土和石头像是自动让开了一条路。他能感觉到双腿有力地交替迈出，每一步落地都稳得惊人，膝盖和髋骨配合得天衣无缝，比之前两条腿打架的时候，简直像是换了一个人。</p><p>兔子在前面七拐八拐，速度快得像一道灰色闪电。换了以前，阿牛顶多追出十几步就会跟丢，可今天不一样——他发现自己竟然能跟上兔子的速度。</p><p>不，不是跟上。</p><p>是越追越近。</p><p>他能看见兔子背上灰色的毛在抖动，能看见它细长的耳朵随着跑动一起一伏，连兔子鼻孔里急促喷出的热气都仿佛近在咫尺。他的身体像是自动进入了某种状态，双腿迈动的频率越来越快，手臂自然地摆动配合，每一步都精准地落在兔子的逃跑路线上。</p><p>这种感觉太奇怪了。</p><p>好像身体知道该怎么跑，根本不经过脑子。</p><p>兔子突然向左一拐，冲进一片乱石堆。阿牛想都没想，脚尖在地上一踩，整个人借力转向，身体倾斜成一个不可思议的角度，几乎是贴着地面拐了过去。如果有人在旁边看见，一定会觉得他像一只敏捷的猫。</p><p>距离越来越近，只有两步远了。</p><p>兔子似乎感觉到了危险，猛地一个急刹，想要换方向。就在它后腿蹬地、身体即将变向的一瞬间，阿牛本能地向前一跃——</p><p>他整个人朝前扑了出去，五指张开，像一张网一样罩向兔子。</p><p>指尖碰到了一团毛茸茸的东西。</p><p>抓住了。</p><p>阿牛重重地摔在地上，胸口磕在石头上一阵生疼，但他顾不上了。他低头一看——右手死死攥着兔子的两条后腿，那兔子还在拼命挣扎，后腿蹬了好几下，最终还是被他紧紧握住了。</p><p>“哈哈哈——”</p><p>阿牛一骨碌爬起来，举起兔子，对着阳光仔细看了看。肥厚的兔腿，厚实的毛皮，一双红眼睛正惊恐地瞪着他。他咧嘴笑起来，笑得合不拢嘴。</p><p>“抓到了抓到了！”</p><p>他激动得原地蹦了两下，胸口那股兴奋劲儿简直要溢出来。以前别说徒手抓兔子，就算用弹弓，他也从没打中过一只。兔子跑得太快了，一眨眼就没影，他只能干瞪眼。可今天——</p><p>他低头看了看自己的手。</p><p>刚才追兔子的时候，那种感觉太清楚了。身体像是被人塞进了另一个人的壳子里，速度、反应、判断，全都不是他自己的水平。那一刻他根本不像是阿牛，倒像是林子里最老练的猎手。</p><p>“我运气也太好了吧！”</p><p>阿牛兴奋地喊了一声，声音在山林间回荡。他拍了拍兔子肥硕的屁股，心里已经开始盘算——这只兔子够他和爹吃两天了，肉炖汤，内脏炒了，皮毛晒干还能拿去换几个铜板。</p><p>他拎着兔子，哼着小曲准备往回走。</p><p>可就在这时，一阵隐隐的凉意从背后升起来。</p><p>是那片后腰上熟悉的凉意。</p><p>阿牛脚步顿了一下，伸手摸了摸后背。隔着衣服，那片皮肤凉得像冰块似的，在太阳底下不但没有变暖，反而像是又凉了几分。他皱着眉，把衣服撩起来看了一眼——</p><p>背上什么都没有。</p><p>但是他能感觉到，那根骨头又动了一下。像是有什么东西在他脊柱里调整了一下位置，轻轻推了推他的腰椎。</p><p>阿牛的眉头拧得更紧了。</p><p>他想起了昨晚照铜镜时看见的东西，想起了走路时那一声声骨骼的咔嗒，想起了今天早上浑身舒畅得异样的感觉，想起了追兔子时那种不像是自己的速度——</p><p>自从自己摔下悬崖，似乎捡到了说书先生常说的大机缘。</p>
