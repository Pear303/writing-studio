# 重生之我是脊椎

<p>黑暗。无边的黑暗。</p><p>不是闭上眼睛的那种黑，是连“黑暗”这个概念本身都显得单薄的那种黑。我脑子里只有一个念头：不对，我不应该在这里。</p><p>等等，我为什么会有“脑子”这个念头？</p><p>我试着动一下——不，不是胳膊，不是腿。我“动”了，但移动的不是四肢，而是一整条……骨头？我是一根骨头，一根长条的、上面有节段、下面连着某种柔软的肉管子——等等，那是神经索吗？我是一根脊椎骨？</p><p>我僵在原地。</p><p>不，我是一根独立的、会思考的、长了口的脊椎骨。一根脊椎。一根他妈的在悬崖底下蠕动吃苔藓的脊椎。</p><p>我叫苏景明，上辈子是长生种里的精英——不，我不是吹牛，我真的在修炼界赫赫有名，当年一剑劈开百里山脉的，就是老子。然后我死了。渡劫失败。魂飞魄散应该是，但不知道为什么，我的魂没散，而是缩进了……这块骨头里。</p><p>我趴在地上，感觉有一片苔藓在我腹下压着。我“脸”的位置——如果脊椎有脸的话——有一圈柔软的口器，正在慢慢蠕动。口器边缘还沾着绿色的汁液。</p><p>我吃了刚才那片苔藓。</p><p>我他妈吃了一片苔藓。</p><p>堂堂长生种苏景明，现在是一条趴在悬崖缝里吃苔藓和腐叶的虫子。我无数次告诉自己这不是真的，但我的口器还在无意识蠕动，像某种迟钝的环节动物。我愤怒地“站起来”——整个身体像一条僵直的虫子那样弓起——然后朝旁边的岩壁上撞过去。</p><p>疼。</p><p>撞不碎。这骨头不知道是什么材质，硬得离谱。</p><p>我无力地瘫回去。算了，先填饱肚子。这不是耻辱，这是生存策略。那些苔藓进到口器里，带着涩味和土腥气，我用神经索把它绞碎、吸收。居然能转化为能量，虽然稀薄得像空气里的一粒米。但至少说明我还能活着。</p><p>活着就有翻盘的机会。</p><p>我在这悬崖底待了三天——我的生物钟告诉我的。白天有微弱的光线从上方照下来，只能照到崖壁上的苔藓层；夜里漆黑一片，连月亮都照不下来。这地方是典型的山沟沟，两边崖壁垂直向上，少说上百米，普通人掉下来必死。我在这里蠕动、觅食、思考。</p><p>为什么我会变成一根脊椎？为什么我会有意识？这东西到底是什么来头？</p><p>我低头端详自己——虽然视觉很模糊，但通过神经索上的触感，我能感知到周围的东西。我大概有三尺长，节段分明，通体莹白，在黑暗中微微发着荧光。我的口器在最粗的一端收缩，每一次呼吸都让空气通过我身上细密的缝隙，发出轻微的哨声。</p><p>这东西绝对不是凡物。</p><p>我正在思考这个深奥的问题，突然听到头顶传来声音。</p><p>不是风声，是石头被踩落的声响。有人从崖壁上面摔下来了。</p><p>我抬头——不，我把我最粗的一端朝向声音传来的方向——看见一个人影从几十丈高处的崖壁上坠落。那是个少年，瘦削，衣衫褴褛，在半空中翻滚了两圈，然后重重砸在我面前三尺的地面上。</p><p>砰的一声，尘土溅了我一身。</p><p>少年侧躺着，一动不动。血从他身下渗出来，染红了苔藓。他的后背有一道触目惊心的裂口——脊椎断裂了，从胸椎到腰椎，碎了好几节。活不成了，普通人这种伤必死无疑。</p><p>但他的眼睛还睁着。</p><p>那少年侧过头，看到我——不，看到我旁边的一片苔藓——然后他居然笑了。一个十七八岁的少年，嘴里吐着血沫，咧着嘴笑，像是在说“哦，死在这山里也不差”。</p><p>我心里一动。</p><p>我活了上千年，见过无数人在死前崩溃哭喊、求天拜地、最后面目狰狞地咽气。能够平静面对死亡的，少之又少。这少年居然能笑出来，倒是有几分意思。</p><p>少年闭上眼睛，呼吸越来越弱。</p><p>我趴在地上，看着他的血迹慢慢扩大。心里没有太多波动——上辈子我杀了多少人，见过多少生死，早就麻木了。一根脊椎而已，又不是什么菩萨道场，没必要替凡人惋惜。</p><p>但我就是不想他死。</p><p>不是善良，是——我低头看看自己这根破骨头，突然觉得，反正闲着也是闲着。再说，我总不能一辈子趴在这悬崖底下吃苔藓吧？那也太跌份了。</p><p>我下定决心，然后“站起来”——我的整根身体像蛇一样弓起，然后朝少年扑过去。我的口器张开，对准他后背上那个触目惊心的裂口，像一条钻洞的泥鳅，猛地扎了进去。</p><p>剧痛。</p><p>我的身体一进入少年的脊椎裂口，就感觉到一股排山倒海般的灼痛涌上来。血肉和神经缠绕着我，我被包裹在热乎乎的血浆里，四周的肌肉纤维像绳索一样收缩，挤压着我。我只能忍着，按照记忆中某种古老的融合术，让自己的骨节与少年的碎骨一一对接、生根、生长。</p><p>那些裂缝在我的能量灌注下缓缓愈合，碎骨重新连接。我占据了他断开的脊椎位置，完完全全成了他身体的一部分。</p><p>少年惨叫一声，身体剧烈抽搐了几下，然后昏过去了。</p><p>我折腾了半天，终于把自己“安装”妥帖。然后我惊讶地发现，少年的身体里居然有一丝微弱的灵气波动。虽然稀薄得如同清晨的雾气，但确实是灵气。</p><p>这小子有修仙资质？</p><p>我暗中窃喜。这不是普通的凡人垃圾场，这具身体居然能修炼。那我的未来就有指望了——只要这少年成长起来，我就能跟着他一路往上爬，恢复修为也不是不可能。</p><p>不过现在我累了。</p><p>这场“手术”消耗了我这几天积攒的所有能量。我感觉自己像被抽空了的皮囊，连接收外界信息都费劲。但我仍然能感觉到少年身体的情况——心跳在恢复正常，呼吸趋于平稳，伤口处的肉芽正在生长。</p><p>活过来了。</p><p>我松了口气，忍不住在心里骂了一句：妈的，我堂堂长生种，居然沦落到给人当骨头的地步。</p><p>骂归骂，我还是沉入休憩状态。少年昏睡了一个下午加一个晚上，我也跟着好好休息了一场。</p><p>第二天清晨，阳光从悬崖上方洒下来，照在少年的脸上。</p><p>他的睫毛动了动，睁开了眼睛。</p><p>“我……没死？”少年喃喃地说。</p><p>我感觉到他的身体在努力动弹——手臂撑地，腿用力——然后他坐起来了。他低头看看自己完好无损的胸膛，又摸摸后背，脸上的表情从迷茫变成震惊。</p><p>“伤口呢？我明明摔断了脊梁骨……”他拍了拍后背，那里只有一层浅浅的疤痕，轻轻一抠就掉了。</p><p>我暗自得意：老子亲手修复的伤口，能留疤就见鬼了。</p><p>少年试着站起来。他扶着岩壁，双腿颤抖——不是虚弱，而是突然适应不了新的身体。他站直了，两条腿劈叉似的往外撇，上半身前倾，两只胳膊在空中胡乱扑腾寻找平衡。</p><p>我在他体内默默地看着这一幕——这小子站起来的姿势，活像一只刚学会站立的猴子。不，猴子都比他稳，他这姿态更像一只被电过的青蛙。</p><p>我的内心世界在疯狂咆哮：我堂堂长生种苏景明，现在住在这具体内，而这个宿主走路的姿势像一个喝醉了的蚂蚱。老天爷，你到底在跟我开什么玩笑？</p><p>但那少年浑然不觉，他还兴奋地喊了一声：“我还活着！”</p><p>我沉默地缩在他体内，开始思考一个问题：我到底是他的骨头，还是他身体里的另一个意识？</p>
