## 第四章《裸奔的尊严》章节细纲

### 场景一：苏晚晴的8B模型（高考前第6天）
- 林一卸载皮皮后在宿舍颓废，苏晚晴敲门送来备用8B模型
- 苏晚晴戳破林一撒谎，表达理解
- 林一找老周安装
- 测试8B写作文：标准模板，无个性
- 王胖子指出与赵铭远72B"一个味儿"
- 林一意识到：安全对齐后的模型都被调教得没有个性

### 场景二：高考前夜的顿悟（主角房间，凌晨1点）
- 林一睡不着，回忆三年经历
- 核心顿悟：不是在使用模型，而是被模型训练
- 0.5B教会他精炼表达，皮皮逼迫他扩展阅读，8B让他知道标准答案长什么样
- 拿出纸笔手写文字，有错别字但每一句都是自己的
- 决定高考裸奔

### 场景三：高考当天
- 考场检测显示"无模型"，赵铭远嘲讽
- 作文题《我的答卷》，林一回忆所有经历
- 用自己的语言写真实的自己，写完发现赵铭远在抓头发

### 场景四：成绩公布与结局升华
- 林一538，苏晚晴687，王胖子456，赵铭远502没过一本线
- 赵铭远作文翻车被识破套路
- 老周坦白后颈伤疤是自己背7B模型留下的
- 回家与父亲对话，"那538分是你的？""嗯，我的"
- 天台与王胖子喝可乐看夕阳
- 点题：最好的模型，是让自己不需要模型的模型
