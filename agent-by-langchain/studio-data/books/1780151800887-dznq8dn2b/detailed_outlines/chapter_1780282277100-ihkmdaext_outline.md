# 第一章《全年级就我一个0.5B》细纲

## 场景一：模型动员大会（学校体育馆）
- 校长宣布"全员模型化备考"，大屏滚动广告
- 苏晚晴演示32B模型，一秒生成满分作文
- 赵铭远演示72B模型，Rap介绍参数，年费99.8万
- 王胖子问"你背的什么模型"，我答"0.5B"
- 老周在角落皱眉，摸后颈（伏笔）

## 场景二：模型调优课（教室）
- 老周打开中控台，大家连接数据线
- 我用0.5B做数学题，算出π=3.2，死机三次
- 赵铭远的72B当场解出三种解法
- 苏晚晴小声说借我8B备用
- 王胖子想分我一半1.2B，结果串扰烧了中控台

## 场景三：模型交易所（校门口）
- 橱窗展示各价位模型，从0.1B到120B定制版
- 赵铭远在看198万的120B版
- 二手区"0.5B估价50元"
- 王胖子说他1.2B是他妈卖了两头猪换的

## 场景四：回家（主角家）
- 父母准备一桌好菜和补脑中药
- 半夜偷听到卖镯子、预支工资
- 父亲递来八千块银行卡
- 我说"0.5B环保省电"，笑着出门
