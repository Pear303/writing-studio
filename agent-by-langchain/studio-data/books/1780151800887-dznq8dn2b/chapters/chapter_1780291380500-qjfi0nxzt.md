# 除夕·雪隐仙踪

<p>除夕·雪隐仙踪 阿宁推开院门的时候，屋里的欢声笑语像一盆冷水泼出来，他顿住脚，转身就走。 身后的门吱呀一声开了，母亲的声音追出来，带着几分恼怒：阿宁，大过年的你又要去哪？他没回头，也没应声，一脚踩进门口的积雪里，咯吱一声，像咬碎了一颗冰疙瘩。身后的喊声渐渐弱下去，被风卷走，被雪埋住，终于什么也听不见了。 他也不知道自己要往哪走。心里堵着一团东西，说不清是跟父亲置的气，还是对这穷山沟里一年又一年毫无指望的日子生出的厌倦。十七八岁的少年，胸中有火，眼底有霜，看什么都觉得憋屈。他沿着山路往上走，脚下的雪越积越厚，路越走越窄，他也不在乎。走就是了，走到走不动为止。 可这山里的天，变得比人的脾气还快。 他刚翻过鹰嘴岭，风就变了方向。原本零零散散飘着的雪沫子忽然密集起来，像有人在天上抖开了一床巨大的棉被，雪片铺天盖地地砸下来。天地之间眨眼间混沌一片，山脊、树影、远处的村庄，所有熟悉的东西都被吞没了，只剩下一片无边无际的白。 阿宁心里一凉，这才知道怕了。他回头想找来路，可脚印已经被新雪盖住，四下里全是相同的白色，东南西北全无分别。风灌进领口，像无数根细针扎在皮肤上，他裹紧棉袄，牙齿开始打颤。腿也在抖，不是害怕，是冷，冷到骨头里那种。 他想跑，可脚陷在雪里拔不出来，每一步都像踩进了黏稠的泥沼。路呢？路在哪里？这片山他从小爬到大的，每一道沟每一道坎都认得，可此刻它变得无比陌生，像一头沉默的巨兽，正张开雪白的嘴，等着他自己走进去。 绝望像夜色一样漫上来。 就在这时候，他看见了那盏灯。 很远很远的地方，在风雪的重重帘幕之后，有一点暖光，橘红色的，温温柔柔地亮着。它随风摇曳，却始终不灭，像一只不肯合上的眼睛，在混沌中安安静静地看着他。 阿宁揉了揉眼，不是幻觉。那光是真的。 他朝它走去，脚步踉跄，却不敢停。那一星暖光是天地间唯一的参照，抓不住它就会被这雪夜彻底吞没。他连滚带爬地翻过一道山梁，又穿过一片枯树林，雪进了鞋里，化了又冻，脚趾已经没了知觉。可他不敢停，眼睛死死盯着那点光，像溺水的人盯着岸上的灯火。 翻过最后一道坡的时候，那座楼阁忽然从风雪中浮了出来。 阿宁愣住了。 一座飞檐翘角的三层楼阁，静静立在雪谷深处，周身朱红，檐下挂着一串风灯，暖光正从灯罩中透出来，在漫天的雪白中摇曳成一团柔软的光晕。屋顶覆着厚厚一层雪，瓦当下的冰凌垂挂如碎玉，晶莹剔透。楼阁前有一株老梅，枝干虬曲如铁，枝头缀着几点红苞，有的已绽开，花瓣上托着薄薄的雪，朱红与素白相映，美得不像人间的景致。檐角的风铃偶尔响一声，叮当，声音细细的，像从很远的地方传来，又被风雪一卷就散了。 阿宁踩着石阶走上台阶，每一步都小心翼翼的，生怕这楼阁只是一个雪中的幻影，一碰就会散掉。木门虚掩着，暖黄的光从门缝中漏出来。他犹豫了片刻，终于伸手推开了门。 一股温热的气息扑面而来，裹着幽幽的香。 那香气说不清道不明。像是梅花的冷冽，又像檀木的醇厚，还混着一缕淡淡的茶香，几种气味纠缠在一起，暖融融地包裹住他。身后的风雪声在一瞬间被隔绝了，门里门外，像隔了整整一个世界。 阁内的布置极为雅致。地上铺着竹席，纹理细腻，踏上去温润无声。正中央放着一只红泥小火炉，炉膛里炭火烧得正旺，橘红的火光在墙壁上一跳一跳的。炉上搁着一只陶壶，壶嘴冒着白气，水已经要开了。旁边的矮几上摆着两只青瓷茶杯，杯壁薄如蝉翼，透着光。角落里有一只博山炉，炉盖雕成层叠的仙山形状，青烟从山间的孔窍中丝丝缕缕地溢出，缓缓上升，在烛光中变幻出种种形状，时而像云，时而像鹤，时而像远山的轮廓。墙上挂着一幅水墨画，画的是雪中寒梅，笔意疏朗，留白处尽是寂寥，落款处模糊不清，像是年代久远。 而让阿宁心跳漏了一拍的，是窗边坐着的那个人。 一位红衣女子，侧身坐在窗前的矮榻上，宽袖长裙，衣料是极正的石榴红，在暖黄的烛光中如同一团静静燃烧的火焰。她的青丝松松挽起，只用一支白玉簪固定住，几缕发丝垂在耳边。侧脸的轮廓柔和而分明，睫毛在烛光下投下一小片阴影。她正低头往杯中倾倒茶汤，手腕稳稳的，水流细如丝线，落入杯中悄无声息，动作不急不缓，从容得仿佛不是在深山雪夜的除夕独坐，而是在自家庭院中闲度一个再寻常不过的黄昏。 她抬起眼，看向门口的少年。 那一双眼睛很平静，像冬日里没有风的湖面，不起一丝波澜。她微微一笑，并不惊讶，也不热络，仿佛早就知道会有人在这个雪夜推门进来。 “外面风大雪大，进来暖暖身子吧。”她说，声音不大，却清清楚楚地落在耳边，像一片雪落在水面上，轻轻柔柔地化开了。 阿宁张了张嘴，想说谢谢，喉咙却像被什么堵住了。他局促地脱了鞋，靴子上沾着雪泥，在门口跺了又跺，生怕弄脏了那光洁的竹席。女子并不在意，只伸手将另一只青瓷杯推到他面前，杯中茶汤澄碧，热气袅袅升腾。 他坐下来，捧起茶杯。暖意从掌心一路渗进去，冻僵的手指渐渐有了知觉。他低头呷了一口，微苦，继而是清冽的回甘，一股说不出的香气从喉咙直冲眉心，整个脑袋都清明了几分，浑身的寒气仿佛被这一口茶驱散了。 “多谢……姐姐。”阿宁不知该如何称呼，支吾着叫了一声。 女子似乎觉得这个称呼有趣，唇角微微弯了弯，没有纠正，也没有应承。她执起茶壶，又给他续了一杯，动作行云流水，像做过无数次一样自然。 窗外的风不知何时小了一些，雪还在静静地下。炉火噼啪作响，炭灰偶尔炸开一颗火星，在空气中划出一道短暂的弧线。博山炉中的青烟缓缓升腾，在两人之间轻轻摇曳。 “这么大的雪，你怎么跑到山上来了？”女子问，语气随意，像在问一个邻家的孩子。 阿宁低下头，手指摩挲着杯壁，沉默了一会儿才说：“家里……有点事，心里烦，就想出来走走。” 他没有细说，女子也没有追问。她只是点了点头，仿佛人世间所有的烦闷，在她眼里都不过是山间的一片云，来了又走，聚了又散。 “除夕夜一个人往深山里走，你倒是有胆量。”她说，语气里带着一点淡淡的感慨，“这山上年年都下雪，年年都有人迷路，能走到这里来的，却不多。” 阿宁抬起头，看着她：“姐姐一个人住在这里吗？” “嗯。” “不冷清吗？”他问，随即又觉得这话问得唐突，连忙低下头去。 女子没有立刻回答。她侧过头，望向窗外。风灯的光映在纸窗上，雪花一片一片地贴上来，旋即融化，留下浅浅的水痕。远处隐约传来几声爆竹响，沉闷而遥远，像隔了厚厚的棉被。 “冷清这种事，习惯了就不觉得了。”她轻声说，语气平淡如水，眼底却掠过一丝极淡的东西。那是一种不属于这个年纪的寂寥，像深冬的月色照在一口古井上，冷冷的，深深的，看不见底。一年又一年，雪落雪融，花开叶落，山中岁月不动声色地流过，她在其中，像一枚沉在水底的石头。 阿宁心头一颤，不敢再多问。 女子收回目光，轻轻转了话题：“你觉得这雪怎么样？” 阿宁愣了一下，顺着她的目光也看向窗外：“冷，大，能把人埋了。” 女子笑了，笑容很淡，却让整张脸都柔和了起来：“它最是公允。富贵也好，贫贱也好，一并盖住了。等雪化了，什么都不留。” 她说着，又往炉里添了一块炭。火光跳动了一下，将她的影子投在身后的墙上，长长的，轻轻的。 “梅也公允吗？”阿宁也不知自己怎么会问出这句话。 女子看了他一眼，目光里多了一丝意外的欣赏：“梅不一样。它偏挑最冷的时候开，倔得很。可要不是这份倔，这冰天雪地里，还有什么好看的？” 她说这些话的时候，语气是淡的，像在说一些毫不相干的事。可阿宁听着，心里那团堵着的东西，不知什么时候悄悄松开了。他低头看着杯中碧绿的茶汤，茶水映着烛光，像一汪小小的琥珀。 又喝了几杯茶，窗外的风雪声渐渐远了，炉火的暖意像一双无形的手，轻轻覆在他的眼皮上。阿宁觉得困意一阵一阵地涌上来，脑袋越来越沉，眼前的景物开始模糊。红衣女子的轮廓在烛光中变得朦胧，像隔了一重薄薄的水雾。博山炉的青烟袅袅上升，在空气中缓缓散开，满室的香气浓郁而温柔。 “困了就睡吧。”她的声音远远地传来，像从另一个世界飘来的。 阿宁想撑住眼皮，却撑不住了。他趴在矮几上，额头抵着温热的竹席，最后的印象是那只红泥小火炉中的炭火，橘红的光一跳一跳的，然后一切都沉入了温暖的黑暗之中。 他被一阵爆竹声惊醒。 劈里啪啦的脆响在耳边炸开，近得不得了。阿宁猛地睁开眼，一片刺目的白光扎进来，他眯起眼，好一会儿才看清自己在哪里。 一堵斑驳的土墙，墙皮剥落，露出里面的黄土和碎石。头顶是破了大半的瓦片，残雪从缝隙中漏下来，在晨光中闪着细碎晶莹的光。供台上积着厚厚的灰，一尊泥塑的土地公歪歪斜斜地立着，漆面已经剥落得看不出本来的颜色，只有底座上依稀能辨认出“福德正神”四个字。 是山脚那座废弃多年的土地庙。 阿宁愣住了。他低头看自己，棉袄上沾着枯草和泥土，双手空空。可是身边的地上，有什么东西在晨光中微微发亮。 一枝红梅。 梅枝横陈在供台上，枝头的花瓣鲜红欲滴，雪珠挂在花瓣边缘，晶莹剔透。它像是刚从枝头折下来的，还带着清晨的露气和寒意。而梅枝旁边，搁着一只温酒壶，陶质的，壶身圆润，透着一层温润的光。他伸手去摸，壶壁还是温热的。 他拔开壶塞，一股酒香扑鼻而来，浓郁中带着一丝淡淡的梅花的清气。酒是温的，像是刚被人暖过。 阿宁猛地抬头，望向土地庙的门。 门外天光大亮，雪已经停了，阳光照在雪地上，白得刺眼。远处的村庄里，爆竹声此起彼伏，炊烟袅袅升起，在蓝灰色的天空中轻轻飘散。这是新年的早晨，人间换了新的一页。 他站起身，走到门口，回头望向山上。 山上的雪雾已经散了，整座山在晨光中清晰可见。枯树，岩石，雪脊，一切都清清楚楚。可没有飞檐，没有灯笼，没有那株老梅，没有那一串风铃的叮当声。只有白茫茫的山脊在阳光下一字铺开，安安静静地卧在那里，什么痕迹都没有。 昨夜的一切，像一场过于真切的梦。 可酒壶是温的。 红梅是真的。 阿宁低头看着手中的梅枝，花瓣上还有未化的雪珠。他又看了看那只温酒壶，壶身的温度正一点点凉下去，但那股梅花的清气还在。 他把红梅小心地揣进怀里，又把酒壶系在腰上，回身看了一眼那座破败的土地庙，然后踏进了新年的晨光里。 山脚下，爆竹声声，人间正热闹着。 阿宁踩着一地碎雪，一步一步向村庄走去。他的脚印在身后弯弯曲曲地延伸，像一行浅浅的诗句，写在这洁白的大地上。 他走得很稳，心里那团堵着的东西，不知什么时候，已经散了。</p>
