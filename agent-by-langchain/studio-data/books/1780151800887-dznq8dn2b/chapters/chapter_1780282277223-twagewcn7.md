# 4. 背权地狱

# 4. 背权地狱

距离高考还有二十天。

我在书桌前坐下，翻开那本从老钱店里带回来的"7B-Lite 背诵手册 v2.3"，深吸一口气，然后呼出来。

封面上那行小字——"精度损失0.01%"——在台灯下泛着微微的光泽。我用手摸了摸，是凸版印刷，手感很好。无论老钱的技术有多坑爹，至少在印刷品上他是下了血本的。

我翻到第一页。

第一行字是这样的：

***参数 #00000001: 0.00002345***

我盯着这个数字看了大概十秒钟。

0.00002345。零点零零零零二三四五。七亿分之一。

我掏出笔，在手边的草稿纸上抄了一遍。0.00002345。然后闭上眼睛默念了三遍。

三遍之后睁开眼，再回想——脑子里一片空白。刚才念的是什么来着？0.00002……什么东西？

我又翻回去看了一眼。0.00002345。好的，重新来。

这一次我用了联想法：0.00002345——把它拆成"两个零、两个零、二三四五"。两个零两个零二三四五，两个零两个零二三四五……

五分钟后，我确信自己记住了。然后我翻到第二页。

***参数 #00000002: -0.00007891***

负的。零点零零零零七八九一。

我的大脑开始发出第一声警报。

但这才第二个参数。七亿个参数中的第二个。我告诉自己，没关系，万事开头难，后面会越来越顺的。我继续往下翻。

第37个参数的时候，我的大脑冒烟了。

这不是修辞手法——我是真的觉得头顶在冒烟。一种灼热感从太阳穴两侧蔓延到整个颅腔，像是有谁在我的脑壳里放了一个微波炉，设定的时间是一整天。

我趴在桌上，额头贴着冰凉的桌面，感受那股灼热慢慢退去。

然后我又坐起来，继续。

第89个参数的时候，我发现前面背的八十八个参数——全忘了。

一个都不剩。干干净净。就像我的大脑是一块刚刚格式化的硬盘，连回收站都没有的那种。

0.00002345？不记得。
-0.00007891？不记得。
0.00000123？好像见过，但不确定是第几个参数。

我翻回第一页，从第一个参数重新开始。这次我学聪明了，不再死记硬背，而是给每一个数字编故事——

0.00002345：凌晨两点三十四分五十秒，我还在背参数。
-0.00007891：负的，代表我此刻的情绪指数。
0.00000123：这个数刚好等于123除以100000000，虽然不知道有什么意义。

编故事果然有效。到第150个参数的时候，我脑子里已经积累了一整套荒诞的数字宇宙。每个参数对应一个故事，每个故事对应一个数字。我感觉自己不是在背模型参数，而是在创作一部后现代数字史诗。

但问题是——这部史诗实在太长了。七亿个参数，意味着七亿个故事。就算每个故事只花十秒钟来想，七亿乘以十秒……

我停下了计算。因为结果太令人绝望了。

绝望到我又把手册摔在了地上。

然后我又把它捡了起来。

---

桌上堆满了咖啡罐。

从最开始的速溶咖啡——雀巢那种一条一条的，一次冲三条，加三块糖，当糖水喝——到后来的挂耳咖啡——在楼下便利店买的，一包五块钱，用开水冲的时候满屋子都是苦味——再到最后的冷萃液——直接拧开倒进嘴里，连泡都省了。

这是我的咖啡梯度降级理论：随着高考倒计时数字变小，咖啡的冲泡成本也必须同步降低。刚开始你还有心情用热水慢慢冲，到后来你连烧水的耐心都没有了。

此刻桌上摆着的是一个冷萃液的瓶子，已经空了。旁边还有两个挂耳咖啡的包装袋，和一个撕开的速溶咖啡条。一个完整的咖啡消费金字塔，从塔尖到塔底，只用了一个星期。

我拿起冷萃液的瓶子，对着台灯看了看，里面一滴都不剩了。我把它放回桌上，继续背第151个参数。

0.00004567。

凌晨两点十七分。

就在我准备背第152个参数的时候，房门被敲响了。

咚咚咚。

三声，不轻不重，带着一种我已经非常熟悉的节奏感——那是我妈的敲门节奏，独一无二，任何人都不可能模仿，因为里面包含着一种混合了担心、催促、不耐烦和"我知道你一定还没睡"的复杂情绪。

"儿子？"

门被推开一条缝，我妈端着一碗鸡汤探进半个身子。

鸡汤的香味像一记重拳，直接击穿了我用咖啡因构筑的防线。那种浓郁、温热、裹着枸杞和红枣香气的味道，让我鼻子一酸。

"妈，我——"

"别说话，把汤喝了。"

她把碗放在桌上，一眼就扫到了桌上那片咖啡罐的"考古遗址"。她的表情以肉眼可见的速度从慈母切换到严母。

"你又喝这么多咖啡？不要命了？"

"妈，咖啡提神。"

"提什么神？你这样喝下去，高考没考先进医院了。"

我没反驳。因为她说得对——我已经连续四天凌晨三点睡了，心脏偶尔会突然跳得很快，快到我必须停下来深呼吸。但我不能停下来，因为全县的考生都在背书，都在喝咖啡，都在凌晨三点跟自己的大脑搏斗。

我妈在床边坐下，视线落在我面前的手册上。

"今天背了几个B了？"

我愣了一下，差点笑出来。"妈，不是几个B，是几个……算了，就是背了多少页的意思。"

"那你背了多少页了？"

"五十多页。"

"五十多页？"我妈的眼睛亮了，"那不就是一小半了？行啊儿子，有希望啊！"

我没告诉她五十多页里反复背了三次才记住，也没告诉她越往后越难。我只是点点头，端起鸡汤，吹了吹上面的油花。

"对了，你李阿姨的儿子——就是那个考了三次的那个——"

我心里咯噔一下。李阿姨的儿子，江湖人称"李三战"，复读了两年，第三年据说已经背到了7B，今年势在必得。

"人家都背7B了！"我妈的语气里有一种"别人家孩子什么都好"的标准腔调，"你咋样？你那本手册是几个B的？"

"7B。"

"那不跟人家一样吗！"我妈一拍大腿，"那你加把劲，别落后了。"

我没说我这7B是花了三千块从老钱那买的，也没说这7B可能和其他几千个人的7B是同一个东西。我只是又喝了一口鸡汤，然后被烫到了——碗外壁不烫，但里面的汤温度极高。

我含着那口汤，咽也不是，吐也不是，最后硬是吞了下去。喉咙一路火辣辣地疼，但我没有吐出来。

因为我妈就坐在旁边，我不想让她看到我连喝汤都喝不好。

我妈坐了大概十分钟，期间又念叨了几句"学习注意方法"、"多休息"之类的套话。临走前，她做了一件让我意想不到的事——

她拿走了我的手机。

"妈——"

"我给你保管，考完再给你。"她把手机揣进兜里，语气不容置疑，"你这孩子，一刷手机就是两个小时，别以为我不知道。"

门关上了。我盯着她离开的方向，张了张嘴，最后什么也没说。

其实我想说的是：妈，我每天凌晨三点才睡，不是因为刷手机，是因为我真的背不完。但你不会信的。在你的世界里，所有晚睡的孩子都是在玩手机，没有一个是在真的学习。

而且——就算我说了，我该怎样跟你解释什么叫"模型蒸馏"？什么叫"参数背诵"？什么叫"0.00002345"？

你只会说：儿子，别整那些复杂的，好好背书就行。

---

凌晨零点，我偷偷从枕头底下摸出了备用手机。

是的，我有两部手机。一部是明面上用的，被我妈没收了；另一部是之前淘汰下来的旧手机，我藏在枕头套里，连着宿舍的WiFi，瞒天过海。

打开微信的时候，班级群里有99+条消息。

我往上翻，看到王胖子在下午四点发的一条消息：

"兄弟们，我决定了，背0.5B，裸考。"

底下瞬间炸了锅。

学霸李明辉第一个回复："你这是全裸考。"

配了一张熊猫头的表情包。

接着是刘子轩的补刀："0.5B连图像识别都跑不了吧？你背这玩意儿有啥用？"

"就是，"陈静也跟着起哄，"人家7B都嫌不够用呢，0.5B？那不是等于没背吗？"

王胖子回了一个愤怒的表情，然后打了一行字：

"0.5B怎么了？0.5B也是B！"

这句话在群里引发了第二轮狂笑。李明辉发了一条语音，我点开听了——里面是他的笑声，夹杂着"0.5B也是B……哈哈哈哈哈……"的断断续续的声音。

我盯着屏幕，手指悬在输入框上方。

我想打一行字：我也背0.5B。

不，我已经不是0.5B了。我背的是7B——至少手册封面上是这么写的。虽然可能跟他们的7B是同一个东西，虽然可能老钱塞给我的是跟另外八千人一样的批发货，但它至少印了"7B-Lite"四个字。

我打了几个字，又删掉了。

再打一行，又删了。

最后我发了三个字：

"加油吧。"

然后我关掉了群聊。

王胖子0.5B是裸考，那我是什么？用三千块买了个"可能也是0.5B但印着7B"的手册，然后把自己关在房间里没日没夜地背，每天花费十四小时以上的时间——我是什么？

我可能是现存最愚蠢的物种。

---

凌晨两点，第十二罐咖啡空了。

我把它放在桌上，和前面十一个空罐子排成一排。从左边往右看，就像在看一个咖啡因中毒者的墓志铭。

我揉了揉眼睛，翻开手册的第137页。

然后我愣住了。

第137页是空白的。

我以为自己看错了，合上手册又重新翻开。没错，第137页的正面是白纸，背面也是白纸。我又翻到第136页——上面印着密密麻麻的参数，到第136页的最后一行戛然而止。翻到第138页——空白。第139页——空白。第140页——空白。

我从头翻到尾。整本手册，从第137页到第200页，全是空白的。

我大脑里那根已经绷了二十天的弦，在这一刻，断了。

第一反应是：盗版？印刷厂装订出错了？少印了几十页？

第二反应是：不对。这不是装订错误。这本手册本来就是这么设计的——它的确是7B的手册，但它只印刷了前面七十分之一的内容。也就是说，我背到第136页，实际上只背了大概0.5B的内容。

第三反应，也是最让我血液凝固的那个：

老钱压根就没打算给我7B。

他给我的是0.5B。从头到尾都是0.5B。只不过他把0.5B的手册包装成了7B——封面印得精美点，定价定得高一点，再用那一套"精度损失0.01%"的屁话让你相信你买到的是真货。

三千块的0.5B。平均一个参数……算了，这个数学题我算不清楚。

我拿起手机，翻开通讯录，找到老钱的微信。

头像是一个动漫人物，我看不清是谁。朋友圈三天可见，最新一条是转发的一个电脑维修的小广告。

我点开对话框，打了一行字："钱哥，手册后半部分是空的，怎么回事？"

然后又删了。

再打："钱师傅，我想问一下——"

又删了。

凌晨两点。我打电话过去又能怎样？他接起来，说"哎呀小伙子，那个是防伪设计，你先背前面的，后面的考前来找我要"，或者"那个是独立包装的，你忘了领了"。

又或者，他根本不会接。

我把手机扔在床上，仰面躺下。

天花板上的灯管在嗡嗡作响，那声音和老钱店里那间小房间的灯管很像。实际上它们可能是一模一样的型号——都是那种最便宜的LED灯管，在深夜会发出一种微弱的、持续的电流声。

我盯着天花板，脑子里什么也没想。

不是因为我不想去想，而是因为我的大脑已经停止了工作。经过二十天的疯狂记忆，经过十二罐咖啡因的化学轰炸，经过第137页空白带来的致命一击，它终于做出了一个理性的决定——关机。

我关掉了台灯。

房间陷入黑暗。

黑暗中，我依然盯着天花板的那个方向，虽然什么都看不见了。耳边是灯管的嗡嗡声，远处偶尔传来一两声车喇叭。

我想起了老钱妻子说的那句话——"不都是同一个模型吗？"

我想起了老钱的那一声"嘘——"。

我想起了走出巷子时没回去质问他的那个决定。

其实在某种程度上，我知道这一切——我早就知道。从我站在这条巷子里，手里拿着这本手册的那一刻起，我就隐约感觉到了不对劲。但我没有深究，因为深究的代价太高了。

一千五，是我两个月的生活费。
7B，是我仅存的一线希望。
承认自己被骗了，就等于承认自己这一千五和一整年的努力全都打了水漂。

所以我选择相信。相信老钱的技术，相信那本印刷精良的手册，相信0.01%的精度损失，相信半小时的脑电波写入就能让我逆天改命。

现在这本手册的空白页告诉我：你信错了。

或者说，你从一开始就选择了信，因为你没有别的选择。

凌晨两点十七分。

我翻了个身，把脸埋进枕头里。

明天——不，今天——我还要继续背。虽然只剩二十天了，虽然手册后半部分是空的，虽然我可能从始至终背的都是0.5B的东西，虽然群里所有人都在嘲笑0.5B。

但0.5B怎么了？0.5B也是B啊。

至少，我现在终于能理解王胖子那句话了。
