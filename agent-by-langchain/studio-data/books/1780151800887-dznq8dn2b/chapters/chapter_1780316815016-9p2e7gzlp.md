# 除夕·轮回客

<p>一、雪崩·离体</p><p>除夕的暮色是从山脊开始沉的。</p><p>白度提着纸钱和香烛，独自走在通往山顶的雪路上。村里爆竹声断断续续地响着，家家户户亮着暖黄的灯火，炊烟在暮色中袅袅升起，混着炖肉的香气，被风送到山脚下。他回头看了一眼村庄，没有停留，转身继续向上走。</p><p>他没有家可以回。父母早逝，没有妻小，孤身一人住在村尾的老屋里，除夕对他来说不过是比平日更冷清的一天。上山祭祖，是每年唯一固定要做的事。不是出于多深厚的孝心，而是除了这件事，他想不出还有什么值得在除夕夜里去做。</p><p>坟茔在半山腰，被积雪覆了大半。他蹲下身，用手拂去墓碑上的雪，露出底下模糊的字迹。香烛插进雪里，怎么也立不住，他索性把纸钱压在坟头上，划了根火柴点燃。火苗舔着黄纸，在暮色中跳跃了几下，便熄了，留下几缕青烟和一片焦黑的纸灰。</p><p>他跪在雪地里，磕了三个头，却不知道该说什么。喉咙像被什么堵住了，千言万语都化成了呼出的白气，在冷空气中散了。</p><p>站起身的时候，他的目光不自觉地越过坟茔，投向更远处的山脊。那里有一道巨大的雪坡，白茫茫的，在暮色中泛着幽蓝的光。他不知道自己在看什么，只是觉得那个方向有什么东西在牵引着他，如同一个做了一百次的梦，醒来后只剩下模模糊糊的轮廓和一种说不清的惆怅。</p><p>他看了很久。</p><p>然后他听见了声音。</p><p>不是风声，不是树枝折断的声音。那是一种沉闷的、从地底深处碾压上来的轰鸣，像整座山在喘气。白度猛地转过头，看见山脊上的雪层裂开了一道缝，那道缝正在以惊人的速度扩大，雪块开始崩塌，翻滚，汇聚成一道白色的巨浪，朝他倾泻而来。</p><p>他的大脑一片空白。双腿想跑，却陷在雪里拔不出来。那声音越来越近，越来越大，像千军万马从头顶碾过。</p><p>白度的最后一个念头是：原来雪崩是这样的声音。</p><p>然后白色吞没了一切。</p><p>极致的冷。然后是窒息。然后是寂静——一种从未体验过的、连自己的心跳都听不见的寂静。白度感觉自己在下沉，又像是在上升，身体不再是身体，成了一片羽毛，一绺烟雾，在无边无际的白色中飘荡。他不知道自己要去哪里，也不知道自己是谁，只是飘着。</p><p>就在这时，他看见了一点光。</p><p>橘红色的，温温软软的，在远处亮着。不是月光，不是星光，那是一种暖的、像灯笼一样的光，在一片死寂的白色中安安静静地亮着，像一只等待的手。</p><p>白度的意识朝那光飘去，不由自主，毫无抵抗。</p><p>二、关前·旧识</p><p>他推开门的时候，还以为自己还在梦里。</p><p>暖意扑面而来，裹着梅花的冷香和炭火的焦香，一瞬间驱散了寒气的记忆。脚下是淡青色的竹席，纹理细密，触感温润。正中央一只红泥小火炉，炭火烧得正旺，橘红的火光在墙壁上一跳一跳。博山炉的青烟从仙山状的炉盖孔窍中袅袅升腾，在空气中蜿蜒变幻。</p><p>窗边坐着一个人。</p><p>红衣少女。石榴红的宽袖长裙，衬得她的面庞白净如雪。青丝松松挽起，斜插一支白玉簪，几缕发丝垂在耳侧。她低着头，正往杯中倾倒茶汤，手腕稳稳的，水流细如丝线，落入杯中悄无声息。姿态从容极了，从容到不像是在除夕夜的深山独坐，而是在做一件已经重复了无数次的事。</p><p>她抬起眼，看着站在门口的白度。</p><p>白度愣住了。那张脸他说不上熟悉，却有一种奇异的亲切感，像在梦里见过无数次，醒来后怎么也想不真切的面容。</p><p>她开口了，声音不大，却清清楚楚落进耳朵里。</p><p>“你来了。第九十九次了。”</p><p>白度张了张嘴，喉咙发紧，一个字也说不出来。</p><p>少女示意他在对面坐下，将一只青瓷杯推到他面前。茶汤澄碧，热气袅袅。他低头捧起杯子，暖意从掌心渗进去。目光落在杯底，他整个人僵住了。</p><p>杯底映着一张脸——不是他自己的脸。那是一张陌生的面孔，瘦削，憔悴，囚衣褴褛，眼眶深陷。他眨了眨眼，杯底的面孔变了，变成了一只白鹿，鹿眼湿漉漉的，透着恐惧和倔强。再眨一下眼，又变成了一个将军，盔甲残破，满脸血污，目光望向远方。然后是书生，锦衣少年，白衣仙人……一张张面孔在茶汤中轮转浮现，像一册翻不完的画轴，每一页都是不同的人，每一双眼睛里都藏着相同的什么。</p><p>白度猛地抬起头，看着红衣少女。</p><p>“九十九世，”她说，语气平淡得像在说今天的天气，“你在六道中轮回了九十九次。每一世我都看着你从关前走过。这一世，你停下来了。”</p><p>她放下茶壶，十指交叠，搁在膝上，静静地看着他。</p><p>“这间楼阁是轮回的关口。天亮之前，如果你能记起自己当初为何堕入轮回，便可以解脱。如果记不起来……”她顿了顿，“你会坠入无间地狱，永世不得超生。”</p><p>白度的手指微微发抖。不是害怕，是一种从骨头缝里渗出来的茫然。他什么也不记得，脑子里一片空白，像一个被掏空了的容器。</p><p>少女看着他，目光里掠过一丝极淡的东西——像是心疼，又像是隐忍了很久的某种情绪。她没有再说话，只轻轻拂了拂袖。</p><p>烛火骤暗。</p><p>三、六世·亲历</p><p>黑暗像潮水一样涌来，然后白度看见了。</p><p>地狱道。他蜷缩在寒冰地狱中，四周是无边的黑暗和彻骨的冷。铁索穿过锁骨，将他钉在冰壁上，皮肉与冰面黏在一起，每动一下都撕下一层皮。他不知道自己在受什么罚，也不知道已经过了多久。在意识最深处，有一个微弱的声音反复说：有人在等我。有人在等我。那个人是谁？他不知道。但这句话像一粒火种，在冰封的胸腔里微弱地亮着，没有熄灭。</p><p>饿鬼道。他是一个妇人，衣衫褴褛，面容枯槁，怀里抱着一个早已没有气息的婴儿。她的手指紧紧抓着婴儿的襁褓，指甲断裂，渗出血来。有人来抢，她蜷缩身子，用后背护住怀里的孩子，发出野兽一样的嘶吼。她已经三天没有吃东西了，饿得胃里像有刀在搅。可她还是不肯放手。孩子已经死了，她知道。可她就是放不下。</p><p>畜生道。他是一只白鹿，腿上中了一箭，血迹在雪地上拖出长长的一条线。身后有猎犬的吠声在逼近，越来越近。可他没有往密林深处逃，他拼命地朝着一座山跑，朝着一座有着朱红楼阁的山跑。他不知道那里有什么，只知道必须回去。必须回去。</p><p>修罗道。他是战败的将军，浑身浴血，拄着断剑跪在尸山血海之中。敌军从四面八方涌来，马蹄声震天动地。他已经没有力气再站起来了。他抬起头，望向北方。北方的天际线上，有一座山的轮廓。他说不出那句话，嘴唇翕动了几下，什么声音也没发出来。可他知道，有人在等他。</p><p>人道。他是赴京赶考的书生，在老梅树下从黄昏站到深夜，从深夜站到天明。雪落了他一身，他没有拂去。他在等一个人，一个说好了要来的姑娘。她没有来。他在那棵梅树下站了一整夜，直到东方既白，晨光照在他满是霜花的眉睫上。他笑了笑，转身离开了京城。此后再也没有娶妻。</p><p>天道。仙门大殿，金碧辉煌，云雾缭绕。殿上站着两排仙门弟子，衣袂飘飘，神色肃穆。正中坐着一位白发老者，手中拂尘一摆，声如洪钟：“长生诀失窃，谁人所为？”寂静。然后一个白衣少年从队列中走出，跪在大殿中央，脊背挺得笔直，声音清朗如玉石相击：“启禀师尊，长生诀是我盗的。”</p><p>满座哗然。</p><p>白度看见那少年的脸——年轻，倔强，眼底有一团不肯熄灭的火。他看见老者的震怒，看见同门的惊愕，看见执法弟子将锁链套上少年的脖颈。他看见少年被推向轮回道的时候，偷偷侧过头，朝殿外看了一眼。</p><p>殿外的台阶下，站着一个红衣少女。</p><p>她哭得无声无息，眼泪像断了线的珠子往下掉，可她不敢出声，不敢动，只能死死咬着嘴唇，看着少年被推入那道旋转的黑色漩涡。</p><p>少年的嘴角弯了一下，像是笑，又像是在说：别怕。</p><p>然后他被黑暗吞没了。</p><p>四、记起·钟响</p><p>六道的光影消散了。</p><p>白度跪在竹席上，浑身颤抖，泪流满面。那些记忆像决堤的洪水一样涌入他的脑海，每一世的痛苦、不甘、思念和等待，全部回来了。他记起了那个决定，那一句“长生诀是我盗的”，记起了他为什么要顶罪。不是出于什么崇高的道义，只是因为——他不能看着她受罚。千年的囚禁，永世的孤独，她不该承受这些。</p><p>他抬起头，望向红衣少女。</p><p>“阿蘅。”</p><p>他说出这两个字的时候，声音是哑的，轻得像一片雪落在水面上。</p><p>少女的肩膀微微颤了一下。她垂下眼，烛光在她脸上投下一片阴影。然后眼泪从她的眼眶里滑落下来，无声无息，沿着脸颊流到下颌，滴在青瓷杯里，叮的一声，极轻极细。</p><p>千年了。这是她千年来第一次落泪。</p><p>窗外忽然响起一阵密集的爆竹声，噼里啪啦的，由近及远，此起彼伏地在山谷间回荡。新岁已至。夜色中隐约有人声在欢呼，在笑，在喊“过年了”。人间正在辞旧迎新，而在人间之外，在这座朱红的楼阁里，两个相隔千年的人隔着烛火和茶烟，对望了一眼。</p><p>阿蘅抬起手，用袖口轻轻拭去眼泪，重新露出那个从容的、波澜不惊的微笑。可这一次，笑容里有了一点点暖意。</p><p>“还有最后一世，”她说，声音里带着一丝极淡的颤抖，“你一定要记得来找我。”</p><p>她拂了拂袖。烛火跳了一下，楼阁的轮廓开始模糊，茶烟、竹席、博山炉，一切都在瓦解，像一幅浸了水的画，颜料一点一点化开。</p><p>白度想伸手抓住什么，指尖却什么也没碰到。</p><p>五、梅信·约定</p><p>白度猛地睁开眼。</p><p>刺目的白光扎进瞳孔，他眯起眼，好一会儿才看清头顶的天空。灰蓝色的，几缕淡云，天已经亮了。他躺在雪崩的残迹中，半个身子埋在雪堆里，一只手露在外面，手指冻得发紫。浑身都在疼，可他还活着。</p><p>他挣扎着坐起来，雪从身上簌簌落下。低头的时候，他看见了怀里的东西。</p><p>一枝红梅。</p><p>枝头三朵花，花瓣鲜红欲滴，在晨光中微微透明。他轻轻地翻转梅枝，看见花瓣上用细如发丝的刻痕写着两个字。</p><p>等我。</p><p>他握着那枝梅，看了很久很久。手指渐渐暖了过来，梅花的清香若有若无地飘进鼻子里。远处的村庄里传来新年的爆竹声，断断续续的，混着鸡鸣和狗吠。炊烟在蓝灰色的天空中慢慢升起，人间又是一年。</p><p>白度笑了。眼泪顺着脸颊滑下来，落在花瓣上，他伸手抹了一把脸，吸了吸鼻子，撑着地面站起来。雪在脚下咯吱作响，他低头看了看手中的红梅，把它小心地揣进怀里，贴着胸口的位置。</p><p>然后他朝山下走去。</p><p>雪地上留下一行深深的脚印，蜿蜒向有炊烟升起的地方。晨光落在他背上，暖洋洋的。他走得不快，却很稳。</p><p>这一次，他会记得。</p>
