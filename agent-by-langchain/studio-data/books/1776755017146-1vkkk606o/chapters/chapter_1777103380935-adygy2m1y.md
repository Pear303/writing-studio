# 1

<p>是福不是祸，是祸躲不过！</p><p>杜煌已经很谨慎地在“BOSS歪聘”上筛选工作了，但他最终还是误入犯罪窝点。</p><p>那是一辆连夜狂奔的黑色商务车，窗户贴着深黑色防爆膜，隔绝外界所有光线和希望。</p><p>等车门再次拉开，混杂着廉价香烟、腐烂芒果和陈旧血腥味的湿热气息，便扑面而来了。</p><p>这里是东南亚的雨林深处。</p><p>护照早在过边境的那一刻，就被那个笑眯眯的“HR”撕成了碎片。</p><p>“欢迎来到缅北创业园区，诸君共勉哈！”</p><p>“这个肩上纹了条过江龙的，你们叫虎哥就行，今天开始由他来管理你们这一批次。”</p><p>那个看起来像是老板的人，对来到这儿的新人发表一番激情演讲。</p><p>他戴着墨镜，穿着白西装，自称白老板。语气激昂，也不知道在燃什么。</p><p>杜煌听见各处不断传来的啜泣和惨叫，唾骂与殴打声。</p><p>不远处，穿着人字拖的壮汉正把一个瘦弱得像猴子一样的男人踩在泥水里，手里拿着一根黑色的电棍，蓝色的电弧在空气中滋滋作响，伴随着焦糊味。</p><p>“居然想泄密求救？”壮汉一口带着浓重口音的普通话，唾沫星子喷在男人脸上，“知不知道你们电脑连的是老板的内网！这一跳防火墙都要报警了！”</p><p>“业绩差的就卖了呗，反正总有地方要。”</p><p>叼着烟的矮个子男人蹲在椅子上，手里把玩着一把生锈的匕首，眼神阴恻恻地盯着那个被打得抽搐的男人。</p><p>“哈哈，也是。现在腰子可值钱，特别是这种刚毕业大学生的，新鲜。”</p><p>杜煌感到一阵寒意从尾椎骨直冲天灵盖。</p><p>他抬眼打量四周。一排排灰白色的水泥楼，像是一块块巨大的墓碑，所有的窗户都装着结实的防盗网。</p><p>院子里拉着高压电网，几个角落里堆着拳头粗的铁笼。</p><p>地面潮湿发黑，不知道是常年积攒的泥还是洗不净的血。</p><p>几个同样穿着拖鞋、缩着肩膀的男人蹲在墙边，眼神空洞麻木，头都不敢抬一下。</p><p>原来是个电诈园区啊。他就说怎么刚入职，就有“公司入职旅行”这么好的事儿。</p><p>“发什么呆？新来的？”</p><p>一只粗糙大手，重重地拍在杜煌的肩膀上，力道大得差点让他一个踉跪。</p><p>杜煌回头，看见个满脸横肉的纹身壮汉，赤裸的上身纹着一条并不怎么威猛的过肩龙，手臂上还有几个烫烟头留下的伤疤。</p><p>“虎哥。”杜煌低着头，镇定下来。</p><p>“别废话，那边给你开好卡了。”</p><p>虎哥指了指角落里的一排破旧电脑，“把话术背熟，今天上号开单！开不了单，今晚别想吃饭。”</p><p>杜煌被分配的任务就是最基础的“狗推”，负责搞电话诈骗。</p><p>绝大多数人只要上网，就相当于裸奔。这里的人能通过各种灰道手段，搞到大量神州境内的网民资料，然后广撒网，愿者上钩。</p><p>他看着屏幕上一行行骗术脚本，以及话术本上那些利用人性贪婪、恐惧的套路，胃里一阵一阵翻涌。</p><p>“魂淡，我不干！”杜煌把手中的鼠标一扔，站了起来。</p><p>周围几个正在打电话的“同事”赶紧把眼神收回，连头都不敢抬。</p><p>虎哥愣了一下，随即像是听到了什么天大的笑话。</p><p>那张油腻的脸上绽放出狰狞的笑容。</p><p>“违法？哈哈哈哈！”虎哥笑得前仰后合，周围的几个打手也跟着哄笑起来。</p><p>“兄弟，你是真不懂还是假不懂？”</p><p>“进了这个门，法律就是老子手里的电棍。”</p><p>虎哥脸上的笑容骤然收敛，野兽般的凶狠爬上他狰狞的脸！</p><p>他猛地一脚踹在杜煌小腹！</p><p>“唔！”剧痛让杜煌弓成虾米，眼前发黑。</p><p>“给脸不要脸的东西。”</p><p>紧接着就是一阵拳打脚踢。雨点般的拳头落在杜煌的背上、头上、肋骨上。</p><p>杜煌试图反抗，但根本不是这几个亡命徒的对手，没两下就被按在地上摩擦。</p><p>不知过了多久，殴打终于停了。</p><p>杜煌感觉自己像是一摊烂泥，每块骨头都在叫嚣着疼痛，嘴里全是铁锈般的血腥味。</p><p>“拖进去，关禁闭。饿他一天，看他骨头硬不硬硬。”</p><p>杜煌被两个打手像拖死狗一样拖走，丢进了一个黑不溜秋的水泥房间。</p><p>嘭。厚重的铁门重重关上，最后一丝光亮也被吞没。</p><p>黑暗中，杜煌蜷缩在角落里，身体因为剧痛和寒冷止不住地颤抖。</p><p>他高烧了。</p><p>体温像是在坐火箭一样飙升，意识开始在滚烫和冰冷的极端中反复横跳。</p><p>这里好热，像是被扔进了太上老君的炼丹炉。</p><p>又好冷，像是被浸泡在万年冰窟里。</p><p>恍惚间，他开始做了一个梦……</p><p>梦境光怪陆离，无法用语言描述。</p><p>……</p><p>自己悬浮在冰冷茫远的星海中。</p><p>四周，是那种他在天文科普视频里看过的「宇宙丝状结构」，尺度巨大到令人本能窒息！</p><p>而在他正前方，一个疯狂膨胀的漩涡正贪婪地撕扯、吸食周围的一切。</p><p>起初杜煌以为是黑洞，但定睛一看，那根本不是什么天体，而是一段疯狂缠绕的不知何物。它在吞噬物质，吞噬能量，甚至连周遭的时空维度都在被它拉扯得扭曲变形！</p><p>杜煌不忍直视，仿佛再看一眼就要爆炸。</p><p>“肉者，形体之质，血肉之躯；灵者，精神之魂，无形之性。二者相合为人，肉载灵而行。”毫无预兆的声音在他身后响起。</p><p>杜煌猛回头，一个看不清面容的人形轮廓，静静立在扭曲的星光里。</p><p>“汝形魄与心魂，将每日倍增。”</p><p>“现在，醒来。”</p><p>呼——！杜煌猛地坐起，禁闭室里依旧昏暗憋闷，没有星海也没有怪物。</p><p>他不知道时间，自己睡了多久？</p><p>刚才做的梦是怎么回事？竟然如此真实……</p><p>铁门上的小窗被拉开，一道刺眼的手电筒光束直射他的眼睛，让他下意识地抬手遮挡。</p><p>“哟，还没死呢？”</p><p>那个纹身壮汉虎哥的声音传来，带着浓浓的讥讽。</p><p>“身体太弱了！你知不知道你昏死过去了1天1夜，整整24小时！我还以为要给你收尸了。”</p><p>随着一阵铁链哗啦声，铁门被打开。</p><p>两个打手进来，架起杜煌就往外拖。</p><p>一盆冰冷的脏水兜头浇下。</p><p>“咳咳咳！”</p><p>杜煌被呛得剧烈咳嗽，原本混沌的大脑被这冰冷一激，瞬间清醒大半。</p><p>但紧接着，他感觉到不对劲，很不对劲！</p><p>他看着自己原本满是手臂。</p><p>昨天留下的淤青，竟然已经消退大半！</p><p>一种从未有过的……饱足感，取代了疼痛。</p><p>就像是身体里的每一个细胞，都吞噬了什么高能量的东西，正在欢呼雀跃！</p><p>[[地点：1]]</p><p>[[地点：1]]</p><p>[[地点：1]]</p><p>[[情节：11]]
