# 3

<p>“为什么要告诉我们这些？”杜煌问，手心全是冷汗。</p><p>“我们工位挺近的，而且都在A区，所以认识认识，提前熟络。”</p><p>那个戴眼镜的男人耸耸肩，“我姓李，叫我老李就行。”</p><p>“我是杜煌。”</p><p>“我在这儿已经四个多月了。”老李靠着墙，声音像是从牙缝里挤出来的。</p><p>“说实话，我觉得自己这辈子回不去了。”</p><p>四个多月，将近半年！杜煌替他难过，但没说话，等着他继续。</p><p>“给你介绍一下这个产业园区的状况，还有几条忠告吧，年轻人。</p><p>“第一条，他们让你干坏事你就干。别犟，犟的人连骨头渣都不剩，我这腿啊，就是因为想逃，所以被打断了一条。</p><p>“第二条，少跟人交心。这里的人，为了减刑什么事都干得出来，你多说一句话，可能就是明天被出卖的理由。</p><p>“第三条，表现得太蠢是绝对不行的。太蠢会被卖器官。聪明一点，至少有机会活。</p><p>“第四条，如果你想活下来，一定要拼命表忠心，并且有什么能力就一定全力展示，这样才有机会从A区出去。”</p><p>“从A区出去？”杜煌猛地抬头，压低声音问，“干聪明点，表了忠心，并且有能力，就能离开这电诈园区了？”</p><p>老李苦笑，那笑容比墙上的霉斑还难看。</p><p>“哪有这么好的事。是从A区转到B区、C区。但至少BCDE区那些地方，能活命。”</p><p>杜煌眉头紧锁：“留在A区会死？”</p><p>“看来你是真的完全不懂。”</p><p>老李往四周扫了一眼，确认没有守卫靠近，才把声音压得更低，“我给你简单介绍一下这个产业园区的情况吧。”</p><p>“这个园区，分为ABCDEFGHIJ十个区。”</p><p>老李伸出手指，在地上划了个圈。</p><p>“十个区里，只有A区一百来号人，是被拐过来和骗过来的。”</p><p>杜煌心里一沉。</p><p>“其他九个区呢？”他问。</p><p>“呵，其他九个区，全是自愿过来的。”</p><p>这句话像一记闷棍砸在杜煌脑门上。</p><p>在他的认知里，缅北电诈园区里的人，不都是受害者？</p><p>“你那个表情，我太熟悉了，我刚来的时候也是这样。”</p><p>老李看穿了他的震惊，嘿嘿低声笑起来，“被拐骗过来的人和自愿过来的人，就算干的都是最低等的‘狗推’，也不能一概而论。”</p><p>“自愿……为什么？”</p><p>“自愿过来的，大多都是宗族产业、老乡带老乡、朋友拉朋友那一套。”</p><p>老李舔了舔干裂的嘴唇，“去之前，那帮人吹得天花乱坠，说什么月入几万、轻松发财、海外淘金，像是弯腰捡钱一样。那些被拉拢的人也知道，自己要去干的，是昧着良心的事，但他们还是来了。”</p><p>“但来了之后呢？”杜煌问。</p><p>“来了之后发现，奋斗是靠电棍。”</p><p>老李指了指虎哥腰间那根滋滋作响的东西，“你以为那些自愿来的人，来了之后还想留？有几个神人愿意天天挨电棍打电话嘛。”</p><p>“那他们为什么不跑？”</p><p>“他们没有不跑啊！BCDEF那些区，有一部分干满业绩的，就走人回家，或者干脆让家里凑钱赎人。</p><p>“其他留下来的，都是为了继续发展事业，反正这园区里，生活娱乐设施一应俱全。</p><p>“要是哪天，园区被神州官方强硬要求中南半岛方面执法，那这些自愿过来的人怎么办？</p><p>“被遣返回国的时候，他们肯定只能说自己是被骗的嘛。</p><p>“难道承认自己自愿过去，然后回神州坐几年十几年号子？”</p><p>杜煌张了张嘴：“但是……嘴会说话，证据不会啊。他们自愿来的，手机聊天记录、转账记录、出入境轨迹，这些东西炸得了吗？”</p><p>老李冷笑了一声，那笑声里带着一种看透一切的麻木。</p><p>“杜煌，你要舍弃典型的神州思维。”</p><p>“啊，什么意思？”</p><p>“这里是中南半岛。这里有大把军阀割据。军阀和这些园区是深度合作关系，利益绑在一起的。神州那边来查，他们就会在人到达之前，提前把整个园区连带着所有服务器、账本、监控录像，炸个稀巴烂。”</p><p>老李用脚在地上碾了碾，像是在碾碎一颗看不见的石子。</p><p>“你以为你在看新闻的时候，那些被捣毁的园区为什么总是只剩一片废墟？是真的被突击成功了吗？</p><p>“不，是人家联合着当地军阀自己炸的！人转移走了，证据销毁，自导自演！</p><p>“到了最后，受害者领个安抚金，被遣返回国。组织者换个地方重新开张，周而复始。”</p><p>杜煌感觉自己的世界观，正在被一寸一寸地撕裂。</p><p>在这个世界的某些角落，规则根本不是他以为的那样运转。</p><p>自己此前还是太过巨婴了。</p><p>“所以……”杜煌喉咙发干，“我们A区……”</p><p>“……唉，A区是没有退路的。”老李替他说完了这句话。</p><p>“其他BCDE区的人，要是哪天不想干了，让自己家里掏钱出来赎，又或者是把业绩干满，就回家去。</p><p>“但A区的人是被骗来的，护照被撕，身份被抹，连自己是哪天死的都没人知道。</p><p>“价值榨干、业绩干够以后，他们似乎也会告诉你，表现不错，让你‘回家’。</p><p>“实际上是转手卖给其他园区。一般来说，直接就送去嘎腰子了。</p><p>“毕竟和其他区自愿来的人相比，A区的只能算是‘猪仔’，算不上人。”</p><p>杜煌的后背一片冰凉。</p><p>“但这次有点奇怪。”</p><p>老李皱起眉头，声音里多了丝困惑，“以前A区的人都是干满一段时间才被转手，这次居然刚来就拉着你们这些新人，和我们这些老员工去抽血，还做器官配型筛查……”</p><p>老李的眼神突然变得锐利起来，死死盯着杜煌。</p><p>“难道说，我们这个‘创业园区’也要开办嘎腰子产业了？”</p><p>远处传来几声狗吠，二人不自觉地压低声音。</p><p>“如果他们现在就急需腰子来换钱……提前物色好优质资源……”</p><p>老李的声音压到了最低，几乎是用气音说出来的，“我们A区这一百来号人，就是第一批遭殃的。”</p><p>虎哥的大嗓门再次响起。</p><p>“磨蹭什么！都滚回工位去！今天的业绩还没动呢！”</p><p>杜煌领了新的手机，和一整本话术指南、任务表单，来到自己的位置上。</p><p>果不其然，他和老李坐的很近。</p><p>在上班期间不准交流，二人也只能默默用眼神相望。</p><p>工位上，杜煌机械地拿起话筒。</p><p>虽然心里翻江倒海，但他也知道，现在还不是反抗的时候。</p><p>他力量虽然增长了，但还不足以对抗整个武装园区，甚至未必是“虎哥”的对手。</p><p>必须忍耐。</p><p>“小姐，你的医保退款很快就要到期了……”</p><p>“【XX银行】您已初审通过，我行可将您的额度提高至880000元，五年随借随还……”</p>
