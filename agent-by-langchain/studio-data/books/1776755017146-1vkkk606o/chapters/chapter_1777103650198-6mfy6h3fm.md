# 2

<p>“说话。”虎哥把玩着手里的电棍，冷笑道，“干，还是不干？”</p><p>杜煌低下头，此刻只能装孙子：“我干……我干还不行吗。”</p><p>“这就对了嘛。”虎哥笑着拍了拍杜煌的脸，“早这样不就少受罪了？”</p><p>他随手从兜里掏出个屏幕微裂的旧手机，还有份皱巴巴的表单，扔在地上。</p><p>“你就跟着上面的名单和话术先背下来，然后一个一个打电话去推。1个月业绩至少一千美刀，达不到就哼哼哼……”</p><p>杜煌弯下腰，捡起那部手机。</p><p>这是一部不知道被多少人用过的老式智能机，后盖都磨花了，边框上全是油泥。</p><p>他按照虎哥的指示，翻开表单，准备背诵。</p><p>然而就在这时，鼻腔里一阵发痒，“阿嚏！”杜煌打了个喷嚏。</p><p>“咔嚓。”杜煌愣愣地看着自己的手。</p><p>仅仅是肌肉随着喷嚏的震动，自然手掌五指收缩了一下。</p><p>那部原本虽然破旧但结构还算完好的手机，就在他手里被掰弯了。</p><p>这手机原本就非常古老，破破烂烂。普通人只要两只手一块稍稍发力，掰断也是轻易的事！</p><p>但他……单手就把这破手机给弄坏了？</p><p>“虎哥，这手机……是不是坏了的。”</p><p>门外，虎哥正准备去点烟，眉头一皱，转身推门进来。</p><p>“坏了？刚才还好好的，你是不是故意？”</p><p>虎哥走进来，一眼就看到了杜煌手里那两半断得离谱的手机。</p><p>他眼神里的凶戾喷薄而出：“你小子想耍花样？”</p><p>“不……不是啊！这个手机我拿到时就已经是这样……的了。”</p><p>“还嘴硬！你意思是，我弄坏了手机？”</p><p>虎哥怒了，从腰间拔出电棍，捅过来。</p><p>滋滋！蓝色电弧顶在杜煌肚子！</p><p>按照常理，这一棍子下去，普通人至少要浑身麻痹口吐白沫悲嚎大叫。</p><p>但这一次的“剧痛”若是和昨天相比，程度却是远远不如先前的痛苦。</p><p>他的肉身防御力……暴涨了！</p><p>杜煌看着暴怒的虎哥，脑海回想起梦境中那个模糊的声音。</p><p>【汝形魄与心魂，将每日倍增。】</p><p>形魄，肉身力量；心魂，精神意志。简单翻译过来就是——他的身体素质和精神素质，会每天翻一倍？</p><p>“虎哥，先别揍了！”</p><p>门外传来声急促的低喝。一个戴墨镜的瘦高个守卫快步走来，按下虎哥的电棍。</p><p>“现在要去体检，白老板亲自选货。你把人打成这样，品相搞差，咱们谁都负担不起！”</p><p>虎哥闻言，手上的动作停止，脸上青筋跳了跳，终究还是收回电棍，啐口唾沫：“算你小子命大。”</p><p>瘦高个没再多言，转身朝外头扬了扬手。</p><p>其他几个守卫立刻拎着橡胶棍涌进各间牢房，粗暴地驱赶那些蜷缩的狗推们。</p><p>“都他妈起来！排队！去园区东边那栋白楼体检！谁磨蹭，今晚的饭就拿去喂狗！”</p><p>杜煌和其他十几名新来的“狗推”、另外上百个老员工，被赶到园区西侧的一排平房前。</p><p>这里原本可能是个仓库，现在墙壁被刷成了令人反胃的惨白色，但依旧掩盖不住墙角渗出的霉斑。</p><p>“排好队！都动起来！”</p><p>虎哥手里拎着那根滋滋作响的电棍，像赶鸭子一样把他们驱赶到走廊里。</p><p>他换了一件黑色背心，那条过肩龙纹身在惨白的灯光下显得格外狰狞。</p><p>队伍里没有人敢大声说话，都低着头只敢窃窃私语，像是一群待宰的牲口。</p><p>“怎么回事？怎么突然就拉我们来这……”</p><p>“这是哪里你们知道吗？”</p><p>“产业园区这么大，我们又只能被困在A区，天知道这儿还藏了些什么……”</p><p>杜煌站在中间，他低垂着眼帘，余光却不动声色地观察着周围。</p><p>这里的布局和昨天不太一样了。昨天来的时候是晚上，加上晕眩没看清。现在光线虽然昏暗，但他却看得异常清晰。</p><p>甚至连墙壁上苍蝇搓动腿部的细微声响，都能钻进他耳朵里。</p><p>这就是那个梦里的“倍增”吗？</p><p>杜煌心中默念，握了握拳。指关节发出轻微的爆鸣声，力量在血管里奔涌。</p><p>按照这里守卫的说法，他睡了整整1天1夜，24小时。</p><p>而自己的力量每天倍增一次，那么现在他的体质大约是先前的……2倍。</p><p>“进去！”</p><p>前面的门开了，一个穿着白大褂、戴着口罩和橡胶手套的医生冷冷地喊道。</p><p>杜煌走进去，屋里摆着一张满是污渍的铁床，旁边是一辆推车，上面摆满了闪着寒光的金属器具。</p><p>“脱了，躺上去。”</p><p>杜煌照做。他刚躺下，镣铐就“咔嚓”一声扣住了他的手脚。</p><p>“我去，这是在干嘛！”</p><p>“别乱动，抽血呢。”</p><p>白大褂从推车上拿起一根粗大的针头，连接上几根透明的采血管，动作麻木而熟练。</p><p>他用棉球在杜煌手臂上涂抹了冰凉的碘伏，找准静脉位置，攥紧针头猛地扎下去！</p><p>……针尖抵住皮肤，却没有刺入。</p><p>白大褂皱眉，加大力道再扎。这次皮层直接被针尖捅穿了，但因为要额外发力，扎歪了，没进血管！</p><p>他烦躁地把针拔出来，盯着杜煌手臂上那个连血都没渗出来的小点，嘀咕道：“怎么回事？你这皮怎么这么硬？”</p><p>杜煌没吭声，心跳平稳如常。</p><p>白大褂摇头，重新换了个位置，咬着牙使劲才扎进去。</p><p>暗红色的血液顺着管子缓缓流出，被分别注入几根标签不同的采血管里。</p><p>杜煌偏过头，看到了那个标签。</p><p>【HLA配型】</p><p>【PRA检测】</p><p>他不懂医学术语，但作为曾经的大学生，本能的直觉让他感到一阵恶寒。</p><p>医生又拿出一把极薄的手术刀，在杜煌的小臂内侧划了一道口子，取下了一块皮肤样本。</p><p>“啊！”隔壁隔间传来一声压抑的惨叫。</p><p>“叫什么叫！忍着！”虎哥在外面骂道。</p><p>医生还在继续，他甚至粗暴地检查了杜煌的口腔和下体，那眼神不像是在看一个人，更像是在检查一台二手车的发动机磨损程度。</p><p>检查结束，杜煌被解开镣铐，扔出门外。</p><p>“下一个！”</p><p>杜煌揉着还在渗血的手臂，站在走廊角落等待后续的指令，旁边一个微弱的声音传了过来。</p><p>“小兄弟，以前是医科出身？”</p><p>他转头，看到一个戴着眼镜的男人。他看起来三十五六岁，面相老实巴交，但眼神里透着一股被生活碾压后的锐利。</p><p>最引人注目的是他的左腿，裤管空荡荡的，断腿处用几圈脏兮兮的胶带胡乱缠着。</p><p>“啊？”杜煌没反应过来。</p><p>“你知道那些标签，是什么意思么？”男人推了推鼻梁上摇摇欲坠的眼镜，声音压得极低。</p><p>“我不懂。”杜煌摇摇头。</p><p>男人惨笑了一下：“HLA、PRA……那是器官移植前的配型筛查。”</p><p>杜煌的心脏猛地漏跳了一拍。</p><p>男人舔了舔干裂的嘴唇：“他们已经在挑我们的腰子了。还有眼角膜，肝脏，凡是能卖的，都在挑。”</p>
