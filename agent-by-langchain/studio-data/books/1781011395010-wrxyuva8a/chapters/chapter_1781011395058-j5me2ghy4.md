# 梦境开发

<p>里面的人是谁？</p><p>不知道，也不要开门，留别人一点隐私。</p><p>不过，钓鱼佬按捺不住心中的好奇。</p><p>他缓缓蹲下身子，眼睛凑近门缝，试图从那狭小的缝隙中窥见屋内的一丝端倪。</p><p>起初，门缝里透出的只是一片昏暗，什么也看不清。</p><p>钓鱼佬嘟囔：“神神秘秘，里面什么也没有吧……等等。”</p><p>他趴在地上的姿势定了很久，眼睛紧紧盯着门缝，仿佛被什么东西死死吸引住。</p><p>脸上的表情从好奇逐渐变为惊恐，身体也开始微微颤抖。</p><p>不知过了多久，他才如梦初醒般。</p><p>钓鱼佬手脚并用慌乱地往后退，好不容易站起身来，脸色煞白如纸，额头上豆大的汗珠不停地滚落。</p><p>他一把拉住杨帝：“我们，我们走吧。”</p><p>钓鱼佬平静了下来。</p><p>但他面部的肌肉束，仍在微不可察地震颤。</p><p>杨帝：“你见到什么了？”</p><p>“没什么，没什么，我们先去讨论一下怎么‘自我催眠’吧。”</p><p>杨帝看着钓鱼佬那明显在刻意回避的模样。</p><p>知道他看到的东西，必定极其恐怖，给他造成了极大的精神冲击。</p><p>杨帝：“行吧，这‘自我催眠’用于召唤一事，确实得好好准备。我估算了一下，要准备妥当大概需要十天十夜。你十天后再来找我。”</p><p>“十天？太久……”</p><p>“这不是义乌小商摊，不能砍价。十天就是十天，不能再短了。”杨帝坚持。</p><p>钓鱼佬忙不迭地点头：“好，好……那就十天，十天后我再过来？”</p><p>“没错，这期间内，你避避风头先别来了，毕竟刚被拉下了水。”</p><p>也许是钓鱼佬开始以杨帝为首，也许他被门缝后看到的东西给吓到。也许，他是考虑到杨帝能一拳打爆不锈钢防盗门。</p><p>综合种种原因，中年男人退让了。。</p><p>钓鱼佬默默地点点头，不再多说什么，回到一楼，收拾自己散落在一旁的东西。</p><p>然后，他拍了拍杨帝的肩膀，声音干涩地说道：“那我就先走了，十天后准时过来。你……你自己也小心点。”</p><p>杨帝看着钓鱼佬，认真地点点头。</p><p>“放心吧，我会注意的。你回去后也好好调整一下，这十天里，尽量别再接触这类可能有危险的事。”</p><p>杨帝掏出一张纸和中性笔，在纸上哗哗地写下几行字。</p><p>“还有，回来的时候帮忙买几样物品，我们要初步对黑水潭子做测试。”</p><p>物品清单：一百根高强度钓鱼线，五十只牛蛙，五十个GPS定位仪。</p><p>“注意牛蛙要活的。足够体型的生物死尸，我自有办法。”杨帝强调。</p><p>钓鱼佬疑惑，但还是答应了下来。</p><p>二人分开。</p><p>杨帝转身，看一眼楼梯井上方。</p><p>那只苍白的手，又有些害羞地缩了回去。</p><p>“真是胆小，人吓鬼。”他笑着摇摇头，上了楼，回到自己的房间。</p><p>这里虽然简陋，但被他收拾得井井有条，在这杂乱荒芜的烂尾楼中，是一方小小净土。</p><p>杨帝从某间空置的房间拆下门，扛回自己的房间，用物理手段强行安装好。</p><p>“可以，这下就能挡风了。”</p><p>这门虽有些破旧，但好在还算完整。</p><p>杨帝盘腿坐于壁炉前，五心向天。</p><p>入梦准备工作。</p><p>……</p><p>通过梦境这一途径，能够尽可能对自己10%的潜意识动手脚。</p><p>从而达到更好的催眠效果。</p><p>例如，在梦境之中，构建出一个对召唤极为有利的场景，让自己的潜意识完全沉浸其中，相信召唤必然会成功。</p><p>如此一来，当从梦境醒来、甚至一边睡觉一边进行召唤时，那种笃定的信念感，或许能让成功率大幅提升。</p><p>但杨帝以前，从未对自己的潜意识动这么多手脚。</p><p>他的梦境，向来是用于学习知识；以及模拟出各种场景，锻炼耐杀性。</p><p>从没尝试过，用梦境营造某种氛围从而催眠自己。</p><p>因为这样子自我催眠，他担忧分不清梦境和现实。</p><p>他寻思，既然要进行这种特殊的催眠，必须得有个能判定梦境与现实的物件才行。</p><p>比如陀螺，比如骰子，比如象棋。</p><p>对普通人类而言，潜意识无法完全复制现实中的所有细节、物理规则。</p><p>因此，灌铅的骰子在梦境中会像正常的骰子一样随机出现各种点数，特制的陀螺会在梦中永不停止旋转。</p><p>这就能够区分现实和梦境了。</p><p>但是，这些方法对杨帝不适用。</p><p>因为，他能够“现实扭曲”。</p><p>目前，杨帝对自己能力的把控还不算太好。</p><p>如果在现实里看到一个陀螺，心里想到“你不要停下来啊”，它就有可能一直转个不停，真停不下来了！</p><p>杨帝有个更好的图腾，以区分梦境与现实。</p><p>他将一块镜片握在手中，仔细端详。</p><p>镜面反射出的不是他的脸，而是后脑勺。</p><p>他已经尝试过，这块镜片中的“灵”看起来和普通镜子差不多，但总给人一种古怪。</p><p>似乎，是事物本源的某种信息被“篡改”过。</p><p>但杨帝现在无法理解，这种现象是怎么生成的。</p><p>就好比树上一串香蕉，基因大体相同。</p><p>但偏偏其中一根香蕉，莫名其妙发生变异，变成金色肌肉大只佬，于过去横击未来敌，镇压混沌，暴打邪神，独断万古，岁月长河再无变异香蕉身影。</p><p>它虽是只香蕉，但已不是普通的香蕉。</p><p>同理，这镜子看起来正常，但其实它不是正常的镜子。</p><p>总之，这块镜片的物理规律，杨帝还没有能力模仿、扭曲、实现。</p><p>所以在他看来，这镜片无疑是绝佳的区分梦境与现实的“图腾”。</p><p>杨帝再次让自己全身心放松，缓缓沉入梦境之中。</p><p>呼吸逐渐变得均匀而深沉，与周围风声与柴火噼啪声融为一体。</p><p>火焰映照下，身影被拉长，投射在身后的墙壁上，与这烂尾楼融为一体。</p><p>思绪如同一叶扁舟，飘荡在一片无尽的黑暗海洋之上。</p><p>渐渐地，黑暗中浮现出一些模糊的光影。</p><p>自己置身于某城市某写字楼天台。</p><p>是楼顶跑酷挑战+砖头使用练习，上次梦境的延续。</p><p>杨帝想起来了，上回的梦，他还没有通关，然后被“墙中之鼠”和“门窗堵塞者”吵醒，所以很生气地用撬棍和砖头单刷烂尾楼。</p><p>此刻，他四周是密密麻麻的丧尸，它们嘶吼着，追逐着他的每一个动作。</p><p>“先通关了吧……”</p><p>他深吸一口气，双腿发力，以惊人的百米六秒速度在楼顶之间飞跃、攀爬！</p><p>身形如山里灵活的猢狲，穿梭在狭窄的边缘和摇摇欲坠的天台之间！</p><p>“嗷嗷嗷——吼！”</p><p>丧尸群在身后追杀。</p><p>这是种将“肾上腺素激增”，“蚓状肌强化”、“运动控制强化”、“合成代谢增强”、“肽合成增强”、“颅骨象皮症”、“骨骼结构异化”拉满了的满级丧尸！</p><p>杨帝就是通过构建这种试炼场景，磨炼身体各项技能，刷数值。</p><p>他一边保持着高速移动，一边眼观六路，手不离砖。</p><p>有丧尸靠近，他便抄起手边的砖头，以0.7马赫的初速猛力掷出！</p><p>砖头在空中划过一道直线，精准击中目标！</p><p>「射击+1」</p><p>但令人沮丧的是，那丧尸只停滞了半秒，随后它便又摇摇晃晃地站稳，继续追逐。</p><p>百米六秒看似很快，其实也就时速60公里。</p><p>杨帝还是被追上，抓到了。</p><p>那是最后一只丧尸，它猛地扑上来，尖锐的爪子划破了杨帝的上衣，胸前被划了道黄瓜大小的血痕，触目惊心。</p><p>他回首掏，一砖头全力乎去，彻底将最后一只丧尸的脑袋砸成烂西瓜。</p><p>「锐器抗性+1」「战斗+1」</p><p>但没有触发「免疫 +1」或「生化 +1」。</p><p>这就是梦境修炼法的限制——杨帝只能刷他“经验范畴之内”的属性。</p>
