# 终极答案

<p>圣光教廷，第一席红衣主教。</p><p>他身着华丽而庄重的红色长袍，那长袍上绣着的金色符文闪烁光芒。</p><p>头戴镶嵌着巨大红宝石的主教冠，宝石散发炽热光辉，与他身上那股凌冽的气息相互呼应。</p><p>在他身后，还跟着数十个气息同样恐怖的术士与圣骑士。</p><p>术士们身着金白色法袍，手执法杖。</p><p>圣骑士们则身披闪耀着神圣光辉的重甲，手持巨大的十字剑。</p><p>每个都有过人之处，每个都有独门绝招，对圣光的虔诚、对灵能的运用，更是技惊四座！</p><p>秘密武器更给瑞弗维尔意外惊吓——</p><p>第一席红衣主教的手指上，戴了三枚力量之戒。</p><p>力量之戒曾是索伦魔王用于控制整个中土大陆最顶尖力量的秘密武器。</p><p>至尊魔戒被摧毁后，力量之戒终于摆脱索伦的控制，正式蜕变为脍炙人手的顶尖法宝。</p><p>人类分得了九枚力量之戒。</p><p>而眼前的红衣主教，独占三枚？！</p><p>难以想象，眼前这个人类，在独占三枚戒指后，力量会膨胀到何等地步……</p><p>灵能轿厢在轨道上剧烈颤抖，似乎也感受到了前方那股强大力量带来的压迫。</p><p>但铁轨与轿厢没有自己的意志。尽管抗拒，它仍然无可避免地驶向终点，驶向教廷追兵的包围圈内。</p><p>瑞弗维尔脸色煞白，双手紧紧抓住轿厢，心中又双叒叕涌起绝望。</p><p>“圣他娘的光啊……”</p><p>面对如此强大的阵容，他们几乎没有任何胜算。</p><p>而此时的杨帝，依旧沉浸在自己的幻想世界里，对眼前的危机浑然不觉，还在傻笑着嘟囔着和柑橘味星星跳舞的话。</p><p>术士们开始低声吟唱咒语，符文在他们身边浮现，汇聚成各种强大法术的雏形。</p><p>圣骑士们则整齐地向前迈进了一步，手中的十字剑闪耀着更加强烈的神圣光芒。</p><p>而在众星拱月之中。</p><p>立于众人中央的第一席红衣主教，缓缓抬起手。</p><p>三枚力量之戒闪烁起炫幻的光辉。</p><p>“亵渎者，接受裁决。”他轻轻一挥。</p><p>瑞弗维尔绝望：“不是，我到底亵渎了什么东西？为什么你们个个都不跟我说清楚啊！”</p><p>“很重要吗？”</p><p>“非常重要，这个问题困惑我好几天了，为什么你们见面就说我是亵渎者。”</p><p>“……莫须有。”</p><p>无形的力量朝着灵能轿厢压去！</p><p>轿厢瞬间像是被一只无形的巨手握住，轨道扭曲变形，速度骤减。</p><p>很快，轿厢即将停下。</p><p>在此之前，瑞弗维尔还一直侥幸地护着杨帝，希望他能在关键时候、剧情高潮点之时，突然醒过来天降战神大杀四方……</p><p>但它只存在于小说中，只存在于野史中。</p><p>瑞弗维尔咬了咬牙，心中明白此刻绝不能指望杨帝，不能坐以待毙。</p><p>他迅速将手伸进怀中，摸到了那个一直舍不得用的瞳孔形状的石头雕塑。</p><p>原初之眼雕像。</p><p>他深知这个东西可能存在巨大的风险，但如今已别无选择。</p><p>虽然不知道为何教廷的人看到这个雕像，反应会如此之大。而自己，反而却啥事都没。</p><p>但瑞弗维尔不管了。</p><p>石头眼珠雕像被他掏出来：“狗带吧教廷的鹰犬！！”</p><p>第一席红衣主教还有其他教廷追兵，先是愣了半分钟。</p><p>他们眼神中满是惊恐与难以置信，死死地盯着瑞弗维尔手中的原初之眼雕像。</p><p>接下来，集体癫狂，精神错乱。</p><p>红衣主教双手抱头，发出狂喜的嘶吼，华丽的长袍在剧烈的颤抖中撕裂，他原本整齐的头发变得杂乱无章。</p><p>术士原本还在吟唱的咒语，变成了含混不清的尖叫，圣骑士丢下十字剑，神圣的重甲也无法阻挡他们遍地打滚。</p><p>直到现在，都还在瑞弗维尔预料之中。</p><p>但下一刻，新的情况出现了……</p><p>瑞弗维尔无法理解发生了什么……</p><p>只见那群教廷追兵，他们的物质身躯开始扭曲，像是被一双无形大手肆意揉捏。</p><p>皮肉翻转，骨骼错位。</p><p>发出令人毛骨悚然的“咔嚓”声。</p><p>瑞弗维尔扛着杨帝奔跑，几乎喘不过气。</p><p>他扭头，看见他们的身体开始相互靠近，逐渐融为一体。</p><p>物理意义上的融为一体。</p><p>空气中弥漫着令人作呕的气息。</p><p>最终……他们融合成一个散发着10环强度魔力波动的糅合怪物。</p><p>它仿佛是一场噩梦具象化的产物。</p><p>无数条手臂、腿和扭曲的躯干相互缠绕，层层叠叠地堆积在一起，分不清彼此。</p><p>头颅们或张大嘴巴发出无声的惨叫，或双眼圆睁露出惊恐的神情，他们的表情永远定格在了癫狂与混乱的那一刻。</p><p>然而，更令人作呕的是……</p><p>就是这样极尽亵渎扭曲的怪物，也能使用圣光。</p><p>而且圣光法术强度，远胜第一席红衣主教！</p><p>周围空气，都被它神圣而强大的力量压制。</p><p>它周身放出淡淡光辉，金色烈芒如潮水般向四周蔓延，将周围的黑暗驱散殆尽。</p><p>这光芒中蕴含着一种让人无法抗拒的威严，仿佛来自至高无上的神圣意志。</p><p>怪物张开由无数扭曲肢体拼凑而成的“大口”，一道水桶粗的金色光柱，从中喷射而出，直直地朝着瑞弗维尔和杨帝射去。</p><p>那光柱所过之处，空气被灼烧成一片虚无，地面上留下一道深深的焦痕。</p><p>“啊啊啊啊————！！！”</p><p>那个由教廷术士、圣骑士和红衣主教组合而成的东西，每一个暴露在外的头颅，都在歇斯底里地尖叫！欣喜若狂的啸叫！</p><p>为首的红衣主教头颅，声音更是尖细。</p><p>瑞弗维尔从没想过，这么一个瘦弱的男人，声音比女高音歌唱家还尖。</p><p>杨帝被他扛在肩上，哈哈大笑起来：“太好了是月球领主，我们死定啦！”</p><p>瑞弗维尔完全不明白，杨帝在说些什么莫名其妙的话，他饱读历史也没听说过“月球领主”。</p><p>但没等他发问，眼前那恐怖的景象再次发生变化……</p><p>极度炽烈的圣光发霉腐烂了。</p><p>奇行种所发出的圣光，开始长出黑色霉块。</p><p>原本纯净的金色光线，像是被某种邪恶力量侵蚀，表面逐渐浮现出一块块斑点。</p><p>斑点扩散，“光”裂开来了，露出后面深邃的黑暗虚无。</p><p>那黑暗，似是深渊，现于理性与逻辑边缘的，横亘于狂乱与秩序分野的，无底深渊。</p><p>刺眼光亮中央裂开的深渊，散发着令人心悸的气息，似乎要将世间万物都吞噬进去。</p><p>瑞弗维尔被深邃的黑暗抓住了眼球。</p><p>他的理智，甚至是他的感性，都在尖叫着告诉他必须立刻离开！！离开离开离开！！！</p><p>但他的身体动不了。</p><p>瑞弗维尔不明白，自己知道即将面对的，是世间大恐怖。可为什么，就是迈不开腿呢？</p><p>仿佛……他意志最深处，潜藏着某种渴求。</p><p>对世界之真相，宇宙之答案，生命之意义，那种最原始、最本能的探寻欲望，让他的双脚像是被钉在了地上。</p><p>万物，不局限于生命，都渴望得到答案，朝闻道，夕死可矣。</p><p>尽管理智在疯狂地警告他危险至极，可内心深处的这股冲动，却如同磁石牵引着他的目光。</p><p>无法移开视线。瑞弗维尔直直地盯着那深渊之中。</p><p>深渊之中的那只眼睛，瑞弗维尔能够从中窥探到万物，看见万物的过去，现在与未来任意一刻，看见万类生灵做出每一个抉择时，世界所走向的分岔路……</p><p>他的灵魂几乎要被吸入进去了。</p><p>但随即，瑞弗维尔双眼被遮住。</p><p>杨帝的声音：“别看。”</p><p>看来他恢复神智了。</p>
