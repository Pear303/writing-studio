# 绑定诅咒

<p>“杨老帝，被我揭穿‘你有女朋友’这个秘密，你就一直在冒冷汗，咋回事儿嘞？”</p><p>张明远一边喝冰可乐，一边问着。</p><p>杨帝摇摇头：“没事儿，我就是有点热，冒汗，所以想去图书馆旁边的湖游个泳。”</p><p>“你又是什么湖人队……”</p><p>杨帝把门带上。走后许久，一直盯着电脑屏幕的张明远才反应过来。</p><p>“等等杨老帝！你说什么去湖里游泳？！那破池子连癞蛤蟆都会淹死！”</p><p>张明远回头，宿舍已经空空如也。</p><p>他叹息：“老帝啊老帝……我性取向正常，你和女友幽会，我又不会吃醋，为何找如此蹩脚的理由欺骗你的挚友？”</p><p>……</p><p>图书馆旁的湖泊，池水浑浊，平静无波。</p><p>这里盛产外来入侵物种水葫芦，它们密密麻麻铺满大片湖面，层层叠叠，翠绿叶片簇拥在一起，犹如一块望不到尽头的巨型绒毯。</p><p>似乎能吞噬一切秘密。</p><p>湖水边缘的岩壁上，附满了粉色的椭球状肉瘤，层层堆叠、彼此交缠，宛如无数肿胀的眼球从湖底深处盲目凝视着这个世界。</p><p>好叭，那些粉色的只是福寿螺卵。</p><p>福寿螺也是外来入侵物种，非常猖狂。</p><p>它们的主要罪证是体内寄生虫又多，而且肉质不好吃，产的卵还特别恶心。</p><p>但对于直视过不可名状之物的杨帝来说，这种程度的“恶心”算不了什么。</p><p>不过也侧面证明，这池水确实很脏。</p><p>在这破池子游泳，连癞蛤蟆都会淹死。</p><p>前几个星期，稷海理工的生活污水管道爆掉过一段时间，很久之后才被人发现。</p><p>那时已经不知有多少吨污水流进湖里了。</p><p>这湖本来就不大，只有一条小溪流注入，补充不了多少活水。</p><p>施工队还得等上一段时间，才能来抽水清污，这段空档里，小水湖已经变成纳垢温床。</p><p>杨帝悄悄来到湖边。</p><p>环顾四周，确认无人注意，深吸一口气，将所有不安都沉入湖底。</p><p>“永别了，耶罗符印。”</p><p>他模仿《指环王》中销毁魔戒的姿势。</p><p>如果弗罗多·巴金斯在最后一刻抵抗住了至尊魔戒的精神污染，那么他毁掉魔戒的姿势，应该和杨帝现在一模一样。</p><p>此刻，杨帝将耶罗符印抡圆了，用力将耶罗符印掷向湖面！</p><p>它划出一道诡异的弧线，“咚”一声扎进幽深的水潭，最终消失在幽深的湖水中，只留下一圈圈涟漪，缓缓扩散。</p><p>但扔出去那一刻，杨帝又有些后悔。</p><p>“这湖迟早要抽水清污的。我把它扔下去，到时被清污的工人捡到怎么办？岂不就把无辜之人拖进来了？”</p><p>他方才一心只想着摆脱这符印，考虑不够周全。</p><p>他不喜欢做损人利己的事情，特别是在自己的“耐杀性”比普通人高许多的情况下。</p><p>但决定已做出，覆水难收。</p><p>只能希望池底的淤泥足够厚，这块铁饼的重量也足够重，能够深深埋进泥地，不那么轻易被人发现。</p><p>一切就这么结束了，吧。</p><p>回到宿舍，杨帝的心依旧难以平复，不时地摸向裤袋，确认那东西是否真的已不复存在。</p><p>“这几天发生的事，真是如梦亦如幻……”</p><p>他手指伸近裤袋，触碰到硬物。</p><p>一股寒意瞬间贯穿全身。</p><p>还是那种带着潮湿和阴冷的寒意，夹杂着铜的锈味。</p><p>“怎么可能？！”杨帝难以置信地低语，仿佛听见命运的嘲笑。</p><p>这又不是游戏，尤其不是Minecraft，怎么还会有“绑定诅咒”附魔效果……</p><p>这次，杨帝换了策略。</p><p>他特意穿了运动短裤——没有口袋的裤子总该安全了，“铁饼”总不可能凭空出现在没口袋的裤子里吧？</p><p>杨帝隔了短短五分钟，便第二次去往湖边。</p><p>午后的天空像蒙了层灰纱，风里漂浮着水葫芦腐烂的腥气。</p><p>拐过某栋教学楼时，听见头顶传来玻璃爆裂的脆响。</p><p>“哪个刁民要害朕？！”本能让他猛地侧身，但后脑勺仍然结结实实的挨了一发砖头。</p><p>还特么是被尖尖的棱角给砸到的，+300%暴击伤害！</p><p>“草，一种植……”</p><p>杨帝直挺挺倒在地上，五官朝地，砖块在脚边碎成两半。</p><p>「钝器抗性+1+1+2+3+5+8」</p><p>「锐器抗性+1+1+2+3+5+8+13」</p><p>致死性伤害，这砖头是冲着杀他来的！</p><p>在地上趴了差不多有十分钟，杨帝才摇摇晃晃地站起身，鲜血顺着指缝缓缓渗出。</p><p>他捂着后脑勺，抬头望向那栋宿舍楼。</p><p>六楼某间寝室的窗户大开着，窗帘被风掀起，露出黑洞洞的室内。</p><p>杨帝直觉却总觉得，里边有只眼睛在窥视着他的一举一动。</p><p>但四周并没有行人。没人也好，没人注意到他挨了这么一发还能活着。</p><p>“厄运，开始了么……”</p><p>杨帝摸了摸渗血的头皮，指腹上的血迹以肉眼可见的速度凝结。</p><p>身体正在急速修复砖头带来的损伤，然后超量代偿、提升皮肉的防御力。</p><p>他捂着渗血的额头继续往前走，腥甜的液体顺着鬓角流进衣领。</p><p>耶罗符印始终握在手心。</p><p>还是说，因为自己试图扔掉这块符印，所以耶罗大仙不知在宇宙中哪个角落投来一瞥，随手一击打出砖头级的恐怖伤害。然后像个老头子那样，降下渺渺梵音：“耶罗符印乃吾宝，岂容尔等小辈亵渎？此印与尔神魂相系，若敢再弃，吾必让尔魂飞魄散，永世不得轮回！”</p><p>杨帝把稀奇古怪的想法甩出脑海。</p><p>鉴定为玄幻小说看多了。</p><p>他第二次站在湖边，夕阳正把水面染成锈红色，水葫芦在暮色中泛着诡异的油光。</p><p>他将符印放在一块突出的岩石上。</p><p>然后退后几步，狠狠地一脚踢去！看着它翻滚着穿透水葫芦层，落入水中。</p><p>“不错，高低是个三分球，或者三分饼。”</p><p>这一脚直接将耶罗符印踹飞十几米远，要知道，跳远世界纪录也才8.95米。</p><p>但命运似乎并不打算轻易放过他。</p><p>杨帝哼着轻快的小曲，转身离去之时——脚底传来熟悉的冰凉触感。</p><p>他后背瞬间被冷汗浸透。</p><p>他踹“铁饼”用的是右脚，而冰凉触感传来的地方，也是右脚脚底。</p><p>体感告诉他，一块半巴掌大小的金属片，透过鞋底，传递着不属于这个世界的寒意，直刺骨髓。</p><p>他敏锐的触觉能感受到，脚底铁饼是规整的正圆形，上面有漩涡状浮雕图纹。</p><p>没错，还是那枚“耶罗符印”……</p><p>裤子没口袋，就直接出现在鞋子里吗……</p><p>四周静悄悄的，只有偶尔传来的鸟鸣和远处教学楼的隐约人声。</p><p>似乎整个世界都在这一刻与他保持了距离，附上了一层透明的膜，静观这场闹剧。</p><p>杨帝脱下鞋子，拿出了符印。</p><p>这玩意，是真的有“绑定诅咒”……</p>
