# 复健计划·上

<p>星海骤亮，守望者舰队的舰群如蜂群分舞。</p><p>鱼尊阿巴知道，守望者文明要出手了。</p><p>守望者舰队中，其中一艘看起来平平无奇的战舰，其舰体表面的“色核力装甲”竟如活物般蠕动剥离，化作无数流光模块。</p><p>“绝对模块化构造”，也是守望者文明的一项关键技术。</p><p>每艘战舰，每个个体，乃至每个微波炉、面包机，本身都是由皮米（10^-12米）级别的超微小子个体构成。</p><p>这甚至不能称作“纳米机器”，因为1皮米便等于1000纳米。</p><p>用“纳米”形容，还是太大了。</p><p>这些泛着金属冷芒的构件在空中飞速拼接，虽然真空不能传声，但咔嚓声仍然密集如暴雨打叶。</p><p>不过数息间，一尊形似巨蚌/蛤蜊/扇贝/花甲的机甲，便悬停在鱼尊阿巴身前。</p><p>这机甲通体灰扑扑的，棱角分明得像块被啃过的陨石，蚌壳状的舱体张合间漏出幽蓝电弧。</p><p>但在鱼尊眼中，这尊丑陋的巨蚌机甲，其能量读数同样很高！</p><p>且对她的灵能极度亲和。</p><p>鱼尊有预感，只要自己去驾驶它，她的战斗力将不只是简单的数值相加，而是成倍暴涨！</p><p>换言之，这个机甲简直是为鱼尊她量身定制的超级兵器。</p><p>真可惜，她是掌握个体伟力的太乙真仙，守望者文明则是登临物质宇宙巅峰的超级文明，二者若是合作，本来有大大的优势互补。</p><p>但为了争夺大罗道果，不得不兵刃相向。</p><p>而现在，横空出世一个杨帝，给了他们能够合作的机会，倒也算是件幸事了。</p><p>满分100，鱼尊能给这身机甲能打60，因为它既强大，又合身。</p><p>然而……强大归强大，合身归合身，就是太丑了。</p><p>说它像个蚌，都算是抬举了。</p><p>“铁罐头，我从来没有对你下死手，你却送我一副铁棺材？！”</p><p>鱼尊心情复杂，盯着蚌壳舱体边缘参差的“齿状”结构，回想到亿年前，深海里那些被珊瑚啃噬的破壳。</p><p>「机不可失，事不宜迟。」</p><p>机甲内部传来电子音的嘶吼，蚌壳舱体“砰”地弹开，露出黏着生物凝胶的鲈鱼凹槽。</p><p>「依据当前局势分析，若你继续停留原地，极有可能出现这样的结果：你的鱼鳍会被那怪物当作牙签使用。」</p><p>「这种推断并非毫无根据，从怪物此前的行为模式以及对你展现出的攻击性来看，这种可能性极大。」</p><p>「不过我需要提前公开声明：我并没有请求你进入我的『民用水产养殖辅助装置』，如果你要强行闯入，我也难以阻止。」</p><p>守望者舰队冷静地说道。</p><p>虽然没有明确让鱼尊驾驶机甲。</p><p>但话里话外，弦外之音，都是这个意思。</p><p>鱼尊阿巴甩动尾鳍，激起相当于黑洞相撞产生的时空涟漪。</p><p>鲈鱼眼瞳中，映着那灰扑扑的机甲外壳。</p><p>她发出一串气泡状的嗤笑：“好个守望者文明，不愧是能把‘绝对中立’态度刻进种族基因的存在。用整支舰队的皮米模块拼装机甲，再把我这个‘第三方’推到前线当肉盾——既没违背你们‘不直接介入文明冲突’的准则，又能借我的鳞甲试试那怪物的拳头硬度，算盘珠子都快崩到星河对岸了吧？”</p><p>机甲内部的电子音高频震颤：</p><p>「严重警告！你正在传播虚假信息！」</p><p>「第一，根据《守望者文明造物归属公约》，这台编号β-2333的『民用水产养殖辅助装置』刚完成流水线组装，是你在强行违背守望者文明造物归属公约，强行霸占该民用水产养殖辅助装置的神经接口。」</p><p>「第二，‘刻进种族基因’用语不妥。自本族诞生以来，便属于硅基智械集群，‘基因’这一碳基生物概念对我们不适用。」</p><p>守望者开始打太极转移话题。</p><p>鱼尊冷笑：“我若强行驾驶你的机甲，你不阻止我？”</p><p>「首先，并非‘机甲’，而是刚刚流水线组装完成的‘民用水产养殖辅助装置’，守望者文明在主观上并不会将之用于战争用途。」</p><p>「其次，守望者文明前线舰队已丧失99.99%的战术机动能力。根据《文明冲突自我保护条例》第42条，我们有权保持战略静默。」</p><p>杨帝最初现身时，因为有“起床气”，所以将守望者文明的舰队一巴掌打成了抽象几何雕塑。</p><p>他们原本就比较丑的战舰，被扭曲成麻花、油条、葱油卷形状。</p><p>现在，守望者以此为由，拒绝直接参战。</p><p>“丧失机动能力？！你们的皮米模块难杀得很，塞进中子星内部考两百年，都能强行重构战舰！现在告诉我，你的船壳仅仅被捏成麻花，就没法参战了！”</p><p>鱼尊和守望者文明对战如此之久，自然明白对方的底细。</p><p>以守望者的科技水平，杨帝“起床”时的随手一击，对他们舰队造成的伤害几乎为零。</p><p>她恼极了。</p><p>堂堂宇宙级文明，搞这种方式脱战，实在是卑鄙无耻且下贱下流生孩子没皮炎的。</p><p>但在仅仅数十亿公里的不远处。</p><p>那个“数值怪”已开始蠢蠢欲动。</p><p>“喂，你们谈好没？谈好我就开揍了。”</p><p>杨帝大梦一场，睡醒一觉，莫名亢奋，已经跃跃欲试，试图找个大道磨灭一下。</p><p>当然也可以退而求其次——找一个强者打上一架。</p><p>一方面是为了复健。毕竟睡了这么久，筋骨都快和坍缩的黑矮星一样僵硬了。</p><p>另一方面，则是为了测试自己的实战能力。</p><p>肉身抗性暴涨，所带来的效果，绝不仅仅只是防御力增强。</p><p>当肉身能硬扛宇宙级灾害时时，攻击力也能和防御力一同暴涨，核心逻辑在于——</p><p>能量传导效率与物理阈值的质变突破。</p><p>譬如说，当他能承受超新星爆发的肉身，其肌肉纤维、骨骼密度乃至细胞结构，都已超越常规物质形态。</p><p>这种躯体挥拳时，拳锋裹挟的动能足以将恒星如捏爆气球般击爆！</p><p>再举个例子，譬如一副用钢铁铸成的身躯，和一具用豆腐组成的身体。</p><p>“豆腐”本身脆弱的防御阈值，注定了其杀伤力的天花板。</p><p>而“钢铁之躯”的战斗力，绝对远超先天豆腐圣体。</p><p>除此之外，杨帝还略微学习了数十亿种1-15环的法术。</p><p>不过，对他而言，法术只能算是身外之物。</p><p>君子不假外物——意思是，君子只靠自身的肌肉力量轰爆敌人，而不屑于用武器或者法术。</p><p>灵能法术对杨帝最大的效果，就是“快速治愈”。</p><p>每次受到伤害，他都会增加防御力和血量上限。</p><p>“血量上限”并不等同于“血量”。血量上限是指水池的容积，而血量是指池水的多少。</p><p>治愈法术，能够快速将他的“血量”补满。</p><p>杀伤类的法术，反倒可有可无。</p><p>杨帝正思索着，一道耀紫色光束擦着他额头射过。</p><p>留下一条极浅的血痕。</p><p>“吼！神也会流血！”鱼尊一边说着中二台词，一边冲杀上来。</p><p>她驾驶着守望者文明现场制造的“民用水产养殖辅助装置”，气势暴涨200%！</p>
