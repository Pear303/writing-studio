# 高魔世界观的战斗

<p>不好！破不了防。当下也来不及多想。</p><p>杨帝一个箭步，扛起瑞弗维尔就跑！</p><p>然而，他先前“一砖头”的行为给自己上了个嘲讽。</p><p>此刻，原初之眼的仇恨全部在杨帝身上。</p><p>奇行种受原初之眼操控，对杨帝穷追不舍。</p><p>它那由众多肢体糅合而成的怪异身躯快速移动着，所经之处地面纷纷龟裂。</p><p>无数道金色的圣光射线如密集的弹幕，从它身上各处射出，朝着杨帝的方向疯狂倾泻！</p><p>杨帝扛着瑞弗维尔，身形在枪林弹雨般的圣光射线中左躲右闪，比开战斗机在不列颠上空狗斗还刺激。</p><p>“这玩意怎么戾气这么大！”</p><p>杨帝将脊椎扭成麻花，险之又险躲过几发灼热的射线。</p><p>他试图躲在一些障碍物，比如巨石和树木后面，但往往下一刻，那怪物就会释放出灼热的射线，打爆障碍物！</p><p>碎石和木屑飞溅，有不少擦过杨帝身体，留下淤青和血痕。</p><p>他自己受伤不要紧，但“导游”瑞弗维尔还是尽量不要死比较好，毕竟他还有很多“常识”尚未学会。</p><p>杨帝大脑飞速运转，思考着脱身之计。</p><p>这么追逐下去，对瑞弗维尔不利！如果无法破局，导游只有死路一条。</p><p>但下一刻，破局了。</p><p>他们的注意力，都同时被远处一声巨响吸引。</p><p>“轰隆——隆隆！！”</p><p>火山顶部爆发巨响，一道冲天火光伴随着滚滚浓烟升腾而起！</p><p>冲击波以火山为中心向四周扩散，周围的空气仿佛被搅动，形成了巨大的气流漩涡。</p><p>杨帝和原初之眼控制的奇行种，都不由自主停下动作，转头望向火山顶部的爆炸。</p><p>一朵蘑菇云缓缓成型。</p><p>他是地球人，对此很熟悉——</p><p>“卧槽，核爆！？或是温压弹？！”</p><p>然后，在爆焰和浓烟中，一个人影……逐渐浮现清晰。</p><p>那厮隔着两公里，法杖顶端光芒大盛。</p><p>瞬间，一个迸发黑光的巨大的术阵出现在精灵身前，符文闪烁，魔力如山崩海啸暴动！</p><p>一股寒凉之意，从杨帝脚底直冲天灵盖。</p><p>跑！！快跑！！！</p><p>眼耳鼻舌身意，色香声味触法，六感六识疯狂警报！</p><p>杨帝一手扛瑞弗维尔，开始千米冲刺。</p><p>甚至这一次，他的“人体附魔”在强大压力威逼下取得第一次成功——速度I级附魔！</p><p>平地疾跑秒速22米！相当于时速80公里，已经可以上高速了。</p><p>刚跑出八九十米，火山顶部，那座黑色术阵绽放了。</p><p>刹那，一道拖着长长尾焰的黑色“彗星”，朝奇行种直线轰去——</p><p>“彗星”所过之处，空间仿佛扭曲，空气被急速压缩，发出尖锐呼啸！！</p><p>那奇行种就是个愣头青。</p><p>虽然也感受到了这一击的强大威力，虽然那只位于喉咙深处的眼睛也骤然收缩。</p><p>但它不躲。像七岁小孩一样。</p><p>初生牛犊不怕虎，初生小孩头如铁。</p><p>它那身躯上，爆发出更为浓烈的圣光，在身前凝聚成层层叠叠十几面金光闪耀的圣光护盾！</p><p>杨帝估算着距离和时间，在4.25秒后一个闪身，带着瑞弗维尔冲向一颗歪脖子老树。</p><p>他将呼呼大睡的瑞弗维尔，扔进只有一人深的树洞。</p><p>思索数十毫秒，用自己的身体堵住洞口，护住洞内的瑞弗维尔，再往自己身上套灵能护盾。</p><p>“轰——轰——轰！！！”</p><p>应该是那道拖着尾焰的黑色“彗星”，与奇行种的十几面圣光护盾碰撞了。</p><p>强大的气浪夹杂着炽热的高温，如同一头狂怒的猛兽，朝着杨帝和老树猛扑过来。</p><p>杨帝只感觉，一股无法抵御的力量重重撞击在他背上，仿佛有无数根针在刺皮肤，火辣辣地疼。</p><p>他咬着牙，护住瑞弗维尔。</p><p>「耐热+1+1+2+3+5+8+13」</p><p>「耐辐射+1+1+2+3+5+8」</p><p>他们距离爆心位置约200米，还有一棵歪脖子大树抵挡冲击波与爆焰，还有自己身上的十几层灵能护盾。</p><p>即使如此，杨帝仍瞬间受到足以重创他的伤害。</p><p>这个威力……杨帝估计，超过一般温压弹，装药量相当于约40吨TNT当量。</p><p>没了过不多知久。</p><p>杨帝已踏入1/4步暴毙，但此刻，身后浓烟中又隐约传来低沉的咆哮。</p><p>那咆哮虽听起来奄奄一息。</p><p>但……那奇行种还活着。</p><p>承受了这种程度的爆炸，居然还能活着，这至少是金丹期的碳基大能吧？</p><p>待这冲击过去，杨帝缓缓抬起头，周围烟尘弥漫，一片狼藉。</p><p>奇行种所在的位置被浓烟笼罩，看不清状况，只能听见隐隐约约的咆哮。</p><p>然后在烟尘和硝烟味之中，杨帝闻到了一种清香——柑橘的淡淡香气。</p><p>虽然烟尘没散去，但他能感到一个凌厉的身影从天而降。</p><p>一脚踹飞奇行种！</p><p>沉闷的撞击声传来，伴随着奇行种痛苦的嘶吼，那声音在烟尘中回荡，显得格外惊悚。</p><p>背后的剧痛与解放10%潜意识相比，根本不足一提，杨帝只想努力想看清烟尘中的情况。</p><p>“人类！趴下！！”</p><p>一个清灵的声音传出，杨帝几乎是下意识地抱紧瑞弗维尔，整个人趴在地上。</p><p>趴下瞬间，又一道强大的能量波动从烟尘中爆发开来！</p><p>“轰轰轰轰！！”又是震耳欲聋的爆炸。</p><p>这次的爆炸，没有之前猛烈，但连绵不绝犹如潮水，炸了三四分钟毫无停歇的意思！</p><p>滚滚热浪如同汹涌的潮水般向四周席卷，地面都在这股力量下剧烈颤抖。</p><p>原本就已经摇摇欲坠的歪脖子老树，在这股冲击力下彻底折断。</p><p>树的上半部分被气浪卷到半空，消失不见。</p><p>杨帝只觉置身于一场末日风暴之中，强大的气压、爆焰与冲击波，试图将他和瑞弗维尔一起掀飞。</p><p>幸好歪脖子树的下半部分比较稳固，树根扎得牢固。</p><p>他们置身于树后，由树根抵挡了90%伤害，而杨帝又为瑞弗维尔抵挡了80%的伤害。</p><p>过了不知多久，咆哮声渐渐平息了。</p><p>杨帝感觉心脏都要从胸腔里蹦出来了。</p><p>他缓缓抬头，从歪脖子树根往外看去。</p><p>爆炸产生的强光穿透烟尘，让杨帝眼前一片白茫茫，什么都看不见。</p><p>过了好一会儿，强光逐渐消散，他才勉强恢复了一些视力。</p><p>周围的一切，都变得面目全非。</p><p>大地布满了巨大的坑洞、焦痕。</p><p>到处都能看见焦土，沟壑，和熔岩。</p><p>而那具奇行种，已经被炸成数十万块碎肉。</p><p>杨帝在烟尘里看不到人。他努力想把头探出去，看得更清楚，至少搞明白是何方大能救了他们。</p><p>然后，后脑勺传来坚硬的触感。</p><p>“别动，人类。”声音很清冷。</p><p>杨帝嗅到了柑橘味。</p><p>他只能小心说道：“是这样的……您差点把我们也干掉了……”</p><p>身后传来嗤笑：“我跟了你们一路，知道你的能耐。这点程度，你最多重伤濒临死亡。只是没想到，你比我想象中还耐杀，居然还有力气说话！”</p><p>“所以您是谁？”杨帝尽量让自己的语气保持平静，同时身体微微紧绷。</p><p>“我是谁不重要，重要的是你们招惹了不该招惹的东西，呵，原初之眼，还有圣光教廷。”</p><p>杨帝瞳孔深处终于泛起一丝波澜：“圣光教廷是什么？”</p><p>原初之眼他知道，中土大陆第一场灾难，摧毁万物秩序的天灾，能轻而易举毁灭世界嘛，也就那样，路人皆知的常识。</p><p>但圣光教廷是什么？</p><p>追杀他们的，不是卖汽水的竞争对手？</p>
