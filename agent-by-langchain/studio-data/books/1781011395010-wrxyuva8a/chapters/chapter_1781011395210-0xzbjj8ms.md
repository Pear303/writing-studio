# 困兽与圣母小队

<p>黑暗是哈基米最好的掩护，四通八达的岔路是它逃生的希望。</p><p>就在它身后不远处，管道壁传来沉重而规律的撞击声！</p><p>咚……咚……咚……</p><p>像是……有什么沉重的东西在管道里拖行、撞击。</p><p>伴随着这撞击声的，还有一种湿滑粘腻的增生声。</p><p>咕唧……咕唧……咕唧……</p><p>血肉在疯狂增殖、骨骼在高速重塑、组织在野蛮生长的声音。</p><p>不……这不科学。在本身已经损失一定量的质量后，那两脚兽何德何能，可以无中生有地长出一条新胳膊？！</p><p>哈基米爆发出前所未有的速度，慌不择路地冲向岔道口，用尽力气撞开个松动的格栅，一头栽进下方充满霉味和灰尘的黑暗隔间里。</p><p>隔间像是个废弃的杂物储藏室，堆满了蒙尘的箱子和破布。</p><p>角落里，立着一个锈迹斑斑的金属衣柜。</p><p>哈基米用仅存的、属于猫的本能智慧，拖着受伤的身体，用触须扒拉开柜门。</p><p>艰难地将自己庞大的身躯塞了进去。</p><p>砰。</p><p>柜门被它用一根相对完好的触须从内部轻轻合上。</p><p>黑暗，狭窄，带着浓重的铁锈和霉味。</p><p>哈基米将自己紧紧蜷缩在柜子最深处，所有感官提升到极限。</p><p>它不敢发出一丝声音，连触须的搏动都强行抑制到最低。</p><p>它像一块真正的死肉，等待着，祈祷着那恐怖的存在忽略这个角落。</p><p>一种非猫的曲调由远及近。</p><p>不是哈基米熟知的任何调子，更像某种湿滑的蠕动被强行拧成了声波。</p><p>歌声像被泡软的脊椎骨，每个颤音都拖着黏液般的尾音，在空气里荡漾出淡紫色的霉痕。</p><p>当然，如果哈基米在人类社会生活得够久，应该会认出这是《国际歌》的旋律。</p><p>“起来，饥寒交迫的奴隶……”</p><p>“起来，全世界受苦的人！”</p><p>只是，人类的艺术和猫猫的艺术不能一概而论，所以在哈基米听起来，会觉得很古怪。</p><p>咚……咚……咚……</p><p>沉重而规律的拖拽撞击声，从隔间外由远及近。</p><p>来了！哈基米的核心血肉几乎要停止跳动！</p><p>它听到了隔间的门被推开的声音，触须感知到了空气的流动。</p><p>接着，是沉重的脚步踏入了这个房间。</p><p>咚……咚……咚……</p><p>脚步声缓慢，沉重，湿漉漉的粘滞感，每一步都像踩在泥泞的血肉上。</p><p>两脚兽在房间里移动，似乎在搜寻。</p><p>哈基米屏住呼吸，整个意识都缩成了一团。</p><p>它能感觉到那脚步在房间里徘徊，越来越近……</p><p>脚步声，在衣柜前停下了。</p><p>死寂。</p><p>哈基米感觉自己的“心脏”（或者说，那个驱动它存在的核心肉瘤）快要爆炸了！</p><p>它甚至能听到柜门外，那若有似无的、湿滑的增生声。</p><p>咕唧……咕唧……咕唧……</p><p>时间仿佛凝固了。每一秒都像一个世纪那么漫长。</p><p>那沉重的脚步声，再次响起。</p><p>咚……咚……咚……</p><p>声音渐渐远去，似乎走向了房间的另一头，然后……是隔间门被关上的声音？</p><p>走了？</p><p>它……它忽略了这个衣柜？</p><p>劫后余生的巨大庆幸，如同电流瞬间流过哈基米全身！</p><p>紧绷到极致的神经骤然松弛，那被强行压制的痛苦和虚弱感，反哺为令猫神经颤栗、肢体末端蜷缩的高潮涌上来……</p><p>就在它精神松懈的千分之一秒！</p><p>轰隆隆！！！衣柜锈迹斑斑的金属门，毫无征兆地被巨力猛地从外面拉开！！</p><p>敞开的柜门外，是那个极度恐怖的杨帝！</p><p>他赤着上身，焦黑的皮肤已经褪去，露出光洁如新的肌肤。</p><p>他刚刚重生的、同样光洁的右手臂，此刻正随意地搭在敞开的柜门上。</p><p>脸上，依旧没有任何表情，只有那蒙尘琉璃般的双眼中，倒映着陷入绝境困兽的倒影。</p><p>……</p><p>刺耳的警报声在蜂巢基地深处此起彼伏，但在这条靠近核心区域的走廊里，却诡异地安静。</p><p>只有应急灯如同垂死喘息般的暗红光芒，勉强照亮着前方的路。</p><p>队长一行人刚从传送的眩晕中恢复，立刻确认了位置。</p><p>“距离安全屋坐标略微偏移了……但偏差不大！”</p><p>眼镜飞快地操作着手腕上的终端，战术目镜闪烁着微光，“我们距离红皇后逻辑核心的物理层，应该只隔着三条走廊！这是最短路径！”</p><p>“最短路径？老子看是最短命路径！”</p><p>铁砣骂骂咧咧地活动着酸痛的肚皮。</p><p>他看着手里只剩下半截，已经彻底报废的狼牙棒棒柄，心疼得龇牙咧嘴。</p><p>五个积分啊！一次任务的报酬！</p><p>他们小队，说好听点是实力很弱，说难听点是菜得出奇。</p><p>每一趟轮回任务，每一次副本，基本都没有完成过。</p><p>但因为他们保命能力出奇的好，所以经历了十几次任务，都没有死人。</p><p>只不过，每次任务都是以最低条件结束，所以得到的奖励也是最低档次的奖励，每人5个积分，恶心程度相当于■团和■了么的跑腿单价，完全是把人当牛马整。</p><p>区别在于，轮回副本都是玩命的。</p><p>该死的主神……真把他们当大豆，往死里压榨！</p><p>“少废话，铁砣，警戒！”队长低喝一声，眼神锐利地扫视着周围。</p><p>念动力如同无形的触须，谨慎地向前方探去。</p><p>“火鸦，注意异常热源。眼镜，继续尝试接入内部监控，哪怕碎片信息也好。影子……算了，让他多睡会吧。”</p><p>他们快速穿过第一条走廊。这里的景象让众人心头一沉。</p><p>走廊两侧的墙壁和天花板上，溅满深褐色、早已干涸凝固的喷射状污渍。</p><p>地上散落着大量的人类残肢断臂——手臂、小腿、甚至半个连着脊椎的胸腔，如同被随意丢弃的垃圾。</p><p>更诡异的是，残骸的断裂处并非撕裂伤，边缘异常整齐光滑，呈现出一种焦炭般的漆黑。</p><p>仿佛，是被瞬间超高温的某种能量束精准切割、碳化。</p><p>“这群叛乱智械的武器超乎我们想象。”</p><p>火鸦担忧地说。她的火焰绝无可能烧出这样的痕迹，最多也只能给老大点点烟。</p><p>“激光防御网？还是……红皇后的某种处决程序？”</p><p>“小心点，这地方比我们想的更邪门。”</p><p>进入了第二条走廊。</p><p>这条走廊相对“干净”一些，没有那么多骇人的残肢，但空气中弥漫着一股难以言喻的焦糊味和……一种更淡、却令人作呕的甜腥气。</p><p>墙壁上布满了深深的爪痕和撞击凹陷，仿佛有什么巨大的野兽在这里肆虐过。</p><p>“安静，有声音！”眼镜突然竖起耳朵，战术目镜的拾音器功率开到最大。</p><p>一阵极其微弱，断断续续，却又无比凄厉痛苦的猫叫声，从走廊深处某个房间的门缝里钻了出来。</p><p>“喵——嗷……嘶……呜……”</p><p>更像是某种生物在遭受酷刑时发出的、濒死的哀嚎。</p><p>而且，这声音……似乎有点耳熟？</p><p>“哈基米？”有人惊呼。</p><p>火鸦和眼镜对视一眼，都看到了对方眼中的叹息。</p><p>他们一队人都是典型的圣母心态，甚至连NPC都不想放弃。</p><p>当时队长大声质问杨帝，其实是希望杨帝能给他一个活着的「理由」，这样，队长就能名正言顺将这个NPC救下。</p><p>当然，付出的资源损耗也会更多，相当于透支了他们未来的一次自救。</p><p>其他队员会在明面上反对队长，但完全不干预他的决定。</p><p>一伙子都是圣母，除了队长外还都是傲娇，能在“轮回副本”中活这么久也是个奇迹。</p>
