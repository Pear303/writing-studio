# 组队挑战风车

<p>“其实我已经收住力了。”</p><p>“哇，阁下的力量控制可真是精细入微。”</p><p>杨帝摊开双手，露出个无害的笑：“当然，方才您也说了，我与‘域外天魔’不同。在我家乡有句话叫‘入乡随俗’，自然不能上来就闹出血案惨剧嘛……”</p><p>青丘白璃将这个由虹色火墙环绕而成的领域收回自己的三十六条尾巴中。</p><p>那大能释放的领域如梦亦如幻。只有空气还残留着灼烧的余温，证明这座领域曾经存在。</p><p>“‘领域’的本质是什么？”杨帝好像没怎么听说过这种法术，在地球上也只是通过幻想类文艺作品听说过。</p><p>青丘白璃守口如瓶：“将自己的灵能外化，让方圆几十米甚至更大范围的东西都变成自己主体的一部分。相当于在一定范围内，施法者就是主宰，而被纳入领域的事物，都被收容在施法者的肠胃里。”</p><p>让环境成为自己的一部分。</p><p>为了不让自己的“主体”溶解于外在环境，而选择将自己的现实/灵能仅仅小范围内扩散。</p><p>比如说几十米，几百米。</p><p>这实在是让人憧憬啊。</p><p>客栈掌柜·青丘白璃领域“诛魔破阵曲·重金属”彻底放开了。</p><p>杨帝看到外界风景，闻到清冽海风，感受到细雪拂面。</p><p>这真是一方适合度假的世界。</p><p>岁月静好的感觉一下子涌上来……</p><p>下一刻，足足六名大内高手杀向杨帝！！</p><p>六位绝世高手，个个都有秘密武器，个个都有太乙真仙修为……除了一个，那就是“守望者·59改”。</p><p>他的强大，主要来自一身大舰巨炮，以及厚得令人发指的护盾与装甲。</p><p>另外五人，分别是图书馆保安·天机子，酒楼厨子·中山无极，道观扫地僧·渡厄禅师，经常在中学附近收徒弟的老头·血手屠魔，以及月斑银鲈·万古鱼尊。</p><p>六股强大气息冲天而起，如天罗地网般将杨帝困在中央，寒光闪烁的法器在虚空中划出致命轨迹。</p><p>杨帝瞳孔骤缩，目光扫过人群中那张熟悉的机械脸庞——守望者·59改，以及正吐着泡泡的月斑银鲈·万古鱼尊。</p><p>他声音里带着难以置信的醋意：“阿巴，59改！难道连你们也背叛了吗？”</p><p>阿巴翻了个白眼：“咕噜咕噜！阿巴阿巴！老大你身上灵能如此诡异，就算不是域外天魔，也定是被这魔性污染，阿巴这就来救你！”</p><p>59改不语，只是一味抬起相位切割刀，不断对杨帝挥出足以轻易切开中子星的斩击。</p><p>他们是真的很想救杨帝。</p><p>杨帝默默领了他们的好意，然后两脚踹飞阿巴和59改。</p><p>随后，他双手双脚四根肢体，同时按死四个大内高手的脑袋，冲出大气层，来到物质稀薄的数千公里高空。</p><p>身体化作大陀螺，原地自旋起来。</p><p>杨帝在高空疯狂旋转，四条肢体宛如螺旋桨般搅动着外层空间稀薄的空气，带起阵阵扭曲的空间涟漪。</p><p>“嗡——嗡——嗡——”</p><p>他身上衣物被撕扯成布条，在离心力作用下飘向四面八方。</p><p>由于此处空气极度稀薄，所以这些突破百倍音速的碎布片没有自燃。</p><p>“嗡——嗡——嗡——”</p><p>而被他按在掌心的四位本地土著大内高手——天机子、中山无极、渡厄禅师和血手屠魔，此时就像被绑在疯狂滚筒洗衣机里的玩偶，脑袋随着旋转轨迹划出圆滑弧线。</p><p>“嗡——嗡——嗡——”</p><p>“话说四位，冷静了吗？”</p><p>虽然这里空气稀薄，但只要足够大声，声波仍然能够通过稀薄的物质传递。</p><p>杨帝扯着嗓子吼出的质问，震得四人耳膜嗡嗡作响。</p><p>“休要坏我道心！”天机子的道袍被扯得破破烂烂，花白头发根根竖起。</p><p>他念出的法诀都因为剧烈旋转，而变得断断续续，符文刚凝聚成形就被甩飞出去。</p><p>杨帝越飞越高，自转越来越快。</p><p>直到距离大地数万十公里的高度，四个人旋转的末端线速度已经达到0.999999999c，极端接近光速，相对论效应极度显著。</p><p>四人法术几乎难以成行，只能用最纯粹的灵能和肉体力量直接轰击杨帝。</p><p>然而他们凝聚满灵能力量的拳头，却像四根淀粉肠打在钢板上，甚至无法打乱杨帝的发型。</p><p>四人的精神短暂连接，召开临时会议。</p><p>他们原本打算等客栈掌柜·青丘白璃撤除领域后，就将里面那“域外天魔”一击制服。</p><p>他们还说服了两个来自异界的大能，和他们一起击败天魔，救出二人真正的同伴。。</p><p>现在看来，那条鲈鱼和坦克都只是假意答应，因为他们知道杨帝的斤两。</p><p>——无论是四个人一起围攻杨帝，还是六个人一块儿群殴他，结果都差不多。</p><p>——都会反过来，被他一人殴打所有人！</p><p>“血手屠魔，在场只有你是依靠肉身成圣，对此有没有逃脱之法？”</p><p>“根本没用！我一拳轰到这怪物脑门，他仅仅是眉毛动了动，随后旋转的力道又陡然增强三分！”</p><p>中学老头·血手屠魔怒吼中夹杂着罡气震颤的嗡鸣，他虬结如古树的手臂上青筋暴起，每一寸血肉都充斥仙元。</p><p>拼尽全力，却始终无法撼动杨帝分毫。</p><p>道观扫地僧·渡厄禅师盘坐半空：“哈利路亚，灵宝天尊，善哉善哉……此子肉身已堪比混沌至宝，禅杖击在他身上，竟如敲在灵茶山乂斧上，有朝一日我必生啖其血肉……”</p><p>“你和尚怎么敢破戒吃肉？还吃人肉？”</p><p>“啧，看来是在域外天魔附近待太久，有些许近墨者黑了。”</p><p>“别废话，到底有无破局之道？比如说领域撤去的时候，客栈掌柜·青丘白璃有没有用眼神暗示我们关于他的弱点之类的……”</p><p>“看来只能我出手了。虽然我曾发过誓不能对同族举起这把刀，但这个‘誓’也不是不能暂时撤销……”</p><p>酒楼厨子·中山无极暴喝一声，周身蒸腾起翻滚的菜籽油般的雾气。</p><p>手中菜刀迸发出万千道金黄刀芒。</p><p>这是他糅合了天道级剑法的“九转乾坤斩”，曾一刀将一尊“半步大帝”级别的域外天魔，竖着斩成两半。</p><p>菜刀也不是普通的菜刀，而是媲美“混沌至宝”的宝刀。</p><p>全力一劈，能够切开他目前所碰到过的所有食材。除了归墟大帝。</p><p>而在此刻，菜刀竖着砍中杨帝一根腿毛。</p><p>刹那间，整片虚空像是被投入了千万颗太阳，耀眼的金芒轰然炸开。</p><p>杨帝腿毛看似纤细脆弱，此刻却如同远古神魔的天柱！</p><p>任凭金芒与寒刃如何绞杀，依旧稳如泰山。</p><p>酒楼厨子·中山无极手中菜刀扭曲变形，刀刃纹路如同活物般扭曲缠绕，一道道裂痕以肉眼可见的速度蔓延开来。</p><p>“不可能！这怎么会！”中山无极喉咙里发出野兽般的嘶吼。</p><p>他能感受到，宝刀原本的汹汹气势，正在以恐怖的速度崩解。</p><p>那把跟随他征战无数岁月、饮尽万千妖魔鲜血的混沌至宝，此刻竟像是遇到蟑螂药的蝼蚁，在一根腿毛面前节节败退！</p><p>但是，酒楼厨子·中山无极也确实对杨帝造成了伤害。</p><p>他小腿上那根毛发，被竖切成了两半。</p>
