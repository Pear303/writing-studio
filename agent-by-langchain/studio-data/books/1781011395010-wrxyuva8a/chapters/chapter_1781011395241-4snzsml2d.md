# 眼睛代表观察

<p>如同惊雷在灵魂深渊炸响，瞬间驱散了沉沦的死寂。</p><p>杨帝猛地睁开了眼睛，瞳孔在惨白的病房灯光下骤然收缩，随即又迅速扩散。</p><p>“啊！！！卧槽。”</p><p>“他醒了？！”</p><p>“心跳！心跳回来了！！”</p><p>围在病床边的医生护士被这突如其来的睁眼吓得魂飞魄散，齐齐向后猛退一步，撞得器械哗啦作响。</p><p>理论上来说，心脏停跳足足十分钟，这特么能活的只有丧尸！</p><p>有人惊恐地看着监护仪——那条刚刚还令人绝望的直线，此刻正顽强地重新跃动起来，虽然节律混乱不堪，但确确实实是心脏在搏动。</p><p>杨帝没有理会周围的混乱。</p><p>他直接从硬板床上坐了起来，低头看了看自己左手腕上那副冰冷的手铐——因为需要抢救，右手腕的铐子被临时解开了，但左手还铐在床栏上。</p><p>他伸出右手，食指和中指并拢，捏住了左手腕铐环与床栏连接处那根不算细的钢链。</p><p>咔嚓。那根足以承受几百公斤拉力的合金钢链，就像一根被掐断的枯树枝，应声而断。</p><p>手腕一轻，束缚感消失。</p><p>杨帝甩了甩左手，目光又落在了断裂的钢链上，那断裂处是锐利的金属茬口。</p><p>远处角落那个刚刚冲回来、目睹了“诈尸”和“徒手断钢链”全过程的警察，此刻大脑已经完全宕机，手按在枪套上，却不为所动。</p><p>杨帝捻起了那截带着锋利茬口的断链，狠狠地划向了自己左手手腕的桡动脉。</p><p>动作快、准、狠！</p><p>可惜的是，钢铁制的锋利茬口并没有划破手腕，反倒擦出了些火星子。</p><p>杨帝全都想起来了。</p><p>不仅仅是拘留所、医院、劣质外卖和那个被他咬死的“耶罗大仙”。</p><p>他想起了那无尽的虚空，那破碎的纯白领域，那被层层世界泡包裹的囚笼，那由冰冷星舰和无限机兵构筑的法则琥珀。</p><p>他想起了那场跨越了无穷阶层，堪称宇宙级饕餮盛宴的吞噬。</p><p>他想起了自己扼住那古老分形狐躯的咽喉，感受着对方从阿列夫一的巅峰跌落，感受着那磅礴的“现实丰度”——构成耶罗存在的灵能本源——被自己贪婪地吮吸，成为自身向更高维度攀升的纯粹燃料。</p><p>他想起了那冰冷的宣告：</p><p>「编撰众生命运的剧作者，永恒地死去。」</p><p>他想起了……灭圣绝盗。</p><p>他早已设定好，最终的也是唯一的归途。</p><p>斩灭一切圣人，包括依靠编织命运而高高在上的存在，最终……斩灭自身。</p><p>因为他杨帝，在吞噬了耶罗、踏过了阿列夫一的界限之后，他自身，就是这条道路尽头，那最大的圣人。</p><p>他即是力量的巅峰，他即是新的“剧作者”，他即是新的命运编织者。</p><p>灭圣绝盗，以“灭”为始，以“绝”为终。</p><p>他自己，就是那最后一尊、也最该被灭掉的“圣”。</p><p>在“杨帝”死去，没有“杨帝”的叙事中，杨帝会走向何等命运的展现？</p><p>没有“杨帝”的叙事里，杨帝该是什么？</p><p>医院走廊里模糊的消毒水味，那份让他上吐下泻的拼优饭，拘留室里冰冷的床板。</p><p>那是杨帝作为凡人，原本应该经历的。</p><p>在没有耶罗大仙和“杨帝”的干预下，杨帝应该会在食物中毒后好好休养，在过失杀人后面对法律的制裁。</p><p>在某个平淡的午后，彻底忘记那些光怪陆离的梦境，做回一个为生计奔波的普通人。</p><p>也可能成为一则“高烧致死”的社会新闻边角料；或许被那个白领的氯化钾彻底终结，在无人知晓的病房里悄然离世。</p><p>连名字都不会被太多人记住。</p><p>但他终究没有自杀成功。他没能杀死自己。</p><p>对自己造成的致命伤，乃至超越世界等级的致死伤害，只会让他更强。</p><p>无法将他彻底杀死。</p><p>“我没死，那么我应该在……星环盟约的控制下。”</p><p>拘留所冰冷的墙壁在眼前褪色溶解。</p><p>医院的刺目灯光，监护仪警报，警察震惊的脸……如同被水冲刷的油彩，迅速模糊，直至永恒的消失。</p><p>取而代之的，是一片绝对无瑕的纯白。</p><p>白杨领域！</p><p>不，这比之前的领域更加纯粹，更加绝对。</p><p>这里没有边界，没有上下左右，只有一片包容一切又否定一切的白色。</p><p>杨帝就浮在这片纯白的中心。</p><p>他的身体看上去仍然是由碳基有机物构成的脆弱身躯，然而，却散发着超越万物的气息。</p><p>强大，却又带着一种即将走向终末的平静。</p><p>他低头，看向自己的手。</p><p>他抬手点向了自己的眉心。</p><p>整个纯白领域，不，是整个由他自身存在定义的“现实”轰然坍塌。</p><p>仿佛宇宙的根基被撼动。</p><p>自我否定！</p><p>存在抹除！</p><p>杨帝的身影，从指尖触碰的地方开始，无声无息地消融。</p><p>构成形体的光芒如同沙粒般流散，融入那无垠的纯白。</p><p>那磅礴到足以支撑无限宇宙的“现实丰度”，那从耶罗处吞噬，又经过自身升华的力量，此刻如同开闸的洪水，疯狂地逸散出这片纯白，流向比虚无更空旷之地。</p><p>这个过程平静得可怕。</p><p>灭圣绝盗，功成。道灭，我亦灭。</p><p>万古唯一念，尽付此决中……不，失败了。</p><p>又一次，杨帝的“自灭”没能成功。</p><p>他模模糊糊的意识到，在自己毁灭耶罗大仙之后，已经经历过无数次对自身的终结。</p><p>‘删除自身……需要删除整个虚空……吗……’</p><p>这个冰冷的结论，突兀地烙印在认知。</p><p>耶罗大仙的死亡，只是撕开了更深层帷幕的一角。</p><p>要彻底终结自身这个最大的“圣人”，就必须将承载他的这无穷无尽的虚空本身，也一并抹去吗。</p><p>但在此之前……</p><p>杨帝的感知猛地向下“沉”去！</p><p>病房的景象、地球的轮廓、太阳系的旋臂、银河系的星盘、本星系群丝状结构、拉尼亚凯亚超星系团……</p><p>宇宙天文尺度，在他眼前如同高速倒退的列车般飞逝。</p><p>他的“感知”在瞬间穿透了所有维度与屏障，达到了一个俯瞰一切的“绝对视点”。</p><p>他看到了地球，那个蓝色的脆弱水球。</p><p>他看到了银河系，那个由数千亿恒星组成的璀璨漩涡。</p><p>他看到了本宇宙，那在膨胀中冷却的时空泡。</p><p>然后，他继续上升，穿透了宇宙膜，看到了更多。</p><p>无数个宇宙泡，如同漂浮在无尽黑暗海洋中的肥皂泡，闪烁着各自不同的物理规则与时空结构。</p><p>它们数量之多，超越了任何凡俗生命所能理解的极限。</p><p>“视线”的扬升并未停止，杨帝的视野穿透了这层海洋，达到了一个更加宏大、更加令人绝望的层面。</p><p>他看到自己之前所处的那个宇宙，连同那无穷无尽的平行宇宙泡，仅仅只是……</p><p>一个硕大无朋，由无数宇宙构成的“点”。</p><p>而这个点，正位于由10^95个宇宙级“点”所构成的，无限嵌套的狐狸轮廓之中。</p><p>那是一个由无量宇宙作为基本像素点，编织而成，横跨无穷维度的耶罗分形狐躯。</p><p>他所在的宇宙，仅仅是这只庞大到超越认知极限的狐狸分形结构上，微不足道的一颗“尘埃”。</p><p>甚至恰好在那巨大狐狸分形结构上，一只眼睛的瞳孔位置。</p><p>眼睛，代表「观察」。</p><p>耶罗……仍然没死。</p><p>但直到取得阿列夫一级别的灵能，杨帝才得以从外部，而不是借助自己的分身，来一窥这宇宙群的全貌。</p><p>这只由无量宇宙构成的巨狐，其形态并非静止。它在缓慢地“呼吸”着，每一次呼吸，都伴随着无数宇宙的诞生与寂灭。</p><p>那双仿佛由亿万星河漩涡构成的庞大狐眼，正注视着杨帝母宇宙内部的一切——包括刚刚试图自我湮灭的杨帝。</p>
