# 十日后

<p>……</p><p>十天之期已到。</p><p>钓鱼佬如约再次来到了那栋烂尾楼。</p><p>踏入这熟悉又透着诡异气息的烂尾楼，他一眼就瞧见了杨帝。</p><p>杨帝站在楼内的一处空旷之地，背对着钓鱼佬。</p><p>他身姿挺拔，周身仿佛萦绕着一种难以言喻的气场。</p><p>“老哥来了。”杨帝转过身，微道。</p><p>眼前的杨帝，让钓鱼佬心中一凛。</p><p>他比十天前更自信，那是一种气质上的蜕变。</p><p>那种自信像是从灵魂深处满溢而出，又更让人难以理解，蒙着一层更深的迷雾。</p><p>钓鱼佬正想着把疑问藏在心中，毕竟人人都有自己的隐私，但杨帝却率先解答。</p><p>他笑道：“或许你难以理解，十日前的我是个弱者，现在的我是已经抵达‘半步强者境’。”</p><p>钓鱼佬只想“啊？”一声表达态度。</p><p>十天前你还弱者？谁家弱者能一拳打爆不锈钢防盗门。</p><p>杨帝并没有理会钓鱼佬的翻白眼。</p><p>他帮忙卸下刚带回来的大包小包物资，包括几十条高强度鱼线、在笼子里密密麻麻一大堆牛蛙、几十沓1/4巴掌大小的定位仪。</p><p>“GPS”意思是全球定位系统，它其实是阿美莉卡建立的卫星导航系统。</p><p>除此之外还有欧罗巴的伽利略，和神州的北斗系统，它们严格来说都不叫GPS。</p><p>而钓鱼佬手里这几十个定位仪，是用北斗卫星定位的。</p><p>只不过“GPS”这种说法已成惯例，也就渐渐地，在民间用来代指一切全球定位系统了。</p><p>钓鱼佬看着杨帝用钓鱼线，将牛蛙和定位仪都系在一起。</p><p>“这堆GPS花了我近五千块，我大概能猜到你要做什么……但你所说的‘生物尸体’呢？”</p><p>十天前，杨帝特地向他强调要活的牛蛙，不要已经做成肉菜了的。</p><p>但活的牛蛙，并不会触发黑色水体的联通效应。</p><p>这是钓鱼佬经过多次实践证明的结论。</p><p>杨帝说他自己“会提供生物尸体”。</p><p>但四下看去，这里一楼似乎并没有摆放什么动物的尸首。</p><p>杨帝让钓鱼佬像他那样把GPS和牛蛙用钓鱼线串起来，然后杨帝自己走上楼梯。</p><p>钓鱼佬满心疑惑，但还是依言开始动手，将一条条高强度鱼线穿过牛蛙的身体，把定位仪也依次系好……</p><p>“不行，还是忍不住好奇。”</p><p>好奇是人类的天性。</p><p>钓鱼佬经过理性分析，决定先停下手头的工作，优先满足自己感性的好奇心。</p><p>他放下牛蛙和钓鱼线，走上楼梯，尾随在杨帝身后。</p><p>来到3楼和4楼之间的转角处时，杨帝停下脚步。</p><p>钓鱼佬躲在不远处的角落里，探出头悄悄观察。</p><p>他停在了一只猫面前。</p><p>那只猫背对着他们而坐，但钓鱼佬总觉得，好像哪里不对劲……</p><p>只见杨帝虚空大手一探，抓住了那从阴影中探出的猫。</p><p>“喵嗷——吼！！”</p><p>那只猫发出声线不太对的咆哮。</p><p>杨帝继续将其拉扯，猫的身形越来越长……</p><p>钓鱼佬看清楚了，那根本不是流浪猫，而是根肉条。</p><p>肉条仿佛没有尽头，不断从阴影里延伸出来！</p><p>楼道响起了奇怪的声音，像是痛苦的咆哮与哀号交织……</p><p>黑色浓稠液体从肉条与阴影的连接处渗出，散发出一股令人作呕的气味。</p><p>杨帝将伪装成猫的“肉条”，从阴影里大量地拔出来，那些扭曲且散发着诡异气息的肉条源源不断，好似无穷无尽！</p><p>他每拉出一截，就一刀子砍断一截。</p><p>那些断口处还在不断抽搐的肉条，纷纷掉落在地，显然都已失去生机。</p><p>钓鱼佬看着眼前这惊悚的一幕。</p><p>好特么多肉肠……</p><p>越来越多的肉条被扯出，楼道几乎被填满。终于，杨帝停了下来，看着满地的肉条。</p><p>他转身看向钓鱼佬躲藏的方向，说道：“出来吧，你应该明白我要做什么了。”</p><p>钓鱼佬从角落里走出。</p><p>空气里洋溢着刺鼻气味，他喉咙里咳出的几句话，词语破碎：“这……这猫怎……这么长……”</p><p>杨帝弯腰捡起几条肉条。</p><p>它们在手中又抖了抖，最后彻底失去活性，成为真正的“生物尸体”。</p><p>它们散发着令人作呕的气味，表面黏腻湿滑，还不断滴下浓稠的黑色液体。</p><p>“这栋楼里不干净的东西多得很，不干净的东西之间也许会相互吸引，所以就用这‘舌头’作为饵吧。”</p><p>“舌头？”</p><p>“不错，这是种伪装成流浪猫的舌头，它貌似会发出喵喵叫，引诱人走进去摸那只猫，然后被舌头卷走。”</p><p>他们也并不清楚，这种舌头是什么生物。</p><p>但可以肯定是碳基生物，可提供大量尸体。</p><p>只要是生物尸体，或者残肢，就可以了。</p><p>“这几天我已经初步尝试过，并不是只有完整尸体，才能够触发黑暗水体的连接效应，足够大块的残肢也是可以的。”杨帝说。</p><p>他从房间里倒腾出蛇皮袋，将地上的肉肠打包装好。</p><p>他们一块回到1楼。</p><p>现在万事俱备，东风也只欠一些。</p><p>他们把剩下的牛蛙和定位仪，用鱼线一根一根串好，码放在一旁。</p><p>杨帝解释这些物品的作用。</p><p>他指了指地上那些物件。</p><p>“猫条”，是黑色水体的“饵”，用于触发黑水的连接。</p><p>牛蛙，用来测试另一个黑色水体的环境，是否适合地球碳基生物生存。</p><p>定位仪，可以用来查看黑色水体另一端的位置，前提是在地球上卫星信号良好的某处。</p><p>高强度鱼线，能让他们把牛蛙和定位仪拉回来，而且不那么容易扯断。</p><p>钓鱼佬默默听着杨帝的介绍。</p><p>自己原本研究这黑色水体，是有些自暴自弃之意味的。</p><p>他在这世上，本来也没几个值得留恋的亲朋好友，所以他将一生扑在教育事业上。</p><p>但十年前，最得意的几个学生却被掳走，包括他们曾经存在于世的证据，也一并被消灭。</p><p>只有些许日渐模糊的记忆，还残留在这个中学老师心中。</p><p>他一遍又一遍报警，雇佣私家侦探，但无济于事，反倒因为“报假警”被拘留了几天。</p><p>他甚至去拜访过那四个学生的父母，他们也都不记得，自己居然有这样一个优秀的孩子。</p><p>明明知道家长会的座位永远空着，他却还要在教室后排摆上四张椅子。</p><p>所有人都把他当做偏执狂，精神病，疯子。</p><p>学校质问他为什么编造不存在的学生。</p><p>公安因为他连续14次“报假警”而列其入黑名单。</p><p>中学老师辞去了教育事业者的工作，当起了全职钓鱼佬。</p><p>表面上是为了研究黑色水体的连接效应。</p><p>实际上，在内心极深处，他希望自己也能被黑水另一边的“东西”带走。</p><p>“我至今记得他最后攥着我衣角的力道，像条上钩的鲫鱼那样颤抖着。”</p><p>他将最后一只牛蛙和定位仪绑在一起。</p><p>眼角微红地看向杨帝：“我们真有可能将失去的人带回来吗？”</p><p>说完这话，他自己都吃了一惊。</p><p>自己竟像是个孩子，忐忑地问长辈“我们能成吗”。</p>
