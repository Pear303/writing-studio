# 闪通玉盘·扇区2

<p>一个毫无情绪起伏的男声，自称是总部人事部门的David，用快得几乎听不清的语速、同样咖喱味的英语通知道：</p><p>“请于今日下午两点，准时到总部大楼B座0721会议室报到，有重要事项沟通。”</p><p>重要事项？</p><p>我的心跳莫名漏了一拍。</p><p>妻子正在费力地拆着装锅碗瓢盆的箱子，闻声抬起头，脸上还带着对新生活的生涩笑容：“谁呀？公司这么快就找你啦？好事儿！”</p><p>“嗯……嗯，好事儿。”我含糊地应着，喉咙有点发干。</p><p>加州的阳光透过百叶窗，在廉价复合地板上投下一条条过于明亮的光带，晃得人眼晕。</p><p>……</p><p>下午一点四十分，我站在那栋玻璃幕墙闪闪发光，冷气足得让人起鸡皮疙瘩的摩天大楼前。</p><p>0721会议室。</p><p>灯光冷白，巨大的长方形会议桌光可鉴人，倒映着天花板冷漠的几何线条。</p><p>只有两个人。一个是我在电话里听过声音的大卫，大抵是天竺裔，灰蓝色西装，金丝眼镜，面无表情，像戴着一张精致的人皮面具。</p><p>另一个是位白人面孔的女性。她面前摊开一份厚厚的文件夹。</p><p>“Mr. Gui，”天竺男开口了，声音像机器合成的，没有任何温度，“感谢您准时到来。基于公司最新的架构评估和本地业务需求，您的岗位软件工程师已被确认冗余。依据您签署的雇佣合同附件C，第7.3款，以及加州‘自由雇佣’相关法律条款，您的雇佣关系，于此刻，即时终止。”</p><p>他吐出的每个单词都清晰无比。</p><p>像一颗颗咖喱味冰珠砸在光洁的桌面上，发出空洞的回响。</p><p>冗……余？终……止？</p><p>也就是……炒我鱿鱼？！</p><p>白人女适时地推过来两份文件。</p><p>一份是解雇通知，措辞冰冷正式。</p><p>另一份是薄薄的两页纸，抬头是醒目的“Separation Agreement”，离职协议。</p><p>“自由雇佣……？”</p><p>我听到自己的声音在空旷的会议室里响起，干涩得厉害，带着自己都陌生的颤抖，“意思是可以……没有任何理由？”</p><p>“Exactly！”那男的嘴角似乎极其轻微地向上扯了一下，“这是加州法律赋予雇主和雇员双方的权利和自由。我们完全依法行事。”</p><p>他指了指那份离职协议。</p><p>“为什么离职协议上没有任何补偿……”</p><p>“我们完全依法行事。”那女的搭腔。</p><p>“可是公司不是说核心人才长远投入、Global Career Path吗……”</p><p>“我们完全依法行事。”他们异口同声强调。</p><p>咖喱男适时地递上一支笔，白人女做出“请”的手势。</p><p>我当时可能有些失态，当场拍着会议厅桌子站起来：“我要把你们告上联邦法院！！”</p><p>那男的继续说着咖喱味英语：“第一，一般的劳动纠纷，如果纠纷仅涉及州法规定的劳动权益，通常需要在州法院提起诉讼。”</p><p>那女的一口纯正地道米式英语：“第二，我们完全依法行事。”</p><p>我直到那一刻，才明白，这是场精心策划，跨国界、跨大洋、彻头彻尾的诈骗。</p><p>又过了半天，我才了解到，这还是“合法的诈骗”。</p><p>双倍加班费，年假十五天起步，补充商业保险，茶水间里无限量供应的、即使偶尔有焦味和“蛋白质加餐”但好歹免费的咖啡，甚至包括那优厚的N+3赔偿方案。</p><p>这些在被某神秘东方国度视为“良心企业”标杆的福利，是外企进来的「基础门票」。</p><p>这些福利是写在合同里、贴在招聘海报上、是展示给监管机构看的“合规证明”，是维持其优质雇主人设不可或缺的道具。</p><p>然而，一旦猎物被诱捕，离开那个需要“门票”才能立足的围栏，被带回了它们真正的、弱肉强食的老巢——阿米利卡。</p><p>温情脉脉的面纱被撕得粉碎。</p><p>外企，哦不，已经回到本土的内企，可以理直气壮、合法地、一分钱额外代价都不付地让我滚蛋。</p><p>喉咙深处那股熟悉的、令人作呕的腥甜味猛地涌了上来，比流感最重时还要汹涌，比喝了蟑螂咖啡更恶心。</p><p>我死死咬住后槽牙，才没当场吐出来。</p><p>一丝荒谬绝伦的念头，像电流般瞬间击穿了我混乱的思维：康复新液……那玩意儿再恶心，至少它成分表是诚实的，它标明了“美洲大蠊”，它实实在在地写着“康复”的承诺——虽然疗效存疑，但它没有用“核心人才”和“Global Career”的幻梦来诱骗你喝下。</p><p>诈骗……背叛……</p><p>一场彻头彻尾的背叛！！！</p><p>……</p><p>桂虚猛地抬起头，眼中烧着被愚弄后的屈辱，和绝境中迸发的火星。</p><p>“工会！”这个词像溺水者抓住的最后一根稻草，瞬间冲上他的喉咙，“我要找工会！你们不能这样！”</p><p>天竺裔咖喱男那张人皮面具般的脸上，终于出现了一丝极其细微的变化。不是慌乱，甚至不是惊讶，而是一种混合着了然和……怜悯？</p><p>他微微向后靠在冰冷的椅背上，金丝眼镜后的目光平静无波。</p><p>“Mr. Gui，”他的语调甚至比刚才宣布解雇时更平稳，带着一种陈述客观事实的冷漠，“在加州，工会并非强制存在。您的岗位，属于‘非工会覆盖’类别。这是您入职时签署的雇佣合同附件D中明确载明的条款之一。”</p><p>工会？非覆盖？</p><p>桂虚脑子里嗡嗡作响。</p><p>合同？那些几百厚的、印满密密麻麻英文的法律文件？</p><p>当时Lisa王笑容可掬地把它们推过来，指着几个需要签名的地方，用甜美的声音说：“都是标准模板，放心签啦，公司全球统一，对打工人最有利的保障！”</p><p>他沉浸在绿卡和核心人才的梦里，哪里会仔细去抠那些蚂蚁大小的术语。</p><p>“那……那我加入！”他几乎是吼出来的，带着某种孤注一掷的疯狂，“我现在加入工会！总可以吧？”</p><p>白人女都抬起了头。</p><p>她的眼神里没有波澜，只有一种职业性的、近乎残酷的清晰。</p><p>“桂先生，”她的声音清晰而冰冷，像手术刀划过玻璃，“首先，您已不再是本公司雇员，工会无权介入您与公司的‘前’雇佣关系。”</p><p>“前”这个字，她咬得格外重。</p><p>“其次，即使您目前仍在职，想要加入覆盖您所在行业或公司的工会，也需要满足特定条件，包括——</p><p>“缴纳会费及入会费；等待‘等待期’结束；获得会员推荐；最后通过工会的审查，再等待名额空缺。</p><p>“您作为新移民，没有本土工作经验记录和相关人脉，这个过程可能非常漫长，甚至……我可以打包票，你不会被接受。</p><p>“在这里，能够加入工会本身就是种类似‘贵族’的特权。您来到这片土地前，应该都了解这些吧？”</p>
