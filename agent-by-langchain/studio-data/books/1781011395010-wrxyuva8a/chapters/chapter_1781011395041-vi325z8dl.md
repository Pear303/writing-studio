# 质壁分离……？

<p>“……”</p><p>杨帝瞳孔骤然收缩成针尖大小。</p><p>他的视线像被磁铁吸附般钉在那滩血涡上。</p><p>震惊如同重锤砸在天灵盖上——希夷的断尾尚未让他消化完毕，此刻又冒出个用鲜血绘制的“漩涡图纹”。</p><p>他的思维瞬间陷入混沌的风暴，困惑缠绕着脑神经。</p><p>这和希夷的断尾有何关联？</p><p>希夷的遭遇只是更大阴谋的冰山一角？</p><p>他想起狸花猫变形时的诡异形态，想起灰袍甘道夫那句“逝者”的隐喻。</p><p>这些碎片在脑海中疯狂碰撞，却拼不出完整的图景。</p><p>恐惧如影随形地爬上脊背。</p><p>黑暗中仿佛有无数双看不见的眼睛在窥视。</p><p>空气中的血腥味变得粘稠，像要将他溺毙。</p><p>但也有一丝惊喜在混乱中迸发。</p><p>至少这个图案的出现，意味着他已经找到了线索——关于耶罗符印的线索。</p><p>继续追查下去，他或许能更多线索，进而摆脱耶罗符印的诅咒。</p><p>但前路，无疑将愈发危险！</p><p>没有太多特殊能力的普通人类，危。</p><p>“胡彦卓。”杨帝开口。</p><p>“怎么了？”胡彦卓察觉到他语气中的严肃。</p><p>这个新结识的兄弟，很少如此正式地直呼他全名。</p><p>杨帝：“胡彦卓大哥，您能陪我走到现在，杨某已经感激不尽了。不过，你也已经见过，这一路凶险万分，各种超自然事物层出不穷，我还是希望你能调头回去。”</p><p>胡彦卓闻言，眉头微微一皱。</p><p>“杨帝，你说这话可就见外了。既然选择了一起走这条路，那我就不会半途而废。耶罗符印的事，就是因为我拍的照片，才让你被诅咒。我也有一部分责任，所以你的事，就是我的事。”</p><p>“不，主要是希望胡哥能去一个信号好的地方帮忙报警……”</p><p>胡彦卓：……</p><p>二人掏出手机，屏幕上都显示“仅可呼叫紧急通话”。</p><p>但实际上，他们无论是拨打妖妖灵，还是妖二零，电话都没能呼出去。</p><p>紧急通话线路和普通线路，不是同一条。</p><p>有些地方拨打普通号码，可能打不出去也呼不进来；但如果报警或者打救护车，还是能打出去的。</p><p>如果连报警和救护车也打不了，那就是真正的、物理意义上的完全没信号了。</p><p>就仿佛……仿佛是跟文明世界完全隔离。</p><p>……</p><p>最终，胡彦卓还是强行留了下来。</p><p>一人手持撬棍，另一人手执钢管，至少两个人，多一份武力值，还是能安全一点的。</p><p>杨帝叹气：“胡哥，如果你执意要留下来，那么请你听我指令，跟在我身后，不要贸然冲上前好么？”</p><p>“行吧，杨参谋长。”</p><p>“可以，胡司令。现在我们第一要务，不是解开这里的秘密，不是探究漩涡图案，不是耶罗符印——而是先找到安全出口。”</p><p>二人一猫也便开始了搜寻。</p><p>他们刚刚是从竖井爬上来的，既然是向上，说明此处离地面又近了一步。</p><p>而且这一间地下室，比刚刚竖井下面的地下室，看起来空旷许多，气氛没那么压抑。</p><p>这里天花板比较高，差不多三米，顶部也没有铺设排污管道了。</p><p>周围堆着许多杂物，破损的石膏雕塑，一箱箱被丢弃不要的画材，生锈了的旧乐器。</p><p>还有遍地可见、腐朽糜烂了的衣物。</p><p>他们甚至找见七八双男女样式的皮鞋。</p><p>手电筒的光束扫过地下室西北角，杨帝顿住脚步。</p><p>在剥落的墙皮下，居然钉着一张用麻绳捆扎的简易木床。</p><p>他迅速判断出来——有人在此生活过，就在不久前。</p><p>床板上还铺着打着补丁的灰色毛毯，毛毯边缘沾着暗褐色污渍，像是干涸的血迹。</p><p>“嗯……看起来有人在这里长期住过。”胡彦卓用脚尖踢开脚边的铁皮罐头盒。</p><p>盒身上印着早已停产的压缩饼干商标。</p><p>罐头盒滚到墙角，撞翻了堆成小山的空罐头盒，金属碰撞声在空旷的地下室里格外刺耳。</p><p>有人在这生活过很久。</p><p>看这个分量，至少有两三年。</p><p>希夷突然弓起脊背，尾巴炸成鸡毛掸子状，喉咙里发出威胁的呼噜声。</p><p>它死死盯着床铺下方，瞳孔缩成细线。</p><p>杨帝俯下身子，顺着猫的视线看去。</p><p>只见床底露出半截锈迹斑斑的铁链，链尾消失在砖块砌成的墙洞里。</p><p>“有东西。”杨帝蹲下身，用撬棍撬动床板。</p><p>腐朽的木头发出抗议的吱呀声，床板掀开的瞬间，一股浓烈的腥臭味扑面而来。</p><p>床底的砖块被掏空成暗格，里面散落着几截断裂的指甲，以及一本用油皮纸包着的笔记本。</p><p>胡彦卓戴上从背包里摸出的橡胶手套，小心翼翼翻开笔记本。</p><p>“你怎么连橡胶手套也有？”</p><p>“居家旅行必备嘛……”</p><p>胡彦卓解释，自从那一次跑酷被电缆绊倒，他一朝被蛇咬，十年怕井绳。</p><p>不光是害怕再次跑酷，而且对“电缆”也心有芥蒂。</p><p>橡胶手套是用来绝缘防电的，能在一定程度上减轻他的焦虑。</p><p>人类的心理便是如此神奇。</p><p>被一根电缆绊倒，摔了个骨折；却能依靠橡胶电工手套，减轻对电缆的PTSD。</p><p>杨帝心中响起一个苍老的声音：</p><p>「我尝试研究人类的想象力，但我发现那是一座迷宫，无穷无尽的迷宫……」</p><p>这话是谁说的来着？</p><p>好像是……梦里？那个老头？</p><p>不知为何，杨帝又想起了博尔赫斯和甘道夫，想起他们在梦里对他的诸多忠告。</p><p>不要踏足人类理性的边缘，不要窥探深渊。</p><p>但这些忠告，似乎对当下困境并无用处。</p><p>杨帝一边胡思乱想着，胡彦卓已经将笔记本从油皮纸中取出。</p><p>笔记本封面是已经泛黄的硬纸板，边缘因为长时间的摩擦和翻阅，略显破损。</p><p>翻开，里面的内容貌似都是些毫无依据，词语破碎，逻辑欠缺的疯言呓语。</p><p>「极光割裂绸缎般的穹顶，人鱼的鳃裂开成玫瑰……」</p><p>「锈铁锁孔正流淌银钥匙，齿轮咬住褪色的黄昏……」</p><p>「女王的低声哀诉是空虚暗淡的喜悦，所以唱吧……」</p><p>杨帝和胡彦卓面面相觑。</p><p>你有什么头绪吗？没有。真巧我也没有。</p><p>“看起来像某种史诗，或者是剧本？”杨帝捏着下巴推理分析。</p><p>很可惜，二人都不是文学专业，既欣赏不了这些无逻辑呓语蕴含的文学、艺术价值，也也无法从中窥探出任何有关耶罗符印的信息，或是这地下室秘密的线索。</p><p>胡彦卓挠了挠头：“感觉……像是精神错乱的人写的胡言乱语？”</p><p>“继续往后看看。”</p><p>往后翻页。到了中间，笔记的主人似乎恢复了些许理性，说话也有条理起来。</p><p>但仍然让人费解。</p><p>而且同时……令人非常不安。</p><p>「2011.10.15，黄斑渔游蛇，爆体。」</p><p>「2011.11.12，仓鼠，干瘪，内脏缺失。」</p><p>「2011.12.2，石膏塑像，面容缺失。」</p><p>「2011.12.30，罗非鱼，鳞片腐败。」</p><p>「2012.1.11，小白鼠，质壁分离。」</p><p>「2012.2.5，麻雀，质壁分离。」</p><p>「2012.2.29，人，死亡。」</p><p>「2013.7.19，人，质壁分离。」</p>
