# 咒怨之世

<p>走廊上的人群依旧保持着仰头的姿势，一动不动，如同被按下了暂停键。</p><p>下一秒，异变陡生。</p><p>最前排一个男生的手臂突然齐肩断裂，无声地脱落下来。</p><p>那断臂并未掉落在地，而是违背重力地悬浮起来，缓慢却坚定地朝着血月飘去。</p><p>紧接着，像是引发了某种连锁反应。</p><p>更多人的肢体开始分离——小腿从膝盖处断开，头颅滚离脖颈，胸腔无声地裂开，露出其中微微跳动的心脏和纠结的内脏。</p><p>所有这一切——手指、眼球、缠绕着肠子的腹部、一整条脊椎——都纷纷从原本的位置剥离，却没有一滴鲜血泼洒下来。</p><p>衣物软塌塌地垂落，或是空荡荡地堆叠在原地，仿佛蜕下的蝉壳。</p><p>而那些脱离的器官与残肢，则如同被无形的线牵引着，组成一道无声且缓慢上升的洪流，朝着天幕那轮巨大的血月汇聚而去。</p><p>它们沐浴在那粘稠的红光里，模糊了原本血腥的细节，只留下各种蠕动的深色轮廓，构成一幅极其引人生理反胃的图景。</p><p>杨帝面无表情地看着这万物归寂般的献祭，仿佛在观察一场与己无关的恶劣天气。</p><p>实际上，他正仔细观察着那些飘向血月的残肢内脏。</p><p>他发现，它们在脱离主体后，细胞活性非但没有衰减，反而在一种未知力量的作用下维持着一种诡异的旺盛生命状态。</p><p>“有趣。”他低声自语，完全无视了眼前的恐怖景象，“能将离体器官长期、低成本地维持活性……这简直是基础医学保存技术的巨大突破。”</p><p>在他见识过的高等文明中，固然有更先进的生命维持技术，但无一不需要耗费天文数字的能量和稀有材料。</p><p>而眼前这种基于“咒怨”和“血月”的廉价活性维持方式，虽然邪门，却展现出一种令人惊叹的性价比。</p><p>“重要的是廉价啊。高级文明的那些东西，成本都太高了。”</p><p>杨帝徒步穿过被血色笼罩的城市，熟悉的旧校舍区域。</p><p>保安亭里只剩下一条花短裤，一件洗得浆白的保安服，手机上还在进行金花炸鱼游戏。</p><p>但屏幕中央游过去的并不是黄金大鲨鱼，而是一条赤橙色的狐狸。</p><p>天空始终悬挂着那轮血月，未曾天明。</p><p>杨帝耗时七八小时，徒步走回家。推开门，客厅里静悄悄的。</p><p>只有父亲常穿的夹克和母亲的外套，软塌地搭在椅背上，里面的人早已不见踪影，想必也化作了飞向血月的碎片。</p><p>他沉默地站了一会儿，然后拿起之前那柄从室友脖子上取下，还沾着锈迹和血污的剪刀，毫不犹豫地对着自己手腕狠狠一割。</p><p>动脉血喷溅而出。</p><p>但下一秒，伤口处的血肉以肉眼可见的速度疯狂蠕动愈合，皮肤光洁如初。</p><p>此刻，杨帝清晰地感知到，体内沉睡的圣人级力量已彻底回归。</p><p>“迷宫迷宫迷宫……盒子盒子盒子……沙盘沙盘沙盘……”</p><p>杨帝身形一闪，已出现在宇宙深处一颗古老的克尔黑洞之前。</p><p>这是一颗高速旋转的带电黑洞，其特殊的结构形成了内外两层事件视界。</p><p>高速旋转的带电黑洞因角动量和电荷的引力效应，会将奇点拉伸并产生内、外两个临界边界，外层视界是物质无法逃逸的边界，内层视界则是物质可接近奇点的边界。</p><p>他凝力于手心，一拳轰出，外层事件视界应声破碎，露出其间扭曲的时空。</p><p>他一步踏入这内外视界间的禁忌区域。</p><p>未有片刻停留，再次挥拳，更为狂暴的力量直接撕裂了内层事件视界，瞬间抵达了那理论中一切物理法则失效的奇点所在。</p><p>他将自己彻底暴露在失去视界保护、极度危险的“裸奇点”那无法用言语形容的光辉辐射之下。</p><p>而后，汇聚全部圣人之力，对着这宇宙结构最脆弱的原点，轰出了最终一拳——</p><p>直接轰爆了时空本身！</p><p>一道无法描述的裂隙骤然绽开，其后并非星辰，而是绝对的“无”。</p><p>杨帝身影一闪，瞬间投入其中，脱离了这方宇宙，踏入了宇宙之外的无垠虚空。</p><p>他看到了自己的10^95个分身。</p><p>分身也在看着他。</p><p>他正处在耶罗分形的眼眸处。</p><p>好消息，这个宇宙仍然是“幽荧界”。</p><p>坏消息，幽荧界被拉到了“耶罗分形区”。</p><p>杨帝立于虚空，望着下方那被强行嵌入耶罗分形结构中的幽荧界，胸中郁垒难平，猛地发出一声响彻虚空的怒吼：</p><p>“耶罗——！给老子滚出来！”</p><p>话音未落，他面前的空间如同幕布般被轻轻掀开一角。</p><p>一只穿着明黄色长袍，人立而起的狐狸，像土地公觐见齐天大圣般，凭空闪现，还故作姿态地掸了掸并不存在的灰尘。</p><p>它抬起爪子，拱了拱手：“白杨大帝，何事动怒？唤小狐前来有何指教？”</p><p>杨帝指着那被血色笼罩、残肢升空的幽荧界，声音冰冷：“指教？我倒要问问你！为何总是如此肆意篡改宇宙众生的命运？将他们玩弄于股掌之间？！”</p><p>耶罗狐狸脸上的嬉笑收敛了些，它耸耸肩，狐尾一甩，指向下方的惨剧：</p><p>“大帝，这您可冤枉好狐了。这轮血月，这漫天飞的零件，真不是我干的。”</p><p>它语气变得略显正经：“是这个宇宙自己走到了尽头。它的‘灵异’基底已突破虚空能容忍的临界点，幽荧界正在自发迎来它的‘魙败’。”</p><p>“在最后一刻，此宇宙唯一的那位本土圣人，在彻底被咒怨吞噬前，向所有能接收到讯息的存在发出了绝望的祈愿。”</p><p>耶罗顿了顿，“他自愿献祭自身的一切，只求换取一个……能让此宇宙文明痕迹得以保留、而非彻底湮灭于魙败的‘好结局’。”</p><p>耶罗摊了摊爪子，一脸“我只是个帮忙的”无辜表情。</p><p>“我，恰好响应了他这份代价高昂的祈愿，接手了这份‘好结局’的定制订单罢了。”</p><p>“你自己看。”耶罗的爪子再次点向幽荧界。</p><p>杨帝目光天旋地转，感知迅速回溯。</p><p>无限虚空，无穷维度，无垠时空，可观测宇宙，双鱼-鲸鱼座超星系团复合体，银河，太阳，蓝星，华夏，稷海……</p><p>随着它的动作，那轮吞噬一切的血月光芒微微流转，其上的景象似乎开始发生某种微妙的变化。</p><p>随着耶罗的指引，杨帝目光投向稷海市远郊的一片荒芜烂尾楼区。</p><p>突然，其中一栋烂尾楼底部积满漆黑污水的电梯井轰然炸开！</p><p>砖石碎块、扭曲钢筋、凝固水泥如同天女散花般向四周爆射。</p><p>烟尘弥漫中，一个中年男人的身影冲天而起，悬停在烂尾楼上空。</p><p>他额前散落几缕显眼的白发，身形精悍，手中赫然紧握着一柄吞吐着混沌神光、威压惊天的巨斧——那分明是“灵茶山乂斧”一类的至宝！</p><p>那男人激动得浑身颤抖，仰天狂笑，声震四野：</p><p>“哈哈，我终于回到蓝星了！！”</p><p>竟然是那个钓鱼佬！他特么的携极道帝兵归来了！</p>
