# 出发，南下

<p>伊芙不愧是上千岁的老油条。</p><p>像每个学术派精灵一样，在上千年岁月里，她一直在勾心斗角、尔虞我诈的环境中长大。</p><p>她必须绞尽脑汁，透视人心，探索语言和文字的极致先锋边缘——</p><p>才有可能让自己的论文通过圣树的查重。</p><p>以及圣树学会评审团的答辩。</p><p>伊芙：“你说，国王曾‘暗中派人去调查’，但那些探子要么被自杀，要么被失踪，对吧。”</p><p>瑞弗维尔：“没错，这是原话。”</p><p>伊芙：“所以他这次不再派遣忠诚、且有专业训练的探子，而是派一个毫无间谍能力、脑子不太聪明、只要失踪就立刻会引起教廷警觉、论战斗力甚至打不过‘杀手兔’的——图书馆馆长，来做连专业探子都做不到的事。”</p><p>瑞弗维尔：……</p><p>伊芙：“国王给你准备的路线‘偏僻难行’，但是‘能最大程度避开教廷的眼线’，对吧。”</p><p>瑞弗维尔：“他是这么说的。”</p><p>伊芙：“结果，你一路上走来，平均每天遭遇两次刺杀。”</p><p>瑞弗维尔：……</p><p>伊芙：“国王声称，‘密道是先王为应对战乱所建’，‘这一百年来都没教廷的人走过’，对吧。”</p><p>瑞弗维尔：“那条过道确实很破旧。”</p><p>伊芙：“所以，隧道里头的邪神原初之眼雕像，不是教廷的人放的，而是国王的人放的？”</p><p>瑞弗维尔：……</p><p>“等等，有个疑点。”</p><p>瑞弗维尔举手，终于抓到一丝不对劲。</p><p>他指了指伊芙的口袋：“那个原初之眼的雕像……如果教廷堕落成祂的走狗，那他们理应也收藏了部分祂的画像、雕塑。可是为何，他们在见到我手里这个石头雕像后，反应如此剧烈？”</p><p>这一回，学术老油条伊芙，也陷入了深深的思索。</p><p>许多学术精灵做实验，做学术调研，都习惯用“结果”去证明自己预设好的“结论”。</p><p>而不是从数据推导出结论。</p><p>但伊芙强迫自己抛开所有先入为主的想法，重新审视这个疑点。</p><p>然后，她得出合乎理性的结论。</p><p>“嗯……小概率事件？”</p><p>“小说都不敢这么戏剧性。”</p><p>“那我确实想不出来，情报量太少。”</p><p>伊芙清了清嗓，“咳咳，总之此地不宜久留，教廷的援兵随时会来，我们该走了。”</p><p>瑞弗维尔也终于打消了回圣古琉斯王城的念头。</p><p>经过精灵小姐这么一捋，他也猛然发现，国王的问题和疑点确实很多。</p><p>说国王和教廷是一伙的，不是没可能。</p><p>真奇怪，自己此前一直没想到。</p><p>“你啊，放进冒险小说活不过一章，丢到悬疑小说就是第一个死的。”伊芙哂之。</p><p>瑞弗维尔说：“至少我们知道了卡利斯托并不会复活，那只是圣光教廷用史莱姆作妖。只是不知道，他们到底要用史莱姆模拟巨龙，到底在谋划什么……”</p><p>杨帝看向自己认识两天的老朋友：“所以你不继续向东走了？你要和伊芙去‘星渊井口’？”</p><p>瑞弗维尔眼神有些躲闪地点点头。</p><p>他似乎被什么东西迷住了。</p><p>也许是想探究清楚，圣光教廷究竟在谋划些什么。</p><p>杨帝对此也是深有同感。</p><p>短短一年前，他还是个普通的神州理工男，同样沉迷于解开一个又一个谜题。</p><p>而且，有了伊芙作为“保镖”。</p><p>瑞弗维尔暂时不用担心被教廷“身后中20刀自杀”了。</p><p>“杨帝你？维尔维尔说你失忆了，感觉记忆恢复些了吗？你跟我们一起，还是另有打算？”伊芙对杨帝说。</p><p>“我？”地球的穿越者陷入思索。</p><p>原本瑞弗维尔谎称自己是旅行商人，杨帝也谎称自己失忆了，你瞒着我，我亦瞒着我～不好意思唱起来了。</p><p>总之情况就是，双方一个将对方当保镖，另一个将对方当导游，各取所需。</p><p>而现在，伊芙强势插入。</p><p>她战力如此强大！知识如此渊博！剥夺了杨帝的保镖职位，也剥夺了瑞弗维尔的导游职位。</p><p>但换个方向想，她既能当瑞弗维尔的保镖，又能当杨帝的导游——简直是双赢！两个人赢了就是双赢。</p><p>所以，他也选择跟着异世界土著人类和土著精灵，一同去往星渊井口。</p><p>……</p><p>中土大陆，广袤无垠，地形地貌复杂多样。</p><p>如果异世界点出了无线电广播技术和晶体管显像技术，他们不出50年，必定会发展出一期黄金档节目——《地理·中土》。</p><p>大陆的西部，是一片广袤的平原。</p><p>土地肥沃，河流纵横交错，滋养着无数的城镇与村庄，是中土大陆人口最为密集、文明最为昌盛之地。</p><p>人类最大的国度，圣古琉斯，坐落于此。</p><p>北方，是连绵起伏的山脉，高耸入云，终年积雪覆盖，寒冷刺骨。</p><p>东方是一片密密麻麻的丛林，那里是精灵的领地。据说这片森林，都是同一棵树垂下的不同气根，自始至终只有一棵树——圣树。</p><p>南边是丘陵，尽头是海洋，海洋岸边则是白色石英滩，鸟不拉屎之地。</p><p>中央，是末日火山所在之处，焚灭天空之龙陨落的地方。</p><p>而“星渊井口”，夹在中央末日火山、南方石英海滩之间。</p><p>山脉过渡到海滩，中间是一堆乱石丘陵。</p><p>同样是鸟不拉屎，但同时适合居家旅行与杀人越货的好地方。</p><p>越过这片乱石丘陵，去往星渊井口，得走个八九百公里，凭三人的脚力，怎么也得走上十天半个月。</p><p>三人之中有两人开了挂。</p><p>其一是精灵伊芙，她像海豚，左右脑可以轮流用，左脑休息，右脑活动；右脑累了就睡觉，轮到左脑思考。</p><p>另外一个是杨帝，他体能越练越好，越好越走，越走越练，越练体能越充沛。</p><p>瑞弗维尔转着粗气跟在后面。</p><p>他虽曾经担任游侠一职，但后来又当了十年图书馆馆长。</p><p>众所周知，担任文员工作很容易让人体脂率上升。</p><p>此时的他，额头上豆大的汗珠不断滚落，湿透了衣衫，脚步也显得愈发沉重。每迈出一步，都仿佛屠杀了一个亲人。</p><p>他哭丧着脸：“歇歇吧二位，再这么下去，走到星渊井口，我恐怕要瘦成一道闪电咯。”</p><p>杨帝看着瑞弗维尔可怜兮兮的模样，对伊芙说道：“伊芙，咱们就休息会儿吧，瑞弗确实有些吃不消。”</p><p>于是，养尊处优的图书馆文员终于得到喘息机会。</p><p>而杨帝，也计划通。</p><p>他以尿遁等重大借口支开瑞弗维尔，来到坐在树干上晃着脚丫的伊芙面前。</p><p>“能助我回忆一下灵能法术吗？您示范一遍，我就能回忆起来了。”</p><p>这是他的原话。</p><p>杨帝记忆超群，过目不忘，他脑子里还有一万多本书没读。</p><p>这是因为他精神力量极度强大，心灵反作用于物质，大脑、神经相关功能也强得离谱。</p><p>只要眼前这精灵愿意示范一遍。</p><p>他就能记住灵能的流动和振动模式。</p><p>伊芙却没有立即搭话，她目光在杨帝身上打量。一人类一精灵，恰如令狐冲和风清扬。这是个剑与魔法的世界，但也不能没有江湖。</p><p>“据我所知，我没见过如此干净、但又不算太彻底的失忆者。你记得如何说话、吃饭，你记得人类、矮人和精灵，但你遗忘了灵能法术、遗忘了巨龙、遗忘了这个世界的势力，就像……”</p><p>杨帝喉结鼓动。</p><p>伊芙已经出现在他身后，耳垂旁低声，在他鼻尖勾起阵阵柑橘清香：“杨帝，你身上有一种独特的气味……你知道吗？不像是这个世界的，味道。”</p>
