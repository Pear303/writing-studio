# 爱与正义

<p>杨帝众人回到地面。</p><p>准确来说是，海面的一艘轮船上。</p><p>这是艘硕大无朋的楼船，长500米，宽200余米，船上盖满了饭店，形形色色，琳琅满目。</p><p>从船头到船尾，一层又一层建筑鳞次栉比，仿佛一座漂浮在海上的繁华城镇。</p><p>船中部最高的建筑，五层楼高，是一座复古风格建造的酒楼。</p><p>朱红立柱，金黄琉璃瓦，鎏金匾额上“无极大排挡”五字在满天悬挂的灯笼下闪烁微光。</p><p>文艺地说，一副牌匾似是将整片星河都凝在了笔锋里。</p><p>字写得很好，只可惜内容有些，有些过于接地气了。</p><p>此次穿越小风波引发的冲突告一段落。</p><p>为维护区域和谐稳定，经友好协商，异界强者白杨大帝·杨帝、月斑银鲈·鱼尊、守望者·59改三位同志，与本地的图书馆保安·天机子、客栈掌柜·青丘白璃、酒楼厨子·中山无极、道观扫地僧·渡厄禅师、中学老头·血手屠魔就区域治理相关事宜达成共识。</p><p>双方于槐安（凡界纪年法）2185年1月1日签署《互不侵犯合作协议》。</p><p>协议签署后，五位土著大能从深化文化互信角度出发，设宴款待异界来宾。</p><p>席间，土著代表就凡界风俗文化进行系统介绍，围绕饮食礼仪、节庆传统、社会治理等维度展开交流。</p><p>双方在轻松友好的氛围中，就文化互鉴、民生发展等议题交换意见。</p><p>“白杨大帝，一身灵能波动很是奇异啊。”有人暗戳戳说杨帝不对劲。</p><p>他不羞不恼地回答：“其实……也许是我的灵能水平溢出了？”</p><p>由于杨帝“话术”超过千亿级别，他这说法一时间唬住了所有人。</p><p>“哦哈哈，白杨大帝还深谙凡界的计算机之道。”</p><p>“咳咳，那么问题来了，几位本地朋友——我应该去哪里才能见到大名鼎鼎的‘归墟大帝’？”杨帝吃完一笼红烧凤爪，擦擦嘴如是说道。</p><p>“这……”</p><p>原本有说有笑，吃吃喝喝的几位土著强者，顿时噎住了。</p><p>土著势力有五个人，而且是东道主；对面只有三人，都是异界不速之客。</p><p>但他们能达成平等交流协议，最根本原因，还在于力量上的不平等。</p><p>本宇宙方面，唯一的大帝已经死去。</p><p>而异世界来客那儿，有一位白杨大帝。</p><p>当个体力量之间的差距太大，由言语和幻觉构筑起的道德律令，便会化作可有可无的纸糊枷锁。</p><p>在高武世界，讲道理确实不如讲物理。</p><p>而纸终究是包不住火的。</p><p>当此之时，“东道主中的东道主”酒楼厨子·中山无极（毕竟这是他掌勺的酒楼）站起身，即将要沉痛的说话，讣告归墟大帝之死。</p><p>这时候，图书馆保安·天机子在他对侧，对他微微摇头。</p><p>同时眼珠子急速抖动，用眼神传达了一个意思：</p><p>「厨子，你要把归墟大帝的死讯告诉他？」</p><p>酒楼厨子·中山无极也通过瞳孔的有规律缩放，回复道：</p><p>「消息终究会走漏，他们迟早知道我们的大帝已经陨落。那时候再承认真相，反而落了个隐瞒欺诈的名头。」</p><p>「更何况，如果对方真的有歹意，那么，提前或滞后几天让他知道大帝陨落的消息，对结果都没有影响。」</p><p>「——如果以归墟大帝作为参考，我估计，整个灵界加起来，都堪堪只能重创他。」</p><p>「就算重创他了，然后呢？灵界元气大伤，被七千二百年就闹一次的域外天魔势如破竹地入侵，摘取胜利果实？」</p><p>「如今我们所能做的，只能寄希望于对方没有歹意。」</p><p>「并希望白杨大帝仍被世俗道德所约束，能被我们的爱与正义所感动。」</p><p>图书馆保安·天机子面色保持陪酒的微笑。</p><p>只是，他太阳穴有轻微的青筋凸起。</p><p>「厨子……你是说‘爱与正义’？！」</p><p>「没错，我们只能放手一搏，用爱感化。」</p><p>「不我是说，你真相信爱与正义？？」</p><p>「很久以前就不信了。但如果有必要，我还可以重新信一信，反正不要钱，多少信一点。」</p><p>「不，你还是没懂我意思。我是说——如果你连自己也无法信服‘爱与正义’，又该如何说服白杨大帝？你得重新安排计划。」</p><p>酒楼厨子·中山无极瞳孔微缩：「天机子，你是说……」</p><p>「没错，让我们之中最单纯，最纯粹，仍然相信爱与正义的‘那个’上。」</p><p>「不只是要单纯和纯粹，而且必须机灵，其智性超过我们五个的平均水准。」</p><p>「同时，长相必须比较柔美和谐，至少不应该是你我这样的耄耋老头。」</p><p>中山无极与天机子眼神交锋。</p><p>「你莫不是想说……」</p><p>「没错，你我所想的应该是同一个。」</p><p>二位智者目光同时扭转，注视客栈掌柜·青丘白璃那双总含着水光的杏眼。</p><p>……</p><p>以上眼神交流发生在电光石火间。</p><p>酒楼厨子·中山无极清了清嗓子，左手微微指向客栈掌柜·青丘白璃：“远道而来的白杨大帝和另外两位阁下，本次跨世界文化与历史交流，实在是受益匪浅。不过，关于归墟大帝之事，我认为以这位妖族的视角描述，也许会更客观，更全面。”</p><p>狐种大妖·客栈掌柜·青丘白璃沉重地放下茶杯，伸手指向自己的下巴：“啊？我？什么？”</p><p>她是最单纯的那个。</p><p>她同时被天机子、中山无极认为大智若稚。</p><p>酒楼厨子·中山无极轻咳一声，朝青丘白璃使了个眼色：“白璃掌柜在凡界待得最久，对归墟大帝的事迹知之甚详。同时她是妖族，和归墟大帝并非同一种族，能够站在一个第三方视角评价他所做的事。青丘，劳烦你带白杨大帝一行，去了解归墟大帝的生平事迹？”</p><p>杨帝做阅读理解一向满分。</p><p>“等等，归墟大帝……已经陨落？”</p><p>“是的，白杨大帝，这就是我们要告诉你的沉痛事实——在不久前，归墟大帝陨落了。他突然仙逝，驾鹤西去。”</p><p>杨帝不语，只是吃水晶虾饺。</p><p>但他内心已掀起骇浪惊涛。</p><p>异世界这么危险？大帝级别的实力，也会突然暴毙。</p><p>还是得谨言慎行，不能随便浪。</p><p>否则，阿巴和59改也可能会莫名其妙暴毙。</p><p>届时，能和他一块浪的朋友就越来越少了。</p><p>“大帝是怎么死的？”杨帝问。</p><p>酒楼厨子·中山无极：“非常诡异。当日他就在凡界吃吃喝喝，喝水呛死了。”</p><p>坐在杨帝一旁的阿巴喷茶。</p><p>她前身是条鲈鱼，笑点和人类不一样。如果有人告诉她“某某喝水呛死了”，就好比有人类听到“某某神尊来到地球被大气压压扁了”一样，有种莫名的荒诞喜剧效果。</p><p>但大帝陨落，这可不是喜剧。</p><p>这件事意味着，她老大也可能有生命威胁。</p><p>阿巴强行绷住，对杨帝说：“老大，这里的喝水呛死应该是个比喻手法，意思应该是‘浅水淹死老师傅’。譬如，大帝在与某位大敌的战斗中，被对方偷袭了后庭或其他弱点……”</p><p>酒楼厨子·中山无极叹气：“并非比喻。归墟大帝，在凡界喝白开水的时候，死了。”</p>
