# 原初之战：技术迭代

<p>三十六教廷修士分散开来，向无限机兵左右而去，随后在空中如蜜蜂跳起8字舞。</p><p>杨帝一时间被迷惑住。</p><p>这是在做什么？某种仪式？某种大型术阵？</p><p>不对。他瞳孔骤缩。这些教廷修士在转移他注意力。</p><p>不知何时，机兵周身空间泛起蛛网状裂痕。</p><p>他已经被法术效果击中了。</p><p>突如其来的攻击千万根钢针贯穿灵魂，他在意识海中，看见自己的“灵”正被强行抽离出机兵躯体。</p><p>原初之眼，在大地之下通过史莱姆集群，对他远程施法。</p><p>将机兵视角拉到1800公里外的圣古琉斯王城，扫视过相当于三座现代图书馆总量的信息，杨帝证实了这一点——这一次，原初之眼交给圣光教廷的“百年任务”是……</p><p>构建“将灵质从物质中剥离”的法术体系。</p><p>在圣光教廷的秘密研究记录中，他们称之为——“十环禁术·质壁分离”。</p><p>他们投入大量人力物力和时间，终于研发出该项成果。</p><p>原初之眼便攫取了教廷的技术。</p><p>然后在这一刻，这项10环法术发挥了其唯一的历史使命——将“杨帝”和“机兵”分离。</p><p>“啧……”杨帝还能努力维持，但撑不了多久。</p><p>必须尽快想到应对方案，否则，他会因“质壁分离”，被弹出无限机兵……</p><p>这一次，竟没有触发进化适应！</p><p>因为“无限机兵”是一种外在的附魔，相当于给杨帝装上假牙。</p><p>原初之眼的法术，是将“假牙”与杨帝剥离，而不是拔他的真牙，没有对杨帝本尊造成伤害。</p><p>耶罗大仙也是通过这种方法，虽然无法泯灭杨帝本身的主体性“现实”，但能将他外在的“现实”消抹殆尽。</p><p>原初之眼恰巧绕过了杨帝最大的优势！</p><p>“真是棘手。”</p><p>杨帝只能用类似“冥想”的方法，将自身“灵”部分稀释于机兵附魔的“灵”，延缓质壁分离。</p><p>但这种做法并不长久，他很容易就会半只脚踏入“主体溶解”，也就是自身的现实丰度，被无限机兵稀释太多。</p><p>必须在「时间机器」校准完成之前，想好下一步计策。</p><p>「警告，世界线变动。」</p><p>整片天地倏地扭曲成漩涡状，而后迅速恢复平整。</p><p>当杨帝视线重新清晰，他看见，“星渊井口”处多出来了个圣光教廷建设的基地，此基地目测超过三百年历史。</p><p>原初之眼……祂再度改变了过去。</p><p>杨帝瞬间读取完这座新基地的所有信息，心中微微一颤。</p><p>这次，祂再度利用圣光教廷的力量，迭代了新的技术——“史莱姆极速增殖”、“超级再生”。</p><p>在数千代选育和优化过后，最新品种的史莱姆，每吞噬一份灵能，就会分裂出成倍数量！</p><p>只要环境灵能充裕，它们就能源源不断、数量以指数级别暴涨。</p><p>下一刻，杨帝的机兵能量读数传感器发出尖锐蜂鸣！</p><p>星渊井口，是中土大陆最庞大的灵能地脉枢纽。</p><p>此刻，它化作沸腾的灵能漩涡，宛如大地睁开了一只贪婪的眼睛，将方圆千里的灵能疯狂吸入！</p><p>原初之眼要降临世间。</p><p>教廷的基地原本只有寥寥数百史莱姆。</p><p>此刻，它们如同被投入热油的水滴，接触灵能的瞬间便炸裂成无数个体，转眼间便在井口上方形成了遮天蔽日的暗红色云海！</p><p>杨帝迅速用机兵的武库压制它们！</p><p>“轰轰轰！”粒子炮疯狂倾泻能量，每一道光束击中史莱姆群都会引发相当于10亿吨TNT当量的剧烈爆炸！</p><p>然而，爆炸搅动的灵能涟漪，反而成了史莱姆增殖的养分。</p><p>每被炸碎10个个体，其它史莱姆能利用不稳定的灵能环境、同伴的碎块，重新拼凑出9个新的个体。</p><p>疯狂增殖的熔岩史莱姆，带着熔岩高温和腐蚀性黏液，如雨点般砸向机兵！</p><p>顷刻间，天空被数以兆亿计的史莱姆铺满。</p><p>熔岩史莱姆组合而成的阴云中央，出现一道狭长如裂谷的缝隙。</p><p>而后，裂谷分开——祂睁眼了。</p><p>轰——嗡——</p><p>凌厉无匹的精神攻击刺入杨帝的意识！！</p><p>……杨帝毫发无损。这点精神杀伤，对现在的他而言，只是挠痒痒。</p><p>但他仍然操控着无限机兵，做出“极力隐藏但仍然遮蔽不住痛苦”的行为。</p><p>“原……初……之……眼……停下……啊啊啊！”</p><p>看起来极度痛苦的样子。</p><p>杨帝一边演戏，一边查看机兵系统。</p><p>「系统警告，时间机器模块尚未校正完成，下次跳跃可能导致更严重的不可控后果，剩余时间25秒。」</p><p>他需要拖延时间。</p><p>但原初之眼直接识破了他的谋划。</p><p>祂放弃精神攻击，转而调动起由整个星渊井口灵能制造的史莱姆集群，凝聚出一道覆盖了整个中土大陆南部的法术。</p><p>杨帝望向仿佛随时要坍塌、正在熊熊燃烧着的天空。</p><p>那是一道庞大到令人绝望的“圣光系”法术。</p><p>数以兆亿计的熔岩史莱姆，在灵能洪流中剧烈燃烧。</p><p>整个中土大陆南部的丘陵、原野，同时发出悲鸣，岩层在重压下扭曲成诡异的螺旋，如同被无形巨手攥紧的纸团。</p><p>天穹像是被撕开的灯罩，泄露出刺目白光，刹那便将整片天空熔铸成液态的白银。</p><p>炽烈圣光中央，腥红的原初之眼仍然在注视杨帝。</p><p>杨帝在努力维持，不让自己的“灵”从无限机兵身上被“质壁分离”。</p><p>所以，此刻已无力再招架起防御。</p><p>但无限机兵的防御力本身高得突破天际，而且，他可以逃。</p><p>“机兵短距跃迁机动！”</p><p>他瞬息出现在39000公里外。</p><p>这里，是异世界这座行星的外围轨道，比同步轨道高大约500公里。</p><p>在这处地方，杨帝终于能短暂地喘息片刻。</p><p>他已经想明白原初之眼的大战略布局。</p><p>——祂以毫不逊色于杨帝的速度，在疯狂进化，升级！</p><p>祂不断将未来的成果传递到过去，推动自己的势力实现超高速技术迭代。</p><p>牛顿是“踩在巨人肩膀上”。</p><p>而此刻，通过不断将未来的成果发送向历史，让巨人反复踩在巨人肩膀，这座“巨人之肩”的高度会急速拉升。</p><p>在极高速的技术迭代过程中，原初之眼不断弥补史莱姆躯壳的弱点，增强己身力量。</p><p>电光石火的思考间隙，原初之眼的熔岩史莱姆集群调转枪口，将圣光法术射向位处外太空的杨帝！</p><p>“差之毫厘，失之千里。”</p><p>杨帝此刻位置比同步轨道还要高500公里，他与异世界行星的自转角速度，有一个微小的偏差值。</p><p>正是这个偏差值，让原初之眼凝聚的巨型圣光法术擦着机兵外壳掠过，在宇宙中拖曳出一条燃烧着灵能的尾迹。</p><p>但原初之眼本身也会预判。</p><p>杨帝最终目的，是借着极其遥远的距离，将机动位置的闪避效果放大。</p><p>毕竟，隔1米用枪打一个会动的苹果，和隔1000米用枪狙击会动的苹果，后者苹果存活率远高于前者。</p><p>「系统警告，时间机器模块尚未校正完成，下次跳跃可能导致更严重的不可控后果，剩余时间15秒。」</p><p>「警告，世界线变动。」</p><p>空间如同被无形巨手搅动的墨汁，扭曲成诡异的漩涡。</p><p>“过去”被重写，“现在”被修正。</p><p>微毫之间，杨帝突然发现，自己沐浴在那道圣光法术攻击之中。</p><p>原初之眼将校准好的弹道、将杨帝的闪避方式，都发送到了过去。</p>
