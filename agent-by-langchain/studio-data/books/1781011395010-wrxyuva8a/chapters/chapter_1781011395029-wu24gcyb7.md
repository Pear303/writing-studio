# 耶罗符印

<p>杨帝一字一句读着这些学术论述，心中涌动震撼。</p><p>自己正经历着一种极为罕见的现象，一种感觉系统的异常觉醒，仿佛大脑的信息处理机制突然失效，让他得以窥见世界的全貌。</p><p>人的大脑存在某种“限制器”。</p><p>而现在限制器被解除，就好像水库被炸。</p><p>那些以往被忽略的细微之处，如今如同泄洪的潮水般，涌入他的大脑。</p><p>原本大量信息处理工作，是由潜意识来完成的。</p><p>而现在，他把潜意识搬到了明面上来。</p><p>但他能“感觉”到，“搬到了明面上”的潜意识，也仅仅占全部潜意识的1%左右。</p><p>占比听起来很少。</p><p>实际上，已经相当于10万bit/秒的信息量。</p><p>为何潜意识不再“潜”，而是如此强势地流露于表层？</p><p>即使只是流露了1%……</p><p>“难道……是因为和希夷的精神交流？”杨帝喃喃自语。</p><p>他还记得，自己在目睹希夷之后，“精神”属性暴涨一万多点。</p><p>精神，是指人的意识、思维、情感等主观世界。潜意识，则是指是指人类心理活动中未被觉察的部分。</p><p>而在杨帝从希夷那儿获取的“神秘学”中，潜意识似乎与精神有分不开的联系。</p><p>精神包含意识和潜意识两个层面，潜意识中内容会通过梦境、直觉、灵感等方式进入意识层面……</p><p>如果“精神”足够强大，是否就能让“意识”有足够的“空间”，来容纳“潜意识”？</p><p>如果将原本人类未能察觉的心理活动、信息处理，全部搬上台面来……</p><p>那么杨帝就不止能通过锻炼，成为“体魄”上的主宰者。</p><p>还能通过精神修炼，成为“灵魂”的掌控者！</p><p>文明其精神，野蛮其体魄，物质与心灵同步发展。</p><p>他越发确信，自己确实走在新人类进化的道路上！</p><p>杨帝继续看向手机，搜集更多信息。</p><p>手机浏览器检索记录里，堆砌着神经学论文关键词。</p><p>他看到一篇《前额叶皮层与信息过滤机制相关性研究》，注意到作者单位标注着稷海理工，但点进去，看不懂。</p><p>“大儒的文章看不懂，那看看民科的？”</p><p>他喃喃自语，关掉学术搜索框，在普通搜索栏输入“超越五感的认知”。</p><p>页面跳转到某个冷门论坛，置顶帖用鲜红字体写着《人类潜觉释放的七十二种征兆》。</p><p>点进去看，却发现全特么是怪力乱神。</p><p>什么修仙、宇宙能量、天线信号锅……</p><p>麻了，学术论文不是他专业，所以看不懂。而民科呢，又比风水先生还玄乎。</p><p>杨帝关掉手机，瘫坐在人体工学椅上。</p><p>“唉，没有更多有效信息了……”</p><p>他耳膜捕捉到纤维摩擦的窸窣声。</p><p>那是张明远的大腿肌肉收缩时，涤纶裤管与工学椅皮革接触产生的振动。</p><p>杨帝后颈寒毛感应到气流扰动，视网膜边缘映出舍友站起身、走过来时带起的衣摆褶皱。</p><p>他光速熄掉锁屏，手机倒扣在桌面上。</p><p>“老张，突然凑过来干嘛？”</p><p>张明远抓了抓后脑勺，然后很严肃地推了推眼镜：“你不对劲。”</p><p>“？怎么说？”</p><p>他压低声音：“你自从七天前急性肠胃炎，整个人跟通了高压电似的，开始疯狂锻炼，还整天跟我说什么进化、新人类。”</p><p>杨帝点点头：“所以呢？”</p><p>张明远突然面色狰狞，痛心疾首：“我现在终于破译出你让我传达的信息了！杨老帝！你好无耻！背叛了哥们，背叛了革命！”</p><p>这回轮到杨帝懵逼了。</p><p>“怎么说？什么意思？”</p><p>“老帝，你找到了女朋友，摆脱单身状态，是为‘进化成新人类’。你天天从早到晚借口说‘出去锻炼’，回来时候大汗淋漓，其实都是和刚结交的女友贴贴去了！”</p><p>他做出“真相只有一个”的动作。</p><p>杨帝：……</p><p>杨帝：“你说得对，我已经找到了可媲美找到女朋友的终极乐趣。”</p><p>这种“终极乐趣”指的是以肉眼可见速度，不断修炼变强。</p><p>他现在能理解，那些修仙小说里的修仙者，为什么总是不择手段修炼升级，好像人生的意义就在于升级。</p><p>直到他自己尝试过，终于有了深切体会：</p><p>升级，是会上瘾的。</p><p>“背叛了哥们，背叛了哥布林族群……”张明远背着手，嘀咕着，一边摇摇头，“啧啧啧”咂着嘴走开。</p><p>杨帝也坐回自己的椅子上。</p><p>窗外的蝉鸣层次分明，他能分辨出东南角第三棵梧桐树上某只蝉的鞘翅正在高频震颤。</p><p>日光灯管的电流声分解成五十赫兹的脉冲波，非常低沉，但仍然被他捕捉到了。</p><p>工学椅扶手的仿皮涂层在掌心摩擦出静电，发梢与衣领的静电吸附声如同昆虫振翅般清晰。</p><p>五感极度敏锐的状态，他已经快适应了。</p><p>恍然间，杨帝还嗅到一股铜腥味。</p><p>像是在海底被浸泡多年，突然被发掘出土，那股混杂着淤泥和寒冰的气息，古老、深邃，又充满了未知。</p><p>他环顾四周，房间内的摆设依旧，似乎并无异样……</p><p>不，有个地方，有问题。</p><p>在如今这种“五感超敏”的状态下，任何一点微小的感受，都会被潜意识捕捉，将感受完整地呈送给大脑。</p><p>而此刻，杨帝隐隐约约捕捉到那股潮湿气味的来源——书堆。</p><p>其中有一本书，看样子是应该是他读到三分之一的《务虚笔记》，书的内部有不正常隆起，像是、像是垫了块东西进去。</p><p>他不记得自己书签有这么厚。</p><p>“什么东西……”他猛地抽开那本书。</p><p>深深的恐惧袭上心头。</p><p>那是一块铁饼，一枚半个巴掌大小的铁饼。</p><p>三条螺旋纹路在白炽灯下泛着暗黄色幽光，似三条盘踞的衔尾蛇。</p><p>耶罗符印……</p><p>这枚从池梦里带出来的铁饼，此刻正散发着青铜器出土时的阴冷潮气。</p><p>据希夷所说，会给人带来不幸。</p><p>分明是盛夏时节，却感觉有冰碴顺着脊椎滑进尾椎。</p><p>“踏马这东西居然跟着我回到了现实？”</p><p>杨帝已经隐隐约约感觉到，他平静的生活结束了。平静日子，从此到头。</p><p>从今往后，喧嚣和波折将会占据余生的绝大多数时间。</p><p>也许从明天开始的生活，就会充斥宇宙人、时间客和超能力者，还有隐匿于世界阴暗角落，窥探众生、蠢蠢欲动的古老存在。</p><p>凉宫春日来了也会直呼受不了。</p><p>……</p><p>“我应该做点什么，摆脱这块耶罗符印。”</p><p>“掂量一下，只有半斤多重，不锈钢差不多的密度。”</p><p>“把它埋了。不错，就这么办。”</p><p>宿舍的狭窄空间仿佛成了囚笼，杨帝急于逃离，去找一个能让这符印永远消失的地方。</p><p>把“铁饼”埋了——这是他唯一念头。</p><p>「遇到讨厌的事情时，逃跑并不是失败，而是一种胜利。」——阿库西斯教义</p><p>「犹豫不决时，无论选择什么都会后悔，因此应选择当下让自己更轻松的方式。」——还是阿库西斯教义</p><p>把这玩意扔了，简洁了事，一身轻松。</p><p>扔掉就能摆脱了吗？应该……能吧？</p>
