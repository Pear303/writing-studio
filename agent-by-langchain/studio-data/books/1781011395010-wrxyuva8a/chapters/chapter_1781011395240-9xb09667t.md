# 少年遗梦 罢了

<p>【我从你觉醒能力那一刻就一直盯着你，你是我投注的潜力股。】</p><p>【如今继续让你存在下去的代价，已经超过沉没成本。】</p><p>【编撰你的命运，没有剩余价值了。】</p><p>【让我为你书写结局……】</p><p>【……】</p><p>消毒水的味道像一层黏腻的薄膜，糊在杨帝的鼻腔里。</p><p>他坐在医院走廊的塑料椅上，额头烫得能煎鸡蛋，视线里的一切都在扭曲——白墙在波动，顶灯成了模糊的光斑，连护士走过的脚步声都像隔着水传来，闷沉又遥远。</p><p>护士的声音，让杨帝想起寂静岭里的肿脸护士。</p><p>前一天吃的那份拼优饭，大概是坏了。</p><p>上吐下泻之后，高烧就缠上了他，梦里更是天旋地转，一会儿是绝地大战西斯，一会儿是穿着非常卫生的主厨制作出特别垃圾的饭食。他像个失控的陀螺，在无数光怪陆离的世界里撞来撞去。</p><p>张明远勉强算得上七分之三个好人，把他送来了这医院。</p><p>杨帝大概是烧糊涂了。</p><p>身体像被什么东西牵着走，脚步虚浮地踏出医院，又不知怎么晃进了附近一栋写字楼。</p><p>电梯数字跳得飞快，他盯着那不断变化的红色数字，眼睛酸胀。</p><p>门开了，走廊铺着灰色地毯，尽头的房间门没关严，里面传来嗡嗡的说话声。</p><p>推门进去。</p><p>房间不大，挤着十几号人，都围着中间那个男人。</p><p>那男人看起来三十五六岁，穿着不合身的绸衫，脸上堆着油滑的笑，正唾沫横飞地说着什么。</p><p>“……我耶罗大仙，上通天道，下晓轮回，只要诚心信我，你们的灾和难，全都能改。</p><p>“你们的不幸人生于我而言，只是如同话本，翻手覆掌即可修编、撰改……</p><p>“……乱你心者，必为魔障。慈悲用错地方，只会伤害自己。你心慈手软，一拖再拖，最后只会酿成大祸……</p><p>“……有个老婆婆问我，为什么她忙碌了大半生还是一无所有？我问她：你为什么不早点找我更易命运呢？……”</p><p>周围的人立刻狂热地附和，有人举着钱往前面递，嘴里念叨着“感谢大仙”“求大仙保佑”。</p><p>几个仙风道骨的干部在一旁维持秩序，外套下藏着撬棍和电击枪，眼神倨傲。</p><p>杨帝的脑子像一团被煮烂的浆糊，那些声音钻进耳朵，变成尖锐的噪音。</p><p>他只觉得烦躁，非常非常烦躁。</p><p>梦里那些光怪陆离的碎片还在闪现，眼前这伙人的嘴脸，和梦里某个扭曲影子重叠在一起。</p><p>“吵死了。”</p><p>他低声说，声音嘶哑得像砂纸摩擦。</p><p>没人理他。耶罗大仙还在慷慨陈词，一只手比划着，仿佛在编织什么虚无的网。</p><p>杨帝在反应过来之前，身体已经行动。</p><p>他的动作快得不像个高烧病人，带着一种混沌中的狠劲。</p><p>最先遭殃的是离他最近的那个黑西装干部，还没反应过来，就被杨帝一记直冲拳砸在面门上，鼻梁骨断裂的脆响混在惊呼声里。</p><p>杨帝没停，转身、踹腿，动作粗暴又直接，每一下都带着高烧催生的狂躁。</p><p>房间里顿时乱成一团，哭喊和惨叫此起彼伏，几个“干部”很快就躺在地上，捂着肚子或胳膊，疼得蜷缩成一团，没一个能再站起来。</p><p>混乱中，耶罗大仙脸上的笑容僵住了，色厉内荏地吼道：“你是谁？！保安！保安呢！”</p><p>杨帝一步步朝他走去，眼神里没有焦点，只有一片烧出来的迷蒙赤红。</p><p>他抓住耶罗大仙试图推过来的手，反手一拧，骨头错位的声音让周围的信徒吓得尖叫着后退。</p><p>在所有人惊恐的注视下，杨帝低下头，以野兽的姿态狠狠咬住了耶罗大仙的喉咙。</p><p>温热的血涌进嘴里，带着铁腥味。</p><p>耶罗大仙的眼睛瞪得滚圆，喉咙里发出嗬嗬的漏气声，身体软软地倒了下去。</p><p>直到这时，外面才传来急促的脚步声和警笛声。警察冲进来时，看到的就是这样一幅景象：满地重伤的人，群众们躲在角落瑟瑟发抖，倒在血泊里的“耶罗大仙”。</p><p>还有那个站在中间，浑身是血，耳朵红得惊人，眼神依旧迷糊的杨帝。</p><p>冰冷的手铐铐住手腕时，杨帝打了个哆嗦，像是终于感觉到了冷。</p><p>他张了张嘴，想说什么，最终只发出一声模糊的呓语，然后脑袋一歪，差点栽倒在地。</p><p>高烧还在继续，只是这场由食物中毒引发的混乱，已经彻底脱轨。</p><p>【编撰众生命运的剧作者，永恒地死去。】</p><p>【……】</p><p>哪有什么独断万古白杨大帝。</p><p>只不过是一个高烧烧糊涂了，吃了变质外卖上吐下泻，脑子被烧成一锅浆糊，梦见光怪陆离幻象的倒霉蛋。</p><p>……</p><p>……</p><p>冰冷的审讯室灯光惨白，打在杨帝脸上。</p><p>他蜷在铁椅子上，手腕被铐着的地方磨得生疼。</p><p>高烧还没退，额头的温度烫得吓人，耳朵更是红得像要滴出血来。</p><p>刚才那阵狂躁的力气好像被抽空了，只剩下骨头缝里透出来的酸软和一阵阵眩晕。</p><p>“姓名！”</p><p>“杨……帝。”声音嘶哑，喉咙干得像砂纸。</p><p>“年龄！”</p><p>“……”</p><p>“说话！年龄！”</p><p>“二十……不……我不确定。”他努力聚焦，眼前警察的脸还是重影的。</p><p>警察皱着眉，翻看着刚送来的初步报告。</p><p>“食物中毒引发的高热惊厥，伴随严重电解质紊乱和精神混乱……有暴力倾向……没有精神成瘾物的吸食历史……”</p><p>他抬头，眼神锐利地盯着杨帝，“说说吧，怎么回事？为什么冲进那个‘心灵健康交流中心’，打伤嫌疑人，还……还咬死了那个叫‘耶罗大仙’的男人？”</p><p>杨帝的脑子嗡嗡作响。</p><p>心灵健康交流中心？耶罗大仙？</p><p>那些模糊的画面又涌了上来：扭曲的白墙，肿脸的护士，还有梦里冰火交织、光怪陆离的旋转……</p><p>最后，定格在穿着绸衫，唾沫横飞的男人脸上。</p><p>那张脸，和梦里某个扭曲的影子重叠，发出刺耳的噪音。</p><p>“吵……”他下意识地低喃，“太吵了……他……一直在吵……”</p><p>警察敲了敲桌子：“谁吵？说清楚点！动机是什么？是不是跟他们有仇？”</p><p>仇？杨帝茫然地摇头。</p><p>他只记得那份油腻腻的拼优饭，吃完后肚子翻江倒海的绞痛，然后就是无止境的高烧。</p><p>再然后……好像是张明远模糊的声音，消毒水的味道。</p><p>还有……混乱的尖叫，带着铁锈味的温热液体涌进嘴里……</p><p>“我……”他舔了舔干裂的嘴唇，眼神依旧迷离，带着高烧特有的浑浊赤红，“我好像……咬了什么……很烦人的东西……像梦里那个……编故事的……”</p><p>编故事的？警察和旁边的记录员对视一眼，眼神里写满了“这怕不是个精神病”。</p><p>记录员刷刷地写着：“嫌疑人思维混乱，表述不清，疑似高热导致精神障碍及行为失控……”</p><p>“带他下去，看好了。等医生确认他神智能做笔录再说。”</p><p>警察挥挥手，语气带着疲惫和一丝不易察觉的怜悯。一个因为吃坏肚子发高烧，烧到产生幻觉和暴力倾向，闯进一个搞迷信+传销+鞋教活动的窝点，稀里糊涂咬死个自称“大仙”的传销组织主要嫌疑人……</p><p>虽然为民除害，但这是笔糊涂账。</p><p>杨帝被两个辅警架起来，拖向拘留室。</p><p>脚步虚浮，每一步都像踩在棉花上。</p><p>走廊冰冷的空气让他打了个寒颤，耳朵的赤红在昏暗的灯光下异常显眼。</p><p>拘留室的门哐当一声关上。狭小的空间里只有一张硬板床和一个蹲坑。</p><p>杨帝蜷缩在冰冷的床板上，高烧带来的寒意和拘留室的阴冷交织在一起，让他止不住地发抖。</p>
