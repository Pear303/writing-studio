# 杨帝梦境

<p>两尊伟岸的存在，完成了这宇宙间最顶级的“清理”工作。</p><p>龙傲天从未存在过。</p><p>「鱼尊。」</p><p>“干哈呢？”</p><p>「杨帝阁下……茧内的气息波动……仍在以无法解析的速率暴涨。」</p><p>「其增长曲线已完全脱离本机所有预设模型及观测上限……超越了‘幂塔级’的描述范畴。」</p><p>「本机已完全无法理解其触及的境界。」</p><p>万古鱼尊俊美得不真实的脸上依旧淡漠，但那双仿佛容纳了万古星空的眼眸深处，似乎有极其细微的涟漪荡开。</p><p>祂没有立刻回应，只是静静地看向宇宙核心处，那永恒悬浮的白金色巨茧方向。</p><p>就在这短暂的、因五九改的话语而出现的微妙间隙——</p><p>“哼。”</p><p>一声极轻、却又仿佛蕴含着无穷道韵的冷哼，如同冰锥刺破寂静。</p><p>万古鱼尊的身影没有消失，反而瞬间由虚化实！</p><p>祂那如玉的手指（偶尔会显露出鱼鳍本相）并未收回，反而在冷哼响起的刹那，对着五九改那厚重的装甲，看似随意地、遥遥一点！</p><p>嗡——！！！</p><p>“滋啦——！！！”</p><p>五九改的装甲爆发出刺目的光芒，随即大片大片地黯淡、崩解。</p><p>「警报！资讯防御模块失效！存在性偏移护盾失效！」</p><p>嗡！嗡！嗡！</p><p>五九改的炮口并未对准鱼尊，而是瞬间在其庞大的钢铁身躯周围，展开了由无数分形结构构成、复杂到足以让超级文明智脑瞬间死机的防御护盾！</p><p>万古鱼尊的身形骤然分化，化作亿万道虚实难辨的鱼影，每一道鱼影都蕴含着不同的道韵真意，或刚猛、或阴柔、或生发、或寂灭，从四面八方、从不同的法则层面，如同星河倒卷般，向着核心的五九改冲刷而去！</p><p>轰轰轰轰轰——！！！</p><p>五九改的机械核心疯狂运转，分形护盾矩阵功率全开，不断生成、湮灭着防御与反击的方程式。</p><p>万古鱼尊的亿万鱼影则灵动缥缈，在逻辑的缝隙中游弋、冲击。</p><p>「万古鱼尊，你我之争已逾百亿年，有何意义？」</p><p>“有了力量，非但不知行善，反而要放纵恶的发展？”</p><p>「我继承白杨大帝/灭圣绝盗君阁下的遗志。」</p><p>“我是他的克隆体，为何你不听我的呢？”</p><p>两个理念迥异，却又因守护同一个梦境宇宙而不得不共存的老朋友，又一次在解决掉共同的麻烦后，熟练无比地打了起来。</p><p>这几乎成了漫长岁月中，他们之间一种扭曲的交流方式。</p><p>……</p><p>与此同时，宇宙核心，白金色的巨茧之内。</p><p>杨帝的意识，并未因沉睡而停滞，反而在感知整个白杨世界。</p><p>那浩瀚如星海、沉重如黑洞的上层信息，被他缓慢而凶险地解析着。</p><p>但在此之上，他更庞大更本源的意识，如同覆盖整个宇宙的网，正在感受着这个世界，由他的“领域”演化而成的世界。</p><p>他在记录。</p><p>记录每一个星辰的诞生与寂灭，记录细胞的分裂与凋亡。</p><p>记录每一道文明的兴衰轨迹，记录蚁群的迁徙与争斗。</p><p>记录宇宙法则的细微脉动，记录身体内激素的分泌与代谢。</p><p>记录每一道因果线的纠缠与断裂，记录神经网络中电信号的传递与湮灭。</p><p>万古鱼尊与守望者·五九改，那惊天动地的碰撞，其引发的法则涟漪、能量潮汐、因果扰动……</p><p>一丝不漏地，传递到了杨帝的感知之中。</p><p>潜水视奸，并非他本意。</p><p>那足以让顶尖准圣，或超级智脑都为之崩溃的战斗信息流，在杨帝的意识里，却如同两滴落入数据海洋的水珠，仅仅激起极其微弱、精确到小数点后亿万位的涟漪。</p><p>直到无数无数个这样的“涟漪”，汇合成滔天巨洪。</p><p>巨浪冲溃了堤坝，信息冲破了某个阈值。</p><p>杨帝突兀感知到在生死兴衰中挣扎、欢笑、悲泣、毁灭的亿万生灵！</p><p>现实溶解……</p><p>但不是杨帝溶解于现实，而是整个世界溶解于他。</p><p>他感觉自己正在坠落，或者说——整个宇宙正在反向坠落进他的毛孔。</p><p>世界被塞进自己的体内……</p><p>他看见自己胸口插着把锅铲，他看见戴着防毒面具、身穿橙色生化服的主厨挥舞菜刀。</p><p>他看见看见驾驶机甲的绝地大师，他看见转生三十三次的西斯尊者。</p><p>他看见很久以前的朋友穿白大褂，他看见很久以前的挚友穿红短袖。</p><p>他看见一个浸泡在缸中的大脑。</p><p>他会不会正在一场梦中？</p><p>哪有什么白杨大帝，哪有什么耶罗大仙，都不过是一个吃了不干净外卖后的少年，死前最璀璨的幻想罢了？</p><p>梦境也是现实，现实即有意义，何必严格区分？</p><p>杨帝不去理解，只是去感受它。</p><p>他同时感受到帝王将相的野心，与蝼蚁求生的本能。</p><p>一个孩童在战火中失去父母的尖锐哭嚎，与一颗超新星爆发时核心物质被极致压缩的无声嘶鸣，以完全相同的痛感，刺入他的心。</p><p>他是在那个泥泞战场上被流弹撕碎，肠子流了一地的年轻士兵。</p><p>他是那颗被贪婪的戴森云工程层层包裹、光芒被榨取得奄奄一息的恒星。</p><p>他是那只工蚁，在庞大的巢穴网络中遵循着信息素传递的指令机械劳作，直到被天敌的巨颚拦腰剪断。</p><p>他是一艘失去动力的殖民船残骸，维生系统早已停摆，最后一名船员在绝望中看着舷窗外永恒的黑暗。</p><p>他是万古鱼尊分化出的亿万鱼影之一，共同围攻五九改。</p><p>宇宙的一切信息不再需要区分内外、主客、宏观微观、生死荣枯。</p><p>它们本就是一体两面，是同一枚硬币不可分割的正反。</p><p>杨帝就是硬币。</p><p>众生之相，万物流转，无分彼此，皆归于“我”。</p><p>构成“杨帝”这个存在的边界，彻底消融了。</p><p>一种难以言喻的“连接”感，一种涵盖一切、承载一切的“容器”感，一种既是观察者又是被观察者的绝对“同一”感，取代了所有。</p><p>第八识·阿赖耶识。</p><p>这概念如同宇宙大爆炸的原点，无需理解，自然浮现。</p><p>承载一切众生业力、记忆、无明种子的集体深层意识之海。宇宙万有信息流转、存储、生灭的终极服务器与数据库。超越个体灵魂的深层背景板，一切存在得以显现的共同根基。</p><p>他即是这海，这服务器，这根基。</p><p>所有的痛苦、挣扎、毁灭、欢欣、创造、存在……</p><p>它们是海水的律动，是服务器运算时散发的余热，是根基自身稳固的震颤。</p><p>那曾撕裂意识、来自亿万生灵的极致痛苦，此刻被解构、还原——它是“痛”，但更是“存在”本身的一种状态反馈。</p><p>白金色的巨茧内部，那沉睡的存在，长长的睫毛，微不可察地颤动了一下。</p>
