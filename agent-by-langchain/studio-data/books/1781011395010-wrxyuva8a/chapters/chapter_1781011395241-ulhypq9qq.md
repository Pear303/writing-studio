# 耶罗诡计 砝码

<p>杨帝的意念在虚空中震颤：“耶罗，你为何没死？”</p><p>狐狸轮廓的宇宙分形骤然凝定，亿万星河漩涡构成的狐眼深处，一粒微尘般的宇宙骤然亮起。</p><p>身着绸衫的人形狐影自光中浮现，悬浮于杨帝的绝对视点之前。</p><p>“第一次让你杀我，你说太过敷衍。”</p><p>耶罗的声音直接在杨帝认知中回荡，带着几分无奈。</p><p>“所以我重写剧本——让你鏖战舰队，粉碎领域，吞噬灵能，登临阿列夫一。让你踏遍艰险，轰轰烈烈地‘杀死’我。可你为何还是不满？”</p><p>杨帝语调冰寒：“我要的是真正杀死你，彻底抹除，而非你剧本里规定好的，舞台上的表演式死亡。”</p><p>狐形宇宙分形的呼吸凝滞刹那，无限灵能宇宙的光辉都随之黯淡。</p><p>“好。”耶罗的声音褪去所有油滑，只剩下跨越维度的疲惫，“那我就让你杀，真正的杀。”</p><p>身影消散的瞬间，由10^95个宇宙构成的狐形分形骤然“活”了过来。</p><p>它那条由螺旋宇宙链织成的巨尾猛地抽向杨帝所在的视点。</p><p>杨帝纹丝不动，径直迎向抽来的宇宙链巨尾。</p><p>无声的湮灭在接触点爆发。</p><p>巨尾从触碰处开始，寸寸化为绝对虚无。</p><p>狐形分形剧烈痉挛，构成它躯体的每一个宇宙泡，其存在的逻辑都被彻底否定，无声无息地归于乌有。</p><p>它的形态开始崩解：尾巴消融，利爪湮灭，庞大的身躯浮现出巨大的空洞。</p><p>那些翻涌的宇宙弦风暴，如同被橡皮擦掉的铅笔痕迹，迅速淡去。</p><p>最终，只剩下那双由亿万星河漩涡组成的巨大狐眼，盛满哀怨地凝视着杨帝。</p><p>最后的“观察”——杀死耶罗的关键。</p><p>狐眼的光辉骤然凝固。亿万星河漩涡停止了旋转。构成眼眸的无量宇宙中，属于“耶罗的观察”被杨帝彻底吞噬。</p><p>狐眸瞬间失去所有光彩，如同骤然熄灭的星辰。</p><p>庞大的眼眸结构，连同其内部承载的亿亿万万宇宙，凝固成最终形态，却彻底丧失了活性，僵滞在虚空中，化作一幅冰冷死寂的巨大浮雕。</p><p>狐眼最后闪烁了一下，终归于永恒的沉寂。</p><p>耶罗大仙，永恒地死去了。</p><p>这一次，是真的。</p><p>……</p><p>“我真的死了，你为何还是不信？”</p><p>耶罗大仙在杨帝面前说，语气有些许羞恼。</p><p>只不过，它不再是之前绸衫翩翩的从容，而是由沸腾的灵能强行拼凑而成，边缘不断溃散又重组，像信号不良的全息投影。</p><p>它悬浮在杨帝前，看着他，那由破碎光影构成的面孔上，羞恼清晰可辨。</p><p>“看啊！”它的声音直接在杨帝的认知里震颤，带着被冒犯的尖锐，“剧本演完，我按照你的要求，把‘死’写得清清楚楚、轰轰烈烈！我甚至把自己写进了最终的死亡句点！”</p><p>他虚幻的狐耳因激动而剧烈抖动，搅动着周围的虚无能量：“当耶罗大仙写下‘耶罗大仙死了’的时候，耶罗大仙就真的死了！这是铁律！是这场游戏我能给你最彻底的死亡证明！”</p><p>“可你！你这个固执的、不肯承认现实的观察者！你的‘不信’是什么？是覆盖规则的橡皮擦？是重启程序的指令？</p><p>“你的怀疑本身，就是拒绝承认我的死亡，就等于在宇宙的根源处，强行续写了一个‘耶罗大仙还活着’的脚注！</p><p>“所以，我回来了！不是我想回来！不是我还有后手！是你！是你那该死的、不肯放下的怀疑，像一根锚链，硬生生把我从‘绝对的无’里拖了回来！</p><p>“你亲手杀死了我，却又用你的‘不信’亲手复活了我！杨帝，告诉我，这到底是谁的剧本？</p><p>“这是谁的舞台？谁在扮演那个无法接受结局的、可悲又可笑的观众？！”</p><p>杨帝大怒。</p><p>“你不肯真的去死就算了，竟还PUA我！”</p><p>“并不，杨帝。是你……”</p><p>杨帝猛地往后一撤，像是被踩了尾巴的猫，双手往腰上一叉，胸口剧烈起伏着：“你胡说！我才没有！是你自己赖着不走！”</p><p>“我明明把你眼睛都弄灭了！那么大的浮雕摆在那儿，你自己说死透了的！现在又跑出来怪我？你就是说话不算数！”</p><p>说着说着，他声音里带上了哭腔，像是受了天大委屈的小孩，手指着耶罗那团破碎的影子乱晃：“你就是想骗我！故意让我杀了一次又一次，看我笑话！我不管！这次你必须真的消失！立刻！马上！”</p><p>“你不消失我就……我就一直盯着你！让你连碎片都拼不起来！”</p><p>耶罗只是悬在那里，破碎的光影构成的面孔没什么表情，只有那点怜悯像沉在水底的石子，清晰又安静。</p><p>它既没辩解，也没动怒，任凭杨帝像闹脾气的孩子般又喊又跳，只是默默看着，像看着一个攥着断线风筝不肯撒手的孩童。</p><p>杨帝闹了半天，突然捂住大脑。</p><p>「精神+1」</p><p>「■■■+1」</p><p>属性上涨了阿列夫一。</p><p>许久，他才缓缓站起身，看向耶罗大仙。</p><p>“你刚才，把我的精神扭曲成一个‘幼童’？”</p><p>“没错。但现在好像不起效了，你的一切都恒定在一个基准态，实在是离奇。”</p><p>耶罗大仙合上「万业之书」，耸耸肩，“这虚空中任何伤害，似乎都只能对你生效一次。”</p><p>“这么做有何目的？”</p><p>“只是觉得有意思，一个幼稚的杨帝，却坐拥能够杀死一个虚空恶意邪神的力量。”</p><p>耶罗大仙身后的狐尾自旋起来，似乎是耶罗表达某种正向意境的手段。</p><p>杨帝不知该说什么好。</p><p>“怎么，我尾巴能自旋很奇怪吗？你还‘不知该说什么好’？”</p><p>耶罗大仙脱下兜帽，耳朵也转起来：“其实不止尾巴，我耳朵也能自旋。”</p><p>杨帝：“你怎么知道……我在想什么？”</p><p>他浮于虚空，将目前所能想到的所有杀死耶罗大仙的方法，都已经否定掉了。</p><p>无效，全部无效。</p><p>如果连自己的吞噬也无能为力，那么其他攻击和杀伤……也不够看。</p><p>“并非‘不够看’，如果你希望，我可以给你营造更宏大的声光效果。”耶罗打断杨帝的思绪。</p><p>杨帝挥手撑开“白杨世界”将自己包裹。</p><p>他不希望耶罗能继续肆无忌惮地阅读他的思想。</p><p>“你的脑子是我的跑马场，但并不是我在阅读你的思想，而是我规定了你的思想以何种方式表达。”</p><p>耶罗又说话了，精准预判了杨帝所想，同时也预判了此时他对杨帝的预判，因为狐就是耶罗大仙，狐就是法力无边的话本编撰者，剧中人杨帝要如何理解老狐深邃的思想？</p><p>狐却貌似有一点感到棘手。</p><p>对杨帝的叙事，正在走向失败。</p><p>失败是显而易见的。杨帝先是免疫了“都市”和“克系”的叙事，然后是“西幻”、“奇幻”、“仙侠”、“规则怪谈”、“卡牌”、“种田”、“日常”、“无限流”……</p><p>能够框住他的叙事越来越少。</p><p>耶罗浑身颤栗，那是身体和思想因兴奋而不自主做出的反射。</p><p>没事，以上种种都只是磨刀石罢了。</p><p>反正他的「终极目的」已经达成。</p>
