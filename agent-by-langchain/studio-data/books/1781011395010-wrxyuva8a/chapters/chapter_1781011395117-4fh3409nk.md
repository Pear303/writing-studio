# 欲戴其冠

<p>“所以，你经过这一通我完全看不懂过程的瞎推导，认为‘虚境’存在驾驶机兵的方法？”</p><p>伊芙面无表情地看着杨帝。</p><p>杨帝点点头：“不是没有这个可能。”</p><p>“……杨帝，你转过身去。”</p><p>这一次，杨帝失了个大误——他全部心神沉浸于思考如何启动“无限机兵”，就对伊芙的奇怪要求放松了90%的警惕，背对着她站立。</p><p>精灵抡起法杖，在狭窄的空间内极速一挥，法棍末端达到1.5马赫线性初速度。</p><p>狠狠击中杨帝脖颈的侧后方。</p><p>那处连接着脊椎和脑袋，布满神经与血管的脆弱节点。</p><p>杨帝眼前炸开刺目的白光，膝盖重重磕在金属地板上。</p><p>他想伸手想去抓伊芙的裙摆，但对方灵巧地躲开。他想怒吼别退！喉间却涌不上半点声音。</p><p>原本单臂力量5吨，现在只剩1000斤……这点力量，就连抓住头大笨象都费劲。</p><p>5吨=1万斤。</p><p>杨帝只能踉跄着撞向金属壁，脖颈剧痛让眼前阵阵发黑。</p><p>他咬牙转身，死死盯住苦笑的伊芙。</p><p>“你的肉身，比我第一次见你时还要强大得多。挨了我这一击，居然还有行动能力。”</p><p>只是蛐蛐脊椎神经受激、大脑血压骤变，还不足以让杨帝彻底晕倒。</p><p>灵能法术只能算身外之物，他从没敢松懈锻炼自己的肉身！</p><p>“杨帝，但我还是希望你好好睡一觉。”</p><p>“伊芙，我的命运由我掌控，而不是你。”</p><p>杨帝发现自己能说话了，单臂力量也缓慢恢复至1500斤。</p><p>他刚放完狠话，下一刻，伊芙的法杖已经带着破空声横扫过来。</p><p>精灵笑道：“这机兵是我先摸到的，你别想着驾驶，杨帝。”</p><p>“精灵的小短手够得着驾驶舱吗？”杨帝侧身躲过这一杖。</p><p>当时极速掏出三块砖头，以极限的1.7马赫砸向伊芙的法杖、持法杖的手、以及脑门。</p><p>近战并非精灵强项，但此地过于狭窄，地面上又太过混乱，不适宜使用魔法。</p><p>她一下子就被拖进杨帝的节奏，不得不脱手扔掉法杖，用护盾抵御住砸向她脑门的板砖。</p><p>杀手兔均速1.5倍音速，就已经在中小法师群体中享有“杀手”之名。</p><p>但对高阶法师而言，这般速度不过尔尔。</p><p>伊芙身为超限级别精灵法师，即便在如此狭窄且混乱的空间，应对起来虽有些狼狈，却也不至于毫无还手之力。</p><p>只见她那没有被发卡束住的头发腾空而起，凝聚成两个沙煲大的拳头！</p><p>一记大力金刚手，另一记黯然销魂掌，对着他劈头盖脸轰去！</p><p>杨帝的体术、体能因为精灵最初那一闷棍，至少下降了80%，他躲不过去。</p><p>只能举起双臂交叉，强行格挡，两团沙煲大的头发震得他臂骨碎裂、虎口发麻。</p><p>但毕竟肉身经历千捶百炼，他甚至没有甩甩手臂，便一个标准跑酷翻滚，迅速滚到伊芙身后扯住她头发！</p><p>即使是在打架斗殴中，扯女孩子头发也是不太放得上台面的行为。</p><p>但杨帝实施的是无限制格斗术——疯狗拳！根本不在意什么“武德”。</p><p>下一眨眼，他却被伊芙反手用一把荧光闪闪的短刀抵住喉结。</p><p>刀身上，还刻印有RL两个字符。</p><p>这边刀子不仅闪烁寒光，锐利至极，而且有隐隐的灵能光芒涌动。</p><p>这把瑞弗维尔的短刀，还被奥拓施加了两大附魔。</p><p>一个是“海之眷顾”，另一个是“击退II”。</p><p>对普通的短刀而言，“击退”绝对算不上好附魔。比方在砧板上切肉，切着切着，肉突然被击飞了！</p><p>但在此刻的颤斗中，杨帝因为这把刀，吃了大亏。</p><p>他像是砧板上的鱼肉，不断被精灵击飞！</p><p>伊芙每一次挥动短刀，那股附着在刀身上的“击退”之力，就如同一股无形的巨力，将杨帝整个人猛地推开。</p><p>“击退”附魔非常特殊，无论对方吨位多少，吃水多深，都能击飞几米。</p><p>面对杨帝，伊芙的斩击相当于凭空多出数千斤力道。</p><p>对于还没100%缓和过来的杨帝而言，这无疑是雪上加霜。</p><p>他身体屡屡不受控制，向后飞去，重重撞在机兵内部的金属壁上，发出沉闷声响！</p><p>但这声音主要来自于他的肋骨、脊柱振动，而不是机兵本身的材质发声。</p><p>在常规情况下，当有强大的冲击力作用于物体表面时，物体往往会通过振动来分散和缓冲这股力量。</p><p>就像敲响的钟，外力敲击使钟体振动从而发出声音，这是因为钟体在试图通过振动来应对敲击的能量。</p><p>而振动，会“发声”。</p><p>不发声，则几乎无“振动”。</p><p>机兵的装甲，似乎不会因杨帝身体撞击，而发生明显的物质振动。</p><p>能量不灭，只是转移。杨帝撞击的动能，被转化为其他形式的能量，而不是引发容易造成结构破坏的振动。</p><p>换言之，构成机兵的材质，拥有无与伦比的卓越防御力。</p><p>——第20次被打飞到机兵装甲板上的杨帝如是想到。</p><p>这挺机兵，很符合他身为21世纪地球男性青年的审美。</p><p>暴力，坚硬，庞大，棱角分明。</p><p>唯一的缺点是，圣树预言过，驾驭机兵者，能否再回到现世，只能由虚无缥缈的命运所决定了。</p><p>……不对，圣树说，是“伊芙”的命运。</p><p>圣树自始至终都没有对杨帝说过他的“红楼判词”。</p><p>此刻，距离伊芙一闷棍敲杨帝后颈，已过去整整5秒。</p><p>他单臂力量恢复至3000斤，终于恢复了30%力量，能与伊芙打得有来有回。</p><p>杨帝也拔出“锋利III”附魔的锻钢撬棍，另一只手执生铁撞角的砖头。</p><p>锻钢撬棍格挡伊芙刺来的短刀，“铛”一声火星四溅。</p><p>他趁机将生铁撞角的砖头砸向伊芙手腕，却被对方侧身躲开。</p><p>伊芙法杖横扫而来，杨帝矮身避过，撬棍顺势勾向她下三路，同时砖头带着破风声砸向精灵的面门。</p><p>伊芙头发凝成护盾挡住砖头，短刀却已贴近杨帝咽喉，他猛地用撬棍卡住刀身，砖头狠狠砸在短刀附魔符文上，“击退”之力让他手臂发麻，却也借着反震力后跃拉开距离。</p><p>两人在狭窄空间里滚作一团，板砖、撬棍、法杖和短刀碰撞出串串火花，机兵表面却连道划痕都没留下。</p><p>杨帝一边与伊芙激烈缠斗，一边瞅准一个间隙，大声喊道：“伊芙！听我说！我是来自世界之外的穿越者，是个无牵无挂的不速之客！而你不一样！”</p><p>伊芙手中的动作微微一滞，眼神中闪过一丝犹豫。</p><p>杨帝趁机，用力一脚踹飞伊芙，将精灵踹到地下岩洞的阴影中。</p><p>二者分隔开了。</p><p>他喘着粗气，断断续续接着说：“伊芙……你只是蛐蛐十环法师，而我的进步空间比你大得多……住手吧，你已经见识过我的肉身强度了，现在的我，就算是在百米范围内硬接你‘湮灭之创’的轰炸，我也有把握自己绝对死不了。”</p><p>无论是神话，还是圣树的现场口述中，「无限机兵」都是一尊强度极高的超级兵器。</p><p>欲戴其冠，必承其重。</p><p>想要驾驭这尊超级兵器，所需付出的代价，对驾驶员的负载，必定超乎常人想象。</p><p>伊芙却一手拎法杖，从阴影中缓缓走出：“我承认你的物理强度了。但亲爱的异乡人，这个世界从来是以法爷为尊。”</p><p>九环法术·兰茵缠绕。</p><p>杨帝成了粽子。</p><p>他只能用几乎喷出火的双眼注视伊芙·柑橘，看着那精灵走到无限机兵前。</p>
