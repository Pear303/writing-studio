# 十万大山

<p>客栈掌柜·青丘白璃领着杨帝三人踏上通往“十万大山”的路。</p><p>远远望去，山峦叠嶂，连绵起伏，层层叠叠的山峰被缥缈的云雾缠绕。</p><p>峰峰相连，岭岭相接，那是大地隆起的脊梁，气势磅礴得令人窒息。</p><p>十万大山，真的是字面意义上的十万大山，有10万座海拔超1600丈（约5300米）的高山，上百条巨型山脉相互纵横穿插。</p><p>对世人而言，这种地形简直是地狱。</p><p>即使是修士，想要飞越这层层叠叠、相互交错的巨型山脉，也得费好大劲儿。</p><p>但修士的飞行，只能让自己一人跨越绵延山脉，鸿沟天堑。</p><p>凡界世人有更大的野心——让天堑变通途，让每个人都能踏上这致富的道路。</p><p>他们的目光，盯上这条贯穿十万大山的铁路修建计划。</p><p>但计划刚提出，便引来了无数质疑。地质复杂、地形险峻，资金短缺、技术落后，每一个问题都像是横亘在面前的大山。</p><p>施工的过程，艰难得超乎想象。十万大山的地形复杂多变，到处都是陡峭的山峰、幽深的峡谷和湍急的河流。</p><p>世人只能一步一个脚印，在悬崖峭壁上开凿隧道，在深谷急流上架设桥梁。每前进一米，所付出的代价都巨大得难以想象。</p><p>在工程中前期的诸多山脉中，他们都成功找到了天然隧道，极大降低工程难度。</p><p>但最后一条巨型山脉，平均海拔2000丈（6600米），其中最高峰“君士叹顶”海拔3000丈（10000米）的绝望高度，横亘在施工队面前。</p><p>寒冷，崎岖，高海拔，各种困难也如大山般横亘在他们面前。</p><p>最后，他们研发出一个巨型大圆筒，世人冠之以名“盾构机”。</p><p>凡人成功了。</p><p>槐安1453年，最后一座巨型山脉“君士叹顶”被打通隧道。</p><p>“君”“士”指众多君子、贤士曾试图跋山。但最后，都只能败退，惊叹对其磅礴险峻，根本无法登至山顶。</p><p>也有人说，“君士”通“钧世”，意为此山脉气势雄浑，如千钧之重，如万世高远。</p><p>自此，那曾经横亘在凡人面前如天堑般的十万大山，终被世人以坚韧不拔之意志与超凡智慧征服。</p><p>客栈掌柜·青丘白璃在凡界当了很多年客栈掌柜，而在此之前，她又在灵界打打杀杀许多万年。</p><p>总之，她没有做导游的经验。</p><p>狐种大妖只能略显急促，有些磕磕绊绊地介绍：“……所以，凡界世人发明出了名为盾构机的机关造物，于槐安1453年一举打通‘君士叹顶’山脉，而这条隧道被称作‘一隧通不绕尔’，意思很直白：一条隧道通了，便不用绕过山脉。”</p><p>“一隧通不绕尔”谐音“伊斯坦布尔”，令人忍俊不禁。</p><p>杨帝、阿巴、59改此时都戴上了鲜艳的红色旅行帽，帽檐上还别着写有“夕阳红”字样的小徽章。</p><p>他们脖子上挂着款式复古的望远镜，手里拿着印有十万大山简易地图的折扇，下身穿着宽松的卡其色长裤，脚蹬结实的登山鞋。</p><p>这其实都是本地旅行团提供的套装。</p><p>青丘白璃也是相似打扮，只不过下身穿的长裙，像个爱美的单纯小姑娘。</p><p>不过联系到阿巴曾提及的“相由心生”理论，杨帝知道，这只狐种大妖心态和自己一样年轻，穿点裙子也不奇怪。杨帝要是性转，以他的心态他也穿小裙子，睡觉洗澡也穿。</p><p>此刻正值黎明，一日之中最黑暗的时刻。</p><p>铁轨在黯淡星光下泛着冷光，延伸向墨色山峦深处。</p><p>那片庞大的墨色山峦，就是十万大山。</p><p>凡人的铁路，串通十万大山。</p><p>“归墟大帝一有假期，降临凡界，经常常坐绿皮火车穿越十万大山。</p><p>“他总说铁轨是凡人用钢铁织的针线，把大山和城市缝在一起，他喜欢这种稳固的联系，他欣赏凡人王朝不放弃任何一个人。</p><p>“三个月前，大帝来到凡界度假，他第一站就是乘上这里的火车。他随后在火车的终点站，十万大山最深处，待了三个月。”</p><p>话音未落，远处传来汽笛长鸣，一节挂着红灯笼的守车从弯道驶出。</p><p>车窗里飘出炒栗子甜香，盖过了火车烟囱的煤烟味，闻着并不让人讨厌。</p><p>唯二的缺点，其一是吵，其二是慢。</p><p>这是辆很普通的绿皮火车，在异界科学加持下，时速约100公里。</p><p>优点是便宜耐用，不用提前预约买票，到站直接上，当场给票钱。</p><p>缺点？都有绿皮火车了，还要什么单车。</p><p>杨帝等人跟随青丘白璃上了车。</p><p>青丘白璃并不是常见的赤狐品种，而更倾向于极地狐，有着银白色皮毛。</p><p>她虽已化形成人，脑袋与狐耳仍然保持着毛发。</p><p>额前碎发如落雪般垂落，双耳支棱在发间，毛茸茸的耳尖泛着珍珠般的光泽，轻轻晃动时会抖落几星尚未化尽的霜花。</p><p>细看时，那绒毛会随着远处火车的汽笛声轻轻颤，耳尖几星未化的霜花簌簌落，沾在发间碎雪似的刘海儿上。</p><p>车上，找了个靠窗“王の故乡”之位落座，一人一狐一鱼一坦克坐下。</p><p>他们各自点了一杯泡面。</p><p>杨帝看着泡面杯内部热气腾腾的香精面汤，喃喃道：“归墟大帝死在凡界，并且此前来到一家客栈点了一杯热的白开水，所以你们认为他喝水呛死是不是？”</p><p>“噗——”阿巴每次听见这个说法，总是绷不住会把口腔里的内容物喷出来，虽然但这件事情本身并不值得笑。</p><p>青丘白璃正用竹筷戳着泡面里的脱水菜包，闻言时头顶狐耳猛地抖了下，表示肯定。</p><p>“没错，出事前三个月他来凡间，在一家普通至极的摊子要了杯滚水。”</p><p>杨帝勺子搅着泡面，看着杯中漩涡思索。</p><p>他和她讨论案情：“那家小摊还有那杯水，都研究清楚了吗？”</p><p>实际上，我们已经把能研究的线索，案发现场的一切，都研究过了。青丘白璃说。</p><p>“那是间再普通不过的小摊铺，来来往往都是些凡人。大帝就那么安安静静坐着，要了杯水。客栈的水都是从附近山溪引来，经煮沸的，其他人喝了都无事。但他喝下之后，突然完全消失。”</p><p>从每根茶叶的成分、每滴水的来源、桌椅的材质、客栈地板的加工工艺等。</p><p>都无异常。</p><p>喝水……喝水……</p><p>「杨帝阁下，说到‘水’，我也许有猜测。」</p><p>杨帝以为，守望者·59改要喷某人“太水了”。</p><p>长着国字脸一看就很方正的男人说「在母宇宙，我与鱼尊盘肠大战、短兵交接之时，鱼尊也使用了‘领域’，其名曰‘太初柠檬浴’。在领域之内的舰队，无法与领域之外的格式塔主机联系，」</p><p>“不是柠檬浴，是溟濛域！”阿巴说完，闭上了嘴。</p><p>杨帝看向她：“你也会用领域。”</p><p>他还以为“领域”是本宇宙的土特产。</p><p>没想到在前一个世界，阿巴就已经把它研究出来了。</p><p>当时他还在那水池子里钓过鱼。杨帝还以为喷水是阿巴的种族天赋。</p>
