# 客套话、打太极！

<p>杨帝微微躬身，不卑不亢说道：“杨帝，白杨大帝，来自另一个截然不同的天地。本是偶然路过此界，却在机缘巧合之下，进入此界。听青丘白璃介绍过，您就是归墟大帝。”</p><p>归墟大帝上下打量着杨帝，眼中满是审视之色：“另一个天地？偶然路过？噢噢，幸会。”</p><p>“幸会。归墟大帝。”</p><p>杨帝微笑道：“归墟大帝，请问你知道‘阴伏流煞’么？”</p><p>他直接爆了，根本不怂。</p><p>归墟大帝保持着淡淡的微笑：“阴伏流煞？未曾听说。诸位，此地耳目众多，不如随我去灵界一谈？”</p><p>杨帝回答道：“能得东道主邀请去往灵界，此乃杨某之幸。杨某初来贵境，诸多规矩尚不明了，日后还望大帝不吝赐教。”</p><p>归墟大帝抚须大笑，周身气势收敛如常：“白杨大帝过谦了，能得异界强者共抗邪祟，亦是我界之福。”</p><p>说罢抬手一挥，一道闪烁着星辉的玉简飞入杨帝手中，“这是凡界的山川舆图与势力分布，权当给白杨大帝接风的薄礼。”</p><p>杨帝指尖轻触玉简，神识探入瞬间便觉海量信息涌入。</p><p>他表面依旧保持着得体的微笑：“大帝如此厚赠，杨某愧不敢当。”</p><p>“彼此彼此。”</p><p>“歪比巴卜。”</p><p>“叽里呱啦。”</p><p>一旁的阿巴歪着头，显然对这番你来我往的客套话摸不着头脑。</p><p>作为掌控个体伟力的鲈鱼，阿巴横行霸道划掉，阿巴直来直去惯了。</p><p>她非常看不惯繁文缛节。</p><p>在母宇宙，鱼尊拥有超级肌肉赐予的超级智慧，所以不需要看人颜色。</p><p>也不必遵循各种礼节，搞各种社交。</p><p>文明螺旋上升。在她眼里，灵能负责上升，政治负责螺旋，而科学负责扯后腿。</p><p>「阿巴，当两个世界的最高权力持有者会面时，此类言辞并非无意义的寒暄。」</p><p>「从博弈论角度，客套话是权力场中的缓冲剂，可有效降低因信息不对称引发的敌意。」</p><p>阿巴：“……啊？”</p><p>「首先，官话构建了安全对话框架，避免因直言引发不必要的利益冲突。」</p><p>「归墟大帝作为本土势力首脑，需维护统治权威；杨帝代表我方异界势力，贸然暴露太多信息和真实意图，易被针对。」</p><p>「其次，这类话术是试探性沟通，通过模棱两可的表态，双方可在不暴露底牌的情况下评估对方立场。」</p><p>「就像归墟大帝赠予舆图，表面是示好，实则是在试探杨帝阁下的深浅；杨帝阁下谦逊回应，既保留合作可能，又维持对等地位。」</p><p>「这种语言博弈本质是权力平衡，非常符合宇宙政治互动的基本范式。」</p><p>阿巴肚子发出不满的咕噜声：“直接开打不就清楚了？”</p><p>「低效且危险，极度愚蠢，满脑肌肉。」</p><p>59改一针见血指出阿巴“超级智慧”的本质。</p><p>阿巴瞳孔骤然收缩成针尖状，化作一道残影扑向59改，利齿咬碎空气发出刺耳尖啸：“敢说我蠢！看我咬烂你这堆废铁！”</p><p>「你的情绪失控指数超阈值300%，此乃典型的低等碳基生物应激反应。」</p><p>「你应该与杨帝阁下学习说话的艺术。」</p><p>阿巴冷静下来，哼了一声。</p><p>她问：“铁罐，头头是道地分析了这么多，那你从老大他们的对话中分析出了什么结论？”</p><p>「从归墟大帝主动邀约灵界会谈、赠予灵界舆图的行为，以及‘共抗邪祟’的言论、装作不知道‘阴伏流煞’的行为看，归墟大帝释放的和平交流信号强度达67.90%。」</p><p>阿巴：“那剩下的就是坏消息了？”</p><p>「咄咄逼人的可能性仅占32.09%。归墟大帝全程保持礼貌性微笑与收敛气势，尚未出现任何压迫性肢体语言或威胁性言辞。」</p><p>「但需警惕的是，他将会谈地点选在灵界，很可能占据主场优势，这为他后续谈判埋下潜在的博弈优势。」</p><p>「而且，不排除归墟大帝是要将知晓他‘释放阴伏流煞’之人……全部封口的可能性。」</p><p>「不过，这里的‘封口’仍然有较大可能性，是以和平手段进行封口，而不是更极端的灭口。」</p><p>阿巴瞪大鱼眼：“那还有0.01%的可能性？”</p><p>坦·守望者·59改·克点点头。</p><p>「约有0.01%可能性，杨帝阁下和归墟大帝会立刻、直接爆发生死决战，试图把我们全部物理灭口。」</p><p>「不过，当前双方的对话模式与信息交换行为，仍在和平交流的安全阈值内波动。」</p><p>“嘁，说了半天还是没个准数。”</p><p>阿巴甩了甩这具身体并不存在的鱼尾，转头看向远处与归墟大帝并肩而行的杨帝。</p><p>“希望老大的嘴皮子比我的尖牙更管用。”</p><p>青丘白璃也和阿巴凑在一块，旁听了59改关于政令社交的解说。</p><p>她心中透起不安。</p><p>归墟大帝真的改过自新，想要洗白自己吗？</p><p>她回想起“碎片”中看到的记忆——大帝先是歇斯底里地恨，随后是毁灭世界的强烈欲望。</p><p>但现在，归墟大帝再度现身，恢复了风度翩翩的姿态。</p><p>哪一个大帝，才是他真实的模样？</p><p>……</p><p>“斧来！”</p><p>归墟大帝喝一声，手掌出现开天巨斧虚影，重重劈下！</p><p>周遭空间如脆弱的镜面轰然碎裂，漆黑裂缝中，隐约可见璀璨灵芒流转。</p><p>青丘白璃愣了一下。</p><p>阿巴戳了戳她尾巴：“青青，咋了？”</p><p>狐种大妖摇摇头：“没什么，我只是好像没怎么见过归墟大帝用过这把斧形兵器，但应该是嗯，这三日以来，从他去的‘第三个世界’带来的土特产兵器吧。”</p><p>归墟大帝示意众人上前，解释道：“凡界与灵界虽层层相隔，却也留有通行之道，只是开启方法，历来掌握在少数大能手中。”</p><p>“竟有此事。”</p><p>“因为只有真正大能，才有足够的力量劈碎空间本身，开辟通道。”</p><p>不愧是大能才可以掌握的秘诀！</p><p>而现在，归墟大帝用一把斧子硬生生撕裂了空间，开辟出通往灵界通道。</p><p>当然可以解读成开路，也可以理解为对异界众人——特别是给杨帝下一个马威。</p><p>“诸位，请！裂缝很快会弥合。”</p><p>说话间，裂隙已经完全展开，灵界特有的灵气扑面而来，带着一丝清甜的气息。</p><p>归墟大帝率先踏入裂隙。</p><p>阿巴等异界来客对视一眼，纷纷跟上去。</p><p>杨帝是最后一个。在靠近空间裂缝时，裂缝边缘竟发出细微的“滋啦”声，仿佛承受不住某种无形的压力。</p><p>他毫不在意地“挤”了进去。</p><p>踏入裂隙的瞬间，杨帝只感觉身体仿佛被无数细小的电流穿过，周围空间扭曲变形。</p><p>空间转换，眼前豁然开朗。</p><p>踏入灵界，杨帝众人第一感觉，就是比凡界浓郁百倍的氤氲环境灵气。</p><p>眼前景象，赫然是另一个缥缈宏大、仙山琼阁若隐若现的世界——灵界！</p><p>阿巴的感知率先反馈。</p><p>“嚯！”她发出一声意义不明的感叹，“这里的灵能浓度是凡界的一百倍！”她惊呼。</p><p>“五九改，看看我还正常不？”杨帝说。</p><p>「……杨帝阁下，您仍然是处于呃，‘溢出’状态。」59改平静的语气里带着略微伤心。</p>
