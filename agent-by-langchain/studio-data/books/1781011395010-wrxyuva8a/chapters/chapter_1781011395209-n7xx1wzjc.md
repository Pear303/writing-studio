# 猫猫图样图森破

<p>甭管是T病毒，Necroa，黑光，亦或者是尸兄病毒……</p><p>那只猫，哈基米，它根本不是幸存者！它是携带者！是行走的瘟疫之源！</p><p>它之所以没被毒气杀死，是因为它早已被这种更可怕的东西寄生了。</p><p>或者说，它本身就是这种怪物的一个形态。</p><p>它之前表现出的“正常”，不过是这种恐怖存在的伪装或休眠状态！</p><p>队长猛地看向杨帝，只见对方依旧站在原地，赤裸的上半身焦黑一片，下半身破烂的黑布勉强遮掩。</p><p>他脸上没有任何惊讶或恐惧，只有一种近乎冷漠的了然。</p><p>“杨帝先生，您真的没有任何情况打算告诉我们，也没有任何工作想让我们接下吗？”</p><p>杨帝摇摇头：“没有。你们只需活下来即可。”</p><p>“噗，噗，噗。”</p><p>火鸦如同豌豆射手般，继续射击那只脑袋裂成八瓣的哈基米。</p><p>火球撞在那些搏动的血管触须上，燎起几缕焦糊的青烟，留下几个微不足道的焦黑小点。</p><p>铁砣嗷嗷叫，双手紧握那柄已经坑坑洼洼、尖端被腐蚀得发黑的狼牙棒，对着支撑着食人花的扭曲脖颈狠狠砸下，导致其HP-1。</p><p>“超！没用了！”</p><p>铁砣看着手里只剩半截的棒柄，又惊又怒又心疼——这可是他仅有的武器了！</p><p>他三次任务前，花五个积分换的不锈钢狼牙棒啊。</p><p>“队长！我们必须走了！影子她又吓晕了！说明还有更多‘人形物体’正在向这边袭来！”</p><p>眼镜拖拽着一团漆黑的影子，一边喊道。</p><p>“杨帝先生！您真的没有任何情报能告诉我们？！”</p><p>队长不再犹豫，迅速从怀里掏出个巴掌大小、闪烁着微弱蓝光的、卷轴状的物品——脱身卷轴。</p><p>这是他们小队压箱底的保命道具，一次性，能将使用者及其灵魂绑定的队友，瞬间传送至相对安全的坐标点。</p><p>“撤！立刻！目标：距离红皇后主机最近的随机安全地点。”</p><p>队长低吼着，毫不犹豫地激活了卷轴。</p><p>卷轴上的蓝光骤然爆发，形成一个复杂的、急速旋转的符文漩涡，将队长、铁砣、火鸦、眼镜以及角落里那团勉强凝聚起来的影子阴影瞬间笼罩！</p><p>“对不住了！杨帝先生！我们自身难保，而你是对剧情走向不重要的NPC。”</p><p>队长在蓝光淹没自己前，看着杨帝那赤身裸体、焦黑一片，却又平静得诡异的身影，忍不住喊了一句。</p><p>语气里带着复杂的歉意。</p><p>蓝光猛地收缩，如同被戳破的气泡般“啵”的一声轻响，消失在空气中。</p><p>整个破败的维护间，只剩下杨帝和那个脑袋裂成八瓣的哈基米。</p><p>怪物似乎对突然消失的“大块点心”感到一丝困惑，撕扯的动作停顿了片刻。</p><p>然后，它那布满螺旋利齿的恐怖口器，缓缓转向房间内唯一的“有机体”——那个下半身挂着破烂黑布的男人。</p><p>嘶嘶的尖啸声再次响起，带着对血肉的贪婪渴望。</p><p>布满倒刺和吸盘的紫黑色肉舌，如同毒蛇出洞，猛地从口器中弹出，带着腥风恶臭闪电般卷向杨帝！</p><p>就在那布满倒刺的肉舌即将触碰到他鼻尖的刹那——</p><p>杨帝的右手，极其随意地抬了起来。</p><p>指尖，虚虚一点。</p><p>啪叽～</p><p>杨帝手臂断裂，脑袋裂成橘瓣。</p><p>脑瓜子不是简单的裂成八瓣，而是以一种令人眼花缭乱、仿佛遵循着某种混沌几何学的精密轨迹，瞬间分裂成了八八六十四瓣！</p><p>“砰。”</p><p>身体砸在冰冷的金属地板上，发出闷响。</p><p>他死了。</p><p>全书完。</p><p>……</p><p>哈基米似乎也因为这突如其来的、过于“干净利落”的死亡而愣了一下。</p><p>不过很快它就想通了——我管你这的那的，有的没的，我照吃不误，哈哈哈喵喵喵桀桀桀！</p><p>困惑只持续了不到一秒。</p><p>浓郁的血腥味，和那具毫无防备、能量充沛的残躯，瞬间点燃了它最原始的吞噬欲望。</p><p>食物，来自两脚兽。</p><p>两脚兽……就是食物。</p><p>哈基米因为饥饿已经忍不住了。“食物都出自于两脚兽”，这句话的意思是，两脚兽本身就是食物。</p><p>“嘶——！！！”</p><p>布满倒刺和吸盘的紫黑色肉舌，如同发现了绝世珍馐的毒蟒，放弃了之前谨慎的试探，以比之前快上数倍的速度，猛地卷向地上那具无头的残躯！</p><p>肉舌带着粘稠的涎液和强腐蚀性的脓液，眼看就要缠上杨帝的腰腹——</p><p>警惕！</p><p>危险！！</p><p>极度危险！！！</p><p>这个看似死掉了两脚兽，身上有一股极度危险的气味！冒了出来。</p><p>它哈基米在最后一刻将舌头歪开，暴退20米，紧盯地上那具无头的两脚兽残躯。</p><p>只见脖颈和右肩断口处，无数粉嫩到近乎半透明的肉芽，如同最狂野的雨后春笋，以肉眼可见的速度疯狂地抽生出来。</p><p>它们不是缓慢的生长，而是爆发！如同被按下了千倍快进键的生命录像！</p><p>粉嫩的肉芽彼此纠缠融合，分化成骨骼、筋膜、血管、神经、肌肉、皮肤……</p><p>所有人体组织，都在以令人瞠目结舌的速度，进行细胞级精度的重构。</p><p>碎裂的颅骨、脑组织、血管、皮肤……</p><p>所有结构都在同步愈合，瞬间还原成一个完整的头颅轮廓。</p><p>右臂也迅速愈合重生！</p><p>整个过程，从肉舌僵直，到杨帝完好无损地从地上站直身体。</p><p>不过短短两三个呼吸的时间，那个两脚兽便又站在了哈基米面前。</p><p>“基米，你又哈气了。”</p><p>一股源自生命本能，前所未有的恐惧，狠狠拽住哈基米的脑子。</p><p>它那由疯狂增殖血肉构成的简单思维，无法理解眼前发生的一切。</p><p>这违背了它认知中一切关于“有机生命”的规则，这已经超出了“猎物”的范畴。</p><p>这……这感觉……像是遇到了某种更高维度、不可名状的……天敌？！</p><p>逃！必须逃！</p><p>远离这个不可名状的天敌！</p><p>“嘶……嘶嘶……”</p><p>哈基米发出一声意义不明的哈气，所有血管触须猛地收缩，以惊人的速度倒退回通风管道深处。</p><p>它要在狭窄黑暗、四通八达的管道中甩掉这个怪物！</p><p>杨帝身影如同鬼魅般冲去，刚刚重生的右手五指张开，抓向哈基米正在缩回的、一根疯狂甩动的血管触须！</p><p>噗嗤——</p><p>暗红发黑、粘稠如石油的污血混合着强酸脓液喷溅。</p><p>“嘶嗷——！！！” 管道深处传来哈基米痛苦到极致的尖啸，充满了惊怒和更深的恐惧！它逃窜的速度更快了。</p><p>杨帝低头，看着自己抓住那根断裂触须的右手。</p><p>手掌、手腕、小臂……凡是被那污血和脓液沾染的地方，瞬间发出“滋滋”的美味声响。</p><p>类似于炒菜热锅阶段，在热油上倒蒜蓉时的滋滋声。</p><p>皮肤融化，肌肉腐蚀，露出底下的骨骼。</p><p>那骨骼也在以肉眼可见的速度变得焦黑、脆弱。</p><p>咔嚓！咔嚓。</p><p>断臂连同那根扭动的触须一起，被管道内亡命逃窜的哈基米巨大的力量猛地拽走，消失在幽深的黑暗之中。</p><p>哈基米用尽最后的触须，将他的断臂也一同夺走。</p><p>它认为，只要夺走对方的身体碎片，杨帝就无法愈合了。</p><p>只能说，这只猫图样图森破。</p>
