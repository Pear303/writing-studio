# 潜意识解放

<p>这块耶罗铁饼不知何种原因，转手到了希夷那儿，然后，它像块传家宝一样，风水轮流转地传到杨帝手上。</p><p>“不过我也终究还是只是在做梦吧？只要醒来一切都会好的，总不能把梦里的东西带出去，现实生活又不是哈利波特……”</p><p>杨帝心怀侥幸。</p><p>都到这份上了，除了希望事情不要变坏，他还能做什么？</p><p>“咔嗒——”</p><p>像老式电视机切断电源的声响，混沌的虚无空间中，泛起涟漪。</p><p>杂乱无章的低语逐渐减弱，直至彻底沉寂。</p><p>就像是某种古老的机器，经历漫长运转后，终于耗尽最后一丝能量，陷入深深的休眠。</p><p>“希夷……睡着了？”</p><p>杨帝注意到希夷的异状，心中暗自嘀咕。</p><p>这个不可名状之生物，似乎在模仿他作为人类的行为和作息。</p><p>天知道这个没鼻子没眼，看起来也不会有大脑和器官的东西，为什么会需要睡觉。</p><p>杨帝有预感：自己要完全醒来了。</p><p>他没有实质性的证据，但心中就是有这个预感。</p><p>就像听见远处雷声的余音，虽没有直接看见闪电，但你也知道风暴正在逼近。</p><p>希夷沉眠，人类醒来。</p><p>意识逐渐从梦境的边缘滑落，向着现实世界的怀抱回归。</p><p>随着一阵轻微眩晕感，杨帝猛地睁开双眼，发现自己已回到了熟悉的宿舍。</p><p>他仍坐在工学椅上，一旁的张明远仍匍匐在笔记本电脑前，疯狂敲击声音贼大的青轴键盘。</p><p>“张明远，我睡了多久？”</p><p>闻言，他舍友诧异地扭过头来：“原来你睡着了啊刚才。我还以为你坐那位子上一动不动，直挺挺看着我盯了半小时咧。”</p><p>半小时……杨帝体感至少过去了一天一夜。</p><p>梦里的时间似乎比现实要快很多，大约是1:50速率，此事在盗梦空间亦有所记载。</p><p>至于为何能在梦中思考那么快，也许是因为梦和“潜意识”有深深的联系，而潜意识比人类的表层意识庞大得多。</p><p>在清醒时候只能想一件事，但在梦中用相同的时间却可以思考50件事，所以体感时间变快了很多。</p><p>醒来第一件事，杨帝迅速对自己搜身。</p><p>“呼——万幸。”</p><p>幸好，他没有在自己身上发现耶罗符印。裤袋里，衣袖里，屁股下，没有。</p><p>梦就是梦，和现实不能一概而论。</p><p>杨帝的手指无意识摩挲着工学椅扶手上的划痕。</p><p>他低头看见地板瓷砖缝沾着两粒干硬的米，表面纹路清晰可见。</p><p>视野清晰得可怕。</p><p>飘浮在空气中的灰尘颗粒，正以布朗运动轨迹游弋，每粒灰尘都拖着彗星般的光尾。</p><p>他能清晰可辨的看见，皮肤表面汗毛竟像水草般在气流中缓慢摇曳，每根绒毛震颤的幅度都清晰可辨……</p><p>这绝不是正常人的动态视力。</p><p>杨帝拼命眨眼，拿起保温杯，里边的枸杞茶还在冒着热气。</p><p>他倾斜杯口，将枸杞茶倒进玻璃杯。</p><p>尽量不让自己的目光再去接触那盏台灯，尽量不去观察手臂上的汗毛。</p><p>他却注意到——某粒枸杞表皮裂开的纹路。</p><p>那些褶皱本该是模糊的褐色斑点，此刻却呈现出丘陵地图般的立体感，像是一道道出现在红色高原上的沟壑，如此清晰可见……</p><p>“我的妈耶……！”</p><p>杨帝触电般松开杯子，金属与桌面碰撞的脆响竟像慢镜头播放。</p><p>他转头望向宿舍门板。</p><p>眼前的世界，正在疯狂增殖细节！</p><p>废纸篓内，某张废纸上写着“北福纽扣电池”打印字体清晰可见，微软雅黑，加粗。</p><p>台灯的光晕里，漂浮着无数银色丝线，像有人把整个银河揉碎了撒在十平米的空间里。</p><p>世界前所未有如此清晰过。</p><p>杨帝突然意识到，自己或许从未真正“看”清楚过任何东西。</p><p>那些被大脑自动过滤的冗余信息，此刻正如潮水般涌进视神经。</p><p>“怎么回事？”太多信息一股脑涌入心神，让他精神疲惫不堪。</p><p>这是说了一觉，开阴阳眼了？</p><p>杨帝有点不适应如此多信息如潮水般挤进脑子，他揉揉胀痛的太阳穴，拍拍张明远的肩。</p><p>“老帝，咋咧？”</p><p>“张明远，你先别笑，我可能真的新人类进化了。”</p><p>“我知道，你不用刻意强调，吼吼哈哈哈！”张明远一边说，一边哈哈大笑。</p><p>“……”</p><p>杨帝知道无论自己说什么，他那坚持绝对理性主义的理工宅男舍友，也都不会相信的。</p><p>只能靠自己了。</p><p>他逐渐发现，不只是视觉，听觉、触觉、嗅觉……都似乎在涌入大量细节，超巨量细节！</p><p>窗外蝉鸣声格外清晰，仿佛有人调高了现实世界的音量旋钮。</p><p>他能清晰分辨出猫猫爪子肉垫与水泥地面摩擦的沙沙声，以及幼崽喉咙里气泡般的呜咽。</p><p>涤纶布料刮得皮肤生疼，以前从未有过这般娇嫩的感受……</p><p>他手臂碰了一下铁架床。</p><p>金属震颤声裹挟着502胶水挥发的甲醛味，在杨帝舌头上刮出五颜六色的的刺痛感。</p><p>“五感，六识，如此敏感……”</p><p>杨帝起身，脚步不自觉地放轻，仿佛怕惊扰了这份突如其来的“敏锐”。</p><p>宿舍里的每一寸空间，每一件物品，都以一种他从未体验过的清晰度展现在眼前。</p><p>连张明远键盘上那些细微的磨损痕迹，都像是被精心雕琢的艺术品，纹理清晰可辨。</p><p>尽管信息量爆炸。</p><p>但杨帝却并不感觉痛苦，只是有些难受。</p><p>这种难受单纯来自于不适应。</p><p>就像没见识过现代夜生活的古人第一次踏入超级嗨的现场音乐会，周围各种声音、灯光、人群的氛围一股脑地砸过来。</p><p>既兴奋又有点被震得脑袋发懵，得花点时间去适应这种“轰炸式”的新体验。</p><p>“我得搞清楚自己身上发生了什么……”</p><p>他摸索着打开笔记本电脑，屏幕上红绿蓝的像素，在虹膜上炸开彩虹色光晕。</p><p>“这么整怎么查资料……”</p><p>他扯过挂在椅背的墨镜戴上，暗色滤镜终于让过度兴奋的视锥细胞稍显安定。</p><p>指尖触碰到键盘，杨帝感受到键帽上的细微划痕。</p><p>“……”他干脆猛地甩开键盘，抓起手机改用语音输入：“过度感官知觉，信息过滤机制失效，神经科学……”</p><p>浏览器上，关联词条和各种内容文字，在视网膜上燃烧般清晰。</p><p>他不得不眯起眼睛侧过头，让文字投影在视野边缘相对迟钝的区域。</p><p>“Hyperesthesia（感觉过敏）通常由中枢神经系统病变引发，但该案例中……”</p><p>杨帝继续翻下去。</p><p>「人类视网膜每秒钟接收海量数据，大脑却过滤了至少95%，但如果失去这层过滤器，原本那些杂乱冗余的细节都会一股脑被读取……」</p><p>「大脑不断受到感官信息的轰炸，特别是视觉方面。要理解这些信息，需要一个复杂的过滤系统，能专注于最重要的细节，主动地对信息进行优先排序，屏蔽掉无用的“噪音”。」</p><p>「人的感觉系统每秒都在向大脑传递着一千一百万比特的信息，而意识能处理的部分只有每秒50比特……」</p><p>「潜意识解放。」</p>
