# 全能耐杀王训练

<p>达到三级运动员标准又有何能耐！</p><p>被刀子捅破喉咙，被硫酸烧尽脏腑，被钢芯穿甲弹打穿脑子，被热核爆炸做桑拿，被大荒囚天指命中死穴……还是难逃一个死字下场！</p><p>这七天，他一直以来陷入一个误区！</p><p>在锻炼身体之前，应该锻炼自己的耐杀性！</p><p>杨帝默默在下一个“自戕锻炼法”周期中，加入额外任务：成为耐烧耐寒，耐锐器耐钝器，耐摔耐毒耐菠萝……的全能耐杀王。</p><p>虽然华夏是世上最安全的地方之一。</p><p>但天道轮回无情，谁都不能说，自己不会被天降事故、飞来横祸给带走。</p><p>生命只有一次。</p><p>他可不敢赌自己被重型半挂创飞之后，百分百会转生异世界，而不是被创下地狱。</p><p>杨帝看向自己的手，已经止住血了，结痂也已经结了一半。</p><p>超速恢复，超量代偿。</p><p>还在进化，还在进化！</p><p>杨帝瞳孔扩大，吸纳更多光线。</p><p>他看见十五米外窗框上的铁锈斑纹，看见钢筋断口处氧化层的剥落轨迹，甚至看见夜蛾翅膀振动时抖落的磷粉。</p><p>钢筋，断裂，生锈——破伤风。</p><p>“呃……不知能不能耐受‘破伤风’？”</p><p>杨帝看了看破出血洞的掌心，有了些担忧。</p><p>用滚水、玻璃渣来磨炼耐热、耐锐器，对他来说是很容易接受的，因为做这些并不致命。</p><p>但破伤风就不一定了。</p><p>这是由破伤风杆菌引起的严重疾病，病菌在缺氧环境下繁殖，并释放毒素。常发病于被生锈铁器划破血肉。</p><p>如果他没能适应耐受破伤风杆菌，它很容易能把自己给刀掉！</p><p>这种几乎要突破“自戕锻炼法”的范畴了，是一种“自杀锻炼法”！</p><p>很容易自己把自己杀了。</p><p>目前为止，杨帝并没有摸清楚——他“超量代偿”的上限在哪里？</p><p>“总之，先锤炼一下其他那些不容易死的、物理方面的‘耐杀属性’吧。”</p><p>“就先从基础动作开始，熟练一下！”</p><p>整个人如离弦之箭射向危楼阴影，冲向二楼破碎的玻璃窗台。</p><p>杨帝强行扭转腰胯，后背着地砸进瓦砾堆。</p><p>“啪——！”碎玻璃渣和瓦砾堆，将某人扎得伤痕累累。</p><p>不过某人也有先见之明，提早脱掉衣服，裤子则是皮实耐操的工装裤，不容易整得破破烂烂的。</p><p>“继续！生命在于蠕动。”</p><p>他吐出带血的唾沫，翻身跃上两三米高的断墙，在墙体上奔腾。</p><p>期间时不时绊到钢筋，绊到砖头，绊到睡大觉的野猫，在地上狠狠扑一街，然后心灵深处传出一个模糊的概念：</p><p>「钝器抗性+1」</p><p>在成为传奇奈莎王之前，杨帝要成为史诗级耐摔王了。</p><p>许多物理上的损伤，其实都可以聚团归类。</p><p>比如砖头拍、被石块砸、被木棍击，本质上都是外力对身体组织的冲击。</p><p>在杨帝的锻炼体系中，这些都可以被归类为“耐外力冲击/钝器抗性”属性。</p><p>这和玻璃渣、刀片、铁皮边缘等锐器，似乎是不太一样的。</p><p>前半个晚上，杨帝经历了至少上百次的摔倒与钝器撞击后，身体逐渐适应了这种高强度的锻炼。</p><p>他肌肉变得更厚实，骨骼更坚韧，仿佛已经进化出了对钝器伤害的天然抗性。</p><p>杨帝能很明显感觉到，他皮肤、肌肉、脂肪等软组织越来越抗造了。</p><p>在最早几十处淤伤消退后，后续对身体的摔打既没有导致多少疼痛，也没有增添新的淤肿。</p><p>甚至隐隐产生一种错觉：从二楼摔下去，他能毫发无伤；搭配跑酷技术，三楼坠落也只是洒洒水。</p><p>但是，他对锐器的防御并没有增强很多。</p><p>锐器割伤则是通过较小的接触面积快速穿透皮肤和组织，能量在极短的时间内集中释放。</p><p>他虽然略微比之前更皮糙肉厚。</p><p>但主要还是皮肤、肌肉、脂肪等软组织更耐受冲击，大幅缓减对血管和脏器的损伤。</p><p>而防御锐器，比较重要的是“硬度”。</p><p>刀子扎进来，拿皮肉做缓冲是不行的。</p><p>最好的方法是让刀子扎不进来。</p><p>杨帝在钝器抗性上都已经所向披靡，成了史诗级耐摔王。</p><p>可一碰这锐器，就感觉像是纸糊的一样，一划就破相。</p><p>当然，杨帝也能明显感受到，再用双手去捏那些玻璃渣子，也不会那么容易捏出血了。</p><p>他在锐器抗性方面，也有了些许进步，只是相较于钝器抗性，提升的程度还比较有限。</p><p>“看来，虽然我在钝器抗性方面已经取得了显著的进步，但锐器防御的提升还需要更多的针对性锻炼。不过，这种进步并非孤立的，钝器抗性能力的增强，也在一定程度上，为锐器抗性能力的提升奠定了基础。”</p><p>他如是想着，一边确立后续的发展思想。</p><p>后半夜，杨帝便集中精力锻炼锐器耐受性。</p><p>锐器不比摔撞，前者是会整出血的！</p><p>整出血，就意味着有一定几率感染。</p><p>杨帝从小运气不算太好，情寻糯米叉烧包/剪刀石头布从没赢过。</p><p>于是，在接连不断的「体力+1」「跑酷+1」「钝器抗性+1」「锐器抗性+1」声音中，掺杂进了一句：</p><p>「免疫+1」</p><p>免疫系统能够抵御感染、防止疾病的发生和发展。</p><p>简而言之，有脏东西进了体内，免疫系统才会发力，与其鏖战到肉身边疆，大道磨灭。</p><p>“……草（一种植物）。”</p><p>杨帝无语地看着手臂上一条渗血大口子。</p><p>而在墙边一条裸露出来的钢筋上，还有一摊腥红色的血渍。</p><p>钢筋断口像野兽獠牙般斜刺在混凝土间，泛着暗红磷光。</p><p>生锈，锋利，沾满污垢，buff叠满了。</p><p>「免疫+1」</p><p>左肩胛骨传来诡异的麻痒，仿佛有千万只蚂蚁在啃食脊髓。</p><p>“不可不可能吧？破伤风都走这么快就起作用了？这点时间别说繁殖了，扩散都还没扩散吧……”</p><p>杨帝又看向那满是污垢、裸露出来的生锈钢筋。</p><p>应该不只是破伤风，这钢条里边，还藏了也许七八百种不同的病菌，这么大剂量直接往血肉里注射，它们大概都乐疯了吧。</p><p>「免疫+2」</p><p>“诶？这感觉和之前不一样，直接给我免疫+2了？”</p><p>在对抗外来病菌之时，免疫系统被激活，人体的免疫力会提升。</p><p>但同时，这也意味着两军鏖战，鏖战就会有损耗，免疫系统会不可避免地受到损伤。</p><p>「免疫+3」</p><p>杨帝穿好衣服，带上手机，准备步行去校医务室。</p><p>晚几个钟头打破伤风不会死。所以，他又在旧校区坐了一个小时，花点时间观察左臂情况。</p><p>酥酥麻麻，像是被万千蚂蚁爬过。</p><p>「免疫+5」</p><p>“啊？跳幅这么大，直接跳到+5了？”</p><p>杨帝总觉得这进步幅度是有一些规律的。</p><p>「免疫+8」</p><p>呃，他想起来了，1 1 2 3 5 8，是非常万能的“黄金分割数列”。</p><p>从第三位开始，每个数都是前两个数之和。</p><p>蜜蜂繁殖，菊花花瓣，星系旋臂……甚至是现在的耐杀性升级，都能和这数列扯上点关系。</p><p>这是不是侧面说明，杨帝身上的异变，其实也是一种自然规律，而不是超自然现象咧？只有天知道。</p>
