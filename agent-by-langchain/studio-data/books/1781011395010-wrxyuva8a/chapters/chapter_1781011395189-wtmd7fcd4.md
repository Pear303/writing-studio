# 食破天惊

<p>事实上，杨帝并不是在看这位20出头的年轻志愿者，他是在看对方身后的“天圆广场”。</p><p>浓雾中央，也有一只眼睛与杨帝对视。</p><p>他的视线，穿透老王因紧张而微微佝偻的肩膀，穿透消防柜金属外壳的冰冷反光，穿透弥漫在走廊里带着铁锈和尘埃味道的潮湿空气。</p><p>最终牢牢锁定在窗外——那片被浓得如同实质的灰白色雾气，所笼罩的广场中心。</p><p>不，不是雾。</p><p>他看的是雾中。</p><p>是那浓雾深处，某个比周围雾气更暗沉、更粘稠的“存在”。</p><p>那东西，悬浮在广场中心偏上的位置，高度大约相当于四层教学楼顶。</p><p>它没有轮廓，或者说，它的轮廓在雾气中不断蠕动、变幻，如同一团不断分泌粘液的活体阴影。但在这团阴影的核心，却有一只眼睛。</p><p>巨大、冰冷、不带任何生物情感的眼睛。</p><p>杨帝皱眉，略微回忆青丘白璃介绍的“相由心生”理论。</p><p>眼睛，代表着某种观察。</p><p>这只混沌的眼睛，它的瞳孔不是圆形，而是由无数个不断旋转、破碎又重组的、更微小的六边形复眼结构构成，闪烁着令人心悸的、非自然的暗紫色幽光。</p><p>这些复眼每一只，都像是个独立的监视器，转动着，贪婪地扫视着以广场为中心的一切。</p><p>环形走廊的每一寸地面、每一个角落；</p><p>周围放射性分布的教学楼每一扇窗户、每一道门扉；</p><p>那些躲在教室窗帘后、桌椅下、瑟瑟发抖或茫然无措的身影；</p><p>那些在走廊里僵硬移动、试图执行“预案”的红袖章志愿者；</p><p>广播室大楼那扇亮着应急灯的窗户……</p><p>一切！一切都被这只巨大复眼的视线所覆盖、所穿透、所记录。</p><p>这是一座以“天圆”为名的、巨大而精密的全景监狱。</p><p>全景监狱……监狱……在蛐蛐某些学校吗？杨帝感受到一股恶趣味。</p><p>全景监狱是一种高效的监狱设计概念，其结构为：中央塔楼，环形牢房。</p><p>塔楼可观察所有牢房，而囚徒无法确定自己是否被监视。这种设计利用心理压力，使囚徒因担忧被注视而主动规范行为，达到“自我监禁”效果。</p><p>而这颗悬浮在中央高处的的恶心眼珠，就是这座监狱最冷酷、最高效的狱卒。</p><p>因为一切试图得知自己是否被观察的囚犯，都会被切掉脑袋，提前执行死刑了属于是。</p><p>杨帝能感觉到，当自己的目光和对方的视线接触，自己脖子就会痒痒的。</p><p>非常玄幻，这不科学！</p><p>只不过，现在那代表观察的眼睛，已经不足以让他cos路易十六。</p><p>换言之，这玩意已经没用了，留着只能污染环境，就是个祸害。</p><p>已有取死之道。</p><p>“很好！”杨帝终于可以正当防卫了，实在让人拳头瘙痒难耐。</p><p>他瞬间元神出窍！</p><p>几乎在同一时间！</p><p>那只悬浮在浓雾中央的巨大复眼，所有疯狂旋转的六边形瞳孔，骤然停止了转动。</p><p>成千上万道冰冷、粘稠、充满极致恶意的视线，瞬间跨越空间，精准地、死死地聚焦在了环形走廊角落——聚焦在杨帝的身上。</p><p>远比之前强烈百倍、千倍的精神威压和规则排斥力，如同整个“监狱”的愤怒，轰然降临。</p><p>杨帝的元神一整个直接哄堂大笑。</p><p>“被‘狱卒’重点关照了吗？”</p><p>全景监狱的狱卒，第一次遇到了一个不仅不怕它，反而将它当作磨刀石的“囚犯”。</p><p>很难说它是个拥有智慧与知性的刽子手，亦或是单纯被规则支配的卒子。</p><p>但在此刻，它只有一事可做——杀。</p><p>一股凝聚到极点、足以将恒星意志都碾成齑粉的毁灭性精神冲击，如同超新星爆发的第一缕冲击波，无视物理距离，精准狂暴地轰向杨帝的元神！</p><p>杨帝的元神也冲杀向前。</p><p>他一瞬间受到数万亿倍于精神承载极限的致死性伤害。</p><p>元神不同于物质躯壳。人的精神、灵魂、元神，更虚无缥缈，能够更快速地……复原。</p><p>浓雾中的眼睛对杨帝施展第二次精神杀伤，然后是第三次，第四次……</p><p>某一时刻，足以湮灭真仙巅峰神魂的冲击，撞在杨帝元神的暗金辉光上，却如同怒涛拍击亘古礁岩。</p><p>至此，体魄、神魂，双双抵达仙帝境界！</p><p>在回合制交战中，通常是你打一枪，轮到我放一炮。</p><p>杨帝的元神，做出一个匪夷所思、亵渎规则的动作。</p><p>“大帝杀招·食破天惊！！”</p><p>杨帝并非抬手攻击，也非念动法咒。</p><p>他只是“看”着，看着那颗悬浮在广场中心高处、散发恶意的巨大复眼。</p><p>然后，以一种主宰万物、定义存在的无上意志，平静地宣告：</p><p>“此坐标时空，非彼时空。”</p><p>“此乃——吾之胃脘！”</p><p>第七识「末那识」高阶应用——对“自我”的定义进行外部扩展。</p><p>包括可以用自己的“胃”，笼罩某一处空间。</p><p>那不再是一个悬浮于广场中心、俯瞰监狱的观察点。</p><p>在杨帝对自我生成的认知中，那个坐标点，就是他庞大肉身内部，用于容纳、分解、吸收万物的器官——肠胃的一部分。</p><p>奶奶经常说，吃啥补啥。</p><p>她认为熬瘦肉水给年幼时体弱的杨帝喝，能够增强体质长肌肉，事实上当年他喝的与其说是蛋白质，不如说是醇厚的嘌呤。</p><p>不多说了。杨帝直到20岁前，承受了整整10年的戴眼镜生活；又因为一些个人经历，从而对大眼珠子没有好感。</p><p>事已至此，开吃。</p><p>被杨帝其“胃部”笼罩的时空，发出来自法则层面的恐怖哀鸣！</p><p>浓雾疯狂倒卷，空间剧烈扭曲，构成广场、教学楼的物质都开始出现不稳定的虚化。</p><p>那只巨大的、不可一世的狱卒之眼，其核心处第一次流露出了……名为“恐惧”的情感。</p><p>它想逃！</p><p>想切断与这片区域的联系，想遁入更深层的规则缝隙。</p><p>但已经晚了。</p><p>在杨帝完成定义的刹那，一种无法抗拒、无法理解、超越了这个怪谈领域规则的“消化”之力，已然作用在那颗眼珠存在的“根本”之上。</p><p>“滋啦……滋滋滋……”</p><p>令人头皮发麻的、如同强酸腐蚀血肉的声音响起，却并非源于物理层面。</p><p>是那只巨大复眼的“现实”正在被侵蚀、被溶解。</p><p>构成它核心的无数旋转六边形复眼，如同被投入熔炉的玻璃，瞬间软化、变形、彼此粘连。</p><p>那冰冷的暗紫色幽光急速黯淡、熄灭。</p><p>覆盖眼珠的蠕动阴影如同沸腾的沥青般剧烈翻滚、蒸发！</p><p>它试图发出的精神尖啸被强行扼断，只剩下无声的、概念层面的凄厉哀嚎！</p><p>很奇妙，这座城市也叫“稷海市”。</p><p>日啖眼珠三百颗，不辞长作稷海人。</p><p>杨帝感受到自己“肠胃”中，顷刻炼化得到的灵能。他有点反胃地咂了咂嘴。</p><p>一位邪神……悄无声息被消化殆尽。</p><p>广播“滋啦——”地响起。</p><p>「全体师生请注意，目前已探出怪谈规则的其中一项特性。」</p><p>「若目视教学楼中央的天圆广场，有可能导致精神失常，严重者甚至会头颅断裂。」</p><p>「请遵守规则，守住理智与生命。」</p>
