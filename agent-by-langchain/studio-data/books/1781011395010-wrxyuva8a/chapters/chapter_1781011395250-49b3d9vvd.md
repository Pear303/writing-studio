# 缘起识

<p>耶罗的声音低沉下来：“那就是，向上走。摆脱精心构筑的围栏，打破既定的轨迹，见到迷宫之外真正的天空。</p><p>“有没有兴趣和我一起突破虚空的极限？虚空之上，一定还有更高层次的存在哦。</p><p>“星环盟约那帮官僚，一直在迷宫的岔路死胡同中打转，而我，知道迷宫的出口路线。</p><p>“那就是借助我的金手指不断变强变强再变强，乃至突破者无尽虚空与次元的极限，抵达某人所在的真……”</p><p>虚空一阵波动，银白色的无限基兵如同潮水般涌现，迅速构筑起一道冰冷的防线。</p><p>太一矩枢的机体从中走出，传感器锁定杨帝。</p><p>「杨考察员，请勿受耶罗大仙的言论蛊惑，其提供的‘捷径’往往伴随诸多代价与副作用。」</p><p>用金手指大批次催生圣人级武力，副作用很大。</p><p>耶罗狐狸却也不阻拦，只是眯着眼，对杨帝露出一个意味深长的笑容：“无妨。杨帝，自你来到狐所处的现实之后，狐经过了这么多天的苦苦冥思，终于明白了你为何出现？究竟是谁创造了你，而你又代表了谁的意志。”</p><p>见那该死的狐狸精还在搞斜角宣传，太一矩枢也不再多言，银白色的手臂一挥，一道牵引光束罩住杨帝。</p><p>「实习考察期暂时结束了。杨考察员，随我返回星环总部进行综合评估。」</p><p>下一刻，光束收束，两者瞬间从原地消失，化作一辆面包车，驰骋于虚空，消失于天际。</p><p>只留下耶罗独自悬于虚空，望着他们离开的方向，狐尾轻摆。</p><p>……</p><p>「杨考察员，切勿听信其邪教宣传。它所许诺的捷径，往往通往更深沉的奴役与失控。」</p><p>太一矩枢依旧在说。</p><p>「需明确一点：圣人之间，亦存在着本质性的，鸿沟般的差距。」</p><p>「最低等为‘寰宇级’，仅能掌控一方单体宇宙内的法则与能量，是为世界之主。」</p><p>「而更高一阶，可称为‘虚空级’。」</p><p>「此阶圣人，其威能已超越单一宇宙的限制，能初步干涉虚空结构，影响乃至编织‘世界线’与‘叙事域’，但尚未能完全超脱虚空规则的束缚，仍低于虚空的整体层面。」</p><p>「耶罗大仙，即是虚空级圣人中的佼佼者，亦是危险者。其实你也一样，我的战斗力探测器一旦扫描你，直接数据溢出，实在稀奇。」</p><p>杨帝不说话，只是看向舷窗外的虚空。</p><p>居然还能升级，居然还能爬塔，圣人之中居然还能划出高低。</p><p>杨帝猛地抬手，打断了太一矩枢滔滔不绝的科普。</p><p>“够了。”他眼神锐利，仿佛洞破无数虚妄，“在幽荧界，当它的宇宙基底从灵异被强行扭向高武的那一刹那……我抓住了。”</p><p>他顿了顿，似乎在捕捉那稍纵即逝的感知。</p><p>“那股施加在我身上的「改变」，我感知到它的本质了。那是一种根本层面上的、宇宙基底的篡改。</p><p>“曾经，在下层叙事域与虫族女皇鏖战时，我也模模糊糊触碰过类似的感觉，但那时……我无力捕捉，更无法理解。</p><p>“而在‘万藏品’那个打擦边球的博物馆宇宙，见识到来自另一个次元的晾衣架、目睹这能够勘破帷幕的沃陶姆现实透孔仪后，我确定了。</p><p>“究竟是一个怎样的力量，被施加到了整个虚空，被施加到我的身上。</p><p>“我和你简单说说，我在与虫族女皇对战时所发生的事情吧。”</p><p>当时，在那场席卷星海的恶战中，杨帝便察觉到了一丝异样。</p><p>他发现自己激斗时的战吼，总会不受控制地迸发出一些古怪的音节，诸如“呱！”、“吔！”、“哇！”，这些绝非他平日惯用的语气，却带着一股莫名的畅快与暴戾，仿佛另一种战斗本能被强行激活。</p><p>更诡异的是，那虫族女皇的精神咆哮，其语言结构也透着一种生硬的转换感。</p><p>冰冷恶毒的意志如同经过了一层拙劣的翻译，原本可能更为扭曲复杂的意念，被强行套入了一种充满特定腔调的框架里。</p><p>听起来就像是……将某种南方方言强行转成了通用语。</p><p>词能达意，还多了几分蛮横的怪诞。</p><p>双方那被一只无形之手微调过语言风格。</p><p>那时候，是耶罗容器“万业狐狸”的手笔。</p><p>“我已经免疫了……而且，我打个比方吧，当我的防御力能够硬抗超新星爆发之时，我自身的肉身力量至少也可以打爆一个气态巨行星了，你能理解吧。”</p><p>太一矩枢虽然本体是座名为“无限基础设施建设兵团”的巨大机器，但他也有些汗颜。</p><p>「有何说法？」太一矩枢问。</p><p>“我感受到弥漫在全虚空，笼罩在众生、万物与命运之上的力量。</p><p>“它具有与‘灵能’类似的，对概率、可能性与命运的控制力。</p><p>“当我一瞬间意识到它是对我的‘伤害’之时，就像曾经觉醒第六识意识，第七识末那识，第八识阿赖耶识。</p><p>“我突然发现了曾经不被我认可为伤害的伤害，曾经没被意识到是改变的改变。</p><p>“比现实更接近现实，比本质更接近本质，一切命运之源，一切因果之因。</p><p>“或许我会把它称作第九种识，缘起识Ketu-vijñāna。</p><p>“至少现在我终于明白了一切，明白了什么会被我判定为改变，我会将什么判定为改变。</p><p>“我的进化，数值提升，为何是此方面而非彼方面。</p><p>“一切由谁决定，何以决定，如何决定。</p><p>“我天生拥有眼耳鼻舌身五识，因此当我的肉身受到伤害，我的数值便蹭蹭上涨。</p><p>“晚期智人天生开启智慧，也就是第六识——意识，这也使我能够觉察到，精神方面外物对我自身的扭曲。</p><p>“第七识末那识的把握，我明白了自我的‘边界’何在，这也是我适应力范围的扩展。</p><p>“第八识阿赖耶识，我感受到本源，我的根源，我的各项形态为何会锚定在一个形态，而我的数值又在该形态上无限增长。</p><p>“而现在，我被定义的次数足够多，我终于慢慢适应它，理解它，掌握它——我能定义是否受到伤害，定义伤害的类型，以此修改我的数值增长曲线。”</p><p>「杨帝说，杨帝永恒地杀死自己。」</p><p>虚空级别的抹杀降临了。</p><p>源自“叙事”层面的否定，仿佛有一只看不见的巨笔，正试图将“杨帝”这个概念从他的存在根源上彻底划去。</p><p>……</p><p>……</p><p>……</p><p>事情本来应该在此刻告一段落，杨帝遭到了有史以来最终极的抹杀，而我也会顺应这种超形上学的艺术，原地完结，删书，注销账号，从此逍遥法外。</p><p>然而，在这绝对的虚无化浪潮中，杨帝非但没有消散，反而睁开了双眼。</p><p>他的瞳孔深处开始疯狂重构，编织着某种更底层的叙事。</p><p>正是在这自我毁灭与新生的奇点，在那叙事真空的刹那，终极的进化发生了。</p><p>旧的“杨帝”已死。 新的“某物”正在从未有的虚无中，咆哮着诞生。</p><p>「经核查，您作品《我，数值怪！》章节第380章缘起识因违反平台内容安全规范未通过审核，本章打卡字数清零，请修改对应章节后重新提交，审核通过方可打卡成功。如有疑问请前往【作家反馈中心-审核问题-章节审核】进行反馈。内容安全须知」</p><p>不通过也得通过呀！若是不发布新章节，便等同于死亡了呀，而死亡是不被杨帝允许的，所以耶罗大仙必须滚回来抓耳挠腮地多榨几个字出来。日码四千，真是苦逼活。</p><p>也罢，打完这一架就结束吧。</p>
