# 破防是锻炼之前提

<p>杨帝显然是被重重心事缠住了脑子。</p><p>他居然忘记躲避摄像头，光明正大从旧校区正门走了出来……路过了那保安亭。</p><p>他回过神来时，保安已经从亭子走出来，放下手机短视频，恶狠狠瞪着这厮。</p><p>保安恼怒道：“小子！我昨晚就见过你，你怎么偷偷溜进去了？！”</p><p>杨帝站在原地，有些无地自容。</p><p>他思索了五秒钟，便很严肃地问保安：“这位哥，你知不知道我是谁？”</p><p>“你谁？”保安问。</p><p>“不知道就好。”杨帝拔腿便跑。</p><p>……</p><p>左肩胛的瘙痒已演变成电流窜动般的酥麻。</p><p>杨帝试着用指甲抠挠，却抓下一块结着黑痂的死皮，皮下是一片粉嫩的新肉。</p><p>“1小时45分钟……就愈合了。”他盯着手机计时器。</p><p>皮下组织里，似乎有千军万马在冲锋陷阵，半小时前被钢筋划开的伤口，此刻正在以肉眼可见的速度，增生出粉红色肉芽。</p><p>而自己身上一块青一块紫的淤肿，也早已经退散。</p><p>但是，很饿。修复伤口，激活免疫系统，都要消耗大量糖分、蛋白质和盐，他非常想吃一些是牛肉六倍蛋白质密度的食物。</p><p>不过，在去饭堂之前……真不先打一针破伤风吗？</p><p>还是打吧。杨帝推开玻璃门。</p><p>值班医生从《外科手术图谱》里，抬起头发稀疏的脑袋。</p><p>眼前这个浑身糟蹋的男生，活像刚从战场逃回来的难民。</p><p>“同学你这是……”</p><p>“被工地铁丝网刮了。”</p><p>杨帝熟练地扯谎，脸不红心不跳，把左臂搁在诊台上。</p><p>医生戴着橡胶手套的指尖顿了顿，镊子夹着酒精棉悬在半空。</p><p>“呃同学，你确定是今天受的伤？这痂皮厚度是一两天前的创伤。”</p><p>“可能我凝血功能比较好。”他听见自己的声音像隔着水缸传来，“需要打破伤风吗？”</p><p>得打，当然得打，要有人在稷海理工医务室里死于破伤风，一大票人的位子保不住。</p><p>医生从冷藏柜取出淡黄色疫苗。</p><p>杨帝盯着那根5厘米长的注射针头，说实话心底有些发怵。</p><p>不过，第一针扎在三角肌时，金属弯曲、针头断裂的脆响让两人同时愣住。</p><p>不锈钢针头在接触到皮肤的瞬间，弯成鱼钩状，仿佛刺中的是凯夫拉防弹纤维，而不是一个年轻人的血肉。</p><p>“奇怪……我手法生疏了么……不好意思啊同学，你再忍忍。”</p><p>医生皱眉换上新的针头，这次用了双手持握的姿势。</p><p>杨帝能清晰感知到，针尖在真皮层上打滑的触感，就像圆珠笔在塑胶桌布上划过的滞涩感。</p><p>针头，也是一种锐器。</p><p>他通过后半夜的“锐器专项适应训练”，现在已变得皮糙肉厚，拿普通的美工刀，不用力划，都划不开皮肤。</p><p>杨帝想起小时候，在动物园看饲养员给犀牛打镇静剂，那也是一个艰难啊。</p><p>“啪嗒～”</p><p>第二根针头，也折断了。</p><p>医生的喉结上下滚动：“同学你，呃，要不要做个核磁共振？”</p><p>他大抵在怀疑杨帝是终结者。</p><p>“啊哈哈，可能我皮肤比较厚。我放松点，您换个针头再试一遍。”杨帝打了个哈哈。</p><p>医生取出更粗的针头，这次他戴上了无菌手套，又换上专业持针器。</p><p>妈耶，这是要结硬寨，打硬仗了。</p><p>“同学，这次可能有点疼，做好心理准备。”医生一边说着，一边小心翼翼地将针头对准杨帝的三角肌。</p><p>杨帝倒吸一口气，尽量让自己的肌肉放松下来：“来吧，医生，我准备好了。”</p><p>针头刚一接触皮肤，他们便感到一股强大的阻力，仿佛针头正在与某种坚韧的屏障抗衡。</p><p>“这……这皮肤怎么跟钢板似的？”医生小声嘟囔。眼前这人难道真是终结者套皮？</p><p>杨帝尴尬地笑了笑：“可能是我最近锻炼过度，肌肉特别紧绷。”</p><p>医生调整了角度，加大了力度，针头终于缓缓刺入皮肤。</p><p>「锐器抗性+1」</p><p>“药推完了。打针地方尽量不要沾水，一天以内不要剧烈运动。”医生松了一口气，将注射器放在一边。</p><p>眼前这小朋友怎么跟铁人一样。</p><p>杨帝从小身体不好，现在已经对医院流程很熟悉了。他轻车熟路刷完医保卡，交完钱，也便就这么离去。</p><p>也是在此刻，他注意到一个细节。</p><p>“奇怪，前两次针头没扎破皮的时候，潜意识并没有弹出‘锐器抗性+1’的提示。第三次扎破了皮肉，才有‘锐器抗性+1’提示。这说明？”</p><p>杨帝皱起眉头。</p><p>“是不是意味着，只有当针头真正穿透皮肤，造成实质性的损伤，身体才会认定这是一次有效的‘锐器’挑战，从而给予相应的‘超量代偿’进步？”</p><p>他回想起自己这段时间以来的经历。</p><p>身体的恢复能力越来越强，伤口愈合的速度快得惊人，甚至超出了常理。</p><p>可与此同时，他也察觉到，想要进一步提升自己的能力，比如已经练了七天的跑步、引体向上，似乎变得越来越困难。</p><p>胡彦卓的忠告犹在耳畔：</p><p>“……职业运动员最怕的不是伤病，而是某天早晨醒来，发现身体再也榨不出一丝潜能。你现在感觉进步神速，是因为站在山脚……”</p><p>杨帝猛然震悚——是不是因为我的身体已经达到了某种极限，真的已经不能再进步了……</p><p>然而，他很快又否定了这个想法。</p><p>“并不，‘进步放缓’只是一种错觉，真正的原因是我对‘伤害’的耐受程度提升了。”</p><p>锻炼的本质，是损伤、超量恢复。</p><p>当杨帝的肌肉强度、密度都大幅提高时，就更难以损耗、撕裂肌肉纤维。</p><p>可能以前跑1公里，就能达到损耗所需的运动量。</p><p>现在则得跑上10公里，才足以损耗和撕裂肌肉纤维，达到和从前一样的运动效果！</p><p>又比如，一天前他把手按上玻璃渣子，就可以划破皮肉，起到「锐器抗性+1」的效果。</p><p>后来玻璃渣子已经扎不穿手掌了，只有锋利的钢筋、刀片能让他破防，实现「锐器抗性+1」。</p><p>直到皮肉再度变得坚硬，连水果刀都划不开时，可能只有针头、手术刀能破开，并起到锻炼「锐器抗性」的效果。</p><p>可以想象，假以时日。</p><p>对于「锐器抗性」的锻炼，要逐步进化为用斧头、用电锯、用钻头、用穿甲弹、用钻地弹、用宇宙大爆炸……</p><p>否则连皮肉的防御都破不开，谈何锻炼？</p><p>之前他还以为，锻炼和伤害是两个截然不同的概念。</p><p>但现在看来，它们之间的界限，似乎并没有那么清晰！</p><p>“今日之「伤害」，经过进化，也能转化成明日之「锻炼」，这就是辩证法啊。”</p><p>打完破伤风疫苗过了许久，杨帝心中才慢慢弹出一个提示：</p><p>「免疫+1」</p><p>疫苗也开始发力了。</p><p>不过，对他免疫力的提升程度，并不及“超量代偿”所带来的升幅。</p><p>裤兜里手机传出来震动，打断他思绪。</p><p>杨帝掏出手机一瞅，是张明远发来的信息，五个汉字，两个标点，很短。</p><p>【宿舍危，速归！】</p>
