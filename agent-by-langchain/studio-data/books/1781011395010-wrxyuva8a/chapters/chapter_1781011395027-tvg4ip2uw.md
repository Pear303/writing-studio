# 希夷与梦

<p>古希腊哲人说万物源于阿派朗，可那个无定形体本身是什么形状？道教讲有物混成，先天地生，又说道之为物，惟恍惟惚，但谁能画出“道”的模样？</p><p>「神秘学+1」</p><p>脑海中疯狂闪回曾经看过的文学片段，无论是他记得的，不记得的，或是以为自己不记得，但记忆仍藏于潜意识深处的。</p><p>《山海经》里九首人面的开明兽，《酉阳杂俎》中记载的夜叉，《庄子》中若亡而存、不形而神的奇怪描述。</p><p>「神秘学+1」</p><p>那个东西是什么？是什么？是什么？！</p><p>视之无形，听之无声，谓之幽冥。</p><p>Χάος，अनंत，太虚……</p><p>他看见去年国庆节，在博物馆里的三星堆青铜神树。又想起小时候，见过的傩戏面具……</p><p>不对那些青面獠牙的造型，其实是对“不可直视之物”的拙劣模仿，就像用儿童蜡笔来描绘黑洞。</p><p>「神秘学+1」</p><p>当这些词汇在意识中碰撞，杨帝看见，穹顶裂开一道缝隙。</p><p>那不是物理意义上的裂缝，更像是宣纸上晕开的墨渍，裂缝中，一条环状物探出触须。</p><p>蛇衔其尾者，谓长生久视之道。呃，这句话是什么意思？</p><p>「神秘学+1」</p><p>那个梦里的老人又出现了。</p><p>只不过，这次他不是以文学巨匠的模样现身，而是变成指环王里那个白胡子老爷爷干豆腐，划掉，甘道夫。</p><p>“我们总说眼睛是心灵的窗户，但或许窗户玻璃上早已落满语言的灰尘，年轻人，你终究还是踏足了迷宫深处的幽邃，见到了世上任何一个文学大家都无法描述的事物。”</p><p>「神秘学+1」</p><p>甘道夫拍拍杨帝的肩膀。</p><p>“年轻人，我第一次见到你，你正站在语言与逻辑的悬崖边缘，下面是深渊。”</p><p>“抱歉，我一直以为您说的‘深渊’就是高等数学……”</p><p>“深渊是个幻象——人类对黑暗的短暂想象，即将被它吞噬的想象。”</p><p>“可是先生，您用微积分来给我做比喻，不就是暗示高等数学吗……”</p><p>「神秘学+1」</p><p>二人对话不在同一个频道。</p><p>“年轻人，真正的深渊，是连‘深渊’这个词都显得傲慢的。”</p><p>“老爷子，所以图片里的‘那东西’究竟是什么？”</p><p>灰袍甘道夫：“它是一名浑浑噩噩的逝者，你可以称它为‘希夷’。人类的理智会自动过滤它的存在，也就是假装看不见它。”</p><p>杨帝大震特震，大撼特撼。</p><p>“但如果真看见它了呢？”</p><p>“就会陷入噩梦——不过，‘噩梦’本身，也是人类的理智所构筑起来、抵挡住它的防线。”</p><p>杨帝的噩梦是“水池”。</p><p>他对水池子有极深的童年阴影。</p><p>「神秘学+1」</p><p>“老爷子，为什么和你谈话，会增加一种叫做‘神秘学’的东西？”</p><p>“你和‘希夷’神交过，而神交是双向的，你受到它对你精神上的冲击，但同时，也窃取到它的一部分知识。”</p><p>听得有些心动，杨帝都想和教授神交了。</p><p>“不说了，我要带上格拉姆德凛剑，去讨伐地狱来的炎魔。啧，佛罗多·巴金斯他们还等着我去护送魔戒，没空和你闲聊。”</p><p>甘道夫抄起宝剑，消失在池子底下水道。</p><p>下水道是个用塑料滤网挡起来的洞，孔径不超过一厘米，他像神灯里飘出的蓝色神仙那样钻了下去。</p><p>唯一陪他说话的老爷子消失了，这场池梦，又仅剩杨帝孤零零一人。</p><p>先前的对话仿似泡梦幻影……还真是泡梦幻影，非修辞。</p><p>而记忆中的不可名状之物，除了对他施加巨量精神伤害，导致增加大量“精神”和“神秘学”点数之外。</p><p>似乎也销声匿迹，没有再造成更多危害了。</p><p>它好像并没有“掉san/减理智”这种不可名状之物必备的功效。</p><p>或者说，精神上的伤害，就是“掉san”的一种表现或者原因。</p><p>但是，还没来得及掉san，杨帝的“损伤→超量代偿”机制，就已经把受到损伤的精神给超量恢复回来。</p><p>并且让己方精神更壮大。</p><p>那么是不是说，理论上杨帝是可以免疫死亡的……</p><p>只要在“死亡”这一事实达成之前，迅速进化、适应了足以让他致死的因素。</p><p>“死亡”就不足以杀死他！</p><p>比如，在一颗穿甲弹要打爆心脏之前，迅速进化出“皮肉加固”，或者是“没有心脏也能生存”的体质。</p><p>然后，穿甲弹打爆心脏，但他已经“没有心脏也能生存”了。</p><p>这是什么，死神永远慢我一步？</p><p>但是，如果“死亡”这一事实降临得太快，他会不会就真死了？</p><p>比如，全身每一寸分子，在0.0001秒内被伽马射线暴轰成等离子蒸汽。</p><p>他还来得及适应吗？</p><p>这也是应该考虑的问题。</p><p>目前来说，杨帝对自己的“特异功能”有了更深理解。</p><p>从琦玉锻炼法到自戕锻炼法，或许还能继续升级为某种“自杀锻炼法”，通过不会即死的自杀行为，快速提高各项属性。</p><p>不过，现在杨帝已经憋得慌了。</p><p>就算是天生熟水性的人，就算氧气，水压和温度都不是大问题，他也不大会喜欢在水里泡上几十个小时。</p><p>而杨帝，不知道在自己的梦里待多久了，还没有醒来的迹象。</p><p>清醒梦本应该挺容易醒的。人意识到自己做梦时，梦境本身，就开始摇摇欲坠了。</p><p>“如果这是我的梦，那么我是不是可以改变它？能不能试试盗梦空间的方法？那部电影里的人是怎么干的，好像忘掉了……总之，俺寻思这样能成。”</p><p>池梦，希夷，甘道夫……</p><p>这个世界太疯狂，杨帝不想继续待在梦里，他想快点回到现实。</p><p>他打了个响指，然后说“要有光”。</p><p>隐隐约约有种感觉——自己开创造模式了，夺得梦境主导权。</p><p>“退潮。”</p><p>水位急速下降，露出池底龟裂的防水涂层，还有湿漉漉的墙缝。</p><p>“拆楼。”</p><p>建筑结构像融化的太妃糖垂落，在接触地面前碎成光屑。</p><p>“删掉一切。”</p><p>整座游泳馆如同被橡皮擦抹去的铅笔画，裸露出背后苍白的虚无。</p><p>“比空更空。”</p><p>那苍白的虚无也消失了，一切都消失了。</p><p>这里没有上下左右的概念，没有东南西北，这里不存在着存在，这里存在着不存在。</p><p>但虚无并非终点。</p><p>在比空更空的底色上，有东西在呼吸。</p><p>那团物质，同时呈现流沙的松散与黑洞的致密，褶皱里折叠着婴儿的胎动，与黏腻的光。</p><p>当杨帝试图用视网膜捕捉它时，双眸传来针扎般的剧痛。</p><p>——生物本能在尖叫着警告，这是不该被观测的存在，希夷！</p><p>「‘噩梦’本身，也是人类的理智所构筑起来、抵挡住它的防线……」</p><p>杨帝没想到，自己脱离梦境那一刻起，便是直面「希夷」之时！</p><p>他还以为自己会直接弹回到现实醒过来！</p>
