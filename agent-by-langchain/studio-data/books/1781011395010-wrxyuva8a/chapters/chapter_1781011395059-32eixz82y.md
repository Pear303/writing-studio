# 赛博都市

<p>……（事已至此，先看电影）……</p><p>夜晚的都市被浓稠的黑暗包裹，沉甸甸压在城市上空。</p><p>被五彩斑斓的霓虹灯切割得支离破碎。</p><p>细密的小雨如丝如缕，在灯光的映照下闪烁着微弱的光芒，纷纷扬扬地洒落。</p><p>都市蒙上了一层湿漉漉的朦胧滤镜。</p><p>人们身着雨衣，行色匆匆。</p><p>里克的目光扫过街边闪烁的全息广告，那跳跃的光影在雨幕中显得愈发迷离；落在飞驰而过的浮空车辆上，它们的尾气在潮湿的空气中留下短暂的痕迹；最后定格在行人匆匆的脚步上，雨水被踩溅起，形成各异的水花。</p><p>他身着标志性的黑色长风衣，雨水顺着衣角不断滑落。</p><p>他在熙熙攘攘的人群中搜寻着目标——那个逃脱的生化人。</p><p>人类创造出了生化人。</p><p>这些生化人拥有近乎人类的外貌、体能与智慧，被广泛应用于星际殖民、危险劳作等领域。</p><p>然而，生化人的发展逐渐失控，部分生化人产生了自我意识，试图摆脱人类的控制。</p><p>所以，人类容不下生化人。</p><p>银翼杀手的使命，便是追捕那些逃脱到地球上的非法生化人。</p><p>在城市的茫茫人海中揪出这些生化人，并将其“退休”——也就是终结他们的生命。</p><p>这就是银翼杀手的职责。</p><p>也是里克从事多年的工作。</p><p>过去十年里，他已帮助超过100名生化人“退休”。</p><p>受服务者对他的评价都非常高，无一差评。</p><p>也没有生化人投诉退休后的生活。足见其服务质量之高。</p><p>现在，他已锁定其中一名生化人的位置，她就是下一个退休目标。</p><p>里克拐进一条稍显狭窄的街道。</p><p>这里的霓虹灯更加密集，五彩色光芒，将地面的积水染成了斑斓的色彩。</p><p>街边的小吃摊散发着诱人的香气。</p><p>里克的目光被一个身影吸引住了。</p><p>那是一个青年男子，正坐在街边的小凳上吃着肠粉。</p><p>他穿着与周围人格格不入，没穿雨衣，一件普通的衬衫已经被雨水打湿，紧紧贴在身上。</p><p>衬衫也是两个世纪前的超古董款式，典型的二十世纪末至二十一世纪初流行的格子衬衫。</p><p>色彩搭配极为复古，以深浅不一的蓝灰色调为主，方格图案规整又带着一种质朴的秩序感。</p><p>衬衫的领口微微敞开，露出一小片结实的胸膛，领口的缝线处有些许磨损。</p><p>衣服上没有任何当下流行的全息装饰、智能感应纹路或能量传导线条，纯粹得就像来自另一个时空。</p><p>而且，它的纽扣竟然还是传统的硬质塑料材质！古老如斯，感觉久远得连大道都还没生成，这种格子衬衫就开始大批量生产了。</p><p>像是从博物馆盗出来的文物……</p><p>里克缓缓靠近。青年似乎察觉到了里克的目光，抬起头来，与里克对视。</p><p>他的眼神清澈而平静，没有丝毫被注视的慌乱。</p><p>“这肠粉味道不错，你不来一份？”</p><p>青年笑着说，仿佛里克是他许久未见的老友。</p><p>里克微微一愣，他没想到这个青年会主动搭话。</p><p>“我在找一个人。”里克简短地回答，目光没有从青年身上移开。</p><p>“找人？这城市这么大，人可不好找啊。”青年说着，又往嘴里送了一口肠粉。</p><p>里克：“嗯，我知道。你在这里坐多久了？”</p><p>青年耸耸肩：“我也刚来不久，这家摊子的肠粉是预制菜，做一顿只用20秒。”</p><p>里克决定不再与青年周旋。</p><p>他转身离开，继续寻找生化人的踪迹。</p><p>青年突然说道：“你是里克吧。”</p><p>里克猛地回头，眼神瞬间变得冷峻，手不自觉地摸向腰间的武器。</p><p>“你怎么知道我的名字？”</p><p>“我是杨帝，戏里戏外，都叫杨帝。你青岛喝太多了，醒来吧。”</p><p>咔——</p><p>里克在肠粉摊子上醒来，茫然地四顾。</p><p>很快，专业素养战胜了一瞬间的茫然，他迅速清醒过来，眼神恢复了往日的锐利与警觉，下意识地摸了摸腰间。</p><p>武器还在原位。</p><p>自己面前还有半盘没吃完的鸡蛋肠粉，蛋是预制的，肠粉皮也是预制菜做的，酱油……至少这个不是预制的，这也是里克喜爱这家店铺的原因。</p><p>现在地球上用手工做的饭菜，从成本，色香味，到营养价值，全方位被预制菜吊打。</p><p>手边的青岛已经喝完了。</p><p>里克站起身来，将风衣扣子系紧，帽子拉低，遮挡住自己面容。</p><p>高耸废弃建筑在雨中显得阴森恐怖，巨大的阴影笼罩地面。</p><p>他放缓了脚步，开始小心翼翼地靠近。</p><p>那座高耸废弃建筑底层一扇半掩的门后，走出一个身影。</p><p>从门后缓缓走出的，是一个身形曼妙的女子，夹克的领口处微微敞开，露出纤细的锁骨。</p><p>她身着一件蛇皮纹夹克。</p><p>少女头发湿漉漉地贴在脸颊两侧，那是一头银灰色短发，在雨夜昏暗中泛着冷冽的光。</p><p>里克心跳加速。</p><p>经过多日排查搜索，他几乎可以断定，眼前的舞女就是他追踪的其中一个生化人。</p><p>她轻抬脚步，步伐轻盈，雨水在她脚下溅起小小的水花，即将远去。</p><p>舞女环顾了一下四周。</p><p>里克微微侧身，藏在一根路灯柱后。</p><p>她眼神中透露出一丝警惕，而后警惕退散，水蓝色眸子里剩下困惑。</p><p>困惑，很快退化成松懈。</p><p>警惕性紧绷一段时间过后，会有一瞬间细微的松弛。</p><p>那是一个人注意力最脆弱的时刻。</p><p>里克看准时机，如同一道黑色的魅影般迅速从路灯柱后闪出。</p><p>手中早已紧握特制眩晕枪，扣下扳机，精准地击中了舞女的后背。</p><p>她身体一震，发出微弱闷哼，原本轻盈的步伐瞬间凌乱，整个人向前踉跄了几步，重重倒在湿漉漉的地面。</p><p>她像《人类一败涂地》的小人那般试图挣扎起身。</p><p>然而四肢如灌铅沉重，身体不受控制地抽搐了几下，便彻底丧失行动能力。</p><p>神经鞭，子弹本身并不致命，但会释放出一阵微弱的电流。</p><p>电流并非简单的麻痹作用，而是能够直接干扰神经系统，使被击中的人暂时瘫痪。</p><p>副作用是极度的剧痛。</p><p>毕竟直接对脊柱神经动手脚。</p><p>里克快步上前，掏出束缚手铐，将她双手反铐在背后。</p><p>他半拖半拽，将舞女带到停在不远处的黑色悬浮车上，开去了审讯室。</p><p>打开了房间里的一盏强光灯，强烈的光线直直地照射在舞女脸上。</p><p>她醒了，缓缓抬起头。</p><p>水蓝色眸子在强光下微微眯起。</p><p>里克则坐在她对面，表情严肃，调试好仪器，几部机器监控着心跳脉搏和呼吸频率，摄像头对准她的眼睛。</p><p>他清了清嗓子，率先打破沉默：“我希望你明白，现在配合是你唯一的出路。接下来我会问你一些问题，你要如实回答。”</p><p>“我在哪？”</p><p>“你叫什么名字？”里克没有回答，而是盯着屏幕上舞女的眼睛。</p><p>“我你，放开我。”她平静地回答。</p><p>银翼杀手和生化人经过一番友好交谈，最终舞女屈服。</p><p>在正式处决之前，生化人都会做一遍移情测试（Voight-Kampff），用最确凿（存疑）的证据，证明眼前的人是生化人。</p><p>舞女坐在里克对面。</p>
