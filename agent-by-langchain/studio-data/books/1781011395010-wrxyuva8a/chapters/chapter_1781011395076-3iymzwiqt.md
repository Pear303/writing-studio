# 馆长走此小道

<p>瑞弗维尔离开了临时囚室。</p><p>他跟着侍从在王宫中曲折的回廊间穿梭，脚步不自觉地加快。</p><p>周围华丽的装饰和忙碌的仆从，在他眼中都如同虚幻的泡影。</p><p>近卫给瑞弗维尔戴上兜帽袍子，二人快速来到王宫一处密室。</p><p>密室里，光线昏暗，只有几盏摇曳的烛火散发着微弱的光芒。</p><p>国王正背着手，静静地站在房间的中央。</p><p>听到脚步声，他缓缓转过身来，目光落在瑞弗维尔身上。</p><p>国王示意瑞弗维尔噤声，随后走到他身边，压低声音说道：“瑞弗维尔，其实朕相信你。”</p><p>瑞弗维尔眼中闪过一丝难以置信的光芒，“陛下，您……确定？”</p><p>国王摆了摆手：“你跟随我多年，我深知你的为人，你绝非信口开河之辈。此次将你流放到末日火山，是委派你去调查末日火山，暗中留意一切异常，一有发现，立刻回来向我报告。”</p><p>瑞弗维尔心中涌起一股暖流，他单膝跪地，激动地说道：“陛下放心，我定不辱使命！”</p><p>国王微微点头。</p><p>他目光转向密室的一侧，轻咳一声。</p><p>只见一道黑影从黑暗中悄然走出，步伐咚咚咚！</p><p>那沉重的步伐声，如同战鼓在耳边敲响，压迫感极重！</p><p>瑞弗维尔心跳漏了一拍——他感觉自己仿佛的面对一头凶猛的暴龙，压力让他几乎喘不过气！</p><p>待黑影走近，瑞弗维尔才看清，是一名身材魁梧的战士。</p><p>身着黑色精钢打造的轻甲，上面刻满符文，散发着淡淡的灵能光芒。</p><p>国王看着瑞弗维尔，介绍道：“这位是哈蒙德，八环级别的战士，实力不容小觑。此次我命他与你同行，一路护送你并协助你调查。”</p><p>哈蒙德微微躬身，向瑞弗维尔行了个军礼。</p><p>眼神中，历经过无数沙场的洗礼，带着一种让人胆寒的暴戾与决绝。</p><p>仿佛只要这位八环级别的战士一出手，就能将一座山头撕成碎片！</p><p>国王表情变得严肃起来，压低声音：“你们此去务必小心，教廷那边有古怪。我虽为国王，但在圣古琉斯光明圣教面前，也不得不有所顾忌。你们要时刻保持警惕，切不可掉以轻心。”</p><p>瑞弗维尔与哈蒙德对视一眼，彼此眼中都闪过一丝惊愕。</p><p>教廷有鬼？！</p><p>国王面色凝重，继续低声说道：</p><p>“自从一百年前，圣骑士‘巴德’讨伐卡利斯托成功，光明圣教教廷的威望达到极点。</p><p>“从那之后，他们借着声望，立刻封锁了末日火山，严禁任何人靠近。</p><p>“起初，大家都以为这是为了防止卡利斯托的残余力量外溢，对大陆造成危害。</p><p>“但后来发生的一些事，让我觉得其中另有隐情。”</p><p>国王将墙边一块幕布拉下。</p><p>一幅巨大的地图展现在瑞弗维尔和哈蒙德眼前。</p><p>地图上，以末日火山、星渊井口为中心，周围的区域被密密麻麻的红色标记所覆盖。</p><p>一些关键地方被打上钉子，帖上各种图片，用红线连接起来。</p><p>“这些年，教廷以守护大陆安宁为由，不断扩充势力，在各地建立起严密的情报网络。</p><p>“这些红色标记是近年来教廷势力的扩张范围，几乎都围绕着末日火山周边。</p><p>“同时，星渊井口也被他们重兵驻守，就算是我的人，也很难出入。</p><p>“而且，他们对任何与焚灭天空之龙·卡利斯托相关的消息，都极为敏感。</p><p>“一旦发现有人提及，光明圣教便会想尽办法压制。</p><p>“我曾暗中派人去调查，可他们要么背后中20个法术自杀，要么杳无音信再无下文。”</p><p>瑞弗维尔瞪大眼：“教廷……果然藏了不见得光的秘密？”</p><p>国王缓缓点头，“很有可能。他们急于否定你的预言，或许是害怕你真的揭开某些他们不想让人知道的真相。”</p><p>哈蒙德捏起拳头：“这些家伙，肯定在搞什么阴谋。要让我发现他们的恶行，定不轻饶！”</p><p>俨然一副满脑肌肉的物理战士形象。</p><p>国王看向哈蒙德，严肃地说：“哈蒙德，你虽然实力强大，但教廷高手如云，切不可鲁莽行事。你们的首要任务是调查清楚情况，而不是打草惊蛇。”</p><p>国王又将目光转向瑞弗维尔。</p><p>“瑞弗维尔，此次前往末日火山，你要留意一切不寻常的迹象。也许巨龙‘卡利斯托’只是一个表象，背后隐藏着教廷更大的阴谋。”</p><p>更大的阴谋……要见证历史了？</p><p>瑞弗维尔内心深处，某根弦被触动。</p><p>“陛下放心，我定会全力以赴。只是……我们该如何避开教廷的耳目，到达末日火山？”</p><p>国王微微一笑，从桌上拿起一份文件递给瑞弗维尔。</p><p>“这是我为你们准备的假身份和通行文书，你们将以边境贸易商人的身份，沿着这条秘密路线前往末日火山。这条路线虽然偏僻难行，但能最大程度避开教廷的眼线。”</p><p>瑞弗维尔接过文件，仔细查看了一番。</p><p>身份很完美，西土大国圣古琉斯前往东方取金的传教士兼商贩子。</p><p>有了这些，成功把握又多了几分。</p><p>哈蒙德拍了拍瑞弗维尔的肩膀，“放心吧，有我在，定能护你周全！”</p><p>这位战士很豪爽，在国王陛下面前也不拘小节。</p><p>瑞弗维尔和哈蒙德深知此次任务的紧迫性与危险性，接过文件后，二人立刻准备启程。</p><p>国王亲自引领他们来到密室的一处石墙前。</p><p>他按顺序推动书架上特定的几本书，石墙上边，暗门缓缓打开，一股陈旧气息扑面而来。</p><p>密道如同一条沉睡的远古巨蟒，巨蟒张开深渊巨口，等待有缘人踏入。</p><p>往里面看去，不见尽头。</p><p>但能看见两侧墙壁上偶尔会出现一些壁龛，里面摆放着不知何用的陈旧物件。</p><p>有的像是古老的油灯，有的像是残缺不全的雕像，这些物件都蒙着厚厚的灰尘，仿佛被时间遗忘在了这里。</p><p>“这便是通往城外的密道，你们沿着此道前行，便能悄无声息地离开圣古琉斯王城。”</p><p>国王指着密道深处，低声解释，“这条密道是先王为应对战乱所建，知晓它存在的人极少，这一百年来都没教廷的人走过。快走吧，囚室没人，他们就会怀疑了。”</p><p>“是。”</p><p>“定不负陛下期望。”</p><p>二人告别国王，告别圣古琉斯王城。</p><p>他们屏着气息，缓缓踏入这条黑暗的密道。</p><p>暗门在他们身后“轰”一声关闭，将密室的光线隔绝在外，只剩下无尽的黑暗笼罩。</p><p>密道中弥漫着一股潮湿的味道，墙壁上偶尔闪烁着点点幽光，不知是何种奇异的苔藓所发。</p><p>“啪嗒。”</p><p>哈蒙德瞬息释放了个三环法术·实体光球。</p><p>小光球悬浮在他手心，照亮二人的脸。</p><p>瑞弗维尔：“诶？你不是战士吗？怎么还对这种圣光法术这么熟练。”</p><p>哈蒙德大笑。</p><p>他一把撕下人皮面具，露出瑞弗维尔白天曾见过的、其中一个红衣主教的脸：“因为吾行于黑暗，供奉光明。”</p>
