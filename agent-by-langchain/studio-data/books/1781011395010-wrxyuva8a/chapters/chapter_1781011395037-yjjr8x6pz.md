# 再探旧校区4

<p>沿着艺术楼清洁工具间的应急通道向下，金属梯阶发出吱呀震颤，锈屑簌簌落进领口。</p><p>推开通往四楼的铁门，穿堂风裹着墨汁陈腐气扑来——书法间到了。</p><p>屋内凌乱得像被飓风席卷过。</p><p>毛边纸、宣纸、废草稿层层堆叠，在地面堆成歪斜纸山，踩上去便发出脆弱的“咔嚓”声。</p><p>桌上堆叠的宣纸足有半人高。</p><p>杨帝掀开最上层的《兰亭集序》临摹稿，摊开的八尺稿纸上，狂草字迹如蛇行。</p><p>杨帝凑近，手电光定住纸面：</p><p>「混沌辟兮星辰列，深邃域兮影重重。穹宇阔兮界难寻，响惊神兮心绪扰。」</p><p>“胡哥，你听说过这首楚辞吗？”</p><p>“好像没有，也许是不甚知名的篇章。”</p><p>胡彦卓戳了戳纸角，“看落款，熟人。”</p><p>泛黄的宣纸上，力透纸背的小字刺进眼底：“稷海理工，2013，陈昭。”</p><p>正是之前那丑逼石膏像的创作者。</p><p>杨帝也啧啧称奇：“没想到这位还是个全能型人才，既懂雕刻，也略通书法。”</p><p>但这时，胡彦卓发现了盲点，“有点不对……”</p><p>“咋？”</p><p>“旧校区是2012年废弃的，不应该有人2013年还滞留在此。”</p><p>“也许这里的‘2013’，指的是2013年毕业的那一届。”</p><p>杨帝掏出手机，将这幅书法拍摄了下来。</p><p>一路上，其实他已经拍了十几张照片，只要稍微觉得有些异常，就会选择记录。</p><p>既然“希夷”这种不可名状之物，可以存在于胡彦卓拍摄的那张.jpg图片上，说明拍照片，也许是种可以和“神秘”接触的方法。</p><p>只不过，目前杨帝没有多少收获。</p><p>比如他期待着，把那石膏雕塑拍下来后，能通过照片看见雕塑上有旋涡状印记。</p><p>但这种恐怖片桥段，并没有在现实发生。</p><p>“卟吱——歪比巴卜——混沌辟兮星辰列，深邃域兮影重重。穹宇阔兮界难寻，响惊神兮心绪扰……”</p><p>杨帝脑子里有个声音传出来。</p><p>是希夷，它又醒了。</p><p>这回醒来，它说话更有清晰条理，甚至能朗读出宣纸上的内容。</p><p>“现代地球掌管暴食和贪睡的神，我的好希夷哦，你终于醒来啦？”</p><p>“老大，我好像像你索取太多‘精神’了……”</p><p>它居然也开始诞生出感情了，话语中透着一股人性化的心虚。</p><p>杨帝笑笑：“吃吃吃，随便吃，你就敞开肚皮吃，我抗造。”</p><p>「精神+1+1+2+3……+55」</p><p>精神值如流水般攀升，却在某刻戛然而止。希夷停了下来。</p><p>“怎么希夷牢弟，现在胃口这么小，吃这么点就完了？”</p><p>“不……不是的，老大。”</p><p>希夷的声音在脑海中回荡，带着一丝犹豫，“我发现了一些……熟悉的东西，就在您拍摄的这些照片里。”</p><p>“嗯？你居然能读取图片。”</p><p>“老大，我就住在广义上的图片里……我只能通过老大你的精神，或者是相册里的图片，才能看到外面的世界。”</p><p>“原来是这么奇特的习性。好像也是，我最初见到你，你就是藏在一个.jpg照片里的。”</p><p>杨帝翻阅手机上的照片。</p><p>每一张照片都看似平常，歪斜的纸山，凌乱的桌面，还是那幅狂草楚辞，都不过是旧校区废弃房间中的寻常景象。</p><p>“你熟悉的在哪？指给我看。”杨帝说。</p><p>“老大，这里……还有这里。”</p><p>希夷的声音指引着，杨帝的目光最终定格在两张照片上。</p><p>一张是陈昭留下的楚辞临摹，另一张则是那尊平凡无奇的石膏雕塑。</p><p>杨帝左看右看，也没瞧出这两张照片有什么异样，它们只是将所见的一切，原封不动地呈现在了屏幕上。</p><p>“老大……感觉好熟悉啊，就好像，我见过，你说有没有可能就是我写的？”</p><p>杨帝表面波澜不惊，内心哈哈大笑。</p><p>“你没手没脚，还长得如此抽象，怎么会是你写的和刻的呢。”</p><p>希夷不做回答，片刻它才疲惫地说话。</p><p>“老大，我又要睡下了。”</p><p>年轻就是好，倒头就睡。它又补充了一句：“吃得好饱，嗝，感谢老大的馈赠。”</p><p>“等等，你有没有想起来，更多‘耶罗符印’相关的事情？”</p><p>“那块铁饼……我不知道，我不知道它怎么来的，我第一次‘醒来’时，它就在我身上。”</p><p>……</p><p>杨帝收回手机，手电筒打开强光。</p><p>光束在霉斑遍布的墙上游移，在某处凝滞。</p><p>光亮照射之处，此刻胡彦卓蹲下了身，挑起半张泛黄的宣纸。</p><p>宣纸后墙根处覆盖的地面，有一块墨渍。</p><p>杨帝也凑近过去：“有啥发现？”</p><p>他闻见霉味里混着墨臭。</p><p>墙根处洇着巴掌大的污渍，表面覆盖着狂放的草书笔迹，墨色尚新。</p><p>但透过那些张牙舞爪的笔画，依稀能看见底下沉淀着更幽深的黑色。</p><p>两层墨迹，有人用新墨覆盖了旧痕。</p><p>杨帝的指尖已经触到墙面。</p><p>冰冷。黏腻。</p><p>他触觉的细节感受力也极大增强，所以能辨别出来——墙根处的“旧墨水痕”，画的是三条弧线首尾相接组成的漩涡。</p><p>漩涡在意识里缓慢旋转，与耶罗符印上的纹章基本吻合。</p><p>“真的有耶罗符印同款的漩涡图案，藏在艺术馆的某些角落……但为什么被人涂掉了？”</p><p>杨帝敲敲脑门。</p><p>上层楼的那个石膏雕塑也一样……那里原本也应该有个漩涡图案。</p><p>但同样被不知何人，用刻刀铲掉，抹平了。</p><p>他想象出这么两股力量：前人画上耶罗符印图纹，后者又刻意将其抹去。</p><p>这背后究竟隐藏着怎样的爱恨情仇，利益纠葛，狗血往事？</p><p>情报太少，一个加强连的福尔摩斯来了，都未必分析得出来什么信息。</p><p>杨帝太阳穴微涨。</p><p>耳边响起细碎的啃噬声，像是千万只白蚁蚕食现实的边界。</p><p>它们要在这个世界咬开一个破洞，让一尊更庞大的存在，能够降临这边……</p><p>某种震颤顺着指腹窜上脊椎，心灵中炸开「精神+1」。</p><p>他猛地缩手，指间残留着被无数细针同时刺入的幻痛。</p><p>“咋了？”胡彦卓也蹲在一旁，打量他瞬间苍白的脸。</p><p>“没事，静电吧。”杨帝扯动嘴角。</p><p>胡彦卓仍盯着墙面：“这些划痕倒像小孩子乱画的。”</p><p>在他眼中，剥落的墙皮下只有几道歪斜划痕，和一滩也许是不小心打洒的墨水。</p><p>胡彦卓什么也没发现。</p><p>那些新墨覆盖下的笔锋转折、墨色浓淡的微妙层次，被自动简化成无序的划痕。</p><p>新墨与旧痕叠加，在他视觉皮层里，混淆成一片混沌的灰黑。</p><p>胡彦卓的大脑过滤了太多细节，看不清掩藏在新墨下的真相。</p><p>“走吧，咱继续下楼看看。”杨帝后退半步，转移话题，如是说道。</p><p>二人继续往外走。</p><p>然而，沿着走廊走到尽头时，发现楼梯口还是被各种杂物堆死了。</p><p>“真的是防君子不防丧尸。”</p><p>摇头苦笑间，他们转身寻找其他通路，或许清洁工具间里，还藏着另一道旋转楼梯。</p>
