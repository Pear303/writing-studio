# 光的反面

<p>“希夷！”</p><p>“老大，我缠住他。这是唯一的机会。”</p><p>下一刻，杨帝耳边再度响起砰砰砰的爆裂。</p><p>麻雀形态的希夷，与陈昭继续缠斗！</p><p>“找死！”陈昭脖颈青筋暴起，扭曲的面孔浮现出诡异纹路。</p><p>他也是将胡彦卓“质壁分离”后，才夺舍其身体。他也能使用“黑色拉面”的力量。</p><p>陈昭抬手瞬间，无数黑色拉面状物质从七窍窜出，如同活过来的触手将希夷缠住。</p><p>这些触手表面布满血管般的凸起，每一根都在疯狂蠕动着禁锢希夷，被触及的羽毛迅速变得黯淡无光。</p><p>“啾！！！”希夷尖锐的鸣叫震得地下室墙面簌簌掉落碎石，它周身炸开一团团黑色光晕，试图震碎束缚。</p><p>杨帝咬牙：“别管我了，你走，希夷！”</p><p>他躺在原地，动弹不得。</p><p>被刀子直接扎进心脏，还是比较难适应的。</p><p>与精神层面的杀伤相比，这种物理层面的致死破坏，让他身体陷入物理性质的瘫痪——这不是用意志就能克服的。</p><p>除非有一天，杨帝能超越碳基的限制……</p><p>更何况，先前与那些狸花猫、小白鼠经历过盘肠大战，体力也确实是濒临极限了。</p><p>希夷不从：“你是老大……你不能不走……”</p><p>“放屁！你要是有我的记忆那你应该记得我16岁那年一口气看完《天元突破》。你要是认我老大，认我作大哥，就应该明白，我是卡米纳，你才是西蒙！”</p><p>“……呵，那很简单，我反过来篡夺你大哥之位不就行了？”</p><p>希夷仍在与陈昭交战。</p><p>它双翅展开，在空中划出混元形意太极八卦图，无数黑色羽毛如暴雨般射向陈昭。</p><p>陈昭瞳孔骤缩，调集黑色拉面组成盾牌。</p><p>黑羽击中盾牌的瞬间，地下室响起连绵不绝的玻璃破碎声，黑色拉面被切割得支离破碎，化作黑色烟雾弥漫四周。</p><p>希夷趁机俯冲而下，利爪直指对手咽喉。</p><p>却在即将触及的刹那，被陈昭突然伸出的拉面触手缠住脚踝，重重摔在地上。</p><p>它颤巍巍站起，用最后的力量凝聚出无数细小的黑色箭矢，暴雨般射向陈昭。</p><p>陈昭挥舞手臂，黑色拉面组成的护盾将箭矢尽数挡下。</p><p>他眼中闪过不耐烦：“垂死挣扎！”</p><p>话音未落，整个人化作黑色拉面洪流，裹挟漫天触手，朝希夷席卷而去！</p><p>这是绝死一击。</p><p>空气中响起令人牙酸的骨骼挤压声，希夷的羽毛被撕扯得漫天飞舞。</p><p>它重重摔在墙壁，拿出个裂纹直径50厘米的坑，身体嵌在坑的中央。</p><p>它已变得若隐若现。</p><p>这一切都发生在短短10秒内。</p><p>杨帝沉痛地闭上眼睛。他感觉自己能够控制肢体了，但距离有能力爬起来，至少还需要……20秒。</p><p>此时此刻，距离他心脏被捅一刀，也才仅仅过去100秒罢了。</p><p>普通人心脏被捅一刀，大部分会在100秒内死去。</p><p>而杨帝的100秒，则能适应这般致死性的伤害，恢复最基本的行动能力。</p><p>他离人已经很远了，但还不够。这个速度，根本不够……</p><p>杨帝看向若隐若现的希夷。</p><p>如果没有撞破陈昭的阴谋，或许“希夷”现在已经步入中年危机，或许已经结婚生子，或许还在新生咨询群里和众人讨论如何炒股，时不时被股市收割韭菜……</p><p>杨帝只能叹息：“你到底能不能想起，自己的名字是什么？如果可以，我回去以后给你配一套衣冠冢。”</p><p>精神链路中的那个家伙沉默了一会儿。</p><p>“老大，以往的一切，我都已然忘却。”</p><p>“我吞噬了你大量的精神力，获取了老大90%的记忆，已经相当于活出了第二次生命，我已很满足了……”</p><p>“噗！”</p><p>陈昭走过来，给挣扎着要爬起身的杨帝又补了两刀，分别扎在咽喉、肺部。</p><p>他自己胸前那块冰凉的耶罗符印，被陈昭取走了。</p><p>他便这样始终待在自己身边两米范围内，确保不会触发符印的“绑定诅咒”。</p><p>没有碳水和蛋白质补充，杨帝的身体恢复速度很慢很慢。</p><p>身上三处致命伤，愈合速度只能达到普通人的二三十倍，远远不足以在有意义的时间内恢复至全盛状态。</p><p>更别提将耶罗符印夺回来。</p><p>杨帝感觉到，自己的身体正在关闭五感，只留下最后一识——意识。</p><p>他看不见光，听不见声音，无法感知自己的身体，但能感受到自己思想的存在。</p><p>他还能察觉到，整个地下室，正在变成某种意识的“子宫”。</p><p>陈昭的仪式成功了？耶罗大仙能够以某种方式影响现实了？</p><p>有某个存在，一个超越时空和因果的意志，祂的目光正以超越物理法则的姿态穿刺而来，祂就是耶罗大仙。</p><p>来，还是去？</p><p>杨帝俘获了那道伟大的目光，看见祂所见之地，追溯到祂所在之地。</p><p>世界在他眼中急剧缩小。</p><p>目光先是洞穿地下室潮湿的天花板，裂开十米厚的土层与钢筋混凝土。</p><p>接着撞碎臭氧层外三百公里处的电离层，在大气层顶端激起极光般的涟漪。</p><p>它继续攀升，穿透范艾伦辐射带，在地球同步轨道上跃过数颗人造卫星。</p><p>并未停留，而是以超越光速跨越地月之间三十八万公里的真空。</p><p>月球表面的环形山被目光所震颤，阴影处的冰尘激荡，逆重力悬浮腾起。</p><p>它抵达火星轨道，划过奥林匹斯山的火山口，掠过柯伊伯带，穿越奥尔特云。</p><p>目光掠过半人马座α星的三体系统，三颗恒星的运行轨迹因它的经过而短暂偏离。</p><p>星际空间之中，划出一道扭曲的时空涟漪。</p><p>这是微不足道的时空涟漪，要知道，至少需要中子星碰撞，才能引发人类目前科技水平所能观测到的引力波。</p><p>目光飞驰到一百三十七亿光年外，类星体群骤然集体爆发，伽马射线暴在宇宙膜上撕开无数细小的裂缝。</p><p>透过裂缝，目光触及可观测宇宙的边界。</p><p>耶罗大仙看见了他。</p><p>目光的焦点汇聚在杨帝身上。</p><p>杨帝看见了祂。</p><p>深渊凝视我之时，我也在凝视深渊。</p><p>他感觉自己的“灵”，正在被某种超维存在拆解，每一粒细胞，每一缕思想，都暴露在无穷维度的审视，剖析，肢解之下。</p><p>周围是一片无穷无穷浩瀚浩瀚的星空，万千星辰闪烁，星空深处传来低频的嗡鸣。</p><p>漫天的星星——杨帝目前的知识体系只能将它们当做“星星”——既非球体亦非方体，既非点状也非线状。</p><p>星辰的形态诡谲。</p><p>正面望去，它们勉强维持近似星体的轮廓。</p><p>但若稍一偏转视线，余光中的它们便如融化的蜡像般流淌。</p><p>比梵高的星空更魔幻，更魔性。</p><p>它们没有固定形状，哪怕是瞬息的平静，也不存在……</p><p>幽深星空传来阵阵低语，宇宙在杨帝耳畔呢喃。</p><p>世界投下自己的阴影，在他大脑每一条褶皱沟中低语。</p><p>这里是宇宙最深处的狂想，是理性认知的坟场！</p><p>杨帝的目光触及它，眼球——或者是大脑顿感灼痛！</p><p>那不是人类视网膜能解析的光谱，那是无数种扭曲的色阶！！</p><p>无星之处翻涌着液态的黑暗，那黑暗不是缺乏光线，而是“光的反面”——杨帝只能想出这么一个描述。</p>
