# 它们还会回来

<p>桂虚浑浊的眼睛猛地睁大，身体不由自主地挺直了一些，布满皱纹的脸上写满了难以置信的震惊。</p><p>联盟最高执政官？！</p><p>那个传说中如同神祇般的存在？</p><p>直接找他这个行将就木的老头子？</p><p>“无需紧张，先生。我以联盟最高权限，重启了对‘黄粱一梦’事件起因的调查。我需要了解在你休病假期间，具体发生了什么？尤其是……你与某某的那次通话。”</p><p>桂虚的身体剧烈地颤抖起来。</p><p>不是因为恐惧，而是因为那段被刻意尘封、带着巨大痛苦和背叛感的记忆，被这个至高无上的声音粗暴地掀开了盖子。</p><p>他沉默了很久，久到帝尊以为通讯中断了。</p><p>终于，一个沙哑苍老与苦涩的声音，断断续续地响起，仿佛每一个字都带着锈蚀的尖刺：</p><p>“他……某某……打电话给我……就在我回国后没两天……咳……咳咳……”</p><p>桂虚剧烈地咳嗽了几声。</p><p>“他说，系统……我负责的核心模块，出大问题了，‘阴伏流煞’……那个我留下的后门失控了，引发了连锁崩溃。</p><p>“他搞不定，项目要黄了，整个团队都要完蛋……求我看在多年同事和朋友的份上，告诉他怎么……怎么才能绕彻底解决它。</p><p>“我、我他妈就是个傻子啊……我当时刚丢了工作，心里也憋屈。但听到他那么着急声音……都带着哭腔说大家都要失业……我、我心软了。</p><p>“我居然相信了他……我把关闭后门的管理员密钥，还有临时抑制‘阴伏流煞’爆发的应急代码，都……都告诉他了，清清楚楚……”</p><p>老人的呼吸变得急促，胸膛剧烈起伏。</p><p>浑浊的泪水顺着沟壑纵横的脸颊流下。</p><p>“结果呢？结果呢？！他拿到代码转头就把我卖了。</p><p>“他拿着我告诉他的东西，还有他早就偷偷录下的、我承认留下后门的通话录音，直接举报给了公司安全部和法务部。</p><p>“那个人，说我是蓄意破坏公司财产，埋藏系统后门的叛徒。</p><p>“我把解决方法告诉他，还不到半小时，微硬公司法务部就给我打来电话。</p><p>“声称将对我发起诉讼，行业内通报，彻底封杀我，连解释的机会都没有，百口莫辩。</p><p>“在IT行业，删库跑路是最恶劣的行径。就算同情我的人数不胜数，认为我干得漂亮的人成千上万，我也彻底断绝了在这条路上的前途。”</p><p>桂虚的声音陡然拔高。</p><p>“但在那遭受巨大背叛的半个小时……我、我感觉不一样了。</p><p>“之前那场‘流感’，让我感觉——那些代码，那些网络，它们好像活过来了。</p><p>“我能‘听’到它们在‘说话’……我能‘感觉’到数据在‘流动’……我对它们有一种前所未有的‘亲和力’。</p><p>“当时那短短半小时，我是多么恨某某，多么恨微硬！我脑子里只想着要报复，要让他们付出代价。</p><p>“既然他们说我留后门是犯罪……那我就给他们留一个真正的，毁灭性的后门。</p><p>“我用我那‘病’后，变得很奇怪的……信息入侵和编程能力，侵入公司数据库。</p><p>“天助我也，当时他们的数据库系统一直联网，似乎是因为正在谈一桩大生意，没有切断与外部的物理联系。</p><p>“通过另外一个我自用的、只是用来调试程序的后门，我找到了一条更深、更隐蔽的路径。</p><p>“我在‘黄粱一梦’最底层，在前辈留下的某一座屎山代码之中……重新植入一个全新的‘阴伏流煞’漏洞。</p><p>“当时我就是怀着深深的恨意，对背叛的恨意，重新植入了它……</p><p>“它更隐蔽，更恶毒，就像深埋的……定时核弹。然后，我就等着，等着看它什么时候炸！</p><p>“再之后，听说那公司动用了足足四十多个人，都没能解决我留下的新漏洞。”</p><p>桂虚说完这一切，仿佛耗尽了所有力气。</p><p>他瘫坐在椅子上，只剩下粗重的喘息和压抑不住的呜咽。</p><p>帝尊：“感谢您的坦白，不过现在微硬公司早已被拆解，您昔日的同事和所敌视之人，也对您并没有恨与恶意。”</p><p>“是啊，神圣人类联盟就是好啊。”</p><p>「现实」比「真相」更复杂一点点，也更残酷一点点。</p><p>正当桂虚即将讲述完充满恨与遗憾的过往。</p><p>他那原本因为激动而颤抖，带着浓重衰老气息的声音，在帝尊的感知中，如同被投入沸水的温度计，瞬间发生了根本性的剧烈转变！</p><p>不再是那个行将就木、满心怨恨的老人。</p><p>通讯链路中，桂虚的啜泣和喘息戛然而止。</p><p>取而代之的，是一个截然不同的声音。</p><p>它不再苍老沙哑，而是变得恢弘低沉，仿佛青铜巨钟在无垠虚空中敲响，带着一种宛如预言般的韵律：</p><p>“聆听，执掌权柄者！”</p><p>这不是桂虚！</p><p>有什么东西……附身？觉醒？</p><p>还是更高维度的存在，通过这个饱受创伤的衰老灵魂在传讯？</p><p>“汝以为，凭借冰冷的机械与无形的网络，能架构永恒的秩序？”</p><p>“汝以为，根除了扭曲的实体，清扫了污秽的皮囊，便涤荡了人心深处的幽暗？”</p><p>“人类可以检阅永啼之面，可以焚寂山土，却不可照灭心中暗！”</p><p>“仇恨、嫉妒、自私、狡诈、背叛、冷漠……”</p><p>“古老的原罪，从未离去！”</p><p>“它们只是蛰伏！如同沉眠的火山，如同深海的涡流！”</p><p>“纵使汝以纳米之丝，连接亿万生灵的浅层思绪，编织名为‘集体’的幻梦……”</p><p>“汝可曾真正触摸到那……集体潜意识之海的深处？”</p><p>帝尊的心神巨震！集体潜意识！</p><p>这是比HOLOS目前能映射的人类表层思维网络更深邃、更混沌、更不可测的领域！</p><p>是孕育神话、噩梦、集体疯狂与所有非理性冲动的深渊！</p><p>在她的母宇宙，它更是被称作——虚境。</p><p>“在那里！在汝那精密仪器无法触及的混沌渊海！”</p><p>“那毫无约束、全盘放纵的欲孽，仍在翻滚沸腾！”</p><p>“那渴求死亡、战争与血的暴虐，仍在磨砺爪牙！”</p><p>“那蛊惑心智、污染智慧的奸诈，仍在编造谎言！”</p><p>“那憎恶纯净、仇恨美好的污垢，仍在悄然蔓延！”</p><p>每一个被点名的“罪恶”，都仿佛化作了实体，在帝尊的意识中投下狰狞而古老的阴影。</p><p>她感到一股源自灵魂深处的寒意，比面对任何S+15级怪谈都要冰冷。</p><p>“它们在等待！它们在积蓄！”</p><p>“终有一日，它们将挣脱束缚的假象，撕碎汝精心构筑的秩序穹顶！”</p><p>“它们将污染宇宙的基石！它们将扭曲时间的河流！”</p><p>“甚至……”</p><p>那声音在此刻停顿，带来一种令人窒息的死寂。</p><p>随后，一句更冰冷更绝望的话语，如同冻结的星辰碎片，狠狠砸下：</p><p>“……它们那源自‘未来’的污秽之身，已然渗透至‘当下’的缝隙……”</p><p>警告如同冰冷的洪流，冲刷着帝尊的意识。</p><p>山脚下，溪流旁的豆腐花摊前，时间仿佛凝固。</p><p>“姑娘，还要添点糖桂花不？”老奶奶慈祥的声音带着山野特有的烟火气。</p><p>帝尊意识到，刚刚又做梦了。</p><p>但这不是梦境，至少比梦境更「真实」。</p><p>诡异，扭曲，混沌……它们并未离去，而是虎视眈眈。它们还会回来。</p>
