# 希夷立大功

<p>“老大快闪开！”希夷声音从怪物体内传出。</p><p>但那是通过“神交”传出的声音，只有杨帝听见。</p><p>此刻，楼梯间的灯泡虽然不亮，却仍然在某种力量作用下纷纷爆裂。</p><p>杨帝本能地扑向胡彦卓，两人在碎玻璃雨中滚下楼梯。</p><p>他们抬头，不约而同把手电筒照过去。</p><p>被希夷占据的哈基面，正以违背物理规律的姿态，悬浮半空。</p><p>那些面条状触须，像是被强酸腐蚀的DNA螺旋链，抽搐着溶解成黑色黏液。</p><p>哈基面像融化的蜡般融化，流淌，剥离。</p><p>墙体和楼梯像是石头形状的海绵，那滩黑泥滴落后，就被吸收，融入进去，消失了。</p><p>只在原地，留下一条短尾狸花猫。</p><p>狸花猫走过来，蹭蹭杨帝的裤腿：“老大，我有物质界的身体了喵。”</p><p>一旁，胡彦卓打了个寒颤，看向那狸花猫：“杨帝……这猫是不是在和你说话？”</p><p>他手持钢管，甚是怖惧。</p><p>刚刚还黑色拉面模样的怪物，在用杨帝手机里某张图片对准后，又变回了狸花猫。</p><p>杨帝蹲下撸猫，一边意外地看向胡彦卓。</p><p>“胡哥，你居然能感觉到我们的‘神交’，说明你的‘精神’属性确实很高。不过别怕，它现在是自己人了。”</p><p>……</p><p>杨帝和胡彦卓背靠背，坐在满是裂痕的楼梯上，粗气在静谧的空间里凝成白雾。</p><p>那只狸花猫乖巧蹲坐在杨帝脚边，短尾巴悠闲地敲他的裤管，瞳孔里流转着金芒。</p><p>胡彦卓瞥一眼那猫。</p><p>“我说，杨帝兄弟……你保证这只被‘希夷’附身的猫无害……但你怎么知道的？你又是怎么将那只……‘哈基面’打回原形的？”</p><p>杨帝苦笑一声，伸手挠了挠狸花猫的下巴，猫咪发出惬意的呼噜声。</p><p>“胡哥，还记得你发在学生群里那张蓝天红气球的照片吗？那天我盯着图片看了太久，再睁眼，希夷就钻进我精神里了……”</p><p>他将手电筒杵在地上，望着天花板上斑驳的阴影，将那段被梦境吞噬的往事缓缓道来。</p><p>……（省略500w字）……</p><p>当然，杨帝简略了关于“无限锻炼进步”的内容，只是说“自己似乎身体素质很好”。</p><p>如此玄幻诡异的经历，一时间将胡彦卓刚建立起来的世界观，又给跌了个粉碎。</p><p>狸花猫竖起短尾巴，绕着胡彦卓的脚踝转了两圈，喉咙里发出轻柔的呼噜声。</p><p>似是在安抚人类的不安。</p><p>“反正现在这鬼地方，多一只会制造噩梦的猫也不算稀奇。”</p><p>胡彦卓也只能低声一笑，承认现实。</p><p>理性主义者不是否定一切神秘要素，而是是在混乱中寻找新的认知框架。</p><p>假如有一天，盘古被证实存在了，理性主义者并不至于世界观破灭，而是会开始思考盘古对人类的意义。</p><p>胡彦卓弯腰捡起杨帝掉在地上的撬棍，用衣角擦拭金属棍身还残留着的黑色黏液。</p><p>旧的那根S形弯棍已经耗尽耐久度了，中间的弯曲处几乎要折断，金属表面坑坑洼洼，像是被强酸腐蚀过。</p><p>握在手里，能明显感觉到内里的金属疲劳，稍微用力，就会发出不堪重负的呻吟。</p><p>这哪是撬棍，分明是被卡车碾过的甘蔗。</p><p>另一根棍，也已经濒临报废边缘。</p><p>但杨帝还是选择了半报废的撬棍。</p><p>“杨帝兄弟，这里有根新的的钢管，不把那弯掉的棍子换了吗？”</p><p>“不必，我还是喜欢撬棍。”</p><p>杨帝攥住弯棍的两端，中间压在大腿上。</p><p>“给我直！”杨帝暴喝一声，腕间青筋暴起。</p><p>弯棍发出类似骨骼断裂的脆响，弧度以肉眼可见的速度被拉直。</p><p>杨帝试着挥动撬棍，破风之声比先前更烈，断裂处竟传来龙吟般的嗡鸣。</p><p>其实那不是“龙吟”，而是撬棍内部结构加剧受损，金属疲劳严重，弹性限度降低。</p><p>用人话说，就是棍子耐久度暴跌。</p><p>希夷趴在一旁，解释：它现在这副“狸花猫”身体，完全是生物学意义上的猫科动物。</p><p>然而，类似于“相随心生”，如果这副躯体内没有“精神”，它他就会随心所欲随意变幻，没有定形。</p><p>“这就是一副空皮囊，谁都能开的EVA——而且这家EVA还能随心变形。”希夷如是评价道。</p><p>天知道它从什么渠道了解福音战士的。</p><p>应该是吞噬杨帝的“精神”后，希夷获取到的部分记忆。</p><p>真是连吃带拿，纯粹米虫。</p><p>希夷能借助这具“空”的短尾狸花猫躯壳，在物质界稳定自己的存在。</p><p>还能变换各种形态，就像刚刚变成哈基面那样的“黑色拉面”。</p><p>它原本只能寄宿在人的精神，或者是像素足够大的静态图片上。</p><p>现在，有了这具身体，希夷终于切实拥有了影响物质世界的能力。</p><p>只是，杨帝内心一直笼罩着一层阴霾——</p><p>为什么此地，会出现一只字面意义上“丢了魂”的短尾狸花猫？</p><p>……</p><p>“胡哥，走，今天的事尽量不要对外说。”</p><p>“我当然知道，说出去，别人当我神经病或者中二病。”胡彦卓苦笑。</p><p>杨帝笑着拍拍他后背，手电筒光束重新扫向楼梯上方。</p><p>原本斑驳的墙面渐渐褪去蛛网与裂痕，台阶上残余的黑色黏液，也在猫咪经过时悄然蒸发。</p><p>那些曾经藏匿在角落、蠢蠢欲动、某种连强光手电都驱不散的黑暗，慢慢退散殆尽。</p><p>一切变好。他们沿楼梯向上走。</p><p>楼梯的台阶恢复平整，剥落的墙皮后露出褪色的乳胶漆，隐约可见泛黄的安全出口标识。</p><p>胡彦卓的手指在扶手上蹭过，青苔与铁锈的触感消失了，取而代之的是光滑的烤漆质感。</p><p>当然，是蒙了厚尘的烤漆质感。</p><p>像每一座废弃几十年的旧建筑那样，尘埃与遗忘交织成时间的纱幔，轻轻覆盖一切。</p><p>这片旧校区已经废弃13年了。</p><p>普通的家中，两个月不打扫，便能到处蒙上灰尘。十三年不清理，比世间大部分狗窝都要脏乱差。</p><p>两人一猫向上走，越是向上，楼梯间的空气似乎变得清新了许多。</p><p>短尾狸花猫走在最前面，和杨帝保持着神交。</p><p>“希夷……现在一静下来，我开始回忆，就想到一种猜测。”</p><p>“老大，啥猜测喵？”</p><p>杨帝一手拎撬棍，一手捏下巴：“你会不会是条孤魂野鬼？”</p><p>狸花·希夷·猫稍稍停了下来。</p><p>“老大，你这么说人家很伤心的喵……又没有什么依据喵？”</p><p>“你看，你没有实体，只能依附于的精神，或是手机里的图片而存在。而那只‘哈基面’呢，你说他是个‘没有灵魂的空壳子’，然后你轻而易举就把它给夺舍了。”</p><p>“所以呢喵？”</p><p>“你是‘鬼’，那团黑色拉面是‘僵尸’，那一切就是说通了呀！”</p><p>“老大，这太玄幻，一点都不科学喵……”</p><p>“你吞了我这么多‘精神’，应该也看过了几部英叔的电影吧？僵尸失去三魂，七魄犹存；鬼失去肉身，三魂却有残余，两者有非常大的互补空间……”</p><p>杨帝顾着和希夷神交，没看路，一脑袋撞到胡彦卓背后。</p><p>抬头一看，原来是面前出现一扇消防门。</p><p>他们确实摆脱了无限循环的空间了。</p>
