# 法术之本质

<p>（前两章纠正一个点——雕塑长得不像鱿鱼，更像菊花。这是原则性问题。）</p><p>杨帝表面上装作虚弱又迷茫，一副娇弱林妹妹的样子，内心却异常冷静。</p><p>“黑暗水体确实能连接异界，一方水体就是联通异界的传送门。”</p><p>从瑞弗维尔的话语以及周围奇异的景象，他已经可以确认——</p><p>自己来到了一个“中世纪西幻”风格异世界。</p><p>周围火山岩犬牙交错，像是被某种超自然的力量随意扭曲塑造，呈现出奇异而夸张的形态，如一把把直指天空的利刃。</p><p>抬头望去，天空的颜色也透着诡异。</p><p>虽然此时并非夜晚，但天空却并非纯粹的蓝黑色，而是带着一抹淡淡的紫。</p><p>特别的，天上有两个月亮。</p><p>地球没有两个月亮吧？</p><p>杨帝低头看手中不断扭动的暗红色史莱姆。</p><p>方才在湖底，脑袋被这小东西缠住时，他潜意识不断提示「耐热+1+1+1」。</p><p>这史莱姆外表温和，内部却极其灼热！</p><p>至少有三百摄氏度，差点把杨帝头发都烧没了。</p><p>“所以，就是这别致的史莱姆，会把穿越过去的活物烤焦，留下带有硫磺味的暗红色粘液？”</p><p>杨帝看向身侧的深水湖畔。</p><p>湖水通往极深处，深邃黑暗，似是被世人所遗忘的角落……符合“黑色水体”效应触发条件。</p><p>但是，为什么湖底的史莱姆，体内竟如此炽热？竟然足以把蛋白质烤焦？</p><p>它们的能量来源是什么？</p><p>“灵能”在其中有没有参与作用？</p><p>因为这里是旧的火山熔融管道，所以还有残存的热液喷口、能够为生物存活提供能量？</p><p>“灵能”符合能量守恒，又或者是一种俺寻思之力？</p><p>一切都很陌生。即使有“导游”，许多常识他也得从头学起。</p><p>杨帝偷偷打量着瑞弗维尔，思索着接下来的打算。</p><p>这个自称“旅行商人”的家伙，看起来对自己没有恶意，甚至还打算带上自己同行。</p><p>或许可以通过他，先初步了解这个世界。</p><p>至于自己的秘密，在没有摸清楚状况前，还是越少人知道越好。</p><p>毕竟在画风正经的中世纪魔法世界，“神灵”这种东西往往是切实存在的。</p><p>哪天杨帝要是太跳脚，被某个神灵一巴掌轰杀……话说也杀不死吧？</p><p>……</p><p>瑞弗维尔领着杨帝，沿湖边小径前行：“杨帝，既然你对灵能忘掉了，那我便给你讲讲？”</p><p>“哦哦，求之不得。”</p><p>灵能，是这世间无处不在的一种能量，它充斥在空气、大地、水流，乃至世间万物之中。</p><p>就如同鱼儿生活在水中却不自知，大多数普通人，也感受不到灵能的存在。</p><p>但对于懂得运用它的人来说，灵能就是力量源泉。</p><p>说着，瑞弗维尔抬起手，只见一缕淡淡的金色光芒在他指尖萦绕。</p><p>“但‘灵能’和‘法术’，是两个不同的概念。”</p><p>瑞弗维尔停下脚步，转头看向杨帝，眼中带着一丝期许：</p><p>“法术的威力和效果，取决于施法者对灵能的感知、操控能力，以及法术的环数。</p><p>“环数越高，法术的威力就越强大，但施展起来也越发困难。</p><p>“高环数的法术，需要更为深厚的灵能储备，和精湛的操控技巧。”</p><p>好强的既视感！就是电子游戏里的内容嘛。</p><p>杨帝开始怀疑，自己是不是穿进什么恐龙与地下室之类的游戏了。</p><p>说不定真存在一个“异世界”，和地球人类创造的游戏、电影、小说完全相同……</p><p>而他，就来到一个西幻世界观游戏里？</p><p>杨帝摸着下巴：“那法术的原理是？”</p><p>瑞弗维尔：“咏唱咒词时，实际上是在利用这些特定的词汇和节奏，对自己的精神进行调整，从而让精神进入一种特殊的状态。</p><p>“这种状态下，精神能够更敏锐地感知周围灵能的流动，并对其施加影响。”</p><p>瑞弗维尔举了一个形象的比喻。</p><p>“灵能”好比是一堆干柴，蕴含巨大的能量，等待被点燃。</p><p>“法术”则是点火的技巧，或是一根火柴，或是一阵恰到好处的风。</p><p>施法者通过特定的「仪式」，将灵能的力量释放出来，产生不同效果，这就是法术。</p><p>“仪式？”杨帝问。异世界人民也讲究仪式感吗。</p><p>瑞弗维尔沉吟片刻，说：“怎么说呢……主要是咏唱一段咒词，咒词其实就是一段‘话语’，通过‘话语’对自我的精神产生暗示，然后通过精神影响环境中的灵能。”</p><p>杨帝：……</p><p>他貌似悟了。所谓“灵能”，就是“灵”。</p><p>一字之差，但两者指代的事物一致。</p><p>灵，灵能，在杨帝看来，是一种“衡量现实之丰度”的属性。</p><p>此事在《超科学的某高斯炮》亦有所记载，超能力者的能力来源是个人现实（Personal Reality），也就是属于个人的现实丰度。</p><p>“灵”越少，物质越不稳定，而且存在感也会变弱！</p><p>当一个物体的“灵”被完全剥夺，它会陷入极不稳定的暴走，变成一团狂躁的“黑色拉面”——类比于驾驶员精神失常时候的EVA。</p><p>这就是灵，同时也是异世界土著口中的“灵能”。</p><p>当杨帝调整好心神，再度向四周环境望去，他深深地倒吸一口凉气——</p><p>这个异世界，有点不正常！</p><p>环境中的“灵”，比地球多得多。</p><p>比如说地球上环境的灵是100，那么异世界就是500。</p><p>瑞弗维尔，这个“旅商”大概是1500。</p><p>而杨帝，只有15左右……两个人之间直接差了100倍呀魂淡。</p><p>确实，杨帝的“灵”被撕裂了一部分，现在的他，非常魂淡。</p><p>或许在这个世界，能够有让杨帝「补完」的方法。</p><p>瑞弗维尔似乎察觉到杨帝眼中的探究，笑着说：“光说不练假把式，我再给你展示个简单的法术，看看能不能回忆起什么。”</p><p>他双手抬起，掌心相对，闭上双眼。</p><p>嘴唇微微蠕动，低声咏唱一段咒词。</p><p>杨帝紧紧盯着瑞弗维尔。</p><p>他清晰地看见，一股on色的“灵”从瑞弗维尔体内缓缓溢出，顺着他的手臂，如丝线般缠绕汇聚到他的双手之间。</p><p>那些on色的“灵”像是受到某种无形力量的牵引，按照某种复杂而精妙的图案和韵律，逐渐稀释融入到周围环境。</p><p>on，研究“作为存在的存在/to on hei on”，英译为being as being。</p><p>所以，“on色”就是“灵”的颜色，中文可读作líng色。</p><p>瑞弗维尔施法成功了！</p><p>他原本约1500灵，付出了大约30灵，在手心凝聚了一小团指甲盖大小的火焰，体内剩1470灵。</p><p>不过，他失去的灵能正在以一种肉眼可察觉的速度缓慢上升，恢复。</p><p>“三环法术·驭火，厉害吧。”瑞弗维尔笑眼看向杨帝。</p><p>杨帝不语，只是捏着下巴，又发现一个奇怪的点。</p><p>“瑞弗维尔大哥……施法，需要消耗这么多灵能？”</p><p>“？这不是天经地义的吗。”</p><p>“法术”是一根火柴、一束闪电、一阵恰到好处的风，用于点燃“灵能”这个干柴堆……</p><p>但杨帝觉得，“法术”是种取巧。</p><p>他们“看不清”环境之中“灵”的情况，所以要用“消耗灵能”的方法进行施法。</p><p>杨帝也伸出了自己一只右手。</p><p>“瑞弗维尔，我也试试施法，你帮我把关……”</p><p>没有口头念咒，没有勾勒符文。</p><p>掌心“嗖”地蹿起炽烈火焰！</p>
