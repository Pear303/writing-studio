# 真实虚幻4

<p>可以自然而然地假设：构建虚拟世界所需的资源量，与现实世界总资源量相比，几乎是九牛一毛沧海一粟。</p><p>像是“十万溯光纪馆”这样的虚拟城市项目，凡人王朝显然还可以承载更多。</p><p>那么，我们就可以认为——现实世界能够创造出多个虚拟世界。很多个！</p><p>“当一个高等文明能轻易用‘边角料’构建次级虚拟世界时，事情就变得很复杂了。”</p><p>杨帝画了块千层威化饼。</p><p>A层能以九牛一毛的资源，构建出虚拟世界B层，B层能用沧海之一粟构建C层，而C层又能依样画葫芦构建D层……</p><p>就好像灵界漏下的“边角料”援助项目，能撑起凡界王朝。</p><p>凡界拨一部分财政支出，就能堆出大山里的浮空都市。</p><p>而这都市再分点算力，就能在纪念馆里捏出五百年的虚拟变迁。</p><p>一生十，十生百，百生千，千生万……</p><p>虚拟世界无限套娃下去。</p><p>59改不为所动。</p><p>「杨帝阁下，虚拟世界与现实世界相比，不论是精度，还是各项物理规律、灵能法则的准确度，必定差很多。」</p><p>他举了自己先前所做的超级工程为例。</p><p>守望者文明将采集到的物理规则与灵能法则悉数输入超级计算机，每条法则都经精确解析、参数反复校准。</p><p>模拟现实的精度极高，接近普朗克尺度。</p><p>本想通过极致精确的虚拟预演，规避现实工程风险与资源浪费，却发现模拟结果始终与真实存在偏差。</p><p>在虚拟空间中的许多参数，一旦模拟到将近普朗克尺度，便开始出现紊乱。</p><p>无论怎样调整算法，增加算力，这些参数就像脱缰的野马，完全不受控制，模拟结果与现实观测的偏差越来越大。</p><p>「所以您瞧，杨帝阁下。」</p><p>59改声音带着笃定。</p><p>「就算是我的本体——守望者文明，即使拥有海量资源，但在面对普朗克尺度这样的微观层面、相对论速度这样接近光速的情况时，虚拟世界仍然会破绽百出，更别提无限套娃般地构建层层虚拟世界了。」</p><p>杨帝抓住59方正的肩膀：“我亲爱的坦克兄弟！制造一个虚拟世界，并不需要以完全复制现实的所有属性。比如，凡界的光速也是约30万千米每秒。那么在凡界制造的虚拟世界，你大可以设定光速为30千米每秒——只要虚拟世界的居民不觉得有问题即可。”</p><p>只要虚拟世界的居民不觉得有问题即可……</p><p>只要让楚门觉察不到异常……</p><p>59改终于绕出了思维盲区。</p><p>（老狐也绕出了思维盲区，原以为Truman是指True man，其实应该是指“处男”。）</p><p>与上层现实世界相比，下层的虚拟时空，精度、规模、上限天花板，一切都大打折扣。</p><p>这并不是什么难想象的事。</p><p>虚拟世界对于现实世界而言，完全可以做得很粗糙。</p><p>或许在他们的宇宙之上，还有一个更接近“真实”的世界，光速是3000亿千米每秒，普朗克长度是1.6x10^-350米，环境平均灵能浓度是5000万灵。</p><p>只不过他们长久地生活在光速30万公里每秒的宇宙中，所以并没有感受到这世界“很卡顿”，也感受不到“很粗糙”。</p><p>再往下。</p><p>如果让一颗“缸中的大脑”，从一开始就生活在光速30公里每秒的“虚拟世界”里。</p><p>那颗大脑或许也会自然而然认为：自己所处的世界一点都不卡顿、不模糊吧。</p><p>这样的例子，杨帝还能举出很多个。</p><p>譬如说有些世界，少年少女们成年后会觉醒什么职业、能力、异能，甚至是觉醒卡牌……</p><p>是不是听起来很奇怪？</p><p>但如果一个人，从小到大生活在这些超自然环境里。</p><p>那么对他们而言，成年后觉醒什么职业，能力，异能，卡牌，就会像呼吸一样自然。</p><p>在他们眼中是另一种理所当然的“规律”，就和日升日落，生老病死般平常。</p><p>杨帝负手而立，俨然一副纯正无添加的世外高人模样。</p><p>“最上层、最终极的‘现实世界’，或许只有一个，但它衍生出来的虚拟世界，几乎无穷。”</p><p>单单以凡界王朝目前的生产力水平，就能够支持建造超过1000个大型“虚拟城市沙盘”项目。</p><p>假以时日，随科技水平和社会生产力进步，他们所能做到的虚拟世界必定更精细，更逼真，数量也更多。</p><p>即使仅仅保持着1000倍的指数级增长。</p><p>嵌套的“虚拟世界”数量也会疯狂爆炸，1000倍的指数增长！</p><p>长期以往，“现实世界”与“虚拟世界”的数量比，将会趋近1:∞。</p><p>换言之，从概率上看，如果没有其他证据，那么他们几乎只有0%的可能生活在真正的现实世界里。</p><p>其实杨帝的论证仍然不算严谨。</p><p>因为他所论证的一切，都建立在思想实验之上，而不是严密的实验。</p><p>但最终，众人还是信服了他。</p><p>原因是……1500亿的话术。</p><p>杨帝最后总结会议精神：“其实，我试图论证我们所处的现实几乎100%是虚拟世界，并不是为了让你们自杀，或者让你们选一个红色药丸回到现实。”</p><p>阿巴无意义地咬着手指头：“那老大你是为了什么。”</p><p>“我所为的，始终是最初的目的——研究归墟大帝怎么死的。”</p><p>“此界的归墟大帝，他既不是被人谋杀，也绝非自杀。”</p><p>青丘白璃瞳孔震动，阿巴也同时脚步踉跄。</p><p>“归墟大帝站在凡界与灵界顶点，你们根本摸不出他的上限。如果，大帝在喝水的时候境界突破、修为暴增，超出了这个世界所能‘承载’的上限，从而被这个世界‘降维’，或者被‘驱逐’——他就会被排离出灵凡二界。”</p><p>甚至被世界针对并“杀死”。</p><p>杨帝最初穿越到此世，心头就掠过一声模糊的「现实+1」。</p><p>现在看来，有可能是“凡界”看他不顺眼，无法承载他突破天际的数值，所以尝试杀死他。</p><p>但没杀动。</p><p>所以只能“降维显示”杨帝的“现实丰度”，这是一种折中的妥协。</p><p>就好像59改在虚拟会议厅中，偷偷将杨帝的还原度从99%下调至98%。</p><p>而归墟大帝，终究只是个普普通通的大帝。</p><p>如果他被世界所针对，还能像杨帝那样安然无恙吗？</p><p>他因此被杀死，或者是被流放至世界之外。</p><p>在先前的“大帝碎片”中，他特意强调背叛。但他也亲口承认：</p><p>「我知道自己要死。但我无法容忍背叛。」</p><p>不一定是因为“背叛”，才导致归墟大帝的“死”。</p><p>可能是归墟大帝意识到，自己的力量即将达到这片天地无法承载的“上限”。</p><p>他正准备慨然赴死。</p><p>但随即，“某人”的背叛发生了。</p><p>已经知道自己死期、并且遭到背叛的归墟大帝在绝望与悲愤之中，竟产生了“灭世”的念头。</p><p>或许，这就是真相了。</p>
