# 藏在图片里的

<p>稷海理工，菊园宿舍。</p><p>张明远手指在青轴键盘上敲出焦躁的节奏，显示器蓝光将他凹陷的眼窝照成两个深潭。</p><p>杨帝瘫坐在人体工学椅上，运动服还在散发汗水的咸腥，后颈黏着几缕湿发。</p><p>“张明远，我匆匆赶回来，还特么以为你需要什么临终关怀，结果你就是整这出事？”</p><p>他把手机重重拍在桌上。</p><p>手机屏幕亮起，还是那个看起来十万火急的消息：“宿舍危，速归！”</p><p>当时看到这条信息，杨帝以为张明远要死了。</p><p>他向来不惮以最大的恶意，来揣测自己的华夏好舍友。</p><p>他还想着，要么赶回来抢救他，要么赶回来含泪吃席。</p><p>结果，既不需要抢救，又没有席吃。</p><p>这把他叫回来，特么不就白回来了吗？</p><p>张明远将那张虚弱自己的脸，从显示屏上挪开：“老杨……我不行了。把老马的星舰图片删除，重新训练，三十次迭代，卷积核都卷穿了，显卡都要烧融了，但还是识别不了这张图片，到底为什么，只有天知道……”</p><p>张明远看起来就要燃尽了。</p><p>黑眼圈，深眼窝，邋遢头，面黄肌瘦，给人感觉是连吃了七天的呃拼优饭。</p><p>杨帝把身子凑过去：“你还在捣鼓你那什么神经模型？和那张平平无奇的图片？”</p><p>张明远默然地点点头。</p><p>那真的只是一张随手拍的照片。</p><p>蓝天澄澈得像琉璃穹顶，鸟蛋形状的鲜红色气球飘在空中，下面是一根系绳。</p><p>除此之外，画面里别无他物了。</p><p>识别模型还是从这么干净的画面上，识别出了十几个物体。</p><p>除了一个红框套住了红气球，其他十几个红框，全部框在了天空上。</p><p>「精神+1」</p><p>杨帝感觉到太阳穴鼓动，有些头晕目眩。</p><p>他今天白昼触发了6次「视力+1」，现在他能感觉，世界前所未有的澄澈，清晰。</p><p>他不仅近视被治愈了。</p><p>而且，还能看清这世界很多细节——以前从未留意过的细节。</p><p>行道树上某片叶脉的形状，路边橘猫瞳孔的模样，学生公寓某块剥落瓷砖上的水泥凹凸……</p><p>但当杨帝视线扫过那张蓝天红气球图片，视网膜传来灼烧般的刺痛。</p><p>他昨天看过这张图片，但那时，他的视力没现在这么好。</p><p>现在，杨帝看清楚了照片上的细节。</p><p>那些曾经被人脑忽略，或者是被大脑自动过滤、屏蔽掉的细节。</p><p>「精神+1」</p><p>很粘稠，空调出风口的水珠滴落声很粘稠。</p><p>蠕动，杨帝看见，照片里云絮边缘在微微蠕动。</p><p>不……云絮没问题，气球也没问题，有问题的是天空……</p><p>天空之中，青金石色与普鲁士蓝在像素间隙流淌，它们在流淌。</p><p>「精神+1」</p><p>视网膜传来灼烧的剧痛，但更恐怖的是疼痛中夹杂的快感，似有寒冰做的手指，在按摩大脑皮层沟回。</p><p>「精神+2」</p><p>“啊……啊……”</p><p>“杨老帝，你在‘啊’什么？”</p><p>杨帝看见了，他看见了！</p><p>照片上的蓝天开始渗出类似液晶漏液的污渍。天空裂开了。不是比喻性的描述。照片里的天空裂开了。</p><p>「精神+3」</p><p>有东西在裂缝深处蠕行，不是生物意义上的蠕动。它是静止的，但它在蠕行。</p><p>它不应该动，它好像在蠕行，但.jpg格式的图片是不会动的，静止的图片是不应该动的。</p><p>「精神+5」</p><p>湿冷的触须刺入太阳穴，粘腻的絮语顺着耳道爬进来，在他脑子里低声耳语。</p><p>某种类似湿海绵摩擦玻璃的细微声响，从电脑的屏幕对面传过来。</p><p>猫狗，消防栓，珊瑚虫，躺椅，章鱼……</p><p>他看到了。图像识别模型没有出错。</p><p>「精神+8」</p><p>杨帝想起来了，他患上急性肠胃炎、发烧在床的那个晚上，那种“玻璃被湿海绵摩擦剐蹭”的声音，就是从张明远电脑里漏出来的。</p><p>有东西……有东西藏在图片里……</p><p>它想出来……它出不来……除非有人看见它，目睹它，直视它，觉察到它的存在。</p><p>「精神+13」</p><p>絮语在耳道深处震动，杨帝后颈汗毛齐刷刷竖立。</p><p>凉意从椎骨穿过脊椎，直冲天灵盖，像是讲的全部神经系统，浸泡在零下200度的液氮。</p><p>寒冷，悲伤，剧痛，涌上意识的最表层。</p><p>「精神+21」</p><p>不会说话了，不知道怎么思考了，组织不起一个完整的句子，想不出如何说完一段完整的话……</p><p>过往的逻辑、智慧、语言、符号、认知结构……如同被投入强酸的碳酸钙，在沸腾的泡沫中近乎分崩离析……</p><p>“我超，怎么回事？老杨你牛逼！就是过来看了两眼，这图像识别模型就修好了！”张明远的声音。</p><p>屏幕上，那十几个框住天空的识别框，消失了。</p><p>只留下唯一一个框，框住鲜红色气球。</p><p>“识别结果：气球 。置信度：99%”</p><p>确实修好了。</p><p>因为藏在图片中的“异物”已经爬了出来，缠住发现它的人——杨帝。</p><p>杨帝陷入昏迷前的最后一刻，数十个声音在心中重叠爆发：</p><p>「精神+34」「精神+55」</p><p>「精神+89」「精神+144」</p><p>「精神+233」「精神+377」</p><p>……</p><p>杨帝睁开眼。</p><p>鼻腔灌满消毒粉和湿润水汽的混合气味。</p><p>无数道暗绿色波纹在天花板摇晃，水波折射的光斑，在视网膜上烙下幽蓝印记。</p><p>他试图撑起身子，掌心传来冰凉的触感——整个地面竟是整块倾斜的浅水池，自己赤着双脚站在一汪浅水中，水波荡漾着，泛起层层涟漪。</p><p>入目是一片白茫茫的雾气，脚底传来一阵冰凉的触感。</p><p>“我超，水池。”杨帝PTSD犯了。</p><p>他深吸一口气，试图让自己冷静下来。</p><p>环顾四周，视野中尽是无边无际的水池，湛蓝的池水在雾气的笼罩下，显得格外诡异。</p><p>这是由无数块30x30厘米的白色瓷砖构成的密闭空间，地板，墙壁，天花板，都是极其干净整洁的白色。</p><p>有些空旷处，立着几根大柱子，柱子则贴满靛蓝马赛克。</p><p>那些靛蓝马赛克在视野边缘蠕动，当他定睛凝视时，又恢复成规整的几何图案。</p><p>远处仿佛传来孩童嬉闹的回声。</p><p>可放眼望去，声音立刻消失了。</p><p>只剩下若有似无的波涛声，和某种低沉、轰隆隆的巨响，有点类似于通风管道的嗡鸣。</p><p>这种低沉的声音，不知为何给人一种安宁，静谧的岁月静好之感。</p><p>但在这种静态的舒适感中，潜藏着某种人类本能的不适。</p><p>太安静了……太空旷了……</p><p>这片由水池构成的迷宫根本望不到尽头。</p><p>杨帝不敢大喊大叫，怕惹来什么不干净的东西。他只能自己一人慢慢的走。</p><p>反正这水很浅，淹不死人。不过对他来说，已经足够恐怖了。</p><p>杨帝恐水，就是因为那条10斤重的大鱼。</p><p>每回想起10岁那一幕，鼻腔粘膜便会嗅到水库藻类腐烂的腥甜，那是挥之不去的阴影。</p><p>当他第三十次绕过相同的马赛克立柱，突然发现……水面正在以肉眼可见的速度上涨。</p><p>原先仅能打湿脚板底的浅池，此刻已漫过脚踝，小腿，膝盖……</p><p>“玛德。”杨帝脸色顿时比吃了屎还难看。</p>
