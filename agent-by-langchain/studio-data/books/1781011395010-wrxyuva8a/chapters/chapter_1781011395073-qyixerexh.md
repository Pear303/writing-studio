# 半步勇士

<p>这是万里长征第一步，确实如此。</p><p>他们到现在所做的一切，就像是在黑暗中摸索着绘制一张未知地图的草图。</p><p>每次实验，都是这张草图上的一笔一划。</p><p>钓鱼佬非常喜欢蔡国权的《顺流逆流》。</p><p>「不相信未作牺牲竟先可拥有……」</p><p>「只相信是靠双手找到我欲求……」</p><p>他是个传统的人。人已到中年，世界观再难改变，他相信每一串汗水换每一个成就，并已相信了了半辈子。</p><p>不经意间在这圈中转到这年头。也许后半辈子，他还会如此笃信下去。</p><p>而现实，也确实给了他回应。</p><p>也许是功夫不负有心人，也许是冥冥之中有天意。</p><p>尽管终端上显示，定位仪全部失踪，50个无一返还，追踪不到它们的位置。</p><p>但是，最后一次实验——牛蛙活着！</p><p>最后一只牛蛙被拉回烂尾楼这边时，仍然活蹦乱跳，叽里呱啦地叫，仍然生机勃勃，也没缺胳膊少腿！</p><p>钓鱼佬眼中迅速重燃了希望。</p><p>50只牛蛙，49只惨死，1只存活。</p><p>有2%的概率，牛蛙能存活超过10秒。</p><p>概率极低极低，而且样本太少，很可能有非常大的误差波动。</p><p>但对于某些人来说，已经足够了！</p><p>2%，已经比他预想过的最坏情况好的多！</p><p>于是，钓鱼佬死死拽住这根稻草。</p><p>“2%的存活率，比我预想的1%甚至是0%还要好……小伙子，你说那些孩子，是不是还在某个地方坚强地活着？”</p><p>“我不知道。但我相信是的。”</p><p>“你说，我还该不该去找他们？”</p><p>“理性来讲，我觉得不应该。”</p><p>杨帝将身子挡在钓鱼佬和电梯井之间。</p><p>但钓鱼佬绕过了他象征性的阻挡，走到电梯井前。</p><p>“杨帝，你不用紧张，我头脑还算清醒。2%的概率已经很让我惊喜，不值得我再去送死，不值得以身入局了。这么多年，或许也该放下，你说是吧，小伙子？”</p><p>杨帝松了口气。</p><p>他点点头：“对啊，过去的就让它过去。”</p><p>“哈哈，不错，人都是要向前看的。”</p><p>钓鱼佬蹲在电梯井前，将最后那只牛蛙放生了，看着它一蹦一跳地消失。</p><p>……</p><p>二人从早到晚，滴水未进。</p><p>他们在烂尾楼二楼生火，将那些几十条残缺的蛙腿作为晚饭。</p><p>钓鱼佬将蛙腿用简易的树枝串起来，架在火上烘烤。</p><p>火苗在简易壁炉中跳跃，映照着他疲惫却兴奋的脸庞。</p><p>“滋滋”声中，蛙腿上的油脂滴落在火焰上，溅起火花。</p><p>在这充斥着不安要素的烂尾楼里，这股食物的香气，竟给人带来难得的踏实感。</p><p>没有带盐，他们便在烤蛙腿上，撒入速溶奶茶粉。</p><p>“没想到，忙活了这么久，最后还得靠这些小家伙填饱肚子。”钓鱼佬看起来很轻松。</p><p>他们一边吃，一边听到墙壁中传来老鼠的吱吱声。</p><p>“吱吱嘎嘎嘎嘎吱吱——”</p><p>起初，这声音很微弱，被火焰燃烧时发出的噼里啪啦声完全压制住。</p><p>若不仔细听，几乎难以察觉。</p><p>但随着时间推移，那吱吱声越来越大，仿佛有无数只老鼠正从四面八方朝着他们涌来。</p><p>“没事，老建筑嘛，墙里多一些老鼠正常。”杨帝并没有停下手中吃烤蛙腿的动作。</p><p>钓鱼佬也是不停口。</p><p>经历了黑暗水体带的种种诡异和惊悚，一只活着的牛蛙给了钓鱼佬莫大的希望。</p><p>此刻这点老鼠的动静，已无法轻易撼动他的神经。</p><p>他半开玩笑：“这烂尾楼里的住户还不少。”</p><p>“估计是被这烤肉味引来了。”</p><p>吱吱声愈发响亮。</p><p>整个墙壁都成了老鼠们的扩音器，音量逐渐攀升到了八九十分贝，那尖锐的声音震得人耳膜生疼。</p><p>两人吃完烤蛙腿，杨帝拍了拍手上的残渣，站起身来，目光朝着声音传来的墙壁方向看去。</p><p>“叔，烂尾楼夜晚很危险，你先回去吧。”</p><p>“比如这‘墙中之鼠’？”</p><p>“墙内老鼠只是大楼恶意的一部分。我们用来当诱饵的‘猫条’，也挺危险的。”</p><p>这种猫条，是某种存在的舌头。</p><p>它们也被判定为生物尸体/残肢。</p><p>钓鱼佬若有所思地点点头：“如果大自然本身能诞生出这种诡异的生命，那电梯井里长出条大鱼，其实也不足为奇。”</p><p>“但你我已经证实过，那水里什么生物都没有——不然，能一口气吃下四十多只牛蛙的大型生物，不可能对在水里乱搅的棍子无动于衷。”</p><p>钓鱼佬有物理硕士学位，对这些变量控制很敏感。</p><p>在开始实验前，他们就用过几根棍子在电梯井积水潭里疯狂搅动。</p><p>确定了电梯井里，真没有任何大型生物。</p><p>他们还参考了工作台遗留下来的设计图。</p><p>烂尾楼确实没有计划建造地下室，一楼就是最底层。</p><p>电梯井容量其实不到10m³，不可能有足够大的空间提供给大型生物。</p><p>钓鱼佬捡起一根已开始微微腐烂的肉条。</p><p>“这种‘舌头猫条’叫什么名字？”</p><p>“不知道，就叫舌头猫条吧。”</p><p>“那剩下这些舌头猫条，我带些回去，你不介意吧？”</p><p>“我建议不要吃，煮熟了也不行。”</p><p>他们交流了一些关于这栋烂尾楼的事情，算是闲聊，比如舌头猫条，墙中之鼠，只能照出后脑勺的镜子，人形青苔，电梯井的手，不安分的真菌，楼顶的尸体。</p><p>总的来说，这栋烂尾楼简直是群英荟萃，人杰地灵，各种稀奇古怪的东西聚集在此。</p><p>单拎一件出去，就是一个都市传说。</p><p>杨帝已经清理了十多天，仍然没有彻底铲除黑恶势力的迹象。</p><p>也正因如此，钓鱼佬留在烂尾楼，并不安全。</p><p>他收拾好自己带来的东西，要离开了。</p><p>“你自己小心点，小伙子。”钓鱼佬临走前，看了杨帝一眼。</p><p>他哼着《顺流逆流》离去了。</p><p>……</p><p>杨帝听着钓鱼佬渐行渐远的脚步声，最后消失在烂尾楼100米开外，确认他真的离开了。</p><p>呵，所以自己还仅仅是“半步强者”，称不上完全体的强者。</p><p>懦夫挥刀向更弱者，勇士挥刀向更强者。</p><p>或者换句话说，他还不是“勇士”。</p><p>尽管口口声声说，自己“不会阻拦就是了”，但他仍然在干涉着钓鱼佬的意志。</p><p>杨帝希望钓鱼佬能在深渊前悬崖勒马。</p><p>就像当初，在杨帝自己的梦里警告过他的博尔赫斯那样。</p><p>这是一种善意吗？他不知道。</p><p>“挥刀”中的“刀”，由谁来定义？</p><p>通往地狱的道路，可能是由善意铺就的。</p><p>当强者以自己的意志干涉弱者，哪怕是善意干涉，实际上也是将自己的价值观和判断强加于弱者，挥刀砍向了弱者的自主意识。</p><p>所以，他只能算半步强者，或曰半步勇士。</p><p>——杨帝特地控制着实验变量，让实验结果滑向98%死亡率的超高风险。</p><p>以此打消钓鱼佬进入黑水潭子的念头。</p><p>他让前49只牛蛙死去，又在最后一次实验，稍稍放松变量控制，让第50只牛蛙活了下来。</p><p>从而放大钓鱼佬的希望，让他不至于堕入绝望。</p><p>但同时，也能在很大程度上杜绝其亲身探索黑暗水体的想法。</p><p>这何尝不是在以一种隐蔽的方式，干涉、玩弄钓鱼佬的意志？</p><p>杨帝清楚地明白——他剥夺了对方自主选择的权利。</p><p>杨帝以自己的意志强行引导实验结果，无疑是对钓鱼佬自主意识的“砍杀”。</p><p>此即，挥刀向更弱者。</p><p>他的这般想法，在正常人眼里看来，也许莫名其妙，理解不能。</p><p>但恰如白夜之下浑噩游荡的幻想家与人类不是同一物种，某屠龙学院的男男女女与正常人的脑回路也凑不到一块——杨帝的想法，很难用短短1亿个汉字来概括。</p>
