# 我欲成人

<p>“老大——！”</p><p>阿巴的鲈鱼眼瞬间充血，他猛地扭头，布满鳞片的爪子几乎要嵌进59改冰冷的冷却管道里，“五九！快！开那个门！坐标天元星！混元山河图！快啊！！”</p><p>「指令确认。目标：天元星。启动‘相位折跃矩阵’。」59改没有丝毫犹豫。说实话，他被阿巴这副严肃模样吓了一跳。</p><p>嗡！空间被强行撕开一道规则的裂口，呈六边形蜂巢形状，一座太空死灵风格的传送门！</p><p>“青青！跟上！”阿巴拖着一旁发呆的本地土著大能青丘白璃，一头扎进那闪烁着冰冷绿光的六边形通道。</p><p>“就是它！装着整个凡界的画！”</p><p>她一股巧劲卷住那卷轴，塞入青丘白璃怀中，“白璃！拿着！让那三个老疯子看看！看看他们想毁灭的到底是什么！”</p><p>青丘白璃抱着那沉甸甸的、仿佛承载着整个凡界重量的画卷，瞬间明白了阿巴的意图。</p><p>深吸一口气，三十六条狐尾在身后如烈焰般燃烧，妖力灌注卷轴！</p><p>“开！”</p><p>一声娇叱，混元山河图在她手中骤然展开！</p><p>刹那间，一幅幅无比清晰，无比鲜活，宏大至极的画卷。</p><p>“画”以光的形式，穿透了混乱的时空，直接投射在三位燃烧本源、操控创世之斧的准圣神魂深处。</p><p>也映照在残星道人淡漠的眼眸里，甚至让那灭世斧光都似乎凝滞了一瞬！</p><p>那是凡间！</p><p>农夫在晨曦中操控撒药无人机，稚童在网课直播摇头晃脑，母亲在LED灯下用扫地机器人扫地，恋人月下盟誓，侠客仗枪江湖……</p><p>山河壮丽，众生百态，爱恨情仇，生老病死……</p><p>凡间的一切，没有毁天灭地的力量，没有长生不死的追求，只有最纯粹、最本真的“活着”的意志，在时间长河中顽强流淌，生生不息！</p><p>青丘白璃的声音，带着灵界土著对这片孕育了万灵的凡界最深沉的眷恋与悲愤，穿透创世斧光的轰鸣，直刺三位准圣：</p><p>“看啊！三位尊者！睁大眼睛看清楚！”</p><p>“看看这人间！听听这众生的声音！”</p><p>“放下斧头！停止这疯狂！灵界的未来，不该以亿万万无辜生灵的陪葬为代价！用爱、用理解、用对生命的敬畏去化解争端，难道不比毁灭更高贵吗？！收手吧！现在还来得及！”</p><p>令人喷饭。真仙境大能缓缓打出“？”。</p><p>阿巴和青丘白璃……试图用爱与正义，话疗对方？</p><p>回应她的，是涅槃轮劫元尊眼中彻底熄灭、只剩下死寂灰烬的涅槃之火</p><p>元尊的声音干涩如砂纸摩擦，透着一种非人的冰冷：</p><p>“蝼蚁之爱，凡尘之情……不过镜花水月，转瞬即逝的尘埃。秩序崩坏，大道倾颓，皆因异数而起。此界根基已污，唯有以创世伟力重炼地火风水，方能涤荡一切，重铸完美天道！尔等所珍视的……皆是需要净化的杂质！”</p><p>杨帝了解自己。</p><p>穷则话疗，强则动武。</p><p>因为后天成长环境不同，阿巴和他性格差距也比较大。</p><p>但蕴藏在基因深处的某些“本性”是相通的。如果有一天，杨帝也遇上不可战胜的对手，他也会尝试让自己变强的同时，用嘴炮话疗对方。</p><p>他仍然在疯狂思考。</p><p>「你和我其实是同一类人。」</p><p>「虚拟世界猜想……」</p><p>杨帝需要一个办法，护所有人周全。</p><p>他的灵能已经突破灵界上限——只有他展开领域，就能将整个“灵界”，被自己的“领域”覆盖住。</p><p>展开领域，他需要感悟“末那识”。</p><p>第七识，末那识，执掌“我执”。</p><p>只有领悟第七识真谛的圣斗士，才能爆发小宇宙的全部威力……</p><p>「需要在绝境中不断磨砺，在战斗中对自我和宇宙的认知达到全新高度，让潜藏在生命深处的本能彻底释放。」</p><p>杨帝已经发现了，就算将他的身体，切分成比普朗克长度还要微小的尺度，他如果能保留有意识存在。</p><p>前五识眼耳鼻舌身，是对世界的“感知”。</p><p>五识渐熄，如同灯火被狂风逐一吹灭。那由前五识构筑的、对物质世界的直接感知壁垒，正在崩解。</p><p>「意识」是第六识，执掌人的思想，智慧，则是对……“自我”的感知。</p><p>“色、声、香、味、触，皆是外境投射。第六识，‘意识’……它整合前五识的信息，加以分析、判断、思考、记忆……形成‘知’与‘识’……但这‘识’，依旧是对外境的反应，是‘我所知’……那‘我’是谁？是谁在‘知’？是谁在‘识’？”</p><p>意识仍在疯狂运转，如同风暴中的孤岛。</p><p>“痛！存在根基在被撕裂！”</p><p>“阿巴……59改……他们的恐惧……”</p><p>“灵界在崩解！亿万生灵在湮灭！”</p><p>时间。杨帝需要时间，顿悟需要时间。</p><p>在斧光将他彻底抹除之前，如何获得足够的时间去思考、去突破这生死的界限？</p><p>时间！这是此刻最致命的枷锁！</p><p>他们还剩1秒时间。</p><p>现实中的斧光，其抹除的速度远超过任何思维的速度。</p><p>顿悟？在绝对的力量和速度面前，连一个完整的念头都显得奢侈。</p><p>梦中？如果是8000倍时间加速，外界的10秒就是梦中的一天。但也只是蛐蛐一天时间，杨帝什么都做不到。</p><p>当然，他也没想着临时抱佛脚“顿悟”。</p><p>领悟第七识的真谛，需要时间，需要磨砺，需要对自我和宇宙本质的深刻洞察！这绝非一朝一夕之功，顿悟本身是强求不来的。</p><p>如果没有足够的积累、运气和根性，就算他在梦中梦中梦里闭关十万亿年，也未必能感悟“第七识”。</p><p>“要用那个了吗……”</p><p>时间已过去100毫秒。</p><p>杨帝：“59改！！你当网线！！联通我和阿巴的精神！！”</p><p>时间已过去200毫秒。</p><p>「指令确认。」59改核心处理器瞬间超频运转，爆发出刺目的光芒。</p><p>一道无形的、基于最底层物理规则构建的信息桥梁，瞬间建立！</p><p>灵界整整待了三天，足够59改将科技树攀到“原子时代后期巅峰半步小圆满”级别！</p><p>时间已过去300毫秒。</p><p>“老大！你要做什么？！”阿巴惊恐地感受到一股庞大而熟悉的精神力正试图涌入她的意识深处，带着杨帝那熟悉又霸道的气息。</p><p>“借你‘记忆’与‘感悟’一用！助我叩问‘我执’本源！”</p><p>杨帝的意识通过59改的“网线”，吮吸阿巴。</p><p>时间已过去400毫秒。</p><p>“为什么不用我的？！我的记忆更久远，感悟更深！”青丘白璃吼道。</p><p>灵界大能，对“领域”和第七识的感悟，比半桶水的阿巴更深刻。</p><p>“不行！”</p><p>杨帝斩钉截铁，带着不容置疑的决绝，同时也爆出一个惊天秘密，“唯有阿巴！因为——她本体不是鲈鱼！她是我的克隆体！修炼‘我执’，我和她的‘排异反应’更小！”</p><p>时间已过去500毫秒。</p><p>阿巴感觉到脑子被邦邦两拳，前额叶都被揍液化了。</p><p>那些困扰她多年的、不属于鱼类的奇怪记忆碎片，比如她脑海中闪回的“阿房宫”、“大汉棋圣”词语片段……来源于此？</p><p>灵魂深处对杨帝难以言喻的亲近与服从……是因为水仙情结，自恋？！</p><p>“不……有什么能证明？”</p><p>杨帝从口袋中掷出一根一次性塑料泡面叉。</p><p>“这是我在火车上吃泡面，吃剩下的叉子，上面沾有我的唾液，你可以检验我的基因序列和你的有无偏差。”</p><p>阿巴接过塑料叉子，扫视一眼，有如晴天霹雳。</p><p>除了最后的性染色体，其他四十五个染色体基本、大致是一样的……</p><p>阿巴就是个性转的杨帝克隆人，仅此而已。</p><p>时间已过去600毫秒。</p>
