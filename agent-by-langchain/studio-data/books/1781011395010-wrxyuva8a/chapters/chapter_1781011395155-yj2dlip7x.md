# 凡尘俗眼，不识神器

<p>“费这么大劲，用那种匪夷所思的方式把这东西打上来，就为了送一个空壳子？”阿巴大呼小叫。</p><p>确实匪夷所思。</p><p>汉堡微波炉和扫地机器人的组合，就是将它们的机器功率发挥到极限百分百，也没有足够的“做功”，能够将这“空壳子”打上天。</p><p>除非……</p><p>青丘白璃眉头凝重：“没错，法则扭曲的情况下，可能可以出现‘动能凭空增幅1000倍’的离奇情况。”</p><p>域外天魔出现的前兆，是细微的法则扭曲，和难以察觉的本源紊乱。</p><p>比如小圆球动能凭空增幅1000倍、材料强度临时暴涨几十倍，使其能够像“电磁炮”一样以10马赫初速射出。</p><p>直到最后，现实丰度会像地陷一样，坍塌为零。</p><p>随后，域外天魔就会出现了。</p><p>「不是空壳。」59改说。</p><p>「圆球类似于黑匣子，其内部数据与指令曾经存在，但随后被格式化。」</p><p>「由于法则扭曲与本源紊乱，无法通过‘熵减回溯’技术复原。」</p><p>「只能大致得出结论——该存储设备中的‘内容’，已经侵入主控大厅的主机设备。」</p><p>众人瞪大眼。</p><p>原来这圆球是执行“跳帮作战”的载体！</p><p>几乎在59改显示这些信息同时，大厅内几块最大的监控屏幕猛地爆发出刺眼的雪花噪点。</p><p>随即，变成一片深邃、令人不安的漆黑。</p><p>紧接着，一些关键的控制台界面开始扭曲，操作指令栏里凭空出现大量毫无逻辑、如同之前炸薯条机疯话般的乱码字符。</p><p>更诡异的是，几个离圆球最近的技术人员，眼神突然变得茫然。</p><p>其中一个指着墙上的城市地图，喃喃自语：“不对……地铁2号线……应该通往……42号混凝土搅拌站才对……”</p><p>“完了又疯几个！”</p><p>青丘白璃倒吸一口冷气，瞬间明白：“炸薯条机和冰淇淋机的目标，是污染整个城市智能系统的运行基础，传播域外天魔？”</p><p>虽然原理听上去怪怪的，但本地土著大能青丘白璃指出，天魔通过网络传播是可行的。</p><p>当年修仙者与时俱进，认为凡界的互联网项目试点效果很好，所以引进该项技术，并在灵界进行大规模推广。</p><p>结果，域外天魔顺着网线传播，差点将所有修仙者一锅端了。</p><p>“对域外天魔的成因，我们尚未100%解明。”青丘白璃耸耸肩。</p><p>杨帝回想起他在大陆最边缘看到的景象。</p><p>世界本身貌似也有寿命，也有生老病死，死掉的部分，现实丰度归零，变成了“崩坏”，别名为“域外天魔”。</p><p>但他们现在所在的此处，并非世界边缘。</p><p>为何也会有域外天魔诞生的迹象？</p><p>是的，原初之眼曾经用过一种法术“十环禁术·质壁分离”，能够用世界之内的力量剥离事物的灵能。</p><p>在其他世界，应该也能通过人为手段、技术达成“崩坏”这一现象。</p><p>域外天魔就是崩坏，崩坏的本质是无穷多条世界线疯狂震荡、串线。</p><p>而世界线“串线”的本质，则是概率与可能性的重叠，蹦迪，癫狂震荡，某个事物彻底失去对自身命运哪怕一丁点掌控。</p><p>那个圆球里面……存储了某种法术，或者是仪式？</p><p>“安保部，主控大厅出现不明人员，请求支援！”</p><p>终于有工作人员发现了若无其事出现在主控大厅的四人。他对着通讯器大喊。</p><p>杨帝四人都穿着黑袍，一看就很可疑。</p><p>再结合地面上的攻壳机动队，报道了有四个可疑的黑袍人物，在案发现场附近游荡。</p><p>工作人员当机立断摇人！</p><p>尖锐的警报声再次响彻大厅，比之前更加凄厉。</p><p>密集的脚步声从各个通道口传来，全副武装的安保队士兵正迅速涌入。</p><p>杨帝看了一眼被包围的59改和地上那个散发着不祥气息的空心圆球，又望向大厅入口处汹涌而至的黑色浪潮，脸上没有任何表情。</p><p>他随手从旁边一个吓傻的工作人员没吃完的午餐袋里，摸出一个冷掉的葡挞，慢条斯理地咬了一口。</p><p>“59改，我们得进到主控大厅的涉事主机，将黑色圆球转移进去的数据给‘揪’出来。”</p><p>「杨帝阁下，您不能进去，否则您的精神力量会撑爆凡界的主机。」</p><p>生活不易杨帝叹气：“好吧，那我在外头等你们，不要让我等太久啊。”</p><p>青丘白璃、鱼尊阿巴、五九改坦克各自元神出窍，钻进君士叹顶堡主控大厅的主机里。</p><p>主控大厅内，安保队员的脚步声越来越近，枪械上膛的“咔哒”声清脆而冰冷。</p><p>杨帝慢条斯理地咽下最后一口葡挞，指尖沾了点酥皮碎屑，在黑袍上随意擦了擦。</p><p>“误会，都是误会。”</p><p>杨帝清了清嗓子，声音不大，却奇异地压过了警报的噪音，“我们是来自半人马座的摄影爱好者，只是路过，记录一下贵地城市主控系统的……嗯，烟火气。”</p><p>他身后的主机开始冒烟。</p><p>杨帝咽了口唾沫：“当然是象征意义上的‘烟火气’啦。”</p><p>他一边说着，一边极其自然地从宽大的黑袍袖子里掏出一个东西——</p><p>四四方方，棱角分明，通体呈现出粗粝、原始的红褐色，还沾着点可疑的泥土痕迹。</p><p>一块板砖。</p><p>杨帝将这板砖托在掌心，神情无比认真，甚至带着点神圣感，对着一脸「你踏马在逗我？」表情的安保队长展示道：“看，这就是我们的摄像机。半人马座最新款，复古风，原生砖纹滤镜，记录人间百态，效果拔群。”</p><p>安保队长的嘴角狠狠一抽，枪口抬得更高：“放下武器！双手抱头！趴下！”</p><p>“唉，凡尘俗眼，不识神器……”杨帝遗憾地摇摇头，到头来没几个人懂他的艺术。</p><p>安保队员应该也不敢开枪，毕竟杨帝身后就是主控中心的主机。</p><p>开枪其实也无所谓的。杨帝还打算用铜花生给自己的板砖嵌成狼牙棒。</p><p>但现在先让他们对峙一段时间，将镜头转向更深邃的计算机内部。</p><p>……</p><p>与此同时，在那由无数“0”与“1”构筑的、常人无法想象的君士叹顶堡城市智能核心——主机硬盘的“内部”。</p><p>这里并非漆黑一片，也非冰冷的机械结构。</p><p>呈现在四位闯入者眼前，是一个光怪陆离、颠覆物理法则的奇异世界。</p><p>脚下是一条由纯粹光芒构成的汹涌长河，河水里流淌飞泄的是数据流。</p><p>河流两岸，是连绵起伏、高耸入云的山脉。这些山脉并非岩石构成，而是由无数密集排列、六边形结晶构成的晶壁。</p><p>六边形晶格散发微光，内部封印海量的信息片段，可能是某段监控录像、某个运行日志、某个市民的社保记录。</p><p>荒野上还矗立着各种奇奇怪怪的门，名为逻辑门；到处都是墙壁，名唤防火墙。</p><p>流动的光河、沉默的晶壁、稳固的迷宫和壁垒。</p><p>天地间始终回荡着一阵低沉的嗡隆声，但声量很小。</p><p>宏大，而静谧。</p>
