# 黑暗水体连接实验

<p>“可以的，叔，我们可以的。”</p><p>杨帝如是说着。似乎只要他在，一切困难都能迎刃而解。</p><p>钓鱼佬看着眼前这个充满自信的年轻人，心中那种忐忑不安的情绪，渐渐被一种莫名安心所取代。</p><p>小孩儿问老爸一件事能不能做成，就算他爸也拿不准，他也要表现出掌控全局的自信。</p><p>尤其是在钓鱼的时候，身为长辈的一方，必须自信力充沛。</p><p>钓鱼佬恍惚间觉得——</p><p>自己在那小伙子杨帝面前，是年龄上的老人、思想上的孩童。</p><p>这种感觉，在10天前还不存在。</p><p>或许，这就是他口中所说“弱者”和“半步强者境”的区别。</p><p>但为什么只是“半步”呢？他对“强者”的定义是什么？</p><p>杨帝话打断钓鱼佬略有混乱的思绪。</p><p>“叔，我们要开始了，别发呆。”</p><p>钓鱼佬赶忙回过神来，与杨帝一同将准备好的“组合道具”搬到电梯井旁。</p><p>杨帝先将“猫条”也用钓鱼线绑好，另一端连接着牛蛙和定位仪。</p><p>将猫猫形状的肉条放入水中。</p><p>那黏腻的肉条一接触水面，便缓缓下沉，周围的水面泛起一圈圈细小的涟漪。</p><p>钓鱼线串好牛蛙和定位仪，在另一端悬在水面上，并不直接与黑水接触。</p><p>两人盯着水面，等待着黑暗水体连接效应的触发。</p><p>沉默在两人之间蔓延了片刻，只有电梯井里那微弱的水波声打破寂静。</p><p>钓鱼佬终究还是忍住了，没问杨帝为何十天内有如此翻天覆地的变化。</p><p>他知道，有些事情，该说的时候，小伙子自然会说。</p><p>杨帝却在此刻微微转头，目光从水面移到钓鱼佬身上：“叔，在做一件事情前，必须要有相应的觉悟，这种道理你也应该明白吧？”</p><p>钓鱼佬若有所思地点点头。</p><p>“所以，我问你，你究竟是抱着自我毁灭的心态，还是决心要将你的学生带回来？你必须得想好。”</p><p>钓鱼佬心中一震，目光有些躲闪。</p><p>他原本确实是抱着自暴自弃、自我毁灭的想法，在这黑暗谜团中沉沦，只求一个解脱。</p><p>他站在潮湿的空气里，温吞吞地嚅嗫：“我以前确实有些……不好的想法，觉得这一切都没意义。但在见到你后，我又觉得好像真的有希望……可我还是害怕，害怕最后还是一场空，又要再次面对那种绝望……”</p><p>见识了杨帝的力量，犹如荒野中亮起篝火，让他心底又燃起一丝渺茫的希望。</p><p>然而，这希望太过微弱。</p><p>他在自我毁灭与渴望找回失去之间，仍然徘徊不定，依旧不确定内心真正的想法。</p><p>杨帝按住他肩膀：“钓鱼哥，你不能抱着死的心去貂蝉这黑色水体。</p><p>“你必须要想自己得活着回来，活着把他们也带回来。</p><p>“这只是我的一点小建议。最终怎么选，还得看你自己，我不会阻拦。”</p><p>呱——噗咚——</p><p>二人同时转过头去。</p><p>牛蛙和定位一日不见踪影，钓鱼线紧绷着。</p><p>杨帝紧紧攥住手中EVA材质的绕线板，钓鱼线另一头，被一股巨大的力量拖拽着。</p><p>如果说，是电梯井自然诞生了大鱼。</p><p>那全地球的生物学家都得自杀，一路砍翻南天门，杀进天庭/天堂，向神/仙质问大自然为何逻辑崩坏。</p><p>“叔，我要拉上来了，你后退一点。”</p><p>杨帝两只手抓住绕线板，双脚稳稳地站定，开始缓缓地往回拉钓鱼线。</p><p>他的手臂肌肉紧绷，但身形很稳，看起来没花多少力气。</p><p>然而，钓鱼佬见识过这小伙子一拳打爆不锈钢防盗门。他事后检查过，是真的不锈钢。</p><p>所以，尽管杨帝看起来没花费多少力气，实际上必然是在暗暗较劲，抗衡着那股来自黑暗水体另一端的强大拉力。</p><p>鱼线紧绷到近乎要断裂。</p><p>钓鱼佬听从杨帝的话，往后退了几步。</p><p>随着杨帝不断地拉扯，钓鱼线一点点从水中被拉出。</p><p>然而，本该连接在钓鱼线另一端的肉条、牛蛙和定位仪却并未出现。</p><p>鱼线完全被拉出来时，钓鱼佬愣住。</p><p>鱼线的末端，只挂着两条被扯断的残缺蛙腿，蛙腿上还残留着一些血迹。</p><p>钓鱼线缠的地方正是蛙腿。</p><p>黑色水体对面的力量如此强大，居然能把蛙腿给……硬生生地扯断。</p><p>蛙腿上还带着些模糊的暗红色黏液。</p><p>钓鱼佬只能用“模糊”这个词来形容那种暗红色粘液。</p><p>那暗红色黏液如同浓稠的墨汁，外表带着一种难以言喻的朦胧感。</p><p>黏液的边缘并不清晰，像是与周围的空气在进行着某种缓慢的交融。</p><p>界限模糊得如同水墨画中晕染开的墨色。</p><p>凑近去看，能发现黏液里似乎蕴含着无数细小的、若隐若现的颗粒，它们在黏液中无序地游动。</p><p>黏液散发着刺鼻且怪异的气味。</p><p>那味道像是腐烂的鱼腥、烧焦毛发、硫磺味，三者的混合，还夹杂着一丝难以形容的酸涩。</p><p>杨帝凑近嗅一口。</p><p>“鱼腥味，很可能意味着黑暗水体的另一端存在着某种水生生物，或者是与水有着紧密联系的环境。</p><p>“正常情况下，腐烂鱼腥味往往源自于水中生物的腐败。</p><p>“结合我们目前所面对的黑暗水体，或许暗示着那边有一套生态系统。</p><p>“而这种生态系统，很可能是基于黑暗水体而形成的。”</p><p>他顿了顿，再次看了一眼蛙腿上的黏液，继续说道，“至于这烧焦毛发的味道，就更为复杂了，我不明白。”</p><p>钓鱼老师虽是物理老师，但也有一定的基础知识。</p><p>他说：“这是典型的蛋白质烧焦气味吧？为什么会更复杂。”</p><p>杨帝摇摇头。</p><p>他先是问了个问题：“像是‘被世界遗忘的黑暗水体’，说起这个描述，你想到哪里？”</p><p>钓鱼佬瞳孔一缩。</p><p>他感受到一种深刻的暗示——</p><p>被世界遗忘的黑暗水体，最大的可能，不是什么名不经传的臭水沟，不是藏在深山老林里的水塘，也不是某处前沿物理实验室的超冷水探测池。</p><p>而是——海底。</p><p>而且，这黏液有硫磺味、烧焦味。</p><p>那应该是海底火山……吗？</p><p>杨帝：“从比例上来说，‘海底’在全地球的黑暗水体中，质量，体积等等占比都最大。</p><p>“所以我最初也猜测，这黑色水潭最有可能会连接到海底。</p><p>“但现在，这些暗红色粘液都带有某种蛋白质烧焦的气味。</p><p>“说明我们的第一次尝试，并没有传送到海底，而是其他某种地方。</p><p>“极有可能说明，这里的‘黑暗水体’很可能不止限于地球，还会通往宇宙其他地方，甚至是其他宇宙……”</p><p>钓鱼佬：“难道不是传送到海底某深海热液喷口附近吗？那里温度足够，而且硫磺含量也丰富。”</p><p>深海热液喷口，差不多就是海底火山。</p><p>海底活火山附近，海水处于超临界状态，温度可达数百度！</p><p>杨帝否定：“在高温高压的超临界水中，蛋白质的变性会非常迅速且彻底，但不会像在干热条件下那样发生焦化反应，也就不会有毛发烧焦的气味。”</p><p>海底火山确实会有硫磺味，但是不可能有蛋白质烧焦的气味。</p><p>他又拿出一只新牛蛙。</p><p>“再来一次实验，如果仍然没有连接到深海海底，我们基本可以肯定——黑暗水体所连接的区域不局限于地球了。”</p>
