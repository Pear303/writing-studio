# 新闻与众生的无用蒙太奇

<p>回到此时此刻。</p><p>苟玖喃喃道：“……高！实在是高！这背景编的，比本君当年骗咳咳，游历灵界时扯的谎圆多了！此子深得‘虚则实之，实则虚之’的苟道精髓啊。”</p><p>面前的护士拍拍他手臂。</p><p>“同学别愣着，伸手，抽血。”</p><p>“噢噢……”苟玖很不情愿地伸出手臂。</p><p>作为邪道大能，苟道至尊，九转大常真君还是有些忌惮让别人获取自己的血液样本，怕被炼制什么定向基因武器给针对了。</p><p>……</p><p>烈日当空，一位臂戴红袖章的志愿者被记者团团围住，汗水顺着他激动的脸颊滑落。</p><p>他指着教学楼上方的环形走廊，声音因亢奋而拔高：</p><p>“就是他！我当时就在这巡逻。别人都绕着走，杨帝倒好，直勾勾盯着天圆广场中心看！规则写得清清楚楚——‘禁止观察’啊！”</p><p>他猛地一拍大腿，眼神里还残留着当时的惊悸：“你们是没在现场！那一瞬间，嚯！一股子说不清道不明的‘气势’就压过来了！</p><p>“跟某些文艺作品里的‘霸王色霸气’一模一样！我浑身汗毛都竖起来了，膝盖发软，愣是动弹不得！</p><p>“就那一眼！我就知道这小子绝对不是一般人！那眼神，那站姿……他脑子里想的，绝对跟咱们这些凡夫俗子不在一个频道上！</p><p>“那时候我就知道，杨帝是真正的‘狠角色’，自己不应该拦住他，也不可能拦得住他……”</p><p>……</p><p>阿巴刚体检完，一切正常。</p><p>她站在路边，手举牌子写着“老大，罐头，狐狸”三个词，类似于火车站或飞机站出车口的接待小妹。</p><p>没几个人理她，她只能默默站在路边。</p><p>第七日，她有所收获。</p><p>一个身着深红长袍，半人半机械，周身散发机油味与神秘气息，面相圆润（正），脑袋上还有个信号锅的机油佬，找到了她。</p><p>“肥鱼，我在电视上看到了你。”</p><p>“噗，你怎么长这样子了罐头？”</p><p>“说来话长。你应该还记得‘残星道人’吧？”</p><p>……</p><p>从北美，穿着军装和实验室白大褂的高级官员和科学家的秘密基地。</p><p>到欧罗巴，一群仿佛从油画里走出来的老者围坐的古老圆桌会议室。</p><p>当“龙组”一词出现时，欧罗巴圆桌会议室瞬间死寂，所有人的目光齐刷刷投向角落里一位戴着墨镜、沉默寡言的华裔特工。</p><p>那位特工身体明显僵了一下，墨镜下的嘴角似乎在微微抽搐。</p><p>沉默笼罩了这一刻。</p><p>而远在神秘的东方。</p><p>某深山地底基地，龙组总部。</p><p>巨大的指挥大厅内，落针可闻。</p><p>龙组总部内，所有工作人员，无论级别高低，全都石化般盯着主屏幕。</p><p>一位头发花白、肩章上缀着龙纹的老者，手中把玩了多年的两个不锈钢文玩核桃，“咔嚓”一声，被他捏得粉碎。</p><p>他旁边一位气质冷冽的女军官，万年冰封的脸上也出现了一丝裂痕，嘴角不受控制地抽动了几下。</p><p>“他……他提我们了？还把我们跟外星摄影佬和蜥蜴人绑一块儿‘生’了他？！”</p><p>“通知下去，最高等级预案启动。”</p><p>“立刻、马上、不惜一切代价，把这位‘杨帝同学’，给我‘请’回来！我要亲自问问他……”</p><p>老者眼中闪烁着复杂难明的光芒，最深处，似乎还藏着一丝难以置信的……期待。</p><p>其实龙组还给杨帝准备了一箱泡面！</p><p>最好的泡面牌子，双倍面饼加超大分量牛肉调料包。</p><p>但是，杨帝最终没有赴约。</p><p>精心准备、双倍面饼加超大份牛肉的顶级泡面，在特制的恒温运输箱里，渐渐失去了温度。</p><p>如同一个被爽约的期待，在角落里无声地积着薄灰。</p><p>他如同人间蒸发，又像从未存在。</p><p>不止是龙组，还有神秘东方大国，神秘西方大国，神秘欧罗巴大国……都动用了所有能调动的天网、地网、人网，都启用了数颗高轨道的监控卫星，聚焦江城，扫描全国……</p><p>一无所获。</p><p>那个端着泡面桶、满嘴跑星际火车的少年，仿佛只是规则怪谈消散时产生的一个离奇幻觉。</p><p>然而，就在全球情报机构陷入困惑，舆论从狂热转向猜疑，甚至开始有人质疑江城事件真实性时——</p><p>异变，开始了。</p><p>地点：第四新东京，新宿歌舞伎町。</p><p>午夜，霓虹闪烁如巨兽的瞳孔，见证着代号“百鬼夜行”的B级怪谈领域骤然扩张。</p><p>扭曲的艺伎幻影，裂口女实体，各路恐怖片的美少女尖啸着扑向惊慌的人群。</p><p>一道身影踏碎霓虹招牌从天而降。</p><p>没有言语，只有一拳！</p><p>光怪陆离的幻影如同劣质幕布撕得粉碎，裂口女的剪刀在触及那身影前寸寸崩解，甚至伽椰子都被训成职业女仆。</p><p>正是白杨大帝。</p><p>下一秒，他已消失无踪，只余一片狼藉。</p><p>地点：巴黎，卢浮宫地下深处。</p><p>沉睡千年的法老诅咒被意外唤醒，化作A级领域“黄金棺椁的哀鸣”，木乃伊卫队裹挟着腐朽与金粉的死亡风暴席卷而上！！</p><p>至于法老木乃伊为啥会在法兰西，这是个历史问题。</p><p>监控画面剧烈闪烁，雪花中，一道人影如炮弹般贯穿了厚重的石壁！</p><p>白杨大帝以50倍音速将黑驴蹄子塞进木乃伊口中，并以秒速10000米向对方弹射糯米，成功将其镇压。</p><p>地点：内华达州，51区边缘沙漠。</p><p>代号“独立日”的S级怪谈领域爆发，一片巨大到违背透视法则的“金属活体组织”悬浮在隔离区上空。</p><p>它发出低沉、规律、却让所有监听设备过载的“嗡——咔嗒——嗡——咔嗒”脉冲。</p><p>这是外星母舰“收割者之心”。</p><p>一道身影，如同被硬生生“插入”这个异质空间的BUG，凭空出现在那搏动着的“金属活体组织”表面。</p><p>杨帝。白杨大帝。</p><p>“警报！未知高能个体突破力场屏障！直接接触‘收割者之心’表皮！”</p><p>“能量读数……无法解析！未知个体在……步行进入‘吞噬之口’？！”</p><p>（交流过程，以宇宙某地官话进行）</p><p>一拳轰出，前方锥形空间内所有物质，包括空气、能量流、液态金属守卫，都被瞬间挤压、坍缩成一个密度无限大的奇点，然后在霍金辐射过程下彻底湮灭。</p><p>原地留下一片绝对的真空，随后，才被涌入的物质填补，发出沉闷爆鸣。</p><p>一记鞭腿，抽碎了空间连续性，将数只聚合体守卫拦腰“截断”。具体效果可以参考挨了一发次元斩的芙兰达。</p><p>白杨大帝如同行走在自家后花园，只是偶尔需要“修剪”一下过于碍眼的“杂草”。</p><p>他抵达了核心。</p><p>此处没有宏伟的殿堂，只有一片悬浮在粘稠能量浆液海洋中心，不断变换形态的晶簇。</p><p>它由无数跳动着幽蓝电弧的、非晶态的多面体构成，是整个母舰的中枢，也是规则怪谈“独立日”的具象化核心——蜂巢逻辑主机。</p><p>杨帝停下脚步，从口袋里，掏出一个东西。</p><p>一个廉价的、红色塑料壳的U盘。</p><p>U盘的尾部，还用细绳吊着一个小小的、粗糙的、用劣质塑料做成的熊猫玩偶挂件。</p><p>熊猫憨态可掬，怀里抱着三根点燃的线香——正是早已绝迹于互联网江湖的传奇病毒载体“熊猫烧香”。</p><p>外星人有一个致命的弱点，那就是他们从来不安装360。</p><p>S级怪谈领域，破除。</p>
