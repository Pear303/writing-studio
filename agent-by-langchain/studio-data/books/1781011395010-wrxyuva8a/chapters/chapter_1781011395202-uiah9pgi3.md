# 大道之争

<p>他右手探出，五指箕张，将爱神一把抓住，顷刻炼化！</p><p>最后，他看向在“十万三千怪谈”副本里，智慧脑花被无数弹幕、规则条款冲刷得几乎冒烟，濒临崩溃的智神·辛烈治。</p><p>“吸溜——！”</p><p>智神的脑花被杨帝一口吸入了腹中！</p><p>“嗯……有点小鬼的杠精味，嘎嘣脆，就是塞牙。”</p><p>杨帝目光平静地转向角落里，那条仿佛被嵌在中子星里的鲈鱼——万古鱼尊阿巴。</p><p>一步迈出，时空在他脚下倒卷，瞬间便来到了阿巴面前。</p><p>阿巴嘴巴张大似铁锅，下巴几乎要砸穿亚空间了。</p><p>那是目睹了超越认知极限的震撼后的余韵。</p><p>混沌翻涌，灵能辉光如破碎的星辰点缀空荡荡的八方四野。</p><p>“老大……您不在的四万年，日子……真是难熬啊。”</p><p>她的鱼鳍似乎想比划什么，最终只是无力地垂下。</p><p>那些被邪神意志扭曲，被高位灵能者肆意摆弄，在概率之海中沉浮挣扎的漫长岁月，仿佛都凝聚在这一声叹息里。</p><p>她看着杨帝，眼神比任何一个统计图都要复杂。</p><p>劫后余生的庆幸。</p><p>亘古等待的委屈。</p><p>目睹了最终答案的释然。</p><p>杨帝静静地听着。直到腹中邪神传出咆哮，彻底破坏了二人好不容易营造起来的氛围！</p><p>“轰隆隆——！！”</p><p>胃囊之中，如同开天辟地般沸腾起来！尖叫、诅咒、战吼、咆哮……</p><p>四股截然不同，却又都强大到突破天际的圣级力量，在杨帝那混沌熔炉般的胃里疯狂冲撞与爆炸！</p><p>他腹部时而鼓起如山峦，时而凹陷如黑洞，发出闷雷般的轰鸣，仿佛有四尊古神在里面进行灭世之战。</p><p>“吵什么吵？消化呢，安静点！”</p><p>胃中的喧嚣顿时被强行压制，只余下沉闷的呜咽和咆哮，如同隔了亿万重山峦传来的回响。</p><p>他那双曾撕裂圣座、洞穿命运的眼眸，此刻看向阿巴时，却敛去了所有的凶戾与锋芒。</p><p>只剩下一种深沉如亘古磐石的平静。</p><p>他沉默了片刻，然后，轻轻吐出三个字：</p><p>“对不起。”</p><p>声音不高，却仿佛带着万钧的重量，穿透了时空的阻隔，也穿透了阿巴心中积压四万年的阴霾。</p><p>阿巴的鱼眼蒙上水雾。</p><p>她说：“但老大你至少没有食言违约。”</p><p>阿巴抬起手，指向这破碎的混沌，指向那仍在感知中翻腾的概率之海，最终，指向阿巴她自身。</p><p>“没错，老大，你真的带我到了成就‘大罗金仙’以外的晋级道路——”</p><p>证道大帝，成就圣人。</p><p>“轰——！！！”</p><p>随着「圣人」二字落下，阿巴浑身修为，仿佛被彻底点燃！</p><p>一股无法形容，无法测量，超越了“灵能”范畴，纯粹由灵能凝聚的帝道气息，如同沉睡的洪荒巨兽睁开了眼眸，轰然爆发！</p><p>整个亚空间，不，仿佛整个宇宙的基石都在这一刻为之震颤！</p><p>那翻腾的混沌灵能，如同遇到真正的君王，瞬间平息，刹那俯首！</p><p>万古鱼尊积攒了万古的底蕴，对蓝星文明刻骨铭心的眷恋，以及目睹杨帝生吞邪神所带来的无上震撼与明悟，在这一刻轰然爆发！</p><p>阿巴，成圣。</p><p>一片朦胧的、充满生机的领域以阿巴为中心急速展开——那是她圣道的具现化。</p><p>领域之内，仿佛有无数星球的虚影在诞生，演化，文明的火种在其中顽强燃烧。</p><p>山川河流，城市田园，孩童笑语，学者的沉思……</p><p>属于蓝星人类文明的“存在”与“可能性”被高度浓缩，化作一道坚不可摧的、象征着“永续”的意志长城。</p><p>领域展开，太虚溟濛·蓝星永续之壁！</p><p>她的愿望纯粹而宏大——让蓝星人类永续下去，让人类文明与天齐寿。</p><p>圣道光辉映照着杨帝平静无波的脸庞。</p><p>他看着那片生机勃勃的领域，看着领域中心那条小小的，却散发着不容忽视的圣人光辉的鲈鱼。</p><p>他眼神深处，那亘古磐石般的平静下，终于掠过一丝极其复杂的涟漪。</p><p>“阿巴。”</p><p>杨帝开口，声音低沉却清晰地穿透了圣道领域的光辉，直接响彻在阿巴新生的圣魂核心，“恭喜你，证得圣位。你的愿望，很美好。”</p><p>“是的，蓝星，人类，文明，再也不会被高灵能者随意篡改命运，不会被邪神收割，不会在概率之海中沉没。”</p><p>“鱼仔，你居然开始相信爱与正义。”</p><p>“过奖了老大。四万年时间，人是会变的，我已成圣人，而您犹是凡者。”</p><p>杨帝缓缓摇头，目光穿透圣道光辉，直视阿巴：“但是，圣人……不能存在。”</p><p>阿巴不出意外地点点头：“我想知道老大你的理由。”</p><p>杨帝的声音平静得可怕，阐述着一个冰冷如宇宙铁律的道理：“你欲让蓝星人类永续，让文明与天齐寿。这本身，就是一种对‘命运’的终极裁定。</p><p>“你定义了什么是‘好’——生存、延续、文明之火不熄。</p><p>“那么，与此相对的消亡、停滞、文明的黄昏，在你眼中，是否就成了必须被抹除的‘坏’？</p><p>“矛盾螺旋，本就是万物运行的底层逻辑。生与死，兴与衰，创造与毁灭，秩序与混乱……</p><p>“它们相互依存，相互转化，如阴阳轮转。而圣人会从矛盾的螺旋中选择一条道路，决定众生的命运走向……</p><p>“你有何权利决定哪种品质是好，哪一种品质是坏？你和原初之眼，归墟大帝，四大邪神，以及那个耶罗大仙……你和他们，有什么本质区别？”</p><p>阿巴眼中第一次流露出近乎悲悯的神色。</p><p>如果是四万年前那条天真的鱼，她不会思考那么多，只会一味地认同杨帝。</p><p>“老大您要说服我——命运只能由组成命运的每一个个体，在矛盾螺旋的推动下，自己去选！去挣扎！去生！去死！去兴！去衰！？”</p><p>杨帝沉默。</p><p>“老大，还记得在我的母宇宙，您带我们追猎那四个‘虚境小贩’时，您曾跟我说过，权力最厌恶真空。</p><p>“正所谓我不入地狱，谁入地狱？芸芸众生总会分强弱，与其让那些信奉社会达尔文主义的‘圣人’登上圣位，不如由我来庇护‘众生之弱’。</p><p>“杨帝！你该清楚，凡界不过是灵界的一幅画。若不是归墟大帝从中阻拦，灵界众仙早就随心所欲地涂改这混元山河图了。</p><p>“而灵界，也只是仙界的‘金融预测模型沙盘’。当初全靠他们那位先天神尊——某个在车库里捣鼓电脑的青年，一步步将灵界建成如今的繁华模样。</p><p>“老大，你我踏遍这么多世界，何曾见过哪个宇宙不是以‘武器的批判’为尊？</p><p>“如今若我不填补圣人的真空，而您又不会在此长久停留，不可能守望这世间永远，必然会有其他强者来占‘圣人’这个位置。</p><p>“可下一个圣人，未必还会为万物众生的福祉着想。”</p>
