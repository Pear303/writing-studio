# 字面意义·大道磨灭

<p>目光扫过三位气息紊乱、法则本源都受到冲击的准圣。</p><p>“花里胡哨，不堪一击。尔等引以为傲的大道法则、本源真理，在绝对强大的拳头面前，不过是土鸡瓦狗！”</p><p>声浪滚滚，震得远处观战的诸多真仙境大能气血翻涌，元神剧颤，仿佛直面了开天辟地的“先天神尊”之咆哮。</p><p>自诩掌控本源的准圣，看着杨帝体内爆发的数字风暴，第一次意识到即使是天道法则本身，在绝对数值碾压前竟也会像玻璃般寸寸碎裂！</p><p>是的，在荒古岁月，天道就是有缺陷的。</p><p>越来越多的大帝级存在以己身化道，才慢慢将此界天道补完。</p><p>天道，从来不是完满无缺，而是处处都有细微的漏洞。</p><p>“无法承载超越此界天地级别的数值”，也是灵界天道的漏洞之一。</p><p>但这似乎是无法克服的缺陷。</p><p>就算杨帝原地“己身化道”，大概也只能将天道所能承载的“数值上限”，提升到他本人的水平。</p><p>如果再之后，又有一个2倍杨帝、3倍杨帝的绝世强者出现。</p><p>也仍然会超出此界“数值上限”。</p><p>这就是灵界天道的永恒缺陷。</p><p>有限，就是缺陷。</p><p>当下，杨帝以一己之力，对抗整个世界。</p><p>三位准圣的道心，在他那蛮横无匹的宣言和绝对力量的碾压下，都产生了动摇。</p><p>耻辱，震惊，难以言喻的恐惧，与愤怒！</p><p>“狂妄！”涅槃轮劫元尊强行压下翻腾的气血与道伤，眼中涅槃之火熊熊燃烧，带着一种玉石俱焚的决绝。</p><p>“你不过是仗着异数之力，蛮力破法！我们三圣的领域之力，终究有其极限，但是，你……撑得住整个灵界的天威吗？！”</p><p>“不错！”太虚妙有法王的声音缥缈而冰冷，带着无边的杀意，“既如此，便让你见识见识，何谓真正的‘天威’！何谓、万古布局！”</p><p>居然还有布局！真是媲美朵拉的智斗巅峰！</p><p>两仪玄界之主没有言语，只是双手猛地结出一个繁复到极致的古印。</p><p>大致呈斧头的形状。</p><p>“引动创世之源！灵茶山乂斧——现！”</p><p>三位准圣头顶的虚空轰然裂开一道贯穿古今未来的巨大缝隙。</p><p>缝隙之中，是流淌着开天辟地之初的混沌母气！</p><p>在那无尽混沌的源头，一柄无法用语言形容其形态的“斧”的虚影，缓缓浮现。</p><p>杨帝瞳孔收缩成针尖大小。</p><p>那并非实体，而是一道凝聚了“开辟”这一终极概念的法则具象。</p><p>斧刃所向，混沌自行开辟，清浊自分，时空长河为之断流。</p><p>仅仅是其虚影散发出的气息，就让整个灵界的空间结构发出不堪重负的呻吟，时间变得紊乱不堪，万物法则都在颤抖、臣服。</p><p>……好吧，这几天，万物法则已经颤抖很多很多次了！</p><p>这是灵界诞生之初，劈开混沌、定鼎乾坤的创世之力的投影「灵茶山乂斧」。</p><p>代表创世的东西，那威能和动静不可能小。</p><p>能够创世，那自然也能灭世。</p><p>“所以你们为何如此执着于杀我，甚至要引动此界创世的力量啊！”</p><p>难道……</p><p>杨帝的思绪如电光石火。</p><p>他的超级智慧，最后一次发动演绎推理法，将散落的线索瞬间串联。</p><p>归墟大帝的阴伏流煞、诸帝不合常理的“复活”与围攻、此刻不惜引动创世之力的疯狂……</p><p>一切指向一个令人不寒而栗的真相：</p><p>“你们……想触碰禁忌，窥探域外天魔之力，甚至尝试掌控它。</p><p>“结果玩火自焚，弄出了‘阴伏流煞’这个你们自己都收拾不了的烂摊子。</p><p>“阴煞泄露，灵界根基动摇。你们第一时间却不是全力补救。</p><p>“而是推出‘归墟大帝’作为替罪羔羊，声称是‘实习期大帝’干的。</p><p>“归墟大帝原本以为，自己和你们站在同一个利益集团。</p><p>“但没想到被人从背后捅刀，推出去顶罪，所以他才呐喊——我遭背叛！！恨！！！</p><p>“你们没想到，最后归墟大帝还是决定跟我爆了，供出‘仙界’的存在，终于略微动摇到你们的存在根基，把站在干岸上的你们拉下水。</p><p>“但你们还是想到了好办法——以‘英雄’的姿态归来，联手镇压这场由你们自己制造出来的灾难！</p><p>“洗白自己，堵上我们的嘴，好一个洗白上岸，瞒天过海！</p><p>“你们才对我这个‘异数’如此忌惮！因为我不仅拥有超越此界极限的力量，更因为我的存在本身，可能会撞破你们的谎言！</p><p>“天威？秩序？维护你们肮脏权力的遮羞布罢了！你们，把生命都当做了什么啊！</p><p>“不要小瞧我，不要小瞧灵界万类众生的力量啊！！”</p><p>最后一次演绎推理，将先前的所有疑点，所有漏洞，都补完补全。</p><p>历史上的大帝，在寿元终尽后，并没有单纯地魂归天地。</p><p>而是飞升至仙界，过上退休生活。</p><p>但这帮老头子们的退休生活并不安分，他们还搞出了“阴伏流煞”这种东西。</p><p>他们让还在任的归墟大帝背锅，却没料到这年轻后辈居然有勇气跟他们这帮老登爆了。</p><p>无奈之下，在仙界的大帝，只好退休返聘，来到灵界帮忙收拾烂摊子。</p><p>其中一个超大的“烂摊子”，就是得知阴伏流煞与归墟大帝息息相关的杨帝、阿巴、五九改等人，既然已没有封口的可能，那必须灭口！</p><p>至于数百个围观的真仙境大能。</p><p>凭借历史上诸位大帝的威望，以及归墟大帝本身的声明，想要说服他们很是容易。</p><p>再不济，就把这些观众的招子都挖出来。</p><p>只要杀死杨帝，一切都会好起来的。</p><p>他是唯一的变数，他是唯一能掀翻天花板的人。</p><p>杨帝极其愤怒！！</p><p>黑暗！太黑暗了！</p><p>残星道人叹了口气，罕见地接话：“白杨大帝，你凡界的互联网刷多了吧？”</p><p>“你我之间已无说话的必要了，批判的武器无法代替武器的批判。”</p><p>杨帝心中那被点燃的滔天烈焰骤然冷却，但并不是熄灭，而是从狂暴的野火凝练成了冰冷刺骨的玄冰。</p><p>他意识到，无论真相如何，无论对方是肮脏的阴谋家还是另有苦衷的守护者，此刻都不是辩论的时候。</p><p>头顶那贯穿混沌的缝隙中，“灵茶山乂斧”的虚影正汲取着整个灵界的创世伟力。</p><p>开天辟地的威压如同实质的亿万钧神山，轰然压下！</p><p>大道，真的会在字面意义上被磨灭。</p><p>三位准圣脸上再无半分动摇，只剩下玉石俱焚的决绝。引动创世之斧，代价巨大，但他们已认定，唯有彻底抹杀杨帝这个超出天道理解的异数，他们自己才有未来！</p><p>杨帝知道自己死不成，他唯一要关心的是阿巴和59改。</p>
