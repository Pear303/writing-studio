# 学者

<p>……</p><p>第八次毒蘑菇事件，发生。</p><p>毕竟人活在世上，还是要吃东西的。瑞弗维尔身上没有补给，也只好采些蘑菇吃了。</p><p>那是个暴雨倾泻过后的下午，只有几缕阳光艰难地从浓云中透出。</p><p>大地仍然笼罩在一片阴沉里。因为没有光，而且到处湿漉漉，瑞弗维尔没有成功点火。</p><p>他只能借着法术的微弱光线，摘到了几丛理论上无毒的菌子。</p><p>雨后的菌子从腐木缝隙里钻出来，伞盖呈暗褐色，表面凝着水珠，像裹了层透明糖衣。</p><p>菌褶泛着淡淡的青灰色，凑近能闻到潮湿泥土混合着草木腐败的腥甜气。</p><p>“这是青褶乳菇，我在食谱上见过。”看来是可以吃的！瑞弗维尔心中无声欢呼。</p><p>他只对了一半。</p><p>这种“青褶乳菇”之所以出现在食谱上，是因为烹煮三刻钟就能分解毒素。</p><p>但四周潮湿，瑞弗维尔没能生火。</p><p>他本身有丰富的蘑菇学知识——对大部分毒蘑菇来说，高温烹煮并不能分解毒素。</p><p>青褶乳菇能出现在食谱上……说明它无毒……如果有毒，高温蒸煮大部分时候都无法去除毒素，所以不可能出现在食谱上……</p><p>“大部分”是个非常要命的词。</p><p>而瑞弗维尔偏偏是个很幸运的人，无论概率有多小的事，都很容易被他碰上。</p><p>其实“预言”法术也和“运气”息息相关。</p><p>就像他总能踩中极小概率的毒蘑菇事件，预言法术也会因他的幸运，而更容易捕捉到那些在常规概率中近乎不可能的未来分支。</p><p>瑞弗维尔愉快地生而啖蘑菇。</p><p>正是对应了那句话，浅水才能阴死老师傅。</p><p>地球上，许多蘑菇中毒的案例，当事人大部分都对对蘑菇有一定的了解。</p><p>因为有所了解，故反而信誓旦旦。</p><p>菌肉入口滑腻，带着雨后青苔的涩味，咽下时喉咙像被细密的针刺痛，胃里很快泛起阵阵绞痛。</p><p>他瘫在泥泞的溪涧旁，唇边还沾着褐色的蘑菇碎屑，瞳孔涣散地盯着天空。</p><p>这次他的幻觉似乎更离谱——嘴里喃喃着什么“原初之眼夺舍史莱姆之海”、“无限机兵与光微子鸟在闭合类时间曲线中决战”、“二尊战至宇宙边疆仿佛大道磨灭”……</p><p>“啊啊啊啊啊！你怎么不直接啃食人花？”</p><p>伊芙原地蹦跳，气得大道都要磨灭了。</p><p>她走到瑞弗身前，手掌按在他后颈，魔力如灼热的溪流，强行穿透他痉挛的血管。</p><p>瑞弗维尔猛地呛咳一声，将毒蘑菇残渣喷在泥水里。</p><p>翡翠色眼眸刚要发火，却对上那双琥珀色、懵懂又无辜的眼睛。</p><p>“小姐早……天啊，是罕见的东方精灵……请问有何贵干？”</p><p>他还懵懵懂懂，迷迷瞪瞪。</p><p>伊芙咬牙切齿地扯住他的衣领：“听着，你已经吃了八次毒蘑菇！这次幻觉又在胡言乱语什么机兵史莱姆！”</p><p>瑞弗维尔抹了把脸上的泥水，湿漉漉的卷发耷拉在额前：“怎么可能？那是褐色的蘑菇，《荒野求生宝典》第42页写得清清楚楚！褐色一般没毒，而且它看样子很像是冬菇。更、更何况要是有毒，那前7次我都已经死了……”</p><p>“死？”伊芙气得笑出声，“你倒是想！要不是本学者大发慈悲施展净化咒术帮你做了整整7次血液透析……”</p><p>她突然顿住，意识到自己说漏了嘴。</p><p>瑞弗维尔的眼睛瞬间亮起，沾着泥浆的手指颤巍巍指向她：“所以前七次也是你救的我？！”</p><p>雨声变得震耳欲聋。</p><p>伊芙感觉后颈发烫，慌忙甩开他的衣领后退两步，却不小心踩进溪涧的碎石堆。</p><p>瑞弗维尔眼疾手快地拽住强者的手腕，两人却因此双双在泥泞中跌作一团。</p><p>潮湿的空气里，暴雨倾盆之下，柑橘香与铁锈味交织，藤蔓在狂风中疯狂扭动，像是无数只纠缠的手臂。</p><p>溪涧边的橡树在狂风中摇曳，叶片簌簌震颤之节奏与跌宕的水声渐次重合。从橡树叶片滴落的雨水，沿精灵尖耳再度滑落，最终在人类锁骨凹陷聚成水洼。</p><p>地衣蛰伏已久，此刻攀附与潮湿的树皮上缓缓苏醒，分泌出带着柑橘清甜的荧光汁液。</p><p>荧光汁液略微照亮混乱且昏暗的草甸，倒伏的蕨类在重压下渗出汁液，与蘑菇孢子共同发酵出令人晕眩的芬芳。</p><p>暴雨在橡树叶尖织成珠帘，锁住芳香与清甜。</p><p>溪涧水线漫过青苔斑驳的鹅卵石，将沾着泥浆的月桂叶发卡冲得上下起伏。</p><p>藤蔓在潮湿中舒展新芽，蜷曲的须尖勾住滑落的精灵披帛，左右摇曳。</p><p>暴风骤雨持续许久，积雨云终于泄尽最后一声呜咽，虹销雨霁。</p><p>乳白月光重新漫过狼藉的溪岸。</p><p>朝云暮雨，潇潇雨云，都不值一提。</p><p>但异界的两轮月亮，在当地颇有说法。</p><p>这两轮月亮被称为“离弦月”，当它们越来越靠近的时候，会双双趋于圆润。</p><p>而当它们慢慢相互远离的时候，便会化作弦月，直至各自悬挂在天际的两端。</p><p>传说，月亮代表某种相互补完的趋势，当它们靠得越近，对方补完自己，自己补完对方，月相越发圆满。</p><p>而到了每个弦月之夜，纯真的孩童会对着两轮月牙中间呵气，试图用温暖的白雾，填补凉夜空中的月轮缺口。</p><p>但精灵长辈知道，那是卫星的轨道平面与行星公转轨道平面存在5.3°的倾角，导致其升交点或降交点周期性变化，影响相位与距离的对应关系。</p><p>两卫星与太阳-行星连线夹角增大至90°，受行星遮挡效应影响，近端卫星进入行星阴影区边缘，呈现西侧明东侧暗的上弦月特征；远端卫星因阳光斜射，呈现东侧明西侧暗的下弦月特征。</p><p>这两座卫星相比于其他行星的卫星，显得硕大无朋。</p><p>众所周知，多数行星与卫星的体积比往往在1/1000至1/5000之间，部分小型卫星甚至不及行星的万分之一。</p><p>而人类熟知的地球与月球，月球体积约为地球的1/49，这样的比例在星系中已算悬殊。</p><p>但这片异界的情形更是离谱。</p><p>名为“离弦月”的双卫星，体积与异世界星的比例颠覆常理。</p><p>东侧卫星直径达异世界星的1/18，西侧卫星稍小，却也达到1/22。这使得两颗卫星在夜空中如同悬浮的巨物，每当它们高悬天际，地表便会泛起引力涟漪，溪流会短暂改变流向，大洋潮水上涨，树冠也会不自觉地向月亮倾斜。</p><p>此时，离弦月正处于天文周期中最接近的时刻。</p><p>银辉如水漫过瑞弗维尔沾着泥的睫毛，将人类琥珀色瞳孔浸染成流动的蜜糖浆。</p><p>“伊娃，实话实说吧，其实我的梦想是做一位博才通古，成一家之言的史官。”</p><p>“就凭你？”伊芙忍不住嗤笑，“先学会分清毒蘑菇和可食用蘑菇再说吧。”</p><p>他凑近，温热的呼吸扫过精灵泛红的耳垂，“我分不出毒菌子和可食用菇，下次能让你亲手做的蘑菇汤吗？”</p><p>“妄想！下次再吃毒蘑菇，我就把你绑在树杈上！”</p><p>“话说，伊娃你为什么姓‘柑橘’呢？”</p><p>精灵躺在苔藓上，向人类解释了其中原因，还有她的童年回忆。</p><p>精灵的姓氏由他们的体香决定，而体香又由圣树决定，是比较随机的。</p><p>伊芙生来带有柑橘味体香，这是个比较正常的姓氏，至少没有随机到什么大王花，食人树，榴莲那般大味之物。</p><p>她幼年时候曾在一处的山洞中玩儿，然后一只熔岩史莱姆蠕行而来，送给她一本人类文明那儿出版的少女漫。</p><p>从此，伊芙一发不可收拾，对人类产生了不可磨灭的兴趣。</p><p>直到现在，刚满1600岁成年，她不仅是名震中土的10环超限大法师，同时也是享誉天下的人类社会学学者。</p><p>如果说一切的契机都是那本少女漫，那么伊芙决意认为，自己与瑞弗维尔的相遇就是命中注定了。就仿佛，他们有过前世因缘。</p><p>“不过，瑞弗，你要是敢写我的野传，我就叫你绑到末日火山做烤人串。”</p><p>“我真不能写你的野传吗……”</p><p>“不能，绝对不能，我是学者，我还要保留学术清白。”</p>
