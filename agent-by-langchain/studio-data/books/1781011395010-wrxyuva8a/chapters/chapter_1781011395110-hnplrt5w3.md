# 追杀

<p>一般人真的可能会迈出那一步，向南出发，渡洋去往星渊井口近海岸的唯一一座岛屿。</p><p>好险，他们也差点就这么做了。</p><p>围三缺一，意味着请君入瓮。杨帝几乎是和伊芙同时对过眼神，确定了这个结论。</p><p>“所以，往北边走，杀出重围？”</p><p>“怎么办，只有冲！”</p><p>于是他们同时下定了决心，同时做出行动，带着尚且懵逼的瑞弗维尔和奥拓，从人群最密集的北方冲杀出去！</p><p>“冲”是对的，但“杀”字不妥，因为他们并没有发动任何攻击类法术，只是单纯在空中飞速疾走、逃跑。</p><p>杨帝对灵能法术的运用，终究过于稚嫩。</p><p>而在此刻，活了一千多年的精灵对他展示了第二手招式——如何用不同的中低阶法术，组合成超有效的逃跑策略。</p><p>旋风术叠加浮空术基础升力，凭空对自己施加原力以驱动水平方向前进，流形的灵能护罩最大程度减缓空气阻力，甚至还可以再利用旋风术在前方制造低压区域……</p><p>杨帝本身也有叠加法术效果的战术意识，但他所缺的是练习，缺乏的是熟练度。</p><p>年龄就是二人最大的鸿沟，时间就是两个物种最漫长遥远的天堑。</p><p>“咻咻咻——”</p><p>他们几乎没有受到任何阻拦，就以三马赫的速度，从教廷头上百米高空飞驰而过。</p><p>瑞弗维尔心潮澎湃，无条件认为精灵是在下一步大棋。</p><p>而奥拓显然没有那么深的觉悟。</p><p>他在空中莫名其妙地飞着，望向下方密密麻麻的教廷修士如涛涛浪潮略过，心底发麻，寻思这和原计划目的地不一样，是不是上黑车了……</p><p>“杨帝兄弟？！能否告诉我为什么反而往北走！”</p><p>“嗯，表达了一种不甘受宿命束缚的思想感情吧。”</p><p>他们包裹在一个密闭气团内，在空中疾驰飞行，感受不到迎面吹来的风压，只能听见隆隆呼啸的风声。</p><p>往身后下方看去，教廷的人没有追上来。</p><p>但他们都转过身，沉默地注视四人。</p><p>除了有些瘆人，可以拍成恐怖片段以外，并没有构成实质性威胁。</p><p>海岸线正在远去。</p><p>白色石英滩正在远去。</p><p>直到教廷的人渐渐变成小黑点，那种逃出生天的如释重负感，像是一块巨石终于从心头缓缓挪开。</p><p>“打不过就逃！野史诚不欺我！”瑞弗维尔兴奋地挥舞着手臂。</p><p>“哪部野史？”</p><p>“巴德传·钢背兽篇。他亲口向我承认了，年轻的时候确实是遇到无法战胜的敌人，拔腿撒丫子就跑，只留下一个钢铁般的背影。”</p><p>奥拓却是不安地左右张望。</p><p>矮人眼神中透露出一丝恐惧，低声嘟囔道：“你们有没有觉得，好像有点不对劲？”</p><p>他这么一说，瑞弗维尔才注意到，杨帝虽一直在和自己有一句没一句说着话，但脸上的严肃始终没有褪去。</p><p>而伊芙，更是眉头紧锁。</p><p>不安的情绪，以符合热力学第二定律的形式，在这个密闭气团内缓缓扩散开来。</p><p>教廷的人虽然没有追上来，但那种被注视的感觉却愈发强烈。</p><p>仿佛有无数双眼睛，正透过层层云雾，紧紧地盯着他们的一举一动。</p><p>“先停下，回到地面上，在空中太显眼了。”</p><p>四人落地，这里是一片崎岖的丘陵地形，远处是他们曾走过的白桦林。</p><p>站在坚实的大地，倍感安全。</p><p>人们开始安定，他们便思考未来——</p><p>下一刻会发生什么？</p><p>下一刻，任何事情都可能会发生。</p><p>就比如现在。杨帝先是感受到暗红色黏液在帆布包内剧烈翻涌，滚烫触感透过布料，灼烧着他的后背。</p><p>而后，那团原本只懂得吞噬游离灵能的生物，那只由混乱灵能自发构成的最低等魔物，那个中土大陆食物链最低端的粘液怪……</p><p>说话了。</p><p>熔岩史莱姆突然开始说话了。</p><p>其惊悚程度，就好比烧腊店里的烧鸭突然开始唱海阔天空和普通话版的富士山下。</p><p>熔岩史莱姆的话音沙哑而尖锐：“精灵，杀了瑞弗维尔。”</p><p>还是那句话，如果杨帝能在0.1秒内弄清楚发生了什么，他会向对方脱帽致敬。</p><p>但这一刻，他已无时间细想。</p><p>这一刻，伊芙双目失神，周身灵能汇聚，法杖顶端一道碗口粗的聚能死光瞬间撕裂空气，直逼瑞弗维尔面门。</p><p>瑞弗维尔瞳孔骤缩。</p><p>凭借当了十来年职业游侠的经验，他在骨子中沉眠已久的本能开始发力——</p><p>身躯猛地向后，游侠的无敌翻滚！伊芙释放的死光擦着鼻尖掠过，将后方气团灼出焦黑裂痕。</p><p>这一翻滚，直接让他脊椎近乎扭断，全身上下七八处软组织挫伤。</p><p>但如果没来得及避开，这发聚能死光会削掉他80%的脑袋。</p><p>“为什么？！”</p><p>“为什么会这样？！！”</p><p>情势瞬间急转直下，天翻地覆。</p><p>伊芙，按照那只会说话的熔岩史莱姆的命令，对瑞弗维尔下死手。</p><p>她闪现至数十米外，周身腾起暗金色符文，无数细碎的黑色符文如同密集的流星雨倾泻而下，组合成一整个篮球场大小的术阵。</p><p>「九环法术·湮灭之创」</p><p>在末日火山，杨帝仅仅是被这一击的余波扫荡到，便深受重伤。</p><p>他想要冲上前踢飞瑞弗维尔。</p><p>但距离太远，无法在0.5秒内赶到。</p><p>下一刻，一个矮小的身影踢飞瑞弗维尔。</p><p>是奥拓。矮人肉身素质本身就很不错，而奥拓的站位也和瑞弗维尔更近，只需0.4秒即到。</p><p>是啊，他很快。</p><p>天下法术，无坚不摧，唯快不破。伊芙更快。</p><p>瑞弗维尔被奥拓踢飞的瞬间，湮灭之创的黑色洪流轰然压下。</p><p>矮人那一脚蕴含的力量，让瑞弗维尔倒飞而出，彻底暴露在法术正中心。</p><p>你特么是救我还是整我……瑞弗维尔心中闪过亿万念头。</p><p>这事其实也不怪矮人……伊娃锁得太稳了……</p><p>再下一刻，符文交织的光芒中，黑色彗星降世。“黑彗星”就是这道法术的本体。</p><p>下一刻，耀白色爆焰冲天而起，紧接着是一声震耳欲聋的轰鸣。</p><p>杨帝瞳孔剧烈收缩，双手如幻影般舞动，二十道灵能护盾呈同心圆状层层叠加。</p><p>他只能将自己与奥拓护住。</p><p>湮灭之创的冲击力撞上护盾，空气炸裂出刺耳尖啸，灵能护盾表面泛起蛛网状裂痕。</p><p>奥拓狱髓钻头在地面犁出半人深的沟壑，只能用后背死死抵住杨帝的护盾，嘴里不断喷出带着血丝的咒骂。</p><p>但他的声音刚出口，就被更剧烈的爆炸声覆盖。</p><p>“轰——轰——隆——！！”</p><p>惊天动地的爆炸……丘陵地表被生生削去三丈，土石如陨石雨砸向四面八方。</p><p>杨帝的灵能护盾接连破碎。</p><p>一层、二层、四层、八层……</p><p>他被余波震得口鼻渗血，整个人被掀飞出去数十米，后背重重撞在一棵白桦树上，将碗口粗的树干拦腰撞断。</p><p>烟尘弥漫间，杨帝挣扎着爬起身。</p><p>20层护盾已破碎了19层。</p><p>最内层那层若隐若现的微光，他难以置信地盯着战场中央，觉察到了不对——</p><p>本该毁天灭地的“湮灭之创”，此刻威力竟比在末日火山时削弱了80%。</p><p>伊芙可能还保有稍许理智，才能以无匹的意志力反抗“史莱姆的操控”，减弱法术杀伤。</p><p>但即使如此，瑞弗维尔也无法硬扛。</p><p>杨帝内心终于流露出一丝真实的情感，像是淡淡的悲伤吧。理智告诉他，自己应该悲伤。</p><p>瑞弗维尔只能是死了，大罗金仙降临中土大陆都救不活。</p>
