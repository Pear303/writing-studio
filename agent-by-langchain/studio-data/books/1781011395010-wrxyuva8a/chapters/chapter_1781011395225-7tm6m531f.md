# 准圣的伤害……不太够

<p>宇宙尽头，历史的终结点。</p><p>在一切可能性的尽头，在时间与因果长河彻底干涸、所有星辰归于冰冷死寂的最后之地，并非虚无。</p><p>一位存在端坐于此。</p><p>祂的身影无法用任何维度描述，其存在本身便是终点概念的具象化。</p><p>祂背对着身后那已坍缩凝固，已然失去所有活力的历史泡影——那泡影中，曾有无穷宇宙生灭，有无量众生悲欢，有诸天神魔争渡，最终都归于祂座下这片永恒静止的墓碑。</p><p>祂面向的，是光锥之外。</p><p>那是连存在与虚无都失去意义的绝对未知，是孕育着所有黑暗不详，以及尚未书写之可能的混沌深渊。</p><p>祂的存在，如同横亘在已死历史与未生混沌之间的叹息之壁，镇压着可能颠覆一切的不详。</p><p>祂是守墓人，亦是镇守者。</p><p>遥想亿万年前，自己还是个在地球上备战高考的普通男子高中生。</p><p>在最初得到“吃饭就能加点系统”的那段青葱岁月，他还不知道，自己最终将会是如此这般结局。</p><p>无人记得，无人知晓，但他的功绩铭刻于星空。</p><p>又有什么意义……？</p><p>就在刚才，祂那仿佛由凝固的宇宙弦构成的袍袖边缘，一粒微不可查的尘埃轻轻震颤了一下，随即彻底熄灭、消散。</p><p>那尘埃，曾是名为玄穹子的太乙真仙，其存在的所有时间线、所有可能性，在某个遥远上游的节点被彻底抹除。</p><p>祂看到了，那发生在过去。</p><p>对祂而言，一切皆已成历史。</p><p>发生在过去历史中，某一条世界线，某个微不足道的蓝色星球轨道上的抹杀。</p><p>一个名为杨帝的存在，像碾死一只聒噪的虫子般，用一根腿毛的反作用力推动自身，以超越光速的物理冲击，将玄穹子及其无穷化身、元神寄托尽数湮灭。</p><p>聒噪。</p><p>一个意念，如同投入死水的石子激起的涟漪，在终末之壁前扩散开，随即被无边的寂静吞没。</p><p>这便是守墓圣人的全部反应。</p><p>祂的目光从未离开光锥之外的黑暗渊海。</p><p>一个太乙真仙的彻底消亡，于祂而言，不过是守墓时拂去衣袖上的一粒微尘。</p><p>蝼蚁的喧嚣，惊扰不了镇压终极黑暗的心境。</p><p>祂的职责，远高于此。</p><p>……</p><p>地球，卡门线之上。</p><p>杨帝的身影静静悬浮在地球大气层的边缘，下方是蔚蓝的星球弧线，上方是深邃的星空。</p><p>他刚刚完成了一次对无限力量的精准展示，也向此界发出了最直白的宣告。</p><p>他清晰地感知到，那来自宇宙尽头、历史终点的漠然一瞥。</p><p>以及随之而来，更多来自四面八方，带着强烈敌意与贪婪的注视。</p><p>如同平静的水面骤然投入巨石，杨帝周围的空间瞬间沸腾！</p><p>七道身影，毫无征兆地撕裂空间，出现在杨帝上下左右前后，七个方位，将他牢牢封锁在中心。</p><p>他们像是高维存在的投影强行挤压进这片空间。</p><p>每一个身影都散发着令星辰颤栗、让法则扭曲的恐怖威压。</p><p>有的身披星河织就的道袍，有的笼罩在燃烧的业火之中，有的如同冰冷的机械聚合体，有的则完全是一团不断演化的混沌能量。</p><p>他们的形态各异，但那份凌驾于凡俗宇宙之上的位格却清晰无比。</p><p>七位准圣！</p><p>这是超越了太乙真仙，触摸到圣人门槛的无上存在。</p><p>他们几乎代表着当前宇宙维度中，所能容纳力量的顶点。</p><p>但，也只是几乎。</p><p>“域外天魔！”为首一位，身披星光道袍，面容模糊不清，声音却如同亿万星辰同时共振，直接在杨帝的灵魂层面炸响，带着审判与不容置疑的威严。</p><p>“汝之存在，悖逆常理！灵如黑洞，吞噬万象，内敛至斯，而非如恒星般照耀诸天！此乃域外混沌天魔之相！汝潜入此界，意欲何为？！”</p><p>他意思是：杨帝的灵能像黑洞一样向内收敛，而非烈阳那边向外放射，一看就不是什么好东西。</p><p>土法鉴魔闹麻了。</p><p>另一位像一大坨机械构造物的准圣，一是充分发挥赛博判官、电子神探的俺寻思精神，其意念冰冷如万载玄冰地说：“灵能向内收敛，是为魔性，该杀；灵能向外放射，是为狂傲，该杀；灵能兼收并蓄、滴水不漏，是为奸邪，该杀；灵能有收有放、形态不定，是为诡诈，该杀。”</p><p>又有个家伙嚷嚷：“玄穹子虽非至强，亦是此界太乙，汝竟悍然灭其形神，断绝其所有道途！此乃挑衅诸天秩序！当诛！”</p><p>一切归根于杨帝那诡异到极点的灵能状态。</p><p>——完全内敛，如同绝对静止的黑洞，与任何已知修行体系的能量辐射都截然不同。</p><p>没有多余的废话。</p><p>七位准圣瞬间达成共识。</p><p>——此乃前所未有之大敌，必须倾尽全力，以雷霆之势灭杀！</p><p>杀！</p><p>镇！</p><p>灭！</p><p>封！</p><p>炼！</p><p>绝！</p><p>戮！</p><p>七声蕴含着无上道则的敕令响彻虚空！七位准圣同时出手！</p><p>刹那间，卡门线之上的空间彻底化为虚无的战场！</p><p>星光道袍准圣抬手引动诸天星斗之力！业火准圣周身地狱业火暴涨！另外五个准圣亦是各显神通，大道震动。</p><p>七种足以瞬间毁灭一片星域、让无数文明灰飞烟灭的恐怖攻击，同时降临在杨帝身上。</p><p>光芒、火焰、混沌、切割刃、毁灭音波、混元禁制……</p><p>七种超越凡人想象极限的力量碰撞湮灭，将杨帝所在的那片空间，彻底化为一片连“虚无”本身都被反复蹂躏粉碎的绝对死域！</p><p>攻击的中心点，爆发出比超新星爆发强烈亿万倍的强光！</p><p>能量风暴席卷而出，地球大气层剧烈扰动，全球通讯瞬间中断，无数卫星化为齑粉。</p><p>他们已经很收住力了。</p><p>仅仅只是瘫痪该行星的全球卫星。</p><p>七位准圣悬浮在风暴之外，神念死死锁定着攻击核心。</p><p>他们自信，七位准圣联手一击，便是真正的混元圣人也要避其锋芒。</p><p>一个来历不明、气息诡异的域外天魔，绝无生还可能。</p><p>光芒与风暴缓缓散去。</p><p>那片被蹂躏得不成样子的空间中央，一个身影依旧静静地悬浮在那里。</p><p>杨帝。</p><p>他甚至连衣角都没有破损半分。</p><p>那足以贯穿星系的星河光矛，在距离他眉心还有一寸时，便定住了。</p><p>随即星辉寸寸崩解，化为虚无的星光尘埃飘散。</p><p>那缠绕而上的业火枷锁，在触及他皮肤的瞬间，仿佛遇到了不可燃的绝对物质，连一丝青烟都未能升起便无声熄灭。</p><p>杨帝甚至没有做出任何防御姿态。</p><p>他就那样站着，眼神平静得如同古井深潭，带着一丝了然。</p><p>他已经摸清楚这个世界的大概实力，和自己的大概位阶。</p><p>最重要的——进化适应超量代偿的水平。</p><p>确实是的，在无限宇宙自己受到任何一丁点微小的伤害，都足以让数值积累到无穷。</p><p>但「伤害」之间，亦有差距，其中就分为三种：</p><p>世界内普通伤害。</p><p>世界级伤害。</p><p>超越世界级别之伤害。</p><p>现在能够伤害他的，至少得是无限灵能宇宙的……圣人级存在，也就是“世界级”甚至“超越世界级”的杀伤。</p>
