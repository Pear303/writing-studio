# 原初之战：机兵附魔

<p>伊芙·柑橘一人背负着整个大陆的命运。</p><p>她在圣树帮助下，孤身跳跃到这4万年前的精灵领地，寻找无限机兵，对抗原初之眼。</p><p>四万年的时空裂隙在她身后翻涌，像一头蛰伏的巨兽随时会将她吞噬。</p><p>现世已在身后，历史犹在眼前。</p><p>远处，传来初代精灵的吟唱，声音裹着晨露与藤蔓的气息，却让伊芙想起原初之眼降临那日——血色云霞下，自己亲手杀死了瑞弗维尔。</p><p>她与矮人一同，拖着残躯回到圣树领地。</p><p>而后，酝酿已久的熔岩史莱姆冲破地表，占领了几乎整片大陆的地表。</p><p>在跳跃前，伊芙·柑橘问了圣树母亲最后一个问题：“瑞弗维尔能复活么？”</p><p>圣树只是回答：“取决于命运。”</p><p>这世间，命运由谁决定？</p><p>四万年前的土壤仍带生命，而现世的圣树领地或许早已被岩浆彻底焚毁——这该死的命运，又是由谁决定？</p><p>已来不及继续悲伤，为了圣树，为了精灵族群，为了大地上的世人，为了瑞弗维尔……她必须找到无限机兵。</p><p>“砰！！！”</p><p>原始精灵愣住了。伊芙愣住了。</p><p>圣树愣住了。每一簇花草都愣住了。每一缕气流都愣住了。</p><p>银白色机兵，屹立于大地。</p><p>无限机兵出现在那个时代的第1毫秒，杨帝扫描遍整个行星。</p><p>“和我预想的不太一样。这个时代，我并不存在。”</p><p>传感器瞬间读取方圆数万公里环境信息，杨帝在这个时空，却并没有发现第二个自己。</p><p>而伊芙，是孤身一人跳跃回来的。</p><p>“这是一条我不存在的世界线？还是说，因为我从异界来，所以比较特殊？”</p><p>第2毫秒，他用传感器扫描第二个目标。</p><p>这一次，找到了——在一切还未开始之前，埋藏于圣树底下的机兵。</p><p>杨帝走向圣树。</p><p>“你是……机兵？！您在驾驶机兵！……您到底是……”</p><p>伊芙的瞳孔映着银白色机兵的金属光泽，喉咙发紧，但她还是强行发出声音，疾呼那位陌生的机兵驾驶员。</p><p>原始精灵、包括这条世界线的圣树，对不知何时闯入森林领地的伊芙没有报以过多注意。</p><p>此刻，杨帝和他的机兵，全场最靓，吸引了万众目光。</p><p>“这……是圣树的指引吗！”</p><p>“银白色巨人，何时来的！”</p><p>这条世界线，这个时代的原始精灵，他们还不知道即将到来的神灵恶意。</p><p>而杨帝也感应到，那尊庞大的意志紧随自己之后，也已来到这个时代。</p><p>他操控机兵，短距跃迁机动，隔空抓取，将埋藏地下的第二座「无限机兵」挖出来。</p><p>“奥拓，恁忒娘真是个天才……”</p><p>社科天才、身残志坚的奥拓，曾经用金融杠杆骗过了“绑定诅咒”这类极其强大的附魔。</p><p>而他通过三个“锋利I”，合成一个“锋利III”，也杨帝带来了更大的启示。</p><p>“奥拓的狱髓钻头，就同时附上了多种不同的附魔效果……而我在最初学习法术时，也发现了‘质量不够数量来凑’的技巧……”</p><p>异世界搞魔法也讲究财侣法地。说到“财”，杨帝能够感觉到，“灵能附魔”其实和“金融杠杆”也没什么区别，都可以视作向一件事物，附加上他不该有、或者是当下不该有的数十倍、数百倍价值。</p><p>最重要的是信心。相信的心就是魔法。</p><p>杨帝不再有丝毫犹豫，操控第一座机兵稳稳地与刚挖出的第二座「无限机兵」对接。</p><p>二次附魔，效果叠加。</p><p>杨帝只觉脑海中“嗡”的一声，置身于一场宏大的信息风暴之中。</p><p>机兵的绝大部分本质，是一大团附魔。</p><p>也就是向一件器具或一个人，附加上外来的定制化灵能。</p><p>不同器具，不的生物，对不同附魔效果的承载能力是不同的。杀手兔的“速度”附魔不能应用于人类，鱼竿的“海之眷顾”附魔则极少出现在刀剑类器具上。</p><p>当两座无限机兵重叠，对杨帝的冲击，相当于在一片糯米纸上雕刻10环法术符文，强大的灵能洪流会撕碎这片脆弱的糯米纸。</p><p>杨帝只觉灵能如火山般在体内喷涌，身躯就似那脆弱的糯米纸，“噗”一声，自皮肤开始，以肉眼可见的速度皲裂、爆裂开来。</p><p>先是指尖，一道道血线如细密的蛛网般蔓延，紧接着手臂、胸腹、大腿，各处的皮肤都纷纷炸裂，肌肉外翻，骨骼在巨大的压力下也发出不堪重负的“咯咯”声，鲜血如喷泉四溢。</p><p>他猛地咬破舌尖，将治愈法术咒文混着血沫喷出。</p><p>「六环法术·枯木逢春·黄金加强版」</p><p>外翻的肌肉像是被一双无形的手轻轻安抚，缓缓回缩、愈合。断裂的骨骼发出“咔咔”响，以不可思议的速度重新拼接、生长。炸裂的皮肤迅速逐渐抚平、合拢。</p><p>眨眼间，原本破碎不堪的身躯，竟已完好如初，只留下些许淡淡血痕。</p><p>「综合抗性+1+1+2+3+5……+1597+2584」</p><p>杨帝能力是“超量代偿损伤”，可以类比受到刺激、修复损伤时，总是能超量获得身体受到的伤害。</p><p>这项特异功能的衍生特性是：自愈速度至少是常人的百倍，甚至在某些方面超越能量守恒；而且，他对于各项“技能”，也可以无限叠加熟练度。</p><p>异界的“治疗法术”，是杨帝目前为止最大的收获。</p><p>损伤→治愈，杨帝防御力和生命值进化的两大过程。</p><p>而“治疗法术”的存在，让“治愈”过程再度提速，与杨帝简直是天造地设的一对。</p><p>“噗——”他再度喷了口混合内脏碎块的血。</p><p>承受两台机兵的附魔，还是有些勉强。</p><p>他的物质身体持续性崩解、爆裂，仿佛陷入了一场永无休止的噩梦循环。</p><p>皮肤刚愈合又再次炸开，肌肉组织再次被扯碎，骨骼在反复的冲击下，哪怕刚刚拼接完好，瞬间又被震得粉碎，碎骨碴子伴随着鲜血飞溅而出。</p><p>每一次崩解带来的剧痛都如汹涌的潮水，将他100%接收所有感官信息的“意识”，狠狠淹没。</p><p>杨帝只能一次又一次地催动治愈法术。</p><p>肌肉在光芒中艰难地重组，骨骼在剧痛中重新归位，皮肤如凤凰涅槃般层层重生。</p><p>还没等他喘上一口气，新一轮的灵能冲击又接踵而至，再次将他好不容易修复的身体击得粉碎。</p><p>粉碎，重生，崩裂，自愈……</p><p>如此往复间，每次自愈，机兵装甲泛起更耀眼的光芒。</p><p>仿佛在血与光的淬炼中，人与机械正熔铸成新的兵器。</p><p>「无限机兵II」</p><p>附魔叠加的过程似是榫卯契合，严丝合缝。</p><p>“原初之眼……这还有一部分灵感，是我向你学习的——通过不断时间跳跃实现迭代，无限进步升级。只是实在难以想象，就连因果律本身，也变成了任人打扮的小姑娘。”</p><p>顷刻间，巨量经过技术迭代的熔岩史莱姆，汹涌之火流，冲破地表，朝杨帝与他的「无限机兵II」疯狂扑来。</p><p>所经之处，大地焦裂，冒着刺鼻硫磺味，这片古老的土地正被来自地幔的业火重铸！</p><p>杨帝机兵冲到圣树森林外围，拳头轻轻一捏，冲击波就炸碎方圆十公里的树木土石。</p><p>他与熔岩史莱姆的战斗，一触即发！</p><p>……</p>
