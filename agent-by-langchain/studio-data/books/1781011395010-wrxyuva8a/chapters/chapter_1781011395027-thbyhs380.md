# 致死伤害

<p>杨帝潜下水。</p><p>他很快便进化了眼睛，能在水下睁开眼，而且没有那种近视模糊的感觉。</p><p>周围的一切都异常清晰，就似他先天带着副眼镜。</p><p>聚光灯透过水面洒下，形成一道道金白色的光柱，照亮了整个被清水淹没的澡堂。</p><p>杨帝在超巨型澡堂里自由游动，感受着水的清凉和光柱的温暖。</p><p>他游向聚光灯，那光线确实暖乎。</p><p>「耐辐射+1」</p><p>“……”杨帝只是随手晒了晒灯泡，没想到竟是紫外线灯。</p><p>只有紫外线灯才会这么烫！</p><p>他见过有一些紫外线灯，专门设计来敷小鸡，温暖鸡蛋，促进小鸡的骨骼生长。</p><p>然后有些卧龙凤雏，突发奇想，买这些紫外线灯来冬天暖手。</p><p>结果把手都灼伤了，在手上留下像漩涡一样的疤痕，搞不好还容易整成皮肤癌。</p><p>皮肤癌听起来只是皮肤起了病变，好像不那么危险，但实际上，只要和“癌”字搭上关系，管你皮肤不皮肤，指甲癌还是头发癌，都是能轻易杀人的。</p><p>核辐射能很容易导致癌症。</p><p>如果哪天他挨了发核弹，尽管免疫了冲击波（钝器伤）和热辐射（耐热性），最后却被核辐射杀死，那岂不是很冤？</p><p>防患于未然，如果紫外线辐射也能耐受……</p><p>那就开刷！像在游戏里刷经验那样，刷耐辐射体质！</p><p>杨帝的瞳孔在水波中收缩成两道竖线，视网膜表层，浮现出淡金色的保护膜。</p><p>他的眼睛，已呈现出初步的耐辐射性。</p><p>「耐辐射+1」</p><p>照紫外线灯还有个好处，那就是很温暖。</p><p>普通人晒了容易得皮肤癌，但对于杨帝来说，有益无害。</p><p>不同地方的紫外线灯有强有弱，比方说，第三根立柱的紫外线强度，明显高于其他区域。</p><p>当他游进那根立柱上紫外线灯的光斑范围，皮肤立即传来灼烧感，一种反胃恶心的感觉涌上心头。</p><p>「耐辐射+1」「耐辐射+1」</p><p>「耐辐射+2」「耐辐射+3」</p><p>「耐辐射+5」「耐辐射+8」</p><p>到“+8”的时候，上升的势头停住了。</p><p>不论杨帝怎么靠近紫外线灯，甚至把整个身子铺上灯罩，再往后，都只是“+1+1+1”。</p><p>杨帝能感受到，DNA链在辐射冲击下层层断裂崩解，但修复速度总能死死咬住破坏频率。</p><p>在基因崩溃、细胞大规模癌变之前，迅速将其修复好，并且能承受更大剂量的辐射，如此形成正反馈，一个良性循环。</p><p>池梦持续了很长很长很长时间，都还没见能醒来。</p><p>杨帝懒洋洋晒着紫外线灯，直到身体免疫了这种强度的紫外线。</p><p>根据“破防才能锻炼”原则，此时，潜意识深处再也不弹出“耐辐射+1”提示了。</p><p>“身体对辐射耐受度太高，这里的紫外线灯已经不能造成一丁点伤害了啊。”</p><p>杨帝感觉在自己的梦里睡了个很长的午觉。</p><p>他有些不舍地离开暖光区域，又回到冰冷的池水深处。</p><p>「耐寒+1」</p><p>他又有发现新大陆的感觉了。</p><p>池水的绝对温度其实并不低，在25℃左右。</p><p>但是，因为他刚才在紫外线灯下待了很久，身体发烫。</p><p>现在一头扎进深水区，温度变化剧烈，所以体感很冷，像浸泡冰水一样！</p><p>仅仅是“体感很冷”，而不是绝对温度冷，就能触发“耐寒”。</p><p>竟是如此……唯心？！</p><p>“如果我找个催眠大师，催眠自己‘我感觉自己身体被浸泡在恒星里’，或者催眠我‘我现在很热很热’，是不是就能增加‘耐热’？”</p><p>再往深处想，杨帝目前在做的，就是个不知何时才能醒的清醒梦。</p><p>在梦里面锻炼……也能增加现实中的游泳技巧，和耐辐射度。</p><p>这本身就很唯心了。</p><p>做梦和看视频的区别在哪？为什么仅仅是理论学习，就能对身体产生物理性的改变？</p><p>一切都太魔幻，不科学。</p><p>杨帝也只能继续漫无目的地潜泳，期待着不知何时醒来，到现实里验证一番。</p><p>而现在，还有个亟待解决的问题。</p><p>为何有的时候，是+1+1+1+1+1匀速进步，又有的时候则是+1+1+2+3+5+8以黄金分割数列的形式递增？</p><p>显然，后者进步速度很快，和前者永远是匀速。</p><p>如果能找出其中的规律，让他的锻炼效率趋向于黄金分割数列，那就能事半功倍，事半功十倍，事半功百倍！</p><p>杨帝开始回忆，都是在哪些情况下，才会触发最高效的进步曲线？</p><p>熟练度以黄金分割数列递增时，分别是：</p><p>手臂被生锈钢筋划拉开一道大口子；他目睹了张明远那张照片；深陷水底无法自拔；被强度紫外线照射。</p><p>而匀速进步，则分别是：长跑、拉单杠、跑酷、摔打身体、锐器割伤。</p><p>“我好像能明白它们之间的区别……”</p><p>手臂被生锈钢筋划拉开大口子、深陷水底无法自拔、高强度紫外线照射。——这几项，应该被归类为“致死伤害”，烈度远远高于“锻炼”。</p><p>而长跑、拉单杠、摔打身体这些——还只能算是“锻炼”，远远称不上“致死伤害”。</p><p>他的身体难以免疫破伤风和大批病菌，难以承受水压和窒息，难以承受高强度、大剂量的紫外线辐射。</p><p>于是，当“致死伤害”造成。</p><p>杨帝的身体似乎会……跟急眼了一样，疯狂进化？</p><p>照射紫外线辐射的时候，还有个细节。</p><p>在经过+1+1+2+3+5+8的狂飙式进化后，杨帝对辐射的耐受度提升，又恢复成了+1+1+1+1的匀速水平。</p><p>很可能就是因为，经过狂飙进化过后，这种强度的紫外线已经对他造不成“致死伤害”！</p><p>所以，后续的辐射轰击，因为对杨帝的伤害有限，所以，都会被视作强度更低的“锻炼”。</p><p>杨帝的脑海中闪过一丝灵光，似乎隐隐抓住了什么关键。</p><p>某一项属性剧烈提升，说明他正在承受致死伤害。</p><p>如果这个猜想没错……那……</p><p>虽然在水里，杨帝还是感觉额头流下一滴冷汗——他发现了个盲点。</p><p>他在看到那张红气球图片时，精神+1 +1 +2 +3 +5……+233 +377，到底是怎么回事？！</p><p>“我的‘精神’在极短时间内，坐火箭一样剧烈地升级进步……只有一个可能。”</p><p>那张蓝天红气球的照片，“致死性”远远超过窒息和破伤风！</p><p>为什么……</p><p>为什么一张.jpg格式的图片……会有如此剧烈的“致死性”？！</p><p>而且是精神上的致死，一种思想和智慧层面的杀伤，而不是物理或者生化上的致死。</p><p>闻所未闻的死法。</p><p>他只在恐怖故事、惊悚电影里见到过。这到底意味着什么？</p><p>哦不……杨帝心中一悸。</p><p>他好像想起来自己在照片里看到什么了……妈耶……</p><p>有东西躲在了那图片里面，难以名状，难以言说。</p><p>他能回忆起那玩意的存在，但无法用语言表述出，那东西到底像什么！</p><p>猫狗，消防栓，珊瑚虫，躺椅，章鱼，葡萄藤，太阳能打火机，绿豆味雪条……惚兮恍兮，其中有象；恍兮惚兮，其中有物。</p><p>杨帝的瞳孔在水波中急剧扩散，被水压挤碎的思绪，在脑海重组。</p>
