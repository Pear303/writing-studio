# 原初之战：龙语诅咒

<p>如果只是普通的攻击类法术。</p><p>那么甭管是10环15环20环，这挺机兵都能硬扛——它各方面的属性值都高到突破天际！</p><p>杨帝仔细研究过机兵的各系统……的目录。</p><p>光是目录，就有500个GB。</p><p>为此，还为系统目录配备了目录的目录，以及目录的目录的目录。</p><p>但是，这道圣光法术，是原初之眼经过数次迭代研发的“十环禁术·质壁分离”！</p><p>祂似乎知道机兵很硬，正面强攻难以奏效，便剑走偏锋，从最薄弱的环节——人与机的连接点下手。</p><p>杨帝的灵质，与机兵愈发分离。</p><p>「警告，世界线变动。」</p><p>刚刚才再度承受撕裂灵体的一击，杨帝还未缓和多久。</p><p>原初之眼再度迭代进化，这次似乎是史莱姆集体意识的远程链接技术、真空环境下灵能的保持方法……而且祂的动作似乎越发熟练！</p><p>更糟的是，杨帝发现，自己对机兵的操控指令开始出现延迟，仿佛有一层无形的屏障，横亘在意识与机兵之间。</p><p>人与机的灵，正在割裂。</p><p>杨帝的意识开始阵阵恍惚，知道他意识世界深处弹出机兵的系统提示：</p><p>「时间机器校准完成！」</p><p>「时间跳跃精度提升至『秒』级。」</p><p>时间机器，启动跳跃。目标时代，第四纪元1999年霜月45日傍晚7点22分59秒，星渊井口。</p><p>根据瑞弗维尔所说，第四纪元1999年霜月45日傍晚7点23分，圣骑士巴德对卡利斯托射出决胜一箭。</p><p>……</p><p>石英滩海岸的硫磺雾霭吞噬了最后一丝日光。</p><p>圣古琉斯军团于星渊井口集结之时，苍穹已被「焚灭天空之龙·卡利斯托」的骨翼遮蔽。</p><p>但在下一刻，银白色机兵出现在火云燎烧的战场。</p><p>卡利斯托惊得在空中硬生生刹车。</p><p>巴德的最后一箭也射歪了。</p><p>随即，原初之眼的庞大意志，也瞬间降临到这个时代地幔中的熔岩史莱姆集群。</p><p>四方势力，除了几乎没有表露出情感的原初之眼，他们面面相觑足足3秒。</p><p>“很好，跟过来了。”</p><p>「十环禁术·质壁分离」的法术洪流轰碎地壳，自下而上，向杨帝激射而来。</p><p>为什么是“轰碎”？沿途所有被这道法术影响到的土石、丘陵，其物质轮廓开始变得不稳定，就像一幅被打乱了线条的画，土石的棱角扭曲起来，原本坚实的山体仿佛瞬间失去了支撑自身的力量。</p><p>先是表层岩石像被高温炙烤的蜡一般，开始缓缓流淌，却又不是正常液体的流动，而是带着一种诡异的抽搐，像是有无数只无形的手在内部肆意拉扯。</p><p>流淌的部分逐渐变黑，黑得纯粹且深邃，仿佛能将周围光线都吞噬进去。</p><p>紧接着，这种黑色如传染病般迅速蔓延，整块石头、整座丘陵都被这股黑色侵蚀。</p><p>原本坚硬的土石在这黑色笼罩下，变成一堆扭曲抽搐的物质，它们仿佛有了自己的意识，痛苦地挣扎扭动，发出低沉而尖锐的声响。</p><p>——物体在崩溃边缘的哀号。</p><p>法术所过之处，打开了一道通往未知恐怖领域的大门。</p><p>原本实实在在的实体物质，都在以一种违背常理的方式瓦解崩溃，化为那令人毛骨悚然的扭曲抽搐的黑色……拉面。</p><p>「形灵桎梏，瓦解。」众人终于感受到，原初之眼所泄露出来的一缕意志。</p><p>巴德这边，本就因为机兵突然出现而分神，这突如其来的诡异攻击更让他措手不及。</p><p>手中由圣剑变形而成的长弓，险些脱手。</p><p>随即，他只感觉一股莫名的力量，在试图剥离他的灵魂。</p><p>那是一种深入骨髓的恐惧与痛苦，他身体不受控制地颤抖起来。</p><p>圣骑士铠甲下的皮肤，浮现出细密裂痕。</p><p>“我正在，离自己远去……”</p><p>翱翔于天空的巨龙，也在打击范围内。</p><p>它灵魂也在这股力量的作用下，与身体产生可怕的分离之感，每一寸灵体都似被无数细小的尖刺狠狠扎入，强行从自己的精神与血肉之中抽离。</p><p>“吼——吼——吼！！”</p><p>它不明白自己发生了什么。</p><p>但卡利斯托知道，如果再不做点什么，自己会变得如同那片黑色的大地般，扭曲，狰狞，浑浑噩噩地蠕行。</p><p>「龙语诅咒·不可破坏」</p><p>当下，焚灭天空之龙已来不及区分自己、巴德或是机兵了，它一声怒吼，整座星渊井口的事物都沾染上名为“不可破坏”的附魔/诅咒。</p><p>但它恐惧地发现，自己的灵质与形体，仍然在分离不止。</p><p>这不是破坏，而是抽离。</p><p>所以“不可破坏”，并没有发挥作用。</p><p>机兵闪现至巨龙面前：“卡利斯托！绑定诅咒！”</p><p>巨龙闻言，心有灵犀，眼中闪过决然。</p><p>它仰天发出一声更为凄厉的咆哮，那声音仿佛能将这片被黑暗笼罩的天空都震碎。</p><p>「吾以太古血脉之名，唤诸界诅咒之力。灵与形的离散，止于此刻。</p><p>渊底有暗火，永无熄灭；穹顶之星辰，恒常高悬。形为牢，灵为卒，相系不可解。</p><p>分离之恶意，诅咒中粉碎。以吾之魂，以吾之体，铸就不可破的桎梏。</p><p>灵归其位，形守其躯，我『卡利斯托』诅咒万物皆受绑定，永不分离！」</p><p>更为磅礴的龙语诅咒之力，以它为中心疯狂扩散开来，整个星渊井口都被这股充满古老力量的诅咒所笼罩。</p><p>原本正在与巨龙身体疯狂分离的灵质，像是被无数条无形的坚韧绳索紧紧捆绑住，强行往回拉扯。</p><p>巨龙自己，包括整个星渊井口的物品和人，都沾染上绑定诅咒。</p><p>巨龙被绑定于自己，巴德被绑定于大地。至于散落四周的物件物品，则在等待82年后，砾石镇的盗墓者前来触发诅咒，绑定于镇民。</p><p>「无限机兵」内部！</p><p>杨帝迅速感知到，自己与机兵的联系重新构建了起来。</p><p>一条十环级别的巨龙，其在生死存亡关头激发出的最强大诅咒，已经摸到了“类概念”的门槛边缘。</p><p>同一时刻，原初之眼发出咆哮。</p><p>「警告，世界线变动。」</p><p>祂想要回溯到对自己更有利的历史。</p><p>本条世界线，卡利斯托从来没有施下龙语诅咒，就已被不知从何而来的史莱姆秒杀。</p><p>但“绑定诅咒”已经成为机兵“灵”的一部分，也就与机兵一同，具备了超越因果律的特性。</p><p>任由天地间斗转星移，沧海桑田，机兵与杨帝都没有因为历史和未来改变，而被影响到当前状态。</p><p>“原初之眼，你太晚了……不仅机兵获得了绑定诅咒，而我，也已经记住绑定诅咒的灵能构建方法。”</p><p>以机兵的超强运算能力、极其强大的观测设备为辅助，清楚地看着卡利斯托构建诅咒，细致入微地目睹每一个细节，迅速将看到的“绑定诅咒”构建细节进行拆解、分析。</p><p>100%潜意识解析，意识圆满境界，借助机兵的类时无限计算机的算力，杨帝在不足10秒的时间内，学会了「绑定诅咒」的铭刻方法。</p><p>量变引起质变。</p><p>杨帝调动环境灵能，在自己身上疯狂堆叠「绑定诅咒」！</p><p>机兵本质是一个占比0.01%的物质壳子，再套上99.99%的附魔。继续施加多几十个、上百个附魔，已经债多不压身，几乎没啥负担。</p><p>「警告，世界线变……」</p><p>在原初之眼进行下一次历史回溯前。</p><p>杨帝已经先行一步，从被动挨打，转向主动逃窜！</p><p>时间跳跃，目的时代，四万年前，精灵圣树领地。</p>
