# 青丘白璃，橙黄赤狐

<p>阿巴被杨帝的人工呼吸救活了。</p><p>“鱼仔你四万年没见你老大，现在一见面就生死决斗？还想未经允许擅自去世？”</p><p>他疯狂揉着她脑袋，“说吧，有什么想对我说的，都说说吧。”</p><p>阿巴刚刚被人工呼吸唤醒，还有些茫然。</p><p>她半醒不醒，鱼眼费力地睁开一条缝隙，看着杨帝的眼睛：</p><p>“老大……你要记得按时喝酒，不舒服就多抽点烟，每天好好熬夜，过马路的时候别忘了玩手机，要记得多吃宵夜，不要经常吃早餐，没事多玩玩手机，不要整天看书，看书的话记得关灯，我想你了……”</p><p>她多吐了两口淤血，逐渐恢复。</p><p>“老大，你那一拳可真够劲儿……差点就真成鳕鱼堡了。”</p><p>“我并没有一拳揍你脸上。”</p><p>杨帝很严肃地纠正，“如果你注意观察，你会发现，最后一刻我的拳头先是变成手刀。然后我想到——即使是手刀，也会把你切成生鱼片。所以，我又及时改成一个爆栗，轻轻弹你额头，没想到这点程度你就抵挡不住了。”</p><p>“啊，又是一爆栗……”</p><p>阿巴有点绝望。</p><p>她修炼到圣人境界，还是被一弹指打爆。</p><p>这力量膨胀也太离谱了吧，写成无脑爽文都会被人喷战力崩。</p><p>“好啦好啦，夕阳红旅行团重新集结，你也别整天惦记着圣人果位什么的了。”</p><p>杨帝的目光从阿巴脸上移开，投向那深邃冰冷，却又充满无限可能的超空间航道网络。</p><p>目光穿透了新生航道的幽蓝光芒。</p><p>他看到更遥远的虚空，看到纠缠在其中，而他又必须去解决的因果。</p><p>他抛出了个名字：“59改呢？”</p><p>阿巴的鱼鳍微弱地抽动了一下，似乎在回忆。</p><p>片刻，她断断续续地说：</p><p>“他在一场大战中，战损很严重，核心几乎熄灭，我把他送走了，送到了四万年前的蓝星，代号是‘残星’……”</p><p>杨帝的眼神微微一动，似乎对这个安排并不意外，甚至有一丝“本该如此”的了然。</p><p>他沉默地点点头，随即问出了第二个名字。</p><p>一个在刚才那毁天灭地的碰撞中，被所有人，包括阿巴，都彻底忽略掉的存在：</p><p>“青丘白璃呢？”</p><p>这个名字像一颗投入死水的小石子。</p><p>杨帝腹中，那刚刚被强行压制的、四大邪神残留意志混合体的咆哮与诅咒，似乎因为这名字的提及而再次猛烈地翻腾了一下，传来一阵沉闷而恶毒的悸动。</p><p>阿巴的鱼眼猛地睁大了些，不再是虚弱，而是瞬间被一种巨大的惊愕和茫然占据。</p><p>她努力调动着残存的感知回忆。</p><p>疯狂回溯着在智神辛烈治被吞噬、亚空间邪神意志沸腾、直至她与杨帝初次来到“江城二中”时的每个瞬间……</p><p>没有！</p><p>完全没有！</p><p>她的气息、她的存在感、她的去向……</p><p>在抵达这个世界的那刻，就像被一只无形的手，从阿巴的记忆和感知里，彻底抹去了！</p><p>“……她……不见了……”</p><p>阿巴的鱼嘴张合了几次，却发不出完整的声音，一种源于未知的寒意，从她神魂深处蔓延开来，比境界跌落更让她感到冰冷。</p><p>就连她在达到「圣人」那一刻，都没有发现这个天大的异常。</p><p>她被干扰了认知。</p><p>能够干扰一个圣人的认知，至少得是……阿巴瞅了老大一眼。她想都不敢想。</p><p>“我……我完全没注意什么时候她消失了……”</p><p>“貌似是来到仙界后……就从未见过她……”</p><p>“不知为何……我完全遗忘了她……”</p><p>“老大，你确定你没有……”</p><p>杨帝托着阿巴的手，微微收紧了一瞬。</p><p>他的目光骤然变得锐利，穿透了眼前新生的宇宙格局。</p><p>穿透新生的超空间航道网络幽蓝的光芒，穿透了刚刚诞生的宇宙物理法则，刺向那隐藏在万古岁月、层层因果之下的深邃阴影。</p><p>他看到了。</p><p>他看到某个被精心掩盖的陷阱，看到一条悄然溜走的毒蛇。</p><p>他看到了一条披着纯白狐裘的毒蛇，它非但没有溜走，而是一直盘踞在棋盘的中央，以最无害的姿态，旁观着一切。</p><p>所谓的“消失”，不过是祂轻轻拂去了落在棋子上的灰尘，顺手抹去了所有棋手关于“灰尘”存在的记忆。</p><p>杨帝轻轻摇头，但目光仍然盯紧远方。</p><p>“我从来没有干扰过世人的认知，包括你。那么，真相就只可能存在一个——是「祂」出手了。”</p><p>杨帝曾跟阿巴讲述过「祂」。</p><p>就在这念头升起的刹那——</p><p>“嗡——！”</p><p>一种无法抗拒、无法理解的伟力降临了！</p><p>整个新生宇宙，暂停了。</p><p>刚刚重塑的浩瀚星河，连同其中奔涌的超空间能量流、正在航道中小心翼翼航行的第一艘凡人科考船，甚至那刚刚从亚空间混沌中析出、遵循新规则运转的基本粒子……</p><p>所有的一切，都在瞬间凝固。</p><p>时间，被抽走。</p><p>空间，被钉死。</p><p>因果，被冻结。</p><p>他保持着托住阿巴的姿势，阿巴眼中残留的惊愕与茫然被永恒地定格。</p><p>杨帝体内，那刚刚被强行压制下去，但仍在不甘嘶吼的四大邪神混合意志，也如同被封在琥珀里的蚊虫，咆哮的姿态凝固，声音戛然而止。</p><p>连杨帝那足以吞噬万界的思维运转，都感受到了一种前所未有的迟滞感。</p><p>绝对的寂静，绝对的静止。</p><p>在这片被按下了暂停键的宇宙画布上，一点微光，无声无息地虚空中浮现。</p><p>光芒柔和，带着一丝熟悉的、让人下意识放松警惕的暖意。</p><p>光晕流转，勾勒出一个纤细的身影。</p><p>三十六条洁白无瑕的蓬松狐尾，如同最上等的丝绸，又像是凝固的月光瀑布，在她身后优雅地铺展开来，占据了视野的全部。</p><p>每一根尾尖的毫毛都清晰可见，蕴含着难以言喻的道韵。</p><p>是青丘白璃。</p><p>她的面容依旧带着那股深入骨髓的、仿佛不谙世事的纯真与娇憨。</p><p>眼眸像含着露珠的黑葡萄，微微歪着头，嘴角噙着一缕孩童般的天真笑意。</p><p>那副模样，与杨帝和阿巴记忆中，那个总是状况百出的傻狐狸别无二致。</p><p>然而。</p><p>杨帝和阿巴心中，再无半分往日的怜惜或无奈，只有彻骨的冰寒。</p><p>祂不是伪装。</p><p>或者说，这种“傻乎乎”的状态，本身就是祂存在的一部分，是祂俯瞰众生时最自然、最本真的姿态。</p><p>如同顽童观察蚂蚁搬家，何须伪装？</p><p>……不，她身上还是有一个地方，与过往不同。这是她唯一的掩饰。</p><p>青丘白璃，不是白狐。</p><p>而是……橙黄色的赤狐。</p><p>她——祂漂浮于虚空。远望，宛若身披一席黄色的神明。</p><p>杨帝从牙缝里挤出那个渍满仇恨的词：“耶罗……”</p><p>白璃轻轻眨了眨眼，长长的睫毛扑闪着，用天真无邪的腔调，吐出足以冻结圣人的话语：</p><p>「来晚了……差点……卡点……三百。」</p>
