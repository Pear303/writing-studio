# 满身狼藉 走马

<p>哪有什么吞噬大仙、独断万古？</p><p>有的只是一个被一份劣质外卖放倒，在病痛和幻觉的漩涡里失足滑向深渊，满身狼藉，前途未卜的年轻人。</p><p>他耳朵红得发烫，身体冷得发抖，脑子里只剩下一个念头：那该死的拼优饭……</p><p>哦对，他当时吃的不只是那份外卖。</p><p>还在超商，买了个豆豉鲮鱼罐头。</p><p>不对，他买错了，不是豆豉鲮鱼，他买到的是“豆豉鲈鱼”罐头，而且看起来是临期食品，特别便宜。</p><p>鲈鱼……罐头……还有，好想喝口水……</p><p>拘留处的铁门“哐当”一声被拉开。</p><p>听到动静，他费力地抬起眼，视线依旧模糊，只能看到两个穿着制服的人影在眼前晃动。</p><p>“起来，送你去医院。”其中一人的声音像是隔着厚厚的棉花传来。</p><p>有人伸手将他架了起来，杨帝的腿软得像面条，几乎全靠对方的力气支撑。</p><p>被抬上救护车，他闻到了熟悉的消毒水味，和拘留处的霉味比起来，竟莫名让人安心了些。</p><p>医护人员迅速给他接上心电监护，冰凉的听诊器贴上胸口，在路上就做着检查。</p><p>杨帝被重新送回了医院。</p><p>这次是加了监护的病房，雪白的墙面上投着监护仪规律的绿光。</p><p>耳朵依旧烫得像要烧起来，四肢却冷得发颤，意识在清醒与昏迷的边缘反复浮沉。</p><p>看守的警察就坐在病房角落的椅子上，目光时不时扫过病床上的杨帝。</p><p>窗外的天色渐渐暗了，监护仪的滴答声成了房间里唯一的节奏。</p><p>警察皱了皱眉，起身时动作轻缓，大概是怕惊动病人。</p><p>人有三急。他看了眼沉睡的杨帝，又检查了下病房门的锁扣，想着只是去趟卫生间，一分钟就回来，不会出什么岔子。</p><p>有时候深夜会有小混混打架打个头破血流，打赢坐牢打输住院。</p><p>这时，经常就是他坐在监护室里，监视瘫在病床上的那几个小混混。他对此特别有经验。</p><p>门轻轻合上。</p><p>走廊尽头，一个穿着合身西装的身影动了。</p><p>那人戴着黑框眼镜，头发梳得一丝不苟，看起来像个普通白领。</p><p>他贴墙走来，确认四周无人后，迅速用一根细铁丝撬开了病房的门锁，闪身溜了进去。</p><p>他手里攥着一支早已准备好的针筒，里面是透明的液体，针头闪着寒光。</p><p>走到病床边，他低头看着昏迷中的杨帝，嘴唇翕动，声音压得极低，却带着咬牙切齿的狠劲：“是你杀了大仙……你毁了我们的希望……我要为大仙报仇……”</p><p>“这是你应得的……为了大仙……”</p><p>他一边念叨，一边猛地扯开杨帝手背上的输液管，将那支针筒的针头狠狠扎进了暴露在外的血管里。</p><p>高浓度的氯化钾溶液，被他毫不犹豫地全部推了进去。</p><p>几乎是注射完成的瞬间，昏迷中的杨帝猛地绷紧了身体。</p><p>他意识依旧模糊，分不清是高烧的幻觉还是真实的痛楚，只觉得心脏像是被一只无形的手狠狠攥住，骤然传来撕裂般的剧痛！</p><p>疼痛来得又快又猛，像有无数根烧红的针在同时刺穿心肌，让他忍不住蜷缩起来，喉咙里溢出一声压抑的闷哼，眼睛却依旧没能睁开。</p><p>氯化钾致死的原理，正是利用其高浓度导致心肌细胞内外的钾离子浓度急剧失衡，心脏瞬间失去正常的收缩节律，在剧烈的痉挛中停跳。</p><p>这也是某些地方执行注射死刑时会采用的方式，用这种迅速的方式终结生命。</p><p>但和此时杨帝不同，注射死刑时，还会打入麻醉剂和肌肉松弛剂，无痛死去。</p><p>那白领看着杨帝痛苦蜷缩的身体，脸上露出扭曲的快意，他迅速拔掉针头，将针筒塞进西装内袋，转身就往门口跑，像做贼一样消失在走廊尽头。</p><p>几乎是他离开的同一秒，监护仪突然发出刺耳的警报声！</p><p>原本规律跳动的曲线骤然变成一条直线，尖锐的“嘀——”声划破了病房的寂静。</p><p>刚从卫生间回来的警察听到声音，心里咯噔一下，猛地推开病房门，看到的就是心电监护仪上那条刺目的直线，以及病床上身体已经开始僵硬的杨帝。</p><p>“不好！”他大吼一声，扑过去按下呼叫铃。</p><p>病房里瞬间乱了起来，医生护士匆匆涌入，急救的声音，仪器的警报声混在一起。</p><p>而那个刚刚经历过杀戮的年轻人，此刻正躺在病床上，在心脏骤停剧痛中，向着更深的黑暗坠去。</p><p>就这么死了吗？</p><p>梦中的光怪陆离，意气风发，红尘离恨，白杨大帝……卷王室友，钓鱼佬师，原初的眼，归墟仙帝……</p><p>往事已成幻梦。或许它们本身就是泡影。</p><p>心脏停跳，器官衰竭。</p><p>杨帝仿佛听到，周围有人在大喊大叫，胸膛似乎被什么东西有规律的按压，都快把他肋骨压断了。</p><p>混乱的意识碎片中，一个清晰的知识点突兀地冒了出来。</p><p>CPR，心肺复苏术针对心脏骤停患者的紧急抢救措施，通过胸外按压维持最低限度的血液循环，为脑和其他重要器官提供少量含氧血液，同时通过人工呼吸（此步骤似乎省略了，遗憾）维持通气……</p><p>目的是争取时间，等待高级生命支持或自主循环恢复……</p><p>心脏停跳后果严重，会导致全身组织器官缺血缺氧。</p><p>脑细胞对缺氧最为敏感，4-6分钟即可发生不可逆损伤……</p><p>心肌细胞也会因缺氧而坏死……</p><p>他感觉自己在飞速下坠，坠向一片冰冷、死寂的黑暗。</p><p>那些宏大的梦境显得如此遥远和可笑，如同阳光下的肥皂泡，浮生一梦罢。</p><p>‘这就是走马灯吗？’</p><p>他麻木地想。</p><p>‘回顾一生？可我的一生……好像也没什么值得回顾的……一份劣质外卖，一个装有「鲈鱼」的「罐头」，一场高烧，神棍，失控……然后结束了？真踏马憋屈……’</p><p>‘结束了……’</p><p>他放弃了挣扎，意识向着那片终极的黑暗沉沦下去，准备迎接永恒的寂静。</p><p>胸口的按压似乎也变得遥远，疼痛仿佛不再是自己的。</p><p>然而，就在这意识即将彻底消散，即将沉入虚无深渊的临界点——</p><p>一个声音，直接凿穿了他混沌的思绪，在眼耳鼻舌身、思想之意识、自我之末那、本体阿赖耶的最深处轰然炸响：</p><p>「综合抗性+1」</p><p>但不是普通的「1」。</p><p>阿列夫一。</p>
