# 再探旧校区3

<p>心魔一去，胡彦卓的话匣子像是被弹簧弹开，噼里啪啦收不住闸。</p><p>“杨帝老弟，我又想到有个都市传说。</p><p>“这座宿舍楼千禧年前后，出过两起坠楼案，每个死者都从同一扇窗户跃下。</p><p>“校方用水泥封死了那扇窗，但每月月底，四楼走廊都会传来湿漉漉的脚步声。</p><p>“之后就有大神在论坛揭秘了：四楼饮水机导水槽堵塞，每个月初才会去清理，月底那几天就会有水渗出来，沿着走廊的缝隙流淌。</p><p>“晚上人走在上面，就会有湿漉漉的脚步声——这就是该都市传说的真相。”</p><p>杨帝忍不住说：“但有两个人在同一扇窗户坠楼是真的吧？”</p><p>胡彦卓点点头，并没有否认。</p><p>他说：“坠楼是真的，而有人走过时发出踩水声也是真的。这是两件不一样的事情，但因为我们人脑具有抽象世界的能力，所以我们将这两件事，强行划上了因果关联，这才会有那么多谣传的都市传说。”</p><p>他踢飞一块风化的水泥渣。</p><p>水泥渣砸到围栏上，碎成渣渣。</p><p>“我们看到石头碰撞，创造出‘力’的概念；我们看见昼夜交替，创造出‘时间’这个容器来装载春秋轮回。这就是我们区别于动物的天赋。”</p><p>杨帝点点头。</p><p>目前他还能理解胡大哥所说的话。</p><p>“但有时，我们面对无法解释的现象，比如突然出现的红气球，忽然腾在空中的电缆，每个月月底走廊上踏踏踏的踩水声。</p><p>“我们会不自觉地把抽象能力，用在构建因果链上。</p><p>“我们会说‘这是诅咒’，‘这是鬼魂作祟’，其实不过是把巧合的碎片强行拼贴成故事。”</p><p>杨帝：“胡哥，你说话像哲学家写散文。”</p><p>“哈哈哈，在我得到过的评价里，你这个算是最特别的一个。”</p><p>杨帝和胡彦卓找到了天台上的门。</p><p>这扇不锈钢防盗门也是被锁链锁上的，但这条锁链同样被“摸金校尉”暴力拆开。</p><p>门后是通往下方的水泥楼梯，楼梯通往深深的黑暗。</p><p>冷风似是冰霜巨龙吐出的极寒风暴，扑面而来，将杨帝包裹在阴冷。</p><p>“这种钢筋水泥下料很足的建筑物，只要紧闭门窗，保温性能都挺好。没人住的时候，里边是挺很冰凉的。”</p><p>胡彦卓因此解释道，走在前面打头阵。</p><p>楼梯过道有楼牌标识。这里是旧艺术楼，总共5层，第5层是雕塑室和美术室。</p><p>他们只下了一层楼梯，然后，天知道为什么——通往4楼的楼梯被一大堆杂物堵死，课桌，板凳。</p><p>像是丧尸危机爆发时，人们尽他们所能，用一切杂物封死楼梯口。</p><p>“当年旧校区探险的‘摸金校尉’太多，堵门堵窗都不管用，干脆连楼道也封死。”</p><p>胡彦卓给出自己的猜想。</p><p>这个猜想，同时也是学校论坛最主流的说法。</p><p>杨帝提议：“那要不，先探索一下这层楼，看看里面有什么东西，比如说……那个三条曲线的漩涡图案？”</p><p>“行，陪你找找你迷上的传说。”胡彦卓笑着拍他肩膀。</p><p>胡彦卓现在看起来心情很不错。</p><p>他拍了拍杨帝的肩膀，两人一起推开雕塑教室的铁门，霉味像块浸满雨水的帆布扑面而来。</p><p>门后的空间，只有手电筒光束切割着黑暗。</p><p>杨帝的鞋底碾碎了地上散落的石膏碎屑，那些惨白的粉末在微光中悬浮。</p><p>所有石膏像都面朝西墙。</p><p>它们凝固的面容在手电筒光束里忽明忽暗，像是被无形的丝线操纵着脖颈。</p><p>石膏雕塑不会动。肉眼感觉它们动了，不过是因为光影变幻，而产生的视觉错误。</p><p>杨帝数到第二十个石膏雕像，顿住脚步。</p><p>那个位于角落的雕像，胸前漩涡状的纹路正对着他。</p><p>“胡哥，这个雕像……”</p><p>杨帝的声音哽在喉咙里。</p><p>漩涡纹路与耶罗符印上的浮雕如出一辙，只是更大、更扭曲，仿佛有某种力量在石膏内部挣扎着要破茧而出。</p><p>潜意识中，倏地弹出了「精神+1」。</p><p>再眨眨眼看过去，一切正常。</p><p>漩涡消失了。石膏只是石膏，只剩坑洼的痕迹。</p><p>那里原本是有漩涡的，但后来被人破坏了。</p><p>胡彦卓走了过来，对雕塑瞅了两眼，用登山杖戳了戳雕像底座。</p><p>“不及格的作品，瞧瞧这比例，脖子比脑袋还粗，下巴还分裂出这么多条触手，不知道的人还以为是南洋菩萨。看落款，2013年，一个叫‘陈昭’的人。估计是这艺术生把失恋情绪刻进去了。”</p><p>杨帝顺着胡彦卓的话望去。</p><p>确实，那个石膏雕像的面容异常模糊，仿佛是在创作过程中，被匆忙或是烦躁地处理过。</p><p>五官的轮廓几乎难以辨认，除非是毕加索那种级别亲自刻出来的，否则完全没有一丁点艺术价值。</p><p>如果是艺术系毕业生雕刻的，那就完全没有符号价值了。</p><p>不过，杨帝还是选择将这幅石膏的脸拍了下来。</p><p>“胡哥，之前我跟你说的那些什么图案你是在哪见到过的？”</p><p>杨帝又掏出那枚耶罗符印。</p><p>“你一直带着这块铁饼啊。”</p><p>胡彦卓捏住下巴思索片刻。</p><p>“因为时间有些久远，我也可能记不太清了，先让我想想……应该就是艺术楼这边，因为当时我觉得这图案挺艺术的。具体应该是某些角落，我记得在一些很阴暗的角落能看到。”</p><p>“阴暗的角落……你当时怎么发现的？”</p><p>“好奇呗。”</p><p>胡彦卓笑笑，“如果你跑酷跑多了，你也会在居民楼屋顶上，发现各式各样的小玩意和小秘密，有时是孩子的风筝，有时是旧收音机，或者也有涂鸦，就像这个漩涡。”</p><p>他指了指杨帝手里的耶罗符印。</p><p>簌簌声恰在此时响起。</p><p>很微弱，很遥远，在空旷的寂静里，只有听觉以及精神大幅强化过的杨帝听见了。</p><p>在门外远处。</p><p>胡彦卓还没反应过来，就被他按熄了手电。</p><p>黑暗像粘稠的沥青包裹着两人，只听见彼此压抑的呼吸。</p><p>“嘘。”杨帝捂住老大哥的嘴。</p><p>那沙沙的声音，像是有人拖着浸水的麻袋，在瓷砖上摩擦，水珠坠地的嘀嗒声，夹杂着指甲刮擦墙面的锐响。</p><p>杨帝的太阳穴突突直跳，耳膜随着渐近的沙沙声共振。</p><p>现在，胡彦卓也才终于听见了。</p><p>他摸到胡彦卓的手腕，在对方掌心快速划写：“门外，右，二十米。”</p><p>“你在写什么？我看不懂。”胡彦卓低声说。</p><p>杨帝只好也开口说话：“我是说外面有人，冲！”</p><p>两人同时冲出教室，雪亮的手电光束如同出鞘的利剑劈开黑暗。</p><p>那地方没有人。只有只受惊的狸花猫。</p><p>这只猫特别漂亮，毛发黑白相间。</p><p>被惊动的哈基米弓起脊背，金瞳在强光中缩成两道竖线。</p><p>它脚下踩着鼓胀的黑色塑料袋，旁边倒着半块被爪子磨出沟壑的松木板。</p><p>所谓的怪声，不过是猫爪挠木、踩响湿塑料袋的动静。</p><p>“吔！”哈基米炸着毛，窜向走廊尽头。</p><p>手电光追着那道灰影，照出墙角堆叠的石膏像后面，一段向下的旋转铁梯。</p><p>“居然把清洁工具间改造成了应急通道，这设计倒是……艺术。”</p><p>“正常，毕竟是艺术楼嘛。”</p>
