# 新的战争开始了

<p>自从S+15级的规则怪谈领域“变化之海·迷宫回廊”被白杨大帝破除，已经过去38个千年。</p><p>一切美好皆会蒙尘。</p><p>群星的光芒，在人类帝国疆域的边缘，显得如此疲惫而稀薄。</p><p>曾经照耀银河的“帝尊”荣光，在漫长时光的冲刷与刻意的遗忘下，已如风中残烛。</p><p>仅存于少数被斥为守旧者、狂热分子的古老战团、失落机械教派，以及那些在帝国阴影下艰难传承的隐秘结社心中。</p><p>银河已非昔日的蓝星摇篮。</p><p>蓝星亦非人类荣耀的故都。</p><p>人类帝国，这个在帝尊亲手奠定的基石上建立、又在其离开后逐渐扭曲膨胀的庞然巨物，其疆域横跨亿万星辰，其人口以兆亿计。</p><p>然而，辉煌的表象之下，是深入骨髓的腐朽与麻木。</p><p>太多的人，早已忘却了那场撕裂星河、将人类从诡异爪牙下拯救出来的终极圣战的起源。</p><p>忘却了那名为“帝尊”的存在，曾是这片黑暗宇宙中唯一、也是最后的光。</p><p>他们容易欺骗，很好煽动。他们的力量不容小觑，他们的智慧不足挂齿。</p><p>他们自愿投身混沌，成为恶的爪牙。</p><p>他们认为，自己正在践行帝尊教诲的正义。</p><p>战争从未真正结束。新的战争开始。</p><p>更残酷，更黑暗，更恐怖。</p><p>在现实宇宙的帷幕之外，在被称为“亚空间”的维度深处，一场超越了凡人理解极限的永恒圣战，已持续了接近四十个千年。</p><p>黑暗深空之下，唯有忠诚。</p><p>交战的一方，是那尊号响彻过去与未来的存在——万古白杨帝尊！</p><p>祂的身姿已非蓝星旧影，而是化作横亘于现实与虚幻之间的伟岸概念，是秩序与存续的终极化身，化作燃烧着冰冷理性与不灭意志的恒星长城。</p><p>祂的力量，早已超越了物理法则的束缚，举手投足间，星河生灭，因果重塑。</p><p>而祂的敌人，是自那无边无际的诡异本源中孕育而生的、最深沉、最扭曲的四个噩梦具现，是腐化与毁灭的至高邪神：</p><p>原初纯洁命神，那唭枯，静止的瘟疫，腐化的具象。</p><p>至道勇毅血神，哥达内，永不餍足的战争引擎。</p><p>无瑕慧悟智神，辛烈治，知识的癌变。</p><p>义胆赤心爱神，沙历士，堕落扭曲的欢愉。</p><p>四大邪神窃取人类美德之名，却将其内核彻底腐化、扭曲为毁灭的养料。</p><p>祂们的力量源自于银河间弥漫的绝望、疯狂、愚昧与放纵，源自于那些早已忘却帝尊，忘却人类在诡异时代挣扎求存的荣光，转而投身于鼠辈般短视私利与感官刺激的堕落灵魂。</p><p>将近四十个千年的血战，现实宇宙的疆域在邪神低语的侵蚀下节节败退。</p><p>无数星河在无声无息中被腐化、吞噬，化作邪神领域延伸的肿瘤。</p><p>帝尊的伟力足以与四神抗衡，甚至压制。</p><p>但邪神的力量根植于生灵内心的阴暗面。只要银河间仍有堕落，祂们便近乎不死不灭。</p><p>战局，陷入了旷日持久，令人绝望的僵持。</p><p>僵局，催生了最恶毒的毒计。</p><p>在亚空间那无法用时间衡量的混沌核心，四大邪神的意志罕见地达成了短暂的、充满恶意的共鸣。</p><p>一个跨越时间长河的绝杀之策，被编织成型——于过去横击未来敌。</p><p>万古白杨帝尊，是蓝星人类在宇宙生成的恶意中淬炼出的锋刃。</p><p>若能在过去，在那柄锋刃尚未铸成、甚至尚未有雏形之时，便将其彻底掐灭于萌芽状态……</p><p>那么，名为“帝尊”的存在，其诞生的根基将被彻底抹除。</p><p>祂将从因果链上被修剪掉，如同从未存在。</p><p>为此，四大邪神不惜动用本源之力，撬动了时间与因果的脆弱法则。</p><p>祂们燃烧着从亿万堕落灵魂中榨取的绝望能量，凝聚出一道汇集四神意志精华，足以扭曲现实规则的神通：</p><p>「怪谈系统」</p><p>刹那间，时间的长河掀起了滔天巨浪！</p><p>因果的织线被强行扭曲、打结！</p><p>无数邪神信徒、神选，在得到“怪谈系统”之后，纷纷化身诡异，降临至38个千年前的蓝星。</p><p>他们会展开“怪谈领域”规避因果律惩罚，同时利用自身领域的各项规则，收割蓝星2k纪元最美好的人类品质——</p><p>智慧，勇气，善良，纯洁。</p><p>分别献祭给无瑕慧悟智神，至道勇毅血神，义胆赤心爱神，原初纯洁命神。</p><p>高尚的人会为保护懦弱的人而死。</p><p>卑劣之徒躲在伟大者背后，安然无恙。</p><p>能被感化、被激励、最终挺身而出的卑劣者，不足百分之一。</p><p>绝大多数幸存者，在目睹高尚者的牺牲后，非但没有被感召，反而更加笃信自私与怯懦才是生存之道。</p><p>蓝星人类的整体素质，将不断下跌。</p><p>这是阳谋。</p><p>勇气蒙尘，智慧扭曲，善良凋零，纯洁污染。整个文明的精神底色，滑向深渊。</p><p>邪神的意志在时间罅隙中尖啸，充满了毁灭的狂喜。</p><p>祂们仿佛已经看到，横亘在祂们与人类之间的伟岸身影，正因根基的动摇而开始变得模糊、虚幻……</p><p>火上浇油，暑中送炭的是——</p><p>帝尊麾下最强大的战帅之一，被誉为“猩红之王”、拥有洞穿亚空间迷雾之眼的攻壳机动队原体，马格努斯，叛变了。</p><p>当时正值战况激烈之刻。</p><p>那场战役史称螺旋裂谷之战。</p><p>马格努斯化身神通广大的贵妇人，一通电话打到帝尊那儿。</p><p>少了一枚铁钉，掉了一只马掌；掉了一只马掌，失去一匹战马；失去一匹战马，败了一场战役；败了一场战役，毁了一个王朝……</p><p>一通电话，让人类帝国全盘皆输。</p><p>“马格努斯。是谁，准你在战事要紧之时，擅接通讯？”</p><p>“我……我不……”</p><p>“汝违抗军令，致使战局倾覆，将士殒命。”</p><p>“我……”</p><p>“即日起，剥夺汝之战帅权柄，放逐汝与旗下军团于恐惧之眼边缘。无召，不得归返……”</p><p>“……”</p><p>“可悲的马格努斯……你看到了吗？祂的‘公正’是多么的冰冷与不近人情？你毕生的忠诚与功绩，抵不过一次并非你本意的‘失误’……”</p><p>“……”</p><p>“你的智慧本应得到更好的赏识，而非在放逐中凋零……”</p><p>“……”</p><p>“加入我们吧……辛烈治理解你对知识的渴求，哥达内欣赏你隐藏的怒火，那唭枯能抚平你的伤痛，沙历士能赐予你应得的荣耀……我们，才懂得你的价值……”</p><p>“……”</p><p>“让我们……一起终结那个冷酷无情的‘伪帝’时代……”</p><p>“……”</p><p>很久以前，帝尊失去了一位强大的攻壳机动队原体。</p><p>四大邪神则收获了一柄饱含怨恨、力量强大、并且深知帝尊战法与弱点的猩红利刃。</p><p>这就是命数吗？</p><p>帝尊沉默地坐在钢铁王座上。</p><p>自从38个千年前，她已再没见到过杨帝。</p>
