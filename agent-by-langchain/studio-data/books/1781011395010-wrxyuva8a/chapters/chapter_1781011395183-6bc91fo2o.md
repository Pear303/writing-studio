# 闪通玉盘·扇区1

<p>（……）</p><p>（再更一章，但只更一章哦(ㅇㅅㅇ❀)）</p><p>（才不是为了你们看爽(；｀ヘ´)再强调一遍，我是怕打卡连更断了）</p><p>……</p><p>公司那台宝贝咖啡机，又一次散发出它仿佛毛发烧焦了的标志性香气。</p><p>我捏着马克杯凑近，深吸一口这提神醒脑的工业气息。</p><p>旁边，保洁部的老张调侃：“老虚，闻出来没？今天这焦香里也藏着高级蛋白质的芬芳，绝对是加餐了。”</p><p>我捂着嘴，有些干呕。</p><p>片刻才缓过来，然后在咖啡机……旁的饮水机，装了杯优质白开水。</p><p>权当给这被代码榨干的身躯，注入一点聊胜于无的冷却剂。</p><p>咖啡？不可能喝公司咖啡的，我知道那些蛋白质烧焦气味其实是什么东西——蟑螂。</p><p>桂虚，正是在下。</p><p>资深码农，人送外号“老虚”——不是那个擅长把一切美好事物毁掉的老家伙，而是因为我纯粹是身子骨虚得跟风里柳条似的，同事们叫顺了口。</p><p>这不，阴伏流煞（Influenza，流感）把我精准狙击在了工位上。</p><p>咳得撕心裂肺，感觉下一秒就能把键盘咳成散装的。</p><p>我硬撑着敲完几行面目全非的代码，眼前发黑，预感可能会猝死。</p><p>赶紧在代码页的某个角落重置好某个参数，灰溜溜回家。</p><p>不过毕竟是外企，福利好，老板心善，痛快利落地答应请假三天。</p><p>“但是，小桂啊，最近由于西伯利亚寒流、诺尔尼诺效应、大萧条等影响，这三天的工资，公司也许结不来。你知道的，最近我们成立的‘效率部’……”</p><p>“豪德。”当时我口头是这么回答。</p><p>但内心是另一回事。</p><p>不是，大萧条是一百年前的事情了呀！而且是远在大洋彼岸的破事。</p><p>还有什么西伯利亚寒流，但现在是夏天……找理由别那么敷衍好嘛……</p><p>医院。</p><p>医生大爷推了推老花镜，龙飞凤舞开出一串药名。</p><p>我捏着单子去药房。药单上，完全看不懂是哪个星球的文字。</p><p>药品拿到手一看，我差点当场表演个灵魂出窍——康复新液。</p><p>带着点神秘土腥味的棕褐色瓶子，标签上赫然印着“美洲大蠊干燥提取物”。</p><p>大蠊！我脑子里瞬间闪过公司咖啡机里那些英勇赴汤蹈火的“蛋白质加餐”前辈们。</p><p>就连自己也中过招……</p><p>蟑螂喜欢阴暗潮湿的地方，它们晚上发现咖啡机这片风水宝地，便一家18口全搬进去。</p><p>白天，咖啡机高强度运转，就把住在里面的小强全部烤焦了。</p><p>“行啊，里外合围是吧？公司咖啡机里是你们家亲戚，现在还得喝你们家祖宗熬的汤？真就阴魂不散，非得让我从物理到精神都跟你们深度绑定？”</p><p>病假第三天。</p><p>感觉魂魄刚被药水粘回身体里七七八八，工作群里就炸了锅。</p><p>一条紧急会议通知像催命符一样跳出来。</p><p>心里咯噔一下。这节奏，不妙。</p><p>会议室里气氛凝重得像冻透的铅块。</p><p>亚太区那位头发梳得苍蝇站上去都得打滑的副总裁，隔着屏幕，操一口掺了咖喱粉的英语，叽里咕噜地宣布着全球“战略优化”的冰冷决定。</p><p>翻译官的声音毫无波澜，却字字如冰锥：“部分岗位，将不可避免地被裁撤。”</p><p>桂虚，我的名字，赫然在列。</p><p>咳嗽憋在喉咙里，憋得胸口生疼，耳朵里嗡嗡作响。</p><p>其实早就预料到了，毕竟今年我都35了。</p><p>总监，那位永远妆容精致、笑容像用熨斗熨过一样平整的Lisa王，踩着细高跟“哒哒”地走过来。</p><p>她手里捏着一张薄纸、一沓厚重的文件，脸上挂着标准的、经过ISO9001认证的同情微笑。</p><p>“桂先生，公司非常理解，也非常感谢您多年的贡献。现在呢，给您两个方案，充分体现公司的人文关怀……”</p><p>她首先抽出那张薄纸。</p><p>方案A：就地裁退，N+3赔偿，干净利落，一拍两散，从此老死不相往来。</p><p>最后是那沓有几百页的超厚文件。</p><p>方案B：一个金光闪闪的大饼——全家技术移民，公司负责搞定绿卡！阿米利卡总部，技术核心岗位！</p><p>Lisa王的声音陡然拔高，充满了诱人的蛊惑，“这可是千载难逢的机会！真正的Global Career Path！想想加州的阳光，想想孩子的未来！公司对核心人才，向来是不惜代价、长远投入的！”</p><p>她手指轻轻点在那行“全家绿卡”的字样上，像点着一张通往应许之地的船票。</p><p>“核心人才”？这个词像根羽毛，搔得我心尖痒痒的。</p><p>那些通宵达旦、熬得眼冒金星的日子，那些被产品经理反复蹂躏的需求，在这一刻都镀上了一层悲壮而崇高的金边。</p><p>N+3？眼前这点钱，在飞涨的物价和三十五岁的年龄门槛前，显得那么单薄可怜。</p><p>良心啊！谁说资本家都是吸血鬼？看看，这才是负责任的大外企！有情有义有担当。</p><p>这选择题还用犹豫吗？傻子才选原地裁员。</p><p>“我选B！”我的声音斩钉截铁，甚至带着点慷慨激昂，“感谢公司！感谢Global vision！”</p><p>接下来的日子快得像按了快进键。</p><p>签证、体检、打包、告别……像一场仓促而亢奋的梦。</p><p>妻子眼中闪烁着对“新大陆”的期冀光芒，孩子懵懂地兴奋着。</p><p>我像一个即将奔赴光明前程的骑士，把离别宴上同事略带复杂的眼神，都解读成了羡慕和祝福。</p><p>要现在的我回到高考，阅读理解一定能拿零分。</p><p>老张最后想劝我一次。</p><p>“命运的一切馈赠，早已暗中标上价码。”</p><p>“老张，你叽里咕噜瞎扯什么文艺呢。”</p><p>“你还年轻，对世上太多问题的看法过于简单。我觉得这裁员，有鬼。”</p><p>老张在这家外企的保洁干了二十年，年近六十岁，算是老前辈。</p><p>老张继续说：“你们这代人，对阿米利卡的印象特别好，我也不明白为啥。我这人嘛都没啥文化，但知道伏尔泰对大清的赞美，本质是借他者言说自我，完成对欧罗巴尚村不足之处的批判与理论建构。但是，不会真有人觉得，大清皇帝真的以儒家理性治国、官僚体系通过科举制选贤与能、社会以伦理道德维系秩序吧？不会真有现代人拜读了伏尔泰的著作后，真心认为大清比欧罗巴先进得多吧？不会吧不会吧？”</p><p>“……老张，到了加州我会想你的。”</p><p>“说半天你一句话都没听进去。对了老虚，新的劳动合同，移民协议什么的，你都完整看过一遍了吗？”</p><p>我醒过来。</p><p>并没有什么离别宴。只是场梦。</p><p>梦中的老张在劝说我不要去……应该是故土情结作祟了吧。</p><p>不过，劳动合同、移民协议什么的，我确实没完整看完……</p><p>飞机轰鸣着降落在天使之城国际机场。</p><p>舷窗外，加州阳光果然名不虚传，明晃晃、白炽炽地泼洒下来，照得一切都锐利而崭新。</p><p>空气里弥漫着一种陌生的、混合着尾气，和某种干燥植物的味道。</p><p>哇，香甜的空气，有些让人呃，上瘾？</p><p>我们拖着大包小包的行李，像笨拙的候鸟终于抵达了传说中的温暖彼岸，心中充满对未来的无限憧憬。</p><p>总算，尘埃落定了。</p><p>安顿下来第三天，公寓里还弥漫着新家具的甲醛味和纸箱的尘土气。</p><p>时差像块湿透的毛巾缠在脑袋，昏沉沉的。</p><p>手机响起来，是个陌生的本地号码。</p><p>（老狐提醒一句：流感可不是感冒，感冒扛一扛就能过去了，但流感病毒引起的症状是要人命的！）</p>
