# 附魔

<p>伊芙目光在锻锤和熔炉之间来回移动，似乎在思索着其中灵能运作的原理。</p><p>熔炉的火光在她瞳孔中跳跃，将那些常人不可见的灵能轨迹映照得纤毫毕现。</p><p>千年岁月赋予的灵视能力，让她能清晰捕捉到每次锤击时爆发的细微灵光。</p><p>偶尔微微皱眉，又是眉头舒展。</p><p>她在现场反推奥拓锻钢的原理！</p><p>“那柄锻锤，那座熔炉，都被施加超过五个附魔效果。而目前我所能确定的，就有三个。”</p><p>伊芙讲解，在场能听懂之人，大概也就失忆传奇法师·杨帝。</p><p>“看那柄锻锤的锤头。”</p><p>伊芙指着奥拓手中翻飞的工具，“内部至少镌刻了三种基础符文。”</p><p>她指尖在空中勾画出螺旋纹路：“首先是震击附魔。每次锤击都会引发灵能共振，相当于用上千根肉眼看不见的钢针同时刺入金属内部。”</p><p>她画了第二个放射性纹路：“其次是净化附魔。注意看飞溅的火星，暗红色碎屑其实是金属杂质。当震击符文破坏杂质与精钢的结合后，净化符文会像磁铁吸附铁屑般将它们扯出。”</p><p>杨帝眯起眼睛，果然发现，火星中混杂着细小的暗斑。</p><p>然而，这些被灵能包裹的杂质还未落地，就被熔炉侧面突然喷出的蓝色火舌卷走。</p><p>“那是第三个，‘引燃附魔’在发挥作用，将杂质作为燃料二次燃烧。”</p><p>一柄锤子，环环相扣，确是一柄好锻锤！</p><p>瑞弗维尔：“杨帝，你听懂了吗？”</p><p>“听懂了，也不算难吧？四环五环级别。”</p><p>“……看起来，这样一柄锤子很贵。”</p><p>确实。有这样一柄锤子，就算个人小作坊搞不了大规模工业化生产，但也能独自锻出相当于地球百炼钢、乌兹钢性能的钢材。</p><p>熟练者，甚至能炼出HRB400E高强度螺纹钢水准的钢材。</p><p>这要是放地球，高低得封个“炼钢仙人”的称号。</p><p>中世纪铁匠果然有钱。</p><p>此时，奥拓将已经初步锻造的撬棍放入熔炉之中。</p><p>那熔炉的炉壁上，同样刻满符文。</p><p>当撬棍进入熔炉，符文瞬间亮起，与炉火相互交织，形成一片绚丽而诡异的光影。</p><p>伊芙目光转向吞吐烈焰的熔炉核心。</p><p>“炎爆符文、优质木炭提供基础热源，但真正精妙的是，外层十几道嵌套的聚能环。”</p><p>说起聚能环，杨帝总会下意识想到电池。</p><p>这是地球的习惯，很难改。</p><p>“这些嵌套的环形法阵，会像透镜聚焦阳光那样，把游离的火系灵能汇聚成高温流。用附魔的迭加效应，取代复杂工艺，这就是矮人工匠的智慧，身残志坚！”伊芙发出种族主义的赞美。</p><p>熔炉内，短暂达到高炉的温度。</p><p>奥拓控制风箱，调节炉内温度和灵能环境，看准时机，再次拿起那把附魔锻锤，将撬棍从熔炉中迅速夹出！</p><p>他将其放在铁砧之上，又是“钉钉钉”一阵密有力的锤击声。</p><p>钢坯在奥拓的手下不断地变换着形状，逐渐变得更加坚韧和修长。</p><p>并慢慢拉长成撬棍的形状。</p><p>“差不多了，接下来就是淬火这关键一步。”奥拓说着，将撬棍浸入一旁装满特殊液体的大桶之中。</p><p>瞬间，桶内液体沸腾起来，蒸汽弥漫，伴随着一阵“滋滋”的声响。</p><p>待蒸汽散去，将撬棍取出，此时的撬棍已然焕然一新，表面闪烁金属光泽！</p><p>这可以说是镇里最好的撬棍了。</p><p>但在接手前，杨帝看向大桶内，还冒着蒸汽和泡的可疑淡绿色液体。</p><p>“哦这个呀，这个是草史莱姆的榨取液，用来淬火特别好用。”奥拓说。</p><p>忒好用！比热容适中，既不会像水在接触高温金属时瞬间剧烈汽化，导致撬棍表面因局部过热、过冷，产生应力集中而出现裂纹；也不会使金属降温过缓，无法快速形成理想的金相组织。</p><p>伊芙脸色变得难看。</p><p>瑞弗维尔赶紧拉着她走出铁匠铺：“亲爱的伊娃哦……眼不见心不烦，你就忘了刚刚听到的……”</p><p>二人离开了室内，到外头院子去。</p><p>奥拓不明白那二人发生了啥。</p><p>他转头对杨帝示意：“接下来，为这根撬棍附魔吧。你大概需要哪些方面的附魔？”</p><p>奥拓列举了一遍可以选择的附魔条目。</p><p>杨帝思索片刻，从中选择：“锋利、耐久以及击退。”</p><p>“事先说好，我只能尽量选择你倾向的附魔条目，但具体能否随机到这些项目，附魔等级是高是低，就不是我所能决定的了。”</p><p>“我没问题。”</p><p>奥拓便领着杨帝朝附魔室走去。</p><p>四周一圈书架，上面摆满了各种散发着微光的书籍，书页上的符文仿佛有生命一般，时而闪烁跳跃。</p><p>屋子中间，矗立着一个底部漆黑如墨、上部呈澄澈蓝晶色的台子，正是附魔台。</p><p>蓝晶部分隐隐流动着灵能的光辉，与周围的神秘氛围相得益彰。</p><p>“黑色基底是黑曜石材质，蓝晶部分则是金刚石——这样一座附魔台，价值占了整件铁匠铺的25%！”</p><p>杨帝倒吸冷气，这可真是贵。</p><p>譬如显卡虽小，却也占了主机价格的大头。</p><p>铁匠铺虽大，但“附魔台”也是相当于“显卡”的高精尖设备，价格高不无道理。</p><p>奥拓轻轻将撬棍放置在附魔台上，那蓝晶色的台面像是感受到了撬棍的存在，光芒闪烁得更为强烈。</p><p>灵能的光辉如水流淌，将撬棍包裹。</p><p>奥拓自身不会使用法术。但“附魔台”作为高精尖设备，其出离昂贵的一个原因，就在于它能自行存储、转化灵能，提供傻瓜式附魔操作。</p><p>唯二的缺点，一个是昂贵，另一个就是随机性。</p><p>“附魔台的随机性，根源在于它所汲取的灵能太过驳杂。周围书架上的书籍，每本都承载不同的灵能符文。当附魔台启动时，它会不加区分地一股脑儿读取书中的灵能符文。”</p><p>“灵能符文？又是什么？”杨帝没听伊芙说过这个概念，想必是附魔领域的专业术语。</p><p>奥拓沉吟片刻，通俗地解释：“高贵的法师都能通过咏唱来调整精神，然后以精神操控灵能嘛。</p><p>“符文，就类似一种物质性的‘精神’，能够让灵能按照规定的模式运转。</p><p>“周围的书架中，蕴藏了数千种最基础的符文结构，能确保足够的随机性。”</p><p>杨帝：“为什么要随机性？”</p><p>“因为不同工具，对附魔接受的程度不同。比如，杀手兔给自己的「速度」附魔，就不适用于人类，这是因为人和兔子的生理结构，灵能运转模式，都大相径庭。”</p><p>杨帝深有体会。</p><p>他尝试把杀手兔的「速度」附魔原封不动移植到自己身上。</p><p>结果全身大出血，五脏六腑差点炸烂。</p><p>不同符文和附魔，彼此之间本就有着各自倾向，好比一群性格迥异的人强行聚在一处。</p><p>每一种附魔都想占据主导，按照自己的方式去塑造这根撬棍的属性。</p><p>但附魔台可没有足够的智慧去协调它们，只能任由这场混乱的博弈展开。</p><p>它们经过‘竞标’，物竞天择出适合此工具的“最适配附魔”。</p>
