# 数值怪的无限可能

<p>阿巴虽是条鲈鱼但仍然炸了毛：“怎么连你也信起了老大那一套邪门学说！而且，你确定把老大剁碎成这么小份，他真的还能活着吗？”</p><p>「所以我认为，杨帝阁下只有0.014%的概率存活。」</p><p>59改重估了一切价值，终于得出此结论。</p><p>他话也不敢说很满。</p><p>就在所有大能都准备收回神念，或叹息、或冷笑、或思索后续格局之际——</p><p>那死寂、灰暗的光茧核心，那片杨帝彻底“溶解”的绝对虚无之处，毫无征兆地，亮起了一点微光。</p><p>在光茧核心的绝对虚无中，一个比较难、但终归是可以用传统物理尺度衡量的“点”，骤然凝聚成形。</p><p>一颗“灵界普朗克尺度”的杨帝碎片。</p><p>它小到难以用此界法则定义，却在混沌中释放出极其微弱的波动，像是宇宙诞生之初的第一缕弦振动。</p><p>它是凭空涌现的。</p><p>但没有人知道，杨帝碎片是否曾经比微观极限还要“碎”。</p><p>“碎”到世界本身也无法理解，只能将其四舍五入、看作是“零”。</p><p>紧接着，第二颗、第三颗普朗克级别的碎片，以指数级速度凝聚！</p><p>这些碎片不遵循灵界的物理规则，它们在量子泡沫中穿梭，彼此间以超越光速的意念连接！</p><p>光茧外，所有真仙境大能，包括三位准圣，神念瞬间被吸引。</p><p>他们震惊地发现，那片本应死寂的虚无中，正爆发着比之前更恐怖的能量潮汐。</p><p>只有圣人——残星道人，饶有兴趣地看着领域中，正在逐渐涌现凝聚的杨帝碎片。</p><p>“白杨大帝，你究竟从何而来……你和鱼尊陛下是什么关系……”</p><p>杨帝的气息仍然是狂暴的数值堆砌。</p><p>但这次，一个普朗克尺度（1.1x10-38米）的碎片，就拥有媲美以前完整杨帝的气势。</p><p>阿巴猛地扑向59改，硬是将这个魁梧的机器人举得双脚离地：“他活了！老大真的活了！”</p><p>「……」59改只是仍然一脸凝重看向战场。</p><p>那群真仙境大能，原本打算陆续离场。</p><p>但此刻杨帝离奇复活，他们不得不继续客串嗜血观众。</p><p>顷刻间，杨帝已经生出心脏、脊椎、大脑和主干神经架构。</p><p>大脑的某一面，已经生出两颗圆咕噜溜的眼珠子。</p><p>“我回来了，诸位，‘死亡’确实有些难受。”</p><p>虚无法则，寂灭法则，倒反法则。</p><p>三重本源法则，三重机制杀，已经无法逆转颠倒杨帝的疯狂的恢复速度、无法衡量的数值总量。</p><p>领域，就是一方“小世界”，小宇宙。</p><p>但这方小世界，已经无法理解他的存在。</p><p>杨帝非但没有收敛气血，反而将心脏催动到前所未有的沸腾！</p><p>磅礴的生命精元喷薄而出，瞬间被“生灭劫域”的死亡法则疯狂侵蚀、转化。</p><p>但就在那污秽死寂之力，从心脏喷薄而出，即将反噬入体的刹那——</p><p>杨帝的每一个细胞，每一缕神魂微粒，都开始了难以想象的超速迭代与畸变！</p><p>他的身体结构在微观层面疯狂重组，如同亿万台精密的生物熔炉，强行将那涌入的“死亡”当作一种前所未见的“极端能量”进行解析、吞噬、转化！</p><p>咔嚓、咔嚓……</p><p>细微到法则层面的破碎声在他体内响起。</p><p>杨帝的血肉骨骼在死亡侵蚀下不断崩解、腐朽，却又在下一个瞬间，以更坚韧、更适应这种“死亡环境”的形态疯狂再生！</p><p>再生的那一刻，又瞬间翻转为死亡。</p><p>如此循环往复。</p><p>硬生生在“生即死”的悖论中，开辟出一条独属于他的、以死淬炼，向死而生的进化之路！</p><p>如何对付机制怪的机制？</p><p>让自己的血条长度，突破“机制”所能理解的上限，把领域本身撑爆，不就行了嘛。</p><p>如此简单朴素的思路，长久以来却很少有人实践过。不实践怎么出真知！</p><p>杨帝的肉身迅速复原成形。</p><p>包括他用毛发织成的衣服裤子，也迅速长了回来，避免少儿不宜。</p><p>他缓缓转过身。</p><p>“不错的玩具。”</p><p>平淡无波，却穿透三重领域、清晰响彻在三位准圣神魂深处的声音，从那混沌光茧的核心传出！</p><p>紧接着，三重嵌套领域内部猛然亮起！</p><p>那不是法则的光辉，而是纯粹到刺眼的、源自肉身气血的混沌神芒！</p><p>“轰！！”</p><p>一声来自灵魂层面的恐怖巨响炸开！</p><p>最内层的“生灭劫域”，如同一个被巨人从内部撑爆的气泡，猛地向外凸起、变形！</p><p>一只指节粗大如撑天神柱的拳头，带着纯粹到令大道都为之哀鸣的蛮力，狠狠地捣在了劫域壁垒之上！</p><p>“噗——！”涅槃轮劫元尊如遭重锤击胸，脸色瞬间煞白，领域反噬让他本源动荡。</p><p>那足以消磨星辰的“灭”之法则丝线，在接触到那只拳头的瞬间，竟如同冰雪遇见熔岩，嗤嗤作响，寸寸崩断、湮灭。</p><p>“生”之法则试图修复，却被那狂暴的肉身气血直接冲散、同化！</p><p>生灭轮转的精密机制，在绝对的力量面前，脆弱得可笑。</p><p>混沌拳头去势不减，悍然轰入了第二重“太虚幻境”。</p><p>那吞噬一切存在感的“无”之潮汐，面对这蕴含开天辟地伟力的帝躯，竟失去了效力。</p><p>拳头所过之处，虚无被强行“撑”开！</p><p>那血肉之躯本身蕴含的“存在”太过磅礴、太过坚实，沉重到连“无”都无法将其定义和抹除。</p><p>就像一滴墨水无法染黑整片汪洋。</p><p>太虚妙有法王闷哼一声，身形微晃。</p><p>拳头带着无可阻挡的威势，直接撞上了最外层的“两仪玄界”。</p><p>那颠倒正反、混乱时空的混沌巨蟒咆哮着缠绕上来，试图扭曲拳头的轨迹，将其导入无尽的正反悖论迷宫。</p><p>“破！”</p><p>杨帝一声断喝，如混沌初开的第一道惊雷，拳头之上，滔天气血骤然暴涨！</p><p>没有动用任何法则神通，仅仅是纯粹的物理力量！</p><p>纯粹、野蛮、碾压一切的力量！</p><p>咔嚓嚓——！</p><p>足以困锁神魔、混淆圣听的两仪玄界，那玄奥莫测的空间褶皱、时间乱流、因果迷网、颠倒规则，在接触拳锋的瞬间——</p><p>如同脆弱的琉璃镜面，布满蛛网般的裂痕。</p><p>正反法则形成的巨蟒发出凄厉的哀嚎，寸寸断裂！</p><p>混乱的机制，在绝对的力量碾压下，被硬生生地、粗暴地砸穿。</p><p>三重嵌套的法则领域，如同纸糊的灯笼被捅破，轰然爆碎。</p><p>狂暴的灵能乱流席卷八荒。</p><p>那爆裂的领域中，喷薄而出的，并不是混乱的能量，而是……一种让所有真仙、仙帝、神皇、至尊、准圣都感到自身渺小，大道仿佛都在颤栗的“力”！</p><p>杨帝周身帝威如狱，气血蒸腾，将残余的法则碎片直接碾成齑粉。</p><p>他甩了甩手腕，仿佛只是随手打碎了几块碍事的石头。</p>
