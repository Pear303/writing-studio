# 食破天惊二度

<p>弹幕洪流瞬间淹没半边屏幕：“祂在想啥？弹幕刷起来！”这明显是个托。</p><p>“弱点盘点！快！我要看祂破防！”</p><p>“规则来了！第一条：禁止眨眼超过3秒！”</p><p>“你们觉得这自称智神的家伙能活多少秒？”</p><p>“吔！第一场的诡异本体竟然是个魔鬼筋肉人！”</p><p>“嘶啦——我要看这智神被打倒跪地口牙！”</p><p>智神·辛烈治脑海中响起一个声音。</p><p>“叮！XXX系统已绑定！”</p><p>“叮！觉醒的是最低等的D级天赋。但可通过XXX系统消耗一个积分点进行‘升级’……”</p><p>……</p><p>电光火石间，三大邪神，硬控！</p><p>“呱！！”哥达内咆哮。</p><p>祂正在杨帝嘴里，此刻感受到了前所未有的致命威胁。</p><p>另外三位同道脱不开身，救不了祂，祂只能自己救自己。</p><p>顿时勇毅血海沸腾，化作亿万柄滴血的战争神矛，带着洞穿万界、破灭大勇的意志，刺向杨帝的脸皮！！</p><p>但杨帝不闪不避，也并不把血神吐出！</p><p>他的脸皮极厚，硬顶着那足以刺穿圣人躯体的战争神矛洪流，强行将血神吞下！！</p><p>啦——！嗤啦——！</p><p>令人头皮发麻的撕裂声响起！</p><p>构成哥达内神躯，高度内敛凝聚的灵能，如同被无形巨口撕咬下的血肉，被硬生生从祂那庞大的血海神躯上剥离下来。</p><p>「血肉」化作一道粘稠如岩浆，散发着无穷煞气与不屈战意的暗红洪流，被强行拖拽着，源源不断地投入杨帝口中那深不见底的漆黑漩涡。</p><p>他一边疯狂吞噬，一边用冰冷凶戾的目光扫视着正在拼命挣脱他硬控的另外三神。</p><p>命神的心脏，在秽与洁的光芒中艰难重组。</p><p>爱神的精神，在杨帝的古神低语之下尖啸。</p><p>智神的身心，在怪谈规则中艰难做题解谜。</p><p>时间紧，任务重，光阴迫，从来急！</p><p>杨帝急着消化，血神急着脱身。</p><p>“吼——！！！”</p><p>血神哥达内的咆哮再度在杨帝口腔中炸开，血色雷霆劈打在齿关上，溅起亿万点法则湮灭的火星！</p><p>祂那被强行撕扯吞噬的神躯，每一滴血都仿佛蕴含着一个沸腾的战争宇宙，此刻在杨帝的咽喉深渊前，爆发出足以点燃纪元、让诸神黄昏提前降临的恐怖力量！</p><p>祂不甘！祂是至道勇毅血神！</p><p>祂执掌战争本源，是兆亿世界杀伐气运的凝聚。</p><p>岂能如凡俗血肉般，被当做果腹之物？</p><p>战！战！战！</p><p>在哥达内燃烧的圣瞳之中，祂看见两座横亘在要道、镇压过太古魔神的堡垒。</p><p>其上布满了古老沧桑的道纹，流淌着杨帝自身“食之大道”（简称食道）的恐怖神辉。</p><p>万界血海，燃吾神矛！</p><p>亿万血矛，裹挟着哥达内最后的疯狂与不屈，如同灭世的流星雨，撕裂了杨帝口腔内的混沌气流！</p><p>带着洞穿万古的尖啸，狠狠攒射向那两座巍峨的壁垒！</p><p>叮叮叮叮叮——！！</p><p>刹那间，金铁交鸣之声响彻杨帝的口腔！</p><p>那是足以让仙帝耳膜炸裂的巨响，而溅射出的唾沫星子足以将星河打成筛粉。</p><p>那两座壁垒，在如此狂暴的冲击下，竟也微微震颤起来。</p><p>表面的肌肉纹理明灭不定，仿佛承受着开天辟地以来最沉重的压力。</p><p>哥达内燃烧一切换来的力量，确实撼动了这“门神”！</p><p>哥达内集中所有残力，凝聚出一柄贯穿过去未来的血战本源之矛，矛身缠绕着无穷战魂的呐喊。</p><p>矛尖未出，一点寒芒先到，狠狠刺向其中一座壁垒！</p><p>轰隆隆——！！！</p><p>这一次的撞击，如同两个大宇宙迎面相撞的恐怖轰鸣！！</p><p>那座被重点轰击的巨型壁垒，光芒瞬间黯淡了大半，表面裂开一道狰狞的、流淌着混沌气的缝隙！</p><p>然而……</p><p>就在血神之矛即将彻底贯穿那座堡垒时。</p><p>一股源自杨帝生命本源，但更加古老，更加蛮横，更加不讲道理的吞噬之力，从壁垒之后那深邃无光的深渊中轰然爆发！</p><p>那是一个吞噬万物的黑洞。</p><p>其中心，一点漆黑到极致、连光都无法逃逸的“奇点”在旋转，在低吼。</p><p>咕噜……</p><p>一声仿佛来自宇宙原初的吞咽声响起。</p><p>刚刚锋芒毕露的血战本源之矛，连同哥达内残存的最后一点意志与神躯，瞬间被那恐怖的吸力捕获，拉扯，撕裂。</p><p>如同坠入深渊的飞鸟。</p><p>所有挣扎，所有光芒，所有咆哮，都在那绝对的黑暗与吞噬之力面前，被无情碾碎。</p><p>“不甘——！！！”</p><p>哥达内只来得及发出一声充满无尽怨毒与不甘的意念嘶吼。</p><p>那声音便连同祂的圣躯、祂的意志、祂所代表的战争本源，一同被拖入了那不可名状的蠕动深渊之中。</p><p>“轰！！”</p><p>杨帝猛地合上了嘴。</p><p>终于把这厮给吞下去了。</p><p>就是扁桃体发痛，像是吞刀片。</p><p>血神在被他吞下过程中，疯狂地用管制刀具攻击他的扁桃体。</p><p>祂似乎是将自己的扁桃体，当成什么“镇压过太古魔神的堡垒”了。</p><p>血神这玩意，抛开色泽、香气、味道、软硬、口感、营养、余韵、形状不谈，其他方面和咔咔脆炸鸡腿根本没区别。</p><p>但是和炸鸡一样，容易上火，吃一口就扁桃体发痛了，还是少吃为妙！</p><p>此刻另外三位邪神也不好过，祂们仍然在被硬控着。</p><p>命神那唭枯的心脏刚刚艰难重组完毕，气息萎靡。</p><p>爱神沙历士眼神涣散，显然还未从“1000-7”的精神污染中挣离。</p><p>智神辛烈治则深陷“十万三千怪谈”的规则泥潭，象征智慧本源的脑花正被无数弹幕和规则疯狂冲刷，脑花似乎都快要过载冒烟。</p><p>杨帝咧开嘴，露出一个令三神都感到安息的微笑，仿佛刚刚饱餐一顿猛兽，牙齿森白如开天之斧凿：</p><p>“味道……尚可。下一个，轮到谁了？”</p><p>圣人不仁，以百姓为刍狗。</p><p>杨帝不圣，以圣人为热狗。</p><p>他向前踏出一步，脚下的混沌再次被纯粹的力量碾爆，目标直指气息最不稳的命神那唭枯！</p><p>“呀——快退！”那唭枯感受到陨落的危机，亿万条代表命运可能性的丝线瞬间交织，企图将自己挪移到兆亿世界线之外，躲过这必杀之口！</p><p>然而，祂发现——</p><p>自己在杨帝面前，无法分裂世界线！</p><p>那唭枯如同被琥珀封存的远古毒虫，徒劳地挣扎着，却连一丝涟漪都难以泛起。</p><p>怎么可能……此人……锚住了“此时此刻”……</p><p>“呜——！”祂只来得及发出一声绝望呜咽，杨帝的大口已然笼罩而下。</p><p>吞咽声比之前更为顺畅，仿佛只是饮下了一杯浊酒。</p><p>杨帝森然的目光已转向眼神涣散、深陷“1000-7”精神污染泥潭的爱神·沙历士！</p><p>“轮到你了，恋爱脑！”</p>
