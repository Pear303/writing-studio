# 妄人

<p>十二位红衣主教围坐在环形审判席上，银丝绶带在彩色玻璃折射的天光里泛着冷芒，宛如凝固的银河。</p><p>教皇与国王隔案相对，金红交织的冕旒垂落，将两人面容隐入明暗交界处。</p><p>瑞弗维尔伫立在冰凉的大理石地面，黑袍褶皱间渗出冷汗，在烛火下泛着微光。</p><p>他怀中的水晶球滚烫如炭，内部翻滚的阴影中，一团白炽光晕正在成形。</p><p>“瑞弗维尔，你可知罪？”教皇的声音震得穹顶壁画上的天使都振翅欲飞。</p><p>这位圣古琉斯光明圣教的领袖，身形矮胖，脑袋椭圆，光秃的头顶在烛光下泛着油亮光泽，却无人敢轻视他眼中森冷的威压。</p><p>瑞弗维尔喉结滚动，指着水晶球道：“星渊井口南部海域，将有足以焚尽苍穹的爆炸，我预知到了蘑菇状的云柱......”</p><p>话音未落，审判席上爆发出刺耳嗤笑。</p><p>“蘑菇云？馆长莫不是将预知画面，和吃完毒蘑菇后的梦境混淆了？”</p><p>第一席红衣主教微笑，抚摸着手指上三枚戒指，“星渊井口百年前就已被封印，深海处更是布下三重结界，就算上古魔神复苏，也无法掀起这般骇浪。”</p><p>瑞弗维尔指甲深深掐进掌心，水晶球内的异象愈发清晰：暗紫色闪电撕裂云层，海面骤然凹陷，炽热白光如新生的太阳般炸开，蘑菇状云柱直冲天际，所过之处，海水蒸腾成虚无……</p><p>这绝非幻象！</p><p>“陛下，我愿以游侠的荣誉起誓！”瑞弗维尔抬头望向王座。</p><p>却见国王眉头紧锁，手中把玩的翡翠扳指折射出冷冽的光。</p><p>国王也是个光头。</p><p>曾经与他彻夜探讨古籍的君主，此刻目光如审视叛徒般冰冷。</p><p>“预言无凭，扰乱枢机院秩序。”国王的声音回荡在空旷的大厅，“将瑞弗维尔流放至星渊井口南部，让他亲眼见证结界的稳固。”</p><p>圣光教皇微微点头：“善。散会。”</p><p>众人纷纷离场，结束这场紧急召开却又草率结束的闹剧。</p><p>瑞弗维尔被拉进设施完备、还算豪华的临时囚室。</p><p>深夜，囚室铁门发出细微响动。</p><p>“馆长走此小道。”</p><p>瑞弗维尔见到了国王。</p><p>“三日前，渔民在南部海域发现了发光的海藻，并有超过了二十户渔民声称，在靠近远海的地方发现比鲸鱼还要大的黑影……”</p><p>“这是一项委派给你的秘密任务，要知道，自从100年前圣光教廷的圣骑士‘巴德’杀死焚灭天空之龙·卡利斯托，教廷威望达到极点……”</p><p>“他们封锁了星渊井口，以及在通往南海的几条必要道路设置重卡。而我也不能不给面子，强行冲关，因为政治资源是有限的……”</p><p>“瑞弗维尔，虽然你没有一丝一毫政治智慧和社交情商，但我相信你的判断……”</p><p>“我已帮你伪装好身份——来自北极群山，去往南土海洋取鲸的捕鱼人……”</p><p>“此乃八环战士哈蒙德，能够手撕大象，脚踢鲸鱼，一拳打碎一座山头，由他护送尔等……”</p><p>“记住，我信任你。”</p><p>“如果你……要写一些关于我的东西，那么请您务必笔下留情……”</p><p>“走这条地下暗道吧，先帝为应对战乱而修建，已经上百年无人通行……”</p><p>崆——</p><p>身后的暗门便轰然闭合。</p><p>黑暗如同有生命的巨兽，瞬间吞噬了最后一线光亮。</p><p>“啪嗒。”</p><p>哈蒙德掌心亮起实体光球，光线将二人的影子投射在石壁上，轮廓随着幽光晃动。</p><p>瑞弗维尔正要开口，却见这位魁梧战士突然伸手揭下人皮面具。</p><p>烛光下，赫然露出白天审判席上某位红衣主教的面容。</p><p>“吾行于黑暗，供奉光明。”哈蒙德指尖捻着人皮面具边缘说道，“陛下没告诉你？教廷十二红衣主教，都是王室暗桩。”</p><p>瑞弗维尔掐指，心一惊。</p><p>也就是说，12席红衣主教都是效忠王室的？</p><p>这位国王，人格魅力竟如此之大。</p><p>图书馆馆长自惭形秽。他早年当十几年的职业游侠，后来又当上图书馆馆长，但朋友总是很少很少，只有不到0.9个。</p><p>高山流水，更是0.5个都没有。</p><p>飘零半生，他还能遇到知己吗？</p><p>……</p><p>「如果国王您不信任瑞弗维尔，明日圣古琉斯街头就会流传《君王秘史》，详细记载您十二岁尿床被奶娘用法式面包打屁股的事，以及您对教皇实施的秘密计划……」</p><p>「而您，若不想‘秘密’被公之于众，就请全力支持瑞弗维尔吧。」</p><p>圣古琉斯国王放下那封三天前出现在他抽屉里的信件，打了个寒战。</p><p>对方究竟是何人，竟能无声无息瞒过宫廷王室的守卫力量，把信件送了进来，还这么精准击中他的痛点。</p><p>国王收到的威胁信，是用古老的羊皮纸书写，封蜡上印着奇异的符号。</p><p>展开信件，字迹用猩红色墨水写成，歪歪扭扭，像是写字之人故意隐藏自己的笔迹。</p><p>信中不仅精准写出国王十二岁尿床的细节，甚至还提及国王某次在密室中接见某位“异界人”的详细记录。</p><p>那几位“异界人”，谋划了将圣光教皇的“生发炼金药剂”替换成特制的“头皮抛光精华”这项惊天计划。</p><p>这瓶看似金光闪闪的药剂，实则是由南极企鹅的脱毛膏、沙漠蜥蜴的蜕皮液，再加上几滴上古精灵的魔法调配而成。</p><p>原本教皇满心期待，以为用了这瓶药剂，自己的头顶就能长出如瀑布般的秀发，说不定还能在圣典仪式上惊艳众人。</p><p>谁料第一次使用，他的头发就以肉眼可见的速度“唰”地一下集体离家出走，最后只剩下锃亮的光头。</p><p>在阳光照射下，甚至能反射出刺眼光芒，差点闪瞎了前来汇报事务的红衣主教们的眼睛。</p><p>事后，圣光教廷宣称事教皇苦修圣光之力过猛，导致绝顶，脑袋会发出圣光。</p><p>尽管公关看似完美，但此事件仍然有力打击了圣光教廷的声望。</p><p>这也正是近百年来，圣古琉斯王室最成功的政治阴谋。</p><p>这种事情，也许会截取部分片段写进正史。</p><p>但只有真正具备大政治智慧的高人，才能看出来背后的门道。</p><p>当然，这种历史最有可能还是出现在野史。</p><p>总之，这种私密的阴谋，是绝对不能被太多人发现的。</p><p>写信之人不仅知晓自己最隐秘的童年糗事，还对与教皇周旋的秘密计划了如指掌，其手腕和目的都让人不寒而栗。</p><p>是“异界人”的反间计？可他们为何要用如此奇特的方式？还是说，是国内某个心怀叵测的势力，企图借此搅乱局势，谋取私利？敌对的境外势力？又或者……来自天外的力量？</p><p>……</p><p>瑞弗维尔兜兜转转出了皇宫下方的地道。</p><p>他们已来到王城之外，这里是荒郊野岭。</p><p>他们刚出新手村那一刻，便遇上第一个杀意凛冽的魔物——杀手兔。</p><p>就如人类之中有圣骑士巴德这般九转大能，亦有手无缚鸡之力的柔弱少女。</p><p>眼前这只杀手兔，不知吃什么东西长大的，身上竟也有九环灵能波动！！！</p>
