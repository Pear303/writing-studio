# 围三缺一

<p>众人陷入可怖的沉默，周围只有远处偶尔传来的几声树木断裂、岩石涨缩的脆响，仿佛大地在这可怕的爆炸后仍在痛苦地呻吟。</p><p>暮色是一块沉重的幕布缓缓落下，将这满目疮痍的世界，用黑暗笼罩了一半。</p><p>另一半天空，是即将消逝的黄昏。</p><p>圣骑士巴德大约确实是死了。</p><p>自从100年前讨伐焚灭天空之龙·卡利斯托，巴德未曾在世人眼中现身。</p><p>或许圣光教廷在大战后的星渊井口，发现了他，但他们对世人隐瞒了巴德的下落。</p><p>在正史中，这位超限级别的圣骑士，只残余半截碳化的手指骨。</p><p>而在野史中，那些想象力丰富的文人，则为他安排了“和当年见家长时被岳父赶走、然后美人鱼反抗大家长权威、重新找到巴德，二人在南方大海里过上幸福快乐没羞没臊的生活”如此童话浪漫幻想的结局。</p><p>但事实上，正史和野史都错了。</p><p>巴德孤寂地站立了100年，就在星渊井口中央方圆一米的圈，永远无法跨越的窄地。</p><p>众人也不知道，他为何被「绑定诅咒」封印于此。</p><p>这个诅咒极可能来自于巨龙卡利斯托。</p><p>它的龙语诅咒，媲美最高级别的附魔台。</p><p>“附魔”和“诅咒”本质一样，都是将一种固定的灵能嫁接到另一种事物身上。</p><p>只不过一个偏褒义，另一个偏贬义罢了。</p><p>连同着「绑定诅咒」的，还有另一个附魔「不可破坏」。</p><p>但这里的不可破坏，并非概念性的力量。</p><p>一发从天而降的十环法术，彻底消磨了“不可破坏”，也解除了“绑定诅咒”，将巴德彻底湮灭，这也算是他的解脱。</p><p>所以，他在面对“涤罪天幕”时，才会显得如此平静吧。</p><p>「教廷的布置可能在南海某处。」</p><p>伊芙看向南方的海洋。</p><p>天塌下来，总得由高个子顶住的。</p><p>人类-精灵友好条约，互不干涉原则，曾经的军事同盟……在潜在的灭世危机面前，这些条约的合法性都得让步。</p><p>“我已经通过圣树的‘超距通讯’，通知了精灵群落。至于他们什么时候反应过来，什么时候做出应对措施，那我不得而知——我明白在你们眼中，精灵总像乌龟一样慢吞吞。其实我也这么觉得。”</p><p>不过目前来看，精灵那边的反应还是挺迅速的。</p><p>伊芙已经接到圣树传来的命令——作为单兵先遣队，调查南海。</p><p>她简单地解释：“纠缠通讯”是圣树的妙用之一，只要身处圣树根系延伸的范围内，都能通过圣树枝干与其建立联系，实现信息传递。</p><p>圣树与精灵之间有着深厚羁绊，此为“通讯协议”；此外还有一套复杂的加密解密算法，信息校验纠错机制。</p><p>瑞弗维尔将磨得锃亮的短刀别进腰间，对伊芙说：“我同你去。”</p><p>伊芙·柑橘脸蛋上泛起一丝惊奇：“在墓道里的时候，你还没有如此勇莽。”</p><p>瑞弗维尔微微红了红脸，避开伊芙的目光，望向那片焦黑大地。</p><p>他说道：“我也不明白。在墓道里，我只想着自己能活下去，逃离教廷的追杀，躲在世界的某个角落著史，但现在，我想……亲身参与进历史了……</p><p>“我一直有个梦想，就是写一部野史，记录下那些被正史遗漏的故事。</p><p>“可直到半个月前，我都没遇到什么值得我大书特书的人和事。</p><p>“比如巴德，已经有写野史的前辈写过他的往事了，我做的也只能是修修补补。</p><p>“但从遇到你开始，我觉得我的梦想可以加上一个限定条件——为伊芙著史。把你经历的一切，你做的所有勇敢的事，都记录下来。”</p><p>伊芙看着他的模样，浑身起鸡皮。</p><p>“我对你这么好，你居然要写我野史！”</p><p>“伊娃冷静！你听我解释！”</p><p>瑞弗维尔冷静地说道，“并不叫‘伊芙野史’，我打算命名为‘伊芙野传’。因为记录一个人并不算‘史’，而应该算‘传’的范畴……”</p><p>“这有什么区别啊！”</p><p>伊芙最终没有拒绝瑞弗维尔。</p><p>但同时，也还没有明确答应。</p><p>她收起沙漏，神色重新严肃：“瑞弗，你真的想好要和我一同踏上此旅？”</p><p>瑞弗维尔郑重地点头，喉结上下滚动：“我从未如此清醒。看到巴德的残片时我就在想，我们或许都是卒子，但至少我要做那个主动往前拱的卒。”</p><p>伊芙转过身，看向另外一个人类和矮人。</p><p>“你们两个呢？”</p><p>奥拓蹲下，粗糙手指抠起一块融化后又凝固的碎石，护目镜后的眼睛闪着复杂的光。</p><p>“唉……其实我早该从墓道溜走的，现在对方围三缺一，我除了跟你们去南边的大海，也没有其他路可走。”</p><p>杨帝点点头：“我和他一样，也只能随你们南下出海了。”</p><p>众人都知道他们面临什么。</p><p>站在星渊井口，往东、西、北三面望去。</p><p>四人瞳孔倒映出无数身着白袍的修士。</p><p>北边，手持巨剑的圣殿骑士，正踏着燃烧的符文步步逼近。</p><p>东边，悬浮在空中的教宗术士，吟唱着古老咒语，云层里开始凝聚金色审判雷球。</p><p>西边，身着轻甲的惩戒者结成扇形阵列，他们腰间的圣水罐在黑暗中泛着冰冷的幽蓝。</p><p>他们把最开阔的南方留给四人。</p><p>南面，广袤无垠的大海，在黄昏暮色中荡漾着流火。</p><p>瑞弗维尔指向北方，人墙正中央有个个子很矮，但帽子高的角色。</p><p>“伊娃，那个就是我跟你说，长得很矮的椭球形教皇。”</p><p>精灵顺着他的手指望过去，咯咯咯地笑。</p><p>为首的教皇，头戴华丽主教冠，面容冷峻，眼神威严。如果忽略他大番薯的椭球形外表，那确实是气质非凡的一个人。</p><p>那个将脸藏在高帽子下的大番薯，嘴唇微张。</p><p>“去吧，祂在等着你……”</p><p>低沉的呢喃如毒蛇吐信，从四面八方渗入众人耳膜。</p><p>教皇身后的修士们也同步抬起头，兜帽阴影下露出泛出同样青白的脸，嘴唇机械开合，重复着同一句莫名其妙的话</p><p>“祂在等着你……”</p><p>声音起初像是微风掠过枯草，很快便如燎原之星火，化作震耳欲聋的浪潮。</p><p>“祂在等着你……”</p><p>“在等着你……”</p><p>“等着你……”</p><p>他们只是站在那儿，复读机一样重复着那句话，并没有走上前来。</p><p>瑞弗维尔在本子上写下「教廷众试图用心理战术分化瓦解我们的意志，虽然双方都没有实际动手，但在无形的意识中已经交战数百千万亿兆遍……」</p><p>什么在等着我们但是？他用眼神问伊芙。</p><p>原目。伊芙说。只可能是“原初之眼”在等着我们了。</p><p>精灵看向南方的大海。</p><p>远处，海浪拍打礁石的轰鸣，像是某种远古巨兽正在苏醒。</p><p>瑞弗维尔翻找出他用了一路的地图：“星渊井口海岸线附近50公里，只有一座岛屿存在……所以伊娃，我们要……”</p>
