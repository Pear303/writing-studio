# 智取四小贩

<p>原本漆黑深邃的宇宙空间，此刻像是被搅乱的水彩画，各种绚烂色彩嵌套缠绕，有生命一般游动、变幻。</p><p>光线不再沿着直线传播，而是弯曲成弧度，像是一道道波浪状彩虹。</p><p>时间线在这里不是线性流淌，而是像一团杂乱的毛线。</p><p>过去、现在与未来混合，让人无法分辨因果逻辑。</p><p>虚境中的物质，更准确来说不是物质，而是纯粹的“现实”，似乎都不遵循常规宇宙的普通法则，以类似云雾的姿态悬浮在空中。</p><p>空间结构在虚境里也毫无规律，上一秒你还置身在波光粼粼的液态金属海洋，下一秒脚下就变成了燃烧着幽蓝火焰的水晶山峰。</p><p>这种混乱，更接近宇宙之本貌。</p><p>“你们看那边。”杨帝指了指某个方向。</p><p>虽然从严格意义上讲，虚境中并不存在他的手指头，也不存在空间本身。</p><p>但鲈鱼和坦克还是很快便明白了杨帝所指之物。</p><p>那是四个涌动着灵能的巨型“漩涡”。</p><p>情况稍有特殊——这四个漩涡，都诞生了一定的主体性智慧。</p><p>那是宇宙之中，各个文明、种族，乃至个体伟力者，都不愿面对的、藏在秩序背面的原始力量。</p><p>从表面上看，那是四口漩涡。</p><p>“这四个‘漩涡’，应该是宇宙本身就存在的自然现象吧……”阿巴有些不确定。</p><p>她每次冥想/观想，都总能感受到那四个漩涡存在。</p><p>杨帝摇头：“并非自然现象，至少祂们目前的力量来源并不算纯粹。在我老家有一个观点：权力真空并不会消失，而总是会被填满。”</p><p>如果A无法填满权力生态位，B就会前来填补。</p><p>打个比方，如果没有足够良好的基层治理，就会形成大量地方帮派、宗族势力，来填补基层治理的空缺。</p><p>「原初之眼」被扫除，“绝对观察者”位置有空缺，便会有外来者填补。</p><p>而在这个宇宙，“外来填补者”就是眼前四个东西。</p><p>尸山与血海的散布者「生命之织缕」</p><p>空虚与贪求的尖叫者「世界之喰煞」</p><p>渴望与占有的呢喃者「渴求之器具」</p><p>信任被摧毁之滋味者「虚空之低语」</p><p>它们是盘踞在亚空间航道上的海盗，化身一个个吃人不吐骨头的“收费站”，吞噬通过亚空间航行的文明与强者。</p><p>它们从虚境中观测着万物，获得大量情报。</p><p>在此基础上，四小贩与宇宙中各大文明、强者做买卖，并达成不平等交易。</p><p>每分钟流水都是天文数字。</p><p>这四个小贩，凭借部分“绝对观察者”权柄获取大量信息差，赚疯了！</p><p>全宇宙生灵像韭菜一样被收割着。</p><p>虽说，那些生命在决定突入虚境、勇闯天幕之时，就应该有承担后果的觉悟。</p><p>但虚境四小贩的手段窃取“绝对观察者地位”的手段，早已超出了“愿赌服输”的范畴。</p><p>它们还组建起庞大的“虚境商会”，本质上是覆盖全宇宙范围的超级托拉斯联盟，形成对宇宙贸易行业的完全垄断。</p><p>此外还有各种金融部门、权力机构、金字塔等级制度……</p><p>宇宙中逐渐流传起可怕的都市传说：若是在亚空间航行时看到闪烁着诡异光芒的“收费站”，千万不要靠近；若是脑海中响起诱人的交易私语，必须立刻斩断神识……</p><p>但即便如此，仍有无数怀揣侥幸的生灵前赴后继，因为四小贩掌握的情报实在太过诱人。</p><p>——失落文明的遗迹坐标、突破境界的关键法门、能颠覆战局的超级武器图纸、持续50年社会生产力翻倍的强力buff……</p><p>阿巴和59改来到“虚境商会”顶楼。</p><p>杨帝坐在59改的驾驶舱中。</p><p>此时，“生命之织缕”刚刚谈完一桩用整个行星人口换成罐头的生意。</p><p>瞅见一条鱼和一辆坦克形状的元神到来，祂眉开眼笑。又有新韭菜从盆栽里跳出，屁颠屁颠送上门了。</p><p>「虚境终于来新客人了！那边的鲈鱼靓女，要不要来买一份‘太空鲈鱼发展基金’？我们可以为您开通专项项目，促进‘月斑银鲈鱼’在全宇宙全世界线范围内养殖，现在促销价只需50个盖娅星球的生命……」</p><p>阿巴看得有些心动，毕竟一鱼得道，鸡犬升天，她也略微有些心系自己的同胞——尽管同胞们大多是浑浑噩噩，没有脑子，尚未开发出灵智的咸水鱼……</p><p>祂刚准备甩出编织着无数生灵残魂的交易契约。</p><p>杨帝从59改中探出精神体：“贵了，你这价格有点太高，我觉得得压一压，35个盖娅星球就差不多。”</p><p>“生命之织缕”发出婴儿啼哭般的尖锐嘶鸣。</p><p>祂瞬间蜷缩成一团血雾，像被踩中的蜈蚣般疯狂扭动着后退。</p><p>「哇是杨帝！快退呀！！」</p><p>话音未落，整团血雾已化作血色流星，拖着长长的尾焰飞驰离去……</p><p>杨帝虚空大手一探，一把将其抓住。</p><p>“跑什么？不是谈生意吗？我问你，35颗盖娅星球行不行？”</p><p>「杨帝阁下！！在下再也不干人口贩卖的事了！！我这次说的只是‘盖娅星球的生命’，并不一定要‘智慧生命’，就算卖给我最原始的苔藓和蛞蝓来做交易也行，所以肯定会贵点……」</p><p>“‘这次’？那除了这次，其他时候呢？”</p><p>「经过整改，绝大部分时候，在下都不敢搞智慧生命的人口贩卖……」</p><p>杨帝叹气，害人虫还是有些难扫干净。</p><p>“不是我信不过你，而是我信不过‘七情六欲化身’的逐利性。你们本就是人间情欲的化身，我担心若是我走了，就没人管得了你们。”</p><p>生命之织缕眼珠子咕噜一转。</p><p>——杨帝，要走了？</p><p>这个恐怖的数值怪若要走，不应该如此直白露骨地告诉自己，他必然已经留下后手……</p><p>祂瞬间化作一团人畜无害的粉色。</p><p>「杨帝阁下，您有任何要求，在下义不容辞。」</p><p>杨帝也明白祂的小心思，也就是要主动来当狗，帮忙打下杂，看能否为自己争取尽量多的利益空间。</p><p>“确实，恰好有一个忙请你帮帮——你可听说过‘投名状’？”</p><p>……</p><p>“世界之喰煞”正在啃食某个修真文明的祭品人皇幡，但下一刻，黑洞巨口突然僵住。</p><p>祂感受到“生命之织缕”逃窜时引发的虚境震荡，还伴随着对方的惊惶怒吼：</p><p>「饿货！还愣着干嘛？城管来了！！」</p><p>世界之喰煞脸色“唰”一声苍白无比。</p><p>偌大虚境，只有一人可被尊为城管。</p><p>那就是从宇宙诞生之初就已存在的一个人形生物，自称“白杨大帝”。</p><p>「怎么会……他怎么会到这里来！我已经节食不知多少个百万年了！！」</p><p>杨帝身形从一片粉色云雾浮现。</p><p>他看似并不庞大，但在世界之喰煞眼中，却仿佛遮蔽了整个视野。</p><p>一种源自灵魂深处的渺小感与敬畏，犹如将可乐猛摇3000次后打开瓶盖的泡沫，蓦然迸发。</p><p>“桀桀桀，你们不要跑呀！”</p><p>世界之喰煞和生命之织缕一块亡命。</p><p>「有一种方法可以减少我们被抓的概率。」世界之喰煞灵机一动，有了好点子。</p><p>「难道是，你想说……」</p><p>「分摊概率，嘿嘿嘿……」</p><p>祂们同时朝向下一个目标。</p>
