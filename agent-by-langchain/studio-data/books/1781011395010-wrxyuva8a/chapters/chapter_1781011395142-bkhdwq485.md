# 旅行团守则

<p>杨帝耳朵微微凑过去，听见甲板传来密集的脚步声与铁链拖拽声，某个尖锐嗓音穿透舱室：“压舱放水，货轮吃水线太高了。”</p><p>压舱放水……原来如此。</p><p>他压低声音说：“行星级文明会造靠浮力漂在水面的运输船，向‘压载水舱’里注水或排水，就能调整船身深浅和平衡。”</p><p>毕竟是土著出身，这些知识正对他路子。</p><p>阿巴发出合理质疑：“但是老大，咱们仨加起来，磨灭大道跟磨灭大豆一样容易，为什么要如此鬼鬼祟祟，见不得光也见不得人？”</p><p>弱小的时候苟得像条鱼，成尊后还是苟得像条鱼，那不是白成尊了吗。</p><p>“这个问题，59改你告诉她吧。”</p><p>59改简明扼要讲完“无限机兵”相关情报。</p><p>阿巴大鲸失色：“你是说，每个宇宙都可能有这种机兵，还专门盯着顶尖强者？”</p><p>「正是如此。」</p><p>不过，59改所知道的这些二手，不，所知道的三手情报，也是由杨帝告诉59改的。</p><p>这台机兵虽然是科技测的产物，但太乙真仙阿巴也能看出来——它身上的能量波动，高到突破天际！</p><p>甚至突破了杨帝小腿，抵达他膝盖的高度，恐怖如斯。</p><p>“既然无限机兵会把至强者设为目标，可在母宇宙老家，这台机兵并没有对我们动手。”阿巴困惑道。</p><p>杨帝点点头：“所以直到现在，我才向你们坦白此事……”</p><p>他把原初之眼从耶罗大仙那儿听来的二手消息，经过转手，转化成更新更好的三手消息，告诉59改和阿巴二人。</p><p>“……我们穿越异世界的目的，并不仅仅只是探索、提升与进化，我们还要收集星环盟约的情报。这也是为了未来如果与那个虚空超级文明接触，我们能攒更多筹码和底牌。”</p><p>星盟制造了无限机兵。</p><p>而无限机兵的存在，是悬在每个宇宙头顶的达摩克利斯之屠龙倚天剑。</p><p>没有人知道星环盟约的目的。</p><p>他们也不明白，“机兵”将至强者设为目标，究竟有何用意？</p><p>而且，如果紧盯这台机兵名字中的“无限”一词，再想到原初之眼提到过、那骇人听闻的——“无限机兵防卫圈”。</p><p>无限，自然数，可数无穷，阿列夫零。</p><p>杨帝原本如10万个极超新星爆发般膨胀的自信心，顿时被拍散一半。</p><p>因为他发现，自己的进化适应能力又双叒叕有一个致命弱点。</p><p>他身上的属性数值，都是有限大小的数。</p><p>譬如，自己的灵能水平经过在前一个宇宙吃了颗大补品，实现“补完”，达到了动心骇目的6.18×10^110灵。</p><p>大吗？还挺大的吧，嗯，确实挺大的。</p><p>但真的大吗？你确定？</p><p>好叭，确实蛮大的。。</p><p>但在真正的“无限”面前，任何大小的有限数，都和“零”几乎没区别。杨帝脊背发凉。</p><p>“总之，现在咱们低调行动，先出了压载水舱，看看这船，看看这世界是个怎么回事。”</p><p>他们立刻做好准备。</p><p>计划：先摸清楚这个世界的势力分布、科技水平，再寻找可能与星环盟约有关的蛛丝马迹。</p><p>如果用专业术语形容，这是个“秘密团”。</p><p>杨帝要寻找星环盟约的线索和耶罗大仙的住所，此二者绝非易事，这就好比在比撒哈拉沙漠还庞大的盐堆里找到一颗白砂糖。</p><p>他心中关于这个世界“最终真相”的猜测，更是犹如一团乱麻，亟待梳理脉络。</p><p>杨帝作为老大，开始为两位小弟分配任务。</p><p>“阿巴，你也不要整天渴望力量，老是盯着自己的战力嘛。力量固然重要，但也不能让它蒙蔽了双眼，错过这世间许多有趣的事。就像这次穿越异世界，多看看不同世界的风土人情，感受感受不一样的文明……”</p><p>阿巴翻了个白色鱼眼。</p><p>“老大，要是我有你那实力，我也能悠哉游哉。”</p><p>仙，修炼到一定层次，所寻求的目标已不是凡俗之人所能理解的了。</p><p>阿巴所追求之物，用普通的文字难以言述，只能强字之曰“道”。</p><p>曾经，她已经是母宇宙走得最远的仙人……仙鱼，再也没有前辈，能供阿巴摸着石头过河。</p><p>所以，阿巴通过自行摸索，认为“大罗道果”是继续“进步”的唯一出路。</p><p>但现在，有一位走得更远的前辈（杨帝）横空出世。那她必须得摸着杨帝过河啊！</p><p>她来到本宇宙的目的，就是要在不摘取“大罗道果”的前提下，试试其他路径能否追求更高境界。</p><p>分配完阿巴的异界旅行任务。</p><p>杨帝转过头，看向守望者。</p><p>“59改，你身上探测器够多，做学术的经验也足够丰富，你不要大张旗鼓，但你可以做一些被动式的观测和实验，慢慢把这个新世界的科技树全部点亮。”</p><p>阿巴只是条鱼，而且修仙，干不成大事。</p><p>59改就不一样了，他前生的守望者格式塔思维，是一个至少发展了数千亿年（体感时间）的超级文明。</p><p>他研究问题，研究事物，远比就知道埋头闭关修炼的仙人……仙鱼，经验要丰富得多。</p><p>「遵旨。我会在低能量状态下开展新宇宙的物理规则测量活动，避免受到高等文明或个体强者注意。」</p><p>杨帝看向59改：“话说你的那些仪器设备到了这个宇宙，还能正常发挥作用吗？”</p><p>「最初穿越而来之时，仅有约0.7%的仪器成功适配此宇宙的物理法则。」</p><p>“现在呢？”</p><p>「目前正在新建数据库记录的物理法则以及灵能规律，以适配当地宇宙环境，本机兵可运行设备已上升至3.4%」</p><p>“嗯……那目前本宇宙科技树你攀到哪一步了，59改？”</p><p>「已经抵达第三阶段‘超物质时代’。按照母宇宙的经验，我已经解明这个宇宙中0.97%的现象背后所隐藏的规律。」</p><p>杨帝记得，守望者曾介绍过，宇宙中的文明按照对物质的大批量工业化操控精度，可以划分为4个阶段。</p><p>“超物质时代”已经是第三个阶段了，却只能解明不到1%的现象所代表的规律？！</p><p>「是的，各个文明时代之间，对宇宙真相之理解各有高低。即使是‘超物质时代99.99%’与‘超弦时代0.01%’，它们的差距亦为天堑。」</p><p>一个非常反直觉的真相：</p><p>宇宙中，文明之间的差距，甚至比不同大境界修士之间的差距还要大。</p><p>经常传出“某某元婴天才击败某某化神老怪”的消息，却从来没有落后时代的文明反杀先进时代文明的案例。</p><p>扯远了扯远了，回到现实。</p><p>此时，压载水舱开始放水。</p><p>头顶甲板的脚步声渐渐远去，三人便顺着舷梯缓缓上爬。</p><p>59改原地搓了个由六边形纹路构成的正版太空死灵传送门。</p><p>“为什么你这传送门即视感这么强？”</p><p>“老大，这是我自主研发的传送门，您不要凭空污蔑……”</p><p>一人一鱼一坦克从压载水舱来到这艘游轮的舱底。</p><p>非常不幸的是，在同一时刻，络腮胡、叉着腰、厨师打扮的中年男人，目睹三人从太空死灵样式的传送门现身。</p><p>他手上还拿着两把锅铲，刚刚从旁边的厕所走出。</p><p>厨师瞪圆的眼睛像是被塞进了两个生鸡蛋，眼皮抽搐着扫过杨帝腰间若隐若现的灵光、阿巴甩动的鱼尾上凝结的仙力水珠，最后定格在59改炮管流转的幽蓝电弧上。</p><p>“三位，很不错的cosplay……”</p>
