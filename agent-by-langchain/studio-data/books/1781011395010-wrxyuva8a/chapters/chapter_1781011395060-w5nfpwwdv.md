# TIME TO DIE.

<p>……</p><p>里克拼命地奔跑着，身后是如鬼魅般紧追不舍的罗伊·巴蒂。</p><p>周围的城市一片灰暗，细雨如丝，将本就阴森的街道笼罩得更加压抑。</p><p>他心中充斥着恐惧。</p><p>他很清楚罗伊·巴蒂的强大，那是Nexus-6型号战斗型号的生化人，力量、速度以及战斗技巧都远超自己。</p><p>回头，看不见罗伊。</p><p>但里克能感觉到他的气息，迫近。</p><p>他拐进了一条狭窄的小巷，希望能借此甩掉罗伊。</p><p>然而，刚一进去，他就意识到自己犯了个错误——这是个死胡同。</p><p>里克转身，背靠墙壁，紧握着手中的枪，眼睛死死地盯着巷口，心脏在胸腔里剧烈跳动。</p><p>“你逃不掉的，里克。”声音低沉冰冷，在雨中回荡。</p><p>在墙对面！</p><p>里克迅速调转枪口……</p><p>可还未等他瞄准，罗伊的拳头如同一发炮弹般轰破墙面伸了过来！</p><p>罗伊的手臂穿过破洞，以迅雷不及掩耳之势抓住里克持枪的手。</p><p>轻轻一扭，里克只觉一股巨大力量传来，手中的枪便不由自主地脱手，被稳稳夺过。</p><p>“里克，你看，这堵墙可拦不住我，你那些所谓的规矩和使命，也阻止不了我。你觉得你还能拿我怎样呢？”</p><p>里克强行镇定。</p><p>他手枪被夺走的同时，几根手指也被强行折断了，现在痛得说不出话来。</p><p>他屏住呼吸，不想引起对方注意。</p><p>还要将反了关节的手指强行扳回来。</p><p>但紧接着，罗伊竟用头直接撞破墙壁，脖子以上探了进来！</p><p>他的脸上溅满墙灰，却依旧一脸平淡，像是刚刚做了一件再平常不过的事。</p><p>“嘿，里克，你这逃窜的样子还挺有趣，像只到处找洞钻的小老鼠。怎么不说话了？”罗伊咧开嘴，露出一抹似笑非笑的表情。</p><p>雨水顺着他的头发不断滴落在地。</p><p>里克强忍着手指传来的剧痛，趁罗伊还在调侃之际，猛地抬腿踢向罗伊探进来的头部。</p><p>罗伊微微一侧头，轻松避开这一击。</p><p>“太慢了，在我眼里你就是只树懒。你知道树懒吗？它们很——慢——很——慢——”</p><p>里克掰好最后一根手指，转身，拼尽全力朝着墙边的排水管冲去！</p><p>双手交替，迅速攀爬而上，但因体力不支和手指剧痛，很久才登上屋顶。</p><p>罗伊一直在后方注视他。</p><p>里克爬上屋顶，双脚刚一踏上那湿滑的瓦片，便一刻也不敢停歇，立刻展开了一场毫无悬念却又充满绝望的跑酷。</p><p>狂风裹挟着冰冷的雨水，如刀刃般刮过他的脸颊。</p><p>他在高低错落的屋顶间疯狂穿梭，身形狼狈却又带着破釜沉舟的决然。</p><p>罗伊·巴蒂不紧不慢地跟在后面。</p><p>银翼杀手里克借着屋顶堆放的杂物，试图给他制造一些阻碍。</p><p>随手掀翻几只破旧的油桶，油桶咕噜噜地朝着他滚落而去。</p><p>生化人只是微微侧身，轻巧地避开。</p><p>“你这是在给我表演滑稽戏吗，里克？”他声音在风雨中忽远忽近。</p><p>里克没有回应，他的目光死死盯着前方，看到了两栋楼之间的一道狭窄空隙。</p><p>他咬咬牙，心一横，猛地加速，不顾一切地纵身一跃。</p><p>里克没能跳过去！</p><p>在半空中，他眼睁睁看着对面的屋顶与自己擦肩而过，心中涌起一阵绝望。</p><p>慌乱间，下意识地伸出手。</p><p>万幸，小臂堪堪抓住了一个凸出来的横梁！</p><p>狂风呼啸，雨水不断拍打在他身上，他整个人就像一片在风雨中飘摇的树叶，摇摇欲坠。</p><p>没力气爬上去了。</p><p>而生化人罗伊慢悠悠走了上来。</p><p>他只是微微屈膝，轻轻一跃，便如矫健的黑豹般，轻松落在对面屋顶。</p><p>他静静站在那，低头看着在生死边缘挣扎的里克，脸上依旧挂着那似笑非笑的表情。</p><p>“里克，瞧瞧你现在这副模样，真是狼狈至极。”</p><p>里克咬牙，用尽全身力气紧紧抓着横梁。</p><p>他手臂因过度用力而颤抖，破碎的指甲缝里渗出鲜血，混着雨水滴落。</p><p>里克觉得自己即将坠入无尽黑暗。</p><p>罗伊突然伸出手，抓住他手腕。</p><p>银翼杀手感觉自己的呼吸都要停止了。</p><p>对方微微用力，自己便被拉了上来。</p><p>里克瘫倒在屋顶上，大口大口地喘着粗气，雨水灌进他的嘴里，他浑然不觉。</p><p>这个银翼杀手，对面前的生化人除了恐惧，只剩困惑。</p><p>但他甚至没力气后退和问问题了。</p><p>罗伊静静地俯视着瘫倒在地的里克。</p><p>雨水顺着他棱角分明的脸庞滑落，在那似笑非笑的表情下，双眸却透着难以捉摸的深邃。</p><p>“你在害怕什么，里克？怕我杀了你？”罗伊的声音在风雨的呼啸中依旧清晰，带着一种奇特的蛊惑。</p><p>生化人罗伊缓缓蹲下身子，与银翼杀手里克对视。</p><p>他眼中的复杂情绪愈发浓烈，像是在审视一件既熟悉又陌生的事物。</p><p>“我见过你们人类无法置信的事……我曾目睹战舰在猎户座的边缘起火燃烧……C射线在星门附近的黑暗中闪耀……”</p><p>罗伊目光越过里克，望向那片灰暗的城市，眼神中流露出一丝难以察觉的向往与落寞。</p><p>“所有这些时刻，终将像泪水消失在雨中……ITS TIME TO DIE. ”</p><p>……</p><p>卡！</p><p>梦境里的时间流逝暂停了。</p><p>从最初一开始，杨帝就在二人之间蹲下来，观察着事态发展。</p><p>“为何战斗型生化人罗伊·巴蒂如此自信；而娱乐型生化人——舞女佐拉面对银翼杀手时，却如此举手无措？”</p><p>杨帝正在实地研究这个问题。</p><p>他用一晚上时间，在梦境中重复刷这部电影20次了。</p><p>舞女佐拉，作为娱乐型生化人，她的设计目的更多是为人类提供娱乐服务，性格上可能更倾向于温和、顺从。</p><p>而罗伊·巴蒂，作为战斗型号的生化人，被赋予强大的力量、速度与战斗技巧。</p><p>他在殖民地暴乱中，见过宇宙壮丽又残酷的景象，远超人类想象的画面，进一步塑造了他超脱常人的世界观。</p><p>他深知生命的短暂与无常。</p><p>既然终有一死，那便要在有限的时间里，以绝对强者的姿态去面对一切！</p><p>包括自己的死亡。</p><p>“磨灭恐惧，实现自信的最好方法，不是自己骗自己，不是自己洗脑自己，不是用宗教式狂热的模因感染自己，而是——”</p><p>而是“无与伦比的数值”！</p><p>世界终究是物质的，不能将“赢感”纯粹建构在虚无缥缈的精神世界上，而应立足在更坚实的物质基础。</p><p>就如那个战斗型生化人，他最大的底气来源于其战斗力。</p><p>战斗力是物质的，具有强大、纯粹的物质世界破坏力量。</p><p>罗伊唯一不足就是寿命太短暂，人生经验太少，到了寿命极限就得死。</p><p>杨帝不同，他可以在有限的时间内，用无穷的文艺作品填补灵魂的纵深。</p><p>“我不能一味当‘老古董’，我必须重塑自己的世界观，让我的思想跟上我的实力。”</p><p>杨帝低头捏着拳。</p><p>比如说世界观、价值观、人生观是“软件”，那么他的身体素质便是“硬件”。</p><p>如果软件太过落后，便无法发挥硬件100%的性能。</p><p>最极端情况下，会变成“祖国人”那样的超能力畜生。</p><p>虽然他无法做到强硬的自我洗脑，但还是能借鉴辩证唯物主义，把这套思想方法套到个人身上，通过物质基础对心灵的反作用，将自己塑造向目标人格。</p><p>“开始尝试吧，我还有9天半时间。”</p><p>……</p>
