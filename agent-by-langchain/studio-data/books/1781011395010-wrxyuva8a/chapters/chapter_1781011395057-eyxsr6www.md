# 钓鱼佬二三事5

<p>钓鱼佬下意识摸出根玉溪，但又放弃了。</p><p>他喃喃说：“有某种东西，有某个存在，能够通过黑暗的水体来到我们熟知的现实。”</p><p>杨帝顺着钓鱼佬的目光看过去，电梯井内淤积了不知多少年，那潭绝望、漆黑的死水。</p><p>“但是，我好像没见过黑色的酒……”</p><p>“黑暗的水体，并不局限于物理颜色上的黑暗。你要知道，那时候整间酒吧都停电了。”</p><p>“环境无光”也被判定为黑暗。</p><p>酒吧停电后，那杯酒水迅速置于浓密的黑暗中。</p><p>结果，就有某种存在，透过黑色水体……降临在它本不应该出现的现实。</p><p>钓鱼佬从渔具包里翻出个塑料盒。</p><p>那看起来是装鱼饵的，但打开，里面全是蝎子！</p><p>他说：“小伙子，我是个物理老师，理科硕士学历。这几年来，我一直在研究民俗神话典籍，尝试控制变量，还原出那一天的现场……”</p><p>“你太轻视自己的生命。就在刚才，你还差点淹死，要不是有别的‘东西’把你拉起来，你已经去见马克思了。”杨帝严肃批评。</p><p>钓鱼佬和他口中的“小伙子”四目相对。</p><p>“我通过大量资料查询，已经发现很多很多线索，我所知道的，超过你的想象。我知道我面对的是什么，不用你操心。”</p><p>杨帝无奈地摇摇头：“你这是在玩火自焚。凭你一个人，不能让它把吃掉的人吐出来。”</p><p>不能让它把吃掉的人吐出来……不能让它把吃掉的人吐出来……</p><p>钓鱼佬脸涨得通红，双手在空中挥舞，情绪几近失控。</p><p>“你根本不理解我现在这个感受！”</p><p>“你没经历过眼睁睁看着朋友在眼前消失，那种无力和自责！像毒蛇日夜啃噬我心！”</p><p>“我甚至不知道他们被黑水吞噬后，有没有哪怕1%的存活几率！”</p><p>“我的底线已一退再退！现在的我只想知道——他们有没有1%的概率活下来？”</p><p>“这种卑微的愿望也无法实现吗？”</p><p>杨帝没有接话，只是看着他，一边点头。</p><p>阴风从楼梯井上方吹下。</p><p>将钓鱼佬发烫的脑袋吹冷静。</p><p>他是老师，高知识人才，却被酒吧里一小杯酒水搞得崩溃，人生轨迹从此不同。</p><p>他甚至只是想知道：被黑暗水体送往另一个地方时，有没有1%的可能存活下来？</p><p>他扶着额头别过脸去，深呼吸一口气：“我冷静了。”</p><p>“好，叔，那你也应该知道，你、一、个、人不可能让它把吃掉的人吐出来，甚至会把自己搭进去。”</p><p>钓鱼佬瞪大眼。</p><p>他意识到，杨帝也想要掺和一脚。</p><p>“小伙子，我不能因为自己的执念，再把你也拉下水。”</p><p>杨帝没有说话，只是走到一旁，那扇锈迹斑斑的不锈钢铁门前。</p><p>不锈钢门倒在水里，门板上有个沙煲大小的凹陷。</p><p>钓鱼佬不知道不锈钢门为何会泡在水里，不知凹陷从何而来，也不知杨帝要做什么。</p><p>但下一秒，他就知道了。</p><p>杨帝将不锈钢门立起来。</p><p>他调整好呼吸，然后猛地一拳轰出！轰！！</p><p>那不锈钢铁门像是被炮弹击中一般，瞬间出现一个巨大的窟窿，边缘扭曲变形，门上的铁锈如碎屑般纷纷落下！</p><p>至少五六公分厚的不锈钢门，砸穿！</p><p>钓鱼佬嘴巴张得老大。</p><p>杨帝捏着微微冒烟的拳头，缓缓走到钓鱼佬面前，说道：“现在你还觉得我没有能力掺和这件事吗？”</p><p>“……这位师傅，你说得对，多一个人多一份力量，团结就是力量。”</p><p>钓鱼佬尽管四十出头的模样，但还是称杨帝为师傅。</p><p>原本他不想杨帝涉险，但这小伙子……这位年轻师傅展现出的力量，让他看到一线希望。</p><p>杨帝终于露出微微一笑。</p><p>“好。现在，我们先商量接下来的计划，你对这方面了解得比较多，说说你的想法，特别是……你所说的‘超乎我想象’的资料和线索。”</p><p>杨帝不只是想帮忙。</p><p>他尤其对“黑色水体能连接不同的世界”有兴趣。</p><p>他想找办法去异世界，去往其他隐秘的维度或时空！</p><p>「拿出世上无难事、只要肯登攀的狠劲，总有一天找到它……」</p><p>耶罗大仙位处另一个世界？次元？维度？</p><p>盲目瞎找固然低效，但若是连“穿越异界”的第一步都无法迈出去，他永远迈不出第二步。</p><p>……</p><p>钓鱼佬首先确定的事是，“召唤”那个东西，需要一片黑暗的水体。</p><p>这种“黑”并不只是物理上的黑，还要在某种意义上，像是被一切光明抛弃、被世界遗忘了的黑。</p><p>“准确来说，像是一种被所有人、被这片天地本身遗忘了的‘黑’。”</p><p>被这片天地本身遗忘……</p><p>指的是“灵”被抹除了一部分？</p><p>钓鱼佬掏出他那本电子书，翻到人类补完计划，又或者是其他某本书的某一页：</p><p>「地是空虚混沌，渊面黑暗；神的灵运行在水面上。」</p><p>钓鱼佬：“我在一些古老传说见过一种说法，黑暗的水体是连接不同空间的媒介。”</p><p>杨帝陷入思考。</p><p>他脑子里记录了一些神话和民俗学的资料，</p><p>但目前通过目录进行检索，似乎没发现过这种说法。</p><p>这是他第一次听说这种见解。</p><p>钓鱼佬：“不用搜肠刮肚回忆哪些神话传说有这种内容了。</p><p>“我整理了十年有余，从各种书籍资料角落拼凑线索，才得出这一结论。</p><p>“要向你解释这一结论怎么推导出来，我可以讲上十天十夜不停。”</p><p>杨帝点点头，示意他继续。</p><p>尽管自己的学习速度，是普通人的百倍、某一领域专家的数十倍。</p><p>但钓鱼佬在这方面钻研了十年，其积累的知识和线索，自然不是杨帝短时间内能够全面掌握的。</p><p>他也侧面得知，这位中学老师的四个学生已经丧生至少10年了……</p><p>钓鱼佬接着说道：</p><p>“其次，需要生物质作为‘饵’。这种生物质不一定需要小蝎子，死掉的生物尸体是最好的。</p><p>“我也不知道原因，但我之前做过一些小范围的试验。</p><p>“每次将大于指甲盖的生物尸体投入类似黑暗水体中时，都会引发一些异常现象。</p><p>“水体的波动、温度的骤变，甚至还会出现短暂的光影扭曲，这些都表明我的推测方向是正确的。”</p><p>水体波动、温度骤变非常轻微，且转瞬即逝。</p><p>没有专业设备监控，很难被常人察觉到这些细微变化。</p><p>这里的“黑暗水体”也并不局限于透光度低的污浊水体。</p><p>比如，钓鱼佬在酒吧里停电，灯灭时，酒杯里的酒，就是一种特殊“黑暗水体”。</p><p>黑暗水体就像是一扇门，而生物尸体就是敲门砖。</p><p>“天蝎座特调”的蝎子浸入漆黑室内的酒水，立即引起了“它”的注意。</p><p>“但是，召唤成功的概率小得可怜。”</p><p>钓鱼佬神情凝重地继续说道，“我在各种模拟的完美漆黑环境、黑色死水潭中，用各种体型的生物尸体做实验，最高也只有0.3%的概率，略微触发‘黑水连接’效应。”</p><p>杨帝挑了挑眉，这个成功率确实低得让人绝望。</p><p>他与自己学生聚会那一次，简直是运气霉到爆炸，一关灯就召唤出了那东西。</p><p>如果打个比方，那就是五个人走在路上，然后天降陨石，将周围四人击中，中间的人却侥幸逃脱。</p><p>钓鱼佬指着电梯井：“而在这个地方，我只消耗了一个蝎子，就成功了——有东西试图把我拖下水。”</p>
