# “爆炸式”

<p>瑞弗维尔简直不敢相信自己的耳朵，怀疑这是红衣主教设下的陷阱。</p><p>他愣在原地，不敢轻举妄动。</p><p>“我说，你走吧。”红衣主教再次说道，语气中满是疲惫。</p><p>“为什么？”瑞弗维尔忍不住追问。</p><p>他知道是个自己“追问到底”的行为，有多么愚蠢荒谬！有这功夫逃命不好吗。</p><p>万一对方被问烦了，反手将你轰杀至渣怎么办？放进冒险小说里，瑞弗维尔就是因为多嘴、连三页都活不过去的跑龙套呀。</p><p>“我感受到祂的孤寂了……”红衣主教静静地看着他，眼神中透露出一种决绝。</p><p>下一瞬间，红衣主教猛地伸出双手，毫不犹豫地朝着自己的双眼狠狠戳去。</p><p>“啊啊——！！”</p><p>“噗——”</p><p>伴随着惨叫，鲜血从他眼眶中喷涌而出。</p><p>瑞弗维尔被这突如其来的一幕惊呆了。</p><p>然而，这还没完。</p><p>红衣主教在戳瞎自己双眼后，身上突然爆发出一股恐怖的能量波动。</p><p>“这个能量波动……圣他娘的光啊……你要‘灵魂自爆’别拉我垫背……”</p><p>瑞弗维尔瞳孔收缩到极点——</p><p>第九席红衣主教，光明圣教原目会，胡伯特·布莱恩·沃尔夫施莱格尔施坦因豪森贝格多夫……竟然毫不犹豫地选择了灵魂自爆！</p><p>“润！”瑞弗维尔转身拔腿就跑。</p><p>“轰——隆隆——”</p><p>强大的能量瞬间席卷而来。</p><p>密道内的空气仿佛被瞬间点燃，爆发出耀眼光芒！</p><p>“不妙，看我灵活地闪——”</p><p>尽管在觉察到红衣主教要自爆的前一刻，瑞弗维尔迅速逃命、连拐七八个弯，以期用转弯地形削弱爆炸冲击波。</p><p>但那是红衣主教，圣光教廷的大能！</p><p>他灵魂自爆的力量，根本不是几十米厚岩石层就能阻挡的！</p><p>半秒后，冲击力狠狠撞击他后背。</p><p>瑞弗维尔感觉，自己就像一片在狂风中无助的落叶，整个人不受控制地向前飞去！</p><p>被冲击波裹挟着向前翻滚，他天旋地转，耳边是震耳欲聋的轰鸣声。</p><p>下意识地用双臂护住头部，心中充满绝望。</p><p>“要莫名其妙送在这儿了吗……”</p><p>就在他以为自己要命丧于此的时候，幸运女神对他掀起裙摆。</p><p>密道的一侧有个狭窄的凹坑，瑞弗维尔的身体正好被冲击波甩进了这个凹坑之中。</p><p>那原本就不宽敞的凹坑，此刻竟成了他的救命稻草，帮他抵挡住了大部分的爆炸威力！如此幸运，真是冒险小说里的主角待遇。</p><p>爆炸的余波逐渐消散。</p><p>密道内弥漫着刺鼻的硝烟味。</p><p>瑞弗维尔艰难地从凹坑中爬了出来，身上布满伤口。</p><p>他摇摇晃晃地站在原地，大口大口地喘着粗气，心中既庆幸自己死里逃生，又对红衣主教的疯狂举动感到震惊和疑惑。</p><p>“他为什么要这样做……只是看了眼这石头雕塑，他就悲痛欲绝，宁愿自爆？”</p><p>他强忍着周身的剧痛，伸出手。</p><p>“光，汇聚，照亮黑暗，驱散迷雾，一切隐匿无所遁形，现！”</p><p>「二环法术·照明」</p><p>对一般人来说，即使是释放个二环法术，也需要咏唱。</p><p>而那冒牌“哈蒙德”释放的是三环法术·实体光球。</p><p>他却不需念咒，法术瞬发成型。</p><p>瑞弗维尔这才发现他是“教廷派”的红衣主教，而不是国王“忠诚派”的战士哈蒙德。</p><p>因为那些脑子满是肌肉的物理战士，魔法天赋不可能会这么好！</p><p>瑞弗维尔借微光看路。</p><p>拖着沉重且血迹斑斑的身躯，一步一步缓缓地朝着爆炸现场走去。</p><p>密道内一片狼藉，原本坚固的石壁此刻千疮百孔，碎石块散落一地。</p><p>红衣主教已不见踪影。他到处都是。</p><p>瑞弗维尔在一堆废墟之中，找到了那石头雕塑。</p><p>令人惊奇的是，经历如此剧烈的爆炸，它居然完好无损。</p><p>瑞弗维尔轻轻拂去雕塑表面的灰尘与碎石屑，这才得以仔细端详它的模样。</p><p>这座巴掌大小的雕塑，主体是颗巨大的眼珠子，虹膜纹路如同漩涡般深邃，瞳孔中仿佛凝固着某种古老而未知的凝视。</p><p>环绕在这颗大眼珠子周围的是一圈密密麻麻的触须，以扭曲、缠绕的方式无序地散开。</p><p>整体就像，呃，一朵菊花。</p><p>长着一颗大眼珠子的菊花。</p><p>这可不兴用来泡菊花茶……</p><p>它背后所隐藏的秘密，或许正是导致第九席红衣主教做出疯狂举动的根源……</p><p>但瑞弗维尔从这雕塑感受不到一丝异常。</p><p>没有邪恶的魔力波动，没有潜藏的灵能。</p><p>就好像只是一件单纯的、造型诡异的后现代石头雕塑。就和他奶奶做的枇杷烤松饼一样平常。</p><p>瑞弗维尔：……</p><p>沃尔夫施莱格尔施坦因豪森贝格多夫到底看到了什么？</p><p>“我感受到祂的孤寂了”是什么意思。</p><p>为何他如此悲伤，最后自杀？</p><p>而且是这种在“光明圣教”中，最亵渎、最不可容忍的“灵魂自爆”？！</p><p>在光明圣教的教义里，生命是“光明神恩赐的礼物”。</p><p>每个人都肩负传播光明、涤荡黑暗的使命，应当珍视并善用这具躯壳，直到自然地回归光明神的怀抱。</p><p>任何形式的自杀，都被视为对光明神的大不敬，都被视作是怯懦与逃避的表现。</p><p>而其中，灵魂自爆更是其中最罪大恶极的行径！</p><p>灵魂自爆意味着彻底放弃圣光赋予的救赎机会。</p><p>还会释放出强大且混乱的能量，对周围造成极大的破坏，甚至有可能将黑暗力量吸引至此，污染神圣的土地！</p><p>……光明教典是这么解释的。</p><p>瑞弗维尔不信教，认为这是放屁。</p><p>但红衣主教不同，他是狂信徒。</p><p>他作为光明圣教的核心高层，向来是教义最坚定的捍卫者和传播者，是无数信徒眼中神圣的楷模。</p><p>他对光明神的信仰狂热而纯粹，平日里哪怕只是听闻有教徒对教义稍有质疑，都会雷霆震怒，施以最严厉的惩戒！</p><p>可如今……</p><p>这样一位虔诚的狂信徒，却毫不犹豫地选择了灵魂自爆？！</p><p>这实在是超出瑞弗维尔的认知范畴。</p><p>但鉴于这石头雕塑对他毫无卵用，</p><p>“那我就把它笑纳了吧……说不定日后，还能救我一命。”</p><p>瑞弗维尔将这个长得像菊花的雕塑擦干净，收纳进背囊。</p><p>他本想转身原路返回，向国王禀报“哈蒙德被第九席红衣主教取代”的情况。</p><p>并且警告国王，现在王宫很可能已被渗透成筛子；而他本人也在这次事故中受损不轻，急需更多盘缠和保镖上路，否则难以完成任务……</p><p>但回去的唯一通道，随着红衣主教的灵魂自爆，被隧道坍塌堵死了……</p><p>瑞弗维尔看了看自己手中，唯一带有“铲子”属性的汤勺。</p><p>他随身携带几十斤炊具，汤勺是唯一用来铲土比较趁手的工具了。</p><p>又看了看眼前数百吨落石。</p><p>原路挖回去，似乎不太现实。</p><p>“圣他娘的光啊，只能硬着头皮继续往外走了。”</p><p>瑞弗维尔安慰自己：就连国王亲自钦点的“忠诚派”八环战士，都能神不知鬼不觉被圣光教廷调包。</p><p>有理由相信，此刻王宫是最危险的地方！</p><p>继续向城外走吧。溜了溜了。</p>
