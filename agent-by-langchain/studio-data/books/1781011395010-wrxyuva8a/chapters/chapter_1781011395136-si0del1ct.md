# 太乙真仙巅峰大圆满混元无极破境超限半步准大罗

<p>杨帝抬手虚握，指尖迸发的力量直贯星河深处。</p><p>一颗直径仅20公里的中子星，在无形伟力的牵引下轰然脱离轨道，如面团般被强行拉长！</p><p>阿巴怖惧。此人……狠狠羞辱她还不够，此刻竟要做鱼竿？！</p><p>中子星的简并态物质在撕扯中迸发出刺目白光，整个星域的引力场都为之扭曲震颤！</p><p>鱼竿成型了，由中子星物质构造。</p><p>是世上最昂贵、最笨重的鱼竿。</p><p>在杨帝淫威下，这根鱼竿根本不敢发生贝塔衰变，而是维持着其超高密度的简并态。</p><p>“这强度刚刚好。”杨帝单手轻轻挥动，长达百万公里的“鱼竿”便稳稳悬于混沌之水上方。</p><p>屈指一弹，守望者舰队中数十艘千米级战舰瞬间被无法抗拒的原力抓住。</p><p>战舰船头接着船尾串联起来，化作泛着冷光的“锁链”，一端牢牢缠绕在中子星鱼竿上，另一端则延伸入水，如同巨大的钓线。</p><p>不，并非“如同”。</p><p>那就是“钓线”。</p><p>鱼尊阿巴意识到不妙，庞大身躯疯狂摆动，鱼尾甩动速度竟超过光速，划破了时空本身。她试图逃之夭夭！</p><p>“哇！不要钓我呀！！”</p><p>杨帝见状，知道大棒之后要跟上萝卜。</p><p>他指尖用力划过掌心，一滴非常普通的血液缓缓浮现。</p><p>这滴血液刚一出现，整个混沌之水便剧烈沸腾起来，其中蕴含的法则之力疯狂涌动，仿佛在朝拜着这滴血液。</p><p>“鱼弟，这可是好东西，我的血，按道理说应该是大补。不来尝尝？”杨帝轻声说道。</p><p>声音虽轻，却在虚空中炸响，震得阿巴脑袋嗡嗡作响。</p><p>这滴血也带有奇奇怪怪的防御抗性效果，竟然不会与周围的纯水发生反应。</p><p>“让我想想该怎么挂鱼饵……”</p><p>末端的“鱼钩”由十二艘无畏舰舰首三棱炮拼接而成，闪烁着湮灭一切的深红色光芒。</p><p>如果略微改造舰舰首三棱炮的输出模式，可以将炮塔的输出，改造成引力场俘获井。</p><p>要做到这一点，杨帝需要完全吃透整套战舰的控制体系设计。</p><p>如果是打孔计算机，就用灵能法术制造打孔效果，从而进行编程。如果是电子计算机，就用法术搓出合适的脉冲电流，对战舰系统操控指令做出修改。</p><p>战争操控系统中还存在加密算法。</p><p>如果是守望者这种级别的文明，杨帝从零开始设计一套解密算法，靠纯心算破解秘钥，需要的时间是……12.5秒。</p><p>Ok，解密完成，开始劫持战舰计算机控制系统，舰首三棱炮输出模式：定向引力摄取。</p><p>摄取对象：鱼饵。</p><p>中子星鱼竿发出低沉嗡鸣，缠绕战舰组成的钓线如活物般扭动。</p><p>阿巴惊恐地瞪大了眼睛，鱼尾摆动得愈发剧烈，时空在她周围扭曲成一团乱麻。</p><p>然而，那由中子星制成的鱼竿却如影随形，钓线紧紧地跟在她身后，无论她逃到水球的哪个角落，钓线总是恰到好处地悬在不远处。</p><p>“别跑啊，你跑多快，这鱼竿就能伸多长。”杨帝笑着说道。</p><p>手腕轻轻一抖，鱼竿瞬间延长数倍，钓线如灵蛇般穿梭在混沌之水中。</p><p>要做到如此的玄幻的效果，自然需要玄幻的力量——他用灵能法术操控鱼竿和钓线，实现手动追鱼，摒弃了传统的单纯等待。</p><p>阿巴绝望地发现，自己逃得越快，身后的钓线追得越紧，那滴蕴含着杨帝本源力量的血液所化的鱼钩，在她眼中愈发刺眼，仿佛随时都会将她吞噬。</p><p>没想到已经踏入太乙真仙大圆满，自己仍然会被人当鱼钓。</p><p>更没想到是鱼饵追她，而非她追鱼饵！</p><p>是的，阿巴根本不敢触碰这粒由杨帝精血所化的鱼饵。</p><p>这滴血液所蕴含的灵能，在她眼中，同样突破可观测宇宙的质能总和！！</p><p>自己吃下去，一定会爆体而亡的……</p><p>如此追逐了半个小时，阿巴的鳞片在时空撕裂的风暴中片片剥落，鱼尾摆动的速度也渐渐慢了下来。</p><p>她的力量不断消耗，而杨帝精力无穷无尽，鱼竿如影随形。</p><p>杨帝见时机差不多了，再次开口：“鱼弟，何必如此倔强？只要你乖乖就范，日后少不了你的好处，桀桀桀。”</p><p>他发出反派的笑声，声音同样从真空传到四面八方。</p><p>阿巴喘息着，庞大身躯在混沌之水中起伏不定。</p><p>她看着那滴悬在眼前，散发着诱人光芒却又充满暴烈灵压的血液，心中充斥恐惧。</p><p>再这样你追我逃下去，自己就要累成咸鱼了！</p><p>可若是吃下鱼饵，等待她的又会是什么？</p><p>“啊啊！！死咸鱼当活鲈鱼医了！我吃！”</p><p>阿巴再也无法抗拒，张开巨大的嘴巴，将那滴蕴含杨帝极小部分灵能的血液吞下去。</p><p>刹那间，狂暴的力量在她体内炸开，仿佛有千万利刃切割经脉，兆亿火焰灼烧内脏。</p><p>让她感到惊惶又狂喜的事情发生了。</p><p>自己原本已走到太乙真仙巅峰大圆满。</p><p>也就是名为「太乙真仙」的大境界进度条已经达到100%。</p><p>原本，阿巴唯一的进步路径就是摘取大罗道果，成就金仙。</p><p>但在吞下杨帝血液的那一刻，她的「太乙真仙」的大境界进度条，倏地窜到100.01%……</p><p>还在飞速往上窜！</p><p>阿巴仍然在翻滚着。但它已经顾不上品味痛苦，此刻，她沉浸于感受全身充满力量的澎湃！</p><p>体内不断攀升的境界数值，却像无法关闭的计数器，疯狂跳动——101%、120%、150%！</p><p>“鱼弟，大罗道果哪有这么好摘？不如试试我的‘超限进化’！”</p><p>“700%！800%！”阿巴发出非鱼非仙的鲈鱼真仙嘶吼，整个混沌水域开始围绕她旋转，形成一个巨大的灵能漩涡。</p><p>数值突破999%的刹那，阿巴周身灵能瞬间炸开，无数道彩虹色的法则光柱直冲九霄。</p><p>“老大，你……对我做了什么？”阿巴恢复了原来体型，声音带着疑惑与惊喜，“我能感觉到，自己可以去磨灭大道了！”</p><p>下一秒，她的法力开始回退。</p><p>体验过巅峰过后，阿巴的灵能从999%太乙真仙巅峰大圆满混元无极破境半步半步又半步准大罗，跌回到100%太乙真仙。</p><p>这些灵能，她不可能如此短时间内消化掉。她根本承载不了。</p><p>只能任由它们溢出逃逸。</p><p>杨帝随即将这些出逃的灵能一口吞下，物归原主。</p><p>可以预见，如果放任这些非野生灵能不管，周围千万光年的区域，将会迎来新一轮灵气复苏，改变当地文明和种族的格局。</p><p>而在阿巴这边，她心中有些空落落。</p><p>获得过攀越巅峰的力量，然后又回到原初状态，确实有些让鱼伤感。</p><p>但阿巴也明白，那股力量不是自己，至少不是现在的自己所能掌控的。</p><p>它若是把这股力量再多留1秒，就真要爆体而亡了！</p><p>非己所有之物，虽一毫而莫取。</p>
