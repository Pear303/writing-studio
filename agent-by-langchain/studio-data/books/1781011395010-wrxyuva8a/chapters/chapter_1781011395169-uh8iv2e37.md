# 狸猫换太子

<p>战斗持续了将近3分钟。更准确来说，是单方面的斗殴，持续了整整3分钟。</p><p>3分钟，也就是180秒，听起来很短，而实际上已经极其漫长！</p><p>高手过招，招招致命，招招关键。</p><p>像是归墟大帝这种级别的超级强者，一场架打他个5秒、10秒就差不多。</p><p>因为大帝级强者，在一秒内就能交手数百个回合。</p><p>而每回合破坏力的能量密度，都相当于黄金圣斗士三人的合体技！</p><p>归墟大帝，在自己统御的灵界，在自己的领域内，用此界的创世之斧，对杨帝疯狂输出了整整180秒。</p><p>他除了前10秒，用纯粹体术将大帝揍飞了几次。</p><p>之后170秒，都是单方面挨揍，不还手。</p><p>尽管杨帝已经气若悬丝，命如累卵，遍体鳞伤，体无完肤，奄奄垂绝，随时可能魂飞魄散。</p><p>但就是死不了。</p><p>犹如风中残灯，随时都可能被扑灭，却又顽强地闪烁着那一丝即将消逝的光芒，在生死边缘痛苦挣扎，令人心惊胆战。</p><p>直到有人走近，才发现那该死的所谓“风中残灯”其实是液晶显示屏上放的.gif动画！</p><p>原本在地上摊成一坨烂肉的杨帝，突然跳起身，拍拍身子。</p><p>他仍然是一脸痛苦和疲惫模样，但仍倔强地站着说话：“我们可以理智冷静、秉持合作共赢的多边主义友好态度谈谈吗？”</p><p>杨帝其实已经完全免疫归墟大帝的劈砍。</p><p>他身上的伤口，完全是体内的虚无本源的作祟罢了。</p><p>但他保持着挨打的被动姿势，其实是希望归墟大帝能像每一个合格的“反派”那样，站在奄奄一息的“正派”面前，将自己的所有计划、所有打算全盘托出。</p><p>但很可惜，归墟大帝缄口莫言。</p><p>并没有将自己的所有计划、所有打算全盘托出。只是一味徒劳地砍人。</p><p>显然不是个合格的反派。</p><p>杨帝刚刚抛出“合作共赢”的橄榄枝。</p><p>归墟大帝就一口回绝：“不可能！！宇宙之间，从来都是你死我活的黑暗森林状态！！”</p><p>说完又冲上前砍了两斧子。</p><p>根据本地土著大能青丘白璃的叙述，归墟大帝并不像是会说出这种话的人。</p><p>归墟大帝，不是归墟大帝。</p><p>他真的和曾经抗击域外天魔，整顿灵凡二界风纪的大帝，完全判若两人了。</p><p>杨帝站在原处，浑身浴血地说：“大帝！你可曾憎恶这个世界？”</p><p>“……”</p><p>“你经历过背叛吗？”</p><p>“……”</p><p>“归墟大帝，回答我！！阴伏流煞真不是你投放的？我已是将死之人，你不必再隐瞒。”</p><p>白杨大帝一边吐血，一边质问。</p><p>归墟大帝一边喘气，一边皱眉。</p><p>“阴伏流煞不是我部署的。”他脱口而出回答道，随即又困惑地闭上嘴。</p><p>杨帝已经感受到了。</p><p>整整3分钟，180秒，他终于用1500亿的话术属性，磨灭了归墟大帝的心理防线。</p><p>“大帝！你可曾憎恶这个世界？”</p><p>“未曾。”</p><p>“你经历过背叛吗？”</p><p>“没有。”</p><p>“阴伏流煞是不是你投放的？”</p><p>“不是。”</p><p>“你和三天前的归墟大帝，是同一个人吗？”</p><p>“……不是。”</p><p>杨帝心神微震。归墟大帝，被夺舍了？！一出狸猫换太子！？</p><p>吼——！</p><p>灵茶山乂斧上的暗紫弱水如同沸腾的毒沼，归墟大帝周身燃烧起近乎自毁般的灵能。</p><p>大帝不再言语，眼中只剩下纯粹的、要将一切存在都拖入归墟的疯狂！</p><p>巨斧撕裂空间，带着比之前任何一击都要决绝、都要暴戾的威势，朝着杨帝的头颅、心脏、周身要害，化作一片遮天蔽日的毁灭风暴，疯狂倾泻！</p><p>斧影漫天，弱水如瀑。</p><p>创世之斧，崩碎星辰，虚无本源，消融万物。</p><p>归墟大帝仿佛要将这片天地，连同杨帝一起劈碎，彻底抹去那令他心神不宁的存在。</p><p>杨帝站在原地，周身依旧是被虚无本源侵蚀出的恐怖伤口，血如泉涌，白骨森然。</p><p>然而，在那破碎的胸膛之下，那团坍缩又爆发的“心脏”，其跳动的声音却穿透了血肉撕裂的噪音，在帝霸阁内低沉地回荡起来。</p><p>咚……咚……咚……</p><p>声音并不响亮，却带着奇特的韵律，每次跳动似是敲打在空间的鼓面上。</p><p>杨帝低垂的头颅缓缓抬起。</p><p>那双被血污黏连的眼眸中，痛苦、疲惫、甚至是那丝刻意维持的“绝望”如潮水般褪去。</p><p>取而代之的，是一种极致的冷静。</p><p>冷眼之下，是宛如宇宙核心般冰冷而磅礴的意志。</p><p>他看着眼前只知挥斧劈砍的归墟大帝，看着那曾经统御灵界、威压寰宇的身影，此刻只剩下被仇恨和恐惧扭曲的躯壳。</p><p>“归墟大帝，”杨帝的声音异常清晰，穿透了斧刃破空的尖啸和能量爆裂的轰鸣，平静得没有一丝波澜，“你累了，我批准你无限期休假。”</p><p>话音落下的瞬间，时间仿佛被无限拉长。</p><p>他没有躲避。</p><p>没有格挡。</p><p>杨帝残破的身躯上，爆发出无与伦比的璀璨银辉！</p><p>他身上那些深可见骨、被归墟弱水腐蚀得焦黑翻卷、甚至流淌着暗紫毒液的恐怖伤口，以肉眼无法捕捉的速度痊愈。</p><p>仅仅是一个呼吸的转换。</p><p>不再是遍体鳞伤、气若游丝的将死之人，而是焕然一新，气息内敛却深如渊海。</p><p>连破碎的衣衫，都在银辉流转中恢复如新，纤尘不染。</p><p>杨帝低头看了看自己完好无损、甚至隐隐透出更强大力量感的拳头。</p><p>又抬眼望向归墟大帝。</p><p>大帝一脸震惊根本掩饰不了。这或许是他证道仙帝后，第一次如此失态。</p><p>杨帝对着那漫天倾泻、足以开天辟地的斧影洪流，向前递出一拳。</p><p>拳锋所过之处，时空被抹去，留下一条纯净到令人心悸的虚无轨迹。</p><p>那狂暴劈落的巨斧虚影，那粘稠腐蚀的归墟弱水，在触及这拳锋轨迹的刹那，连一丝涟漪都未能激起，便如同投入熔炉的冰雪，无声无息地湮灭消解。</p><p>归墟大帝眼中疯狂的杀意瞬间凝固，被一种源自生命本能的，最深沉的恐惧所取代。</p><p>他看到了那拳头，看到了那拳头后方杨帝平静无波的眼神。他想要嘶吼，想要爆发，想要调动整个归墟帝霸阁的无尽灵能……但一切念头都来不及。</p><p>没有声音。接触的瞬间，没有巨响。</p><p>只有一声极其轻微的、如同琉璃破碎的“咔嚓”声。</p><p>咔——</p><p>那把「灵茶山乂斧」从被拳头击中的那一点开始，像被投入烈火的画卷，焦黑、卷曲，化为连尘埃都算不上的基本粒子。</p><p>湮灭的过程并非爆炸性的扩散，而是以绝对不可逆转的方式，瞬间完成。</p><p>漫天斧影，那滔天弱水，那笼罩帝霸阁的恐怖威压……</p><p>嚓——</p><p>在杨帝这一拳之下，如同从未存在过一般，烟消云散。</p><p>帝霸阁，顶层。</p><p>杨帝的拳头，在归墟大帝鼻子前停下。</p><p>他收起拳头，将手搭在大帝的肩膀上。</p><p>“你不是归墟大帝，你是何人？回答我。”</p><p>大帝虽已完全失去招架之力，但在此刻，他既不回答，也不反抗，而是歇斯底里吼笑起来。</p><p>“竟然被识破了……那便再无隐藏必要。我还会回来。”</p><p>啵。</p><p>归墟大帝，在杨帝眼皮子底下消失，他的气息也随即无影无踪。</p><p>杨帝空有一身超级肌肉，却留不住他。</p><p>他才发现自己的短板——竟然没有几个好用的嘲讽技能！</p>
