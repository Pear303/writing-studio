# 面见圣树

<p>第一头熔岩史莱姆触碰到圣树领地。</p><p>第一万头熔岩史莱姆侵入圣树领地。</p><p>下一刻，天空炸开刺目的银光——数百只通体雪白的巨鸮如离弦之箭俯冲而下，振翅发出尖锐啼鸣。</p><p>它们周身迸发出足以冻结岩浆的极寒雾气，直接冲向涌进来的史莱姆群。</p><p>整片熔岩史莱姆集群，顿时被翻滚的寒冷白雾笼罩。</p><p>奥拓瞪大双眼，看着雪鸮群如训练有素的军队般结成阵型。</p><p>“那是雪鸮，人工炼金生命，原本计划用于猎杀焚灭天空之龙·卡利斯托——因为那头巨龙虽然能喷火取暖，但本质上还是冷血动物，爬行类的近亲，生性怕冷。后来一直没有派上用场，没想到今天，它们居然能有大作用。”</p><p>杨帝说这熟悉的很啊。</p><p>这不就是自杀无人机嘛！</p><p>短短几分钟内，原本气势汹汹的万头熔岩史莱姆，已化作地上一片暗红的冰晶残骸。</p><p>而后方，绝大部分熔岩史莱姆没能抓住机会冲进圣树屏障。</p><p>它们撞在屏障上，发出刺耳尖叫，浓稠黏液在光幕上滋滋作响，蒸腾起刺鼻的白雾。</p><p>随后，它们的胶质身体在一声爆鸣过后，化作岩浆。</p><p>却始终无法突破圣树护盾分毫。</p><p>杨帝想到了他看过的丧尸电影。</p><p>亿万只史莱姆，不要命地冲击屏障。</p><p>前方的熔岩史莱姆爆裂，化作一滩熔岩，后方的紧接着填补上，永远不会留下空档。</p><p>不远处传来一声震耳欲聋的咆哮——整片史莱姆浪潮被搅动，竟堆叠成一座数百米高的液态火山！</p><p>顶端的熔岩史莱姆不断分裂重组，最终凝结成一只熔岩与烈火组成的巨手！</p><p>巨手之上，熔岩如沸腾的血液般翻滚涌动，每一滴溅落之处，大地便被灼出深深的坑洞，滚烫的岩浆四溢横流。</p><p>史莱姆凝聚的巨手伸到什么地方，哪里的毁灭性灵能就泛滥成灾！</p><p>它所过之处，空气都被点燃，扭曲变形，发出痛苦的“滋滋”声。</p><p>它裹挟毁天灭地的气势，朝着圣树护盾轰然拍下——</p><p>整片平原都被染成白昼。</p><p>“轰————！！！”</p><p>即使隔着圣树护盾，他们仍被这场爆炸震得耳膜嗡鸣、大脑颤抖！</p><p>隔空受创最严重的是矮人奥拓。</p><p>他耳膜被高温与冲击波震得嗡嗡作响，大脑也因这恐怖的压迫感而一片空白，仿佛所有的思维都在这一瞬间被冻结。</p><p>他毕竟没有修为，身体和精神没有得到过灵能强化。</p><p>杨帝只好分润出部分灵能，模拟出驱风油的效果，在奥拓的太阳穴和人中处一抹，尝试吹散其笼罩在他脑海中的混沌与刺痛。</p><p>矮人的痛苦仍然不减。他颤抖的手抓住杨帝肩膀，口齿不清地说话：“With great power, comes great responsibility……”</p><p>奥拓把钻头递给杨帝，昏迷了过去。</p><p>“……”这体质不太行。杨帝拿着附魔狱髓钻头，默默地想。</p><p>“没事，昏迷的这两人都不会有生命危险，因为我们已经在圣树管辖区。”伊芙说。</p><p>万能的圣树，百科全书般博识的精灵。</p><p>待杨帝与伊芙视力慢慢恢复，二人才小心向身后瞥去一眼。</p><p>只见，圣树屏障终于发生了变化。</p><p>原本的淡绿色逐渐被黄色取代。</p><p>而在受击最严重的位置，黄色又慢慢过渡成令人不安的浅红色。</p><p>这些红色区域的光幕，隐隐约约摇摇欲坠。</p><p>仿佛整片光幕、整片天空都在燃烧，随时要化作流火坍塌而下！</p><p>“圣树屏障还能继续支撑。它的触须几乎扎遍整片大陆的地脉灵能枢纽，能够调动准行星级别的庞大灵能，一时半会儿还能维持住护盾，但拖久了就不好说……圣树说，它要立刻面见我们！”</p><p>随着他们深入，身后熔岩史莱姆对圣树屏障的冲击声也渐渐远去。</p><p>那仿佛能撕裂天地的咆哮和轰鸣声，慢慢变成了低沉的闷响，就像是一场遥远的噩梦，正在缓缓消散。</p><p>偶尔传来几声爆鸣，也如同残留在大脑褶皱之间的幻听，显得愈发微弱。</p><p>回头望去，只见那片由史莱姆汇聚而成的浪潮，此时已变成远方一片模糊光影。</p><p>杨帝这才最终确认，伊芙为什么执意要众人去往圣树森林的地域。</p><p>她是精灵，她知道此时此刻，只有这个地方是安全的了。</p><p>森林算是市区，不能像先前那样飙到500公里车速了。</p><p>伊芙放慢速度，回到120公里每小时，刚好是高速公路的车速上限。</p><p>她操控轿厢，直接冲往森林中央。</p><p>那儿，有一棵明显隆起的巨木。</p><p>根本不用猜，那就是圣树。</p><p>圣树要见他们……这个也不用思考，只可能与肆虐全大陆的熔岩史莱姆狂潮、乃至它们背后的金主“原初之眼”有关。</p><p>当灵能轿厢缓缓靠近那棵隆起的巨木时，周围的气氛愈发显得神秘而凝重。</p><p>圣树的树干粗壮得难以想象，树皮上布满了岁月的纹理，每一道纹路仿佛都在诉说着古老的故事。</p><p>树枝向四面八方伸展，宛如巨人的手臂，将这片森林庇护在其怀抱之中。</p><p>精灵从四处的树冠木屋中探出头来，沉默地注视、送行伊芙众人。</p><p>“这片森林本质上只有圣树一棵树。”</p><p>伸出手臂，挥向四方，“其他树木，在某种意义上都只是圣树的根。”</p><p>杨帝在地球也曾见过独木成林的奇景，那就是他老家附近的小鸟天堂。</p><p>那棵古榕树已有数百岁高龄，以一己之力撑起一片繁茂天地。它的气根从枝干上垂下，扎入泥土，又长成新树干，久而久之，竟占地数亩，远看如一座绿岛浮于水面。</p><p>虽说所处世界不同，但大自然的鬼斧神工，无论是在地球，还是在这片大陆，都有令人惊叹的相似之处——都很鬼斧，都很神工。</p><p>有一点不相似。</p><p>就是眼前的精灵圣树也忒特么大了。</p><p>小鸟天堂也才占地270多公顷，合2.7平方公里。</p><p>而这片圣树森林，占地……目前体感+观察地图比例尺，至少超过10万平方公里，也就是一整个浙江省的体量！</p><p>一棵树，占地整个浙江！</p><p>而现在，他们已经到了这棵树的最终本体面前。</p><p>杨帝、伊芙走出轿厢，仰头望着这棵参天巨木，心中满是敬畏。</p><p>杨帝回忆起精灵口述的历史——四万年前，“先天精灵”种下圣树。圣树不断发展，扩张，并诞下现世的精灵。</p><p>四万年！比华夏还老八倍。</p><p>此刻，树干上浮现出一张巨大的面容。</p><p>按道理说树上出现一张人脸是挺惊悚的，但眼前的面容慈祥而又庄重，双眼如同两汪深邃的池泊，反而给人慈眉善目之感。</p><p>这便是圣树的意识投影。</p><p>圣树的目光越过他们，望向那不断冲击屏障的史莱姆群，眼中闪过一丝忧虑。</p><p>它开口说话了，声音如同从远古传来的深沉回响，在空气中震颤。</p><p>“你们来了。我会将你们带到「无限机兵」所在之地，务必在原初之眼发现机兵之前，将其带走。”</p>
