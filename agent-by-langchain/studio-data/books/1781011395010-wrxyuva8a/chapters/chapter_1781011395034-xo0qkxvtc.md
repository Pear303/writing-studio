# 再探旧校区2

<p>“看这儿。”胡彦卓指着墙面。</p><p>藤蔓从三楼垂挂而下，在晨雾中泛着湿润的青色。</p><p>杨帝凑近细看。藤蔓上缀着米粒大小的蓝花，花瓣薄如蝉翼，在微风中轻轻颤动。</p><p>“不是看花，是看藤蔓。”</p><p>胡彦卓攥住婴儿小臂粗的藤茎，指节因发力而泛白。</p><p>“一楼大门全锁着，一二楼窗户都装了防盗网。想进楼里，要么爬水管，要么爬这个。”</p><p>胡彦卓扯了扯有婴儿小臂粗的藤蔓，试了试结实程度。</p><p>藤蔓纹丝不动，岁月并未削弱它的生命力。</p><p>“这藤蔓，看着有些年头了。”</p><p>杨帝摸了摸藤蔓表面，粗糙的质感让他不禁想起了那些关于旧校区的都市传说。</p><p>胡彦卓将登山包甩上肩，单手抓住藤蔓根部，肌肉在红色运动衫下虬结。</p><p>晨雾沾湿了他的运动衫，布料紧贴脊背勾勒出绷紧的肌肉线条。</p><p>他右腿在发力时明显颤抖，却仍以惊人的速度向上攀升。藤蔓在晨风中轻晃，细碎的蓝花簌簌飘落下方，坠到杨帝肩头。</p><p>胡彦卓登顶，进到三楼。</p><p>杨帝也紧随其后，很快也爬了进去。</p><p>三楼里边有些破败。</p><p>两人穿过走廊，这儿也是劣质的瓷砖地板。</p><p>看样式，这里是旧的学生宿舍，房间门半掩，积灰的窗棂透出斑驳光线，空气中弥漫着久未人居的沉闷气息。</p><p>杨帝轻轻推开一扇半掩的门，门轴发出悠长的吱嘎声，已经很多年没上油。</p><p>室内光线昏暗，只有从破碎的玻璃窗外溜进的几缕路灯的光，勉强照亮室内轮廓。</p><p>“这里……好像比外面看起来还要荒凉。”</p><p>杨帝目光扫过一张张锈迹斑斑的铁床，床上铺着早已褪色的床单。</p><p>室内大部分生活用品早就被清空，看起来是有序撤走的。</p><p>但还是残留了些衣服裤子，很有年代感的红白蓝蛇皮袋，缺了个角的白底红字搪瓷杯。</p><p>一脚踩下去，碾碎了堆积半厘米厚的灰雪。</p><p>墙皮剥落处露出泛黄的报纸残页，墨迹模糊的“稷海理工学报”字样。</p><p>“好东西早就被‘摸金校尉’摸完了，剩下都是些烂布。”</p><p>胡彦卓也随着杨帝走入宿舍，“而且这里是男寝，男寝能有什么看头，走吧。”</p><p>“摸金校尉？”</p><p>“就是些跑来旧校区‘探宝’的人，这几栋楼废弃十几年了，稍微有点价值的旧物什，早被搜刮完了。”</p><p>出了宿舍，继续沿走廊走，过道尽头的声控灯早就坏掉。</p><p>饮水机很久没开，水龙头流出的也是锈水，过道的窗户玻璃大多已破碎，冷风夹杂着雾气灌进来，让人打寒颤。</p><p>楼梯在走廊两侧，沿楼梯而上，一路走到到达次顶楼。</p><p>而通往顶楼天台的铁门，奇迹般的没锁。</p><p>门歪斜地挂着，褪色封条如蜕皮般耷拉。</p><p>“估计是哪个探险前辈砸开的。”胡彦卓踢了踢地上扭曲的锁头。</p><p>旧校区废置之后，经常有学生溜进来，把这儿当自己老巢。</p><p>直到WiFi和个人手机全面普及，吃饱了撑的大学生有了新的可宣泄精力之地方，闲着没事跑旧校区的现象才逐年减少。</p><p>二人穿过顶楼铁门，来到天台。</p><p>胡彦卓用登山靴碾碎一块松动的混凝土，碎屑滚落天台的排水口，手指指向东北角。</p><p>天台东北隅，缺角搪瓷缸盛着雨水，倒映着支离破碎的晨曦。</p><p>杨帝的手机震动——导员的消息跳出来：“杨帝同学，有医务室证明吗？”</p><p>此时距离他以“家族遗传性梦游症复发”为由请假，刚过去两个多小时。</p><p>他能清晰感觉到，屏幕对面导员的面色多么古怪。</p><p>杨帝飞速打字：“导员您看，这种精神类怪病，学校医务室是很难开证明出来的吧。”</p><p>导员：“上次你说急性肠胃炎，上上次是偏头痛……”</p><p>杨帝咬牙切齿地发了个微笑表情：“[微笑]只要导员批准，我现在就能表演个当场梦游。说实在话，我之前凌晨3点多还没睡着，就是因为梦游了起来。”</p><p>最后假条还是开下来了，毕竟都是成年人，学生的私事导员也不会过多干涉。</p><p>胡彦卓看过来：“咋了？”</p><p>杨帝摇摇头：“只是和导员请个假而已。”</p><p>二人一前一后继续走，到了天台边缘。</p><p>胡彦卓指向天台东北角。</p><p>那里有一道不足三米的横向落差，连接着另一栋稍矮的教学楼。</p><p>他解释，两年前，正是在这个位置，他的跑酷生涯遭遇了滑铁卢。</p><p>下方是丛生的杂草与破碎的建筑废料，在晨光下显露出粗粝的真实质感。</p><p>六楼如果直接摔到水泥地面，那大概率一命呜呼，不可能仅仅是髋关节骨折。</p><p>胡彦卓指了指不远处，一根锈迹斑斑的铁栏杆。</p><p>“两年前，在坠落的前一刻，我抓住了那边的栏杆，这才没有当场摔死。”</p><p>“但是，那股冲击力还是让我的髋关节受了重伤，休养了大半年才勉强恢复。”</p><p>他很遗憾的样子，叹息道，“有些记不清那一天的情况，记不清那根电缆是怎么出现的。”</p><p>胡彦卓退后两步，开始助跑。</p><p>他右腿在发力时仍有轻微颤抖，但动作却流畅得如同猎豹掠过岩脊。</p><p>运动鞋与混凝土摩擦出低沉的啸声，他跃向空中，红色运动衫鼓胀如帆，仿佛要将整个黎明都收进胸怀。</p><p>跳跃，越过两栋楼之间的峡谷，落地。</p><p>冲击让胡彦卓的右腿一软，但他迅速调整重心，像棵被飓风折弯的红松般重新挺直。</p><p>他稳稳停在对面那栋楼顶上。</p><p>胡彦卓的声音里，带着某种解脱后的轻松：“杨帝老弟，这一跳很安全，很简单……我终于感觉到释怀了。”</p><p>杨帝默默点头。</p><p>他注意到胡彦卓落地的位置附近，确实散落着几段早已锈蚀的电缆。</p><p>但它们都躺在尘埃里，丝毫没有凌空悬垂的迹象。</p><p>两年前，他是怎么被绊倒的？</p><p>除非那几个电缆腾到了空中，否则，以胡彦卓的体能和经验，失误实在有些蹊跷。</p><p>而且……他不知道该不该提出来。</p><p>杨帝还发现另一件事：这几根电缆都是深红色的，并非黑色。</p><p>“杨帝老弟，要跳过来吗？不行我下楼找你。”胡彦卓喊道。</p><p>“不用，我已经看完跑酷基础教程了，懂一点点怎么跑跳。”</p><p>闻言，胡彦卓脸上仍然挂着的担忧。</p><p>毕竟理论和实践是分开的，看完“跑酷基础教程”视频，并不代表已经有了相应的体能和肌肉记忆。</p><p>杨帝只是默默将背包扔对面楼顶，深吸一口气，模仿着胡彦卓的动作开始助跑。</p><p>心脏在胸腔里狂跳，仿佛要撞碎肋骨。</p><p>说实话，他有恐高。</p><p>但当身体腾空，所有恐惧都被晨风卷走。</p><p>他看见初升太阳正将地平线染成熔金，旧校区的建筑群在脚下铺展开来。</p><p>腾空跳跃的半秒，没有绊到电缆，没有绊到任何牛鬼蛇神。</p><p>他松了口气。</p><p>落地时的冲击力让杨帝踉跄了几步，但很快胡彦卓扶住他，稳住身形。</p><p>“第一次跳成这样，够意思！”胡彦卓递来一瓶矿泉水。</p><p>杨帝喝水吨吨吨。</p><p>胡彦卓继续说：“知道吗，老弟，当年我在这儿摔断屁股时，以为自己永远都站不起来了。那些夜晚，我一遍遍地回想那个瞬间，总觉得有什么东西在暗中操控着一切。”</p><p>他停顿了一下，目光投向远方：“但现在看来，不过是巧合罢了。红气球是哪个孩子不小心放飞的。冰寒的空气是保温性能良好的钢筋水泥建筑内部，偶尔涌出的冷量。而那根电线……大概是被风刮下来的……”</p>
