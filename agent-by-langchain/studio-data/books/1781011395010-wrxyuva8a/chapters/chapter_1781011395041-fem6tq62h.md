# 后天性短尾狸花猫

<p>杨帝从背包里摸出三包压缩饼干，递给胡彦卓一包，希夷一包。</p><p>狸花猫蹲在两人中间，短尾巴竖直向天。</p><p>“老大，我现在是猫体，不需要吃人类的食物喵。”希夷用爪子拍了拍杨帝的小腿。</p><p>“少废话，补充体力要紧。”杨帝撕开包装，饼干碎渣簌簌落在满是灰尘的地面。</p><p>胡彦卓也啃着饼干，目光在竖井壁上逡巡：“这梯子少说有4米高，叠罗汉行不通，可附近也没什么杂物，比如说木箱子铁架子……”</p><p>杨帝：“没事，待会把希夷当梯子用。”</p><p>短尾狸花猫炸毛后退两步：“呱！老大你当我是变形金刚吗喵？”</p><p>杨帝咽下饼干，生啖蛋白粉，抹了把嘴：“希夷，你之前说这身体是空壳，谁都能开的EVA，为什么在‘当人梯’这件事上畏畏缩缩嘞？”</p><p>希夷看起来有话却难言。</p><p>它最后还是嚅嗫道：“老大，我现在已经适应了有脊椎动物的身体，随便变形总觉得会闪到腰……”</p><p>这种借口根本算不上理由。</p><p>在杨帝的淫威压迫下，狸花猫进化出Doublethink，强行纠正了自己的错误心态，并自发认为自己是软体动物。</p><p>“那我开始变形了吧。”</p><p>雾气中，短尾狸花猫的身体开始扭曲膨胀，骨骼发出令人牙酸的咔咔声。</p><p>最终，它变成了一个直径半米的黑色玩意，表面浮现出类似睡莲的圆盘结构。</p><p>希夷的声音从黏液中闷闷传来：“愣着干什么！踩上来，我把你们弹上去喵！”</p><p>“胡哥，我先来。”</p><p>杨帝当先踏上圆盘，黏液立刻包裹住鞋底，提供了惊人的摩擦力。</p><p>“抓好了！”希夷的声音陡然拔高，圆盘底部伸出数十根触须扎进地面，如同弹簧般压缩蓄力。</p><p>下一秒，圆盘以惊人的速度弹射升空！</p><p>它在竖井壁上借力反弹，如同巨型跳蚤般连续跳跃。</p><p>杨帝成功抓到了竖井的断梯。</p><p>希夷像一团失去所有力气的烂泥，流淌回到了地上，但很快又恢复弹性。</p><p>“老大他的便宜师傅，到你了喵！”</p><p>“便宜师傅？我？”胡彦卓迟疑片刻，确认这猫指的是自己，才有些犹豫地站到它身上。</p><p>希夷故技重施，史莱姆似的再次一跃而上。</p><p>“DUANG～DUANG～DUANG～”</p><p>胡彦卓抓住断梯，嘴里叼着手电筒，攀上竖井顶部。</p><p>但刚刚探出头来，看见杨帝背对自己，全身肌肉紧绷如弓弦，指尖几乎要将撬棍捏出裂痕。</p><p>咔嗒，轻微的一声响，他手电筒被拍杨帝关掉了。</p><p>怎么了？胡彦卓低声问。</p><p>杨帝把胡彦卓拉上来，快速在他手心上写下三个字“血腥味”。</p><p>没错，空气中漫着某股若有似无的血腥味，非常细微。</p><p>希夷也无声地变幻为短尾狸花猫模样，凑到杨帝脚边。</p><p>肉身变形，对于它来说似乎非常消耗精力。</p><p>短尾狸花猫希夷蹲坐在地上，喘着粗气，小舌头微微伸出，眼睛却警惕地四处张望。</p><p>杨帝通过精神交流，无声地询问：</p><p>“希夷，有没有发现什么？”</p><p>“老大，我这肉身素质和普通的猫一样，到了太黑的地方，也是两眼一抓瞎喵。”</p><p>杨帝的呼吸声渐趋平缓，他将意识沉入潜意识的深海，让占潜意识2%的算力，疯狂解析周围每一丝异动。</p><p>黑暗中，他听见胡彦卓喉间滚动的吞咽声，听见希夷爪子在地面刮擦的细响，甚至听见自己睫毛扫过皮肤的窸窣。</p><p>时间在耳鸣中被无限拉长。</p><p>直到所有非自然的声响，都被过滤殆尽。</p><p>他才缓缓松开紧扣胡彦卓手腕的手指。</p><p>咔嗒。</p><p>手电筒的光束重新刺破黑暗，在斑驳的墙面上投下摇晃的影子。</p><p>“没事了胡哥，现在可以呼吸了。”</p><p>胡彦卓这才如释重负：“确认安全？”</p><p>杨帝点点头：“没错，这里只有我们俩人和狸花猫的呼吸声，没有另外第四个存在。”</p><p>手电筒向四周扫视一圈，然后照亮了脚下。</p><p>——水泥地面上，凝固着半干涸的血渍，呈喷射状向右侧延伸，边缘略微发黑。</p><p>创口似乎是被类似于螺丝刀、圆锥这类锐器所致，因为血迹向四周溅射，形成的是规则的扇形。</p><p>胡彦卓的瞳孔在强光下收缩：“这血……至少有一个小时，但应该不到两个小时。”</p><p>杨帝的撬棍突然顿住，尖端挑起一根缠绕在血渍中的白色绒毛。</p><p>他半跪在地上，指尖几乎贴着地面，潜意识将毛发的每一丝纹理都放大成高清图像：</p><p>绒毛根部沾着暗褐色血痂。</p><p>毛尖泛着白色，是某种哺乳动物的体毛。</p><p>杨帝仅仅是观察能力敏锐，不意味着他无师自通生物学知识，只能下一个草率的结论：“不是人类，不清楚是什么动物的。”</p><p>他们的疑惑很快有了答案。</p><p>不仅知道了是哪种动物留下的血液。</p><p>甚至精确到“是哪只动物”……</p><p>……</p><p>循着臭味另一个源头，杨帝等人来到角落，持撬棍挑开地上一张可疑的防水布。</p><p>手电筒光束里，半截毛茸茸的白色尾巴蜷缩在血痕中。</p><p>同样是比较新鲜的血迹，不到两个小时前留下的。</p><p>尾巴根部的黑色环纹，与希夷如今的短尾尖儿如出一辙。</p><p>希夷喉咙里发出幼猫般的呜咽，爪子死死抠住杨帝裤脚，瞳孔缩成细缝。</p><p>“毛色、尾环，和希夷你的一样……”</p><p>杨帝用撬棍拨动着地上那半截尾巴，根部的锯齿状断口还残留着暗褐色血痂。</p><p>两个人类同时看向希夷。</p><p>“这是你的尾巴，希夷……至少是你现在这具身体的尾巴。”</p><p>杨帝很难过地看着它。</p><p>这猫的身体根本不是天生短尾，而是有人把它的尾巴活生生扯下来了！</p><p>希夷：“这种事情，不要啊——”</p><p>它跳上防水布，爪子扒拉尾巴，想把它重新接回自己臀部。</p><p>杨帝按住它颤抖的脊背：“冷静，人死不能复生，尾断不能重接，默哀。”</p><p>杨、胡二人轮流上前去撸猫，快要把它背上的毛都薅平了。</p><p>希夷渐渐恢复了冷静。</p><p>它接受了现实。</p><p>“我也不知道为什么，老大……我刚才有一种直冲脑门的冲动，就是非常不想死喵。看到自己的身体碎块，我真的很害怕，我好像——我不知道怎么说——我好像已经死过一次，甚至不止一次了喵。”</p><p>一簇灵感的闪电划过杨帝脑海。</p><p>他想到上一回做梦，梦里的灰袍甘道夫对他说：</p><p>「它（希夷）是一名浑浑噩噩的逝者……」</p><p>所以……希夷其实是已经死过了的人，或者是死掉了的东西……</p><p>它真就是一只鬼？！</p><p>“希夷，你说为什么，这只狸花猫被扯断尾巴、再出现在我们面前时……它就变成了黑色拉面团一样的怪物？”</p><p>“老大，我也不知道喵……”</p><p>杨帝迅速还原出当时的场景：</p><p>狸花猫看到他们后，惊叫地跑下楼梯。</p><p>狸花猫被某人或某种动物扯断尾巴，在此地留下血渍。</p><p>狸花猫又回到楼梯，变成蠕动的黑色拉面团“哈基面”。</p><p>这其中发生了什么？</p><p>“杨帝兄弟，还希夷……有新发现，你过来看一下，和你有关的。”</p><p>胡彦卓的声音打断了他们的思绪。</p><p>他声音好像有些许紧张，这可不常见。</p><p>刚才，杨帝只是掀开了防水布的一角，发现了那半截断掉的尾巴。</p><p>而现在，胡彦卓把整张蓝色防水布都掀了起来。</p><p>除了断尾，下面还盖住了一样东西。</p><p>——用散发着血腥味的红色可疑液体，在地上画的图案。</p><p>由三条曲线组成的漩涡。</p>
