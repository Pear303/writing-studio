# 万古鱼尊！

<p>那道身影降临的瞬间，整个时空的逻辑都开始扭曲。</p><p>午夜的月光不再是月光，而是无数眼睛的反光。</p><p>空气里凝结着某种低声絮语，像是远古祭坛上被献祭的语言……</p><p>银质勋章并非被“放置”在巴德手中，而是世界线本身被强行改写，让勋章以某种超越因果律的方式天然存在于那里。</p><p>改写了……历史？</p><p>阿巴作为灵能丰度25000的可怖存在，此刻它却像被攥在孩童掌心的蝌蚪。</p><p>大气不敢从鱼鳃出一口。</p><p>那尊存在泄露的灵压，如同撕裂现实的利刃，其量级甚至难以用日常语言丈量——仅仅是微不足道的一丝一毫，就远远远远远远远远超过十万亿灵。</p><p>阿巴在其面前，不过是深渊里浮起的泡沫，永夜中偶然掠过的磷火。</p><p>这个世界，存在一个……东西。</p><p>整个世界的规则在那身影面前如同沙砌的城堡，而宇宙不过是某个数值怪指甲缝里的尘埃。</p><p>十环法师级别的灵能，也许只是数值怪划定的游戏刻度。</p><p>窥见禁忌的阿巴，不敢再多想。</p><p>她已知道，这个世界的皮下，蠕动着一个无法用任何文明语言描述的“数值怪”。</p><p>那个东西，正在用自己的方式改写历史……</p><p>“不能动，不能动……”</p><p>阿巴蜷缩在灵能潮汐褪去的废墟中，鳃盖剧烈开合着吞吐浑浊的空气。</p><p>她鳞片下蛰伏的25000单位灵能此刻如将熄的烛火，在那道身影遗留的威压余韵里瑟瑟。</p><p>直到七七四十九天后，圣骑士巴德的头七都已经进行了7次。</p><p>阿巴才缓缓回过神来。</p><p>还是人鱼公主叫醒她的。</p><p>“对不起，公主，我要离开了。”</p><p>阿巴置死地而后生。</p><p>只有直面过世间最宏大的风景，才能超新星爆于眼前而面不改色。</p><p>修炼变强，抵达极限，登顶巅峰。</p><p>炼精化气，炼气化神，炼神返虚……</p><p>炼虚合道，虚空粉碎，位证真仙……</p><p>鱼尊阿巴已经完成多元归一的修炼，渡过天人五衰，跳出时间长河，将过去未来集于一身，步入太乙真仙大圆满。</p><p>只余半步，便可摘取大罗道果。</p><p>然而，她在与「守望者文明」争夺「大罗道果」（对方则称之为“最终观测者权柄”）之时，守望者舰队的至强法则神兵“熵劫战锤”在她胸前留下一道极其恐怖的创伤。</p><p>直到现在，那道伤口仍在不断蚕食其道基。</p><p>这是鱼尊证道太乙真仙大圆满以来，遭遇的最惨烈一战！</p><p>她甚至被迫回到自己还是条淡水鱼时候的时间点，那时候，她才三天大。</p><p>阿巴在这个极度脆弱的时间点，陷入沉眠足足20分钟。</p><p>如果这时候，有人把她钓上来，或者用板砖将她拍上来，火上烤吃掉。</p><p>那鱼尊将会永远死亡。</p><p>一证永证，一死永死。</p><p>假如瑞弗维尔·兰斯洛特在河边扎营的那一天，真的下河抓捕到了刚刚历经宇宙大战、极度虚弱的「鱼尊」阿巴，并将其架在火上烤来吃。</p><p>瑞弗维尔，将会成为本世界线、这个时间点第二个以凡俗之躯吃掉神明，的，凡人。</p><p>幸好，在这个世界线上，瑞弗维尔身边没有钓鱼爱好者。</p><p>她熬过了最艰难的20分钟。</p><p>现在，鱼尊即将要恢复到全盛状态——这就是太乙真仙的权柄，滴血重生，永恒不朽。</p><p>“守望者，该算账了。”阿巴眼中的竖瞳燃起紫色业火。</p><p>她跳上岸，鱼尾扫过之处，时空长河被撕开百丈裂口。</p><p>无数时间碎片从裂缝中涌出，在她周身旋绕成螺旋状传送门。</p><p>鱼鳍最后一次摆动，整片河水，包括飘飞的落樱，万物瞬间冻结！</p><p>阿巴的身形裹挟着破碎时空，消失在散发着臭氧气息的裂隙之中。</p><p>1000亿年后的战场上，守望者母舰的主炮刚刚蓄能完毕。</p><p>下一刻，一道银色巨影撞碎星系屏障！</p><p>阿巴周身缠绕着复仇雷霆，化作一尊横跨星河的巨鱼，举手投足间撕裂现实与虚幻的界限，仿佛随时会将守望者舰队咬碎在鱼嘴里！</p><p>她张开足以吞噬恒星的巨口，冲向守望者母舰，沿途以20万亿倍光速撞碎七八百个星系。</p><p>但下一刻，万千法则兵器自虚空中浮现——守望者文明的舰队前来支援了。</p><p>守望者的决战旗舰编队。</p><p>每一支舰队包括一艘333万公里规模的决战旗舰，千余座中子战星护卫侧翼，以及百万规模级的战巡舰、千万规模的护航舰。</p><p>在这个宇宙，守望者文明是最巅峰的势力，他们再将自己的技术磨练到登峰造极之时，成功利用FTL装置改造的宇宙大爆炸初期的环境，使他们自身在宇宙诞生的极短时间内，就从时空瑕疵中演化出“肉身成圣”级别的物质身体，以及媲美2.5级文明计算机的精神智慧。</p><p>不断将技术资料回传到过去，不断将亟待解惑的问题发送至未来……</p><p>他们在超过三百万轮技术迭代后，触及本宇宙科学力量所能达到的顶点。</p><p>万物的答案，已在守望者眼前徐徐展开。</p><p>守望者文明只剩下一个目的，只剩下最后的问题——</p><p>宇宙将走向死亡，他们何去何从？</p><p>他们的超级计算机“深思”最终给出解答——存活至历史的终结，取得“最终观测者权柄”（那尊星空巨鱼称之为「大罗道果」）。</p><p>然后，将万千条离散的世界线、割裂的宇宙快照，确定为唯一的历史。</p><p>宇宙中所有的物质，每一个事件，任意一种可能情况，都是沙海中一粒微渺至极的沙子。</p><p>守望者不断穿梭各种“沙子”，以违反因果律的效果穿越时间，才有了今日这一切成就。</p><p>但这般成就，必须被固定下来。</p><p>否则，这段漫长的历史就仅仅是宇宙一个幻梦泡影。</p><p>只消被风一吹，由脆弱的发丝连合起来的沙子，顷刻间将会倾覆于无。</p><p>守望着文明的科学家，指出了这个恐怖的可能性。</p><p>他们必须为了文明的未来，为生命的意义，为智慧的存续而战。</p><p>鱼尊阿巴，就是他们必须清除的巨大威胁。</p><p>「超相对论导弹准备就绪。」</p><p>「全舰队，集火。」</p><p>「湮灭光矛已发射，命中率99.52%」</p><p>「确认世界线变动，开启本体论稳定器补偿修正。」</p><p>鱼尊穿越来便被大把舰队集火。阿巴仰天长啸，头顶浮现出贯穿过去未来的永恒道体。</p><p>她的伤口处却不溢出灵能，反而喷涌出某种混沌鸿蒙之气，将整片战场染成灰蒙蒙的海。</p><p>守望者舰队瞬间解析出这片“灰色海洋”的成分。</p><p>「1级物质分类：基础物质态」</p><p>「2级物质分类：凝聚态物质-液态」</p><p>「3级物质分类：分子晶体流体」</p><p>「4级物质分类：非离子型极性分子体系」</p><p>「5级物质分类：H2O二聚体主导的氢键网络，不含任何同位素杂质（D/H<10^-18）的理论纯水」</p><p>「经深度光谱分析与分子结构扫描，这片灰色海洋实则是普通的H2O，无任何同位素变异，无任何量子层面的能量波动，化学键稳定在常态数值，PH值精确为7，电导率近乎于零，无任何超凡物质或能量掺杂其中，完全等同于宇宙间最普通的纯水，不具备任何超越已知科学范畴的属性。」</p><p>「结论：无任何电磁极化、无夸克层级以上结构变化的凡俗物质，俗称‘纯水’。」</p><p>阿巴哈哈吼吼大笑。</p><p>“此乃‘太初溟濛域’，世间万法皆生于水，亦终将归于水。你们眼中的普通纯水，正是承载天道运转的母液！”</p><p>万古鱼尊，爽朗大笑，根本停不下来。</p><p>战斗果然是变强的催化剂。她终于学会释放「领域」了。</p>
