# 捕获

<p>车厢连接处传来“砰”的一声巨响，厚重的金属车门向内凹陷变形。</p><p>机械蠕虫那巨大、狰狞的钻头前端，已经顶在了车门上。</p><p>高速旋转的刀盘摩擦着钢铁，发出刺耳的尖叫，火花四溅。</p><p>透过变形的门缝，能看到钻头后面巨大复眼传感器发出的冰冷红光，如同深渊巨兽的凝视。</p><p>一股无形的、狂暴的电子脉冲波瞬间席卷了整个车厢！</p><p>“安保队直接动用EMP了？”杨帝佩服他们的魄力（或者说破坏力），毕竟这火车上的顾客都有手机，火车设备本身也价值不菲，事后必定要赔付一大笔钱。</p><p>为何要如此大动干戈？</p><p>灯光彻底熄灭，所有电子屏幕瞬间黑屏，应急灯也闪烁不定。</p><p>乘客们的手机、平板等设备直接报废，冒出青烟。</p><p>这是EMP的作用，炸掉所有电子设备。</p><p>巨大的失控盾构机，也随即停了下来。</p><p>「EMP生效了！目标停止活动！」车头方向传来安保队员扯嗓子喊道，带着一丝劫后余生的喘息。</p><p>然而，另一种东西在黑暗悄然出现了。</p><p>一股强烈的、混乱的、带着破坏和吞噬欲望的“意识流”，如同实质的狂风般冲撞着每个人的精神。</p><p>“有什么东西在游荡，你们感受到了吗？”</p><p>“没错，有些类似于‘元神’离体后的残念。”</p><p>原来如此。火车安保队并不是在与空气斗智斗勇，他们是在防止失控盾构机中某个“元神”顺着网线逃脱。</p><p>更准确来说，那是一个“数字生命”。</p><p>它以电磁波、电脉冲作为生命载体，似乎被安保队忌惮。</p><p>它本身就是个高度危险的、失控的电子幽灵！</p><p>但安保队员不知道的是，那“数字生命”在EMP脉冲爆发的前一刻，逃脱了。</p><p>此刻，一股强烈的、混乱的、带着被强制剥离躯壳的愤怒、破坏和吞噬欲望的“意识流”，如同冰冷的、无形的潮水，在绝对的黑暗中悄然弥漫开来。</p><p>它不再是依托庞大机械体的冲击波，而是在废墟中游荡的孤魂野鬼，寻找着新的宿主。</p><p>它掠过惊恐的凡人，掠过那四位伪装成老者的灰袍大能。</p><p>四人气息收敛完美无瑕，如同四块冰冷的顽石，但混乱的意识流还是本能地察觉到致命的危险，绕开了他们。</p><p>它掠过青丘白璃和阿巴时，感受到了强大的阻力，所以不敢动不敢动。</p><p>最终，它猛地锁定了角落里那个沉默的身影——方形坦克，59改！</p><p>此人的灵能水平不超过300灵，修为极低，大概也就炼气期水准。</p><p>而且，在混乱意识眼中，这个“人类”体内蕴藏无比庞大而精密的“神经网络”和“计算核心”，是它这濒临崩溃的机械意识最完美的寄生宿主！</p><p>远比那些脆弱的人类大脑和简单的安保装甲控制系统，要好无数倍。</p><p>“嗡——！”</p><p>一股比之前强烈数倍的精神冲击，凝聚成一道肉眼可见的、扭曲着数据流的惨白色光柱，精准地轰向方形坦克的脑袋。</p><p>这是孤注一掷的夺舍。</p><p>“不好！它的目标是铁罐！”阿巴趁机要一巴掌轰杀59改，公报私仇。</p><p>杨帝拉住万古鱼尊：“等等，别添乱。”</p><p>滋滋滋滋——</p><p>59改眼睛闪烁五光十色，夺舍之战，正进入白热化；钢铁的意志，正在对抗疯狂的钢铁。</p><p>就在阿巴忍不住又要开口声称“这铁疙瘩要炸了”的时候——</p><p>59改耳朵里喷出等离子火花，带着焦糊味和臭氧味。他举手，对杨帝比了个OK。</p><p>「目标已捕获。」</p><p>他所做的工作并不微小，相反还相当复杂。59改一方面要分出0.01%算力，抵御“数字生命”的强行入侵。</p><p>另一方面，还得用另外99.99%的计算资源迅速分析这个“数字生命”的组成和原理，构建出一个完备且稳定的虚拟空间框架。</p><p>那条野生的数字生命已经奄奄一息，多延迟一秒，它生命气息就多流逝一分。</p><p>这场较量实在是凶险万分。</p><p>59改只要稍有一个不留神、一个不注意，就会把“数字生命”给整死。</p><p>杨帝松了口气，问道：“很好。它有没有说什么？关于它自己？关于失控的原因？或者……关于这条铁路，甚至归墟大帝？它是不是就是不会黑手，它是不是一切灾祸的根源……”</p><p>59改的电子眼闪烁着平稳的蓝光，沉默了两秒，似乎在检索对话记录。</p><p>然后，他那充满“机器人刻板印象”的无机质合成音响起：</p><p>「目标意识体处于高度混乱、不稳定状态，当前不具备清晰表达与逻辑沟通能力。审讯尝试失败。」</p><p>59改汇报完毕，电子眼平静地看着杨帝，仿佛在说：该做的都做了，它就是个疯子，啥有用的都没说出来。</p><p>他能做的，就是精准捕获，然后如实汇报它获得的、分析出的、毫无情感修饰的数据。</p><p>显然，指望一个情商约等于零、思考方式完全是逻辑代码的59改，去“感化”或者“撬开”一个混乱数字生命的嘴，无异于缘木求鱼。</p><p>缘木求鱼……求鱼……鱼……</p><p>杨帝摆出碇源堂的唯一指定造型。</p><p>另外一鱼一狐一坦克不明所以，私下开小会议商量后，也做出了相同动作。</p><p>“学我者生像我者死……没事儿，只是想起一句有趣的话而已。”</p><p>杨帝恢复到正常坐姿。</p><p>“我大概有思路了，我会亲自审讯这个失控盾构机里蹦出的林妹妹，或许它嘴里有情报，就算没有情报，也当是聊天了……</p><p>“但问题在于我的精神力量比较不可名状，和我的精神体直接接触，可能会导致它，甚至是让大伙精神错乱。</p><p>“59改，开一个虚拟会议厅，我能够和那‘盾构机幽灵’面对面聊天。”</p><p>守望者·59改略微抬头，然后又比了个OK：</p><p>「我已结合当地土著的本土化技术，可以发出基于完全潜行技术的虚拟空间小程序，加装认知滤网防护系统，可有效阻止邪神随意传播恶意模因和过于海量庞大的知识。」</p><p>“你说得对，但我不是邪神。”</p><p>杨帝终归是有些悲哀的，居然被其他人称作邪神，活成了自己讨厌的模样。</p><p>但此刻并非纠结于此的时候，还有更重要的谜团亟待解开。</p><p>Link
