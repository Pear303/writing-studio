# 仙界之上，暂名神界

<p>仙界之上，按照惯例，暂名神界。</p><p>流光溢彩的虚空神殿，无数牌佬端坐云端，指尖流淌着法则凝成的卡牌。</p><p>决斗领域，浩瀚星图！</p><p>无数星辰、星云、乃至蜷缩的维度，都化作棋盘上闪耀的光点。</p><p>两位气息磅礴的牌佬，正进行着一场决定某片星域归属权的至高对决。</p><p>身披星辰光铠，面容冷峻：</p><p>“哼，欧米伽！你那依赖‘星尘虫群’的战术，在吾之绝对力量面前，不过是宇宙尘埃！吾之回合，抽卡！”</p><p>他指尖光芒暴涨，一张卡牌在星图中央具现，化作一条缠绕着苍白星焰、龙瞳冰冷俯瞰众生的恐怖巨龙虚影！</p><p>“现身吧！裁定星域之终焉的龙神「青白龙眼」！ 支付1000点‘神能’，发动其效果：‘龙威凝视’！ 此卡召唤成功时，选择你场上所有等级低于此卡的怪兽——抹除其存在！”</p><p>欧米伽周身环绕流动的液态法则，嘴角噙着玩味笑意：</p><p>“呵，阿尔法，你还是这般急躁。你以为我没有防备你的‘龙神’吗？”</p><p>欧米伽优雅地打了个响指，一张散发着诱人堕落气息的卡牌在他面前翻转。</p><p>“连锁发动陷阱卡——「绯蓝荔枝」！ 当对方发动以‘破坏’或‘除外’为效果的怪兽效果时方可发动！将你那只怪兽的效果——扭曲、反转、并以双倍的毁灭之力，回敬给你场上所有其他卡牌！ 你的‘青白龙眼’……现在要噬主了哦？”</p><p>阿尔法脸色剧变： “什么？！欧米伽，你这狡诈的……！”</p><p>欧米伽笑容更盛： “胜负已分！你的‘星域守护者’和‘次元锚点’将在你心爱龙神的吐息下化为虚无！然后，就是我的直接攻……”</p><p>——轰！！！</p><p>一声并非来自星图棋盘内的，沉闷却仿佛能撼动整个神殿基石的巨响——从某个被标注为“低等娱乐行星-编号XG-03”的遥远坐标点传来！</p><p>一股蛮横原始，充满了“掀桌子”气息的恐怖意志，瞬间撕裂了那行星脆弱的虚拟屏障，蛮横地挤入现实！</p><p>阿尔法和欧米伽同时感知，心神剧震：</p><p>“什么鬼东西？！”</p><p>“低等行星的桌游网页里……蹦出来个太乙真仙级大能？！”</p><p>“这股气息……充满破坏欲！它锁定了我们？！”</p><p>眼神瞬间交汇！</p><p>刚刚还在生死相搏的两位牌佬，在更高层次的威胁面前，达成了前所未有的默契！</p><p>阿尔法怒吼： “管他是什么！先联手摁死他！「青白龙眼」！目标变更！锁定那个非法入侵者！发动最终裁定——‘终焉星爆吐息’！”</p><p>欧米伽狞笑： “正合我意！「绯蓝荔枝」！效果持续，目标同步！让这扭曲的毁灭之力，成为埋葬他的双重奏！‘堕落双生·湮灭交响’！”</p><p>两位大能吼着中二台词，两张顶级卡牌的力量瞬间调转矛头！</p><p>「青白龙眼」的苍白星焰被「绯蓝荔枝」浸染成妖异的紫红，毁灭性的龙息与扭曲堕落的能量波完美融合。</p><p>化作一道贯穿星图，撕裂维度，足以将复数星系瞬间汽化成基本粒子的恐怖洪流，精准无比地轰向刚从网页像素点里蹦出来的杨帝！</p><p>面对这神明联手，足以改写宇宙规则的必杀一击……</p><p>杨帝迅速反应过来，抬头嗤笑一声：“花里胡哨。”</p><p>他甚至懒得看那毁天灭地的能量洪流一眼。</p><p>只是随意地抬起一只手，五指张开，虚空中抽出了一张印着“闪”字的，朴实无华到甚至有点土气的卡牌虚影！</p><p>三国杀经典“闪”卡样式！！</p><p>“‘闪’！” 杨帝的声音平淡无波，却带着一种绝对否定的意志。</p><p>——嗡！</p><p>奇迹发生了！</p><p>那道毁天灭地、融合了双重顶级卡牌伟力的「终焉星爆吐息·湮灭交响」，在即将触及杨帝身体的瞬间……</p><p>如同撞上了一堵无形的、绝对无法逾越的叹息之墙！</p><p>没有爆炸，没有冲击，没有能量逸散。</p><p>那道洪流就那么凭空消失了！</p><p>仿佛从未存在过！</p><p>仿佛它所有的“命中判定”都被那张轻飘飘的“闪”卡，以一种不讲道理的、近乎耍赖的方式完全无效化了。</p><p>“不……不可能！！！”</p><p>阿尔法和欧米伽眼珠子差点瞪出来，声音因为极致的惊骇而变调。</p><p>“ 他……他用了卡牌？那是什么卡？‘闪’？哪个神系的规则里有这种效果？！无效化顶级卡牌的融合攻击？！开什么星际玩笑！！”</p><p>神明们惊骇的面容定格。</p><p>杨帝收回那张虚幻的“闪”卡，仿佛只是掸了掸灰。</p><p>实则他心底也有些惊奇。</p><p>“妈耶，当我以强烈的决心要做出‘闪避’这一行为时，它居然具现化成一张卡牌，逼迫我打出去，才能触发这种效果？”</p><p>“这是否太玄幻，不科学？”</p><p>杨帝五指成爪，直接抓向构成这“神圣牌桌”的空间法则本身……</p><p>刺啦——！</p><p>整片规则星图被他如破布般撕扯、揉碎！</p><p>五指凝聚成钻头，将天空与次元尽数突破！</p><p>同时在原地留下一个分身，一个圣人级别的白杨大帝。</p><p>或许有朝一日，他会被写进神界历史书；或许有朝一日，他会成为神界动画片中的角色。</p><p>但可以肯定的是，在不久的将来，也许是下个月——他就会被收录进卡片中，效果是爆杀牌桌上的全体其他！</p><p>……</p><p>阿巴：“老大，你每到一个世界，都要安插一个在此界的‘钉子’。”</p><p>“没错。”</p><p>“但这种行为真的不会导致世界大乱吗？”</p><p>“怎么说？”</p><p>“比如说凡界是灵界的一幅画，灵界是仙界的虚拟金融预测沙盘，仙界又是神界的一款桌游。那岂不是说，仙界以后再也不能用虚拟世界来预测灵界？神界岂不是再也玩不到战争之锤四万年桌游？”</p><p>“傻鱼，你忽略了一样东西——领域。”</p><p>阿巴一边吃着鳕鱼堡，一边做出标志性的愣住。</p><p>杨帝微笑道：“‘领域’本身，就是一处与外界相隔的小世界。”</p><p>小世界也是世界，小宇宙也是宇宙。</p><p>“我用我的领域，覆盖了下界的‘表面’，就像给电视机遥控器加上了一层防尘塑料套，想按遥控器的人都只能按在塑料套上，他们以为自己按下了按钮，实际上是塑料套本身放出了红外线信号控制电视换台——我会让上界之人看到他们想看到的，但两个世界从此不相往来。”</p><p>“这……”</p><p>“你知道模拟器吗？并不是运行其他操作系统的那个模拟器，而不是，嗯，小说题材中的模拟器。”</p><p>阿巴瞳孔一缩。</p><p>杨帝用眼神告诉她，你想得没错。</p><p>“对世人而言，世界线几乎无穷无尽。而我这圣人境界的基因原体，会始终守望下界，并从上界的视角，将其中某一条世界线清晰呈现——这就像电视遥控器外的塑料套或许积满灰尘，但揭开套子，内里的遥控器却依旧洁净如新。”</p><p>“老大……你是塑料套？”</p><p>“吃你的鳕鱼堡吧。”</p><p>杨帝最后看了一眼这篇可笑的天地。</p><p>“耶罗……我已经不会再按你的规矩，老老实实在每个世界里闯所谓的‘关卡’了。”</p><p>如果是以前的杨帝，或许还会老老实实了解这个世界的历史和面临的灾难，结识几个朋友，再打几场牌。</p><p>但他发现，根本没个卵意义。</p><p>应该直接就暴打关底Boss，直面耶罗。</p>
