# 三重领域

<p>杨帝眼神微眯：“你能看到我的本质？那你认为我的本质是什么？”</p><p>“那四十一个大帝以为，你是来自异界的入侵之人，不速之客。但只有我看得清楚，你和我其实是同一类人。”</p><p>残星道人抬手：“JOIN me，我的同胞。”</p><p>“什么同胞？什么同一类人？”</p><p>“不言自明，你无需装作不懂。我是诚心诚意的。”</p><p>“你搞传销啊！说话还谜语人！”</p><p>“我无意杀你。我此行之目的，只是万古鱼尊。”</p><p>“所以归根结底你就是搞传销的，我不臣服于你，你就动粗；不仅如此，你还要当着我的面拐抢妇女。是这意思对吧。”</p><p>杨帝冷笑，他早看透了这帮黑恶势力的作案手段。</p><p>“残星道人，你可知道，你麾下的归墟大帝曾经放出‘阴伏流煞’，试图将整个凡界投入毁灭的深渊。”</p><p>残星摸着山羊胡：“归墟大帝？我明白是怎么回事了。但现在的归墟大帝，不是以前的归墟大帝。”</p><p>居然承认归墟大帝被夺舍。</p><p>已无嘴炮的必要。光是对方想要“抢走阿巴”这一点，就已经触碰杨帝的逆鳞。</p><p>他瞬间入梦，20^3=8000倍时间流速，将三位准圣的法则磨灭攻击全部适应！</p><p>不到半秒，他脱离梦境，猛然睁眼。</p><p>一巴掌将距离最近的五个「至尊」轰成碎渣！</p><p>他们的肉身连惨叫都未发出便化作星屑般的光点，消散在天地间。</p><p>五位至尊的元神仓皇出逃，冲向一众围观的真仙境大能身后。</p><p>到了安全的观战席，还止不住颤抖，似乎被打出心理阴影。</p><p>杨帝并没有打算赶尽杀绝，而是任由其元神飞走。</p><p>毕竟这些菜鸡，菜得出渣，并不重要。</p><p>随即，他大掌一挥，将二十二仙帝、十一神皇拍飞，有的轰至亿万光年九霄云外，有的拍到黑洞吸积盘中让他们挣扎一番。</p><p>总之通通轰到观战席，别在这里碍事。</p><p>“哇！归墟大帝被打飞了！”</p><p>“战狂至尊倒拔葱后失去动静……”</p><p>一众观战的大能再次发出惊呼，像旁白一样做出大众点评。</p><p>在场便只剩下四位老朋友。</p><p>一位传销头头——圣人，和另外三位试图磨灭他的准圣级打手。</p><p>三位准圣见状，周身法则波动骤然加剧。</p><p>涅槃轮劫元尊的灭世轮盘黑气翻涌，试图将杨帝再生的手臂寸寸分解；太虚妙有法王指尖凝出虚无之矛，直刺他眉心；两仪玄枢真君则双掌合十，正反法则形成的漩涡将杨帝周身空间彻底搅乱，试图从根源上阻断他的能量运转！</p><p>“我不会被同一招打倒两次。”</p><p>杨帝此刻的气息已截然不同。</p><p>在那20^3倍时间流速的梦境中，他不仅适应了三位准圣的法则攻击，更将自身防御与能量抗性推向了新的维度。</p><p>他并未主动攻击三位准圣，只是周身逸散的帝威骤然暴涨，如海啸般向四周扩散。</p><p>那股力量并非毁灭，而是纯粹的“压制”。</p><p>三十三仙帝神皇的残余气势，在他面前如同稚童玩闹。</p><p>而三位准圣虽竭力抵抗，却感觉周身法则如同被无形大手攥住。</p><p>刚刚凝聚起的灭世轮盘、虚无之矛、矛盾漩涡，轰然破碎爆灭。</p><p>杨帝咧嘴一笑，露出森白牙齿。</p><p>他不退反进，脚下猛地一跺，整片虚空竟如玻璃般寸寸龟裂，道道漆黑裂缝蔓延向三位准圣。</p><p>三准圣迅速出手抵抗，但下一刻，杨帝身形已如一道流光暴掠而出！</p><p>拳头上缠绕着混沌色的拳罡，带着开天辟地般的威势，直轰两仪玄枢真君面门。</p><p>两仪玄枢真君脸色大变，袖袍狂舞间，正反法则化作阴阳双鱼图横亘身前</p><p>阴阳为基、正反为纲，双鱼首尾相衔、旋转不休，此即「反者道之动」，万物皆可被化解矢量、逆转方向，简直是某玄学的一方通行——</p><p>嘭。</p><p>阴阳双鱼图寸寸碎裂！</p><p>强大的拳劲透过法则防御，狠狠砸在真君胸口。</p><p>真君如遭万钧重击，口中狂喷鲜血，身形如抽搐的野猫般倒飞出去。</p><p>“哼！”</p><p>两仪玄枢真君撞碎了沿途数片凝固的空间碎片。</p><p>涅槃轮劫元尊与太虚妙有法王瞳孔骤缩。</p><p>杨帝这纯粹到极致的力量，已非寻常法则所能束缚。他站在那里，肉身便是大道，气血奔涌便是混沌初开之音！</p><p>真君蕴含正反法则的阴阳双鱼，在杨帝面前如纸糊般脆弱，并非术法本身不够精妙，而是杨帝的力量已超越了法则之范畴。</p><p>如同凡人试图用渔网兜住海啸。</p><p>涅槃轮劫元尊、太虚妙有法王与杨帝迅速拉开距离，执掌「生灭」的元尊迅速扭转了两仪玄枢真君的伤势。</p><p>“布阵！锁死他！”真君刚醒来便发出低吼，声音带着一丝不易察觉的惊悸。</p><p>涅槃轮劫元尊心念一动，身后那巨大的灭世轮盘虚影轰然爆碎，化作亿万缕深邃幽暗、吞噬生机的“灭”之法则丝线，与“生”之菁纯本源。</p><p>生灭之道，瞬间蔓延虚空，构筑起第一重领域「生灭劫域」！</p><p>领域之内，时光错乱，万物凋零，草木瞬间枯荣亿万次，星辰幻灭只在弹指间。</p><p>“万法皆虚，唯道永存！”太虚妙有法王紧随其后，指尖轻点。</p><p>本源法则之力如潮汐上涌，瞬间填满生灭劫域之外的虚空，形成第二重领域「太虚幻境」！</p><p>此境之中，“有”的概念被极致压制。光线、声音、能量、乃至空间本身的存在感都在飞速流逝，一切有形有质之物都在向绝对的“无”塌陷。</p><p>“正反逆乱，玄枢锁神！”两仪玄枢真君强压伤势，咳着血沫厉喝。</p><p>顿时身后浮现黑白二影，正反法则。</p><p>正反法则不再追求攻伐，而是化作两条纠缠咆哮、首尾相衔的混沌巨蟒！黑者逆乱秩序，白者稳固法则，盘绕着生灭劫域与太虚归无境，构成了最外层的第三重领域「两仪玄界」！</p><p>此界玄奥莫测。空间被无限折叠、拉伸、反转；时间流速忽快忽慢，甚至倒流回溯；因果线混乱交织。</p><p>三重领域，嵌套叠加。</p><p>领域能够极大增幅战斗力。</p><p>原本，他们是试图用渔网兜住海啸。</p><p>而此刻，被困在三重嵌套领域中的“海啸”被压制成了“钱塘江大潮”。</p><p>而“渔网”，也升级为了“绝境长城”。</p><p>刹那间，杨帝所处的虚空彻底被这三重恐怖的法则领域所吞噬。</p><p>外界看去，只剩下不断旋转、色彩变幻、散发着令仙帝都灵魂颤栗气息的混沌光茧！</p><p>光茧内部，是足以让任何仙帝、神皇、至尊瞬间化作飞灰，就连圣人也可能被伤到的终极法则炼狱！</p><p>……</p><p>杨帝感到大脑皮层被人一个拳在额叶。</p><p>这是一处极致诡异，极致恐怖的时空。</p><p>“我超，原来如此……抵达准圣这个级别这个层面，就可以被称为‘机制怪’了。”</p><p>三位准圣，各自掌控一方「完整」的法则。</p><p>无论是生灭、有无还是正反，它们都是同一法则、同一本源的分裂。</p><p>这种法则本源合而为一，才是其完整形态！</p><p>譬如：有无法则。它比单独的“虚无”或单独的“存在”，要更完整一些。</p>
