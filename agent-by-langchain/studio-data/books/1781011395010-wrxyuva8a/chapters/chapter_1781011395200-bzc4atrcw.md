# 圣人不仁

<p>杨帝摇摇头，然后看向周围一片乳白色的白杨世界领域，“只是因为这粒‘宇宙之沙’，是四邪神的老巢，我直捣黄龙罢了。”</p><p>“呃……啊？”</p><p>“此时此刻是亚空间邪神、混沌力量最强大的时刻。‘老巢’，指的可不仅仅是空间概念。”</p><p>杨帝看向领域外的极远处。</p><p>“邪神，我见过了。祂们的把戏，我也领教过了。现在，是时候让祂们直面大恐怖了。”</p><p>在浩瀚寰宇之上，存在着一种凌驾于凡俗生命所能想象极限的境界——圣人境。</p><p>此境者，已非“强大”二字可以形容。</p><p>他们并非简单地拥有移星换斗、再造乾坤的神通。</p><p>而是其存在本身，便已无限逼近于、甚至部分等同于世界运行的根本法则——天道。</p><p>“圣人不仁，以众生为刍狗。”</p><p>对于圣人而言，兆亿生灵的悲欢离合、文明兴衰，乃至星河生灭，都如同孩童手中随意摆弄的草扎狗偶。</p><p>他们并非心怀恶意，而是其视角与意志早已超越了个体，乃至超越族群的范畴。</p><p>达到了与世界、宇宙本身等格的高度。</p><p>凡俗生灵的情感、道德、诉求，在圣人眼中渺小如尘埃。</p><p>其价值，仅在于作为世界运转中可被观察，利用，表达自身的现象或材料。</p><p>圣人之间的争斗，是概念层面的终极碰撞，是根源法则的互相倾轧。</p><p>祂们的每一次交锋，都不是简单的能量爆发或物理破坏，而是字面意义上的磨灭大道。</p><p>磨灭大道，不是修饰意义上的！！</p><p>是字面意义！！</p><p>可参考满血版“灵茶山乂斧”，其代表了灵界的“最高系统权限”，具备磨灭大道的出色功效。</p><p>而此刻，在亚空间那永恒翻腾的混沌核心，端坐于各自扭曲圣座之上的，正是四位达到了此等恐怖境界的存在——</p><p>原初纯洁命神·那唭枯，至道勇毅血神·哥达内，无瑕慧悟智神·辛烈治，义胆赤心爱神·沙历士。</p><p>祂们，个个都能磨灭大道。</p><p>个个都是“圣人”。</p><p>与其说，祂们窃取了人类最闪耀的美德。</p><p>不如说人类所谓的美德，其实是由祂们自身所分裂出的本源、概念。</p><p>“污腐”这一概念，需要有“纯洁”的对照，才得以存在。</p><p>相反，洁，也预设并依赖于“污”。</p><p>圣人境的存在，其恐怖与超然的根源，便在于祂们对万物矛盾螺旋的超越。</p><p>譬如命神·那唭枯，本身就是纯洁与污腐的根本源头。</p><p>祂的存在就是“熵”的绝对律动。熵增为污腐与紊乱，熵减为纯洁与秩序。</p><p>祂们已经由“剧中人”，跃升为“编剧”，乃至是“舞台”本身。</p><p>祂们看待众生如刍狗，正是因为众生所经历的一切悲欢离合、善恶斗争、兴衰成败，在圣人眼中，不过是祂们所掌控的微不足道的现象。</p><p>阿巴抓住杨帝衣角，一边喷血一边说：“老大，事从权急……我简单说说四大邪神的恐怖手段，或许对您决战有帮助。”</p><p>磨灭大道，只有一种方法。</p><p>即是对构成该大道的矛盾，推向极致的单一化，彻底颠覆其平衡。</p><p>大道，将会被“磨”去“一层”。</p><p>还是拿命神·那唭枯举例，祂象征“纯洁与污腐”。</p><p>但祂只要删除“纯洁”，让全世界只剩下“污腐”，大道便从根基上退化。</p><p>或许，“污腐”还能分裂出“善良的污腐”和“邪恶的污腐”之类的矛盾；善良的污腐，还能继续分裂出“善良的污腐甜党”和“善良的污腐咸党”这样的对立……</p><p>但只要继续“磨”下去，子子孙孙无穷匮也，终有一天能够“灭”之。</p><p>「磨灭」一词，本身隐含一层意思：即使是圣人，也很难把宇宙、世界、大道彻底磨成“虚无”，而总会剩下些“残渣”。</p><p>用石盘磨大豆，总会剩余豆渣。</p><p>“所以，祂们可以像磨豆腐那样‘磨’我，但永远无法‘灭’我。”</p><p>杨帝一捏拳头，指关节劈啪作响。</p><p>“我，就是那部分打不死、磨不灭的残渣。”</p><p>虽然很少会有人称自己是“豆浆”，但称自己为“豆渣”的人显然更少。</p><p>杨帝指向万古鱼尊。</p><p>“而且阿巴，你说错了一个点。”</p><p>“……啥？”</p><p>“磨灭大道，并不只有一种方法。”</p><p>“哈？……”</p><p>“纯粹的蛮力，极致的强度，突破天际的数值，能够超出‘大道’的极限……我认为只要我再努力一把，一定能够磨灭大道，对付域外天魔，或许也不是不可能。”</p><p>只是“或许”。</p><p>许多事情是拳脚做不到的，比如你不能通过殴打哈基米使其变成猫娘——这显然不够现实。</p><p>杨帝挥挥手，撤除自己的领域白杨世界。</p><p>他和鱼尊，两位在各自领域最巅峰的存在，此刻如同被抛入沸腾恒星内核的尘埃，暴露在庞大得令人窒息的灵能洪流之中。</p><p>“四神……从来没出过全力吗……”阿巴那古老沧桑的神念剧烈颤抖，几乎无法凝聚成形。</p><p>四位邪神，四个圣人。</p><p>如同凝固星海般浩瀚磅礴的，正是四大邪神所散发的灵能。</p><p>灵能是“现实”本身的丰度表征。</p><p>亚空间此地，每一缕翻腾的灵能辉光，都代表着海量的“现实可能性”被固化、被锚定。</p><p>这片区域的“现实”厚重得如同简并态物质。</p><p>阿巴仅仅是要动弹半分，也尤为艰难。</p><p>四大邪神端坐于扭曲圣座之上，祂们本身就是这片“现实海洋”的核心源泉，是无限灵能之洪流的化身。</p><p>灵能的本质是什么？</p><p>关于灵能的本质，世人已经有诸多研究。</p><p>无论是真仙境大能，还是宇宙级文明，都无一例外将其定义为对“现实丰度”高低的刻画。</p><p>但「现实」这个玩意，本质是什么？</p><p>用“现实”去解释“灵能”，这种定义，不过是用一个名词，去解释另一个名词。</p><p>什么是红色？成熟的苹果便是红色。</p><p>什么是成熟的苹果？也就是颜色开始发红的苹果。</p><p>最终，如何解释“现实”，仍然只能用比喻，亦或者是隐喻，侧面描绘出其特征。</p><p>现实，就像每天坐的那把胶凳——你知道它稳稳当当撑着你，哪怕起身倒杯水回来，它依然在原地保持着椅子的形状，不会突然变成一团橡皮泥或者飘起来。</p><p>这种“始终是它自己”的特性，就是稳定性。</p><p>就像青白石搪瓷杯，杯口磕碰的小豁口、杯身掉漆的斑点，每次喝水时手指摸到的触感都一样，这让你确定“它是真实存在的杯子”。</p><p>但如果你幻想“这杯子能自动倒满茶水”，或者在手机里玩个“虚拟茶杯养成游戏”，里面的杯子会随剧情变成金镶玉，这就是缺乏稳定性的幻想和虚拟——它们依赖你的念头或程序设定，随时能被改写。</p><p>换句话说，这个茶杯的世界线变动了。</p><p>它不再是原来的茶杯。</p><p>它无法掌控自己的命运。</p><p>它的命运被更高等的灵能者所改写。</p><p>它被一个“灵能相对上位者”，修改了其世界线，也就是修改了其命运。</p>
