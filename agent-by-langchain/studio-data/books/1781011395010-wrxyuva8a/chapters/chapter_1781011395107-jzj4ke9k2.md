# 奔现？

<p>晚上是瑞弗维尔采了些菌子煲汤，所幸这次没吃到毒蘑菇。</p><p>一觉到天明。</p><p>晨光刺破林间雾气时，杨帝被瑞弗维尔的惊呼声扯碎了梦境。</p><p>“伊——娃——哼哼啊啊啊啊——”</p><p>杨帝花费50毫秒感知四周，明白了瑞弗维尔的大叫的原因——伊芙的铺盖凌乱散在一旁，却不见她的踪影。</p><p>包括她的法杖，也被一并带走。</p><p>“杨帝……我昨晚睡死过去了！我不知她是被何人带走的！你有没有看到伊芙去哪？！”</p><p>“没有。冷静下来，看看有无线索。”</p><p>杨帝昨晚也睡觉了。</p><p>因为再不睡，就会超过三天期限，引来夜魅袭击。</p><p>瑞弗维尔捂住脑袋：“伊娃……她的魔法感知至少比我敏锐20倍，如果有危险，不可能不发出信号。”</p><p>有人趁他们熟睡时掳走了伊芙？可没有留下一点打斗的痕迹。</p><p>如此悄无声息，就一个十环超限法师拐跑，这片大陆又有几人能做到？</p><p>又或者……伊芙是自己离开的？</p><p>但她为什么要这么做，她也有秘密？</p><p>脑中又响起精灵的声音：</p><p>「哦哦噢，这题我会，‘浮士德’型的基本故事类型，主角有无法掩饰的秘密，或者难以洗清的过去。对吧杨帝？对吧奥拓？」</p><p>所以她并不只是在影射奥拓和杨帝。</p><p>而且还是在揶揄自己吗？</p><p>奥拓终于被他们的大声说话给吵醒了，他睁开眼，躺在石板上，望着陌生的、天花板（天花板指白桦林的树冠枝叶，以及天空），非常不想起床。</p><p>杨帝捏着下巴：“伊芙可是这片大陆数一数二的巅峰强者，能够把强者打败的只有强者，能把强者吸走的只有强者，这就是物以类聚，人以群分，自然界中某种天然的‘聚类’现象……思维太发散，我需要更集中。回到原点——伊芙可是这片大陆数一数二的巅峰强者……强者……”</p><p>他呼吸微微一顿。</p><p>瑞弗维尔·急·不可耐：“想到什么了？”</p><p>“昨天，临近砾石镇的时候，气温显著下降了对不对？”</p><p>“对……我还记得。那时候奥拓披上亚麻披风，戴上兜帽，他说自己冷。”</p><p>奥拓坐起身：“嗯？叫我吗。”</p><p>“没事，您接着睡吧。”</p><p>杨帝接着说：“虽然听起来是强加因果，看起来毫无关系，但我总觉得那时候伊芙说的一句话有提示，她说——”</p><p>「我认识一些超限强者，他们能改变局部地区气候……」</p><p>瑞弗维尔：“伊娃说这句话有什么问题？她是在陈述事实，并没有欺骗我们。”</p><p>他没经历过21世纪新闻学的磨练，并不觉得这句话有什么疑点。</p><p>杨帝只能解释：“这是种‘信息锚定效应’，当异常现象出现时，人们会不自觉地将后续信息与初始事件关联。</p><p>“昨天进入砾石镇前的气温骤降，可能是灵能地脉波动，或地形导致。</p><p>“伊芙却在没有语境铺垫的情况下，主动将其与‘星渊井口附近的超限强者’挂钩。”</p><p>瑞弗维尔反对：“这并无问题，她本身就是超限强者。”</p><p>大佬说自己是菜逼——谦逊。</p><p>大佬说自己是大佬——诚实。</p><p>杨帝：“重点是‘他们能改变局部地区气候’的下一句话——”</p><p>「星渊井口附近的气温降低，大概也是因为如此。」</p><p>“她应该说‘砾石镇附近的气温降低’。然而，她说的不是‘砾石镇’，而是‘星渊井口’。”</p><p>瑞弗维尔：“她说的也确实是实话，毕竟在当时，星渊井口、砾石镇方向是一致的，都是往南走。就算有事实性错误，那也是一种合理的假说观点表达……”</p><p>杨帝：“不对，你要看当时的具体场景具体语境。当时，奥拓带着我们去往砾石镇……”</p><p>奥拓又坐起来：“在叫我吗？”</p><p>两个人类让矮人躺下，别插嘴。</p><p>杨帝继续说：“当时我们正在被某矮人带队去往砾石镇，而非去往星渊井口——没错，这两个目的地以当时我们的位置来看，方位是重叠的——但是，从形式上说，当时我们的行进目的地是前往‘砾石镇’，而非‘星渊井口’。关于星渊井口的话题，完全是伊芙主动提起、强调的。”</p><p>瑞弗维尔难以理解：“她怎么会有这么多心眼？”</p><p>“我觉得是你心眼比较少……”</p><p>图书馆馆长瑞弗维尔还是听不明白。</p><p>他所处的社会形态虽然有魔法，生产力很高，但大体上毕竟还是中世纪。</p><p>新闻学发展没有21世纪那么发达。</p><p>杨帝举了个例子：“我说两句话，你来想想我要表达什么意思——</p><p>“今天天气很好。我和矮人去倒斗。”</p><p>因为天气很好，所以我和矮人去倒斗？</p><p>不对，并没有“因为”“所以”……</p><p>但这句话，确实在暗示某种因果关系……</p><p>瑞弗维尔瞳孔微缩：“我明白了……‘天气很好’、‘我和矮人去倒斗’并没有明显的因果联系，但我们语言的用词、语气、甚至仅仅是顺序……就会透露出某种额外的暗示。”</p><p>“没错，伊芙主动提及‘星渊井口’的话题，就已经表达了某种‘额外内容’。”杨帝说。</p><p>这里的额外内容，与星渊井口、超限强者有关。</p><p>瑞弗维尔思考：“所以你的意思是，她不小心泄露了自己内心正在思考的内容？”</p><p>杨帝摇头：“不，我认为，她是故意把‘气温下降’和‘星渊井口’联系起来。”</p><p>“图什么？”</p><p>“图的是暗示我们。”</p><p>“暗示我们什么？”</p><p>“又是星渊井口，又是超限强者，瑞弗维尔你再猜猜？”</p><p>瑞弗维尔又开始有些焦急了，你能不能一次性把话说完！谜语人滚出中土大陆啊。</p><p>杨帝见他不领情，便作出恼羞模样：“好，我就把结论告诉你——事实已经显而易见了，伊芙·柑橘，她要和战死在星渊井口的超限强者、圣骑士「巴德」私奔！”</p><p>瑞弗维尔的眼睛瞪得滚圆，差点从石板上摔下来。</p><p>“和战死的圣骑士私奔？！杨帝你是不是睡迷糊了，巴德可是一百年前就陨落的人物！”</p><p>人死不能复生。</p><p>人被杀，就会死。</p><p>这貌似是铁律，但其实也不一定吧……在灵能富裕的异世界，说不定秽土转生、死后诈尸什么的都能合理存在。</p><p>而且，他还记得瑞弗维尔讲述过的历史：巴德射杀巨龙后，现场并没有发现他的尸体，只留下半枚碳化指骨。</p><p>要么是死得不够干净，只剩半截指骨。</p><p>要么是受的伤太轻，仅损失半截指骨。</p><p>奥拓这时也凑过来，毛茸茸的络腮胡一抖一抖的。</p><p>“我大概听明白你们在讨论什么了。说不定啊，这圣骑士的灵魂被困在了这里，然后和伊芙不知咋地就看对眼了。”</p><p>瑞弗维尔锐利的目光扫过来：“奥拓，你都知道些什么？”</p><p>矮人似乎知道一些事情。</p><p>奥拓：“我昨晚辗转反侧，看见精灵走了。往南。口中还喃喃着‘巴德’。”</p><p>補完計劃【下】（126-185）</p>
