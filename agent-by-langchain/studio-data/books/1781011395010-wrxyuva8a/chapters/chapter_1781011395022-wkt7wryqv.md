# 三级运动员

<p>“我怎么会是这般偷偷内卷的无耻之人……”杨帝反驳，脸不红心不跳。</p><p>“你就是卷！你总是半夜拿书在上铺熬夜做题，别以为我不知道。”</p><p>“……”</p><p>杨帝哽然，赶紧转移话题，“呃，话说，张明远，这劳动节七天小长假，你不也是天天都对着电脑做你那什么神经项目？从我急性肠胃炎那天你就开始了，这难道不是更大的内卷吗？”</p><p>他说着说着，理直气壮起来，发现真理和正义都站在自己这边。</p><p>张明远见势不妙，也迅速转移话题：</p><p>“咳咳，其实这几天我都没在卷，我已经把那模型卷完了……做完了。这几天我都只是在调试自己的模型。调试的事，怎么能叫卷呢？”</p><p>他利索地打开笔记本电脑。</p><p>抓起鼠标，把笔记本屏幕扭过给杨帝看。</p><p>“老杨你来帮忙看看。我这模型修改了损失函数，从头到尾完完整整优化了一遍，又训练了五千多张气球照片，从1920年的热气球到老马的星舰，模型识别准确率始终超过九九成……但始终在一张照片上，会栽跟头。这图片我拿PS分析过像素分布，噪点图普什么的，完全没问题，但就是识别不出来，鬼知道为什么。”</p><p>他点开名为“test_017”的图片。</p><p>那是一片湛蓝如洗的天空，一个红色气球悬在画面中央。</p><p>普通得再不过的照片，背景蓝天很干净，没有多余的杂物和干扰项。</p><p>理应是一张识别难度很低的图片。</p><p>然而，AI识别框却像癫痫发作般抽搐，这儿框框，那儿框框。</p><p>不大的屏幕上，居然有十几个红框！</p><p>只有其中一个框框住了鲜红色的气球，显示该物体应该是“气球”。</p><p>其他框都出现了奇奇怪怪的结果，什么猫猫狗狗，消防栓，珊瑚虫，躺椅，章鱼……</p><p>杨帝把脑袋凑近，仔细瞅过去。</p><p>感觉眼球有些酸涩发痒，他揉了揉眼。</p><p>画面貌似晃动了一下，但转瞬即逝，恢复了平静，和普通得不能再普通的……普通。</p><p>「精神+1」</p><p>这些被框住的位置都只是片蓝天。</p><p>明明背景这么干净，模型却总在云层边缘检测出十几个锚框……</p><p>杨帝想脱口而出“对抗样本”“自然噪声”之类的专业术语云云。</p><p>但在此之前，他疑惑地问了个问题。</p><p>“识别的是气球，你拿老马的星舰干嘛？”</p><p>张明远放下一直托在脸上的手。</p><p>张明远呼吸变得沉重。</p><p>张明远瞳孔骤缩。</p><p>他像是明白了什么不得了的事：“卧槽，为什么我一直没想到……太奇怪了，如此显而易见的错误，我却将它有意无意地忽视掉了？老杨，你救我一命了，你是我的救世主，你就是我的神仙皇帝！”</p><p>你说话真奇怪。</p><p>杨帝笑笑，洗澡睡觉去了。</p><p>只是，始终有一个想法，一直萦绕在内心深处。</p><p>错误地用老马的星舰来训练模型，也只是会把“火箭”识别成“气球”而已。</p><p>不应该出现消防栓、珊瑚虫、章鱼这些东西吧？</p><p>这个念头在脑海中盘旋，最后沉坠到心灵深处，埋藏起来，被他暂时遗忘。</p><p>一股巨大的困意袭上心头。</p><p>不知为何，大概是杨帝回到宿舍不久后，总觉得精神很疲惫，像是刚熬了四小时夜，写完30道数学大题。</p><p>也许是今日运动过于超量了，看来就算是自戕，也得有个度。</p><p>草草洗了个澡，便躺下睡觉。</p><p>杨帝又做梦了。</p><p>这回梦见，天上有颗顶级挂绿荔枝般的大眼球，伸出几根椒盐蘑菇味鱿鱼丝似的肉触手，死死缠住他脖子。</p><p>杨帝口中流出恐惧的泪水。</p><p>但随即，他惧极反怒，大吼一声扑向天空：“哪条刁民要害朕？”</p><p>「精神+1」</p><p>然后他便醒过来了，发现原来是被耳机线缠住了脖子。</p><p>以后有钱了一定买蓝牙耳机。</p><p>有线耳机睡梦杀人的概率很低，但绝不为零。</p><p>这诡异的梦只是小插曲。</p><p>第七日清晨五点十分，晴，微风，杨帝啃着米老头走向西田径场，与跑友汇合。</p><p>胡彦卓正在做高抬腿热身。</p><p>待二人热身完毕，红衣跑者竖起三根手指：“先说规则。第一圈热身配速4分钟，之后每三圈提速5秒，最后三圈自由冲刺。扛不住，随时退场，急救电话已经预设成快捷键。”</p><p>杨帝点头，顺带着颈椎发出细碎噼啪声。</p><p>两个身影同时出发，一前一后，一左一右，步履协同，也是几乎同时切入弯道。</p><p>杨帝从最开始便咬住了胡彦卓，二人并驾齐驱。</p><p>跑步其实是件很枯燥无聊的事情，没有身体对抗，没有观众席上震耳欲聋的呐喊，没有进球时的欢呼，没有水花飞溅的视觉冲击，没有格斗运动中荷尔蒙的激烈碰撞。</p><p>它只是一个人与自己较劲的孤独旅程。</p><p>哦，如果有人陪跑，那就是两个孤独的驴友在旷野上相依为命。</p><p>单调节奏，重复动作，长时间体力消耗。</p><p>因为缺乏戏剧性的张力和情感的爆发，很难调动起观众或读者情绪。</p><p>即使是运动类的商业文艺作品，也不会拿跑步作为题材。</p><p>大约也就中小学生的叙事作文，会将跑步作为头等大戏了。</p><p>“1时20分25秒，三级运动员水准，恭喜恭喜恭喜你啊。”</p><p>远处天际泛起蟹壳青，第一缕晨光正刺破云层。</p><p>胡彦卓望着瘫坐在跑道边的青年，晨露与汗液沾湿的运动服紧贴在他剧烈起伏的脊背上。</p><p>「体力+1」「下肢+1」「心肺+1」……</p><p>“杨帝，我必须要向你说一些事情。”</p><p>“呼、呼……什么……？”</p><p>胡彦卓很严肃：“你知道国家三级运动员的标准是什么概念吗？如果是普通人，就需要每天训练八小时，坚持半年才能摸到门槛。而你只用了六天。”</p><p>杨帝正用手指按摩小腿肉，新生的肌纤维在皮下跳动。</p><p>他看似冷静，实则后背已经渗出冷汗。</p><p>因为进步速度太快，这就被看出来了？</p><p>他不会已经通知非正常人类研究中心，就要派人来把他拉去切片吧？</p><p>“杨帝，正常运动员的能力增长是一条不断放缓增速的函数，前三个月可能提升30%，接下来半年提升15%，之后每年能有5%就是奇迹。</p><p>“有个师弟刚入队就能跑进3分40秒配速，结果两年过去，卡在3分20秒再难寸进。</p><p>“职业运动员最怕的不是伤病，而是某天早晨醒来，发现身体再也榨不出一丝潜能。你现在感觉进步神速，是因为站在山脚。”</p><p>说到“脚”字，他抓住杨帝的脚踝。</p><p>他像是少林足球里“黄金右脚”初遇大力金刚腿时的兴奋，两眼放光：“真是一双天生跑酷的好腿。”</p><p>他拇指精准按在腓肠肌与跟腱连接处。</p><p>青年痛得倒吸冷气，却见前辈露出果然如此的表情：“肌腱已经出现纵向撕裂，若是继续用这种自杀式训练，你迟早成为陨落的天才，泯然众人！”</p><p>“胡大哥，你到底要说什么？”</p><p>“杨帝，趁着还年轻，和我学跑酷。”</p>
