# 与猫线团纠缠

<p>“……杨帝！我们又回到了原来的楼层！”</p><p>胡彦卓的惊叫，从面前、头顶和楼下，三个方向同时传来。</p><p>空间被强行扭曲重叠在一起，无论向上还是向下走，都会回到原地。</p><p>而现在，那团“哈基面”正在楼梯上方，直勾勾盯着胡彦卓。</p><p>“我来挡住！”杨帝上前，用愈发精湛的剑技和愈战愈强的力量，逼退那哈基面的攻势。</p><p>楼梯间回荡着乒铃乓啷声。</p><p>墙壁地板吸音效果很好，声音并不大。</p><p>胡彦卓知道自己冲上去也只是帮倒忙，便立刻转身，往下走。</p><p>他的任务是，探查回头路有无一线生机！</p><p>哈基面瞬移到了上一层，说明下一层应该空了出来，比较安全……吧？</p><p>他前方，手电筒照亮的区域……也传来乒铃乓啷打斗声。</p><p>“什么……？还有人在下面？”胡彦卓的瞳孔瞬间缩成针尖状。</p><p>往下，看清晰了——下方通道也有团扭曲蠕动的怪物。</p><p>抬头，上方楼梯口那团翻涌的黑色拉面，亦是在以相同的姿势扭曲蠕动。</p><p>楼上和楼下的怪物，都在和杨帝搏斗着。</p><p>两个哈基面，两个杨帝。</p><p>他们（他？）的撬棍同时抡圆了，划出圆月般的弧光。</p><p>撬棍挥击的弧度、肌肉颤动的频率，甚至额角滑落的汗珠轨迹，一切都分毫不差。</p><p>当啷！×2</p><p>两个的哈基面同时被击中，两个的怪物同时发出嘶鸣。</p><p>两团黑色物质同一时刻剧烈抖动，拉面状的躯体上浮现出相同的裂痕网络。</p><p>……</p><p>杨帝已经发现异常。</p><p>他和哈基面的交战之声，从面前、楼上、楼下三处地方传来。</p><p>他一闷棍敲在黑乎乎的拉面团上，首先是手中撬棍发出金石敲击之声，接着楼上楼下传来第二声。</p><p>“胡哥！怎么回事？！”</p><p>胡彦卓从楼下刚刚经过的桌椅堆，流着冷汗急匆匆跑上来：“向上向下，都会回到原点！”</p><p>杨帝大脑颤抖：“无限循环？”</p><p>“一种循环性的，周期性的拓扑空间……总之就是鬼打墙了！！”</p><p>“妈耶！”杨帝暴喝一声，又狠狠敲中怪物一闷棍，让它将暂时僵持1.5秒。</p><p>趁这个机会，他弯腰抄起先前丢弃的弯曲撬棍。</p><p>他明明记得，这已经弯掉了的撬棍，是掉到了楼梯更深处。</p><p>但现在，它居然出现在了楼道上端。</p><p>最坏的情况是，这楼梯无限循环……</p><p>“不，这不科学……很玄幻……”</p><p>杨帝的后槽牙咬得咯吱作响，两根撬棍在掌心旋转出银亮的圆弧。</p><p>一根直撬棍，一根S形弯棍，倒像是武侠小说里的子母鸳鸯钺！</p><p>“喝啊！！胡哥你再向上走试试看！”</p><p>杨帝两柄撬棍划出互为补集的轨迹，同时击中哈基面的脸，传来某种类似陶瓷破碎的动静。</p><p>它被暂时压制在墙角。</p><p>胡彦卓趁机冲向楼梯拐角，从杨帝身后跑上了楼。</p><p>他按照杨帝的指示，再次尝试向上探索，手电筒的光束在前方摇曳。</p><p>第六次转过楼梯拐角，眼前景象让他几乎窒息——</p><p>面前的上方，是一堆桌椅板凳。</p><p>废桌椅堆旁，还有一根被扯断了，婴儿拇指粗细的，生满锈的锁链。</p><p>而在桌椅板凳再往上，哈基面与杨帝仍然在胶着缠斗。</p><p>胡彦卓呼吼：“兄弟！没路！”</p><p>喊声在空旷又诡异的楼梯间里回荡。</p><p>杨帝透过楼梯栏杆缝隙，朝后下方的胡彦卓瞥了一眼。</p><p>他开口提醒：“胡哥往下！它调头了！”</p><p>那哈基面听到胡彦卓的叫喊声后，立刻暂停与杨帝的互殴，掉头朝他袭去了！</p><p>胡彦卓赶紧往楼下跑去。</p><p>跑了大约两层半的楼梯，双手持撬棍的杨帝出现在眼前。</p><p>胡彦卓一个，差点没一头撞进杨帝怀里。</p><p>他喘着粗气：“杨帝兄弟！要不要二打一！”</p><p>杨帝将他护在身后：“你只会影响我一秒六棍的速度。”</p><p>他把“现在双持，是一秒十二棍”咽回肚子。</p><p>那哈基面的攻势愈发猛烈。</p><p>胡彦卓看着杨帝在前方与哈基面激烈交锋，每一次撬棍挥动，都带着破风之声。</p><p>可那怪物的攻势，也如潮水般连绵不绝！</p><p>只不过魔高一尺，道高一丈，杨帝的“剑技”进步速度超过哈基面的攻势猛烈程度！</p><p>所以，他表面上看起来，还未到招架不住的时候，暂时还游刃有余。</p><p>但实际上，杨帝心知肚明——</p><p>就算他能撑下去，他手里的两根撬棍也撑不了多久！</p><p>“胡哥，再帮我掰些棍子，最好是金属的，钢管也行……”</p><p>杨帝刚说完一句话，头颅内突然被一个声音充斥填满——</p><p>“老大！！这是什么？！！”</p><p>希夷的声音在颅腔里炸响。</p><p>声音之大，杨帝差点握不住手中的撬棍。</p><p>他一边格挡并殴打哈基面，一边和希夷斗大声：“你吼那么大声干嘛！什么事？！”</p><p>“老大……你在疯狂殴打的这玩意，很‘空’，很虚……”</p><p>“很‘空’？这是什么意思？”杨帝眉头紧皱，手中撬棍不停。最讨厌谜语人了。</p><p>希夷：“就是……它是个‘空壳子’，我觉得我可以住进去。”</p><p>“你是说像驾驶暴风赤红，或者驾驶强袭自由那样？”</p><p>“没错！我应该可以驾驭住它！老大！你手机相册里刚刚拍的那张‘石膏雕塑’图片！你把那张图片调出来，屏幕对准它！”</p><p>希夷能藏身于图片中。</p><p>但似乎仅限于大小12.96MB以上的.jpg和.png图片文件。</p><p>此刻已无其他更好的办法，只能冒险一试！</p><p>“胡哥！接住！密码是9527，去相册把那张石膏雕塑的图片调出来，对准怪物！”</p><p>胡彦卓接住杨帝抛来的手机，一头雾水。</p><p>“什么……？”</p><p>“来不及解释了，照做！”</p><p>胡彦卓不明所以，只能照办，输密码进相册找图片一条龙，手指在屏幕上飞快滑动！</p><p>那张石膏雕塑的照片出现在屏幕上。</p><p>他一愣。分明看见图片里的阴影诡谲蠕动，仿佛有什么东西，在像素点间苏醒。</p><p>杨帝：“别多看！把屏幕对准怪物！然后闭上眼！”</p><p>他知道，胡彦卓的精神属性比一般人高一些，能够略微察觉希夷的存在。</p><p>“我信你！杨帝！”胡彦卓暴喝着将手机屏幕对准最近的哈基面，另一只手捂住双眼。</p><p>刹那间，手机屏幕泛起幽蓝的光。</p><p>在杨帝的视野中，希夷虚影从像素中渗出，像一团扭曲的水墨附在照片上。</p><p>像贞子爬出电视机，希夷也从方寸大小的手机屏幕中“流”了出来。</p><p>杨帝只能用“流”，一是因为希夷长得实在抽象，像一大坨角度、线条混合在酱缸里发酵180天所得的产物。</p><p>二是因为，它走出手机屏幕的形态，实在太像流体了。</p><p>它一滴一滴地坠出来，但“坠落”方向不是指向下，而是指向猫线团怪物。</p><p>“希夷！快点！你丫长得好抽象！！”杨帝痛斥希夷，批评它天生长得抽象这一恶劣行径。</p><p>胡彦卓仍然紧闭双眼。</p><p>即便如此，他也能感觉到周围空气异常波动，仿佛有某种不可名状的存在正在迅速膨胀。</p><p>希夷从手机中射出，缠住怪物。</p><p>下一瞬间，黑色拉面状的哈基面停滞了，无数面条状的触须在半空凝固，仿佛被无形的手攥住了咽喉。</p>
