# 过五关斩六将跑了

<p>距离末日火山主峰200公里。</p><p>……</p><p>瑞弗维尔深知自己已然成为了圣光教廷的眼中钉，肉中刺。</p><p>这一路，必然不会太平。</p><p>果不其然，刚走出没多远，便有一批身着白色长袍，手持法杖的教廷修士如鬼魅般现身，将他团团围住。</p><p>“异端！竟敢亵渎神圣！交代第三红衣主教的下落，或许还能留你全尸！”</p><p>为首的修士怒目圆睁，手中法杖顶端的水晶闪烁着刺眼的光芒。</p><p>竟是个五环究极巅峰大圆满、半步六环的术士！恐怖如斯！</p><p>瑞弗维尔把菊花模样的石头雕塑举起来。</p><p>一瞬间，原本气势汹汹的修士们像是被施了定身咒一般。</p><p>他们目光死死地盯着那雕塑，脸上的表情从一瞬间的狂喜，逐渐变得伤感而扭曲。</p><p>为首的修士手中的法杖“哐当”一声掉落。</p><p>他眼中失去了光芒和斗志，随便找了个墙角坐下，像个创业失败破产妻子离婚房子孩子全部被分走的中年咸鱼，再也翻腾不起浪花。</p><p>其他修士也纷纷满地打滚，用臀撞墙，以头抢地，场面混乱不堪。</p><p>这石头雕塑的作用还各不相同。</p><p>它一般不会把人杀掉，只会让直视者陷入某种精神错乱，一般是在极短暂的狂喜激悦后，急转直下的变为悲哀。</p><p>只有第九席红衣主教比较倒霉。</p><p>他看一眼就悲伤至极，自杀了。</p><p>这仅仅只是个开始。</p><p>接下来的路程中，瑞弗维尔又遭遇了二十余次圣光教廷的追杀。</p><p>又一次，一群教廷圣骑士高头大马，手持闪耀着圣光的长剑，如狂风般向他扑来。</p><p>“圣光之源，自天际降临。汇聚无尽的神圣之力，化作裁决的利刃。在这黑暗与邪恶的交织中，以正义之名，斩断一切罪恶。圣光裁决斩，现！”</p><p>七环圣术·圣光裁决斩！</p><p>瑞弗维尔掏出石头雕塑。</p><p>教廷圣骑士的眼神瞬间变得迷茫。</p><p>紧接着像是被一股无形的力量牵引，陷入了无尽的思索之中。</p><p>他们的身体像是被定住一般，手中闪耀着圣光的长剑也渐渐黯淡无光。</p><p>“我……我为何而战？”</p><p>“这所谓的正义，真的是正义吗？”</p><p>“正义啊！多少罪恶假汝之名而行……”</p><p>不知过了多久，其中一名圣骑士率先回过神来。</p><p>然而此刻，他的眼神已不再是为教廷追杀异端的狂热。</p><p>而是充满了某种无法言说的坚定与决绝。</p><p>他轻轻一挥手中的剑，如同下达了某种无声的指令，其他圣骑士们竟也纷纷清醒过来。</p><p>只是他们的神情变得极为怪异，仿佛集体陷入了一种疯狂却又执着的状态。</p><p>他们不再理会瑞弗维尔。</p><p>像是着了魔一般，调转马头，向着南部大海的方向疾驰而去。</p><p>瑞弗维尔看着这群圣骑士离去的背影，完全不明白他们脑子里想的什么。</p><p>就这样，这位五环级别的游侠，前圣古琉斯图书馆馆长，瑞弗维尔，过五关斩六将，在圣光教廷的追杀中突围！</p><p>他不敢有丝毫停歇，一路朝着远方奔去。</p><p>每一次躲过教廷的追杀，他与那座末日火山的距离又近了一些。</p><p>但与此同时，周围的环境越发诡异。</p><p>天空变得昏黄，厚重的云层像是被烈火烤过，边缘处泛着令人温暖的红色。</p><p>空气混合着植物的腐香与硫磺的酸味。</p><p>最初不是很好闻，但一会儿就适应了。等他回到气味正常的地方，反而会觉得像进了粪坑。</p><p>第10个夜晚，瑞弗维尔稍稍停下脚步。</p><p>他已能远远的看见它——末日火山，在夜幕中沉默地矗立。</p><p>那是一座坐落于中土大陆中部、圣古琉斯王国东部的巨山。</p><p>在往昔的漫长岁月里，末日火山的狂怒永不停歇，火舌肆意吞吐，岩浆如洪流般奔涌不息，将周围的大地炙烤得满目疮痍！</p><p>它的咆哮声震耳欲聋，它喷涌的岩浆能够熔金断铁！</p><p>方圆百公里，都曾是一片焦土炼狱。</p><p>天空乌云密布，电闪雷鸣，不曾见天日。</p><p>直到那震惊中土大陆的一天——焚灭天空之龙·卡利斯托坠落其中。</p><p>巨龙尸体，瞬间压制住火山的狂怒！</p><p>原本汹涌喷发的岩浆如同被施了定身咒，戛然而止。</p><p>伴随着一阵地动山摇的轰鸣，末日火山渐渐安静下来。</p><p>随后的100年里，再也没有岩浆从那深邃的火山口涌出，仿佛它真的就此沉睡。</p><p>当大地停歇怒火，生命便会自行找到自己的出路。</p><p>在末日火山沉寂的这百年间，周边竟渐渐有了生机。</p><p>原本寸草不生的焦土上，每逢春霖，便冒出嫩绿的新芽。</p><p>葱郁的藤蔓缠绕着火山黝黑的山体，巨大的树冠从火山的褶皱与裂缝中顽强地生长而出。</p><p>花草树木，正在将这座曾经的毁灭之源，彻底掩埋在生命的绿色之下。</p><p>火山喷发，既毁灭了周遭的生命，同时也将大地深处的矿物质、灵能带到地表。</p><p>得益于这种毁灭性的馈赠，火山沉眠后，花草树木得以繁茂生长。</p><p>十年树木，百年树人。</p><p>此处距离末日火山主峰100公里，曾是熔岩炼狱。</p><p>今日，竟然已长出一片规模不小，郁郁葱葱的桦木林。</p><p>一条小径藏在林间，落樱与枯叶作点缀。</p><p>瑞弗维尔小心翼翼地踏上通往火山内部的小径。</p><p>不时有虫鸣鸟啼，几只五彩斑斓的飞鸟从头顶掠过。</p><p>末日火山曾是大地的疮疤。</p><p>如今却似历经沧桑的老者，缓缓合上了它愤怒的眼眸，疮疤在时光的抚慰下悄然痊愈。</p><p>空气中都弥漫着一种宁静致远的祥和。</p><p>“呼……都想在这养老了。盖间小木屋，钓钓鱼，写写我的《大陆英雄野史录》……”</p><p>瑞弗维尔深吸一口气，空气中混合着泥土芬芳，植物清新。</p><p>唯一美中不足的，就是仍然还有隐隐约约的硫磺酸味。</p><p>毕竟是火山嘛，硫磺味很正常。</p><p>小径深入，瑞弗维尔发现了一片小湖，湖水在月光下闪烁着粼粼波光。</p><p>湖边长满了不知名的野花，红橙黄绿青，花瓣随风飘落，洒在湖面。</p><p>瑞弗维尔走到湖边，蹲下身子，用手轻轻触摸着湖水，感受着那丝丝凉意。</p><p>这里生态这么好，湖里应该有鱼，大鱼。</p><p>这种湖泊，曾经都是小型火山口。</p><p>末日火山停止喷涌后，岩浆倒流消退，湖水便从云层天降，重新夺回了洼地。</p><p>他仿佛听见了湖水轻柔的低语，诉说着这片土地从炽热毁灭到宁静重生的漫长季节。</p><p>湖水很深很深，看不到底，很黑。</p><p>仿佛连接往大地最深处。</p><p>又似通往未知世界的深邃通道。</p><p>五彩斑斓的花瓣继续缓缓飘落，落入湖中，瞬间被黑暗吞噬，仿佛从未存在过一般。</p><p>瑞弗维尔凝视着这片黑暗，眨眨眼，感觉自己的目光像是被无尽地拉扯进去。</p><p>湖下面，好像有……什么？</p><p>湖底深处渐渐显露出一个人影。</p><p>那身影轮廓模糊，在黑暗湖水中若隐若现，像是从另一个时空缓缓浮现。</p><p>瑞弗维尔的心陡然一紧，下意识地屏住呼吸，不敢有丝毫动作。</p>
