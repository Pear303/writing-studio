# 大帝群殴

<p>空间仿佛都被冻结，时间也似在这一刻停滞，命运的浮沉似乎也被按下中止键。</p><p>那目光中蕴含的力量，足以让仙帝级强者魂飞魄散，让神皇级存在道心破碎，即便是至尊、准圣见了，也要为之颤抖！</p><p>这便是灵界唯一的圣人，残星道人。</p><p>他的存在，本身就是一个传说，一种禁忌，一股足以颠覆一切的恐怖力量。</p><p>据青丘白璃所说，残星道人证道“帝临真一”的第五境界之后，从未出手。</p><p>所以从没有人试探出他的真正实力。</p><p>据说他曾跨了五个境界击败对手。爽文这么写，都会被读者追着从海南喷到黑龙江。</p><p>此时此刻此地。</p><p>残星道人并未立即动手。</p><p>甚至，杨帝从他目光中感知不到杀意。</p><p>他缓缓说道：“‘仙界’之真相，远超灵界的认知。当归墟大帝从那里归来时，我们这些早已化道的存在，才得以借助某种契机重现世间。”</p><p>杨帝耳朵抖抖，捕捉关键词。</p><p>仙界。</p><p>仙界，看来那就是归墟大帝曾去过的第三个世界。</p><p>他居然还能找到方法，让原本应该已经被埋没于历史的大帝，重现于灵界。</p><p>按照青丘白璃信誓旦旦的说法，大帝死亡之时，都会以“己身化道”。</p><p>大致意思就是，将自己的力量归还于天地。</p><p>包括他们从各地拾取的“零散的法则”，经过重新整理整合，修补制成“本源补丁包”，归还给天道。</p><p>连同自身所集合的“灵气”，也一并逸散，哺养天地。</p><p>这就是一位大帝的死亡，死亡就是大帝的终极奉献。</p><p>抵达“帝临真一”境界，都可称为大帝。大帝的力量来源于天道，他们本身就是天道在人间的行走，死后，自然也要归于天地。</p><p>否则，天地灵气只会一天天枯竭，大道本源只会一日日衰落。</p><p>但灵界发展了不知多少亿年，灵气反而日渐充沛，万物发展反倒愈发繁荣。</p><p>都正是因为大帝以己身化道。</p><p>而现在，那些在死后将自己的一切归还天地的大帝们，回来了。</p><p>是灵界的天道将他们召回？</p><p>还是说，死去的大帝并没有彻底消散，而是去往了仙界？</p><p>如果他们真的是在死后去往仙界，为何又能在灵界，留下切实存在的灵能和本源遗产？</p><p>大帝现身，却没有使此界的灵气浓度环境发生显著变化。</p><p>说明并不是“天道”调用此界资源、把大帝们重新捏出来。</p><p>“大帝死后化道”这6个字的描述中，“死”字和“化道”一词，很可能藏有猫腻。</p><p>化道可能不意味着死亡，而是留了些东西在灵界后，便飞升仙界享福去了。</p><p>化道，是个骗局。</p><p>灵界的大帝，事实上是退休去了！</p><p>归墟大帝对他痛下杀手，是为不让“黑历史”影响自己的退休金？！</p><p>如今42位大帝从仙界归来，将他包围，来者不善呐！不对我才是来者。</p><p>“尊敬的残星道人，重现世间有何目的？”</p><p>残星道人的回答出乎意料：“万古鱼尊。”</p><p>还没等她问清楚起因经过结果，四十一位大帝的目光如万钧雷霆压向杨帝，帝威几乎凝成实质。</p><p>三位“准圣”周身的仙力更是翻涌成灭世狂潮，随时轰然爆发！</p><p>已经迫不及待要开打了？但残星为什么要提万古鱼尊——阿巴？</p><p>杨帝这辈子最恨谜语人。</p><p>特别是那些用谜语拨弄他命运的事逼。</p><p>“等等！”杨帝举手指天，声如洪钟，竟硬生生压下了周遭翻涌的帝威狂潮。</p><p>即将爆发的灭世灵压，被他一声断喝，强行凝滞了一瞬。</p><p>残星道人微微颔首，声音依旧平静无波：“白杨……大帝？有什么想说吗？”</p><p>杨帝瞳中里带着七分狂傲，三分不羁，更有睥睨万古的嚣狂，看向众大帝：“没什么，就是想提醒一下诸位‘老前辈’。”</p><p>他目光扫过那严阵以待的四十一位大帝，尤其在三位准圣身上顿了顿。</p><p>“各位前辈死而复生，一定还不了解我是什么人。哦，归墟大帝其实也不知道。</p><p>“自我介绍一下，我从异界而来，人称白杨大帝，今天站在这里不是为了被各位群殴，而是为了群殴各位。</p><p>“待会儿动起手来，可别怪晚辈……下手没轻没重。为了不把这个美丽的灵界炸掉，我们去天空之上一战吧。</p><p>“之后，若是把诸位前辈打成猪头、狼狈逃回仙界，杨某必定痛打落水狗，而不是传统功夫点到为止那么简单。</p><p>“所以请各位前辈使出全力！！”</p><p>一众绝世强者、极巅存在，自然不会被普通的阴阳怪气所轻易左右神智。</p><p>但杨帝「话术」点数极高，「精神」属性也突破天际。</p><p>现在的他说话，相当于古神低语。</p><p>竟然略微勾起了大帝们心中的怒。哪怕只是一丝怒火。</p><p>“放肆！”</p><p>“狂妄！”</p><p>“无知小辈，安敢口出狂言！”</p><p>除却残星道人与三位准圣依旧沉凝如山。</p><p>那三十八位仙帝、神皇、至尊境界的绝世强者当即对杨帝出手。</p><p>轰隆——！！！</p><p>天地剧震！</p><p>归墟之地本就破碎不堪的虚空，瞬间被彻底撕裂。</p><p>无穷无尽的混沌气流如同决堤的洪流，从四面八方汹涌灌入，却被那交织的帝威强行阻隔、绞碎，形成一片混乱至极的能量风暴带！</p><p>率先动手的是手持断剑的战狂大帝。</p><p>他虽被称作大帝，但有帝临真一的第三境“至尊”境界，能与20个归墟大帝打得有来有回。</p><p>他双目赤红，仿佛回到了那个以战证道、血染星河的峥嵘年代。</p><p>手中那柄看似残破的断剑，骤然爆发出刺穿万古的洪荒煞气！一剑挥出，并非斩向杨帝，而是斩向了杨帝身周的空间。</p><p>“剑断乾坤！”</p><p>嗤啦——！</p><p>一道横贯天地的巨大裂痕凭空出现，并非空间裂缝，而是更深层次的“道痕”。</p><p>这一剑，竟是要将杨帝与灵界天地法则的联系暂时斩断！</p><p>几乎同时，掌控时间法则的溯洄大帝双手结印，时间长河虚影在他身后奔腾咆哮，浪花翻涌间映照出无数过去的画面。</p><p>他也是至尊境界，属于超大号蝼蚁。</p><p>他对着杨帝遥遥一指：“逆流、封禁！”</p><p>一股无形却沛然莫御的时间之力骤然降临，企图将杨帝拖入灵界的时光逆流之中，冻结其当下之身！</p><p>归墟大帝更是冷哼一声，双手虚握，整个归墟深渊的“虚无本源”仿佛都被他调动。</p><p>“归墟葬灭！”像是新招，之前怎么不放？</p><p>无尽的黑水自他脚下涌出，化作亿万条吞噬一切的魔龙，咆哮着扑向杨帝。</p><p>所过之处，连光线和声音都被彻底湮灭。</p><p>但新招也没啥用，还是被他一力破万法了。</p><p>DUANG～归墟大帝砸在杨帝脸上，反而是大帝的右手被炸成红烧凤爪。</p><p>其余三十五位大帝见状，亦是各展神通！</p><p>有仙帝祭出煌煌大日般的帝印，镇压寰宇似的当头砸落；有神皇口吐神言，言出法随，亿万金色锁链凭空生成。</p><p>刀光剑影、神通宝术、法则洪流……</p><p>三十八种截然不同、却又同样恐怖到极点的攻击，从四面八方、上下左右，以毁天灭地之势，瞬间将杨帝的身影彻底淹没！</p><p>那景象，已非言语所能形容，故此处不得不省略50万字。</p><p>宇宙之巅，仿佛瞬间化作了宇宙初开时的混沌原点，又像是诸天万界破灭的终焉之地。</p>
