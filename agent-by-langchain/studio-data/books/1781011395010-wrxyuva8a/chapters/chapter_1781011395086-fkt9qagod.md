# 诈尸

<p>他们用力推开轿厢的门，伴随着一阵沉闷的“嘎吱”声，一股潮湿且带着腐朽气息的空气扑面而来。</p><p>因为轿厢轨道实在过于曲折离奇。</p><p>所以他们都不能很准确判断自己位于何方。</p><p>出了轿厢，他们便发现，此刻置身之处正是火山口内部的底部！</p><p>火山口在上方数百米高处，宛如一只深邃的独眼，遥远的天空显得格外渺小。</p><p>微弱天光从火山口透下来，却好似隔一层厚纱打灯笼，根本无法驱散洞底的黑暗。</p><p>只能勉强勾勒出周围物体模糊的轮廓。</p><p>杨帝眯起眼睛，适应了这昏暗环境。</p><p>瑞弗维尔两眼一抹黑：“兄弟，我什么都看不见，我先点个火或者光……”</p><p>他施法的手被阻止了。</p><p>杨帝用手指轻轻贴住他嘴唇，示意他不要作声，不要发出任何光亮和动静。</p><p>“我感受到了，有人。他们比较远，似乎是站在高处观察我们。”杨帝低声说出一个惊天大事。</p><p>瑞弗维尔屏住呼吸，双目瞪圆。</p><p>圣光教廷……已经在火山口内设好了埋伏？</p><p>二人一前一后这么走着。</p><p>某一时刻，走在最前面的杨帝停住脚步，目光盯着前方黑暗处。</p><p>瑞弗维尔顺着他的视线看去。</p><p>他眼睛已逐渐适应黑暗，只见在不远处的阴影中，似乎有一个庞大轮廓若隐若现。</p><p>但他视力终究不如杨帝，看不真切。</p><p>“兄弟，那是什么？”</p><p>而杨帝呢？面对黑暗中的庞大阴影，心绪早已飘飞到他六岁那年，父母带他去省博物馆看恐龙骨架的那个下午。</p><p>那个下午，那具巨大而神秘的骸骨，又仿佛将他带到了6500万年前的青葱岁月。</p><p>此刻，眼前这黑暗中的庞大阴影，竟与记忆中的恐龙骨架有几分相似的震撼感。</p><p>“看起来……像是某种巨大生物的残骸。”杨帝压低声音。</p><p>但是，“残骸”会动。</p><p>瑞弗维尔咽了口唾沫。</p><p>出现在此处的巨大生物残骸，也只能是昔日的苍穹霸主，焚灭天空之龙，卡利斯托了。</p><p>瑞弗维尔一路走来，自然没有忘记自己的任务——检查卡利斯托的尸体，打探教廷的动静，向国王汇报。</p><p>这十多天了，还经历许多事情。</p><p>他都打算在完成这任务后，告老还乡，回老家退休写书。</p><p>瑞弗维尔想写本“成一家之言”的野史，就叫《大陆英雄野史录》。</p><p>如果一切都能平安落幕，他或许会写圣骑士巴德讨伐卡利斯托时，偷摸到巨龙身后砍屁股，又或者是一个登龙剑让巨龙下头。</p><p>但Flag立早了。</p><p>瑞弗维尔绝望地看着黑暗之中，那团如山岳庞大的阴影缓缓向他们移动而来。</p><p>而身旁的杨帝始终一言不发。</p><p>但他能感觉到，这位失忆的传奇近战法师，呼吸也变得急促。</p><p>“瑞弗维尔，已经来不及慢慢教了，我要你在3分钟之内，将你还没教给我的攻防类法术都展示出来。”</p><p>杨帝低声快速说道，“不需要开灯，我能看见灵的流动。”</p><p>瑞弗维尔如梦初醒：“哦……好！”</p><p>瑞弗维尔飞一样地开始展示，那是最简单的一环、二环法术，然后是更困难的三环、四环。</p><p>他双手如幻影般舞动，口中念念有词，一道道灵能从他指尖迸发。</p><p>异世界土著的施法方式很繁琐。</p><p>杨帝本身学习能力相当于普通人100倍。</p><p>他还能够省略咏唱咒词、构筑术型，跳过这些最难的重点，直接调动环境中的“灵”进行施法，法术学习速度至少提升20倍。</p><p>100×20=2000倍学习速度！</p><p>假如一个3环法术，需要10小时完全集中、不间断地学习和练习。</p><p>那杨帝只需要……18秒，理论上。</p><p>瑞弗维尔不明所以，只能照杨帝所说的做。</p><p>先是二环法术“微光护盾”，然后是三环法术“奥术飞弹”……</p><p>杨帝全神贯注地看着瑞弗维尔展示的每一个法术，精神力高度集中，仔细捕捉每一个法术中灵能流动的轨迹和细节。</p><p>瞳孔中闪烁过万千个幻境与光影。</p><p>三分钟过去，那如山岳般庞大的阴影已经更近了。</p><p>末日火山底部空间非常宽敞，足以容纳10个完整足球场。</p><p>瑞弗维尔他们也不是没尝试过重启轿厢。</p><p>但他们搭的车，似乎是单程票，回去的路被堵上了……</p><p>很明显，灵能轿厢数千年后还能启动、轨道通畅无阻、能源系统仍然正常运作——并不是因为“矮人工艺，震撼人心”。</p><p>而是……瓮中捉鳖。他们二人是鳖。</p><p>只是杨帝不明白，为何瑞弗维尔的“商业竞争对手”要搞这么多弯弯绕绕，把他们引进这种“瓮”再动手。</p><p>路上直接对他们下手不好嘛。</p><p>自己在异世界，又不是什么出名的大人物。</p><p>为何要如此大费周章设下陷阱，请君入瓮，瓮中捉鳖呢？</p><p>甚至还动用了昔日的天空霸主。</p><p>焚灭天空之龙·卡利斯托！！</p><p>杨帝施展了一道超大功率照明术，将整个火山内部洞底照亮。</p><p>在照明术加持下，瑞弗维尔终于绝望地肯定，那就是卡利斯托！</p><p>至少外表和体型一模一样。</p><p>巨龙每一步落下，大地都如遭重锤，发出沉闷震颤。</p><p>那震动顺着二人的脚底直传心底，令他们的五脏六腑都跟着微微发颤！</p><p>一双萤萤鬼火的龙瞳，自黑暗中浮现。</p><p>“你不是说那龙死了吗？！”</p><p>“我咋知道它会复活？”</p><p>瑞弗维尔拉着杨帝跑，“别学什么魔法了！我们得赶紧想办法离开这儿，回到王国警告所有人……”</p><p>在强光的映照下，卡利斯托那庞大的身躯完全展露在二人眼前，一股令人窒息的压迫感扑面而来。</p><p>仿佛一座山岳。</p><p>它身上的青金色鳞片，历经岁月与战斗的洗礼，依旧散发着金属般冷冽的光泽，犹如一片片精心锻造的铠甲紧密相连。</p><p>每一片鳞甲足有一人大小，边缘锐利如刃，缝隙间，隐隐透露出滚烫红光。</p><p>那光芒好似来自地心深处的火焰，炽热且充满毁灭的力量。</p><p>这红光随着卡利斯托的呼吸节奏，有规律地明灭闪烁。</p><p>每一次红光的闪烁，都伴随着一阵热浪的涌出，空气中弥漫着焦灼！</p><p>杨帝背包里的熔岩史莱姆也躁动不安起来，像20只受惊的猫狗挤在同一个背包里扭动。</p><p>他看着包中的史莱姆。</p><p>“瑞弗维尔，来不及解释了，快上车。”</p><p>杨帝当机立断，一把将背包里躁动的熔岩史莱姆扯出，迅速摊开！</p><p>他可是熟读一千零一夜的神州青年，各种求生手段信手拈来。</p><p>他对着瑞弗维尔喊道：“快趴上去！”</p><p>瑞弗维尔没有丝毫犹豫，一个箭步就趴到了史莱姆之上。</p><p>杨帝以无比强大的意志迫使现实发生扭曲，默声瞬发，施展出一道凌厉的风系法术！</p><p>刹那间，狂风骤起，围绕着他们二人飞速旋转，强大的气流托举着他们缓缓升空。</p><p>瑞弗维尔惊喜：“杨帝兄弟！你是不是恢复记忆！想起自己是传奇法师！然后把那些什么八环九环十环法术全部回忆起来了！”</p><p>杨帝：“？什么传奇法师？”</p><p>“那你现在用的这法术是什么？我没记得自己教过你。”</p><p>“三环法术·旋风术。”杨帝如是说道。</p><p>瑞弗维尔又双叒叕瞠目结舌：“不可能！旋风术没有这个精度和力度，不可能把我们竖直平稳地向上托举！”</p><p>这道法术从本质上来说，就是召唤一阵呼呼猛刮的大风，或者做匀速圆周运动的旋风。</p><p>杨帝正在调动所有精神操控“灵”。</p><p>他只能分出0.1%的注意力，随口答道：“你多释放十几个，从不同角度向上托举。”</p><p>瑞弗维尔再次惊骇。</p><p>瞬发+默声+同时施放多法术。还是同时释放十几个法术？</p><p>杨帝是个什么物种？</p><p>但很快，瑞弗维尔就开始为别的事情惊叹怖惧了。</p><p>就在他们刚飞起来十来米，变故陡生！</p><p>山壁上的岩穴里，爆发出一道道耀眼的法术光芒——圣光类攻击法术！</p>
