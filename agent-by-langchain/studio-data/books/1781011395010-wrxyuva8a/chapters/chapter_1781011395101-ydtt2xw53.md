# 秘密

<p>杨帝呼吸和心跳频率瞬间上升了10%，但他很快就压制回去。</p><p>他问：“伊芙，你不是说，你不当文青精灵，转而投身理工科了吗？”</p><p>伊芙打哈哈道：“嘿，谁说投身理工科就不能懂这些啦，知识又不是泾渭分明的，多懂点总没坏处。”</p><p>她眨着灵动的眼，似笑非笑看二人。</p><p>“杨帝，奥拓，你们突然聊起这个，不会是真遇到类似的事了吧？”</p><p>杨帝：“……只是和奥拓闲聊，突然想到这么个假设而已。您可别多想。”</p><p>“是的是的是的。今晚吃兔肉，要不我去准备准备，看看能不能变点花样，让大家吃着不那么腻……”</p><p>奥拓站起身溜走。</p><p>伊芙注视着矮人远去。</p><p>杨帝正欲起身去帮奥拓处理兔肉，法杖末端却轻轻点住他的衣角。</p><p>伊芙看着奥拓远去的背影，轻声对杨帝说：“大老远听见你们在谈浮士德什么的。所以，你也看出来他的秘密了吧？”</p><p>杨帝露出奔波儿灞的表情：“啊？我？谁？看出什么？他？秘密？”</p><p>“瑞弗啊！心神不宁，你没察觉到？这两天他总是一副心事重重的样子，老是走神，之前他可不是这样的嘛……”</p><p>伊芙托住下巴，有些忧郁。</p><p>原来如此。这位精灵作为队伍领袖，自然也很关心大家的身体心理健康。</p><p>杨帝摇摇头：“我这两天对付杀手兔，又忙着‘回忆’人生，没留意。他怎么了？”</p><p>“比如今天上午赶路时，他眼神飘忽迷离，好几次差点撞树上。还有几十次，是直接撞树上了。”精灵回忆道。</p><p>杨帝斟酌着说：“那……有时间找他聊聊？”</p><p>“没错，有时间你就找他聊聊。”</p><p>“？为什么是我，你不行吗。”</p><p>伊芙白了杨帝一眼，“我去问，多不合适啊，显得我特别在意他似的。你和他都是人类，更容易沟通些。”</p><p>杨帝恍然大悟：“确实也是。我也觉得你的思维结构人类不太一样。”</p><p>精灵龇起牙：“总之，你可别想歪了，不然有你好看的。”</p><p>“等会儿我就找瑞弗维尔聊聊，看看他到底怎么回事。”</p><p>杨帝曾有段时间情商特别高。</p><p>但后来，在10%潜意识的状态下思考太久，他返璞归真了，显得情商和小孩没有区别。</p><p>当然换句话说，你可以说他“回归童心”，完成了狮子骆驼小孩的超人转变。</p><p>庆幸，智商不会物极必反。就像数学题，会就是会，不会就是不会。</p><p>并不会说，智商太高、知识太多的时候，反而不会做加减乘除。</p><p>……</p><p>月光如同妈妈地拖得满地板消毒水，静静地流淌在起伏的山丘之上。</p><p>原本嶙峋的山体，蒙上层柔和的薄纱。</p><p>远处的山谷中，影影绰绰地生长着树木，轮廓在月光下显得愈发朦胧，像是群沉默，亘古的卫士。</p><p>有一条蜿蜒的小溪，河波粼粼，流光碎银。</p><p>溪水潺潺流淌，咕咚咕咚很是清缓。</p><p>如果杨帝没有经历过那些事情，他的毕生梦想，就是35岁前拼掉半条命攒够钱躺平，婚也不结了，回到家乡的水库边，就天天和老爸一起钓鱼，主要是钓水鳖。</p><p>虽然他曾经害怕水，但不怕钓鱼。</p><p>鱼不会淹死，他曾羡慕鱼。</p><p>也羡慕水鳖，不仅能游泳，而且生来就有房。</p><p>溪边石头上，瑞弗维尔静静地坐着，他的身影在月光下拉长。</p><p>杨帝起身朝他走去，在他身边坐下，起手一个地球名句：“瑞弗维尔，今晚月色真美。”</p><p>瑞弗维尔回过神，看了眼天上两轮月亮，“是啊，真圆。”</p><p>但明显，今天左边的月亮是上弦月，右边的月亮则是下弦月，根本圆不了一点。</p><p>看来，瑞弗维尔确实很心不在焉。</p><p>看来伊芙猜得没错，瑞弗维尔确实有心事。</p><p>杨帝斟酌了一下措辞，问道：“瑞弗维尔，你这两天不对劲。”</p><p>瑞弗维尔浑身一震：“这么明显？”</p><p>“没事，目前也就我一个人看出来了。要是信得过我，就跟我说说吧。”</p><p>瑞弗维尔身子微微一僵，沉默了好一会儿，才缓缓开口道：“杨帝，你能保证不把我说的话告诉伊芙吗？”</p><p>杨帝连忙点头，“当然，我保证。”</p><p>“我……我又开始做噩梦了。”</p><p>“又梦见焚灭天空之龙·卡利斯托了？那龙我们不是见过了嘛，那条所谓复活的龙，只是教廷的人试图用熔岩史莱姆‘仿生’的。”</p><p>虽然不知道圣光教廷的人在做什么生物实验。</p><p>但显而易见的是，那只“冒牌卡利斯托”弱不禁风，根本翻不起风浪，就被伊芙摁死了。</p><p>瑞弗维尔恐惧地摇摇头：“不，不是巨龙。这次的噩梦，和以前梦见‘卡利斯托’不同，这次我梦到的是……杨帝，你千万不要和伊芙说。”</p><p>杨帝连忙点头，“当然，我保证。”</p><p>瑞弗维尔深吸一口气，像是鼓足了莫大的勇气才接着说道：“我梦到伊芙……她追杀我们。”</p><p>沉默是今夜的小溪，沉默是今夜的丘陵，沉默是今夜的杨帝。</p><p>“杨帝，这个梦太过真实了，真实到我现在想起来，还心有余悸。”瑞弗维尔捂着脸，痛苦道。</p><p>杨帝眉头紧蹙，眼中满是难以置信：“你确定那是伊芙？”</p><p>瑞弗维尔狠狠地点头：“确定，她的金色瀑布编发，青绿短披风，橘红熔岩发卡，凉鞋，甚至连她身上那股淡淡的柑橘气味都一模一样。除了……”</p><p>“除了什么……”</p><p>“除了眼睛。在梦里，她目中无神，像是具盲目吃鱼的提线木偶。”</p><p>杨帝想到了那些西幻冒险小说里的固有情节：同伴被蛊惑、影响心智，所以“背叛”。</p><p>难道伊芙也遭遇了这样的事？</p><p>可他们一路走来，并未察觉到什么异常力量的存在。</p><p>……有一种可能，就是超越了理性和逻辑的不可名状之物，才有几率影响一个十环超限法师的心智。</p><p>比如说，“原初之眼”。</p><p>但那只象征着“世界第一次观察”的眼睛，已经被放逐到“虚境”。</p><p>自从不知多少万年前被封印，原初之眼再没有翻起风浪。</p><p>不过，“圣光教廷”似乎与原初之眼有联系。</p><p>他们难道有能力把原初之眼，从“虚境”中拉回来吗？</p><p>瑞弗维尔继续说：“杨帝……我也希望只是我想多了。但如果这个梦真的是某种预兆呢？万一伊芙真的……我不敢想象会发生什么。”</p><p>杨帝拍拍他肩膀：“没事的兄弟，你想想，你之前不也预言到巨龙会复活？</p><p>“但结果呢，却是套了层龙皮的史莱姆。我说这个，并不是为了证明你预言能力很差。</p><p>“而是想说，预知术、未来梦境画面，也有可能是骗人的。</p><p>“如果你学过新闻学传播学，应该会对我的话深有感触。”</p><p>瑞弗维尔若有所思地点点头。</p><p>他看起来好多了。他说：“你这么一说，我也好像明白了，毕竟我也饱览野史，知道史官会用各种春秋笔法、冬夏笔法修饰历史。想必梦境也是如此。”</p><p>杨帝最终没有向伊芙说实话。</p><p>只说“瑞弗维尔又梦到焚灭天空之龙了”。</p><p>他也对这精灵留了个心眼。</p>
