# 真实虚幻2

<p>杨帝神色认真，缓缓说道：“59改，在虚拟空间里，数据是以一些可认知的量来表示万事万物，通过这些数据的运算与交互构建起一个模拟世界。而在宇宙之中，物质、时空、灵能、法则，其实也是这个世界向我们敞露出来，可以被认识的部分。”</p><p>世界的最底层一般被称作“虚境”。</p><p>而表层，则是摸得见看得着的“万物”。</p><p>虚拟空间里的数据，是我们对现实事物的一种“翻译”，用可认知的量来代表万事万物。</p><p>而在真实的宇宙中，物质、时空、灵能以及各种法则，同样是世界呈现给我们，让我们能够去认识和理解的东西。</p><p>“虚拟空间，现实世界，两者本质并不一定是不一样的。”杨帝如此总结道。</p><p>守望者·59改还是转不过弯儿。</p><p>「杨帝阁下，我理解您试图探寻两者共通本质的想法，然而，虚拟空间与现实世界尽管可以有颇多相似，但仍然有一个难以弥合的差异。」</p><p>「那就是‘现实’本身。」</p><p>「我们所认知的物质、时空、灵能以及各种法则，只是这个‘现实’呈现出来的表象。」</p><p>「即便虚拟空间能够用数据去模拟这些表象，可它始终缺少了那个最为本真的‘现实’。」</p><p>「虚拟空间里的数据模拟，无论多么精确，终究是基于我们对现实的认知和解读，是一种人工构建的‘拟像’。」</p><p>「但现实世界的运行，是基于一种自然而然、不受我们认知局限的本真现实。」</p><p>杨帝耸耸肩，看向阿巴。</p><p>“鲈鱼，这些搞科学研究的，多多少少都沾点唯心啊。”</p><p>阿巴和青丘白璃正蹲在一起吃瓜看辩论。</p><p>都是宇宙级强者，都是超级大能，都是一步一个脚印修炼上来的。</p><p>她们自然也都能听懂杨帝和59改都在说些什么。</p><p>只是些非常浅显易懂的讨论，关于宇宙，生命，意义，以及一切的终极答案，远比搓一个10环法术，或者是做一道守望者文明600年级期末考试的数学大题要容易多了。</p><p>但为了让领导倍有面子。</p><p>阿巴甩了甩鱼尾，一脸天真，眼神比大学生还清澈：“老大，什么意思。”</p><p>杨帝笑着解释：</p><p>“59改觉得，万物背后藏着个最本真原始的东西，类似绝对真实的‘模板’。</p><p>“现实里我们感知到的一切，都是从这‘模板’衍生的表象。虚拟空间即便能模仿表象，也触及不到最核心的‘现实’。</p><p>“好比照着苹果画的一副画，再像，也不是真苹果。59改认为现实是真苹果，而虚拟空间只是那幅画。”</p><p>阿巴点点头，其实不用比喻她也能明白的。</p><p>“那么杨帝阁下，你的看法和五九改的分歧是？”青丘白璃说道。</p><p>她和阿巴提前谈好了，一人问一句话，公平地浪费口水。</p><p>杨帝扭动着他在虚拟空间中不可名状的彩色斑斓身躯，看向天边。</p><p>“我有一个故友……不不不她没死。她只是曾经启发了我——判断一只史莱姆有没有真正的智慧时，它‘内心’是怎么想的并不重要，重要的是它表现出‘智力’这一现象即可。”</p><p>本质不重要，现象更重要。</p><p>在一个能从物质、时空、灵能等所有层面完美复现现实世界运行逻辑的虚拟空间里，无论从何种维度观察、用何种方式验证，都与现实世界毫无差异。</p><p>“既然如此，为何不能将其视作现实？难道仅仅因为你肉身所在的宇宙，万物是由‘基本粒子’相互作用构成，就比通过‘数据’运行的虚拟空间更接近‘真实’吗？”</p><p>59改秉持“本质优先”的世界观，这套逻辑至今运行顺畅，很少导致他宕机。</p><p>而杨帝则倾向“现象优先”，从他的处事风格可见一斑——为人随性，不执着于探究事物本真，凡事只求“差不多就得了”即可。</p><p>「杨帝阁下，若按您所说，虚拟空间与现实世界的本质可能一致。」</p><p>59改的机械音陡然锐利，显然已与杨帝杠上。</p><p>「那请问：您如何证明一个在所有表象上都等同于‘现实’的虚拟空间，其本质就真的与现实世界无异？」</p><p>杨帝那由无数蠕动线条与闪烁光斑构成的怪异形体微微一滞，似陷入短暂沉默。</p><p>此前的探讨，更多基于直觉与宏观思考，尚未触及如此尖锐的本质叩问。</p><p>杨帝与59改在虚实本质的思辨中激烈交锋。</p><p>59改继续说道：</p><p>「杨帝阁下，您瞧，虚拟空间与现实世界还有一个显著差异。」</p><p>「在现实世界中，每一个物体的属性都有着其基于自然规律的精确设定，哪怕我们尚未完全认知。」</p><p>「但虚拟空间却很难做到对物体全部属性的精确模拟。」</p><p>「就以你为例，您那突破天际的精神属性，一旦进入虚拟空间，便会导致空间撑爆。」</p><p>「虚拟空间在对不可认知属性的承载和模拟上，存在着局限性，无法像现实世界一样，精准地定义和容纳过于复杂且强大的存在。」</p><p>杨帝抠抠耳朵——在外人看来只是一大团斑斓的色彩突然蠕动——叹口气：“说到底，你还是认为现实世界‘无上限’，而虚拟世界‘有限’？”</p><p>「正是如此。」</p><p>“我撑爆了你先前的虚拟空间，也撑爆了青丘白璃的领域。”</p><p>「嘿，说得对。」</p><p>“所以无论是你的赛博领土虚拟空间，还是她的诛魔破阵小宇宙，都算不上‘现实’，而是类似于‘虚拟空间’的虚假现实。”</p><p>「就是这个理。」</p><p>“有限的虚拟空间无法承载我的精神，所以将我表现为不可名状的扭曲斑斓彩色线条；土著狐妖的诛魔破阵领域无法容纳我的灵能，所以她的琵琶原地爆炸。”</p><p>「这正是人造小世界、虚拟空间‘有限性’的力证。」</p><p>杨帝冷笑起来，你这铁罐头机械榆木脑袋还没意识到吗？</p><p>“那么，五九，回答我！为什么在所谓的‘现实’里，你们看我的眼神那么奇怪？！”</p><p>杨帝的精神力量不再掩饰，从0.01%飞跃至0.1%，周身彩色光斑陡然暴涨，蠕动的线条如挣脱枷锁的野猪般炸裂。</p><p>虚拟会议室里，金属墙面裂纹蔓延，银灰色涂层如受潮墙皮层层剥落，露出锈蚀的合金骨架，并以肉眼可见的速度风化。</p><p>他顷刻将59改的虚拟会议厅彻底撑爆！</p><p>众人的意识骤然抽离，跌回现实世界。</p><p>59改、阿巴和青丘白璃仍怔在原地。</p><p>他们看到，杨帝身上诡异的“负值灵能”。</p><p>正常的修仙者，周身灵能都是如孔雀开屏般外放。</p><p>而杨帝，周围灵能则是像鹌鹑一样，向内收敛。</p><p>他们看杨帝的眼神很奇怪，原因就在于此。</p>
