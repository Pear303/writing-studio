# 极度危险！

<p>钓鱼佬着手展开了第二次实验。</p><p>他们再次将“猫条”、牛蛙和定位仪以同样的方式串串好，投入电梯井的黑暗水体之中。</p><p>伴随着“呱——噗咚——”的声响，牛蛙和定位仪再次迅速消失在水中，钓鱼线瞬间被绷紧。</p><p>杨帝拉扯绕线板，肌肉紧绷。</p><p>经过一番拉扯，钓鱼线被完全拉出时，结果依旧如第一次那般。</p><p>线的末端已经没有了牛蛙和定位仪，这次连蛙腿也被扯掉了大半，只剩一对小蛙脚，上面沾了些许暗红色黏液。</p><p>这次，气味有所不同。</p><p>没有了腐烂的鱼腥味，只剩下硫磺味、蛋白质烧焦气味。</p><p>他们马不停蹄开始第三、第四次实验。</p><p>过程与前两次并无二致，结果一样。</p><p>后面几次都没有鱼腥味，但硫磺味是一定有的。</p><p>“所以说，黑水对面很可能联通的，不是深海海底——或者不是纯粹的海底环境。”</p><p>杨帝拿起定位仪的追踪设备。</p><p>屏幕上一片空白，没有任何信号反馈，定位仪就仿佛从这个世界上消失了般。</p><p>“找不到它们，完全没有信号，这些定位仪就这么凭空消失了。”</p><p>钓鱼佬：“也可能没消失，比如GPS传送到深海环境，水压会一瞬间把仪器压坏。就算仪器没损坏，那里太深了，卫星信号也连接不上。”</p><p>总之，黑水对面连接到了会瞬间把仪器损坏，或是接收不到卫星信号的环境。</p><p>甚至，黑暗水体连接的区域很可能不局限于地球。</p><p>还有几十只牛蛙，继续实验。</p><p>一只又一只的牛蛙被投入黑暗水体之中。</p><p>每次都伴随“呱——噗咚——”的声响。</p><p>等上个8分钟10分钟，在某一时刻，他们的注意力同时移开时，钓鱼线就会被猛地绷紧。</p><p>杨帝便开始拉扯绕线板。</p><p>很少有让人眼前一亮的新结果。</p><p>不过，当第10只牛蛙被抽回时，钓鱼佬都被眼前的景象惊住，杨帝也为之侧目。</p><p>这只牛蛙的皮肤千疮百孔，就像被无数尖锐的物体同时穿刺过。</p><p>体内的血肉内脏都瘪了下去，仿佛是被人从皮肤里，硬生生地挤了出去，只留下一张残破不堪、皱巴巴的外皮。</p><p>皮上还沾着斑驳的暗红色黏液，散发出更加浓烈的怪异气味。</p><p>“这……到底是什么情况？”钓鱼佬瞠目。</p><p>眼前的场景超出他的认知范畴。</p><p>是什么样的存在，能用不到10秒将一只牛蛙戳出千疮百孔，然后将血肉、脏器都从皮肤挤出去？</p><p>异形？铁血战士？</p><p>杨帝眉头紧锁，仔细地观察着这只牛蛙。</p><p>“黑暗水体另一端，存在某种强大的力量，能够对生物造成毁灭性的伤害。”</p><p>还没等钓鱼佬从这只牛蛙带来的震惊中缓过神来，又一只牛蛙被抽了回来。</p><p>这只牛蛙的状况更惨不忍睹。</p><p>它身上带有明显的焦炭化血肉，部分身体已经变成了黑色的焦炭，散发出刺鼻的焦糊味。</p><p>“怎么会这样……那里确实存在高温环境，能瞬间将生物烧焦？”钓鱼佬也凑近了。</p><p>显示屏上，仍然没有这几个定位仪的信息。</p><p>杨帝没有立刻回答，他陷入沉思。</p><p>他首先总结：“我们经过至少10次实验，牛蛙的下场都极度相似，同样是被某种巨大的力量拉扯，残肢处带有兼具硫磺味、蛋白质烧焦味的黑色粘液，有时可能带有少量腐烂的鱼腥味。”</p><p>钓鱼佬接过话茬：“既有类似能产生强大挤压力的东西，又有高温、干热的环境。”</p><p>所以，黑暗水体所连接的区域，大概率不局限于地球。</p><p>也许是宇宙中某个地方。</p><p>但“水体”和“干热”两个词，本身是对立的。</p><p>又要在水里，又要干燥，不可兼得吧？</p><p>以钓鱼佬甚至是杨帝的知识储备，找不到几个可能的答案。</p><p>“如果固态和气态水，也能视作‘水体’，那也许在彗星接近恒星时，会生成一片既是水体、同时干燥火热的区域。”</p><p>彗星接近太阳时，表面温度会急剧升高。</p><p>冰的升华和喷发，表面变得干燥。</p><p>但内部仍然存在未升华的冰。</p><p>这种情况下，彗星表面可能看起来干燥，而内部仍是一片“水体”。</p><p>杨帝耸耸肩，“但谁知道呢。不说我们的太阳了，宇宙中恒星那么多，彗星更多，排查是绝对不现实的。而且，我们对这种黑色水体机制的理解，也根本不够全面。”</p><p>他们没有停下实验的打算。</p><p>剩下的牛蛙一只接一只地投入水中。</p><p>每一次拉回，呈现出的都是不同却同样恐怖的惨状。</p><p>有的牛蛙身上布满了奇怪的黏液，仿佛被某种未知的生物包裹过。</p><p>有的牛蛙则像是被强酸腐蚀过，身体残缺不全。</p><p>钓鱼佬内心的不安越来越深。</p><p>所有实验结果都在指向同一件事——黑色水体对面，很危险！</p><p>他的学生恐怕亦是凶多吉少。</p><p>毕竟茫茫宇宙中，适合人类生存的地方少之又少。</p><p>尽管是孕育了生命的地球，人类能够生存的区域仍然微乎其微，只有热带到极圈之间一部分浅浅的岩石地表。</p><p>和地球总体积相比，根本是沧海一粟！</p><p>人类穿越到“黑水”另一端，最大的可能是在数秒内丧生。</p><p>而那几个学生，已经失踪十年。</p><p>即使让贝爷、德爷本尊，在物资丰富的热带雨林里与世隔绝生活十年，也保不齐感染什么寄生虫、疾病而中途出局。</p><p>别提黑水对面有可能是恶劣的环境、而那四个学生也非荒野求生专家。</p><p>钓鱼佬很快平复住了躁动的心情。</p><p>其实，他知道自己的学生凶多吉少。</p><p>以前他不愿去想，而现在杨帝告诉他“在做一件事情前必须要有相应的觉悟”，他也慢慢开始接受现实。</p><p>试验到第30个牛蛙，杨帝暂停。</p><p>“叔，经过这30次实验，目前看来有两个可能性。”</p><p>钓鱼佬：“你说，我看看有无补充。”</p><p>“第一，这处黑色水体连接的地方，大概率是同一个地方，有着相对稳定的环境。”</p><p>“不错，每次实验牛蛙都呈现出相似惨状，残肢上有类似气味的黏液。”</p><p>“第二，触发黑色水体的连接效应时，可能会对生物本身造成灼烧效果。”</p><p>钓鱼佬沉吟片刻。</p><p>“你是说，这些暗红色的粘液并非完全来自于目的地环境，而是在‘传送’的过程中产生的。”</p><p>就好像，目的地A和目的地B，都是适合人类生存的环境。</p><p>但是，往返A和B，需要经过一道岩浆瀑布冲洗。</p><p>结果，生物就在半路上被烤焦了！</p><p>目的地A和目的地B本身很安全。</p><p>黑色水体“传送”的过程却不安全。</p><p>杨帝接着说道：“如果是第一种可能，那我们面对的就是一个极度危险且未知的固定环境；若是第二种，那就意味着黑暗水体的传送机制本身就存在对生物有害的因素。”</p><p>不管怎样，想要找到你学生的下落，难度都超乎想象。</p><p>钓鱼佬叹了口气。</p><p>“我知道你想做什么，你想告诉我，被黑水吞噬必定活不下来，让我死心，不想让我继续浪费生命。”</p><p>杨帝点点头，没有否认。</p><p>钓鱼佬：“你的心意我领了，但万里长征才刚迈出第一步，我不会这么快做决定。把剩下的牛蛙都用完吧。”</p>
