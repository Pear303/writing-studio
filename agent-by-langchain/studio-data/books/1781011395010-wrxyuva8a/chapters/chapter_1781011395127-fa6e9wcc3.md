# 兆载揭谛（上）

<p>“原初之眼，你给予我的记忆虽然零散，但对我来说已经足够。</p><p>“我将这些片段进行整合，再结合我自身对精神力的理解和掌控，终于找到了构建大脑封闭术的方法。</p><p>“现在，你再也无法随意侵入我的意识，我有了真正和你平等谈判的资本。”</p><p>说罢，杨帝气息不再掩饰，精神爆发出璀璨如烈日的精神光辉，沿着意识边界疯狂切割。</p><p>在原初之眼侵入的“灵”体上，以雷霆之势进行着阻隔与排挤！</p><p>“给我——出去！”杨帝的意识嘶吼在这片混沌空间中炸响，每一个字都裹挟着恐怖的精神威压。</p><p>原本正在缓慢渗透杨帝的原目之“灵”，像是被无形巨手狠狠攥住，逆推回去！</p><p>原初之眼默默看着他。</p><p>「杨帝，你其实根本不必担心因我作为‘宇宙规律’被杀死，而导致世界运行出现问题。」</p><p>口说无凭，根本信不过。</p><p>杨帝摇摇头：“我向来不惮以最大的恶意揣测度量你……”</p><p>他感觉到一丝不对劲。</p><p>尽管自己正在使用大脑封闭术，将原初之眼的“现实”驱赶出去。</p><p>但他与祂的绝对距离，仍然在缓慢、但坚定地缩小。</p><p>「在宇宙的历史之原点，所有基本粒子同时重叠在一个点，这是宇宙中最特殊的‘沙子’。」</p><p>原初之眼的声音，亘古般平静。</p><p>「我们回溯时间，来到接近宇宙原点之时，万物向一个点的收缩，就几乎不是人力所能阻止的了。」</p><p>「——那是宇宙最本源、万物最本真、时空最本质的力量。只有迈过终极飞升的强者或文明，才有抗衡整个宇宙的力量。」</p><p>「你的‘灵’和我的‘灵’，会重叠在一起。」</p><p>「那时候你的主体现实，会消融在我、消融在万物的客体现实之中。」</p><p>“啧。”</p><p>杨帝没想到，他已进化到这般不可名状的境地，仍然会被一颗眼珠子战略欺骗。</p><p>但这是阳谋，他不得不跟。</p><p>「我的主体性现实过于庞大，原本并不足以通过‘消融到万物之中’来自杀。」</p><p>「也就是说，回到宇宙最初的起点，原本并不足以杀死我。」</p><p>「但现在，你已消化吞噬了我大部分主体性现实。」</p><p>「剩余的‘我’，已经很弱小。」</p><p>「再回到历史原点，用万物的现实稀释我的‘现实’，已经足以抹杀我了。」</p><p>「杨帝，现在你面前又有两个选择：继续杀死我，或者是等死。」</p><p>杨帝冷冷道：“你有些魔怔了。我做第三个选项，驾驶机兵重返未来。”</p><p>他意识猛地扎进机兵主控舱。</p><p>他猛然间发现，自己无法操控机兵了。</p><p>无数数据流像被撕碎的纸片，在空气中盘旋消散。</p><p>原初之眼的声音却再度响起，这次竟从机兵内置的广播中传来，带着某种近乎悲悯的颤音：</p><p>「难道你没有好奇过，为何我不选择将自己的意志降临到机兵身上？」</p><p>杨帝再度惊叹于自己战略思维的稚嫩。</p><p>原初之眼决心要自杀之时，祂需要将自己的意志投影到物质世界。</p><p>在物质世界，必须要有一副足够高强度、智力足够高级的躯体。</p><p>而无限机兵，拥有坚不可摧的物质构造，极度科幻风的计算机系统。</p><p>一副身体，一个大脑……无限机兵，完美符合原初之眼夺舍的两个前提！</p><p>但原初之眼没有那么做。</p><p>祂把无限机兵的控制权交给伊芙和杨帝。</p><p>原因绝对不只是忌惮“星环盟约”。</p><p>「自始至终，我的目的都是‘自杀’。」</p><p>「在发现你能消化、磨灭我的‘灵’，我就决定不去占据无限机兵，而是让你驾驶，作为第一道考验。」</p><p>「如果事实证明，你确实有无匹的意志力，以及上限深不可测的进化适应能力，我就会让你吞噬我的现实，达成第二种‘自杀’方法。」</p><p>「而不是将整个宇宙推向毁灭。」</p><p>「毕竟……我也拥有凡人的情感，凡人的心智。」</p><p>原初之眼已经对这宇宙的万物生灵，诞生了某种特殊感情。</p><p>尽管京垓兆亿年的记忆几乎要将祂推向疯狂，但祂知道，这不是宇宙万物的过错。</p><p>在保证能自杀成功的前提下，原初之眼还是希望，宇宙、生命、爱与万物的意义，能够延续下去。</p><p>“那么你为何要劫持我的无限机兵，强迫我吞噬你的‘主体性现实’？你目的已经达成，无论现在我做什么，你都能自杀成功。而你也拥有人的情感，为何一定要我吞噬你？！”杨帝咬牙，勉强启齿问道。</p><p>他正在尝试夺回对无限机兵的控制权。</p><p>这个过程比较艰难，但只要给杨帝时间，他绝对能做到，因为他在永恒进步。</p><p>但是……现在最缺的就是时间。</p><p>宇宙，很快将要走向它的起点。</p><p>届时，万物重叠于同一个点上，他的“主体现实”将被四面八方挤过来的万物之“客体现实”所稀释。</p><p>杨帝很可能会丧失自己的“主体现实”——那是绕过他的进化适应能力、让他彻底死亡的一种可能的方式。</p><p>除非，他答应撤除“大脑封闭术”，让原初之眼被杨帝吃下。</p><p>可是，为什么？</p><p>「我希望你尽可能变强。」</p><p>「我也不清楚‘星环盟约’之善恶立场，如果他们对生命和意义万般漠视，希望你可以保护这个世界。」</p><p>「同时，我希望你能……击败该死的‘话本编撰者’。所以，你得多吃点，你得变得更强。」</p><p>杨帝神色从默然，到愤怒，最后是深深的，毫不掩饰的鄙夷。</p><p>“先前的大战，你所杀死的生命同样数以万亿计。</p><p>“所以，不要假惺惺地说‘希望我保护这个世界’。</p><p>“你逼迫我吞噬你，真正目的是让我替你对耶罗大仙复仇，而不是其他更崇高的理由。</p><p>“你自己也坦白，你所获得的是凡人心智，凡人自有局限性，我也不例外。你不必把自己包装得如此高尚。</p><p>“我？我也没得选了。既然你能做到这个地步，那我也只能收下你的‘馈赠’。”</p><p>杨帝放开他的“大脑封闭术”。</p><p>原初之眼的主体性现实涌入杨帝体内，横冲直撞，但很快就被他的消化能力所磨灭、攫取。</p><p>「现实+1+1+2+3+5……」</p><p>祂的计划有条不紊地进行着。</p><p>「你说得对，我假惺惺。我最后一个愿望，其实是能让耶罗大仙感受到我的痛楚。」</p><p>「宇宙的历史早已经全部演化完毕，但我将会从既定的、恒河沙数计的时空被抽离。」</p><p>「一个主体的‘现实’，包括他自身本身，以及他对世界所造成的所有影响。」</p><p>「譬如，如果我是一颗恒星，而你将我的所有‘现实’彻底杀死，那么不只是这颗‘恒星’的个体被消除，连带着恒星历史上所放出的光和热——都一并不曾存在过。」</p><p>「我对现世所造成的一切影响，也都不曾发生过。」</p><p>「未曾有人因我而死，也未曾有人因我而流泪。」</p><p>「所有时间点，所有时间线，所有人的记忆中，都未曾发生过所谓的‘原初之眼天灾’。」</p><p>「也从来没有过‘原初之眼’这个伪神，永远不会有人知晓此战的发生。」</p><p>「哦——除了你，杨帝。」</p>
