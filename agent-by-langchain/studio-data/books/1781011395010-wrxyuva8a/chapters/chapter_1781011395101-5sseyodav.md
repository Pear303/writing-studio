# 砾石镇

<p>连绵的山地丘陵地貌，如同书卷缓缓合上，渐渐在他们身后消退。</p><p>道路愈发平坦起来，原本崎岖的小径变成了宽阔些的土路，两侧景致也悄然发生变化。</p><p>不再是突兀嶙峋的山石与密不透风的山林，取而代之的是一片片稀疏的草地。</p><p>间或生长着几株歪脖子的老槐树。</p><p>杨帝突然觉得，这些苍天大树，其实是几百年前一个精灵旅人路过时，随意插下的枝丫，数百年后长成如今模样。</p><p>远方出现了些错落有致的轮廓，那便是砾石镇所在。</p><p>瑞弗维尔掏出望远镜，看向镇子。</p><p>“为什么这座镇子会叫做‘砾石’？”他问。</p><p>奥拓边吃腌兔肉干，边说道：“我不知道。就好像没人知道太阳为何被称作‘太阳’，天空为何被唤作‘天空’。”</p><p>这位半路加入队伍的矮人，强烈要求在镇子外吃完饭，再进去。</p><p>按他的说法，这镇子的饭店宰客很严重。</p><p>所以在镇外吃了饭，就不会被宰。</p><p>奥拓拍了拍瑞弗维尔：“怎么样？镇里头很正常吧？没有什么在巡逻的矮人军队之类的。”</p><p>“那倒是没有。你在怕什么嘛。”</p><p>奥拓帮忙收起锅碗瓢盆钻头镐子：“我哪里怕了？搞定咱就走吧。”</p><p>……</p><p>望山跑死马。</p><p>直到傍晚，他们才走到看起来很近的砾石镇。</p><p>奥拓提议的“吃完饭再进镇”并没有奏效，因为他们吃的是午饭，但还有俩小时就要吃晚饭了。</p><p>夕阳为砾石镇披上琥珀薄雾。</p><p>炊烟从烟囱里袅袅升起，像妇人解下沾满面粉的面纱，那些歪斜的木屋便成了烤炉里蓬松的面包。</p><p>矮人、人类来来往往。</p><p>脚下的路，变成了由大小不一的砾石铺就而成，踩上去，发出细碎清脆的声响。</p><p>这或许就是砾石镇名字的来源。</p><p>周围要么是丘陵山地，要么是稀疏草原，并没有多少木材可供建屋。</p><p>就算有充足的树木，砍伐也需要特许经营，所以，街道两旁是清一色的泥质房屋。</p><p>屋顶的茅草在微风中轻轻摇曳。</p><p>就算是钢筋混凝土建筑，裂隙都容易长草，更不用说，眼前这些多孔稀疏的泥砖房了。</p><p>所以他们看到的镇子楼房，墙壁上无不爬满不知名的藤蔓植物。</p><p>淡紫色小花星星点点，绽放其间。</p><p>有些房屋墙壁上，挂着晾晒的草药和腌制兽肉，屋檐下坐着小憩的老人。</p><p>市集残留着肉桂与铁锈的余韵，摊主们收拢起了油布篷，打烊回家。</p><p>有个穿补丁长裙的姑娘蹲在墙角，指尖轻点陶罐，罐中的水化作涌泉飞出来，流进路旁小猫嘴里。</p><p>还有矮人孩童与人类幼儿追逐打闹。</p><p>瑞弗维尔有些怀疑——看起来如此淳朴的偏远小镇，真的会宰客吗？</p><p>“这里矮人很多。”他还发现这件事。</p><p>奥拓走在最前面解释：“这座镇子是矮人和人类混居，很正常。但精灵从来没有过，伊芙女士应该是第一个。。”</p><p>他不怎么说话了，只是一味向前走。</p><p>街道上，矮人大多身形敦实，腰间总是别着各类精巧的工具，极其符合刻板印象。</p><p>人类没什么特点。</p><p>如果说一定要有特点，那就是是很能生，特别是在这种“光明中世纪”的魔法乌托邦世界。</p><p>因为灵能法术的广泛普及，异世界在与地球同等社会形态的情况下，生产力要高3倍以上。</p><p>比如用灵能来挥动锄头耕地，用灵能引动针头织衣。</p><p>又因为火系法术的存在，异世界没有高炉也能炼钢，随便一家铁匠铺都能锻出高品质钢锭。</p><p>当然，也是用土法炼的。</p><p>要是有足够的知识体系，异世界的大法师们，甚至能手搓微米级、亚微米级制程芯片。</p><p>不过，杨帝穿越过来，也没想着说要带来什么现代科学知识。</p><p>他认为，最好的选择是不要打扰当地土著自主发展。</p><p>除了与伊芙、奥拓、瑞弗维尔几个普通土著，保持最低限度的交流。</p><p>其他时候，杨帝有责任不对异世界做出过多干涉。</p><p>不会泄露过多自然科学知识，也不会插手当地的政治与宗教事务。</p><p>观察，不干涉……杨帝低笑起来，自己倒是像神话中的“原初之眼”，只是纯粹的观察，不带有情感、偏见或目的性。</p><p>“天黑之前，我们应该能找到铁匠铺。”</p><p>奥拓说着，披上亚麻披风和兜帽，还蒙上面罩遮住脸，才在前面带路。</p><p>瑞弗维尔上前去，问了众人都想问但没有说出口的问题：“奥拓，打扮这么神秘？”</p><p>“啊哈哈……这天气着实有点冷，你听，阿嚏。”他努力憋了个喷嚏出来。</p><p>确实不知为何，气温好像下降了。</p><p>按理来说，越往南方走越暖和。</p><p>那里的雨林也被称作“热带雨林”，说明这地方又热又润，甚至没有一年四季，全年无冬。</p><p>“是啊，为啥我也感觉变冷了些？”</p><p>“确实，要不我搓个火球术助助兴？”</p><p>唯一没有插嘴的人是伊芙。</p><p>她站在原地，凝视远方天空中的风暴云，眉宇闪过一丝疑虑。</p><p>是强者的气息，向南，远方。</p><p>她耸耸肩，示意各位继续走：“我认识一些超限强者，他们能改变局部地区气候。星渊井口附近的气温降低，大概也是因为如此。”</p><p>灵能环流一旦出现异常，就好比原本顺畅流淌的河流突然改道或者断流，会引发一系列连锁反应。</p><p>一旦环流紊乱，就可能使得局部地区的气温骤降或者骤升。</p><p>瑞弗维尔掏出野史见闻录，打算积累素材：“伊娃，超限强者？比如说呢？”</p><p>伊芙指了指自己：“比如我啊。”</p><p>……</p><p>杨帝因为心理年龄过于沧桑，以至于物极必反，返老还童。</p><p>当他被路边一个扎着花辫子的小孩叫“叔叔”时，杨帝只能搜肠刮肚，从各大文艺作品里翻找——自己现在应该表现出何等情绪？</p><p>是应该笑眯眯地反驳那小孩叫“哥哥”，而不是叔叔，对吧？</p><p>杨帝这么想着，便笑眯眯地蹲下身子。</p><p>对那扎着花辫子的小孩说道：“小朋友，叫哥哥哦，叔叔听起来可就老啦。”</p><p>小孩歪着脑袋，一双大眼睛忽闪忽闪地打量着杨帝，眼神就像在看咸蛋超人等身手办。</p><p>她说：“不是越老越好吗？”</p><p>杨帝：“？什么逻辑啊这。”</p><p>随后小盆友“咯咯”笑起来，跑开了。</p><p>瑞弗维尔凑上前：“杨帝，还跟个小孩子较上劲了，看来真是不服老。”</p><p>“我哪老了，队里最老的都不是我。”</p><p>伊芙一脚把杨帝踹飞，用黄泥砖砌的墙直接被砸塌了。</p><p>虽然伤不了他，但表明态度立场还是很重要的。</p><p>杨帝抖落身上的干草屑和碎泥沙，一边拍着身子一边走回来。</p><p>“师傅，原来还有精灵介意别人说老。”</p><p>“我也没介意啊，只是腿不小心抖了一下罢了。还有，你把别人的墙砸坏了，去赔礼。”</p><p>杨帝赶紧用法术帮忙修葺一番。</p><p>他手心泛起一层淡淡的蓝色光晕，如同水波荡漾开来，缓缓笼罩住坍塌的土墙。</p><p>碎落一地的黄泥砖被无形力量拆解，化作最原始的泥土微粒，在空中悬浮、飘散，随后有序地聚拢、排列成一块块崭新的黄泥砖。</p><p>崭新的土墙便矗立在众人眼前，甚至比原先看起来更坚固平整。</p><p>周围的矮人和人类居民目睹这一幕，才发觉有“大人物”莅临了。</p><p>奥拓却在一旁，“啧”了一声。</p><p>他低声道：“走！你们太显眼！再不走，这里的居民要上来宰客了！”</p>
