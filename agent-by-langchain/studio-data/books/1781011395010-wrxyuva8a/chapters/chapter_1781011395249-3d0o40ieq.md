# 咒怨之释

<p>那钓鱼佬立于烂尾楼巅，手中那柄“灵茶山乂斧”嗡鸣不止，吞吐着开天辟地般的混沌毫光。</p><p>他望着天穹那轮吞噬万灵的血月，脸上狂喜渐褪，化为一种沉淀了无尽岁月的凝重。</p><p>他归来，并非为了衣锦还乡。他是来赴一场早已注定的、迟到了亿万斯年的战争！</p><p>对手，并非一城一地的冤魂，也非一族一文明的诅咒。</p><p>而是这方宇宙，自诞生第一个懂得悲喜的生灵以来，所有逝去者留下，无穷无尽的“业”的终极凝聚。</p><p>凡有生灵处，必有死亡。</p><p>凡有知性与情感者，其死亡便不再是物质的消散，而是会在虚空之中刻下印记，留下或轻或重的“业”。</p><p>爱别离，怨憎会，求不得……无数生命的遗憾与不甘，如同涓涓细流，自时间的长河伊始便不断流淌、汇聚。</p><p>它们流过文明的兴衰，流过星辰的生灭，最终在宇宙的尽头、时间的终点，沉淀，压缩，质变，化为了这团无法用尺度衡量的、贯穿了过去现在未来的、至暗至秽的终极咒怨。</p><p>它并非来自某一处，它本就是这宇宙众生的一部分。它积累了多少星辰的生灵，就拥有多么庞大的怨恨。</p><p>此刻，它超越了时空的束缚，从那最终的终末之地，降临于此“现在”，要将一切还未发生的过去，也拖入那永恒的沉寂。</p><p>钓鱼佬缓缓举起帝斧，斧刃上流淌的光芒仿佛承载着无数世界的重量。他面对的，是古往今来一切死亡的总和。</p><p>而他身后，是蓝星，是故乡，是仍值得一战的……现在。</p><p>斧光劈开混沌，并非斩向有形之敌，而是贯穿时空，直击那弥漫宇宙、承载一切众生业力的无形系统——阿赖耶识，根源之涡！！</p><p>刹那间，因果倒卷，信息奔流。</p><p>钓鱼佬这一斧，并非在当下毁灭某个实体，而是在“创世之初”的概念层面，斩断了那未来将汇聚成滔天咒怨的业力之根。</p><p>于过去之因，横击未来之敌。</p><p>几声仿佛宇宙基盘碎裂的巨响过后，那弥漫虚空、吞噬星辰的血色咒怨，如同被抽去根基的巨塔，开始剧烈波动，最终崩解。</p><p>漫天飘向血月的残肢仿佛失去牵引，骤然停滞。</p><p>那轮血月本身，也发出一声源自时间尽头的哀叹，光芒急速黯淡，表面裂开无数蛛网般的黑色缝隙。</p><p>终极的咒怨，正在从其诞生的源头被彻底抹除。</p><p>耶罗的狐尾轻摆，语气平淡地解释着他的“紧急救治”方案：</p><p>“对于一个即将魙败的宇宙，常规手段已无力回天。唯有用非常之法。”</p><p>“比如，挑选一个合适的‘种子’，让他带着文明毁灭后的全部记忆，逆溯时间，在灾难发生前‘重生’。”</p><p>“再赋予他一个足够强大的‘金手指’，助其在外挂加持下急速成长，迅速登临圣位，拥有足以在‘过去’横击‘未来’之敌的力量。”</p><p>他爪子指向那烂尾楼上空挥舞帝斧的身影。</p><p>“最后，再暗示这位圣人，用自己的力量制定出一套新的金手指系统，巧妙伪装成其‘奇遇所得’，精准投放回他还弱小的时代，完成因果闭环。”</p><p>“如此一来，救世主是他，奇遇是他，力量源头是他，斩断业根的还是他。”</p><p>耶罗耸耸肩，“自己救自己，自给自足，逻辑自洽，岂不完美？”</p><p>杨帝打断耶罗：“为什么？”</p><p>耶罗狐狸爪子一摊：“历史的因果性必须要尊重，至少要保证比较严格的因果闭环，不能太过无厘头……”</p><p>“你知道我问的不是这个。”杨帝声音更冷，“我是问，为什么你执着于用‘金手指’这种外力催熟的方式，来培养所谓的‘圣人’？”</p><p>耶罗沉默一瞬，脸上的嬉笑彻底消失，金褐色的狐瞳深处闪过一丝冰冷的理性。</p><p>“因为快。面对‘大魙败’，我们没有时间等待一个生命自然演化、感悟天地、历经磨难再水到渠成地成就圣位。那需要的时间以纪元计算。”</p><p>“而宇宙的崩溃，往往只在顷刻。”</p><p>“金手指，是能在最短时间内，将一个普通灵魂强行拔高到足以参与维度层面战争的最‘高效’手段。”</p><p>“它是催化剂，是捷径，是必要的代价。”</p><p>耶罗狐狸那双总是眯着的狡黠眼眸，此刻竟迸发出一种近乎狂热的火光。它不再是那个玩世不恭的幕后黑手，更像一个窥见了终极真理的畜生先知。</p><p>它的声音陡然拔高，带着一种颤抖的激越，回荡在无垠虚空之中：</p><p>“你还不明白吗？杨帝！这就是为什么‘成圣’才是那最终答案！</p><p>“不是科技和魔法这些依赖外物的歧路，而是个体伟力的终极升华，是生命向内求索、打破一切桎梏的登神长阶！</p><p>“唯有成圣！唯有这条路，能让一个渺小生灵，在有限时光里，将自身锤炼到足以一拳打爆星辰，一剑斩断因果，一念重塑轮回！”</p><p>“你会看见的！”耶罗的声音近乎呐喊，“无论是星环盟约那冰冷机械的秩序，还是我这分形区诡谲多变的混沌，无数看似迥异的世界，其文明形态千帆竞渡，但其最终、最终的归宿，都必将指向——成圣！”</p><p>“这不是偶然，这是虚空的终极暗示！是写在所有宇宙根基里的，最深沉的命运低语！”</p><p>“因为只有拥有这等伟力的个体，才能在那席卷一切、否定一切的大魙败面前，站着活下去！”</p><p>它的尾音带着宿命般的回响，仿佛宣告着一个既定的未来。</p><p>它缓缓抬起下巴，蓬松的狐尾在身后舒展开，仿佛披上了一层无形的神圣光晕。</p><p>先前的激动，沉淀为近乎布道般的庄严，声音恢弘而缥缈：</p><p>“故此现象——这自我指涉的闭环，这因果的螺旋，这始于终焉、终于开端的无限回廊……</p><p>“星环盟约那帮官僚，虽乏味无趣，却也不得不承认其精妙与无解。</p><p>“它们与我的唯一区别，仅在于星环稍显激进地培育圣人，而我仍嫌星环过于保守，应该利用金手指快速催生出本土圣人力量。”</p><p>耶罗的眼中流转着万千宇宙的生灭，用一种宣告神谕般的口吻，平静而掷地有声地说道：</p><p>“他们将此现象命名为——”</p><p>“耶罗迷宫。”</p><p>“以吾之名。”</p><p>“毕竟，吾为‘金手指’的掌控者。”</p><p>它如果生活在地球，将会是个走在街上随时被人打死的文青。</p><p>只可惜它是只在虚空中荡漾的狐狸。</p><p>耶罗的狐尾轻轻扫过虚空。它歪着头，金褐色的眼瞳里闪烁着狡黠的光：“杨帝，你玩过迷宫吗？”</p><p>不等回答，它便自顾自说了下去，声音里带着一种悠然的回味：</p><p>“大多数的迷宫，蜿蜒曲折，岔路无数，但真正能通往出口的路径，往往只有那么一条。你需要不断地试错，碰壁，回头，才能找到那条唯一的生路。</p><p>“但也有些迷宫……嗯，比较特别。它们的设计者更为‘慷慨’，或者说，更富‘创意’——里面可能藏着不止一条路能让你走出去。每一条都看似正确，但沿途的风景与代价，或许截然不同。</p><p>“但无论迷宫有几条路，其最终的目的，从来都只有一个——”</p>
