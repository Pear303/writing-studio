# 传奇 圣骑士 巴德

<p>伊芙手执法杖，神色无波：“巴德，你说教廷在进行某种‘仪式’，可你本身就是教廷的人，我该如何相信你？更何况，你背叛了你的信仰，你的教廷，我又该如何相信一个叛教者？”</p><p>巴德平静地说：“我接受你的指责，除了最后一句话——我确实是叛教者，但我没有背叛我的信仰。”</p><p>“？什么？”</p><p>“自始至终，我信仰的都是圣光，而非圣光教廷。”</p><p>“圣光教廷在做什么？”</p><p>这同时也是埋藏杨帝、瑞弗维尔心底已久的问题。</p><p>此时，瑞弗维尔三人也终于走近，站在伊芙与巴德对峙之处的20米开外。</p><p>对两位超限强者而言，数百米外的风吹草动都逃不过他们的感知。在三人刚刚登上丘陵、眺望星渊井口之时，精灵和圣骑士就已经察觉到他们到来。</p><p>但二人都没有为此分心。</p><p>直到瑞弗维尔又准备向前迈出一步。</p><p>“瑞弗，别过来。”伊芙说。</p><p>她仍然没有扭头看一眼。但瑞弗维尔倏地感受到一股无形的威压如潮水般包裹住全身，那是伊芙刻意释放的灵能力量。</p><p>这股威压并非要伤害他，而是以一种温和却不容置疑的方式，将他牢牢定在原地。</p><p>瑞弗维尔这才惊觉，看似平静对峙的两人之间，实则暗潮汹涌，每一个细微的动作都可能引发难以预料的冲突。</p><p>高手过招之前，便在意识中交手了千万遍。</p><p>伊芙仍然不确定圣光教廷的史上第一圣骑士——巴德，有何意图。</p><p>所以不能让那几个菜逼八掺和进来。</p><p>她是大姐，也就是女版的大哥。</p><p>而大哥正是男版的大姐……总之，伊芙有义务保护好那几个年轻小伙子。</p><p>就算是杨帝本身，也欣然接受她的保护。</p><p>方才瑞弗维尔贸然走近，算是一个极度危险的行为，伊芙的注意力被分散1%。</p><p>但巴德并没有趁着精灵注意力下降1%，而发动突然袭击。</p><p>他依旧保持着双手按剑的姿势，神色平静，外界的一切都无法干扰他。</p><p>巴德缓缓开口，声音不高：“圣光教廷在进行一场仪式，但我不明白他们在做什么，我只能警告你们——他们似乎在制造一个东西，一个极度强大的东西，比你我还要强大。”</p><p>骑士缓缓抬头。</p><p>铅铁色浓云压境，似乎随时要陷落大地。</p><p>“此地的异常气象，并非我所引发的。”</p><p>“不是你？”</p><p>“我已经死了。尽管我生前是超限强者，但我所剩余的力量，已不足以影响气候。”</p><p>“那么究竟是……”</p><p>“是教廷，他们所制造的那个‘东西’，它仅仅是存在，就能引发天地异象。”</p><p>当得知教廷“要制造一个强大的东西”。</p><p>伊芙，包括旁听的杨帝，第一时间知道了他们在做什么——召唤原初之眼。</p><p>圣光教廷，包括他们的红衣主教，都已经被只存在于神话与野史中的神灵「原初之眼」所腐蚀嗯。</p><p>反派角色总是由教廷承担。</p><p>在这一点上，饱览地球商业文艺作品的杨帝已经见怪不怪。</p><p>虽然他本人也尊重地球上的解放神学派系，但不知为何，在文艺作品里，教廷总会以反派的面貌出场。</p><p>还有一个设计，就是反派教廷阵营中，必须要有一个真正虔诚信仰XX、为教廷当了多年打手、最后发现教廷有着不可告人的黑暗秘密、而后世界观崩溃重组、开始着手反抗教廷……这样一个觉醒者角色。</p><p>此刻，巴德便是这个角色。</p><p>面对伊芙所说的“原初之眼”，圣骑士巴德却是否认了。</p><p>他反问：“他们如何召唤原初之眼？你知道的，祂被放逐到虚境尽头。”</p><p>第一代魔王“魔苟斯”也被放逐到了虚境，它再也没有回来过。</p><p>顶多只能暗戳戳使坏，撺掇几个心肠坏的人去干点坏事，但掀不起更大的风浪。</p><p>……好叭，还是掀得起风浪的，比如二代魔王索伦，就是被魔苟斯写的“黑魔法百科大全”所蛊惑，堕入邪恶，一天到晚研究什么索命咒、钻心咒，能将世上所有白砂糖替换成食盐+胡椒粉的邪恶魔咒。</p><p>但原初之眼，祂对现实世界的影响，似乎比魔苟斯更小。</p><p>中土大陆上，时不时会有信仰原初之眼的偏门小宗教。</p><p>除非他们整出什么邪祭淫祀，否则朝廷和教廷一般不会去管。</p><p>历史上来说，圣古琉斯王国的圣光教派还算开明，不是一神教——他们信仰的不是人形的神，而是更形而上的符号“圣光”。</p><p>总之，数万年来，中土大陆的土地上，诞生了许多原初之眼信仰团体。</p><p>他们有的是捡到原初之眼雕塑，有的是发现藏在古代废墟里的壁画，然后染上模因效应，拜起了大眼珠子。</p><p>但他们无一例外掀不起波澜。</p><p>最大原因是“原初之眼”被放逐到了虚境，很难影响到现实世界。</p><p>伊芙挠了挠举起法杖老半天的发酸的手的小拇指，继续集中注意力：“不……他们还有一个方法，是的，就在前几天。”</p><p>巴德的空荡荡的头盔微微颔首：“嗯？”</p><p>“数日之前，我在末日火山干掉了几十个被原初之眼蛊惑的教徒、修士，貌似还有两个穿红衣的……他们扭曲成‘一体’，然后，原初之眼降临到了他们身上。”</p><p>旁听的杨帝也有印象。</p><p>瑞弗维尔小声问：“怎么回事？”</p><p>“那天你昏迷了，所以不记得。那几个修士不知咋滴，他们的身体扭成了一个整体。”</p><p>巴德皱眉：</p><p>“你是说，夺舍？</p><p>“但是，原初之眼的危险性来源于其诞生了‘主观’，试图以自己的意志重塑现实。</p><p>“如果降临到像人类这种凡俗动物的肉身中，祂无限的主观意志会极大削弱。</p><p>“而且，这还是几十个修士强行糅合的‘畸变体’，他们的思维器官——大脑，必定在‘糅合’过程中遭到器质性重创。</p><p>“这种大脑受到重创的身体，能不能有8岁小孩智商都难说。所以，完全不可能承载原初之眼的意志。”</p><p>伊芙一怔。</p><p>她专业不在于此，了解不多。</p><p>但按照巴德的思路回想，好像确实如此。</p><p>那一日，数十个教廷术士、圣骑士组合而成“奇行种”，战斗力确实很强大，能让伊芙打起7.5分的精神来应对。</p><p>但是，对方的战术极为稚嫩，或者说完全就是毫无战术，横冲直撞，有什么法术过完CD就一通瞎胡乱放。</p><p>面对她手搓的“九环法术·湮灭之创”，也是非常头铁地开盾，正面硬抗。</p><p>像一个掌握了超人力量的幼孩。</p><p>它只会本能地释放圣光法术，用手臂、腿脚等肢体在地上追着精灵跑。</p><p>而且，伊芙事后总有感觉——并不完全是她杀死了那奇行种。</p><p>至少有50%原因，它是自己崩溃的。</p><p>就像在一片脆玻璃上强行镌刻10环附魔、强行运转10环法术符文，脆弱的玻璃会承载不住汹涌灵能，几秒便解体破碎。</p><p>现实世界的凡俗之躯就是玻璃，很难承载原初之眼的意志。</p><p>适合承载祂的容器，首先必须得强大。</p><p>但强大还是不够的。</p><p>比如「大地」如此广袤，为何原初之眼不去夺舍“大地”？</p><p>因为“大地”没有高等的智力。</p><p>原初之眼的恶意，来自其从“无”之中涌现出的主观意识。</p><p>如果没有狂热渴望重塑世界的“主观意识”，原初之眼就只是一个纯粹的、无情的观察者，不会干预世界，而是以万物为刍狗。</p><p>横尸遍野不会使其表达一丝悲恸，文明繁荣也不会让祂露出欣慰笑颜。</p><p>这时候，祂是无害的。</p><p>瑞弗维尔好像很激动的样子。</p><p>他掏出本子，在远处挥手呼唤：“屠龙者巴德！我是你粉丝！！所以说‘原初之眼’相关野史记载都是真的？”</p><p>“具体哪些野史？有些野史太野，肯定会存在谬误。”</p><p>“比如说……这些，还有……”</p><p>他们开始隔空对话起来。</p><p>巴德还转过了身去，将自己毫无防备的后背露给伊芙。</p><p>伊芙思考了挺久，叹息着放下法杖。</p><p>“巴德先生，您看起来与瑞弗一样无害……我暂且相信您的说辞。”</p><p>只剩一副盔甲的圣骑士呵呵笑了笑：“被教廷封锁这么多年，能有人陪我说说话，我还得感谢你们。”</p>
