# 钓鱼佬二三事2

<p>杨帝轻轻靠在修复好的门上，有一句没一句单方面聊起来：</p><p>“我小时候啊，就和你现在一毛一样，特别胆小又害羞。</p><p>“每次一个人在家里，只要听见门外有脚步声或者敲门声，心里就慌得不行。</p><p>“那时候，我总会下意识地抄起晾衣叉，才敢去猫眼看门外是什么情况。</p><p>“现在想想，那时真是幼稚又好笑，但那种紧张害怕的感觉，到现在都还记得清清楚楚。”</p><p>门后的呼吸声似乎缓和了一些，不再像之前那般沉重压抑。</p><p>美中不足，仍然没有心跳和脉搏声音。</p><p>沉默片刻，门后传来含糊不清的声音。</p><p>像是从很遥远的地方传来，像是被什么东西阻隔了一样，让人听不真切。</p><p>即使杨帝听觉超常，也听不明白。</p><p>他凑近房门，努力想要听清对方在说什么。</p><p>“你……说什么？能不能再说清楚点？”杨帝试探着问道。</p><p>门对面只有呼吸声，没有心跳，没有骨关节运动和肌肉绷紧的动静，也没有肢体与墙壁或地板接触的声音。</p><p>他又轻轻敲了敲门：“如果你还在，那就消消气，我把东西留给你了，我先走一步。要是你愿意，咱们之后再聊。”</p><p>杨帝也不打算把一整天，都耗在未曾谋面、只闻其声不见其形的“邻居”身上。</p><p>他还要去清理顶楼天台，他感觉那里阴气最重。</p><p>所谓灯下黑嘛，太阳暴晒的地方，黑暗肯定远少于室内，但是阴影的存在更刺眼、更明显。</p><p>……</p><p>天气预报说今天晴朗。</p><p>但事实是多云，阴天。</p><p>天台阴森诡异，铅铁色的浓云黏稠地流动，遮住阳光，使得天台笼罩在一片灰暗。</p><p>这座建筑，其实也算是个不小的都市传说，在五六年前流传挺广。</p><p>某论坛就有人分享过，这里有人跳过楼。</p><p>有些人说是跳过一个，有些说是跳过两个，有些是3个，然后5个，8个……</p><p>越传越离谱，还莫名符合黄金分割数列。</p><p>但可以肯定的是，这里在5年内，至少丧生过一个无辜路人。</p><p>抓在天台边的那只手，就是力证。</p><p>杨帝走过去，握住那只指甲发黑、皮肤青灰的手。</p><p>触手之处，一片冰凉，仿佛握住了一块千年寒冰，冷意瞬间顺着手臂蔓延至全身。</p><p>那只手似乎对杨帝的举动感到惊讶，原本僵硬的手指微微颤抖了一下。</p><p>杨帝晃晃那手：“老哥，睡着了？”</p><p>那只青灰色的死人的手反应过来，爆发出强大的力量，猛地用力想要把他拉下天台！</p><p>杨帝只是微微后仰，以纯粹肉体力量，轻松写意对抗着这股拉力。</p><p>岿然不动。</p><p>他手心的“灵”开始躁动，分子热运动速率增加，释放出大量热量。</p><p>为对方暖暖手。</p><p>“你生前是个人，对吧？我能看见你，你现在略微带有人形轮廓，但已经快散了。”</p><p>那只手没有回应，只是疯狂地拉扯着。</p><p>冰冷的气息愈发浓烈，周围的空气仿佛都被冻结。</p><p>幸好杨帝能通过现实扭曲自行发热。</p><p>不然他胳膊很容易冻住——虽然，他现在也不怕冷就是了。</p><p>杨帝自顾自的说话：</p><p>“老兄，你可知人类有几种视锥细胞？没错，红绿蓝三种。</p><p>“你又可知皮皮虾有几种视锥细胞？答对了，十六种。</p><p>“我视觉不断进化，已经异于常人，有更多视锥细胞，你可以当我是‘人形皮皮虾’。</p><p>“所以我才能看到你——虽然你已经死掉了，但你留下一个人形轮廓，而且你的轮廓有颜色。</p><p>“但至今为止，几乎所有人类都只有三种色锥细胞，所以我的语言里没有相应词汇，来描述你现在的颜色。</p><p>“如果非要规定一个颜色，我想称它‘viv’，来自拉丁动词vivere，意为生命，翻译成中文可以读作mìng色，与‘生命’的命同音。</p><p>“用粗俗一点的说法，viv是生命和灵魂的颜色，不过‘灵魂’和‘灵’又是两个需要厘清的概念……</p><p>“总之，我眼中能看见，世上的物体都在流动，所有颜色都在腐烂，像是是印象派画家将调色板摔碎在画布上的抽象图景。”</p><p>杨帝模仿哲学家写散文的方式来说话。</p><p>他的视觉系统像强行撕开现实的包装纸，让这个世界以非常接近本来的面貌，毫无遮蔽地涌入意识。</p><p>源自于每隔小半天触发一次的「视力+1」，让他视觉走向无底线的进化。</p><p>一开始只是视力变好，摘掉了眼镜。</p><p>而后，就是夜视能力提升、动态视力增强、望远视距增大……</p><p>最后，视锥细胞开始变得更多，他能看到红绿蓝三原色之外的更多颜色。</p><p>他能捕捉到紫外线、红外线的颜色。</p><p>“抱歉，单方面对你说了这么多。”</p><p>杨帝握住那些青灰色的枯手，手心开始冒出炽热的蒸汽。</p><p>“我一直很想找个人吐槽，但这世上大部分人都不合适，因为他们没死过。”</p><p>那只指甲黝黑的死人手，停止了拉拽。</p><p>它似乎真的在听。</p><p>杨帝：“我的存在无法被杀死，所以祂剥夺了我存在过的所有痕迹。现在的我，非常不引人注意，因为包括我的存在感，也被杀死了许多。我走在街上，都没人能注意到我……等等。”</p><p>他猛地发现盲点。</p><p>没什么人能注意到他……</p><p>那钓鱼佬是怎么注意到楼顶上的他？</p><p>他的存在感可是很弱很弱。</p><p>走在空旷的街上，都能被路人迎面撞上。</p><p>“兄弟，最后一次聊天就告一段落吧，我带你找块风水宝地安息了。”</p><p>杨帝顺着那只手，稍稍用力一拉。</p><p>一具干瘪的尸体便从天台边缘被拉了上来。</p><p>皮肤紧紧贴在骨头上，仿佛被抽干了所有水分，头发稀疏且杂乱地贴在头皮上，两个眼眶空洞无神地睁着。</p><p>从尸体的腐烂程度和穿着来看，杨帝推测他死了大概有两三年。</p><p>杨帝抱着尸体走下楼梯。</p><p>途径一楼，那钓鱼佬还在看电子书。</p><p>他一开始并没有注意到杨帝和尸体，直到他闻见一股咸臭味。</p><p>然后眼中闪过一丝惊异，抬头，看见杨帝。</p><p>“小伙子，这是怎么回事？”</p><p>“天台上发现的，没人收殓，怪可怜的。”</p><p>钓鱼佬放下了鱼竿。</p><p>他们在楼边的空地上，找了块还算松软的泥地，捡了一把野生铲子，将这具尸体埋葬。</p><p>杨帝从口袋里掏出块漂亮的砖头，插在坟头。</p><p>然后掏出块木炭，在砖头写下“R.I.P.”。</p><p>钓鱼佬用三根香烟祭奠。</p><p>他摸出三支点燃，插在坟前，念念有词：“兄弟，一路走好，愿你来世不再受苦。”</p><p>他摘下渔夫帽微微鞠躬，然后戴回帽子拍拍手，看向杨帝。</p><p>“好了，小兄弟，有什么要问的就问吧，从刚才开始，你就一直有话要说的样子。”</p>
