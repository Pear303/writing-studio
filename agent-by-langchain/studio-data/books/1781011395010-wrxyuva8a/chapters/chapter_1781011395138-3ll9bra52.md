# 夕阳红

<p>「阁下，这座半成品机甲并非人形……」</p><p>“我知道，这不刚好嘛，这台坦克的设计完全不像人，完美规避了恐怖谷效应。你设计的其他人形机甲，只是看着，就让人直发怵。”</p><p>守望者舰队的通讯频道顿时炸开了锅，无数数据流在格式塔网络中碰撞。</p><p>他们开始了紧锣密鼓的重建。</p><p>片刻后，电子音再度汇报。</p><p>「杨帝阁下！有了您的模板参照，外形设计已完成。」</p><p>一台全新的机甲缓缓升起，墨青色装甲表面流淌着星辰，肩甲上的炮塔呈蜂巢状排列。</p><p>人形机甲，除了配色不同，造型上和“无限机兵”一样，非常戳每一个地球胶佬的审美。</p><p>杨帝对其抄作业速度表示称赞。考虑到它由59号半成品改造而来，故为这座机甲赐名为守望者机兵59号改装型，简称“59改”。</p><p>他盯着新出炉的“59改”机甲，又转头看向身旁圆滚滚的鲈鱼阿巴。</p><p>杨帝突然来了兴致：“阿巴，你不是自称变异觉醒的深海鲈鱼吗？化成人形给我看看。”</p><p>“是不是深海鲈鱼”和“能不能化成人形”，到底有什么因果逻辑呀喂。</p><p>“哇老大，原来你有这种癖好吗……”</p><p>“什么什么癖好，别乱说，污我清白。”</p><p>“好吧，如果是老大的愿望，那也不是不行的……”</p><p>一边说着令人误解的话，阿巴周身泛起幽蓝光晕，原本臃肿的鱼身在光芒中不断扭曲重组。</p><p>光晕消散，鱼尾化作白皙双腿，圆润的鱼鳍蜕变为纤细手指，浅粉色鳞片在锁骨处和肚脐下方泛着微光，耳尖还残留着未完全消失的透明鱼鳍，随呼吸轻轻颤动。</p><p>仔细看，面容还和杨帝有七分甚至六分相似。</p><p>“穿点衣服好吧，害臊不害臊啊。”</p><p>“阿巴是条鱼嘛，不懂碳基人类的审美和文化也正常。”</p><p>她和杨帝一边研究衣服怎么穿，一边唠唠叨叨说着。</p><p>“人形生物总觉得人形才符合美学标准，可就算是人形生物自己，内部审美也是千奇百怪。有人痴迷机械义体的金属冷感，有人钟情精灵耳朵的异域风情，也会有人喜欢阿巴我这样有鱼腥味、湿黏且冷硬的鱼鳞……”</p><p>杨帝沉默片刻，顿悟。</p><p>他好像知道守望者的审美是怎么回事了。</p><p>他们怕是把整个文明的xp，都塞进战舰设计里，所以看起来尤为怪异。</p><p>深海鲈鱼阿巴化成人形，在杨帝面前敞开心扉，坦诚相见地挑衣服，耳尖处的透明鱼鳍随着呼吸轻轻颤动，每次翕张都撩拨起隐秘的情愫。</p><p>她看起来居然与杨帝有几分相像，碳基人类都长一个模样？</p><p>阿巴刚穿好衣服，歪着头，眼波流转间尽是天真的媚态：“老大，这样......还满意吗？”</p><p>杨帝垂眸凝视着她，目光澄澈得如同亘古不化的雪山冰川。</p><p>“扣子扣错了！就这还自称太乙真仙。”</p><p>杨帝的心智已超脱凡俗，早已不是普通生灵所能比拟，他只觉得平淡无趣且枯燥。</p><p>无论对方是深海鱼，还是淡水鱼。</p><p>在杨帝眼里都只是骷髅剑鱼。</p><p>他的灵台清明如镜，倒映着万物却不沾染分毫，再炽烈的诱惑在此等超脱的心境下，都不过是镜花水月。</p><p>阿巴一边解扣子，重新扣上扣子，一边说：“其实达到一定境界，年龄已经不重要。各人所呈现出的外貌，都是相由心生的……我心态比较年轻，所以在参考几个碳基人类样本后选取了这副模样……”</p><p>见这两个碳基生物磨磨蹭蹭，守望者文明的电子音响起：</p><p>「杨帝阁下，何时出发去往异世界？」</p><p>“对哦，你提醒了我，我还有事没做。”</p><p>杨帝摩挲下巴，指尖无意识划过太阳穴。</p><p>太阳穴似乎那里，似乎残留着原初之眼记忆的灼热感。</p><p>“还有最后最后最后最后一件事。这将是我在本宇宙做的最后一件事，你们不可能阻止我，也没理由阻止我。”</p><p>本来，阿巴和守望者文明也没想着要阻止杨帝——毕竟打不过。</p><p>「杨帝阁下，您还需要做什么？需要我们助您一臂之力么？」守望者文明仍然不留余力地攀关系。</p><p>和杨帝关系搞好了，对宇宙万物生灵都好。</p><p>就这么简单，没有什么谄媚不谄媚的。</p><p>杨帝指了指上方，又指了指下方。</p><p>“？老大，这什么意思？”</p><p>“哦，是我老家的典故，那没事了。”</p><p>杨帝一边活动关节做热身，眼中闪烁火焰，“我是想说，洞穴里向上攀爬的囚徒，地狱中向下坠落的灵魂，本质都是对真理的追寻。”</p><p>阿巴懵懂地转动着耳尖的鱼鳍。</p><p>而守望者舰队的格式塔网络，已经解析完成海量文献，电子音带着困惑震颤：</p><p>「阁下是指，您要前往宇宙的‘地狱深渊’，或曰‘虚境’？」</p><p>“你说的对，我们要去一趟虚境，还有些爱恨情仇亟待解决。”杨帝点头。</p><p>阿巴脑筋有些转不过来：“怎么就转到虚境这个话题了？”</p><p>杨帝拔出一柄撬棍。</p><p>“有一些盘踞在真理漏洞里的蛀虫，还在啃食这个宇宙的根基——我能感受到，你们也应该隐约感知得到。”</p><p>杨帝转头看向阿巴和守望者舰队，“准备好了么？”</p><p>作为宇宙中登顶巅峰的强者与文明，“虚境”于阿巴、守望者而言，并不是十死无生的极危之地。</p><p>就好像在封建时期，下南洋跑到好望角，已经是古人所能做到的极限。</p><p>随着科技进步，翻船的概率虽仍然存在，但下海已经不算危险之事。</p><p>有些以灵能为主导的文明，还会定期开展“突入虚境”、“勇闯天幕”之类的大型活动，以此来确定下一个50年的国运。</p><p>“老大，我元神出窍了。”阿巴眉心探出一团璀璨光球，凝聚成一条鱼形元神。</p><p>与此同时，守望者舰队中的“59改”也脑洞大开，从掀起的天灵盖中飞出一辆坦克模样的全息投影。这个呃，可以类比成智械的“元神”。</p><p>杨帝拍拍手：“那么夕阳红旅行团第一站，就是虚境。”</p><p>“夕阳红旅行团？”</p><p>“在场的各位，不一定是心灵上的老人，但一定是物质上的老人。如果你们曾经是单恒星系统中的行星生物，应该能够接受这种想象力的类比——人的衰老，和太阳夕照。”</p><p>「我明白，当恒星步入‘红巨星’阶段，它看似膨胀得更加耀眼，实则内核在急速坍缩。」</p><p>守望者确信这是对“夕阳红”的绝佳解释。</p><p>阿巴：“不，铁壳子你根本不明白……老大说不是红巨星，而是一种周期性的天象……”</p><p>夕阳红旅行团初步建立就这么草率决定。</p><p>目前成员组有三人，第一站是虚境。</p><p>虚境，更像是藏在皮影戏后的“后台”。影子戏的层层帷幕下，真实的演员都藏在后台。</p><p>进入虚境的方法也很简单，比如说冥想，凭着直觉，向一个浩瀚、庞大的区域游过去。</p><p>对机械脑袋来说，则要复杂一点，但其实也差不了多少。</p><p>在足够强大的硬件与软件支持下，仿生人也能梦到电子羊，“冥想”也不是碳基肉人的专属。</p><p>守望者文明内部，由元婴期面包机、化神境燃气灶、炼虚境指甲钳组成的大军，甚至是主要陆军力量。</p><p>杨帝和阿巴相继进入学之又玄妙之又妙不可言不可说不可视不可听的“冥想”状态，在其他联盟者门派中，也可能会称为“入定观想”等等。</p><p>59改终于编译完成他的“冥想程序”，也赶上来，加入虚境遨游的队列。</p><p>一人一鱼一坦克，同时刺破某种屏障，进入一个更宏大、浩瀚的戏外世界。</p>
