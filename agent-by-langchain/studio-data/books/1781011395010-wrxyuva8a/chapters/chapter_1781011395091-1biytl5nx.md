# 学者伊芙

<p>身后那人又开始哈哈笑起来。</p><p>杨帝听得出是个女声，通过声音的传播时间差以及声音的指向性，推断声音来源距离自己大约1.5米。</p><p>考虑到声音传播的方向以及对方与自己的相对位置，从这个距离和角度判断，对方的身高应该在1.7-1.73米之间。</p><p>对方身形挺拔，站立时身姿笔直，这从声音的垂直传播角度和清晰程度可以推断出来。</p><p>声音在传播过程中，没有因身形弯曲等因素，而产生明显的反射或衰减变化。</p><p>但推断这么多，皮用没有。</p><p>杨帝还是一动不敢动。</p><p>“‘圣光教廷是什么’，你的这位朋友可是对你瞒了挺多事情呢。让开，让我审他一审。”</p><p>杨帝也想让开。</p><p>但他背部95%严重烧伤，身体皮肤与歪脖子树接触的部分，则已经黏连。</p><p>换句话说，他皮肤已经烧融化，和这棵歪脖子树黏在一起了。</p><p>强行分离也不是不行。</p><p>只是这么做非常惊悚。</p><p>杨帝：“我随时可以离开，前提是您能接受我大面积皮肤脱落、全身赤裸的模样。”</p><p>“……”在杨帝身后手持法杖，顶住他后脑勺的人顿了顿。</p><p>随后轻哼一声道：“行，勉为其难治治你。”</p><p>话音刚落，杨帝感觉到，身后有翠绿色光芒如潺潺流水般流淌而出，缓缓笼罩自己。</p><p>光芒仿佛具有生命，包裹他烧伤的部位。</p><p>所到之处，杨帝原本剧痛难忍的伤口渐渐传来丝丝凉意，疼痛开始减轻。</p><p>他能清晰感知到，自己背部已经烧焦黏连的皮肤，在慢慢恢复活力。</p><p>受损细胞重新修复组合。坏死的血管复苏。烧断的神经重连。</p><p>原本与树干黏连的部分也逐渐松开，皮肤开始重新焕发出健康的色泽。</p><p>杨帝忍不住轻哼起来——他的潜意识完完全全捕捉到，自己身体的各项耐杀点数，又上升了几十上百个点。</p><p>用“人物面板”来看，“耐热”属性从900+提升到1200+，坐火箭般飞速进步。</p><p>在地球，很难通过合法手段搞到1000度以上的高温。</p><p>但在这至少是中魔世界观的大陆上，法术能做到很多事情。</p><p>话说回来，身后此人，法力高强，疗愈法术的效果也是一绝，是杨帝的20倍打上！！</p><p>如果可以，杨帝其实想不施加任何灵能防御，肉身沐浴在温压弹级别的爆焰中，以此让这种致死伤害更好地冲洗全身。</p><p>但考虑到在场还有高手，所以杨帝不打算表现得那么出格，以免又引的哪个九转大能、创世神明出手，一巴掌将整片大陆轰杀至渣。</p><p>身后，那人将青绿色披风扔给杨帝，让他披着。</p><p>披风还残留着柑橘气味。</p><p>他并不明白，这是单纯的香水，或是异世界种族特有的体香。</p><p>待杨帝转过头来，看清来者，一切也便都明了了。</p><p>一个长得非常典型的精灵。</p><p>尖耳朵，金毛长发，气质秀丽。</p><p>看年纪，应该有一千六百岁了……好吧，这个年龄就是杨帝瞎猜出来的。</p><p>他不可能猜得出来。眼前这精灵，从人类审美看可能也就十五六岁，长着一张去麦门炸薯条都会被人举报“雇佣童工”的脸。</p><p>但从她种族的视角看，年龄也许可能得翻个100倍吧。</p><p>然后，杨帝被原力锁喉，固定在了一边。</p><p>“姑娘……何意……呜……”</p><p>他被原力锁喉在空中，说一句话，呼一口气都分外艰难。</p><p>他挣扎几下，发现毫无卵用，便放弃了。反正自己也不需要氧气。</p><p>“不要碍事，就呆在那，不要干扰我。”精灵瞥了他一眼，表情说不清是微笑，还是平静。</p><p>她又一个弹指，凭空生成巴掌大小的清水，将瑞弗维尔泼醒。</p><p>瑞弗维尔猛地一激灵，从昏迷的混沌状态中清醒过来，大口喘着气，眼神中满是迷茫。</p><p>“我是谁我在哪我在干什么？”</p><p>“我从哪里来到哪里去？”</p><p>“这位精灵小姐，您哪位？”</p><p>瑞弗维尔慌张地问道，目光在杨帝、精灵以及周围那片狼藉的环境中来回扫视。</p><p>精灵踩住他胸腔，掏出个沙漏，杵在老歪脖子树剩余的树根上：“我问，你答，沙子漏完，脑袋搬家。”</p><p>杨帝在一旁被原力锁喉，无法出声，但眼神示意瑞弗维尔如实回答。</p><p>精灵：“原目在哪，说出来。”</p><p>瑞弗维尔：“原目！原目……什么是原目？”</p><p>“原始之目，原初之眼！”</p><p>沙漏已经漏完一小半。</p><p>瑞弗维尔疯狂点头，好像再不点头这脑袋就要搬家了：“雕像在！雕像在！就在我右手边第二个兜里。”</p><p>精灵，掏出块黑色天鹅绒，小心地将他口袋里那雕塑包严实，才慢慢拿出来，放一边。</p><p>她把漏了大半的沙漏倒过来。</p><p>“再给你半分钟，从雕像往开始说，这雕像从哪里来？”</p><p>“捡到的。”</p><p>“从哪捡到的？”</p><p>“圣……圣古琉斯王城的地下暗道。”</p><p>“你是谁？”</p><p>“我是西土大国圣古琉斯来的旅行商人，要去东方取金哎啊啊啊啊——！你说我说！”</p><p>杨帝听见瑞弗维尔肋骨有轻微破碎声。</p><p>无所谓，这种小伤，精灵动动手指、甚至只是动动腿毛就能治好。</p><p>“我叫瑞弗维尔，是圣古琉斯王国的宫廷图书馆馆长！受国王之命来末日火山调查圣光教廷的异动，顺便勘察末日火山情况！”</p><p>“末日火山有什么情况？”</p><p>“我……我预言到卡利斯托会复活。”</p><p>“圣光教廷有什么异动？”</p><p>“他们……自从一百年前，圣骑士巴德讨伐卡利斯托成功后，他们就在星渊井口、末日火山扩张自己的势力，没人知道他们在做什么……”</p><p>精灵笑了：“你想知道我名字吗？”</p><p>瑞弗维尔大惊失色：“不敢不敢！规矩我都懂！知道了您名字，喀嚓，脑袋分家！”</p><p>她笑嘻嘻：“我说给你，听一听嘛。”</p><p>“不——！！”瑞弗维尔想要闭紧耳朵，但他双手都被束缚住。</p><p>精灵拿起一旁早已经走完的沙漏：“你看沙子早就漏完了，我都没让你脑袋分家，说明我这个人不讲规则。所以，就算你知晓了我名字，恐怕也没什么事的哦。”</p><p>这段话有点拗口。</p><p>简单来说，她自称是个大好人，不滥杀。</p><p>被锁喉在半空中的杨帝差点要睡着了。</p><p>但他还是在睁眼那一刻，及时听到最关键的信息。</p><p>这位精灵，名叫伊芙·柑橘（Eve Citrus），也有人称她伊娃。</p><p>读音相近，所以都大差不差。</p><p>伊芙用治愈法术修复瑞弗维尔的骨折，一边笑眯眯地看着他。</p><p>笑容仿佛春日暖阳，让人很难将她刚刚狠厉的模样联系起来。</p><p>“好了好了，别这么紧张，我真没打算把你们剁碎了添油加醋喂给史莱姆。刚刚只是形势紧急，要辨认出是敌是友，是敌我矛盾还是内部矛盾，是对抗性矛盾还是非对抗性矛盾……”</p><p>她轻轻一挥手，解除了杨帝的束缚。</p><p>被原力锁喉整整十分钟的杨帝，跪倒在地，大口呼气。</p><p>瑞弗维尔揉揉被踩得生疼的胸口，小心翼翼地看着伊芙，“您……您真不打算把我们剁碎分尸焯水添油加醋放盐爆炒红烧，然后喂给史莱姆？”</p><p>“你真的很想被我剁碎吗。”</p><p>“不想。”</p><p>“那不就对了嘛。”</p><p>而在一旁，杨帝整理了一下身上的青绿色披风，插了个嘴：“伊芙小姐，刚刚多有冒犯，还请见谅。所以，敢问您来此处，是与‘原初之眼’有关？”</p><p>他旁听了伊芙对瑞弗维尔的审讯，已经大概了解事件经过。</p><p>他也已经大致明白，瑞弗维尔姓甚名谁，从哪来，到哪去，要干嘛。</p><p>所谓“商业竞争对手”，是假的……</p><p>不过，既然是国王密令，对杨帝这个陌生人有所隐瞒，是很正常的事。</p><p>现在，他们显然卷进一个更大的风波——被名为“伊芙·柑橘”的精灵缠上了。</p>
