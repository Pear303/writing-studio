# 境界游戏

<p>其实并不全是因为客栈掌柜·青丘白璃太多嘴，也不是世界本身的缘故。</p><p>最主要原因，是杨帝的“话术”属性点太高。</p><p>1500亿！你们跑团见过12位数的数值吗？</p><p>普通人和他谈话，不到10毫秒就会乖乖交代自己的浏览器记录。</p><p>青丘白璃能坚持好几分钟，也算是大能级别的土著了。</p><p>而在领域内，与这只口水量丰富的狐种大妖交谈十几分钟后，杨帝也渐渐套出了许多关于这世界的情报。</p><p>这世界是分层结构。</p><p>下层，是一个比较平凡的凡界。</p><p>上层，是一个灵能浓度更高，金丹不如狗元婴遍地走的灵界。</p><p>凡界被灵界罩着，相当于小弟和大哥。</p><p>非常典型的修仙小说设定！极有既视感。</p><p>“域外天魔”会周期性刷新在灵界，它们本质上应该是种黑色拉面。</p><p>但这些天魔不会刷现在凡界，这倒是件好事儿。凡界没多少战斗力。</p><p>青丘白璃守口如碎瓶，疯狂泄露情报。</p><p>在跨越不同世界时，会发生“适配”现象，比如说杨帝脑中关于“普通话”的概念替换成一种本地的普通话；青丘白璃来到凡界时，也会被这片天地带上“多嘴话痨”的属性。</p><p>最后，她还透露了这片修仙世界观最关键的机密情报——</p><p>境界划分！</p><p>在地球，人们已经对“穿越进不同的世界观后应该做什么”进行了相当多的应对预案。</p><p>比如穿到大明初期，就不能做官，也不要和马皇后争宠，除非觉得九族太多；穿到某种像素分辨率很低的方形世界，就应该先撸树，做出只有三格耐久的木镐，半分钟开启石器时代；穿到名为“泰拉”的地方但不清楚是哪个泰拉，如果在附近晃悠了几天都没发现一个兽娘，那应该尽快自鲨以免被黄皮子征兵……</p><p>而穿越到了修仙世界观，第一步，是了解当地的境界划分。</p><p>境界划分之于修仙世界观，就像交通规则之于繁华都市。</p><p>从炼气到渡劫，每个境界都是一道隐形标尺，标定着修士实力、地位与行事边界。</p><p>习得当地境界化分后，就可以参与到一件有趣的事了——吃瓜。</p><p>当某某地两位大能因个人琐事、性格不合、商务纠纷、情感缘故等原因大打出手时。</p><p>周围往往会围了一群吃瓜修士。</p><p>他们蜷缩在一旁的安全地带，围观二位至尊对决。</p><p>人群中还会自动刷新出“说书人”，绘声绘色描述二人的战斗，分析他们的战法与胜率。</p><p>他们时不时会飙出专有名词，比如“XXX可是YYY有名的豪门望族”、“ZZZ是TTT新晋的绝世天才”，“一个是AAA巅峰另一个半步BBB”，“这招竟然是CCC”，“对方通过DDD反制”。</p><p>如果这时候连修仙界的各种境界划分都认不全，吃瓜观赏性一定大打折扣。</p><p>扯远了。</p><p>在这个世界（指灵界），修仙者划分为3个顶层大境界：</p><p>格物致知，炼虚洞玄，帝临真一。</p><p>也可以称之为：蝼蚁，道友，大帝。</p><p>3个顶层大境界分别划分为5个中层境界：</p><p>炼气，筑基，金丹，元婴，化神。</p><p>炼虚，合道，渡劫，逍遥，真仙。</p><p>仙帝，神皇，至尊，准圣，圣人。</p><p>5个中层境界划分为41个小境界：</p><p>低阶，初期，小成，登堂，中阶，入室，大成，炉火，高阶，纯青……（省略中间29个小境界）……巅顶，无极。</p><p>每个小境界，划分为461阶。</p><p>每一阶，划分为1889级。</p><p>最终，修仙界承认的合法境界总数为：535559835层。</p><p>如此大规模的境界游戏，能终跨越到炼虚洞玄-真仙-低阶-1阶-1级，也就是俗称“位证真仙”的天才，都是凤毛麟角。</p><p>真正登临世间绝顶“仙帝境”，俯瞰众生者，最近数千万年来，都只有“归墟大帝”一人。</p><p>他在一万年前出世，也是一千万年来唯一一个大帝，是字面意义上的万古一帝。</p><p>但归墟大帝，仍然不是灵界数百亿年历史上最强的。</p><p>他毕竟只是“帝临真一”第一境界“仙帝境”巅峰大圆满。</p><p>据说在荒古时代，曾有第五境界的「圣人」出世，其名曰「残星道人」，引得整个灵界争相跟随。</p><p>杨帝：“那么青丘女士现在是何境界？”</p><p>“真仙圆满。”她当即回答。</p><p>话一出口，她脸色瞬间煞白如纸，指尖不受控制地微微发颤，死死捂住自己的嘴——那是个会自动泄露秘密的无底洞。</p><p>某狐狸尾音还带着哭腔：“又说漏嘴。这凡界的法则简直是附骨之疽！”</p><p>杨帝瞳孔微缩，面上却不动声色，心中暗自暗喜这意料之外的意外之喜囍喜。</p><p>真仙境大能，在这等级森严的修仙体系里，已然是站在超凡大境界顶端的存在，实力远非寻常修士可比。</p><p>如果真仙这么弱，那这个世界的土著，对杨帝应该没多少威胁。</p><p>毕竟大帝很少很少，真仙差不多就是顶尖土著了。</p><p>现在唯二要防的，一个是有没有类似“原初之眼”那样的变异版天道衍生物。</p><p>另一个就是星环盟约的无限机兵。</p><p>杨帝寻思片刻，继续问道：“归墟大帝……他有没有被一些银白色的金属巨人袭击过？”</p><p>凭借一整个宇宙的知识，他也只能理解无限机兵5%左右的构造。</p><p>就是这5%的信息，蕴藏了机兵的原设目标。</p><p>它们会将宇宙中超过阈值的至强者与超级文明，作为目标。</p><p>至于是“敌对”、“中立”还是“友好”目标，不得而知。</p><p>对于这个超脱宇宙之外的虚空霸主文明，他了解还很少。</p><p>青丘白璃根本经受不住1500万的话术诱惑。</p><p>她脱口而出：“从来没有……哦，大帝在上，原谅我又透露了这么多情报。”</p><p>名为“诛魔破阵曲·重金属”的领域，发出阵阵破碎之声。</p><p>青丘白璃眼中闪过凌厉：“也行，即便你不是域外天魔，你也必须为你们所做之事做个交代。”</p><p>杨帝一拍大腿：“没错！这是最后一个问题了——我们到底做了什么，才让你敌意这么大咧？”</p><p>“你别装懵扮傻。”</p><p>“不，是您在谜语人！快告诉我罢！”</p><p>话术过个判定，叮，大成功。</p><p>青丘白璃又双叒叕脱口而出：“你们竟敢对中山无极下此毒手……”</p><p>中山无极，是那个酒楼厨子。</p><p>当时杨帝对他使出了“大记忆删除术”，又称“给他一个拳在鼻”，使其失去短期记忆。</p><p>当然，如果原本想把人打晕，却因为力量估计错误，把对方轰碎成碎渣，未免影响不好。</p><p>所以，杨帝自己琢磨出一些揍人法门：最初，只会用最轻微最轻微的力气轰上去。在拳头碰到鼻子时，通过感受对方的防御强度和生命值，进而动态调整力气。</p><p>见人打人拳，见鬼打鬼拳。</p><p>从而实现不论对方是普通人还是真仙大能，都能安全打晕，而不会失手把对方轰成凡人碎片，或者打不出一点伤害。</p><p>杨帝记得，自己当时打晕那个厨子，确实是花费了一点力气。</p><p>没想到，一穿越过来，就碰见个土著大能。</p><p>还不小心把对方揍到短期失忆。</p><p>也难怪他们会被其他土著盯上。</p>
