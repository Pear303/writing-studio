# 疯狂玄学家的笔记本？

<p>质壁分离：将成熟的植物细胞置于高渗溶液中，细胞内的水分会向外渗透，液泡逐渐缩小，原生质层与细胞壁逐渐分离。</p><p>……</p><p>盯着笔记本上最后那行“人，质壁分离”，喉咙泛起铁锈味。</p><p>胡彦卓吐出一口气，缓缓的说：“这些实验记录的时间是从2011年到2012年，这两年正是都市传说的高发时期。2013年，校方终于决定搬离这几栋楼。”</p><p>他看向杨帝，黑暗中那双眼睛炯炯发亮。</p><p>“杨帝，你说会不会有人在拿活物做某种……人体改造实验？”</p><p>杨帝的瞳孔微微收缩。</p><p>他想起梦中，灰袍甘道夫提到的“逝者”。</p><p>想起狸花猫变形时骨骼错位的脆响。</p><p>黑色拉面团“哈基面”，会不会是某种失败的实验产物呢？</p><p>甚至“希夷”本身，会不会就是实验中逃脱的“逝者”？</p><p>二人一猫都想到了这一点。</p><p>杨帝：“信息也许还不足，继续翻页看下去吧，还有最后几页。”</p><p>怀着不安，翻开最后几页。</p><p>他们有预感，艺术楼地下室的秘密，即将揭晓。</p><p>“杨帝，这个和你展示过的‘耶罗符印’非常相似。”胡彦卓指着其中一页。</p><p>泛黄的树叶上，画着和防水布下一模一样的漩涡图案，同时也是“耶罗符印”上的图纹，旁边标注着“耶罗大仙”。</p><p>但对于这个“耶罗大仙”，笔记本仅有只言片语的介绍：</p><p>「“耶罗”这个词并不准确，只是当地村民的洋泾浜。它的真正所指，应该是“YELLOW ”」</p><p>杨帝和胡彦卓你一言我一语，火热地讨论起来。</p><p>“Yellow？黄色？黄色仙人？”</p><p>“这里的‘村民’又是什么意思？”</p><p>“哦，稷海理工所在地方，以前就是片荒芜的城郊村落。说到底，就算是稷海市区，在几百年前甚至一二百年前，不也都是村落发展而来的嘛。”</p><p>“那么这个‘耶罗大仙’，很可能就是以前当地村民的某种信仰？”</p><p>“结合‘当地村民的洋泾浜’，而且稷海是沿海商都——我认为，有可能是外来信仰结合本土民俗后，演化成类似宗教的文化。”</p><p>“不知道哪朝哪代，西洋人来到此处经商，同时带来了一个‘Yellow God’，后来被当地村民演变成‘耶罗大仙’……”</p><p>“黄神？听说过哪国有这种信仰吗？”</p><p>“没有，对民俗学不了解。”</p><p>虽然仅仅是寥寥几语的文字。</p><p>杨帝和胡彦卓也慢慢推断出，许多可能有价值的信息。</p><p>他们再翻到下一页。</p><p>是张图片，图片上有个男人。</p><p>男人的面容被抹除了，只剩下模糊轮廓。</p><p>看起来像是“无相神功”修到走火入魔。</p><p>现实中，怎会有人五官俱无呢？应该是图片拍下后，有人把它抹掉了，吧。</p><p>杨帝指尖触到照片上的男人轮廓，却像戳进一团正在融化的雪。</p><p>那些本该存在的油墨纹路，在皮肤下诡异地塌陷，没有温度，没有质感，唯有深入骨髓的恶寒。</p><p>“看来有人不想让我们认出他。”杨帝将照片抽出，夹进提前准备好的塑料文件袋。</p><p>这东西，日后也许能成为呈堂公证。</p><p>但这时，希夷跳上杨帝的肩膀，爪子死死抓住他的衣领。</p><p>它盯着照片，喉咙发出幼猫般的呜咽。</p><p>“老大……我好像闻到了自己的味道喵。”</p><p>它尾巴无意识地甩动，扫过杨帝手背。</p><p>“但是……又不完全是现在的味道，像是很久很久以前的味道喵。”</p><p>杨帝诧异：“希夷……难道图片上这男人你认识？或者你生前就是他？”</p><p>他坚持希夷是鬼，并擅自为它划分了非常合理的境界：鬼魂境后期七重六转55级巅峰大圆满半步56级。</p><p>“呃……不确定喵，老大我进图片看看。”</p><p>希夷目前有三种存在形式，一是借宿在人的精神里，二是住在图片中，三是夺舍一大团黑色拉面。</p><p>它可以随时切换自己的灵体。</p><p>杨帝脚边的狸花猫身子一瘫，倒在地上。</p><p>他手中的相片微微颤动一下，然后脑海中传来希夷的精神交流：</p><p>“老大……太恐怖了，我感觉不到图片里这个人的存在喵。”</p><p>“希夷？什么意思？”</p><p>“老大，这个男人的图片……他的脸不是被物理方法抹掉的，似是被某只‘无形大手’刻意抹除似喵……”</p><p>瘫倒在地上的狸花猫，开始蠕动暴走了。</p><p>希夷赶紧魂穿回来，镇压住即将变成黑色拉面的断尾猫猫。</p><p>它吞吞吐吐地说：“以往寄宿在图片里，我都能感受到图片里的实物存在，比如说先前的那张红气球，在雕塑室拍下来的石膏雕像，它们都是切实存在的喵喵……”</p><p>断尾狸花猫跳上杨帝肩膀。</p><p>它的肉爪指了指图片上，那个缺失五官的男人。</p><p>“但是，我却感觉不到他的存在喵……”</p><p>杨帝一边向胡彦卓解释着希夷的发现，一边陷入沉思。</p><p>感觉不到他的存在？意思是图片里的人已经死了？或者是某种更彻底的灰飞烟灭了？</p><p>物质不灭，只是粉碎。</p><p>希夷能感受到图片中的石膏、红气球这些“死物”的存在。</p><p>这反而感知不到那个男人的“存在”。</p><p>希夷突然瞳孔颤动，喉咙发出低声的呼噜呼噜：“老大，这种感觉——图片里的男人，和我现在寄宿的狸花猫肉身，一样的‘空’、‘虚’喵。”</p><p>空虚？寂寞冷？</p><p>……身为人类，杨帝和胡彦卓很难理解希夷口中的“空虚”是什么意思。</p><p>反正肯定不是情绪上的空虚寂寞冷。</p><p>希夷又斟酌了一会儿用词，最终接受了自己并非文豪的悲惨事实。</p><p>它说：“老大，我试试直接把我的感觉传输给你喵。”</p><p>“你还有这种功能？”</p><p>“本质上，就是把我的一部分精神割给老大你喵。三二一，开始了老大喵！”</p><p>杨帝的视线倏地变得恍惚，整个世界都在剥离色彩。</p><p>胡彦卓的脸，在视野边缘模糊成一团阴影，而手中的照片却异常清晰起来。</p><p>那个五官缺失的男人，轮廓开始渗出淡淡的灰雾。</p><p>不是物理意义上的烟雾，而是某种更本质的溃散——</p><p>就像一团火，被抽走了热量，只剩下冰冷的灰烬保持着燃烧的形状。</p><p>「精神+1+1+1+1+1」</p><p>“呱！我不要看呀，快停下！”</p><p>他踉跄着后退半步，后背撞上潮湿的墙壁。</p><p>眼前的世界恢复了色彩。</p><p>胡彦卓赶紧冲上前去把杨帝扶起来：“你看到了什么？那是种什么感觉？”</p><p>杨帝握住胡彦卓的手：“对不起了胡大哥，回去以后，我会成为一个彻底的唯灵论者。”</p><p>“？什么意思杨帝！不要吓我！”</p><p>“在我们计算机操作领域，有一个很严重的错误，叫做‘内存泄露’。一块内存发生了泄漏，除非重启，否则就再也找不到这块内存了。”</p><p>杨帝脸色有些苍白地执起撬棍，在地上写写画画。</p><p>“而就在刚才……我看到了一个‘再找也不到它存在’的人。”</p><p>“图片上这个男人，他……就好像一块在现实里被泄露了、再也找不回来的‘数据内存’。”</p><p>“我们只能摸着破洞的边缘，发现这里有个洞——却再也没办法得知，这个大洞以前曾有些什么东西了。”</p>
