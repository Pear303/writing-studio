# 若罗碑刻域

<p>——如果说，他的五感无法捕捉到圣人的轨迹，那么“体术”能够发挥的作用应该不大。</p><p>那么，他就必须施展“法术”……</p><p>是用磁场武道·杀鲸霸拳……还是用模仿自阿巴的太乙仙术·大荒囚天指……亦或者是二十环法术·格密尔之怒……</p><p>“梦境与现实，本就一线之隔。你觉得何为梦？何为现实？这个灵界，真的就是现实吗？”残星道人露出浅浅的微笑。</p><p>杨帝：“你是说‘这个灵界’？我可否理解为你在暗示我——你不是灵界土著，而是来自仙界的异界人？”</p><p>“没错，我来自仙界，我在仙界等你。”</p><p>残星道人回复了一句怪话。</p><p>下一刻，异变突生！</p><p>杨帝还没想明白圣人说这话是干啥子。</p><p>意识便如同一滴墨汁，坠入无垠之海。</p><p>三十八位大帝的威压本源与法则绞杀，都化作了遥远天际模糊的光影碎片。</p><p>灵界的一切风景，是被风吹散的残卷古籍，在意识的边缘簌簌作响。</p><p>他的灵识不受限于血肉之躯，化作万千道流光，在精神维度的虚空中纵横穿梭。</p><p>杨帝眼前，开始闪回灵界的历史。</p><p>荒古时期开天辟地的斧影、中古年代论道台上的思辨火花、近世与诸帝交锋的雷霆剑意，此刻都如气泡般升腾、炸裂，释放出磅礴的意念洪流。</p><p>而残星道人的意识，则如同一座亘古存在的冰山，沉默地悬浮在这片意识之海的中央。</p><p>他的意念没有丝毫外放的狂暴，却带着一种“存在即合理”的绝对威严。</p><p>“白杨大帝，‘他们’开启‘若罗碑刻域’了。我无法出手。圣人以己身化道补全天序时，便已被戴上枷锁。你和万古鱼尊必须找到离开灵界的‘通道’！”</p><p>“喂！你别谜语人好吗！你为什么要提阿巴！”</p><p>“白杨大帝，活着逃出来，我的……同道。”</p><p>“我叫你不要谜语人。”</p><p>“你有资格辅佐鱼尊陛下。”</p><p>“我辅佐她？你莫不是在说笑？”</p><p>“我知道你现在心中有诸多困惑。这块‘闪通玉盘’，记载了归墟大帝在‘入魔’前，残留下的最大的一块现实残片，其中蕴含了他数日以来比较完整的记忆。待你安全了，你可以查看这枚玉简中的内容。”</p><p>杨帝掌心出现一块类似U盘的东西。</p><p>啧，不管了，现在得先活下来。</p><p>杨帝看向三位准圣。</p><p>他们正在催动一道更庞大、更具破坏性，且覆盖整个灵界的法术。</p><p>这些大帝……都疯了么？</p><p>若罗碑刻域……动静比创世之斧“灵茶山乂斧”还庞大。</p><p>「你必须在自己被‘回溯’前逃出来，来到‘仙界’。」</p><p>印诀成型，天地震动。</p><p>整个灵界，三十三重天，无量星河，无尽位面，都仿佛微微一颤！</p><p>一股苍茫、古老、仿佛自开天辟地之初便已存在的宏大意志，骤然从灵界的本源深处苏醒！</p><p>这股意志并非生灵，而是规则本身，是铭刻在宇宙基石上的铁律！</p><p>“若罗碑刻域，启。”</p><p>三位准圣同时厉喝，声音穿透万古时空，响彻在每一个灵界生灵的灵魂深处！</p><p>轰隆隆——！</p><p>灵界的天穹，不再是蓝天白云或璀璨星空，而是浮现出亿万枚巨大无朋、闪耀着混沌神光的古老碑文！</p><p>这些碑文并非文字，而是直接由大道法则凝聚而成，每一枚都蕴含着一种最根本的宇宙秩序：重力、空间、时间、因果、阴阳、五行、生灭、虚实……</p><p>它们相互勾连，层层嵌套，瞬间构成了一个笼罩整个灵界、贯穿过去未来的无上领域——若罗碑刻域！</p><p>这不再是针对个人的小领域，而是将整个灵界都化作了囚笼，是灵界天道法则本身的具象化与极限升华！</p><p>杨帝感觉到，整个宇宙的重量都压在了他的身上，无穷无尽的规则锁链从虚空中探出，缠绕向他的肉身、神魂、乃至他存在的每一个“点”。</p><p>他那狂暴增长的力量，似乎真的触碰到了此界承载的极限，引来了天道的终极反噬！</p><p>……不，这股力量并不只是针对杨帝他。</p><p>三位准圣，打算又双叒叕毁灭世界。</p><p>若罗碑刻域的光芒，如同亿万只冰冷、无情的法则之手，拂过灵界的每一寸时空。</p><p>光芒所及之处，时间的概念被扭曲、撕裂，然后强制性地向着某个既定的原点坍缩。</p><p>光阴倒流，时间回溯。</p><p>远方一颗濒临爆发的超新星，炽烈的光芒刚刚喷薄欲出，便在碑文光芒扫过瞬间急速暗淡、收缩。</p><p>它庞大的星体结构逆向旋转，喷发出的物质被硬生生“吸”回核心，炽热的等离子云层向内塌陷，最终回归为一颗年轻、炽热的蓝巨星。</p><p>蓝巨星并非终点。</p><p>它继而继续坍缩，光芒越来越微弱，形态越来越原始，膨胀为一大团炽热的星云漩涡。</p><p>——亿年演化，弹指间被抹去。</p><p>另一边，某颗行星上。</p><p>城市中尽是粗大的铆钉和裸露的管道，冒着滚滚黑烟、喷吐着灼热蒸汽和煤灰的庞大锅炉随处可见。</p><p>“蒸汽朋克”文明倒退了数亿年。</p><p>原来蒸汽风格的城市，变成覆盖整片大陆、由纳米级自修复合金构筑的悬浮城市群。</p><p>其核心的反物质能源阵列正稳定地输出着照亮半个星球的冷光。</p><p>城市中，思维网络以量子纠缠的方式瞬间连接着每一个经过四次基因强化的个体，他们正以集体意识规划着向邻近恒星系铺设戴森环的宏伟蓝图。</p><p>亿年前，它是个原子时代后期文明。</p><p>亿年后，它却仅仅是个宏观时代的文明。</p><p>亿年时间，多少演化？但如今，全部灰飞烟灭。</p><p>被“若罗碑刻域”影响到的区域，都在回溯成亿年前的模样。</p><p>“鱼仔、五九过来！！！！”杨帝怒吼！</p><p>他的两位心腹，两位旅行团的道友，化作银芒扑向杨帝的方向。</p><p>就在这电光石火之间，那笼罩整个灵界的“若罗碑刻域”光芒已然扫过这片星域！</p><p>“嗡——！”</p><p>无形的法则波纹掠过。</p><p>远处，一颗原本正孕育着原始生命的年轻行星，其上刚刚萌芽的藻类瞬间消失，沸腾的岩浆海洋凝固、冷却，地壳板块剧烈碰撞、抬升，星球在短短一息间倒退回数十亿年前炽热熔岩球的状态！</p><p>近处，其中几位靠得稍近的真仙境大能，脸上的惊骇瞬间凝固。</p><p>他们的身体开始变得模糊、透明，如同褪色的画卷，强大的仙力、精炼的道体、甚至蕴含其中的元神印记，都在这无情的回溯之光下开始瓦解、消散！</p><p>甚至，他们的存在痕迹正被“时间”本身强行抹除。</p><p>时间……回溯……</p><p>整个灵界都在被强制格式化，回归到某个设定的“原点”。</p><p>这些真仙，只要没有一亿岁，都将会被抹去。这只是时间问题。</p><p>“啧。”一声轻叹，听不出是烦躁还是怜悯，亦或是两者兼有。</p><p>残星道人的话在脑中一闪而过——你必须找到“通道”！</p><p>现在不是思考玉简和谜语的时候。</p><p>“放心吧，诸位……据我了解，不会有任何‘悲剧’发生。”</p><p>“我会带你们离开此地。”</p><p>“末那识——恒审思量，我执之根！！领域展开！！！！！！！！！”</p><p>杨帝怒喝！！！！！！！！</p>
