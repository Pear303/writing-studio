# 法术修行

<p>杨帝一直有件疑惑的事。</p><p>如果精灵长期不吃肉，为什么不会患上肌肉萎缩、贫血和营养不良？</p><p>伊芙现身说法了：“你这又是哪个年代的刻板印象？不吃肉的都是原教旨精灵，而现在嘞，观念改变了，绝大部分都是世俗化的现代精灵，该吃吃，该喝喝。”</p><p>他们欢快地吃完兔肉煲。</p><p>这兔子常年往身上施加「迅捷III」附魔，肉质紧致有嚼劲。</p><p>今日中午是杨帝亲自下厨，是他临时在脑海中狂翻食谱做的一锅炖兔肉煲。</p><p>食材本身优质，抵消了他厨艺的不足。</p><p>而杨帝如此拼命要下厨，可以理解成献给伊芙的拜师费。</p><p>因为这里是西幻世界观，所以拜师流程没那么复杂，杨帝不必像孙猴子给菩提祖师磕头。</p><p>这日，伊芙饭饱酒足，对兔肉煲很满意。</p><p>她将杨帝唤来。</p><p>精灵忽将檀木碗往青石上一磕，震得碗底残汤泛起金圈涟漪。</p><p>她指尖点向杨帝眉心：“痴儿！这七日你既参透御火、凝冰、引雷等一到三环灵能变化，我考考你：可记得‘三环法术·实体光球’的偈子？”</p><p>杨帝但觉灵台清明如洗，脱口便道：“以太为引，聚元素灵，凝光辉成球；力聚其中，坚逾金石，破诸般碍，照明前途。”</p><p>伊芙听闻，眼中闪过一丝赞许，点头笑道：“善！看来你这几日的修行并非虚言，确是精通三环灵能之变化。</p><p>“七日通晓三环法术，便是精灵族三万年来，也极少极少有过。</p><p>“今日，我便传你第四环法术，看我示范！我演示一次！”</p><p>瑞弗维尔正剔着牙。</p><p>忽觉自己座下石头化作流沙簌簌而落，惊得跳将起来：“石头化作沙了！”</p><p>“莫慌。”</p><p>伊芙微哂，屈指轻弹，流沙复聚成石头，“此乃「四环法术·物质解形」，练至大成，任他大魔导师，也要化作一滩泥水。”</p><p>……</p><p>伊芙手抚杨帝天灵盖：“你且观想那雪山巅的云霭。”</p><p>杨帝闭目间，见意虚境里腾起千丈雪浪。</p><p>待要运起御冰术抵挡，却听伊芙喝道：“蠢材！岂不闻刚不可久？”</p><p>他回想起要对火鸡“亲切地问候生活上有什么困难”，福至心灵，纵身跃入雪浪。</p><p>寒意透骨时分，漫天飞雪忽化三月杏花雨。</p><p>杨帝睁眼时，手中钢叉变作冰雕玫瑰。</p><p>精灵抚掌大笑，鬓边熔岩发卡映得满地落英似火焚。</p><p>“嘻！这便是「四环法术·元素嬗变」关窍，可悟了？”</p><p>……</p><p>“「四环法术·自然感应」须斩断三千烦恼丝，方得窥见一斑。你且去溪边打坐，何时听见石头诵经再来寻我！”</p><p>杨帝却不挪步，挠着后脑傻笑。</p><p>“师父错怪了，弟子自打‘失忆睁眼’那日，便听得见山石絮语、草木谈天。前日过乱石岗时，那青纹石还与我抱怨，说三百年前矮人铁匠踩了它一脚没道歉。”</p><p>伊芙目放精光，发觉真是捡到鬼才矣。</p><p>……</p><p>简单来说，伊芙开始指导杨帝4~6环法术。</p><p>当然，对外说法是“帮他回忆”。</p><p>毕竟杨帝是个“失忆的传奇法师”嘛。</p><p>到了“四环”这一步，灵能流动的模式，已经不是杨帝几秒就能记下来的了。</p><p>其复杂程度，远远不是三环所能比！</p><p>杨帝需要观察半分钟，才能记住一个四环法术的术型。</p><p>部分法术习得比较快。比如「四环法术·自然感应」，其实就是偷听万物的“语言”。</p><p>这些“语言”，其实任何人都能“听”到。</p><p>但是被潜意识过滤了。</p><p>但只有杨帝，在将10%的潜意识上浮至思维表层后，才发现了这些被“过滤”的内容。</p><p>天空的絮语，大地的呼唤，铁制炊锅在篝火旁见证过的九百六十二个故事。</p><p>人类孱弱的精神，将它们当做垃圾信息，在潜意识中就过滤掉了。</p><p>然而，异世界人能在没开发潜意识的情况下，通过灵能法术获取到这些信息。</p><p>这就是一代代异界人的智慧结晶啊。</p><p>学习得正上头，一声不和谐的呐喊爆发！</p><p>“吔！闹鬼了哼哼哼啊啊啊啊啊啊！！”</p><p>大本营那儿传来瑞弗维尔的惨叫。</p><p>“瑞弗！”伊芙闪现到炊具堆前时，四十米法杖显露本体握在手中！</p><p>她扫视一圈，发现了唯一疑点——</p><p>本该盛着半锅兔汤的炊锅，此刻锃亮如新，连糊在锅底的焦痕都消失了。</p><p>杨帝也给自己施加「迅捷I」附魔赶来：“瑞弗维尔？怎么回事？”</p><p>瑞弗维尔惊魂未定，指着空空如也的锅。</p><p>他结结巴巴：“我……我刚睡着就听到一阵奇怪的动静，感觉有什么东西在靠近，等我醒来，锅里的兔肉煲就没了。”</p><p>这可不是闹鬼了么？</p><p>伊芙蹲下身子，仔细查看地面。</p><p>果不其然，发现有一片地方的泥土性质和之前不同。</p><p>湿度更大，成分也有差异。凑近细嗅，能闻到一股更为浓郁的土腥味，似乎还夹杂着些许腐殖质的气息。</p><p>指尖揉搓，感觉质地更为细腻，颗粒感远没有表层泥土那般粗糙。</p><p>“并非闹鬼，而是有东西从地下钻了出来。”</p><p>瑞弗维尔嘟囔着：“这可怎么办，咱们不会被什么高阶魔物、灭世魔王给盯上了吧？”</p><p>是怎么强大的存在，能在伊芙和杨帝眼皮子底下，悄无声息间从地下钻出，偷走兔肉煲后又遁入地下？</p><p>但在元素视野中，没看到任何施法灵能残留的痕迹。</p><p>伊芙搓着光滑的下巴：“并非魔物。但如果是没有掌握灵能的生物，能做到如此神不知鬼不觉吗，我觉得不行。你怎么看，瑞弗？”</p><p>瑞弗维尔抿嘴唇耸肩，无言可论。</p><p>伊芙：“那你怎么看，杨帝？这样吧，这就作为你学习‘1~4环法术’的结业考试了。”</p><p>“杨帝这么快回忆起这么多内容了？”瑞弗维尔很是欣喜。</p><p>“好吧，我看看。”</p><p>杨帝打开「四环法术·自然感应·Pro-Max-Plus」进行探查。</p><p>异世界人民虽能在没开发潜意识的情况下，用灵能法术听见“万物的语言”。</p><p>但他们获得的信息，终究抹上了一层名为“法术”的薄纱。</p><p>就像人通过眼睛来观察外界，那些投影在视网膜上的光学信息，终究需要经过大脑处理，呈现的并非世界真实模样。</p><p>用“灵能”感知真实世界，终究相当于雾里看花。</p><p>杨帝凭借着潜意识上浮，能听见的“万物语言”更为清晰、深入。</p><p>甚至……更略微接近万物“原本的模样”。</p><p>10%潜意识解放！</p><p>六感接受的信息，如大坝决堤后的洪水狂暴涌入。</p><p>整个世界仿佛被撕开了一层神秘的面纱。</p><p>无数纷杂信息涌来。</p><p>他将感知力如细密的蛛丝般蔓延开来，渗入那片异样的泥土。</p><p>泥土中那些微小的生命，它们在黑暗中的蠕动与呢喃，都化作了可解的言语。</p><p>他听见了，地下昆虫对这突如其来变化的惊惶，还有树根对陌生气息的警惕。</p><p>顺着这些声音脉络，杨帝捕捉到一丝隐晦的痕迹。</p><p>那是一种奇异的脉动，与周围自然之声格格不入，像是往乐曲强行插入一段不和谐的音符。</p><p>这股脉动中，似乎蕴含着某种狡黠与灵动，刻意隐匿自身存在。</p><p>杨帝走到二百步外，不动声色地指了指下方。</p>
