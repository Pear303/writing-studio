# 鱼尊大战守望者

<p>随着鱼尊意念微动，混沌海沸腾起来，每一滴水珠都迸发出璀璨光芒，映出无数星球与生命生灭的幻象。</p><p>“看清楚了，这不是普通的H2O，而是蕴含润下法则的混沌之水！在我的领域内，一滴水中可演化三千大道，湮灭万千法则。”</p><p>当然这是吹的，大道有那么好演化有那么好磨灭吗？</p><p>不过这领域也确实有水平。</p><p>守望者舰队在混沌海中寸步难行。</p><p>能够轻易硬抗极超新星爆发的色荷力装甲，此刻在最普通的水分子冲击下，开始土崩瓦解。</p><p>守望者-决战旗舰绽放出刺目紫光。</p><p>他们要发动决死一击了。</p><p>决战旗舰与战争舰队同时启动某座共振仪，将整个星系大小的时空本身强行折叠、压缩至一块极小的空间。</p><p>舰队周身泛起诡异的靛蓝色光晕。</p><p>鱼尊敏锐察觉到，这些看似无序的操作，实则是某种直接干涉宇宙底层规律的行为——</p><p>就像将无数张胶片堆叠在一起，所有“不该重叠”的实时空，同时出现在同一个坐标。</p><p>那处坐标，万物的波函数同时坍缩为一个确定态，随即撕开了宇宙某种底层力量的封印。</p><p>“奇技淫巧！”阿巴呼吼，也使出了自己的终极绝招，太乙仙术·大荒囚天鳍！</p><p>双方攻击几乎同时出手。</p><p>两道恐怖的能量在虚空中轰然相撞——方圆百万光年的星域化为虚无！</p><p>数百万光年的时空结构，如同被无形巨手揉皱的纸张，实时空与虚时空的边界彻底消融……</p><p>鱼尊感受到某种超越认知的力量正在涌动。</p><p>现实与虚幻的接缝处，渗出极度刺目的光芒——零点能，宇宙诞生前就存在的真空能量。</p><p>即使是真空，其实也并不空。</p><p>真空之中仍然蕴藏了密度极高的能量，充满涨落泡沫的迪拉克之海。</p><p>而守望者将一万光年内的时空与质能，强行折叠到普朗克尺度，以绝对的蛮力打破了这些泡沫的平衡……</p><p>局域时空的卡西米尔效应增强，作为真空量子涨落的本底能量，此刻如同决堤的洪水般倾泻而出！！</p><p>一场盛大的零点能爆炸！规模超过8000亿次超新星爆发的总和！</p><p>这个数量并不大，但恐怖的是——它在非常狭小的战场空间内集中爆发！</p><p>爆炸没有声音，内部与中层深邃的漆黑，以及外围璀璨到极点的光。</p><p>那些被强行压缩至普朗克尺度的真空能量，此刻如同挣脱枷锁的远古巨兽，以超越光速的膨胀撕裂维度膜。</p><p>迸发出的伽马射线暴横冲直撞，在宇宙的幕布上刻下永久性创伤。</p><p>时空本身，在这场狂欢中失去意义。</p><p>甚至，引力波都在这片混乱中，短暂失去了传播方向，如丧尸那般抽搐。</p><p>零点能爆炸，正在以宇宙尺度扩散。</p><p>这场爆炸动摇了时空的底层规律，毁灭性爆焰的扩张速度，短暂破坏了光速限制，以数万倍甚至百万的光速蔓延。</p><p>距离爆炸中心十万光年处，一颗年迈的红巨星首当其冲。</p><p>它膨胀的气态外层在接触时空骇浪的瞬间就被剥离，如同被无形火焰点燃的棉花，以惊人的速度坍缩又被吹飞殆尽。</p><p>极度接近光速的能量物质洪流从蜷曲的时空泡中弹出，与恒星的重物质核碰撞，发生极端相对论性冲击加热，红巨星残余的星核物质在一纳秒内达到夸克-胶子等离子体相。</p><p>它发生了也许是此生最后一次超新星爆发。</p><p>迸发出的光芒，足以照亮周围百万光年的星域，却在下一刻被爆炸的余波彻底吞噬。</p><p>只留下一片扭曲的时空涟漪，以一小片微不足道的痕迹，证明它曾存在过。</p><p>这只是星空中微不可察的一角。</p><p>在这场超光速爆炸的覆盖区域上，超新星爆发不再是孤立的奇观，而是如多米诺骨牌般在星群间蔓延。</p><p>这片星域内，星光在某时刻达到亮度峰值，将百万光年深空染成纯粹的白。</p><p>还有任何生命能存活吗？</p><p>宇宙中绝大部分生命形式，都诞生在行星和卫星上。</p><p>此时此刻，无数行星飞蛾扑火般坠入恒星的火海，冰封星球在高能粒子雨中瞬间气化，海洋行星被煮沸成等离子体云雾，金属星球也在时空潮汐力下被撕成原子级别的碎片……</p><p>阿巴却没有听见万物生灵的哀嚎。</p><p>爆炸……没有杀死多少超过一定智慧能力的生物？</p><p>她身为太乙真仙，没有感受到虚境中有任何多出来的痛苦和死亡思潮。</p><p>无人因此受难，那倒也是好事。</p><p>说到底她是修仙之鱼，不是青面獠牙满脸麻子的杀人狂魔。</p><p>修仙者讲究斩却凡尘因果，能够尽量少造成生灵消逝，都要尽量争取，减轻身上的业孽。</p><p>这也是为了道心不破碎。</p><p>有些修仙者，就因年少轻狂时失手杀了一个人，此后每临境界突破，必遭心魔反噬，终生不得进步半寸。</p><p>阿巴被零点能的能量狂潮冲刷鳞甲。</p><p>很恐怖的威力呢……相当于她三万三千年前渡过的最后一次天劫的20倍威力。</p><p>如果是三万三千年前的她，一定会在这种威力的爆炸下原地暴毙。</p><p>但时代也变了。</p><p>今日的阿巴，只是蛐蛐重伤。</p><p>她冷眼瞥向守望者文明舰队。</p><p>正所谓杀敌一百，自损八千。</p><p>守望者文明有超过8000支亿级规模的舰队，在零点能的洪流中坚持不到五秒，就接连化作一朵朵转瞬即逝的璀璨星云。</p><p>残骸如流星群般在能量风暴中飘荡，银白色舰体碎片表面，还残留着零点能火焰的余烬。</p><p>整片星域，仿佛在下一场金属与光子组成的暴雨。</p><p>但阿巴知道，守望者虽自损八千，但根本称不上伤筋动骨。</p><p>暂且不提他们比虫族还变态的爆兵能力。</p><p>守望者的舰队，所有战舰皆是无人驾驶的战争机器。</p><p>它们被程序化的指令驱动，从建造之初就剔除了情感模块。</p><p>自始至终，“守望者”都只有一个个体。</p><p>一个极度庞大的“格式塔思维”。</p><p>对他而言，数以万亿计的战舰与超级计算机既是它的神经元，是文明延伸向宇宙各处的感知触手。</p><p>这些冰冷的金属载体通过零延超光速迟信息交互，每个节点都能瞬间调用整个文明的知识宝库，所有数据在意识洪流中不断重组、迭代，形成超越个体认知的集体智慧。</p><p>它只有绝对理性的战略推演，必要的时候才会模拟出感情，媲美宇宙中最多愁善感之诗人。</p><p>在战斗中损失的战舰，不过是被删除的程序模块，随时可以通过宇宙各地、密密麻麻的工厂批量重构。</p><p>“损失几千支亿级舰队”对它而言，不过是一次有点冒险的战术抉择。</p><p>鱼尊望着这片机械葬礼的毁灭场景，鳞片下的灵识微微震颤。</p><p>那些化作宇宙尘埃的战舰里，确实没有一丝生灵陨落的波动。</p><p>守望者文明将机械智能发展到极致，反而成了他们抵御业障反噬的屏障，这让她心中涌起一丝难以名状的复杂情绪。</p><p>——为避免生灵涂炭感到庆幸，又对这种近乎冰冷的文明形态生出几分警惕。</p><p>大罗道果，必须落在我手里……</p><p>但此刻，舰队中极其喧嚣的通讯链路，以及鱼尊灵魂中原本奔腾不息的思维，霎时间陷入诡异的沉寂。</p><p>有一个东西，卡在了战场最中央。</p><p>一具黑色人影。</p><p>阿巴回想起她在美人鱼海湾的惊鸿一瞥。</p><p>深埋在皮囊之下、灵魂深处的原始恐惧再度被唤醒。</p><p>「这个世界的皮下，蠕动着一个无法用任何文明语言描述的‘数值怪’。」</p><p>「宇宙不过是某个数值怪指甲缝里的尘埃。」</p><p>她与那尊“数值怪”对视仅仅长达5秒钟。</p><p>但那是五秒钟深入骨髓，刻进灵魂的原始之恐惧啊……</p><p>那可是5秒钟的伟大的恐惧，难道还不足以让鱼受用一生吗？</p><p>她受用一生，并期待不要再见到数值怪。</p><p>期待落空。此刻……那具黑色的人影，蠕动了。</p>
