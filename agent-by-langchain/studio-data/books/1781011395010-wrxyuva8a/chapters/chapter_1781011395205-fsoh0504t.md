# 天界之上，暂名终界

<p>天界宇宙从诞生之初，就从来不存在“18岁少年少女觉醒用水晶球装着的天国世界”。</p><p>如果有人提起这个荒谬的设定，也许会遭到周围同僚的嘲笑。</p><p>虽然他们也无法证伪，是否有个超级存在，将这个“机制”扼杀在了历史的起点。</p><p>独断万古，不可证明。</p><p>也根本没有证明的必要，好比你也无法证伪某人的后车库里有一只会完美隐形并阻断所有信息流通使世上任何人都无法直接或间接察觉其存在的红色喷火龙。</p><p>天界之上，按照惯例，暂名终界。</p><p>穿过那层被视为“天界尽头”，穿过象征着万物归寂、法则凝固的厚重壁垒。</p><p>杨帝，被装在特制鱼缸里挂在腰带上的阿巴，以及被装在小灵通中的59改，看到的景象却出乎所有人的意料。</p><p>那里没有想象中的死寂、荒芜或扭曲。</p><p>也没有吞噬一切的黑暗，没有冻结灵魂的寒意。</p><p>终界，反而是一个正常得近乎诡异，美好得令人心醉的世界。</p><p>草原在风里起伏，无边无际地铺向天边。</p><p>可此刻，连天空也被浓得化不开的乌云吞了去，铅灰色的云团铺满穹野。</p><p>压抑的昏暗里，乌云中央忽然裂开一道缝。</p><p>那缝起初细如发丝，随即被无形的手撕开，露出背后藏着，亮得灼目的金黄。</p><p>阳光像决堤的河，顺着那道裂罅倾泻而下，一束束、一道道，在深绿的草海上砸出亮闪闪的光斑，把近处的草叶照得透亮，连草尖上的露珠都折射出细碎的彩虹。</p><p>他们看清了，平原上点缀清澈如镜的湖泊，蜿蜒流淌着散发草木清香的河流。</p><p>远处有连绵起伏、形态柔和的山峦，山间云雾缭绕。</p><p>隐约可见精巧雅致、与自然完美融合的建筑群落。</p><p>智慧生灵——形态各异，有的类人，有的如精灵，有的甚至如同元素聚合体——和谐地生活着。</p><p>没有争斗，没有匮乏，没有病痛，甚至连衰老都显得优雅而缓慢。</p><p>这里的一切都洋溢着一种……永恒的、恰到好处的“美好”。</p><p>阿巴在鱼缸里吐了个泡泡：“天堂？呵，本尊见过太多表面天堂、内里腌臜的地方了。老大，事出反常必有妖！”</p><p>杨帝眉头微皱。</p><p>他强大的感知扫过这片天地。没有伪装，没有幻象。</p><p>这里的法则稳固和谐，能量循环完美自洽，生灵的情绪波动纯粹正向。</p><p>这里的美好，都是真实的。</p><p>并不是像什么纳垢花园那样的糖衣炮弹虚伪陷阱。</p><p>一个身影无声无息地出现在他们面前。</p><p>祂的形态难以描述，仿佛由最纯净的光、最深邃的智慧以及这片土地本身的意志凝聚而成。</p><p>祂的气息浩瀚无边，却又温和内敛，如同包容万物的海洋。</p><p>祂是支撑这片“天堂”运转的核心，此界唯一的圣人。</p><p>“欢迎来到终界，远道而来的客人。”</p><p>圣人的声音直接在众人心中响起，不带丝毫敌意。</p><p>杨帝没有寒暄，开门见山：“你就是此界的圣人？把这里变成这样的？”</p><p>圣人微微颔首：“非我之功，此乃终界本相。我所做的，不过是引导与守护，确保这份美好不被玷污，不被破坏。”</p><p>“守护？”杨帝眼神锐利起来，“以隔绝万界、禁锢一切的方式守护？”</p><p>“禁锢？”归藏轻轻摇头，笑容带着一丝无奈，“不，是保护。保护这片净土，不被外面的……地狱所侵蚀。”</p><p>“地狱？”阿巴忍不住插嘴，“你说外面是地狱。”</p><p>“是的。”</p><p>土著圣人的语气带着一种沉重的确信。</p><p>“外面是怎样的地狱。”</p><p>“无尽的争斗、资源的掠夺、文明的倾轧、强者的肆意妄为、弱者的挣扎沉沦……欲望如深渊，贪婪如烈火，将一个个星星焚烧殆尽。”</p><p>“所以你在此地构建了一个天堂。”</p><p>“没错。”</p><p>“你将此界生灵囚于永恒的温室，剥夺了他们经风雨、历世事、自主抉择乃至犯错的自由。你所谓的守护，不过是一潭死水——纵有万般美好，也不过是幅凝固的画，而非奔涌不息的生命长河。”</p><p>“……客人，您真是冷血的怪物。您可曾听过母亲伏在病榻边的恸哭？可曾听过孩童在硝烟中的悲泣？您可见过父亲深夜辗转的半头白发？又可见过老人独倚寒窗时，眼中翻涌的浊泪？”</p><p>阿巴也和终界圣人站在一起。</p><p>“老大，虽然我打不过你，但我始终在心灵上支持他。”</p><p>“是吗？大人打架，阿巴你去观战席。至于这位圣人，你问‘可曾见过’……”</p><p>杨帝踏前一步，身上那股蛮横不屈，欲与天公试比高的恐怖意志轰然爆发！</p><p>“我当然见过，我也经历过。”</p><p>“那你为何执意如此无情？”</p><p>终界圣人周身，爆发出璀璨圣光。</p><p>二人大战至终界尽头，就连那个大道都近乎磨灭。</p><p>最后，杨帝一记膝顶定胜负，将对方五脏六腑打至错位。</p><p>圣人如遭雷击，身形剧震，心中充满了难以置信和深深的挫败感。</p><p>他居然被对方三拳一膝盖打倒。</p><p>还都是没有招式和师承的王八拳！</p><p>杨帝收起沙煲大小的拳头。</p><p>他声音平静下来：“你的‘永恒天堂’，还是太弱小，就连我来了也能几拳打爆。”</p><p>圣人身上的光芒黯淡下去，祂变成他。</p><p>他看着杨帝，又看了看这片祂守护了无尽岁月的土地，看着那些因法则波动而略显茫然的生灵。</p><p>最终，长卸下了万钧重担般叹息一声，脸上露出释然的苦笑。</p><p>颤颤巍巍地从口袋里，掏出一红一蓝两粒药丸。</p><p>“吃下红色药丸，你便获得此世的控制权。吃下蓝色药丸，你也能获得此世的控制权，不过我加了蓝莓味。”</p><p>“不，我并不是要毁掉你的世界，也没打算搞什么掠夺占领的戏码。”</p><p>“……嗯？”</p><p>“你是终界的‘原生圣人’。如果是此世界原生的，那倒不至于打倒批倒。除非……”</p><p>“除非？”</p><p>“……除非你是上界之人，僭越行事！”</p><p>杨帝的声音带着冰冷的审判意味，“下界岂是上界之人能随意干涉的玩物？此乃天地至理，乾坤定序！你身为终界圣人，若本分守己，护持一方，倒也罢了。若是上界来的搅屎棍……”</p><p>杨帝一路掀桌子砸场子。</p><p>“夕阳红旅行团”从水晶球打到神界牌桌，凿穿天界壁垒，最后破开“终界”的壳子。</p><p>但杨帝并非不加分辨地就开屠。</p><p>他对此界圣人疯狂开嘴炮话疗。</p><p>杨帝批判得兴起，正欲再给这“思想落后分子”上上强度。</p><p>他定住了。</p><p>他看到了下一层世界，也就是天界的本质。</p><p>那是一百公里外，一条睡梦中的小狐狸所做的梦。</p><p>那小狐狸并非耶罗大仙，别阴谋论了。</p><p>一个终界生灵的梦，孕育了天界宇宙。</p><p>这特么是何等乾坤倒悬连无理数看了都要直呼卧槽的惊天设定。</p><p>“梦，也是一个世界？”</p>
