# 扩散不同宇宙

<p>破开时空，撕裂维度。杨帝并没有抵达更上层的宇宙，因为此地就已经是最上层的世界。</p><p>但在“无限宇宙”之外，仍然有不可数的，无穷多个的，与其平级的“故事/沙盘/世界/宇宙/天地”。</p><p>杨帝踏入光锥之外。确实没有预想中更上层的宇宙。此地已是万界顶点。</p><p>但无限宇宙之外，还有无穷平级的世界泡，如同黑暗海洋里漂浮的无数光点。</p><p>世界即现实。泡膜之内，是法则物质能量时间因果存在本身。</p><p>泡膜之外是虚空，比虚无更空旷，是现实的绝对反面。源于世界内部的法则逻辑存在，在虚空中如雪消融。</p><p>杨帝悬于虚空。</p><p>绝对的“无”包裹着他。</p><p>没有上下左右，也没有时间流逝，只有纯粹吞噬一切的“空”。</p><p>他自身携带的存在感，成为这片绝对虚空中唯一不和谐的“杂质”。</p><p>一点微光在远方亮起。似是虚空这块黑布上一个被针戳破的小孔，透出另一个世界的微芒。</p><p>他朝那光点移动。</p><p>这里没有距离概念，念头一起，他已站在第二个世界泡膜之外。</p><p>泡膜晶莹，映出内部景象：一个科技与仙道畸形融合的宇宙。星舰与飞剑并行，数据流与灵气交织。</p><p>杨帝穿透泡膜，进入此界。</p><p>几乎同时，一道身影撕裂空间挡在他面前。此人浑身笼罩在由亿万纳米机器人构成的液态金属战甲中，背后悬浮着不断刷新的数据光屏，散发着与此界法则完美融合的圣威。</p><p>“异界来客？”圣人开口，声音带着电子合成质感，“此界归我‘天工道主’统御。报上你的数据流编码。”</p><p>杨帝看着他：“耶罗大仙？”</p><p>天工道：“检索失败。未发现匹配名号。立刻提交你的存在编码进行备案，否则将执行格式化程序。”</p><p>杨帝不再言语。</p><p>天工道主的摄像头中寒光一闪，扬声器发出危险的滴滴嘟嘟声。</p><p>他背后光屏瞬间爆发出足以瘫痪整个星系的浮游炮群，同时液态战甲变形，延伸出无数高维切割武器，空间本身被数据化重组，形成一个绝对的数学率囚笼，将杨帝封镇其中。</p><p>攻击持续了数次心跳的时间。</p><p>光芒散去，杨帝站在原地，连衣角都未曾晃动。</p><p>天工道主的数学率武器，在触及他体表前便自行崩解，如同雪花落入熔炉。</p><p>他核心处理器瞬间过载，逻辑陷入死循环。</p><p>杨帝抬手，指尖一点灵能凝聚。</p><p>这点灵能脱离指尖，迅速膨胀、塑形，化作一个与他外貌别无二致的分身。</p><p>分身气息与此界法则瞬间交融，稳固如山。</p><p>“待着。做我应该做的事……算了，反正你我心神相连。”杨帝对分身道。</p><p>他转身离去，无视了天工道主那由震惊、恐惧和逻辑混乱交织而成的僵硬数据表情。</p><p>虚空。下一个光点。</p><p>杨帝进入第三个世界。这是一个纯粹的古修真宇宙，灵气浓郁得化为实质的星云。</p><p>他刚进入，便感到一股磅礴、古老、历经无尽岁月打磨的圣威锁定了他。</p><p>一位身着朴素麻衣、脚踏草鞋的老者出现在星空中。</p><p>他面容沧桑，眼神却如初生星辰般明亮纯净，周身气息与整个宇宙完美共鸣，仿佛他就是宇宙意志的化身。</p><p>“老夫‘百劫散人’，见过道友。”</p><p>老者稽首，姿态平和，眼神深处却带着审视，“道友气息古怪，不属此界。不知跨界而来，所为何事？”</p><p>“耶罗大仙？”杨帝重复。</p><p>百劫散人捋须沉吟：“耶罗？未曾听闻此等名号。老夫自微末凡尘而起，拾遗补缺，偶得机缘，步步为营，方有今日。此界生灵，老夫皆有所感，并无此等存在。”</p><p>杨帝沉默。</p><p>百劫散人叹了口气：“道友既不言，又身怀莫测之力，为免此界生乱，老夫只得……”</p><p>他话未说完，身形已动。</p><p>动作看似朴实无华，一拳递出，却引动整个宇宙的灵气潮汐，化作一条咆哮的星河巨龙，蕴含的力量足以将一片星域打回混沌未开！</p><p>同时，他脚下步伐暗合周天星斗，瞬间布下困锁时空的太古绝阵，封死杨帝所有退路。</p><p>星河巨龙撞上杨帝。</p><p>足以重开混沌的力量，连他体表的一层微尘都未能激起。绝阵符文闪烁几下，无声熄灭。</p><p>百劫散人瞳孔骤缩，脸上那亿万年磨砺出的从容瞬间破碎。</p><p>杨帝抬手，又一具蕴含无限灵能的分身凝聚成型，落于此界星空。</p><p>“我会一直看着你。”杨帝道，身影消失。</p><p>光点。光点。光点。</p><p>虚空中的光点无穷无尽。</p><p>第四个世界，本土圣人是天生地养的仙道大帝，生为荒古圣体，走在路上都能捡到七八十个机缘。</p><p>杨帝进入，迎接他的是覆盖整个宇宙的灭世雷罚。雷罚湮灭，分身留下。</p><p>第五个世界，圣人是一个将自己意识塞进计算机里的地球人。它分析了一下杨帝，顿时数据溢出，神颠魂倒，宕机昏迷。分身留下。</p><p>第六个世界，圣人是一位将自身存在寄托于众生信仰的香火神灵。亿万信徒的祈祷化作因果巨网，缠绕而来。巨网腐朽，分身留下。</p><p>第七个，第八个，第九个……</p><p>杨帝在虚空中行走，在无穷光点间跳跃。他的动作越来越快，留下的分身越来越多。</p><p>从最初的逐一探索，到后来一步踏出，身影便同时在千万个世界泡膜上泛起涟漪。</p><p>千万个杨帝同时穿透泡膜，进入千万个不同的宇宙。</p><p>每一个杨帝进入新世界，无论本土圣人反应如何，无论攻击多么绚烂恐怖或诡异莫测，最终结果都毫无悬念。</p><p>攻击完全无效，圣人惊骇，分身留下。</p><p>分身并非复制体。</p><p>它们都承载着杨帝的本源灵能，保留有与“原本”相同增势的无穷现实丰度。</p><p>每一个分身诞生的瞬间，其心神意志便与杨帝的本源意识相连，如同神经网络中新增的神经节点。</p><p>一化十，十化百，百化千……</p><p>最初是线性增长，很快变成指数爆炸。</p><p>杨帝的分身数量，或者说它分布于各个世界的“肢体”数量，以无法想象的速度疯狂膨胀。</p><p>十的十次方，十的二十次方，十的三十次方……</p><p>每一个新世界，都如投入平静水面的石子，激起的涟漪尚未平息，便又有亿万颗石子同时砸落。</p><p>杨帝的本体意识，如同矗立在风暴之眼的中心。</p><p>无穷无尽的信息流从每一个分身节点汹涌而来——亿万种不同的宇宙法则，亿万种文明的兴衰画卷，亿万种圣人的惊骇与绝望，亿万种存在的可能性……海量的信息足以瞬间撑爆任何存在的意识。</p><p>但杨帝的第六识-意识，如同黑洞，又如同无限延伸的弦网。</p><p>信息洪流涌入，被瞬间解析、吸收、统合。</p><p>在第七识-末那识连接下，每一个分身都是他的眼睛，他的耳朵，他的触角。</p><p>他意志覆盖的范围，正以指数爆炸的速度，侵蚀着这片无穷虚空中每一个漂浮的“世界泡”。</p><p>借助第八识-阿赖耶识，他的心神网络，正在指数级扩张，覆盖向虚空中的每一个角落，并将自己所占据的每一个世界，作为“大脑”的一个神经节点。</p>
