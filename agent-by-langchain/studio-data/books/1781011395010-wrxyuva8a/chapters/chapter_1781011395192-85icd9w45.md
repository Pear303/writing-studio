# 以下界为食

<p>杨帝意识触碰到那裂隙边缘的瞬间，那道宏大，冰冷且古老的意志，如同深海的暗流，无声无息地包裹了他。</p><p>它没有敌意，没有情绪，只有一种近乎绝对理性的漠然审视。</p><p>紧接着，一个意念，清晰无误地在杨帝的识海中响起：</p><p>「汝……可观本源。非敌……可共谋。」</p><p>你能窥见本源。你不是敌人，我们可合作。</p><p>“哦？合作共谋？谋什么？谋这蛐蛐仙界的一点灵能渣滓？”</p><p>「灵能……养分。此界……牧场。上界牧者……以下界为食……亘古常理。」</p><p>灵能是养分。此界是牧场。上界的牧者以下界为食，是亘古不变的道理。</p><p>庞大意志的意念如同冰冷的星辰运转，阐述着一个残酷而理所当然的事实。</p><p>它顿了顿，继续传递信息，那“裂隙”似乎微微波动了一下：</p><p>「汝……亦可为牧者……分享……盛宴。」</p><p>杨帝脑中瞬间闪过一个画面：一个程序员坐在电脑前，手指翻飞，维护着某个庞大的虚拟沙盘项目。</p><p>项目里的每一个NPC，每一次资源变动，都成为他工作汇报、领取工资的养分。</p><p>这算不算另一种形式的“上界牧者以下界为食”？</p><p>那位名为“桂虚”的程序员，在三十五岁前都是这样的生活模式，直到大厦崩塌。</p><p>眼前这厮，和“桂虚”那伙程序员的区别在，对方并没有把自己看作是bug，没有把自己视作黑客。</p><p>相反，还主动抛出橄榄枝要合作。</p><p>“有点意思。不过，空口白牙就想拉人入伙是否有些搞错了什么？”</p><p>杨帝的意念带着审视，“你这诚意，看起来可不太够。至少，得先交个‘投名状’，或者展示点真本事？”</p><p>庞大意志的意念沉默了片刻，那核心裂隙周围的崩坏血肉似乎蠕动得更快了些。</p><p>杨帝能感觉到一种“思考”的波动。</p><p>「汝所求何物？」</p><p>它声音清晰了些。</p><p>「你图个啥？」</p><p>它又问一遍，这次终于翻译成大白话。</p><p>杨帝指了指周围那些还在试图重组、散发着疯狂呓语的崩坏物质，以及空气中无处不在的精神污染余波。</p><p>“我看你污染精神、扭曲认知的本事挺溜。这招怎么玩？教教我，让我看看，你这‘牧者’的手段，值不值得我合作。”</p><p>他不久前被59改一语惊醒梦中人。</p><p>——原来，自己内心深处有一个愿望，是让自己也成为不可名状的玩意，过过瘾。</p><p>……好吧这是次要原因，重要的是他想找到对虚无缥缈的目标，有无更好的杀伤手段。</p><p>拳头能解决99.9%的事情，但有些东西用拳头揍不到，就只能用更虚无缥缈，更形而上的攻击。</p><p>杨帝回想起一颗“大眼珠子”的形象，回想起某个长得很丑很抽象的已逝之人。</p><p>他搓了个不可名状的精神体。</p><p>这个精神体形象，没有固定形态，时而像无数眼球堆叠成的肉瘤，时而化作长满扭曲肢体的漩涡。</p><p>无数细小的嘴巴在体表开合，发出既像大道轰鸣又像婴儿啼哭的诡异声响。</p><p>这算是很经典的恐怖元素堆砌了。</p><p>“直视我！无限恐怖之主！你觉得现在我这模样还行吧，精神污染足不足？能不能把最底层的‘仙帝’一眼瞪死？”</p><p>杨帝对庞大意志说。</p><p>那道庞大意志锐评：</p><p>「并不能。现在你只是一颗长满触手和嘴巴的四喜丸子，并不具备太多不可名状的形而上威慑力。」</p><p>神交是双向的，它现在甚至学会“四喜丸子”这种地球名菜。</p><p>他们看起来有一句没一句地聊起来了。</p><p>「你的‘不可名状’仍停留在‘形’的层面，就像孩童用泥巴堆砌怪物，以为越扭曲就越可怖。」</p><p>“啧，要求还挺高。好吧，我再想想。”</p><p>杨帝继续微调自己的精神体形象。</p><p>“审美这事儿能够同步进行。现在我比较好奇的是，你口口声声说‘上界牧者以下界为食’，是亘古常理。那具体是怎么个‘食’法？为何需要动用‘诡异’，或者说，为什么需要将现实丰度归零？这不像‘进食’，倒像是……彻底毁灭。”</p><p>庞大意志的意念波动了一下，那核心裂隙周围的黑暗仿佛变得更加粘稠、深邃。</p><p>这一次，它传递的信息，不再仅仅是冰冷的陈述，似乎带上了一丝难以言喻的，偏好？</p><p>「将世界线偏移至极远的远端，即可收获因偏移而产生的‘灵能’。」</p><p>类似于化学键的断裂和重组，都随着能量的变动。</p><p>有些物质的化学键断裂重组时，在宏观层面便表现为剧烈的能量释放，比如发热、燃烧或爆炸。</p><p>对一个世界内的世界线走向做相应的操作，将原本正常的世界线“燃烧”、“释放”掉，上界之人可以获得那什么……灵能。</p><p>「我所求的不只是现实丰度归零。」</p><p>「更有现实之中，一切意义与美德意义彻底湮灭……存在归于绝对之‘无’……」</p><p>「此乃我等追求的终极之静，终极之净。」</p><p>「崩坏/诡异/天魔，不是工具，而是‘食’本身，亦即‘盛宴’之真味……」</p><p>庞大意志的意念中，第一次流露出近乎愉悦的情感。</p><p>一种对“终极虚无”的病态追求和满足感。</p><p>杨帝沉默了。他理解了。</p><p>他理解了——对方已经沉浸在自己的艺术里不能自拔。</p><p>它享受有意义之物，被撕裂、被溶解、被归零的过程，所带来的扭曲满足感。</p><p>庞大意志的意念再次传来，带着一种理所当然的平静，但深邃的平静之下，是一股兴奋到颤栗的愉悦。</p><p>「此即我等之道，你可愿意，与我共赴毁灭一切美好事物的悲剧？」</p><p>“但你不只是简单的毁灭一切美好事物。”</p><p>「没错……我们一致决定，操控诡异降临在此世18-22周岁的人群之中，因为，此年龄段的青春少年男女情感最为浓烈。」</p><p>“你们？……你要他们在怪谈领域中挣扎，而且是群体性地拖进怪谈中。”</p><p>「因为单纯毁灭的本身，过于粗糙。」</p><p>「我等所求是‘意义’崩解刹那，所绽放的最璀璨，亦是最绝望的‘光’。」</p><p>「智慧，勇气，善良，纯洁，甚至卑劣……在生死边缘，人之原性被压榨，被点燃，如……最绚烂的……烟花……」</p><p>庞大意志的意念中，颤栗的愉悦感几乎要满溢出来。</p><p>杨帝想到阿巴。如果她也陷入这样的游戏，被逼到绝境，爆发出璀璨的求生意志，或某种极致的情感。</p><p>然后……成为这狗屁意志“艺术”的一部分？</p><p>“你是说，你收集人类的智慧、勇气、善良和纯洁，作为自己的艺术展览品？”</p><p>「没错。」</p><p>杨帝看着那核心裂隙，看着周围仍在不断试图侵蚀、溶解“意义”的崩坏血肉。</p><p>他缓缓抬起了手，五指微微收拢，仿佛要扼住某种无形之物的咽喉。</p><p>他的意识体——那颗还在变幻着眼球、触手和尖叫嘴巴的四喜丸子，停止了无意义的蠕动。</p><p>他看着那坨蠕行的宏大意志，那核心裂隙如同宇宙的伤疤。</p><p>“你叫什么名字？”</p><p>「马格努斯。」</p><p>“这样吧小马哥，你这种艺术很大的发展和进步空间，你先听我说……”</p>
