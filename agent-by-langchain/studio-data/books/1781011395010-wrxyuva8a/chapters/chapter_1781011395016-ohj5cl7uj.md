# 吃坏肚子做乱七八糟的梦哼哼啊啊啊啊

<p>杨帝天真地以为，如果能重来一次，他再也不会去吃一口拼优饭。</p><p>直到许多年后再回看，这口饭，是他前半生的结束，后半生的开始。</p><p>……</p><p>“喂，没事老爸，我还好，但有点事，五一可能回不来。”</p><p>“哎，我知道，生活费肯定够啦。过完五一我再回来和你钓鱼。”</p><p>“我声音哑了？没有吧，可能只是有些喉咙发炎。”</p><p>杨帝挂断电话，蜷缩在铁架床上。</p><p>他身体扭成条蛆的形状，汗水把四年前军训时发的草绿色床单浸出个人形。</p><p>体温39.9℃，有种濒临死亡的快感。</p><p>杨帝视网膜上，已经爬满彩色噪点。</p><p>距离吃下“拼优饭·赌上厨师生涯的青椒炒饭”已过去10小时30分钟。</p><p>直到现在，他才后知后觉那口发黏的米饭有什么不对劲。</p><p>——谁家潮汕肉卷是酸苦的？！</p><p>为什么吃的时候没有发觉啊啊！</p><p>已经迟了，他大抵是患上了急性肠胃炎。</p><p>胃里翻江倒海，打嗝却嗝不出一点气，像是一大泡湿的粘的东西堵在肠胃。</p><p>过去几个小时，杨帝上吐下泻，仿佛已经消耗完了未来一周蹲大号的次数。</p><p>在五分钟前，最后一次将肠胃清空之后，他终于撑不住，爬上了床铺。</p><p>杨帝以前也有过急性肠胃炎的经验，这种肠胃疾病很容易伴随着发热高烧。</p><p>一发烧就会很累很困。</p><p>事已至此，只能顺应天道，先睡一觉。</p><p>但下铺，舍友张明远一直在嘀咕着什么。</p><p>“绝壁有问题，这该死的图片……训练集里明明有一千张气球照片……”张明远第五十三次重复这句话。</p><p>这个计算机天才此刻正疯狂敲击青轴键盘，这种键盘的声音在狭窄室内，比过新年放鞭炮还大声。</p><p>天知他道在捣鼓什么。</p><p>“高斯噪声增加0.7%，边缘检测阈值也得改改……老杨，我觉得你要下来看一下……老杨？哦发烧了啊，那你睡吧。”</p><p>真善解人意呢。</p><p>杨帝已经没力气说话，只能默默翻个白眼。</p><p>他盯着天花板上的霉斑。</p><p>昏昏沉沉之中，似乎那团黑褐色污渍在顺时针旋转，边缘的污秽如波涛般蠕动。但明明这里是北半球，漩涡应该逆时针吧……</p><p>太阳穴突突直跳，高烧让听觉产生了诡异的，分层。</p><p>他能同时听见，舍友张明远指甲敲击青轴键帽的脆响，自己肠胃痉挛的咕噜声，隔壁间开水时管道里流动的水声。</p><p>还有——某种类似湿海绵摩擦玻璃的细微声响，不知从哪传来的。</p><p>高烧39.9度的视野里，天花板开始剥落。</p><p>混凝土碎屑如鳞片般簌簌坠落，露出后面蠕动的星空，亿万颗星辰在深空中眨动。</p><p>有粘腻的絮语顺着耳道爬进来，在脑沟回里下蛋。</p><p>杨帝低头，看见胸腔变得透明，肠胃化作缠绕的云，急性炎症部位正在喷发玫瑰色的星尘。</p><p>他感觉自己正在坠落，或者说——整个宇宙正在反向坠落进他的毛孔。</p><p>世界被塞进自己的体内……</p><p>……</p><p>杨帝睁眼，发现自己正躺在某家苍蝇馆子的料理台上，胸口插着把锅铲。</p><p>“拼优饭·赌上厨师生涯的终极奥义！”</p><p>戴着防毒面具、身穿橙色生化服的主厨挥舞菜刀。事实上没那么卫生。</p><p>画面支离破碎。</p><p>……</p><p>他看见看见驾驶机甲的绝地大师，与转生三十三次的西斯尊者战斗。</p><p>二位大能鏖战至宇宙边疆，仿佛大道都要磨灭了！大道似乎比大豆坚固不了多少</p><p>……</p><p>他看见“善解人意”的张明远穿白大褂，正在给泡在福尔马林里的杨帝大脑接数据线。</p><p>“这不对……”</p><p>杨帝感觉脑子濒临融化，“如果我是缸中之脑，那正在思考‘缸中之脑’这个概念的又是哪个主体……”</p><p>……</p><p>坠落。</p><p>自己正在分裂成无数个平行时空版本，坠入不同的时间线。</p><p>有的掉进白垩纪末期的火山灰云，有的卡在战国时期墨家机关城的缝隙里。</p><p>最幸运的版本，莫过于杨帝碰上了一个让他很眼熟的老人，小径分岔花园的作者。</p><p>那位文学巨匠问道：“年轻人，你知道我为什么要写《想象动物志》吗？”</p><p>杨帝摇摇头。</p><p>他甚至没听过这本书。</p><p>“我尝试研究人类的想象力，但我发现那是一座迷宫，无穷无尽的迷宫。这个迷宫有无数个房间，但人类目前只接受很小一部分的房间，而另外大多数的岔道，都是不宜窥探的危险。”</p><p>杨帝并不太明白什么意思。</p><p>“我们只能接受符合我们想象力的类比——人的衰老和太阳的夕照，梦和生命，时间和水的流逝。超过了这些，擅自窥探逻辑之外的灰区，甚至是黑区，你会看到超越一切言语所能描述的恐怖。”</p><p>杨帝已经慢慢有些懂了。</p><p>“我举个例子吧，比如我手中有一个拇指盖大小的圆球，内部囊括了整个宇宙，但是体积没有按比例缩小。”</p><p>杨帝点点头：“我想象不出来那具体是怎样的情景，只能比较模糊的理解那种抽象概念，但我明白您要表达的意思。”</p><p>“不错。‘无限’就是人类接触的第一个想象力之外的恐怖，无理数、无穷、极限……但是，这种属性并非不可言说，还能通过严格的数学语言定义出来。那只是迷宫的最表层。而真正的不可名状，在我们的语言和文字中，没有它们存在的位置。年轻人，不要随意涉足迷宫的深处，那是比高等数学恐怖亿万倍的无间地狱。”</p><p>“晚辈谨记，不会再去碰数学了。”</p><p>“善。”</p><p>博尔赫斯比杨帝见过的图片里的形象，还要老得多，憔悴得多。</p><p>他说：“我不希望有一天，你会像我一样，觉得眼睛失明、再也看不见那些恐怖，会是一件莫大的好事……”</p><p>道别了老人，杨帝继续做梦。</p><p>某次眨眼间隙，他瞥见宇宙膨胀真相——竟是创世神用银河系当打奶泡器，黑洞咖啡渍洒在时空滤纸边缘。这个世界，是一杯巨大的卡布奇诺～</p><p>某次呼吸空档，他看见冰川纪的猛犸象群正在用象牙撬动地球自转轴，从而导致地球进入温暖期。它们自取灭亡！</p><p>一个杨帝翻开《天狗》高声“我是天狗”！另一个自己翻开《肥企鹅如是说》疾呼“我是企鹅”！他吞了全宇宙，吞了上帝，吞了风雷地火，他在宇宙中狂奔，如烈火一样地燃烧，他在神经上飞跑！他变成企鹅和天狗在脊髓上飞跑！他拥有了全宇宙energy的总量！他补完了完满的自我！他变成骆驼狮子婴儿在脑筋上飞跑！他把日来吞了，月也来吞了！</p><p>杨帝一拍大腿。</p><p>“我逐渐理解一切！”</p><p>“我一定是在做梦。”</p><p>“灵觉归位，神魂速醒，诸般困意，退散无形，急急如律令！”</p><p>还真有用，他醒了。</p><p>有些人在意识到自己在做梦时，就能很快醒来。</p><p>很黑，室内很黑，只有从下铺透上来的蓝白色电脑光线。</p><p>杨帝花了许久时间，才意识到现在是夜晚，他一觉从早上睡到了夜晚。</p><p>「杨帝+535559835」</p>
