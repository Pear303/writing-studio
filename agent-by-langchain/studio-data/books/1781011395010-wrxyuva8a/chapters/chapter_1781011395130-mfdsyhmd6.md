# 大盗

<p>（一哥们因为情感破裂，对老狐诉苦许多。老狐深感「爱情」水深，身为楚楠把握不住，故利用无形的大手撮合二人为CP，以此表现爱的「混沌」属性。）</p><p>（爱是什么？）</p><p>（在此引用ZZY的一句话：一见钟情往往是见色起意，长相厮守都是经济原因。换言之，他根本不相信爱情。）</p><p>（ZZY是谁？他是老狐的中学同学，曾提出“金丝眼镜大猩猩”理论，也就是通过脱掉上衣、戴着金丝眼镜、在球场练出一身腱子肉、徒手进个三分球，以此搏得观众席上的学妹喜欢，然后轻易就能有女朋友了！但他至今没找着女友，并且沉迷LOL。）</p><p>奥拓刚刚年满18岁，他找到了父亲铁匠铺的地契，反手用这个地契破除了卡利斯托巨龙的“绑定诅咒”。</p><p>为了彻底让他父亲解脱，这位传奇矮人带上他爸的绑定诅咒之物，一挺贝斯。</p><p>孤身一人，去往坐拥大量剩余价值的矮人王室所在地——铁熔堡。</p><p>铁熔堡地下三层的密室里，潮湿的石壁上爬满会发光的苔藓。</p><p>奥拓贴着墙角滑行。</p><p>他知道，上方一百步处，矮人王室引以为傲的“原初之眼”魔法监控阵列正在缓缓转动。</p><p>想要阻隔此等强度的信号探测，至少需要三层厚的黑曜石铺设。</p><p>非常巧，在铁熔堡，就有一处这样的地方能够完美阻隔信号探测——</p><p>地基之下。</p><p>为了建造这座超级工业巨城，为了使其能够承载数千万、数百亿吨的工业机器，矮人用黑曜石作为地基。</p><p>他们将开采自岩浆池附近的千吨黑曜石，切割成规则的六棱柱状，以铜汁铁水浇筑连接。</p><p>矮人极其豪横。他们用这些黑曜石砖密密麻麻将整个地基填满，铺设了整整三米厚！</p><p>同时，铁熔堡的矮人工匠也当然知道，地基之下是探测器死角。</p><p>但他们没有修复这“漏洞”。</p><p>因为在最一般、最正常的情况下，这根本算不上是漏洞。</p><p>在这个世界，岩浆被极速冷却之时凝结而成的“黑曜石”，是世上数一数二坚硬的材料。</p><p>即使用攻城武器轰击，黑曜石表面最多只会留下白痕；纵然是巨龙利爪撕扯，也只能在砖面划出浅浅沟壑。</p><p>只有用矮人的高精尖设备，或者传奇法师的高深法术，才能慢慢切割雕琢。</p><p>历史上，黑曜石无法用于防御焚灭天空之龙·卡利斯托，仅仅是因为“原汤化原食”——黑曜石会被10000度的龙炎烧熔。</p><p>但是，正常的人力，很难制造出一万度的火焰。</p><p>有这个本事的法师大能，基本都从铁熔堡正门走进来，并被尊为这座巨型工业城的VIP贵客，犯不着在地基下方偷偷摸摸做烧烤。</p><p>总而言之，言而总之。</p><p>能凭自身力量破开黑曜石地基的，基本都被铁熔堡拉拢收买，不会偷偷摸摸。</p><p>偷偷摸摸者，基本不可能破开三米厚的黑曜石地基。</p><p>“基本”。</p><p>确实，在绝大部分情况下，矮人工匠的估计都没有错误。</p><p>除非在他们看不见的地方，一个名不经传、对附魔理论研究极深的天才，搞出了一把「效率V+耐久III+丝绸之触」的极品狱髓钻头。</p><p>狱髓，又称下界合金。</p><p>这种原本需要字面意义上下地狱才能获取的珍贵合金，出现在了在星渊井口。</p><p>100年前，焚灭天空之龙在星渊井口与人类鏖战，它身上像抖落灰尘一样掉下来的器具，有的被附上了“绑定诅咒+不可破坏”；有的则被龙炎重新烧熔，破除掉诅咒，但也只剩下最原始的“合金锭”形态。</p><p>奥拓他爸，和镇民一同去“摸金”之时，就捡到了一大块“下界合金锭”。</p><p>依靠这块合金，做出狱髓钻头，再用钻头采集足够的黑曜石和钻石，制造出附魔，完成原始资本积累。</p><p>这就是奥拓他爹的创业历程……但富贵险中求，代价是他们家一辈子背负着绑定诅咒。</p><p>洗澡洗着洗着，手中的浴球、搓澡巾就会变成贝斯或木镐。</p><p>当然，现在有可能摆脱这个诅咒。</p><p>用不好听的话来说，就是洗白。</p><p>矮人摇摇头。奥拓！你脑子已经被城里那些学者的知识污染了！不要再学社会科学啦！跟从你内心最深处的想法——事成之后，金盆洗手，不再偷盗，改行去摸金倒斗！</p><p>奥拓看向头顶上方，尖重的黑曜石层。</p><p>这些黑曜石地基，历经三百年岁月，仍坚不可摧。</p><p>三百亿吨重的工业熔炉在地面运转百年，地基始终纹丝不动，连最精密的震颤探测仪都检测不出丝毫位移。</p><p>在铁熔堡的建造史上，唯一能对黑曜石造成损伤的，只有岩浆池中喷涌的，以及巨龙喉中倾泻的超高温烈焰。</p><p>正因如此，这看似存在漏洞的地基，被矮人工匠视作最安全的屏障。</p><p>奥拓摸着这层黑曜石砖。</p><p>石砖之间，他摸到一条缝。缝中不是温润坚硬的黑曜石，而是刺骨冰冷的金属。</p><p>三层黑曜石石砖并非浑然一体，矮人建造时为确保地基稳固，特意在每层之间、每块石砖之间，都预留了一厘米的减震夹层。</p><p>一般人也不可能钻进去这些夹缝，但它们为奥拓钻头提供了一个发力点。</p><p>奥拓将狱髓钻头抵住石缝，淡紫色的合金表面泛起灵光。</p><p>启动！钻头发出蜂鸣，高速旋转的锯齿瞬间切入黑曜石，滚烫的碎屑四溅，空气中弥漫起焦糊味。</p><p>黑曜石和黑曜石砖并非同一样事物，需要四个黑曜石，才能合成这么一块硬度极高的黑曜石砖。</p><p>即使是用钻石镐挖掘，也需要整整5小时才能破坏一块矮人精制的黑曜石砖。</p><p>换算过来，奥拓的钻头则需要1分25秒。</p><p>钻过三层黑曜石后，顺着预先计算好的方位前进。</p><p>凭借绝对的自信，他把在场所有矮人守卫唬过去。</p><p>通过三寸不烂之舌，和突破天际的魅力值，他说服铁熔堡某王室成员本尊，带奥拓去往自己的小金库参观。</p><p>偷取价值足够的财物，强行交易，再将财物原封不动地馈赠回去，最后挖地道，重新从黑曜石地基下离开。</p><p>好像也不算很难吧。</p><p>当奥拓终于从城外一处隐蔽的矿洞钻出地面时，清晨的阳光刺得他睁不开眼。</p><p>这里是铁熔堡外围城区。</p><p>晨光掠过锈迹斑斑的蒸汽管道，丁达尔效应如梦亦如幻。</p><p>奥拓眯起眼，看见孩童追逐着滚动的铁环跑过，赤脚踏过积水，溅起的水花里倒映着修补过无数次的羊毛斗篷。</p><p>背着竹篓的矮人老妪正踮脚采摘藤蔓上的发光蘑菇，独眼矮人铁匠锤打着烧红的铁块，身旁的学徒时不时抬头偷瞄师傅的手法。</p><p>走出巷道尽头，远处传来老式蒸汽机轰鸣，几个推着矿车的矮人擦身而过。他们兴致勃勃争论着哪家酒馆的麦酒最够劲。</p><p>今天似乎还在讨论些别的内容。</p><p>“据说矮人王他表弟的姨姑的女儿的青梅竹马喜欢上了乐器……”</p><p>“你是说，那种一吹就能滴滴答答发出声音的东西？”</p><p>“不是吹的，据说那是用拉的，或者是用指甲去弹的。”</p><p>“我儿子说他早上去偷听那个人弹奏乐器，但什么也没听见。”</p><p>“身为矮人，居然还玩儿音乐这种东西，真是离经叛道。”</p><p>这是铁熔堡最平常的早晨。</p><p>此刻中央广场传来不同寻常的喧闹声。</p><p>奥拓穿过叽叽喳喳讨论的人群，望去。</p><p>只见城头的永夜之瞳投影屏上，赫然是自己的影像——画面里的矮人满脸脓疮，眼瞳泛着凶光，青灰色獠牙刺破唇角，狰狞得如同传说中的恶鬼。</p><p>现在，全城矮人都将记住这个恶名昭著的形象，虽然实质上他并没有偷走任何东西，甚至还给王室送了一把永远不会损坏的优质贝斯。</p><p>而真实的奥拓，已湮灭在谎言中。</p>
