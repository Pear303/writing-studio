# 人生五十月，如梦亦如幻

<p>杨帝被“零点能炸弹”和“大荒囚天鳍”同时击中身体。</p><p>这一记的力量实在太过强大，将他生生打出肋骨轻微骨裂，胸膛淤紫，右侧小腿腿毛被削去10%，显然受了极其严重的伤害！</p><p>而这两招攻击，也将他从睡梦中唤醒。</p><p>杨帝睁眼，外头的世界恍然已过去，嗯，50个月，也就是四年两个月吧。</p><p>人生50月，如梦亦如幻。</p><p>这50个月，杨帝一直在呼呼睡大觉。</p><p>睡觉也是一种修炼——通过做梦。</p><p>梦中修炼，属性点的增加可以反馈到现实，虽然听起来非常心胜于物，但事实就是如此。</p><p>就仿佛……梦境其实也是某种意义上的「现实」。</p><p>他曾经在梦中习得游泳和潜水，并获得一定的紫外线抗性。</p><p>但也仅仅止步于此。</p><p>他没承受过比“紫外线灯”更高的辐射伤害，那么在睡梦中所受到的伤害，也就止步于在医院照射过的那盏紫外线灯了。</p><p>但是在这异世界，获得原初之眼兆亿年的记忆和知识，获得祂的绝大部分“现实”之后，杨帝的梦中修炼能力终于迎来质的提升。</p><p>——他得到大量一手的珍贵做梦素材。</p><p>比如说，他原本对丧尸病毒的印象仅限于寥寥几部电影小说。</p><p>在梦中被丧尸咬后，不会增加相应的「丧尸病毒抗性」。</p><p>他需要实际体验过，经历过，感受过。</p><p>才能利用梦境将一项抗性磨练到登峰造极。</p><p>而现在，接手了这位宇宙观察者的记忆，获得了原本属于祂的现实。</p><p>杨帝的记忆中，多出来大量被斧头、电锯、钻头、穿甲弹、钻地弹、氢弹、宇宙大爆炸……所狂轰滥炸的“亲身经历”。</p><p>他的身体，误以为他经受过这样的伤害。</p><p>于是，杨帝能够在梦中修炼的属性、点数，无论深度还是广度，都疯狂爆涨！</p><p>针对于本宇宙所出现过，任何类型的杀伤，包括但不限于锐器切割、物理钝击、高温灼烧、极寒冻结、生化侵蚀、辐射穿透、细胞崩解、基因链断裂、精神冲击、灵魂震荡、激光贯穿、正反物质湮灭、强弱核力崩解、黑洞潮汐力撕扯、超新星爆发级别的伽马射线暴、熵增加速引发的物质快速衰变、真空衰变引发的宇宙规则重构、个人现实撕裂导致的质壁分离、维度坍缩引发的空间扭曲撕裂、因果律武器造成的既定事实伤害、概率武器引发的随机致命事件……</p><p>本质上就是在「挨打」。</p><p>对杨帝的个人现实（Personal Reality）而言，他都确确实实经历过无数遍。</p><p>进化，适应，增强，直至免疫。</p><p>梦中时间的流速比现实要慢许多，他将现实的1秒掰成20份来用，疯狂挨揍，被各种奇怪杀伤围殴。</p><p>然后，他的身体就以为自己受到损伤。</p><p>心胜于物……各项抗性开始暴涨。</p><p>这就是原初之眼的馈赠——整个宇宙的经验和记忆，就是祂最大的礼物。</p><p>梦中的时间流速和现实又略有不同。</p><p>同时，在杨帝100%意识圆满的情况下，他能够随心所欲操控自己的精神，自定义梦境。</p><p>于是，各项属性点以极高速度暴涨。</p><p>他想起来自己曾做过一个“人物面板”。调出面板，查看：</p><p>【综合力量：3.14E100】</p><p>【综合抗性：2.71E105】</p><p>【现实丰度：6.18E110】</p><p>攻击，防御，蓝条，三位一体。</p><p>以及还有各种技能行为的熟练度，譬如剑术和炒菜，这些技能点数已达到极高境地。</p><p>杨帝能用普通的锅铲，劈开30公里厚的中子星，同时锅铲还能继续用来炒菜；用一根筷子当剑，将红巨星均匀平整地切开，却却不损伤筷子表皮一丝一毫；精准控制腿毛生长并打一个华夏结，又或者是用头发当琴弦弹首《喜欢你》，成为史上最强DJ。</p><p>此刻被攻击唤醒，杨帝没想到，现实宇宙中还有如此烈度的攻击。</p><p>果然宇宙代有人才出，一节更比一节强。</p><p>肋骨骨折的剧痛，在杨帝的抗性面前不过像挠痒痒。</p><p>胸膛的淤紫正以肉眼可见的速度消退，新生的皮肤泛着蓝巨星般的光泽。</p><p>“感谢闹钟服务。”</p><p>杨帝缓缓舒展身体，断裂的肋骨发出玉石相撞般的脆响，瞬间恢复如初。</p><p>摩挲着微微发颤的指尖，那些残留的零点能与荒古法则，在杨帝掌心还有余波回旋。</p><p>无论是被摧毁的时空本身，亦或是蕴含本源法则的攻击，都尚未触及他的抗性极限。</p><p>杨帝眯起眼睛，目光如两道实质化的射线穿透层层空间，锁定了阿巴所在的时空，与另一边庞大的守望者舰队。</p><p>感谢归感谢，他不喜欢“闹钟”也是事实。</p><p>大胆，竟敢吵醒我。</p><p>他掏出一块破碎的镜片，看到自己后脑勺的发型都被吹乱了。</p><p>已有取死之道！</p><p>但杨帝是大善人，所以不会搞“滥杀”这种低劣的、不纯粹的、无道德的、低级趣味的、对世人有害无益的行为。</p><p>打得一拳开，免得百拳来，虽然百拳千拳万拳对杨帝没有伤害，但还是得表个态。</p><p>他握拳，挥出拳罡。</p><p>舰队外围的防护罩竟如同肥皂泡般接连破碎！暴露在外的战舰瞬间被无形力量扭曲，变成抽象的几何雕塑。</p><p>而鲈鱼阿巴也受到了影响，鳞片在无形威压下片片迸裂，原本嚣张的鱼鳍也拧成麻花。</p><p>杨帝：“大伙怎么愣在原地不动啊。”</p><p>真空不能传声，但声音仍然传出了。</p><p>绝对理性一方的守望者舰队，狂热追求大罗道果的阿巴，此刻却挪动不了半步。</p><p>在他们的探测传感器、灵魂感知视角之中。</p><p>杨帝身体涌动的能量指数，虽仍然没有触及无限……</p><p>却远远突破可观测宇宙总和。</p><p>一个超出探测器上限的超大数值……</p><p>可观测宇宙本身并不是无限大。</p><p>由于宇宙的年龄和光速的限制，文明、强者都只能看到一定距离内的天体和现象。</p><p>理论上来说，光锥之内，皆为命运。</p><p>但在FTL超光速技术、太乙仙术的加持下，鱼尊阿巴和守望者文明都能超越光锥，看到可观测宇宙以外的情景。</p><p>即使如此……可观测宇宙的质能总和，仍然是一个海量庞大的令人绝望的规模。</p><p>这种规模的能量，统统凝聚在这一尊个体身上。</p><p>他到底是吃什么长大的——所有人、所有鱼心里都发出这个疑问。</p><p>杨帝踏破真空，一步一道空间裂缝，向鱼尊走去。</p><p>“那边的朋友，你是条鱼吗？哦，我刚刚好像见过你一面，那时候你才面包车大小呢，还和屠龙者、人鱼公主一块生活。”</p><p>“……不要小瞧我啊！我修炼到今天的境地，就是为了不再活在你的阴影之下！”</p><p>鱼尊惧极反怒，决心直面恐惧，斩杀心魔！</p><p>她周身凝聚高能，大荒囚天鳍第九式·万蝠朝宗，向杨帝冲杀而去！</p>
