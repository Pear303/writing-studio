# 老干部的教诲

<p>杨帝刚落座，一直在尝试接收WiFi但信号格始终在挣扎的外卖员，和用大尾巴缠着他脖子的狐娘，几乎是同时抬起头，有气无力地晃了晃手和尾巴尖。</p><p>二人声音带着某种默契但缺乏激情的慵懒：“欢迎欢迎欢迎……”</p><p>仿佛在念一段被强制要求执行的欢迎代码。</p><p>带着一种微死感。这种感觉，杨帝在打工人身上频繁见到。</p><p>远处，那处于生与死叠加态的三个实体，只是同步地、幅度极小地微微颔首，量子隧穿般的嗡鸣短暂地变得有规律了一些。</p><p>算是点头致意？</p><p>然而，那片无法被描述形态的混沌存在，其内部扭曲的光线骤然凝固，某种冰冷的“注视”锁定了杨帝。</p><p>一个直接在认知层面响起，混合了无数矛盾频率的意念砸了过来：</p><p>“小同志瞅着有点眼生啊，不是咱这旮旯‘原生户口’的吧？你身上有‘耶罗’的味道。”</p><p>这意念带着毫不掩饰的排斥与质疑，仿佛杨帝的存在本身污染了这里洁净的空气，就差指着他鼻子骂“乡毋宁”了。</p><p>没等杨帝回应，那银白色的无限机兵人形向前半步：</p><p>“实体‘杨帝’适用《星环盟约特殊人才引进与破格准入条例》第条款：具有显著超越性潜质或当前即具备虚空圣人级灵能、且其原生环境已被证实为下层叙事域，可豁免常规出身审查，经至少一名现任‘圣人’级成员推荐并经由盟约人事中心快速通道核准后，予以临时接入权限。”</p><p>它顿了顿，补充道：“推荐人：耶罗。核准机构：星环人事中心。流程完备。”</p><p>流程完备，程序正义！</p><p>我都走流程了，你还能说什么！</p><p>那团混沌剧烈波动了一下，发出一连串仿佛急刹车的刺耳杂音：“那不还是耶罗的人？！”</p><p>但也不说话了。</p><p>名为“寂无终焉形藏”的家伙，似乎对耶罗大仙有很大意见，在这一点上，杨帝倒是能和对方达成一致。求同存异嘛。</p><p>但对方有些过于出身决定论了。不想理他。</p><p>杨帝屁股还没坐热，会议厅后方一扇几乎与背景融为一体的“门”无声滑开。</p><p>一个身影走了进来。</p><p>他径直走向杨帝所在的角落区域。杨帝旁边恰好还有一个空位。</p><p>这位中年道人走到空位旁，没有立刻坐下，而是先对会议厅里几位投来目光的圣人微微颔首致意，然后才落座。</p><p>坐下后，他似乎才注意到身旁的杨帝，侧过头，脸上露出温和的笑意。像个即将退休的老干部。</p><p>“抱歉，刚去处理了点‘超大当量民事纠纷’，耽误了点时间。这儿没人坐？”</p><p>杨帝像一个被即将退休的老干部问候的年轻实习生。</p><p>“我认识你吗？”他说话没有那么谦逊。</p><p>“现在就认识了嘛。我是洞虚破妄天尊。在外要称职务，可以简称为洞天尊。”</p><p>“洞……洞天尊？”</p><p>“你就是小杨吧，听说你是从耶罗分形区出来的，虽然本身很想打倒耶罗，但同时也被它当做武器来对付我们星环盟约。年轻人，有锐气，好！非常好！</p><p>“想当年我刚入职星环那会儿，也是天不怕地不怕，看什么都想捅一捅，那股子劲头，跟你很像嘛。</p><p>“不过啊，小杨，咱这地方，不比下面那些小世界、小宇宙。这里头的水深得很呐。规矩也多，程序也复杂。</p><p>“你看，就像刚才，寂无终焉形藏——哦，就是身形不定的那位——他问你‘户口’的事儿，那是在点你。</p><p>“虽然星环的同志给你走了流程，备案了，但这‘临时参会’的身份，它不稳当。你得知道，咱这‘虚空治安联防大会’，规格高，责任重。</p><p>“参会的同志，那都是经过层层筛选、政治过硬、业务精通的骨干力量。</p><p>“出身清白，成分正常，还是比较重要的，这不是迂腐，而是必要。</p><p>“不然的话，万一混进来个背景复杂的，关键时刻掉链子不说，要是被别有用心的势力策反了，多少同志的心血都可能白费。</p><p>“所以要成为星环盟约的骨干，第一步就是给自己拴上链子，不得乱动。”</p><p>杨帝眉头微蹙，刚想说什么。</p><p>洞天尊没看见，自顾自地继续唠叨。</p><p>“‘寂无’那人，资历深，背景硬，虽然看起来像个退休钓鱼的，但说话很有分量。</p><p>“他那一嗓子，其实就是提醒在座的各位，你是‘外来户’，根基浅。</p><p>“特别是出身自耶罗分形区，在某些老同志眼里，那就是思想觉悟可能还不到位，需要进一步考察，这涉及到组织信任问题，马虎不得！</p><p>“所以啊，小杨，你坐在这里，姿态要放低！多看多听少说！</p><p>“你现在是临时参会，大家心里难免对你还有些观望，这都正常。</p><p>“等你以后真正站稳了脚跟，用行动证明自己的立场，让大家看到你的根是正的，那情况自然就不一样了。</p><p>“听耶罗说你还提出了‘灭圣绝盗’的口号……口号嘛，喊喊可以，表明立场嘛。但具体工作，要讲究方式方法。</p><p>“不能搞一刀切，不能搞无差别打击。你知道咱们星环盟约的‘盟约’是什么？</p><p>“哦，你刚来，还不知道，不过你终会知道的。”</p><p>杨帝被洞天尊的入职辅导念得有些头疼。</p><p>不是很想听这些老前辈官场经验。</p><p>“寂无”其实并不是故意针对杨帝，而是他见过太多因为出身问题出纰漏的事，深知成分审查的重要性。</p><p>会议厅中央一块原本毫不起眼，杨帝原以为是井盖的圆形区域突然滑开。</p><p>一个身披银袍，看起来年纪不大的少女，利索地从底下爬了出来。</p><p>杨帝始终是那个基准态的杨帝心智，秉持朴素的地球人类思维，根据“相由心生”，首先假定对方是个阴性智慧生物，用“她”加以指导。</p><p>她拍了拍身上根本不存在的灰尘，径直走向前台，动作熟练地将那个像U盘的仪器插进像电脑的设备。</p><p>敲了几下，一阵刺耳的电流麦克风啸叫声顿时响彻大厅。</p><p>“咳咳！试麦试麦！”</p><p>她清了清嗓子，声音透过劣质扩音设备带着点杂音，但异常清晰，“各位盟主、特派员、代表以及……临时列席的杨帝同志。”</p><p>她环视下方，目光扫过打哈欠的外卖员次元旅者，闭目养神的退休大爷，扭曲的混沌，以及三人合一的家伙。</p><p>“我是本次会议召集人，逸曜星尊。感谢各位在百忙之中——特别是洞天尊刚处理完‘超大当量民事纠纷’就赶回来——抽空出席本次‘虚空治安联防大会’。”</p><p>逸曜星尊表情严肃起来：“议题只有一个：应对日益严峻的‘大魙败’扩散趋势。根据不可知论办公室的最新模型推演，侵蚀速度比上次预估快了百分之零点零零零……（她报出一长串令人头晕的数字）个标准宇宙秒，形势不容乐观。”</p><p>杨帝趁她念数据时，微微侧头向旁边的银白色机兵人形低声问：“六大盟主？”</p><p>盟主，听起来是个很大的官位。</p><p>一下子升官了，就，挺突然的。</p>
