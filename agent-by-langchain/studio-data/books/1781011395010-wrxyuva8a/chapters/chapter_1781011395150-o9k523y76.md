# 猜测

<p>比如，酒楼厨子·中山无极是修为最高的头头，王队王将对将，他将全部注意力都集中在杨帝身上。</p><p>四人团伙中，第二睿智的图书馆保安·天机子则负责监听正在侃侃而谈的青丘白璃。</p><p>青丘白璃仍然在忠诚地当个导游。</p><p>她侃侃而谈，讲述归墟大帝和这条铁路的故事。</p><p>“等到槐安1453年，‘君士叹顶’的隧道终于打通，那一刻，整个凡界都沸腾了！”</p><p>“哇偶，那么他们修建这条铁道，到底是为了什么呢？”</p><p>“凡人王朝贫困群体的最后壁垒，就藏在这十万大山最深处，是一个超封闭国度——共500万人口，不可能全部迁出，只能滞留。所以只要能把这个区域与外界连接起来，就能给那里的人们带来希望。”</p><p>500万人，藏在10万座5300米高的山峰、上百条巨型山脉包围的山沟沟中央最深处，那片占地数十万平方公里的盆地，就是他们祖辈生活的世界。</p><p>“凡人王朝走向团结一统，迈入工业革命大后期之时，却惊奇地发现，里边还有一个500万人口的封建部落，就像……旧时代遗落在大山中的一场梦。”青丘白璃感慨。</p><p>狐狸已经介绍了很多本地历史。</p><p>作为回复，杨帝也决定不当谜语人。</p><p>但今日之我向昨日之我开战，现在的他否定了之前自己作出的猜测。</p><p>“我原本觉得，归墟大帝可能是活腻了。不过，眼下我不认这个结论了。”</p><p>青丘白璃并没有发笑。</p><p>在一阵思考后，她一板一眼地反驳道：“确实，此猜测太过荒诞离谱。大帝身处世间顶端，坐拥无尽寿元与至高权力，世间万物皆已见识，岂会只因活腻就轻易赴死？”</p><p>杨帝点头称是：“我起初觉得归墟大帝在悠悠漫长岁月里，被困在了‘永恒’的囚牢之中。恰似那见过汪洋大海的牛蛙，却只能被困于井底仰望同一片天空……”</p><p>大帝纵览星河长达万载，即便奇观再绚烂，久而久之也会沦为不断重复的幻影。</p><p>杨帝本以为，归墟大帝是活腻了。</p><p>但现在看来，并不是。</p><p>说着，杨帝低下头，隔空张嘴将面汤一饮而尽。</p><p>他续道：“他不会自杀，他的心态比克拉克·肯特还健康。”</p><p>“请问……那克什么特是谁？”</p><p>“并不重要，只是个心态超棒的超人。”</p><p>到了这里，线索又好像中断了。</p><p>永远不要低估异世界土著的智力。</p><p>不畏上天入地的大能，已经将能调查的都调查过一遍。</p><p>归墟大帝最近数月的行程，他的性格，一切兴趣和癖好，都被彻查得清清楚楚。</p><p>包括书房里的日历扉页用写着“喝水就能变强系统”，万仙会上突然问“火锅蘸麻酱还是香油？”导致满场仙君没敢接话的会议记录……</p><p>这些陈芝麻烂谷子都被翻出来了。</p><p>五位土著大能大脑串联，加班连轴转，试图从这些大帝的日常小事，反映出他出事前的心境变化。</p><p>他们已经做过很细致的心理学分析、人格画像描绘。</p><p>得出的结论是，归墟大帝心态正常，甚至比绝大部分凡人、仙人都要健康。</p><p>出事前，也没有行事异常。</p><p>“大帝自杀”这么方向的猜测可以结束了。</p><p>杨帝撕开第二杯泡面的塑料膜，寻思着：“总之各种证据都在说明，大帝并非自杀，也没有提前知道自己将死。他直到死前三个月，言行神态仍然没有出一丝一毫异常。”</p><p>大帝绝不可能在这长达三个月，共计129600分钟的时间里，始终如一地维持着奥斯卡小金人级别的巅峰演技。</p><p>哪怕退一万步讲，就算他事先知晓自己命不久矣。</p><p>可依照归墟大帝这一生的行事风格，从其人格画像来看，他是那种始终将强者责任扛在肩头、对天下世人关怀备至的大帝啊。</p><p>如此人物，为何在明了自己大限将至之时，却丝毫不为后事做任何安排？</p><p>中山无极等人呈上的调查资料，将种种细节都呈现得明明白白。</p><p>无论杨帝所能想到的，还是他想象不到的方面，他们皆已周全地考虑过一遍。</p><p>直到现在，他提出的几个猜测都仍然只是“重复发明轮子”，并没有更多新进展。</p><p>杨帝叹气看向窗外，拆开新一桶泡面盖。没有思路时，他喜欢通过看风景和冲泡面转移注意力，寻找灵感。</p><p>他刚把开水倒到泡面，突然想到什么。</p><p>刚才撕泡面盖时，粘在手上的塑料膜。</p><p>杨帝神识散开，迅速刺向凡人王朝的工业基地，尤其是化工原料中心。</p><p>是的，这个世界同样有这种事物，石油。</p><p>他们要是有石油开采井，有加工原油的化工厂，有利用石油衍生物制造物品的流水线。</p><p>裂解塔将原油裂解成小分子，聚合釜里翻滚着浆液。“浆液”被传送带送往模具车间，压铸成还有仿玉质感的梳子、菜刀刀柄、以及泡面盖子的塑料膜。</p><p>完整的石油化工生产线。</p><p>石油，工业的血液。</p><p>那些埋在地下亿万年的古生物残骸，经过高温高压“焖煮”千万年，烂成了粘稠的黑浆。</p><p>凡人把它开采出来，诸多妙用。</p><p>就连灵界也喜欢派人下凡，采购塑料杯和塑料椅。</p><p>杨帝将第一碗泡过面饼的热水倒掉，将各种调味料加入泡面杯中，倒入开水。</p><p>嘴上漫不经心地问道：“凡界江山，如此多娇，无数英雄折腰。话说这凡人王朝能够延续至今，繁荣一统，定是代代皆有人才出，只是不知，凡界的文明已发展了多少年？”</p><p>青丘白璃：“嗯……如果从凡人学会用打火石点燃第一把火开始算，大概五十万年多点。”</p><p>这是段很长的历史，一段足够富裕的时间。地球上的智人也才仅仅发展十几万年，就能进化出“文明”，相比之下，凡界的人还是有点慢。</p><p>“他们发展出工业至今，多少年了？”</p><p>“大概八百多年。白杨大帝，有何发现？”青丘白璃有些期待地看着他。</p><p>杨帝提出问题：“八百年！凡界的石油……挖不完？”</p><p>他粗略地扫视了一眼地下石油存储。</p><p>较深地层的石油，呈现出更为浓稠的质地，色泽也愈发黝黑。</p><p>与之相比，较浅地层的石油相对稀淡一些，颜色也稍浅，仿佛还未完全褪去青涩。</p><p>从深到浅的状态变化，清晰表明这个世界的石油同样是由古生物残骸，在漫长的时光历经高温高压作用，逐渐演变而来的。</p><p>和地球上的石油形成过程一样。</p><p>凡界工业史八百年，石油作为不可再生资源，按常理早该触及储量红线。</p><p>可凡界至今能维持完整的化工生产线，甚至灵界都在统销采购塑料制品，这似乎不太地球的常识。</p><p>杨帝目光再度扫视整个凡人王朝。</p><p>此界的石油，确实是从地下开采的，但是为什么……</p><p>守望者·59改像日常边缘小透明突然说话：</p><p>「此界地脉灵能流持续活化古生物沉积层，石油生成周期被压缩至万年量级，属于灵能物理法则耦合后的‘半可再生’资源。」</p><p>「目前已探明储量可支撑工业体系运转至少5000年，灵界的塑料制品采购链稳定。」</p><p>原来世界物理法则和地球不太一样，石油储量远大于地球。</p><p>59改说完，用询问的眼光看向杨帝。</p><p>“谢谢你的情报，很有价值，我亲爱的守望者·59改·大科学家同志。”</p>
