# 一巴掌戮仙

<p>“达文西已死，从此他在此世的命运再无延续。这是他的既定命运，而更上层的圣人只是对其略作勾勒，我无法改变其灭亡的终局，你要承担他的一切，替他继续活下去。”</p><p>了却这桩因果，心中再无挂碍。</p><p>属于“杨帝”的灵压，如同挣脱了最后一道枷锁，骤然拔升。</p><p>嗡——！</p><p>凝练如实质，色泽混沌难辨的灵能光柱，瞬间洞穿稷海市上空的云层。</p><p>以超越光的速度，悍然刺向冰冷深邃的宇宙真空。</p><p>这道光柱，是力量本质的宣告，是“无穷”之上的“无穷”在此世坐标的锚定。</p><p>其蕴含的超越此界常理的灵能，如同在寂静的宇宙池塘中投入了一颗超新星，涟漪以超越因果的速度扩散开去。</p><p>深空，某处。</p><p>一座由仙玉构筑、瑞气千条、霞光万道的巨大仙宫正悬浮于小行星带之间。</p><p>仙宫深处，一位身着星纹道袍、面容俊美却带着刻骨冷漠的太乙真仙——玄穹子——猛地从云床蒲团上睁开了双眼！</p><p>他眼中星河流转，瞬间穿透无尽空间，锁定了地球方向那道转瞬即逝、却烙印在时空背景上的冲天灵能！</p><p>“嘶——！”</p><p>玄穹子倒吸一口冷气，随即被难以言喻的狂喜淹没。</p><p>“如此纯粹！如此超然！这……这是新出世的先天至宝？！不，这气息更像是……人形道果？天助我也！此等无上机缘，合该为本座所得！”</p><p>他完全忽略了那印记源头所在的行星上可能存在的任何生灵。</p><p>蝼蚁而已，何须在意？</p><p>在他漫长的仙途中，因争夺机缘而随手抹去的星辰、湮灭的文明早已不计其数。</p><p>弱者，没有存在的意义，更没有被他感知的资格。</p><p>只有足够有潜力的宝物或人出世，才能勾动他的心思。</p><p>“拿来吧！”</p><p>玄穹子长啸一声，声震寰宇。</p><p>他一步踏出仙宫，身形瞬间化作一道撕裂虚空的璀璨仙虹！目标直指地球！</p><p>速度之快，沿途的恒星系被仙光余波扫过，无声无息化为宇宙尘埃。</p><p>仙虹所过之处，时空薄膜如被烧红的琉璃般剧烈褶皱，一道深黑色的轨迹赫然烙印在宇宙画布上——那轨迹并非直线，而是以一种超越三维几何认知的弧度疯狂弯折，曲率趋近于无穷大，仿佛将整片星域都当作了衬托其速度的背景板。</p><p>轨迹边缘的时空涟漪层层叠叠，连穿梭的宇宙射线、群星光芒都被强行拽入这道“沟壑”，化作缠绕其上的金色光丝。</p><p>周围的星光彻底失了原本的轨迹，像被无形巨手攥住的绸缎般疯狂扭曲</p><p>玄穹子踏在仙虹顶端，星纹道袍猎猎作响，却连一丝宇宙尘埃都沾不上身。</p><p>他眼中只有那“至宝”，贪婪与志在必得的冷酷交织。</p><p>“不过瞬息路程，此宝已是囊中之物。”玄穹子眼中星河翻涌，嘴角勾起冷冽的弧度。</p><p>太乙真仙的仙虹本就以撕裂因果的速度横亘宇宙，前方那颗中子星骤然闯入视野。</p><p>那是颗直径仅二十公里的坍缩恒星残骸，表面引力达地球百亿倍，磁场强度万亿高斯。</p><p>在他反应过来前，便已击穿了中子星。</p><p>星体表面的“中子海洋”被仙力撕裂，强核力竟被撑开数十公里通道，内壁中子骤变为质子与电子，中微子撞击物质激发出贯穿星体的伽马射线暴，撞击处炸出弥散的中子云，逐步生成氢、氦轻元素，伴随时长十秒的超强中微子暴。</p><p>在久远到无法估量的未来，或许这团氢氦元素重新凝聚成恒星，甚至诞生生命和文明。</p><p>但在肉眼可见的将来，一个婴幼儿文明将会被毁灭。</p><p>19.6光年外，一个平平无奇的恒星系中，行星地表，“星芽文明”的发射场里第一枚火箭刚突破卡门线，尾焰还在大气层中残留白色轨迹。</p><p>控制室里，三十个裹着纤维制服的星芽人正欢呼。</p><p>他们用五百年从部落时代走到航天时代，这枚搭载卫星探测器的火箭，是他们触摸星空的第一步。</p><p>众人激动地看向天穹，他们知道火箭的尾焰会焚尽一切阴霾。</p><p>如若此后百年千年，我们或将漫步于群星之侧……</p><p>但世人不会知道，仙力激荡下崩溅的中子星碎片，正以相对论射向19.6光年外他们刚点燃火箭的恒星系。</p><p>星芽文明对此一无所知。</p><p>他们的望远镜仍追逐着火箭的尾焰，欢呼声在控制室里回荡如潮。</p><p>他们将在19.6年后目睹那颗中子星死亡的绚烂光芒——而那时，致命的碎片距他们的恒星将只剩3个月航程。</p><p>碎片将会撞入恒星内核，引发史无前例的氦闪，恒星表面将会喷发出直径百万公里的超级耀斑，日冕物质抛射带着亿度等离子体流，以每秒五千公里的速度扑向行星。</p><p>超新星的光芒是讣告，也是倒计时的钟声，死亡与信息将会几乎同时抵达。这就是光锥之内的命运。</p><p>宇宙从未在意。太乙真仙从未在意。</p><p>地球近地轨道。</p><p>杨帝的身影无声无息地出现在这里，脚下是蔚蓝的星球弧线。</p><p>宇宙的冰冷真空对他毫无影响。</p><p>他刚刚“看”到那股贪婪的意念锁定自己，也“看”到了那道撕裂星空、视众生如草芥的仙虹。</p><p>他先前向天穹射出的灵能洪流，其实是一封信。</p><p>一封对耶罗大仙的邀请函。</p><p>以及对诸天仙神的警告函。</p><p>没想到有个小脑萎缩到1000,0000,0000字内容都读不进去的太乙真仙，接收到他的灵能洪流之后，还往这边冲来。</p><p>“聒噪。”杨帝面无表情，甚至连眼神都懒得波动一下。</p><p>就在那横跨星河的仙虹即将冲入大气层，玄穹子那俊美而贪婪的面容已在仙光中清晰可见的刹那——</p><p>杨帝意念微动。</p><p>覆盖在他小腿上的一根最普通的腿毛，轻轻一抖。</p><p>咔嚓——噗嗤——</p><p>无法形容的恐怖动能瞬间爆发。</p><p>那根看似微不足道的毛发，在阿列夫零级力量加持下推动了时空本身，产生的反作用力达到了一个匪夷所思的层级！</p><p>在完全不违反相对论的情况下，超越光速！</p><p>杨帝的身影在原地消失。</p><p>他身后拉出一道将空间本身都犁开的、炽白扭曲的虚无轨迹，如同宇宙巨神投出的标枪，迎着那道俯冲的仙虹，正面怼了上去！</p><p>太快了。</p><p>快到玄穹子脸上的贪婪，甚至还没来得及转化为惊愕。</p><p>快到他的仙识刚刚捕捉到杨帝的存在，毁灭就已经降临！</p><p>也没有绚烂的法术对轰，没有影迷们想要的宏大声光效果。</p><p>只有一次最原始最野蛮的“物理接触”——这也是真正的强者，在战斗时的真实情况，因为强者战斗，不会让多余的能量以声光形式逸散。</p><p>杨帝那因高速摩擦而覆盖着一层白炽夸克胶子等离子体的拳头，或者说，他整个人化作的这道“人形标枪”，在千亿分之一纳秒内，精准无比地印在了玄穹子那张俊美仙颜正中央。</p><p>噗。</p><p>如同熟透西瓜破裂的声响，在真空中诡异地传递开来——空间本身的震动。</p><p>玄穹子那蕴含磅礴仙元、足以硬抗星辰撞击的仙躯，连同他周身护体的万丈仙光、祭炼万年的护身仙宝，连珠炮似的炸裂开来。</p><p>人头落地。</p><p>但这仅仅是开始。</p><p>杨帝的攻击，蕴含着“维持基准态不变”这一核心能力的终极体现——绝对唯一性！</p><p>玄穹子身为太乙真仙，必然拥有无数分身、化身、元神寄托于不同时空、不同维度、不同世界线。</p><p>这是真仙大能赖以不死不灭、纵横宇宙的依仗。</p><p>然而，在杨帝这一拳之下——</p><p>咔嚓！咔嚓！咔嚓！咔嚓！咔嚓！……</p><p>无数个重叠的、来自不同时间线、不同平行宇宙、不同高维层面的破碎声，如同连锁崩塌的多米诺骨牌，在超越时空的层面同时响起。</p><p>所有玄穹子存在的痕迹，所有他寄托元神的锚点，所有他可能复活的“备份”和“可能性”……</p><p>在同一时刻，被一股凌驾于“无穷”之上的力量，强行锁定。</p><p>然后，所有世界线上的玄穹子，世界线上每一个时间段的他，都同时被切爆头颅。</p><p>一死永死，再无过去，再无未来，再无任何复生的可能。</p><p>杨帝看着自己掌心，捏了捏拳头。</p><p>再看向眼前的空间，时空本身被他切出了一条裂缝，裂缝很快在无穷灵能作用下愈合为一个外挂的“小宇宙”，或者称“小洞天”。</p><p>那失去了头颅、正在惯性作用下继续前冲的无头仙躯，以及那尚未完全消散的仙光，掉进了小洞天内。</p><p>于是，那被玄穹子仙虹轨迹撕裂的时空褶皱悄然平复，中子星未曾被击穿，自然也无碎片迸溅。</p><p>因为他存续过的证明，皆如写在沙上的字迹被潮水抹平，了无痕迹。</p><p>故中子星被引爆的19.6光年外，星芽文明的火箭仍在既定轨道上航行。他们的学者将在未来观测到一颗普普通通的野生中子星，而非一场突如其来的毁灭。</p><p>所有被仙力余波碾碎的星尘、扭曲的光轨，都回归了原本的运行轨迹。</p><p>他的身躯连同其存在的一切因果痕迹，正被从所有时间线与可能性中彻底擦除，只留下那掉入小洞天的头颅。</p><p>对于这浩瀚宇宙而言，玄穹子此人，从未在过去显现，未在现在驻足，亦不会在未来留下任何涟漪。</p><p>万物回归其固有的轨迹。</p><p>如果太乙真仙玄穹子生命力足够顽强，遭到此抹杀仍然生存下来，那么他将与早年的杨帝那般，被世人所遗忘，存在过的一切尽遭抹除。</p><p>陆渊这一击精准斩杀一只“太乙真仙”，还让对方的尸首，依照惯性自己跳进埋尸坑里。</p><p>一套丝滑连招，凡人是看不明白的。但引起的动静，已经让诸天魔神、仙圣，跨越光年与兆载，朝着地球这颗小小的泥丸看过来。</p><p>仿佛有无数双眼睛，在同一瞬间睁开。</p><p>他们藏在某个超新星爆发的光焰里，嵌在暗物质构成的星云褶皱中，悬于时间长河的支流分叉处，倒映在某个凡人梦中转瞬即逝的惊悸里。</p><p>——同时向太乙真仙玄穹子形神俱灭的地方，投射来目光。</p><p>地球上80亿凡人，没来由的感觉到心悸。</p><p>他们看不清那威压的源头，只是蓦然觉得，自己被整个世界所注视。</p><p>无数双俯瞰过亿万年生灭、见证过无数文明兴衰的眼睛，第一次将目光聚焦在这颗“不起眼”的星球上。</p><p>杨帝感知到了他们的视线。</p><p>这个宇宙，拥有无穷的空间与无穷的时间，无穷的世界线与无穷的可能性，无穷的微观与无穷的宏观。</p><p>无穷的时空里，无穷的强者盯着他。</p><p>那些跨越无尽维度的目光，最初的确带着一丝被冒犯的轻蔑与不悦。</p><p>一个刚刚散发出如此惊人灵能波动，却又如此“不懂规矩”的新面孔，竟敢以如此蛮横的方式抹杀一位太乙真仙。</p><p>甚至不屑于掩饰过程，这在他们看来是近乎野蛮的傲慢。</p><p>然而，那轻蔑如同投入深潭的石子，未能激起更多涟漪便迅速沉底。</p><p>因为当他们试图回溯这个名为“陆渊”或“杨帝”存在的根脚时，却发现了一片绝对的“无”。</p><p>过去的时间长河中寻不到他诞生的涟漪，未来的无数可能性里也看不见他命运的支流。</p><p>甚至连当前时空的因果线上，他也像是一个被硬生生嵌入的、与周遭一切毫无关联的绝对孤立点。</p><p>震惊之下，他们试图丈量其力量，却窥见更心悸的景象：</p><p>那灵能本质凌驾于“无穷”之上，绝非法力、仙元等已知形态，深到无法理解、度量，甚至无法久视——如同用标尺测深渊，反被深渊吞噬。</p><p>这份深不可测，让诸天强者们陷入集体沉默与前所未有的凝重。</p><p>诸天目光深处泛起密集波动，维度间隙与法则弦线间，流转着非声音的震荡，满是惊疑。</p><p>“太初……难道是‘那位圣人’的痕迹？”</p><p>“不可能！‘祂’早归寂道解，概念都已模糊……”</p><p>“可这般凭空出现、无法测度，除了超脱一切框架的‘祂’，谁能做到？”</p><p>“若与‘那位圣人’同源或继承遗泽……”</p><p>“唯有寻回‘祂’散落的权柄，唤醒根源印记，或许能制约此僚。”</p><p>“但‘那位圣人’之踪迹，比宇宙生灭更渺茫……”</p><p>低语落，无数目光重聚杨帝，先前的不屑与审视尽消，只剩难以置信的震惊、源自古老记忆的敬畏，以及绝境中探寻一线生机的绝望。</p>
