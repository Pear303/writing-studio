# 野史 原目 教廷

<p>瑞弗维尔三人在伊芙允许下，终于能走上前来，与巴德近距离对话。</p><p>巴德是上个世纪的老人。虽然在精灵眼里看来，一百年也就做半个学术课题消耗的时间，但对人类而言，这已是一段漫长的岁月。</p><p>他谈吐略带风趣，语调平和。</p><p>即便天空中黑云压境，骑士仍有种不紧不慢的沉稳。</p><p>瑞弗维尔：“请问……能完整讲讲原初之眼的历史么？”</p><p>杨帝，伊芙，奥拓，三个名字都是双音节的人，就坐在一旁旁听了。</p><p>圣骑士讲起了他所知的历史：</p><p>原目，原始之目，原初之眼，是宇宙诞生的第一道闪耀，是混沌中初次睁开的“眼”。</p><p>它并非以实体形态显现，它其实只是一条自然规律，象征“观察”。</p><p>只是有一天，这条“自然规律”突然有了自己的意志。</p><p>「诶，我有个点子……」</p><p>有了主观能动性，有了目的和想法，有了渴望与梦想，有了爱与恨。</p><p>“将小球抛到空中，它会掉回大地，这就是铁律。但如果有一天，铁律不再是‘铁律’，小球不落回大地，而是选择自己飞去想要的地方，整个世界都会毁掉。”</p><p>看似只是“东西不再往下掉”，自然规律发生了浅浅的变化。</p><p>但细思极恐！</p><p>比如，房屋之所以能稳稳矗立，是因为重力法则是坚定的奴隶主，让每一块牛马砖石都老老实实待在原位。</p><p>当重力有了自己的“好点子”。</p><p>房屋中原本依靠重力才能稳定放置的石块、木材，会突然不受重力控制，四处乱飞。</p><p>人类，矮人，精灵过往所依靠的一切，都将毁于一旦。</p><p>“所以，原初之眼有了自己的‘主观意识’，这就是古人一定要消灭祂的原因？原来如此，感谢解答疑惑。”</p><p>瑞弗维尔笔下生风，在本子上刷刷记录。</p><p>巴德瞥了一眼书封皮，“大陆英雄野史录”。</p><p>嗯，有些后悔接受瑞弗维尔采访了。</p><p>“巴德先生，您为什么没死……呃，我是说，您是怎么在百年前屠龙之战后幸存了下来？”</p><p>圣骑士现在很难说还活着。</p><p>他只剩一副飘浮空中的盔甲，破碎的披风，护臂和手套，腰间尚未生锈的宝剑。</p><p>不过以普遍理性而论，他只是形式上死了，实质应该还是活着的，毕竟还能说话思考嘛。</p><p>巴德人性化地挠挠头，虽然他已经没有脸，没有手，也没有头，了。</p><p>他咔咔咔地说话，声音从盔甲缝隙间传出：“当年屠龙之战，那是一场惨烈至极的恶斗。巨龙的火焰能熔毁山川，吐息所至万物皆灭。”</p><p>顿了顿，盔甲内似有一声叹息，“战斗到最后，我已身负重伤，几乎没了生息。等我再度恢复意识，便发现自己以这般形态留存于世。”</p><p>巴德缓缓飘浮着，望向远处被黑云笼罩的山峦，“也正因如此，我才能驻守此地，察觉到教廷见不得光的勾当。”</p><p>他自己也说不清为啥活着。</p><p>瑞弗维尔便在本子上写下几段字：</p><p>「民间有传说认为，巴德先生崇尚“钢背兽主义”，也就是遇见打不过的敌人，就以必生的决心地逃跑。敌人根本追不上，只能望见其钢铁般的后背，归来倚杖自叹息。」</p><p>「但在我与他的交谈中，我愈发了解到，巴德先生并非有谋无勇之辈，相反，他有勇，可能也有谋……」</p><p>「面对『焚灭天空之龙·卡利斯托』，巴德先生仍然没有选择做钢背兽，而是正面迎战，并成功击杀巨龙……」</p><p>「但在弑龙的细节方面，巴德先生始终避而不谈……我有理由猜测，他是通过如下方式杀死卡利斯托：」</p><p>「首先，趁着巨龙在星渊井口附近的浅海泡澡时……」</p><p>圣骑士沉默地看着瑞弗维尔在本子上写下的内容。</p><p>这注定是一场漫长痛苦，对自己毫无意义，嘚用没有的采访。</p><p>瑞弗维尔的记录似乎暂时结束。他抬起头，目光炯炯：“巴德先生，请问您在讨伐北极领主的时候，是否真的用了20倍致死量的巴豆，智取大魔王？”</p><p>……</p><p>“目前已知，圣光教廷已经成为原初之眼的走狗，拥趸，狂热粉丝，乌龟王八蛋。”</p><p>伊芙目光放在瑞弗维尔和巴德身上，一边对杨帝说道，“杨帝，你怎么看？”</p><p>“嗯……我可以答我托腮看吗……”</p><p>“给我个正经的回答，我想听听意见。”</p><p>杨帝沉思片刻，说道：“他们想召唤原初之眼。”</p><p>“何以见得呢？”</p><p>“直觉，只是直觉。我曾见过一个狂信徒，他狂热地想要召唤某物到这世间。结果，他被自己所信仰之物一脑瓜崩给弹死。但他就连死都觉得，把命交给祂是值得的。”</p><p>伊芙·柑橘微笑：“这么说，你‘恢复记忆’了？”</p><p>“……”杨帝无言可论。疏忽大意，荆州丢了！</p><p>伊芙似笑非笑地看着杨帝，那眼神仿佛能洞悉他内心所有的秘密。</p><p>杨帝当机立断转移话题：“咳咳，咱们先别纠结我记忆的事儿。当务之急是弄清楚，教廷制造的那个‘强大的东西’，和原初之眼有无关系。”</p><p>伊芙摇摇头：“我不知道。”</p><p>她解释——从目前已知的情报来看，能够承载原初之眼意志的“容器”，至少得满足两个条件：</p><p>第一，极高的物质力量。</p><p>第二，复杂的思维器官。</p><p>“如果不需要‘极高的物质力量’，那原初之眼不需要将教廷成员‘糅合’，才能降临。他完全可以只降临在其中一个教廷修士身上。”</p><p>“如果不需要‘复杂的思维器官’，祂能直接夺舍天空、大地、万物。但祂没有那么做。”</p><p>“肉身承载灵质，大脑解析精神，二者缺一不可，所以原初之眼在‘虚境’徘徊如此之久，也没能回归现实世界。”</p><p>杨帝点点头。伊芙的话确有道理。</p><p>“所以……祂渴望一件容器。”</p><p>一个兼备高能量、高智力的容器。</p><p>圣光教廷正在制作这种容器。结合他们在末日火山的所作所为，伊芙和杨帝同时瞳孔一缩，觉察到到同一个可能性。</p><p>“卡利斯托？！”</p><p>如果，他们最终目的是复活卡里斯托，用巨龙的身躯承载原初之眼的意志。</p><p>他们所见的一切，都能说得通了。</p><p>伊芙也开始捏起下巴来思考：“确实有这个可能……焚灭天空之龙，它的身体庞大且兼具力量，媲美10个圣光教廷的红衣主教。而它本龙也拥有高等智力，比如‘贪财’，恰恰就是在它高等智力下发展出来的性格。”</p><p>这么一看，巨龙是一件完美的容器。</p><p>而且，教廷封锁了屠龙之战发生的战场——星渊井口，和巨龙最终陨落之地——末日火山。</p><p>他们还妄图用最低等的魔物史莱姆，来复活最强大的巨龙。</p><p>虽然这个思路听上去很可笑，但万一真的有戏呢？</p><p>要知道，地球一种听上去非常高大上的材料石墨烯，最初也是靠透明胶带，在石墨上慢慢脱离下来的。</p><p>听起来很蠢的方法，也许真能干成大事。</p><p>更何况，这里是有魔法的异世界。</p><p>魔法和奇迹都是存在的。</p>
