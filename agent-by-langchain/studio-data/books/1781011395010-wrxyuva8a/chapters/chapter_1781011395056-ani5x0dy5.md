# 钓鱼佬二三事3

<p>杨帝微微眯起眼睛，集中精神感应钓鱼佬身上的“灵”。</p><p>在他感知中，周围世界被一层“滤镜”覆盖，万事万物都以一种别样的“灵”的形态呈现出来。</p><p>他看到钓鱼佬身上的“灵”，确实比常人要少一些。</p><p>就像……就像是被撕裂了一部分。</p><p>和自己一样。</p><p>与之形成鲜明对比的是，钓鱼佬的精神属性比普通人要高上许多。</p><p>这种精神上的特质，让他比常人更容易察觉到杨帝的存在。</p><p>“大叔，我刚刚感应了一下，发现您身上的‘灵’比普通人少，但精神属性却很高。”</p><p>钓鱼佬微微皱眉，眼中闪过一丝疑惑。</p><p>“小伙子，你说的这些太玄乎。什么‘灵’少，精神属性高，我还是头一次听说。”</p><p>杨帝见状，继续问道：“大叔，那您平时是不是直觉特别准，观察力也异于常人呢？”</p><p>钓鱼佬愣了愣，随后缓缓点了点头。</p><p>“不错。我钓鱼这么多年，总能察觉到别人注意不到的鱼群动向，按照直觉去钓，大多时候都没错。”</p><p>三句话不离本行啊。</p><p>但看起来他并未过多接触世界的“另一面”。</p><p>精神属性可能天生比较高，比如胡彦卓。</p><p>但对于“灵”，不可能先天不完整。</p><p>就好像工厂生产的啤酒瓶，大部分都是完好无损、符合标准的。</p><p>偶尔会有小部分，出现一些细微的瑕疵。</p><p>——但基本不可能出现只有“半个啤酒瓶”这种情况。</p><p>那极大概率，不是自然生产过程中会出现的，极可能是受到了某种外力的破坏，扭曲。</p><p>同理，“灵”对于每个人来说，正常情况下应该是完整的。</p><p>钓鱼佬身上“灵”的缺失，不可能先天形成。</p><p>必然是后天经历了什么特殊的事情，导致他被撕裂了一部分。</p><p>斟酌两秒，他决定亲口问问。</p><p>杨帝：“您是不是曾经经历过什么特别的事情，才导致了这样的变化呢？”</p><p>钓鱼佬的脸色瞬间变得凝重。</p><p>他眼神中闪过一丝复杂的情绪，似乎陷入了一段不愿回忆的往事。</p><p>“小伙子，有些事情……还是不说为好。那是一段很不好的回忆，我不想再提。”</p><p>“好吧……咱不聊这个。”</p><p>杨帝看着钓鱼佬的表情，知道自己触碰到了对方的底线，便也不再追问。</p><p>钓鱼佬拍了拍杨帝的肩膀：“谢谢理解，小伙子。我还惦记着我那鱼竿呢，刚把它放下了，我得回去继续钓鱼。”</p><p>他真的非常热爱钓鱼。</p><p>在杨帝印象里，父亲同样是个资深钓鱼佬。</p><p>经常带他去水库钓鱼，钓鳖。</p><p>杨帝点了点头：“行，大叔，你去吧。要是有什么异常情况，就大声喊我。”</p><p>钓鱼佬咧嘴笑笑，“放心吧，小伙子。我这么大个人，能照顾好自己。”</p><p>“对了，叔，这楼死了人，没想过报警吗？”</p><p>钓鱼佬停下脚步，无奈地笑了笑，说道：“小伙子，我刚来时就试过了，这地方压根没信号。”</p><p>杨帝闻言，掏出手机一看，果然，信号栏显示无服务。</p><p>就连妖妖灵都打不通，是物理意义上的没信号，这种情况……太眼熟了。</p><p>就像旧校区艺术楼地下室。</p><p>看来只能到楼上去接收信号了。</p><p>杨帝沿着楼梯向上。</p><p>刚才还没那么明显，现在，楼道里又弥漫着一股令人作呕的腐臭气息。</p><p>3楼和4楼之间的转角处，一个熟悉的东西映入他的眼帘。</p><p>猫般背对着他坐着，发出喵喵叫。</p><p>假的猫，它没有心跳和呼吸。</p><p>——那是一个从黑暗里滋生出来的东西，有着猫形状的舌头，引诱人类靠近。</p><p>这是杨帝在这栋楼里，第二次见到它了。</p><p>之前他才把那只猫形状的舌头砍了下来，扔火堆里烧掉。</p><p>烤肉味甚是香，蛋白质至少是牛肉的三倍，但他忍着没吃。</p><p>现在好了伤疤忘了痛，它又从阴影和角落死灰复生！</p><p>三天不打，上房揭瓦。杨帝现在正想打妖妖灵，被这一骚扰，有些恼了。</p><p>虚空大手一探，一把抓住！</p><p>一把抓住那猫形状的舌头，用力将它从阴影中往外拔。</p><p>然而，这诡异的肉条仿佛没有尽头！</p><p>随着他的拉扯，不断从阴影里延伸出来，越拔越长！</p><p>那触感黏腻湿滑，仿佛抓着一条巨大的鼻涕虫，令人作呕！</p><p>“哼，我就不信拔不完你！”杨帝手上的力量又加大了几分。</p><p>“舌头猫肉条”仿若无穷无尽。</p><p>楼道里回荡着一种奇怪的声音，像是低沉的咆哮，又像是尖锐的哀号，交织在一起。</p><p>声音是从角落阴影那传出的。</p><p>那个伸出猫舌头的东西，很痛苦。</p><p>被拔舌头当然很痛，十八层地狱的第一层就是“拔舌地狱”，看来这项规律放在怪物身上，也没有例外。</p><p>杨帝拼尽最后一丝力气，猛地一扯，至少一万斤力道！</p><p>“啪叽～”</p><p>那肉条超过弹性限度极限，断了。</p><p>大量浓稠黑色液体从肉条断裂处喷涌而出，溅射到墙壁和地面。</p><p>散发出刺鼻的酸腐气味。</p><p>「生化+1」</p><p>这玩意有毒，简直跟异形似的。</p><p>肉条断口处还在不断抽搐，仿佛有生命般。</p><p>“viv”色的灵魂，从肉条里慢慢流出。</p><p>——当然，杨帝并不确定那是不是“灵魂”，这种颜色也可能是代表某种“活力”。</p><p>因为不只是死人附近有，他在截肢病人的肢体断口处、菜市场里的生鲜肉、甚至是一些新鲜蔬菜附近，都能看到这种颜色。</p><p>应该是某种生物质活力吧。</p><p>又或者是，人类以往宗教、神话里，对灵魂的认识是有偏差的。</p><p>“……”</p><p>看着霸占半条楼道的舌头猫肉条，杨帝决定先不管这玩意儿，完事了再烧掉。</p><p>这栋楼里的“恶意”太多了，只清理一天，一时半会儿是压制不了的。</p><p>就像巴甫洛夫的狗，得持续驯化。</p><p>这栋大楼，也得持续地清理。</p><p>杨帝绕过地上那还在抽搐的肉条，继续朝着楼顶走去。</p><p>铅铁色的浓云依旧在天空中黏稠地流动，世界笼罩在灰暗之下。</p><p>报警。</p><p>这种事他已干过很多遍。</p><p>虽然自己是黑户，不应该如此大张旗鼓引起相关部门的注意。</p><p>但他存在感够低，即使是被摄像头录下来，查看摄像头的人，也往往会忽略画面中的他。</p><p>所以，他还是喜欢在自己能力范围内，贡献一下社会。</p><p>一个有秩序的世界，便于他探访脚步所及的所有都市怪谈。</p><p>杨帝举着手机，在楼顶上四处踱步，依旧没能搜索到哪怕一格信号。</p><p>“仅可拨打紧急呼叫”，这句话是假的，紧急拨叫也打不动。</p><p>“吔！！！！！！！”</p><p>一个人惊呼怒吼咆哮的声音！</p><p>那熟悉的嗓音，从一楼来。</p><p>杨帝瞬间判断出，正是钓鱼佬。</p><p>他又一次意识到一件事——这栋楼的恶意并不只是在晚上才会攻击人，就像他刚才，光天化日之下，在楼道里被那只伪装成猫猫的舌头袭击了。</p><p>钓鱼佬孤身在一楼。</p><p>他可能也碰上些不干净的东西。</p>
