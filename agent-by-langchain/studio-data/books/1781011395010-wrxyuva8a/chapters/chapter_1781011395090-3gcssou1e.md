# 原初之眼

<p>杨帝原本裂开八瓣的头，现在完全愈合，而且意识也恢复清醒。</p><p>他回想起自己意识还没清醒时，那种混混沌沌，迷迷糊糊的状态。</p><p>仿佛置身于一片虚无的迷雾。</p><p>那时的他，思维像是一团杂乱无章的丝线，每一个念头都如风中柳絮，飘忽不定。</p><p>眼前总是浮现出一些光怪陆离的景象，那些柑橘味的星星像是真实存在一般，在他的视野里肆意飞舞，引诱着他去追逐。</p><p>他意识在虚幻与现实之间徘徊，根本分不清什么是真实，什么是幻想。</p><p>他记忆由原来的线性，变为离散的非线性。</p><p>他过去一生的记忆，被扔进碎纸机铰烂，支离破碎；然后扔进搅拌机，彻底打乱顺序，无法拼凑出任何一丝逻辑。</p><p>杨帝终于明白了醉步男的绝望。</p><p>一切回忆，一切时间，在眼前被风暴扯得支离破碎，毫无规律地重组。</p><p>将打散的记忆，重新按某种逻辑重组起来，并不容易。</p><p>直到自己的身体自愈完全，大脑中的神经重新搭桥，血肉重新接续，断骨重新愈合。</p><p>杨帝才恢复清醒，回到他的身体中。</p><p>第一眼，就看到从光幕中央裂开缝隙露出的深邃黑暗。</p><p>黑暗中，出现一只眼睛。</p><p>那只眼睛不是任何动物的眼睛，也不是任何想象力所能想象出来的眼睛。</p><p>它没有固定的形状，眼球像是流动的墨汁，不断变换着形态。</p><p>时而膨胀成一个巨大的球体，几乎占据了整个黑暗空间，时而又收缩成一个微小的点，仿佛随时都会消失不见。</p><p>眼眸的颜色糅合了世间所有色调，其中似有无数星辰在其中诞生与毁灭。</p><p>眼眶周围，环绕一圈圈纹路。</p><p>与其说是纹路，那更像是触须，它们不停地蠕动着，仿佛拥有自己的生命，在黑暗中肆意伸展与收缩……</p><p>杨帝的灵魂在这目光下，不自觉地颤抖。</p><p>这种颤抖像是种强制性的效应，他的理智和感性无法镇压。</p><p>那目光能看穿他每一个想法，每一段记忆，将他内心最深处的恐惧与秘密，都暴露无遗。</p><p>杨帝强行移开视线。</p><p>还行。感觉要是再看个十来分钟，就能进化适应了。</p><p>他看向身边僵硬的友人，叹了口气，遮住瑞弗维尔的眼睛：“别看。”</p><p>但这个“旅商”毫不领情。</p><p>瑞弗维尔狂热地想要掰开杨帝的手。</p><p>他言语中，充满了一种近乎癫狂的渴望。</p><p>“让我看，杨帝！我必须看清楚它。”</p><p>瑞弗维尔一边挣扎，一边大声叫嚷着，声音因为激动而变得尖锐刺耳。</p><p>杨帝死死地抵住瑞弗维尔，双手如同铁钳一般，不让他的目光触及那只眼睛。</p><p>“冷静，瑞弗维尔。”</p><p>“滚呐。”瑞弗维尔像是着了魔一般，力气变得出奇的大，竟能撼动杨帝一根手指。</p><p>他脸上满是汗水，五官因为扭曲的欲望，而显得有些狰狞。</p><p>“那里藏着答案，宇宙的终极答案！只要看一眼，我就能明白一切。”</p><p>“没有，那仅仅是一只眼睛。”</p><p>瑞弗维尔在这咆哮声中，又开始剧烈挣扎起来，声音几近嘶吼，不顾一切地想要挣脱杨帝的束缚。</p><p>“眼睛是心灵的窗户，而它是万物的窗户，放手杨帝。”</p><p>杨帝捂着瑞弗维尔的眼，一边再次看向那个……虚无中的眼睛。</p><p>他一瞬间就明白了那是什么。</p><p>中土大陆的第一场灾难，原初之眼。</p><p>他们对视一眼，便完成了大量精神交流。而神交，是双向的。</p><p>当那只眼睛，看透杨帝每一个想法、恐惧与秘密的同时，祂也将自己的一部分暴露在杨帝的目光下。</p><p>所以，杨帝也知道了「祂」是什么。</p><p>原初之眼是宇宙诞生时的第一道光芒，是混沌中睁开的“第一眼”。</p><p>它见证了时间起点，渴望见证岁月终焉。</p><p>它本质是一种“纯粹的观察”，不带有情感、偏见或目的性……不对，并不“纯粹”。</p><p>祂在世人面前显露形象，本身就是对人的意志进行了“干涉”。</p><p>杨帝看到了那个藏深邃眼眸下、最原始最狂热的渴望——祂并不甘心于永恒的「观察」。</p><p>祂想要降临这个物质世界，亲自书写现实。</p><p>杨帝意识到，原初之眼有可能，也许，大概——是一个创作欲望极强的“同人二创作者”。</p><p>它拥有着无穷无尽的灵感与想法，这些念头在它诞生以来的漫长岁月里不断发酵、膨胀。</p><p>它见证宇宙诞生，目睹无数星辰的升起与陨落，生命起源与消逝。</p><p>巨量素材，在它“脑海”中堆积。</p><p>它不满足于仅仅作为一个旁观者，静静地看着世间万物按照既定的轨迹发展了。</p><p>它的创作欲望，如同熊熊燃烧的火焰，炽热而疯狂。</p><p>它希望打破现实的框架，用自己的意志去勾勒每一处细节，重新定义时间与空间，赋予生命全新的形态和意义。</p><p>它想要将世间所有的可能性都一一实现，构建一个只存在于它想象中的完美世界。</p><p>它想要亲自下场，用自己的意志去重塑这个世界。</p><p>但它那超越凡人理解的创作方式，很可能会将万物秩序撕得粉碎。届时，所有人都是“醉步男”。</p><p>“瑞弗维尔，你听我说！”</p><p>杨帝一边压制着瑞弗维尔，一边大声说道，“那玩意在诱骗你，祂想要改写中土大陆的历史与现实。那时候你写再多野史也没有用，因为历史可能会在1秒内变化七八百万亿遍……”</p><p>但瑞弗维尔此时，已冲昏了头，根本听不进杨帝的话。</p><p>杨帝已没时间多费口舌，抬起手，对着瑞弗维尔的后颈侧方的神经和血管富集处砍下去。</p><p>这一击凝聚他恰到好处的力量，瑞弗维尔顿时双眼一翻，身体软绵绵倒下。</p><p>杨帝将注意力重新放回那只眼睛上。</p><p>但是，藏在圣光裂隙中的眼睛消失了。</p><p>杨帝又转动眼球，看向由几十个圣光教徒杂糅而成的奇行种。</p><p>奇行种扭曲的身体正不断地颤抖着，散发着令人作呕的气息。</p><p>数十个头颅在尖叫，始终没有停过，天知道是什么动力，支持他们如此尖叫下去的。</p><p>而那只眼睛，出现在第一席红衣主教、喉咙深处的黑暗中。</p><p>这个由数十人肢体、驱赶、头颅杂糅而成的奇美拉，已成为原初之眼行走世间的“物质身体”。</p><p>杨帝不打算干涉世人的命运，但“原初之眼”的降临，是超凡存在对凡尘世人命运的赤裸裸之干涉。</p><p>他要抽刀向更强者了。</p><p>那只眼睛仿佛察觉到杨帝的决心，周围黑暗愈发浓郁，其中的星光疯狂闪烁。</p><p>祂正在适应这具物质身体。</p><p>在此之前，祂处在僵直状态动弹不得，有便宜不占乌龟王八蛋！</p><p>杨帝先下手为强！</p><p>板砖在极限肌肉力量的加持下，附上三层“杀手兔”速度附魔，突破2.1马赫初速！</p><p>这已经接近一般步枪的枪口初速。</p><p>但力量还是太弱小，速度太慢了。</p><p>几十毫秒内，原初之眼适应了这具身体。</p><p>一个闪耀着刺目光芒的护盾，瞬间出现在奇行种身前，精准挡住杨帝全力掷出的砖头。</p><p>砖头化为齑粉，消散在空气中。</p><p>只留下一圈圈波动在护盾表面荡漾开来。</p>
