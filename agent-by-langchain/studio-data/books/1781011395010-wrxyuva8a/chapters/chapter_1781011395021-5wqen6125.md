# 一种基于自戕的锻炼法

<p>“让让道？”杨帝的声音，他试图从外道超车。</p><p>胡彦卓的胜负欲在髋骨旧伤里苏醒。</p><p>他猛然蹬地提速，又和来者拉开一段距离。</p><p>侧头，余光一瞅，杨帝仍然死死咬住。两个影子再次并驾齐驱。</p><p>胡彦卓的髋关节开始隐隐作痛。</p><p>这旧伤像块烙铁，每逢阴雨天便在骨缝里滋滋作响，提醒着他你已不复往日光彩。</p><p>三圈，五圈，七圈。</p><p>这个曾经被轻易甩开的菜鸟，此刻竟带着某种非人类的匀速，如同永不停歇的节拍器般压迫而来。</p><p>整整15圈，6公里，3分45秒的配速，杨帝全程紧紧咬住。</p><p>……胡彦卓还记得，当初他达到这个速度，跑了将近半年。</p><p>而这个叫杨帝的，六天……六天？！</p><p>胡彦卓心中有一抹妒火一闪而过。</p><p>他身体先于脑子做出反应，不自觉地迈下更大的步子，迈出更快的步频。</p><p>随手将这个花六天时间、实现他六个月成绩的天赋怪给拉爆，出了口恶气！</p><p>最后三圈，他以每公里3分20秒的速度彻底甩飞杨帝，向那个天赋异禀的妖孽展示——我还是有些老底的！</p><p>我不想让你看到车尾灯，你就一点都看不到……至少目前为止，是这样的。</p><p>“呕——我不行了。”</p><p>杨帝跑完第16圈，匍匐在地，干呕着。</p><p>「体力+1」「下肢+1」「心肺+1」……</p><p>他瘫坐在跑道旁的塑胶地面上，胸腔剧烈起伏着。</p><p>他能清晰感受到肺泡在高压下痉挛的刺痛，耳膜随着心跳发出规律嗡鸣。</p><p>这种濒临极限的体验，在过去六天的琦玉锻炼法之中反复上演。</p><p>今天的疼痛比以往剧烈一些——右腿腓肠肌传来撕裂般的触感，像是有人把烧红的铁丝捅进了肌腱。</p><p>大抵是肌肉纤维挫伤，甚至断裂了。</p><p>胡彦卓向他走过来：“还好吗？”</p><p>杨帝摆摆手：“还好还好，没事没事，只是扭了一小下。”</p><p>右腿处，某种温热的麻痒正从痛楚中心扩散，如同3D打印机正在逐层修复组织。</p><p>不过五分钟，原本需要静养两周的拉伤竟已消退大半，伴随着划过心头的模糊感觉。</p><p>「下肢+1」「下肢+1」「下肢+2」</p><p>是的，疯狂折腾自己的身体，甚至能使“超量恢复”的效果比正常锻炼还要好。</p><p>对普通人来说，这是会落下病根的，甚至是永久病根，绝不可轻易尝试。</p><p>但对于杨帝而言，新世界的大门再次对他敞开了一扇！</p><p>这新世界大门真是越开越多啊哈哈。</p><p>他改进了落后的琦玉锻炼法，逐步发展成今日的“自戕锻炼法”！</p><p>过度使用肌肉导致拉伤、进行超出身体负荷的高强度运动使肌肉纤维出现微小撕裂，每次锻炼都拉伤肌肉三四次。</p><p>反正肌肉锻炼的原理，原本就是磨损→超量恢复。</p><p>现在，杨帝是把这个机制利用到极致！</p><p>虽然很不科学，但事情就这么发生了。</p><p>存在的事物自有其一定的道理。</p><p>此刻，凭着拉伤挫伤的代价，短短6天内，杨帝6公里配速终于突破3分45秒，可喜可贺！</p><p>虽然还未达到国家三级运动员水准，但已经是“业余级巅峰大圆满”。</p><p>胡彦卓站在一旁，脸不红心不跳。</p><p>他瞥了眼瘫在跑道边的身影，记忆闪回六年前的自己，那个在县城中学操场吐得昏天黑地的瘦弱少年。</p><p>他放慢脚步，鬼使神差地抛下一句：“明早五点二十，我跑半马。”</p><p>半程马拉松，大概20公里，正常人不会拿这个里程来锻炼身体。</p><p>杨帝脸色有些虚浮，抬起头看向那矮个子红衣青年：“胡哥，我也来跟着。”</p><p>胡彦卓看他一眼：“你太慢了。”</p><p>“不，我已经能跟上你了。”</p><p>“是吗？那明天你就试试跟上我的节奏，不过我不会手下留情。”</p><p>胡彦卓嘴角勾起一抹不易察觉的笑意。</p><p>杨帝感受到胡彦卓话语中的挑衅。</p><p>但在这轻微的挑衅之意背后，“精神”被拔到很高层面的杨帝，听出了隐藏的意味。</p><p>话说，令狐冲重伤后被风清扬发现，风清扬有心传他独孤九剑。</p><p>但风清扬并未直接说要收令狐冲为徒，而是像个面试官一样，先与之交谈，考验令狐冲是否有足够的悟性和资质来学习这门高深剑法。</p><p>这种似曾相识的既视感。</p><p>半程马拉松强行跑下来，应该能让他双腿肌肉大范围挫伤，关节囊发炎肿胀，练一回相当于练三回。</p><p>效率更高，他肉眼就能感觉到，自己在光速进步。</p><p>杨帝咬了咬牙，说道：“好，那我就试试，哪怕拼尽全力也要跟上你！”</p><p>胡彦卓微微颔首，眸中掠过赞许的意味。</p><p>这是个好苗子。</p><p>六天，做到我六个月努力才能达到的地步，甚至有可能发展成奥赛选手……</p><p>胡彦卓很熟络地拍拍杨帝的肩：“一块吃早饭去？”</p><p>杨帝却婉拒：“我还得在加练一会儿，你先走吧胡大哥。”</p><p>加练？</p><p>“你刚开始跑，一次跑太多反而用处不大，有害无益，很容易横纹肌溶解。”他好心提醒。</p><p>杨帝仍然摆摆手，坚持要留在田径场：“感谢胡哥提醒，我对自己身体的情况自有把握。”</p><p>都是成年人了，当然不能强行去管。</p><p>胡彦卓也便双手插兜，溜达着去了饭堂，先吃顿早饭。</p><p>但他越想越不逮劲。</p><p>不能让这个运动领域的奇才，因为不科学的锻炼方法，半途折戟沉沙！</p><p>他越想越害怕。</p><p>仿佛已经看见杨帝练得太疯太狂，导致肌肉溶解，肾功能衰竭，断绝了大好前途……</p><p>他随手抓起鸡蛋灌饼便走，径直回去田径场。</p><p>救人一命胜造七级浮屠，浪子回头好过中道崩殂。</p><p>穿褪色红运动服的红衣青年走过跑道外围，看了一圈，没见到杨帝。</p><p>他闲逛着来到器材区，才忍不住停下啃了一半的鸡蛋灌饼。</p><p>他看见杨帝吊着单杠，正以每分钟二十次的频率上下翻飞，活像台人形打桩机。</p><p>在做引体向上。</p><p>杨帝说的加练，不是指跑步，而是其他锻炼项目，比如引体向上。</p><p>“那人刚跑完这就多，就开始拉单杠……这运动强度，真特么是备战奥运会？”</p><p>他看着杨帝那两条快抡出残影的手臂，突然觉得手里的鸡蛋灌饼不香了。</p><p>在田径领域，他或许能碾压杨帝。</p><p>但综合身体素质，他或许就不如对方了，一种莫名的挫败涌上心头。</p><p>“杨帝，第几组了？”胡彦卓凑近问道。</p><p>杨帝像钟摆般规律起伏的身体突然定格，从单杠上跳下来，激起一片尘土。</p><p>他稍稍甩动手腕，刚撕裂的尺侧腕屈肌已能活动自如。</p><p>“哦胡哥你又来了啊……第几组来着？可能第八组？还是第九组？”</p><p>胡彦卓盯着对方小臂上蛇形隆起的静脉，如蚯蚓般蠕动的肌纤维，充血的双臂和手掌，不禁咽了口唾沫。</p><p>他拉完单杠，便又倒挂在横杆上做卷腹，汗水在下巴汇成溪流。</p><p>杨帝的“气息”很疯狂，不像是在锻炼身体，更像是一种……自戕。</p>
