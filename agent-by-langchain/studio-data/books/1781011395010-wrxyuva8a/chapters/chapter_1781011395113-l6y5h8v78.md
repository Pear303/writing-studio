# 精灵的论据

<p>哪里的史莱姆最多？</p><p>伊芙补充：“我加个限定词吧，哪里的熔岩史莱姆最多？”</p><p>奥拓想了想：“嗯……火山附近？海底火山……海底？”</p><p>“不，并不是。”提出反对意见的是杨帝，“要论哪里的史莱姆最多，我想应该，地脉？”</p><p>灵能地脉，异世界特产。</p><p>地脉是异世界的能量枢纽，那些纵横交错的能量通道之中，大量混乱的灵能相互交织碰撞、摩擦起火。</p><p>紊乱的灵能流会像搅拌浓汤般淌起浑水，把游离的元素粒子搓成半透明的胶质生命体。</p><p>半透明的胶质生命体，俗称史莱姆。</p><p>伊芙开古：“杨帝的回答已经很接近了。正确答案应该是——地幔。”</p><p>杨帝：……</p><p>异世界居然不是大陆世界观，而是非常符合经典力学的星球世界观！</p><p>伊芙绘出一幅立体的异世界剖面图，地幔层在投影中泛着炽热的橘红色光芒，宛如流动的液态火焰。</p><p>“这个圆球是什么？”</p><p>“我们所生活的世界。”</p><p>奥拓喃喃自语：“我们生活在一个球上？”</p><p>精灵的学术水平已经达到很高的地步。只有真正去了解精灵他们的知识体系，才会猛然惊觉——这群自然之子，怎么已经点出初级量子力学了？？</p><p>伊芙：“地幔并非普通的熔融层，还是火系灵能的天然熔炉。地幔深处高温与高压环境下，火系灵能不断压缩、凝聚，就像被塞进摇酒器的火焰，疯狂碰撞交融。</p><p>“这里每立方厘米的灵能浓度，是地表火山口的数百倍。</p><p>“只要灵能循环不停，新的熔岩史莱姆就会源源不断诞生。”</p><p>在灵能丰盛且混乱的地区，能监测到大量初等魔物——史莱姆的生成。</p><p>如果这个理论是普适的。</p><p>那么，大地深处的炽热、地下灵脉的灵能汹涌，是孕育史莱姆变异种——熔岩史莱姆的绝佳场域！</p><p>只不过基本没人能确定，那里是不是真塞满了史莱姆。</p><p>毕竟动辄数十千米厚的地壳，不是那么容易凿穿的。</p><p>地球上，人类最深的钻井也才12公里。</p><p>虽然不知道异世界的地壳有多深，但根据当地科技和魔法水平看，他们应该没能力挖掘超过10公里的探洞。</p><p>杨帝总结：“所以你认为，大地极深处存在大量岩浆，岩浆和地脉共同孕育了大量熔岩史莱姆，大量熔岩史莱姆又诞生了高等智慧，原初之眼就可以寄宿于‘熔岩史莱姆群体’之中。”</p><p>一个是中土大陆的原初天灾，拥有神灵力量的虚境存在。</p><p>另一个是这片大地最弱小的底层魔物，食物链底端的生产者。</p><p>前者依附后者而降临现实。这就是伊芙的答案。</p><p>“总结得很好！”</p><p>“你说得对，但你的假设链条太多了。”</p><p>杨帝一针见血，指出伊芙存在的问题。</p><p>精灵顿时面色煞白，就像成步堂一样死鱼眼+满头大汗，一时间不知如何辩驳。</p><p>她所做的这一系列假设，的确环环相扣，却又缺乏确凿证据。</p><p>如果一个推论，它的假设前提太多，而且论证过程过于精巧复杂，那么可信度会急剧下降。</p><p>世间最坚实的结论，都建立在最简单的假设上，比如数学。</p><p>最经典的欧氏几何，仅仅依靠五条公理，就推导出庞大而严密的体系！</p><p>这些简洁的公理就像稳固的基石，数学家们凭借纯粹的逻辑推演，从这寥寥数条基本规则出发，逐步构建起涵盖角度、形状、面积、体积等无数几何定理的宏伟大厦。</p><p>相比之下，伊芙关于熔岩史莱姆与原初之眼的推论，就如同在流沙上建造高塔。</p><p>高情商：99%的汗水+1%的灵感。</p><p>低情商：我是学术权威，有丰富经验。我猜的。</p><p>伊芙缺少强有力的证据，缺少抛瓦否艾维灯丝！</p><p>但杨帝忽略了精灵的一大优势——天生能与圣树“超距通讯”。</p><p>此前，伊芙与圣树的通话，一直被她头上那个伪装成“发夹”的“熔岩史莱姆”窃取篡改截断。</p><p>而现在，通讯频道通畅，伊芙将问题申请提交给圣树。</p><p>圣树，就是异界的“物联网”。</p><p>伊芙介绍，他们花了一万年时间，让这棵树的根须扎遍大陆各地。</p><p>究其原因，是被魔苟斯、索伦两代魔君打怕了，精灵差点绝种。</p><p>他们的母亲——圣树的生育率又不高，没有“战后婴儿潮”这一说法。施肥也提高不了精灵出生率。</p><p>于是，这群自然之子痛定思过，建立起一套大陆级别的信息监控工程。</p><p>老大哥竟是我自己。</p><p>一万年来，圣树防范化解魔王崛起的风险，将任何有潜力成为魔王的种子扼杀在摇篮。</p><p>比如什么“这个幼年炎魔潜力极高！”然后派出一队刺客，将其斩首。</p><p>又或者那个萝莉魅魔深不可测！这时则派出好看的精灵大姐姐将其收服，化敌为友。</p><p>“我还以为精灵不会轻易参与历史。”</p><p>“这又是哪个年代的刻板印象……不过我们也确实不会轻易人前显圣，不会留下太多记忆完好的目击者——我们会用大记忆删除术，删减目击者的记忆，所以最近几千年的史书中，很少出现我们精灵。”</p><p>圣树很快就发来新回应。</p><p>精灵眼前骤然一亮：“有结果了，在1分20秒前，圣树已经确认，在东海海底的地壳薄弱层，监听到下方有微弱的史莱姆活动信号，仅仅是持续5分钟的被动式探测，就在10平方千米区域发现了……将近500万熔岩史莱姆的信号……圣树在上，夺少？！”</p><p>这回，奥拓也听懂了。</p><p>数字非常直观，震撼人心。</p><p>而对于杨帝而言，这个数量级，这个史莱姆密度，更是让他头皮发麻！</p><p>要知道，神州-港城的九龙城寨，人口密度也才4.9万人/平方公里。</p><p>而东海海底探测到的结果，是50万史莱姆/平方公里，相当于九龙城寨人口密度的10倍！</p><p>这还仅仅是简单探测了5分钟的结果。</p><p>如果继续深入观察，也许这个数量级，还得往上乘系数。</p><p>三个人，三个种族，同时倒吸一口凉气，气温都骤然升高。</p><p>杨帝沉默了一会儿，问：“数据可信吗？”</p><p>“圣树出品，童叟无欺……总之你相信我……等等，又有新情况。”</p><p>杨帝和奥拓屏住呼吸聆听。</p><p>伊芙将额头抵在法杖上，脸上是平静，时而扭曲。</p><p>最后，她眸中绽出逆流成河的悲伤。</p><p>“熔岩史莱姆集群已经彻底撕破脸了。第一队熔岩史莱姆从末日火山涌出……摧毁了人类国度圣古琉斯。第二队史莱姆从‘孤山’出现，已经毁灭了铁熔堡……南海、东海出现10万数量级的史莱姆集群超过一千个，并且还在不断增多……除却东部精灵圣树领地，大陆其余地区已全面沦陷，95%的人类和矮人确认死亡。”</p>
