# 耶罗教经

<p>希夷几乎也是同一时间发出哀嚎。</p><p>杨帝艰难地扭过头，看见穿红色上身运动衫的胡彦卓嘴角扯出僵硬的弧度。</p><p>他左手掐住希夷，右手持瑞士军刀，捅进杨帝的心脏。</p><p>“胡彦卓，你……什么时候……”</p><p>他，或者“它”缓缓张开口。</p><p>声音却从遥远的四面八方传来：“胡彦卓，胡彦卓——真是个好名字。但我还是希望你称呼我的本名，陈昭。”</p><p>杨帝瞳孔因痛苦而收缩。</p><p>他见过这个名字，就在艺术楼的雕塑室和书法室里，2013届的老学长，陈昭。</p><p>出现过耶罗符印漩涡图案的位置，都有他的名字。</p><p>比如，没有五官的石膏雕塑，基座上就有他的名字。</p><p>「2011.12.2，石膏塑像，面容缺失……」</p><p>还有书法室角落的漩涡图纹……</p><p>陈昭惬意地甩动胳膊，嘴角笑意抑制不住，近乎癫狂：</p><p>“不错……他是叫胡彦卓对吧，真是一具年轻，健康，富有活力的身体。你得替我谢谢他，若不是两年前他出现在艺术楼楼顶，也许直到今天，我都等不到我的有缘人。”</p><p>“混蛋……你把胡彦卓怎么了……”</p><p>“嘿嘿，在他醒之前，我就已经完成‘质壁分离’了。”</p><p>“质壁分离”，这个四个字化作一柄重锤砸在杨帝脑袋上。</p><p>从陈昭口中说出这个词，裹挟着令人反胃的粘稠恶意。</p><p>他把胡彦卓的“灵”挤了出去，占据了胡哥的血肉之躯……</p><p>杨帝捂住胸口的瑞士军刀。</p><p>剧烈的抽痛。</p><p>但他不敢贸然将刀刃拔出来，冷兵器贯穿伤都是如此，直接拔出来，很可能造成肌肉二次撕裂加大出血。</p><p>他……能扛得住这种程度的死亡吗？</p><p>杨帝看向脚边滚落的铝罐。</p><p>蛋白粉和运动饮料已经吃喝完了。</p><p>若没有糖分、蛋白质补充，还能否超量代偿，迅速恢复适应伤害？</p><p>他知道，自己能适应致死性伤害。</p><p>但那是建立在物质充足的基础上。</p><p>如果完全不补充任何水分，他的身体会流干最后一滴血而死，还是无中生有、凭空造血？</p><p>杨帝对自己的“适应”能力，了解得还是太贫瘠，开发还是浅薄了。</p><p>「杨帝，你简直跟星际虫族一样扛造……」</p><p>呵，虫族，虫族也有血条。</p><p>有血条就会死。在物资充沛时，他能免疫致死伤害；但在弹尽粮绝之刻，奇迹还能否复现？</p><p>杨帝跪在地上，勉强扭头看着陈昭。</p><p>陈昭从怀中掏出笔记本，然后抽出杨帝口袋里的中性笔。</p><p>他在实验记录那页的最后，又添加两行：</p><p>「2025.5.9，狸花猫，质壁分离。」</p><p>「2025.5.9，人，质壁分离。」</p><p>陈昭合上书页，笑吟吟地看着他，把中性笔塞回杨帝口袋。</p><p>后者狼狈不堪，胸膛还插着把刀，喉咙一直在呕血。</p><p>杨帝仍然从牙缝里挤出声音：“陈昭……耶罗大仙的符印，质壁分离邪术，还有这间不可能存在的地下室……你究竟在做什么？”</p><p>他蹲在杨帝面前，一边把玩着手中变成麻雀的希夷，一边狞笑：“和你们这些庸人不同，我追求的是宇宙至高的真理——”</p><p>像每一个合格的反派，他开始讲述自己的过往经历，与宏大计划。</p><p>……</p><p>六十年代，推土机碾平了村口的“耶罗庙”，鎏金神像在尘烟中碎成齑粉。</p><p>在这片求神拜佛数百年的土地，理工大学扎根。</p><p>千禧年之前，祖父还在世。</p><p>那时他总在灶台边，坐着安乐椅，浑浊的眼睛映着跳动的火光，哼着俚语。</p><p>“沿湖边，云彩散，碎成一片片……”</p><p>“耶罗大仙的汗巾扫过稻田，谷穗就会结出血红的米……”</p><p>“女王的低声哀诉，是空虚的喜悦，所以开口唱……”</p><p>这些被新世纪斥为迷信的歌谣，像毒蛇般缠绕在陈昭童年的梦境里。</p><p>十八岁那年，陈昭握着稷海理工的录取通知书重返老家。</p><p>同一日，暴雨夜，他在祖屋阁楼的樟木箱底摸到一本古旧的线装书。</p><p>封面烫金的“耶罗大仙话本”六个宋体字，在雷光中诡谲发亮。</p><p>那本蓝皮线装书很旧，很古老，像一具蜷缩的尸体，躺在箱底积灰的棉絮间。</p><p>封面的靛蓝早已褪成斑驳的灰蓝，似被岁月抽干了颜色。线装的书脊已裂开数道缝隙，泛黄的棉线随时可能崩断。</p><p>翻开书页，蝇头小楷竟与记忆里祖父的俚语一一吻合。</p><p>更夹着半张残卷，绘着漩涡状的符印，边缘用中文标注着“耶罗符印”。</p><p>陈昭读完话本，心有感召，周身似被暖流裹挟，从此陷入对耶罗大仙狂热的崇拜。</p><p>「沿湖边，云彩散，碎成一片片……那两个太阳慢慢往下落，落到湖边去了……长长影子就罩在了‘卡耳叩山’那地方……」</p><p>祖父的俚语在耳畔盘旋。</p><p>他想起村后那片荒草丛生的祖坟，想起某个清明节随父亲扫墓时，曾瞥见一座没有碑文的土冢。</p><p>祖父说，那是供奉耶罗大仙的衣冠冢。</p><p>清明的夜，暴风骤雨，行人欲断魂。</p><p>雨水抽打着陈昭狂笑的脸。</p><p>他跪在泥水中，用从锄头上掀下来的铁钎，在祖坟坟头疯狂挖掘。</p><p>泥土混着腐叶灌进指甲缝，直到铁钎突然磕到硬物。</p><p>一个圆的，厚重的铁饼。</p><p>闪电撕裂黑暗的刹那，他看清了那截露出地表的铁质印纽。</p><p>上面缠着褪色的红绸，刻着漩涡状图案。</p><p>当他将符印捧在掌心时，雷声骤然化作悠长的呜咽。</p><p>好像、好像一尊古老存在，正透过云层，在老天上面俯瞰人间，凝视陈昭。</p><p>2011年冬，稷海理工，第一次实验。</p><p>陈昭的瞳孔兴奋地收缩，笔记本上的字迹因颤抖而扭曲：</p><p>「2011.10.15，黄斑渔游蛇，爆体。」</p><p>四个多月后，艺术楼的地下室迎来了第一个人类实验体。</p><p>这个可怜的建筑系新生住在学生公寓四楼。</p><p>当时正值月底，陈昭套一麻袋把他绑走，带到地下室进行“质壁分离”实验。</p><p>结果是败了，那建筑系的学生当场死亡。</p><p>陈昭花了比较大功夫，把现场伪装成“从四楼阳台窗户跳下自尽”。</p><p>之后造成的社会影响、在学生之间流传起来的都市传说，对他而言并不重要。</p><p>心无二物，只为求道。</p><p>耶罗大仙，法力无边。</p><p>“把人的‘灵’从肉体中剥离，将最纯粹干净的真我献于耶罗大仙……原本实验很顺利的，甚至还有意想不到的成果——创造出‘都市传说’，在学生群体中制造恐慌，逼迫校方放弃这几栋‘邪门’的教学楼和公寓，让这里彻底成为我的自由天地……但是！”</p><p>陈昭的指节因暴怒而发白。</p><p>他将“希夷拐杖”在膝盖上一下折断，揉成一团。</p><p>他捏着那只挣扎的麻雀，指甲几乎要戳进蓬松的羽毛里。</p><p>希夷的喙部渗出鲜血，黑色眼珠里映出陈昭扭曲的脸。</p><p>“希夷……这个不知天高地厚的家伙，撞开地下室的铁门，看见了我为耶罗大仙所做的崇高研究，还抢走了耶罗符印。”</p><p>陈昭用两只手掐住希夷，十指如铁钳收紧，恶狠狠盯着它。</p>
