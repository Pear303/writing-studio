# 肯打鸡事变

<p>眼前是热风扑面的城市，身后是能令君子、国士都望洋兴叹的超巨型山脉“君士叹顶”。</p><p>嶙峋山体刺破云层，皑皑雪顶在阳光下泛着冷冽的光，仿佛一道天然屏障，将城市与未知的苍茫天地隔开。</p><p>一半天空，被高山遮蔽。</p><p>而另一半天空，则是钢铁的天下。</p><p>阿巴仰头望着悬浮在云端的银灰色建筑群，乍一看，确实像是权贵在云端堆砌的空中宫殿。</p><p>事实上，那只是普通的城建设备。</p><p>悬浮建筑群上安插了密密麻麻的天线，虽繁杂却不乱。</p><p>中央那座形似宝塔的建筑，则是整座城市的神经中枢。</p><p>负责调控城市的能源分配、交通网络，连下方每一片反重力浮岛的倾斜角度，都由其计算系统实时校准。</p><p>换言之，所谓的浮空宫殿，其实是放大版信号基站。</p><p>最初的城建中，天线阵列生硬如机械森林。</p><p>五十年前的设计师突发奇想，将技术需求与建筑美学结合，这才有了如今的“云端器官”。</p><p>……总体来说颇为艺术，如果忽略那些大红大紫大绿五光十色的明星怼脸大头照广告招牌，那确实很艺术。</p><p>如果不忽略。哇，辣眼睛。</p><p>“给，”杨帝将一个印着和蔼上校头像的纸袋塞进阿巴手里，“藤椒鸡腿堡，热乎的。省得你说我食言。”</p><p>食言？</p><p>哦，在离开母宇宙前，老大曾对她保证，跟他走能够有吃有喝，吃吃喝喝，大吃大喝。</p><p>虽然到目前为止，阿巴自己的境界、修为仍然没有升级进步的迹象。</p><p>但大吃大喝本身就是一场酣畅淋漓的修炼。</p><p>阿巴接过袋子，那刚出炉的、混合着藤椒辛香和炸鸡油脂的霸道香气瞬间冲散了空气中的硅脂焦味，直往鱼鼻子里钻。</p><p>其实她原本想点鳕鱼堡，但杨帝认为“有违伦常”，拒绝了阿巴这一请求。</p><p>她明明是鲈鱼，而不是鳕鱼，哪里有违伦常了。</p><p>嗯，不过嘛……藤椒鸡腿堡……</p><p>阿巴努力维持着修仙者的淡然，但喉咙却不争气地咽了一下。</p><p>“哼，凡俗之物……”</p><p>话虽如此，还是忍不住低头，手指已经扒开了纸袋边缘。</p><p>“我、我要开动了……”</p><p>现在他们正处于肯打鸡门店内。</p><p>忘记是谁开头提议说“去吃个堡吧”，所以他们决定去了这家最近的门店。</p><p>不得不说，这地方风水很好，一下火车就能看到巨大的发光上校头像，红白色的招牌在建筑群中格外显眼，仿佛是这座城市给旅人准备的专属地标。想必铺位租金特别贵。</p><p>阿巴刚咬下藤椒鸡腿堡的第一口。</p><p>59改突然说：「又有东西要来了。」</p><p>异变突生！</p><p>“滋啦——”</p><p>肯打鸡店内，那台原本安静运作、散发着诱人薯条香气的巨型炸薯条机，猛地发出刺耳的电流尖啸。</p><p>它粗壮的金属出料臂毫无征兆地横扫，滚烫的热油如同高压水枪般喷射而出，目标却不是炸篮，而是店内惊愕的店员！</p><p>“哼哼啊啊啊啊！”</p><p>“烫，救命。”</p><p>“机器疯了！”</p><p>尖叫声、哭喊声瞬间炸开。</p><p>滚烫的油脂泼洒在光滑的地板和人体上，激起一片痛苦的哀嚎和混乱的躲避。</p><p>几个靠近的顾客和店员差点被烫伤。</p><p>但炸薯条机的出油管道，终究不是那么活动自如，因为原本设计就是固定死的。</p><p>而现代的凡间人类练得身形似鹤形，也都是勉强躲过去了，只有几个人被烫红了手。</p><p>“警告！烹饪单元过热！需要冷却！需要冷却！”炸薯条机发出毫无感情的电子音，但动作充满恶意。</p><p>它笨重的机体咔咔作响，试图转动方向，将更多的热油泼向人群。</p><p>人群乌泱泱避开油泼之处。</p><p>但也一部分有心人，发现了这部炸薯条机的邪恶目的——驱赶人群……</p><p>在把人群都赶到远离门口的角落后，它瞄准好最终方向——门口。</p><p>炸薯条机的目的，并不是把顾客、员工都烫成熟人。</p><p>而是用热油封锁住门口，不让任何一个人逃出。</p><p>几乎同时，旁边的冰淇淋机也加入暴乱。</p><p>“滴滴！糖分浓度过高！急需中和！急需中和！”</p><p>伴随着电子音的尖叫，冰淇淋机顶部的喷嘴疯狂旋转，不再是喷射柔软的奶油，而是像霰弹枪一样，将粘稠、冰冷的糖浆混合物猛烈地射向人群！</p><p>冰冷的糖浆如同胶水，粘在皮肤、衣物甚至眼睛上，带来刺痛和恐慌，极大地阻碍了人们的移动……好吧，总比热油好得多。</p><p>也就是威慑一番。</p><p>“所有人！不许动！蹲下！手抱头！”</p><p>炸薯条机彻底不演了，电子音竟然模拟出了命令的口吻，带着诡异的压迫感。</p><p>热油和糖浆弹在店内交织，形成了一道混乱而危险的封锁线，将惊慌失措的顾客们牢牢困在了快餐店的用餐区，变成了人质。</p><p>“这么有花活的整蛊节目？”阿巴手里的汉堡差点掉地上。</p><p>修仙不知多少万年亿年，洞府里钻出来的都是些山精野怪，偶尔也有几支星际舰队来犯。</p><p>这种炸薯条机、冰淇淋机集体造反的场面，真是活久见！</p><p>话说他们怎么走到哪，哪都有新事故。</p><p>杨帝扫视混乱的店内和那些惊恐的人质，并没有立刻动作。</p><p>他目光扫过角落里坐着的四个黑袍老头……</p><p>这四个老头，有些熟悉。</p><p>而且这副打扮，像是在高调地向世人宣布哈哈我有问题！我身上有惊天阴谋！之类的。</p><p>任何一个拥有成年人智力、同时身上真有惊天大阴谋的人，都不会将自己打扮成这副模样。</p><p>所以，这四个黑袍老头疑点反而最小。</p><p>略过。</p><p>其他顾客、店员，也都没有什么异常，都是凡俗之人，身上没有放出奇怪的电波。</p><p>就在人群瑟缩之际，身着红黑制服的店长突然抄起墙角的灭火器，几个女店员也随手抓起托盘和餐具，组成人墙向失控的机器逼近。</p><p>“都别怕！这两台破机器本身设计出来，就只是为了炸薯条和做冰淇淋，没有多少战斗能力！”</p><p>店长声嘶力竭的喊声给众人注入一丝勇气，人群中响起零星的助威声。</p><p>然而冰淇淋机仿佛预判到攻击，喷射口骤然收缩成针孔状，浓稠的糖浆瞬间化作密集的银色钢线。</p><p>这奶油和糖浆太冷了。店员惊叫，刚张开的嘴却又被刺骨寒凉的奶油填满。</p><p>炸薯条机同样不甘示弱。</p><p>它发出野兽般的轰鸣，将整排桌椅掀翻，滚烫的薯条如子弹般喷射而出。</p><p>肯打鸡店长被射得欲仙欲死，主要是这刚炸出锅的薯条真特么烫，剐蹭一下就得起水泡。</p><p>整个肯打鸡店内，弥漫着热油的焦糊味、糖浆的甜腻味，以及令人窒息的恐惧气息。</p><p>两台失控的机器如同恶魔般，将快餐店变成了人间烧烤架，呸，人间炼狱。</p><p>青丘白璃淡定地吃着薯条：“白杨大帝，不可干涉凡界内政哦。”</p><p>“用不着你提醒，我有自觉。”</p>
