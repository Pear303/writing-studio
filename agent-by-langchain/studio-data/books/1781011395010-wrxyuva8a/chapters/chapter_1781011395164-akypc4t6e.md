# 真实虚幻3

<p>阿巴瞪大眼眸，看向杨帝。</p><p>她虽然修仙，但和守望者文明交战已久，知己知彼百战百胜，阿巴并不是只机械白痴。</p><p>她知道，在有些计算机系统中，如果数据太大太大了，溢出内存所能承载的上限……</p><p>计算机会把这个“超级天文数字”，翻转为某个负值，比如-1。</p><p>杨帝目光依次掠过59改的方正面庞、阿巴耳下隐蔽的腮部，最终停在青丘白璃清澈的竖瞳狐眼上。</p><p>在她眼中，杨帝周身灵能呈现出一种诡异状态——并非趋近于零的正值，而是“负灵能”。</p><p>因此，在见杨帝的那一刻，她才笃定他是变异的新品种域外天魔，只有天魔的灵能会如此诡谲！</p><p>负灵能意味着什么？</p><p>自然数一般认为是由0开始，一个接一个，组成的一个无穷集体。</p><p>人手中可以有10个苹果，可以有1个苹果，亦或是0个苹果。</p><p>但“-1个苹果”是什么意思？贷款欠债了一个苹果？</p><p>凡界无法理解像杨帝这般的存在，却又无法驱逐或杀死他。</p><p>只能用这种颇为诡谲的方式，在世界能力范围内“降维显示”杨帝的存在。</p><p>简而言之，他“数据溢出”了。</p><p>恰似计算机无法理解超出其运算规则和数据承载范围的数值，只能以异常的“负值”来呈现。</p><p>阿巴已经知道了杨帝的想法：“老大，所以你最终想说的是……”</p><p>杨帝点点头：“有光速限制，有微观尺度极限，有各种各样‘数值上限’的现实世界，其实和虚拟世界没什么不同。”</p><p>只不过现实世界更显得精细。</p><p>虚拟世界相比之下更粗糙。</p><p>「……杨帝阁下，您的论证充满民间学术风格。但您仍然无法严格证明现实世界和虚拟空间的等价性。」</p><p>59改暗戳戳用“民间学术风格”这样的词汇指责杨帝是个彻头彻尾的民科。</p><p>但同时，他的电子音也比较高亢，以掩盖底气不足的颤抖。</p><p>然而，本应该底气不足的，反倒是杨帝才合理。</p><p>因为杨帝的“证据”根本不充分，“论点”半只脚迈入狗屁不通的境界。</p><p>就算在民科里，都算是最次的那批。</p><p>因为A具有XX特点，B也恰好具有XX特点，并不能说明A等于B。</p><p>即使A和B看起来确实有很多特点重合，看起来确实确实很相似，但也一样说明不了什么。</p><p>就连看起来最憨的阿巴，也能一瞬间想到七八百个相似的论证，能够证明香蕉和人类其实是同一种东西。</p><p>比如人类与香蕉的基因序列相似度约为50%-60%，四舍五入就是100%，这不就很相似了嘛！</p><p>但提出“世界为假”论点的人是杨帝。</p><p>他拥有超级力量赋予的超级智慧，超级肌肉赋予的超级大脑。</p><p>此刻，杨帝就是最大的学术权威。</p><p>三位大能，都不得不耐着性子听他论证。</p><p>杨帝捡起一块石头，徒手捏碎，将碎石粉洒落地面，目视它们随风而逝，一边说道：</p><p>“我知道你们不服我的‘虚拟世界’推断，认为我是胡说八道。尤其是59改，你秉持实证逻辑，打心底把我当沙比。</p><p>“你先前质问过我——如何证明一个在所有表象上都等同于‘现实’的虚拟空间，其本质就真的与现实世界无异。</p><p>“那么现在，咱来严格证明我们这世界几乎100%是假的。”</p><p>严格证明？</p><p>有些事情，是能严格证明的吗？如果结论脱离现实场景，便会沦为纯逻辑游戏。</p><p>比如“缸中之脑”假设，还有数学上的“无穷大”概念。</p><p>缸中之脑无法证伪，该结论对中午吃碟头饭还是盒仔饭，要不要加根玉米淀粉肠或五香茶叶蛋，毫无指导意义。</p><p>现实中暂未发现真正的无穷实体，该结论仅在符号体系内有效，比如语言，比如数学，却无法对应客观世界。</p><p>你无法在现实中找到无限个苹果。</p><p>守望者文明认为，世界应该是无穷的，但这也只是他作为前一个宇宙最大的学术权威，而做出最大可能的假说。</p><p>也没有严格地证实。</p><p>而现在，杨帝声称要严格证明他们所处的现实世界，接近100%的可能是虚拟世界。</p><p>等同于证明“缸中之脑”。</p><p>“文明发展到一定阶段，生产力将会爆炸式膨胀。届时文明所能掌控的资源，所能调动的生产力量，是极度恐怖的天文数字。”</p><p>抬眼望向悬浮在云层中的霓虹光带。</p><p>此刻，他们正位于君士叹顶山峰顶部。</p><p>此处能俯瞰整座超级城市。</p><p>杨帝：“君士叹顶堡……这座城市位于十万大山最深处。青丘白璃，告诉我，为了建造这座城市，凡界的人们花费的资源，和整个凡人王朝所有建设工程相比，是怎么样的情况？”</p><p>青丘白璃思索片刻说道：“凡界王朝广袤无垠，分为九州，每州三十六郡，每郡又辖七十二城，天下共两万三千城。而十万大山独分一郡，由72座城市结合为城市群，在凡界中的城市规模占比约0.3%……”</p><p>凡界极大，半径30亿光年。</p><p>凡界王朝也很大，占地30亿平方公里。</p><p>单论城池数量，便已是数不胜数。</p><p>而深藏于十万大山最深处的巨型城市，虽在建造时耗费了大量资源，可谓是不惜血本。</p><p>但放在整个凡界王朝的建设版图中，也不过是九牛一毛。</p><p>凡界王朝繁荣一统前，天下共500亿人，其中400亿文盲，极端贫困率超过95%。</p><p>生活在类似于“十万大山”这样极端恶劣环境中的人口，超过恐怖的100亿。而十万大山人口数，也才500万。</p><p>从修筑万里长城般的防御工事，到兴建庞大的基础设施，再到为每一座藏在天堑之中的城邦村镇通路通水通电。</p><p>为了摆脱贫困，每一项工程所耗费的人力、物力、财力都是难以估量的。</p><p>相比之下，十万大山城市群虽规模宏大，但也仅仅是凡界王朝建设、乡村扶贫之海洋中的一粒粟。</p><p>青丘白璃：“……综上所述，在大山之中制造出相当于首都这般繁华的城市，所占用的资源，在整个凡界王朝的建设资源总量里，着实只占很少一部分。”</p><p>自从归墟大帝出世，禁止灵界干涉凡界。</p><p>凡界又经过上万年对抗，终于逐渐走向团结和平、繁荣统一。</p><p>凡界王朝历史悠久，地大物博。</p><p>即便是“君士叹顶堡”如此一座巨型城市的建造，也不过是其庞大建设体系中的一个小分支罢了。</p><p>杨帝点点头，看向云巅。</p><p>钢筋水泥大厦组合成密密麻麻的建筑群，铺满整个天空。</p><p>他继续说，“灵界漏下一点边角料，凡界就能堆出王朝盛世；凡界拨出部分建设零头，就能在大山里砸出浮空都市；而这都市再分点资源，就能用计算机捏出五百年的虚拟变迁。”</p><p>正如“虚拟世界”中的“虚拟”二字。</p><p>构建虚拟世界所需的资源量，与现实世界的总资源量相比，很少很少。</p>
