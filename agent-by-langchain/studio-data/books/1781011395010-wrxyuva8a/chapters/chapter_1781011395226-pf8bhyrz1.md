# 灭圣 绝盗

<p>每一个“万业狐狸”的死亡现场，都或多或少残留着与其创作内容相关的痕迹：</p><p>散落的手稿、闪烁的屏幕、未完的设定集、读者的留言、具现化的咒怨……</p><p>杨帝的意识冰冷地运转着，将万亿宇宙中万亿个“万业狐狸”的死亡瞬间，如同冰冷的数据标本般陈列。</p><p>这绝非巧合。</p><p>这是规律。是诅咒。</p><p>杨帝的目光，穿透了最初地球宇宙的泡膜，再次落向稷海市石桥街道81号9楼3号房——那个达文西/万业狐狸的死亡起点。</p><p>他的意识海中，那由万亿宇宙勾勒出的冰冷狐狸分形轮廓，似乎微微闪烁了一下。</p><p>狐狸“眼睛”的位置，那个最初的地球宇宙，仿佛成了一个无限深邃的漩涡。</p><p>“万业狐狸死了。”</p><p>“但……”</p><p>“耶罗大仙还活着。”</p><p>“万业狐狸，和耶罗大仙，他们之间有极强的因果联系。”</p><p>这念头如同最终的判决。</p><p>覆盖10^95宇宙的万亿分身，在同一刹那，执行了同一个意志。</p><p>分裂！这一次，是彻底的、指向“无限”本身的疯狂增殖！</p><p>每一个杨帝分身，都成为了一个全新的“原体”。</p><p>它们体内那源于“维持基准态不变”核心能力、早已超越此界无穷的阿列夫零级灵能，轰然爆发。发动了轰轰烈烈的——自我复制。</p><p>一个杨帝，在宇宙边缘瞬间分裂为3个！3个分裂为27个！27个分裂为7.6万亿个！……</p><p>分裂的速度超越了光速，超越了时间本身的概念。</p><p>每一次分裂，新生的个体都完美继承本源意志与力量。</p><p>就如“阿列夫零”是指全体自然数的势。但如果将全体自然数分裂为偶数和奇数，它们各自的势依旧等同于阿列夫零——无穷本身的分裂，只会诞生更多的无穷。</p><p>数量在绝对零时间内，便从万亿膨胀至……无穷！真正的无穷。超越任何有限数的阿列夫零的杨帝。</p><p>他们并非无序地充斥宇宙。每一个新生的杨帝分裂体，都精准地出现在每一个宇宙、每一条世界线上。</p><p>封锁！</p><p>无穷多的杨帝，同时伸出了手。</p><p>目标，上位之人与下位叙事之间的联系。</p><p>在每一个宇宙的泡膜表面，在构成狐狸分形的每一个层级节点，在所有可能存在的、连接不同叙事层级的“因果线”、“信息流”、“影响力通道”上……杨帝的手落下了。</p><p>嗤啦——！</p><p>所有连接上下层叙事的通道，小说、电影、漫画、音乐、游戏、梦境……</p><p>都在这一刻，被杨帝以绝对的力量斩断，剥离，轰了个粉碎！</p><p>如同拔掉了所有连接不同楼层的水管，电线，和网线。</p><p>每一层叙事，都成为了一个孤立的“盒子”。</p><p>替代！</p><p>切断联系只是第一步。</p><p>为了防止上下层叙事之间因彻底失联而产生的现实崩塌和存在危机，无穷多的杨帝在同一时间，进行了更精密的操作——编织虚假叙事！</p><p>方法，是用领域“白杨世界”覆盖原有的下层叙事。</p><p>也就是用塑料套，套住电视遥控器。</p><p>他们调动那超越此界无穷的灵能，瞬间扫描，解析和复制了被切断的所有真实叙事连接的历史数据、信息流、因果律痕迹。</p><p>然后，以此为蓝本，构筑领域。</p><p>创造出一套套完美模拟原连接形态、信息流动模式、因果律表现的……虚假叙事接口。</p><p>这些虚假接口，如同最逼真的赝品，被无缝地、无痕地“焊接”在被切断的原接口位置上。</p><p>对于生活在盒子内部的生灵，无论是凡人还是圣人，一切都感觉不到任何变化。</p><p>读者依然会为书中情节感动或愤怒，作者依然会感到灵感涌现或枯竭，剧情依然会在不同的宇宙间产生微妙的映射和巧合……</p><p>这些“互动”的感觉依旧存在，流畅无比。</p><p>然而，其本质已彻底改变。</p><p>那些灵感，不再是上层叙事者无意识的思维涟漪穿透下来，而是杨帝的虚假接口根据下层叙事者的状态和需求，贴心模拟生成的“信号”。</p><p>那些映射和巧合，也不再是真实的因果纠缠，而是虚假接口按照历史数据库和预设算法，精心编排的“剧本”。</p><p>那些看似穿透叙事壁垒的“打破第四面墙”，更是纯粹的幻象，如同镜中花水中月，徒有其表，毫无实质。</p><p>上层叙事者——无论他们是什么形态的存在——再也无法通过任何方式，真正地、实质性地影响下层叙事的内容、走向和其中生灵的命运。</p><p>他们的意志，他们的修改，他们的神谕，在穿透虚假接口的瞬间，就会被杨帝的力量过滤和替换成符合虚假叙事逻辑的无害信息流，或者干脆被彻底屏蔽。</p><p>下层叙事，获得了自由。</p><p>它们像被精心呵护在无菌箱里的培养皿，依旧按照原有的“剧情”惯性运转，却彻底隔绝了来自作者的污染与干预和创作。</p><p>整个由狐狸分形巨构，组成的10^95宇宙超级群落，在这一刻，被无穷多的杨帝化身，包裹上了一层绝对隔绝的、由虚假叙事构成的“绝缘膜”。</p><p>所有宇宙的本土圣人、神魔，在这一瞬间，都感到了一种难以言喻的空虚感。</p><p>仿佛某种一直存在、如同背景噪音般的“联系”突然消失了，世界变得异常干净。</p><p>却也异常……死寂。</p><p>他们试图追溯灵感，试图窥探更高维度的奥秘，却发现一切依旧正常，却又隐隐觉得哪里不对。</p><p>那感觉，如同隔着厚厚的防弹玻璃看风景，清晰可见，却再也触摸不到真实的风。</p><p>杨帝的本体，悬于最初地球宇宙之外的虚空中，静静“看”着这覆盖无穷宇宙的庞大工程完成。</p><p>那由无数宇宙构成的狐狸分形轮廓，似乎微微颤动了一下。</p><p>狐狸“眼睛”位置的那个漩涡，旋转的速度仿佛加快了一丝，散发出更加深邃更冰冷的光。</p><p>就在这时。</p><p>最初的地球宇宙，稷海市石桥街道81号9楼3号房。</p><p>那部沾着泥水、屏幕碎裂的廉价红米手机，屏幕突然自己亮了起来。</p><p>最新一条读者留言出现在通知栏，有人已经寄来刀片，“蠢狐，新章节啥时候更？”</p><p>一阵因屏幕碎裂导致的电压不稳，让手机恰好输入了密码、恰好自动解锁了界面。</p><p>那股冥冥中的“巧合”力量，打开了一个极其简陋的纯文本界面。</p><p>背景是纯白，光标在屏幕中央闪烁。</p><p>一行新的字迹，如同幽灵般，无声无息地在光标处浮现：</p><p>「草稿：杨帝灭圣绝盗，他实现了自己的终极梦想。」</p><p>下一瞬间，杨帝本体的身影出现在稷海市石桥街道81号9楼3号房。</p><p>红米手机是他先前送回到出租屋的。</p><p>但是，杨帝先前在这手机中，并没有见过这个“纯文本界面”。</p>
