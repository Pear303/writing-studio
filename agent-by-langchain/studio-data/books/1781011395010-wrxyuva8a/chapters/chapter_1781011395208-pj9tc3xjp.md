# 天生上位者

<p>就在众人惊疑不定，将目光聚焦在神秘男子身上时。</p><p>眼镜的战术目镜捕捉到了男子身下，压着的一个不起眼的异物。</p><p>“等等，那是什么？”眼镜小心翼翼地靠近，避开男子。</p><p>他从冰冷的地板上，捡起了一张边缘沾着些许灰尘的便签纸。</p><p>潦草！颤抖！力透纸背！每一个笔画都扭曲变形，充满了书写者濒临崩溃的恐惧和绝望。</p><p>墨迹被深色的污渍（也许是血迹？）晕染开，浸透了绝望的文字：</p><p>「门锁死红皇后她疯了」</p><p>「谁来救救不没有救了」</p><p>「让我想想别的美好的地方」</p><p>「草原」</p><p>「无边无际的绿色草原像毯子铺到天边」</p><p>「头顶是厚厚的铅灰色浓云」</p><p>「沉甸甸的压得人喘不过气」</p><p>「但是看啊」</p><p>「云裂开了一道缝」</p><p>「光金色的像熔化的金子从裂缝倾泻下来」</p><p>「就照在草原中央一个小小的隆起山坡上」</p><p>「那里是亮的是光明的」</p><p>「像无边黑暗大海里一座光明的孤岛」</p><p>「我想躺在那片光里」</p><p>「躺在光明的小岛上」</p><p>「没有警报没有红光没有腐烂和尖叫」</p><p>「只有暖暖的风吹过和青草的味道」</p><p>队长沉默地看完。</p><p>纸上描绘的景象——无边压抑的阴云下，一道撕裂黑暗、温暖纯粹的金色光柱，在辽阔草原上营造出的唯一一片充满生机的“光明小岛”。</p><p>带着一种凄美到令人心碎的强烈冲击力。</p><p>这显然是一位在蜂巢基地中饱受折磨，最终走向毁灭的研究员。</p><p>他在生命尽头用尽最后一丝力气，在绝望的深渊中为自己构建的精神避难所。</p><p>创建了一个世外桃源，一个美好的梦。</p><p>一个虚幻的、只存在于想象中的天堂。</p><p>轮回者们的心，被这遗言中最后一抹凄美的光狠狠攥紧。</p><p>就在这死寂的沉默几乎要凝固成冰的时刻——</p><p>角落里，那个被他们视为诡异“尸体”或“未知威胁”的赤身男子，毫无征兆地、猛地睁开了眼睛！</p><p>那眼神空洞得可怕，没有初醒的迷茫，没有对环境的惊惧，只有一片深不见底的虚无，仿佛两颗毫无光泽的黑曜石镶嵌在苍白的脸上。</p><p>“尸变？！”</p><p>“尸变个嘚儿，这是智械叛乱副本——这具尸体特么的是埋伏在这里的‘终结者’！！”</p><p>火鸦的神经一直绷在最紧的状态，对任何风吹草动都如同惊弓之鸟。</p><p>这突如其来的“诈尸”瞬间引爆了她过度紧张的神经！根本来不及思考，几乎是凭借无数次生死搏杀练就的本能，一把将离那男子最近的队长狠狠拽向身后，同时右手食指闪电般弹出！</p><p>一粒黄豆大小的橘红色火苗，如同子弹般激射而出，精准地射向男子赤裸的胸膛！</p><p>她的战术思路极其明确：</p><p>这粒黄豆大小的火苗，显然啥都做不到。</p><p>射完，就跑！</p><p>代价嘛……她会将仇恨拉到自己身上。</p><p>火鸦知道，自己的“火系异能”只有蛐蛐LEVEL 1，除了给队长点烟，其他都做不了。</p><p>拉嘲讽，是她为队伍所能做的最大贡献。</p><p>“火鸦！别！”队长的惊呼被淹没在火焰破空的细微嗤响中。</p><p>然而，预想中的金属撞击声，或者机器人愤怒的蜂鸣……统统没有发生。</p><p>那粒致命的火苗，毫无阻碍地落在了男子胸前那片仿佛融入黑暗的“衣服”布料上。</p><p>嗤——</p><p>一声轻微但清晰的燃烧声响起。</p><p>蛋白质烧焦时特有的糊味，和一丝诡异肉香的刺鼻气味，瞬间在狭小的维护间内弥漫开来！</p><p>那团覆盖着男子上半身的“黑色物质”，在接触到火焰的瞬间，如同浸透了油脂的棉布，迅速卷曲碳化，迅速变黑好吧本来就是黑的。</p><p>火焰甚至沿着接触点贪婪地向上蔓延了一小片，舔舐着男子裸露的皮肤。</p><p>“呃……烫烫烫……”仿佛从喉咙深处挤出的痛苦闷哼，从男子的唇缝间溢出。</p><p>他那空洞的眼神似乎微微波动了一下，但身体却僵硬得如同木偶，没有任何躲避或扑灭火焰的动作。</p><p>被火焰舔舐的皮肤迅速变红、起泡、焦黑。</p><p>这气味、这反应……绝对不是金属！</p><p>也不是任何已知的合成材料！</p><p>轮回小队所有人都愣住了，包括还保持着弹出火焰姿势的火鸦。</p><p>铁砣张大了嘴巴，足以塞进一个拳头：“操……活的？真……真烧着了？”</p><p>眼镜的战术目镜疯狂闪烁着微光，捕捉着男子的生理数据：“生……生命体征确认！体温急剧升高！局部组织严重烧伤！这……这真的是个活人？！”</p><p>“不，不一定是活人。”</p><p>“刚醒的铁砣，你有何高见。”</p><p>“他说了‘烫烫烫’，这和那段非常传统的乱码‘烫烫烫锟斤拷’如出一辙。所以，这显然是个机器人！”</p><p>“你是说他确实是终结者，但因为高温烧坏了处理器，所以开始报乱码？”</p><p>“显然如此。这是智械叛乱副本！”</p><p>就在这时，那个被火焰灼烧、发出痛苦闷哼的男子，目光似乎极其缓慢，极其艰难地，从一片虚无中挣脱出来一丝焦点。</p><p>他的视线，极其偶然地，落在了眼镜手中那张沾着灰尘和污渍的便签纸上。</p><p>他的嘴唇，极其轻微地翕动了一下。</p><p>一个带着气音，却异常清晰的词语，如同梦呓般，从他干裂的唇间溢出：</p><p>“……草……草原……”</p><p>“快灭火！”队长低吼，念动力瞬间发动。</p><p>他大手一挥，用万能的念力掐灭了男子身上的火焰。</p><p>“队长！你怎么……”</p><p>“他是活人，我看得出来。”</p><p>火焰被队长精准的念力掐灭，只留下男子胸前一片触目惊心的焦黑，以及空气中令人作呕的蛋白质焦糊味。</p><p>维护间内陷入诡异的寂静，只剩下众人粗重的呼吸和心跳声。</p><p>连一直瘫在角落装死的影子那团阴影，都似乎极其轻微地收缩了一下。</p><p>那半裸男子，似乎感觉不到胸口的剧痛。</p><p>或者说，他感觉到了，但毫不在意。</p><p>他僵硬如同提线木偶般，缓缓站直了身体。</p><p>火光熄灭后，他上半身那件奇异的黑色“衣物”被烧掉了一大半，焦黑的边缘卷曲着，露出底下同样被灼伤泛红的皮肤。</p><p>下半身那部分倒是相对完好，勉强遮住了关键部位，但也显得破败不堪，边缘处甚至能看到类似……碳化的纤维结构？</p><p>材质不明。</p><p>他就这样，近乎赤裸地站在众人面前。没有一丝一毫羞赧，也没有惊慌或试图遮掩的动作。</p><p>那姿态，坦荡得近乎诡异，仿佛人类最本能的羞耻心在他身上完全不存在。</p><p>队长莫名想到了一个野史：</p><p>在古典英吉利，辨别一个人是否是真正的公主，就看她当众脱衣服是否会害羞。</p><p>如果她会害羞，那么她就不是真正的公主；如果她不会害羞，那么她就是真正的公主。</p><p>因为真正的公主，一直有仆人贴身伺候，由女仆负责穿和脱衣服。</p><p>而公主是天生的上位者，从来不会将仆人视作“人”，所以也就不会害羞。</p><p>久而久之，便成习惯。</p><p>低道德优势不是乱吹的，哪怕带英的道德水平高一点，工业革命都得往后延几十年。</p>
