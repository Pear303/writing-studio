# 星环第一枢纽

<p>「欢迎乘坐星环公务专车∞-Ω-002，乘客杨帝。请系好本体论稳定器安全带，即将进行虚空航行。」</p><p>「目的地：星环盟约第一枢纽。预计抵达时间：四十二标准宇宙秒。」</p><p>「途中将为您播放入职引导音频：《论维持基准恒定的必要性与崇高性》节选，以及《新员工灵能安全操作规范》第三章：如何在驾驶公务专车时避免引发虚空涟漪……」</p><p>车窗外的光与影在透明舷窗上散开。</p><p>风景匆匆略过，像被孩童胡乱泼洒颜料，浓的淡的、亮的暗的，幻梦交杂，虚实难辨。</p><p>公务车大约行驶了几个小时，眼前苍茫无际的虚空，开始出星星点点。</p><p>他们重新回到了宇宙群密度较高的区域。</p><p>就像离开了一个狐狸形状的孤岛，驶过浩瀚大洋，转而扑进一片广袤无垠的大陆。</p><p>这片宇宙群，其规模远超耶罗分形区域。</p><p>无限机兵无声滑行，掠过无数宇宙泡影。最终，它精准地切入其中一个。</p><p>刹那间，景象剧变。</p><p>杨帝目睹无穷世界线如狂怒星河般奔涌、分裂、咆哮，又在宇宙诞生第42亿亿年的刻度轰然收束，万川归海，坍缩为唯一终点。</p><p>在那绝对终末的坐标上，矗立着一座设施。</p><p>它存在，却无任何可被感知的属性。</p><p>色彩、形状、尺度、质感……一切观测维度皆被否决。</p><p>非黑非白，非圆非方，非大非小。</p><p>它只是纯粹地蛮横“存在”于此，抗拒一切定义的企图。</p><p>「星环第一枢纽。」</p><p>无限机兵的中性声音响起，解答着这不可名状的景象。</p><p>「具备反叙事属性。其外在不可被感知，内在不可被描述。你的任何观测手段均已失效。」</p><p>那设施仅是沉默地矗立在时间尽头，如同一个自我完成的悖论。</p><p>杨帝眯起眼，努力看过去。</p><p>他只能知道这是一座设施，可能是一座建筑物，其余的属性一概不知。</p><p>杨帝又眨眨眼。</p><p>一种全新的感知，如同沉睡的器官骤然苏醒，开始在他存在的最深处蓬勃脉动。</p><p>这感觉其实一直潜藏，如同背景噪音般持续低鸣，只是他从未知晓该如何命名，如何调用这份官能。</p><p>在耶罗大仙将他修改成八九岁孩子的心智那几秒，他能感觉到，自己并不只是精神属性得到了提升。</p><p>第九种感知，第九识。</p><p>现在，在这绝对异质的“存在”面前，这第九感知被强行激活、凸显。</p><p>透过这模糊而汹涌的新视角，那不可名状的设施首次向他泄露了极其微小的信息碎片——他“感觉”到，那栋建筑并不是方的。</p><p>一个否定的认知，一个排除了某种可能性的微小坐标。</p><p>除此之外，关于它的色彩、质地、规模……一切依旧沉没在不可知的深渊里。</p><p>与此同时，窗外那伴随而来，由无数银色机兵构成的星辰海洋，随着世界线轰然收束为唯一终点，也发生了剧变。</p><p>它们在无数条世界线的收束中，也同时发生坍缩、融合，归复为最初那唯一的一辆银白色人形机兵。</p><p>它仿佛从未分裂过，忠诚地履行着引航者的职责。</p><p>这辆无限机兵平稳地驶向设施底部一个同样无法用常规几何描述的“凹陷”或“接入点”——若强行用旧有感知去理解，或许可称之为“停车场”。</p><p>它无声停泊，光滑的舱壁滑开，形成一个绝对契合的出口。</p><p>杨帝步出。</p><p>令他目光微凝的是，那辆银白色的无限机兵本身开始流动变形。</p><p>它的形态迅速收敛，棱角柔化，体积缩减，最终固化成一个约莫一米八左右、通体保持着哑光银白质感的人形轮廓。</p><p>它没有五官，没有发丝，只有流畅而简练的类人体态，静静地立在杨帝身旁。</p><p>杨帝看着这个银白色的人形物，一个自然而荒谬的问题脱口而出：“啊？你也要进去？”</p><p>那银白色的人形转过头，虽然没有面孔，但一种“注视”的感觉精准地落在杨帝身上。</p><p>与之前机兵形态毫无二致的中性声音直接响起，匪夷所思地反问：</p><p>「不然呢？难道你以为我只是辆公务车？」</p><p>它说完，不再理会杨帝可能有的反应，转身迈步，向着那并非方形、也无法被其他八种感知所捕捉的枢纽入口走去。</p><p>杨帝沉默地跟上。在这片连“空间”概念都显得可疑的区域，两个形态迥异的存在，一前一后，走向那拒绝一切叙事的庞大未知。</p><p>进入一栋建筑。</p><p>杨帝脚下是光洁得能映出人影的黑色石材地面，延伸向视野尽头。</p><p>四周是高耸的、由某种温润如玉的奇异物质构成的墙壁，墙壁上点缀着柔和的光带，勾勒出简约而宏大的几何线条。</p><p>头顶——那是一个巨大无比的、完全透明的穹顶。</p><p>透过穹顶，看到的并非璀璨星河，而是绝对吞噬一切的漆黑。</p><p>没有星光，没有一丝一毫的光源。</p><p>那是纯粹的虚无之暗，是“无意义时间”流淌至此彻底枯竭后的终极背景板。</p><p>这里是该宇宙的“历史终点”，42亿亿年所有波澜壮阔，爱恨情仇，文明兴衰最终沉淀，凝固和消逝的地方。</p><p>绝对的寂灭，是这里唯一的风景。</p><p>据说，此宇宙最终将毁于大撕裂。</p><p>虽说无限宇宙的每一粒尘埃，都蕴含着无穷灵能，但灵能毕竟不是看得见、摸得着的能量和质量。</p><p>灵能是表征“现实”丰度多少的指标，与可能性、概率、命运息息相关。</p><p>然而，就在这片象征宇宙终焉的绝对黑暗穹顶之下，却是一派……世俗的会议景象。</p><p>材质不明的长条形会议桌旁，稀稀拉拉坐着几个人影。</p><p>除了和杨帝一同走会议厅的银白色1米8无限机兵，室内还有另外三人。</p><p>左侧坐着三个状态叠加的虚影——生机、死寂、闪烁——强行坍缩在同一坐标，散发出令人不适的嗡鸣。</p><p>像是一种非常简陋的描述世界的物理模型：量子理论。</p><p>右侧是个披着华丽暗金长袍的疲惫外卖员，明黄制服上印着模糊字迹。一只银白狐娘从他椅背后探出，巨大蓬松的尾巴亲昵地缠在他脖子上，勒得外卖员偶尔翻个白眼，口吐白沫。</p><p>那狐娘有些生气地举起一个方形设备：“这里的WiFi忒差！”</p><p>更远处，一团绝对混乱的光线扭曲吞噬着周围，无法被定义或描述。只能从其轮廓，勉强看出似乎是个人。</p><p>银白机兵人形自顾自坐下，敲击桌面。</p><p>「生死渡劫主，和你一样是打不死的小强。」它指向叠加态。</p><p>「次元旅者，擅长远程投递灵能。」它指指黄袍和狐娘。</p><p>「寂无终焉形藏，很中二的名字对吧？但他是在场等级最高的，正处级。」</p><p>「坐下。你的入职会马上开始。」</p><p>外卖员打了个哈欠，狐尾收紧。叠加态嗡鸣。那团混乱无声地扭曲着。</p><p>杨帝看向唯一空座，正对那片不可名状。</p><p>他落座后，发现面前放着一瓶未开封的矿泉水。在场所有嘉宾，面前都有瓶矿泉水。</p><p>在场一共有9瓶矿泉水，但落座的只有8个实体。</p>
