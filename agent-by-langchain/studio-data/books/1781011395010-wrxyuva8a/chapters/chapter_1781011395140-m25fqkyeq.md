# 大帝杀死了自己？

<p>图书馆保安·天机子抚了抚斑驳的长须，充满智慧的眼珠亮起：“也有可能……是他在炼化渊水、对抗域外天魔时积累的暗伤，都集中在了到凡界喝水那一瞬间，才突然爆发开来。”</p><p>暗伤之说倒有几分道理！</p><p>五人明白，归墟大帝担负了很多。</p><p>经常在中学演武馆附近眯眼休息、时不时发掘几个天赋异禀但被其他人视作废柴的男子高中生、在江湖上留下许多传说但没几个人知道他相貌的老头「血手屠魔」，也点了点头。</p><p>老头·血手屠魔缓缓说道：</p><p>“诸位可还记得一万年前那场‘归墟炼化劫’？那时大帝孤身闯入虚无本源核心，试图将桀骜不驯的渊水纳入道统！</p><p>“我当时嗜血极了，以死也值回票价的决心跑到附近观战，见大帝的袍袖被撕成碎片，七窍不断渗出血，可他愣是硬抗下来呀！</p><p>“世人对大帝所知甚少，认为他炼化渊水，与喝白开水一样容易，殊不知他肉身与精神也需要承受极大伤害啊！</p><p>“很可能，暗伤就是那时留下的！”</p><p>学校老头儿说完，众人表示附和。</p><p>归墟是把双刃剑，如果驾驭好，个人力量确实能有质的提升。</p><p>但即使是大帝，狂饮三千瓢归墟渊水，体内也必定暗伤遍布。</p><p>到某一时间点，突然集中爆发，造成“在凡界喝水导致暴毙”的因果假象。</p><p>这，或许也是其中一个真相。</p><p>道观扫地僧·渡厄禅师在胸前画了个十字，低诵一声佛号：“阿弥陀佛。还有，归墟大帝曾以一己之力镇压黑暗不详，击退域外天魔……”</p><p>域外天魔每7200年降临灵界。</p><p>它们是灵界最大的天灾。</p><p>规模最庞大的天魔入侵，在一千多年前。</p><p>当时，灵界边界的天穹都被染成墨色，七十二座护界大阵接连崩解。</p><p>域外天魔军团似黑雾翻涌，所过之处，万物崩溃混乱，生灵扭曲。</p><p>大帝单枪匹马冲入魔潮。</p><p>天穹如熔金碎裂，归墟大帝周身灵力爆炸涌动，化作千万道星河垂落。</p><p>天魔只要触及，瞬间爆灭！</p><p>然而，域外天魔无穷无尽，又有数不清的魔影从虚空裂缝中蜂拥而出。</p><p>于是，大帝长啸一声，周身道韵暴涨，背后浮现出与天地同高的法相。</p><p>法相抬手间，灵界所有修士都感受到一股莫名力量涌入体内，而那些天魔则在这股威压下寸寸湮灭。</p><p>这场大战持续了七七四十九日。</p><p>最后一丝魔气消散，归墟大帝法相也缓缓消散，他踉跄着吐出一口鲜血，周身环绕的灵力也黯淡无光。</p><p>用渊水的力量补全灵界法则，修复六道，同时还要镇压域外天魔，费心协调灵界矛盾……</p><p>如此多方面的工作，心力交瘁。</p><p>就算大帝没有暗伤留于体内。</p><p>他也要因日理万机、日理亿机、日理兆机而累倒，提前光荣退休。</p><p>客栈掌柜·青丘白璃却说：“但是，我们并不知道，如果大帝级别的存在爆发暗伤，会有怎样的现象？我们已知的是，在大帝仙逝那天，凡界风平浪静，没有一丝异常。”</p><p>“包租……客栈掌柜的，您的意思是？”</p><p>妖族大能-客栈掌柜身子微微向前倾，两条狐尾如碇司令般托举着下巴：“大帝级别，虚无本源，归墟渊水——这仨标签，只要出现一个，都能引发千里范围的天地异象。更不用说，是在灵气浓度极低、只要有一点风吹草动就能被我们察觉的凡界。”</p><p>在灵界，充沛的灵气反而容易遮蔽修士的感知。</p><p>而在凡界，灵气的一丝一毫异动，都和黑夜中点燃的篝火那般显眼。</p><p>然而大帝陨落那日，凡界连风都没乱过。</p><p>“所以，是怎么做到，把本该震碎九重霄的动静，生生压成了哑炮了呢——？”客栈掌柜尾音拖得极长。</p><p>她用审视的眼光看向众人，屈指弹飞鬓边落雪，关上房间的窗户。</p><p>下雪了。</p><p>凡界此时是寒冬腊月，雪粒子簌簌砸在酒楼青瓦上。</p><p>包间内开了地暖，一盏明黄色挂灯，窗外是缓缓降下的夜幕与新雪，和大地上渐渐亮起的万家灯火。</p><p>凡界照常平静。</p><p>若非暗伤爆发，那么，又究竟是何等的力量杀死了大帝？</p><p>“可是，如果并非暗伤爆发而死，而是另有他人将其谋杀，同样也不应该如此安静。”</p><p>若真有人能对他痛下杀手……且不说这等凶手必然拥有通天彻地之能，居然能刺杀大帝。</p><p>单是行凶之时所引发的力量波动，又怎会不搅得天地风云变色？</p><p>试想，在地球上没有“氪石”的情况下，如何无声无息刺杀氪星超人？</p><p>酒楼内众人面面相觑，再度陷入沉思。</p><p>天机子摩挲着胡须，喃喃道：“难道是有绝世强者，甚至是隐世的远古大帝，掌握了某种极为隐秘、能隐匿力量波动的神通？”</p><p>青丘白璃·客栈掌柜又讲了一大串话反驳：“可这等神通，莫说在凡界，便是在灵界，怕也是闻所未闻。若是他杀，凶手定是算准了一切，包括大帝前往凡界的时机、如何悄无声息地动手。试问有多少人，或者说多少组织，有能力做到这几点？你我在场所有人经营的势力加起来，才能勉强做到吧？”</p><p>“哦灵宝天尊在上……难道是我们合伙杀害了归墟大帝？”</p><p>越是讨论，他们越是绝望地发现。</p><p>无论怎么看，归墟大帝都像是被他们合力杀害的。</p><p>道观扫地僧胸口画十，然后双手合十。</p><p>闭目沉思片刻，说道：“或许，这凶手并非来自灵界或凡界的任何人。”</p><p>众人看向那位光头和尚。</p><p>“诸位可曾想过，那些域外天魔虽被大帝击退，但难保不会有漏网之鱼，暗中蛰伏，寻机报复。他们所处之地，法则与我界不同，说不定真有办法在凡界无声无息地对大帝下手。”</p><p>老头·血手屠魔眯起眼：“你是说，域外天魔那群苟东曦跑下了凡界？”</p><p>域外天魔一般来自“灵界”的天外。</p><p>而凡界，被灵界罩着。</p><p>域外天魔如果打不过灵界的防守，而选择暗度陈仓，从侧路绕过去，潜伏在凡间……</p><p>客栈掌柜·青丘白璃轻轻摇头：“域外天魔习性残暴，行事张扬，若真是它们所为，即便能隐藏力量波动，也定会在事后留下些蛛丝马迹，以彰显它们的‘功绩’。”</p><p>如果是域外天魔，在干掉大帝后，它们应该更猖狂地开始杀戮盛宴。</p><p>屠城灭族只是顺手的事。</p><p>可如今，一切都太过平静，平静得让人觉得诡异。</p><p>“有没有一种可能——是域外天魔和归墟大帝，悄无声息地同归于尽了？”酒楼厨子说出一种很离奇的可能性。</p><p>这种可能性比狗舔完了锁的概率还要低。</p><p>“慢着，厨子，你怎么不去做饭？”图书馆保安·天机子发现盲点。</p><p>“对喔，我们已经在这儿做一个钟头啦，怎么一道菜都还没上？”客栈掌柜·青丘白璃也开始筷子敲碗。</p><p>“煮两碟酒酿豆腐，我出家人，不吃肉。”</p><p>“不吃肉就能喝酒了？”</p><p>酒楼厨子·中山无极只好站起身，向包厢外走去。</p><p>做饭……豆腐……煮豆燃豆萁……</p><p>他转过身：“大帝，会不会是自杀？”</p><p>“……为什么要自杀？”</p><p>“或许，活腻了？”</p><p>“你知道我们在3小时15分钟前就已经分析过这个可能性。结论是没可能。”</p>
