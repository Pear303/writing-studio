# 网课的最大受益者

<p>杨帝感觉到小腿发烫、抽搐。</p><p>那是修复中的肌纤维，像春雨后的竹笋般疯长。</p><p>这具身体正在进化的路上狂飙，路上没有限速标识牌，有没有减速带。</p><p>而他甚至不清楚进化的终点在哪。</p><p>胡彦卓掏出手机调出一张表格：“你的天赋实在没得说。看，三级运动员半马标准是1小时22分。你才练了六天就破了线，这速度堪比坐火箭，妈的。”</p><p>他脱口出一个语气词。</p><p>杨帝看向他手机屏幕上的表格。</p><p>二级1小时21分，一级1小时11分，健将级1小时03分。</p><p>爬塔升级，任重道远啊。</p><p>胡彦卓蹲下，食指重重按在他腓肠肌外侧。</p><p>杨帝又赶紧装模作样哎哟一下，假装很疼。</p><p>“更可怕的是你的恢复能力，正常人这种训练量，跟腱早就该肿得像法棍。而你，只是单纯的痛，说明韧性好得离谱。呱，你看这结实的muscle，肌纤维排列整齐，乳酸代谢快得反常，气味强而有力，简直像……像……”</p><p>他比划了半天，然后抬头，瞳孔收缩成两点星火，终于想到那个词。</p><p>“对，杨帝，你简直跟星际虫族一样扛造。”</p><p>虫族？他为什么要提星际虫族？</p><p>这是要把我解剖吗？终于开始毫不掩饰自己要把我送去非正常人类研究中心切成薄片的意图了吗……</p><p>杨帝后背瞬间沁出冷汗，正欲辩解，对方却话锋一转：“所以跟我学跑酷吧！”</p><p>“啊哈哈……胡大哥还会跑酷？”</p><p>对方已经不止一次提到跑酷。</p><p>注意到杨帝疑惑的眼神，胡彦卓犹豫了一刹那，苦笑着掀起运动服。</p><p>一道二十厘米长的疤痕蜿蜒在腹部。</p><p>“我确实会跑酷，但现在已经不怎么跑了。前年为了拍短视频涨粉，我打算搞个飞跃居民楼的视频，结果半空绊到电线摔地上，髋臼碎成七八块，之后便就退休了。”</p><p>他放下运动服，杨帝望着他重新变得挺拔的身姿。</p><p>自己拼尽全力无法战胜的“路人”，居然还是个髋关节动过大手术的有疾人士。</p><p>他摩挲着疤痕，眼神却愈发炽热：“杨帝，虽然跑酷容易骨折，容易摔瘫痪，容易摔死……但是！你可知跑酷能激活深层肌群，练出猎豹般的动态视觉，距骨前突比常人长两三毫米，好处多多！”</p><p>杨帝看了眼胡彦卓髋关节处，二十厘米长、若隐若现的蜈蚣状疤痕。</p><p>跑酷太危险，就一周前他还只是眼神清澈愚蠢的平凡华夏大学生呢，不跑不跑。</p><p>他斟酌着开口：“谢了，胡哥，其实……我更想找种能均衡发展，最好能同时锻炼全身肌肉，最重要是安全的运动，就像游泳，或者其他陆上的运动。”</p><p>刚说出来“游泳”这个词，杨帝都被自己吓了一跳。</p><p>某种潮湿的记忆从脑海深处泛起，他看见童年时那个在泳池底缓缓下沉的自己。</p><p>杨帝不会游泳……陪老爸在水库边钓鱼时差点淹死过。</p><p>当时他年龄还小，从未想过一条10斤重的大鱼，居然有这般力量，能把一个10岁小孩给拖下水。</p><p>幸好老爸天生神勇，硬生生将他从水库捞了起来。</p><p>各种科普告诉他，游泳是能够锻炼全身肌肉，综合性最强的运动。</p><p>划水动作锻炼手臂、肩部及背部的三角肌、背阔肌。打腿动作则着重锻炼腿部肌肉，主要是股四头肌、臀大肌……</p><p>但在此之后，杨帝很少去泳池了。</p><p>深邃幽蓝的水池，就算只有半米高、才刚刚没过膝盖，他也不敢碰。</p><p>只是看一眼，心头便浮起水库藻类滑腻的触感，耳道灌满的嗡鸣，反复被水淹没的视野。</p><p>童年阴影啊！</p><p>杨帝不自觉地用拇指掐住虎口，直到骨节发白才遏制住战栗。二十岁的身体，依然残留着十年前的肌肉记忆。</p><p>「精神+1」</p><p>而在对面，胡彦卓的瞳孔暗了暗，像被云翳遮蔽的月亮。</p><p>但他还是诚挚的给出建议：“游泳……确实是不错的，如果你想在陆地上找到类似的全身锻炼方式，可以试试一些自重训练组合。比如引体向上、俯卧撑、深蹲这‘铁三角’，它们能高效地刺激全身肌肉……”</p><p>不愧是专业人士，能给出很多听起来就挺靠谱的建议。</p><p>他一口气说了很多，最后有些不好意思地挠挠头：“嘴瘾犯了，不好意思啊……一遇到志同道合的人就喜欢夸夸其谈。”</p><p>胡彦卓又根据在田径场上看到的情况，对杨帝的跑步姿势、发力技巧做了些指点。</p><p>专业人士现场指导，都是很有用的。</p><p>杨帝能感觉，如果将错误姿势纠正过来，锻炼效率还能提高几个百分点。</p><p>「技巧+1」</p><p>“你真不学学跑酷吗？”</p><p>“不了不了，我还是游泳。”</p><p>杨帝汗流浃背，生怕不注意就入了邪道。</p><p>胡彦卓的跑酷技术后继无人，他看起来非常遗憾。</p><p>“这样吧，加个企鹅号，如果你想学跑酷了就来找我吧。或者你有体育专业其他方面的需求，我也能算是你的人脉了。”</p><p>杨帝扫了胡彦卓的企鹅二维码。</p><p>对方ID叫“退休跑手”。</p><p>头像是穿红色运动服、飞跃断桥的矫健身姿剪影，背景里歪斜的楼宇像被推倒的多米诺骨牌。</p><p>这似乎是对方已逝去的青春。</p><p>“跑酷基础教程.zip”立即出现在聊天框。</p><p>杨帝指尖悬在屏幕上空半寸，最终长按选择了收藏。</p><p>两个GB的大文件，跑酷基础教程，还是收藏在云端吧，到了有WiFi的地方再下载。</p><p>“有空来体育学院找我。”胡彦卓拍了拍他肩膀，然后便走了。</p><p>稷海理工虽然有“理工”二字，但事实上是一所综合大学。</p><p>校内不只是理工科的学院，还有医科，商科，文科，艺术科，体育科等。</p><p>各项设施齐备完全，连游泳池都有两个。</p><p>而稷海理工的图书馆建在湖边，落地窗外垂柳轻拂水面。</p><p>图书馆有免费WiFi可蹭，那里距离田径场不远，杨帝将胡彦卓发来的基础教程.zip下载。</p><p>压缩包解压后弹出三十多个视频文件，按动作难度从“落地缓冲”到“金刚跳”依次排列。</p><p>第一个视频开头是九十年代录像带特有的雪花噪点，画外音用带法语口音的英语讲述跑酷起源：</p><p>“Parkour不是征服障碍，而是理解身体与空间的对话。人体有206块骨骼，每个关节都是造物主预留的榫卯结构，奔跑时距骨在踝穴里滑动，就像钥匙转动锁芯，啪嗒——整个世界都是你的游乐场……这就是人体的魅力。而跑酷，就是对人体综合极限挖掘的艺术……”</p><p>讲解深入浅出，他竟一口气看了三个小时，实在是网瘾太深！</p><p>「跑酷+1」</p><p>霎时间，杨帝陷入诧异。</p><p>没想到这种重实践的技能，只是通过理论学习，也能增加熟练度。</p><p>这实在是有些过于玄幻了……他甚至没有在实践中形成肌肉记忆，就跑酷+1了？</p><p>但随即，他内心也狂喜起来。</p><p>——他似乎又找到一种高效、安全的“修炼”法门，那就是刷视频，理论学习。</p>
