# 大帝被包围

<p>大道又双叒开始哀鸣！崩碎！</p><p>灵能被蒸发成虚无，坚固的时空如同纸糊般层层剥离、粉碎。</p><p>煌煌帝威交织成毁灭的罗网，足以让任何至尊境以下的生灵瞬间灰飞烟灭千万次。</p><p>“吼——！”</p><p>就在这毁灭风暴的核心，一声震彻九天十地的长啸陡然爆发。</p><p>嗡！</p><p>一点纯粹的、深邃到无法形容的“黑”在风暴中心亮起。</p><p>那抹“黑色”，并非时空裂缝。</p><p>而是杨帝的黑发黑眸。</p><p>他脚踏虚空，每一步落下，都让混乱的时空为之震颤。</p><p>“居然没有把方圆百万光年的时空都打成齑粉，看来环境中蕴含的‘灵能’越高，现实本身就越稳定，越不容易被各种高能攻击、或者是灵能法术所影响。”</p><p>杨帝从捡起一块路过的野生陨石，一巴掌捏出核爆炸。</p><p>如果以相同的力度握拳。</p><p>在凡界，他能让周围十万里山河都笼罩在空气核聚变产生的火球中，让十里八方的老乡都是熟人。</p><p>但在灵界，杨帝这一巴掌仅仅相当于在凡界五千万吨TNT爆炸产生的效果。</p><p>看起来只是一颗沙皇氢弹的威力。</p><p>原本在凡界能够毁天灭地的攻击，在此地被狠狠压制，削弱成狗了。</p><p>也正是因为如此，大帝之间的混战，并没有将整片灵界毁于一旦，焚作焦土。</p><p>再加上他们并非在地表战斗，而是飞跃至不知多少光年外的“太空”中斗殴。</p><p>所以那颗行星的大好河山，倒也没有因此毁于一旦。</p><p>此界，不像凡界那样是大陆世界观，而是比较经典的宇宙世界观。</p><p>也就是遵守天体力学的那种。</p><p>超大质量物质，会在自身重力作用下坍塌成球形。</p><p>宇宙中各种天体，恒星，行星，中子星，乃至黑洞，皆由此取得比较标志的形体。</p><p>“灵界”并不泛指某颗行星。</p><p>灵界众仙其实已经步入宇宙级文明，他们的星舰一般将灵能者作为导航员，用蜂窝状的灵石作为飞船燃料，用星炬定位航向。</p><p>灵界人族、妖族、灵族三族合一，共同对抗宇宙边疆的域外天魔。</p><p>他们将一颗岩石行星作为“首都”天元。</p><p>在那里，留有先天神尊创世的痕迹——也就是归墟。</p><p>一般认为，归墟所在的行星，是宇宙中心。</p><p>现在，他们距离那颗行星很远，已经快抵达字面意义上的宇宙边疆了。</p><p>如果战况足够激烈，还是很有机会磨灭大道的。</p><p>“前辈们反手无力，正手不精，脚步松散，反应迟钝，就这？”</p><p>杨帝无视了空间裂缝的切割，无视了虚无本源的腐蚀。</p><p>他用自己纯粹肉体硬抗。</p><p>硬抗之后，就是反击了。</p><p>“来而不往非礼也！”他眼中寒芒爆射，右拳紧握。</p><p>无与伦比凶悍的动能，在他拳头上疯狂压缩、凝聚，化作一个沙煲大小的拳头。</p><p>“北斗神拳！！”一拳轰出。</p><p>没有惊天动地的爆炸，没有狂霸炫酷的声光效果，只有令人心悸的“毁灭”。</p><p>拳锋所向，无论是战狂大帝斩出的法则伤痕，还是溯洄大帝引动的时间乱流，抑或是归墟大帝操控的虚无游龙……</p><p>一切神通、法则、帝威，都在那拳印触及的瞬间，如同冰雪消融无声无息溃散、湮灭。</p><p>拳势余波扩散，将数位冲得最近的仙帝震得气血翻涌，帝袍碎裂，狼狈倒飞！</p><p>混战彻底爆发。</p><p>杨帝如同一尊行走于毁灭风暴中的太古神魔，在三十八位大帝的围攻中纵横捭阖！</p><p>他时而以肉身硬撼帝兵，发出震耳欲聋的金铁交鸣。</p><p>时而身化流光，在密集如雨的神通间隙中穿梭，留下一道道残影。</p><p>轰！轰！轰！</p><p>一次碰撞，便如同开天辟地的巨锤砸落！</p><p>“我嘞个豆！那位至尊被一巴掌拍成猪头！”远处群星之间，有人惊呼。</p><p>是那些被杨帝拍走的灵界真仙大能。</p><p>他们没有走远，一批接一批陆续回来了。</p><p>只不过都躲在远处观战，毕竟再嗜血再颠，也总得有个限度。</p><p>这种烈度的战斗，还是不要瞎掺和为好，远远地观战就好了。</p><p>他们在星云之中观战，在恒星背后观战，在黑洞与引力空泡之间的时空畸变区域观战，在璀璨群星之下喋血地观战！</p><p>……</p><p>三位准圣，亦在观战。</p><p>立于残星道人身侧稍后的位置，如同三座亘古不变的太古神山。</p><p>他们的目光穿透混乱的能量风暴，牢牢锁定着风暴中心那道不断闪烁、不断挥拳的身影。</p><p>其中一位身着玄黄道袍，面容古朴的准圣，眉头微不可察地蹙了一下，低声道：“此子的‘灵能’……诡异绝伦。非此界法则所能约束，亦非我等所认知的任何本源。其‘负’，非缺失，而是……另一种存在的‘盈’？”</p><p>另一位笼罩在星光中的准圣，眼中似有星河幻灭，声音缥缈：“他并未动用全力。更像是在试探，在适应。”</p><p>最后一位气息最为暴烈，周身环绕着混沌雷霆的准圣，冷哼一声，眼中战意升腾：“不论牛鬼蛇神，磨灭即可。”</p><p>“不过，关于这个白杨大帝，你们怎么看？”</p><p>“你看他在战场中的所作所为，他目的已经很明显了。”</p><p>“他是把我们当做‘磨刀石’了……”</p><p>“这是什么‘先天挨打圣体’？”</p><p>……</p><p>宇宙边疆的虚无战场，早已化作法则湮灭、能量沸腾的混沌熔炉。</p><p>三十八位仙帝、神皇、至尊的联手攻伐，足以让星河倒卷，让古界沉沦！</p><p>煌煌帝威交织成毁灭的罗网，每次与杨帝发生碰撞，都仿佛开天巨斧劈砍在混沌壁垒之上，发出震碎神魂的轰鸣。</p><p>杨帝的身影，在那足以瞬间磨灭亿万星辰的恐怖洪流中，非但没有显得渺小，反而如同一块亘古不灭的磐石，又似一头踏破洪荒的狂龙！</p><p>身形在法术攻伐中疯狂闪烁。</p><p>也许大帝能看清战场发生了什么。</p><p>但在那些躲藏在扭曲时空裂隙、星辰碎片之后，以各种仙宝秘术护体，勉强窥视战场的灵界真仙境大能眼中——</p><p>杨帝的动作，充满令人头皮炸裂的疯狂！</p><p>他像是化作万道幻影，疯狂闪烁。</p><p>“此子竟然如此能躲，难道是……先天泥鳅圣体？”有人惊叹。</p><p>“白杨大帝好帅。”有人犯花痴。</p><p>“在如此密集的攻伐下，居然万花丛中过，片叶不沾身。”有人赏析。</p><p>“嘶——！不对，非常不对劲！白杨大帝的动作非常不对劲！”一位须发皆张的老真仙，声音因极致的惊骇而嘶哑变形。</p><p>众大能看向他。</p><p>那是一位资深真仙境大能，扶持过许多初出茅庐的灵界大能，众人对他尊敬有加。</p><p>老真仙指着战场核心，眼珠几乎瞪出眼眶，“白杨大帝……他根本不是在躲！他是在……是在用身体接啊！！”</p><p>“什么？！”旁边一位妖族的真仙大能，九颗头颅同时倒吸一口凉气。</p><p>众大能反应过来，也同时倒吸一口凉气。</p><p>宇宙背景温度，仿佛都因此上升了零点零零零几开尔文。</p><p>“非但没有躲，反而是去接？”</p>
