# 磁场转动与独断万古

<p>“磁场力量……”</p><p>杨帝盯着那颗似乎正在适应现实、触须变得更加凝练活跃的黑球，若有所思地低语了一句。</p><p>他刚才那一拳并非毫无收获，拳锋接触的瞬间，他清晰地感知到那黑球并非纯粹的“现实丰度归零”。</p><p>而是存在着一种极其狂暴、混乱的……电磁场。</p><p>被抽走灵能的事物，可以是狸花猫，可以是麻雀。它“崩坏”之后，保留一部分原物体的形态，比如说猫猫哈气，比如说叽叽喳喳。</p><p>而能够被抽走灵能的事物，同时也可以是泥土石头，可以是电磁场。</p><p>而这只域外天魔，它的前身是一团不断震荡的“电磁场”。</p><p>电磁场也是物质。</p><p>观测到灵能归零的磁场，对其存在形态投去惊鸿一瞥，杨帝灵感大爆发。</p><p>他缓缓抬起右手，五指张开，对准了那颗正在尝试冲击59改信息屏障的域外天魔黑球。</p><p>没有惊天动地的气势爆发，没有绚烂夺目的光芒闪耀。</p><p>只有……</p><p>滋啦——某个细胞之中，分子磁矩集体发生轻微的变化。</p><p>一缕微小的磁力，正在体内游走，涌动。</p><p>这股力量，正在疯狂扩散。</p><p>一种令人窒息的、源自碳基生命最深层的恐怖力量，被强行唤醒、凝聚、并提升到了凡俗生命无法理解的恐怖能级。</p><p>以杨帝为中心，方圆数十米内的空气瞬间电离。</p><p>无数细小的、跳跃的蓝白色电蛇凭空生成，疯狂扭动！但这仅仅是微不足道的表象。</p><p>更深层的变化在微观层面发生！</p><p>“一百兆匹、磁场转动！！！”</p><p>百万亿级别的磁力线如同被投入了超高速离心机的狂龙，围绕着杨帝的手掌，以超越光速的极限频率疯狂旋转、叠加、共振！</p><p>狂！！！——空间哀鸣，时间扭曲！</p><p>那颗刚刚还不可一世、吞噬物理攻击的域外天魔黑球，瞬间如同被投入了宇宙级粉碎机的玻璃珠！</p><p>它体表盘桓的黑色触须在狂暴到极致的磁场转动下寸寸断裂、湮灭。</p><p>那深邃、仿佛能吞噬一切的黑球本体，开始剧烈地颤抖、变形。</p><p>构成它存在的、混乱的电磁场结构，在杨帝那精妙到超越物理法则、霸道到碾压一切的力量面前，脆弱得如同风中残烛。</p><p>“安静点。”杨帝的声音平淡无波，仿佛只是在教训一个吵闹的孩子。</p><p>他虚握的五指，轻轻向内一收。</p><p>嗡——仿佛宇宙琴弦被拨断的悲鸣响彻屏障内部。</p><p>在磁场转动一百兆匹的绝对伟力下，那颗象征着崩坏与绝望的域外天魔黑球，再也无法维持其形态。</p><p>它被强行压缩、坍缩、揉捏，最终化作一颗只有乒乓球大小、却散发更加内敛恐怖气息、漆黑如墨的能量圆球。</p><p>杨帝看也没看，随手将这颗由域外天魔“捏”成的能量球往嘴里一抛。</p><p>咕噜。喉结滚动，像咽下一颗糖豆。</p><p>嗝——</p><p>一声极其轻微、带着点电磁杂音的打嗝声响起，杨帝嘴角溢出一缕细微的、如同烧焦电线般的黑烟，随即消散。</p><p>悬浮平台上，死一般的寂静。</p><p>阿巴张大了鱼嘴，下巴都快掉到地上了。</p><p>杨帝咂了咂嘴，露出了一个在漫天金属尘埃背景下显得无比核善的笑容：“味道呕……你们吃过烧焦的蟑螂味保险丝吗，再浇上康复新液，就是那种恶心味道。”</p><p>“这……是什么力量？老大？”阿巴不太想讨论蟑螂的味道。</p><p>“用你无匹的意志力牵引体内磁场转动。”</p><p>杨帝开启“磁场视野”，看向天边某个方向，“嗯……野生的幕后黑手出现了。搞出一只域外天魔，居然还想跑？”</p><p>他看到了一团以电磁形式存在的……生命？</p><p>「分析确认。」</p><p>「是与个体‘天元神皇’组成形式相同的数字生命。」</p><p>「但目标的第一类量子活动，于大约10分钟前已停摆。」</p><p>59改冰冷的电子音响起。</p><p>他们找到已经死亡10分钟的，一具数字生命体残留的“尸骸”。</p><p>「对象已无活性意识波动。」59改说。</p><p>「其核心数据存储区域存在大规模、彻底的自毁痕迹。自毁程序执行得极其决绝，几乎是格式化级别的抹除。」</p><p>“尸骸？”</p><p>阿巴凑近了点，小心翼翼地戳了戳那团在空中被59改攥住的奇异电磁场，“活的死的？”</p><p>冷知识，生鱼片是死鱼片。</p><p>所以“尸骸”分生的还是死的，确实是有区分的必要。</p><p>「已经自杀了。已死的。」</p><p>“自杀？这年头的数字生命，咋这么流行自杀？”阿巴感叹。</p><p>先是炸薯条机和冰淇淋机，然后是这圆球存储器里的数字生命。</p><p>目前能够爱惜自己生命的，也就那个五百年前的天元神皇土皇帝。</p><p>青丘白璃想法很简单：“把域外天魔搞出来，这么大的事，畏罪自杀了呗。”</p><p>当然没狐狸小姑娘想的这么天真。这炸薯条机冰淇淋机，分明就是壮士一去不复返的死士。</p><p>杨帝：“五九，能撬开这‘棺材板’，看看里面还剩点啥‘遗言’不？”</p><p>59改无声无息地悬浮在他身侧，冯诺依曼自动机构成的护盾早已散去，只留下空气中淡淡的电离焦糊味。</p><p>「从冰淇淋机和炸薯条机自杀之时，本机便尝试进行熵减回溯。」</p><p>「但两个目标的生存欲望极低。而记忆信息回溯技术需要对方的配合，它们想死，我很难拦住。」</p><p>「但是现在，成功获取第三个样本——来自黑球存储器的数字生命。」</p><p>「虽然它的生存欲望同样极低，但样本数量足够多，我可以通过比对其残余的核心信息，勉强打捞出三者的一小部分信息。」</p><p>熵减回溯，并非简单的修复数据。</p><p>而是在数据的废墟和灰烬中，逆向推演熵增前的状态，捕捉那些被抹除信息残留的轮廓。</p><p>是一种触及热力学本质、更高层次的技术。</p><p>59改内部偶尔传出极其细微、如濒死叹息般的“滋……啪……”声。</p><p>时间在寂静中流淌。</p><p>「信息损毁过于彻底，仅能提取若干记忆碎片与逻辑片段。信息指向一个关键时间：凡界王朝槐安1644年。」</p><p>「该年份出现一个关键事件：阴伏流煞突然爆发。」</p><p>又是阴伏流煞，偏偏各地的历史、县志和文献中，都完全没有类似记载。</p><p>「三位数字生命对阴伏流煞的描述中，其无形无质，吞噬生机，所过之处草木枯朽、鸟兽成僵，凡人触之即疯。」</p><p>59改的声音罕见地停顿了几十秒，似乎在对比一个极其荒诞的巧合。</p><p>「其最初爆发点坐标……与青丘白璃阁下此前提供的、归墟大帝失踪前最后出现并‘喝水’的那个无名小铺坐标……基本重合。」</p><p>“蛤？！”</p><p>阿巴的鱼眼瞪得比灯泡还圆，“归墟大帝喝凉茶的地方，就是这什么‘阴伏流煞’的老巢？铺子老板卖的不是凉茶，是TMD灭世毒药吧。”</p><p>杨帝黑袍下的眉头微不可察地挑动了一下。</p><p>他缓缓托起那块红砖摄像机，对着下方城市那团仍在沉降、如同巨大灰色坟冢的金属尘埃云，又“咔嚓”一下。</p><p>然后，他慢悠悠地转过身，目光投向远方。</p><p>视线仿佛穿透空间，落在十万大山边缘、君士叹顶堡郊野的莽荒之地。</p><p>那里有一家凉茶铺子。</p><p>杨帝的超级智慧正在急速还原事件原貌：</p><p>……</p><p>槐安1644年，君士叹顶山峰边缘。</p><p>那地方与其说是“郊区”，不如说是文明与蛮荒之间一道模糊、渗血的伤口。</p><p>稀疏的村落点缀在瘴气弥漫的山脚下，一条勉强能容牛车通过的土路蜿蜒其中。</p><p>路边孤零零杵着那间低矮、破败的凉茶铺。</p><p>那一天，毫无征兆。</p><p>先是空气变得粘稠，仿佛吸进肺里的不是气，而是掺了铅粉的油。</p><p>它来了。</p><p>不是从天而降，也不是破土而出，更像是从空间的“皱纹”里渗出来的。</p><p>它黑得纯粹，仿佛宇宙诞生前的虚无被浓缩成了液体。没有反光，没有波纹，只有一种吞噬一切光线的的深邃。</p><p>“阴伏流煞”，它开始流淌。</p><p>无声无息，却带着一种无可阻挡的、近乎慵懒的扩张感。</p><p>像一滴巨大的墨汁滴入清水，只是这“墨汁”是活的，是饥渴的。</p><p>接触它的泥土，瞬间失去所有颜色和生机，化作一种灰败、酥脆的粉末，被它“吞”了进去。</p><p>路边的野草，前一秒还在微风中摇曳，下一秒就发黑、崩解成同样的飞灰，汇入那不断扩大的黑色潮水。</p><p>一只懵懂的山雀从树梢跌落，翅膀刚沾上一点黑色的边缘。</p><p>没有惨叫，没有挣扎，它的身体如同被按下了快进键的腐朽影片，迅速被转变成那一腔空荡荡的黑色面条团。</p><p>恐惧和死亡，如同瘟疫般在村民中炸开！</p><p>归墟大帝穿越光阴而来。</p><p>然后就是人民群众喜闻乐见的戏码：大帝踏过光阴长河，于过去横击未来敌，镇压黑暗不祥，背对众生，独断万古。</p><p>——他在喝白开水时突然消失，就是因为穿越了时间！</p><p>但世人并没有将他彻底遗忘，说明他并未完全死亡。</p><p>但直到此时，域外天魔从五百年前来到五百年后，大帝仍不现身，说明他可能身受重伤，甚至可能陷入昏迷状态，故无法回到现世。</p><p>但至少，他确实解决了500年前绝大部分的域外天魔灾患。</p><p>但仍然残留了些名为“阴伏流煞”的小尾巴，来不及剪除。</p><p>阴伏流煞，是一种“信息”，能够引发域外天魔的信息态存在。</p><p>其生态位类似于“十环禁术·质壁分离”，都是一种人为导致“灵能归零”的技术。</p><p>充满深深的恶意。</p><p>而且，还有几个以阴伏流煞为信仰的邪教信徒，似乎也穿越到了五百年后的现在。</p><p>但不知为何，变成了数字生命。</p><p>……</p><p>超级智慧主持的演绎推理结束。</p><p>“啊啊啊！我明白啦！我为什么直到现在才想到！”青丘白璃后空翻，兴奋叫道。</p>
