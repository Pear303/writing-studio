# 鱼尊补完

<p>（写太慢了是我的锅qwq有苦水的都在这一段倒一倒吧qwq就当是诉苦大会）</p><p>阿巴，这条承载着无数期待的月斑银鲈，这条深海大鲈鱼，完成了它的使命。</p><p>它被小心翼翼地，送回了那片它原本的栖息之所——大海。</p><p>它奋力摆动了一下，却只在水面划出半道颤抖的波纹，就被暗流卷进深海。</p><p>研究人员望着它逐渐消失的方向，沉默地摘下防护面罩。</p><p>咸涩海风混着灵能雾气扑在脸上，竟比预想中更冷。</p><p>“于探索未知、迈向浩瀚星空的征程中，我们沉痛悼念一位英勇无畏的航天先驱——阿巴，一条月斑银鲈……</p><p>“……当它完成使命归来，虽已奄奄一息，却仍试图划出生命的痕迹。最终，它被暗流卷入深海，消失在我们的视野，但它精神永远留在我们心间……</p><p>“……它用生命验证了可能性，让我们明白，每一次伟大的进步背后，都可能有着无法言说的牺牲……</p><p>“……如今，阿巴已回归大海，那是它最初的归宿，亦是它灵魂的安息之所。愿它在深海中得到永恒的宁静，而它所付出的一切，将永远镌刻在中土大陆探索宇宙的历史丰碑之上。”</p><p>中土大陆，南洋，深海。</p><p>阿巴没有直接死去。</p><p>它鳞片间残留的幽蓝荧光尚未褪去，随着下沉的动作，如星屑般簌簌脱落，引得周围的小鱼群好奇地游弋环绕。</p><p>没人，也没鱼注意到，阿巴体内掀起一场无声的风暴。</p><p>魔晶裂变的辐射仍然在轰击着它的基因。更准确而言，是轰击着缠绕在基因链上的“锁”。在黑暗冰冷的海水中，一股力量正在它体内酝酿。</p><p>阿巴继续下沉，周围的水压逐渐增大，可它却浑然不觉。</p><p>体内那股由魔晶裂变辐射激发的力量，如沉睡巨兽渐渐苏醒，肆意地改造它每一寸肌体。</p><p>原本小小的鱼鳃开始扩张，鳃丝变得坚韧而粗壮，能够从海水中摄取更为复杂的质能。</p><p>骨骼在噼啪作响中不断重塑，愈发坚硬，硬度逐渐超过花岗岩、玄武岩、深板岩……</p><p>鳍也在发生着惊人的变化，边缘生出尖锐锯齿，鳍条之间有灵能闪烁，强大的能量在汇聚。</p><p>阿巴的身体急剧膨胀。</p><p>原本只有巴掌大小，灵动的身姿，变得如虎鲸庞大。</p><p>深海之下，它缓缓睁眸，散发出红光。</p><p>双眸犹如两团燃烧的火焰，令那些原本好奇的小鱼群惊恐地四散逃窜。</p><p>阿巴停止了下沉。</p><p>它摆动了一下尾巴，那股力量便在海水中掀起了巨大的漩涡，周围的珊瑚礁被轻易地搅碎，附近的小型海底山脉也出现了裂缝。</p><p>力量。</p><p>平生以来，月斑银鲈的宿命只有被吃掉。</p><p>但在此刻，阿巴掌控了自己的命运。</p><p>思想。</p><p>鱼，原本应该是浑浑噩噩的。它们的生理结构虽比史莱姆复杂得多，但与最基本的智慧生物比起来，仍然相差甚远。</p><p>阿巴摆动着已然无比强壮的身躯，迅速向南游去。</p><p>它所经之处，海水被劈开，形成一道幽深的轨迹。</p><p>周围海洋生物感受到这股强大的压迫力，纷纷远远避开。</p><p>为什么向南——它感受到那边有强者存在。而强者，是会相互吸引的。</p><p>她从小就是吃核辐射长大的，根本不怂。</p><p>火箭上的辐射泄露，则是促成进化的最后一根火柴。</p><p>力量，思想。</p><p>刚刚突破基因锁的鲈鱼，尽管身怀强大力量与最基本的思想，但仍然对这新奇的世界尤为陌生。</p><p>阿巴来到南海某处无名岛礁。</p><p>此处距离中土大陆南岸，2000公里。</p><p>阳光透过海水，洒在礁岩上，形成一片片斑驳的光影。岛礁上，存在强者气息。</p><p>它缓缓靠近，硕大无朋的身形在浅海处若隐若现。</p><p>阿巴看到了一个人类骑士。</p><p>巴德，他正与美丽的人鱼公主在礁岩的一处浅湾中，享受着宁静幸福没羞没臊的时光。</p><p>巴德那身曾经在战场上闪耀的银色铠甲，就这么摆在沙滩边，如今已少了几分锐利的杀气，多了些岁月沉淀的温和。</p><p>昔日讨伐巨龙的圣骑士，此刻脸上洋溢着满足的笑容，与人鱼公主促膝交谈，偶尔伸手轻抚人鱼公主那如海藻般的长发。</p><p>自从100年前讨伐巨龙成功，圣骑士巴德因为一口龙息，受到重伤，进入濒死体验。</p><p>濒临死亡的走马灯时刻中，巴德重新经历了一生，突然想到自己还有个遗憾未解——当年他试图和美人鱼私奔，结果见家长时，被对方的岳父赶走。</p><p>美人鱼，那可是美人鱼！</p><p>可恶的封建大家长，竟敢毁我梦想。</p><p>而大地上的世人也一知半解，居然把可爱的美人鱼称作塞壬，到处传唱，说我击败了什么海妖海怪。</p><p>都错了。</p><p>巴德是真心喜欢她。</p><p>而现在，卡利斯托巨龙已被讨伐，大地恢复安宁。在可预见的十年百年，王国将走向昌盛，文明将步入繁荣。</p><p>乱世已去。</p><p>新世界里，也没他这个武夫什么事了。</p><p>所以，趁现在实现自己的梦想吧——这次不见家长了，再和那位人鱼公主私奔一次，躲到南海一处无人岛礁生活，不成功便成仁！</p><p>他成功了。</p><p>代价是，世人都以为他在那次战斗中牺牲，只留下半截碳化指骨什么的。</p><p>其实那是巨龙的尾椎骨啦。根本不是人类植骨，只是形状长得比较像，体积又刚好差不多。</p><p>阿巴的出现打破了这份宁静。</p><p>它巨大的身躯从海水中猛然探出，溅起数十米高的水花。</p><p>巴德警觉地将自己弹射起来。</p><p>多年征战培养出的本能，让他瞬间进入戒备状态。</p><p>圣骑士几乎是在阿巴现身后0.1秒内握住身旁的长剑，尽管心中充满了对眼前这个庞然大物的震怖——</p><p>这条鱼，特么的五百米高。</p><p>看品种还是条鲈鱼！鲈鱼长这么大！这世界果然已经步入不可名状的癫狂。</p><p>那条深海大鲈鱼，盯着人鱼公主，看了半小时。</p><p>公主终于忍不住开口说话了。</p><p>——公主嘛，能和各种小动物交谈……“大”动物也行。</p><p>“您、您有何贵干？这位女士？”她小心地说着，防止话里哪个字眼激怒眼前这条鲈鱼，毕竟人形动物和鱼形动物思维结构差异比较大。</p><p>“阿巴阿巴。”阿巴勉强说出了第一句话，这也就是她的名字由来。</p><p>阿巴并没有什么恶意，她只是被强者的气息吸引而来。</p><p>在往后的日子里，一人一鱼一人鱼把日子过好，岁月静静流淌。</p><p>巴德与人鱼公主日夜没羞没臊，阿巴则在一侧旁观学习。</p><p>她渐渐补完了常识，和各种知识，包括灵能法术的使用，与人交际的礼仪，还有这片大地上的漫长历史。</p><p>人类生命是有极限的。</p><p>圣骑士巴德于第四纪元2185年睡梦中逝世，享年284年。</p><p>人鱼公主发现已经失去气息的巴德时，他手中紧握一枚略带锈迹的银质玫瑰徽章。</p><p>他在生前总是对这枚勋章念念叨叨，说这勋章是他初入骑士团时，团长亲手授予他的。</p><p>还有什么见证荣耀与伤痛，伴随英雄冲锋陷阵斩杀邪恶，寄托着他与战友的羁绊，云云。</p><p>但很可惜，那枚勋章大抵是遗失在了屠龙战场中，巴德始终找不回来。</p><p>而圣古琉斯的圣光教廷，也没有相关的遗物记录。</p><p>但现在，它回来了，就这么出现在刚刚逝世的骑士长手里。</p><p>人鱼公主只能将一切归于冥冥天意，还有圣光的护佑。</p><p>但在场并非无人目睹这一切，并非无人（或者说无鱼）知道真相。</p><p>在潮湿的阴影里，某条非人之物以非人的感官见证了银质玫瑰勋章的降临。</p><p>是的，阿巴感知到了。</p><p>尽管那是转瞬即逝的极短时间。</p><p>十环级魔王鲈鱼——阿巴的鱼鳃剧烈翕动。</p><p>她心肝胆肺却几乎要被吓破了。</p><p>那是一个人形玩意，灵能水平……高得突破天际！！</p>
