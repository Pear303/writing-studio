# 关于耐杀性的构思

<p>“……当你的身体记忆超越意识，才能听见重力在时空中弯曲的声响。跑酷技术基础教程到此结束。”</p><p>10个小时，2GB的跑酷基础教程视频，杨帝终于全部刷完了。期间触发5次「跑酷+1」，6次「视力+1」。</p><p>果然用手机看视频还是挺伤眼的。</p><p>他将手机插回兜里，拉上拉链，站起身来，膝关节发出轻微的爆响。</p><p>全身骨骼，筋络和肌肉束都跃跃欲试。</p><p>他已经很想跑一通了。</p><p>这种迫切的渴望，仿佛是刻于骨髓深处的本能：人习得一项本事却从来没有实践过，总感觉心头痒痒的。</p><p>类似于人拿着锤子，看谁都是钉子。</p><p>口嫌体正直啊。今早在胡彦卓面前，杨帝还拒绝过跑酷拜师的，现在却要去偷偷跑起来。</p><p>按照舍友张明远的说法，他就是大卷币。</p><p>杨帝活动着发麻的脚踝，想起那截被爬山虎吞没的废弃旧校区。</p><p>那里人少，而建筑多，杨帝决定就去那里试试身手。</p><p>稷海理工的老校区，就藏在镜湖对岸，上世纪的红砖建筑爬满爬山虎，废弃的廊桥下堆着建筑废料。</p><p>此处被废弃，说法是年久失修，发生过危楼坍塌事故。</p><p>而且自来水管道也总是时灵时不灵，隔三差五就有几十上百个师生投诉。</p><p>像每一座废弃的学校建筑一样，此地的都市传说也经久不衰，流传久远。</p><p>比如说软件楼三层的脚步声传说，学生公寓地下室水龙头间歇性出现的“血水”。</p><p>不过，事后揭秘都表明，这些所谓都市传说是有科学依据的。</p><p>比如说，软件楼采用上世纪60年代特有的空心预制板结构，热胀冷缩效应明显。</p><p>接缝处产生的微小位移经空心结构放大，最终形成类似皮鞋叩击地板的1.5kHz声波频率，恰好在人类听觉敏感区间。</p><p>学生公寓地下室的血水更容易解释。</p><p>老校区给水系统仍在使用镀锌钢管，停水时管内形成负压，导致管壁氧化层剥落。</p><p>地下室很少人用，偶尔有人过来，然后打开了水龙头，就能品尝到一段新鲜的氢氧化铁红褐色悬浊液。</p><p>但相较于科学理性的解释，还是都市传说比较有市场。</p><p>毕竟，毕竟，人对未知与神秘的渴望，远远超过对平淡科学真相的追求。</p><p>如果神学能帮助牛顿预言股票走势，他大抵是不会发明出经典力学和微积分的。</p><p>因此，此处除了那些神秘学爱好者拿着撬棍来探索、还有小情侣来幽会之外，基本上没有几个人造访。</p><p>趁夜色，杨帝来到此处。</p><p>在废弃校区的铁门旁，杨帝掏出手机看了眼时间，20点47分。</p><p>杨帝来到铁门前，正对着门卫室。</p><p>门卫室的灯还亮着，里面坐着一个五十多岁的保安，正看着手机。</p><p>他头也不抬地对杨帝说：“同学，这么晚了，你来这儿干什么？”</p><p>“我……”</p><p>“知道了，不能进。”</p><p>“我还没说……”</p><p>“前年有人在里边摔断屁股，上周又有俩作死的崽子翻危楼摔断腿，现在连只野猫都别想溜进去。回去回去。”</p><p>“好好好，我走。”</p><p>杨帝余光扫过保安身后，瞅见亮着红点的监控屏幕，六块分屏里有五个对准这片区域。</p><p>第六个黑了一片，似乎是摄像头坏了。</p><p>不错，还是有路的。世上本没有路，摄像头坏了，也便有了路。</p><p>杨帝走过旧校区外围。</p><p>他的直觉如野兽般敏锐。</p><p>因为看了整整一上午加一下午的手机屏幕，杨帝视力在短时间内被拔高到一个很高的层次，他现在已不需要戴近视眼镜，能在无路灯的夜晚看清20米开外的事物。</p><p>他轻而易举便发现闪着红光的摄像头。</p><p>外围共发现六个摄像头，其中一个没有闪烁红光，和他在保安亭里见到的情况符合。</p><p>在损坏的摄像头下方，他从铁丝网缺口钻了进去。</p><p>踏入旧校区，一眼便看到那栋被爬山虎完全包裹的主教学楼。</p><p>像是人类消失后，留下一地砖瓦水泥，高屋建瓴，二三十年重新被大自然占领的模样。</p><p>据说切尔诺贝利也是这个荒芜景象，那座因为核泄漏而被迫撤空的城市，已经重新成为荒野的俘虏。</p><p>大楼上窗户黑洞洞的，似是矗立于路两边的沉默的巨人。</p><p>月光将钢筋骨架的阴影拓在瓦砾堆，便构成了天然的障碍跑酷训练场。</p><p>杨帝记忆自动过了一遍跑酷动作，纵跳、蹬壁上墙、猫挂……非常清晰，历历在目。</p><p>“感觉我也要成为跑酷奇才了！”</p><p>他首先找到面一人高的小矮墙，对着斑驳的墙面屈膝，脊柱如弹簧般压缩。</p><p>视频里那个法国教练说，人体重心应该在腰子前突……位置，双腿应该……发力。</p><p>杨帝的视线正在自动拆分环境。</p><p>“剥落的水泥块可以是踏脚点。歪斜铁管构成稳固的三角支撑。墙缝滋生的苔藓易打滑，不能踩，大危特危。”</p><p>明明是第一次跑酷，却能感觉自己像个跑了半年的老手。</p><p>他助跑几步，脚尖轻点地面，借力跃上走廊的栏杆。</p><p>栏杆有些生锈，发出嘎吱嘎吱的响声，杨帝并未停顿，反而加快了动作。</p><p>他双手撑在窗台上，一个漂亮的蹬墙动作，身体如灵巧的猎豹般腾空而起，落在了二楼的窗台上。</p><p>「跑酷+1」</p><p>这个提示在脑海亮起。</p><p>杨帝意识到，自己完成了“猫挂接反身蹬墙”动作，跑酷标准动作。</p><p>在实操过程中，他当然也有所收获。</p><p>视频无法教会的，是起跳时小趾侧屈肌的微妙震颤的四种作用，某块筋骨拉扯时的六个注意要点。</p><p>还有各种因为视频画质不清，而无法完全展示的小细节。</p><p>杨帝回过神来。</p><p>“牛逼！欸痛痛痛……”一股巨大的痛意卷上心尖。</p><p>他猛回头，窗台的玻璃早已破碎。</p><p>再低头一看，玻璃渣子将他手掌扎出七八个血洞和伤痕。</p><p>按照这几天经验，大概需要三四个小时才能痊愈了。</p><p>「锐器耐性+1」</p><p>杨帝心头划过这般奇妙的感觉。</p><p>锐器耐性……？这也能+1+2+3？</p><p>杨帝只是思索两秒便释然了：“锻炼”的本质是损伤→超量代偿，被热水烫到，被玻璃渣子伤到，也算是一种“损伤”。</p><p>所以会有耐热、耐锐器。</p><p>尽管已经感慨过很多次，但杨帝还是想说一句“真玄幻啊”！</p><p>简直像小说主角一样的离奇遭遇。</p><p>平心而论，作为还没活够的年轻人，杨帝还是挺怕死的，这是很正常心态。</p><p>被玻璃渣子伤到、被热水烫到、跑酷途中摔到关节或者摔断其他的杂七杂八的四肢百骸、五脏六腑……</p><p>杨帝意识到一件重要的事情：</p><p>除了锻炼力量，强壮体魄，还应该锻炼「耐杀性」，成为一个非常耐杀的华夏好青年！</p>
