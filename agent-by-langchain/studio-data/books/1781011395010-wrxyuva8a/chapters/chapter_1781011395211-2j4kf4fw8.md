# 智械大战丧尸

<p>“都是像那只猫的血肉之怪物？！”</p><p>“不应该呀，这应该是智械叛乱副本……”</p><p>“但那只猫为何如此诡异？怎么看都不像是机器猫。”</p><p>“难道是仿生皮肤，人造肌肉……？”</p><p>轮回者小队开始有一句没一句讨论起来，当然，讨论归讨论，他们的身体早已行动起来，准备着跑路。</p><p>杨帝做到房间门前，打开气密闸门。</p><p>众人的呼吸咽在支气管，沉默刚刚涌上心头，随即被喉咙中喷出的怒火焚尽：</p><p>“杨帝！！你在做什么？！！”</p><p>“如你所见，我在开门。”杨帝的声音平淡无波，仿佛只是推开自家后院的门。</p><p>厚重的气密闸门被他单手推开，发出令人牙酸的金属摩擦声。</p><p>“该死，你会把它们引过来的！全员准备战斗突围！”</p><p>他们并没有打算将门关上，因为所有还醒着的人都注意到了——这门应该是拉开才对。但杨帝是推的。</p><p>眼镜手腕上的微型探测器发出刺耳的蜂鸣，战术目镜被代表高威胁的猩红警报信息刷屏。</p><p>“队……队长！”</p><p>眼镜的声音因为极度的惊骇和荒谬而扭曲变调，“热源和生物信号……太多了！走廊两侧！左右各一百个！正在高速接近！距离我们……不到三十米！”</p><p>“完犊子，竟然左右都有，被包饺子了！”</p><p>“准备死战！”队长目眦欲裂，念动力场催发到极致。</p><p>他们仿佛已经看到两侧走廊尽头涌出铺天盖地的恐怖血肉怪物，或者冷酷无情的杀戮机器。</p><p>然而，当那两股洪流终于冲出走廊拐角，暴露在昏暗应急灯光下时。</p><p>——轮回小队众人，包括刚刚被吓醒又差点被这数量吓晕的影子，全都愣住了。</p><p>左边走廊涌来的，是一支……极其“廉价”的机械部队。</p><p>领头的是几个被改装得面目全非的扫地机器人底盘，上面用粗铁丝和胶带捆着几根挥舞的机械维修臂，臂端焊接着菜刀、螺丝刀甚至消防斧，活像一群长了机械臂的暴躁金属乌龟。跟在后面的则是一些关节发出“嘎吱”怪响的简易人形支架，显然是用仓库搬运机械臂，临时拼凑的“步兵”，它们手里拿着激光焊枪、高压水枪和切割锯。</p><p>而右边走廊冲出来的，则印证了他们最坏的猜想——是“人”，或者说，曾经是人。</p><p>他们穿着破烂不堪的研究员白大褂或保安制服，皮肤呈现出死尸般的灰败或诡异的紫黑色，肢体扭曲变形，有的手臂异化成利爪，有的脊椎刺破皮肤形成骨刺，有的下颌撕裂到胸口，露出森森利齿。</p><p>两股截然不同，却同样致命的洪流。</p><p>在轮回小队所在的维护间门口狭小的T型走廊，交汇了！</p><p>战斗，瞬间在轮回小队眼前爆发！但目标不是他们。</p><p>嗡——！</p><p>一道高功率激光束，从某个搬运机械臂改装的“步兵”手中的焊枪射出，精准命中一只飞扑而来的丧尸头颅！</p><p>噗嗤！</p><p>没有鲜血四溅，那丧尸的头颅如同被强光照射的蜡像，瞬间碳化发黑，然后在一阵轻微的爆裂声中，化为飞溅的焦黑碎块。</p><p>“吼！”</p><p>一只力量型的丧尸，猛地撞飞一个挡路的简易机器人，金属支架瞬间散架。</p><p>激光切割、能量灼烧、金属撕裂、血肉破碎、骨骼折断、腐液腐蚀……</p><p>各种刺耳的声音和刺鼻的气味混杂在一起，构成一幅地狱图景。</p><p>“所以……所以……”</p><p>“这根本不是什么智械叛乱副本，而是生化危机？！”</p><p>噗！噗！噗！</p><p>几声沉闷的爆响。走廊上几只狰狞的丧尸，整个身体连同身上的污秽，瞬间被碾碎。</p><p>看起来，“拼好械”机器人部队这边优势比较大。</p><p>机器人的激光武器对付移动相对缓慢、防御力有限的丧尸效果拔群，只要不被近身淹没，就能持续输出。</p><p>灵活的火鸦趁乱捡了几块碎片回来。</p><p>一小块丧尸的焦黑组织样本。</p><p>“原来第一条走廊那儿的人类丧尸碎片，是这么来的。”</p><p>“是红皇后主控AI，控制了机器人部队，对那条走廊上的丧尸进行了肃清。”</p><p>“所以这是一场丧尸危机，红皇后叛乱是为了遏制丧尸的扩散。”</p><p>“但总觉得好像忽略了什么关键要点。”</p><p>“……那只哈基米，难道是什么特殊变异体丧尸？”</p><p>就在这时，眼镜的战术目镜捕捉到上方通风管道口的轻微震动。“队长！上面！有动静！可能是被战斗吸引过来的东西，也可能是……别的路！”</p><p>众人抬头，只见天花板上一个不起眼的角落，还有第二个通风管道的格栅。</p><p>“不能待在这里了！”</p><p>队长当机立断，“混战随时可能波及我们。即使大战结束，也难保的那方会不会对我们不利。眼镜，扫描那个管道口！快。”</p><p>眼镜立刻将目镜对准上方。</p><p>“结构扫描……管道直径勉强够单人通过，内部暂时未发现明显热源或生物信号，方向似乎是绕过核心区域侧翼。”</p><p>“好！就它了！”</p><p>队长指着那个通风口，“火鸦，烧开它！铁砣，准备托人上去！眼镜，你第二个！影子……算了，我把她绑身上带上去！快！”</p><p>火鸦抄起一支路过的野生撬棍，将通风管道的栅格撬开。</p><p>铁砣扎稳马步，双手交叠成梯。眼镜第一个被托起，钻进管道口，战术目镜的红光在黑暗中扫视前方。</p><p>“队长！安全！暂时！”眼镜的声音从管道里传来。</p><p>“火鸦，你上！铁砣，自己上！”</p><p>队长命令道，同时用念力将依旧昏死的影子卷起，固定在背上。</p><p>狭窄，黑暗，弥漫着灰尘和机油味的管道内，众人暂时获得了喘息之机。</p><p>就在这时，他们看到下方的杨帝抬起了头。</p><p>经历了刚才那场血肉盛宴和捏爆丧尸的恐怖景象，小队成员对杨帝的恐惧和忌惮已经达到了顶点。</p><p>这个存在太诡异、太强大、太不可控了！</p><p>跟他待在一起，比面对外面那两百个怪物还要让人心胆俱裂。</p><p>更远处，还隐隐约约传来非人的嘶吼。</p><p>他们看见，另有几十个像之前的“哈基米”一样面目狰狞、脑袋裂成八瓣了的生物，从走廊远端冲来。</p><p>“杨……杨帝先生，感谢您之前的援手。”</p><p>队长说，“但接下来的路，我们恐怕……需要分头行动了。您之前出来的那个通风管道，哈基米已经被您解决了，那条管道现在是安全的！您可以从那里离开……去您想去的任何地方。”</p><p>去你想去的任何地方。</p><p>因为你有力量。</p><p>而我们没有。</p><p>他既没有点头，也没有反对，只是沉默地站在那里，像一尊不属于这个地狱的黑色雕像。</p>
