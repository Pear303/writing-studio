# 仙界

<p>在阿巴的摇晃中，杨帝那只一直垂落在冰冷地面上的的手，极其轻微地抽搐了一下。</p><p>动作细微得如同秋叶飘落。</p><p>其动静，在周遭一众炼气期巅峰强者、半步筑基大能们毁天灭地的能量轰鸣，和歇斯底里的咆哮声中，几乎可以忽略不计。</p><p>然而，时间仿佛在这一刻被投入粘稠的502胶水。</p><p>那狂暴肆虐、将教室化作混沌熔炉的仙光魔气、雷霆冰霜，骤然凝滞！</p><p>如同奔腾咆哮的江河，在抵达悬崖边缘的刹那，被一股无法抗拒的伟力，硬生生冻结成了静止的冰雕……</p><p>飞扬的尘埃、碎裂的纸屑、迸溅的碎石……</p><p>一切运动的物质，都诡异地悬停在半空。</p><p>所有声音，被一只无形大手瞬间扼住喉咙，掐灭在喉咙深处。</p><p>深入骨髓的恐惧。</p><p>所有人，都只剩眼珠可以勉力转动。</p><p>所有人的目光，带着一种源自灵魂本能的战栗，死死地、不受控制地转向同一个方向——</p><p>教室最后方，那片狼藉的角落。</p><p>他们感受到纯粹的“能量”威压，其数值在字面意义上突破天际。</p><p>大道的运行，都要略微为杨帝让步。</p><p>仿佛整个宇宙运行的法则，都在此时此刻被强行改写和冻结。</p><p>杨帝缓缓地，坐直了身体，站了起来。</p><p>众人看到他的眼睛。</p><p>那是一双怎样的眼睛？</p><p>没有神光爆射，没有威压外放。只有一片……深不见底的虚无。</p><p>漆黑，纯粹的黑，如同宇宙诞生之前最原始的混沌。然而，就在那无边无际的黑暗深处，骤然亮起了光！</p><p>是破碎的星河！是燃烧的星云！是坍缩的黑洞！是爆炸的超新星！是无数个纪元生灭、亿万星辰破碎又重组的壮阔图景！是万物走向最终大热寂的悲凉与孤寂。</p><p>有开天辟地的巨人轰然倒下，有撑起苍穹的神树被拦腰斩断，有填平星海的巨眼在血泊中哀鸣……</p><p>无数辉煌到极致又破灭到彻底的景象，在那双深邃的瞳孔里一闪而逝，最终归于一种俯瞰万古轮回的……</p><p>极致的平静。</p><p>然后，杨帝冷笑地说话。</p><p>“呵……”</p><p>“……灵界诸位真仙大能，昔日叱咤风云，如今竟如同与柴犬争屎吃那般，为了一张准考证、一处风水宝座，而不惜大打出手，斗殴起来？”</p><p>高考，对你们来说是如此快乐的事吗？</p><p>你们把此届考生都当成了什么！</p><p>他顿了顿，目光似乎穿透了教室的墙壁，穿透了江城二中的校园，越过此界的大好河山，投向了另一个半球、灯火阑珊的城市。</p><p>投向这片被归墟大帝、残星道人称为“仙界”的天地。</p><p>什么嘛，这不还是行星世界观。</p><p>和自己想象中的仙界有些大不同。</p><p>哦，还有归墟大帝……</p><p>他算是个可怜人吧，被吃人不吐骨头的老钱占了便宜。不过，也有小部分原因是咎由自取。</p><p>杨帝目光最终落回手中那本被踩了一脚、沾满灰尘的《五年高考三年模拟》。</p><p>“……参加高考？”</p><p>“你们到底为什么想参加高考？”</p><p>“准考证人人都有，而后排靠窗的座位，本身就是我的。”</p><p>“诶……诶？哦，我明白了，我把它当垃圾信息给过滤了，原来如此。”</p><p>杨帝来到仙界，记忆恢复后的一瞬间，大脑接收了无匹巨量的信息。</p><p>其中有一条藏在犄角旮旯，被他不经意间过滤掉的信息，似乎是由某个“圣人”级存在发出的。</p><p>「致18-22岁人类：」</p><p>「将于【随机时刻】启动本轮诡异入侵战争筛选，符合年龄范围的个体将以【概率抽取】形式参与。以下为核心规则，请务必牢记：」</p><p>「规则即生命线。场景内会通过【纸条、广播、NPC低语】等形式发布规则，严格遵守可保安全，违反将触发【未知后果】（包括但不限于角色消失、认知扭曲、物理湮灭）。」</p><p>「所有参与者【物理死亡】或【意识被规则彻底扭曲】，无任何存活个体可执行【规则破局】操作，将触发【诡异永久侵占程序】……」</p><p>「……」</p><p>这个世界，确实不正常。</p><p>高考，就是18岁到22岁的人，第一次接触诡异副本。</p><p>没想到“仙界”，或者说“蓝星”，生存环境如此险恶。</p><p>“白杨……白杨大帝？”一个带着无尽惊恐和难以置信的颤音，从牙缝里艰难地挤出。</p><p>是班长，那位凌云圣皇。</p><p>他那张俊朗的脸上，此刻只剩下扭曲的惨白和极致的恐惧。</p><p>他周身那曾经堂皇璀璨、象征至高神圣权柄的金光，此刻像是狂风中的残烛，剧烈地摇曳、明灭，仿佛随时都会彻底熄灭。</p><p>他曾被认为，是灵界最接近“仙帝”的真仙极巅大能之一。</p><p>但人在屋檐下，不得不谦逊。</p><p>此刻，凌云圣皇终于想起来了，记忆终于回来了。</p><p>他们都目睹了杨帝，是如何与数十位大帝打得有来有回，如何硬扛三位准圣的领域磨灭，是如何承受灵茶山乂斧的创世级轰炸。</p><p>如今，这战力爆炸的怪物跟来了。</p><p>……不对，当时就是这“战力爆炸的怪物”带他们逃出升天的。</p><p>嘶……记忆有些残缺零散，跟不上现状。</p><p>隔一段时间，才能零星回想起什么。</p><p>像是数据传输过程中的信号不良……</p><p>总之，对“白杨大帝”的恐惧，已经深深刻在一众真仙境大能的基因和模因中。</p><p>其他人也纷纷记起了痛。</p><p>玄冰尊者周身寒气疯狂倒卷、回流——这才是真正的倒吸一口凉气！</p><p>雷罚天尊指尖的电光早已无影无踪。他原本还想用硬币对某人来一发电磁炮！</p><p>整个教室，死寂得如同宇宙坟场。</p><p>他们这些所谓的圣皇屠魔，在他面前，与蝼蚁何异？方才的争抢、狂妄、大打出手……此刻回想起来，是何等的可笑与亵渎。</p><p>特别地，还是在抢杨帝的考试座位！</p><p>冻结时空的伟力，如同退潮般悄然散去。悬停在空中的尘埃碎屑簌簌落下。凝固的能量光芒缓缓熄灭、消散。</p><p>杨帝微微弯腰，在满地狼藉废墟中，捡起一支沾满灰尘的钢笔。</p><p>笔身是那种最普通的黑色塑料，已经磨损得露出了底色，笔帽上的金属夹子也锈迹斑斑，甚至有些歪斜。</p><p>一支在任何一个文具店，花几块钱都能买到的廉价品，丢在地上都不会有人多看一眼。</p><p>可杨帝的目光，却在这支破旧的钢笔上停留了一瞬。</p><p>「无良印品」</p><p>“居然和地球上的品牌完全一样。而且这世界的文字，嗯……非常标准的简体汉字。”</p><p>他拈起这支生锈的钢笔，塞进同样沾满灰尘的校服口袋。</p><p>杨帝没有再说什么。</p><p>身影穿过凝固的人群，在无数道惊恐、敬畏、复杂至极的目光注视下，平静地走出后门，消失在走廊昏暗的阴影里。</p><p>教室，那片被凌云圣皇和血手屠魔争夺、蕴含所谓“龙气”和“杀气”的座位区域，此刻空荡荡的。</p><p>「叮铃铃……」</p><p>清晨七点半，江城二中校园内，往日催命般刺耳的上课铃声。</p><p>「叮铃铃……」</p><p>「是我没法像戏内那些 主角，」</p><p>「为你为爱让气力也都 花光，」</p><p>「遗下 每段情话 就算吧～」</p><p>“等等，不对……”</p><p>有人发现了盲点。</p><p>“上课铃声……怎么会是Pandora乐队的最新专辑？？”</p><p>“这学校我记得没那么潮流啊……”</p><p>“布豪！都是假象！是此界的特殊灾难——诡异降临！！”</p><p>……</p><p>阿巴正要去垂向杨帝，她突然僵住。</p><p>记忆，汹涌如潮的记忆，正在挤入她身为智人的狭小大脑中。</p><p>是她从小鱼苗，修炼至万古鱼尊，这亿万年来的全部记忆，全部爱恨情仇，全部喜悦与恐惧……</p><p>她天生臃肿，自幼就有成年人类的体型。</p><p>阿巴能追溯到关于自己最古老的记忆，就是她满月时，正在高高兴兴吞噬核辐射，突然就诞生灵智了。</p><p>现在看来，在她“出世”一个月前，自己其实是性转版的杨帝克隆体，是个正版的人类。</p><p>杨帝也许对自己做了许多惨绝人寰的实验，最后在他操纵下，阿巴化形为鱼。</p><p>在深海中游荡，并且取得智慧……</p><p>古怪的是，亿万年来的修行技艺和经验，并没有因为她现在这具身体降格为“炼气期”，而把大脑挤爆。</p><p>……似乎是因为“仙界”的灵能水平贼高。</p><p>连带着此界的普通物质，都能够承载灵界真仙大能级别的灵能。</p><p>按照灵界经验，结合自身体感，粗略估算，环境平均灵能水平至少有，嗯“真仙境”打上。</p><p>也就是说，仙界的人一出生就有真仙修为。</p><p>但因为周围环境的灵能丰度也极高，所以，这个世界的人并不会表现出现实扭曲特质。</p><p>但仙界任何一个普通人，来到灵界，都能和阿巴大战500回合。</p><p>可恶，果然出生比努力更重要吗！</p>
