# 单刷烂尾楼

<p>大厅一团糟，像是被洪水刷洗过的成龙家具城，能看到一地黏腻黑色的积水，可疑的蚊虫在其上游走。</p><p>虽然门是锁着的，但窗户敞开，没有装防盗网。</p><p>路过的人如果好奇，翻窗也很容易进来。</p><p>水泥天花板都快被泡烂了。</p><p>稷海位处神州南端，天气很是湿润，潮湿的天对建筑物破坏力很强。</p><p>而这栋烂尾楼稀烂的排水系统，更是让情况雪上加霜。</p><p>空气里浸满饱和的水蒸气，水泥支柱、承重墙上都铺满了厚厚一层苔藓。</p><p>楼房中央是一处电梯井，但还没来得及安装电梯，大楼就烂尾了。</p><p>电梯井底部也被黑色积水淹没。</p><p>那是一口完全看不到底的黑水潭子。</p><p>透过浑浊水面向下望去，杨帝的倒影也在注视杨帝。</p><p>被积水浸泡了这么多年，不知道水下有没有生物。</p><p>现在看来，应该是没有的，否则会招惹来外界的钓鱼佬。</p><p>他们对鱼的嗅觉，比鬣狗嗜血的渴望还要旺盛百倍。</p><p>在电梯井不远处，是一堆杂乱无章的建筑材料。</p><p>生锈钢筋歪七扭八地堆在一起，像是一堆扭曲的怪物肢体，表面附着铁锈，如同它们腐朽的外皮。</p><p>旁边几块破损的木板，半泡在积水中。木板上的霉菌肆意生长，形成一片片诡异的花纹。</p><p>烂尾楼的一角，有个简易工作台。</p><p>上面摆放着一些残缺不全的工具，锤子少了木柄，锯子的锯齿也已钝损变形，它们都被灰尘和铁锈覆盖。</p><p>工作台下，散落着几本早已湿透、纸张黏连在一起的施工图纸。</p><p>只能隐约辨认出上面模糊的线条和标识。</p><p>曾经精心规划的建筑蓝图，如今也同这烂尾楼一般，成为了未竟的残梦。</p><p>回到电梯井，抬头向上望去，空荡荡的缆绳在风中呼啸。</p><p>某层楼有个东西，探出半只苍白的手。</p><p>杨帝注意到它时，它嗖一声缩了回去。</p><p>“有人住这吗？没人的话，我来借宿两晚。如果有人，我也还是得借宿两晚。”</p><p>他朝着空荡荡的电梯井向上呼喊几声。</p><p>无人回应。</p><p>它似乎表现得很害羞，但也许是调皮，你懂的，小孩子和客人玩躲猫猫的那种心态！</p><p>杨帝将背后的撬棍抄下来，扛在肩上，从一旁的楼梯向上走去。</p><p>沿着楼梯不紧不慢向上走着。</p><p>楼道里弥漫着一股潮湿腐朽的气味，每一步都能听到鞋底与积水接触发出的“噗嗤”声。</p><p>楼梯的扶手布满了锈迹，轻轻一抓，铁锈便簌簌落下。</p><p>来到刚刚那只手出现的楼层。</p><p>他借着从窗户透进来的微弱光线，看到电梯井前面只留下一些水渍，和一道水痕。</p><p>水痕延伸向一扇紧闭的门。</p><p>紧闭的门，代表拒绝。</p><p>“出来吧，我并无恶意。只是想找个地方借宿两晚。”杨帝再次开口。</p><p>声音在空旷的楼层里回荡，却依旧没有得到任何回应。</p><p>然而，他却隐隐感觉到，有一双眼睛正躲在门后，透过猫眼窥视他。</p><p>虽然那个东西，没有心跳和脚步，但杨帝还是想好好讲道理的。</p><p>他趴下，从最下方的门缝，向里面看去。</p><p>门缝下只有一片昏暗，除了些微灰尘在黯淡光线中漂浮，没有任何异样。</p><p>门后空间是一片死寂虚无。</p><p>杨帝眨了眨眼睛，想让视线更清晰些。</p><p>眨眼瞬间，一只眼睛陡然出现在门缝之后。</p><p>那是怎样的一双眼睛啊，眼球浑浊泛白，像是蒙了一层厚厚的翳。</p><p>却又在眼白之中，透着一抹诡异的青灰，死死地与杨帝对视着。</p><p>那双眼没有丝毫人类的情感，冰冷、死寂，仿佛来自另一个世界的凝视。</p><p>「精神+1」</p><p>他站起身来，拍拍身上的灰：“精神攻击？你先动手的哦，接下来我所做的是正当防卫。”</p><p>杨帝也希望“感觉一股寒意从尾椎骨瞬间蹿升至头顶”——他已经很久没品尝过“恐惧”这种心情了。</p><p>但就是怂不起来。</p><p>与耶罗大仙对视过后，曾经沧海难为水，除却巫山不是云，已识乾坤大，犹怜草木青。</p><p>他几乎忘掉了“喜悦”和“恐惧”。</p><p>「你要把它们当作磨刀石，把自己炼得更加锋利！记住，胜利永远属于善斗争的人……」</p><p>杨帝双手握住撬棍，往后退了几步。</p><p>高高举起撬棍，狠狠砸向门锁。</p><p>“轰！”一声巨响，腐朽的门锁在撬棍的重击下瞬间崩裂，木屑飞溅。</p><p>伴随着一阵刺耳的“嘎吱”声，门被这股强大的力量撞开，向内猛地弹去，重重砸在墙壁上，激起一片灰尘！</p><p>门后弥漫着一股更为浓烈的腐臭气息。</p><p>房间内摆满了各种奇奇怪怪的物件，破旧的桌椅杂乱地摆放着，墙壁上布满了密密麻麻、扭曲蜿蜒的水渍痕迹。</p><p>没有怪物，也没有人。</p><p>杨帝很失望，这意味着，这栋楼的住户或者是房东，并不太想和他协商住宿的事情。</p><p>他把门安装回去，回到走廊过道。</p><p>走廊两侧墙壁，像是被光阴啃噬过，墙皮大块大块地脱落，露出里面泛黄且潮湿的水泥。</p><p>偶尔还能看到几滩青苔，从裂缝中顽强地挤出，在昏暗里泛着幽绿的光。</p><p>杨帝手中紧握着撬棍，看似随意地走着，眼睛却时不时地扫过四周。</p><p>他路过一扇扇紧闭的门，它们像是沉默的卫士。</p><p>其中一扇门半掩着，随着从过道尽头吹来的阴风，发出“咿呀咿呀”的声音。</p><p>但这扇门并不欢迎他。杨帝走近时，它被风“砰”一声关上。</p><p>这层楼，只有一扇门是大敞开着的，就在走廊另一端尽头。</p><p>敞开的门是一种邀请。</p><p>杨帝挑了挑眉，朝着那扇敞开的门走去。</p><p>踏入房间，一股陈旧且带着微微酸腐的气味扑面而来。</p><p>屋内光线微弱，仅靠窗外透进来的丝丝缕缕光线勉强视物。</p><p>他将背上的行囊卸下，随意地扔在那张简陋的木板床上。</p><p>木板床发出一阵不堪重负的“嘎吱”声。</p><p>床看上去摇摇欲坠，仿佛稍微用力便会散架。</p><p>一旁摆放着几摞砖头，像是曾经有人试图在这里搭建些什么，却又半途而废。</p><p>杨帝挑选了几块品相好的砖头，放了七八块到自己包里，身上揣着一块。</p><p>这都是品相非常好的动能武器。</p><p>目光落在墙角那半瓶子坏掉的酒上。</p><p>玻璃瓶身布满灰尘，里面的液体呈现出一种浑浊的暗黄色，表面还漂浮着絮状物，散发刺鼻馊味。</p><p>他把玻璃瓶捡起来，打算找个地方扔掉。</p><p>杨帝出了房间，继续向上走。</p><p>经过的每一层，场景都大同小异。</p><p>破旧的建筑材料、发霉的墙壁，还有那挥之不去的潮湿气息。</p><p>偶尔能听到一些细微的声响，像是老鼠在暗处穿梭，又像是风从破碎的窗户缝里挤进来发出的呜咽。</p><p>五楼，通往楼顶的门半掩着，门后透出一丝微弱的天光。</p><p>踏上楼顶，眼前的景象略显空旷，四周的围栏有些地方已经残缺不全。</p><p>天台边缘，有一只手扒拉着水泥护栏。</p>
