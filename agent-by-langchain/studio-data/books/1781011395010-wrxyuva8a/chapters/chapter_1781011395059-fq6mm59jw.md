# 自我催眠

<p>如果将书籍的内容牢记在心，那么在梦境中翻阅书籍、理解吸收时，就能提示「知识 +1」的加成。</p><p>自己曾经落水并奋力挣扎过，那么在梦中的游泳经历，才会带来「游泳 +1」的提升。</p><p>小时候杨帝接受过紫外灯治疗，还照过CT检查脱臼，所以在梦中承受辐射时，才能触发「辐射抗性 +1」。</p><p>然而，如果仅仅观看过丧尸电影，但并未真正感染过丧尸病毒，那么在梦中被丧尸咬伤，并不会获得「生化 +1」的增益。</p><p>当然，因为他感染过其他病菌，所以免疫力本身非常强，若是真在现实里感染了丧尸病毒，也会有一定的抗性。</p><p>但终究，杨帝没有真实的“丧尸病毒感染”经历。</p><p>所以，无法获得“针对丧尸病毒”的相应能力提升。</p><p>“这就是我做梦的局限性——只能刷已知事物的熟练度，不能理解‘未知之物’的熟练度。”</p><p>“但是，换一个角度想。”</p><p>“只要我承受了一种新的伤害，就能在梦境中，持续锻炼到‘这种伤害无法对我造成任何锻炼效果’为止！”</p><p>刷数值的神机制啊！</p><p>杨帝用板砖打爆最后一只丧尸，终于通关了这个生化危机梦境。</p><p>“终于可以干正事了。”</p><p>除了用梦境学习，用梦境锻炼。</p><p>现在要个开发第三种功能——借助梦，来进行自我催眠。</p><p>他必须得将自己彻彻底底地骗过去。</p><p>与以往梦境试炼不同，在这过程中，最重要的便是抛弃理性，全身心地拥抱感性。</p><p>他紧闭双眼，开始在脑海中勾勒出一个光怪陆离的赛博朋克世界。</p><p>在最初的“场景构建”阶段中，杨帝模拟的场景是著名电影《银翼杀手》。</p><p>因为这部片子他刷了不下十次。</p><p>所以对里面的设定和细节，都比较熟悉，能够显著减少梦境建构的真实度。</p><p>眨眼间，杨帝置身于一座未来都市。</p><p>霓虹灯闪烁，高楼大厦直插云霄，空中飞车呼啸而过，川流不息。</p><p>街道上，行人与机械生物摩肩接踵，各种全息投影广告在空中交错闪烁。</p><p>但与普通赛博朋克世界不同的是——这里每一块屏幕，无论是街边巨大的广告荧幕，还是行人手持设备的显示屏，亦或是飞驰车辆上的车窗玻璃，都在滚动播放着同样的字幕：</p><p>“召唤一定能成功！”</p><p>路上所有行人同时停下手头的活，扭头看向杨帝：</p><p>“召唤一定能成功！”</p><p>月亮上没有投放蝌蚪可乐的广告，而是投影了另一句话：</p><p>“召唤一定能成功！”</p><p>声音和文字，如同咒语一般。</p><p>在这个虚拟的世界里不断回荡，一波又一波地冲击着他的潜意识。</p><p>杨帝选择赛博都市的原因，就是它能够容纳大量广告牌。</p><p>每个广告牌都替换成暗示词。</p><p>这种持续重复的信息刺激，利用了人的潜意识易受暗示的特性！</p><p>当同一条信息以高频次、全方位的方式不断涌入时，意识的防御机制就会逐渐疲劳。</p><p>三人成虎，三百人成龙，三万人齐声说同一件事，地球都能是方的。</p><p>这也是现代媒体和网络水军的传播学原理。</p><p>根据“议程设置理论”，通过单一信息集中轰炸，将“召唤一定能成功”设置为绝对核心议程，让杨帝的注意力高度聚焦于此，从而忽略其他可能干扰自我催眠的信息。</p><p>而且，这种全方位的信息传播，在赛博朋克的梦境中，形成一种“拟态环境”。</p><p>所有屏幕传递的信息，营造出一种“召唤成功是必然”的环境氛围。</p><p>杨帝身处其中，就如同在现实生活中受周围舆论环境影响一样。</p><p>不知不觉地被这个拟态环境所塑造。</p><p>他会逐渐相信“召唤一定能成功”这一暗示，进而达到自我催眠的目的！</p><p>……理论上应该是这样的。</p><p>「精神+1+1+1+1」</p><p>“……”杨帝有些无语，住了。</p><p>他没感受到任何催眠效果。</p><p>不知为何，自我洗脑似乎被自己判定成了“有危害的精神攻击”。</p><p>为什么会这样呢……？</p><p>“……没错，我以前也遇到过这种情况。”</p><p>杨帝一拍脑袋，似乎明白了：</p><p>他之前观看电影时，每当影片营造出极为强烈的情感氛围，或是展现出极具冲击力的画面与情节，他就会触发「精神 +1」！</p><p>还有聆听某些激昂澎湃、直抵灵魂深处的音乐时，同样也会出现这种情况！</p><p>每当他听着音乐，不自觉想要抖腿——潜意识中就会传来「精神+1」，然后豁免了这次抖腿。</p><p>电影和音乐，并不是攻击。</p><p>至少，不是常规意义上的“精神攻击”。</p><p>但它们都有一个共同点——强烈的模因效应。</p><p>“它们不会直接对人的精神造成狭义意义上的‘损伤’，它们是一种具有高传染性的模因。”</p><p>模因，简单来讲，就像是“文化传播中的基因”。</p><p>基因通过遗传传递生物特征。</p><p>而“模因”，则通过模仿，在人与人之间传播思想、行为和风格等文化信息。</p><p>简单来说，就是“梗”。</p><p>一部精彩的电影，能将导演想要传达的情感、价值观等模因，像病毒一样感染观众。</p><p>比如那些经典的电影台词——阿祖收手啦、点解霎时间会没水咧、马什么梅——常常会在观众之间口口相传，成为一种文化现象，这就是模因传播的体现。</p><p>而自己在梦境中构建的这种全方位重复“召唤一定能成功”的环境，其实也是在传播一种模因。</p><p>只不过，这种模因的传播方式过于直接和强烈，就像一股汹涌的洪流，试图强行冲破潜意识的防线。</p><p>潜意识察觉到这种不寻常的强烈冲击。</p><p>它便将其判定为“有危害的精神攻击”，从而触发了类似防御的机制，给予了「精神 +1」！</p><p>“保守派都觉得我疑似太保守了……”</p><p>杨帝不禁苦笑。</p><p>自己的潜意识，对于这类强大信息冲击的判定机制相当敏锐。</p><p>优点是让他很耐杀。</p><p>能够和耶罗大仙对视。</p><p>缺点是，以后很难能有“触动灵魂”的文艺作品了。</p><p>说不定，他还会变成一个“老古董”。</p><p>食古不化，无法接受新思想！</p><p>因为“思想文化”也是一种模因。如果传播性太强，也会被视作攻击，从而锻炼适应……</p><p>“得找到一种更温和、巧妙的方法，让模因能够悄无声息地渗透进潜意识啊……”</p><p>杨帝“啪嗒”一声打个响指。</p><p>他出现在一座图书馆内，周围书架上摆放着一千零八十本书。</p><p>G210 新闻学……G220 传播学……</p><p>他想到了《银翼杀手》中的“记忆植入”技术。</p><p>电影里，人造人被植入无比真实的记忆，这些记忆，深刻地影响着他们的行为和认知。</p><p>如果将“召唤一定能成功”的相关信息，以一种类似记忆的方式植入，或许能绕过潜意识的防御……？</p><p>“为自己植入虚假记忆吗？”</p><p>杨帝叹气，一不小心就走到人类文明道德伦理最前沿了，再往前一步，动辄万劫不复。</p><p>虽然连他自己都不知道，要如何给自己植入记忆！这完全是知识盲区。</p>
