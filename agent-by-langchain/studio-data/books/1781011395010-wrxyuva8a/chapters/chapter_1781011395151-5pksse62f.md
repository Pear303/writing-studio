# 直视真相！

<p>就像每个被甲方打回重做的乙方，59改只能重新调整这虚拟空间的承载上限。</p><p>杨帝看了眼自己的手心，又撑爆了别人的东西。</p><p>上次，还是青丘白璃的“领域”。</p><p>据说有些人直视古神之后疯掉，根本原因在于他们的脑子被古神传授的“知识”撑爆了，至死也装不下。</p><p>灵能……领域……撑爆世界……</p><p>「修好了。」59改简直就是神速力的化身。</p><p>他全面加固了虚拟会议厅，提供与那只数字生命相互通信的接口，还特别贴心地加装认知滤网补丁。</p><p>四人再次踏入重新构建好的虚拟空间。</p><p>杨帝这回小心翼翼，收敛着自己那如同汪洋般浩瀚的精神力量。</p><p>他在日常生活中，无论是与凡人交流，还是与太乙真仙谈话，都总结得自己就像一个手持利刃的莽汉，闯进一间摆满精美瓷器的屋子，略显拘促，总是放不开手脚。</p><p>阿巴在虚拟空间里的形象是条大鲈鱼。很肥美，鲜腴。</p><p>她摇头晃尾说话：“老大请您悠着点，再把这弄塌了，59改那铁罐头可就该罢工啦。”</p><p>杨帝看向其他人。</p><p>青丘白璃是法天象地的三十六尾超级狐妖大能。</p><p>59改是辆毁天灭地的二十五对负重轮超级战车。</p><p>和阿巴又肥又憨的虚拟形象完全不是一个画风。</p><p>杨帝看向自己，却发现竟是个五颜六色的蠕行之物。</p><p>自己的形体是由无数蠕动线条和闪烁不定的光斑随意拼凑而成，时而膨胀，时而收缩，表面的色彩不断变幻，却并非自然和谐的过渡，而是如噩梦般错乱，红得如鲜血喷溅，蓝得似幽冥寒渊，黄得仿若腐败的脓疮，这些色彩以堪称荒谬的方式交杂在一起，好似要将人的理智一点点剥离……</p><p>“59改，我在你眼中，难道就是如此恐怖而不可名状的存在？”</p><p>「差不多，杨帝阁下，因为您的存在，从前一个宇宙第一次见面开始，我已经死机超过五亿余次。」</p><p>「您的各项数值实在太高，已经超出了我所能正常观测和处理的范畴。」</p><p>「您散发出来的精神波动、灵能强度等诸多数据，一旦进入我的感知和运算体系，就会引发即使是宇宙级文明都无法解决的溢出错误。」</p><p>「不过在下需要声明一点——诸位在虚拟会议厅中的形象，并非完全由我所构建。」</p><p>「诸位用于展示的形象，有较大权重，是由您对自身的认知所决定。」</p><p>「包括万古鱼尊也是如此。」</p><p>阿巴的鲜美大鲈鱼形象，也是她对自己的认知。</p><p>“太棒了，我要的就是这个效果，五九改！”杨帝大声指出。</p><p>既然都把我当成不可名状的存在了，那就贯彻到底吧。</p><p>虚拟空间的“地面”流淌着液态数据的光泽，墙壁由不断重组的几何符号拼接而成。</p><p>在这片由59改重构的认知安全区中央，一个身影缓缓凝聚——</p><p>他头戴歪斜的电子冕旒，身披由乱码和过时电路图拼凑的“龙袍”。</p><p>他张开双臂，混杂着电流杂音和古怪方言腔调的声音，响彻空间：</p><p>“孤乃奉天承运，统御三界十方，万灵万民臣服，天元神皇！尔等凡俗之人，见孤为何不拜？！”</p><p>这夸张的登场让青丘白璃的三十六条虚拟狐尾都吓了一大跳。</p><p>“神皇？！帝临真一五大境，归墟大帝穷尽宇宙也只攀至第一境‘仙帝’顶点。传说中，帝临真一的第二境，才有资格尊号‘神皇’！难道这破盾构机里藏着……”</p><p>她声音带上惊疑。</p><p>但下一刻，她瞳孔的震动骤然停止，狐脸上露出一丝极其人性化的、混合着荒诞和鄙夷的表情：</p><p>“不对，从来没有大帝自称过天元神皇，或者被他人称为‘天元’。你是什么人？”</p><p>天元，是棋盘中央的点，在灵凡二界的棋道文化里，象征着正中、核心与起始。</p><p>在灵界诸多隐秘传说与古籍记载中，从无一位大能或大帝以“天元”作为尊号前缀，无疑是破绽百出。</p><p>因为有资格称为天元者，除了创世的“先天神尊”，另一个就是“帝临真一”第五境——圣人。</p><p>从来没有一个蛐蛐神皇，敢自称“天元”。</p><p>因为就连荒古时代的圣人，也从没有自称过天元。</p><p>「正在读取数据……检索到‘神皇’关键词关联地方志及民俗数据库……‘十万大山’解放前地方割据史料。」</p><p>59改实事求是求真务实，他已经黑进凡界王朝的数据库，调取了许多珍贵史料。</p><p>其中，自称“天元神皇”的土皇帝或者土匪头子，在凡界历史上共有过十几位。</p><p>但只有一位与“十万大山”能够扯上关联。</p><p>那是十万大山解放前，统治本地的土皇帝。</p><p>杨帝指着他鼻子：“搞了半天！你这‘神皇’，压根不是什么境界大能，而是凡界十万大山解放前，那些躲在穷山沟里坐井观天、鱼肉乡民的土皇帝！一个用辣椒硫磺熏死反抗者全家的土匪头子，盲眼骗子丁兴来之流，也配称神皇？”</p><p>“老大，丁兴来是谁？”</p><p>“这个不重要，我家乡的典故罢了。”</p><p>那自称天元神皇之人，身形一顿，似是被这质问打了个措手不及。</p><p>但他很快稳住身形，继续嘴硬。</p><p>“放肆！孤乃天命所归！孤之疆土，十万大山层峦叠嶂，子民百万，铜钱火铳皆由孤铸！”</p><p>那“神皇”的马赛克脸剧烈扭曲，试图维持威严。</p><p>杨帝那团不可名状的、由蠕动线条和癫狂色块构成的存在静静“注视”着这场闹剧。</p><p>祂（此刻用这个代词更合适）散发出的精神波动带着一种近乎怜悯的、无语。</p><p>祂伸出一根触须，轻轻点向那还在叫嚣“孤有后宫佳丽三千数据备份”的神皇。</p><p>嗡——</p><p>没有惊天动地的能量爆发，只有一层极其细微、几乎不可查觉的涟漪扫过。</p><p>那“神皇”华丽的电子龙袍如同被岁月瞬间风蚀，化作飞灰消散，露出底下锈迹斑斑、布满油污的盾构机核心控制模块的粗糙投影。</p><p>但在盾构机控制台上方，保留有一个中年男人的身体。</p><p>就像是一个人类，和一台盾构机强行糅合在了一起。</p><p>“天元神皇”的马赛克脸，凝固成一个惊恐的表情。</p><p>“怎么会，我怎么会长这个样子……”</p><p>那些他曾经坚信的“统治”“权力”，此刻如泡沫般破碎，露出残酷赤裸的现实。</p><p>他双目极瞪，马赛克脸上的惊恐愈发浓重，嘴巴大张着，发出一连串含混不清、尖锐刺耳的怪叫，仿佛是来自深渊最底层的嘶吼。</p><p>“不……不可能！我所看到的，什么……”</p><p>他正在目睹最禁忌、最不可名状的真相！</p><p>简而言之，十万大山土皇帝看到自己的模样后，突然理解了一切，随即就掉san了。</p>
