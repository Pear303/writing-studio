# 大帝、归来！

<p>一处贩卖山水豆腐花的小摊子，就跟你在街头巷尾常见的那些一模一样。</p><p>巴掌大的地儿，支着个破遮阳棚，那棚子的颜色早就被太阳晒得褪干净。</p><p>摊子上摆着几个铝制大桶，桶边坑坑洼洼，像是跟人干了好几架。</p><p>揭开桶盖，白花花、颤巍巍的豆腐花就露了出来，看着倒是鲜嫩。</p><p>摊主是个大叔，穿着件洗得泛白的背心，上面印着不知道啥时候的广告，估计连他自己都记不清了。</p><p>无靠背胶凳，折叠小木桌，唯一亮点是桌上摆放着的是搪瓷杯，而不是一次性塑料杯。</p><p>鱼尊阿巴、守望者59改尚未回过神来。</p><p>他们仍然在思考、在品味杨帝的“虚拟世界”推论。</p><p>他的“虚拟世界”理论，并不是说我们的世界是虚拟的，太恐怖了呀！</p><p>而是重点指出——现实世界和虚拟世界并无不同。</p><p>所以，也许我们可以用“虚拟世界”的运行逻辑，来研究“现实世界”中归墟大帝的死。</p><p>原以为，杨帝带他们来到此处，可能是心底对自己的“虚拟世界”理论也没有个底，想要最后再调查一番归墟大帝留下的蛛丝马迹。</p><p>阿巴他们后来才意识到，自己错了。</p><p>杨帝对自己提出的结论，始终极度自信。</p><p>杨帝他们来到此处，只有一个目的——见一个人。</p><p>归墟大帝。</p><p>他出现了。大帝就静静坐在那铺子边。</p><p>他出现得很突兀，正如三天前“喝水呛死”那般突然。</p><p>归墟大帝还活着，回到了此世。</p><p>他可能是死而复生，可能是诈尸。</p><p>也可能从来没死过，只是单纯失踪……总之大帝回来了，没带走、也没携来一片云彩。</p><p>那股突然出现的大帝级别强者气息，就来自“死而复生”的归墟大帝。</p><p>杨帝虽已提前数十秒预料到，但心中仍然翻起一道骇浪。</p><p>他迅速平抑住内心的一丝丝震惊，迅速动用大帝级别的感知，全力收集周围信息。</p><p>余光瞥见，周围的青丘白璃、阿巴同样露出数十倍于他的震惊之色。</p><p>现场最震惊的，不是已识巫山之云的杨帝，不是鱼尊和狐妖，也不是铁皮罐头·人形坦克·莫得感情的59改。</p><p>反而是归墟大帝本人。</p><p>大帝目视青丘白璃微微释放灵压，顿时，青丘白璃等人感到如芒在背，如山在背，如珠穆朗玛峰在背。</p><p>这个灵压……错不了。</p><p>是归墟大帝，本尊！货真价实童叟无欺，青丘白璃心中惊呼！</p><p>大帝生得一副远超凡俗的容貌。墨发如瀑垂落至腰际，面容轮廓分明如刀削，眉骨高挺，一双眼眸深邃若宇宙深渊。</p><p>他周身萦绕着难以言喻的王者气场，身上的气息时而如黑洞般吞噬一切声息，时而又像白洞般喷薄出沛然威压。</p><p>靠近他的人会莫名感到——灵魂被一股无形力量审视。</p><p>连心跳都要遵循大帝呼吸的节奏。当然除了杨帝。</p><p>失踪三日后，归墟大帝便莫名其妙回来了，回到了自己失踪前最后待的摊子。</p><p>他是……被世界“放逐”后，重新找到方法降低自己的“数值”，强行回到了凡界？</p><p>事情愈发诡异。</p><p>归墟大帝的目光直直地看向青丘白璃，和夕阳红旅行团的杨帝三人，眼神中满是疑惑，与浓烈的警惕。</p><p>警惕和疑虑，难掩瞳孔深处的惊异。</p><p>杨帝一眼便看得出来，归墟大帝并非单纯惊讶于青丘白璃等人的在场，更像是察觉到了杨帝的诡异存在形态。</p><p>“负灵能”，也就是和正常修仙者完全相反的、向内收敛的灵压。</p><p>如此诡谲的灵能水平，任哪位修仙者，路过都会朝杨帝多看两眼。</p><p>就好像道路上流浪的哈基米随处可见，凡人也视若无睹。但如果是一条狗骑电瓶车追一只母鸡、母鸡受惊飞起并下蛋恰好下到狗嘴里，那绝对是极度不常见的新奇事。</p><p>归墟大帝缓缓站直身躯。</p><p>手中青白色搪瓷杯轻轻晃了晃，里面残余的白开水泛起微微涟漪。</p><p>青丘白璃、阿巴和59改迅速作出战斗姿态。</p><p>大帝……他可是亲手释放了“阴伏流煞”。</p><p>谁也不知道，“死而复生”的他，还会做出什么恶行。</p><p>归墟大帝环顾四周，看着众人各异的表情。</p><p>他闭目，数秒，面部肌肉略过的几缕困惑，似乎陷入思索，又像是在查看什么。</p><p>随即睁眸，直勾勾看向杨帝。</p><p>“他把我当域外天魔了么？归墟大帝是彻底堕入魔道，想要拉拢我……还是要和我打一架？这可有点不妙，我若是与他交手，就不能保证这片半径30亿光年大陆的周全了。”杨帝寻思。</p><p>如果是战斗至宇宙边疆，那他可以放心地磨灭大道。</p><p>但这里是凡界，人口众多，杨帝不想随便动手。</p><p>下一秒，卖山水豆腐花的摊主大叔前来：“嘿，几位客人要不要来碗水灵灵的豆腐花嘞？用的是纯正山泉水制作，非转基因纯天然绿色无添加大豆，特别是像那位靓女吃了还能变得更白更嫩皮肤像豆腐一样……”</p><p>与此同时，豆腐花摊铺的音响开始播放《大碗脑花》。</p><p>「何必针锋相对你看……」</p><p>「相聚就要举起杯……」</p><p>二位大帝按兵不动。</p><p>归墟大帝首先目视自己熟悉的人——青丘白璃，不失威严地问话：“青丘白璃，为何如此慌张？”</p><p>“归……归墟大帝。”</p><p>青丘白璃深吸一口气，努力让自己不要说出“阴伏流煞”那四字。</p><p>她说道，“大帝，此事说来话长。在您消失的这段时间里，发生了许多超乎想象的事情。”</p><p>“消失？”归墟大帝眉头微皱，而后舒展。</p><p>他继续注视青丘白璃：“哦，没错，离开了一阵子。我‘消失’了多久？”</p><p>这是一句看似普通，实则信息量极其庞大的话。</p><p>杨帝的猜测，瞬间推翻了一半。</p><p>“虚拟”与“现实”之论暂时未能证明真假。</p><p>但归墟大帝，并不是因为修为超出世界承载上限导致“数据溢出”，而被动地遭到世界排斥。</p><p>他的失踪和归来，都在大帝自己的掌控内。</p><p>所以，他才会表现出成竹在胸的淡然神态，问话语气带着不容置疑的威严。</p><p>大帝早已洞悉一切，却故意引导众人揭晓答案。</p><p>青丘白璃：“三日。”</p><p>归墟大帝神色淡定：“没想到已过三日，不同世界的时间流速有差别，确实并非灵凡二界的特例啊。”</p><p>又是一句情报量爆棚的话。</p><p>“没想到已过三日”，这表明归墟大帝虽能掌控自身的失踪与归来，但对时间的流逝感知并不精准。</p><p>归墟大帝提及不同世界时间流速有差别，且“并非灵凡二界特例”，无疑暗示着，他是去了凡界和灵界以外，第三个世界。</p><p>归墟大帝将目光从青丘白璃身上移开。</p><p>他扫视着在场的众人，最后落在杨帝身上。</p><p>“你是何人？有何贵干？”</p>
