# 摇滚狐狸与真仙领域

<p>“青丘白璃女士，此处是何地？”杨帝礼貌。</p><p>青丘白璃怀抱琵琶，指尖轻捻琴弦，姿态宛如Nightwish乐队的吉他手般桀骜。</p><p>她与杨帝隔丈许对峙，眸光锐利如刀。</p><p>“此地乃本座领域——诛魔破阵，重、金、属、版！”尾音四字被她刻意强调，咬得铿锵。</p><p>杨帝颔首，心中疑云消散。</p><p>这正是地球幻想作品中常见的“领域”。</p><p>也就是将敌人拖进自己的小世界，用自己的“上等马”与对方交战。</p><p>领域内外恍若割裂的两个世界，唯有身处其中的人依旧是本体，只是形貌气质悄然蜕变。</p><p>譬如青丘白璃，外界时化为人形，此刻在领域内却显化出“狐娘”的身体。</p><p>脸颊两侧尚有人耳轮廓，头顶银色毛发间支棱起一对毛茸茸的狐耳，两对耳朵在风中轻轻颤动。</p><p>多出来的耳朵——她不是人，而是妖，亦或者是人妖算了这个称呼不太好听。</p><p>总之按照异界分类法，她是妖族的大能。</p><p>杨帝低头打量自身，只见寻常衣衫此刻泛着淡金微光，周身被一层琉璃似的光幕包裹。</p><p>——像是被“标记”为重点猎杀对象。</p><p>并且，领域内的时空，对他力量的容忍程度似乎更差了。</p><p>杨帝现在努力压制修为，收敛境界，勉强不让一身霸王色霸气外泄，将霸气死死锁在体内，</p><p>如果霸气毫不掩饰地外露，他能感觉到，自己会立刻撑破这片天地。</p><p>如何在不把狐妖制造的“领域”撑破的前提下，将对方制服？</p><p>杨帝陷入沉思。</p><p>青丘白璃呱呱大笑：“此界规则由我书写，就像凡人执笔作画——你的灵能虽诡异且强大，却好比一滴墨滴入本座的砚台，是污了画卷，还是被墨海吞噬，全看本座心意。”</p><p>杨帝：“我是怕我收不住手。”</p><p>狐耳抖了抖，歪头轻笑：“收不住手？在这儿，天地不过是本座琵琶上的一根弦罢了，速速投降吧域外天魔！领域外面已经被我们的大能包围了！”</p><p>她忽然拨动琴弦，一道音刃斩向杨帝脚下。</p><p>轰！隆！！地面瞬间裂开沟壑，空间本身被撕开一道漆黑如墨的裂缝。</p><p>然而，那无形的“刃”却在触碰他衣摆时，化作流萤消散。</p><p>杨帝：“等等，我再说两句……”</p><p>“没破防？！”青丘白璃瞳孔骤缩，十根指尖同时按弦猛地一拉，琵琶爆发出撕裂金属般的锐响！</p><p>领域内，三十六条狐尾虚影同时喷射烈焰。</p><p>如烈火炽热的氛围，以天地为舞台！</p><p>她猛地将琵琶高举，身形如鬼魅般疾转，狐尾飞扬间，五彩光芒大盛。</p><p>紧接着，青丘白璃以一种狂野不羁的姿态，疯狂拨动着琴弦，琵琶声如暴风骤雨般响起！</p><p>铮！铮铮！化作一道道锐利锐利音波，斩向向杨帝射去。</p><p>“天魔，别以为能轻易躲过！在领域内，我的攻击绝对命中！”她一边弹奏，大声怒喝，声音带着摇滚的激昂与疯狂。</p><p>杨帝：……</p><p>他也没想过要躲避。</p><p>音波在虚空中相互交织、碰撞，形成了一个个巨大的螺旋，所过之处，空间如同破碎的镜子般纷纷龟裂！</p><p>杨帝四周瞬间被这狂暴的音之漩涡所笼罩。</p><p>无论他想说什么话，都会被重金属风格的音波死死盖过去。</p><p>百口莫辩，哑巴吃黄连啊。</p><p>青丘白璃仍竟在自我的世界中，通过打嘴炮疯狂加戏：“竟是如此强大的防御！域外天魔恐怖如斯。在实力层面我认可你了，但在道义上，本座绝不退让半步！”</p><p>青丘白璃指尖翻飞如舞，琵琶弦震颤出刺目电弧！</p><p>音波化作猩红剑刃劈砍、鎏金锁链缠绕、幽蓝音锥穿刺，每一道攻击都裹挟着空间碎裂的爆鸣，在空中留下一道道漆黑似胶的裂缝！</p><p>三十六条狐尾虚影齐齐张口，将音波凝聚成咆哮的九尾狐头砸向杨帝！</p><p>声光效果炸裂到极致。</p><p>甚至仅仅是音波碰撞产生的气浪，都凝成实质，在地面犁出深不见底的沟壑，沟壑边缘燃烧着噼啪作响的熔岩。</p><p>然而这毁天灭地的攻势落在杨帝身上，却只像春日柳絮拂过。</p><p>炸裂的音波气浪撞在他身上，不过让衣衫泛起几不可查的涟漪，连衣角都未曾掀起。</p><p>青丘白璃：“啊啊——！”</p><p>杨帝：？</p><p>“曾经，我也只是青丘山脚下一只弱小的狐妖。”她的声音渐渐低沉，带上苦涩。</p><p>不好，是回忆杀！</p><p>“为了能在这残酷的世界中……我眼睁睁看着亲人和挚友……从那时起……</p><p>“我便发誓……我历经无数艰难险阻……我以为……有了这力量，便能守护……可如今……</p><p>“我如此努力，如此拼命，却连一个天外来客都无法战胜。难道，我所做的一切，都只是徒劳吗！！”</p><p>她的声音哽咽了，看向杨帝的眼神中多了几分悲戚与愤怒。</p><p>泪水不自觉地从她的眼角滑落。</p><p>杨帝后退一步：“等等，青丘女士，我到目前为止都没对您出过手，而且，也不是害您童年不幸的人……”</p><p>狐妖太过沉浸于自己的世界里。</p><p>她怒道：“闭嘴！你知道吗，一万年前……</p><p>“我……我……我……</p><p>“后来，归墟大帝出世，一举镇压灵界残存的攻讦、征伐、战争，统御二界六道，此世终于迎来万众团结的繁华。</p><p>“现在你来了，带着负灵能的域外天魔……是不是也要把我们这些‘秽物’烧成灰？！回答我！</p><p>“但我不会让你得逞！就算这领域碎了，我也要用最后一根弦勒断你的脖子！”</p><p>青丘白璃说完最后一句话，又吐了口血。</p><p>杨帝：……</p><p>杨帝：“我知道。你的心情我都能体会。如果你想发泄，我也不是不能陪你做个沙包，毕竟时间充裕，来日方长。”</p><p>然后发生一件意想不到的事。</p><p>二人都意想不到。</p><p>也许是承担了太多来自某人的压力，青丘白璃手中，琴弦“铮”地绷断了。</p><p>杨帝与青丘白璃隔着流转的光河四目相对。</p><p>一个维持着略显僵硬的防御姿势，中分发型被领域内的能量流吹得凌乱，一缕发丝还倔强地竖在头顶。</p><p>一个保持着挥弦的动作，指尖残留着未消散的狐火，月白色裙摆被气浪掀起又落下，露出绣着九尾狐的裙裾。</p><p>杨帝有些愧疚。他似乎搞坏了人家的领域。</p><p>青丘白璃刚还沉浸于往日痛苦之中，一筐一筐往外倒苦水。虽然杨帝一句都没听。</p><p>但她突然被打断，心里一定不是滋味吧。</p><p>青丘白璃冷静下来。</p><p>发觉自己好像失态了，竟然把身世全部供出来。完蛋……</p><p>她神色波澜不惊，面前看着杨帝因用力而涨红的脸，还有他身前胡乱拼凑的灵能护盾上歪歪扭扭写着“和平交流”四个大字，指尖不自觉地动了动。</p><p>“那个……”两人同时开口，又同时闭上嘴。</p>
