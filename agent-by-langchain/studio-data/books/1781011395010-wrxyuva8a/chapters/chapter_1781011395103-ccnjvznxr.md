# 铁匠与考古

<p>老矮人原本满心期待儿子能守着这小小的铁匠铺，跟他一起打铁，过上安稳的日子。</p><p>打铁虽辛苦，但赚得多（非常多！），能实实在在地过生活。</p><p>不用像盗墓，时刻在生死边缘徘徊。</p><p>现在，这逆子居然跟他说想做考古学家？</p><p>他一直以来的期望，就像泡沫般，“噗”地一下破灭了。</p><p>“爸啊……都说了考古不是盗墓。”</p><p>“唉……没什么区别。奥拓，你还记得你一岁生日那天吗？”</p><p>“？这么久远的事，我怎么可能记得！”</p><p>那天，老爸在奥拓面前放了三件物品，让他抓周，也就是Draw lots。</p><p>三样物品分别是铁锤头、银锤头、金锤头。</p><p>抓中铁锤头，说明他要成为普通铁匠。抓到银的，说明他要成为优秀铁匠，金的则是传奇铁匠。</p><p>一岁的奥拓犹豫许久，最后扛起墙角的铁镐，“笃笃笃”敲打地面。</p><p>他爸急了，认为这是孩子没见过世面。</p><p>他把奥拓的错误选择，归咎于自己没带他全世界去看看！</p><p>为了做一个合格的父亲，他老爸第一站，就把奥拓带进一支倒斗团队。</p><p>他们一同去往星渊井口“开开眼界”。</p><p>那井口黑黢黢的，仿佛一头择人而噬的巨兽，散发着令人胆寒的气息。</p><p>周围弥漫雾气，让人看不清前方的路。</p><p>“然后，你就在那地方又抓了一次周，抓到这把有‘绑定诅咒’的木镐。从此，它就在你身上脱离不了了。”</p><p>虽然很难理解老矮人决定“带着一岁小孩去倒斗”的脑回路。</p><p>但看起来，奥拓对他爹没有丝毫责怪。</p><p>老矮人：“如果挖坟倒斗是你命中注定的，那就随你去吧，这铁匠铺我自己守着。”</p><p>“都说了爸，考古不是倒斗……”</p><p>不论老矮人过去的心意，曾经的愿望和期待是什么，一切似乎都过去了。</p><p>老矮人在给奥拓过一岁生日、到星渊井口倒斗之时，就已经预见今天。</p><p>只不过那时他以为，奥拓是想做矿工，所以很抗拒。</p><p>得知原来奥拓想要倒斗（考古），那就放心了。</p><p>虽然也需要镐子，但终归不是挖矿。</p><p>“爸，为什么你这么反对我去做矿工？”奥拓疑惑地问。</p><p>“……”老矮人一时间难以启齿。</p><p>伊芙情商最高，她对其他无关群众使了个眼色，拉起瑞弗维尔往屋外走去。</p><p>杨帝也便跟随他们离开屋子，留下两个矮人，在屋内交谈。</p><p>刚出到院子，伊芙把法杖杵地面，仰躺在干稻草堆上：“我不想在这待很久。”</p><p>瑞弗维尔走近她：“伊娃，难得来一趟，我们先让奥拓帮忙给炊具附附魔好吗？”</p><p>他坐在一轮树桩上，捻着稻草，安抚精灵不耐烦的情绪。</p><p>伊芙伸了个懒腰：“好叭，那我们就多待两年。事先声明，我不喜欢在人多的地方待十年以上……”</p><p>“等等！怎么是以‘年’回单位了啦！”</p><p>毕竟是精灵的时间观。</p><p>在一个地方感到不耐烦，只想待一小会儿，这“一小会儿”都是以“年月”为单位起步的。</p><p>她踢了踢杨帝：“杨帝，你幸福吗？”</p><p>他回过神：“哦哦不，我姓杨……”</p><p>杨帝最近几日比较少说话。</p><p>他沉浸于潜意识深处存储的庞大信息之中，简而言之，他用走路吃饭睡觉的一切时间来练习掌握“灵能”。</p><p>除了必要的时候，才会真正入睡，以规避夜魅袭击。</p><p>伊芙从干稻草堆上跳起来，径直走到杨帝身前：“啧……真是心不在焉。杨帝，你包里有只熔岩史莱姆。”</p><p>杨帝装出脸色剧变的模样，以为伊芙要兴师问罪。</p><p>但她只是说：“而你却根本不会养它！要不是我偷偷给它喂小零食，史莱姆就要饿死在你的包里了！”</p><p>杨帝挠挠头，小心翼翼地从包里，把熔岩史莱姆掏了出来。</p><p>这小家伙在他手里扭动着身躯，散发着柔和的橘红色光芒。</p><p>如果忽略热量，它就是一团会动的火焰果冻。</p><p>“让我摸摸。”</p><p>伊芙眼睛一下子亮了起来，像个得到心爱玩具的孩子，迫不及待地伸出手，轻轻戳了戳熔岩史莱姆。</p><p>史莱姆被戳后，竟欢快地颤动起来，发出细微的“咕噜咕噜”声。</p><p>伊芙咯咯咯笑起来，胸怀抱紧史莱姆。</p><p>这是低等魔物急促不安的乱动。于是，她又生成了一颗散发着五彩光芒的实体光球，递到史莱姆面前。</p><p>史莱姆像是感知到了美食的到来。</p><p>它伸出一小部分身体，将光球包裹住，而后整个身体都亮起来，光芒比之前更耀眼。</p><p>瑞弗维尔：“伊娃……你最近有没有觉得哪儿不对劲？”</p><p>精灵抬头：“什么不对劲儿？”</p><p>“比如说心情很不好，想要诛人九族，想要毁灭世界，想要礼崩乐坏，想要……”</p><p>瑞弗维尔咽了口紧巴巴的唾沫，“又比如想要杀掉某些人类，或者说杀掉我。”</p><p>杨帝捏紧拳头。</p><p>这图书馆馆长，怎么上来就打直球！</p><p>还苦心提醒杨帝，关于他梦到“伊芙追杀他们”这件事，不要对伊芙本人说。</p><p>结果，自己先把此事给爆出来了！</p><p>你说话前先考虑下后果啊！不然放进任何题材的小说里，都活不过三章。</p><p>事已至此，杨帝也只能走一步看一步。</p><p>伊芙笑了：“诛九族？毁灭世界？瑞弗你是不是冒险小说看多了，被里边的情节唬住。</p><p>“我是个高知识高道德的精灵啊，怎么会有‘毁灭世界’这么庸俗、低级趣味的想法。</p><p>“至于想干掉你就更不可能了啦，不然你还能站在这儿跟我说话么。”</p><p>杨帝旁听，心中暗暗松了口气。</p><p>伊芙并没有因为瑞弗维尔的话而发怒，微表情，神色，心跳，脉搏，呼吸也没有显著变化。</p><p>她似乎在主观上并没有歹意。</p><p>而且正如伊芙所说，她若是想干掉二人，也不用等到现在。</p><p>杨帝正这么想着，却见伊芙轻轻将熔岩史莱姆放回杨帝手中。</p><p>她站起身，目光在杨帝和瑞弗维尔身上来回扫视，眼神中多了几分审视。</p><p>“你们有事瞒着我。瑞弗，告诉我。”</p><p>瑞弗维尔：“呃……是这样的，我觉得伊娃你不过有些时候会变得狂躁。是因为圣光教廷的事吗？”</p><p>他守住了底线，没把“噩梦”抖落出去。</p><p>伊芙肯定了：“猜得不错。人类的教廷，居然将史莱姆融合成卡利斯托那样的生物，我还不得不亲手将其杀死……真的很生气。我要向他们讨个说法。”</p><p>她从小就开始喜欢史莱姆。</p><p>此行去往星渊井口，占大头的原因是研究史莱姆社会学。</p><p>还有部分原因，是为了向“利用史莱姆制造弗兰肯斯坦缝合怪”的圣光教廷讨个说法。</p><p>作为自然之子，精灵很讨厌这种将生命随意揉捏的做法。想必他们也同样鄙夷转基因作物。</p><p>至于圣光教廷内部出现异端、信仰“原目”，她并不关心这些事，这都是人类的内务。</p><p>谈话之间，奥拓走出来了。</p>
