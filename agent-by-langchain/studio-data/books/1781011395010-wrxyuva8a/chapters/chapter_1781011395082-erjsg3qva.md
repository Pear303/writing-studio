# 人体炼成（划掉）人体附魔

<p>杨帝目的是偷师学习灵能法术。</p><p>这些“法术”，都是异世界人民在不知多少千年甚至万年里，通过不断探索与实践总结出来的智慧结晶。</p><p>法术中灵能的流动模式，都昭示着某种事物比较接近本质的运行原理，非常有用。</p><p>虽然异世界土著使用灵能构筑法术的方式有些粗糙。</p><p>但仅仅是“方式”上粗糙，而它的“内容”则是博大精深的，极度值得参考学习。</p><p>就比方说，最开始的“火焰法术”。</p><p>原本在地球，杨帝经过半年摸索，才实现用手指点燃香烟。</p><p>而在观察瑞弗维尔的“灵能流动方法”后，杨帝成功改进原本的手法，能够凭空窜出火焰，而不是小得可怜的火星子。</p><p>若是某一天他置身荒野。</p><p>就不需要像“拜火德”德爷那样，拼尽全力才能升起一把火。</p><p>同时，为了更好展现灵能法术的学习成果。</p><p>杨帝还结合自己10%潜意识上浮的特点，制造出一件震撼人心的精神产物——</p><p>「终极无敌狂霸炫酷技能熟练度人体属性可视化界面！」类似于，嗯，系统。</p><p>或者是RPG游戏中的“人物面板”。</p><p>可以清晰反映当前他身体各项属性值，以及各项技能的熟练度。</p><p>初始值，即普通人的平均值是100。</p><p>杨帝多项属性已突破五百大关，比如用撬棍练出的「剑」术达到600，「耐热」达到900，「钝器抗性」甚至达到惊人的1000……</p><p>他如今能无伤生啖八九百度的火炭，在拉钢卷的全险半挂车的120公里时速冲击下骨折不超过十处，还可以随便用电动钢锯挠脖子、剃胡须。</p><p>「抗性」方面，杨帝在地球上经常跳楼、撞大运、火中做自己、电锯挠痒、生吞绣花针，然后在睡梦中重复品味痛楚，重复磨炼肉身抗性千百回。</p><p>现在，进步已经非常缓慢，进入了某种“瓶颈”，但此时数值也特别特别高，暂时够用。</p><p>但在「攻伐」方面，稍逊一筹，还做不到一脚踢死一头成年非洲象——必须两脚才行。</p><p>他虽然能通过强大无匹的精神，直接操控环境中的灵/扭曲现实，不需“咏唱”、“仪式”。</p><p>但与其从零开始摸索如何高效扭曲现实，不如“拿来主义”，学习异世界人民的智慧结晶。</p><p>还是那个例子——他在地球上尝试半年，才学会从手指中搓出火星。</p><p>而到了异界，仅仅是几分钟的理解和模仿，他就能从手心窜出火苗。</p><p>所以，学习“法术”，势在必得。</p><p>而法术中的“附魔”分支，也对力量提升很有帮助，不能不尝。</p><p>……</p><p>“确实是有「附魔」这种技法，但我不会。只有比较资深的工匠，才会专门学习附魔。”</p><p>瑞弗维尔挠挠头。</p><p>无论是游侠，图书馆馆长，还是旅行商人，基本都不会了解“附魔”类技法。</p><p>最多也就掌握点火、治愈等实用小法术。</p><p>术业有专攻，这就是社会分工，所以白领不需要学习螺丝的四种打法，外卖小哥也无需学习怎么用狙击步枪在800米外狙鬼子。</p><p>“不过我可以给你介绍一下‘附魔’。”瑞弗维尔话锋一转说道。</p><p>实践不会，但大致原理还是能介绍一下。</p><p>附魔，简单来说，就是将特定的灵能符文注入到物品之中，赋予其特殊的属性。</p><p>不同的符文组合和注入方式，会产生不同的附魔效果。</p><p>比如，一把刀子被注入疾疫类术型，得到「破伤风之刃」附魔效果。</p><p>除此之外，还有增加武器的耐久度、赋予防具防御特殊攻击的能力等等。</p><p>“除了给器具附魔，能给活物附魔吗？”杨帝问。</p><p>“有的兄弟，有的。”</p><p>瑞弗维尔指了指杨帝手中的杀手兔，“比如这兔子，能跑这么快，就是因为它对自己施加了「速度III」附魔。”</p><p>杨帝正在用刚磨好的刀，剥兔皮。</p><p>他看了看已经剥一半的杀手兔。</p><p>在之前被兔子袭击的时候，杨帝已经记下那只兔子体内的灵能流动方法。</p><p>那就是……附魔？</p><p>还真能给活体附魔，也就是给自己上buff。</p><p>他试了一下，试图引导自身灵能按照同样的模式流动，以期获得速度提升。</p><p>刹那间，一股狂暴且紊乱的灵能在他体内横冲直撞起来！</p><p>杨帝只感觉仿佛有无数根钢针在体内四处乱刺，五脏六腑好似被一双无形的大手肆意搅动。</p><p>嗡——嗡——嗡——</p><p>他根本来不及做出任何反应，一口鲜血便猛地从口中喷出，溅落在正剥着的兔皮上。</p><p>“杨帝！你怎么了？”瑞弗维尔见状，急忙冲来。</p><p>杨帝摆摆手，示意自己还撑得住。</p><p>但那苍白如纸的脸色和不断颤抖的身体却出卖了他。</p><p>「脏腑+1+1+2+3+5+8……」</p><p>「骨+1+1+2+3+5+8……」</p><p>「神经+1+1+2+3+5+8……」</p><p>仅仅一瞬间，杨帝内部大撕裂、大出血！</p><p>他心中暗自懊恼，自己还是太过心急了。</p><p>虽然记住了杀手兔体内灵能流动方法，却忽略了这是适用于兔子的特殊模式！</p><p>自己身体构造与兔子截然不同，强行模仿无异于自寻死路。</p><p>还是得具体情况具体分析啊。</p><p>“我……我没事，就是刚才突然想试试，没想到……咳咳……”杨帝摆摆手，一边说话一边几百毫升几百毫升地喷血。</p><p>瑞弗维尔根本想象不到——杨帝是在模拟杀手兔的“附魔”方案。</p><p>就好像地球人想象不出来：从没用过手机的人，看一眼手机，立刻就能画出手机设计图，详细到每个芯片类型、每个引脚接法！</p><p>太过匪夷所思，不会往那个方向想。</p><p>所以，瑞弗维尔认为，是不是眼前这传奇法师，体内留下过什么暗伤、诅咒？</p><p>“不妨事，不妨事，我好像快找到技巧了。”</p><p>杨帝强忍着身体的剧痛，集中精神，调动周围“灵”。</p><p>大量的灵能如潮水般朝着他涌来，在身前快速汇聚。</p><p>在重伤状态下，杨帝又搓了个“绿色小太阳”三环法术·愈合！</p><p>猛地将其按在自己胸口，光芒瞬间蔓延至他的全身。</p><p>体内那股狂暴紊乱的灵能渐渐被安抚下来，如同脱缰野犬般的伤势，也开始得到控制。</p><p>原本被撕裂的脏腑、骨骼和神经，在这股强大治愈力量作用下，以惊人的速度愈合！</p><p>杨帝原本愈合速度是普通人100倍。</p><p>在治愈法术加持下，他的恢复速度被拉到了1000倍！</p><p>而且在这个过程中，他明显感觉到，“超量代偿”机制仍然在发挥作用。</p><p>“也就是说我能一边肆无忌惮损伤自己的身体，一边以快得离谱的速度恢复伤势。”</p><p>杨帝捏了捏拳头。</p><p>他能感觉到，痊愈之后，自己五脏六腑、血管筋络，状态前所未有的好！</p><p>即使一天炫50斤江米条也不会得糖尿病。</p><p>以前，他体内的这些脏器、血管、神经，都很难用外力进行锻炼。</p><p>而在这个灵能充沛的世界，他就有了更多的手段，来折腾自己身体！</p><p>比如说，用外界的“灵”隔山打牛，折腾自己体内、物理外力难以锻炼到的器官。</p><p>异世界灵能如此充沛，妙用还不止于此……</p><p>他陷入沉思。</p><p>与此同时，瑞弗维尔紧张地观察杨帝。</p><p>这个“喜欢扮猪吃虎的传奇级失忆法师”对自己使用治愈法术后，虽然面色变得红润，看起来伤势是恢复了。</p><p>但此后一直在发呆思考，这让瑞弗维尔有些许不安。</p><p>对方突然吐几大口血，然后记忆恢复了？</p><p>对自己用了个治愈法术，神志清醒了？</p><p>他作为图书馆馆长，饱览野史。</p><p>瑞弗维尔知晓众多普通人不知道的秘辛：比如有些传奇强者，因为修炼走火入魔，多了很多奇异的癖好。</p><p>他们会将手下败将，拖到一个任何探测器都找不到的深洞，然后开始做极度不可名状、极尽疯狂、扭曲与亵渎且深入人类灵魂恐惧的终极侮辱……</p><p>“醒醒，瑞弗维尔，这就是‘野史’读太多的后遗症。”</p><p>他拍了拍自己的脸，让自己回过神来，恢复清醒和理智。</p><p>瑞弗维尔微笑着看向杨帝：“朋友，你……”</p><p>“噗噗噗，呕。”</p><p>杨帝又喷了几百上千毫升的血。</p><p>他擦擦嘴角的红色液体，又一个三环法术·愈合·pro-max-plus豪华版拍在身上。</p><p>“人物面板”中，自己脏器的坚韧程度提高了几十个属性点。</p><p>他转身朝向瑞弗维尔：“怎么了？”</p><p>“……没什么，有什么可以帮您的吗？”</p><p>“没事，我感觉好得很。我先睡一觉了……”</p><p>（灵=灵能=现实丰度）</p>
