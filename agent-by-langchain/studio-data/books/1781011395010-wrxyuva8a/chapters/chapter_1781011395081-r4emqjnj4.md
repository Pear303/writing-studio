# 物理近战法师

<p>距离末日火山主峰85公里。</p><p>……</p><p>前方的草丛突然一阵抖动。</p><p>瑞弗维尔和杨帝立刻警惕起来，前者拿出小刀，后者掏出撬棍。</p><p>瑞弗维尔看到杨帝掏出的撬棍，眼睛瞬间瞪大。</p><p>传奇法师的权杖，如此普通？！</p><p>不……只是外在看上去普通！</p><p>“扮猪吃老虎，故意藏拙……这位传奇大法师杨帝，在失忆前也是个心计深厚的谋略者！”</p><p>瑞弗维尔在图书馆的日子里，看过很多冒险小说，同时也接触过许多《野史》。</p><p>里面记录的许多历史，和官方文书上光鲜亮丽的记载不同。</p><p>比如说，圣骑士巴德其实并不是靠强大的武力平定击败“北极领主”，而靠的是偷偷在那位强大的魔族领袖的晚饭里，添加了20倍超标致死量的巴豆。</p><p>然后趁其腹泻，摸到茅房，在北极领主最脆弱的时候偷其屁股！</p><p>还有各路大法师、狂战士、传奇游侠之类的大能，早年也喜欢装逼打脸扮猪吃虎。</p><p>这么做也情有可原，能提供情绪价值。</p><p>有理由相信，杨帝这根金属法杖，也藏了毁天灭地的能量。</p><p>“太阴险了。”</p><p>瑞弗维尔感慨一声世风日下人心不古，黄钟毁弃瓦釜雷鸣。</p><p>他很快将注意力拉回来，执游侠小刀，紧紧盯着草丛中，动静传来之处。</p><p>窸窸——窣窣——</p><p>有什么东西在靠近……</p><p>从草丛中缓缓探出一个圆滚滚的绿色物体，原来是一小团草史莱姆。</p><p>“噢！这是草史莱姆，相对比较温和的一种史莱姆，一般以吸收植物中的灵能为生，很少主动攻击人类。”</p><p>瑞弗维尔松了口气，“不过也不能掉以轻心，有时它们会释放麻痹性的草汁保护自己。”</p><p>杨帝能感知到，草史莱姆体内灵能流动。</p><p>那是一种相对缓慢而柔和的循环，不似熔岩史莱姆那么暴烈。</p><p>“不知道吃起来，像不像甘草味果冻……”</p><p>如果是一个人，杨帝就能大快朵颐了。</p><p>可惜，身旁一直有个可疑的旅行商人盯着，不方便在异世界土著面前，做太出格的事情。</p><p>告别了草史莱姆，他们继续往前走。</p><p>没走多远，草丛又传来窸窸窣窣的声音。</p><p>瑞弗维尔刚放松的神经，瞬间又紧绷起来，握紧手中的小刀。</p><p>杨帝也只好跟着握紧撬棍——虽然他已经看清那动物是啥了，没什么危险。</p><p>果不其然，草丛中跳出只很显然人畜无害的小白兔。</p><p>它浑身雪白，耳朵长长，红宝石眼睛滴溜溜地转着。</p><p>虽然杨帝老早就知道那是只兔子，但他还是要装模作样，长出口气放松下来：“是只兔……”</p><p>“快闪！！”瑞弗维尔怒吼。</p><p>杨帝瞳孔骤缩，他也感觉到异样了。</p><p>看似人畜无害的小白兔如炮弹般以1.5马赫的速度朝着杨帝冲了过来！</p><p>瞬间炸出锥形音爆云！！</p><p>杨帝反应极快，在千钧一发之际闪电般地用手臂挡了这一击。</p><p>冲击力传来，手臂轻微骨裂，整个人也被这股力量震得向后退数米。</p><p>“轰轰——隆！！”</p><p>音爆声姗姗来迟，震得人耳膜生疼。</p><p>瑞弗维尔趁着兔子攻击杨帝的间隙，快速绕到兔子身后，手中小刀闪烁着寒光，朝着兔子的背部刺去。</p><p>他虽是图书馆馆长，但在此之前，还当了十几年的游侠！</p><p>而且混到了“五环游侠”专业证书。</p><p>现在利刃出鞘，宝刀未老，瑞弗维尔找回当年在野外殴打魔物的快乐！</p><p>然而，兔子察觉到了身后的威胁。</p><p>在瑞弗维尔的小刀即将刺中它，兔子一个转身，战术位移，速度快得几乎让人看不清！</p><p>它速度极快，闪开了！</p><p>杨帝甩着酸麻的手，弹射起步地上蹦起来：“瑞弗维尔！这是什么？”</p><p>“你没事，太好了！”</p><p>瑞弗维尔一边警惕地看着兔子，一边快速向杨帝解释道，“杀手兔，五环级别！它们能在瞬间爆发出惊人的速度，所产生的冲击力足以撞碎巨石！”</p><p>撞碎巨石……撞碎巨石……</p><p>瑞弗维尔转头看向几乎没有皮外伤的杨帝，再度瞠目结舌、惊心骇目！</p><p>结结实实挨了一发撞，什事都没？</p><p>“还是物法兼修的‘近战法师’？”</p><p>瑞弗维尔再度肃然起敬。</p><p>要知道，高贵的法师天然看不起满脑子肌肉的战士。</p><p>要他们放下身段，去锻炼庸俗的肉身，需要承受很大心理负担！</p><p>“杀手兔？为什么被称作杀手兔？”</p><p>“因为……天下法术无坚不摧，唯快不破，这兔子虽只有五环级别的灵能波动，但速度太快太快了，许多法师没来得及防御，就被撞了一发，当场死亡。要知道这兔子看似柔软，实则骨头比钢铁还坚硬，连带着体重也能达到10kg……”</p><p>“速度很快啊，那我明白了。”</p><p>杨帝听闻瑞弗维尔的解释，心中对这杀手兔的危险程度有了清晰认知。</p><p>他已经大致判断出来，1.5马赫初速，大约10公斤体重的兔子。</p><p>单纯动能，相当于1.0吨重的轿车以180千米/小时速度行驶。</p><p>神州高速上限也才120千米。</p><p>这动能，可以直接撞死成年非洲象。</p><p>如果没有灵能加持，单纯生物，咋可能整得出1.5倍音速这么快——它只是条兔子啊喂。</p><p>值得一提的是，异世界常温下，音速也大概在340米/秒左右，看来造物主还是很随便的。</p><p>“既然它速度快，那我就以力破巧。”</p><p>杨帝低喝一声，双脚猛地一蹬地面，如同一道黑色的闪电般朝着杀手兔冲去。</p><p>那只杀手兔似乎感受到了杨帝身上散发出来的强大战意，红眼睛儿竟闪过一丝慌乱。</p><p>但它并未退缩，反而再次发动攻击，以1.5马赫的恐怖速度朝着杨帝撞来！</p><p>一人一兔接触的前一刻——</p><p>杨帝将藏在身后的手露出来。</p><p>手里拽块镶了八个铁质撞角的豪华砖头！</p><p>杨帝猛地将手中那块镶了八个铁质撞角的豪华砖头横在身前。</p><p>“轰！”一声巨响，犹如闷雷炸响。</p><p>杀手兔狠狠撞在板砖上！</p><p>这股冲击力之强，周围空气都为之一震，地面也隐隐颤动。</p><p>杨帝的板砖差点脱手。</p><p>其中一个撞角铁质瞬间嵌入杀手兔的脑袋300%暴击伤害！</p><p>并且叠加兔子本身的速度。</p><p>鲜血爆溅，杀伤惊人！</p><p>杀手兔的身体在空中停顿了一瞬，随后如同一块烂抹布摔地上，扬起尘土。</p><p>它四肢抽搐几下，头一歪，便咽了气。那双原本闪烁着凶光的红眼睛，黯淡无光。</p><p>瑞弗维尔嘴巴张得老大，下巴都快把地板砸穿了。</p><p>杨帝竟能以如此简单粗暴的纯物理手段，解决掉这只四环级别的杀手兔。</p><p>手腕没脱臼，甚至砖头也没脱手。</p><p>这，就是强者的手腕！</p><p>瑞弗维尔眼睛化作饼状统计图，三分惊异，三分喜悦，三分畏惧，一分其他。</p><p>虽然那只是一只五环魔物。</p><p>但是，瑞弗维尔看出了更多的情报——杨帝，传奇级别物理系近战法师！</p><p>“杨帝……战斗方式挺特别啊，哈哈。”</p><p>“可能是我失忆前就习惯用这种简单直接的方法解决问题吧。”</p><p>杨帝也只能笑笑地打趣，将镶嵌撞角的砖头藏回身后小背包里。</p><p>他也不知道，这种激情四射的物理战斗，在异世界算不算稀有。</p>
