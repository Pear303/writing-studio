# 卡耳叩山

<p>杨帝的手指触碰碎裂屏幕。</p><p>那行字瞬间燃烧起来，化作灼目的信息流，顺着指尖冲入他的意识。</p><p>眼前景象如同被投入碎纸机的油画。稷海市出租屋的霉味、虚空的无垠感、万亿分身构建的虚假叙事领域……</p><p>一切熟悉的存在感被粗暴地剥离搅碎。</p><p>眩晕感汹涌而来。</p><p>杨帝的“维持基准态不变”本能瞬间激发，将这股震荡强行压下，意识始终保持冰冷的清醒。</p><p>搅动的混沌平息。</p><p>脚下是冰冷潮湿，布满不规则裂痕的黑色玄武岩。</p><p>空气粘稠沉重，带着浓烈的咸腥和某种腐朽花朵的甜腻气息，每一次呼吸都像吸入粘稠的液体。</p><p>没有风，只有令人窒息的永恒死寂。</p><p>抬头。</p><p>天空不存在。取而代之的是翻滚蠕动的、无法形容的暗黄与病绿交织的厚重云团，如同巨大腐败的内脏悬垂。</p><p>云团间隙偶尔透出非自然的光——杨帝莫名地知道，那不是星光，那是某种遥远而充满恶意的注视感。</p><p>视线所及，是破碎的几何噩梦。</p><p>坍塌的巨大石柱倾斜着刺入粘稠的天空，柱体表面覆盖着湿滑的苔藓和意义不明的浮雕。</p><p>这些浮雕扭曲变形，仿佛在痛苦蠕动。</p><p>建筑物残骸呈现出非欧几里得的角度，墙壁以不可能的方式折叠穿插。</p><p>一座断裂的高塔，斜插进漆黑如墨的水潭，水潭表面光滑如镜，倒映上方翻滚的云团，却诡异地映不出任何实体建筑的影子。</p><p>远处，一片巨大得超乎想象的废墟轮廓在昏暗中若隐若现。</p><p>那像是一座被遗弃的远古剧场，然而单从外形看，更像是一只硕大无朋的残破狐狸雕塑。</p><p>它的轮廓在视线中不断轻微地扭曲闪烁，似是同时存在于多个重叠的空间相位，帧数不稳定。</p><p>卡耳叩山。</p><p>这个名字如同冰冷的铁钉，随着环境的感知，直接楔入杨帝的意识。</p><p>不需要解释，这就是此地的真名，耶罗大仙的失落之城，疯狂与绝望的永恒囚笼。</p><p>充斥空间的，是一种蕴含“主体性”的灵能。</p><p>它高于环境之现实，所以，能将物理法则视为可随意揉捏的泥巴。</p><p>杨帝能清晰感觉到自己那超越无穷的防御力场，在此地规则的持续侵蚀下，正发出如同金属疲劳般的低沉嗡鸣。</p><p>虽然远未到被破防的程度，但那种无处不在的、粘稠的污染感，如同跗骨之蛆。</p><p>他的目光扫过那些扭曲的浮雕，掠过漆黑水潭，穿透翻滚的暗黄云层，锁定了那座不断闪烁的巨大废墟剧场——卡耳叩山的核心，那座不断闪烁的巨大废墟剧场。</p><p>杨帝身形一动，一步踏出，已然置身于卡耳叩山剧场的中心。</p><p>脚下是布满湿滑苔藓的巨大石板，周围是倾斜欲倒、刻满蠕动浮雕的断壁残垣。空气中弥漫的腐朽甜腻气息浓烈到令人窒息。</p><p>“耶罗大仙。”杨帝的声音如同冰冷的铁块砸在死寂的空气中，没有回音，只有更深的死寂。</p><p>回应他的，是整个卡耳叩山的苏醒。</p><p>那些覆盖在石柱和残垣上意义不明的浮雕，猛地活了过来！</p><p>扭曲的线条脱离石面，化作无数滑腻蠕动，散发着非人恶意的暗影触须，从四面八方、从虚空的每一个角度向他绞杀而来。</p><p>与此同时，他脚下的巨大石板变得粘稠和柔软，如同巨兽的食道内壁，分泌出强酸般的腐蚀性粘液，试图将他吞噬溶解。</p><p>耶罗大仙的攻击，直接作用于现实，作用于杨帝的灵能本身。</p><p>杨帝面无表情。</p><p>面对绞杀而来的亿万影子，他还是没有任何防御动作。</p><p>触须击中他身体，便如同撞上了无形的绝对壁垒，其蕴含的疯狂恶意与侵蚀力被瞬间解析和适应，然后是超越。</p><p>触须本身开始剧烈颤抖崩解，化为毫无意义的黑色灰烬飘散。</p><p>脚下试图吞噬他的粘稠地面，在他立足的瞬间，其腐蚀特性便不再对杨帝有效。</p><p>粘液依旧流淌，却失去了所有威胁。</p><p>“定义。”杨帝开口。</p><p>两个字，如同创世神谕。</p><p>他抬起右手，对着这片疯狂的空间，对着整个卡耳叩山，对着那潜藏在无尽疯狂背后的耶罗大仙意志，虚虚一握。</p><p>嗡——！</p><p>一种超越卡耳叩山本身，更加绝对、更加霸道的规则，瞬间降临！</p><p>以杨帝为中心，一个绝对排斥其他法则的无形“领域”出现。</p><p>这个领域内的所有空间、所有物质、所有能量、所有规则……其“定义”被杨帝强行篡改。</p><p>“此地。”杨帝的声音冰冷，穿透疯狂，“为我之胃。”</p><p>轰隆隆——！</p><p>整个卡耳叩山剧烈震颤。</p><p>仿佛一个被强行塞入错误模具的巨大活物，发出痛苦哀嚎。</p><p>那些扭曲的几何建筑，在杨帝的领域内疯狂变形。</p><p>非欧几里得的角度被强行掰直，坍塌的石柱如同被无形巨手扶正又捏碎，覆盖的苔藓和蠕动浮雕在惨叫声中枯萎。</p><p>翻滚的暗黄病绿云团，也被无形的力量撕扯。</p><p>卡耳叩山的巨大废墟剧场、断裂的高塔、漆黑的水潭……卡耳叩山的一切物质与非物质存在，都被强行纳入杨帝这个新定义的“胃”的形态之中！</p><p>乍一看，杨帝的领域很小，仅仅刚够把他包裹起来，而他站在“胃”的中央。</p><p>事实上，他站在自己肠胃的外侧。</p><p>好比如何用一个口袋装下整个世界？</p><p>只要将自己的“胃囊”整个“倒翻”过来，那么杨帝的胃就包含了整个卡耳叩山。</p><p>既没有胃酸分泌，也没有物理研磨。</p><p>只有绝对的消化能力。</p><p>构成卡耳叩山的每一块扭曲岩石、每一缕腥臭的空气……都在杨帝的胃域内，被强行分解，打散成最原始的灵能。</p><p>耶罗大仙潜藏的意志发出了无声的尖啸！</p><p>祂试图污染杨帝的意志，扭曲他的定义！</p><p>杨帝的意志如同黑洞，冰冷地吞噬着这股洪流。</p><p>属于耶罗大仙的疯狂叙事被瞬间解析，其污染性被剥离，灵能被吸收。</p><p>卡耳叩山在崩溃。</p><p>暗黄病绿的光芒彻底熄灭。</p><p>卡耳叩山消失了。</p><p>仿佛从未存在过。</p><p>粘稠的空气、腐朽的甜腻、永恒的寂静……所有属于那个疯狂世界的特征，瞬间消散。</p><p>杨帝站在稷海市石桥街道81号9楼3号房的客厅中央。</p><p>脚下是沾着污渍的廉价塑料地板革。</p><p>空气中弥漫着泡面、旧书和灰尘混合的味道。窗外传来城市傍晚的喧嚣车流声。</p><p>他回来了。</p><p>仿佛刚才那场超越维度的吞噬只是一场短暂的幻觉。</p><p>只有一点不同。</p><p>那部沾着泥水，屏幕碎裂的廉价红米手机，此刻正安静地躺在客厅中央的地板上。屏幕亮着微光。</p><p>依旧是那个简陋的纯文本星空背景。</p><p>光标在屏幕中央闪烁了一下。</p><p>新的字迹，如同冰冷的墓志铭，一个字符接一个字符地浮现：</p><p>「杨帝毁灭卡耳叩山，杀死了耶罗大仙。」</p>
