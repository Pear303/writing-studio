# “神秘学”

<p>是的，没错，你说得对，领域是弱者用于增幅自身力量的工具。</p><p>对杨帝而言，有构筑“领域”的精力，不如去多挨几回打。</p><p>但在经过长久的挨打之后，他已经进化出边挨打边进行深度思考的能力。</p><p>所以在挨打的同时，他也开始思考如何构筑领域。</p><p>思考的结果是：并不局限于让体内磁场转动100兆匹，而是让灵能转动100兆匹。</p><p>杨帝这般想着，眸光骤亮，周身灵能如沸腾的岩浆剧烈翻涌。</p><p>刹那间以他为中心，周遭空间被狂烈地搅动，原本就混乱的气流更是狂暴不堪，归墟之地的雾气也如被卷入漩涡一般，急速旋转。</p><p>狂风之狂，就连59改的国字脸也被吹得犹如纸巾般变形！</p><p>阿巴紧紧拽住青丘白璃尾巴还没有被吹飞。她大叫道：“老大，领域不是这样玩的！”</p><p>杨帝身处于灵能暴风眼：“诶，不是将灵能转动100兆匹就行了吗？”</p><p>鲈鱼疯狂摇头：“根本不是而是你要在维持自我主体性的同时，将‘主体’的概念扩散四周，让周围一片空间成为你的一部分……青青你来跟我老大讲吧，我也一知半解而已。”</p><p>灵界修士技术路线和阿巴非常不同。</p><p>他们早早就点出了“领域”技能，并发展到很成熟的水平。</p><p>青丘白璃算是个专家，她能用琵琶作为领域的模拟天道，创造一个以重金属摇滚作为主题的小世界。</p><p>她指出，“领域”不是涡轮增压，不是单纯的灵能输出，而是要让空间本身认同您为“新的物理常数”。</p><p>用凡界的电子游戏举例，您现在是疯狂堆攻击力，但领域是直接修改游戏底层代码。</p><p>总而言之，您要将您扩散刻进周围的时空，将自己对“自我”的定义，向外延展。</p><p>杨帝：“那我将自己的灵能延展出去，不也是一样吗？”</p><p>青丘白璃理了理被吹乱的尾巴，说：“心不诚则不灵！您要意识到，在世界最原初之时，人与外界没有分裂开来……等等……白杨大帝，您难道没有进行过‘第七识’的修炼？”</p><p>杨帝有些困惑了。</p><p>第七识，到现在为止他都没成功修炼过。</p><p>“冥冥之中有‘神秘学’知识储备告诉我，第七识可称作‘末那识’，第七感是‘我执’，似乎是和自我、主体性有关。”</p><p>“没错。为什么太乙真仙境的强者、大能会强大无比，正是因为他们参悟了领域/小世界的真髓——第七感！您或许只对领域/小世界有个模糊的概念，认为它是源于内心、精神、灵魂、生命、自我意识和心志器量等……”</p><p>青丘白璃在狂风中滔滔不绝侃侃而谈。</p><p>但就像每一个嘴碎的狐狸，她迟迟说不到重点。</p><p>没有听的意义。</p><p>杨帝闭眼，扫描自己脑中的神秘学知识。</p><p>有些知识，像是“老天一拍脑子想出来”的。</p><p>又有些知识，则是在现实中完全找不到对照物，像是凭空创造的设定。</p><p>还有些知识，具有……极其古怪的性质。</p><p>它们，统称为“神秘学”。</p><p>比如，某些在物理层面缺乏直击事物本质的“实操行为”、灵能领域亦不存在具备法术意义的“仪式架构”。</p><p>——却能轻易达成单凭法术体系或科技力量都难以企及的事。</p><p>举例来说，比如构建可见光波段光线反射率较低、主要成分为液态水的深色水池，对其投入象征“动物遗骸”的物体，可以是肉块，骨头，甚至煤炭石油此类化石。</p><p>水本身就是常见物质，改变其光线反射率，仅仅是一种物理外观上的调整，并未触及到物质深层次的本质规律，也没有引发新的物理反应或揭示物理原理。</p><p>投入象征“动物遗骸”的物体，无论是肉块、骨头，还是煤炭石油这类化石，从物理角度看，只是简单的物体投放。</p><p>不会产生超越常规物质混合的特殊物理效应，不会改变水的基本化学性质，也不会引发核反应等重大物理变化。</p><p>而上述行为，没有按照已知法术体系的规则来构建仪式架构，也没有引发任何可被识别为法术效果的灵能流动。</p><p>但它就是有效。</p><p>能够随机穿越异界。</p><p>完全违背所有技术理论和逻辑。</p><p>这类知识体系，也被统归为「神秘学」。</p><p>它跳脱于既定规则之外，以非逻辑的路径触碰某种更接近世界本质的真相。</p><p>还有些知识，则是现实中完全不存在的事物。</p><p>比如，偶尔划过杨帝心头的“TYPE-MOON”啊，什么“磁场转动”啊，什么“十万三千小黄书”之类的。</p><p>但这些“现实不存在的设定”，往往也隐喻了某些非常实用的技术和理论。</p><p>当杨帝第一次得知“领域”这种事物时，他的脑子里涌上了一个神秘学词汇——</p><p>圣斗士！</p><p>在“圣斗士”的世界里，小宇宙是一切力量的根源，它潜藏于人类灵魂深处，是与宇宙同根同源的能量。</p><p>前五感是普通人都具备的视觉、听觉、味觉、嗅觉和触觉，而第六感“意识”，则是踏入小宇宙修行门槛的标志。</p><p>可第七感“末那识”，才是小宇宙的真髓。在神话时代，人类刚诞生时便人人拥有第七感，那时的人类与神明差距并不显著。</p><p>但随着文明发展，这份天赐之力被逐渐深埋，只有极少数天赋卓绝、意志坚定之人能重新唤醒它。</p><p>一旦觉醒第七感，小宇宙便会爆发出接近神明的战斗能力，战力呈百倍增长，拳可裂星辰，速能达光速。</p><p>虽然“拳裂星辰”、“光速飞踹”对没有修炼第七识的杨帝而言，并不困难。</p><p>但考虑到圣斗士只是凡人，没有自己怪物级进化适应能力，这么看来“小宇宙”对他们而言确实很重要。</p><p>最关键的一点——小宇宙，似乎就是本地土著大能口中的“领域”。</p><p>“在我的神秘学储备中，有没有提及‘我执’这第七种感觉如何开启？</p><p>“让我瞧瞧，让我翻翻，要是我的记忆有本目录就更好了……</p><p>“需要在绝境中不断磨砺，在战斗中对自我和宇宙的认知达到全新高度，让潜藏在生命深处的本能彻底释放……</p><p>“什么意思？能不能说得再抽象一点？”</p><p>……</p><p>月斑银鲈·万古鱼尊·阿巴此刻陷入极大的绝望之中。</p><p>她刚认不久的老大，似乎沉浸于深度思索，对他们所说不闻不睬。</p><p>更重要的是，杨帝周身的灵能漩涡，正在愈发庞大、愈发炽烈！</p><p>随时都要爆了！</p><p>阿巴扯着嗓子嘶吼：“老大！你再愣着灵能就要把整个宇宙炸成蜂窝煤了！”</p><p>终于，在第4096次呼喊过后，杨帝从沉浸式深度思考中脱离。</p><p>“不好意思啊，有一丢丢走神。”</p><p>他抬头，看向愈发狂暴的灵能漩涡。</p><p>不好搞，有些覆水难收。</p><p>解铃还须系铃人，但现在就连“系铃人”都感到有些棘手。</p>
