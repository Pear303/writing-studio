# 系统、细思极恐！

<p>“但是，大帝怎么可能一喝水就修为暴涨？”阿巴反驳。</p><p>她也经常喝水，但没见变强多少。</p><p>要是喝水就能变强，那海里的鱼早就金丹遍地走，元婴不如狗了。</p><p>杨帝闭眼。</p><p>他不是在思考原因，而是在思考如何解释。</p><p>他想到了中山无极、青丘白璃等几位土著大能整理出来的卷宗资料。</p><p>其中有一段记录，特别让他在意：</p><p>「大帝书房的日历扉页，写着『喝水就能变强系统』这个含义晦涩的句子。」</p><p>系统。</p><p>位高权重的真仙境大能，或许不明白这是什么东西。</p><p>但出身于市井人家的杨帝，非常清楚那是什么玩意！</p><p>——在凡人的文学里，“系统”类似于一个突然砸到主角头上的“金手指”。</p><p>它大部分时候，是个虚拟界面或者声音，会发布任务、给奖励，逼着主角打怪升级。</p><p>比如有人摔一跤醒来，脑子里多了个“变强系统”，喝口水都能加经验。</p><p>也有系统像游戏面板，把修炼变成攒经验条、解锁技能的过程。</p><p>本质上是人们对“快速突破自身局限”的幻想投射。</p><p>或许在某个宇宙，兆亿条世界线之中，也会有个中二至极的男人，幻想自己一觉醒来获得什么数值怪系统，挨打就能变强，锻炼就能进步什么的。</p><p>绝大部分时候，“系统”应该是种幻想。</p><p>但在经历与原初之眼一战后，杨帝了解到，“话本编撰者”似乎在暗示他们所生活的现实世界的虚拟性。</p><p>这个“系统”，有无可能是由更高层级的存在所设定，其目的或许是引导归墟大帝走向某个既定的结局？细思极恐。</p><p>杨帝在脑海中模拟出事件全貌：</p><p>归墟大帝首先觉醒了喝水就能变强系统。</p><p>靠着不断喝水，完成修为境界的原始积累。</p><p>登临大能之境后，普通的白开水、矿泉水已经满足不了他日益增长的升级需求。</p><p>于是，他开始炼化“归墟渊水”。</p><p>结果不仅不会被反噬其身，反而能将水中蕴含的本源法则，转化为磅礴修为，不断变强。</p><p>他成为了归墟大帝。</p><p>就像凡人游戏里为人物属性加点，大帝每饮一口渊水，系统面板上的“修为进度条”就疯狂跳动，猛地向上涨一截。</p><p>然而，成也系统，败也系统。</p><p>当他来到凡界，沉迷风景，忘记关注“喝水就能变强系统”时。</p><p>他用青白石搪瓷杯喝下最后一口白开水。</p><p>随即，喝水就能变强系统的帮助下，修为上涨了一丝丝。</p><p>这一丝修为，便是压死骆驼的最后一根稻草——凡界，再也无法承载“归墟大帝”这股超规格力量的具象化显现。</p><p>大帝的存在本身，已突破世界的数据类型上限，成为了规则之外的“世界异常”。</p><p>归墟大帝知道自己无力回天了，本想安静去死。</p><p>但突然“遭到某人背叛”。</p><p>于是他在被驱逐出这个世界、甚至是被杀死之前，放出了“阴伏流煞”，试图拉所有人下水。</p><p>真是天衣无缝的推理！缺点是……这推理太复杂、太曲折。</p><p>而且加入了太多主观预设……没有多少客观的实证……像是一个蹩脚编剧，强行安插各种奇怪设定、出戏的巧合，写成的狗血剧本……</p><p>而且，归墟大帝，会仅仅因为遭到背叛，就要把全世界毁灭掉吗？</p><p>没人比青丘白璃更懂大帝。</p><p>她认为，绝不可能。</p><p>但是……现在，也没有其他能够自圆其说的可能性。</p><p>是的，杨帝这一番狗血、曲折的推论，甚至在逻辑上还能够一丝丝自洽的可能性。</p><p>若他没有什么远大宏伟的目标，那么他在走到今日的境界之时，也许不会再朝着更高境界升级。</p><p>而是会找到一个水库边的小房子养老，每天钓钓水鳖。</p><p>再写点本格派推理，对本就走向衰落的推理文学界再开一枪，火上浇油，雪上加霜，暑中送炭。</p><p>就在杨帝正式下定决心祸害推理文学界之前。</p><p>59改仍然没有放弃挣扎。</p><p>他转向本地土著大能青丘白璃，正方形国字脸上露出人畜无害的问询之色：</p><p>「青丘白璃女士，您是本地土著，对此世了解更深刻。您对‘虚拟世界’之论有何见解？」</p><p>“这个啊，嗯，其实……我认为白杨大帝阁下的话确实有几分道理。”她说。</p><p>青丘白璃，投敌了！！！</p><p>阿巴也凑上来：“青青，你竟相信了我们老大的推理……难道你知道些什么？”</p><p>青丘白璃似乎有些难言：“其实这有关凡界的本质，我不能随便透露，这是灵界的秘密……”</p><p>“你说你说啊。”</p><p>“这灵界与凡界啊，说起来那可真是既有关系又没关系。灵界有灵界的独特，凡界有凡界的韵味，它们相互依存又相互区别，灵界不是凡界，凡界也不是灵界，但又都在这世间存在着，谁也离不开谁，这其中的微妙，着实难以言说，说来说去，好像说了些什么，又好像什么都没说……”</p><p>话痨狐狸开始了某种废话文学。</p><p>杨帝对青丘白璃开了静音。现在，仅剩的问题是，“归墟大帝遭到谁人的背叛”？</p><p>又是如何强烈的背叛，才让大帝生出毁灭世界的想法？</p><p>或许是时候去一趟灵界了，毕竟他们已经在凡界晃悠好几天。</p><p>虽然号称“夕阳红旅行团”，但队伍核心宗旨，还是内卷修仙、爬塔升级变强。</p><p>但就在此刻。</p><p>一道奇异的感觉，突如其来。</p><p>杨帝蹙眉，打断本地土著大能和自己小弟之间的长篇废话。</p><p>他微微闭眼，仔细感知。</p><p>整个世界，整片天地的气氛，都发生了某种剧变。</p><p>就仿佛，从表世界走进了寂静岭，从前厅卡进了后室。</p><p>有什么事情将要发生。而这刻，正是暴风雨前低压、潮湿的空气。</p><p>有些事情正在发生，而此时是日出前夕，群星突然消失、东方燃起紫霞的黎明。</p><p>不出杨帝所料，下一刻，一件出乎他所料之事，水灵灵地发生了。</p><p>一股气息“强者气息”出现，极其细微，转瞬即逝，但仍然被他敏锐捕捉到。</p><p>强者，是会相互吸引的。</p><p>修仙三境界，蝼蚁境，道友境，前辈境。</p><p>对杨帝而言，能够达到“道友境”的强者，至少也得是这个世界的“大帝”级别。</p><p>难道是……是的。</p><p>杨帝看向青丘白璃，看向阿巴和59改。</p><p>“非常非常非常出乎意料的情况发生了。现在我们很快就能知道，你我双方各执之词，究竟谁才更有道理。”</p><p>狐种大妖青丘白璃揉了揉狐耳朵：“什么？有什么事情要发生了？”</p><p>“你们的感知力比较差。现在我们先去归墟大帝‘失踪’前，最后停留过的地摊铺子。”</p><p>“十万大山”城市群的边缘郊区景点，某个卖三块钱一大碗山水豆腐花的摊子旁。</p><p>破空而来的一人一鱼一狐一坦克出现于此。</p><p>他们仍然恪守灵界规则，不在人前显圣。</p><p>四人用大记忆消除术让路人觉察不到异常，化身作普通游客，慢慢地走向那卖山水豆腐花的摊子。</p><p>这里就是归墟大帝最后出现的地点。</p>
