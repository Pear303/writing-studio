# 冥想的副作用

<p>……</p><p>42分钟前。</p><p>杨帝：“原来如此，那我该怎么冥想。”</p><p>伊芙：“首先，让身心彻底放松下来，想象春日里融化的积雪，毫无保留地释放所有的紧绷与压力。”</p><p>让自己放松很容易。</p><p>杨帝只需自己对自己催眠，下暗示。</p><p>“然后呢。”</p><p>“我会简单介绍一下原理，让你对接下来发生的事情，有个大概把握。”</p><p>在最初的世界里，现实是混沌而一体的，没有“自我”与“外界”之分，灵能（现实丰度）均匀分布，如同未分化的原始海洋。</p><p>但随着意识的觉醒，世界被“观测”割裂——主体/自我，与客体/外界，相互分离。</p><p>于是，现实被分配成不同的存在。</p><p>冥想，本质上是一种逆向的回归。</p><p>通过削弱主客体的界限，短暂地模糊主客体区分，让灵能从客体流向主体，从而增强自身的现实丰度。简而言之，就是一种客体的主体化。</p><p>“客体世界趋向混乱，而冥想者通过精神集中，局部制造秩序，从而‘窃取’外界的结构。你学会了吗？”</p><p>“听懂了听懂了。”杨帝啄米式点头。</p><p>“如果你触碰到虚境边缘，你会感受到一种前所未有的‘浩瀚’与‘深邃’。但这时千万注意！不要步入‘虚境’，那不是凡人的精神所能踏足之地，你很难再回来了。”</p><p>杨帝听着耳熟的话，有些恍惚。</p><p>很久以前，也曾有人告诉过他，不要踏足深渊。</p><p>“一个人的灵能，他呼呼吸就能补回来，但是拓展上限非常困难。只有当你体内的灵能，长时间保持在充盈、溢出的状态，你才能提高灵能容纳上限。”</p><p>他将伊芙的叮嘱铭记于心，深吸一口气，闭上双眼，躺在非常诱人的床上。</p><p>“睡吧，人类。”</p><p>四周静谧无声，仿佛世界在此刻静止。</p><p>他依照先前自我催眠营造出的放松状态，让身心进一步沉溺其中。</p><p>如同春日暖阳下的一滩积雪，毫无保留地释放着所有的紧绷与压力，意识逐渐变得空灵。</p><p>让主客体之间的界限模糊……</p><p>文艺的说法是拥抱自然，神州的说法是天人感应，西幻称之为回归以太，修仙则称作夺天地造化。</p><p>杨帝尝试从这股浩瀚的力量中汲取“意义”。</p><p>就如同三千弱水，舀取一瓢饮。</p><p>集中精神，感受着那股力量与自己精神力丝线的交融，将其中蕴含的秩序与结构融入自身。</p><p>外界客体世界变得模糊，“灵”在他体内缓缓流动。</p><p>似潺潺溪流，润泽着他的本体，填补自身的现实丰度。</p><p>杨帝在这诸多概念的交织中，进一步沉浸于冥想的玄奇。</p><p>他变成一片飘荡在无垠虚空中的羽毛，既与外界一切连接，又能清晰感知到自身存在。</p><p>然后，杨帝来到了“虚境”边缘。</p><p>他触碰到一片极致静谧的黑暗。</p><p>他听见虚境深处传来的古老呢喃，他听见有声音似乎在诉说宇宙诞生之初的秘密。</p><p>杨帝意识到，自己距离物质世界太远了，必须回来。</p><p>一阵轻微的恍惚，他冲破一层无形薄膜，重新与物质世界建立起联系。</p><p>“灵”在他体内的流动，也从最初肆意润泽，变得更加内敛沉稳。</p><p>「大多数人尝试不久，便会因精神力耗尽而陷入昏迷，睡上一觉……」</p><p>杨帝感觉不到困意。</p><p>相反，还有持续性的「精神+1+1+1……」</p><p>与此同时，自己体内的“灵”，也就表征现实丰度的属性，也在缓慢但坚定地增长。</p><p>「现实+1」</p><p>他原来只有15灵的容量，白天“驾驶”灵能轿厢提升了约0.5灵。</p><p>那么现在，仅仅是通过几十分钟的冥想，杨帝的灵能水平/现实丰度暴增至30！</p><p>他可以就这么“夺天地造化”一整天……三千弱水……我取三万瓢饮！</p><p>不过，杨帝思忖起来：“但如果我不入睡，伊芙和瑞弗他们，岂不是要被夜魅骚扰一夜？”</p><p>虽说那位精灵术士天生神勇，骁勇善战。</p><p>但把怪物晾给他们，而我独自升级，未免有些情节恶劣，影响不好。</p><p>他自己日后，可以有大把机会继续冥想、补完自身。</p><p>杨帝决定暂时退出冥想。</p><p>但伊芙没有教给他怎么退出——因为伊芙从没想过，有人的精神如此强大！居然冥想几十分钟都昏迷不过去。</p><p>他想起伊芙说过，冥想是通过削弱主客体界限来实现的。</p><p>那么，退出是否意味着，要重新强化这种界限呢？</p><p>杨帝尝试在意识中，构建起清晰的主体与客体的区分，将自己的精神力集中于“自我”的认知上。</p><p>他想象外界客体世界的具体模样，回忆自己的模样。</p><p>他不应该是苇草、蚂蚱和清风。</p><p>他能感觉到外界的声音逐渐清晰起来，仿佛从遥远的地方传来，其中夹杂着夜魅尖锐的叫声和伊芙、瑞弗维尔偶尔的交谈声。</p><p>但继续走，前头却有阻碍。</p><p>杨帝像是撞在一堵柔软，却又坚韧的墙上，无功而返。</p><p>“回不去了？怎么可能。给我破！”</p><p>他以撞破南墙的头铁姿态，又试了几次。</p><p>“我是人类，我是杨帝，我是地球人，我是神州青年，我是男人，我曾是工科学士……”</p><p>杨帝有些分不清楚苇草、蚂蚱和清风了。</p><p>万物之间好像是不分彼此的，它们之间都是存在某种更深刻的联系。</p><p>不敢相信，对事物一个概念一个概念，一个范畴一个范畴地划分，居然是可行的。</p><p>杨帝身上在发生一些事情，就像做梦，所有事物之间的联系都轰然断开。</p><p>每一个原子在自由地穿梭、交融，它们不再受限于物体，一切都在难以言喻的虚假秩序中无序地涌动。</p><p>他思维也开始不受控制地蔓延。</p><p>有时是夜魅尖锐叫声的回音，在黑暗世界里飘荡。有时是柑橘味的回忆，却又如流沙从指尖溜走。</p><p>“杨帝是我在18岁时虚构出来的人物，他坐在暴雪中的庭院内，与一只帝企鹅喝茶……”</p><p>他或许是会思考的苇草，或许是秋后只剩一口气的蛐蛐。</p><p>但他绝对不是一阵风。不过，柑橘气味的清风，应该和他有深刻联系。</p><p>指尖触到了某种温热的事物。</p><p>那可能是瑞弗维尔手背的汗，也可能是自己正在蒸发的泪。</p><p>杨帝在混沌中抓住这个锚点，用牙齿死死咬住记忆中关于“人”的定义。</p><p>“我是人，我叫杨帝，我从地球来……”</p><p>我不应该是苇草、蚂蚱和清风。</p><p>我可以无限地进化，无限地适应环境，我比星际虫族更耐杀，你无法杀死我，即使是环境本身，也不应该消解我。</p><p>杨帝睁眼。然后看到朝他轰来的拳头。</p><p>“轰！！”</p><p>杨帝在十分之一秒内释放出10层二环法术·微光护盾。</p><p>坚韧的白色薄网，瞬间挡在他与那轰来的拳头之间。</p><p>“伊芙？你在整什么活……”</p><p>杨帝还未完全反应过来时，伊芙侧身借力刹那间脱开他胳膊的臼，那柄刻有R.L.的短刀刺入喉咙，但精妙地避开了颈大动脉、食道和气管。</p><p>伊芙手心的光球放出强光，刺得杨帝睁不开眼，只能听见一个声音，柑橘的清甜萦绕在鼻尖：“睁开眼，直视我！我问你答，你只需要回答你脑子蹦出的第一个想法，明白？”</p><p>（第48略微修正了一点，将「存在」改成「现实」，统一了专有名词的使用规范，有助于维护语言的纯洁性和稳定性。）</p><p>（灵=灵能=现实丰度=现实）</p>
