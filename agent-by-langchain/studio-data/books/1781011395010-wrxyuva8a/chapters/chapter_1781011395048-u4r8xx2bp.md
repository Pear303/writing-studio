# 耶罗大仙

<p>杨帝转身，意识的原野上炸开无数道银色裂痕。</p><p>每一道裂痕都延伸出迥异的人生轨迹：</p><p>有的世界线里，他从未目睹过那张蓝天红气球照片，在拼优饭的米粒卡喉之夜平静死去。</p><p>有的世界线中，他与陈昭联手献祭了整个稷海理工，让伟大的耶罗降临于此世。</p><p>有的世界线，他背刺胡彦卓，让自己逃出了无限循环轮回的艺术楼楼梯。</p><p>当他再度回望前方，所有的世界线突然像被黑洞吞噬般向内坍缩。</p><p>在坍缩的中心点，虚无以实体形态呈现，那是比黑暗更深沉，更纯粹的黑暗。</p><p>“我这是……我过去的每一条世界线，都集中到了当下这一个点。”</p><p>“来到此处，是命定之事？”</p><p>杨帝的灵体在虚无边缘震颤。</p><p>此刻，星空深处渗出一缕明黄。</p><p>他听见陈昭在地下室发出癫狂的嘶吼。片刻，陈昭没了声息，似是断气了。</p><p>这家伙，不知有没有成功把自己的“灵”奉献给了耶罗大仙。</p><p>但可以肯定的是，他把自己的狗命，交给了那个存在。</p><p>明黄迅速蔓延成漩涡，中心处缓缓升起一道模糊的轮廓。</p><p>杨帝注视着那抹黄色轮廓。</p><p>「精神+1+1+2+3……+6765+10946……」</p><p>仅仅一眼，像是被掀开了头盖骨，将一大箱二踢脚塞到里面的脑浆，嘣，爆炸！</p><p>「崩坏抗性+1+1+2……+4181+6765」</p><p>但杨帝没死。</p><p>他正在以恐怖的速度，暴涨精神属性，适应与这尊存在大眼瞪小眼！</p><p>毫无疑论，不论是抽象程度还是力量水准，耶罗大仙远胜希夷。</p><p>仅仅数十秒时间，像是过去了几千年！</p><p>他感觉自己被放置在地心，经受着数以亿计大气压的沉重压迫！</p><p>那种压抑和窒息感，要将人无尽地拉伸、扯裂、压扁！</p><p>又好像把一个人，强行塞进一个乒乓球内，但那个人非但没有死，而且思维极度清晰敏锐。</p><p>一个人类，你都清晰的感受着自己变成潮汕肉丸或广式腊肠。</p><p>第一秒，杨帝开始悔恨，悔恨为何没有早点自杀，悔恨自己为什么生在这个世上……</p><p>「……精神+17711」</p><p>第二秒，他尝试一切办法自杀，却发现自己无法动弹半分，甚至无法咬舌自尽。</p><p>「……精神+28657」</p><p>第三秒，第四秒……在地狱里的那段岁月越拉越长，无限膨胀。</p><p>「……精神+46368」</p><p>直到某一瞬间，杨帝才终于适应，进化，免疫。</p><p>「精神+1+1+1+1……」</p><p>这一刻，他终于有资格，与那黄色影子四目相对视了。</p><p>高耸王冠下无数虚影明灭闪烁，祂拖曳的衣摆褶皱里，似有无数星辰诞生又毁灭。</p><p>祂仍然很模糊，轮廓明灭不定，细节不清晰。</p><p>杨帝觉得，正常情况下，祂的细节应该更清晰可辨。</p><p>每一个细节，微小到瞳孔、毛发、原子，乃至无穷小的存在——都应该纤毫毕现。</p><p>也许是出于对他的照顾，也许是其他什么原因，祂降低了自己的分辨率。</p><p>尽管如此，也在十二秒前，远远远远超过了杨帝精神力承受的上限。</p><p>“你就是耶罗大仙。”</p><p>杨帝说完，又回头瞥了一眼，无穷多条世界线汇聚于此。</p><p>他回过头，继续说：“是你把我引到此处，是你……无论过去的我做出何种选择，我最终都会在这儿与你见面，耶罗。”</p><p>那个黄色的王者却摇摇头。</p><p>祂的声音亦从四面八方而来，像是数百万亿个人，在他上下四方说着同一句话：</p><p>「不是我。你，自己来的。」</p><p>“我自己来的？”</p><p>「你凭自己，意志，技能，走到这一步。我，没有对你，施加，任何影响。一切，不过是有意，巧合。」</p><p>“……”杨帝从祂话里，感受到一种肯定的，确信的意味。</p><p>「我，无法影响，你次元。我，无法编织，你次元，剧本。」</p><p>祂看起来有些……掉帧。</p><p>耶罗的声音如洪钟般在杨帝的意识中轰鸣：</p><p>「时间有限，你可以，问，任意问题。」</p><p>杨帝：“陈昭现在怎么样了？”</p><p>耶罗大仙：</p><p>「他，妄图以，灵，换取我垂青。他，已被我汲取，意识消散，无尽虚空，永无超生。他，太贪婪，妄图窥探，不可触及领域，被欲望，吞噬。」</p><p>杨帝想起胡彦卓和希夷，接着追问：“胡彦卓和希夷呢，他们有事吗？”</p><p>「希夷，胡彦卓，吾已吞此二人。」</p><p>寥寥几句话，杨帝头痛欲裂。</p><p>他说：“你不能吃他们，把他们还给我。”</p><p>「他们，已泯灭。他们，未曾存在。」</p><p>杨帝感受到耶罗大仙话语里，所蕴藏的毋庸置疑的肯定。</p><p>他环顾四周，观察这片粘稠的星空。</p><p>真奇怪，感受不到悲伤与喜悦，好像劫后余生不值得欣喜，而同伴的消逝也不值得遗憾。</p><p>他抬眼直视那明黄色的模糊影子，问道：“这是哪？”</p><p>耶罗大仙的身形微微波动，那拖曳着无数褶皱的衣摆仿佛在另一个维度中翻涌。</p><p>祂的声音如滚滚雷音，在这片奇异的空间中回荡：</p><p>「你，现在，无法理解。蜉蝣，难以理解，天空广袤。」</p><p>“你是什么？”</p><p>「话本编撰者，黄衣之王。」</p><p>“你既然是话本编撰者，那你能编织剧本？”</p><p>「可编，可改，但非随意，有律可循。诸般世界，都有轨迹，我顺其势，略作勾勒。」</p><p>“我怎么了？为何会突然来到这里，我的身躯又在哪？”</p><p>「你，灵体，挣脱躯壳，跨越重次元，来此处。你，身躯，原本次元，陷入沉睡。」</p><p>杨帝握紧双拳，回想起过去八九天。</p><p>他回想起从琦玉锻炼法，到自戕锻炼法，而后是极限自杀锻炼法……</p><p>他回想起初次面对耶罗大仙时，精神力疯狂攀升、狂飙、适应的过程。</p><p>“我身上的无限进化能力是怎么回事？”</p><p>「不知。」</p><p>“这项能力是某人赋予我的吗？”</p><p>「不知。」</p><p>“为何我的无限进化，能够违反物质能量守恒，甚至比游戏内的虫族更加离谱？”</p><p>「不知。」</p><p>“……耶罗，关于宇宙、生命和意义的终极答案是什么？42吗？”</p><p>「对你宇宙而言，非42，是535559835。」耶罗大仙如是说。</p><p>祂突然爆出一串九位数，闹得杨帝有些懵。</p><p>耶罗大仙……能明白这个宇宙的终极答案，却也不知道杨帝他身上“无限进化”能力的来源？</p><p>潜意识中升起一个声音，一个久远缥缈的声音：「现实+1」。</p><p>杨帝：“你在此与我交谈，我需要付出代价吗？”</p><p>「需要。」</p><p>“什么代价？”</p><p>「你的现实。但是，你杀不死。所以，吞食，你存在痕迹。」</p><p>“什么意思？你把我所有存在过的痕迹抹除了？！”</p><p>「是。那些，不是你的，我，可以吞食。」</p><p>魔性。杨帝脊背发寒。</p><p>他还欲再问，耶罗大仙周身光芒闪烁。</p><p>整个空间陷入绝对寂静，祂的轮廓变得模糊不清，融入了这无尽虚无。</p><p>「时间已到，你该回了。」</p><p>「■■■■■■」</p><p>「我们，还会再见面。」</p><p>话音落下，杨帝只觉天旋地转，目光迅速回溯——次元之外、无穷维度、无穷时空、可观测宇宙、双鱼-鲸鱼座超星系团复合体、银河、太阳、地球、神州、稷海……</p><p>他躺在艺术楼的三楼，圆形音乐厅。</p>
