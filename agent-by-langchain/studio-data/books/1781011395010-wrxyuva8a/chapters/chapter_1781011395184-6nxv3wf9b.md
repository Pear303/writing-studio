# 闪通玉盘·扇区3

<p>白女推了推眼镜，只留下毫无感情的下半张脸：</p><p>“最重要的是，桂先生，工会的力量在于集体谈判权。</p><p>“您的雇佣关系，终止于我们今天的会议之前，工会对此没有追溯力。</p><p>“即使突然间耶稣降临，让您现在立刻、马上加入了一个工会，获得席位。</p><p>“它也无法改变您已被合法解雇、且依据合同及加州法律无权获得额外赔偿的事实。”</p><p>什么叫特么的零赔偿……桂虚喃喃。</p><p>咖喱男瞥了一眼文件。</p><p>他适时地补上了最后一刀，语气带着事不关己的善意提醒：</p><p>“而且，密斯特桂，您目前的签证状态，是基于公司雇佣的。雇佣关系的终止，意味着您的合法居留身份也将面临问题。您需要尽快处理转换身份或离境事宜。”</p><p>呵，背叛……</p><p>桂虚强迫自己挤出一个僵硬、甚至带着点谦卑的弧度，声音干涩地问：“那……那我是不是要退出那个‘黄粱一梦’金融预测系统项目了？我是负责技术开发和维护的，还有些文档没来得及归档……”</p><p>咖喱男的嘴角似乎又向上扯了一下，这次更明显，带着一种掌控全局的、近乎施舍的意味。</p><p>他身体微微前倾，双手指尖相对，摆出一个经典的谈判姿势。</p><p>“Mr. Gui，感谢您的专业素养，事已至此还想着交接。不过，不必了。您的工位，已经由一位更符合项目‘新阶段需求’的工程师接手。您的所有任务权限，在本次会议开始前……”</p><p>他抬腕看了看那块闪着冷光的昂贵手表，“准确地说，是在您踏入这栋大楼的那一刻，就已经被‘安全地’、‘彻底地’移除了。”</p><p>白人女点点头。</p><p>“这是标准的安全流程，请您理解。毕竟，我们需要确保公司资产，尤其是像‘黄粱一梦’这样的核心项目，不会遭受任何嗯……潜在的、报复性的破坏风险。”</p><p>报复性破坏？</p><p>这个词像一根烧红的针，狠狠扎进桂虚的神经末梢。</p><p>一股混杂着荒谬、愤怒和冰冷嘲弄的洪流，瞬间冲垮他强行维持的平静假象。</p><p>“敢做出‘报复性破坏’的人，会被本行业全面封杀。你们信不过我？”</p><p>桂虚脸上表露出极致的愤怒与恨意。</p><p>他痛苦地低下头，把脑袋埋在胳膊里。</p><p>他肩膀似乎因为“过度悲伤”而微微耸动。在咖喱男和白人女看来，这是崩溃的前兆。</p><p>然而，在那低垂的眼睑下，一丝狰狞到近乎疯狂的笑意，如同毒藤蔓般，悄然爬上了桂虚的嘴角，扭曲成一个无人能见的弧度。</p><p>笑容。</p><p>——带着三十五岁老油条码农、浸透了咖啡因和熬夜怨气的、冰冷的、带着血腥味的狡黠。</p><p>报复性破坏？</p><p>呵。</p><p>他早就留下了“东西”。</p><p>不是病毒，不是逻辑炸弹，不是那些低级、粗暴、容易被发现的恶意代码。</p><p>他留下的，是更“桂虚”式的东西，防御性编程的终极形态。</p><p>那些年，在用户需求朝令夕改、项目经理反复横跳、测试环境如同豆腐渣工程的蹂躏下，他早已练就了一身自保的本事。</p><p>桂虚在核心模块里，像地鼠打洞一样，埋下了无数个只有他自己知道的、极其隐蔽的“安全阀”和“检查点”。</p><p>其中有一个，是他最隐秘的杰作。</p><p>一个被他私下命名为“阴伏流煞”(Influenza)的后门。</p><p>这名字起得既贴切又恶趣味。</p><p>它的原理，是精心设计的、潜伏期漫长的致命赛博流感。</p><p>通过一个极其细微的边界条件处理瑕疵，一个在代码评审中被他以“性能优化”为名巧妙保留下来的、看似无害的“特性”，它会悄无声息地影响某些关键变量的内存分配和溢出保护机制。</p><p>最精妙之处在于，它不会立刻发作，而是依赖一个看似合理的“心跳摇篮”机制。</p><p>罗辑同款。</p><p>这个“心跳”，就是桂虚本人的定期手动维护——被他伪装成“例行性能调优”的习惯性操作，每三天，都会在夜深人静时执行一次。</p><p>只要超过三天，没有他的“心跳”去重置那个特殊的计数器……</p><p>“阴伏流煞”就会悄然苏醒。它不会直接崩溃系统，那太低级。</p><p>它会像真正的流感病毒一样，开始蔓延。</p><p>一些关键变量的值，会在看似随机的计算中，悄无声息地突破精心设定的安全阈值“灵茶山乂斧”（0x3f3f3f3f）。</p><p>起初只是零星的数据漂移，如轻微咳嗽。</p><p>然后是指标监控的误报，便是低烧。</p><p>接着是依赖这些变量的下游逻辑开始出现难以复现的、诡异的连锁错误，相当于高烧不退、浑身酸痛。</p><p>最终，当这些错误积累到足够多、覆盖范围足够广时，整个系统的核心将如同陷入高烧谵妄的病人，逻辑混乱，输出不可预测的、灾难性的结果。</p><p>这个过程，根据系统负载和触发条件的不同，可能持续数小时到数天。</p><p>但结局早已注定——系统性的崩溃与大规模数据污染。</p><p>这就是为什么，他上次得了那么重的流感，咳得撕心裂肺，也只敢请假三天！！！</p><p>三天，是他的安全线，是“阴伏流煞”沉睡的期限！</p><p>他拖着病体，在第三天深夜挣扎着登录系统，完成那次至关重要的“心跳重置”。</p><p>几十分钟前，他被一脚踹开，权限被剥夺。</p><p>距离他上次“心跳重置”，已经过去了……整整三天零几个小时？</p><p>又一个三天之期。</p><p>时间掐得刚刚好。</p><p>一股冰冷的、带着血腥味的快意，像毒液一样瞬间流遍他的四肢百骸，压过喉咙里的腥甜和胃里的灼痛。</p><p>他抬起头，脸上的表情，迅速切换成一种被彻底击垮后的麻木和顺从。</p><p>那抹狰狞的笑意消失得无影无踪，只剩下空洞的眼神，和微微颤抖的红唇。</p><p>“我……明白了。”他的声音沙哑，带着浓重的疲惫感，“谢谢……解释。”</p><p>他伸出手，不再看那份协议一眼，手指僵硬地抓起那支冰冷的笔，在白人女指定的地方，签下了自己的名字。</p><p>签完字，他把笔轻轻放回桌面，仿佛放下千斤重担。</p><p>他站起身，动作有些迟缓，像个真正的、被风车彻底打败的盗版堂吉诃德。</p><p>“阴伏流煞”，Influenza……</p><p>流感……该发作了。</p><p>祝你们……咳得愉快。</p><p>中文代号“黄粱一梦”，由我一行代码一行代码构建起来的虚拟沙盘，安息吧。</p><p>桂虚回到“家”。</p><p>妻子和儿子还在外边买日用品。等他们回来，我们就回去吧。</p><p>他拿起床头柜上那瓶从国内带来的、还剩最后一点的棕褐色药液——康复新液。</p><p>美洲大蠊干燥提取物的独特气味，依旧令人作呕。</p><p>他拧开瓶盖，对着窗外同样刺眼但已无关紧要的自由的阳光，举了举。</p><p>“敬……你马币。”</p><p>他低声说，然后仰头，将那混合着土腥与微甜的最后一口，一饮而尽。</p>
