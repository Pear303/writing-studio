# 团伙落网

<p>“渴求之器具”寻了处好地方摆摊。</p><p>直到两名同袍突然朝祂冲来，口中念念有词“不好！是城管！快跑！！”</p><p>祂表面的人脸同时露出惊恐表情，从中喷出的蛊惑之音瞬间转为尖叫。</p><p>渴求之器具，这个平时总爱用幻化成各种神器的分身，以勾引修行者的存在，此刻竟将所有分身强行召回本体，化作布满倒刺的黑球，疯狂撞开挡路的虚境雪糕桶，朝远方跑去。</p><p>「饿货，丧尸，你们特么跑远点！别跟牛皮癣一样粘着我！！本居士小本买卖，合法经营，城管来了也无大碍！身正不怕影子斜！！」</p><p>「人多力量大，聚在一起挺好的呀。」</p><p>「没事即便你再清白，只要和我们一块跑，也必定会被一块儿追。」</p><p>「换言之，入了我们这个团伙，你就洗不清了。」</p><p>「所以，你我只剩下最后一条出路——继续稀释概率。」</p><p>茫茫之虚境，浩瀚如虚境。</p><p>如果想要凸显虚境的浩瀚与庞大，而将其比作大海、天空，那反而缩了水。</p><p>虚境就是虚境，以世间任何具体的万物去描述它，都只会矮化它。</p><p>它是超越了万类认知与想象边界的存在，是无数可能性交织的混沌场域，是现实与虚幻相互渗透的无垠渊薮。</p><p>这里，没有实质上的时间与空间。</p><p>其本质的“浩瀚”，本身就是绝佳的藏身场所。</p><p>“虚空之低语”早早就发现了逃亡团伙和城管的到来。</p><p>祂选择最安静最省力的逃亡方式。</p><p>祂不再发出任何蛊惑人心的私语，而是悄然将自己融入虚境的阴影中，化作一缕几乎不可见的灰雾。</p><p>虚境，没有严格意义上的时间。</p><p>虚空之低语，看名字就知道是个话痨。祂认为自己已经安静太久，又忍不住窃窃私语：</p><p>「怎么回事？为啥没有动静？那老倌儿走了不成？被那厮搅动的虚境竟然这么和平？」</p><p>身后响起三个声音：</p><p>「对啊，对啊，为什么呢？」</p><p>「对啊，对啊，为什么呢！」</p><p>「对啊，对啊，为什么呢。」</p><p>“虚空之低语”吓得浑身一哆嗦，灰雾剧烈翻滚，好不容易稳住身形回头看去，只见世界之喰煞、生命之织缕和渴求之器具正一脸嬉笑地看着祂。</p><p>「你们三个瘟神！又把祸水东引！」虚空之低语向来说话都是“低语”，这回破戒了，是祂第二次放声尖叫。</p><p>第一次尖叫，则是杨帝追杀祂的上一回。</p><p>世界之喰煞咧开黑洞般的巨口，发出一阵令人毛骨悚然的笑声。</p><p>「嘿嘿嘿，咱们一起合计合计，说不定能想出个法子逃出杨帝魔爪。再说了，多一个人多一份力嘛。」</p><p>渴求之器具的无数张人脸同时露出诡异的笑容，齐声说道：「没错没错，现在可不是内讧的时候。」</p><p>生命之织缕只发出一声叹息。</p><p>另外三个虚境神灵看向祂。</p><p>「丧尸，你为何叹息，你有何看法？你觉得该怎么逃？还是继续在这躲下去？」</p><p>“丧尸”，是尸山与血海的散布者「生命之织缕」的小名儿。</p><p>生命之织缕随即轻笑出声，粉色雾气剧烈翻涌：「各位，我倒觉得，与其像丧家犬般逃窜，不如直面杨帝。」</p><p>世界之喰煞的黑洞巨口凝滞在半张状态，渴求之器具的人脸同时浮现惊恐与不解，虚空之低语更是发出尖锐的嘶鸣。</p><p>「你疯了？！上次被他追杀到形神俱灭的滋味，你忘了？！」</p><p>「我当然没忘，所以抱歉了，诸位，我是卧底。」生命之织缕哈哈大笑。</p><p>下一刻，杨帝的声音从四面八方传来：“好都到齐了，我宣布几件事儿。”</p><p>螳螂捕蝉，蝉里面有个卧底，还有只黄雀跟在后。</p><p>这绝境太绝了，三位虚境大能除了将生命之织缕这一罪行记在小本本以外，现在什么也做不了。</p><p>鱼和坦克，此时也围靠上来。</p><p>「杨帝阁下，这就是您所说，我日后需要重点监管的四位对象？」守望者-59改问。</p><p>杨帝点点头：“不错，从今往后由你来监管虚境的市场秩序，别让这四个占据‘原初之眼’生态位的家伙太过猖狂。”</p><p>这回，轮到“生命之织缕”有些慌了。</p><p>「杨帝……我也在重点监管对象中？」</p><p>“啊，这样吧，生命之织缕，你带我找到祂们三个，算是有功神士。当罚则罚，当赏则赏，看在你这次立了大功的份上，允许你保留十分之一的非法所得——不过得换算成宇宙环保积分，用来给被你们祸祸过的星系恢复生态，重建文明……”</p><p>他们正说着，一座银白色机甲携流光溢彩，从虚境远端而来。</p><p>正是「无限机兵」。</p><p>但现在，驾驶员不再是杨帝。</p><p>驾驶者是守望者文明超庞大的格式塔思维。</p><p>“哦对了，经过一段时间的研究，无限机兵与原初之眼，二者在因果序列上的优先度，高于宇宙间其他万物。</p><p>“原初之眼的‘绝对观察者’生态位被你们四个家伙占据了半壁，那么，另外半壁将由守望者文明驾驶这台机兵，对你们实行‘制衡’。</p><p>“嗯……告诉四位另外一个好消息——守望者文明将不仅仅分走一半‘绝对观察者’生态位，每时每刻观察着万物走向。</p><p>“他们还会成为本宇宙的‘最终观测者’，确定本宇宙的唯一历史线哦。</p><p>“虚境虽然很虚，但也是宇宙、世界、也是这片天地的一部分。</p><p>“希望丧尸、饿货、品如、话痨，你们四个能好好遵守我划下的规则。</p><p>“记住，我只是不想过多干涉世界原本的面貌，但这不意味着，我永远不会亲自下场‘干票大的’。”</p><p>四小贩只能像四只斗败的咕咕鸡，唯唯诺诺地点头答应。</p><p>其中，三个小贩目光灼灼地盯着“生命之织缕”，眼神里有深深的怨恨，即将要用目光将祂千刀万剐，剐成生神片，大快朵颐。</p><p>“生命之织缕”被这几束目光盯得心里直发毛，粉色雾气不安地翻滚着，试图解释：</p><p>「各位，我也是没办法啊，杨帝那等存在，咱们根本抗衡不了……咱都是出来混，就别这么内斗了好吗……」</p><p>「闭嘴，这几天夜就拿你当配菜了。」</p><p>「……不如我们讨论一下‘品如’是我们之中的谁？」</p><p>「丧尸是生命之织缕，饿货是喰煞，话痨是低语，为什么渴求之器具是‘品如’？」</p><p>「其中必定隐含着某种深意。」</p><p>「但城管杨帝……修炼了非常高级别的大脑封闭术，即使是我们，也不能轻易窥探到他的思想。」</p><p>「怎么，你还想着窥探他的思想？离我远点呐，血别溅我身上。」</p>
