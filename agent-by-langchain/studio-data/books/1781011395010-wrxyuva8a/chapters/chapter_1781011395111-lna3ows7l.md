# 预知梦

<p>瑞弗维尔没有死。我是瑞弗维尔。所以我没死。如此完美的形式逻辑三段论。</p><p>他脑子里如是想到。</p><p>但为什么自己还活着呢？</p><p>烟尘中，一道青芒如破晓利剑撕开混沌。</p><p>瑞弗维尔以诡异的姿势悬浮半空，三支鎏金戒指，在右手食指、中指、无名指飞速旋转，环身镌刻的远古符文正迸发着幽蓝、赤金与墨绿的光芒。</p><p>幽蓝、赤金与墨绿的光流如漩涡般绞杀着黑色法术洪流，空气中爆发出一连串细密轰鸣声。</p><p>本该成为亡魂的图书馆馆长毫发无损。</p><p>而他周身缠绕的三股力量，如同活物般相互纠缠，形成一道不断重组的防护屏障。</p><p>是的……昨日在砾石镇铁匠铺，瑞弗维尔向伊芙坦白了自己梦，梦中精灵追杀他。</p><p>于是，她交给瑞弗维尔三枚力量之戒。</p><p>而追溯三枚戒指的渊源——它们来自第一席红衣主教。</p><p>也就是在末日火山，和其他教廷修士揉合成“奇行种”的那位。</p><p>现在，三枚戒指戴在瑞弗维尔手上。</p><p>它们挡住了伊芙的九环法术一击。</p><p>虽然在伊芙残存理智控制下，已被削弱80%的力度，但仍然不容小觑。</p><p>而操控力量之戒，本身也需要使用者有一定灵能基础的。</p><p>瑞弗维尔的脸庞因力量过度消耗而扭曲，发根开始泛起霜白，这是透支生命力的征兆。</p><p>“精灵，加大力度！”史莱姆的声音如同砂纸刮过金属。</p><p>伊芙原本凝滞的瞳孔泛起猩红，手中法杖顶端的宝石，则完全被不安的血色浸染。</p><p>一道更庞大的黑色术阵在天空展开。</p><p>密密麻麻的符文如同倒悬的黑洞，每一枚都流淌着末日般的气息。</p><p>完全体的「九环法术·湮灭之创」。</p><p>矮人从焦土中爬出，脸上还挂着劫后余生的惊恐：“还来？！”</p><p>奥拓四处张望，却发现刚刚支起灵能护盾的杨帝不见所踪。</p><p>丢下自己跑了？！也是，对方没义务救自己，他也得学会自救……如果用钻头现在挖地洞……只可惜瑞弗维尔……</p><p>不。奥拓视野中，终于发现了杨帝。</p><p>杨帝的身影裹挟着炽热的灵能残影，借着爆炸掀起的烟尘为掩护，如鬼魅般绕到熔岩史莱姆身后。</p><p>“你，死吧。”</p><p>一把伸出大手，将其抓住！</p><p>“这不可能！精灵救我！”史莱姆发出尖锐的嘶吼，粘稠的身躯疯狂扭曲，试图挣脱束缚。</p><p>而此刻，精灵伊芙仍然处于释放九环法术的“前摇”之中，她身形僵直了整整0.9秒，没能阻止到杨帝。</p><p>杨帝掌心发力，六环法术，冰霜凛冽，顷刻将其炼化！！</p><p>熔岩史莱姆庞大的身躯剧烈震颤，体表流淌岩浆凝固，化作一颗颗焦黑的石粒簌簌掉落。</p><p>陪了杨帝一路的史莱姆，死了。</p><p>伊芙手中的法杖猛地一颤，血色符文黯淡几分。</p><p>她的眼神中闪过一丝慌乱，原本凝聚的「九环法术·湮灭之创」出现了不稳定的波动。</p><p>瑞弗维尔抓住这转瞬即逝的机会，三枚力量之戒光芒大盛，幽蓝、赤金与墨绿的光流交织成法相金身，一个乾坤大挪移冲向天空！</p><p>“伊芙！醒醒！”</p><p>伊芙不语，只是重新凝聚法术，疯狂下死手。</p><p>她眼中血色暴涨，发丝飘飞，即便九环法术出现波动，她依然强行将那道倒悬的黑色术阵压向地面。</p><p>符文迸发出邪门黑光，所过之处空间寸寸崩裂，宛如末日降临。</p><p>黑色彗星，压向瑞弗维尔。</p><p>他的法相金身光芒在这威压下黯淡了几分，额角渗出鲜血顺脸颊滑落，将衣领染成暗红。</p><p>但伊芙似乎已经摆脱了一半的控制。</p><p>她凝聚“湮灭之创”的速度很慢，威力也比上一回还要低。</p><p>属于自我的意志，正在重新占据身体，但还是不够，还差一点……</p><p>瑞弗维尔直接冲破了黑色彗星。</p><p>拥有三枚力量之戒的他，简直是个超人。</p><p>但是冲破黑色彗星时，周身法相金身仍然崩解大半，三枚戒指也黯淡得只剩微光。</p><p>消耗太大了。</p><p>瑞弗维尔仍然难以驾驭住戒指的力量。</p><p>他的指甲深深掐进掌心，强撑着最后一丝灵能，如离弦之箭冲向伊芙。</p><p>伊芙虽眼神混沌，却本能挥出法杖阻拦，杖头血色宝石迸发出尖锐红光。</p><p>“给我破！”瑞弗维尔咬破舌尖，保持精神。</p><p>幽蓝、赤金与墨绿的光芒骤然暴涨，化作三头虚影，生生撕开红光屏障。</p><p>这是他濒临极限的情况下，三枚力量之戒所能调用的最后灵能了！</p><p>伊芙瞳孔猛地收缩，手中法术出现刹那停滞，而这0.1秒间隙，正是瑞弗维尔翘首已久的机会。</p><p>他欺身而上，左手扣住伊芙的手腕，右手直取她发间的橘红色熔岩发卡。</p><p>发卡表面滚烫如烙铁。</p><p>接触到指尖的瞬间，一股诡异吸力将他灵能疯狂向外拉扯。</p><p>光脚的不怕穿鞋的，他已经没有灵能可被吸了！！</p><p>“果然有鬼！”瑞弗维尔青筋暴起，拼尽最后力气狠狠一拽。</p><p>发卡断裂的脆响与伊芙的惊呼同时炸开，发卡带着几缕精灵的金发被拽了下来。</p><p>橘红色发卡仿佛是依附在精灵脑袋上的寄生物。</p><p>他拉扯开来，发卡藕断丝连，但最后那些缠绕的粘液丝线终于层层崩解。</p><p>伊芙的神智终于恢复100%清醒。</p><p>但随即，她眼神中血色褪去，取而代之的是空洞与迷茫，整个人如断线风筝般坠落。</p><p>而在此刻，眼前的瑞弗维尔已经榨干了体内最后一滴灵能。</p><p>然后，火焰在0.1秒内从瑞弗维尔紧握发卡的手爆发、蔓延全身！！</p><p>“奥拓！！接住伊芙！她身轻如鸿毛你不必担心被压扁！！”</p><p>杨帝飞向另一人，瑞弗维尔。</p><p>他双手搓出一个自行车车轮大小的绿色太阳——六环法术·枯木逢春，强化版PLUS。</p><p>法术狠狠按进瑞弗维尔体内。</p><p>瑞弗维尔双目猛然暴凸，大吼道：“痛！！”</p><p>即使是嘶吼声，也带上显而易见的颤音，他必定沉浸在极大的痛苦之中。</p><p>杨帝为他续命的每一秒，都是煎熬。</p><p>他手心的史莱姆，极度恶毒，正以无可匹敌的热力，毁灭瑞弗维尔的十二正经、奇经八脉、五脏六腑、周天百穴。</p><p>“兄弟，对不住了！！”</p><p>杨帝心一横，抽出瑞弗维尔腰间的短刀，使出凌厉剑法，手起刀落。</p><p>“咔——”</p><p>这位前前职业游侠，前图书馆馆长，失去了自己的右手手掌。</p><p>那个橘红色发卡紧紧抱死了瑞弗维尔右手掌心，杨帝只能这么干。</p><p>但终于，他不必再忍受蔓延全身的烈火。</p><p>那枚“发卡”在地面上形成炽热的漩涡，周围土地岩石开始融化，变成岩浆，向漩涡中心流淌汇聚！</p><p>杨帝迅速又是一个巴掌盖下去，六环法术·冰霜凛冽，连续叠加20个！</p><p>“轰隆隆！！”</p><p>热胀冷缩的膨胀爆炸应声而起。</p><p>然而，那发卡仿佛是来自熔岩地狱的邪物，20道六环法术释放的冰霜触及它的瞬间，迅速蒸腾成白茫茫雾气，根本无法对其造成任何实质性伤害！</p><p>它身上滴落着熔岩，缓缓飞腾而起。</p><p>它准备随机逮住个人来杀。</p><p>“事已至此，我也不能藏拙了……”</p><p>对于这种攻高血厚，但是体积小的“敌人”，杨帝能够天然克制。</p><p>——杨帝一把抓住朝他飞来的橘红发卡。</p><p>炽烈至极的灼烧感瞬时蔓延半个身子。</p><p>杨帝张开饕餮巨口，将发卡吞下。</p><p>刚刚接住伊芙的矮人奥拓看到这一幕，瞳孔地震，心脏都漏了半拍。</p><p>杨帝踉跄着单膝跪地，十指深深抠进滚烫的土地，指缝间渗出的血珠还未落地就化作青烟。</p><p>他皮肤以肉眼可见的速度泛起赤红，血管在表层暴突如扭曲的蚯蚓，热浪从毛孔喷涌而出，空气扭曲成流动涟漪。</p><p>「耐热+1+1+2+3+5……」</p><p>「精神+1+1+1+1……」</p><p>「现实+1」</p><p>奥拓背着伊芙，随时想要溜之大吉。</p><p>再看杨帝，嘶吼渐渐变成粗重的喘息，然后睁开了眼，从地上慢慢爬起。</p><p>“杨帝……你是否清醒……”</p><p>“啊，好多了，上火是真难顶。”他颤抖着撑起身子，染血的嘴角裂开一抹舒畅的笑。</p><p>他的身体没有像急剧升温的岩石那样爆开，而是慢慢冷却，恢复了原样。</p><p>杨帝默默打开自己的“人物面板”，只见原本仅仅1200+的“耐热”属性，瞬间翻了50%，飙升到1800+。</p><p>战斗是最好的进步催化剂，但现在，还有更重要的事情要关注，更多问题亟待解决，更多困惑从迷雾中浮现。</p>
