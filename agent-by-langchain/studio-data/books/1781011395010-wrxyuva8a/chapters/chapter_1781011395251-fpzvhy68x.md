# “你已经学会了用魔法对抗魔法，用编撰对付我的编撰？”

<p>他重复着，声音里带着一种难以言喻的激动，“好！很好！这才有趣！这才配得上……”</p><p>杨帝打断了他的兴奋，语气平淡地投下另一颗炸弹：</p><p>“其实，在来见你之前，我已经永久性地‘杀死’了一个你的受肉/容器。名为‘万业狐狸’的那个存在，其一切痕迹、因果、乃至在众生认知中的烙印，都已被我从根源上抹除。从此，世上再无万业狐狸。”</p><p>他看向耶罗，等待着对方的反应。这理应是一次沉重的打击。</p><p>然而，耶罗只是微微偏头，脸上露出些许真实的困惑，仿佛在记忆的仓库里翻找一件无关紧要的物品。</p><p>“万业……狐狸？确实，我好像是不记得有这么一个具体的受肉了。”</p><p>他沉吟了一下，随即恍然，却又带着一丝轻蔑的笑意，“被抹消了？嗯，手段不错，干净利落。”</p><p>他话锋一转，狐尾——不，那毛茸茸的尾巴激动地甩动了一下——带着一种近乎戏谑的意味看向杨帝：</p><p>“但是，我亲爱的杨杨帝，有一点你猜得大错特错！”</p><p>耶罗猛地扯下兜帽，露出一张尖削带吻部的脸，细长的眼睛里闪烁着狡黠的光芒。</p><p>“我从来都不是狐狸！”</p><p>他几乎是大笑着喊出这句话，“回想一下第354章！在该死的出租屋里，你那一拳轰在我脸上的时候！巨大的冲击力让我的面部结构都暂时发生了形变，呈现出明显的鼬科动物特征！那时我都以为凭你的观察力，早该看出我的真身了！”</p><p>他凑近几步，脸上那皮笑肉不笑的表情变得清晰而诡异：</p><p>“没想到你啊没想到，你居然真信了那些外界以讹传讹的‘狐狸’说法？还一本正经地叫我‘万业狐狸’？真是可爱得让我发笑。”</p><p>耶罗，或者说，耶罗大仙，挺直了身子，脸上带着一种揭露真相的得意洋洋：</p><p>“听好了，杨帝！吾之真身，乃是鼬科仙祖，黄门魁首——黄鼠狼是也！‘耶罗’不过是‘黄鼬’（Yellow Weasel）的部分音译！这才是我的本来面目！你难道不好奇！赤狐（Red Fox）和北极狐（Arctic
