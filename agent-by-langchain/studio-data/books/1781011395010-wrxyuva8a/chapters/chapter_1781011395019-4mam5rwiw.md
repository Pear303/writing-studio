# 万能锻炼

<p>牙齿这种羟基磷灰石结晶结构……怎么可能适用肌纤维的损伤修复机制？</p><p>不，从生理学上来讲应该是不行的吧？</p><p>杨帝从小身体虚弱，他还去补过几次牙。</p><p>他是明白的，如果牙齿能自行修复，牙医根本不会那么好赚钱。</p><p>包括消化系统。从来没听说过饮食能够增强消化系统，一般都是听说暴饮暴食导致肠胃炎、消化不良的啊！</p><p>但为何，明知是不科学的，自己潜意识里还会冒出“消化+1”。</p><p>杨帝拿着倒数第二个小笼包的手又僵住了。</p><p>潜意识？</p><p>这想法一冒出来，杨帝自己都有些震惊。</p><p>“人的感觉系统每秒都在向大脑传递着1100万比特的信息，而意识能处理的部分只有不到每秒50比特，其余的信息都交由潜意识完成……”</p><p>他从日常生活，也能隐约感觉到，还有一股庞大的、不流于自己表面思想的潜意识，在暗中支配人的一颦一笑，七情六欲。</p><p>就好像一台电脑。</p><p>鼠标键盘、桌面软件，这些都只是计算机本身展露出来最表面的冰山一角。</p><p>而键鼠和软件的运作——其实都被电脑之中最底层的程序代码所操控着。</p><p>一般人耍电脑的时候，都极少会使用到这些系统底层的代码。</p><p>他们只需要耍好键盘和鼠标便可。</p><p>一个小小的移动鼠标操作，就能牵涉大量底层代码工作：</p><p>从鼠标的传感器捕捉到物理移动信号，将其转换为数字信号……</p><p>通过USB接口传输到电脑主机，电脑驱动程序接收信号后，在操作系统进行解析和处理……</p><p>然后将指令传递给图形界面，最终在屏幕上显示出光标的移动轨迹……</p><p>人的潜意识，就如同这电脑底层的代码。</p><p>看似无形，却掌控着许多连自己都未曾察觉的行为和反应。</p><p>人仅靠表层意识本身，无法完美地觉察身体各个部位的准确状况。</p><p>但是，如果涌上杨帝心头的“体力+1”、“消化+1”，就是他潜意识的手笔呢？</p><p>是他的潜意识，在实时监控身体各个部位传来的数据？</p><p>“如此说来，便不是‘觉醒系统’，而是我的潜意识在对我‘汇报’身体情况……”</p><p>杨帝拍拍脸。</p><p>每个人的潜意识，本就是24小时运转的生物智脑。</p><p>只是99.99%的人从未获得管理员权限。</p><p>牙齿咬合时，传来的反馈异常清晰，杨帝似乎能感觉到，牙釉质的裂纹正在某种催化作用下缓慢地实现自我修复。</p><p>非常非常慢，但他真的感觉到了。</p><p>这绝非传统认知的人体机能，倒像是各大文艺作品里高武级别的“异能丧尸”。</p><p>或者更进一步，能够无限修复自身的“星际虫族”。</p><p>他吃完最后一个小笼包。</p><p>“那么……继续验证？”</p><p>在饭堂大妈惊异目光的注视下，杨帝离开了深夜食堂。</p><p>吃饱喝足不宜剧烈运动。他来到田径场旁的器材区，找到一处生锈的单杠。</p><p>他当即做起引体向上。</p><p>生锈的单杠立刻发出吱吱呀呀声。</p><p>比金属变形更震撼的，是此时此刻涌入脑中的信息流：背阔肌纤维略微撕裂，睾酮分泌量提升，乳酸代谢速率……</p><p>断断续续做了十七八个引体向上。</p><p>“停！”他踉跄落地，扶着膝盖剧烈喘息。</p><p>这些海量数据若在平日足够写满三页体检报告，此刻却被潜意识自动提炼成简洁的「上肢+1」「单杠+1」「体力+1」。</p><p>就像超级计算机将万亿次运算结果，凝练成屏幕上的百分比进度条。</p><p>“呼，呼……”</p><p>激动的心，颤抖的手，喘气的肺。</p><p>杨帝脑海里各种念头纷至沓来。</p><p>“如果这些变化都是真的，那我岂不是……”他停顿了一下，似乎在寻找合适的词汇来描述自己的状态，“一个拥有管理员权限的人？”</p><p>拥有管理员权限，呃，又意味着什么？</p><p>最初的兴奋和新奇劲儿散去，杨帝开始务实的思考，这种能力有什么用？</p><p>更好的调控自己身体情况？让他运动起来，呃，更有成就感？</p><p>杨帝从小身子弱，身子板单薄，常常半年一小病，俩年一大病，年纪轻轻成为药罐子，就算有医保也不扛造。</p><p>这回要是能凭借这独特的“管理员权限”，把自个儿的身子骨练得棒棒的，那可就太美了。</p><p>光是未来的医药费都能省很多。</p><p>“事已至此，再锻炼一下不用剧烈运动的上肢，再去睡觉！”</p><p>照例是做引体向上，负重深蹲，这些不那么容易得盲肠炎。</p><p>……</p><p>回到宿舍，张明远还趴在笔记本电脑前做他的项目。</p><p>本科，他学业方面一向很刻苦，和许多混吃等死的同窗不同，看起来是对今后出路有想法和打算的。</p><p>杨帝从他身后走过，去向冲凉房。</p><p>冲了个热水澡，热水将疲惫冲刷殆尽，随着下水道的漩涡螺旋而去。</p><p>热水不算便宜，洗一次花三毛到一块不等。</p><p>但今晚比较特殊，他奢侈了一把，直接将热水拧到最大，犒劳犒劳自己。</p><p>滚烫的热水浇淋全身，消除肌肉疲劳。</p><p>杨帝将头缓缓仰起，目光穿过氤氲的水雾，望向天花板。</p><p>天花板在热气的笼罩下，似是被蒙上了一层梦幻般的纱幕，轮廓都有些扭曲模糊了。</p><p>滚烫的水珠顺着脊椎滑进股沟，五十度的水温持续冲刷着背部。</p><p>皮肤却没有传来应有的灼痛感，反而像浸泡在温泉般舒适。</p><p>「耐热+1」</p><p>“……嗯啊啊？”</p><p>杨帝手指在淋浴开关上颤抖了一下。</p><p>“我丫的想起来忽略什么了……”</p><p>皮肤的表皮细胞、组成牙齿的牙釉质，这些显然不属于传统意义上的“可锻炼器官”，更不存在肌肉纤维的超量恢复机制。</p><p>但它们仍然能……“消化+1”和“耐热+1”？</p><p>这也是能锻炼的吗？这也是能进步的吗？</p><p>杨帝并没感觉水温有多刺激。</p><p>他彻底关掉冷水，热水阀拉满！</p><p>热，烫起来了……他咬着牙坚持站在滚烫的水流下，要通过这种方式来测试自己的身体究竟还有多少潜力可挖。</p><p>这种温度一时半会还不会烫伤，和温泉水差不多，而且是流动的水，只是会事后皮肤发红发痛，看起来有点恐怖罢了。</p><p>「耐热+1」</p><p>杨帝看着自己逐渐发红，却丝毫未出现烫伤迹象的皮肤，心中震惊不已。</p><p>“怎么会？”</p><p>张明远掀开浴室门，出现在一脸懵逼的杨帝身后。</p><p>“张明远你开门干嘛！滚啊！”</p><p>踹门者张明远一脸严肃：“我踏马喊你很多次了，你没出声。”</p><p>“那so鸠rry咯，关门，拜托，谢谢。”</p><p>“你煮虾呢？整层楼热水都被你抽干了！”</p><p>“关门啊北七！”</p><p>“老帝，你别想不开，别像个变态似的把自己烫成麻辣小龙虾。”</p><p>门终于关了。</p><p>密闭的冲凉房内，杨帝关掉花洒，蒸腾的雾气里隐约可见身体泛着奇异的粉红色。</p><p>这不是烫伤的红肿，更像是新生儿娇嫩的肌肤在灯光下透出的血色。</p><p>没有任何刺痛和不适感。</p><p>他手指触碰上去，肌理光滑得不可思议，就像触摸刚剥壳的溏心蛋。</p><p>那些经年累月的痘印和蚊虫叮咬的疤痕，此刻全都消失无踪。</p><p>牙齿硬度也能锻炼？</p><p>皮肉耐热性也能锻炼？</p><p>若顺着这个逻辑去想，说不定身体的每一个部位，都有着被开发、被增强的潜力……</p><p>而自己现在，就是在无意间揭开这神秘面纱的一角！</p>
