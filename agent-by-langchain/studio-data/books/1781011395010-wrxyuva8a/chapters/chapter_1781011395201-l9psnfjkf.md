# 血神有点勇哦

<p>阿巴的神念在狂暴的物理冲击波和法则湮灭的余波中剧烈摇曳，但它那古老沧桑的感知，却被前所未有的震撼填满。</p><p>她看到，圣人级别的战斗，既没有法术的对抗，也没有法则的倾轧。</p><p>只有最野蛮，最原始，最不讲道理的“力”，蹂躏着一切精巧复杂，掌控概率与命运的“理”。</p><p>杨帝不在磨灭大道，他在砸！撕！碎！</p><p>砸碎大道！手撕大道！</p><p>“吼——！！！”</p><p>四大邪神第一次，不得不为了自己的最基本生存而战！</p><p>祂们圣座上的身影像损坏的盗版DVD光盘内容画面一样，疯狂扭曲。</p><p>尤其是坐于颅座之上、试图与杨帝拳头硬碰硬的血神，整个脑袋都被震麻了。</p><p>四大邪神同时爆发出前所未有，混合着惊怒与难以置信的恐怖灵能波动！</p><p>但那并不是向外放射的一样，而是向内收敛成点，有如亘古黑洞般安静地撕裂万物。</p><p>祂们被打痛。应激哈气了！！</p><p>杨帝再次捏紧了拳头，指关节劈啪作响，如同星核在挤压。</p><p>“再来！”</p><p>邪神周身涌动的灵能大潮，被他一拳蒸干，留下沸腾的法则熔岩。</p><p>隆！咔嚓！</p><p>杨帝尤其针对血神哥达内，因为祂太勇了，居然敢和自己硬碰硬。</p><p>祂代表“战”本源的扭曲圣座，被杨帝一记鞭腿抽得四分五裂！</p><p>哥达内的神躯如被打碎的琉璃神像，化作亿万道蕴含着熵之极意的流光碎片，四散飞溅。</p><p>然而，未等杨帝追击，那些碎片竟在翻腾的混沌中自行汇聚，亚空间深处仿佛有亘古存在的血海洪流倒灌而来，瞬间重塑祂的圣座与神躯，只是光芒略显黯淡。</p><p>杀不死！</p><p>杨帝眸光如冷电，洞穿虚妄。</p><p>被他如此针对，但仍无法以物理方式整死。</p><p>这四大邪神的“命”，早已与这方宇宙运行的大道深度绑定。</p><p>祂们的“身”，不过是这矛盾螺旋在亚空间的一个强大投影和凝聚点。</p><p>毁掉这个“身”，不过是打碎了一个水缸，而缸里的水——也就是祂们代表的大道本源，早已弥漫渗透在宇宙的每一个角落，贯穿了时间长河的每一个瞬间。</p><p>祂们会在过去、未来、或者某个未被注意的角落，再次凝聚圣人之位，归来。</p><p>这是“圣人”境存在的终极特性。</p><p>天道不灭，祂们便不死！</p><p>更棘手的是，祂们的灵能早已超越了寻常意义上的庞大。</p><p>甚至可能达到杨帝的级别。</p><p>以至于，祂们自身的灵能，超过了此世所能承载的上限，表现出一种向内坍塌的收敛状态，犹如黑洞，亦如鹌鹑。</p><p>试图将祂们“溶解”于万物，稀释其主体性？</p><p>不够。这个世界的灵能，根本不够这么做。</p><p>可以用一个泳池的水，稀释一桶墨汁。</p><p>但一桶墨汁，无法用一杯水来稀释。</p><p>还能怎么杀死祂们？</p><p>除非……毁掉承载一切的“舞台”——天道！</p><p>将整个宇宙推向大热寂的终点，熵增到最大值，让一切运动、一切矛盾、一切概念都归于死寂。</p><p>那时，依附于矛盾而生的邪神，自然灰飞烟灭。</p><p>但杨帝的目光扫过那翻腾的混沌深处，看到了诸天万界、无尽生灵。</p><p>他不可能为了灭杀这四个东西，就拉着整个宇宙陪葬。</p><p>“身”杀不死，“灵”溶不掉，“世”不可灭……</p><p>那么，路在何方？</p><p>“……我原本还幻想，能否用物理手段揍死你们。但如果我继续发力，整个宇宙、此世天道，都会被我的拳头砸穿。”</p><p>杨帝低沉的声音在破碎的法则乱流中响起，如同混沌初开时的第一声雷鸣，带着一种让四大邪神都感到莫名悸动的蛮荒气息</p><p>“答案已经很明显了——”</p><p>轰——！</p><p>话音未落，杨帝化作一道吞噬一切光与存在的模糊虚影，无视了智神辛烈治瞬间布下的兆亿层陷阱迷宫，无视了沙历士试图扭曲他意志的六大爱恨，无视了那唭枯咆哮着释放的毒瘴！</p><p>他的目标，直指刚刚重塑圣座、气息略显不稳的血神·哥达內！</p><p>杨帝张开了嘴！</p><p>一个漆黑、旋转、仿佛连通着宇宙归墟的恐怖漩涡，在他面前骤然成型！</p><p>吞噬光！吞噬暗！吞噬空间！吞噬时间！吞噬大道！！</p><p>我把日来吞了！我把月来吞了！</p><p>嗤啦——！仿佛宇宙胎膜被撕裂的声音响起。</p><p>血神·哥达内，执掌勇毅与怯懦的莽夫，又一次选择了正面硬碰硬。</p><p>然后，祂就被吞了。</p><p>杨帝吞下哥达内的瞬间，另外三尊邪神的反击如同灭世洪流般倾泻而至！</p><p>面对这足以令任何圣人手忙脚乱、甚至饮恨当场的三位一体绝杀，杨帝眼中只有一片燃烧到极致的、纯粹的凶戾！</p><p>“滚开！”</p><p>一声暴喝，如同开天辟地的神雷炸响！</p><p>他牙口虽好，但胃囊还不够巨大，一次只能吞下一个邪神。</p><p>面对另外三个捣乱的亚空间小贩，杨帝对症下药。</p><p>没有回头，但左手五指猛然张开，化作一道撕裂混沌的利爪，裹挟着纯粹到让空间本身都发出不堪重负呻吟的物理力量，对着身后那片覆盖而来的命神狠狠一抓——</p><p>噗嗤——！</p><p>命神·那唭枯庞大神躯猛地一僵。祂的「心脏」，被硬生生捏爆！</p><p>几乎在捏爆命神心脏的同时，杨帝的精神力猛然震动！</p><p>他不仅没有防御那汹涌而来，来自爱神的“爱欲离恨心魔六环”的精神污染。</p><p>反而将自己那“豆渣”般不可磨灭，承载了无穷战斗意志与吞噬欲望的精神体，投影到爱神·沙历士的「心灵」中。</p><p>杨帝以无匹的“话术+魅力+精神”组合拳，硬生生控制住爱神。</p><p>“1000-7=几？”</p><p>“993-7=几？”</p><p>“986-7=几？”</p><p>“……”</p><p>最后，杨帝的目光如冷电般扫向辛烈治。</p><p>祂眸中闪耀出智慧的光芒，在此刻做出最正确的战术和战略决策——跑路！！</p><p>晚了一步。杨帝右手猛地向虚空一按。</p><p>“领域展开，白杨世界·十万三千怪谈！”</p><p>智神·辛烈治睁开眼。</p><p>此刻，祂正代表某个国度，参与一场“国运+直播+怪谈+擂台+历史断层+心声揭露+大盘点”的超级恐怖的副本！！！</p><p>「亲爱的观众朋友们！欢迎锁定‘寰宇怪谈·国运生死斗’全球直播频道！我是你们的心脏起搏器，能实现愿望的蓝色蘑菇大王！！看呐！最新一期、地狱S+16级副本《白杨世界·十万三千怪谈》已强制载入！本次‘幸运’选手——代号‘智神’！」</p><p>「规则速递：1.国运绑定！选手所属国度身份已录入系统！选手死亡或失败，对应国度将遭受‘天灾级怪谈入侵’！2.神战擂台！每轮随机生成致命‘诡异生物’，选手需要在擂台中具现化出自己国度文化所拥有的神明形象与之对抗！3.心声揭露！选手和NPC的所有思维、恐惧、策略将被实时弹幕化，全球直播！4.大盘点！每间隔时间，系统将盘点选手的强度、弱点，以及历史上各种著名怪谈的特点！5.词条觉醒体系！每位选手每进入一个新场景，会随机觉醒一个E到S级的天赋词条！6.赌注系统，观众可对选手的预测成绩下赌注，买断离手……」</p>
