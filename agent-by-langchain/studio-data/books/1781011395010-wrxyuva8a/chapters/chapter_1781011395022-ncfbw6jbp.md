# 所以你真的要新人类进化？！

<p>六天以来，杨帝一直依靠自戕锻炼法做训练。仅仅是六天，体能便有了质的飞跃，心中响起了上百次「体力+1」，以及其他各种锻炼进步。</p><p>尽管如此，在面对这位名为“胡彦卓”的大哥时，仅仅只是勉强跟上对方脚步。</p><p>就在刚才，胡大哥还随手将他拉爆！</p><p>恐怖如斯，深不可测！</p><p>杨帝还以为自己已经进步了很多，没想到山外有山，人外有人。</p><p>看来还是得时刻保持谦逊。</p><p>不然，怎么随便一个路边跑者，就能反手碾压杨帝！</p><p>自己的锻炼进步速度，还是太慢了。</p><p>每日训练项目还得不断加码，三百个深蹲，三百个俯卧撑，三百个仰卧起坐，12公里长跑。</p><p>据说游泳可以调动全身肌肉，综合性强，可以考虑……</p><p>但因为一些童年阴影，杨帝不喜欢接近水池。</p><p>不过这几天，除了通过不断加码的琦玉锻炼法来提升体能，杨帝也有许多其他收获。</p><p>比如说，时不时弹出来的「视力+1」「听觉+1」诸如此类。</p><p>他能感觉五感都敏锐了很多。</p><p>杨帝推测，人一天中有十几个小时是要用到眼睛耳朵鼻子的。</p><p>只要使用，就会提升「熟练度」。</p><p>嗯，怎么想都很不科学，非常玄幻。</p><p>此外，嗅觉味觉触觉也时不时弹出熟练度提示，比如「嗅觉+1」「触觉+1」。</p><p>杨帝真觉得，假以时日，自己会变超人，而且是没有氪石弱点的地球超人。</p><p>还有「精神+1」，这是众多项目中最神秘的一项。</p><p>一般，都是睡醒一觉后，会触发精神+1。</p><p>睡梦里也有可能触发，但就算有，他也注意不到。</p><p>偶尔，看了一部让他灵魂震颤的电影、或是听了一曲触动心灵的歌，也可能会让精神+1。</p><p>这更让杨帝好奇，这精神到底是个啥东西，本质是什么？</p><p>它增长的机制又是什么？</p><p>最后，经过数日摸索，杨帝发现了让精神增加最快的方法——熬夜。</p><p>往死里熬！</p><p>熬夜→伤神→超量代偿→精神+1→以更好的精神状态继续熬夜→……</p><p>虽然听着很不科学，非常玄幻，但逻辑链是完整的，自始至终逻辑都是自洽的！</p><p>对精神世界之探索，原本一直毫无进展。</p><p>转折发生在能力觉醒后第三日，彼时杨帝正为数学焦头烂额。</p><p>凌晨三点的困倦像潮湿的棉被裹住大脑，直到某个临界点突然炸开——</p><p>「精神+1」</p><p>仿佛有冰锥刺入太阳穴，混沌的思绪瞬间澄明如洗。</p><p>矩阵的秩呈现出几何美感，原本艰涩的证明过程，在精神世界自动拆解重组。</p><p>他从这种奇异状态脱离，桌上的演算纸密密麻麻铺满了整个桌面。</p><p>自此，杨帝开始有意识地记录身体数据。</p><p>他在实验记录本上绘制出三条曲线：红色代表睡眠时长，蓝色标注锻炼和学习时长，黑色记录表示“精神+”出现次数。</p><p>当连续熬夜突破10小时后，那些黑色标记开始呈指数级增长。</p><p>此后又花了一夜时间，杨帝戴着心率手环坐在图书馆顶楼。</p><p>凌晨三点，困倦达到峰值，内心深处同时浮现「精神+1」「视觉+1」「心脏+1」三行文字。</p><p>这种透支与修复的循环，逐渐形成精密的正反馈。</p><p>对常人来说，熬夜只会让精神崩溃，视力模糊，搞不好喜提猝死礼包。</p><p>但对杨帝而言，一切对身体的损伤，都被超量修复代偿！</p><p>包括原本就不可自行修复的牙齿，视力，甚至包括虚无缥缈的精神本身。</p><p>杀不死我的，只会让我更强大！</p><p>跑步，仅仅是他众多锻炼进步之中，微不足道的一小部分。</p><p>只可惜，一系列损伤-代偿机制，虽然挺玄幻的，但似乎……仍然无法摆脱能量守恒定律，吗？</p><p>自戕式运动过后，杨帝需要大量进食补充糖分和蛋白质；但同时，就算他不吃东西，也能保持自己不死。</p><p>反而是熬夜，他发现自己可以无限制熬下去，不需要睡觉来补足精神。</p><p>只需要保持摄入糖分便可，毕竟全速运转的脑子是耗能大户，虽然其重量仅占人体体重的2%左右，但却消耗了人体约20%的糖分。</p><p>为了维持肢体、躯干和大脑“自戕式锻炼法”所需的能量，杨帝每天都要暴饮暴食，这一举措顺带还能锻炼消化系统。</p><p>总之讲究一个只要折腾不死，就往死里折腾。</p><p>这就是自戕式修炼的真谛。</p><p>他能坚持下来靠的不是纯粹意志力，而是众多激素共同影响，让他血液中多巴胺维持在很高水准，保持着高度兴奋状态。</p><p>换句话说，锻炼使人上瘾。</p><p>普通人运动时的愉悦感，或许只有那么短短几分钟，或者十几分钟、几十分钟。</p><p>但杨帝能兴奋上一整天——</p><p>毕竟连上皮组织耐热力提高、牙釉质自行修复等超自然现象都出现了，再多一些超越科学的现象，倒也不算奇怪吧？</p><p>原本，运动、做题，都是非常让人困乏的无聊事。</p><p>但是，当每一丝微小的锻炼进步，都可以被潜意识量化出来。</p><p>就可以当场提供情绪价值！</p><p>并且杨帝发现自己锻炼进步没有器官限制，没有生理上限之时。</p><p>超量运动和熬夜做题，就成了享受，一种能时刻提供大量情绪价值的享受！</p><p>不过，今晚杨帝不打算熬夜跑步。</p><p>他七点半便回到宿舍，准备洗洗睡。</p><p>宿舍黑着灯。杨帝开门闹出一些动静，张明远便从蚊帐里探出半个脑袋，打亮了手电，晃着来者的脸。</p><p>他声音带着虚弱：“老杨你中邪了？这几天五点就往外蹿，回来时衣服能拧出半斤汗。”</p><p>杨帝啪嗒一声打开灯，回道：“中邪的是你吧。整个五一小长假不去玩也不放松，一直在做你那什么神经作业，做完了吃，吃完了睡，睡醒就又开始做。”</p><p>“不是神经作业，是基于人工神经网络的图像识别！”</p><p>杨帝摆摆手，找好衣服去了冲凉房：“我只是锻炼去了，不用管干了啥，比你健康得多的生活。”</p><p>张明远却是翻身下床，“健康？未必，我看你脚步虚浮，气色苍白，让我搭个脉。”</p><p>他一边说着，手指已经按了上来。</p><p>「触觉+1」</p><p>“嗯呃呃……心率52？你特么是冬眠的熊修炼成精化作人形了？”</p><p>杨帝见了鬼的表情望向张明远：“老张，你不是计算机专业吗？怎么还会搭脉？而且一搭脉就知道我心率。”</p><p>“你带着运动手环呐，杨老帝。”</p><p>运动手环上显示，杨帝的心率在50~54之间波动，平均值52。</p><p>张明远继续抖书袋子：“这种低心率，要么是专业运动员，要么是心脏病。”</p><p>杨帝首先排除心脏病。</p><p>那么只剩一种可能了，专业运动员？</p><p>六天下来就能达到专业运动员的体质了吗？</p><p>“运动员是怎么一回事？”杨帝把舍友张明远当成人形搜索引擎了。</p><p>张明远解释：运动员长期进行高强度的耐力训练，他们的心脏功能会变得极为强大。</p><p>心脏每次跳动泵出的血量比普通人多得多，所以不需要很快的心率，就能满足身体的供血需求。</p><p>就好比一台小功率水泵，要不停运转才能送够水；而大功率水泵转一下，顶小水泵转好几下，自然就不用那么频繁工作了。</p><p>最后一拍大腿，痛心疾首：“老杨，你到底这几天干了啥，难不成背着我们偷偷参加铁人三项魔鬼特训了？还是说……你真的要新人类进化了？！”</p>
