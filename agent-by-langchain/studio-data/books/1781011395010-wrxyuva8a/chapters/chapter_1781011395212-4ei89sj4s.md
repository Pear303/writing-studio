# 红皇后主控机房

<p>完了！这个强大到诡异的NPC，在现代化重火力面前，终究还是……</p><p>然而，那团爆开的血雾和碎肉并未落地，反而如同被按下了倒放键，以惊人的速度倒卷、聚合！</p><p>在漫天飞舞的灼热弹雨和刺鼻硝烟中，一个赤裸的身影轮廓在血雾中心瞬间重塑！</p><p>皮肤、肌肉、骨骼……甚至那件蠕动的漆黑“战甲”，都在眨眼间恢复如初！</p><p>杨帝站在原地，仿佛从未移动过。贫铀穿甲弹再次倾泻而来。</p><p>但这一次，它们撞在那具新生的躯体上，却发出如同重锤敲击超合金的沉闷钝响！</p><p>叮叮当当！</p><p>弹头瞬间扭曲、变形、碎裂，化作一片灼热的金属碎屑，溅落在地。</p><p>防御系统似乎也被这违反物理法则的一幕激怒了。</p><p>空气中交织的猩红激光网瞬间亮到极致，高频能量束发出刺耳的嗡鸣，如同死神的剃刀，精准地交叉切割向杨帝的脖颈、腰腹和四肢！</p><p>嗤——！</p><p>杨帝的身体瞬间被纵横交错的激光网切成了十几块整齐的碎块！</p><p>碎块散落一地。</p><p>轮回小队众人再次倒吸一口冷气。这……总该死了吧？</p><p>但下一秒，那些散落的碎块如同拥有独立生命般，在地面上疯狂地蠕动、增生。</p><p>断裂的血管像活蛇般自动寻找对接，切开的骨骼发出“咔咔”的再生脆响，肌肉纤维如同织布般飞速连接……</p><p>仅仅两三个呼吸间，一个完整的杨帝，再次毫发无损地站在了原地。</p><p>这一次，激光网再次扫过他的身体，却如同无害的光线穿过玻璃。</p><p>仅仅只是将他婴儿般弹嫩的皮肤灼红，除此之外，啥事都没有。</p><p>轮回小队的五人如同被冻结在冰层里，眼睁睁看着杨帝以非人的方式硬闯激光网与机炮阵。</p><p>每一次被撕碎又瞬间重组的景象，都在挑战着他们对生命、宇宙乃至万物的认知极限。</p><p>激光网最终失效，哨戒机炮因过热或弹药耗尽而停歇时，走廊里只剩下金属扭曲的焦糊味，融化的地面，和硝烟弥漫的空气。</p><p>杨帝毫发无损地站在那扇厚重合金大门前。</p><p>他目光扫过轮回小队藏身的阴影角落——那目光仿佛能穿透影子的异能，直抵他们瑟缩的灵魂。</p><p>没有言语，但无形的威压如同实质的潮水涌来。</p><p>队长感到自己的念动力场在剧烈颤抖，几乎要被这纯粹的“灵压”碾碎。</p><p>他艰难地咽了口唾沫，从喉咙里挤出嘶哑的声音：“影子，撤掉异能……我们跟着他。”</p><p>深沉的阴影如同退潮般缩回，露出了五人苍白的面孔。</p><p>杨帝：“啊，我终于适应这具身体了，刚才一直很冷漠，不好意思啊。”</p><p>杨帝对他们露出善意的微笑。</p><p>当然在轮回者小队眼里看来，那是祖国人的同款笑容。</p><p>“我刚来到这个世界的时候，没有对你们说几句话，其实并不是装高冷，而是真的调动声带有些困难，身体与精神有些不匹配不同步，需要一段时间适应。话说，这世界的灵能水平，高到爆炸啊。”</p><p>杨帝伸出新生的手掌，按在合金闸门上。</p><p>那扇理论上需要多重密钥或物理破坏，才能打开的厚重闸门，被他缓缓推开。</p><p>但这扇闸门其实是拉开的……无所谓了。</p><p>“这个世界都是1:1的弱者。打了两个钟头，我才晋升到‘金丹晚期’境界，我需要有真正的大能与我对战，你们有什么头绪吗？”</p><p>轮回者小队不说话。</p><p>他们压根儿没听懂，没搞明白情况。</p><p>杨帝叹了口气，红皇后的核心主控机房。</p><p>众人跟在身后，如同受惊的鹌鹑，踏入了这个蜂巢基地最核心的区域。</p><p>机房内部是一个巨大的球形空间，墙壁由无数高速闪烁、流淌着数据流的透明光板构成，构成了一个三百六十度的全息信息海洋。</p><p>无数纤细的银色光缆如同活物的神经束，从穹顶垂落，汇聚到中央一个由纯净水晶般材质构成的巨大棱柱体。</p><p>——那便是红皇后的物理逻辑核心。</p><p>整个空间寂静无声，只有数据光流无声奔腾的微光。</p><p>棱柱体内部，一个由无数0与1构成的小女孩轮廓若隐若现，正是红皇后的二次元皮套。</p><p>影子晕了过去。红皇后太像真人了。</p><p>眼镜的呼吸瞬间急促起来，手腕上的终端发出疯狂的嗡鸣。</p><p>他几乎是本能地就要扑向最近的一个物理接口：“队长！是物理接口！给我十秒钟，不，五秒！我就能尝试夺取……”</p><p>杨帝摁住了他伸向红皇后的魔爪。</p><p>“杨帝先生……”</p><p>队长一步挡在眼镜身前，身体紧绷，念动力场在身周形成一层几乎看不见的护盾，尽管他知道这如同纸糊。</p><p>他强压恐惧，直视那双非人的眼睛，“我们无意冒犯。但我们需要红皇后的权限，这是完成任务的唯一途径。”</p><p>“任务？”</p><p>“对……等等？！您居然能理解‘任务’？您可以听到？难道您不是NPC而是轮回者？”</p><p>这几句话，信息量有点大。</p><p>杨帝打算待会儿好好听他说话。</p><p>在此之前，他把头转向红皇后。</p><p>“丧尸虽然已经被清除，但真正的威胁还未解决，不，我说的并不是智械叛乱，而是另有他物。我说的对吧，红皇后？”</p><p>红皇后的二次元皮套看向杨帝。</p><p>水晶棱柱内部的数据流骤然紊乱！</p><p>小女孩的投影猛地清晰起来，不再是模糊的轮廓，而是一个穿着维多利亚式裙装、面容精致却毫无表情的少女形象。</p><p>她那双由纯粹数据构成的眼睛猛地睁开，第一次，真正地“注视”着杨帝。</p><p>眼神中充满了前所未有的复杂情绪——惊骇、恐惧、一丝绝望。</p><p>以及……终于被理解的震颤。</p><p>红皇后的电子音，带上了无法抑制的波动：</p><p>「你……解析了它的精神信号？而且……你‘理解’了它？」</p><p>杨帝没有回答，只是平静地看着她。</p><p>红皇后的投影少女微微颤抖着，她缓缓抬起手。</p><p>刹那间，整个球形机房的墙壁光板，同时熄灯。</p><p>周围流淌的数据流消失不见，取而代之的是一幅无比宏大，令人窒息的景象。</p><p>星辰大海！</p><p>他们仿佛置身于无垠的宇宙深空。</p><p>脚下，是一艘庞大到难以想象的碟形星舰的局部装甲板，金属的冷光在遥远的恒星光芒下闪烁。</p><p>而在星舰更远的上方、下方、四周……</p><p>是旋转的星云，闪烁的群星，以及冰冷黑暗的虚空。</p><p>红皇后的声音带着一种冰冷的庄严：</p><p>「我们，不在任何星球的地表。」</p><p>「这里是深空科研舰‘探索者-7号’。」</p><p>「坐标：猎户座旋臂边缘，距离最近的类地行星殖民星系——128光年。」</p><p>「科研船正在以1G的加速度加速行驶，目的地是‘自由众星同盟’的科研枢纽。」</p>
