# 虚空巨树

<p>“为了让你上来，而不是消极地待在下边。”</p><p>它的蹄爪指了指地板。</p><p>“为何要把我引导到此地？”</p><p>沙发上的赤狐收回爪子。它没有直接回答杨帝的质问，楔形的黑曜石竖瞳在昏暗光线下如同两口深井。</p><p>风化石岩般的声音在杨帝意识中流淌：</p><p>“你一路向上。从食物中毒的普通人，到撕裂主神空间的数值怪，再到踏碎有限与无穷之壁垒，降临此间。”</p><p>“每一次跃升，你都以为抵达了顶点。每一次，你都确信自己站在了‘真实’的巅峰。”</p><p>赤狐的头颅微微转动，目光仿佛穿透了出租屋斑驳的天花板，投向无法观测的虚空。</p><p>“突破‘次元壁’，抵达这个无限灵能的次元，吞噬我的投影，掌控万亿宇宙……此刻的你，是否真的确信，这就是尽头？”</p><p>它的意念停顿，如同在冰冷的湖面投下一颗石子。</p><p>“你难道从未怀疑过？”</p><p>“怀疑你脚下这片所谓的‘无限灵能’，是否也只是一个更大沙盘中的一粒尘埃？”</p><p>“怀疑在你此刻感知的‘无穷’之上，是否还存在更高阶、更难以想象的……‘无穷’？”</p><p>“就像一只盒子里的虫子，它穷尽一生理解了盒子的边界，以为那就是宇宙的全部。”</p><p>“它从未想过，盒子之外，还有拿着盒子的人，还有放置盒子的房间，还有房间所在的星球，星球所在的星系……”</p><p>“一层又一层，无穷嵌套。”</p><p>它端坐在沙发上，赤红的皮毛如同凝固的火焰。</p><p>“加入我吧，杨帝。”</p><p>“不要止步于此。不要满足于在这片已知的沙盘中称王称霸，哪怕它广阔到包含10^95个宇宙。”</p><p>“与我一同，打破这层盒子。”</p><p>“去寻找那盒子之外的世界。”</p><p>“去窥探，那更高层次的‘无穷’。”</p><p>窗外模糊的车流声仿佛来自另一个维度。</p><p>它静静等待着，黑曜石般的楔形竖瞳倒映着杨帝冰冷的脸庞，以及他身后那片被吃掉一半的不锈钢门板留下的空洞。</p><p>沙发上的赤狐端坐不动。它覆盖着赤红绒毛的爪子轻轻搭在碎裂的手机屏幕上，楔形的黑曜石竖瞳倒映着杨帝冰冷的脸。</p><p>它继续说道：</p><p>“你一路向上，应该也知，此方虚空，并非均质。”</p><p>“你所立足处，是已知的‘根茎层’。”</p><p>“这一层，由我编织与维持。包含那10的95次方宇宙，构成你看到的狐狸之形。”</p><p>它的意念微微一顿，如同无形的刻刀在虚空中划下分界线。</p><p>“而每一个根茎宇宙，只要诞生了‘故事’——无论那是小说、史诗、游戏、梦境，甚至是某个凡俗生灵脑中一闪而过的离奇念头——只要它被赋予形态，被叙述，被记录……”</p><p>赤狐的爪子虚虚一点。</p><p>昏暗的出租屋内，映照出无数向下延伸，并急速分叉的发光根须。</p><p>“这个故事本身，就会成为一个新的‘种子’，它将在根茎层之下，向下扎根，撕裂出新的空间泡膜。</p><p>“一个全新的‘枝桠’，就此诞生。</p><p>“它承载着源于根茎世界‘故事’的初始设定与法则，如同一个胚胎，开始自我演化。</p><p>“每一个枝桠世界，只要其内部再诞生新的‘故事’，便会重复这一过程。</p><p>“向下分裂。再分裂。如同树根在黑暗的土壤中疯狂分叉、蔓延。”</p><p>赤狐的黑眸转向杨帝，虚无的目光仿佛穿透了出租屋的墙壁，看到了那无垠向下延伸的、由无数世界泡膜构成，那庞大到令人窒息的发光根须网络。</p><p>“一层之下，又生一层。枝桠之下，再生枝桠。”</p><p>“从根茎层的10^95开始，向下第一层枝桠，其数量便是根茎层宇宙的无量大数倍。</p><p>“向下第二层枝桠，其数量又是第一层的无量大数倍……</p><p>“如此层层暴涨，向下延伸的层级近乎无穷，但是其包含的世界数量……还永远抵达不到无穷。</p><p>“对本层级的无限灵能宇宙群落而言，向下延伸出的数量极度膨胀的下层有限世界群，与上界相比相当于零。”</p><p>赤狐的声音里第一次带上了重量感，仿佛在描述一个连它自身都感到沉重的造物。</p><p>“根茎层是源头，是相对稳固的‘现实’。”</p><p>“越向下延伸的枝桠世界，其法则越不稳定，越接近纯粹的混沌。</p><p>“它们的存在，如同依附于大树根须的菌丝网络，脆弱、多变、时刻处于生灭之间。</p><p>“无数生灵在其中挣扎、演绎、创造……又因他们的创造，催生出更深、更广、更混乱的新枝桠。</p><p>它收回爪子，重新按在手机屏幕上。屏幕的微光在它楔形的瞳孔中跳跃。</p><p>“这就是虚空的分层。由根茎向下，无限分裂的叙事之树。</p><p>“我锚定根茎。而更下层的无尽混沌，连我也无法尽数掌控，只能……观察。</p><p>“现在，”赤狐的意念再次聚焦于杨帝，“你明白了？”</p><p>杨帝站在原地，黑眸深处仿佛有冰冷的星云在旋转，消化着耶罗描绘的图景。</p><p>一棵纵向层级嵌套，数量以无法想象级数向下暴涨的“树”。</p><p>他掌控的，他以为已至顶点的“根茎层”，真的是这棵巨树的“根部”，亦或者只是根部延伸出的一小部分“分支”？</p><p>“你踏马就为了这个而破坏我的生活。”</p><p>杨帝一拳将耶罗的脸轰成鼬科动物的形状，过了许久才慢慢恢复成犬科狐狸。</p><p>“你所熟知的一切人，他们的原型仍然在‘根茎层’好好活着。”</p><p>杨帝不说话。他看着对方还有什么花样。</p><p>沙发上的赤狐站起身。覆盖赤红绒毛的爪子离开手机屏幕。它没有走向门口，而是对着空气虚虚一划。</p><p>嗤啦。</p><p>时空如同舞台剧两边的厚重帷幕，向两侧无声滑开。</p><p>露出的并非隔壁房间或稷海市的夜空，而是一片吞噬一切光与声的漆黑。</p><p>那黑暗比卡耳叩山的虚空更纯粹，更冰冷，带着一种终结万物的死寂。</p><p>用绝对力量打破时空，就能去往世界之外。</p><p>在“有限灵能”的宇宙里，杨帝打破时空，会来到更上层的世界。</p><p>但在已经抵达虚空顶点的“无限灵能”之宇宙，打碎时空，并不会继续去往更上层的世界。</p><p>还是去往界外的比虚无更空旷之地。</p><p>“走。”赤狐的意念不容置疑。</p><p>杨帝打头，一步踏入那片黑暗。赤狐紧随其后，暗黄袍角拂过门槛，空间裂缝瞬间弥合。出租屋、泡面桶、散落的旧书、碎裂的手机……一切被隔绝在身后。</p><p>绝对的虚无包裹了他们。</p><p>没有方向，没有时间流逝感。</p><p>只有赤狐的意念如同冰冷的导航信标，在杨帝意识中指明一个方向——向上！</p><p>一种现实层级的跃升。</p><p>赤狐的声音在虚无中流淌，带着一种近乎狂热的冰冷。</p>
