# 哈基米……是对的

<p>战争一代代持续下去，每一代经过战火的洗礼，最后只剩下无人的荒野。</p><p>被烙印的伤痕随着时间消失了，那些伤痕，说不定只有天上闪亮的星星曾奠基过。</p><p>但是，还记得此世之事的星星，总有一天也会像流星一样陨落，注定了消失的命运。</p><p>银河英雄传说</p><p>【食破天惊下半场】</p><p>一段叙事就是一个世界，狐狐写到这的时候都被自己吓死了。</p><p>一段叙事里藏了一个世界，一个世界里又有恒河沙数段叙事。</p><p>无穷地嵌套下去……</p><p>杨帝，他能生这么多吗？太绝望了。</p><p>……</p><p>实验室里，亚当博士正盯着试管里那点银色粉末，手指微微发抖。</p><p>他转向鲍勃，声音因激动而发颤：“老鲍！成了！茂叠铪基醚！真让我给合成出来了！”</p><p>茂叠铪基醚，也就是二叠氮二茂铪的爱称。</p><p>鲍勃正对付一份油腻的炸鱼薯条配速食无糖汉堡，腮帮子鼓囊囊的，眼皮都懒得抬。</p><p>“少来，老亚，别耽误我享受人生至味，你这诡异的有机化合物，难道比我这究极美味的炸鱼薯条加双层汉堡还带劲？”</p><p>他含糊地嘟囔着，又狠狠咬了一大口，酱汁蹭到了白大褂上。</p><p>亚当对只顾着吃的鲍勃嗤之以鼻，脸上混杂着狂热科学家特有的那种被轻视的恼怒，和急于分享发现的兴奋。</p><p>“无知！”</p><p>“为什么说我无知啊……我专业都不是这个方向。那你说说，它有什么用？”</p><p>“庸俗！”</p><p>“怎么我又变庸俗了？！”</p><p>“婴儿还小的时候，他有什么用？”</p><p>“你别cos特斯拉了。”</p><p>“那是法拉第，你半桶水就别乱说话，免得再闹出笑话。”</p><p>鲍勃毕竟是“蜂巢”基地内的信息安全工程师，术业有专攻，他对什么科学史啊，什么理生化环材啊，不甚了解。</p><p>亚当快步走到自己的实验台前，手指几乎带着虔诚，点了点一台外壳有些焦黑，明显被粗暴改造过的微波炉。</p><p>“我用那罐过期的铪催化剂作基底，配合你加热碳水炸弹、垃圾食品用的微波炉，终于把这玩意合成出来了！”</p><p>“什么？！你怎么敢说我的无糖汉堡是垃圾食品！！”</p><p>两人脚边，那只叫“哈基米”的虎斑猫突然停下舔爪子的动作，猛地抬起头，背脊弓起，喉咙里滚出低沉的“哈——哈——”声。</p><p>那双琥珀色的猫眼瞪得溜圆，瞳孔缩成两条极细极黑的竖线，死死盯住鲍勃手中的速食无糖汉堡，仿佛看见了无形的地狱之门。</p><p>它全身的毛炸开，像一团受惊的刺球，接着闪电般窜起。</p><p>“喵呜”一声凄厉尖叫，化作黄褐色的影子，撞开虚掩的实验室门，消失在走廊深处。</p><p>“嘿！这傻猫。”鲍勃嘟囔着，又塞进一大根转基因薯条。</p><p>亚当耸耸肩，小心地把那管银色粉末放进恒温箱：“随它去，没见识的小东西，不懂什么叫改变世界的伟大发现。”</p><p>就在恒温箱门咔哒合拢的下一秒。</p><p>没有任何预兆。</p><p>实验室里柔和的背景白噪音，空调的低鸣，仪器待机的轻微嗡响——瞬间消失了。</p><p>死寂如同实质的冰水，兜头浇下。</p><p>所有照明瞬间切换成刺目的血红色。</p><p>鲜血般浓稠，令人窒息的红光！</p><p>随即，尖锐得能撕裂耳膜的警报声浪，像实体一样砸进每一个角落。</p><p>天花板上，所有通风口“嗤”地一声喷出浓密的灰白色惰性气体，瞬间模糊了视野。</p><p>冰冷的电子女声盖过警报，毫无波澜地在每一个房间回荡，如同最终的审判：</p><p>「最高级别生化污染警报。检测到极度危险的生化现象。依据《蜂巢紧急事态协议》第零章第一条，启动‘净化’程序。」</p><p>“什么？！”</p><p>“净化？！净化什么？！”</p><p>“寄。”</p><p>“轰隆！——咔嚓！——轰隆！——咔嚓！”</p><p>实验室厚重的合金气密门，走廊连接口的安全闸门，甚至天花板上的通风管道格栅。</p><p>——所有通向外界的可能通道，瞬间锁死。</p><p>沉重的合金撞击声在狭小的空间里回荡、叠加，震得人心脏狂跳，耳膜刺痛。</p><p>那声音是如此巨大而密集，仿佛整个地下蜂巢都在发出垂死的呻吟。</p><p>最后一声“咔嚓”落下，余音还在神经末梢震颤，头顶天花板深处传来一阵轻微的“嘶嘶”声。</p><p>这次是淡紫色的气体。</p><p>如同有生命的薄纱，混合着臭氧和甜杏仁的甜腻腥气，从天花板上每一个通风口的网格里，无声无息地喷涌而出。</p><p>迅速沉降，弥漫，像一场诡异的紫色薄雾，温柔又冷酷地笼罩下来。</p><p>紫雾吞噬着闪烁的红光，吞噬惨白的灯光，吞噬两张因极度恐惧而扭曲的脸庞。</p><p>“不！”亚当发出不似人声的凄厉嚎叫，猛地扑向离他最近的合金门，徒劳地用拳头撞击那冰冷坚硬的金属壁垒。</p><p>他布满血丝的眼睛死死盯着门禁控制面板，那上面代表锁死的红灯，像恶魔嘲讽的眼。</p><p>鲍勃庞大的身躯僵在原地，汉堡的油腻还糊在他的嘴角。</p><p>他仰着头，呆滞地看着那片迅速弥漫、越来越浓的淡紫色雾气，甜腥的气味直冲鼻腔。</p><p>巨大的恐惧，已经抽干了他所有的力气和狡辩的欲望。</p><p>只剩下一个荒谬绝伦的念头，在彻底被紫色淹没的视野里炸开：</p><p>“那猫……该死的……它……对了……”</p><p>……</p><p>哈基米在走廊上游荡。</p><p>它只是一只普通的猫，饿了就喵喵叫，总会有人投食和铲屎。</p><p>但现在，那些两脚兽都待在各自房间，一动不动。</p><p>饥饿像一团冰冷、粗糙的石头，沉甸甸地压在哈基米空瘪的胃袋里。</p><p>十几个小时的黑暗与寂静，只有通风管道金属壁传来遥远而模糊的震动，还有自己肚子偶尔发出的，可怜兮兮的咕噜声。</p><p>空气里残留的消毒水、金属锈蚀味，早已被它敏锐的鼻子过滤掉，只剩下一种令它烦躁的空洞感，挥之不去。</p><p>总觉得两脚兽们都睡着了，但实际上并没有睡着。</p><p>爪子下的金属管道冰冷。</p><p>它把自己缩成一团带着点灰尘的蓬松橘色毛球，尾巴紧紧圈住身体。</p><p>琥珀色的竖瞳，在绝对的黑暗中睁得很大，捕捉着任何一丝可能代表食物或危险的微光与声响。</p><p>耳朵像最精密的雷达，贴伏在管道壁上，接收下方那个巨大，冰冷，充满死亡气息的巢穴传来的每一丝震动。</p><p>突然！</p><p>脚步声！不是一只，是好几只！</p><p>沉重、杂乱，带着一种泥土和烟混合的奇怪气味，从下方很远的地方传来，正快速接近它所在的这条横向通风管道下方！</p><p>哈基米瞬间绷紧。</p><p>饥饿感被一种更原始的警惕暂时压了下去。</p><p>它无声地调整姿势，柔软的肉垫在冰冷的金属上挪动，几乎没有发出任何声音。</p><p>它小心翼翼地凑近管道壁上，一条被它自己爪子扒拉开、边缘还带着金属毛刺的狭窄缝隙。</p><p>缝隙下方，是第七生物合成实验室外面，那条被应急红灯映得一片血红的走廊。</p><p>几个散发着强烈陌生气味的两脚兽身影，闯入了它俯视的视野。</p>
