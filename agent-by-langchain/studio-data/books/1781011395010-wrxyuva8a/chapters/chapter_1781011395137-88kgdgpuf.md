# 种族审美差异

<p>杨帝知道这个宇宙中大部分文明的底细，毕竟原初之眼的记忆在脑中盘旋，而祂又花了兆亿年时间观察宇宙中的文明与生命演变。</p><p>如此庞大规模的记忆，对普通人来说，窥一眼就能痛苦万分；对九转大能而言，亦是生命不可承受之重。</p><p>但杨帝具有字面意义“吃得苦中苦方为人上人”的体质，同时精神力量浩瀚，所以硬扛下来问题不大。</p><p>目前这条被他命名为“金色通道”的世界线，与前世的世界线其实变化不多。</p><p>最大的差异——也只是没有了“原初之眼”干涉。</p><p>在原初之眼的记忆中，“守望者文明”在多条世界线里，都是宇宙霸主级别的势力。</p><p>只不过，以前的“守望者”并不能通过超光速手段玩弄因果。</p><p>直到原初之眼的“主观意志”被杨帝吞噬殆尽、宇宙重新演化后，他发现——</p><p>宇宙万物，重新获得“通过FTL超光速技术实现因果倒悬”的权限。</p><p>杨帝推测，也许是悬挂于万物之上的“绝对观察者”终于消失了……</p><p>万物在没有被“观察”的情况下，主观能动性便蹭蹭蹭增长。</p><p>举个例子——Minecraft中，当区块距离玩家过远，这片区块就不会加载，此刻，远方区块中的内容就会处于“野蛮生长”的自由混沌状态。</p><p>如果每个区块都同时被玩家“原初之眼”所注视着，那么区块中所有生物的行为模式，都会被确定下来。</p><p>……其实背后的原理机制更复杂，杨帝只是用最简单的“Minecraft模型”对阿巴和守望者如此解释。</p><p>“尽管如此，老大你说的‘原初之眼’……听起来还是太玄幻，一点都不科学。”太乙真仙-阿巴说道。</p><p>杨帝所讲的“原初之眼”故事，像是一场如梦如幻的泡影。</p><p>除了他本人的记忆，世上再没有其他东西，可以佐证原初之眼存在过。</p><p>「杨帝阁下，所以您的意思是——这世界曾经存在一个横亘于全时空、全世界线、全时间点的绝对观察者。」</p><p>「这个绝对观察者被您，呃，进行了一个名为‘吃’的行为，导致其陷入俗称‘死亡’的状态。」</p><p>「否则，我们的常规超光速手段，并不会导致‘闭合类时曲线’生成，也就无法修改因果。」</p><p>杨帝点点头：“根据祂的知识和经验，确实如此。”</p><p>一鲸落，万物生。</p><p>为了天地万物，你不自己体面，我也会帮你体面的，请大眼珠子赴死吧！</p><p>杨帝只是想不到，最终祂会被他吃掉。</p><p>而这个宇宙，除却多出来“超光速可以扭曲因果”这条新规则，也没有更多变化了。</p><p>原初之眼的死亡，催生出一片勃勃生机万物竞发的宇宙新景。</p><p>而祂，也是杨帝到目前为止，遇见过效果最好的一块“磨刀石”。</p><p>在这异世界也待得够久了，是时候挥挥手离去，不带走云彩，只带走些老乡送的土特产。</p><p>比如顶级挂绿荔枝-原初之眼的灵能，让杨帝补完了自我，现实丰度达到10^110级别。</p><p>以及整个宇宙的知识宝库，都被暂存在杨帝脑子里，需要之时便可调取查阅。</p><p>当然，这恒河沙数的知识，不可能一下子全部学习。</p><p>小小脑瓜，尽管有无限的进化潜能，却也无法如此快速地塞进整个宇宙。</p><p>记忆是记忆，理解是理解，这两个必须分开看待。</p><p>论记忆能力，一块硬盘就能存出十万三千本魔导书；但“硬盘”并不能理解书中的内容。</p><p>杨帝的优势在于，他和小黄书一样，都能快速检索脑海中的记忆内容，现场调取知识，为己所用。</p><p>即使是目前这样的清醒状态，他仍然能将自己的心神分出90%，用于“白日做梦”。</p><p>在梦中，学习必要的知识。</p><p>这个世上，再没人能卷得过他了。</p><p>杨帝看向守望者舰队，问道：“对了，你们研究这么久，人形身体制造得怎么样？”</p><p>守望者文明作为本宇宙最强大的势力，原地开辟生产线，手搓一座自由高达不在话下。</p><p>但此刻，通讯频道中短暂卡顿。</p><p>似乎守望者们在也在紧急检索资料，用力组织语言。</p><p>他们如此强大的科学技术与生产力，搓一台高达很困难吗？</p><p>片刻后，电子音传来：「杨帝阁下，我们已初步攻克大部分技术难题，制造出了拥有基本行动能力的人形躯体。但……在外观审美设计上，遇到了重大难点。」</p><p>杨帝知道守望者文明的抽象审美。</p><p>这一点，从他们的战舰设计就可见一斑。</p><p>杨帝的目光扫过守望者舰队，那些悬浮在星空中的战舰，犹如从混沌深处爬出的机械巨兽。</p><p>它们舰体表面布满扭曲的几何结构，尖锐的棱刺与诡异的凹陷交错，仿佛是将无数破碎的镜面强行拼接在一起。</p><p>舰身轮廓完全背离人类对“流线型美感”的认知，呈现出类似病毒结晶的不规则形态，每一处凸起与凹陷，都落在出人意料的位置。</p><p>高情商的评价。这是对宇宙原始美学的另类解构，对传统美学范式的大胆挑战，以近乎荒诞的形式，借助极端的丑态，反衬出宇宙间那更为深邃、更为本真的美之本质。</p><p>杨帝笑道：“外观审美设计？有无已经暂定的半成品，让我品鉴品鉴，给予建议？”</p><p>「感激不尽。请阁下过目。」</p><p>话音刚落，一艘运输舰驶到杨帝面前。</p><p>这种重型运输舰的个头，其实和地球公路上的全险半挂差不多。</p><p>这些“全险半挂”的运货原理，并非是传统意义上注重空间容积的货厢，而是借助时空折叠技术、惯性消除技术，用一根腿毛大小的空间就能运一车钢卷，同时，其表现出的质量并不比腿毛重多少。</p><p>舱门缓缓打开，牵引光束射出，将一系列半成品机甲搬运出来。</p><p>第一台机甲呈站立姿势，身形臃肿，四肢短粗，头部巨大且呈不规则的多面体，每处细节都透露着粗粝与荒诞。</p><p>之后的机甲……</p><p>我们还是讨论第一台机甲吧。</p><p>守望者们紧张地等待着杨帝的评价，电子音再次传来。</p><p>「杨帝阁下，这些就是目前的设计成果，不知您觉得如何？」</p><p>“一言难尽，真的一言难尽。”</p><p>杨帝一边过目一边摇头，他对守望者文明的审美快彻底失去信心了。</p><p>如此强大的科技文明，居然无法参透普通的人类审美，看来术业有专攻。</p><p>就比如杨帝——他不擅长钓鱼。</p><p>快速将在场上百个方案过目一遍，杨帝最后选出勉强能看的一个造型。</p><p>“你们的设计理念，我们现在暂且不提，先来看这个59号。”</p><p>杨帝指着悬浮在半空的59号设计投影。</p><p>那并非任何意义上的人形躯体，而是一辆棱角分明的……履带式装甲载具，俗称坦克。</p><p>整体轮廓犹如被精心雕琢的黑曜石方碑，在宇宙冷寂星光下流转着沉稳的光泽。</p><p>近看，还有5对负重轮！</p>
