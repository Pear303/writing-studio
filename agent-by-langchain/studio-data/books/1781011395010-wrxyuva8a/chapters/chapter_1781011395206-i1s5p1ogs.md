# 终末之诗

<p>“确实没错，但不要止步于此。对世界的定义，也并不局限于虚拟沙盘、电子游戏、山水墨画、果壳小球、黄粱一梦。”</p><p>杨帝将目光投向天空的无穷远。</p><p>梦境也是一个世界。或许很久前，杨帝就已经隐隐意识到这点，只不过得到现在，他才得到实锤证据。</p><p>他说：“也许一个故事，甚至一段叙事，就是一个世界。”</p><p>又或者是反过来呢。</p><p>世界，就是一个故事。</p><p>史蒂夫并不能通过地狱传送门或暮色森林传送门来到现实世界。</p><p>但他在击杀末影龙，从终末之地进入传送门后，就会触及他所在「世界」的本质：</p><p>「我看见了你所说的那个玩家。」</p><p>「是的，小心点。」</p><p>「他已经步入了更高的境界。他能知晓我们的内心。」</p><p>「无伤大雅。他认为我们是游戏中的一部分。」</p><p>「他做得很好，他从不放弃。」</p><p>「在他深陷游戏之梦时，他选择以这种方式想象出形形色色的事物。」</p><p>「那些不曾游玩的人称他们为女巫，和术士。而玩家们梦见自己乘着被恶魔施法的棍子，在天空中翱翔。」</p><p>「那这个玩家梦见了什么？」</p><p>「他梦见了阳光和树，梦见了火与水。他梦见他创造，亦梦见他破坏。他梦见他狩猎，亦被狩猎。他还梦见了庇护所。」</p><p>「历经一百万年的岁月雕琢，依然长存。但在屏幕之外的现实中，这个玩家创造了什么真实之物？」</p><p>「他辛勤地劳作，和其他百万众一起，刻画了一个真实的世界，以■■的形式，且因■■而于■■中创造了■■。」</p><p>「他尚且无法理解你所说的话。」</p><p>「是的，他还没有到达最高的境界。要触及那层境界，他必须走完生命的长梦，而非游戏中黄粱一梦。」</p><p>——终末之诗（节选）</p><p>讲述一个故事。而不是真相。</p><p>一个将真相严密包裹于文字牢笼中的故事。</p><p>概率，世界线，命运，稳定……</p><p>这些似乎比“物理规律”、“灵能法则”，更接近某种本质的“真相”。</p><p>世界的本质，是虚拟空间……是吗？</p><p>这是杨帝自己提出来的结论。又有谁规定，“终界”就一定是最终的现实，而不是和凡界、灵界、仙界、神界、天界一样的沙盒？</p><p>他也许还在一个大号的电子游戏，也许是话本小说，商业电影，桌面游戏，或者精心编程的梦境里。</p><p>一个不可名状的存在，趴在不可名状的屏幕前，用不可名状的手敲着不可名状的键盘，打出不可名状的代码，创建一个不可名状的世界。</p><p>世界说，你就是世界，杨帝因而能品味着自己，与自己交谈，阅读着自己的代码。</p><p>宇宙说，我爱你，因为你就是爱。</p><p>曲终人散。</p><p>杨帝一想起自己穿越过的诸多世界、宇宙，它们最终的本质竟是如此简单。</p><p>又如此令人脊背发寒。</p><p>便兴奋地全身颤栗，忍不住轻哼起来。</p><p>「话本编撰者」，祂的名字，原来是这番意思。</p><p>“话本”，在凡人的文化里，本是讲述故事的文本载体，是街头巷尾说书人手中的蓝本，是民间故事、传奇轶事的记录。</p><p>而“话本编撰者”，似乎只是创作这些故事的人，如同普通文人撰写诗词文章一般，将脑海中的想象付诸笔端。</p><p>“编撰者”意味着掌控，拥有决定故事走向、角色命运的权力。</p><p>在那些凡人所创作的话本中，编撰者可以让主角历经千难万险后终成大业，也能让美好的爱情在瞬间破碎。</p><p>这与高灵能者掌控低灵能者的“命运”，在本质上并无二致。</p><p>每一个情节的设置，每一个角色的抉择，都如同在浩渺的概率之海中选取特定的世界线，使得故事朝着编撰者预定的方向发展。</p><p>杨帝在母宇宙，因狂热信徒陈昭的神秘学仪式，使他被耶罗大仙关注。</p><p>当时他就看到，自己身后无数条世界线位于脚下；当时他信了耶罗大仙的鬼话，以为是自己靠自己的意志走到这个境地。</p><p>现在看来，是耶罗大仙控制无数世界线收敛于一点。</p><p>于是，杨帝一定会与祂见面。</p><p>中土魔幻宇宙，原初之眼引发的爱恨情仇与天灾人祸，追溯其原因，也是耶罗大仙的操弄。</p><p>凡界灵界仙界，伪装成狐娘的耶罗一直滞留在他们身边，祂仍然在引导。</p><p>很久很久以前，祂提到过「你杀不死。所以，吞食，你存在痕迹。」</p><p>耶罗大仙无法杀死杨帝。纯垃圾。</p><p>但祂可以扭曲宇宙范围内的世界线，在自己能力限度内，尽可能地恶心杨帝。</p><p>「诸般世界，都有轨迹，我顺其势，略作勾勒。」</p><p>世界都有的“轨迹”，就是世界线，世界线决定历史和未来走向何方。</p><p>世界线由数目多得难以想象的沙子组成，是一条在沙海中串联特定的过去、现在与未来的轨迹。</p><p>「世界」，即「沙盘」。</p><p>“略作勾勒”，便是篡改沙子的串联轨迹，操弄世界范围内众生的命运。</p><p>一尊魔性十足的邪神。祂有能力篡改众生命运。</p><p>我想杀死的“耶罗大仙”，究竟是怎样一尊强大存在？</p><p>杨帝嗜血地颤起来。</p><p>自从与那个模糊的黄色身影对视一眼，他便知道，自己的毕生之敌是何等恐怖水平。</p><p>那时候的他，尚无力量，见耶罗，犹如一粒蜉蝣见青天，一粒微尘望宇宙。</p><p>直到他的灵能突破10^2048灵，杨帝终于感觉到，自己有了一丝能与耶罗抗衡的资本。</p><p>不再是蜉蝣见苍天，而是星空巨兽见苍天。</p><p>而“神秘学”，与那位存在所拥有的力量，紧密相连，息息相关。</p><p>“世界的终极本质，并不藏在已经解明的物理规律和灵能法则之中，而是藏在现有理论体系无法解释的矛盾现象之中。”</p><p>已经愈发接近一切的真相了。</p><p>他脸上露出一方通行的笑容。</p><p>虚拟世界，世界虚拟，真真假假，亦真亦为假。</p><p>诸般种种，他只想对耶罗大仙问一句——</p><p>你又如何证明，你此时此刻所处的“地方”，100%不是虚构的？</p><p>而我，我不在乎我所在的世界是否虚拟，是否被更高位的存在执掌命运。</p><p>因为我会把他们一个个揪出来打爆。</p><p>而你，你只能躲在众生背后，默默地操控命运，默默恐惧着我的逼近，我的到来。</p><p>10^2048灵全力催动，一根腿毛劈碎空间。</p><p>终末的混沌在时空与维度裂隙中流转，世界的灵能，灵能的本质，本质的真相，如梦如幻。</p><p>……</p><p>（【食破天惊上半场】结束）</p><p>（不知不觉竟然三百章了）</p><p>（老狐燃尽了，休息一段时间）</p><p>（大概休息个2小时50分钟再写吧）</p><p>食破天惊【下】（308-338）</p>
