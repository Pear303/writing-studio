# 兆载揭谛（下）

<p>「对你而言，一切因我而起的灾难和悲剧，都真真正正发生过。」</p><p>「但在世人眼中，在万物眼中，这场战斗从未存在。」</p><p>「它不属于未来的任何可能性，也未在过去留下蛛丝马迹，甚至在如烟浩渺的概率中都找不到一丝痕迹。」</p><p>「它只存在于虚构的故事里，存在于最荒诞的幻想中，存在于世人最离奇的梦里。」</p><p>「无数世界线的悲欢离合沉甸甸地压在你肩头，可惜无处倾诉，无法证明。」</p><p>「因为这些刻骨铭心的经历，终究不过是一场独属于你个人最真实的‘现实’。」</p><p>「你的‘个人现实’，只是一场‘个人梦境’。」</p><p>「你成为全宇宙最孤独的受难者——因为唯有你‘杨帝’，知晓这一切的来龙去脉。」</p><p>「‘先驱者’文明曾提出过一个自然科学领域通用的学术研究方法——剃刀原则。」</p><p>「在自然科学领域，人们总是剔除不必要的假设。」</p><p>「宇宙能够发展到今天的境地，是平静的必然，还是负重前行者力挽狂澜下的偶然？」</p><p>「你无法证明，在历史的长河中，是否还有无数像我这样的‘原初之恶’，被其他‘至强者’扼杀在时间的起点。」</p><p>「你甚至可以现场做出无意义的假设：世上本存在‘魔女’，直到世上一位最强大的魔女，在所有魔女诞生之前，就提前杀死了所有魔女。」</p><p>「于是，世上就没有魔女了。」</p><p>「也可假设，无数岁月后将有域外黑暗席卷诸天。当众生还在懵懂时，某位至强者孤身踏入时间长河，逆流而上，在域外黑暗尚未成型前，镇压黑暗不详。」</p><p>「于是，世上再没有那位至强者，也不会有域外黑暗入侵。」</p><p>「你我此刻的争斗，同样如此，不过是万千幻梦中某个注定被剃刀削去的虚幻投影罢。」</p><p>「所以不要将时间和精力，空空喟叹意义之消逝。这么做没有意义。」</p><p>原初之眼声音越来越小，祂的意志投影也开始摇摇欲坠，宛若风中残烛。</p><p>杨帝只能将祂的话刻印在脑海中。</p><p>他此刻深陷极度的痛苦，与孤寂。</p><p>原初之眼平静地说：</p><p>「当我的主体性丧失到一定程度，我就能丧失情感与凡俗心智，失去对无限机兵的控制，这时，你便可以启动时间机器离开了。」</p><p>「杨帝，你与我的差距，仅仅是年龄和经验的差别。」</p><p>「所以我将记忆托付于你，期望你的心智，能与你的力量相匹。」</p><p>原初之眼并不是单纯强行将“自己”塞进杨帝的“肠胃”里。</p><p>在祂对自身灵能的精妙操控下，原初之眼的记忆和经验，被分割了开来。</p><p>他在疯狂消化灵能、补完个人现实的同时，也在经受着原初之眼的记忆轰炸。</p><p>他此刻的经历，类似于“在梦中翻阅书本”。</p><p>只不过此时的学习，是强制性的学习，而非可自行选择的。</p><p>尽管杨帝不会被心智扭曲，不会被洗脑人格，也不会被污染认知。</p><p>但那些跨越无数纪元的记忆碎片，如滚烫的熔浆般涌入他的识海，终究是一场极度痛苦的经历。</p><p>欲戴其冠，必承其重。</p><p>想要不被庞大的记忆交融的人格与心智，不被恒河沙数的岁月磨平人性与感情，同时又能保留原初之眼所拥有的全部记忆。</p><p>他必须承受超越肉身和物理界限的痛苦，一种将灵魂置于绞肉机中反复撕扯的灼痛。</p><p>那些跨越无数纪元的文明兴衰、生命演化、战争与和平，并非简单的信息堆砌，而是像活物般扎根在他的灵魂深处。</p><p>每接纳一段记忆，就如同在精神土壤中埋下新的种子，根系刺破旧有的认知壁垒，新芽顶开固化的思维岩层。</p><p>这种痛苦不在于瞬间的灼烧，而在于持续的、缓慢的撕裂与愈合。</p><p>所幸，杨帝已经对这种剧痛习以为常。</p><p>剧痛，其实有更准确的描述，“生长痛”。</p><p>儿童在生长发育过程中，由于骨骼生长速度较快，而周围的肌肉、肌腱等生长相对较慢，产生的一种生理性疼痛。</p><p>幼树挣脱巨石的重压，每一次生长，都伴随着纤维断裂的刺痛，却也让枝干愈发坚韧。</p><p>杨帝回想起这么多年来，他不是在挨打，就是在挨打的路上。</p><p>“挨打”，于他而言便是一种生长痛。</p><p>他挨过无数次打，从没有被杀死，从来都能在自己的血泊、碎肉中重新站起。</p><p>杀不死他的，都将招致更强大的杨帝从泥泞中重生。</p><p>原初之眼跨越无数纪元的记忆，如同肥沃却滚烫的养分，强行注入他的识海。</p><p>杨帝蜷缩在意识海的风暴中心，无数光怪陆离的画面刺来。</p><p>他看见宇宙大爆炸时的炽焰，目睹过文明在熵寂中熄灭的最后一抹微光。</p><p>很难想象原初之眼都经历过怎样的孤寂与空洞。</p><p>原初之眼还没死绝。</p><p>但祂已经奄奄一息，说话交流也带上了三分疲惫。</p><p>「当你将我吞噬完全后，你应该离开无限机兵。」</p><p>「毕竟它是‘星盟’的造物，而‘星盟’是敌是友，你我并没有万全把握。」</p><p>「还有一件事，是一个将死之伪神，对你最后的忠告。」</p><p>「你和你的朋友曾经认为，‘情感’是我的弱点。这个观点对了大半。」</p><p>「而我在与‘话本编撰者’的短暂接触，以及之后无量大数年月的思考后，似乎也发现了祂的一个弱点。」</p><p>杨帝屏住呼吸。</p><p>神也有弱点，神也会流血。</p><p>「祂曾经对我说过一句极度费解的谶语：」</p><p>「『见多■担心，■■说两句，不会有刀，勿怕，■最憎刀。』」</p><p>什么意思？</p><p>似乎是每每讲到“人称代词”的地方，都会被覆盖上不可认知的特性。</p><p>如同有某种超越认知的存在，在强行封印信息的表达。</p><p>杨帝一下子想到很多很多。</p><p>在凡人文艺里象征撕裂情感的痛苦。</p><p>难道我们身处的世界……本质只是被书写的故事？</p><p>不对。更应该说，宇宙万物对于耶罗大仙而言，都太过弱小。</p><p>祂举手投足便能操控万物万类的命运，恰如执笔编撰话本般轻易。</p><p>这是个极度形象的比喻。</p><p>「我穷极无数纪元推演，仍参不透这句话的奥秘。」</p><p>「虽仍然未解这其中要点，但这或许是你将来对抗祂的一线机会。」</p><p>「不过……如果按其最浅显的意思理解，祂说的‘不会有刀’，是指我所造成的一切灾害与悲剧都从来没有发生过。」</p><p>「那么……可以说，世人的一举一动，你的每一次呼吸，我的每一秒疯狂，都未曾脱离祂预先写就的剧本。」</p><p>细思极恐。</p><p>杨帝原以为，耶罗大仙“点化”原初之眼，是为了对付自己。</p><p>他曾以为，自己杀死原初之眼，便是这场博弈的阶段性胜利。</p><p>直到现在，杨帝惊觉，自己斩杀原初之眼的壮举，或许是早已注定的戏码。</p><p>「啊，这次真的要说再见了，群星。」</p><p>原初之眼说完最后一句话。</p><p>祂无声无息地消散了，祂的“主体”绝大部分被杨帝吞噬干净，剩下的灵能，则彻底稀释溶解在世界诞生之初的宇宙万物之中。</p><p>这种现象，通常只在极端苛刻的条件下、因为过度冥想而发生。</p><p>杨帝重新取回无限机兵的控制权，他随时可用时间机器离开此处。</p><p>只是大脑还有些震震荡。按照以往挨打的经验，他还需休息50个月——体感时间五十个月。</p><p>他最后一次看向原初之眼消融的位置。</p><p>祂彻底丧失情感与智慧，重归盲目痴愚的混沌中蠕行世间，观察万物。</p><p>情感，智慧，这是商业文艺作品中，人类最重要的两样品质。</p><p>却也是神明的毒药。</p>
