# 理论上来说……

<p>然而——</p><p>就在杨帝一拳打爆时空的刹那，他所瞄准的目标坐标本身，如同被投入强酸的冰块，瞬间溶解、湮灭了！</p><p>整个江城二中空间猛地一震！</p><p>那无处不在的、压抑扭曲的规则感，笼罩一切的灰败滤镜，令人窒息的诡异低语……</p><p>如同退潮般迅速消褪。</p><p>阳光重新洒落，空气恢复流动，不再是那种充满精神污染的黏稠味道，而是恢复成充满城市特有的空气污染。</p><p>操场上的杂草停止了蠕动，教学楼墙壁上扭曲的涂鸦也恢复正常，或者说彻底消失。</p><p>笼罩学校的无形屏障——消失了！</p><p>覆盖江城二中，隔绝内外物质能量与信息交流的屏障，彻底解除！</p><p>本次通关怪谈领域，用时2小时17分钟，击败了全球100%的人类。</p><p>……</p><p>江城二中，校外。</p><p>时间，上午11点不到。</p><p>烈日当空，水泥地面蒸腾着扭曲的热浪。</p><p>警笛声在燥热的空气中格外尖锐。</p><p>数十辆消防车、救护车严阵以待，车身在烈日下反射着刺眼的白光。穿着厚重制服的消防员和医护人员汗流浃背，紧盯着校门，眼神凝重。</p><p>荷枪实弹的军队士兵在临时掩体后布防，枪口指向校内，汗水顺着紧绷的脸颊滑落。</p><p>最近的军区拉来了几辆装甲车，和一批精锐的特种小队。</p><p>穿着密不透风防化服、携带特殊仪器的人员则紧张地监测着数据，汗水浸透了内衬。</p><p>临时指挥中心的大屏幕上，代表规则怪谈领域的能量读数，在刚才的几分钟内断崖式下跌，最终归零！</p><p>一名肩章闪亮的军官放下被太阳晒得发烫的望远镜。</p><p>他看着那骤然消失，如同“海市蜃楼”般曾笼罩学校的诡异力场，脸色铁青，声音沉重沙哑地通过通讯器传遍全场：</p><p>“怪谈领域……消散了。”</p><p>短短七个字，在灼热的空气中砸下冰点。</p><p>所有人的心都沉到了谷底。</p><p>如此快，如此彻底的消散……</p><p>只意味着一件事——里面的“养分”已经被榨干，所有生命都已归于虚无。</p><p>“太快了……才一天不到……”</p><p>旁边一位专家声音干涩，被晒得发红的脸上满是难以置信的悲凉，“这代号‘马格努斯’的诡异之物……凶残至此……这是……全军覆没啊……”</p><p>他后面的话几乎说不下去。</p><p>悲观的阴云如同实质般压在每个人心头。</p><p>他们脑海中是资料里描述的恐怖景象：扭曲的规则、同伴相残、在绝望中被诡异吞噬……</p><p>一天时间，一千多条生命，就这么无声无息地蒸发了？</p><p>或许唯一值得庆幸的消息，就是高考临近，校内高一高二的学生都被疏散。</p><p>只剩下高三学生，和部分老师、教职工。</p><p>这真算得上是什么好消息吗……更像残酷的黑色幽默。</p><p>一位在封锁线外苦苦守候、被烈日晒得几乎虚脱的母亲，听到军官的话，发出一声凄厉的哀嚎，直接瘫软在地，被医护人员迅速抬上担架。</p><p>啜泣，叹息，在灼热的空气中弥漫。</p><p>“各单位注意，诡异彻底消灭所有‘养分’后，可能会有深度污染的师生冲出校园区域。”</p><p>“目标已非人类，极有可能具有高度攻击性和污染性，注意守住所有出口。”</p><p>“发现异常目标时，优先阻止其离开校园范围！必要时……可动用致命武力！重复，必要时可动用致命武力！”</p><p>“防化一队、二队，准备按计划进入，进行污染评估与初步清理！记住，我们的首要任务是防止污染扩散！其次才是……搜寻可能的幸存者迹象。”</p><p>防化人员深吸一口气，准备踏入那片在他们想象中已成炼狱的校园。</p><p>“诡异”杀死后污染其内部所有人后，怪谈领域消散，并不意味着灾难结束。</p><p>这只是刚刚开始。</p><p>规则怪谈会固定地笼罩在江城二中这片区域，但人类不能将其物理摧毁，也不能将它空置出来。</p><p>江城二中必须继续维持一所正常全日制高级中学所具备的所有功能：上课，考试，住宿，吃饭……</p><p>必须具备应有的人：教师，学生，职工……所有岗位。</p><p>最迟在第二天，这所学校必须重新响起上课铃声，必须有人在教室里讲课，有学生在操场上活动，必须有食堂在营业。</p><p>必须看起来和诡异降临之前一模一样。</p><p>他们必须在这片刚刚吞噬了一千多条生命的恐怖之地，假装一切正常。</p><p>否则，相同的怪谈将会极速扩散。</p><p>这所新学校和曾经的学校，唯一区别是，必须将怪谈规则一字不差当作新的校规。</p><p>哪怕里面写着“不要吃同学的碎片”，“禁止观察天圆广场中心区域”等奇谈怪论，各种匪夷所思的规定，也必须一字不差地遵守。</p><p>就在这时。</p><p>吱呀——</p><p>江城二中那扇锈迹斑斑、被烈日暴晒的电动大门，突然发出一阵老旧的摩擦声，然后缓缓自动向两边滑开。</p><p>灼热刺目的阳光，毫无阻碍地涌入校门内，照亮了里面略显狼藉但无比正常的校园景象——</p><p>空荡荡的操场，寂静的教学楼，甚至能看到远处旗杆上的红旗在热风中微微飘动。</p><p>所有人的呼吸瞬间停滞。</p><p>所有的目光，所有的枪口，所有的仪器，如同被磁石吸引，死死锁定了那洞开的校门！</p><p>阳光下，一个身影，慢悠悠地从门内踱步而出。</p><p>不是扭曲的怪物，不是行尸走肉，不是哭嚎的幸存者。</p><p>是杨帝。</p><p>他穿着一身蓝白色普通校服，双手插在裤兜里，嘴里甚至还叼着一根冒着袅袅热气的桶装方便面叉子？</p><p>另一只手端着个一次性泡面桶，正低头吸溜了一口面汤，发出满足的“嘶哈”声。</p><p>阳光落在那人身上，给他镀上一层悠闲的光晕。他像是刚在学校小卖部买完泡面，或者逃了一节无聊的体育课，正打算找个阴凉地解决午餐的三坏学生。</p><p>杨帝抬起头，被门外刺眼的阳光和黑压压、枪炮林立的壮观景象晃得微微眯了眯眼。</p><p>他明显愣了一下，有点意外。</p><p>但很快反应过来，轻轻放下泡面桶和叉子，整理仪容，严肃地说：</p><p>“同志们辛苦了，这所学校的怪谈已经被我全部干掉。”</p><p>啪嗒！</p><p>一名记者手中被晒得滚烫的麦克风，因过度震惊失手掉在滚烫的水泥地上。</p><p>哗啦！</p><p>一架悬停的无人机，螺旋桨搅动热浪，似乎也因操作员手抖，在空中猛地打了个趔趄。</p><p>指挥中心大屏幕上，除了能量归零的读数，只剩下监控画面里，杨帝端着泡面桶，站在阳光普照、空无一人的校门口，一脸“你们是不是搞错了什么”的茫然。</p><p>烈日炎炎，蝉鸣聒噪。</p><p>理论上来说，此刻从里面走出的任何人，那至少是重度污染起步，已经不可逆地成为诡异的爪牙。</p><p>所以，一位尽职的战士开了第一枪。</p>
