# 纯手搓附魔

<p>“附魔也能搞自由竞争？？”</p><p>杨帝对奥拓的解释大为惊叹，哈椰壳的大手还在追我。</p><p>矮人点点头，操作着附魔台：“这么‘自由竞争’，好处是工具与附魔的兼容性好，坏处是容易产生劣币驱逐良币类型的‘另类垄断’——整个附魔台都被低环数的附魔给垄断。”</p><p>所以这附魔台操作也非常麻烦。</p><p>只有高技术人才能够熟练运用。</p><p>“就像菜市场。低级附魔是廉价小贩，会把整个附魔台占得满满当当。想要高级货，得先把这些占着茅坑不拉屎的赶走。”</p><p>奥拓带上隔热手套，他一边说着，一边从蒸汽腾腾的存储仓里夹出块青金石。</p><p>矿石表面，纹路流动，仿若活过来的星河。</p><p>青金石可以赶走“占着茅坑不拉屎的”，再一次随机洗牌，下一次就有可能刷出“高级货”。</p><p>从本质上来说，“附魔”和“抽卡”并无两样。</p><p>每次刷新附魔条目，都要消耗青金石。</p><p>而抽卡则是消耗金钱和寿命。</p><p>甚至某些游戏的出SSR的爆率，比附魔台出“高级货”的概率还要低。</p><p>杨帝看到矮人背后的木镐。</p><p>“绑定诅咒也是一种附魔吗？能给我附魔‘绑定诅咒’么？”他问。</p><p>奥拓停下动作，像看疯子一样盯着他。</p><p>“确实是，‘绑定诅咒’是种环数极高的附魔。‘附魔’和‘诅咒’原理一样，只是褒贬义不同。但在给工具施加「绑定诅咒」前，先猜猜：为什么它被称作‘绑定诅咒’，而不是‘绑定附魔’？”</p><p>杨帝捏着下巴，却不死心：“所以，是可以人为施加这种诅咒/附魔的？”</p><p>“可以。”</p><p>奥拓叹气，“但我也不会，别想了。我研究了许多年，也只能证明‘绑定诅咒’这种贬义的附魔技术，至少是十环级别的难度。”</p><p>杨帝注视矮人随身携带的木镐：“绑定诅咒能使物品不受损坏吗？我记得你说过，把这些绑定诅咒的物品摧毁，它们会恢复原样，重新出现在身边。”</p><p>“并不。这些邪乎墓葬品‘不会损坏’的原因，是另一个极高难度的附魔「不可破坏」。”</p><p>绑定诅咒，不可破坏。</p><p>两种附魔如果单独出现，都好办。</p><p>绑定诅咒？那我直接将工具摧毁便可。</p><p>不可破坏？这完全是个正面增益buff，试想一把永远不会钝的菜刀，高兴还来不及！</p><p>但当它们同时出现在一件物品上时。</p><p>那就是一场噩梦的开始。</p><p>无法摧毁，永远会如鬼魅般回到身边，不断出现在眼前，占据个人空间，成为生活中的一个“电灯泡”。</p><p>奥拓背着木镐，在附魔台前站了一阵子。</p><p>“运气很好，第一、二、三轮都出货了「锋利I」，最后叠加成「锋利III」。就选这个了，你试试。”</p><p>他将撬棍扔来，杨帝接住。</p><p>“附魔效果还能叠加？”</p><p>“可以堆叠哦。”</p><p>撬棍看起来似乎没有什么变化。</p><p>但杨帝能感觉到，上面蕴含一股凌厉气息，仿佛轻轻一挥，就能切开时空，刺破维度，劈碎宇宙，磨灭大道比磨灭大豆还容易。</p><p>当然，实际情况没那么夸张。</p><p>这撬棍外观仍然粗粝，只是在以同等力度挥下，会比原来伤害提高约25%。</p><p>当然，这个提升率不是概念性钉死在“25%”的，比如用撬棍动能是原来的10倍时，“锋利”附魔的增幅可能会跌至2.5%，因为10×2.5%=25%。</p><p>杨帝抚摸着撬棍，看见其中的灵能分布模式。</p><p>“这上面的附魔……就是‘锋利’？”</p><p>他瞳孔倒映出一副景象：撬棍内部，on颜色的灵能，被固定进了属于“撬棍”的现实当中。</p><p>“on”是灵能的颜色，意思为“作为存在的存在，to on hei on”。</p><p>很神奇。</p><p>通过“附魔”这种工艺，居然能轻易将大量客体的灵能，嵌进物品之中。</p><p>唯一的缺点，如果是嵌入人体的附魔，那并不会算作“主体的一部分”，相当于健身界的“死肌肉”。</p><p>所以，就算杨帝对自己“附魔”，也不能实现“补完”。</p><p>又好比给他镶上假牙，假牙终究不是杨帝自身的组成部分，而是外在之物。</p><p>杨帝身上的衣服和假牙受到损伤，并不会触发进化适应。</p><p>附魔，就是给撬棍装上假牙。</p><p>杨帝盯着撬棍整整三分钟。</p><p>“我大概明白是怎么回事了。”</p><p>在奥拓困惑目光的注视下，杨帝掏出自己背包里一件地球的工艺品——指甲钳。</p><p>集中精神，以强大的意志迫使现实/灵能做出改变……</p><p>在一侧旁观奥拓附魔的全流程，杨帝对这一工艺有了更深刻理解。</p><p>能够直视灵能颜色，加上极其强大的精神，杨帝可以绕过最繁琐的咏唱咒词、构筑术型，直接对环境中的“灵”动手脚。</p><p>同时，在10%潜意识解放的状态下，每秒110万比特信息流入，杨帝能增幅上千倍的学习速度。</p><p>于是在20分钟内，他学会了「锋利」附魔。</p><p>“嗡——”</p><p>指甲钳泛出淡淡紫光，其边缘铮亮，似乎更锋利了些许。</p><p>奥拓瞳孔骤缩。他嗅到了熟悉的味道。</p><p>“虽然只是最简单的「锋利I」，但这是从0到1的跨越。”</p><p>杨帝指甲钳修剪了手指甲，特别好用！显然是支上品指甲钳。</p><p>奥拓瞪大了眼睛，像是看到了什么不可思议的怪物一般。</p><p>在他漫长的岁月里，无数次见过天赋异禀之人。比如每天起床照镜子时。</p><p>但像杨帝这般，在短短二十分钟内，仅凭观察就学会「锋利」附魔的……</p><p>奥拓会毫不犹豫到铁熔堡自首，并声称砾石镇有个伪人。</p><p>此刻，杨帝已经把门锁好。</p><p>他低声对害怕至极的矮人说道：“奥拓你先别害怕，我不是跟你说过？我是以前可能是个什么八九环传奇术士、冠位指定魔法使、战略级法师。</p><p>“所以，我以前也并非不可能精通附魔，只是我失忆了，身世记不起来。</p><p>“我知道听起来很离谱，但事实摆在眼前。你想，我能在这么短时间学会「锋利」附魔，总不能是凭空冒出来的本事吧？</p><p>“所以我并不是现场学习，而是一种对过去知识的回忆，很合理吧？”</p><p>奥拓沉默了片刻，铁匠铺里安静得只能听到偶尔传来的微弱炉火噼啪声。</p><p>矮人说：“杨帝阁下，我们还是谈谈‘砖头’吧。您想炼制怎么样的砖头？”</p><p>……</p><p>伊芙·柑橘呆呆地凝望天边。</p><p>浓密的积雨云在南方的天空汇聚，黑云深处有雷光闪烁。</p><p>“呐，瑞弗，你最近有没有做奇怪的梦？”精灵问。</p><p>瑞弗维尔心头一紧。</p><p>“梦……确实是做过些噩梦。伊娃你呢？”他转移话题，一脚皮球把问题踢回去。</p><p>伊芙皱起眉，有些不情愿地回忆：“一言难尽，一言难尽……瑞弗，我梦到我在追杀你、杨帝和奥拓。”</p><p>瑞弗维尔大惊了真的这次。</p><p>他思想斗争了足足10秒，又回想起先前多日试探的结果，他认为，伊芙主观上不可能有恶意。</p><p>于是，瑞弗维尔说出来了自己保守数日的秘密：“伊娃，我也做了很相似的梦……我梦到我正在被你追杀。”</p><p>“真巧，我们心有灵犀呀。”</p><p>“咱会不会做了同一个梦啊你说。”</p><p>“嗯……这种梦会不会在冥冥中有什么预示呢……”</p><p>伊芙思考了一阵子。</p><p>她最终下定了决心，“这样吧……瑞弗，我交给你三样东西，本来它们也不属于我，而是属于人类。如果梦里的情况真发生了，你要保护好自己。”</p>
