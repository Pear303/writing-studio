# 三班倒制度

<p>众人呈包围之势将杨帝围在中央，强大的灵压相互碰撞，归墟之地的灵气环境开始剧烈震荡。</p><p>空间如被无形巨手揉搓的塑料保鲜膜，裂纹蛛网般蔓延，现场弥漫着压抑到令人窒息的肃杀之气。</p><p>凌云圣皇周身星辰之力与身旁数位大能的灵压交织，化作一道璀璨却冰冷的光墙，将杨帝死死锁在中央——至少，他们自认为将杨帝死死锁在了中央。</p><p>远处强者们祭出的法宝悬浮空中，剑芒、雷弧、毒瘴交织成可怖的绞杀之网，随时准备撕裂这片天地。</p><p>青丘白璃眼尖儿地看到酒楼厨子、图书馆保安、扫地僧、中学老头四人，也刚刚从凡界飞升上来了，混在一众强者内暗中观察。</p><p>“我是青丘白璃，三十六尾狐仙！”</p><p>她站了出来，“这几位是异界的客人，诸位莫要破坏了灵界形象！”</p><p>“青丘妹妹快避！就算不是域外天魔，那厮一看就是魔道修士一类的怪东西！莫要被蛊惑了心神！”</p><p>某个叫做什么“凌云圣皇”的人形东西却在那叫唤道。</p><p>另一个自称“瑶光仙尊”的家伙鼻翼微动。</p><p>她脸色骤变，凄厉尖叫撕破长空：“魔头！方才归墟大帝的气息还清晰可辨，如今灵界竟遍寻不着！定是你暗中下了毒手！”</p><p>此言一出，众人皆是心头一震。</p><p>以归墟大帝的脾性，断不会对杨帝这个一看就极度可疑的“负灵能”存在坐视不理。</p><p>如今，归墟大帝在灵界短暂露脸后，又突然消失，杨帝显然嫌疑最大。</p><p>只有一种可能，就是他将归墟大帝敲闷棍，藏起来了，甚至杀害了！</p><p>“为大帝报仇！”</p><p>“守护灵界！”</p><p>众强者的怒吼震得虚空轰鸣。</p><p>尤其是凌云圣皇，他虽自称圣皇，但对大帝忠不可言。</p><p>此时归墟大帝离奇失踪，杨帝又是最可疑的第一嫌疑人，自然需要大刑伺候！</p><p>只见凌云圣皇大手一挥，九天龙辇拉棺瞬间化作漫天星辰，如陨石雨般朝着杨帝砸落！</p><p>四周强者同时出手，各色法术如天女散花打乱调色盘般倾泻而下！</p><p>归墟之地的灵气被搅得混乱不堪，连呼吸都变得灼热刺痛。</p><p>此地不宜久留。阿巴等人赶紧离开战场，去往后方观战。</p><p>整个灵界九成的战力，都汇聚于此。</p><p>三百多个真仙境大能，这股力量只要配合打得好，用神圣的F2A连接起来，实际上已经可以对抗八九个归墟大帝。</p><p>杨帝的身影在这铺天盖地的攻势中显得渺小如蝼蚁，却又像即将爆发的火山，暗藏着能焚尽一切的恐怖力量。</p><p>但他没有还手。</p><p>光幻炫影中，他在思考一个问题。</p><p>“归墟大帝的身体强度、自愈速度都远不及我，他居然也能狂喝三千瓢归墟渊水，确实算是英雄豪杰了……”</p><p>大帝失踪三日，再次归来时，和青丘白璃等土著大能的描述显然不同。</p><p>他更暴戾，像是脱离了高级趣味，从一位纯粹的大帝转化为不纯粹的强者。</p><p>而且他还亲口承认……自己不是三日前的自己。</p><p>他……被夺舍了。</p><p>在“第三个世界”，归墟大帝碰上了一些不干净的东西。</p><p>但诸般种种猜测，仍然无实质证据。</p><p>总之，归墟大帝性情大变。</p><p>他决心要灭杨帝的口，无比坚定。</p><p>无需谈判，自动破裂！</p><p>而大帝三日前在凡界“突然失踪”，和他在与杨帝战斗过程中“突兀消失”，都是很突然，天地间就感应不到他的气息了。</p><p>他的去向呼之欲出。</p><p>一切疑问，一切线索，都指向了归墟大帝所去过的“第三个世界”。</p><p>大帝很可能掌握了随时随地传送到第三世界的方法。</p><p>而不是像“黑水传送门”，只能随机传送。</p><p>顷刻间，杨帝便已想通下一步行动计划。</p><p>现在唯一要做的，就是等归墟大帝二度现身。</p><p>那好，就在原地耗时间吧。</p><p>等到那位大帝，或是其他幕后黑手什么的出现为止。</p><p>面对四周震天的怒吼与杀意，杨帝眼神平静得像是在自家后院散步。</p><p>那些砸向他的九龙拉棺、太乙仙术、亿万神通，并无甚卵用。</p><p>他双手负于身后，神色悠然，目光时而扫过四周那疯狂攻击的人群，时而望向天际，仿佛在思索着更为深远的事情。当然主要是为了维护自己世外高人、深不可测的形象。</p><p>第一天，凌云圣皇打得青筋暴起：“魔头！有种你还手！”</p><p>杨帝眼皮没抬，随手捏碎一道劈来的雷火，指尖连一丝焦痕都未曾留下。</p><p>他怎么就是不还手，搞得一众灵界大能都有些不好意思。</p><p>单方面群殴一个人，从形式上看确实不太讲武德。</p><p>第二天，瑶光仙尊累得气喘吁吁，法宝都挥不动了。</p><p>她靠着块悬浮的陨石，从袖里摸出个紫砂壶晃了晃：“诸位歇会儿？我这灵泉茶不错。”</p><p>一众强者纷纷赞同。</p><p>第三天，整个灵界强者自发组织成三班倒的群殴制度。</p><p>每组群殴八小时。</p><p>清晨卯时到午时，是先锋攻坚组。由凌云圣皇带领一众以力量见长的武道修士，手持巨斧、重锤、链锯剑、爆矢枪等重型法宝，为杨帝抛光刮痧。</p><p>午时到酉时，则是法术轰炸组。瑶光仙尊率领擅长各类仙法道术的修士接手战场。这一组修士的定位，相当于给杨帝洗头。</p><p>酉时到次日卯时，是最恶心，也是唯一让杨帝出手反击的“消耗袭扰组”。</p><p>该组由一些擅长运动战、偷袭战术和骚扰战术的“邪道修士”组成。</p><p>他们是偷鸡摸狗打架专挑下三路之辈，其中的领头修士号称“九转大常真君”。</p><p>此人用一手“后庭喂丹药”的邪道技巧，一路爬到太乙真仙境。</p><p>能够对自己使出这种招数的人，对付外人的手段必定更狠辣、更阴毒！</p><p>事实也是如此。</p><p>他们趁着夜色，像鬼魅一般悄无声息靠近杨帝。</p><p>他们的“消耗袭扰”，并不是简单的打冷枪、下剧毒、偷屁股。</p><p>而是兼具物理攻击与精神杀伤的“拖把粘屎”战术！</p><p>在飞镖上涂尸油，在符纸上浇潲水，往箭矢和刀剑上涂凡界化粪池内的液体……</p><p>种种情节极度恶劣的行为，终于触及杨帝的雷点和底线！</p><p>“你们、找死！”杨帝一声怒吼。</p><p>这吼声如同宇宙崩塌般震耳欲聋，以他为中心，一股毁天灭地的力量瞬间扩散开来！</p><p>稍远的攻击者们被这股力量直接掀飞，如断了线的风筝般朝着四面八方飞去，重重地砸在远处的地面上，生死不知。</p><p>“本不想与你们过多计较，可你们却不知死活！”</p><p>距离杨帝最近的那位灵界强者，在被掀翻前，正手持粘屎拖把。</p><p>他还来不及陷入昏迷，就被杨帝探出虚空大手一把抓住。</p><p>百万亿匹灵能转动，将其捏爆成漫天血雾！</p><p>手持拖把的灵界大能，只剩半条残魂孤零零飞走。</p><p>被打成这惨状，滴血都不剩下，得花上个几百年重新温养肉身，重铸灵能。</p><p>“那魔头动手了！！”</p><p>那条残魂边飞边呼吼，将其他刚刚下班的灵界强者都吵醒了。</p><p>整个归墟之地的空气仿佛瞬间被冰封，原本因三班倒而略显疲惫麻木的灵界强者们，此刻全都瞪大了眼睛，死死盯着杨帝。</p><p>之前还在互相抱怨“排班表不合理”的大能，此刻连呼吸都放轻了，生怕哪个动作会惹恼眼前这尊刚被点燃引线的核弹。</p><p>先前，灵界大能单方面群殴杨帝三天三夜，却没有付出血的代价，便逐渐放松警惕，认为他是病猫子。</p><p>直到此时此刻他们才恍然。</p><p>如果对方有能力干掉归墟大帝。</p><p>那么他与在场所有人直接爆了，不在话下。</p><p>高低也能拉几十个垫背的。</p><p>连远处观战吃瓜了三天三夜的阿巴都忍不住咽了口唾沫，多喝了口西瓜汁。</p><p>原本青丘白璃还在充当说书人，现场直播讲解战局。</p><p>此刻她戛然无声，生怕沾屎拖把下一刻落到自己头上。</p><p>杨帝和灵界大能又足足对峙了8个小时，直到天亮。</p><p>他原本打算手持粘粪拖把，以其人之道还治灵界大能之身。</p><p>但在对峙刚刚超过8小时5分钟时，杨帝收手。</p><p>因为灵界的氛围再度大变。</p><p>仍然是强者的气息，极度细微，冲天而起，就如归墟大帝突然出现的那次。</p><p>但这次，不只是一道“强者气息”，而是42个。</p><p>归墟大帝回来了。但不止他一个人。</p><p>黄粱一梦【下】（247-266）</p>
