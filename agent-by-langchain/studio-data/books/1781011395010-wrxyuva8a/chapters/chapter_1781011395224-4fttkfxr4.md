# 作者答辩

<p>杨帝的嘴角抽动了一下。</p><p>他闭上眼，更深地挖掘那份记忆。</p><p>达文西熬夜码字，对着空白文档绞尽脑汁胡诌数据的画面浮现出来。</p><p>“是疏漏。”杨帝肯定地说，“他早忘了自己都写过什么了。”</p><p>“达文西只是觉得37度听起来更酷一点。这与他童年时看过的地摊杂志《世界未解之谜》有关，里面提到几个古代文明都诞生在北纬37度附近，神秘至极。其实原因是此纬度带多为亚热带至温带气候，稳定支撑农作物生长，而且地势多为平原或河谷，便于人类聚集定居……”</p><p>银隼端起身前的冰水，做了一个极其类似“饮酒”的动作，虽然水杯并未真正靠近她的唇瓣——那里或许根本没有进水的结构。</p><p>“难以置信。”</p><p>她的声音里带上了某种可称之为情绪的调子，极细微的挫败感，或者说是对巨大混乱的惊叹。</p><p>“基于如此混乱矛盾的基础，竟能构建出那个让我……我的雇主，投入情感追随的世界。”</p><p>她抬起眼，目光锐利地看向杨帝：“那么，最后一个问题。你——杨帝。你现在如何定义自己的存在？是达文西的延续，一个借尸还魂的亡灵？还是一个全新独立的生命体？你继承了他的记忆，但你的行为模式、你的目标，似乎已截然不同。”</p><p>窗外，城市的灯光无声闪烁，如同亿万星辰的倒影。</p><p>酒吧内的爵士乐换了一首，萨克斯风的声音慵懒而深邃。</p><p>这首曲子放完，下一首就变成土嗨金曲。</p><p>风格挺多样。</p><p>杨帝迎着她的目光，那双黑眸深处，仿佛还残留着吞噬流星时的光芒。</p><p>“我是杨帝，白杨大帝。我不承认我由他创造，我还有自己的路要走。”</p><p>杨帝顿了顿，补充道：“比如，弄清楚我为什么会来到这里，以及……接下来该做些什么。或许，你可以不再仅仅是作为一个‘读者’？”</p><p>“你的意思是，将该网络连载小说的著作权转让于我？”</p><p>“嗯，我看你说话挺利索。作为一个‘智械’，你内置的大语言模型性能不错，但还是有一个致命弱点。”</p><p>“但闻其详。”</p><p>银隼已经将自己带入写手身份了。</p><p>杨帝站起，指着桌对面的银隼的大额头：“你一开始来我家时的笑，都是伪装出来的。你从来没有发自心底笑过！”</p><p>根据程序，银隼露出震惊。她目前为止的情绪表达，确实是通过一个蛐蛐20GB的模拟程序呈现。</p><p>杨帝站起身，手指隔空点了点银隼的额头：“作家，或者说任何创作者，都要经历三个阶段。第一，写的文不像人。第二，写的文像人。第三，写的文不像人。”</p><p>他放下手，看着眼前这位战术人形。</p><p>“你现在，还卡在第一阶段。你得先努力达到第二阶段，写出点‘人味儿’来。否则，读者不会买账，他们会骂你是个黄皮子，写文是为了讨封，逼着他们骂你神人。”</p><p>银隼的瞳孔微不可查地收缩了一下，内部处理器高速运转，分析着“黄皮子讨封”的民俗学含义及其在网络语境下的隐喻。</p><p>片刻的沉默后，她似乎做出了某个决定。</p><p>她抬起双手，纤细的、包裹在黑色战术手套下的手指，轻轻撑住自己脸颊两侧。</p><p>她的表情管理系统全力运行，试图调动所有能模拟“真挚笑意”的参数。</p><p>嘴角被手指推着向上弯起精确的弧度，眼部肌肉微微收缩试图让眼神显得柔和，甚至刻意让肩膀放松，做出一个类似“俏皮”的微动作。</p><p>一个完美符合人类审美定义的标准“笑容”出现在她脸上。</p><p>笑容像是用最精密的尺规画出来的，弧度无可挑剔，却冰冷得像手术刀。</p><p>眼底深处依旧是那片无机质的平静湖面，没有一丝真正的暖意或愉悦涟漪，假得让人后背发凉。</p><p>连吧台后一直保持沉默的酒保，擦拭杯子的动作都顿了一瞬，默默移开了视线。</p><p>杨帝看着她，叹了口气：“看，就是这样。你这笑，比反器材步枪指着达文西还让人发毛。”</p><p>银隼缓缓放下手，脸上的“笑容”瞬间消失，恢复成平日里的冰冷精准。</p><p>“表情管理系统日志报错：情感模块‘愉悦-真挚’子项加载失败。建议增加更多人类微表情样本进行深度学习。”</p><p>她看向杨帝，语气重新变得冷静：“训练数据采集请求。请提供更多‘发自心底的笑’的实例样本。”</p><p>“发自心底的笑？”</p><p>杨帝想到一个很好的样例。</p><p>“达文西死前的那一笑就很贴切。”</p><p>银隼好像钢铁之躯微微震颤了一下。</p><p>“为什么？”</p><p>杨帝身体微微后仰，指尖无意识地点着桌面。</p><p>“达文西那笑。我想想怎么描述。”</p><p>他缓缓开口，像是在解剖一具冰冷的标本。</p><p>“用精神分析那套来看，是死本能对生本能的绝对碾压，同时完成了终极的性幻想升华。</p><p>“他一生困于庸常，渴望创造超越现实的艺术‘神迹’，这本身就是一种生本能的驱动。</p><p>“但另一方面，他笔下充斥的黑暗与自毁倾向，又透露出强烈的死本能——毁灭秩序，回归虚无。”</p><p>杨帝看向对面冰冷的人形。</p><p>“而银隼你，是他潜意识中最完美的造物集合体：少女外形本是为了降低目标的警惕性，却恰到好处构成极致的美。因为人形的力量足够，可以携带重型枪械，又象征了极致的毁灭。以及你对他创作作品绝对关注，是重视读者。你是他所有压抑欲望的投射实体。”</p><p>“因此，当你的枪口指向他——”</p><p>“这场景同时满足了他三个层面的深层渴望：第一，被自己创造的、代表‘终极艺术’的完美存在所终结，死本能的实现。第二，被一位兼具纯洁与暴力特质的年轻异性处决，性本能与攻击本能的扭曲结合。第三，作为创作者，被他最忠实的读者以最激烈的方式‘认可’其存在价值，即自恋需求的极端满足。”</p><p>“所以那一刻，他的笑是发自心底的。”</p><p>杨帝顿了顿，总结道：“简而言之，这是个XP。但你并没有和人类类似的生物学结构与功能，所以你无法体会被多巴胺、内啡肽与肾上腺素充斥着神经突触，让理智在极致快感与毁灭欲中彻底消融的感觉。”</p><p>银隼眼中的微光稳定闪烁，安静地录入了这段分析。</p><p>“听您的表述，类似于服用致幻剂后的生理现象……”</p><p>“呃，重点不是这个，重点是一种精神的升华，你不能空有肉体的欢愉。”</p>
