# 个体进化论

<p>一切始于一场拼优饭导致的急性肠胃炎。</p><p>身体内部潜能的隐秘大门被打开。</p><p>自己身体在这场大病后，发生了难以置信的自我进化。</p><p>“张明远，我可能要成为新人类了。”杨帝擦干身子穿好衣服走出来，对舍友郑重道。</p><p>张明远悲悯地看着他，拍了拍兄弟肩膀：“趁着还有理智，吃点好的吧。”</p><p>他抱着笔记本电脑缩回上铺，键盘敲得噼啪响：“哦还有，新人类第一步先把热水费结清。”</p><p>杨帝也套着皱巴巴的睡衣爬上床梯，半边身子探进对方床帘：“说真的张明远，存不存在某种生物机制，能让有机体无限适应环境，甚至持续进化？”</p><p>“虫族。”张明远头也不抬，“《星际争霸企鹅版》的资料片刚更新，现在充季卡还送黄金豪华刺蛇皮肤。”</p><p>“张明远，我指现实中的！”</p><p>键盘声停了。</p><p>张明远从显示器后露出半张脸，镜片反射着幽蓝的光：</p><p>“不会自己动手指上网搜资料的尊贵的新人类阁下，‘水熊虫’应该符合您的要求。就是缓步动物门那老赖，能在沸水里泡桑拿，在液氮里睡午觉，把真空辐射当马杀鸡的水熊虫。”</p><p>杨帝的脚趾不自觉扣紧床梯横杆。</p><p>浴室里灼热的水流，仿佛还裹在皮肤上。</p><p>张明远继续说：“它们会进入隐生状态，对于恶劣环境有极端适应力，甚至超过一些病毒和细菌的生命力。”</p><p>他把笔记本转过来。</p><p>显微照片里，蜷缩成酒桶状的生物正散发着诡异美感。</p><p>那就是地球上最顽强的生物，水熊虫。</p><p>“水熊虫会脱水成只有3%含水量的干尸，等环境好转再吸水复活——从南极冰盖到海底热泉，就连卫星残骸里都发现过这玩意。”</p><p>杨帝摇摇头：“不是这种适应，而是一种……原来不适应，而之后就适应了。”</p><p>“进化？”</p><p>张明远哔哩啪啦敲起键盘，对度娘上下其手。</p><p>一则网页的标题展露出来。</p><p>《震惊！2011年东太平洋隆起带新发现的种群小虾米，环境剧变导致共生菌灭绝，它们竟在三个月内进化出全新的代谢方式。》</p><p>杨帝：“三个月？”</p><p>这种适应，还是……太慢了。</p><p>张明远见多识广，还常年刷知乎浸泡在知识区：“是不是超级快的进化速度？我也有所耳闻，当时学界吵翻了天。直到在实验室复现了环境骤变，仅仅72天，这些虾的线粒体膜结构发生了可遗传的适应性改变，就像…..”</p><p>“就像有个进度条在疯狂+1？”</p><p>两人同时沉默。</p><p>楼外传来野猫厮打声，或者是发情啸叫。</p><p>「听力+1」</p><p>某个瞬间，杨帝几乎要坦白身上的异变，但他最后还是忍住了。</p><p>这种秘密说出去，说不定会被拉去切片。</p><p>一张切片几十微米厚的那种！</p><p>世人常调侃，什么非正常人类研究中心，什么拉去中科院切片泡酒。</p><p>杨帝也知道那是调侃。</p><p>但事情真发生到自己头上时，他不敢赌。</p><p>他不能100%确定那真的只是调侃，说不定是空穴来风！</p><p>却见张明远笑了笑：“生命，很神奇吧？这些奇迹般的适应能力，在寒武纪大爆发时就刻进所有生命的源代码了，通过种群的不断繁殖，随机变异，死亡，留下有利的变异个体，继续繁殖，随机变异……然后就实现一个物种的进化。”</p><p>杨帝忍不住问：“只能是物种的进化，不能是个体的进化吗？”</p><p>张明远像看傻子一样看着他。</p><p>“‘进化’其实不恰当，更准确来说，应该把它写作‘演化’。演化是一个族群的事，不停通过物竞天择，淘汰掉不适合生存的，保留下适应环境的。而个体本身，基因从生下来就被固定了，有什么‘个体进化’之说呢！不存在的。”</p><p>其实这些知识杨帝都知道，他从小看动物世界自然传奇探索发现。</p><p>他也知道，进化是物种的进化，而不是个体的进化。</p><p>但……发生在自己身上的一切，究竟如何解释？</p><p>张明远找了个科普网页，层层分叉的进化树在屏幕上舒展：</p><p>“三十五亿年前海底热泉口的古菌，学会用化学梯度差供能；二十四亿年前的蓝藻掀起大氧化事件，毒死全球厌氧生物的同时，为真核生物铺好了舞台。每次灭世级灾难，生命都开始激烈演化。”</p><p>杨帝注意力放在一个词上，“灭世级灾难”。</p><p>灭世……灾难？</p><p>“但人类早过了野蛮进化的阶段。”</p><p>张明远合上电脑，语气突然严肃，“我们用抗生素取代免疫系统，用空调对抗自然选择，现代医学把进化论锁进了ICU。幸好，现在你出现了，来自新世纪的新人类，勇敢的少年哟不对，勇敢的青年哟，快去创造奇迹～”</p><p>杨帝不理会张明远的挖苦。</p><p>“老张，你真的觉得，进化只能是物种的事吗？真没有那种集伟力于一身的个体进化吗？”</p><p>“有的，老帝。在某些极端情况下，生命体可能会发生突变，这种突变或许是瞬时的，就像是被某种力量推了一把。”</p><p>杨帝的心跳不由得加快。</p><p>他能感觉到，张明远的话里藏着某种深意。</p><p>或许，自己身上发生的一切，正是这种“被推了一把”的结果。</p><p>“张明远，这种‘推一把’又是什么理论，我好像第一次听说。”</p><p>“杨老帝，‘推一把’理论是我于公元2025年4月30日晚上9点27分刚编的，专门为你这种新人类量身定制。”</p><p>“……吔！不要再插科打诨啦！食我海虎爆破拳！”</p><p>「格斗+1」</p><p>张明远挡住了杨帝的手，然后抓住手腕，瞳孔骤缩，观察到他手正泛着不正常的粉红</p><p>不是烫伤的水泡，倒像新生儿的娇嫩，透出珊瑚般的粉色。</p><p>“你手怎么了？”</p><p>“热水器老化。”杨帝闪电般缩回手。</p><p>“不是你把自己烫的？对哦，你洗澡时候那热水哗哗的拧，人又好像卡bug了一样，定住不动，我在外面喊你都不答应，就是那时候烫到的？”</p><p>“呃呃呃，也许是被烫到了吧。”</p><p>杨帝根本没有被烫伤，甚至完全没有感受到任何不适。</p><p>源于那一句“耐热+1”。</p><p>张明远拉上床帘，打了个哈欠。</p><p>“好吧，要是新人类阁下还没进化出光合作用，就请帮忙把白炽灯关掉，一是为了我们共同的宿舍省省电费，二是我要睡了，我已经连干一天一夜没合过眼了。”</p><p>睡觉？这么早。</p><p>“你干啥子趴在电脑前干了这么久。我今早肠胃炎发烧睡觉的时候，一直迷迷糊糊听到你在说什么‘高斯噪声’，听起来有些像深度学习。”</p><p>张明远已经半梦半睡了：“嗯……就是件倍儿麻烦的屁事罢了，一张蓝天红气球图片，我的图像识别项目一直识别不出来那图片，怎么调整参数，怎么检查图片本身噪点，都搞不定……呼……呼……”</p><p>他已经睡着了，堕入梦乡。</p><p>杨帝也决定早点睡。他打算从明早开始，开始一项激动人心的大计划。</p><p>琦玉锻炼法。</p>
