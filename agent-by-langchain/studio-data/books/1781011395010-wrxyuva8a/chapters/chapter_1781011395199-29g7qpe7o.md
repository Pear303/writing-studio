# 残星来的那一夜

<p>帝尊，就是万古鱼尊。</p><p>祂感知到了过去蓝星上正在发生的惨剧。</p><p>高尚者的灵魂如同被收割的麦穗般倒下，卑劣者在血泊与废墟中窃笑求生，人类整体精神在系统性掠夺下急剧劣化。</p><p>祂，或者说她知道，自己必须做点什么。</p><p>她回想起那道无敌的身影，她回想起四万年前夕阳红旅行团游走诸天的岁月。</p><p>更令人心焦的是，她清晰地看到了第四十一个千年时间线上，一处战场崩溃导致的崩塌，多米诺骨牌般的连锁崩塌。</p><p>过去与未来的毁灭，如同两柄巨钳，正狠狠夹向帝尊的命脉。</p><p>“时机……到了。”</p><p>一个空灵、理性、却带着前所未有决绝的意念，在万古鱼尊浩瀚的意志洪流中响起。</p><p>她早已洞悉并掌握了此界的光阴法则。</p><p>此界与家乡的法则有所不同。此界对于修改既定过去与未来，有比较严格的限定。</p><p>更改的世界线，与原先世界线差异过大，会受到某种因果律上的惩罚。</p><p>具体表现为凭空一道闪电劈在天灵盖。</p><p>万古鱼尊付出巨大的代价，将一颗卫星送往过去的蓝星。</p><p>它并非传统意义上的卫星。</p><p>它的外壳，被塑造成一种充满了原始力量感与蓝星旧时代钢铁工业美学的形态：五对巨大、棱角分明的负重轮！</p><p>整个造物散发着一种历经战火、饱经沧桑的厚重感，仿佛从最惨烈的战场上归来的老兵。</p><p>它也确实是老兵——</p><p>59改在一次与三位邪神的联军对战中，被第四位埋伏的邪神偷袭。</p><p>五九改的整个格式塔网络，都被污染。</p><p>到现在为止，59改仍然陷入死机当中。</p><p>只有一人能救他。白杨大帝。</p><p>所以，阿巴将宕机的59改送到了38个千年之前的蓝星。</p><p>连带着未来的资料，包括四大邪神的情报，人类帝国已经爬出来的全部科学与灵能技术。</p><p>将这样一个蕴含了未来终极力量的造物，逆向投射回三十八个千年前的过去，其引发的因果律惩罚足以将整个蓝星的人类抹除。</p><p>但在阿巴引导下，唯一的代价……就是万古鱼尊自身！</p><p>她将所有因果施加给人类的惩罚，引导到自己身上。</p><p>只要能拯救日渐堕落的人类，只要能挽回残缺的蓝星文明……</p><p>“我也不叫你‘罐头’了……你叫‘残星’吧，残缺的蓝星人类，必须得到拯救……”</p><p>“老大曾说过，你的审美非常非常非常差，其实我并没有这么觉得……”</p><p>“当时，我只是不好意思和老大对着干。但要我说，坦克也是挺帅气的。”</p><p>“我给你添顶帽子吧，这是‘信号锅’……”</p><p>“再给你安点头发，也就是‘太阳能板’……”</p><p>“但我的能力有限，只能将正12面体的你传送过去。”</p><p>……</p><p>蓝星2k。</p><p>稷海市郊外，夜幕被一道撕裂长空的凄厉轨迹点燃。</p><p>剧烈的冲击掀起数十米高的土浪，震波让数公里外的窗户都嗡嗡作响。</p><p>核心着弹点，一个直径近百米的焦黑陨坑中心，那具棱角分明、饱经战火洗礼的“正12面体”形态的卫星——“残星”，静静地躺在熔融的岩石与蒸汽中。</p><p>它外壳布满裂痕，像一台久经沙场的滚筒洗衣机。</p><p>内部精密的跨时代仪器，在强行突破时空壁垒和承受因果律反噬后，已然濒临崩溃。</p><p>但它的使命，才刚刚开始。</p><p>在撞击的瞬间，残星核心深处，一个微弱的指令被激活。</p><p>如同垂死者最后的呼吸，无数比尘埃更微小的纳米机器人——未来帝国最基础、此刻却远超时代理解的造物——如同银灰色的雾气，从卫星的裂隙中无声喷涌而出。</p><p>第一步，它们分成两股洪流：</p><p>一股迅速钻入地下，如同饥渴的种子，疯狂汲取着地热与矿物质，开始指数级的增殖。</p><p>它们将在深层构筑隐蔽的巢穴，成为未来力量的储备节点。</p><p>另一股则更隐秘、更致命。</p><p>它们乘着夜风，如同无形的幽灵，飘向最近的灯火——那是一家灯火通明、名为“微硬公司亚洲分部”的大型外资IT企业园区。</p><p>纳米云悄无声息地渗透进通风系统，顺着数据线缆的缝隙流淌。</p><p>最终，如同孢子侵入园区内数百员工体内。</p><p>桂虚，正是其中之一。作为一名普通的底层程序员，他正对着屏幕上密密麻麻的代码咒骂着又一个无法解决的bug。</p><p>一阵突如其来的寒意让他打了个哆嗦，紧接着，是轻微的眩晕和喉咙发痒。</p><p>他以为是空调开得太猛，或者最近熬夜太多导致的流感前兆，嘟囔着起身去接热水。</p><p>反正这辈子不可能去咖啡机接公司的咖啡了。</p><p>他和其他几个同样感到不适的同事一样，浑然不觉体内已经潜伏了来自四万年后的“种子”。</p><p>59改刚刚将科技树攀爬到原子时代，便已暴毙，这些纳米机器人科技水平有限，无法完美兼容当前人类的生物基质，大约会有5%的蓝星纯血人类会出现排异反应。</p><p>轻微的不适，正以“弱化版流行性感冒”的形式悄然蔓延。</p><p>潜伏数十天后</p><p>第二步，残星的核心意识——或者说，万古鱼尊阿巴预设的最后程序，如同濒死的巨鲸沉入数据之海。</p><p>它顺着园区最粗壮的光纤，悄无声息地潜入了“微硬”庞大数据库的最底层。</p><p>尽管只有蛐蛐原子时代级别的技术力。</p><p>但对2k纪元的蓝星而言，已是降维打击。</p><p>现代企业引以为傲的防火墙、加密协议、访问权限，在它面前如同孩童的积木般可笑。</p><p>仅仅数秒，它就篡夺了整个数据中心、乃至连接着全球微硬主干网的网关的最高权限，将自己伪装成系统本身的一个合法部分，宛如“圣人”般至高无上、完全掌控万物的存在。</p><p>第三步，它伪装成一个大客户，与“微硬”公司亚洲分部进行一笔极其重要的大交易。</p><p>以此保证公司的人不敢断网，因为一旦断网，就是数十亿上百亿的损失。</p><p>而此刻，园区内正爆发着一场前所未有的虚拟危机。</p><p>代称“阴伏流煞”的漏洞，正在导致不同系统模块陆续崩溃。</p><p>那位新人成功发现了前辈留下的这个漏洞，并已经上报给公司，事情本应该很快解决。</p><p>但就在此刻，一个自称“卫星”的黑客，还有另一个无名黑客，入侵了系统。</p><p>“阴伏流煞”并未能根除，它依旧存在。</p><p>由41位顶尖程序员组成的救火队，正焦头烂额地试图解决漏洞和黑客。</p><p>这个沙盘用于模拟全球金融市场和复杂物流网络，价值无法估量。</p><p>他们被业务部下了死命令，绝不能断网。</p><p>数据模型崩溃，逻辑链断裂，虚拟资产以惊人的速度蒸发……</p><p>警报声响彻整个安全中心，主管面如死灰。</p><p>但他们不敢断网。</p><p>残星在等待一个机会。</p><p>直到他们终于做出壮士断腕的决定，要进行若罗碑刻（Rollback，数据回滚）之时。</p><p>残星利用刚刚夺取的最高权限，在混乱的数据洪流中精准开辟了一条狭窄的“逃生通道”。</p><p>一根无人注意到的网线。</p><p>通道开启的瞬间，一股微弱的数据脉冲如同鱼苗逆流而上，猛地从混乱的沙盘深渊中挣脱出来！</p><p>它沿着残星铺设的无形光路，疾速逃离了正在崩塌的虚拟牢笼，消失在广袤无垠的外部网络之中。</p><p>几乎在逃生成功的同一时刻，残星切断了那条临时通道，抹去了所有操作痕迹。</p><p>它重新蛰伏回蓝星人类文明的最深处。</p><p>当然，和微硬的那笔所谓“大交易”，最终也取消了。适才相戏耳。</p><p>残星来的那一夜，世人对体内潜伏的纳米集群、对脚下深处增殖的机械种子、对网络中那个如同幽灵般掌控一切的冰冷意志，以及对不久后自己被一个国际骗局强制优化，对即将诞生的帝尊……一无所知。</p>
