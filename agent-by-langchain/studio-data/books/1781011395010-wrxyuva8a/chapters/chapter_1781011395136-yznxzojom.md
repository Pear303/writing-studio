# 复健计划·下

<p>杨帝站在原地，面对这铺天盖地的攻击，燃起了更为浓烈的战意。</p><p>“既然你已下定决心，信念饱满，那我也要使出全力！”</p><p>他周身气息陡然一变，气势原本沉稳如山，此刻竟如汹涌的海啸，战意涌动！</p><p>如果此刻他还吊儿郎当，随意散漫——那就是对鱼尊以及其信念的最大侮辱。</p><p>爆气！！</p><p>杨帝的黑发根根倒竖如超级赛亚人，额角青筋暴起似赤红蚯蚓。</p><p>他垂在身侧的右拳骤然攥紧，指骨发出炒豆爆响，指关节迸溅出细密的金色火花。</p><p>“咔嚓——咔嚓——”</p><p>脊椎从尾椎开始节节上挺，他左侧胸肌如活物般鼓胀抽搐，古铜色的皮肤下，条状肌肉纤维正以皮米级幅度疯狂震颤，将体表血管挤压成蛛网般的紫黑色纹路。</p><p>右肩三角肌猛地隆起，带动整条手臂骨骼发出沉雷般的闷响。</p><p>热身。</p><p>肩胛骨错位，迸发出一瞬白光，亮度竟媲美极超新星爆发！</p><p>呼吸。</p><p>杨帝深吸一口气，整个胸腔如风箱般急剧扩张，肋骨错位的脆响连成一片。</p><p>蓄力。</p><p>背后十二对肋骨依次翻转，在体表形成龙鳞般的凸起轮廓——他正在仿照弹簧蓄力。</p><p>凝劲。</p><p>丹田处传来沉闷的爆鸣，仿佛有万亿头洪荒凶兽在体内奔腾，带动四肢百骸的肌肉群如浪涛般层层翻滚。</p><p>杨帝抬起了右拳，拳锋所指之处，泛起蛛网般的深邃的空间裂痕。</p><p>他周身迸发的气势在宇宙中掀起惊涛骇浪，方圆百万光年，星辰都因这股威压而剧烈震颤，星核迸发出刺目的光芒，仿佛在为即将到来的终极碰撞发出哀鸣。</p><p>纯粹体术，武道巅峰！</p><p>鱼尊的「大荒囚天鳍」已裹挟着三千大道、众生愿力的威压斩至，巨镰状鳍影所过之处，空间被彻底绞碎，露出其后混沌未开的虚无。</p><p>就在鳍影即将触及杨帝的刹那，杨帝右拳骤然挥出！</p><p>针尖对麦芒！</p><p>这一拳没有华丽的光芒，没有震天动地的声响，却让整个宇宙陷入了诡异的寂静。</p><p>拳风所过之处，空间如镜面般平整地凹陷，形成一个深不见底的黑洞，将周围的光线、能量乃至时间都尽数吞噬。</p><p>零点能的余波与灵能的狂潮，在一人一鱼之间轰然相撞。</p><p>爆发出比宇宙大爆炸还要耀眼的光芒。</p><p>没错，两股能量相撞的瞬间，战场中心瞬间复现了宇宙大爆炸最初的十的负四十次方秒。</p><p>在普朗克尺度下，时空结构彻底撕碎，暴胀场剧烈震荡，释放出足以扭曲因果律的能量，虚粒子对以超乎想象的速度凭空产生又湮灭。</p><p>温度刹那间攀升至十的三十二次方开尔文，超越了质子和中子能够稳定存在的阈值。</p><p>夸克与胶子挣脱强相互作用的束缚，在碰撞区域形成夸克-胶子等离子体，随即进一步熔化成更纯粹的能量形态。</p><p>以纯粹的“能量”，摧毁法则。</p><p>周围时空，烧蚀出永久的蜂窝状结构。</p><p>这将是本宇宙的不愈之伤，亦是二位至尊战斗过的证明。</p><p>鱼尊知道，自己败了。</p><p>在杨帝轰出那一拳时，她知道自己死定了！</p><p>仅靠纯粹体术，轰出相当于10^50灵强度的一击。诗人握持。</p><p>她制造的漫天光效便如遇针的气球般寸寸龟裂，那些搭在她肩膀上温暖的手/肢体/鳍/鞭毛，无数碳基生命殷殷期盼的目光……</p><p>在接触拳风刹那，尽数坍缩成细微的光尘。</p><p>鱼尊本想就此拥抱那创世能级的烈芒。</p><p>但下一刻，她又看见了无数生灵的眼睛。</p><p>“不……我不能死，我一定要活下去呀！！”</p><p>死亡是对命运的最终妥协，也是万千意义的终结。</p><p>鱼尊眼中闪过决然，刹那间，她的灵能护盾与机甲的超维度护盾，如潮水般层层展开，相互嵌套，眨眼间便堆叠了数十万层！</p><p>然而，拳罡与护盾接触瞬间，便爆发出不祥的刺目红光！</p><p>“咔嚓——”</p><p>护盾在杨帝的一拳之下，如同脆弱的玻璃般瞬间破碎，接连爆破！</p><p>十万层护盾，化作光屑飘散星空中！</p><p>那股强大的反震力让鱼尊的机甲都剧烈颤抖起来，她只感觉一股排山倒海般的力量顺着机甲传导至全身，震得她五脏六腑都移位。</p><p>护盾已无，现在是第二层防御——装甲。</p><p>守望者文明的“色核力装甲”，是此世最硬的玩意。</p><p>色核力在夸克之间的结合力量随距离增加而暴涨，将强子内总“色”为零的复数个夸克，牢牢束缚在一起。</p><p>守望者文明找到了将强子拆解为独立夸克的方法。</p><p>在此基础上，他们仿照夸克禁闭，通过调整不同“色”夸克的布局，成功制造出了一种可无限扩展延伸、且总色保持为零的微元结构。</p><p>这种微元被用作装甲的构成单元，而色核力则起到了如同胶水一般，将装甲各部分牢固粘合的作用。</p><p>即使是一座中子星以高亚光速横冲直撞来，也无法在色核力装甲上留下一道白印子！</p><p>噗。</p><p>那层能硬扛中子星撞击和黑洞撕扯的色核力装甲，被杨帝打穿出沙煲大小的洞。</p><p>鱼尊一瞬间鱼脑空白——她原以为护盾和装甲至少能撑个3秒2秒1秒，为她逃出生天争取一点点时间。</p><p>不曾想，这号称宇宙最强防御的组合在杨帝拳下竟脆弱如纸。</p><p>拳锋与她的鱼脸近在咫尺。</p><p>随即，杨帝将拳头切换成了手刀。</p><p>鱼尊双目暴凸——不，不对！！</p><p>这个威力，就算是手刀也足以将我一分为二啊啊啊！</p><p>快字面意义上的住手啊啊！</p><p>杨帝的手刀距离她光滑额头仅剩毫厘时，突然听见一声呜咽的“老大”。</p><p>“你说什么？”</p><p>“呜呜呜……老大别杀我。”</p><p>那怪物已将大手伸来，阿巴必须忍辱负重！</p><p>而众所周知，鱼类卑躬屈膝的方式，就是将对方称为“老大”，并且露出肚皮最柔软的鳞片。</p><p>隐忍，阿巴……</p><p>杨帝一怔，把手刀改成爆栗，将鲈鱼大仙弹飞3600度：“既然把我称作老大，那我不得不罩你了。我是杨帝，白杨大帝。”</p><p>“噢噢哦……哦啊？”</p><p>阿巴双鳍护住肿胀的脑袋，一脸懵逼。</p><p>虽然不明白发生了什么，至少，活下来了。</p><p>“鱼，放点水。”</p><p>“哦哦……啊？老大？什么？水？”</p><p>杨帝说：“水，纯水，H2O，蕴含你那什么本源的混沌之水，你好像把它称作什么……太初溟濛？</p><p>“呃呃呃，这名字……鱼弟，我这么说吧，你天生为鱼，中二点也正常。</p><p>“起名风格我就不多做评价了。现在能不能帮我个忙，放些水出来？纯水最好，可以多放一点。。”</p><p>鲈鱼阿巴浑身鳞片簌簌发抖，庞大的身躯不受控制地扭曲变形。</p><p>原本用来镇压万界的「太初溟濛域」竟如决堤之水，倾泻而出。</p><p>混沌之水在虚空中翻涌，每一滴都蕴含着创世之初的法则之力。</p><p>却在接触到杨帝的刹那温顺得如同家养的溪流，自动汇聚成直径百万公里的透明球体。</p><p>如果是直径百万公里的普通水，会迅速塌缩成一颗巨行星，核心处的压力足以瞬间点燃核聚变。</p><p>但这一颗巨型水球，只是浮在真空中。</p><p>杨帝哂笑：</p><p>“或许你们会觉得，我言语和行为带有低等碳基生物的幼稚与不成熟。</p><p>“其实是我在梦里被杀、挨打太多次了，对本宇宙历史与世界线的操纵也耗费心力。</p><p>“现在一闲下来，放空大脑，有些返璞归真了吧，特别怀念在老家的时光。</p><p>“找到一条真正的‘金色道路’实在困难，但我至少让自己目力所及范围内的知性生命，能够随心意选择更美好的明天。</p><p>“接下来我要做的事，鱼弟可能会反感——但我已经在梦里磨练过数千万次‘钓鱼’，就是为了这一刻。”</p>
