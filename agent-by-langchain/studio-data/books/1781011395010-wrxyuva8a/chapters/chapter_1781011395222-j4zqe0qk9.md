# 受肉

<p>达文西的尸体并未开始腐烂。</p><p>嗯是个刚下完雨后，还算凉爽的夏夜。</p><p>一件概率很低的奇迹发生了。</p><p>被射杀的那一刻，达文西的廉价红米手机从裤袋滑落，正面朝天掉在一旁的地上。</p><p>笔名万业狐狸的宅宅死后一小时。</p><p>荒野上，短暂下了一场小雨。</p><p>因为达文西尸体是在树头下，所以雨珠经过一段时间的积蓄，才慢慢从树叶滚落。</p><p>一滴沉重的水珠，从树冠叶尖坠落，精准无比地砸落在那部正面朝上、沾满泥点的廉价红米手机屏幕上。</p><p>屏幕瞬间被砸出一朵小小的水花。</p><p>这滴水珠，恰好浸润了屏幕下方指纹识别区的中心位置。</p><p>这部手机的触屏靠电容感应来识别操作，而水珠本身是导电的，会让电极间的电容分布出现混乱，像是有人“触屏”了。</p><p>指纹识别模组忠实地执行它的程序——检测到不明液体覆盖，判定为“指纹识别失败”。</p><p>屏幕自动亮起，跳出了数字密码解锁界面。</p><p>啪嗒……嗒……嗒……</p><p>仿佛天意弄人，又是连续几滴更大的水珠，紧随着第一滴，沿着几乎相同的轨迹，狠狠砸在亮起的手机屏幕上。</p><p>它们并非散乱溅开，而是像被无形的手指引导着，在光滑的屏幕上汇聚成一小股细流。</p><p>这股细流，顺着屏幕的弧度，恰好流过数字密码键位“1”、“2”、“3”、“4”……最终停在“6”的位置。</p><p>水痕连成一条湿漉漉的路径。</p><p>屏幕的电容触控层，将这湿润的导电体接触，错误识别为了一次连贯的滑动解锁动作。</p><p>“6690……密码错误次数：1”</p><p>“6580……密码错误次数：2”</p><p>“6587……密码错误次数：3”</p><p>“6547……密码错误次数：4”</p><p>系统提示疯狂闪现。</p><p>然而，就在第四次“错误”的滑动路径完成，有一次错误就会自动锁屏之时。</p><p>“6544……解锁。”</p><p>红米手机进入桌面。</p><p>又有几滴水珠落下，形成临时“导电手指”，在屏幕顶端短暂停留的。</p><p>它恰巧覆盖了屏幕最上方通知栏区域——那里，有一个“洋柿子作家助手”后台运行的图标通知。</p><p>水滴的导电性，又一次被屏幕错误地识别为了一次“点击”。</p><p>手机屏幕猛地一跳，瞬间切换到了“洋柿子作家助手”APP的主界面。</p><p>后台进程被强行拉到了前台。</p><p>巧合的链条尚未终结。</p><p>那几滴肇事的水珠，在完成了“点击”这一行为的壮举后，也并未立刻逃逸。</p><p>它们残留的水迹，在屏幕解锁进入App主界面后的短暂延迟里，因为晚风吹过，导致了微不可查的位移，以及短暂的水珠震动。</p><p>这微小的位移，恰好让一滴最大的水珠的边缘，轻轻触碰到了APP主界面上一个名为《舌尖上的数值怪》的草稿文件上。</p><p>误触。屏幕瞬间切换，进入了这本仅仅只有2000多字草稿的编辑页面。</p><p>编辑页面打开，显示着达文西死前——或者说就在银隼敲门之前——刚刚敲下的、关于他“痛改前非”后构思的“绝对爽文”的零星碎片。</p><p>开头是一段混乱的、充满感叹号的开场白，描述着“白杨大帝”如何在一个类似主神空间但被他称为“新手村”的地方醒来，如何“虎躯一震”震碎空间，如何“眼神睥睨”吓尿众人。</p><p>中间夹杂着大量“待填充”、“设定待定”、“XX作品XXX设定可缝”的潦草备注。</p><p>几滴水珠，在重力和最后一丝晚风拂动的共同作用下，终于开始了最后的滑落。</p><p>它们滑过那些混乱的文字，滑过那些潦草的备注，最终——</p><p>恰好覆盖在了文档侧边栏“人物设定”列表上唯一一个孤零零的名字上：</p><p>「杨帝」</p><p>并且，因为水的表面张力与屏幕的接触面积，这次覆盖被识别为了一次“点击”。</p><p>人物卡界面瞬间弹出。</p><p>这张人物卡简陋得令人发指：</p><p>姓名：杨帝 （“白杨大帝”太土，直接杨帝！简洁霸气！）</p><p>样貌：黑发黑眸 （标配省事，经典出装，读者有代入感）</p><p>能力：星际虫族怎么样？索雷普林原虫也不错，正好最近群星也出了巨兽起源，还没时间玩儿呢。。。</p><p>性格：不想写杀伐果断……</p><p>背景：整天孤儿开局，寓意貌似不太好吧，不够吉祥。还是祖上三代贫下中农吧，</p><p>草稿在“滑动屏幕”动作的惯性作用下，拉到最底部。</p><p>「第二版改稿」</p><p>「杨帝和主神空间扯不上关系，他是个平凡的在校大学生，因为食物中毒偶然激活无限进化升级的能力。」</p><p>「锻炼级→线性递增。世界内致死级→指数递增。世界外致死级→幂塔递增。」</p><p>「哇，完美符合高德纳箭头的进化路径。难道我真是天才吗？」</p><p>水珠漫过「第二版改稿」那几行充满自嘲与灵光一闪的文字。</p><p>最终，在文档编辑区最末尾的光标处——也就是达文西生前敲下的最后一句“难道我真是天才吗？”的后面——汇聚、融合。</p><p>屏幕的电容层，将这摊不规则的水渍边缘细微的颤动与重力的持续牵引，错误地识别为了一次持续的、缓慢的“长按输入”。</p><p>水滴的导电性，代替了生物电信号，忠实地在屏幕上“键入”了新的字符。</p><p>一个字符，接着一个字符，缓慢而诡异地浮现：</p><p>「杨帝在最终卷，突破了真正的无限，来到我所在的叙事域」</p><p>光标在最后一个句号后闪烁，如同一个微小的、来自另一个维度的信号灯。</p><p>就在这行由自然水滴“代笔”的文字被完整“输入”的瞬间——</p><p>嗡！</p><p>一种难以言喻的“嗡鸣”，以那部沾满泥点和雨水的红米手机为中心，极其短暂地扩散开来，又瞬间坍缩消失。</p><p>荒野的空气似乎凝固了一刹那，连虫鸣都陷入了暂停。</p><p>整个可观测宇宙，都凝滞了一瞬间。</p><p>紧接着，地上那具属于“万业狐狸”、属于“达文西”的尸体，发生了剧变。</p><p>首先是那颗爆裂开的头颅。</p><p>那些沾满泥土和暗红凝固物的颅骨碎片，那些散落的脑组织残渣，如同被按下了倒放键。</p><p>它们仿佛无视熵增，无视时间流逝的不可逆，以肉眼可见的速度逆流回溯。</p><p>骨茬收缩、拼合，软组织增生、覆盖，血管神经如同精密的电路板被重新焊接……</p><p>短短数分钟，一颗覆盖着头皮和黑发的完整头颅，便在那无头的脖颈上重新“生长”出来。</p><p>然而，那绝非达文西的脸。</p><p>新生的头颅轮廓更为硬朗，眉骨更高，鼻梁更挺。</p><p>紧闭的眼皮下，是典型的东方人眼型，紧闭的嘴唇线条透着一股近乎冷漠的坚毅。</p><p>那正是人物卡上描述的「杨帝」——黑发，黑眸，简洁而充满力量感的面容。</p><p>这张年轻人的脸，取代了达文西原本略显颓废和疲惫的脸庞。</p><p>一个虚构的角色，正强行覆盖在创作者的遗骸之上。</p><p>头颅再生的完成只是一个开始。这具拥有了杨帝头颅的身体，猛地剧烈颤抖起来！</p><p>体温计如果存在，会瞬间爆表。</p><p>皮肤以惊人的速度变得通红滚烫，仿佛体内点燃了一座熔炉。</p><p>密密麻麻的红疹如同燎原之火，瞬间爬满了脖颈、手臂、胸膛，甚至延伸向被衣物覆盖的部分。</p><p>这不是普通的过敏或感染，这是构成这具身体每一个细胞的遗传物质——属于“达文西”的基因序列——正在被某种更高级、更霸道的存在强行篡改替换。</p><p>“杨帝”的基因信息，正在粗暴地覆盖写入每一个细胞核。</p><p>达文西的身体，将会是杨帝的受肉。</p>
