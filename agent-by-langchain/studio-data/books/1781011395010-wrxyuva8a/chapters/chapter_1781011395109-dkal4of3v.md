# 十环法术轰炸

<p>“不，还是有问题。”</p><p>伊芙指尖划过空中，凝聚出一团跳动的火焰，将其塑造成史莱姆与巨龙的形态。</p><p>“就算堆砌成百上千熔岩史莱姆，它们体内的火系灵能，也不过是巨龙力量的零头。混乱无序的能量流动，也无法复刻巨龙血脉中的精纯灵能。”</p><p>简而言之，巨龙、史莱姆，它们的物质组成和物质结构，从本质上就是不同的。</p><p>如果说，巨龙是钛合金板砖。</p><p>那么，熔岩史莱姆就是细沙。</p><p>因为史莱姆的构造太过简单，根本不足以承载很高浓度的灵能，也不足以承载超过5岁小孩的智力。</p><p>伊芙轻轻一握，火焰化作齑粉，“用史莱姆莱模拟巨龙，就像试图用细沙构筑高塔，用绳子捆绑流沙，稍有外力，便会崩塌。”</p><p>“更何况，在‘智力’方面，史莱姆作为最低等魔物，没有复杂的神经结构，没有精密的大脑，终日浑浑噩噩——原初之眼不可能愿意夺舍之，因为这意味着对己‘降智打击’。”</p><p>就相当于一个绝世魔尊想要秽土转生。</p><p>但大魔头不会容忍自己转生后，变成个彻头彻尾的菜逼八+傻帽。</p><p>落差太大，他宁愿好好死着！</p><p>于是，推断又陷入僵局。</p><p>杨帝：“那如果把史莱姆堆多一点呢？量变引起质变……”</p><p>伊芙却是瞳孔一缩，倏地站起身，抄起圣树法棍，对圣骑士吼道：“巴德！你们教廷的人！他们来了？！”</p><p>“哦，没错，他们已经包围了我们。”</p><p>伊芙恒常地愤怒：“你果然还是和教廷勾结！亏我还把你当作并肩作战的伙伴！”</p><p>“并没有，我也刚刚才知道。”巴德说。</p><p>“那你为何还如此平静？！”</p><p>“我莫得感情。物质决定意识，在变成现在的形态后，虽然我保留了绝大部分记忆，但我失去了大部分情感，感觉人格也有轻微变化……”</p><p>话音未落，巴德的盔甲剧烈震颤，佩剑发出清越鸣响。</p><p>“有什么大的要来了？！”瑞弗维尔惊呼着举起笔记本。</p><p>他后知后觉，终于发现一丝不对劲。</p><p>乌云如潮水般自天际翻涌而来，仿佛整片苍穹都被撕开了一道裂口，浓稠的黑暗正从裂缝中倾泻而下。</p><p>低沉的闷雷如同巨兽的嘶吼，从远方滚滚而来，震得地面微微发颤。</p><p>气候异常，愈演愈烈了。</p><p>伊芙握紧圣树法杖，杖顶的翡翠在闪电照耀下泛着妖异绿光。</p><p>此时此刻，她能清晰感受到空气中的灵能正以恐怖速度被抽空。</p><p>“嗯，是教廷的‘光明圣典·十环法术·涤罪天幕’，他们要把这里焚成一片焦土。”巴德的声音依旧平静，却罕见地表现出一丝凝重。</p><p>伊芙皱眉：“实力如何？”</p><p>“能把方圆十公里轰平吧。”</p><p>“……你为何仍然如此平静啊！”</p><p>“我已经死过一次了，应该惊慌的是你们才对。你们应该现在就跑。”</p><p>云层中窜出幽紫色的闪电，将天空劈成狰狞的碎片。</p><p>“涤罪天幕”即将降下。</p><p>多年来对灵能法术的浸淫，伊芙的丰厚经验告诉她：距离十环法术落下，还剩10秒。</p><p>人能在10秒内跑出10公里外吗？</p><p>就算有灵能法术，也很难吧……</p><p>就算她自己能逃脱，另外二人也十死无生。</p><p>哦，或许杨帝不会死？但瑞弗……</p><p>伊芙思考了500毫秒，忧郁地望向天空。</p><p>巴德嘴巴仍然噼里啪啦的说话：“我会帮你们抵挡一部分，但不保证能阻隔所有能量，所以你仍然要尽快和他们躲到地下……”</p><p>“……他们？地下？”</p><p>伊芙这才注意到，杨帝和瑞弗维尔他们在几百米开外，张扬双臂，对自己呼吼着什么。</p><p>还矮人奥拓，他半截身子在土里……那是个地洞。</p><p>“巴德！你不来！？”</p><p>“我无法离开此地超过一米，我被卡利斯托巨龙施加了‘绑定诅咒’。”</p><p>伊芙瞳孔再度收缩成针尖大小。</p><p>果然，「绑定诅咒」是巨龙的诅咒吗……</p><p>“保重。”伊芙最后低声道了一句。</p><p>“教廷的布置可能在南海某处。”巴德也回了最后一句。</p><p>伊芙来不及多想，来不及分析他为何选择这时候在透露出如此关键的情报，也来不及再深入追问。</p><p>或许这是他与巴德所见的最后一面了，这位孤寂的圣骑士，只有高悬银河的孤月，和他守望的这处井口，能够知晓他未说出口的心声。</p><p>她瞬发旋风法术、敏捷增益，在3.5秒内从零开始加速-冲刺-刹车，到达二百米外瑞弗维尔三人所在之地。</p><p>“来不及解释了，快下洞！”</p><p>三人中，瑞弗维尔也是唯一一个还把半截身子留在地面上的人，呼吼着让精灵不要像个老太太，老太太没人爱。</p><p>（我爱我奶奶( •̥́ ˍ •̀ू ) ）</p><p>“瑞弗！咬牙！”伊芙一个飞天大踹，将人类连带着自己踹进进地洞里。</p><p>已过去4.2秒。因为瑞弗维尔把身子探出洞，所以多消耗了0.2秒。</p><p>潮湿的腐土气息扑面而来，伊芙重重摔在布满青苔的石板上。</p><p>洞壁缝隙渗出的水珠，啪嗒落在精灵颈间，寒意顺着脊椎爬上来。</p><p>抬头望去，直径不足半米的洞口正被黑暗吞噬——杨帝施展着物质形态重塑的法术，用岩石和泥土将洞口堵死。</p><p>下方，奥拓正在用「效率V+耐久III+丝绸之触」的狱髓钻头疾速挖洞，最坚硬的花岗岩，也触之即碎。</p><p>距离伊芙离开巴德，已过去6秒。</p><p>精灵想起她60岁读小学时，老师布置的一道题目：在一个洞穴内，矮人施工队阿尔法、人类施工队贝塔，同时开工。一队负责开洞，另一队负责填补，这就是“滑动窗口”……</p><p>精灵伊芙正想让杨帝奥拓两人挪开屁股让她上，却听见矮人激悦的声音震得整座洞穴“崆崆”回响：“找到了！我们镇的祖传墓道！！”</p><p>那是18年前，砾石镇联合倒斗队挖的墓道。</p><p>奥拓他老爹当过矿工，有挖洞经验，所以当年也是负责开路的，对这条墓道持有一定股份。</p><p>那是条蜿蜒着向下的通道，宽两米，有些地方用圆木和铁箍固定。</p><p>来不及细想了，伊芙用灵能凝成虚空大手，将杨帝三人按进下方的墓道，然后自己跳进去，用花岗岩封死来路。</p><p>已过去9秒。</p><p>据巴德所说「圣光·十环法术·涤罪天幕」能够轰平方圆十公里地形。</p><p>伊芙尝试计算要土遁多深才能避免爆炸波及，但计算1.1秒后放弃了，这数学题她做不出来。</p><p>放弃计算的瞬间，那恐怖的“涤罪天幕”轰然落下。</p><p>应该是落下了，因为那巨大的轰鸣声仿佛要将世界震碎。</p><p>“轰轰——轰——隆隆——隆！！”</p><p>洞口被封死的土层与岩石，在这股毁天灭地的力量下剧烈颤抖。</p><p>墓道内众人，只觉一股强大到难以想象的冲击力顺着通道疯狂灌下，像是有无数只巨手，拼命撕扯周围一切。</p><p>“愣着干嘛？继续往下走啊！！”</p><p>伊芙左手释放范围增益法术给众人上buff，右手顶住地面的爆炸冲击。</p><p>“这里距离地面的土层也不过五六米，我们却没有被爆炸瞬间蒸发……是巴德还在支撑。”</p><p>18年前的墓道内，众人朝深处奔袭。</p><p>奥拓一马当先，手中的狱髓钻头在昏暗中闪烁着幽冷的光，无论什么牛鬼蛇神，都能轻易钻碎！</p><p>杨帝、瑞弗维尔紧跟其后。与其说他们主动跑，不如说是被伊芙用隐形的大手推着。</p><p>“奥拓挖快点啊啊啊啊！”</p><p>“我在镇上被木镐撞断了根肋骨！速度不起来！”</p><p>伊芙兼任数职，还得时不时回头，用法术加固着身后墓道的石壁。</p>
