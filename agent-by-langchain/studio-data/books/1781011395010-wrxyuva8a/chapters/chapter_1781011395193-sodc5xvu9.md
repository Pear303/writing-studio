# 大胃王，来收人了

<p>“我懂的，小马哥。你追求的是‘意义’在彻底湮灭前，那瞬间爆发，最极致、最纯粹、最璀璨的光。智慧，勇气，善良，纯洁……所有美好或挣扎的事物，在归零刹那绽放的‘烟花’。”</p><p>马格努斯的意志微微波动，带着一丝被理解的、近乎赞赏的冰冷愉悦：</p><p>「悟性尚可，你我高山流水。」</p><p>但杨帝话锋一转。</p><p>他大声批判：“不过你这‘艺术’，格局小了！层次低了！最可怕的是，太——肤——浅——了！”</p><p>这突如其来的贬斥，让马格努斯那亘古冰冷的意志都产生明显凝滞。</p><p>周围的崩坏血肉，蠕动的速度都慢了下来，仿佛在“倾听”。</p><p>“你就像个……嗯……街头卖艺的。”</p><p>杨帝的意念模拟出一种刻薄的惋惜，“收集点凡人临死前的闪光，就沾沾自喜，以为掌握了这种悲剧艺术的真谛？小马哥，我问你，你收集的这些‘烟花’，再璀璨，再绝望，它们是什么？”</p><p>没等马格努斯回答，杨帝自问自答，一字一句敲打在对方的核心上：</p><p>“它们！都！是！‘他者’的烟花！”</p><p>“是‘别人’的毁灭！是‘别人’的意义归零！你是什么？你只是个贪婪的观众！一个躲在幕布后面，品味着他人悲剧的……鉴赏家！一个……品味着‘二手虚无’的可怜虫！”</p><p>马格努斯的意志核心，那裂隙周围的黑暗剧烈翻涌起来，传递出一种混杂着愤怒、困惑和被刺痛的波动。</p><p>杨帝的话语，精准地戳中了它的痛点。</p><p>二手……？</p><p>“真正的终极艺术是什么？”</p><p>杨帝的意念陡然拔高，带着一种狂热而癫狂的蛊惑力，“真正的终极艺术，不是看别人怎么怎么死！而是——你自己死！”</p><p>“是创造者的自我献祭！是艺术家的终极谢幕！是‘牧者’亲自踏入自己设计的屠宰场！”</p><p>杨帝的意识体疯狂变幻着形态，模拟出各种壮烈或凄美的自毁场景：</p><p>星辰坍缩、宇宙热寂、画卷自焚，乐章在最高潮处戛然而止……</p><p>“想想看！马格努斯！当你成为你艺术的主角，当你操控着那足以归零现实的‘诡异’，不是作用于那些渺小的‘烟花材料’，而是作用在你自己身上！”</p><p>“你的宏大！你的冰冷！你的亘古！你的艺术！这一切‘意义’，在你亲自操控下被撕裂！被溶解！被归零！这个过程，将是何等惊心动魄的璀璨啊。”</p><p>“这才是超越一切‘他者烟花’的，独一无二，只属于你自己的绝唱！”</p><p>马格努斯忍不住表达认可。</p><p>它内心逐渐滋生出强烈冲动，甚至产生当场自杀、奔赴西方极乐世界的念头。</p><p>就在这千钧一发之际，庞大意志骤然剧烈晃动了一下，才恍然大悟。</p><p>原来杨帝正借助那连绵不绝的话语，对祂的精神进行着污染！</p><p>「你该死！！」</p><p>马格努斯恼羞成怒，这一刻艺术已经不重要了。</p><p>它凝聚“无限恐怖之主”的全部力量，一巴掌呼上来，打算要将杨帝轰杀至渣。</p><p>“领域展开。”</p><p>杨帝的意念平静得没有一丝波澜，甚至带着点……无聊？</p><p>嗡——</p><p>没有任何惊天动地的声势，没有光芒万丈的特效。</p><p>以杨帝那颗“四喜丸子”为中心，一个无法形容、无法观测、无法理解的“领域”悄然展开。</p><p>它没有形状，没有边界，仿佛只是空间本身被替换成了另一种绝对异质的“规则怪谈”。</p><p>马格努斯那足以毁灭一切的恐怖一击，在触碰到这领域边缘的瞬间，如同泥牛入海，没有激起半点涟漪。</p><p>甚至连一丝能量波动都未能传递出来，就那么无声无息地……消失了。</p><p>「怪谈领域」本质上，就是规则非常古怪的领域。诡异所展开的领域，就是规则怪谈。</p><p>比如在某些宇宙，规则是：重力与距离的平方应当成反比。</p><p>也许在某些存在所创造的领域，规则变成：售货机里的山羊血不要喝。</p><p>领域也是一方小世界，不同世界不同规则。规则本身，由领域的主人来定。</p><p>马格努斯有些忌惮地感知“无限恐怖之主”所在的位置。</p><p>更让它感到冰冷颤栗的是——看不到里面！</p><p>马格努斯完全无法感知“无限恐怖之主”这部分肢体的存在，对方的领域绝对霸道至极，居然完全隔绝了内外信息流动。</p><p>领域内的法则，必定比它设计的“怪谈”还要扭曲可怖，酷烈万分。</p><p>那里面是什么？杨帝在做什么？它的攻击被如何化解了？</p><p>一切信息都被彻底屏蔽、吞噬，仿佛那里存在的是一个逻辑上的绝对空白，一个连“观测”这个概念本身都被否定的区域。</p><p>就像一个凡人闭着眼知道面前有一堵墙，但墙后面是天堂还是地狱，是空无一物还是森罗万象，完全无从得知。</p><p>这种未知，比任何已知的恐怖更让它感到不安，甚至……恐惧？</p><p>马格努斯吓人吓了一辈子，这是它第一次感受到未知所带来的恐惧。</p><p>时间失去了意义。对小马哥而言，可能只是一瞬，也可能过了亿万年。</p><p>那片“绝对空白”的领域毫无征兆地消散了。</p><p>空间恢复正常。</p><p>杨帝的“四喜丸子”意识体依旧悬浮在原地，他的肉身连位置都没挪动分毫。</p><p>只是，那片原本属于“无限恐怖之主”力量核心的区域，此刻空空如也。</p><p>马格努斯麾下象征着恐怖、扭曲、精神污染的肢体化身，无论肉体还是灵质，都被抹除。</p><p>“呕……咳咳……呕哇……！”</p><p>杨帝以“orz”的姿态跪倒在地，声音里充满了生理性的厌恶和嫌弃。味道比蟑螂难吃点。</p><p>他透过那条裂缝，看向马格努斯的庞大意志本体：“你……你肢体平时就喂你吃这种东西？这是何等的不幸。”</p><p>马格努斯的愤怒凝固了。</p><p>它“啵”一声消失。</p><p>“喂我话都还没说完你别跑啊！你跑了我追不到你。”</p><p>杨帝有些懊恼。现阶段的他，对付一个什么无限恐怖之主，尽管只是对方的一根吸管肢体触须，就已经需要将胃囊扩展到极限。</p><p>幸好，对方跑得了初一，跑不了十五。</p><p>杨帝将这座怪谈领域彻底踢爆，飞出了图书馆，看向食堂方向。</p><p>那里，是真正意义上吃饭的地方。</p><p>那里也有马格努斯留下的相似气息。</p><p>江城二中的每一处“怪谈副本”，都是马格努斯的一根肢体，一条触须。</p><p>它正在疯狂收回自己的触须。</p><p>但是……大胃王，要来收人了。</p><p>刺激又紧张的追逐战已经开始。</p><p>……</p><p>图书馆内。</p><p>凌云圣皇等人围在第二个出口前，众人中心处是那把崭新的优质撬棍。</p><p>“我们还不知道盘旋于这处怪谈的‘诡异’有何性质，规则书中有没有假规则，也不知道有无尚未提及的规则……”</p><p>“但可以肯定的是，撬门时发出的动静，绝对会招来不幸。”</p><p>“话说，在柜台那儿找到钥匙了吗？”</p><p>“找到几根万能回形针，也许可以试一下。”</p>
