# 大帝碎片

<p>“网络节点存在非标准协议强行接入残留。物理端口……有非授权神经链接装置接入，型号未知，能量等级……负值，也就是正溢出。”</p><p>一条条冰冷、客观的报告如同重锤，狠狠砸在工作人员的心上。</p><p>技术主管程序员的脸色惨白。</p><p>“龙组？”</p><p>队长捕捉到了这个关键词，幽红的目光再次聚焦在面如死灰的技术主管身上，“这个‘龙组’，是你们的编制单位？隶属哪个部门？”</p><p>“我……我们……”技术主管语无伦次。</p><p>银狐队长不再看他，直接通过内置加密通讯频道连接上级数据库。</p><p>“查询内部编制数据库，关键词：‘龙组’，权限：Omega。”</p><p>短暂的沉默，只有加密频道里传来的细微电子噪音。</p><p>秘密部门的行动都是秘密，档案资料可能都没有他们的代号留存。</p><p>但这位经验丰富的队长知道，只要她查，而且如果对方真的隶属什么“秘密部门”——那么，会有人及时通知她“不要查”、“洗洗睡”。</p><p>几秒钟后，一个清晰、毫无感情的电子音在银狐的听觉处理器中响起：</p><p>“查询结果：未在已知官方及秘密行动机构编制数据库中发现匹配项：‘龙组’。重复：无此单位。请核实信息来源。”</p><p>冰冷的确认如同最终判决。</p><p>最重要的是，这过程中，始终没有一通神通广大的电话打过来，告诉他们“不要再查了哦”、“再查就不礼貌了哦”。</p><p>看来，并非什么秘密部门。</p><p>队长缓缓转过头，那双幽红的、流淌着数据的义眼，如同探照灯般锁定了瘫软在椅子上的技术主管和秃顶码农。</p><p>空气中的压迫感瞬间暴涨，连应急灯的光线都似乎黯淡了几分。</p><p>“没有‘龙组’。”</p><p>她的声音依旧平稳，但每一个字都像淬了冰的钢针，“你们刚才，放了一群使用伪造最高权限标识、窃取机密任务代号、身份不明的危险分子，进入了处于隔离状态的国家级虚拟遗产核心沙盘。”</p><p>她微微前倾身体，完美的脸庞在惨绿灯光下显得有些妖异。</p><p>“现在，”那冰冷的金属摩擦音带着不容置疑的杀伐之气，“告诉我，他们进去做什么？你们打算怎么解释这严重的渎职和……通敌行为？”</p><p>一股比之前得知半人马座摄影师存在时更深的寒意，瞬间从尾椎骨窜上了他的天灵盖。</p><p>完了。他想。</p><p>真的捅破天了。</p><p>假的“龙组”刚带着最高授权闯进去处理“间谍”，真的“攻壳”就带着最高授权堵上门来追查“间谍”……</p><p>而他们这群夹在中间的凡人，刚刚还给假货开了门！</p><p>队长并不理会陷入石化状态的工作人员。</p><p>她只是闲得慌，吓吓他们罢了。真要追责，只会追到她自己头上。</p><p>她上前一步，冰冷的义眼直视着通往核心虚拟沙盘区域的厚重隔离门。</p><p>“解锁。”</p><p>这一次，再无人敢阻拦。技术主管颤抖着手，输入了复杂的解除指令。</p><p>厚重的合金门无声滑开，露出后面闪烁着无数指示灯的庞大主机阵列核心区。</p><p>队长那对深红的义眼瞬间聚焦，穿透昏暗，精准地锁定了前方景象——</p><p>就在核心区的入口处，四个身影静立如渊。</p><p>他们身着黑袍，宽大的兜帽低低压下，将面容彻底隐没在深沉的阴影之中，只留下令人不安的轮廓。</p><p>其中一名黑袍人微微侧首，兜帽下的阴影似乎扫过攻壳机动队。一个低沉、带着奇异摩擦感的声音，用某种无法辨识的音节快速地对身旁同伴低语了几句。</p><p>银狐队长的听觉增强模块，瞬间捕捉到了几个关键音节碎片。</p><p>核心处理器高速运转，进行模式匹配和语义分析。</p><p>分析结果，令她内部的冷却液循环都似乎停滞了一瞬。</p><p>——那破碎的音节组合，指向的正是她连日噩梦的核心意象：颅骨京观。</p><p>……</p><p>“59改，你是说，那个城管头头脑中植入了智能芯片，有一段与归墟大帝波形一致的‘现实特征码’也存在其中，里边还有一些残留记忆，什么‘颅骨京观’之类的。”</p><p>「正是如此。」</p><p>归墟大帝的“碎片”，似乎散落得到处都是。</p><p>也不知道收集足够的碎片，能否拼出一个完整的大帝。</p><p>但至少这些现实的碎片，灵能的残渣，能够提供许多活人和死人都说不出口的情报。</p><p>59改便大手一探，将攻壳机动队第九课的队长握在手心，顷刻黑进芯片。</p><p>「杨帝阁下、白璃女士、阿巴那厮，信号中继建立。请准备接收‘现实特征码’衍生信息。」59改的电子音直接在三人意识中响起。</p><p>他继续充当“网线”，传输信息。</p><p>LINK START！杨帝、青丘白璃和阿巴的视界切换。</p><p>不是虚拟沙盘的残破景象，而是一片充斥着混乱的宇宙战场。</p><p>归墟大帝！</p><p>他伟岸的身影矗立于混沌风暴的中心，不再是杨帝记忆中那深不可测的淡然，而是披挂着破碎战甲。</p><p>周身流着由凝固星光与破碎法则构成的能量洪流，蕴含足以撕裂星河的伟力。</p><p>而他的敌人……</p><p>是扭曲、蠕动、不断解构又重组，形态瞬息万变，如同亿万条由纯粹黑暗与疯狂意志构成的、不断抽搐痉挛的扭曲“面条”。</p><p>时而聚合成吞噬光线的漩涡，时而散开成足以覆盖星系的、散发着不祥呓语的黑色雾霭，核心则永远是无序的、令人作呕的剧烈抽搐。</p><p>“是归墟大帝与域外天魔战斗的珍贵影像！而且是第一人称视角。”青丘白璃震撼。</p><p>这段记忆要放到灵界黑市拍卖，会被各路痴情女修炒到天价。</p><p>锵！锵！锵！</p><p>大帝以无上伟力，打爆域外天魔。</p><p>然后将这些蕴含着恐怖怨念与混乱本质的漆黑颅骨，当作砖石，堆叠起来。</p><p>于是，在那片战场的最前沿，由无数漆黑颅骨堆砌而成的、规模宏大得难以想象的京观，正以令人头皮发麻的速度拔地而起。</p><p>这也是青丘白璃介绍过的，“用天魔筑京观”的现场。</p><p>画面一转。</p><p>刚刚与域外天魔搏杀完，疲惫不堪的归墟大帝回到灵界中心。</p><p>他请了一次带薪假期，然后通过一种奇异的手段，去往凡界。</p><p>“踏破铁鞋无觅处！这块现实碎片上，恰好存在归墟大帝三天前的记忆！”</p><p>青丘白璃化悲愤为动力，她预感到真相离自己很近了。</p><p>归墟大帝来到凡界，先去商业街逛了半天，随后去千篇一律的古镇又逛了半天。</p><p>他在深夜搭上火车，去往十万大山内部，在君士叹顶堡下了车。</p><p>紧接着，一股极度强烈的心理活动涌上心头——</p><p>“我死了，你们也别好过！！！！”</p><p>归墟大帝出现在十万溯光纪念馆外。</p><p>紧接着，画面暂停。</p><p>59改庞大的身躯猛地一震，头发尖上有电弧“噼啪”作响。</p><p>「警告！超高能级攻击！警告……」</p><p>被暂停的画面中，归墟大帝缓缓转过头，看向纪念馆墙外、玻璃幕墙上自己的镜像。</p><p>“你是，何人。”大帝看着杨帝的眼睛。</p>
