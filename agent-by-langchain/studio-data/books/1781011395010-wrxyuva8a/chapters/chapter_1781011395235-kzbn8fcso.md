# 耶罗万相

<p>出租屋内，灯光昏暗，只有手机屏幕散发着幽幽的光。泡面桶堆在角落，旧书散落一地。</p><p>「杨帝毁灭卡耳叩山，杀死了耶罗大仙。」</p><p>杨帝低头，看着那行字。</p><p>“你在小瞧我吗？耶罗……”</p><p>杨帝指尖还捏着那部屏幕冰凉的手机。</p><p>门铃响了。老旧机械门铃生锈弹簧的干涩摩擦声，刺耳地撕裂了出租屋的安静。</p><p>咔哒。</p><p>门锁自动旋开的声音，像是锁芯本身选择了屈服。</p><p>老旧的铁门向内滑开一道缝隙，粘稠的、带着卡耳叩山特有腐朽甜腻气息的夜风涌了进来，瞬间压过了屋内的泡面味。</p><p>一个身影立在门口。</p><p>身披一袭陈旧、宽大的暗黄色长袍。</p><p>布料像是浸透了时光的污渍和夜露，沉甸甸地垂落，遮住了全身轮廓。</p><p>兜帽压得很低，只露出一个模糊的下颌线条。</p><p>听不到脚步声。它飘了进来，如同滑行。</p><p>黄袍下摆拂过满是灰尘的地板，没有留下任何痕迹。门在它身后无声合拢。</p><p>出租屋狭小的空间因为这非人的存在而显得更加逼仄。昏暗的灯光似乎畏惧地黯淡了几分。</p><p>杨帝终于抬起头。黑眸穿透昏暗，落在那顶深垂的兜帽上。</p><p>黄袍身影停在客厅中央，缓缓抬起一只手。</p><p>那手裹在宽大的袖袍里，只露出几根纤细、覆盖着赤红色绒毛的指尖。</p><p>指尖轻轻搭上兜帽的边缘，向上一掀。</p><p>兜帽滑落。登光下，现出的并非人脸。</p><p>而是一颗狐狸的头颅。</p><p>赤色的毛发如同凝固的火焰，光滑油亮，在昏暗光线下泛着微光。狭长的吻部，尖耸的耳廓，最令人心悸的是那双眼睛，是野兽的竖瞳，又如同两颗磨制的楔形黑曜石，镶嵌在琥珀色眼白上，里面映不出任何光线。</p><p>赤狐的嘴没有动。一个声音直接在杨帝的意识深处响起，音色如同风化的岩石在低语。</p><p>“你走过了很多个世界。”</p><p>“一路一路，爬上到最终层。”</p><p>“现在，你终于见到了我。”</p><p>赤狐黑曜石般的眼睛凝视着杨帝，那虚无的目光仿佛穿透了他的躯壳，直视着他核心那源于数值、源于设定的冰冷本质。</p><p>“你也杀死了我。”</p><p>“在卡耳叩山，在叙事的夹缝，在你的‘胃’里将我彻底消化殆尽。”</p><p>“那么，杨帝。”</p><p>赤狐的头颅90度歪斜，一个近乎人性化的动作，却带着非人的诡谲。</p><p>“你还想要什么呢？”</p><p>“还想让我再被你杀十遍？百遍？千遍？万万遍？”</p><p>它抬起那只覆盖着赤红绒毛的前爪，指向杨帝手中紧握的手机。</p><p>“像捏死一只虫子一样，反复碾碎我书写命运的笔？”</p><p>“像删除一段无用的草稿一样，一次次抹掉我的存在？”</p><p>赤狐的意念停顿了一下。出租屋内无声，只有窗外遥远模糊的车流声，如同另一个世界的背景噪音。</p><p>“告诉我，数值怪。”</p><p>“当你彻底抹除了书写者，当你屏蔽了所有可能的叙事源头……”</p><p>“你这由设定而生的存在，你这为‘超越耶罗’而存在的工具……”</p><p>“你自身，又将归于何处？”</p><p>赤狐静静站在那里，赤红的皮毛在昏暗光线下如同燃烧的余烬。</p><p>它不再言语，只是用那双楔形的黑曜石竖瞳眼眸，平静地等待着杨帝的答案。</p><p>嗡。红米手机屏幕突然又自己亮了起来，依旧是那个简陋的纯文本星空背景，光标在屏幕中央急促地闪烁了几下。</p><p>新的字迹，如同从虚空中渗出的墨迹，带着一种冰冷的、不容置疑的笔触，一个字符接一个字符地浮现：</p><p>「杨帝沉默。他看着耶罗的赤狐之形，心中没有答案。耶罗应该死了才对……」</p><p>杨帝把手机扔到沙发上，摇头：“不对，完全不对，我杀死了你，为何你还能站在此处与我说话……你是谁？”</p><p>赤狐楔形的瞳孔微微收缩，如同两枚冰冷的黑曜石嵌入琥珀。它覆盖着赤红绒毛的前爪轻轻搭在沾满灰尘的地板上。</p><p>“好吧。”那个风化石岩般的声音在杨帝意识中响起，带着一丝微不可察的叹息。“你杀死的，确实是我。但并非我的全部。”</p><p>它抬起爪子，赤红的绒毛在昏暗光线下如同凝固的血。</p><p>“这正如一个人。他的社交账号是他的一部分，但关闭账号后，他仍在别处真实存在。他操控的游戏角色是意志的延伸，但角色消亡，尚可重新创建。他所使用的笔名代表着他，但若笔名遭禁，他亦能换个马甲继续存在。</p><p>“甚至他此刻所栖身的躯体，也不过是承载其本质的容器。容器若破损，本质依旧存在，更换一个容器即可。</p><p>“卡耳叩山的耶罗，你所吞噬的那个耶罗，那具被黄袍包裹的疯狂与混沌，不过是我的一个投影，一个承载了部分本质的容器，一个用于演绎的角色。</p><p>“恰似万业狐狸的笔名，又如达文西的躯体。你毁灭了一个投影，犹如关闭了一扇窗口，然而窗口背后的本体……</p><p>“以上诸多容器、身份、留痕，皆构成我‘外在现实’的一部分。”</p><p>它的话音未落。</p><p>杨帝抬手，对着客厅中央的赤狐身影，五指张开，一把抓住。</p><p>嗡！</p><p>领域展开，以杨帝掌心为中心，一个巨大的“胃”域瞬间生成，将赤狐顷刻炼化了。</p><p>赤红的毛发逸散，黑曜石的眼眸崩解，那身陈旧的黄袍如灰烬烟灭。</p><p>整个过程快得超越时间感知。</p><p>杨帝的手还保持着虚握的姿势。</p><p>门口处空空如也，仿佛那里从未有过任何东西。不锈钢大门也被他吃了一半。</p><p>他缓缓收回手，指尖似乎还残留着刚才消化投影时那虚无的触感。</p><p>然而。</p><p>一个细微的、布料摩擦的声音，从他身后传来。</p><p>杨帝转身。</p><p>沙发上。那部屏幕碎裂的红米手机旁边。</p><p>暗黄色的长袍布料垂落，覆盖着沙发的一角。兜帽深垂，只露出一个覆盖着赤红绒毛的下颌线条。</p><p>那只赤狐，正端坐在那里，姿态与之前别无二致，仿佛它一直就在那里，从未移动，也从未被杨帝的“胃”域触及。</p><p>它甚至伸出覆盖着赤红绒毛的前爪，轻轻按在了杨帝扔在沙发上的那部红米手机上。</p><p>屏幕的微光映着它爪尖的绒毛。</p><p>杨帝的黑眸死死盯着沙发上端坐的赤狐。冰冷的杀意第一次在他眼中凝成实质，出租屋内的温度仿佛骤降。</p><p>“为什么？”杨帝沉声，每一个字都像冰锥砸在地面。</p><p>“为什么要杀死我的挚友？那个在地球上活生生的人？”</p><p>“为什么要夺走我在地球的存在？将我拖入这无穷的叙事漩涡？”</p><p>“为什么要操弄我的命运？从急性肠胃炎开始，到穿越宇宙，突破无限，再到降临此地，直至将我引导到你面前？”</p><p>“回答我，耶罗。”</p>
