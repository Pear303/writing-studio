# 大帝陨落于此？

<p>很久很久以前，一个梦中，甘道夫老爷子曾经告诉他：</p><p>「它是一名浑浑噩噩的逝者，你可以称它为‘希夷’。人类的理智会自动过滤它的存在，也就是假装看不见它。」</p><p>老头子在一边说话的同时。</p><p>杨帝心中不断冒出「神秘学+1」。</p><p>也就是说，关于“希夷”的知识，其实和“黑水传送门”、“耶罗大仙召唤仪式”一样。</p><p>都归属同一种超出主观与客观，某种“老天爷随便定”的知识体系——神秘学。</p><p>希夷，用于指代“卡在生死夹缝中”的存在。</p><p>它们的现实丰度仅仅只有0～0.1灵的水平，存在感极度稀薄。</p><p>普通人一眼看过去，会忽略它们。</p><p>那个曾经喊杨帝作“老大”的已故学长，就是因为全部灵能，都被丧心病狂的耶罗信徒给剥离了出来，只留下一缕“灵”的残渣。</p><p>所以他成为了“希夷”形态，只能依附在胡彦卓拍摄的图片中。</p><p>什么是“灵”？灵就是灵能，就是灵气。</p><p>灵气与灵能一般无二，皆是表征“现实丰度”的属性，表示一个事物所蕴含“现实”的多寡。</p><p>一个人经由灵修之路，蜕变成为法师或修仙者后，其体内所蕴含的灵能浓度，便会高于所处环境的灵能。</p><p>此时，我们便称这个人的“现实”相较于周围环境的“现实”更为“高阶”。</p><p>对周围环境而言，这类高灵能浓度之人无疑就是“现实扭曲者”。</p><p>诸如修士、法师、斗宗、超能力者等等，都属于现实扭曲者。</p><p>他们依靠扭曲环境中的现实，来达成自身期望的效果。</p><p>理论上讲，环境灵能越低，与修仙者体内灵能水平的差距便越大。</p><p>如此一来，修仙者操控环境灵能就愈发得心应手，仿若能随心所欲地扭曲现实。</p><p>好比将一位力大无穷的大力士，置身于一群孩童之中。</p><p>大力士凭借远超孩童的力量，能够轻而易举地依照自己的意愿，随意搬动、摆弄周遭一切。</p><p>在这种力量悬殊的鲜明对比之下，孩童们的行动以及环境的改变，几乎完全取决于大力士的心意。</p><p>相反，如果与周遭环境比起来，此人灵能浓度/现实丰度反而更低。</p><p>那么其存在本身，就将变得“不稳固”且“易受支配”。</p><p>它们难以对客观物质世界施加有效的影响，自身的形态、位置甚至存在状态都极易受到环境灵能波动或高现实丰度体意志的干扰。</p><p>就像水中的一滴油墨，其形态会被水流轻易冲散、重塑。</p><p>正如甘道夫所言，人类的理智会本能地“过滤”掉希夷这种极低丰度的存在。</p><p>普通人会下意识地忽略它们，将其视为背景噪音、光影错觉或干脆“视而不见”。</p><p>这是一种被动且普遍的认知防御机制，保护普通心智不被过于“稀薄”且的异常存在所困扰。</p><p>因为普通人对希夷而言，都算是“高阶现实扭曲者”。</p><p>当普通人察觉到希夷的存在，他们会因异常而恐惧。</p><p>而只要心生一丝针对希夷的“惧意”，它们就会被普通人的意志“扭曲现实”，像滚雪球一样逐步发展成目击者内心最深处所害怕的“大恐怖”。</p><p>（类似《深海圆疑》中的大圆球）</p><p>（哇，这是部挺好看的电影，科幻恐怖类）</p><p>杨帝比较特殊，他在梦中克服了对“水池”的恐惧，连带着也不再害怕“希夷”。</p><p>并且还把对方硬生生“喂”出灵智。</p><p>这也就是为什么那些鬼魂时强时弱，因为许多人恐惧它们，但也有大佬对它们不屑一顾。不同的认知，会将鬼魂一类的存在，扭曲成他们所恐惧或所轻蔑的形态。</p><p>总而言之，想要变成希夷形态，需要变成碎片，变成一块仅剩余极少量“现实丰度”的碎片。</p><p>杨帝的目光变得无比锐利，穿透了虚拟世界的苍穹，仿佛看到了那隐藏在无尽时空之外的真相：</p><p>“归墟大帝……他到底遭遇了什么？”</p><p>“是重伤濒死，力量失控逸散，被魔崽子们窃取了这部分‘现实残片’？”</p><p>“归墟大帝，陨落在虚拟沙盘中？？”</p><p>“还是……为了某个我们无法想象的、极端到疯狂的目的，所以他主动割肉饲魔，把力量交给这些执行灭世计划的数字生命？！”</p><p>无论是哪一种可能，都指向一个令人毛骨悚然的结论：归墟大帝的状态，绝对出了问题！而且是大问题！</p><p>这剥离的“现实残片”，这回荡的“特征码”，就是铁证。</p><p>它是大帝流淌滴落的脓血。</p><p>但谁也不知道他到底遭遇了什么，才会留下这滩血迹，不知是自杀还是他杀。</p><p>“哇呀老大！！那个‘黑色烟花’看起来要爆了啊！”阿巴没心没肺地大叫起来，扯着杨帝衣服喊道。</p><p>“黑色烟花？”</p><p>杨帝的目光最终落回那不断散发着不祥气息的紫黑祭坛核心。</p><p>边缘流淌着令人不安的紫黑色污秽数据流，如同溃烂的伤口边缘渗出的脓血。</p><p>中间那缸黑色的东西，就是“阴伏流煞”。</p><p>一段受污染的数据。</p><p>这但是能直接影响现实世界。</p><p>59改很快分析出这些污染数据的性质。</p><p>「在凡界，任何程序无论其表象如何复杂绚丽，其本质皆为一系列逻辑指令0与1的集合。」</p><p>「这些指令经由处理器译码、执行，驱动硬件电路产生特定的电流变化与电磁场波动。」</p><p>「譬如，让一个灯泡亮起来。程序告诉硬件开灯。电流便流过灯丝，产生光热。」</p><p>「这个过程，对现实世界的影响微乎其微，不过是几个电子开关的开合，逻辑门电平的翻转，最终结果就是——灯亮了」</p><p>「但‘阴伏流煞’不一样。它被设计出来，不是为了点亮一盏灯，或者显示一张图片。」</p><p>「它是一段极度扭曲、高度特化的恶意指令集。」</p><p>「利用硬件运行时的物理过程本身，作为撬动现实世界根基的杠杆。」</p><p>阿巴很难以置信。</p><p>她印象中，“磨灭大道”需要大力出奇迹。</p><p>而现在的阴伏流煞，却可以“磨大道如烹小鲜”。</p><p>“仅仅是极度细微、特定的电流变化与电磁场波动，居然能够引发‘崩坏’？！”</p><p>「是的。‘阴伏流煞’会控制硬件，在微观层面短暂、局部地‘模拟’出域外天魔所代表的‘终极混乱’的物理法则。」</p><p>「当特定硬件执行该段恶意代码时，其内部电子运动、量子态、乃至基本粒子间相互作用力场，将被强行诱导至一个高度不稳定的、趋向于‘混沌熵增最大化’的临界状态。」</p><p>「此状态与‘域外天魔’存在的底层物理表征具有高度同构性。」</p><p>「如果直接毁灭承载它的硬件，也会导致相同效果，目前原理未知。」</p><p>「完全破解‘阴伏流煞’之原理，预计用时：仅虚40000年。」</p><p>阴伏流煞，就是真正意义上的工程学奇迹。</p><p>仅仅撬动1焦耳不到的能量，轻触杠杆。</p><p>这个微型杠杆，就能撬动更多杠杆。</p><p>更多杠杆，发生不可控的连锁反应。</p><p>最终，现实崩坏，天魔降临。</p><p>“不管他图啥……这‘黑色烟花’，放的太不是地方了。”</p><p>“先把这‘炮仗引信’掐了。”杨帝的语气平淡得像是在说捏死一只蚂蚁，当然事实也差不多。</p>
