# 物理驱魔，但似乎驱不干净

<p>机甲巨臂抬起，猩红光束无声射出，瞬间洞穿地层直贯地心。</p><p>光束过处，岩层汽化。下一秒，整个行星猛地向内坍缩，随即难以想象的光芒从无数裂缝中迸发而出——地核被点燃了。</p><p>狂暴的中微子流撕碎地幔，撑裂地壳，直达地心。</p><p>高能中微子与地核中高温高压熔融物质的相互作用，将其巨大动能瞬间转化为热能，在有限区域内沉积远超临界点的能量。</p><p>该能量注入精确破坏了地核原有的流体静力学平衡，瞬间极大地提升了局部区域的温度和压力。</p><p>这直接触发了一场失控的核裂变链式反应，反应以指数级速度蔓延至整个地核。</p><p>地核在极短时间内释放出相当于恒星内部级别的巨大能量。这股能量远超行星引力结合能。</p><p>巨大的向外压力直接导致地壳被整体崩碎。</p><p>剧烈的爆炸随之发生，行星在无声的剧烈膨胀中化为齑粉。</p><p>只留下一团急剧膨胀，炽热的行星碎屑云，映照出“挖掘机”冰冷的轮廓。</p><p>「真是一次出色的驱魔仪式。」太一矩枢虽然也是一具人形机甲的模样，但也像碳基生物那般鼓了鼓掌。</p><p>……</p><p>「杨考察员，你怎么看？」</p><p>“我问一下，如果无法完成宇宙基底转型，后果很严重么？对此宇宙而言。”</p><p>「对‘大魙败’的抵抗性会大量削弱，你想，终于守卫一个宇宙最基本的高端力量都没有。」</p><p>“将‘宇宙基底’改造，是为了预防大魙败，是吧？”</p><p>「是的，正是这项政策的根本宗旨……」</p><p>真是奇异搞笑。杨帝闭眼回忆。</p><p>【高唯心主义、低逻辑自洽性、以及包含大量不可证伪或不可名状元素的宇宙……】</p><p>【……其现实结构的鲁棒性显著低于平均值。】</p><p>杨帝能理解星环盟约的决策。</p><p>将宇宙基底从灵异调整为高武，核心目的在于提升宇宙结构的“鲁棒性”。</p><p>一边思考着，杨帝又骂了一遍这词的翻译。</p><p>高武世界的规则通常更稳定、更依赖物理性的力量体系和明确的能力等级，这使其对“大魙败”引发的现实崩溃——尤其是那些源自概念扭曲和认知污染的“域外天魔”，具有更强的抵抗性。</p><p>一力破万法，只要有足够的武力，万物皆可打爆。</p><p>更重要的是，长期观测数据表明，这类逻辑相对自洽、唯心程度较低的宇宙，似乎不易吸引“大魙败”的初始关注。</p><p>或者说，不那么容易成为其爆发的“温床”。</p><p>这并非什么美学选择，而是一项基于冰冷统计数据的生存策略。简单粗暴，但有效。</p><p>“大魙败的本质是什么？”</p><p>「不明。星环盟约主流学说认为，也许是无限虚空本身对世界的偏好筛选。」</p><p>大魙败并不是一个主体，它没有智慧，没有思想。</p><p>它是一个现象，它只是在筛选。不合它“心意”的宇宙群，现实丰度会剧烈归零，并诞生出大量域外天魔，直至将整个世界摧毁殆尽。</p><p>就像……</p><p>就像“主神”达文西死时，他手机中的「主神空间」的剧烈崩溃。</p><p>杨帝抬起头：“我认为这个宇宙的圣人，对此世界基底改造，效果……”</p><p>还没说完，一颗罗盘大小的螺丝飞来，削去了太一矩枢·无限基础设施建设兵团的脑袋。</p><p>他从后备箱里拿出个新脑袋，给自己安上，然后和杨帝一块看向大螺丝飞来的地方——</p><p>格索尔七号行星。</p><p>螺丝的来源，正是那辆铲除凶宅的挖掘机。</p><p>它被拆了。</p><p>那座庞大的人形机甲挖掘机，此刻正被无形的力量暴力拆解。</p><p>它的装甲板像被撕碎的纸片般剥落，粗壮的机械臂被拧成麻花状，内部的管线与零件如同被掏出的内脏，散落在虚空中。</p><p>那颗以0.9999999999999999992c的超相对论速度飞来的巨型螺丝，就来自这个被拆解的挖掘机。</p><p>与此同时，在不远处，格索尔七号行星唯一的一颗卫星表面，一团难以名状的巨大阴影正在急速蔓延。</p><p>阴影之中，骤然涌出无数纠缠蠕动的、尺度达到天文级别的黑色发丝，它们如同活物般刺破虚空。</p><p>一声无法用物理介质传递、却直接刺入意识最深处的尖啸猛地炸开，冲击着杨帝的感知。</p><p>紧接着，下方那颗早已死寂的行星表面，开始渗出暗红色的浓稠液体，仿佛整个星球都在流血。</p><p>这些血流汇聚、扭曲，最终在星球表面形成了一只巨大无比、充满恶意的眼睛，正直勾勾地凝视着他们。</p><p>深空中的星辰开始扭曲、溶解，如同墨滴落入血池。冰冷的光点渗出粘稠的暗红，一道道血泪般的轨迹划过漆黑的天幕。</p><p>整片虚空仿佛都在无声地哭泣、怨恨、哀恸，化作一片浸透绝望的血色牢笼。</p><p>「咒怨随着死于强大愤怒的人诞生，在死者逝去之处集结成为因果报应，触碰诅咒的人会丧命，新的诅咒则随之诞生。」</p><p>太一矩枢刚换完脑袋，适配好扬声器，就开始科普。</p>
