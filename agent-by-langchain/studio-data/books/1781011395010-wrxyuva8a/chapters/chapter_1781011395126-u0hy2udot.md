# 谈判主导权

<p>杨帝：“我要证据。证明杀了你，不会导致整个宇宙陪葬。”</p><p>原初之眼，原本是宇宙自身的底层规律。</p><p>祂只是很不幸，被点燃了自我意识。</p><p>如果将宇宙底层规律抽走……有可能会像抽去积木最底层一块，导致整座大厦轰然倒塌。</p><p>原初之眼露出人性化的冷笑。</p><p>「你认为你占据了谈判主导权，是这样吗，杨帝？」</p><p>“……难道不是？原目，你还有什么筹码？事到如今，难道不是你在单方面请求我？”</p><p>「杨帝，你应该知道，神交是双向的。当你与我精神交流、获得大量信息时，我也读取了你所知的诸多情报。」</p><p>「在你们世界，有一部奇幻儿童文学，里边有一个伟大的老师。」</p><p>「他教会他的学生使用‘大脑封闭术’。」</p><p>「很可惜，你还没遇到那样的老师——因为我的教学方法很粗暴。」</p><p>杨帝虎躯一震。他自然知道是哪部儿童奇幻文学，出现了“大脑封闭术”这个词语。</p><p>霍格沃兹学院里的“大脑封闭术”，乃是抵御异物元神入侵的无上秘术，修习者需从对抗中升级，磨炼紫府，镇守元神。</p><p>话说那灭世魔尊伏地魔，本是魔道魁首，天生魔体，自诞生便引得天地色变，魔气汇聚成滚滚黑潮，所过之处，万物凋零、生机尽断。</p><p>他修的是至邪至恶的“魂分七道”魔功，将元神撕裂成七份，藏于世间各处奇珍异宝、生灵躯体之中，以求不灭不朽，即便肉身湮灭，也能借分魂重聚，堪称不死不灭的魔神。</p><p>他麾下魔党万千，势力盛极一时。</p><p>“大脑封闭术”，正是哈利波特为对抗这尊魔道大能而修炼。</p><p>而杨帝此刻，尚未参透这等玄妙法门。</p><p>在原初之眼这等掌握宇宙本源的存在面前，杨帝虽精神力浩瀚至极。</p><p>但他的思维就如未设防的万里疆土，任其肆意驰骋。</p><p>“原初之眼，你知道的，就算我无法封闭自己的意识，你也不可能洗脑我。任何稍微强烈的模因效果，统统对我无用——你控制不了我的行为。”杨帝冷静地说。</p><p>「我明白。」</p><p>「杨帝，我只是告诉你，即使你占据谈判主动权，许多事情都并非由你决定。」</p><p>「我会用我全部‘现实’去夺舍你，拼劲一切作抵抗吧。」</p><p>话音未落，杨帝意识空间中的眼珠子形象，竟实质化地凝聚起来！</p><p>那只眼睛，幽邃瞳孔，宇宙对自身的观察，如远古凶兽的獠牙般洞穿虚空！</p><p>杨帝瞳孔骤缩，意识深处轰然炸响惊雷。</p><p>无数记忆碎片如钢针刺入他的精神。</p><p>他感觉不到有多大伤害，但他看到了原初之眼的记忆。</p><p>长达亿兆京垓年岁月的记忆。</p><p>他看见宇宙诞生之初的蛮荒，无数文明崛起又覆灭。他看见熵海翻涌，恒星如萤火熄灭，黑洞贪婪吞噬着万事万物。硅基生命在液态金属海洋中搭建逻辑网络，碳基强者切开中子星与夸克星作为棋子对弈。他看见意识体在量子泡沫里诞生又消散，它们的思想如昙花一现……</p><p>杨帝的进化适应，是被动技能。</p><p>原初之眼根本无需征得他同意。</p><p>祂一开始就用全部“灵”，冲杀进杨帝体内即可。</p><p>祂将自己当做个大号的“发卡”。</p><p>强迫杨帝将祂“吃下”。</p><p>当然，量变可能会引起质变。原初之眼自己也并不确定，祂究竟是会被杨帝“适应”，然后被“消化”掉……</p><p>——还是会超出杨帝能力极限，导致这个人类的主观意志彻底崩解？</p><p>「无所谓的，杨帝。」</p><p>「如果你成功消化我，那么我也成功自杀，而且，还有机会让‘耶罗大仙’被你找上门。」</p><p>「如果你失败，我会继续将整个宇宙的熵值推到极限，毁灭这个世界，让自己去死。」</p><p>「所以，抵抗吧，进化吧，为了自己，为了全宇宙的生命，为了向耶罗大仙复仇。」</p><p>杨帝扭动眼球，感知四周。</p><p>此时此地，已极度接近宇宙原点。</p><p>在这个地方，宇宙本身尚未容许时间和空间存在，维度结构也尚未成型。</p><p>原初之眼的暗物质结构不被允许存在。</p><p>然而，杨帝的无限机兵物质躯体却能继续存在着，没有被大道所磨灭。</p><p>他们同时保留着各自的“灵”。但是，杨帝阻止不了原初之眼的“灵”侵入自己。</p><p>同时，祂的现实，携带了不知多少兆亿年的记忆。</p><p>多少个千古的历史，多少个万载的岁月！</p><p>光是这段记忆的零头，就超过了宇宙中最古老的文明，最亘古的种族。</p><p>祂同时存在于全部时空，祂的“现实丰度”又是个何等恐怖的数值！</p><p>光是原初之眼倾泻出的一丝灵能，就能制造出数以恒河沙数计的十五环神级法师。</p><p>杨帝感受许久未涨的精神，再度如超新星爆发般膨胀起来。</p><p>意识掀起前所未有的惊涛骇浪，无数个世界线的碎片在精神中炸开，灵魂仿佛被强行拆解重组。</p><p>原初之眼的记忆如沸腾的钢水，似乎要将他过往的认知彻底浇铸重塑。</p><p>——不，他的认知坚如磐石。</p><p>在这股裹挟着宇宙终极真理的记忆洪流中，杨帝并没有被原初之眼无穷的孤寂完全感染。</p><p>他拥有了兆亿年岁月的记忆。</p><p>却没有因此步入孤寂的痛苦。</p><p>他的神经突触……不，而是某种更形而上的“精神链接”，以超越物理和灵能法则的速度疯狂增殖，每纳秒都有数以亿计的新连接生成，又断裂，又生成。</p><p>「精神+1+1+1+1……」</p><p>他免疫了原初之眼的恶意模因感染。</p><p>就如最终设想的那样，原初之眼无法洗脑他的人格。</p><p>但这并不代表杨帝可以拒收祂的记忆。</p><p>祂说得对……自己刚刚达到100%意识圆满的境界，并未开发出更高深的“大脑封闭术”。</p><p>他的精神，意识，坚不可摧，摧则更坚。</p><p>但就是无法阻止外界之物侵入。</p><p>尽管“侵入”对他造成的精神伤害、对他导致的人格扭曲都在时间被超量代偿，恢复原状，甚至超越原有。</p><p>可与此同时，他也能感觉到——</p><p>自己正在“消化”原初之眼的“灵”。只是，并非出自他本人同意地消化。</p><p>「现实+1+1+2+3+5……」</p><p>杨帝的现实丰度数值——即“灵能”，开始疯狂跳动。</p><p>不再是稳定的线性递增，而是呈现出指数级的爆炸式增长。</p><p>原初之眼拥有主观意志，但独属于祂的“主体性”正在被杨帝强行适应进化，并“消化”成自己的养料。</p><p>他自己却无法阻止这一过程。</p><p>绝对的适应进化，这是个被动技能——原初之眼对他能力的了解如此透彻。</p><p>杨帝停止了物理层面的挣扎。</p><p>他只能将所有精力，用于构建“大脑封闭”。</p><p>即使最终目的，还是要杀死原初之眼。</p><p>但至少现在，他得让自己有“拒绝杀祂”的权利，才能获得更多谈判的筹码。</p><p>「杨帝……我的心智正在粉碎，情感走向陨灭，意志步入空寂……」</p><p>原初之眼的声音再度响起。</p><p>从一开始，杨帝就阻止不了祂在自己的意识中投下投影。</p><p>只是这道投影，对他造成不了更多致命伤害罢了。</p><p>「而作为报酬，我也会告诉你关于无限机兵、话本编撰者的情报。」</p><p>“……”杨帝迅速分割出49.9%的注意力聆听。</p>
