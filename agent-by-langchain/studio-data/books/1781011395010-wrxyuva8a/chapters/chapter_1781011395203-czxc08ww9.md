# 为美好群星献上祝福

<p>宇宙间最冰冷的现实——权力厌恶真空。</p><p>物竞天择是常态，与其让恶者登顶，不如由心怀善念者执掌权柄，庇护弱小。</p><p>然而，杨帝听着她慷慨激昂的陈述，那亘古磐石般的脸上，非但没有动摇，反而浮现出一种更深沉，洞悉了无尽轮回的疲惫。</p><p>“填补真空，庇护众生……”</p><p>杨帝声音低沉，却像一把冰冷的凿子，敲打在阿巴的天灵盖上。</p><p>“归墟大帝也曾如你一般，视凡界生灵如亲子，不容外力侵扰分毫。</p><p>“他以无上伟力守护凡界几十万载，于是凡界在他的羽翼下安然繁衍。</p><p>“结果，他最后还是亲手释放了阴伏流煞。”</p><p>阿巴的圣道领域剧烈波动，文明虚影明灭不定。</p><p>她的信念受到了冲击，但这种程度还不足以动摇她的决心。</p><p>“无论是守护者还是创造者，当他们登临那个可以裁定命运的位置，当他们拥有了‘定义好坏’、‘决定存亡’的绝对权力。</p><p>“无论其初心如何崇高，最终都会让守护会变成囚笼，创造孕育毁灭，用善意铺就通往地狱的道路。</p><p>“而你，阿巴，一旦坐稳这圣位，以‘永续’之名行‘裁定’之实，你终将成为下一个‘归墟大帝’。</p><p>“相信我，你会成为下一个为了业务需求，而格式化整个灵界的仙界程序员。</p><p>“你会成为第二个原初之眼、归墟大帝、四大邪神，以及……第二个祂。”</p><p>轰隆隆！</p><p>阿巴心中充满了巨大的痛苦。</p><p>她构筑的“蓝星永续之壁”领域发出不堪重负的哀鸣，无数文明虚影，如同被投入熔炉的蜡像般扭曲融化。</p><p>然而当她再度抬头，眼神已如万载玄冰。</p><p>“杨帝，你只懂得破坏，却不明白建设。你杀死了玩弄众生命运的恶意，但你无法遏制这种‘恶意’的二次出现。</p><p>“而且，你又要怎么确定，你现在所信奉的‘命运只能由我们自己选’，就不是在将自己的意志强加于万物众生？</p><p>“若你给不出更好的方案，若你给不出更好的解释，若你只懂得否定而不懂得肯定，那就与我战！”</p><p>大道之争！</p><p>万古鱼尊早已不是天真的鱼。</p><p>此战无关私怨，只为至高理念。</p><p>是庇护众生永恒，还是放任万类于命运的漩涡中自决？</p><p>杨帝看着阿巴眼中那万载玄冰般的战意，那亘古磐石般的脸上，终于不再是纯粹的平静或悲悯，而是升起一股——</p><p>纯粹的、仿佛能点燃混沌的兴奋！</p><p>那是棋逢对手，道遇强敌的昂扬！</p><p>“好！”</p><p>一声断喝，如同开天斧劈开鸿蒙！</p><p>杨帝向前踏出一步，右拳收于腰际，递出！</p><p>朴实无华到了极致。</p><p>阿巴也动了。整个“蓝星永续之壁”领域轰然收缩，凝聚于身躯，带着“我欲存故我在”的不灭信念，悍然撞向那粉碎一切的拳锋！</p><p>轰——！！！！！！</p><p>碰撞。</p><p>无法用言语形容的碰撞！</p><p>以碰撞点为中心，整个亚空间，这片由无尽混沌灵能、扭曲法则、圣人意志交织而成的庞大领域，如同被重锤击中的超巨型玻璃穹顶——</p><p>瞬间布满了亿万道纵横交错、贯穿上下四方、过去未来的恐怖裂痕！</p><p>那些低语着的扭曲呢喃，那些翻腾的混沌狂潮，那些凝固如简并态物质的灵能辉光……</p><p>在这两种极致力量碰撞，超越维度界限的冲击波面前，如同被投入工业熔炉的冰雪，瞬间蒸发粉碎，化为最原始的灵能碎片！</p><p>布满裂痕的亚空间，再也承受不住这终极碰撞的余波，爆炸。</p><p>彻底地轰然地炸了！</p><p>如同宇宙大爆炸的奇点重启！</p><p>破碎的亚空间碎片，在两种极致力量碰撞残留的法则余烬催化下，并未归于虚无，而是被一种全新的有序物理规则强行“焊接”、“重塑”。</p><p>亿万道纵横交错的巨大裂痕，在宇宙法则的自我修复与重构下，被拉伸，拓宽和稳固。</p><p>它们不再是空间的伤疤，而是变成了……</p><p>——联通群星的超空间航道网络。</p><p>曾经翻腾的混沌灵能，被强行转化为稳定的曲率驱动能量流，在航道中无声奔涌。</p><p>无数亚空间碎片，被重塑成航道中稳定的质量阴影，和显眼的导航信标。</p><p>充满绝望混沌，不可名状恐怖的亚空间……消失了！</p><p>取而代之的，是一个遵循严格物理定律的超空间航行网络。</p><p>一个适合科技文明探索，殖民，贸易和交流的宇宙格局。</p><p>杨帝的拳和阿巴的圣道之光，在引发这场惊天剧变的瞬间，也同时湮灭于无形。</p><p>阿巴小小的鱼躯如同被彻底抽空了所有力量，圣道光辉彻底熄灭，气息萎靡到了极点。</p><p>她如同风中残烛，从破碎的虚空向下方新生的超空间航道坠落。</p><p>她圣位根基被杨帝那一拳的余韵彻底击碎，本源遭受重创，境界跌落谷底，现在只能单挑20个准圣。</p><p>杨帝身影，在重构的能量风暴中显现。</p><p>他低头看了看自己的拳头，又看了看下方那冰冷而贯穿星海的超空间航道网络。</p><p>他那一拳，本意是粉碎阿巴的圣人果位。</p><p>却无意间打碎了旧宇宙的枷锁，凿开了一个全新的纪元。</p><p>他一步迈出，出现在下坠的阿巴身边，伸手轻轻托住了她冰冷的小鱼身。</p><p>阿巴的鱼眼勉强睁开一条缝，看着杨帝。</p><p>又看了看下方那闪烁着幽蓝光芒，如同宇宙血管般延伸向无尽深空的超空间航道。</p><p>万古鱼尊气若游丝，却带着一丝奇异的释然：</p><p>“……老大……你看……没有邪神低语了……亚空间的混沌生物，也没了……凡人的飞船……可以安全航行……”</p><p>杨帝沉默着，感受着阿巴体内那几乎熄灭的生命之火，和破碎的圣道根基。</p><p>“代价太大了。”他低声道。</p><p>“呵……”</p><p>阿巴极其微弱地嗤笑了一声，“……总好过……变成……格式化世界的……程序员吧……去……群星间……写自己的……命运……老大……这结局……还算不坏……我……想吃鳕鱼堡……”</p><p>她的声音越来越低，最终彻底沉寂。</p><p>杨帝托着阿巴，悬浮在新生的超空间航道之上。</p><p>下方，一艘流线型的、闪烁着金属冷光的星际科考船，正带着难以置信的惊喜，缓缓驶入这条刚刚诞生的超空间航道。</p><p>引擎喷射出稳定的蓝色尾焰，航向远方璀璨的星海。</p><p>战锤的绝望纪元，在两位圣人级别的理念碰撞中，被一拳终结。</p><p>属于凡人的，充满未知与可能的群星时代，在破碎的亚空间废墟上，悄然拉开序幕。</p><p>为美好群星献上祝福吧。</p>
