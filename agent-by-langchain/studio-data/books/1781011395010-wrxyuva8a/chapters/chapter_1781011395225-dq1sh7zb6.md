# 圣人的伤害……也不太够了

<p>七位准圣脸上的自信与冷酷瞬间凝固，取而代之的是无法置信的惊骇，与源自灵魂深处的恐惧！</p><p>“不可能！！”</p><p>“吾等杀招，蕴含无限宇宙伟力，为何……”</p><p>“他……他连动都没动？！”</p><p>杨帝的目光缓缓扫过七位将他包围的准圣，那眼神平淡无波，却让七位屹立于宇宙顶点的存在感到一种被更高维存在俯视蝼蚁般的寒意。</p><p>“你们的攻击……蕴含的能量，确实是‘无限’。”</p><p>“但在我面前，你们的‘无限’，只是‘有限’。”</p><p>“就像零和一，一和无穷的差距。”</p><p>这轻飘飘的三句话，如同宇宙终极法则的宣判，瞬间击溃了七位准圣的道心！</p><p>他们能清晰地感知到，自己的攻击所蕴含的能量层级——那是真正意义上的无穷无尽，足以支撑一个宇宙的生灭。</p><p>然而，在这个人面前，他们的无限，被轻描淡写地定义为了有限？</p><p>并不是“定义”，而是“相当于”。</p><p>有穷和无穷是对比出来的。</p><p>连续连续统定理阿列夫零和阿列夫一中，还相隔着无穷多个隐式的“中间态无穷”。</p><p>而构成这个中间态无穷的数量和大小，同样是中间态无穷。</p><p>虽然连续统问题在文明的原始时期，就往往能够被提出来。</p><p>但绝大多数，直到成为宇宙级别的超弦时代文明，才将这个问题完满解决。</p><p>而此刻，杨帝与其他准圣之间……</p><p>已经不是力量的差距，这是位格的根本不同。</p><p>是无限与更大无限之间，那令人绝望的无法逾越的鸿沟。</p><p>杨帝目光扫过七位准圣。</p><p>“耶罗大仙？”他问。</p><p>声音平淡，却像重锤敲在凝固的空气中。七位准圣或惊疑，或茫然，无人能答。</p><p>他们甚至无法理解这个名字蕴含的意义，如同朝菌不知晦朔，夏虫不可语冰。</p><p>杨帝不再看他们。</p><p>这些所谓的宇宙顶点，对他无法构成一丝一毫伤害，在他眼中已失去意义。</p><p>一步踏出，一步落下。</p><p>景象飞速坍缩变幻，星系生灭如泡沫，文明兴衰似烟火。</p><p>无穷的世界线在他脚下收束、凝固，最终指向一个绝对的终点。</p><p>他身形消融，顷刻间来到宇宙尽头，历史之终点。</p><p>这里并不是绝对的虚无，而是所有奔腾咆哮的世界之河最终将会汇入的，近乎停滞的浩瀚死海。</p><p>无数璀璨或黯淡的世界线在此刻收束凝固，如同亿万条发光的丝线，在“有意义时间”的终点处，打成了一个庞大到无法观测全貌的结。</p><p>这个“结”，便是已知宇宙所有故事、所有因果、所有挣扎与辉煌的最终墓碑。</p><p>而在“结”之后，时间仍在流淌。</p><p>但那已不再是奔涌的河流，而是一条单调灰暗，已经失去所有可能性的涓涓细流。</p><p>一条再无分岔，再无波澜，再无任何新故事诞生，一切意义归零的单行道。</p><p>这便是“无意义时间”，宇宙在耗尽所有可能性后的漫长弥留。</p><p>宇宙的时间，也是无穷。</p><p>只不过其中有意义的部分，大约只有不到42亿亿年。</p><p>杨帝的身影，便悬停在这“结”与“无意义时间”的交界处。</p><p>他站在了万古的尽头。</p><p>前方，一道身影坐于时间长河尽头，位于历史有意义与无意义的分界处，背对一切。</p><p>他身下是凝固成永恒墓碑的宇宙泡影，前方是翻滚咆哮的光锥之外的无尽黑暗。</p><p>他是守墓人，是镇守者，独断万古的圣人。</p><p>圣人没有回头。一个意念跨越凝固的时空，冰冷坚硬，带着不容置疑的终结意味。</p><p>“退回去。”意念如同宇宙法则本身，“此乃终末之壁。汝若执意踏入光锥之外，引动黑暗不详，吾便镇杀汝。”</p><p>杨帝看着那道背影，看着那隔绝已知与未知的叹息之壁。</p><p>他没有回答，只是抬脚，向着光锥之外的黑暗，踏出一步。</p><p>这一步，是回答。</p><p>嗡！圣人端坐的身影微微一震。</p><p>无法形容的攻击瞬间生成，“终结”概念本身具象化成绝杀一击。</p><p>它无视时间空间，从所有可能的历史线、所有存在的维度同时爆发，汇聚于一点——杨帝的头颅。</p><p>这是机制杀！</p><p>砰。杨帝的头颅，连同内部刚刚稳固的阿列夫零级防御，如同脆弱的琉璃般轰然炸碎。</p><p>无头的躯体依旧保持着前踏的姿势，立在万古尽头与黑暗世外的交界处。</p><p>圣人端坐不动。</p><p>这一击蕴含了他镇守万古的力量，抹杀过试图窥探黑暗的不朽存在。</p><p>他确信，这个气息诡异的存在，已经终结。</p><p>然而，下一瞬。</p><p>那无头的颈项断口处，血肉骨骼以超越逻辑的速度疯狂滋生、重构。</p><p>星辉在伤口边缘流淌，灵能被强行纳入新生的结构。不到一息，一颗完整的头颅重新出现。</p><p>还是那张脸，黑发黑眸，眼神却更加幽深，仿佛刚刚吞噬了一片星海。</p><p>圣人那万古不变的心境，第一次泛起一丝真正的涟漪。</p><p>他的意念泛上凝重：“汝……”</p><p>杨帝活动了一下新生的脖颈，发出轻微的骨骼摩擦声。他看向圣人，眼神平静无波。</p><p>“数值只要足够，也是能撑爆‘机制杀’的。现在，你的攻击对我无效了。”</p><p>刚才那一击蕴含的终结伟力，其能量层级与攻击模式，已被他身体本能地解析、适应、超越，固化进无穷防御的体系。</p><p>阿列夫零到阿列夫一之间“中间态无穷”的防御，曾经在那一击下破碎。</p><p>但破碎的瞬间，他的“点数”再次跃迁，防御层级已进入一个更高阶的无穷领域。</p><p>“厉害。”话音落下的刹那，圣人抬手。</p><p>指尖凝聚起一道无法用语言描述的锋芒。</p><p>似是从“无意义时间”的单调本质中剥离出的“绝对切割”概念，是存在与不存在的界限本身，是能斩断一切因果、劈开所有法则的终极之刃。</p><p>整个终末之地的时间流速都出现了刹那的紊乱。它跨越了光锥内外的阻隔，以一种必然命中的姿态，直斩杨帝的天灵盖！</p><p>杨帝额头光滑，隐约有地中海之势，似是弱点。</p><p>这是圣人镇守万古以来，真正意义上的最强杀招，是足以让整个“有意义时间”的宇宙结都为之震颤的一击。</p><p>然而，就在刀锋即将触及杨帝头颅的瞬间，一根黑色的发丝，从他发间悄然垂下。</p><p>发丝纤细如尘，看似脆弱得能被微风拂断，却在与那终极之刃接触的刹那，爆发出一种凌驾于所有概念之上的稳定。</p><p>那道能斩断一切的锋芒，就那样被一根普普通通的黑发，死死挡在了半空，寸进不得。</p><p>圣人收手，沉默。</p><p>一根头发，挡住他最强杀招。</p><p>他能感觉到，自身力量本质已被对方彻底免疫。</p><p>再攻击，不过是重复无效的过程。</p><p>杨帝的目光越过圣人僵硬的背影，投向光锥之外那片孕育着一切可能，也孕育着终极黑暗的翻腾之混沌。</p><p>耶罗大仙的气息，仿佛就藏在那片未知的黑暗之后。</p><p>他不再看圣人，迈开脚步，坚定地踏向光锥之外那片连圣人都只敢坐镇，而不敢踏入涉足的无尽黑暗。</p>
