# 这地方不对

<p>胡彦卓伸手搭在消防门上，金属门把手上的铁锈簌簌剥落。</p><p>他屈肘轻推，门扇仿佛被水泥浇筑般纹丝不动，门缝里渗出陈年积灰。</p><p>杨帝皱了皱眉，正要出手把门砸开。</p><p>却见胡彦卓后撤半步，脊椎如弹簧压缩到极致，抬脚一个飞天大踹猛地踹在门板中央！！</p><p>“哐——啷！！”</p><p>哐当巨响震落头顶墙灰，消防门豁然洞开。</p><p>二人一猫走出沉闷的楼梯间。</p><p>手电筒光束首先扫过消防门后的墙壁，青苔在墙面上蔓延出斑驳的水痕，霉味像湿抹布般贴在鼻腔里。</p><p>“叽叽嘎嘎——”</p><p>消防门在他们身后自动闭合，铰链发出垂死病人般的呻吟。</p><p>胡彦卓踹门时带起的灰尘还未散尽，手电光束产生丁达尔效应。</p><p>狸花猫伸手挥了挥面前悬浮的尘埃，光柱中的细小颗粒，如同金色星屑缓缓飘落。</p><p>“咳咳。”</p><p>胡彦卓轻咳两声，抬手掩住口鼻，眉头紧蹙，“这地方，真是有够荒废的。”</p><p>杨帝的手电筒扫过墙面。瞳孔震动起来。</p><p>“不，不对……这里不是我们刚才的3楼。”</p><p>他们面前是条三米宽的通道，两侧排列着粗壮的水泥承重柱。</p><p>通道穹顶低垂，混凝土浇筑的天花板被密集的污水管道盘踞。</p><p>管道直径从碗口到手臂粗细不等，表面凝结着暗绿色的水锈。</p><p>管道与管道之间，用生满铜绿的螺丝勉强固定，有些地方甚至可见裸露的钢筋骨架。</p><p>杨帝继续说：“你还记得3楼出了楼梯，走廊应该是左右延伸的对吧。但现在，过道是正对着门口延伸出去……”</p><p>胡彦卓闻言，神色一凛，迅速将手电筒的光束在周围扫视一圈，确认着杨帝的话。</p><p>确实，这和他们之前所在的楼层布局大相径庭。</p><p>“我们可能走到其他楼层了。”</p><p>胡彦卓理性猜测道，“可能是一楼或二楼，但这里的氛围，却根本不像艺术楼……”</p><p>杨帝的目光落在那些密集、粗壮的水泥柱，还有天花板的排污管道上。</p><p>虽然他不是学土木的，但这种建筑结构……</p><p>杨帝脑海中闪过一个念头，一个让他感到不寒而栗的念头——</p><p>“胡哥，我们应该在地下楼层。”</p><p>“不可能的，杨帝兄弟，你有什么依据？”</p><p>“直觉，胡哥。你见过哪里的教学楼，地板距离天花板目测只有2.1、2.2米？这里承重柱也多得不正常，装修很糟糕，而且天花板铺满污水管道。”</p><p>“……杨帝你看，那边还有窗户，地下室怎么会有窗户？更何况艺术楼是没有地下室的……”</p><p>胡彦卓走到最近的窗前，掀开积着厚厚灰尘的窗帘。</p><p>砖墙。</p><p>手电筒光映出窗外的砖墙！</p><p>砖块、水泥，严丝合缝地封住了窗框！</p><p>连续试了几扇窗户，结果都一样。</p><p>每扇窗户都是假的，装饰罢了，窗户外边都被厚重的水泥和红砖封闭。</p><p>胡彦卓的手缓缓从窗帘上滑落，指尖沾满了经年累月的灰尘。</p><p>他脸色在手电筒光下格外凝重。</p><p>“好吧，你是对的，咱刚出龙潭又入虎穴。”</p><p>二人也知道，现在不是闲聊的时候了。</p><p>刚刚在无限循环楼梯里打完怪，现在他们都一致肯定，这艺术楼绝壁是中了邪，再唯物主义的人来了，也得认这个理。</p><p>杨帝来旧校区的目的，是寻找耶罗大仙的线索，把这块烫手山芋“耶罗符印”给丢掉，解铃还须系铃人嘛。</p><p>但现在，能平安脱身也是不错的了。</p><p>尤其是这次来，还卷入了无辜群众胡彦卓，杨帝心底还是有些内疚的。</p><p>如果这刚认识几天的跑酷师傅兼便宜大哥，回去的时候缺胳膊断腿了，也许，会成为他的心魔梦魇吧……</p><p>杨帝摇摇头，把各种想法甩干净。</p><p>“‘精神’属性太高了，副作用竟然是让我变得如此感性吗？”</p><p>对——精神。</p><p>杨帝踢了踢短尾狸花猫：“希夷，我有个好点子——你现在用你最强的精神攻击，对我发动全力一击，不要留手。”</p><p>短尾狸花猫怖惧，浑身炸毛。</p><p>“呱！老大你这是终于打算找个理由把我吞掉了吗？！好叭qwq如果老大要把我吃了，那我也死而无憾……没而不朽……魂兮来归喵……”</p><p>“别自己加戏。”</p><p>杨帝指尖掐住希夷后颈的软肉，将炸毛的狸花猫提到面前。</p><p>“照我说的做，否则今晚没小鱼干。”</p><p>“老大，你就从没给过我小鱼干喵……”</p><p>杨帝松开手，狸花猫重重摔在地上，短尾巴炸成三倍长，周身骤然腾起青灰色雾气。</p><p>“老大，你确定真的要精神攻击你喵。搞不好，很容易精神分裂，谵妄，思维迟缓，意志行为障碍，内感性不适……”</p><p>“你别废话了，你老大的血
