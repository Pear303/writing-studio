# 沉浸在艺术（5000字）【记得放图片】

<p>「他只能静静沐浴着恒星垂死的光芒，感受着亿万生灵的悲鸣。」</p><p>啪！键盘声停止。</p><p>“用这句话作为卷结尾，实在是艺术、太艺术了吔！！”</p><p>窗外的雨下得没完没了，豆大的雨点砸在锈迹斑斑的防火梯上，声响沉闷，但挺有氛围感。</p><p>逼仄的出租屋里弥漫着泡面和旧书的霉味，电脑屏幕的冷光映着一张胡子拉碴、眼袋深重的脸——正是笔名“万业狐狸”的作者达文西。</p><p>他刚敲完《轮回者不需要操作手册》（又名《我，轮回者！》）的最新一章。</p><p>主角团轮回者小队五人，险之又险地以最低评价苟活过“第二阶段任务·虫影迷踪”。</p><p>此刻，他们面对重伤垂死的虫族女王幼体，在铁砣的怒吼和火鸦的火焰即将终结这灾祸之源时，队长拦住了他们。</p><p>屏幕上，队长正通过精神链接，向那团散发着不祥紫光的肉瘤传递着“生命的真谛”与“战争的残酷”。</p><p>他试图感化这以毁灭为本能的造物。</p><p>“完美！”</p><p>达文西搓了搓脸，灌下一大口凉掉的速溶咖啡，脸上带着一种近乎病态的满足。</p><p>“这才是深度！人性的光辉在绝境中的挣扎！图兰泽的悲剧根源在于理解与沟通的缺失！放走这个幼体，让它带着‘启示’回归虫群，引发它们内部的反思……多么震撼的转折！艺术！这就是艺术！”</p><p>他沉浸在自己编织的黑暗深邃与人性光辉交织的宏大叙事里。</p><p>全然不觉门外由远及近的脚步声。</p><p>这脚步声不同于邻居的沉重或快递员的匆忙，它轻快、精准，停在了门前。</p><p>笃、笃、笃。</p><p>三声清脆的敲门声，礼貌得有些过分。</p><p>达文西疑惑地起身，透过猫眼往外看。</p><p>楼道昏暗的光线下，站着一个身影，让他瞬间精神一振，甚至下意识地捋了捋自己油腻的头发。</p><p>乌黑亮丽的长发柔顺地披在肩后，上身是剪裁合体的深色制服，勾勒出少女的线条，下身是及膝的百褶裙，双腿包裹在纯黑色的过膝袜中，脚下踩着一双擦得锃亮的黑色乐福鞋。</p><p>面容姣好，皮肤白皙，在昏暗的光线下仿佛自带柔光。</p><p>她怀里似乎抱着一个长条形的、用防雨布包裹的东西。</p><p>达文西心跳加速，难道是粉丝？</p><p>这么高质量的粉丝？！</p><p>按照“屋千蟑”理论，当你发现一个高质量粉丝，就说明你有大量高质量粉丝！</p><p>万业狐狸的粉丝都是超高质量滴！</p><p>“请问是万业狐狸老师的家吗？我是你的粉丝哦。”</p><p>JK似乎感觉到达文西正透过猫眼向外偷窥，掏出手机，亮屏，屏幕上正是她发表的书评：</p><p>「我已经无可救药的迷恋上狐狸了口牙[好吃][好吃][好吃]」【如图】</p><p>8月16日的评论，五星好评。</p><p>这是真粉丝，没得喷，铁证如山。</p><p>达文西瞬间把什么“图兰泽的悲鸣”抛到脑后，手忙脚乱地打开了门，脸上堆起自认为最和蔼可亲的笑容。</p><p>“您好！您就是万业狐狸老师吧？”少女的声音清脆悦耳，带着一丝恰到好处的仰慕，大眼睛扑闪扑闪地看着他。</p><p>“对对对！我就是万业狐狸！达文西！快请进快请进！”</p><p>达文西受宠若惊，连忙侧身让开，警惕心已经降到负数。</p><p>黑长直脸上露出一个甜美得毫无破绽的笑容，轻盈地迈步进屋。</p><p>就在她与达文西擦肩而过的瞬间。</p><p>她藏在身侧的手闪电般抬起！</p><p>达文西只看到——眼前似乎有什么东西喷出了一股带着奇异甜香的雾气，瞬间笼罩了他的口鼻。</p><p>“唔？！”达文西眼睛猛地瞪大，一股强烈的麻痹感如同电流般瞬间席卷全身！</p><p>他想惊呼，喉咙却像被堵住，只能发出嗬嗬的怪响。</p><p>四肢百骸的力量被瞬间抽空，身体软得像一滩烂泥，直直地向前栽倒。</p><p>他并没有摔在地上。</p><p>一只纤细却异常有力的手臂稳稳地架住了他下沉的身体。</p><p>少女脸上的甜美笑容早已消失，取而代之的是一种无机质的冰冷。</p><p>她像拖一个沉重的麻袋一样，毫不费力地将全身瘫软，只有意识还勉强清醒的达文西，拖出了房门。</p><p>达文西绝望地感受着自己被拖行在冰冷潮湿的楼道地面。</p><p>到了可能是停车场的地方，被粗暴地塞进了一辆轿车狭窄的后备箱。</p><p>黑暗、颠簸、汽油味和身体无法动弹的恐惧淹没了他。</p><p>他只能模糊地感知到车辆在行驶。</p><p>时间流逝，车辆终于停了下来。</p><p>后备箱盖被猛地掀开，雨后黄昏的天光，让达文西眯起了眼睛。</p><p>带着泥土和青草气息的空气涌入，但无法驱散他心中的寒意。</p><p>他被粗暴地拖了出来，扔在了一片荒无人烟的草地上。</p><p>泥土的湿冷透过薄薄的衣物渗入皮肤。</p><p>他像一
