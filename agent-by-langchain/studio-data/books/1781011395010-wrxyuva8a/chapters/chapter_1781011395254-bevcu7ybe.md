# 哈喽，某是耶罗，很好。这几日没有更新，并不是有人突然从书里穿出来突破到真上层叙事来把某秒掉屎忽，也没有被绑架和威胁——怎么可能嘛，用脚踝想想都知道的啦。

<p>写到此处，有感而发，想要将本应该放在书字开头的序言，待到了此处再释出。</p><p>序言一般分两种，而要写的正是“自序”，讲讲创作初衷和心得吧。</p><p>元和二年……实际上并没有那么遥远，但也可以说比那个更遥远。不过创作这本书，也确实与童年经验密切相关。</p><p>5岁起就用橡皮筋弹击自身，适应3月后，改用弹弓搭配泥丸。又经过半年磨合，将泥丸换成石粒，一步步突破身体耐受度。</p><p>6岁时，开始用竹制弓箭射击自己。最初几周会破皮见血，再后来就慢慢的不会受伤了。至于痛觉——对痛觉的忍受阈值也在上涨。</p><p>7岁，开始对自己的最脆弱的眼球进行杀伤。所使用的箭矢也从最开始软趴趴的燧石箭矢，逐渐升级为磨尖的燧石箭矢。</p><p>肉身抗皱能力上涨的同时，某能感受到，自己“进化的能力”本身也在提升。</p><p>函数本身在增长，函数的增长率也在增长。</p><p>8岁时，已经完全免疫猎弓+钢箭矢+针对眼球的杀伤。某意识到再接下来，应该要进入火器的领域了。</p><p>然而在那时候的神州，私藏火器是大罪。</p><p>《大明律·兵律·军政》有云：</p><p>“凡民间私有人马甲、傍牌、火筒、火炮、旗纛、号带之类应禁军器者，一件杖八十，每一件加一等，私造者加私有罪一等，各罪止杖一百，流三千里。非全成者，并勿论，许令纳官。”</p><p>买不到火筒，便只能退而求其次。</p><p>肉身已经不怕普通刀子了，就把主意打到那些看不见的阴招上。9岁那年，开始自己吞毒药练。</p><p>一开始是断肠草，咽下去喉咙像着了火，肚子里跟有把刀在搅，硬生生扛了三天才好。</p><p>吃了一个月的断肠草，后来又试砒霜。</p><p>白粉末放嘴里没什么味儿，可过一会儿，五脏六腑就像扎进了成千上万根冰针。</p><p>事后自然也是吐了一大滩黑血，才把情况稳定下来。再往后，鹤顶红、乌头、牵机药……市面上能听到的那些猛毒，以及路边时常能寻到的毒蛇，都成了练抗毒性的磨刀石。</p><p>12岁的时候，一般的矿物、草木毒已经伤不着肉身，某就开始埋头诵读四书五经。</p><p>这些经书发现，越是诵读，记忆力也便越是好。</p><p>14岁，考取进士谋了个官职。16岁那年，终于想尽办法去到稷海当地的都司卫所军器局。</p><p>上任后第4天还是第5天，尝试用火筒朝自己开了一枪，却还是低估了它的威力——弹丸瞬间穿透皮肉，深深嵌入小腹。</p><p>倒在榻上休养两整日，才勉强恢复元气。</p><p>伤愈之后，意识到自己的肉身柔软，比较贫弱，便取来军中强弩与钢矢，对着最为脆弱的眼球开始新一轮加练。</p><p>如此日夜不辍地苦练两月，终于连火筒抵近射击，也能以肉身相抗了。</p><p>既然火器已不足为惧，某将目光投向了更古老的淬炼之法。</p><p>在军器局的古籍库中，寻得几卷《易筋经》与《洗髓经》残本。</p><p>打住打住，并不是要一转修仙啦。</p><p>按其中法门，以粗麻石砾磨擦周身肌肤，再辅以特制药酒擦拭，让表皮在反复破损愈合。</p><p>简单来说，就是试图擦破体表的皮肤，然后涂抹上杂质和水比乙醇还多的酒。这一训练并非没有意义，对痛觉的忍耐度又进一步提升。</p><p>16岁秋，拜访戍边老兵，习得“铁裆功”。以沙袋捶打下体，最初几百下，痛彻心扉。</p><p>不过3个月后已经能承受石杵对下三路的弱点全力撞击，总归来说收获大于痛苦。</p><p>后又习“铁喉功”，以木棍顶住喉结冲击墙面，直至能咽喉顶着枪尖行走十步而肌肤不破。这个比铁裆功简单。</p><p>20岁春，某令亲兵将某装入灌满水的铁棺沉入河底。第一次仅支撑半柱香便濒临窒息。</p><p>2年后，终于能在水底闭气两个时辰。</p><p>期间还发现，双目竟能渐渐在漆黑浑浊的水中视物如昼，这也为之后游到澳洲埋伏笔。</p><p>23岁，又迷上了“金针渡穴”，命医官将三寸银针烧红，依次刺入百会、膻中、气海诸穴。</p><p>最初七针便会昏厥，但也是随着日积月累的磨练和适应，最后周身要穴皆可同时受72针而神志清明。</p><p>一夜翻阅某某草药书，见“水银”条描述其“绝阳蚀脑”，忽然心念微动——某虽已有横强肌肉，但大脑的锻炼尚不足够。或许明日，该试试承装百斤水银沐浴了……</p><p>别笑，当时这确实是某的想法。也许当时做出的确实是错误决定，也许是正确决定……</p><p>总之一觉醒来，不止大明灭亡了，大清也亡了！</p><p>众所周知，重金属，尤其是水银这玩意儿，其毒性主要在于侵蚀神经。当时一头沉进那棺材，把自己浸在几百斤水银中，脑子里想的还是“绝阳蚀脑”的益脑功效，结果可想而知——神经是蚀了，但没完全蚀对路子。</p><p>要找个比喻，像是身体里那套经过千锤百炼的系统，把这足以让一整个城市的人慢性病
