# 合规的公共博物馆

<p>「请带路，馆长先生。我方需直接前往A-2至Z-99区域的时空区域进行实地测量。」</p><p>太一矩枢小声告诉杨帝，他们用26个字母，也就是从A-Z，定位该宇宙的所有区域。每个字母都分为1-99区。</p><p>A-2至Z-99区域被馆长开辟成博物馆，只留下A-1区域没有作为文物展出的区域。</p><p>但事实上，A-1一个区域，就占据了整个宇宙68.45%的时空，另外A-2至Z-99这2573个区域，只占剩下的31.55%，只能说贫富差距极大。</p><p>随后，圣人便领着他们挪移到某个不起眼星球的一条普通街边，各自在一家烟火气十足的小吃店门口找了张塑料凳坐下。</p><p>三人隔着几张油腻的桌子，各自点了一份招牌炒粉，杨地多要了一瓶豆奶，太一矩枢和圣人则各自点了一碗猪脑花汤和可乐。</p><p>他们没有交谈，只听见路边摊嘈杂的人声和锅铲碰撞的声响。</p><p>杨帝也很久没这么吃过路边摊了。想起来，上次与其他人外出在餐饮行业店家消费，还是与一具战术人形。</p><p>气氛有些压抑，三人沉默地嗦着炒粉。杨帝终于忍不住，低声问太一矩枢：“连吃饭也不能坐近些？非得像拼桌的陌生人？”</p><p>太一矩枢的电子音平稳无波，却在嘈杂的背景音中清晰可辨：</p><p>「这也是盟约外勤人员行为的规定，执行核查任务期间，应尽量避免与被核查对象发生非公务接触，包括但不限于共同就餐、娱乐等可能引起利益关联嫌疑的行为。原则上，不应于同一餐饮单位内用餐。此刻已是流程允许范围内的最大弹性。」</p><p>他顿了顿，补充道：「此行为俗称‘避嫌’。」</p><p>杨帝看了一眼远处独自喝着可乐的馆长，对方正用一根极其精致的吸管搅拌着冰块，脸上对可乐里的冰块露出凝重神色。</p><p>炒粉吃完，豆奶见底，猪脑花汤和可乐也解决了。</p><p>馆长优雅地擦了擦并不存在的嘴角，起身笑道：“二位，既然公务餐用毕，是否现在就去展厅看看？保证让二位不虚此行。”</p><p>所谓的“参观审核”正式开始。</p><p>这时候才算正式进入此宇宙。</p><p>穿过一道看似普通，实则扭曲了时空的回廊后，眼前的景象豁然开朗。</p><p>内部空间之大，超越了视觉感知的极限。</p><p>无数展厅如同蜂巢般延伸至视野尽头，每一个都散发着迥异的时间流速和物理法则波动。</p><p>藏品确实堪称宇宙级瑰宝。</p><p>在一个展厅中央，悬浮着一块巨大的暗色水晶，其内部封存着一整颗超新星爆发瞬间的壮烈景象，极致的光与热被永恒定格，无声地咆哮着。</p><p>另一个展厅则是一座无限延伸的图书馆，书架由某种记忆材料构成，其上陈列的并非书籍，而是一封封载体各异的“分手信”，从刻在兽骨上的原始铭文，到铭刻在量子泡沫中的文明绝响——这里收藏着一个已彻底消亡的文明所有个体，在与他者直接关系终结时留下的最后话语。</p><p>而在一个防护极其严密的隔间内，只孤零零地放着一件物品：一个来自其他叙事域，看起来再普通不过的塑料晾衣架。</p><p>在此宇宙的物理法则下，它无法被理解，无法被复制，甚至无法被长久注视，杨帝看了半天似乎也有些描述不出其外形特征、组成成分，只能知道它的作用是用来晾衣服。</p><p>馆长张开双臂，脸上洋溢着混合了自豪与贪婪的光芒，声音在这瑰丽的奇观中回荡：</p><p>“请看！这都是我耗尽心血，从万千宇宙角落搜集而来的文明珍宝！每一件都价值连城，独一无二！我这一切，可都是为了文化交流与传承啊！”</p><p>太一矩枢的传感器扫过每一件藏品，冷静地记录着，同时对杨帝传音：</p><p>「藏品真实，估值符合申报。但请注意，维持这些藏品稳定存在的能量消耗，仅占该区域即A-1区总能耗的0.3%，剩余能量流向？」</p><p>这只是句平平无奇的质询。馆长清清嗓子，认真回答道：</p><p>“绝大部分能量，都用于维持一件意义非凡的遗产——‘沃陶姆现实透孔仪’。”</p><p>他抬手示意，众人前方空间层层展开，露出一个被无数能量导管和静滞力场环绕的核心展柜。</p><p>柜中悬浮着一个结构极其精密的奇异装置，由某种非晶态物质构成，表面流转着仿佛能窥见万物本质的微光。</p><p>“此乃本宇宙曾最先进的文明‘沃陶姆’所造，他们试图用它窥探现实的底层结构，却最终因触及禁忌而自我湮灭。”</p><p>馆长的语气带着惋惜，“这仪器是他们存在过的唯一证明，亦是警示后人的丰碑。维持其稳定，需要难以想象的能量，但这一切，都是为了铭记与守护！”</p><p>他张开双臂，姿态悲壮而崇高。</p><p>据说，沃陶姆文明的个体皆呈小白鼠形态。他们仅用三千年便飞出行星殖民星系，又耗三千万年称霸全宇宙。</p><p>当其建筑横亘星河、设施超越恒星之际，他们却意外发现了一个只需文艺复兴时期初等数论知识便能推导出的公式——如此简单，却无一只小鼠曾触及。</p><p>这让他们毛骨悚然，怀疑有只无形大手操控现实，自身不过是纸上可随意修改的文字。</p><p>为此，他们倾尽一切，建造了能窥视现实孔洞的“沃陶姆现实透孔仪”。</p><p>开机之日，全文明直播。</p><p>当孔洞开启的瞬间，所有小鼠都看到了——看到了，也许是某种东西，某种概念，也许什么都没看见。</p><p>但无一例外，所有小鼠在直播后，没有留下任何遗书和言语，不约而同全部选择了自杀。</p><p>如今，这台用整个文明换来的仪器，正静静悬浮在馆长的展厅里，消耗着巨额能量，也成为他解释能源去向的最佳借口。</p><p>“想要解析‘现实透孔仪’的原理，将不可避免地要看到这部机器捕捉到的画面。”</p><p>馆长一边说着，一边耸耸肩，“为了压制现实透孔仪所展现的内容物，我需要大量能量，镇压其中蕴含的恶意模因实体……”</p><p>视线穿透能量屏障，看到的并非庄严的文物展厅，而是一片广袤的作战空间。</p><p>无数庞大的战舰正排列成攻击阵列，舰体后方拖着粗壮的能源电缆，它们将磅礴的能量汇聚于舰首，持续不断地向中央一个巨大的金属圆环喷射炽热的魔动光波炮、鸳鸯蝴蝶炮、阿姆斯特朗回旋炮。</p><p>光流奔腾，嗡鸣震耳。</p><p>太一矩枢的传感器瞬间锁定那些密密麻麻的能源接口。</p><p>「检测到超规格能量输出。这些战舰及其持续性的炮击行为，即为异常能耗的主要去向。」</p><p>这个行为，仍然是合规的，甚至还经过了盟约相关部门备案——太一矩枢如是说。</p>
