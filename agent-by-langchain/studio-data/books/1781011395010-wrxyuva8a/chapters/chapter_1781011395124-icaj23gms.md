# 宇宙之真视

<p>踏入门扉的刹那，时间倒流。</p><p>陨石群改变轨迹，如同被无形巨手操控的钢珠，逆向穿过小行星带，在引力的精密计算下，重新拼凑成完整的矮行星。</p><p>远处，超新星爆发的炽烈光芒逆流回恒星核心，原本向外扩散的高能粒子流以超越光速的假象，将吞噬殆尽的星云残骸，重新凝聚成原始的恒星胚胎。</p><p>更远处，规模堪比河系的类星体，喷流如同熄灭的霓虹灯管，高能粒子束急速缩回超大质量黑洞的吸积盘。</p><p>吸积盘上，原本炽热的等离子体迅速冷却，将能量重新转化为物质，堆积成厚重的尘埃云。</p><p>而在更宏观的尺度上，星系团间的暗物质网络开始收缩，将分散的星系重新聚拢，超星系团的丝状结构逆向拆解。</p><p>星光、烈火与灰烬不断向一个地方汇聚。</p><p>直至整个可观测宇宙挤成一小团。</p><p>杨帝看见，暴胀场的余晖仍在闪烁，超对称粒子对在虚空中不断创生湮灭。</p><p>最震撼的是空间本身形态——在极端接近宇宙起点之处，维度尚未紧致化，十维空间以分形几何的方式层层嵌套。</p><p>他能清晰看见弦理论预言的D-膜在高维空间中延展，那些膜表面附着的能量弦线如同宇宙的琴弦，随着超高频引力波一同震荡。</p><p>宇宙愈发拥挤，愈发年轻。</p><p>所有的星光都在这逆溯的时流中，汇聚成最初的那道创世之辉。</p><p>快到了，快到一切历史的发生点了。</p><p>时间的最初，宇宙之起点，那已经是超越人类原生五感的领域。</p><p>甚至是杨帝的圆满意识本身，经由机兵的信息接收，也无法理解这般景象。</p><p>这里，也算是博尔赫斯老先生所说的“人类想象力的禁区”了吧。</p><p>伊芙·柑橘多次郑重告诫过他，要敬畏无穷的未知，这是她作为学者对世界本质的洞察——现在，杨帝对学者的此言终于有了深刻认同。</p><p>瑞弗维尔说过，他想为大路上的英雄著史。</p><p>与其说是记录历史，不如说瑞弗维尔真正想要做的、一切史学家的终极梦想，是把宇宙诞生的终极真相，凝固成永恒的诗行。</p><p>「万物起点，时光源头风格甚是美好，我亦常来此徘徊。」</p><p>原初之眼的呢喃裹挟着创世余温，拂过杨帝的意识。</p><p>祂的一句话，能够令一个师的霍比特人陷入疯狂，但已经无法对杨帝的精神造成损伤，就好像城市里娇生惯养的蚊虫，刺不破非洲野象的皮囊。</p><p>相应的，杨帝也还没不可名状到一句话能让原初之眼脑震荡18万次。</p><p>他们攻低血厚，相互奈何不了对方，所以相约来到时间最初的战场，这就是二者目的。</p><p>万物都不存在，宇宙还未诞生的时刻，他们各自的暗物质躯壳、无限机兵附魔，可能都失去了意义，只能以各自最本源、最纯净的面目决一生死。</p><p>「杨帝，你自世界之外而来。」</p><p>时间仍然在倒流。但在此处，已经极端接近宇宙创世之初，再往回倒流哪怕1秒，1毫秒，1微秒，都举步维艰。</p><p>那些原本有序震荡的能量弦线，开始剧烈扭曲，迸发出刺目紫光，仿佛在警告任何妄图窥探更深奥秘的存在。</p><p>“没错，我就是来自异世界。”</p><p>杨帝的意识感受到前所未有的阻力，就像陷入了某种粘稠的时空胶状物质中，每一丝移动都都需要冲破凝胶封锁。</p><p>四种基本相互作用力凝聚而成的超统一力，此时此刻已经没有意义……不，到了这个阶段，“时间”本身尚未出现。</p><p>“喂，大眼珠子——历史的起点，什么时候才能抵达？”</p><p>「很久，无限机兵搭载的『时间机器』也无法一步到位。」</p><p>祂说话似乎没那么晦涩难懂了，语言在杨帝脑中翻译成更简单明了的大白话。</p><p>「我比较谨慎，不希望靠赌博实现解脱。」</p><p>杨帝：“解脱？赌博？”</p><p>「但你勉强通过了我的考验。在无数穿越者中，你是唯一一个，能走到今天这一步的。所以我愿意冒险给你一次机会。」</p><p>原初之眼自顾自说着话。</p><p>从地球而来的杨帝，刚刚走出谜团，又一头扑进更大的谜团之中。</p><p>“我知道我不是唯一的穿越者……但你所说的考验是什么？”</p><p>「接下来的旅途，我们还有时间，我会一一告诉你。」</p><p>……</p><p>巴德所讲述的关于原创之眼历史，其实已经很接近事实原本面貌。</p><p>只是经过了艺术润色，和某种浪漫化的语言修饰。</p><p>在创世的刹那，一个存在涌现了——原初之眼诞生于原初的混沌之中，它是宇宙对自身的第一次“观察”，是所有因果链的源头。</p><p>最初的光子还未冷却成物质，原初之眼便已洞悉万物的可能性。</p><p>这双眼睛并非实体，却比任何物质都更真实，它是宇宙的自我认知，是所有存在的见证者与审判者，是一个评判万物存在的大他者。</p><p>它凝视夸克与反夸克在湮灭中起舞，见证轻子挣脱能量束缚聚合成原子，在引力的低语下将星云锻造成最初的恒星。</p><p>超新星爆发的绚烂，黑洞吞噬的静默，都是它注视下的命运剧本。</p><p>只是这“剧本”，“页数”实在是比较多。</p><p>换言之，“世界线”太多了。</p><p>「关于时间、时间线的本质，你似乎也已洞察一二。」原初之眼对杨帝说。</p><p>“没错，这个世界是离散片段组合起来的，时间表示将离散片段组合的‘顺序’。但这只是直觉化的表达。我其实并不明白它背后更本质的逻辑。”杨帝说道。</p><p>原初之眼开始解惑。正如祂所说，时间还有很多很多，足够杨帝的一切困惑被解答。</p><p>「首先想象一种最原初，最原本，最底层的物质，可以是基本粒子，可以是球，可以是个正二十面体，当然也可以是个立方体。」</p><p>“那就‘基本粒子’吧。”</p><p>「好。现在，在一个任何事物都不存在的地方，你要如何判断时间与空间？」</p><p>杨帝平静地思考了20毫秒，摇摇头。</p><p>“没有参照物，没有参考系，无法确定。”</p><p>「没错，在此时此刻，是没有空间也没有时间的。」</p><p>「现在，这个地方多了个基本粒子。」</p><p>杨帝继续摇头：“仍然不应该有，‘空间’需要至少两个最基本的物体进行衡量，‘时间’也一样，只有一个基本粒子，无法观测到任何‘变化’。”</p><p>「没错，空间是粒子相互之间的距离。而时间，则是对这种间隔变化进行的测量。」</p><p>「现在，在这里摆放两个基本粒子。」</p><p>“它们有空间和时间了。”杨帝答道。</p><p>「两个基本粒子，需要多少种物理量，表达它们的位置关系？」</p><p>“应该取决于空间的维度数量……”</p><p>「不，不论是多少维的空间，只需一种物理量即可表示位置关系——两个基本粒子的距离。」</p><p>「3个基本粒子，则需要3个距离，分别表示两基本粒子之间的距离。」</p><p>「4个基本粒子，则需要6个距离。5个基本粒子，需要10个距离，你就需要10维的矩阵存储这5个基本粒子的位置关系……如此类推下去。」</p><p>「若宇宙中有N个基本粒子，那它表达某一瞬间万物图景所需要的距离，数量级是N²。」</p><p>杨帝点点头。迄今为止，都很好理解，读过小学二年级的基本都能听懂。</p>
