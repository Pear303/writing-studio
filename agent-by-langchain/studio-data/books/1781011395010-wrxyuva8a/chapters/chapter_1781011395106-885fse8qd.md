# 极难封印

<p>如果经常看走进科学自然传奇探索发现，应该会对“黑洞”很熟悉。</p><p>黑洞，大抵是宇宙中极端的天体，是由质量巨大的恒星在生命末期坍缩形成。</p><p>引力场强大到连光都无法逃逸，从而形成了一个事件视界。</p><p>一旦物质或光线越过这个事件视界，就会被吸入内部，永远无法逃脱。</p><p>被“次元封锁”的木镐，锁在黑色的“球”中。</p><p>仿佛是黑洞跨越了浩瀚星河，在这工坊之中降临……</p><p>它周身散发令人心悸的压迫感，周边一圈幽蓝光晕，如同沸腾的液态光，疯狂翻涌。</p><p>光晕中的符文不断闪烁、扭曲、重组。</p><p>那是某种力量在疯狂对抗与挣扎的具象化体现？</p><p>杨帝知道，那并非是黑洞。</p><p>要是有这么个砂锅大小的黑洞，出现在铁匠铺，这片大陆会在下一秒彻底撕碎，整片时空扭曲成刀削面。</p><p>可眼前这个黑色球体，虽然散发着相似的恐怖威压。</p><p>表面却流转着异界特有的灵能符文，边缘光晕中跃动幽蓝光芒。</p><p>仍在伊芙掌控之中，不会暴走。</p><p>还好，至少不是那种掌控不了的不可控链式反应。</p><p>杨帝瞥见奥拓、他爸、瑞弗维尔躲在门缝后苍白的脸。</p><p>灵压太强，狂风肆虐，说话根本听不清楚，他们只能用眼神，通过眨眼、眼角抽动、瞳孔缩放、睫毛颤抖进行交流。</p><p>“伊芙她怎么了？！”</p><p>“你问我我问谁。”</p><p>“杨帝！砾石镇暴民好像察觉到异常，正朝着这边集结围观。”</p><p>“不可能，我已经设下幻象法术、防御护盾了，从外边看过来，应该风平浪静。”</p><p>“不……在你铺设幻象法术前，伊芙那根圣树枝杈做的法棍，就短暂显露过40米本体。”</p><p>“那你们想好理由，就说我们在院子里植树造林搞绿化评选文明小镇之类的，把他们支开！”</p><p>杨帝不敢离开伊芙太远。</p><p>他还得支撑幻象、护盾法术。</p><p>虽然这个黑色球体不是货真价实的黑洞，但终究是10环法术，光是泄露的一丝气息，就能震死史莱姆，震晕猫猫狗狗！</p><p>护盾以内，工坊石砖开始崩裂，空气中漂浮的铁屑与碎石被无形力量牵引，围绕黑色球体旋转成螺旋状。</p><p>伊芙的金色长发已经完全化作光焰，眼珠子像是被挖掉，然后塞进两个500000流明的灯泡，射出耀眼强光。</p><p>铁匠铺外边的事情先安排好。</p><p>护盾和幻象一时半会儿还不会破开。</p><p>那么接下来就只需关心一件事了——</p><p>杨帝看向黑色球体，又用余光扫一眼奥拓。</p><p>那柄木镐，还没有回到矮人身边。</p><p>成功了？也许吧，但是代价是什么。看看这铁匠铺的院子，地板破碎不堪，旁边养的几盆雏菊也被吸走，和碎砖头、几只猫猫狗狗一块儿在天上打转。</p><p>所幸破坏力有限，铁匠铺也就院子的空地、部分墙体受到波及，不至于说把矮人家抄了。</p><p>杨帝只能大叫，尝试唤醒精灵。</p><p>“伊芙！镐子已经困住了！外面全是暴民！收手吧！”</p><p>话音刚落，杨帝意识到自己立了个Flag——“镐子已经困住”。</p><p>却见黑色球体表面，符文开始逆向旋转，幽蓝光晕如同沸腾的沥青般剧烈翻涌。</p><p>然后，伊芙身体开始透明化，金色光焰逐渐稀薄。</p><p>而她眼中的灯泡状光芒却愈发刺眼。</p><p>杨帝有种感觉。</p><p>就像是计算机CPU全力运行一个程序，但读取到某一行中断指令，触发异常，然后CPU偃旗息鼓，电脑死机蓝屏冒烟了。</p><p>伊芙所运行的10环法术，进程崩溃。</p><p>她芙周身的光焰向内坍缩，40米高的法杖重新被收入风王结界，隐去形状。</p><p>工坊内所有悬浮的碎石铁屑、砖瓦碎片，失去了力的悬浮，重新被重力所支配，掉落在地。</p><p>那柄被封印的木镐竟穿透球体表面，裹挟着撕裂空间的尖啸破空而出，直直刺向奥拓。</p><p>矮人下意识张开双臂，下一秒整个人便如断线风筝般被撞飞出去。</p><p>冲击力让他后背重重砸在铁匠铺的铁砧上，砰沉闷一声，随后整个人又被弹开，在布满碎石与铁屑的地面上连滚七八圈。</p><p>矮人皮甲与地面摩擦，溅起串串火星，最后在墙角停了下来。</p><p>“没事，还行！”</p><p>奥拓浑身灰尘，看起来颇为狼狈。但还是比了个OK，向众人报平安。</p><p>周围扬起的灰尘久久不散，将他狼狈的模样笼罩其中，仿佛一尊失去生气的雕塑，安静地躺在那里。</p><p>矮人体质非常棒，皮实耐操。</p><p>挨了媲美杀手兔一撞，也仅仅是断根骨头。</p><p>要知道异世界不是所有人，都和杨帝一样是个体质怪物。</p><p>“法术”之于人，就像“附魔”之于工具，其实都是种外在的增强，并非本质的进化。</p><p>所以法师大多是玻璃大炮。</p><p>瑞弗维尔顾不上满地狼藉，跌跌撞撞冲到伊芙身边。</p><p>精灵瘫坐在碎裂的石砖上，金色光焰尽数熄灭，苍白的脸上没了往日的神采，连耳尖都耷拉下来，像是被霜打蔫的藤蔓。</p><p>她指尖还残留着零星符文的微光，却已无法凝聚成形。</p><p>“伊芙？1000-7等于几？”</p><p>瑞弗维尔轻拍她脸颊。</p><p>精灵毫无反应，眼皮紧闭，呼吸虽平稳，却比平时微弱许多。</p><p>瑞弗维尔轻轻扯开她沾着尘土的披风，指尖按在脖颈脉搏处——跳动有规律，只是速度快得惊人，像失控的风箱。</p><p>“灵能透支了应该。”瑞弗维尔长舒一口气，抹了把额角冷汗。</p><p>不会有生命危险。</p><p>他解开伊芙胸前几颗纽扣，从腰囊掏出一小瓶闪着银光的药水。</p><p>这是用薄荷脑、桉油、冬青油、樟脑、石蜡熬制的醒脑剂，专门用于祛风止痛，芳香通窍，伤风喷嚏，鼻塞头痛，舟车晕浪，跌打扭伤，肌肉酸痛，蚊虫叮咬。</p><p>药水抹上精灵的太阳穴。</p><p>她睫毛微微颤动，却依旧没醒。</p><p>他注意到精灵耳后浮现的细密裂痕，像是干涸河床上的纹路。</p><p>如果他没记错书本上的内容，这应该是过度使用高阶法术的后遗症。</p><p>奥拓也迅速走来，身后还背着那柄木镐。</p><p>“老爸已经去和镇民解释了，就是说我们在尝试种树什么的。但因为我们一家两口不会几个灵能法术，所以他们肯定还会怀疑。你们得快走了。再往南走，穿过灌木丛，就能绕到官道。”他瓮声瓮气地说，声音里带着疲惫。</p><p>瑞弗维尔赶紧背起伊芙，随时撤退跑路。</p><p>杨帝快速施展法术，就是《神奇动物在哪里》出现过的同款法术，将散落的碎石铁屑、砖头瓦片归拢回原位，恢复工坊原貌。</p><p>土木的学长穿越到异世界，必定风生水起，前途无量，平步青云。</p><p>因为异界建筑行业非常发达，盖房速度是地球同社会形态的10倍以上。</p><p>奥拓：“我会把他们引到北面，你们就从院子南边的小门，走小道而出。只要绕进南边的桦树林，基本上就留不下踪迹了。”</p><p>他们走小道出了院子，个个戴着披风和兜帽蒙上脸，往南继续走。</p><p>那几个老头老太，仍然抱着车轮、剪刀和鱼竿等物，坐在树头下谈天扯地。</p><p>“奥拓家院子，刚刚是不是竖起了个什么东西？”</p><p>“貌似是棵树，40来米高。”</p><p>“树？这么快怎么可能长出棵树木，就算用城里商队的‘不纯不要钱的金坷垃’也做不到那么快吧。”</p><p>“所以我必定是看错了，唉，老了，既没有激情，身体也变差了。”</p>
