# 原初往事

<p>星渊井口距离圣树1200公里，平均120公里时速疾驰10小时，杨帝四人已依稀看见地平线远方的繁茂森林。</p><p>“我们会在半小时后抵达。瑞弗维尔还没醒来吗？”杨帝操控着灵能轿厢，有些疲惫地问。</p><p>伊芙坐在车内，神色无波地摇摇头。</p><p>瑞弗维尔躺在她膝盖上，仍然双目紧闭，意识昏迷，对外界做不出任何反应。</p><p>“如果直接问瑞弗维尔，效率会高很多。”</p><p>“我知道，但世上哪有这么多如果。”</p><p>“咳咳……诸位，我好像找到了。”</p><p>矮人奥拓清了清嗓子，打断发言。他在队伍里一直是个透明，存在感比杨帝还低，但在社科方面，似乎也小有研究，是个早年被父亲逼着做铁匠的文科人才。</p><p>他现在宁愿做一辈子铁匠，不碰考古，不碰人文社科——只要能换他老爸安然无恙。</p><p>伊芙看向奥拓：“找到了？念出来吧……”</p><p>奥拓手里翻着的，正是瑞弗维尔随身携带、写有“大陆英雄野史录”的笔记本。</p><p>矮人照着他翻到的内容念起来：</p><p>「巴德口述的『原初之眼』与旧野史记载略有不同，故在此（原初之眼篇）作简单记录。」</p><p>「天地初辟，混沌未分。据说在久远到连原子（一种很小很小的颗粒？）都没有形成的时间起点，世上所有东西都汇聚在一个没有体积的点，这个点拥有整个世界的重量（太奇怪了）」</p><p>「无穷小的点突然膨胀，迸发出无数看不见的丝线（巴德坚持说那是时间与空间，但时空怎么会像蚕丝一样具象化呢？），这些丝线在虚无中互相撕扯、缠绕，逐渐凝结成我们熟知的元素——风、火、水、土。」</p><p>「而在最早期这片混沌浓汤中，一种代表着世界“观察”的趋势诞生了，那就是原初之眼。」</p><p>奥拓的声线突然变得古怪，显然被后续内容惊到了：</p><p>「值得注意的是，巴德声称最初所有元素都处于完美对称状态（他画了个类似铁匠砧台的几何图形），直到某个时刻——就像锻造时突然落锤——原初之眼在某个瞬间突然选择向某个方向倾斜（怀疑是原初之眼诞生主观意志的开始？亦或偶然？）」</p><p>车厢剧烈震动，瑞弗维尔的睫毛在颠簸中颤动。</p><p>伊芙按住笔记本防止滑落，示意奥拓继续。</p><p>「这种倾斜导致元素分化出等级，就像铁水冷却时会先凝固出晶核。高热元素沉向底层形成熔岩之海（巴德称之为“粒子”？），轻灵元素则上升为苍穹之息。」</p><p>「这就是原初之眼第一次干涉世间——祂导致我们熟知的实物得以生成，否则世界就永远是一锅沸腾的元素浓汤，而且永远不会有变化（证实了前面的猜测）。」</p><p>「这一次干涉，还使元素得到了“形体”，物质获得了“力量”，世界有了一个驱动力，开始向我们今天的模样演变（不可思议）。」</p><p>「而后，原初之眼暂时没有了干涉世界的兴趣，祂开始自己的本职——观察。」</p><p>「（这里有点乱我理一下：巴德的意思是，世界开始自动发生变化，祂就被世界的各种变化发展迷惑住，只想着观察，不再想干涉。）」</p><p>「但后来，大地上出现了智慧的人们。」</p><p>「人们创造了灿烂的科技，艺术，文化和哲学，他们有远超死物的丰富思想。」</p><p>「而原初之眼的“观察”，会为自己刻上被观察对象的烙印。」</p><p>「祂被人的爱恨情仇、悲欢离合所感染，祂想要自己动手为所有人书写命运。」</p><p>「于是，原初之眼开始了第二次干涉。」</p><p>「也就是野史中有记载，四万年前中土大陆的原初之战。」</p><p>「为了对抗即将引发“现实重构”世界末日的原初之眼，大地上和星星上（星星上？）的人们，制造出了被称作『无限机兵』的巨人。」</p><p>「（接下来的内容很拗口，我只能尽量转述巴德先生所讲的）」</p><p>「但是，原初之眼同时存在于过去和现世，祂的“真身”一直待在主观意志诞生之刻，祂的肢体可以影响未来。」</p><p>「所以，只要不解决时间起始的原初之眼，他们在“现世”的战斗注定只能是徒劳。」</p><p>「于是，人们为无限机兵安装了相当于“心脏”的机器『时间机器』。」</p><p>「人们利用时间机器穿越时间，回到历史的最初起点。驾驶无限机兵，与原初之眼的真身战斗（太诡异了……难道不会打破因果律吗？或者是会有什么冥冥中的力量修正‘祖父悖论’？）」</p><p>「战斗结束，我们的祖先驾驶机兵，独断万古，于过去横击未来敌，击败了原初之眼，将其放逐虚境，但历史长河中再无机兵踪迹，只有『野史』以寥寥几语记录其存在。」</p><p>「（史官曰：我听不太明白，但大受震撼——古人的想象力居然如此丰富。）」</p><p>……</p><p>奥拓将笔记本合上：“没了。”</p><p>轿厢内，伊芙咬着指甲，眉头紧锁。</p><p>“翻看瑞弗维尔笔记本”这主意，是她提出来的。</p><p>她认为，如果教廷要灭口巴德，是因为那位屠龙者掌握了某些秘密。</p><p>那么，为什么熔岩史莱姆也要不惜暴露自身，打草惊蛇，试图将他们一起灭口在半路？</p><p>精灵回忆起她被熔岩史莱姆“脑控”的细节，发现那史莱姆，自始至终都是在命令她杀死瑞弗维尔，并没有提到其他人。</p><p>精灵认为，瑞弗维尔已经掌握了某种关键信息。</p><p>所以熔岩史莱姆必须追杀他。</p><p>但信息不是瑞弗凭空得知的，而是在与巴德的访谈过程中，隐晦地传递了过去。</p><p>而熔岩史莱姆集群，直到他们半路才发觉不对劲，提前翻露底牌。</p><p>在此之前，则没有动作。</p><p>他们没有被教廷的十环法术炸死，史莱姆按兵不动；他们没有按照要求去往南海，史莱姆仍然没有现身。</p><p>这就说明，在他们偏离既定路线、前往星渊井口这段时间里，有什么关键信息被触发，或者是史莱姆觉察到有哪里不对，才让它们不得不提前出手。</p><p>而最有可能的，就是瑞弗维尔记录在笔记本上的内容——关于原初之眼的“访谈记录”。</p><p>当然，这也是她瞎蒙的。</p><p>伊芙：“你们认为这关于原初之眼的历史，有什么不对劲的地方？又或者是能毁灭祂的方法？”</p><p>问了一圈，满朝文武，竟无人能言。</p><p>“这访谈录似乎没什么实质性内容……”</p><p>杨帝发言了，虽然他已经连续开了十二小时的车，但仍然很有精神，“神话里记载了，人们通过搭载时间机器的‘无限机兵’战胜原初之眼，方法是穿越到原初之眼诞生的那一刻。”</p><p>暂且不讨论其真实性。</p><p>现在最大问题是……</p><p>我们既没有时间机器“时间机器”，也没有能与绝世强者大战的兵器“无限机兵”。</p><p>伊芙闻言，也陷入了沉思。</p><p>然后，矮人奥拓终于发表重要讲话：“情感。原初之眼进化出来的情感，就是祂最大的弱点。”</p>
