# 这把高端局

<p>杨帝那边附魔也大功告成，不仅得到了附魔撬棍，而且连瑞弗维尔的锅碗瓢盆刀叉筷子，都附上了一些诸如“保温”之类的实用附魔。</p><p>而瑞弗维尔的短刀，得到了一个全场最棒的附魔「海之眷顾」。</p><p>以后只要他在钓鱼时，手持这把短刀。</p><p>甚至不用打窝，就能钓上大把好东西！</p><p>不得不说，魔法改变生活！有了灵能法术，异世界到现在还没发展出成建制的空军。</p><p>杨帝将撬棍背在身后，悬挂起来，手伸到背后即可像拔刀那般抽出。</p><p>同时用绳子捆住几块砖头，挂在腰间。</p><p>此举模仿的是身上挂满炸弹的悍匪。</p><p>他们走出工作室时，伊芙和瑞弗维尔凑在一块儿不知谈论些什么，有说有笑。</p><p>把器具收好。奥拓说：“留下来吃个饭？”</p><p>也好，不急，某精灵还说在这待两年呢。</p><p>在众人决定待两天还是待两年之前，伊芙提出，想研究一下绑定诅咒之物。</p><p>“绑定诅咒也是一种附魔，附魔也算是一种法术的分支。我是理工精灵嘛，研究研究灵能法术，不是天经地义嘛。”</p><p>鉴于外面全是暴民，他们不能随便出门。</p><p>就算用「风王结界」之类的隐身法术出去，也不可能偷走对方附有「绑定诅咒」的物品。</p><p>刚拿走没几秒，这件物品就被还回去了。</p><p>长此以往，怎么做学术研究？</p><p>所以，伊芙决定研究奥拓的木镐——这座铁匠铺里，唯一仅存的绑定诅咒之物。</p><p>看着精灵认真的模样，矮人最终还是缓缓点了点头。</p><p>“其实绑定诅咒还是有一点点不方便。你们要是能行，那自然是再好不过。”奥拓说道，语气中带着几分无所谓和一丝期许。</p><p>他补充了一些在“铁熔堡”经历的细节：</p><p>价值650万的财宝比较难偷，他当时分了4个批次，轮番将财宝搬到自己挖的地道里，然后才将贝斯放到某个熟睡的矮人王室成员身边。</p><p>贝斯这种乐器，无论如何弹奏，都吵不醒睡着的人。</p><p>所以，奥拓有些不舍地小弹一曲。</p><p>毕竟是陪了他爸多年的贝斯，就算是诅咒之物，也有了感情。斯德哥尔摩综合征嘛。</p><p>结果不小心弹了二三十首曲目，浪费太多时间，来不及把木镐也卖掉。</p><p>再之后，铁熔堡追兵追了奥拓上百里路，从东部平原的孤山，到中央丘陵的城镇，“铁熔堡大盗”的恶名无人不知无人不晓。</p><p>“我和爸说‘我喜欢这个镐子’，其实有部分原因说是气话上头。所以，如果可能的话，请帮我解除木镐的诅咒吧。”</p><p>奥拓把镐子递出去。</p><p>手抓得很紧，还是有些不舍。唉，受虐癖。</p><p>伊芙轻轻接过木镐，入手便能感觉到一股阴寒之气顺着手臂蔓延开来，她不禁打了个寒颤。</p><p>“我感受到很深的诅咒……一种深深的恶意与憎恨。只可能是下诅咒的人，对某些事情，抱有极大的恨意……”</p><p>仔细端详木镐，表面看起来并无特别之处。</p><p>等她第6次眨眼，木镐突然不见了，转而重新出现在矮人奥拓背后。</p><p>“有意思。其实我这辈子见过的「绑定诅咒」案例不算多，也就七八个，大都是些传奇附魔工匠干活时，附魔出岔，然后余生都得和一件工具去过了。”</p><p>伊芙再次接过奥拓的木镐。</p><p>她左手持镐，右手执法杖，罕见地开始咏唱秘咒：“缚灵之链，虚无编织，缠绕灵魂，封印命运……混沌初开缝隙，星辰坠落轨迹，封印完成，直至永恒。”</p><p>「九环法术·缚灵封禁咒​」</p><p>伊芙不愧是超限法师，一出招就是大手笔，九环法术！</p><p>这缚灵封禁咒​施展起来，周围灵能瞬间如被搅动的漩涡，迅疾地朝木镐涌去。</p><p>符文实质化，凝聚成锁链。</p><p>锁链缠绕住木镐，试图将它钉死在伊芙手上。</p><p>但下一刻，木镐上陡然爆发出一股强大且诡异的力量！</p><p>那股力量如同挣脱牢笼的凶兽，直接将那些符文震得粉碎，化作点点荧光消散在空气中！</p><p>木镐“嗖”的一声，倏地回到奥拓背后，就好像刚才伊芙的九环法术从未施展过一般。</p><p>精灵被这股反震之力冲击得后退了好几步。</p><p>瑞弗维尔眼疾手快，赶忙上前扶住了她。</p><p>伊芙面色略显苍白，眼中满是困惑，“怎么会……居然用蛮力突破我的封锁？”</p><p>“能正面硬上伊娃你……这不能用单纯的恐怖形容了，必须形容为‘如斯恐怖’！”</p><p>“什么叫正面上我？滚开啦你。”</p><p>杨帝自始至终都在一侧旁观。</p><p>他只感受到精灵伊芙的法术，目睹她的灵能流转。</p><p>而那柄木镐，在被「九环法术·缚灵封禁咒​」禁锢起来后，内部“on”色的灵能骤然亮起，极端复杂的附魔符文短暂闪烁。</p><p>然后它瞬移了，出现在奥拓手中。</p><p>杨帝……说实话，只能勉强看懂这是一种附魔，极其高深的附魔，但他完全学不会。</p><p>或许活了至少上千年的老妖怪伊芙，凭借深厚的修为和极度丰富的经验，能够看出些什么门道。</p><p>“我再试试。”</p><p>从古到今，做实验失败的多得去了。</p><p>伊芙让奥拓把木镐放地上。这次，她手中法杖显露40米本体！</p><p>法杖重重杵在地上，整座工坊的石砖泛起细密裂纹，如蛛网般朝着四周蔓延。</p><p>伊芙缓缓飘浮起来。</p><p>她周身灵能如新鲜岩浆疯狂翻涌，金色长发如同金毛浮绿水一般扩散在空中，在身后狂舞成一片朦胧的光雾！</p><p>杨帝包里的熔岩史莱姆威压下滋滋作响，不安地扭捏，像是在平顶锅里煎的鸡蛋翻了个面。</p><p>“额滴个娘亲……躲远点，快跑！”</p><p>“伊娃！……不要这样……”</p><p>“这把高端局……瑞弗维尔！我用幻象法术和防御护盾遮住这里，你和奥拓走！”</p><p>在凌冽的灵压漩涡中，杨帝只能撬棍杵地，艰难地朝身后扯嗓子。</p><p>奥拓他爸老矮人从里屋探出头：“发生什么事儿了？”</p><p>他被18岁年轻矮人奥拓按了回去。</p><p>瑞弗维尔也紧随其后冲进屋内，锁上门。</p><p>杨帝面向伊芙，边警惕边退。</p><p>同时分出50.1%的心神，在铁匠铺周围构筑起幻象、护盾二重法术。</p><p>他抬头朝空中望去。</p><p>伊芙手执40米法杖，低沉的咏唱声像是从远古深渊传来。</p><p>“圣树溯源诗章·其一·创世残响……”</p><p>“根脉织光茧，枝垂创世泉……第一缕风自叶隙诞生，星辰之胚芽于年轮中抽枝……”</p><p>工坊内空气骤然扭曲，无数道半透明的符文从虚空中浮现，流转幽蓝光芒。</p><p>这些符文相互交织，在伊芙头顶凝聚成庞大复杂到令人发指的术阵，捅入阵眼处的法杖，开始疯狂吸收四周灵能。</p><p>杖身不断延伸，最终化作一道直插穹顶的璀璨巨木！</p><p>地面上的木镐似乎察觉到危机，剧烈震颤着发出尖锐爆鸣。</p><p>但它还没来得及传送回到奥拓身边，伊芙已经光速咏唱完成。</p><p>“超限法术申请通过，当前队列人数：零。”</p><p>“十环法术·次元封印。”</p><p>超级赛亚人形态的精灵浮在空中，手臂轻轻向木镐一挥。</p>
