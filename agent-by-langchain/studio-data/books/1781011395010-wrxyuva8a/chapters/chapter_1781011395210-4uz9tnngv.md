# 武道强者的大胃袋

<p>那个叫白杨大帝的NPC必死无疑，哈基米这基地内应该没有天敌。</p><p>但当下它发出的凄厉嚎叫，分明是在和什么东西进行生死搏斗。</p><p>里面正在发生什么？哈基米大战终结者？</p><p>强烈的不安和一丝难以遏制的好奇心驱使着他们。</p><p>队长打了个手势，示意众人保持绝对安静，放轻脚步，向着声音来源靠近。</p><p>声音是从走廊尽头一扇虚掩着的、标着“备用服务器维护间B”的厚重合金门后传出的。</p><p>门缝里透出的红光比走廊里更加刺眼，猫叫声也更尖锐。</p><p>队长念力撬锁，无声地将门缝推开得更大一些。</p><p>眼前的景象，瞬间让轮回小队的所有人，大脑一片空白，大脑皮层褶皱瞬间光滑展开！</p><p>包括刚刚被拖行而稍微清醒一点的影子，她刚睁开眼清醒了一点，又吓晕过去。</p><p>房间内部早已不是普通的维护间。</p><p>墙壁、地板、天花板……目之所及的一切金属结构，都呈现出一种如同被高温熔融后又强行冷却的波浪状扭曲。</p><p>应急灯管早已爆裂，光源来自房间中央如同沸腾岩浆池般的战场！</p><p>在这个扭曲沸腾，仿佛空间本身都在呻吟崩溃的战场中心，两个身影正在以一种超越凡人理解，令大道都要磨灭的方式激战！</p><p>其中一个，正是那只脑袋裂成八瓣的哈基米——或者说，是它进化后的终极形态。</p><p>它的身躯庞大得几乎塞满了半个房间，不再是简单的食人花状头颅，而是变成了一个由无数疯狂增殖蠕动并融合的血肉触须构成的聚合体！</p><p>巨大的口器如同深渊般开合，喷射出足以腐蚀合金的强酸脓液和带着精神污染尖啸的音波。</p><p>无数根末端带着骨刺或吸盘的触须如同狂舞的毒蟒，撕裂空气。</p><p>而它的对手……怎么又是杨帝！</p><p>他依旧赤着上身，但下半身破烂的黑布，此刻仿佛活了过来，如流动的墨汁覆盖他全身，形成一件不断蠕动、仿佛有生命的漆黑“战甲”。</p><p>面对哈基米那足以将钢铁撕裂成麻花、江米条、葱花卷、砵仔糕的狂暴攻势，杨帝的身法却透着一股难以言喻的“古意”。</p><p>“吼！”</p><p>杨帝身形微伏，双拳一前一后，如猛虎下山，带着磨灭大道的威势扑出！</p><p>拳锋过处，空气被硬生生挤压出肉眼可见的波纹，竟真的将数根袭来的粗壮触须震得寸寸碎裂，腥臭的污血漫天泼洒！</p><p>—— 虎形拳！</p><p>哈基米剧痛嘶鸣，更多的触须毒龙出洞，从四面八方绞杀而来。</p><p>杨帝身形却如风中柳絮，轻盈得不可思议。</p><p>他脚步一错，身影瞬间变得模糊，在密不透风的触须绞杀网中穿行自如，每每在间不容发之际避开致命的缠绕和穿刺。</p><p>——八卦游身掌！</p><p>漆黑战甲流动，更添几分鬼魅。</p><p>杨帝双手化作灵蛇，顺着触须缠绕而上，猛地发力一抖。</p><p>咔嚓！整根触须便似被抽掉了骨头的长鞭，软塌塌地垂落。</p><p>——蛇形刁手！</p><p>“这……这踏马是武功？！”铁砣眼珠子都快瞪出来了，下巴砸在地上。</p><p>眼前这画风，怎么看都是科幻恐怖片里的血肉怪物大战，结果那个自称“大帝”的裸男NPC，居然在用金庸武侠里的招式跟它打得有来有回。</p><p>“不……不止是武功！”</p><p>眼镜的战术目镜疯狂闪烁着，声音因为极度的震惊和运算过载而颤抖。</p><p>“他的动作违背了生物力学！没有肌肉纤维能承受那种瞬间爆发的加速度和扭转力……还有那些能量反应……他每一次出招，身体周围的空气几乎要产生音爆。”</p><p>“难道……”</p><p>“这个NPC，是终结者智械？！”</p><p>众人倒吸四口凉气，全球变暖+1。</p><p>之所以是四口，是因为影子仍然昏迷在地。</p><p>更让众人瞳孔骤缩的是哈基米的反应。</p><p>这只恐怖的怪物，明明在杨帝传统功夫的打击下不断受创，污血碎肉飞溅，却始终没有尝试逃离这个房间！</p><p>“仇恨值……锁定！”眼镜失声叫道，“他身怀某种极其霸道的‘嘲讽’技能！”</p><p>仿佛为了印证眼镜的分析，战场局势陡变！</p><p>杨帝在一次精妙的“鹞子翻身”躲过一道强酸喷射后，身形如同鬼魅般贴近了哈基米那庞大身躯的核心区域。</p><p>漆黑战甲包裹的右手五指成爪，带着撕裂一切的锋锐之意，猛地插入了哈基米那搏动着的暗红核心肉瘤边缘！</p><p>“噗嗤——！！！”</p><p>污血如同喷泉般激射！</p><p>哈基米发出了仿佛灵魂被撕裂的惨嚎，整个庞大的血肉聚合体，都剧烈地抽搐起来。</p><p>“居然是武道绝学九阴白骨爪！欧阳锋用这招吊打一众武道宗师，最后是靠着神仙下凡，才将其打成精神分裂，从此只能与大猩猩、恐鸟、等野生动物为伍。”</p><p>“这又是哪里的野史？”</p><p>杨帝五爪嵌入肉团，随后猛地向外一扯！</p><p>一条足有成人手臂粗细，表面覆盖着粘液和搏动血管的粗壮肉筋，被他从哈基米的“心脏”旁扯了出来。</p><p>接下来的一幕，成为了轮回小队成员们毕生难忘的噩梦。</p><p>杨帝将还在疯狂抽搐、滴落着强酸脓液和污血的粗壮肉筋，送到了嘴边。</p><p>“咔嚓！”</p><p>一声令人头皮炸裂的脆响！如同咬断一根过分坚韧的牛筋。</p><p>他把那坨血肉给吃了。</p><p>暗红的汁液顺着他线条刚毅的下颌流淌，滴落在他漆黑的活体战甲上，迅速被吸收，让那战甲的颜色似乎变得更加幽深、更加……饥渴。</p><p>比起恶心、反胃，队长只觉得一股寒意从脚底板直冲天灵盖，连灵魂都在颤抖。</p><p>影子刚醒来的一趟。</p><p>他一睁眼就看见有个人形生物，在生啖异形。他认为是没睡够，于是彻底晕死过去。</p><p>杨帝生啖完整条哈基米。</p><p>天知道他的大胃袋藏在哪里。</p><p>“果然，与强者战斗才是进步的最快路径。”</p><p>“和这弱鸡喵喵打了半天，才堪堪提升到筑基期修士的中位数水准。”</p><p>“等等……”</p><p>“嗯？”</p><p>杨帝不可思议地看着自己的手。</p><p>他感觉到，自己的“精神”受到伤害。</p><p>再度回忆刚才生啖那只哈基米时的感受——它在死前的最后一刻，类似于“大脑”的思维器官突然爆发过载，温度骤升了至少20℃。</p><p>这是哈基米的……精神攻击？</p><p>不，不对，或者说，并不止是“精神攻击”这么简单。</p><p>“队长，我成功夺得了一部分摄像头的控制权限……”</p><p>“废话少说。”</p><p>“有……有大量的物体正在朝这边快速靠近，数量超过……200。”</p><p>如果每一只都有那“哈基米”的实力，他们现在该考虑的，是如何将自己的尸首安全保存。</p>
