# 般若波罗蜜

<p>杨帝回忆起他所看过的自然传奇走近科学探索发现，一个熠熠生辉的理论在大脑深处点亮。</p><p>“时间是一种幻觉。构成我们过往的每一个瞬间，都是并列的，同时存在的。</p><p>“所有在逻辑上可能出现的其他组合，也同样同时存在，不论它们是否遵循了那段历史的进程轨迹，也都同样存在着。</p><p>“我们所要做的，是要将既定的历史轨迹，从一条岔路抄出去，走向更好的未来。</p><p>“世上并没有无穷多个平行世界。真实存在的，仅仅是那些被我们弃置，或是被我们修改了的可能性。”</p><p>伊芙听着杨帝的讲述，眼中的忧虑似乎淡了几分。她轻声重复着：“时间是幻觉……”</p><p>世上一切糟透的事情，都已经“发生过了”。</p><p>但他们可以选择避开这些发生过的事情。</p><p>换句话说，因果律不存在，“因果”只是人们对事件发生顺序产生的幻觉。</p><p>只是人们从无数个离散的瞬间叠加之中，诞生的某种幻觉。</p><p>从这个意义上来说，“飞矢不动”才是世界的真实，其“运动”反而是世人的错觉。</p><p>同时，这也是杨帝所持有的世界观。</p><p>他曾在半年多前，生吃过几只被抽走“灵”的黑色物质。</p><p>吞下的一瞬之间，他短暂触及过宇宙另一副图景——没有被“灵”约束之时，万物所呈现出的极度混沌之本相：</p><p>物质，是概率海洋中的残影。规则，皆是人为设定的幻象。</p><p>谈及真实，它更像是无数个离散、破碎的瞬间，拼凑而成的虚假认知。</p><p>那是种难以言说的诡异。</p><p>假如有一片无穷无尽的沙漠，沙漠中的每一粒沙子，都代表着整个宇宙其中一种可能性的截图、快照。</p><p>选择特定的沙子串联起来，它就组成了我们的历史。</p><p>而这条由特定沙子串联起来的线，就是一条“世界线”。</p><p>杨帝缝合了泽利系列和命运石头门创造出来的理论。</p><p>伊芙不太理解，但表示大受震撼。</p><p>听了杨帝胡诌这么多，她心情也平静些许。</p><p>如果这个世界的真实面貌，远比简单的平行世界、自洽原理要复杂得多，那就不是她有资格担心的了。</p><p>这就是用“债多不压身”来缓解焦虑。</p><p>下一秒，他们就钻到一个坚硬的平台。</p><p>钻头与这“平台”接触，发出尖锐摩擦声，溅起串串火花，却难以再深入分毫。</p><p>杨帝皱起眉头，关闭了钻头，四周瞬间安静下来，只剩下他们急促的呼吸声，越来越远的嘈杂与轰鸣。</p><p>他们确实在四万年前的土地里，挖出了什么东西。</p><p>伊芙蹲下身子，用手轻轻抚摸着这块东西，触感冰凉且光滑，质地如金属。</p><p>表面有纹理，但分辨不出是什么工艺或者是材料所能留下的。</p><p>他们的极品附魔狱髓钻头，在这块金属材质的板上甚至连刮痕都没能留下。</p><p>要知道，就算是世上最坚硬的黑曜石，在这钻头面前也坚持不到3秒，便会分崩离析！</p><p>只有一种可能——它就是足以与原初之眼对抗的「无限机兵」。</p><p>“金枝纪元……确定是四万多年前？”</p><p>“我记得请！那是小学历史课42年级就开始教的内容，每个精灵都知道。”</p><p>“四十二年级……好吧，我是说，神话中谈到‘无限机兵’是四万年前的世人，为对抗原初之眼而制造的。”</p><p>“如果这就是‘机兵’，那它显然已在地下埋藏了许久……”</p><p>“……没错，它显然并不是被世人所制造出来的，至少，不是被这些很‘原始’的精灵所制造。”</p><p>一人一精灵坐在金属质感的平台上。</p><p>黑暗之中，只能面面相觑。</p><p>到了这一刻，他们才发现，自己不知如何驾驶机兵。</p><p>他们沿着平台转上好几圈，试了好几个中二动作和台词，一无所获。</p><p>伊芙还尝试了几个穿墙法术、土遁技巧，钻不进级别内部。</p><p>然后是透视、感知、甚至预言类法术……对机兵一概无用。</p><p>它就像块实心铁疙瘩，而伊芙和杨帝在这块铁疙瘩面前就是普通人。</p><p>他们没能力掰开铁块，看清楚它内部构造。</p><p>伊芙有些气馁，一屁股又坐回平台上，双手托腮，陷入沉思。</p><p>外界爆炸声愈发密集。</p><p>隆隆的声响已经近在咫尺。</p><p>原初之眼，不知祂是用何种方法穿越光阴，追踪二人，来到此处。</p><p>神话中提到：原初之眼同时存在于过去和现世，祂的“真身”一直待在主观意志诞生之刻，祂的肢体可以影响未来……</p><p>伊芙和杨帝看向狭窄洞口，洞口上方是愈发猩红的天空，炽热的气浪灌下。</p><p>这就是毁灭的前奏么？</p><p>没想到一番探寻，竟把这恶魔引到了这里。四万年前的生灵涂炭，难道是他们引起的……</p><p>因果就此形成闭环。</p><p>“一切都结束了么，时间将在此处走向尽头么，岁月迎来终焉了么，历史再无后续了么……”</p><p>杨帝拍了下大腿：“数学！”</p><p>伊芙刚开始犯文青病就被他打断。</p><p>精灵扭头，疑惑地摇摇耳朵：“什么数学？数学怎么了？”</p><p>杨帝大脑开始发烫，潜意识全功率运转：“‘机兵’不是这片大陆这个年代所能制造的，只能是超古代先贤，或外星文明所铸。而我们与他们很可能语言不通，甚至连生命形式与物质构成，都极可能大有不同。圣树提及，驾驶员会与机兵共享感官、同步思维，以此操控。如果我们要操纵他们制造的无限机兵，至少在思维层面，要达成最基本的一致……数学。”</p><p>数学是万物的语言。</p><p>只要涉及物质的构建与运动，就必然遵循数学规律。</p><p>圆的周长公式C=2πr，这是基于平面欧氏几何的必然。</p><p>“不，等等，不对……数学也仍然只是符号的排列，以此反映其背后的逻辑。而如果我没学杂，那么万物背后的逻辑，蕴藏于……虚境。”</p><p>异世界存在“虚境”这个东西。</p><p>相传，它蕴含世间万物最深层次的奥秘，是某种更高层次的理念世界。</p><p>在地球，哲学家可能会称之为“实在界”，并认为它处于人类语言和象征系统之外，是无法被直接感知和描述的真实存在，代表着绝对的、未经符号化的“真实”。</p><p>而在中土大陆，它居然还是个可以看得见、摸得着的地方。</p><p>从本质上说，虚境不是某个具体的地点，但可以用象征和隐喻来理解它——所以，最后还是把它比喻成一个“地方”便可。</p><p>如何抵达虚境，伊芙曾在数天前给出过答案——冥想。</p><p>这是个极度唯心的世界。在地球，人们通过外在的实践，用显微镜观测细胞，用望远镜丈量星河，用物质工具触碰真理，向外寻求万物的至道。</p><p>而在此处，精神意志本身就是凿开「虚境」的钥匙。</p>
