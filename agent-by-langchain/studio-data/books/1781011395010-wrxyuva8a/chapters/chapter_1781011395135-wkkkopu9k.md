# 复健计划·中

<p>杨帝立在星海中央，黑发逆着亿万星辰的光焰狂舞。</p><p>那道紫芒在他额角犁出的血痕，已在弹指之间凝结愈合。</p><p>「综合抗性+1」</p><p>鱼尊驾驭的巨蚌机甲轰然展开蚌壳，皮米模块如星河倒卷，在她身后聚成遮天蔽日的机械梭鱼阵！</p><p>每条梭鱼都是一门浮游炮，口径大得令人发指，足足2000毫米直径炮口！</p><p>齐齐锁定杨帝周身三百六十窍穴。</p><p>“轰隆！”</p><p>鱼尊机甲率先发难，幽蓝电弧织成的灭世光网裹着阿巴的怒吼，宛如星河崩塌，无数耀眼光束向着杨帝狂轰滥炸而去！</p><p>空间湮灭炮，将时空本身击碎，释放出真空中最底层最本质的能量——零点能。</p><p>真空中的零点能，能量密度堪称恐怖绝伦。</p><p>每立方厘米的空间内，所蕴含的零点能相当于将数千颗太阳同时压缩至极致后，所释放的能量总和。</p><p>零点能真空的基态涨落，是一种在微观层面涌动的、永不静止的能量海洋。</p><p>当空间湮灭炮激发零点能时，那一瞬间，仿佛宇宙的底层秩序被强行撕开一道口子。</p><p>零点能如汹涌的狂潮般喷薄而出，所过之处，一切物质与能量都被无情地扭曲、吞噬。</p><p>其能量密度之高，使周围时空像被高温炙烤的蜡像，以一种诡异而恐怖的方式剧烈变形。</p><p>“嗡——嗡——”</p><p>虽然真空不能传声，但众人都听见了时空本身破碎传来的濒死哀嚎。</p><p>整个宇宙仿佛都在这绚烂而恐怖的攻击下颤抖，星辰在光芒中黯然失色，时空被搅得支离破碎，蜷曲于微观的高维结构被展开。</p><p>那些向着杨帝射去的耀眼光束，本质便是被高度凝聚、定向引导的零点能。</p><p>每一道光束都蕴含着足以摧毁一个中等星系的能量，在真空中划出百万道扭曲的轨迹。</p><p>所经之处，空间像破碎的玻璃般纷纷瓦解，露出其后深邃无垠的“虚境”。</p><p>“有点意思。”杨帝的声音穿过能量乱流，平淡得像在点评一锅佛跳墙是否鲜美。</p><p>轰轰隆隆隆隆隆——！！</p><p>数以百万计的零点能浮游炮轰击在杨帝身上！！</p><p>鱼尊大喜：“中！”</p><p>“并非躲不开，而是如果任由这些射线在宇宙中驰骋，绝对会造成环境污染，伤到路边的花花草草，还有无辜文明。不过……”</p><p>杨帝看向身后。</p><p>他原以为那些守望者舰队是在防备他。</p><p>但猛然间，杨帝发现这些舰队还有另一项隐蔽的任务——</p><p>如果他选择了躲开，这些舰队就会将“零点能射线”抵挡住，不让其继续乱射，污染环境。</p><p>“有公德心，是好文明。”杨帝默默认可了。</p><p>硝烟渐渐散去。</p><p>鱼尊悬着的心一下子死了一半。她看见杨帝毫发无损。</p><p>“科技侧的攻击果然无卵用，还是得看我辈修士的灵能法术！”</p><p>在机甲加持下，阿巴周身灵能以300%倍率狂暴地涌动。</p><p>万千符文从鲈鱼躯壳迸发，在宇宙天幕织就血色星图，每一道纹路都吞吐着混沌雷光，竟将方圆百万里星云绞成液态光流，如亿万条火龙逆卷苍天！</p><p>鱼尊轻挑鳍尖，刹那间，机甲的蚌壳如遭无形巨力撕扯，骤然裂开千百道缝隙。</p><p>这一瞬，星海仿若被投入了一颗炽热的火种，瞬间似滚烫油锅沸腾起来，翻涌着令人胆寒的能量波澜。</p><p>“太乙仙术……”鱼尊的声音裹挟着无尽的力量与决然，在这浩瀚宇宙间震荡开来。</p><p>身为本宇宙有史以来最为强大的土著仙人，她的背后，亿万虚影如梦幻泡影般浮现。</p><p>宛如展开一卷横跨亿万年的史诗长轴。</p><p>有的是泛着磷光的银色鲈鱼群，鳞片折射着远古海洋的幽蓝。</p><p>有的是刚刚开化的精灵高举火把，火星飘入青铜铸就的器鼎。</p><p>更远处，智人将骨头抛向天空，便化作刺破大气层的钢铁巨舰。</p><p>千兆文明，亿万生灵。</p><p>目光与虚影，众生之愿力，汇聚于此……</p><p>恐龙灭绝时扬起的尘埃、超新星爆发的余晖、第一株植物进行光合作用的微光，所有生命在演化历程中迸发的精神火种，此刻都在鱼尊背后熔铸成流动的星河。</p><p>就连空间与时间本身，都在这威能下扭曲成螺旋状的火舌。</p><p>哦，时间。</p><p>鱼尊心头回忆起亿万年前的苍蓝海域。</p><p>她曾是条甩着尾巴啃珊瑚的小鲈鱼。</p><p>但她不普通——她能将“核辐射”当饭吃。</p><p>族老们挤在礁石缝隙间，目光紧紧锁住那小小的身影，浑浊的鱼眼里闪烁着如碎钻般熠熠生辉的期待：“阿巴，要做能跃过星海的鱼啊！”</p><p>彼时的阿巴，尚不懂得何为太乙仙术，亦不知大罗道果为何物。</p><p>她只是凭着一股执拗的劲儿，以最质朴笨拙的方式，不断吞吐着核辐射。</p><p>哪怕鳞片因辐射的高热而片片脱落，她也未曾有过片刻停歇。</p><p>她，是“月斑银鲈”族群独一无二的奇迹。</p><p>遭受核辐射的侵袭后，不仅顽强存活，还机缘巧合之下成功解开“基因锁”，就此踏上修仙的漫漫征途，成为族群中，亿万年来绝无仅有的存在。</p><p>后来，她被捕鱼船捞走。</p><p>被送到火箭里，打上了天。</p><p>阿巴因此接受了更大剂量的辐射。</p><p>她迈向星海……</p><p>她身后汇聚了亿万生灵的殷切期盼，跨越无尽时空而来的灼灼目光，亦如璀璨星辰，尽数聚焦在她身上。</p><p>——对对突破种族极限的期待，对走向星辰大海的渴望。</p><p>那些曾在苍蓝海域与她一同嬉戏的同族，大多已消逝在历史的长河中，化作点点星光，隐匿于岁月的深处。</p><p>然而，它们的期盼却是永不熄灭的火种，在阿巴心中熊熊燃烧，从未有过丝毫的黯淡。</p><p>阿巴不是为了自己而战，她肩负着整个族群的梦想与荣耀。</p><p>她肩负着碳基生命最伟大的愿望。</p><p>永无止境地进化，直至超越天地束缚，跳出残酷的自然法则。</p><p>让「生命」的光辉冲破宇宙间一切桎梏，绽放出最耀眼的烈芒！</p><p>你们……一直与我同在！</p><p>鱼尊周身的灵能愈发狂暴汹涌，如同一头挣脱千年牢笼的远古凶兽，以她为中心，向四周疯狂扩散。</p><p>法术强度，三千杼灵！</p><p>1杼=10^24。</p><p>“阿巴，要做能跃过星海的鱼啊！！”</p><p>由宇宙万象、亿兆生灵凝聚而成的虚影，碳基生命百亿年的期盼。</p><p>无数双手/肢体/鳍/鞭毛搭在她肩膀，无数目光祝福鱼尊。</p><p>宇宙生灵之愿力，信念，羁绊，推动着阿巴以三千杼倍光速疾行。</p><p>“大、荒、囚、天、鳍！！”</p><p>三千大道，亿万神通，由鱼尊与万族毕生信念凝聚而起的鳍影，如跨越次元的巨镰，裹挟本宇宙最庞然的愿力斩向杨帝！</p><p>战场上的物理规则寸寸崩断，灵能法则在这股力量前彻底失效。</p><p>宇宙根源的大道，都因为这一斩而发出恐怖嘶嚎！</p>
