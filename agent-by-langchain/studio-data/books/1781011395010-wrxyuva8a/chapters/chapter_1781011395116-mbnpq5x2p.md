# 机兵适配者

<p>“我可以将一定的质量，传送到某个地方。而那个地方，就是四万年前原初之战结束后，无限机兵的埋葬之地——这是那位机兵驾驶员，给我留下的……任务。”</p><p>圣树开门见山，语出惊人。</p><p>信息量极度爆炸，让人一下子感受到胜利的曙光！</p><p>但随即，谜团纷至沓来。</p><p>“我们？你要把我们都传送了？我们是指？”</p><p>“无限机兵怎么驾驶？”</p><p>“等等，所以那根本不是神话传说，而是实打实的历史……”</p><p>“现在除了圣树领地，外界全部都是熔岩史莱姆……即使能传送，也会被史莱姆淹没吧。”</p><p>“就连挤满熔岩史莱姆的地幔，都已经被原初之眼掌控，那么在哪里，还有祂没能发现的安全地带……”</p><p>“世上应该已无安全角落。”</p><p>“还有什么地方不在原处之眼的掌控之中……”</p><p>杨帝心有所感，望向天空。</p><p>高达在太空战斗，而颜面也能在星河之间中大战反螺旋族。</p><p>无限机兵，难道被放卫星打到了天上？</p><p>圣树却说：“并不是天空。机兵所在的安全地方……你们到达之后，自会明白了。</p><p>“你们二人需一同行动，只不过，最终只有一人驾驶机兵。</p><p>“无限机兵和原初之眼的战斗，都曾是真实历史，只不过真相早已埋葬在岁月的尘埃下。</p><p>“机兵的驾驶通过脑部精神活动操控，驾驶员会与机兵共享感官、同步思维。</p><p>“所以，驾驶机兵并不需要通过刻意的多年苦练，最重要是与机兵的适配度。</p><p>“驾驶机兵对驾驶员的素质有极高要求，希望……你们的意志足够坚定。”</p><p>圣树也把他们问出来的问题都回答了，没有当谜语人，谜语树。</p><p>只是，二人的困惑有减亦有增。</p><p>伊芙·柑橘没有拥护圣树的一切决定。她指向瑞弗维尔与奥拓：“瑞弗……他们，怎么办？”</p><p>“现世的精灵会照顾好二位客人。”</p><p>“为什么要我和杨帝一同去？只让机兵的‘适配者’去，不就可以了？”</p><p>“你们之中，有适配者。”圣树却说。</p><p>杨帝便问：“您为什么认为，在我们之中存在机兵适配者？适配者的条件是什么？”</p><p>圣树罕见地沉默了。</p><p>它似乎沉思了许久，也可能是在思考是否要全盘托出，还可能是在防备存在于万物、窥视着万物的“原初之眼”。</p><p>它给出一个模棱两可的答案。</p><p>圣树说：“适配者，必须能够适应、操控无限机兵搭载的所有功能。”</p><p>精灵和人类瞳孔一缩。</p><p>杨帝和伊芙同时明白了什么。</p><p>他们向对方看去，对过眼神，确认自己的猜测与对方相同。</p><p>伊芙深吸一气：“母亲，我问最后一个问题我能回来吗——我们还能回来吗？”</p><p>一阵凛冽的风掠过树梢，圣树枝叶发出沙沙声响，仿佛在回应伊芙的问题。</p><p>伊芙的发丝被风吹起，遮住她脸庞。</p><p>她望着在风中摇曳的圣树，蓦然觉得，守护了他们无数岁月的母亲，此刻竟显得如此孤独而苍老。</p><p>奇怪，很奇怪的感觉。</p><p>伊芙隐约有种预感，圣树知道些什么，但它不愿说出来。</p><p>既然它认为，不把隐情说出来对伊芙更好，那精灵也会欣然接受圣树的安排。</p><p>圣树终于在风中开口，声音随着风的呼啸忽远忽近：“取决于命运。”</p><p>它的答案非常模糊。与其说是答案，不如说更像是“判词”。</p><p>驾驶机兵的……会失去对命运的掌控？</p><p>取决于命运，命运。</p><p>命运就是世界线，就是既定的历史和既定的未来。</p><p>人有时候能够掌控命运，但更多时候，命运在他死亡那一刻便已决定，因为此刻，历史对他而言已是既定，而未来对他而言再无意义。</p><p>杨帝默默捏紧拳头。</p><p>伊芙：“我明白了。妈妈再给我些时间。”</p><p>她缓缓走向躺在轿厢座椅、仍在昏迷中的瑞弗维尔，指尖拂过他染血的鬓角。</p><p>精灵的神色平静得可怕，眼眸深处没有丝毫波澜，像是被冰封的古老湖泊，封印着岁月。</p><p>俯身而下，如春日的第一缕微风，在瑞弗维尔额头上轻轻一吻。未尽的话语和无法言说的情愫，在触及皮肤之瞬间化作诀别。</p><p>最后能否归来，也许只能听天由命。</p><p>命运指引少年少女去开机甲。</p><p>他们或许能为自己所爱之人创造奇迹，改变过去，开辟未来。</p><p>但在这最后一分钟，让我陪在你身边。</p><p>伊芙起身时，裙摆扫过地面的落叶，发出细微的声响。</p><p>她挺直脊背，缓步走到杨帝身旁。</p><p>伊芙转头看向杨帝，目光如淬了冰的利刃，却又在对视的瞬间泛起一丝不易察觉的温度。</p><p>“走吧。希望我们不会成为历史的尘埃。”</p><p>圣树的枝干开始随风摇曳。</p><p>在“传送”开始之前，杨帝心念一动，对圣树问了最后一个问题：“圣树，您知道‘耶罗大仙’这个名号么？”</p><p>圣树表情没有变化，语气也没有丝毫波动。</p><p>“我仅仅知晓这片大陆过去四万年的历史。”潜台词就是它不知道。</p><p>杨帝心底扬起淡淡的失落。</p><p>本期望圣树能知晓“耶罗大仙”的线索，为一直那个以来模糊不清的谜团，撕开一道哪怕极其细微的口子。</p><p>但那尊远在不知哪个次元的仙神，仿佛是缥缈于天际的幻影，无论杨帝如何努力追寻，始终难以捕捉到其分毫踪迹。</p><p>“那么，传送开始，做好准备。”</p><p>不论如何，杨帝现在只能遵从圣树的安排，试着去拯救世界。</p><p>圣树的树冠骤然迸发出璀璨光芒，枝干上的纹路如活物般扭动，整棵巨树发出古老而低沉的嗡鸣。</p><p>它正在施展某种传送法术。</p><p>“传送发生之后，原初之眼就会意识到我把你们送去了哪里。所以，你们要尽快行动。”</p><p>杨帝与伊芙脚下的地面泛起银色涟漪，像是平静湖面被投入巨石，层层叠叠的空间褶皱将二人包裹其中。</p><p>嗡——嗡——嗡——</p><p>杨帝和伊芙看向对方，他们发现对方，包括自己，身体都开始扭曲成面条。</p><p>如果将他们此刻的模样拍下来，那就是双倍的爱德华·蒙克画作《呐喊》。</p><p>一股无可抗拒的吸力将他们拽入光涡。</p><p>眼前世界开始扭曲变形，星辰倒悬，日月同辉，整个宇宙都在倒转，正片天地都在逆翻。</p><p>伊芙感觉自己的身体变得透明，能清晰看到血管中奔涌的血液，每一个细胞都在震颤。</p><p>支离破碎的画面如流沙般从身边掠过，她捕捉到转瞬即逝的画面：燃烧的大陆，血与沙的战场，万千世人的悲嚎……以及笼罩于万物之上的“眼”。</p><p>呼啸风声中，夹杂着无数细碎呢喃，像是岁月长河里千万生灵的低语。</p><p>岁月长河。</p><p>当光芒终于消散，两人踉跄着跌落在一片陌生的土地上。</p><p>“我们的猜测应该没错。”杨帝从地上爬起，望向四周陌生的环境。</p><p>伊芙点点头，拍拍身上的尘土：“没错，适配者‘必须能够适应操控无限机兵搭载的所有子系统’——所有子系统，包括时间机器。”</p><p>他们仍然在精灵的领地内。</p><p>只不过，现在是另一个时间。</p>
