# 旧人之死·第二卷终

<p>钓鱼佬将无名尸体、数十根舌头猫条一起，朝着电梯井的积水潭倒去。</p><p>“扑通”一声，水面溅起巨大的水花，随后又迅速恢复平静，仿佛什么都没有发生过。</p><p>杨帝看向电梯井上，垂下来的那只手。</p><p>它似乎也察觉到了杨帝的目光，微微颤抖了一下。</p><p>杨帝摇了摇头，轻声：“随便你。”</p><p>那手缓缓缩了回去，消失在黑暗中。它没有选择再拉一把，而是遵循了杨帝的意志。</p><p>钓鱼佬眸中烁着光，似乎是欣慰，叹息，与释然。</p><p>现在，他随时会被黑色水体对面的“那个东西”带走。</p><p>这也许，是钓鱼佬留在地球上的最后几分钟时间了。</p><p>他看向杨帝：“年轻人，你是怎么做到让舌头猫条重量不一样的，我可没留意到你有做什么小动作。”</p><p>杨帝想了想，从包中掏出一块砖头，抛给钓鱼佬：“掂量掂量，再给我。”</p><p>钓鱼佬接过，照做了。</p><p>而后杨帝重新拿回那块砖头，在手中摩挲了几秒，再度抛给钓鱼佬。</p><p>后者接过，顿时感觉不对。</p><p>“轻了一半？！”</p><p>“你可以理解为特异功能或者超能力……我能有限度地操控物质形态，还有念力、隔空取物、有限度地透视……等等。”</p><p>杨帝走上前，手指在砖头上轻轻一点。</p><p>砖头裂开，里面不知何时已经空心了。</p><p>它内部的物质已被掏空，被杨帝“隔空取物”走了。</p><p>钓鱼佬把砖头还给了他：“真厉害……果然我们还是有超能力者的，你是神州龙组？还是什么秘密部队……”</p><p>都不是。他摇摇头。</p><p>杨帝倚靠在墙边，吐了口气，仰头看向这孤独的烂尾楼。</p><p>“叔，我挺好奇的，你本科读的是新闻学，硕士却念了物理系，这转变跨度可不小啊？”</p><p>钓鱼佬微微一愣，随即陷入回忆。</p><p>他缓缓说道：“哎，这说来话长啊。我读新闻学那会，越是深入学习，就越发现自己很难做到绝对客观公正。</p><p>“你知道，在人文社科领域，无论你怎么努力，都难免会受到个人情感、价值观、社会背景这些因素的影响。</p><p>“就拿写报道来说吧，同样一件事，不同的记者从不同的角度去写，呈现出来的内容可能大相径庭。</p><p>“比如，科学家的观点是‘末日逼近’，而媒体则会截取事实，拼造观点，让人们只能看见中间那两个字。</p><p>“哪怕你力求公正，可字里行间还是会不自觉地透露出自己的倾向。</p><p>“这让我很苦恼，感觉自己像是被困在一个无形牢笼里，无法真正触及到事实的本质。”</p><p>他停顿了一下，目光变得深邃，似乎在思索着过往的种种。</p><p>“后来接触到理科，我发现完全不一样。理科的世界是那么清晰、纯粹，它可以做到比人文更公正客观。</p><p>“就像物理定律，无论在何时何地，对任何人来说都是一样的，不受主观因素的干扰。</p><p>“只要你遵循规律，用正确的方法去研究，得出的结论基本是准确无误的。</p><p>“这种确定性和纯粹性深深地吸引了我，所以我决定转专业，去探寻那个绝对理性、客观的世界。”</p><p>但“理性客观”的现实，似乎并不稳固……</p><p>钓鱼佬坐在他的钓鱼凳上。</p><p>他最后一次，用冷水冲了杯速溶奶茶。</p><p>叹了一口，钓鱼佬说：“杨帝，双修了新闻学和物理学，我现在有了个最大的感悟：天地不仁，以万物为刍狗；圣人不仁，以百姓为刍狗——万类平等，这是天地和圣人，对万物与百姓最大的仁慈……”</p><p>噗——通——</p><p>钓鱼佬消失了。</p><p>他被某种力量拖进黑水潭里，他实现了自己的梦想。</p><p>那只手又从电梯井偷偷探了下来，只露出两个指头，似是在窥视杨帝。</p><p>杨帝没有理它，而是坐在电梯井前，看着水面。</p><p>此刻，烂尾楼里陷入一种近乎死寂的静谧。</p><p>那声“扑通”被这寂静瞬间吞噬，没有留下丝毫余音。</p><p>杨帝依旧倚靠在墙边。刚刚钓鱼佬所在的位置，人已消失得无影无踪。</p><p>他在这栋烂尾楼里，完全感受不到第二个人的气息了。</p><p>周围的空气仿佛凝固一般，没有一丝流动，墙中老鼠那令人烦躁的叫声也戛然而止。</p><p>他沉溺入思考。</p><p>在不可名状的道路上越奔越远，他也终究会遇到这样的问题——如何界定对普通人的干涉是好或坏？</p><p>最优的选择，恰如钓鱼佬所说，大概就是——什么都不做。</p><p>为无为，事无事，味无味。</p><p>钓鱼佬认为，自然科学，有幸拥有一位永恒冷漠的无言裁判——大自然。</p><p>就算有狂妄之徒对“重力”横加指责，大自然也不会因此违背自己的法则，不会让那些人真的在空中自由地翻转、游泳。</p><p>而人文科学的脚踝，始终站在悬垂的钢丝上。它会因价值判断、人的思想、物质利益，而左右摇摆不定。</p><p>若有乌合之众对今年的财政支出指指点点，那么“事实”也会为之改变。</p><p>无法做到绝对客观。</p><p>没有一个绝对客观的裁判，能够为善恶、正邪、美丑，做出绝对公正的判决。</p><p>这就是为什么，杨帝不再阻止钓鱼佬。</p><p>天以万物为刍狗，刍狗陈于祭坛，非天地弃之，亦非天地贵之。</p><p>风雨摧折桃李，非天有怒。霜雪润泽松柏，非天存仁。大道如川谷，任万物自涌自息。</p><p>至人观世犹观云，见其聚散而无喜悲。</p><p>杨帝正式向“强者”的境界迈出第一步。</p><p>或许在外人看来，他会变成个冷血的混蛋，无情的数值怪。</p><p>……对，数值怪。</p><p>这真是个适合用来描述他自己的名词啊。</p><p>所谓“数值怪”，是对一种极致功绩主义的比喻。</p><p>电子游戏或数学模型中，一切都以精确的数值来衡量和判断，不掺杂任何多余的情感与主观臆断。</p><p>人的各项属性，皆可以数值加以量化。</p><p>只不过，对现实来说，属性数值是有增长上限的。</p><p>凡人的进步曲线，也是一条最初上升很快，而后进步放缓，最终会收敛到极限的渐进线。</p><p>就如同数学中的级数概念，普通人的成长恰似几何级数 1+1/2+1/4+1/8+…</p><p>这个级数是有上限的，最终结果等于2。</p><p>而对于杨帝、对于数值怪而言，属性数值不应该有增长上限！</p><p>尽管他的进步速度也会放缓，但增长曲线最终会发散至无穷大！</p><p>他的进步轨迹更像是调和级数 1+1/2+1/3+1/4+…</p><p>虽然从表面上看，每一项的增长幅度逐渐变小，进步速度也会放缓，如同普通人成长过程中的瓶颈期。</p><p>但是，1+1/2+1/3+1/4+…+1/n 最终会趋于无穷大。</p><p>杨帝可能会有暂时的瓶颈，却永远不会有停滞下来的尽头、上限。</p><p>今日，随着钓鱼佬的消失，随着他在这诡异烂尾楼中的种种经历，旧的杨帝死去。</p><p>旧人已死。</p><p>曾经的杨帝或许还会被世俗的情感、常规的道德观念所束缚。</p><p>自我之下，众生平等，不问红尘。</p><p>自我之上，杨帝曰斩！</p><p>（PS
