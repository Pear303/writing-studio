# 毕生之敌·第一卷终

<p>存储在银行数据库的银行卡信息、政府部门里的个人身份、稷海理工存储的学生信息、社交平台上的账号……</p><p>烟消云散。</p><p>现在，杨帝连路边买一瓶水都难，因为他身上没带现金。</p><p>他曾经拥有过的现金，因为没有带在身上，所以被一并删除了。</p><p>他打算跑步。跑步回家。</p><p>沿着公路边缘跑，晨雾在他身后渐渐消散，春日的阳光平铺在马路上，像撒了一把温热的碎金。</p><p>杨帝数着自己的呼吸。</p><p>一呼一吸，路边香樟树一棵棵向后退去。</p><p>起初还能看见三三两两的行人和车辆，后来道路愈发空旷，只剩下偶尔掠过的卡车，卷起一阵带着柴油味的风。</p><p>家在稷海市城郊，距离学校50公里开外，比马拉松还要长，和开汽修店的中学同学差不多地方。</p><p>日头升到中天时，杨帝拐进一条熟悉的乡间小路。</p><p>路旁的油菜花已经结籽，豆荚在风中轻轻摇晃。</p><p>远处的山峦蒙着一层淡蓝色的雾霭，山脚下那栋白墙黛瓦的老屋，是他从小长大的地方。</p><p>记忆中，母亲总在院子里晾衣服，父亲会在门口修理农机。</p><p>老妈下班，有时会带几个厂里新研制、比史莱姆还恶心的糕点。</p><p>老爸农闲，有时会瞒着妈，偷偷带杨帝去鱼塘钓鳖，摘些艾草和五指毛桃。</p><p>他绕到屋后，推开那扇略朽的木门。</p><p>门后庭院，葡萄架早已坍塌，藤蔓纠缠着堆成乱麻。</p><p>他能看出来，院子里虽杂草丛生，但门窗紧闭，室内布局整洁。</p><p>生活器具比记忆中少了很多。</p><p>四处蒙上一层厚尘，但有些东西尘很薄——它们被动过，比如镰刀、锄头和水鞋。</p><p>上个月清明，爸妈应该回来拜山祭祖过。</p><p>他们可能已经搬家，住到另一个地方，所以这里荒废而略显破败。</p><p>这座老房子便这样空置出来了。</p><p>他能通过蛛丝马迹推断出来，家里人都还安好。</p><p>杨帝想到：既然他原本在学校的身份，被另一个黑框眼镜理工青年替代，那么他在家庭里的身份，也会被另一人代替吧？</p><p>爸妈也许会忘记自己的杨帝。他们也许会有个女儿，或者新的儿子。</p><p>如果，杨帝再出现在爸妈面前，他们也大概率不会认识他了。</p><p>他坐在门槛上，直到暮色渐浓，望着天际最后一抹晚霞褪去。</p><p>夕阳的余晖洒落睫毛，他想起七岁那年，父亲用竹篾给他扎了个蝴蝶风筝，就在这个院子里。</p><p>那时的风也是这样暖，蒲公英种子乘着风掠过他鼻尖，痒痒的，他笑出了眼泪。</p><p>288亿比特。</p><p>18亿个汉字。</p><p>这是从他告别稷海理工、到现在晚霞褪去这一刻，思维之中所流转过的信息量。</p><p>《四库全书》囊括乾隆中期以前，神州历代主要典籍，涵盖了古代神州几乎所有学术领域，但总字数也才8亿个汉字。</p><p>杨帝几乎已经感受和体验过——潜意识中每一束最幽微、最细腻的情感。</p><p>他今日半天所思考的总量和质量，几乎是一个文豪一生思索的总和。</p><p>心智被海量恐怖的资讯填充。</p><p>杨帝在短短几分钟内走向成熟，随后数个小时的思想分裂，最后开始返璞归真。</p><p>就像完成了从青年，中年，老人，最后到小孩的转变。</p><p>他像个小孩一样躺在地上哭起来。</p><p>哭累了，杨帝在门槛上蜷成一团，意识像书页般轻轻合拢，进入梦乡。</p><p>……</p><p>图书馆的穹顶悬着无数盏煤油灯，光线在无数排书架间流淌成河。</p><p>老人背着手，立在书架中央，银白的胡须垂落在深色正装上，双眸深不见底。</p><p>这次不是博尔赫斯，也非甘道夫，而是另一个老人。</p><p>“年轻人，又见面了！”</p><p>“老人家，您又有什么建议给我？”</p><p>“不错，你听我同你分析。天下本无路，走的人多了，就成了路嘛。耶罗大仙看起来高不可攀，但你只要拿出狠劲，总有一天找到它。你有个线索‘卡耳叩山’，就是陈昭无意识中唱出来的地名。”</p><p>“可是耶罗大仙太强大了。”</p><p>“它看似张牙舞爪，实则是泥足巨人。你观察过没有？它的攻击看似凶猛，甚至杀不死你，徒徒增加你的‘崩坏抗性’和‘精神属性’。最后也只能把你存在过的痕迹给抹掉，做不到别的了，恰恰说明它本质的虚弱。”</p><p>“虽然祂攻击对我无效，但我的攻击也伤不到祂吧？”</p><p>“事物是会变化发展的，要用发展的眼光看问题嘛。从今往后，你可能会遇上更多不可名状生物，你可能会碰见更多危险，你要把它们当作磨刀石，把自己炼得更加锋利！记住，胜利永远属于善斗争的人。”</p><p>“锻炼，变强吗……”</p><p>“仅仅半日过去，你如今胸中装着18亿汉字的智慧。假以时日，难道还怕这区区妖孽？”</p><p>“卡耳叩山……耶罗大仙……”</p><p>“你要抓住事物的本质，抓住它隐藏于庞大与嚣张之下的微小裂痕……”</p><p>……</p><p>杨帝在门槛上猛地惊醒，晨露顺着屋檐滴落，在他脸上凝成冰凉的水珠。</p><p>居然已是第二日朝晨。</p><p>还未睁眼，资讯和信息似氢弹爆炸劈头盖脸砸来。</p><p>杨帝只能闭着眼，紧皱眉，躺了两个钟头，才稍稍缓解不适。</p><p>他身为普通人二十多年，而开发10%潜意识不过短短一天。</p><p>尽管这一天以内的所思所想，超过了过去20多年的总和。</p><p>但杨帝仍需要适应。</p><p>他过去所构建起来的全部思维结构，人格三观，经验总结……绝大部分都已不再适用。</p><p>他必须重新整理记忆，重新总结经验，甚至重新协调身体动作。</p><p>「我们，还会再见面。」</p><p>那句话又一度在耳畔炸响。</p><p>我们还会再见面的……耶罗大仙，或者说——黄衣之王，我会将我的挚友夺回来，我会将我的身份夺回来，我会将你所吞噬的“意义”重新吐出来。</p><p>「■■■■■■。」</p><p>你在说什么，为什么那几个词会被屏蔽……</p><p>「时间已到，你该回了。」</p><p>也就是说，你位处一个很久远的地方。</p><p>你距离这个地球，距离我们的宇宙，距离我们的次元——太过遥远。</p><p>你只能有限地干涉我们的世界，你可以吞食我存在过的证明，但你杀不死我本身。</p><p>我会重新找到你。</p><p>我的进步能力没有上限，终有一天，我也会进化成无可名状的地步。</p><p>“我要杀了你，耶罗。”</p><p>（第一卷-耶罗之阴霾-终）</p><p>（原本是打算起手孤儿院开局，杨帝就能名正言顺一个人去闯都市传说，探访鬼屋怪谈，不被生前身后事所牵挂。）</p><p>（但后来想想，整天孤儿开局，寓意貌似不太好吧，不够吉祥awa）</p><p>（正好，写着写着，突然发现胡彦卓和希夷真的很难活下来，毕竟是直面耶罗大仙。私密马赛了qwq，就让友人代替爸妈走一趟吧。）</p><p>（看到这，大伙应该也都心知肚明“耶罗大仙”是哪个地方冒出来的产物了——非常美味非常新鲜的，海鲜！）</p><p>（宇宙对人类最深邃的慈悲，恰是将真理永远封存在认知彼岸。我们像蒙着纱幔的盲者，蜷缩在无知的孤岛，深渊近在咫尺，却感受不到波涛之下翻涌的恶意。）</p><p>（感受过世界之下翻涌的恶意，而仍然存活的幸运儿，再也无法回到平凡的日常中去了。）</p><p>贪狼钓渊（52-73）</p>
