# 诅咒

<p>被“绑定诅咒”之物纠缠的摸金校尉发丘将军搬山道人卸岭力士们，很久前就发现了一件事：</p><p>可以用8192倍溢价的货币买下被诅咒之物；也可以用8192倍溢价的实物进行交换。</p><p>两种方法，都能够摆脱绑定诅咒。</p><p>他们还意识到另一件事：</p><p>“绑定诅咒”之物的价格，以圣古琉斯王城市场价为准，不以个人意志为转移。</p><p>而“以物易物”中的两个“物”，也都是以圣古琉斯王城市场价为准。</p><p>“也就是说，冥冥中，会判定‘砾石镇地皮价格与圣古琉斯王城的地皮价格一样’。”</p><p>奥拓说着，看了看其他人。</p><p>他爸眼睛瞪圆，紧盯桌上的锡壶。</p><p>无人打断，他便继续说道：</p><p>“圣古琉斯王城大集市-中央广场，每平米的地价50000铜，王城的地产商连石头缝都能炒出不知多少倍溢价！</p><p>“铁匠铺占地约120平米，再加上附带建筑铁匠铺子，这片地的总价格如果以‘圣古琉斯王城大集市’的市场价为基准，差不多有700万铜。</p><p>“货币是商品内在价值的社会表现形式。我用地契的‘虚拟资本’属性，让诅咒误判这张纸承载着8192倍贝斯价格……”</p><p>刚好够赎买他爹的贝斯。</p><p>铁匠是较为低等的职业，但铁匠一般比较有钱，比如说一整间铁匠铺。</p><p>奥拓把地契占为己有，居然被判定成占据了整间铁匠铺。</p><p>然后用地契换走他爸的贝斯。</p><p>瑞弗维尔扫视奥拓一圈：“但当天我们发现你开始，你身上都没有带着贝斯……”</p><p>“没错，我先把它放在铁熔堡某王室成员的卧室，然后在仓库偷走价格650万的财宝，完成形式上的交易。最后重新将财宝重新‘赠与’王室，完成全流程。”</p><p>诅咒之物，被奥拓转移到铁熔堡的矮人王室了。</p><p>“……臭小子，你还偷了我的地契？”</p><p>“我已经还给你了老爸，就放在老地方。”</p><p>老矮人在老地方（一个非常有21世纪华夏月饼盒风格的小盒子）找回了那张纸，。</p><p>他充血的眼球死死盯着那张地契。</p><p>作为被诅咒者，奥拓老爸一个月前就清晰感知到，缠绕在自己身上的黏性的诅咒怦然消散。</p><p>同一时刻，犬子不辞而别。</p><p>直到今天他才明白，奥拓到底做了什么。</p><p>老矮人抄起茶壶：“臭小子，未经我允许，竟敢把我的贝斯抢走！”</p><p>奥拓躲闪：“我知道你从来不喜欢弹贝斯！因为你耳背，根本听不到它的声音！”</p><p>“什么？你说什么？什么背？听什么声音？”</p><p>“……没有，我什么都没说。”</p><p>老矮人常年打铁，靠近大熔炉工作，和许多重工业工人一样，视力听力都受到很大损害。</p><p>奥拓换了更洪亮的声音：“爸，我是说，摆脱了绑定诅咒，你不开心嘛。整天有一挺贝斯傍身，不会觉得很不方便嘛。”</p><p>老人这次听清了，他点点头，默认了奥拓的说法。</p><p>确实很不方便，比如他打铁时，手上的锻锤莫名其妙就变成贝斯了。</p><p>虽然绑定诅咒之物坚不可摧，无法损坏，但贝斯和锻锤比起来，还是太软，形状也不够优异，打铁效果非常差。</p><p>后来，这件乐器在一起的时间太久，日久生情，甚至每当有客人来，还会弹两首小曲。</p><p>但有朝一日能摆脱，他内心深处也有几分如释重负。</p><p>“奥拓你个混球……”老矮人声音略微哽咽，却带着重获新生的畅快。</p><p>父子相拥，但瑞弗维尔只感到惊悚。</p><p>什么叫“放在铁熔堡某王室成员的卧室”？什么叫“在仓库偷走价格650万的财宝”？</p><p>为什么从你嘴里说出来会这么轻松啊喂！</p><p>杨帝和伊芙则更注重这件事情的处理方式和思维模式。</p><p>精灵小声说：“你知道‘金融’吧？”</p><p>杨帝微愣，随即点点头。</p><p>他原以为金融是现代才会有的产业，但在脑海中迅速翻阅关于中世纪相关的书籍后，才明白银行、保险、汇票和信贷也算是金融。</p><p>在地球中世纪就已经出现了。</p><p>伊芙：“没错，圣古琉斯那边的人类最近几百年发明了叫做‘金融’的东西，具体原理我不是很懂，但它可以空手套白狼，让一种原本没那么值钱的东西，身价飙升几十倍，几百倍。”</p><p>这就是种无中生有的手段。</p><p>在这种唯心的世界，“无中生有”能够通过灵能，对世界产生更明显的影响。</p><p>比如绕过判定，钻空子解除诅咒。</p><p>“唉，好了奥拓，你做过的事我都不追究，现在咱好好……”</p><p>老矮人顿住，不做言语。</p><p>他粗糙的手指刚触到奥拓外衣下摆，像被火舌燎到般缩了回来。</p><p>“奥拓……这是什么？”</p><p>奥拓身体僵住：“爸，你听我解释……”</p><p>老矮人瞪大浑浊的蓝眼睛，死死盯着儿子腰间凸起的形状，鼻孔翕动，仿佛要喷出火星。</p><p>“你！”他铁钳般的手掌扯开奥拓外套，露出衣服下的木镐。</p><p>奥拓之前一直在保养的木镐。</p><p>他爹浑身发抖，“既然有机会，为什么不把你该死的木镐也摆脱了？！”</p><p>“原来这木镐是奥拓的绑定诅咒之物！”瑞弗维尔比在场其他人加起来还要惊讶。</p><p>所以，这支木镐永远不脱奥拓之手。</p><p>不是他不想，而是不能。</p><p>奥拓苦涩道：“爸，我跟你说过我喜欢这个镐子，并非虚言。”</p><p>老矮人颤抖着质问：“为什么你喜欢这木镐？它可是被诅咒的东西！你生活上感觉不到不方便？”</p><p>奥拓不语，只是低垂着头。</p><p>老矮人见他这般沉默，愤怒更甚，大声吼道：“你就和你的木镐过一辈子去吧！”</p><p>他喘着粗气，胸膛剧烈起伏，显然是气得不轻。</p><p>瑞弗维尔见状，赶忙上前打圆场：“前辈，您先消消气。奥拓这么做，说不定有他自己的苦衷。我看他经常保养自己的木镐，想必是很喜欢……”</p><p>老矮人有了台阶下，叹口气：“奥拓他就是太年轻，有一份摆脱诅咒的机会在面前，他不好好珍惜。我年少时也同样轻狂，觉得一挺贝斯背在身上，还挺有范……直到我被颈椎病和高低肩击败……而且每年阴雨天，都会肩周炎发作，现在还有略微腰间盘突出……这都是常年累月背着一挺贝斯，而落下的病根……”</p><p>“等等。”打断话题的人是伊芙。</p><p>她问，“奥拓他很年轻吗？冒昧问问，他几岁了？”</p><p>“嗯，上个月前刚满十八。”</p><p>这踏马十八岁！杨帝心底响起了张麻子的声音。</p><p>矮人真是显老，估计他们刚生出来的时候，就已经有而立之年的脸了。</p><p>瑞弗维尔以他“被丢进宫斗小说连三行都活不过去”的情商，根本没有注意到奥拓父子之间的尴尬。</p><p>他只是拍拍18岁奥拓的肩：“告诉你父亲为什么要留下这柄木镐，我想他会理解的。”</p><p>但这一次，瑞弗维尔的话奏效了。</p><p>真诚永远是必杀技啊。</p><p>奥拓斟酌着用词，嚅嗫道：“爸，我要做考古学家，没错也是挖坟的。”</p><p>老矮人听到这话，像是被抽走浑身力气，整个人瞬间萎靡下来，仿佛一下子老了十岁。</p>
