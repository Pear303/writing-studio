# 两脚兽与哈基米

<p>他们穿着完全不像地下巢穴白大褂的衣服，花花绿绿，布料粗糙厚实，但沾着干涸的深色污渍。</p><p>“污渍”——其实是米老头的动漫画像，但在哈基米的认知里，那是各种难以分辨的陈旧血迹和泥土。</p><p>他们动作敏捷，迅速占据了走廊的几个关键位置，动作熟练得不像第一次来。</p><p>“妈的，这么多爬梯！这是地下多深呐？”一个块头最大、像座移动小山的两脚兽，低声咒骂着。</p><p>他声音嗡嗡的，震得哈基米贴着的管道壁都在微微发颤。</p><p>他粗壮的手臂裸露在外，肌肉虬结得如同老树根，上面布满狰狞的旧伤疤。</p><p>大块头两脚兽烦躁地活动了一下脖子，发出“咔吧”的脆响。</p><p>哈基米能嗅到从他身上散发出类似钢铁和火药混合的浓烈气息，还有力量感。</p><p>此外，大块头两脚兽扛着一根闪着冰冷金属光泽的棒子（不锈钢狼牙棒），棒子上还残留着可疑的暗红色。</p><p>“闭嘴，铁砣！集中精神！”</p><p>另一个声音响起，冰冷，平稳，带着不容置疑的权威。</p><p>这回，说话的两脚兽身材修长，站在队伍稍前的位置，眼神锐利如鹰隼，快速扫视着四周。</p><p>他穿着深色的作战服，体表似乎有一层极其微弱的流光，在应急红灯下掠过。</p><p>哈基米看到，他脚边几粒散落的金属碎片，正违反重力地微微悬浮起来，围绕着他的脚踝缓缓旋转。</p><p>这个两脚兽身上，没有浓烈的气味，反而有种奇怪的“干净”感。</p><p>是只干净的两脚兽。</p><p>仿佛周围污浊的空气，都被无形的力量推开了一点点。</p><p>另外还有两个两脚兽。</p><p>一个是鼻梁上架着发光圆片（战术目镜）的瘦小两脚兽，手腕上戴着一个不断闪烁微光的金属环。</p><p>另一个是红色长毛发的两脚兽。</p><p>后者身上的气味最复杂，有哈基米前主人给它洗澡的硫磺皂的刺鼻，还有烧焦自己毛发时的焦糊味。</p><p>干净的两脚兽突然停下。</p><p>他猛地转头，看向天花板上的通风管道。</p><p>哈基米赶紧往回缩了缩，野兽的本能让你不敢哈气。</p><p>红毛两脚兽问：“老大，发现什么了？”</p><p>干净两脚兽：“……摄像头，它仍然在工作，始终在追踪我们四人。”</p><p>“因为这摄像头是运动传感式的。”瘦小的两脚兽说道。</p><p>“好吧。”那个干净的两脚兽再次开口，声音压得更低。</p><p>他的目光锐利地扫过血红色的走廊，最后定格在第十三实验室那扇紧闭的，闪烁着危险红光的合金气密门上。</p><p>“这次的任务目标很模糊——阻止什么大屠杀。但这次的副本极度逆天，居然是S级。</p><p>“所以按照惯例，我们不以‘完成任务’作为第一要求，我们的第一目标是‘苟活’。</p><p>“在今天之前，我们遇到过最艰难的任务，也只是堪堪B级副本。而现在一下子跳到S级。</p><p>“SB，诶，真是SB，副本任务难度宽度竟然这么大……沟槽的主神。</p><p>“总之，努力苟活下来吧。碰上你们几个这样的队友，定是我上辈子救过江洋大盗。</p><p>“不过，如果还有下辈子，我也不是不能和你们继续组队……扯远了。</p><p>“现在我们的目标是，找到一处尽量安全的房间，然后苟在里边。</p><p>“按照经验，我们的出生点都非常不安全，必须尽快离开此处。</p><p>“铁砣，准备破门。火鸦，警戒，任何移动的东西，烧成灰。眼镜，看好摄像头。我总觉得摄像头后面有东西。影子，你……”</p><p>队长的目光投向走廊一处看似空无一物的阴影角落。</p><p>哈基米的竖瞳猛地收缩了一下！</p><p>它刚才根本没注意到那里还有东西！</p><p>在它的视野里，那角落的阴影似乎比其他地方更“浓”一点，像一团凝固的墨汁。</p><p>当队长目光扫过去时，那团“墨汁”极其轻微地晃动了一下，一个低沉得几乎融入背景噪音的声音才传来：</p><p>“在。里面……很安静。室内无热源。但有东西……在动。很小，很快……在上面，通风管道里边……”</p><p>声音带着非人的空洞感。谁又能想到，这个声音的源头是个可爱的女孩纸？</p><p>哈基米的尾巴尖瞬间炸毛！</p><p>一股冰冷的战栗顺着它的脊背窜上来！</p><p>那个声音指向的……正是它自己藏身的通风管道。</p><p>那个叫“影子”的两脚兽发现了它。</p><p>它几乎是本能地想要后退，缩进管道更深处的黑暗里。</p><p>但就在它肌肉绷紧的刹那，一股更庞大更无形更令人窒息的压迫感，骤然降临！</p><p>哈基米动弹不得。</p><p>它被一股无形的念力，硬生生拉扯出了通风管道。</p><p>它看到那个干净的两脚兽，手如鹰爪，似乎隔空掐着自己的猫喉咙。</p><p>事实上，哈基米确实感觉到窒息。</p><p>“原来是圆头猫啊，我还以为是苦力怕呢。”</p><p>“嘬嘬嘬，咪咪过来给我摸摸头。”</p><p>“分析显示这只猫已经超过20小时未进食。”</p><p>饥饿感早已被猫猫抛到九霄云外。</p><p>食物来源于两角兽，但眼前的两角兽不太好惹。</p><p>铁砣——那个肌肉虬结的大块头——烦躁地挠了挠满是疤痕的光头：“搞快点队长，这鬼地方多待一秒都晦气！”</p><p>“我知道，待我用念力刺探情报。”</p><p>队长没理会他们。</p><p>他那双冰冷的眼睛死死盯着悬在半空，因恐惧而微微抽搐的哈基米。</p><p>哈基米感觉到，那股无形的力量不再是单纯的禁锢，而是变成了一种带着强烈目的性的冰冷探针，粗暴地刺入它的意识深处。</p><p>探针翻搅着它过去十几个小时的记忆碎片。</p><p>通风管道冰冷的触感、空气中残留的甜腻毒气味道、下方实验室刺眼的红光、沉重的落锁声……</p><p>还有，就在它疯狂逃窜、爪子扒开管道壁隔热板之前。</p><p>它那视野放大的猫眼，似乎瞥见了下方第十三实验室（在猫混乱的认知里，是那个充满死亡红光的可怕房间）气密门旁边，某个不起眼的角落……</p><p>金属墙壁上，有一个密码输入框。</p><p>那是20小时前的记忆。</p><p>在红光疯狂闪烁，淡紫色毒气刚刚喷涌，鲍勃发出绝望嚎叫时，一个穿着白大褂、半边脸已经开始不正常扭曲的两脚兽——亚当，踉踉跄跄走到门前，试图在门上输入密码开门逃出。</p><p>他失败了。门没有开。</p><p>但他输入密码的顺序留在了猫脑中。</p><p>哈基米当时只顾逃命，根本没在意。</p><p>但现在，这个密码，被队长用念动力从它的记忆里硬生生“抠”了出来。</p><p>“R…7…L…K…G…8…”队长/干净的两脚兽嘴唇微动，无声念出被猫眼记录下来的字符串。</p><p>他眼中闪过一丝了然，随即是更深的凝重。</p><p>“嘁，还真有密码？”</p><p>铁砣扛着狼牙棒，一脸不可思议，“队长你这念力也太万能了吧？下次缺钱是不是能直接让‘主神商店’吐钞票？”</p><p>“不可以，因为我打不过主神。”</p><p>队长说道，隔空抓着哈基米的力量一松。</p><p>橘猫像块破布一样“啪叽”掉在冰冷的金属走廊上。</p><p>但因为“猫猫四脚优先着地”定律，它并没有摔个七荤八素。</p><p>哈基米哈了两声气，蜷缩在角落。</p><p>毕竟这几个人，是它目前见过活蹦乱跳的两脚兽、唯一的希望了。</p><p>食物，都来自两脚兽。</p><p>队长不看它，径直走到第十三实验室，那扇闪烁着不祥红光的合金气密门前。</p><p>“R…7…L…K…G…8…”</p>
