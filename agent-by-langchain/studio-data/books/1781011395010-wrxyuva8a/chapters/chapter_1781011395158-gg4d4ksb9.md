# 魔道修士的阴谋？

<p>啪。极其轻微的“脆响”几乎同时响起。</p><p>杨帝的右手，那刚刚捏爆了域外天魔、转动百万亿磁力线的拳头，此刻正拍在自己的大腿外侧。</p><p>不是懊恼，而是思路被打通、关键齿轮严丝合缝卡入凹槽时，近乎本能的确认动作。</p><p>他一拍大腿：“我也明白了。”</p><p>几乎在同一毫秒，59改某个关节部位也发出了一声极其短暂、如同精密齿轮咬合到位的细微金属撞击音。</p><p>他构成手臂的冯诺依曼自动机群一阵高速流转，变形重组，凝聚成极其拟人化的“拍大腿”动作——无数细小的金属单元精密堆叠，模拟出大腿轮廓，另一只“手”干脆利落地“啪”一下拍了上去。</p><p>他也拍了一下大腿。</p><p>「二位言之有理，是在下考虑不周，误入思维盲区。」</p><p>阿巴一头雾水，两头雾水，亿头雾水。</p><p>她也想一拍大腿，醍醐灌顶，但怎么都想不明白。</p><p>她脑瓜里塞满“槐安1644”、“阴伏流煞”、“归墟大帝喝水”和“数字生命自杀”这些碎片，像一锅煮糊的鱼汤，黏糊糊分不清东西南北。</p><p>“想到啥了？是不是想到那凉茶铺老板其实是域外天魔变的？我就说他卖的水有问题！”</p><p>59改说话，带着一种洞悉本质的平静：</p><p>「青丘白璃、白杨大帝阁下的兴奋点与本机及杨帝阁下的逻辑同步点高度重合。」</p><p>「其核心信息均指向槐安1644年阴伏流煞爆发事件，地点与归墟大帝失踪点重合。」</p><p>「本机数据库对比分析完成。凡界王朝在虚拟现实技术领域，其沉浸度、信息丰度及环境交互拟真度，已逼近甚至局部超越部分同级别星际文明的标准。」</p><p>「那么，完全无需进行时间穿越。」</p><p>「只需构建一个以‘槐安1644年君士叹顶堡郊野凉茶铺’为核心场景的超高精度虚拟现实‘沙盒’。」</p><p>「这能够解释为何在十万大山乃至整个凡界的史书、县志，都完全找不到关于‘阴伏流煞’的记载。」</p><p>凡界王朝搞技术的理工人，在虚拟现实这块玩得比谁都花。</p><p>就连59也在火车上称赞过，他们的虚拟现实技术远超同级别文明，达到星际平均水平。</p><p>这个解释确实比独断万古正常许多。</p><p>能够同时解释，为什么古人到了现在会变成数字生命，又为什么会凭空出现“阴伏流煞”这一事物。</p><p>“不过保险起见，我们还是进行一下‘独断万古’的相关实验为好。”</p><p>“是的，老大，你要带我们穿越时间吗？”</p><p>“我？我把机兵留在前一个宇宙了。而这里是一片陌生的天地，有陌生的法则和天道，穿越时间应该不太行吧。”</p><p>“青青，你是这儿的地头蛇，地头狐，有没有什么野路子带我们回500年前？”</p><p>“穿越时间，需要掌控光阴法则。我还在努力掌握。”</p><p>意思就是我不会，这辈子都未必能学会。</p><p>“五九，我记得你的前一个宇宙也掌握了时间机器技术。”</p><p>「杨帝阁下，此世物理法则与前世的最大不同，就在于超光速并不能诞生闭合类时曲线。」</p><p>「在此世，一切对信息的超光速操作，暂时未发现会导致时间曲线闭合。」</p><p>意思是巧了我也不会。</p><p>而且貌似不同世界有不同版本差异，所以超了光速，也穿不了时间。</p><p>就算是同一世界，也会有不同版本差异。</p><p>比如，绝对观察者“原初之眼”存在与否，都会影响时间能否被穿越。</p><p>就和Minecraft未被玩家观察的区块，会随机刷新一些生物出来类似……</p><p>杨帝一捏拳头，不知自己能不能用蛮力跨过时间长河。</p><p>“但虚拟现实，也只是我们的猜想，并没有实质性证据。”</p><p>“啊！说到这个！凡界王朝确确实实牵头搞了个超大的虚拟城市-历史博物馆项目，就叫‘十万溯光纪馆’！”</p><p>人类，鲈鱼，坦克，三个种族一起望向狐狸。</p><p>“你为什么不早说？”</p><p>“你们也没问……”</p><p>杨帝收起超级肌肉。</p><p>他深邃的眼眸中，超越常理的超级智慧再次被点燃。</p><p>这一次，推演的目标更加明确，路径更加清晰：</p><p>……</p><p>虚拟世界“十万溯光纪馆·槐安1644·君士叹顶堡郊野”模块内。</p><p>归墟大帝，这位横压当世的强者，并非踏入了时间长河，而是凭借其深不可测的修为与对能量、信息的敏锐感知，察觉到了这片区域空间结构上极其细微的“不谐之弦”——</p><p>凡界王朝庞大虚拟现实系统与真实世界边界产生的、常人甚至顶级修士都难以觉察的“异常信息”。</p><p>他坐在凉茶铺简陋的木凳上，粗糙的陶碗盛着寡淡的白水。</p><p>就在他举碗欲饮的刹那，指尖凝聚起一丝几乎不存在的、纯粹由神念引导的灵能。</p><p>这缕灵能媲美最精密的探针，悄无声息地刺破了那层虚拟与现实的“膜”。</p><p>他“黑”进了凡人的“虚拟世界”。</p><p>瞬间侵入了那个模拟槐安1644年场景的虚拟沙盒系统。</p><p>映入他感知的，并非预想中乡野的平静。</p><p>虚拟的凉茶铺外，那滩“阴伏流煞”正如同数字化的瘟疫般蔓延！它不是物理层面的黑潮，而是表现为一种恐怖的数据流。</p><p>归墟大帝瞬间洞悉了本质：一种极其恶毒、高效，类似“法术”的仪式。</p><p>一旦被某种技术手段“投射”或“具象化”到现实世界，其造成的破坏，将与沙盒内模拟的“草木枯朽、鸟兽成僵、凡人触之即疯”的恐怖景象别无二致。</p><p>那三个自杀的数字生命，正是虚拟空间中，负责“带出”阴伏流煞，并加以“引爆”的魔道核心人员！</p><p>当他们的存在即将被59改捕获，意识到秘密即将暴露。</p><p>便毫不犹豫地执行了最后的“格式化”指令，以彻底湮灭自身信息为代价，试图掩盖“阴伏流煞”的真相。</p><p>……</p><p>“大帝他……他钻进一个超大的幻境游戏里？然后发现游戏里有个能毁灭现实的病毒？”</p><p>“阴伏流煞显然不可能是自然造物，更有可能，是有‘魔道修士’偷渡到了凡界，并且将自己隐藏在虚拟世界中。”</p><p>魔道修士——杨帝第一次听说的新物种。</p><p>青丘白璃解释，在灵界，修仙道途主要吃五种东西：天赋，资源，道友，传承，根据地。</p><p>一些灵界土著既没有好户口好家庭让他能继承财侣法地；也没有天赋，没有根骨，更没有觉醒什么系统、捡到什么机缘。</p><p>但他们有极其坚韧的心性。</p><p>这些修士，就可能会偏离正途……</p><p>“开始搞各种剑走偏锋的修炼方法？”</p><p>“不，那叫‘邪道修士’。‘邪道’奉行极致的实用主义、极致的灵活应变、极致的省钱，比如‘直肠给药’这种手段就是邪道修士玩出来的。邪道只是邪门了点，他们和秉持‘反社会人格’的魔道修士截然不同。”</p><p>魔道修士，是纯粹的反社会人格。</p><p>你跟他们介绍五讲四美三热爱，他们会反手将你轰杀成渣，掠夺你身上所有资源。</p><p>他们是坚定的自杀主义战士，久经考验的人性恶意实践者，脱离高级趣味，是纯粹的恶人。</p>
