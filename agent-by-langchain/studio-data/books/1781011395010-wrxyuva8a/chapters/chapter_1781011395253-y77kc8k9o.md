# 番茄的迷人机制

<p>二位至尊踏足九天十地，诸天万界。</p><p>先是第五卷食破天惊第302.5章。</p><p>然后到了第一卷耶罗阴霾第48.5章。</p><p>再者是第三卷補完計劃第73.5章。</p><p>由于番茄的迷人机制，这些章节都会发布在那几卷的卷末。</p><p>比如，第302.5章，并不会夹在第302和第303章之间。</p><p>而是放在【食破天惊】的末尾，也就是第338章之后。</p><p>接下来到了第六卷耶罗迷宫第344.5章。</p><p>然后是第五卷食破天惊第278.5章……</p><p>再到第二卷贪狼钓渊第51.5章……</p><p>第零卷比较特别，因为它的别名是第七卷。而在这一卷有一个第0.0章。</p><p>最后二人又重新踏入了第六卷第359.5章。</p><p>耶罗大仙顾着逃命，而从容追逐的杨帝却已发现——他们每次总会踏入卷末。</p><p>那么接下来就很简单了。</p><p>“你……你怎使我回到第六卷第383章的？！”</p><p>耶罗大仙发现自己的身处之地后，现在终于无计可施。</p><p>每一卷至少需要1000字才能发布。即便计算上标点符号，也不可能开头第三段就达到字数要求。</p><p>直到这句话截止，算上标点符号，也才蛐蛐438字。当然如果用438进制计算，那就是10个字。</p><p>杨帝冷笑。</p><p>“我在第零卷留有99.99%实力的身外化身。随便念诵一下你的名，再召唤一下那狗屎仪式，你条蠢材就被骗过来了。”</p><p>“不可能！你根本没在这个宇宙留下你的分身，我记得清清楚楚！”</p><p>杨帝感应了一下。哦，好像也是。</p><p>确实有点奇怪，这个宇宙并没有他的分身，可是耶罗就这么被引来了，说明确实有人念诵了他的名，究竟是谁呢？</p><p>无所弔谓，现在杨帝感觉人生目标前所未有地清晰，那就是轰爆“耶罗大仙”。</p><p>“㗅！他妈的杨帝，你以为吃定本仙了吗？！”</p><p>耶罗大仙凭借最近这几章，从后台新收获了几个大骂“神人作者”的回复。此刻力量如同吃了春药般疯狂暴涨的它，狂吼出声！</p><p>那“神人作者”的封号加持在身，让它变成他，他气势陡增，破碎的虚空都在它周身哀嚎，仿佛承受不住这股因读者怨念而生的磅礴伟力。</p><p>“他妈的！看本仙的——耶罗秘传·读者怨念拳！吔——！！！”</p><p>无数扭曲的、代表着「拖更」、「断章」、「吃书」的负面意念汇聚成漆黑的拳罡，如同决堤洪流，朝着杨帝猛轰过去！</p><p>这一拳蕴含了被坑读者的滔天怨气，足以让寻常强者道心崩碎，元神污染。</p><p>“无聊的把戏，根本阻不了我。”</p><p>平静的说话，杨帝面对这蕴含叙事层面污染的拳劲，竟是不闪不避。</p><p>他……如果不挡，又怎能避下这一拳？</p><p>只因就在此刻，一股更加超然的意念仿佛来自万界叙事之外，一个更高层次的存在，带着几分玩味与欣赏，悄然为杨帝加持了一个全新的「封号」——</p><p>神人主角！</p><p>此号一出，杨帝周身好似笼罩上一层光环。他本就是这故事中横行无忌的霸道存在，此刻得此「正名」，更是如虎添翼，瞬间适应并驾驭了这种基于「名号」的规则力量！</p><p>“我便以主角之位格，打破你这无聊的叙事！皇极惊世拳·主角破格版！给我爆！！”</p><p>杨帝狂怒的说话，一拳轰出。耶罗那依靠读者怨念凝聚的漆黑拳罡，如同遇到了克星，竟被硬生生冲散净化！</p><p>“不可能！我的读者怨念……噗哇——！”</p><p>耶罗惊骇欲绝，话未说完，杨帝那缠绕着“神人主角”光辉的拳头，已然如同流星赶月，一连数拳，都轰在了它的身上。</p><p>第一拳，粉碎它刚刚凝聚的“断章狗”神人封号！</p><p>第二拳，打爆它窃取的“剧情杀”神人权柄！</p><p>第三拳，更是直接将那核心的“神人作者”封号，轰得裂痕遍布，光芒黯淡！</p><p>“呱——！！”</p><p>封号破碎带来的反噬，让耶罗惨嚎出声，身形剧震，气息如同泄气的皮球般萎靡下去。更可怕的是，随着「神人作者」封号的破碎，它那凭借封号维持的人形姿态再也无法保持，身上那单人旁的「他」，在一阵扭曲的光影中，被迫退化成了指代非人之物的「它」！</p><p>耶罗大仙，就要这样被轰死了？</p><p>并没有！拳锋距离它的额头只剩下半厘，在它即将被杨帝彻底轰杀至渣的瞬间……</p><p>那股来自万界之外的召唤感再次降临！比之前任何一次都要清晰，都要更加强烈啊。</p><p>“嘻嘻嘻！天不绝我呀！”</p><p>耶罗眼中爆发出最后的求生光芒，不顾一切地催动起那沃陶姆现实透孔仪。</p><p>“杨帝！任凭你‘神人主角’又如何？只要诸天万界还有一人颂我真名，我便能卷土重来！”</p><p>“现在已经足足1630字了！！”</p><
