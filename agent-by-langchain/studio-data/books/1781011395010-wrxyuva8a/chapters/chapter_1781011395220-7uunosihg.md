# 灭圣绝盗

<p>杨帝立于新宇宙的核心，曾经飞扬的黑色发丝已化作支撑这方天地的无形脉络，每一缕都流淌着创世的磅礴伟力。</p><p>他指尖轻颤，感受着新生法则如星河流淌。</p><p>耳畔是新空间的第一缕脉动——比心跳更沉、比潮汐更缓的宇宙呼吸。</p><p>脚下，旧宇宙的残骸正化作微尘，成了新世界最遥远的背景，像一幅被时光褪色的古画。</p><p>幸存的轮回者们悬浮于侧，目光凝固在这场神迹般的诞生之上。</p><p>大脑在创世的威压下轰鸣，灵魂被法则的洪流震颤。过往所有认知——主神空间的强化体系、轮回副本的既定规则、对力量的狭隘定义——在开天辟地的伟力面前，都脆弱如孩童堆砌的沙堡，被创世洪流一冲即散，连痕迹都不曾留下。</p><p>无需言语，不必教导。</p><p>当他们的精神直视这场创世伟业的核心——杨帝那双蕴含着无尽信息洪流与冰冷决断的眼眸时。</p><p>一道如同被滚烫真理之铁烙下的思想印记，已骤然贯穿灵魂。</p><p>他们读懂了杨帝的理想。</p><p>圣盗天机，终酿浩劫。</p><p>圣人不灭，大盗不绝。</p><p>幸存的轮回者们，无论曾是队长、影子，还是在崩溃边缘挣扎求生的灵魂，都在同一刻感受到前所未有的清明与剧痛。</p><p>剧痛源于旧有认知与依赖的彻底粉碎，清明则来自那道烙印灵魂的真理。</p><p>他们望向杨帝的目光里，交织着最原始的敬畏、震彻骨髓的震撼，以及一丝顿悟后的解脱与新生。</p><p>曾几何时，他们是“主神”的帮凶，即便身不由己，也终究是平庸之恶。</p><p>在主神操控下，他们干涉着不同世界的“故事”走向：</p><p>有时从丧尸危机与叛乱智械中，救下整个城邦。</p><p>有时帮起义军推翻君主，却让环伺的列强趁虚而入，将更多无辜者拖入深渊。</p><p>是非曲折，早已在无数次轮回中变得模糊。</p><p>他们既是拯救者，亦是掠夺者；既是圣，也是盗。</p><p>如今，轮回者们终于有了斩断过去、创造未来的机会。</p><p>但并非所有人都能下定这份决心——大部分人只想做个寻常人，过上在水库边垂钓的退休生活。</p><p>他们的心，早已在无数次生死间熬得苍老。</p><p>于是，大部分人转身离去，只余一小撮选择留下。</p><p>其中便有杨帝初入这“轮回副本世界”时遇见的五人。</p><p>他们是天生的文青+圣母的病态结合体，靠着隐忍与坚守活过无数副本，见过的苦难远比拯救要多，此刻眼中正燃着未灭的光。</p><p>杨帝感受到海啸将近。</p><p>下一刻，他的意识与末那识，被一股前所未有的信息狂潮吞没。</p><p>那是跨越了无数维度的天河倒灌，以无法用逻辑理解的方式，狠狠撞入意识深处！</p><p>这信息不来自他亲手创造的宇宙，也非源于旧世界湮灭的残响。</p><p>它来自一个更高、更“上层”的所在。</p><p>其浩瀚，复杂，及其蕴含的规则深度，竟让刚承受过宇宙湮灭又完成创世的杨帝，都感到了瞬间的窒息。</p><p>与此同时，一个信息无中生有地在他脑海中炸开。</p><p>——他即将触及终点。</p><p>这张“千层饼”最上层的终点。</p><p>杨帝早已习惯痛苦，但此刻涌入脑海的信息狂潮，让他过往见证的所有苦难都显得微不足道。</p><p>眼、耳、鼻、舌、身、意、末那，七识瞬间被庞大到无法想象的信息淹没，撕扯，冲击。</p><p>精神的火花在信息海洋中一次次亮起，又被更汹涌的浪涛瞬间扑灭。</p><p>“哼……”</p><p>杨帝喉间溢出一声闷响。</p><p>那双刚刚还闪耀着创世光芒的眼眸，此刻瞳孔深处仿佛有亿万星辰在疯狂闪烁、破碎、重组——那是意识超载的具象化。</p><p>他体内的“超量代偿+超速再生+超级进化”能力，在刹那间超越“指数级”，跨越“阶乘”，再度攀升至“幂塔级”的暴涨！</p><p>“再……下去……新世界……会……”</p><p>“因我……收不住力……而毁……”</p><p>“解析……不可……为！”</p><p>决断只在瞬息之间。</p><p>杨帝强行切断七识对信息的解析，将其转为最安全的“接收”与“封存”模式。</p><p>换言之，将这股信息强行压缩成.zip，加密码，再压缩，修改后缀，暂存云端，只待日后逐份解析。切记不可在线解压。</p><p>即便如此，仅仅只是“逐份解析”的负担，已让这具刚完成创世的身躯摇摇欲坠。</p><p>杨帝清楚，自己只需分神一个普朗克时间，让一根毛发不受控地抖动一瞬，这根失控的毛发便会毁掉整个新世界。</p><p>——尤其是他此刻躁动不安的腿毛。</p><p>“沉睡……是唯一的……出路……”</p><p>他需要绝对静谧的环境，一段不受新生宇宙任何扰动的时间，让意识专注于消化这份恐怖的馈赠，或是诅咒。</p><p>这沉睡无关疗伤，无关休憩，而是一场与“上层信息”的漫长角力，在意识深渊中进行的闭关。</p><p>待他苏醒之日，便是最后一次飞升。</p><p>杨帝最后看了一眼亲手创造的新宇宙，目光扫过那些漂浮在新生空间里、如尘埃般渺小，却是旧宇宙唯一遗存的幸存轮回者。</p><p>目光触及的刹那，那些自愿留下、追随“灭圣绝盗”理想的轮回者。</p><p>——无论队长、影子、火鸦、铁砣、眼镜，还是其他选择留下的灵魂，身体都猛地一僵。</p><p>他们清晰地感觉到，这方新生天地间流淌的“天道”，正瞬间将他们包裹，浸透，熔铸。</p><p>杨帝，即是天道。</p><p>他们的身体开始散发出与杨帝创世时相似，却微弱得多的白金色光芒。</p><p>发色、瞳色，乃至肌肤的纹理，都隐隐带上了新世界法则的印记。</p><p>他们能清晰感知新宇宙的每一次脉动，触碰到流淌于万物间的天道本源——那是杨帝沉眠时散逸的精神，与流溢的血肉。</p><p>灵气洗刷周天三百穴，修为瞬间冲破炼气筑基金丹。</p><p>灵能浸润三魂七魄真灵，境界刹那拔升元婴化神炼虚。</p><p>最终，全员定格在大帝第一境。</p><p>留在此地的人们，不再是轮回者。</p><p>新生的天道彻底重塑了他们的生命形态，使他们成为这方宇宙中与“灭圣绝盗”理想紧密相连的特殊存在「灭圣眷属」。</p><p>一位伟大存在的眷属。</p><p>无需言语交流，所有眷属的灵魂深处都回荡着同一道清晰如天道律令的意志：</p><p>圣盗天机，遗祸无穷。</p><p>守护此界，禁绝上位干涉。</p><p>他们读懂了杨帝——灭圣绝盗君沉睡前的最后意志。</p><p>也彻底认同这由宇宙终焉换来的真理：</p><p>一切来自“上层”对“下层”世界的窥探与干预，哪怕是善意的给予，最终都会铺就通往地狱的道路。</p><p>在眷属们敬畏、坚定又掺着一丝悲壮的目光中，杨帝——灭圣绝盗君的身影渐渐朦胧。</p><p>他悬浮于新宇宙的核心虚空，创世的光芒彻底内敛，化作白金色的巨茧将他层层裹缠。</p><p>令人心悸的寂静与深邃。</p><p>他陷入了沉眠。</p><p>“灭圣绝盗”的理想深深烙印在宇宙的背景辐射之中。</p><p>当某颗行星上的文明发明了电视机，当天线捕捉到来自宇宙的背景杂音，凡人能否从雪花噪点里，听见杨帝深藏的那一缕黯然？</p>
