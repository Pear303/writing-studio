# 神州耐杀王

<p>在准备第三次尝试前，杨帝再次被袭击了。</p><p>这次不再是面容和善，看起来人畜无害的小砖头了。</p><p>而是青面獠牙的全险半挂。</p><p>那会儿，夕阳把柏油路面晒得发软，远处传来半挂车的轰鸣。</p><p>一辆满载钢筋的半挂车，如同失控的钢铁巨兽，轮胎摩擦地面发出刺耳尖叫，径直冲向杨帝站立的位置！</p><p>“我超，撞大运！！”</p><p>他瞳孔骤缩，本能地扑向路边。</p><p>但贴着“大运”标志的车头，仍以诡异的姿态扭转方向，结结实实砸在他后腰上。</p><p>是福不是祸，是祸躲不过？！</p><p>他感觉自己像片落叶般被狂风卷起，在半空中翻滚三周半，然后狠狠砸到路边的金属栏杆。</p><p>栏杆都被砸得变了形，杨帝像块烂抹布一样仰躺在地上。</p><p>半挂车司机脸色煞白地跳下车。</p><p>做工生涯完了，做工生涯完了，上大学的孩子断供了，家里没人养了，父母对他失望了，一切完了……</p><p>司机声音发颤：“兄弟你没事吧？！我、我不知道怎么回事，眼前一黑，然后刹车失灵……啊啊你不要死啊！我立刻报120……”</p><p>却见，躺在十米外的杨帝慢慢爬起来。</p><p>年轻人活动了两下脖子，转头望向自己方才站立的位置。一滩血渍。</p><p>耶罗符印仍然稳稳贴在他裤腿上，像块冰凉的，极度黏人的狗皮膏药。</p><p>如此大的冲击力，也没法把它撞飞。</p><p>不愧是“绑定诅咒”……比狗皮膏药还难甩。</p><p>杨帝扯下符印，在司机愈发惊恐的目光中晃了晃，咧嘴露出带血的牙，招招手。</p><p>“师傅放心，我比小强还命硬。今天的事就不要说出去了，开车的时候开慢点，这是咱们私下了结，诶不用报警，120也不用，我说真的。”</p><p>半挂车师傅呆立原地，看着年轻人的背影逐渐消失在公路尽头。</p><p>这段路位于城郊，摄像头很少。</p><p>而刚才的马路上，也是没有其他人和车。</p><p>或许只有路边的一小滩血，还有全险半挂前方的微微凹陷，证明这方才所发生的荒谬一幕。</p><p>杨帝怀里揣着耶罗符印，跌跌撞撞。</p><p>T恤被粗糙的柏油磨得支离破碎，后背血肉模糊。</p><p>但伤口以肉眼可见的速度结痂愈合，断裂的肋骨，在皮下发出细碎的复位脆响。</p><p>潜意识还在爆出一连串声音：</p><p>「钝器抗性+1+1+2+3+5……+21+34」</p><p>这回，黄金分割数列直接蹦到了+34！</p><p>单论杀伤力，比今天下午那块砖头还要猛。</p><p>“幸好……幸好之前有先见之明，在锻炼体能和跑酷那些之余，还抽空锻炼了‘耐杀性’，否则已经死两回了……也许不会死，但谨慎点，总好过拿只有一次的生命去赌。”</p><p>杨帝暗自庆幸。</p><p>如果他之前没有锻炼耐杀性，这次一定会被撞的血肉模糊，皮肉绽开，肋骨刺破胸膛之类的。</p><p>但因为他原本就增强过自身防御力。</p><p>所以现在只是受了蛐蛐重伤，距离致命伤还有半步之遥，没那么痛苦。</p><p>虽然杨帝很耐杀，不容易死。</p><p>但他仍然怕痛！</p><p>尽管精神属性很高，意志坚挺，然而，极度敏锐的“触觉”也会数倍乃至十几倍放大疼痛。</p><p>能少挨点痛也好。他只是比寻常人更难精神崩溃，不代表能无视痛觉。</p><p>杨帝其实刚下公交车，来到郊区没多久。</p><p>他来这人迹罕至的偏僻地方，是为了找老同学。</p><p>第三次尝试——物理毁灭。</p><p>杨帝高低也算是个尊贵的本地土著，在当地有些人脉……其实也就是中学时期，和他玩得比较开的几个同学。</p><p>还记得其中一个，在城郊开了家汽修店，里边还购置了各种乱七八糟，杂七杂八的设备。</p><p>其中就有老少皆宜、男女皆喜的液压机。</p><p>杨帝当天带着耶罗符印前去拜访。</p><p>用液压机施加超过五吨的压力，符印隐隐约约有些弯曲。</p><p>但在它即将到达崩裂的极限，工坊的几排日光灯管同时爆裂。</p><p>“妈呀！怎么回事！”</p><p>话没说完，平台发出金属呻吟。</p><p>黑暗中，杨帝瞳孔骤缩，只见符印边缘迸出一枚指甲盖大小的碎片，以子弹般的速度激射而出。</p><p>他下意识侧身，铁片却像长了眼睛般转向，噗嗤一声扎进他右侧后腰。</p><p>因为灯管爆了，杨帝老同学自始至终都没留意到那片子弹一样的碎片。</p><p>剧痛像电流般窜遍全身。</p><p>杨帝闷哼一声，手撑着液压机缓缓蹲下。</p><p>“呃？杨老帝你有没有听见什么好像爆掉的声音。”老同学打亮手电筒。</p><p>他第一眼看见的是——液压机下，那块铁饼毫发无损。</p><p>回头，第二眼，杨帝在吐血。</p><p>他极度震惊：“杨老帝你怎么……机魂在上，液压机操作时我叫了你不要站在它面前，如果有碎片，和子弹一样快……”</p><p>“不妨事，穿透伤而已，至少没留在肉里，修养两个小时……休养两周就好。”</p><p>杨帝扯下染血的布条裹住腰，捡起变形的耶罗符印。</p><p>剧痛中，他迷迷糊糊看见金属表面的漩涡在流转，仿佛有生命般蠕动。</p><p>耶罗大仙，你又在发力了。</p><p>“老规矩，今天的事别跟任何人提，这是我们俩人之间的秘密。”</p><p>杨帝用杰哥的口吻说着，摇摇晃晃走出汽修店。</p><p>其实“老规矩”指的是：他们中学的时候经常用这台液压机来压东西玩儿，压咸蛋超人手办，压威震天手办，压强袭自由手办，压水瓶座黑云巨人手办。</p><p>自从家里买了液压机，家里就只剩液压机了。</p><p>同学他爸要是知道，自家宝贝液压机被拿去做这种用途，必定进入狂暴状态。</p><p>赵铁柱（他同学的妙称）看着杨帝背影消失在夕阳里，咽了咽唾沫。</p><p>……</p><p>第四次尝试，在子夜进行。</p><p>杨帝戴着橡胶手套和安全帽，利用熟练的跑酷技巧和超然的五感，避开所有摄像头和巡逻人员，半夜潜入施工现场。</p><p>他跪在未干的水泥地基前，将铁饼符印沉入水泥浆。</p><p>符印埋进水泥的那一刻，仿佛听见了一声轻微的叹息。错觉吧。</p><p>“这次应该万事大吉了。”</p><p>杨帝四顾，塔吊探照灯和安全员还没有发现他溜了进来。</p><p>这片水泥地不过是校园扩建项目中用于铺设新路的部分，并非承重结构。</p><p>塞进耶罗符印这种扁平的铁饼，理论上不会对建筑安全构成任何威胁，顶多之后的路面可能会有几毫米凸起。</p><p>水泥很快便会硬化，将铁饼牢牢困住！</p><p>但在第二日，正午烈日下。</p><p>杨帝哼着小曲去吃饭时……一声「消化+1」让杨帝觉察到不对劲。</p><p>现在除了中毒和病菌，已经没有什么触发他的“消化”属性增长了。</p><p>只有一种可能，这饭混进了什么东西……</p><p>没错，符印出现在他的咖喱下面。</p><p>青铜表面还沾着米粒与胡萝卜丁，腐臭腥咸的铜锈味混着咖喱酱，他喉头涌上一股品尝会员制套餐的反胃。</p><p>杨帝闭上眼睛，深吸一口气。</p><p>绑定诅咒？有意思，我认命了。</p><p>他非常淡定地将剩下饭菜都扒完。虽然有股铜腥味，但对他而言，总归是能吃的。</p><p>用看起来非常劣质的食堂特供卷纸擦净嘴，抹干净铁饼，然后携着这枚符印，慢悠悠走回宿舍。</p>
