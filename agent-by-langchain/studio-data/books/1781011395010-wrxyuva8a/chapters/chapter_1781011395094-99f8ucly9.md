# 虚境

<p>天空晦暗，太阳已落山。</p><p>数十只紫黑色、扁平状的飞行魔物，如同来自深渊的暗影，在狂风暴雨中肆意翻腾。</p><p>这些“蝠鲼”成群结队，相互交错飞行，编织出一张密不透风的恐怖之网。</p><p>“我要在这里发电！！”</p><p>伊芙左手原力让轿厢停下，右手朝着天空举起法杖。</p><p>刹那间，天空乌云密布，粗壮的闪电链条如蛟龙般自云层中劈下，朝着夜魅群轰去。</p><p>“噼里啪啦”的声响震耳欲聋！</p><p>闪电链所到之处，夜魅瞬间被强大的电流包裹，炸得粉碎，化作一缕缕黑烟消散在空中。</p><p>而在此之前，杨帝已经与这些从天而降的魔物缠斗十来分钟。</p><p>他还以为，这也是伊芙试炼的一部分。</p><p>伊芙用原力将杨帝、瑞弗维尔捞下车，逼停灵能轿厢。</p><p>两个人类正襟危坐。</p><p>而精灵则在他们面前来回踱步，审视着二人微微垂下的脑袋。</p><p>“哪个人，超过三天没睡觉了？”</p><p>瑞弗维尔小声说：“我有好好睡……”</p><p>然后二人目光聚焦杨帝。</p><p>地球青年被这么盯着，思维表层居然有些发怵。</p><p>他控制着面部肌肉、眼睛神态，做出有些困惑的微表情：“我确实可能算是‘没有睡觉’。”</p><p>杨帝简单解释：他能在梦中清醒思考，读读记忆中的书，喝点想象中的速溶奶茶，钓些想象中的鱼。</p><p>“至少我是合上眼了的。”他总结道。</p><p>伊芙走到他面前，轻轻蹲下，叹了口气：“这件事太过‘常识性’，所以忘记提醒你了——超过三天不睡觉，是会被‘夜魅’追杀的。”</p><p>“夜魅？”</p><p>“就是之前那些扁平的紫黑色飞行生物。”</p><p>“它们从哪里来的？我没从‘夜魅’身上感受到灵能波动。”</p><p>杨帝回忆着他与这些诡异生物的战斗。</p><p>有一点点奇怪——夜魅并不是魔物，也不是正常生物。</p><p>它们仿佛是在自己“余光死角”刷新出来的。</p><p>伊芙站起身，双手抱胸，神色严肃地解释起来。</p><p>“夜魅并非源自我们所熟知的灵能体系。它们来自于一种更为隐晦的力量——虚境。</p><p>“当人的精神因长时间不休息，就会在虚境层面撕开一道细微的缝隙。</p><p>“而夜魅便会发现裂缝，然后顺着缝隙，从虚境中钻出来。”</p><p>杨帝似乎觉察到某种比“灵”更本质的力量。</p><p>他问：“什么是‘虚境’？它在哪？”</p><p>伊芙微微沉吟，似乎在思考该如何向杨帝解释这个复杂的概念。</p><p>“它并非是我们肉眼可见的实体，却蕴含着世间万物最深层次的奥秘。”</p><p>“某种更高层次的理念世界？”</p><p>“没错。如果说，灵能是改变世界表象的力量，那么虚境就是这一切力量的根源，你可以将它理解为一种……更为‘实在’的界域。”</p><p>言语无法描述出那个世界的真实模样，仅仅通过语言叙述，终究如同雾里看花，难以触及本质。</p><p>伊芙补充道：“包括我们先前见过的原初之眼，据说在上古大战后，祂所有的物质躯壳被摧毁，本体被流放到了虚境，危险性也就大大降低了。”</p><p>杨帝追问：“那虚境之中，还隐藏着什么牛鬼蛇神？为什么夜魅也会存在于其中？和原初之眼有关系吗？”</p><p>伊芙耸耸肩。不知道。</p><p>纵使是伟大的十环·超限级法师，也说不清夜魅的成因。</p><p>总之，这就是个普遍现象对了。</p><p>应该是“世界”在鼓励大伙儿要有充足睡眠，不要熬夜，熬夜伤身，物理意义上的伤身。</p><p>在地球上，人们长时间不睡觉，就会看到各种幻觉，说不定那是人的精神接收到来自虚境的信号，短暂地窥见世界的本质一角。</p><p>而在异世界，灵气充沛，各种形而上的东西比如“困倦幻觉”，都取得了具体的物质形态，化作“夜魅”，对人造成实质性伤害。</p><p>所以，异世界人民有孩子后，都省去了讲“你不好好睡觉会有怪物把你抓走”的故事。</p><p>第一，是几乎没有哪一个孩子，能真的连续熬三天夜不合眼。</p><p>第二，要是真做到三天不合眼，那就被物竞天择、适者生存给淘汰掉了。</p><p>夜空低沉，天边又隐隐传来尖啸。</p><p>伊芙凝望天空：“夜魅又刷了……”</p><p>“它们还会一刻不停生成？那怎么解？”</p><p>“很简单，睡一觉便可。你们两个先睡，今晚我来守夜，我左右脑可以轮流休息，能够时刻处于‘睡眠’状态，所以不会被夜魅盯上。”</p><p>此刻，从刚才开始一直在旁听的瑞弗维尔，突然发话：</p><p>“伊娃，我也不睡了，一块站岗放哨……你知道的，和被夜魅盯上的人睡，它们也有可能会跑进我梦里。”</p><p>伊芙盯着瑞弗维尔，笑了笑。</p><p>“也好，你以前做过游侠，对环境的感知能力应该能达到我的5%，不睡就放夜哨吧。”</p><p>在杨帝“完成睡眠”之前，夜魅都会源源不断刷新出来，袭击他。</p><p>所以，队伍中如果有人三天没睡觉，那必须有同伴帮忙放哨。</p><p>伊芙擅长挖三填一，她轻挥法杖，没有任何咏唱和起手式，就挖了个地窖。</p><p>地窖内，用植物根茎、枝叶，铺了张很诱人的床。</p><p>“躺上去。然后在睡觉前，我会传授给你第二种锻炼灵能的办法。”精灵说。</p><p>杨帝心中一动——这种方法，和睡眠有关？</p><p>伊芙露出狡黠的笑：“算是吧，因为第二种方法非常让人昏昏欲睡。”</p><p>“我该怎么做？”</p><p>“这第二种方法，便是通过冥想融入自然。听起来简单，实则极为困难，因为这过程会消耗大量的精神力……”</p><p>精神力？！杨帝根本不慌。</p><p>但他还是要适度地表现出困惑：“精神？也就是心灵、灵魂？”</p><p>“差不多吧。大多数人尝试不久，便会因精神力消耗过多而陷入昏迷，睡上一觉。”</p><p>虽然在其他方面，他确实比伊芙弱上许多。</p><p>但在“精神”方面，杨帝自认是数值怪。</p><p>伊芙继续说道：</p><p>“在冥想过程中，你需要摒弃一切杂念，精神扩散开来，与万物融合，升华至‘虚境’边缘。然后假装自己是根苇草、是个蚂蚱、是阵清风。让灵能从客体流向主体，从而填补自身的现实丰度。”</p><p>伊芙的意思是：填补自身的“现实丰度”也就是“灵能”。</p><p>如果再翻译一下，就是“夺天地之造化”！</p><p>地球人自然很开心。在这之前，他都找不到「补完」自身的方法。</p><p>因为“灵能”过于虚无缥缈，不像是肌肉和骨骼那样容易锻炼。</p><p>杨帝突然警觉：“不对，虚境边缘？如果精神进入了虚境，那会很危险吧？”</p><p>以人的思想去接触实在界，后果很严重。</p><p>这一点伊芙虽未明说，但杨帝已然察觉。</p><p>虚境作为万物的根源，那是超越了凡人理解范畴的形而上存在，绝非人类脆弱的精神可以随意触碰。</p><p>就如同以蜉蝣之躯，妄图拥抱太阳。</p><p>稍有不慎，便会被无尽的光芒与热力吞噬。</p><p>而且，若真如伊芙所说，“原初之眼”的本体被流放到虚境。</p><p>那虚境之中，说不定还潜藏着各路魑魅魍魉牛鬼蛇神的影响，或者残留意志。</p><p>虽然杨帝自认“精神”强大，直视过耶罗大仙的模糊投影；而且受到致死伤害时，也不一定真的会死。</p><p>但在伊芙眼里，自己应当只是个生命力比较顽强的普通人。</p><p>她并不知道自己突破天际的进化适应能力。</p><p>她想把他推上绝路吗？</p><p>杨帝不相信她是这种精灵。</p><p>伊芙摇摇手指：“所以你只能‘触碰虚境的边缘’，切记不可深入——当然，就算你想深入，一般也进不去就是了。”</p><p>“原来如此，那我该怎么冥想。”</p>
