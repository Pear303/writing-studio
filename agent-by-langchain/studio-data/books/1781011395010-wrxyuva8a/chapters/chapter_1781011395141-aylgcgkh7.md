# 夕阳红传送门抵达目的地

<p>杨帝三人钻入由阿巴凝练的“太初溟濛域”，顺带往里边倒进几万亿吨优质褐煤。</p><p>煤炭也是种生物尸体嘛。特指凋零骷髅的尸体。</p><p>黑暗水体构建完成，祭品已献上，这是一道能够连通其他宇宙的传送门。</p><p>在真正抵达目的地之前，杨帝并不清楚自己将会去往哪里。</p><p>也许在“中土大陆”世界，由于法则不同，黑暗水体并不能作为异界传送门。</p><p>也许进入黑水传送门后，他会回到原来地球所在的宇宙——黑水很可能仅仅是连通两个宇宙的单向通道。</p><p>也许是90%的几率，也许是10%的可能。</p><p>无论如何，杨帝都要选择跳进去。</p><p>眼前光芒一闪，意识一阵恍惚，再次恢复清明时，耳边传来潺潺的水流声。</p><p>他知道自己成功了。</p><p>虽然还未睁眼，虽然还未适应这具身体，但杨帝已知道——自己来到了第三个迥然不同的异世界。</p><p>物理法则与“中土宇宙”、“地球宇宙”的有细微不同。</p><p>比如说精细结构常数，光速，都有极其轻微的差别——59改当场告诉杨帝。</p><p>它毕竟是一座很棒的高科技机甲，身上装满探测器。</p><p>「杨帝阁下，这个新宇宙的物理法则与我们原本所处略有不同。」</p><p>「譬如，光速大约变慢了0.14%，电磁力强度也因此发生剧变。」</p><p>「然而，构成我们身体的宏观物质，并没有因电磁力参数变化而崩溃。」</p><p>「我认为，进行跨世界航行时，宇宙会尝试调整异世界来的东西，让其适应当地法则。」</p><p>「类似一种‘调和’机制。当外来者进入新宇宙，宇宙会尝试将这些‘外来客’逐渐调整到与本地法则相契合的状态。」</p><p>把不同形状的拼图块扭曲、重塑，最终使之能够严丝合缝地嵌入新的拼图之中。</p><p>杨帝微微点头，思索着“59改”所说的话。</p><p>确实，一种调整、适配。</p><p>到了这个异世界，杨帝脑子里存放“普通话”的位置，又被替换成一种新语言。</p><p>尽管从直觉上来看，和地球上的“普通话”没什么两样。</p><p>但不一样就是不一样了，他说不出哪里不一样。</p><p>比如：趁一个人熟睡时，将其绑架到亚马逊雨林之中的隐蔽山洞，用天顶星科技将除了他以外的全世界广告牌，书籍，文字，还有人们脑中关于“中文”和“英文”的概念完全对调。</p><p>那人醒来后，直觉告诉他——中文和英文貌似……对换了？</p><p>但周围所有人，所有广告牌，包括度娘上能搜出的所有资料，都显示英文是种象形文字，中文是种拉丁字母。</p><p>那个人无法分清楚究竟是“楚门世界”，还是自己疯了。</p><p>真是种奇妙状态。</p><p>这种适配机制最后达成的效果，就是整个多元宇宙都在讲普通话！</p><p>同时，杨帝还觉得，这片天地试图让他的身体适配这个世界。</p><p>是自己的身体太强大，太特殊了？</p><p>「现实+1」</p><p>在异世界对他的调整过程中，自身灵能似乎受到了些许伤害。</p><p>但因为构成杨帝的绝大部分“现实丰度”，都是被刻上了他主体性的烙印。</p><p>换言之，这6.18E110体量的灵能，从此成为他身体的一部分，而不再是身份证信息、银行卡账号、假牙那样的身外之物。</p><p>作为他“身体”的一部分，享受“超量代偿”机制的百亿补贴。</p><p>即使是世界本身，也无法将杨帝割裂。</p><p>杨帝重新控制了自己身体。</p><p>他睁开眼睛，仨人置身于一片浑浊的水中。</p><p>四周漆黑一片，唯有上方隐约透下几缕微弱光芒。</p><p>他定了定神，转头看去，阿巴、59改也在身旁。</p><p>深海鲈鱼泡水一般不会死，而这里的水也齁咸齁咸，是海水，恰好是阿巴的原生环境。</p><p>59改作为站在宇宙顶点的科技文明制造的机兵，应该也能防进水，绝对能防进水，轻易能防进水。</p><p>此次传送过来，各位情况良好。</p><p>其实在茫茫宇宙中，能够一瞬间杀死太乙真仙级别强者的地方，占整个世界的比重很小。</p><p>比如说黑洞的事件视界内部。用肉眼直视“奇点”，有概率让太乙真仙陷入疯狂。</p><p>又比如，在一个极小极小的空间范围内，发生媲美一万亿次超新星爆发的猛烈爆炸，也能够重创乃至杀死太乙真仙。</p><p>杨帝就更耐杀了。</p><p>目前他所能想到的唯一“自杀”方法，也就是将自身现实完全稀释于环境之中，抹除自己的情感、记忆与思想等“主体”。</p><p>失去了自己的人格和记忆，他虽然活着，但和死了是没有区别的状态。</p><p>阿巴看起来有些迷迷糊糊。</p><p>她说：“老大，究竟是什么原理……为什么往黑色水体献上尸体祭品，就能穿越到异世界？”</p><p>「杨帝阁下，没想到这种仪式能成功？！」</p><p>59改的逻辑运算核心也在全力思考。</p><p>但穷极数据库中的内容，也无法理解，为何黑色水体能够成为连接异界的传送门？</p><p>他拥有哲人王的思维，拥有一整个宇宙的知识，这里的科学知识包括的不只是数理方面的知识，更有灵能、哲学、文艺……方面的理论。</p><p>即使如此，守望者·59改仍然无法建立起哪怕一个可能的理论模型。</p><p>杨帝只能诚实地摇摇头：“我也不明白。但我心中隐隐有些猜测。”</p><p>宇宙中的自然现象，可以分为两种。</p><p>一种，能靠某些方法论找出规律，就像经典力学里，能用数学工具发现引力和距离平方成反比。</p><p>就算是更深奥的物理规则，也能用数学工具发现它们像套娃一样环环相扣的美感。</p><p>另一种就有点“老天爷随便定”的意思了。</p><p>谈不上有美感，只能说极致随便。</p><p>比如：黑色水潭当传送门，还有耶罗大仙的召唤术。</p><p>要完成穿越世界或者召唤邪神这事儿，既不用懂能改变物质本质的高科技，也不需要能够篡改因果的灵能法术。</p><p>就俩简单操作：</p><p>怀着相信的心，然后跳进黑水潭。</p><p>怀着相信的心，手持铁饼，念一段捧耶罗臭脚的祷词。</p><p>这两个仪式，既没有使物质本身发生足以改变世界的运动，也没有让灵能流动构成任何法术术型。</p><p>在物理上没有直击事物本质的行为，在灵能上也没有法术意义的仪式，却能够轻易做到仅凭法术和科技难以实现的事情。</p><p>关于这种仪式的知识，被归为「神秘学」。</p><p>这种神秘学现象背后，本身就昭示了一定的真理性本质：</p><p>想要揭开宇宙更深层的真相，不能光盯着已经弄解明清楚的事物，而必须得从那些还有矛盾和疑问的怪现象里找线索。</p><p>“话说我们在哪里？”</p><p>周围全是水，漆黑无光的水体。</p><p>阿巴摸索着墙壁上冰凉的金属铆钉，触到某种规则排列的凹槽，压低声音道：“有舷梯。”</p><p>其实凭借三人实力，他们一眼就能将方圆万里的事物尽收眼底。</p><p>但初到异世界，低调些，也好。</p><p>“轰——咚。”头顶传来重物坠地的声响，三人同时定在原地。</p><p>「有机物集群反应，距离正上方12.5米，生命体征处于应激状态。」</p>
