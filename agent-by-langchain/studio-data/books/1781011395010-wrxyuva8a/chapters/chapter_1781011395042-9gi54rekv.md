# 心物二元论

<p>光是言语描述，实在难以道明那种玄之又玄、妙之又妙的感觉。</p><p>胡彦卓也是跃跃欲试，想要让希夷通过精神交流，给他传输些身临其境的感觉。</p><p>在酿成大祸前，杨帝及时介入阻止。</p><p>“不行！希夷根本没轻没重，它轻轻一刮擦，就能让你身为正常人类的精神崩溃掉！”</p><p>“杨帝，那你怎么没有精神崩溃？”</p><p>“我……我‘爆气’了嘛，精神水平大幅提升，所以五感变得极度敏锐，这才勉强承受住希夷的无线传输。”</p><p>经过民主投票，杨帝和希夷二比一胡彦卓，否决了他“与希夷神交”的议案。</p><p>杨帝的话，其实只说了一半。</p><p>他确实担心，和希夷神交，会瞬间烧毁胡彦卓的大脑。</p><p>他们继续翻页，这次，是最后一页了。</p><p>字迹与前面的癫狂记录截然不同，工整得近乎冷酷：</p><p>「抽走物质本身的灵，有机物甚至是无机物都将呈现预想中的崩坏现象……」</p><p>「灵质剥离实验体，呈现出无固定规则的黑色物质……」</p><p>“难道……他们在试图分离灵魂和肉体？”</p><p>胡彦卓喃喃重复，喉结滚动。</p><p>“把人的‘灵’抽出来？”</p><p>二人不约而同，心照不宣地想起那些实验记录里的“质壁分离”。</p><p>如果这里的“壁”指肉体，“质”指灵魂。</p><p>那么所谓的实验，先是从开始测试，最后竟是在活生生的人身上……剥离灵与肉？</p><p>当某种力量抽走了存在的“灵魂”，剩下的躯壳是不是就像被高渗溶液浸泡过的细胞，只剩下空虚的外壳？</p><p>失去了“灵”的肉壳，会变成黑色拉面？！</p><p>居然把人类当做了实验对象！！</p><p>被剥离了灵魂的肉体，就会变得“空虚”。</p><p>脱离肉体的灵魂，则成为了“鬼”……</p><p>也是在翻完最后一页那刻起，地下室的空气变得粘稠，一股恶意从角落升腾。</p><p>远处传来水管漏水的滴答声，在寂静中被放大成心跳般的节奏。</p><p>希夷和杨帝是同一时间意识到不对劲的。</p><p>多么熟悉的感觉，就像在先前那个无限循环的楼梯间，他们能感受到同样的恶意——来自于那团黑色拉面“哈基面”。</p><p>狸花猫炸毛而起，人类则手持撬棍。</p><p>“有东西过来了喵！”</p><p>猫的瞳孔几乎缩成一条线，“带着照片上一样的味道……和我这具狸花猫身体相似的味道，很空，很虚无，让猫恶寒喵。”</p><p>杨帝握紧撬棍，手电光束扫过墙洞。</p><p>那里的黏液痕迹正在蠕动，仿佛有什么东西正顺着管道缓缓逼近。</p><p>从解放2%潜意识那一刻开始，他一直听见周围有窸窸窣窣的声响，蚊子、苍蝇、蟑螂……</p><p>而现在的声音，比飞虫大得多！</p><p>“是某种……比虫子更大体型的啮齿类动物，老鼠？”</p><p>手电光束在墙洞上摇晃，混凝土裂缝里渗出黏液，泛着诡异的油光。</p><p>小东西湿漉漉的皮毛贴在骨架上，粉红色的鼻尖在冷空气中微微颤动。</p><p>爪子扒拉着碎石，发出细碎刮擦声。</p><p>杨帝听见胡彦卓喉咙里，发出一声短促的抽气声。</p><p>那是一只小白鼠。</p><p>小白鼠探出头，瞳孔纯黑，没有一丝光。</p><p>「2012.1.11，小白鼠，质壁分离……」</p><p>他们还记得这一栏目，实验体是小白鼠。</p><p>希夷的尾巴炸成了鸡毛掸子，喉咙里滚出低沉的嘶吼。</p><p>小白鼠瞳孔本该漆黑，此刻，其中倒映的手电光斑正在扭曲，仿佛有无数细小的黑色丝线在眼球深处蠕动。</p><p>“吱——吱——吱！！”</p><p>下一秒，白鼠的脊背开始隆起。</p><p>皮肤下像是有无数条虫子在疯狂啃噬，皮毛成片脱落，露出下面肿胀发亮的灰白色肉团。</p><p>“退后吔！”杨帝拽着胡彦卓向后踉跄。</p><p>白鼠的身体以违背生物规律的速度膨胀，骨骼发出不堪重负的脆响。</p><p>直到整个躯体撑成半人高的肉瘤，表面布满血管状的黑色纹路。</p><p>然后，它毫无征兆地炸开了！</p><p>“噗——！！”</p><p>黑色物质像腐烂的泥浆般飞溅，带着令人作呕的腥臭味。</p><p>那些黑色物质落地后并未凝固，而是像活物般缓缓蠕动，汇聚成一张没有五官的脸。</p><p>表面覆盖密密麻麻的细小绒毛，正以某种不属于这个世界的频率，起伏颤动。</p><p>他看见黑色物质边缘，伸出无数根纯粹黑色的触须，正沿着墙壁缓缓攀爬。</p><p>黑色拉面团。</p><p>希夷弓着身子后退，尾巴尖不自然地抽搐。</p><p>“希夷，刚才不是很勇的要护在我身前吗。”</p><p>“老大，我虽有匹夫之勇，却亦有自知之明喵。”</p><p>这只小白鼠，和先前的狸花猫一样，都是被剥离了“灵”。</p><p>他们算不清楚这个“灵”指的是灵魂，还是其他什么东西。</p><p>在实验栏目里面，有出现过“石膏雕塑”，石膏雕塑也被抽走了灵。</p><p>这种死物，也能失去灵魂？</p><p>黑色拉面在地板上如活物般抽搐。</p><p>“蹦沙卡拉卡！！”那些半透明的触须以惊人的速度弹射而出。</p><p>胡彦卓本能地挥出钢管格挡，金属碰撞声在密闭空间里炸响，火星四溅。</p><p>预想中的断裂感并未传来。</p><p>撬棍竟被触须上密布的绒毛死死缠住，仿佛被某种生物胶水黏住。</p><p>他手腕一麻，铁棍差点脱手飞出。</p><p>杨帝瞳孔骤缩，反手将胡彦卓拽到身后。</p><p>黑色拉面的抽搐蠕动加剧，黑色拉面状触须如灵蛇般，在空中划出弧线。</p><p>杨帝挥起撬棍砸向最近的触须，震起金属碰撞声，擦出火星四溅。</p><p>“胡哥！你没对付它们的经验，让我来上！它们的触手特别硬，特么和镀镍不锈钢一样，只有正中核心，才能稍微击退它！”</p><p>杨帝剑技惊人，一梆子敲上去，撬棍精准地击中了黑色毛线团正中心。</p><p>那触须仿佛受到了重创，猛地一颤，癫痫着狂舞。</p><p>手电筒光束扫过墙面，只见被触须扫过的混凝土块纷纷碎裂，露出里面的红砖和水泥。</p><p>趁此机会喘息，杨帝大叫：“希夷！为什么你只是看着！难道连你也背叛了吗……”</p><p>狸花猫指了指自己：“啊？我？”</p><p>“说的就是你！快把这具无主之躯也夺舍了。”</p><p>希夷咬咬牙，本体出窍，在空气中划出一道银灰色的残影。</p><p>断尾黑白狸花猫的躯体轰然倒地，而那团黑色拉面状的小白鼠残躯，则剧烈收缩。</p><p>“呱！给我收缩喵！”</p><p>希夷如箭矢般扎入肉瘤中央。</p><p>那团黑色拉面状的触须疯狂甩动，肉瘤表面的血管纹路疯狂蠕动，仿佛有两股力量在内部撕扯。</p><p>与此同时，变故突生——地上的狸花猫肉身也抽搐起来。</p><p>狸花猫四肢暴长，指尖长出弯钩状的骨刺，喉咙里翻涌出黑色泡沫，脊椎骨节节隆起，皮肤像融化的蜡般剥落，露出底下正在重组的黑色拉面结构。</p><p>刚刚闲下来的杨帝：“希夷！你的猫身子也要爆了！我先帮你镇压住！”</p><p>杨帝抄起撬棍，又是一梆子下去。</p><p>见状，胡彦卓也是抄起钢管，加入这场殴打大会。</p><p>“哇！老大你轻点！我很喜欢那具身体！”</p>
