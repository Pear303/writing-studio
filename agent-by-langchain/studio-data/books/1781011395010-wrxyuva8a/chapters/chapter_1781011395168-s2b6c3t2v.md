# 挨得揍中揍，方为帝上帝

<p>归墟大帝持斧而来：“还有什么招数都祭出来吧！”</p><p>“你说的！伤害·顷刻炼化之术！”</p><p>杨帝瞬间入梦，周遭景象陡然变幻，一片混沌之中。</p><p>紧接着，在这梦境里，他又再次入梦！</p><p>四周浮现出奇异的光怪陆离之景，仿佛踏入了一个更为深邃的意识空间。</p><p>然而，这还未结束。</p><p>在这已然如梦似幻的境界里，杨帝的意识继续深入，再次坠入梦中梦。</p><p>他所构造的梦境，与现实时间流速比，一般是20:1。</p><p>如此嵌套三层梦境，时间流速被放大到了惊人的8000:1！</p><p>在这第三层梦境，也有一个“归墟大帝”，手持“灵茶山乂斧”，向他脖子劈来！</p><p>“砰！！！”</p><p>杨帝抬手接住斧刃。</p><p>但这次，“创世之斧”仅仅劈开了他的手臂从虎口到小臂的一半位置，并没有劈到胳膊肘。</p><p>他的抗性相较之前，又上涨了一截。</p><p>在梦境中受到伤害也能反馈到现实。</p><p>所以，杨帝才会提出“现实其实和虚拟世界没什么不同”的论点。</p><p>因为梦境本身也是由人脑构筑出来的一种虚拟世界。</p><p>随着这“灵茶山乂斧”砍在手臂上，那股剧痛以及灵能的冲击，瞬间跨越三层梦境。</p><p>以8000倍的时间加速效应，反馈到现实世界的杨帝身上！</p><p>只见他身躯微微一颤，体表灵能光芒爆闪。</p><p>他全身血肉、灵能，以一种惊人的速度开始重组、强化！</p><p>其对伤害的适应和防御抗性提升速度，是先前的8000倍。</p><p>在归墟大帝眼里看来，这压根儿就是“顷刻间修为暴涨”！</p><p>杨帝睁开了眼。他睡醒了。</p><p>虽然外界才过去堪堪1秒，但他在梦境中经受了大约2小时的“沉浸式斧头砍击”。</p><p>仿佛只是顷刻间，他已然适应了归墟大帝“灵茶山乂斧”级别的伤害。</p><p>不过，尽管他的灵能如滔滔江水在体内奔腾不息，肉身强度暴涨大截媲美乌鸦坐飞机。</p><p>然而，那“虚无本源”仍然在疯狂侵蚀杨帝的肉身和灵能。</p><p>“啊！可恶！我透支本源、榨尽潜能、燃烧寿元，竟然都无法压制你的虚无本源！”</p><p>杨帝以“orz”姿势捶打地面，脸上和眸中满是懊恼不及的悔恨。</p><p>“这虚无本源，岂是你能轻易抗衡的。”</p><p>说罢，归墟大帝双手紧握灵茶山乂斧，周身气势陡然攀升，灵能疯狂涌动。</p><p>他竟再次分化出更多的虚无本源，如黑曼巴毒蛇般朝着杨帝汹涌扑去！</p><p>这些新分化出的虚无本源，比之前更为狂暴，所过之处，空间都发出不堪重负的呜咽，扭曲变形。</p><p>杨帝“orz”姿势未变，绝望无助，那低垂的眼眸下，浸满痛苦与悲恸！</p><p>虚无本源瞬间将杨帝淹没，疯狂地啃噬着他的肉身与灵能。</p><p>杨帝发出嘶吼，身上再次出现无数深可见骨的伤口，鲜血如泉涌般喷出。</p><p>然而，他只是一味喷血。</p><p>距离死亡，总是差那一点点！</p><p>在那层层叠叠的伤口之下，杨帝的肌肉与骨骼在不断地重塑，变得更加坚韧和强大。</p><p>但他没有表现出来，没有催动治愈法术去超速修复“皮肤表面”的损伤。</p><p>甚至还暗地搓了几个“杀伤型超位法术”，打在自己身上。</p><p>以至于，杨帝看起来像是全身灵能紊乱，导致各处身体部位接连爆炸、损伤。</p><p>“呃啊！噗——！”</p><p>他周身血肉翻卷如破碎的绸缎，原本挺拔的身躯佝偻得近乎对折，染血的发丝黏在脸上，将半睁的眼眸遮成两道血缝。</p><p>虚无本源化作的黑蛇钻入他后背。</p><p>随即，他脊椎发出令人牙酸的脆响，扭曲成诡异的S形。</p><p>殷红血珠顺着凹陷的脊柱沟壑连成溪流，啪嗒啪嗒砸在地面，竟腐蚀出冒着青烟的孔洞。</p><p>右臂以反关节角度垂落，皮肉被啃噬得只剩森森白骨，却仍在抽搐，指尖还残留着搓动法术时未消散的蓝色残芒。</p><p>“呃哇！”</p><p>杨帝几百毫升几百毫升地往外吐血。</p><p>喉骨发出一连串细碎的爆裂声，声带被撕扯得支离破碎，只能发出断断续续的气音。</p><p>归墟大帝见状，知道大局已定。</p><p>但除此之外，眼中还闪过一丝疑惑。</p><p>——他显然受了很重的伤，但竟然还没死？</p><p>但心头刚冒出的困惑，旋即被杀意掩盖。</p><p>“异界之人，安息！”</p><p>归墟大帝猛地挥斧，又一道虚无本源凝成的锁链缠住杨帝脖颈，将其狠狠拽到身前。</p><p>杨帝喉间发出气若游丝的呜咽，脖颈青筋暴起如盘踞的蚯蚓，半张脸被锁链勒得扭曲变形。</p><p>他声音细得几乎微不可察：“我……噗，阴伏流煞是你释放的对吧，归墟大帝，噗……能不能对我这个将死之人，噗……坦白透露，我好瞑目，噗……”</p><p>归墟大帝闻言发出震天狂笑，笑声中夹杂着无尽的森冷杀意。</p><p>他手中锁链骤然收紧，杨帝脖颈处顿时渗出血珠：</p><p>“世人只知‘域外天魔’，却不知这域外天魔，竟可由域外之人通过‘阴伏流煞’播撒，并暗中控制！</p><p>“他们驱使着那些恐怖的天魔，如蝗虫过境般肆虐这片天地，所到之处，哀鸿遍野，无数生命消逝，无数文明覆灭。</p><p>“我亲眼看着挚友在我被天魔撕成碎片，亲耳听到百姓们绝望的哭喊。这血海深仇，怎能不报。</p><p>“这片天地不容许任何未知的威胁，哪怕只有万分之一的可能！”</p><p>归墟大帝猛地将杨帝甩向空中，灵茶山乂斧带着毁天灭地的气势劈去。</p><p>“带着你的‘阴伏流煞’，永远消失！”</p><p>斧刃与杨帝接触，大约还需要50微秒时间。</p><p>50微秒，他能绕地球赤道跑50万儿圈。</p><p>但因为“归墟帝霸阁”领域内，那骇人听闻的10^100灵环境灵能。</p><p>原本能轻易把光速超了又超、能生啖相对论效应的杨帝。</p><p>在此地全力一拳，也只能挥出2.5马赫左右，杀手兔的速度。</p><p>在这领域中，“50微秒”已经是他做出反应的极限时间。</p><p>但杨帝当然不打算躲开。</p><p>50微秒内，杨帝思考了很多很多。</p><p>除了上述的疑问，还包括——人要自己赋予生命意义，还是一切本就毫无意义，我们只是在自欺欺人；我们所认知的善恶、对错，在这宏大而未知的宇宙面前，是否还有意义；中午之前能不能打完收工，去哪吃？</p><p>这些念头如闪电般在杨帝脑海中划过。</p><p>而那带着毁天灭地之力的斧刃，也终于狠狠砸在杨帝天灵盖。</p><p>斧刃与头皮接触之处，爆发出刺目光芒，灵能冲击以两人为中心向四周扩散。</p><p>仅仅是冲击波，就将帝霸阁的某一层吹得七零八落。</p><p>杨帝脑瓜没有开瓢，没有裂成八瓣。</p><p>归墟大帝震惊：“你使了什么妖法！”</p><p>杨帝捂住天灵盖，作头痛难忍状，同时强行解说：“我跟你说过，我透支本源、榨尽潜能、燃烧寿元试图抵挡‘虚无本源’。虽然没成功，但你这些拳打脚踢、斧子劈砍的基础伤害，我勉强能通过极限超频透支阻挡。你要是再拼尽全力多砍几下，我真的要破防了！”</p>
