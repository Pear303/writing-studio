# 最有价值之物

<p>杨帝倚在树旁，将归墟帝霸阁内的惨烈鏖战徐徐道来。</p><p>当说到被灵茶山乂斧劈砍时，阿巴倒抽一口冷气，59改的国字脸都因震惊而微微颤动。</p><p>青丘白璃更是瞪大琥珀色的眼睛，尾巴僵成了木棍：“你……你说归墟大帝动用了领域？还和你缠斗了整整三分钟？这不可能！他向来……”</p><p>“向来温文尔雅，不嗜杀、不暴戾？”</p><p>“不，我是说大帝向来一招毙敌……”</p><p>杨帝继续讲述了他用“话术”逼迫归墟大帝讲真话，并因此推断出的惊天阴谋。</p><p>一边说着，又咳嗽出几升血，随后作出总结：“归墟大帝，被夺舍了。”</p><p>青丘白璃世界观有些爆炸，浑身狐毛炸起，像一团受惊的白色毛球：“被域外天魔？被魔道中人？被‘第三个世界’的人？大帝他……他可是喝过三千瓢归墟弱水而不死的存在！万法不侵，怎么会被夺舍……”</p><p>“不是我夺的。”</p><p>“当然不敢怀疑白杨大帝阁下……”</p><p>“谢谢狐狸。”</p><p>杨帝将这几天来所有线索，以及方才与归墟大帝战斗中所有信息，从头到尾再捋一遍。</p><p>超级智慧再度发力，他进入演绎推理状态。</p><p>“归墟大帝万法不侵？那要看是什么‘法’。域外天魔的手段，诡谲莫测，远超灵界常理。”</p><p>“您是说，域外天魔夺舍了大帝？”</p><p>“不一定是夺舍，也可能是污染，也就是俗称‘堕入魔道’，具体可以参考在君士叹顶堡-主控大厅时，感染了‘阴伏流煞’的59改。”</p><p>「是的，当时我的梦想是毁灭世界。」59改证实了这一点。</p><p>虽然毁灭世界对他而言并没有任何好处，但欲望上头了，想止都难止住。</p><p>“大帝在对抗天魔最前线，接触最深，风险最大。在战场上，他感染了‘阴伏流煞’，他预感自己即将被彻底污染、失去自我，所以……”</p><p>青丘白璃瞳孔一缩：“所以决定自杀？”</p><p>“没错。通过你对归墟大帝的叙述，对他临摹出人物画像，可以确定，在这种情况下他极大可能会为了万物生灵，而尝试自我了结。”</p><p>大帝原本是个高尚的，纯粹的，脱离低级趣味的人物。</p><p>“尝试？”</p><p>“是的，自杀并没有成功，否则他刚才怎么会活生生地站在我们面前？人被杀就会死嘛。而自杀不成功的原因可能有很多，比如，也许归墟大帝的意志已经被‘阴伏流煞’污染了一部分，导致他决心不够坚定。”</p><p>“如果要尝试自杀，他为何要去凡界？”</p><p>杨帝摇摇手指：“并非是为了尝试自杀而去往凡间，而是自杀不成功，所以只能去凡界孤注一掷。”</p><p>旁听的阿巴困惑了：“凡界灵气稀薄，法则脆弱，大帝去那儿干嘛？”</p><p>“因为大帝知道，一旦他被完全夺舍，一个疯狂的、拥有他全部力量的‘魔道大帝’，对灵界和凡界都是灭顶之灾。”</p><p>杨帝的声音低沉下去，带着一丝洞察真相的寒意。</p><p>“但是，归墟大帝已经适应了‘归墟渊水’，连虚无本源都无法将他杀死。他需要一个‘囚笼’，一个能困住失控怪物的牢笼，至少暂时困住‘阴伏流煞’，给灵界其他人争取时间。”</p><p>“囚笼？凡界有东西能克制阴伏流煞……？”</p><p>青丘白璃：“虚拟城市沙盘！”</p><p>不知为何，“阴伏流煞”存储在凡界的主机和硬盘中时，并不会表现出太大的杀伤力，也只是导致数据紊乱，系统错误。</p><p>而一旦暴露在现实世界，就会极速生成域外天魔。</p><p>“那他为什么接触虚拟沙盘里的数字生命，指使他们将‘阴伏流煞’撒播出去……”</p><p>“因为归墟大帝被域外天魔污染后，滋生出反社会人格，所以才会投放阴伏流煞，并蛊惑数字生命大规模播撒。”</p><p>青丘白璃捏着下巴，阿巴薅着狐尾巴努力思考：“可最终，‘阴伏流煞’并没有被限制在虚拟城市沙盘内，而是被数字生命想方设法送到了外界。”</p><p>杨帝：“这说明归墟大帝没能将自己的记忆抹除干净，导致他在‘堕入魔道’之后，仍然记得此处其实是虚拟沙盘城市，而非凡界。”</p><p>“为何他会有如此重大失误？”青丘狐问。</p><p>杨帝点点头：“我认为，这就是归墟大帝所受到的‘背叛’。”</p><p>大帝死前，携着无尽的恨意。</p><p>那些恨意来自某人的背叛。</p><p>“具体是什么背叛？”</p><p>“嗯……也许在虚拟沙盘里，有人告诉他，他正处在虚拟世界，应当不计手段回到现实？”</p><p>到头来，真相仍然扑朔迷离。</p><p>如果有装监控就好了。</p><p>杨帝想起那个“魔性归墟大帝”最后一句话。</p><p>「竟然被识破了……那便再无隐藏必要。我还会回来。」</p><p>“魔性归墟大帝”，似乎掌握了随时随地去往“第三个世界”的方法。</p><p>他才会回来，回来继续灭他们的口。</p><p>杨帝自己无所谓，反正他难杀。</p><p>59改也是，死了就死了，反正守望者文明的本体又不在这儿。</p><p>但阿巴不能死，她还有更重要的历史使命。</p><p>所以还是在略微变强一点，就早日离开这世界吧……这话怎么听起来这么不吉利不管了。</p><p>总之，杨帝已经下定决心。</p><p>他瞄准了这个世界对他最有价值的目标。</p><p>于是他抬手轻挥，一道流光将如鲈鱼、狐狸和59改包裹住。</p><p>“这招啊，刚从归墟大帝那偷师学来的，我觉得挺好用，能驱散无关人员。毕竟，如果我说要去痛饮归墟水，你们之中有一只狐狸会试图用不轻不痒的言语阻止我。”</p><p>青丘白璃的尾巴剧烈颤抖，绒毛根根竖起：“归墟渊水连大帝都要谨慎对待，白杨大帝你疯了？！”</p><p>杨帝眼底跳动着兴奋：“不亲自尝尝，怎么知道我的极限在哪里？”</p><p>“灵界”对他价值最大的事物，不是什么帝级功法，不是什么创世之斧。</p><p>价值最大之物，是那口能持续杀伤的水潭，归墟。</p><p>能让他持续变强。</p><p>探究真相，破案？那只是顺手的事儿。</p><p>他又不是毛利小五郎，他来到这世界的主要目的只是变强。</p><p>杨帝将被光球笼罩的三人弹飞到数千里外，自己身形一闪，如离弦之箭朝着归墟的方向疾驰而去！</p><p>光球中的三人只看到空中残留的血雾残影。</p><p>阿巴抓着头发大喊：“呱！老大又开始发癫了！快追！”</p><p>59改也做出了蹲踞起跑姿势。</p><p>青丘白璃挣扎着拽住他们：“把我松开呀！兹事体大，至少得有个灵界土著在场。”</p><p>59改表示认可，并在飙出一大堆阿巴听不懂的话后，做出总结：</p><p>「从系统稳定性优化角度，释放青丘白璃并使其参与行动，属于收益风险比最优解。」</p><p>简单来说，就是把这狐狸放了一块儿走比较好。</p><p>他们也便还青丘白璃以自由。</p><p>三人联手花了5分钟打破光球，冲向杨帝消失之处。</p>
