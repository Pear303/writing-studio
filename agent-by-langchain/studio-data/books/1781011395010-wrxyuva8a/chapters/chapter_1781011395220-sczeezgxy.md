# 生死渡劫（4800字）

<p>达文西至少是幸福的，他沉浸在自己的艺术中死去。</p><p>执行处决，由这位动人的少女亲手执行，在这片被晚霞和山峦拥抱的荒野。</p><p>咔嚓。</p><p>他听见少女扣扳机，反而不闻枪响。</p><p>特制的钨合金弹芯，在出膛瞬间就达到了四倍音速。</p><p>它毫无怜悯地吻上了达文西的额骨。</p><p>那感觉……并非痛苦。痛苦需要神经传导，需要时间感知。</p><p>达文西只感觉到温柔。</p><p>额骨在接触弹芯的瞬间，刺出一个边缘瞬间碳化的圆形孔洞。</p><p>弹芯没有停滞，贯入颅腔。</p><p>脑脊液被瞬间蒸发，颅内压如同被引爆的炸弹，将尚未被直接接触的后脑部分组织，猛烈地向后挤压、撕裂。</p><p>如同装满液体的皮囊被重锤击破的声响，从达文西的后脑勺传来。</p><p>一个远比前额入口大得多，边缘呈不规则放射状撕裂的孔洞，在后脑勺轰然炸开。</p><p>混合着粉白色絮状碎屑、鲜红血沫、惨白骨渣以及被高温瞬间碳化成黑色微粒的粘稠物质，如同被高压水枪喷射般，呈扇面状猛烈地喷溅在他身后沾着泥泞的草地上。</p><p>他跪着的身体，在枪口巨大的冲击力下猛地向后一仰。</p><p>然后失去所有支撑，像一袋被丢弃的垃圾，沉重地摔倒在泥泞之中。</p><p>额前那个边缘光滑的孔洞，如同第三三三只眼，茫然地瞪着被晚霞染成瑰紫色的天空。</p><p>天空，也是美丽的天空。</p><p>少女动作流畅地站起身，退弹，管保险，卸弹匣，收枪，捡回弹壳。</p><p>她以一种近乎优雅的姿态，把步枪重新背回身后特制的固定带中。</p><p>做完这一切，她微微整理了一下因射击动作而略有褶皱的制服裙摆，然后，做出一个标准得如同教科书般的动作。</p><p>双脚并拢，身体挺直，双手自然垂于身侧。</p><p>对着达文西的尸体，深深地鞠了一躬。</p><p>程序化的礼仪，职业性的敬意，如同清洁工完成打扫后对空房间的致意。</p><p>夕阳终于沉没。</p><p>最后一丝熔金般的光线也从山巅消失。</p><p>深沉的靛蓝色迅速吞没了天空，如同巨大的幕布缓缓掀起。</p><p>荒野彻底陷入了寂静，只有晚风掠过草叶的沙沙声。</p><p>不知过了多久，第一颗星辰在深邃的天幕上怯生生地亮起，紧接着是第二颗、第三三三颗……</p><p>星群如同被打翻的钻石匣子，迅速占据了夜空，冰冷而永恒地俯瞰着这片泥泞草地上的小小死亡。</p><p>……</p><p>图兰泽并没有毁灭。</p><p>在自由众星同盟“地爆天星”巨像武器那道贯通天地的惨白色光柱之中，一个渺小的身影突兀地出现了。</p><p>是杨帝！</p><p>他似乎具有分裂分身的能力。</p><p>取得太乙真仙修为的轮回者小队五人，瞪目欲裂地看向碎星炮炮口。</p><p>他们目力所及的每一条世界线上，都有一个“杨帝大神”抵挡在炮口前。</p><p>他竟直接出现在了“地爆天星”光柱的核心路径上，用渺小的身躯，直面这足以贯穿星辰的毁灭洪流！</p><p>“他疯了？！”</p><p>“他想肉身抗行星炮？？”</p><p>卫星上的轮回者们一片哗然，难以置信。</p><p>他们没亲眼目睹过杨帝的变态级进化适应能力，自然不相信。</p><p>某个轮回这小队的某个战术分析人员，带了二十多副眼镜轮番转换，最后得出结论：</p><p>“地爆天星巨像武器的原理，是通过加热地核，永久性破坏岩石行星的宏观地质……这个过程，巨像武器会输出至少10^31焦级别的能量，相当于2020年地球消耗总能源的720亿倍。”</p><p>“也就是说他，不可能有任何存活的希望。”</p><p>“哇，老兄，原来你也是地球人。”</p><p>“你也是是老乡啊！你哪里的？我山西的，太原，大刘还写过咱城市的作品嘞。虽然没读过，但听《太原之恋》这名字应该是表达了对我家乡的喜爱吧。”</p><p>“哦山西啊，就是击杀凋零骷髅能获得煤炭的那地方。”</p><p>除了五个人，其他人都认为大局已定之时，</p><p>事实是，杨帝并未被瞬间气化。</p><p>他张开双臂，在拥抱这毁灭的能量！</p><p>他那头乌黑的头发——不，此刻已不能称之为头发，而是化作了无数条闪烁着暗金色光芒、坚韧无比的活体能量藤蔓——开始疯狂地生长！</p><p>“藤蔓”并非向下坠落，而是逆流而上。</p><p>如同亿万条贪婪的虬龙，沿着那纯粹由毁灭能量构成的惨白色光柱，以超越想象的速度向上蔓延、攀爬。</p><p>它们无视了“光柱”本身蕴含的恐怖能量和高温，反而将其当成了滋养自身的养分和攀附的“藤架”。</p><p>几千万公里的距离，对于此刻的杨帝和他的头发来说，咫尺之遥。</p><p>仅仅数息之间。</p><p>在“地爆天星”巨像那直径十公里的炮口处，无数头发增殖，堵塞了整个口。</p><p>并且向内疯狂钻探，生长！</p><p>嗡——！！！！</p><p>“地爆天星”巨像被掐住了脖子的巨兽，炮击光芒剧烈地闪烁、扭曲、然后……</p><p>戛然而止。</p><p>整个宇宙仿佛瞬间安静了下来。</p><p>数以百计千计万计的世界线中，世界都仿若被按下暂停。</p><p>杨帝的身影，则如同一个微不足道的黑点，站在那停止的光柱源头，站在巨像的炮口边缘。</p><p>图兰泽行星的巨大创口仍在无声地喷涌着熔岩和电离气体，如同宇宙中一道流血的伤疤。</p><p>但至少，这颗无辜的行星不会彻底毁灭。</p><p>行星级的炮击，被他一人硬生生挡住。</p><p>这种伤害，对于已经迈入真仙境界的杨帝而言，只能算冲了场冷水澡。</p><p>所有轮回者，无论强弱，正准备要恰到好处地表现出震惊，即将就要纷纷倒吸凉气。</p><p>却突然之间，都感到心脏猛地一抽。</p><p>某种难以言喻的空虚和恐慌，毫无理由地从灵魂深处涌现。</p><p>紧接着，在所有人惊愕的目光中，那片深邃的星空毫无预兆地浮现出文字。</p><p>文字能让所有轮回者瞬间理解其含义，仿佛信息直接烙印在意识里：</p><p>「在很久很久以前，一个遥远的星河……」</p><p>「自由众星同盟的星际战舰，从秘密基地出击……」</p><p>「……赢得了对邪恶英仙帝国的首次胜利！」</p><p>「在战斗中，英勇的同盟军间谍……」</p><p>「……设法窃取了帝国终极武器——“图兰泽虫族”的秘密计划！」</p><p>「同盟必须想办法摧毁“图兰泽”这颗邪恶的行星……」</p><p>轮回者们面面相觑。他们对此都很熟悉，这是主神空间轮回副本的剧情触发。</p><p>每当通关一个轮回副本，都会滚动出这样的剧情梗概。</p><p>当出现这样的字幕，就说明他们终于解决了这个S级副本。</p><p>众人蛇鼠一窝，弹冠相庆。</p><p>剧情过完，终于可以回主神空间了。</p><p>……但什么也没发生。他们并没有触发副本结束后的传送。</p><p>整个宇宙，凝固住。</p><p>翻滚的熔岩停止流动，电离气体如同被冻结的冰雕，远处恒星的光芒定格在传播途中，连卫星上轮回者们惊愕的表情都僵在脸上。</p><p>紧接着，是比之前强烈千万倍的凝滞感。</p><p>如果把宇宙比作连续播放的胶卷，此刻，摄像机按下了暂停键。</p><p>然后，是“灵能消退”，末法时代到来。</p><p>队长试图张开真仙级别念力场，却发现那如臂使指的力量变得滞涩无比，范围急剧缩小，强度暴跌！</p><p>仿佛构成力场的基础规则正在瓦解。</p><p>影子更是惊恐地发现，自己与阴影的联系变得断断续续，时有时无，仿佛信号不良的电台。</p><p>他脚下的阴影剧烈地波动着，如同沸水，不受控制地时而膨胀，时而收缩。</p><p>“怎么回事？！”</p><p>“我的力量！我的装备！”</p><p>“主神！主神空间！出bug了？！”</p><p>卫星上的轮回者小队们，不仅没有被传送回主神空间，而且，自己身上包括周围的世界，都发生了显而易见的异变。</p><p>恐慌如瘟疫般瞬间蔓延。</p><p>所有轮回者惊恐地发现，方才兑换的力量、技能与装备，正以骇人的速度崩解退化。</p><p>仿佛支撑这一切的根基被骤然抽离，连一丝回响都未曾留下。</p><p>而这，仅仅是毁灭的序幕。有人颤抖着抬头，便撞见了足以冻结灵魂的景象：</p><p>星河正在熄灭。</p><p>一颗，两颗，三三三颗……星群如被狂风扫过的烛火，成片坠入绝对的黑暗。</p><p>就连那颗遭重创的图兰泽行星，表面熔岩的炽烈光芒也在飞速黯淡。</p><p>星球内核正沉入永恒冰封，走向死寂。</p><p>脚下的卫星地面开始“软化”。</p><p>坚硬的岩石如同浸入强酸的金属，在无声中消融，边缘晕染成模糊的雾霭。</p><p>空间本身泛起褶皱，光线在众人周遭诡异地弯折，织就怪诞的光晕与重影，仿佛现实被揉成了一团废纸。</p><p>时间也陷入疯狂的紊乱。有人感到光阴被无限拉长，每一秒都漫长得如同永恒；有人则眼睁睁看着指尖在眼前飞速苍老，皱纹如蛛网般蔓延；更有人觉得自己被撕裂成无数碎片，同时栖身于过去的尘埃、现在的喘息与未来的惊鸿一瞥中。</p><p>那些实力较弱，或是力量过度依赖主神空间规则的轮回者，身躯开始变得透明。</p><p>他们在绝望中徒劳地抓挠，最终化作漫天细碎的光点，如被风卷走的沙砾。</p><p>队长的五人小队背靠背而立，脸色惨白如纸。</p><p>刚刚涌来的力量如退潮般散尽，甚至比最初还要虚弱。</p><p>他们望着成片熄灭的星辰、脚下消融的大地、周围蒸发的同伴，望着这片无可逆转地滑向死亡与虚无的宇宙。</p><p>永恒的黑暗裹挟着万物衰败的死亡气息，骤然降临。</p><p>宇宙正在死亡。</p><p>一股冰冷彻骨的明悟如毒蛇般缠上心脏——</p><p>主神，不见了……</p><p>但是，杨帝出现了。</p><p>他立于一块尚未完全溶解的卫星岩体边缘，心中早已明了：</p><p>支撑这世界的“天外圣人”已然逝去。</p><p>他们这些“域内凡人”，连同这个宇宙，正走向存在的终极的死亡。</p><p>超大批量的“域外天魔”，从世界的尸骸上诞生。</p><p>群星熄灭的深空背景，已经开始蠕动起深邃黑色的扭曲之物。</p><p>“白杨世界，领域展开！”</p><p>嗞——！！</p><p>一道无形却凝练到极致的边界，以他为中心轰然扩张，现实的法则被强行改写。</p><p>太乙真仙五人看见，他们目力所及的所有世界线中，轮回者都被笼罩在“白杨世界”之内。</p><p>包括他们自己，不知何时，也被杨帝大神的领域所笼罩。</p><p>领域之内，崩溃的狂潮猛地停滞。</p><p>正在溶解的卫星岩体凝固了边缘的模糊，宛如被按下暂停键；紊乱的光线短暂地恢复笔直。</p><p>那些濒临消散的轮回者身躯瞬间稳定，虽力量微弱无可挽回，但好歹没有跨过鬼门关就把腿收了回来。</p><p>“书写结束了。”</p><p>杨帝的声音穿透宇宙崩溃的背景噪音，清晰地传入每个幸存者耳中，带着洞悉一切的平静。</p><p>“墨迹已干，书页将焚，字迹焉存？”</p><p>他的目光穿透领域界壁，望向那片正加速坠入永恒虚无的外界。</p><p>领域之外，是彻底的死寂。</p><p>亿万星辰逐一熄灭，从亿万颗到百颗，再到十颗、五颗、三三三颗、两颗、一颗……</p><p>最后一片残存星光的星域，仿佛被无形巨手拂过，光芒彻底湮灭。</p><p>最终失去所有形态，归于一片混沌的、无法描述的“非存在”。</p><p>他们存在的“叙事”，正在被撕碎、焚烧。</p><p>而他们自己，是书页上的“字迹”。若被焚毁了书页，字迹焉存？</p><p>轮回者们——包括苟道巅峰的五人小队——看着超越想象力的宇宙终焉景象，无不面色惨白，灵魂战栗。</p><p>不少san值过低的人已经开始肢体扭曲，面容似伪人——因为相由心生。</p><p>统御诸天万界，管理主神空间的——主神……祂大抵是已经死了。</p><p>杨帝不知道在祂身上发生了什么，他知道自己必须先活下来。</p><p>世界的死亡，疯狂地吞噬着一切现实。</p><p>当整个宇宙的“现实”都在崩塌、消亡时，维持这个堡垒本身所需的“现实”——即定义领域内一切存在、法则、逻辑，都在被疯狂腐蚀、疯狂摧毁。</p><p>领域边缘，无形的界壁如同被亿万把虚无之刃疯狂切削，发出令人灵魂撕裂的尖啸。</p><p>但白杨领域本身，就是杨帝。</p><p>于是，他的“现实丰度”在绝境中燃烧、沸腾、攀升！</p><p>为了对抗外界虚无侵蚀，而进行的疯狂自我现实加固。</p><p>「世界之死」的杀伤力，似乎超过了世界本身的规格。</p><p>这一次，杨帝再度感受到超越指数级的“幂塔级”数值膨胀！！</p><p>「现实+3↑↑1+3↑↑2+3↑↑3……」</p><p>数值递增，并不是严格按照他意识中弹出的那个“数字”来增加。</p><p>更准确地说，他脑袋弹的这些数字，只是为了方便坐在观众席上的读者们理解，那是一条怎么样的曲线。</p><p>譬如，当他的现实丰度加1+1+2+3+5+8时，并不一定代表说——现实总量是严格意义上增加了20。</p><p>而是指：杨帝的数值暴涨，遵循黄金分割率指数函数的曲线。</p><p>当数值上升到“曾经的伤害已无法改变基准态杨帝”时，便会戛然停下。</p><p>“幂塔级”增长也是如此。</p><p>3↑↑3已经是个13位数，而3↑↑4更是约有三三三万六千亿位数。</p><p>杨帝的数值增长，在3↑↑3和3↑↑4之间开始放缓（退化为普通的致命伤）再放缓（退化为蛐蛐重伤）最后近乎停滞（造不成伤害）。</p><p>他的血肉、骨骼、意志乃至构成他本质的每一个信息单元，都在对抗“世界之死”的侵蚀中，被淬炼得超越凡俗理解。</p><p>道生一，一生二，二生三三三，三三三生万物。</p><p>“此界已死，新世当生。”</p><p>“白杨世界——展开！！！”</p><p>不再是抵抗，不再是维持，而是……创生！</p><p>嗞——轰隆隆！！！</p><p>那道原本坚韧却收缩的领域边界，如同被点燃的宇宙奇点，以超越光速、超越空间概念的方式，猛烈地向外膨胀。</p><p>与其说是“膨胀”，不如说是“爆炸”。</p><p>一场崭新的宇宙大爆炸！</p><p>大爆炸所及之处，混沌的虚无被强行撕裂、拉伸、折叠，形成全新的时空结构。</p><p>无数晶莹剔透的几何体在虚空中自发凝结、旋转，勾勒出新宇宙的骨架。</p><p>闪烁着柔
