# 宇宙尽头 考公

<p>那辆银白色的人形无限机兵，其冰冷的光学传感器在杨帝和耶罗之间短暂地徘徊，内部似乎正在进行超越光速的逻辑演算。</p><p>片刻的绝对寂静后，那绝对中性的声音再次响起，精准地投向杨帝：</p><p>「信息更新。根据‘圣人’耶罗于■■前提交的预备案，及本次事件现实特征签名与预设参数高度吻合。」</p><p>「确认：未知实体‘杨帝’，为耶罗推荐予星环盟约的待考察人才。潜在评级：虚空圣人（待进一步验证）。」</p><p>它们声音很奇特，杨帝能直接听见“括号”中的内容。</p><p>似乎是某种超越八识的感知。</p><p>随着它的声音，在它旁边，虚无被无声地裁剪开。一扇门出现了。</p><p>那是个规则的绝对几何平面，其内部是更深沉无比，仿佛经过严格消毒和规整后的空间。</p><p>敞开的门扉是一种邀请。</p><p>「基于此推荐，常规身份质询流程暂缓。」</p><p>机兵继续说道，它那流畅的手臂抬起，指向那扇银色的门。</p><p>「请‘杨帝’，即刻搭乘指定运输单元，通过此临时批准的太一矩枢甬道，前往星环盟约第一枢纽进行初步接入与评估。你的配合将影响最终评级与资源配给。」</p><p>耶罗的破碎光影在一旁微微晃动，狐尾尖轻轻扫动，像是在无声地耸肩。</p><p>杨帝的白杨世界屏障纹丝不动。</p><p>他的意念穿透屏障，比周围的绝对虚无更加冰冷，带着不加掩饰的质疑：</p><p>“如果，我拒绝呢？”</p><p>「拒绝配合评估，即视为自动放弃‘耶罗推荐人才’所享有的潜在权益与快速通道资格。」</p><p>人形无限机兵的传感器光芒恒定，没有丝毫波动，仿佛这个问题早已被写入应对协议的底层。</p><p>「同时，根据《星环盟约泛宇宙安全宪章》第阿列夫一·补充条款，任何未经登记、无法解析且拒绝接受监管的阿列夫一级或以上潜在变量，将被重新归类为‘不稳定实体’。」</p><p>它的声音没有任何威胁的意味，只是在陈述一个冰冷的事实：</p><p>「对于‘不稳定实体’，盟约将……」</p><p>「将强制你加入神圣星环盟约正式编制。」</p><p>杨帝：“……？”</p><p>那声音毫无波澜，继续宣读，如同在念一份标准的人事录用通知：</p><p>「入职即享受二十险五金，包含但不限于：跨维度医疗全保、概念级意外险、灵能枯竭补偿金、时空稳定性公积金、真灵不灭抚恤金等。」</p><p>「每年度享有定额的柴、米、油、盐、燃料补贴，可折现为通用宇宙信用点。」</p><p>「工作内容包括，维护所辖叙事域的基准态稳定，监控异常高能波动，阻止非法叙事层入侵及破坏性探索等……」</p><p>「义务包括，必须按时参加星环组织的技能提升培训，如《高维冲突调解技巧》、《灵能阈值精准控制》、《多元宇宙基础法条解读》等，及思想研讨会，研讨会主题包括《论维持现实基准恒定的必要性与崇高性》、《如何正确处理下位叙事域原生文明诉求》、《神圣星环盟约核心价值观学习》等……」</p><p>「考核要求包括，定期提交辖区《乡村宇宙改报告》及《城乡结合潜在风险排查与处理预案》等……」</p><p>杨帝那凝聚到极致的灵能，差点当场失控暴走。嘴角抽了一下，又搐了一下。</p><p>他张了张嘴，想说什么，喉咙有点干涩。</p><p>像是圣斗士凝聚毕生信念打出天马流星拳，却一拳打在一光年厚的棉花上。</p><p>不，是打在了厚厚一沓《员工手册》和《思想汇报范文》上。</p><p>“所以神圣星环盟约，你们是要招安我？”</p><p>「如果您想用这个表述，也是可以的，陌生的虚空圣人级实体。」</p><p>无限机兵的扬声器如是说道。</p><p>杨帝思想斗争片刻，进入了作为“邀请”的敞开之门。</p><p>舱门“咔”地合上了。</p><p>没震动，没声响，连半分移动的感觉都没有。</p><p>但透过那看似透明、实则封闭的舱壁，杨帝清楚地看着外界景象变化。</p><p>耶罗那碎成渣的光影，还有后头那能压垮人神经的狐狸分形宇宙群，正以一种压根没法用速度衡量的架势“往后缩”。</p><p>不像是它们在动，也不像是机兵在跑，更像是彼此间的“联系”被硬生生扯断拉长。</p><p>直到那狐形轮廓淡得像团雾，最后“噗”地融进虚空里，连瞅都瞅不见了。</p><p>虚空里，就剩下四面八方、铺天盖地的银白色机兵，照出一条没声没响的路。</p><p>直到此时此刻，被这片银白色的死寂裹得严严实实的杨帝，才后知后觉打了个颤——</p><p>“无限机兵是无人驾驶？”</p><p>「否。由第四席『太一矩枢』统一操控。」</p><p>“你们……不是用于战争的杀伐机器？”</p><p>「判断目标存在理解偏差，我将启动标准流程解释模块。」</p><p>距离杨帝最近的一具机兵，非金非玉的哑光表面流淌起柔和的银辉，庞大而充满力量感的机体，如折纸艺术般重组收缩。</p><p>机械臂优雅地收叠，棱角分明的胸甲如花瓣般内折，粗壮的腿部构件灵活地回旋。</p><p>最终，化为了一辆悬浮于虚空中，线条同样流畅冷硬，充满未来科技感的面包车！</p><p>酷似面包车，但本质上并非面包车的载具。</p><p>那辆悬浮的“小车”发出了与刚才亿万机兵阵列同源、但音量柔和了许多的合成音。</p><p>听起来比先前凶神恶煞的机兵语音，要无害得多。</p><p>「根据《神圣星环盟约》人事管理条例第1章第1款，您符合‘特殊人才引进’条款。」</p><p>「现为您提供公务专车服务的编号为：∞-Ω-007。目的地：‘星环盟约第一枢纽’进行初步接入与评估，并参加岗前统一培训。」</p><p>公务专车？！</p><p>平生第一次，杨帝实在无法理清现状。</p><p>无穷浩瀚的机兵海洋，它们每一个，都能够变成这样一辆“公务专车”。</p><p>也就是说，神圣星环盟约所谓用来“镇压一切不服”的无限机兵，其日常形态，或者说其主要功能之一，竟然是给编制内的“公务员”当……通勤工具？！</p><p>他感觉自己不是站在宇宙终点的反抗者，而是闯进了某个庞大到无法理解的超级官僚机构招聘现场。</p><p>宇宙的尽头是考公，地球人诚不欺我……</p><p>顿时一阵气馁。</p><p>杨帝上车了。他要看看，这星环盟约究竟是什么货色，究竟在做些什么。</p>
