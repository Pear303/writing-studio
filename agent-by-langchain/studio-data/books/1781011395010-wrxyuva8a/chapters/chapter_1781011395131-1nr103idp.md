# 麻子大盗

<p>精灵望向奥拓消失的地方，笑道：“这矮人每次来都风风火火的，不过他带来的熔岩蜂蜜，确实是世间少有的美味。”</p><p>据说那是一种居住在岩浆池旁的蜜蜂，从生长在岩浆池旁的花朵，采撷出被岩浆烘烤许久的花蜜，酿成的岩浆形态的蜜糖。</p><p>再来一只野生熔岩史莱姆，将这些野生蜜糖吞下。</p><p>蜜糖史莱姆体内经过发酵，最后便可剖开取出。</p><p>史莱姆罢了，并不重要。</p><p>伊芙不是原教旨精灵，史莱姆这东西她当零食碎嘴吃的，也没什么好忌讳。</p><p>瑞弗维尔拿起铁皮盒，挖出一勺蜂蜜，淋在剩下的烤蘑菇上。</p><p>蜂蜜遇热瞬间融化，与蘑菇香气完美融合，散发出更加诱人的气息。</p><p>伊芙取出两个陶制酒杯，缓缓倒满。</p><p>两人端起酒杯，碰了一下，仰头饮下。</p><p>酒液入口，一股炽热的暖流顺着喉咙滑下，却又带着一丝麦芽香甜。</p><p>夕阳的余晖与火山迸发的火光交织，将林中小路浸染成一条熠熠生辉的“金色通道”。</p><p>他们谈天说地，最后聊到第一次遇见奥拓时的情景。</p><p>“当时你还把他误认为通缉令是的那个‘铁熔堡大盗’，可他只是神态相似罢了，脸上明明没有麻子。”</p><p>“有无麻子并不重要，真正关键的是实力。就像你野史里写的那些传奇法师，即便顶着满脸麻子，只要抬手间能召唤雷霆，照样能让万千信徒顶礼膜拜。”</p><p>“伊娃，你自己也说了，只有传奇法师、超级大能等位高权重者，脸上有麻子时，才不会被人当作嘲讽之谈资，甚至能被解读成星象图，预言圣古琉斯之国运。可对奥拓那样的普通人而言，脸上的麻子，会被说是打铁时火星溅的瑕疵，又或者是什么家族遗传的先天性皮肤病，终身无法治愈的超级绝症……”</p><p>“哼嗯，或许有朝一日，当奥拓能用那把钻头劈开星辰，并且身高长到1米8，他脸上的每颗麻子，都会成为铭刻在历史里的星辰。”</p><p>“不管了，我们先为熔岩蜂蜜，干一杯。”</p><p>数百里外。</p><p>“阿嚏。有人背后议论我。”</p><p>奥拓想了想，或许并非有人议论他，而是这地下洞确实太冷了。</p><p>他此刻正在挖洞——不是盗洞，还是普通的地洞。</p><p>地洞离地表近，仅仅数十米深，地热影响有限；没太阳晒，还缺空气流动“搬”热量，自然比地上冷啦。</p><p>如果要长途赶路，奥拓总是用挖地洞代替地面行走。</p><p>矮人估算过，这柄由狱髓锻造、附魔加持的神器钻头，每秒能掘进五十米，相当于他在地面全力奔跑速度的五倍。</p><p>钻头能裹挟这奥拓，在地下“飞行”。</p><p>更妙的是地下路径的直线优势。若在地表穿越森林和丘陵，需绕行三十余处天险，耗时整整三天。</p><p>而地下隧道只需精准定位，沿着岩层断层斜插而过，并在钻头拖拽下，奥拓仅需三个小时便能抵达。</p><p>而他的目的地，仍然是铁熔堡，矮人建立起来最庞大的工业城邦。</p><p>看看有没有机会摆脱“绑定诅咒”的木镐。</p><p>话说，百年前卡利斯托巨龙与圣骑士巴德决战，它为何在垂死关头，会选择用“绑定诅咒”无差别诅咒战场上的东西？</p><p>……</p><p>……</p><p>百年前。</p><p>星渊井口的焦土上，卡利斯托巨龙的龙息将云层都染成了血色。</p><p>圣骑士巴德的银甲在火光中明灭，他挥舞着符文巨弓，头盔上还沐浴着巨龙鲜血。</p><p>“我不能死，我不能输！！！等这场战斗结束，等我打完这仗，我就和她结婚，陪她去海底看珊瑚！”</p><p>这句话让卡利斯托发出震天怒吼。</p><p>它扭曲着庞大的身躯，逆鳞处惊心怵目的伤口喷涌出黑紫色的血——逆鳞，巨龙不可触的弱点，同时也是被巴德的圣银箭矢贯穿的地方。</p><p>巨龙眼中翻涌着浓稠的嫉妒，比它巢穴里堆积的黄金还要刺眼。</p><p>「该死的人类，凭什么拥有这样的幸福！」</p><p>卡利斯托容不得有人对它发狗粮。于是仰天咆哮，全身鳞片迸发出诡异的绿光，无数墨绿色咒文从巨龙体内爆发，如蛛网般笼罩整个战场。</p><p>「我诅咒你与星渊井口的焦土、熔岩永恒绑定束缚，永世不得脱离！」</p><p>话音未落，巨龙庞大的身躯轰然倒地。</p><p>而巴德的长剑，此刻已深深嵌入他的手掌——无论怎么用力，都无法将其拔出。</p><p>他只能看着自己被咒文包裹的手，绝望地意识到：他再也无法兑现带她看珊瑚的承诺了。</p><p>圣骑士单膝跪地，剧痛如毒蛇啃噬着掌心。</p><p>忽有一团幽蓝磷火自天穹坠落，落地化作三寸长的蝶形蛊虫，翅翼上流转着古老的梵文，每振翅一次便有清越的铃音回荡。</p><p>“人类人类，你为何悲伤？”蛊虫口吐人言。</p><p>巴德悲伤地说：“我与爱人约定共赏海底珊瑚，可这诅咒将我禁锢在此地。”</p><p>蛊虫说：“吾乃真心蛊。交出你最深沉、最赤诚的圣光信仰，我便为你斩断这诅咒。”</p><p>圣骑士眼中燃起希望，却又在刹那间黯淡。他望着星渊井口翻涌的熔岩，想起教会典籍中“不可与邪祟交易”的训诫，喉结滚动咽下苦涩。</p><p>“圣光教导我们，苦难是灵魂的试炼。”</p><p>蛊虫说：“可你眼底倒映着是她的笑颜，是海底珊瑚摇曳的幻影。人类啊，在我面前，连圣徒的忏悔都是谎言。”</p><p>巴德思想斗争了三天三夜，最终嘶吼着答应了：“我愿以背弃圣光为代价！”</p><p>真心蛊发出愉悦的尖啸，化作流光没入他丹田，刹那，墨绿色的龙语诅咒寸寸崩裂。</p><p>这就是人类第一次收服九转蛊虫“真心蛊”的真实记录。</p><p>……</p><p>……</p><p>奥拓“哇呀”一声从土里探出头来。</p><p>他看见许多人在城墙下，围着一个东西叽叽喳喳。</p><p>走近，一看，喵个咪，是自己的通缉令。但是……</p><p>“特喵了个咪！我不长这个样！！”奥拓恼了。</p><p>他一眼就看见通缉令上自己的脸，又凭空多画了几颗麻子，不由得怒从中来。</p><p>退一步越想越气，他现在就想冲进铁熔堡，抓住画他画像的人，当场问责。</p><p>不过也好，画得越抽象，越少人能认出他。奥拓想了想，于是转身向城内走去。他还要买东西，等回到镇子再生气也不迟。</p><p>事实并不重要，如何描述事实更重要。</p><p>城墙下贴的那一张通缉令，通缉令上，面部长满麻子的“大盗”，已经在奥拓内心深处埋下一粒种子。</p><p>考古学≠历史学。</p>
