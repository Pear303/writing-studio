# 耶罗本体

<p>杨帝扼住赤狐脖颈的手，纹丝未动已逾永恒。指下喉骨的碎裂声微不足道，真正的交锋在更深层展开。</p><p>他的意志化为手术刀，沿着指尖与皮毛接触的微小界面，刺入耶罗存在的核心网络。</p><p>那覆盖10^95宇宙、构成狐狸分形的庞大“根系”，在他阿列夫零层级的感知下纤毫毕现。</p><p>每一个宇宙中，属于耶罗的“容器”都被精准定位：</p><p>稷海市出租屋码字的扑街写手——抹除。</p><p>赛博都市操控数据洪流的黑客——覆盖。</p><p>魔界编织命运之网的古老存在——替换。</p><p>废土末世低语启示的癫狂先知——湮灭。</p><p>甚至那些潜藏在宇宙法则背景辐射中的细微意志碎片一一清扫。</p><p>杨帝的白杨世界领域无声扩张，以媲美外科手术的方式覆盖与取代。</p><p>你是否见过水银在地上流淌的情景？白杨世界领域就如同打碎了水银温度计，流淌过耶罗构筑的每一寸叙事疆域，渗透每一个幻梦泡影的缝隙。</p><p>属于耶罗的色彩和意志，属于它的签名，被强行剥离与抹去，替换成杨帝永恒维持基准态不变的“纯白”色烙印。</p><p>赤狐在杨帝手中剧烈颤抖。</p><p>用形象的比喻来说，它正在被杨帝剥皮，将狐皮覆盖到杨帝自己身上。</p><p>它覆盖赤红绒毛的身体开始变得透明，虚幻，如同信号不良的投影。</p><p>楔形的黑曜石竖瞳中，爆发出无法抑制的惊怒与难以置信。</p><p>“你……竟敢……扒我的皮！”它的意念在杨帝的钳制下破碎扭曲。</p><p>来不及了。覆盖10^95宇宙的清洗和覆盖，在虚空的绝对时间尺度上已然完成。</p><p>耶罗大仙寄托于无穷容器的意志锚点，被杨帝的白杨领域彻底覆盖与替代，彻底斩断终结。</p><p>“吼——！！！”</p><p>一声超越声音范畴、直接撕裂虚空的咆哮，从杨帝掌中那濒临消散的赤狐投影体内爆发出来！</p><p>杨帝松手。</p><p>赤狐的投影如同被风吹散的沙画，瞬间溃散成虚无的赤红光点。</p><p>但就在投影消散的原点，虚空本身……裂开了。</p><p>无法形容的庞然之物，从这道裂缝中挣脱出来！</p><p>它没有具体的形态，或者说，它的形态就是“无限分形”本身。</p><p>虚空之中，狐狸轮廓凭空显现。</p><p>但它的每一根毛发末端，都延伸出更小、更精细的狐狸轮廓；那些更小的狐狸轮廓，其毛发末端又延伸出更加微小的狐狸……</p><p>如此层层嵌套，无限递归，直至超越一切观测极限的微观尽头，分形仍然在嵌套延续，直至极限也永不终止……</p><p>它并非由物质构成，而是由沸腾的灵能和充满恶意的叙事凝聚！狐狸毛色的赤红，如同星云燃烧，在其无限分形的结构中流淌咆哮。</p><p>那双如同楔形黑曜石的竖瞳，死死锁定着杨帝。</p><p>横亘虚空，脱离宇宙！</p><p>其存在本身，就挤压得周围的虚空和宇宙被挤压退散。</p><p>这才是耶罗大仙的本体！</p><p>一只以无限分形结构存在于虚空之中，掌控10^95宇宙叙事根系，但在杨帝剔除它所有“容器”后，被彻底逼出老巢的——万业狐狸！</p><p>那双黑暗奇点般的巨瞳中，燃烧着被蝼蚁掀翻巢穴的滔天怒火，以及被逼入绝境的疯狂。</p><p>“杨！帝！”</p><p>它的意念如同亿万宇宙同时崩塌的轰鸣，裹挟着毁灭一切的叙事风暴，狠狠砸向那个渺小如尘埃的身影。</p><p>“哈哈哈哈——！”杨帝的笑声如同亿万星辰炸裂的狂啸，在死寂虚空中卷起混沌风暴。</p><p>他黑发乱舞，眼中燃烧着比星辰更炽烈的战意，一步踏出，无视那横亘虚空、威压万古的万业狐狸！</p><p>“当年漠视众生如蝼蚁，生杀予夺一念间！”</p><p>“如今现出这副臃肿狗样，尿骚味隔着虚空都能闻见！”</p><p>“耶罗！你的逼格，碎了一地！”</p><p>“我说你是狗，完全不为过，因为狐狸就是一种犬科动物！”</p><p>话音未落，杨帝的身影已消失在原地。</p><p>下一瞬，他已出现在那无限分形巨狐如宇宙般硕大无朋的头颅正前方！渺小如尘埃，气势却崩裂寰宇！</p><p>一拳！</p><p>蕴含着他一路吞噬，一路进化，踏破无穷宇宙、凝练至巅峰的中间态无穷级伟力。</p><p>虚空之中没有时空，没有维度，没有能量与物质等一切构成秩序宇宙的相关概念。</p><p>存在的事物在此处不存在，不存在的事物在此处亦不存在，就连存在与否的概念在此也不存在。</p><p>但杨帝的拳头，强行定义出其轨迹、动量、能级……和最终的命中目标。</p><p>咚——！！！</p><p>令虚空颤栗的巨响炸开！</p><p>拳锋狠狠印在那由沸腾灵能与恶意叙事凝聚的无限分形赤红狐首之上。</p><p>但预想中的头颅炸裂，狐毛纷飞，并未出现。</p><p>那看似由混沌橡皮泥捏成的狐首，竟纹丝不动。</p><p>杨帝那足以崩碎无穷宇宙的一拳，如同泥牛入海，冰雪进熔炉。</p><p>只在那赤红的分形结构表面，激荡起一圈圈细微到几乎不可见的涟漪。</p><p>涟漪层层扩散，沿着毛发末端无限延伸的更小狐狸轮廓传递、分散、消弭……最终归于零。</p><p>这化劲手段……不是一般狐。</p><p>耶罗那巨大如同星系漩涡的黑暗竖瞳中，滔天怒火被一丝冰冷的嘲弄取代。意念轰鸣：</p><p>“蝼蚁之力，也敢撼天？”</p><p>“吾之本相，超脱尔等认知之穷尽！岂是尔能伤？！”</p><p>“还有，吾并非犬科狗，唯独这一点，你大错特错。”</p><p>巨狐昂首，一只覆盖着赤红分形毛发的巨爪抬起。爪中并非空无一物，而是不知何时，多了一物。</p><p>一本。书。</p><p>书页非金非玉非皮，看似只是最普通的纸。</p><p>还有。一支笔。</p><p>笔尖流淌着暗红的光，如同干涸的血与凝固的墨。</p><p>耶罗的意念带着审判般的冰冷：</p><p>“吾为话本编撰者。”</p><p>“吾执掌万业之书。笔落，则命运成灰。”</p><p>巨爪执笔，在那混沌星辉的书页上，闪电般写下两个扭曲的字符。</p><p>「杨」「灭」</p><p>字符落成，刹那。</p><p>轰隆——！！！</p><p>杨帝所在的那片虚空，连同其存在本身，毫无征兆地轰然炸裂。</p><p>他的躯壳，他的意志，他超越无穷的灵能，如同被投入碎纸机的画卷，瞬间被撕扯成亿万万片闪烁着微光的碎片。</p><p>叙事抹杀。</p><p>然而，就在那亿万万碎片即将彻底归于虚无的前一瞬。</p><p>所有的碎片猛地向内坍缩汇聚，如同倒放的毁灭录像。</p><p>亿万分之一刹那，杨帝的身影完好无损地重新凝聚于虚空之中。</p><p>黑发依旧，像触手怪般在虚空中狂舞，仿佛刚才那足以抹杀圣人的破灭，只是一场幻梦。</p><p>“哼！”杨帝甩手，仿佛掸去不存在的尘埃，“挠痒痒么？老狐狸！”</p><p>就在这时——</p><p>嗡！嗡！嗡！</p><p>那无边无际的无限机兵银白之海，发出冰冷的机械的广播：</p><p>「警告！」</p><p>「侦测到超高强度非法叙事扰动！」</p><p>「目标个体杨帝！立即停止攻击行为！」</p><p>「目标个体耶罗！立即解除武装形态！」</p><p>「放弃抵抗！接受拘捕！」</p><p>「星环盟约将给予公正审判！」</p><p>「重复！放弃抵抗！」</p><p>银白的炮管森林齐齐调转方向，毁灭性的能量在无数炮口汇聚，冰冷的锁定感如同亿万根钢针扎在杨帝与耶罗的灵觉之上。</p>
