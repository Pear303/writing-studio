# 反抗天命，亦是天命

<p>“三百？！什么三百！你说清楚，耶罗！！”</p><p>杨帝最憎恨谜语人。这种讲谜语的行径，严重触犯了银河正义法中的讲话不说清楚之罪。这项罪名，可以与种族灭绝相提并论。</p><p>耶罗大仙不语。</p><p>祂对着杨帝和阿巴，露出了一个更加纯粹，更加无辜的微笑。</p><p>杨帝的眼瞳深处，那源自洪荒、吞噬了四大邪神意志的力量轰然爆发！</p><p>“吼——！”</p><p>吼声来自他每一个被强行冻结的细胞，来自他意志最狂暴的呐喊。</p><p>凝固的时空如同被投入巨石的冰湖，以他为中心，炸裂开蛛网般的裂痕！</p><p>强行运转的力量甚至让他自身的血肉都发出啸叫，骨骼嘎吱作响，仿佛下一秒就要被自身的力量撑爆。</p><p>但他终于，硬生生撕开了那无所不在，冻结一切的伟力！</p><p>托着阿巴的手瞬间化为撕裂虚空的利爪，凝聚着足以将星辰碾为尘埃、将法则焚成虚无的狂暴能量，毫无花哨，带着最纯粹的愤怒与毁灭意志，一拳轰向那张挂着纯真笑容的脸！</p><p>“给老子说清楚！！！”</p><p>面对这足以重创乃至毁灭一个新生宇宙的一击，耶罗大仙——或者说，披着青丘白璃外皮的祂——甚至连睫毛都没有颤动一下。</p><p>那三十六条铺满虚空的橙黄狐尾，其中随意的一条尖端，慵懒地轻轻向上一拂。</p><p>杨帝那足以粉碎星河的拳头，在距离那张纯净无瑕的脸庞仅剩毫厘之遥时，如同撞上了一层超越了所有维度概念的叹息之壁。</p><p>杨帝足以贯穿宇宙的拳锋，如同撞上礁石的脆弱浪花，瞬间消弭于无形。</p><p>「次元壁」</p><p>时间与空间的碎片在拳尾交击处无声湮灭，构成宇宙的基础法则在那里像被揉皱的糖纸般褶皱扭曲，却又在下一个瞬间被一种更宏大、更不可违逆的意志强行抚平。</p><p>杨帝的手臂保持着出拳的姿态，僵硬地停在半空。</p><p>「杨……反抗天命……亦是天命。」</p><p>杨帝嘶声吼道：“你说的‘不会有刀’踏马是什么意思？！”</p><p>她、祂垂下长长的睫毛：「很久以前，我已告诉，你——爱与正义。」</p><p>然后，就像出现时那样，身影连同那遮天蔽日的赤橙色狐尾，开始无声无息地淡化虚化。</p><p>如同滴入水中的墨迹，在凝固的时空里晕开。</p><p>仿佛祂从未出现过。</p><p>又仿佛，祂无处不在，祂于万物之中。</p><p>咔……嚓……</p><p>一声极其轻微、却又清晰得如同在灵魂深处响起的碎裂声传来。</p><p>凝固的宇宙，那被按下的暂停键，松开了。</p><p>时间重新流淌，空间恢复延展，因果继续编织。</p><p>“老大……那就是你最憎恶的谜语人……那个什么……耶罗大仙？”</p><p>杨帝不语，只是伸出手像以前无数次那样，狠狠揉了揉阿巴冰凉的鱼脑袋。</p><p>他的目光再次投向那深邃无垠、看似平静却已暗流汹涌的星海。</p><p>投向那耶罗大仙——或者说，青丘白璃——可能存在的任何角落。</p><p>“老大……她到底想干什么？为什么？为什么藏到现在才露尾巴？这么多年，她就在我们身边装傻充愣，看戏吗？！看我们像无头苍蝇一样撞得头破血流？”</p><p>“鱼仔，她不是在‘藏’。我觉得，她只是在‘观察’，或者说……在‘引导’。”</p><p>“引……引导？”</p><p>“她说的‘天命’，更像是被设计好的话本、或剧本。‘反抗天命亦是天命’，我们的‘反抗’本身，可能就是她剧本里早已写好的，不可或缺的关键一环。”</p><p>“青丘……耶罗大仙，引导我们反抗圣人？”</p><p>“想想看鱼仔，我如何一步步走到这里的？我为何执着于追寻邪神背后的黑手？为何会执着于打破‘圣人’的桎梏？为何会坚信‘命运应由众生自决’？”</p><p>“老大你目睹了太多的不公，归墟大帝的堕落，邪神的收割，灵界、仙界对下界的操控。”</p><p>“是谁让我们如此清晰地‘目睹’了这一切？”</p><p>“不是……我们自己吗？”</p><p>“那我问你，是谁在我们追寻真相的道路上，看似‘无意’地留下线索？”</p><p>“我认为这应该归咎于我们自身的努力……”</p><p>“青丘白璃的存在本身，就是耶罗大仙投下的最大‘诱饵’和‘催化剂’！”</p><p>“老大，你偏执了。”</p><p>“青丘白璃的天真，她的依赖，她时不时流露的‘对命运不公的懵懂困惑’，她本心对爱与正义的坚信，都在潜移默化地强化我们的信念——这个世界被更高层次的力量操控，是扭曲的，是必须被反抗的！”</p><p>“老大，你喝口水先。”</p><p>杨帝喝了口阿巴召唤的纯水。</p><p>“但不论如何，青丘白璃就是耶罗大仙，是无法被歪曲的事实。”</p><p>“这个……没错。”</p><p>“你要用最大的恶意揣测祂。祂极有可能是故意引导我——决心杀灭一切‘玩弄众生因果与命运’的圣人。”</p><p>“耶罗大仙费心费力，引导你去仇视圣人，是为了什么？”</p><p>“不，也有极大可能不是引导我仇是圣人，而是反其道而行之——祂可能希望我认识到‘祂在引导我反抗天命’，从而激发我的逆反心理，让我顺从天命。”</p><p>“啊，老大，你越说我越混乱，所以祂到底是为了什么。”</p><p>“我不知道。这和剪刀石头布一样，是个无解的怀疑链。”</p><p>“……啊？”</p><p>“也许是宣告我们的‘表演’达到了祂预期的‘高潮’，我们成功扮演了祂剧本里‘反抗者’的角色，完成了她设定的‘关键剧情点’。”</p><p>“哦没错，祂自称话本编撰者。”</p><p>“祂一直都在。祂只是在我们完成了祂期待的‘壮举’，成功‘认识到上界存在’这个核心认知后，觉得是时候谢幕点题，给我们恍然大悟——或者说当头棒喝——的时刻了。”</p><p>“当头棒喝什么？恍然大悟什么？”</p><p>“她在告诉我们：游戏进入下一阶段了，你的对手不再是无聊的‘赌客’与‘荷官’，玩家该知道真正的‘庄家’是谁了。”</p><p>“那……老大，我们现在怎么办？她……祂这么强大，能赢吗？”</p><p>“会赢的，包赢的。”</p><p>“那老大，我们现在怎么办？”</p><p>“吃鳕鱼堡去，吃饱了才有力气把所有桌子一张一张掀掉。”</p><p>“好耶，咱去干碎祂。”</p><p>“不过，除了吃鳕鱼堡，我们还得干一件紧要之事。——掀桌子前，得先钉几颗钉子，确保这桌子掀了后，不会有新的‘庄家’坐上来，或者上面的‘庄家’直接伸手把牌局搅得更乱。”</p><p>“老大，你是说……”</p><p>“阿巴，你知道的，你是我的基因原体。当年我分裂出一部分体魄基因，糅合一部分灵魂模因，将你创造出来。没想到你刚出生就打破基因锁并且‘拟态’成一条深海鲈鱼。”</p><p>“没错老大，我天生自带超速再生、血源诅咒、磁场天赋、基因锁解放等天赋。”</p><p>“现在我要做的事儿原理相通，规模不同，鱼仔，看好了，这才是真正的‘钉钉子’！嗤啦——！”</p><p>“哇！比血肉撕裂更令人心悸的声音！”</p><p>“好听吧？我亲爱的傻鱼鱼。”</p><p>（后半部分尝试了一下通篇对话，发现还是很难的）</p>
