# 这次真突围了，吧

<p>一个金色头发尖耳朵，披着青绿色斗篷的东西从天而降，从最上方的火山洞口跳了下来！</p><p>然后一脚把红衣主教踹进地里！</p><p>那一脚蕴含着惊人的力量，揣在红衣主教脑门，他身躯便如同炮弹般突破音障，直直砸进地里，扬起大片尘土！</p><p>等到烟尘散去，第二席红衣主教摔落的位置出现一个深坑。</p><p>大地都为之震——震——荡——</p><p>瑞弗维尔瞪大了眼睛，简直不敢相信眼前发生的一切。</p><p>还有高手？！</p><p>那金绿色东西落地，身形轻盈地一转，稳稳地站在地上。</p><p>金色的长发随风飘动，身上洋溢着柑橘的气味。</p><p>味道不浓，清新淡雅，很解渴。</p><p>瑞弗维尔看清楚了那人形东西是什么。</p><p>极为罕见的物种，一个精灵！</p><p>传说精灵身上都有各种香味，蔬菜瓜果花草树木的清香。经常有野史描述：大魔王将精灵公主剁碎，萃取成香水。击败魔王的勇者找到这瓶香水，从此悲痛欲绝地将液态精灵送给公主，和公主没羞没臊地生活在一起……</p><p>当然，世人对精灵最典型的印象还是尖耳朵和长寿，而不是魔王的香水。</p><p>也只有饱读野史的瑞弗维尔，会有如此非主流的印象。</p><p>“香水……呸，我是说精灵，您、您是谁？”瑞弗维尔松开了去摸石头雕塑的手，结结巴巴问道。</p><p>精灵没有立刻回答，而是说：“他还活着，只是昏过去了，带他离远点。”</p><p>瑞弗维尔照做，他手忙脚乱地将杨帝背在背上，拖着熔岩史莱姆，连滚带爬地远离战场。</p><p>此时，卡利斯托似乎感受到了局势的变化，又开始蠢蠢欲动。</p><p>它巨大的身躯微微颤动，空洞眼窝中，紫色鬼火闪烁得更加剧烈，喉中发出低沉咆哮。</p><p>只见精灵凉鞋一踏，横在巨龙面前。</p><p>她那纤细的手中，出现一根简朴的木法杖。</p><p>没有任何繁琐咒语吟唱，也不见复杂的施法动作，就这样默声瞬发一道九环法术。</p><p>“湮灭之创！”</p><p>刹那，一道耀眼光芒从法杖顶端迸发。</p><p>但那“光芒”是黑色的，难以直视。</p><p>如同一团燃烧黑色火焰的“彗星”，直直射向卡利斯托！</p><p>“吼吼——！！”</p><p>卡利斯托似乎察觉到致命威胁。</p><p>它试图躲避，巨大的翅膀猛烈扇动，想要掀起狂风来干扰法术的轨迹。</p><p>但它没有躲避的机会。</p><p>黑色光芒瞬间击中卡利斯托，在它青金色鳞片上爆发出一阵绚烂而恐怖的光芒。</p><p>“嗡——嗡——嗡——”</p><p>尽管背着身，瑞弗维尔也被强光刺得短暂失明。</p><p>似是电光石火间，火山内部空腔陷入死亡般的寂静。</p><p>……不，并非寂静，而是失聪耳鸣。</p><p>卡利斯托的身体在光芒中剧烈颤抖。</p><p>它似乎在咆哮，但瑞弗维尔听不到。</p><p>它的鳞片开始一片片脱落，露出底下焦黑的血肉，而暴露出来的血肉又随之灰飞烟灭……</p><p>瑞弗维尔也被强光笼罩。他感觉到灼烧。他的后背几乎被点燃。</p><p>他试图用风衣遮住杨帝，但能感觉到，衣服也被狂暴的烈风席卷着。</p><p>仅仅是绽放出来的光，就能灼烧万物……</p><p>这就是九环法术吗……</p><p>灼烧感突然被祛散大半，瑞弗维尔松口气，感觉到视力也慢慢恢复了。</p><p>他缓缓睁开眼，看向身后。</p><p>精灵跨步，背对着他们，法杖反手，指向身后杨帝、瑞弗维尔二人。</p><p>权杖顶端释放出淡淡冰凉、蕴含某种灵能的水汽，笼罩着瑞弗维尔他们，让他们免于被光和热所焚灭。</p><p>精灵自己则暴露在光与热之下。</p><p>她却毫发无伤，紧紧注视前方。</p><p>而山寨版卡利斯托，已经暴死了。</p><p>它整个上半身直接汽化，空气中弥漫着炽热的岩石和血肉蒸汽，它所站立的地方残余一个熔岩巨坑。</p><p>只在原地留下一对后肢，其中右肢还缺了三个脚趾。</p><p>就算是生命力比小强还顽强的史莱姆，被打得只剩脚趾，也至少得丢半条命。</p><p>而对于巨龙这种复杂生物而言，脚踝以上全部截肢，它还有什么资格活下来？</p><p>一击秒杀，恐怖如斯。</p><p>“龙还没死，你们先走。”精灵伸出一只纤细手指，对着灵能轿厢的方向一划。</p><p>“砰！”原本被堵塞的入口轰然破开。</p><p>卡利斯托还没死？！</p><p>瑞弗维尔知道，自己在她面前没资格反驳任何一句话，只能扛起杨帝，朝他们进来的入口奔去。</p><p>但在逃出生天前。</p><p>他还是忍不住扭头看了一眼。</p><p>卡利斯托残余的前肢似乎有暗红色的血肉蠕动，膨胀出来……</p><p>不对，与其说是血肉，不如说更像是——</p><p>熔岩史莱姆？</p><p>只见那暗红色的物体越来越大，逐渐从卡利斯托的残骸中脱离出来。</p><p>一大团蠕动的暗红色果冻。</p><p>新生的“卡利斯托”没有定形，就与熔岩史莱姆相似，只是体积要大上数百倍……</p><p>它表面滚烫，散发着炽热气息，所过之处，地面的岩石都被融化成一滩岩浆。</p><p>那群教廷术士也纷纷从岩壁上跳下来，站在史莱姆一边。</p><p>精灵则拦在他们面前，1 vs N，遥相对峙。</p><p>在瑞弗维尔想要看得更清楚前。</p><p>灵能轿厢启动了，他们沿着轨道冲出火山。</p><p>……</p><p>瑞弗维尔和杨帝正在逃出生天。</p><p>在轿厢上，杨帝不知何时，脑袋愈合然后醒过来了。</p><p>他有些傻乎乎，眼神呆滞地看着瑞弗维尔，嘴角还挂着一丝亮晶晶的口水。</p><p>“杨帝？杨帝你怎么样了？”瑞弗维尔焦急地问道，伸手轻轻拍了拍他脸。</p><p>杨帝缓缓眨眨眼睛，像是好不容易才聚焦看清眼前的人，含糊地说道：“我……我好像看到好多星星在飞，还有甜甜的柑橘味……”</p><p>说完，还咧嘴傻笑起来。</p><p>瑞弗维尔心中一紧，担心杨帝是不是脑袋受伤留下了什么后遗症。</p><p>虽然不明白脑子裂成八瓣是怎么活下来的，但他终究活了。</p><p>人活了，就得想下一个阶段的问题。</p><p>就是能不能维持住人性和理智地活。</p><p>但此时他们还在逃离的途中，也没办法仔细检查杨帝的状况。</p><p>他只能尽量安抚杨帝：“没事没事，我们先离开这里，等安全了再想办法。”</p><p>杨帝却像个小孩子一样，对周围的一切都充满了好奇，完全没有了往日的沉稳。</p><p>他一会儿伸手去抓轿厢壁上闪烁的灵能光芒，一会儿又对着轨道两旁快速闪过的岩石大喊大叫，手舞足蹈。</p><p>或许多年以后，这一幕将会成为中土大陆家喻户晓人人津津乐道的野史。</p><p>但此刻，刚刚大脑痊愈的杨帝，没能看清命运的戏剧冲突，变化无常，大肠包小肠。</p><p>此时此刻，他只剩下浑浑噩噩。</p><p>“嘿嘿，柑橘味的星星，和我一起跳舞……”</p><p>“杨帝，别乱动，我们还没脱离危险……”</p><p>灵能轿厢剧烈摇晃起来，瑞弗维尔差点被甩出去。</p><p>他赶忙紧紧抓住轿厢的扶手，同时努力稳住杨帝。</p><p>“怎么回事？难道是教廷的人追上来破坏了轨道？”</p><p>瑞弗维尔心中一沉，脑海中迅速闪过各种危险的可能。</p><p>事后梳理，瑞弗维尔发现，这段经历离奇至极——“我们还没脱离危险”明明是反向立Flag，为何话音刚落，危险就接踵而至？</p><p>灵能轿厢轨道尽头，矗立着一尊气息恐怖至极、灵压锋芒凌厉的身影。</p><p>圣光教廷，第一席红衣主教。</p>
