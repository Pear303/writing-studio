# Voight-Kampff

<p>在正式处决之前，生化人都会做一遍移情测试（Voight-Kampff），用最确凿（存疑）的证据，证明眼前的人是生化人。</p><p>杨帝坐在里克对面。</p><p>里克盯着青年。</p><p>他手中拿着记录移情测试问题的电子板，房间里安静得只能听到仪器轻微的嗡嗡声。</p><p>他清了清嗓子，开始提问，声音冷峻而平稳，带着一种不容置疑的压迫感。</p><p>“街边有个小孩不小心摔倒，膝盖擦破皮，开始大哭。”</p><p>“我会扶他起来，唱一首《水手》。”</p><p>“你和你的妈妈在海边漫步，日光探照灯将海面染成一片金黄。”</p><p>“我把捡到的最漂亮的贝壳送给她。”</p><p>“你面前有个穷凶极恶的歹徒，他在街上用链锯剑无差别杀人。”</p><p>“我一砖头将其打爆。”</p><p>“你右手上有只黄蜂。”</p><p>“我一巴掌将其打爆。”</p><p>“你的宠物猫被飞梭撞成重伤。”</p><p>“我一拳头将飞梭打进地里。”</p><p>“……”</p><p>已经没什么好犹豫的了，里克眼神瞬间变得狠厉，右手闪电般抽出腰间配枪。</p><p>枪口直指杨帝的脑袋，扣动扳机！</p><p>“砰！”</p><p>一声巨响，子弹裹挟着强大的冲击力呼啸而出，直直冲向杨帝的头颅！</p><p>然而，令人震惊的一幕发生了。</p><p>子弹在接触到杨帝脑袋皮肤的瞬间，竟像是撞上了无比坚硬的合金，发出清脆的“铛”一声，随后无力地弹落在地！！</p><p>而杨帝的脑袋连一丝擦伤都没有，仅仅是被冲击力震得微微后仰了一下。</p><p>额头上有一个指甲盖大小的红印。</p><p>里克瞪大了眼睛，脸上写满了难以置信。</p><p>他迅速又连开数枪，枪口火光频闪，子弹如雨点般射向杨帝！</p><p>可每一颗子弹都如同之前那颗一样，被杨帝的脑袋弹开，在地上溅起点点火花。</p><p>杨帝看着里克徒劳的举动，嘴角勾起一抹温和的笑。</p><p>他发力，枷锁竟在强大的力量下“咔嚓”一声断裂开来！</p><p>里克一边迅速往后退，与杨帝拉开距离，一边用镇定的声音警告道：“你最好停下，不然我马上按下这个按钮！”</p><p>他手中攥着一个小巧的遥控器。</p><p>上面唯一的红色按钮，在昏暗灯光下闪烁着诡异的光。</p><p>杨帝停下脚步。</p><p>里克额头上布满汗珠，顺着脸颊滑落。</p><p>他心里清楚，现在按下按钮，刺耳的警报声固然会响起。</p><p>可在支援到来之前，以杨帝展现出的恐怖实力，自己根本撑不住！</p><p>他继续给自己造势：“只要我按下按钮，整个银翼杀手部队，都会向这里聚集。你有双拳，也难敌四手。”</p><p>杨帝没有回应银翼杀手的警告，反而问道：“你觉得生化人有灵魂吗？”</p><p>里克微微一怔。</p><p>这个问题出乎他的意料。</p><p>而对方在挣脱镣铐后，始终没有主动发起攻击，只是静静地站在原地。</p><p>似乎在等待里克回答，给予他思考时间。</p><p>“生化人不过是仿生人，没有真正的灵魂。他们的存在就是对人类的威胁。”银翼杀手回答道。</p><p>手指微微放松。</p><p>但仍然接触着红色按钮。</p><p>杨帝轻轻摇头，“你如此笃定？那灵魂又是什么？是情感，是记忆，还是其他？如果一个生化人拥有了和人类一样的情感与记忆，那他和人类又有什么区别？”</p><p>里克陷入了短暂的沉默。</p><p>自己追捕的那些生化人，有的渴望自由，执着于寻找自我。</p><p>包括那个银发蛇纹夹克的舞女，她喜欢跳舞，她的生命仿佛和舞蹈融合在了一起。</p><p>里克希望这是她身为生化人的伪装。</p><p>但情感和理智，居然双双否定了自己……</p><p>思绪不由自主地飘回到那地下酒吧。</p><p>那是个弥漫着迷离光影与嘈杂音乐的地方，镭射灯，灯球，将整个空间映照得如梦似幻。</p><p>里克本是为了试探舞女，不经意间，目光却被她的身影所吸引。</p><p>那个银发蛇纹夹克的舞女，身姿曼妙得如同夜空中最灵动的精灵。</p><p>身体随着节奏起伏、旋转，脚尖轻点地面，像是在与大地私语。</p><p>她的手臂伸展、弯曲，如蛇的柔美。</p><p>银灰色短发在灯光下烁出冷冽光泽，流苏舞服熠熠闪耀。</p><p>里克想到了古老神话中走出的精灵。</p><p>里克跟随她来到后台更衣室。</p><p>更衣室里弥漫着淡淡的沐浴露味，灯光略显昏暗。</p><p>舞女正坐在镜子前，轻轻喘着气，额前的碎发被汗水浸湿，贴在白皙的脸颊上。</p><p>她在镜中看到里克，眼中闪过一丝惊讶，但并没有过多的防备。</p><p>只是微微侧过头，眼神中带着一丝询问。</p><p>“你的舞很特别，在这地下酒吧里算是独树一帜了。”里克赞叹。</p><p>她一边脱衣服，一边向镜子露出个淡淡的笑容：“谢谢，跳舞对我来说，就是生命中最重要的事。</p><p>里克：“刚刚在台上，你的舞跳得真是让人印象深刻，我还从来没见过跳得这么好的，这舞蹈功底，想必也是下了很大功夫练出来的吧？”</p><p>他一边说着，一边仔细观察着舞女的表情。</p><p>舞女轻轻皱了皱眉头，但很快又恢复平静，“当然，我练了很久。”</p><p>里克接着试探道：“那你跳舞的时候，心里在想些什么呢？会不会只是按照某种既定的模式，去完成那些动作？据我所知，舞者都一般是排好一套固定的舞蹈步法和动作。”</p><p>舞女听了这话，眼中明显流露出一丝不悦。</p><p>跳舞对她而言，与呼吸一样自然而必要。</p><p>“如果只是机械地完成动作，那又有什么意义呢？如此无趣。”</p><p>舞女没有再多说什么，她迅速换好衣服，收拾好东西，便径直离开了更衣室。</p><p>里克继续跟踪调查。</p><p>她的生活简单纯粹，除了在地下酒吧跳舞，大部分时间都待在一间狭小公寓内。</p><p>经过数日的跟踪研究，他确定了舞女是逃回地球的生化人之一。</p><p>证据其实不算充分，人造蛇鳞片，异常的紧张和惊恐，本能地逃避银翼杀手……</p><p>但在审讯室的移情测试表明，她确实是生化人。</p><p>子弹洞穿她脑袋后，里面流出的也不是人类那样带有腥味的红色血液。</p><p>是的，Voight-Kampff Test从未错判……</p><p>她确实是生化人。</p><p>“等等，舞女……但你是男性青年杨帝，你不是舞女佐拉……你何时来的？！”</p><p>杨帝敲了个响指：“很显然，你压力太大，也可能是现实出了问题。”</p><p>他消失了。</p><p>生化人舞女坐在里克对面。</p><p>里克看到舞女浑身颤抖，双手下意识地交握在胸前，声音带着哭腔。</p><p>“求求你，里克，别杀我……我真的想活着，跳舞就是我的一切……只要能让我继续站在舞台上，我什么都愿意做……”</p><p>但他还是犹如控制不住自己，犹如身体被上了发条，犹如肢体是死板执行固定程序的机器。</p><p>他掏出了相位光束枪。</p><p>他对古老神话中走出的精灵扣下扳机。</p>
