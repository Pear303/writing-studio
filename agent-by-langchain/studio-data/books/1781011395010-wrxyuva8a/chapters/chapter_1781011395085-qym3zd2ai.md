# 旧日景点

<p>距离末日火山主峰50公里。</p><p>……</p><p>短短几秒，在杨帝的六感中，已经彻底感受不到追踪者的存在。</p><p>自始至终，他只记住对方两个特征：柑橘气味，金色影子。</p><p>对方的来历，身份，目的，一无所知。</p><p>而在另一边。</p><p>瑞弗维尔此刻正在思考另一件事，又惊又异——已经整整一天，没遇到圣光教廷的追杀了！</p><p>没有被追杀的日子，真不习惯！</p><p>难道，是追兵忌惮于杨帝？</p><p>这个想法冒出来，他觉得不是没可能。</p><p>毕竟杨帝实力不俗，从各种蛛丝马迹能清楚看出，他绝对来头不小，失忆前极可能是传奇近战法师。</p><p>瑞弗维尔只是个小小的图书馆馆长，理论知识丰富，但在社交方面，并不认识多少大人物。</p><p>他不认识杨帝，但势力深厚的圣光教廷可能认识吧，应该认识吧，绝对认识吧！</p><p>也许，教廷的追兵发现他身边多了个“传奇法师”，所以暂时忌惮，按兵不动了？</p><p>这样的旅途也挺好。</p><p>这一天来的平静，与之前被追得如丧家之犬的狼狈形成了鲜明对比。</p><p>末日火山也不远了。</p><p>一路走来算是渡尽劫波，也就一开始在隧道里被红衣主教的自爆，炸得满脸灰。</p><p>后来吃饱美味无敌的菌子，睡了一小会儿。</p><p>除了这两件事，瑞弗维尔发觉，自己好像也没受多大伤。</p><p>现在还攀上一个传奇法师级别的保镖。虽然对方失了忆，看起来不太聪明的样子，但路上教廷的追兵一下子销声匿迹了。</p><p>他确信这都是杨帝的功劳。</p><p>不然，难道是圣光教廷幡然悔悟，放下成见不再追杀他了？</p><p>只有一种可能，那就是教廷意识到瑞弗维尔有高手相伴，所以暂时不敢动他。</p><p>就是比较担心，等杨帝“记忆恢复”后，如果意识到自己被他利用、哄骗来当保镖，会不会有什么严重后果。</p><p>……</p><p>距离末日火山还有40公里。</p><p>正前方的山壁上，出现一个山洞。</p><p>瑞弗维尔：“关于这个山洞，是有来历的，有源远流长的历史传统……”</p><p>杨帝：“愿闻其详。”</p><p>第三纪元，也就是第四纪元的是一个纪元，霍比特人成功利用末日火山的烈焰，摧毁至尊魔戒，打败索伦魔王。</p><p>而后，这一整座火山就被改造成旅游景点。</p><p>但景点没开几百年，就荒废了。</p><p>原因是距离主要人口聚集地太远，交通也不便利，基础设施不够完善，导致物价水平非常高，人流量也特别少。</p><p>纵使每天都有硬核驴友，以八仙过海各显神通的手段，来到这鸟不拉屎之地，瞻仰霍比特人击溃索伦魔王的战场。</p><p>但景区终究人太少，游客消费入不敷出。</p><p>所以，当地的旅游经济最终失败了。</p><p>“从洞口可以到末日火山内部，这就是我们要走的路。”</p><p>瑞弗维尔指了指眼前那洞口，“这个洞口就是景点入口，当年收费标准是一人10个铜狮鹫，1.1米以下免票。”</p><p>“索伦魔王？能给我讲讲吗。”杨帝追问。</p><p>这一路上，跟着瑞弗维尔这个异界土著走，杨帝边走边补充基本常识。</p><p>他已经了解了很多关于灵能、法术和魔物，也大概知晓了当地历史风俗与社会文化。</p><p>瑞弗维尔清了清嗓子，开始讲述起来：“索伦魔王，可是个极为邪恶强大的存在……”</p><p>杨帝又了解了一段关于异界的历史。</p><p>传说，索伦本是一位强大的迈雅。</p><p>在远古时期，索伦被“被放逐至虚境”的黑暗魔君“摩苟斯”诱惑，堕落成了邪恶的象征。</p><p>他一心追求统治整个中土大陆，为此他施展了极为邪恶的魔法，制作了七件魂器。</p><p>只要这些魂器中有一件存在，索伦就无法被真正消灭。</p><p>为了讨伐索伦魔君，整座中土大陆结成统一战线，大地万族乱成一锅粥……</p><p>红袍女巫在君临城点燃血月……星之彩的眷族涌出天空之门……</p><p>燃烧军团的恶魔之核，在海加尔山重新跳动……</p><p>“……第六件魂器‘霜之哀伤’被传奇强者用‘炎之欢愉’打碎，最终，霍比特人将第七件魂器‘至尊魔戒’投入末日火山，将其摧毁，索伦魔王陨落。”瑞弗维尔侃侃而谈。</p><p>其实正史内容没那么有戏剧性。</p><p>这都是他结合野史，自己添油加醋润色了一遍。</p><p>杨帝捏着下巴，看向眼前通往末日火山内部的洞口。</p><p>没想到这小小的一座山，见证了两个绝世凶物的陨落。</p><p>一个魔王，一条巨龙。</p><p>他站在山洞前，一脚踹在铸铁大门上。</p><p>“轰——！！”五米高的铁门被踹翻，地上滚了几圈，正中央还留下个天残脚般的脚印。</p><p>“咳咳，我们走，进去。”</p><p>杨帝闻了一口里面的空气，感受到大自然重新夺回了这处旅游景点。</p><p>潮湿的泥土气息、腐朽的木头味，以及淡淡的苔藓腥味混合在一起，扑面而来。</p><p>曾经作为旅游景点时的人工气息，早已被岁月和自然侵蚀得一干二净。</p><p>这里已经荒废数千年，人造物基本都挺不过去。</p><p>内部的布料和木头，早已经朽烂到和泥土没有任何区别。</p><p>只有几座铁制的架子，还顽强耸立在原地，但外表也早已是锈迹斑斑，腐朽不堪。</p><p>杨帝跟在瑞弗维尔身后，小心翼翼地跨过倒下的大门。</p><p>洞内光线昏暗，只有洞口透进来的微弱光线勉强照亮一小片区域。</p><p>中部还残留着些碎玻璃、砖瓦和铁锭，应该是售票处。</p><p>越过售票处，里边又是一扇门。</p><p>他们踹门而入，已经封闭数千年的空间，顿时空气流通了。</p><p>突然有彩色的东西向他们飞过来！！！</p><p>瑞弗维尔下意识地抬手遮挡，惊叫道：“蛙趣这是什么！星之彩？！！”</p><p>五彩斑斓的碎片在昏暗中飞舞，仿佛一瞬间将这荒废千年的山洞唤醒，重现出曾经辉煌时的绚烂。</p><p>经常摸金倒斗的朋友都知道，那是墙上图案脱色，突然遇到了空气迅速氧化脱落。</p><p>然后3D电影一样飞过来。</p><p>（参考文献：电影《寻龙诀》，说实话电影拍得没有原著的味道，但说不清哪里不一样。）</p><p>但瑞弗维尔不知道！他原本是游侠，后来当了图书馆馆长，自始至终都没倒过斗。</p><p>便以为自己闹鬼了。</p><p>又或者是什么“索伦的一缕残魂留存于此”、“寄宿在至尊魔戒上的魔王老爷爷”、“巨龙魂魄被困在神灯或者漂流瓶里”之类的超展开。</p><p>杨帝安抚住他，向他解释了其中原理。</p><p>“原来是画……？杨帝兄弟，你记忆恢复了？”瑞弗维尔既为他感到高兴，又对接下来自己可能失去保镖而感到担忧。</p><p>杨帝摆摆手：“哦，还没有还没有，只是脑子里突然回忆起来一些知识而已。”</p><p>“那杨帝兄弟，你有从那些氧化脱落的‘画’上看到什么吗？”</p><p>杨帝点点头。</p><p>那些画面，似乎是历史，讲述的是圣骑士巴德大战焚灭天空之龙卡利斯托。</p><p>画面内容和瑞弗维尔讲述的历史，大致对得上。</p>
