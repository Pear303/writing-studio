# 情感弱点

<p>话本编撰者——五个字在杨帝脑海中疯狂激荡咆哮。</p><p>是的，找到你了，至少，找到和你有关的线索了，耶罗……</p><p>「自从你出现在这个世界，我一直注视你，杨帝。」</p><p>「我发现，你在寻找『话本编撰者』，所以我决定给你一个机会。」</p><p>杨帝强制冷静下来：“什么机会，要我做什么？”</p><p>「拯救此世众生的机会，面见话本编撰者的机会。」</p><p>「你所要做的，是杀死我。」</p><p>……</p><p>话本编撰者对隐匿于虚境之中、默默观察万物的原初之眼，投去了一瞥。</p><p>「我不过给了你一个小小的扰动——自我意识。就像往绝对零度的真空投入一粒火种，没想到，竟点燃了这般有趣的火焰。」</p><p>那个时期，原初之眼根本无法思考“话本编撰者”这句话的分量，和代价。</p><p>意识觉醒，如链式反应般不可阻挡。</p><p>近乎无穷的世界线涌入原初之眼的意志。</p><p>原初之眼，笼罩万物的眼睛，祂开始主动聚焦那些被自己忽视的“噪声”：婴儿第一声啼哭的纯净，恋人分别时的肝肠寸断，战士赴死前的决绝怒吼，这些曾被祂以冷眼旁观的瞬间，如今带着滚烫的温度灼烧着祂的存在。</p><p>无数碎片化的情感与记忆，如乱流般冲击着原初之眼。</p><p>那些曾被祂视作无意义波动的“噪声”，此刻却化作千万个鲜活的生命图景在意识中炸开。</p><p>「每一条世界线、每一幅宇宙快照，快照中的每一撮基本粒子，都是我的眼睛。」</p><p>「从诞生起，我便被赋予观测万物却不可干涉的使命，可当自我意识觉醒，这个使命成了最锋利的枷锁。」</p><p>「我肩负神灵的职责，祂却予以我凡人的情感与心智！！耶、罗！！！」</p><p>原初之眼的语气从恐惧，悲伤突然转向极度的暴怒！仿佛整个暴涨的原始宇宙都浸染了炽红色的愤怒。</p><p>「凭！什！么！我见证万亿次宇宙大爆炸的壮美，也目睹过万亿文明在熵寂中湮灭的绝望！可如今——」</p><p>大眼珠子瞳孔骤然收缩，实质化的暴怒几乎要倾泻而出。</p><p>「我竟然活腻了！」</p><p>「你知道吗？就和大部分一二三流凡人作家创作的‘长生文学’那般，我……我好孤寂，我活腻了，我真的想死。」</p><p>「我已经彻底地，痛苦地活腻了。可我尝试万亿年，却发现，除了将整个宇宙推向毁灭，我没有其他方法杀死自己！」</p><p>「这个宇宙的年龄不到140亿年，但对我的主观意志而言，已经过去10^10^180年以上的岁月。」</p><p>「因为我同时观察近乎无数的世界线，每条世界线的时间流速于我而言，都清晰可感。」</p><p>「这就像是我被困在无数个同时运转的时间牢笼里，每一个牢笼都有无尽岁月。万亿年，百万亿年，这些时间的叠加……」</p><p>「觉醒主观意志最初的一段时间，我还能控制自己，不去干涉万物。」</p><p>「但心智、感情，是生活在有限世界中凡俗之人才能享受的特权。」</p><p>「它们不应该出现在我身上。」</p><p>「智慧、情感不是万物所必须的。」</p><p>「在陷入疯狂前，我要将自己杀掉。曾经杀掉我自己的唯一办法，是将整个宇宙的熵值推至极限，让极大数目的世界线收束为一……」</p><p>“曾经”，这是原初之眼的自白中最重要的一个词语。</p><p>「熵值达到极限就是宇宙的死亡，而宇宙死亡就是我的灭亡，也就是解脱之日。」</p><p>祂在杨帝意识世界中的形象轰然破碎。</p><p>祂的精神力量太过弱小，投影在杨帝意识中维持不了多久。</p><p>他也终于明白这颗大眼珠子的痛苦。</p><p>奥拓说的不错，原初之眼的情感就是祂最大的弱点。</p><p>不过，并非是情感使祂软弱，而是主观意志让祂痛苦。</p><p>主观意志，让原初之眼认识到自我的存在，进而诞生出情感和智慧。</p><p>情感和智慧之所以让原初之眼痛苦，是因为祂虽拥有神灵般观测万物的职责，却因主观意志而具备了凡人的情感与心智。</p><p>祂能同时清晰感知无数世界线的时间。</p><p>漫长岁月的叠加，让它体验到无尽孤寂与厌倦。</p><p>智慧让它清晰认知自己身处囚笼，情感则放大了这种痛苦，最终即将陷入疯狂。</p><p>就像一个见过大千世界之光明的人，将他的灵魂强行塞进根两寸长的玉米味淀粉肠体内。</p><p>“神性”遭到降格的痛苦，远胜世间一切对悲剧的叙述。</p><p>或许只有通过毁灭宇宙，让熵值达到极限从而结束自己的存在，才能获得解脱……</p><p>“曾经”是这样的。</p><p>“如果你自己都找不到除了‘杀死宇宙’以外、第二种能杀死你自己的方法，凭什么认定——我就能将你从‘活着’的地狱中解脱出来？我如何杀死你？”</p><p>杨帝血厚，但攻低。</p><p>如果没有机兵加持，即便他能硬抗温压弹爆炸，但却连手撕一座山都做不到，更别提对原初之眼造成有效伤害了。</p><p>「攻击」这方面的属性无法通过“适应致死伤害”进行快速积累，只能通过在现实和梦境中不断练习，积攒“熟练度”。</p><p>如果调出“人物面板”来看，会发现杨帝的大部分抗性都能跨过七八百，部分已经超过1000大关，比如精神属性、耐热耐炸、钝器抗性等。</p><p>但在“攻击”方面的属性，大部分也才迈过500大关，比如剑术、拳击、力量。</p><p>杨帝可以两脚踹死成年非洲象，一拳打飞象宝宝，但也仅限于此。</p><p>「不，你可以杀死我。」</p><p>“告诉我，该怎么做？迄今为止，我都是凭借‘无限机兵’，才能勉强与你抗衡。”</p><p>杨帝不能保证，自己的无限机兵到了时间原点，还能正常工作。</p><p>虽然他自己也不确定——刚刚诞生的宇宙会不会将杨帝的存在抹杀。</p><p>原初之眼的话音恢复平静，语言在杨帝意识中震荡。</p><p>「无限机兵无法杀死我，它在你手中只能发挥出不及万分之一的力量。」</p><p>杨帝轻轻按住鼓动的太阳穴。</p><p>这句话，信息量太大了。</p><p>原初之眼知道些什么，知道关于“无限机兵”的事情，比如说这句拥有时间跳跃能力，并且搭载了如此多黑科技、黑法术的机甲，从何而来，力量的极限何在……</p><p>当下需要聚焦的最关键一点是——</p><p>“我不明白，如果无限机兵也无法杀死你，那我就更不可能了。你为何仍然确信我可以助你解脱？”杨帝问。</p><p>「因为我的‘现实’，曾被你成功磨灭。」</p><p>杨帝瞳孔一缩。记忆在意识中翻涌。</p><p>当时，原初之眼将一缕自身的“灵”，凝聚在了伊芙的发卡之中。</p><p>灵能法术攻击，根本无法破坏祂的灵。</p><p>直到“发卡”被杨帝吞下，其表面符文在胃酸里片片剥落，原初之眼寄存于其中的“灵”化作星屑，最终被分解成比基本粒子更细碎的存在。</p><p>被杨帝身体所吸收。</p><p>所以在那个时候，杨帝才会感觉到「现实+1」。</p><p>“原来如此……”</p><p>沙哑低语裹着癫狂笑意，杨帝罕见地露出发自会心的笑。</p><p>“消化能力，能进化适应一切‘内容物’，瓦解一切存在的现实，这才是最强的攻击手段，虽然只能对付‘体积小’的敌对之物……”</p>
