# 线索 旧校区

<p>杨帝走进咖啡馆，冷气激得他打了个寒颤。</p><p>正后艳阳被深灰色窗帘过滤成浑浊的光晕，照在角落卡座那个穿着红色连帽衫的身影上。</p><p>胡彦卓面前摆着杯冷掉的拿铁，拉花已经凝结成扭曲的……漩涡……</p><p>见到杨帝，他招了招手。</p><p>“杨帝老弟，喝点啥？”</p><p>杨帝看了眼昂贵的菜单，自己掏出瓶运动饮料来，在他对面坐下。</p><p>背包的金属搭扣撞在木质桌面上发出闷响，“胡哥，咱们直接说正事吧。”</p><p>杨帝打开手机。</p><p>将它放到桌子正中央，屏幕上显示的是蓝天红气球图片。</p><p>胡彦卓的目光在屏幕上定格，喉结滚动了两下。</p><p>他伸手将冷掉的拿铁推到一边，杯底在桌面拖出黏腻的水痕，没头没尾地说：</p><p>“你见过凌晨4点的旧校区吗？”</p><p>问这个干啥？杨帝想点点头。</p><p>但为了让胡彦卓继续说下去，还是选择摇摇头。</p><p>对方继续说：“前年，我打算去旧校区的废建筑群，拍一期第一人称跑酷视频。</p><p>“拍摄前需要勘察现场，规划路线，清理路上的杂物。</p><p>“第一次来到旧校区内的学生公寓顶楼，当时我以为是中暑眼花，因为我余光瞥见对面艺术楼顶……”</p><p>他的声音陡然变调：“有个红气球。”</p><p>胡彦卓的指尖，重重戳向屏幕里那个鲜艳的红气球，“那天我拍完这个镜头，随手分享到炒股群里后，所有怪事都开始了。”</p><p>————————————</p><p>“前年七月，我在旧校区拍最后一期视频。虽然隔的时间很久，但我记得，那天特别热，空气黏得能拧出水来。</p><p>“在网友的热烈呼唤下，我决定去我们学校的旧校区废弃建筑区，拍摄一部第一人称跑酷片子。</p><p>“刚踏入旧校区大门，我就感到一股莫名的压抑感。那里的空气仿佛凝固了，连风声都显得格外沉重。</p><p>“我在建筑群穿梭，想找个拍摄角度，但越是深入，就越觉得不对劲。”</p><p>杨帝忍不住插话：“不对劲？是指什么？”</p><p>胡彦卓用双手比划着，继续说下去。</p><p>“欸……有时候，明明烈日当空，却会突然感觉好像穿过了一团冷空气团。那感觉就像突然掉进冰窖，裸露的皮肤瞬间暴起鸡皮疙瘩。</p><p>“有时候，会感觉有温热的吐息拂过我的脖子，那种触感真实得让人毛骨悚。回头，GoPro只拍到飘动的窗帘。</p><p>“我以为是错觉，但那种感觉反复出现。我想骗自己去忽略，但我的理智骗不了自己。”</p><p>杨帝盘算着，大约是胡彦卓“灵感”比较高，隐隐约约察觉到希夷的存在。</p><p>但又没有直接观测到它的本体，所以只是感觉不舒服。</p><p>他抓起冰凉的金属勺子在掌心来回滚动，像是要通过这个动作，汲取令人安心的真实感。</p><p>看起来他还没走出那日的阴影。</p><p>“终于到了拍摄那天，我特意选在了视野开阔的天台上进行热身……</p><p>“起跳前三十秒，我习惯性检查GoPro，却发现屏幕突然毫无征兆地黑屏了……</p><p>“最后那个远跳，是我精心策划的高潮部分。我反复勘察过现场，确认每一寸土地都安全无虞。然而，就在我准备起跳的瞬间，原本空无一物的地方，凭空多出条拇指粗的黑色电线……它静静地挂在那里。”</p><p>杨帝：“所以胡哥，你的髋关节就是这么伤到的？”</p><p>胡彦卓：“是啊，就因为那条凭空出现的黑色电线，我整个人失去平衡，狠狠摔倒，髋关节遭受重创……”</p><p>杨帝：“胡哥，我有个东西想给你看看。”</p><p>杨帝从口袋里拿出了耶罗符印。</p><p>胡彦卓：“这是什么？让我看看。”</p><p>接过符印，仔细端详着上面的漩涡状图文。</p><p>胡彦卓：“这图案……我好像在旧校区的某些角落见过。”</p><p>杨帝：“真的？在哪？”</p><p>胡彦卓：“在一些被阳光照射不到的地方，比如实验楼的地下室，还有艺术楼某些教室……在那些存在感很低的角落，有类似图案。”</p><p>杨帝：“这些图案是什么意思？”</p><p>————————————</p><p>杨帝有些失神地走出学校后街咖啡馆。</p><p>这一趟他把能问的都问了，所有一切都指向了旧校区。</p><p>胡彦卓在旧校区遇到诸多怪事，他在旧校区里拍到张奇怪的红气球图片，里边寄宿着不可名状之物“希夷”。</p><p>而希夷“随身携带”着耶罗符印。</p><p>而符印上的漩涡图纹，同时也出现在旧校区的某些角落。</p><p>胡彦卓最后强调：“千万不要一个人去旧校区。如果你要去，那就带上我。”</p><p>他最后捏了捏鼻梁，又补充一句：“说真的，杨帝老弟，真不随我学跑酷吗？”</p><p>不用了，麻烦胡哥了。杨帝谢绝。</p><p>回到宿舍，连上超慢的WiFi，打开手机，翻阅关于旧校区资料。</p><p>加载开某个网页，弹出张图片。那是一张旧校区的俯瞰图，图中的建筑错落有致。</p><p>说是旧校区，其实它不像是个“校区”，更应该说是几栋空置出来的楼。</p><p>两栋学生公寓，两栋教学楼，被铁皮棚和不锈钢栅栏围住，距离“新教学楼”仅仅一墙之隔。</p><p>从俯视图上看，像是从整所大学中，被强行分割出来了一角。</p><p>学校官网简介在屏幕上闪着官腔：“因建筑老化于2012年停止使用……”</p><p>杨帝切进校园论坛，输入“旧校区 秘密”。</p><p>十几条帖子瀑布般涌出，从十年前到上个月的帖，排在了搜索框里。</p><p>【求助】旧校区是不是有很多流浪猫？</p><p>楼主：匿名</p><p>内容：昨晚和男友去旧校区试胆，在艺术楼旁边听到喵喵叫。</p><p>【纪实】旧校区偷渡记</p><p>楼主：（用户已注销）</p><p>内容：艺术楼的地下室有个漩涡刻在墙上，挺艺术的……</p><p>【求助】在旧校区捡到一个奇怪的笔记本</p><p>楼主：谷恒条野的狗</p><p>内容：昨天在旧校区闲逛，捡到一个笔记本，里面的内容全是些看不懂的符号和奇怪的图画，还有什么“质壁分离”，有没有人知道这是什么？</p><p>【求助】为什么旧校区废置不用了？</p><p>楼主：匿名</p><p>内容：看起来挺新的，怎么不用了，都是纳税人的钱呐。</p><p>【最新】旧校区的都市传说又有新版本了</p><p>楼主：资深校友9527</p><p>内容：晚上我偷偷溜进旧校区，在软件楼附近到一种，像是在摔打自己身体，那种血肉与石块碰撞的声音，响了整整一晚上……</p><p>“……”</p><p>杨帝看了一眼这个【最新】贴的时间，恰好是他溜进旧校区、练习“耐杀性”那晚。</p><p>那一晚，他不断让自己身体撞击水泥地面、红砖墙壁，来锻炼「钝器抗性」属性。</p><p>没想到附近还有人偷听。</p><p>杨帝摸摸鼻尖，有点尴尬——自己也成为都市传说的一部分了。</p><p>不过也侧面反映出，这学校论坛里的大部分帖子，其实都是自己吓自己，并非真实的灵异现象。</p><p>在这个学校论坛里看了半天，最后只筛选出一个有价值的帖子。</p><p>那篇“【纪实】旧校区偷渡记”，里边提到了“漩涡”。</p><p>楼主的账号已注销，他联系不上对方。</p><p>只能细细地看内容。</p>
