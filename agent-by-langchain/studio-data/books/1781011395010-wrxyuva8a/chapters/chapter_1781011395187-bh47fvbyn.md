# 今夕是何年？

<p>这是最坏的时代，也是最辣鸡的时代。</p><p>这是人心凋敝的时期，也是信心凋零的时期。</p><p>这是阴云遮蔽的季节，也是雾锁烟迷的季节。</p><p>昨晚阿巴被远处的爆炸声吵醒，今早听说是某家金融公司数据库的存储硬盘过热，自行爆炸了。</p><p>谁知道呢。</p><p>距离学校近的地方，都是这样的。</p><p>时不时发生一场莫名其妙的爆炸，时不时出现几个伪人、皮行者，时不时有人陷入活尸循环，时不时有人不小心卡进后室……</p><p>不管怎么说，这样的生活还有4年。</p><p>而当下，对18岁的阿巴而言，只是开始。</p><p>六月六日晨，江城二中高三零班的教室，闷得像一口烧糊了高压锅。</p><p>空气里塞满了油墨、汗酸和一种名为“最后冲刺”的味道。</p><p>头顶老旧的风扇徒劳地搅动着浑浊的气流，发出令人牙酸的呻吟。</p><p>墙壁上鲜红的倒计时“1天”。</p><p>红得刺眼，像悬在所有人脖颈上的血痕。</p><p>教导主任老马是个头顶反着油光的中年人，挺着标志性的啤酒肚，正站在讲台唾沫横飞。</p><p>他挥舞着肥厚的手掌，每一记拍在讲桌上，都震得粉笔灰簌簌落下，飘进前排学生汗湿的头发里。</p><p>“高考！人生的分水岭！无论你们是穿草鞋还是穿皮鞋，到了这个时候，都只能拿出自己的真本事！是骡子是马，明天就得拉出来溜溜！”</p><p>老马的声音洪亮而亢奋，带着一种近乎诅咒的狂热，“都给我打起十二万亿分的精神！把你们吃奶的劲儿，不，把你们拉屎的劲儿都给我使出来！相信的心就是你的魔法，异能，神通！争取在高考现场觉醒特殊能力，为抗击诡异做出贡献……”</p><p>话音未落。</p><p>“轰——咔！！！”</p><p>一声无法想象的巨响，仿佛九天之外的神明抡起了巨锤，狠狠砸穿了整个苍穹！</p><p>教室顶部那用了不知多少年的老旧预制板，如同脆弱的蛋壳，被一股沛然莫御的力量瞬间撕裂掀飞！</p><p>水泥碎块、断裂的钢筋、扭曲的灯管……</p><p>裹挟着刺鼻的粉尘和烧焦的电线气味，暴雨般倾泻而下！</p><p>隆隆隆隆——</p><p>巨大的冲击波横扫整个空间。</p><p>窗户玻璃在尖锐的悲鸣中轰然粉碎，化作漫天晶亮的冰雹。</p><p>课桌被无形巨力狠狠掀翻、扭曲、撕裂，书本、试卷、文具盒如同狂风中的落叶，被撕扯得漫天飞舞，白花花的纸页瞬间淹没了视野。</p><p>“哼哼哼啊啊啊啊啊啊——！”</p><p>“地震了？”</p><p>“楼要塌了！”</p><p>“难道是……它们提前来了？”</p><p>“高考不是还有一天吗？！”</p><p>尖叫、咆哮、桌椅碰撞的巨响瞬间炸开，淹没了老马那戛然而止的训话。</p><p>老马那张唾沫横飞的脸瞬间变得惨白。</p><p>有些学生像受惊鹌鹑，下意识地抱头蜷缩，迅速找到安全的角落和掩体。</p><p>但更多学生，则是很冷静地观察四周，维持秩序。</p><p>有人迅速起身抵住摇晃的门框，防止预制板残骸坠落封堵出口，有人扯下窗帘拧成绳索，准备应对可能的二次坍塌。</p><p>“把课桌扣过来，躲进去！捂住口鼻，粉尘有毒！”</p><p>“坍塌原因是什么？”</p><p>“尚未清楚。幸好我们这里是顶楼，天花板坍塌造成的损害并不算大。”</p><p>“天花板是由内向外先飞的。包括室内的窗户，玻璃碎片也是向外溅射。”</p><p>“冲击波的中心是？”</p><p>“是……是她？！”</p><p>毁灭性的混乱仅仅持续了不到三秒。</p><p>一道无法形容的光，从穹顶那个巨大的破洞中灌了进来。</p><p>那不是阳光，也不是灯光。</p><p>它带着一种冰冷的、纯粹的、蕴含着毁灭与创生双重气息的紫色！</p><p>……粗大得如同神话中支撑天地的巨柱，凝练得如同实质的紫晶！它无声地贯穿而下，精准地笼罩了教室中央的区域，将混乱的尘埃和惊恐的声浪瞬间凝固、排开。</p><p>就在那紫得令人心悸的光柱中央，一个身影，缓缓地、违背物理定律地悬浮了起来。</p><p>是班花。</p><p>平日里那个总是安静地坐在前排，梳着柔顺马尾辫，说话轻声细语，成绩永远名列前茅的乖乖女。</p><p>此刻的她，悬浮在离地三尺的空中，校服无风自动，猎猎作响。</p><p>那平凡的校服之上，竟隐隐覆盖着一层流动的、如梦似幻的七彩霞光。</p><p>她低垂的头颅缓缓抬起，脸上惯有的那种温顺和怯懦消失了。</p><p>取而代之，是一种俯瞰众生的漠然。</p><p>那双曾经清澈如水的眼眸，此刻深邃得如同宇宙的起点，瞳孔深处，仿佛有无数星辰在生灭流转。</p><p>她的嘴唇微张，吐出的声音不再娇柔，而是带着一种穿透万古时空的冰冷回响，每一个字都敲打在每个人的灵魂深处：</p><p>“悠悠万载，大梦方觉……本座，乃九天瑶光仙尊。”</p><p>声音不大，却盖过了所有喧嚣，清晰地烙印在每一个幸存者的耳膜和心神之上。</p><p>绝对的寂静。连呼吸声都消失了。</p><p>所有人都保持着上一秒惊恐的姿态，眼神却凝固在班花身上。</p><p>不，他们眼神里有恐惧，更多的是茫然，和一种认知被彻底颠覆的空白。</p><p>就像先秦时期的古人，突然挨了发原子弹时的震撼感。</p><p>教导主任老马脸上的肥肉停止了抖动，眼珠子瞪得几乎要脱眶而出。</p><p>但他喉咙里仍然艰难地挤出几句话：“其他同学迅速撤离教室。”</p><p>主任一拳头砸在讲台上的一个红色按钮，却发现电路失效了，并没有报警声。</p><p>那些还正常的同学迅速涌向教室门口，或干脆打开窗户准备翻出去……</p><p>“嗡——”</p><p>教室里的空气再次震荡起来。</p><p>这一次，亦是源自某种无形的、却更加威严磅礴的威压。</p><p>所有原本还想离开教室的人，都僵在原地不能动弹。</p><p>班长猛地从地上站起。</p><p>他身上校服寸寸碎裂，化作点点光屑飘散。</p><p>取而代之的，是一层仿佛由液态黄金浇筑而成的璀璨神光！</p><p>那光芒并不刺眼，却蕴含着一种至高无上的堂皇与威严，如同初升的旭日照耀尘世。</p><p>他身形在金光中似乎拔高了几分，面容依旧俊朗，眉宇间却多了一种执掌乾坤、俯瞰万灵的冷漠与尊贵。</p><p>周身金光流转，将靠近的尘埃杂物无声地推开数尺。</p><p>班长的目光扫过悬浮的“瑶光仙尊”，扫过满地狼藉和呆滞的师生，最后缓缓抬起右手。</p><p>掌心之中，一个小小的、保温杯形状的虚影一闪而逝。</p><p>最终，保温杯虚影定格成一口古朴铜鼎。</p><p>他开口，声音如同洪钟大吕，带着金属摩擦般的质感，震得空气嗡嗡作响：</p><p>“仙古纪元已远，吾，凌云圣皇，终抵此间仙界。”</p><p>“敢问诸位仙界之人，今夕是何年？”</p>
