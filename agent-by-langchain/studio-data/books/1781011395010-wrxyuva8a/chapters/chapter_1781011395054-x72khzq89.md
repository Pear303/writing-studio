# 单刷烂尾楼4

<p>声音从楼梯口附近的一个房间传来，房间门半掩着，不像人类哭，又不像婴孩嚎叫。</p><p>杨帝伸手轻轻推开房门，“嘎吱”一声，门轴发出令人牙酸的声响。</p><p>屋内弥漫着一股陈旧腐朽的气息，正中央摆放着一面巨大的镜子，镜子上布满了裂痕。</p><p>从外表上看，镜子挺正常的。</p><p>唯一异常的是，杨帝正面看镜子的时候，镜子不会映照出他的脸，只会照出他的后背。</p><p>就像在他身后装了个摄像头。</p><p>“奇葩。”</p><p>杨帝在镜子前缓缓转身，镜子里的自己也随之改变。</p><p>这镜子刻意回避映照正面，尤其是不想映照出他的脸。</p><p>他把头向一个方向扭九十度，然后用余光去观察，甚至也不能从镜子看到自己的侧脸。</p><p>“有点意思。”</p><p>杨帝握紧了手中的撬棍，绕着镜子踱两步。</p><p>镜子里始终映照出他的后脑勺。</p><p>他把撬棍安回身后，然后从背包里抽出把西瓜刀，深吸一气，猛地挥刀朝着镜子砍去！</p><p>“咻——”</p><p>凌厉至极的银光陡然划过，宛如天际流星。</p><p>这是极快的一刀。</p><p>刀光收敛，万象归一。</p><p>那面巨大的镜子还来不及破成碎片，就被精准地劈成了两半。</p><p>但即便遭受了如此重创，那面落地镜的两半，都奇迹般保持着原有的奇异性质！</p><p>它们仍然固执地只展现出站在它们面前之人的后脑勺，而不是正面的脸。</p><p>杨帝背对着镜子站好。</p><p>掏出手机，给自己和身后的镜面自拍一张。</p><p>“咔嚓～”</p><p>刚拍下来的相片中，杨帝能从照片里面的镜子，看见自己的正脸。</p><p>背对镜子，是可以照出自己正脸的。</p><p>杨帝稍作思索，有了个好点子。</p><p>他便将这两半镜子，面对面地竖了起来，然后自己站在了两面镜子中间。</p><p>奇妙而诡异的景象出现了：两面镜子相互映照，形成了一条仿佛没有尽头的镜中长廊。</p><p>而长廊里出现的全是杨帝的后脑勺，层层叠叠，一眼望不到边际。</p><p>将面前的镜子稍稍挪一下角度，就能从他身后那半张镜子的反射，看到自己的正脸了。</p><p>杨帝对着镜子，理了理头发。</p><p>但正脸相对的时间很短暂。</p><p>镜子刻意回避映照正面，特别是回避两张脸正面相对。</p><p>当他强行让两面镜子映照出自己“正脸相对”时。</p><p>仿佛向湖面投入了一颗巨石。</p><p>原本静止的镜中长廊，泛起细微的涟漪，涟漪翻成水波，水波惊起巨浪，巨浪跃成海啸——</p><p>镜中画面疯狂扭曲，那些层层叠叠的后脑勺，与好不容易映出的正脸相互交织、碰撞、摩擦、挤压，恰似水火不相容！！</p><p>一阵接一阵，尖锐刺耳的声音从镜中传出，是无数尖指甲，同时划过玻璃的声音。</p><p>镜面上裂纹不断扩大，一些模糊的，躁动的黑影，开始在镜子深处若隐若现。</p><p>黑影形状扭曲，仿佛是被囚禁在镜中！</p><p>女人的哭泣与孩童的尖啸，又从镜子里传出来！</p><p>这就是那些怪声的来源。</p><p>「精神+1」</p><p>杨帝整理好头发，叹气：“我一人类，照个镜子就这么大反应，要是哪天‘黄帝’本尊来对镜梳梳头，你们不得山崩地裂。”</p><p>传说中，黄帝拥有四张脸，能同时顾及东西南北四个方向。</p><p>他无论怎么照镜子，都能看见自己的脸。</p><p>“瞧瞧你们这点出息，不就是两张正脸相对嘛，至于闹得这么鸡飞狗跳？”</p><p>镜中，那些黑色雾气开始涌动了。</p><p>它们如触电的蛆，疯狂地扭动着身躯，发出阵阵低沉咆哮，仿佛在回应杨帝的挑衅。</p><p>杨帝举起板砖，提前一步将两张镜子拍了个粉碎。</p><p>碎了一地的镜片里，那些黑影还在蠕动。</p><p>他将碎镜片全部徒手捡起来，自己留了一块干净的。</p><p>其它带回到自己房间，丢进火堆里。</p><p>镜片在火堆中滋滋作响。</p><p>随着火焰舔舐，逐渐被烧得氧化，表面覆上了一层漆黑的颜色，变得焦糊不堪。</p><p>那些原本在镜片中蠕动的黑影，随着镜片的变化，似乎也受到了某种强大力量的压制，渐渐停止了动作。</p><p>镜子的主要成分是玻璃，被灼烧时，玻璃中的有机物杂质在高温下碳化，产生黑色的碳，有时，也会有黑色的氧化银。</p><p>表面完全被这些黑色的碳化物质和金属氧化物覆盖，就会变得焦糊不堪。</p><p>学好数理化，有鬼我不怕。</p><p>处理完这房间的镜子，继续带上撬棍板砖，扫荡下一间空房。</p><p>天亮之时，杨帝终于清空了2楼。</p><p>稍作休息，吃了些随身携带的干粮，喝了几口水，杨帝扛起撬棍，揣着板砖，迈向三楼。</p><p>三楼的氛围与二楼并无太大差异，同样弥漫着一股腐朽陈旧的气息，墙壁上同样布满水渍和霉斑。</p><p>这层楼同样噪音污染严重。</p><p>时不时能听到一些奇怪的声响，像是有人在低声哭泣，又像是沉重的叹息。</p><p>生物污染也不容小觑。</p><p>在某些空房间里，杨帝会看见一大堆青苔、真菌滋生在某个角落，并组成人的形状。</p><p>过几个小时再去看，那些真菌和青苔组成的人形，还会改变自己的动作。</p><p>就像一个姿势维持久了，放松放松。</p><p>电梯井附近，还经常能看到有青灰的手露出半截，或者是一只猫背对着人。</p><p>青灰色的手已经见过，会把人拉下高处坠楼。</p><p>而背对人的猫则是彻底虚假的——那是某种东西的舌头。</p><p>它会用喵喵叫，把人引诱过去，然后将受害者卷进阴影里。</p><p>杨帝成功把那东西的舌头砍掉，所以没被拖走。</p><p>但他也看不清阴影里那东西是什么——即使他实力超然，那地方也好像打上一片马赛克，看不清晰。</p><p>用手电筒照亮黑暗处，那里什么都没有。</p><p>猫状的舌头在地上抽搐片刻，就会失活。</p><p>其质地像一只小乳猪，表皮脆而酥。</p><p>不过，这条“舌头猫”仅仅背面覆盖有毛发，正面光秃秃，没有毛发的遮盖，呈现出一种异样的苍白。</p><p>在昏暗光线中散发幽冷光泽，好似一块从千年冰窖中取出的老肉块。</p><p>它的表皮虽已酥脆，也不再抽搐，可那纹理却好似有着生命一般，微微蠕动着。</p><p>仿佛，还在试图与那隐藏在阴影中的本体建立联系。</p><p>四周的黑暗仿佛被这诡异的舌头吸引，愈发浓郁地朝着它聚集。</p><p>杨帝没有证据，但能感觉到——无数双手，想要将其重新拖回那不可知的黑暗深处。</p><p>于是，他把它也烧了。</p><p>当你不确定面对的是什么生物，把它烧了，也许就是最好的选择。</p><p>这栋烂尾楼虽然对外来者充满恶意，但有趣的小玩意还是挺多的。</p><p>杨帝如法炮制，清理干净所有楼层的东西，确保没有遗留奇怪的镜子，奇怪的小猫舌头，和奇怪的手。</p><p>他站在楼顶，向下探出上半身。</p><p>他无意间，瞥见一个人正在朝烂尾楼走来。</p><p>这鸟不拉屎的偏僻地方，居然有新客人。</p>
