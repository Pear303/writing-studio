# 大帝包围

<p>灵界天穹裂开42道缝隙。</p><p>气势极度汹涌，一众灵界大能都发现了不对劲，他们同时看向天边42处位置。</p><p>每道缝隙中都透出煌煌帝威。</p><p>率先踏出者，是三日前，二度失踪的归墟大帝。</p><p>他周身仙力缭绕，眼神冷漠。</p><p>紧随其后，是更多萦绕汹涌帝威的存在。</p><p>青丘白璃记忆中那位仁慈的初代灵界大帝，手持断剑的战狂大帝，掌控时间长河却最终陨落的溯洄大帝，甚至还有荒古时代的三位准圣、一位至圣之人……</p><p>一众古籍中记载的身影，相继出现！！</p><p>42位大帝刚一现身，便以惊人的默契形成环形阵列，将杨帝牢牢围困在中央。</p><p>他们的帝威交织成一张无形巨网，压得下方的灵界大能们几乎匍匐在地。</p><p>虚空在帝威挤压下发出不堪重负的呻吟，归墟之地的地貌以肉眼可见的速度崩裂塌陷，暴露出深层燃烧的灵能岩浆。</p><p>四十二道目光如四十二柄绝世神兵，从不同角度锁定杨帝，有的裹挟着灭世雷霆，有的弥漫着冰封万古的寒意。</p><p>只要杨帝稍有动作，便会迎来42位巅峰存在的同时绞杀！</p><p>一众灵界大能，满朝文武，无一人敢动。</p><p>杨帝动了。</p><p>“拖把粘粪的事情，我日后再和你们慢慢清算。”</p><p>他将那些只有蛐蛐真仙境界的蝼蚁们，包括阿巴59改和狐狸，一同包裹在光球里。</p><p>屈指，将其弹飞到千万里之外。</p><p>王对王，将对将，神仙打架，小孩退让！</p><p>看当下氛围，打一场是不可避免的了。</p><p>四十二位历史上曾存在过的大帝，此刻集结于归墟之巅。</p><p>归墟大帝悬浮于正前方，周身仙力如怒海翻涌，每道波纹带着碾碎星辰的威压。</p><p>青丘白璃是个极好的土著导游！她在极短时间内，向杨帝传达了相当于1000章的情报，其中999章是废话，1章是有用的信息。</p><p>有用的那1章，告知了这四十二位大帝的基本情况：</p><p>修仙者划分为3个顶层大境界，也就是：格物致知，炼虚洞玄，帝临真一。</p><p>据杨帝所知，“帝临真一”境又划分为5个次等境界：仙帝，神皇，至尊，准圣，圣人。</p><p>5个次等境界往下，还有3500万个细分境界，在此暂不讨论，不然我能水一亿字。</p><p>归墟大帝，他也只是“仙帝巅峰大圆满”级别的绝世强者。</p><p>绝世强者和绝世强者之间，亦有差别。</p><p>追溯到灵界的荒古时期，那时候天道有缺，法则不稳，本源经常泄露。</p><p>漏出来的“本源”都是大补之物，导致“大帝”扎堆出世。</p><p>众多大帝，死后以己身化道，补全天道，稳固法则，并以自身全部灵能反哺灵界。</p><p>于是，灵界大能越来越多，百花齐放。</p><p>但反而因此，后世“大帝”越来越少——因为灵界之强者，越来越难以接触那些愈发稳定的法则、天道。</p><p>天道稳固了，本源啊、法则啊就很难漏出来了！</p><p>仅靠“数值”的积累，几乎不可能抵达大帝之境。</p><p>必须要有“质”的突破。否则谁的灵能能够无限进步，无限积累？</p><p>归墟大帝是最后一位大帝，他靠炼化归墟渊水中的“虚无本源”，获得法则之力，从而触及天道的层次。</p><p>但归墟大帝终究只是“仙帝”境的大帝。</p><p>历史上，共有22名仙帝，11名神皇，5名至尊，3名准圣，1名圣人。</p><p>归墟大帝只能算中下游水平。</p><p>此刻，四十二尊震古烁今的绝强存在，都在杨帝眼前了。</p><p>站在最前头的归墟大帝，微微上扬嘴角：“白杨大帝，你以为等的是我？”</p><p>杨帝看着眼前阵容庞大的四十二位大帝，摇摇头：“你倒是好大的排场，找了这么多老古董来撑场面，是觉得自己单打独斗没把握，所以才玩起了狐假虎威的把戏？”</p><p>他目光扫过归墟大帝身后，那些散发着煌煌帝威的身影。</p><p>抵达“帝临真一”境界者，皆可称作“大帝”。</p><p>相传，灵界第一尊大帝，同时也是有史以来唯一一个“圣人”，在荒古年间率先跨过真仙境巅峰大圆满。</p><p>一众上古修士将“真仙境”的下一个境界称为“仙帝”，俗称大帝。</p><p>但没想到，跨越仙帝之境，而后仍然有境界延伸。</p><p>仙帝、神皇、至尊……灵界史上的第一位大帝，一路晋升为圣人，但是人对他的称呼“大帝”已成习惯。</p><p>所以“帝临真一”境界，皆称大帝。</p><p>大帝之间亦有差距。</p><p>四十二大帝中，“仙帝境”、“神皇境”、“至尊境”可以忽略，只是小中大号蝼蚁而已。</p><p>真正棘手的，是四个带“圣”字的家伙。</p><p>杨帝能够感应到这个事实，因为强者是会相互吸引、相互了解的。</p><p>他语气陡然一转，带着试探的意味：“不过说起来，你三日前突然失踪，再回来时性情大变，如今又带着这么多本该早已陨落的大帝一同出现……啧啧，该不会真是被什么东西夺舍了，所以才需要靠这些帮手来壮胆吧？”</p><p>杨帝打算套话，但对方人数众多，且个个修为高深。</p><p>即使是1500亿的话术，一时半会也发挥不出作用。</p><p>“够了。”</p><p>一道声音自四十二位大帝的阵列深处传来，平静无波，却带着一种能让天地法则都为之凝滞的威严。</p><p>身着素白道袍的存在缓步走出。</p><p>他面容古朴，眼神深邃如星空，周身没有丝毫外放的仙力，却让整片归墟之地的灵能岩浆都悄然凝固。</p><p>他正是灵界历史上唯一一位达到“圣人”境界的存在，残星道人。</p><p>杨帝赶紧做出“眼神一凛”的微表情。</p><p>寻常大帝，或许是法则的掌控者、天道的补全之人。</p><p>可残星道人，似已与天道法则融为一体，举手投足间便能引动天地本源。</p><p>他站在那里，便如同一尊万古不朽的神魔雕像，任由另外四十一位大帝气势如何雄浑，在他面前却仿佛都成了衬托其无上威严的背景板。</p><p>如果说，仙帝、神皇是小号大号蝼蚁。</p><p>至尊是能够划伤人的哈基米。</p><p>准圣是能一口咬烂航母的哥斯拉。</p><p>那么，“圣人”就是一个直径160公里的死星战舰，拥有一炮歼星的平A。</p><p>他的实力已不能用境界来衡量，那是一种返璞归真的极致！</p><p>何为“返璞归真的极致”？</p><p>就是纯粹的强度，纯粹的数值！</p><p>就连杨帝一瞬间，也恍恍然生出望洋兴叹之意。</p><p>他也看出来了，圣人的“灵能丰度”，和自己一样都是高破天际。</p><p>但和杨帝向内收敛的“负值灵能”不同。</p><p>圣人身上的灵能，更像是被打了马赛克，让人看不真切。</p><p>通俗来讲，就是玄之又玄，妙之又妙，不可言不可说。</p><p>——残星道人的境界，同样无法被灵界的天道所理解，超出了此世所能表达的范畴。</p><p>他极有可能达到和杨帝相同的水平。</p><p>甚至，还可能一山更比一山高，一节更比一节强。</p><p>残星道人眸光扫过杨帝。</p>
