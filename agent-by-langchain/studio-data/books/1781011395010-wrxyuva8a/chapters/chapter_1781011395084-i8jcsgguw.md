# 撬棍之死

<p>距离末日火山主峰60公里。</p><p>……</p><p>最初，人弱小，只能用木棍敲打皮皮虾。</p><p>而后，人升级，装备强化，敌人进阶。</p><p>直到有一天，手执「传奇·天崩地裂般若奔雷棍 +13」大战「真·霸王落日皮皮虾」！</p><p>这就是升级打怪的终极逻辑：用更好的棍子殴打更强大的皮皮虾。</p><p>耶罗大仙，也只是一尊无比强大的“皮皮虾”罢了。</p><p>这也是为什么，杨帝保留他的撬棍。</p><p>他尽可能在每次战斗过后，通过改善撬棍中“灵”的分布，修复撬棍内部细微损伤，优化棍子的应力集中点。</p><p>“吼呀！”</p><p>杨帝一撬棍捅进那只魔物的脑袋。</p><p>没想到这只通体墨绿色、有四只软足、没有双臂的魔物，生命力顽强，不死。</p><p>杨帝听见它嘶嘶声，火药味瞬间在空气中弥漫开来——</p><p>瑞弗维尔绝望地吼叫提示杨帝快跑：“快跑啊啊！苦力怕！要爆啦！！”</p><p>卧槽！苦力怕？！</p><p>但此时距离实在太近，杨帝来不及跑出多少米！</p><p>只听“轰”的一声巨响，苦力怕剧烈爆炸，强大的冲击力如同一股汹涌的狂潮！</p><p>火浪与冲击波以爆炸点为中心向四周疯狂扩散！！</p><p>杨帝整个人直接被气浪掀飞出去，在空中翻滚了好几圈后，脸朝地重重趴在地上。</p><p>“杨帝！”瑞弗维尔心急如焚，顾不上爆炸余波，朝着杨帝落地的方向冲了过去。</p><p>只见杨帝浑身尘土，衣服被爆炸的冲击力撕裂，身上也出现了几处血淋淋大伤口。</p><p>他，仅仅只是青一块紫一块！</p><p>脸接苦力怕……居然没有东一块西一块……</p><p>然而，那根杨帝一直珍视并精心维护的螺纹钢撬棍，此刻被炸得扭曲变形。</p><p>棍子一端还冒着淡淡的青烟。</p><p>“我的撬棍！！”刚站起身来看到这残酷一幕的杨帝悲鸣。</p><p>“原来那真是撬棍，而不是传奇法杖……别动！你受伤严重！”</p><p>瑞弗维尔迅速蹲下身，查看杨帝的伤势，同时施展起治愈法术。</p><p>这伤势……太轻太轻了。</p><p>按理来说，被苦力怕贴脸爆炸，人应该会炸成碎块，东一块西一块。</p><p>但杨帝，仅仅是蛐蛐重伤……</p><p>淡绿色光芒从瑞弗维尔掌心涌出，缓缓融入杨帝的身体，修复受损的组织。</p><p>……</p><p>杨帝受的伤，比他自己想象中要严重！</p><p>最可怖的是四肢，已经扭曲成“大快活”的图标那样了，像是有人用杨帝的手脚扎了四个麻花辫。</p><p>不过，魔法是万能的。</p><p>在治愈法术作用下，杨帝缓缓睁开了眼睛，喷出1200cc的血，然后气色重新红润。</p><p>他的四肢也开始自行扭动，将刚刚修复好的骨头，重新安装进关节，恢复到正确位置。</p><p>被炸成一团血糊糊的内脏器官，也在“俺寻思之力”的作用下，迅速生长。</p><p>杨帝虚弱地说道：“我……我没事，幸好昨夜锻炼了一整晚‘内部器官’……不然这会儿更难受。话说这苦力怕的自爆威力还真不小……”</p><p>烟尘渐散，爆炸的地方露出个大坑。</p><p>粗略估计，约等于30公斤TNT当量。反坦克地雷的装药量通常在5公斤左右，30公斤TNT当量，相当于6枚普通反坦克地雷的威力！</p><p>瑞弗维尔皱着眉头：“先别说话，休息。”</p><p>杨帝摇头：“你太慢了，我来罢。”</p><p>他默声瞬发了七八个“三环法术·愈合”，拍到自己身上。</p><p>法术叠加，治愈效果极好！这也是一种另类的优势火力学说。</p><p>瑞弗维尔眼角一抽，看着杨帝身上触目惊心的伤口，以肉眼可见的速度疾速愈合。</p><p>从人物面板视角看，杨帝各项抗性又在蹭蹭蹭上涨。</p><p>这异世界真是个好地方，要知道在地球，尤其是神州，很难通过比较合理的手段，搞到这么大当量的高爆炸药。</p><p>但在这里，各种魔物和法术，都能极大增强自戕效率。</p><p>他缓缓站起身来，活动了一下身体。</p><p>其中一条胳膊，下肢髋关节，两节脊柱，又脱臼了。</p><p>杨帝把它们安装回去，继续活动身体，要是还有脱臼，再重新把它安回去。</p><p>如此重复四五遍，骨头终于回到它们该待的正确位置。</p><p>虽依旧有些疼痛，但已不影响行动。</p><p>他手中那根变形的撬棍，心中惋惜！</p><p>他转身逃离的时候，撬棍还插在苦力怕的脑子里，它承受的爆炸最剧烈。</p><p>毫不意外，被炸到耐久度归零！</p><p>撬棍只是用螺纹钢做的棍子，比杨帝的血肉之躯要脆弱得多。</p><p>听起来有些倒反天罡，但事实如此。</p><p>杨帝神情肃穆，轻轻地将那根扭曲变形、已然耐久度归零的撬棍，放入了苦力怕爆炸后形成的大坑之中。</p><p>随后，他在四周寻找了块平整的石头。</p><p>利用对灵能的掌控，杨帝让灵能汇聚在双手之上，如同握着一把无形的刻刀，在石头上刻下了“纪念我亲爱的撬棍”几个字。</p><p>他再也不能用同一根棍子，来殴打终极Boss霸王落日皮皮虾了。</p><p>他小心翼翼地将这块石头立在坑边，算是为撬棍立了块碑。</p><p>做完这一切，杨帝肠胃传出雷声。</p><p>“治愈法术”仅仅是加速身体治愈，虽然也违反了一点质量守恒，但违反得不多。</p><p>现在，大病初愈的杨帝就非常非常饿。</p><p>他消耗了大量糖分、蛋白质修复身体。</p><p>虽然自己已经进化到“免疫‘饿死’”这地步，但也只是不死而已。</p><p>在质能稀缺的情况下，身体恢复力不如质能充沛的时候。</p><p>瑞弗维尔：“……事已至此，先做午饭吧。”</p><p>离开苦力怕炸出的大坑。</p><p>运气不错，他们发现条河流。</p><p>河流从东边的“末日火山”流下来，河道不算宽敞，但应该能俘获足够的蛋白质供给二人。</p><p>瑞弗维尔凭借身为宫廷图书馆馆长的丰富学识，在河岸搜寻野菜。</p><p>杨帝则决定钓鱼。</p><p>他找了根细长的树枝，用石头将一端削尖，又从衣服上抽出几根线，绑在树枝顶端。</p><p>然后，拔出一根嵌进了砖头里的铁钉，通过“物质形态重塑”的现实扭曲能力，将它变成一个鱼钩的形状。</p><p>简易鱼竿就做成了。</p><p>杨帝从一直随身携带的熔岩史莱姆身上小心翼翼地扣下一小团凝胶。</p><p>这团凝胶散发着微微的热气，尝一口，还有些奇异的微甜。</p><p>对于河里的鱼来说，想必是极具吸引力的美味！</p><p>……</p><p>作为“正圣字旗”的老圣古琉斯土著，瑞弗维尔喜欢午后斟上一杯茶，蹲在皇城根下，笑嘿嘿看着街头马戏团的小丑表演抛球，身边再走过几个穿束腰装的小姐、打领带戴高帽的先生，时不时磕点商贩卖的甜菜根曲奇饼。嘿，那叫一个地道！</p><p>平静的生活已离他远去。</p><p>圣古琉斯王城距离此地五百公里。</p><p>但瑞弗维尔习惯不改——他借着“采野菜”的机会，摘取大量花瓣和嫩尖芽儿用以泡茶。</p><p>瑞弗维尔用帽子捧着野菜和花叶，心情愉悦回到营地。</p><p>当他看到杨帝一脸无奈坐在河边，鱼钩孤零零地悬在水面，一条鱼也没钓上来时，忍不住笑出了声。</p><p>“哈哈，看来今天鱼儿们不太给面子。”</p><p>瑞弗维尔笑了半分钟后才努力憋住了笑，以表示对传奇法师尊重，以防对方恢复记忆后，为掩盖黑历史而反手将他轰杀。</p><p>杨帝目不转睛盯着水面，一脸困惑。</p><p>「不应该呀，关于钓鱼的姿势，我在梦中翻看记忆，模拟过成百上千遍，包括小时候我老爸是怎么钓的，以及钓鱼佬每个手法和步骤……」</p><p>他内心如是想着。</p><p>但不知为何，这该死的鱼，就是一条也钓不上来！</p><p>小时候如此，现在也是如此。</p><p>瑞弗维尔：“要不我再去找点野果和蘑菇……”</p><p>杨帝：“不用，我决定士子以身入局。”</p><p>他丢下简易鱼竿，抄起板砖，跳进水流。</p>
