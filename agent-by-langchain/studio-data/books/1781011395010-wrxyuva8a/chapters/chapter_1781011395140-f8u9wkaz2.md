# 大帝死了？

<p>归墟大帝喝水呛死了。</p><p>「归墟」是什么？</p><p>归墟乃是先天神尊手持“灵茶山乂斧”，开辟天地混沌之初，世界未稳，从天道裂隙中渗出的“虚无本源”所化。</p><p>传闻归墟深处悬浮着混沌未开时的渊水，每一滴渊水都蕴含着解构万物的力量。</p><p>寻常修士若饮下，三魂七魄会在瞬息间被抹除殆尽。</p><p>情欲、灵智，乃至存在本身，都将如泼墨般溶于虚无。</p><p>何为「大帝」？</p><p>他进出归墟自如，取渊水三千瓢饮，非但未被其消解，反而将渊水化作莹莹微光，融入体内道统，炼化无上伟力。</p><p>众仙目睹此景，举世震骇，无不俯首称臣，尊为“大帝”，名号“归墟”。</p><p>归墟大帝立于归墟之畔，袍角被虚无本源的微光染得透亮。</p><p>他垂眸望向三界芸芸众生，眸中蕴存怜悯，与超脱尘世的淡漠。</p><p>凡间战火燎原处，稚子捧着龟裂的陶碗舀浑浊雨水。</p><p>仙山渡劫台上，渡劫修士因心魔反噬而形神俱散。</p><p>幽冥忘川边，孤魂因执念困锁不得往生……</p><p>归墟大帝负手而立，背对世人，镇压黑暗不详，平靖域外天魔。</p><p>他背后是二界苍生的万家灯火，眼前是域外天魔撕裂空间的狰狞血口。</p><p>那些扭曲黑影挥舞着骨爪，叩击虚空，荡起腐蚀神魂的暗紫色涟漪。</p><p>大帝牵引万千因果，凝聚兆亿灵能，化作一道横贯天地的光刃劈去，斩杀汹涌魔潮。</p><p>平荡天魔，安定天地。</p><p>“大帝为何总背对我们？”有小仙望着那道孤寂的背影喃喃自语。</p><p>老仙君抚须长叹：“大帝镇杀域外天魔，杀戮过多，沾染煞气极重，其‘心’亦被杀业所染，因‘相由心生’，面容亦逐渐化作‘傩’般可怖。所以，大帝用代表杀戮的脸注视黑暗不详、域外天魔……他只会用最脆弱的后背，朝向众生。”</p><p>大帝以归墟之力，修补天地裂隙，稳固六道秩序。</p><p>他重新划定灵界秩序，护佑凡界太平。</p><p>他炼化天魔头骨，铸成“镇煞京观”立于灵界边陲，碑身刻满战死仙将之名。</p><p>他以无上神通，深入归墟最深处，采集天材地宝，烧铸成砖。</p><p>他召集三界中擅长土木建造与符文铭刻的大能之士，齐聚灵界边陲，建成对抗域外天魔的宏伟长城。</p><p>他禁止灵界插手凡界内政，除了几件特定的事——对凡间实施人道主义援助。</p><p>以及不以盈利为目的的基础设施工程、城乡结合建设、区域协调发展。</p><p>归墟大帝带来了和平。</p><p>饱经沧桑的世界——不只是灵界，还有凡间，如今处处洋溢着生机与希望。</p><p>无数修士争相追随归墟大帝。</p><p>无数凡人将大帝挂在墙上。</p><p>可惜，兴许是归墟之道太过霸道。</p><p>也许是他的力量为天地所妒。</p><p>或许是命运无常，宇宙混沌，才是这片天地本真的面貌。</p><p>世人即使成仙，纵然证道大帝，也仍然无法绝对主宰自我的命运。</p><p>哪怕大帝已证道混元，哪怕他能够进出归墟自如，哪怕他的力量能够开辟天地。</p><p>也难逃“死亡”的宿命。</p><p>最终，归墟大帝喝水呛死了。</p><p>「喝」是喉结滚动间津液入腹，解渴润喉的寻常举动。</p><p>「水」也并非归墟之渊水，而是非常普通的凡界白开水。</p><p>当日，归墟大帝微服私访，来到凡界一家小摊，发现热水免费于是要了杯热水。</p><p>搪瓷盏中升腾的白雾裹着粗茶的涩香，他垂眸望着水面上摇晃的月影。</p><p>他也许想起已经尘归尘土归土的父母，也许想起仍然封印于光阴琥珀中的爱人。</p><p>大帝也许想到：自己能掌控虚无本源，却握不住指间流沙般流逝的岁月。</p><p>指尖无意识摩挲杯沿。</p><p>这具肉身，竟在此刻生出微妙的渴意——这在他证道后漫长岁月里，是从未有过的体验。</p><p>喉结轻颤，热水入口。</p><p>意识坠入黑暗前的刹那，他听见酒楼外孩童嬉笑跑过，恍惚间又回到了最初的人间，那时一杯清水，也曾如此甘甜。</p><p>归墟大帝喝水呛死了。</p><p>何为「死」之意？</p><p>于生物学而言，“死”是生命体征彻底消亡，细胞停止代谢，神经活动归于沉寂，烛火熄灭，再无生机。</p><p>于物理学而言，“死”是构成一个主体的能量与物质混乱程度超过阈值，回归宇宙循环，遵循熵增定律走向无序。</p><p>于哲学而言，“死”的可解释方向就更多了，可以是存在意义的终结，可灵魂脱离躯壳，意识不再具备超越生死轮回的思辨。</p><p>具备无限可能性与奇迹的生命，向有限性缴械；俯瞰六道的智慧，如今无法再捕捉真理的流动。</p><p>归墟大帝喝水呛死了。</p><p>以理性而论，归墟大帝不可能死。</p><p>从生物学角度，大帝的身躯与精神，早已超脱凡俗，超脱六道。</p><p>他的细胞更迭遵循混沌道则，每一寸肌理都由虚无本源淬炼。</p><p>即便遭受致命创伤，也能瞬间从“解构”状态中重组。</p><p>物理学层面，大帝能够逆转时空流向，将溃散的能量与物质重新凝聚成有序形态。</p><p>归墟渊水在他手中，可化为重塑天地的秩序之力，又怎会任由自身走向无序？</p><p>他的存在本身就是对天地法则的超越，任何能量消散，都不过是暂时的表象。</p><p>从形而上意义看，归墟大帝的意识早已与天道同频。他承载着“虚无本源”的道统，是无数修士心中不灭的信仰图腾。</p><p>即便肉身崩解，其存在本质与归墟相连，记忆铭刻于天道纹路。</p><p>除非彻底毁灭灵凡二界，湮灭天地万物之运行法则，否则归墟大帝不可能达成真正的死亡。</p><p>然而，归墟大帝喝水呛死了。</p><p>灵界目前仍在努力压住这个消息。</p><p>但纸终究包不住火，他们必须立刻彻查，找到能让一尊大帝喝水呛死的原因。</p><p>特别是……大帝居然还是在凡界死去。</p><p>不可理喻，极度不可理喻。</p><p>关于凡界，灵界一众修士皆有了解：那是一片灵气匮乏、法则残缺的荒芜之地。</p><p>街道上川流不息的钢铁巨兽，闻着空气中刺鼻的工业废气——此地连连最低阶的引气诀都难以施展。</p><p>若要论凡人最强的武器，大约也就是“热核炸弹”、“重力炸弹”此类，挠痒痒罢了。</p><p>难道那些凡人看似在烧水做饭，实则是在为“弑帝大阵”提供能量？</p><p>这也太科学了，一点都不玄幻！</p><p>如果凡人都能拥有“戮仙”的能力，什么灵力都不需要、就能将一个大帝杀死。</p><p>那他们这些在灵界混了这么多年的老油条，对归墟大帝俯首称臣这么多年，都活到狗身上去了么！</p><p>所以，大帝既不是凡人所杀，也不能是凡人所杀。</p><p>这个首先是原则，是底线。</p><p>（此篇略微偏向悬疑风格？）</p>
