# 凡界、本质！

<p>像归墟大帝那样，一身霸道灵压，随意散溢出来一丝，都能震人心魄。</p><p>而杨帝，一身灵能不是向外散，而是向内收缩，和鹌鹑基本没区别。</p><p>或者不用鹌鹑做比喻，也可以把杨帝比作黑洞。但“黑洞”的逼格终究没有“鹌鹑”那么高。</p><p>外界的灵能，被杨帝疯狂向内拉扯，消失在体表，仿佛溶于无底深渊。</p><p>鹌鹑，呸，杨帝，的目光扫视四周。</p><p>他们正站在一座悬浮于云海之上的巨大白玉平台上，远处是连绵不绝、散发着各色霞光的仙山福地，灵禽异兽穿梭云间，浓郁的灵气几乎凝成实质的薄雾。</p><p>这景象，比十万大山深处的浮空都市还要瑰丽壮阔千百倍。</p><p>然而，他的注意力很快被身后的景象吸引。</p><p>他们刚刚出来的地方，并非什么空间裂缝或传送阵。</p><p>而是一幅……悬浮在灵界空气中的巨大水墨画卷！</p><p>画卷的主体，正是他们刚刚离开的凡界——十万大山的巍峨轮廓清晰可见，君士叹顶堡那座钢铁森林般的城市如同画卷中心一颗微缩的、闪烁着金属冷光的奇异墨点。</p><p>山川河流，城池村落，甚至隐约可见凡人的活动轨迹，都在这幅巨画中以一种宏大又精细的方式呈现。</p><p>不只是十万大山，也不只是君士叹顶堡。</p><p>整个凡界，分为九州，每州三十六郡，每郡又辖七十二城，天下共两万三千城……</p><p>都被囊括在这幅水墨画之中。</p><p>而他们四人，正是从这画中山峰顶部的一个小小“墨渍”中“走”出来的。</p><p>而那小小“墨渍”，就已经是万山最磅礴的主峰——君士叹顶峰。</p><p>美中不足的是，这画上有一条裂缝。</p><p>“世界裂缝也只有真正的大能可以弥合……”</p><p>归墟大帝伸出一只手，五指张开成鹰爪状，按在那道漆黑的裂缝上，五指用力收缩。</p><p>他将打通两个世界的裂缝，强行贴合在了一起。不愧是只有大能才能“掌控的世界裂缝弥合技术”。</p><p>时空本身，开始蠕动着自愈。</p><p>世界，并没有很多人想象中的那么脆弱。</p><p>大道，也并不那么容易就会被磨灭。</p><p>“噗……”</p><p>阿巴看着那幅画，又看看脚下真实的灵界白玉平台，再回头看看那幅画，忍不住噗嗤一声笑了出来。</p><p>“噫，好！我们真是从画里爬出来的耶！哈哈哈哈！”</p><p>「又疯一个。」59改按住阿巴，努力让夕阳红旅行团不要在归墟大帝面前出糗。</p><p>杨帝看向狐狸：“青丘女士，这画看着有点眼熟。”</p><p>青丘白璃也为那幅画所吸引，多看了几眼。</p><p>随后她才定了定神，声音带着敬畏：“杨帝阁下目光如炬。此图，正是‘凡界的本质’，传说中的混沌至宝‘混元山河图’。”</p><p>“哦？”杨帝来了兴趣，凑近那悬浮的巨画。</p><p>他的靠近，让画卷边缘的墨色又开始不安地波动。</p><p>仿佛是这幅画在恐惧杨帝的灵能。</p><p>“传说在天地初开之时，混沌中孕育了数件至宝。这混元山河图便是其一。”</p><p>青丘白璃解释道，目光追忆着古老的传说。这种设定放在网游里，是要氪金才能取得的红色品质装备。</p><p>“相传，此图最初并非如此，它只是一张蕴含无上造物伟力的空白画卷。</p><p>“后来，一位惊天动地的大帝，在这张空白画卷上，绘制了最初的‘山河’。</p><p>“他画下了日月星辰，画下了山川河流，画下了草木生灵……起初只是一个概念，一方雏形小世界。</p><p>“随后那位大帝以己身化道，补全此画卷的天道法则、本源规律。随后，画卷上的万物，开始演化、膨胀、完善。</p><p>“最终，它演变成一个较为完整、独立、生机勃勃的‘世界’，也就是我们口中的——凡界。</p><p>“这就是凡界的本质，一副画。它本应该是个要保守的秘密，就连灵界，也没多少个大能知道‘凡界其实是一幅画’。”</p><p>杨帝和阿巴啧啧称奇，青丘白璃卑微地站在一旁介绍。</p><p>归墟大帝则背对他们负手而立，一副纯正世外高人的模样。</p><p>这就是为什么——凡界是一片大陆。</p><p>凡界是被那位惊天动地的大帝，给设计成了大陆世界观！</p><p>你们这些做设定、做世界观的人，能不能别那么随便啊！</p><p>显然，归墟大帝默许与杨帝诸位外来者，分享“混元山河图”这个秘密。</p><p>这或许也是一个友好信号。</p><p>阿巴发出啧啧怪声，仿佛在咀嚼这个信息：“真有意思！搞了半天，凡界是画出来的？还是自己长出来的？这‘虚拟世界生成器’的版本够古老。”</p><p>59改的电子音带着强烈的求知欲：</p><p>「青丘白璃女士，您的意思是，我们所知的整个凡界宇宙，其物理基础、时空结构、乃至生命形态，其根源都基于这幅‘混元山河图’所定义和承载的‘数据’？」</p><p>「这简直是对守望者宇宙大一统模型的颠覆性发现！」</p><p>「它如何维持如此庞大宇宙的稳定运行？它的‘算力’或者说‘本源’从何而来？它……」</p><p>59改顿住了。</p><p>他回想起杨帝所说过的“虚拟世界”假说。</p><p>而在半秒前，他还成功测定了灵界的基本物理常数。</p><p>灵界，光速约为300万公里/秒，普朗克尺度也相应地更精细。</p><p>是的，在现实世界，极难制造出“还原度”100%，也就是每一条物理细节完全照搬现实、精度极限达到普朗克尺度的虚拟世界。</p><p>和灵界比起来，凡界显得如此“卡顿”、“粗糙”……</p><p>但在此之前，他们丝毫察觉不到，凡界其实是一幅画。</p><p>换言之，即使是阿巴这样的真仙境大能、59改这样的宇宙级文明，都察觉不到“虚拟世界”和“现实世界”有什么不同……</p><p>过去在凡界游历的几天，都仿若黄粱一梦。</p><p>“那么我之前的推理，彻底不成立了。”</p><p>杨帝开始心思电转，头脑发烫。</p><p>“归墟大帝根本不是因为什么觉醒了‘喝水就能变强系统’，然后在喝水那一瞬间，修为超出凡界上限，从而被弹出。</p><p>“如果被凡界弹出，那么他应该回到他原本的现实世界——‘灵界’，这才对。</p><p>“但是，他没有被‘弹回’灵界。而几位土著大能都说，凡界和灵界的每个角落，没有归墟大帝的身影。</p><p>“据归墟大帝的话语暗示，他可能是去往了凡界、灵界以外的‘第三个世界’。</p><p>“但这与‘背叛’有何关系？与‘阴伏流煞’又有何关联？”</p><p>杨帝绞尽脑汁，但想不出答案。</p><p>他只能用力扫视灵界环境，将各个地方的景点名胜，和归墟大帝给的山川舆图对上号。</p><p>先尽可能收集灵界情报。</p><p>人生五百年，如梦亦如幻。在漫长岁月的洗礼下，凡界蓬勃发展，烟火气息愈发浓郁醇厚。</p><p>与之截然不同的灵界，则因长久笼罩在比凡界浓郁100倍的灵气之中，而孕育出独具特色的社会形态与个体风貌。</p><p>灵凡二界，灵气浓度呈100:1。</p><p>此地，是修仙的圣地。</p><p>归墟大帝抬手虚引，脚下云阶化作流光载着众人升腾，眨眼间便悬停在一座云雾缭绕的高山之巅。</p>
