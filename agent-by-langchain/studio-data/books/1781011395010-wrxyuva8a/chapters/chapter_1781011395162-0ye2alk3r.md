# 恨与背叛

<p>杨帝的意识透过59改建立的中继，直面着那来自碎片记忆的、跨越了生死界限的庞大意志。</p><p>那并非完整的大帝，更像是一道刻骨铭心的伤痕，一段凝固的、充满剧毒的执念。</p><p>逝者已逝，但仍有一部分被强行留于世间。</p><p>“你是，何人。”</p><p>声音直接在杨帝的思维深处回荡，没有通过听觉，却带着实质性的压迫感，竟然略微撼动了杨帝亿万分之一的精神力量。</p><p>那感觉，如同冰冷的星辰碾过灵魂。</p><p>如果是在全盛状态，归墟大帝至少能媲美杨帝0.85根手指，四舍五入就是一根中指。</p><p>杨帝并未直接报上名号，而是迎着那道穿透时空的目光，沉声反问：</p><p>“我是谁不重要，重要的是你。告诉我，发生了什么？”</p><p>眼神骤然变得极其复杂。</p><p>愤怒、痛苦、茫然、以及那几乎要焚毁一切的恨意在其中疯狂交织、翻涌。</p><p>59改的警告声变得更加尖锐急促，连青丘白璃和阿巴，都感到一阵源自灵魂深处的悸动。</p><p>“你是归墟大帝？”</p><p>“毋庸置疑。”</p><p>“发生了什么？”</p><p>大帝的声音低沉下去：“我、不记得了……记忆……散落、模糊……”</p><p>“你不记得发生过什么，但你仍然知道自己是归墟大帝？”</p><p>“绝对没错……”</p><p>他抬起虚幻的手，看着那由数据流构成的、沾染着凝固星光的破碎甲胄，动作带着一种迟滞的困惑。</p><p>“虽然记不清楚，但感觉……清晰如昨……”</p><p>他的声音陡然拔高，如同压抑亿万年的火山终于找到了宣泄口，那深沉的恨意瞬间化为实质性的冲击波，狠狠撞向杨帝的意识体！</p><p>轰——</p><p>杨帝迅速撤销“大脑封闭术”，这才没有让归墟大帝撞死！</p><p>“恨！！”大帝的咆哮在杨帝脑中炸开，如濒死野兽般的凄厉嘶吼，“我心中……恨！滔天恨！焚星煮海之恨！！”</p><p>那恨意是如此纯粹，如此磅礴，几乎淹没了其他所有情绪。</p><p>“你恨什么？”</p><p>“记……不清。”</p><p>“你为什么恨？”</p><p>“不……知道。”</p><p>“你能够回想起三天之前的事情吗？”</p><p>大帝的动作停滞了，眼中翻涌的恨意被更深的迷茫覆盖，如同浓雾遮蔽了灯塔。</p><p>他努力地思索，赛博手指用力按住自己的太阳穴，仿佛要将那破碎的记忆硬生生挤压出来。</p><p>杨帝咄咄逼人：“阴伏流煞，是你放的？”</p><p>“没错！！因为我恨！！！”</p><p>归墟大帝又突然咆哮起来，“背叛！！我遭受了最可耻的背叛！！！阴伏流煞是我制造的，那群数字生命也是我指使的，我所为的就是毁掉这个世界！！”</p><p>“你是因为‘被背叛’而死？”</p><p>“不是……不是……我……知道自己要死。但我无法容忍背叛……”</p><p>「警告：软体不稳定。」</p><p>「现实特征码：归墟大帝，即将崩溃。」</p><p>大帝的面容变得模糊不清，时而化作愤怒的狰狞面孔，时而又呈现出痛苦的扭曲表情，嘶吼声变得支离破碎，夹杂着刺耳的杂音。</p><p>“背叛……背叛……阴伏流煞……”</p><p>这个词汇不断重复，越来越快，越来越高亢，最终变成了尖锐的、刺破耳膜的啸叫。</p><p>滋啦——！</p><p>连接因“大帝碎片”的不稳定崩溃，而被强行切断。</p><p>在最后那一刻，杨帝将归墟大帝的“现实碎片”吞噬干净，防止污染环境。</p><p>“大帝碎片现实特征码”也在同一时间崩溃，杨帝、白璃、阿巴的意识弹出虚拟沙盘。</p><p>归墟大帝的残存记忆消失了。</p><p>但刚才那直面大帝滔天恨意的冲击，如同烙印，刻在他们心头。</p><p>“他……真的恨……”青丘白璃的声音带着一丝颤抖。</p><p>作为与归墟关系最密切的人之一，她最能感受到那份恨意中蕴含的、足以颠覆星河的绝望力量。</p><p>那不只是愤怒，更像是被整个世界背叛后，拖着残躯走向毁灭深渊，发出最后诅咒。</p><p>“他不记得具体过程，但记得是背叛，来自信任圈内的背叛。”</p><p>青丘白璃的瞬间回忆完灵界的势力交错，爱恨情仇，以及归墟大帝生平的所有社会关系。</p><p>她不明白。</p><p>无论是什么人背叛了他，都不太可能。</p><p>她只是天真的狐狸，坚信爱与正义，不适合思考政治阴谋。</p><p>“别动！！放开队长！！”</p><p>核心区的冰冷空气仿佛凝固。</p><p>现实世界里刚过去3秒。</p><p>三秒前，59改突然抓住攻壳机动队第9课的队长，这让其他城管很是震怖。</p><p>他们知道队长的实力，她不能说手无缚鸡之力，只能说可以一拳打爆钢筋水泥墙壁。</p><p>第九课的城管全身的武器激活，幽冷的指示灯转为刺目的战斗红。</p><p>杀意如同实质，锁定那四个黑袍身影。</p><p>他们队长深红的义眼数据流疯狂奔涌，颅骨京观的噩梦呓语与眼前不祥的阴影重叠，几乎要将她的处理器烧穿。</p><p>就在这千钧一发之际——</p><p>“别紧张，自己人。”</p><p>一个带点漫不经心的声音突兀地响起，打破了令人窒息的死寂。</p><p>声音的来源，就是其中一个黑袍人，杨帝。</p><p>他就这么随意走到两拨人中间，无视了攻壳队员蓄势待发的武器。</p><p>随手一抛，动作随意得像丢开一个空饮料瓶。</p><p>“喏，还给你们。刚才这位美少女队长有点数据紊乱，差点在主机里短路了，我们‘龙组’正好路过，本着人道主义精神和维护公共数字安全的原则，顺手帮她重启了一下系统。放心，保修期内，没拆封条，就是做了个小小的深度杀毒，保证没后门。”</p><p>杨帝拍了拍手。</p><p>学雷锋做好事。</p><p>“龙组？！”攻壳机动队的城管几乎是咬着电子音挤出这个词，枪口纹丝不动。</p><p>“对，龙组。别查数据库了，查不到的。我们就是个……嗯，民间自发组织的兴趣小组。”</p><p>杨帝严肃地点点头，甚至露出一个“你懂的”那种眼神，“我们这个‘民间组织’，主要负责维护世界和平，打击外星间谍，是业余爱好，纯属自愿。没编制，没预算，连五险一金都没有，全靠一腔热血和对半人马座摄影艺术、黑蜥蜴星时尚潮流的高度警惕在支撑。”</p><p>他摊了摊手，语气略微带着点小本经营不容易的无奈：“官方没背书，自然不认识我们，很正常嘛。毕竟我们低调惯了，做好事不留名，深藏功与名。”</p><p>这番话信息量巨大，配合杨帝那副“我就是这么理所当然”的表情，让整个主机大厅陷入了一种诡异的寂静。</p><p>瘫坐在椅子上的程序员五心向天，技术主管的眼角疯狂抽搐。</p><p>但由于他话术点数极高，所以，在场所有人都相信了他。</p><p>这对凡人而言，已经是邪神级别的精神污染了。</p><p>“你们……”</p><p>城管虽然全盘相信了杨帝，但他的职责还是控制他冰冷的说话，“闯入国家核心设施，伪造最高权限，劫持执法人员，非法访问机密数据……这就是兴趣小组的业余活动？”</p><p>“没错。今后我们可能会继续搞活动，希望你们能配合我们行动。”</p><p>杨帝像领导视察结束一样，对着那些依旧处于石化状态、三观彻底粉碎性骨折的工作人员，挥了挥手：“辛苦各位同志了，加班费记得找你们领导要双倍。回见。”</p><p>一人一鱼一狐一车消失。</p>
