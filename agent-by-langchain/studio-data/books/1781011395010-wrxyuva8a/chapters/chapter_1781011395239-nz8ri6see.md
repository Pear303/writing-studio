# 同归于尽

<p>而被消化和榨取出的“现实丰度”——那原本支撑耶罗分形存在的灵能，正化作最纯粹最高位的燃料，疯狂反哺着他自身。</p><p>他的灵能越丰厚，消化能力越强。</p><p>消化能力越强，对灵能的榨取速度越快……</p><p>无止境的正反馈。</p><p>如同坐上了一架没有顶棚的火箭，冲破阿列夫零的藩篱，向着耶罗所立足的阿列夫一之海，发起狂暴的冲锋。</p><p>“不够！还不够快！距离‘涌现’，我还需要更多更快……老狐狸，再给我多来点！”</p><p>杨帝狂啸，他的身影在纯白背景中仿佛也带上了一丝赤红的分形虚影，那是正在被他暴力消化吸收的耶罗之力。</p><p>不顾一切地吞噬着眼前这超越认知的美食，用对方的“血肉”作为自己攀登更高无穷的阶梯。</p><p>此消彼长。</p><p>蔓延，迭代，扬升——进化。</p><p>耶罗大仙分形狐躯剧烈震荡，黑暗竖瞳闪过一丝狠厉。</p><p>它意念狂涌，虚空中瞬间撕裂数万亿道裂缝，每一道裂缝中都挤出一位散发着强大圣威的身影——皆是它最狂热的铁杆信徒圣人。</p><p>“小的们！拥趸们！走狗们！上！”耶罗意念嘶吼。</p><p>数万亿圣人如同自爆的流星，燃烧着毕生修为与灵魂，带着殉道般的狂热，悍然撞向杨帝。</p><p>杨帝眼神冰冷，毫无波动。</p><p>这些冲上嘴边的自助餐，卡路里实在太低，他不屑一吃。</p><p>纯白的白杨世界领域猛地向外一“吐”！</p><p>如同吐出一口浊气。</p><p>那数万亿被耶罗当作肉盾和消耗品的狂热圣人，瞬间被白杨领域精准地排斥出去，如同垃圾般被抛向领域之外。</p><p>杨帝继续扼住耶罗的咽喉。</p><p>一边扼住，一边将其疯狂消化磨灭。</p><p>“耶罗，机制怪我不是没有杀过。蕴含无穷灵能的人，我也没有怂过。”</p><p>无形无质的深邃光芒，在自我交替迭代中，向上延展一切间隙，拓展所有可能。</p><p>“只有你能够填满我的胃袋。”</p><p>“ONLY U——”</p><p>杨帝体内那沸腾的“胃域”之中，被疯狂消化撕扯的耶罗大仙，其无限分形构成的赤红狐躯猛地一滞。</p><p>它身上属于阿列夫一不可数无穷阶的磅礴灵能，不可计数的现实丰度，如同被戳破的气球骤然暴跌，瞬间跌落回一个“有限”的层级。</p><p>质变的飞跃。</p><p>在前一时刻，杨帝的消化力「涌现」出“磨灭阿列夫一级别灵能实体”的能力。</p><p>它层层嵌套无限递归的赤红狐形灵能护盾，失去了高阶无穷的支撑，如同风化沙堡，在杨帝胃域狂暴的消化力量面前，无声无息彻底崩碎。</p><p>耶罗大仙，从阿列夫一的神坛上，被硬生生拽了下来。</p><p>咔嚓！</p><p>紧接着，包裹着杨帝与耶罗的纯白色白杨世界领域，毫无征兆地碎裂了。</p><p>如同被无形的重锤击中的琉璃穹顶，瞬间布满蛛网般的裂痕，然后轰然炸成漫天飞散的纯白光屑。</p><p>领域破碎的瞬间，视野骤然开阔。</p><p>杨帝和耶罗，暴露在无尽虚空之中。</p><p>他们扭头看向外部。</p><p>外面，不再是单一的无限机兵之海。</p><p>无数棱角狰狞，散发着冰冷金属光泽的巨型星舰，如同从虚空中生长出的钢铁山脉，层层叠叠，密密麻麻，将这片区域围得水泄不通。</p><p>每一艘狰狞星舰的周围，都包裹着一层流动的光膜——那是一个个法则完整、自洽运行的微型小世界，如同坚固的移动堡垒外壳。</p><p>杨帝很快就明白，这些战舰从何而来。</p><p>无限机兵，它们并不是攻击武器。</p><p>而是某种，架桥铺路的基建设备。</p><p>它们抵达预定地点后便停下，构成一道道硕大无朋，边缘流淌着炽热能量流和复杂几何光纹的稳定结构。</p><p>从这些“门扉”的炽热核心中，如同火山喷发般，一艘艘庞然大物轰鸣着挤了出来。</p><p>这些正是杨帝和耶罗所见的、棱角狰狞的巨型星舰。</p><p>按道理，任何未经保护的物质、能量，没有任何保护，裸体地进入虚空，都会被“虚无空旷”缓慢却不可逆转地消融，最终归于寂灭。</p><p>即便是强如耶罗的古老存在，其分形狐躯的边缘也开始泛起细微的涟漪，如同墨滴落入清水缓慢扩散。</p><p>只不过这点微不足道的伤害，对耶罗而言只是九牛一毛，还不如杨帝多轰它半拳。</p><p>那些战舰，和无限机兵组成的传送门，也做出了精妙的应对措施。</p><p>由机兵组成的圆环传送门，每当有一艘战舰驶出，就会如巨大的吹泡器在运作。</p><p>一层薄如蝉翼，却又流光溢彩的“膜”，以星舰的舰首为起点，瞬间膨胀延展，完美地包裹住了整艘巨舰！</p><p>眨眼间，构成一个稳定世界所需的底层逻辑就被编织出来。</p><p>它拥有一个完整世界该有的一切底层规则：空间在此膜内稳定存在，时间在膜内单向流动，物质与能量遵循守恒定律……它就是一个独立运行的“领域”。</p><p>这些星舰没有开火。</p><p>它们似乎瞬间就洞悉了杨帝那恐怖的进化与适应能力。</p><p>无数道强大到足以禁锢宇宙的拘束力场，如同亿万条冰冷的锁链，精准地缠绕上来，试图将他完全束缚。</p><p>杨帝在领域破碎、拘束力场加身的瞬间，目光沉静地迎向了这片骤然出现的钢铁星舰之海。</p><p>一艘，十艘，百艘，千艘，万艘……</p><p>数不清的巨型星舰，源源不断地从那些由无限极兵撕裂并维持的能量门扉中涌出。</p><p>它们瞬间完成法则之膜的包裹，似是包裹着七彩肥皂泡的钢铁巨卵，稳稳地悬浮在虚空中。</p><p>杨帝扼住耶罗咽喉的手掌，仍旧纹丝不动。</p><p>他能清晰感受到掌中那曾经拥有阿列夫一阶伟力的分形狐躯，此刻正如从地狱传送门进到地狱跳进岩浆的雪傀儡般飞速消融崩塌。</p><p>跌落回“有限”层级的灵能，在杨帝体内那已然“涌现”出磨灭阿列夫一无穷级存在能力的“胃域”面前，脆弱得不堪一击。</p><p>耶罗大仙的黑暗竖瞳中，最后一丝灵性的光芒正在熄灭。</p><p>无限递归的分形结构，失去了高阶无穷的支撑，正从最核心处开始，如同多米诺骨牌般连锁崩解。</p><p>构成它存在的“现实丰度”——那支撑其分形本质的灵能，正被杨帝吞噬，化作推动自身向更高维度攀升的纯粹燃料。</p><p>「编撰众生命运的剧作者，永恒地死去。」</p><p>不知是何处而来，不知是谁人言语。</p><p>这段信息，出现在杨帝的脑海之中。</p><p>眼耳鼻舌身意末那阿赖耶，全部感知回荡着这段信息。</p><p>星环盟约的机兵和舰队，似乎也检测到耶罗大仙之死。</p><p>嗡隆——无数星舰组成的钢铁囚笼骤然光芒大盛，舰身外世界法则之膜不再孤立，开始疯狂延伸连接，最终融合。</p><p>无限机兵构成的庞大基座核心，亮起超维度的几何图案，所有机兵不再独立，化作蓝图精密零件，全投入同一目标——构筑超巨型“吹泡器”，封装杨帝及他手中的耶罗之尸。</p><p>虚空被强行扭曲塑形，无数闪烁光泽的机兵瞬间在四周形成巨大环形结构，让其中的杨帝都显得渺小。</p><p>这环，便是“吹泡器”的口。</p><p>噗——！</p><p>法则层面的震耳欲聋的轻响，厚重到实质化的“膜”以环形为界瞬间生成，迅速膨胀，像包裹星域的超级肥皂泡，将白杨大帝、耶罗之尸及所在虚空彻底裹入其中。</p><p>「耶罗大仙与白杨大帝在神圣星环盟约的终极兵器『万世点火装置』射流中同归于尽。」</p><p>「或许这也是个好结局吧。」</p><p>「西元二零二五年八月十六日」</p>
