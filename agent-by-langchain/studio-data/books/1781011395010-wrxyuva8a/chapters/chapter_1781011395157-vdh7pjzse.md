# 格式化C盘（物理）

<p>“59改，搞定了？”杨帝收起砖头问。</p><p>「外部通讯系统物理结构已摧毁。污染源扩散通道已切断。」</p><p>「但污染数据流核心样本……未能在物理层面彻底湮灭。」59改的电子音毫无波澜。</p><p>一颗拳头大小的“黑球”凭空出现。</p><p>五九改和杨帝同时看过去。</p><p>「不好。」59改冷静地说完这个词，抬手虚握。</p><p>那片尚未完全沉降的金属尘埃云中心，开始向内坍缩。</p><p>亿万计细微的金属粉尘如同被强磁吸引的铁屑，疯狂汇聚、挤压、熔融！</p><p>59改尝试以不计损耗的方式，强行毁灭那颗“黑球”！</p><p>然而，无法破坏。</p><p>那球，黑得深邃，像是宇宙深处坍缩的绝望实体，光线、感知，甚至空间本身都被它贪婪地吞噬、扭曲。</p><p>方圆百米内，空气变得粘稠如胶，光线黯淡如同沉入墨池。</p><p>无数肉眼不可见的、由纯粹“崩坏”与“高熵”凝结成的黑色触须，以非欧几里的诡异形态在虚空中盘桓、蠕动。</p><p>域外天魔！</p><p>在现实丰度坍塌的节点，在信息湮灭的核心位置，它终于挣脱了数据流的桎梏。</p><p>以最原始、最暴戾的姿态降临于世！</p><p>“啧，真不讲究。”杨帝撇撇嘴，主要是嫌弃天魔出场不够环保。</p><p>他右拳紧握，没有任何花哨的光芒，也没有引动天地灵气，仅仅是纯粹的、被压缩到极致的物理动能！</p><p>嗡！</p><p>空气被瞬间抽空又挤压爆鸣。</p><p>杨帝的身影在原地模糊了一下，下一刻，他的拳头已经裹挟着能轰碎山岳、轰碎行星、轰碎太阳、轰碎银河的力量。</p><p>“五九！开盾！！”</p><p>59改赶忙控制他的冯诺依曼自动机，组成一个倒立的圆锥状屏障护盾。</p><p>圆锥呈倒立形状，下尖上宽，其中杨帝就在尖角位置。</p><p>护盾隔绝内外一切能量流动与物质交互，将这片圆锥形空间，暂时从现实的时空中“隔绝”了出来！</p><p>杨帝正在蓄力。</p><p>他的力量如果泄露出哪怕亿分之一，都会将整个凡界王朝从地图上抹去。</p><p>……</p><p>一分钟前。</p><p>就在59改的元神瞬间抽离、回归现实，刚刚准备执行那惊天动地的物理毁灭的同时。</p><p>数据硬盘世界内，青丘白璃与阿巴正面对着失去干扰后更加汹涌的污染泥潮。</p><p>“没时间了！鱼头，随我出手！”青丘白璃清喝一声，银白色的瞳孔中爆发出前所未有的决绝光芒。</p><p>看到狐狸眼中闪烁的光，阿巴充满了决心。</p><p>她们精神意志短暂共鸣，同步率在极短时间内达到400%，此时如果让她们驾驶赤红风暴，二者能从南天门杀到凌霄宝殿。</p><p>“合！”</p><p>一人一鱼，元神共鸣！</p><p>刹那间，一道前所未有的、融合了极致切割与纯粹净化的“连携技”诞生了。</p><p>她们化作一红一绿，相互缠绕的光带，冲杀向受污染数据的源头。</p><p>华丽、壮烈、带着孤注一掷的决绝，颇有点凡人眼中“魔法少女”放大招对抗灭世邪恶的悲壮感。</p><p>轰隆——！！！！</p><p>魔法少女与黑色海啸正面相撞！</p><p>没有预想中摧枯拉朽的净化，也没有激烈的能量湮灭。</p><p>撞击的中心，时间仿佛凝滞了一瞬。</p><p>她们倾尽全力轰出的“连携技”，那闪耀着净化光芒的数据神龙，在撞入黑色海啸的瞬间……</p><p>构成黑泥的、那些无法解析的“阴伏流煞”，在她们攻击触及的刹那，其存在形式……发生了诡异的跃迁！！</p><p>它们不再是“数据流”，不再是依附于硬盘世界法则的“信息”。</p><p>它们仿佛挣脱了“载体”的束缚，从“信息”坍缩成了某种更原始的，恶意。</p><p>域外天魔。</p><p>“什、什么？！”</p><p>“如果毁掉了主机和硬盘，它反而脱离了某种束缚，迅速成长为……域外天魔？”</p><p>“靠北！必须去警告他们！不能物质层面破坏硬盘，否则就是在解开它的枷锁——”</p><p>“不要再格式化C盘了呀！！……”</p><p>嗡——嗡——嗡——</p><p>一股远比之前任何一次都要恐怖、都要根源的“解体”感，从这片虚拟空间升起。</p><p>文艺的说法：世界沉进虚无的深渊。</p><p>简单的说法：外面的人在格式化C盘！</p><p>承载她们元神的整个世界——君士叹顶堡的主机硬盘，正在从物质层面，被分解、湮灭。</p><p>是59改的纳米机器正在发力！</p><p>构成这个世界的“0”与“1”，被59改的冯诺依曼自动机风暴，从原子层面无情地抹除。</p><p>“呃啊！”</p><p>她们由元神之力构筑的虚拟躯体瞬间变得模糊、透明。</p><p>随即，两道代表着元神的光影如同被弹弓射出的石子，瞬间从这片正在飞速瓦解、被无尽黑暗和乱码吞噬的虚拟空间中被强行“弹”出去！</p><p>“拦不住域外天魔！还有铁罐头千万不要物理毁灭主机和硬盘……完，你已经这么干了。”</p><p>一个咋咋呼呼的声音响起，是阿巴。</p><p>她刚刚元神回归，现在才醒来。</p><p>她从躺尸状态弹起，鱼眼瞪得溜圆，指着黑球，“卧槽！这黑煤球成精？”</p><p>青丘白璃也垂死病中惊坐起。</p><p>她看向那黑球，一瞬间明白发生了什么。</p><p>土著狐狸绝望地说：“降临了，域外天魔还是降临了……”</p><p>“无所谓，我会打爆它。”杨帝说着，终于蓄力完毕，拳头指关节发出一连串爆响！</p><p>他猛地挥拳！</p><p>拳头如同一颗冲破天际的超级炮弹，沿着圆锥护盾向上笔直轰出。</p><p>轰——隆——隆！！</p><p>一声沉闷到令人心脏骤停的巨响炸开！</p><p>拳力沿着圆锥面呈螺旋状急剧扩展，空间如鼓面凹陷，环状冲击波以肉眼可见的速度扩散。</p><p>下方金属尘埃云被狂暴气流撕开巨大空洞，平台剧烈震颤，仿佛随时会崩塌。</p><p>然而，那深邃的黑球，只是……微微一滞。</p><p>仿佛一颗投入泥沼的石子，激起一圈涟漪。</p><p>足以粉碎星辰的纯粹物理动能，被黑球内部那无尽的“虚无”与“崩坏”悄然吞噬、瓦解。</p><p>连一丝裂痕都未曾留下。</p><p>那盘桓的黑色触须，如同贞子和伽椰子的发丝，甚至更加兴奋地舞动起来，发出令人灵魂战栗的无声尖啸。</p><p>域外天魔不能依靠物理方式消灭。</p><p>杨帝当然知道最好的解决方法——就是向它灌输灵能，使其现实丰度超过0，但远小于1。</p><p>当纯粹的“崩坏”核心处，被强行注入了一缕微弱却无比“真实”的“秩序”与“存在”。</p><p>就相当于往绝对零度的冰核里，滴入一滴滚烫的铁水。</p><p>核心结构出现短暂凝聚后，立即发生剧烈崩溃，使得域外天魔自行瓦解。</p><p>但杨帝发现了另一种新奇的力量。</p>
