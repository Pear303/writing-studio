# 单刷烂尾楼2

<p>正常人这个时候都会以为：哦妈耶！那是个不小心快要掉下去的人。</p><p>但杨帝看得清楚——那只手上全是污垢，而且皮肤青灰，像是陈年死人的手。</p><p>那手的指甲又长又黑，弯曲得如同鹰爪，死死抠住水泥护栏，仿佛在极力支撑着不让自己掉落。</p><p>但与其说是在支撑自己，不如说是在引诱其他人过来。</p><p>杨帝将手中装了坏酒的瓶子朝着那只手伸过去，故意在它面前晃了晃。</p><p>那只手仿佛受到了某种刺激。</p><p>它瞬间做出反应，以极快的速度抓住瓶子，朝着楼下用力扔去。</p><p>过了几秒，1楼地上，才传上来玻璃瓶破碎的声音。</p><p>“沉不住气。现在我要‘正当防卫’了。”</p><p>几乎在同一瞬间，杨帝握紧螺纹钢撬棍，如猎豹迅猛发力，将撬棍像标枪一样投掷！</p><p>只见撬棍带着凌厉的风声，直直地朝着那只手飞去！</p><p>“噗”的一声闷响，撬棍精准无误地将那只手死死钉在了混凝土护栏上。</p><p>那只手被钉住后，还在不停地抽搐着。</p><p>指甲在水泥护栏上划出刺耳的声音，仿佛在挣扎，要逃走！</p><p>杨帝走近撬棍，准备一睹这厮的风采。</p><p>但下一刻，那只手像是被一股强大的力量强行拖拽——伴随着令人牙酸的“嘎吱”声，手掌与撬棍接触的部位竟开始慢慢撕裂！</p><p>“断尾逃生？！”</p><p>“噗”一声，那只手的手掌整个从中间被撕裂开来，挣脱了钉在混凝土护栏上的螺纹钢撬棍。</p><p>手在半空中划过弧线，随后在重力作用下坠下去。</p><p>杨帝在阳台边缘探头。</p><p>无论是他想看到的“东西”，又或者是那只断手，都消失得无影无踪。</p><p>只留下转瞬即逝的青灰色残影，以及螺纹钢撬棍旁零星腐烂的碎肉、碎骨。</p><p>杨帝站起身，走到撬棍前，将其拔出来。</p><p>撬棍深深嵌进了混凝土矮墙，拔出来还费了一些劲儿。</p><p>他来烂尾楼的高层，可不是为了被人拉下去跳楼，又或者是解决什么怪物。</p><p>他是来找干燥木材的。</p><p>正如他所料，相比于底层的潮湿，高层要干燥许多，这也使得他能在几个高层房间里，顺利捡到一些干木板。</p><p>虽说这些木板大多破旧不堪，还带着腐朽的痕迹，但勉强也能当作今晚的柴火。</p><p>他抱着一堆干木板，慢悠悠地回到二楼，那个之前对他敞开大门的房间。</p><p>杨帝将木板放在一旁，摆弄起在角落剩下的几摞砖头。</p><p>“二楼这房间又湿又冷，睡一觉都容易得风湿、老寒腿，晚上还是生点火吧。”</p><p>他将砖头一块块码放整齐，在房间的角落，搭起了个简易的小壁炉。</p><p>小壁炉搭好，他搓捻手指擦出火星子，引燃干木板。</p><p>壁炉将整个房间映照得暖黄一片。</p><p>藏在角落的黑暗，夹缝中滋生的阴影，都被火光驱逐干净。</p><p>“噼里啪啦”的声响很是舒服，催眠白噪音。</p><p>杨帝惬意地靠在一旁，在篝火温暖的映照以及那“噼里啪啦”的声响陪伴下，不知不觉进入了梦乡。</p><p>……</p><p>如果，我是说如果，世上有一个大手腕的主办方，主办了一场比赛。</p><p>而这项比赛的名字，叫“卷王锦标赛”。</p><p>那么，杨帝将会是当之无愧的第一名。</p><p>因为，对于绝大部分普通人类而言，即使他再卷，也不可能将一天24小时用干净。</p><p>他们至少也得留出一些时间休息睡觉。</p><p>这是人类的基因和模因共同决定的。</p><p>这是非常一般的自然规律，所以一般来说，难以违抗。</p><p>据说某半岛上的人，已经将睡眠进化掉了，疯狂加班熬夜，但那只能算夸张的说法。</p><p>杨帝才是真正进化掉“睡眠”的那个人。</p><p>他在梦中读书，疯狂学习！</p><p>事情是这样的——在开始四处流浪前，杨帝几乎将整座图书馆、每个类型、每个细分种类的书，都挑出一两本，提前记忆在脑子里。</p><p>虽不至于像茵蒂克丝，达到十万八千本书的境界。</p><p>但一千零八十本还是有的。</p><p>涵盖了史地生政、物理化学、文学艺术、哲学宗教、烧火做饭、荒野求生……各个领域的知识。</p><p>对杨帝而言，文字图像“记住”很简单，耗时的是“理解”。</p><p>他先把它们记住，日后再慢慢学习。</p><p>于是这些知识，都如同繁星般点缀在脑海之中，随时供他调取，查阅。</p><p>若遇上不懂的事情，碰到知识盲区，他可以随时在脑海中“翻书”！</p><p>而精神力暴涨如海，也带来了第二项生活习性变化——</p><p>他可以“定制梦境”，并且在梦中清醒思考，梦后保留全部记忆。</p><p>10%潜意识上浮至思维表层，让他可以定向选择自己的“做梦内容”。</p><p>杨帝可以在自己的梦里当个创世神，像史蒂夫一样构建万物。</p><p>可以体验人生赢家的生活，装逼打脸扮猪吃虎龙王归来战神赘婿。</p><p>可以让自己性转，从另一个迥然不同的视角审视事件。</p><p>他可以在此满足自己一切欲望——只要这种欲望，是他的知识体系所能构建并理解的。</p><p>然后，杨帝把自己的梦，用来内卷了……</p><p>还是那句话：已识乾坤大，犹怜草木青。</p><p>目睹大恐怖，他在很长一段时间里都感觉，地球真是索然无味！</p><p>人的七情六欲，高尚者的宏大理想，文明的终极追求，都索然无味，淡如鸡肋。</p><p>还差一步陷入虚无主义的杨帝，像具游魂般游荡了一个月，才确立自己存在的意义：</p><p>向耶罗大仙复仇。</p><p>为了达成这一目标，他需要尽可能变强。</p><p>以蛮力武装体魄，以智慧武装灵魂。</p><p>杨帝养成了习惯——每晚八小时睡眠，大部分都用来读书，读书，再读书！</p><p>在梦中的“进化”，可以反馈到现实。</p><p>今晚也不例外，杨帝陷入梦境后，立刻置身于一座宏伟的知识殿堂之中。</p><p>其实就是一座图书馆。</p><p>他信步走到一排书架前，手指滑过书脊，挑选出一本关于刚体力学、材料学的专业书籍。</p><p>因为今天找到几块品相极佳的砖头，所以，学习一下牛顿力学和材料性质，才能更好地驾驭它们。</p><p>“砖头抛射轨迹……”</p><p>“普通伤害平面……暴击伤害撞角……”</p><p>然而，就在杨帝全身心投入学习时，一阵隐隐约约的嘈杂声，打破了梦境宁静。</p><p>起初，这声音如同微风拂过树叶般轻柔，几乎难以察觉。</p><p>但它逐渐变得清晰刺耳，如同警报蜂鸣器，不断冲击杨帝意识。</p><p>虽然伤害刮痧，但是很吵！</p><p>……</p><p>杨帝从梦境学习状态中醒过来，瞬间回到现实世界的烂尾楼房间。</p><p>此时，屋内弥漫着浓厚的烟雾，呛得人嗓子生疼，脑袋也有些昏沉。</p><p>他瞬间清醒过来，发现门窗不知何时竟被砖头紧紧封住，缝隙间连一丝光线都透不进来。</p><p>显然，室内一氧化碳中毒的情况已经相当严重。</p><p>杨帝站起身来，活动一下筋骨，握紧右拳，猛地朝着封住窗户的砖头轰去！</p><p>“轰轰——轰！！！”</p><p>砖头瞬间破碎飞溅，一股强劲的气流裹挟着新鲜空气猛地灌进屋内，将烟雾迅速驱散。</p>
