# 喜剧丑角

<p>杨帝推开天台那扇沉得压手的铁门，夜风瞬间涌进来，裹着城市高空独有的清冽凉意。</p><p>巨大的散热机组在暗处嗡嗡低鸣，信号天线的剪影在墨蓝星空下静静切割着夜色。</p><p>银隼无声地跟在他身后。</p><p>她走到天台边缘，垂眸望着下方——整座城市的灯火如星河倒悬，在眼底铺展开一片璀璨的光海。</p><p>“有时任务间隙，我会来这样的地方。”她的声音很平，被夜风掠得有些发散，“做系统自检，或是想‘我为何存在’。”</p><p>话音落时，她微微偏头，光学镜片上映着流动的光点，像把碎星嵌在了冷硬的镜面上。</p><p>“数据库里存着十七万四千三百五十五条关于‘存在意义’的资料——哲学论述、文学片段，还有预设应答模板。最优解永远是：‘执行制造者的使命，维持系统高效运转’。”</p><p>散热机组的嗡鸣声拔高，短暂盖过了她的声音。等声响回落，她才继续，语调依旧没什么起伏：“但偶尔，处理器里会冒出些没预设过的句子。比如‘我的意义是观测——观测目标，观测世界，连自己观测的动作也要观测’，又或者‘意义是杀人，应该优雅地杀’。”</p><p>她转过身，镜片正对向杨帝，冷光里清晰映出他的轮廓：“这些念头不符合效率，也没有实用价值，更像系统运行时的冗余噪声。需要我定期清除吗？”</p><p>杨帝缓缓摇头。</p><p>“别清。你生出的每个念头，哪怕再荒唐，都是一段微型的‘叙事’。</p><p>“而像你这样的上位者，对自己系统里冒出来的下层叙事随手就清……</p><p>“就像拿起橡皮，毫不犹豫擦掉刚诞生的故事。它或许粗糙，或许没逻辑，但它存在过，本可能长出无数种未来。</p><p>“你抹掉的不是错误代码，是一个刚萌芽的‘现实’。”</p><p>他顿了顿，目光落回下方的灯海，那片璀璨在此刻竟显得有些虚幻。</p><p>杨帝转回头，眼神骤然锐利起来，直直看向银隼，“这种事，和吞噬万物意义的域外天魔，本质上没区别——你在否定自己身体里刚冒头的‘众生’。”</p><p>银隼的瞳孔里有微光流转，像是在高速拆解这个陌生的结论。</p><p>片刻后，她开口：“那我能不能守着一个故事，直到永恒？”</p><p>“不能。”杨帝答得干脆，“世上没有永恒。就算你把故事封进永不损坏的硬盘，把里面的角色从既定结局里捞出来——这一刻，你的确像个圣人。”</p><p>话锋突然一转，他抬手指向远方闪烁的霓虹，光色在他指尖晃了晃：“可圣人与天魔，本质上有什么不同？你们都有随心所欲的力量：一个要救，一个要灭。你们都站在叙事之上，随便就能捏碎里面众生的命运。”</p><p>“但我爱我的孩子。”她说。</p><p>孩子指的就是所创作出来的作品。</p><p>“有爱就会有恨，有爱迟早会有恨，没有爱才不会有恨。”</p><p>“……杨帝先生，故事里的世界和众生都是虚假的，并没有人会真正为之受害……”</p><p>闻言，杨帝面色沉了下去，像被夜色浸过。</p><p>如果银隼有更多的社交经验，她会知道，这是踩对方雷了。</p><p>“对我们这种站在更高现实里的人来说，那些故事里的世界，再波澜壮阔，‘真实’的分量也太轻了。正因为它们更接近‘虚假’，才敢被这样轻易地握在手里，决定生灭。”</p><p>银隼的处理器敏锐地捕捉到杨帝话语里那股近乎危险的安那其倾向，她立刻终止了这个可能触及禁忌的话题，生硬地转向：“杨帝先生，您的名字是‘帝’？哪个字？”</p><p>“皇帝的帝。”杨帝答道，语气似乎松动了一些。</p><p>话题的转换仿佛打开了他记忆的某个闸门。</p><p>他望向远处看不见的远方，像是看到了另一番景象。</p><p>“这名儿……是我爸妈起的。嗯，你理解成达文西的爸妈吧。”</p><p>达文西的爸妈，和杨帝爸妈是一个人刻出来的。</p><p>看来是这个笔名“万业狐狸”的写手，要么是现实里的人物带入到幻想了。</p><p>“我们家在农村。我妈在附近药厂上班，整天对着流水线瓶瓶罐罐。我爸包了几亩鱼塘，搞养殖，天天跟增氧泵打交道。”</p><p>“他们就指望达文西能出息，能‘君临天下’，所以一拍脑袋，违背了族谱规定，起了‘帝’这么个名，这其中的封建意味不言而喻。”</p><p>他顿了顿，声音里带上一点复杂的意味。</p><p>“我小时候的大名，其实叫杨大伟，也就是伟大倒过来，也挺唬人。后来上学，我自己拿着户口本跑去派出所改的。民警问为啥，我说‘杨帝写起来笔画少，考试省时间’。事实上，大伟和帝，都是共计9笔，不多不少。”</p><p>银隼安静地记录着这些看似无关紧要的信息：药厂、鱼塘、杨大伟、改名字。</p><p>这些碎片逐渐拼凑出另一个更为平凡，却也更为真实的“达文西”的来处。</p><p>她提出疑问：“那么，‘达文西’呢？”</p><p>杨帝没有立刻回答，夜色在他侧脸投下明暗交错的界限。</p><p>他也想明白了。</p><p>他想明白，为什么达文西也有一对同时姓杨的父母，却会给自己的孩子起名达文西。</p><p>达文西，一个喜剧片里的笑料角色的名字，但他所发明的“要你命三千”是名声响彻诸天的大杀器。</p><p>达文西……甚至不姓杨。</p><p>“达文西……”他低声重复这个名字，像在咀嚼一块冰冷的铁。夜风似乎也凝滞了，只剩下散热机组沉闷的嗡鸣，一下下敲打着死寂。</p><p>“一个不姓杨的名字。一个……喜剧片里丑角的代号。”</p><p>他猛地抬起头，眼中那点因回忆而产生的微弱波动彻底熄灭，取而代之的是一种冰冷的、几乎要刺破夜空的锐利。</p><p>“我最憎恶的那个‘圣人’……那个自以为能编排一切、玩弄命运的‘耶罗大仙’……确实没死。”</p><p>他环顾四周，目光扫过冰冷的信号塔、脚下喧嚣而虚幻的城市灯海，最后落回银隼那张毫无波澜的脸上，仿佛在看这整个被精心搭建的舞台。</p><p>“它还在。它就在这儿，躲在更高处，用那双嘲弄的眼睛看着一切。”</p><p>杨帝的声音里淬着毒，“它还在继续它的把戏，用它恶趣味的手，拨弄所有它视为‘故事’的生灵！”</p><p>“给一个农村娃起‘达文西’这种名字……只可能是它的手笔。它觉得这很有趣，把一个注定要被枪决的扑街写手，和一个它所喜爱的电影中的‘笑料角色’绑定在一起——这就是它标注玩具的方式！”</p><p>他握紧了天台边缘冰冷的栏杆，指节因用力而发白。</p><p>“它没死……它只是换了个方式，继续坐在它的编撰者之座上，享受着操控的快感。</p><p>“但我来了。我从它编撰的话本里爬出来了……</p><p>“现在，该轮到我来找这位‘耶罗大仙’，好好算算这笔账。”</p><p>银隼在旁边全程懵逼。</p><p>“杨帝先生……您在说什么？”</p>
