# 哈基面

<p>这狸花猫是短尾品种，尾巴按某种韵律轻轻颤动。</p><p>瞳孔在黑暗中分裂成两枚细小的金芒。</p><p>它喉咙里发出咕噜声，比先前的鬼哭狼嚎低沉，仿佛砂纸摩擦生锈铁门的刺耳声响。</p><p>“吼……吼……呼噜……”</p><p>它慢慢走上楼梯，不急不缓，从容雅致。</p><p>但每一步都像踩在浸透水的棉絮上，松软得令人作呕。</p><p>那只狸花猫的脊椎正像波浪般起伏，皮毛下凸起无数游走的条状东西，就像往猫的皮肤下塞进几十条蛇。</p><p>然后……蛇破皮而出。</p><p>它原本是只——至少看起来是只普通的短尾狸花猫，而现在，那无数条蛇状的凸起挣破了皮毛的束缚，在空气中疯狂扭动着。</p><p>每一条，都泛着深邃的漆黑，漆黑中闪烁诡异光泽。</p><p>“这猫还特么是变形金刚！”胡彦卓大惊。</p><p>杨帝见势不妙，冲下去，将胡彦卓拦在身后：“胡哥，你去把那些桌椅清个通道出来，我来挡住这哈基面！”</p><p>“哈基面？”</p><p>“哈基米变成了拉面！”</p><p>用什么去挡？自然是手中利器，撬棍！</p><p>杨帝手执撬棍，模仿《英雄》中的姿势，缓缓步至哈基米身前。</p><p>这撬棍三尺六寸，湛若秋水，乃当年稷海理工施工队取螺纹神钢，地火淬炼，天雷附魔，静若卧波潜蛟，动似惊雷裂空！</p><p>“喝！”杨帝手臂抡圆了一棍子敲下去！</p><p>撬棍第一次砸中那团黑色物质，他便立刻确信——自己不是在对抗生物。</p><p>至少不是传统意义上的生物，不是人类目前用理性所规范出来的生物。</p><p>这团蠕动的拉面状物体，至少违反了他熟知的经典力学。</p><p>他看起来跟肉肠一样柔软，然而每次敲击，都像是砸在主战坦克正面装甲！</p><p>硬得令人发指！</p><p>杨帝有想过——它的性质会不会类似于非牛顿流体，或者是《沙丘》中的护盾场？</p><p>动量越大，反而越难击穿？</p><p>他尝试以比较轻、比较慢的速度捅过去。</p><p>然而，并没有什么卵用，仍然感觉像是戳在钢板上。</p><p>杨帝继续尝试了很多可能的方法。</p><p>最后确定——眼前这个并不是机制怪，而是纯粹的数值怪！</p><p>质量、硬度、防御力、生命值、疼痛耐受度惊人的数值怪！</p><p>“胡哥！桌椅扔准点！”杨帝侧身闪过飞来的课桌。</p><p>桌椅板凳砸到哈基面身上，仅仅是稍稍让它后退了半步。</p><p>“啪叽！”杨帝手里撬棍挥得要冒火，最后一次砸落在那东西身上时，擦出蓝色火花，撬棍也终于不堪重负地弯了。</p><p>“……”杨帝二话不说，将已经弯掉了的撬棍扔向哈基面。</p><p>那根弯掉的撬棍并没有太多动量，仅仅将哈基面击退了两三厘米，然后掉下了楼梯更深处。</p><p>杨帝接过胡彦卓的撬棍，继续抡圆了砸！</p><p>每次挥击，都会响起金铁交鸣的清越之声。</p><p>声音来自于手中撬棍的振动，而非那团哈基面本身，看起来毫发无伤。虽然它没毛发。</p><p>“这拉面一样的玩意，简直就是物理学中的概念‘刚体’，天知道是用什么材质做的！”</p><p>杨帝一边抱怨，一边用撬棍殴打哈基面。</p><p>尽管对方很硬，但似乎也要遵守动量守恒。</p><p>在他暴风骤雨般的“剑斩”之下，哈基面放缓了前进的脚步。</p><p>不过也仅仅是放缓了而已。</p><p>他的呼吸如同拉风箱般粗重，每一次挥击，都让肩关节发出不堪重负的脆响。</p><p>「剑+1」</p><p>但瞳孔在黑暗中愈发明亮，仿佛有金色的火焰，在眼底燃烧。</p><p>「剑+1+1」</p><p>哈基面的拉面状躯体上，开始出现细微的凹痕——那是撬棍留下的痕迹。</p><p>「剑+1+1+2」</p><p>尽管每道凹痕都会在眨眼间恢复，但杨帝分明感觉到手中的阻力在减弱。</p><p>「剑+1+1+2+3」</p><p>他肌肉以诡异的频率震颤，骨骼深处传来细密的刺痛，仿佛有无数钢针在骨髓里游走。</p><p>「剑+1+1+2+3+5」</p><p>杨帝身体发生肉眼可见的变化。</p><p>他脊椎骨一节节隆起，肌肉虬结如盘根错节的古木，皮肤下泛起淡淡光泽。</p><p>为了阻挡这团猫线球，他将自我肉身与精神逼到极限。</p><p>他的肌肉记忆不再依赖神经信号，而是直接由细胞层面的应激反应驱动。</p><p>他的小臂骨骼以肉眼可见的速度增粗，骨小梁重新排列成更具冲击力的力学结构，肌腱与韧带则在违背生物规律和极限的路上变强。</p><p>与琦玉的日常锻炼、自杀锻炼法的自我毁灭不同，杨帝每一次挥击，除了透支肉体，还是在压榨意志。</p><p>普通人在剧痛中崩溃时，杨帝的意识却在痛苦中淬炼得如刀锋般锐利。</p><p>杨帝称之为“极限-自杀锻炼法”。</p><p>“弱点击破，会心一击！！”</p><p>他大喝一声，“给我破！！”</p><p>全身细胞在这一刻集体沸腾，线粒体释放的能量将体温推升至极短暂的摄氏六十多度。</p><p>理论上来说，杨帝是恒温动物。</p><p>但如今，身体机能似乎被打破了极限。</p><p>撬棍尖端骤然收缩成尖锐的锥形，棍身缠绕着气浪，空气呼啸。</p><p>“砰砰轰！！”</p><p>短尾狸花猫异变后的哈基面，被杨帝这全力一击轰中，竟发出了一声尖锐刺耳的嘶鸣。</p><p>好似金属刮擦玻璃，令人牙酸欲呕。</p><p>那团拉面状的躯体剧烈颤抖起来，原本不断蠕动修复的凹痕，此刻竟无法迅速复原，一道道裂痕如蛛网般在表面蔓延。</p><p>哈基面发出类似玻璃碎裂的刺耳声响，裂纹出现，它陷入僵直！</p><p>趁着怪物被连续重击僵直的瞬间，胡彦卓猛地拽下缠在铁链上的消防水管，往外一拔。</p><p>像是往骆驼背上放了最后一根稻草，腐朽的桌椅，发出濒临崩溃的呻吟。</p><p>胡彦卓疾呼：“杨帝，走！”</p><p>杨帝没有丝毫犹豫，转身便朝着通道狂奔而去。</p><p>桌椅板凳并没有完全清开来，在这么短时间内，肯定是不可能的。</p><p>他只是清空了通往楼上的半条小甬道。</p><p>“这、这怎么上？”</p><p>“都叫你跟我学跑酷了……抓紧我手腕！”</p><p>杨帝反手扣住胡彦卓的手腕，借力跃上倾斜的课桌。</p><p>两人如猿猴般在桌椅残骸间腾挪，杨帝一脚踩碎摇晃的椅面，借着反震力跃上更高处。</p><p>胡彦卓跃上摇摇欲坠的书架，又反过来倾下身子，让杨帝借力而上。</p><p>下方传来哈基面躯体重新聚合的黏腻声响，黑色拉面状触手已刺破桌椅堆，卷起断裂的课桌腿激射而来。</p><p>它愤怒咆哮着，无数条蛇状触手疯狂舞动，朝着杨帝和胡彦卓追去。</p><p>触手如钢鞭，抽打在周围墙壁上，溅起一片片碎屑。</p><p>两人身后的桌椅堆轰然坍塌，哈基面的触手擦着杨帝的运动鞋鞋底扫过，在瓷砖地面留下蛛网般的裂痕。</p><p>杨帝和胡彦卓在桌椅山之间，找到狭窄的通道，向上逃窜，身后的哈基面如附骨之疽。</p><p>万幸，那些被锁链捆在一起的桌椅，仅仅堆了仅仅两三米的垂直跨度。</p><p>翻过最后一张桌子，楼梯过道很快变回空旷。</p><p>他们也不再需要手脚并用，不需像人猿泰山那样在桌椅之间跑酷了。</p><p>“我们安全了，暂时。”</p><p>不曾想，杨帝立了个flag。</p><p>胡彦卓迅速冲上前去捂住他嘴。但还是晚了一步。</p><p>flag已经无可避免地立下了，覆水难收，驷马难追。</p>
