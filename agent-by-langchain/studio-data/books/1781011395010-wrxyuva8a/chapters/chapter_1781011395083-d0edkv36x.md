# 你死我活的商战！

<p>距离末日火山主峰85公里。</p><p>……</p><p>瑞弗维尔确实是昨天太累了，在极度的紧张与担忧之后，不知不觉间睡死了过去。</p><p>直到日上竿头，阳光透过洞口斜斜地洒在他脸上，他才悠悠转醒。</p><p>瑞弗维尔揉了揉惺忪睡眼，坐起身来。</p><p>发现杨帝正坐在一旁，依旧在专注地思考着什么。</p><p>他回想起昨晚发生的种种。</p><p>他小心翼翼地问道：“杨帝朋友，你……感觉真的没事了吗？”</p><p>“哗啦——”杨帝一口气喷了半升血，然后“啊～”舒爽地伸了个懒腰。</p><p>他转过头，擦擦嘴角，脸上带着自信的笑容。</p><p>“没事了，你看我现在精神多好。”</p><p>二人也便继续上路，往东行进。</p><p>“货物没丢之前，你带的什么货？”杨帝漫不经心问。</p><p>瑞弗维尔喷了口茶。这事怎么总咬着不放。</p><p>幸好经过半天酝酿，他已经想好搪塞过去的话术了。</p><p>他解释：他从西土大邦“圣古琉斯”而来，去往东方取金，而“商品”是一种浸了龙血的苔藓被牛吃了然后取出牛肝脏和胆汁喂给史莱姆再将这种黏糊糊的魔物晒干研磨成粉制成的饮料冲剂。</p><p>“什么冲剂？”</p><p>瑞弗维尔又流畅地重复了一遍。</p><p>杨帝问几遍，瑞弗维尔便相应重复几遍。</p><p>虽然有点绕口，但他已经练习很久，所以都没有说错，过了这一关。</p><p>瑞弗维尔松了口气。</p><p>杨帝感慨：“这么复杂且诡谲的工艺流程，那这制作成本想必不低，你这一趟要是顺利，肯定能赚不少吧。”</p><p>“是啊，虽然成本高，但收益也相当可观。只可惜那些货物都随着隧道坍塌被埋了，真是损失惨重。”</p><p>杨帝还从这饮料制造工艺里，敏锐地捕捉到一个词。</p><p>“不过，‘龙血’？什么龙血？”他问。</p><p>杨帝的问法相当含糊，既像是不知道龙这种生物的存在，单纯对这个概念感到新奇。</p><p>又似乎知晓龙的存在，只是好奇究竟是哪条龙的血被用于制作这奇特的饮料冲剂。</p><p>犹豫了片刻，瑞弗维尔决定先按照杨帝“忘记龙的存在”来解释。</p><p>“其实这一万年来，世上都曾经只有一条龙。所以说到龙，都说的是它——”</p><p>“‘曾经’？”</p><p>“……没错，焚灭天空之龙，卡利斯托！以普遍理性而论，它已经死了，所以是‘曾经’。”</p><p>说到这个名字，瑞弗维尔抖了抖。</p><p>他又想起那清晰得要命的预言画面。</p><p>“焚灭天空之龙……它曾霸据天空。它身形庞大无比，双翼展开足有千米之长，周身覆盖着如黑曜石般坚硬且闪烁着幽光的鳞片，每一片都有一人多高。它喷出的火焰能瞬间将整座城镇化为灰烬，无数生命在它肆虐下消逝。它所过之处，天空被火焰染得通红，大地在它的咆哮声中震颤，熔岩化作冲天的喷泉……”</p><p>瑞弗维尔吐了口气，“后来圣骑士巴德干掉了它，它砸落在末日火山。”</p><p>杨帝：“就这么死了？那龙血呢？”</p><p>瑞弗维尔左右看了看，假装小心翼翼地凑近杨帝，压低声音：</p><p>“实不相瞒，我做饮料用的龙血，并非卡利斯托的血。卡利斯托何等强大，就算它死了，其血液周围必定凶险万分，岂是常人能够靠近获取的？我用的是一种大蜥蜴的血。”</p><p>大奸商！还是食品安全方面的大奸商！</p><p>杨帝有一点点恼。</p><p>他到现在的境遇，都源自那一口“拼优饭·赌上厨师生涯的青椒炒饭”！</p><p>但瑞弗维尔紧接着说：“不过，那些大蜥蜴身上也流淌着稀薄的龙之血脉，而我卖的饮料也比市场价便宜80%。”</p><p>原来还是有一丁点真材实料了。</p><p>而且这么便宜，还算良心。</p><p>瑞弗维尔借此话题继续说：“我透露一个秘密给你：其实我这次去东边，其实本来也计划要去一趟末日火山。”</p><p>杨帝微微挑眉：“末日火山？你不是说卡利斯托死在那里，周围危险重重吗？”</p><p>“我的第一个任务，是去东方取金。第二件事，则是躲避商业竞争对手！”</p><p>杨帝闻到八卦的味道。</p><p>“细说细说。”</p><p>瑞弗维尔装作无奈地叹口气，说道：“商场如战场啊，杨帝。我在生意场上树敌不少，这次不知走漏了什么风声，被几个商业对手盯上了。他们一路追杀，我实在没办法，才想着躲到末日火山这种绝地。最危险的地方，往往也是最安全的地方！”</p><p>他说完，擦了把额头上的冷汗。</p><p>这下如果有圣光教廷的追兵，那事情就好解释了——来追杀我的人，都是该死的商业对手！</p><p>“所以你在隧道遗失货物的那次，就是被商业对手追杀。”</p><p>杨帝说着，心中则在暗自思索。</p><p>如果他说的是真，那看来异世界风俗，和地球大相径庭。</p><p>在杨帝家乡，商战打法是给对方的发财树倒开水。</p><p>而在异世界，商人能真枪实弹干起来！</p><p>不过，他对瑞弗维尔所说的商业竞争并不太感兴趣，他更在意的是末日火山以及与龙相关的秘密。</p><p>那可是龙！</p><p>在地球的神州，龙性恋在亚文化圈子里并不小众。</p><p>杨帝在数十次刷爆终末之地后，也开始将末影龙想象成黑长直大姐姐，而对“龙”这一神秘而充满魅力的生物情有独钟起来。</p><p>异世界是西幻风格的，所以，“卡利斯托”大约也是西方龙。</p><p>杨帝想去瞻仰瞻仰了。</p><p>或许还能像小说主角那样，捡到八九件龙尸宝藏，闯过六七座龙族试炼秘境，继承龙裔血脉什么的。</p><p>能让自己尽可能变强就好了。</p><p>他会在这个世界待一段时间，直到自己很难再快速变强为止。</p><p>不知道，黑暗水体还能不能离开这个世界？</p><p>到时候再找离开的方法吧。</p><p>杨帝想起一件事，他决定现在就问。</p><p>“瑞弗维尔，你听说过‘耶罗大仙’，或者是‘黄衣王者’之类的存在吗？”</p><p>瑞弗维尔想了想，回忆了十几年的游侠经历、十几年的宫廷图书馆生涯。</p><p>“没有。”他耸耸肩，“我确信自己没在任何一个地方听说过这个人。”</p><p>……</p><p>“噗。”杨帝一边喷血，一边喝水。</p><p>瑞弗维尔对此已经麻木——这个失忆传奇近战法师，平均半小时吐一次血，偶尔还会咳出可疑的暗红色碎块。</p><p>杨帝只是一味告诉他“没大碍没大碍”。</p><p>他不知道的是，杨帝一直在自己身上运行只适合兔子、不适合人类的「兔子型速度」附魔，引发全身器官大出血。</p><p>以此锻炼脏器的坚韧程度。</p><p>“环境有些诡异，我感觉到噗，此地的灵能，噗愈发混乱了，噗。”杨帝说。</p><p>瑞弗维尔点点头，一边观察四周。</p><p>原本湛蓝的天空被一层淡淡雾气所笼罩，阳光透过雾洒下，变得朦胧而暗淡。</p><p>路边树木也越发高大茂密，枝叶相互交织，几乎遮住整个天空。</p><p>地面上形成一片片阴暗的区域。</p><p>瑞弗维尔说的不错，越是接近末日火山，灵能环境越是混乱。</p><p>在这种灵能混乱的环境里，天然会滋生大量魔物。</p><p>在遭遇“商业竞争对手派来的刺客”前，他们先遭遇了各种千奇百怪的魔物。</p><p>比如，现在有一只绿色怪物，出现在他们前方不远处。</p><p>它没有脚步声，就那样静静地站在阴暗的角落里，身体微微颤抖，发出轻微咝咝声。</p><p>它那青灰色的身体与周围阴暗的环境融为一体，若不仔细看，很难发现它的存在。</p><p>在瑞弗维尔掏出小刀前，杨帝拦住他，执起撬棍与板砖。</p><p>“我来。”打怪刷级开始了。</p>
