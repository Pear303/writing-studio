# 白杨大帝，有丝分裂

<p>他硬生生从自己体内，撕扯下了一部分！</p><p>这过程带来的痛苦，远非肉体之痛可比。</p><p>那是生命本源缺损，是存在根基动摇。</p><p>杨帝只是闷哼一声。</p><p>被他撕扯下来的那团物质，在虚空中剧烈蠕动、变形。</p><p>基因螺旋光链疯狂编织重组，灵魂之火剧烈燃烧塑形。</p><p>阿巴在一旁看得心惊肉跳，她能清晰感知到杨帝的气息瞬间跌落了一截！这代价太大了……</p><p>呃，老大的气息跌落一截后，又上升了两截。</p><p>光芒渐敛，一个身影在杨帝面前凝聚成形。</p><p>那是一个身着朴素白衣的男子，面容与杨帝有七八分相似，却少了几分狂野不羁的凶戾，多了几分沉静如渊的威严。</p><p>他的眼神深邃，仿佛蕴含诸天运转的至理。</p><p>他周身散发着纯粹而稳固的圣人气息！</p><p>这气息与阿巴曾经的“蓝星永续之壁”不同，它更加内敛，核心意志只有一个——禁绝！</p><p>禁绝此界仙界再出圣人！</p><p>禁绝上界之人干涉此界！</p><p>阿巴能很明显感知到，如果自己再次尝试登临“圣人”果位，定会遭到对方提前截胡。</p><p>“去吧，白杨大帝。”</p><p>杨帝的声音有些肾虚，却无比坚定，“守好这里。你就是此界的‘白杨’。”</p><p>那「白杨大帝」微微颔首，没有任何多余言语。</p><p>克隆体继承了原体100%的记忆与决心，他们之间就是最好的基友或妻子。</p><p>“仙界白杨”一步踏出，身影瞬间融入仙界那浩瀚磅礴的法则洪流之中，如同水滴汇入大海，却又如同定海神针，悄然锚定。</p><p>——成为仙界法则网络中的一个核心节点，一个活着的、专司“禁绝”的规则本身。</p><p>他的存在，本身就是一道无形的界碑，宣告着此界圣位的终结与外力的禁区。</p><p>法则洪流之中。</p><p>仙界白杨的目光穿透了仙界的壁垒，投向下方那法则精度更低的灵界。那并非孤例，仅仅是他此刻视角所及的一个典型。</p><p>他的意识在浩瀚的法则网络中延展，一个更宏大的图景在他“眼前”铺开。</p><p>仙界，不止一个“灵界”。</p><p>何谓“灵界”？</p><p>一个承载意识、情感、“沙子”轨迹的信息结构——的沙盘。</p><p>一粒「沙」，就是一种可能性。</p><p>而这「沙盘」，形式之广，数量之巨，远超想象。</p><p>他“看”到了：</p><p>某个古老文明以纯粹的光子晶格构建的庞大“世界服务器”，其中运行无数模拟生态与文明，有的懵懂初开，有的已演化至星际时代，生灵在其中生老病死，悲欢离合，浑然不觉自身乃数据之流。</p><p>此为沙盘。</p><p>一位凡间作家笔耕不辍，呕心沥血构筑的故事，其意念竟在宇宙的信息底层激荡起微澜，一个依托于叙事逻辑，由读者集体潜意识共同维系的“书中世界”悄然凝聚。书中主角的每一次抉择，都牵动着真实的“命运”涟漪。</p><p>此亦为沙盘</p><p>一段被反复传颂的古老神话，其蕴含的象征与情感力量，在信仰与口耳相传中，于冥冥之中沉淀结晶，形成一个光怪陆离的传说。</p><p>此亦为沙盘</p><p>凡有完整叙事框架，有意识活动，有稳定运行法则的信息集合体——无论其依托于精密的量子计算机、泛黄的羊皮纸卷、口口相传的歌谣，抑或是某个生灵的梦境，当其复杂度达到临界，便有可能坍缩为一个“灵界”。</p><p>宇宙何其广袤？文明何其繁多？智慧生命的创造力何其澎湃？</p><p>凡有智慧处，便有故事诞生；凡有故事处，便有构筑世界的冲动。</p><p>无穷的智慧火花，在无尽的时空长河中，点燃了难以计数的下层世界。</p><p>仙界白杨没有任何犹豫，遵循着杨帝本尊烙印在核心的终极指令，以及“延续使命”的深刻本能，缓缓抬起了自己的手。</p><p>如同杨帝本尊的动作再现，克隆体五指成爪，并非抓向虚空，而是同样抓向自己的胸膛！</p><p>“嗡——！”</p><p>一种同宗同源的撕裂感传来。</p><p>他有丝分裂出了额外数百个“白杨大帝”。</p><p>只不过这些二次分裂体，修为都只有真仙级别。</p><p>但当他们驻扎到精度更粗糙，灵能浓度更稀薄的下层世界——灵界时，他们便都有相对于灵界而言、圣人级别的修为。</p><p>这几百个“仙界真仙”、“灵界圣人”级别的白杨大帝二次克隆体，只是“仙界圣人”杨帝一次克隆体的“第一批货”。</p><p>往后，“仙界圣人”杨帝会持续进行有丝分裂。</p><p>直至他的分身，驻扎满全部“灵界”！</p><p>“老大，为啥你生一个这么艰难；而别人一窝产几百个崽，看起来挺轻松写意呢？”</p><p>“傻鱼，我这是‘圣人分娩出一个圣人’，而他是‘圣人产崽出一窝真仙’。”</p><p>他只需要“量”去填满那些低精度的沙盘，保证每个沙盘里都有个能摁死新圣、挡住上界爪子的“钉子”就够了。</p><p>这叫资源优化配置。</p><p>白杨大帝，他们皆由初代「杨帝」自行分裂次生克隆体而来，力量逐层衰减。</p><p>却都因世界法则精度差异，在各自世界稳稳占据“圣人”生态位。</p><p>他们共享同一个核心意志——禁绝本世界再出圣人，禁绝上界干涉下界。</p><p>他们构成了一条自上而下、自我复制、自我维持的“禁绝”链条。</p><p>阿巴回忆起杨帝撕裂自己的血肉与精神的手法。</p><p>她总觉得，这手法有些眼熟，有些熟悉，貌似在哪见过。</p><p>“傻鱼，你就是我第一个‘钉子’。”</p><p>“啊？”</p><p>“严格来说，你就是我的第一个‘原体’，我的第一个‘钉子’原型机！拿你练手，顺便研究怎么高效地‘分裂’出能继承力量的个体。”</p><p>不过，杨帝原本所设想的“阿巴历史使命”，并不是那么简单。</p><p>原本，他打算通过自己的基因原体，搞清楚这身“无限进化”“超量代偿”的根源在哪。</p><p>但最终，杨帝拿阿巴当实验品搞的研究失败了，没完全搞清根源。</p><p>副产品却收获巨大！</p><p>杨帝学会了怎么用自己的灵、神、肉当材料，捏出更优质的“原体分身”。</p><p>他看向远处，还在不断分裂“子钉”的仙界白杨。</p><p>“我发现，继承的‘料’越多，捏出的‘钉子’进化潜力和适应能力就越强。就像你，继承得多，还没满月就打破了基因锁，还玩出个深海鲈鱼拟态。仙界白杨继承得更多，所以一出生就是能钉死仙界的‘圣钉’！”</p><p>阿巴沉默了，鱼尾无意识地拍打着虚空。</p><p>原来自己这个“鱼仔”，从一开始就是老大宏大计划里的一块关键拼图，一个成功的实验品。</p><p>这份认知让她心底涌起难以言喻的感觉，混杂着被利用的酸涩和成为“原型”的奇异自豪。</p><p>杨帝一把捞起发呆的阿巴，巨大的手掌拍了拍她的鱼背，发出沉闷的响声。</p><p>“走了，鱼仔！鳕鱼堡！吃饱喝足——”</p><p>他眼中燃烧着比星河更璀璨的战意，投向耶罗大仙可能存在的任何维度，“然后，就该去找那位最上层的编剧，好好聊聊她的‘爱与正义’，还有那该死的谜语。”</p>
