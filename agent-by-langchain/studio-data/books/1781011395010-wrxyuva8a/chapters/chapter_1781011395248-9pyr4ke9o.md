# 宇宙基底改造试点：视察

<p>视察按预定路线进行，原本按照计划，应该一路正常。</p><p>但当检查团途经示范街与未改造区域的交界缓冲带时，意外还是发生了。</p><p>该区域灵异能量浓度骤然异常飙升，引发大规模现实扰动。</p><p>多名伪装成居民的高阶工作人员立即反应，体内电流全力推动，磁场全力转动，试图镇压突然实体化的怨灵集群。</p><p>压制过程引发能量激荡，部分区域的遮蔽结界过载失效。</p><p>几道尤为浓郁的鬼影趁机挣脱束缚，扭曲着试图穿透临时屏障，其形态在探照灯强光下已隐约可见。</p><p>正处在即将进入检查团视野的边缘……</p><p>要被看见了！</p><p>一眉大帝表面恭敬，暗地里小动作不断。</p><p>他背地里通过眼神急令手下：“快！把示范街所有‘探照灯’开到最亮！绝不能让督查看见街区外面的重重鬼影！”</p><p>竭力将这弹丸之地伪装成已被“高武”伟光正彻底净化，一切邪祟无所遁形的样子。</p><p>当然探照灯也不是普通探照灯，那是数千挺快子光矛阵列，单发输出能量功率1.14×10^27瓦特，光矛初速120c，这些都是幽荧界总工程部标准配置，用于净化高危灵异环境的便携式战略武器系统。</p><p>其发射的快子流能极高效地瓦解非实体结构的灵能聚合体，对鬼魂类异常存在杀伤力显著。</p><p>当然，对碳基生物体、乃至宇宙天体的毁灭性效果同样出众。</p><p>刹那间，数千道肉眼无法完全捕捉的高速粒子流如同灼热的审判之雨，精准覆盖了鬼影躁动的区域。</p><p>那些扭曲的瘦长阴影，在接触到快子流的瞬间，便如同暴露在烈日下的冰霜。</p><p>死的死，伤的伤，逃的逃。</p><p>饱和式轰炸持续了数秒，交界缓冲带被耀眼的光芒彻底清洗了一遍，所有灵异迹象被暴力抹除。</p><p>虽然杨帝二人确实看不到鬼影了，但特么的这么大动静，当他们是耳聋听不到？</p><p>“怎么回事？什么动静？”</p><p>一眉大帝心头一紧，没料到对方灵觉如此敏锐。</p><p>他面上立刻堆起无奈又习以为常的笑容，连忙解释：</p><p>“二位专员见谅！本地这些灵异现象，诸如咒怨、鬼魂之流，偶尔会吸收点至高天的能量产生恶性膨胀，规模能达到天文级别。对付这种体量的‘巨祟’，动静难免会大一些……实属常规操作，常规操作！”</p><p>说完，他眼皮急跳，向身旁副手飞速递去一个凌厉眼神——</p><p>立即启动预案乙！</p><p>片刻过后。</p><p>一眉大帝面色凝重地掏出那个砖头状的通讯器，装模作样地贴近耳朵听了片刻，随即脸上露出恰到好处的惊喜。</p><p>“巧了！真是太巧了！”</p><p>他夸张地一拍大腿，“刚接到汇报，距此四千二百光年外，曾经爆发过大规模恶性灵异事件的‘格索尔七号’行星，正在举行驱魔仪式！机会难得，正好请二位领导移步，亲眼观摩一下我界武德充沛的基层民众是如何高效处理此类事件的！”</p><p>不等太一矩枢和杨帝回应，他便热情地在前引路。</p><p>嘴里开始喋喋不休地介绍，语速快得像是在背诵工作报告：</p><p>“得益于盟约的指导和我们不懈的努力，本宇宙的基层治理体系建设已卓有成效！我们建立了全覆盖、无死角的灵异事件快速响应机制！</p><p>“无论是偏远星系的凶宅鬼屋，还是人口稠密区的咒怨污染，只要监测网络发出警报，我们的‘民防施工队’——也就是经过严格培训、掌握高武力量的本地居民——就能第一时间通过短途传送阵抵达现场！</p><p>“通常采用‘物理超度’与‘强行拆迁’相结合的方式，高效、彻底地根除灵异隐患！</p><p>“真正做到小事不出恒星，大事不出银河，冤魂厉鬼全部就地镇压！</p><p>“我们坚持的理念是，没有什么怨气是一发‘阳电子破邪炮’解决不了的，如果有，那就两发！彻底将危险扼杀在摇篮里。”</p><p>瞬移光芒散去，三人已置身于一片荒芜行星的轨道上空。</p><p>下方星球地表笼罩着一层不祥的灰霾。</p><p>“就是这里了！‘格索尔七号’，刚接到消息，近期诞生了一道极凶咒怨，污染性极强。”</p><p>一眉大帝语气沉痛，“听闻有几个修为不济的旅友，仅是进入大气层烤了几顿肉串，便遭诅咒反噬，连夜暴毙，甚至牵连母星血脉断绝，惨遭绝户！”</p><p>杨帝目光扫过下方星球。</p><p>注意到环绕行星的轨道上，悬浮着数颗早已锈蚀、能量耗尽的古代卫星，其样式陈旧，看来这个行星的文明已经灭绝。</p><p>他随意地开口：“这咒怨，有些年头了？”</p><p>一眉大帝叹气：“我们几十年前，因为几颗毫不相干行星上接连发生暴毙事件，最终才锁定了这颗行星，行星上的文明早在不知多久前的岁月便已灭绝。之后几十年，这颗行星一直被封锁。”</p><p>“封锁这么久，直到今天才舍得驱魔？”</p><p>一眉大帝继续叹气：“这就是问题所在，我们的财政实在是亏空……”</p><p>此刻便是事情的转折点。</p><p>踏入幽荧界宇宙后2小时45分钟，本地的管理者第一次提到财政问题。</p><p>「从踏入此宇宙开始，第一次提及关键词，小于平均时间4小时，看来此宇宙的财政状况确实非常紧急。」</p><p>太一矩枢如是说。</p><p>“你们这么评判该不该增加财政拨款，不会被这些比狐狸还奸诈的圣人摸到套路，下次刚进宇宙就哭爹喊娘，痛诉财政不够？”</p><p>「无所谓的。我们只是评判财政状况，无论本宇宙财政情况如何，我们都不会增加。」</p><p>“那……那你把他们财政状况记在本子上干什么？”</p><p>「人皆知有用之用，而莫知无用之用。」</p><p>到头来还是没说明白到底有什么用。</p><p>一眉大帝仍然在夸夸其谈。</p><p>正说到“一旦居委财政充足，立刻派遣重型镇压单位彻底解决”，话音未落，远处虚空骤然被撕裂。</p><p>一台庞然大物轰鸣着驶出跃迁窗口。</p><p>那根本不是什么挖掘机。分明是一具人形决战兵器！</p><p>其高度堪比大陆板块，装甲上布满狰狞的撞角和炮口，粗壮的机械臂末端并非挖斗，而是足以捏碎小行星的巨型动力爪，肩部搭载的双联装巨炮散发着令敌人眼神清澈的能量波动。</p><p>当然，对于已识乾坤大的杨帝而言，这座机兵平平无奇，能否镇压一个银河系都难说。</p><p>“挖掘机”冰冷的传感器独眼扫过荒芜的行星，锁定了那股盘踞的咒怨。</p><p>它迈开巨足，震得虚空嗡嗡作响，径直朝着格索尔七号行星地表那怨气最浓稠的核心区域降下。</p><p>“嗯，你们就靠这个驱魔对吧。”</p><p>“考察员阁下好眼光。”</p><p>据一眉大帝描述，有居民发现辖区内存在一栋被传为“鬼屋”的建筑，在向居委会反馈后，基层部门连夜派出挖掘机，将该建筑从地基开始彻底拆除。</p>
