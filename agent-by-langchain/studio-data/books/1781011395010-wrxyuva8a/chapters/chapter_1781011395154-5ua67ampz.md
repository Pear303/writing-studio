# 主控大厅

<p>攻壳机动队指挥官——那位肩部装备着微型导弹发射器的女性队长——反应极快。</p><p>她头盔下的蓝色目镜瞬间锁定目标，没有丝毫犹豫，厉声下令：“控制住那四个穿黑袍的！立刻！”</p><p>居然穿这么多衣服！一看就很可疑。</p><p>“是！”</p><p>离得最近的两名攻壳队员外骨骼装甲发出嗡鸣，瞬间启动，以惊人的速度向角落扑去。</p><p>然而，就在他们即将触及黑袍人的前一刹那——</p><p>四个身影仿佛被无形的橡皮擦抹过，毫无征兆地、极其诡异地消失在原地！</p><p>不是高速移动留下的残影，不是障眼法，就是纯粹、突兀的消失。</p><p>仿佛他们从未存在过那个角落。</p><p>两名扑空的攻壳队员硬生生刹住脚步。</p><p>他们环视四周，扫描设备功率开到最大，却只捕捉到一片混乱的能量残余和惊慌失措的人群热信号。</p><p>“报告！目标消失了！重复，目标消失！”队员的声音带着一丝不易察觉的惊骇，在通讯频道响起。</p><p>几乎同一时间。</p><p>店外不远处一条狭窄、堆满废弃包装箱的阴暗小巷深处，空间如同水波般荡漾了一下。</p><p>四个穿着同样款式兜帽黑袍的身影凭空浮现。</p><p>巷口，恰好有一名负责外围警戒的攻壳队员，发现了这突兀出现的四人组。</p><p>他立刻举枪瞄准，厉喝道：“站住！什么人？！”</p><p>四个黑袍人缓缓转过身。</p><p>其中一个黑袍人用一种毫无起伏、如同电子合成的平板腔调开口，声音不大，却清晰地传到了警戒队员的耳中：</p><p>「我们是来自半人马座的摄影爱好者。只是路过，记录凡间烟火气。」</p><p>话音落下的瞬间，不等那名队员做出任何反应，四个黑袍人的身影再次如同信号不良的投影般，剧烈闪烁几下，随即彻底消散在空气中。</p><p>只留下巷子里弥漫的垃圾酸腐味和警戒队员一脸茫然、举着枪僵在原地的身影。</p><p>“半……半人马座？摄影爱好者？”</p><p>“国家果然有异能者组织……”</p><p>“我猜这组织叫‘龙组’。”</p><p>肯打鸡店内。</p><p>攻壳机动队的扫描设备，对店内外进行地毯式搜索。</p><p>却再也找不到那四个黑袍人的任何踪迹，仿佛他们真的只是“路过”的幻影。</p><p>混乱的疏散还在继续。</p><p>惊魂未定的顾客和店员被武装士兵引导着，跌跌撞撞地涌向店外。</p><p>其中包括四位坐在角落的老人。他们原本各自点了一份吮指原味鸡，俩人要的可乐，另外俩人要的豆浆。</p><p>疏散的时候，四位老人在攻壳机动队引导下安静离开。他们身穿羽绒服，看起来是地摊货，但在君士叹顶堡的冬季里，也还算够用。</p><p>老人家上了年纪，比较传统，不接受透明的纳米材质透明保暖衣，更喜欢这种羽绒服。</p><p>“奇怪……”</p><p>“队长，怎么了？”</p><p>“我怎么好像记得，这四位老者，之前穿的应该是带兜帽的黑袍？”</p><p>“带兜帽的黑袍？那该多显眼呐。”</p><p>“也是，应该是我记错了。”</p><p>案发当时，肯打鸡店内的摄像头，都被冰淇淋机给糊上了糖霜。</p><p>他们就算调取了监控，也啥都看不到。</p><p>反正事情解决了，何必纠结四个普普通通的老头儿、之前穿的究竟是什么衣服。</p><p>……</p><p>来自半人马座的摄影爱好者，总共四人，停在君士叹顶堡城市智能公共设施主控大厅门前。</p><p>“老大，为啥我们还是选择了出手干预。”</p><p>“傻鱼，因为挨上‘域外天魔’这档子事，就不再是凡界自己的内政了。”</p><p>其中一人褪下黑袍，露出清秀的少女面庞，“我，青丘白璃，幼年曾坚信天生万物以养人，域外天魔和魔道修士必须杀杀杀杀杀……”</p><p>“那现在呢？”</p><p>“现在？我还是认为天生万物以养人……但域外天魔并非‘天’所生，所以还是得杀杀杀杀杀……这就是对天地所生的世人，最大的‘爱与正义’。”</p><p>以杀作为爱吗，有点意思。</p><p>主控大厅门前，流光溢彩的力场屏障无声运转，扫描探针如同警惕的眼瞳，扫视着每一个试图靠近的生命体和非授权机械。</p><p>高精度监控阵列覆盖了每一寸空间，足以让任何未经许可的闯入者无所遁形。</p><p>然而，对于“59改”来说，这些足以让惊天魔盗团都头疼的安保措施，形同虚设。</p><p>他作为守望者文明的浓缩结晶造物，本身就是个超大号御坂妹，对本身由电气操控的机械，有着天然的绝对统治权。</p><p>59改甚至没有启动任何复杂的电子干扰或光学迷彩——那太高级了，不符合他朴素的定位。</p><p>他推着一辆同样平平无奇的清洁推车（不知何时从哪个角落顺来的），车上堆着几个半透明的垃圾袋和一些清洁工具。</p><p>一人一鱼一狐跟在身后。</p><p>他们径直走向主入口的识别区。</p><p>“身份识别：未授权访问。清洁服务机器人型号：……错误，型号数据库无匹配。申请驳回。”冰冷的电子合成音响起。</p><p>阿巴正要狠狠嘲笑铁罐头。</p><p>59改伸进推车上的一个垃圾袋里，摸索了几下，掏出一张皱巴巴、沾着可疑油渍的纸质小票——似乎是附近某家超市的购物凭证。</p><p>他用扫描头认真地看了看小票，然后郑重其事地贴在了身份识别器的感应区上。</p><p>“滴……滋啦……”</p><p>识别器发出一阵紊乱的电流杂音，屏幕闪烁几下，显示出一个绿色的通行箭头。</p><p>“清洁服务，授权通过。请保持路径清洁。”系统的声音带上人性化的困惑。</p><p>力场屏障悄无声息地打开一个仅供推车通过的缺口。</p><p>四人一路畅通无阻，进入主控室。</p><p>主控大厅内部，景象壮观且混乱。</p><p>巨大的全息星图在穹顶缓缓旋转，无数光带和数据流在透明的操作界面上奔腾流淌，代表着城市每一个神经末梢的运行状态。</p><p>然而此刻，空气中弥漫着紧张与恐慌。</p><p>刺耳的警报虽已解除，但红色的警示灯仍在角落无声闪烁。</p><p>工作人员面色苍白，许多人围在控制台前。</p><p>他们对着屏幕上大片大片的乱码和错误报告焦头烂额，争论声、指令声、系统报错声混杂在一起。</p><p>十分钟前，雷达侦测到“肯打鸡快餐店发射了一枚导弹”，主控大厅被击中。</p><p>凡界王朝已经很久没出现过战争了，突然被射了个导弹，普通人也不知道该怎么应对。</p><p>虽然事后，在现场的攻壳机动队表明那并不是导弹。</p><p>但是，用扫地机器人和微波炉，将一个金属圆球发射至10马赫初速——特么谁信？！</p><p>大厅中央，地板上。</p><p>一个拳头大小、边缘因高速撞击而微微发红变形的孔洞，清晰可见。</p><p>至于金属圆球，则深深地嵌入了石灰天花板之中，只露出半个球体。</p><p>它的表面那些不规则凸起，此刻正以某种诡异的节奏，极其微弱地明灭着，散发出之前青丘白璃感知到的那股隐晦而恶意的灵能波动。</p><p>几名穿白大褂的技术人员正拿着各种仪器，紧张又不敢靠近地围着它扫描，脸上写满“无从下手”的绝望。</p><p>59改的电子眼亮度陡增，数据流滚动。</p><p>「分析中……目标结构解析……外壳：普通高密度合金，具备初级相位转移抗性及能量吸收特性。内部核心：多层加密隔离仓。数据存储单元状态：已清空。重复：核心数据存储单元已清空。」</p><p>“空？”</p>
