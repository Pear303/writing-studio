# 怪谈领域

<p>“可恶，果然出生比努力更重要吗！”杨帝刚刚恢复部分记忆，他如是吐槽。</p><p>自己身上的灵能……总之并没有衰减，但是在此界仅仅相当于，嗯，“真仙境”水准。</p><p>（炼气，筑基，金丹，元婴，化神）</p><p>（炼虚，合道，渡劫，逍遥，真仙）</p><p>（仙帝，神皇，至尊，准圣，圣人）</p><p>如果说，他的灵界是「圣人」级别，此刻就相当于倒退12345……倒退整整5个境界！</p><p>下界再强大的人，到了上界，还是得乖乖从挖矿打工开始。</p><p>这是何等强烈的既视感，这根本特么就是爬塔升级！！</p><p>逍遥境，又被称作散仙。</p><p>散仙，顾名思义，比真仙“散”一点，而且没那么“真”，实力更弱小。</p><p>不知道在这“仙界”能不能横着走。</p><p>“这世界有点意思，诡异入侵，怪谈领域……还有我这副身体，染色体和我曾经的肉身完全不一样啊！</p><p>“物质决定意识，我的肉身已经不是原来那副，连带我的元神也会发生异变……</p><p>“可是我能感觉到，那股支配着我的能力，那股‘禁绝自我发生变化’的特性，仍然附在我身上。”</p><p>杨帝使出一记九阴白骨爪，捅穿自己胸膛。</p><p>胸膛上，狰狞的破洞在灵能催动下，正以肉眼可见的速度蠕动合拢，新鲜血肉飞速再生，覆盖了森然白骨。</p><p>一丝难以言喻的舒畅感，如同细小的电流，沿着愈合的神经末梢窜遍全身——「综合抗性+1」。</p><p>杨帝低头，指尖拂过胸前完好如初的皮肤，只留下一抹刺目的暗红血迹。</p><p>“是的……这种进化适应的特性，不依附于我的血肉或灵魂，而是依附于我对‘自我’的认知。”</p><p>杨帝心念一动，回忆起他在梦中所吸收的，阿巴的经验和感悟。</p><p>末那识，即是对“我”的执取与生成。</p><p>“若‘我’的边界，仅由‘我’来划定呢？”一个念头如闪电劈开混沌。</p><p>杨帝当即行动起来，神念高度凝聚，如同无形的刻刀，狠狠斩向那根深蒂固的“自我”樊篱！</p><p>不只是骨骼，不只是那缥缈的精神……</p><p>一种更深邃、更本质的认知被强行撬动、重塑。</p><p>他“看”到了自己，一个更广大的“自己”。</p><p>那件沾染着他鲜血、包裹着他躯体的蓝白色校服，这一刻，被他那霸道而偏执的意志，蛮横地拖进了“自我”认知的范畴之内。</p><p>“衣服，亦是我！”</p><p>念头落定，再无半分犹疑。</p><p>杨帝在使出一记“一阳指”，手臂如电光般挥下，指尖划过胸前那片血污斑驳的衣料。</p><p>“嗤啦——”刺耳的裂帛声响起。</p><p>纯棉材质应声裂开一道数寸长的口子，边缘的纤维倔强地卷曲着。</p><p>几乎在布帛撕裂瞬间，一股熟悉的、略比方才捅穿胸膛时微弱，却绝对真实存在的“暖流”，涌遍杨帝全身。</p><p>「综合抗性+1」</p><p>数值微小，意义却重逾千钧！</p><p>杨帝的嘴角，无法抑制地向上勾起。</p><p>“中！”</p><p>他看向走廊外头的圆心广场。</p><p>杨帝的脖子出现一道血痕。</p><p>……</p><p>“……这学校我记得没那么潮流啊……”</p><p>“布豪！都是假象！是此界的特殊灾难——诡异降临！！”</p><p>“嘘，听广播。”高三0班内，班主任已经醒来，将手指抵在嘴唇上，示意众人不要说话。</p><p>广播很快放完Pandora乐队的最新专辑。</p><p>“叮铃铃铃铃——”</p><p>刺耳的上课铃声再次响起。</p><p>然而，这一次的铃声旋律并未停止在单调的循环上。</p><p>在几声尖锐的电子音后，一个极其甜美、标准、甚至带着点AI合成感的女性声音，伴随着舒缓到近乎诡异的背景轻音乐，从遍布校园——包括这间千疮百孔的教室——的广播喇叭里流淌出来：</p><p>「校园广播启动中……」</p><p>「滋滋……检测到高三学段考前焦虑指数超标……启动‘心灵港湾’特别抚慰程序……」</p><p>「各位亲爱的江城二中高三学子们，距离决定你们人生走向的全国统一高考，仅剩最后24小时！」</p><p>「为了确保每一位同学都能以最佳状态迎接挑战，维护校园和谐稳定的备考环境，本校特此发布《高考前夕心灵守护指南》，请全体高三师生务必严格遵守：」</p><p>广播声音甜美得不带一丝人间烟火气。</p><p>「1. 请保持积极乐观的心态。过度焦虑是通往成功的绊脚石。请相信，努力必有回报，汗水终将浇灌出最美的花朵。微笑吧，少年！」</p><p>「2. 请专注于知识的海洋。课间请留在教室内安静复习或闭目养神。禁止在走廊追逐打闹、高声喧哗。」</p><p>「3. 请珍惜同窗情谊。互相鼓励，彼此扶持。严禁任何形式的言语冲突、肢体冲突。记住，你们是并肩作战的战友！」</p><p>「4.
