# 神界之上，暂名天界

<p>神界之上，按照惯例，暂名天界。</p><p>浮空云岛，霞光万丈。</p><p>无数刚满18岁的少年少女悬浮空中，神情或期待或茫然。</p><p>他们面前，一枚枚剔透的“世界水晶”正缓缓凝聚成型。</p><p>水晶内，微缩的原始大陆、海洋、生命胚胎隐约可见，即将随着主人的意志开始演化。</p><p>天界“园丁”们俯瞰众生，如同欣赏新一批作物播种。</p><p>一位少年将手按在水晶球上。</p><p>大屏幕上顿时显示出内容。</p><p>「世界觉醒等级：F」</p><p>短暂的寂静后，如同投入滚油的水滴，周围瞬间炸开了锅。</p><p>“噗——F级？！最低等的尘埃世界？”</p><p>“哈哈哈，开局就是地狱难度啊兄弟，你这水晶球里怕不是只有几块石头和苔藓？”</p><p>“啧啧，白瞎了这觉醒仪式，F级世界能发展到石器时代就算烧高香了！”</p><p>“认命吧，赶紧去后勤部报到，以后负责给我们的神国擦地板也挺有前途的。”</p><p>“莫欺少年穷？醒醒吧，你这起点连穷都算不上，是负资产啊！”</p><p>嘲讽、怜悯、幸灾乐祸的低语如同尖针，刺向少年。</p><p>少年面色微微涨红，但眼神深处却燃烧着一簇异样的火焰。</p><p>他没有丝毫紧张，反而有种压抑的兴奋。</p><p>只有他自己知道，当他的意识沉入水晶球的瞬间，清晰无比地感知到了——在那片被判定为“F级”的、看似贫瘠荒芜的原始大陆深处，蛰伏着一团庞大到令他灵魂都在颤栗的气息！</p><p>一个被完美隐藏，未被探知的特质天赋，如同烙印般刻印在他与世界连接的灵魂深处：</p><p>「隐藏SSS级世界特质-圣人宿土：您的世界将孕育出圣人级人物。」</p><p>圣人！少年心中咆哮着那句古老的箴言：“三十年河北，三十年河南，莫欺少年穷！”</p><p>他紧紧握住水晶球。</p><p>他知道自己握住了通往无上荣耀的门票。</p><p>在众人的哄笑声中，少年低着头快步离开了觉醒广场，冲回自己的简陋小屋。</p><p>关上房门，隔绝了外界的喧嚣。</p><p>少年迫不及待地将水晶球放在桌上，心脏狂跳，意识迫不及待地再次沉入其中。</p><p>作为早年父母双亡，从小被福利院收养，与妹妹相依为命的孤儿，少年知道自己的命运将在这一天发生改变。</p><p>他要好好看看，他那必将孕育出圣人的SSS级世界！</p><p>他要规划，他要引导，他要让妹妹读一所好大学，他要为福利院的各位做贡献，他要……</p><p>轰隆——！！！</p><p>一声并非来自水晶球内部，而是直接炸响在他小屋内的、仿佛空间本身被撕裂的爆鸣！</p><p>少年眼前一花。</p><p>只见一道无法形容的、如同浓缩了亿万年雷霆的闪电状圆球，毫无征兆出现在他房间中央。</p><p>闪电球出现的瞬间，并非爆炸，而是带着一种绝对的、不容置疑的“抹除”之力。</p><p>以它为中心，半径半米内的空间连同其中包含的桌椅、地板、甚至空气……</p><p>如同被最精准的外科手术刀剜去，又像是被橡皮擦从现实画布上彻底擦掉，凭空消失得无影无踪，留下一个边缘光滑如镜、散发着微弱空间涟漪的完美球形空洞！</p><p>简而言之，就是终结者的出场特效。</p><p>球形空洞中央，一个身影缓缓显形。</p><p>黑衣如墨，身姿挺拔，眼神淡漠得仿佛能冻结时空。</p><p>他身上还残留着刚刚撕裂世界壁垒，强行挣脱水晶球束缚时，逸散出的恐怖道韵。</p><p>那股气息，让少年感觉自己如同狂风巨浪中的一粒尘埃，渺小到近乎虚无。</p><p>正是杨帝！</p><p>他目光扫过这简陋的小屋，最后落在那捧着水晶球，嘴巴张得能塞进鸡蛋，浑身僵硬如同石雕的少年脸上。</p><p>杨帝微微皱眉，似乎对自己“出生点”的环境不太满意，又像是嫌弃少年那副蠢样。</p><p>他一步迈出，直接跨过那凭空剜出的空间空洞，走到少年面前。</p><p>少年大脑一片空白，嘴唇哆嗦着想说什么：“你……你是……我的……master……？”</p><p>他想说“圣人”，但不小心说成了master。</p><p>杨帝根本没兴趣听他废话。</p><p>直接像拎小鸡仔一样，一把揪住了少年命运的后颈皮。</p><p>“走。” 杨帝的声音平静无波，却带着不容置疑的意志，如同神谕。</p><p>“去哪？”</p><p>“你的球。”</p><p>下一刻，两人身影如同被橡皮擦抹去，瞬间消失在原地。</p><p>桌上那枚彻底黯淡，布满裂纹的F级水晶球内部。</p><p>杨帝拎着那名少年，如同拎着一袋土豆，一步踏出，便已出现在一片悬浮于混沌虚空中的奇异空间。</p><p>但这里并不是纯粹的混沌。</p><p>他们脚下，一片贫瘠的原始大陆上，茹毛饮血的原始人正围着篝火，惊恐地看着从天而降、撕裂了他们“世界壁垒”的杨帝和少年的虚影。</p><p>“这是我的‘天国世界’！”少年叫唤道。</p><p>杨帝点点头：“你这儿是片风水宝地，我用来放点东西。”</p><p>他挥挥手，空间中央，出现一个巨大而残破的金属造物。</p><p>——正是59改。</p><p>「核心逻辑框架初步稳定，记忆数据库较完整，但底层认知模块损毁严重。」</p><p>杨帝走到59改庞大的车体前，伸出手，掌心按在布满裂纹的装甲上。</p><p>一股纯粹而霸道的意志力混合着磅礴的信息流，直接灌入59改的核心处理器。</p><p>“欢迎回来。给你找了个新沙盘练手，就当是康复训练。”</p><p>一条鲈鱼形状的东西出现在众人身旁，少年被吓了一跳。</p><p>“老大，为什么要让这铁罐首先着陆在‘天国世界’？”</p><p>“因为此地相对于‘天界’而言，算是一个虚拟世界，灵能/现实丰度更低，环境更温和。59改本身体虚，贸然飞升到灵能更充裕的天界现实，比较容易溶解。”</p><p>少年颤颤巍巍举起手。</p><p>“呃，不好意思，但这是我的世界……”</p><p>“只是借来一用而已。如果你不嫌弃，我们还能帮你发展一下哦。59改……诶？给我干哪来了？这还是原来那个水晶球吗？”</p><p>59改照常手痒开始爆科技树。</p><p>卫生与基础生存，拉屎撒尿远离水源，用火烤熟生肉再吃，看见同类尸体要埋掉不能吃……</p><p>材料获取与工具制造，捏土烧陶器，崩砍燧石做刀具，将麻制成布……</p><p>农业雏形与定居，收集能吃的草的种子，搭建半地穴式房屋，刀耕火种……</p><p>冶金启蒙……三酸两碱……材料升级……蒸汽动力……</p><p>他们只是和少年多说了两句话，大陆上的原始人就开始闹工业革命了。</p><p>「杨帝阁下，我感觉活力回来了。」</p><p>59改口中吐出那个很难想象是从他自己说出来的词，“活力”。</p><p>刚说完一句话，眨眼间，原始人已经推到原子时代早期，中期，晚期，晚期巅峰大圆满，原子时代末期了。</p><p>“五九，你攀科技这么牛，当初在仙界是怎么被四神把格式塔思维给搞烂了。”</p><p>「偷袭。」</p><p>“啧，这邪神怎么这么坏，不讲武德啊。”</p><p>原始人已经攀到超物质时代。</p><p>「哦，这处水晶球内的天国世界能够时间加速，他们从宏观时代发展到原子时代，耗时5000年。发展到超物质时代，花费500万年。」</p><p>原始人已经走到了终点，超弦时代。</p><p>「花费50亿年。」</p>
