# 浮士德

<p>不知是谁随口提了一句“杀手兔真特么多”，然后一行四人发现，他们被数十成百只兔子包围了。</p><p>这纯兔妖瞳色赤红，青面獠牙，个个流着口水，跃跃欲试！</p><p>瑞弗维尔见多识广：“这杀手兔在这当地的山地丘陵地区，算是一种外来入侵物种。”</p><p>“也就是说，随便吃都无所谓？”</p><p>“没错，它们繁殖能力惊人，这附近又没有足够强大的魔兽来捕食它们，所以数量愈发泛滥。”</p><p>说起来，杀手兔在当地最大的天敌，居然是它们自己！</p><p>这些家伙经常横冲直撞，时不时撞到一些棱角锋利的石头上，就把自己给撞死。</p><p>哦对了，还有另一个天敌，那就是矮人和人类。</p><p>矮人正在实行工业化大生产，他们对环境的态度是先发展后治理。</p><p>而人类因为“冒险者公会”的存在，也经常来组团猎杀魔物，刷战力和金币。</p><p>一只杀手兔砍死后，带回冒险者公会。如果皮毛完整，成色好，能换一天饭钱。就算成色不好，也能换一顿饭钱。</p><p>天知道这套经济体系是怎么运行下去的！</p><p>但在此时此刻，他们远离文明社会，杀手兔的唯一用处，也就是拿来吃罢了。</p><p>但周围一圈杀手兔至少上百只！根本吃不完。</p><p>众人将询问的目光投向伊芙。</p><p>她便指了指杨帝：“给你来个，嗯，期中考如何？用4~6环法术解决杀手兔。既然是外来入侵物种，那就把它们清干净。以下是题目要求：</p><p>“第一，身体不得超出作答区域，一旦超出，作答无效。</p><p>“第二，答题必须按照4-6-2-3-1-5的环数顺序，进行施法。</p><p>“第三……”</p><p>伊芙列出了几个大题，还有些开放性题目，显然是学生时期被题目折磨疯了，留下了极大的心理阴影。</p><p>杨帝苦着脸，望着那层层叠叠、满眼的杀手兔，无奈地应下这荒诞又艰难的“期中考”。</p><p>“天下法术，无坚不摧，唯快不破。”</p><p>他睁开眼，气势陡然高涨，灵压澎湃！</p><p>第一招「四环法术·元素嬗变」，将地上泥沙转化成20块方正的砖头。第二招「六环法术·烈火流焰」将这些砖头烧制坚硬……</p><p>……</p><p>此后的两天，他们一路绞杀泛滥成灾的杀手兔，一路向南走去。</p><p>杨帝正在努力“回忆”自己的身份，并且向精灵伊芙请教灵能法术。</p><p>他使用法术也很有特色，都融入了“板砖”、“撬棍”这两种神兵利器的特点。</p><p>眼尖的伊芙早就发现了这点，但她没有明着提出来，而是将其与“杨帝潜意识中残留的过去之记忆”联系起来，试图描绘杨帝的「人格画像」。</p><p>殊不知，杨帝预判了她的预判——</p><p>他故意让自己的行为和言语，表现出与“板砖”、“撬棍”或其他事物有特定关联。</p><p>从而误导另外三人中智商最高的精灵。</p><p>隐藏自己来自地球的身份和目的。</p><p>但现在，杨帝陷入了某种内耗。</p><p>他不确定……精灵伊芙，是不是也预判了他对她预判的预判？</p><p>这就相当于大气层无限套娃，我以为你在第5层，我在第60层，然而你却在第700层。</p><p>陷入这种内耗困境，有些不妙。</p><p>伊芙是个聪明人。而瑞弗维尔看起来……算了，杨帝主要得防备伊芙的心眼，瑞弗维尔并不重要。</p><p>他认为，自己不应该随意看扁异世界人民的智慧，尽管自己是21世纪地球人类，尽管自己脑子中贮藏着一万零八百本地球书籍。</p><p>在无穷尽的内耗之中，心中各种关于什么虚无主义、意义危机、价值崩坏等后现代危机已经愈演愈烈。</p><p>他决定找个人聊聊。</p><p>那就找看起来最老实的奥拓吧。</p><p>奥拓，来自铁熔堡的一名矿工。</p><p>那铁熔堡以盛产各类珍稀矿石、巧工神器而闻名，在这片土地上，矿工们的地位可不低。</p><p>奥拓身材魁梧壮实，大概是因为常年在矿洞中劳作，所以他的双臂充满了力量。</p><p>皮肤也被岁月和矿洞中的烟尘，打磨得黝黑粗糙。</p><p>虽然奥拓资质不佳，本身只有堪堪一环水平的灵能。</p><p>但因为是矮人种族，天生巨力，单臂力量500斤，所以肩负起了背行李、扛炊具的任务。</p><p>他有一把超级漂亮的钻头和镐子。</p><p>钻头是顶尖的狱髓材质，三重附魔——效率V、耐久III、丝绸之触。</p><p>这钻头外表闪烁着荧荧紫光，光用肉眼看，就知道是极品！</p><p>而镐子就比较不同寻常了——那是把木镐，是真用木头做的镐子。</p><p>一般来说，珍藏这样不起眼的普通器具，还一脸沧桑的模样，简直是把“我有很多故事快来找我谈话触发剧情”写在脸上了。</p><p>杨帝找到奥拓时，他正坐在篝火旁，拿着一块柔软的布，仔细地擦拭着他的钻头和镐子。</p><p>奥拓对这两件工具宝贝得紧，平日里谁要是想碰一下，他都不太乐意。</p><p>杨帝在他身旁坐下，犹豫了一下，开口道：“奥拓，我有点事想和你聊聊。”</p><p>“咋啦，杨帝，你说。”</p><p>“生命有没有意义，世界会不会是虚无的……”</p><p>气氛逐渐哲学起来。</p><p>奥拓说：你就做好自己，按照自己的想法去做，生活本身就是意义。</p><p>你越琢磨，越把自己绕进去。</p><p>就像挖矿，顺着矿脉挖，总能挖到宝贝，要是东一锄头西一榔头，最后啥也捞不着。</p><p>我觉得做啥事儿，只要能让自己有个奔头，那就是有意义的。</p><p>比如我，我就想成为震古烁今的考古学家。</p><p>或者不震古、不烁今也行——我就是喜欢挖东西。特别是古时候的器具，老古董。</p><p>大地蕴藏了万物，万物终将会被大地埋藏。</p><p>打个比方，炊锅终究会破掉、被丢在某个地方无人理会，最后被风沙土壤埋葬。</p><p>但不能因为炊锅的命运既定，而在当下就放弃了“煮饭”这一功能。</p><p>对炊锅来说，煮饭就是意义。</p><p>奥拓长篇大论完人生鸡汤，舔了舔干裂的嘴唇：“说到煮饭，今晚吃啥？”</p><p>杨帝：“还是兔肉。”</p><p>他们已经连吃几天兔肉，腻得可怕。</p><p>不过奥拓知道也没啥好抱怨的，当下在这鸟不拉屎的山地丘陵，有东西吃就不错。</p><p>杨帝感觉胸中淤堵的情绪解开了一些。</p><p>他微笑，继续对奥拓说道：“奥拓，如果有个人……我是说如果。”</p><p>“嗯，如果有个人对吧，您说。”</p><p>“那个人，他身上有秘密，这个秘密暴露出来，他也不知道自己的命运会倒向哪一条路。”</p><p>奥拓眼皮抖了抖：“很经典的悬疑类小说情节。”</p><p>杨帝叹气：“可是，那个人的秘密快要被暴露，也有可能已经暴露。但他还不知情，只是心中有不安的感觉。”</p><p>奥拓双手紧捏木镐：“那，那真不幸。这一定是个虚构的故事对吧，杨帝兄弟，又或者你想做什么思想实验？要没其他事我就去做饭……”</p><p>“哦哦噢，这题我会，‘浮士德’型的基本故事类型，主角有无法掩饰的秘密，或者难以洗清的过去。对吧杨帝？对吧奥拓？”</p><p>不知何时，伊芙出现在二人之间。</p>
