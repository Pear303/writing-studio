# 意识圆满

<p>「四万载前，宇宙孕育出了首位『先天精灵』。她将手中常伴的木杖插入土壤，瞬息间，木杖化作精灵圣树。民间相传，这位先天精灵的体味类似于柑橘……」</p><p>——《大陆英雄野史录·精灵列传·序言》瑞弗维尔·兰斯洛特，第四纪元2100年</p><p>……</p><p>……</p><p>新生的圣树，它的第一缕感知，便是一个精灵和一个人类，伊芙与杨帝。</p><p>它太困了。它只是一根枝杈，刚刚在焚焦的土地上扎根。</p><p>它停止了作为初生生命的第一次感知。它陷入暂时的沉睡。</p><p>只是，伊芙和杨帝的面庞，已深深记录于圣树的根须与茎叶之中。</p><p>圣树看到的最后一幕，是那个柑橘味的精灵被一众原始精灵拥簇，而那个人类转过身，缓缓远去。</p><p>杨帝的背影，逐渐被精灵们的喧闹淹没。</p><p>他脚步在焦土上拖沓出深浅不一的痕迹。</p><p>怀中，伊芙留下的物件仍带着余温，奥拓的钻头，黑色天鹅绒包裹的雕塑，巴德的银质玫瑰徽章……这些，是伊芙一并嘱托给他的身后事。</p><p>当最后一个精灵的喧嚣也消散在热浪里，杨帝终于停在无限机兵的阴影下。</p><p>百米巨人单膝跪地，链锯光刃割裂的大地仍在渗出暗红岩浆，那是这个世界的未愈之伤。</p><p>深吸一口气，杨帝盘坐在焦土上。</p><p>他意识如丝线般抽离躯体，穿越主体与客体的界限。</p><p>开始冥想。</p><p>当感官重新复苏时，杨帝置身于一片混沌的星海之中，无数光点在黑暗中明灭，像是宇宙的呼吸。</p><p>他的视野打破时空之高墙——冥想状态已进入。</p><p>远处传来类似琴弦断裂的嗡鸣。那边，是虚境的方向。</p><p>杨帝不打算将自己的思考沉溺于哲学，他现在只想做到一件事——找到机兵。</p><p>直面恐惧，斩断因果，创造未来。</p><p>杨帝正要做出必死的决心，突入虚境。</p><p>但下一刻，他眼前一闪，虎躯一震，看见了——机兵的灵。</p><p>“位处现实世界的物质躯壳……并非机兵的全部。它的精华，是一大团‘灵’，一大团‘现实’。”</p><p>冥想状态下，杨帝“眼”前看见之物，铺天盖地的信息流，正在疯狂涌入他的精神——</p><p>那是一座庞大到令人窒息的、仿佛跨越万千维度、亿万光年的巨型迷宫。无数“on色”灵能组成光带，光带交织成网，网络生长到无穷远方。</p><p>那不是普通的“光带”。</p><p>也并非无实际意义的“网”。</p><p>杨帝精神在感知到那无穷浩渺之时，几乎是在同一时间，理解了「无限机兵」的本质。</p><p>它是极大量、极其复杂的「附魔」。</p><p>它是一种，或是多种附魔的集合体，本质上与奥拓钻头上的附魔没有大不同。</p><p>人驾驶机兵，即是给人本身“附魔”。</p><p>而“附魔”，本质上又是为撬棍镶嵌假牙。</p><p>只不过，撬棍只有手臂大小，而假牙……</p><p>无限机兵，是一颗也许比银河系还要庞大的“假牙”。</p><p>伊芙镶嵌着这颗“假牙”，战斗了足足两个多小时。</p><p>“附魔”的本质，就是一大团附加的灵能。</p><p>所以，伊芙才会认为以他瘦弱的小身板，一旦进入驾驶舱，就会被迅速溶解！！这就是她老大哥心态作祟的缘由。</p><p>而事实也确实如此。30灵的杨帝，太弱小了，犹如一杯墨水之于一片沧海，他一旦不小心，就会将自己溶化于机兵。</p><p>原初之眼不知何时还会卷土重来。现在，该轮到自己了。</p><p>杨帝用自己的“灵”，触碰机兵。</p><p>精神与庞大的灵能网络接触之刹那，感官如超新星爆发般爆炸！</p><p>从大气层外暗物质流的振动频率，到新生圣树根系分泌的某种酶分子结构，五百公里外一只工蚁分泌的信息素，地心金属液核的流淌，都以类似全息影像的某种方式，投射在意识深处。</p><p>「同步率：10%」</p><p>杨帝咬咬牙，还能支持。</p><p>“同步率10%”，他莫名地知道意思——目前掌控10%潜意识。</p><p>但是，他的六感六识，从原来的眼耳鼻舌身意，替换为了机兵的暗物质矩阵传感器、星空观测接口、超维度芯片、类时无限计算机……</p><p>这些名词所代表的技术造物，亦远超杨帝所能理解的范畴。</p><p>同时，机兵上还有亿万万其他更微小，但聚沙成塔、聚流成河的附魔。</p><p>穿透、力量、火焰附加等杀伤性附魔效果，融合在机兵的武器和指尖。</p><p>节肢克星、亡灵杀手、星河卫士、逐鹿银河……各种属性克制的增益，弥漫在机兵全身。</p><p>每个零部件，都被打上耐久、无限、灵能修补等辅助附魔。</p><p>附魔效果并非各自独立，而是相互叠加、相互增幅。</p><p>而此刻，同步率10%的他，仅仅只是窥见无限机兵奥秘的冰山一角。</p><p>这座机兵，这就是膝盖关节处最小的一颗螺丝，复杂程度也远超奥拓附魔台的构造。</p><p>“幸好，这种用作‘附魔’的灵能，并不会因为我的个体灵能过于弱小，而狂暴地涌入我，将我稀释溶解……”</p><p>「主体溶解」，原因是一个“主体”吸纳的外界灵能过多过多。相当于“种植牙”太多，反而对“真牙”喧宾夺主。</p><p>而「附魔」，是可以随时拆卸的“假牙”，是外物，所以并不会轻易导致溶解。</p><p>前提是杨帝能镇守住理智和清醒。</p><p>一旦他精神撑不住，忘记了“自我”，分分钟就会溶解在这庞大的“机兵附魔灵能”之中。</p><p>深呼吸，聚精凝神，抱元守一。</p><p>我是杨帝，我不是苇草和蚱蜢，也不是精灵与机兵。</p><p>暂时稳定下来了。</p><p>只要自己的意志不崩溃，自我意识尚存，就不会被庞大的“附魔”所稀释溶解。</p><p>此刻，杨帝面前是一本机兵说明书，目录约500GB。</p><p>匆匆看两眼，便大致知道这座无限机兵有什么功能，如何驾驶，哪边是向左向右，怎么用眼睛开炮。</p><p>「同步率较低。但根据紧急协议，允许启动『无限机兵』战斗模块。是否强制提高机兵同步率？」</p><p>“……是。”</p><p>杨帝的意识世界仿若被一挺阳电子炮击中。</p><p>他搞明白伊芙痛不欲生，乃至最后遗忘过去所有记忆的原因了。</p><p>同步率强制提高至100%，那一刻……他100%的潜意识，毫无保留、纤毫毕露地显现在自己意识之中。</p><p>没有经过任何图标、表格、曲线、显示屏、文本框、进度条、视网膜、听觉神经、味蕾、大脑皮层处理的世界——向杨帝展现了其最真实，最狰狞的面目。</p><p>时间不是一条连续的长河，而是由无数闪烁的碎片悬浮于混沌之中。</p><p>万物的抉择存在于无数个碎片中，“未来”既由过去和现在所决定，“过去”也被未来与现在所影响。</p><p>穿越过去把你祖父干掉？</p><p>干掉就干掉，对你来说，未来的你就不会出生，但并不影响“当下的你”继续存在。</p><p>一证永证，一证永恒。</p><p>因果律？至少在这个世界，不重要。</p><p>杨帝的精神正在被这个世界100%的真实面目所冲刷。</p><p>「精神+1+1+2+3……+6765+10946……」</p><p>「……+75025+121393……」</p><p>此时的痛苦超越生理极限。</p><p>任何剂量和毒性的生物激素，任何对神经施加的电流，无论在“量”方面如何堆积，都无法在“质”超越生理极限。</p><p>都无法达到此时杨帝精神世界的剧痛程度。</p><p>那是超越肉体界限的煎熬。</p><p>他身体做不出任何反应，哪怕是操控小拇指动一毫米也做不到。</p><p>包括意识本身，也无法做出任何思考。</p><p>杨帝看见了真相，看清世界本来的模样。</p><p>七彩的河里过去未来都涌动，万千景象涌到了他的大头中，脑瓜子一阵嗡嗡嗡嗡嗡嗡。</p><p>人的前五识眼耳鼻舌身，分别对应色声香味触五觉，是对万般现象最直觉、主观的感知。</p><p>第六识“意识”是串联前五识的丝线，它能将视觉捕捉的光影、听觉接收的声波、嗅觉分辨的气味、味觉品尝的滋味、触觉感知的质地，编织成完整的认知图景。</p><p>当先天的“五识”所有信息，完全地涌入第六识“意识”。</p><p>便再也没有表层意识和潜意识之分。</p><p>隐藏在冰山一角之下的庞大潜意识，已经不再“潜”，它完全浮出水面。</p><p>「精神+317811+514229……+1346269」</p><p>「五识圆满，意识圆满，精神力量膨胀到这片天地都承载不动，接下来我会何去何从？」</p><p>杨帝隐隐约约触及到第七种“识”，末那识。</p><p>他隐隐约约觉察到“自我”的根源，关于“我”为什么存在，我和世界的联系与区别。</p><p>精神的超界限剧痛停止了。</p><p>杨帝在30秒内疾速进化，适应了这座机兵的最低驾驶条件。</p><p>他恢复清醒后的第一件事，是为伊芙感到至极的悲伤。</p><p>她可没有无限进化适应的超能力，却竟然在这种痛苦中，驾驭机兵战斗连续两小时。</p><p>杨帝完全理解了伊芙眼神的空寂，为何她情感会迟钝，而后不可扭转地失去记忆。</p><p>为了承受这般痛苦，她不得不抛弃掉一些什么，诸如情感，记忆，理智。</p><p>只在内心最深处，留下最后一点点，对自己而言最重要的东西。</p><p>五感与意识彻底贯通，痛苦失去定义，取而代之的是超越维度的孤独。</p><p>只有忘记一切，献祭一生的记忆与情感，她才能治愈这两个小时的痛楚。</p>
