# 湖人队杨帝

<p>距离末日火山主峰90公里。</p><p>……</p><p>那是个人形的东西。</p><p>说他是“人形”，而非确凿的人，主要是因为他脑袋太大了，和马车车轮一样大！</p><p>这颗巨大的头颅缓缓转动，似乎察觉到了瑞弗维尔的注视。</p><p>它的五官模糊不清，或者可以说根本看不到五官。</p><p>脑袋中部，有一团黑乎乎的“核心”，瑞弗维尔一时间词汇匮乏，想不出别的词来形容了。</p><p>他心中涌起一阵寒意。</p><p>这玩意，怎么看都不像人吧？很可能是末日火山本地孕育出来的魔物——</p><p>尽管瑞弗维尔在它身上，感受不到一丝一毫灵能波动……</p><p>“我是不是应该尖叫着抱头鼠窜逃跑？”</p><p>瑞弗维尔正犹豫着是应该转头就跑，还是从包里掏出那石头雕塑正面硬刚。</p><p>那个“人”上岸了。</p><p>原来那真是个人，但是他脑袋被一只史莱姆包住了，史莱姆是暗红色的。</p><p>那史莱姆像是一层诡异的外壳，紧紧裹着男人的头部，只留出下巴以下的部位。</p><p>男人身体瘦弱，但不佝偻。</p><p>衣袍破破烂烂，但他昂首挺胸。</p><p>“真是让人‘头大’……你好，今年夕是何年？”</p><p>他一步一步缓慢地朝着瑞弗维尔走来，每一步都带着水渍，发出“啪嗒、啪嗒”的声响。</p><p>瑞弗维尔愣了一下，原本紧张到极致的神经稍稍放松了些，但依然不敢掉以轻心。</p><p>他紧紧盯着这个怪异的男人，手还是下意识地握住了包里的石头雕塑。</p><p>“呃……您吃了吗？”瑞弗维尔如是问。</p><p>被暗红色史莱姆包住脑袋的青年没有直接回答。</p><p>他嘴里嘟囔着什么，“这还是国内吗”、“异世界也讲普通话”、“这史莱扒拉不下来”……</p><p>瑞弗维尔叹了口气，将石头雕塑收回去，缓缓抬起双手：“我来助你。”</p><p>正常来说不该帮的吧……</p><p>这么奇怪的人，万一是圣光教廷的圈套呢！</p><p>要知道，圣光教廷行事向来诡谲，为达目的不择手段，说不定就会弄出这般怪异的情景引人入局。</p><p>如此没有警惕意识的瑞弗维尔，要是放在冒险小说里，活不过十行字！</p><p>他开始咏唱一道驱散类法术：</p><p>“远古的清风，拂过混沌的大地，以太的波纹，驱散虚妄的迷雾。黑暗与虚妄，皆为虚幻之影，在这净世之息中，消散无踪。风起，云散，一切归于宁静，以吾之名，净世之息，现！”</p><p>「四环法术·净化」</p><p>他双手间泛起柔和的白色光芒，光芒逐渐凝聚成一个微小法阵，法阵中符文闪烁。</p><p>那暗红色的史莱姆不安地扭动起来，发出“滋滋”声。</p><p>瑞弗维尔加大灵能注入，法阵迅速扩张，将青年的头部、包括史莱姆笼罩其中。</p><p>暗红色史莱姆被一股无形巨力拉扯。</p><p>“啵”的一声，它被从青年头上扯了下来，摔在地上。</p><p>“成功！你免费了！”</p><p>史莱姆落地后，不甘地在地上翻滚了几下，随后迅速朝着湖边黑暗的角落蠕动而去，眨眼间便消失得无影无……</p><p>然而下一刻那青年虚空大手一探，抓住史莱姆强行拉扯了回来！</p><p>瑞弗维尔惊讶。</p><p>这人在刚刚摆脱史莱姆控制的情况下，竟还有这般力量。恐怖如斯，如斯恐怖。</p><p>青年看着手中不断挣扎的暗红色史莱姆。</p><p>然后又转头看向瑞弗维尔：“多谢相助，我叫杨帝。”</p><p>瑞弗维尔点了点头，回应道：“我是瑞弗维尔，一名国王秘密派遣的咳咳，一名旅行商人，来自西土大国圣古琉斯，前往东方取金。这位朋友刚刚是在游泳吗？”</p><p>怎么看都不像游泳吧。</p><p>杨帝轻轻晃了晃手中的史莱姆，借坡下驴：“哦哦噢，对对对，刚才在这湖底潜泳，我用史莱姆当潜水头盔呢，哈哈。这位兄弟普通话说挺好啊，今夕是何年？”</p><p>瑞弗维尔年前这人像是从异界而来。</p><p>他如实相告：“第四纪元2099年，也就是公历40k年左右。您想起来了么？”</p><p>杨帝直勾勾盯着他眼睛。</p><p>“宫廷玉液酒？”</p><p>“？先生你说什么。”</p><p>“天王盖地虎？”</p><p>“如果您想对暗号，那应该找错人了。我只是个意图前往东方取金的商人。”</p><p>杨帝默默长叹：他真穿越到异世界了。</p><p>这地方说的还是普通话……不对，不是普通话，而是某种新语言，顶替了他记忆中“普通话”的位置。</p><p>这穿越，似乎还伴随着某种类似 “软件系统适配” 的奇妙现象。</p><p>就好像他大脑里的语言系统被重新编程了。</p><p>明明身处异世界，可听到的话语竟能自动转化为他所熟悉的概念。</p><p>就像将这陌生世界的语言“翻译”成记忆里的普通话。</p><p>然而某些特定的词汇和梗，又对不上号。</p><p>看来，这种“适配”是有限度的。</p><p>杨帝抱着暗红色史莱姆四顾张望。</p><p>“对了，瑞弗维尔……你刚才那是魔法？看起来还挺神奇的，和我以前认知里的东西完全不一样。”</p><p>瑞弗维尔微微一愣：“魔法？算是一种通俗的说法吧，我们称之为灵能法术，通过调动周围游离的灵能，按照特定的符文和咒语形成法术效果。”</p><p>“灵能？法术？”</p><p>“像刚才的四环法术·净化，就是专门用来驱散不洁之物的法术。杨帝朋友，你似乎对这些完全不了解，从什么地方来的？怎么连基本的灵能概念都没有？”</p><p>面对异世界土著的质疑。</p><p>杨帝挠挠头：“我失忆了。”</p><p>……</p><p>失忆，这招真好用吼！</p><p>一切不合理的事情，一切和这世界格格不入的行为和表现，都可以推给“失忆”。</p><p>你不知道灵能是什么？</p><p>我失忆了。</p><p>哦哦哦，祝你早日“补完自我”！</p><p>瑞弗维尔打量着杨帝，眼中好奇：“失忆倒也常见，许多冒险者在经历了强大的灵能冲击，或受到魔物的特殊攻击，都会出现失忆。只是你连灵能都不知晓，这可有些棘手。”</p><p>相当于一个人失忆后，连怎么蹲坑都忘了。</p><p>这是很严重的失忆。</p><p>杨帝装作虚弱地靠在旁边的树上：“我醒来后脑袋一片空白，只记得自己叫杨帝，连怎么到这湖边的都不晓得。现在浑身乏力，虚弱得一只猫就能把我撂倒。也不知该往何处去。”</p><p>瑞弗维尔见他相貌老实憨厚，失了忆。</p><p>而且修为惊人，被史莱姆裹住脑袋，在水里泡不知多久，醒来后还能反手抓住史莱姆。</p><p>如果带他上路，或者就多了个可供使唤的保镖！</p><p>——有这种想法的瑞弗维尔实在太天真了，放进冒险小说里，活不过20个字。</p><p>他勉为其难道：“若不嫌弃，便随我同行一段吧。我正准备前往东方的末日火山，途中或许能遇到知晓如何恢复你记忆的人。”</p><p>二人望向四周。</p><p>周围的地形颇为奇特，他们所处之地乃是末日火山外围区域的某处小型熔岩喷口。</p><p>黑色火山岩犬牙交错，犹如狰狞的巨兽之齿，记录了曾经火山喷发的狂暴与炽热。</p><p>现在，火山岩都被草木苔藓覆盖了。</p><p>一百年前，随着卡利斯托坠落，这里的岩浆停止了疯狂的喷涌。</p><p>斗转星移，竟慢慢汇聚成了一个小湖。</p><p>湖面看起来并不大，像是大地眼眸中一方小小的泪池。</p><p>然而，这湖水却特别特别深，仿佛是通往地心深处的通道。</p><p>也正常，毕竟原来是熔岩管道。</p><p>曾经，大地深处的熔岩从此管道流上来。</p><p>而现在，“熔岩管”被湖水填满。</p><p>由此变得深邃得让人不敢直视，仿佛只要多看一眼，便会被那无尽的黑暗吸进去，获得通往九幽地狱的单程车票。</p><p>天知道这个“杨帝”是怎么掉进去的。</p>
