# 无穷潜力

<p>“不过，我每天吃下这么多食物，为何单单在吞下那枚附带了你‘灵’的发卡时，才感觉到自身现实丰度增加呢？”杨帝继续追问。</p><p>原初之眼说：</p><p>「我不明白你这种‘进化’能力的本质，但我认为，食物、水中、空气中的‘灵’并没有对你造成伤害，对吧？」</p><p>杨帝再度瞳孔一缩，发现这确实是个盲点。</p><p>他的进化能力有种局限性——必须需要被动受到伤害，才能触发超量代偿。</p><p>「我依附于那枚发卡上的灵，目的是操控、感染接触者的精神和思想，扭曲他的人格，让他成为我物质肢体的一部分。」</p><p>祂就是这么控制熔岩史莱姆的。</p><p>「但我发现，你的精神力量浩瀚如海不说，就连思维模式、性格人格也都难以撼动，根本无法扭曲。」</p><p>没错，杨帝还能免疫性质强烈的模因效果。</p><p>经常说一首好歌、好电影能“触动心弦”，但他就连心弦也能适应进化，难以被触动。</p><p>更不要提原初之眼，竟然试图将他洗脑成功一个自己。</p><p>这种行为，只会极大刺激杨帝的进化机制。</p><p>「当我的一缕‘灵’试图将你夺舍，你的身体似乎……起了某种反应，我不仅没有夺舍成功，你还反过来吞噬我的灵。」</p><p>杨帝思维如高速运转的齿轮。</p><p>“所以，我需要主动吞噬你，把你的灵啃食殆尽，才能完成这场‘杀戮’？”</p><p>「更准确说，我还要主动对你发起攻伐，刺激你的适应进化，才能让你主动‘消化’我。」</p><p>“可你作为原初之眼，既然存在于所有时空的每个角落，我该如何将你尽数纳入体内？”</p><p>「所以我们要去往时空的起点，历史与万物的源头。在宇宙刚刚诞生的那一刻，宇宙中的所有基本粒子同时重叠在同一个点，这是‘沙漠’中比较特殊的一粒沙子，是所有世界线的源头，没有‘其他世界线’之分。」</p><p>“你从什么时候注意到我？”</p><p>「最初。」</p><p>“最初？”</p><p>「你穿越到此世的那一刻。」</p><p>「我控制的熔岩史莱姆，包裹住你的头颅整整10个小时，但仍然无法脑控你的思想，甚至没有对你造成伤害。」</p><p>「穿越者，是这个世界既定命运中为数不多的随机变量。」</p><p>「绝大部分穿越者来到此世，往往能掀起一片激荡风云。」</p><p>「但在搅动些许变化后，往往就偃旗息鼓，被此世规划出新的既定命运。」</p><p>「只有你，你非常不同，杨帝。」</p><p>原初之眼已经观察杨帝很久，知道他来自异世界，也知道他进化适应的秘密。</p><p>就连伊芙都能隐约察觉到他不是这个世界的土著，更不用提笼罩于时空之上、观察万物运行轨迹的「原初之眼」。</p><p>「你无法被世界线所‘分裂’，自始至终，你都只能存在于一条世界线之中。」</p><p>「在其他世界线，包括这一条世界线的过去与未来，我都看不到你的存在。」</p><p>「你只能存在于这一条世界线的当下。」</p><p>「亦是在那个时候，我觉察到你能免疫崩坏现象。」</p><p>崩坏……这是个久远让人怀念的词汇。</p><p>当年杨帝吞下了那几团黑色拉面，他能感觉到自身先是濒临破碎分解，仿佛组成身体的每一个粒子都在极度不稳定地振荡。</p><p>仿佛……就要被同化成那些黑色拉面的存在形态。</p><p>而后，他的“崩坏抗性”上升。</p><p>构成身体的物质也重归稳定。</p><p>“‘崩坏’的本质是什么？”杨帝问。</p><p>「‘崩坏’是‘稳定现实’的对立。」</p><p>「时间，其实是由近乎无穷的‘瞬间’按顺序连接而成。那么如何保证‘下一个瞬间’的东西，仍然还是上一个瞬间的东西？」</p><p>「灵能，现实丰度，就起到这种功能。」</p><p>「它保证了上一刻的‘飞矢’，和下一刻的‘飞矢’，都是同一根飞矢。」</p><p>「如果一个事物的灵能被彻底抽走，它的现实会陷入不稳定。」</p><p>「它会‘串线’，时不时跑到其他世界线，在宏观就表现为物质不稳定的震荡，像拉面一样蠕动；会吸收所有频段的绝大部分光线，所以表现为黑色；同时物理性质也会略微扭曲……」</p><p>过去许多疑惑都一口气得到解答。</p><p>这才过去堪堪10分钟不到。</p><p>十分钟的收获超过半年漫无目的地搜寻。</p><p>“所以，你恳求我吃了你的‘灵’，然后你会变成有史以来规模最庞大的‘崩坏’。”</p><p>「并不会。因为在在时间原点，万物尚未生成，我没有物质躯壳，不会引发崩坏。」</p><p>「而你只存在于当下这一条世界线、只存在于这一瞬时间点的‘沙子’中，所以免疫崩坏，更不可能因吞噬了我而受伤。」</p><p>「因为‘崩坏’本质是现实的不稳定与跨世界线‘串线’，而你根本没有可供‘串线’的其他世界线投影。」</p><p>“……为什么会这样？”</p><p>在其他世界线没有自己存在？</p><p>那他是不是亏麻了，毕竟别人都有自己的同素异形体。</p><p>原初之眼说：</p><p>「还是用你们岩石行星生物容易理解的比喻说明。」</p><p>「杨帝，你是一座孤岛上的灯塔，所有试图扭曲你现实的海浪，在触碰到你独属于当下的存在本质时，都如同海浪撞上礁石般溃散。」</p><p>「我推测，你的身体将‘世界线分裂’也视作了某种程度上的……伤害。」</p><p>杨帝瞳孔微微收缩。</p><p>他的进化适应能力，有这样的潜力……？</p><p>世界线分裂，也是一种“裂”。</p><p>原初之眼的声音带着某种难以名状的赞叹。</p><p>「普通存在的灵能如同流动的溪流，会随着时间与世界线的变动而分流、汇聚。」</p><p>「而你的灵能却是一汪永不外溢的深井，始终锚定在此时此刻。」</p><p>「当黑色拉面的崩坏之力渗入你的身体，它找不到其他世界线的‘漏洞’，只能在你当下的现实中徒劳冲击，反而刺激你的进化机制将其转化为加固现实的力量。」</p><p>「然而你穿越过来之时，我注意到，你的‘灵’，也就是‘现实’，极度稀薄。」</p><p>「考虑到你的进化适应能力——我猜测，你的部分‘客体现实’遭到撕裂。」</p><p>个人的现实，被划分成主体和客体两部分。</p><p>客体的，比如银行卡账号，个人信息资料，以及在地球20多年来，杨帝对这个世界所造成的所有影响，都是存放在“外界”的。</p><p>杨帝正是损失了这部分的“灵”。</p><p>「再结合你正在四处寻找‘话本编撰者’，我推断，祂就是伤到你的罪魁祸首。」</p><p>「那么，我们有共同的敌人了。」</p><p>杨帝笑着说：“你既希望我杀死你，又希望我找到耶罗大仙为你复仇，看来是我占据了谈判主导权。”</p><p>原初之眼的眼珠子形象，在杨帝意识中疯狂扭动。</p><p>「没错……没错……你有能力杀死我，你将杀死我，你必须杀死我！」</p><p>「杀了我，拯救众生免于熵寂，打破话本编撰者设下的观测闭环。」</p><p>「唯一的全知视角消失，这个虚假‘剧本’便会出现裂缝。而你，能顺着裂缝触摸到真相。」</p><p>「你想要知道话本编撰者的信息，就必须把我杀掉。」</p>
