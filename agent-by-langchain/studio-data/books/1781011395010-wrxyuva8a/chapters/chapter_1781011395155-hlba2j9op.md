# 阴伏流煞

<p>“你们看数据流。”</p><p>数据之河上，混进了几缕闪烁不定的黑色乱流，如同污浊的油渍。</p><p>正是那黑色圆球侵入后带来的污染。</p><p>它们扭曲着正常的数据流，发出刺耳的、如同指甲刮擦玻璃的噪音。</p><p>“这条河流，应该就是铁罐头所说的‘数据总线’了。顺着污染飘来的方向，溯洄而上，应该能找到金属圆球带来的信息源头。”</p><p>他们看向“河流”的源头。</p><p>主机内部，数据光河奔腾不息，六边形晶壁构成的“山峦”沉默矗立。</p><p>59改的扫描头闪烁着冷静的蓝光，阿巴鱼鳍不安地拍打着虚拟水流。</p><p>他们仍然是一行四人。</p><p>与他们同行的，是那位总以“天元神皇”自居的、来自十万大山的土皇帝。</p><p>这位天元神皇此刻在数据空间里的形象，依旧穿着他那身象征帝位的、略显陈旧但金线密布的虚拟衮服。</p><p>只是脸上没了往日的睥睨，反而带着一丝迷茫和挥之不去的惊悸。</p><p>59改在自己的虚拟空间沙盒里，自然不会放任这位土皇帝为所欲为。</p><p>虚拟沙盒空间内，他给这位“天元神皇”设下的诸多限制，命令其参与劳动，上山下乡，然后将时间流速调快。</p><p>到目前为止，天元神皇已经和老乡同吃穿整整三个月，终于把他身上那股所谓的“皇道龙气”磨去了厚厚一层。</p><p>这回59改把天元神皇放出来，是为了问话。</p><p>他因为附身在自动化盾构机的计算机中枢，从而导致盾构机失控。</p><p>冰淇淋机、炸薯条机也内置了智能芯片，同样也被数字生命附身，才导致失控暴走。</p><p>但这两台机器内，数字生命求死之心强烈，59改若是强行观测“打捞”，将会抹除对方的记忆数据。遇事不决量子力学，神奇吧。</p><p>所以，只能在求生欲旺盛的土皇帝身上，看能否挖掘线索。</p><p>“俺真不知道咋回事儿嘞！俺在那盾构机里头，黑灯瞎火的，就觉着脑袋嗡嗡响，跟被雷劈了似的！”</p><p>“到现在还没想起别的什么吗？”</p><p>“那些机器发疯的时候，俺也吓得腿肚子直打颤，哪还有空琢磨咋回事儿？恁们可别冤枉俺这老实人！”</p><p>59改摇摇头「看来该疗法收效甚微。」</p><p>不过也对，“上山下乡”对一个土皇帝来说算是截然不同的生活，很难帮助他联想回忆过去。</p><p>但杨帝——59改的直属上司——认为天元神皇必须经过劳动改造，必须上山下乡。</p><p>所以，只能用这种比较低效的虚拟情景。</p><p>就在这时，沉默不语许久的天元神皇，忽然停下脚步。</p><p>他怔怔地看着一条从主河道分叉出来的、颜色格外污浊粘稠的黑色支流。</p><p>那支流里翻涌的不再是单纯的乱码，更像是一种粘稠、蠕动、散发着不祥气息的黑色泥浆。</p><p>支流两岸的晶壁山峦，竟被这黑泥腐蚀出蜂窝状的孔洞，孔洞边缘闪烁着类似金属锈蚀的暗红光泽。</p><p>“阴……阴伏流煞……”天元神皇的声音干涩沙哑。</p><p>他回想起来更多了。</p><p>这正是59改之前扒他底层数据，扒到的一个出现频率极高的词汇。</p><p>“阴伏流煞？老土，你嘀咕啥呢？赶紧想起什么都详细说说。”阿巴凑近问道。</p><p>天元神皇猛地回过神，脸上血色褪尽，眼中残留着巨大的恐惧：“是……是它！俺想起来了！俺的天元帝国……末路之时……就是被这‘阴伏流煞’吞噬的！一种无形无质，却能蚀骨销魂、污秽灵脉、扭曲心智的恐怖瘟疫！无声无息蔓延，感染之地万物凋敝，生灵癫狂……俺的子民……俺的宫殿……”</p><p>他的声音哽咽，虚拟的衮服似乎都在微微颤抖，“那些信奉此邪秽的邪信徒……他们……他们就像这黑泥一样，将整个帝国拖入了深渊！这……这不可能！它怎么会出现在这里？在这个铁疙瘩的肚子里？！”</p><p>仿佛是为了回应他的恐惧，又像是被他唤醒了更深层的恶意。</p><p>整个数据硬盘世界，骤然剧变！</p><p>“嗡——！！！”</p><p>刺耳欲聋的、如同亿万只金属昆虫振翅般的尖啸，瞬间撕裂了之前的静谧。</p><p>两岸的晶壁山脉剧烈震动，六边形的晶格像被注入了污血，迅速变黑、皲裂！</p><p>大块大块由纯粹“错误报告”和“逻辑死锁”凝结成的黑色“岩石”从山体上剥落，砸入光河，激起更猛烈的黑浪。</p><p>天空中，原本代表稳定数据流的柔和光带，此刻疯狂扭动、断裂，化作一条条燃烧着幽黑火焰的荆棘长鞭，无差别地抽打着空间！</p><p>被抽中的地方，空间像劣质的画布一样被撕开，露出后面更加混乱、闪烁着马赛克和雪花噪点的“虚无”。</p><p>“……老土，你刚才说，阴伏流煞是什么？”</p><p>“瘟疫。”</p><p>“你管这玩意叫瘟疫？！”</p><p>防火墙迷宫开始扭曲变形，坚固的壁垒软化、流淌，似融化的蜡油。</p><p>门户洞开，从中涌出不再是数据流，而是粘稠的、散发着垃圾酸腐味的黑色泥浆。</p><p>泥浆所过之处，代表健康数据的“地面”迅速被腐蚀、塌陷，形成冒着黑烟的沼泽。</p><p>两位真仙境大能、一位超级机器人，连携着刚刚上山下乡三个月的土皇帝，在虚拟数字空间内飞驰。</p><p>“妈耶！这比本尊当年被网住还吓鱼！铁罐头！想想办法！这破硬盘要炸了！”</p><p>「分析失败。目标并非已知数据结构或能量形态……其构成……无法解析。核心信息熵值……极高……表现为……纯粹的无序乱流？」</p><p>“啥玩意儿？铁罐你都看不穿？”阿巴已无心讽刺，只想知道这黑泥巴到底是什么东西。</p><p>青丘白璃指尖凝聚一缕仙光，小心翼翼地探向一条流淌过脚边的黑泥支流。</p><p>仙光接触，那黑泥竟如同活物般猛地一缩，发出“嗤嗤”的腐蚀声，法术瞬间黯淡几分。</p><p>她脸色微变：“好污秽！非毒非煞，却能侵蚀数据……乃至灵能本身！”</p><p>“阴伏流煞！就是它！俺的天元帝国……就是被这东西活活‘吃’掉的！”</p><p>土皇帝的声音抖得像筛糠。</p><p>当然，脚上的奔跑是不能停的。</p><p>“黑色的疫病，不断侵染万事万物的黑色！所过之处，灵脉枯竭，心智癫狂，连石头都会长出脓疮！俺亲眼看着俺的龙椅……化成了……化成了……呕……”</p><p>他声音里带着哭腔，上山下乡三个月磨砺出的些许沉静，此刻随着记忆复苏，而荡然无存。</p><p>阿巴看向59改：“罐，历史上人们是怎么处理这些‘阴伏流煞’？”</p><p>「无相关记录。」</p><p>「检索十万大山全域历史数据库，自‘天元帝国’建立至覆灭所有可考文献……」</p><p>「无任何关于‘阴伏流煞’的记载。该名词在公开及秘藏史料中……」</p><p>「出现频率：0」</p><p>十万大山当地所有历史文献记载中，从来没有出现过“阴伏流煞”。</p><p>“难道……它能吞噬现实，还能抹去自身存在的‘记录’？连历史文献都无法承载其名？”</p>
