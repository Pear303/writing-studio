# 涌现论

<p>所谓社会性，在诸多生物身上都有所体现，像狼群会集体狩猎，鸟类会成群迁徙，这些生物群体内成员间存在相互协作与交流。</p><p>但这种社会性相对松散，个体仍保留着较大的独立性，一旦群体利益与个体利益冲突，个体很可能会优先满足自身需求。</p><p>而“真社会性”则截然不同。</p><p>“史莱姆拥有的是‘真社会性’，而不是普通的假社会性。”伊芙说。</p><p>奥拓：“呃……有什么区别？”</p><p>真社会性生物具有更为紧密的群体联系，与高度分化的社会分工。</p><p>譬如蜂群里，蜂王专职产卵，工蜂承担采蜜、酿蜜、哺育幼虫、守卫蜂巢，雄蜂主要负责与蜂王交配。</p><p>这些真社会性生物群体内的个体，几乎完全放弃了自身个体的生殖等权利，一切行为都围绕着群体利益展开。</p><p>个体与群体紧密相连，生死与共，仿佛是庞大生物体的不同器官，你是脚趾、我是腿毛、他是牙龈，这个是盲肠，那个是头皮……共同维系着整个群体的生存与发展。</p><p>“从这个意义上来说，精灵、人类、矮人，都是假社会性的。”</p><p>奥拓不可思议：“难以想象……社会这个词，原本是用来描述我们。但没想到，人反而是假社会性，这些虫子反而是真社会性……”</p><p>人类是通过后天的“抽象叙事”能力，形成社会关系。</p><p>而真社会性的物种，则是它们的生理结构本身，就决定好了社会形态。</p><p>你是“腿长”一族，终身负责跑腿；他是“手粗”一族，终身负责打架……</p><p>这就是真社会性。</p><p>杨帝坐在车顶：“所以，你认为史莱姆集群诞生出了真社会性？”</p><p>伊芙点点头：“嗯，没错……不过，史莱姆的不同生理形态，不是通过先天遗传确定的，而是通过它们诞生时的环境确定的。”</p><p>史莱姆诞生在火山，就是熔岩史莱姆。</p><p>诞生在草原和森林，就是草史莱姆。</p><p>奥拓还是一脸懵逼的状态。</p><p>“但‘真社会性’算是一种智力吗？”</p><p>“好问题。”</p><p>伊芙将破碎的发卡攥在掌心，眼神变得遥远，仿佛回到了无数个研究史莱姆的日夜。</p><p>“真社会性本身不是智慧，但它为智慧诞生搭建了桥梁，打好了地基。”</p><p>伊芙咬着手指，“我该如何用简单的一个词或者一句话，来向你们解释那个概念呢……”</p><p>杨帝：“涌现。”</p><p>精灵呼吸倏地急促。</p><p>伊芙大吼：“涌现，真是个极妙的词！没错，单个史莱姆是没有智力，但是，无数史莱姆聚集在一起，形成庞大的集群，他们会第一步涌现出‘社会性’。</p><p>“但如果想要得到‘高等智能’，光是数量还是不够。庞大数量还需要结合某种秩序，也就是史莱姆的‘社会性’，规定史莱姆集群的运行秩序。</p><p>“此时，开始第二次‘涌现’，它们会像无数个精密运转的零件，在真社会性的框架下，自发地构建出超越个体能力的复杂行为模式……”</p><p>奥拓还是一脸懵逼的状态。</p><p>杨帝：“你认为这就是‘智力’？拥有‘复杂的行为模式和能力’，就是有智力的体现吗？”</p><p>地球青年举了个例子：</p><p>在一座任何探测器都找不到的昏暗小屋内，摆放着一部精灵语词典，词典中还包括了对世间绝大部分常用精灵语句子的回答选项。</p><p>屋子内坐了一个不懂精灵语的人类。</p><p>每当有精灵将写着问题的纸条从门缝塞进来，这个人类就会根据纸条上的精灵语，按图索骥在词典里找到对应的词汇。</p><p>再根据词典预设的规则，从回答选项中拼凑出一段回应，最后将纸条从门缝递回去。</p><p>从精灵视角来看，每次得到的回复都精准、合理，仿佛对面坐着一位精通精灵语的人类。</p><p>可实际上，这个人类既不理解问题的含义，也不知道自己给出的答案是什么意思。</p><p>他只是机械地执行着翻书、查找、抄写的动作。</p><p>“这个人类的行为，就像是史莱姆集群的复杂模式。”</p><p>杨帝坐在车顶一边把方向盘，一边说，“史莱姆们根据真社会性的‘规则’，组合出应对外界的行动，但也许……它们本身并没有理解这些行为的意义。”</p><p>奥拓还是一脸懵逼的状态。</p><p>伊芙轻哂：“和你聊天真有趣……为什么你会觉得，我们的‘智力’，与腔肠动物的‘条件反射’有不同呢？”</p><p>杨帝有些说不出来了。</p><p>在地球的人工智能领域，关于“智能”的定义权也已经争吵了数十年。</p><p>比如，符号主义学派坚信智能源于逻辑与符号系统，就像那间小屋中的人类，只要将世界的知识编码成精确的规则和符号，通过复杂的逻辑运算就能模拟出智能行为。</p><p>还有连接主义学派，沉迷于用海量神经元般的计算节点，搭建模仿精巧的人脑。</p><p>行为主义学派，则更关注智能在现实环境中的“行动”。简单来说——你只要会“做”就行了，我不管你是怎么“想”的。</p><p>伊芙应该属于“行为主义学派”。</p><p>她认为，大数量的史莱姆，能够在社会实践中逐渐学会高效的行为模式，而不执着于对“智能”内在本质的抽象探讨。</p><p>你只要表现得像个人就行了。</p><p>而你实际上思考方式是不是像个人，并不重要。</p><p>杨帝也无从反驳，毕竟这几个学派暂时不能分出对错，暂时比不出高低。</p><p>说不定，人类的“智力”和史莱姆的“条件反射”真的其实就是一回事。</p><p>只不过一个规模更庞大，另一个规模比较小罢了。</p><p>人类能做出的行为反应更多、更复杂，所以看起来智能更高级。</p><p>伊芙见杨帝不回答，她继续说：“你是否还是很困惑——它们始终没有个体意识，没有自我认知。就算行为再复杂，又怎能称之为真正的智慧生命？”</p><p>杨帝也只能默认伊芙的说法。</p><p>他还得专注开车。</p><p>随时警惕不知哪里可能会出现的教廷追兵、史莱姆势力。</p><p>“但是，自我认知就那么重要吗？”</p><p>伊芙反问，“人类的自我认知，难道不也是在社会环境中逐渐形成的吗？史莱姆集群通过紧密的联系和分工，或许也在以它们的方式‘认知’世界。就像人脑，单个神经元并没有意识，可无数神经元的连接与协作，却诞生了意识与智慧。史莱姆集群说不定也是类似的道理。”</p><p>奥拓举手：“等等，神经是什么？”</p><p>“……你就理解成，在我们脑子里，像树干一样蔓延分裂开来的细微树状物体。”</p><p>“真有这种东西吗？”</p><p>“要不我帮你开开颅。”</p><p>杨帝点点头，暂时认可了伊芙的说法。</p><p>毕竟地球的人工智能学界都吵了这么多年，也没出个结果。</p><p>于是他问出最后一个问题，希望能得到答案：“我们讨论了如此之多，问了史莱姆的真社会性与‘智能’的涌现，但最后还得落到那个终极的问题上——原初之眼，圣光教廷，他们要从哪里搞来这么多史莱姆？”</p><p>无论是史莱姆集群产生社会性。</p><p>还是在庞大数目中涌现出高等智能。</p><p>都有一个前提条件：你得有一大堆一大堆史莱姆，能够为己所用。</p><p>“对原初之眼而言，这反而是最容易解决的问题。”</p><p>伊芙问了个问题：你觉得哪里史莱姆最多？</p>
