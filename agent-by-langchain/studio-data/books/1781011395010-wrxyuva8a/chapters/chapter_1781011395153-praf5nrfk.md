# 十万大山城市群

<p>“你特么是给他盖了个数字版阿房宫！他能在里面接着挖山当皇帝玩到宇宙热寂。”</p><p>不知为何，阿巴脑子里闪过“阿房宫”、“秦”之类的概念。</p><p>她很生气。自己在上个宇宙疯狂修炼，都是随便找个阴暗的洞穴，一钻进去，山中无日月寒暑不知年。</p><p>他这个土皇帝，一下子就能住一千万平方光年面积的阿房宫。</p><p>不行。阿巴压抑住生气，强迫自己不要羡慕啦。她是修仙者，超脱红尘，这些凡俗的黄白之物，身外之事，怎能连累她的心境？</p><p>「资源消耗可控。」</p><p>「且沙盒内时间流速可调。理论上，他能在其中体验近乎永恒的‘帝王生涯’，直至其意识熵增彻底崩解，或……寻回部分稳定认知。」</p><p>59改简洁回应。</p><p>找这么大一个沙盒世界让土皇帝折腾，是一种精神疗法，或许能让他突然回忆起更多本不应该复现的记忆。</p><p>“啧，便宜这老小子了。不过也好，省得他出来添乱。让他自己在里面玩泥巴吧。”</p><p>实话实说，阿巴一点都不羡慕！</p><p>杨帝眼中有了些许兴趣。</p><p>“59改，他在做什么？”</p><p>「目前沙盒内‘天元神皇’活动状态稳定，主要行为模式为：重复性巡视赛博疆土，徒劳地试图挖掘虚拟山体，以及间歇性地对着天空发出含混的‘朕乃……无上……’等呓语。」</p><p>「认知混乱指数维持在阈值内，暂无进一步恶化迹象。」</p><p>59改补充道。那土皇帝的生活丰满又充实。</p><p>“这么说，他似乎真的存在智慧。”</p><p>「这得看杨帝阁下您对‘智慧’的定义。」</p><p>杨帝轻哂：“能够通过图灵测试便可。我并不重视‘智慧’的本质，只要他能表现出智慧的行为，那就是智慧。”</p><p>「那么目标‘天元神皇’是有灵智的个体。」</p><p>把有灵智的人塞进小岛大小的楚门世界，这叫囚笼。</p><p>但如果把他塞进一千万平方光年，这就是极致的人道主义。</p><p>既然59改本人认为没有占用多少运算资源，那就把土皇帝放进去住一段时间吧。</p><p>“行吧，至少暂时消停了。”</p><p>阿巴一点都不羡慕，“那咱们就准备下车，去会会那山顶上的‘堡’，看看里面到底是卖汉堡的，还是藏了叫作‘阴伏流煞’的邪乎玩意儿！”</p><p>随着一阵轻微的减速感传来，火车穿越了最后一段幽深的隧道。</p><p>刺目的白光涌入车窗，外界豁然开朗。</p><p>君士叹顶堡，到了。</p><p>列车平稳地滑入站台。</p><p>站台本身极具科技感，光滑的合金穹顶，悬浮的引导光带，无声穿梭的清洁机器人。</p><p>抬眼望去，整座城市依附着那座名为“君士叹顶”的、几乎垂直插入云霄的巨峰而建。</p><p>城市结构是分层的，下层是密集的工业区，巨大的管道如同血管虬结。</p><p>中层是灯火通明的商业与居住区，全息广告在玻璃幕墙上流动。</p><p>最上层，则是凡界的经典城建——反重力浮空建筑群。</p><p>阿巴至少有一点猜测是对的。</p><p>这座城市，真的有卖汉堡。</p><p>循着味道望去，站台转角处赫然立着座红白色相间的招牌，巨大的上校头像笑得和蔼可亲，招牌下方“肯打鸡”三个发光大字正一闪一闪地变换着霓虹色彩。</p><p>一人一鱼一狐一坦克，再加一个土皇帝存储在59改的脑子里，一同下车。</p><p>还未出门，潮湿的山风——是的，在钢铁丛林里的潮湿山风——裹挟草木腥气灌进车厢。</p><p>眼前是一个新世界。</p><p>十万大山深处的巨型都市，在云雾中若隐若现。钢筋水泥的建筑群，与原始山林奇异地交融着。</p><p>此地即使与凡人王朝最繁华的地带，隔绝于数千公里深山之中，但也在数百年前也引进了外界的反重力技术，建起规模庞大的浮空城市群。</p><p>古老的吊脚楼残骸嵌在摩天楼墙体里，玻璃幕墙反射着原始森林的绿意。</p><p>仿佛有人强行将两个时代的碎片塞进同一幅画框，原始与科技以撕裂感共存。</p><p>连空气里，都混杂着雨后泥土腥气，和芯片硅脂煮熟的焦味。</p><p>很难想象到，在五个世纪前，这座超级城市还是几座城邦、百来个郡县、上千条村落，组合而成的封建国度。</p><p>现在随着外部资金、人才、技术的涌入，十万大山已不再是贫穷与偏僻的代名词。</p><p>五百春秋等闲过，荒城一夜起雄关。</p><p>十万大山的繁荣，其实是凡界王朝的繁荣。</p><p>青丘白璃走在前头，一边介绍道：“而凡界王朝的繁荣，则来自持久的和平。但其实，凡界和平背后还有更深刻的含义……”</p><p>和平与战争，繁荣与萧条。</p><p>凡界的社会状态，实质上是灵界政治生态的晴雨表。</p><p>灵界的数万年前，因为域外天魔入侵越来越猛烈，灵界三大种族，人族、妖族、灵族不得不捏着鼻子，团结合作。</p><p>但利益分配争端——是不可能消失的。</p><p>所以他们利用凡界，打热战、冷战、温战，作为某种程度上的代理人战争。</p><p>你麾下势力的某某国度赢了一回仗，那么我就将XXX的占有权转让给你。</p><p>他控制的某某商团吞并了你的超级财团，那么你就得把YYY的开发权双手奉上。</p><p>把凡界当作沙盘游戏，灵界各大势力愿赌服输，以此维持虚伪的和平。</p><p>灵界的数千年前，凡界的二十多万年前，归墟大帝横空出世。</p><p>于是，灵界众修士不能出手干预凡界了。</p><p>即使是“人前显圣”这类几乎难以改变历史进程的间接干预，也被全面禁止。</p><p>因为归墟大帝亲自下了死命令：不允许灵界干涉凡界内政，除非是经济援助，或者凡界出现因不可抗的自然因素导致的灾害等特殊情况。</p><p>一旦被他发现违反戒律，杀无赦。</p><p>天上一日，地上十天。</p><p>虽然没有了仙家力量干涉，但凡界各个势力仍然因先前持续千百万年的战争，而相互敌视，结下的血海深仇尚未化解。</p><p>广袤的土地上，灵界曾经造成的影响不可能瞬间杜绝，而是还在延续。</p><p>但矛盾的坚冰并非不可消融，就像十万大山的云雾终会被朝阳驱散。</p><p>没有了灵界操控，凡界开始在炊烟与商道间另寻出路。</p><p>昔日战场化为农田，锈蚀的甲胄熔铸犁铧，那些刻着血誓的战旗，如今在市集上成了晾晒布匹的支架。</p><p>仇恨是刻在石碑上的旧铭文，而生活却是不断生长的新藤蔓。</p><p>只要没有脑子染性病的事逼、成日妄想再招一核的沙比在那儿成天揣着百草枯乱喷，假以时日，藤蔓终会顺着裂隙爬满整面石墙，掩盖砖面下的旧伤疤。</p><p>幸好，凡界没有碰上脑子染性病的事逼，慢慢走向和平，团结，繁荣，昌盛。</p><p>生产力不断发展，技术不断突破，人文关怀成为社会主流思潮。</p><p>甚至连“十万大山”最深处的聚落，也在凡界王朝发展的浪潮中脱胎换骨。</p><p>就连“肯打鸡”这样的喵麒麟三星餐厅也随处可见。</p>
