# 无上神机或天元神皇？

<p>相由心生。</p><p>在杨帝认知里，自己确实是个不可名状的怪物，各方面属性突破可观测宇宙。</p><p>当六边形的6个角都捅穿了世界，59改就得开始发愁：如何在虚拟会议厅内表现出杨帝的形象？</p><p>他的硬盘塞不下还原度达到99%的杨帝。</p><p>如果要和现实的还原度达到99%，那么杨帝的各项数值和属性，会导致59改数据溢出。</p><p>随即大脑宕机。</p><p>最终，59改用了个聪明的伎俩。</p><p>——那就是将杨帝的形象“降格”，搓成一坨不断变换的线条和马赛克。</p><p>把他的还原度，降到98%以下，虚拟会议厅就能流畅运行了。</p><p>那么，这个自称“天元神皇”的数字生命，其形象该如何处理？</p><p>相由心生。土皇帝表现出来的形象，是半个人类的身子，以及一条机械蠕虫似的盾构机。</p><p>那由人类躯干和锈蚀盾构机核心强行糅合的“天元神皇”，在目睹自身缝合怪的本质后，陷入剧烈的认知混乱。</p><p>他的马赛克脸扭曲着，发出意义不明的电子尖啸和含混的方言咒骂。</p><p>仿佛两个截然不同的意志，在争夺这具躯壳的控制权。</p><p>“铁罐，是不是你新装修的这虚拟会议厅是豆腐渣工程，甲醛太多，所以他才陷入疯狂！”阿巴指责。</p><p>59摇摇头「目标精神波动紊乱，认知结构呈分裂态。这是‘赛博精神病’的一种发病症状。」</p><p>「建议启动‘拷问’协议，尝试稳定其核心信息流。」59改冷静地分析，虚拟战车的炮塔象征性地微微转动，瞄准了那团混乱的“神皇”。</p><p>简单来说，他打算刑讯逼供。</p><p>“省省吧铁罐头，对付这种玩意儿，青青更有经验。”阿巴将青丘白璃放到数字生命身前。</p><p>五九、阿巴看向狐狸。</p><p>她咽了口唾沫，有些紧张。</p><p>她被作为导游推出来，尝试用爱与正义感化白杨大帝，而且对此界历史有一定了解。</p><p>杨帝那团不可名状的存在体微微“蠕动”了一下，算是默许。</p><p>祂散发出的精神波动如同无形的深海，虽已收敛，却依旧让整个虚拟空间的数据流都带着一丝粘滞的沉重感。</p><p>“呔！那山沟里的土鳖！”</p><p>青丘白璃的声音带着一丝威严，如同审判，“报上汝之真名！莫再以‘孤’‘朕’这等虚妄之词污了此地清净！”</p><p>“放肆！孤乃天元……”</p><p>那“神皇”挣扎着，挺起他与盾构机相连的胸膛，试图维持最后的尊严。</p><p>但声音却在接触到杨帝那无声无息的“注视”时陡然变调，带上了无法抑制的颤抖，“朕……朕乃十万大山之主！尔等刁……刁民安敢犯上！”</p><p>“老大，他好像还没搞清状况哦？谁才是被困在这铁疙瘩里的‘刁民’啊？”</p><p>阿巴那条肥美的大鲈鱼吐了个泡泡，精准吐槽。</p><p>“肃静！”青丘白璃三十六条狐尾一甩，“本座且问你，汝之疆土几何？子民几许？可有户部鱼鳞册为凭？”</p><p>“疆土……疆土……”</p><p>“神皇”的马赛克脸显出迷茫，眼神空洞地扫视着周围由0和1构成的虚拟墙壁，仿佛在搜寻他记忆中的十万大山。</p><p>他不记得了，好像。</p><p>“层峦叠嶂……无穷无尽。子民……百万……”</p><p>“你真当过土皇帝吗？”</p><p>天元神皇似乎被戳中痛处，马赛克脸涨红，“孤……孤有火铳铜钱！孤……孤能挖山！对！孤乃无上神机！挖通天地，再造乾坤！”</p><p>无上神机，指的是身子下方这台盾构机。</p><p>他似乎混淆了“人”和“机器”，分不清自己是什么。</p><p>“你怎么又成无上神机了？你不是自称天元神皇吗？”</p><p>“对……不是……孤不是无上神机……孤是……天元神皇……”</p><p>他喃喃自语，声音充满了惊恐和困惑，仿佛在说服自己。</p><p>他低头看着自己锈迹斑斑、与冰冷机械相连的“龙体”，又抬头看看那不可名状的杨帝、法天象地的狐妖、毁天灭地的坦克，还有那条会说话的肥鲈鱼。</p><p>最后，他的目光定格在自己那双半是血肉、半是金属关节的手上。</p><p>“朕……朕是不是……一台机器？”</p><p>他茫然地抬起头，马赛克脸扭曲成极度荒诞的表情，有帝王的最后一丝倔强，又混杂对自身存在本质的、无法理解的恐惧，“一台……能当皇帝的……盾构机？”</p><p>“也可能是一个土皇帝投胎成盾构机。”</p><p>“谁是我？我是谁？我在哪？我到底要干什么……我分不清！！”</p><p>土皇帝抱着脑袋扭曲起来。</p><p>“又疯一个。封建余孽加赛博精神分裂，没救了，埋了吧。”阿巴叹息摇头。</p><p>「他的记忆单元在方才的EMP爆发中损失太多，产生了严重的混乱，导致他的认知体系彻底崩塌。」</p><p>简单而言，就是失忆+人格分裂。</p><p>一股神州国产狗血恋爱霸总电视剧的味道。</p><p>“关键问题来了。”</p><p>杨帝那团不可名状的蠕动存在，伸出一根手指，指向那团数字生命，“一个五百多年前，躲在十万大山里作威作福的土皇帝，凭什么能跨越如此漫长的时光，出现在这里？并且，是以这种半人半机的诡异形态？”</p><p>《重生之我是秦始皇，驾驶SSS级挖掘机大战域外天魔》？</p><p>这个问题瞬间打开了众人话题的闸门。</p><p>阿巴点点鱼头：“500年，这老小子应该早就烂成泥巴了。就算他真有点什么邪门歪道延寿的法子，在凡界这种灵气稀薄的地方能做到吗？还把自己塞进一台盾构机里？有点重口。”</p><p>其实阿巴早就想提出这个显而易见的疑点。</p><p>但她最后还是憋住没说出来，把机会让给领导。这就是职场生存哲学。</p><p>青丘白璃的狐狸爪子优雅地摩挲着下巴，陷入沉思：“凡界寿元有其极限，纵使有些旁门左道的延寿之术，也绝难突破五百年大关。</p><p>“何况，将自身意识与如此庞大、精密的机械造物融合……这绝非凡间手段。</p><p>“五九改先生，这台盾构机有无特殊之处？它的来历、编号、建造时间？”</p><p>59改比青丘白璃年长，这点从面相可以看出来，所以称他“先生”。</p><p>他在虚拟会议厅中的形象，是一辆二十五对负重轮的满级坦克。</p><p>59改睁开眼。</p><p>「目标载具型号：‘地龙-10型’重型灵能盾构机。」</p><p>「建造记录显示，其于114年前，由‘新长安重工集团’生产下线，序列号唯一。」</p><p>「服役记录显示，它主要参与‘十万大山’支线隧道贯通工程，于104年前，在执行‘支线隧道贯通工程’任务时失控失联。」</p><p>“104年前？”</p><p>“但这土皇帝自称是‘解放前’的，那至少是五百多年前的事了！”</p><p>阿巴立刻抓住矛盾点，“时间对不上。他要么是五百年前的人，要么是一百多年前的机器，怎么能搅和到一块儿？”</p><p>“这台盾构机在失联期间，进入了某个……能扭曲时间或者封存意识的地方。比如十万大山深处，有传说中的上古遗迹？”</p><p>“或者，是某种力量，将五百年前那个土皇帝濒死或残存的意识，从时间长河中捞了出来，然后强行塞进了这台在一百多年前建造、几十年前失联的盾构机里？”</p><p>如果没有新情报，这样讨论是讨论不出事情的。</p><p>但59改恰好有新发现。</p>
