# 突围！……

<p>杨帝的六感、精神都承受着极大负担。</p><p>既要关注着环境变化、敌人动向，又要维持着两秒17发混杂旋风术、驭火术的奥术飞弹。</p><p>普通人的潜意识与表层思维隔离，他们就算想“读取”潜意识的内容，都不可能。</p><p>而杨帝将10%潜意识上浮，但并不意味着，他必须每时每刻都“读取”这10%潜意识内容。</p><p>他可选择“读或不读”。</p><p>“不读取”的时候，减轻精神负担，相当于休息。</p><p>选择“读取”，则是全盛状态，近乎神性！代价是痛楚。</p><p>直视耶罗大仙后，最初的一个月，是最痛苦的一个月。</p><p>那个月，杨帝浑浑噩噩，不只是因为友人逝去、世界忘记了他，让他心灰意冷。</p><p>更是因为，他还没能学会如何选择“读或不读”10%的潜意识。</p><p>六感接收的信息、资讯、情报，轰炸着他的大脑皮层。</p><p>200米外的一声蛙叫，100米外红绿灯闪烁，50米外全险半挂驶过引发的震颤，20米外的飞虫振翅，环境中数以百万计的微小动静……</p><p>都被杨帝毫无保留地觉察。</p><p>都毫无保留地涌入他脑子里。</p><p>整个世界被清晰地塞进脑子，这可以说是进化的阵痛，也可以说是恐怖的折磨。</p><p>而后他才慢慢适应，并且学会对海量信息如何“不读取”。</p><p>但那时候，他的物质思维器官大脑，也已经进化到适应海量信息轰炸，习惯每时每刻剧烈的痛楚了。</p><p>取消“全部读取”，只是因为习惯做平凡简单的自己。</p><p>而现在，为了最大程度调用环境中的灵能，以对抗冒牌卡利斯托。</p><p>杨帝再度选择了“读取”全部。</p><p>当他将感知提升到极致，敏锐的精神力如同细密的蛛丝，渗透到周围每一丝灵能波动之中。</p><p>这才发现，眼前的卡利斯托虽外表看上去天衣无缝，每一个动作、每一声咆哮都充满了昔日苍穹霸主的威严与恐怖。</p><p>但内在却是个冒牌货。</p><p>它的灵能波动紊乱而诡异。</p><p>像是被某种邪恶力量强行拼凑、激活的一具空壳，徒有其表，败絮其中。</p><p>缺失了真正属于焚灭天空之龙的精神，仅仅是只龙形的“弗兰肯斯坦”。</p><p>如果只有这一条假龙，那一切都还好办。</p><p>但现实情况不是。真正让杨帝感到棘手的，是山壁上围的一圈法师。</p><p>他们看似只是在一旁掠阵，实则每个人身上都隐匿着深不可测的力量。</p><p>这些术士的总体实力，竟远超那冒牌的卡利斯托！</p><p>他们的灵能相互交织，形成了一个巨大的灵能网络，将瑞弗维尔二人牢牢困在其中。</p><p>他们太谨慎了，没有选择正面上来硬刚，而是坐山观虎，像斗蛐蛐一样旁观，让赝品·卡利斯托持续消耗杨帝二人，自己则在安全地带伺机而动。</p><p>杨帝快撑不住了。</p><p>他掏出一块棱角分明的砖头，以0.3马赫的超级慢速度掷向山壁上的某人！</p><p>“砰——”</p><p>意料之中，那些人迅速支起发光的护盾屏障，挡住了他投来的动能炮弹。</p><p>“有戏。”杨帝却嘴角微微扬起。</p><p>他特地用0.3马赫的速度扔砖头，发现——那厮架起护盾的速度，太慢了。</p><p>维持护盾似乎需要消耗灵能。</p><p>异世界土著施法，需要消耗大量体内的灵能，做不到直接调用环境中的灵。</p><p>所以，经过与山壁上的术士几次冲突，杨帝很快推演出“异界土著魔法对战”的简单模型：</p><p>放波→支起护盾格挡→放波……</p><p>灵能必须实现最大性价比利用，必要的时候再支起灵能护盾。此事在《辛逝纪的我带领西红柿与茄子徒弟重走讨伐魔王路！》亦有所记载。</p><p>所以，会有一个反应时间，一个护盾空档期……</p><p>杨帝继续两秒17发奥术飞弹，与冒牌·卡利斯托秦王绕柱走。</p><p>他似乎速度越来越慢，奥术飞弹的释放频率也越来越低。</p><p>有好几次，那卡利斯托都看起来、将近要把他抓住了……</p><p>某一时刻，杨帝一个踉跄，跌入黑暗阴影之中。</p><p>“吼吼吼！”弱化版巨龙咆哮着扑去。</p><p>它庞大的身躯，阻挡了山壁上其中几个术士的视野。</p><p>有那么短短0.5秒，杨帝脱离了他们几个的视线掌控。</p><p>而就在这视觉死角，三块砖头掷出，尾部跟随着一圈接一圈的音爆云——</p><p>1.5倍音速！！</p><p>砖头被附魔了，和“杀手兔”同款的速度类型附魔！</p><p>那三个术士的反应速度，即使和锻炼肉身素质的狂战士比起来，也算非常快了。</p><p>但还不够……</p><p>天下法术无坚不摧，唯快不破！杀手兔之所以被称作“杀手兔”，自有其道理。</p><p>而在那三个法师的护盾凝聚成形前50毫秒，三块1.5马赫的砖头，距离他们的鼻尖只剩10厘米不到。</p><p>“砰砰砰——”</p><p>三声闷响几乎重叠成一声，那三个术士瞬间被高速飞来的砖头砸得头晕目眩，身形摇晃。</p><p>护盾还未来得及完全凝聚，就如同脆弱的泡沫般破碎消散。</p><p>趁着山壁上的术士陷入短暂混乱，防空网出现缺口，杨帝看准时机，一个箭步冲到瑞弗维尔身边！</p><p>一把将他抄起，扔到熔岩史莱姆上。</p><p>瑞弗维尔还没来得及惊呼，杨帝已然双手舞动，再次手搓十几个旋风术。</p><p>刹那间，狂风在火山底部肆虐而起，强大的气流以杨帝为中心疯狂旋转，卷起地上的尘土和碎石。</p><p>熔岩史莱姆在狂风的托举下，带着瑞弗维尔缓缓升空。</p><p>杨帝紧紧抓住史莱姆的边缘，与瑞弗维尔一同被这股旋风裹挟着向火山口冲去。</p><p>火山口近在眼前！</p><p>“嚯嚯嚯！杨帝！牛哔！我们安全了！”</p><p>瑞弗维尔兴奋至颠，完全没有了宫廷图书馆馆长的风范。</p><p>一向冷静的杨帝，首次大惊失色：“哇！不要立Flag呀！”</p><p>但已经晚了。</p><p>在觉察到那股直刺天灵盖的庞大危险降临前一刻，杨帝以比WX抢红包还快十倍的手速在他们头顶架起20层灵能护盾。</p><p>但下一个刹那，20层护盾……轰然破碎。</p><p>“砰——！！！”瑞弗维尔完全看不清发生了什么，便从天而坠。</p><p>直到烟尘散去，他才看清出现在他们头顶的来者。</p><p>“第二席红衣主教！他叫那个谁！”瑞弗维尔刚刚燃起的希望之火瞬间被浇灭，心如死灰。</p><p>红衣主教有十二席，数字越小实力越强！</p><p>他们每个季度都会开展排位天梯重启、末位淘汰制度，确保这十二人在教廷中，是除教皇之外对圣光理解最深刻的大能！</p><p>瑞弗维尔曾直面第九席主教。</p><p>二人的差距，只能用鸿沟形容。</p><p>而第九席与第二席，差距也是鸿沟……</p><p>瑞弗维尔的力量与其相比较，就不是简单的鸿沟了，而是鸿沟的平方。</p><p>当下，杨帝趴在一旁，脑袋裂成八瓣。</p><p>他已没有声息，没有动静，没有举起手比个“OK”。</p><p>他脑袋虽然还算完整，没有东一块西一块，但这个惨状……就算是近战法师也不可能……</p><p>情势急转直下。</p><p>一下子从天堂堕到地狱。</p><p>“竟未能一击湮灭尔等，此人（杨帝）头甚铁矣……”第二席红衣主教说话，是莎士比亚的风格。</p><p>瑞弗维尔将手伸进风衣内层，几乎就要将石头眼睛雕像掏出来……了……</p><p>能不用就不用。但如果真没办法，那就得果断地用！</p><p>但下一刻，异变再起。</p><p>瑞弗维尔的手完全愣住——</p><p>他闻到一种香甜的气味。柑橘味。</p><p>一道金色与青绿色相间的身影，从天而降！</p>
