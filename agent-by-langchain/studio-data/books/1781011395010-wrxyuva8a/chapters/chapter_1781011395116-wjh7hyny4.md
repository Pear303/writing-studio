# 因果律问题

<p>圣树曾在“过去”，见过来自“现世”的伊芙和杨帝。</p><p>所以它知道，此二人有能力承受穿越时间带来的未知副作用。</p><p>否则它不可能在过去，见到未来的二人。</p><p>但此处就引出另一个诡谲的结论——圣树之所以会让伊芙、杨帝穿越时空，是因为它在过去看见穿越成功的二人；而二人之所以穿越时间，则又是因为圣树目睹他们穿越成功，所以对他们使用了“机兵-时间机器”的一次性权限……</p><p>互为因果，循环论证。</p><p>“时间穿越……不会打破因果律吗？”</p><p>这是困扰伊芙与杨帝已久的问题。</p><p>时间穿越会整出大把问题，譬如祖父悖论。</p><p>假设杨帝穿越回1970年，在父亲出生前杀死自己的祖父。没有祖父就不会有父亲，没有父亲自然也不会有杨帝，那又是谁穿越回去完成了这场谋杀？</p><p>就像条咬尾的蛇，永远困在自相矛盾的闭环里。</p><p>地球后世的科学家、哲学家也提出诸多解决方法。</p><p>比如自洽性原理：穿越回去，却没有发现自己的祖父。然后自己成为自己的祖父，和尚且年轻的祖母生下自己的父亲，父亲再生下未来的自己……以此形成因果闭环。</p><p>“狗血，堕落。”伊芙如此评价道。</p><p>杨帝耸耸肩：“那我们现在应该……做什么？你知道的，在外人看来，我们是突然出现在了圣树地域内。”</p><p>二人向四周看去。</p><p>已经有数十个原始社会的精灵，手持刀剑与弓矢，对准突然出现在圣树身边的杨帝和伊芙。</p><p>伊芙看起来是个金毛尖耳朵精灵，身上也有相当于身份ID的柑橘味体香。</p><p>但她是黑户，ID用不了。</p><p>至于杨帝，更不用说了，明显是个人类。</p><p>虽然他身上没有那种人类特有的臭味（圣古琉斯人体味大），但怎么看都是比另一个陌生精灵可疑百倍的不速之客。</p><p>在场80%的弓，都指向杨帝。</p><p>“这里可真是和平啊……”伊芙眼角发红地看向四周。</p><p>没有漫天的熔岩与烈火，没有震耳欲聋的爆炸，四周围精灵身上也没有沾染血与泥沙。</p><p>“诸位请问，今夕是何年？”伊芙将法杖杵在地上，举起双臂，一副人畜无害的模样。</p><p>“金枝2025年。”有个声音弱弱地说。</p><p>“金枝？”伊芙虎躯一颤，“那是四万多年前，久远到第一纪元还没开始的时候……”</p><p>她转身看向圣树——此举吸引了在场另外20%的火力瞄准。</p><p>但仍然有60%的精灵对杨帝虎视眈眈。唉，种族骑士。</p><p>“伊芙，你动作不要那么大。”</p><p>“杨帝，有问题。这棵圣树……不是我们现世的圣树。它不会说话。”</p><p>这下连杨帝也为之侧目。</p><p>顿时90%弓弩刀枪剑戟斧钺钩叉对准杨帝。</p><p>“难道……伊芙，解决祖父悖论有另一个方案，不是狗血剧情，而是‘平行宇宙’。”</p><p>假设世界是一条主干道，他们并没有穿越时间回到“金枝纪元”，而是到了另一个平行世界。</p><p>面前这棵圣树，或许是某个平行时空中，尚未觉醒意识的原始形态。</p><p>伊芙下意识想做出捏下巴的思考动作，最后还是维持了高举双手的动作。</p><p>她低声道：“不，不是那种‘还未进化完全’的不同，而是一种更本质的差异——无论给眼前这棵圣树多少时间，它都不可能进化出我母亲的智慧与情感……它们本质上并非同一棵树。</p><p>“它们外形也完全不相像……你看，就连最基本的树品种都完全不一样！这棵是榕树，现世的圣树母亲是橡树！”</p><p>伊芙指着圣树扭曲如蛛网的枝桠，原本记忆中圣洁舒展的树冠，此刻的暗紫色树皮上布满鳞片状凸起。</p><p>难道说，他们精灵的母亲也会“变态发育”。</p><p>还是幼苗的时候是品种甲，长大后就是品种乙……</p><p>“如果圣树母亲认定‘时间穿越适配’的方法，是看‘它是否在过去见过未来的人’……虽然我们现在确实穿越到了四万多年前，但这根本不是同一棵圣树，并不能构成因果闭环。”</p><p>“也就是说……”</p><p>“平行世界理论，有正确的嫌疑……”</p><p>伊芙和杨帝的交谈，被极远方的不和谐噪声打断。</p><p>所有精灵同时竖起耳朵。</p><p>大地在震颤，天空在呜咽。</p><p>如果他们足够心细，会看到两百米外停靠在橡树新芽尖儿上一只蚜虫的蜡质绒毛翅翼末端一滴极小的水珠被大地的震颤抖落。</p><p>而震颤的来源是圣树森林之外——西边丘陵，南部海洋，北方山脉，东面原野，以及天色急剧暗淡、随后骤然爆发出橙红色炽热火光的苍穹。</p><p>敌人，从四面八方而来。</p><p>除了一个地方。大地之下。</p><p>杨帝福至心灵，掏出矮人奥拓昏迷前递给他的附魔狱髓钻头。</p><p>“伊芙，‘圣树屏障’不可能仅仅守护住东南西北四个方向以及上方天空。包括地下，也在圣树屏障的防御范围内，对吧？”</p><p>“没错……”</p><p>如果地下没有圣树的防御护盾，那么早在杨帝开着轿厢赶来之时，那些从地幔爬出来的熔岩史莱姆早就挖地道攻入精灵老巢了。</p><p>此刻，周围的精灵慌乱起来。</p><p>“太好啦！不知那是什么东西！但我们死定啦！”</p><p>“圣树没有回应！要启动那个吗？”</p><p>“那个？难道你是说……”</p><p>“圣树母亲刚刚发明的‘自适应护盾’……”</p><p>趁着这群年轻的精灵军心大乱，杨帝手中狱髓钻头已没入地表。</p><p>钻头旋转时掀起泥土，则被伊芙用法杖凝成的风盾卷向空中，形成遮天蔽日的尘雾，掩盖二人鬼鬼祟祟的踪迹。</p><p>在“效率V+耐久III+丝绸之触”加持下，钻头挖土效率比热刀切黄油还迅猛！</p><p>二人顺着螺旋形的土洞迅速下潜。</p><p>“等等。”伊芙突然按住杨帝手腕。</p><p>钻头戛然而止的瞬间，上方传来精灵慌乱的脚步声。</p><p>杨帝屏息凝神，却听见头顶传来布料摩擦声——有人在他们刚挖开的洞口边缘窥探。</p><p>伊芙指尖泛起柑橘色微光，杨帝立刻会意。</p><p>当那个精灵探头的刹那，两人同时发力。</p><p>钻头猛地向上突刺，伊芙生出藤蔓缠住对方脚踝，将其倒吊进洞里。</p><p>杨帝眼疾手快捂住对方嘴，却发现是个满脸雀斑的精灵少年，腰间别着的箭壶还沾着露水。</p><p>“别杀我！”少年呜呜挣扎。</p><p>伊芙和杨帝对视一眼。伊芙随手一击劈砍在他脖颈的侧后方——连接脊椎和脑袋，布满神经与血管的节点。</p><p>将精灵少年扔到地面上，钻头再次启动。</p><p>“杨帝，你说，我们能救所有人吗？”</p><p>杨帝微微扭头：“我们会穿越到一切开始之前，将罪魁祸首杀死。”</p><p>“不，我是在想你的那个什么……平行宇宙和时间线猜想。”</p><p>“伊芙，你想到了什么？”</p><p>“我很害怕。也许就算我们成功了，会不会实际上，只有我们所处的、当下的、这一个平行宇宙获得了解放，在我们看不到的地方，还有亿万个超越现实之外的人们，无数个真实存在的平行宇宙的人们，还深陷炼狱……”</p><p>杨帝暂时停下钻头，打断她。</p><p>“伊芙，那我告诉你第三个解决因果律冲突的假说吧，冲淡‘平行世界假说’成真的概率，你认为如何？”</p><p>虽然颇有精神胜利、鸵鸟主义的嫌疑。</p><p>但在地下阴瑟瑟的坑洞内，伊芙轻轻点头。</p>
