# 铁匠

<p>伊芙作为“脱离文学拥抱理工的精灵”，对人文社科理解并不太深，也就人类硕士水平。</p><p>但她能隐约感觉到，奥拓有水平。</p><p>这不是普通矮人！他有机会和自己进行平等的学术交流。</p><p>她很喜欢矮人中的学者。</p><p>伊芙认为，矮人学者是“身残志坚”的体现。</p><p>暂且不提观点是否含有种族主义成分，总的来说，这是伊芙对另一个矮人的超高评价。</p><p>而杨帝，他第六识“意识”所代表的感知“灵感”，则捕捉到一束转瞬即逝的闪光：</p><p>“灵能”代表的是“现实丰度”，也就是度量所含「现实」的多少。</p><p>“附魔”，是将某种灵能固定进器具。</p><p>也就是为器具赋予更多「现实」。</p><p>所以附魔这一行为，其实和销售员吹“钻戒代表永恒”是同一性质。</p><p>——都是对一件事物，赋予一种本不属于它的「现实」。</p><p>在比较物质的世界，就是“符号价值”。在比较唯灵主义的世界，则被称作“灵能附魔”。</p><p>杨帝对「灵能」的理解已经比较深入。</p><p>经过这几天伊芙的调教，他已习得大部分1~6环法术！</p><p>部分4~6环中阶法术还未精通，但也已能磕磕绊绊地施放。</p><p>这个速度不能说是恐怖，只能说是恐怖如斯！</p><p>而现在，他的新目标是“附魔”。</p><p>杨帝在与瑞弗维尔相遇的前几天，就曾请教过附魔知识。</p><p>奈何这位图书馆馆长自己也不懂。</p><p>瑞弗维尔毕竟不是工匠，也就懂得些皮毛理论，实操方法一概不知。</p><p>杨帝也问过伊芙。</p><p>有些意外，这位活了不知多少岁的精灵，她也说自己不会。</p><p>“师傅，你不是说你拥抱理工科了吗？附魔应该是工科的吧。”</p><p>“杨帝，这么说吧，就算是你师傅，也有很多不懂的东西，所以要永远保持敬畏。”</p><p>现在，终于遇到个擅长附魔的矮人，杨帝不会放过这个机会。</p><p>“如果买下了镇民的东西，会怎么样？”杨帝问道，表现出很关心的样子。</p><p>奥拓止不住地摇头：“别买，会后悔——你会成为这件物品的新宿主。”</p><p>“如果只是一件物品扔不掉，似乎也并没有那么恐怖。”瑞弗维尔插话了。</p><p>奥拓点头：“说的没错，所以如你们所见，这镇子大概也就二三十个人渴求着要卖掉物品，只占砾石镇几百号人的不到一成。”</p><p>“其他人呢？”</p><p>“认命了呗，反正东西扔不掉，只是超级不方便，但又不是不能活着。”</p><p>生活还要继续的。</p><p>不能因为身上有个抛弃不掉的砖头、锄头、锤头，就对这个世界说拜拜。</p><p>奥拓领队、伊芙隐形，二人配合下，在小镇角落，他们看到了那家铁匠铺。</p><p>一旁是两三户平常人家。</p><p>几个上了年纪的人类，有男有女，各自抱着剪刀、车轮、鱼竿等物品，在老槐树下谈话。</p><p>“镇北那边有些热闹。”</p><p>“听说有乡毋宁。”</p><p>“那帮小伙子还不死心，想摆脱诅咒。”</p><p>“有激情也好。这就是青春啊，李！”</p><p>绕过正在树头下指点江山的老头老太太，一行四人来到砾石镇唯一的铁匠铺。</p><p>铺子的门半掩，里面传出“叮叮当当”的打铁声。</p><p>奥拓停下脚步，左右看了看，才示意大伙进去。不知道的还以为在拍碟中谍。</p><p>铺内弥漫着一股炽热气息，炉火熊熊燃烧，将四周映照得通红。</p><p>他打手势示意众人不要轻举妄动。</p><p>他很轻微地掀开兽皮门帘……然后……</p><p>“咻——！！”</p><p>一柄烧红的铁钳擦着奥拓耳朵飞过。</p><p>杨帝下意识百分百空手接铁钳，下一刻他听到皮肉滋滋作响。</p><p>自己耐热性高，但再摸多几分钟就要轻微烫伤了。</p><p>铁匠铺里那矮人，动的是真格。</p><p>虽然瞄准的是奥拓脸颊，但只要擦过，至少也得烫掉块皮。</p><p>众人朝里看去，那是个男性矮人。</p><p>矮人本就发须旺盛，此刻，炉火旁的老矮人更是须发皆张，活像头炸毛的狮子。</p><p>他近乎咆哮对眼神躲闪的奥拓吼道：</p><p>“你个逆子！居然敢偷老子那倒霉玩意！这么多天你死哪儿去了！”</p><p>老矮人怒吼，挥舞锤子朝奥拓冲来。</p><p>奥拓吓得脸色苍白，避到杨帝身后。</p><p>“那啥，你们家庭矛盾还真是激烈。”杨帝也只好笑笑道。</p><p>矮人铁匠一个急刹，锻锤没有砸到他脑袋，而是落到地上，崩飞大片泥砖。</p><p>伸手不打笑脸人，特别还是客人。</p><p>杨帝也大概明白了——奥拓带他们回砾石镇，大抵是为了用“贵客”当挡箭牌，应付他老爸。</p><p>“客人？里边坐里边坐。”</p><p>老矮人比川剧变脸还猛，一瞬间就收好锻锤和铁锨，招呼众人进屋。除了奥拓。</p><p>奥拓灰溜溜跟在杨帝身后，一同进了屋。</p><p>……</p><p>老矮人的待客之道堪称典范。</p><p>他粗糙大手在围裙上擦了擦，转眼间就从柜台底下，摸出整套锡制茶具。</p><p>炉火映得他鼻尖发亮的汗珠都透着友善。</p><p>“来，岩茶配无花果松饼，各位贵客尝尝我们砾石镇特产。”</p><p>没想到这摸金校尉发丘将军搬山道人卸岭力士牛鬼蛇神稽首汇聚的镇子，也会有自己的土特产。</p><p>杨帝接过茶杯，发觉他手很粗粝，那双手被岁月与铁火反复锻造过。</p><p>掌心与指腹布满厚茧，手指关节粗大且微微变形，指甲缝里残留难以洗净的黑灰，手背上青筋如老树的根须般盘错蜿蜒。</p><p>便能看出老矮人一生都与铁匠铺为伴。</p><p>但他下一句话让众人差点喷茶。</p><p>“我的贝斯被逆子卖了，请见谅啊。”</p><p>贝斯？是指那种没声音的乐器？</p><p>眼前这毛发浓密，身形粗犷，但身高不到1米3的老矮人，真的很难让人把他和“音乐”联系在一起。</p><p>“父亲，其实我……”奥拓刚开口。</p><p>啪叽！茶壶就擦着他头皮砸在墙上。</p><p>锡壶的茶水刚刚给客人倒完。所以这壶只是掉落地上，滚了几圈，并没有碎裂和洒水出来。</p><p>“闭嘴！”老矮人额头青筋暴起。</p><p>他转向客人时又换上和煦笑容，“让各位见笑了。这小子上个月偷了我的‘绑定诅咒’之物——贝斯，所以没法演奏了。”</p><p>瑞弗维尔惊奇：“奥拓，你帮你父亲摆脱诅咒了？怎么做到的？”</p><p>因为有“绑定诅咒”，所以被诅咒物不可能远离宿主太久。</p><p>按理说，奥拓应该带不走他老爸的贝斯。</p><p>而且，杨帝与瑞弗维尔快速交流过：一挺贝斯在圣古琉斯王城大集市里，均价800铜。</p><p>想要摆脱，至少以650万卖出去。</p><p>这个相当于什么概念呢？按异界土著瑞弗维尔所说：以平价购买力计算，忽略通货膨胀、物价变动，650万能让普通的五口之家以平民的生活水准，活160年。</p><p>奥拓要偷走他爸的“被诅咒贝斯”，必须能掏出这笔钱，或者是与其等价的实物。</p><p>众人，包括老矮人，都以审视、好奇的目光看向奥拓。</p><p>奥拓只好说道：“你们知道，圣古琉斯王城大集市附近的房价被炒到多少了吗？”</p>
