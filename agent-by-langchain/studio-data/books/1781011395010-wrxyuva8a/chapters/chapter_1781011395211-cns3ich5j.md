# 最后100米！

<p>逼仄的通风管道仿佛没有尽头，只有队员们粗重的喘息，和衣物摩擦管壁的窸窣。</p><p>他们向着远离杨帝、远离那片血肉修罗场的方向爬行。</p><p>“出口！前面有出口！”眼镜的声音带着压抑的兴奋。</p><p>火鸦第一个凑近格栅，向外窥探。外面是一个相对空旷的机房或设备间，只有几盏应急灯提供着昏暗的光线。</p><p>“安全！至少现在没看到活物！”</p><p>用念力卸下通风管道栅格，众人依次跳下管道，落在这个新的空间里。</p><p>影子终于被颠簸弄醒，茫然地看着四周，但至少没有再晕过去——这里没有铺天盖地的人形物体，也没有那个让人灵魂颤栗的杨帝。</p><p>“眼镜，定位！”</p><p>“队长！我们……我们几乎到了！这里距离红皇后逻辑核心的物理层，只隔着最后一条走廊！全长……500米！”</p><p>“一条走廊，500米……”</p><p>铁砣舔了舔干裂的嘴唇，握紧那根仅存的半截狼牙棒棒柄，“他奶奶的，总算要见真章了！”</p><p>“别高兴太早，”队长神色凝重，“整合情报——我们到底在对付什么？”</p><p>是啊，副本已经进行了好几个小时，他们还没明白自己在面对什么。</p><p>更准确来说，还没明白这个副本的真正核心主题是什么。</p><p>阻止大屠杀，但当他们传送过来的时候，基地中的研究员已经死绝了。</p><p>既有“智械叛乱”，又有“丧尸危机”。</p><p>他们知道，第一条走廊的痕迹，是机器人激光武器造成的。</p><p>红皇后确实在用拼装机器人肃清丧尸。</p><p>“所以，核心矛盾是：一场失控的生化危机，导致了红皇后启动最高级别隔离和清除协议。”</p><p>眼镜快速总结。</p><p>“‘智械叛乱’是误导，或者……只是表象。红皇后并非主动叛乱，而是被迫采取极端措施。”</p><p>“那哈基米呢？”影子难得地开口，声音还有些发虚，“它……它不像那些丧尸。它更聪明，更强大。”</p><p>“特殊变异体，或许是源头，或许是更高等的感染形态。”</p><p>队长沉声道，“总之，它被杨帝解决了，暂时不用考虑。”</p><p>影子抖成筛糠的身子，平静下来。</p><p>但他回想起哈基米裂开的脑袋和那恐怖的触须，身体又不由自主地抖了一下。</p><p>作为全队伍胆子最小的人，影子的异能也尤为胆小——“阴影虚化”，能够让自己及周边一定范围的事物，进入“影子”状态。</p><p>这本是个神技能，尤其是在众多敌人包围的情况下，能神不知鬼不觉溜出去。</p><p>只可惜是个社恐。</p><p>队长目光扫过队员：“最后500米，必须潜行过去！影子！”</p><p>他看向那个一直缩在角落的阴影，“看你的了！能不能把我们‘藏’起来？”</p><p>“可以，这里的人形生物不多，我的极端社恐不会发作。”</p><p>影子脚下的阴影，如同活物般蠕动蔓延，颜色变得如同最浓稠的墨汁。</p><p>一瞬间，他们的身形、气息、甚至体温都仿佛被这片深邃的黑暗吞噬了，与房间本身的阴影完美融合。</p><p>从外界看去，那个角落只剩下一片比周围更加深沉的黑暗，没有任何异常。</p><p>“走！”队长的声音直接在众人意识中响起——影子甚至短暂地连接了他们的精神，避免了声音外泄。</p><p>多么强大的异能。可惜是个变态级社恐。</p><p>被阴影包裹的轮回小队，飘出设备间的门，进入了那条通往最终目标的走廊。</p><p>走廊异常宽阔，足以容纳大型设备运输。</p><p>应急灯的光线比之前更加昏暗，仿佛电力也即将耗尽。</p><p>这条本应防守最严密的走廊，竟然异常“干净”。</p><p>没有预料中严阵以待的机械守卫大军，也没有游荡的丧尸。</p><p>只有零星几个形态极其古怪的“机器人”，在漫无目的地徘徊。</p><p>“看来，‘红皇后’的大部分机器人，都调去对付丧尸了。”</p><p>“不管是什么，别惊动它们，绕开！”</p><p>队长下令。</p><p>影子的阴影包裹着众人，如同水流般绕过这些机器人，悄无声息地向前推进。</p><p>400米……300米……200米……</p><p>距离红皇后主机房越来越近，走廊尽头那扇异常厚重的合金大门已经隐约可见。</p><p>然而，前方的情况也陡然严峻起来！</p><p>最后100米！</p><p>这最后一段路，布满显然处于高度警戒状态的防御设施。</p><p>光源也不再是黯淡的应急灯。</p><p>上下左右都是敞亮的光源，到处都是监控摄像头。</p><p>除此之外，还有激光网陷阱、地面压力感应区、自动哨戒机炮等十八般刀枪剑戟斧钺钩叉。</p><p>然而，在平常情况下，以上通通都不算什么。</p><p>最要命的是——路上没有任何障碍物！</p><p>换言之，最后100米，没有任何“阴影”可供他们藏身。</p><p>他们如果打算强闯，便会如同在聚光灯下试图隐藏的黑布，随时可能暴露！</p><p>“怎么办？硬闯吗？”铁砣看着那些机炮，掂量了一下自己的半截棍子，觉得有点牙疼。</p><p>“硬闯就是送死！”火鸦立刻否定。</p><p>眼镜飞快地计算着：“激光网有规律，但空隙极小，速度极快。机炮扫描有死角，但切换很快。压力感应区覆盖范围太大……几乎没有安全路径！除非……”</p><p>“除非什么？”</p><p>“除非我们能瞬间瘫痪所有防御系统，或者……让它们短暂失效几秒钟！”</p><p>“那么，我们该怎么瞬间瘫痪所有防御系统呢？”</p><p>“我需要直接物理接触红皇后的主机。”</p><p>“那么，你该如何直接物理接触红皇后的主机呢？”</p><p>“我们需要通过最后这100米。”</p><p>“……”</p><p>眼镜满头大汗：“还有一个办法！”</p><p>“快说快说。”</p><p>“可以切断提供给这些防御机制的电源。”</p><p>“那么，该如何切断呢？”</p><p>“我们还是得物理接触红皇后的主机，因为我通过查询发现，它的主机有备用电源。”</p><p>“……”</p><p>“要不还是别管那主机了，后退一两百米，找个房间苟起来？我们关掉红皇后，归根结底也是为了‘苟’。”</p><p>“不能……这段路有摄像头和机器人巡视，但影子的虚化技能只能维持个把小时，苟不到72小时后。”</p><p>“如果苟在通风管道里呢？”</p><p>“当初哈基米就是顺着通风管道来追杀我们的，如果在那狭窄的空间里，再遇见这样的怪物……”</p><p>“可恶，最后的方法就只能关闭红皇后……”</p><p>就在这时，一股冰冷而沉重的威压，如同无形的潮水，悄然从他们身后的走廊弥漫过来。</p><p>众人猛地回头！</p><p>在身后那片被阴影笼罩、他们刚刚通过的昏暗区域，一个高大的身影，无声无息地出现在了走廊中央。</p><p>又双叒叕是杨帝！</p><p>他不知何时，以何种方式，穿过了那片混乱的战场，追了上来！</p><p>“怎么又双叒叕是他？！”</p><p>“他又双叒叕活下来了？！”</p><p>杨帝赤着上身，那件蠕动的漆黑“战甲”在昏暗的光线下仿佛吞噬着周围的一切光线，让他看起来更像一个深不见底的人形黑洞。</p><p>他的目光平静地越过惊骇欲绝的轮回小队，径直投向了走廊尽头。</p><p>那条明亮的100米过道。</p><p>杨帝那深不见底的身影踏入最后一百米的光明走廊，如同投入滚油的冰块，瞬间引爆了所有防御系统！</p><p>嗡——！</p><p>自动哨戒机炮的扫描头，瞬间锁定了这个突然出现、散发着强烈“有机体”信号的目标。</p><p>刺耳的警报声在走廊中尖锐响起。</p><p>哒哒哒哒哒！！！</p><p>六管加特林菩萨，大慈大悲冒蓝火。</p><p>能够轻易撕碎钢板的贫铀穿甲弹，打在杨帝身上，竟然！</p><p>……呃，杨帝被打碎成碎片。</p>
