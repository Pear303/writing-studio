# 鬼打墙

<p>……不对，这楼梯好像真的没有尽头。</p><p>楼梯下方传来细碎的抓挠声。</p><p>狸花猫不知何时又出现在光束边缘，尾巴竖得笔直，瞳孔在黑暗中闪烁如鬼火。</p><p>杨帝瞳孔一缩。按照常理，从四楼夹层下到一楼，最多只需两分钟。</p><p>可他们已经在楼梯间转了……三分钟。</p><p>每一层的墙面都重复着同样的褪色涂鸦，重复着用红漆画的歪扭箭头。</p><p>“胡哥，我们走多少层楼了？”</p><p>胡彦卓僵住，冷汗顺着脊椎滑进衣领。</p><p>5楼是雕塑室，4楼是书法室。</p><p>4楼和3楼是双层挑高结构，他们刚刚从音乐厅3楼的大门出来。</p><p>现在，他们从3楼开始，已经向下走了三层半……</p><p>他们已经越过一楼，现在至少处于地下负一层。</p><p>“论坛里的帖子说艺术楼只有六层，根本没有地下室。”</p><p>“我知道……贴在音乐厅外面的那张楼层示意图我也看过，是没有地下室的……”</p><p>“那我们……在哪？”</p><p>楼梯深处吹来阴冷风，带着潮湿的土腥味，裹挟着猫猫的微弱喵喵叫。</p><p>“布豪，感觉不对劲，回头，向上！”</p><p>胡彦卓猛地转身。</p><p>来时的楼梯已经消失，取而代之的是堆砌到天花板的桌椅。</p><p>腐朽的木板上缠着生锈的铁链，像某种古老的封印。</p><p>“桌椅，何时堵上的？！”</p><p>胡彦卓的声音拔高了八度，撬棍重重砸在障碍物上，木屑飞溅，“奶奶滴……这次真遇上鬼打墙了……”</p><p>杨帝的太阳穴突突直跳，精神属性带来的敏锐直觉让他浑身发冷。</p><p>——他感觉到了，楼梯间的空气正在凝固，某种更黏腻的黑暗正从深处漫上来，裹挟着铁锈味和腐烂气息。</p><p>胡彦卓回头大吼：“上楼的路堵死了！！”</p><p>“不能把桌椅移开吗？”</p><p>“它们被锁链缠到了一块，不砸断那链子，根本解不开！等等，那我试试把椅子的木板撬下来，看看能不能解开……”</p><p>胡彦卓握着撬棍的手青筋暴起，铁链与铁架碰撞出刺耳的脆响。</p><p>“啪嗒！”</p><p>椅子上的木板被撬了下来。</p><p>可铁链和板凳的铁架绑在一起，撬下木板也无济于事。这显然是个很会玩捆绑的鬼。</p><p>“……”杨帝与胡彦卓相顾无言。</p><p>如果是一般人，那肯定别无选择，只能攥紧撬棍继续向下。</p><p>然而，根据惊悚小说和恐怖电影的套路，如果他们继续向下走，便是土鳖入瓮，正中下怀！</p><p>“越是敌人反对的，在大部分时候，我们都越要支持……”</p><p>“越是牛鬼蛇神逼迫我们走唯一一条路，越是有大恐怖。”</p><p>“所以不能向下走。而应该调头往上！”</p><p>只能让他们往下，这摆明了是个陷阱。</p><p>杨帝直接调头，先是研究了一下那些桌椅还有锁链。</p><p>他用力拉扯。锁链和想象中一样坚韧，任凭他如何用力，也只是微微晃动，未有丝毫断裂的迹象。</p><p>“预料之中。”杨帝转头，看向身旁紧张兮兮的胡彦卓，“胡哥，你看好我后背。”</p><p>杨帝发力，肌肉紧绷，青筋暴起，朝着铁链狠狠砸去！</p><p>“砰——砰——砰！！”</p><p>金属与金属的撞击迸出火星。</p><p>声响震耳欲聋在楼梯间炸开，耳膜生疼。</p><p>“哇，够硬。”仅仅是敲三下，便觉手掌发震，虎口发麻。</p><p>胡彦卓扭头看向他：“……杨帝兄弟，你这是在，呃，做什么？”</p><p>“如你所见，砸开这锁链。”</p><p>他犹如不知疲倦的机器，每一记都倾尽全身力气，汗水顺着下巴砸在积灰的台阶上，洇出深色的圆点。</p><p>楼道里响彻久久不绝的“DUANG～DUANG～DUANG～！！”</p><p>胡彦卓的吼声在封闭空间里撞出回音，他一把拽住杨帝的胳膊：“别白费力气了！这铁链子拇指粗，你以为自己是液压钳吗……撬棍再硬也扛不住你这么造！”</p><p>“DUANG～！！”</p><p>杨帝的虎口已经震出血痕，混着铁锈沿指缝往下淌，在台阶上蜿蜒成暗红的细流。</p><p>第15发，他终于体悟到那种奇妙的感觉。</p><p>「剑+1」</p><p>尽管他手中是根半生锈的撬棍，而不是剑，杨帝仍感觉，自己获得一种兼顾技巧、力量、节奏与决心的能力。</p><p>然后是第30发，第45发，第60发……</p><p>敲击愈发熟练，第180次敲击过后，杨帝成功达到一秒六棍的水平！</p><p>「剑+1」</p><p>并不单只是撬棍，他能感觉到，只要自己拿到长条形硬物，都能唤醒某种潜藏的韵律。</p><p>它们都是广义上“剑”。</p><p>冥冥中，杨帝抓住那一缕闪光。</p><p>他感受到一种剑术，剑法，剑道。</p><p>他找出一个词汇加以形容——广义剑道。</p><p>“杨兄弟，你手都流血了！快停下！”</p><p>胡彦卓震惊，以为杨帝先他一步把san值掉光了。</p><p>“胡哥，再给我一分钟！”</p><p>杨帝一秒六棍，疯狂刷「剑」的属性！</p><p>210次……270次……330次……</p><p>他还时不时停下来，从背包里掏出压缩饼干和一罐蛋白粉，就着枸杞茶，生而啖之！</p><p>胡彦卓眼角抽动，完全不明白杨帝在干嘛。</p><p>但内心总有股声音，告诉他——相信杨帝。</p><p>“直觉”是人类感知中比较神秘的存在。</p><p>它本质上是潜意识在收集外界信息后，总结加工出来的有价值的结论。</p><p>胡彦卓本身“精神”属性比较高，所以他两年前才会在旧校区感受到“希夷”的存在，并且遇上些怪事。</p><p>用神秘学术语来说，就是“灵感”很高！</p><p>灵感高了，直觉还会低吗？</p><p>直觉让胡彦卓相信杨帝，直觉也让他感受到楼下有大恐怖。</p><p>狸花猫的叫声从楼梯下方传来。</p><p>这次不再是咕噜声，而是类似婴儿啼哭的尖啸。</p><p>像是在质问：为什么你们两个哈基人不遵循恐怖电影套路！为什么不乖乖走下来！</p><p>腐臭味愈发浓烈，像有无数条湿滑的舌头，正顺着楼梯舔舐上来。</p><p>胡彦卓有些动摇了。</p><p>“那只猫……怎么比发情时候还叫得恐怖？”</p><p>“那猫不是猫！胡大哥，你就守在我下面这个楼梯口，看见‘猫’来了，就喊我！”</p><p>“杨帝老弟？你是预感到了什么……”</p><p>“不错，你应该也发现了——直觉告诉我，这只猫很危险！”</p><p>交代完，杨帝全部精力和心神重新集中在手中撬棍，和眼前的铁链上。</p><p>目前他已通过临时抱佛脚，共计触发了「体能+6」和「剑+22」。</p><p>差不多够了。这锁链虽然有婴儿拇指粗，但锈迹斑斑，看起来像清朝传下的古董锁链。</p><p>且经过之前数百次猛烈敲击，其内部结构早已松动。</p><p>天时地利人和皆备。</p><p>杨帝调整了一下姿势，双脚稳稳地扎在地上，身体微微下蹲，像是一张蓄满了力的弓。</p><p>撬棍在铁链上滑动，发出细微摩擦声。</p><p>杨帝眼睛紧紧盯着铁链。</p><p>“最脆弱之处，找到你了。”</p><p>他的眼神一凛，撬棍猛地停住，然后以一种奇妙的角度和力度，狠狠地戳向铁链的一处链接环。</p><p>“咔嚓！”</p><p>一声清脆断裂声在楼梯间响起，似是黑暗被撕开了一道口子。</p><p>“成功了！”杨帝大吼。</p><p>胡彦卓又双叒叕瞠目结舌：“我超！兄弟，你是宇宙人还是新人类？来到我们地球有什么目的？！”</p><p>“别顾着开玩笑了，过来帮忙卸走桌椅，清开道路！”</p><p>杨帝喊胡彦卓赶紧帮忙。</p><p>但下一刻，一股寒意顺着脊柱爬上天灵盖。</p><p>“吼吼……”某种动物的嘶哑咆哮，陡然在楼体下方炸响。</p><p>胡彦卓迅速将手电筒调转方向。</p><p>只见在手电筒光束里，狸花猫正慢慢拾级而上。</p><p>它来了。</p>
