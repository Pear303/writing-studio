# 胡彦卓 希夷 杨帝

<p>希夷发出细弱的哀鸣，翅膀疯狂扑棱却掀不起半分气流。</p><p>那个顶替了胡彦卓身体的陈昭，双目暴凸着：</p><p>“你以为自己能成为救世主吗？你只能亲眼看见自己的‘灵’，像被挤碎的蛋黄从躯壳里，一点点剥离，一点点从你的血肉皮囊里挤出来……”</p><p>“轰”的一声，学校论坛那篇帖子，从杨帝记忆中蹦出。</p><p>「【纪实】旧校区偷渡记……」</p><p>「这是为了解密那个臭名昭著的都市传说——旧校区艺术楼到底有没有地下室？为什么会有地下室？地下室里有什么……」</p><p>「2013-07-18 03:03更新：艺术楼的地下室有个漩涡刻在墙上，挺艺术的……」</p><p>人死为鬼，鬼死为聻，聻死为希，希死为夷。</p><p>视之不见名曰夷，听之不闻名曰希。</p><p>人视之，听之。但潜意识屏蔽了它们，大脑过滤了它们，人无法觉察到它们的存在。</p><p>“【纪实】旧校区偷渡记 ”这篇帖子的楼主，曾也是个人类。</p><p>他于2013年7月17日探索了旧校区，撞破陈昭的阴谋后，夺走耶罗符印。</p><p>但他最后还是被抓住，然后被“质壁分离”。</p><p>「2013.7.19，人，质壁分离……」</p><p>他的“灵”脱离了物质躯壳。</p><p>却因为“耶罗符印”的作用，他脱离了物质存在的“灵”并没有迅速消散磨灭，而是浑浑噩噩，飘荡在旧校区艺术楼上空。</p><p>直到两年前，胡彦卓将其俘获于相片。</p><p>胡彦卓这张携带了“希夷”的照片，上传至“炒股”群。</p><p>两年后的今天，舍友张明远下载了它，保存为测试集之一“test_017”，并因为图像识别模型的诡异结果，而废寝忘食好几天。</p><p>于是，杨帝看了那图片“test_017”一眼。</p><p>一切便都开始了。</p><p>拼优饭那口米粒，早在他急性肠胃炎那夜，就卡进了宿命的牙缝里。</p><p>“原来如此，真是造化弄人……”杨帝叹息。</p><p>陈昭将希夷捏成一团瘫软的黑色烂泥，随手甩在墙角。</p><p>他站在杨帝身后，将插进心脏的瑞士军队刀把，顺时针、逆时针各自转了几圈。</p><p>娘希匹，痛，全身动弹不得。</p><p>「心脏+1+1+2+3……」</p><p>陈昭从杨帝口袋里翻找，夺过刻有漩涡图案的耶罗符印。</p><p>他瞳孔因狂喜而收缩成针尖状，嘴角涎水顺着下巴滴落。</p><p>手指在耶罗符印表面游移，仿佛抚摸着情人的发丝，神情迷醉如吸食五石散的瘾君子。</p><p>“12年，终于回来了……耶罗大仙的信物，能让我的灵持久脱离于物质而存在。毫无保留，以赤子之态，展现在耶罗面前……”</p><p>他将符印举向头顶，铁饼表面的漩涡纹路在黑光中流转，似无数冤魂在沟壑里挣扎。</p><p>杨帝趴了下来，身子弓成虾状，匍匐在地。</p><p>心脏还在绞痛，2%潜意识读取带来的副作用，是包括触觉在内的五感极度敏锐。</p><p>痛觉，从未如此清晰剧烈，绞入脑髓。</p><p>「缺血+1+1+2+3……」</p><p>陈昭用鞋尖碾着他后背，军刀在心脏处又拧了半圈：“换作常人……早该烂成肉泥了，你倒像块嚼不烂的牛筋，甚至没喊一声痛。简直，简直和星际虫族一样顽强，哈哈。”</p><p>「无氧+1+1+2+3……」</p><p>“终于——耶罗符印终于回到我手里了。胡彦卓，胡彦卓，他可真是我的有缘人呐。杨帝，你知道吗，本来旧校区就很少人来，来者也大都没有那个身手能够进入门窗、楼梯全部封锁了的艺术楼。”</p><p>陈昭将耶罗符印高高举过头顶。</p><p>铁饼表面的漩涡纹路迸发出幽蓝的光，空气瞬间凝固，温度骤降。</p><p>杨帝睫毛上结起冰晶，而陈昭的皮肤却泛起潮红。</p><p>陈昭一手捏着耶罗符印，高举铁饼。</p><p>然后一口咬断另一只手的小指，脸上看不到任何痛苦。</p><p>陈昭悠悠地从嘴里抠出那根正流着血的小指，在自己胸前——画了个漩涡图案。</p><p>空气粘稠如胶，杨帝呼吸困难——仿佛有一双无形的手正挤压着他的胸腔。</p><p>不对啊，他已经很久没呼吸了。</p><p>杨帝这才想起来，在那场“池梦”里，他已经将“呼吸”这种碳基生物的阑尾，给进化掉了。</p><p>杨帝听见陈昭高亢兴奋的呼声。</p><p>“血肉为祭，灵魂为引——”</p><p>那声音变得沙哑而冗长，每个字都像是从喉咙里挤出的血块。</p><p>像是某种史诗，似哀悼词，又类祭文。</p><p>“耶罗大仙，卡耳叩山的守望者，吞噬光明的漩涡之主，享用我的‘灵’！”</p><p>陈昭的嘴角始终挂着极乐的笑意，仿佛在触摸世界最本质的真理。</p><p>耶罗大仙，或者说那什么黄色神仙，祂人格魅力真有这么大吗？</p><p>能把一个90后稷海理工大学高材生给迷住。</p><p>还要心甘情愿把自己的“灵”奉献出去。</p><p>杨帝上一次见到这样的“魅魔”，还是在《三国》里读到的诸葛孔明。</p><p>一想象到那位羽扇纶巾，谈笑儒雅之人，他会发自心底生出“匡扶汉室”的冲动。</p><p>论名字，耶罗大仙是四字，诸葛孔明也是四字，二者伯仲之间，不相上下。</p><p>要杨帝匡扶汉室，可以。但若让他为卧龙先生献上灵魂和肉体——他自认为做不到。</p><p>陈昭究竟在追求什么？</p><p>朝闻道，夕死可矣？</p><p>天知道。</p><p>下一刻，杨帝再度听见沉闷的撞击声响。</p><p>“噗……又是你！此恶气，岂可休！！”然后是陈昭暴怒的声音。</p><p>杨帝艰难地睁开眼，第一眼看见插在自己心脏上的瑞士刀，第二眼望见麻雀形态的希夷，试图将陈昭手中的耶罗符印撞飞。</p><p>被扔到角落后，它一直在蛰伏。</p><p>它旁听了杨帝和陈昭的对话，也终于了解了自己的身世，来龙去脉。</p><p>明白自己原来也曾是人类，曾是这座学校的某个学长。</p><p>“符印！你娘勒戈壁！”</p><p>希夷不语，只是将羽毛炸开成刺，空气中划出幽蓝残影，麻雀小小的身躯一味地撞向陈昭。</p><p>“咚！！”</p><p>撞击竟带起雷鸣般的轰响。</p><p>陈昭的耶罗符印终于脱手，被撞飞的符印在地面弹起，漩涡纹路吞吐着黑芒，像一只贪婪的巨口。</p><p>杨帝似乎明白希夷的想法——将符印撞到下水道里，永远埋葬。</p><p>“不行……希夷……符印离太远……它会重新回来的。”杨帝只能通过精神和希夷交流。</p><p>即使是神交，他的语调也是若有似无，气若游丝。</p><p>下一刻，杨帝仅存的触觉感受到胸前一凉。</p><p>他勉强低头望去。除了那把插入心脏的刀，在自己胸膛上，多了一个金属饼状物体。</p><p>耶罗符印。它受到“绑定诅咒”，无法脱离他太久或太远。</p><p>“……老大，带着铁饼，快走。”希夷在精神链接中说道。</p><p>杨帝瞳孔一缩。</p><p>不，并非希夷失策……它拥有自己的记忆，所以它知道，将符印扔得太远，符印就会重新回到自己身边。</p><p>它目的就是这个，让杨帝带着符印逃，离开陈昭。</p>
