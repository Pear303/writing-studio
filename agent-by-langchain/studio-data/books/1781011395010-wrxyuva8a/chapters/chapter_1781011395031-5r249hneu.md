# 线索 胡彦卓

<p>“张明远，你那图片，是从哪里来的？”</p><p>杨帝掀开宿舍门，大摇大摆走进来，开门见山问。</p><p>张明远仍然盯着电脑屏幕：“什么图片？”</p><p>“就是你的那什么神经模型，它一直识别不出来的蓝天红气球图片。”</p><p>“啊？那张图片啊，是我在网上随便下的。”</p><p>张明远转过身，有些疑惑，“怎么了？找到女朋友、摆脱了哥布林族群的新人类同志，有什么问题吗？”</p><p>“说清楚点，网上哪里？”</p><p>“哦，一个社交软件。”</p><p>“什么社交软件？”</p><p>“企鹅群聊。”</p><p>“哪个企鹅群？”</p><p>“稷海理工的新生咨询群。”</p><p>杨帝打开手机，找到那个群聊，他记得自己开学的时候也参加入过。</p><p>但后来将这个群聊设置为“消息免打扰”。</p><p>原因无他，里边根本没有新生咨询功能！</p><p>从表面上看，这是个“新生咨询群”。</p><p>实则除了“群”字是真，另外两个“新生”和“咨询”都是假的！</p><p>说是新生群，其实这群里从高中小登，到已经毕业多年、快要奔四的老登，应有尽有。</p><p>说是咨询群，其实群内绝大部分时候，都在交流炒股心得。</p><p>每天都有人发各种股票走势图，讨论啥时候买啥时候卖。</p><p>前一刻还有人发大红包，说自己赚疯了。</p><p>几个钟头后，他也许就可怜巴巴地求群友，能不能资助10块吃个午饭。</p><p>有人笑着问他：“哟，XXX，又爆仓了？”</p><p>他红温，额上的青筋条条绽出，争辩道：“散户的事，能算爆仓么？那只是短暂的资金回撤罢了……是市场的非理性波动，懂不懂！那些机构大户，不也有看走眼的时候？我这只是时机未到，等行情一转，必然连本带利赚回来，区区十块钱，日后发达了，百倍奉还！”</p><p>接着便涨红了脸，额上的青筋条条绽出，引一些诸如“价值投资”“长期持有”的话，结尾还特地加上句号。</p><p>众人听了越发哄笑起来，群里充满了快活的空气。</p><p>这就是起起落落，惊心动魄的生活啊。</p><p>但杨帝和张明远，直到现在也不明白为啥一个新生咨询群，会变成校友的股票交流群。</p><p>“老帝，你可知道混股票圈子必定赚钱的方法？”</p><p>张明远坐在木凳上，翘着二郎腿，押一口冰可乐，如是问道。</p><p>“什么？”</p><p>“就是加入一个股票交流群，然后呢只要有人说自己亏钱了，你就让他发转运红包。有人说自己赚钱了，你就让他V你50。总之抢红包就行了，千万不要买股票。”</p><p>杨帝点点头，深以为然，这是世上唯一一句客观真理。</p><p>他们二人短短说几句话的时间，十几条炒股群@全体成员的信息瀑布般冲刷下来。</p><p>「特大喜讯！XX板块即将暴涨！」</p><p>「内部消息：国家政策扶持！」</p><p>「来不及解释了，速买代码002XXX！」</p><p>太疯狂了。杨帝忽略掉这些炒股佬的狂欢，直接翻看群里的聊天记录和文件。</p><p>他找到那蓝天红气球的图片。</p><p>图片发布于两年前，发布者是一个昵称为“退休跑手”的网友，头像是一道红色剪影穿梭于建筑之间。</p><p>尽管是两年前的内容，但这图片并不难找，它就这么摆在“群相册”的封面。</p><p>群里每天都会发很多各种股票涨幅的截图，但默认不会上传到群相册，它们是分开来的。</p><p>群相册里只有寥寥几张图，其中之一就是这张蓝天红气球照片。</p><p>照片的上传者问：“有人知道为啥旧校区会有这种儿童玩具，那里不是不让进嘛。”</p><p>群友沉迷炒股，没几个人回答。</p><p>寥寥几个答复，也都是“不知道”。</p><p>等等，“退休跑手”这个ID，“红色剪影穿梭于建筑”的这个头像……</p><p>杨帝惊讶。</p><p>他自然知道这是谁——昨天刚加企鹅号的那位跑酷大佬，胡彦卓。</p><p>世上怎会有如此机缘巧合？这又不是小说！</p><p>就算放进小说里，也艺术过头了吧？</p><p>那个跳跃断桥的红色身影，在杨帝的记忆中中凝固成一道刺目的剪影。</p><p>总之，胡彦卓早就被卷入这场诡异的因果？</p><p>为什么胡彦卓会和一群炒股佬混在一起？</p><p>……不对，重点不是这个吧。</p><p>重点是，为什么他随手发的一张图片里，会藏着“希夷”这么奇怪的东西？</p><p>杨帝点进胡彦卓的头像，和他私人聊天。</p><p>他们的聊天记录目前只有一条，就是对方发给杨帝的“跑酷基础教程.zip”。</p><p>「胡哥，方便问个事吗？」</p><p>消息气泡旁跳出“对方正在输入”的提示。</p><p>「嗷嗷嗷，是杨帝老弟！是不是想通了？想要和我学跑酷！」</p><p>「胡老哥，你怎么进炒股群了？」</p><p>对方正在输入ing……</p><p>「呃，哈？什么炒股群？」</p><p>「就是我们学校的新生咨询群，里面不是有一群炒股佬嘛。」</p><p>「噢噢，我进那个群是想问旧校区的事。」胡彦卓发来一串捶桌大笑的表情包。</p><p>他继续说，「结果刚问完有没有人知道旧校区为什么废弃，群里突然开始刷屏讨论新能源汽车股，硬生生盖了三百多楼！」</p><p>旧校区？</p><p>杨帝的拇指在手机边缘轻轻摩挲。他也经常去那里，那里不只是小情侣幽会的场所，现在也成为他的跑酷训练场地。</p><p>「你问旧校区，是怎么回事？」</p><p>对方正在输入ing……</p><p>「有人说闹鬼，有人说危房。但前年我翻墙进去时，混凝土墙面连裂缝都没有，爬山虎倒是把整栋实验楼裹成了绿粽子，看起来除了没人待里面，不像是危房的模样。」</p><p>杨帝一拍脑袋，差点忘了正事儿。</p><p>他来这不是为了问旧校区的事啊。</p><p>「胡彦卓大哥，问你个事，两年前在炒股群发了张蓝天红气球的图片，还有没有印象？」</p><p>杨帝将那张蓝天红气球图片发给他。</p><p>聊天框对面沉默了一下。</p><p>似乎在斟酌语言，又像是不愿谈起此事。</p><p>但最后，他还是作出回答了。</p><p>「记得。」</p><p>杨帝手指微微颤抖着，又发送了几个字。</p><p>「胡大哥，你看到那气球后面……有什么奇怪的东西了吗？」</p><p>「呃呃，其实也没什么特别的，就是那天我在旧校区探险时，无意间抬头看到了那个红气球挂在天上，觉得挺有意思的，就拍了下来。」</p><p>对方刚发送完信息，又显示正在输入中，然后立刻发送了第二条：「杨帝老弟，旧校区很危险，不要过去。」</p><p>第三条：「两年前，也就是前年，我髋关节就是在那伤到的，骨折一处，骨裂两处。」</p><p>杨帝立刻想到——旧校区外的保安亭，那个老头说“前年有人在里边摔断屁股”。</p><p>大抵指的是胡彦卓大哥，惨……</p><p>当时杨帝并没有反应过来保安指的是谁。现在细细回忆，才恍然明白——</p><p>那不是“摔断屁股”，而是“髋关节骨折”。</p><p>胡彦卓发来新消息：「有些事情隔着屏幕说不清楚，我们线下当面聊聊。学校后街的猫尾咖啡馆，如果可以，就现在。」</p>
