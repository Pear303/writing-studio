# 灾厄往事

<p>他们继续踹门而入，随着更多门轰然倒下，更多氧化脱落的壁画如汹涌的浪潮朝他们扑来。</p><p>瑞弗维尔下意识地又抬起手臂遮挡。</p><p>尽管心里已经明白，这只是壁画脱落，但如此震撼的场景，还是让他本能地感到紧张。</p><p>杨帝则全神贯注地看着这些壁画碎片。</p><p>历史正以倒叙的方式，在他眼前展开。</p><p>第一幅画面，圣骑士巴德与焚灭天空之龙卡利斯托的胶着战斗。</p><p>第二幅画面，魔戒同盟在半兽人与食人妖围追堵截下奔向末日火山。</p><p>第三幅画面，人类与尖耳朵精灵结成联军，对抗魔多大军。</p><p>第四幅画面，维拉出兵对抗魔苟斯……</p><p>杨帝会向瑞弗维尔讲述壁画上的画面。</p><p>瑞弗维尔很快也发现，这些画面是倒叙的历史，而且呈现的，都是中土大陆数万年来面临的灭顶危机。</p><p>巨龙，魔君，黑暗……</p><p>瑞弗维尔向杨帝稍微解释和补充一下那些历史。</p><p>房间有许多个，绘制的都是这片大地曾经遭受过的灾难。</p><p>其他那些相比之下小打小闹的战争，以及各种族之间的内战，则没有记载。</p><p>越是往深处走，瑞弗维尔在听完杨帝讲述的画面后，思考时间越长。</p><p>毕竟中土大陆的历史太长太长了，能够追溯到古老的40k年前。</p><p>即使是博闻强记的瑞弗维尔，也很难一下子反应过来——这些画面讲的是啥啥啥（shà shà shà）历史啊！</p><p>杨帝表示能理解。</p><p>在他故乡，上古时期最古老的历史，比如夏朝，几乎不能称作历史，而更类似于某种神话传说了。</p><p>如果有人对杨帝说“画面上有个魁梧的巨人带很多人在一条沟里挖土，旁边有条河”，他还得反应半天才明白，这是在描述大禹治水。</p><p>杨帝对异世界的历史并不那么了解。</p><p>他口述出来的画面，也抓不住重点，无法准确传达每个细节。</p><p>所以，瑞弗维尔思考时间越来越长。</p><p>终于，他们走到了最深处。</p><p>这是最后一个房间了。</p><p>而呈现在他们眼前的最终画面，是个棱角分明的巨人，对决一颗圆润的大眼珠子！</p><p>因为这里的历史都是倒叙的，所以，“巨人大战眼珠子”就是中土大陆所面临的第一场灭世危机？</p><p>眼珠浮在天空，巨人矗立大地。</p><p>那巨人身材魁梧，肌肉贲张，每一块隆起的肌肉都仿佛蕴含着毁天灭地的力量！</p><p>巨人身后有棵大树。大树，也就是一棵树，它很大。</p><p>而大眼珠子，直径足有巨人身高的一半，散发着诡异而邪恶的光芒。</p><p>眼球表面布满了血丝，瞳孔中跳动着黑色的火焰，仿佛凝视一眼，灵魂都会被吞噬！</p><p>杨帝回忆这幅画面，眉头紧锁。</p><p>他向瑞弗维尔描述了画面内容。</p><p>“这画的是什么？巨人和大眼珠子，你有印象吗？”</p><p>瑞弗维尔盯着画面，思索良久，脸色逐渐变得凝重起来。</p><p>比魔苟斯更古老的黑暗……</p><p>“我……我好像在一些极其古老的典籍中看到过类似的记载，只可惜，那些都是接近千年前写的《野史》。”</p><p>“野史也是史，快端上来罢。”</p><p>“传说在中土大陆最古老的时代，世界成型那刻，一个‘东西’诞生了。它没有具体形体，唯一象征就是眼睛，所以被称作「原初之眼」。”</p><p>“那这个巨人呢？”杨帝追问。</p><p>瑞弗维尔缓缓摇头，“关于这个巨人，野史中并没有太多描述，只能知道它被描述为「无限机兵」。据说它挺身而出，保护了如今精灵族境内的‘圣树’，对抗堕落的原初之眼……”</p><p>野史读得多，还是有好处的。</p><p>能够了解许多不会出现在正史上的秘辛。</p><p>比如这颗大眼珠子，科班出生的历史学家或许反应不过来那是什么。</p><p>大部分野史都太野了，他们不屑一顾。</p><p>……</p><p>杨帝并不太懂传说神话史诗。</p><p>他只能一边在脑海中翻阅《古代神话与民族》《伏羲考》之类的书籍，临时恶补。</p><p>在决定随钓鱼佬的脚步、从黑水潭子离开地球之前，杨帝又去了趟图书馆，把大量书籍的内容刻印在脑子中。</p><p>虽然还是比不过小黄书，但他脑海中已经有一万零八十本各类书籍，相对于十分之一的茵蒂克丝。</p><p>通过半分钟临时抱佛脚式的恶补。</p><p>杨帝也逐渐有了些上古神话研究的学术基础。</p><p>他已经有足够的基础知识，可以思考这些画面背后的隐喻和寓意。</p><p>在地球上的诸多神话体系中，眼睛常常象征着洞察、监视以及掌控力量。</p><p>这颗“原初之眼”，或许代表企图掌控中土大陆，将一切纳入黑暗统治的原始邪恶力量？</p><p>而“无限机兵”这一巨人形象，其名字中的“无限”可能暗示着无尽的力量、不屈的意志或者源源不断的生机？</p><p>“机兵”也许表示它并非自然生物，而是某种具有强大战斗力的构造体，被创造出来专门对抗“原初之眼”带来的黑暗？</p><p>颇有童话浪漫气质的解读。</p><p>他们继续往前走。</p><p>在房间的尽头，瑞弗维尔和杨帝看到一个，呃，像是摩天轮轿厢一样的，轿厢。</p><p>瑞弗维尔眼中闪过一丝惊喜：“由矮人工艺打造的装置，灵能轿厢！”</p><p>“什么？这是做什么的。”</p><p>瑞弗维尔解释了两句，杨帝立刻意识到，这就是异世界版“电梯”。</p><p>轿厢会去往末日火山内部的最深处。</p><p>他们走进轿厢，内部空间宽敞，四壁由一种泛着幽光的金属打造。</p><p>轿厢的门缓缓合上。</p><p>瑞弗维尔走到轿厢一侧，在一个镶嵌着各种宝石的操控台上，随手乱按拉扯。</p><p>刹那间，轿厢微微一颤，开始移动。</p><p>瑞弗维尔有些欣喜：“没想到时隔几千年还能动，矮人工艺，震撼人心！”</p><p>他按下一个红按钮。</p><p>按正常逻辑来说，看见红按钮不能乱按，如果那是全球核武发射按钮怎么办？</p><p>按钮被瑞弗维尔按下了。</p><p>下一刻，强大的超重感，让杨帝二人身体猛地向上一提！</p><p>与想象中竖直向上的移动方式不同，轿厢先是沿着一条略微倾斜的轨道水平前行。</p><p>它是倾斜向上的，就像扶梯。</p><p>但很快，杨帝发现自己还是有些狭隘。</p><p>某一个拐口，轿厢突然改变方向，沿着一个更加陡峭的坡度向下俯冲！</p><p>更令人意想不到，轿厢在俯冲一段距离后，又突然水平转向，朝着第三个方向疾驰而去。</p><p>“这怎么回事？”杨帝装作大惊失色。</p><p>“矮人制造的灵能轿厢在设计上总是充满了奇思妙想，他们会根据不同的地形和需求，打造不同的移动方式。”瑞弗维尔大声说道。</p><p>杨帝只在Minecraft地图里，见过这种天马行空、施工难度极大、完全没有性价比的移动方式。</p><p>今日有幸在现实里见过，也算是不虚此行。</p><p>在轿厢持续不断的变换方向和速度中。</p><p>二人不知道，自己究竟深入到了末日火山内部多深的地方。</p><p>过山车似的轨道延伸了20分钟。</p><p>轿厢的速度才逐渐慢下来，最终缓缓停住。</p><p>“看来我们到了。”瑞弗维尔深吸一口气，差点呕出来。</p>
