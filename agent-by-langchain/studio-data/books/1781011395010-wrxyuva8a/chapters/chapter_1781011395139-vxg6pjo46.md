# 事了拂衣去·第三卷终

<p>与此同时，杨帝与守望者文明庞大的格式塔思维，正火热朝天地神交。</p><p>是关于无限机兵的使用事宜，以及守望者文明后续的发展方向、历史使命。</p><p>「杨帝阁下，这台机兵……使用的是极其先进前沿的技术手段，以我们当下的技术力，甚至只能复刻其5%的结构。」</p><p>「就比如，这台机兵内置的‘类时无限计算机系统’，虽然原理上很简单，是通过超光速负能流制造的时间机器。」</p><p>「但其无论是效率还是功率，都远超我们目前最先进的闭合类时曲线计算机。」</p><p>「尽管我们守望者文明能够通过时间机器，从未来获取答案，再将答案发送往过去。」</p><p>「但唯独对于这台机兵的原理，我们的时间机器似乎……失效了。」</p><p>「这台机兵更多部件系统，是根据某种更高层次的理论，制造而出的超时代产物。」</p><p>正方主角团聊天或回忆时，反派一般都会陷入时间暂停。</p><p>而在这里，也是一样。</p><p>此刻，守望者文明作为本宇宙最强大的科技文明，向杨帝解释本宇宙的境界划分，划掉，文明级别划分。</p><p>其实杨帝自己也完全明白文明级别划分。</p><p>但他只是“记住”，并没有“理解”。</p><p>科技和魔法复杂到一定程度，光记住也不一定能理解，具体可参考数学。</p><p>「其实划分方式挺多的，比如能量产出功率划分，文明领域扩张范围划分，等等。」</p><p>「我们倾向于以‘可操控物质结构’对文明进行划分。」</p><p>「第一级是‘宏观时代’，许多文明早期，虽能冶炼金属、烧制陶瓷，但对于分子与原子的运用，几乎为零。」</p><p>「往上一层是‘原子时代’，他们能够深入到原子层面，甚至能质子、中子、电子的领域，发展至成熟，粒子对撞机会成为他们构建特殊能量场，或者制造新型材料的常规手段。」</p><p>「第三阶段是‘超物质时代’，在这个阶段，文明能够突破常规物质的限制，对物质的操控深入到夸克层面，对四大基本相互作用的操纵，信手拈来。」</p><p>「最后，也就是我所处的‘超弦时代’，玄之又玄，妙之又妙，超弦震颤，万象皆虚！此境之下，时空如残卷可撕，因果似丝线能织，夸克崩解为弦之震颤，五大基本力化作无形道韵，抬手便是万物生灭……」</p><p>天知道怎么突然如此玄幻。</p><p>「可即使是‘超弦时代’巅峰大圆满的技术，也无法完全解析这台机兵超过5%的技术。」</p><p>「您知道这意味着什么吗，杨帝阁下？是的，您一定知道。」</p><p>杨帝当然知道。</p><p>无限机兵由一个被称作“星环盟约”的超级文明所打造。</p><p>这个超级文明星环盟约，绝对已经跨过了第四个时代“超弦时代”。</p><p>它远远超越了本宇宙最强文明——守望者，当下阶段所能达到的巅峰水平。</p><p>那是何等恐怖的地步？</p><p>杨帝翻找原初之眼的记忆和经验，也无法得知“超弦时代”往后，应该是怎样的文明形态。</p><p>原初之眼仅仅是观察着万物，收集万物的信息，而守望者文明所代表的，正是万物所能达到的极致巅峰水平。</p><p>他们都脱离不了宇宙内万事万物的约束。</p><p>原目曾说，星环盟约是超脱宇宙之外的虚空霸主。</p><p>很可能无法用宇宙、无法用时间之内万事万物的评判标准，去评价一个“虚空霸主级”的多元宇宙文明。</p><p>守望者文明-59改，继续说下去：</p><p>「杨帝阁下，宇宙内的万事万物，我们已经研究透彻，将理论大厦最后一块砖补全。」</p><p>「此后，我们进步越来越缓慢，逐渐趋于极限。即使是用闭合类时曲线计算机，也无法从未来获得更多答案。」</p><p>「从取得‘无限机兵’到目前为止，我们已经用时间机器跳过了长达50亿年的发展过程。」</p><p>「然而，关于这台机兵的技术，我们对它的逆向工程始终进度缓慢。」</p><p>「50亿年的时间跳跃换来的，只是证实了这台机器的每个零件，都违背我们现有的全部技术理论。」</p><p>「我们认为，这台机兵使用了某种超越宇宙之外的技术。」</p><p>「所以，冲出宇宙，是越过超弦时代，抵达下一个文明阶段的必由之路。」</p><p>正因如此，守望者文明在听说杨帝有跨宇宙旅行的方法时，才如此希望学习相关技术。</p><p>继续困在宇宙之内，守望者文明终将如被困在玻璃瓶里的飞虫，耗尽所有能量也撞不破那层无形的壁垒。</p><p>超弦时代能够随手修改物理法则、一巴掌创生出个一个小宇宙，看似无所不能。</p><p>但在面对无限机兵、面对更高层次的技术之时，像孩童摆弄积木般稚嫩。</p><p>所以守望者文明试图抓紧一切机会，冲出宇宙，抵达世界之外。</p><p>可以视作宇宙时代的最后一次大航海，新天地的画卷，将在勇敢者眼前徐徐展开。</p><p>阿巴虽然是搞修仙那一套的，但她也上前来插个嘴：“没错。在本鱼设想中，达到更高层次的超脱只有两条路径，要么证道‘大罗金仙’，成为那铁壳子说的什么‘最终观测者’；要么超脱于世界，飞升至宇宙之上。”</p><p>杨帝点点头，摸着下巴思考。</p><p>如此看来，无论是个体强者或是群体文明，升级到一定阶段，都会以“超越他们所居住之地”作为下一阶段的发展目标。</p><p>譬如，行星时期离开大气层与大地；恒星文明时期则需要离开日球顶层，去往更辽远的宇宙深空。</p><p>文明进化，是一场酣畅淋漓的“天元突破”。</p><p>……</p><p>十步嘎一神千里不留行，事了拂衣去深藏身与名。</p><p>经与虚境四小贩充分沟通协商，各方达成如下共识：</p><p>一、经营原则</p><p>1. 严格遵循公平、公正、公开的市场交易准则，坚决杜绝以智慧生命的自由意志、生命本源、灵魂本质、记忆情感等一切宝贵存在作为交易价码，严禁任何形式的生命剥削、意识操控、灵魂买卖等践踏知性尊严的行为，确保市场交易建立在尊重生命价值、维护生命权益的基础上。</p><p>2. ……</p><p>……</p><p>各方均表示将严格履行上述承诺，共同维护虚境市场的良好经营秩序，推动商业环境健康、稳定、可持续发展。</p><p>特此说明。</p><p>虚境四小贩（盖字签章）：</p><p>[生命之织缕]</p><p>[世界之喰煞]</p><p>[渴求之器具]</p><p>[虚空之低语]</p><p>至此，这个世界重新走向正轨。</p><p>或许仍然会有悲欢离合，这个宇宙可能还会发生更多故事，更多阴晴圆缺。</p><p>所幸万物并行不悖，真正的神灵“原初之眼”已死，虚境中剩下的几个，也不过是比较强大的伪神。</p><p>它们只是伪神而已，难道能斗得过人？</p><p>本就命运颠沛的世人，能少受许多无妄之灾了。</p><p>不过，上下四方、古往今来的文明与个体，他们的命运，仍然需要靠自己抗争。</p><p>杨帝安排好生前身后事，又给虚境四小贩秀了几个钟头的肌肉。</p><p>夕阳红旅行团，真的真的要上路了。</p><p>守望者文明本体将滞留在本宇宙，继续守望万物的发展。</p><p>尤其是对于虚境中的“神灵”，守望者文明的主体，将滞留本宇宙，执掌尚方宝剑，监管市场秩序。</p><p>他分裂出的子个体“59改”，则与杨帝一同上路。</p><p>随之同行者，还有太乙真仙·月斑银鲈·阿巴，以及本宇宙最恐怖的数值怪·杨帝。</p><p>所组成的旅行社团被称作“夕阳红”。</p><p>杨帝抬头仰望，星光灿烂无比，但整个宇宙因他的光芒而盲目。</p><p>金色道路如此遥远，事了拂衣去。</p><p>黄粱一梦【上】（186-246）</p>
