# 内圣之道

<p>归墟之地笼罩在浓稠如墨的雾气中，方圆百丈寸草不生。</p><p>——或者说，方圆百丈别说寸草了，就算是寸土石、寸空气都没有一丝。</p><p>只要是接近归墟渊水，无论是何种物质，都会被磨灭消除。</p><p>正因如此，归墟之地的空气被持续抹除。</p><p>形成一个极低气压的区域。</p><p>周遭的气流疯狂涌入这片虚无领域，狂风呼啸肆虐不止，宛如深渊巨兽的贪婪呼吸。</p><p>杨帝负手而立。</p><p>他的衣服并没有因归墟渊水而被消抹。</p><p>——因为这衣服，都是他催动自己的毛发编织而成的，上衣主要是腋毛，裤子主要靠腿毛，短袖上还纹了只可爱的苦力怕图案。</p><p>毕竟，修炼到他这个地步，随意更改体毛颜色也不是很难吧？</p><p>世上无难事，只怕有心人，达到大帝境界，只要肯下功夫，总能找出让体毛变色的方法。</p><p>颜色的本质，不过是物质对特定波长光的选择性吸收与反射。</p><p>而物质对特定波长电磁波的发射吸收，又与与物质内部粒子的能级结构息息相关。</p><p>而当电子在不同能级间跃迁时，会吸收或释放特定能量的光子，即电磁波，这一过程又由电磁相互作用介导。</p><p>知道了原理，接下来如何改变毛发颜色就很简单了。</p><p>杨帝只需让人体磁场转动100万匹，干涉毛发原子的电磁相互作用，精准调控汗毛细胞中色素分子的电子云分布，改变其分布和能级差。</p><p>毛发就能反射出他想要的颜色。</p><p>此刻，他有种奇怪的感觉。</p><p>电磁场也是一种“物质”，而杨帝能够扩散人体磁场，在体外随意转动。</p><p>当他的一根“磁场触手”接触到归墟渊水时。</p><p>他清楚地感知到某种「磁场+1」的超量代偿效果。</p><p>杨帝看着自己的手，感受到无数多根磁感线从五指射出，又收拢于掌心。</p><p>仍然生长、未曾断裂的毛发，是他身体的一部分。</p><p>而从他身上延伸出的人体磁场，无论是100兆匹还是100匹，同样也算作“身体的一部分”。</p><p>磁场转动，直观上看，似乎并不算常规意义上的“身体”。</p><p>但这些转动的人体磁场，也能享受到超量代偿……</p><p>以往杨帝的认知中，血肉筋骨、脏腑经络才是构成身体的核心。</p><p>杨帝好像抓住了某种关键点，但又不清楚自己抓住了什么关键点。</p><p>“磁场转动100匹，100万匹，或是100亿匹，像是……领域？”</p><p>杨帝确实修为极高，能一巴掌将阿巴拍飞到宇宙边疆，砸穿大道。</p><p>但却因此，反而不懂得释放“领域”。</p><p>领域，是弱者为了增幅自己力量，而研究出来的工具。</p><p>强者不需要领域，因为他们一巴掌就能将对方扇成猪头。</p><p>在杨帝认知里，那些花费心思去构建领域的行为，多少有些浪费时间与精力。</p><p>有构筑“领域”的精力，不如多挨点打。</p><p>话都说到这份上了，先喝一口归墟渊水。</p><p>杨帝手搓了一个“色核力材料”制成的勺子，弯腰尝试舀起一瓢渊水。</p><p>这几乎是宇宙最坚硬的宏观物质材料。但在接触归墟之水的刹那，如同雪花遇到开水，迅速而彻底地溶解了。</p><p>这个勺子并没有算在他“身体的一部分”内。</p><p>杨帝寻思片刻，用自己的手舀起一勺。</p><p>漆黑的液体在掌心翻涌，发出令人牙酸的嘶鸣。</p><p>“干了！”他仰头一饮而尽。刹那间，皮肤开始皲裂，血管在皮下暴起如紫色蚯蚓。</p><p>体内的灵能疯狂暴走，五脏六腑仿佛被万把钢刀同时绞碎，鲜血从七窍喷涌而出！</p><p>相当于数十个银河系恒星数量的超新星爆发造成的伤害，在他体内同时绽放。</p><p>归墟渊水中蕴含的虚无本源，如贪婪饕餮，疯狂吞噬着他的血肉与灵能，就连血小板、白细胞都被撕扯得支离破碎，恐怖如斯！</p><p>“有点意思，用手心捧一口渊水，对我身体额外造成的伤害，大约是三十个银河系恒星数量的超新星爆发。”</p><p>没错，“虚无本源”也能反过来被消耗。</p><p>和虚无本源比起来，其实“灵”更接近于这个世界的本质。</p><p>灵能衡量着现实的丰度。</p><p>而现实就是……就是什么？</p><p>无论是站在宇宙巅峰顶点的太乙真仙，亦或是穷尽宇宙万物规律的宇宙级文明，都只能将灵能定义为“表征现实富集程度的属性”。</p><p>但对“现实”本身，并不能很好地下定义。</p><p>就像还在行星上缓慢爬行的“原子时代”低等文明，并不能很准确地定义“引力”，只能描述其表象与部分规律，难以触及到它深层次的本质。</p><p>无所谓，能用就行。</p><p>求真的同时，也要务实啊！</p><p>“我能预感到，接下来还会有一场恶战。哼哼，继续升级吧。”</p><p>杨帝不再用手捧归墟渊水。</p><p>而是一口气炫入几百升。</p><p>随即，原地入梦，梦中梦，梦中梦中梦！</p><p>……</p><p>远处打开一道正六边形太空死灵风格的传送门，门中几个身影窜出，传来破空声。</p><p>阿巴三人赶到时，正看见杨帝的身躯爆成一团血雾！</p><p>血雾并未消散，反而在虚空中不断重组，每一次聚合都伴随着骨骼错位、肌肉抽动的爆响。</p><p>每次爆开血雾，间隔仅仅1/8000秒。</p><p>他们的老大，此时此刻正是一串8000赫兹的人肉鞭炮，正在不断爆炸口牙！</p><p>阿巴悲痛欲绝：“老——大——你终于要神魂尽灭、身名俱裂、万劫不复了？！”</p><p>虽然众人又惊又异，但没一个敢上前。</p><p>归墟渊水的毁伤之力，他们都听青丘白璃做过详细科普。</p><p>除非是大帝级别的角色，否则贸然上前，只能落得个“被虚无本源顷刻炼化”的下场。</p><p>杨帝的爆炸已持续了30秒。</p><p>他身上血雾炸开的频率越来越慢，威力也开始如瀑布般暴跌。</p><p>第35秒，身体各处的爆炸彻底停止了。</p><p>杨帝站在一地碎肉血沫之中，缓缓睁眸。</p><p>归墟之地的狂风被他周身形成的磁场绞成齑粉，虚空中不断炸响空间破碎的脆响，宛如宇宙诞生时的弦鸣。</p><p>他随意踏出一步，脚下的归墟渊水竟发出婴儿啼哭般的哀鸣，漆黑液体疯狂退避！</p><p>脱胎换骨，脱脱又胎胎，换换又骨骨！</p><p>杨帝顷刻适应了“虚无本源”的杀伤。</p><p>在外界看来，他只是经受了一分钟的痛楚，便免疫了虚无本源的“法则级别”杀伤。</p><p>阿巴的瞳孔剧烈收缩，喉结上下滚动着发不出完整音节。</p><p>“老大……你又双叒叕升级了？！”</p><p>深海鲈鱼从小时候起，就目睹杨帝的恐怖数值，从而立志要跨越星海，成为宇宙最强碳基生物。</p><p>这个目标至今未能达成。</p><p>杨帝既是她新认的老大，也是始终笼罩在鲈鱼心头的阴影。</p><p>那是一道高耸入云，绝望到令人无法跨过的危墙。</p><p>而现在，“危墙”再度向天空迈进了不知多少光年……</p><p>杨帝说：“青丘白璃，阿巴，我好像明白该怎么展开领域了，你们帮我把把关，看看哪里还不到位。”</p><p>二位尊者震怖。</p><p>他们哪敢给杨帝把关呐？</p><p>就好比某天几位得了炸药文学奖的巅峰强者，突然发邮件给你，讨教几个文学问题。</p><p>青丘白璃看了眼已经消失大半的归墟渊水潭子，咽了口唾沫：“咕……白杨大帝阁下，还请您收点力。”</p>
