# 飞升是骗局

<p>首先是话本编撰者，耶罗，黄神。</p><p>「宇宙的演进，大部分时候是自然法则的结果，但最重大的历史事件和进程，都有可能是话本编撰者的手笔。」</p><p>「祂漫不经心地拨动，某个星系的诞生便提前了千万年，而另一处宇宙边陲的文明则在瞬间灰飞烟灭……」</p><p>「祂甚至能篡改‘熵’的方向——你以为宇宙的热寂是必然？不，那很可能只是祂某个午后突发奇想的结局设定。」</p><p>「那些所谓的‘天命之子’，不过是祂笔下的提线木偶。」</p><p>原初之眼语气平静如水，但在说到“提线木偶”之时，话音略带一丝人性化的苦涩。</p><p>每当祂提笔书写，现实世界便会产生扭曲：某个凡人突然觉醒创世之力晋升大帝，某个平平无奇的普通男子高中生觉醒了挨打就能变强系统，某个星球核心竟藏着能够切割万物的韭菜鸡蛋饼。</p><p>「耶罗似乎在刻意创造‘矛盾’——祂既渴望有人能打破自己编写的剧本，又不断强化世界线的宿命闭环。」</p><p>「这就是我对祂了解的全部。」</p><p>「再多的信息，我已经读取不到了。」</p><p>「而据我所知，祂开启我的主观意志，是为了让我对抗一个极其强大的超级文明。」</p><p>「那个超级文明超脱于宇宙之外，同时也是‘无限机兵’的创造者。」</p><p>「这个已经有能力超脱宇宙、遨游虚空的文明，似乎叫『神圣星环盟约』。」</p><p>杨帝大脑有些颤抖。</p><p>耶罗曾经提及「■■■■■■」，似乎，似乎……就是这个。</p><p>（根据前排的观众的反馈，耶罗大仙突然说出这几个字非常掉逼格，遂将48章那六个字打上了码 (。﹏。) 私密马赛）</p><p>直觉告诉他，是这样的，耶罗所说的那几个字，就是“神圣星环盟约”。</p><p>「在此之前我先问你，当个体的力量修炼到极致，或是一个文明的水平达到宇宙巅峰。」</p><p>「那么接下来，他们会想怎么做？」</p><p>“……退休？”杨帝并没有实际经历过以上的情景，所以并不清楚——当事人和当事文明，抵达这种境界后，还会做些什么？</p><p>「怀有退休心态的人不能成为强者。」</p><p>「谜底揭晓：根据我以本宇宙为样本，进行的数以兆亿计的观察，他们会选择继续突破世界的极限。」</p><p>「用最贴切的词语来表达……他们会尝试进行最后一次、最盛大的『终极飞升』。」</p><p>「他们会试图以凡俗之力，超脱宇宙，飞升界外，抵达一个比本宇宙更‘高’的世界。」</p><p>听起来非常玄幻。</p><p>但这里确实是个玄幻的异世界。</p><p>「但是，只差临门一脚就能实现终极飞升的强者、文明，会被神圣星环盟约提前堵截。」</p><p>「耶罗说，‘那些至强者以为自己是被选中的天骄，在星环盟约引导下踏向飞升，实则是踏入了神圣星环盟约的牢笼’。」</p><p>「耶罗说，当某个宇宙诞生出足以威胁星环盟约统治的个体存在，他们便会以飞升为诱饵，将强者……带走。」</p><p>「那些被带走的至强者，一旦离开自己的宇宙，便如同石沉大海，不知去向。」</p><p>「飞升是一场骗局。」</p><p>杨帝眉头紧锁，心中涌起难以言喻的忧虑。</p><p>倘若这一切属实，那神圣星环盟约的行径简直令人发指，无数怀揣着终极飞升梦想的强者，竟在毫不知情中沦为了猎物。</p><p>当然，前提是——属实。</p><p>“神圣星环盟约为何要这么做？”</p><p>原初之眼像是看穿了他的心思，缓缓说道：「耶罗大仙推测，神圣星环盟约或许是为了垄断自己的『虚空霸主』地位。」</p><p>“虚空霸主？”</p><p>「话本编撰者说，宇宙之上还有宇宙，世界之上仍有世界。」</p><p>「最终极最上层的世界，并非是我们通常所理解的‘空无一物’。那是一片比‘虚无更空旷’的地方，所以被称作『虚空』。」</p><p>「神圣星环盟约，便是在这片虚空之中崛起的一股最强大的势力。」</p><p>「他们或许意识到，每一个能够突破宇宙极限，实现终极飞升的强者或文明，都有可能成为他们在虚空中的竞争对手。」</p><p>「为了维持自己在虚空的统治地位，确保自己‘虚空霸主’的独尊，他们便对各个宇宙中即将飞升的至强者下手。」</p><p>如果真如祂所言，那么神圣星环盟约的野心简直大得超乎想象。</p><p>“但这只是耶罗大仙的推测？并没有确凿的证据？”杨帝问道。</p><p>「是的，这是基于现有情况的推测。」</p><p>“那为什么‘星环盟约’不来将你我接走？”</p><p>「……我不敢肯定，那我可以转述耶罗的回答给你。」</p><p>「我也对话本编撰者问过相同的问题，祂的回答是：虚空中出现了一场天灾，而星环盟约内部也出了状况。」</p><p>「至于那是场怎样的天灾，他们内部又出现什么状况？话本编撰者只透露了很少的情报。」</p><p>「天灾，名为‘魙敗’，意思是万物正在走向不可逆转的死亡——我这个词是我意译过来的，祂原话是一个更晦气难懂的词汇，我只能转达其音调——」</p><p>「duàn gēng」</p><p>「内乱，是有些他们招揽的至强者叛变了。」</p><p>「内外压力，他们应接不暇，所以暂时搁置了对各个宇宙至强者的接应。」</p><p>听起来像是封建王朝走向暮年。</p><p>内部藩镇割据、党争不断，外部群狼环伺、天灾肆虐，神圣星环盟约陷入风雨飘摇之境地。</p><p>“耶罗有没有告知这场‘魙敗’天灾具体什么情况？还有那些叛变的至强者，他们又有着怎样的目的？”杨帝追问。</p><p>「关于‘魙敗’，耶罗只是提及它代表着万物不可逆转的死亡，但具体的形式和成因，并未详细说明。」</p><p>「似乎就连他也对这场天灾所知有限。」</p><p>「而叛变的至强者，祂所知甚至更少，只知道甚至有星环盟约高层人物也叛变了。」</p><p>「但可以肯定的是，星环盟约对边疆宇宙的掌控力已经大幅削弱。」</p><p>「最直接的证据，就是你手中这座‘无限机兵’——它需要人，才能驾驶激活，而非全自动作战。」</p><p>无限机兵由星环盟约出品。</p><p>它蕴含极其强大的力量。</p><p>这台强大的兵器，既然出自神圣星环盟约之手，那么是否也是他们宏大计划的一部分？</p><p>“无限机兵应该是全自动的？”杨帝追问。</p><p>「曾经是。」</p><p>「你猜，为什么它是‘无限’机兵？」</p><p>「无限机兵，如果是正常状态，它会从所有时间点和世界线上同时启动，同时攻击同一个目标。」</p><p>「组合成……耶罗称之为‘无限机兵防卫圈’的超级优势火力+无限人海战术结合的战争体系。」</p><p>（十三机兵防卫圈，剧情特别酣畅。）</p><p>「它本质上是星环盟约为宇宙安装的‘疫苗机制’，会攻击被判定为‘目标’的存在。」</p><p>“这个‘目标’，是以什么为标准？”</p><p>「抵达‘终极飞升’阶段的至强者，或宇宙级文明，都是‘它们’的目标——我解析了机兵的部分源代码，虽然只能勉强理解其中5%左右，但我确实发现，机兵会将个体至强者、宇宙级文明设定为目标。」</p><p>“但现在，无限机兵没有按照设定程序正常工作。”</p><p>「所以，仅凭这一点，就可以证明星环盟约自顾不暇。」</p><p>「否则，当我展现出宇宙至强者的实力时，无限机兵就不可能仅仅是出现在了物质界，却没有更多动作。」</p><p>「当你非法驾驶无限机兵，也没有触发它的反制措施。」</p><p>「它们处于‘离线’状态，没有成功连接上神圣星环盟约的主机。」</p><p>原初之眼酣畅淋漓地说话。</p><p>杨帝酣畅淋漓地获得大量信息情报。</p><p>直到他认为时机成熟，这才打断原初之眼。</p><p>“打开天窗说亮话吧，大眼珠子。”</p><p>杨帝说，“大脑封闭术，我已习得。”</p>
