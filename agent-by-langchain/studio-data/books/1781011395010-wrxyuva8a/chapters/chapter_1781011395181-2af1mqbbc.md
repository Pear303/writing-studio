# 我执思

<p>“阿巴，你不能死，你有重要的历史使命，那就是研究明白我的‘超量代偿’能力来源。”</p><p>杨帝说着，将最后一口阿巴的“感悟”吮吸干净。</p><p>当然，“吮吸感悟”的操作是复制，而不是剪切。他没那么缺德。</p><p>时间已过去700毫秒。</p><p>“我……我不是什么万古鱼尊，我是老大的克隆鱼？我是被扭曲了形态的老大……？”</p><p>“不，阿巴，你不是我。我曾在火车上对你说过，学我者生，像我者死。你就是你，你就是阿巴，万古鱼尊。”</p><p>杨帝疯狂灌鸡汤，稳住阿巴心神。</p><p>时间已过去800毫秒。</p><p>“可是，老大我明明是深海鲈鱼，不是什么人类……”</p><p>“我把你克隆出来之时，其实是个人。鲈鱼反而是你‘化形’所变——那个时候你已经开启了基因锁，否则早被核辐射摧残得全身癌变了！”</p><p>“轰——！！！”</p><p>创世斧光的毁灭之力，彻底淹没了杨帝意识与阿巴记忆本源建立的链接。</p><p>59改因为在杨帝、阿巴中间充当网线，他将近99%的身体被斧光直接崩毁。</p><p>创世斧光，已经斩开一道1AU长的裂缝。</p><p>时间已过去900毫秒。</p><p>杨帝那双圆咕噜溜，刚被抹除又勉力重生的眼珠子，骤然失去所有神采。</p><p>并非死亡，而是……入梦！</p><p>杨帝的意识，以一种超越了时间与消亡的诡异方式，遁入一个由自身意志强行开辟的、比刹那更短的梦境。</p><p>梦中梦中梦，20^3=8000……还是不够！</p><p>再嵌套一层梦境，对杨帝而言反而很危险。</p><p>如果是普通人，还能用诸如“重心被改变的象棋”、“一面灌铅的骰子”，用这些图腾确认自己是否还处在梦中，或是已经回到真实的现实。</p><p>但本宇宙除去圣人，杨帝就是最强大的灵能者，又称现实扭曲者。</p><p>不论是在现实还是在梦境，他都能随意扭曲自己的图腾。</p><p>没有好的图腾可用，杨帝最终会陷入永无止境的怀疑——怀疑自身是否仍然未回到真正的现实。</p><p>然而，事已至此，冒点小小的风险又如何。</p><p>一直以来，杨帝习惯挨打就能变强。</p><p>他也因此形成路径依赖：如果遇上暂时不可战胜的敌人，那就先挨一顿打吧。</p><p>面对机制怪，他无可匹敌的数值仍然发挥了作用，撑爆了机制所能抵达的上限。</p><p>但现在，杨帝的目标不只是让自己活着，他还需要保全世界万物。</p><p>一人吃饱全家不饿，这是最轻易就能触及的境界。</p><p>杨帝必须走出舒适圈，超越这个境界。</p><p>20^4=160000，十六万倍速。</p><p>幻境一弹指，世上已春秋。</p><p>杨帝的意识，那源自异界的、不被此界天道完全束缚的本质，开始了难以想象的超速解析与适应。</p><p>梦中无岁月，一念即万古。</p><p>亿万次模拟！亿万次崩解！亿万次重构！</p><p>杨帝要细细剔除阿巴感悟中的“污染”，防止自己精神分裂。</p><p>随后在梦中模拟出场景，二度、三度、一百度重复阿巴的理解、记忆、感悟。</p><p>就像将同一部电影，重复播放千八百遍，但是将主角替换成自己，让自己沉浸于电影主角的视角。</p><p>一百毫秒，十六万倍速。</p><p>并不是在梦中单纯的感悟，而是奉行拿来主义，直接无缝插入阿巴的感悟。</p><p>「精神+1」</p><p>啧，还是有些许“排异”吗？</p><p>超过一定阈值的外来“模因”，无法感染杨帝的心智。</p><p>就像他吞噬原初之眼的记忆，却没有因祂兆亿年的岁月而“孤寂”。</p><p>杨帝仍然是杨帝自己，心智只能在冥冥中某种合理安全的范围内改变。</p><p>这个“合理安全”，又是由谁定？</p><p>为什么在溺水窒息后，他会进化出在水下呼吸的体质，而不是让自己肺和鼻演化为鳃？</p><p>为什么骨折后能获得超速骨骼再生，和更强的骨硬度？</p><p>为什么不是进化成“史莱姆”那样的无脊椎生物？</p><p>变成史莱姆不就一劳永逸、不会骨折了吗？</p><p>为何他被拆解为比普朗克尺度更小的“杨帝碎片”时，再恢复成人形，仍然是原来的模样。</p><p>而不是变成一大团不成人形血肉触须？</p><p>“对自我的定义……当自我发生改变，如何判定是受到有害的‘伤害’，还是在有益地‘进化’？”</p><p>血条下降是有害的损伤，血条上升是有益的进化。</p><p>血肉的强度增加是有益，血肉的强度减少是有害。</p><p>是谁在冥冥中决定孰好孰坏？</p><p>“或者说，我能力的本质，其实是为了阻碍我‘发生改变’？”</p><p>这个念头如同创世斧光本身，劈开了杨帝认知的混沌。亿万次自身的经历疯狂印证，指向一个颠覆性的真相。</p><p>“是的！阻碍改变，这才是‘超量代偿’最底层的逻辑……”</p><p>它并非追求“更好”或“更强”，它的核心驱动力，是维持“杨帝”这个存在的基准状态。</p><p>在物理上，任何试图改变他物理形态、生理结构的外力，都会被判定为“损伤”。</p><p>能力启动，不是为了让他“进化”成更适应环境的形态，如史莱姆。</p><p>而是疯狂地将杨帝拉回、并加固在基准态的人形物理结构上！</p><p>骨头断裂？那就再生得更硬、更强韧，让下一次同等级别的外力再也无法造成骨折。</p><p>溺水？不是进化出鳃，因为那会改变生理结构，而是让肺部生成类似“现实扭曲”的效果，从水中提取氧。</p><p>强大的“基准态”锚定力会强行将每一颗粒子拉回原位，重组为杨帝，而非一滩肉泥。</p><p>物理损伤的阈值越来越高，正是因为能力在不断加固基准态的壁垒，让“杨帝被改变”发生的门槛高到不可思议。</p><p>精神层面更为复杂，但同样如此。</p><p>吞噬原初之眼的记忆洪流？精神污染试图改变他的心智、认知、人格。</p><p>能力判定此为“损伤”，当即启动防御机制，顽固地守护着他“杨帝”的核心意识——不被污染，不被篡改。</p><p>于是，这位积淀了亿万年阅历的古老存在，归来仍是少年。</p><p>“并非‘挨打就能变强’，而是‘挨打会变得更难挨打’……”</p><p>他的物理外形与精神状态，至今未有显著改变。</p><p>但在微观视角下，那些看似与凡人无异的肌肉细胞，却能轻易爆发出堪比超新星的力量。</p><p>这就像一具能硬扛刀剑的钢铁之躯，天生便拥有一掌击碎人颅骨的力道。</p><p>他的力量，他对技能的熟练度，不过是肉身抗性提升所带来的副作用罢了。</p><p>杨帝在十六万倍速的思维风暴中，骤然抓住了这能力的真髓。</p><p>“不允许改变……自我。”</p><p>生成「自我」的第七识，末那识。</p><p>阿巴的记忆，他虽能学习理解，但却无法把握住那到一闪即逝的灵光。</p><p>但如果，阿巴就是杨帝呢？</p><p>“如果我能扩展对‘自我’的定义……”</p><p>……</p><p>时间已过去999毫秒。</p><p>灭世斧光终于完全穿过了杨帝所在的位置。</p><p>时空被剜去一块，留下纯粹的虚无混沌。杨帝的气息、形态，彻底消失无踪。</p><p>“成……成功了？！”涅槃轮劫元尊咳出带着道则碎片的本源之血，眼中带着难以置信的狂喜和深藏的疲惫。</p><p>以及一缕难以言表的不安。</p>
