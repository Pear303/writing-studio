# 轮回副本主题

<p>“滴——”</p><p>最后一声长音响起，刺耳的警报声如同被掐住脖子的鸡，戛然而止。</p><p>门禁面板上，锁死的红灯“啪”地熄灭，取而代之的是一抹代表解除锁定的绿光。</p><p>“嘎吱——轰隆隆……”</p><p>沉重到令人牙酸的金属摩擦声响起，巨大的合金门在液压装置的推动下，缓缓向内打开了一条缝隙。</p><p>一股更加浓郁，混杂着腐臭、消毒水、以及某种化学药剂烧焦味道的气息，猛地从门缝里喷涌而出，冲击在走廊里每一个人的脸上。</p><p>火鸦嫌弃地捂住口鼻，指尖的火苗差点被这污浊的气流吹灭：“呕……这味儿比主神空间的公共厕所还冲！”</p><p>“眼镜，干活！”</p><p>眼镜——那个戴战术目镜的瘦小两脚兽——立刻凑到门边，手腕上的金属环投射出一道细细的蓝光，尝试入侵门禁系统。</p><p>擅长念力的干净两脚兽率先侧身，谨慎地挤进了那条门缝。</p><p>高大的两脚兽啐了一口，握紧狼牙棒跟上。</p><p>实验室内部一片狼藉。</p><p>应急红灯的光芒透过弥漫的淡紫色薄雾，给所有东西蒙上一层不祥的血色。</p><p>实验台翻倒，玻璃器皿粉碎，凝固的深色污渍溅得到处都是。</p><p>两具穿着白大褂、姿势扭曲的尸体倒在门附近，皮肤呈现出一种诡异的青灰色。</p><p>眼镜的蓝光扫描着中央控制台残破的屏幕。</p><p>他将数据线插到主机内，开始敲电脑。</p><p>就在他专注于下载数据时，实验室深处……</p><p>一个极其魁梧的身影，正以一种与其庞大体积不符、近乎无声的僵硬步伐，缓缓挪了出来。</p><p>他，或者说“它”，一只眼睛只剩下浑浊的白翳，另一只则闪烁着非人的、饥饿的暗红光芒。</p><p>它的下颌不自然地张开，露出森白的牙齿和挂着粘稠唾液的牙龈。</p><p>它沉默地，向全神贯注操作电脑的眼镜走去。</p><p>它沉重的脚步落在地面覆盖的玻璃碎片上，发出极其轻微的“咔嚓”声。</p><p>“眼镜！后……”队长的念动力感知最快，他猛地转头，厉声警告。</p><p>那魁梧如海格力斯的来者，动作看似僵硬，速度却快得惊人！</p><p>它一步跨过翻倒的实验台，肌肉虬结的手臂带着一股恶风，直直朝着眼镜的后脑勺抓去！</p><p>指尖乌黑尖锐，闪着金属般的光泽！</p><p>“啊——！”眼镜发出尖锐爆鸣，一个翻转卡无敌帧，险之又险躲过这一劫。</p><p>嗤啦！</p><p>那厮的利爪擦着他的战术背包划过，坚韧的合成纤维背包像纸一样被撕开一个大口子，里面的零件和线路板哗啦啦掉了一地。</p><p>“火鸦！烧它！”铁砣怒吼一声，巨大的狼牙棒朝着丧尸的腰腹横扫过去！</p><p>铁砣平地一摔，失去意识。</p><p>火鸦反应也快，指尖的火苗猛地窜起，朝着丧尸的面门射去！</p><p>火苗仍然只有打火机喷出的火焰大小。</p><p>“噗”的一声轻响，那点可怜的小火苗精准地撞在丧尸毫无表情的脸上，然后……熄灭了。</p><p>连点焦痕都没留下，只燎掉了几根它脸上沾着污垢的眉毛。</p><p>来者似乎被这微不足道的攻击激怒了，或者只是单纯地被铁砣那声势浩大的一摔，吸引了注意力。</p><p>它猛地转头，那只完好的暗红眼睛锁定了铁砣。</p><p>“操！这铁砣又踏马脚滑？”</p><p>执掌“念力”的小队队长很心累。</p><p>姑且称这位来敌“施瓦辛格”，因为对方体型和模样都很像。</p><p>施瓦辛格缓步而来，巨大的手掌带着撕裂空气的呼啸，朝着铁砣当头拍下！</p><p>这一掌要是拍实了，铁砣的脑袋绝对会像西瓜一样爆开！</p><p>他虽然防御力出众，是轮回者小队里的主T。</p><p>但那是在他清醒的情况下，发动“龟岩金身”技能，才可以取得的效果。</p><p>队长一脸嫌弃，念动力瞬间爆发，将瘫倒在地的大块头两脚兽拉回。</p><p>施瓦辛格继续逼近，压迫感铺天盖地。</p><p>“老大！我带睡着了的‘影子’走一步！！”火鸦大叫道。</p><p>影子患有极度的社交恐惧症，只要人多起来，不管是不是活人，他都会吓晕。</p><p>她背着一大团黑色阴影，转身就扑向最近的天花板通风口。</p><p>眼镜连滚带爬，顾不上散落一地的设备了，也手脚并用地冲向通风口。</p><p>“干净的两脚兽”面容苦涩。</p><p>他作为这支轮回者小队的队长，到目前为止没多少业绩，穷得快揭不开锅了。</p><p>队长用念动力卷起几张翻倒的实验台，狠狠砸向那再次逼近的施瓦辛格，试图争取时间。</p><p>但因为还要同时将铁砣拉回来，一心二用，他准头非常差。</p><p>试验台并没有击中目标，只是挡在了施瓦辛格面前。</p><p>不管那么多了。</p><p>队长用念力背着铁砣，冲向通风口。他回头看了一眼。</p><p>那个魁梧的施瓦辛格，正用蛮力撕开他砸过去的金属实验台，暗红的独眼死死锁定着他。</p><p>它迈开沉重的步伐，再次追来。</p><p>哈基米缩在走廊角落，眼睁睁看着那几个可怕的两脚兽如同被猛兽追赶的兔子，以极其狼狈的姿态，争先恐后地钻进天花板那个被他们暴力撬开的通风管道口。</p><p>最后进去的是那个“干净”的两脚兽。</p><p>他进去时，一股无形的力量“砰”地一声将通风口的格栅重新拉上，扭曲变形地卡在洞口。</p><p>紧接着，沉重的撞击声就从那被堵住的通风口传来。</p><p>“咚！咚！咚！”</p><p>每一下都震得天花板簌簌落灰。金属格栅肉眼可见地向外凸起、变形。</p><p>——那个长得很像施瓦辛格的恐怖两脚兽，正在疯狂地砸门！</p><p>……</p><p>通风管道内弥漫着陈旧灰尘、铁锈和下方飘上来的淡淡腐臭混合的刺鼻气味。</p><p>狭窄的空间里挤着四个狼狈不堪的轮回者，算上影子那团阴影是五个。</p><p>铁砣瘫在冰冷的金属管壁上，火鸦背靠着管壁，队长沉默不语。</p><p>眼镜脸色惨白，战术目镜的微光映着他额头的冷汗，他正疯狂地操作着手腕上的终端，调取刚才千钧一发下载到的实验室日志碎片。</p><p>影子依旧是一团融在角落的沉默阴影，仿佛晕过去就没打算醒。</p><p>“队长……”</p><p>眼镜的声音带着难以置信的颤抖，打破了压抑的寂静，“日志……红皇后的核心日志不对劲，非常不对劲！”</p><p>“说重点！”队长说。</p><p>“这座研究所的主控AI名为‘红皇后’，她执行了最高级别生物污染协议，封闭了实验室，释放了神经毒气，目的是……清除所有有机生命体。”</p><p>“机器疯了？！原因呢？”</p><p>“我临走前只来得及取出一部分日志文件，另外一部分还来不及拷贝……原因不明。”</p><p>队长的心脏猛地一沉。</p><p>他的超级大脑发动演绎推理。</p><p>所有的线索瞬间串联起来，指向一个令人毛骨悚然的真相：</p><p>那个力量恐怖，动作僵硬，表情冷淡的“施瓦辛格”……更像一台执行程序的杀戮机器。</p><p>它是机器人。</p><p>这是一场精心策划的智械叛乱。</p><p>“所以，那个追着我们的……”</p><p>火鸦的声音干涩，指尖的火苗因为她的颤抖而明灭不定，“是终结者？T系列？”</p><p>“终结者？三次轮回前我们遇到的那个？”</p><p>“你我都清楚，主神喜欢素材复用。终结者这个‘素材’……祂也许在这里复用了。”</p><p>“这次的轮回副本，是‘智械叛乱’！”</p>
