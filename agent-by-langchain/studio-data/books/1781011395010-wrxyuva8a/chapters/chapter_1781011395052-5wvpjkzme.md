# 单刷烂尾楼3

<p>杨帝弯下腰捡起几块干木板，补充到壁炉之中。</p><p>火焰得到新的燃料，猛地蹿高，将整个房间照得更亮了些。</p><p>他重新躺回到木板床，躺下，脑袋枕在胳膊肘上，注视灰色的天花板。</p><p>人在狭窄空间内睡觉时，偷偷将他门窗都给堵上……这是非常不道德，不文明的行为。</p><p>而在城市里，还常见另一种不道德的行为。</p><p>那就是在别人睡觉的时候，制造噪声污染，比如跳广场舞的大妈，或者是国道上的飙车党。</p><p>杨帝重新躺下时，耳边出现一些声音。</p><p>起初，只是令人毛骨悚然的窸窸窣窣声，从墙壁和天花板传来。</p><p>声音很密集，但也微弱。把它当做白噪音，还是能入睡的。</p><p>而后，声音愈发清晰明显。</p><p>已经达到噪声污染的范畴。</p><p>仿佛无数细小的爪子在墙体内攀爬，又像是有什么东西，在空心墙体里啃食着什么，摩擦声令人牙酸。</p><p>那种感觉是……墙里藏了几百万只老鼠。</p><p>又开始了，这栋楼，满是恶意。</p><p>杨帝眉头微皱，握紧手中撬棍，缓缓走到墙边，侧耳倾听。</p><p>老鼠的吱吱声。可能有些小强，但不多，主要是耗子，大量的耗子，藏在墙里。</p><p>这面墙看起来很完整，并没有太多裂缝和孔洞。</p><p>21世纪最大的谎言、最成功的骗局，就是让人们相信——老鼠洞都会长得像《猫和老鼠》里面那种规整的拱门形状洞口。</p><p>实则不然。鼠洞并非拱门型。</p><p>老鼠洞往往是不规则的，狭小且隐蔽，只要能容下老鼠灵活的身躯便可。</p><p>童年除了饱览《猫和老鼠》，同时常刷《动物世界》的杨帝深知这一点。</p><p>他仔细观察墙面，确实在墙底，发现几个不规则孔洞。</p><p>墙中有鼠，铁证如山。</p><p>老鼠是四害之一，人人诛之。</p><p>他举起撬棍，朝着发出声音最响亮的地方，猛地戳进去！</p><p>“砰！！”</p><p>墙皮簌簌落下。</p><p>将螺纹钢撬棍拔出来，但……撬棍上并没有带出什么东西。</p><p>杨帝抖落上面附着的墙灰，目光紧紧盯着那被砸出的坑洞。</p><p>透过洞口，没有看到想象中乱窜的老鼠。</p><p>但从那墙洞里透出的一股腐臭气息，类似于从时间深处腐朽的墓穴中散发出来的。</p><p>那窸窸窣窣的声音不仅没有停止，反而愈发密集。</p><p>杨帝目光在房间内扫视一圈后，毅然转身朝着楼下走去。</p><p>仅靠暴力，似乎难以解决这隐藏在墙内的麻烦。</p><p>来到一楼，这里的积水依旧散发着令人作呕的气味。</p><p>他找到了几根浸泡在水里的塑料和木头，都是湿漉漉的。</p><p>他将这些材料拖回二楼房间。</p><p>首先，重新往壁炉里添加了一些干木板，让火势更旺些。</p><p>接着，他把找来的湿塑料、湿木头，一一架在火焰上。</p><p>塑料遇热迅速融化，发出“滋滋”的声响，伴随着刺鼻的气味，与原本的腐臭混合在一起，愈发浓烈。</p><p>腐朽的湿木头也开始冒烟，滚滚浓烟升腾而起，迅速弥漫了整个房间。</p><p>杨帝将门窗再次用砖头封死，只留下一个小缝隙，确保烟雾不会过快散尽。</p><p>他在四周的墙上戳出几十个洞。</p><p>剧毒烟气透过墙洞，浸润了墙体内部的空腔。</p><p>杨帝站在一旁，看着浓烟一点点往墙壁的缝隙里钻，一边饱吸着新鲜的一氧化碳、氯化氢和二噁英。</p><p>「生化抗性+1+1+1+1」</p><p>一般，甚至不能对杨帝造成致死性伤害。</p><p>随着毒烟弥漫，墙壁里的动静似乎更大了。</p><p>窸窸窣窣声变成了一片混乱的嘈杂，仿佛墙内的生物正在遭受巨大的痛苦。</p><p>当然，也有可能是里面的东西毒烟上头，吸嗨了。</p><p>但没过多久，墙里的动静竟逐渐小了下去，那混乱的嘈杂声也慢慢归于平静。</p><p>看来是第一种可能。</p><p>整个房间陷入了一种死寂般的安静。</p><p>只有壁炉中偶尔传出的“噼里啪啦”声，以及浓烟在空气中弥漫飘动时发出的轻微“簌簌”声。</p><p>他握紧撬棍，靠近墙壁，耳朵贴在墙上。</p><p>除了水泥墙体内，钢筋受热膨胀的“砰砰”声，再也听不到任何来自墙内的动静。</p><p>他将封堵窗户的砖头一块块挪开，空气灌进屋内，冲淡了那令人作呕的混合气味。</p><p>杨帝走向房门，同样打开通道，让空气在房间内形成对流。</p><p>他将湿漉漉的木头和塑料挪到房间外。</p><p>重新处理好壁炉火堆，用干木板而不是湿木材，让烟雾恢复平常。</p><p>又一次，在木板床上躺下。</p><p>但这回，被墙壁中的鼠鼠一折腾，杨帝又有些睡不着了。</p><p>他又想起那一日所发生的事情。</p><p>他爬起身来，找了几块被烤得熏黑的木炭，掰下一段作为炭笔。</p><p>他在地上画出一个图案：三根弧线，从外向内，绕成一个漩涡。</p><p>漩涡图案在火光燎烧之下，扭曲成精似的。</p><p>“耶罗大仙，卡耳叩山的守望者，吞噬光明的漩涡之主……”</p><p>他模仿那个邪教徒的祭词。</p><p>什么都没发生。</p><p>房间里依旧只有壁炉中火焰燃烧的声音，以及偶尔从窗外传来的风声。</p><p>杨帝沉默地盯着地面上那个被火焰扭曲得不成样子的漩涡图案，眼神中闪过不甘，和预料之中。</p><p>蹲下身子，用手掌将那漩涡图案一点点地擦掉，地面上只留下一片漆黑的痕迹。</p><p>杨帝站起身，右手握拳往墙上一砸。</p><p>“轰！”</p><p>水泥墙壁上出现一个深深的坑洞，墙皮和碎砖簌簌落下。</p><p>他把陈昭那的资料都研究了一遍，整个稷海理工大学的村落旧址都走访了一遍。</p><p>从来没有提到过耶罗大仙的召唤方法。</p><p>因为，陈昭把重要的资料都收集到一起。</p><p>而后，他的“灵”被吞食，存在遭到抹除。</p><p>结果，与陈昭建立起强因果关联的那些重要资料，也一并消失在世上。</p><p>包括“如何见到耶罗大仙”的资料。</p><p>也被当作“陈昭的一部分”，从而遭到抹除。</p><p>特别是，杨帝还缺少了应该是很重要的仪式道具——耶罗符印。</p><p>他也尝试自己找了块铁饼，刻上漩涡图纹，但毫无用处。</p><p>后来用红铜饼，青铜饼，不锈钢饼，乃至塑料饼，都是一样无效。</p><p>耶罗符印是特殊的，不可仿制的。</p><p>但他唯一能找到的真品，已经被陈昭消耗掉，作为觐见耶罗大仙的通行证。</p><p>杨帝坐在木板床上，盯着火光，看了许久。</p><p>睡不着，真的睡不着。</p><p>他扛起撬棍，又往兜里揣了块好砖头，便走出房门。</p><p>已经没心情睡了，便起来走走吧。</p><p>夜晚阴气重，魑魅魍魉出没。</p><p>正好杨帝在这楼里待了这么久，也没正面打爆过什么东西，拳头痒痒，想要发泄。</p><p>他去了几间门开着的房间，收获寥寥无几。</p><p>除了一些腐朽的家具，随处可见的灰尘，破抹布，烂麻绳，绣钉子，实在没什么值得关注的东西。</p><p>走廊里，总有隐隐约约的声响，像是女人在哭泣，孩童在远方尖叫。</p><p>或许是风在楼道里穿梭，发出的呜咽。</p><p>要是一般惊悚片影视剧，主角团大约会循着声音，去找那怪声的来源。</p><p>……杨帝也不例外。</p><p>那声音时而清晰，时而模糊，挑动着人的神经。</p><p>仿佛，或者说根本就是在故意引诱他深入。</p><p>这楼里有很多东西都在诱惑人。</p>
