# 阶段结算

<p>黑色毛球炮弹的速度，在近乎真空的宇宙环境中，并没有减速的势头。</p><p>它表面的毛发已不复最初的光泽，布满了熔融的坑洞和烧蚀的痕迹，体积也缩小了近三分之一，显得更加凝练、坚硬，如同宇宙中一块饱经磨砺的黑色玄铁。</p><p>如果有星际友人路过，比如摄影爱好者啊，来自某某星的间谍啊，见到杨帝的毛发球时。</p><p>或许会认为这是个一般路过的野生陨石。</p><p>说曹操曹操到，黑色毛线球身边，就很幸运地飘过一颗野生陨石。</p><p>那是一颗铁陨石，没有多少水。</p><p>不过不要紧。被摊成薄饼、正在缓慢复原成人形的杨帝大手一探，抓住铁陨石，像拧海绵一样，将铁陨石中的结晶水拧成几十克的液态水。</p><p>随后，用特殊的指法引发陨石中的铁质发生裂变。</p><p>对……就这样……精准地裂变出氢和氧。</p><p>能够做到这一点的人，打任何难度的音游都是初见即秒杀。</p><p>氢和氧，再拼拼凑凑出水、氧气。</p><p>他先是自己喝了几口，然后将剩下的纯净水、氧气输送到黑色毛球内。</p><p>影子解除“虚化”技能。她几乎累成路边一条了，再多撑一阵子就得把众人强制弹出。</p><p>幸好在这种情况发生前，杨帝已经在毛发球里，囤了足够多的水和氧气。</p><p>轮回小队5人，在毛发球里大口呼吸。</p><p>毛球外，杨帝喝了几口水润喉，他也终于能说话了。</p><p>他那破碎嘶哑、仿佛从地狱油锅里冒泡的声音，在轮回小队的意识连接中响起，带着一种令人头皮发麻的平静：</p><p>“队长，现在有空，咱聊聊‘主神空间’、和‘NPC’，还有……‘轮回者’是什么东西。”</p><p>队长五人脑瓜子嗡嗡嗡，表示大受震撼。</p><p>外面这位爷，身体都变成摊在热锅上的肉酱了，声音都嘶哑得像破风箱了，居然还有心思问这个？</p><p>这得是多么强大的意志。</p><p>“杨帝先生！您先专心……” 队长试图劝阻。</p><p>“我没事，巴适得很。”杨帝回答，他声音的确中气十足。</p><p>队长只好解释：</p><p>“主神空间，是一个凌驾于我们理解之上的存在。它把我们从各自的世界抓走，丢进像这里一样的‘副本世界’执行任务。</p><p>“完成任务，就能获得‘积分’。积分能兑换一切！修为、武器、技能、血统……甚至成神登仙，不过那只是理论上的。</p><p>“轮回者，就是我们！被主神选中，在无数恐怖世界挣扎求生的人。</p><p>“NPC，即Non-Player Character，非玩家角色，就是副本世界里原本存在的人物。就像……红皇后，还有那些死掉的船员。</p><p>“他们通常是任务的一部分，提供线索、发布任务或者是敌人。</p><p>“虽然轮回者惯称他们为NPC，但实际上，我们小队认为他们应该是和我们一样的活人……</p><p>“主神商店，是用积分兑换东西的地方。可惜……我们太穷了，穷得买不起能扛住这场爆炸的道具。</p><p>“副本，就是我们现在所在的这个‘世界’。主神会给我们发布任务目标，比如在这个副本里，我们的任务是‘阻止大屠杀’。”</p><p>队长一口气说完。其实阴影状态下的他，也不需要呼吸。</p><p>他尽可能地解释着主神空间的残酷规则、轮回者的挣扎、积分的万能与匮乏——对他们而言很是匮乏。</p><p>“主神空间……主神……听起来，该杀。”</p><p>毛发球外，那摊被“煎烤”的肉酱猛地向内收缩、凝聚。</p><p>一股浩瀚无边的生命波动冲天而起！</p><p>化神期，突破！</p><p>他刚刚经历了堪比地狱的煎烤，此刻却仿佛浴火重生的神魔，毫发无伤，气息比爆炸前强大了何止百倍。</p><p>不过，这种进化也只是「肉身」层面的化神期水平。</p><p>他的目光扫过如同鹌鹑般挤在毛发球中，仍惊魂未定的轮回小队五人。</p><p>“便签纸，还给我。”</p><p>“豪德，豪德……”</p><p>“现在，带路。”</p><p>“去哪？”</p><p>“去那什么劳什子‘主神空间’。”</p><p>“杨帝先生，主神空间不是我们说去就能去的。”</p><p>队长艰难地咽了口不存在的唾沫，“我们需要完成这里的任务，由主神结算后，才能……”</p><p>话音未落。</p><p>一个毫无感情，却又清晰得如同直接在每个人灵魂深处响起的声音，毫无征兆地降临：</p><p>【叮！】</p><p>【副本世界：群星之战（S级副本）】</p><p>【副本任务：阻止大屠杀（进度 12%）】</p><p>【第一阶段任务：科研舰惊魂】</p><p>【任务状态：完成】</p><p>【任务评价：95%】</p><p>【奖励结算：基础积分+95……】</p><p>这声音如同天籁！轮回小队五人瞬间狂喜涌上心头，几乎要喜极而泣！95%评价！他们活下来了！而且是几乎是最高的评价！</p><p>这意味着海量的积分和珍贵的奖励！足以让他们脱胎换骨。</p><p>然而，这份狂喜仅仅持续了不到一秒。</p><p>火鸦打着寒战指出：“但这个‘第一阶段’是什么意思？”</p><p>众人噤声。</p><p>他们想到一个恐怖的可能。</p><p>恐怖的可能下一秒就应验了。</p><p>那个冰冷的机械音再次响起，内容却如同九幽寒风，瞬间冻结了他们刚刚沸腾的血液：</p><p>【第一阶段结算完毕】</p><p>【第二阶段任务开启】</p><p>【第二阶段任务：虫影迷踪】</p><p>【第二阶段目标：探明虫族的动向，阻止幕后之手发动大屠杀】</p><p>【第三阶段任务（待解锁）：图兰泽】</p><p>【完成第二阶段任务后方可解锁详情】</p><p>巨大的落差和更深的绝望瞬间吞噬了他们。</p><p>刚刚从地狱边缘爬回来，还没喘口气，就被主神一脚踹进了更深、更黑暗、更凶险的炼狱！</p><p>怎么还有第二甚至第三阶段呐？</p><p>屁事真多。</p><p>杨帝敲了敲自己的太阳穴：“这个声音，就是你们所说的‘主神’？”</p><p>“您也能听到？！”</p><p>“看来，主神似乎是把我也判定成‘轮回者’了。”</p><p>轮回小队五人闻言，恍然大悟！</p><p>怪不得这么弱鸡这么菜的他们，被甩进了S级副本！</p><p>他们原本还想——自己究竟何德何能？</p><p>原来是被杨帝平均了。</p><p>杨帝搓搓手：“我不打算坐以待毙，傻乎乎做什么副本任务。弈局胜负，在棋盘内，更在棋盘外。”</p><p>他闭上了眼睛。</p><p>并非休息，而是将化神期浩瀚无垠的神念，顺着脑海中那冰冷机械声音留下的、几乎微不可查的痕迹，逆流而上。</p><p>他要“扒网线”，顺藤摸瓜。</p><p>这念头本身，就足以让任何知晓主神存在的轮回者魂飞魄散。</p><p>那是亵渎！是自寻死路！</p><p>杨帝的神念在虚无的维度中穿行，速度超越了光，超越了时空的概念。</p><p>阻力！难以想象的阻力！</p><p>仿佛整个宇宙的规则都在排斥他，要将他这个试图窥探“管理员后台”的“病毒”彻底格式化。</p><p>但这种行为本身，反而使杨帝的精神力量疯狂膨胀，以抵御冥冥中的抹杀。</p><p>终于，在那冰冷管道的尽头。</p><p>他看到了。</p><p>一个存在。</p><p>它悬浮在无法描述无法理解的维度间隙中。</p><p>杨帝一眼就知道，那就是传说中大名鼎鼎的「主神」。</p>
