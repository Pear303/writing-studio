# 流浪与安身

<p>（不能3更了。）</p><p>（在这里要向各位读者致歉，为了写这书，作者燃尽了生命，青春，与头发。）</p><p>（但作者也因此触碰了某些人的蛋糕，他们做局，让我的五一假期结束了。）</p><p>（再次抱歉，不能3更了。）</p><p>（不过可以4更。）</p><p>……</p><p>如果说这个世界只有两种人真正拥有广阔的疆土、阳光和空气，一种是国王，另外一种人就是流浪汉。</p><p>——忘记谁说的了</p><p>最初一个月，杨帝像具游魂。</p><p>他睡在工地的闲置水泥管，靠便利店过期的三明治充饥，在公共厕所照镜子，见证自己的脸颊日益陌生。</p><p>他的存在感很低，很少有人注意到他。</p><p>正因如此，他没有被拉去流浪汉救助站。</p><p>一旦他被公安机关盯上，他们就会发现——自己是个未曾存在过的“黑户”。</p><p>没有护照，身份证，指纹和基因记录。</p><p>他的一切，都是从几天前，才开始被摄像头记录下来。</p><p>所幸，杨帝已经进化掉了进食、喝水和呼吸，免疫了市面上大部分常见的致死伤害。</p><p>不过他也只能做到“没有死”。</p><p>如果想要保持最佳状态，仍然需要摄入能量和物质。</p><p>尤其是在受到致死伤害，比如被枪击、车撞之后，多吃多喝才能更快超量代偿恢复。</p><p>物质上的吃喝，满足不了他饥渴的精神。</p><p>……</p><p>第二个月，杨帝把自己泡在图书馆。</p><p>从早上10点阅读到早上9点，才略作休息一个小时。</p><p>看一本书耗时很短，目光只需在一页停留5到6秒，便能移目下一页。</p><p>不到半小时，即可读完10万字中长篇小说并完全消化理解。</p><p>学术内容更难吸收，半小时只能熟练掌握2~3万字的本科级别知识。</p><p>当然这也在预料之中。</p><p>文史哲类，他可以先一眼记住，再逐个部分慢慢琢磨，可以“多线程”处理。</p><p>而自然科学遵循严密的逻辑推理，知识链条环环相扣，前一个链条没弄清楚，是无法开展下一个链条的，被迫“单线程”。</p><p>纵使如此，杨帝的学习速度仍然恐怖，远超普通人类百倍！</p><p>五个小时，精通高等数学，或者是一种编程语言，又或者是一门外语……</p><p>这是凡人做梦都不敢想的经历。</p><p>……</p><p>第三个月，杨帝发现颓废看书一个月后，自己身体机能没有丝毫下降。</p><p>这种进化是永久性的，不会随着生活习惯颓废而退化。</p><p>但他还是重新开始了每日运动。</p><p>杨帝在市图书馆-公园器材区-天桥底，三点一线往返。</p><p>至于睡觉——睡觉已无太大必要，只能算是个习惯，每日略微睡二三小时。</p><p>……</p><p>第四个月，他感到虚无。</p><p>杨帝已经对世上一切小说、散文、诗歌，乃至极致先锋的艺术，都感到厌烦。</p><p>他全心全意投入物理上的锻炼，以及自然科学的学习。</p><p>他有时会去干一些日结，然后把所有工资用去买廉价碳水馒头、整箱的运动饮料。</p><p>——大脑对接收到的信息做高强度理解和思考，能耗会提升，所以杨帝需要随时补充糖分。</p><p>不过，他任由脑子温度飙升到50℃。</p><p>如此高温，却没有任何不适，没有留下任何后遗症——他适应了将大脑浸泡在高温中。</p><p>对普通人类而言，脑温突破42℃，神经元的离子通道会像熔断的保险丝般失效，神经递质系统陷入紊乱。</p><p>超过45℃，星形胶质细胞大量释放谷氨酸，这种兴奋性神经递质，会像失控的野火般，吞噬突触连接。</p><p>50℃，维持神经元结构的微管蛋白会不可逆地变性，整个大脑如同被放进微波炉的鸡蛋。</p><p>而杨帝烧了一个多月的脑。</p><p>他所得到反馈，仅仅是几句「耐热+1」。</p><p>……</p><p>第五个月，杨帝不打算在天桥底待下去了。</p><p>因为天桥底建起了水泥锥。</p><p>还有十多个自称是“网络写手”的扑街，也来到天桥底安家，挤兑了他生活空间。</p><p>现实逼迫他开始真正的流浪生活。</p><p>当世界执意要抹除一个人的存在，流浪便是最锋利的反抗。</p><p>说来惭愧，从地理概念上看，杨帝家住在稷海市十八环，勉强也算半个稷海市土著。</p><p>但对于这座城市，他基本不熟悉。</p><p>现在，他打算弥补过去的缺憾，将稷海这座城市每一条街巷遍历一遍。</p><p>杨帝收集了很多城市的边角料。</p><p>菜市场顶棚漏雨的锈洞，立交桥下被踩碎的彩票，医院后巷猫群争夺的过期输液袋。</p><p>暴雨夜在地下通道，拉二胡的瞎子，缺一个角的搪瓷碗里两三块菊花硬币。</p><p>一次，黎明前最黑的时刻，他蹲在垃圾焚烧厂的烟囱下，和管理员共分半瓶二锅头。</p><p>他们坐在腐朽的木板凳上。</p><p>喝到上头，对方开始用俄语背诵《荒原》，但是带有浓重的稷海本地口音。</p><p>“我坐在椅子上，像坐在抛光的宝座上，在大理石上发光，玻璃由缠绕着果实藤蔓的支架支撑……”</p><p>另一次，废品回收站上，他和老头一块听收音机，听交通广播电台的讲古节目。</p><p>老头说，这节目他听了30年，熬走了好几个主持人。</p><p>杨帝模仿胡彦卓跑酷。</p><p>「飞在空中，俯瞰风景，我会觉得自己是真正活着的……」</p><p>凌晨四点，地平线刚探出一丝晨曦，半座城市仍在睡梦中呓语，便开始在稷海市上空奔跑。</p><p>跑酷至黄昏，稷海市渐渐沉眠，它的夜晚带着霓虹灯的热风，混合了水泥的坚重。</p><p>杨帝真的在居民楼屋顶上，发现各式各样的小秘密和小玩意：小孩子的塑料陀螺，再也发不出声音的MP3，模仿梵高星空的涂鸦。</p><p>胡哥说的不错，城市画手的《星空》，确实比美术馆里的好看。</p><p>……</p><p>第六个月开始，他的脚步不再局限于稷海。</p><p>杨帝出了城，徒步到另一座城市。</p><p>用半年时间，足迹踏过二十座城市的街道，把本省逛了个遍，在无数个陌生人记忆里留下惊鸿一瞥的残影。</p><p>但无论走到哪里，他都能感觉到，自己被世界排斥着。</p><p>既然如此，他最终还是选择故乡作为心安之处。</p><p>他回到了稷海。</p><p>现代概念上的“城市”，并不单指一座城池。</p><p>是指以市区为核心、向外辐射一片广袤的区域，包括了大片城郊、乡镇甚至是荒地。</p><p>他沿着十八环辅路逆行跑步了三个钟头。</p><p>然后，杨帝看见了那栋楼。</p><p>这栋四层高的烂尾楼，突兀地矗立在稷海市开发区边缘。</p><p>它像被时光遗弃的化石，脚手架锈蚀成暗褐色血管，玻璃幕墙剥落处露出水泥骨骼。</p><p>杨帝能感受到，此楼与他有某种相似的气质，二者相互吸引彼此，或许这就是他来到此处的驱动力。</p><p>——这栋烂尾楼，被世界遗忘了。</p><p>它的“灵”，是残缺的。</p><p>杨帝拿出手机，搜索了一番这栋楼的信息。</p><p>网络上关于它的存在只有寥寥片语，绝大多数都是怪力乱神。</p><p>比如说是在开发该地段时，经常出现人员伤亡，又是请什么高僧施法，又是什么打生桩，也压不住这片地。</p><p>但开发商买下这块地，花了很多钱。</p><p>都是沉没成本，覆水难收，有诡也得咬着牙开发。</p><p>直到最后，开发商大老板走在平地上走路时扑街死，施工才被终止，告一段落。</p><p>后来，陆续有人在那儿跳楼，施工方只能锁死那边的大门。</p><p>有前因后果，有来龙去脉，看起来和那些添油加醋、道听途说的劣质都市传说一模一样。</p><p>但杨帝还是去碰运气了。</p><p>他拎一把螺纹钢锻制的撬棍，走向烂尾楼。</p><p>过去一年，除了锻炼力量，他也走遍了本省很多个都市传说发生地，拜访了许多玄学人士。</p><p>他们无一例外，不清楚“耶罗大仙”，也没听说过“卡耳叩山”。</p><p>图书馆中，大量民俗类资料他也已过了一遍眼睛。</p><p>同样找不到那尊明黄色的存在。</p><p>而稷海理工当地的原住村民，所剩的资料亦是少之又少。</p><p>杨帝想起——“希夷”就是为了探索旧校区艺术楼的都市传说，而被邪教徒抓住的。</p><p>这些传说怪谈，有99%为假。</p><p>但即使有1%为真的可能，他也必须碰运气。</p><p>而且这一次，他很确信自己来对地方了——如果是普通的自然造物，会有更完整的“灵”。</p><p>而不会像他一样，灵是残缺的。</p><p>杨帝拧了拧门把手。锁上了。</p><p>他后退一步，然后一脚将锁死的不锈钢防盗门踹飞二三十米。</p><p>“轰——隆——隆！！”</p>
