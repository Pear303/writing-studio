# 神光魔气纵横

<p>“凌云？哼！”一声冷哼如同九幽寒风刮过。</p><p>坐在班长斜后方的体育委员猛地站起来。</p><p>他本就高大壮硕的身躯此刻更显膨胀，肌肉虬结贲张，将校服撑得几乎要爆开。</p><p>一股浓烈到令人窒息的血腥气和战意轰然爆发，在他身后隐隐凝聚成一尊模糊却顶天立地的魔神虚影，三头六臂，仰天咆哮！</p><p>他双拳紧握，指关节发出爆豆般的炸响，皮肤下隐隐透出暗红色的魔纹。</p><p>“小小圣皇，也配在此聒噪？吾乃血手屠魔！当年一战，若非归墟大帝认为‘有伤和气’加以中断，我……”</p><p>“够了，老魔头！”一个清冷如冰泉的女声打断了他。</p><p>学习委员不知何时，已站在一张倾倒的课桌上。</p><p>周身寒气四溢，脚下迅速蔓延开一层晶莹剔透的冰霜。</p><p>她从大腿根处掏出一把西格绍尔P226，对准血手屠魔，眼中没有一丝温度，只有极致的冷静与掌控：“此界法则诡异，大道对，我等到来定有警觉，尔等是想提前引来大道斩杀吗？吾，玄冰尊者，尚需此身证道，休要胡来！要打架，就用本界的火铳激情一把。”</p><p>“哈哈哈！有趣！当真有趣！”</p><p>一阵张扬不羁的大笑响起。</p><p>角落里的“刺头”猛地一甩头，额前几缕碎发自旋起来。</p><p>他周身电光缭绕，细密的紫色电弧在皮肤上跳跃游走，发出滋滋的爆鸣。</p><p>指尖随意一弹，一道细小的电蛇窜出，将半空中飘落的一张试卷瞬间烧成飞灰。</p><p>“想不到这么多老熟人也一同飞升‘仙界’了！吾，雷罚天尊，也来凑个热闹！这劳什子高考，谁他妈爱考谁考去！”</p><p>仿佛点燃了引信的火药桶，整个教室瞬间炸开了锅！</p><p>“吾乃青木仙王！此地竟有我草木一族后裔气息？”</p><p>“本尊，万毒老祖！桀桀桀，这仙界考场……倒是炼蛊的好地方！”</p><p>“无量天尊！贫道……唉，贫道怎么成了历史课代表？”</p><p>“我佛慈悲……此身功课未竟，明日高考考卷尚需严肃对待……”</p><p>“……”</p><p>惊呼声、咆哮声、低语声、狂笑声混杂着各种或强或弱的奇异能量波动，在狭小的教室空间内疯狂激荡碰撞。</p><p>五彩斑斓的灵光、森然魔气、堂皇神辉、刺骨寒气、爆裂电光……</p><p>交织成一片混乱而瑰丽的末日绘图。</p><p>桌椅的残骸在能量乱流中如同玩具般被卷起抛飞和碾碎。</p><p>墙壁上布满蛛网般的裂痕，不断有碎石簌簌落下。</p><p>天花板那个巨大的破洞外，天空已被灰铁色的黑云覆盖，紫耀雷霆依旧在云层深处翻滚，将混乱的教室映照得忽明忽灭。</p><p>“疯了……都疯了……”教导主任老马瘫软在讲台角落，只能掏出讲台下各个行政班标配的SIG Sauer MPX冲锋枪，打开保险，试图瞄准在空中乱飞的神佛妖魔。</p><p>但他怎么扣得下班机！</p><p>这可都是他的学生啊！虽然他的学生已经明显都不是正常人了。</p><p>“杨哥！杨哥你醒醒！”</p><p>混乱中，一个焦急的声音格外突出。</p><p>是阿巴，她试图唤醒自己的死党。</p><p>她连滚带爬地冲到教室最后方，那个被能量风暴边缘波及、堆满碎裂桌椅和书本的角落。</p><p>杨帝，那个永远坐在最后一排靠窗、仿佛被世界遗忘的影子，此刻半个身子都被压在一张扭曲变形的课桌下，一动不动。</p><p>阿巴奋力掀开沉重的桌面，露出杨帝安详平静的脸。</p><p>此人虽有呼吸心跳，但浑身弥漫着一股淡淡的死感。</p><p>他紧闭着眼，长长的睫毛在脸上投下淡淡的阴影，嘴角似乎还残留着一丝若有若无，与周遭末日格格不入的慵懒睡意。</p><p>“杨帝！快醒醒啊！世界踏马的要完蛋了！班花变仙尊了！班长成圣皇了！连体育委员那傻大个都成筋肉魔鬼了！”</p><p>用力摇晃着杨帝的肩膀，“他们都疯了！在抢准考证！要打起来了！”</p><p>仿佛是为了印证阿巴的话，教室中央爆发了新一轮、更激烈的冲突。</p><p>“滚开！此座蕴含一丝地脉龙气，当属本帝所有！”凌云圣皇周身金光暴涨，一只由纯粹神能凝聚的巨大金色手掌凭空出现。</p><p>带着排山倒海的威压，狠狠拍向正试图抢占一个相对完好座位区域的血手屠魔。</p><p>那座位下，一张被踩烂的准考证上，依稀可见杨帝的名字和照片。</p><p>“放屁！蛐蛐龙气残渣，也配入本尊法眼？本尊看中的是此桌杀气！”</p><p>血手屠魔狂吼一声，身后那模糊的金身法相瞬间凝实了几分。</p><p>六只手臂同时挥舞，滔天的暗红色魔气如同实质的血浪，轰然迎上那只金色巨掌！</p><p>“轰隆——！！！”</p><p>金红两股恐怖的能量在半空狠狠对撞！</p><p>刺眼的光芒瞬间吞噬了一切，狂暴的冲击波如同无形的重锤横扫四方！</p><p>阿巴：……</p><p>这几位大能，争夺的正是教室后排靠窗的座位，也就是杨帝的座位。</p><p>靠近战圈的几张课桌，如同纸糊般被撕成碎片，几个躲避不及、刚刚显露出微弱前世气息的学生惨叫着被掀飞出去，撞在布满裂痕的墙壁上，口喷鲜血，瞬间萎靡下去。</p><p>空气中弥漫着能量湮灭后的焦糊味，和淡淡的血腥气。</p><p>“够了！”</p><p>瑶光仙尊柳眉倒竖，七彩霞光骤然扩散，形成一道柔韧的屏障，艰难地阻挡着逸散的能量风暴，护住了她附近一小片区域的学生。</p><p>她声音冰冷：“尔等欲毁此身道基不成？！”</p><p>“哼，仙尊倒是心善。”玄冰尊者冷哼一声，身周寒气更盛，脚下冰霜蔓延，冻结了向她飞溅而来的碎石和杂物。</p><p>但玄冰尊者随即眼神一凛，勉强扭脖子躲过了一颗由瑶光仙尊发射而来的9mm子弹。</p><p>每个学生，都配有一把手枪。</p><p>子弹在她精致无暇的面庞上，划出一道血痕。</p><p>“……来到此仙界，这方天地灵气浓郁至极，对我境界压制如此恐怖，竟然只能发挥出炼气期实力！”</p><p>“不过，考场座次，关乎明日汲取此界‘文道气运’之效率。对于本尊从零开始修炼成仙大有裨益，确实需争上一争！”</p><p>她指尖微动，几道无声无息的冰锥悄然凝聚，锁定了另一个方向正试图挪动桌椅的“万毒老祖”。</p><p>雷罚天尊则狂笑着，指尖跳跃的电弧化作数条狰狞的紫色电蟒，在混乱的人群头顶肆意游走鞭挞。</p><p>所过之处，焦烟四起，引来一片怒骂。</p><p>“打！打得好！都别藏着掖着！让本天尊看看，这万古岁月，把你们这些老家伙磨成了什么怂样！”</p><p>整个高三零班，彻底沦为仙魔战场。</p><p>昔日的同窗，此刻为了一个座位、一张准考证，显露出狰狞的前世面目，大打出手。</p><p>神光魔气纵横交错，冰霜雷霆肆虐咆哮。</p><p>教导主任晕了过去。</p><p>他天生低血糖。这届计划是他退休前带的最后一届，没想到碰上这档子事……</p><p>其他未曾觉醒或觉醒微弱的学生，要么瑟瑟发抖地蜷缩在能量风暴的缝隙里，要么被余波扫中，生死不知。</p><p>“杨帝！速醒！”阿巴徒劳地拍打、殴打、扇打杨帝的脸颊，试图唤醒最后的依靠。</p><p>终于，那只苍白的手动了。</p>
