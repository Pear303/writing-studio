# 无穷进化

<p>杨帝的目光，缓缓降落到脚边沾满泥水的红米手机上。</p><p>属于“达文西”的记忆碎片——关于密码、关于解锁、关于这卑微电子造物的一切——如同本能般浮现在他新生的意识中。</p><p>6544。</p><p>他俯身，僵硬的手指准确地戳在沾着泥点的屏幕上。</p><p>屏幕亮起，微弱白光刺破了荒野昏暗。</p><p>右上角的电池图标，显示仅剩孤零零的五格电。信号栏，却倔强地显示着满格。</p><p>荒山野岭，满格信号。</p><p>杨帝扯动嘴角，还是熟悉的基建水平啊。</p><p>他点开地图应用。</p><p>目光扫过，市区的位置，以及记忆中“达文西”那个充斥着泡面味的出租屋坐标，迅速记在脑海。</p><p>大致就是那个方向。</p><p>他迈开脚步。初生的肌肉与神经仍在笨拙地协调，步伐有些踉跄，踩在湿润的草叶和泥土上，发出轻微嘎吱声。</p><p>“啪叽。”杨帝脸朝地摔了。</p><p>适应这具身体，需要时间。</p><p>适应这个每粒尘埃都携带无穷灵能的世界，也需要时间。</p><p>有一种方法可以加速他对肉身的掌控力提升。</p><p>杨帝目光扫过地面，一块边缘带着锐利断口的黑色燧石映入眼帘。</p><p>弯腰拾起，石头冰冷，举起燧石，将那锋利的边缘压在自己裸露的左小臂上猛地一划，黑刀子进黑刀子出！</p><p>嗤——</p><p>皮肉被割开，狭长而鲜红的血痕出现在苍白的皮肤上，刺痛感沿着神经传递上来。</p><p>痛感只持续了不到一次心跳的时间。</p><p>就在杨帝低头注视的瞬间，那翻开的皮肉边缘，仿佛被精准到纳米的隐形“针线”飞速缝合。</p><p>鲜红的血液甚至来不及大量涌出，伤口就以肉眼可见的速度弥合收口，最后消弭！</p><p>手臂上，只留下了一道粉红色的浅浅痕迹，如同被晒伤后即将脱落的旧皮。</p><p>杨帝的眼神没有丝毫波动，只有冰冷的计算。</p><p>“这不是致死级伤害，而且是世界之内的伤害，一次伤害。线性递增？不……”</p><p>他感受着肉身的变化。</p><p>再次举起燧石，用尽全力，朝着手臂上那道浅浅的粉红痕迹砸去！</p><p>往自己刚刚愈合的旧伤上又开一道口子，不是一般狠人能做出来的。</p><p>嘭！燧石砸在皮肤上，预想中的皮开肉绽并未出现。</p><p>看似脆弱的皮肤坚韧得如同中子星，锋利的燧石，甚至没能给皮肤留下一丝白印。</p><p>“阿列夫零。”</p><p>杨帝低声吐出这个代表最小无穷大的数学名词。</p><p>随着这个词的出口，他清晰地“感知”到，自己那源自“数值怪”设定、以高德纳箭头为路径的进化核心——那个抽象的“点数”——并非如过往设定般需要“锻炼”或“击杀”来累加。</p><p>在这个无限灵能的世界……</p><p>规则也发生了质的变化。</p><p>每次真实的伤害，每次对自身存在完整性的破坏，无论多么微小，都如同向无垠大海投入一颗石子。</p><p>石子本身微不足道，但它激起的“涟漪”所覆盖的水面面积……是无穷大！</p><p>每一次受伤，他的“点数”增加量，都直接跨越了线性、指数、幂塔……这些有穷尽，慢吞吞的增长模式。</p><p>而是一步到位，跃迁至阿列夫零！</p><p>一次伤害，就是一次直步无穷的跃迁！</p><p>因为一次伤害所蕴含的“灵能”，就是阿列夫零。</p><p>正如同删去自然数中的所有偶数，剩下的奇自然数也仍然是阿列夫零的势。</p><p>此刻的杨帝，已不再是那个能被凡俗燧石破防的碳基生物。</p><p>他的基础防御，在第一次自伤完成、获得阿列夫零级强化的瞬间，就已经被拔升到了一个凡俗物质难以企及的高度。</p><p>荒野的风吹拂着他新生的黑发。</p><p>他抬起头，望向城市的方向，那万家灯火在遥远的地平线勾勒出模糊的光晕。</p><p>力量，以最直接、最残酷、也最符合“数值”本质的方式，回来了。</p><p>他不再需要锻炼。</p><p>他只需要……一次轻微的受伤。</p><p>每一次受伤，都是向无穷尽的力量深渊，跃进一个阿列夫零的层级！</p><p>“我是用锋利的锐器划伤皮肤，所以现在的我，似乎彻底免疫了‘锐器’的伤害。</p><p>“但是对精神攻击、生化毒性等其他类型的杀伤，并没有做到彻底的免疫。</p><p>“深度已经足够，我需要补齐的是广度。”</p><p>荒野尽头，已经隐约显露出城市轮廓。</p><p>而在市区与郊区农村之间的分野，路边有一座孤零零的建筑。</p><p>锈迹斑斑的铁皮围栏，烟囱高耸，在灰蒙蒙的天空下吐着带着薄薄白烟。</p><p>垃圾焚烧厂。</p><p>夜幕是最好的掩护。杨帝绕开正门，像一道融入阴影的幽灵，轻易翻过低矮的铁丝网。</p><p>厂区内弥漫着令人作呕的混合气味：腐烂有机物的酸臭、塑料焚烧的刺鼻、以及灰尘与灰烬的干燥呛人。巨大的焚化炉如同钢铁巨兽，蛰伏于厂内，炉口散发着令人心悸的余温。</p><p>已经是深夜，巡查力度不大。</p><p>绕开所有在黑夜中微微反光的监控摄像头。</p><p>他来的一个装废弃纺织品的集装箱前，集装箱敞开着口，里面是肮脏破败的布料碎屑、留着污水的塑料部件。</p><p>杨帝将自己整个埋了进去。</p><p>不知过了多久，金属摩擦声骤然响起，集装箱的门被猛地合上，“哐当”一声，最后一点光亮被彻底掐灭。</p><p>引擎的轰鸣由远及近，铁链绷紧的“咯吱”声钻入耳孔。集装箱猛地一沉，随即是剧烈晃动——它被吊起来了。</p><p>固定锁扣“咔嗒”咬合的脆响后，引擎声再次轰鸣，这次是持续而稳定的震动——卡车开动。</p><p>卡车最终停在一个地方，集装箱被倾倒。杨帝连带着箱子的内容物一同泄出。</p><p>紧接着，炉膛内温度开始急剧攀升！</p><p>初始的温热迅速转化为灼人的滚烫。</p><p>空气变得稀薄滚烫，呼吸都像吸入烧红的铁砂。劣质化纤在高温下熔融燃烧，释放出剧毒的浓烟和燃烧的黏稠液滴，噼啪作响地滴落在他身上。</p><p>杨帝的身体，成了这炼狱的中心。</p><p>他暴露在外的皮肤承受着最直接的炙烤。</p><p>足以瞬间将普通人化为气体、只留下骨灰的高温，刺激着他每一个细胞。</p><p>杨帝的眼睛并未合上。</p><p>他看到火焰的狂暴舞蹈——燃烧的化学键断裂与重组释放的能量，热力学定律下分子的疯狂运动，物质向能量转化的熵增过程……</p><p>一切都被他解析，被他的身体本能地适应、抵抗、进而……超越，抵达绝对之无穷。</p><p>炉膛内的火焰逐渐减弱，温度开始下降，最终归于沉寂时，焚烧程序结束了。</p><p>晨光透过炉门的缝隙渗入。炉内一片狼藉，只有厚厚的、松软的灰烬。</p><p>一只覆盖着薄薄灰烬的手，猛地从灰堆中伸出。</p><p>杨帝整个身体坐了起来。他毫发无伤。皮肤光滑依旧，连一根毛发都未曾卷曲焦黄。只有身上覆盖的厚厚灰烬，证明他曾置身于那恐怖的熔炉。</p><p>他悄无声息地离开冷却中的焚化炉，找到提前藏在厂区角落灌木丛中的衣物，穿上，以免被路人认为是痴汉。</p><p>继续向市区走去。</p>
