# 第二阶段，虫影迷踪（4200字）

<p>那是一个散发着绝对冷冽，散发纯白光芒的巨大光球，它悬浮在无法用三维坐标定义的维度间隙中。</p><p>它是一个复杂到极致的数学奇点，一个规则的聚合体，一个用物理规律和玲珑法则杂糅的点，一个……“管理员”终端。</p><p>就在杨帝的神念触及这光球的刹那，远超之前亿万倍的信息洪流如同宇宙风暴般冲击而来。</p><p>这似乎仅仅是这个“主神”系统存在着，就自然散发出关于其运作背景的庞杂信息流。</p><p>杨帝的神识以前所未有的速度解析着这股信息流，一个宏大、冰冷、令人战栗的宇宙图景在他“眼前”展开：</p><p>这个宇宙，并非源自单一的原初奇点。</p><p>它更像是一片无限广阔，沸腾不息的“时空泡沫海”。</p><p>在难以想象的漫长岁月，和难以度量的广阔空间广度中，“宇宙大爆炸”并非只发生了一次。</p><p>它们如同泡沫般不断从更深层的量子真空中随机涌现，此起彼伏。</p><p>每一次“爆沸”都创造一个独立的时空泡，一个“宇宙空腔”。</p><p>这些空腔在“诞生”时间上极端不均匀：有些是以地球时间为粗糙参考137亿年前与某个著名奇点同时诞生，有些则在1万亿年前、甚至1秒钟前刚刚炸开一个崭新的时空。</p><p>而在空间上，它们更是分布得毫无规律，如同巨釜中翻滚升腾的气泡，彼此可能毗邻，可能相隔亿万光年计的原始虚无，甚至可能因维度折叠而相互重叠却不直接互通。</p><p>每一个宇宙空腔，都拥有自身独立的世界线和发展逻辑，时间轴速率、甚至流向都可能迥异。</p><p>它们就是主神空间称之为“副本世界”的根源。</p><p>其数量之多，并非亿万可以形容。</p><p>即使是天竺老哥辩经时创造出的恒河沙数、无量大数，也无法描述这片沙盘上最微不足道的一个触角。</p><p>这个宇宙/世界/沙盘大得难以想象，是个纯粹的数值怪。</p><p>而在许多宇宙空腔之中，坐落着数量规模虽然暴跌了很多，但同样是天文数字的大尺度丝状结构、超星系团、漫天星河。</p><p>大部分这些宇宙空腔，总会存在一个本超星系团，其中一般都会有一个银河系，而在位于银河系猎户座悬臂内侧边缘附近，距离银河系中心约2.6万光年之处，往往都会蹦出一个蔚蓝色的岩石行星，地球。</p><p>杨帝神识扫过去。</p><p>绝大部分宇宙空腔中，银河系以外的广袤时空，是近乎永恒的、令人窒息的混沌与虚无。</p><p>那里是物理规律的蛮荒之地，是几乎没有多少值得书写在卷章上的故事。</p><p>无数星系在难以计数的岁月中徒劳地燃烧，徒劳地膨胀，相互吞噬，最终归于沉寂。</p><p>只留下弥漫的暗物质和缓慢蒸发的黑洞，似巨兽散佚的骸骨，述说着毫无意义的熵增史诗。</p><p>而在宇宙空腔之间，这些区域的时间轴要么近乎停滞，要么在疯狂的相对论效应下扭曲断裂，空间结构本身也可能布满微观尺度的裂缝和畸变。</p><p>对于绝大多数文明而言，这片深渊是无法穿越，无法理解，甚至无法有效观测的“噪音”，是物理法则书写完毕后留下的无限重复且空洞的余白。</p><p>然而，近乎奇迹般地，在无数宇宙空腔中，那颗位于银河系边缘的蔚蓝色岩石行星——地球。</p><p>她被镶嵌在这片大部分区域都单调乏味的混沌绒布上。</p><p>并非所有地球都孕育出生命，也并非所有生命都能演化为文明。</p><p>但总有一定比例的地球，其上演的“故事”却呈现出一种违反概率、惊人的“灵能富集”状态。</p><p>杨帝的神识如同超维扫描仪，掠过无数世界线。</p><p>他看到一个地球，恐龙的王朝并未终结，哺乳动物在巨影下艰难求存，最终演化出拥有初级智慧的爬行类文明，正在它们的钢铁丛林中祭祀着古老的星空图腾。</p><p>他看到另一个地球，罗马/大明万世永存，军团战舰装备着蒸汽动力和差分机，正试图跨越英吉利海峡/日本海，征服最后的反抗势力。</p><p>他又看到一个地球，灵气在二十世纪末骤然复苏，都市白领们在996之余开始偷偷修炼金丹大道，国际局势因修仙者联盟的出现而变得微妙异常。</p><p>还有核战后的废土、被深海巨怪统治的星球、人工智能觉醒后与人类达成的脆弱平衡、发现古代修真者遗迹而科技树点歪的星际时代……</p><p>每一个存在文明或重大变故的地球，都像一个异常活跃的奇点，不断喷涌出极其复杂且高位的“灵能”。</p><p>爱恨情仇、战争和平、科技突破、个体觉醒、文明兴衰……</p><p>这些事件所蕴含的现实复杂度，因果纠缠的强度，远远超过了银河系乃至本超星系团其他区域那缓慢而物理的演化过程。</p><p>杨帝意志回归。</p><p>眼前还是那颗冰冷的白色光球。</p><p>主神。</p><p>他明白了，这一个个宇宙空腔，其实只是主神的一场场梦境。</p><p>他们之间，正在展开一场别开生面的精神交流，而神交总是双向的。</p><p>杨帝隐隐约约听见这个大光球，呢喃出些许奇怪的句子，破碎的语词：</p><p>【用这句话作为卷结尾，实在是艺术、太艺术了吔！！】</p><p>【这才是深度！人性的光辉在绝境中的挣扎！】</p><p>【主角！就叫……白杨大帝！满级、人类！开局是满级大佬！什么主神空间，在他眼里就是个新手村！秒天秒地秒空气！装逼打脸扮猪吃虎！龙王归来都市战神！】</p><p>【……】</p><p>“呃啊——！！！”</p><p>杨帝新生的凡人级别神魂，被主神的言语，也给硬生生打成“化神”境界！</p><p>挨打就能变强，挨致命的打击便能蹭蹭蹭的飞快变强。</p><p>轮回小队五人惊恐地看着杨帝，只见他七窍瞬间迸射出刺目的金光——那是神魂能量逸散的具象。</p><p>同时，整个人的气息如同断崖般暴跌……然后重新坐火箭似的暴涨回去，比原来更猛更劲霸！</p><p>破碎的神魂在毁灭性的压力下，完成了最终的涅槃。</p><p>它变得更加凝实、更加璀璨、结构更加复杂玄奥。</p><p>杨帝猛地睁开双眼！瞳孔深处不再是星云旋生旋灭，而是两轮金色烈阳在缓缓转动。</p><p>“噗，噗，噗……”</p><p>他一升一升地吐血，眼神却亮得吓人，充满了亢奋与贪婪：“好一个主神！好大的‘食堂’！这开胃菜够劲，可惜为什么不多看我几眼呢？”</p><p>轮回小队五人已经完全懵了。</p><p>他们只看到杨帝闭眼，然后七窍喷金光，气息暴跌又暴涨，最后吐血但眼神狂热……</p><p>这短短几秒发生了什么？！</p><p>没等他们发问，主神那冰冷的提示音再次响起：</p><p>【传送准备完成。传送目标：第二阶段任务起始点。】</p><p>【传送倒计时：3……2……1……】</p><p>刺目的白光瞬间吞噬了六人。</p><p>眩晕感袭来，空间扭曲。</p><p>……</p><p>视野再次清晰时，他们仍在毛发球中，包括杨帝——他也安静盘坐在角落。</p><p>球体内部空间不算宽敞，五个人挤在一起，几乎能感受到彼此的呼吸和心跳。</p><p>除了处于虚化状态的影子。</p><p>四周是厚实、坚韧、微微散发着体温和奇异能量波动的毛发壁垒，隔绝了外界的一切光线和声音。</p><p>只有毛球内部结构脉动时发出的低沉嗡鸣，以及众人自己粗重的喘息声，在这片绝对黑暗、相对安全的“茧房”内回荡。</p><p>在这层由杨帝化神期力量构筑的壁垒内，诡异地弥漫着一种令人安心的的安全感。</p><p>仿佛暴风雨夜躲在门窗紧闭的狭窄小房间，虽然压抑，却暂时隔绝了外界的狂风暴雨。</p><p>脑海中，主神的声音姗姗来迟。</p><p>【第二阶段任务：虫影迷踪，开始。】</p><p>【目标：探明虫族的动向，阻止幕后之手发动大屠杀。】</p><p>【当前地点：自由众星同盟工程勘探船‘开拓者-3号’格纳库。】</p><p>“开拓者-3号？自由众星同盟？这不就是刚才那艘科研船的隶属政体嘛！他们是来搜救的？可真够及时呢。”</p><p>“不，直觉告诉我，不像是来搜救。”</p><p>“看看主神给的任务：‘探明虫族动向，阻止幕后之手发动大屠杀’……我不觉得我们被传送到了一个安全友好的地方。而且，开拓者-3号出现在这里，时机太‘巧’了。”</p><p>一直盘坐在角落，气息如同深渊般不可测的杨帝，又吐了几十升血后，缓缓睁开了眼睛。</p><p>他的瞳孔深处，那两轮金色烈阳的光芒收敛了一些，但威严更盛。</p><p>“想要不被外边的人发现，就安静啦各位。”</p><p>众人立刻噤声。</p><p>只见杨帝伸出右手食指，指尖萦绕着一缕极其细微、却蕴含着恐怖力量的银色电流——那是高度凝练的磁场力量。</p><p>他没有多余的动作，只是将指尖轻轻点向身前厚厚的毛发壁垒。</p><p>嗡……</p><p>一股无形的磁场扩散开来。</p><p>被杨帝指尖点中的那一小块区域的毛发，内部结构瞬间发生了微妙的变化。</p><p>原本紧密纠缠、不透光线的毛发纤维，在精妙绝伦的磁场操控下，被强制性地调整了分子排列和光学折射率。</p><p>几秒钟后，奇迹发生了。</p><p>那一片约莫脸盆大小的毛发区域，颜色迅速褪去深黑，变得如同最纯净的水晶般透明！</p><p>光线从外面透了进来，形成了一扇清晰的观察窗。</p><p>从毛发球内部，轮回小队可以清晰地看到外面的景象：</p><p>惨白色的高功率灯光，打磨得锃亮反光的金属地板，高耸的、布满粗大管线和机械臂的金属墙壁，空气中似乎还漂浮着细微的尘埃。</p><p>整个空间巨大，空旷，充满工业感和肃杀。</p><p>“不用担心，这是单向透光的‘窗’，类似酒店玻璃。”</p><p>“嘶……”眼镜倒吸一口凉气，战术目镜疯狂扫描着那扇“单向窗”的结构，试图解析原理，结果全是乱码和问号。</p><p>“磁场操控物质微观结构……改变光学性质……这……这简直是……”</p><p>“化神期的便利罢了。”</p><p>杨帝摆摆手，仿佛只是做了一件微不足道的小事，“看气密大门那边。”</p><p>队长、火鸦、铁砣和刚刚从虚化中稍微探出头的影子，立刻凑到那几扇单向窗前，小心翼翼地向外窥探。</p><p>他们所在的毛发球，正静静地躺在格纳库中央一个巨大的维修平台上。</p><p>平台周围空无一人，但远处，靠近格纳库气密大门的方向，却能看到一队队穿着统一制式、带有“自由众星同盟”徽记动力装甲的士兵正在巡逻。</p><p>士兵的武器处于待命状态，装甲面罩下的扫描仪不时扫过空旷的格纳库，重点似乎就在他们这个巨大的“陨石”上。</p><p>“看他们的阵型，是标准的外星异常物品收容警戒队形。”</p><p>“他们以为我们是颗陨石。”</p><p>“可能会把虫族带出来的陨石。”</p><p>“按常理来说，虫族应该在那场大爆炸中死绝了，而主神给我们的任务，是继续追查虫族的踪迹？”</p><p>“你忘记了吗？科研船上的虫族，是通过伪装成陨石入侵的。”</p><p>“那么警惕倒也无可厚非。”</p><p>远处巡逻的一支小队似乎接到了什么指令，停了下来。</p><p>其中一名像是队长的人，面罩转向他们所在的维修平台，似乎在仔细打量着这个巨大的黑色陨石。</p><p>他抬起手臂，在通讯频道里说着什么。</p><p>几秒钟后，他手臂上的扬声器响起，声音经过扩音后冰冷而清晰：</p><p>“那边的不明人员！这里是自由众星同盟工程勘探船‘开拓者-3号’安保部队！我们已确认你的存在！解除伪装，立刻现身！重复，解除伪装，立刻现身！否则我们将采取强制措施！”</p><p>话音落下的瞬间，那支巡逻队的所有士兵动作整齐划一，动力装甲发出铿锵的机械声，手中的脉冲步枪瞬间抬起，黑洞洞的枪口齐刷刷地对准了维修平台。</p><p>——更准确地说，是对准了毛发球所在的区域！</p><p>“糟了！被发现了！”火鸦低呼一声，异能瞬间在掌心凝聚，凝聚出一颗足以同时点两根烟的火球。</p><p>队长的心沉到谷底，念动力场无声地张开，护住众人最前方。</p><p>影子更是吓得晕过去，在梦中与看不见的敌人进行激烈对抗。</p><p>就在这剑拔弩张、千钧一发之际！</p><p>毛发球后方阴影处，空气突然如同水波般剧烈扭曲。</p><p>唰！唰！唰！</p><p>三道身影毫无征兆地解除了某种高级的光学迷彩或相位伪装，如同鬼魅般从虚空中跃出！</p><p>他们穿着紧身的黑色作战服，装备精良，动作迅捷如猎豹。</p><p>“是英仙帝国的走狗！”</p><p>巡逻队大叫，纷纷扣下扳机开火。</p><p>火鸦收起她小得可怜的火球，队长安心坐下来，影子也缓缓睡醒，在杨帝的毛线球内安全看戏。</p>
