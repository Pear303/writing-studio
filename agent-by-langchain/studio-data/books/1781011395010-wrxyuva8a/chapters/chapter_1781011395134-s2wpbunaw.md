# ZZ是ZZ的延续

<p>杨帝负手立于星海之间，连鬓角发丝都未沾染半分星尘。</p><p>鱼尊阿巴的大荒囚天鳍第九式·万蝠朝宗已然临身，万千能量黑蝠张牙舞爪，所过之处空间如万古琉璃寸寸崩裂，那碎裂声直欲将亘古岁月都震得簌簌落尘！</p><p>“轰隆——轰隆——”</p><p>星海咆哮，时空哀鸣。</p><p>杨帝甚至未曾抬眼，只是左臂随意一振。</p><p>拳风未至，气浪已先行撕裂虚空——</p><p>怪哉！那气浪竟源自守望者文明某支舰队战巡舰泄露的冷却液！</p><p>堂堂宇宙巅顶的超级文明，竟仍需凡俗之物散热，当真是滑天下之大稽。</p><p>凝聚大道法则的囚天鳍撞在杨帝身上，他连腿毛都不屑于一动。</p><p>鱼尊的大荒囚天鳍第九式万蝠朝宗，恰似残雪落于骄阳，瞬间扭曲成紊乱的能量流，触及他皮肤的刹那，便轰然炸散。</p><p>阿巴只觉鳍尖一麻，仿佛以全身最柔嫩肥美的鱼腹撞上了黑洞的事件视界，整个鱼躯如断弦之箭横飞出去。</p><p>周身坚硬如中子星的鳞片，竟摇摇欲坠，簌簌坠落，每一片都刻满了法则崩解的道纹。</p><p>“就这？”杨帝的声音穿透万千星云，平淡得如同在说今日天气正好，去烧腊馆吃排骨饭。</p><p>他一步踏出，时空竟在足下凝成玄奥阶梯。</p><p>大手卷如虬龙古枝，径直向鱼尊探去。</p><p>阿巴眼中血丝狂涌，鱼鳍猛地绽放万千符文，如诸天星辰倒悬：“太乙仙术·曦琥𪓡煜决！”</p><p>（xī hú cù yú）</p><p>身后星辰虚影疯狂旋转，化作一道贯穿星域的煌煌洪流，那能量之恐怖，足以顷刻间将整片星河碾作齑粉！</p><p>就连刚才对付守望者舰队，都没如此透支、超频、压榨极限！</p><p>与她的终极一击相比，纵然是极超新星爆发过程中炸响的伽马射线暴，都黯淡如萤火，在这灭世威能前瑟瑟发抖。</p><p>这股能量若是具象化，其瞬间释放的能量总量，相当于可观测宇宙中一万亿次超新星爆发的能量总和——须知一次超新星爆发的能量便能在瞬间照亮整个星系团，而此刻阿巴汇聚的能量洪流，正以将一万亿颗恒星压缩至极限后引爆的恐怖规模。</p><p>那些在星云中炸响的伽马射线暴，此刻在能量洪流面前不过像萤火虫撞向蓝巨星！</p><p>天地失色，万道哀鸣。</p><p>唯有无上强者屹立于风暴中心，以肉身抗万法，于无声处听惊雷。</p><p>杨帝终于抬了抬眼皮，右拳紧握。</p><p>没有惊天动地的巨响，只有一声微不可闻的“噗”。</p><p>也没有惊天动地的灵能流转，仅有让鱼尊无声嘶吼的疯狂——</p><p>那个人，他还是没有没有动用任何灵能法术！！</p><p>仅仅是用肉身，用最纯粹的物理方式抵挡！</p><p>不……甚至不算“抵挡”，而是主动进攻。</p><p>他的拳头如同贯穿豆腐，径直插入能量洪流核心。</p><p>拳势过处，星河虚影寸寸湮灭成齑粉，法则符文如琉璃盏坠地般纷纷碎裂，迸溅出细碎的光雨。</p><p>杨帝手腕猛地翻转，竟以血肉之躯、以纯粹物理力量，将足以荡平星系的恐怖能量生生揉捻成球！</p><p>那能量球致密到极致，质能密度远超宇宙中任何万古长存的黑洞，连时间流速在其表面都扭曲成螺旋状的光带。</p><p>掌心的能量球仍在疯狂坍缩，时空曲率被压榨到极限，连光线都被强行拽入球体表面，形成一道漆黑的吸积环。</p><p>理论中，黑洞奇点撕裂时空的场景在此刻化为现实：能量球边缘的时空，犹如被烈火吞噬的破旧古卷般寸寸崩裂，露出其后翻涌着混沌光带的时空裂隙。</p><p>隐约可见，裂隙另一端流淌着非物质非能量的诡异存在。</p><p>名为「杨帝」的存在，用最纯粹的肉身，一巴掌捏爆时空和维度的壁垒，一巴掌打穿了物质界和“虚境”的隔阂。</p><p>“这……这究竟如何能够！！”</p><p>阿巴的神魂在疯狂嘶吼，鲈鱼躯壳因极致的恐惧而剧烈震颤，鱼鳞都在时空扭曲的压力下发出不堪重负的呻吟。</p><p>远处本作壁上观、愉快吃瓜围观的守望者舰队，此刻竟集体向后急退三百万千米。</p><p>舰体表面比中子星还要硬数百倍的“色核力装甲”，在那恐怖的时空涟漪下，泛起细密如蛛网的裂纹。</p><p>杨帝轻哂。</p><p>能量球在他掌心滴溜溜旋转，泛着足以让星河失色的幽光。</p><p>随手一抛，那团凝聚着一万亿次超新星爆发威能的能量，便径直飞入他口中。</p><p>喀嚓，吧唧，生而啖之。</p><p>鱼尊内心最深处的恐惧终于重占上风。</p><p>还好，万幸，杨帝一次性生吞相当于一万亿次超新星爆发的能量，并非没有代价，也不可能没有受伤。</p><p>他皮肤骤然裂开蛛网般的缝隙。</p><p>裂纹呈螺旋状爬满全身，像是半凝固的熔岩地壳被强行撑开，露出内部翻涌的炽烈红光。</p><p>每一道裂纹都在吞吐着某种最本质纯粹的能量，耀白色的炽芒刚刚泄出冰冷深空，</p><p>血肉深处爆发出的光芒，比超新星更盛，比奇点更炽，连时空的褶皱都在这光芒中扭曲成燃烧的绸缎，被这股能量映照成流动的橘红色。</p><p>一万亿烈阳，一万亿恒星爆炸完全释放其能量……</p><p>其实单从“量”上看，这股能量并不庞大，仅仅是5个银河系的恒星总数而已。</p><p>最重要的是，杨帝将其搓成苹果大小，才一口吞下……将5个银河压缩成苹果大小！</p><p>就算是宇宙本源意志、天道的私生子在此，怕也得被轰成泡沫！</p><p>杨帝的肌肉纤维在肉眼可见地蠕动重组，皮肤下隐隐浮现出血管、神经重组的纹路。</p><p>他体表那些看起来即将崩裂的裂隙，竟被自己的血肉强行抚平、愈合、完好如初！！</p><p>“咔嚓——”一声脆响，最后一道裂纹在胸口处闭合，渗出的红光凝聚成一枚微缩恒星，缓缓沉入心脏位置。</p><p>“嗝——”那个人形生物试图长出一气，但气管貌似被卡住。</p><p>直到杨帝重重吐了10升血，面色才恢复红润，呼吸顺畅，舒筋活络。</p><p>现场陷入诡异的沉默。</p><p>其实沉默是很正常的，因为真空不能传声。</p><p>虽说真空不能传声，但在此地的战场上，物理规律似乎并不那么稳固。</p><p>杨帝活动了下脖颈，骨骼发出银河旋转般的嗡鸣，骨骼爆响就连鱼尊也听得一清二楚。</p><p>他微笑着，直勾勾盯紧鱼尊。</p><p>“这鳍……还是太软，剔牙都不够看。”</p><p>“你可以侮辱我的人格，但不能侮辱我的鱼鳍，因为我是鲈鱼而不是人！”鱼尊怒喝。</p><p>她转头盯向守望着文明舰队中，一支不太显眼、看起来普普通通的战舰：“铁罐头，别再藏拙了！我知道你从一开始就在偷偷摸摸干些不干净的手脚！你有什么绝招都端上来吧！！”</p><p>言罢，鱼尊暴退数十亿公里！</p><p>“哦？还有高手！你们刚才打得这么欢，现在居然联合在一起对付我。”</p><p>「战争只是政治的延续。」守望者文明发出一道通讯波，如此说道。</p><p>言外之意：我就捏着鼻子，和你鱼尊暂时合作先，将眼前这个“怪物”给制服了，再慢慢谈事情。</p>
