# 知识的殿堂级饭店

<p>阿巴挤眉弄眼，用眼神交流：“我在找我同伴……你们知道白杨大帝、青丘白璃，还有那台贼头贼脑、没多少修为的机器人在哪？他们理应和我们一同到达了仙界……”</p><p>血手屠魔的眼神如同咆哮猛虎，第一个撞进众人识海，也撞向阿巴：“淦！刚才那书架是你丫碰的？”</p><p>书架倒下，他闻到淡淡的鱼腥味，还以为是自己错觉。</p><p>“呃，路过，手滑。看你们鬼鬼祟祟，本想打个招呼，没想到你们这么……‘灵敏’。”</p><p>阿巴本想用“泥鳅”做形容，但考虑到和鱼腥味有关的东西，很可能会再度把血手屠魔惹怒，便作罢。</p><p>凌云圣皇打断扯皮的二人：“钥匙。图书馆通往体育馆的备用钥匙，鱼尊你有没有？”</p><p>阿巴摊了摊手，动作幅度极小。</p><p>“没有。我对开锁没兴趣。我……我帮你们找找吧。”</p><p>……</p><p>十分钟前。</p><p>图书馆内部异常安静，静得能听见自己血液流淌的声音。</p><p>惨白的应急灯光勉强照亮一排排高耸至天花板的书架，投下浓重、扭曲的阴影。</p><p>杨帝的身影如同融入阴影的流水，悄无声息地滑入图书馆大门。</p><p>空气中弥漫着旧书混合尘埃与的微涩气味，以及一丝若有若无，冰冷的窥视感。</p><p>“知识的殿堂？”</p><p>杨帝想到一个诡谲的问题——为什么都说知识的殿堂，绝不说知识的饭店？</p><p>这是否有些太过注重于抽象的符号意义，而忽略了物质本身的力量，尤其是忽略了物质本身的营养价值。</p><p>书本，主要成分植物纤维，本身算是一种“多糖”，算是糖类。</p><p>虽然人类的肠胃无法消化纤维质，但世上无难事，只怕有心肠。</p><p>杨帝定向进化了自己的肠胃，吃过几本精神食粮，味道醇厚，书内还有蠹虫加餐，既有糖类又有优质蛋白质。</p><p>杨帝站在图书馆中央，双手插口袋。</p><p>空气中，弥漫纸张腐朽和陈年灰尘的味道，但更深层的是某种冰冷的恶意，如同蛰伏在书架阴影中的毒蛇。</p><p>“鬼鬼祟祟，滚出来！”</p><p>声音不大，也就180分贝左右，以杨帝为中心，带着沛然莫御的意志悍然爆发。</p><p>图书馆的规则——寂静——被这声宣告蛮横地撕裂，践踏，扔地上当泡踩。</p><p>嗡——！</p><p>整座图书馆的空间瞬间凝滞，仿佛被投入琥珀的昆虫。书架震颤，灰尘簌簌落下，书籍封面都似乎扭曲了一下，发出无声呻吟。</p><p>十几道身影如同从书页夹缝中、从书架阴影里、甚至是从光线本身中“析出”。</p><p>他们穿着类似图书管理员的深色制服，面无表情，眼神空洞，但每一个人的左胸，都别着一枚散发着不祥暗金色泽的徽章。</p><p>他们的存在感冰冷、僵硬，带着程序化的非人感。</p><p>十几双空洞的眼睛，毫无感情地聚焦在杨帝身上。那目光更像是扫描，锁定，归档。</p><p>图书管理员。</p><p>管理员不说话。其中一人毫无征兆地抬手，他手中没有书，但一本A4大小的黑色典籍虚影，在他掌心浮现。</p><p>书页无风自动，哗啦啦翻卷。他翻了几百，几千，几万，几十万页，都还没翻到头。</p><p>就好像……页数无限。</p><p>直到某一页，那本黑色的“无限之书”停止了翻动，随即一股难以言喻的吸力笼罩杨帝。</p><p>这股熟悉的气息，熟悉的灵能波动……是领域展开。</p><p>空间在杨帝眼前折叠扭曲，图书馆的景象飞速褪色拉长。</p><p>他感觉自己被强行拖入一个由无穷无尽书页构成的漩涡。</p><p>无数模糊的文字、尖叫的符号、扭曲的插图在身周飞旋而过，带着令人作呕的低语，试图钻入他的意识。</p><p>杨帝的AT力场「心之壁」比可观测宇宙还要厚。试图污染精神的低语，瞬间消弭。</p><p>「第一阶段：进入战场」</p><p>脚下不再是地面，而是踩在巨大、泛黄、散发着霉味的书页上。</p><p>头顶是同样望不到边际的书页天穹，无数文字如同活虫般在纸面上蠕动，组合与分裂。</p><p>悬空的段落文字凝聚成狰狞的利爪，整章整节的文字洪流化作咆哮的恶兽。</p><p>空气里弥漫着油墨、尘埃和一种更深邃的、源自知识扭曲的“疯嚣”气息。</p><p>咻！咻！咻！</p><p>十几道身影紧随其后，从翻卷的书页通道中“掉落”下来。</p><p>正是那些佩戴金徽的管理员。</p><p>他们落地瞬间，空洞的眼神瞬间锁定杨帝，身体僵硬地摆出攻击姿态。</p><p>「第二阶段：清理杂兵」</p><p>第一个扑上来的管理员，有鼻子有眼，嘴巴也刚好只有一个。</p><p>但其拟人的气质，无可掩饰，就算打上马赛克也会让人犯恐怖谷效应。</p><p>杨帝随意一拳印在其胸口。</p><p>面目可憎的管理员，如同被列车炮击中的劣质陶俑，轰然炸裂！</p><p>构成它存在的“物质”在无法想象的巨力与能量冲击下，瞬间被粉碎、电离、加速。</p><p>亿万碎片化作肉眼根本无法捕捉，炽热到发白光的致命洪流。</p><p>这些碎片，携带着杨帝拳力中逸散出的，足以执行黑暗森林打击的恐怖动能，以高亚光速接近光速但未达到狂暴喷射而出！</p><p>咚！</p><p>达到超相对论速度的“管理员碎片”，向两侧“散射”。</p><p>第二个、第三个刚摆出攻击姿态的管理员，甚至连“反应”这个概念都来不及产生，就被爆散的碎片，在躯干上贯穿出脸盆大小的洞。</p><p>随即，被“管理员碎片”击中之处，引发微型的湮灭爆炸，将更多的碎片抛射出来，加入这场毁灭的盛宴！</p><p>链式反应！</p><p>一个中子高速撞击铀-235原子核，原子核会裂变成两个质量相近的中等原子核，释放巨大的能量，同时射出2-3个新的中子。</p><p>每个中子都可能撞上其他未裂变的铀-235原子核，引发新一轮裂变。假设第一个裂变释放3个中子，3个中子都成功击中其他铀核，就会引发3次新的裂变，释放出9个中子；这9个中子再各自击中铀核，又会引发9次裂变，释放27个中子……这就是链式反应。</p><p>杨帝以无匹的物理蛮力，引发了宏观层面的链式反应！</p><p>一拳，扫完杂兵。</p><p>杨帝缓缓收回拳头，吹了吹拳峰上并不存在的烟，仿佛只是随手掸掉了一点灰尘。</p><p>他这一拳，对当代人亦是绝杀。</p><p>（因为当代社会愈发原子化，每个个体都趋于变成原子人，容易发生链式的原子核反应）</p><p>不到一息。</p><p>毁灭性的炽白光球膨胀到极限，然后如同超新星遗迹般缓缓黯淡，消散。</p><p>整个战场中央区域，已经变得一片狼藉。</p><p>十几个佩戴金徽的管理员，连同他们所在区域的“大地”、“山脉”和“河流”，彻底消失。</p><p>只留下一个巨大无比的、边缘还在流淌着熔融纸浆和沸腾墨汁的焦黑深坑，以及空气中如同恒星核心般的高温灼热气息，和臭氧混合焦糊的刺鼻味道。</p>
