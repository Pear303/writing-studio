# 探索行动与业务实习

<p>“自然现象”，这四个字分量很高，杨帝要是对耶罗随便下手就是不政确了。</p><p>逸曜星尊敲了敲讲台，将众人的注意力拉回。</p><p>“本次远征探索行动，已获星环最高议会批准，列为特级优先事项。所有参与人员，按《星环盟约外勤特别补助条例》执行，享有全额灵能损耗补贴、跨维度通讯津贴，以及……每日四十标准虚空信用点的餐食补助，实报实销，需提供相应宇宙的有效消费凭证。”</p><p>外卖员脖子上的狐尾尖几不可察地抖了一下，似乎对这微薄的餐补表达了无声的抗议。</p><p>那团混沌的寂无终焉形藏发出一阵意义不明的气流嘶声。</p><p>逸曜星尊无视了这些细微的反应，目光转向杨帝。</p><p>“考虑到队伍中有新成员加入，经验尚浅，且其所属区域情况特殊。</p><p>“经会议表决通过，决定先安排杨帝同志随队完成几项常规辖区维护任务，作为实习考察，熟悉业务流……熟悉盟约的工作方式。</p><p>“实习期表现将计入最终评估，影响转正定级及后续资源配给。杨帝同志，你有什么问题吗？”</p><p>杨帝张了张嘴，无数问题堵在喉咙口，最终却只化作一个清晰的认知：</p><p>他，反抗耶罗、质疑盟约的杨帝，就这么在一瓶矿泉水和每天四十块餐补的标准下，莫名其妙地，有了一个神圣星环盟约的岗。</p><p>那银白色的机兵人形不知何时已站到他身侧，平静无波的声音响起：</p><p>「实习任务一：协助维护编号S-73…(一段超长的坐标)…34号宇宙叙事基准稳定性。公务车已备好，请随我来，杨帝同志。」</p><p>杨帝也便坐进了那具机兵的驾驶舱。</p><p>舱门无声闭合。</p><p>那银白色的人形坐在驾驶位，流畅地启动载具。虚空再次于窗外扭曲、倒退。</p><p>「重新自我介绍。」</p><p>它——或者说他——的中性声音在狭小的空间内响起，平稳如常。</p><p>「吾即太一矩枢，星环盟约第一宇宙群盟主，现任盟约交通架构总工程师。」</p><p>杨帝挑眉。</p><p>「你的表情显示疑问。我将做通俗解释。」</p><p>太一矩枢一边操控载具穿梭于光怪陆离的维度间隙，一边说道：</p><p>「想致富，先修路。吾致力于虚空基建设施互联互通，星环现有交通网络骨架，百分之九十九由吾奠定。」</p><p>「至于这形态，修路常遇阻碍：难以逾越的虚空天然险隘，或试图收取过路费的野生圣人劫道。」</p><p>「所以我将自身设计需集成勘探、筑路、防御、清障、物理劝服等多功能于一体。」</p><p>「人形适配绝大多数宇宙的操作接口与环境，综合效率最优。」</p><p>「譬如，存在部分仙道宇宙，灵气感应与运转必须依托‘人形’架构才能实现。」</p><p>「我若仍是纯粹机械形态，连最基础的灵气牵引都做不到。若单纯使用自然科学手段，我需要多付出约12%的代价建设基础设施、道路交通系统。」</p><p>「除此之外，此机体可随世界线需求无限分裂，确保工程全域覆盖……」</p><p>「我的正式编号为：无限基础设施建设兵团。」</p><p>太一矩枢顿了顿，传感器微光流转。</p><p>「简称，‘无限基兵’。」</p><p>杨帝坐在驾驶舱里，听见有滴滴嘟嘟像是闹钟的声音，想必太一矩枢在讲出“无限基兵”这个正确的简称时，心情一定很不错。</p><p>「只是修路过程中，我物理劝服的次数稍微多了一些。」</p><p>「便被以讹传讹，叫成了如今这个略显暴力的‘无限机兵’。」</p><p>「须知，这都是恶意造谣抹黑。」</p><p>「星环盟约向来热爱和平，不会随意动用武力。我所有‘物理劝服’行为，均严格遵循《星环盟约跨宇宙基建安全条例》第三章第七条，仅针对‘主动破坏公共交通设施、威胁施工人员安全、恶意阻断虚空航道’的行为，且全程有执法记录仪实时存档，事后需提交议会基建安全委员会审核备案，确保每一次行动都符合必要性与适度性原则……」</p><p>杨帝看着窗外飞速掠过的宇宙，一片纯粹白色的虚空，沉默了片刻。</p><p>“所以，星环盟约镇压一切不服的终极武力……”</p><p>「是生产建设兵团。」</p><p>太一矩枢精准接话。</p><p>「主要业务确实是修路。顺带，用道理和物理手段，维护一下道路畅通。」</p><p>杨帝：“虚空无物。你是怎么移动的呢？你所建设的‘道路’又在哪里？”</p><p>太一矩枢的声音平稳，如同陈述一项基础工程参数：</p><p>「虚空无维度，无时空，无方向，无一切可被定义之概念。在此，‘移动’本身亦无意义。」</p><p>「所以，若欲前行，需要先定义‘前’。」</p><p>太一矩枢操控载具，银白色外壳泛起微光。</p><p>「宇宙本身能在虚空中存在。宇宙为何物？上下四方，古往今来，其实喻指一个能让故事发生的场域。」</p><p>「无限基兵首先找到起点，定义终点，随后在绝对无中，强行定义出一条临时路径。」</p><p>「此过程可理解为，在两个圆球状的宇宙之间，再架设一根长条状的宇宙。」</p><p>「无限基兵职责，便是将这条临时定义的‘路’，永久固化为可通行的‘世界’。」</p><p>「看似移动，实则是发现、激活并沿着自我定义的结构前行。」</p><p>「路铺到何处，便能行至何处。」</p><p>「简言之。想去哪儿，就先修条路过去。」</p><p>杨帝想起他在耶罗分形区宇宙群。</p><p>那里并没有无限基兵进行基础设施建设，宇宙和宇宙之间往往老死不相往来，只有极少数圣人之中的佼佼者可肉身横渡虚空。比如杨帝。</p><p>原理是自成一界，一人即是一整个宇宙。</p><p>「可将宇宙视为一本书。」太一矩枢的声音毫无起伏，却带着一种工程般的精确。</p><p>「虚空，是比空白更彻底的‘无书’。它连‘可书写’的属性都不具备，是绝对的‘无意义’。」</p><p>「一个完整宇宙，便是装订成册、写满故事的书。其外壁，即是封面与书脊。」</p><p>「为何能抵抗虚空腐蚀？因这‘封面’并非单纯物理阻隔，而是由宇宙内部所有叙事、法则、存在性共同编织的镀层。」</p><p>「内部故事越丰饶，逻辑越自洽，存在越坚实，‘镀层’就越厚越坚韧。它向虚空宣告‘此处有物’，从而拒绝被‘无’同化。」</p><p>「虚空的‘空’，无法侵蚀存在的‘有’。」</p><p>「耶罗分形区能在大魙败边缘存续，正因其内部无限递归的复杂叙事提供了极强的‘现实丰度’，形成了近乎绝对的闭锁，相当于一本自我引证、无限循环的书，极难被擦除。」</p><p>「而我等修筑的‘路’……」</p><p>他补充道。</p><p>「即是人为制造一条极简的线性‘故事线’，将其固化，成为连接两本‘书’的通道。虽单薄，但足够指明方向。」</p><p>正在飞向另一本“书”，也就是业务实习的地点。</p>
