# “正常”

<p>杨帝不过是见识广博。一般而言，广度与深度难以两全。</p><p>他获得原初之眼不知多少兆亿年的记忆后，记忆的广度自是极为宽泛，然而其中科学技术素养所占比重却极小。</p><p>在前一个宇宙，灵能极为充沛，大多数文明皆是以魔法与修仙作为发展根基。</p><p>灵修之道，更侧重于探寻一种精神层面的升华，秉持“唯灵论”的世界观来审视宇宙。</p><p>像守望者文明这样，机缘巧合诞生于灵能稀薄的星系，进而踏上纯粹物理技术发展路线的文明，在前一个宇宙中实在是凤毛麟角。</p><p>59改的守望者文明，作为正儿八经从自然科学逐步崛起的顶级势力，其在物理研究领域，乃至灵能开发方面的能力，都堪称出类拔萃。</p><p>他很快便分析得出，此界的石油物理法则以及灵能规律，存在着微妙的差异，这便是此界石油储量极度丰富的缘由。</p><p>如此看来，“石油储备丰富”这一点，便也算不得什么疑点了。</p><p>这一番发现，倒是给杨帝带来了更多启示——不同的世界有着不同的规则，当真可谓入乡随俗。</p><p>世界与世界之间，本就存在着千差万别。</p><p>59改接下来继续说道：</p><p>「我还顺带检查了凡界王朝的科技树攀爬历史。但由于‘凡界’受到‘灵界’干涉过多，历史过程中存在过多断层与扭曲，关键节点模糊不清，缺失的部分无法拼接，只留下难以连贯的碎片，难以从中梳理出完整且清晰的发展脉络。」</p><p>凡界受灵界干扰的历史进程太多了。</p><p>而且大多数时候都是暗中干扰，各种见不得光，也没留下纸质记录的手段。</p><p>导致此界的历史，一旦细细梳理起来，就会发现有些猎奇。</p><p>杨帝原本也怀疑，是凡界研发出能够无声无息灭杀大帝的武器。</p><p>但59改信誓旦旦地担保，凡界的全部社会生产力加起来，杀一个元婴老怪都够呛，得用核弹不要命地炸。</p><p>所以，目前也排除凡人文明通过“技术爆炸”突然在几年、几十年内获得能够杀死大帝之能力的可能性。</p><p>「继续罗列其他情报：」</p><p>「凡界拥有较为落后的反重力技术，其反重力原理，源自于一种名为‘Cavorite’的天然反重力矿石……」</p><p>「凡界拥有较为先进的虚拟现实技术，对虚拟空间的技术操控力，远远超过相同卡尔达肖夫级别的其他文明。」</p><p>「他们利用虚拟现实技术仿真与模拟历史、城市规划建设、教学科研、娱乐生活。」</p><p>「凡界社会文化极为保守，使用不透光的宏观物质遮挡性征……」</p><p>杨帝一边听着情报，一边观察来来往往、身上只贴了两三片创可贴的路人。</p><p>这哪保守了……</p><p>59改叽里呱啦解说着凡界情况。</p><p>事已至此，泡面吃饱，火腿肠也放了，甚至连卤蛋也放了两个加餐。</p><p>一人一狐一鱼一坦克陷入难得的沉默。</p><p>此刻是i人的人性解放时刻。</p><p>火车在沉闷的黑暗中穿行，窗外是连绵不绝的岩石壁，只有车厢内昏黄的灯光映照着乘客们昏昏欲睡的脸庞。</p><p>车轮碾过铁轨的节奏仿佛催眠曲。</p><p>阿巴已经抱着泡面桶打起了小呼噜，青丘白璃则支着下巴，望着窗外飞速掠过的隧道壁光影出神。</p><p>那四位灰袍老者依旧蜷缩在角落阴影里，如同四尊凝固的雕像。</p><p>杨帝闭目养神，但思绪显然还在归墟大帝和十万大山的谜团中盘旋。</p><p>乓啷！</p><p>一阵刺耳的金属摩擦声撕裂了宁静！</p><p>紧接着是令人心悸的剧烈震动，仿佛整列火车撞上了一堵无形的墙。</p><p>乘客们被猛地甩向前方，惊呼声、孩子的哭喊声瞬间爆发。</p><p>灯光疯狂闪烁几下后骤然熄灭，只留下应急灯幽幽的绿光，车厢内陷入一片混乱的昏暗。</p><p>“怎么回事？”</p><p>“撞车了？”</p><p>“我们还在隧道里啊！”</p><p>刺耳的广播声响起，带着明显的电流杂音：</p><p>「各位旅客请注意……临时停车……前方轨道……出现异常情况……属于正常……维护范围……请保持镇定……待在座位上……不要随意走动……重复……不要害怕……这是正常情况……」</p><p>“正常情况？”阿巴夸张地皱起眉，泡面汤差点洒出来，“这动静可一点都不‘正常’。”</p><p>她这么说并不是空口无凭。</p><p>一阵沉闷而极具压迫感的“隆隆”声从隧道深处传来。</p><p>声音并非来自火车本身，而是某种巨大、沉重、在地底或岩壁中穿行的东西正在靠近。</p><p>声音越来越响，带着金属扭曲和岩石粉碎的混合噪音，震得车厢地板都在嗡嗡作响。</p><p>透过应急灯微弱的光线，车厢连接处的乘客惊恐地看到——</p><p>隧道壁的阴影中，一个庞然大物的轮廓正在逼近。</p><p>那东西形如一条放大了无数倍的钢铁蠕虫，头部是高速旋转、闪烁着寒光的巨大复合钻头，直径几乎与隧道相当。</p><p>钻头后方是覆盖着厚重装甲、布满液压杆和传动装置的粗壮身躯，一节节地蠕动推进，所过之处，坚固的隧道壁如同豆腐般被轻易撕裂、挤压，碎石簌簌落下。</p><p>杨帝等人自然也早就发现了这玩意在逼近。</p><p>但青丘白璃一个劲儿地在说“这玩意真的很正常”。</p><p>她解释道：“凡界时不时有机械故障。那些明明不应该有任何智慧的洗衣桶、面包机和微波炉，偶尔会暴走。”</p><p>只不过，这次暴走的是一台废弃盾构机。</p><p>「动力装甲安保队！立即前往B7隧道段！重复，立即前往B7段！目标：失控工程单元‘盾构地龙-10型’！最高威胁等级！阻止其靠近列车！」</p><p>他们的耳朵捕捉到安保队的队内语音。</p><p>车厢门猛地被拉开，几名身着外骨骼动力装甲的安保人员冲了出去。</p><p>他们的装甲涂着铁路安保的标识，手中武器并非传统的枪械，而是闪烁着能量光芒的爆矢枪和能产生高频震荡波的链锯剑。</p><p>沉重的脚步声迅速消失在车头方向。</p><p>“轰轰轰！”</p><p>“滋滋——！”</p><p>“警告！护盾过载！”</p><p>激烈的交火声、能量武器轰鸣声、金属撞击的巨响以及装甲通讯频道泄露出的断断续续的警告和怒吼，透过厚重的车厢壁传了进来。</p><p>战斗显然异常激烈，乘客吓成一团。</p><p>阿巴也醒了，抱着她的泡面桶，眼巴巴地看着杨帝和青丘白璃。</p><p>“你要出手干涉吗，白杨大帝？那只是一条普通的失控盾构机，属于凡界的正常内务。”青丘狐狸说。</p><p>“我当然知道。”</p><p>“青青……你确实这真的正常？”</p><p>“凡界嘛，特别是这种大型工程区域，总有些自动化设备年头久了或程序错乱，偶尔‘闹点小脾气’，出来溜达溜达搞点破坏。放心，安保队处理这个有经验……嗯？”</p><p>轰！她的话音未落，一声远超之前的巨大爆炸声传来。</p><p>「网络屏蔽装置被那大虫子打爆了！」他们又听见安保队的队内语音如此呼吼道。</p><p>「上EMP！别让它进车厢！」</p>
