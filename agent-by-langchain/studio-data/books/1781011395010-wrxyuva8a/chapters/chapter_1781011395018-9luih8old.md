# 新人类进化

<p>“老帝，你刚被‘新生咨询群’那帮畜生蛊惑，网贷了一百万炒股全亏？”</p><p>“……为什嘛突然这么说。”</p><p>“因为我看你比精神分裂症还要魂不守舍。”</p><p>杨帝回过神。魂不守舍不是因为“炒股”，而是因为脑子里的声音……淦！系统？</p><p>他明白这莫名其妙的即视感从何而来。</p><p>大病一场后，脑子里突然出现了声音，似乎，是某种普遍存在于网络文学中的形而上学神秘力量——系统！</p><p>……吗？</p><p>“张明远！你有没有听见……”话到嘴边却硬生生刹了车。</p><p>杨帝脑海中闪过他迄今为止读过的十万八千本经典文艺作品。</p><p>他换了种高情商问法。</p><p>看着张明远困惑的神色，杨帝试探地问道：“张明远，我是说，如果你脑子里出现一些声音，比如说体力加一，体能加一，体质加一，诸如此类的，你觉得这声音可能会是什么呢？”</p><p>张明远瞳孔微缩。</p><p>他手指捏着下巴，深入思考：“嗯……那麻烦了，真的麻烦了。”</p><p>这话说得杨帝都紧张起来：“咋？”</p><p>舍友耸耸肩：“我只帮你预约了明天的消化科，但还没有预约精神科。”</p><p>杨帝没有怼回去。</p><p>他喉结滚动，改用心理咨询室海报上的话术：“我是说，假设存在某种……神经反馈机制？比如运动时自动生成体能评估？”</p><p>张明远前倾，注视杨帝眼睛，让他想到《银翼杀手》中的移情测试。</p><p>用来测试对方是不是人类。</p><p>“唉，麻烦太大了。”</p><p>张明远推了推滑落的眼镜架，“明早消化科复查后，我带你去挂陈教授的号——他专攻创伤后应激障碍。”</p><p>见舍友一脸不相信，一直插科打诨，杨帝只好站起身走出门外，自己去研究研究。</p><p>“……张明远，我出去下。”</p><p>“干蛤？”</p><p>“跑步，吃饭。”</p><p>“哦。”张明远应了一声，又转身匍匐向他的电脑前。</p><p>过了好一会儿，他才终于后知后觉，猛的转过身：“等等老帝！现在夜晚，什么跑步？你刚痊愈，什么吃饭？！”</p><p>……</p><p>杨帝早就溜出宿舍了，他第一站先来到大田径场。</p><p>种种迹象表明，他的身体确实发生了某种神奇的变化。</p><p>这不，喝了南瓜粥后，杨帝原本以为会像往常刚得完急性肠胃炎一样，肚子咕噜咕噜响个不停，甚至还会有点胀气什么的。</p><p>可这次完全不同。</p><p>南瓜粥下肚没一会儿，他就觉得全身暖烘烘的，一股莫名的力量在身体里涌动，仿佛有小宇宙在体内爆炸。</p><p>这手臂上的肌肉，好像比刚才又结实了些？</p><p>是夜晚灯光不够产生的错觉吗？</p><p>“这难道就是……「体力+1」的效果？”</p><p>杨帝踏上跑道时，夜风卷着塑胶颗粒特有的焦糊味扑面而来。</p><p>大学夜跑的人也有几个。</p><p>这个点还在跑步，是真田径爱好者了，大概率不是为了完成指标而被迫苦着脸去跑。</p><p>他们短袖短裤，穿着运动腰带和耳机，一边跑一边朝新来的杨帝看一眼，点头致意，还是挺欢迎新人的。</p><p>杨帝特意选了最外侧的第八道，怕自己大病初愈跑起来跌跌撞撞，妨碍他人。</p><p>田径场跑道一圈400米，一坤圈是1000米。</p><p>「跑步+1」「体力+1」</p><p>最后100米，他内心再次出现这个诡异的声音。</p><p>他低头看着被汗水浸透的前襟，秒表显示才过去4分15秒。</p><p>往常，就算是状态好，只要不是豁出去没命地跑，一千米也得花4分30左右。</p><p>而现在，快了15秒。</p><p>他的体力，似乎真变好了一点……？</p><p>刚放松下来，胃部便传来绞痛，像有把电钻在搅动肠子。</p><p>“我超……好饿。”杨帝踉跄着扶住栏杆，冷汗顺着脊椎往下淌。</p><p>方才的轻盈感荡然无存，取而代之的是每个细胞都在尖叫的饥饿。</p><p>似乎能理解央九台《动物世界》里，非洲草原掠食者鬣狗看见腐肉时的心情了。他想。</p><p>现在特别想吃饭！</p><p>本来一碗粥不算饱，刚才跑步又像是将体力全部挥霍了出去，身体非常饥渴。</p><p>……</p><p>深夜食堂亮着唯一窗口，上夜班的食堂大妈正在收拾蒸笼。</p><p>玻璃窗突然被拍得砰砰作响。</p><p>她抬头就见个浑身湿透的男生扒在取餐口，眼睛绿得发亮，跟生化危机的丧尸似的。</p><p>“十个肉包！不，十五个。”</p><p>“同学你还好……”李阿姨把蒸笼递过去，话没说完，校园卡已经拍在刷卡机上。</p><p>她在玻璃窗后，眼睁睁看着这个清瘦男生找了个以为无人看见的隐蔽位置坐下，风卷残云般扫荡食物，蒸笼以肉眼可见的速度空下去。</p><p>那可是十五个小笼包啊。</p><p>一个不大，但十五个，绝对超过一个健康成年男子一顿宵夜的分量。</p><p>杨帝感觉自己身体化作黑洞，在吞噬十五颗行星！</p><p>肉包刚入口就化作暖流，淀粉与蛋白质入喉瞬间蒸发成能量。</p><p>当然这是比喻，真正消化还需要时间。</p><p>「消化+1」「体力+1」</p><p>那种诡异而又模糊的感觉又划过心头。</p><p>他边吃边开始寻思。</p><p>如果是“体力+1”，那很好理解，应该是一种身体素质的提升。</p><p>但这个划过心头的模糊感受，又远远不只这个意思，似乎还隐藏着各种晦涩的概念：</p><p>比如是什么肌肉束断裂愈合，获得了增强，骨骼力量提升了多少个千分点……</p><p>神经与激素如何更适应了剧烈运动……</p><p>心肺功能又如何因什么综合因素获得了哪方面增强，下肢力量的增强又比上肢要多……</p><p>他只能大概将其概括为“体力+1”这四个字。</p><p>但是，“消化+1”呢？</p><p>同样是非常模糊的感受，其中展开来说的概念极其复杂：</p><p>胃部蠕动的速度加快，食道壁增厚且力量加强，肠道吸收营养的效率提升，代谢速度隐隐有加快趋势……等等。</p><p>增强和进步发生的比较微弱，并不明显。</p><p>但他能切实感受到，自己通过跑步，俯卧撑和吃饭，身体对应的部分机能被增强了。</p><p>俯卧撑主要增强上肢力量，跑步则是下肢和心肺，就算是吃饭也能强化咬合肌、牙齿和消化系统。</p><p>等等，牙齿也能进化？</p><p>……是的，杨帝似乎能从“消化+1”中捕捉到一个模糊概念：他咬东西，牙齿变硬。</p><p>不……尽管他是工科专业，与医科风马牛不相及，对口腔知识更是两眼抓瞎。</p><p>但也知道最基础的口腔卫生科普：</p><p>经常咬东西更多的是会导致牙齿的磨损，过度咬东西可能会使牙齿排列不齐。</p><p>啃咬不会让牙齿变强，反而会导致磨损！</p><p>牙齿不是肌肉啊喂！</p><p>杨帝拍了拍自己的脸，他怎么会产生“锻炼牙齿使其增强”的想法……</p><p>又等等。肌肉？</p><p>杨帝拿着倒数第三个小笼包的手愣在空中。</p><p>锻炼肌肉的原理也是先进行肌肉锻炼，使肌肉纤维受到一定程度的损伤，然后再生长修复、超量恢复。</p><p>关键是损伤，然后是损伤后的超量恢复，二者缺一不可。</p><p>牙齿切碎食物会导致磨损，但如果牙齿能够自行超量恢复呢？</p>
