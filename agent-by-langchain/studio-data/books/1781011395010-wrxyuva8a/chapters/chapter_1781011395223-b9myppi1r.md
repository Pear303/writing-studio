# 降灵

<p>剧烈的排异反应席卷全身，免疫系统在疯狂攻击那些既熟悉（原本的宿主细胞）又陌生（被快速修改中的细胞）的“异物”，导致了这场恐怖的高烧和全身性炎症风暴。</p><p>血管扩张，血液奔流如沸水，汗水瞬间浸透衣物又迅速被高温蒸腾成白气。</p><p>这场基因层面的战争持续了不知多久。</p><p>当高烧如同退潮般猛然降下时，尸体——或许此刻应称为“受肉”——的皮肤温度迅速冷却。</p><p>红疹也开始消退，留下大片的暗红印记，仿佛被烈火灼烧过。</p><p>皮肤下，肌肉的纹理似乎也发生着微妙的改变，变得更精炼，更富有爆发力。</p><p>血型检测仪如果插入，会发现这具受肉中每一个细胞，内部的核已经被替换成“杨帝”的基因编码。</p><p>一个人——至少属于达文西的肉身，被彻底地调换了。</p><p>高烧的退去并非终结，而是另一场更诡异风暴的序曲。</p><p>刚刚冷却下来的头颅，内部开始急速升温。</p><p>这一次，热量仿佛被约束在大脑的颅骨之内，没有散发出来。</p><p>与此同时，那具身体的脑电波——如果有仪器能捕捉的话——呈现出一片狂暴的混沌。</p><p>波形剧烈地起伏、跳跃、叠加、撕裂。</p><p>峰值高得远超正常人类极限，频率混乱得如同宇宙初开时的背景噪音。</p><p>这像是某种……超载的信息处理？</p><p>是两套截然不同的记忆、人格、世界观，在同一个物理容器/受肉内激烈地碰撞，争夺主导权？</p><p>属于“达文西”的过往：码字的焦虑、扑街的沮丧、对成功的渴望、对生活的妥协、对银隼的恐惧……</p><p>如同破碎的胶片在意识深渊中飞速闪回。</p><p>大脑内部的温度持续攀升，仿佛一颗即将超新星爆发的微型恒星被禁锢在颅骨之内。</p><p>属于“杨帝”的设定：平凡学生、食物中毒、能力觉醒、直面邪神……覆盖了原本属于碳基人类“达文西”的思维器官。</p><p>颅腔内那场无声的超新星爆发耗尽了最后一丝狂暴的能量。</p><p>当混乱的脑电波风暴平息为深潭般的寂静，那具受肉，已彻底嵌入了这片雨后荒野的怀抱。</p><p>晚风早已停歇，虫鸣不知何时重新织起了细密的网，唯有头顶，是天鹅绒般的深蓝天幕，缀满了亿万颗冷冽的钻石。</p><p>黑发如泼洒的墨，散落在微凉的草叶间，黑眸紧闭，睫毛在眼睑下投出两弯小小的月牙形阴影。</p><p>时间仿佛失去了刻度。</p><p>荒野、尸体、残存的手机幽光……</p><p>一切俗世的喧嚣与死亡的痕迹，都被浩瀚的宇宙稀释。</p><p>他只是一粒微尘，被轻柔地放置在无垠的星盘之上。</p><p>受肉仍然没有呼吸的起伏，也没有心跳的搏动，只有永恒的静谧包裹着他。这具躯壳本身，就是一块从遥远叙事深渊漂流至此的宇宙奇石，正等待着某个指令，或某个契机，来唤醒其中沉睡的星火。</p><p>不知过了多久，也许是一瞬，也许是千年。</p><p>一道银线，毫无预兆地撕裂了天鹅绒般的夜幕。</p><p>那是流星，宇宙间最孤独也最绚烂的旅者。</p><p>就在那流星燃烧到最炽烈，光芒几乎要刺破穹顶，将星辉都短暂压下的巅峰刹那——</p><p>荒野上，那具静默的“受肉”，眼睑微微颤动了一下。</p><p>如同沉睡的古神，被星陨叩响心扉。</p><p>契机。</p><p>覆盖着星尘的睫毛，带着初生般的滞涩，向上掀开。</p><p>流星最后最璀璨的光芒，恰好在这一刻，毫无保留地倾泻入那双初睁的眼眸深处。</p><p>那双黑曜石般的眸子，瞬间捕捉并吞噬了这道来自天外的炽烈辉光。</p><p>“我终于来到此地。”</p><p>这个距离他曾经待过的地球，很远很远很远的地方。</p><p>宇宙的冰冷与宏大，以近乎暴虐的方式，挤压着他刚刚凝聚的感官。</p><p>他尝试移动一根手指。</p><p>肌肉纤维发出不堪重负的吱嘎，关节僵硬如同锈蚀千年的齿轮。</p><p>头颅内部，那场意识风暴平息后的余烬仍在隐隐灼烧，带来阵阵眩晕。</p><p>力量？</p><p>属于“数值怪”那动辄撼动星辰的力量？</p><p>已蛰伏在基因链的最深处，如同被亿万道枷锁禁锢，只余下属于碳基生命的原始之孱弱。</p><p>他虚弱得甚至无法支撑起自己的头颅，无法支棱起一根腿毛。</p><p>只能被动地仰望着那片过于慷慨的星空。</p><p>他的眼睛——那双刚刚吞噬过流星余烬、非人的黑曜石之瞳——穿透这具凡俗躯壳的桎梏，刺破了宇宙的表象。</p><p>视线所及，并非仅仅是闪烁的星辰和深沉的虚空。</p><p>他看到的是…… 无穷。</p><p>无穷的星海，无限的维度，无垠的宇宙，无尽的世界。</p><p>杨帝目光不受控制地向下沉降，穿透身下冰冷的泥土，深入微观的领域。</p><p>一粒被夜露沾湿、最卑微的尘埃，在他眼中轰然炸开。</p><p>他看到无穷无尽奔涌狂涛的灵能在感知中咆哮。</p><p>即使是一粒尘埃，都拥有绝对意义上的「无穷」灵能。</p><p>杨帝只是看一眼，但感觉自己的普通碳基大脑接收到了宇宙初开时爆炸，震得他新生的颅骨嗡嗡作响。</p><p>这能量层级……远超他过往认知中的任何“世界”。</p><p>头顶的星辰与脚下的尘埃，在“无穷”的尺度上，本质并无不同。它们都是蕴含无限灵能的结构体，都是沸腾着无穷现实丰度的奇点。</p><p>这里，就是一切叙事得以编织、一切现实得以锚定的——最上层世界。</p><p>“耶罗……”一个名字，如同烙印在灵魂深处的初始指令，随着这认知的明晰，轰然撞入他混乱的意识。</p><p>耶罗大仙！</p><p>那个书写了他命运每一个转折、每一次挣扎、每一丝痛苦与狂喜的存在。那个将他从平凡的杨帝塑造成突破无限、降临此地的“数值怪”的至高意志。那个……操纵者。</p><p>找到祂！质问祂！甚至……超越祂！</p><p>这个念头如同点燃了引信的炸药，瞬间引爆了他降临此世后第一个明确的目标。</p><p>“耶罗大仙……”</p><p>然而，就在他意识探入这具“受肉”的记忆深渊刹那——</p><p>杨帝躺在星空下的躯体猛地绷直，如同被无形的电流击中！</p><p>“耶罗大仙，等于书写我命运的编撰者……”</p><p>“我降临此地，是为了杀掉耶罗大仙……”</p><p>“这具‘受肉’残留的记忆显示：就是达文西/万业狐狸书写了我降临于此的命运……”</p><p>“达文西写的东西太毒，被找上门的‘银隼’枪毙了，头颅爆裂……”</p><p>“而我……我是在他死亡之后，降临于此，覆盖了他的尸体，成为了‘杨帝’……”</p><p>“达文西就是耶罗大仙？！”</p><p>“那个设定了我的命运路径，让我突破无限的存在……就是这个扑街写手？”</p><p>“我已经杀掉了耶罗大仙？！！”</p>
