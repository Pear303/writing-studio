# 原初之眼：崩坏之物

<p>想象一下，一个人的世界线疯狂震荡，就拿凤凰院凶真举例子吧——假如在一次用微波炉穿越时间后，他的命运陷入一秒变化3000次的永恒混沌，会有怎么样的现象？</p><p>构成他的每一个粒子，都因为其他世界线的粒子串线，而获得了随机的能量、位置，以及其他任何能列举的粒子属性。</p><p>凤凰院凶真的身体，会如同被卷入一场无形的风暴，呈现出极其诡异且混乱的状态。</p><p>女武神部队的队长警告，若不尽快解决这团黑色拉面，它所引发的“崩坏”将会如病毒般扩散至整个宇宙。</p><p>届时，所有文明都将在这场混乱的命运漩涡中覆灭。</p><p>当然，在此之前，全宇宙也可能已经在“原初之眼”这个横空出世的怪物肆虐下，被毁灭千百万亿遍了。</p><p>很巧，这位智械文明的使者也叫“凤凰院凶真”。</p><p>他已经不幸染上“崩坏”。</p><p>他的轮廓愈发模糊，似被一股无形之力肆意摆弄，时而如面团般被拉长，仿佛身体的某些部位正硬生生地被拽入未知维度。</p><p>不同能量状态的粒子相互激烈碰撞、彼此干涉，种种复杂作用之下，他的体表几乎丧失了反射有意义光线的能力。</p><p>远远望去，像是一团深邃的黑色。</p><p>一种五彩斑斓的黑。</p><p>其间光芒杂乱无章地跳跃闪烁，色彩绚烂却又弥漫着令人胆寒的不安气息。</p><p>前一秒，体表还泛着炽热的红色光芒；下一秒，却又瞬间转为冰冷的幽蓝，恰似来自极寒深渊的凝视。</p><p>他的身形更是变幻莫测，此刻还是正常人类的模样，转瞬之间，四肢便可能以违背人体结构常理的方式肆意伸展或急剧收缩。</p><p>脑袋的位置会毫无预兆地突兀鼓起奇异的肿块，又或者身体的某一部位骤然凭空消失，紧接着却在一个匪夷所思的地方再度浮现。</p><p>以他为中心，一圈圈扭曲的时空涟漪如投入平静湖面的石子激起的水波般扩散开来。</p><p>混乱的场域向外蔓延，周围的万事万物皆未能幸免。</p><p>那些靠近“崩坏”的物质，或是被一股莫名且强大的时空潮汐力拉扯得扭曲变形，或是在一阵刺眼的闪烁之后，便消失得无影无踪。</p><p>物质被卷入了疯狂震荡的世界线洪流之中，去向成谜。</p><p>稳定秩序的崩溃，可认知论的损坏。</p><p>这就是宇宙战场中，世人所面临的“崩坏”。</p><p>如果说，“崩坏”是灵能归零，世界线无限震荡，命运走向永恒的混沌与绝对的随机。</p><p>那么，诸如“女武神”这类灵能富集者，就是崩坏的反面——他们是自身命运的绝对主宰者。</p><p>他们能够凭自己的心意，扭曲现实。</p><p>——这正是对命运的随心操控啊！</p><p>领头的「渡劫境」女武神，周身缭绕着澎湃且纯粹的灵能，宛如一轮炽热的太阳，光芒万丈却又蕴含着令人敬畏的力量。</p><p>她的眼神锁定眼前那颗恒星大小的“崩坏”。</p><p>那团如黑色拉面般的物体正疯狂地抽搐着，紫黑色的纹路仿佛是邪恶的诅咒，在其表面肆意游走，散发着令人胆寒的气息。</p><p>如果是寻常如此庞大的天体，必定会在自身重力作用下，坍塌成球形。</p><p>但普通的物理规则，已经对崩坏失效。</p><p>女武神率先发难！她双掌舞动，将灵能凝聚于手心，随手戳出一颗月球大小的元气弹，朝着“崩坏”疾射而去，划破虚空，发出尖锐的呼啸。</p><p>当灵能箭矢触及崩坏物质的瞬间，爆发出一连串震耳欲聋的轰鸣声。</p><p>崩坏物质表面的紫黑色纹路，像是被激怒的毒蛇疯狂扭动起来！无数黑色拉面触须从其表面窜出，朝着女武神凶狠地扑来。</p><p>哐当！真空不能传声但还是传出了激烈爆炸声。</p><p>其他女武神也眼神一凌，加入战局。</p><p>从微观层面看，“崩坏”物质的粒子由于世界线的疯狂震荡而处于无序状态，能量、位置等属性随机变化。</p><p>而灵能的介入，会以一种有序的力量影响这些粒子。</p><p>灵能携带某种“确定性”和“稳定性”，能够在微观尺度上对粒子进行重新排列和稳定。</p><p>就像在混乱拼图中找到正确的拼接方式。</p><p>在宏观上，这种微观的改变逐渐累积，使得“崩坏”物质原本混乱的结构开始恢复一定秩序。</p><p>比如说，恢复基本的分子结构。</p><p>从原本严格意义上的0.000灵，上升至约0.014灵的水平。</p><p>但此刻，恢复了一点点物质结构的“崩坏”，像是被触动了某个隐藏的毁灭开关。</p><p>刚刚凝聚出的些许分子结构，不堪承受这突如其来的“秩序”重负，瞬间开始瓦解。</p><p>随着分子结构的崩溃，原本被禁锢在混乱结构中的能量，如同脱缰的野马般汹涌而出。</p><p>这些能量不再受任何物质结构的束缚，瞬间化作最纯粹的形态，以“崩坏”物质为中心，向着四周疯狂扩散。</p><p>纯粹的能量爆发形成了一场绚烂而恐怖的光爆，其亮度远超宇宙中任何一颗主序星！</p><p>简单来说，灵能者杀伤这些“崩坏之物”的方式，就是让其原本归零的“血条”，先稍微回复一点点。</p><p>但这一缕“生机”，却相当于在摇摇欲坠的危楼上添一块本不该存在的巨石，瞬间打破“崩坏”状态下那诡异的平衡。</p><p>回复0.014灵能后一瞬间，物质重新死亡。</p><p>如果是死不了的东西，那先让其活过来，再杀一遍。</p><p>一个野生的渡劫境大能，大约能磨灭一个黄矮星体积的崩坏之物。</p><p>以个体伟力著称的灵能者，也擅长将“人海战术”和“优势火力学说”相结合。</p><p>一个渡劫大能，连带数百合体境、数千炼虚境强者，对星海各地的崩坏之物疯狂围殴。</p><p>大道、近乎磨灭。</p><p>渐渐的，战争的消息传遍整个宇宙，越来越多文明参战，不断有隐士高人出世。</p><p>数以万亿计的灵能者、魔法使、修仙者、原力大师，如流星般穿梭于宇宙战场间，所过之处灵能波动波涛浪涌。</p><p>他们与星河之间涌动的黑暗拉面、烈阳之下翻腾的黑色阴影，大战至宇宙边疆。</p><p>参战者在毁灭与重生的边缘徘徊。</p><p>但他们必死的意志，决生的冲锋，也许会在下一次时间跳跃回溯后，消失得无影无踪。</p><p>他们的死亡与存活，存在和从未存在，都因为时间回溯，而无足轻重。</p><p>但总归而言，他们的助力，为杨帝减轻了一部分物质世界的反抗力量。</p><p>大约是5%，最高时候，可达到10%的压力减轻效果。</p><p>原初之眼的暗物质之躯，其90%以上的战斗力，仍然只能由驾驶“无限机兵”的杨帝抵抗。</p><p>说实话，他也不知道，这场漫无止境的军事战备，烈度无限升级的战争，何时是个头。</p><p>随着原初之眼的疾速技术迭代，祂的力量也在疯狂爆涨，暗物质躯壳为数不多的缺陷，不断补齐完善。</p><p>文明战线正在崩溃，秩序侧为数不多的优势正在丧失。</p><p>十年空军，百年海军，千年陆军，为秩序与自由而奋战的人们不断死去，但原初之眼无穷无尽。</p>
