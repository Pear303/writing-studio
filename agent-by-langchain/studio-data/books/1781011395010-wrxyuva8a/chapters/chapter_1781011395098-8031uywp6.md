# 赶路途中

<p>翌日清晨，晨曦透过斑驳的枝叶，洒在田间地头。</p><p>自从精神力量变得无比强大，杨帝已很久没睡过一个纯粹的觉。</p><p>他从地窖走出，看见外头守夜的异世界人类和精灵。</p><p>伊芙伸了个懒腰，金色长发在晨光中如火流瀑布般垂下。</p><p>而瑞弗维尔，则顶着两个浓重的黑眼圈，类似于熊猫修炼成人形的模样。</p><p>他看向睡醒一觉、神采奕奕的杨帝，有些好奇：“杨帝，你没梦到什么吗？”</p><p>“梦？对，你怎么知道我梦到夜魅了。我的妈呀你知道吗，梦里，那群夜魅在我脑袋上像秃鹫似的盘旋了一宿，幸好它们在梦境中似乎变温顺了，没有攻击我。”</p><p>梦境中的杨帝，所显露的是精神体。</p><p>在夜魅眼里，杨帝的精神力量犹如一座冰冷的太阳。</p><p>悬于空中，安静地灼烧万物。</p><p>看起来分外恐怖，所以它们不敢靠近……当然要，杨帝不确定这一点对不对，这只是他的合理猜测。</p><p>三人收拾好行囊，继续踏上旅程。</p><p>瑞弗维尔无精打采地跟在队伍后面，脚步虚浮。</p><p>他的眼皮像被铅块坠着，不住地往下耷拉，好几次都差点撞到路边的树干上。</p><p>伊芙回头，“瑞弗，你昨晚没睡好吗？怎么困成这样。”</p><p>她是精灵，能够左右脑轮流休息。</p><p>昨晚，左右半脑各自睡了4小时。</p><p>虽然她知道瑞弗维尔一直陪着自己没睡，但还是要关心一下嘛。</p><p>瑞弗维尔有气无力地摆摆手：“没事，就是夜里一直在想：怎么把我们和熔岩史莱姆的故事写进《大陆英雄野史录》，兴奋得没睡着。”</p><p>“你写野史可以，别把我当主角。”</p><p>他们要继续往南走，去往星渊井口。</p><p>此处距离目的地，大约还有800公里。</p><p>八百公里！相当于从坎通到潇湘。</p><p>坐飞机也得1.5小时，高铁3小时，火车8小时，摩托车15小时。</p><p>异世界虽有魔法，但走路也得走上十天半个月。</p><p>……</p><p>从末日火山出发，已过去七日。</p><p>北边的火山群地形慢慢过渡到平原。</p><p>平原只维持了很小一段，又急促地转变成山地丘陵。</p><p>极目望去，这片天地仿若被巨人随意抛掷的棋盘，乱石嶙峋，犬牙交错。</p><p>硕大的石块或如卧虎，或似盘龙，不规则地散落在起伏的丘陵之上。</p><p>丘陵的低洼处，一汪汪水池星罗棋布，像是大地的眼眸，倒映着天空中翻腾的云海。</p><p>荒芜山地上，稀稀拉拉生长着些低矮植被，叶子因山风与烈日的双重洗礼，变得坚韧而又枯黄。</p><p>在它们的簇拥下，几株野花倔强地绽放。</p><p>伊芙背着手走在草甸上：“一百年前，我见到此情此景，或许还会文青病发作。”</p><p>“现在怎么不会了，伊娃？”</p><p>“我已经彻底拥抱光荣的理工科，不再是多愁善感的文学精灵。”</p><p>那有点遗憾，瑞弗维尔的梦想是编纂野史，而野史算得上是一种文学。</p><p>片刻宁静，这般美景出现了不协调的东西。</p><p>杀手兔。</p><p>杨帝手持板砖，毫无惧色。</p><p>他略施小计，发动嘲讽，杀手兔就会以1.5马赫速度，不要命的向他冲撞而来。</p><p>然后，只需要掏出板砖，便可让杀手兔子撞上砖头棱角，造成300%暴击伤害，自找死路。</p><p>几回合下来，几只杀手兔便成了他们的囊中之物。</p><p>但与此同时，杨帝最喜欢的优质板砖，也耐久度耗尽，轰然破碎！</p><p>他看着手心的红色碎石与粉末。</p><p>这块砖头，超出耐久度上限已经多次了，但每一次，他都用灵能强行将其缝合修补。</p><p>而现在，修补也已经无济于事了。</p><p>杨帝是要找一把趁手的新武器。</p><p>如果能从精灵那儿偷师到“附魔”的门路，那就更棒了。</p><p>中午时分，三人在平原到丘陵之间的过渡地带停下脚步。</p><p>这里地势较为平坦，周围有不少干枯的树枝可供生火。</p><p>瑞弗维尔则从行囊中取出宝贝炊具。</p><p>他总是把几十斤的炊锅、铲子和碗筷都带在身上，所以走得又慢又累。</p><p>但每次他们吃饭时，都会感激将这些厨具带在身上，没有中途把它们丢弃。</p><p>这些炊具就是生活的意义呀！</p><p>杨帝将杀手兔处理干净，切成大小均匀的肉块，用些从附近采集来的香料腌制，放入锅中。</p><p>火苗舔着锅底，锅中的水开始咕噜咕噜地翻滚，兔肉在锅中上下沉浮。</p><p>兔肉在香料的加持下，被赋予了新生。</p><p>空气中弥漫起致命的香味，直往人鼻子里钻。</p><p>为什么致命呢？因为这煮的是杀手兔，杀手专门夺人性命哈哈哈哈哈哈哈哈。</p><p>许多高贵的法爷，因为疏于物理锻炼，而被这种看起来无害的兔子夺了性命。</p><p>吸收了经验后，越来越多术士、法师开始锻炼肌肉。</p><p>更有甚者，法杖镶入狼牙，圣典嵌上撞角。</p><p>而伊芙·柑橘的方案比较小众——她用一种名为「风王结界」的附魔，将自己法杖的主体隐藏起来。</p><p>以此迷惑近战魔物，让它们掉以轻心，从而被隐形的法杖敲闷棍暴毙。</p><p>她在与瑞弗维尔聊天侃大山时，无意中透露出这个信息。</p><p>瑞弗维尔强烈地表达“想看”。</p><p>伊芙拗不过他，无奈道：“退后二十步——不，三十步。法杖显形时要留足生长空间。”</p><p>瑞弗维尔拽着杨帝退到岩石后。</p><p>精灵指尖泛起翡翠色涟漪。</p><p>刹那之刻，山风凝固成琥珀，方圆百米的枯草齐刷刷倒伏。</p><p>——不是被风吹的，倒像有什么庞然巨物，正从虚空里挤出来！</p><p>“有什么大的要来了。”杨帝评价。</p><p>瑞弗维尔有些兴奋地看着精灵：“伊娃！加油啊。”</p><p>“咻——”</p><p>先是三根虬结的青铜色枝干刺破空气，带着千年古木特有的沉香味。</p><p>紧接着！主枝如巨龙抬头般轰然舒展，分叉的末梢不断生长出更细的枝桠！</p><p>原本停在精灵头上的山雀都逃向云端。</p><p>不到三秒，四十米长的“法杖”完全显形。</p><p>最近的小山丘都被遮成阴影里的模型！</p><p>瑞弗维尔下巴几乎要跌碎岩石：“你们精灵管这叫法杖？这分明是攻城槌！”</p><p>杨帝的六感，被伊芙庞大到令人窒息的灵压所震慑。</p><p>那支40米长的法杖周围，萦绕着时间凝固般的力场。</p><p>眨眼间，那支所谓的“法杖”又从视野中消失了。</p><p>伊芙拿着1.5米长的木枝，向他们走来：“风王结界不是隐身术，而是一种空间折叠类附魔——没办法，这术杖太大了，如果只是隐身，进室内容易撞头。”</p><p>瑞弗维尔：“这么长，它是吃啥长大的？”</p><p>“并不是施肥浇水长大的啦。它是圣树的一截枝杈，所以比较大。”</p><p>据说，东方精灵的森林，其实不是严格意义上的“森林”。</p><p>因为据精灵所说，这片林子中的所有树，都由是同一棵树“圣树”衍生出来的。</p><p>同时，后世所有精灵也都是圣树“生”的。</p><p>而圣树，又是精灵神话中“先天精灵”手中的木棍所化。</p><p>所以，许多精灵都喜欢取下圣树母树的一根枝杈，当作手杖或法杖，再出森林闯南走北。</p><p>这和神州人背井离乡前，用布包走一把水井旁的土，是同样道理。</p><p>伊芙向两位人类招招手：“好了，眼界已经开过了，来吃饭呗。”</p>
