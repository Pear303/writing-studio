# 谁杀死了大帝？

<p>凡界，一处酒楼。</p><p>这栋酒楼招待来自五湖四海的客人，不论来自东南西北，天涯海角，只要怀揣着故事与酒，便能在此寻得一隅安身。</p><p>很难想象，如今这凡人王朝的版图，繁荣一统的人间盛世，五百多年前还是碎成四百零八个弹丸国的状态。</p><p>直到最后一次世界大战，那场惨烈的厮杀，像一场席卷大地的暴风烈火，将四百零八个弹丸国搅得天翻地覆。</p><p>战火烧尽了诸国间无谓的藩篱，也烧醒了众人对和平与统一的渴望。</p><p>与此同时，灵凡二界也迎来了归墟大帝。</p><p>大帝禁止灵界把凡界当作“沙盘”，禁止灵界恶意干涉凡间。</p><p>曾经，灵界利用凡界的各个势力、国度，大打“代理人战争”，以此进行灵界内部利益分配。</p><p>美其名曰“光荣战争”，号称没有任何一个灵界人在利益分配中流血。</p><p>只是打一回丈，死几十万几百万凡人罢了。</p><p>归墟大帝出世不久，便全面禁止了灵界对凡界的干涉。</p><p>甚至清洗了大量灵界高层。不管是灵界哪个势力的高层，只要是在凡界挑动过太多血与沙之事，都被视作战犯处决。</p><p>这个过程持续了几千年，期间仍然有零星灵界人偷渡凡界，干涉凡人内政。</p><p>最后，归墟大帝完全把控住灵凡二界的通道，绝地天通，终于遏制住偷渡现象。</p><p>凡界没有了灵界势力的挑拨。</p><p>压抑已久的和平愿望，终于有了实现的可能。</p><p>在一片废墟之上，各国代表齐聚一堂，尽管彼此眼中仍有戒备，但他们终于坐了下来，商讨和平统一的可能。</p><p>无数次激烈争吵、无数次利益博弈后，他们艰难地达成共识。</p><p>以某块中立之地为中心，各国逐步放下武器，共同组建起一个庞大的联盟。</p><p>他们推举出一位贤能之人，作为凡人王朝的君主。</p><p>从那以后，曾经四分五裂的土地，渐渐愈合伤口。</p><p>人们在废墟上重建家园，以双手收拾这片破碎的山河，重新拼凑成如今这繁荣一统的人间盛世。</p><p>民间有歌谣：东铸币，西量衡，南修渠，北屯兵，四百邦国炉里熔，铸成天下一口鼎。</p><p>现在，是槐安2185年。</p><p>这是最好的时代，也是最好的时代。</p><p>这是信心百倍的时期，也是信心百倍的时期。</p><p>这是阳光普照的季节，也是阳光普照的季节。</p><p>繁荣已持续不知多少万年，并且在灵界不断供养下，还会持续不知多少万年。</p><p>而在这生产力极度丰富的盛世。</p><p>餐饮行业，因其提供超过50%的凡界就业岗位，故以绝对经济地位姿态，占据着凡界经济运行的半壁江山。</p><p>街头巷尾的食肆酒楼从早到晚飘着烟火气，南来北往的食客捧着食盒茶杯穿梭其间。</p><p>在凡界，餐饮行业是绝对的霸主产业！</p><p>此时此刻。</p><p>人族、妖族、灵族五位大能齐聚一堂。</p><p>每个人的脸色都极为凝重。</p><p>数位大能各自在凡界都有工作，比如酒楼厨子，图书馆保安，道观扫地僧，客栈掌柜，经常在某某中学演武馆附近眯眼休息的老头。</p><p>比较庸俗的说法是“幕后大佬”，比较正式的说法则是“走访基层”，大隐隐于市。</p><p>凡界灵气极其稀薄，所以称为“凡”。</p><p>这个“凡”字还有更多含义，日后再说。</p><p>总之，寻常修士不允许来到此处。</p><p>只有一些大能，可以拿到特批。</p><p>但这样的大能少之又少，而且往往在灵界身负要职。</p><p>不时镇压这里，经常镇压那里，偶尔还得出差镇压哪里哪里，工作繁忙，不方便抽身下访。</p><p>最终，有时间尘游世外，游戏凡界的大能。</p><p>满打满算也就五个。</p><p>现在，五人都已齐聚这里，聚集在凡界的一座酒楼。</p><p>他们选择在凡界，有三大原因。</p><p>第一，天上一日地下十天。凡界与灵界的时间流速比是10:1，灵界才过去1弹指，凡界便过去了10弹指。</p><p>他们有了10倍的充裕时间来讨论研究。</p><p>代价则是，凡界灵气也只有灵界的1/100。但对抵达“真仙”境界的大能而言，这点代价没啥影响，他们体内自可以生生不息地涌现灵气。</p><p>第二，归墟大帝的死亡就发生在了凡界。要调查他的死因，来到案发现场是最好的选择。</p><p>第三，这里是其中一位大能“酒楼厨子·中山无极”的地盘。</p><p>五位大能围着酒楼一张四人桌而坐，周围的时刻都在喧嚣，但五人缄口不语，因为不知从何说起。</p><p>人族的中山无极率先打破沉默。</p><p>“中山无极”此名字实在过于冗长，而其他大能也都上了年纪，记性衰退，故他的同道都称中山无极为“酒楼厨子”。</p><p>他在凡界的职位，是个烧菜的。</p><p>当然，他的特长不局限烧菜。作为真仙境大能，他也擅长打架。</p><p>捞几颗黑洞和中子星下围棋，用棒状星系打桌球——都只是寻常舒筋活络的超级运动。</p><p>如果将归墟大帝平均掰成10份，那么，酒楼厨子的实力能够比拟其中1份！</p><p>换言之，他虽还称不上“半步大帝”，但已经可以尊为“0.1步大帝”了！如斯恐怖，恐怖如斯。</p><p>酒楼厨子·中山无极摸着艺术风格浓厚的络腮胡，目光扫视众人。</p><p>“归墟大帝之死，太过蹊跷。如今灵界无主，各方势力蠢蠢欲动。</p><p>“纸包不住火，灵界迟早陷入大乱。凡界也会被人偷偷动手脚，做些不利于团结的事。</p><p>“当此之时，火烧眉毛之事，还是要找出大帝突然暴毙仙逝的缘故。</p><p>“如果大帝是被人设计杀害，那么‘他’对付我们几个小卡拉米，绝对比对付大帝更简单。”</p><p>“所以，我们还不能轻举妄动，否则可能会成为下一个目标——虽然我们也尚未确定，大帝是否真的被人设计所杀害。”</p><p>毕竟，就算是在灵界，能够威胁到归墟大帝一根腿毛的人物，一巴掌都能数过来。</p><p>在凡界这个“蛮荒之地”，弑帝更是艰难。</p><p>更何况，长久居住凡界的五位“隐世大能”，在事发当天，也并没有在凡界感应到有任何超过警戒线的能量波动。</p><p>凭五位大能的感知力，即使是三千里之外有个小孩将二踢脚扔进化粪池，他们也能看得一清二楚。</p><p>那么，究竟是谁杀死了大帝？</p><p>酒楼内，空气仿佛凝固。</p><p>他们同时回忆起大帝是怎么死的。</p><p>当时，大帝在灵界请了假，去往凡间度假旅游。</p><p>他在凡界的出行路线与平常相似，坐火车，行走巷弄间，吃点地摊小吃，买几根淀粉肠，或者山水豆腐花。</p><p>凡界旅游三个月后，大帝最终来到凡界-十万大山-君士叹顶堡-郊区一处卖豆腐花的小摊，落座。</p><p>他发现此摊位热水免费，便要了杯免费白开水。</p><p>他喝下第一口，死了。</p><p>其实严格来说，归墟大帝是“失踪”，并没有人目睹他确实“死亡”。</p><p>然而，整个灵界凡界都再也找不到归墟大帝的踪迹。</p><p>同时，他留下的所有“魂灯”也已熄灭。</p><p>魂灯，与一个人的三魂七魄挂钩，宛若量子纠缠般相互联系。</p><p>魂灯尽数熄灭，证明大帝的魂魄完全消失于这片天地，无处可寻。</p><p>如此多铁证，都表明大帝已死。</p><p>结合他生前还悠哉悠哉在凡界喝白开水，所以五位土著大能的内部说法是——大帝喝水呛死了。</p><p>更准确来说，是大帝喝水的那一刻失踪，并极有可能已经死亡。</p><p>但是，谁拐走，并杀死了大帝？</p><p>许久，客栈掌柜·青丘白璃轻晃手中折扇，扇面上九尾狐图腾泛着若有若无的光晕：“诸位可曾想过，大帝之死或许并非外力强攻，而是源于自身？”</p><p>这种人看向那位妖族包租婆，青丘白璃。</p><p>因为“包租婆”一词有些粗俗，所以大伙儿都称她“客栈掌柜”。</p><p>她似乎对“谁杀死了大帝”，有猜测了。</p><p>她顿了顿，眼中闪过一丝思索，“或许，大帝不是被他杀，而是死于‘自己’。”</p><p>这也是个思考方向，一下子就为众人打开思路。</p>
