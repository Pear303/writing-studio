# 修路狂魔

<p>如果说，原来杨帝的灵能是「1」（阿列夫一），那么此刻至少飞越了两千多倍。</p><p>抵达「无穷」这一领域，再用“倍数”衡量，确实有些不恰当。</p><p>但当下，没有别的形容词能够描绘太一矩枢从杨帝身上感受到的变化。</p><p>公务车知道，杨帝偷偷摸摸有些小动作，但他究竟具体干了什么？</p><p>……</p><p>虚空无垠，银白色的机体如一道寂寥的流星，划过那比永恒更深的黑暗。</p><p>偶尔有圣人的神识掠过，带着毫不掩饰的抱怨与不耐：</p><p>“太一！你这路，何时能修得清净些？”</p><p>“今日挖开铺这管，明日掘断埋那线，轰轰隆隆，扰人清静！”</p><p>“莫非是借修路之名，行那中饱私囊之实？这修路资材怕不是如肥肉过手，油水沾身！”</p><p>太一矩枢的传感器微微闪烁，那中性的电子音在虚空中平静地荡开。</p><p>他看似并无委屈，实际上委屈如海，但只能陈述着庞杂的事实：</p><p>「我并非有意反复打扰。只是，一条连接两个宇宙的标准虚空通道，其内部包含的功能性管道种类繁多。」</p><p>「包括但不限于基础时空稳定架构管​，因果律信息流输送管，高维灵能传导矩阵管​，文明讯息波广播管​，历史可能性坍缩引流管，等等。」</p><p>「诸如此类管道，总计超过五亿种，这还只是基础配置。」</p><p>「若遇特殊需求的宇宙，还需额外增设文化模因污染过滤管、时间悖论消解溢流管等类型，管道种类甚至会在此基础上翻倍。」</p><p>「无论是对其中任何一条管道进行技术标准迭代、容量升级，还是故障维修，都必须接触到通道的本体结构。」</p><p>「我无法单独剥离某一管道而进行操作，好比行星级原始文明为修复一根深埋在城市地下的细小血管，不得不先把整条街道挖开。」</p><p>「每一次进行升级维护，都相当于要“把整条通道拆开”。」</p><p>他的解释淹没在虚空里，那头的圣人早已收回神念，或许只听得“五亿余种”便觉头痛，但仍固执地认为这冰冷的无限基兵，不过是借机摊派工程，劳民伤财罢了。</p><p>太一矩枢不再多言，继续操控着无数分身。</p><p>在那无垠的虚无中，沉默地挖开，修补，再挖开。</p><p>永恒推动着维持万千宇宙互联互通的巨石，周而复始，永无止境。</p><p>而太一矩枢的「本体」则与杨帝一同。</p><p>这是星环盟约交于他的一项秘密任务——监视杨帝。</p><p>这位刚从下层叙事飞升的阿列夫一级圣人，其精神评估得分相对偏低。</p><p>盟约总部的专家组至今未能破解关键问题：杨帝究竟依靠何种方法，实现了从下层叙事到本层的飞升。</p><p>尽管这听起来像是对数学的背离，但现实情况确实如此——在他们所处的虚空语境中，本层宇宙内部的现实被定义为有限常数，而下层叙事的现实则始终为零。</p><p>专家组通过深入研究进一步得出结论：若切换到杨帝原属的下层叙事视角，他所在的下层叙事应属于有限现实范畴。</p><p>与之相对，本层无垠虚空中的任意一个宇宙，其现实级别都达到阿列夫零阶的无穷状态。</p><p>换算关系有些混乱，但中心思想永远不变：</p><p>有点逆天。</p><p>这杨帝莫不是耶罗大仙的亲儿子，被它直接摁住天灵盖灌顶修为了？</p><p>虚空航行中，公务舱内一片寂静，只有设备低沉的嗡鸣。</p><p>太一矩枢突然打破沉默，语气状似随意：</p><p>「杨帝同志，据记录，你是从下层叙事域飞升而来？」</p><p>杨帝抬眼看了看银白色的机体：</p><p>“是又如何。”</p><p>太一矩枢传感器微光流转：</p><p>「不必紧张。仅是常规背景调研。星环盟约对各类晋升途径皆抱有学术性兴趣……尤其是像你这般，能从‘现实为零’的下层叙事，一步跨越至‘现实为阿列夫零’的本层虚空，此间转换机制，着实令人费解。」</p><p>杨帝冷笑一声：</p><p>“绕弯子不像你的风格。直说吧，到底想问什么？”</p><p>太一矩枢短暂沉默，似乎在权衡：</p><p>「……你似乎对耶罗抱有相当大的敌意，甚至提出过‘灭圣绝盗’的口号。但在当前形势下，任何针对耶罗分形区的实质性制裁提案，都是极不明智的。」</p><p>杨帝挑眉：</p><p>“哦？因为它是‘自然现象’，动不得？”</p><p>太一矩枢电子音压低，近乎耳语：</p><p>「远不止如此。耶罗分形区是目前已知唯一能在大魙败边缘保持结构稳定的宇宙群，其抗侵蚀特性是盟约最高优先级的研究对象。」</p><p>「此刻谁动耶罗，谁就是在动摇盟约应对大魙败的战略基石。」</p><p>它顿了顿，传感器光芒稳定却带着无声的警示。</p><p>「换言之，当下谁公开提议制裁耶罗，谁的仕途恐怕就会立刻画上句号。」</p><p>「这已非理念之争，而是最根本的生存逻辑问题。望你谨记。」</p><p>简单来说，现在大魙败的关键时期，谁提制裁耶罗分形区宇宙群，谁仕途生涯直接死。</p><p>杨帝思索了片刻。</p><p>“太一矩枢，对星环盟约而言，耶罗分形区究竟意味着什么？”</p><p>「一个特殊自治区域。」</p><p>太一矩枢的电子音毫无波澜。</p><p>「被默许存在的‘实验性宇宙群特区’。」</p><p>「它在一定程度上，被豁免完全遵守《星环盟约》的部分条款。以此换取耶罗大仙在此地相对自由的……研究权限。盟约则可观测其演化，汲取所需数据，尤其是应对大魙败的方案。」</p><p>杨帝立刻抓住核心：“这个‘盟约’，具体内容是什么？”</p><p>「《星环盟约》最核心、不可动摇的基石条款只有一条：强者，不得随意干涉弱者。」</p><p>「它规定了不同能级存在之间的互动边界，旨在维持虚空的基本秩序。这也是盟约存在的根本意义。」</p><p>「而耶罗分形区，是目前唯一被严格限定的例外。」</p><p>「耶罗虽然同样反对魔性的‘极端反世界分子’，但它也鼓励圣人涉世。」</p><p>「虽然不愿承认，但或许，这就是它长存的秘笈……」</p><p>「但其实我们也不必妄自菲薄，毕竟星环盟约目前的政策，也已被证实对大魙败有相当不错的抵抗效果。」</p><p>“所以，星环盟约现在行使什么政策？”</p><p>「在一定限度上制约圣人的同时，将各个‘高风险’宇宙实施重建改造。」</p><p>“高风险，又该如何定义？”</p><p>「在大魙败中，首当其冲被毁灭的聚类宇宙群。」</p><p>「物以类聚人以群分，一个宇宙群，拥有的『宇宙基底』是相似的。」</p><p>「比如在耶罗分形区宇宙群，宇宙的基底是一种‘金手指命运’……」</p><p>杨帝懵懵懂懂，迷迷瞪瞪，似乎懂了。</p>
