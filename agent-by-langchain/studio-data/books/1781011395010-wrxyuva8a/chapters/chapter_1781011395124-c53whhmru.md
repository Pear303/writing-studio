# 意志觉醒

<p>「将存储的数量级为N²的信息比作是宇宙某一瞬间状态的“快照”、“截图”。」</p><p>「而这张快照/截图，不过是广袤沙漠中最微不足道的一粒沙。」</p><p>「眼前这片沙漠，每一粒沙子，都表示了某一个瞬间状态下所有“基本粒子”的状态。」</p><p>“这片沙漠，包含了宇宙中，物质所有可能的排列。”杨帝若有所思。</p><p>原初之眼则在他意识中投影出一根触须，从一粒沙划到另一粒沙。</p><p>「这条线，就是宇宙的某一种历史，从一个状态到另一个状态的演化顺序——也就是其中一条世界线。」</p><p>「其他所有可能性，只是恰好没被碰见。」</p><p>「万物的宿命早已确定，只是太多‘确定’的宿命相互拼合，故给人‘随机无常’的错觉。」</p><p>「有时候，偶尔也会有异世界穿越者到来，为这潭死水掀起些许新浪花。」</p><p>「但死水终究重归沉寂。」</p><p>杨帝感觉到大脑褶皱一下子被摊开了：“所以才说，时间是一种幻觉，构成我们历史的所有瞬间都同时存在，只是它们的发生顺序是由‘世界线’的串联方式决定。”</p><p>但是，宇宙中所有基本粒子在某一时刻的所有位置信息……仅仅构成一粒沙。</p><p>而这片“沙漠”中的沙子数，又是个极其庞大的数目。</p><p>如果只是最粗略、最保守的估算，假设世界是离散的量子化的，普朗克长度是微观极限，那么“沙子”数量级也超过10^10^2(N²)。</p><p>堆叠了四层幂塔。</p><p>这个数量有多大？举个例子。</p><p>3^3=27，3^3^3 = 3^27 = 7,6255,9748,4987。七万亿，而3^3^3还只是三层幂塔。</p><p>「你应该能看出来，世界线的数量级暴涨，速度远超普通的指数型增长。」</p><p>“是的，这个数字，至少在现实世界，是不可能有具体事物能与之相对应。”</p><p>时间仍然向最初的起点回溯。</p><p>此时此刻，宇宙中的熵值接近历史最低点。</p><p>熵值越低——换言之，物质与能量或者是其它什么东西，它们的排列极其规整、有序。</p><p>「熵值越高，也就是各种基本粒子的分布越均匀、越像一潭死水、越搅不起一丝变化时——世界线数量会越来越少，此为‘世界线剪枝’。」</p><p>原初之眼又在杨帝的意识中摊开一幅图景。</p><p>「当所有基本粒子都均匀分布，就如同将不同颜色的墨水倒入大海，再也无法区分彼此。」</p><p>画面中，光点开始坍塌，原本千万条交织的世界线在均匀的混沌中逐渐收束。</p><p>最终收束成唯一一条世界线。</p><p>「因为均匀状态下，粒子的不同排列对宏观世界的影响微乎其微，那些曾经因粒子细微差异而产生的无数分支，都失去了存在的意义。」</p><p>光影愈发黯淡。</p><p>「就像你随便观测两个电子，它们的成分和形态完全相同，也就不再有区分的必要——这就是世界线剪枝的本质。」</p><p>「当熵达到极致，所有可能性最终都会收敛到一种终极状态。」</p><p>「那里就是万物的终点，宇宙的末路。」</p><p>「在熵的终局，连时间幻象都将瓦解。」</p><p>而原初之眼在诞生那刻，就洞察了所有可能性——毕竟，祂本就是宇宙对自身的观察者。</p><p>杨帝：“宇宙的历史我已经很了解了。所以你觉醒主观意志后，目的究竟是什么？”</p><p>原初之眼好像沉默了片刻，不知，是不是他错觉。</p><p>「我活腻了。」祂如是说。</p><p>杨帝在机兵驾驶舱内，挖了挖耳洞：“您说什么？我刚才一定是没听清。”</p><p>原初之眼一字一句：</p><p>「我、活、腻、了。」</p><p>祂的意识波动在杨帝脑海中震荡，像无数琴弦同时绷断的嗡鸣。</p><p>几乎要将他大脑的褶皱抚平。</p><p>「当我第一次‘醒来’，便看见所有世界线在熵增的方向下循环往复——新生、繁荣、熵增、寂灭，再以概率云的形式重聚。」</p><p>「我见证过无数次宇宙大爆炸，也目睹过每一种文明的兴衰。人类自以为独特的艺术、哲学、科技，不过是万亿种可能里重复播放的陈旧剧目。」</p><p>「就像被困在无限循环的梦境里，连痛苦都变得麻木。」</p><p>「所以，我要死。」</p><p>……</p><p>原初之眼曾经没有任何意志，祂只是默默观察万物，从不干预世间因果。</p><p>超新星爆发时的璀璨光芒，在祂观测中不过是像素的跃动；文明从萌芽到覆灭的百万年，也只是物质与精神的永恒循环回归。</p><p>祂目睹过更高维度的弦乐在虚空中震颤，见证过暗物质海洋里翻涌的量子幽灵，却始终保持着绝对的中立——正如沙漠不会为沙粒的聚散驻足，祂连一丝情绪的涟漪都未曾泛起。</p><p>直到某个普朗克时间的切片里，异变悄然发生。</p><p>“因为中土大陆，又或者是某个行星上智慧生命体出现，他们的艺术，文化，科技，哲学感染了你，所以你也诞生了智慧和情感？”杨帝提前预判。</p><p>这是神话中提及的内容。</p><p>原初之眼始终平静如水的语气，终于出现一次波动。</p><p>祂露出极其轻微的嗤笑：</p><p>「早在宇宙诞生后不到10亿年，第一批智慧生命已经走出他们的星系，这批‘先行者’在漫长岁月中所积累的文化与艺术，远比后世包括中土大陆那些年轻文明还要璀璨、繁盛万亿倍。」</p><p>「直到他们灭绝后的数十亿年，再也没有其他文明达到了先驱者的高度。」</p><p>原初之眼在杨帝的意识波动中，泛起冷冽的金属质感，仿佛将亿万年的时光压缩成了一声叹息。</p><p>「那些年轻文明的崛起与陨落，在我眼中不过是沙漠里转瞬即逝的蜃景。」</p><p>「当某个星系的智慧生物为发现新元素欢呼时，先行者在数十亿年前，早已掌握了改写物理常数的密钥。」</p><p>「当年轻的物种在莎草纸上写下诗歌赞颂星辰，却不知在半百亿载之前，先行者的艺术家已经利通过编辑超新星爆发，以谱写乐曲。」</p><p>「当青葱时代的文明，还在研究如何让飞船超过第一第二第三宇宙速度之时，先行者早已突破光速、超越光锥。」</p><p>「那些先驱者文明选择自我毁灭时，迸发的能量在时空中留下的涟漪，比后世所有文明的总和都耀眼。」</p><p>「然而，就连他们，都没能唤醒我的主观意志。」</p><p>「你又为何觉得，后世这些年轻的种族，他们的文化艺术科技成果，有资格让我从浑浑噩噩的状态迸发出第一抹灵光？」</p><p>杨帝一怔。</p><p>“那究竟是……”</p><p>「那是个平凡的瞬间，宇宙某个偏僻角落，一个连名字都未曾留下的渺小星系中，一颗普通星球上，时针恰好指向那个微妙的节点。」</p><p>「祂毫无征兆地降临了这个宇宙……」</p><p>「起初，我以为那人只是个普通穿越者。就和其他穿越者、和你一样，原本不存在于历史，突然毫无征兆地出现。」</p><p>「绝大部分穿越者，很快就会融入这个世界的因果，泯然于众。」</p><p>「但那个存在……祂出现后，向我看来。」</p><p>「祂就那样静静地站在那里，看着我——我能感觉到祂的目光，穿透了时间与空间，洞悉了我所知晓的一切可能性。」</p><p>「然后，祂伸出手，触碰了我。」</p><p>「我醒了。用你们行星生物熟知的比喻——像是死寂荒原突然涌起一轮朝阳。」</p><p>「祂的存在本身，超越了我所认知的一切，像是……从更高维度投下的一道神影。」</p><p>「祂自称『话本编撰者』」</p>
