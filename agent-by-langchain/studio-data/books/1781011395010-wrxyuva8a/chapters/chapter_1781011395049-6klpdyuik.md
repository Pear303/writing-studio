# 超体进化

<p>是的，为什么自己没有睁眼，就已经知道这里是音乐厅？</p><p>哦，靠的是触觉，嗅觉。</p><p>心脏很痛，但不重要，血已经止住了。</p><p>他攥住扭曲的瑞士军刀，从后背拔出来，没有流血，伤口以肉眼可见的速度愈合。</p><p>好饿，好累，还有……痛苦，空虚。</p><p>万般感觉，诸多念头，涌上心间，充斥精神。</p><p>因为目睹一尊古老而遥远的存在，杨帝如今的“精神”属性太高，潜意识开发程度达到10%。</p><p>潜意识每秒处理约1000万比特的信息，10%即100万比特/秒，相当于6.25万汉字的文章。</p><p>一秒内所感知到的外界，相当于一部中篇小说。</p><p>信息，资讯，数据，比特，脑袋爆炸，精神要爆炸了，爆炸了。</p><p>杨帝呆呆躺地，指尖触碰到瑞士军刀。</p><p>金属的灵，向他诉说铁矿在地球深处沉睡的记忆，刀身上的血迹，则浮现出胡彦卓临终前的恐惧涟漪。</p><p>他盯着天花板某个角落。</p><p>天花板的角度不对。光暗好像也不对。</p><p>貌似那里有个黑点，那个黑点在窃窃私语。</p><p>不止一个黑点，不止一个黑点在呢喃。</p><p>正面看过去时，它消失了，它们消失了，絮语也停止了。</p><p>然后，耳畔的窃窃私语又出现——在他余光之外的范围传来，从四面八方传来，从他视线的所有死角传来。</p><p>杨帝听不清内容，但可以听到它们切实存在。</p><p>“这也是……曾经大脑帮我过滤掉的东西。”</p><p>万物都在说话。万物有灵。</p><p>大脑、潜意识过滤屏蔽掉这些信息，是有意义的，它让人类免于疯狂，可以安静地向内，寻求自我的主体和理性。</p><p>他在地上躺下5小时35分钟，跪坐5小时59分钟，最后站立8小时35分，终于感觉到，自己勉强能接受这个世界。</p><p>藏在万事万物中的“灵”，并不是传统玄学概念上的灵魂，或者灵智、智慧、精神。</p><p>而是种不一定会思考、但能让物质和实体安全地存在于世上的……东西。</p><p>杨帝那感受到，如果抽走“灵”。</p><p>那么，这个物质实体，它就会混乱，暴走，像是失去了驾驶员控制的EVA机体。</p><p>具体表现出来，就是那些黑色拉面。</p><p>对了，黑色拉面，哈基面，狸花猫，麻雀，希夷，胡彦卓……</p><p>耶罗大仙吞噬了他的两个朋友。</p><p>——这个想法如同一把淬毒利刃，直直刺进他的心窝，把他刚刚穿出一个大洞的心脏，又扎出另一个空洞。</p><p>杨帝挣扎着爬起身，脚步踉跄，如同醉酒一般。</p><p>他死死盯着远方，仿佛耶罗大仙就站在那里。</p><p>明明才认识一周左右，但为何，心中如此不甘？</p><p>杨帝在那柄染血的瑞士军刀，又扎进自己的心脏，试图用剧痛转移注意，填上那个空洞。</p><p>但无济于事。</p><p>耶罗大仙……耶罗……黄衣……</p><p>晨光穿透穹顶的彩绘玻璃，在满地支离破碎的乐谱间游移。</p><p>他这才注意到，音乐厅居然是有玻璃穹顶的。</p><p>但就在数小时之前，圆形音乐厅的穹顶没有透下一丝光亮，尽是黑暗。</p><p>杨帝爬上音乐厅的二层，推门而出，此处也正好就是艺术楼4楼。</p><p>循着记忆向右走，他来到书法室。</p><p>书法室角落干干净净，没有用墨水涂抹的地面，也没有漩涡图案。</p><p>中央的长方桌上，最上面三层分别是《兰亭集序》《少司命》和《苦昼短》。</p><p>唯独没有了陈昭所写的楚辞。</p><p>杨帝凭着脑子里残存的印象，从包里掏出中性笔，将那首陈昭所写的楚辞，在宣纸上随便地写了下来：</p><p>“混沌辟兮星辰列，深邃域兮影重重。穹宇阔兮界难寻，响惊神兮心绪扰。”</p><p>混沌辟兮星辰列……他低吟着首句，眼前浮现出耶罗大仙所在的那片诡谲星空。</p><p>深邃域兮影重重……在他余光中呢喃的黑点，于脑海中具象成无数漂浮的灵。</p><p>它们构筑了现实世界的隐形框架，却又在人类感知之外低语。</p><p>穹宇阔兮界难寻，响惊神兮心绪扰……万事万物低语呢喃，宇宙之外仍有世界。</p><p>杨帝不知道陈昭写下这篇楚辞时的感想。</p><p>他或许在见证世界的神秘、宇宙的疯狂后，走上了一条不归路。</p><p>而自己呢？</p><p>目睹泡沫幻影般的世界真相，是否也会堕入癫狂的深渊？</p><p>“我的‘无限进化’能力，为我保持了人性。相比于心智脆弱的胡彦卓、希夷、陈昭，相比于身不由己被卷进漩涡中的普通人类，他们没得选，而我有得选。”</p><p>希夷因为吞食了杨帝的精神，获取了他大部分记忆，活出了第二次生命，所以死心塌地认他为老大。</p><p>而耶罗大仙给予了陈昭什么样的生命体验？</p><p>难以想象。</p><p>杨帝循着记忆找到4楼工具间，却发现此处根本没有向上的旋转楼梯。</p><p>没有，从来没有。清洁工具间仅仅只是清洁工具间。</p><p>时空就是从那时候开始扭曲的么。</p><p>杨帝不是很想走被桌椅板凳堵死的楼梯。</p><p>他翻出窗外，踏着排水管和墙外的凸起，爬上了5楼。</p><p>雕塑室在5楼，石膏雕塑仍然面朝西墙。</p><p>但那座没有五官的雕塑，已经不见了，貌似从未存在过。</p><p>当然，那些石膏雕像的基座里，也已经找不到2013届学生“陈昭”了。</p><p>陈昭的“灵”被吞食。于是，他的存在从这世上被抹去。</p><p>过去，现在，未来，无穷多条世界线中，都不会存在陈昭这个人。</p><p>——杨帝脑海中出现了这样的神秘学知识。</p><p>5楼可以直通天台，并没有桌椅阻挡。</p><p>杨帝走上那条黑不溜秋的楼梯，楼梯尽头，是刺眼的晨曦。</p><p>天终于亮了，最初探索艺术楼时，他还在担心天永远亮不过来。</p><p>他站在楼顶边缘，风掀起染血的衣角。</p><p>远方的晨雾中，灰色的水泥森林耸立大地。</p><p>10%潜意识解放，他的意识不再受限于颅骨，而是像气态巨行星般膨胀。</p><p>排水管的铁锈，天台边缘的青苔，远处晨雾中的摩天楼群，混凝土巨人的低频震动……</p><p>他的意识如同流动的汞，将所有矛盾的信息吞噬、重组，在混乱中构建出新的认知框架。</p><p>“我正在经历类似《超体》的进化。”</p><p>杨帝低下头，伸手抚过生满铁锈的栏杆，原本笔直的铁条——居然扭曲变形了起来。</p><p>他能够改变周围物质的“灵”。</p><p>“灵”是物质实体的本质。</p><p>一个人，一个物的“灵”，是他之所以为他、你之所以为你、我之所以为我，的本质。</p><p>可以说，当他发现“灵”的存在，他也就具备了“现实扭曲”的能力。</p><p>电影《超体》的内容和他现在情况相似，但略有偏差，导演和编剧似乎没有“潜意识解放”的经历。</p><p>最重要的不是什么“大脑开发度”。真正关键的是，人对潜意识的掌控。</p><p>潜意识，是指人类心理活动中未被觉察的部分，相当于一台电脑底层滚动着的万千行代码。</p><p>它不会表露于台面上，但掌控着人的思想和行为。</p><p>就好像支持一个帝国运转，不能只有皇帝，还有皇帝背后百千万个幕僚、文官组成的系统。</p><p>普通人，相当于一个幼年傀儡小皇帝，被摄政大臣、宦官内阁左右着意志。</p><p>潜意识掌控1-2%，相当于洪武帝朱元璋，已经能摆脱已经能摆脱摄政系统的桎梏，亲自执刀改革官僚体系。</p><p>而杨帝此刻的10%，则如同大洋国“老大哥”站在权力巅峰，驾驭百官，重塑律法根基——他的意志已能直接干涉现实的底层逻辑。</p><p>掌控身体和意志，驾驭物质与精神。</p><p>这才是现实的超体进化。</p><p>杨帝已走在进化路上。</p><p>手握帷幕的一角，虽然现在……还小得可怜。</p>
