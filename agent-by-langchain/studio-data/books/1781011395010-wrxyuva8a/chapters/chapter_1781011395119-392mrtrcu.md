# 机兵屹立于大地

<p>杨帝讲述了万物的观测者，原初之眼。</p><p>在世界的褶皱里，原初之眼自熵寂中苏醒。祂以星河为瞳，将万物纳入观测，却在无尽之凝视中，滋生出超越维度的渴念。</p><p>原目睁开了祂的永恒，于是，观测这一行为本身，成为神灵最残酷的暴政。世人驾驭机兵，对抗堕落的原目。</p><p>寂静如潮水般漫入地下洞穴，连精灵们轻微的呼吸声都变得清晰可闻。</p><p>杨帝讲完他在瑞弗维尔笔记本中所看到的内容。</p><p>然后，外界的爆炸声停止了。</p><p>一时间，地下溶洞里安静得只能听见众人微微的喘息，与偶尔滴落的水珠声。</p><p>年长的精灵率先打破沉默，他声音沙哑，像是被砂纸磨过一般：“结束了……么？”</p><p>话音落下，溶洞内便又陷入一段时间的沉寂无言，可能是5分钟，10分钟，半小时，杨帝站起身，向溶洞上方的出口走去。</p><p>没有人说话，只是默默跟在他身后向前走。</p><p>碎石簌簌落在肩头，混着洞顶垂下的水珠，在脖颈处凝成滚烫的痕迹。</p><p>气温越来越高，他们逐渐接近地面。</p><p>溶洞出口的石板被杨帝拍飞，硫磺气息裹挟着滚烫的灰烬扑面而来。</p><p>众人眯起眼睛，在刺眼的强光中艰难地迈出第一步。</p><p>日光惨白，像是被抽去了所有温度，冷冷地洒在这片疮痍满目、灼热逼人的大地上。</p><p>阳光像钢针般扎进瞳孔，精灵抬手遮挡。</p><p>单从指缝间漏出的画面，就让一众精灵不由自主让喉咙发紧——原本葱郁的精灵森林，化作一片灰黑色的千里焦土。</p><p>到处都是光秃秃的灰黑色大地，不少地方流淌着岩浆，升腾青烟。</p><p>焦土在脚下发出脆响，如同踩碎千万片枯骨。</p><p>熔岩流淌过，痕迹如同狰狞的伤口，蜿蜒延伸至地平线尽头。</p><p>空气中飘浮尚且炽热的尘灰，将地平线远端染成诡异的暗橘色。</p><p>“这是……我们的家园？”身后传来精灵颤抖的声音。</p><p>“这……这都成什么样了……”</p><p>“圣树啊……我们的庇护所……”</p><p>几个年轻精灵扒着洞口张望，指尖死死抠住岩石。其中一人用手紧紧捂住嘴，或踉跄地捂嘴干呕，努力不哭出声。</p><p>曾缀满藤蔓的丘陵如今寸草不生。</p><p>被凝固的岩浆包裹着的树木残骸，扭曲成诡异形状。</p><p>熔岩史莱姆的残骸遍地都是，堆积成山，流淌成川，漫溢着令人作呕的气味。</p><p>那些截击机和哨戒炮，大多已损毁得不成样子，扭曲的金属部件散落一地。</p><p>空气中弥漫着浓重的硫磺和硝烟。</p><p>远处隐约可见圣树所在的位置，那里本该直插云霄的树冠已经消失，只剩下半截焦黑树干，表面还在冒着缕缕青烟。</p><p>圣树，不只是它的枝干，包括它的根须，已在昏天暗地的爆炸中摧残殆尽，焚作焦灰。</p><p>如果圣树当下死了，它就不再存在。</p><p>未来就不会有圣树将杨帝、伊芙传送回来。</p><p>而没有时间穿越，原初之眼就不会跟踪他们来到这个时代，圣树也便不会死亡。</p><p>但这不合因果的一切，仍然发生了。</p><p>幸存的精灵悲切地走向圣树残骸，而杨帝的目光，则被地平线远端一座银色轮廓攫住。</p><p>机兵屹立于大地之上。</p><p>伊芙驾驶的无限机兵，胸口的翠绿色核心早已黯淡无光，却依然保持着战斗的姿态。</p><p>它单膝跪地，链锯光刃深深插进地面，仿佛要将这片焦土钉在原地。</p><p>机兵不动，它已成为凝固的挽歌。</p><p>伊芙怎么样了？</p><p>银白色的机兵在焦土上泛着冷冽的光，明明刚经历了惨烈战斗，棱角分明的金属躯体上却看不到一丝裂纹、灼痕。</p><p>它大致成直立人的形状，但有百米高。</p><p>它双眸处的幽蓝光芒剧烈震颤，由强转弱，随即连带胸前的翠绿色核心，彻底熄灭。</p><p>伊芙出现了。</p><p>精灵站在机兵的阴影中，右手执法杖杵在地面。</p><p>她的金色长发垂落在褪色青绿披风上，随着呼啸而过的热风，轻轻颤动。</p><p>她指尖深深掐进法杖的纹路里，连指节都泛起青白，却依然死死攥着，似是她与这个世界最后的联结。</p><p>无限机兵在她身后投下巨大的阴影，将她整个人笼罩其中，宛如雕像。</p><p>杨帝跳入岩浆河，向伊芙游去，一边高声呼唤：“伊芙……！”</p><p>她却好似没有听见，依旧呆呆地望着前方，眼神中满是空洞。</p><p>仿佛，灵魂已被眼前这片荒芜填满。</p><p>杨帝游过岩浆河，到了精灵面前。</p><p>他衣服已被烧干净，便用物质重构法术给自己换上新衣。</p><p>手心释放出一枚实体光球，照亮伊芙早已收缩成针尖大小的瞳孔。</p><p>此举像是刺破了某种无形的屏障。</p><p>伊芙睫毛微微颤动，终于，一滴滚烫的泪水顺着脸颊滑落，在焦土上砸出微小的坑洞。</p><p>她嘴唇翕动几下，终于发出声音：“杨帝……我还有一件事，嘱托给你。”</p><p>“你说，你说。”</p><p>“我同意瑞弗维尔写我的‘野传’了……你告诉他我答应了。”</p><p>杨帝呼吸有些许急促：“我会的。”</p><p>伊芙紧绷的肩膀松弛下来，像是被剪断提线的木偶。</p><p>她握着法杖的手无力地垂落，杖尖在焦土上划出蜿蜒的痕迹。</p><p>“扶我去圣树那。”</p><p>杨帝想到只剩半截焦黑树干的圣树，但他也知道精灵不可能不知道到圣树的情况，只得面露难色：“圣树已经……”</p><p>“我知道，旧的母亲已逝。”</p><p>伊芙杵着法杖，朝一众原始精灵所在的方向走去，“但历史终究要形成闭环，这是我驾驶机兵后学习到的新知识……给我记好了，杨帝，要对万物保持谦逊，因为世界几乎是无限的，我们的认知却非常有限……”</p><p>杨帝搀扶伊芙，一路施法冷却岩浆河，二人来到圣树残骸前。</p><p>精灵围在道路两侧，默默注视迎接机兵驾驶员的到来。</p><p>难以想象，昔日叱咤天下，驾驭十环灵能法术的超限精灵法师，操控百米机兵与史莱姆海啸对抗的伊芙，此刻竟虚弱得需要依靠杨帝搀扶，弱不禁风，摇摇欲坠。</p><p>伊芙将法杖插到枯死的圣树面前。</p><p>原本暗沉的木质纹理，流转起翡翠色光纹，宛如血液在血管中奔涌。</p><p>杨帝瞳孔一缩。</p><p>他想起来了……这柄法杖，是圣树的枝杈。</p><p>它是圣树的一部分。</p><p>伊芙虚弱地抬起手，轻轻一挥，放弃了对法杖的“主体性宣称”，它不再是伊芙的一部分，而是脱离伊芙而存在的“外在之物”了。</p><p>法杖矗地，显露出40米高的圣树枝杈本体。</p><p>“轰！！！”</p><p>整片焦土泛起涟漪，法杖，或者说圣树枝杈顶端迸发光芒，化作光柱，直冲云霄。</p><p>被灰烬遮蔽的天空，裂开蛛网状的缝隙。</p><p>“圣树……”</p><p>“圣树复活了……！”</p><p>伊芙抚摸圣树的粗粝木质树皮，低声轻语：“母亲，我已知晓无限机兵的本体，我会将操控它的一部分权限给予您……您需要不断积攒足够的灵能，在历史与命运的抉择点到来之时，激活它的时间跳跃功能……”</p><p>周围的原始精灵围上来。</p><p>他们眸中闪烁着困惑，惊奇，兴奋。</p><p>“陌生的精灵尊者，请问您是圣树指引而来的？”</p><p>伊芙扭头，看向人群中发问的年轻精灵。</p><p>“我……”</p><p>下一刻，伊芙·柑橘忘记了自己的名字。</p><p>她目光空洞，盯着自己的脚尖，久久说不完这一句话。</p><p>“她是世上第一个精灵。”杨帝将伊芙掩到身后，对众精灵说。</p>
