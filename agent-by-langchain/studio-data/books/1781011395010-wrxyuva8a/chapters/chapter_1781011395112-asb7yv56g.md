# 史莱姆

<p>瑞弗维尔仰面躺在焦土上，断肢处缠着杨帝匆忙撕下的亚麻布，暗红血渍仍在不停渗染，将布料浸得如同一块沉重的铅。</p><p>他唇色泛着青白，睫毛在风里微微颤动，霜白发根此刻爬满半张脸。</p><p>胸口起伏微弱得近乎不可见，唯有脖颈处的血管还在偶尔抽搐，如同濒死的蝶翼徒劳挣扎。</p><p>瑞弗维尔发出断断续续的呓语。</p><p>但他终究是顽强活了下来，毕竟是戴有三枚力量之戒的男人。</p><p>伊芙躺在奥拓身边，双眸紧闭，眉峰仍保持着战斗时的扭曲，偶尔传出幼兽呜咽般的抽气声。</p><p>她裸露的小臂上凝结着冰晶与焦痕。</p><p>随着呼吸而轻颤的指尖，还残留着九环法术释放时的过载痉挛。</p><p>“杨帝……到底怎么会变成这样……”</p><p>全场最懵逼的人是矮人奥拓。</p><p>对他来说，自己就是去铁熔堡解了个诅咒，回来的时候和这帮人搭上线，帮他们干了些活。</p><p>然后莫名其妙被人类的圣光教廷追杀。</p><p>莫名其妙碰见屠龙英雄。</p><p>精灵莫名其妙造反。</p><p>而杨帝，莫名其妙吞下“发卡”，没死。</p><p>“事情经过其实是这样的……”杨帝快速将最重要的信息提取出来，告诉奥拓。</p><p>“所以……你们惹上人类教廷了？！”</p><p>“奥拓，把你拖下水，有点抱歉啊。”</p><p>“无妨……债多不压身，反正我也在被矮人的铁熔堡官方通缉。”</p><p>杨帝看向干草堆上的伊芙。</p><p>“她情况怎么样？”</p><p>奥拓一摊手：“只是昏迷过去了。我不会施展灵能法术，如果可以，你来稳定她伤势？”</p><p>精灵看起来没有外伤，所以他的治疗法术也无从下手。</p><p>万幸，此时伊芙睫毛剧烈颤动两下，猛然睁开眼。</p><p>杨帝有气无力：“伊芙，你醒了……”</p><p>精灵只是默默点头，然后踉跄着扑到瑞弗维尔身边，掌心腾起翡翠色的治疗光晕，细碎的光粒渗入他伤口时发出滋滋轻响。</p><p>断肢处渗血，以肉眼可见的速度减缓。</p><p>原本凝滞的血管重新泛起鲜活的跳动。</p><p>“暂时吊住命了。重新长出手也不是难事，只需三四个法术疗程。唯一麻烦，也就是整个右臂都被烧毁了神经，需要慢慢帮他重连。”她沙哑地喘息，指尖在法杖顶端重重一按。</p><p>原本普通长度的法杖发出龙吟，缠绕其上的符文亮起炽烈金光。</p><p>风王结界，撤除。</p><p>法杖展露出40米长的圣树枝杈本体。</p><p>同时，她袍袖一抖，原地放置出那辆轿厢。</p><p>伊芙越过奥拓，对杨帝说道：“我要尝试联系圣树，你带着我们，迅速往东北方向赶去。”</p><p>杨帝：“圣树联系不上？”</p><p>“联系不上……我不知从何时开始断联的，但可以肯定的是，十天来我和圣树的通话，都被熔岩史莱姆劫取、篡改过。这几天，我都是在和假的‘圣树’对话。”</p><p>她多想自己的金色长发，橘红色发卡没了。</p><p>幼年时期，熔岩史莱姆送给她的发卡。</p><p>“我不知道原初之眼为这一天谋划了多少个纪元，但可以肯定……我们时间不多了，祂已做好万全准备，与我们彻底撕破脸。”</p><p>杨帝感觉真相愈发扑朔迷离：“原初之眼？祂和史莱姆是什么关系……”</p><p>“上车再说，我会把知道的都告诉你们。如果我再次被控制住，你们一定要把真相传播到大陆每个角落。”</p><p>……</p><p>伊芙、奥拓，以及昏迷的瑞弗维尔，三人坐在轿厢内。</p><p>而灵能尚未枯竭的杨帝坐在车顶，控制轿厢向东北方以120公里时速奔袭。</p><p>伊芙灵能消耗过大，现在只能坐在轿厢内，一边恢复MP一边分析情况。</p><p>“杨帝，你记不记得我们在被教廷包围前，你所说的最后一句话？”</p><p>杨帝传音：“是的……那句话是——”</p><p>「那如果把史莱姆堆多一点呢？量变引起质变。」</p><p>伊芙：“这就是真相。”</p><p>地球人缓缓：啊？</p><p>“伊芙，我当时只是提出一个理论可能性。但史莱姆终究是最低等的魔物，要如何堆叠数量，才可能让它们诞生智慧？”</p><p>杨帝继续质疑，“更何况，将大脑串联在一起，这真的能做到吗？”</p><p>在末日火山，那几十个教廷修士、包括第一席红衣主教，他们如何在一起后，智力反而下降到七八岁小孩的水准。</p><p>这是因为原本精密的大脑受到器质性损伤。</p><p>发挥出了10+10＜1的卓越效果。</p><p>但伊芙指出：“如果是像人类，精灵，矮人这样的高等智慧物种，大脑结构复杂，人格，记忆，性格这些也相当复杂，自然是很难连接在一块……但史莱姆是最低等、构造最简单、自然生成的魔物，它们天生没有复杂的神经结构。”</p><p>如果说人的大脑是精密的“机械表”。</p><p>那么史莱姆就是最简单的“积木”。</p><p>将两块机械表的零件强行融合在一起，难度远超将一百块积木搭在一块。</p><p>“伊芙，所以你是想说，‘原初之眼’用大量史莱姆融合一体，制造出能够承载祂的容器？”</p><p>伊芙疲惫地点点头：“没错。”</p><p>“但是……你也对我们讲解过史莱姆，它们只有最基本的条件反射，甚至称不上是动物原始本能，而仅仅是‘腔肠动物’那个级别的条件反射。”</p><p>将一百块，乃至一千、一万块积木搭起来，也难以实现“机械手表”的功能。</p><p>除非……</p><p>杨帝瞳孔一缩。他似乎明白了……</p><p>自己是地球人，本应该比异世界人更快反应过来这一点才对。</p><p>奥拓急了：“你们不要谜语啦！所以现在最大问题是，原初之眼想要通过史莱姆降临现实，但史莱姆堆得再多，也只是个蠢货。而原初之眼不可能夺舍蠢货对吧？”</p><p>正是如此。</p><p>但在地球神州，有一句谚语——三个臭皮匠顶个诸葛亮。</p><p>然后，伊芙代替杨帝说出了关于原初之眼、熔岩史莱姆的最终真相。</p><p>毕竟杨帝还要维持“失忆”人设。</p><p>……</p><p>伊芙·柑橘作为“学术大手子”，专注于研究史莱姆的社会形式。</p><p>在一般情况下，最低等的魔物——史莱姆，都表现出浑浑噩噩的习性。</p><p>这些软趴趴的生物，既不会躲避突然坠下的冰雹，也不会追逐掠过水面的蜻蜓。</p><p>即便被荆棘刺穿，也只是缓慢变形，将尖刺裹进身体后，继续漫无目的地流动旅行。</p><p>偶尔有冒险者的箭矢穿透某只史莱姆，它也没有哀嚎，没有愤怒，连挣扎都不存在。</p><p>因为它们甚至感觉不到痛。</p><p>“疼痛”是一种生物进化出来的反射机制，而史莱姆没有这种机制，表明它们甚至无需通过“疼痛”，来警示自身远离危险。</p><p>它们的结构实在太过原始，根本不需要如此复杂的警示系统。</p><p>它们没有骨骼，没有脏器，没有可以称之为“肌肉”的组织，也没有类似“神经”的系统。</p><p>仅仅是一团由黏液构成的、近乎于流质的存在。</p><p>如此简单的物质构成，本不应该诞生出高等智力。</p><p>然而，它们有社会形态。</p><p>当大量的史莱姆聚集在一起，它们会表现出“真社会性”。</p><p>而这，也是伊芙研究已久的课题。</p>
