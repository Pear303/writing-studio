# 世人常言，无限虚空无限广阔，无限空旷，无限虚无，万物皆不存在，存在者不存在，不存在者亦不存在。世人追寻的真理，众生避让的谬误，万物恐惧的裂痕，在此都毫无意义。

<p>但奇怪的是，万物皆无意义的无限虚空之中却有一个概念横亘于万物与虚无之上——那就是极致的武力。</p><p>只要武力足够庞大，数值足够破天，强度足够恐怖，就能够重塑虚空的一方地形，重塑某个宇宙群的基础底色。</p><p>就好像，虚空似乎在无声地咆哮，将这条冰冷的铁律刻入每一个能感知它的存在心底：</p><p>「不论面对何事何物。」</p><p>「战斗力，即是唯一的真理。」</p><p>「但这个战力分级太多太繁杂了，精简一下吧。」</p><p>「太乙真仙就该到头了。」</p><p>杨帝转头，看向太一矩枢，像在写申论：</p><p>“幽荧界宇宙在生物组织离体活性维持技术上，拥有令人惊叹的低成本解决方案。尽管其产生方式略显‘非常规’，但我认为，技术本身极具推广价值。</p><p>“我认为，完全可以将其包装成一项特色医疗技术出口专案，换取其他宇宙群的稀有资源、资金。</p><p>“乃至雇佣兵性质的武力支援，这是一种产业优势分工合作方案。”</p><p>太一矩枢的感测器闪烁了几下，似乎在快速进行效益分析。</p><p>片刻后，它那中性的电子音响起：</p><p>「分析报告：该提案符合《盟约资源置换条例》第■章第■款，具有较高的可行性性与潜在收益。分析得很好，杨考察员。」</p><p>杨，是杨帝的姓氏。</p><p>考察员，则是他的职责。</p><p>出门在外要称植物，植物前面可以加姓氏。</p><p>「依据现行条例与许可权划分，您当前职务，即为本区域之特派考察员，负责基层宇宙之调研与汇报。」</p><p>无论曾经如何，此刻的杨帝，就只是这位奔波于各个“城乡结合部”宇宙的杨考察员。</p><p>太一矩枢的机械臂在空中划出一道蓝色光痕，投射出一份全息产业图谱，无数光点在幽荧界宇宙的座标上闪烁。</p><p>光痕骤缩，化作两条交错的链路。</p><p>一条连线著幽荧界的闹鬼工厂，另一条则通向虚空深处无数医院。</p><p>「各区域互补的关键，是建立‘战力-资源’回圈。此界可以向其他宇宙出口医疗服务，换取他们的战力背书，让他们成为幽荧界的‘移动防御体系’，防备可能爆发的魙败灾难。」</p><p>「同时，以此为样板，吸引更多宇宙加入资源置换网路，形成以幽荧界宇宙为核心的产业联盟……」</p><p>无限虚空中从来没有出现过圣人，过去不曾存在，未来也不将存在。</p><p>杨帝从幽荧界宇宙回来，那份考察报告按流程递了上去。</p><p>司里很快开了处务会。处长先点了头，说他眼睛亮，能抓住地方的闪光点。</p><p>话锋一转又指了问题：“有些话太冲，得磨磨。‘资源置换’这思路不错，但‘雇佣兵’这词不够规范，改成‘跨宇宙安保协作’或者‘战略性防御外包’，听起来更书面。”</p><p>报告打了回来，核心要求就两条：多提“盟约指导下的区域性合作创新”，少提技术来源。</p><p>杨帝改完再交，报告便顺着流程往各部门传，等着会签。</p><p>神圣星环盟约科技司的回复先到，总结起来就一件事——技术标准化可以支持，但得先论证立项，明年预算草案里再议。</p><p>资源司跟着表态：“方向没问题，置换细则得联合外事、安保部门另写。”</p><p>安保部的意见更细，提出防御外包先查承接方资质，必须靠谱。除此之外，没有其他部门卡他的提案了。</p><p>太一矩枢也在会签单上盖了章，备注就四个字：“通行无碍。”</p><p>报告在各司局间转着，等着下次跨部门协调会。按道理来说，作为城乡结合部宇宙的特派考察员，杨帝的任务到这步已算完成，剩下的便是等流程跑完，看方案落地时再补份跟进调研。</p><p>但他没回自己的临时驻点，反倒调了艘小型穿梭舰，直奔盟约安保部的资质审查科。</p><p>科里的值班专员见是他，翻了翻记录便挑眉：“杨考察员，承接方资质核查刚启动，最快也得下周出初步名单。是要查阅什么？”</p><p>“嗯，打算提前了解一下情况。”</p><p>杨帝指尖在终端上划了划，调出几份企业资料，控股栏都标着“耶罗集团”。</p><p>值班专员扫了眼：“耶罗？他们旗下的安保公司昨天才提交承接申请，资质材料看着没毛病啊。”</p><p>“材料确实是没毛病。”</p><p>杨帝收起终端，转身往门外走。他已经记住了那几家耶罗控股超过50%的安保公司。</p><p>第一家叫“暗星防务”，藏在神圣星环外围的废弃空间站里。</p><p>杨帝推门进去时，前台正对着发财树浇水，见他没预约就闯进来，刚要拦，就被他亮出的考察员证件怼得闭了嘴。</p><p>办公室里，负责人是个留着络腮胡的壮汉，见他来，堆着笑递烟：“杨考察员，是资质审查有问题？我们可是按规矩交的材料……”</p><p>杨帝面色平静地收起证件，踱步走进“暗星防务”的办公区。</p><p>目光看似随意地扫过工位隔断，瞥一眼，走廊尽头，最终在那盆枝叶茂盛、寓意吉祥的发财树上停留片刻。</p><p>他微微颔首，仿佛只是赞赏其长势。</p><p>“材料是齐全了。”杨帝语气平淡，“但实地运营环境也是评估一环。看看就好，你们忙。”</p><p>络腮胡负责人稍稍松了口气，陪着笑亦步亦趋。</p><p>接下来一整天，杨帝以同样“突击检查”的名义，接连走访了另外几家耶罗控股的安保公司——“虚空盾”、“界域巡防”、“终末保障”、“xxxx”什么的。</p><p>流程几乎一模一样：亮证、进门、婉拒接待、在办公区内“随意”走动，目光总会“不经意”地在那几盆摆在特定方位、或是造型奇特的发财树或其替代品，如在鸿运竹、金钱榕上略有停留。</p><p>他甚至在终端上记录着“消防通道畅通”、“员工精神面貌”等无关紧要的细节。</p><p>下午16点50分，赶在盟约各部门下班前，杨帝返回资质审查科，提交了一份补充观察报告。</p><p>报告内容看似琐碎，罗列了几家公司的“办公环境观察项”，其中不起眼地标注了各公司前台、CEO办公室、财务室门口或西南方位特定观赏植物的种类与摆放精确坐标。</p><p>并附注：“此类绿植摆放，或涉及未经申报的微小空间坐标标记行为，建议纳入潜在风险观察项。”</p><p>这份报告被例行公事地录入系统。</p><p>然而，几乎就在报告录入的瞬间，某些高度依赖算法与隐秘信息流的资本市场立刻捕捉到了这一细微变动。</p><p>“耶罗系”、“安保公司”、“发财树”、“潜在风险”。</p><p>这些关键词在无形的信息网络中飞速碰撞、急剧发酵，悄然催生着一场资本风暴。</p><p>17点24分，虚拟交易市场的平静被骤然打破——“暗星防务”“虚空盾”等关联公司的股价毫无征兆地断崖式暴跌，交易量在瞬间飙升至峰值，随即又因抛盘汹涌、买盘枯竭而陷入短暂冻结。</p><p>没有任何明确的利空消息释出，但所有嗅觉敏锐的资本早已捕捉到危险信号，如同受惊的蚁群般疯狂逃离所有带有“耶罗”标签的资产。</p><p>17点56分，这场恐慌性抛售演变为全面崩塌。</p><p>所有标有“耶罗”标签的股票集体崩盘，股价彻底失去支撑，在混乱的交易洪流中一泻千里。</p><p>18点01分，神圣星环盟约股市紧急宣布技术性调整，但这也无法挽救耶罗股份的颓势。</p><p>再庞大的阴谋、再精妙的布局，其运转终究需要资源的支撑。而资本市场的信心，往往比堡垒更易崩塌。</p><p>有时候，摧毁一个虚空巨头的第一步，只是记住它旗下所有公司里，每一盆发财树的位置。</p><p>经济基础决定上层建筑。大生意本身，本质上就是各种力量的博弈。</p><p>当晚，杨帝完成了他的目标，他也在第二日10点15分，见到了耶罗。</p><p>地点是神圣星环盟约总部，通天之塔的顶端天台。</p><p>虚空的风在这里也变得稀薄而格式化，只余下维持环境参数所必须的基础物质流。</p><p>脚下是延绵无尽的建筑群与光流，象征着盟约所维系的无垠秩序。</p><p>10点15分，耶罗依旧穿着那身标志性的黑色兜帽大袍，狐尾在身后悠然摆动，仿佛昨夜其商业版图遭遇的资本风暴与他毫无干系。</p><p>10点16分，他看着走上天台的杨帝，脸上挂着那副永远看不透，皮笑肉不笑、若绷似绷的表情。</p><p>“力量和道义，你无法同时拥有，杨帝。当你选择踏入这规则编织的罗网，用一纸报告、几条备注来敲打我的那一刻起，你就已经做出了选择。你选择了在框架内行事，选择了秩序的道义，而非……纯粹的暴力。”</p><p>他微微张开手臂，仿佛在拥抱整个神圣星环盟约的庞大体系。</p><p>这就是耶罗大仙的计策。</p><p>杨帝很能打，是的，到了这最后一卷，白杨大帝的数值，或许已在单纯的破坏力上凌驾于万业狐狸。</p><p>但那又如何？他无法再用它来简单地解决狐狸。</p><p>因为万业狐狸把杨帝拖进的，或者说，杨帝被耶罗大仙拖入的，是这个“官场”，是这套运行了无数纪元的规则体系。</p><p>在这里，力量的表现形式不再是拳头的大小，而是规则的解释权、流程的掌控力、资源的流向。</p><p>耶罗的眼中闪烁着狡黠的光芒，如同一个布下完美陷阱的猎人。</p><p>“星环盟约的存在本身，即是合法性的终极体现。破坏它，你就是秩序的毁灭者，是虚空的公敌。</p><p>“你所珍视、所要维护的一切，都会因你的暴力而失去法理基础。</p><p>你动用的力量越强，你失去的道义就越多，最终……你只能成为魔君。而魔君，是会被群起而攻之的。”</p><p>他微笑着，得出结论：“所以，现在的你动不了我。至少，不能用你最擅长的方式，你也只能靠‘破坏发财树’这种小伎俩，来攻击我了。”</p><p>杨帝走到天台边缘，与耶罗并肩而立，俯瞰着下方浩瀚的秩序疆域。</p><p>他的表情平静无波。事实上，耶罗的话语早已在他预料之中。</p><p>“没错，你很聪明，耶罗。你精准地抓住了现阶段的主要矛盾。</p><p>“利用规则的惯性，将我可能的暴力反应约束在秩序之内。</p><p>“在这个层面，你的确暂时立于不败之地，因为你虽然不掌握我所掌握的力量，但你拥有我所不掌握的合法性。”</p><p>耶罗的嘴角弧度更上扬了几分。</p><p>杨帝认怂了。他承认自己输了。全书完。</p><p>全书完！！！！！！！！</p><p>然而，杨帝的话锋没完。</p><p>“但是，耶罗，你犯了一个错误。”杨帝缓缓转过头，他的眼眸深处，仿佛有无数底层规则在生灭流转，那是“缘起识”全力运转的征兆，“你误以为，我理解了规则，选择遵守规则，就仅仅只是为了……‘遵守规则’。”</p><p>耶罗的笑容微微一僵。</p><p>“你误以为，我看到的‘规则’，和你看到的，是同一个东西。”</p><p>杨帝的话语让周围格式化的虚空风都出现了细微的涟漪。</p><p>他抬起手，指尖仿佛有无形的丝线蔓延而出，连接着下方整个盟约总部的无数信息流、审批流程、资本信号、乃至更基础的物理法则。</p><p>“你看到的规则，是藩篱，是迷宫，是需要利用或规避的对象。</p><p>“而我看到的，是结构，是脉络，是‘缘起’本身。第九识，‘缘起识’，让我看到的从来不是规则的‘条文’，而是它之所以成为规则的‘原因’。</p><p>“是支撑它存在的全部因果，诸因之因，超越形而上学的终极本质。”</p><p>他的目光重新锁定耶罗。那目光让耶罗感到一种前所未有的穿透感，仿佛自己的一切算计都被放在了一个更宏大更根本的尺度上被审视，顿时有些许不寒而栗。</p><p>“动你用暴力，确实是最低效、最不划算，也最无趣的方式。”</p><p>杨帝的语气甚至带上了一丝怜悯，“你的计策之所以能成立，依赖于当前这套规则体系的有效运转。不过你也得明白，用魔法对抗魔法这招，我不可能不去学。”</p><p>耶罗浑身颤栗：“你是说，已经学会了用魔法对抗魔法，用编撰对付我的编撰？”</p>
