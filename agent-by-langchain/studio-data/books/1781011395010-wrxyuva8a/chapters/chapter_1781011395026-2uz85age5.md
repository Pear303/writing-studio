# 池梦

<p>还愣着干什么？他踢开水面向前狂奔，赤足拍打水面的声响在空旷中层层回荡！</p><p>靛蓝马赛克立柱，似乎扭曲成珊瑚礁形状，表面布满蜂窝状的孔洞。</p><p>杨帝余光瞥见，孔洞里闪过鱼类的鳞光，貌似有东西蠕动……</p><p>但当他转头直视时，珊瑚礁重新变成马赛克立柱，那些孔洞又变回规整的几何图案。</p><p>水面已经漫到大腿，裤管吸饱了水，每一步都像拖着铅块。</p><p>水面泛起不自然的波纹。</p><p>有什么冰冷滑腻的东西擦过小腿。</p><p>杨帝扑向最近的立柱，指甲在瓷砖上刮出刺耳声响，但水面在呼吸间涨到胸口。</p><p>他手脚并用地向上攀爬，奈何这立柱过于光滑，马赛克瓷砖上抓不到着力点。</p><p>水流灌入鼻腔。水面漫过头顶。</p><p>十年前的记忆与眼前景象重叠。</p><p>杨帝看见自己又变回那个抓着钓竿的男孩，鱼线那头传来恐怖的拉扯力。</p><p>但这次，他余光扫见的根本不是十斤大鱼，而是无数条苍白的手臂，从水底伸出，正攥着鱼钩狞笑。</p><p>但是正眼望过去，没有手臂，也没有大鱼，只有重力拖拽着他沉向水底。</p><p>自己吓自己。</p><p>那种低沉的，像是通风管道的声音，穿过水面后便化作亿万溺水者的哀嚎。</p><p>“布兑，握在做梦。”</p><p>肺叶在灼烧，杨帝的意识却异常清明。</p><p>他发觉环境极不对劲，世上不应该存在这么大，而且构造如此诡异的池子。</p><p>据说北方澡堂也很大，但总不可能……天花板距离地面50多米吧？</p><p>他终于肯定，自己在做梦！</p><p>“意识到自己做梦有个嘚儿用……这被水淹的梦也太特么真实了吧啊啊咕噜噜——”</p><p>杨帝四肢在水体中划出混乱的轨迹，指甲划过瓷砖，在水下变成闷钝的摩擦声，像是林正英电影里的清朝老僵尸要从水底破关而出，用指甲狂挠棺材板！！</p><p>「游泳+1」</p><p>这个念头像气泡般浮现在意识表层。</p><p>杨帝只是愣了一瞬间。他再次摆动双臂时，动作竟比方才标准三分，蹬水动作也更流畅了一丝。</p><p>「游泳+1」</p><p>“有戏！”</p><p>他将头探出了水面，终于能饱吸空气。</p><p>浮出水面只是第一步。</p><p>杨帝疯狂摸索着，试图寻找一个可以支撑身体的点。可除了冰冷的水，什么都没有。</p><p>身体很重，很冷，感觉又快要沉下去了。</p><p>一个人，只要他真的不会游泳，那他不论是能一拳打死黑熊/西伯利亚大仓鼠，结局和一个旱鸭子没啥区别。</p><p>这就是游泳的魅力，它和数学题一样，不会就是不会。</p><p>「游泳+1」</p><p>“哈，差点忘了我有挂，而且梦里竟然也能用。”杨帝乱蹬腿乱划水，居然也让游泳的熟练度+1了。</p><p>照这个势头下去，他能活的。</p><p>想到这儿，杨帝也稍稍放松下来，开始边游泳，边打量周围环境。</p><p>水是清澈的，甚至比他之前见过的任何海水都要清澈。</p><p>池子内部有窗户，是狭长而高的落地窗，乳白色天光透入。</p><p>但是，他看不清窗外的光源是什么，也见不到外面有什么景风。</p><p>在澡堂某处房间的一角，杨帝发现了一个小型喷泉，喷泉的水流在水下涌成暗流。</p><p>喷泉周围的瓷砖上，有些彩色的镶嵌图案。</p><p>图案单独看，会觉得很抽象。如果把它嵌进一个整体，综合来看，也仍然很抽象。</p><p>三圈金黄色马赛克瓷砖，扭曲地嵌套在喷泉中央，只能大致辨认出那是个螺旋，像银河系一样的漩涡。</p><p>螺旋似乎形成了某种视觉错觉，它看起来会旋转、闪烁和蠕动。</p><p>喷泉口中央堵着块铁饼，半个巴掌大小，上边也有螺旋状花纹。</p><p>像是玩解密游戏一样，杨帝不多想，将这有螺旋图纹的铁饼揣进怀里。收集道具嘛。</p><p>下一刻，他笑不出来。</p><p>拿走“铁饼”之后，喷泉开始疯狂喷涌水流！</p><p>杨帝一下子就被超高水压冲开，接近都接近不了，更甭提把铁饼堵回去。</p><p>水位迅速上升，原本50米高的天花板，现在已近在咫尺。</p><p>水面漫过穹顶，整个空间化作巨型水族箱。</p><p>每一寸空间，都在被上涨的水流慢慢填满。</p><p>白色瓷砖接缝处生出青苔状纹路，靛蓝立柱仿佛正在融化成珊瑚礁……一切扭曲变幻，如梦如真。</p><p>不是如梦，这就是梦……</p><p>如此真实的梦，他真的要淹死了么？</p><p>杨帝绝望地蹬水蹬到最顶端，但每一寸空间，每一缕空气，都被池水覆没。</p><p>“快醒来快醒来快醒来啊——不行了要窒息了啊啊啊！！”</p><p>「深海+1」</p><p>耳膜传来气球爆裂般的脆响，他感到鼓膜在重组。</p><p>新的提示让杨帝在混沌中抓住一丝清明。身体，身体在适应水压！</p><p>「深海+1」</p><p>但杨帝没有力气挣扎，他肺快要炸了。</p><p>当他放松肌肉，身体像海马般自然悬浮，肺中仿佛要爆炸般的灼烧感，竟减轻了三分。</p><p>「深海+2」</p><p>深海？深海和游泳有什么不同……</p><p>游泳可以呼吸，是可以把头露出水面的。而深海呢？人在深海，去不到水面，他必须无时无刻承受着水压，低温，和窒息。</p><p>「深海+3」</p><p>水流抚过杨帝虹膜的触感，变得清晰可辨，甚至能分辨出不同温度的水流在睫毛间形成的微型涡旋。</p><p>那些曾令他恐惧的靛蓝马赛克，此刻在深水中呈现出教堂彩窗般的光晕，梦幻迷离。</p><p>能呼吸，或者说不用呼吸，而且身体也不怕冷了。</p><p>「深海+5」</p><p>又出现了，1 1 2 3 5，黄金分割数列。</p><p>在什么情况下，“熟练度条”会以这样的数列增加？</p><p>「深海+8」</p><p>杨帝彻底活过来辣！他主动张开嘴，任由清冽液体灌入食道，和气管。</p><p>想象中的窒息没有到来，甚至没有任何难受，取而代之的是腮部撕裂般的瘙痒。</p><p>鳃部？人体是没有这个器官的，但如今杨帝只能这么称呼它。</p><p>它似是凭空多出来的幻肢。</p><p>杨帝朝他感知中塞的地方摸了一把，却只能摸到光滑的皮肤——他只是感觉自己多出来了一个鳃，但实际上，那里没有长出任何新器官。</p><p>杨帝笑了出声。</p><p>在梦里都能刷熟练度……不知道回到现实，能不能真的获得一技之长。</p><p>应该可以。</p><p>如果说，光看视频也能刷跑酷熟练度，那么，做梦……应该也行？</p><p>逻辑是这个逻辑，就是不太科学罢了。</p><p>这场“池梦”，原本应该能成为他永生难忘的噩梦。</p><p>但现在随着自己学会了游泳，适应了深海环境，杨帝发现，再深的池子也不过是纸老虎！</p><p>纸老虎不是真老虎，纸老虎可以上下其手。</p><p>杨帝在水里一拍脑袋——既然逃不出去，不如把这场噩梦变成特训，就像游戏里卡bug刷经验那样！</p><p>他主动扑进水中，在水底潜泳，用最笨拙的狗刨式触发提示。</p><p>「游泳+1」「深海+1」</p><p>“深海”方面的熟练度似乎到了瓶颈，没有接上之前黄金分割数列那样递增，而是恢复了+1+1+1的正常速率。</p><p>杨帝一边思考，一边游泳，潜水探索这处超巨型澡堂。</p><p>澡堂真的非常大，装饰也风格单一，白色的地板，墙壁和天花板铺满马赛克瓷砖的靛蓝色立柱，时不时能看见大黄鸭子玩具和不锈钢扶梯。</p><p>——这就是澡堂子的全部。</p>
