# 突入虚境

<p>他只能眼睁睁看着对方，将法杖斜插进背后的环扣，然后在那台金属材质的平台前坐下。</p><p>“杨帝，你提到‘虚境’时，我才被一语点醒。随后在冥想视野中，我终于窥见了这座机兵的真相……说实话，你的肉身强度确实很强，但你的灵能，你的‘个人现实’，实在是太稀薄了。”</p><p>意思是……</p><p>无限机兵的负载，不在于肉身的物理破坏，而在于个人的灵能强度……？</p><p>很显然，杨帝暂时比不过15000灵的精灵。</p><p>“无限机兵……总之它位于物质世界的躯体，只不过占其本体的0.01%，我也不清楚以你可怜的灵能体量，贸然去驾驶机兵，会不会瞬间就溶解彻底了。”</p><p>杨帝瞳孔一缩——主体溶解。</p><p>30灵的他，犹如一小杯墨水落入大海，瞬间就能稀释溶解。</p><p>15000灵的伊芙，则是一泳池的墨水，虽然也会被大海稀释，但好歹能保持形态一段时间，不至于瞬间“主体溶解”彻底。</p><p>他听到伊芙压抑的抽气声，以及法杖坠地的闷响。</p><p>杨帝身上的兰茵缠绕缓缓脱落。他恢复自由，扭头看过去。</p><p>精灵轮廓正以肉眼可见速度崩解，仿佛被无形之风撕碎的薄纱。</p><p>下一个瞬间，伊芙消失了，包括她的衣服，凉鞋，和圣树枝杈所化的法杖。</p><p>第三秒，杨帝恢复了更多行动能力，他强行站起来，浑身颤抖着看向那座“金属平台”。</p><p>“伊芙！你还在不在！”</p><p>杨帝记得，伊芙说过，突入虚境并不容易。</p><p>不同于冥想过多带来的副作用“主体溶解”，人的精神突入虚境，可能会有更危险的后果——迷失于世界之本质，朝闻道，夕可死。</p><p>在TYPE-MOON世界的历史上有记录显示，曾有几人成功抵达了根源之涡，也就是类似于虚境的东西。然而，在他们触及万物本源的刹那，他们在这个世界的一切存在痕迹都被瞬间抹去，如同从未出现过一般，彻底消失了踪影。</p><p>当然，TYPE-MOON的「根源之涡」，不一定就等于中土大陆的「虚境」。</p><p>但很可能同样危险。</p><p>“伊芙！如果你成功进入了机兵，就做出点反应让我知道！”</p><p>“……”</p><p>“这就是强者的责任……瑞弗维尔，你渴求力量，但谁人比我更渴求……”</p><p>“……”</p><p>杨帝一瞬间回忆完与伊芙的过去。</p><p>她是个古灵精怪的古怪精灵。她尾随杨帝与瑞弗维尔一路，在末日火山出手救下他们。</p><p>初次见面，这位柑橘姓氏的精灵咄咄逼人，在石头上摆沙漏的动作，恰似张麻子掏出闹钟。</p><p>如果熬过初次见面的那几个小时，你会发现她其实是个随性的精灵，喜欢学术研究，偶尔挫败几个惊天阴谋。</p><p>她在东行队伍中是老大姐角色。</p><p>众人都曾认为天塌了有伊芙顶着，事情就不可能坏到绝望的地步。</p><p>她对史莱姆的热爱，起源于年少时送给她发卡的陌生史莱姆。</p><p>但他们都没能想到的是，熔岩史莱姆是原初之眼阴谋的一环。伊芙还差点因此让瑞弗维尔死于自己之手——尽管那并非出于自我意志。</p><p>她过去所热爱的一切破灭后，心境到底是如何的呢？</p><p>但杨帝还没来得及反对杨帝自己。</p><p>伊芙·柑橘已经听取他的建议，突入虚境。</p><p>“伊芙……这就是圣树所说的命运吗？”</p><p>杨帝最后一次呼喊伊芙的名字，声音在空旷的岩洞内撞出破碎的回响。</p><p>短暂死寂中，他咽下喉间腥甜。</p><p>转身，欲离开这个充斥着失败与死亡气息的空间。</p><p>下一刻，地面传来令人牙酸的震颤。</p><p>齿轮咬合的刺耳声响从四面八方涌来。</p><p>杨帝扶住岩壁，目睹平台中央裂开蛛网状缝隙，有什么东西正在破土而出。</p><p>“机兵……伊芙……？！”</p><p>杨帝扒着岩壁爬上地面。</p><p>灼热的气浪裹着硫磺味扑面而来，远处此起彼伏的爆炸声震得耳膜生疼。</p><p>熔岩史莱姆的凝成的惊涛骇浪，已经将这棵年轻圣树所凝结成的护盾轰炸得千疮百孔。</p><p>但杨帝的目光，仍然死死钉在大地。</p><p>“轰——隆隆！！”</p><p>他被气浪掀翻在地，却仍撑起上身，眼睁睁看着银白色机械体如破土春笋般冲出地表。</p><p>机械身躯彻底成型的瞬间，巨大的阴影笼罩住杨帝。</p><p>机械巨人足有百米之高，胸口镶嵌的核心闪烁着与伊芙眼眸如出一辙的翠色幽光。</p><p>“伊芙！”杨帝呼吼。</p><p>机兵的头部转向杨帝。</p><p>“我与它……达成了同步。”伊芙的声音从机兵的胸腔传来，混着机械轰鸣与空间震颤。</p><p>那一刻，杨帝深刻感受到，她已不再是那个爱笑的柑橘味精灵，而是成为了这台超越时代兵器的一部分。</p><p>他眼前折射出伊芙的身影。</p><p>精灵眼神中却没有了往日的灵动。</p><p>取而代之的是与机兵同样深邃的冷漠，与沉默的坚重。</p><p>“杨帝，我每个关节的运动都在承受千倍的冲击，我能感知到三十公里外熔岩史莱姆沸腾的黏液，能听见它们体液流动的频率，但这些信息正在撕裂我的思维。我无法维持很久，再之后就只能靠你了。你猜得对，突入虚境是进入机兵的途径。”</p><p>伊芙的声音带上了尖锐的颤音：“我在同时经历千万种感官，呼吸都变成了需要计算的精密操作。杨帝，在我失去心智前，我只能将我的心愿嘱托给你——”</p><p>空气宛如尼尔叔叔的白乳胶那般粘稠，但杨帝还是用力点了点头。</p><p>“对史莱姆的学术研究已经不重要了。如果可以……啊啊啊啊！！！”</p><p>话未说完，机兵的翠色核心爆发出刺目强光，伊芙嘶吼，混着机械过载的嗡鸣撕裂空气。</p><p>百米高的金属身躯剧烈抽搐，机械指节深深插进地面，将岩层碾成齑粉。</p><p>即使是心思最粗粝的矮人，也能从这座钢铁巨人僵硬动作中，感受到狰狞的痛苦。</p><p>“不——停下！！”伊芙的声音支离破碎，撕心裂肺。</p><p>杨帝未能发话，机兵已如离弦之箭弹射而起。</p><p>它背后展开三对光翼，将燃烧的天空切割成两半！</p><p>岩浆却从天空的裂缝中喷涌而出，如同苍穹睁开无数只流淌着血泪的眼睛。</p><p>下一刻，熔岩史莱姆集群汇聚成的巨型触手穿透云层！</p><p>每条都足有山脉般粗细，表皮上沸腾的岩浆不断滴落，在半空就化作燃烧的陨石！</p><p>粘稠体液裹着尖锐骨刺，伴随着令人牙酸的挤压声，以超音速横扫镇压！</p><p>“轰——！！”</p><p>最前端的触手狠狠砸向机兵，伊芙失控的嘶吼声与金属碰撞的巨响同时炸开。</p><p>爆炸气浪掀飞数十万史莱姆，冲击波在地表犁出一道横跨天际的深沟。</p><p>但机兵也在反作用力下向后倒飞，撞碎了三座山峰才勉强稳住身形。</p><p>但尚未等触手彻底压制，机兵背后残缺的光翼突然迸发蓝光，机械身躯以违反物理规律的姿态弹射而起，在一阵阵音爆声中再度冲向天穹！</p><p>右臂变形的链锯光刃撕开触手表皮，沸腾的熔岩如瀑布倾泻。</p>
