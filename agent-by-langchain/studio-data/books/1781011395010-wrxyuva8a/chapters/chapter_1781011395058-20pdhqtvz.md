# 钓鱼佬二三事6

<p>这栋楼和外界最大的不同，就是“灵”含量显著的小，“存在感”很低。</p><p>杨帝默默得出结论——灵比较少的地方，比较容易召唤另一个世界的东西？</p><p>这或许是个值得思考，有其启发性的猜想。</p><p>按他目前的理解，“灵”和事物的存在性，息息相关。</p><p>旧校区艺术楼地下室、这栋烂尾楼……这些地方所含的“存在”比较少。</p><p>也许，就会因此更容易让另一个时空，次元，维度，世界……的“东西”，在现实的薄膜上开一个洞，入侵我们的宇宙。</p><p>钓鱼佬重新翻开他的电子书，翻找着一些资料。</p><p>“我原以为召唤时间可能有讲究。在一些特殊的时间节点，成功率会略微提升，比如，阴阳交替的黎明与黄昏。但后来发现不是这样的。”</p><p>杨帝：“那事实是怎么样？”</p><p>……</p><p>钓鱼佬开始叙述。</p><p>“当时我在那个废弃地下商场做实验，一心沉浸其中，做到天昏地暗。周围没有窗户，完全分不清外界的昼夜。</p><p>“就在某一刻，我不经意间瞥了眼手表，发现指针停在了六点左右的位置，我下意识就以为那是黎明时分。</p><p>“毕竟按照以往的认知，阴阳交替之时或许会有特殊的能量波动，利于召唤。”</p><p>杨帝身体不自觉向前倾了倾，“然后呢？”</p><p>“然后，嘿，你还别说，那次召唤的成功率真就略微提高了。</p><p>“当时出现的异常现象，比以往强烈不少，可能差一点就成功引出了些东西。</p><p>“可等实验结束，我走出地下商场，才发现外面阳光明媚。</p><p>“拿出手机一看时间，竟然都下午两点了，而我的手表没上发条——所以停在了六点。</p><p>“后来复盘，我认为关键并非在于真正的时间，而是我‘心里认为’当时是黎明。</p><p>“我当时坚信是阴阳交替之时，这种强烈的心理暗示，使得成功率有了些许提升。”</p><p>钓鱼佬结束叙述。</p><p>……</p><p>“时间”与成功率无关，“心理”才与成功率有关。</p><p>心胜于物的设定啊。</p><p>杨帝微微皱眉，摩挲着下巴思考：“召唤成功率和人的心理预期、信念感密切相关？只要内心笃定处于某种有利于召唤的条件下，即便实际情况并非如此，也能对召唤产生影响？”</p><p>这这就好比自我催眠。</p><p>当你完全相信某件事，精神层面就会产生一种力量，作用于召唤过程。</p><p>那个“东西”似乎能感知到召唤者的精神，也许这种强烈的心理暗示，能引起它的注意。</p><p>陈昭觐见“耶罗大仙”，是否也符合此规律？</p><p>可能是的。</p><p>陈昭研究耶罗大仙多年，并且内心对其极其推崇、狂热。</p><p>日积月累下来，他的对自己的“精神暗示”和“精神驯化”已经达到很高水平。</p><p>再搭配信物“耶罗符印”，才能召唤成功。</p><p>狂信徒更容易把他们想见的神召唤出来。</p><p>杨帝脑海中迅速闪过各种可能性。</p><p>那个点了杯“天蝎座特调”的学生……也研究神秘学到癫狂？</p><p>他对钓鱼佬道：“召唤时，提前做好心理建设，营造出一种必定成功的心理氛围，就能提高那些异常现象出现的成功率。”</p><p>中年男人点点头，“没错。”</p><p>杨帝：“那如果，我对自己完全催眠了……”</p><p>钓鱼佬有些惊喜地看向他：“小伙子……师傅，你还会催眠？！”</p><p>“是会一点，但只能对自己催眠……”</p><p>杨帝说出这番话，并非没有依据。</p><p>虽然他不会催眠别人，但他确实能在一定程度上催眠自己。</p><p>“催眠”的本质，是让“潜意识”上浮。</p><p>“上浮”之后，催眠师更容易与被催眠者的“潜意识”建立深度沟通，并施加暗示。</p><p>暗示你现在很困……</p><p>暗示你说出银行卡号……</p><p>暗示你暴露浏览器记录……</p><p>暗示做出什么动作……诸如此类。</p><p>平时，潜意识隐匿于意识层面之下，默默影响着人们的行为与决策。</p><p>当人进入催眠状态时，“潜意识”大量上浮至思维的浅滩，变得更活跃且易于接受暗示。</p><p>而杨帝，有足足10%的潜意识，上升到了他的表层思维！</p><p>原本50bit每秒的表层思维，被100万bit每秒的潜意识内容大幅冲淡。</p><p>可以说，他无时无刻都不处在“催眠状态”！</p><p>只不过，“催眠者”是杨帝自己。</p><p>杨帝“催眠”自己的身体做出种种动作，“暗示”自己做出理性或感性判断。</p><p>这才让他大体上像个正常人。</p><p>杨帝笑着说：“我能对自己深度催眠——你应该觉察到，你我都是相似之人。我也是在遇上一些事情后，获得了异于常人的能力。”</p><p>钓鱼佬一怔。</p><p>他直觉一向准。</p><p>他确实感受到了，杨帝的气质和自己有些相似……</p><p>“难道，你也……”</p><p>“平静的生活千篇一律，而能来到这栋楼的人各有各的境遇。叔，我并不太想和你比惨，但可以告诉你，我也有两个朋友，被‘一些东西’带走了，而我甚至对‘祂’在哪里都毫无头绪。”</p><p>杨帝本来有一千个机会，让自己流露出“淡淡悲伤”的微表情，博得同情。</p><p>但他最后一刻，还是没有这样做。</p><p>他只想表现出纯粹的真诚。</p><p>杨帝保持着微笑与平静，说：“所以，我不只是为了帮你，同时也是为我自己收集线索。”</p><p>钓鱼佬抬起手，重重拍了拍杨帝肩膀。</p><p>随后从口袋里摸出一根烟，递给杨帝，自己也叼上一根。</p><p>二人无言。</p><p>打火机的火苗在昏暗的光线中跳跃，点亮了两人面前小小的一片区域。</p><p>“我不吸的。”</p><p>“嗯？那你之前为什么问我要支烟。”</p><p>“我说过，‘那不是给我吃的’。”</p><p>“哦，那我误会了，要不要给回我？”</p><p>“不用了。帮忙点着吧，它刚才救了你一命，我们再去谢谢它。”</p><p>钓鱼佬也被勾起了一丝好奇。</p><p>从他被救上来为止，一直有个问题悬置着，被他下意识忽略——</p><p>是谁救了自己？</p><p>是谁把自己从电梯井积水里拉了上来？</p><p>杨帝口中的“它”是谁？</p><p>杨帝：“把你拉上来的人，我也不太清楚来头，但我大概知道是只苍白的手。”</p><p>一只手……钓鱼佬想到那些老掉牙的鬼故事。</p><p>藏在余光里的老太太呀，听到不存在的声音啊，家里多出来的一双红绣鞋，家里多出来的两双红绣鞋，家里多出来的1000双红绣鞋，家里多出来的10^100双红绣鞋……</p><p>杨帝带着他上了楼。</p><p>他们来到那扇紧闭的房门前。</p><p>地上的纸盒子还在，只是轻轻一抖，里面仅抖落了一点点烟灰，先前放在这里的那只烟已然被拿走。</p><p>“这……是谁呢？”钓鱼佬问。</p><p>这门后面到底是什么人，为什么一支烟就能救命？</p><p>他当然很关心。但遗憾的是，杨帝也不知道。</p><p>世上很多事情目前为止都不可理喻——为什么费米子与希格斯场耦合就能获得质量，为什么为什么《半湖绿》结尾如此沟槽，生命、宇宙、意义的终极答案为什么是535559835……</p><p>“它很害羞，而且有些傲……傲立于世外，我们还是不要进房打扰它了。”</p><p>杨帝说着，把钓鱼佬刚刚点燃的香烟，立在那盒子上。</p>
