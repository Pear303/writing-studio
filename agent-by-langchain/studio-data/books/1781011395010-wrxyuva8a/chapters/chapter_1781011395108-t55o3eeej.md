# 井口对峙

<p>瑞弗维尔面色苍白，嘴唇微微颤抖着，“往南？那不是星渊井口的方向吗……难道伊芙真的是自己去找巴德了？可这到底是为什么？”</p><p>精灵打着“研究史莱姆”、“制止教廷对史莱姆的残暴行径”这俩旗帜。</p><p>最终目的却是奔现？！</p><p>“奥拓兄弟……你确定她是往南走的，而且还提到了巴德？”</p><p>矮人用力地点点头，“千真万确，我没睡踏实，这点听得真切。”</p><p>那么，杨帝的分析就很有说服力了。</p><p>瑞弗维尔的指尖深深掐进掌心，冷汗顺着下颌线滴落在腰间的短刀皮套上。</p><p>刀身的RL标记，似一道深刻的伤痕。</p><p>“不……她并非完全意义上的不辞而别，她不是给了我们暗示吗？这说明，伊娃是希望我们能随她去到星渊井口。”</p><p>前图书馆馆长，前前职业游侠，瑞弗维尔，心中燃起希望——或许能赶在星渊井口前，拦住那个总爱歪着头笑的精灵？</p><p>他急道：“那还愣着干嘛现在麻利出发！”</p><p>轮到杨帝不解了。</p><p>“瑞弗维尔，你担心什么。伊芙是10环大法师，一般来说，没什么能威胁到她。”</p><p>瑞弗维尔也说不清为啥自己急。</p><p>但当下无事，他们随便采摘了些树莓、无花果和菠萝蜜，吃了顿早饭，就上路了。</p><p>继续向南。</p><p>这里已经非常靠近大陆南边。</p><p>虽然不知是哪位大能的灵能影响了环境，局部气候紊乱，忽冷忽热，但总体而言，南方热量丰富，雨水充沛，这样得天独厚的气候条件，恰好是菠萝蜜生长的理想环境。</p><p>菠萝蜜是瑞弗维尔第一喜欢的水果。但现在他不想吃菠萝蜜，也不想榴莲，只想要柑橘。</p><p>三人裹紧披风，继续于白桦林中赶路。</p><p>不时，某人的靴子碾碎满地枯叶，惊起几只银尾雀，扑棱棱的振翅声惊破死寂。</p><p>林间弥漫着松脂与腐殖混合的气息。</p><p>起初，阳光还能穿过白桦林的枝叶间隙，还有光线轻抚他们的披风，在地面洒下斑驳碎金。</p><p>然而，不知从何时起，远方的天际线悄然泛起灰影。</p><p>灰影如同被无形之手缓缓铺开的墨渍，以肉眼可见的速度，从天空中央蔓延。</p><p>风也变得冷冽起来，裹挟着潮湿。</p><p>环境气温好像越来越冷了。</p><p>如果杨帝猜测非虚，伊芙所说“局部地区气候改变”是因为“超限强者”存在。</p><p>那么，来自东部森林的精灵伊芙、可能以某种形式存活于世的圣骑士，他们之间正在发生着什么？</p><p>已急行军10公里，原本就不大的白桦林，很快将到尽头。</p><p>地势渐低，细碎的石英砂砾开始在鞋底发出沙沙轻响。</p><p>杨帝穿的是人字拖，他感觉到这一段路，有特别多细密小碎砂扎脚。</p><p>最后一棵桦树消失在身后，眼前豁然展开一片泛着冷光的石英滩。</p><p>百万片碎水晶在沙粒间折射出冷冽的光。</p><p>正午时分，云层却压得极低，铅灰色的天幕如同倒扣的熔铅。</p><p>整片滩涂浸在诡异的青白色光晕里，让人看得目眩迷离。</p><p>是地面在发着光。</p><p>数百万颗石英晶体在阴云下仍然熠熠闪烁，像是覆盖了某种荧光材料，在有光照的时候会吸收能量，无光照的环境下自行发光。</p><p>杨帝弯腰拾起一颗鹅蛋大小的石英，里面竟封存着半截褪色的羽毛。</p><p>某种巨鸟遗留的标本？</p><p>“这些并不是石英，至少不是普通的石英。”</p><p>瑞弗维尔奔袭半日，终于走累了，他停下来，研究地上发光的白色石英，“这里的石头，都被星渊井口渗出的灵能长期浸染，物理和灵能属性都发生了变异。”</p><p>比较明显的变异，就有其“荧光”特性。</p><p>这都是很正常的“灵能现象”，只能说明此地灵能极度丰富。</p><p>但无暇顾及风景，失去主心骨的众人也没那个兴趣。</p><p>继续走下去，远处传来轰鸣，是海浪拍打礁石。</p><p>“星渊井口和大海很近。听到海浪声，说明我们离井口不远了。”</p><p>三人登上最高的丘陵，远处的大海翻涌着铁灰色的浪。</p><p>而在数百米开外，大海与丘陵之间，星渊井口的轮廓终于清晰起来。</p><p>那看起来像一座湖，一座结了冰的湖，结满蓝色冰凌的圆形湖面。</p><p>蓝色晶体组成的“湖泊”，镶嵌在纯白的石英滩之上，在云影下若隐若现。</p><p>那些不规则的六边形晶面，如破碎镜面，倒映着扭曲的天光。</p><p>普通人的眼睛中仅有3种视锥细胞，分别对红、绿、蓝三种光敏感，只能感知到大约100万种颜色。</p><p>据不完全统计，杨帝拥有16种视锥细胞，能区分到的颜色是1000万种。</p><p>他能感受到偏振光，他能感受到更大的光谱范围，区分出更多红外、紫外光线的颜色——大约是普通人10倍数量的新颜色。</p><p>杨帝所看到的星渊井口，与瑞弗维尔、奥拓所见的，全然不同。</p><p>视网膜上炸开一团光晕，星渊井口在他眼中化作沸腾的色彩漩涡，靛蓝色的冰凌表面流转着液态的虹光。</p><p>如果说，此刻还有什么人，能用几千字就能表达杨帝的心情。</p><p>那他一定会向那人脱帽致敬——尽管自己没有戴帽子。</p><p>因为就连杨帝自己，也没办法在30万字内用足够准确清晰的语言，表达出此刻之心境。</p><p>“这就是……中土大陆最庞大的地脉灵能枢纽？”</p><p>话说回来，如果杨帝戴帽子，他认为自己戴的一定是渔夫帽吧。</p><p>戴上渔夫帽的人，气质都会发生翻天覆地的变化。</p><p>那副模样，那种气质，总让他想到《无间道》里，陈永仁和刘建明在天台的对峙。</p><p>而在此刻，星渊井口中央。</p><p>亦有二人近距离地对峙着。</p><p>一人金色长发飘飞，青绿色披风乱舞，手执法棍指向另一人。</p><p>另一人身披鎏金铠甲，肩甲处缠绕的锁链在风中叮当作响，可整个人却像是蒙着层半透明的薄纱，随着云层的阴影时隐时现。</p><p>他缓缓抬头，面甲下露出的双眼没有瞳孔，只有两团不断燃烧的金色火焰，宛如两颗坠落人间的星辰。</p><p>或许异界人会把他当作亡灵骑士，地球人认为他是字面意义上的鬼火少年。</p><p>但在此时此刻，杨帝、奥拓与瑞弗维尔心中，浮现出的是同一个名字——</p><p>巴德。</p><p>那位一百年前，给予焚灭天空之龙·卡利斯托绝杀一击的传奇。</p><p>从实际现场看，圣骑士巴德是“刘建明”，而精灵伊芙是“陈永仁”。</p><p>只不过，巴德并没有被双手反铐在身后，他双手按在古朴的剑把上，剑刃深深杵入地面，迸溅出的紫色火星与电光。</p><p>伊芙手中拿的也不是枪，而是法杖。法杖对准巴德的脑袋。</p><p>他们在说些什么。</p><p>风向逆着刮，瑞弗维尔与奥拓听不清他们在谈论什么。</p><p>杨帝听清楚了。</p>
