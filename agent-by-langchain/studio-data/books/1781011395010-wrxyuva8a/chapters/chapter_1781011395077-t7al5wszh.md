# 这完全是爆炸式天崩开局

<p>“猜猜我是谁？答对没奖励，答错有惩罚。”</p><p>“你是……红衣主教第九席！！”</p><p>“猜对了，但是猜对了一半，我还有第二个身份，不介意告诉你这个将死之人。”</p><p>第九红衣主教露出狰狞的笑容。</p><p>“光明圣教-原目会-胡伯特·布莱恩·沃尔夫施莱格尔施坦因豪森贝格多夫，参上！”</p><p>瑞弗维尔：……</p><p>瑞弗维尔：“您能再重复一遍名字？”</p><p>“光明圣教，原目会，胡伯特·布莱恩·沃尔夫施莱格尔施坦因豪森贝格多夫！等等……你这是在戏弄我？！”</p><p>沃尔夫施莱格尔施坦因豪森贝格多夫恼羞成怒。</p><p>瑞弗维尔绝非坐以待毙之人。</p><p>他身形一闪，迅速朝着密道深处奔去！</p><p>红衣主教沃尔夫施莱格尔施坦因豪森贝格多夫见状，冷笑一声，身形如电般追了上去。</p><p>密道中，两人一追一逃。</p><p>瑞弗维尔灵活地在狭窄的通道中穿梭，试图利用密道复杂的地形摆脱追捕。</p><p>然而，红衣主教毕竟境界远高于他，每一次都能精准地预判他的行动，紧追不舍。</p><p>“为什么要追我？！”</p><p>“你很有意思，瑞弗维尔。我追杀其他人时，他们一般会说‘求你别追我’，只有你在明知故问‘为什么我要追你’。”</p><p>“那您倒是说说，为啥非得追我这个小术士，教廷事务繁忙，您不该去处理大事吗？”</p><p>瑞弗维尔一边在密道中左突右拐，一边大声喊道，试图分散红衣主教的注意力。</p><p>那嚣张的声音从身后某处传来。</p><p>“你还不算是‘大事’吗？居然说焚灭天空之龙·卡利斯托将重生，还被委派去末日火山调查？”</p><p>瑞弗维尔敏锐地捕捉到关键点。</p><p>他得到了两个可能性很大的结论：</p><p>第一，末日火山，确实藏了“东西”。</p><p>第二，圣光教廷，确实有“秘密”。</p><p>只可惜……这些发现，应该传达不出去了。</p><p>追逐间，瑞弗维尔的体力逐渐不支。</p><p>而红衣主教却依旧气定神闲，速度丝毫不减，始终与“猎物”保持着不远不近的距离。</p><p>这场追逐，对他只是猫捉老鼠的游戏。</p><p>“有时，你们这些猎物很让我费解，既然最终结局都是被我抓到，杀死。为什么不跳过流程，直接把脖子递上来让我杀掉呢？”</p><p>“你这是什么狗比歪理。”</p><p>“堂堂圣古琉斯宫廷图书馆馆长，竟然面不改色地骂脏话，果然在近邻生死的时刻，人都会收起伪善的面具，暴露出最真实的兽性……”</p><p>“闭上嘴，别念了啊啊！”</p><p>瑞弗维尔特地朝着密道中那些阴暗的犄角旮旯处跑去。</p><p>他心中抱着一丝侥幸。</p><p>——希望能在这错综复杂的黑暗角落中寻得一线生机，摆脱身后如影随形的红衣主教。</p><p>“别白费力气了，瑞弗维尔。”</p><p>红衣主教那嚣张的声音再次传来，带着一丝戏谑，“我已经开启了‘原目’，在这双眼睛之下，你的一举一动都无所遁形，甚至能看到不该看到的东西……”</p><p>瑞弗维尔心中一沉。</p><p>虽然……他并不知道“原目”是啥。</p><p>但这名字如此炫酷，必定来头不小呀！</p><p>他只能咬着牙在密道中狂奔。瑞弗维尔本身是个五环游侠，虽然和红衣主教比起来是个纯粹菜逼八，但身体素质也是远超普通人。</p><p>“你以为往这些阴暗的地方跑就能躲开我？太天真了。在原目的视野里，你身上就像挂了一盏明灯。”</p><p>那隐隐约约恍恍惚惚的声音，又从身后断断续续而来。</p><p>瑞弗维尔扭头望去。</p><p>身后极度深沉的黑暗之中，隐隐约约有一对紫色的瞳孔，仿若荧荧鬼火，震人心魄。</p><p>那就是……“原目”？</p><p>红衣主教所言不虚，瑞弗维尔终究逃不脱。</p><p>终于，在一个较为开阔的密道空间，红衣主教看准时机，伸出如鹰爪般的手掌，一把抓住他的肩膀。</p><p>“呀！放开我！”</p><p>“看你还往哪里跑！”红衣主教得意地大笑。</p><p>手上微微用力，瑞弗维尔便感到一阵剧痛袭来，身体瞬间失去了反抗的力气。</p><p>“可以和解吗？”瑞弗维尔一边说着，心中满是绝望。</p><p>他不甘心就这样束手就擒。</p><p>慌乱之中，他瞥见身旁的壁龛上，有一个巴掌大小的石头雕塑。</p><p>于是想也没想，一把抄起便朝着红衣主教扔了过去！</p><p>石头小雕塑不偏不倚砸在了红衣主教脸上，发出“咚”的一声闷响。</p><p>这一下并没有对他造成实质性的伤害，毕竟以他的实力，这点冲击如同挠痒。</p><p>但在红衣主教看来，这却是一种极大的侮辱吔！！</p><p>“大胆！毁我妆容。此时此刻，你我已无和解的可能。”</p><p>红衣主教扬起手，准备给瑞弗维尔致命一击，以惩罚他的胆大妄为之僭越。</p><p>但下一刻，他扬起的手在半空中顿住。</p><p>他的目光扫向掉落在地、巴掌大小的石像雕塑。</p><p>脸上先是露出困惑的神情，仿佛看到了什么难以理解的东西。</p><p>“这……我……南……”</p><p>红衣主教喉咙中嚅嗫着什么，听不清晰。</p><p>眉头紧紧皱起，眼神中满是疑惑，盯着那雕塑，像是在努力回忆着什么。</p><p>随着时间的推移，困惑逐渐在他脸上转变为震惊。</p><p>他的双眼瞪得滚圆，仿佛看到了世间最恐怖的景象，脸上的肌肉不受控制地微微颤抖着。</p><p>“这……这……啊……”他的声音不自觉地拔高，带着一丝难以掩饰的恐惧。</p><p>瑞弗维尔也被红衣主教这突如其来的反应弄得不知所措，心中原本的绝望被巨大的好奇所取代。</p><p>他顺着红衣主教目光，看向那座石头雕塑。</p><p>可在他眼中，这不过是一个普普通通、不知用途的小雕塑罢了，并没有什么特别之处。</p><p>“难道这厮因为开启了‘原目’，所以看到了不一样的东西？”</p><p>瑞弗维尔咽了口唾沫，也不敢看了。</p><p>他悄悄挪动身形，摸到最近的路口。</p><p>然后，红衣主教有个令人瞠目结舌的新动作——</p><p>他像个小孩子一样，坐在地上哭泣起来。</p><p>哭声在密道中回荡，似乎蕴含着无尽的恐惧与悲伤，仿佛触及到了他内心深处最不堪回首的往事。</p><p>“呜……呜呜……”</p><p>瑞弗维尔从未见过如此失态的红衣主教。</p><p>可以说，他从未见到有小孩，甚至是人类，能够哭泣得如此悲恸，如此怅惘！</p><p>“呜呜呜……呜哇！！呜……”</p><p>瑞弗维尔心中的好奇愈发强烈，但求生的本能又驱使他不敢有丝毫懈怠。</p><p>许久，红衣主教才缓缓站起身来，用颤抖的手抹了抹脸上的泪水。</p><p>图书馆馆长下意识后退。</p><p>他没有追杀上来，也再没有一丝不怀好意。</p><p>他看向瑞弗维尔，但眼中没有了之前的杀意与愤怒。</p><p>那双泛着紫光的瞳孔中，蕴藏着一种世间无人可及的悲恸。</p><p>“你走吧……”红衣主教的声音沙哑而低沉，仿佛苍老了几十岁。</p>
