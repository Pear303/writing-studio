# 再探旧校区1

<p>杨帝决定要问正事儿了：“希夷，你以前一直住在旧校区吗？”</p><p>二人交流并非汉语和普通话，而是更高深莫测，更形而上的“神交”。</p><p>所以当杨帝说“旧校区”时，希夷得到的信息也绝不止简单的三个汉字。</p><p>它理解了杨帝表达的所指。</p><p>希夷的声音如同老式收音机调频时，断断续续：“混沌，无形，未定……”</p><p>“说人话！你在被人拍到之前，是不是就定居在旧校区？”</p><p>它回答：“思绪混沌，心窍闭塞……茫然无措，一无所解……”</p><p>「精神+34」</p><p>信息如潮水般涌来，杨帝明白，在被相机定格的刹那前，希夷不过是团浑噩的物体，尚无自我认知。</p><p>「精神+55」</p><p>“那你和我神交的时候，为什么我获取了你这么多‘神秘学’知识？”</p><p>「精神+89」</p><p>“内圣之道，浑然若天成……生于无化于有……呼……呼……”</p><p>话音未落，这贪睡的家伙又陷入沉睡。</p><p>杨帝抓了抓头发，敢情自己脑子里养了个只会吃精神值的米虫。</p><p>希夷在吞噬他的精神前，还没有开化灵智，连自我的存在都没意识到。</p><p>更别提让它提供有用线索了。</p><p>或许，除了用来刷精神属性，它还会有其他用处的，只不过现在，杨帝还没开发出来。</p><p>来不及睡觉了，现在开始收拾行李。</p><p>打开衣柜，翻找鞋架，挑选适合户外活动的衣物。</p><p>耐磨的牛仔裤，透气性能良好的运动衫，透明雨衣。</p><p>在鞋架前犹豫片刻，终究放弃人字拖，选了双抓地力强的球鞋，毕竟未知的征途需要稳妥。</p><p>书桌前，抽屉里取出一个装满必需品的小背包。</p><p>杨帝曾经眼都不眨，一口气刷完《行尸走肉》一到十季。市面上常见的丧尸电影，也都平均刷过三遍以上。</p><p>尽管后来把英叔的电影来回看过几遍，还开“风灵月影”爽玩了植物大战僵尸破解版。</p><p>但他心中对僵尸的恐惧仍难以消解。</p><p>所以，杨帝随时准备着一个背囊，以备不时之需，用于末日生存！</p><p>背囊内有手电筒，指南针，十瓶矿泉水，十天分量的压缩饼干。</p><p>还有万花油，驱风油，跌打油，活络油，正骨水，双飞人，无比滴，花露水，保心安油。</p><p>居家常备，包治百病！</p><p>最重要还有自己的手机，连带三个充电宝，用来打电话看小说，能撑仨星期。</p><p>一切准备就绪，杨帝打开微聊。</p><p>他找到导员的哇信，随口编个理由“家族遗传性梦游症复发，需静养一二日”，发信息请假。</p><p>对方还没回复，看来应该在睡觉。</p><p>万事俱备，带上背包，直接上路出发。</p><p>现在是凌晨4:30，张明远还在梦话中呓语叱责杨帝不要吵了。</p><p>说实话，他以前从不知道，张明远不仅磨牙，而且频繁讲梦话。</p><p>南方的夏天，天亮得很早。</p><p>天地虽然笼罩在一片朦胧的黑暗中，但极远处地平线已渗出蓝紫色的天光。</p><p>晨雾像融化的玻璃糖纸裹着旧校区，生锈的铁栅栏在雾气中若隐若现。</p><p>他沿着上次的路线，饶过铁丝网，避开监控和保安，轻而易举翻越围墙。</p><p>艺术楼后门的锁链比记忆里更松垮，推开的时候，铁锈簌簌落在手背。</p><p>“杨帝老弟，见过凌晨4点的旧校区吗？”</p><p>好熟悉的一句话……等等谁在说话？！</p><p>杨帝一惊，抬头。</p><p>只见——胡彦卓坐在防火梯上，红色运动衫下摆垂落如凝固的火。</p><p>他翻身跃下，像折断翅膀的鹰隼，右腿落地时明显迟滞半拍。因为髋关节的暗伤。</p><p>杨帝下意识后退半步：“胡哥，你怎么……一大早埋伏在这？！”</p><p>胡彦卓笑笑：“昨天我暗示过你的，凌晨4点我会在这等。如果你来了，咱就结伴，你不来，那我便孤身一人。现在快5点了你才来。”</p><p>“胡哥，你来这儿干嘛？”</p><p>“蓝天红气球图片。”</p><p>他如是说，“昨天你问我关于那张图片时，我才突然想起来，我所遭遇的不幸，不是踏入旧校区后开始，而是在拍下那照片后开始的。”</p><p>在他讲述中，杨帝也终于对胡彦卓大哥这位跑酷界大佬，有了更深一些些了解。</p><p>稷海理工旧校区，前年7月那场跑酷，是胡彦卓驱之不散的心魔。</p><p>空置多年的旧校区楼顶突兀漂浮的红气球，冰寒刺骨的空气墙，后颈若有若无的温热吐息，莫名出现的电线……这些梦魇纠缠了他一千多个日夜。</p><p>他经历了很多，现在一切都该有个了结。</p><p>只有直面旧日的恐惧，才能让噩梦中的魑魅魍魉闭上嘴，让往昔的恐怖滚出他的生活。</p><p>胡彦卓要回到此处来证明，世界是物质的，理性的，他有必须面对的过去。</p><p>而杨帝，也要处理即将到来的未来。</p><p>耶罗大仙，漩涡图纹，希夷……</p><p>“那……胡哥你说你想要‘直面恐惧’，可否透露一下您具体要去哪儿？”他说。</p><p>“我会去天台，把两年前失败的最后一跳，再跳一次。”胡彦卓笑着说。</p><p>他内心被恐惧之火灼烧已久，似在迷雾中迷失的孤魂，执念于往昔的失败。</p><p>于是，他要以无畏一跳，在旧地寻回理智，摆脱噩梦，重获掌控。</p><p>说完，胡彦卓目光炯炯地看向杨帝。</p><p>“杨帝你呢？你突然问我关于红气球，还有那个漩涡图案的事。你来此处是为了什么？”</p><p>杨帝赶紧找了个合乎理性的理由：“呃……就是我在旧校区捡到这块铁饼，然后刚好在炒股群发现，胡哥好像来过旧校区，所以就向你问问这块符印……这块铁饼的来历。”</p><p>他掏出耶罗符印。</p><p>胡彦卓扫了一眼“铁饼”上的漩涡浮雕，点点头：“原来你也对都市怪谈有兴趣。”</p><p>二人在旧校区内往深处走，空气带着清冽的湿润。</p><p>杨帝踩着碎砖，听见自己的呼吸声在空荡的楼群里打旋。</p><p>胡彦卓在前头领路，然后蹲下了身。</p><p>“砖缝里长草了。”他指尖抚过水泥裂痕中倔强的绿意，其中，还有淡紫色的小花倔强地从石缝里钻出来。</p><p>那些野花生得奇怪，叶子边缘泛着紫晕，像被某种淡色的水彩颜料浸染过。</p><p>“前年七月，这些草有膝盖高。”</p><p>胡彦卓回头看了眼杨帝，他的声音混着晨露的潮气，“我当时想，这鬼地方连野草都长得这么野。”</p><p>旧楼宇在雾中若隐若现，外墙砖面剥落处露出暗红色砖芯，那是被光阴啃噬的伤口。</p><p>清晨的旧校区，和深夜所见的完全不一样。</p><p>夜晚，它像是被弃之于荒野的文明遗迹。</p><p>早晨的校区不再是昨夜的死寂废墟，微弱晨光为它镀上了一层朦胧的生机，却也让暗处的阴影愈发深邃。</p>
