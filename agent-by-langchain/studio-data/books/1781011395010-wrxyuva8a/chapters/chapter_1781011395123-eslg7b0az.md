# 原初之战：决一生死

<p>“舰队后撤50万光年！迅速！！”</p><p>“神盾舰队维持过载输出，武库舰激活宇宙弦武器后迅速撤离！”</p><p>“左部侧翼灵能使军团全部损失……”</p><p>“注意！敌方在暗物质网络中构建出新攻击模式……”</p><p>无数道亮紫色的能量束从暗物质纤维网中迸发而出！光束所过之处，空间如同被无形的巨手生生撕裂，露出其后深邃的虚无！</p><p>被亮紫色光束击中的白矮星要塞、中子星战舰，甚至来不及发出最后的悲鸣，便在量子层面上被彻底解构，化作一滩抵达本宇宙所能允许的最大熵值、均匀飘散在真空中的基本粒子团。</p><p>即使是十四环、十五环的神级法师，竭尽全力激发联合护盾，却在接触到耀紫光束瞬间，如同脆弱玻璃轰然破碎。</p><p>“那究竟是什么攻击？”</p><p>“尚未能解明原理。现场能量读数突破探测器上限……发现向爆心回缩的空间曲率特征，检测到被展开的高维结构……”</p><p>“敌方攻击所经过的路径，似乎生成了强度极高的引力源，牵引这些能够毁灭空间结构本身的高能量波纹。”</p><p>“专家组认为，暗物质之体将路径中蜷缩于微观中的高维结构展开出来……”</p><p>“祂毁灭了时空本身，引发了整条路径上的小范围不可控湮灭……”</p><p>“除了我们的决战旗舰可以勉强抵挡一次，其他战舰，触之即亡……”</p><p>联合舰队-前线指挥部的超级计算机解析完这种新型攻击手段的原理，原初之眼已经凝聚起第二道闪耀紫色的射线束。</p><p>时空本身也随之共振！</p><p>真空几乎不存在可传播物质波的介质，但在此刻，舷窗外扭曲的时空——本该寂静无声的宇宙，此刻却回荡着震耳欲聋的轰鸣！</p><p>“嗡——嗡——嗡！！！”</p><p>刺耳嗡鸣如同实质的强相互作用力锥子，穿透真空径直刺入每位舰员的物质振动感受器官！</p><p>那声音仿佛是千万个黑洞相互吞噬，兆亿的恒星同时坍缩。</p><p>“咚咚咚咚咚！！！”</p><p>预想中，被亮紫色光束湮灭的场景并没有发生。</p><p>无限机兵——它抵挡在光束前。</p><p>周身附魔光芒爆闪，与那亮紫色死亡光束相互抗衡！</p><p>然而，原初之眼的攻势如海啸般连绵不绝。</p><p>机兵只有一挺，暗物质触手无穷无尽。</p><p>无限机兵仅仅拖延住祂95%的物质力量。</p><p>另外5%的肢体，原初之眼用来劫持了数千个星系。</p><p>霎时间，暗物质网络发出高频震颤，直径数千万光年的引力场开始扭曲成螺旋状。</p><p>数万亿恒星被无形之力牵引，在一次超距跃迁之后同时出现在不足联合舰队10光秒处位置，并在出现的那一刻就拖着万亿条光尾，以0.999999999c的超相对论速度撞向联合舰队防线。</p><p>机兵背后，由三千文明联合舰队联合打造的“星河长城”要塞群在引力漩涡中扭曲变形。</p><p>阵地最中央，超巨型灵能引擎焚天神兵尚未完成充能，就被撕裂成破碎飘絮的星尘。</p><p>杨帝瞳孔收缩，看见遥远宇宙之边际，漆黑虚空像被无形巨手撕开，无数暗物质触手裹挟着混沌能量喷涌而出，所过之处，时空极度扭曲，引力迅速膨胀。</p><p>原初之眼，祂可以用自己的暗物质触手，随意释放引力攻击了。</p><p>这说明——祂已经克服“极度不稳定的强引力场”。</p><p>联合舰队的引力波和宇宙弦攻击，已经无法伤到祂。</p><p>原初之眼的物质躯壳，只剩一个弱点——灵能法术。</p><p>但躯壳终究是躯壳。祂在无穷的历史与未来中游走，只要拥有知识，祂随时都能再造出一副完美的身体。</p><p>已经不需要再多无谓的牺牲了。无限机兵全频段广播：“所有单位，立即脱离战场，感谢诸位勇士的帮助。”</p><p>“机兵阁下，星河长城第七舰队请求殿后！”通讯频道里传来沙哑的嘶吼，夹杂着能量过载的刺啦声。</p><p>“你们的牺牲毫无意义！”杨帝不妥协。</p><p>无数时间线的残影在他瞳孔深处流转，“原初之眼已破解引力场攻击，唯有灵能法术能形成有效杀伤。可即使是你们之中最精锐的十五环神级法师，一发攻击也只能摧毁普通体积的岩石行星。”</p><p>在他视角中，宇宙之深处，暗物质触手正以超越光速的速度编织成囚笼，每一根触须都缠绕着足以摧毁星系的能量。</p><p>一个星系，平均2000亿恒星。</p><p>原初之眼……祂愈发强大了。</p><p>通讯链路沉默了片刻，而后，另一个新声音传来。</p><p>“感谢您的牺牲，机兵阁下。全体撤离。”</p><p>“那你怎么办？！”某个文明的九转大能嘶声力竭喊道。</p><p>“我会终结祂。”</p><p>空间裂隙、亚空间通道、灵能传送门在宇宙各处轰然展开，璀璨的灵能光芒如瀑布倾泻，传送光芒将灵能使的身影渐渐吞噬。</p><p>无数战舰头部搅动时空曲率，舰身周围空间泛起阵阵涟漪，伴随着刺耳的空间撕裂声，一艘接一艘消失在茫茫宇宙深处。</p><p>尽管那些神级大法师、超级文明的舰队，都能够实现超光速航行。但他们的超光速，似乎没有形成闭合类时曲线，并没有打破因果律。</p><p>玩弄因果律的特权，被无限机兵、原初之眼所垄断。</p><p>亦或者，机兵、原目超越因果的原理，根本不是简单的超光速。</p><p>杨帝驾驶机兵悬浮在战场中央。</p><p>机兵表面附魔光芒疯狂闪烁，他却伫立不动，对原初之眼冷眼而观。</p><p>暗物质触手已经编织成巨型囚笼，正向他缓缓收紧，每根触须上都散发着令人心悸的灵能，所过之处，星辰黯淡，时空扭曲得近乎崩溃。</p><p>“原目……事到如今，你我都无法击破对方的物理防御，精神攻击也一无所用。正面对决吧，来场堂堂正正的灵能对轰！”</p><p>那些曾经在不同时间节点被叠加的附魔效果，此刻相互交融、共鸣……</p><p>杨帝的现实丰度，刚刚超过25000灵，相当于1.6667个伊芙。</p><p>机兵的现实丰度，已达到10^70灵。</p><p>与机兵相比，杨帝犹如蜉蝣望烈日。</p><p>而机兵的灵能与整个无限的宇宙、和真正的“无穷”相比起来，也似萤火见皓月。</p><p>但在此时此刻，无限机兵似乎终于拥有了改写宇宙规则的潜力，触碰到了物质世界的极限。</p><p>量变真的能引起质变。</p><p>原初之眼回应了。</p><p>一道跨越百亿光年的暗物质波，自虚空中浮现，附近星云都被撕扯成扭曲的漩涡，化作中土大陆通用语悬浮在杨帝眼前。</p><p>「你若具足能力，可凭此力击杀我身。​」</p><p>宇宙深处，传来钟表倒转般的的嗡鸣，时空界限轰然裂开，露出混沌初开时的暗紫色虚空，和一抹深暗幽邃的瞳孔。</p><p>暗紫色虚空翻涌如沸腾的沥青海，无数光点自虚无中迸发。</p><p>「去岁月起点，决此一战。」</p><p>杨帝终于露出一抹笑容。</p><p>这次，他没有想着“跳出捉鳖之瓮”，没有想着敌人越是支持的战略大部分时候要反对。</p><p>他单刀赴会鸿门宴，跨入原初之眼为他打开的传送门。</p>
