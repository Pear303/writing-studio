# 倒斗与锻钢

<p>“一百年前，我爸是末日火山附近的矿工，那会儿他在末日火山附近，挖掘一种富含火系灵能的矿石。</p><p>“这种矿石用来养殖熔岩史莱姆，酿制一种熔岩麦酒。</p><p>“据说吧，那酒在矮人圈里很受欢迎，就是非常烈，特别烧喉咙。</p><p>“然后，卡利斯托坠下末日火山……接着，熔岩史莱姆暴动了。”</p><p>熔岩史莱姆打爆的矿洞，老矮人的许多工友都没能活下来。</p><p>从那以后，他爸就PTSD了，正是因为这般理由，才坚决不想让奥拓步自己后尘。</p><p>伊芙轻轻皱眉，眼中满是思索之色，喃喃道：“史莱姆向来习性温和，怎么会如此不安，乃至暴动……”</p><p>她稍作停顿，搜刮自己的库存知识。</p><p>这次，轮到瑞弗维尔抖书袋了。</p><p>他毕竟当过十几年图书馆馆长，知识储备远比常人丰富。</p><p>尤其是早年有过游侠经历，所以对这些自然现象，也有独到见解。</p><p>“很简单，卡利斯托是强大的巨龙，它的陨落，势必会引发周围灵能巨大变动。而‘熔岩史莱姆’作为最底层最基础魔物‘史莱姆’的一种，它们对灵能环境变化，非常敏感。”</p><p>图书馆馆长打了个比方。</p><p>譬如说，有一种很原始的植物，苔藓。</p><p>只要空气质量变差一点，苔藓就难以生存，率先枯萎，被喻作“空气污染的吹哨草”。</p><p>在一些空气质量差的地方，比如矮人工厂附近、“被遗忘者”聚集的亡灵废土，苔藓要么绝种，要么变异。</p><p>史莱姆之于灵能环境，就如同苔藓之于空气质量。</p><p>灵能稍有异动，它们便会做出反应。</p><p>它们要么大范围暴毙，要么原地变异成不同分支的史莱姆，比如熔岩史莱姆、草史莱姆、岩史莱姆等等。</p><p>巨龙卡利斯托的死，在末日火山附近搅起的灵能风暴。</p><p>对史莱姆而言，狂暴的灵能乱流就是场灭顶之灾。</p><p>它们因此陷入狂躁，失去原本的温顺，变得极具攻击性。</p><p>众人对此说法表示信服。</p><p>这非常符合常识与经验，而且，也是长久以来主流学界、官方民间的见解。</p><p>但伊芙眼神却有些奇怪。</p><p>“瑞弗说得挺不错，只是有可能忽略了一些内容……”</p><p>“伊娃，你能补充或者纠正一下我的答案？”</p><p>“……我说简单一点吧，当然这也只是我的猜测。”</p><p>伊芙研究史莱姆一千多年，她积累的史莱姆知识，比中土大陆上其他种族所有史莱姆学家加起来还要丰富。</p><p>要是问魔镜和神奇海螺：世上谁对史莱姆了解最深刻？</p><p>第一名是伊芙，第二名史莱姆。</p><p>她说：“其实史莱姆不只是受环境客体的影响，某些强大的主体意志，比如‘卡利斯托’，它的意志也会影响到史莱姆。</p><p>“卡利斯托作为天空霸主，陨落之际必定怀揣着强烈的情感，或是愤怒，不甘，恐惧。</p><p>“这些情感融入了灵能，而史莱姆对这种蕴含情感的灵能波动，同样格外敏感。”</p><p>众人一愣，这说法倒是闻所未闻。</p><p>奥拓挠挠头，满脸疑惑，“情感还能影响灵能，进而影响史莱姆？听起来不科学。”</p><p>在拥有魔法的异世界讲科学，是否搞错了什么。</p><p>伊芙：“如果你经常冥想，就会明白，主客体之间的界限，从来不是那么分明。”</p><p>瑞弗维尔总结：“所以，伊娃你是说，巨龙‘鬼上身’那群熔岩史莱姆，导致它们暴动？”</p><p>“我可没说鬼魂，瑞弗别瞎脑补啦。”</p><p>奥拓拍拍掌：“往事就不提了……话说，我先履行义务吧。杨帝、瑞弗维尔，你们需要我帮忙锻炼武器和附魔？我已经和父亲谈好，材料费成本费我出。若不是你们，我估计已饿死在半路，或者被铁熔堡的追兵抓回去了。”</p><p>于是史莱姆和巨龙的话题告一段落。</p><p>众人随着奥拓走进了打铁的工作室。</p><p>里面热浪扑面而来，各种打铁工具摆放得井井有条，炉火正旺，将整个屋子映得通红。</p><p>奥拓拿起一旁的风箱，用力拉动，炉火顿时蹿得更高，光芒闪烁。</p><p>首先是撬棍。</p><p>“你真的只要撬棍，不需要其他更成熟、更趁手的武器？”奥拓这个问题已经憋很久了。</p><p>杨帝连忙说：“不。不只是要撬棍，还要几块好砖头。要求是够硬，而且耐操。”</p><p>这玩意比桃木剑还好使。</p><p>虽然他们对话不在同一频道上，但客人兼救命恩人如此要求，奥拓也只好就这么行事。</p><p>毕竟他是乙方，习惯了用骚操作实现甲方的各种骚要求。</p><p>“如果你想要足够坚硬并且耐用，那我可以为你炼几块生铁砖头、一把钢制的撬棍。”奥拓与甲方交流。</p><p>炼钢，在此界并非难事。</p><p>矮人已经点出高炉技术，而许多法师也能够用相应的法术替代高炉工艺。</p><p>可对于这些个体户铁匠铺而言，要每家都配备一座高炉，又或者是精通超高温冶炼法术，那简直是天方夜谭。</p><p>高炉不仅造价高昂，且需耗费大量资源与人力来维持运作，哪是这些小本经营的铁匠铺能够承受的。</p><p>而法术，也不是人人都有天赋。</p><p>像瑞弗维尔，灵能水平五环级别，在异世界图书中算是很不错的了，相当于21世纪地球神州的中流985本科毕业生。</p><p>奥拓这种，最多只懂两三个一环法术的普通人，才是大多数。</p><p>但灵能法术的好处，就在于其仍然具有很强的“物质性”。</p><p>只需要引导灵能，按照特定的顺序和方向流动，就会产生相应效果。</p><p>比如杨帝，他体内“灵能/现实丰度”极低，但也能通过强大无比的精神，强行引动环境中的“灵”。</p><p>而不需要消耗自己的灵能。</p><p>奥拓也一样，他本身灵能水平不高，但能够借助工具，以一种别样的方式实现类似法术的效果。</p><p>就拿眼前这附魔了的锻锤和熔炉来说，它们便是奥拓的左膀右臂，左腿右脚。</p><p>这把锻锤被刻录了符文。</p><p>当奥拓握住它，用力挥动砸向金属时。</p><p>碰撞会产生“压灵效应”之类的东西，就和地球上的“压电效应”类似吧。</p><p>它能提供“引燃干草堆的第一根火柴”。</p><p>符文便会被激活，多米诺骨牌效应，小范围地吸收周围灵能，释放出一股微小却精准的灵能脉冲。</p><p>这股脉冲能够巧妙地渗透进金属内部，将那些隐藏其中的杂质，像驱赶顽皮小兽般，一点点地剥离出来。</p><p>“你们退后点！”</p><p>奥拓福至心灵，铁锤在空中划出玄奥轨迹，一个“乱披风锤法”使出！</p><p>砰砰砰砰几声，比阿美莉卡的街头枪战还要激烈，火星四溅，金属在奥拓的锤击下，仿佛有了生命一般颤抖！</p><p>杨帝用护盾护着众人站远。</p><p>虽然非常不明白，矮人那浓密胡子这么近距离为啥没被火星点燃。</p><p>但对方看起来很熟练，胸有成竹，看来确实如他爸所说，他是个当铁匠，锻好钢的苗子。</p><p>只可惜奥拓的意愿是倒斗，划掉，考古。</p>
