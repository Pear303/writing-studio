# 灵能训练

<p>像是每一部三流幻想小说那样，中部大陆的各项职业也有等级划分，大致分为佣兵、职业、英雄、传奇、超限。</p><p>也不是随随便便就能评的，得去考试，包括笔试加实操，考异常多的试，极其繁琐。</p><p>因为考试很麻烦，得做大量题，还得交报名费。</p><p>所以，真正的境界划分反而是这样的：</p><p>佣兵、职业、英雄、传奇、超限/佣兵。</p><p>真正的强者，不屑于去考试。他们虽也是有“超限”的水平，在程序上仍然是“佣兵”。</p><p>许多大佬都喜欢谦称自己是菜逼八，可以说是文明进入现代社会后，会越来越普遍存在的谎言。</p><p>伊芙拍拍杨帝肩膀：“第一种锻炼‘灵容量’的方法，我小时候也经常用——用法术托举重物，定向越野。”</p><p>“您练了多久？”</p><p>“也就短短四五百年，这种锻炼方法便进入瓶颈了，很难再进步。”</p><p>伊芙把瑞弗维尔塞进轿厢，最后自己也坐进去。</p><p>这轿厢是矮人工艺，遵循的是矮人标准，所以天花板特别矮，他们都只能坐到地板上。</p><p>精灵伸出手拍拍轿厢：“司机，开。”</p><p>杨帝深吸一口气，集中精神，引动灵能，旋风术与浮空术几乎同时施展而出。</p><p>周围狂风呼啸，这股气流却极为听话地簇拥着轿厢，朝着伊芙所指的方向飞速前行。</p><p>靠纯粹的风力本身，不足以托举起这么重的车和人。</p><p>实际上，“旋风术”是用于减少空气阻力，而“浮空术”稍加改进就可以扭转其方向，提供一个斜向上的力。</p><p>两种法术结合，再多释放十几个，增大冗余量和推动力，不容易翻车。</p><p>“你们好重。”他说。</p><p>伊芙探出头：“小子，我把你轰杀至渣呀！”</p><p>杨帝自己也坐上了轿厢顶部，心神则完全凝聚起来，控制轿厢姿态。</p><p>在他努力下，轿厢如流星在大地上飞驰。</p><p>“感觉这没什么难度吧。”杨帝还算轻松。</p><p>“非常好，那现在正式开始第一个练习：天上突然开始下火鸡雨！”</p><p>刹那间，天空仿佛被点燃。</p><p>“杨帝！速度不要慢下来！”</p><p>伊芙手一挥，无数由火焰凝聚而成的鸟铺天盖地般朝着杨帝冲来。</p><p>“居然是这种火鸡！！”</p><p>这些火鸟周身烈焰翻腾，尖锐的啼鸣声仿佛要将空气都灼烧殆尽。</p><p>它们眼眸中闪烁诡异红光，锁定杨帝。</p><p>杨帝咬了咬牙，脑海中飞速检索毕生所学，最终选定了一个较为合适的——冰风暴术。</p><p>冰棱与火鸟碰撞在一起，发出阵阵爆鸣！火焰与寒霜摩擦摩擦，天地间冰火交融，景象蔚为壮观。</p><p>但火鸟数量实在太多，尽管冰风暴术成功阻挡了一部分攻击，仍有不少火鸟突破防线，朝着杨帝冲来。</p><p>“哇呀！当量不够，数量来凑。”</p><p>再次凝聚灵能，纯手搓出连续20个强力的风刃术，将突破封锁线的火鸡剁成麻辣鸡杂。</p><p>但个人之力有限，终究还是力不从心。</p><p>最后，杨帝头发被烤焦了，嘴里喷烟。</p><p>伊芙弹出上半身，两条胳膊交叉：“错啦错啦！大错特错。”</p><p>精灵伊芙强调，灵能法术的应用，讲究的是对矛盾的巧妙处理，其中包含对抗性矛盾与非对抗性矛盾。</p><p>人与火鸡之间的矛盾，原本是是非对抗性矛盾。</p><p>然而，你用冰锥、风刃去硬碰硬，这么一整，硬生生将非对抗性矛盾升级为对抗性矛盾。</p><p>你不应该上来就下狠手，把它们都吓坏。</p><p>你要和火鸡握握手，亲切地问候它们：在天上飞得舒服吗？生活上有没有什么困难？</p><p>你自己都发现，魔法的精髓是顺应自然。</p><p>但你在实操时，到底有没有做到这一点？</p><p>灵能法术不只是解释世界的学说。</p><p>它还有更坚重的使命——通过人的主观能动性，改变世界，创造未来。</p><p>伊芙看着杨帝抽动的眼角，轻轻一笑，继续说道：“你看啊，这些火鸟由灵能所化，本质上与你的灵能同源。就如同一条大河分流出来的两条小溪，本不该针锋相对。”</p><p>“呃，我再想想。”</p><p>他摒弃了之前对抗的念头，尝试着换一种思路。</p><p>脑海中回想着伊芙的教导，将灵能以一种更为柔和的方式释放出来……</p><p>轿厢周围，构筑起一层流线型的空气护盾。</p><p>护盾是一层高速流动的气流，流动方向是轿厢后方。</p><p>那些轻飘飘的火鸟，顺着他所引导的气流，恰到好处避开了轿厢，纷纷向后飞去。</p><p>10公里过去，越来越多的火鸟被成功导流。</p><p>杨帝感觉到，自己对灵能的操控愈发熟练，那种与灵能融为一体的感觉也愈发强烈！</p><p>属于「自己」的灵能强度提升了0.2%！真是进步显著，显显又著著。</p><p>伊芙微微有些惊异：“这悟性也高得有些离谱了……我只是一提点就明白了要做什么……”</p><p>杨帝只能报以嘿嘿一笑。</p><p>他站在巨人肩膀上——地球上的高铁、飞机和火箭的气动外形，都可以作为参照。</p><p>好巧不巧，他脑子里也有几十本关于流体力学、空气动力学、空气动力设计的书籍。</p><p>虽然短短十几分钟，并不足以让杨帝完全理解并吸收。</p><p>但也够他读完讨论，并且从插图里面，截取几个比较典型的气动外形，为己所用。</p><p>伊芙拍拍手：“那现在开始第二个练习：春回大地，地上长出大量石笋！”</p><p>尖锐的石笋如雨后春笋般破土而出，向着轿厢迅猛刺来。</p><p>石笋表面粗糙，泛着冰冷的光泽，随便掰下来就是柄漂亮的石刀刃，天然自带「锋利II」附魔。</p><p>杨帝瞳孔抖动，心思电转。</p><p>他继续调动灵能，继续磨炼法术。</p><p>……</p><p>某人坐在轿厢顶部艰苦奋斗之时。</p><p>轿厢内，瑞弗维尔又凑在精灵伊芙耳边说着什么话。</p><p>“伊娃……我在图书馆当馆长那段日子，曾经从角落淘到一本野史……据说圣古琉斯一世国王没有隐瞒他早年开国前的经历，是因为……”</p><p>“呵呵哈哈咯咯咯……”</p><p>伊芙一边捂着嘴笑起来，一边朝车外勾勾手指。</p><p>霎时，灵能轿厢外又传进狂风暴雨的呼啸之声，整个轿厢也抖了三下。</p><p>“杨帝，稳一些。”</p><p>“我知道，但我更认为，您应该出来看看现在这情况……”</p><p>杨帝的声音罕见地带着些担忧。</p><p>而他的担忧也不无道理。</p><p>轿厢外除了狂风暴雨的呼啸，果然还有阵阵令人毛骨悚然的尖细声。</p><p>尖细的啸叫越来越刺耳。仿佛从九幽地狱传来，尖锐得能刺穿人的耳膜。</p><p>紧接着是一连串密集的破空声，如同无数利箭在空气中穿梭。</p><p>伊芙打开轿厢门，探身出去查看情况。</p><p>她看见漫天飞舞着紫黑色“蝠鲼”。</p>
