# 我，域外天魔！

<p>她身着一袭月白色的长裙，裙摆随风舞动，上面绣着的九尾狐图案栩栩如生，仿佛随时都会破布而出。</p><p>“哼哼哼，光头和尚竟然没猜错，真有域外天魔偷摸到了凡界。在下‘青丘白璃’，你们的目标是我！”</p><p>“慢着，女士，此言差矣。”</p><p>事已至此，杨帝也只能装出风度翩翩的菌子气质，试图从眼前这位异世界土著、狐种大妖的口中套点情报。</p><p>杨帝整理了下衣襟，唇角勾起一抹从容的笑，“我们并非域外天魔，只是来自其他世界的旅人。我叫杨帝，白杨大帝。他是59改，这位是阿巴。阁下仅凭一面之词便将我们定罪，未免有些草率。”</p><p>杨帝熟读《识人树》和《社交的脚腕》……不过这些并不值得一提。</p><p>更重要的是，在人物面板中，他的“话术”点数超过1500亿！</p><p>此时此刻承认自己来自其他世界，并非孤注一掷地爆了，而是理性抉择。</p><p>为什么大方承认自己是异世界之人？</p><p>因为穿越现象似乎并不罕见。</p><p>暂且不提绝对观察者-原初之眼，甚至只是活了1600多年、还没走出行星的伊芙，都碰见过穿越者。</p><p>为什么不故技重施说自己失忆了？</p><p>因为对方并不是瑞弗维尔那样平平无奇的无名小卒、跑龙套、茄喱啡、群演、路人甲，而是媲美阿巴和59改的土著强者。</p><p>说一个谎言，就要用更大的谎言圆过去。如果最后谎言全部戳破，会引起比较大的外交事故，不利于多世界和谐交流团结发展。</p><p>为什么不开无双？</p><p>“无限机兵”是其中一方面的潜在威胁；另一方面，杨帝本身是个大善人。</p><p>就算今天有二十个大汉跳出来，手持猫王榴莲打劫他，杨帝至多也只会让对方达到重伤二级水平，譬如肢体离断、膝关节活动功能丧失、实质性脏器的破裂、肺部破裂充血等，并不会进一步造成更大伤害。</p><p>这，就是自律的男人。</p><p>但是，狐狸妹子似乎不领他的善意。</p><p>客栈掌柜怀抱琵琶，指尖轻轻拨弄琴弦，发出一声泠泠之音，一边轻声道：“莫以为能蒙混过关，尤其是中间打头那个梳着中分、穿着奇怪衣服的人形天魔，你身上的灵能强度，已经暴露了一切。”</p><p>灵能？灵能怎么了？</p><p>杨帝看向自己的人物面板。</p><p>得益于“补完计划”的圆满成功，他现在坐拥10^110数量级的现实丰度，如斯恐怖。</p><p>不用说抬手施法，即使是普通地动动腿毛，都能字面意义上的摘星换月，劈天裂地。</p><p>杨帝自认为没有异常。</p><p>然而，此时此刻，本就毛发不多肌肤光滑的阿巴蓦然炸毛，而59改也闪退至10米外摆出古武机甲风格的作战姿势。</p><p>阿巴化作人形的手指不受控地颤抖：“老老老老大！你的灵能……怎么……我词穷……”</p><p>杨帝一头雾水地看向二人：“嗯？”</p><p>「对个体‘杨帝’检测出现异常，目标灵能读数为非常规值，自检中……已确认错误形式，灵能读数数据类型非法：负值……逻辑错误，正在启动数学率机器……本宇宙法则环境偏离，重新校准数学率，预计需要144小时……」</p><p>59改看起来宕机了。</p><p>散热器传出硅脂烤焦的气味。</p><p>杨帝愈发困惑了：“59改，你是说‘负值’？灵能怎么会是个负值？”</p><p>“对！！负的！！！老大你是负的！！！”阿巴蹦起来，鳍舞鳍蹈夸张地大叫起来。</p><p>杨帝只觉心脏突突直跳。</p><p>眼前，59改不断冒出乱码数据流变成实体的弹幕在空中乱飞，阿巴头发炸成蒲公英状在那发出犬科动物拟人般的乱叫。</p><p>负数的“灵能/现实丰度”？</p><p>就好比说负数的开尔文温度，负数的物体个数，负数的圆周率……</p><p>即使是能够操控法则的太乙真仙，能够扭曲物理参数的数学率机器，也从未见过如此违背万物底层逻辑的存在。</p><p>尽管杨帝自我感觉良好，自己眼中的自己一切正常。</p><p>但在本宇宙，站在此地，他人眼里看来，自己似乎是个不可名状之物。</p><p>不可名状……？</p><p>“不可名状”这么廉价的吗！</p><p>“别在那诈傻扮懵。就像你并非域外天魔，你也是满怀恶意的天外来敌。”</p><p>客栈掌柜的琵琶弦再次紧绷，狐火在指尖明灭不定，将她的影子扭曲地投在雕花廊柱上，像是某种不祥的谶语。</p><p>杨帝也开始爆气：“天外来敌？满怀恶意？我觉得我们应该先停下来好好谈谈，毕竟交流合作是人类文明发展至今仍然繁荣的基础。”</p><p>眼前这狐狸人，战斗力数值超过1亿2000万（异界本地评价体系，不是杨帝评价体系），相当于超级赛亚人。</p><p>能不打就不打。</p><p>“你说得对，交流合作是人类文明发展至今仍然繁荣的基础，但本座不是人类。”</p><p>自称青丘白璃的狐种大妖将琵琶横抱，指尖勾住琴弦猛地一拽，檀木琴身竟发出电吉他般的刺耳啸叫。</p><p>她踩着夸张的摇滚步甩了甩银白长发，九尾在空中甩出残影：“真仙领域——诛魔破阵曲·重金属版！”</p><p>诛魔破阵，未见前奏，先闻solo。</p><p>她身后九尾虚影冲天而起，化作五光十色的光轮将整片天空割裂，琵琶共鸣出的音波在虚空中凝成实质的波浪形。</p><p>一声清喝，方圆百里的空间开始扭曲折叠，无数道虹色光墙从四面八方升起。</p><p>杨帝感受到领域内骤然暴增的压力，腿毛开始不自觉地抖动起来。</p><p>青丘白璃的战斗力数值，瞬间突破5亿！</p><p>“阿巴！59改！你们先走。”鲈鱼和坦克还没来得及反应，就被一股巨力推出领域范围。</p><p>“哇呀！老大！”阿巴一边不舍得呼唤杨帝，一边飞快逃跑。</p><p>她肩上还扛着个为人方正的国字脸坦克，正是莫名其妙宕机冒烟的59改。</p><p>……</p><p>客栈掌柜·青丘白璃的领域“诛魔破阵曲”内。</p><p>三十六条狐尾流淌着七彩霞光，织就成瑰丽的光网，将整片空间浸染成梦幻的琉璃色。</p><p>——她表面上是九尾狐，实际上有36条尾巴，这就是战术欺诈。</p><p>杨帝明显感知到自己能受到轻微损伤，心头划过一句「现实+1」。</p><p>料想不到，本地土著全力一击竟然能伤到自己的一根毫毛，只能说如斯恐怖。</p><p>此时此刻，杨帝身处这片被瑰丽光芒充斥的领域。</p><p>他敏锐地察觉到，一股奇异而陌生的力量在四周弥漫开来。</p><p>正是这股力量，正在试图定义他，塑造他，将他容纳进“领域”之内。</p><p>但除了对他造成「现实+1+1+1」的微小损伤，再没有更大战果。</p><p>杨帝抬头。</p><p>“领域”内，空间呈现出诡异的扭曲感。</p><p>原本平整的地面仿佛变成了一块被顽童肆意揉捏的橡皮泥，时而隆起如山岳，时而凹陷似深谷，毫无规律可言。</p><p>光线在这里也不再遵循直线传播的常理，而是如灵动的蛇般蜿蜒穿梭。</p><p>各色幻光，在各个不规则的表面上反射、折射，如梦如幻，目眩神迷。</p><p>杨帝试着挥动一下手臂，却发现周围空气阻力变得极为奇特。</p><p>不像是在正常空气中那般轻盈顺畅，也并非如在浓稠液体中那般阻力巨大。</p><p>而是一种难以言喻的、仿佛带着某种意志的阻碍，仿佛这片空间本身在抗拒他的动作。</p>
