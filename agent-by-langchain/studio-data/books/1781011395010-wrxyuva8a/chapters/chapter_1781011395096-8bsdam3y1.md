# 补完计划略微受挫

<p>对一般人来说，都是灵能的提升速度跟不上消化速度。</p><p>而杨帝正好相反，“灵”的提升吸收太快，消化速度反而跟不上。</p><p>最理想状态下，他达到1.5万灵，需要246年多。</p><p>而根据伊芙所说，她自己到达这个水平花了1600年。</p><p>精灵的这个速度已经堪称恐怖了，从小就是别人家的精灵孩子，什么百里挑一的天才，凤毛麟角的存在，各种名誉加身。</p><p>没想到，世上还有人类能比她更恐怖。</p><p>伊芙耸耸肩：“我有换位思考意识——我说的‘很多很多时间’是相对人类而言，而不是相对精灵而言。”</p><p>246年，漫长的岁月。</p><p>要知道，天下无敌、四处收狗、随手一记“皇恩碎地拳”就能打爆万物的大明，国祚也不过276年。</p><p>在正常情况下，他得活一整个大明国祚，才能达到伊芙的力量！</p><p>杨帝没有想过，在异世界待到地老天荒。</p><p>他从不确定，自己能否进化到连寿命上限也被拔高到几百年的水平。</p><p>试错成本有点高……等等。杨帝想起来个事儿。</p><p>“灵能的提升速度跟不上‘消·化’速·度。”</p><p>消化……消化……</p><p>杨帝瞳孔猛地收缩。</p><p>他自然永远不会忘记一切的开端——他吃下某种劣质饭食，消化不良，而后急性肠胃炎。</p><p>但在那之后，他牙口和肠胃都变得特别好。</p><p>能够进化到免疫很多劣质食品对身体带来的“伤害”。</p><p>“主体溶解”，也可以定义成一种伤害？</p><p>被伊芙判定为「主体溶解」的异常状态，在他脑海中呈现出全新的轮廓。</p><p>如果这是一种伤害——就像之前遭遇的刀刃威胁、法术轰击、蘑菇毒素一样，那他的适应能力岂不是，能将其“消化”掉？</p><p>杨帝曾经生吃了被质壁分离的狸花猫和大老鼠。</p><p>那些蠕动的黑色拉面，说实话，味道不太好，有一种生吃“康复新液”原料的口感。</p><p>“黑色拉面”味道极为浓烈，初尝时舌尖感到一丝涩意，口感与嗑瓜子时留下的皮相似。随后，黑色拉面在舌齿间挣扎抽搐，把牙齿刺得叮叮哐哐作响。若将其咬开，便会爆发出酸、辣、涩交织的汁液。</p><p>特别是将这些黑色拉面吞下后，他感觉到，构成自己身体的物质试图崩解，手臂上的汗毛、小腿上的腿毛，都开始不稳定地扭曲。</p><p>再坚持多几秒，他就将其适应了。</p><p>也没有患上第二次急性肠胃炎。</p><p>那时候，杨帝便已发现，当自己的“攻击力”不足以杀死敌方时，他可以选择把敌方吃掉。</p><p>肠胃将会自动适应、消化对方。</p><p>并不断进化出更强力，用途更广泛的消化功能。</p><p>或许可以类推——如果他的进化能力，可以适应“主体溶解”，那么刷等级刷属性的速度将会大大大大幅提升。</p><p>“伊芙，你说的主体溶解，能具体描述下过程中身体承受的物理层面反应吗？”杨帝抹去嘴角血迹，目光灼灼。</p><p>精灵愣了愣，合上笔记本：“理论上是灵能过度冲击导致的意识混沌，具象化表现为感知错位、精神层面的涣散、人格分裂、精神失常。</p><p>“除了这种实质性伤害，还有主客体界限模糊，自身的‘个人现实’陷入崩溃，丧失自己的主体性，失去‘自我’的概念。</p><p>“甚至有理论模型指出，主体溶解会招致更高层面的泯灭，比如你的存在本身从这个世上抹去，人们只能勉强记住你的一部分……”</p><p>原本杨帝还带有希望。现儿越是听，心里越没底。</p><p>他能明显听出来，这种“伤害”，比纯粹的物理化学生物以及精神伤害更高。</p><p>“主体溶解”在理论上能够抹除人的存在……就像杨帝，曾经被删除了一切社会关系。</p><p>这是一种更形而上的伤害。</p><p>而且，他有耶罗大仙的前车之鉴——杨帝的“灵”被撕裂过一部分，却没有触发相应规模的超量代偿。</p><p>他事后分析原因，认为是：诸如银行账户、论坛账号、学生资料等等，虽然是构成他“现实”的一部分，但从直觉来看，不属于自己“身体”的一部分。</p><p>而是一种“客体”，外物。</p><p>所以这部分“灵”，就被那个黄衣邪神成功劫取，吞噬。</p><p>如果自己也“主体溶解”了。</p><p>那么原本属于自己的“主体”，也许会溶解在周遭的外物中，成为不属于他自己的“客体”。</p><p>耶罗无法杀死他的头发，却能杀死他的银行账户。</p><p>主体溶解对杨帝就有了极大的风险——他可能会把属于自己的主体部分，都溶解成类似于银行账户、学生资料、身份信息的“客体”。</p><p>从而，无法触发无限进化与适应的能力。</p><p>然后，被真正被杀死。</p><p>所以，不到十死无生的绝望之境，杨帝并不打算冒险过多冥想，不打算一次性跟吹瓶子一样吸纳过多灵能。</p><p>地球有句俗语说的好，搏一搏单车变摩托。但世人只看到单车变摩托，看不到九成五的人都把单车赔进去，两手空空了。</p><p>到时候不仅没能完成「杨帝补完计划」，反倒将自身所剩无几的现实，消融稀释在环境中。</p><p>如何“补完”自身的现实，这是杨帝当下的历史使命。但他只能另寻出路。</p><p>伊芙往本子上刷刷地写字：“接下来我还会问几个问题，你同样坦白从宽便可。”</p><p>地窖又传来夜魅的呼啸，和瑞弗维尔嗷嗷嗷的砍杀声。</p><p>杨帝摸了摸自己的脸：“我身体还有什么不正常的地方吗难道。”</p><p>“并不，我只是获取一个刚半只脚踏入‘主体溶解’案例的一手资料，你这情况够我撸五篇学术论文。”</p><p>“伊芙，你不是说，你是研究史莱姆社会关系的么？”</p><p>“懂不懂什么叫跨学科融合。”</p><p>漫长枯燥且问了很多奇怪问题的访谈终于结束了。</p><p>期间，外边一直传来夜魅的呼啸与瑞弗维尔的砍杀声。</p><p>伊芙却说，没什么的不用担心，让瑞弗他一个人再搏斗一会儿吧！</p><p>“虽然你师傅我求知若渴，但我始终恪守一个原则，而你也应该记住这个原则。”</p><p>杨帝：“您说。”</p><p>“世界很大，生命渺小，你应对一切未知保持敬畏。如果你想要强行吃下整个世界，必遭其反噬……”</p><p>“怎么突然灌起睡前鸡汤来了……”</p><p>历经风波，渡尽劫难，杨帝终于睡上四天以来的第一场觉。</p><p>在他入梦那一刻，原本还在纠缠瑞弗维尔的几只夜魅啸叫一声，调头飞走，消失在阴风怒号的夜空。</p><p>瑞弗终于免费了，不需要再继续看门。</p>
