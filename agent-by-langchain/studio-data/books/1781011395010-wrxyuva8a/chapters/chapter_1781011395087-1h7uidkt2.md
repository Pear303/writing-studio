# 人形自走速射炮

<p>瑞弗维尔一瞬间理清了来龙去脉。</p><p>圣光教廷的人将他们勾引到火山底部，让诈尸的卡利斯托对付二人。</p><p>教廷的人则隐藏在山壁中，瞅准时机，拦截住意图逃跑的他们！</p><p>此刻，一道道带着神圣力量的光束，如流星般射向杨帝和瑞弗维。</p><p>其中20道，精准地击中了他们下方的旋风法术，法术冲击力瞬间破坏了旋风的稳定性。</p><p>狂风一阵紊乱，杨帝和瑞弗维尔失去了上升的动力！</p><p>他们直直地向着下方坠去，伴随着“轰”一声巨响，重重摔落在地。</p><p>熔岩史莱姆被压在下面，发出一阵痛苦的“咕噜噜噜”声。</p><p>但它是史莱姆，所以坠落伤害本身不是多大事。</p><p>真正让它吃痛的，是趴在它身上的人。</p><p>杨帝早已预见了这般情况，提前让瑞弗维尔趴在了熔岩史莱姆身上。</p><p>利用弹性极好的史莱姆作为缓冲垫，吸收大部分坠地的动量，瑞弗维尔才没有当场摔成番茄肉酱。</p><p>而杨帝则没那么幸运。</p><p>他头朝下，砸在一块锋利的岩石上。</p><p>瑞弗维尔悲恸：“杨——帝——！”</p><p>趴在地上的地球人抬起手，表示自己OK。</p><p>没死就好，近战法师的身体果然抗揍。</p><p>还没等他们缓过神，卡利斯托那沉重的脚步声再次传来！</p><p>瑞弗维尔拖着杨帝逃跑，一边怖惧万分地扭头看去。</p><p>卡利斯托巨大的头颅缓缓转动，空洞的眼窝中，两盏紫色鬼火愈发旺盛地燃烧着。</p><p>它死死地锁定了瑞弗维尔和杨帝，仿佛在注视着两只微不足道的蝼蚁。</p><p>那眼神中所蕴含的冰冷与残暴，让图书馆馆长的灵魂都忍不住为之颤抖。</p><p>卡利斯托身上所散发出来的龙威，如同实质化的风暴，不断冲击着他的意志！</p><p>教廷的人，也从山壁上纷纷现身。</p><p>他们围拢起来，形成了一个密不透风的拦截网，阻止他们从上方的火山口离开。</p><p>“只有一个办法了。”</p><p>瑞弗维尔摸向衣服内衬。</p><p>瞳孔形状的石头雕塑。</p><p>在指尖碰到那块坚硬冰凉的物体时，瑞弗维尔似乎明白——这雕的是什么玩意了。</p><p>“这是……原初之眼雕像？”</p><p>他立刻联想到最后一幅壁画。</p><p>这么危险的东西，他之前却滥用了几十遍，而毫无自知！</p><p>所以，还要用吗？他们已经没得选……</p><p>但在瑞弗维尔正式掏出石头雕像的前一刻。</p><p>他的肝胆几乎被另一个突然爆发的狂暴气势所炸裂——</p><p>杨帝，他站了起来，拦在瑞弗维尔和卡利斯托之间，双眼圆睁，魔力如同沸腾的岩浆般汹涌澎湃！</p><p>刹那间，二十枚散发着幽蓝光芒的奥术飞弹在他掌心凝聚成型！</p><p>杨帝热衷于数值。虽然每个法术都很简单，但他相信量变能够引起质变。</p><p>二十枚飞弹，每一枚都同时混杂旋风术、驭火术！随时都会炸裂开来。</p><p>瑞弗维尔瞳孔震动。</p><p>这里的每一个法术，都不超过3环。</p><p>但有能力将它们同时施展，并混合、叠加起来，难度呈几何上升，但同时威力、效果也会暴增……</p><p>杨帝大喝一声，将奥术飞弹猛地推出！</p><p>奥术飞弹在旋风与火焰的裹挟下，如同一群疯狂的猛禽，劈头盖脸朝卡利斯托糊了过去！</p><p>一时间，整个火山底部都被这绚烂而又恐怖的法术光芒所笼罩。</p><p>卡利斯托似乎也感受到一丝威胁。</p><p>它那巨大的身躯微微后仰，张开血盆大口，发出一声震天动地的咆哮。</p><p>“吼吼吼！！”</p><p>这咆哮声如同滚滚雷霆，在火山内部不断回荡，震得众人耳膜生疼。</p><p>然而，杨帝发出的攻击已来到它面前。</p><p>它那青金色的鳞片上，爆发出一朵朵蓝色的魔力火花，每一次爆炸都让卡利斯托的身体微微一颤。</p><p>两秒17发。</p><p>纵使是焚灭天空之龙，在这一刻居然和杨帝只能打个五五开！</p><p>卡利斯托在火焰与旋风中扭动，它巨大的翅膀猛烈扇动。</p><p>强大的气流在火山底部肆虐开来，瑞弗维尔紧紧抓住身旁的一块岩石，才不至于被这股狂风吹走。</p><p>瑞弗维尔方才根本没预料到，失忆的杨帝居然还有这么强的战力！</p><p>实锤了，他绝对是一尊传奇法师。既然如此，石头雕塑能不用就不用，毕竟可能会误伤队友。</p><p>而且，“原初之眼”这东西还是很晦气的，说不定有什么潜在的副作用，比如用多了会导致脱发什么的。</p><p>瑞弗维尔抱着熔岩史莱姆，在大后方走位躲起来，不给杨帝添麻烦。</p><p>“兄弟！制空权！”他疾呼。</p><p>杨帝听到瑞弗维尔的呼喊，心中明白。</p><p>“瑞弗维尔！山壁上那些发光的，那就是你商业竞争对手派来追杀你的刺客对吧！”</p><p>“呃……没错！你可以这么理解。”</p><p>没想到一群卖汽水的资本家，有能力重启已经荒废数千年的末日火山旅游景点，有能力将卡利斯托复活，还豢养了如此多高素质私兵……这根本就是军阀。</p><p>此刻的杨帝，宛如一尊人形自走速射炮。</p><p>他全身魔力激荡，头发在强大的魔力气流中肆意飞舞！</p><p>两秒17发的恐怖射速，使得奥术飞弹如同密集的雨点，不间断地朝着卡利斯托倾泻而去。</p><p>他一边维持着对卡利斯托的火力压制，让混合着旋风术与驭火术的奥术飞弹如连珠炮般不断射向巨龙。</p><p>一边分出一部分灵能，对山壁上的阻拦者展开反击。</p><p>他瞅准时机，迅速抬起一只手，转而对着山壁上的拦截者扫射！</p><p>“轰隆隆隆隆隆隆隆！！”</p><p>杨帝指尖光芒大盛，一道道蕴含着强大魔力的奥术飞弹如火神炮子弹般射出。</p><p>飞弹所到之处，光芒炸裂，山壁上顿时碎石飞溅。</p><p>然而，山壁上那些人，也不是等闲之辈。</p><p>他们支撑起金黄色护盾，轻而易举挡下了杨帝射来的奥术飞弹。</p><p>护盾表面泛起一圈圈金色涟漪，将爆炸的冲击力和四散的魔力，尽数消解抵挡。</p><p>说到底，只是普通的三环法术，奥术飞弹，并不能造成很大杀伤。</p><p>虽然声光效果酷炫，场面宏大壮观，但对于五环六环以上的法师而言，构不成致命威胁。</p><p>瑞弗维尔躲在大后方观察。</p><p>他目睹了全程，眉头微皱。</p><p>不太对……这实在是，怎么说……别扭。</p><p>他对着杨帝疾呼：“兄弟！这个‘卡利斯托’太弱了！仅仅是外表一样！实质上是赝品！！”</p><p>杨帝闻言，瞳孔微微一缩。</p><p>确实，太弱了，甚至能被“三环法术·奥术飞弹”用数量压制。</p><p>如果历史中，焚灭天空之龙真就这么弱，它还不配作为这片大陆的灭世灾难。</p><p>而且……眼前的龙，始终贴地面行走，而不选择飞起来，一对翅膀好像是充话费送的摆设。</p><p>它仅仅只是在两秒17发的火力下，就被打压得抬不起头。</p><p>你可以说2秒扔17颗石头很有气势。</p><p>但不能说，只要扔的石头够多，就能对一辆主战坦克造成伤害了。</p><p>现实里，是没有“血条”这一设定的！除非你把石头扔出个一两马赫，否则主战坦克的装甲永远刮不花。</p><p>“但就算发现是假的卡利斯托，对战局也没有丝毫影响……”</p><p>因为杨帝的火力压制，很快就维持不住了。</p>
