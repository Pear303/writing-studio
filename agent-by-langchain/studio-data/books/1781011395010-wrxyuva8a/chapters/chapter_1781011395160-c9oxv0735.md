# 攻壳机动队

<p>他缓缓抬起手，五指微张，没有惊天动地的声势，也没有撕裂空间的力量爆发。</p><p>防止整个主机都会被他撑爆。</p><p>他动作带着极致、精密的控制力，仿佛在对待一件脆弱无比的琉璃器皿。</p><p>一股无形无质，却足以改写虚拟沙盘底层规则的力量，精准切入祭坛核心。</p><p>磁场转动，100匹！！</p><p>在赛博虚拟世界里，用磁场力量自然是如鱼得水，浑然有如天成。</p><p>“磁场转动之力”，更是直指虚拟沙盘“天道本源”。</p><p>毕竟以凡界的技术力，建造一个虚拟世界，本质还是电磁数据、软硬部件的交互。</p><p>就好比用强磁铁靠近传统机械硬盘，能轻而易举地扰乱磁盘内的磁性粒子排列，从而抹除数据。</p><p>但此刻杨帝所做的事情，远比用强磁铁消磁更复杂，更困难。</p><p>首先要将人体磁场转动到100匹……好吧，实质上就是大力出奇迹。</p><p>他五指一握，将阴伏流煞顷刻消抹。</p><p>这里的“阴伏流煞”因为还没进化成域外天魔，所以非常容易解决。</p><p>“搞定，引信掐了。”杨帝拍拍手，转过身，看向苍穹那道狰狞的“ERROR”裂痕。</p><p>裂隙之外，并非璀璨星河，而是更深沉、更混乱、仿佛能吞噬一切的……凡界主机。</p><p>这个虚拟沙盘的刷新频率是300帧，通过算法将贴图纹理细节填充至微米级别。</p><p>杨帝捡起一块石头，在掌心用力一捏，变做齑粉。</p><p>他眉头一皱。这个虚拟沙盘，徒手捏出核爆炸都做不到吗……</p><p>虚拟世界的精度，和现实世界比起来，刷新频率还是太卡顿，画质仍然太模糊，物理规律和灵能法则仍然太粗糙。</p><p>杨帝抬起头，目光穿透虚拟世界的苍穹，投向了某个更遥远、更本质的层面。</p><p>现在，有非常大的可能性，可以确认归墟大帝并不是失踪，而是货真价实、童叟无欺的死亡。</p><p>一切问题归结于两个问题。</p><p>第一，大帝是怎么死的？</p><p>第二，大帝为什么把“阴伏流煞”交给虚拟沙盘中的数字生命？</p><p>……</p><p>画面一转，虚拟沙盘外的主机大厅。</p><p>刺耳的警笛声早已被强行切断，只留下应急灯惨绿的光晕，在金属墙壁和服务器阵列上无声流转。</p><p>空气里弥漫着臭氧、过热塑料和一种名为“绝望加班”的混合气味。</p><p>先前被“龙组”特派员，以及他们口中骇人听闻的“半人马座摄影师”、“黑蜥蜴星人间谍”冲击得七荤八素的工作人员们，正三三两两地瘫坐在控制台前。</p><p>眼神空洞，精神恍惚。</p><p>这可不只是加班加多了。</p><p>更是有三观崩塌、试图重组时的心力交瘁。</p><p>秃顶程序员机械地往嘴里灌牛马咖啡，试图压下世界观崩塌带来的眩晕感。</p><p>技术主管则对着控制台，凝视依旧闪烁的几处黄色告警灯，愁眉苦脸。</p><p>就在这片劫后余生般的死寂中，合金闸门无声地向两侧滑开。</p><p>没有警报，没有通报，只有一股凛冽如西伯利亚北极寒流（当然，凡界没有西伯利亚，也没有北极）的气息，瞬间灌满整个大厅。</p><p>一行人走进来。</p><p>为首者，身形高挑纤细，包裹在哑光黑色、线条凌厉的紧身作战服中。</p><p>步伐无声，每一步都带着精确到毫米的机械韵律。</p><p>她的脸孔是精心雕琢的完美，皮肤光滑得不似真人，在应急灯下泛着冷玉般的光泽。</p><p>然而，那双眼睛，或者说那对嵌在完美脸庞上的光学义眼——却散发着非人的、深不见底的幽红光芒。</p><p>她身后，跟着数名同样全身高度义体化的队员，沉默如同移动的钢铁雕塑，身上闪烁着各种待机的指示灯和武器接口的冷光。</p><p>“攻壳机动队。”低沉、略带金属摩擦质感的女声响起。</p><p>声音不高，却清晰穿透了主机风扇的低鸣，敲打在每个人的耳膜上。</p><p>“第九课。出示最高识别码。”她向旁边微微侧头。</p><p>一名队员上前，手掌按在主控台一个不起眼的感应区。</p><p>一道深邃的蓝色光束瞬间扫描而过，主屏幕上刷过瀑布般的加密认证信息，最终定格在一个威严的狐狸徽记。</p><p>这一次，是货真价实的最高权限认证，带着国家暴力机器特有的冰感。</p><p>“有没有自称‘半人马座摄影爱好者’和‘黑蜥蜴星人’的人，来过你们这里？”</p><p>“啊请喝水请喝水。您刚才说什么？什么摄影爱好者和什么黑猩猩？”</p><p>预想中的敬畏和配合出现了。</p><p>但第九课的队长总觉得哪里怪怪的。</p><p>她非常不耐烦地重复一遍：“来自半人马座摄影爱好者，与黑蜥蜴星人。”</p><p>“就我们自己人在抢修，没有外人来过……半人马座？黑蜥蜴星？那是啥？科幻电影吗？”</p><p>“啧，好吧。”</p><p>她最近很烦躁。</p><p>接连三天都在被奇奇怪怪的噩梦纠缠：无尽的虚空中，她用一双明显是男人的粗粝的手，将一个个同样漆黑、表面缠绕着蠕动触须的怪异颅骨，一层层垒叠成一座直插星海的恐怖京观。</p><p>那冰冷、黏腻的触感，和颅骨空洞眼窝中残留的怨毒意识，即使醒来，也挥之不去。</p><p>此刻，面对这群麻木、抗拒，脸上带着虚伪笑容的工作人员，一股难以言喻的烦躁如同冰冷的毒蛇，缠绕上她的核心处理器。</p><p>追捕所谓的“半人马座危险摄影师”和“黑蜥蜴星人间谍”本就如大海捞针，线索扑朔迷离。</p><p>现在连最基本的现场调查，都遭到如此不专业的阻挠。</p><p>——是的，她一眼就看出来，这里的工作人员说“听不清”“不知道”，都是在扯谎。</p><p>他们根本不懂得如何伪装、掩饰自己的微表情和心跳速度。</p><p>但同时，她也不明白，为何这群人要扯谎。</p><p>……哦是的，他们应该被威胁了。</p><p>自从接连做了几个噩梦，她能感觉到自己思维变迟钝了许多。</p><p>“抢修？你们在抢修什么？”队长问。</p><p>“我们……我们这里刚经历了一场严重的数据错误，主机还在自检隔离。”</p><p>她没再追问工作人员，只是对着身后轻轻一摆手指。</p><p>两名队员立刻上前，动作迅捷无声。</p><p>他们手臂弹出接口，直接物理接入主机阵列的底层诊断端口。</p><p>另外几人伸出双手，指节骤然发出细密的机械齿轮转动声，化作十几根泛冷光的金属指节。</p><p>键盘敲击声如暴雨骤至。</p><p>虽然看着很有视觉效果，但就像是发明了人形机器人，然后让机器人借助搓衣板来洗衣服，或者是让这些机器人挥锄头耕田，颇有脱裤子放屁的感觉。</p><p>仅仅过了不到十秒。</p><p>“队长，”一名技术队员抬起头，电子合成音毫无起伏地报告，“发现高强度入侵痕迹。手法……极其霸道，完全没有掩饰自己的打算。时间戳：三十二分钟前。”</p><p>另一名队员的义眼锁定了主控台某个隐蔽角落残留的、正在缓慢消散的数据残影：“检测到伪造的最高权限认证标识注入记录。标识名称：‘最高授权-龙组’。”</p>
