# 域外天魔与层次世界

<p>青丘白璃轻咳一声，别过脸重新拨动断弦，试图维持威严：“呃，休要以为能拖延时间！中山只是暂时性本体严重受创，蛐蛐致命伤罢了，他很快便能回忆起一切，痛歼尔等！”</p><p>杨帝叹气。</p><p>“青丘白璃女士，问题就出在这，我们根本无心与您交战，也不认识您口中的‘中山’先生或女士，自始至终都是您单方面将我当做‘天魔’。”</p><p>说实话，杨帝也不知道，为什么在外人看来自己是“负灵能”。</p><p>迄今为止，他见过的最低灵能水平是0。</p><p>那些“现实丰度”掉到0的物质，都会变成蠕动的黑色拉面。</p><p>负数，真的闻所未闻。</p><p>首先，我从天外来……这点没错。</p><p>对于异世界土著来说，我们这些穿越者都来自天外，所以“域外天魔”这句话正确了75%，换言之其中三个字是对的——域外天。</p><p>至于“魔”字，这个杨帝不认。</p><p>他是大善人，和“魔”沾不上边。</p><p>如果要强行用这类风格的字词去形容他，“怪”这个字不错。</p><p>而现在，又出了件怪事。</p><p>外人观察到他的灵能，是负值？</p><p>一般修仙者，周身灵能高于周围环境，灵压便会像爆炸火焰一样向外放射性发散……而杨帝，则是向内收缩，像黑洞一样收缩。</p><p>为什么只有他身上出现这种情况，阿巴和59改却没有？</p><p>杨帝似乎思考到一些关键，可能说不上关键，也可能真是关键……</p><p>他需要更多情报。</p><p>《食人树》第一章第三节，主动转移话题，打破当下剑拔弩张的紧张氛围，引导对方朝着自己期望的方向交流，从而获取更多有用情报，化解眼前的危机。</p><p>“青丘白璃女士，在下恳请您暂且息怒，容我一述。我们虽来自天外，但绝非您口中无恶不作的‘魔’。您看，我等并未主动挑衅，且一直试图与您和平交流，这足以证明我们的善意。”</p><p>我正充满善意地与你和平交流嘛。</p><p>只是不小心把您的琴弦撑爆了。</p><p>杨帝轻轻摊开双手，以示意自己毫无敌意。</p><p>青丘白璃狐疑地盯着他看了好一会儿。</p><p>没办法，反正现在琴弦断了，她的战斗力从刚过5亿，一下子跌回到1亿2000万！</p><p>这点战斗力，打不过眼前这疑似“域外天魔”的人形物体啊，连防身都够呛。</p><p>她心中微微动摇，目标从原本的“歼敌于此”变化为“拖时间”。</p><p>杨帝盯准“青丘白璃”的微表情变化，把握到好机会。</p><p>他娴熟地套近乎：“是这样的，狐狸女士，那你不妨说说什么是‘域外天魔’？”</p><p>“你不就是吗？”</p><p>“……我都说不是啦，我连域外天魔是什么都不知道，你要我怎么自证清白啊！”</p><p>青丘白璃思索片刻，才缓缓开口，语气中带着一丝厌恶与忌惮：“那些东西……就像一大团疯狂抽搐的黑色线状物质，所过之处，灵气紊乱，万物扭曲。</p><p>“它们没有固定形态，能随意变形，且对灵气有着近乎贪婪的渴望，狂热吮吸万物的灵。</p><p>“它们所过之处，灵气被疯狂汲取，灵植枯萎，灵脉断裂，就连空间都会被撕扯出一道道狰狞裂缝。</p><p>“一旦出现，必然带来毁灭与混乱，灵界每次大规模的动荡，几乎都与它们有关。</p><p>“上次大规模入侵，七十二座护界大阵接连崩解，若不是归墟大帝……”</p><p>她的声音突然一顿，总感觉自己是不是透露太多了。</p><p>她是狐种大妖。而凡界的狐狸都特别能说。</p><p>截止至凡界的槐安纪元2185年，人族和妖族总共有200次政变和起义，都以狐狸半夜大叫“XX兴YY王”作为导火索。</p><p>关键在于，那并非有什么人去装狐狸叫，并非人族或妖族起义者的计谋。</p><p>真的是狐狸在叫。</p><p>正因如此，本界的狐狸有个外号“搅屎棍”。</p><p>青丘白璃想到，自己下到凡界，似乎也染上了一丝丝话痨属性，当然也只是一丝丝。</p><p>她抬起头，看向杨帝，却发现对方眉头拧成葱油花卷，陷入深深的思索。</p><p>嗯，说起来，域外天魔一般都浑浑噩噩，没有思想，身体呈现一大团黑色拉面的形态……</p><p>而眼前的杨帝，不像是域外天魔。</p><p>相比之下，貌似，更像是个“人”。</p><p>除了灵能形态和域外天魔一样诡异，杨帝的其他方面和“天魔”完全沾不上边。</p><p>保持着稳定的宏观物质形态，没有随意扭动的黑色线条，也保持着理性和感性，可以交流。</p><p>对方要么是看起来像人的天魔。</p><p>要么是看起来像天魔的人。</p><p>也不像魔道修士……那些崇拜域外天魔的修士，他们一般都疯疯癫癫，邋里邋遢。</p><p>杨帝说话：“青丘女士，如果我没猜错，‘域外天魔’的灵能级别，应该是零，对吧？”</p><p>现实丰度跌到零点的物质，也就是其“现实”被抽离的物体，被如同“驾驶员精神失常的EVA”般暴走。</p><p>青丘白璃微微一怔：“没错，你怎么知道？你不是自称来自其他世界？”</p><p>杨帝不慌不忙不急不躁不卑不亢解释道：“我在来此之前，曾在异界见过类似现象。一般来说，那些被抽离了‘现实’的物质，也就是灵能跌到零点的物体，会变得如同您描述中域外天魔那般，像是疯狂抽搐的黑色线状物质。”</p><p>在与“原初之眼”的大战中。</p><p>祂曾释放出大范围“质壁分离”AOE。</p><p>导致途经的诸多天体被剥离了“现实”。</p><p>宇宙各地貌似还有灵能者组成什么女武神部队，与崩坏大战三千亿回合，给驾驶无限机兵的杨帝减轻了超过1%的压力。</p><p>没想到，这世界的人也面临相似情况。</p><p>“域外天魔从何而来？”杨帝问。</p><p>物质本身，是不可能无缘无故被抽离所有灵能、自动导致现实丰度归零的。</p><p>至少在原初之眼兆亿年的记忆中，没有检索到一例自然发生的“崩坏”现象。</p><p>迄今为止，杨帝所遇见的“黑色拉面”，无不是有人作妖才出现的。</p><p>此界，存在能够天然发生的“崩坏”机制？</p><p>能够存在一种自然现象，使得一个物体质壁分离，原地暴走。</p><p>那真是一片黯淡无比的未来呀！</p><p>所以，杨帝对异界土著知情者问——这些魔物究竟从何而来？</p><p>青丘白璃眼神警惕，却还是缓缓开口：“你真的不知道？域外天魔一般出现在灵界，来自灵界域外。”</p><p>“抱歉，我连‘灵界’是什么也不知道……话说你这个‘领域’，什么时候撤了比较好？”</p><p>“居然连灵界都不知道，看来确实有几分可能是异世界来的客人……这座领域是由我的本命法器——琵琶所控制，如今不知为何，我的本命法器莫名其妙破碎，连带我对领域的控制也略微受创，短期内还不能取回‘领域’控制权……布豪！我多嘴，透露太多了！您能不能假装没听到？都怪这凡界的天地法则……啊啊啊！青丘白璃你不要再说了……可恶……那群老头总说我是最单纯的狐狸，难道真被他们说中了么……呜哇！为什么连这个也暴露了！”</p><p>杨帝动动耳朵。</p><p>“‘凡界的天地法则’怎么了？”</p><p>“凡界的狐狸特别多嘴，所以我来到凡界，会被天地误认成狐狸，也会沾染这项特性……”</p>
