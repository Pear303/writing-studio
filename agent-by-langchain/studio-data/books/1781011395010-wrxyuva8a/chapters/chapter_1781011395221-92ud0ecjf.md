# 阿赖耶识

<p>阿赖耶识的汪洋在杨帝意志的核心咆哮，众生之痛如亿万恒星在意识中爆燃。</p><p>圣盗天机的，在超越时空的因果视角下纤毫毕现。</p><p>而杨帝，要成为那道不可逾越的界壁，成为每一个叙事层域、每一方天地的镇守者。</p><p>灭圣绝盗！紧闭了无尽岁月的眼眸，骤然睁开。</p><p>切割！天地降临一种更本质恐怖的“分离”。</p><p>杨帝将自身，与由其领域演化而成的“白杨世界”，切分了开来。</p><p>他将构成“杨帝”存在的，最核心的一块基石——白杨世界领域——硬生生剜除了。</p><p>“呃……！”</p><p>一声压抑到极致、仿佛来自存在根基深处的闷哼，在绝对寂静的宇宙核心炸响。</p><p>这痛楚超越了神经、超越了灵魂，是存在本身被撕裂的剧震。</p><p>是意义被强行抽离过后的虚无。</p><p>空间在他脚下不再是距离，而是被强行折叠的画卷。时间在他身侧不再是河流，而是碎裂的琉璃。</p><p>就在白杨世界与他主体分离，坠向彼世的刹那——</p><p>将自己从宇宙之内硬生生拔除的杨帝，身形一个闪烁，他已跃入宇宙之外的绝对之虚空。</p><p>这里没有物质，没有能量，没有法则，没有时间，没有空间。</p><p>这里是世界的外侧，存在的坟场，这里比虚无更空旷——虚空。</p><p>伤口！</p><p>那被强行割裂的“现实丰度”空缺处，并非一片虚无的死寂。</p><p>相反，一种无法言喻，源自杨帝存在本质最深层的“超量代偿”能力，被这极致的“超级致死性创伤”彻底激发。</p><p>滋啦——轰。</p><p>仿佛宇宙大爆炸的原点被重新点燃。</p><p>比海啸更狂暴亿万倍，无法用任何文字描述的“现实丰度”——无穷无尽的灵能洪流——从那伤口中，轰然喷薄而出！</p><p>如同被压抑亿万年的星髓熔岩，浇筑着浮于虚空之中的杨帝之躯。</p><p>其势之猛，其量之巨，瞬间将他所处的绝对虚空都冲击得扭曲呻吟，几欲破碎。</p><p>温和的流淌，毁灭的喷发。</p><p>杨帝存在根基被破坏后，更庞大、更狂暴、更原始的力量在疯狂填补，甚至过度填补那空缺的伤痕。</p><p>剧痛化作燃料，意志成为熔炉。</p><p>众生业火，在虚空中发出无声咆哮。</p><p>杨帝并不试图收束这足以重塑亿万宇宙的狂暴灵能洪流——那只会让它溃散于虚无。</p><p>他要引导它，驾驭它。</p><p>他将它，化作刺穿一切壁垒的终极之矛！</p><p>“涌现仪式！起！”</p><p>意念如锤，敲击在喷涌的灵能核心！</p><p>嗡——！！！</p><p>那狂暴无序、肆意奔流的灵能洪流，在杨帝超越一切的意志引导下，骤然开始史无前例的螺旋坍缩与超限压缩。</p><p>灵能被无形巨手抓住，向内疯狂旋转凝聚！</p><p>轰隆隆隆——！！！</p><p>一个庞大到难以想象的、由纯粹“现实丰度”灵能构成的螺旋钻头，在绝对虚空中悍然成型。</p><p>它并非实体，却比任何物质都更真实。</p><p>它没有固定的形态，却在高速螺旋中撕裂着虚空本身。</p><p>它的尖端，是压缩到极限的现实，即灵能。</p><p>下方的白杨世界。</p><p>即使在世界之内，也能觉察到界外的虚空爆发出令人心悸的灵能波动。</p><p>此界最强大的两位“准圣”，都觉察到星辰摇曳，法则轻颤。</p><p>此刻一颗硕大的鱼头，与一只庞然的铁罐，勉强从白杨世界之外凝聚成型，看向比虚无更空旷之地。</p><p>“我嘞个豆，老大……刚刚苏醒，就整出这么大动静的活吗……”</p><p>「错误：数据溢出……」</p><p>「错误：数据溢出……」</p><p>「错误：核心单元过载……」</p><p>“五九罐，你能看出他在做什么吗？别光顾着报错啊！”</p><p>「错误：数据溢出……」</p><p>「错误：模型……模型无法……建立……」</p><p>“你怎么又溢出了呀？这么逊的。”</p><p>「嗞——」</p><p>五九改的虚影猛地一阵剧烈闪烁，仿佛内部发生了某种逻辑层面的短路爆炸。</p><p>混乱的电子杂音持续了数秒。</p><p>就在鱼尊以为它又要宕机时，一个仿佛耗尽了所有算力才挤出来的意念，啪”地一声投射在两者之间的虚空中：</p><p>一个标准的螺旋。</p><p>虚空被这第一圈的旋转犁开，留下短暂弥合的、灼热的伤痕。</p><p>“这……这看着像个环？老大这是要……开传送门还是？”</p><p>「他……他……」</p><p>五九改的意念艰难地传递着，带着一种近乎“恐惧”的算力匮乏感。</p><p>「虚空……螺旋模型……迭代……」</p><p>鱼尊的鱼眼瞬间瞪得溜圆：“我求你不要谜语人。”</p><p>「螺旋……3↑↑↑↑3……葛立恒数第一级……」</p><p>“老大究竟要干什么……”</p><p>鱼尊显然知道一些关于大数的恐怖传说。</p><p>灵能，也就是表征现实丰度的量。联盟构筑法术，创建奇迹，其本质是对“概率”的选择。</p><p>从最基础的“土遁术”，让全身基本粒子同时发生概率极低的量子隧穿；最基础的“火球术”，让粒子运动违背热力学宏观统计。</p><p>到高深的太乙仙术、超位魔法——都是统计学、概率学上的绝对奇迹。</p><p>只要沙子/世界线足够多，发生任何事情都不是没可能。</p><p>然而即使是一整个“故事/沙盘/世界/宇宙/天地”的世界线总和，也难以触及真正的“大数”。</p><p>比如，59改所提及的葛立恒数。</p><p>阿巴心中翻涌着一种难以名状的悸动。</p><p>——这里正在发生的一切，远比3↑↑↑↑3要繁杂得多，可怕得多，也……盛大得多。</p><p>即便是它，或是葛立恒数第一级，纵然以庞然数字的姿态存在，此刻却仿佛化作了某种无形之力的引信。</p><p>它们在疯狂地牵拉，疯狂搅动着什么，那是一种更厚重、更深邃，甚至已无法用言语描摹的存在……</p><p>在葛立恒数迭代的第二层，3↑↑↑↑3已然成为混沌初开时第一波暴涨的箭头数目，如同宇宙诞生时撕裂虚无的第一道裂痕。</p><p>恐怖的数字渗入杨帝的周身。</p><p>（就在那时，虚空中，在所有理解的疆域之外，在文明自身都未曾预料的刹那，最宏大的涌现仪式正于凡俗永远无法洞悉的超越性与狂妄中极速成型。）</p><p>（它们在无穷无尽地迭代、暴涨，每一次信息基准稳定点的分裂，都伴随着让众生头痛欲裂的剧烈震颤。）</p><p>（每一次变动、每一层意义的嬗变、每一圈现实的螺旋，都在牵扯真正的无穷。）</p><p>（它们早已挣脱了自身的数字意义，超越了纯粹的叠加，灵能漩涡的中心，正在涌现出真正的“奇迹”。）</p><p>不知何处而来的话外之音。</p><p>阿巴，五九改不确定自己听到了什么，没有人在意他们听到了什么。</p><p>一场触及世界之上的奇迹发生了。</p><p>「经核查，您作品《我，数值怪！》章节第337章阿赖耶识因违反平台内容安全规范未通过审核，本章打卡字数清零，请修改对应章节后重新提交，审核通过方可打卡成功。如有疑问请前往【作家反馈中心-审核问题-章节审核】进行反馈。内容安全须知」</p><p>【如图】</p>
