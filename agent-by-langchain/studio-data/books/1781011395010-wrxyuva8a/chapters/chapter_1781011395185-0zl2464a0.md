# 从天而降的来客

<p>（在正常人看来，事情的每个链条都逻辑通顺，但只要合起来，就会匪夷所到无法理解。）</p><p>（有些人真就活在理性人的世界里，认为世上每个人在做出每个微不足道的动作前，都会深思熟虑二三十遍。）</p><p>（狐若写道：有人放火烧山只为了让更多消防员来救火、救火出汗喝水在原地丢下更多矿泉水瓶、从而捡空瓶子来卖钱——要这么写，相信10个人里有12个会把我当傻逼。）</p><p>（但现实中确实发生了这种事。）</p><p>（有的人用水管直接冲洗带电的电器。）</p><p>（有的人认为面粉混了两成的滑石粉。）</p><p>（有的人装修房子时把1楼承重墙砸爆。）</p><p>（有的人非要拍短视频在铁轨旁边站着，然后被碾杀成渣。）</p><p>（有的人在动物园观光，非要下车和吊睛白额大虫拍照，被扑杀至渣。）</p><p>（有的人对塑料大米人造鸡蛋深信不疑。比如狐的妈妈(つд⊂)）</p><p>……</p><p>（补充……唉。）</p><p>（推荐大家看看大刘的流浪地球，我指的是原著，不是电影。）</p><p>（它是一部现实主义作品，在狐狐心目中算是大刘作品的top100。）</p><p>（你说top100太过宽泛？那我精细点，这本就是狐狐心中的大刘top1。）</p><p>（晚上又翻出来看了一遍，脊背发凉。）</p><p>（公元二零二五年七月二十日夜。）</p><p>……</p><p>桂虚捏着那杯寡淡的免费白开水，指尖能感受到粗瓷杯沿的毛糙。</p><p>廉价小铺的塑料凳子硌得慌。一旁的工业风扇虽然能吹12级台风，但搅动的，终归是八月初依旧溽热的空气。</p><p>“这鬼天真够呛，”老张抹了把额头的汗，瞥了眼铺子外白晃晃的日头，“报上说了，这月热浪凶得很，没个消停。”</p><p>他顿了顿，浑浊的眼睛看向桂虚，“比那破公司还磨人。起码老天爷折腾你，明明白白。”</p><p>“你还看报？”桂虚抓住这几句话中的关键点。</p><p>这年头看纸质报的人很少了。老张年近60，是“稷海市”这座国际化大都市中，为数不多的传统派。</p><p>“还有，老张，那哪是磨人，那是吃人。连骨头渣子都嚼碎了咽下去，临了还要你夸它一句人文关怀。”</p><p>“这不是，一个被撵到太平洋那头踹回来，一个在家门口就让人扫地出门。”</p><p>老张也失业了，他倒是看得开，毕竟社保交齐，退休在即。</p><p>桂虚沉默着，低头看着碗里晃荡的水面，映出自己模糊的影子。</p><p>“回来小俩月了，找着工作了么？”</p><p>“没有，简历没人要。‘三十五岁以上’，‘技术栈陈旧’，‘有海外经历但非大厂核心’……总之理由多得很。”</p><p>“实在不行就只能去送外卖。听说这热天，单子多，跑熟了也能糊口。”老张给出了最现实的建议。</p><p>桂虚没接话，只是缓缓喝下一口搪瓷杯里的白开水。</p><p>冰凉的水滑过喉咙，却浇不灭心头的燥意和一丝隐秘的期待。</p><p>“黄粱一梦”那边，应该已经开始业务混乱，系统崩溃了吧？</p><p>他们还要多久才能发现“阴伏流煞”的端倪？</p><p>除了他这个设计者本人，其他人想揪出那个防御性编程，难如登天……至少也得一坤天时间才能解决。</p><p>很快，一丝不对劲的感觉，像水底的暗流，悄然浮上心头。</p><p>流感……阴伏流煞，Influenza，全称“流行性感冒”。</p><p>“老张，”</p><p>他抬起头，眉头微蹙，“你记不记得，往年好像都是冬季才会爆发流感。今年的流感，怎么在这么热的时候爆发？还这么……普遍？”</p><p>“你这么一说，确实是。”老张点点头。</p><p>随即像是突然想起了什么重磅消息，身体下意识地前倾。</p><p>他压低声音，带着点神秘兮兮的探询：“老虚，你走南闯北的，见识多。回来路上听人嚼舌根没？说……不到一个月前，就你还没被炒那会儿，天上掉下来个陨石，‘轰隆’一声砸进稷海市北边老林子里了！动静大得邪乎，说是流星？”</p><p>“还有这回事？”</p><p>桂虚端着水碗的手几不可察地顿了一下。</p><p>稷海市？陨石？</p><p>他睡得太死，而且工作之余纯属宅男，根本没有注意到这些事情。</p><p>老张自顾自地往下说，声音压得更低，几乎成了气音：“邪门的是，这事儿刚过没多久，也就半个来月前吧？咱稷海市就开始闹这种怪‘流感’。不凶，但几乎没人不中招！发烧、咳嗽、人昏沉沉，医院都挤爆了，所幸症状都不严重，也就类似着了凉。但这玩意儿跟长了脚似的，顺着铁路、公路，从稷海市一路往外爬……现在听说北边几个省都不安生。你说……”</p><p>他浑浊的眼睛里，闪着一种混杂了恐惧和猎奇的光。</p><p>“老虚你说，这流星砸下来，带下来东西，会不会就是这要命的‘流感’的根儿啊？天上掉下来的……丧尸病毒？”</p><p>桂虚差点被最后一口白开水呛到。</p><p>他放下杯子，哭笑不得。</p><p>“……老张，没想到你还挺赶得上年轻人的潮流，丧尸病毒都出来了。”</p><p>他顿了顿，眼神恢复了程序员特有的那种冷静和理性。</p><p>“不过，老张我可以跟你这么讲：陨石带了丧尸病毒进蓝星——这种可能性基本为零。”</p><p>“哦？”老张被勾起了兴趣。</p><p>“你想啊，一颗流星，或者陨石，进入大气层的时候，速度有多快？跟空气剧烈摩擦，表面温度能达到几千摄氏度。什么概念？钢铁都能气化。碳基生命体，管它是病毒还是细菌，在这种高温下，蛋白质结构直接就灰飞烟灭了，连渣都剩不下。怎么可能活下来，还跑到地上来传染人？”</p><p>老张听得一愣一愣的，下意识地点点头：“是……是这个理儿。”</p><p>身上陨石掉下来的时候，总是一路上火花带闪电，风吹落星如雨。</p><p>老张没读过多少书，文化水平不高。</p><p>但他和桂虚是十来年的好友，超越年龄和文化阶层。</p><p>这种友谊，在当今小市民群体里已不多见。</p><p>也就和群友吹水的时候，可能搭上某个富哥富姐。</p><p>“除非！”</p><p>桂虚话锋一转，眼神变得锐利起来，仿佛穿透了这闷热嘈杂的小铺子，看到了那片神秘的北部老林。</p><p>“除非它外面有个极其坚固、隔热性能超强的外壳。比如，某种高强度合金，或者电视能看到的那些火箭返回舱。这东西本身不是生命，但它里面装着的东西……那就不好说了。”</p><p>他端起空了的搪瓷杯，看着杯底残留的水痕，声音低沉下去：“一个能扛住大气层摩擦高温的外壳……里面的东西，会是什么呢？”</p><p>“宇航员呗。”</p><p>“其实也有可能是空的。比如卫星。”</p><p>“卫星里面是什么？”</p><p>“我都说是空的……或者是一只‘卫星精’？”</p>
