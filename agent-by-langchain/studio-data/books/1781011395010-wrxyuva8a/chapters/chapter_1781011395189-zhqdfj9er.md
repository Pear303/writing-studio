# 天圆广场

<p>由于思考太过深入，杨帝无意间看向走廊外头的圆心广场——那座被晨雾笼罩、广播规则严令禁止观察的天圆广场。</p><p>噗嗤！</p><p>一声极其轻微、如同熟透果实落地的闷响。</p><p>杨帝的脖颈上，一道细如发丝、却深可见骨的血痕凭空出现！</p><p>“禁止观察”的规则本身，就是一把无形的铡刀，在他目光触及广场核心的瞬间便落下。</p><p>头颅与身躯的连接，被某种概念性的力量瞬间切断。</p><p>然而，杨帝脸上的笑意甚至还未完全敛去。</p><p>那颗即将滚落的头颅，断口处血肉如同拥有独立意识的活物，爆发出惊人的活性。</p><p>无数细微如纳米级的肉芽疯狂蠕动、交织、融合，发出令人牙酸的滋滋声。</p><p>断裂的颈骨精准对接，神经束如灵蛇般缠绕重生，血管壁瞬间弥合。</p><p>「十六环法术·大罗金仙来了或许能救活」</p><p>就在头颅即将彻底脱离身体的刹那，超乎想象的自愈力硬生生将其“缝合”了回去。</p><p>皮肤光洁如初，只留下一圈淡淡的红痕。</p><p>「综合抗性提升」的提示在杨帝的意识深处几乎同步闪过。</p><p>“哦？”</p><p>杨帝眼中爆发出比星辰破碎更璀璨的光芒，那是纯粹的研究狂热。</p><p>“规则级的‘即死’判定？有趣！判定速度极快，但伤害模式……似乎仅仅只是断一次头。”</p><p>将头颅缝合回去后，并不会持续性的断裂。</p><p>当然，前提是停止目视“天圆广场”。</p><p>杨帝毫不犹豫，再次看向圆心广场。</p><p>噗嗤！</p><p>血痕再现！头颅再断！</p><p>「综合抗性↑↑」</p><p>血肉狂涌！瞬间缝合！</p><p>“效率不错。”杨帝挺意外，来到新世界，就找到了很棒的作死方法。</p><p>噗嗤！噗嗤！噗嗤——！</p><p>走廊的阴影里，上演着一场惊悚到到顶点的循环，上传到暗网都过不了审。</p><p>杨帝的头颅，一次次被“规则”斩断，又一次次在血肉与意志的狂潮中瞬间再生。</p><p>每一次断裂与重生的间隙都在缩短，每一次重生的速度都在加快，每一次愈合后脖颈皮肤的坚韧程度都在以指数级攀升！</p><p>真仙初期……中期……真仙晚期……末期……</p><p>他的肉身强度，在这超越生死的循环中，如同坐上了火箭，疯狂飙升。</p><p>规则带来的“即死”伤害，在飞速提升的肉身抗性和超速再生面前，从“瞬间斩首”变成了“留下深痕”，再到“浅痕”。</p><p>最后……变成了脖颈皮肤上转瞬即逝的一抹微红。</p><p>他的肉身强度，抵达“大帝”层次。</p><p>杨帝稳稳地站在那里，头颅再未离开过肩膀。</p><p>他目光如炬，牢牢锁定着圆心广场那片浓雾深处。</p><p>这玩意，是概念性杀伤。</p><p>又称“机制怪”。</p><p>但纵然是机制怪，也有其极限天花板。</p><p>一力破万法，一力降十会，只要用蛮横无比的强度突破机制的上限便可。</p><p>“逊诶。”杨帝扭扭脖子，发出轻微咔哒声，感受着这具在规则淬炼下达到此界“大帝”级别强度的崭新躯体。一种近乎无敌的力量感在血肉中奔涌。</p><p>他继续凝视，目光更加深邃，试图洞穿那层笼罩广场的诡异迷雾，看清其中隐藏的、令广播规则都如此忌惮的存在。</p><p>自己的肉身强度才堪堪相当于仙帝，实在是令人不安desu。</p><p>想要横着走，怎么也得修炼成圣吧？</p><p>就在杨帝意识即将触碰到某种更深层次、粘稠而冰冷的“核心”时——</p><p>“同学！危险！！别看那里！！！”</p><p>焦急到变调的大吼在身后响起。</p><p>紧接着，一股巨大的力量从后方猛地抱住了杨帝！</p><p>那是双戴着粗糙白色劳保手套的手，以不容抗拒的力道，死死捂住他的眼睛。</p><p>此人手臂上，赫然缝着一圈刺目的鲜红色袖章。</p><p>是规则里提到的“志愿者”。</p><p>这志愿者，显然目睹杨帝呆立在走廊边“凝视”广场的举动。</p><p>他看不到无数次斩首再生的惊悚过程，只看到杨帝像中了邪一样直勾勾地看着广场，身体似乎还微微颤抖过几次。</p><p>在志愿者看来，这简直是教科书级别的作死行为！</p><p>必须重拳出击，立刻阻止，否则后果不堪设想。</p><p>说不定看了一眼那圆形广场，就会掉脑袋什么的。</p><p>“闭眼！捂耳朵！快跟我走！”志愿者声音发颤，用尽全身力气想把杨帝拖离窗边，同时试图去捂杨帝的耳朵。</p><p>他完全是出于救人的本能，按照广播的最高指导原则行事。</p><p>然而，他抱住和拖拽的，是一具刚刚在规则绞杀下淬炼至仙帝巅峰的躯体！</p><p>……杨帝为了不伤到志愿者，将就着顺从对方的动作，没有反抗，任由这个气喘吁吁、满脸惊恐的志愿者，将他拖到走廊内侧一个相对远离窗户的角落。</p><p>这里堆放着几个空置消防柜，勉强算是个“掩体”。</p><p>无所谓，以他的实力，就算隔着一万光年厚的墙，也能目视圆形广场。</p><p>只不过，现在广场中央的那团浓雾，已经无法对自己的脖子造成比“瘙痒”更大的伤害。</p><p>就这？要说不失望，那当然不可能。</p><p>“呼……呼……你不要命了？！广播里说的清清楚楚！不能看！绝对不能看那个广场！”</p><p>志愿者是个看起来二十岁左右的年轻人，此刻脸色煞白，额头全是冷汗，显然刚才杨帝的举动把他吓得不轻。</p><p>“你是哪个班的？叫什么名字？”</p><p>志愿者稍微平复了一下呼吸，立刻拿出一个小本子和笔，语气带着后怕和一丝公事公办，“我得记录一下，刚才太危险了……”</p><p>“白杨大帝。既然我来了，那么我会终结怪谈和诡异统治时代。”杨帝像是在陈述一个亘古不变的真理。</p><p>志愿者执笔的手猛地顿住，笔尖差点戳破纸页。</p><p>他愕然抬起头，仔细打量着眼前的少年：灰扑扑的校服，清瘦的身材，脸上甚至还带着点没睡醒的迷茫。</p><p>唯独那对招子，深邃得不像话。</p><p>这怎么看……也不像精神失常啊？</p><p>但“大帝”这种称呼……</p><p>“同学，别开玩笑了！”志愿者皱着眉，语气加重了些，“说真名！哪个班的？高三零班？二班？”</p><p>杨帝不说话，双眸直勾勾盯着他，眼神平静无波。</p><p>志愿者被他看得心里有点发毛，又想起刚才他直勾勾盯着广场的诡异样子，顿时嘀咕完了完了。</p><p>他拿起对讲机。</p><p>“指挥部，这里是巡逻组，在高三教学楼西侧环形走廊，发现一名高三男生试图目视中心广场，已被我及时阻止！重复，目视行为已被阻止。但该生精神状态不稳定。建议指挥部全校广播警告：目视广场可能导致严重精神异常。重复，目视广场可能导致严重精神异常，症状初步判断表现为痴呆与人格分裂……”</p>
