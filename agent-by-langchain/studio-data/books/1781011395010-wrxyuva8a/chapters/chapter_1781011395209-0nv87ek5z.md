# 自称独断万古的白杨大帝

<p>他那双刚刚还空洞如深渊的眼睛，此刻艰难地凝聚起一丝微弱的光泽。</p><p>像蒙尘的琉璃，茫然地扫过眼前几张充满警惕、惊疑、甚至带着一丝恐惧的脸孔。</p><p>他的目光在队长脸上停留得最久，似乎在努力辨认着什么，又像是在读取看不见的信息。</p><p>终于，他的嘴唇再次翕动。</p><p>声音干涩沙哑，仿佛许久未曾开腔。</p><p>“我是……杨帝？”</p><p>他吐出两个词，字正腔圆，却像两块冰冷的石头砸在地上。</p><p>眼镜的战术目镜疯狂闪烁着，试图分析对方的面部微表情、肌肉震颤、瞳孔收缩……任何能判断其精神状态的生理指标。</p><p>然而，数据反馈回来的只有一片混乱，仿佛对方的身体和意识处于一种极不协调的状态。</p><p>居然有他看不透的NPC！！</p><p>“杨……先生？你感觉怎么样？你从哪里来？怎么会在这里？基地都发生了什么？你都知道些什么？有没有需要跑腿的工作？有没有什么已经不要了的二手道具想要转手出去？”</p><p>队长连珠炮似的吐字，试图触发剧情。</p><p>这NPC怎么看，都是重要人物。</p><p>重要人物，往往联系到重要事件。</p><p>队长身经百战，经验丰富。</p><p>他知道怎么通过穷举法触发事件。</p><p>但自称杨帝的男子对他置若罔闻。</p><p>杨帝那蒙尘琉璃般的目光，缓缓扫过众人身后紧闭的金属门，又仿佛能穿透厚重的墙壁，投向整个蜂巢基地的深处。</p><p>最后，看向地上的便签纸。</p><p>那首关于草原，云海，阳光与风的诗。</p><p>他眉头极其轻微地蹙了一下。</p><p>他重新看向队长，那双眼睛里，茫然褪去了一瞬，取而代之的是一种近乎漠然的的平静。</p><p>“这里的地狱，不该存在。”</p><p>杨帝的目光扫过轮回小队众人，那眼神平静无波，却带着无形的重量。</p><p>“而我，白杨大帝，将会终结它。”</p><p>空气仿佛凝固了。</p><p>铁砣叹了口气，拍拍队长肩：“没救了，咱走吧。”</p><p>终结地狱？就凭这个被火鸦一颗火星子就烧得嗷嗷叫、衣服都没穿利索的家伙？</p><p>队长却叫住众人：“且慢。”</p><p>他用眼神暗示队员：对方既然提到了“将会终结它”，那么，按照主神的尿性，此人可能真的有破解通关副本的方法。</p><p>他看向杨帝：“这位杨先生，您可有关于这里的智械叛乱、和那个‘红皇后’的解决途径？”</p><p>杨帝摇摇头：“这种方法，只有大能才可以掌握。”</p><p>“啊？”</p><p>“就是用大能级别的超级力量打爆一切。”</p><p>“呵呵，果然是只有大能才可以掌握。”</p><p>队长有些放弃了。</p><p>他不明白，为何自己身边总是些画风奇葩的家伙，包括队友，甚至也包括眼前这NPC！</p><p>但眼下，线索似乎真的就系在这个被烧得皮开肉绽还自称“大帝”的怪人身上。</p><p>铁砣已经不耐烦，火鸦则有些警惕，眼镜再次低头看向那张便签纸，影子……嗯，影子依旧是一团阴影。</p><p>“好吧，杨……帝先生，我们知道的也不多，但我们会知无不言。”</p><p>队长决定死马当活马医，至少对方看起来像本地土著NPC，而且似乎对基地的“地狱”状态有认知。</p><p>如果按照对方的要求，将情况告诉他，或许真能开启什么主线任务。</p><p>“这里是名为‘蜂巢’的秘密基地，应该位于地下。主控AI叫做‘红皇后’。”</p><p>杨帝打断：“地下？你们怎么判断的？”</p><p>“升降机停摆，我们爬了大量的扶梯，一路向下才来到这里。”</p><p>“好吧。请继续说。”</p><p>“……主控AI叫做‘红皇后’。根据我们刚截取到的零碎日志，红皇后启动了最高级别生物污染清除协议，封锁了整个区域，释放神经毒气……目的是彻底清除所有有机生命体。我们判断，这是一场智械叛乱。”</p><p>队长语速很快，尽量简洁地概括了他们掌握的情报。</p><p>他目光始终紧紧锁定杨帝，观察他的反应。</p><p>他提到了“有机生命体”这个关键点，希望能触发点什么。</p><p>杨帝静静地听着，脸上没有任何波澜，仿佛在听一个遥远的故事。</p><p>他的目光甚至没有聚焦在队长身上，而是缓缓扫过这个破败的维护间，扫过紧张兮兮的轮回者。</p><p>最后，落在了天花板上。</p><p>那里，一个毛茸茸的橘黄色小脑袋，正小心翼翼地从他们之前掉下来的通风管道破口处探出来。</p><p>哈基米那双琥珀色的竖瞳，在昏暗的光线下闪着幽光——它一直悄悄跟着这群“两脚兽”。</p><p>杨帝的视线准确地捕捉到了那只猫。</p><p>他抬手，指尖正对着通风口那只探头探脑的橘猫。</p><p>“清除所有有机生命体？那么，这个有机体为什么没被杀死？”</p><p>“喵？”哈基米似乎感觉到了什么，疑惑地歪了歪脑袋，发出细小的叫声。</p><p>“对啊！”铁砣一拍大腿，恍然大悟，“这肥猫活蹦乱跳的！”</p><p>“眼镜，日志里有没有提到豁免……”队长的话音未落。</p><p>噗嗤！</p><p>一声令人头皮发麻、如同熟透浆果被捏爆的闷响，毫无征兆地在死寂的空气中炸开！</p><p>在所有人惊骇欲绝的注视——</p><p>哈基米那毛茸茸、圆乎乎的橘黄色猫头，瞬间膨胀扭曲撕裂！</p><p>橘黄色的毛发被撑裂，皮肤如同劣质橡胶般被扯开，露出底下疯狂增殖、暗红发黑的粘稠肉芽组织。</p><p>这些肉芽以肉眼可见的恐怖速度增生膨胀，取代了原本猫头的结构。</p><p>并在眨眼间，形成了一朵不断蠕动的……血肉食人花！</p><p>这朵“花”的“花瓣”是由无数不断搏动的血管状触须组成，边缘滴落散发甜腻腥臭的暗黄色脓液。</p><p>在原本应该是猫嘴的位置，裂开了一个深不见底、布满螺旋状利齿的恐怖口器，口器深处发出如同高压锅泄气般的“嘶嘶”尖啸。</p><p>一根布满吸盘和倒刺的紫黑色肉舌，如同毒蛇般从那口器中猛地探出，在空中疯狂甩动，粘液四溅。</p><p>“超！！！”铁砣的怒吼炸响。</p><p>他几乎是本能地将巨大的狼牙棒抡圆了，带着呼啸的恶风，狠狠砸向那猫条肉舌！</p><p>“滋啦——！”狼牙棒的尖刺与肉舌碰撞，发出令人牙酸的撕裂声和腐蚀声。</p><p>肉舌被砸得血肉模糊，倒刺刮下一大片粘稠的组织。</p><p>但铁砣的狼牙棒尖端也瞬间冒起青烟，被强酸般的粘液腐蚀！</p><p>狼牙棒，卒。</p><p>那肉舌吃痛，猛地缩回，但食人花状的头颅却发出充满痛苦和暴怒的嘶鸣，无数血管触须疯狂舞动，酝酿更可怕的攻击！</p><p>“这踏马是什么鬼东西？！”</p><p>“这怎么看都不是是终结者啊！”</p><p>眼镜的战术目镜疯狂报警，一片红光闪烁：“高能生物反应！强酸性体液！细胞活性指数爆表！这……这……这特么难不成真不是智械叛乱、而是丧尸危机？！”</p>
