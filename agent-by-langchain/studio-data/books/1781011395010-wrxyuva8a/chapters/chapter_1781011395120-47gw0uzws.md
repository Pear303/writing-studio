# 原初之战：时间跳跃

<p>机兵的本质是“附魔”。</p><p>附魔是将大量“灵能”嫁接到另一个物体上。</p><p>如果将10环的附魔强行镌刻进脆玻璃，这片不堪一击的玻璃，瞬间就会被汹涌澎湃的灵能摧毁，化为碎片。</p><p>伊芙虽作为超限强者，意识仍然被撕扯得支离破碎。</p><p>而杨帝的意识，则在极其诡异的超量代偿机制下，愈挫愈勇，受激进化，趋于圆满。</p><p>他感受到，自己身上挂载了一个附魔效果——「无限机兵I」。</p><p>「同步率100%，驾驶者状态正常，允许启动『时间机器』机动模块。是否立即加载？」</p><p>时间机器，也即“时间机器”。</p><p>伊芙的话音犹在耳畔：「历史终究要形成闭环……」</p><p>杨帝还能感受到，原初之眼的恶意正在虚境深处膨胀，对他乘上“无限机兵”此事，表露出暴怒、憎恨之意。</p><p>但也有一丝……期待？</p><p>祂在这个时代，已经没有可用的物质身躯。</p><p>在这个时间点，天然形成足够社会性、并涌现出一定智力架构的大型熔岩史莱姆聚落，已经在和伊芙的战斗中损耗殆尽。</p><p>但经过这场战斗，祂也成功让机兵驾驶员之一，伊芙·柑橘失去驾驶机兵的能力。</p><p>但祂仍然会在其他时代降临。</p><p>尤其是四万年后。</p><p>那个时代，被控制的圣光教廷，为原初之眼做了许多工作。</p><p>工作内容围绕着“如何用熔岩史莱姆集群承载一个庞大的意志”，“如何用史莱姆构筑足够强大的物质躯壳”。</p><p>那里，将会是原初之眼的主场。</p><p>于是，杨帝说：“启动时间机器。”</p><p>目标，第四纪元2099年。</p><p>……</p><p>意识变成一只透明玻璃杯，正被倒进沸水，时间片段在杯中旋转着溶解。</p><p>「时空坐标偏移，当前时间坐标：第四纪元2081年，误差值约18年2月15日20时36分。」</p><p>冰冷的机械音在意识深处炸响。</p><p>「时间机器偏差值超过界限，正在调整……正在自动校准时间偏差值……剩余时间：1分52秒。」</p><p>视线重新凝聚时，焦土上蒸腾的热浪已然消失，取而代之是漫山遍野的紫藤花。</p><p>杨帝矗立原地，感受这宁静的世界，微风和煦，生机勃勃，万物竞发，足足20秒。</p><p>然后……他感受到一个庞大的意志，降临在自己脚下数十公里深处。</p><p>原初之眼，祂紧随其后。</p><p>同一时刻，他看见1200公里外，圣光教廷布局在南海某岛礁上的，基地。</p><p>机兵的暗物质矩阵传感器瞬间捕捉到异常能量波动，将1200公里外的岛礁数据，展开在杨帝意识中。</p><p>该岛礁位于南海漩涡坐标点，最大直径5.5公里，地表覆盖着玄武岩。</p><p>岩石内部蕴含着浓度高达20%的灵能矿，这种纯度是普通灵能矿脉的4.1倍。</p><p>岛礁藏有深达800米的蜂巢状地下工事，层层嵌套。</p><p>工事底部的符文矩阵，每秒可从星渊井口的支脉汲取2.30万灵，这些能量通过百余条灵能导管，输送到整座岛礁的装置中。</p><p>中层的核心舱室，有大量培养罐，以及熔岩史莱姆。</p><p>核心舱室旁的夹层，一卷泛黄的羊皮纸，边缘焦黑的灼痕昭示着它曾经历过剧烈的能量冲击，但上面的记载依然清晰可辨：</p><p>「实验编号141，熔岩史莱姆融合……」</p><p>「实验编号514，史莱姆智力发生学……」</p><p>这是圣光教廷研究用史莱姆作为容器，承载原初之眼的秘密基地。</p><p>如果他在2099年的18年前，也就是2081年，提前捣毁这处实验室兼养殖工厂。</p><p>未来的原初之眼，是否会被削弱，甚至彻底死于历史？</p><p>杨帝在抵达这个时代的第21秒，机兵短距跃迁机动来到一千二百余公里外的南海岛屿，调动武器模块——动能冲击，也就是轮起个大拳头砸下去！</p><p>机兵的合金指节在大气中划出炽烈的尾焰，拳风将方圆百里的云层撕扯成螺旋状漩涡。</p><p>“轰轰轰轰轰！！！”</p><p>拳头触及岛礁，玄武岩如同被无形巨手碾碎的玻璃，在震耳欲聋的爆鸣中化为齑粉！</p><p>灵能矿脉在超高温下剧烈沸腾，紫色的能量流喷涌而出，与爆炸产生的气浪交织成扭曲的光幕！</p><p>地壳在发出不堪重负的呻吟，蛛网般的裂缝以落点为中心向四周蔓延。</p><p>岛礁下方的蜂巢工事瞬间蒸发，连带着数万史莱姆以及数百圣光教廷修士，一同泯灭。</p><p>地壳直接击穿，被轰出巨大缺口！</p><p>岩浆如挣脱枷锁的巨兽，裹挟着炽热气浪冲天而起，与紫色的灵能流相互缠绕。</p><p>数万米高的蘑菇云缓缓升起！！</p><p>但原初之眼没有来阻止他。</p><p>所以，杨帝感觉到，没有意义。</p><p>——在此时此刻摧毁圣光教廷的研究场所，没有意义，因为原初之眼仅仅只是冷眼旁观。</p><p>星渊井口处，所有教廷修士都被惊动。</p><p>他们原本镇守星渊井口，但在此刻统一接到紧急命令，集体撤离，冲往南海岛礁。</p><p>他们各显神通，各自施展法术向岛礁这边飞来。</p><p>于是，星渊井口就暂时无人驻守了。</p><p>或许会有某个摸金校尉发丘将军聚集的镇子，抓住该机会前来淘宝……</p><p>「警告，世界线变动。」</p><p>杨帝眼前一阵迷离。</p><p>掀飞上天的岩浆雨还未落地，杨帝视网膜上的部分读数迅速归零。</p><p>满目疮痍的岛礁表面，原本还有极少量残存的蜂巢状工事建筑材料、培养罐残骸、废弃设备零件。</p><p>但这些人造之物，下一刻便消失了。</p><p>似是从未存在过。</p><p>杨帝一瞬间想通了原初之眼的策略。</p><p>——祂跳跃到不知多少年前的过去，控制圣光教廷，取消对熔岩史莱姆的研究。</p><p>于是，这座岛礁从没有教廷的人来过。</p><p>杨帝也就没有对圣光教廷造成任何损失。</p><p>然而，原初之眼的强度不仅没有下降，他甚至感知到对方的熔岩史莱姆躯壳，似乎更完整、更强大了。</p><p>「解：原初之眼将熔岩史莱姆的所有研究资料拷贝到久远的过去，重新交给圣光教廷，从而使教廷在50年内实现500年的技术跨越。综合观测数据，此猜想置信度大于99.5%……」</p><p>机兵的计算中枢给出解答。</p><p>杨帝隐约牙疼。</p><p>在这个世界，“因果律”是种事件发生有先后顺序而造成的假象，所以，原初之眼能以违背因果的姿态篡改历史，影响未来。</p><p>而在历史被飞快篡改过后，仍然能保留主体性不变的——在这个世界上，似乎只有无限机兵和原初之眼，两大巨擘。</p><p>二位都拥有时间跳跃的能力。</p><p>它们跳出岁月长河，过去未来集于一身，将光锥熔铸成不朽权柄，于万古投下贯穿永恒的背影，不受历史的影响。</p><p>他还有第二个猜想……或许，因为自己是从世界之外而来，在这个世界的地位比较特殊，不会受到因果律太强烈的影响。</p><p>与此同时，传感器有新消息。</p><p>三十六个光点自海天交界处急速逼近。</p><p>那是从海岸线边急速飞来的教廷修士。</p><p>“时间机器，启动跳跃。”</p><p>「系统警告，时间机器模块尚未校正完成，下次跳跃可能导致更严重的不可控后果。校准剩余时间1分27秒。」</p><p>杨帝也只能就此应战。</p><p>如果仅仅只是几个圣光教徒，而非原初之眼所操控的史莱姆集群，机兵弹指即可将教廷修士捻碎……</p>
