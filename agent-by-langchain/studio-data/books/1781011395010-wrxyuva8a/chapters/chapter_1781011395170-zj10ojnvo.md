# 战后

<p>方才还威压如渊的“归墟帝霸阁”领域轰然崩塌，天穹上流转的创世符文寸寸崩裂，化作簌簌坠落的星屑。</p><p>领域崩溃，回归灵界。</p><p>“啊？”杨帝也只能缓缓说出这个字，以表示不理解。</p><p>双指下划，打开「终极无敌狂霸炫酷技能熟练度人体属性可视化界面！」，俗称人物面板。</p><p>【综合力量：3.33E100】</p><p>【综合抗性：5.55E105】</p><p>【现实丰度：7.77E110】</p><p>“归墟大帝”打入他体内的大量“虚无本源”之类的玩意，不仅能够持续性损伤血肉，而且能不断破坏他的灵能。</p><p>然而，杨帝已不再是那个15灵、30灵的小朋友。</p><p>他坐拥7.77E110灵，全部都是相当于“真牙”的灵能，属于身体一部分。</p><p>而不是像附魔、银行卡、身份证号、他人对杨帝之记忆这那样的“假牙”。</p><p>所以，“虚无本源”侵蚀他的灵能，反倒能哺育杨帝自身的现实丰度。</p><p>只是挨揍了3分钟，各项数值并没有质的变化，仍然停留在100，105，110的数量级。</p><p>——说到底，杨帝自己也发觉了，自己对某样事物是否是“我的一部分”，判定似乎有些奇艺。</p><p>一般来说，只要天然是他身体的一部分，比如手臂、躯干，乃至头发、指甲、腿毛。</p><p>那么，都会被自己的进化能力囊括在内。</p><p>但是，从自己身上脱落的残肢、碎肉、血液、毛发、死皮，这些从身体脱落的东西，一旦离开本体，就仿佛被瞬间剥离了与进化能力的联系，不再受“超量代偿”的庇护。</p><p>比如从手上脱落的指甲，不仅再也不能“挨打变强”，而且硬度似乎也大打折扣，比中子星硬不到哪里去。</p><p>杨帝也尝试过，用自己的体细胞克隆另一个自己出来。</p><p>但目前看来……成效并不显著。</p><p>虽然他的克隆体境界和修为攀升速度很快，而且愈合能力也特别强。</p><p>尽管杨帝的“克隆体”有自己的主观意志，全身细胞除了一个小小的变化，其他部分与他别无二致。</p><p>却始终达不到“锻炼就能升级”，“挨打就能变强”的概念级超量代偿能力。</p><p>那些“超速愈合”、“快速升级”特质，似乎只能算是几个普普通通平平无奇的SSS级别天赋。</p><p>“归墟帝霸阁”彻底崩塌。</p><p>杨帝彻底回到灵界。</p><p>他第一件事，是释放感知力，如天罗地网般铺展至灵界的每一寸角落，搜寻每一厘空间。</p><p>无论是法则波动的残痕，还是仙力逸散的蛛丝马迹，此刻都被他的神识反复筛检。</p><p>归墟大帝确实已经不见了，就像他三天前突然失踪那样。</p><p>远处，三个极小的影子从正六边形绿色传送门中现身，疾速而来。</p><p>分别是鲈鱼，坦克，狐狸。</p><p>阿巴惊喜说：“老大你回来辣！我们远远地感知不到你和大帝的气息，并且原处爆发出一股惊天的灵能波动，还以为你已经神魂尽灭、身名俱裂、万劫不复——”</p><p>“少咒我。”杨帝打断，看向青丘白璃，“归墟大帝呢？”</p><p>狐种大妖瞪眼：“不是和您在一起么？”</p><p>杨帝看向天空，发现灵界好像看不了星星和天象，只好问：“自从我和大帝进了‘领域’，过去多久了？”</p><p>“领域？什么领域？”</p><p>“归墟大帝的领域‘帝霸阁’，他有事和我谈，所以就说找一处私密的地方。”</p><p>但青丘白璃眸中还是浓浓的质疑。</p><p>“历史上，归墟大帝从来没有过打开‘领域’的记录，他无论是镇压叛乱大修，亦或是对抗域外天魔，从来都是从来都是一招定胜负，一拳将对方打爆。只是，有时候碰上域外天魔狂潮时，多路作战、疲于应对，所以才会陷入苦战。但总而言之，从来没有人见过他打开‘领域’……”</p><p>青丘白璃话痨属性大爆发，碎碎念起来。</p><p>杨帝对阿巴、59改使了个眼色。</p><p>这对冤家心领神会，一个负责蒙眼另一个负责敲闷棍，顷刻放倒青丘白璃，以奇怪的姿势绑好控制住。</p><p>人类和狐狸相对而坐。</p><p>“我问，你答。”</p><p>“白杨大帝，你是在破坏两个世界的友好！”青丘白璃大嚷大叫道。</p><p>杨帝掏出撬棍，在青丘白璃眼前轻轻晃动：“我问你答。第一个问题，‘灵茶山乂斧’是什么？”</p><p>阿巴在一旁煽风点火：“桀桀桀，你要是不回答，老大就用这撬棍，把你的狐狸尾巴一根根撬开，看看里面是不是藏着秘密。”</p><p>狐种大妖瞳孔骤缩，拼命往后缩，却被59改死死按住。</p><p>“我绝对不会告诉你‘灵茶山乂斧’乃是创世之斧！也绝对不会向你透露关于——先天神尊从混沌中苏醒、手持此斧劈开虚无、清气上升为天、浊气下沉为地——这些灵界机密情报！”</p><p>“好的，第二个问题。‘归墟’是什么？”</p><p>青丘白璃被捆得七荤八素，却仍在垂死挣扎，尾巴疯狂甩动。</p><p>“白杨大帝！你对我使用了何等妖术？为何我遏制不住将——先天神尊劈开虚无时、天道裂隙渗出了‘虚无本源’、那些吞噬一切的黑流汇聚成了归墟、任何东西掉进去都会被彻底抹除——这个情报告诉你的冲动？”</p><p>青丘白璃解释道，归墟汇聚了大量蕴含虚无本源的黑色渊水，能够解构万物，毁灭万物。</p><p>也曾有些大能尝试捞一勺子喝，但他们要么重伤残疾不治，要么就变成黑毛红毛大粽子，晚节不保。</p><p>这百万年千万年来，只有归墟大地一人喝了3000瓢渊水而不死，还越来越强。</p><p>杨帝瞳孔微缩，想起归墟大帝注入他体内的虚无本源。</p><p>会抹除万物的黑水？找机会喝两杯。</p><p>“OK，第三个问题，什么是‘虚无本源’？”</p><p>青丘白璃双眼翻白，仿佛被无形的力量扼住喉咙，话语如苏打水气泡般不受控地倾泻而出：“虚无本源是超脱于灵界法则之外的‘反存在’！它就像......像凡界的橡皮擦，能把物质、能量、甚至记忆都从天地间彻底擦除！”</p><p>好吧，看起来也还是修仙小说里很经典的设定。</p><p>代表混沌和虚无的本源法则力量；</p><p>开辟天地的上古至宝“超级斧头”；</p><p>灵界与凡界的“肉夹馍”层次结构；</p><p>以及域外天魔入侵、大帝站在最前线……</p><p>觉得眼熟？这样的情景，在玄幻修仙小说各处上演，下一个就可能轮到你！</p><p>“噗——”杨帝苦思冥神，一不小心没闭合喉咙，吐出了几十升血。</p><p>阿巴和59改见怪不怪，倒是被五花大绑的青丘白璃震惊了：“白杨大帝！你要神魂尽灭、身名俱裂、万劫不复了吗？！”</p><p>杨帝擦了擦嘴。</p><p>体内的虚无本源，仍然在持续性破坏他的躯壳和灵能。</p><p>只要他想，随时能够将血液中流动的“归墟渊水”引导到肠胃处，使它们被消化。</p><p>他已经用自己的胃，成功磨灭一滴渊水，以此验证了自己的消化能力确实无比绝伦。</p><p>他说：“不要咒我啊狐狸。我就讲讲刚才发生的事情，你们有没有头绪……”</p>
