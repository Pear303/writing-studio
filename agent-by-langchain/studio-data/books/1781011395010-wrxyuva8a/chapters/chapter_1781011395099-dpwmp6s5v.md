# 大盗奥拓

<p>“我轰开，你们挖。”伊芙法杖往地上一杵，四十米圣树虚影轰然砸落。</p><p>轰——轰——隆！</p><p>地面顿时裂开蛛网状纹路！</p><p>瑞弗维尔抡起铁锹，一铲子下去——铁锹停滞不前。</p><p>没有预想中的铲土声，反而是某种闷响，仿佛捅到了什么硬物。</p><p>他有些困惑：“这是挖到什么……”</p><p>土层突然炸开个两米宽的窟窿！</p><p>浓烈的麦酒混着机油味冲天而起，呛得三人齐齐后退。</p><p>烟尘里晃出个酒桶高的身影，铸铁钻头还在头顶嗡嗡旋转：“哪个缺德玩意儿往人天灵盖上挖土？”</p><p>待他掀开生锈的护目镜，露出双布满血丝的眼睛，看清眼前一个精灵两名人类。</p><p>他脸上的恼怒，瞬间突变为讪笑。</p><p>“是这样的，各位听我解释，我拾走这个兔肉煲，纯属紧急避险……”</p><p>……</p><p>矮人自称奥拓（Otto），来自铁熔堡，是个矿工，所以随身带着钻头和十字镐。</p><p>他自称干这行很多年了，所以能熟练挖开土层，来到地表，顺走兔肉煲，再躲到地下。</p><p>“等等。”</p><p>伊芙打断矮人奥拓的滔滔不绝，“可是你身上没有灵能波动……正常人真能仅凭身体素质，从我们眼皮子底下顺走食材？”</p><p>奥拓指了指安在自己头盔上的钻头：“我有非常好的钻头，‘狱髓’材质，施加「效率V」、「耐久III」和「丝绸之触」附魔。”</p><p>极品材质，极品附魔，这是件极品钻头！</p><p>伊芙法杖仍然怼着他脑门：“我认可你的装备了，那么，你来这里干嘛呢？为什么要偷兔肉煲？”</p><p>奥拓挠了挠头，脸上浮现出尴尬。</p><p>“是这样的，铁熔堡最近出了点状况。堡里的大熔炉不知为何失控，火焰温度远超以往，把周围的矿石都快烤化。我寻思这事邪乎得很，就想着找个安全的地方躲躲，结果在荒野逛了两天两夜，实在要饿炸了。”</p><p>杨帝把瑞弗维尔拉到一边低声问：“铁熔堡是什么？”</p><p>铁熔堡，事实上是一座依山而建的城市，以矮人种族为主体。</p><p>更准确来说，是一座挖空山体而建起来的工业巨城，以其精湛绝伦的锻造技艺而闻名遐迩，是矮人们锤炼神兵利器的圣地。</p><p>堡内有着错综复杂的地下矿脉，蕴藏各种珍稀矿石。</p><p>大量优质矿石、成批熟练工匠，是铸就传奇装备的源头。</p><p>杨帝搓搓手：“那铁熔堡坐落在哪？”</p><p>“还得往东走个五六百公里。”</p><p>“两天两夜走这么远？”</p><p>“斗宗强者，恐怖如斯。”</p><p>连这两个人类都能看出奥拓满嘴跑火车、跑飞机、跑火箭，心思更缜密的伊芙就更不用说了。</p><p>她正要轰杀这偷兔子吃的矮人顺便将方圆十里的荒野焚作焦土，杨帝冲到精灵与矮人之间百分百空手接法杖：“杖下留人！！”</p><p>“怎么？杨帝你要劫法场？”</p><p>“不是……只是有事要拜托这位仁兄。”</p><p>杨帝假装动情地讲述了他失去撬棍、砖头的痛苦。</p><p>他想让奥拓帮忙一柄皮实耐操的撬棍，几块耐用的砖头。</p><p>这段时间的饭票，他来包。</p><p>奥拓听闻，先是一愣，随后脸上又挂上那副讪笑。</p><p>伊芙有了台阶下，倒也不咄咄逼人了，收起40米长的法杖，坐在一旁任由他们基层自治。</p><p>杨帝和奥拓跑到远处，协商。</p><p>瑞弗维尔蹲在他们身边旁听。</p><p>奥拓低声道：“这位兄弟，不是我不想帮你，你瞧现在这地，就我随身带着的钻头和镐子，连个像样的铁砧工作台都没有，根本造不了啥好撬棍和砖头。”</p><p>杨帝皱了皱眉：“那依你看，我们该咋办？总不能就这么算了吧。”</p><p>他指了指被洗劫一空的炊锅。</p><p>然后压低声音对矮人说：“看见那精灵没？她是我师傅，我了解她，她青面獠牙，吃小孩不吐骨头，平常杀人如麻，甚至到了不知道什么是人、也不知道什么是麻的境界。如果我不拦住她，你绝对没有好果子吃。所以，无论有多困难，你也要想办法帮我搞一根撬棍，不然我就把你丢给她。”</p><p>奥拓真急了：“我手头真没工具。”</p><p>也是，巧妇难为无米之炊。</p><p>尤其是对于这个身上没有灵能波动，看起来就是个非常平凡的矮人而言。</p><p>缺少工具，他甚至没能力把铁材熔化。</p><p>“那……我们去铁熔堡？”</p><p>“不……不行，大熔炉失控了嘛，现在那里已经被紧急封锁了，可能还得排查十天半个月，六七个星期，八九年什么的，才能重新开启。”</p><p>杨帝看向瑞弗维尔。</p><p>两个人类通过眨眼、眼皮抖动，完成眼神交流。</p><p>杨帝：瑞弗，你带的那堆行李里，有没有铁砧和熔炉？</p><p>瑞弗维尔：这么重，怎么可能带上。</p><p>杨帝：伊芙呢？你和她熟，她的「风王结界」里有没有带炼器设备？</p><p>瑞弗维尔：那是大家闺秀的私房行李，我怎么能提出要看啊。</p><p>杨帝：在到星渊井口之前，如果没能搞到好的武器，我若对上……你那些“卖汽水的商业竞争对手”，或许会非常吃力……</p><p>奥拓看见让人的眼神交流里传过了“星渊井口”四字，眼睛微微睁大。</p><p>他犹豫一下，打断两个人类的交谈。</p><p>矮人指了指南边方向：“是这样的……继续往南走，有一座小城镇，名为砾石镇。规模不大，镇里却有家铁匠铺，老板手艺相当不错，是我熟人——真的很熟。我或许能向他借用一下铁砧台。”</p><p>杨帝一听，顿时来了精神。</p><p>“既然如此，那可真是再好不过。不过，奥拓兄弟，既然都要去铁匠铺了，我们就想把事情一次性解决妥当。”</p><p>他用胳膊肘顶了顶发呆的瑞弗维尔。</p><p>后者立刻反应过来。</p><p>“对对对，没错，我有把短刀，平日里用着虽说顺手，但要是遇到些厉害的角色，怕是有些不够看，能不能也帮忙附上些厉害的魔？”</p><p>杨帝继续肘瑞弗维尔。</p><p>瑞弗维尔再度心领神会。</p><p>“还有我们的炊具、碗筷，若是能有些特殊的附魔，比如让饭菜保温更久，餐具不易损坏，甚至是自动做饭之类的，那可就方便多了。”</p><p>羊毛逮着薅啊。</p><p>奥拓一听，脸上露出些许为难之色。</p><p>但看着杨帝那不容拒绝的眼神，又瞥了瞥坐在一旁看似云淡风轻，实则时不时投来锐利目光的伊芙。</p><p>他心中一凛，只能僵硬地点点头。</p><p>“好，帮你干了。”</p><p>瑞弗维尔拍了拍奥拓的肩膀，笑道：“奥拓兄弟，那就全靠你了，我会把你写进我的作品中。”</p><p>“作品？你是小说家，吟游诗人？”</p><p>“以前我还是图书馆馆长，现在……嗯，你可以认为我是个‘史官’吧。”</p><p>伊芙在远处点头，默许了。</p><p>她总是喜欢在初次见面时吓唬人。混熟之后，比杀手兔还温和。</p><p>一行四人整顿好行装，便朝着南方砾石镇的方向进发。</p><p>原本伊芙、瑞弗、杨帝三人，就是各自心怀鬼胎结成的队伍，恰好都往南走。</p><p>现在只是多个人，多张嘴，多顿饭罢了，倒也不是什么大问题。瑞弗维尔还有碗筷。</p>
