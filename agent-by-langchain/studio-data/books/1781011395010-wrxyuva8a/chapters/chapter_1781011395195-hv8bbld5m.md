# 结束了！

<p>凌云圣皇深吸一口气，指尖捏着那枚被灵力微微淬炼过的回形针，探向第二扇门的锁孔。</p><p>这扇门散发着浓郁的不详气息，门板上甚至凝结着暗红色，仿佛凝固血液般的污渍。</p><p>“诸位小心，门后恐有大凶之物……”</p><p>他沉声道，体表泛起一层古铜色光泽，那是他引以为傲的圣皇体在自发运转，虽然目前以他的修为，即使是圣皇体，也只能抵挡筑基修士的全力一击。</p><p>话音未落，他手腕轻抖，回形针精准地探入锁芯。</p><p>咔哒。</p><p>一声轻响，出乎意料的清脆。</p><p>门……开了。</p><p>没有预想中汹涌而出的腥风血雨，没有扭曲蠕动的阴影怪物，甚至没有一丝一毫的诡异低语。</p><p>门缝里，只有江城六月正午那灼热、刺眼、带着汽车尾气和柏油路面焦糊味的阳光，汹涌地灌进来，瞬间冲散图书馆内阴冷腐朽的空气。</p><p>阳光太过猛烈，刺得习惯了昏暗环境的众人下意识地眯起了眼。</p><p>“这……”阿巴愣住了，手中撬棍微微下垂。</p><p>“怪谈……消散了？”另一位灵界修士难以置信地低语。</p><p>他敏锐地感知到，那无处不在的、令人窒息的精神污染和规则束缚感，如同潮水般退去，消失得无影无踪。</p><p>凌云圣皇第一个踏出门外。他站在图书馆侧门廊檐的阴影下，举目四望。</p><p>阳光普照，蝉鸣聒噪。</p><p>操场空旷，教学楼寂静。旗杆上的红旗在微风中懒洋洋地飘动。</p><p>一切都显得……过分正常，正常得诡异。</p><p>除了空气中还残留着一丝极淡的、难以言喻的能量余烬，以及远处校门口传来的隐约喧嚣。</p><p>“结束了？”</p><p>凌云圣皇古井无波的脸上也露出一丝困惑。</p><p>“结束了？”</p><p>高三零班紧闭的教室门也被猛地推开。以苟玖为首的几个邪道修士，形容狼狈但眼神精光四射，小心翼翼地探出头来。</p><p>体育馆的爆炸声刚过去不久，一切便都结束了。</p><p>他们显然也感知到了规则领域的消散，脸上有劫后余生的喜悦，但也充满了错愕和一丝丝遗憾。</p><p>“怎么回事？老夫刚摸清这‘教室守则’的七处空子，正准备卡BUG去食堂后厨捞点油水……怎么怪谈就没了？”</p><p>一个干瘦的青年捶胸顿足，仿佛错过了一个亿。</p><p>很快，穿着白色防护服、手持检测仪的防化人员，以及全副武装的士兵和医护人员进入了校园，开始有序地引导他们这些幸存者撤离。</p><p>当凌云圣皇一行人，以及被苟玖等人“夺舍”的师生们，在军警和医护人员护送下走出校门。</p><p>瞬间被外面的景象淹没。</p><p>警灯闪烁，人潮汹涌，长枪短炮的摄像机镜头如同森林般密集。</p><p>灼热的空气里混合着消毒水、汗水和紧张的味道。</p><p>而最引人注目的，是校门口临时搭建的巨大屏幕。</p><p>屏幕之上，正进行着现场直播。画面中央，是一个他们所有人都无比熟悉、为之战栗也为之敬服的身影——</p><p>白杨大帝！</p><p>他穿着那身蓝白校服，在一圈麦克风的簇拥下，神情自若，甚至带着点百无聊赖。</p><p>他手里还端着个一次性泡面桶？旁边的记者正激动地提问。</p><p>语速极快的记者A：杨同学！您是说您一个人解决了整个怪谈？！这太不可思议了！能描述一下您是怎么做到的吗？比如，您用了什么特殊的武器或者能力？</p><p>杨帝：武器？哦，主要是靠牙口。那玩意儿味道不咋地，有点……嗯，过期鲱鱼罐头拌陈年腐乳的感觉，还有点塞牙。</p><p>他顺手抠下卡在头发缝里的子弹。</p><p>快门声咔咔作响。</p><p>没有多少专业素养的记者B：面对镜头，请问你有什么想说的吗？</p><p>杨帝：感谢并肩作战的集体，感谢默默付出的家人，感谢一路同行的朋友……</p><p>强行找回话题记者C：那、那杨同学您能说说，您是怎么进入这个战斗状态的吗？或者您力量的来源是？</p><p>杨帝放下泡面桶，表情变得严肃而深远：来源？这个说来话长。本质上，我并非纯正的蓝星人类。我的诞生，源于一场星际……嗯，邂逅？</p><p>镜头瞬间推近，所有记者屏住呼吸。</p><p>连校门口刚刚走出来的凌云圣皇、苟玖等人，都下意识停住了脚步，竖起耳朵。</p><p>星际？这又是什么惊天秘闻？</p><p>白杨大帝要当众传道了？</p><p>杨帝：事情是这样的。有几位来自半人马座的摄影爱好者，他们痴迷于记录宇宙中各种极端能量爆发的瞬间，比如超新星爆炸、黑洞吞噬、或者……嗯，像刚才那种规则怪谈湮灭时的“烟花”。他们技术很高，擅长潜入各种高危地带。</p><p>记者们：？？？</p><p>屏幕外的凌云圣皇等人：“？？？半人马座？摄影爱好者？”</p><p>杨帝：“然后呢，有一群来自黑蜥蜴星的原住民，他们是宇宙里的‘清道夫’或者说‘追踪者’，专门追捕这些不守规矩、到处乱拍、容易引发次生灾害的摄影佬。黑蜥蜴星人也跑到了蓝星，一直在追踪这批半人马摄影佬的行踪。”</p><p>声音发颤的记者D：那……那这和您有什么关系？</p><p>“摄影佬们忙着找下一个爆点，黑蜥蜴忙着追债，至于咱蓝星的‘龙组’正忙着查户口，负责将偷渡进蓝星的非法移民逐出‘卡门线’。”</p><p>卡门线是国际上通用的，一条用于划分蓝星大气层与外层空间的分界线，其高度被定义为海拔100千米。</p><p>三方势力会面，发生各种爱恨情仇。</p><p>省略过程。结果是，他们生了个白杨大帝。</p><p>就在全球观众被这星际家庭伦理剧震得七荤八素，年轻女记者问出那个关键问题：</p><p>“您的‘家长’们近况如何？”</p><p>杨帝露出了那个意味深长的微笑。</p><p>他没有直接回答，只是抬起手，用那根泡面叉子随意地指了指天空，又指了指脚下，最后虚点了一下镜头，或者说，镜头背后那无数双盯着他的眼睛。</p><p>“宇宙很大，世界很小。既然我来了，那么我会终结怪谈和诡异统治时代。”</p><p>在杨帝发言后的几秒内，全球各大社交平台彻底瘫痪。恢复后，热搜榜瞬间被屠榜：</p><p>「泡面战神杨帝」</p><p>「半人马座摄影爱好者入侵地球」</p><p>「黑蜥蜴星人在逃通缉犯」</p><p>「龙组 宇宙计生办？」</p><p>「求问吃诡异是什么口感在线等挺急的」</p><p>「杨帝星际家庭伦理剧」</p><p>「怪谈速通记录保持者」</p><p>「宇宙很大，世界很小」</p><p>「我会终结怪谈和诡异统治时代」</p><p>杨帝端着泡面的图被P上熊猫头和boomer，表情包以光速传播。</p><p>阴谋论者狂欢，科学家头秃，段子手灵感爆棚，普通人则亲眼目睹救世主诞生的震撼中，感受到活久一点也确实是件好事儿，能见到如此离谱的事情发生。</p><p>当天过后，全球自杀率下降了20个百分点。</p><p>这是在诡异肆虐的当下，全球自杀率第一次降低。这一切都在杨帝计算中。</p>
