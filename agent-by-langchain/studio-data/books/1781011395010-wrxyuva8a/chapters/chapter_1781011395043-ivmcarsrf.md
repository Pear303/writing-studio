# 请君入瓮

<p>希夷见老大和老大的便宜师傅根本不留手。</p><p>它“哇”心痛地大叫了一声，回到猫尸。</p><p>黑色拉面立刻停止重组，重新凝固成狸花猫的形态。</p><p>但小白鼠那边，黑色拉面状触须又开始剧烈膨胀，触须如毒蛇般扑向杨帝！</p><p>杨帝翻滚避过触须，后背重重撞在墙上。</p><p>他看见希夷的灵体在两个躯体间来回闪烁，如同风中明灭的烛火。</p><p>每当希夷进入白鼠肉瘤，猫尸就开始崩溃；而它回到猫尸，肉瘤便失控暴走。</p><p>顾头不顾腚。</p><p>不过，如今杨帝剑术大成，精神属性极高，对身体的掌控度也水涨船高，所以不至于像之前那么狼狈。</p><p>而且这里空间宽敞，适合两个人一起施展群殴。</p><p>杨帝看向胡彦卓：“胡哥！一块把——”</p><p>异变来得毫无征兆。</p><p>“砰——！”闷响像熟透的西瓜被重锤砸开，胡彦卓的身体倒飞出去。</p><p>后背撞上水泥柱，发出令人恐惧的骨裂声。</p><p>他张嘴喷出猩红血雾，左手死死按住凹陷的胸口。</p><p>杨帝瞳孔骤缩成绣花针，五感解放，潜意识疯狂处理环境中一切信息，一切蛛丝马迹。</p><p>他捕捉到空气里细微的破空声。</p><p>某种物体高速移动时撕裂气流的尖啸！</p><p>下一秒，一只裹挟着黑色黏液的团子撞碎头顶的灯泡，腐臭的腥风扑面而来！</p><p>它的躯体早已不是血肉之躯，羽毛间伸出数十条纯黑色的拉面状触须！</p><p>「2012.2.5，麻雀，质壁分离……」</p><p>“麻——雀！”杨帝暴喝一声，撬棍划出半圆弧线，精准砸向麻雀的脖颈。</p><p>火星四溅，却未能斩断那些滑腻的触须。</p><p>麻雀发出尖叫，触须如章鱼腕足般纠缠住撬棍，强大的拉力几乎要将杨帝手腕拧断。</p><p>“老大！我快不行了喵！！”</p><p>希夷的猫躯炸毛，灵体从白鼠肉瘤中抽身飞回。</p><p>却见狸花猫的断尾处再次渗出黑色物质。</p><p>“不！”它发出凄厉猫叫，在两个躯体间疯狂穿梭。</p><p>原本这是个可行的策略。</p><p>现在，却因胡彦卓的重伤而乱了分寸。</p><p>白鼠肉瘤趁机膨胀，触须如蟒蛇般缠住胡彦卓的脚踝，将他拖向墙角的阴影。</p><p>“混账！把他给我！！”</p><p>杨帝将耐久度耗尽的撬棍扔掉，接过胡彦卓的钢管。</p><p>六脉神剑，关冲式！</p><p>“砰！！”黑色的小白鼠结结实实挨了钢管全力一击，一时间头晕脑震。</p><p>“希夷！别管猫身了！把那只鸟夺舍了对付那只狸花猫！我来压制小白鼠！”</p><p>希夷的灵体猛地从猫尸中脱出，化作银灰色流光，冲进0.5马赫的黑色面条状麻雀。</p><p>与此同时，小白鼠的触须分裂成数十条细如发丝的黑线，向杨帝罩来。</p><p>他就地翻滚避开致命的纠缠，后背却撞上了潮湿的墙壁。</p><p>小白鼠趁机扑向杨帝。</p><p>“砰——轰轰！！”</p><p>希夷操控着麻雀，以171米/秒的速度创飞了变异小白鼠，救杨帝于鼠口！</p><p>他暴喝一声，跳起来，钢管舞出漫天残影，把僵直的小白鼠触须砸得节节断裂。</p><p>白鼠肉瘤发出高频尖啸，触须疯狂收缩成盾牌状。</p><p>好盾反！杨帝一棍下去，竟震得虎口撕裂，钢管险些脱手，钢管末端直接凹下去一大块。</p><p>这白鼠肉瘤的防御强悍如斯！</p><p>杨帝借着反震之力跃上半空。</p><p>六脉神剑，关冲式、少冲式、中冲式！</p><p>三式连破，钢管如毒蛇吐信般刺中白鼠肉瘤的核心。</p><p>剑术大成+运动员级体能+马氏体不锈钢管，杨帝将小白鼠按在地上摩擦。</p><p>花开两朵，各表一枝。</p><p>希夷在麻雀体内发出鸟子特有的低吟，控制着这具躯体，以匪夷所思的角度折转！</p><p>利爪如闪电，撕碎狸花猫的脊椎。</p><p>但异变陡生！狸花猫猫头180度扭转。</p><p>七窍渗出的黑色物质凝结成骨刺，向着麻雀激射而去。</p><p>希夷操控麻雀一个鹞子翻身，左翼却被骨刺贯穿。</p><p>“哇呀！老大救我！”</p><p>杨帝眼角余光瞥见这一幕，立刻舍弃被重创的小白鼠。</p><p>他纵身跃上墙壁，钢管如标枪般掷出，将暴走的狸花猫钉死在地面！</p><p>但另一边，白鼠肉瘤抓住机会，剩余触须再次猛然缠住胡彦卓脚踝。</p><p>没等杨帝和希夷反应过来。</p><p>刚刚才被打成肉酱的小白鼠，就将重伤昏迷的胡彦卓，拖向阴影中的排水管道了。</p><p>“不！希夷阻止它！！”</p><p>“吔啊啊啊啊啊——！！”</p><p>鸟子体内，却传来希夷惨绝人寰的尖啸。</p><p>杨帝红着眼，手电筒扭过去——不知何时，被钢管插到地上的狸花猫将身体撕裂开来，从插到地上的钢管中强行脱出，反手扑杀麻雀。</p><p>杨帝的嘶吼在潮湿的墙面上撞得支离破碎。</p><p>他竭尽全身力量和意志，一闷棍将狸花猫砸进水泥墙中。</p><p>「体能+1+1+2+3+5」</p><p>「剑+1+1+2+3+5+8+13+21」</p><p>钢管呜咽一声，末端凹陷折成120度角。</p><p>那狸花猫抽搐片刻，随即化作数百根黑线，从砖缝里流走，消失了。</p><p>扔下钢管，杨帝疯了般扑向排水管道，指尖几乎要擦过胡彦卓染血的衣角。</p><p>却在中途被小白鼠的触须扫得踉跄。</p><p>彻底隐入黑暗阴影前，小白鼠长满黑色拉面的身躯上，似乎露出阴恻的冷笑。</p><p>好像在说，“抓到他了，嘻嘻……”</p><p>那是一抹极其细微，如果不仔细观察，根本不可能发现的笑意。</p><p>“黑色拉面”本身，是一团失去了一切能动性的绝对死物——杨帝亲身感悟过的。</p><p>「一团火被抽走了热量，只剩下冰冷的灰烬保持着燃烧的形状……」</p><p>小白鼠的躯壳，无灵无智，不可能对他露出这般笑容。</p><p>但是，刚才那抹冷笑绝不是错觉。</p><p>而且，小白鼠和麻雀分工配合，战术娴熟，目标是冲着更弱的胡彦卓来的。</p><p>与杨帝的缠斗，完全是为了缠住他，分散自己的注意力。</p><p>他们的战术藏着某种秩序……</p><p>——有东西在操纵它们。</p><p>杨帝从未如此笃定地确信过一件事——必定有什么东西在操纵它们！！</p><p>“黑色拉面”本身是浑浑噩噩的死物，而操控它们的存在，必定拥有智慧。</p><p>胡彦卓的身影彻底没入黑暗，唯有染血的青砖上留下一道蜿蜒的血痕。</p><p>杨帝的指甲几乎抠进青砖缝里。他盯着排水管道深处翻涌的黑暗，喉间滚出压抑的低吼。</p><p>希夷现在是只麻雀。</p><p>它扑棱着受伤的翅膀，摇摇坠坠飞来，停在杨帝头上。</p><p>“老大……物质有了‘灵’就更难操控吱……”</p><p>“不用解释了，非战之罪，追。”杨帝抹去嘴角的血渍，从地上爬起身来。</p><p>希夷又一次阻住他。</p><p>它有些焦急道：“老大！我还有话要说吱！”</p><p>杨帝盯着那还不那么适应身体的麻雀，苦笑了一下。</p><p>“希夷，你是想说在我左侧80米处就是出口了对吧？”</p><p>希夷哑然：“老大，你发现了吱？此地不宜久留，我们必须要走，至少出去报警……”</p><p>杨帝转头，看向墙上那个被阴影笼罩的安全出口标志。</p><p>绿幽幽的箭头，在墙面上投下诡异的光，像某种恶意的嘲讽。</p><p>“希夷，你以为你便宜老大没看见？”</p><p>他低哑的嗓音里裹着冰碴，“从那只小白鼠现身瞬间，我就注意到出口在左后方。它们故意把胡哥拖向相反方向，就是要引我追进这片黑暗。”</p><p>“那老大，咱们就更不能落入圈套吱……”</p><p>杨帝摇摇头，吐出最后一口从喉咙倒流上来的血。</p><p>“没错，我知道这是‘请君入瓮’，但对方也知道‘我知道这件事’，所以，如果我不进去——他，或者他们，就会撕票。希夷，胡彦卓这副模样，我是负有责任的。”</p>
