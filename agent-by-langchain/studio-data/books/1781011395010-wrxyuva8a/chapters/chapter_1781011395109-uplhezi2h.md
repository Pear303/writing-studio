# 大地焚烧

<p>在墓道中不断深入，那恐怖的轰鸣声逐渐被甩在身后。</p><p>但在某一时刻，原本渐趋微弱的爆炸声突然放大数倍！</p><p>仿佛一个加强连的唢呐手在他们耳膜边吹奏重金属版的百鸟朝凤。</p><p>“轰！轰！！隆！隆！！”</p><p>强烈震颤从身后迅猛传来，众人站立不稳，纷纷踉跄几步。</p><p>伊芙回头望去，只见尘土如汹涌的浪涛般席卷而来。</p><p>与此同时，他们清晰地感觉到——身后很长一段墓道，都坍塌了。</p><p>本就是18年前挖的墓葬，虽然经过了加固，但迟早也会坍塌。</p><p>伊芙知道，地面上的巴德撑不住了。</p><p>复杂的情绪涌上精灵心头，但她也明白，此刻容不得过多感伤，必须尽快找到安全之所。</p><p>“都说了别愣着，继续往下走！”</p><p>她不断向身后施展法术，抵挡汹涌而来的尘土和碎石，延缓墓道坍塌的速度，为众人争取更多时间。</p><p>奥拓则在最前方带路。</p><p>若是路被堵死，便掏出极品狱髓钻头，原地开出条路来！</p><p>黑暗、狭窄、压抑与爆炸噪声之中，伊芙驻足刹车漂移转身，又一道强力的法术稳住身后坍塌的趋势。</p><p>“伊芙！快跟上！”杨帝回头。</p><p>他看见伊芙被尘土渐渐淹没，身影在其中显得那般单薄。</p><p>只可惜自己过于弱小，还没有资格帮助一个超限法师什么忙。</p><p>伊芙又是凭空召唤出几块数吨重的花岗岩石板，堵住来路，转头飞速奔去。</p><p>就在她前脚刚离开不久，被她暂时挡住的碎石尘土，如决堤的洪水般冲破石板！</p><p>汹涌袭来！将刚才她所站之处瞬间掩埋！</p><p>众人一刻也不敢停歇，在这狭窄且随时可能继续坍塌的墓道里逃窜。</p><p>直到某一时刻，身后墓道坍塌停止。</p><p>爆炸声也渐渐平息，冲击波与火焰亦被削减了99.99%威力。</p><p>他们在一个稍微宽敞的空腔内停下。</p><p>瑞弗维尔松口气：“我们安全了，暂时……”</p><p>杨帝已经懒得阻止他立flag。</p><p>他开始思考现状。奥拓和伊芙，一个在前一个垫后，他俩得了MVP，而杨帝自己和瑞弗维尔躺着活了下来。</p><p>爆炸来自……他听清楚了，是圣光教廷的十环法术，威力媲美战术核弹头。</p><p>杨帝抱着胳膊：“教廷为什么要灭我们口？我们知道了什么不该知道的？”</p><p>伊芙仍然握着法杖看向来路：“并非我们。”</p><p>“你是说？”</p><p>“他们要灭的是巴德。当然，如果能把我们也顺带灭了，就更好。”</p><p>精灵道出了圣骑士最后说的一句话。</p><p>「教廷的布置可能在南海某处。」</p><p>“巴德知道一些教廷的事情，但也仅限于‘知道一些’。”</p><p>“仅仅是‘知道一些’，圣光教廷就要如此大费周章，要把这样一个参与过讨伐卡利斯托战争的功臣灭口？！”瑞弗维尔又双叒大惊。</p><p>他虽当了10年宫廷图书馆馆长，但政治智慧没有就是没有。</p><p>若不是国王莫名信任他，瑞弗维尔早就在无尽的宫斗之中迷失自我，甚至迷失生命了。</p><p>“怎么样，你们还要继续走下去吗？”一直默不作声的奥拓突然说道。</p><p>矮人只是想在此地摸金，摸完就走。</p><p>并不太想卷入波诡云谲的政治斗争。</p><p>“呃……伊娃，你怎么看？”瑞弗维尔喉结动了动，这位宫廷图书馆馆长，此刻像只受惊的鹌鹑。</p><p>虽然，从一开始将那叫什么沃尔夫施莱格的红衣主教杀死的时候，他就已经和圣光教廷彻底闹掰，不死不休。</p><p>但若是继续探寻教廷的秘密，就要继续遭受追杀。</p><p>他虽然没有政治智慧，但也是知道的——教廷既然动用十环法术，就不会放过任何活口。</p><p>现在回头，不过是把脖子提前伸进绞索。</p><p>但如果可以，他还是希望能过上平静的逃亡生活，而不是轰轰烈烈的解密、硬刚教廷。</p><p>逃跑到海角天涯，总比杀进对方总部大本营要容易吧！</p><p>伊芙说，不行。</p><p>“只是目前不行……我们先去地表，看看巴德的情况。”</p><p>精灵说话很决绝，带着不容置疑的意味。</p><p>另外两个人类和一个矮人，都只能在洞穴腔室的另一端看着她。</p><p>如果教廷的攻击是冲着巴德而来，那他现在极有可能已无存活概率。</p><p>圣光教廷虽被原初之眼蛊惑，但也只是将组织宗旨将“侍奉圣光”变成了“崇拜大眼珠子”。</p><p>基本的战术判断，合乎理性的战略抉择，他们完全有能力做。</p><p>教廷既然决心除掉巴德。</p><p>那失手的概率必定很低很低。</p><p>但众人还是决定去往地面看看。</p><p>众人顺着奥拓挖开的临时通道，爬出墓道，回到海平面以上。</p><p>暮色已将天空染成暗红，一股强烈的热浪扑面而来，还夹杂着浓烈的焦糊味。</p><p>原本的星渊井口已经面目全非，大片的土地被翻起，呈现出一片焦黑之色，似是被一场巨大的炼狱之火洗礼过。</p><p>数百米外的树木直接碳化，有的枝干碳化层脱落后，露出结晶状物质。</p><p>虽然早已预见到这番恐怖景象，但瑞弗维尔仍然感到生理反胃。</p><p>“呕——他们就为了炸一个人？”</p><p>远处，一个巨大的深坑出现在视野中，那想必就是十环法术爆炸的中心。</p><p>坑底还冒着丝丝缕缕的黑烟，仿佛大地被撕开了一道狰狞的伤口。</p><p>“巴德……”伊芙喃喃自语。</p><p>在深坑最底端，他们发现了巴德残破不堪的身躯。</p><p>说是“身躯”，其实只能算几块金属残片。</p><p>扭曲变形，杂乱地散落在坑底。</p><p>一块较大的胸甲残片，表面坑坑洼洼，边缘处卷曲着，宛如被烈火舔舐后痛苦扭曲的嘴唇。</p><p>其上原本象征着荣耀与守护的金色纹路，此刻已被高温融化，模糊成一团难以辨认的污渍。</p><p>伊芙跳下刚刚被炸出来、还冒着高温蒸汽的焦黑深坑。</p><p>她指尖抚过巴德胸甲残片上凝固的熔痕，忽然在金属褶皱间摸到一处凸起。</p><p>精灵掏出匕首，小心翼翼挑开碳化的皮革，露出半枚镶嵌在护甲夹层里的徽章——那是枚褪色的银质玫瑰，花蕊处刻着极小的铭文：「献给永不凋零的信仰」。</p><p>她用丝绒布小心地将那几块残片包裹起来，带在身上。</p><p>杨帝则震撼于“十环法术”的力量。</p><p>“这得赶上一发战术核弹头了吧？这是人类所能掌握的力量？？”</p><p>他将不超过三秒的震撼藏在心底，然后看向一旁的矮人奥拓。</p><p>矮人面相本来就显老。</p><p>老了，神色就很难看明白。</p><p>只能从奥拓眼睛里，瞥见33.3%的震惊，33.3%的恐惧，33.3%的侥幸，和0.1%的其他。</p><p>瑞弗维尔则站在焦土边缘。</p><p>他指尖触碰那些结晶状的树木和岩石残骸。</p><p>在图书馆做馆长时，他曾见过类似描述——圣光之力扭曲到极致，就会产生将物质强行结晶化的效果。</p><p>似乎是这种晦涩的物理反应。</p><p>在狭小的地洞里，他曾无数次想象过教廷追杀的场景。</p><p>每一个脚步声，都让他冷汗淋漓。</p><p>可此刻，真正站在这被摧毁的土地上，恐惧反而像被高温蒸发了般，只剩下某种近乎麻木的平静。</p><p>下一刻，瑞弗维尔浑身颤抖，意识到一件事。</p><p>自己，见证了历史。</p><p>“十环法术……即使是历史书籍，甚至是野史记录中，都没有出场超过一个巴掌……”</p><p>瑞弗维尔的声音，连自己都觉得陌生。</p>
