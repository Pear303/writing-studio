# 楼船夜雪大排档

<p>“得罪了，这位刚上完厕所就得赶回去厨房做菜的酒楼师傅。”</p><p>杨帝一个熟练的“大记忆消除术”，那厨师眼神瞬间变得清澈，锅铲也“哐𪠽”一声掉地上。</p><p>阿巴上前将锅铲捡起，放回厨师手中，用很嗲很机车的声线说道：“师傅，您继续忙。”</p><p>厨师机械地点点头，转身朝船舱上部走去。</p><p>三人跟在厨师身后，踩着锈迹斑斑的金属楼梯蜿蜒而上。</p><p>空气里漂浮着潮湿的铁锈味，混着从上层甲板漏下的咸腥海风。</p><p>厨师毕竟是厨师，在一个拐角后便走进了厨房。三人也没理他，继续往甲板方向走去。</p><p>按理来说，“船”一般是有甲板的。</p><p>从“趋同进化理论”的角度来看，不同生物在相似环境下会演化出相似特征。就如鱼类、海豚虽分属不同物种，但为适应水中生活，都进化出了流线型身体。</p><p>大伙都已经发现，这儿的环境和地球还算比较相似，也都是人形生物，与地球人特别像。</p><p>这艘游轮，甚至也进化出了和地球一样的压载水舱。</p><p>从功能需求的趋同出发，此船必然得有这么一处空间，能让人们在上面应对变幻的天气、观察四周的海域、调整航行的方向。</p><p>即便它可能在形态或材质上与地球的甲板有所差异，但本质功能应该是相同的。</p><p>“‘轮船’这种机器，能用‘进化’这词吗？”</p><p>「自然可以，我愚蠢的鲈鱼朋友。」59回答道，同时，身上一块金属板“窸窸窣窣”脱落下来几粒锈尘。</p><p>他正在定向进化，主动适应本地物理规律。</p><p>守望者文明本就是智械出身，在文明发展历程中遇到的第一个天灾，便是星际虫族。</p><p>那时候守望者还未研制出超光速技术。</p><p>虫族和智械，两个文明开始疯狂刺激的军备竞赛，最后以守望者文明恐怖的爆兵和技术迭代能力，压倒虫族的繁殖速度，最终取胜。</p><p>历经艰难的守望者，在军备竞赛中研制出的一项核心技术，名为「模板升级方案」。</p><p>每一个个体，每一艘战舰，都能自行升级。</p><p>只要群体之中，哪怕一颗螺丝的设计通过了工程论证，发展出了史诗级优化的方案。</p><p>其他所有个体，都可以在不需要去往工厂、不去维修厂的情况下，原地改进身上的螺丝！</p><p>这就是独属于机器的进化方案。</p><p>深海鲈鱼幼年时，并未走虫族的超速繁殖、肉身成圣方案。</p><p>而是沉迷于灵修，感悟天地法则。</p><p>不然，阿巴很可能会被守望者文明摁死在娘胎。</p><p>“所以说你欠了我很多——在其他世界线，你肯定杀了我不止一次。”阿巴对59改发表重大谴责，并原地要求索赔。</p><p>“小声点，不要太张扬，说不定这方圆500米内，就藏着四五个绝世高手、隐世大能，又或者六七百万座无限机兵、八九千亿个星环盟约的暗哨，正盯着咱们，蠢蠢欲动。”</p><p>杨帝指出的暗淡未来，并非不可能。</p><p>一鱼一坦克也便停止拌嘴。</p><p>这二位生物都经过了化形，阿巴成了人形自走美少女，59改则是个为人方正（像主战坦克一样方正）的大叔。</p><p>他们看起来虽然都像人，但毕竟衣服风格不太一样，引起了路上许多人注意。</p><p>这个异世界这个时代，人们好像挺开放的。</p><p>假如哪一天有人断了根手指头，急需布料包扎止血——他把自己身上所有衣物全扒下来，都不够用。就是这种开放程度。</p><p>“说起来，我们在舱底看见的那厨师，算是船上穿得最多的土著了吧？”杨帝回忆道。</p><p>那厨师确实穿太多了。</p><p>阿巴摸着下巴，虽然在场她穿最单薄，但其实她也是一条传统的鲈鱼：“文化差异吗？本地厨师会穿的比较多。”</p><p>“其实有可能，为了防止热油溅身上。”</p><p>他们已来到最后的舱室门前。</p><p>走廊已在身后，甲板犹在眼前！就连过道里一直在放的土嗨音乐，也倏地切换成《The Edge Of Night》[^0^]</p><p>舱门推开瞬间，冷冽海风裹挟着细密雨丝，从天空中扑面而来。</p><p>忽见星河垂夜幕，三千世界一灯红。</p><p>眼前夜景如同被打翻的银河，倾泻在海面。</p><p>数以万计的发光建筑悬浮在粼粼波光之上，建筑表面流转荧火，在雨幕中晕染成斑斓光带。</p><p>哦，建筑表面的并非“荧火”，而是千家万户的灯火。</p><p>细雨被城市光晕染成七色，在风中凝成流动的彩虹帷幕。</p><p>“这是……反重力城市？浮在海面上！”阿巴的尾鳍在身后兴奋地摆动。</p><p>她是条深海鲈鱼，在老家的水里，也感受不到多少重力，一切都是那样轻盈自在。</p><p>当她看到悬浮于海面的反重力城市时，睹物思乡，潸然泪下，登时觉得这个世界的人们真的很有品！</p><p>给她留下了极好的第一印象。</p><p>杨帝目光掠过悬浮建筑间交错的光轨。</p><p>流线型的透明舱体在轨道上穿梭，像流星拖着银蓝尾焰，与海面倒映的星芒缠绵纠缠。</p><p>——那是异世界城市的公交车。</p><p>「这是个科技极度落后的原始文明。」59改评价道。</p><p>他评判先进和落后，是以守望者文明发展的顶峰时期作为标准。</p><p>杨帝根本不打算听59改的鬼话。</p><p>这位地球青年，现在只想在赛博朋克的世界里亲身遨游。</p><p>“妈耶！你们看看身后，仙气飘飘——”</p><p>杨帝转身，看见阿巴朝身后夸张地张大嘴，幸好没有露出腮，看起来还是个人。</p><p>身后仰头望去，五层飞檐斗拱层层叠叠，每层廊柱都垂着流苏灯笼，烛光透过鲛绡纱帐，将雨丝染成温暖的橘黄。</p><p>楼体表面缠绕发光海藻，随海风轻轻摇曳，宛如被封印在木料里的星河在流淌。</p><p>手指抚过栏杆上的云纹雕刻，触手是温润的檀木质感。</p><p>这是座会移动的海上楼阁，楼船。</p><p>丝绸朋克？杨帝更喜欢了。</p><p>“哇，一扇门都做那么豪华。”</p><p>阿巴发现，原本以为的舱门竟是雕花木门，门楣悬着鎏金匾额。</p><p>但比较煞风景的是，木门朱漆剥落处，依稀可见“无极大排挡”六个字。</p><p>确实是六个字，因为五字不行。</p><p>大排档内，还隐约能看见几个或红、或白的胶凳。</p><p>“果然这起名还是有点俗吧。”</p><p>“‘无极’是何人？说不定是刚才那厨师嘞。”</p><p>「‘无极’与‘厨师’是同一人，该猜想置信度低于5%，换言之，无极是厨师有可能，但厨师是无极不太可能。」59改说。</p><p>阿巴好奇了：“你这套置信度算法，又是怎么计算出来？”</p><p>「并非计算，而是随机数生成器。」</p><p>楼船顶层，传来流水潺潺般的琵琶声，婉转曲调裹着酒香与雪雾，在飞檐斗拱间流转。</p><p>一人一鱼一坦克，同时抬头。</p><p>是的，雪雾，下雪了。</p><p>杨帝长这么大，始终只能通过他人的镜头，或借助别人的眼睛、外人的记忆，才能看赏雪景。</p><p>这一次，是他亲身经历下雪。</p><p>伸出手掌，接住一片泛着冷光的雪花。</p><p>杨帝闭上眼睛，再睁眼，雪花已融于掌心。</p><p>他笑道：“鲈鱼，坦克，我告诉过你们要低调要低调。现在被盯上了怎么办？”</p><p>楼船最顶层，一只白狐狸化成的人形生物，怀抱琵琶，身姿轻盈似一抹流云。</p>
