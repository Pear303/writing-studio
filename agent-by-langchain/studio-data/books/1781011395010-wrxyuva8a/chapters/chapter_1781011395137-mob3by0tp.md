# 如果你想要，你就来拿它

<p>杨帝微微叹息：“果然失败了……虽然也不出所料……鱼弟，跟我走吧。”</p><p>阿巴仍然沉浸于那一瞬间的力量澎湃。</p><p>听到这尊神秘大能“杨帝”的话语，才堪堪反应过来。</p><p>“啊，老大您让我跟你走？”</p><p>“没错，你们双方的核心冲突，就是只能有一方成为最终观测者，或者夺得大罗道果嘛。”</p><p>双方冲突，那就把一方拉走。</p><p>左右双方的群体可能会互搏，但一个人左右脑一般不会互搏。</p><p>“哇！本鱼的大罗道果……”</p><p>“你得到最终观测者权限，又能做什么呢？最终观测者权限，本质上只是通过最后一次的观测，把这个宇宙的‘唯一历史路线’最终确定下来罢了。”</p><p>“可是，我渴望大罗金仙……”</p><p>“你为什么而修炼？鱼，回答我！你为什么而修炼？！”</p><p>阿巴恍惚：“我……”</p><p>杨帝：“修炼变强是为了获得更大的自由。可你的自由已经损害到万物的自由。你可以向周围看一眼。”</p><p>阿巴向四周望去。</p><p>方圆数百万、上千万光年，已经被她与守望者文明的大战，炸出一个宇宙尺度级别的空洞。</p><p>“如果你稍微回想，你可能会疑惑：守望者舰队为何不在一开始释放‘零点能炸弹’，为什么一开始不把主力舰队全部调来。而非要拖到你重新杀回来，才动用必杀技？”</p><p>阿巴当时没想通，只能归咎于对方的决策中央，是个机械死脑筋。</p><p>毕竟守望者文明走的是机械科幻风路线，一提到机械，总刻板印象认为它们很死板。</p><p>“守望者调度了百分之九十的舰队，用于疏散方圆数亿光年的群众，所以，他们的主力很晚才匆匆赶来，都是为了抢险救灾。这可能是战术的失败，但一定是战略的胜利。”</p><p>杨帝一边敲打鲈鱼，一边说着，“我认为，由他们管理这个宇宙是非常好选择。而任由你留在这个世界，则是对万物的祸害。”</p><p>阿巴浑身上下鱼嘴最硬：“修炼不就是为了追求逍遥快活的终极自由么……”</p><p>“哈哈，那把你做成水煮鱼也是我的自由。”</p><p>“不，这种事情不要哇。”</p><p>阿巴小声说，“那我就跟你走了，老大？”</p><p>杨帝收起笑嘻嘻的表情，恢复到属于强者的严肃：“阿巴，和我走，必须约法三章，有些事情你能做，有些事不能做。”</p><p>“好、好叭。”</p><p>“能随意干涉文明内政，不能随意操控种群命运。就这样。”</p><p>两点很正常的要求，阿巴点头道是。</p><p>虽然她内心还有一些疑惑，一些质疑。</p><p>杨帝替阿巴把她的质疑说了出来：“在你刚刚因核辐射而变异觉醒之时，应该与我有过一面之缘。”</p><p>阿巴小心地点点头。</p><p>“你看见我把那枚银质玫瑰勋章，放回到圣骑士巴德的手中。你还发现，我在不同的时间点都曾现身过，偷偷干涉此世的历史走向。”</p><p>“对的，老大……您是在‘干涉文明内政’吧？”</p><p>“恰恰相反，我只是让世界回到没有被「某个存在」干涉时候的原本模样。”</p><p>“‘某个存在’？”</p><p>杨帝目光穿透宇宙深空，凝视万物：“祂同时拥有神灵的视野与凡人之心智，祂很痛苦，所以干涉了万物运行的轨迹，计划让世界提前走向毁灭。”</p><p>阿巴活这么大，却没听说过“那个东西”是什么。</p><p>她是深海鲈鱼，但不是一般的鲈鱼，而是见多识广的鲈鱼。</p><p>“那祂到底是……”</p><p>“祂曾经是一位绝对的观察者，原初之眼。”</p><p>阿巴承认自己不知此人。</p><p>如果是某星域的隐世大能，那她至少也得听说过对方留下的江湖传说。</p><p>但事实是，这个所谓的“原初之眼”，在江湖划掉，在宇宙中，从来没有留下过痕迹与传说。</p><p>就好像……祂从历史的起点开始，就从未存在过。</p><p>“宇宙中太多事情都被原初之眼干涉过，我只能根据祂的记忆，慢慢修复原样。”</p><p>杨帝指了指自己的太阳穴。</p><p>“Personal Reality - 个人现实，也就是你我俗称的‘主体性灵能’。而我体内的大部分灵能，都源自祂。</p><p>“只不过，因为祂的灵能表现出了杀伤性和认知危害性质，所以被我的‘消化能力’同化。</p><p>“现在的我，其实是拥有‘杨帝’情感、心智与皮囊的人形态‘原初之眼’。”</p><p>阿巴有些被搞糊涂了。</p><p>“您是说‘夺舍’？老大你夺舍了祂？又或者是……”</p><p>“并不是我夺舍祂，而是我把祂吃了。”</p><p>杨帝拍拍阿巴的鱼头，“生命在于吃喝。你跟着我，可能无法获得那什么‘大罗道果’，但你一定能酣畅地吃吃喝喝。”</p><p>此时，守望者舰队传来通信：</p><p>「杨帝阁下要离开这个宇宙了么？」</p><p>这个问题暗藏三重精妙之处。</p><p>其一，以“离开这个宇宙”作问，既避开了直问穿梭宇宙技术的冒昧，又精准切中核心诉求：若杨帝确认离开，便意味着掌握跨宇宙穿梭的能力。</p><p>守望者文明希望，借此自然开启技术探讨的可能性。</p><p>其二，“阁下”的敬称暗含拉拢之意，用尊重铺垫后续潜在的合作请求，淡化技术索取的功利性。</p><p>我认你作老大，但如果不惠惠你小弟，那还怎么当老大呢？</p><p>其三，通过含蓄的问询试探杨帝态度，若对方否认离开，说明仍有合作空间。</p><p>若肯定，便能顺势以“宇宙交流”“文明互助”等理由委婉表达学习穿梭技术的愿望，将己方需求包裹在宏大的宇宙发展叙事中，既不失文明体面，又为后续谈判预留回旋余地。</p><p>守望者文明已经做好和对方扯皮半个月的打算了。</p><p>杨帝却说：“如果你想学，你也跟过来？怎么样，多个人也只是多双吃饭的筷子。”</p><p>守望者文明已经忘记——自从自己将物质身体替换成超级战舰、思维上传至格式塔网络，他们已经多久没有做过“咽一口唾沫”的动作了。</p><p>但此刻，他们的底层代码逻辑中，回旋着一条象征“咽口唾沫”的指令。</p><p>「杨帝阁下……那我派人跟随，可否？」</p><p>“我说可以，那就是可以的啦……不过看你战舰风格，感觉你们文明的审美和我有些对不上。这样吧，我想想……有了。”</p><p>杨帝打个响指，撤除“风王结界”。</p><p>人、鱼、舰队三角的中央，出现一座银白色机甲。</p><p>“这座机甲，以你们的科学水平应该还没有能力破解100%的技术，但你们可以参考机兵的设计审美。当然，你们也可以尝试下，尽可能多地解析这台机兵的技术。”</p><p>反正机兵不是杨帝的，爱怎么折腾就怎么折腾。</p><p>“但这台机甲的力量，你们还是要小心利用为好，不要被心怀歹意的家伙趁虚而入了，因为‘无限机兵’极其强大……”</p>
