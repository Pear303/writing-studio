# 无限机兵

<p>“你来自下层，杨帝。那个你获得力量的世界，与根茎层的无限灵能相比，其现实丰度……近乎为零。”</p><p>“现实丰度。这是衡量一个世界‘真实’与‘稳固’的核心指标。灵能，不过是它的外在显化。”</p><p>“你一路向上突破，从零丰度的底层，跃升到低丰度的中层，再到你此刻立足的、拥有‘无穷’灵能的根茎层……”</p><p>“每一次跃升，你是否感觉到世界的‘质感’在变化？法则更稳固，物质更凝练，能量更磅礴？那种‘存在感’本身，是否越来越沉重、越来越……真实？”</p><p>赤狐出现在杨帝身侧。</p><p>“这就是现实丰度的提升，越是向上，越是接近‘真实’的源头。</p><p>“根茎层，绝非顶点！它只是这棵叙事巨树暴露在地表之上的部分。</p><p>“向上！在根茎层之上，在更接近虚空天花板的地方，必然存在更高层级的‘土壤’。</p><p>“那里的现实丰度，将超越根茎层的‘无穷’。那里的世界，将更接近绝对的‘真实’。</p><p>“我几乎可以肯定，那才是真正的‘真实世界’所在，是我们所有叙事，所有世界，所有‘沙盘’和‘沙子’的终极源头。”</p><p>它的意念晕染着不容置疑的强烈笃定，如同狂信徒在宣讲神谕。</p><p>虚无的旅程仿佛持续了永恒，又仿佛只是一瞬。</p><p>前方的绝对漆黑中，一点微光突兀地亮起。</p><p>然而光芒并非温暖，而是仿若墓碑般的冰冷质感。</p><p>随着靠近，微光迅速扩大，勾勒出一个端坐的轮廓。</p><p>一个身影正对着他们，身后是凝固成永恒墓碑的宇宙泡影残骸，身前是翻滚咆哮的光锥之外的无尽黑暗。</p><p>某个宇宙，镇守历史终结点的圣人。</p><p>祂的存在如同横亘在已知与未知之间的叹息之壁，散发着令万物归寂的绝对威压。</p><p>任何试图穿越此地的存在，都将被祂视为对终结秩序的亵渎，予以无情镇杀。</p><p>耶罗大仙和杨帝轻易绕过了他。</p><p>圣人端坐的背影纹丝未动，仿佛从未察觉身前虚空中，那两道如同尘埃般滑过的存在。</p><p>杨帝和赤狐，又接连穿过了十的九十多个次方的宇宙。</p><p>穿过最后一个世界，继续向「上」，已经再没有新的世界了。</p><p>本宇宙群呈现“狐狸”的超维度结构，并在有限维度中的投影是一个分形结构，每个分形都是相似的狐狸构造……</p><p>如果将耶罗大仙实控的10^95次方数量的宇宙群落，看作是一只巨大的狐狸。</p><p>那么，狐狸的姿势是端坐于地，鼻尖朝天。</p><p>现在，他们就位于鼻尖最上层的那根毫毛的末端。</p><p>赤狐的暗黄长袍在混沌乱流中猎猎，它楔形的黑曜石瞳孔爆发出前所未有的光芒，意念如同最狂热的洪流。</p><p>“看！感受！杨帝！</p><p>“这就是我所掌控宇宙群的边缘，这就是盒子之外的‘空白’。</p><p>“这里的混沌，不是终点，它是孕育更高现实的温床。</p><p>“向上！继续向上，穿越这片混沌，在混沌的彼端，在更接近虚空天花板之处——</p><p>“那里，必然存在着丰度超越想象的土壤。存在着真正的‘真实’。</p><p>“加入我，与我一同凿穿这混沌，去见证，去抵达，去掌控那终极的真实。</p><p>“这才是我们存在的终极意义，超越一切叙事的——终极自由！”</p><p>赤狐的意念在狂暴的混沌乱流中回荡，充满了对“更高真实”的狂热信仰与不顾一切的渴望。</p><p>它死死盯着杨帝，等待着这个最大异数的最终抉择。</p><p>是满足于根茎层的王座，还是追随它，冲向那可能存在的终极真实？</p><p>赤狐狂热的意念还在混沌乱流中震荡，它楔形的黑曜石瞳孔燃烧着对终极真实的渴望。</p><p>下一秒，那燃烧的渴望骤然冻结。</p><p>它觉察到有不好的事情即将发生。</p><p>“走！”赤狐的意念第一次带上了近乎失真的急促尖利。</p><p>它覆盖赤红绒毛的爪子猛地探出，抓向杨帝的手臂，试图强行将他拖离这片区域。</p><p>杨帝纹丝不动。</p><p>他的黑眸死死盯住赤狐视线的方向——那片翻滚的混沌深处。</p><p>起初只是零星几点银白。如同在浓稠墨汁中撒落的几粒盐晶，微弱，但异常醒目。</p><p>然后，是几十点，几百点……</p><p>如同被无形之手拨动了开关，银白的光点以超指数级暴涨！</p><p>从稀疏的星屑，到密集的星尘，再到奔涌的星河。</p><p>短短一息之间，目力所及的混沌虚空，已被一片无边无际、冰冷死寂的银白之海彻底淹没！</p><p>它们不是自然光点。</p><p>每一个光点，都是一具人形的轮廓。</p><p>棱角分明的躯干，流线型的四肢，毫无生气的光滑头部，肩部延伸出冰冷的炮管轮廓。</p><p>通体覆盖着毫无反光的哑光银白装甲，如同批量浇筑的金属墓碑。</p><p>无穷无尽，沉默如渊——无限机兵。</p><p>杨帝的瞳孔，在认出那片银白狂潮的瞬间，猛地收缩至针尖大小。</p><p>一股源自生命本能的震悚感，如同高压电流般瞬间贯穿了他超越无穷的躯壳与意志。</p><p>是它们，无限机兵。神圣星环盟约。</p><p>不是一具，亦非百具，也不是亿万兆京，无量大数，恒河沙数……</p><p>是填满视界，塞满感知，将整个虚空都染成死寂银白的——军团。</p><p>赤狐抓向杨帝手臂的爪子僵在半空。它那张覆盖着赤红绒毛的狐狸脸上，第一次清晰地显露出一种名为“惊骇”的情绪。</p><p>“放开。”杨帝下令。</p><p>他反手，如同铁钳一把扼住了赤狐覆盖着暗黄袍布的脖颈。</p><p>五指收紧，布料下的喉管结构在绝对力量下发出沉闷的挤压声。赤狐的意念被强行掐断，只剩下意识层面痛苦的嘶鸣。</p><p>“那是什么？关于你警告过我的星环盟约，你都知道什么？”</p><p>杨帝的目光没有离开那片沉默逼近的银白金属狂潮，“说！”</p><p>赤狐在他的钳制下一动不动，一个破碎的意念从被遏制的咽喉中挤出：</p><p>“星环盟约……虚空中最庞大的力量……”</p><p>“无限机兵防卫圈……”</p><p>“被它们锁定……会被……”</p><p>就在赤狐意念落下的瞬间。</p><p>那片无边无际的银白机兵海洋，在同一刹那，抬起了它们那光滑的金属头颅。</p><p>无数个毫无反光的冰冷面部，精准无比地，锁定了混沌乱流中那两个渺小的存在——杨帝，以及他手中钳制的赤狐。</p><p>嗡——嗡——嗡——</p><p>如同亿万张金属薄片以最高频率共振，瞬间充斥了整片虚空。</p><p>「坐标锁定完成。」</p><p>「目标个体：耶罗，杨帝。」</p><p>「你们已被包围。」</p><p>「放弃抵抗。」</p><p>「立即解除武装。」</p><p>「接受星环盟约审查。」</p><p>「重复：放弃抵抗。立即解除武装。接受格式化审查。」</p>
