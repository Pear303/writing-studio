# 咒怨之始

<p>那颗行星的灭绝，始于一个再简单不过的悲剧：一个无辜者在一栋陋室中含冤而死。</p><p>极致的怨恨没有消散，滔天业力反而凝结成了最初的“咒怨”，如同滴入清水的一滴浓墨。</p><p>第一个踏入凶宅的探访者被杀死。他的恐惧与不甘融入了最初的诅咒，使其壮大一分。</p><p>随后是第二个、第三个……每一个死者都成为咒怨新的养料，让它变得更强大、更饥渴。</p><p>凶宅的边界开始扩张，吞噬了整个街区。踏入这片死域的人无一幸免，他们的死亡又让诅咒的雪球越滚越大。</p><p>街区变成死城，死城蔓延成死国，死国覆盖整片大陆……最终，这自我复制的死亡诅咒如同瘟疫般横扫全球。</p><p>几十亿人的恐惧、痛苦和绝望相互叠加、催化，最终形成了此刻横亘在虚空中的、凝聚了整个文明所有怨念的——天文级咒怨集合体。</p><p>就在这时，一旁的一眉大帝身体猛地一僵。</p><p>他的皮肤瞬间变得灰败，眼珠暴突，喉咙里发出“咯咯”的异响——这是最经典的咒怨杀方式。</p><p>噗通一声，他直挺挺地倒下，气息断绝。</p><p>然而下一秒，他体内某个保命法宝微光一闪，尸体消失，又在不远处重塑出一个新的他。</p><p>可这新身体刚凝实，又立刻以另一种方式暴毙——可能是七窍流血，可能是浑身骨骼碎裂，也可能是毫无征兆地自燃成灰。</p><p>他就这样，在杨帝和太一矩枢的旁观下，连续不断地以各种凄惨的方式暴毙、复活、再暴毙……</p><p>如此反复了几十次，那恐怖的即死诅咒似乎才稍稍减弱，或者说，暂时“满足”了。</p><p>一眉大帝第N次重塑身形，瘫坐在虚空中，脸色惨白如纸。</p><p>他喘着粗气，抹去嘴角不断渗出的血沫，死死盯着那颗化作巨眼的猩红行星。</p><p>“一整个文明死绝凝结成的咒怨……竟有了真仙巅峰大圆满的实力！让考察员见笑了。”他声音嘶哑，带着难以置信的惊惧。</p><p>下一秒，他周身气息陡然剧变。</p><p>那副被迫营业的窝囊样瞬间消失无踪，一股浩瀚无边、足以令星辰倒转的威压轰然爆发！</p><p>仙帝修为，展露无遗。</p><p>他甚至没有动用任何法术，只是隔空朝着那行星巨眼，遥遥一握。</p><p>咔嚓——！</p><p>仿佛整个虚空都被捏碎的巨响传来。</p><p>那只由亿万怨念和血海构成的巨大眼球，连同其下的整个行星，就像被一只无形巨手攥住的脆弱鸡蛋，瞬间向内坍缩，随手挤压崩碎。</p><p>连同其中嘶吼的咒怨，一同被捏成了黑洞。</p><p>物理驱鬼，最为彻底。</p><p>然而，漫天星辰渗血的恐怖异象并未结束。</p><p>一眉大帝的通讯器急促响起，传来绝望的汇报：</p><p>宇宙各处，每时每刻都有生灵怀着极致怨恨死去，散逸的业力早已饱和。</p><p>此刻，整个宇宙的咒怨突破了某个临界点，正凝结成一个统一的、无处不在的恐怖存在。</p><p>简单来说收容失效了，全宇宙的咒怨、灵异、鬼魂……都跑了出来，并且连为一体。</p><p>什么东西比贞子恐怖1000倍？</p><p>也就是1000个贞子。</p><p>那么什么东西比伽椰子恐怖1000倍？</p><p>正确答案是，体积放大1000倍的伽椰子。</p><p>这个世界，在考察员来到后，恰到好处的闹鬼了。宇宙级的闹鬼。</p><p>……</p><p>杨帝睁开眼。</p><p>宿舍里冷得反常。</p><p>明明已是初夏，窗外夜色沉闷，室内的空气却凝滞着一种渗入骨髓的阴湿寒意，不像空调，倒像停尸房的冷柜无声地敞开着。</p><p>头顶的日光灯管滋滋轻响，光线非但不亮，反而在墙壁上投下一种泛青的病态惨白。</p><p>所有物体的边缘都模糊不清，像是蒙着一层翳。</p><p>空气里飘着一股难以名状的腐败甜腥气，混着外卖盒里冷掉的油腻味，令人作呕。</p><p>杨帝嘴里还嚼着拼优饭送来的潮汕肉卷，味道是酸的，带着一股难以言喻的苦涩。</p><p>但他太饿，还是机械地咽了下去。</p><p>宿舍里不算安静，键盘敲击声响不绝耳。舍友张明远正背对着他，在电脑前专注地做课题。</p><p>杨帝的视线落在手边那杯外卖奶茶上。</p><p>厚厚的塑料包装袋被一个极其复杂的死结紧紧缠住，勒进了杯壁。</p><p>他用力扯了扯，那结纹丝不动，反而更紧了。天杀的，为什么打死结，又不是项圈。</p><p>他需要剪刀。所以他极其自然地向唯一可能在宿舍的室友张明远开口去借。</p><p>“明远。”杨帝舔了舔发涩的嘴唇，声音有些沙哑，“你那儿有剪刀么？”</p><p>张明远缓缓转过头。</p><p>他的眼神空洞呆滞，脖颈上正插着一把生锈的剪刀，剪刃深深没入喉管，只留下手柄在外微微颤动。</p><p>暗红的血液顺着他的衣领往下淌，但他仿佛毫无知觉。</p><p>杨帝心中先是一惊，随即记忆涌上心头——自己刚才还在幽荧界宇宙观摩土著对抗咒怨。</p><p>于是他只是了然地微笑了一下，平静地点点头，伸手握住了那柄插在室友喉咙上的剪刀柄，小心地将其拔了出来。</p><p>“你是我的神州好舍友。”</p><p>半糖雪王入腹，刚灌下半杯，小腹突然传来一阵急胀的尿意，像有根弦陡然绷紧。</p><p>纵然已经证道圣人，也仍逃不过这一劫吗？独自一人在恐怖场景里上厕所，这就是命运……</p><p>拉开阳台门，对着嵌刻于大地之上的深邃黑洞，开闸泄洪。</p><p>完事后转身，却发现通往宿舍的玻璃门变成了一片浑浊的毛玻璃，完全看不见室内景象。</p><p>防盗网外是浓得化不开的纯粹黑暗。</p><p>他走到角落的水龙头前——拧开，流出的竟是粘稠温热的鲜血。</p><p>他面无表情地用这血水冲了冲手。但其实心底还是有些惊奇——哇，这无限量的鲜血供应，血库永远都不会告急！</p><p>一只冰冷、浮肿的手悄无声息地搭上了他的肩膀。</p><p>杨帝动作丝毫未顿，仿佛那只是滴水珠。</p><p>其实此时此刻，他内心也是点头称赞——这么多野生的残肢断臂内脏器官，这是排队等待器官更换的患者们的福音……</p><p>他甩了甩手上的血珠，关掉“水龙头”，对肩上的手置之不理，径直走向那扇无法看透的玻璃门。</p><p>杨帝拧了拧门把手，纹丝不动。他加力再试，门把仿佛焊死一般。</p><p>面前的玻璃逐渐映出他的倒影，但不是自己的模样，而是一张扭曲惨白、双眼流血的鬼脸，正咧着嘴对他无声怪笑。</p><p>杨帝面无表情，后退半步，猛地抬脚狠狠踹在门板上！</p><p>“嘭”的一声巨响，整扇拉门连同旁边的墙体应声向内爆裂，碎石飞溅，墙上瞬间蔓延开几十道蛛网般的裂缝。</p><p>门后，宿舍内一片漆黑空荡，张明远连同他的电脑桌椅消失得无影无踪，只有阴冷的风打着旋。</p><p>杨帝毫不停留，径直穿过废墟，拉开宿舍大门。</p><p>门外走廊上，密密麻麻站满了人。</p><p>所有学生都静默地仰着头，脖颈绷直，眼睛一眨不眨地盯着空中那轮巨大无比、散发着不祥血光的月亮。</p><p>没有人说话，没有人动作，只有一片令人毛骨悚然的死寂。血红色的月光洒下，将每一张仰望的脸都照得如同毫无生气的蜡像。</p>
