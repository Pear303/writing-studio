# 批发的零

<p>杨帝打算强行压制，却如同徒手攥住正在发射的枪管，收不住。</p><p>灵能洪流在体表凝成无数道螺旋纹路，如同无形膛线缠绕他的躯体，将能量疯狂压缩。</p><p>“再度不好意思，真的收不住力了。”杨帝只能讪笑，“不过我可以给你们看看，我研究‘第七识’末那识的最新成果。”</p><p>啵。</p><p>像是某种桎梏碎裂的脆响。</p><p>又如无形丝线被骤然扯断，失控的灵能洪流瞬间调转方向。</p><p>经常打仗的朋友都知道，枪管内侧有一圈一圈螺纹状的膛线。</p><p>而此刻，杨帝周身这股灵能洪流，就像被点燃底火的弹药，沿着“灵能膛线”的轨迹，裹挟着撕裂空间的尖啸，冲天而起！</p><p>归墟之地的虚无领域在这股力量面前竟如同薄纸，被灵能柱瞬间撕开一道巨大裂缝。</p><p>螺旋状的灵能柱所过之处空间如镜面般扭曲破碎，将周围的空间绞成齑粉，像是被线膛枪射杀的狐狸。</p><p>灵能直冲云霄，划破苍穹，灵界上空的云雾被尽数撕裂，露出诡谲的靛紫色天空。</p><p>杨帝甩了甩发麻的手腕，指尖还残留着灵能溃散时的震颤。</p><p>“我方才灵光一闪，就有个好点子——领域不是暴力征服，而是让空间自愿接纳我的存在，所以在强行将自己的意志刻印进空间之前，不如先学会放手。”</p><p>“所以您是……放弃了对灵能的控制？”</p><p>“准确来说，是放弃了‘控制’这个执念，让离开我体外的灵能，不再是我身体的一部分。”</p><p>这并不同于“消耗灵能构筑法术”。</p><p>消耗灵能构筑法术，蓝条上限不变。</p><p>而现在，杨帝主动地削短蓝条上限。</p><p>蓝条的“损伤判定逻辑”，和血条不太一样。</p><p>众所周知，“灵”被划分成主体性的和客体性的，相当于真牙和假牙。</p><p>释放法术，其实是消耗“假牙”的那部分。</p><p>而杨帝所做的，是把自己的“真牙”给拔了下来，直接削减蓝条上限。听起来有点疼，事实上确实很疼。</p><p>杨帝低头看向自己的掌心。</p><p>「现实+1+1+1+1……」</p><p>效率比较低下，因为他损失的只是自己很小一部分灵能。</p><p>从比例的角度看，这实在只能算是轻微伤，连最基本的“重伤”都算不上，更不用提“致命伤”了。</p><p>只是，这“很小一部分灵能”……似乎已经能影响整个灵界的灵能环境了。</p><p>灵界，算上“归墟”这种特殊地形，整个大环境平均灵能水平，约为19982灵。</p><p>也就是说，在这儿出生的人，最次都有两万灵的强度，媲美十环超限大法师。</p><p>很多灵界土著出生炼气，小学筑基，初中金丹，成年元婴。</p><p>而现在……</p><p>环境平均灵能水平，是23944灵。</p><p>整个灵界，平均灵能上涨了将近4000灵！</p><p>是整个灵界！一整个世界。</p><p>正是杨帝将自己的“真牙”拔下来了一颗，化作一粒硕大无朋、横亘天地的“超级假牙”。</p><p>而他自身的灵能，也在痛饮归墟渊水后，再度提升一个台阶，几个台阶，几千万个台阶。</p><p>食指中指并拢下划，调出人物面板。</p><p>【综合力量：E101】</p><p>【综合抗性：E107】</p><p>【现实丰度：E113】</p><p>有效数位已经不那么重要了，重要的是指数位，也就是数字后面会跟多少个零。</p><p>从人物面板可知，杨帝的综合力量属性为E101，意味着该属性后面跟着101个零；综合抗性属性跟着107个零，现实丰度跟了113个零，真把零当做是批发的。</p><p>……</p><p>在杨帝将“很小一部分灵能”射飞后10分钟。</p><p>天边，骤然爆发如海灵压。</p><p>59改将阿巴和青丘白璃护至身前：</p><p>「检测到361组空间波动，灵界强者抵达倒计时：3秒。」</p><p>青丘白璃也感受到空气的异样。</p><p>她望着天际，远端裂开了数十道空间裂缝，每道缝隙中都传来让灵魂略微震颤的威压。</p><p>数百个与自己同级别的真仙大能、正气势汹汹赶来！</p><p>用尾巴想都能知道，他们的目标是杨帝。</p><p>进一步用尾巴尖儿上的毛思考，都能明白，他们是被归墟的异动、环境灵气的异变所吸引。</p><p>空间裂缝中，一个精神小伙脚踏九天龙辇率先踏出！</p><p>青丘白璃惊呼：“十万年前叱咤一时的凌云圣皇！我还以为他早死了。”</p><p>凌云圣皇目光如炬，锁定杨帝的瞬间，周身的星辰之力骤然暴涨：“归墟大帝您又来喝……不是归墟大帝？何人胆敢在此搅动归墟、破坏灵界平衡！”</p><p>杨帝举起“锋利3000+灵能修补+海之眷顾”的神级撬棍：“你变脸太快了！”</p><p>越来越多空间裂缝，越来越多从裂缝中涌出的绝世强者。</p><p>青丘白璃能叫得上名字的，叫不上名字的，还以为已经死了的……皆尽现身！</p><p>都是灵界数一数二的真仙境大能，有的甚至比青丘白璃强上二三十个百分点。</p><p>杨帝拥有10^113灵数量级的现实丰度，这个数值震古烁今。</p><p>灵界众强者围上来时，情况本该是这样的：</p><p>————进入幻想————</p><p>【杨帝手持神级撬棍，周身灵能迸发，现实丰度如浩瀚星河般璀璨。】</p><p>【他望着九天十地蜂拥而至的灵界强者，嘴角勾起一抹霸道至极、耐克标志的冷笑。】</p><p>【“一群土鸡瓦狗，也敢在本帝面前放肆！”杨帝声如洪钟。】</p><p>【那些刚从裂缝中踏出的强者，竟有大半被这股无形威压震得气血翻涌，嘴角溢出鲜血。】</p><p>【其他灵界强者见状，也只能纷纷祭出本命法宝，只能堪堪勉强抵挡住杨帝的一个字、一个眼神。】</p><p>【那些残存的灵界强者，望着杨帝那宛如神明般的身影，只好俯首称臣。】</p><p>————退出幻想————</p><p>幻想很丰满，现实很骨感。</p><p>在外人看来，杨帝的灵能呈现诡异的负数形态。</p><p>正常修仙者的灵能是外放，犹如无私奉献给予的恒星。</p><p>而他是向内缩，就像一颗阴险狡诈、年老色衰、诡谲多变的黑洞。</p><p>试想一下，当某位正在暗无天日的山洞里闭关打坐的大能，突然感应到一道冲天而起、撼动了整个世界的灵能爆发。</p><p>他会觉得那是啥？</p><p>有可能是史上最强至宝出世，一出现便引动此界的灵气大变。</p><p>也可能是大帝身死道消，一鲸落万物生。</p><p>但直到他们匆匆赶到——暂且不论本地土著青丘白璃在干嘛。</p><p>——也暂且不论那个同样是真仙境巅峰大圆满的美少女大能、只有炼气期灵能波动的国字脸大叔他们是谁。</p><p>至少在归墟附近，那个灵能状态诡谲的东西（指杨帝）一看就不是人！！</p><p>负值的灵能，并不能表现出正常的“滔天灵压”。</p><p>根本没有压迫感，而且让人看着非常不对劲。</p><p>一看就是域外天魔，至少也得是魔道修士！</p><p>我辈修士，诛魔伏邪，在所不辞啊啊！</p>
