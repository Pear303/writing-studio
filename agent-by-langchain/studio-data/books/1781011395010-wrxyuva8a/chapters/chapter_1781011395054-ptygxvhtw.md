# 钓鱼佬二三事

<p>那客人脚步略显蹒跚，背着个破旧的渔具包，头戴一顶褪色宽檐渔夫帽。</p><p>眯起眼一看，杨帝看清了他——那张脸和父亲的很像，是典型的中年男人模样。</p><p>“嘿，小伙子！”</p><p>钓鱼人还没走到近前就大声打招呼，“你咋在这烂尾楼楼顶呢？这地方可阴森得很呐。”</p><p>杨帝：“随便转转，倒是您，怎么会来这钓鱼？这可不是个常见的钓鱼地儿。”</p><p>钓鱼人咧嘴一笑：“嘿，您可别小看这地方，我听说这楼的电梯井积水里藏着‘大鱼’，罕见的品种。我钓了这么多年鱼，就爱找些特别的地儿，说不定能钓到个稀有的。”</p><p>说着，他拍了拍背后的渔具包。</p><p>杨帝在楼顶呼喊：“这儿危险，是危楼来，回去吧。”</p><p>钓鱼佬却不以为然，摆了摆手：“小伙子，我啥大风大浪没见过，钓鱼嘛，讲究个随缘。”</p><p>杨帝无奈地摇摇头，走楼梯下去一楼。</p><p>刚到最下层，中年男人已经坐下钓鱼凳。</p><p>他坐在电梯井旁，熟练地打开渔具包。</p><p>拿出鱼竿、鱼饵，开始钓鱼。</p><p>一边忙活，一边哼起了不知名的小曲。</p><p>杨帝蹲在他旁边，一起看着他将鱼钩甩进电梯井。</p><p>鱼钩带着鱼饵，在空中划过一道弧线，“噗通”一声落入电梯井那漆黑的积水中。</p><p>水面很快恢复平静，什么也没有。</p><p>钓鱼人并不着急。</p><p>他哼着小调，从渔具包里掏出一本电子阅读器，享受着这宁静的等待时光。</p><p>他还在钓鱼凳的扶手凹槽，放了个搪瓷杯，用保温杯里的热水冲了一杯速溶奶茶。</p><p>钓鱼佬惬意地抿了一口奶茶，瞥了一眼身旁神色紧张的杨帝。</p><p>他笑着说道：“小伙子，我心里也清楚，这地方按常理是不可能有鱼的。你看这楼，荒废成这样，四周又没什么水源流通，怎么可能有鱼。”</p><p>确实如此。</p><p>他轻轻晃了晃手中的搪瓷杯，热气腾腾的速溶奶茶，散发出淡淡奶香。</p><p>“钓鱼不是为了鱼，钓的是一份期待。你想啊，在这本不可能有收获的地儿，说不定下一秒就有惊喜咧，多有意思。”</p><p>原来是个赌徒，杨帝如此理解。</p><p>但“不可能”和“说不定”，这两个词是纯粹的矛盾关系啊喂。</p><p>杨帝看了眼手机上的日落预报。</p><p>他说：“你还能在这待10个小时，落日之前就得离开。”</p><p>“哦，那当然，我从不夜钓。”</p><p>钓鱼佬穿着人字拖，半只脚板就这么泡在积水里，裤腿沾着绿藻。</p><p>他体态匀称，身体健康，而且看起来心情不错。</p><p>钓鱼人继续说：“你一定觉得我精神有问题，或者有什么怪癖，才会来这种地儿钓鱼。我跟你说，不是。你知道古埃及神话的‘Nun’吗？它代表水的无边、混沌和永恒，古埃及人认为水是世界的起源，所有的水都是连在一起的。如果你听说过希腊亚各斯古城的无底洞，你会发现那个所谓的‘无底洞’其实和凯法利尼亚岛另一边的洞窟是通的。我想说，这世上有很多水体，看起来没关系，但从更高的层次或者维度看，它们是连在一起的。”</p><p>“原来如此，我大彻大悟了。”</p><p>杨帝能理解他说的每一个字，但捋不顺他的逻辑。</p><p>很多水体……从更高的维度看是连在一起的？</p><p>“对了，如果你还待在这，就帮我个忙——若是鱼漂动了，就叫我。”</p><p>他一边喝速溶奶茶，一边看电子书，沉浸在书里的世界。</p><p>杨帝瞥了一眼钓鱼佬手中的电子阅读器。</p><p>发现屏幕上显示的竟是《人类补完计划》，不禁微微挑眉。</p><p>杨帝他老爸有丰富的阅历，但终归知识水平不高。上年纪后，仍然被短视频自媒体和营销号荼毒，沉迷于《谷子鬼》《人妻的弱点》《羊皮卷轴》，以及众多人生鸡汤类畅销书。</p><p>钓鱼佬似乎没察觉到杨帝的惊讶。</p><p>杨帝蹲在他身旁，问道：“大哥，你听说过‘耶罗大仙’，或者是‘黄衣之王’么？”</p><p>“耶罗？当然知道，他也算是个传奇……”</p><p>杨帝警觉：“大哥，请细说。”</p><p>“那我简单说说吧。和大多数传奇一样，耶罗的家庭足球氛围相当浓厚。凭借在巴拉多利德的成绩，费尔南多受到其他俱乐部的关注……”</p><p>“等等，什么足球？什么费尔南多？”</p><p>“费尔南多·耶罗，西甲银靴啊——你不是问我这个吗？”</p><p>显然不是问一个人类球员。显然。</p><p>杨帝拍拍身上的灰尘，站起身来：“大哥，那您先钓着。对了您有烟么？”</p><p>钓鱼佬放下手中的电子阅读器：“嘿，小小年纪就有瘾了？”</p><p>他在渔具包里翻找起来，掏出一包皱巴巴的烟，从中抽出一根递给杨帝。</p><p>“谢这位叔，这不是给我吃的。”</p><p>钓鱼佬头也不抬，摆了摆手。</p><p>杨帝重新回到楼上。</p><p>昨日，他原则上只清理了门开着的房间，对于门锁上的房间，他秉持着尊重原则，不会轻易去破门而入。</p><p>然而，有一个例外。</p><p>——就是出现在电梯井的那只苍白的手，以及水渍延伸到的房间。</p><p>那是他唯一破门而入的房间。</p><p>现在想来，昨天太冲动了。</p><p>私闯民宅，坏了自己给自己立的规矩——不能欺凌弱小者。</p><p>所以，杨帝打算带些慰问品去请罪。</p><p>他拿着钓鱼佬给的香烟，在楼道找了一圈，发现一个还算干净的盒子，将香烟小心翼翼地放进去。</p><p>再次来到那扇被他撞开的房门前。</p><p>那扇门，昨晚他已经重新安上去了。</p><p>杨帝轻轻敲了敲门，尽管他知道，这屋里很可能没有正常意义上能回应他的“人”。</p><p>紧闭的房门后传来一阵沉重的呼吸声，声音中充满疲惫——或许还有愤怒。</p><p>“昨天实在对不住，我不该贸然闯进来。这烟算不上什么特别贵重的东西，但在这烂尾楼里，也算是一份心意了。”</p><p>杨帝对着门内说道，然后将装着香烟的盒子轻轻放在门口。</p><p>意思是“给你上一炷香”。</p><p>他将烟立起来，食指拇指微微搓捻。</p><p>他已经掌握最初级的现实扭曲方法。</p><p>通过操纵事物中的“灵”，杨帝能够在一定程度上，轻微改变事物的运动状态、物理性质。</p><p>周围的空气泛起一阵涟漪，就好像空间本身变成了柔软的绸缎，被肆意揉弄。</p><p>香烟的顶端亮起一点火星。</p><p>那燃烧的香烟静静地立在盒子里，橘红星火在阴暗环境中摇曳。</p><p>“其实我只是想找你谈谈罢了，昨天你躲太快，我有些应激，冲动了，真不好意思。”</p><p>杨帝集中精神，继续施展现实扭曲能力。</p><p>门轴处，一些细微的木屑开始自行振动，仿佛被一只无形的手重新排列组合。</p><p>原本断裂的锁芯内，金属分子在“灵”的引导下，缓缓流动、融合。</p><p>锁舌与锁扣之间，缺失的部分逐渐填补完整。他修补好这扇门。</p><p>这是他目前摸索出来的最新能力，宏观物质形态重组。</p>
