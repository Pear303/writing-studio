# 红烧杨帝

<p>他真的是人吗？</p><p>与其说是人，不如说更像是一尊正在锻造中的神魔兵器，一碟正在蒸煮中的红烧排骨。</p><p>“现在的我已经提前步入……元婴中期巅峰大圆满、半步元婴晚期！马马虎虎，不过这‘桑拿’蒸得还算通透。”</p><p>整整十一个小时的高强度“淬炼”。</p><p>杨帝用自己的毛发，将藏匿在阴影中的众人密密麻麻包裹起来。</p><p>“我的头发，已经能耐受5万摄氏度的稠密等离子体持续喷射，待会儿的大爆炸，应该能大大缓解高温和粒子流的瞬时杀伤。”</p><p>适应性进化——这正是杨帝核心能力「抗拒外力因素导致的变化」的最简单表现。</p><p>“哦，对，还有我有一件极其重要的东西要交给你，你要用你的生命保护住它，否则我把你们全吃掉。”</p><p>杨帝半恐吓半威胁地将一样东西交给影子。</p><p>那是张泛黄的便签纸。</p><p>纸上写着关于草原、乌云、清风与阳光的那个幻想世界。</p><p>影子凝重地点点头，将这张便签纸也融入阴影，随后一同被毛发缓缓包裹起来。</p><p>红皇后冰冷的声音适时响起。</p><p>她带着一种前所未有的敬畏：</p><p>「自毁程序最终确认。倒计时启动：」</p><p>「00:15:00」</p><p>「00:14:59」</p><p>「聚变核心超载中……引擎阈限阀门关闭中……」</p><p>「00:13:26」</p><p>「目标区域：整舰……预计爆炸当量：200亿吨TNT等效当量……能量释放模式：定向内爆，最大化湮灭效果……」</p><p>「00:12:24」</p><p>轮回小队五人被彻底包裹在致密的黑色毛球核心，如同坠入最深沉的夜。</p><p>外界的一切声音、光线都被隔绝，只有杨帝平稳的呼吸声，和毛球内部结构微微脉动的低沉嗡鸣，成为他们唯一能感知到的现实。</p><p>“记得你们探索过垃圾投射口？”杨帝的声音在绝对的黑暗中响起。</p><p>清晰得如同在耳边低语。</p><p>队长一愣，立刻回应：“对！引擎区附近，一个大型气密舱，用于处理不可回收废弃物，直接向深空弹射。我们检查过，舱门被厚重的生物质封死了……”</p><p>“它通向船外。”杨帝接话道，“足够了。”</p><p>包裹着他们的巨大黑色毛球猛地一震！</p><p>一股强大的加速度毫无征兆地传来，将他们狠狠地“按”在了毛球内壁上。</p><p>即使有影子的虚化状态缓冲，众人也感觉五脏六腑都移了位。</p><p>毛球如同一个活体炮弹，在杨帝意志的驱动下，沿着舰内通道高速滚动、弹跳，厚重的合金舱门在它面前如同纸糊，被轻易撞开或挤碎。</p><p>沿途试图阻拦的零星虫族或丧尸，瞬间被这裹挟着恐怖动能的黑色巨球碾成了宇宙尘埃。</p><p>他们在最后5分钟，成功撞破了垃圾投射仓的大门。</p><p>并和红皇后合作，将自己塞进了投射舱内。</p><p>此时距离聚变爆炸还剩5分钟。</p><p>「00:05:00」</p><p>「00:04:59」</p><p>漆黑的毛球炮弹，以2倍音速的初速，从垃圾投射口激射而出。方向与“探索者-7号”科研船前进方向，完全相反。</p><p>没办法，只能这么快，又不是动能大炮。</p><p>「愿自由众星护佑你们。」</p><p>「00:00:00」</p><p>嗡……！！！</p><p>真空中没有声音。</p><p>但光芒——足以刺瞎肉眼的光芒，在飞船的核心位置爆发！</p><p>那光芒之强烈，瞬间压过遥远的恒星，将飞船本身映照得如同透明。</p><p>此时即使在人的眼睛与爆炸之间，筑起一道一米厚的水泥墙，那人也会一瞬间整个眼球被点燃，整个身体被点燃，全部的精神与思想都被点燃！</p><p>探索者-7号。</p><p>数以万吨计的金属碎片，熔融的装甲，以及未能逃逸的虫族残骸，被狂暴的能量冲击波裹挟着，化作急速膨胀、炽热无比的金属风暴云团。</p><p>而就在这毁灭风暴的边缘，那颗反向高速飞离的黑色毛球炮弹，正承受着最猛烈的第一波冲击。</p><p>足以瞬间汽化战舰的恐怖光辐射，夹杂着高能粒子流，和超高速金属碎片的冲击波，如同宇宙的愤怒海啸，狠狠地拍打在毛球表面！</p><p>嗤——！！滋啦——！！</p><p>球体表面，那层经过五万度稠密等离子淬炼的五米厚毛发，瞬间亮到极致。</p><p>毛球内部，被压缩在核心狭小虚化空间的轮回小队五人，感觉如同置身于被锻打的铁砧。</p><p>光和热无法突破杨帝的毛发球。</p><p>要命的是冲击波。</p><p>物理上的冲击，赋予了杨帝毛发球一个极大的加速度。</p><p>尽管他已经尽量将自己的球体，设计成流线型外壳。</p><p>但在爆炸后，那持续了整整五分钟的加速度过载，仍然几乎将毛发球内的轮回者小队5人杀死。</p><p>幸好，“影子”的群体虚化技能，能够让五人的质量下降到和几粒圣女果差不多重。</p><p>这几团影子，才勉强没有被过载压成肉饼。</p><p>他们像几粒在惊涛骇浪中翻滚的尘埃，除了祈祷，别无他法。</p><p>但他们仍然分出圣母心，担忧地想到——位于毛发球外的杨帝，现在究竟是个什么情况？</p><p>……</p><p>毛发球外，杨帝的“体验”远比他们想象的更加丰富。</p><p>他终于体验了一回烤牛扒的感觉。</p><p>不过他是牛扒，正在被一颗超大当量氢弹“炙烤”。</p><p>当那足以汽化星辰的光芒、蕴含毁天灭地动能的冲击波，狠狠撞上毛发球表面的瞬间。</p><p>最外层的坚韧毛发在光辐射和粒子流的双重打击下，瞬间碳化崩解，迅速化为飞灰。</p><p>紧接着，杨帝附着在毛发壁垒外层的血肉、骨骼、内脏，被硬生生地从内嵌状态“挤压”了出来。</p><p>想象一下一颗熟透的烂番茄，被高速行驶的卡车轮胎碾爆——杨帝此刻的状态，就是那个烂番茄的超级加强版！</p><p>烂番茄！</p><p>他化作一滩粘稠的“肉糜”和“骨泥”混合物。</p><p>这摊混合物在巨大冲击力的作用下，被均匀地涂抹、摊开在毛发球的外壁结构上。</p><p>不妨想象，就像给一颗硕大的黑色石球，刷上了一层薄薄的血肉酱料。</p><p>为了尽可能防止毛发球被聚变爆炸击穿，球体正以每秒300转的速度高速自旋——这样便能确保它均匀承受冲击波与高温光热的炙烤，避免出现一面被击穿、另一面却还保留着大量耐久度的情况。</p><p>也正因如此，包裹住毛发球的杨帝血肉酱，正被均匀加热着。</p><p>血肉被瞬间烤焦、水分被极致蒸发、细胞结构在高温高压下彻底瓦解。</p><p>一股难以形容的、混合着焦糊蛋白质和奇异能量的“香气”，在封闭的球体空间内弥漫开。</p><p>虽然轮回小队闻不到，但杨帝能感觉到。</p><p>他的每一寸被摊开的血肉都在承受着极致的痛苦——被煎烤、被撕裂、被重组、再被煎烤！</p><p>无所谓，这种剧痛早就习惯了。</p><p>每一次血肉被烤焦，每一次细胞被摧毁。</p><p>——就有更多适应了这种极端高温高压环境的新生细胞，以更坚韧更高效的方式再生出来。</p><p>想当年，超人被核弹炸了一发，也是体内水分被瞬间蒸发殆尽。</p><p>现在，杨帝也很渴很渴。</p>
