# 原初之战：不可达真实

<p>大地经历了一场灭顶之灾的洗礼。四处都是爆炸后留下的巨大弹坑，向外翻卷焦黑的土石。</p><p>焦土连绵不绝，仿佛一片荒芜的黑色海洋，圣树领地外，植被已化为乌有，只留下扭曲变形的残枝败叶，半掩在滚烫的灰烬之中。</p><p>岩浆如迟缓却致命的河流，在大地上肆意流淌。</p><p>流淌到机兵的脚下，杨帝轻轻舀起一勺，冲洗干净粘在机兵外壳上的史莱姆残渣。</p><p>原初之眼在这个时代，可用的熔岩史莱姆力量很少很少。</p><p>但经过数次技术迭代，史莱姆强度和战斗烈度，都远超伊芙最初驾驶机兵战斗的那一次。</p><p>对了，那个正在向自己跑来的精灵，就是这条世界线的伊芙。</p><p>她深一脚浅一脚地从焦土中冲过来，眼神对这片千里焦土，已然麻木。</p><p>她望着杨帝的机兵，声嘶力竭大喊：“我们能不能回到四万年后去阻击原初之眼？！那里已经……已经毁得不成样子了！”</p><p>杨帝本已操控机兵准备沉默地离开，听到伊芙的呼喊，又缓缓转过头来。</p><p>短暂对视后，杨帝的声音从机兵中传出：“伊芙，你应该还记得吧？神话里提到，机兵是在‘历史的最初起点’战胜原初之眼。”</p><p>伊芙一怔，脑海中迅速闪过那些古老传说的片段。</p><p>“您在驾驶无限机兵，您究竟是谁？”</p><p>“我是杨帝，你听说过这个名字么。”</p><p>伊芙略作思索，用力摇摇头：“不曾。”</p><p>“很正常，因为在你看来，我过去并没有出现过在你眼前。”</p><p>伊芙搜肠刮肚，绞尽脑汁，还是想不到除了她自己，还有谁会来到这个时代驾驶机兵？</p><p>“杨帝阁下，您究竟是什么身份？是如何知晓我名字的……”</p><p>“我是你的朋友，至少不是敌人。我铭记你的牺牲。暂时再见，我会终结这一切。”</p><p>“你要离去了吗？你如何终结原初之眼……”</p><p>“不急，我们还会再见面的，就在‘过去’。”</p><p>更多原始精灵从圣树领地中围过来，他们好奇，感激，又有些惧怕地注视着银白色机兵。</p><p>那个曾经为了救回杨帝而牺牲的精灵少年，也怯生生地站在伊芙身后，看向机兵眼睛。</p><p>“再见，诸位。”</p><p>杨帝是在1小时53分钟15秒前来到这个时代的圣树森林。</p><p>无限机兵启动跳跃。</p><p>目的地，1小时53分钟16秒前。</p><p>也就是他第一次来到这个时代的圣树森林，的一秒前。</p><p>机兵超越因果律限制，可以肆意地造成祖父悖论。</p><p>根据这个特性，可以推演出很多更实用的“时间战术”。</p><p>比如说，不断穿越到过去，不断将原本存在于过去的年轻祖父捞到未来，以此实现克隆，甚至能解决人口老龄化问题。</p><p>同理。</p><p>即使1小时53分钟15秒前的“无限机兵”已经被杨帝开走。</p><p>但1小时53分钟16秒前的机兵，还静静埋在圣树底下的土壤，尚未被他拿去。</p><p>「因果律」在本世界的时间机器面前，只是幻象。</p><p>杨帝驾驶1小时53分钟16秒前的机兵，并不会影响曾经的自己在现在的1秒后开走的机兵。</p><p>而无限机兵所搭载的时间机器，跳跃精度极限是秒。</p><p>杨帝便以秒为单位，朝时间与历史的最初起点追溯而上。</p><p>当他获得「无限机兵II」，他就嵌套驾驶第3座机兵，获得其附魔。</p><p>“无限机兵III”之时，就去驾驶第4座机兵。</p><p>于是，杨帝从「无限机兵II」逐步跃升到「无限机兵III」，而后是IV，V，VI……</p><p>他就这样在这无尽的进化之路上狂奔，无限机兵附魔不断线性增长，与原初之眼的军备竞赛愈发激烈。</p><p>无限机兵1024……2048……4096……</p><p>从原来，大概需要10秒时间，才能驾驶新的一辆无限机兵。</p><p>到后来是8秒，4秒，1秒。</p><p>反应时间的尺度在这场进化中被不断压缩。</p><p>身体损伤和自愈速度相互追赶。而在最后，自愈的速度总能超过机兵带来的灵能冲击。</p><p>杨帝浴火，凤凰涅槃。</p><p>在无尽的伤痛与自愈中不断蜕变，不断向着不可名状的的强大迈进。</p><p>机兵并不拘泥于那座银白色机甲的具体物质形态。他所做的，是不断叠加附魔效果。</p><p>杨帝置身其中，置身于浩瀚的信息与灵能海洋，机兵内部澎湃的力量波涛汹涌，不断冲击着他的感官。</p><p>他能听见历史长河震耳欲聋的呼啸，看见时间的丝线在眼前交织、穿梭。</p><p>他看见茫茫沙海，而每一粒沙子，都是宇宙一个可能性的截图，一张快照。</p><p>某一粒沙子A，与另一粒沙子B，他们的差距可能仅仅是宇宙某荒芜地带某一个电子偏移了一皮米距离，而其他所有基本粒子的状态都完全一致。</p><p>然而，在宇宙这宏大的体系中，初始条件的微小变化，经过时间不断放大与积累，会引发连锁反应，最终导致天翻地覆的改变。</p><p>或许在沙子A所代表的宇宙里，一个电子偏移，能极其细微地改变另外一个电子的运动状态。</p><p>两个电子的偏移，又极其细微地影响到四个电子的运动……</p><p>最终，两个宇宙走向截然不同的命运，一切都是混沌离散的巧合。</p><p>这仅仅是茫茫无尽沙海中，两条可能的世界线罢了。</p><p>也许在某颗行星，某时刻诞生了智慧生命，智慧生命组成文明，文明因求索而团结。</p><p>他们可能会试图找出几条数学公式，描述万物运行的轨迹。</p><p>他们穷尽无数代人的智慧，在浩如烟海的观测数据与理论推导中摸索前行。</p><p>最初，他们发现了宏观力学，便以为自己找到了解开万物的钥匙。</p><p>但随着探索的深入，他们发现这些公式在微观世界中变得漏洞百出。</p><p>他们不断修正公式，引入新的参数，再次将看似随机的现象纳入可预测的框架。</p><p>但数百年后，他们会发现，即使用量子理论描述微观世界，实验现象与理论之间仍然有无法弥合的裂痕。</p><p>每次突破都带来更多谜团，仿佛宇宙故意遮蔽了自己，在他们面前拉起一层又一层帷幕，永远不让他们看清全貌。</p><p>宇宙，到底是什么？</p><p>世界，究竟从何来？</p><p>天地，为何而存在？</p><p>上下四方曰宇，古往今来曰宙。</p><p>宇宙是个有限大的空球，还是个无限大的整块？</p><p>杨帝只知道，世人所追求的确定性，在这片混沌宇宙中不过是偶尔浮现的几座孤岛。</p><p>确实是一个荒诞且让人难以接受的事实。</p><p>我们所揭示出来的物理法则，不过是最有可能走向世界线的概率。</p><p>离散比连续更接近真实，概率比规则更接近真实……但即使是此时此刻杨帝所见到的宇宙之景，也可能并不是“最终真实”。</p><p>但在此刻，驾驶无限机兵的杨帝，已经达到本宇宙一个从未有凡俗生灵所能抵达的高度，前所未有的境界。</p><p>他比以往任何生灵，都更接近世界的终极真实。</p>
