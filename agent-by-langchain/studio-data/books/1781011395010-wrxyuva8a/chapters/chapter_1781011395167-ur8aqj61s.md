# 灵茶山乂斧

<p>斧刃所过之处空间寸寸碎裂，裹挟着毁灭气息的斧风直逼杨帝面门！</p><p>他瞳孔微微收缩，双臂自动做出格挡姿势。</p><p>他的身体，居然因感受到一丝超过阈值的威胁，而自动做出了反应！</p><p>攻击超过这个“阈值”，他至少会受到皮外伤。</p><p>“轰——隆隆！！！”</p><p>斧头与双臂狠狠轰在一起。</p><p>杨帝闷哼一声，双臂皮肤寸寸龟裂，鲜血如喷泉般洒向地面。</p><p>他眼中战意更炽，右腿猛地蹬碎脚下晶石，整个人化作流星撞向归墟大帝。</p><p>拳锋未至，空气已被压缩出尖锐爆鸣，归墟大帝瞳孔微缩，斧刃横挡的同时，周身亮起九道环形光盾。</p><p>“砰！！！”</p><p>杨帝的拳头重重砸穿九层光盾。</p><p>在金属扭曲的尖啸声中，光盾表面蛛网般的裂纹迅速蔓延，瞬间被轰了个粉碎！</p><p>归墟大帝借力倒飞，斧刃划过虚空拉出百米长的漆黑裂痕。</p><p>无数虚无本源所化的骨刺，从裂缝中窜出，如雨点般刺向杨帝周身大穴！</p><p>杨帝不退反进，视“骨刺”如无物。</p><p>“噗噗噗——”</p><p>他身上顿时炸出数十血洞。</p><p>随即杨帝徒手抓住两根“毙肾克”骨刺，反手掷向归墟大帝的肾脏！</p><p>同时欺身而上，膝盖重重顶向对方下三路！</p><p>大帝斧柄横扫，挡掉骨刺。</p><p>但随即他与杨帝膝盖碰撞，恐怖的冲击力，将方圆百米的阁楼轰得摇摇欲坠。</p><p>归墟大帝搓了搓下三路，凝重道：“肉身证帝？有趣！”</p><p>随即斧刃再度迸发万千符文，化作遮天蔽日的斧影笼罩杨帝。</p><p>杨帝双臂交叉高举，任由斧刃在身上斩出道道深可见骨的伤口，鲜血浸透衣袍却未发出半分痛呼。</p><p>在归墟大帝攻势稍缓的刹那，他猛地抓住斧刃！</p><p>“为何下死手！我不是魔道。”</p><p>“啧，还不承认？”</p><p>杨帝虎口被锋利的斧缘割裂，鲜血顺着符文流淌。</p><p>但他并未因此落得下风，反而借力腾空，一记鞭腿如重炮般轰向归墟大帝面门。</p><p>大帝迅速撑起全部光盾，但仍然慢了一步。</p><p>他被鞭腿糊脸，轰击到“帝霸阁”的一根立柱上。</p><p>像个嵌入式部件一样，深深嵌进柱子内部，难以抠出来。</p><p>这座阁楼状领域，灵能浓度极高，达到骇人听闻的10^100灵！</p><p>似乎也正是因为如此，这座阁楼的硬度极高极高。</p><p>他们每一拳每一斧，其威能都能够在前一个世界中，原本将星系团轰出千万光年直径级别的宇宙空洞。</p><p>但在这处领域内，仅仅是把地砖、栏杆、柱子什么的给拍成碎屑。</p><p>连带着杨帝的物理攻击，也被削弱到仅仅是筑基金丹水平的表现力。</p><p>但从实际上来讲，他们这场打爆墙壁、打断栏杆的战斗，确实是能够磨灭大道的。</p><p>杨帝走上前，将嵌在立柱里的归墟大帝抠出来，像按住砧板上的鱼肉般扼住其咽喉。</p><p>“归墟大帝，你为何堕入魔道？难道你已经不相信爱与正义了吗？</p><p>“你为何要叫我等灭口？据我所知，你不可能是这样的人，难道你过往的正气凛然都是装出来的吗？</p><p>“你背后是不是有个沃特公司？你知不知道祖国人，老乡人，Homelander？</p><p>“是该死的消费主义、虚境景观和大资本挟持了你？”</p><p>杨帝疯狂话疗。</p><p>试图用“爱与正义”感化大帝。一般来说，只要他足够热血笨蛋，这招就能奏效。</p><p>只是每说一句话，“人格修正拳”便如雨点般落下，打得归墟大帝口鼻溢血，五官扭曲。</p><p>话疗和物疗，同步进行。</p><p>“我们来自异界，本是抱着和平交流、共同探寻真相之心，为何你却如此决绝！</p><p>“说实话，我根本不关心你悲惨的过去，不关心你有无不可告人的秘密，也不关心你有多少不可言说的理由。</p><p>“但你做错了事就要承认，认之后要改正，正视问题才能解决问题。</p><p>“难道你是——以为自己临近死亡，所以恐惧得做了出格的事、做出有违本心之事？</p><p>“你到底在怕什么！人在江湖，谁没过一两次、三四十次、五六百次濒临死亡的经验？！</p><p>“还是说，你被魔道蛊惑，才做出不端之举？这更是人之常情，从小到大谁没被骗过！</p><p>“即使是拥有超级智慧的本人，10岁的时候也被号称刷Q币的贩子骗走了整整20块！！”</p><p>杨帝的声音中带着愤怒与不解，手上欧拉欧拉欧拉欧拉丝毫未停。</p><p>“你我若能携手，说不定能解决域外天魔灾害，还可以将真正的魔道中人揪出来吃掉。为何，你非要选择这种血腥的对抗？”</p><p>归墟大帝“木大木大木大木大”地用脸接杨帝的拳头。</p><p>接得很准，就像陨石坑总能够精准接住从天外而来的陨石。</p><p>大帝嘴角溢血，冷冷一笑：“事已至此，你居然还能演下去，在下实在佩服。但不论你是真从异界而来，亦或是隐居于灵界某处洞府、修炼成大帝的魔道大能，本帝今日必将你就地正法……噗……”</p><p>他有些恍惚。归墟大帝过于正气凛然。</p><p>杨帝都以为自己才是大反派、大魔头了。</p><p>难道……归墟大帝真是无辜的？</p><p>可能性很小。青丘白璃已经确认，他们在凡界捡到的，确实是纯天然无添加的大帝碎片。</p><p>总不可能连青丘白璃也在骗他。</p><p>杨帝自诩一千五百亿话术点值声振寰宇，再加上自己的人格魅力也并非一般人能比，应该不会有小狐狸能抵挡住说真话诱惑。</p><p>杨帝继续殴打这位大帝。</p><p>嘴炮不停：“归墟大帝！你可曾憎恶这个世界？你遭遇的背叛究竟是什么？！为何你要向凡界投放阴伏流煞！”</p><p>归墟大帝喷出金色鲜血，眼中闪过癫狂，仰头大笑：</p><p>“……‘阴伏流煞’会诞生域外天魔，祸及整个凡界和灵界，但这是白杨大帝你的杰作吧？</p><p>“我是魔道，或者异界之人是魔道——两个选择。你认为天下众生，更愿意相信哪一个？</p><p>“你认为世人会相信归墟大帝，还是相信一个不速之客——白杨大帝？”</p><p>杨帝一边殴打对方，一边深入思考。</p><p>猛然间，他察觉到一个极度肮脏的政治阴谋。</p><p>——没有死成的归墟大帝，要灭他们的口，并将“阴伏流煞”的脏水泼杨帝身上。</p><p>先前的正义凛然，也是他纯演的。</p><p>大帝的洗白方式，是让杨帝作为替罪羔羊。</p><p>“既然你心存以强权压人的想法……那就用我这双有超级肌肉加持的双臂，粉碎你的幻想！”</p><p>他又“邦邦”对着归墟大帝的脸轰了两拳。</p><p>归墟大帝猛地一挣，周身爆发出一股磅礴的力量，竟生生挣脱了杨帝的钳制。</p><p>“灵茶山乂斧！！”</p><p>归墟大帝暴喝声中，阉割版·灵茶山乂斧迸发万千符文，化作遮天蔽日的斧影！</p>
