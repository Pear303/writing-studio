# 强殖装甲

<p>这段发言过于惊世骇俗。</p><p>但已经来不及细细琢磨了，哈基面、小白鼠已经扑杀上前！</p><p>“希夷，现在暂且不讨论你的身世之谜，你还记不记得你是怎么带我登上竖井的？”</p><p>麻雀希夷：“变形包裹住老大的双腿吱。”</p><p>杨帝一手钢管，一手瑞士刀，暂时艰难抵挡住狸花猫与小白鼠的攻势。</p><p>“希夷，再包裹一次，强殖装甲！”</p><p>听到最后4个字，希夷心领神会。</p><p>它吞噬了杨帝大量精神，包括记忆——它知道“强殖装甲”四个字所代表的意义。</p><p>希夷瞬间化作黑色拉面洪流裹住他双腿。</p><p>然后是膝盖，腰部，再到脖颈。</p><p>杨帝屈身蹬地，背后骤然炸开黑色羽流，整个人如炮弹般射向天花板！</p><p>狸花猫的骨刺擦着他的耳畔飞过，他在半空一个鹞子翻身，利爪撕裂扑来的触须。</p><p>小白鼠的黑色拉面网在身后合拢。</p><p>杨帝借着翅膀的反推力急停，钢管在掌心转出寒光，一棍下去。</p><p>“鼠辈，赤石！”他暴喝着俯冲而下。</p><p>钢管作标枪，精准刺入白鼠肉瘤的核心。</p><p>那鼠辈被扎穿破防，黑液喷涌。</p><p>另一侧，狸花猫的猫头180度扭转，七窍渗出的黑色物质凝成骨刺暴雨。</p><p>杨帝冷哼一声，双翅狂振，在密集的骨刺中穿梭。</p><p>2%的潜意识信息爆炸，五感疯狂调动，收集环境信息。</p><p>他在20毫秒内预测到，那六根骨刺会封锁处他所有躲避路线。</p><p>最优解是让腹部挨一发，肩膀刮蹭一下，换取一个用飞天大踹将狸花猫踢飞的机会。</p><p>「战斗+1+1+1」</p><p>但在杨帝做出反应前。</p><p>希夷的拉面便瞬间硬化成盾牌，格挡住其中四根骨刺，火星四溅。</p><p>“噗。”希夷发出闷哼。</p><p>杨帝微微皱眉：“希夷，这对于我来说只是区区重伤，不必为我格挡——你知道理由的。”</p><p>“明白……老大，祝武运昌隆吱。”</p><p>下一刻，他再次被黑色骨刺、拉面网络所封锁。</p><p>杨帝硬扛伤害，皮肉绽起血花，衣裤濒临破碎。</p><p>「锐器抗性+1+1+2+3」</p><p>「钝器抗性+1+1」</p><p>他闷哼着任由骨刺贯穿左臂。</p><p>鲜血在接触黑色拉面装甲瞬间被吞噬，伤口以肉眼可见的速度结痂。</p><p>他反手抓住刺入皮肉的骨刺，借力将狸花猫扯到身前，膝盖重重顶在猫尸脊椎上。</p><p>“咔嚓——”</p><p>听着软骨碎裂的脆响，咧嘴露出森然笑意。</p><p>杨帝自己的膝盖骨也碎了，不过问题不大，他感受到了「骨+1+1+2+3+5+8」。</p><p>不逼一下自己，还不明白上限在哪。</p><p>第不知道几十根骨刺擦着耳畔飞过，他反手掷出瑞士军刀，寒光精准钉入猫尸左眼。</p><p>它却似乎毫无痛苦。</p><p>尽管被刀刺进眼窝，也仅仅只是抽搐了一下。</p><p>然后将军刀拔出来——那刀刃已经扭曲变形成马来剑的模样了。</p><p>马来剑也是剑，而且比瑞士军刀更符合“剑”的定义。</p><p>杨帝抄起那柄扭曲的剑，顿时如鱼得水。</p><p>一手钢管，一手马来剑。</p><p>“砰！砰！砰——砰砰！！”</p><p>他挥剑斩开哈基面扑来的触须，又一脚踹飞小白鼠，竟以一己之力，镇压两尊诡异之物。</p><p>然而，哈基面无穷无尽，小白鼠杀而不死。</p><p>这两个玩意本身就是死物，被抽走“灵”、比无机物更接近“死物”这一概念的死物。</p><p>已经死掉的东西，一般来说是很难被杀死的。</p><p>杨帝的剑锋绞碎第不知几百根骨刺。</p><p>他盯着满地蠕动的黑色拉面残躯，将马来剑插入猫躯，徒手抓住发软的狸花·哈基面·猫。</p><p>这团黑色怪物，在杨帝的握持下剧烈痉挛，猫头以违背生物力学的角度疯狂扭动。</p><p>哈基面开始哈气，黑色拉面物质爆裂，将周围空气染成浑浊的墨色。</p><p>面条状的肢体疯狂甩动，它的躯体在扭曲中不断拉伸变形，连猫头也逐渐拉长为蛇颈。</p><p>它七窍中喷涌的黑液，如活物般扭曲成无数细小的骨刺，在半空炸开成密集的弹幕。</p><p>「锐器抗性+1+1+1」</p><p>“贫弱贫弱……现在，你伤不了我，但我也杀不死你了，怎么办呢？”</p><p>杨帝陷入3.45秒的沉思。</p><p>杀不死，根本打不死这哈基面。</p><p>“耐杀……你们可真是耐杀啊，甚至比我还耐杀。”</p><p>杨帝嘴角咧起扭曲的笑意。</p><p>他想起自己奶奶，她看待“世界”和“食物”的观点是这样的：吃啥补啥。</p><p>“既然杀不死，那就成为我的养分。”</p><p>他张开嘴，一嘴咬崩嘎嘣脆的黑色拉面，唇齿间爆出汁液。</p><p>他任由黑液如活物般涌入喉间。</p><p>辛辣的灼烧感顺着食道蔓延。</p><p>「消化+1+1+2+3……+21+34」</p><p>「崩坏抗性+1+1+2+3……+610+987」</p><p>杨帝的骨骼发出爆豆般的脆响，脊椎节节拔高，肌肉虬结如活物般蠕动。</p><p>剧痛。一口吃下那黑色拉面，他的第一感觉是极度疼痛。</p><p>黑色拉面状物质在他血管里奔涌，如同无数个微型的超新星爆发，将细胞结构拆解成最原始的粒子……</p><p>然后将最基本的粒子，继续拆解成更微小的弦状存在……</p><p>弦状存在继续被破坏，拆解，否定自身……</p><p>直到最本质的存在也被否定，杨帝周身泛起一种介于透明与混沌之间的色泽。</p><p>似乎所有的物理法则，都在他血肉皮囊中崩溃重组。</p><p>在持续解构与超量代偿中，杨帝的肉身与精神，正在经历变革。</p><p>他的肉身和精神，不断被“失去‘灵’的黑色拉面状物质”所侵染，毁灭，否定。</p><p>但同时，他也在不断适应这种形而上层面的杀伤。</p><p>杨帝的灵魂是一团不灭火焰，在解构的飓风中燃烧得更加炽烈。</p><p>全身皮囊，血肉，筋骨……疯狂增强，直至能够抵御这种黑色拉面侵染的崩坏。</p><p>他短暂窥见了没有“灵”干涉的宇宙本相：</p><p>所有物质都是概率的残影，所有规则都是人类强加的幻觉。</p><p>所谓真实，是无数个离散、破碎瞬间的自欺欺人……</p><p>但是，“万物有灵”。</p><p>“灵”锚定住了他肉身和精神的稳定性。</p><p>万物的灵，让它们稳定地保持住物质形态。</p><p>不至于上一秒还是个面容和善的特异人士，下一秒就变成大团抽搐的黑色拉面。</p><p>所以灵的本质，是维持事物的确定性，稳定性，同一性。</p><p>“灵”让杨帝只能是杨帝，而不会是胡彦卓、狸花猫、石膏雕塑或黑色飞天意面。</p><p>不过，他本身的肉体素质与精神强度并没有太多提升。</p><p>“纸面战斗力并没有提升太多，真是有些遗憾。”</p><p>杨帝壮志饥餐猫猫肉，笑谈渴饮鼠鼠血。</p><p>哈基面、小白鼠，这两个亵渎的拥趸，被他用绝对强大、无限进化的肠胃，彻底磨灭了存在。</p>
