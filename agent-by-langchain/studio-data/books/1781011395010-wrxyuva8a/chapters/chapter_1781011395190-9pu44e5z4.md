# 图书馆规则

<p>凌云圣皇等人身穿荧光绿的工作服。</p><p>衣服的来头，只是动用了一点非常规手段而已。现在，他们就是去往体育馆的探路队伍。</p><p>目前还醒着的人，没有一个提出反对意见。</p><p>路过环形走廊之时，他们看到地上有几滩血迹。</p><p>血迹尚未完全干涸，边缘呈现出不规则的放射状喷溅痕迹，如同某种残酷暴力瞬间发生的证明。其中最大的一滩血迹旁边，散落着一些凌乱的脚印和拖拽的痕迹。</p><p>血迹前方十几米的一个拐角处，几个戴着红色袖章的志愿者正紧张地忙碌着。</p><p>他们穿着白色的防护服，戴着口罩和护目镜，动作有些僵硬。</p><p>地上摊开着一个巨大的、黑色的、印着反光标识的运尸袋。</p><p>袋口敞开着，露出里面一具……没有头颅的人形轮廓。</p><p>尸体穿着和他们一样的蓝白校服，脖颈处是参差不齐的断裂口，暗红色的肌肉组织和森白的颈骨茬口清晰可见，血液浸透了胸前的布料。</p><p>一个上了年纪，心理承受力比较好的志愿者告诉他们。</p><p>这些人在广播宣读完规则前，特别是在宣布“禁止目视天圆广场”的规则前，就无意中看了一眼广场方向。</p><p>结果，他们的头颅脱落了。</p><p>“混蛋！诡异连‘法不溯及过往’都不遵守，还逼迫我们在规则内与它交手，它们既是运动员，又是裁判。”那位红袖章志愿者痛心疾首地说。</p><p>“但据说刚才有学生直视了广场方向，但没有被砍头，而只是变成傻子了。”一位下来帮忙收拾烂摊子的老师补充道。</p><p>几个觉醒者下意识地缩了缩脖子，仿佛那无形的铡刀随时会落下。</p><p>他们来到仙界，只有蛐蛐炼气巅峰半步筑基的实力，在这诡异之地是何等渺小。</p><p>别说移山填海，就是挡几颗凡俗的7.62步枪子弹，恐怕都得拼尽全力、付出代价。</p><p>特别是那几具尸体，断头处创口平整。</p><p>以他们现在的肉身强度，绝对扛不住。</p><p>至少，也得是抵达筑基境界的超级强者，才能挨上一刀吧！</p><p>但就算是筑基强者，也很可能抵挡不住让人变傻逼的“精神攻击”。</p><p>如此看来，高低也得是“金丹大能”才能硬抗诡异的伤害！</p><p>众人猫下腰，几乎是半蹲着，利用走廊墙壁和零星堆放的杂物作为掩护，加快脚步，试图快速且悄无声息地通过这片染血之地。</p><p>凌云圣皇、血手屠魔、玄冰尊者等七人组成的“探路小队”，如同惊弓之鸟，终于摸到图书馆巨大的不锈钢门前。</p><p>他们一路避开了所有可能直视天圆广场的角度，神经高度紧绷，身上荧光绿的工作服在昏暗光线下格外扎眼。</p><p>“图书馆也有规则……好像还和教学楼、广场那边不太一样？”一位觉醒者低声开口。</p><p>那是一张贴在图书馆门旁的纸。</p><p>纸张不大，A4规模，看起来是刚打印出来，就用透明胶贴好的。</p><p>规则上的内容也甚是是怪异：</p><p>「为维护神圣的求知环境，保障每一位求知者的心灵纯净，特发布《图书馆守则》，请全体师生务必虔诚遵守：」</p><p>「1. 请保持静默。知识的海洋，需要宁静才能聆听其真谛。任何形式的言语交流、喧哗、叹息、甚至过重的呼吸声都不允许。」</p><p>「2. 请爱护每一册典籍。书籍是智慧的结晶，是通往真理的桥梁。严禁折叠、涂画、撕毁或任何形式的损坏。」</p><p>「3. 请保持端正的坐姿。专注是获取知识的钥匙。禁止倚靠、趴伏、翘腿或任何不庄重的姿态。」</p><p>「4. 请相信并服从图书馆的秩序维护者——佩戴金色徽章的管理员。他们是知识的守门人，智慧的引路者。」</p><p>「4.1 管理员可能出现在任何书架后、阴影中。若你发现管理员正在注视你，请立刻停止当前动作，将当前阅读的书籍全部推至一边，并不再翻阅。保持静止，直至其视线移开。」</p><p>「4.2 管理员不会说话，只会用眼神或手势指引。请勿试图与其交谈或质疑其指令。」</p><p>「4.3 如果你寻求管理员的帮助，可以用除说话交谈外的方式进行。」</p><p>「5. 请坚信守则的力量。遵守守则，即是拥抱真理。」</p><p>「6. 亲爱的求知者，欢迎来到本校图书馆。为了帮助您获得更纯粹、更专注的阅读体验，避免在浩瀚书卷中迷失方向，图书馆另外特别提醒您注意以下事项：」</p><p>「6.1 若您在阅读过程中，无法回忆起上一页的页码，或感觉连续翻页的次数明显多于页码增长量（例如：感觉自己翻了十几页，页码却只从15跳到了16），请立即停止阅读，并远离该书至少十米，必要时可求助管理员。」</p><p>「6.2 任何声称“忘记翻过多少页”、“感觉书页翻不完”或“页码数字长得离谱（如535559835页）”的言论，都是深度阅读疲劳的初期征兆！请勿惊慌，更勿大声喧哗影响他人，只需遵循上述步骤寻求管理员帮助即可。」</p><p>「愿知识的圣光，照亮每一位求知者！」</p><p>“看到这个第6条规则没有？”</p><p>其中一个看起来博闻强记，虽然是中学女孩的外貌，但事实上可能是几百万岁的觉醒者说，“第5条规则看起来是结束，但第6条规则随即又新增了一些注意事项，过渡很生硬。”</p><p>“这意味着什么？”</p><p>“好像说，有些规则怪谈里的人，如果受某种污染过深，就会看到一些正常人看不到的额外规则。”</p><p>“那……我们大伙都病入膏肓了？”</p><p>“无一幸免。”</p><p>“无人生还剧本么，有意思。”</p><p>“OK，各位英雄豪杰不要发出声音，我们虽为蛐蛐炼气期，但最基本的‘隔音术’应该还是能发动的。”</p><p>图书馆沉重的门在身后悄无声息地合拢，将走廊的血腥与死寂隔绝在外。</p><p>门内，是另一种令人窒息的寂静——被无数书页和规则重重包裹，近乎实质的压抑。</p><p>七人立刻散开，此举是为了防止相互碰撞。</p><p>炼气巅峰的灵力在体内流转，全力压制着心跳和呼吸，使其微弱如蚊蚋。</p><p>玄冰尊者此刻是一位戴着眼镜、神情严肃的少女。</p><p>她在靠近哲学区的一个阅览桌下，发现了一张被揉皱又展平、塞在桌腿缝隙里的纸条。</p><p>字迹潦草，透着恐惧：</p><p>「别信页码！别数页码！管理员……管理员在盯着每一个开始怀疑页码的人！张小明疯了，他说他在第18亿6000万页时看到了自己的终点……然后管理员带走了他，再没回来！——李大哲，千万别看太久。」</p><p>这张纸条印证了规则6.1和6.2的恐怖。</p><p>文学少女玄冰尊者推了推眼镜框。</p><p>人类胚胎都能看出来，图书管理员的职责，并不是单纯为了保护学生，其存在本质是为了遏制某种“污染”的传播。</p><p>貌似，还有为了揪出“受污染深”的人。</p><p>那什么是污染源……是书？</p><p>此事并不重要，最重要的是去到图书馆的另一个出口。</p>
