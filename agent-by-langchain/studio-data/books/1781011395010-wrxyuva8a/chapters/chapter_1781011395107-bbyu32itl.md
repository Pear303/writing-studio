# 星渊井口

<p>学术界主流认为，灵能地脉就像一张巨大且错综复杂的网，遍布整个世界。</p><p>澎湃的“灵能”在网道中汹涌奔腾。</p><p>而“星渊井口”就是这张大网在地表的关键节点，像极了无数丝线汇聚的中心点。</p><p>灵能从这里如泉水般涌出，向四面八方蔓延渗透，滋养着周边的土地、森林，也塑造了各种奇异的自然景观。</p><p>就像咱们看到这桦树林里灵能凝结的花瓣、微光，都是因为灵能浓郁，才会凝结起来的自然景象。</p><p>那些灵能贫瘠的地，是看不到这些风景的。</p><p>当年圣骑士“巴德”就是借助这里的力量，才成功射杀焚灭天空之龙·卡利斯托。</p><p>据说，那一次战争非常激烈。</p><p>巴德施展了圣光神教的十环神技「终焉断罪虹」，并湮灭了自身的全部、和三分之一的星渊井口，才将霸据天空的巨龙射杀。</p><p>卡利斯托被击中，并没有当场死亡，还剩最后一口气，不过也无力回天。</p><p>它并没有坠落在星渊井口，而是疯狂试图逃离此地，最终坠落到末日火山。</p><p>“巨龙本身拥有高等智力，极度贪财，甚至不只是财宝，它还会去掠夺各种日常生活用品，比如某家某户的沙发，某家某户的锄头。</p><p>“但它只是敛财，掠夺，却从不消费，不加入市场经济体系。</p><p>“它在自己的龙巢中，堆满金币银币，珍珠宝钻，作为自己的小窝。</p><p>“据说，大量珍宝‘卡’在了巨龙的鳞甲缝隙、皮肤褶皱之中。</p><p>“就好比一个人在脏乱的地方待久了，他身上总会沾染许多灰尘。</p><p>“巨龙和骑士在此地大战了十天十夜，它身上的‘灰尘’——占比小部分金银财宝，和占比大部分平常的家居物品，都掉落到星渊井口。</p><p>“所以，战后掀起了一波淘金潮。比如砾石镇，就曾是一众‘盗墓贼’的聚居地。”</p><p>杨帝想起在砾石镇里，那些手持车轮、剪刀和鱼竿的老头老太。</p><p>这些日用品，也能算是“龙之宝藏”吗。</p><p>不过，如果是龙的宝藏，那带点诅咒倒也正常。至少童话书上都是这么说的。</p><p>杨帝：“瑞弗维尔，你何时突然了解这么多当地历史？”</p><p>“嗯，我的愿望大概类似于‘史官’吧……所以来到各个新地方之后不久，就迅速摸清当地大概的见闻和历史，这是基本的学术素养。”</p><p>杨帝也大概了解了星渊井口。</p><p>圣光教廷的人，在理论上来说，应该也封锁了这里，和他们封锁的“末日火山”一样。</p><p>末日火山，星渊井口，这两个地点都和巨龙的陨落有关。</p><p>而教廷在“火山”研究用史莱姆模拟焚灭天空之龙卡利斯托。</p><p>那么在“井口”，他们又会研究巨龙的什么？</p><p>正当两人思索间，杨帝敏锐地察觉到有情况不对。</p><p>脚下土壤，传来微微震动。</p><p>那感觉就像是……有什么东西，正从地下缓缓爬来。</p><p>他心头一紧，立刻伸手示意瑞弗维尔噤声，同时握紧了腰间的武器。</p><p>“嘘。”</p><p>瑞弗维尔也瞬间警觉，嘴上继续说闲话，一边用眼神与杨帝交流。</p><p>眼神交流的内容，和口头说的闲话，内容毫不相关。</p><p>“圣光教廷？天知道他们研究巨龙做什么，可能想挖龙骨出来，泡几罐药酒挣外汇。”</p><p>（地下那是什么东西？他在哪里？我感官没你那么敏锐。）</p><p>“泡药酒啊，虽然我‘失忆’了，但我感觉我好像喝过龙酒，不，又好像是蛇酒。”</p><p>（七点钟方向，七点五米。）</p><p>“哦？那你这记忆真够混乱，蛇酒和龙酒都能搞混。话说龙和蛇，这两种生物也没什么不同吧。”</p><p>（它移动速度加快了，杨哥我们是主动出击还是等它现身？）</p><p>“药酒里泡龙崽，这得是多奢侈的玩意儿，一般人可喝不起。说到喝的，我去采些野花泡点茶喝。”</p><p>（我把它捅出来，你准备好，先把伊芙护到一边。）</p><p>瑞弗维尔抽出短刀，微蹲于伊芙身侧。</p><p>杨帝小心翼翼地站起身，拔出撬棍。</p><p>可就在这时，地面的震动愈发强烈，一道裂缝从七点钟方向迅速蔓延开来，周围泥土松动。</p><p>对方似乎没想着隐藏自己。</p><p>黑乎乎的东西就这么破土而出，溅起尘土，手中还握着一个巨大的钻头。</p><p>“这地下的土真够硬。”那身影一边嘟囔着，一边拍打着身上的泥土。</p><p>待尘土渐渐散去，两人看清，是个矮人，身材矮小敦实，比下巴还大的毛茸茸络腮胡，一双眼睛炯炯有神。</p><p>“奥拓？你又从土里翻出来？”熟人相见，瑞弗维尔又惊又喜。</p><p>“顺路，所以赶上来了。”矮人收起极品附魔钻头，说道。</p><p>瑞弗维尔：“你也要去星渊井口？”</p><p>瑞弗维尔是去考察历史，顺便戳穿圣光教廷布局百年的惊天阴谋、顺手拯救一下世界。</p><p>伊芙，则是为制止教廷对史莱姆的非人道研究。</p><p>杨帝，则在持续性恢复记忆中。</p><p>奥拓说道：“我？我还得倒一笔大的斗。你知道的，傍晚帮你们附魔了很多器具，那是一笔不小的开销。”</p><p>“你说过你要考古，为什么还碰‘倒斗’！”</p><p>矮人挠了挠头，那比下巴还大的毛茸茸络腮胡跟着动了动，看起来81岁的脸一红，说道：</p><p>“咳咳，听我解释。卡利斯托为何叫焚灭天空之龙？正因为那家伙吐息的温度，能把精金都烧成水！当年它和巴德在星渊井口大战，喷出的龙焰会把部分金银文物熔成金银疙瘩。”</p><p>瑞弗维尔眼睛一亮：“那些凝固的金块……”</p><p>“没错，它们算不上文物。”</p><p>普通金币、银器皿上，有铸造纹路、铭文，能当历史研究的铁证。</p><p>可那些被龙火烧过的金疙瘩，早变成没字的死疙瘩了。</p><p>奥拓笑道：“别说教廷那群老古董，就是铁熔堡的鉴定师，都不认这是文物。”</p><p>瑞弗维尔鼓掌，喟叹，以为绝妙。</p><p>但旋即他想到一件事：“你没考虑过，那些熔融金块也有绑定诅咒么？”</p><p>矮人自然也想到这一层，他笑道：“那些被诅咒的‘龙之财宝’都有两种附魔——绑定诅咒，和不可破坏。”</p><p>瑞弗维尔大彻大悟。</p><p>被烧熔了的金银疙瘩，说明没有被附魔「不可破坏」。</p><p>没有“不可破坏”，说明没有「绑定诅咒」。</p><p>因为目前来看，这两个附魔是死死捆绑在一起的全家桶套餐。</p><p>有了其中一个，基本上就会存在另一个。</p><p>“但卡利斯托死去已经100年了吧，如此漫长的时间，星渊井口里值得搜刮的东西，都已经被摸完了吧？”杨帝说。</p><p>还未建立起完善监管体系的自由市场，对文物遗迹的杀伤力是很强的，远远超过有组织地进行破坏。</p><p>此事在鬼吹灯中亦有所记载。</p><p>潘家园这么多古玩怎么来的？都是人们发挥主观能动性，自发性地去倒斗。</p><p>奥拓又是一副“我就知道你要问这问题”的表情。</p><p>他当即回答：“自从卡利斯托陨落，一百年来，星渊井口都被圣光教廷封锁，仅仅在几个特定的历史时期短暂解封过。如果圣光教廷没有大张旗鼓发掘，那么井口的破坏程度，应该并不是很大。”</p><p>“特定的历史时期？”</p><p>“没错。据镇民所说，是18年前。十八年前南海方向突然传来巨响，大地震动，并且有蘑菇状的云升起。人类教廷的修士都跑过去了，我们就迅速来捡漏……”</p><p>这怎么听都像是南海有核爆，教廷修士全部赶去救场！</p><p>莫不是有穿越者在那搞核试验？</p>
