# 被机制秒了

<p>杨帝在彻底的黑暗、虚无和死亡中，猛地睁开眼。</p><p>在许多年前，他还只是个青涩的学生，还没参与工作，也未投身实践。</p><p>简而言之，那时候杨帝六岁，还在幼稚园上大班。</p><p>那时候，他就已经厌倦了和别的幼稚园孩子用数字来比大小、比战力、斗蛐蛐。</p><p>别的小朋友还在为“我有10个弹珠，你只有8个”，“我有100个”，“哼哼哼我有999个，这是世界上最大的数字！”争得面红耳赤时。</p><p>杨帝则在看蕴含深刻哲思的动画——《果宝特攻》！</p><p>终局之战，水果合体成巨大机甲对抗忍者龟太公。</p><p>杨帝盯着屏幕里散碎零件骤然聚合的画面，小脑袋里忽然闪过一道光。</p><p>橘子尊、菠萝帝各自的力量叠加，竟能产生剁碎上位者“人类”的力量，这和算术本上1+1=2的逻辑完全不同。</p><p>如果将橘子菠萝苹果草莓蜜桃葡萄分开，它们并不能战胜龟太公。</p><p>但当它们组合成果宝战神，却有能与人类一战的力量。</p><p>分散和聚合，团结就是力量？</p><p>并不是，但有一些相似，和他所感悟到的理论已经有一点联系了。</p><p>……是的，就像史莱姆，聚起来便是一个跨时代的聪明大脑。</p><p>当数值以某种秩序堆叠到一定程度，便有可能会涌现出某种更新更好、更劲更霸、更猛更强的性质！</p><p>（其实不一定更好，也有可能是更坏）</p><p>机制怪很恐怖，对吧？准圣，他有超越天道的实力吗？</p><p>也许有。因为凡界、灵界的天道，无法准确识别他的“灵能”总量，而这三个准圣级领域，却能够容纳杨帝。</p><p>——但也只是「现在」能容纳而已。</p><p>如何打破机制怪的机制，如何冲破概念神的概念。</p><p>杨帝的答案，很简单，很粗暴，蕴含着人类最原始的暴力美学。</p><p>所以，现在的他不用做任何事情。</p><p>他只需静静地看着，看着用于「衡量」自己的数字以指数型曲线跃升。</p><p>……</p><p>远处，在恒星上、星云里、中子星下、暗物质浓雾内，围观的真仙境大能们屏住呼吸。</p><p>他们死死盯着那片翻涌的混沌光茧。</p><p>光茧内的法则波动渐渐平息，杨帝的气息疯狂褪散，灵能愈发微弱。</p><p>三位准圣的“领域”很有意思。</p><p>似是因为触碰了本源，所以大道至简，返璞归真——从外面，透过一层彩色斑斓的光茧，是可以看见里面的，一览无余。</p><p>甚至也没有什么气流变化。</p><p>将内外相隔开的，仅仅是一层薄如蝉翼的光茧。</p><p>但是，杨帝偏偏就凭空……溶解了。</p><p>他的身体，正如风化的沙雕，寸寸瓦解，无声无息。</p><p>皮肤最先融化为最微小的粒子，融入混沌。紧接着，蕴含磅礴精气的血肉，如同烈日下的冰雪，迅速消融、湮灭。</p><p>接着是纵横交错的经络，流淌着澎湃气血的血管，乃至构筑元神桥梁的神经，随即到全身骨骼……</p><p>当包裹着心脏的最后几根象征守护的肋骨也化为虚无后，那颗曾如太古战鼓般擂动的心脏，彻底暴露在三重领域中。</p><p>象征着“生”与“力”的心脏，在三位准圣联手缔造的、触及世界本源的三重领域中，剧烈颤抖萎缩。</p><p>表面的红光急速黯淡，仿佛被无形的巨口贪婪地吮吸着精华。</p><p>杨帝的心脏开始层层剥落，化为飞灰，随后融于虚无。</p><p>短短半分钟，它连同最后一点生命的气息，彻底消失。</p><p>“如此看来，他已无力回天。”有人叹息。</p><p>毕竟是个数值爆炸的枭雄，而且，事实证明似乎他并没有杀归墟大帝。</p><p>在极端社会达尔文主义盛行的灵界，强者，从来都是众修士崇拜的对象。</p><p>只要你不搞魔道就好。</p><p>一位须发皆白的老真仙惺惺相惜，叹了口气道：“帝心都寂灭了，白杨大帝陨落。”</p><p>修真者达到一定境界，尤其是元婴或化神之后，“外相”已经不甚重要。</p><p>比如面容，其实象征的是对自己的“看法”。</p><p>比如耳朵，象征对外界的“感知”。</p><p>心脏的消亡，在他们这等境界看来，绝非简单的器官毁灭，而是象征着生命本源与道行动力的彻底枯竭，是陨落的核心征兆！</p><p>几乎所有的围观者，无论立场如何，此刻心中都已下了定论：白杨大帝，陨落了！</p><p>形神俱灭，连一点真灵都未能逃逸。</p><p>什么都没剩下了，他还能活吗？</p><p>众仙将视力催动到极限，乃至已经有能力看清普朗克尺度的事物，也仍然找不到尚存的杨帝碎片。</p><p>那些被黑色塑料袋装着、扔到灵界宇宙各地的杨帝碎片，也已经失活。</p><p>那光茧之内，只剩下最原始、最空洞的混沌气流。</p><p>再无半分生机与法则波动。</p><p>先前那翻涌的、象征着杨帝恐怖力量积蓄的最后一团灵能，也耗尽了最后一丝能量，彻底平息下来，变得灰暗、死寂，如同宇宙中一块冰冷的顽石。</p><p>尘埃落定。</p><p>阿巴脸色煞白，颤抖着喃喃道：“难……难道真的……”</p><p>她这几天抱大腿抱习惯了。一下子失去老大，重归独立自主，反而有些不适应。</p><p>59改拍拍阿巴的肩膀：「建议保持观测，不建议过早判定杨帝阁下的生命活动终止。」</p><p>“……五九改！你是说老大还活着？！”</p><p>「根据此界的物理规律、灵能法则观测所得数据，结合杨帝阁下所提出的‘虚拟世界’猜想，并不排除他还存活可能性。」</p><p>杨帝曾经提出过很多极度荒谬的“虚拟世界”猜想。</p><p>阿巴当笑话来听的，只不过，她不敢在老大面前笑得太过放肆。</p><p>“老大到底要怎么样才能活着？你看那领域里面，什么都没有了！”</p><p>「并不。」</p><p>59改看起来是个国字脸的中年人类大叔，但实际上，他是套了层仿生皮肤的机器人。</p><p>此刻，他的超算核心疯狂运转。</p><p>并在阿巴问出那个问题后的5.0秒内，给出一个模糊的答案。</p><p>「杨帝阁下有0.014%的可能并未被彻底抹除为虚无，而只是被分解为……比‘本世界所能表达之极限’尺寸更小的单位。」</p><p>「灵界的‘普朗克长度’，约为1.1x10-38米。结合杨帝阁下所表现出的超强恢复力与适应进化能力，如果他能够将自己切分为小于此界微观极限的尺寸……」</p><p>“怎么可能小于微观极限尺度？！”阿巴大叫起来，随即又变得低落。</p><p>当空间尺度小于普朗克长度时，量子引力效应会变得无比剧烈。</p><p>此时，时空本身不再是平滑的背景，而会因量子涨落呈现出剧烈的泡沫状结构。</p><p>简单而言就是一片混沌，没有秩序的混乱。</p><p>此时不可能有任何物质能够存在。</p><p>更准确来说，任何“秩序”都不可能存在。</p><p>微观极限尺度，没有任何灵能与物理意义。</p><p>「按照杨帝阁下的猜想，‘微观极限’仅仅是世界本身所能理解的极限。」</p><p>「如果是世界之内所诞生的自然事物，自然不可能超越微观极限。但我们来自此世之外。」</p><p>「杨帝阁下认为，他所表现的‘负值灵能’，也是由于此界无法理解他的灵能丰度。」</p><p>「这是反向突破世界极限。」</p><p>「如果杨帝阁下有能力让自己的灵能总量，超过世界所能表达的极限。」</p><p>「那么，进行同质类比——」</p><p>「或许，他也有能力，将自己的身体切分到小于此世所能表达的‘微观尺度极限’。」</p><p>59改冷静地说。</p><p>也就是“碎”到世界本身无法理解，只能四舍五入，看作是“零”。</p>
