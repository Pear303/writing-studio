# 领域

<p>领域，是一种“技术性”应用，而不是一种“理论型”研究。</p><p>不同文明，不同世界，即使他们都攀出了相同的科学理论，譬如经典力学、相对论等等。</p><p>但如果它们之间没有相应的技术交流，那么即使是相同的理论水平，也很可能会点出迥然不同的技术树。</p><p>比如说，守望者文明的技术树围绕着金属、能源与编程算法不断攀升，将机械的力量发挥到极致。</p><p>而阿巴，以生物进化与灵能修炼为核心，不断提升到更高的心灵境界。</p><p>尽管鱼尊和守望者文明都已经达到前一个宇宙的顶点，但他们走的技术路线完全不同。</p><p>阿巴赶紧把嘴里塞满的泡面咽下去，摆摆手：“老大冤枉啊！大帝不是我杀的！更何况我也绝对打不过……请苍天辨忠奸……”</p><p>“没说是你干的，我是在想，归墟大帝悄无声息地死了，会不会是因为被拉进领域中？”</p><p>青丘白璃嗦着泡面摇头：“不是，我们也已经检查过了。”</p><p>阿巴其实也才刚刚自创出“领域”这一技术不久。</p><p>显然，异世界的土著大能对于“领域”这条技术路线的摸索已经很成熟，有着成熟的技术基础和生态。</p><p>所以，青丘白璃便开始介绍领域。</p><p>以及为什么大帝不可能是被拉进领域、然后被杀害的。</p><p>领域，简单来说，就是将自己的灵能外放，让外界空间成为自己的一部分。</p><p>领域可以简单理解成一个“小世界”。</p><p>只不过释放领域的人，就是这个“世界”的本身！</p><p>杨帝回忆起他被拉进“诛魔破阵·重金属”领域时的细节。</p><p>他们在“诛魔破阵·重金属”里待了58分钟。</p><p>但脱离领域后，杨帝注意到，其实外界只过了约39分钟，这其中也暗示着另一个世界之本质——不同世界之间，物理法则、灵能规律都能有所不同，不出意外，时间流速亦有差异。</p><p>还有就是，嗯……杨帝好像刚进去，就把青丘白璃的琵琶给撑爆了？</p><p>青丘白璃眼神躲闪，像是某个身高155的少女被她爸妈和男朋友发现一顿干20碗白米饭的那种羞涩。</p><p>她说：“没错，领域可以固化在一个具象事物上，有助于修士对自己的领域加深掌控。琵琶在我的领域范围内相当于对‘道’的隐喻……”</p><p>青丘白璃也许是喝面汤喝上头了，开始有些文艺起来。</p><p>简单来说，开“领域”相当于自己创造个小世界。</p><p>在此基础上，可以自己整一些遥控器比如琵琶、吉他、贝斯，加深对领域的掌控；可以给领域安装假牙，一口咬碎牛鬼蛇神；装上五对负重轮，让领域实现全地形快速移动……</p><p>而且，能开领域的，都是凤毛麟角的牛逼人物。</p><p>毕竟，开领域相当于创造一个小世界。</p><p>创世啊，即使是直径只有几十米的世界，也不是凡俗之人所能碰瓷。</p><p>而且，创世，动静能小吗？</p><p>“当时我们就怀疑过‘领域’，所以仔细检查了客栈周围的灵能波动。”</p><p>青丘白璃放下面杯，继续说道。</p><p>“如果真有人在那里施展领域，周边的灵能波动必定会极其强烈，就像平静湖面投入巨石，泛起的涟漪根本藏不住。</p><p>“而且，大帝自身修为极高，若真有人对他施展领域，以他的实力，不说反抗逃脱，至少挣扎的动静也不会小。</p><p>“可我们什么都没发现。那片区域的灵能状态和往常一样，平稳得就像一潭静水，没有丝毫波澜。</p><p>“我们虽比不上白杨大帝，但也是大帝之下、万人之上的大能！最细微的灵能波动都不可能逃过我们的探测，这点我们办事你放心。”</p><p>所以不可能是把大帝拉进领域/小世界。</p><p>他的死，另有其原因。</p><p>杨帝闭目沉思片刻，又问了几个问题，比如归墟大帝出事时在室内或室外？白天还是晚上？他用的杯是什么颜色？茶水是什么颜色？</p><p>室外，白天，白色搪瓷杯，白开水。</p><p>“看来不是误触发了‘黑水传送门’这种神秘学仪式。”</p><p>“黑水传送门？”青丘白璃困惑。</p><p>“没什么。我们还是了解下大帝的生平吧，现在我心里又有另一个猜测，或许能从归墟大帝的生平经历得到答案……”</p><p>异世界谜语人比较少，所以杨帝主动扮起了谜语人，吊住鲈鱼，狐狸和坦克的胃口。</p><p>青丘白璃此生最痛恨在关键时刻突然卡壳，还久久不更新章节的魂淡说书人。</p><p>当下，她也只能连珠炮似的讲解归墟大帝生平事迹，希望尽快触发杨帝的关键剧情。</p><p>……</p><p>说起这十万大山铁路。</p><p>可是有一段与大帝的渊源。</p><p>当年，归墟大帝刚和域外天魔盘肠大战，打得天地间翻云覆雨，整个灵界颠鸾倒凤。</p><p>大帝身心俱疲，便请了一天假，来到凡间。</p><p>他降临凡界第一脚，便踩在铁轨路基上，正撞见凡人拿镐头凿石头。</p><p>那会儿盾构机还没影，世人刚刚试爆原子弹不久，人们用电弧法固定空气中的氮加工成硝酸钙氮肥不过四十年。​</p><p>建设铁路的途中，满山都是抡锤的汉子。</p><p>大帝蹲在崖边看了仨时辰。</p><p>他们正在凿第一座山，时不时用黄色炸药开山卸岭。</p><p>末了，他走向十万大山，将所有巨型山脉给戳穿了，并修饰成天然隧道的模样。</p><p>除了最后一座，同时也是最庞大、最鬼斧神工的一座巨型山脉“君士叹顶”。</p><p>青丘白璃吃着海鲜泡面解释道：“大帝欣赏凡人的勇气和决心，于是给凡人留下点挑战，就选中最后一条，最庞大的‘君士叹顶’山脉，让凡人自己去克服。”</p><p>杨帝摩挲下巴：“这么看来，归墟大帝倒像是个正常人。”</p><p>“他怎么可能心理不正常了啦！他可是站在万人之上的大帝。”</p><p>生理年龄不到35岁的地球青年摇摇手指：“不一定，我给你讲一个‘老乡人’的故事吧……”</p><p>杨帝讲了几个大恶人的故事，讲得阿巴和青丘白璃脸红心跳，不忍卒听。</p><p>不过并非终点站，只是中途停车。</p><p>火车走走停停，目的地始终不变。</p><p>有人下车，有人上来。其中四个是兜帽灰袍的老头。</p><p>老头们佝偻着背走上火车，袍角沾满暗褐色泥渍，像是从陈年古墓里刚挖出来的枯木。</p><p>他们轻易买好座票，就挤在车厢连接处，兜帽阴影里露出的下巴爬满雪白山羊胡，随着呼吸轻轻颤动。</p><p>他们坐在与杨帝四人同一节车厢，对角线的角落。</p><p>这看起来四个花甲之年老头，不是别人，正是酒楼厨子·中山无极、图书馆保安·天机子、扫地僧·渡厄禅师、中学老头·血手屠魔四位大能！</p><p>当然，他们无不收敛了自己的气息，压制住全身气机，完全修改骨骼形状、面相、身高、肌肉分布、年龄、服饰、习惯性动作、微表情、气味、声线语调，甚至是关于他们来到此处的记忆也经过了掩盖和扭曲——</p><p>才没有在杨帝眼皮子底下暴露。</p><p>他们此刻只有一个目的：就是偷听杨帝四人的内容，一人分别负责记住一个人所说过的话。</p>
