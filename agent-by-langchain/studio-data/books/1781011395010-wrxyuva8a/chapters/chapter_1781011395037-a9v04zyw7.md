# 再探旧校区5

<p>遗憾的是，这层楼似乎没有清洁工具间。</p><p>倒是走廊另一边尽头，发现一扇橡木门。</p><p>胡彦卓踹开门，霉味裹着松香扑面而来，前方传来空旷的回声。</p><p>“这里直通音乐厅。”杨帝闻声而来，手电光照见左下方数十米处，泛着幽光的三角钢琴。</p><p>他疑惑：“层高是不是有些不对，四楼到三楼不该有挑空吧。”</p><p>胡彦卓敲了敲墙上模糊的楼层示意图：“看，四楼实际是夹层。艺术楼改建过，1998年把音乐厅改成了双层挑高结构。”</p><p>他们顺着嵌墙铁梯下降。</p><p>手电筒光束在前方摇曳，照亮了一片片斑驳的墙面和堆积如山的杂物。</p><p>堆积的杂物中散落着几具残缺的石膏像，断臂的维纳斯与无头的大卫在阴影里静默对峙。</p><p>这里似乎被时间遗忘，连垂下舞台的烂幕布透露着荒废。</p><p>此地的黑暗更甚于书法间和雕刻室，某种粘稠的黑暗，正顺着铁梯蜿蜒而下。</p><p>“应该5点多了，还是这么黑。”</p><p>“这里连窗户都没有吧，就算有光也透不进来。”</p><p>杨帝视觉灵敏，远远地就透过黑暗，瞅到大堂灯开关。</p><p>他摸过去按，但预料之中，灯没有亮起。</p><p>手电筒往上打，音乐厅穹顶如倒置的碗钵，边缘勾勒出圆润弧线。</p><p>杨帝呼吸声在耳畔被放大数倍，仿佛整座建筑都在屏息倾听。</p><p>“声音从舞台中央发出时，会沿着穹顶的弧度层层折射，最终汇聚成某种共振。这就是为何此处的回声如此清晰。”胡彦卓说。</p><p>很多音乐厅都有这种声学设计。</p><p>无论观众坐在哪一处，前或后，左和右，听到的声音都是差不多的。</p><p>沿着环形看台边缘下行，他们发现音乐厅下方的出口大门虚掩着，生锈的门轴发出断断续续的呜咽。</p><p>手电筒光照过去——又是那只狸花猫。</p><p>此行之后可以下一个论断：一半以上的都市传说，都是由“流浪猫”倾情提供的。</p><p>那只猫在黑暗中抓挠门板。感受到手电筒光束的刹那，它扭头望向两人，瞳孔裂成细长的竖线，喉间滚出低沉咕噜声。</p><p>“吼——”</p><p>手电照射下，它影子在斑驳墙上拉长变形，像是用弓弩发射的拉面，自己将自己弹走了。</p><p>杨帝咽了口唾沫。</p><p>不知为何，刚才狸花猫扭成一团拉面时，他潜意识中提示触发了「精神+1」。</p><p>那玩意，有古怪，不是只普通的猫。</p><p>相比之下，胡彦卓只感受到岁月静好。</p><p>他用手电筒照了照杨帝的脸，笑笑说：“你看过论坛那帖子吗？说半夜经过旧校区，能听见成百上千只猫叫，跟开演唱会似的。”</p><p>手电光束指了指狸花猫消失的门后过道，“现在看来，搞不好就是这位仁兄组的乐队。”</p><p>“啊哈哈……胡哥，要不你先回去吧？”</p><p>“为啥？神神秘秘。”</p><p>“就是，呃，两个人结伴的话就没有那种氛围感。”</p><p>杨帝一时想不出能名正言顺支开胡彦卓的理由。</p><p>他隐约感觉，继续往下也许会有危险，因为他的精神遭受到了“伤害”。</p><p>虽然目前几次“精神伤害”，都是由杨帝本人扛下，但保不齐胡大哥之后可能受到损伤。</p><p>胡彦卓只是个普通人。而杨帝不是。</p><p>胡彦卓展示他一身结实虬劲的肌肉：“怎么老弟还担心我的安危？我跟你说过，都市传说只能是传说，半数以上的鬼故事，都只是条普通的野猫在作妖，在搅事。”</p><p>“呃，其实不只是担心您的安危，还有更深层次的原因……”</p><p>“甭多说了，这一趟我陪你走定了。两个人总比一个人安全。”</p><p>“哐当——”胡彦卓弯腰，抄起两根锈迹斑斑的撬棍，将其中一根抛给杨帝。</p><p>“这玩意比桃木剑还好使。”他笑着说。</p><p>杨帝接住抛来的撬棍时，指尖触到几道凹陷的刻痕。</p><p>两根撬棍，一人一根，利器在手，安全感顿有。</p><p>毕竟是“物理学圣剑”，专门克制牛鬼蛇神。</p><p>二人走过音乐厅的正门大门，就沿着狸花猫的行迹。</p><p>从那里走出去又是一条新的走廊。</p><p>然而，这条走廊也没有窗户，笼罩在深沉的黑暗与寂静之中。</p><p>黑色的世界里，只有两道光柱从手电筒发出来，切割黑色的空间，但光柱移走的区域又会迅速被墨色填补。</p><p>不过神奇的是，这条走廊上的应急楼道，并没有被杂物堆死。</p><p>防火门敞开着，欢迎生人到来。</p><p>既不防君子，也不防丧尸。</p><p>杨帝寻思起来：“奇怪，如果是不希望‘摸金校尉’偷偷摸摸潜进楼里，那应该每层楼的楼道都设置封锁。”</p><p>但现实是，只有最上方的两层被桌椅板凳堵死，低处的楼层反而没设置障碍？</p><p>“别自己吓自己。”胡彦卓嘴上这么说，却握紧了手中的撬棍。</p><p>他们走进楼梯间。</p><p>手电筒首先照亮的是红底白字的“3”，表示此处是3楼。</p><p>楼梯向上，被堵死。</p><p>向下，是通畅的。</p><p>应急楼道感应灯早在十几年前就寿终正寝，两人的手电筒光在剥落的墙面上游走，照见层层叠叠的涂鸦。</p><p>有90年代的流行歌词，九十年代褪色的“忘情水”歌词。</p><p>有泛黄的寻人启事，有破破烂烂的大字报。</p><p>还有用红笔画的歪扭箭头，歪歪扭扭，像是醉酒者的胡画，却整齐划一地指向楼梯下方。</p><p>“红漆箭头在马路上挺常见的，地下管网标记嘛。”</p><p>“可在这楼里画箭头……总不能是在标化粪池位置？”</p><p>杨帝指尖抚过箭头边缘。</p><p>他生出一种错觉，仿佛这栋楼在刻意引导他们向下。</p><p>“愣着干嘛，向下走呢，这边。”胡彦卓的撬棍敲了敲地面，惊起几只仓皇逃窜的蟑螂。</p><p>他的声音在楼道里激起回响，却撞不见预想中的空旷，没有多少回声效果。</p><p>墙面似乎比寻常楼道厚实，吸音效果异乎寻常。</p><p>二人一前一后，漫无目的走着。</p><p>胡彦卓以为杨帝是某种都市传说爱好者，再加上他潜意识认为旧校区很危险，所以便跟上来一块走了。</p><p>杨帝自己也很是迷茫。他来此处，是为了寻找有没有能甩开耶罗符印，或者是摆脱厄运诅咒的方法。</p><p>但他不知道怎么做。</p><p>九年义务教育没教过神秘学。</p><p>杨帝手电筒朝四周晃了晃。楼梯口极黑，氛围太压抑了，他便有一句没一句的和胡彦卓聊起来。</p><p>“你问我怎么迷上跑酷？说来可笑，最初是为了逃补习班。”</p><p>胡彦卓回忆起来。初三那年，他妈给他报了七个补习班，从早到晚像被钉在课桌上。</p><p>有天，他翻窗逃课，结果发现爬水管比解三角函数有意思多了。</p><p>于是一发不可收拾，陷进了跑酷这一行业。</p><p>“你试过在凌晨4点的城市屋顶奔跑吗？整座县城都是你的赛道，防盗窗、广告牌、空调外机都是障碍物。飞在空中，俯瞰风景，我会觉得自己是真正活着的。”</p><p>胡彦卓兴致勃勃，脸脖子都通红了。</p><p>“旧校区的天台、废弃的烂尾楼、立交桥下的管道，这些角落藏着真实的生活。有次在老城区屋顶，有人用喷漆画了整面墙的星空，比美术馆里的油画还豪看。”</p><p>他们一直向下走，楼梯好像没有尽头。</p>
