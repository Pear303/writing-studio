# 大帝被群殴

<p>“硬接三十八个大帝攻伐，这怎么可能！”</p><p>“千真万确！”又一位人族真仙，声音带着颤栗的兴奋，如同见证神话的诞生。</p><p>“看战狂大帝的断剑！那‘剑断乾坤’的道痕斩落，他非但不避其锋芒，反而侧身以肩胛骨硬生生撞了上去！”</p><p>众大能将目力催动到极限。</p><p>他们终于勉强捕捉到杨帝的身影。</p><p>战场中，至尊境界的战狂大帝手执那柄缠绕洪荒煞气的断剑，撕裂万道法则，狠狠斩在杨帝左肩！</p><p>预想中血肉横飞、帝骨崩裂的场景并未出现。</p><p>只听“铛——！！！”一声仿佛神金仙铁碰撞的恐怖巨响。</p><p>肉眼可见的冲击波纹，在真空中以撞击点为中心轰然炸开，将附近几道席卷而来的神通余波都震得粉碎。</p><p>杨帝身形只是微微一沉，肩头衣衫碎裂，露出下方流转着金属光泽的古铜色肌肤。</p><p>竟只留下一道浅浅的白痕，随即消失无踪！</p><p>“其实这并非我的极限。”</p><p>杨帝一边说着，一边转动兆亿匹磁场，“古铜色肌肤不是我的极限！我还能控制肉身变化出其他颜色。”</p><p>他的皮肤、由毛发织成的衣裤像彩虹一样闪烁。</p><p>“奇技淫巧！”溯洄大帝手托沙漏虚影，冲杀上前。他也是至尊境界，能一只手对抗二十个归墟大帝。</p><p>“夭寿啊！溯洄大帝的‘逆流封禁’！光阴之力加身，足以冻结万古！”一位略微触及光阴法则的真仙尖叫起来。</p><p>光阴法则真的很夭寿，一不小心就会让自己回到还没满月的时候。</p><p>鱼尊阿巴曾经用时光逆流之术，回到三天大时候的幼鱼状态，差点整死自己。</p><p>她当时是抱着赌命的心态去回溯时间。</p><p>而玩弄光阴法则，对“至尊”而言，只能算普通攻击。</p><p>只见杨帝被一股无形的、足以冻结星河的时光逆流之力笼罩，身形似乎出现了刹那的凝滞。</p><p>“他被困住了么？”</p><p>这是溯洄大帝，或曰溯洄尊者的绝招“逆流封禁”，简单来说就是时间暂停。</p><p>然而，就在那凝滞的虚影之中。</p><p>杨帝的双眸，骤然爆射出刺破时间长河的锐利光芒。</p><p>“给我破！”低沉的咆哮，并非源自喉咙，而是来自他体内每一寸奔腾咆哮的恐怖气血。</p><p>他骨骼发出如开天辟地般的爆响，被光阴之力凝固的肌肉，以肉眼可见的速度重获生机。</p><p>体内奔腾的气血更是化作一条条金色的神龙，在他的经脉中横冲直撞。</p><p>“这不可能！”溯洄大帝瞳孔骤缩，手中沙漏虚影疯狂旋转，想要加大“时间暂停”的强度。</p><p>他比谁都清楚，眼前这厮，破解他光阴法则的方法，也是纯粹蛮力——</p><p>让全身的血液、真元、生物电流、思维速度等等的物质运动，推动至极端接近光速。</p><p>许多宇宙都兼容广义相对论。</p><p>在灵界版相对论效应作用下，高亚光速的杨帝，发生“尺缩钟慢”现象。</p><p>他的思维速度已经快到不可思议，每一个念头都能引发空间震荡。</p><p>更可怕的是，体内的血液流速已极端接近光速。</p><p>要是此时从毛细血管中渗出一滴血，能像串串香一样，炸碎几十颗野生中子星！</p><p>足以封禁至尊的时间枷锁，被杨帝纯粹到极致的肉身力量生生挣断。</p><p>时间长河虚影剧烈晃动，溯洄大帝闷哼一声，眼中满是难以置信！</p><p>就连至尊也无法制衡他。</p><p>可恶，还是做不到吗。</p><p>“归墟葬灭，虚无孽龙！”归墟大帝操控的亿万条吞噬一切的漆黑，咆哮着将杨帝彻底淹没。</p><p>黑水翻滚，似能湮灭一切存在。</p><p>作为一众大帝之中的中下游存在，归墟大帝的自信，来自于他在“归墟帝霸阁”中交战时，杨帝似乎对“虚无本源”表现出弱点……</p><p>就好像蝙蝠侠在正义联盟里战力低得发指，但他掌握了许多大能的弱点，比如说，针对超人他囤了一仓库的氪石。</p><p>归墟大帝自认是“蝙蝠侠”。</p><p>“完了！被归墟大帝的虚无本源正面侵蚀，纵使大帝金身墟大帝的也……”有吃瓜群众不忍再看。</p><p>他们没有目睹杨帝痛饮归墟渊水的一幕，自然猜不到人物命运。</p><p>那翻滚的、连光线都吞噬的绝对黑暗之中，一点璀璨的光芒骤然亮起！</p><p>“很抱歉，归墟渊水，我已经喝了10个国际标准泳池的量。先前在您面前示弱，都纯粹是我演的。”</p><p>紧接着，是第二点，第三点……无数点光芒！</p><p>那是杨帝体内奔腾如宇宙初开般浩瀚的气血在燃烧。</p><p>他通体发光，如同一尊在归墟中涅槃重生的混沌神祇。</p><p>“吼——！”</p><p>杨帝双臂一震，纯粹到极致的肉身力量化作无形的冲击，竟将那亿万条由虚无本源凝聚的孽龙硬生生震得粉碎、蒸发。</p><p>他一步踏出黑暗，毫发无伤，唯有眼神更加炽热，战意更加高昂！</p><p>“疯子！但也……强得令人绝望！”另一位真仙喃喃道，“他的肉身，究竟达到了何种境地？难道真是什么先天神尊转世不成？”</p><p>“什么秘宝护体？什么神通卸力？统统不需要！他就是最强的武器，最坚的盾牌！白杨大帝，他是在用自己的身体，丈量诸帝的深浅和长短。”</p><p>“我们先前对他的进攻围殴，简直是蜉蝣撼大树。”</p><p>“还有什么方法能使他破防？”</p><p>“有的。心灵攻击。不不不，并不是指精神攻击，而是‘拖把粘……”</p><p>战场中，杨帝越战越勇。</p><p>面对如雨点般落下的帝印镇压、神言锁链、毁灭光束……</p><p>他或挥拳硬撼，或挺胸硬接，或侧身硬扛！</p><p>尽管战场近乎真空，但每次碰撞仍然发出震耳欲聋、令星辰摇曳的轰鸣。</p><p>他的身躯，成了这方混沌战场上最醒目的坐标，一个不断承受着足以毁灭世界的力量，却始终岿然不倒、反而愈发璀璨夺目的坐标！</p><p>杨帝仰天长啸，黑发狂舞，主动冲向攻击最密集的区域，任由那些毁天灭地的神通轰击在自己身上，发出连绵不绝的爆鸣。</p><p>那场景，如同亿万颗星辰在他体表同时爆炸，却无法撼动其分毫！</p><p>“砰！”一位以肉身强横著称的、专注炼体证道的神皇，凝聚全身帝力的一拳结结实实轰在杨帝胸口。</p><p>他不闪不避，挺胸迎上！</p><p>“咔嚓！”令人牙酸的骨裂声清晰传来。</p><p>骨折的当然并非杨帝的胸骨，而是那位神皇的手臂。</p><p>他整条手臂瞬间扭曲变形，帝血飞溅，惨叫着倒飞出去，眼中只余骇然。</p><p>“你用拳头硬接杨帝的胸膛干什么！”远处观众席，几个对赌输了的真仙大能一拍大腿怒骂。体修果然满脑子肌肉。</p><p>杨帝突然眼珠抖动看向自己身侧。</p><p>某个至尊境大能的杀招打偏了。</p><p>“如此优质、无添加、纯天然的杀招往我身上招呼啊！居然打偏了？不要浪费好吗？”</p><p>杨帝冲过去，接住杀招。</p><p>但在接触那一击的刹那，他周身气血瞬间凝固。</p><p>那道偏离的攻击表面看似寻常，实则裹挟着三重截然不同的气机。</p><p>轰隆！！</p><p>杨帝低头。自己的胸膛被打了个直径30厘米的大洞，圆珠状的血液一滴一滴向外渗出。</p><p>再看，出招人是三位准圣的方向。</p><p>他们已不再躲到圣人身后，而是走上前来，立于空中。</p><p>准圣入场了。</p>
