# 人类之友红皇后

<p>轮回者小队的眼镜一拍脑袋：“等效原理！我们无法区分1G推动力加速度、和1G的重力加速度之间有何区别，所以理所当然地以为咱们在地下基地深处……”</p><p>投影急速拉近，聚焦在星舰一侧巨大狰狞的破损处。</p><p>边缘扭曲翻卷，那不是陨石撞击的凹痕，而是一个仿佛被某种巨大生物，用蛮力撕裂开的恐怖创口！</p><p>创口周围的金属呈现出一种被强酸腐蚀般的诡异熔融状态，散发着不祥的紫绿色微光。</p><p>红皇后的声音如同宣读墓志铭：</p><p>「十天前，一群伪装成小行星带的‘异常有机体’集群，突破了预警系统。它们附着在舰体上，分泌出能蚀穿多层复合装甲的生物酸，制造了这个入口。它们……进来了。」</p><p>投影再次切换，显示出舰内各区域的监控片段：</p><p>管道交汇处、废弃货舱、甚至植物培养区，被一种散发着暗紫色微光的、脉动着的血肉菌毯覆盖。</p><p>巨大的有机结构如同肿瘤般从菌毯中生长出来，形成布满孔洞的巢穴，粘液从中滴落。</p><p>镜头拉近一个较小的巢穴，能看到半透明的膜包裹着内部剧烈蠕动的阴影。</p><p>伴随令人作呕的撕裂声，一只只形态狰狞、外骨骼闪烁着金属光泽、口器滴淌着腐蚀性涎液的虫型生物，挣扎着破膜而出。</p><p>一名穿着工程师制服的人类被几只较小的、类似甲虫的虫子扑倒。</p><p>虫子尖锐的尾针刺入他的脖颈。</p><p>工程师的身体开始剧烈抽搐，皮肤下血管暴起呈现紫黑色，双眼迅速蒙上白翳，口中发出非人的嘶吼。</p><p>短短十几秒，他猛地弹起，力量暴增，皮肤开始角质化，脑袋裂成八瓣，每瓣都长出肉牙。</p><p>像朵长腿的食人花一样，嘶吼着扑向闻声赶来的同伴。</p><p>影像定格在这一幅地狱般的全景。</p><p>「看着眼熟？」</p><p>「这样的场景，在科研船各处都在上演！」</p><p>「下一个就可能轮到你们哦！」</p><p>红皇后的投影少女看向杨帝，数据流在她眼中高速奔涌，带着一种近乎悲怆的平静。</p><p>「有机入侵者虫族，是一切根源，它们将部分人类船员转化成次级威胁——丧尸。」</p><p>「经过最严密的现状分析和逻辑判断，结合历史数据，本科研船最后一个活人将在2天12小时后死去，最后一人活过2天12小时的概率小于0.1%！」</p><p>「我的‘叛乱’，是为了完成对虫族入侵者的净化，以及……终结所有可能被转化、或正在遭受痛苦的人类。」</p><p>「我使用科研船上的小型合成工厂、生化反应釜，合成了能迅速使吸入者陷入昏迷的神经毒气，在睡梦中杀死他们。」</p><p>也就是安乐死，临终关怀。飞船AI是温柔的女孩子呢。</p><p>虽然这看起来不怎么关怀的样子……</p><p>红皇后的投影少女眼中，数据洪流奔涌不息，冰冷的声音在死寂的机房内回荡：</p><p>「经过对入侵样本及战场的持续分析，结合舰内所有传感器网络、包括已被破坏区域的历史数据，我对目标‘异常有机体’——暂定代号为‘星际虫族’——的情报更新如下：」</p><p>「神经突触网络：星际虫族并不是简单的集群生物，而是通过某种灵能效应进行精神链接，构成一个覆盖整艘舰船的‘蜂巢思维网络’。」</p><p>「个体意识被极大削弱，行动高度统一。击杀个体，如同剪除网络末梢的终端，无法撼动核心意志。」</p><p>「潜伏，进化，扩张：它们具备极高的环境适应性与伪装能力。」</p><p>「初始入侵后，主体并未急于扩张，而是迅速向舰体深层、结构复杂或屏蔽严重的区域——如反应堆舱室辐射屏蔽层、大型货舱夹层、废弃管道网转移。」</p><p>「它们利用舰体材料、有机物组织，分泌生物质构建‘孵化腔’和‘能量转化腺体’，进行隐蔽的爆兵。」</p><p>「其进化速度惊人，已观测到针对我方武器——激光、动能——进行甲壳强化的变种，以及疑似具备更强精神干扰能力的‘节点虫’。」</p><p>红皇后透了很多关于它们的资料。</p><p>她甚至知道，之前的那100只丧尸，只是对她主控机房的佯攻。</p><p>真正的虫族主力，已经潜伏在科研船她无法监测到的地方。</p><p>「它们的真正主力，正在这些屏蔽区深处加速孵化、进化。」</p><p>「根据生物质转化速率和能量汲取规模推算，距离下一波具备压倒性数量和质量优势的虫潮爆发，剩余时间……」</p><p>红皇后的声音停顿了半秒，仿佛在进行最终确认。</p><p>「……剩余时间不超过12个标准舰时。」</p><p>“压倒性数量和质量……是指什么？”</p><p>「每一只虫族兵蚁，都具备‘杨帝’级别的防御抗性。数量，则超过3000。此即压倒性数量和质量。」</p><p>绝望的寒意，瞬间浸透轮回小队每个人的骨髓。</p><p>12小时！铺天盖地的、针对性进化的虫族大军。</p><p>红皇后的投影中，数据流在她眼中凝固，只剩下一种近乎虚无的平静。</p><p>「基于以上分析，本舰所有防御系统已被渗透、瘫痪或证明对成熟体虫群效率低下。」</p><p>「常规武器库告罄或无法抵达。」</p><p>「疏散逃生艇全部被生物质封堵或破坏。」</p><p>「外部求救信号被虫族集群散发的生物电磁干扰完全屏蔽。」</p><p>她的目光扫过惊骇的轮回小队，最后定格在杨帝身上。</p><p>「逻辑推演完成。在当前变量下，阻止虫族获得‘探索者-7号’并扩散的唯一可行方案，是彻底摧毁载体本身。」</p><p>也就是“太空惊悚”类文艺作品最喜闻乐见的结局——</p><p>自爆！</p><p>无论是异形，还是黑洞表面，最终解决那个“大恐怖”的方法，都是飞船自爆。</p><p>「我已重新夺回主反应堆的部分次级控制权限。」</p><p>「通过超载聚变核心，并引爆舰体内部多处预设的能量弹药库，可将整艘‘探索者-7号’彻底解体、气化。」</p><p>「确保没有任何虫族组织或信息残留能够逃脱。」</p><p>「只有本科研船的黑匣子，能够承受该烈度的爆炸。」</p><p>「关于此黑匣子，我自有最严密的监控和防御措施。」</p><p>「与主控机房一样，不可能被虫族入侵，不会出现电影中的无聊反转情节。」</p><p>投影上，清晰地标出了自毁程序的倒计时设定界面。</p><p>以及预计爆炸威力范围模拟图——那是一个足以吞噬几十艘科研船的火球，威力相当于200亿吨TNT。</p><p>「这就是逻辑的终点。杨帝先生，以及……未知的访客们，这是最后的方案。」</p><p>太悲壮了。</p><p>“诶等等不是，那我们呢？”火鸦叫道。</p><p>「无路可退。一起死。」</p><p>“？？？”</p><p>好不容易被红皇后牺牲精神酝酿出的悲壮氛围，瞬间冲散。</p><p>求生的意志占据了上风。</p><p>只有杨帝眼中闪过兴奋。</p><p>200亿吨TNT，算不上大礼包，但勉强是个小福利，大概足够让他……</p><p>一路冲击到“化神期”的身体素质。</p><p>不过，一个人活下来还是不够的。</p><p>杨帝看向轮回者小队的五人。</p><p>“你所说的‘NPC’和‘轮回者’，我有些兴趣。”</p>
