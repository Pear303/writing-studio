# 蘑菇云与蘑菇人与蘑菇

<p>“九环大能！”哈蒙德瞳孔缩成针尖。</p><p>银光闪过，比箭矢更快的身影撕裂夜幕。瑞弗维尔只觉后颈一凉，本能地使出“游侠之无敌翻滚”，险之又险避开。</p><p>方才站立的地方已经凹陷出半米深的坑洞。</p><p>那是只通体雪白的巨兔，体长足有两人高，耳尖垂落的不是绒毛，而是倒钩状的金属骨刺，每根都在月光下泛着冷冽的紫光。</p><p>“这踏马是兔子？！”</p><p>“这特么是披着兔皮的魔王种吧！！”</p><p>“喀嚓——轰！”巨兔踏碎岩石，音爆震得四周树木齐齐折断。</p><p>哈蒙德的铁拳裹挟着呼啸风声砸向杀手兔，拳风将周围杂草绞成齑粉。</p><p>兔头和拳头对轰在一起。</p><p>针尖对麦芒，而结果也并不出人意料——在纯粹物理方式对轰的情况下，九环力量比八环的要强。</p><p>哈蒙德与杀手兔相撞的气浪如实质般爆开，瑞弗维尔被掀飞出去，后背重重撞在古松树干上，喉间腥甜翻涌。</p><p>他挣扎着抬头，只见两道身影裹挟着电光直冲云霄，眨眼间消失在浓稠的夜幕里。</p><p>只留下漫天飘零的碎木残片，和空气中尚未散尽的灵能余波。</p><p>哈蒙德，被那只杀手兔撞飞了。</p><p>杀手兔自己也飞了。</p><p>“哈蒙德！”瑞弗维尔呼喊。</p><p>边传来一句拉得很长的话：“你——走——别——管——我——”</p><p>这位圣古琉斯图书馆馆长，梦想成为史官的人类，只能背着自己身上几十斤炊具，孑然一身继续往星渊井口的方向走去。</p><p>事已至此，也只能乐观地想到——幸好没有把炊具都交给哈蒙德来背，否则他最珍视的平底锅和铁罐头也会连带着飞走。</p><p>“我究竟是应该留下来等哈蒙德，还是听他的指令继续走？”瑞弗维尔思索起来。</p><p>前路也许会有更多大恐怖，大危险。</p><p>比如什么9环10环的史莱姆，已经成尊了的九转杀手兔，单杀传奇法师的溺尸王，能够一拳打爆整片大陆的苦力怕但苦力怕没有手所以也就握不紧拳头……</p><p>没有哈蒙德做护卫，也许他走两步，就会在转角遇到无可战胜的敌人，遗憾暴毙吧？</p><p>“不，当下还是研究清楚南海那边出现什么问题更要紧。”</p><p>瑞弗维尔闭上眼，水晶球内的异象如烙印般浮现：</p><p>暗紫色闪电如蛛网撕裂铅灰色云层，海面骤然向下凹陷成墨黑色漩涡，炽热白光从深渊底部喷涌而出，像新生的太阳般炸开。</p><p>“太阳”降临大地仅仅十几秒，便散去，留下一座蘑菇状云柱裹着蒸腾的海水直冲天际。</p><p>爆焰所过之处，海水瞬间化为虚无，暴露出焦黑的海底岩石；冲击波如透明巨浪横扫海面，将途经的岛屿碾成齑粉，随风而逝。</p><p>远方的天空被染成诡异的血红色，无数燃烧的碎石如流星般坠落，砸在更远处翻涌的黑色海面上。</p><p>“不行，真的太好奇了。哈蒙德，那我就遵从你的意思，自己先走了！”</p><p>瑞弗维尔有些过于自信了。</p><p>放进冒险小说里，恐怕活不过50个字！</p><p>然而，他有一项任何人都无法比拟的特质——运气。</p><p>虽然瑞弗维尔不懂得社交，不懂得察言观色，对未知事物的好奇和求知欲盖过了谨慎。</p><p>但他偏偏就是死不了。</p><p>自从遇上那只九环级别的筋肉杀手兔，此后数日，瑞弗维尔一路上都没遇到任何危险魔物了，也就偶尔两三只草史莱姆在脚边滚动，咕噜咕噜。</p><p>……</p><p>某日，他拖着沉甸甸的炊具在荒草丛生的小径上蹒跚前行。</p><p>这些炊具重达30斤，他随身携带，从未想过要丢弃。</p><p>于行走荒野的旅人而言，这些炊具，就是身上所背负的生活之意义。</p><p>瑞弗维尔快发现一件要命的事——他带的大部分干粮，都在哈蒙德身上。</p><p>那位八环战士被杀手兔撞飞，不仅仅代表全队力量下跌90%，更意味着兔子一脑袋撞飞80%的补给。</p><p>胃袋发出“咕噜”的抗议。</p><p>幸好，瑞弗维尔曾经任职游侠，对各种荒野求生小知识信手拈来。</p><p>他正巧瞥见灌木丛里，一簇簇圆滚滚的褐色蘑菇，在夜露浸润下泛着油亮光泽。</p><p>“这形状这色泽，绝对是《荒野求生宝典》里记载的‘香菇’，我以当了10年职业游侠的名誉起誓。”</p><p>虽然偶尔吃到毒蘑菇翻车，但他每次翻车都会从中吸取教训，不会在同一种毒蘑菇上绊倒两次。</p><p>他曾中毒6次，都是6种不同品种的毒蘑菇。</p><p>瑞弗维尔哼着正圣字旗的小曲，徒手揪下灌木丛中的菌子，还不忘用袖口仔细擦拭。</p><p>没有香料怎么办？原地找些看起来可食用的小野花儿、嫩牙尖儿混在一块煮。</p><p>“要是有黄油就完美了，不过将就着用月光煎煮，也能吃出喵其林三星的浪漫。”</p><p>三下五除二处理好食材，滋滋作响的香气很快在荒野弥漫开来。</p><p>他享受完这顿野外大餐。</p><p>瑞弗维尔揉了揉眼睛，发现平底锅腾空而起，空中转体三周半，冲他比了个中指。</p><p>“这不科学……”</p><p>下一秒，瑞弗维尔两眼翻白栽倒在地。</p><p>七天后。</p><p>这已是瑞弗维尔第七次生啖毒蘑菇，昏迷在地乱抽搐。</p><p>躲在暗处观察的伊芙·柑橘几乎要把鼻子和耳朵都气歪了。</p><p>这厮，到底要被毒个半死多少次！要是还有下一次误食毒菌子，她一定会冷眼旁观，任由他在幻觉中死去。</p><p>我只会再救这一回！伊芙·柑橘深吸一气，翡翠色的眼眸泛起幽蓝微光。</p><p>她指尖划过腰间银质藤蔓纹章，翠绿色咒文如萤火般跃出，在瑞弗维尔周身编织成发光的圆环。</p><p>空气中浮动着月桂叶与薄荷的清香——净化咒术特有的气息。</p><p>超限大法师将他体内毒素，用类似“透析”的方法净化完毕。</p><p>这位精灵扯住瑞弗维尔乱蓬蓬的头发，将其歪斜的脑袋强行抬起。</p><p>“蠢货人类，醒来后睁开眼睛看看，这次再记不住毒蘑菇的模样，就把你腌成标本挂在橡树上去！”</p><p>瑞弗维尔喉咙里发出呜咽。</p><p>伊芙心底怒火消散大半，全部转换成好奇。</p><p>她把耳朵凑近，去听。</p><p>“嗯……好吃……”</p><p>伊芙重新气得直跺脚，翡翠色眼眸里满是恨铁不成钢的羞恼。</p><p>她粗鲁地将瑞弗维尔丢回地上，看着他无意识地砸出个浅坑，扬起的尘土沾在她纤尘不染的精灵长袍上。</p><p>“连毒蘑菇都能当成美味，人类的味觉系统简直是对自然法则的亵渎哇……”</p><p>作为研究人类行为学的学者，伊芙本该保持客观冷静。</p><p>可这个笨游侠，总能轻易突破她心理防线。</p><p>她躲进附近的橡树阴影里，双手接触法杖，将数据资料远程传输到圣树云端。</p><p>「第七次观察样本因食用毒蘑菇产生幻觉，昏迷中出现‘美味’呓语，推测人类普遍存在味觉认知障碍与自毁倾向……」</p><p>夜风掠过树梢，瑞弗维尔突然翻了个身，手臂无意识地朝着伊芙隐匿的方向伸展。</p><p>精灵学者屏住呼吸，看着月光勾勒出人类棱角分明的侧脸。</p><p>他睫毛上还沾着未干的冷汗，双眸紧闭，嘴角却带上餍足的笑容，似是偷吃蜂蜜的幼熊。</p><p>伊芙烦躁地扯松发间的月桂叶发卡。</p><p>她关闭了与圣树的通讯。</p><p>在自己携带的笔记本上，精灵学者用蘸着银质墨水笔快速写下一行备注：</p><p>「下次得亲手给他做顿真蘑菇汤，省得这笨蛋再把自己毒至半死。」</p>
