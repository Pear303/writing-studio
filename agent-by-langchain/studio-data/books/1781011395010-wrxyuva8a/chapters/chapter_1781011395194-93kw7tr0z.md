# 白杨世界

<p>崩坏之力侵蚀上去，猫条表面泛起涟漪，仿佛被灼伤。</p><p>但转瞬间，新的，更粗壮的根须就从灼伤处萌发出来，带着更强的生命力，更死死缠绕、包裹！</p><p>仿佛，马格努斯裹挟的崩坏之力，反而成了滋养它们生长的特殊养分。</p><p>黑与白，崩坏与生命，在触须表面展开了一场无声而激烈的拉锯战，但黑触须明显在被缓慢地、不可逆转地吞噬转化。</p><p>另一条试图钻入地底遁走的触须更惨。</p><p>它刚刚撕裂地表，试图潜入更深层，模仿削肾客挖地洞逃跑，又或是试图寻找规则的薄弱点，悄无声息地溜出去。</p><p>却发现下方的土壤、岩石，乃至地基本身，都已被“白杨世界”的规则浸染！</p><p>「欢迎进入白杨世界-LEVEL 1-人防工事」</p><p>「生存难度-等级1」</p><p>「安全-稳定-极少量实体」</p><p>「LEVEL 1类似江城二中的地下人防工事，墙壁由斑驳的水泥浇筑而成，角落里堆着生锈的铁架床，两侧的房间门大多虚掩着，门框上还贴着褪色的红色标语。窗户被彻底封死，砖块从内侧砌满窗洞，水泥将缝隙填得严丝合缝。」</p><p>「偶尔会有几根舌头猫条从你眼前闪过，但它们一般不会注意到你。」</p><p>这条漆黑的触须刚一接触潮湿阴冷的空气，冰冷的规则信息就强行灌注进它的意识核心。</p><p>它感到一种强烈的排斥和束缚感，仿佛这方空间本身就是一个巨大的、缓慢蠕动的胃袋。</p><p>它不敢停留，疯狂扭动着，冲向标着“安全出口”的门。</p><p>「白杨世界-LEVEL 1.5-人防工事二层」</p><p>「生存难度-等级1」</p><p>「安全-稳定-极少量实体」</p><p>「没想到吧？人防工事分为两层。」</p><p>马格努斯的触须肢体，在迷宫般的通道中找到一处似乎更薄弱更深邃的向下裂缝，不顾一切地钻了进去！</p><p>空间骤然扭曲、下坠。</p><p>「欢迎进入白杨世界-LEVEL 2-建筑地基」</p><p>「生存难度-等级2」</p><p>「不安全-不稳定-少量实体」</p><p>「LEVEL 2位于 LEVEL 1之下，由粗糙巨大的混凝土块、扭曲的钢筋骨架和潮湿的原始泥土构成。这里是建筑物真正的根基，但也充满了因‘白杨世界’规则异化而产生的不稳定结构。」</p><p>「请注意脚下，地面随时可能软化或塌陷。避免接触那些发光的舌头猫条、处在某些建筑物边缘的手，它们具有轻微的攻击倾向。」</p><p>下方地面发出不堪重负的呻吟，迅速软化、塌陷！</p><p>沿途还有七八根猫条，三四只枯手。</p><p>但马格纳斯的肢体毕竟是灵魂无比，勉强跑酷过去了。</p><p>它惊喜地发现一条更小的裂缝，散发着更浓的“虚无”气息，它以为是出口便立刻钻入！</p><p>空间变得更加狭窄、压抑。</p><p>「欢迎进入白杨世界-LEVEL 3-盗洞」</p><p>「生存难度-等级3」</p><p>「危险-极不稳定-无实体」</p><p>「LEVEL 3是一条极其狭窄、蜿蜒向下的不规则隧道，由粗糙的挖掘痕迹构成，洞壁布满湿滑的苔藓和粘稠的、散发着植物清香的汁液。空气稀薄，弥漫着土腥味和某种根茎的甜香。隧道内能见度极低，唯一的光源是洞壁上零星生长、散发幽白微光的蕨类。」</p><p>「隧道会自行蠕动、收缩。请时刻保持移动，一旦停留过久，洞壁分泌的汁液将开始‘分解’并‘吸收’非白杨世界认可的存在。」</p><p>狭窄！窒息！触须疯狂地在黏滑的隧道中向下穿行。</p><p>洞壁像活物的肠壁一样缓缓蠕动、挤压，分泌出的粘稠汁液沾满了它的身体，带来强烈的灼烧感和力量流失感。</p><p>它甚至能“听”到汁液在滋滋作响，疯狂分解它表层的“崩坏”。</p><p>触须爆发出前所未有的速度，不顾一切地撞向隧道尽头一个仿佛通往无尽深渊的垂直竖井，纵身跃下！</p><p>自由落体感漫长而恐怖，最终狠狠砸入一片泥泞。</p><p>「欢迎进入白杨世界-LEVEL 5-古墓穴」</p><p>「生存难度-等级4」</p><p>「极危险-稳定-大量实体」</p><p>「LEVEL 5是一片被巨大发光根系彻底占据的巨型古代墓穴群。棺椁、陪葬品被虬结盘绕的根须包裹，成为根系结构的一部分。空气弥漫着浓烈的陈腐泥土味和旺盛生命力的奇异混合。空间被根系散发、恒定不变的幽白光芒照亮。」</p><p>「有大量僵尸与鬼魂、崩坏和希夷在此地游荡，请小心躲避。」</p><p>绝望！冰冷的绝望瞬间攫住了触须！</p><p>它砸落的地方，被无数散发着幽白光芒的植物根须、奇异苔藓照亮。</p><p>落魄的幽鬼、失魂的僵尸，如同嗅到血腥味的鲨鱼，瞬间从四面八方冲杀来！</p><p>触须能清晰地感觉到，自己被数道冰冷、充满食欲和饿意的意志，死死锁定了！</p><p>“嗷——！！”触须发出无声的、源自本能的尖啸。</p><p>它用尽最后力量，崩断被缠绕的部分躯体，像一道濒死的黑色闪电，射向墓穴穹顶一个不起眼的、被巨大根茎半掩的溶蚀洞口！</p><p>眼前出现一座巨大的黑水潭子。</p><p>它跌入一片冰冷潮湿的黑暗。</p><p>「欢迎进入白杨世界-LEVEL 8-溶洞」</p><p>「生存难度-等级5」</p><p>「死区-绝对稳定-实体巢穴」</p><p>「LEVEL 8是一个庞大到难以想象的地下溶洞系统。钟乳石与石笋林立，但所有岩壁、石柱都被一层厚厚的、散发着浓郁白光的苔藓或菌毯覆盖。地下河在这里汇聚成潭，潭水会溶解、杀死除溶洞原生物以外的一切外来物。」</p><p>「闯入者在此生存几率为零。」</p><p>触须残破的躯体浸泡在冰冷的潭水边缘。</p><p>那看似诱人的潭水，正疯狂地溶解着它崩坏的本质，带来比之前强烈百倍的痛苦。</p><p>无数散发着柔和白光、形态如梦幻水母或流动光带的“舌头猫条”，从洞穴深处、从潭水中缓缓升起。</p><p>它们没有攻击性动作，只是静静地、缓慢地向着触须飘来，正在给马格努斯的肢体，做最后的临终关怀。</p><p>“宝宝你已经很棒很棒了……”</p><p>“安心地睡吧，睡吧……”</p><p>“偷偷告诉妈妈，你的本体在哪呀……”</p><p>它终于彻底理解了，那个名为杨帝的存在所拥有的恐怖领域，意味着什么。</p><p>不是简单的囚笼或战场，这是一个活着的，呼吸着的，拥有无尽生命力和同化能力的……消化系统。</p><p>它自以为聪明的深入，不过是从“食道”滑落，最终坠入了无可逃避的“胃袋”深处。</p><p>触须最后残存的一点意识，在无边无际的、充满绝对生机的幽白光芒中，终于彻底崩解。</p><p>马格努斯的最后一条触须被彻底消化了。</p><p>它心理防线彻底崩溃，供出了本体位置。</p><p>杨帝终于锁定住马格努斯本源所在。</p><p>“逮到你了，小马哥！”杨帝眼中精光爆射，嘴角咧开一个兴奋。</p><p>或许还带着点对下一顿饭的忐忑。</p>
