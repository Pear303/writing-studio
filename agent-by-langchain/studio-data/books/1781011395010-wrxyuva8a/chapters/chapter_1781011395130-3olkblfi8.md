# 金色通道

<p>末日火山的浓烟常年在天际翻涌，却丝毫不影响桦树林里的炊烟袅袅升起。</p><p>瑞弗维尔蹲在木屋前的石桌边，羊皮纸上墨迹未干，他正绘声绘色地描述一位传奇法师。</p><p>“瑞弗，你又在编排谁的黑历史？”伊芙的柑橘香混着松针气息飘来。</p><p>她指尖缠绕着翡翠色咒文，正将新采的野蘑菇悬在半空清洗。</p><p>瑞弗维尔抹了把脸，说：“我在写大陆英雄野史录的姊妹番外《末日火山生存指南》，比如被熔岩史莱姆炸飞时要记得摆个帅气姿势，落地才能摔出英雄气概；又比如脑袋裂成八瓣后，得做好表情管理，否则会留下一张流着口水傻笑的丑照……”</p><p>“脑袋裂成八瓣还能活？”</p><p>“理论上是不能的，但我跟你说过，那一次吃完毒蘑菇后我做的梦吧。”</p><p>“记得，你在那什么‘末日火山旅游区’里，看见一个朋友脑袋裂开……不对，你把梦境当历史了？”</p><p>“都说了这是姊妹番外篇，为我虚构想象中的‘梦中挚友’著传。当然，我也会为你写传的，伊娃……”</p><p>精灵浑身恶寒，心里生出一个冲动——将此人卷成粽子吊在树上，种在火山灰里。</p><p>只要别让他写我野传就好。</p><p>远处火山正巧喷发，桦树林在热浪中轻颤，橘红色的火光照亮两人交叠的影子。</p><p>他们已习惯了这般炼狱景象。</p><p>末日火山的烈焰不会随意蔓延。东部森林，精灵们制造的人工炼金生命“雪鸮”，会在末日火山与林地的交界处盘旋巡逻。</p><p>它们一旦发现有岩浆试图越界，便会迅速俯冲而下。</p><p>提前录制好的冰霜法术瞬间施展，气流便汹涌而出，与炽热的岩浆激烈碰撞，一时间水汽蒸腾，烟雾弥漫，嘶嘶声响彻天地。</p><p>因为水的比热容很大，而且量大容易获取，所以，冰霜的法术都经常用液态或固态水作为施法介质。</p><p>末日火山喷发出赤红岩浆，桦树林上空升起一道彩虹。</p><p>火山灰在生机的碰撞中化作细密金粉，随着樱粉色花瓣飘落。</p><p>若不是这些不用发工资、不用缴保险的人工炼金生命，这片桦树林怕是早就被末日火山的怒火吞噬。</p><p>“今天火山又炸了呢。”</p><p>“但比一百年前祥和多了。”</p><p>瑞弗维尔收起纸笔，坐在树头下。</p><p>他们在末日火山以南的桦树林，那片一年四季落英缤纷、层林尽染的林中，寻了片空地建起一座小屋子。</p><p>因为圣古琉斯王城的地价房价实在太贵，所以他们在林子里，圈了块野生的地，用野生的材料建了一栋人工的温馨小屋。</p><p>工程刚建完一半时，就有贵族带着他的扈从前来，试图以这块地是他的为由，强占之。</p><p>这位贵族回去之时，他领地下的人们惊奇地发现，他们的领主那一头波浪卷儿金发没了，只剩余一颗刺眼的光头。</p><p>他的亲信一边绷住笑容一边安慰他，国王和教皇也是同款发型，这说明位高权重者，都有天然的趋同性。</p><p>——即光头。</p><p>数年后，“光头”已经正式成为贵族病。</p><p>在地球上，欧洲皇室因为骨科乱伦，他们的贵族病是血友病。</p><p>而在这片中土大陆，贵族们（此处主要指男性）纷纷顶着锃亮的光头出入社交场合。</p><p>起初，贵族们为了遮掩这尴尬的“时尚”，用镶嵌魔法宝石的精致头冠、缀满羽毛的夸张礼帽来修饰。</p><p>但久而久之，反而衍生出了新的审美潮流。</p><p>贵族们甚至举办起“最闪耀光头”评选大赛，以光头的亮度、光洁度和独特装饰为评判标准。</p><p>从事件发生顺序上看，是以“伊芙将那名试图占据他们小屋的贵族剃光头发并永久破坏头部毛囊”为开始。</p><p>但从因果上理一理，圣古琉斯的男性贵族越来越多光头，其实是因为有几个流浪商人大力向他们推销的“头皮抛光精华”。</p><p>再加上国王和教皇都是光头。</p><p>所以，这股潮流就这么掀起来咯。</p><p>当然，这都是后话。扯远了。</p><p>瑞弗维尔很喜爱这栋可爱的小屋子。</p><p>周围是密林包围的白桦丛，其间点缀几株樱树。起风时，金黄与绯红的树叶纷纷飘飞，打着旋儿，悠悠然落下，将整片林子装点成流动的云霞。</p><p>海风从南面拂来，霎时间，瑞弗维尔发梢、衣摆都沾满了细碎的绯色，活像只偷穿精灵斗篷的浣熊。</p><p>他仰头接住一片飘落的樱花，花瓣沾在鼻尖轻轻颤动，逗得他忍不住打了个喷嚏。</p><p>伊芙轻笑出声，但最后实在忍不住，所以换成放肆的狂笑。</p><p>天知道精灵的笑点是什么。</p><p>但瑞弗维尔的一言一行，总能准确把握伊芙的笑点，我一发话你笑如飞，你一露笑我舒眼眉，因为你笑了，所以我也笑；而我笑了，又会导致你笑，这就是永动机。</p><p>类似于两个麦克风凑一块儿，啸叫。</p><p>笑饱了，也就正式开始吃饭。</p><p>吃饭是在外头露天吃的，看似蚊子很多，其实二人都有灵能护体，效果比药艾和蚊香好。</p><p>除非是只十环级别的灭世之蚊，或者一群九环级别的精英BOSS蚊，否则这些四害根本近不了二人的身。</p><p>暮色悄然漫过树梢，林间渐起薄雾，雾气将夕阳染成细碎的金箔。</p><p>远处火山轰鸣，此刻成了天然白噪音，偶尔有星火冲破云层，却在触及雪鸮巡逻范围瞬间，被凝成晶莹的冰晶簌簌坠落。</p><p>伊芙从木屋取出陶制餐盘，盘中，烤蘑菇滋滋冒着油花。</p><p>混合着她新采摘的薄荷香气，在暖风中酿成醉人的甜。</p><p>瑞弗维尔用树枝拨弄着空地处的篝火，看火星窜上夜空与星辰共舞。</p><p>这是个平常的夜，就如同过去与未来，已经经历过的，与还未到来的无数个夜。</p><p>地面传来剧烈震动。</p><p>瑞弗维尔手里的树枝差点掉进火堆。</p><p>伊芙站起身，翡翠色咒文在指尖亮起，却见泥土像波浪般隆起，“砰”的一声炸开！</p><p>戴着护目镜的矮人奥拓顶着钻头破土而出，浓密胡须上还沾着蚯蚓，活像颗从地里蹦出来的毛栗子。</p><p>“哈哈！终于找到组织了！”奥拓扯下脏兮兮的皮围裙，露出里面印着“砾石最佳铁匠”字样的汗衫。</p><p>奥拓随手将钻头往地上一插，震得几片樱花簌簌飘落：“你们这地方不错，可比我那矿洞舒服百倍！听说你们在烤蘑菇？我从地底挖了点宝贝——”</p><p>说着，他从背包摸出个铁皮盒。</p><p>打开后，竟是金灿灿的熔岩蜂蜜，在火光下泛着与瑞弗维尔眼眸相同的琥珀色。</p><p>“还有这个，矮人特酿，绝版一百年的熔岩麦酒，专治各种腰酸背痛！”</p><p>他掏出一个瓶，瓶里是赤金色的酒液，杵在金合欢木小圆桌上。</p><p>伊芙无奈地摇头，放弃了将“电灯泡”一巴掌轰杀至渣的想法，默默添副碗筷。</p><p>毕竟来了就是客，而且是带了美食与好酒来的优质客人。</p><p>奥拓却只是抓起几串滋滋冒油的煮菌子，狼吞虎咽地往嘴里塞，油渍顺着胡须滴滴答答往下落，一边嚼着一边含糊不清：“这味道绝了！不过我那矿洞还有一堆活儿等着，得赶紧回去。这蜂蜜和酒就留给你们，就当是蹭饭的谢礼！”</p><p>话音未落，他已经将钻头扛在肩上，对着瑞弗维尔挤眉弄眼。</p><p>“哦噢……好好……”</p><p>“下次我再带更稀奇的玩意儿来！”说完，矮人猛地将钻头往地上一戳，地面瞬间裂开缝隙。</p><p>他跳进去，眨眼间缝隙便合拢，只留下微微颤动的泥土。</p>
