# 创世与灭世之斧

<p>战场外围。</p><p>数百名围观的嗜血真仙境大能，眼神已有些麻木。</p><p>噫，好，天空有一把大斧头！</p><p>虽然单论声光效果，并不足以让他们魂飞魄散、肝胆俱裂、花容失色、须发皆焦。</p><p>但当那虚影完全成型的刹那，在场所有真仙境大能体内，灵力开始不受控制地疯狂涌动。</p><p>像是要冲破经脉，汇入那道创世投影之中。</p><p>嗜血真仙境的强者们惊恐地发现，自己引以为傲的仙术在这股力量面前如同孩童的把戏，就连呼吸都变得无比艰难。</p><p>此世的法则，都在强迫他们向那柄「灵茶山乂斧」俯首称臣。</p><p>这就是“满血版”灵茶山乂斧。</p><p>归墟大帝所用的那把斧子，虽然也能算得上极道神兵，但实际上是货真价实的“阉割版”。</p><p>和神话传说中的“正版·创世之斧”比起，仍然稍逊一筹，稍逊十筹，稍逊一万筹。</p><p>而正版的创世之斧，还未落下，便已让他们看见自己死亡的命运。</p><p>青丘白璃颤颤巍巍目视天空：“灵界学者普遍认为，真正的‘灵茶山乂斧’应该只带一种将世界分裂开来的原始驱动力……没想到，比起斧头它形状更像菜刀。”</p><p>“别管形状是斧子还是菜刀了，现在我们是不是应该跑？”</p><p>“能跑到什么地方去？那斧子要是挥下来，我感觉这片天地，整个宇宙，都要被第二次开辟一遍。”</p><p>重炼风雷地火，把五行打回原形。</p><p>躲到灵界任何一个角落，又有什么意义呢？</p><p>而这一招，仅仅是为了对付一个人，杨帝。</p><p>灵茶山乂斧正在无垠深空中呼啸。</p><p>不，并不是斧子在呼啸，而是大道法则又双叒叕开始惨叫。</p><p>三位准圣面色惨白，显然引动此物对他们也是极大的负担，本源都在剧烈燃烧。但他们眼神中的决绝更甚！</p><p>“斩！”</p><p>轰——！！！</p><p>那柄凝聚了开天辟地伟力的“灵茶山乂斧”虚影，在三位准圣不惜燃烧本源道果的催动下，终于动了。</p><p>一道无法形容其璀璨的斧光，自混沌缝隙中劈落。</p><p>它无视了空间，超越了时间，锁定了杨帝的存在本质。</p><p>杨帝感受到了前所未有的压力。</p><p>问世间，自有山比此山更高。</p><p>正版、原装、无删减的“灵茶山乂斧”。</p><p>这就是三位准圣的万古布局！</p><p>他们布局的时候究竟是以什么为假想敌？希灵帝国还是不朽者联盟？</p><p>三位准圣的咆哮，裹挟着不惜一切的决绝，仿佛点燃了万古的烽燧。</p><p>他们头顶的虚空，如同被无形巨手撕裂的古老画卷，一道贯穿过去、现在、未来的巨大缝隙悍然洞开！</p><p>缝隙之内，非是虚无，而是奔涌咆哮、开天辟地之初最本源、最狂暴的力量源泉！</p><p>灵茶山乂斧并非实体，却比任何实体更重，重到压塌万古青天。</p><p>它没有固定的形态，却又清晰地烙印着“开辟”这一终极法则的意志。</p><p>斧刃所向，混沌自动裂解，清浊自分，</p><p>无数真仙大能更是面色惨白，体内仙力如沸水般失控翻腾。</p><p>包括被打到场外的仙帝，神皇，至尊，都无法在这威压下挺直腰板。</p><p>斧，此界诞生的根源意志，万物必须遵从的母法，即使是“至尊”，也无法抗衡。</p><p>“疯子！你们都是疯子！”</p><p>阿巴现出原形，的鲈鱼须根根倒竖，死死抓住59改冰冷的臂膀，“为了杀老大，你们要把整个灵界都搭进去吗？你们都保护了些什么！”</p><p>是的，这把创世之斧一经出世，灵界便开始走向毁灭。</p><p>此界，也无法承载它的力量。</p><p>创世之斧，正在带来字面意义上的“大道磨灭”。</p><p>「斩！！」</p><p>三位准圣齐声厉喝，声音嘶哑，带着本源燃烧的焦糊味。</p><p>他们面容扭曲，七窍中逸散出本源道则的光辉，显然引动这创世投影，代价是他们的道基在飞速崩解！</p><p>轰——！！！</p><p>那道凝聚了开天辟地伟力的“灵茶山乂斧”虚影，动了。</p><p>没有声音，或者说，声音在诞生的刹那就被抹去。</p><p>但众人可以看到，一道无法形容其“存在”的斧光，自混沌缝隙中劈落。</p><p>它没有璀璨的光华，反而像是吞噬了所有的光与色彩，只留下纯粹的、斩断一切的“线”。</p><p>线，超越空间的概念，无视时间的阻隔，一出现，便已降临。</p><p>斧光所过之处，并非毁灭，而是彻底的“抹除”！</p><p>空间消失，化为最原始的虚无混沌。</p><p>时间断流，过去未来于此刻被归零。</p><p>法则崩解，化作点点流光遭斧刃吞噬。</p><p>甚至连“现实”这个概念本身，都在斧光路径上被硬生生剜去。</p><p>“不——！”有真仙大能发出绝望的嘶吼。</p><p>仅仅是斧光逸散的一丝余波扫过，他连同其所在的空间，瞬间化为乌有，连一丝尘埃都未曾留下。</p><p>这已非战斗，而是灭世。</p><p>三位准圣，和那个始终无动于衷的圣人，疯了。</p><p>为了杀死一个杨帝，不惜赔上整个世界？</p><p>整个灵界宇宙，在这创世之斧的威能下，物质结构崩解，星辰黯淡熄灭，万物归于混沌。</p><p>如同将一幅画卷，粗暴地投入浓硫酸之中，一切色彩、形体、意义都在飞速消融。</p><p>“这一斧，是为我而落。那么，就先砍在我身上吧！”</p><p>杨帝首当其冲！</p><p>他冲杀至创世之斧落下的路径前方，用自己的身躯，挡在尚未受害的灵界万物与众生之前！</p><p>但是，灵茶山乂斧的力量远超三位准圣的领域联手。</p><p>杨帝那足以撑爆三重领域的混沌帝躯，在这道斧光面前，竟如同投入沸水的雪花，以肉眼可见的速度消融。</p><p>血肉、骨骼、乃至沸腾的气血神芒，都在接触斧光的瞬间被“抹除”。</p><p>一种源自灵魂最深处的剧痛和冰冷，席卷了杨帝。</p><p>剧烈的痛苦，远超之前任何一次“死亡”，那是存在根基被连根拔起的终极痛楚！</p><p>一山更比一山高。</p><p>境界之上仍有境界，大能之上仍有大能。</p><p>“这就是爬塔升级的宿命？下游的无敌，在上游的创世伟力前，依旧不堪一击？！”</p><p>杨帝浑身被撕裂。不过他已经习惯了剧痛，这点痛算不上什么。</p><p>他只是出离的愤怒，并困惑。</p><p>三位准圣，乃至他们背后所代表的某种意志，为了自己的退休金，竟不惜引动灭世之力，将整个灵界拖入陪葬的深渊！！</p><p>杨帝看到无数真仙大能绝望闭上的双眸，看到亿万灵界生命，在斧光余波中无声湮灭……</p><p>看到了远处青丘白璃眼中极致的恐惧，看到了59改核心处理器爆出的火花。</p><p>还看到阿巴眸中一闪而过的精光。</p><p>点子王有点子了。</p>
