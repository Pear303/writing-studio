# 杨帝的消失

<p>杨帝已经找遍了艺术楼，乃至整片旧校区。</p><p>都找不到希夷、陈昭和胡彦卓的存在了，包括他们存在过的证据。</p><p>他们真的存在过吗？</p><p>他甚至开始怀疑，自己所经历的一切是否是梦。</p><p>他站在楼顶。数小时前，便宜师傅——胡彦卓大哥在这哈哈大笑道：</p><p>「在我得到过的评价里，你这个算是最特别的一个……」</p><p>杨帝按照原定路线，顺着空调外机、排水管和外部平台，爬下旧校区地面1楼。</p><p>一切都很熟悉，但又似乎陌生。</p><p>晨雾在楼宇间流淌，如轻纱般缠绕着褪色外墙，檐下燕窝里传来雏鸟啁啾。</p><p>然而，暗处的阴影并未完全褪去。</p><p>走廊尽头的拐角、台阶下的死角，仍蛰伏着未被阳光驱散的幽微黑暗。</p><p>光明与阴影进行着永恒的拉锯，白昼与黑夜是它们各自占据上风的轮回。</p><p>但至少，那股一直笼罩在旧校区上空的深沉的不安，已经彻底消失。</p><p>旧校区再也不会诞生新的都市传说，或者说——再也不会诞生真正的都市传说。</p><p>而随着校园论坛远古贴子的没落，此地的秘密终将被世人遗忘，被时间埋葬。</p><p>一切都不存在。</p><p>非理性的神秘并不存在。</p><p>……</p><p>他从摄像头注视下，从保安亭一旁的大门走出旧校区。</p><p>保安没有理他。</p><p>路旁桂花在微风中簌簌作响，花瓣飘落，于他而言不过是徒增寂寥的残景。</p><p>一种混沌的不安在心头萦绕。</p><p>今天，路人都好像有些不对劲。</p><p>他们的目光，未曾在他身上做过任何停留，仿佛他是透明的空气。</p><p>包括镇守旧校区的保安，也对他的出现无动于衷。</p><p>杨帝游魂般穿过稷海理工的林荫道，梧桐树影在他脚下碎成斑驳的鳞片。</p><p>一株古树下，穿碎花裙的姑娘正踮脚吻男友的下巴。</p><p>杨帝路过时，两人沉浸在缠绵的气息里，连衣角被风掀起的弧度都没注意到。</p><p>完全忽视了他这个电灯泡吗，有意思。</p><p>杨帝心中萦绕着不对劲。</p><p>迎面是戴黑框眼镜的理工男，抱着一摞资料迎面走来，眉头紧锁盯着手机。</p><p>杨帝退到路边让行。</p><p>对方却没有选择擦肩而过，而是正面一撞。</p><p>戴黑框眼镜的理工男，这才如梦初醒般嘟囔一句“对不起”，眼神却依旧迷茫。</p><p>好似——杨帝只是他意识边缘一闪而过的幻影。</p><p>他抱着资料和手机继续向前走。</p><p>“你钥匙掉了。”杨帝蹲下身捡起那不锈钢钥匙，扯开嗓子道。</p><p>声音却像被塞进了棉花里，连自己都听得模糊。</p><p>那人更是没听到似的，继续向前走。</p><p>杨帝盯着掌心里那枚泛着冷光的钥匙，齿痕状的纹路在指腹下硌得生疼。</p><p>14-514号。这分明是他宿舍的钥匙。</p><p>仅有一把，仅有一把的备用钥匙。</p><p>可杨帝清楚记得，上周刚把备用钥匙交给对门的室友，张明远保管着。</p><p>此刻，钥匙却出现在一个陌生人手中。</p><p>而那个人，杨帝敢发誓，他的宿舍从来没有这个人。</p><p>从记忆中搜索，也未曾在稷海理工见到过。</p><p>自从能够调度10%的潜意识，杨帝发现，他可以事无巨细回忆起任意一天的记忆。</p><p>但他翻遍了4年来，在稷海理工的记忆，匹配了数千张人脸。</p><p>未曾见过他。</p><p>这人似乎是突然出现在稷海理工大学的。</p><p>晨雾不知何时又浓了些，将两人的身影裹进灰蓝色的纱幕里。</p><p>那个拿着自家宿舍钥匙的人，又是谁……？</p><p>杨帝脑海中一瞬间流传过千百万个念头。</p><p>他已有猜测，但不愿承认。</p><p>他加快脚步，无声无息跟上那个男子。</p><p>理工男在图书馆旁的人工湖右转，走过天桥，转入宿舍楼。</p><p>就是自己所住的宿舍楼，那栋熟悉的赭红色建筑。</p><p>杨帝观察到一些细节。</p><p>他曾在一楼放养的野生花盆、以及花盆上的向日葵，不见了。</p><p>取而代之，是一瓶从未见过的铃兰花，长势良好，有经常换水和肥料。</p><p>他尾随那男子一路。</p><p>杨帝甚至没有刻意隐藏自己。</p><p>他越来越发现，甚至是从路人面前走过，他们也好似看不见自己。</p><p>唯一发现他的，貌似也只有校园到处出现的流浪猫。</p><p>当时，杨帝距离那坨橘猫不足20厘米时，它终于抬起头，有些困惑地朝他看一眼。</p><p>紧接着，另一个抱着书的女生想去摸摸它。</p><p>她与橘猫相距3米的时候，它跑开了。</p><p>杨帝尾随那黑框眼镜理工男进入公寓，走上楼梯，来到5楼。</p><p>那人停在514号房前，膝盖曲起顶在墙上，书本垫在大腿，右手摸口袋翻找钥匙。</p><p>他找不到房门钥匙，有些困惑。</p><p>杨帝走上前，去拍拍他肩膀：“兄弟，刚才叫你你没反应，这是你掉的钥匙。”</p><p>男子看了他一眼，如梦初醒：“哦哦噢，谢谢啊。”</p><p>他一手抱着书和资料，另一手钥匙打开门。</p><p>杨帝朝宿舍内瞥一眼。</p><p>他已经确定了自己的猜想——室内景象如同被篡改的画卷。</p><p>原木书架变成了冰冷的铁柜，床铺上铺着陌生的格子床单。</p><p>曾经光秃秃的墙壁上，贴着一张攻壳机动队的海报。</p><p>海报旁边是全宿舍的合照。</p><p>照片里，杨帝的位置，被黑框眼镜青年面无表情的脸占据。而舍友们的笑容刺眼，仿佛从未认识过他。</p><p>那陌生的黑框眼镜理工男，进了屋，快要关上宿舍门时，才注意到杨帝还堵在门口。</p><p>“呃，这位老哥还有事吗？”他问。</p><p>杨帝：“没什么。相逢即是缘，兄弟加个微信吧，我和你宿舍张明远认识。”</p><p>张明远顶着黑眼圈和鸡窝头，从电脑屏幕上探出头来，嘴角还挂着几根泡面碎屑。</p><p>他看起来同样一脸困惑。</p><p>“嗯谁叫我？这位兄弟你谁？我认识你吗？”</p><p>杨帝：“……打游戏认识的。张明远，如果你听到我声音还想不起来，咱就删好友吧哈哈。”</p><p>张明远连猜了几个名字，杨帝都道“不对”。</p><p>他和那个黑框眼镜理工青年交换企鹅号。</p><p>但杨帝掏出手机那一刻，却发现——自己没有企鹅号。</p><p>登录不上去。企鹅服务器显示，该账号不存在。</p><p>他登上学校论坛，又找到那个帖子。</p><p>楼主（希夷）那一栏，显示也是“用户已注销”。</p><p>而自己的学校论坛账号，同样显示已注销。</p><p>他明白了。</p><p>杨帝始终认为，“希夷”不是希夷的本名，但他的真正名字也无从知晓了。</p><p>“被剥夺了‘灵’，就连自己的账号也要失去吗？”</p><p>杨帝身上的衣服、手里的手机并没有消失，是因为这些物品始终和他待在一起。</p><p>而他的社交账号、学生身份、其他人对他的记忆……这些信息，并非存储在他身上。</p><p>而是存储在服务器、数据库，和他人的大脑中。</p><p>这些存在于“外界”的事物，只有很小一部分能幸存，比如希夷发的“【纪实】旧校区偷渡记”帖子。</p><p>耶罗大仙杀不死杨帝“本身”，却能杀死他的“外在之物”。</p><p>于是，耶罗大仙将他的账号、身份、其他人对他的记忆……杀死，吞食了。</p><p>杨帝感到深深的恶意。</p><p>他收回手机：“兄弟开个玩笑而已，人人之间还是要保留些距离感。以后不要把514钥匙搞丢了。”</p><p>不等黑框眼镜青年答话，杨帝离去。</p><p>偌大地球，还有安身之处么……？</p><p>飘落的桂花沾在他的肩头，又无声滑落。</p><p>所有喧嚣都离他远去了。</p><p>世界是一场默片，而杨帝是唯一的观众。</p><p>那些曾与他擦肩而过的路人，此刻都成了透明的幽灵，在他触不可及的平行时空里，继续着各自的生活。</p>
