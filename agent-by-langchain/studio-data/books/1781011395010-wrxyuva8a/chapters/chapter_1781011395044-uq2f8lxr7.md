# 幕后黑手

<p>老大是容不得反驳的。</p><p>将它喂养到开启灵智的人是老大，它的性格与思想和老大有九成相似。</p><p>希夷反驳杨帝，相当于反驳它自己。</p><p>左右脑互搏，不是所有人都能做得到。</p><p>“操控这些怪物的东西，比我们想象的更聪明。它算准了我的弱点。”</p><p>杨帝一手持电筒，另一手拎着砾经磨损的钢管，抬脚踩进脚踝深的污水。</p><p>他对希夷笑笑：“不过没事的，希夷。它们为什么不直接杀了胡哥？因为想逼我入瓮。如果我退缩，胡哥必死无疑；但如果我进去……”</p><p>他的和煦微笑变为森然笑意：“说不定能反过来抓住那只藏头露腚的老鼠。”</p><p>杨帝迈步走向黑暗深处。</p><p>“你老大我最讨厌被人牵着鼻子走。既然它想玩猫鼠游戏，老子就做那只掀翻棋盘的鸟。”</p><p>希夷发出一声麻雀叫，振动翅膀追上他的步伐。</p><p>杨帝的手电筒光束照在污水表面，划出一道颤抖的银线，腐臭的气味像实质般黏在鼻腔里。</p><p>污水没过脚踝，水面浮着的油膜，彩虹色的光斑在砖墙上扭曲成诡异的图腾。</p><p>成群的蟑螂在光束边缘疯狂逃窜，它们就是杨帝所听到的甲壳摩擦声来源。</p><p>很恶心，令人反胃，像无数把生锈的小刀刮过神经。</p><p>这里像是个下水道。管道很黑，手电筒光束在幽黑的管道内格外孱弱。</p><p>光束扫过潮湿的管壁，青苔斑驳的砖缝里渗出暗绿色的黏液，在光束中泛着妖异的荧光。</p><p>杨帝注意到，头顶的管道接缝处有黑影在蠕动。</p><p>不是蟑螂，而是某种更庞大的东西。</p><p>——管道内壁的阴影里，数条黑色拉面状的触须正像毒蛇般缓缓游移。</p><p>它仍在观察着杨帝，注视着他一步步走入瓮中。</p><p>希夷扑棱着翅膀跃上杨帝的肩头，鸟喙指向左侧：“老大！那边有反光！”</p><p>杨帝微微侧身，手电筒光束劈开黑暗。</p><p>二十米外的管壁上照出一抹金属冷光。</p><p>那是胡彦卓随身携带的瑞士折叠刀，此刻正深深插在砖缝里。</p><p>杨帝走去，收下了瑞士刀，别在腰间。</p><p>前方空间逐渐开阔，管道尽头豁然开朗。</p><p>生锈的铁栅栏被手电光照亮，混凝土穹顶高高隆起，数十根碗口粗的管道，像巨蟒般从四面八方汇入中央的圆形平台。</p><p>积水在平台周围形成暗褐色的漩涡。</p><p>圆形平台边缘，有个锈迹斑斑的控制台，胡彦卓的登山背包正歪倒在控制台旁。</p><p>背包拉链开着，里面的强光手电和信号弹散落一地。</p><p>而胡彦卓——他正躺在圆形平台中央。</p><p>杨帝两步冲到胡彦卓身边，钢管哐当砸在地上。</p><p>手电筒光束扫过胡彦卓苍白的脸，只见他胸骨处凹陷成诡异的弧度，肋骨在皮下支棱出狰狞的轮廓，却非常幸运地没有穿透内脏。</p><p>杨帝扯开他的短袖，手指按上颈动脉。</p><p>跳动虽然微弱，但还算规律。</p><p>及时就医，不会落下病根。</p><p>但前提是“及时”。现在，他们想要逃出去都有点难，入了虎穴，来去就不能由自己了。</p><p>希夷的羽毛炸立起来。</p><p>“老大，头顶……有东西，我们预料之中地被包围了吱。”</p><p>杨帝也已注意到。</p><p>他抬头，手电光束扫过穹顶。</p><p>无数条黑色触须正像融化的沥青般，从裂缝中渗出，在半空织成一张蠕动的网。</p><p>“瓮中捉鳖啊。”</p><p>杨帝在管道上腾挪，把胡彦卓翻过身来，后者发出微弱的呻吟。</p><p>他将胡彦卓扛上肩头。</p><p>却在此刻，发现了令人难过的异常——胡彦卓，这位跑酷界冉冉升起而又快速陨落的新星，他右手食指被切除了。</p><p>他右手戴着的白色橡胶手套，在食指根部位置，裂开切口，像咧开的嘴般翻卷着。</p><p>暗红的血珠正从断口处渗出。</p><p>而在他正面的胸膛上，用胡彦卓自己的血，画了一个图案。</p><p>三条弧线扭曲，蜷向中心圆点。</p><p>一个漩涡样图案，耶罗符印的图纹。</p><p>至于“绘画工具”是什么，已经呼之欲出了。</p><p>断尾狸花猫的“画笔”，是断掉的尾巴。</p><p>而胡彦卓胸膛上的图案，则是被他流血的断指所绘。</p><p>绘画的“墨水”，都是受害者自己的鲜血。</p><p>幕后黑手，他或者他们——正在执行某种仪式，极尽邪恶的仪式。</p><p>总之，非常符合邪教的定义，人人得而诛之。</p><p>“这帮畜生……”杨帝喉间滚出咆哮。</p><p>这处旧校区混进了不干净的东西，一种对人民有害无利，一种毁灭性的鸦片，一种邪教。</p><p>“幕后之人”的声音出现了。</p><p>一个沙哑的声音从四面八方挤压过来：</p><p>「你这…蛆虫……窃贼……那是……我的……祭品……我的……的门钥！！！」</p><p>被转化成黑色拉面团的狸花猫和小白鼠，分别从左右二侧出现。</p><p>再次进入战斗轮，而且是最终boss战前，最后一场战斗轮。</p><p>杨帝熄灭手电，的瞳孔在黑暗中扩散。</p><p>「视力+1」</p><p>他反手抽出胡彦卓遗留的的瑞士军刀，寒光掠过胸前，猛然刺向自己的左臂。</p><p>“老大！！你在干嘛吱！！”</p><p>刀锋入肉的闷响，惊得希夷发出尖叫。</p><p>暗红的血瞬间浸透战术衬衫，在平台上滴落，绽出血花。</p><p>他忍痛笑着：“如你所见，我在自戕。”</p><p>「锐器抗性+1+1」</p><p>杨帝咬碎一声闷哼，刀刃在肌肉里绞出更深的伤。</p><p>然后迅速抽出，在其他部位继续刺出更多伤口，刀刃如法炮制地绞动。</p><p>「锐器抗性+1+1+2+3」</p><p>“此次前来，最大的遗憾是没有提前刷好各项属性和数值，导致我只能一遍遍临时抱佛脚，一遍遍进入危急情况。虽然一次次化险为夷，但现在，运气终于耗尽了。”</p><p>他另一只手掏出运动饮料，直接倒进蛋白粉罐子里，一块混合着喝下。</p><p>「锐器抗性+5+8+13」</p><p>杨帝几乎被电解质饮料和蛋白粉呛死。</p><p>他无视缓缓逼近的狸花猫和小白鼠，抬头，望向穹顶那一大团黑色黏液质的怪物。</p><p>他仍然在往身上插刀子。</p><p>但是，那刀刃越来越难以插入皮肉。</p><p>借助极限自杀式的锻炼，他肉身对锐器的耐受度，正在急剧提升。</p><p>「锐器抗性+21+34+55」</p><p>「锐器抗性+1+1+1+1+1……」</p><p>“喂，怪物，说我是什么‘蛆虫’、‘窃贼’，你不要凭空污人清白啊，我偷你什么东西了！”</p><p>那个刺耳的声音再次从四面八方传出：</p><p>「耶罗……符印……那是……门钥……」</p><p>杨帝怒吼：“这混账符印是你强加在我身上的！我根本摆脱不掉！！你特么不要倒果为因！！！”</p><p>那个声音沉默了一下。</p><p>而后，那个声音骤然拔高，像生锈的铁钉刮擦黑板，又似无数玻璃碎片在耳道里迸裂。</p><p>杨帝的耳膜刺痛，鲜血从耳道渗出，在脸颊上蜿蜒成血痕。</p><p>「听力+1+1+2+3+5+8+13」</p><p>「精神+1」</p><p>那个癫狂的声音，裹挟着近乎魔怔的恨意：</p><p>「窃贼！！不是你！！！是……是你……该死的你！！他叫希夷！！」</p>
