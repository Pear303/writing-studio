# 杨帝在睡觉

<p>精灵坐在一根倾倒的原木上，凉鞋晃悠着，笔记本垫在膝盖上写画着什么。</p><p>他坐到柑橘香气的精灵旁边。</p><p>“伊娃，你做学术研究多少年了？”</p><p>“不长，1300年。”她丢来一句话。</p><p>瑞弗维尔笑笑：“我20岁开始当职业游侠，前后干了十三四年，品尝了诸多珍馐。”</p><p>“你到底想说什么？”</p><p>瑞弗维尔轻轻挠了挠头，眼神中带着几分认真与思索，“伊娃，是这样的……我之前跟你说过，我最喜欢菠萝蜜，第二喜欢是榴莲对吧。”</p><p>“嗯。”</p><p>“是因为我在南方的雨林里当职业游侠时，曾六度将毒蘑菇当好吃的菌子，下锅炫了。那几次，我都原地昏迷了几天几夜，醒来后饥寒交迫，走路都走不稳。”</p><p>伊芙合上笔记本，将头发撩到耳后放好，托腮专注地听：“居然没死？后来嘞。”</p><p>“你知道的，雨林里水果很多的嘛，其中有4次我遇到的是菠萝蜜，2次遇到的是榴莲。”</p><p>“雨林里确实很多菠萝蜜，其实我也吃过几块，味道不错……”</p><p>“但对于那个时候的我来说，它的味道已经不重要了。伊娃，在我当游侠的冒险生涯里，菠萝蜜救了我四次，榴莲救了我两次。”</p><p>伊芙噗嗤地笑出声来。</p><p>“迟早馋死你！天天采菌子，却又分不出毒蘑菇。”</p><p>“但菌子真的很好吃，我会吃一辈子。只不过，下次中毒，也许我身边就没有菠萝蜜和榴莲了，这时候，或许就能有第三个水果，成为我的第一喜欢……”</p><p>“呵呵……所以嘞，瑞弗你的梦想是吃一辈子蘑菇吗。”</p><p>他们突然谈起了理想。</p><p>“我毕生愿望并不是吃菌子啦。”</p><p>瑞弗维尔拾起一根枯枝拨弄火堆，火星子噼啪炸开像群星坠落。</p><p>“攒够钱，我就去雨林边上盖座树屋，檐角要挂满风铃。早晨采菌子，下午写《大陆英雄野史录》，把那些吟游诗人不敢唱的故事全记下来——比如，圣骑士巴德当年和美人鱼私奔，结果见家长时被岳父赶走。后人以讹传讹，把带着美人鱼下海、又从水里游上来的巴德传唱成‘消灭塞壬’……”</p><p>伊芙又“咯咯”地想起来。</p><p>“写完，然后第七次被毒蘑菇送走？”</p><p>“啊——我也希望我下次被毒晕醒来后，不会饿死……”</p><p>“瑞弗，请记得树屋刻好墓志铭：这里长眠着一位坚定的菌类鉴赏家。”</p><p>瑞弗维尔也对着篝火傻笑起来。</p><p>他问：“伊娃你呢？学者？”</p><p>“没错，而且是专门研究史莱姆的学者。”</p><p>史莱姆，即使是最菜鸡的佣兵，也能赤手空拳将其挑翻。</p><p>中土大陆最强的战斗力之一，研究起了最低档的魔物。</p><p>看起来颇有趣味，但这就是中土大陆现状：魔君荡灭，巨龙陨落。政通人和，四海平安。</p><p>身怀伟力的人没事儿干，也只好干起了学术研究。</p><p>“其实我不是因为没事干，才去研究史莱姆的。在加入联军、讨伐焚灭天空之龙以前，我就已经研究史莱姆1000多年。”</p><p>瑞弗维尔张大嘴：“你从小就对史莱姆感兴趣？”</p><p>“没错，是我很小的时候了，那时我大概才70岁……”</p><p>她回忆起那天的场景：</p><p>那时候，她和其他几十岁、几百岁的孩子躲猫猫。</p><p>伊芙躲进废弃矿洞，在一处水潭边，发现一只史莱姆正用触手串矿石玩。</p><p>第二天，它顶着一个东西游上来，像捧着晨露的蜻蜓。</p><p>“锵锵～你有没有注意到我发卡？”</p><p>伊芙微微低下头。</p><p>瑞弗维尔这才看到，她脑袋上别着个金色的发卡，内部橘红色光泽流动，仿佛熔岩光泽。</p><p>伊芙托着腮：“这个发卡，就是那时候那史莱姆送的。按理来说，史莱姆没有‘馈赠’概念，但那一刻我感觉……它们在等待被理解。”</p><p>夜风裹来柑橘与篝火交织的暖香。</p><p>瑞弗维尔看见，精灵瞳孔里跳动着比岩浆更炽热的光。</p><p>这就是她研究史莱姆的原因，一段可以放进史诗里传唱的奇缘。</p><p>而瑞弗维尔，他当年选择当职业游侠的理由则很简单，也很现实——没钱，只好出来打工。</p><p>打工挣钱嘛，不寒碜。</p><p>平日里做的最多的就是保镖，护送货物。</p><p>在此过程中，他接触了许多生动的“当代野史”。</p><p>瑞弗维尔用树枝挑起一簇火星，火光照亮他老实的眉眼：“我也讲讲我的过去吧。伊娃，知道护送商队最重要的是什么？”</p><p>“嗯，拳头？”</p><p>“不，不是剑术也不是追踪，而是往马粪里掺雷火蜥蜴的尿，那种气味，能让魔狼闻了绕三里地走。”</p><p>“肯定比榴莲和霸王花恐怖～”</p><p>“那可不是嘛。当年，我还随着圣骑士团的银辉战出征，你知道么，全队马鞍垫布里都缝着发臭的菘草，都刚刚从马厩里捞出来的。”</p><p>伊芙捧住脸颊，羞红脸：“妈耶！”</p><p>“我想说的是，史书里衣袂飘飘的英雄，早年裤脚都沾着泥点子，他们早年弱小的时候，也一定善用各种阴谋诡计。”</p><p>而认识到这一点的瑞弗维尔。</p><p>从此立志——要撰写一部野史！</p><p>伊芙挖苦：“瑞弗，我认为是你以己度人了吧？总不可能所有英雄都这么狡诈。”</p><p>远处传来夜枭啼鸣，瑞弗维尔往火堆添了新柴。</p><p>“怎么会怎么会……就像伊娃，你发卡里的岩浆，最开始不也是地底黑乎乎的石头么？”</p><p>伊芙捏着发卡轻轻一转，熔岩流光泼洒在瑞弗维尔脏兮兮的皮甲上。</p><p>“我的史莱姆可不会教幼年精灵使阴招。”</p><p>她脚尖勾起块石子踢进火堆，火星炸开。</p><p>瑞弗维尔一拍脑袋：“说起史莱姆，杨帝他也带了只超棒的熔岩史莱姆！”</p><p>伊芙催促他快一起去看看。</p><p>他们摸进地窖，偷偷打开杨帝的背包。</p><p>DUANG～DUANG～</p><p>一坨Q弹的暗红色生物从内部弹出，正是原本在冬眠、却突然被吵醒的熔岩史莱姆。</p><p>伊芙抱起熔岩史莱姆，然后开始“啊啊啊宝宝你是一个史莱姆！”</p><p>它又困又饿，现在一被打扰，更是疯狂扭捏起来。</p><p>精灵的指尖凝聚一小团实体光球，用火焰珠微微加热，喂给熔岩史莱姆。</p><p>灵能提升过程中，“慢”指的是扩张容量上限，如果只是单纯吸收灵能，那速度会快许多。</p><p>对九环法爷、精灵伊芙而言，一个实体光球所消耗的灵能，不到10秒就能呼吸补回。</p><p>光球富含灵能，入口温度刚刚好。</p><p>熔岩史莱姆吃下，光泽都变润了些。</p><p>它舒服地颤动着身体，原本因为饥饿和被吵醒而略显黯淡的体表，此刻竟焕发出一种温润的光彩，像是被精心打磨过的宝石。</p><p>“事实证明，杨帝不会养史莱姆。”伊芙如是总结。</p><p>他们把史莱姆物归原主。</p><p>人类与精灵回到篝火旁，只留下杨帝在地窖里睡觉。</p><p>瑞弗维尔给伊芙来了杯正经的柑橘茶，并保证没添加任何“英雄的小伎俩”。</p><p>杨帝在睡觉，人和精灵则愉快地待到天明。</p>
