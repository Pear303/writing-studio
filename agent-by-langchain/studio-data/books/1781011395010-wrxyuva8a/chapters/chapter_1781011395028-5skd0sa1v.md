# 和这玩意共存也不是不行……

<p>杨帝尚未脱离梦境。</p><p>将“池梦”的表层全部剥离后，他看到了「希夷」本体。</p><p>梦是抵挡希夷的防线……</p><p>梦的表层被剥离了。于是杨帝直视希夷。</p><p>针扎般的剧痛在视网膜上炸开。</p><p>他猛然理解，古人为何要用“目击”来形容“见证”！</p><p>此刻，他眼球正被某种存在暴力地“击穿”！</p><p>仿佛两根烧红的铁钎，直挺捅入晶状体，插到脑髓深处猛地一搅。</p><p>视神经在焚烧，却无法移开视线。</p><p>剧痛升级为某种超越疼痛的感知。</p><p>多巴胺与去甲肾上腺素在错误地分泌，恐惧与狂喜双螺旋般缠绕着上升。</p><p>目击「希夷」本体，注视无定形之物。</p><p>对有些人来说，能目击这种神秘侧的东西，真是死也值回票价呀！</p><p>杨帝也是这样的人，对神秘事物极度好奇，小时候天天看自然传奇走近科学探索发现，高中以后开始混迹各大灵异怪谈论坛。</p><p>直到这一刻他惊觉，自己是不是有些叶公好龙了？</p><p>“要死……了么……这就是精神伤害……”</p><p>如果说，数学对人的精神伤害是10000，那么直视希夷的杀伤是535559835。</p><p>杀伤……伤……损伤……</p><p>如果有损伤，那是否便可以超量修复？</p><p>如果是致死性伤害，那么，应该是符合黄金分割数列形式的爆炸式进化……</p><p>「精神+1」「精神+1」「精神+2」「精神+3」「精神+5」「精神+8」「精神+13」「精神+21」「精神+34」「精神+55」「精神+89」「精神+144」「精神+233」「精神+377」「精神+610」「精神+987」「精神+1597」「精神+2584」「精神+4181」</p><p>「精神+6765」</p><p>「精神+1」「精神+1」</p><p>理智崩溃止住了。</p><p>在杨帝变成抽象行文艺术大师之前，“损伤代偿机制”遏制住了变傻逼的过程。</p><p>爆炸性增长了上万精神力，恐怖如斯！</p><p>杨帝的视觉皮层用毕加索式的抽象画风，重构出“希夷”形象。</p><p>听觉中枢则将不可名状的低语，转译成一股贝多芬味的交响曲。</p><p>那团存在，已被大脑自动打上马赛克，就像处理血腥镜头的电视画面。</p><p>不过，如果杨帝执意要查看那玩意的本体，马赛克也是可以消除的。</p><p>只不过，掀开马赛克后，长时间盯着那玩意看，有点让人反胃恶心、头痛欲裂、呼吸急促、血氧降低、腰背酸痛、眼压升高。</p><p>这并不是精神攻击，仅仅是他身为人类，生理上对“不可名状之物”的不适。</p><p>重新打上马赛克！</p><p>杨帝眼球停止住震颤，嘴角扯出笑。</p><p>凭空获得大量神秘学知识后，他对不可名状之物“希夷”的性质，似乎有了直指本质的洞见。</p><p>这种寄宿于图片中的存在，目的似乎是汲取人的精神。</p><p>人的精神被“汲取”，也就是受到“损伤”。</p><p>精神损伤，杨帝就会被提示“精神+n”。</p><p>杨帝破碎的认知皮层自发组织起对话逻辑：“神交是双向的。希夷，你在侵蚀我精神时，也被我逆向侵染了。你为何要吞噬他人之精神？”</p><p>它说话了……可能是在说话。</p><p>“嗷呜呜哇啊……”</p><p>声音如同从遥远的宇宙传来，模糊不清，毫无逻辑可言。</p><p>无数几何状声波刺破寂静。</p><p>希夷作出的“回答”，如同被碎纸机处理过的百科全书，话语像是被风撕裂的纸片。</p><p>杨帝却能感受到，这混乱的声音背后，似乎正逐渐凝聚出某种逻辑的雏形。</p><p>「精神+1+1+2+3+5+8」</p><p>「神秘学+1+1+2+3+5」</p><p>竟然又加了很多“精神”和“神秘学”。</p><p>很显然，希夷也在尝试和杨帝神交。</p><p>但每次神交，都会吞噬杨帝一部分精神；杨帝则反过来，能获取神秘学知识作为回报。</p><p>但同时，因为杨帝能“超量代偿损伤”，所以对他来说，而是同时获得精神和神秘学知识，没有任何损失。</p><p>赢两次，就是双赢！</p><p>“也罢。就算你还没能组织起完整的逻辑，来回答我为何要汲取我的精神……我还是允许你留在我的脑子里了。”</p><p>杨帝郑重地对“希夷”去留发表重大决议。</p><p>一个东西藏在他的精神里，既能够高效刷数值，还几乎没什么代价，何乐不为？</p><p>和这玩意共存也不是不行……</p><p>杨帝开始整理思维中凭空多出来的神秘学知识，这都是希夷灌进他脑子里的。</p><p>“意大利面要拌42号混凝土能够供奉飞天意面之神……什么乱七八糟的？”</p><p>“对移动迷宫使用量子波动速读？这读的不是书，是玄学。”</p><p>他必须不断在意识中给这些信息打上“可能有用”、“无效”、“存疑”、“精神病院特供”等各种标签。</p><p>直到某个漩涡状符号，突然在记忆褶皱里亮起。</p><p>这个漩涡，三条扭曲的弧线组成，看起来很眼熟。</p><p>“这是什么？”</p><p>“耶罗……大仙……信物……”</p><p>“一个叫耶罗的仙人的信物？”杨帝咀嚼着这几个突兀清晰的词组，脑海自动组词造句。</p><p>但他印象中，好像没听说过古今中外神话里有叫作“耶罗”的仙神。</p><p>希夷罹患抑郁症似的，突然安静了下来，没有再说更多，也许是连它自己也不知道。</p><p>杨帝掏出一直揣在身上的漩涡图纹铁饼，或者现在应该改名为耶罗大仙信物。</p><p>当时在“池梦”中，他从一处喷泉口取走这块铁饼。</p><p>然后水位快速上升。</p><p>梦境崩塌后，泳池水、地板、墙壁全都消失了。</p><p>唯独他手中这块“铁饼信物”仍然存在。</p><p>这么说来，耶罗大仙信物应该是不属于“梦”里的东西。</p><p>至少，一定是件更特殊的东西。</p><p>“希夷小朋友，那我问你。”</p><p>“嗷……”</p><p>“这块耶罗铁饼有什么作用？”</p><p>不可名状的希夷像是卡壳了一下，信号不良似的颤抖起来。</p><p>“非金非玉，其色幽昧……命运细语，深渊低吟……执之者厄难随影，昼夜不息，无有断绝……梦魇萦绕，白日亦昏，终至寿终……”</p><p>它神叨叨念着。</p><p>杨帝越听着，愈发惊恐，他居然听明白了对方在说什么。</p><p>他正站在一个前所未有的生死边缘。</p><p>“希夷，你是说……这块铁饼，或者说耶罗大仙的信物，它会给人带来无尽的厄运，直至死亡？”</p><p>希夷的回答如同风中残烛，断断续续，却又异常清晰：“……执此信物者，必受其诅咒……命运之锁，无人能解……”</p><p>完犊子，路边的东西果然不能乱捡。</p><p>“希夷，你既然能与我交流，能否告诉我，如何解除这信物的诅咒？”</p><p>“……命运既定……唯有……唯有……”</p><p>“唯有什么？”</p><p>“耶罗大仙……耶罗……耶罗……耶罗……耶罗……耶罗……”</p><p>卡壳到最后，希夷还是给不出解决方法，只能不断重复“耶罗大仙”。</p><p>它像婴孩般支支吾吾，话语支离破碎，逻辑稀烂残缺，词句五零四散。</p><p>而且，它似乎是真不知道怎么摆脱“耶罗大仙的诅咒”。</p>
