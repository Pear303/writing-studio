# 学术大手子

<p>“原初之眼？我研究方向不是这个。”</p><p>伊芙坐在歪脖子树树桩上，法杖杵在一边。</p><p>她托着下巴：“起因是这样的——我在做一个课题，研究史莱姆的社会形式。你们可知？史莱姆看似是一种低等生物，却有令人惊叹的群体行为模式和潜在的社会结构。”</p><p>瑞弗维尔困惑：“研究史莱姆，为何要跑来末日火山？”</p><p>精灵伊芙指间撩动发丝，陷入回忆。</p><p>“是圣树，母亲圣树指引我来此地……本姑娘一开始还很怀疑，这鬼地方有什么可研究的。但现在看来，圣树一如既往的正确——我遇到了你们两个。”</p><p>伊芙站起身来，拍了拍身上并不存在的灰尘，眼神中透露出一丝兴奋。</p><p>“刚刚在火山内部，我发现了一些不得了的东西——我杀死的那个冒牌货卡利斯托，竟然是由熔岩史莱姆组成的！”</p><p>杨帝和瑞弗维尔闻言，皆是一愣。</p><p>“由熔岩史莱姆组成？这怎么可能？”</p><p>瑞弗维尔忍不住问道。</p><p>伊芙得意地扬了扬下巴，说道：</p><p>“一开始我也难以置信，但事实就是如此。</p><p>“熔岩史莱姆以一种极其精妙的方式，组合在一起，模拟出卡利斯托的形态和力量。</p><p>“它们彼此之间存在联系，能够协同行动，形成一个具有强大战斗力的个体。”</p><p>一群最低等的魔物。</p><p>模拟成了这片大陆最强生物——焚灭天空之龙·卡利斯托的模样。</p><p>虽然实际属性不到“原版”的十分之一。</p><p>但仍然令人困惑——它们是如何自发合体、拟态的？</p><p>瑞弗维尔捏着下巴：“这并不是自然现象。”</p><p>伊芙眯着眼看向他：“小弟弟有何高见？”</p><p>他说：“我从圣古琉斯王城开始，一路上被圣光教廷的人追杀，但他们吃亏十几次后，没有再在半路上对我下手，而是……任由我进入末日火山，瓮中捉鳖。”</p><p>伊芙：“你们是‘鳖’，那个冒牌卡利斯托是‘捉鳖的’？”</p><p>瑞弗维尔点点头：“没错。我认为，熔岩史莱姆模拟卡利斯托，并不是自发的，因为过去我们从没有观测到‘史莱姆模拟其他生物’的案例。”</p><p>“你怀疑与圣光教廷有关？”</p><p>“就是这个意思。”</p><p>杨帝在一旁看着。</p><p>异世界学术大拿之间的对话，他作为地球人，完全是个局外人。</p><p>身着青绿色披风的杨帝，悄悄挪动脚步。</p><p>“你是叫杨帝？想去哪？”</p><p>他轻车熟路地举手投降：“末日火山山脚，那个废弃旅游景点的入口，我衣服都在那儿。”</p><p>伊芙让他快去快回，转头继续和瑞弗维尔聊起来。</p><p>杨帝回到山洞入口。自己的背包、瑞弗维尔的行囊，确实都还放在“灵能轿厢”上。</p><p>在地球准备跳入黑水潭子之前，杨帝也带了很多居家旅行必备之物，换洗的衣服裤子，风油精万花油双飞人，还有五双拖鞋。</p><p>包括地球带来的镜子碎片，还有那一小团被折腾得死去活来的熔岩史莱姆，也都在这包里。</p><p>杨帝换上干衣服，一双完整的拖鞋。</p><p>他回到那片遍地焦土、沟壑、坑洼的战场，在老歪脖子树树边上，看见伊芙和瑞弗维尔交谈甚欢。</p><p>“你知道嘛，现任国王是秃头。”</p><p>“秃头国王，嚯嚯哈哈哈哈哈！”</p><p>“我们昨天吃的鱼没有调味料。”</p><p>“没腌过的鱼？嚯嚯哈哈哈哈！”</p><p>他们的笑点很奇异地撞一块了，这让地球青年杨帝愈发感觉，自己和二人格格不入。</p><p>杨帝把行囊丢过去：“瑞弗维尔。”</p><p>瑞弗维尔接住，和杨帝傻乎乎地笑笑道谢，然后继续和伊芙讲完全听不出笑点的笑话。真是个见色忘友的家伙。</p><p>伊芙拍拍手，跳下树桩，捡起用黑色天鹅绒包起来的雕塑，收进自己口袋里。</p><p>她拍案（拍腿）说：“就这么决定了，我们要去星渊井口。”</p><p>瑞弗维尔的笑声戛然而止。</p><p>杨帝也转头看向伊芙：“星渊井口？那个巴德杀死卡利斯托的地方？”</p><p>“伊芙，你不是说你研究方向不是神话传说，而是史莱姆。”</p><p>“没错，我就是要去星渊井口。你不是说，那里也有圣光教廷的布局嘛，我去撬开他们的嘴，获取关于史莱姆的‘一手资料’。”</p><p>伊芙舔了舔唇，眼中闪出兴奋的光。</p><p>瑞弗维尔有些畏惧地退了退。</p><p>杨帝：“您确定这不是学术剽窃……”</p><p>精灵生气(｀⌒´メ)瞪了他一眼，杨帝耸耸肩。</p><p>她招呼众人打扫战场，收拾行囊，一边解释到：“圣光教廷——他们竟然能利用‘熔岩史莱姆’，拟态出一条巨龙，想必他们对史莱姆社会学的研究也颇为深刻。”</p><p>她踢了踢地上半个残破的圣骑士头盔：“只可惜……火山里那群修士像疯了一样，我只能把他们送去见创世神了。这里几个教廷术士，又被你该死的原初之眼雕像蛊惑，揉成一大团奇行种。一个活口都没给我留……”</p><p>瑞弗维尔小声道：“他们要杀我……我也不知道滥用这雕像，后果会如此严重……”</p><p>伊芙摇摇头：“不，你没明白我意思。一般人即使灵感属性很高，直视原目雕像，也只是会头晕、眼花、呕吐、腹泻、胀气、恶心、反胃、消化不良，并不会受影响很深，更不会直接让身体扭曲成一团。只有虔诚的狂热信徒，才能让被放逐到虚境的神灵影响到现实……”</p><p>瑞弗维尔瞪大眼珠子：“你是说……”</p><p>“没错，这几个教廷术士，包括红衣主教，都是‘原初之眼’的狂热信徒。”</p><p>杨帝旁听到此言，心中一动。</p><p>心胜于物……狂信徒……相信的心就是你的魔法，魔女诚不欺我。</p><p>就像陈昭一样，狂信徒更容易让他们的所信奉之物，影响这世间。</p><p>从钓鱼佬的控制变量实验也得知，在内心“相信”情绪狂热的情况下，穿越黑水潭子更容易成功。</p><p>这也就能解释，为何瑞弗维尔和杨帝目睹了雕像也没事，而那些教廷追兵，受影响却如此之大。</p><p>信徒与非信徒之间，对现实的扭曲能力也是不同的。</p><p>瑞弗维尔咽了口唾沫：“难道……整个圣光教廷，都已经堕落成原初之眼的爪牙了？”</p><p>很可能。伊芙沉重地点点头。</p><p>“不过我已将消息传回到圣树那边了，现在我们可以心无旁骛地进行学术研究。”她很快表情又舒展开来，如此说道。</p><p>姐们，这不是学术研究的时候吧？</p><p>不过现在，线索都串起来了。</p><p>在王城的地下隧道里，第九红衣主教胡伯特·布莱恩·沃尔夫施莱格尔施坦因豪森贝格多夫，自称是“光明圣教-原目会”。</p><p>“原目”，指的就是原初之眼。</p><p>瑞弗维尔感觉呼吸都变得急促起来：“不……我得赶紧回圣古琉斯王城，去警告国王，教廷已经向某种亵渎黑暗的势力妥协堕落……”</p><p>伊芙拦住了他。</p><p>“你现在回去只是打草惊蛇。”</p><p>“不行，这是国王派给我的密令……”</p><p>精灵有点恼：“大傻春，如果给你委派秘密任务，只是国王和教廷合演的一场戏呢？”</p><p>瑞弗维尔坚决否定：“不会的，在地下隧道被第九席红衣主教袭击时，他的话语暗示教廷和国王无关……”</p><p>伊芙扶额：“别人说什么你就信什么，把你丢进冒险小说里，你一章都活不过！”</p>
