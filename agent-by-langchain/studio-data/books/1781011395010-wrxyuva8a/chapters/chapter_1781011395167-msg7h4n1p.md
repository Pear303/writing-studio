# 归墟帝霸阁

<p>“此乃灵茶山。”归墟大帝介绍。</p><p>阿巴对青丘白璃低声吐槽：“要说这是茶，那我的鳞片都能当茶叶泡着喝。”</p><p>鱼腥草煲汤确实挺不错。</p><p>狐种大妖摇摇头：“并不是，灵茶山不是‘茶山’……我好像想起什么了。”</p><p>大帝行走于天空，负手而行，说道：“灵茶山不是茶山，而只是单纯地名字叫‘灵茶山’。”</p><p>大帝踱步至悬崖边缘，袖袍被山风掀起。</p><p>他屈指弹向脚下蒸腾的黑雾，刹那间，整座山峰剧烈震颤，无数金色符文自山体深处浮现，勾勒出一柄巨斧的轮廓。</p><p>“千万年前，天地混沌如卵，先天神尊以‘灵茶山乂斧’开天辟地。</p><p>“看到山涧的黑潭了？那是从天道裂隙渗出的大量‘虚无本源’所化。</p><p>“神尊开天时，斧刃曾撕裂宇宙，虚无本源渗出，顺斧柄滴落于此行星，汇聚成‘归墟’。”</p><p>杨帝摩挲着下巴。</p><p>听着有点像地球上的盘古开天地。</p><p>但细节有些不同，听起来更像玄幻小说的内容。</p><p>而在一旁，青丘白璃瞳孔骤缩。</p><p>“我……我想起来了。方才归墟大帝开辟空间裂缝，他手中的那把斧头，就是……就是……就是——灵茶山乂斧……”</p><p>归墟大帝转身，似笑非笑地瞥向青丘白璃，又把目光转回向杨帝。</p><p>他神秘的说话。</p><p>“白杨大帝，本座用灵界的山川舆图与势力分布，作为礼物，终于将你请来‘灵界’了。在此地，我们才能更好的说话交流啊。”</p><p>归墟大帝负手立于云阶之上，周身星辉与灵界的青芒交织，看似随意的站姿却暗含道韵。</p><p>将此地作为主场的掌控欲，昭然若揭！</p><p>「坏事，归墟大帝‘咄咄逼人’的可能性从32.09%，上升至78.59%，大幅上涨，比任何一个牛市的增长率更凶猛。」59改发出担忧的旁白音。</p><p>但他随即安慰众人道：</p><p>「不过也不用太过担心，杨帝阁下和归墟大帝直接撕破脸、立刻爆发冲突的可能性，仍然只有约0.01%。」</p><p>0.01%直接撕破脸的概率，要是他们碰上，可以明天组团去买彩票。</p><p>归墟大帝抬手轻挥，一道流光将阿巴、青丘白璃连同59改瞬间包裹。</p><p>大帝指尖一弹，将他们弹飞到数千里外。</p><p>“白杨大帝的同伴，还有青丘白璃，不妨先去灵界别处游览，暂时不要打扰我俩。”</p><p>他话音未落，三人身影已消失在云雾之中，只留下惊呼声在山涧回荡。</p><p>杨帝瞳孔微缩，周身灵力悄然运转。</p><p>他感受到了，归墟大帝周身气息陡然转变。</p><p>原本和煦如春风的灵压，瞬间化作实质化的滔天巨浪。</p><p>身上的衣袍无风自动，猎猎作响。一股足以毁天灭地的气势，自他体内迸发而出。</p><p>“终于暴露出真面目了么，堕入魔道的归墟大帝。”</p><p>“我？魔道？你才是魔道。”</p><p>空气扭曲变形，杨帝脚下的地面如同沸腾的沥青般翻涌。</p><p>黑色雾气顺着脚踝缠绕而上，所过之处，皮肤泛起阵阵灼痛——是归墟大帝的攻击手段。</p><p>而归墟大帝，他手持一柄非金非玉的斧。</p><p>“方才青丘白璃猜得不错，这正是‘灵茶山乂斧’，不过并不算‘完全体’，只能算是仿品。</p><p>“原品能够劈开灵界的天地。但即使我手中的是仿品，也有原品大约百分之一二的威能，这个力量足以劈碎凡界的时空。</p><p>“因为青丘小狐狸太碎嘴，若是留在原地，只会暴露出更多关于这把创世之斧的情报，所以先送到别处了。</p><p>“毕竟接下来的战斗，不是你死便是我活，狮子搏兔，亦要用全力！”</p><p>归墟大帝一手执斧，一手结印。</p><p>“领域展开，归墟帝霸阁。”</p><p>领域内的空间疯狂扭曲，杨帝脚下的地面化作沸腾的黑潭，沸腾如墨的黑水将他淹没，不知所措。</p><p>短暂黑暗过后，眼前景象骤变。</p><p>浓稠的黑雾如活物般翻涌重组，眨眼间化作一座巍峨的阁楼。</p><p>楼阁通体由漆黑如墨的晶石构筑，表面流转着细密的金色符文，每一道符文都仿佛蕴含着开天辟地的伟力。</p><p>杨帝此刻就站在这座名为“归墟帝霸阁”的领域核心——楼阁内部的最底层。</p><p>刚落地，便感觉仿佛陷入亿万年的深海淤泥之中。</p><p>无形的重压从四面八方汹涌而至，不仅是物理上的沉重，还有时空本身的无形凝滞与排斥！</p><p>空气粘稠得如同液态金属，每次呼吸都像元婴期弱者在吞咽铅块。</p><p>元婴弱者吞铅块是什么感受？</p><p>大概相当于凡人在回南天时期的两广地区蒸桑拿，呼吸一口，肺里全是水。</p><p>杨帝试着调动肌肉力量。</p><p>然而，血液运转速度竟变得异常迟滞，仿佛经脉被灌满了冷却的岩浆。</p><p>最直观的感受是速度——他尝试性地全力挥出一拳，那足以在凡界撕裂空间的力量，在这里仅仅带起一阵沉闷的音爆。</p><p>拳锋所过之处，空气仅仅炸出两朵音爆云，其速度被硬生生压制到连三倍音速都不如！</p><p>“好霸道的领域！”杨帝心中凛然，这“归墟帝霸阁”的时空阻力远超想象。</p><p>阁楼那扇巨大厚重，同样铭刻着无数符文的漆黑大门，正缓缓向内敞开。</p><p>门外，是翻腾不息、犹如活物的黑雾领域背景。</p><p>一股陈旧而压抑的气息扑面而来。</p><p>杨帝敏锐地察觉到，这股气息中混杂着虚无本源的冰冷与血腥的杀戮气息。</p><p>归墟大帝的身影，就那样从容不迫地悬浮在门外半空。</p><p>他脸上那似笑非笑的神情早已消失，取而代之的是掌控一切的冰冷漠然。</p><p>归墟大帝踏着虚空，缓步步入阁楼。</p><p>手中的“灵茶山乂斧”轻轻一挥，原本紧闭的阁楼大门轰然合并。</p><p>砰砰——！！</p><p>对方并未急于进攻，而首先是以一种俯瞰的姿态，像个性转阿飘，缓缓飘入阁楼大门内。</p><p>“感觉如何，白杨大帝？”归墟大帝的声音在空旷而压抑的阁楼底层回荡。</p><p>还没等杨帝想好词儿回答。</p><p>归墟大帝自顾自接着说：“此地乃本座道韵所化，时空法则由我而定。你的速度，力量……甚至你的思维，都将在此地寸步难行。”</p><p>归墟大帝站在远处，但又似乎站得很近。</p><p>他的声音从四面八方传来：“开天辟地的神尊暂时不在，但祂的斧，我已继承百分之一二。白杨大帝，你说，来自异界的你能承受几分？”</p><p>他缓缓举起手中的灵茶山乂斧仿品，斧刃遥遥指向杨帝。</p><p>一股仿佛能劈开万古、终结一切的恐怖锋芒瞬间锁定了他。</p><p>无处不在的时空阻力中，又平添了刺骨的锐利切割感。</p><p>随即，巨斧轰然劈下。</p>
