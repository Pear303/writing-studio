# 超限法师

<p>伊芙的敏锐远超杨帝想象。</p><p>仅凭一些细微的迹象，似乎就察觉到，他并非这个世界的人。</p><p>但在这精灵面前，杨帝想跑也跑不掉。</p><p>他也只能凭借对神经和肌肉的强大操控力，像祖国人一样绷出微笑，淡定地说：“谢谢夸奖，看来失忆还能让人的气质也发生大变。”</p><p>“你不想说就算了。其实这片大陆，隔三差五就会有些‘突然出现’的家伙，逢人便去问奇变偶不变、天王盖地虎之类的奇怪话。我活了这么久，也见怪不怪啦。。”</p><p>伊芙看起来有些遗憾。</p><p>难不成，穿越者只是正常现象？</p><p>“不过，我也不讨厌你。说吧，在瑞弗的帮助下，关于灵能法术，你都‘回忆’起了什么？”</p><p>伊芙又恢复了笑嘻嘻的表情，看起来人畜无害。</p><p>提到“回忆”这个词的时候，她双手齐上阵，各自竖起食指和中指，在脑袋两侧比划出大大的“双引号”。</p><p>杨帝把瑞弗维尔说过的，又简略复述一遍。</p><p>环境中的“灵能”是干柴堆，术士可以用特定手法点燃，这种手法就是“法术”。</p><p>所以，“法术”相当于一根火柴、一道闪电、一阵来得恰到好处的风。</p><p>伊芙曰：“这种理解虽然初级，但已经足够了。所以，你有没有从中把握住‘灵能法术’的精髓所在？”</p><p>“嗯……顺应自然？”</p><p>伊芙微微眯起眼睛，神色变得认真起来，“非常对。所谓灵能法术的精髓，就是依靠物质自身的能动性，来改造世界的方法。”</p><p>并非是强行去改变物质，而是引导物质，按照其自身潜在的能动性，发生变化。</p><p>法术其实很难的。</p><p>光从过程上看，就像是一阵狂风在乱石丘陵上肆虐，恰到好处用丘陵里散落的物质，组合成一块机械手表。</p><p>法师的精神就是那阵“风”，只要稍有偏差，就可能导致法术的失败。</p><p>所以，异世界人民发明出“咏唱”。</p><p>咏唱，是驾驭“精神之风”的手段。</p><p>“咏唱的原理，其实是通过言语对自己下暗示，从而改变思维的流动模式。你知道，精神有强大的力量，当我们咏唱特定咒语时，其实是在调整自己精神的频率和节奏，让思维以一种特殊的方式流动。”</p><p>并非“言语”本身具有力量。</p><p>而是被言语干涉的精神，再通过精神去控制个人现实，才会体现出力量。</p><p>杨帝：“那么‘灵能’是什么？”</p><p>伊芙道：灵能/灵，是表征物质中“现实含量丰度”的内禀属性。</p><p>灵能流动的形状决定物质的功能，顺序方向规定现实的因果。</p><p>“现实丰度/灵能”分为主体与客体两个部分，每个人都有各自的“个人现实”，那就是魔法的源泉。</p><p>你记住就行，我不是这个专业方向的，所以我也不太懂。</p><p>她微笑：“总之现在你已经明白灵能、法术的基本原理了，来和我手搓九环法术吧！”</p><p>杨帝在伊芙调教下，开始了残酷训练。</p><p>精灵把上千种1~3环法术，都给地球人扫了遍盲，收获颇丰。</p><p>瑞弗维尔则坐在一侧的残垣上。</p><p>他只看见一大堆眼花缭乱的声光效果。</p><p>上一个法术示范完，不到三秒又轮到下一个——这怎么可能让人记得住啊喂！</p><p>精灵又一发超高度的三环法术，第不知几百次血虐完杨帝，第一阶段学习暂时结束了。</p><p>1~3环法术，比较常用的基本都示范完毕。</p><p>而杨帝，也不出所料全部记住了。</p><p>他剩下所需的，只是练习/做题！而“做题”这一过程，80%都可以在梦中进行。</p><p>当然，用他的话来说肯定不是“我终于学会灵能法术了”，而是“我终于回忆起来这法术怎么放了”。这就是叙事的技巧。</p><p>伊芙轻轻拍拍杨帝肩膀，目光中带着几分赞许与审视。</p><p>“不得不说，你魔法天赋……呸，你‘以前’的魔法造诣当真很高。能够默声瞬发法术，虽然只是1~3环，但这也不是一般人能够做到的。”</p><p>她话锋一转。</p><p>“美中不足，你本身所蕴含的灵能太少。人的灵能水平是大厦基石，若是基石不稳，即便拥有再精妙的建筑技巧，也难以建起高耸入云的魔法之塔。所以，你必须锻炼锻炼。”</p><p>说到“锻炼”，杨帝就不困了。但他也是第一次知道——人的“灵”，也是能锻炼壮大的？</p><p>“灵”是表征现实丰度的属性。这种概念比“精神”还要抽象。</p><p>杨帝的“灵”被耶罗大仙撕裂过。</p><p>如果是地球上环境的灵是100，那么异世界大约是500。</p><p>瑞弗维尔，五环级别，约1500灵。</p><p>精灵伊芙，她是真正的数值怪……杨帝看不懂，但至少是瑞弗维尔的10倍。</p><p>15000，只是他对伊芙估计值的下限。真实值，只能高不会低。</p><p>相应的，杨帝只有15……果然还是少的离谱了，真不知道自己怎么活着的。</p><p>“我会教你两种锻炼‘灵容量’的方法，届时你自己选取更有效的一种。现在，让我们先看看第一种。”</p><p>伊芙看了眼手腕上类似手表的东西。</p><p>她对瑞弗维尔大喊：“喂——时候已经不早了。再走50公里，我们就生火扎营。”</p><p>瑞弗维尔呜咽：“不是姐们，五十千米？”</p><p>伊芙摇摇手指：“不需要你动腿走。这是针对杨帝的试炼。我们负责坐在轿厢中，杨帝负责驱动。”</p><p>说着，她轻挥法杖，灵能轿厢出现在众人面前。</p><p>“等等……这轿厢看起来如此眼熟……”</p><p>“是我们在末日火山里坐过的那辆。”</p><p>“矮人工艺轿厢？何时带过来的……”</p><p>瑞弗维尔啧啧称奇。</p><p>伊芙一路上，至少外表看起来是轻装上阵，没想到居然有袖里乾坤、须弥纳戒之奇术，将行李藏在一个不知道在哪的地方，需要的时候再拿出来。</p><p>杨帝也用询问的眼光看向她。</p><p>精灵两手一摊：“别想了，这是九环级别的附魔「风王结界」，最大用处是用来藏拙，还有放行李。”</p><p>九环！法术的“环数”增加，难度不是简单的线性递增，至少是指数型爆炸。</p><p>1~3环，4~6环，7~9环，三个阶段的难度都在指数暴增。</p><p>瑞弗维尔懂得七八十个1~3环法术，而4~6环就只会四五个了。</p><p>杨帝：“伊芙女士，斗胆问一句——到现在为止，我们只知道您的名字，但不知道您是何方神圣。”</p><p>伊芙悲伤：“我这么不出名？我上次出来，也才只是一百年前的事而已。”</p><p>一百多年，火能烧断七把锁，狗能舔完十碗面，已经是很漫长的岁月啦。</p><p>她目光变得深邃，仿佛又回到往昔峥嵘。</p><p>“我曾见过你们人类绝对无法置信的事物……我曾目睹，末日火山上卡利斯托的拥趸如岩浆涌动，烈焰与熔岩在他们脚下翻滚，炽热火光照亮整个黑暗天际……”</p><p>怎么诸天万界都喜欢银翼杀手。</p><p>瑞弗维尔已经惊得下巴砸穿地心：“您……伊芙芙你，你参加过100年前讨伐卡利斯托的大决战？”</p><p>“没错，现在回想起来，仿佛只是短短一个世纪前的事情。”</p><p>她抠了抠耳朵，继续说道，“那时我连3环术士资格证都还没考。哦，现在也还没去考。你问我现在几环？大概是10环吧。别催我，我真的不想考试。”</p>
