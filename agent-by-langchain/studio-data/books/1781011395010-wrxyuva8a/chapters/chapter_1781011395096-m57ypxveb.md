# 主体溶解

<p>“好……”杨帝从卡着刀刃的喉咙挤出一个字，努力睁开被强光刺痛的双眼。</p><p>眼前一片模糊，只能隐约看到伊芙的身影。</p><p>伊芙紧接着发问：“你眼前浮现的第一个画面是什么？”</p><p>杨帝看见各种色彩和光影交织在一起。</p><p>“一片五彩……十彩斑斓。不过事先说明，我能看见很多额外的颜色。”他如实回答。</p><p>“此时是夜晚，你身处一片寒冷的沙漠，这时你面前有一只垂死的骆驼。”</p><p>“我倚靠着骆驼一起睡觉，睡前若有精力，再给它唱一首《沙漠骆驼》。”</p><p>“骆驼在你怀里死去，你看着它的眼睛。”</p><p>“什么鬼魅传说，什么魑魅魍魉妖魔～只有那鹭鹰在幽幽的高歌……”</p><p>“别唱歌，回答我。”</p><p>“……我有些伤感，但接下来，我还是会用它的尸体和皮毛挡风、保暖。”</p><p>其实杨帝什么感觉都没有。</p><p>只是理性告诉他，在那些情况下，应该表现出怎样的感情。</p><p>“沙漠的尽头出现了一座繁华的城市，灯火辉煌，可你走近后发现，那只是海市蜃楼。”</p><p>“我会非常失望，而且有些愤怒。”</p><p>尽管杨帝眼前强光刺眼，视线模糊，但仍能感觉到那审视的目光。</p><p>“一只沙漠蜜蜂趴在了你手臂上。”</p><p>“我晃晃手臂，把它赶走。”</p><p>……</p><p>移情测试结束了。</p><p>幸好杨帝提前看过几十遍银翼杀手，深谙“移情测试”的套路，不然，伊芙一眼就能看出来他不是人！</p><p>到时大威天龙，一个九环法术，就杨帝在10毫秒内轰杀至等离子气，将每一团分子和原子均匀扩散到整个异世界的大气层（如果这片大陆存在类似大气层的构造），那时，或许他来不及进化适应。</p><p>伊芙收起手中散发强光的光球，短刀也抽出杨帝脖子，擦干，收入鞘。</p><p>瑞弗维尔赶忙走上前，一个治疗法术拍在杨帝身上：“兄弟还好？”</p><p>“噗，还行，脖子噗，有点漏风罢了。”</p><p>杨帝此刻状态和《西游降魔篇》的喷血哥一样。值得一提的是，那位喷血哥名叫杨迪。</p><p>瑞弗维尔不太清楚现状。</p><p>方才，伊芙突然把短刀捅进某人脖子，他哪见过这种阵仗？</p><p>不过还好，杨帝看起来没有生命危险，也就是吐吐血。</p><p>“噗，伊芙，我，噗，怎么回事？”他一边吐血一边问。</p><p>精灵说：“已经没事了。你的思考模式与情感反应还维持在正常范畴，并没有‘主体溶解’太深。”</p><p>在听到“主体溶解”这个四字词语之时，杨帝瞳孔骤然收缩。</p><p>——没错，他之前的状态，就好像消融在了世间万物之中，分不出自己和外物。</p><p>类似于庄周梦蝶，蝶梦庄周。</p><p>那时候，杨帝也分不清自己是杨帝，是苇草，或是蟋蟀。</p><p>他仿佛与周围的万物融合一体，回归到最原始的混沌状态，没有主客体之分。</p><p>瑞弗维尔站在一旁，显得像个局外人：“伊娃……到底什么是主体溶解？杨帝他溶了？”</p><p>“可以这么说——他几乎溶解要在周围的庞大现实之中。”</p><p>伊芙瞥了瑞弗一眼，又看向杨帝。</p><p>“杨帝，你体内的现实丰度实在低得可怕，就像被某种‘外力’撕扯过。”</p><p>杨帝：“也许这就是我失忆的原因吧。”</p><p>精灵伊芙：“真相怎么样，只有天知道。现实丰度极低的结果就是——外界的‘灵’融入你体内，稀释了原本属于你的现实。”</p><p>“我被稀释……溶解了？”</p><p>“打比方说，每个人就像一缸染料，如果注入太多外界的清水，就会被大幅度稀释。”</p><p>杨帝心中微微一凉：“那岂不是说，冥想是有上限天花板的。”</p><p>不断冥想，外界就会不断“污染”他。</p><p>“并不，这些‘清水’是可以消化的。你只是一次性吸收了太多灵能，所以‘消化不良’。”</p><p>他安心了下来。</p><p>自己的体质并不害怕致死性伤害，唯独恐惧他引以为豪的「理性」被彻底破坏。</p><p>杨帝又问：“那么，我一次冥想所能‘吸收’的灵能，极限在哪？”</p><p>伊芙摸着下巴思索：“啧，这也是个很深奥的问题，我研究的不是这方面……我只能记住那个大致的分界——我们的学者测算出来，一次性从外界汲取的灵能，不能超过总量的56.68%，出于保险起见，你应该把55%，或者百分之五十，作为警戒线。”</p><p>比方说，原本杨帝是15灵。</p><p>那么在冥想一次中，从外界新吸收的灵能也不应该超过15灵。</p><p>自身的灵能水平，在一次冥想过后，最好只翻一倍，这是最保险的。</p><p>否则，主客体的边界会被大幅模糊。</p><p>他会很容易迷失自我。</p><p>伊芙把刀子扔回给图书馆馆长，使唤道：“瑞弗维尔，守门，不要让夜魅进来。”</p><p>“哦，哦……”</p><p>他真成橘外人了，现在只能拿短刀去守门，留下二人共处一室。</p><p>伊芙把法杖横在空中，坐在杖上。</p><p>她翘起二郎腿，掏出笔记本：“冥想过程中的‘主体溶解’现象，原本只存在于理论中，今天还是我第一次见到。”</p><p>“罕见吗？我第一次冥想就撞上了诶。”</p><p>“非常罕见，至少在我们精灵氏族中，从来没有过这样的案例。但你不同，杨帝，你身上恰好满足两大条件。”</p><p>其一，原本自身的现实丰度极其弱小。</p><p>第二，精神力深不见底，可以长时间维持冥想状态。</p><p>正常人不会冥想两下就把自己搞死，也就杨帝体质特殊，把这两项苛刻的条件都达成了。</p><p>“然后，你就差点爆缸了。”她笑道。</p><p>杨帝理解了：“好吧……那换句话来说，只要我的灵能水平不断进步，‘主体溶解’现象就会越来越少发生？”</p><p>“理论上没错。”</p><p>“理论上？”</p><p>伊芙一边在某种视野下观测杨帝，一边用笔在本子上写着什么，语气带上稍许遗憾：“理论可以，实际很难！因为完全消化从外界取得的‘灵能’，需要时间，很多很多时间！”</p><p>“具体多少时间？”</p><p>“假设当下这一刻，你体内的灵能为30灵，其中包括刚刚从外界汲取的15灵，那么你大概需要……三个月来转化完全。否则你只是徒劳的提升灵能总量，但没有提升灵能的容量上限。”</p><p>杨帝心一沉——平均一天0.1667灵。</p><p>这得到猴年马月，才可以让灵能练到足够毁天灭地、不可名状的水平。</p><p>将灵能水平提升到和伊芙一样的15000灵以上，需要至少……九万天，合246年。</p><p>这是最理想情况下。</p>
