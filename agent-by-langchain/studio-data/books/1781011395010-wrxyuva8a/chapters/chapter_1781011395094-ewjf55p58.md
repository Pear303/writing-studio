# 手动入睡

<p>……</p><p>夜更深了，黑暗如墨般浓稠。</p><p>伊芙和瑞弗维尔坐在篝火旁守夜，火焰微光在他们脸上跳跃，映出二人轮廓。</p><p>四周静谧得有些诡异，唯有偶尔传来的夜魅尖啸打破这份宁静。</p><p>夜魅袭来，紧接着便是利刃划破空气、砍翻夜魅的声响。</p><p>“好刀！”伊芙收刀坐下，动作干净利落。</p><p>她轻轻抚摸着那把刚刚砍翻了二十来只夜魅、却依旧锋利如初的刀刃。</p><p>其实这种品质的刀，在精灵氏族的地摊上可以批发购入，Made By Quendi这名头特别响。</p><p>精灵生产的器具品质很高，缺点是产量少，这一点和跑步迈入工业社会的矮人氏族相比，恰好情况相反。</p><p>伊芙只是觉得，瑞弗维尔的短刀挺顺眼罢。</p><p>瑞弗维尔赞同：“我也喜欢这把刀子。”</p><p>“它缺点是太容易钝了。”</p><p>“没事，我最喜欢这把刀子之前，就已经了解了它全部缺点和优点。”</p><p>她把短刀还给瑞弗维尔：“瑞弗，这刀上有两个符号‘RL’，是什么意思呢？”</p><p>瑞弗维尔接过刀，娓娓道来：“其实，我姓兰斯洛特Lancelot，征着高尚品德和对知识的忠诚守护。R.L.就是我全名Reviver Lancelot 的简写……”</p><p>“很古老的姓氏哦，我妈妈年轻时见过。”</p><p>“话说伊娃，你怎么姓‘柑橘’？有点奇怪诶。”</p><p>“用水果描述一个人，果然有些奇怪吗……我们精灵都有体香，姓氏是根据这气味类型当场起的。尤其是我们的圣树，它也是柑橘气味的。”</p><p>“那岂不是说……”</p><p>“你猜对了，据说远古时期有些精灵的姓氏是香蕉、狐狸、霸王花。”</p><p>“天啊，他们一定闻起来很可怕……”</p><p>瑞弗维尔夸张地瞪大眼睛，惹得伊芙不禁“噗嗤”一声笑出来。</p><p>“伊芙，那你爸妈也是柑橘味的吗？”</p><p>“爸妈？我们没有爸妈，精灵都是‘圣树’生出来的。”</p><p>“圣树？很有名诶，给我讲讲它的历史。”</p><p>“传说，四万年前，天地间诞生了第一个‘先天精灵’。先天精灵将自己随身携带的木棍插到地上，就变成了圣树……”</p><p>伊芙还没介绍完圣树，又有两三只夜魅从天边呼啸而来。</p><p>尖锐叫声打破短暂的轻松氛围。</p><p>伊芙·柑橘抓起法杖，坐直身体，对着天空一划，那几只夜魅当场解体分尸，化作一团团黑烟消散在空中。</p><p>她将法杖杵到一边，抱着膝盖，扭头看向瑞弗维尔，没头没脑地问道：“如果有一天我改姓成‘榴莲’，你又会怎么办呢，瑞弗。”</p><p>“太棒了伊娃，我平生以来第二喜欢的水果就是榴莲。”</p><p>“第二喜欢？那第一呢？”</p><p>“菠萝蜜。”瑞弗维尔兴致勃勃地说道。</p><p>他年轻时当游侠，去过南方的某片丛林里，被毒蘑菇毒晕在地，躺了整整3天3夜。</p><p>他刚睁眼，就看见树上有菠萝蜜。</p><p>菠萝蜜的甜浆汁、脆果肉救了他一命。</p><p>又一只夜魅在天空中尖叫。</p><p>伊芙站起身，举起法杖一个法术将其轰杀，说：“烦死了。去看杨帝。”</p><p>“怎么了？发现什么了吗，伊娃？”</p><p>“你眼瞎？这夜魅就没停过。”</p><p>理论上来说，当事人入睡后，夜魅就不会在现实生活中出现并袭击他了。</p><p>它们转而会出现在杨帝梦中，在梦里作祟，骚扰他的睡眠。</p><p>但现在，夜魅却依旧源源不断。</p><p>只能说明一件事——杨帝还没昏迷过去。</p><p>“难道他没学会冥想？”瑞弗维尔担忧。</p><p>伊芙眉头紧皱：“不。杨帝学习能力极强，没可能学不会并不困难的冥想……天杀的，夜魅又来。”</p><p>精灵挥舞法杖，物理打晕几只飞来的夜魅，然后转身向地窖走去。</p><p>瑞弗维尔总觉得眼前的精灵在生什么闷气，暴躁了起来。</p><p>虽有疑惑，他也只能跟上去：“伊娃！慢点……”</p><p>地窖黑乎乎的，没有灯，也没有火。</p><p>不过魔法的方便之处，在于能够很方便地代替各种生活用品。</p><p>瑞弗维尔正想要咏唱咒词，召唤一颗“三环法术·实体光球”出来。</p><p>伊芙花了1.5个弹指，就已经召唤出两颗实体光球。</p><p>她向图书馆馆长抛来一颗。</p><p>瑞弗维尔手忙脚乱地接住，差点让光球掉地上。</p><p>光球放射出凌乱的光。石窖深处，杨帝宛如睡美人，婀娜多姿地躺在床上。</p><p>伊芙蹲下身子，仔细观察杨帝状态，发现他全身肌肉极度紧绷，身躯微微发颤。</p><p>呼吸急促，心跳狂乱，血液流速比平常快15%，脉象紊乱，舌苔厚黄，汗出偏沮，略微上火。</p><p>他似乎在与什么进行着激烈对抗。</p><p>“难不成，他的精神仍然在保持冥想状态，还没有没有昏迷？”伊芙心中弹出这个想法。</p><p>太不可思议了。</p><p>虽然先前就隐隐约约觉察到，杨帝的精神比其他人强大得多。</p><p>但这也太强了，就像……神灵、圣树那般深不见底。</p><p>也正因如此，在末日火山他目睹了“原初之眼”的真身投影足足几十秒，却没有发疯暴毙。</p><p>精神极度庞大浩瀚，就能够容纳那只眼睛的形象。</p><p>否则，就会像把一整本厚书的内容，强行写在一小张便签纸上，会把精神撑爆。</p><p>即使是伊芙自己、10环超限法师，与原初之眼的真身投影——那只瞳孔——对视超过半分钟，都会心慌胸闷。</p><p>这足以说明，杨帝不是寻常人。</p><p>所以，伊芙也不敢用强硬手段，从他嘴里撬出情报和身份。</p><p>万一是哪个神灵，恶趣味发作，造了具物质躯体到人间私服微访？</p><p>伊芙仔细检查了一下杨帝的状态。</p><p>发现：虽然他身体各项指标混乱不堪，但生命体征却出奇地稳定，并没有生命危险。</p><p>这个“人类”特别耐杀。</p><p>之前吃了剧毒蘑菇，伊芙治好瑞弗维尔后，她便发现杨帝已经痊愈了。</p><p>而且不久之前，在末日火山，他脑袋还裂成了八瓣。</p><p>受过这么多致命伤，他照样活了下来，活蹦乱跳，看起来愣事没有。</p><p>伊芙：“他还活着，而且看样子，并非是身体无法承受精神消耗，更像是在主动坚持着什么。”</p><p>瑞弗维尔：“怎么会出现这种情况？”</p><p>“我怎么知道，他都‘失忆’了，连自己是谁都不知道，我更不清楚他身上发生过什么。”</p><p>伊芙将手按在他额头。</p><p>她猛然有种触电的刺痛——杨帝体内的灵，极其弱小！</p><p>就好像……有人硬生生撕裂了他大部分的“现实”。</p><p>伊芙瞳孔一缩，猛然意识到一件事——杨帝存在感的确太低了。</p><p>到现在为止，她还不知道杨帝穿的是什么衣服。</p><p>仔细看过去，他穿的是一件自己叫不上材质的风衣，下身是带有金属拉链的长裤，脚上是一双很简陋的鞋。</p><p>鞋面由两条带子交叉固定在脚面上。带子拧成一股，延伸到鞋底，恰好卡在大脚趾和二脚趾之间。</p><p>如此奇异的打扮，她一直毫无察觉。</p><p>地窖外头，夜魅又开始啸叫了。</p><p>“看来只能用那一招了。”伊芙低声说。</p><p>瑞弗维尔一脸疑惑：“什么招，伊娃。”</p><p>“就是通过物理方式打断‘冥想’。”</p><p>“物理……方式？”</p><p>伊芙将瑞弗维尔推远：“没错，我要让他进入婴儿般的睡眠，或者从冥想状态恢复清醒。”</p><p>她把拳头抡圆了。</p><p>“轰！！！”</p><p>……</p>
