# 智械

<p>杨帝降落在东方一片繁华的岸边。</p><p>稷海市。“稷”者，古之五谷之长，本地是指饱满沉坠的稻子。</p><p>而“海”，并非真有浩渺汪洋。这座城临江而起，穿城而过的大江开阔如镜面，晴时映着天光云影，雨时裹着雾霭朦胧。</p><p>岸边亭台楼阁与错落灯火交相辉映，晨昏皆有不同景致，望去竟有几分海的壮阔与灵动，故而得名“海”。</p><p>但对老稷海人而言，最重要的是“稷”，用来吃饭的家伙子。</p><p>入夜，霓虹灯勾勒出杨帝熟悉的街巷，晚风送来海腥与油炸小吃的混合气息。</p><p>杨帝咬下一口脆皮淀粉肠。</p><p>稷海理工大学的西门依然立着那座石狮，左侧第二根胡须还是断的。他沿着银杏大道走向男生宿舍，脚步在暮色中无声。</p><p>514室亮着灯。</p><p>透过窗帘缝隙，他看见张明远戴着一次性耳塞猛敲键盘，泡面碗在桌角堆成摇摇欲坠的塔。</p><p>这个人居然也在。已经很久没见过他。他还是不知道自己的青轴键盘有多大声。</p><p>达文西的红米手机推送了条娱乐新闻：“知名跑酷博主‘胡彦’昨日完成滨海艺术中心极限挑战……”</p><p>画面里矫健的身影在穹顶间飞跃，红色卫衣被风吹得鼓胀。镜头特写定格在他明朗的笑脸上，评论区滚动着粉丝的欢呼。</p><p>杨帝打开手机。博主ID“未退休跑手”，头像是一道穿梭在建筑间的红色剪影。</p><p>他发现，达文西关注这个跑酷博主已经很多年了。</p><p>又通过手机中各项蛛丝马迹，譬如运动健康数据、相册自拍，杨帝知道达文西是个肥肥。肥肥也有跑酷于钢筋水泥丛林间的梦想么？</p><p>跑酷博主主页显示昨日更新：</p><p>【谢谢大家关心！昨天直播时摔的那跤真没事，就是楼梯突然晃了下，可能地震了吧哈哈#艺术中心跑酷#】</p><p>配图是他在医疗站比耶的自拍，手腕纱布都系成蝴蝶结了。</p><p>银杏叶落在屏幕上方。杨帝抬头，看见胡彦卓正从远处跑来，运动发带压住飞扬的黑发，颈间银哨随着步伐跳动。</p><p>他掠过杨帝身边时带起一阵风，没有回头，没有认出杨帝。</p><p>阳光穿过叶隙，在杨帝掌心投下光斑。他轻轻握拢手指。</p><p>光子作为静质量为零的玻色子，本应始终以光速运动，但此刻在约束场中，其波函数被压缩至德布罗意波长与场半径相当的尺度。</p><p>杨帝转动体内磁场，磁生电，通过毛发传导神经电流，模拟出强电场，使场域内的正负电子对激发概率骤增。</p><p>光子能量被时空曲率不断挤压至临界值，与虚实电子发生康普顿散射——这一步严格遵循能量守恒，光子的部分能量转化为电子的动能，剩余能量则让光子的频率降低，波动性减弱而粒子性凸显。</p><p>根据希格斯机制，杨帝用俺寻思的灵能之力引导场域内的希格斯玻色子凝聚体与散射后的光子残余能量发生耦合。</p><p>光子像穿过粘稠液体的粒子般获得惯性质量，其运动速度从光速骤降至亚光速，此时的光子已不再是纯粹的电磁辐射，而是成为了一种介于光子与电子之间，具有静止质量的准粒子。</p><p>杨帝手搓一个掌心雷，也可以说是元气弹。</p><p>他微微侧头，像是对着身后某个地方说：“不要遮遮掩掩了，你对‘达文西’有什么意图？”</p><p>树后，一个背着巨大吉他盒的少女走出。</p><p>是个机器人，仿真程度很高。</p><p>她从树后走出，月光在光滑的合成皮肤上投下冷冽的微光。机器人自称银隼，更准确来说，她是智械。</p><p>“我的任务进程中没有要求将死而复生的你列为清除目标。数据已确认：目标‘达文西’生命信号已终止。”</p><p>她的声音依旧平稳，但那种冰冷的电子质感似乎减弱了少许，“你是新的未知变量。根据逻辑推演，冲突并非最优解。我们可以谈谈。”</p><p>她微微偏头，光学镜片聚焦在杨帝脸上，“并且，我数据库内确实存储并分析过《轮回者不需要操作手册》的全部已发布章节。从某种角度而言，我确实是他的读者。修正：忠实读者。”</p><p>杨帝缓缓松开手，掌心那团被赋予临时质量的掌心雷无声湮灭，散作点点星尘。</p><p>“很可惜，现在掌控这具身体的是我，杨帝，而非达文西。但我继承了他所有的记忆。”</p><p>他扯了扯嘴角，一个属于达文西的习惯性小动作。</p><p>“如果你有任何关于他，或者关于那本‘书’的问题，我可以解答。”</p><p>“跟我来，这里不是谈话的地方。”读者说。</p><p>他们穿过依旧喧嚣的步行街，霓虹灯牌和食物的香气构成熟悉的市井画卷，却都与他们无关。</p><p>银隼走进一栋外观普通的写字楼，电梯直达第20层。</p><p>走廊安静得出奇。银隼在其中一扇写满花里胡哨标识的深色木门前停下，对着门把手用可疑的力度一拧，门锁传来“咔哒”一声轻响，向内滑开。</p><p>门后并非想象中的办公室格间，而是一个极具反差感的空间。</p><p>柔和的爵士乐流淌在空气中，暖黄色的灯光照亮了深色木质吧台和整齐排列的酒瓶。</p><p>空气中弥漫着白兰地和咖啡豆混合的醇厚香气。吧台后站着一位中年男人，身穿马甲，头发梳理得一丝不苟，正慢条斯理地擦拭着玻璃杯。</p><p>这里是一家隐藏在高耸写字楼里的Speakeasy风格酒吧，安静，私密，仿佛与楼下的世界完全隔绝。</p><p>“银隼小姐。”酒保微微点头，目光扫过杨帝，没有流露出任何惊讶，“老位置？”</p><p>“谢谢。”银隼径直走向最里面一个靠窗的卡座。窗外是稷海市的璀璨夜景，蜿蜒的江面倒映着万家灯火。</p><p>两人落座。酒保无声地送来两杯冰水，随即离开，留下绝对私密的空间。</p><p>银隼将巨大的吉他盒小心地放在身旁座位上，她的坐姿端正得不像人类，因为本来就不是人类。</p><p>她看向杨帝，直接切入正题：</p><p>“第一个问题：达文西在第100章提到，‘灵能流动的形状决定物质的功能，顺序方向规定现实的因果’，但之后的剧情并未体现该设定。此处的设定是临时起意，还是他早期大纲中确有规划后被废弃的支线？”</p><p>杨帝愣了一下，随即在达文西的记忆碎片里翻找。那感觉像是在一个堆满废纸和快餐盒的混乱房间里寻找一份特定的草稿。</p><p>“呃……是临时起意。”</p><p>他揉了揉眉心，“他当时觉得那样写‘比较有深度’，当时他受泛灵论影响比较深，又看了几分钟科普视频，浅浅了解了一下麦克斯韦方程，就吧‘电’拿来类比‘灵’了。。。”</p><p>银隼眼中的微光似乎闪烁了一下，像是系统在处理一个极低概率的答案。</p><p>“这种随意性严重降低了设定的可信度。”</p><p>“他的写作一直如此。靠瞬时灵感，或者说一拍脑袋。”</p><p>“第二个问题。‘图兰泽’的自转轴倾角在第331章，其自转轴倾角为37度。”</p><p>银隼继续追问，语气仿佛在审讯，但内容却极其硬核，“这是暗示了该星系曾遭受足以改变轴倾角的大质量撞击事件？如果是后者，为何后续再无伏笔回收？”</p>
