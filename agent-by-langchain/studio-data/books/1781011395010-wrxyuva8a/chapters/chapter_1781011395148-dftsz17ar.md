# 协助调查与嫌疑人

<p>（不知不觉就200章了，能看到这里的家人们，居然能忍受老狐无聊至极的文字，在此深表感谢。）</p><p>（我也知白驹过隙，逝者如斯。我会吸取更多读者的批评，未来写更有意思的文，著更好看的章，做更壮丽的事业。）</p><p>（宇宙的终极答案是一串9位数字，欢迎大伙儿进群玩耍儿。）</p><p>五位土著眉间生出悲伤。</p><p>三位异界来客惊悚震骇。</p><p>包括杨帝，已识乾坤大没想到还有大乾坤。</p><p>一位至强者喝水呛死，实在闻所未闻。</p><p>就好比说，无剑胜有剑的独孤求败打遍天下无敌手，最后死于一块绊倒他的砖头。</p><p>其实，此时此刻，五位土著大能都处于极其紧张的氛围中。</p><p>在爆出归墟大帝的死讯后，如果白杨大帝有任何入侵称霸此界的念头，他随时都能动手。</p><p>随时都可能暴起发难。</p><p>弱界无外交。除非强界出了个绝对强者确立秩序，保护弱界。</p><p>但上一个“绝对强者”归墟大帝已然仙逝。</p><p>他们这个世界，已没有足够的力量与来自外界的“白杨大帝”相抗衡。</p><p>但杨帝只是吃着蛋挞，捏下巴思考：“好端端一个大帝，怎么就死了呢……你们找到原因没有？”</p><p>酒楼厨子·中山无极微微松了口气：“陨落原因仍在调查，如果白杨大帝阁下愿意助一臂之力，那是我们的荣幸。”</p><p>杨帝沉思，随后点头。</p><p>查明此界大帝之死，对他只有好处，想不到有什么坏处。</p><p>实这也是个很好的切入点，能让几位土著大能充当他的向导。</p><p>按照惯例，杨帝首先问出那个至关重要的问题。</p><p>他用指尖蹭去嘴角的蛋挞屑，抬手朝满桌佳肴虚虚一揖：“诸位连日来的款待，杨某算是尝遍了此界珍馐。就说这‘无极大排挡’的招牌红烧凤爪，骨缝里都浸着氦-3聚变的香气。”</p><p>“白杨大帝，区区小礼，谬赞了。”</p><p>杨帝点点头：“好吧，我便协助你们调查归墟大帝的死因。”</p><p>图书馆保安·天机子擦了把冷汗：“那实在是感激不尽。有您的协助，想必归墟大帝之死，很快能揭晓谜底。”</p><p>他衣袖一挥，将一叠卷宗放在案上。</p><p>这是归墟大帝最后三个月的行程记录。</p><p>“这些卷宗记录我们已经研究完了，目前正在结合大帝最后三个月的行程，分析他为何而死，因何而死。”</p><p>记录显示，最后三个月，归墟大帝向灵界请了三天假。</p><p>然后他迅速来到凡界。</p><p>凡界的时间流速与灵界相比是10:1，灵界请假3天，在凡界就能拥有30天假期。</p><p>大帝在凡界四处行走，给渔村修堤坝、帮书院调灵气、教小贩算账……</p><p>图书馆保安站起来，总结性说道：“青丘，我们的希望，大地的愿望……灵界和凡界的梦想都寄托在你身上了。带我们的‘白杨大帝’客人们，重走一趟归墟大帝最后三个月的行程。虽然对大帝临终前的行为，我们已经研究很多遍，但在杨帝协助下，或许可以发现更多新线索。”</p><p>他们就这么把导游任务，丢给一位“最单纯”的弱狐狸。</p><p>……</p><p>图书馆保安·天机子一拍桌案，手背上青筋暴突，眼睛盯住酒楼厨子。</p><p>“厨子！你可没有告诉过我，也没有和我们讨论过，要让白杨大帝掺和进‘归墟大帝陨落’这一事！”</p><p>在他们先前的眼神交流中，只是计划让青丘白璃以相对温和且单纯的方式，向杨帝讲述归墟大帝的事迹。</p><p>尽量避免直接冲突，争取以“爱与正义”感化这位异界强者。</p><p>却从未想过，要将杨帝直接牵扯进归墟大帝陨落的调查之中。</p><p>相当于让外人干涉内政。</p><p>酒楼厨子叹茶，双眸始终注视前方，缓缓点头：“嗯，没错，是我当场改变了主意。”</p><p>“给我们个解释。”图书馆保安将青瓷酒杯重重磕在桌面，酒液当场溅出来几滴。</p><p>道观扫地僧·渡厄禅师、中学老头·血手屠魔二人，也都齐齐看向酒楼厨子·中山无极。</p><p>这二人一个是光头，另一个也是古稀老头，并不具备用甜美声线做导游、用爱与正义感化大魔王的资格。</p><p>酒楼厨子看起来有些紧张，倒茶装满了整个杯子的120%才收手。</p><p>他叹了口90度的普洱，声音带上微不可察的颤抖：“我刚刚复盘，想起一件事……白杨大帝把我当路人打晕时，他用的是纯粹物理力量。”</p><p>窗外海浪拍击楼船的声响陡然放大，五层高的酒楼檐角铜铃齐鸣，明明无风，却震得众人耳膜发疼。</p><p>中学老头·血手屠魔双手颤抖：“你是说，他仅凭手臂的物理力量，就将真仙大圆满、半步大帝的你，殴打至短期失忆；不仅没有用一点灵能力量，而且物理力量收放自如，没有一丝一毫泄露出来？”</p><p>酒楼厨子·中山无极是四位土著大能中的最强存在。</p><p>而中学老头·血手屠魔则是大帝之下，最强的“体修武者”。</p><p>他非常清楚，将力量收放得这般自如，本身意味着什么……</p><p>——这种能将中山无极敲到失智的纯粹物理力量，哪怕泄露出0.01%，就足以让方圆数万平方公里的大气发生核反应。</p><p>让整个凡人王朝，连带向外绵延数百万里山河，在核火焰中焚灭殆尽。</p><p>但在杨帝殴打中山无极之时。</p><p>船舱底部走廊的平均气温，仅仅升高了蛐蛐一度，相当于几乎没有能量泄露。</p><p>杨帝的力量，达到了极高境界，深不可测。</p><p>酒楼厨子·中山无极将身子向前探，面色略微煞白：“所以你们都知道，这意味着什么吧？”</p><p>“白杨大帝以武证道？”</p><p>“以武证道只是最浅显的结论！”</p><p>图书馆保安、酒楼厨子、扫地僧都已经相继想通，脸色接连惨白。</p><p>只有满脑子肌肉的体修大佬——中学老头·血手屠魔仍然一头雾水：“不是以武证道？你到底想说什么……”</p><p>“白杨大帝能将‘中山无极’这个已经极度接近大帝的男人，给悄无声息敲到失忆。但这，仍然不是杨帝的上限！”</p><p>“那么，有没有一种可能——杨帝，他如果使出全力，也能悄无声息地谋杀归墟大帝？”</p><p>几位土著大能很早就排除了“他杀”。</p><p>但那是建立在两大前提之上：</p><p>第一，凡界灵界没有能伤到大帝的强者。</p><p>第二，域外天魔没有理智，行事极度猖狂，张扬跋扈。</p><p>而现在，出现了意外变量，杨帝。他很可能有能力杀死归墟大帝，同时也表现出足够的理性——足以施展计谋的理性。</p><p>道观扫地僧轻咳两声：“中山厨子，所以你是想……？”</p><p>酒楼厨子·中山无极做出碇司令的动作：“我们跟踪他们。”</p>
