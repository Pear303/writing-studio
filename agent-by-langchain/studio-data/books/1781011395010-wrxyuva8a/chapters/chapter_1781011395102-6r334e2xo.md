# 宰客

<p>原本来说，奥拓的警告会像风掠过耳畔，从瑞弗维尔他们左耳进右耳出。</p><p>毕竟这镇子，和居民，都看起来如此质朴，尤其有这么多豪爽的矮人，怎么会干出如此龌龊而不道德之事呢？</p><p>不符合刻板印象。</p><p>但瑞弗维尔还未来得及发问，整条街道突然活了过来。</p><p>挂着草药的泥墙缝隙里，探出无数脑袋。</p><p>晾晒兽肉的木架后，转出绰绰人影。</p><p>连屋檐下打盹的老人都掀开草帽，紧紧注视着杨帝四人。</p><p>居民从四面八方涌来，整个砾石镇仿佛被捅破的蚁穴。</p><p>杨帝也感到背后一寒，想到他曾看过的电影《逃出绝命镇》。现在也许能翻拍一部异界版的逃出砾石镇。</p><p>数十镇民，如饥渴的豺狼看见血肉，聚焦杨帝等人的目光满是狂热、喜悦与……贪婪。</p><p>他们同时把手放进口袋……掏出来……</p><p>掏出来一堆老古董。</p><p>“高贵而富有的法爷！看看这把第一代矮人王用过的黄金锄头！”</p><p>“真正的龙骨化石！是从恶龙卡瑟琉斯尾巴上掉落的！”</p><p>“卡瑟琉斯就是卡利斯托它远房亲戚！没听说过正常，这个只在野史上才有记录。”</p><p>“八百年前精灵祭祀的翡翠古玩，外边市场价5000万，这里我给你批发价500万……”</p><p>杨帝好像明白了什么——</p><p>刚才喊他“叔叔”的小女孩，为何认为“越老越好”了……</p><p>都是被这帮古玩贩子带坏的！！</p><p>奥拓摁灭瑞弗维尔众人眼中的好奇：“别看了各位，今天展示在咱面前的这些‘古董’，要有半件是真的，我表演个倒立洗头剃胡子好吧。”</p><p>说实话，瑞弗维尔还挺想看矮人倒立洗头剃胡子的。</p><p>特别是奥拓——有一副典型的矮人模样，脑袋毛茸茸，胡子眉毛特别浓密。</p><p>但在周围围上来的镇民中左看右看，他也一时拿不准哪些真哪些假。</p><p>伊芙·柑橘眼中闪了闪，一锤定音下了判决：“确实都是新的，年代不超过200年。”</p><p>杨帝也看出来了。</p><p>精灵的“四环法术·自然感应”能感应到，杨帝的六感也自然能觉察到。</p><p>这些“古代瓷器”、“皇帝锄头”，印记还很新，做旧工艺也不够精。</p><p>但对于小作坊来说，已足够欺骗大多数外地游客、外行人士。</p><p>矮人奥拓叹息：“您瞧，来宰客了。”</p><p>道路被围得水泄不通，古玩贩子里三层外三层。</p><p>看起来人很多，其实只是因为他们附近人流密度极大，其他地方还是很空旷的。</p><p>最后数下来也就二三十人。</p><p>“让开！”伊芙指尖迸出电弧和火焰。</p><p>人群惊呼，霎时空出半径两米的圆。</p><p>某个举着“上古魔晶”的矮人慌忙后退，怀里的水晶簇在震荡中裂开，露出内里填充的彩色糖渣。</p><p>他们加快脚步直奔某处。</p><p>伊芙威慑众人，让他们不敢跟上来，紧接着对一行四人施加「风王结界」，隐形起来。</p><p>“哦不，天哪！不见了！”</p><p>“我们亲爱的客人躲在了哪里？”</p><p>在一片诡谲的氛围中，他们借着「风王结界」的隐形效果，小心翼翼地穿梭在逐渐混乱的人群中。</p><p>那些古玩贩子们还在四处寻找。</p><p>嘴里嘟囔着奇怪的话语，不时有人因为占据所谓“最佳售卖点”而推搡起来。</p><p>瑞弗维尔压低声音：“这些人真是疯了，为了卖这些破玩意儿，简直不择手段。”</p><p>“他们为何这么狂热？”</p><p>奥拓叹了口气：“我原本不想和你们说，就是怕你们心软。如果你们执意要听，那么之后你们做的一切，发生的事情，都和我无关。”</p><p>伊芙胃口也被吊起来，身子微微向前倾。</p><p>奥拓看了看四周，确定没人能听到后，缓缓开口：“镇上人原本都是盗墓出身的。早些年，他们在‘星渊井口’大肆挖掘，以为找到了致富的捷径。可他们不知道，那些古墓里不少物件都被施加了‘绑定诅咒’的附魔……”</p><p>“绑定诅咒？！”</p><p>瑞弗维尔倒吸一口凉气，“居然是绑定诅咒！！！所以……什么是绑定诅咒？”</p><p>奥拓无奈地摇摇头：“触碰了附有‘绑定诅咒’的物件，就如同跗骨之蛆，再也摆脱不掉这件物品。”</p><p>每件赃物，都像吸血蛭似的黏在这群盗墓者血脉里。</p><p>就算他们决意将其摧毁，也打不碎那些物品，比秘银还硬。</p><p>无论是将自己藏到天涯海角，还是将那些物件扔到地角天涯，一个不留神，它们又会再次回到身上。</p><p>洗澡的时候，这些物件说不定就突然从排水口冒出来，吓得人魂飞魄散。</p><p>不管怎么藏，怎么扔，总能回到身边。</p><p>这种“回到身边”的机制极度强大，近乎概念神。</p><p>已知摆脱它们的第一种方法，就是去死。</p><p>身死债消，所以盗墓者们才会发现，这些平平无奇的小物品会被当作“陪葬品”。</p><p>——并非陪葬品，而很可能到墓主人死的前一刻，都摆脱不掉它们。</p><p>杨帝恍惚，回忆起很久前自己似乎也有这样一段经历。</p><p>那时候的他，摆脱不掉耶罗符印。</p><p>瑞弗维尔：“那第二种摆脱的方法呢？”</p><p>奥拓：“把圣古琉斯王城为市场基准点，将其以8192倍市场价卖出去。”</p><p>怪不得这些人如此疯狂，为了卖掉这些所谓的“古董”不择手段。</p><p>瑞弗维尔和伊芙点点头，如果这是唯二摆脱它们的机制，这确实值得镇民们狂热。</p><p>“但8192倍市场价真会有人买吗？”瑞弗维尔低声问。</p><p>比如一个碗，市场价5块。</p><p>乘上8000大概就是4万块。你愿意花四万块买一个平平无奇的碗？很难。</p><p>“基本不会有人买，所以这里的镇民十年下来，最多一两个人能摆脱诅咒。”</p><p>奥拓在风王结界里，低声地介绍此地风土人情。尽管风王结界本身不仅能屏蔽光线，还能遮断声音和引力。</p><p>“为了以8000多倍市场价卖出去，他们不得不将手中的物件修饰成‘古董’的模样。”</p><p>这些东西从使用价值来说，或许和普通物件并无二致，甚至更差。</p><p>就像那“第一代矮人王用过的金锄头”，拿来锄地，还不如一把普通锄头好使。</p><p>毕竟黄金是很软的，而且密度大，特别笨重。</p><p>但镇民赋予了这些物件符号价值。</p><p>在他们口中，这柄金锄头就不再只是锄头，而是矮人王荣耀的象征，承载着古老的历史与传说，象征矮人也不全是工业狂热，他们也很注重第一产业“农业”的……你就当真了听。</p><p>“人们对于这种符号价值的追求，有时候会远超物品本身的使用价值。</p><p>“收藏家眼中，这些被包装成古董的东西，代表着一段过去，是历史的见证。</p><p>“他们愿意为这份独特的符号价值，付出高昂代价。</p><p>“这就好比一颗普通钻石，本身不过是坚硬的碳，可一旦被赋予了‘爱情永恒’的象征意义，价格就能飙升到普通人难以企及的高度。”</p><p>“镇民们正是抓住了这一点，将被诅咒的物件包装成拥有极高符号价值的古董。</p><p>“试图卖给那些追求这种虚幻价值的人——即便明知道价格离谱得如同天方夜谭。</p><p>“但只要有一丝希望，能遇到一个愿意为这符号价值买单的冤大头，他们就有摆脱诅咒的可能，所以才会如此狂热。”</p><p>奥拓压低声音说着。</p><p>瑞弗维尔有些半懂不懂地点点头。</p><p>伊芙和杨帝心中各自微微诧异。</p>
