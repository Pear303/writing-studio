# 看哭800万亿地球人

<p>蜂巢基地，最深处的实验室。</p><p>一种难以言喻的变化，首先在空气中发生。</p><p>在人类感官无法直接观测的微观尺度上，空气——这本是无数氮气、氧气分子以及微量水蒸气、二氧化碳、尘埃等组成的混沌热运动集合体——突然违背了它亿万年来遵循的熵增铁律。</p><p>这并非魔法，而是数学上那近乎于零，却又不完全为零的、令人窒息的渺茫概率。</p><p>微观层面的一系列巧合，演化成宏观尺度上一次惊心动魄的具现化。</p><p>数以亿亿计的气体分子，在做着永不停歇、方向随机的热运动。</p><p>在一个极短的瞬间内，它们仿佛被一只精准到量子级别的手拨动。</p><p>它们在混乱碰撞中，经过一系列低得令人发指的巧合，成功在宏观统计学层面违背着热力学第二定律的洪流，开始朝空间中一个“点”汇聚。</p><p>氮气分子、氧气分子、水分子，飘散的有机尘埃……</p><p>这概率之低，比宇宙中所有基本粒子同时排成一只狐狸形状还要荒谬无数倍。</p><p>这些分子在飞向某点的过程中，它们的速度矢量发生了精妙绝伦的同步，每个分子的运动方向、速度大小都被精确，发生完美的动能传递与叠加。</p><p>在宏观上，竟汇聚成一股朝着某个点中心的定向“物质与能量洪流”。</p><p>分子和原子在该“点”处，达到前所未有的高密度和超高能量状态。</p><p>原子核与电子之间，本应存在的巨大能量壁垒，但在量子隧穿效应的作用下，如同虚设。</p><p>只是，“隧穿”发生的概率很低。</p><p>但此刻，量子隧穿现象，成建制、成批次、系统性地爆发！</p><p>质子、中子、电子……它们跨越的斥力与键合能垒，以极低概率穿透“势垒”。</p><p>氢原子核“隧穿”到氧原子核附近，精准地捕捉到游离的电子，形成水分子。</p><p>碳原子核在原子云的混沌中闪现到恰到好处的位置，伸出四只正在成型中的共价键，牢牢抓住四个氢原子，构建出甲烷的骨架——这是一种极其基础，但蕴藏无限可能性的有机化合物……</p><p>复杂的氨基酸前体，在无数次的量子涨落和隧穿中，以超越想象的速度自组织、链接……</p><p>这过程涉及无数次精准到飞秒（10^-15秒）级别的量子事件同步发生。</p><p>其概率之低，足以看哭80亿地球人。</p><p>这一切，在宏观世界的时间感知里，几乎是瞬间完成的。</p><p>前一纳秒，那里还是空荡荡，弥漫着毒雾的空气。</p><p>下一纳秒——</p><p>氮、氧、氢、碳……空气中散逸的元素，以及那些被卷入的尘埃微粒，在宏观尺度上恰到好处地拼合出了一个复杂的有机体结构。</p><p>一个人类男性的躯体，毫无征兆地摔落在冰冷的金属地板上，发出“噗通”一声闷响。</p><p>他看起来约莫二十多岁，身形匀称，黑发，黄皮肤。</p><p>身体上没有任何伤痕，皮肤光洁如同新生。</p><p>他所穿衣服，看起来质地很是奇怪。</p><p>此人双眼紧闭，呼吸微弱而急促，胸膛剧烈起伏，仿佛刚刚经历了一场超越极限的、灵魂层面的长途跋涉。</p><p>他陷入了深度的昏迷。</p><p>显然，这具由概率奇迹瞬间“打印”出来的躯体，其内部复杂的神经网络和意识还远未适应这个突兀降临的世界。</p><p>他需要一段时间的“初始化”和“载入”。</p><p>……</p><p>天花板如被撕开的锡纸，混合着碎裂的隔热材料、线缆和灰尘倾泻而下。</p><p>几道狼狈不堪的身影裹挟在这片金属与尘埃的洪流中，重重地摔落下来，砸在走廊地面。</p><p>“咳咳咳！”铁砣庞大的身躯最先着地，发出沉闷的巨响，一下子把他震醒了。</p><p>幸好他皮糙肉厚，只是被震得气血翻涌，这才仅仅只是骂骂咧咧地撑起身体。</p><p>队长、火鸦、眼镜、影子则接连落到铁砣肚皮上。这是个很不错的缓冲垫。</p><p>“大伙都检查一下，没事儿吧？”</p><p>“没事没事，胳膊和腿，鼻子眼睛，一个都没少，数量刚刚好。”</p><p>“诶，铁砣刚不是醒了一下吗？怎么又睡过去了。”</p><p>“呼……话说暂时甩掉了？”</p><p>“‘施瓦辛格’没有跟着我们跑进通风管道，看起来不是很聪明的样子。”</p><p>眼镜惊魂未定地扶正战术目镜，一边喘息一边快速扫视周围环境：“我们……我们在哪里？数据……数据还在。”</p><p>他摸了摸背包，里面仅存的存储设备似乎还完好。</p><p>队长没有立刻回答，他脸色依旧苍白，但眼神锐利地扫视着这个新的空间。</p><p>这里像是一个废弃的设备维护间，空间不大，堆放着一些蒙尘的备用零件箱和锈蚀的工具架。</p><p>空气浑浊，带着浓重的铁锈味和尘埃气，但至少没有第十三实验室那股甜腻的毒气和血腥腐臭。</p><p>应急灯的光芒比外面走廊更微弱，勉强能视物。</p><p>暂时安全了。紧绷的神经稍微松弛了一丝缝隙。</p><p>就在这时，队长的目光如同被磁石吸引，猛地定格在房间角落。</p><p>一个与周围废弃环境格格不入的存在！</p><p>那是一个赤身裸体的年轻男子，正无知无觉地蜷缩在冰冷的金属地板上，黑发，一身黑。</p><p>他胸膛微微起伏，呼吸均匀但微弱，显然陷入了深度昏迷。</p><p>“这……这是什么玩意儿？！”</p><p>铁砣顺着队长的目光看去，牛眼瞪得溜圆，“哪冒出来的黑佬？！”</p><p>“不是黑人，你仔细看，他的脸是黄皮肤，他身上那团黑色的应该是衣服。”</p><p>“他看起来也不像研究人员。”</p><p>队长的眉头紧锁得能夹死苍蝇。</p><p>这个男子，完全超出了他的认知范畴。</p><p>他的念力隐约感知到——眼前这个昏迷的男子，身上衣服并不是布料。</p><p>一眼看上去就不是“蜂巢”基地的工作人员。</p><p>强烈的警惕和求知欲驱使着他。</p><p>队长强大的精神念力再次凝聚，化作一道极其锋锐的念力探针，悄无声息地刺向地上男子的眉心！</p><p>他要读取昏迷男子的记忆。这是他多年来的习惯，从NPC脑中获取第一手情报。</p><p>然而——</p><p>“嗡！”</p><p>极其轻微却又无比清晰，一股如同撞上绝对光滑镜面的精神反馈，瞬间反弹回来！</p><p>队长的念力探针在接触到男子意识外围的刹那，仿佛遭遇了某种无法理解的绝对致密屏障！</p><p>念力如同泥牛入海，似是光线撞上了绝对黑体，瞬间被吸收消散，连一丝涟漪都无法激起，更遑论侵入意识深处读取记忆碎片。</p><p>“唔！”</p><p>队长闷哼一声，脸色更加难看，眼神中溢出一丝挫败。</p><p>“不行，我的念力完全无法侵入他的意识，他的精神被彻底隔绝封闭了。”</p><p>“什么？！”</p><p>铁砣和火鸦异口同声，都感到不可思议。</p><p>队长的念力是他们小队最核心的探测和控场能力，竟然失效了。</p><p>这意味着，昏迷男子很可能是个精神力量远超队长的NPC！</p><p>因为即使对方处于重度昏迷，也仍然能无视队长的念力探针。</p><p>对方要是处于清醒状态，在“精神”方面，至少能打10个队长！恐怖如斯。</p><p>不愧是S级副本，如斯恐怖。</p>
