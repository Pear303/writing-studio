# 恐怖机制怪

<p>生灭劫域的力量无孔不入。</p><p>他每一次心跳泵出的磅礴气血，本该是生命最澎湃的象征，却在法则扭曲下瞬间转化为最污秽的“死寂之源”，反噬自身，试图从内部将他腐朽、分解。</p><p>他呼出的气息，本应媲美混沌初开的精粹，却化作剥夺生机的毒瘴。</p><p>在这里，“生”即是“死”的起点，维持生命的活动本身，就是加速死亡的毒药！</p><p>太虚幻境的侵蚀更是诡异。</p><p>杨帝的肉身，那经过无穷岁月锤炼、蕴含开天辟地伟力的不朽之身，其存在的“实感”正在飞速流逝。</p><p>构成他血肉、骨骼、能量的最基础单元，其灵能被疯狂抽离，存在被强行模糊、稀释。</p><p>他感觉自己正变得透明，仿佛一幅被雨水冲刷的水墨画，即将彻底消融于这片“无”的绝对背景之中。</p><p>但最棘手的，还得是两仪玄界。</p><p>两仪玄界，不是简单的空间折叠扭曲。</p><p>上一瞬拳头轰向元尊，下一瞬那拳劲可能被空间褶皱折射回来打向自己；时间流速忽而亿万倍加速，忽而彻底停滞，甚至出现短暂的逆流回溯，让他对自身动作的判断出现致命延迟。</p><p>因果线更是混乱如麻，他意图攻击准圣的想法，可能被法则扭曲成自残的指令。</p><p>感知、判断、攻击意图，一切都在正反的悖论迷宫中迷失。</p><p>如果他逆向自思维，一拳轰向自己脑袋……那杨帝脑袋会结结实实挨下这一拳。</p><p>“哼！”杨帝闷哼一声，开始止不住地吐血。</p><p>三重领域的叠加，是恐怖的机制镇压！</p><p>……</p><p>躲在极远处围观的真仙境大能们，此刻已是面无人色。</p><p>青丘白璃望着那片翻涌的混沌光茧，声音发颤地打破死寂。</p><p>“诸位可曾知道，在荒古年间，灵界曾有十万域外天魔、与一尊仙帝境大妖融合成的「寂灭血海尊者」？</p><p>“那怪物一出世便血洗灵界三十三重天，连当时的一位至尊都被它重创，超过一百位真仙境大能战死。</p><p>“那时的太虚妙有法王尚是‘帝临真一’第一境——仙帝。但他仅凭一道生灭劫域，便将那寂灭尊者困在其中生生磨灭！</p><p>“要知道，那可是连‘帝临真一’第三境·至尊都能重伤的怪物啊！”</p><p>此言一出，众仙皆是倒吸一口凉气。</p><p>横跨两个境界，将敌人击杀？</p><p>要知道境界层次越高，不同境界之间的差距就越庞大，越是天堑。</p><p>炼气期反杀筑基期，筑基期反杀金丹期……这样的新闻，灵界隔一个星期就有。</p><p>再往上，比如什么化神期反杀炼虚期，合体期反杀渡劫期，则是百万年、甚至千万年一遇。</p><p>但这，还只是跨一个境界反杀。</p><p>当时的太虚妙有法王，是跨了两个大境界！</p><p>本就有天堑，此刻再隔一个天堑，他居然还有能力反杀！</p><p>有白发老仙翁抚须颤声道：“白璃仙子所言非虚，老夫曾在古籍中见过记载。而且而且，那时的法王尚未成就准圣境界，生灭劫域便有如此威能，如今他已是准圣……”</p><p>这领域，只可能更强，而不可能更弱。</p><p>一众大能超级频繁地倒吸凉气。</p><p>那位白杨大帝居然恐怖如斯，不愧是承受了数百号真仙境大能狂轰滥炸三天三夜的强者。</p><p>虽然最后时刻，因粘屎拖把破防，恼羞成怒血溅五步。</p><p>但那都是人之常情。</p><p>其肉身和精神防御，绝对不容小觑！</p><p>“还有一个更恐怖的事实。”人群中又有大能低声说道。</p><p>那位不愿透露姓名的大能说了很多。</p><p>他说什么……准圣之间亦有差距，什么很抱歉没让太虚妙有法王使出全力。</p><p>一句话总结为——知情人爆料：太虚妙有法王，竟还只是荒古三位准圣中最弱的？！</p><p>……</p><p>这是一场几乎无解的死局。</p><p>只要杨帝活着，他就会被逆转为死亡。</p><p>只要他还存在于世，就会被消灭于虚无。</p><p>如果他自杀，他也还是死亡，而不会被逆转为活着。因为这座三重嵌套领域的“天道”是三位准圣，准圣会自主操控杨帝的命运，不以世人为刍狗。</p><p>若以世人为刍狗，则为「圣人」。</p><p>杨帝有点撑不住。他有些怀疑自己是不是玩脱了，是否对自己的进化适应能力太过自信了。</p><p>就算心脏疯狂泵出象征“生命”的存在，也会瞬间被逆转为最深沉的死亡。</p><p>意识在绝对的黑暗中沉浮，像是坠入无底的深渊。</p><p>杨帝能清晰地感知到肉身的崩解——那不朽之躯，在生灭劫域的法则下化为飞灰，灵能被太虚幻境抽离得一干二净。</p><p>按照常理，他的存在早已该归于“无”，连一丝残魂都不该留存。</p><p>但“思考”却顽固地存在着。</p><p>这不是基于肉身或灵力的思维活动，更像是一种……纯粹的觉知。</p><p>没有感官输入，没有时空概念，甚至没有“自我”的明确边界，唯有一缕意念在虚无中飘荡，如同风中残烛，却偏偏不熄。</p><p>“我……还活着？”</p><p>这个念头刚一升起，就被某种无形的力量狠狠扭曲。</p><p>他能感觉到，准圣三重领域的法则再次躁动起来，试图将这残存的意识彻底抹除。</p><p>生灭劫域的死寂之源如潮水般涌来，试图将这丝意念腐朽。</p><p>太虚幻境的侵蚀则化作无数模糊的光影，强行稀释他的存在实感。</p><p>两仪玄界的逻辑崩坏更让他的思绪陷入混乱，前一刻还在分析现状，下一刻试图将“存活”的认知逆转为“死亡”。</p><p>但奇怪的是，这一次，法则的反噬似乎打在了空处。</p><p>杨帝的意识没有实体，没有可被攻击的“生”之源头，生灭劫域的转化机制失去了目标。</p><p>它纯粹如混沌初开的虚无，太虚幻境的抽离与模糊，也仿佛作用在一片空白之上。</p><p>只要他活着，那么他就死了。</p><p>哪怕死了也不得安生，因为他还存在。</p><p>只要他存在，那么他就不存在。</p><p>杨帝无法操控任何力量，无法感知外界，甚至无法确定自己是否真的存在。</p><p>但这缕意识却在三重领域的缝隙中，以一种诡异的方式延续着。</p><p>他看不到青丘白璃等人的震惊，听不到远处真仙境大能的低语，感受不到三大准圣、残星道人的攻击。</p><p>只能沉浸在这无边的虚无中，感受着法则如跗骨之蛆般的持续侵蚀，以及……</p><p>那一丝微弱到几乎可以忽略不计的、来自领域之外的“注视”。</p><p>很模糊，像是某个遥远时空的一声叹息，某种超越了准圣领域的更高层次的……注视。</p><p>很远……但也很近，近得像是在观众席上投射出的目光。</p><p>杨帝的思想无法理解那是什么，只能本能地抓住这道视线作为锚点，在死寂与虚无的夹缝中，维持着这缕不该存在的“思考”。</p><p>生即是死，死即是生。存在即是虚无，虚无即是存在。这不是哲学思辨，而是此刻的现实。</p><p>「综合抗性+1+1+2+3+5……」</p><p>「现实丰度+1+1+2+3+5……」</p><p>数值不断提升，指数级跃升。但在机制面前又有什么用？数值怪能打得过机制怪吗。</p><p>不对。</p><p>杨帝抓住识海中一个明亮的光点。</p>
