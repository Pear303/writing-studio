# 正邪两立

<p>高三零班，教室内。</p><p>广播继续说：</p><p>「……怪谈领域完全降临后，领域内外将被强制封闭隔离十二天！」</p><p>「领域内外物理及信息交互，将受到严重阻隔。未来12天内，领域内无法出去，领域外无法进入！请全体师生做好长期坚守的心理准备。」</p><p>「请诸君按照《江城二中怪谈事件应急演练预案（第7版）》展开行动！」</p><p>「首要任务是，引导、保护学生！组织转移至安全区，即无视野连通教室和体育馆！」</p><p>「请各年级组，立刻派遣各科教师一名，搭配三位红袖章志愿者，组成探路小队，优先前往体育馆安全区。」</p><p>「任务目标：一、探明通往体育馆的路径是否安全，有无新规则出现。二、确认体育馆内部环境是否稳定，有无异常。」</p><p>「重复！规则即生命线！行动务必谨慎！」</p><p>广播结束，高三零班内死一般的寂静被打破了。</p><p>“十二天？与世隔绝？”凌云圣皇眉头紧锁，俊朗的脸上阴云密布。</p><p>他前世统御亿万疆域，何曾受过这等囚禁？更何况是在这规则诡异的险地！</p><p>“吼吼吼哈哈哈哈哈！！”</p><p>血手屠魔大笑起来。</p><p>“让肉体凡胎的教师和志愿者去探路？一群连炼气门槛都摸不到的蝼蚁，去送死么？”</p><p>“不错，此等探查之事，关乎我等安危，岂能假手他人？若遇变故，那些凡人连自保都难，遑论传递有用信息？”</p><p>“附议！”</p><p>“区区凡人，安能担此重任？”</p><p>“吾等虽境界跌落，然眼界、经验、神通根基犹在！探查之事，舍我其谁？”</p><p>“正是！吾等灵界真仙，岂能在此界坐等凡人庇护？”</p><p>一时间，班内那些觉醒了部分前世记忆和炼气期修为的学生纷纷附和。</p><p>杨帝一走，立刻猴子称王。</p><p>方才被杨帝碾压的恐惧，此刻似乎被一种“必须证明自己价值”的迫切感和身为“上位者”的骄傲所取代。</p><p>他们急需一场行动，来确认自己在这个诡异世界的位置，哪怕对手是未知的规则。</p><p>阿巴缩在角落，鱼眼里满是茫然和不安。</p><p>她体内的鱼尊记忆碎片还在冲击，让她本能地觉得这地方很危险，非常危险。</p><p>看着这些“同学”热血上头的样子，她张了张嘴，想说什么，却只发出几声意义不明的“阿巴阿巴”。</p><p>啊……老大去哪了……</p><p>“我反对，你们特么是蠢货？”一个声音给热血的几人浇了盆冷水。</p><p>并非所有觉醒者都如此勇猛。</p><p>角落里，一个身形干瘦、眼神闪烁、名叫“苟玖”的学生，猛地摇头。</p><p>他前世乃灵界赫赫有名的“九转大常真君”，以“直肠给药药效翻倍”、“肛门藏剑出其不意”等独门邪术，一路苟到真仙巅峰，是邪道中的第一梯队人物。</p><p>九转大常真君声音尖细：“不可！万万不可！凌云道友、屠魔道友，诸位且慢！冲动是魔鬼啊！”</p><p>他搓着手，一脸苦口婆心：“诸位想想，吾等如今是何修为？炼气！炼气期啊！放在灵界，连给杂役弟子提鞋都不配。此界规则诡异莫测，连那广播都透着一股邪性。那体育馆，若真是安全区，为何还要派人‘探路’？必有蹊跷！”</p><p>他压低声音，眼神飘忽：“依老夫……之见，当务之急是稳！是苟！需得寻一绝对安全之所，布下层层禁制，再徐徐图之。待老夫寻得此界适配的灵材，炼他十炉甚至九炉太乙仙丹，将药力以无上秘法‘后庭直灌丹田’，或可恢复几分神通，那时再探不迟！现在去？与送死何异？”</p><p>九转大常真君一开口，立刻引起了一批同样走偏门、邪道起家的觉醒者共鸣。</p><p>他们前世能成就真仙，靠的都不是堂堂正正的大道。</p><p>而是各种匪夷所思、剑走偏锋的邪法。</p><p>如今修为跌至谷底，赖以依仗的邪门手段无法施展。</p><p>让他们去未知的险地探路？比杀了他们还难受。</p><p>“苟玖说得对！现在去就是送菜！”</p><p>“本座‘化骨绵掌’需以童子元阳为引，此地阳气稀薄，不宜动手！”</p><p>“附议苟道！先苟住！待我寻得此界雌性纯阴之体，采补一番，恢复元气……”</p><p>一时间，班内分成了两派。</p><p>一派是以凌云圣皇为首的“激进派”，自信或者说自负于前世经验，并且有极深的弥赛亚救世情结。</p><p>另一派则是以“九转大肠真君”苟玖为首的“邪道派”，对现状认知更清醒。</p><p>凌云圣皇看着这群畏畏缩缩、满嘴邪门歪道的“同道”，眼中闪过一丝鄙夷。</p><p>“贪生怕死，道心蒙尘！尔等就留在此地，与凡人为伍，静待吾等佳音吧！”</p><p>许多正道修士而言，“道心”比“性命”重要。</p><p>这也就是为什么，这么多灵界真仙大能都是“嗜血观众”。</p><p>修仙者如果让自己的道心蒙上尘埃，很容易在突破境界时“想不开”，渡劫失败。</p><p>凌云圣皇不再理会，对着愿意同行的血手屠魔、玄冰尊者等人一挥手：“吾辈修士，当勇猛精进！岂能因一时境界跌落而畏首畏尾？走！”</p><p>“走！”血手屠魔低吼一声，一脚踹开挡路的扭曲课桌。</p><p>两个小时后，体育馆方向骤然亮起惨白光芒，隐约传来惊恐咆哮和天地震颤的恐怖波动。</p><p>留在教室的“邪道派”几人，脸上非但没有担忧，反而露出了“果然如此”、“吾道不孤”的庆幸表情。</p><p>苟老九甚至得意地又嚼了一颗丹药。</p><p>“看吧！老夫说什么来着！”</p><p>他含糊地嚷道，向全世界人民证明自己算无遗策。</p><p>只是那眼神深处，看着窗外体育馆如同巨大白色灯笼般亮起的方向，也悄然掠过一丝难以察觉的恐惧。</p><p>——那规则波动，让他灵魂深处那点真仙残魂都在颤栗！</p><p>这“仙界”的怪谈，似乎比灵界的魔头……更不讲道理。</p><p>……（时间回到20分钟前）……</p><p>走廊里，雾气比之前稀薄了许多，这是杨帝消化眼珠的副作用。</p><p>但依旧弥漫着令人不安的阴冷。</p><p>墙壁和地面，残留着战斗的痕迹和干涸的血污，这是之前大能们争抢座位时留下的。</p><p>零星有几个红袖章志愿者在艰难地引导疏散学生。</p><p>看到这群气势汹汹、明显“不正常”的学生冲出来，都赶紧躲开。</p><p>一行人目标明确，直奔体育馆方向。他们速度不快，但步伐沉稳，带着明知山有虎偏向虎山行的决绝，或者说傲慢。</p><p>沿途经过的教室窗户后，不少学生和老师都看到了这支奇怪的队伍。</p><p>“那是……高三零班的？他们要去哪？”</p><p>“妈耶，他们身上在发光？！”</p><p>“对，那个人眼里真有红光，太中二了……”</p><p>“疯了！广播说要等师长带队啊！”</p><p>议论声被他们抛在身后。</p><p>他们停在由教师和志愿者组成的“体育馆”的探路队前。</p><p>探路队身穿荧光绿的工作服，都携带突击步枪冲锋枪，颇为显眼。</p>
