# 结束了？

<p>稷海、抡敦、开骆、扭腰客、喵斯科……</p><p>一个接一个令人闻风丧胆的规则怪谈领域，被那个自称“白杨大帝”的存在，以最蛮横、最直接、最不讲道理的方式，单枪匹马踏破粉碎，彻底湮灭在档案资料记录中！</p><p>有人说，他的行动模式冷酷高效，如同设定好程序的杀戮机器T-800。</p><p>有人说他的力量强大到无视规则逻辑，生命力凶猛过小强，更像是T-1000。</p><p>（T-800和T-1000都是终结者系列中的机器人型号，实力强大。尤其是T-1000，理论上能单杀一支装甲师）</p><p>但所有人都承认，人类曾经节节败退。</p><p>这点从他们对怪谈领域的“等级命名”，可以窥见一斑。</p><p>蓝星人类曾经用EDCBA五个级别，表示怪谈的困难程度逐步递增。</p><p>后来，出现一个比A级怪谈领域更逆天的超级怪谈，于是人们将等级拓展到S。</p><p>之后是SS，SSS……</p><p>到最后……发展出足足15个S！</p><p>那是一段人类与诡异力量拉锯数十年，牺牲无数，防线节节败退的黑暗时代，同时也是可歌可泣的悲壮岁月。</p><p>直到“三方势力的孩子”白杨大帝横空出世。</p><p>仿佛一道横空出世的霹雳，骤然撕裂黑暗！</p><p>压抑已久的希望，混合着对那未知力量的敬畏甚至恐惧，在全球每一个角落爆炸开来。</p><p>街头巷尾，酒吧军营，秘密基地的指挥室，幸存者聚集的避难所……</p><p>人们攥紧拳头，盯着屏幕上模糊的影像或简短的战报，注视社交平台中的全球直播，眼中燃烧着前所未有的光芒。</p><p>一个名字，一个代号，如同划破长夜的利剑，深深镌刻在这个被诡异蹂躏的世界之上：</p><p>白杨大帝！</p><p>他是救世主。</p><p>他是清道夫，是终结者。</p><p>是以绝对力量，宣告终界诡异的——白杨大帝！</p><p>大帝出现的时机很微妙。</p><p>彼时，虽然某神秘东方大国社会还算比较稳定，但对于全蓝星大部分国家和地区来说，社会已经因诡异而接近动乱崩溃边缘。</p><p>当白杨大帝如同人形天灾般，在全球各地肆虐，以匪夷所思的方式强行撕碎一个个令人绝望的规则怪谈领域时。</p><p>蓝星社会，正在寻求一个既懂破坏、更懂建设的领导者。</p><p>在全人类因杨帝，而充斥巨大的震撼与狂喜之余，也陷入了短暂的权力真空与秩序混乱。</p><p>旧的体系在诡异的冲击下早已千疮百孔，新的力量格局尚未形成。</p><p>恐慌、投机、地方割据的苗头开始滋生，人类后方的凝聚力面临严峻考验。</p><p>是为时势造英雄，而非英雄造时势也。</p><p>在这个微妙而危险的时刻，另一个身影，以一种截然不同的方式，登上了历史舞台。</p><p>她没有撕裂空间降临的威势，也没有一拳破灭领域的狂野。</p><p>她出现得低调却高效，仿佛从盐水湖泊中精准析出的结晶。</p><p>她自称为——万古鱼尊。</p><p>与她同行的，是一支沉默、精密、行动如一的部队。</p><p>它们不是血肉之躯，而是闪烁着冰冷金属光泽、搭载着远超当前蓝星科技水平武器的人形战斗机器人。</p><p>它们结构精妙，行动间带着一种非人的协调感，机体外壳上，统一喷涂简洁而充满未来感的标志，表明它们隶属于同一支军队。</p><p>万古鱼尊领导的“攻壳机动队”。</p><p>万古鱼尊的出现并非偶然。她似乎对蓝星各地残存，尚未被白杨大帝“光顾”的中小型怪谈领域，以及那些趁乱崛起、利用诡异力量或混乱局势作恶的人类势力，有惊人的情报掌控力。</p><p>她的“攻壳机动队”在全球范围内同步展开行动，对以上种种展开外科手术般的精确打击。</p><p>她的战略极其宏大，只有在专业领域经营数十年的专家团队，才能从她的行动中窥见一丝端倪：</p><p>第一步，后方肃清与秩序重塑。</p><p>第二步，残存怪谈的定点清除。</p><p>第三步，全球力量统合，完成蓝星人类资源整合与后勤保障。</p><p>攻壳机动队以雷霆手段，剿灭依托小型怪谈领域或混乱建立起来的非法武装、邪教组织、掠夺者团伙……</p><p>万古鱼尊以个人魅力以及团体的信念宗旨，高效联络、整合了全球残存的政府机构、科研力量、抵抗组织以及民间能人异士……</p><p>她建立了一套高效的后勤网络，将全球残存的工业能力、科研资源，乃至回收抢救得到的怪谈残留物，都纳入统一调配……</p><p>万古鱼尊始终笼罩着一层神秘的面纱。</p><p>她通常通过全息投影出现在联盟会议或公众视野中，身影朦胧，声音经过处理，带着一种非人的空灵与绝对理性。</p><p>她的“攻壳机动队”如同她意志的延伸，沉默而强大。</p><p>白杨大帝的每一次惊天动地的胜利，都为万古鱼尊的整合与反攻扫清了最大的障碍，注入无与伦比的信心与凝聚力。</p><p>万古鱼尊稳定后方、肃清中小威胁、整合全球资源，又为白杨大帝提供了近乎无限的后勤保障和无需分心他顾的战略环境。</p><p>终于，最后一个被标记为“S+15”级的规则怪谈领域——位于百慕大三角海底的“变化之海·迷宫回廊”，被白杨大帝以某种方式破解。</p><p>全球迎来了久违的、真正的和平曙光。</p><p>白杨大帝在完成这最后一击后，如同他来时一样，再次神秘消失，只留下一个关于泡面战神的传说。</p><p>万古鱼尊并未随着和平的到来而隐退。</p><p>她领导的“神圣人类联盟”开始了漫长而艰巨的战后重建工作。</p><p>一部分攻壳机动队从杀戮机器，转型为工程大队、救援先锋和秩序维护者。</p><p>世人惊觉，这支军队不但是战斗团队，而且也是生产和建设团队。</p><p>过去，这片大地也曾有过一支类似的军队，但在诡异降临后，他们筑成血肉长城，抵挡住了第一波最凶猛的诡异入侵，将近百分之五十的部队被打得取消番号。</p><p>战后十年，一位曾深度参与“攻壳机动队”核心程序维护的工程师，在整理浩如烟海的战时数据备份时，发现了一段被多重加密、隐藏在底层冗余代码中的日志记录。</p><p>「鱼尊……是……杨帝……」</p><p>其中，“杨帝”被认为指“白杨大帝”。</p><p>这一发现引发了小范围的秘密研究。</p><p>紧接着，语言学专家在分析万古鱼尊发布的所有公开指令和加密通讯的底层韵律时，意外地发现其“情感基模”，尽管极其微弱，却与当年江城二中门口，白杨大帝面对全球直播时那看似胡扯却暗藏玄机的讲话节奏，存在统计学上无法忽视的关联！</p><p>最关键的证据，来自龙组尘封的档案。</p><p>当年江城事件后，龙组曾秘密收集了白杨大帝短暂停留区域的所有物理残留物。</p><p>其中，包括一根他用过的、最普通的塑料泡面叉子。</p><p>龙组动用了一件“S+14”级别的怪谈副本掉落道具。这件道具和因果律有关。</p><p>结果发现，这根泡面叉子，和“万古鱼尊”存在极大的因果联系。</p><p>最后，鱼尊的营养师冒着杀头的风险，提取化验了泡面塑料叉子上沾有的唾液，化验了其基因序列，并证实——与万古鱼尊的基因序列基本相同。</p><p>只是性染色体有所变化。</p><p>当这些零散的、跨越时空的证据碎片，被一群执着的研究者拼凑在一起时，一个石破天惊的结论终于浮出水面：</p><p>白杨大帝与万古鱼尊，那看似截然相反、一矛一盾、一狂放一理性的两位救世主。</p><p>他们是同一个意志，同一个存在。</p><p>他们是同一人。</p>
