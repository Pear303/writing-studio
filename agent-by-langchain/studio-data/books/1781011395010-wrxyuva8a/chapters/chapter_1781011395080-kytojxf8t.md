# 失忆的传奇术士？

<p>杨帝能感知到环境中“灵”的流向。</p><p>所以，他不需要过多输出自身的“灵”，就能以极小的代价干预现实。</p><p>而异世界的术士，认为“灵”是干柴堆，需要用他们消耗大量自身的“灵能”去点燃。</p><p>那是因为，他们没有清晰地看见——环境中的灵，并不只是纯粹的干柴堆。</p><p>“木柴”之中，已经蕴含了“纯天然打火机”，不需要用人为的手段去点火。</p><p>但一般人看不见。</p><p>只有像杨帝这般，将超过10%潜意识上浮至思维表层，从而全面增强眼耳鼻舌身意六识，才能隐约感知到“灵”的存在。</p><p>他越发觉得，这些异界术士的施法方式，简直就是脱裤子放屁。</p><p>环境中的“灵”蕴含着巨大潜力，他们却只能消耗自身的“灵能”去激发。</p><p>这是肉体凡胎的局限性。</p><p>……</p><p>目睹杨帝“掌心‘嗖’地蹿起炽烈火焰”。</p><p>瑞弗维尔已经震惊得无地从容瞠目结舌，惊心骇目动地惊天，恐怖如斯如斯恐怖！</p><p>他怎么也没想到，这个失忆的杨帝，居然能默声念咒+瞬发法术。</p><p>要知道，即使是在术士中，能够默声施法就已经是罕见的天赋。</p><p>瞬发法术亦是凤毛麟角，许多大术士穷极一生，成耄耋老头了才能做到！精灵除外，他们太命长了。</p><p>瞬发、默声，两种才能居然同时在一个看起来很年轻的小伙子身上出现？</p><p>瑞弗维尔围着杨帝转了几圈，上下打量着这个看起来像男性人类的物体。</p><p>“或许他在失忆前，是个牛逼哄哄的传奇法师……完了，请神容易送神难。”</p><p>瑞弗维尔心里想着，咽了口唾沫。</p><p>原本以为这杨帝只是个名不经传的冒险者，误入末日火山，掉进湖水失忆罢了。</p><p>没想到，是个「传奇法师」级别的人物！</p><p>国王叮嘱过他，要低调。</p><p>虽然瑞弗维尔从没听说过“杨帝”这号大能，但还是不敢轻慢，对方实力就摆在那！</p><p>越想越觉得事情不简单，心中的猜测如同脱缰的野猪般肆意驰骋——</p><p>一个能默声瞬发法术的传奇法师，怎么会无缘无故出现在末日火山的湖边，还失忆了？</p><p>背后隐藏着什么巨大的阴谋？教廷在这其中扮演什么角色？</p><p>难道这是圣光教廷的阴谋？他们故意让这位传奇法师失忆，再安排他出现在我身边？</p><p>如果真是这样，那我现在的一举一动岂不是都在他们的掌控之中？</p><p>可看杨帝的样子，又不像是演戏……</p><p>但万一他演技高超，连我都被蒙骗了呢？</p><p>不对，与其大费周章安排人到我身边，为啥不一巴掌将我轰杀至渣？</p><p>有一种可能——他们要借着“瑞弗维尔”这个窗口，对国王传递错误情报？</p><p>哪种可能性是正确的？</p><p>瑞弗维尔的手心已满是汗水。</p><p>他努力让自己镇定下来，却发现双腿还是忍不住微微颤抖。</p><p>现在的他，放进冒险小说里，应该能勉强活过三页了。</p><p>但还是活不过一章。</p><p>“不行，我得小心行事。既不能得罪他，又不能让他察觉到我对他的怀疑。可要是他真的别有用心，我该如何应对？以他的实力，我根本不是对手！”</p><p>想到这里，瑞弗维尔深吸一口气。</p><p>右手不自觉地摸向腰间的石头雕塑。</p><p>挤出一丝比哭还难看的笑容，对杨帝说道：“杨……杨帝啊，你这能力可真是惊人，说不定恢复记忆后，会是这世上屈指可数的强者呢！哈哈……”</p><p>杨帝看着瑞弗维尔那副紧张又怪异的模样，心中暗自疑惑。</p><p>这旅商神色不对，很不自然。发现我不属于这个世界了？</p><p>或许是我刚才的施法行为太过惊世骇俗，把这旅商给吓到了？</p><p>应该是这样吧。</p><p>杨帝表面上依旧装作一副虚弱迷茫的样子：“真？我还是什么都不记得。瑞弗维尔，你怎么了，脸色看起来不太好。”</p><p>瑞弗维尔连忙摆手，说道：“没……没事，可能是这末日火山的环境有些压抑，让我有些不舒服。咱们继续赶路吧，早点离开这是非之地。”</p><p>二人各怀鬼胎，仿佛隔了层可悲的厚障壁，但还是继续上路了。</p><p>杨帝决定打破这令人尴尬的沉默。</p><p>他举起手中依旧不断扭动的暗红色史莱姆，好奇：“瑞弗维尔，这史莱姆为什么暗红色的，内部还这么烫？我刚在湖底被它缠住脑袋，差点没被烤熟。”</p><p>这话题倒是能让气氛不那么紧绷。</p><p>瑞弗维尔微微放松了几根神经。</p><p>他清了清嗓子，解释：“这是‘熔岩史莱姆’，一般栖息在靠近火山的区域，像咱们所在的末日火山附近就常有它们的踪迹。”</p><p>“湖底也有熔岩史莱姆？”</p><p>“这……它们喜欢生活在高热环境中，也许湖底还有尚未耗尽的地热。”</p><p>比如热液喷口。</p><p>接着，瑞弗维尔又解释了熔岩史莱姆怎么发热的。</p><p>很神奇，有种利用灵能发热、制造“电暖炉”的意味。</p><p>法术理论认为，灵能流动的形状决定功能，顺序规定方向。</p><p>瑞弗维尔见杨帝对熔岩史莱姆如此好奇，看起来真的失忆严重。</p><p>于是主动深入讲解起来，刷杨帝的好感度：“史莱姆的生成原理，其实和灵能的流动与聚合息息相关。”</p><p>他抬手指向四周奇异的火山地貌：“像末日火山这种恶地，灵能一直处于活跃且不稳定的状态。周围灵能被搅动，在亿万次碰撞中，恰好按照特定的模式和规律相互交织、融合，逐渐赋予了一些物质以生命形态，‘魔物’便由此诞生。”</p><p>“所以……魔物的诞生是巧合？”</p><p>“先天的魔物是‘巧合’。但大部分魔物，其实就是掌握了某些灵能术式的动植物，和我们人类本质上差不多。”</p><p>瑞弗维尔转头看向杨帝手中的熔岩史莱姆，接着说：“而史莱姆，是最底层、最低级的魔物种类，是通过‘巧合’随机生成的。”</p><p>最低级，嗯没错，非常网游。</p><p>出新手村前，都是打史莱姆刷级的。</p><p>瑞弗维尔指出：史莱姆的构造相对简单，灵能流动模式也较为基础。</p><p>通常情况下，史莱姆是由一些游离的灵能和周围的物质偶然结合而成。</p><p>它们没有复杂的思维和高级的行动能力，更多是凭借本能行动。</p><p>依靠吸收周围环境中的灵能或者特殊物质，来维持浑浑噩噩的生命。</p><p>所以，环境不同，诞生的史莱姆也不同。</p><p>比如除了熔岩史莱姆，还有水史莱姆、毒史莱姆等等。</p><p>水史莱姆，简称水姆！是不是很冷（</p><p>“就拿熔岩史莱姆来说，它们长期处于火山附近高热的灵能环境，身体内灵能流动逐渐适应并模拟了这种高温环境下的能量模式，所以才会呈现出高热特性。”</p><p>瑞弗维尔知识甚是渊博，侃侃而谈。</p><p>杨帝：“先生懂得真多，像是，嗯，图书馆馆长一样学识渊博。”</p><p>他只是摆摆手，说：“啊哈哈旅行商人嘛，走过的路多，见过的也多，学识也就逐渐和图书馆馆长一样丰富了……”</p><p>瑞弗维尔为了转移对方注意力，薅了薅杨帝怀里的熔岩史莱姆。</p><p>这魔物看起来生无可恋的模样。</p><p>史莱姆是非常低级的生物，还不足以诞生思维，甚至连“动物本能”也非常浑噩。</p><p>但是不知为何，杨帝在这史莱姆身上感受到一种——那年高考语文阅读题里“咸鱼眼中闪烁着诡谲的光”的感觉。</p>
