# 君士叹顶堡

<p>「在那台废弃的盾构机中，找到了尚未被完全破坏的硬盘数据，其中还有零星能够恢复读取的数据。」</p><p>「经过拼凑和分析，我再度成功为这位数字生命恢复了一定程度的数据记忆。」</p><p>59改简简单单轻飘飘一句数据恢复，貌似要攀出很黑的黑科技，才有可能实现。</p><p>具体是通过操控微观粒子的运动方向，让物理损坏的存储介质在热力学层面“熵减回溯”，逆着混乱趋势重新有序聚合。</p><p>就像把打碎的杯子反向还原，从而恢复事故前的数据状态。</p><p>总之就是很黑、特别黑的黑科技。</p><p>相当于掌控了部分时间法则。</p><p>据他介绍，这大概是文明等级划分第四阶段“超弦时代”才有能力研发出的技术。</p><p>「但是，硬盘中的数字生命意识，即‘土皇帝’存在第一类量子精神活动，其底层架构呈现混沌数学模型。」</p><p>「所以，任何超过80%的还原度尝试，都会触发大规模数据丢失。」</p><p>「我只能将其数据还原至78.9%」</p><p>任何事物，只要沾上什么量子力学，总会变得反直觉，奇怪呢。</p><p>阿巴的鱼鳍不安地摆动：“你是说，这老古董的意识是个老薛的硬盘？”</p><p>“老薛”是上一个宇宙的典故。传说，老薛将鱼放进了水族箱，此时，鲈鱼在水族箱中同时处于生与死的叠加状态。</p><p>只有当你掀开水族箱盖子，才能知道里面的鲈鱼是活是死。</p><p>但“掀开盖子”这一行为，也导致了更多信息不可逆转地丢失。</p><p>即“鲈鱼有可能活也有可能死”这一信息的丢失。</p><p>“信息”的定义是对不确定性的消除。但在59改-守望者文明看来，“不确定性”本身也能成为信息的一部分。</p><p>59改点点头「当我们观测某段记忆，其余部分就会随机重组，就像在试图捕捉液态汞，抓得越紧，散得越快。」</p><p>“捕捉液态汞是什么感觉？”</p><p>“没试过，感觉就算我是真仙资质，也会汞中毒。”</p><p>青丘白璃和阿巴显然不可能汞中毒，她们只是觉得这种液态金属滑溜溜，抓不住，很容易就从指尖溜走，和史莱姆一样恶心。</p><p>59改说道：</p><p>「根据恢复后的数据，目标似乎来自于，十万大山最高的一座山峰‘君士叹顶’。」</p><p>他的炮塔微微转动，虚拟投影在会议厅中央展开一片扭曲、闪烁的山体内部景象。没想到这不仅是炮管，还可以是投影仪。</p><p>画面中，十万大山最后那座仿佛要刺破苍穹的巨型山脉“君士叹顶”的底部，被粗暴地凿开了一个巨大的、流淌着粘稠黑暗的洞口。</p><p>洞口深处，并非天然岩层，而是布满了人工开凿的痕迹——粗糙的甬道、刻满亵渎符号的墙壁。</p><p>以及令人极其不适、油腻的暗黄色反光。</p><p>「在目标‘土皇帝’的记忆中，君士叹顶的深层结构存在大型人造腔体，是为‘密教基地’。」</p><p>「这座秘密基地中，那些邪教信徒，信奉一种名为‘阴伏流煞’的存在。」</p><p>59改的声音毫无波澜。</p><p>但在投影中，那些甬道阴影里若隐若现、裹着仿佛浸透了某种油腻污渍的肮脏黑袍的身影，以及他们无声膜拜的姿态，却透着深入骨髓的邪异。</p><p>一个邪教基地，藏在君士叹顶内部。</p><p>还有非常经典的黑袍+佝偻+关灯省电！</p><p>而自称天元神皇的土皇帝，就从那儿来。</p><p>更具体来说，他是从邪教基地逃出来，随后“附身”至盾构机上，试图逃出生天。</p><p>众人逐渐凑出事件全貌。</p><p>五百年的时光，十万大山的土皇帝，被邪神“阴伏流煞”扭曲，最终沦为一台锈蚀盾构机里的疯狂幽灵。</p><p>「现实通知：盾构机残骸清理完毕。火车核心系统紧急修复完成，EMP造成的物理损伤已隔离，冗余系统上线。」59改发来情报。</p><p>火车维修机器人工作非常高效。</p><p>他们退出虚拟会议厅，重回现实。</p><p>恰好，列车广播发声：「火车即将重启，感谢旅客们的等待。请坐稳扶好……」</p><p>“呜——嗡……”</p><p>一声低沉、雄浑，带着金属摩擦与巨大能量流涌动的声音。</p><p>不再是之前被EMP瘫痪时的死寂，而是钢铁巨兽复苏的喘息与宣告。</p><p>火车，重新启动，碾过铁轨发出震动。</p><p>「下一站，君士叹顶堡。」</p><p>冰冷的电子广播响起，不带丝毫感情，却像一颗石子投入了刚刚平静的湖面。</p><p>“就是那土鳖老巢头顶上盖的‘堡’？听起来就不像个正经地方，一股子过期汉堡味儿。”阿巴嘴馋起来。</p><p>汉堡包是很容易发明的美食，每个文明都会发展出类似的食物，比如陕西肉夹馍，香辣鸡腿堡。阿巴在上一个宇宙经常吃。</p><p>青丘白璃轻轻敲了下阿巴的鱼鳍：“别拿吃的打比方，君士叹顶堡可没你想的那么简单。它是离开君士叹顶隧道后第一座城市，建立在山体断层与人工加固结构上，城墙由合金浇筑，据说能抵御小型核爆。”</p><p>抵御小型核爆，对凡人来说很厉害了。</p><p>这里不是氪星，没有肉体硬抗核爆的能力。</p><p>“同时，‘君士叹顶堡’这座城市，也是归墟大帝最后出现过的地方。”</p><p>几条看似毫不相干的线索，阴差阳错地交织起来。</p><p>此刻，59改又爆出另一个大瓜：</p><p>「我已部署微型侦查单元先行渗透该区域网络，但没有发现任何异常。」</p><p>“什么？‘没有发现任何异常’？”</p><p>阿巴闭上眼，将神识笼罩整座君士叹顶峰。</p><p>确实……没有在山体内找到任何空腔，也几乎没有人造设施。</p><p>并没有什么“密教基地”。</p><p>考虑到天元神皇是500多年前的人，但在山体内部，也同样找不到古代遗迹残留。</p><p>这真是出乎意料的情报。</p><p>而勉强能算“人造地下设施”的，大概是在修筑“君士叹顶隧道”时，遗留的临时工地。</p><p>临时工地就位于山体内，一处足球场大小、三四层楼高的空腔。</p><p>工地上弃置了几台废弃挖掘机，发不出电的发电机，生锈严重的信号站和临时宿舍。</p><p>都是大约100年前剩下的。</p><p>宿舍某房间，还存有当时的工程招标书。</p><p>夕阳红旅行团，关键在于“旅行”，所以59改提出要“下车探查”，这是为了使他们团伙的行为符合组织的精神。</p><p>但在此之前，杨帝已经用神识将这处临时工地内外扫描800遍，实在找不到任何异常。</p><p>“得嘞，领导点头了！”阿巴也喜欢旅游。</p><p>在上一个宇宙，她就顾着内卷修仙，根本没有时间体验生活。</p><p>“不过，如果有其他新情况，我们就不去山体内部的临时工地了，毕竟里面真的什么都没有，最多也就闲逛……”</p><p>“好叭老大……对了铁罐，那坨‘赛博精神病’皇帝呢？总不能揣兜里带下去吧？万一他又在现实里抽风，抱着个电线杆子喊‘朕的龙柱’，多丢份儿啊。”</p><p>阿巴还是挺担心的。主要是担心丢脸。</p><p>「无须担忧。」</p><p>「我已在其原始数据崩溃前，完成了一次深度快照。目前，这位‘天元神皇’的意识副本，正运行于我硬件内部新开辟的‘隔离沙盒’中。」</p><p>“沙盒？”</p><p>「初始空间约为一千万平方光年，而目标最近500万平方公里则模拟十万大山基础地貌及君士叹顶形态。」</p><p>「环境参数动态调整，可满足其基本的‘统治’需求。」</p><p>59改的解释轻描淡写，仿佛在说给鱼缸换了个更大的过滤器。</p>
