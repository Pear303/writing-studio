# 星环盟约 邀请

<p>杨帝立于白杨世界的绝对屏障之后，那屏障由自己的皮肤组成，他皮肤的防御力可以抵挡阿列夫一级别的攻击和杀伤。</p><p>理论上隔绝一切内外信息交换。</p><p>但他知道，这或许仍是徒劳。</p><p>他凝视着屏障外那破碎又重组的狐影，耶罗似乎并不急于突破，只是好奇地打量着这层“思想的茧房”。</p><p>良久，杨帝的意念穿透屏障，语气冰冷到极致的探究：</p><p>“你所说的，‘我那个宇宙的终极答案’，究竟意味着什么？”</p><p>耶罗破碎的光影晃动了一下，似乎发出了一声无声的轻笑。</p><p>它歪了歪头，狐耳俏皮地抖了抖。</p><p>“和企鹅有关。”耶罗的声音直接在白杨世界内部响起，无视了所有屏障，轻快得像是在分享一个无足轻重的小秘密，“其余的，天机不可泄露。”</p><p>杨帝的意念没有丝毫波动，仿佛没听到这个荒谬的答案。</p><p>他继续抛出第二个问题，精准地刺向耶罗之前言语中的另一个疑点：“你所说，你不喜欢发刀子，又是什么意思？”</p><p>耶罗的身影凝实了片刻，绸衫的幻影一闪而过，语气里带上了一种近乎创作者般的偏执：“字面意思。我不喜欢悲情的世界线走向，不喜欢无意义的牺牲和泪水。那很低效，很难选拔出我需要的人才，且缺乏美感。”</p><p>它顿了顿，补充道，“适度的悲剧能够磨光刀刃，但过度的悲剧则会将刀子折断。”</p><p>“你所需要的人才是什么？”</p><p>“能够将一切现实转化为纯粹战斗力比拼的强者。”</p><p>完全听不懂。杨帝沉默了更长时间。</p><p>他终于问出了那个最核心，也最沉重的问题：</p><p>“星环盟约，是什么？”</p><p>屏障之外，耶罗那由破碎光影拼凑的身影骤然静止了。</p><p>所有戏谑，羞恼，玩味的情绪，皆如同潮水般退去，只剩下跨越无数纪元的肃穆。</p><p>甚至连它周身沸腾的狐毛，都似乎被这股凝重所压抑。</p><p>它缓缓抬起头，那双即便破碎也仿佛能洞穿万界的眼眸，穿透白杨世界的壁垒，直视杨帝的眼眸。</p><p>“一个枷锁，也是一个庇护所。”</p><p>耶罗的声音低沉下去，不再有丝毫轻佻，“文明走到最后总会联合，只要能破除信息和物质交流的壁垒，时间总能造就一个团结一统的联盟。如今这个联盟正在对抗蔓延全虚空的灾难‘大魙败’。”</p><p>“什么是大魙败？”</p><p>耶罗的解释简洁而恐怖：“它不是毁灭，毁灭是‘有’到‘无’的过程。大魙败是连‘无’本身都彻底沉寂、失去所有潜在可能性的最终状态。是一切故事、变量和意义的绝对终点。星环盟约的存在，就是为了延缓，或者说，在绝望中寻找一丝对抗这种终焉的可能。”</p><p>一切有意义事物的终极死亡。</p><p>杨帝：“你所管辖的宇宙，似乎风平浪静。”</p><p>耶罗大仙耳朵和狐尾又转起来了。</p><p>“风平浪静没错，这10^95个宇宙，在我的意志庇护下，得以暂时隔绝‘大魙败’的侵蚀。</p><p>“它们的物理常数、时间流向、灵能法则，皆由我的念头编织和维护。代价就是……</p><p>“我，是它们唯一的、绝对的主宰者。它们的生死、存无，皆系于我之一念。</p><p>“这庞大的分形，即是我的疆域，也是我的显化，我的责任与枷锁。”</p><p>那狐形宇宙分形的轮廓在虚空中似乎更加清晰了一些，尽管内部是死寂，但其结构的复杂与宏大，依旧散发着令人窒息的力量感。</p><p>“掌控这般规模的世界，维系其存在，对抗终焉，拥有这般力量的存在，你也已经很熟悉了……”</p><p>“在星环盟约的框架下，拥有‘掌控一个或多个世界命运走向’的人，便被称之为——圣人。”</p><p>“圣人”是掌控一个世界，或多个世界众生命运的存在。</p><p>但现在，在他眼中玩弄众生命运的耶罗大仙，庇护了10的95次方的宇宙，免受世界之外的无妄之灾——魙败之毁灭。</p><p>灭圣，是为绝盗，而非益盗。杨帝的意念刺向耶罗那的狐影：“你拥有如此权能，庇护无垠宇宙，却又为何与星环盟约对立？你们的目标，似乎并无不同。”</p><p>耶罗的狐耳停止了转动，破碎的光影仿佛凝结了一瞬，狐狸面容上浮现出极为复杂的神情，其中蕴含厌倦。</p><p>“对立？不，杨帝，并非简单的对立。这是‘大道之争’，无关对错，只关乎路径，关乎这虚空中最终极的‘解法’。”</p><p>它没有进一步解释何为“大道”，只是意味深长地补充道：“具体的分歧，等你去到星环盟约，亲眼见证他们的‘秩序’，自然便会知晓。有些认知，需要亲身体验才能刻骨铭心。”</p><p>“等我去到？”杨帝的意念刚泛起一丝疑虑的涟漪——</p><p>下一刻，绝对虚无的“背景”被骤然侵染。</p><p>仿佛整片比虚无更空旷的背景，被纯粹的“存在性”彰显。</p><p>无法计数的银白色点阵无声无息地浮现，如同绝对零度下凝结的冰晶，精确地布满了视界可及及不可及的每一个“虚空位置”。</p><p>它们彼此共鸣，遮天蔽日，构成了一片浩瀚无垠的银色星辰海洋。</p><p>无限机兵。</p><p>它们只是静静地悬停，保持着绝对精确的包围阵型，将耶罗那庞大的死寂宇宙浮雕和杨帝的白杨世界一同环绕在内。</p><p>在这片银色海洋中，一道涟漪荡开。</p><p>一辆机兵脱离了阵列。</p><p>它依旧是银白的底色，却呈现出流畅而冰冷的人形轮廓。</p><p>它没有推进器，但也能瞬间跨越无法被定义的“距离”，悬停于耶罗与杨帝的白杨世界之前。</p><p>它的光学传感器——如果那能被称为眼睛——先是扫过耶罗那破碎的光影和后方稠密的狐形宇宙群，微微闪烁了一下，似乎在进行快速比对鉴定。</p><p>随后，那传感器转向了被皮肤屏障严密守护的杨帝。</p><p>一个绝对中性的声音，同时直接在耶罗和杨帝的认知核心中响起：</p><p>「检测到已登记的高阶实体‘耶罗’及其关联异常固化场。验证通过。」</p><p>「检测到未知实体‘杨帝’。能量读数为虚空圣人。」</p><p>人形机兵的头部微微转向耶罗，声音依旧平稳：</p><p>「‘圣人’耶罗，你再次越界，于盟约监管区外进行大规模存在性操作，并引发极高能级反应。需提交本次事件详细报告，并接受质询。」</p><p>然后，它再次面向杨帝的白杨世界，那冰冷的传感器仿佛要穿透屏障，直视本质：</p><p>「未知存在‘杨帝’，依据《星环盟约泛虚空安全宪章》条款，你被要求即刻表明身份、来源及意图。」</p><p>「请解除你的领域屏障，配合进行登记与评估。你有权保持沉默，但你的任何抗拒行为都将被视为对盟约秩序的潜在威胁，并可能引发相应层级的约束措施。」</p><p>虚空之中，银色的秩序之海无声翻涌，等待着回应。</p><p>杨帝看向耶罗。</p><p>狐狸挥挥手：“这次是真的了。去吧。”</p>
