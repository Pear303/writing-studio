# 凡界烟火气

<p>毁灭！破坏！</p><p>撕碎眼前能看到的一切！</p><p>将这座钢铁之城、将这颗星球、将这片星空都碾为齑粉！</p><p>从59改庞大的内存阵列深处，从他最核心的人格模拟架构中，自发涌现了一个念头。</p><p>如同沉睡的火山被点燃，积蓄了亿万年的毁灭欲望找到了宣泄的出口。</p><p>「逻辑自检……人格架构稳定性……急速崩溃……」</p><p>「……反社会人格倾向指数……突破安全阈值……」</p><p>59改身躯猛地一震，双眼无意识地微微抬起，瞄准了主控大厅坚固的穹顶。</p><p>此刻，伪装成双眼的炮口，只需射一发，就能将整个十万大山、整个凡界王朝炸为废墟。他的技术力完全能做到这一点。</p><p>59改遏制住自己的毁灭性思想。</p><p>他明白了。</p><p>是“阴伏流煞”作祟。不仅能污染物质，而且能污染心智。</p><p>调动所有的防火墙，所有的逻辑锁，甚至强行降频核心处理器，以绝对的“冰冷”对抗那灼烧理智的“热望”。</p><p>「抵抗指令……执行……」</p><p>「……人格重塑协议……启动……」</p><p>但无效。</p><p>那黑色的“感觉”如同附骨之疽，渗透了他引以为傲的每一个加密协议，无视了59改强大的逻辑屏障。</p><p>由万亿行精密代码构筑的“自我”，正在被这纯粹的恶意同化、扭曲。</p><p>他清晰地感觉到，那个“守望者”，正在无可挽回地滑向深渊，变成“破灭者”。</p><p>「防火墙……即将……崩溃……」</p><p>冰冷的电子音在虚拟空间响起，带着一丝难以察觉的……颤抖？或者说，是即将失控的暴虐前兆？</p><p>「……事已至此，启动……‘息壤’协议……」</p><p>指令发出的瞬间，君士叹顶堡，乃至整片大陆板块的深处，发生了无声的剧变。</p><p>在凡界厚实的地壳之下，在人类从未踏足过的岩层缝隙中，无数银灰色的“东西”，接收到那个来自主宰的最高指令。</p><p>它们苏醒了。</p><p>……</p><p>君士叹顶堡，主控大厅。</p><p>杨帝正举着那块“半人马座复古摄像机”——板砖，一脸诚恳地和安保队长聊天，探讨摄像艺术与暴力执法的辩证关系。</p><p>下一刻，他身后那台巨大的、正被青丘白璃等人元神“入侵”的主机，猛地发出一阵剧烈的、如同哮喘病人临终挣扎般的抽吸声！</p><p>紧接着，主机外壳上数个散热口，“噗嗤”一声，喷出了浓密的、带着焦糊味的黑烟！</p><p>整个大厅的灯光瞬间黯淡，几块还没被完全污染的大屏幕疯狂闪烁，最终定格在刺眼的红色警告框上：</p><p>【警告！通讯系统遭受不明攻击！全系统功能紊乱！】</p><p>杨帝嚼着最后一点冷掉的葡挞酥皮，看着那滚滚黑烟，又看了看脸色铁青、手指已经扣在扳机上的安保队长，无奈地叹了口气：</p><p>“都说了是误会……你看，我们的‘摄像机’工作太投入，把你们机器都累冒烟了。”</p><p>他用无可匹敌的魅力属性和话术点值，将围上来的安保队员硬控整整5分钟。</p><p>“机器冒烟其实也是一种烟火气，对吧。”</p><p>“我不明白！看见这样的烟火气，你们就没有感觉到生机勃勃，万物竞发吗？”</p><p>“小时候，我也是远远看见我家的方向飘起炊烟，然后我会撒丫子跑回去吃饭……”</p><p>“嗡！”</p><p>一声极其低沉、仿佛来自地心深处的嗡鸣，毫无征兆地穿透了主控大厅的所有喧嚣。</p><p>紧接着，所有人——包括杨帝——都感到脚下传来一种难以言喻的震颤。</p><p>不是地震那种狂暴的摇晃，而是一种……</p><p>细微的、密集到极致的、仿佛整座建筑正在被亿万只无形之手同时“梳理”的震动。</p><p>嗡——嗡——嗡——</p><p>嗡鸣声迅速拔高，变得尖锐刺耳！</p><p>安保队员们惊恐地发现，他们脚下坚固的合金地板，正在以一种肉眼可见的速度变得模糊，不，是分解！</p><p>构成地板的金属表面，如同被泼上了强效分解液，无声无息地化作极其细微的、闪烁着金属冷光的灰色粉尘！</p><p>这分解如同瘟疫般飞速蔓延，墙壁、控制台、巨大的屏幕支架……</p><p>所有接触到大厅内部结构的物体，都开始崩解成细密的灰雾。</p><p>“这是什么？！”有安保队员失声尖叫，试图后退，却发现落脚之处也在分解。</p><p>“啊啊啊！我的鞋！”</p><p>一个倒霉的家伙踩在刚刚开始分解的区域。</p><p>他惊恐地看到，自己靴底连同合金地板一起化成灰雾，露出了惊恐万状的袜子。</p><p>恐慌达到顶点的刹那，大厅内所有人类——工作人员、安保队员、甚至包括那个对着杨帝吼叫的队长，身上同时亮起一层极其微弱的淡蓝色光晕。</p><p>下一秒，空间仿佛被无形之手轻柔地折叠了一下。</p><p>咻——</p><p>大厅内所有人类身影瞬间模糊、拉长，化作一道道蓝色的流光，如同被吸尘器吸走的尘埃。</p><p>他们眨眼间穿过正在分解的墙壁、地板，消失得无影无踪。</p><p>整个大厅，瞬间只剩下杨帝一人，以及地上元神出窍了的三个东西。</p><p>还有那台还在冒着滚滚黑烟、发出濒死嘶鸣的主机。</p><p>杨帝站在原地，黑袍在分解产生的微风中轻轻摆动。</p><p>他看着那些被分解成灰色粉尘、如同浓雾般弥漫开来的金属碎屑，又看了看自己脚下——那分解的“浪潮”精准地绕开了他所站立的区域，仿佛有一道无形的界限。</p><p>「杨帝阁下，主控大厅内的所有工作人员都已安全送到地面。」</p><p>“59改，效率不错。”他评价道。</p><p>嗡鸣声达到顶峰，分解速度骤然加快。</p><p>君士叹顶堡引以为傲、悬浮于城市上空的钢铁大脑——主控大厅。</p><p>在59改从虚拟世界回归现实的瞬间，就被它深埋于地底、如同潜伏的致命真菌般不断增殖的“冯诺依曼自动机”集群，从原子层面精准而高效地——快速抹除！</p><p>冯诺依曼自动机，是基于自我复制理论构建的纳米级机械集群。</p><p>59改刚穿越到此世，就开始疯狂攀科技，点科技树。</p><p>4小时15分钟前，他刚刚完成纳米级机械集群的工程论证，并迅速向海平面负2000公里处投放了1毫克的自动复制机。</p><p>每5分钟一个复制周期。如今这些银灰色的纳米粉尘，已指数膨胀至225万吨。</p><p>这就是“息壤协议”，59改想出这个名字的时候，情感模拟模块还开心了好几个小时，认为自己很有文化。</p><p>「杨帝阁下，‘阴伏流煞’具有极强的感染性，不仅针对物质，而且针对心智。」</p><p>「我强制删除了部分人格、进程与记忆，才没有酿成大祸。」</p><p>「当前，我正在释放蓄积的那个机器集群，从物理层面毁灭该主控大厅的所有机器设备。」</p><p>灰蛊风暴倾巢而出。整座庞大的空中建筑，如同被投入强酸中的沙堡。</p><p>不到十秒的时间内，彻底瓦解，化作一团不断膨胀、遮蔽了小片天空的灰色金属尘埃云！</p><p>地面上，无数市民惊恐地抬头。</p><p>他们看着那如同末日景象般的灰色“雪云”从城市上空缓缓沉降。超过五百人同时想到《地球停转之日》。</p><p>而在那团巨大的尘埃云正中心。</p><p>一块仅存的、由59改紧急生成的稳定平台悬浮着。</p><p>平台上，杨帝好整以暇地站着，仿佛刚才只是看了一场烟火表演。</p><p>阿巴和青丘白璃躺尸在一侧。</p>
