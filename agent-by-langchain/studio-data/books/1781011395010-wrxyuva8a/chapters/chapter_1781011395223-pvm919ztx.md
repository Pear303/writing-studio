# 了却生前身后事

<p>市区的气息越来越浓。</p><p>达文西——万业狐狸所住的城市……没错，仍然是“稷海市”。</p><p>路边开始出现零星的民居，然后是成片的公墓。灰色的墓碑在晨雾中若隐若现。</p><p>一旁的红底黄字写着“给逝者一个美丽的安息地”，意思是不要在坟墓前乱丢太多垃圾。</p><p>就在公墓边缘的排水沟旁，一点醒目的红色吸引了杨帝的目光。</p><p>一颗被遗弃的，尚未燃放的大地红鞭炮，红色的纸壳沾着泥水。</p><p>他弯腰捡起。</p><p>目光扫视，不远处一个早起打扫公路和街道的清洁工，正惊愕地看着这个从荒地方向走来、身上还沾着不明灰烬的年轻人。</p><p>妈呀，大粽子？！我扫这墓这么多年，终于让我碰上了？</p><p>杨帝径直走过去，停在清洁工面前。清洁工下意识地后退一步，警惕地看着他。</p><p>“阿伯，借个火。”他说。</p><p>清洁工寻思着，僵尸应该是怕火的，而此人主动来借火，那大概率不是僵尸了吧。</p><p>目光在杨帝平静得过分的脸和他手中的鞭炮之间来回扫视，下意识地摸出打火机递过去，结结巴巴：“你要干嘛？”</p><p>杨帝接过廉价的塑料打火机，“嚓”一声点燃火苗。</p><p>然后做了一件让路人瞳孔瞬间收缩到针尖大小、灵魂几乎出窍的事情——</p><p>他捏着那颗鞭炮，塞进自己嘴里！</p><p>然后用打火机，凑近露在外面的引信。</p><p>砰！</p><p>带着火药味的青烟，从他微张的嘴角和鼻孔里，袅袅悠闲地冒了出来。</p><p>杨帝的腮帮子微微鼓动了一下，像是在咀嚼什么。</p><p>然后表情挂上一副“感激不尽”的微笑，将打火机还给了公墓的清洁人员。</p><p>迈开脚步，嘴里依旧冒着丝丝缕缕的白烟，像个刚抽完劣质烟的流浪汉，若无其事地继续朝着市区走去。</p><p>用燧石在手腕上改刀花，从此皮肉刀枪不入，杨帝永久失去享受“凌迟”这一死法的机会。</p><p>在垃圾焚烧厂的焚化炉里，做他18岁开始就想做，但一直没去成的桑拿房马杀鸡。</p><p>鞭炮塞嘴里是为了引发脑震荡，此举和冲击波的传导与防御息息相关。</p><p>公墓边缘的荒草丛中，找到几株色彩鲜艳的蘑菇，生而啖之。</p><p>路过一个废弃的修车厂，找到废弃的蓄电池电解液，不知名的强碱清洗剂，一口一桶喝完。</p><p>路边有一条垂落的高压电线，太危险了，杨帝徒手将其拾起，丢到高处，让路人用电话通知市政。</p><p>每一次“自残”后，杨帝都清晰地感受到体内那抽象的“点数”在阿列夫零的层级上再次跃升，对应领域的防御被固化至无穷。</p><p>无穷之间，亦有差距。</p><p>在这个无穷灵能的世界，杨帝的无穷数值已经高于此世的无穷灵能。</p><p>他卡在阿列夫零和阿列夫一之间。</p><p>杨帝能清晰感受到，自己是高于这个世界的上级“无穷”。</p><p>来到此世，他的能力强度瞬间暴涨。</p><p>又或者说……其实到了这个世界，才显露出“维持基准态不变”这一核心能力的原貌。</p><p>他在下界时，能力都是阉割的弱化版。</p><p>而到了这个“无限”的世界，才觉醒了能力的本貌。</p><p>当他终于站在破旧的城中村公寓楼下时，身上沾染的灰烬、嘴里残留的硝烟味、以及眼神中那份非人的漠然，都与周围早起上班、买早餐的芸芸众生格格不入。</p><p>地球神州岭南省稷海市石桥街道81号9楼3号房。</p><p>——那个扑街写手，达文西的住处。</p><p>杨帝踏入达文西那间充斥着泡面与旧书霉味的出租屋。</p><p>空气仿佛凝固着原主人生最后的焦虑。</p><p>他环顾四周，狭小的空间、堆积的杂物、闪烁的电脑屏幕……</p><p>属于“万业狐狸”的记忆碎片翻涌，带着一种扭曲的熟悉感。</p><p>这里，曾是他的“造物主”在钢筋水泥森林，勉强能获得一隅安息的临时囚笼。</p><p>“安息吧……”</p><p>杨帝身形微动，甚至看不清他如何发力，空气中只留下一道模糊的残影和轻微的爆鸣。</p><p>下一瞬，他已置身于万里之外的某处荒凉戈壁。脚下是亘古不变的砂石。</p><p>他抬脚，随意地对着地面一跺。</p><p>轰隆——！</p><p>坚硬的地壳如同被无形的巨锥凿开，瞬间裂开一个直径数米的幽深洞口，边缘光滑如镜，直通地底深处翻涌着暗红光芒的地幔！</p><p>恐怖的高温高压喷薄而出，足以瞬间汽化任何凡物。</p><p>杨帝面不改色，俯视着下方熔岩地狱。</p><p>他伸出手臂，无视那足以熔炼星辰的热浪，探入流淌着炽白与暗金光芒的地幔熔流之中。</p><p>手臂精准地一捞，再收回时，手中已多了一块巴掌大小，散发着灼目金红色光芒的“石块”。</p><p>它是地核深处在极端条件下天然形成的，纯度极高的金矿石。</p><p>他另一只手对着裂开的地壳洞口虚虚一按。</p><p>嗡——</p><p>如同倒放录像，裂开的大地岩石如同拥有生命般蠕动聚拢，最终弥合。</p><p>高温熔岩被强行压回地底深处，翻腾的洞口迅速缩小，合拢。</p><p>数息之后，戈壁滩上只留下一片颜色略深、仿佛被熨斗烫过的平整地面，再无丝毫痕迹。</p><p>大地恢复平静，仿佛刚才的裂变只是幻觉。</p><p>杨帝掂量了一下手中那块温度急剧下降、但依然滚烫沉重的暗金色“石头”。</p><p>下一个瞬间，空间再次扭曲，他已站在东南亚某国一个不起眼的小巷深处。</p><p>面前是一家挂着“高价回收黄金珠宝”招牌，卷帘门半开的老旧当铺。</p><p>当铺老板是个精瘦的老头，正打着瞌睡。</p><p>杨帝无声地出现在柜台前，将那块冷却后闪耀着暗金光泽的“石头”放在柜台上。</p><p>“黄金。”</p><p>老头被惊醒，先是被杨帝的突然出现和身上残留的硝烟灰烬气息吓了一跳，随即目光就被那块“石头”死死吸住。</p><p>他颤抖着手拿起放大镜和试金石，一番紧张而沉默的检测后，眼中爆发出难以置信的光芒！</p><p>纯度、密度、天然形成的独特纹理……这绝非寻常金矿石。</p><p>没有多余的话，老头报出了一个远超市价、足以让他自己都心惊肉跳的天文数字。</p><p>杨帝点头。</p><p>“不过，我要用软妹币交易。”</p><p>三十分钟后，一个鼓鼓囊囊，塞满了厚厚一沓软妹币的背包被推了过来。</p><p>一个黑帮团伙盯上了杨帝。东南亚还是比较乱的。</p><p>杨帝只是打断了他们的三条腿，身影再次消失。</p><p>岭南省，稷海市远郊。</p><p>晨光熹微，一处普通农家小院。</p><p>杨帝如同幽灵般出现在一间简陋的卧室内。达文西的父母是一对面容沧桑的老人——他们还在沉睡，发出轻微鼾声。</p><p>房间陈设简单，一张旧木桌靠墙放着。</p><p>杨帝将那个沉重的背包轻轻放在旧木桌的正中央。动作轻得没有发出一丝声响。</p><p>他没有留下任何字条，也不需要。</p><p>这笔远超他们想象的财富，足以改变他们清贫的余生，算是对“万业狐狸”这具凡俗躯壳最后一点因果的清偿。</p><p>杨帝的直觉告诉他，达文西/万业狐狸，不是耶罗大仙。</p><p>灭圣尚未成功，大盗亦未死绝。</p>
