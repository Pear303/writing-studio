# 不科学的大陆

<p>除此之外，没有更多成绩了。</p><p>酒楼厨子·中山无极抹了把脸上被气浪掀得飞溅的油渍，握着几近碎裂的宝刀指向杨帝。</p><p>最后还是放下了。</p><p>酒楼厨子·中山无极甩了甩发麻的手腕，菜刀化作流光缩回袖中。</p><p>他抖了抖被气浪掀飞的厨师帽，最后擦了把额角冷汗，秒变气定神闲，微微笑道：</p><p>“灵界是礼仪之界，迎接远道而来的客人，应该以礼相待，以和为贵，怎么能一上来就打打杀杀呢？”</p><p>始终严肃脸的中学老头·血手屠魔强行舒展了眉头，语气中多了几分感慨：</p><p>“我们身处这天地之间，本就应顺应自然，接纳万物。如今这杨帝虽来自天外，灵能诡异，但他并未主动挑起事端，一上来便大打出手，并非智者所为。”</p><p>“对啊。”</p><p>“没错。”</p><p>“附议。”</p><p>“再者，我们不知他究竟怀着怎样的目的来到此地。若能以和为贵，与之交流，说不定能从他口中得知许多关于域外天魔，或是其他世界的隐秘信息。”</p><p>“妙极。”</p><p>“如今灵界无主，各方势力蠢蠢欲动，域外天魔又虎视眈眈，我们实在经不起内部损耗了，共同的损失让我们必须团结一致。”</p><p>“甚对。”</p><p>“继续争斗下去，于我们而言，不过是徒增伤亡，毫无益处。一味地敌对，只会将我们推向双输。”</p><p>“无误。”</p><p>杨帝慢慢停止自旋，把四人放下了。</p><p>他知道，这几位土著大能终于冷静下来，可以和他们好好讲道理而不是讲物理了。</p><p>他抱拳，笑道：“在下杨帝，白杨大帝，来自另一个天地。此次前来本是机缘巧合，却不想卷入了诸多奇妙之事。”</p><p>几位土著大能听闻杨帝自称“白杨大帝”，先是微微一怔，旋即便立刻反应过来。</p><p>刚刚与杨帝交手的情形，那恐怖实力，的确担得起“大帝”这一称号。</p><p>于是乎，众人纷纷换上笑容，态度热情，簇拥着杨帝往地面落去。</p><p>酒楼厨子·中山无极不失礼仪地微笑，伸手做出请的姿势，说道：“咳咳，原来是白杨大帝阁下，刚刚多有冒犯，咱们这就回地面，定要摆上最丰盛的宴席，好好款待？”</p><p>图书馆保安·天机子也赶忙笑着附和：“能与白杨大帝结识，实乃我等荣幸。回到地面就为您接风洗尘。”</p><p>“不必，不要搞大排场。”</p><p>杨帝指出，你们迎接我不要铺设迎宾地毯，不用悬挂标语横幅，也没必要摆放花草；公共食堂外，每人每餐不超过30块，也不要准备酒水和香烟。</p><p>虽然因谐音梗和文化差异，他被异界的土著大能认成“大帝”，但也无伤大雅。</p><p>毕竟，他确实有大帝起步的实力。</p><p>只是在谈论到本地发展的一些问题时，杨帝总会以后辈自谦。</p><p>其他异界土著也能看出来——这位大帝比他们年轻。</p><p>当修炼境界达到某一阶段，人的相貌外形就可以自由呈现。</p><p>但一般来说，相由心生，大能都会根据自己的“心理年龄”，表现出相应模样。</p><p>毕竟修炼过了一定境界，已经寿比天地，证道长生，少年、青年、中年、老年这样的划分已无意义。</p><p>有些大能是个老头，因为他们心态比较老。有些是少男少女，因为他们臭美。</p><p>而“白杨大帝”杨帝，他看起来是青年面相。</p><p>心理年龄是个年轻人，自称后辈无可厚非。</p><p>年轻人对世界充满好奇。而杨帝心里，已经憋了太多新问题，都快憋出内脏大出血了。</p><p>他目光再次投向脚下的大地。</p><p>杨帝问道：“前辈们，本帝咳咳，晚辈初来乍到，有一问题相问。在此之前，诸位可曾听说过‘流体静力学平衡’？”</p><p>……</p><p>他通过原地实验和思想推导，原地搓出个类似经典力学的异界版力学理论大厦。</p><p>没想到他去过的两个异世界，物理规律和地球都如此相似。</p><p>或许这也是一种“人择原理”。</p><p>我们看到的宇宙之所以是这样，是因为如果它不是这样，我们就不会在这里观察它。</p><p>只有物理规则适宜，像人类这样依赖特定物理条件生存、发展智慧的生命才可能出现，进而才会有杨帝这样的人类去观察和思考这些物理规则。</p><p>而杨帝本尊，恰好两次都穿越到了这种物理规则相近的宇宙。</p><p>有可能正是因为物理规律相近，他才能穿越过去？</p><p>通过现场推理，杨帝通过异世界魔改版微积分和经典力学，以及59改用探测器现场测量出来的亿点点材料学知识（59改还是挺忠诚的），能够很顺畅地推出，本宇宙也存在某种程度上的“流体静力平衡”规律。</p><p>——在这个宇宙，质量超过一定规模的自然天体，应该向内坍塌成球体。</p><p>杨帝作谦逊状：“那请不吝指教了。大地……我观其平坦异常，不知是何缘故？”</p><p>从地面一路飞到这数十万公里的高空，他竟发现一件很诡异的事——大地没有弧度。</p><p>本该呈弧形的天际线笔直如刀削，远处山峦的轮廓在云雾中若隐若现，却始终保持着同样的高度，没有因距离而产生弧度变化。</p><p>目力所及之处，广袤陆地平坦得如同一块巨型棋盘，向四周无限延展，没有丝毫弯曲迹象。</p><p>不存在星球应有的球体形状。</p><p>他本以为来到这个世界，虽有诸多不同，但至少星球的基本形态应是相似的。</p><p>没想到，真存在有“大陆世界观”的宇宙。</p><p>当然，也有可能是脚下这颗“星球”直径大得离谱，所以弧度近乎看不出来。</p><p>但经过杨帝估算，想要他肉眼看不出来这其实是一个庞大的星球，至少需要直径万亿公里。</p><p>那是什么概念？</p><p>如果以柯伊伯带的边缘作为太阳系的边界，那么太阳系的直径大约为149.6亿公里​。</p><p>但是根据当地的物理法则，又能根据异世界魔改版经典力学和材料学，推导出基本的“流体静力平衡”原理。</p><p>虽然实际上这里是大陆世界观，但从理论上看，这里不应该是大陆世界观。</p><p>是世界出了问题，还是我考虑漏了什么？</p><p>经常以一己之力（或者在XX系统帮助下）将整个行星级文明拉升到宇宙级文明的普通男子高中生都知道，许多看起来与原有物理规则矛盾的现象，很可能都是因为人们对这些规则背后的底层原因认识，还不够深入。</p><p>譬如，人类局限于低速宏观世界时，牛顿三大定律如同真理般牢不可破。</p><p>可一旦将目光投向接近光速的领域，或是深入微观粒子世界，经典力学便开始出现裂痕。</p><p>——像此刻这片违背流体静力平衡的大陆，在常规认知中堪称荒谬。</p><p>但或许在某种更高层次的规律中，是可以实现的。</p><p>图书馆保安·天机子博学强记，他略微向众人泄露了一点天机：</p><p>“白杨大帝，这其实与凡界的‘本质’相关。但这是本界的机密，暂时不方便透露。</p><p>“凡界比较平坦，其实是正常情况。”</p>
