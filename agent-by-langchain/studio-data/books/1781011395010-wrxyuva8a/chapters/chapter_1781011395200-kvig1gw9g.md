# 杨帝不圣

<p>如果世间的灵能处处均匀，那么世上，也就不会存在修仙者、魔法使和现实扭曲者。</p><p>万事万物，都会沿着既定的物理规律行进。</p><p>但此时，假设出现一个显著高于环境灵能的现实扭曲者，再假设他掌握了“火球术”。</p><p>那么，火球术的施法本质，其实是他选取了一条「能让空气粒子在极低极低概率巧合下，恰好在空中凝聚成高能空气团」的世界线。</p><p>此外还有种种法术，上天入地，焚山煮海，预知未来，都与“世界线”、“概率”与“命运”此类有关。</p><p>这就是“法术”的原理。</p><p>灵能是万事万物的最本源。圣人也喜欢用灵能将世界引导向某个模样。</p><p>对于行星级灵能者/修仙者/魔法使/现实扭曲者而言，他们对“法术”最浅显的理解——</p><p>就是“利用一根恰到好处的火柴点燃柴堆”，就是“用一阵恰到好处的风将一堆零件组合成机械手表”。</p><p>而从更「本质」层面看，灵能法术，就是掌控命运。</p><p>低灵能者，会被高灵能者“掌控命运”。</p><p>各种灵能法术，其实是在极其浩渺的概率之海中，找到一条恰好发生了某种事情的世界线。</p><p>遇事不决，量子力学。</p><p>灵能法术的诸多本质，恰好也与微观粒子的量子特性相关。</p><p>微观世界的粒子行为由概率波描述，这使得很多宏观上看似不可能的事情，其实都存在理论上的概率，只是概率低到近乎荒谬。</p><p>比如“土遁术”，俗称穿墙。构成人体的每个粒子都有极小概率发生“量子隧穿”，即不打破墙壁却穿过障碍物。</p><p>让一个人全身约10^28个基本粒子同时隧穿，不是不可能，而是概率极低。</p><p>又比如用“霜冻术”让热水瞬间结冰。</p><p>热量本质是分子热运动，理论上，一杯热水中的分子可能因随机运动突然全部聚集到杯底，导致上方水温骤降至冰点。</p><p>还有其他种种灵能法术，比如把香蕉变成铅笔，将钻石捏成煤炭，亦是同理。</p><p>命运即世界线走向。</p><p>一个人拥有的灵能越强大，越能掌控自我命运；其能够稳定存在、不会被随意篡改“命运”的概率更高。</p><p>而“灵能”又可以用数值加以量化……</p><p>如果灵能的本质，可理解为对世界线和概率的掌控力度。</p><p>现实稳定性体现在事物能保持自身特性，如胶凳不会随意变形、搪瓷杯触感始终如一。</p><p>那么，灵能法术可以打破这种稳定——高灵能者可通过法术在海量概率中，选取并实现低概率事件。</p><p>如让人体粒子同时隧穿穿墙、热水分子瞬间聚集结冰，本质是“掌控命运”。</p><p>杨帝无“圣人”之愿，不打算按照自己的意愿掌控众生命运，即使这个命运是“好”的。</p><p>他也不打算让其他圣人如愿以偿。</p><p>目光穿透翻腾的混沌灵能，死死锁定那四尊扭曲的圣影。</p><p>四神的灵能，和杨帝一样，是“向内收敛”的负值型。</p><p>祂们的灵能力量，同样高得突破了天际，不可测量。</p><p>祂们的意志，无需言语，无需动作，仅仅是存在于此，其庞大的灵能就自然而然地扭曲着周围一切世界线的走向。</p><p>阿巴感觉自己像被嵌入了中子星核心的普通鲈鱼，连思维的涟漪都难以泛起。</p><p>她只能坐在一边，乖巧地观战。。</p><p>自己只是“准圣”修为，和正式圣人比起来，差距很大很大很大。</p><p>就像实习生、劳务派遣和正式员工，是天差地别。</p><p>杨帝放弃了圣人境界、放弃了灵能伟力，此刻周身没有任何灵能光辉，只凭着一具凡躯站在这里。</p><p>咚！！！</p><p>杨帝脚下的混沌物质，翻腾的灵能辉光，在脚掌落下的瞬间被纯粹的力量压特么爆了！！</p><p>仿佛超新星在他落脚点诞生又瞬间坍缩。</p><p>一圈纯粹由物理冲击构成的冲击波，呈完美的球形轰然扩散！</p><p>所过之处，凝固如简并态物质的灵能“现实”被硬生生撕裂粉碎，挤压成更原始的混沌乱流！</p><p>这片被四大邪神意志锚定的领域，第一次出现了酷似宏观物理现象的剧烈动荡。</p><p>端坐的四大邪神，祂们那超越个体情感的意志中，终于泛起可以被称之为“诧异”的涟漪。</p><p>祂们掌控万千世界线，一念之间可以引导概率之海倒灌，让兆亿分之一的可能成为必然，让必然化为乌有。</p><p>祂们是命运的编织者，是可能性的主宰。</p><p>也就那位「万古白杨帝尊」，能够稍微撼动他们所编织的既定剧本。</p><p>但杨帝的攻击，不涉及任何“可能性”。它就在「这里」，就在「此刻」，以绝对的速度、绝对的质量、绝对的力量，碾了过来！！！</p><p>命神·那唭枯身周的“纯洁-污腐”法则漩涡最先亮起。</p><p>无数代表熵增熵减、秩序与混乱的世界线瞬间交织，试图将杨帝这纯粹的物理冲击引导向一个“无害”的概率——</p><p>比如，冲击波在传递过程中突然所有粒子都发生了量子隧穿，散逸到亚空间深处；或者，其动能瞬间转化为纯粹的热辐射，均匀散布到整个宇宙背景之中。</p><p>更甚至，在过去提前杀死杨帝……</p><p>无效。</p><p>杨帝的拳，裹挟着踏碎混沌的余威，已经轰至！</p><p>那拳头上蕴含的力量数值，早已突破了大道所能容纳的极限阈值。</p><p>它不是“选择”了哪条世界线，而是直接砸碎了所有挡在它路径上的世界线！</p><p>不知多少亿万种可能性，寸寸断裂，粉碎，湮灭。</p><p>仅余蕴含着微弱现实的碎片四处飞溅。</p><p>吼——！！</p><p>至道勇毅血神·哥达内冲杀上前。祂没有徒劳地操纵世界线变动，而是以纯粹磅礴的灵能，如同亿万个超星系团同时撞击，正面迎向杨帝！</p><p>针尖对麦芒，纯粹硬碰硬！</p><p>血海狂涛与杨帝的拳锋撞击点，形成一个吞噬一切光与信息的绝对黑域。</p><p>但下一刻，那绝对的黑域，被更纯粹的力量撑！爆！了！！</p><p>杨帝的拳，穿透了血海。</p><p>由无尽血光与战争意志凝聚的血神之躯，胸口处出现了一个怵目惊心的巨大凹陷！</p><p>血神全“身”炸出“血雾”。</p><p>严格来说，祂们并没有“身”，亦无“血”。</p><p>此处，身象征存在，血即为生命，就如心脏是生命之源，大脑是元神居所。</p><p>杨帝猛追穷寇，动作没有丝毫花哨，就是最基础的拳、脚、肘、膝！</p><p>无瑕慧悟智神·辛烈治脑花四溅，义胆赤心爱神·沙历士心脏炸裂。</p><p>这种级别的战斗，为什么会表现成如此低端呐啊啊！！</p><p>——原因是，万古鱼尊阿巴修为太低，根本无法看明白发生了什么。</p><p>她浅薄贫瘠的眼界只能将其理解成：一个弱不禁风身板瘦小的青年，和四个看起来就很邪恶的肌肉佬，在亚空间中肉搏。</p>
