# 很玄幻的大陆！

<p>不管怎么说，存在即合理。</p><p>杨帝不可能直接否定这个大陆的存在形式，只能寻找原因，而不是捂上耳朵蒙上眼睛说“都是假的都是假的”，否则是自欺欺人。</p><p>他与众人以相对论速度朝地面飞去。</p><p>临近之时，那股一直被忽视的引力，像是隐匿在黑暗中的大手骤然伸出，陡然发力，将他们一把拽住。</p><p>他们受引力俘获，也便放开主动飞行，进入自由落体状态。</p><p>那庞大得令人窒息的陆地，向杨帝扑来。</p><p>风声在耳畔如狂兽怒号，他们的身躯如流星般向着下方的大地疾驰。</p><p>从这极高的天空俯瞰，这片大地宛如一幅恢宏而奇异的画卷，在他们眼前徐徐铺展。</p><p>目力所及，是一片无垠的平坦，仿若一块精心雕琢却无边无际的巨大玉板，向四面八方无尽延伸，没有丝毫弯曲的迹象。</p><p>大陆之上，山川纵横，似是用巨笔勾勒出的粗狂线条。</p><p>广袤的平原如绿毯般铺陈开来，其间点缀着一片片金黄的田野。河流是大地的血脉，从高山发源，奔腾而下，蜿蜒曲折地贯穿平原。</p><p>城市与村落星罗棋布地点缀在大地上。</p><p>聚居区中，建筑错落有致，尖顶的塔楼直插云霄，飞檐斗拱的楼阁古色古香。</p><p>论具体观感，可能类似于地球二十二世纪后期。</p><p>在大陆极远极远的边缘，云雾缭绕，云海层层叠叠，将大地边缘模糊在一片迷离之中。</p><p>如果仅凭目力，他看不到大陆的尽头。</p><p>反正现在已经暴露了……如果他肆无忌惮地使用法术进行“观测”呢？</p><p>在不动用法术的灵能下，杨帝的肉眼能力有限，只能看见9999公里外一只飞虫翅膀上的蜿蜒纹路。</p><p>此刻，距离地面约0.1光秒。</p><p>“我在与这几位土著大能战斗过程中，已经表露出‘大帝级’实力，但并没有招致无限机兵的注意。既然如此，应该可以表现出大帝级的‘视力’，看清这片大陆的全貌。”杨帝心中寻思。</p><p>杨帝心意一动，磅礴的灵能瞬间在眼眸中汇聚，仿佛有两团璀璨的星辰在眼底燃烧。</p><p>“原初之眼，启动！”</p><p>当然不是原初之眼，只是杨帝自创的16、17环法术罢了，可以用来观察万物，甚至能裸眼看清电子的形状——非常标准的球形。</p><p>当然众所周知，这里的“球形”并不是指实体刚性球，而是指点粒子的电荷分布。</p><p>随着灵能的注入，杨帝的视力以一种超乎想象的程度急剧提升。</p><p>原本目力难及的远方，变得清晰可见。</p><p>甚至原本依靠肉眼不太可能看穿的大地，此刻也被扒个精光，露出其本真的胴体。</p><p>地表之下5000公里的岩层，在他感知中徐徐展开。</p><p>最上层是厚度约50公里的硅铝层，淡灰色的花岗岩如同凝固的浪涛。往下是硅镁层，玄武岩组成的致密结构泛着铁青色。</p><p>接近2500公里深处，岩石结构已接近极限。</p><p>高温使得岩石内部的矿物质呈现出一种半融化的状态，在黑暗中缓慢地流淌，散发着炽热的气息。</p><p>硅氧四面体与金属离子重新排列组合，形成一种介于固态与液态之间的超离子态物质。</p><p>杨帝灵力感知触碰到这层区域，感受到微弱的震颤，仿佛大地在进行着某种永恒的呼吸。</p><p>越过了2500千米这条分界线，越往下走，岩石层重新变回稀疏脆弱。</p><p>大陆对面，还有另一个世界。</p><p>就像一块硬币有两面。</p><p>硬币正面能够承载起繁荣的凡界文明，万般生灵，鬼斧神工的湖海万壑。</p><p>没理由说，硬币的反面不行。</p><p>大陆的另一面，也是个长得差不多的文明，只不过没点出现代科学，而是个以“斗气”为根基的封建社会。</p><p>他还看到某个广场，一名少年将手按在石头上，屏幕随即显示“斗之力三段”之类的内容。</p><p>此事平平无奇，社会学+8。</p><p>最值得关注的，是大陆最远端边缘。</p><p>杨帝眨眨眼，庞大的地理尺度在意识中轰然展开。</p><p>感知范围呈指数级膨胀。</p><p>他的目光云雾穿透缭绕的边际，跨越无数个交替的晨昏线，直到大陆边缘。</p><p>大陆并没有严格意义上的晨昏线，整片大陆同时沐浴在“白昼”的光辉，又同时沉浸于“黑夜”的沉寂。</p><p>——这片大陆不是传统意义上的昼夜交替，而是全域同步的黑暗与光明。</p><p>偏偏，天上挂了个像是“月亮”的东西。</p><p>然而，当杨帝目光延伸至少30亿光年，他却没能看清楚那“月亮”的本体是什么。</p><p>这是个很随便的世界，像是某个考试59分的不知名笨蛋创世神随便捏捏出来的大陆。</p><p>既然是整个大陆范围同时步入白昼与黑夜，那么，其实也就没有晨昏线之说。</p><p>此处“晨昏线”是以地球为标准，每两条晨昏线，相距约4万公里。</p><p>杨帝视线跃过7E17条晨昏线，来到30亿光年之外。</p><p>……这里，就是宇宙边缘了。</p><p>这是大陆世界观的世界。在此地，宇宙边缘其实就是大陆的尽头。</p><p>但那里的景象，即使是拥有了一整个宇宙记忆的他，都瞳孔骤缩。</p><p>非常新奇，真没见过。</p><p>——距离此地30亿光年的“边境之地”，也就是大陆边缘之处，空间质感极度扭曲。</p><p>光线如同被无形巨手揉搓的丝线，在空气中无力地荡漾。</p><p>地表的地貌在边界处逐渐模糊，连绵山脉如同蜡像融化，支离破碎，却又诡异地连成一体。</p><p>植被不遵循任何已知的生长规律，树木枝干以违背重力的姿态盘旋扭曲，长出愤怒的棱角。</p><p>大气层与真空的交界线，呈现出液态汞般的流动光泽。如果要给出形容，那犹如将“极光”的饱和度降到最低，调成黑白二色，然后强行涂抹到天空中。</p><p>“边境之地”的现实丰度极低。用当地的大白话说，就是灵气浓度极度稀薄，万物都已经无法稳定存在。</p><p>再往外，应该就是原初之眼所说的“虚空”，“比虚无更空旷”的地方。</p><p>“没想到世界不是无限的……”杨帝收回视线，缓缓睁眼。</p><p>周围四个本地土著大能，一边下坠一边在空中交谈，时不时前来与他的交互。</p><p>此刻，距离他用目光扫视世界之边缘，仅仅过去半毫秒。</p><p>他们还在急速下坠。不过杨帝知道，以众人的能力，落地前稳住身形并非难事。</p><p>趁着这短暂的间隙，杨帝看向身边的四位本地土著大能，笑着开口道：“几位，方才情况紧急，还未正式认识几位。就从这位看起来颇具厨师风范的老兄开始如何？”</p><p>他看向酒楼厨子·中山无极。</p><p>中山无极哈哈一笑，双手负于身后，稳稳当当，颇有几分潇洒。</p><p>其实内心慌得一匹，不像是活了几万年的老怪物那样沉着平静、淡定自若、泰山崩于眼前而不惊。</p><p>因为，这是一个他们完全不知来历、不知善恶、不知目的的大帝，貌似话里有话地在向自己问话。</p><p>就好比某天，祖国人走到你面前微笑，让你开始自我介绍。</p><p>酒楼厨子·中山无极在空中清了清嗓，说道：“杨帝阁下，实不相瞒，我确实是个厨子，而且是个对美食极为执着的厨子。”</p><p>“可你同时是‘真仙境大圆满’。”</p><p>“哦，是的，在做厨子之余，我兼职修炼到真仙境界，这也是机缘巧合吧。</p><p>“我原本就是灵界土著。在追求美食与失落菜谱的过程中，我不可避免需要踏遍整个灵界，期间肯定会遇上各种危各种杀机。</p><p>“比如想要摘取洪荒凶兽看守的极品木耳。比如看上了比如看上了深海蛟龙守护的灵泉，那灵泉的水可是熬制顶级羹汤的绝佳配料。</p><p>“为了这些难得的食材，为了吃喝，我与人争斗、与兽厮杀，慢慢地，也就练就了这身还算过得去的本领。”</p><p>成为万人之上，一人之下的厨子。</p><p>那“一人”特指归墟大帝。</p><p>现在嘛……就特指“白杨大帝”了。</p><p>图书馆保安·天机子，扫地僧·渡厄禅师，中学老头·血手屠魔，另外三人也分别介绍了自己姓甚名谁。</p><p>不过杨帝也只记住了他们姓甚名谁。</p><p>这么多人的生平往事，性别性格，不想记。</p>
