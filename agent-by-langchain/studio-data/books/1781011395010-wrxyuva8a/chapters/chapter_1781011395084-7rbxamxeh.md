# 柑橘味追踪者

<p>杨帝最终擒到一条大鱼。</p><p>将其开膛破肚，里面还有张纸条，不过写的不是“苍天已死黄天当立”，而是“阿巴阿巴我是条摆烂的鱼”。</p><p>鱼之大，一口吃不下，故一人半条。</p><p>但因为没有酱料，这鱼肉腥得要命。</p><p>幸好瑞弗维尔采来的花瓣和嫩尖芽儿煮成的花茶发挥了作用。</p><p>杨帝接过茶杯，轻轻抿了一口。</p><p>花茶入口，一股清新的味道瞬间在口腔中散开，带着淡淡的花香和植物的清新气息，迅速冲淡了那股令人难受的鱼腥味。</p><p>“嗯，感觉清爽多了。”</p><p>瑞弗维尔满意地点点头：“没错，非常的鲜美。”</p><p>“不过我有个疑问，这个嫩芽尖是绿色的，花瓣黄色，但为什么泡出来的茶是红色的？”</p><p>瑞弗维尔又叹了口午后花茶，答道：“我加了些蘑菇。”</p><p>“……什么样的蘑菇？”</p><p>“红伞白杆的，不过我应该没认错，那是可食用的红蘑菇。”</p><p>「消化+1」</p><p>「消化+1+1+2+3+5+8……」</p><p>杨帝沉默地放下茶杯。</p><p>不，你认错了。</p><p>在地球，许多溺水者都是会游泳的；吃蘑菇中毒者，大多对蘑菇有一定了解。</p><p>浅水才能淹死老师傅。</p><p>热茶喝下去，全身暖烘烘，但与此同时，杨帝感觉到急性肝衰竭+急性肾衰竭+副交感神经兴奋+眼球震颤+溶血。</p><p>“寄。”</p><p>杨帝心里闪过这个念头，一股无与伦比的困意朝他袭来。</p><p>异世界的毒蘑菇，和地球的品种似乎不太一样，他需要重新适应异世界的特色毒素，慢慢免疫这类中毒效果。</p><p>杨帝倒是不担心自己。</p><p>只是，他刚认识异界土著导游瑞弗维尔，如果对方就这么死了，那真是有点冤枉。</p><p>但在自己进化到免疫异世界剧毒蘑菇前，他什么都做不了。</p><p>即使自己做得了任何事，如果不能及时催吐洗胃，不能及时上血液透析机。</p><p>还能怎么救瑞弗维尔……</p><p>对了，魔法。</p><p>刚才还想着“催吐洗胃”、“血液透析”，真是典型的地球理工男思维。</p><p>杨帝在昏迷前，强顶住困意榨取所有精神，搓了个西瓜大小的「三环法术·愈合」拍到瑞弗维尔身上。</p><p>能不能撑过去，剩下的就看他体质了。</p><p>……</p><p>瑞弗维尔悠悠转醒，只觉得脑袋昏沉，仿佛刚从一场噩梦中挣脱出来。</p><p>他视线还有些模糊，努力眨了眨眼睛，才逐渐看清周围环境。</p><p>他意识到自己原地睡了一觉，挺不安全！</p><p>下意识地，瑞弗维尔伸手摸了摸衣服内袋，触碰到那熟悉的形状，心中一松。</p><p>幸好，那块石头雕塑还在。</p><p>这石头雕塑对他来说意义非凡。虽然不知原理是什么，但那些圣光教廷追兵只是对着雕塑看一眼，就会精神混乱，放弃追杀他。</p><p>他只是个小小的图书馆馆长，退休的游侠。</p><p>没了这石头雕塑，已经死二三十回了！</p><p>瑞弗维尔缓过神来，这才发现杨帝躺在一旁，一动不动，脸色惨白如纸。</p><p>他心猛地一紧，一种不祥的预感涌上心头。</p><p>杨帝死了！吗……</p><p>“杨帝！杨帝！”瑞弗维尔扑到杨帝身边，双手用力摇晃着他的肩膀。</p><p>过了好一会儿，杨帝才悠悠转醒，眼神迷茫地看着瑞弗维尔。</p><p>像是还没从昏迷的混沌中完全清醒过来。</p><p>他迷糊了一会儿，才缓缓开口：“你在吃柑橘？”</p><p>瑞弗维尔见他没死，松了口气，但随后困惑：“什么柑橘？没有啊。”</p><p>杨帝闻言，安静了下来。</p><p>在地球上，某些剧毒蘑菇中毒后，患者可能会出现幻嗅。</p><p>如果他闻到类似柑橘的气味，这可能意味着中毒已对神经系统造成了严重影响？</p><p>……并不，柑橘味确实存在，但是很微弱。</p><p>只有他闻得见，普通人应该觉察不到。</p><p>而且，这柑橘味还有些熟悉感……</p><p>没错，是在昨晚睡觉的山洞里。</p><p>昨夜，杨帝刚走进山洞，就闻到里面残留的微弱柑橘气味。</p><p>但是他以为有动物在里面。</p><p>瑞弗维尔看着杨帝凝重的表情，问：“杨帝兄弟怎么了？有什么问题？”</p><p>“继续走吧。”杨帝说着，缓缓站起身来。</p><p>他开始留意起四周，警惕是否有人跟踪。</p><p>虽然自己刚刚重度昏迷而醒，但六识仍然强于普通土著。</p><p>眼、耳、鼻、舌、身、意，每秒都能接受到海量数据。</p><p>正常人的表层思维无法承受这么多信息，所以，潜意识会处理完99.99%的数据，然后制作成一份极其简洁的“总结报告”，递交给表层思维。</p><p>但也因此，正常人会忽略大量细节。</p><p>因为“总结报告”毕竟不是“原始数据”。</p><p>比如说，空气中那一丝若有若无的柑橘味，普通人即便闻到了，也会因为过于微弱，而被简洁的“总结报告”所忽略。</p><p>可杨帝却能敏锐捕捉感官传来的任何一丝细节。</p><p>又比如说，后方50-60米处，时不时传来的喵喵叫。</p><p>徘徊于柏树林，没有固定形状的viv色游魂。</p><p>酸甜苦辣香鲜咸以外的味觉……</p><p>杨帝的的第六识“意识”所对应的第六感“灵感”，也觉察到周围环境隐隐不对。</p><p>这是有一个东西，一种东西，在跟着他们。</p><p>杨帝明白不宜打草惊蛇。</p><p>他佯装若无其事地继续与瑞弗维尔前行，只是暗中更加留意四周的动静。</p><p>那股若有若无的柑橘味萦绕在鼻尖，忽远忽近。</p><p>但每次，杨帝扭动眼球去捕捉那道身影，对方都会瞬间消弭。</p><p>只在余光最边缘之处，瞥见一小抹极其难以觉察的模糊金色。</p><p>他试图用“灵”去感知那神秘存在的气息。</p><p>却发现，对方似乎能巧妙地避开他的探测，与周围的柏树林融为一体，仿佛天生是森林的一部分。</p><p>数十次试探后，对方似乎是察觉到了杨帝的警惕。</p><p>那股若有似无的柑橘气味，渐渐变淡。</p><p>他松口气。虽然感受不到对方的恶意，但杨帝清楚，这个人一直跟着他们，必定有想法。</p><p>杨帝想到瑞弗维尔所说的商业竞争对手。</p><p>异世界的商战，是真刀实枪的。</p><p>按理说，在他们中毒昏迷毫无反抗之力的时候，那些人若是想下手，简直易如反掌！</p><p>可对方却没有这么做。</p><p>这说明，那位可能存在的跟踪者，并没有要置两人于死地的决心。</p><p>对方不是商业竞争对手派来的刺客，而是另为他人……会是谁……想要干什么……</p><p>杨帝驻足，看向身后走得慢的瑞弗维尔：“你怎么样？肚子还行？”</p><p>“挺好挺好……看来仅仅只是会让人昏迷的蘑菇，差点嗝屁了。”</p><p>杨帝翻白眼，斯特喵“只是会让人昏迷”，当时他清楚感知到自己正在急性肝肾衰竭。</p><p>“你昏过去后，我给你拍了个‘愈合’法术。”杨帝说。</p><p>瑞弗维尔站住了。脸上露出困惑。</p><p>“你说你给我拍了个‘三环法术·愈合’？”</p><p>“没错，你知道的，我从你这里学来的这项法术挺好用……”</p><p>“不不不，不是这个问题……这法术只能治疗物理性伤害啊，对生物化学伤害几乎没有效果，怎么可能救得了蘑菇中毒……”</p><p>瑞弗维尔和杨帝面面相觑。</p><p>瑞弗维尔笑笑：“所以杨帝兄弟你别紧张，这正好说明这种蘑菇没有剧毒，只是会让人睡一觉罢了。”</p><p>如果杨帝是正常人，那他确实会相信。</p><p>可在中毒刹那的身体反应，都真真切切被他的潜意识收集起来，整理成详细汇报，说明这种蘑菇确实是剧毒。</p><p>所以……不是杨帝，而是有另外的人救了瑞弗维尔。</p><p>那个柑橘味的追踪者——杨帝立刻想到这人。</p><p>追踪者救了瑞弗维尔一命。</p>
