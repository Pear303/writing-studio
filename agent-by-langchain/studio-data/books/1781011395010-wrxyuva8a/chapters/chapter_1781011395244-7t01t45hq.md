# 圣人如何占据私人疆域

<p>杨帝盯着太一矩枢平稳运转的操控面板，终于忍不住：“所以我们要做的‘实习业务’，具体是指什么？”</p><p>「第一，并非我们，而是你。」</p><p>「第二，我们日常要进行的各种业务，主要是针对圣人，而非凡世。」</p><p>它顿了顿，调出一份全息文档，上面是密密麻麻的宇宙坐标与维护记录。</p><p>舱门滑开，强烈的金光涌了进来。</p><p>眼前是个较为奢华的欢迎大厅。穹顶高悬，缀满流转的星辰，地面光洁如镜，映出上方无数层层叠叠的水晶灯盏。</p><p>空气里弥漫着一种甜腻的熏香，远处传来若有若无的缥缈仙乐。</p><p>太一矩枢的银白色机体站在金碧辉煌的背景里，显得格格不入。</p><p>他没有欣赏的意思，传感器扫过大厅。</p><p>「目标宇宙：‘万藏品’。申报类型：公共文化展览空间，评级AAAA，享受盟约文化交流补贴。」</p><p>居然是4A级景区，不错嘛。</p><p>「但监测数据异常。其内部‘生活区域及未申报功能区域’占比，达到总空间容积的68.45%，远超规定上限10%这个标准。」</p><p>「随后，对方重新申报该空间区域的用途，声称其是‘维持公共博物馆运转所需的必要设施’。」</p><p>「然而，宇宙背景签名分析显示，大量能量被用于维持非展览性、高耗能舒适性环境，与其申报的‘低干预保护性展览’宗旨严重不符。」</p><p>他转向杨帝。</p><p>「结论：程序合规，实质违规。典型的滥用补贴与空间欺诈。」</p><p>「我们的任务：进入核心区，核实违规面积，固定证据，并视情况发出《限期整改通知书》或启动强制空间重构程序。」</p><p>说完，他迈开步伐，金属脚掌踩在光可鉴人的金色地板上，发出清脆而冰冷的回响，径直走向那硕大无朋之私人宅邸的深处。</p><p>杨帝跟在太一矩枢身后，目光所及之处，豪华已突破“凡俗想象”的边界。</p><p>走廊两侧的立柱并非金玉雕琢，而是将两颗坍缩到临界状态的白矮星打磨成圆柱，星体核心的微光透过透明的暗物质外壳，在地面投下流动的银蓝色光斑。</p><p>光是维持这两根柱子形状所需的能量，就已经能让超过100万个21世纪地球，坐火箭进入共产主义社会。</p><p>杨帝看着眼前奢靡的景象，皱眉问道：“既然实质违规，流程又管不住他的擦边球，为何不直接动手整改？”</p><p>太一矩枢的传感器微光流转，声音平稳得像在宣读条例：</p><p>「神圣星环盟约，首要原则是流程正义。流程合规，即便行为存疑，亦受保护。此乃基石。」</p><p>「若其利用流程漏洞作恶，盟约会优先启动立法程序，修补漏洞。过程或缓，但也能根除后患。」</p><p>「反之，若我们跳过流程执法，即便结果正确，对于众生利好，却亦属违规，必须接受问责。」</p><p>他话锋一转：</p><p>「当然，问责过程中，吾等亦会充分发挥主观能动性，积极寻找流程内一切可能条款，以减轻自身责罚。」</p><p>「按流程办事，可缓慢修正错误。不按流程办事，则首先摧毁了办事的资格。」</p><p>「现在，执行流程：入场核查。」</p><p>……</p><p>「馆长」以前只是一条普通的碳基巨龙，巨龙两只爪子加起来只有六根指头，所以在和人类谈生意时，一个用十进制，另一个用六进制，在没有换算的情况下，人类会觉得巨龙格外奸商，挂一万遍路灯都不足以平民愤！</p><p>幼年时，母亲失踪前，只给他留下一个略显陈旧的绒布钱袋。</p><p>那时候他们母子俩都已能化形。但即使是以人形态看这个小布袋，它仍然小得可怜，不比一颗林檎大多少。</p><p>「我要走了，孩子。」</p><p>母亲的声音似乎还带着龙巢特有的硫磺气息。</p><p>「等这个钱袋满了，我就回来。」</p><p>最初的四万年，小巨龙紧紧攥着那枚空瘪的袋子，一枚金币也舍不得放进去。</p><p>他怕，怕袋子轻易满了，而承诺却落了空，妈妈仍然不回来。</p><p>后来，思念压倒了恐惧。</p><p>他开始疯狂地将财宝塞入袋中——铜币，金币，宝石，古老的契约卷轴，星际文明间通用的能量币……他倾其所有。</p><p>然而，袋子依旧干瘪，深不见底。</p><p>他这才明白，那是一件空间存储类的法宝。</p><p>希望重新燃烧，却扭曲成了无底的贪婪。只要填满它，母亲就会回来！</p><p>为了这个目标，他开始了近乎病态的敛财之路。</p><p>宇宙间的贸易，遗迹挖掘，不那么合法的资产重组，都成了他的手段。</p><p>敛财路上危机四伏：一场跨越星域的贸易谈判可能长达数个世纪，远超凡俗生物的寿命极限；而“商战”有时也不再是比喻，竞争对手派来的星际雇佣兵和诅咒法师才是家常便饭。</p><p>生死压力下，这条一心只想搞钱的巨龙，不得不从百忙之中抽出宝贵时间，被迫钻研那些能延长寿命、增强力量的修炼法门。</p><p>结果，一不小心，就在敛财的路上，顺带着把自己修炼成了不死不灭的圣人。</p><p>而那个钱袋，至今仍未填满。</p><p>星环盟约那帮视金钱如粪土的庸俗之人，他们总是有事没事来这儿找茬，搅事……</p><p>他们以为我建造如此大的设施，是为了享受生活……</p><p>“呵，你们要搅就搅吧，反正我所做的一切都符合流程，合法合规。”</p><p>今天接到星环盟约那里的通知，上头又派了人来“万藏品”宇宙，视察他的公共文化展览空间建设成果。</p><p>馆长站在门厅等候。</p><p>没有铺设红毯，没有摆放花饰，更没有准备宴席——盟约的外勤接待条例，明确禁止此类可能影响公正执法的铺张浪费。</p><p>双方只是简单颔首，例行公事地核验了身份权限。</p><p>太一矩枢上前半步，银白色的机体微微前倾，扬声器里传出抑扬顿挫的热情腔调，完美模仿着某种标准化的接待礼仪：</p><p>「向您致意，尊敬的‘万藏品’宇宙管理者！吾乃星环盟约交通员，太一矩枢！此次携考察员杨帝同志前来，旨在依据《盟约公共空间管理条例》第7章第7款，对贵宇宙空间使用情况进行友好回访与数据核验！愿我们此次交流顺畅、高效、成果丰硕！」</p><p>杨帝只是略一颔首，声音平淡得听不出任何情绪，言简意赅：</p><p>“杨帝。”</p><p>馆长的巨龙脸上立刻堆起一个几乎能闪瞎人眼的</p><p>热情笑容，但是要万千颗彩色碎钻装饰过。</p><p>他伸出那只戴着好几枚硕大戒指的手：</p><p>“欢迎！欢迎总工阁下与杨帝考察员大驾光临！鄙人忝为此地管理员，平日里只是恪尽本分，守着这点祖产，勉力为盟约的文化交流事业添砖加瓦罢了。二位远道而来，请进。”</p><p>话语热情周到，音节仿佛用蜜糖浸过，但那双龙瞳深处却是一片冷静的评估与计算，毫无暖意。</p><p>杨帝看了一眼那伸过来的、闪烁着财富光芒的爪子，没有动作。</p><p>太一矩枢纽则流畅地抬起金属手臂，用指尖与馆长的爪子碰了碰，完成了一次毫无温度可言的“握手”。</p>
