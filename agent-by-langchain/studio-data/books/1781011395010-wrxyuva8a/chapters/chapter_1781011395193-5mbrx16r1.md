# 马格努斯之惧

<p>「江城二中食堂守则：」</p><p>「1. 巴拉巴拉巴拉巴拉……」</p><p>「2. 呱啦呱啦呱啦呱啦……」</p><p>主旨是不要浪费食物，不要对舀菜的阿姨大吼大叫，不要吃到自己同类，也不要吃到自己同类的碎片。</p><p>杨帝寻思着，现在才上午九点，为何食堂内已经络绎不绝？</p><p>许多浑浑噩噩的群演在出餐口前排队，一眼就不是人、而且套着个三角头的“大妈”，则在出窗口后面用电锯打菜。</p><p>那些菜品看着有些恶心，他暂时没胃口。</p><p>杨帝深吸一口气，一口气把摆到台面上的所有规则全部违反。</p><p>成功勾出诡异本体现身。</p><p>一拳轰杀所有杂兵，一记鞭腿对关底BOSS来个下马威，一道法术剥离其物质躯壳，显露出其“崩坏”本质。</p><p>杨帝和马格努斯第二次见面。</p><p>「我等与你无冤无仇，为何追杀不止？！」</p><p>马格努斯一边操纵“诡异”与杨帝战斗至大道几乎磨灭，一边嘶声喊话。</p><p>“废话别多说了，小马哥，快把你地址告诉我，或者打开一道通往你那边的传送门，我要指导你关于艺术创作的10种甚至9种技巧！”</p><p>杨帝正在尝试定位马格努斯的位置。</p><p>对方似乎并不存在于此界……</p><p>马格努斯的本体，似乎完全游离于此方世界之外，其存在的根基深植于一个无法被常规空间距离所衡量的、更加深邃和异质的维度。</p><p>在灵界的“终极之战”中，杨帝的最大收获——是关于最后那条去往仙界的“通道”。</p><p>那是一条稳定可供通行的路。</p><p>一道短暂撕裂世界胎膜，能够窥探到界外的隧道。</p><p>他学习到了一点经验，关于如何“顺着网线到另一个世界去打人”的经验。</p><p>这个经验要求杨帝首先锻炼出超级智慧，不对，是超级肌肉。</p><p>用超级肌肉凝聚出“圣人”级别的超级力量，一拳打爆世界的壳。</p><p>就像灵界通往仙界的通道，就是用“灵茶山乂斧”劈出来的裂缝，一条连通“黄粱一梦/灵界”与现实世界/仙界的网线。</p><p>圣人，是帝临真一第五境。</p><p>他目前爬塔升级到第三境界而已。</p><p>开局炼气期，修为全靠吃。</p><p>江城二中这个“怪谈领域”内，几个规则怪谈副本，已经成了杨帝的自助餐厅。</p><p>食堂，艺术楼，人防工事……</p><p>他就像一头闯入精致恐怖主题餐厅的饕餮巨兽，所过之处，怪谈领域支离破碎，食破天惊。</p><p>那些精心设计的、用以收割恐惧，制造华丽悲剧的诡异存在，统统沦为他口中或难吃或古怪的点心。</p><p>吞噬完一个，都伴随着杨帝或嫌弃或吐槽的意念，以及对“小马哥厨艺”毫不留情的差评。</p><p>“规则太多，整整20条，失败！”</p><p>“规则太少，还不到20条，失败！”</p><p>“规则太复杂，居然还得靠注释表达意思，失败！”</p><p>“规则太简单，一眼就看明白，这么容易钻漏洞找空子，失败中的失败！！”</p><p>杨帝来到10年不开放一次的天文台，一口将盘踞于此的怪谈副本吞噬殆尽，一点残渣都不留，这就是光盘行动。</p><p>他扫视环形教学区。</p><p>阿巴等人到了图书馆后，一直停滞不前，不知在干什么牛犊子。</p><p>一看就很苟的几个邪道修士，都苟在高三零班内。这就是典型的不敢把握机会。</p><p>有一些熟悉的面孔，似乎找不到。整个江城二中校园，只有寥寥几十个灵界熟面孔。</p><p>包括59改、青丘白璃，似乎也不在这座怪谈领域内。</p><p>灵界众人，穿过那条世界裂缝，从网线里飞出来时，似乎是随机去往四面八方，夺舍了……某些路人的身体。</p><p>未经允许夺舍他人，实在有些抱歉。</p><p>但杨帝也控制不了自己的航向，当时他能保住意识，已经尽了最大努力。</p><p>只看后续有无方法，补偿一下被占据身体的人，以及他们亲近的人。</p><p>当然眼下最大的问题，是要先把那坨恶心人的诡异，从远方揪出来。</p><p>体育馆上空，已经达到第三境界“至尊”境的杨帝，凌然万物之上。</p><p>此处是最后的怪谈副本。</p><p>体育馆下方传来爆炸。</p><p>轰隆——！</p><p>整座庞大的体育馆如同被无形巨手捏碎的沙堡，钢筋骨架发出呻吟，混凝土墙体在冲击下瞬间化为齑粉，混杂着玻璃碎片和扭曲的金属，尘暴巨浪裹挟着冲击波向四面八方扩散！</p><p>“啧，狗急跳墙了？”杨帝立于半空，衣袂被爆炸的气浪吹得猎猎作响。</p><p>他脸上那点玩味彻底消失，眼神锐利如刀。</p><p>这爆炸不只是毁灭，而是马格努斯壮士断腕般的决绝！</p><p>它知道无法在正面抗衡这个恐怖的“食客”，竟不惜引爆自己盘踞在体育馆的最后、也是能量最集中的一根主触须，制造出毁灭性的混乱。</p><p>目的只有一个——掩护！</p><p>就在体育馆爆炸的烟尘尚未完全腾起，能量冲击波肆虐的同时，从爆炸中心、从操场地下、从实验楼的废墟阴影中……</p><p>数道漆黑、粘稠、散发着浓烈“崩坏”气息的触须如同离弦之箭，朝着完全不同的方向激射而出！</p><p>东南西北上下左右。</p><p>它要舍弃这处精心布置的“猎场”，将这些核心力量收回，遁入那无法被追踪的异质维度。</p><p>只要有一根成功逃脱，它就能瞬间恢复三成以上的实力。</p><p>甚至不需要蛰伏，就能无缝衔接下一次的诡异降临。</p><p>“想跑？问过我的胃口了吗？”杨帝冷笑一声。</p><p>看着那数道撕裂空气、意图遁走的黑芒，眼神中没有丝毫慌乱，反而是一种终于等到猎物入网的兴奋。</p><p>他缓缓抬起右手，五指张开，掌心对准了下方正被爆炸与逃窜触须搅得天翻地覆的江城二中校园。</p><p>“领域展开，白杨世界。”</p><p>嗡！</p><p>一种难以言喻的“存在感”，瞬间笼罩整个体育馆，乃至其周边数百米的空间。</p><p>仿佛有无形的画笔，以杨帝为中心，在现实的画布上重新涂抹了底色。</p><p>坚韧。</p><p>生命力。</p><p>这是踏入这片领域最直观的感受。</p><p>体育馆爆炸掀起的毁灭性冲击波，在撞上这无形领域的边缘时，如同麻雀撞上防弹玻璃。</p><p>狂暴的能量被瞬间分散，吸收。</p><p>足以摧毁银河系的冲击力，竟像是投入了深不见底的泥沼，仅仅激起了几圈微不足道的涟漪，便迅速平息下去。</p><p>碎石飞溅、钢筋扭曲、致命的冲击碎片……</p><p>在接触到白杨世界边缘的刹那，速度骤然降低，仿佛被无形的粘稠空气包裹。</p><p>而那些正疯狂逃窜的漆黑触须，此刻陷入了前所未有的恐慌。</p><p>无数触须一样的东西，散发着诡谲气息，纷纷从阴影中探出，缠绕上那漆黑的、代表着崩坏的触须！</p><p>「吔！此乃何物！！」</p><p>「不要掂我啊啊！！」</p><p>那是无数根长着和“猫”一样形状，但本质上是由肉束与绒毛拧合而成的“猫条”。</p><p>它们如舌头般舔舐着马格努斯的触手。</p><p>现场极其可怖，将视频上传到暗网都会被管理员封号，顺着IP地址拉黑名单。</p>
