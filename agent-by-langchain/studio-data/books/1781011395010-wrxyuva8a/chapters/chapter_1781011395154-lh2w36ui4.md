# 圆球炮弹

<p>“呜——呜——呜——！”</p><p>刺耳的警笛声由远及近，尖锐地撕裂了站台的喧嚣。</p><p>数辆造型极具未来感、线条硬朗的黑色装甲悬浮车如同幽灵般滑入站台，车门无声滑开，跳下一队全身覆盖着哑光黑色外骨骼装甲的士兵。</p><p>和火车上的“安保队”是统一风格类型。</p><p>他们的头盔是流线型的全覆盖式，眼部是散发着幽蓝冷光的复合目镜，手中武器造型奇特，能量槽闪烁着危险的光芒。</p><p>动作迅捷、无声、整齐划一，瞬间就占据了有利位置，将肯打鸡店面包围得水泄不通。</p><p>“里面的人听着！这里是‘城市滑头’第三战术小队！”</p><p>一个经过扩音器处理、冰冷而威严的声音响起，“立刻终止攻击行为！释放人质！否则我们将采取强制措施！”</p><p>“‘城市滑头’隶属攻壳机动队。”青丘白璃的狐耳警惕地竖起，“这是凡界王朝的精锐执法部队……看来事态不小。”</p><p>店内，炸薯条机停止了喷射热油，冰淇淋机也停下了糖浆弹。但它们并未解除武装，冰冷的机械臂依然对准人质。</p><p>“强制措施？哈哈哈！”</p><p>炸薯条机发出一阵免费素材库里随便下载的罐头笑声，“吃意大利面要拌42号混凝土！因为这个螺丝钉的长度，它很容易会直接影响到挖掘机的扭矩！”</p><p>它说话逻辑似乎彻底混乱，但动作却带有隐蔽的目的性。</p><p>然而，攻壳机动队被炸薯条机的无逻辑喊话吸引了大部分注意力，一时间被迷惑住，并没有注意到冰淇淋机和炸薯条机的小动作。</p><p>僵持了约5分钟，期间炸薯条机的狗屁不通废话不断。</p><p>某一时刻，店内角落那台原本安静待机的扫地机器人，突然发出高频嗡鸣！</p><p>嗡——嗡——嗡——</p><p>它的底盘过载旋转，如同失控陀螺，在原地疯狂打转，摩擦地板发出刺耳的尖啸和焦糊味。</p><p>与此同时，旁边那台巨大的商用微波炉猛地亮起刺目的光芒！</p><p>炉门紧闭，内部的磁控管超功率运转，发出沉闷的、如同心脏搏动般的“嗡嗡”声，甚至能看到炉门缝隙处溢出的危险蓝白色电弧。</p><p>它显然不是要加热什么，而是在疯狂地聚集、压缩能量。</p><p>他们要做什么？攻壳机动队实在无从下手。</p><p>扫地机器人是很基础的商用款，外壳早已磨出斑驳划痕，原本用于规划路径的激光雷达布满灰尘，寻常情况下只能完成基础的清扫任务。</p><p>而那台微波炉，也不过是用来加热汉堡包的普通款型。</p><p>“谈判破裂，失控机械有新动作……”就在攻壳机动队指挥官下令强攻的刹那——</p><p>“目标锁定！发射程序启动！”冰淇淋机冰冷的电子音盖过了所有混乱。</p><p>嗡！！</p><p>一声低沉到穿透骨髓的震鸣响起！</p><p>咻！！</p><p>只见那台高速旋转、底盘几乎要擦出火花的扫地机器人，在离心力达到顶峰时，底盘猛地向上弹开。</p><p>一个拳头大小、表面布满不规则凸起、闪烁着幽蓝光芒的金属圆球装置，被离心力猛地甩向天花板。</p><p>随即，超载运转的微波炉爆发了！</p><p>一道凝聚到近乎实质的、高频高能的定向微波束，精准地轰击在“圆球装置”底部！</p><p>刺眼的蓝白色电光爆闪。</p><p>圆球装置如同被无形的巨锤狠狠击中，瞬间获得了恐怖的初始动能，化作一道肉眼几乎无法捕捉的流光残影。</p><p>它带着撕裂空气的尖啸，无视了肯打鸡的钢筋混凝土天花板（直接熔穿了一个小洞），以惊人的速度直冲云霄。</p><p>它的目标极其明确。</p><p>城市最高层，那座悬浮在云雾缭绕的巨峰顶端、宛如水晶王冠般闪耀着冷峻光芒的浮空建筑群核心。</p><p>钧士叹顶堡城市智能公共设施主控大厅！</p><p>“阻止它！”城市滑头-攻壳机动队小队长瞬间反应过来。</p><p>她肩部的微型导弹发射器瞬间弹出，锁定目标。</p><p>然而，那圆球的速度太快，轨迹刁钻，而且体积太小！</p><p>小型拦截导弹刚刚点火升空，圆球就已经化作一个小点，消失在层层叠叠的浮空建筑群阴影之中。</p><p>“目标已突破拦截！方向，顶层主控区！”队员急促的报告声在通讯频道响起。</p><p>店内。</p><p>炸薯条机和冰淇淋机在圆球发射成功瞬间，就被武装人员集火。</p><p>它们不再抵抗，甚至连炸薯条和冻奶油都不在售出或射出。</p><p>仿佛完成终极使命，冰淇淋机，炸薯条机，在枪林弹雨中，它们电子眼中的红光缓缓熄灭。</p><p>喷射热油和糖浆的管道无力地垂下，机体发出几声短促的、类似临终喘息般的“咔哒”声，彻底瘫软不动，变成了一堆冒着青烟、沾满油污和糖渍的废铁。</p><p>人质们惊魂未定。</p><p>看着死完的机器，狼藉的门店，顾客和店员爆发出更大的混乱和哭喊，争先恐后地试图逃离这个诡异的快餐店。</p><p>“那东西……”青丘白璃的狐耳高频抖动，死死盯着圆球消失的方向。</p><p>她声音带着前所未有的凝重：“我感觉到一股非常隐晦但极其恶意的灵能波动……是域外天魔的气息。”</p><p>杨帝的眼神瞬间锐利如刀。</p><p>他之前就感到一丝微妙的违和，此刻白璃的感知印证了他的直觉。</p><p>那圆球里，确实有些不对劲的东西。但他看不懂是什么。</p><p>“看不懂”，并不是他智力不够，而是对于这个世界的理解水平不深。</p><p>圆球里的玩意，貌似与灵凡二界的大道、本源、法则之类的事物息息相关。</p><p>而青丘白璃又说，她感觉到“域外天魔的气息”。</p><p>“域外天魔？可我并未感受到接近‘零值’的现实丰度喔。”杨帝一边吃葡挞，看向狐狸。</p><p>本地土著大能青丘白璃解释：</p><p>“这其实是种经验之谈。以往域外天魔降临的地方，都会有法则混沌、本源紊乱的先兆。</p><p>“这种波动极为隐匿，若不是在一线战场抗击域外天魔经验丰富、对天魔的气息格外敏感，根本察觉不到。</p><p>“但最终，域外天魔都会引发此地灵能丰度趋近‘零值’，抹除周遭的现实。”</p><p>杨帝微微皱眉，将手中吃了一半的葡挞放下，心中快速思索着其中的关联。</p><p>“难道说，这一系列机械失控事件，背后都是域外天魔在操控？”</p><p>“不一定……从来没有听说过，域外天魔能够诞生智慧。”</p><p>“但至少，这个冰淇淋机和烤面包机，它们是‘域外天魔’的爪牙。”</p><p>“但是，它们为什么要针对君士叹顶堡城市智能公共设施主控大厅？”</p><p>一人一车一狐一鱼饭饱酒足。杨帝站起身，透过天花板破洞，看向上方的智能公共设施主控大厅。</p><p>他的目光瞬间扫过店内所有人。</p><p>最终，再次定格在那四个缩在角落、似乎也被“吓傻”了的黑袍老头身上。</p><p>“呵。”杨帝走过去。</p>
