# 钓鱼佬二三事4

<p>下一层楼，要经过两节楼梯。</p><p>每节楼梯一个大跳可下去，然后需要转弯，继续下一节楼梯。</p><p>假设一个大跳+转弯耗时一秒，顶楼六楼到一楼，至少需要10秒下楼梯。</p><p>但还有另一个方法。</p><p>两点之间，线段最短。</p><p>杨帝几乎没有丝毫犹豫，瞬间凝聚全身力量，从天台纵身跃下楼。</p><p>狂风在耳边呼啸而过，强烈的风压几乎要将他的呼吸都压制住。</p><p>杨帝头朝下，神色平静。</p><p>“砰！！”</p><p>短短数秒，杨帝便如同流星般坠落到一楼。</p><p>可能有些狼狈，他并没有稳稳落在地面，而是脸朝下，砸在地上。</p><p>坠落用了2秒，杨帝趴在地上睡了5秒。</p><p>之所以要睡这么久，是因为杨帝大意了——还记得一天前，他用装了坏酒的啤酒瓶试探天台上那只死人的手么？</p><p>那只手抓住玻璃瓶，扔了下楼。</p><p>现在，一楼大门外，一地玻璃渣！</p><p>从六楼跳下去，杨帝脸着地砸在玻璃渣上！虽然还不够资格划开他脸皮，但还是挺疼的。</p><p>睡完五秒后，毫发无损的杨帝迅速弹起，立刻朝着钓鱼佬的方向冲去。</p><p>全程仅耗时7秒，比原本爬楼梯快了3秒。</p><p>节约出来的3秒，能做很多事了。</p><p>……但杨帝来晚了。</p><p>只不过这里的“来晚”，并非指钓鱼佬已经遭遇不测。</p><p>而是他在杨帝赶到前，已经脱离了危险。</p><p>他跪伏在地，浑身湿透，喘着粗气，似是刚从水里捞出来。</p><p>他原本整齐的头发，此刻凌乱地贴在脸上，身上的衣服也紧紧裹在身上，不断有水珠滴落。</p><p>碳素鱼竿不见了踪影，整个人气喘吁吁地跪在地上。</p><p>看到杨帝赶来，带着劫后余生的庆幸说道：“幸亏你刚才来救我，把我从水里拉了起来。再晚一会儿，我恐怕就没救了。”</p><p>“……你感觉到有人把你拉上来了？”</p><p>杨帝面上波澜不惊，但内心满是问号。</p><p>他非常清楚，自己根本来不及把钓鱼佬从水里拉起来——他刚刚才赶到而已。</p><p>但他注意到，钓鱼佬的手腕上确实有个清晰的抓痕，那痕迹呈现出一种不自然的青紫色，五指印十分明显。</p><p>确实是被一只手，狠狠抓住留下的。</p><p>钓鱼佬缓过神来，他敏锐的直觉开始觉察到不对，并且很快理清现状——</p><p>“小伙子，你不是上楼了吗？怎么从门外来的？”</p><p>“呃……我在2楼玩跑酷，翻窗下来的。”</p><p>“若你刚刚才赶到，那把我拉上水的是……”</p><p>杨帝配合钓鱼佬，倒吸两口凉气！一楼气温显著上升。</p><p>杨帝的视线越过钓鱼佬，在楼梯井那儿，看见一截露出的苍白的手。</p><p>皮肤毫无血色，正缓缓地缩回到黑暗。</p><p>那只手，那是杨帝第一天来，第一眼就看到的，藏在电梯井里的苍白的手。</p><p>他刚还给它上香（香烟）道歉。</p><p>只能是它，有时间、有能力把钓鱼佬救出积水的电梯井了。</p><p>它看起来气消了，有些傲娇，有些害羞。</p><p>“大叔，到底怎么回事？你慢慢说。”杨帝一边盯着楼梯井，一边扶着钓鱼佬站起身来。</p><p>钓鱼佬心有余悸：“我正好好钓着鱼呢，突然听到水里有奇怪的动静……”</p><p>他还原出事情全貌。</p><p>他听见水里有动静，但还没反应过来，就感觉一股巨大的力量把他往水里拽。</p><p>要是放在外头，他铁定反应过来，这鱼至少上百斤！！</p><p>但这电梯井是一潭死水，上百斤的鱼，不可能在如此狭窄的空间内孕育。</p><p>钓鱼佬掉水了，这时，突然有人抓住它的手腕，把他往上拉。</p><p>“我当时以为是你，可等我回过神来，你还没到，我就知道，是有什么东西在帮我。”</p><p>他一边换衣服，一边喝热的速溶奶茶。</p><p>这电梯井，陈年老水沟，确实臭。</p><p>但钓鱼佬丝毫没有生理厌恶感——杨帝判读他的微表情得出这一结论。反而是某种深藏不露的激悦……狂喜。</p><p>他只是兴奋地说着：“小伙子……我就说我的猜测有搞头，这些黑暗的水体，它们本质上是一体的，黑色积水，从更高维度或者层面来看，连接到另一个时空……”</p><p>杨帝帮忙从渔具包里，翻找出几件干燥衣服递过去。</p><p>天知道他出来钓鱼，怎么会提前准备那么多干衣服，很有经验似的。</p><p>钓鱼佬：“有东西把我拽下水去——但一个小小的积水电梯井，不可能诞生这样的生物，对吧？”</p><p>杨帝想说不一定。</p><p>天知道大自然的逻辑是什么，房屋角落的阴影，都可以滋生出长得像猫猫的舌头。</p><p>“叔，这楼里的事情越来越诡异了。不管怎样，我们先离开这儿，找个安全的地方再说。”</p><p>杨帝说道，拎上钓鱼包，准备扶钓鱼佬朝楼外走去。</p><p>但那男人拒绝了。</p><p>他扭头看向身后的电梯井。</p><p>“我鱼竿掉里面了。”</p><p>钓鱼佬执意要把鱼竿捞回来。</p><p>但杨帝从钓鱼佬那闪烁兴奋光芒的眼神里看出来，他目的不止于此。</p><p>“叔，这太危险了，刚刚你也看到了，这电梯井里不知道藏着什么东西……或者，你必须告诉我，为什么执意要留在此，你的理由应该不局限于鱼竿。”</p><p>杨帝试图劝阻，并套话。</p><p>钓鱼佬最终决定透露他秘密的一部分。</p><p>“小伙子，你似乎与我一样并非一般人，所以我才把这件事情告诉于你，但是你答应我，我讲述完后，你要远离这片危险地方，不要待在这了，你还年轻，你的生命有无限可能。”</p><p>杨帝只好郑重地点点头。</p><p>先听听情况，再看是否遵守约定吧。</p><p>钓鱼佬深吸一口气，脸上的表情变得凝重起来：“我曾是老师。那一天，我和几个往日的学生，相约去小巷子里的小酒吧聚会……”</p><p>……</p><p>我带的第一届学生，是最让我骄傲的一届。</p><p>那时候，那中学的旧校长还没退休，我们的办学水平和理念一直保持着高度先进。</p><p>自从旧校长退休，新校长上任后，那中学开始无可避免走下坡路，之后我带过的每一届，都是在刷新“最差的一届”。</p><p>说回正题。</p><p>我带过的第一届学生里，其中4个是最让我满意的。</p><p>你知道吗，其他人只能称为“成才”，而他们四个，真正能称为“成人”。</p><p>就是那四个孩子，他们各自走向不同的路，然后在同一天约上我，一起去小酒吧聚会了。</p><p>……诶，关于他们我也不多做介绍。</p><p>毕竟已经逝去的人，说再多，也不能让他们复生。</p><p>那时候我们坐在小酒馆2楼，人很少。</p><p>那儿的特调非常贵，一杯九十！够我四天饭钱。坐在我右手边第一个学生点了杯“天蝎座”，那酒里还真有只小蝎子！</p><p>然后，灯灭了。</p><p>小酒吧突然停电了几十秒，现场陷入黑暗。</p><p>黑暗压得人喘不过气来。</p><p>我直觉一向很敏锐，瞬间察觉到不对。</p><p>一股寒意从脊梁骨直往上冒，有什么极其危险的东西正在靠近我们的世界！</p><p>我当场大喊：“快跑！”下意识地拉上身边最近的一个学生，不顾一切地往楼下冲！</p><p>一切都太快，太突然了。</p><p>我感觉手中一紧，像是有一股巨大的力量抓住了我拉着的那个学生！</p><p>那股力量，硬生生地把他往放满酒杯的桌子方向拽。</p><p>那力气大得超乎想象，我根本抗衡不了！</p><p>手一松，那学生眨眼间就消失了！</p><p>求生的本能还是驱使我拼命跑下了楼，你知道的，极度恐惧时，肾上腺素开始发力。</p><p>我跑到1楼，那里还有备用光源，直觉告诉我那里比较安全。</p><p>十来秒后，酒吧老板重新开了电闸，光明恢复。</p><p>我顾不上大口喘气，心急火燎地跑回刚才聚会的地方。</p><p>我不知道他们发生了什么。</p><p>方才感应到那巨大的危险，我因为距离楼梯最近，所以才有时间跑下去。</p><p>等我回到二楼。他们消失了。</p><p>我的学生都消失了。</p><p>桌上的酒杯，基本都保持着原样。</p><p>只有原本泡了只蝎子的“天蝎座”特调，此刻正在“咕噜咕噜”地冒着气泡。</p><p>蝎子也随学生消失了。</p>
