# 字面意义·缝合大道

<p>“蟑螂”是一种遍布诸天万界的超级生命，以其生命力强盛而著名。</p><p>人们常常形容它们“像杨帝般顽强”。</p><p>……</p><p>以杨帝为中轴线，整个灵界，正在被灵茶山乂斧切为两半。</p><p>此时此刻，再停下那把创世之斧，意义已经不大。</p><p>宇宙裂痕，已经长达5AU。</p><p>世界被切分的进程，无可逆转。从引动满血版灵茶山乂斧开始，此世就注定走向彻底毁灭。</p><p>这个过程可能会持续几十上百年。</p><p>超光速扩散的创世裂缝会不断扩张，吞噬沿途所有物质，能量，时空，维度，因果……直至万物俱灭。</p><p>从宇宙尺度看，百年光阴，白驹过隙罢。</p><p>和灵界历史比起来，哪怕只是和一个小小的元婴修士的寿元相比，百年不过是弹指一瞬。</p><p>三位准圣看向灵界。</p><p>上下四方，八荒六合，九天十地。万事万物将走到尽头。</p><p>“残星道人……这么做，只为对付一个白杨大帝，值得吗？”</p><p>圣人负手而立，目光注视杨帝消失之处。</p><p>“他没死。”</p><p>不只是三位准圣，包括其他灵界土著、真仙境大能，无不被这简单三个字蕴含的恐怖信息量所震慑。</p><p>一点微光，微弱得如同风中残烛，却在绝对的虚无中固执地燃烧起来。</p><p>那是蕴含着某种生命冲动的波动，像是母胎中婴儿那蓬勃迸发的生机，地平线尽头喷薄欲出的朝阳，如远海地平线刚刚露出桅杆尖的航船。</p><p>微光迅速蔓延、勾勒，如同最精密的打印机在修复被擦除的图案。</p><p>骨骼、血肉、经络、皮肤……</p><p>杨帝的轮廓在虚无中重新凝聚。</p><p>他那双刚刚在梦中经历了十六万倍速思维风暴的眼眸，此刻睁开，眼里不再是圆咕噜溜的狡黠或愤怒。</p><p>而是近乎神性的漠然，以及洞悉本源后，对“自我”无限延伸的决绝。</p><p>凤凰涅槃，烈火烧尽，超越生死。</p><p>“仅仅是为了把当事人灭口，就把整个世界毁掉，真的值得吗？”</p><p>时间已过去1001毫秒。</p><p>“嗡——”</p><p>一声震荡寰宇的嗡鸣，超越“抹除”的寂静。</p><p>杨帝的头皮处，无数根蕴含着混沌气息、闪烁着黑金色泽的发丝，以一种匪夷所思、超越了空间扩张极限的速度疯狂暴涨！</p><p>它们无视了正在崩塌的时空结构，无视了那抹杀万物的斧光，如同亿万条开天的混沌巨龙，撕裂了归零的黑暗。</p><p>发丝交织、缠绕、瞬间构筑！</p><p>一个庞大到令真仙窒息，让准圣都为之失神的巨物，在千钧一发之际悍然成型。</p><p>那是一个由无尽坚韧发丝编织而成的、直径横跨30AU、无比巨大的——头发空心球。</p><p>它以杨帝残存的位置为核心，瞬间膨胀。</p><p>其体量之巨，足以将太阳系八大行星都轻松包裹其中。</p><p>但这团“毛发球”包裹的并不是太阳系。</p><p>而是那道正在以超光速扩散的世界裂缝。</p><p>杨帝用头发，把那条裂缝包裹了起来！</p><p>“轰隆——！！！”</p><p>正在急速扩张的灭世斧光，狠狠撞在了这突兀出现、巨大无朋的头发巨球内壁！</p><p>真空听不见惊天动地的爆炸，只有令人牙齿发酸、仿佛宇宙根基被强行撕裂的吱嘎。</p><p>吱嘎——嘎——</p><p>那灭世的斧光，宇宙的裂缝，竟真的被他漫天狂舞的黑色毛发所阻挡。</p><p>被强行定义、不被抹除的毛发屏障，硬生生抵住了创世之斧的锋芒。</p><p>那巨大的发丝球体，成为了横亘在毁灭与残存世界之间的一道不可逾越的堤坝，将后续汹涌而来的斧光洪流死死拦住！</p><p>“挡住了……真的挡住了？”涅槃轮劫元尊咳出带着道则碎片的金血，眼中满是难以置信的骇然。他们燃烧本源引动的创世投影，竟被一个……头发球拦下了？</p><p>不仅仅是挡住。</p><p>杨帝那双漠然如渊的瞳孔中，倒映着正在被撕裂的宇宙图景。</p><p>“缝。”</p><p>一个冰冷的字眼，仿佛宇宙的律令。</p><p>只见那包裹着残存灵界的巨大发丝球体表面，无数根坚韧到不可思议的发丝，如同拥有生命般，骤然分化出更细、更密的“针线”！</p><p>发丝针线无视时空距离，无视法则崩解，精准地刺入那道被斧光劈开的、不断扩张的宇宙裂缝边缘！</p><p>咻！咻！咻！</p><p>亿万根发丝穿透了虚无与现实的界限，如同最精密的缝合手术。</p><p>穿梭、交织、打结。</p><p>在混沌的虚无背景上，强行将正在分离、破碎的时空结构“缝合”起来。</p><p>三位准圣看得心神俱裂。他们哪见过这样的场面？</p><p>“收。”</p><p>杨帝再次开口。</p><p>随着他的意念，那横跨星海的巨大发丝球体，连同那些深入宇宙裂缝进行缝合的亿万发丝针线，瞬间如同退潮般收缩！</p><p>速度之快，远超其伸展之时。</p><p>漫天的暗金流光倒卷而回，所有的发丝都精准地、丝滑地收束回杨帝的头皮。</p><p>前一秒还是横亘星海、缝合宇宙的造物主之姿，下一秒，杨帝已恢复成那看似平凡的黑发青年模样。</p><p>只有他周身残留的、尚未完全收拢的长发，以及那双深不见底、仿佛蕴藏着整个宇宙风暴的眼眸，证明刚才那惊世骇俗的一幕并非幻觉。</p><p>他静静地悬浮在破碎的虚空之中，脚下是勉强被缝合、但依旧遍布裂痕的灵界宇宙。</p><p>这，就是只有大能才可以掌控的“世界裂缝弥合技术”。</p><p>面前，是因本源燃烧过度而气息萎靡、形容枯槁的三位准圣。</p><p>以及，那位从始至终都显得超然物外，此刻眼中终于闪过一丝真正波澜的——残星道人。</p><p>“打怪升级结束，勇者已经满级。”</p><p>杨帝的声音平静无波，他的目光在虚无中与残星道人对撞。“我们可以好好谈谈了，灵界的野生BOSS，一切黑暗的根源，残星道人。”</p><p>不知多少亿年以来，灵界唯一一位圣人。</p><p>“站住。”三位准圣还想冲去拦下杨帝。</p><p>但被他一拳轰爆，瞬间沦落观众席。</p><p>残星道人面无表情，既不轻松，也没表现出严肃。</p><p>“白杨大帝，你想问什么？”圣人率先开口，声音仿佛从无尽岁月的深处传来。</p><p>杨帝挑眉：“首先，我是不是还在梦中？这里是不是现实？”</p><p>嵌套四层梦境，杨帝已有些难分虚实。</p><p>梦境，也是一种「虚拟世界」。</p><p>虚拟世界，底层逻辑几乎是相同的。</p><p>杨帝作为此界有史以来最强大的灵能者，也无法分清。</p><p>残星道人微微挑眉，眼中闪过一丝意外。</p><p>随即，露出一抹意味深长的笑意。</p><p>灵界唯一的圣人，出现在杨帝面前。</p><p>——是的，没有一个“移动”的过程，也不似瞬移、闪现那般突兀。</p><p>没有空间波动涟漪，没有时间凝滞的痕迹，甚至连空气流动都未曾改变。</p><p>他就像一幅早已存在的古老画卷，在众人意识到他的瞬间，便自然地融入了眼前的场景。</p><p>仿佛，残星道人的存在超越了“移动”这一概念，是一种永恒的在场。</p>
