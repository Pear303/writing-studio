# 活命的好办法

<p>队长苦涩地开口：“杨帝，兴趣归兴趣……但红皇后已经判了我们死刑。12小时后，我们都要和这艘船一起化为宇宙尘埃了。就算您可以扛过去，我们也……”</p><p>主神商店里，其实还有很多保命道具，可以随时兑换。</p><p>但他们小队很穷很穷。</p><p>能够扛住200亿吨TNT当量的道具，把他们全部卖了，再把所得的积分翻上10倍都不够。</p><p>飞船外面就是一望无际的宇宙深空。</p><p>诸如“脱身卷轴”这种低等级道具，根本不足以应对。</p><p>“活不了？谁说的？”</p><p>一大圈抬手，轻轻拂过身上那层仿佛拥有生命般缓缓蠕动的漆黑“战甲”。</p><p>那深邃的黑色，仿佛连光线都能吞噬。</p><p>“你们似乎对我的‘衣服’很感兴趣。”</p><p>杨帝的目光扫过众人惊疑不定的脸，“它不是什么高科技流体金属，也不是什么共生体……它是我的‘毛’。”</p><p>“毛？”铁砣下意识地重复，以为自己听错了。</p><p>“没错，毛发。”杨帝肯定道。下一秒，心念微动！</p><p>嗡——！</p><p>一股无形的波动以杨帝为中心扩散开来，他身上那层蠕动的“黑甲”骤然沸腾！</p><p>无数细密到肉眼几乎无法分辨的黑色丝线，如同被赋予了生命的海藻，违背了所有物质守恒定律，开始几何级数地疯狂生长。</p><p>它们不再是紧贴皮肤的薄膜，而是化作汹涌澎湃的黑色潮水，瞬间淹没了杨帝的整个身形，并且以惊人的速度向四周蔓延！</p><p>黑色头发从最开始的丝状，一撮一撮，拧成一股，形成“电缆”状结构。</p><p>毛发彼此缠绕融合，发出令人牙酸的“咯吱”生长声。</p><p>“我的天……恐怖长毛怪……”眼镜的战术目镜疯狂报警。</p><p>战斗力探测器显示，周围空间物质密度和生物能量场的急剧攀升，数值瞬间爆表！</p><p>他从未见过如此诡异的现象。</p><p>相比之下，星际虫族简直就是营养不良啊。</p><p>刚刚醒来并通过火鸦补习完现状的“影子”，面对着密密麻麻的头发，倒也没有害怕。</p><p>她只是社恐，而不是密恐。</p><p>杨帝的身影，已经完全被这疯狂生长的黑色毛发吞没。</p><p>黑色的“浪潮”并未停止，它如同拥有意志的活物，蹬开了红皇主机房厚重的合金门。</p><p>汹涌地涌向那条刚刚经历战火洗礼、遍布硝烟与金属残骸的走廊！</p><p>在轮回小队、和红皇后虚拟影像惊骇的目光中，那黑色的“毛发洪流”冲入了之前他们遭遇丧尸与拼装机器人混战的战场区域。</p><p>接下来的一幕，让所有人胃部翻腾，灵魂震颤。</p><p>蠕动的黑色毛发如同无数饥饿的触手，精准地卷起地上散落的虫族兵蚁残肢。</p><p>送进杨帝口中。</p><p>生啖虫族，杨帝获得大量物质。</p><p>再加上自身以违背质能守恒的方式，无中生有出大量质量、能量。</p><p>黑色毛发的生长和吞噬过程，持续了整整11个小时。</p><p>当那蠕动的黑色浪潮终于平息下来时，原本狼藉的战场区域变得干净了许多。</p><p>地上的虫族尸体、菌毯，已经消失不见，甚至连那些机器人残骸也被杨帝一扫而空，真实铜牙铁齿不锈钢胃。</p><p>唯独那上百具人类丧尸残骸，被杨帝小心地收集起来，堆在一块火化了。</p><p>现在，呈现在众人眼前的，已经不再是一个人形的杨帝。</p><p>而是一个占据了机房大半空间、直径接近十米、巨大而致密的黑色毛球！</p><p>毛球的表面并非光滑，而是布满了不断微微起伏，仿佛在呼吸的脉络，散发着深沉如渊的气息。</p><p>“时间差不多了。”杨帝的声音从毛球内部传出，清晰无比，“影子。”</p><p>缩在角落、好不容易没再晕过去的影子猛地一激灵：“啊？在……在！”</p><p>“你的异能，‘阴影虚化’，范围极限是多小？能钻进毛发球体内吗？”杨帝问道。</p><p>“勉……勉强可以！半径一米左右……但需要目标不剧烈反抗，而且……而且环境阴影浓度要够……否则阴影范围会扩张。同时这个技能只可以维持一个小时。”</p><p>影子结结巴巴地回答。</p><p>“很好。现在和你队友，走到我这个‘毛球’旁边。”</p><p>杨帝的声音带着不容置疑的命令，“然后，发动你的异能，把你们自己‘虚化’，融入阴影。最后，进入毛发球。”</p><p>“融入……阴影？”</p><p>队长瞬间明白了杨帝的意图，心脏狂跳，“您是说……让我们躲在您的……毛发里面？并依靠影子虚化，来抵抗爆炸的物理冲击？”</p><p>众人利落地行动起来，服从命令，听从指挥。</p><p>这11个小时里，他们探索了科研飞船的其他地方，包括垃圾投射舱、引擎室、逃生舱等，但真的找不到任何逃离方法。</p><p>就比如那些逃生飞船，都被密密麻麻的菌毯覆盖。扒开菌毯，才发现逃生舱已经成为虫卵培养舱，他们恶战（逃窜）了好几十分钟才逃出来。</p><p>可以想象，如果飞船上还有大批活人，他们会在如何惊慌与绝望之中，被虫族慢慢折磨至死，最后根本没有逃生希望。</p><p>与之相比，“安乐死”是人道得不能再人道的了。</p><p>轮回者小队，彻底山穷水尽。</p><p>不管怎么样，都只能信杨帝。</p><p>“物理冲击只是聚变爆炸最基础的一部分。200亿吨TNT当量的能量释放，核心是光辐射、冲击波和粒子流。</p><p>“我的‘毛’会吸收、分散、转化大部分能量，最大程度抵抗冲击波、光辐射等杀伤。</p><p>“而你们的‘虚化’，是确保你们的体积尽可能小，我包裹的毛发球尽可能厚。</p><p>“红皇后，你应该已经发现飞船‘等离子推进器喷口’的异常了吧？”</p><p>红皇后没有显露身形，以免吓晕影子。</p><p>她通过广播说道：</p><p>「是的……杨帝先生，我的监控检测到等离子推进器喷口被堵上了异物，但那并非虫族所为，难道……」</p><p>「该异物……具有极高的能量吸收与转化特性，并且……正在主动承受喷口核心的等离子体流冲刷。」</p><p>「喷口核心温度：标准工况下为摄氏32000度。异物正在该温度下持续存在并……增殖？」</p><p>广播声音带着前所未有的困惑，和人性化的惊悚。</p><p>杨帝的声音从毛球内部传出，带着一种近乎享受的慵懒：“我只是在那里‘泡个澡’而已。”</p><p>毛球表面微微蠕动，仿佛在回应主人的话语。</p><p>轮回小队成员顺着毛球延伸的方向看去——虽然隔着厚重的舱壁看不到，但他们脑海中都浮现出飞船尾部那巨大的等离子推进器阵列。</p><p>其中一个喷口，此刻恐怕正被杨帝那疯狂生长的、坚韧无比的黑色毛发彻底堵塞！</p><p>杨帝是主动将自己的“毛发”延伸，探入了喷口最核心、温度最高、能量最狂暴的区域。</p><p>每根探入推进器喷口的毛发，都如同亿万条贪婪的舌头，疯狂地舔舐着那足以瞬间气化星舰装甲的稠密等离子体喷流。</p><p>狂暴的能量洪流冲入毛发纤维，带来的是极致的毁灭与痛苦。</p><p>但随即，更适应高温高压环境的分子结构 以更快的速度再生重构！</p><p>每次破坏与重生的循环，都让毛发纤维的耐热极限、能量传导效率、结构强度呈指数级数飙升！</p>
