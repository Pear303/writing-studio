# 未作牺牲

<p>……</p><p>钓鱼佬离开后，杨帝转身面向那面传出震耳欲聋老鼠叫声的墙壁。</p><p>此刻，整面墙都在微微颤抖，仿佛有一股巨大的力量在墙内涌动。</p><p>他尝试过用毒烟去熏，放火在内部烧，但对墙中之鼠无济于事。</p><p>隔上一天两天，它们便会卷土重来，继续作妖。</p><p>而且这些老鼠还会编织噩梦。</p><p>夜深人静，杨帝稍一放松警惕，便会陷入它们精心构筑的噩梦之中。</p><p>在梦里，钢筋混凝土墙体像海浪般涌动，无数老鼠从中冲出。</p><p>它们眼睛空洞无神，嘴里发出无声尖啸。</p><p>这大概是某种精神方面的攻击，但杨帝没感觉到任何伤害。</p><p>杨帝用那块镜片作为图腾，区分现实与梦。</p><p>这块镜片比较特殊，在现实用它来照镜子，只会看见自己的后脑勺，看不到正脸。</p><p>墙中之鼠叫声越来越凄厉。</p><p>杨帝手中的镜子残片，映照出自己清晰的正脸。</p><p>“看来我还在梦里……这房间真是一天比一天难待下去了。”</p><p>他闭上眼。按照经验，再次睁开眼时，应该就能退出当前梦境。</p><p>……</p><p>杨帝睁眼。</p><p>镜子残片里仍然显现出自己的正脸。</p><p>他一转身，自己站在了电梯井前。</p><p>黑暗水体汹涌澎湃，残缺不全的牛蛙从水中涌出，眼珠子被挖空，蛙腿几乎都被扯断了。</p><p>日有所思，夜有所梦嘛。</p><p>墙中之鼠所编织的噩梦，也会与时俱进，从他脑子里的记忆当场取材。</p><p>比如今晚，他便梦到白天的牛蛙。</p><p>杨帝的眨了眨眼，眸子在黑暗中熠熠闪烁，像是城市黑夜，星辰稀疏至极的天空。</p><p>那些被黑水吞噬的生命，是否也曾见过这样虚假的星光？</p><p>……</p><p>杨帝睁眼。</p><p>他听见了铲子挖土的声音，伴随着某个人沉重的呼吸声，在泥地上来回走动的脚步声。</p><p>非常真实的细节，感觉不像梦境了。</p><p>但他掏出镜片时，里面映照出的仍然是他正脸。</p><p>……</p><p>今夜的“墙中之鼠”力量尤为强大，给杨帝嵌套了足足20层梦境！</p><p>最终，他在充满了毒烟的房间中惊醒。</p><p>残破镜片中，清晰地映出自己的后脑勺。</p><p>杨帝连破20层梦境才回来到现实。</p><p>这一夜，门口和窗户也被用砖头封死，极大程度上隔绝了他与外界的感知。</p><p>这一夜，墙中老鼠的吱吱声刺耳欲聋，削弱了他的听觉。</p><p>这一夜，壁炉释放的一氧化碳、刺鼻烟雾在密闭空间聚集，淡化了嗅觉感知。</p><p>这一夜，杨帝的六感，被墙中之鼠制造的噩梦蒙蔽，被幻境中的内容所混淆……</p><p>所以，直到醒来那一刻，杨帝才感知到——</p><p>一楼有人。</p><p>他毫不犹豫，猛地一拳轰向二楼的水泥地面！！</p><p>“轰——隆！！”</p><p>伴随着一声沉闷巨响，水泥地面瞬间龟裂，碎石飞溅！</p><p>二楼的混凝土地面、一楼的天花板，瞬间破开一个大洞，破碎的水泥洞口裸露出变形扭曲的钢筋。</p><p>他身形如电，顺着破开的洞口一跃而下，稳稳落在一楼。</p><p>眼前的景象让他心头一震。</p><p>只见钓鱼佬正将自己和一具尸体，用绳子紧紧绑在一起。</p><p>那具尸体面色苍白，肢体扭曲，散发着一股令人作呕的腐臭味。</p><p>尸体上，还连带挂着几十根狸花猫大小的“舌头猫条”。</p><p>而在一旁，电梯井的积水潭水波荡漾，似乎正等待着接纳这一切。</p><p>钓鱼佬手中有一把沾满泥的铲子。</p><p>是那具尸体，从楼顶找到的尸体。</p><p>他把那具尸体重新挖出来了。</p><p>10天前，钓鱼佬还和杨帝一同将其埋在烂尾楼之外，献上了三支香烟。</p><p>梦里铲子挖土的声音，并非虚构，而是钓鱼佬在外面挖掘这具无名尸体。</p><p>“叔，你在干什么。”杨帝喊。</p><p>“杨帝……很感谢你，肯在悬崖边拉我一把，而不是任由我坠下。但非常抱歉，我有文科学士、理科硕士学位，各种控制变量、玩弄数据的手段，我已经见过很多了。”</p><p>他声音沙哑，像从喉咙深处挤出来的。</p><p>他看破了杨帝“控制变量”手段。</p><p>“你都看出来了吗？”杨帝喉咙梗塞。</p><p>钓鱼佬笑道：“看出来了，第五十只牛蛙的时候，就已经看出来了。你的钓鱼经验太匮乏，但如果你像我钓上二三十年的鱼，你也能学会目测‘猫条’的重量……”</p><p>前四十九个猫条和最后一个猫条，重量显著的不一样。</p><p>通过猫条的下沉速度，钓鱼佬能判断出其重量不同。</p><p>物体在水中下沉速度，受到很多因素影响。</p><p>重量，密度，体积，形状，水流速度，环境温度……</p><p>电梯井积水潭是一潭死水，各种环境参数始终不变，而猫条体积也大致一致，钓鱼佬这才有判断的基准。</p><p>尽管如此，普通人也不可能看出来。</p><p>只有浸淫钓鱼二三十年，对水流、浮力、物体下沉细微差别都了如指掌的钓鱼佬，才能看得出门道。</p><p>杨帝虽也随老爸去钓过鱼，但老爸从没教过他钓鱼。</p><p>他只教过杨帝一件事：你老爸没出息，所以你不要学我，你学了我，你就更没出息了。</p><p>钓鱼佬：“第50根猫条比之前的重了至少40%，而与之对应的第50只牛蛙却是质量最小的。</p><p>“结果，第50只牛蛙的‘诱饵: 活体’比值显著高于其他牛蛙。</p><p>“我有理由推测，‘活体’想要安全穿越，‘尸体诱饵’必须质量足够大，超过某个比例值。</p><p>“我说的对吧？杨帝兄弟。”</p><p>杨帝不想说“你误会了”、“这是巧合”诸如此类装萌扮傻的废话。</p><p>钓鱼佬继续往那具尸体绑舌头猫条：“我活了大半辈子，什么手段没见过。</p><p>“年轻时，在论文数据上捣鬼。做教师后，看学生捣鬼。</p><p>“我硕士虽然是理科，理论物理学，但本科——读的是新闻学。”</p><p>学新闻学的。那不奇怪了。</p><p>杨帝伸手摸向腰间，摸到张扑克牌。</p><p>他已掌握《濠镜澳风云》石一坚的掷牌技巧，并通过在梦中超过10万次练习，能够做到用普通的纸牌，切断婴儿小臂粗的麻绳。</p><p>只要自己的“意识”给自己的“10%潜意识”下一个暗示，一次催眠，一条命令。</p><p>身体就会做出响应动作。</p><p>他就能切断钓鱼佬和尸体之间的绳子。</p><p>杨帝几乎要将手中的黑桃A掷出去了。</p><p>但他还是没有那么做。</p><p>只见钓鱼佬把最后一根舌头猫条绑好，深深地看了杨帝一眼。</p><p>“杨帝，你看过《霍比特人》吗？我挺喜欢里面的一个角色——长湖镇的‘巴德’，他如果愿意，是可以无忧无虑钓鱼的，只是偶尔被卷进拯救世界的旅途中。现在，我也要被卷进去了。”</p><p>钓鱼佬固执的神色中，似乎带有一丝……问询。</p><p>如果杨帝强硬点，或许就能彻底阻止他。</p><p>但这一次，他没有。</p><p>他只是说：“你的学生，他们的‘尸体诱饵’仅仅是一只小蝎子，而被传送的总共有四个人。他们很大概率不在了。”</p><p>“我知道，所以他们的存活概率应该是0%左右，而不是2%。”</p><p>“……如果已经确认他们存活概率极小，为何要放弃现实世界，执意去往异界？你去了也改变不了什么。”</p><p>“现实世界也已无我容身之所。”</p><p>钓鱼佬笑着说道。</p><p>他为调查世界的暗面，辞去教师工作，与昔日好友断绝关系。</p><p>十年如一日，沉浸于民俗、神话、传说与神秘学的研究。</p><p>他的社会关系链条已经崩溃。</p><p>他的生命即使不为那四个学生而活，也是为神秘学而活了。</p>
