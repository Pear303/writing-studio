# 无限之书

<p>“这所中学的图书馆有两个出口，第一个出口通过环形走廊连接教学楼，第二个出口则联通体育馆方向。”</p><p>血手屠魔回忆起那几个红袖章志愿者所说的话。</p><p>原本的探路队，打算绕过环形走廊，从图书馆离开教学区。</p><p>他们所在的教学楼主体，是一个被巨大的环形走廊所包围的“凹”字形结构。</p><p>所有教室的门，都朝向这条环形走廊内侧开启。而环形走廊的内侧，就是那个致命的天圆广场。</p><p>理论上来说，想要离开教学区前往体育馆或其他区域，必须经过天圆广场。</p><p>不过另外一个的方法——就是从环形走廊走到圆环两侧，其中一侧就是图书馆，而图书馆又是距离体育馆比较近的一侧。</p><p>图书馆有第二个出口，平常不开门，但原本那只探路队早就预料到这个情况，所以身上备有“万能钥匙”。</p><p>总而言之，穿过图书馆，就是抵达目的地的最佳路线。</p><p>每到一个新地点就会有新规则，这是没办法的事儿。</p><p>众人快速穿越图书馆，这本是一条很顺畅的路。但不出意外的话，总会有意外发生。</p><p>一个书柜倒下了。</p><p>血手屠魔只能以无上肉体伟力，支撑住即将如多米诺骨牌般倒塌的书柜。</p><p>当他们通过眼神交流质问，到底是哪个逼碰倒了书柜时，无人回答，无人知道。</p><p>现场唯一的疑点，是淡淡的鱼腥味。</p><p>但他们甚至连嫌疑人的找不到——没有人站在“第一块多米诺骨牌”前面。他们探路队七人，都在别的地方。</p><p>最大的嫌犯，反而是受害者血手屠魔他老人家自己。</p><p>屠魔只能用睫毛做手语，对众人说着些很脏的话，骂骂咧咧地将书架扶正。</p><p>幸好这偌大书架，只有一本书，被他眼疾手快接住。</p><p>否则巨响发出来，说不定自己也要掉脑袋。</p><p>最后就是把这本书放回去……血手屠魔微微挑眉，这是本厚重的典籍，被他接住的时候，恰好翻到某一页，里边还有书签掉出。</p><p>那一页，布满看似无意义的凌乱划线，但有几处异常——</p><p>在页眉和页脚的空白处，有人用极细的笔尖，刻下了几乎难以辨认的小字：</p><p>「页码是假的……它在模仿我读过的书……但细节在扭曲……越翻越陌生……」</p><p>有点诡异。血手屠魔五大三粗，想不通这是个怎么回事儿。</p><p>他看见另外几个书架区的同道，在对他挤眉弄眼，问有没有什么异常情况。</p><p>血手屠魔摇摇头，通过瞳孔震动报平安，顺带将书上那句话传递给周围人。</p><p>众人纷纷感慨又疯一个，只有文学少女若有所思。</p><p>众人很快穿过图书馆，有惊无险，因为他们基本没在没看书。只要不看书，不发出声音，基本不可能违规。</p><p>七位正道大能，汇合在图书馆另一侧角落，背靠冰冷的书架。</p><p>不锈钢大门就在一旁，这就是图书馆常年不开放的第二个出口。</p><p>这个门是进出货用的，后来发现这门设计的用处不大，还容易招贼，便慢慢荒废。</p><p>众人在灵界相爱相杀多年，无需言语，通过眼神和极其轻微的手势，信息迅速传递、整合：</p><p>“终于摸到第二个出口了，路上没遇到啥情况吧？”</p><p>“就屠魔那儿出了点事儿。”</p><p>“狗屎，不知是谁把书架往我这推了一把。”</p><p>“诸位没有遇到传说中的管理员？”</p><p>“没有，其他人都没有异常情况，路上一个管理员都没遇到，更不用说被他们盯着看。”</p><p>“好的，那么，万能钥匙我记得被谁带在身上？”</p><p>“在我这。不过，这钥匙形状有点奇怪。”</p><p>其中一位正道大能掏出一根撬棍。</p><p>“……你的意思是说，万能钥匙是支撬棍。”</p><p>“开把锁，比屠杀了亲娘还大动静的撬棍。”</p><p>“可能，也许，前一支探路队并没有意料到这个图书馆的规则是保持安静……”</p><p>“但它确实是一把万能的钥匙。”</p><p>撬棍开锁？在这要求绝对静默的图书馆？</p><p>动静会把整个图书馆潜藏的诡异都惊醒，顺便把管理员直接召唤到脸上。</p><p>凌云圣皇眼神凌厉如刀，瞬间扫过众人，无声的指令传达：放弃撬棍！找常规钥匙！</p><p>七道荧光绿的身影，再次立刻如同壁虎般散开，紧贴地面和书架底部阴影，朝着图书馆入口附近那个半圆形的服务台匍匐前进。</p><p>柜台后面一片狼藉，登记簿散落，笔筒倾倒，几本厚厚的图书随意摊开。</p><p>一个上了锁的抽屉，引起了他们的注意——最有可能存放备用钥匙的地方。</p><p>一名擅长用物理以外方式的开锁的觉醒者，开始用回形针轻撬抽屉。</p><p>与此同时，文学少女形态的玄冰尊者，用纤细的手指，极其轻微地触碰了一下摊开在柜台上的一本图书的页脚。</p><p>她的动作，引起凌云圣皇等人的注意。</p><p>眼神交流：“怎么了？”</p><p>“这个世界……实在诡谲。‘诡异’，这个称呼太合适了。”</p><p>她手指悬空，在摊开的书页上虚划一条线，然后这条“线”在她眼神的引导下开始无限延伸，分叉，扭曲，缠绕。</p><p>“这里有一本书，页数不是固定的。它在无限增长。你翻一页，它可能生出十页、百页……如一条疯狂增殖、没有尽头的藤蔓。”</p><p>“无限之书……有什么危险么？”</p><p>玄冰尊者那戴着眼镜的少女面庞上，罕见地浮现出一种近乎悲悯的凝重。</p><p>她的眼神透过镜片，在众人识海中无声地炸开惊雷：“诸位，不要小觑‘无限’二字。”</p><p>她的意念如同冰锥刺入每个人的思维，“在我们原本的灵界，纵使有移山填海之能，寿元以万载计，可曾真正触及过‘无限’？</p><p>“灵气有枯竭之时，星辰有寂灭之刻，大道亦有穷尽之路。</p><p>“就算是大帝，年轻时意气风发，脚踩域外天魔，拳打真仙大能。</p><p>“某一天，大帝还是会寿元终尽，灵与肉回归天地，哀生之须臾，羡天地无穷。</p><p>“但天地亦非无穷。你们也都见到那柄创世之斧——灵茶山乂斧对吧？它撕裂了灵界。</p><p>“仙界诡异，却将‘无限’此等禁忌概念，具象于蛐蛐书册之上！”</p><p>众人思之，脊背发凉。</p><p>正当凌云圣皇等人神魂俱震、遍体生寒之际——</p><p>喀哒！</p><p>一声极其轻微，但在图书馆这片死寂中却如同惊雷般的脆响，从服务台方向传来！果然不出意外又要出意外了。</p><p>是那位正用回形针撬锁的觉醒者。</p><p>他太过专注于避开玄冰尊者描述的恐怖，心神激荡之下，指尖灵力一个微不可查的失控，回形针竟在锁芯内部碰出了声响。</p><p>这声音不大，却像一颗石子投入墨池。</p><p>七人的心跳几乎在同一刻骤停！</p><p>凌云圣皇、血手屠魔等人猛地扭头，目光如电射向服务台方向，瞳孔因极致的惊骇而收缩。</p><p>晚了。</p><p>就在服务台侧后方，两排高大书架投下的，最为浓重的阴影交界处……</p><p>空气毫无征兆，泛起极其细微的涟漪。</p><p>一个身影，如同从凝固的黑暗中析出，无声无息地“浮现”在那里。</p><p>“冷静，我当时还和你们一同嗜血观战。”是阿巴。</p>
