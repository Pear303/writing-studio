# 异界的知识宝库

<p>“我们得找个安全的地方过夜了。”</p><p>瑞弗维尔抬头望向两轮月亮，意识到自己犯下一个错误——旅行商人夜晚，干嘛这么急着赶路？又不是要赶去投胎啊。</p><p>杨帝背着手，点点头。</p><p>其实他两条胳膊还在抖。</p><p>被头骨硬度媲美钢铁的杀手兔，以1.5马赫正面一撞，感觉有点骨裂，可能得七八分钟才能自然痊愈。</p><p>毕竟伤筋动骨一百天。七八分钟，算挺快了。</p><p>当务之急，确实需要好好吃点东西。</p><p>瑞弗维尔闭上眼睛，开始施展“自然共鸣”。</p><p>这是游侠独有的技能，能够让他与周围的自然环境产生共鸣，敏锐地感知到灵能的流动和变化。</p><p>常用于侦察环境，看看这山洞能不能睡。</p><p>随着他的意识逐渐沉浸，周围的世界仿佛发生了奇妙的变化。</p><p>原本肉眼可见的景物变得模糊，取而代之，是各种色彩斑斓的灵能线条和光芒。</p><p>他能清晰地感觉到，此地的灵能流动并不规则，呈现出一种混乱而又活跃的状态。</p><p>就像无数条奔腾的河流，各自朝着不同的方向涌动，偶尔相互交汇碰撞，产生出一阵灵能涟漪。</p><p>不稳定的灵能环境，就是导致各种魔物特别是史莱姆，在此出现的原因之一。</p><p>想找地方过夜，得找个“灵能稳定”的地。</p><p>他发现了一处灵能相对稳定的区域。</p><p>在那里，灵能的流动如同平静的湖面，虽然也有微微的涟漪，但相较于周围混乱的状况，已经是难得的安宁之所。</p><p>他睁开眼睛，朝着感知中的方向望去，只见不远处一座山壁下，有一个浑然天成的山洞。</p><p>“杨帝，那边有个山洞，灵能相对稳定，应该是个过夜的好地方。”</p><p>瑞弗维尔指着山洞的方向说道。</p><p>“看起来还不错，没有发现什么异常。”杨帝扫了一眼，欣然说道。</p><p>地球20-21世纪最大的谎言，就是让人们认为老鼠洞是拱门形状的。</p><p>而二人眼前的洞口，呈现不规则形状。</p><p>得将身体扭成一股麻花，才能从不规则的狭窄洞口钻进去。</p><p>杨帝顿了顿。</p><p>山洞里有种好闻的柑橘味。</p><p>有草食性或者杂食性动物曾来过此处？他不动声色的走进山洞深处，四周探查了一番。</p><p>幸好，并没有发现其他动物的踪迹。</p><p>杨帝回到洞口附近，瑞弗维尔已经生起一堆篝火。</p><p>看着逐渐旺盛的火，还有堆在岩洞边寥寥无几的行李。</p><p>杨帝终于问出他憋了很久的问题：“你不是旅行商人嘛，货物呢？总不能出门做买卖，什么都不带吧。”</p><p>瑞弗维尔正往火里添着柴，听到杨帝之问，动作一顿，脸上闪过一瞬即逝的慌张。</p><p>这位传奇法师，开始怀疑了？</p><p>他用来伪装身份的那些“货物”，此刻早已随着坍塌的隧道，和那位第九席红衣主教一起被深埋地下了。</p><p>“唉，说来话长。”瑞弗维尔叹了口气。</p><p>他只能如实相告：他在一条隧道被人追杀，后来隧道坍塌，那些货物就追杀者一起被埋了。</p><p>杨帝：“你被什么人呢？”</p><p>瑞弗维尔还没想好理由，所以强行转移话题：“……我帮你看看手臂吧。”</p><p>他说着，不等杨帝回应，就主动凑过去，握住杨帝骨裂的手臂查看起来。</p><p>杨帝看着瑞弗维尔专注的样子，心中也明白他这是在强行转移话题。</p><p>不过，他并不在意，毕竟每个人都有自己的秘密，就像自己也隐藏着“来自地球”的秘密。</p><p>杨帝看着瑞弗维尔。</p><p>更何况，这个自称“旅商”的异世界土著，到目前为止都在帮他，没有对他做出不好的行为。</p><p>此时，瑞弗维尔握着杨帝的手臂，啧啧称奇。</p><p>“仅仅是骨头受到了损伤……但还没骨折，多么强大的肉身……”</p><p>瑞弗维尔说，“我治治。”</p><p>手臂的当事人点头默许。</p><p>“远古灵光，苍穹降下，以太之力，汇聚吾手，驱散病痛，抚慰灵魂之伤，如晨曦初照，如暖风拂面，灵光圣愈，愿汝重获新生！”</p><p>一段冗长且空洞的咏唱。</p><p>随后，灵能从瑞弗维尔掌心涌出，按照特定的图案和韵律流动！</p><p>他自身的“灵”与环境中的“灵”，犹如水乳交融，绽出丝丝淡绿色光泽。</p><p>绿色光芒融入，杨帝手臂上的疼痛明显减轻了。</p><p>原本骨裂处也开始有了温热酥麻的感觉，那是断裂的骨头在快速愈合！</p><p>「骨+1」</p><p>杨帝敏锐地察觉到，这项法术对自己而言意义非凡。</p><p>他能通过自己损伤身体，而后超量代偿，实现永无止境的进步。</p><p>而这种“治愈法术”，如果能加以利用，简直是如虎添翼！</p><p>而对于异世界的人民来说，这样的医疗法术更是无价之宝！</p><p>在地球上，即使是现代医学，骨折的愈合也需要漫长的时间和精心的调养。</p><p>所谓伤筋动骨一百天，哪怕是肩膀脱臼、臂骨骨裂，没几个月时间根本不能恢复。</p><p>但在这个异世界，通过这样的法术，就能在短时间内加速骨骼愈合，大大减少伤者的痛苦和恢复周期。</p><p>这项法术如果能够广泛传播和应用。</p><p>将会极大地改善所有人的生活质量，改变整个医疗格局……啊，想太远了。</p><p>杨帝装作惊奇：“这是什么法术？”</p><p>瑞弗维尔又给失忆大佬做了回老师。</p><p>“三环法术·愈合，法力测试得达到三环水准才能释放的法术。但对您而言，应该轻而易举吧。”</p><p>杨帝讪笑，他确实已经记住这个法术“灵”的流动方式和韵律。</p><p>山寨一个出来也不难。</p><p>同样没有咏唱，用四两拨千斤的方法直接调动周围灵能！</p><p>大量灵能从四面八方涌来，在他掌心汇聚，绽放出比瑞弗维尔施展时更为耀眼的绿光。</p><p>如同一小轮绿色太阳，将整个山洞都映照得通亮！</p><p>他将绿色小太阳拍进体内，但虽然因为身体健康，所以并没什么效果。</p><p>但技能都搓出来了，总不能浪费吧。</p><p>瑞弗维尔眼睛瞬间瞪得滚圆。</p><p>四环法术对于大多数术士来说，施展起来都需要全神贯注，消耗颇大。</p><p>杨帝见识过一次之后，又一次默声瞬发，施展出来……</p><p>而且从汇聚的灵能强度来看，似乎比自己施展得更加完美？！</p><p>他真失忆了？</p><p>还是说，杨帝以前的施法经验，已经形成忘不掉的肌肉记忆，所以才能在失忆的情况下默声瞬发？</p><p>“瑞弗维尔，借把刀。”</p><p>“哦，哦……”</p><p>杨帝接过短刀，还没等瑞弗维尔反应过来，手臂挥出残影的速度，两肋插刀！</p><p>噗噗噗噗噗——！</p><p>……杨帝没能捅穿两肋，没能在最柔软的腹部上留下哪怕一道皮外伤。</p><p>他只是想将自己刺伤，试试“治疗法术”的效果——但没想到，连肚皮都戳不穿。</p><p>并非杨帝力气不够，而是瑞弗维尔的铁质短刀，已经被捅弯捅钝了。</p><p>二人看着前一刻还铮亮锋利，现在已经磨损严重的短刀。</p><p>杨帝：“瑞弗维尔先生，是这样的，您听我解释。”</p><p>瑞弗维尔：“杨帝朋友，不用解释了，您的身体素质真不错，经常锻炼吧？”</p><p>见对方打圆场，杨帝也尴尬地笑了笑，顺势接过瑞弗维尔递来的台阶：“哈哈，可能是失忆前经常锻炼的缘故吧。这刀都被我弄成这样了，我磨一磨，说不定还能接着用。”</p><p>他找了块表面相对平整的石头，“呲啦呲啦”的磨刀声在山洞里回荡。</p><p>瑞弗维尔走了上来：“呃，要不您歇歇，我来磨？”</p><p>“不了不了，毕竟是我整坏的刀。”</p><p>二人打太极似的推脱了一阵子，刀子便已经磨好。</p><p>杨帝看着手里那磨好的刀，想到各路游戏一个很重要的设定。</p><p>他问：“瑞弗维尔，有没有一种……类似‘附魔’的技法？”</p>
