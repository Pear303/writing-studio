# 夭寿啊，精灵睡着了

<p>告别了砾石镇，两个人类带着一个昏迷的精灵，往南继续旅程。</p><p>夜色已渐渐浓郁，星光逐渐铺满天空。</p><p>一行人在蜿蜒小道上疾行，脚下枯叶被踩得沙沙作响。</p><p>伊芙靠在瑞弗维尔背上，苍白的面容在兜帽阴影下显得脆弱，耳后裂痕仿佛随时会蔓延开。</p><p>但伤势最终还是渐渐痊愈着。</p><p>她毕竟是伊芙·柑橘，参与过剿灭焚灭天空之龙·卡利斯托战争的上古老兵，10环超限大法师，圣树的亲女儿——据说所有精灵都是圣树分娩出来的。</p><p>伊芙的睫毛微微颤动，在瑞弗维尔肩头蹭出一声含糊的呢喃。</p><p>“远古灵光，苍穹降下……灵光圣愈，愿汝重获新生……”</p><p>瑞弗维尔对准精灵额头，搓了个疗愈法术。</p><p>她身上的龟裂纹路，正以肉眼可见之速度收拢，像被春风拂过的冻土重新愈合。</p><p>“杨帝，怎么走？”瑞弗维尔问。</p><p>向南啊！他说。这不是显而易见嘛。</p><p>“回想起来，那把木镐……绑定诅咒实在强得有些超模了吧？就连伊娃也只能把它封住几秒。这样的诅咒，只有大陆历史上数一数二的顶尖强者才有可能施展。很可能……就是焚灭天空之龙·卡利斯托，它能施加龙语诅咒……”</p><p>瑞弗维尔一路念念不已。</p><p>背着伊芙走一路的人正是他。</p><p>从设定上说，精灵是字面意义的身轻如燕，所以图书馆馆长费并没有很大劲。</p><p>他们离开砾石镇时已是近晚。按照奥拓的指引，踏入桦树林时候，早已入夜。</p><p>林子内，星光细碎迷离。</p><p>银白树皮上，木质褶皱将月光筛成流动的水银，在铺满浅粉花瓣的小径上蜿蜒成河。</p><p>不知从何处飘落的花与桦木絮在空中纠缠，每一片都裹着莹蓝微光，如同萤火。</p><p>树冠间偶尔传来振翅声，惊起几簇花雨飘落，将伊芙发梢的碎金染成温柔的淡紫。</p><p>杨帝抬手接住一片半透明花瓣，不曾想，指尖刚触到，就化作清泠的露水。</p><p>那是环境灵能自然凝结成的景观。</p><p>如果说，异世界其他地方的环境灵能平均值大约是500，那么这里就是700。</p><p>“此地的灵能很浓郁。”</p><p>“我也感受到了，这说明我们离‘星渊井口’很近。”瑞弗维尔随口说道。</p><p>杨帝不是土著，他不知道“星渊井口”具体是啥。</p><p>但这口“井”出镜率似乎非常高，经常能听到提及它。</p><p>比如这里曾是圣骑士“巴德”射杀卡利斯托的地方。</p><p>又比如砾石镇的居民这里倒斗，导致染上了“绑定诅咒”。</p><p>又据说圣光教廷在此重兵驻守，平常人很难进入。</p><p>“……瑞弗维尔，你不是说这里有教廷的人驻守？如果现在，我们真的离星渊井口很近了，为何一个守兵也未曾见过？”</p><p>瑞弗维尔也发现盲点。</p><p>他背负伊芙，瞪着茫然的眼，在桦树与星空下驻足沉思。</p><p>“也许……国王确实一句真话都没说。”</p><p>瑞弗维尔只感觉到悲凉，伊芙体温透过衣料传来，却暖不化他发凉的指尖。</p><p>圣古琉斯国王，他的忘年之交，真的如伊芙所说，和教廷一块设局，对付他这样一个小小文员？</p><p>颇有种资本家、大财阀、大权贵谋划三年，只为狙击一个县城小社畜的荒诞感。</p><p>可他又如何区分被害妄想？</p><p>王城图书馆馆长，听起来位高权重。</p><p>但都是虚的。瑞弗维尔没有贵族头衔，没有势力根基，没有经济基础。</p><p>在整个圣古琉斯王国的朝廷和教廷面前，他只是个普通人，小人物。</p><p>如果有人要迫害他，瑞弗维尔只能逃。</p><p>只要做错一个选择，便会万劫不复。</p><p>前几天，瑞弗维尔还未能有这种「觉悟」。现在，伊芙昏迷超过三小时，没能力保护他了，他突然发现，自己更是难以保护好昏迷的精灵。</p><p>大腿伤了，必须养护好大腿，才能抱大腿。</p><p>本质上，都是自己不够“大腿”……</p><p>“杨帝，我渴望力量，我需要力量。”</p><p>“抛瓦？你想要抛瓦？”</p><p>“没错……否则我甚至保护不了自己，更别提保护伊娃……”</p><p>“哦，是吗，那先在此地睡一觉吧。”</p><p>他们便在桦树林中空地停下驻足。杨帝寻来枯枝，指尖迸发火焰，点燃干燥的树皮，暖意驱散了几分桦树林夜晚的阴森。</p><p>瑞弗维尔放下伊芙，轻轻将其安置在铺着他自己斗篷的地面。</p><p>杨帝说先等等。</p><p>他从自己背包里掏出熔岩史莱姆，将史莱姆温度调到合适，然后铺展开来，垫在伊芙脑袋下方当枕头。</p><p>月光勾勒出精灵颤抖的睫毛。</p><p>某一时刻，伊芙眉头剧烈皱起，苍白的嘴唇溢出破碎呓语。</p><p>“巨龙……史莱姆……复活……绑定……”</p><p>瑞弗维尔慌忙按住她肩膀，却发现，精灵掌心传来滚烫的温度。</p><p>“伊娃在发烧。”</p><p>“而且，她在做梦，可能是噩梦。梦境似乎影响了现实。”</p><p>杨帝指向火堆。</p><p>——火苗不知何时变成了诡异的靛蓝色，映得四周桦树的影子扭曲变形。</p><p>更可怕的是，那些飘落的花瓣开始在伊芙周身盘旋，拼凑出一条龙。</p><p>——提及“龙”，90%情况都是在说焚灭天空的卡利斯托。</p><p>瑞弗维尔掏出异界版风油精，涂抹精灵的太阳穴。</p><p>杨帝也贡献出地球原产的双飞人，混在温水中喂伊芙服下。</p><p>“嗯……这双飞人怎么没味……不应该这么快过期吧？”</p><p>各路神药神油加持，纵使伊芙身中暗伤，棘手非常，却也渐渐有了缓和的迹象。</p><p>围绕她周身、盘旋的花瓣所拼凑成的龙形，在一阵微风拂过之后，竟如同虚幻的泡影一般，“噗”地一下消散开来。</p><p>只留下一些莹蓝微光，缓缓飘落在地，融入那鹅黄枯叶，浅粉花瓣铺就的小径。</p><p>伊芙眉头渐渐松开，掌心滚烫也开始慢慢消退。</p><p>只是额头上还挂着细密汗珠，显示她刚刚经历过一场并不轻松的挣扎。</p><p>精灵应该没有在做梦了。</p><p>“精灵左右脑可以轮流用，当她真正睡着，说明负荷、消耗真的很大。”</p><p>“说明她在施放「次元封印」时，应该是左右脑同时开工。”</p><p>“杨帝你说，用半脑工作，另外半脑睡觉，会是种什么感觉？”</p><p>两个人类坐在一块闲聊起来。</p><p>说实话，在“重兵驻守”的星渊井口旁，不应该如此掉以轻心，在黑暗的林中升起篝火。</p><p>但如果不点起火，夜晚会刷大量敌对魔物，僵尸、骷髅、蜘蛛、苦力怕。</p><p>管他，保证今晚不被魔物啃了再说。</p><p>杨帝往火堆里又添了些枯枝，噼里啪啦的声响在寂静的夜里格外清晰。</p><p>现在闲置下来，虽然95%心神用于警惕四周环境，但杨帝终于有心思，用另外5%的精力问他好奇已久的问题。</p><p>“瑞弗维尔，‘星渊井口’究竟是什么？”</p><p>瑞弗维尔也往火里扔了根树枝，火星子“噌”地一下溅起老高。</p><p>他拍了拍手上的灰，缓缓开口道：“‘星渊井口’并非那种打水的井。它是超大型灵能地脉露在地表的枢纽，这‘井’不过是比喻意义上的。”</p>
