# 圣树屏障与熔岩火浪

<p>在商业文艺作品里，“情感”总是人类，或者其他看起来和人类差不多善良阵营生物击败外敌的最大法宝。</p><p>据说常有旧日支配者降临中土大陆，一尊由光明聚而成的巨人站起来与之对抗。</p><p>结局中，光之巨人汇聚万千人心意，凝结成一棵硕大无朋的元气弹，成功将旧日支配者炸飞到十万亿八千万里开外。</p><p>而现在竟然说，对方的弱点是其情感？</p><p>这犯了商业文艺作品的大忌，非常不正确。</p><p>奥拓：“呃你们别这样看我……我虽看起来是粗人，但毕竟时代变了，我也读了许多书。你们没发现我气质和其他矮人大有不同吗？”</p><p>“看不太出来，矮人不都长一个样吗……”</p><p>不过，伊芙和杨帝也认为，奥拓在人文社科方面确实有知识基础，以及一定的独到见解。</p><p>不然，他绝不会懂得用金融杠杆，摆脱绑定诅咒。</p><p>“……好吧，简单说结论：对我们这些群体性的人来说，情感共鸣能够构建起更紧密的人与人的联系，增强群体生存延续下去的几率。</p><p>“但当个体脱离群体，情感反而成了羁绊。原初之眼作为凌驾于万物的神灵级存在，祂的一举一动都牵引莫大威能……</p><p>“当祂产生恐惧、怜悯、愤怒这些情感时，就像精密仪器渗入杂质——恐惧会让祂迟疑，怜悯会让祂手软，愤怒更会蒙蔽祂的判断。</p><p>“巴德在暗示我们主观意志是原初之祸根，但这同时也是祂的弱点。”</p><p>对抗祂的关键，就是利用这份“人性”——那些让祂变得软弱的情绪波动。</p><p>这就是致命破绽。</p><p>伊芙若有所思地抚着光滑下巴：“所以情感对个体强者而言，反而是种缺陷？”</p><p>“正是如此！”奥拓用力点头。</p><p>杨帝：“所以这理论也是你猜出来的？”</p><p>“社会科学和人文心理的事，怎么能叫猜。”</p><p>看来确实是猜的了。</p><p>猜测又进入僵局，他们陷入长达十分钟的无效口水交流。</p><p>一切都没有定论，而可能知道关键信息的瑞弗维尔仍然在昏迷。</p><p>于是，轿厢内外的气氛又重归沉重。</p><p>他们也只能沉重，以沉重，默悼在史莱姆集群暴动中死去的人们。</p><p>他们共享这份沉重，为逝者哀悼，对敌人愤怒，对同伴的依附。</p><p>就在气氛压抑到极点时，轿厢晃动起来。</p><p>“伊芙，我觉得你又需要来看看这个。”杨帝在轿厢车顶如此说道。</p><p>上一次他开车叫精灵往外看，还是在遇到夜魅的时候。</p><p>伊芙从轿厢看出去，她一眼就知道遇到了什么。</p><p>——圣树的自适应防御屏障。</p><p>那是一道横亘大地，直入天穹的半透明淡绿色屏障。</p><p>在杨帝眼中，不只是淡绿色，还有各种其他颜色混杂，比如最经典的，代表生命的颜色“viv”。</p><p>它包围着森林，似是奇幻风格的长城。</p><p>“那是圣树的护盾。魔君‘索伦’觉醒之时，曾开启过一次。现在是第二次。”伊芙说。</p><p>杨帝目测，他的车要是按原速度撞到屏障，大抵是会车毁人亡？</p><p>但就在他减慢速度之际，伊芙突然告诉他：“不要减速，全速冲过去……算了，我来接管轿厢行驶。”</p><p>然后，杨帝便感觉对轿厢的操控陡然一沉，被另一股无形且磅礴的力量给牢牢攥住，再也不受他的控制。</p><p>伊芙已经强制夺取了他对轿厢的控制。</p><p>这就是超限法师对普通法师的体量碾压。</p><p>杨帝顺势爬回轿厢内，找个位置坐好，眉头紧锁着，扒拉窗户看向外边。</p><p>“相信圣树！”伊芙说，“自适应防御会根据闯入者进行过滤调整。”</p><p>她的声音被剧烈颠簸撕碎。</p><p>此刻，轿厢与屏障的距离不足10千米。</p><p>而身后，出现杨帝和奥拓此生从未见过的、超巨数量的史莱姆……“海啸”……</p><p>——数以百万计的熔岩史莱姆，密密麻麻，相互堆积，铺天盖地！</p><p>流动的火焰遮蔽了整座平原！！</p><p>如奔腾的岩浆巨浪，一波一波席卷而来。</p><p>数以百万计的炽热躯体相互挤压、翻滚，体表流淌的岩浆在夜幕下勾勒出狰狞的光纹。</p><p>整片大地都在燃烧。</p><p>那片熔岩史莱姆组成的“海啸”正以摧枯拉朽之势席卷而来。</p><p>奥拓亲眼看见——原本平原上，有一座隆起的，百米高的小山头。</p><p>当史莱姆“海啸”席卷而来，那整座山头轰然崩塌，化作熔岩海啸中的齑粉，连残渣都被沸腾的黏液彻底吞没。</p><p>那片熔岩海啸却仍在以不可阻挡之势推进，所过之处，万物皆化作流淌的火海。</p><p>而更远处连绵的丘陵，在海啸面前同样如同纸糊的模型。</p><p>先是山体表层的岩石开始剥落，露出内部赤红的熔岩核心。</p><p>而后，凸起的丘峰如火山喷发般炸开——滚烫的碎石裹着黏液射向天空，形成一片遮天蔽日的弹幕。</p><p>千里丘陵，顷刻被推平！！</p><p>“抓稳了，我要继续加速。”伊芙平静地说道。</p><p>与此同时，轿厢刺破空气发出野兽般的嘶吼，灵能轿厢在杨帝脚下震颤如困兽。</p><p>轿厢速度急剧飙升，从原本可怜的120公里飙升至300公里，和高铁一个速度！</p><p>“我……我晕车！呕哇！”</p><p>奥拓首先支撑不住，将头探出车窗外吐出彩虹，浇灌身后穷追不舍的熔岩史莱姆。</p><p>不看不知道，一看吓一跳。</p><p>只见后方，黏腻的史莱姆浪潮正裹挟着尖锐嘶鸣追来，触须尖端已堪堪擦过轿厢尾部！</p><p>它们一直在观察，一直在追杀。</p><p>它们也许不能突破圣树屏障，所以选择将伊芙等人作为“诱饵”，引诱圣树的护盾裂开缺口。</p><p>毕竟，轿厢想要进入森林内部。</p><p>圣树屏障必须得打开一条通道。</p><p>这就是它们以万分决心要把握的机会。</p><p>“它们要追上来了！！”奥拓扯嗓吼道。</p><p>杨帝也将半个身子探出车窗。</p><p>三环法术·奥术飞弹，同时附带大量扩散、冰冻、爆裂效果。</p><p>“轰！轰！轰！轰！！”</p><p>杨帝指尖迸发的奥术飞弹如流星群划破夜空，每一枚符文弹体在触及史莱姆浪潮的瞬间，骤然分裂成无数冰棱与寒雾！</p><p>轰鸣声震耳欲聋，冻结的黏液与炸开的岩浆在半空交织成绚烂的冰火风暴！</p><p>数百只熔岩史莱姆被掀飞至百米高空，体表岩浆在低温中，迅速凝固成暗红色晶体，如破碎的琉璃簌簌坠落。</p><p>然而这壮观的攻势不过是沧海一粟。</p><p>后方的史莱姆浪潮如同沸腾的活物，空缺的部分瞬间被更多炽热躯体填补。</p><p>新涌来的史莱姆甚至在半空重组形态，将那些尚未落地的同伴碎片吞噬，化作更大的黏液怪物。</p><p>但也幸亏几发大范围轰炸，杨帝干掉了那几百只差点要追上轿厢的“精英型熔岩史莱姆”。</p><p>至少解决了燃眉之急。</p><p>额外效果是削弱了对方约0.01%的力量。</p><p>“我们要进圣树屏障了，杨帝把头缩回去！”伊芙命令道。</p><p>圣命在上，杨帝不敢不从。</p><p>他将头收回轿厢的那刻，这座方形的矮人灵能造物精准穿过屏障上的方形缺口。</p><p>与边缘口误差仅仅一厘米。</p><p>更准确来说，是轿厢在即将撞上屏障的那一刻，圣树为他们的车子打开了一个严丝合缝的临时通道。</p><p>尽可能减小入口面积。</p><p>轿厢进入后，屏障迅速复原，但是复原需要更多时间。</p><p>就在这不到5秒的空档期，超过一万头熔岩史莱姆涌入精灵圣树的领地。</p>
