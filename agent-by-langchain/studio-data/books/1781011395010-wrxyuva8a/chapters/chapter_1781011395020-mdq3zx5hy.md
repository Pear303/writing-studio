# 琦玉锻炼法

<p>琦玉锻炼法的精髓不在于训练量本身，而在于用非人的意志突破生理桎梏。</p><p>当手臂骨裂仍要完成标准俯卧撑，当髋关节错位仍要维持马拉松配速。</p><p>以这种近乎自虐的坚持，重塑人体极限。</p><p>它是一种全面的、系统的训练方法，注重体能的提升，还包括意志力和精神的锻炼。</p><p>至少杨帝是这么理解的。</p><p>他清晨五点就起了床。</p><p>此时宿舍楼外还是一片昏暗。</p><p>他还躺在床上，刚睁眼，一种莫名其妙的模糊概念被尚在混乱的思绪捕获，许久才慢慢解读出来：</p><p>「精神+1」</p><p>“又是一个新名词……精神是哪种意义上的精神？神秘学的，生理学的，哲学的？”</p><p>杨帝拍了拍脑袋，他的理智能够将“睡觉”与“精神”两个字连接起来，但也只能模模糊糊地连接个大概。</p><p>精神疲惫就去睡觉，睡醒一觉神清气爽。</p><p>或许这里的“精神”，与一个人的思想状态、智力水平波动有关。</p><p>他集中注意力。</p><p>发现对面床架铁锈的纹路清晰得不可思议。</p><p>被褥纤维的毛边、墙皮剥落的螺旋形裂纹、甚至张明远枕巾上凝固的哈喇子，都呈现出某种……高清3D效果。</p><p>走出阳台，远处晨读的英语系女生翻书声变得层次分明，他能分辨出，牛津词典铜版纸与小说轻型纸的摩擦差异。</p><p>所谓“精神+1”，是让他感知力更敏锐？</p><p>或者说，所谓的精神强化，更像是大脑在强行扩容缓存区。</p><p>让他能够从视听嗅等感知中，捕捉到往常被忽略的细节。</p><p>大脑在微观层面的暴力升级了一下，就像张明远说的“被推了一把”。</p><p>只不过推他的是上帝之手pro-max-plus版。</p><p>杨帝猛然低头，惊奇。</p><p>如此强大的细节观察、总结归纳能力……这还是以往那个清澈愚蠢的我吗？</p><p>……日后慢慢观察总结。</p><p>他摸黑来到洗漱台，用凉水拍了把脸，强迫自己清醒。</p><p>按照原教旨的琦玉锻炼法，每天要完成一百个俯卧撑、一百个仰卧起坐、一百个深蹲，外加十公里长跑。</p><p>不过一开始也不能这么高烈度，得按实际情况，实事求是，适当调整。</p><p>今天是5月1日，正值劳动节小长假，学校空空荡荡，该回家的回家，旅游的旅游，补觉的补觉。</p><p>而且是早上5点，田径场上的人很少。</p><p>不过，杨帝也注意到了几个熟面孔，是昨晚夜跑时见过的真爱好者。</p><p>比如其中一个穿褪色红衣服的青年，昨晚打过招呼。</p><p>“早。”</p><p>“跑。”</p><p>二人一个照面便认出彼此，会心一笑。</p><p>在这个小长假既不回家，又不出去旅游，一大早就来这儿跑，想必双方都是那种离家非常远或非常近、穷学生没有多少的生活费、而且没找到女朋友的普普通通的穷小子。</p><p>二人萍水相逢，倒也没说几句话。</p><p>跑就完事了，田径场上靠脚力分高下。</p><p>红色衣服的小个子青年呼吸平稳，腿部肌肉壮硕，节奏把握非常好。</p><p>他正以每公里3分45秒的配速切割空气。</p><p>这个速度对脆皮大学生而言，已是望尘莫及。</p><p>多圈下来，他配速都没有减慢，偶尔还略微增快几秒。</p><p>杨帝很快就跟不上了。</p><p>他不论是耐力，体能还是爆发力，通通达不到前面那人的零头。</p><p>被甩掉根本不奇怪。</p><p>小个子红衣青年见自己甩掉杨帝，微微摇摇头，内心闪过一瞬间的快感。</p><p>不过这种快感很快被他自己压制回去。</p><p>“看来连业余都算不上……不过还能这么早出来晨跑，精神是可嘉的。如果再坚持练半个月，应该能有我五年前的水平。”</p><p>他很快便把杨帝忘却，抛之脑后，继续沉浸在自己的跑步之中。</p><p>他叫胡彦卓，大四，准备毕业，目前是稷海理工的田径校队首席。</p><p>他原本不是田径专业的，只是后来给广大家人们拍短视频时出了事故，伤到髋关节。</p><p>落草为寇，卸甲归田，后来进了校田径队，成为最强跑者。</p><p>15圈下来，6公里，今日晨跑结束。</p><p>他放松着走去食堂，在离开田径场前，又回头看了一眼。</p><p>杨帝还在慢跑，喘气看起来快要死了似的。</p><p>不知对方跑了多少，但应该快有四公里。</p><p>年轻人，还得练！</p><p>……</p><p>胡彦卓有个优点，那便是持之以恒。</p><p>早跑六公里，晚跑六公里，雷打不动，除非真打雷下雨了。</p><p>他在稷海理工的西田径场跑了四年，见过很多熟面孔，也有更多的生面孔。</p><p>生面孔往往坚持不到几天便放弃，熟面孔要么是退休教职工，要么也是田径爱好者。</p><p>胡彦卓见证着这片田径场上人来人往，熙熙攘攘。</p><p>这几天，田径场上又多了个生面孔——暂时是生面孔。</p><p>也就是那个清瘦青年，他自称杨帝。</p><p>他每天早晚都会来跑，两人时间恰好重叠。</p><p>挺巧的，相逢即是缘嘛。于是很快，杨帝变成了胡彦卓的熟面孔。</p><p>第五天时，那个叫杨帝的来问了胡彦卓：你每天都来跑啊，跑多少啊？</p><p>他答道：“不多，也就12公里。”</p><p>对方看起来倒吸一口凉气。</p><p>说实话，每天12公里，这只是让胡彦卓自己的身体，保持在最佳状态所需要的量罢了。</p><p>从零开始达到这个水平，则还得跑更多，锻炼更剧烈。</p><p>胡彦卓已经很久没进步过了。</p><p>一公里极限速度2分40秒，六公里极限配速3分08秒。</p><p>前年出了事故后，这个成绩他再也没有打破过。</p><p>但就算没有出过事故、没有伤到髋关节，他也很难继续进步下去。</p><p>再往后，就是比拼天赋的领域了。</p><p>人类的体魄是有极限的，就算打破基因锁，也不可能永远进步下去。</p><p>最开始跑的时候，他也就每千米配速五分钟，跑不到两千米就累成死狗。</p><p>但最开始的时期，也是进步最快的时期——胡彦卓只花了八星期，也就是两个月，就将配速拉到4分钟，能一口气跑六公里！</p><p>之后，进步是极慢的。</p><p>跑六公里，他将每公里配速提升到3分40秒，花了半年。</p><p>还是按照正常的训练，到六公里配速3分20秒，用了两年。</p><p>到最终配速3分08秒，又用了三年！</p><p>此后，哪怕是一星期不跑，胡彦卓的耐力、爆发速度、腿部力量，都会呈现断崖式下跌。</p><p>其实不只是跑步，其他重体能远甚技巧的运动，也是类似的，游泳，自行车，划船……</p><p>没有人类能永远进步下去。没有。</p><p>也没有人类能在接近潜力极限之时，还能保持最初那么快的进步速度。</p><p>但是说实话，就算是刚开始练，也不应该进步这么快的……</p><p>胡彦卓第一次感受到在运动天赋方面被碾压，是在第六日清晨。</p><p>此刻晨雾正浓，跑道上的露水折射着鱼肚白的天光。</p><p>他身后传来了熟悉的喘息。</p><p>微微侧头，胡彦卓的余光瞥见那道踉跄身影时。</p><p>他看见杨帝，他听见杨帝的肺发出破风箱般的嘶鸣，听见对方喉咙里扯着沉重的喘息。</p><p>他看见自己投在跑道上的影子，被另一个影子蚕食。杨帝的足尖，几乎要踩上他的脚跟。</p><p>今天，他跟上来了。</p><p>跑鞋踩在塑胶跑道的脆响，对方喉头血沫翻涌的咕噜声，这些声音涌进耳膜——胡彦卓惊觉，自己竟无意识将对方当成一个完美配速员。</p><p>第六天……就能跟上我？</p><p>胡彦卓瞳孔震动。这什么天纵奇才……</p>
