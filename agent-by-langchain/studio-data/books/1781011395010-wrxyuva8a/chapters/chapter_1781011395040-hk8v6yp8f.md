# 潜意识：2%

<p>杨帝的指尖深深掐进掌心，指甲几乎要刺破皮肤。</p><p>他能听见自己心跳在耳道里轰鸣，听见飞虫嗡声，啮齿动物咀嚼的咔擦音，胡彦卓慌乱的喘息。</p><p>那些声音从四面八方挤压过来，似将杨帝放进液压机中，挤压成不到1mm厚的肉酱。</p><p>杨帝无力地瘫倒在地。</p><p>喉间溢出非人类的低频震颤，像是某种远古生物在调试声带。</p><p>但那双眼睛，却变得异常明亮，仿佛能洞察世间一切虚妄。</p><p>呼吸渐渐平稳，胸膛起伏逐步平静，仿佛刚从鬼门关走了一遭。</p><p>“成……成了！”他艰难地挤出一丝笑容，声音沙哑虚弱。</p><p>胡彦卓连忙上前扶起他：“杨帝你没事吧？情况咋样？”</p><p>“非常好，无与伦比的好，我从未觉得这世界如此清晰过……我只是需要几分钟来适应。”</p><p>在10分钟前，杨帝只能将大概1%的潜意识调到表层。</p><p>而现在，他已经能掌握大约2%的潜意识！</p><p>看似占比很小，不过是从1%→2%。</p><p>但从另一个角度看，增幅达到100%！</p><p>而且，这2%也已经蕴藏着海量资讯了。</p><p>潜意识每秒处理1000万bit的各种感官的信息，2%就是20万bit，相当于一万字文章。</p><p>原本看见一朵梅花，人脑可能1秒之内只能想到“哇这花儿真红啊叶子真绿啊这朵花真是花……”寥寥十几个字、至多几十个字的感受。</p><p>而现在，杨帝能在1秒内，获得相当于1万字描述的信息。</p><p>他能更敏锐地捕捉环境中的微小变化、潜意识中的记忆碎片、情感波动。</p><p>他跨越了常人不可能逾越的鸿沟，触及到了潜意识的深邃海洋。</p><p>希夷的声音从心灵中传来：“老大……我已经尽力了喵……你没事吧？感觉怎么样喵？”</p><p>杨帝站起身，拍了拍畏缩在角落的短尾狸花猫小脑袋：“现在是不是觉得，你老大的精神体浩瀚如海，无边无际？”</p><p>“对，老大你是怎么练的喵？”</p><p>“记住，那些杀不死你的，会让你更强大。”</p><p>“老大，你对一只猫灌什么鸡汤喵？”</p><p>「精神+1+1+1+1……」</p><p>大量原本深藏于潜意识之下的思维活动，如今被翻出水面，在意识表层翻涌。</p><p>然而，大脑功耗却没增加多少。</p><p>——因为“潜意识”是本就存在于人脑中、只是没有被我们察觉的思维活动。</p><p>就像原本，人们只能透过电脑屏幕看到正在加载的进度条。</p><p>而现在，只是把进度条背后代表的参数、软件的底层代码、甚至是“010101”机器语言这些本就存在的东西，也一起显示在屏幕上。</p><p>功耗并不会增加多少。</p><p>他在地上躺了10分钟，光速适应了2%潜意识开发后的身体。</p><p>“感觉好多了，走吧。这次我来打前头。”</p><p>杨帝从地上一跃而起，活动一下筋骨。</p><p>胡彦卓站在他一侧，钢管杵在地上：“杨帝兄弟，‘这世界如此清晰过’……现在，你具体看到了，听到了什么？”</p><p>杨帝看向他。</p><p>打个比方，大约一个加强连的福尔摩斯，在他脑海中组成专家研讨会，进行专项研究。</p><p>“你的喉结在吞咽时比正常速率快了25%，瞳孔扩张0.8毫米，伴随左侧嘴角0.03毫米抽动。刚才扶我起身时，你右肩三角肌异常收缩，钢管一直放在距离手边不足30厘米处。我不了解微表情学和心理学，但直觉告诉我，你略微有些恐惧和矛盾，尽管你个人可能没觉察到——啊对不起胡哥＞人＜，有些说过头了。”</p><p>杨帝心里还憋着很多话没说出来。</p><p>“就像看见幼狮长出獠牙的驯兽师”、“你对天才略有嫉妒”、“从‘杨帝老弟’变成‘杨帝兄弟’后你心里有落差”……</p><p>他忍着没说出口。</p><p>海纳百川有容乃大，山高万仞无欲则刚。</p><p>两个人之中，一方对另一人了解太过深入，而另外一人也对此情况心知肚明。</p><p>那一般来说，就很难做成朋友了。</p><p>杨帝还是很看重这个便宜大哥、跑酷入门师傅的。</p><p>尽管他及时收口，胡彦卓仍感觉自己像是被剥开了外衣，赤裸裸暴露在杨帝面前。</p><p>“杨帝兄弟，你……你这也太厉害了吧。”</p><p>胡彦卓干笑两声，试图缓解这尴尬的气氛，“我这点小心思，全都被你看透了。”</p><p>杨帝也有些尴尬。</p><p>但极度敏锐的感性，让他下意识迅速转移话题。</p><p>“其实五感变敏锐，也不是什么好事啦。”</p><p>比如说，你知道吗，胡哥，现在我连你心跳的频率，血液在血管里流动的速度，都能隐约感觉到。</p><p>就像……嗯，就像耳朵里塞了个超级敏感的听诊器。</p><p>全世界的声音都放大了一百倍。</p><p>一二十米外的小虫振翅，也会一股脑放大，全盘灌进脑子里。</p><p>“胡哥，你想象一下，深夜睡觉时耳边有几十只蚊子嗡嗡嗡地叫，蚊帐也格挡不了——除非你的床和蚊帐方圆可达三十米。”</p><p>胡彦卓想了一下，确实有点毛骨悚然。</p><p>杨帝咧嘴苦笑：“我现在就像是突然被扔到了一个信息爆炸的世界里，每秒都有无数信息往我脑子里钻。”</p><p>胡彦卓：“那你能不能控制一下，别接收那么多信息？”</p><p>“还做不到。”他摇摇头。</p><p>“闭眼，捂耳朵……都不过是权宜之计。”</p><p>也许随着时间的推移，杨帝也能慢慢学会怎么筛选和处理这些信息。</p><p>但现在为了逃命，尽可能接收更多信息，是更优的选择。</p><p>两人一猫，再次踏上前路。</p><p>人的潜意识，本来帮助表层意识过滤了很多不该看到、听到、感知到的东西。</p><p>杨帝打头阵，手执撬棍，剑指前路。</p><p>倾斜的混凝土立柱上爬满墨绿色苔藓。</p><p>干涸的沟渠堆积着可疑的淤泥和铁锈。</p><p>他看见无数尘埃在空气中悬浮游弋，这些被呼吸搅动的微粒组成湍流，勾勒出肉眼不可见的空气轨迹。</p><p>这个地下室并非完全密封，有些地方，存在气流流动。</p><p>伴随气流而来的，还有各种气味。</p><p>铁锈，青苔，腐烂，湿润。</p><p>每一缕气流的方向，还有气味的浓度种类，都是信息，都在呈现出一个立体的地下室。</p><p>地下室的庞大轮廓，在脑中缓缓展开。</p><p>“前面有风，应该有出去的路。”</p><p>杨帝指向一个方向。</p><p>胡彦卓顺着他的视线，将手电筒光束照过去，只看到一片深沉的黑暗。</p><p>他们朝那方向行进数十步。</p><p>终于，风的流动连胡彦卓也能感受到了。</p><p>他们正站在某个竖井的底部，检修梯向上延伸，尽头是浓稠的黑暗。</p><p>井口顶部传来的腐臭气息，裹挟着婴儿啼哭般的风声。</p><p>“现在有个问题。”</p><p>他们手电筒扫视四周，这里空空荡荡，除了水泥墩子，没见到其他杂物。</p><p>“我们该怎么上去？”</p><p>手电指向上方——竖井梯子距离地面接近四五米。</p><p>他们俩人就算叠罗汉，最多三米二，还差八十公分。</p><p>人与猫决定事已至此，先坐下来吃顿饭。</p>
