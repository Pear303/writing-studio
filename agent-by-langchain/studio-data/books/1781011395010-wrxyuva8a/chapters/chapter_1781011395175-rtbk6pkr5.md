# 磨灭杨帝

<p>残星道人依旧负手而立，不动如山。</p><p>素白道袍在狂暴的能量流中纹丝不动，那双洞悉万古的眼眸里没有丝毫波澜，仿佛眼前即将展开的惊天大战与他无关。</p><p>杨帝在气势上自然也不能逊色，不然他会很没面子。</p><p>他只是静静地站在那里，如同天地初开时便已存在的界碑。</p><p>万事万物，无时无刻不在更易。</p><p>有什么事物是始终不变的呢？就算是天道，也是从荒古的有缺，逐步走向如今的完善。</p><p>否则大帝就不可能从上古时期的扎堆诞生，到如今成为稀缺资源，保护动物。</p><p>此界大帝太少了，才四十二个。</p><p>杨帝岿然不动。</p><p>22名仙帝和11名神皇，33位低阶大帝的气势如何冲撞，都无法在他身上激起半分涟漪。</p><p>5名至尊出手，才勉强能在杨帝身上留下几道血痕、伤疤，偶尔戳出个血洞。</p><p>真正让他难以保持风度的，是3位准圣。</p><p>执掌「正反」之准圣，两仪玄枢真君。</p><p>执掌「生灭」之准圣，涅槃轮劫元尊。</p><p>执掌「有无」之准圣，太虚妙有法王。</p><p>像是归墟大帝，仅仅只是执掌了归墟渊水中的“虚无本源”，对虚无法则的炼化和感悟级别并不够高。</p><p>而且，“无”的对立面“有”，他也未能执掌。</p><p>三位准圣则不同。</p><p>他们分别将正反、生灭、有无，同一块硬币的两面，都感悟至圆满至臻境界，走到准圣这一步。</p><p>总之，他们很强就对了。真的很强！</p><p>杨帝得花上两三秒，才能把肚子上的大血洞自愈回来。</p><p>反者道之动，弱者道之用。</p><p>两仪玄枢真君袖袍一挥，“反”之法则发力，天地间阴阳二气骤然倒转！</p><p>杨帝周身灵能本如浩瀚星河奔涌，却在顷刻间化作逆流漩涡，如同逆推山岳，经脉传来撕裂般的剧痛。</p><p>涅槃轮劫元尊双眸开合，杨帝左半身在“灭”的法则下寸寸焦枯。</p><p>太虚妙有法王伸手虚抓，杨帝暂时用以护体的亿万道灵能护盾竟在“无”的法则中顷刻湮灭。</p><p>一个禁锢他的灵能调用。</p><p>一个遏制他的超速再生。</p><p>一个消抹他的护体手段。</p><p>实在是精妙绝伦的配合，根本不像是在各自时代叱咤风云的个体伟力集大成者！</p><p>打配合，最初也是弱小者报团取暖。</p><p>母狮凭借利爪与尖牙独行于荒野，单枪匹马便能撕裂猎物咽喉。</p><p>角马只能聚于庞大族群，依靠群体奔逃与互相遮挡抵御捕食者。</p><p>此刻三位准圣的配合，恰似角马群面对独行猎手时的生存策略，将各自法则的“犄角”交错成防御与进攻的网络。</p><p>他们曾经在各自的时代引领风骚，个体伟力冠绝一时，曾为“狮”。</p><p>本应有桀骜不驯的品性，但此刻却能按下彼此的脾气，分工行事。</p><p>不过也好理解。</p><p>毕竟在白杨大帝、残星道人面前，他们算不上“虎狮”，只能算“角马”。</p><p>角马只能抱团，否则会被狮子一一绞杀。</p><p>杨帝虽然被捆缚住，但没有挣扎。</p><p>残星道人，更是始终未动一指。</p><p>他甚至连眼神都未曾改变，只是漠然地看着这场力量悬殊的围杀。</p><p>仿佛杨帝的生死在他眼中，不过是尘埃落定的必然结局，根本无需他亲自出手。</p><p>那股超越境界的恐怖威压却愈发沉重，无形中锁定了所有的退路。</p><p>他在观察杨帝，随时出手。</p><p>但在这位圣人出手前，三位准圣首先抡着拳头走上前来。</p><p>“哇嗨，沙煲大的拳头喔。”杨帝说。</p><p>话音未落，两仪玄枢真君已如鬼魅般欺近，拳风裹挟着正反法则的狂暴力量，狠狠砸向他的头颅。</p><p>“嘭！”</p><p>一声闷响，仿佛西瓜爆裂，杨帝的脑袋瞬间炸开。</p><p>脑浆、神经、血肉、血液在拳力的极致压缩与撕扯下，全部化为炽热的亮红色夸克-胶子等离子气，如烟花般从七窍喷涌而出，染红了半边天际。</p><p>但下一刻。</p><p>杨帝的头颅以肉眼可见的速度，重新生长出来，嘴角甚至还挂着花白色脑浆。</p><p>“我不需要灵能，也可以快速愈合，而且似乎比你的‘无’之法则更高阶。”</p><p>杨帝刚把舌头和声带长出来，便不紧不慢点评道。</p><p>涅槃轮劫元尊见状，眼中寒芒一闪。</p><p>周身“生灭法则”骤然暴涨，化作一道漆黑如墨的轮盘虚影，朝着杨帝的身躯狠狠碾压而下！</p><p>“既然头颅能再生，那就将我彻底分解吗？很典型的头痛医头，脚痛医脚的思路。”</p><p>轮盘转动间，杨帝的身体在“灭”的法则侵蚀下，从四肢开始寸寸瓦解，肌肉、骨骼、经脉，由外向内逐步逐层化为飞灰。</p><p>太虚妙有法王、两仪玄枢真君紧随其后，尝试将这些飞灰彻底磨灭为虚无。</p><p>有些灰烬磨不烂，直接抛尸归墟。</p><p>但那些灰烬在归墟渊水上方漂浮，甭说被湮灭，它们甚至沉不下去。</p><p>于是，他们又决定抛尸八荒四海。</p><p>将人均匀地剁成10万份，洒往各地！</p><p>一时间，灵界东西南北，山川湖海，行星烈阳，乃至归墟深渊、时间缝隙之中，都出现用黑色塑料袋包装的杨帝碎片。</p><p>某些路过的灵界土著，或者是野生动物，成精的花花草草，或许会将其当作野生肉灵芝，合着开水服用。</p><p>对杨帝而言，这些已经“离体”了的残渣和灰烬，并不能算作身体的一部分。</p><p>所以确实是可以被磨灭殆尽的。</p><p>但很快，三位日常磨灭大道的准圣，逐渐磨不动了！</p><p>如果说，磨灭杨帝的皮肤表层，像是用飞刃切割伊文斯般容易，伊文斯很快就成了伊文丝。</p><p>那么磨灭其血肉，则是热刀切黄油、快刀斩乱麻，虽然顺畅，但“滞涩感”已经初现端倪。</p><p>如果各位日常生活中没怎么吃过或见过那种固体一大块的黄油（本狐也没怎么见过），可以想象用直尺的波浪锯齿，去锯香蕉。</p><p>而到了骨骼部分，想要磨灭，则更为艰难。</p><p>相当于用生锈的水果刀，劈砍过期20年的五金月饼。</p><p>准圣级实力轰上去，火星四溅却只能在骨头上留下浅浅白印，仿佛白杨大帝的骨骼本身蕴含着抗拒磨灭的本源力量，让三位准圣的法则之力都难以真正渗透。</p><p>杨帝的血肉正在再生，防御力不断暴涨，逐渐赶超三位准圣的磨灭速度。</p><p>他仍然一动不动，不打算反抗。</p><p>他紧紧盯住远处空中的「残星道人」。</p><p>除了三位准圣，就只剩下这位圣人，才是真正的劲敌。</p><p>残星道人，灵界圣人，是这四十二大帝中，杨帝唯一完全看不透的存在。</p><p>他们虽未在物理层面有任何冲突，但在精神维度，已然交手亿万回合。</p><p>“白杨大帝，你的精神力量浩瀚如天，甚至和我都不分伯仲。”残星道人不吝啬赞美。</p><p>杨帝在精神世界微微笑道：“我真的已经快死了，现在是‘重伤巅峰大圆满半步死亡’。你们还有什么手段，尽管招呼上来吧！”</p><p>“我注意到，你每次受到攻击，你的防御抗性都会上涨一个台阶。包括你的灵能水平。”</p><p>“逍遥，你能看清楚我的真实灵能水平？”</p><p>“圣人之下，皆为蝼蚁。我的存在甚至高于灵茶山乂斧，也就是高于这个灵界。我能看清你的本质。”</p>
