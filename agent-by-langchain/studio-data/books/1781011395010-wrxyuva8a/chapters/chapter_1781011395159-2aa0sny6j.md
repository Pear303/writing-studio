# 那位大人

<p>虚空中浮现出一行字幕，以及一口标准广播腔的普通话：</p><p>「槐安17世纪初，十万大山的封建帝国爆发最后一场内乱战争。」</p><p>「彼时，各方势力混战，百姓苦不堪言。1640年，外界已大部分统一的王朝加入战局，并与农民起义军合流，势力大增。」</p><p>「战火纷飞，局势逐渐从混乱走向明朗。至1644年，十万大山内的封建帝国风雨飘摇，其最后一任土皇帝天元神皇，在宫内走投无路。」</p><p>「天元神皇最终选择在歪脖子树上吊自杀，宣告这个封建帝国的覆灭。」</p><p>“呜哇……这就是五百年前的内战现场？比青丘狐狸讲述的惨多了喂！”</p><p>阿巴缩了缩鱼头，感觉虚拟的寒意都透过了精神连接，“那个什么天元神皇，最后就吊死在这种地方？”</p><p>虚空中，那行介绍槐安17世纪初内战背景的字幕缓缓淡去，标准的广播腔也归于沉寂。</p><p>只留下这片浸透了绝望与毁灭的虚拟战场。</p><p>杨帝的目光早已越过脚下破败的村落和焦土，投向远处那座笼罩在阴霾与战云中的巍峨山峰——君士叹顶峰。</p><p>它是这片虚拟天地中唯一还保持着相对“完整”的地标，如一头蛰伏的巨兽。</p><p>他以超越凡俗的超级智慧，推演出山峰内部的结构模型——</p><p>一个巨大的、不符合自然地质规律的“空腔”轮廓，清晰地烙印在他的感知中。</p><p>其他人也都已经感知到山体内的空洞。</p><p>“老大，里面真有一个密教基地。我们要一路砍杀，打怪升级，爬塔进去吗？”</p><p>“打怪？爬塔？”</p><p>杨帝仿佛听到了一个极其幼稚的笑话，哈哈大笑整整五分钟，随后才说，“浪费时间。”</p><p>青丘白璃还没来得及从这惨烈的虚拟景象中回过神，就感觉一股难以言喻的、仿佛要将整个虚拟世界都撕裂的恐怖“存在感”从杨帝身上升腾而起！</p><p>那不是灵能，也不是法力，也并非是纯粹到极致的力量……</p><p>而是磁场转动，足足100匹！！</p><p>“等……等等，杨帝阁下！您会把硬盘和主机打爆，将域外天魔放出去的……”</p><p>青丘白璃的惊呼只喊出一半。</p><p>杨帝动了。</p><p>他没有飞身而起，只是对着远方那座象征封建帝国最后堡垒的君士叹顶峰，平平无奇地抬起了右手。</p><p>五指张开，然后，缓缓收拢。</p><p>轰隆隆隆——！</p><p>无法用言语形容的巨响瞬间撕裂了虚拟世界的“宁静”。</p><p>这声音超越了物理法则的极限，更像是一个庞大数据库被暴力篡改时发出的、来自底层的崩溃悲鸣！</p><p>君士叹顶峰，屹立了不知多少虚拟岁月的庞大山体，在杨帝那只无形巨手的力量下，如同被顽童捏碎的泥塑玩具。</p><p>大地在模拟的震颤中疯狂抖动。</p><p>构成山峰的无数数据流、环境贴图、物理引擎预设的岩石模型……</p><p>在超越系统设计上限的力量面前，如同脆弱的玻璃般寸寸崩解。</p><p>巨大的山体结构被一股无可抗拒的伟力从基座上硬生生“掀”了起来。</p><p>不是崩塌，不是滑坡，是字面意义上的“掀掉”！</p><p>整座山峰，连同覆盖其上的积雪、焦枯的植被、残留的堡垒工事，被沛莫能御的力量连根拔起。</p><p>庞然阴影笼罩下方的焦土，无数虚拟巨石、泥土、碎裂的树木模型如同瀑布般倾泻而下。</p><p>山体内部，空腔暴露无遗，如同一个被强行剖开的巨蛋。</p><p>现实世界的“君士叹顶峰”，并不存在如此庞大的人造空腔。</p><p>由此可见，“十万溯光”虚拟世界中，确实发生了脱离历史走向的意外事件。</p><p>莫名其妙出现魔道信徒，挖空了一座山，作为秘密基地。</p><p>而且有能力在凡界技术工程师的眼皮子底下发生……</p><p>“老大！这是人家的历史沙盘！要赔钱的。”</p><p>杨帝对身后阿巴的惊呼和虚拟世界的哀鸣，置若罔闻。</p><p>他的目光穿透漫天飞舞的像素尘埃和崩解的数据流，牢牢锁定在山峰基座，暴露出的巨大空腔的深处。</p><p>如同神魔降世，一步踏出，身影已然出现在那被暴力撕开的“伤口”边缘，俯视着下方幽深的黑暗。</p><p>漆黑一片。几十个黑袍人将阴翳的脸庞，隐藏在阴影之下。</p><p>果然很符合传统反派的作风，也就是竭尽全力的关灯省电。</p><p>几十个身着漆黑兜帽长袍的身影，如同蛰伏在阴影中的毒虫，正围绕由扭曲符文构成、流淌着污秽紫黑色光芒的祭坛。</p><p>他们狂热地挥舞着枯槁的手臂，口中发出嘶哑、重叠、仿佛无数虫豸啃噬朽木的诵念：</p><p>“此界只是开端！让这流煞之焰，燃遍诸天万界！”之类的怪话。</p><p>他们用于藏身的山峰突然被人掀飞，仪式才终于被打断，诵念声戛然而止，如同被掐住脖子的鸭子。</p><p>一众魔信徒露出一瞬间的惊愕，随即，兜帽下隐藏的脸庞因愤怒和羞辱而扭曲。</p><p>“是朝廷鹰犬，还是‘那位大人’的敌对者？”</p><p>“能够凌空飞行，必定是来自‘那位大人’的世界，是大人的敌对者。”</p><p>“我们已将灵魂侍奉吾主，无论你说什么，做什么，我们都不可能开口……”</p><p>杨帝一步踏至空腔边缘，对着下方几十个狂热的黑影屈指一弹。</p><p>嗡！</p><p>所有魔道信徒如同琥珀中的蚊虫，连呼喊都卡在喉间，动弹不得。</p><p>“首先，你们不能自杀。”</p><p>杨帝的声音带着奇异的诱惑，“其次，说吧，把你们的小秘密都抖出来。”</p><p>杨帝凭亿近人，被禁锢的信徒，根本抵挡不住一千五百亿点的“话术”诱惑。</p><p>眼神瞬间迷离，争先恐后地嘶吼：“是那位大人赐下‘阴伏流煞’！我们奉命将其洒遍大地！”</p><p>“那位大人赐下的‘阴伏流煞’乃是灭世之种！只需一丝泄露，便可污秽星辰，腐化万灵！”</p><p>“我们的教主和左右护法……他们抓了重要人物，天元神皇，于是天道裂开一道缝隙，教主便带着核心煞种去往戏外……”</p><p>不多时，他们便将自己的老底透得干干净净。</p><p>“你们是说，阴伏流煞是‘那位大人’留给你们的，并且让你们尽可能的散布出去。”</p><p>“是。”</p><p>至于散布去哪里，自然就是虚拟城市之外的现实世界「凡界」了。</p><p>“散播到世界之外的方法，是拐走一些位高权重的重要人物？”</p><p>“没错。所以我们选择天元神皇作为下手目标……原本我们都是躲在阴暗的角落里发展。如果我们干涉世事，且干涉的程度越大，天空就越有可能出现一道去往世界之外的裂缝……”</p><p>仿佛为了印证这绝望的供词，众人抬头。</p><p>虚拟苍穹之上，赫然残留着一道狰狞的、尚未完全弥合的“伤疤”。</p><p>伤疤边缘，还用红色字体标注着几个凡界文字「ERROR」。</p><p>“原来如此，当虚拟沙盘内，对历史的模拟走向出现重大偏差，工作人员就会介入。此时恰好也是这些‘魔道数字生命’脱身的绝佳机会……”</p><p>杨帝：“最后一个问题，‘那位大人’是谁？”</p><p>这次，魔道信徒头头竟然在杨帝的话术诱惑下，坚持了整整3秒。</p><p>他终于支撑不住，说出那个名字：“那位大人的名讳不可言说，甚至不可想象。我只能勉强说出其他伟大的发音——</p><p>“guī xū dà dì啊啊啊！！”</p><p>说完他便陷入疯狂，掉san把自己脑子洗成傻逼了。</p>
