# 逃离阴霾

<p>杨帝转身走向胡彦卓，强殖装甲在黑暗中泛着幽光。</p><p>圆形平台中央，胡彦卓已经醒了，他好像有些费力地睁开眼睛。</p><p>他眼前的身影，仿佛是从深渊梦境中挣脱而出的噩梦。</p><p>“啊，呜哇啊——”</p><p>胡彦卓口齿不清，不知道在说什么。</p><p>正常，毕竟杨帝周身被一层流动的黑色拉面所覆盖，紧密交织，宛如装甲。</p><p>他半张脸庞被一层甲壳结构，仅有左眼裸露在外，瞳孔深处似有火焰跃动。</p><p>外表看起来，完全是个黑色拉面怪物。</p><p>“是我，胡哥。”杨帝的声音从装甲中闷闷传来，“我用希夷的力量做了个临时装甲，样子是丑了点。”</p><p>他捡起地上的强光手电，打开灯。</p><p>胡彦卓呆滞地眨了眨眼。</p><p>他缓了好一会儿，才好像想起该怎么说话，干裂的嘴唇翕动：“杨帝……你的脸？”</p><p>“刚才和那俩怪物硬碰硬，挂了点彩。”</p><p>杨帝扯动嘴角，装甲面具随之裂开缝隙，露出染血的牙齿。</p><p>胡彦卓望着他背后如蝙蝠展开的黑色翼膜，以及翼膜上密布的拉面状凸起，虚弱地说道：“我刚才……还以为你是个人形的黑色拉面怪呢……”</p><p>他面色很苍白，凹陷了一小块的胸腔微弱起伏，说话和呼吸都是气若游丝。</p><p>胡彦卓的目光突然凝固在自己的右手上。</p><p>他感受到除了略微凹陷的胸腔，那处地方同样传来钻心的剧痛。</p><p>他手指在黑暗中微微颤抖，直到手电筒的光束扫过掌心，才发现——食指根部只剩下一截血肉模糊的断茬。</p><p>“我的手……我的手指呢？”他的声音像被掐住脖子的幼兽，带着破碎的呜咽。</p><p>杨帝蹲下身，按住胡彦卓颤抖的肩膀。</p><p>“但只要保持断指的生物活性，等出去后找家好医院，接回去的概率很大。”</p><p>他又喘了几口气。</p><p>胡彦卓摸了摸胸口：“我感觉……胸口这里好痛……凹下去了……嘶，我可能骨折了，但万幸没有伤到内脏……”</p><p>杨帝默默看着他：“你不会死的。”</p><p>胡彦卓看起来是强行平复了心情，他点点头：“接下来怎么做？”</p><p>“胡哥，咱话不多说，现在有个大麻烦——上头那位把这里当祭坛。我们得赶紧走了。”</p><p>他指了指上方。</p><p>那团翻涌的黑色潮水，或者说更像是一大团黑色拉面，此刻正在焦躁地蠕动。</p><p>它从十分钟前，就开始不说话。</p><p>杨帝不会天真到认为它睡着了。</p><p>但他不清楚，这团幕后主使、这一大团有智慧的黑色拉面——它到底在谋划些什么？</p><p>它正在准备些什么？</p><p>它是否仍然在注视二人的一举一动？</p><p>一概不知。情报量太少，未知使人不安。</p><p>杨帝不喜欢被动等死，他要主动出击。对当下情况，应该得主动逃跑。</p><p>他把胡彦卓从圆形平台中央扶起来，帮扛着向前走。</p><p>“那边就是出口。出了下水管道，右转不到80米就是逃生通道……坚持一下……”</p><p>话音未落，头顶传来混凝土爆裂的轰鸣。</p><p>无数黑色藤蔓穿透穹顶倾泻而下，那些黑色的面条终于有所动作。</p><p>它们如同被斩断的章鱼腕足般疯狂扭动，表面布满青筋暴起般的脉络。</p><p>它似乎绝望地想要挽留二人。</p><p>但手不够长……没错……那些黑色触手不够长。</p><p>始终差那么一点，无法触及猎物的衣角。</p><p>怪物发出尖锐哀鸣，整个洞穴的墙壁都开始渗出黑色黏液，仿佛在为无法触及猎物而痛苦挣扎。</p><p>它似乎被禁锢于穹顶，活动范围有极限。</p><p>方才的狸花猫、小白鼠、麻雀，就是它仅存可用于活动的几具躯壳。</p><p>而现在，它能用来进行活动的身体，都因为战略和战术的失误，永远失去了。</p><p>杨帝看向穹顶，一边擦嘴角的血一边笑：“虽然不知道你是个什么玩意，但你可以操控的身体都没了！我不知你哪来的勇气，居然敢对我用瓮中捉鳖！”</p><p>那一大团被禁锢在最顶层的黑色拉面团，发出断断续续，像是老式电视机卡壳时的哀嚎：</p><p>「瓮……鳖……耶罗……符印……」</p><p>「站……住……窃贼……贼……」</p><p>杨帝敲了敲半死不活的希夷：“希夷，脱离我，然后你为胡大哥殖装‘辅助外骨骼’，他有些走不动道，但我们必须走快点。”</p><p>“哦……好……明白……yes sir……”</p><p>希夷从杨帝身上流淌下来，有些筋疲力尽地重新凝聚成麻雀团子。</p><p>它喘着粗气，飞到胡彦卓身前，重新化作黑色拉面触手怪，包裹胡彦卓的肢体躯干……</p><p>胡彦卓潜意识却有些惧怕，几乎是下意识将希夷甩开。</p><p>他看着地上那滩生无可恋的黑色拉面，一边道歉，一边摆摆手：</p><p>“不用不用，我自己能走……”</p><p>“胡哥，你这是……害怕这些黑色拉面？”</p><p>“……”</p><p>胡彦卓顿了好久，可能是在思考措辞，可能是组织语句。</p><p>最后叹了口气，苦笑道：“杨帝兄弟，我只是突然发现了一件可怕的事——两年前，我录制跑酷视频时，把我绊倒的其实不是‘电缆’，而是这些黑色拉面形状的物质。”</p><p>原来如此。杨帝堵在心口的诸多疑问，也终于解开了。</p><p>如果是这样，那确实说得通。</p><p>凭空出现、绊倒了胡彦卓的电缆，根本不是电缆，而是有人在捣鬼。</p><p>为此，他承受了整整两年的PTSD。</p><p>杨帝沉默地看着他剧烈起伏的胸膛，注意到他后颈已经沁出细密的冷汗。</p><p>那些黑色拉面在胡彦卓的认知里，已不是单纯的物质形态，而是具象化的未知威胁，是命运恶意的具现。</p><p>胡彦卓疲惫地闭上眼睛，喉间发出一声苦笑：“抱歉，让你们看笑话了。”</p><p>希夷长吱一气：“这样吧，我妥协一下。”</p><p>它在地面上缓缓蠕动，立了起来，逐渐凝聚成一支乌木拐杖的形状。</p><p>它刻意收敛了所有触手形态，表面呈现出木质的纹理与温度，甚至在杖柄处留出了便于握持的凹陷，放到外界会被奉为“人体工学仙人”。</p><p>杨帝在一旁默默点头：“希夷的拟态能力比我想象的更强，这拐杖能支撑你的重量。”</p><p>二人一杖，踉踉跄跄，相互扶持着走向污水管道。</p><p>边缘有几根黑色拉面，似乎是从穹顶延伸下来，想要阻止他们逃离。杨帝生而啖之。</p><p>这些类似于“漏网之鱼”。</p><p>数量很少，实力低微，但危险是有的。</p><p>杨帝斟酌了利弊，反手掏出麻花形状的瑞士军刀，塞给胡彦卓。</p><p>“胡哥拿着这个，你用来防身。现在我真的很累很累，我背后就交给你了……噗……”</p><p>钻心的剧痛从后背开始，刺破胸膛，传遍全身。</p><p>杨帝难以置信地低下头。</p><p>他用0.1秒，搞清楚了现状——</p><p>自己心脏被扭曲成马来剑的瑞士刀穿透。</p><p>持刀者，胡彦卓。</p><p>或者说是“胡彦卓”——他已不再是他了。</p><p>现在醒悟实在太晚，但杨帝无论如何都想象不到，瓮和鳖，都是它的饵。</p>
