# 第31章

<p>而更让他震撼的，是那些凡人！</p><p>田间耕作的老农，集市上的小贩，河边洗衣的妇人，私塾里读书的孩童……</p><p>所有人，整个天墟界，所有人族一夜之间，全部迈入炼气期以上！</p><p>萧凡叶浑身颤抖。</p><p>他活了九百年，从未见过这样的景象！</p><p>即使用“机缘”、“造化”描述此情此景，都显得太过贫瘠了！！</p><p>“龙佑阁下……这……”</p><p>龙佑摆了摆手：“我只是做了微小的工作，把这尊太乙真仙十三万年掠夺的‘气运和因果’，返还给大地众生而已。”</p><p>十二万九千六百年的气运，返还给众生。</p><p>他无言可论，最终也只能深深一揖，声音郑重：“前辈大恩，天墟界永世不忘。”</p><p>“哈哈，不妨事。对了萧凡叶，问你个事。”</p><p>“前辈请讲。”</p><p>“你思念地球故乡吗？”</p><p>这个问题来得突然。萧凡叶目光越过那些欢呼的人群，越过崩塌又重生的山峰，投向不知名的远方。</p><p>良久，他苦笑了一下。</p><p>“思念。怎能不思念。九百年来，我每夜都会梦见公司楼下那家卖煎饼果子的摊位。</p><p>“我甚至梦见过年时我妈包的饺子——她总喜欢在馅里放一枚硬币，谁吃到谁有福气。</p><p>“我小时候总抱怨硌牙，而我换牙期时也确实有两颗牙是这么磕掉的。后来……”</p><p>龙佑：“要我帮你回去吗——”</p><p>“不必麻烦。前辈，在下疯狂修炼九百载，您觉得是为了什么？”</p><p>龙佑怎么回答？仙尊悔而我不悔，春秋蝉鸣少年归吗……</p><p>萧凡叶自己给出了答案：“有一部分原因，确实是为了天下苍生。天墟界八百兆黎民，我既为人皇，自当守护。”</p><p>他顿了顿，眼中闪过一丝复杂的光芒：</p><p>“但更多原因，是为了有朝一日破碎虚空，回归地球。”</p><p>龙佑静静地听着。</p><p>“九百年来，我无数次想过，若是修为足够，或许能找到一条归乡的路。合体期能触碰空间法则，渡劫期能破碎虚空，太乙真仙更是有让熵倒流的威能——我一步步往上爬，就是盼着有一天，能凭借自己推开回家的门。”</p><p>他看向龙佑，眼中满是感激：</p><p>“如今在前辈帮助下，在下已臻至渡劫期。虽然只是初阶，但归乡之路，已不再是遥不可及的梦。</p><p>“再过些时日，待我稳固境界、参悟空间法则，便能自行寻到那条回家的路！</p><p>“境界越是高深，便越能感受到跨越世界付出的‘代价’之大。</p><p>“前辈将投影送到此界，帮助天墟界度过万载危机，已是‘极大的牺牲’。</p><p>“萧某便不再劳烦前辈出手相助了。”</p><p>龙佑本想说我让你回去，其实只要动一个念头就好了，并没有什么‘大牺牲’。</p><p>但看着萧凡叶坚定的眼神，他也便没有破坏这位人皇穿越者的觉悟。</p><p>自力更生好啊，反正在这个世界，他龙佑，已经做得够多了。</p><p>天墟界将会走向蒸蒸蒸蒸日上的盛世，想必人皇萧凡叶，很快便能靠自己的力量回来吧。</p><p>……</p><p>九十九层高的凌霄酒楼门口，琉璃作瓦，灵玉铺阶，飞檐斗拱间篆刻着流光溢彩的聚灵符文。</p><p>御风阵驱动版的纯灵力电梯直上八十八层，这层专供刚入修途的散修小聚，菜谱都是灵气融合凡俗风味的创意菜。</p><p>龙佑挑了个靠窗的位置坐下。</p><p>虽是夜，却也能见窗外云海翻涌，远处几名金丹修士踩着飞剑送外卖。</p><p>天墟界社会变化速度极快，再加上萧凡叶是地球人，对周围的土著描绘了诸多地球职业，耳濡目染，一些类似外卖员、玄法顾问、境界突破培训班之类的新行业也纷纷出现，以适应如今人人皆可修炼的世界。</p><p>侍者小跑过来，仙鹤腿颤巍巍，手里捧着云母托盘上的菜单：“客官您好，本楼今日特色是翡翠灵藕炖冰鸾、火云符烤仙鹤腿……”</p><p>一听就很贵，而且名字花里胡哨。</p><p>这类菜一律不点，这也是地球经验。</p><p>“那好，给我来——半只卤水烧鹅，一份见手青刺身，再来一大杯折耳根榨汁！要现榨的！”</p><p>“卤水烧鹅？见手青？折耳根？！”</p><p>“对，最通俗的那种。见手青要切薄，蘸芥末酱油；折耳根别加糖，原味。”</p><p>店小二脸上的笑容瞬间凝固，周围几桌正吹嘘自己品鉴过多少灵草仙丹的食客，耳朵也齐刷刷竖了起来。</p><p>“这……这位道友……”店小二结结巴巴，悄悄压低声音。</p><p>“卤水烧鹅也就罢了，虽油腻，凡人亦能食之，只是于修无益。但见手青乃剧毒灵菌，凡人食之立毙，便是一般炼气期修士贸然吞食，也得在床上躺个十天半月！折耳根更是气味独特，榨汁生饮，非铁胃道心不可！小店有规矩，点这类‘险馐’，需出示修为证明，否则……得签生死状，后果自负啊！”</p><p>倒不是说搞什么身份政治、修为歧视。</p><p>而是这骨科点的菜品比较劲爆，如果修为不达标，就得签生死状才能开饭！</p><p>龙佑轻弹衣袖，一缕微不可察的仙韵荡开。</p><p>他朗声一笑：“现在这天墟界，谁还不是个修仙者呢？”</p><p>店小二似有所感，躬身应是，快步离去。</p><p>不多时，菜齐了。</p><p>卤水烧鹅油光发亮，见手青切片薄如蝉翼，折耳根榨汁盛在玉杯里，碧绿清冽。</p><p>周围食客早已放下筷子，有的偷偷祭出留影石，有的掐诀远程识文扫描菜盘。</p><p>天墟界长期处于封建社会，人们的思想没那么放得开。</p><p>龙佑点这种菜，已经有很多旁听的食客想要蠢蠢欲动，大骂一声菜白死、你白活，上前将他擒住制服。</p><p>但见龙佑慢条斯理夹起一片见手青，蘸了芥末酱油，送入口中。冰凉、辛辣、鲜滑、继而一丝微麻蔓延舌尖——熟悉又陌生的毒菌风味，配上灵气滋养后更浓郁的氨基酸鲜味，竟比地球的还要上头。</p><p>又夹块烧鹅，油脂入口即化，卤香与灵气在齿间爆开，连骨缝都酥了。灌口折耳根汁，清冽回甘，毒热浊气顿时冲散。</p><p>不对！他真吃完了，没有浪费！</p><p>结账时，龙佑没有付款，老板像供大佛一样将他踢出去。</p><p>就这样骗吃骗喝，龙佑在天墟界晃荡了整整一个月。</p><p>这一个月里，他可谓是把修仙爽文的套路玩出了花。什么“坠崖捡秘籍”、“退婚打脸”、“拍卖会捡漏”，全用一种极为超然又极为无聊的心态体验了个遍。</p><p>比如去赌石。</p><p>天墟界的赌石坊里，那种声嘶力竭的氛围和地球的地下赌场别无二致。龙佑开启概率视角，一眼扫过那堆灰扑扑的顽石。</p><p>【天墟界所有赌石坊，开出好货的概率：0.9%】</p><p>“0.9%？还挺高。”龙佑摸了摸下巴。</p><p>按照爽文套路，这时候他应该大手一挥，把这块没人要的废石买下，然后一刀切开，惊掉周围人的下巴，再收获一枚高冷红颜知己。</p><p>但他只是笑了笑，心念微动。</p><p>【天墟界所有赌石坊，开出好货的概率：0.9% → 0.09%】</p><p>无形大手暗调概率。</p><p>“潜龙，你说我这是不是在劝人向善，远离赌博？”</p>
