# 操纵一界概率！

<p>“这是……”他看向四周。</p><p>那些重伤的化神期掌门还单膝跪在地，保持着刚才的姿势。但他们的表情凝固，眼神定格，连呼吸的起伏都消失了。</p><p>萧凡叶瞳孔微缩。</p><p>他抬头看向天空——那些四散奔逃的异族残兵，那些飘浮的云朵，那些翻涌的妖气，全都静止了。</p><p>整个世界，仿佛被按下了暂停键。</p><p>时间……萧凡叶喃喃。时间变慢了？</p><p>不，不只是变慢。</p><p>他艰难地转动眼珠，发现连这个动作都需要耗费巨大的意志力。试图抬手指，手指末端只能微微颤抖，幅度小得几乎看不见。</p><p>他想催动灵力，体内那澎湃的渡劫期力量却如同沉睡的巨兽，对他的呼唤毫无反应。</p><p>唯一能自由活动的，只有自己的思维。</p><p>能让整个世界静止，能让渡劫期修士如同琥珀中的蚊虫般动弹不得？！</p><p>九天之上，一道裂隙缓缓打开，从裂缝中涌下光芒。</p><p>阵阵梵音从天而降，虽不是任何语言，却能让听者明悟其中真意——天道的低语，法则的吟唱，宇宙运转时自然而然发出的声音……</p><p>萧凡叶瞳孔剧烈收缩。</p><p>他拼尽全力，勉强转动眼珠，看向裂隙。</p><p>裂隙中，一尊笼罩在白光中的虚幻人形缓缓降下。</p><p>那人形没有实体，只是一团光影，却给人无穷无尽的压迫感，仿若是那种“存在本身”就足以让人明白自己渺小的感觉，蝼蚁仰望苍穹，滴水面对沧海！</p><p>那人形悬浮于九天之上，没有动作和表情，甚至没有目光——但萧凡叶莫名知道，祂正在看着这边。</p><p>准确地说，正在看着龙佑。</p><p>“何人在操纵此界气运？”</p><p>萧凡叶的思维疯狂运转。操纵此界气运？谁？龙佑阁下？</p><p>他艰难地转动眼珠，看向身侧三丈外那团人形黑雾。</p><p>龙佑依旧悬浮在那里，依旧飘忽不定，依旧无法感知任何气息。</p><p>但此刻，在萧凡叶眼中，那团黑雾变得无比神秘，无比深邃，无比、可怕！</p><p>操纵一界气运！这般行径，便是上古开天辟地的传说大能，也从未有人敢触及，更无人能做到。</p><p>一界气运为何物？</p><p>天道流转的轨迹，苍生祸福的根髓，天地间最不可触碰的至高法则。</p><p>即便是已踏足合体境、洞悉自身道途与实力的萧凡叶，也比谁都清楚：</p><p>以凡躯修者之力，妄图执掌一整个世界的气运、拨弄因果，无异于蚍蜉撼树。</p><p>莫非是天道亲自出手？</p><p>唯有天道本源，才有这等改写一界气运、定夺因果的伟力。</p><p>可天道无情、无念、无执，它只循规运转，盈则自溢，亏则自补，从不干涉凡尘分毫。</p><p>而此刻，偏偏有一道存在，悍然插手了此间气运与因果。</p><p>那是超脱凡俗、又凌驾道法的存在。</p><p>拥有“天道”级别的伟力，却又以“人道”损不足而奉有余的准则行事。</p><p>是古籍中只存只言片语、世人连仰望资格都没有，超越的渡劫境界的——真仙！</p><p>天墟界不知今夕何年，太乙真仙降临。</p><p>九天之上，一道朦胧人影静静悬立。</p><p>周身弥漫道韵凝成的无上清辉，漫过苍穹，压塌万古！</p><p>世界在他出现的一瞬彻底静止。光阴凝固，空间锁死，风不吹，云不动，连天地法则都为之噤声！</p><p>凡人与低阶生灵连一丝察觉都不曾有。</p><p>他们的神魂、灵识、甚至存在本身，至多只会感觉前一个动作和下一个动作之间，似乎不太连贯。</p><p>唯有萧凡叶凭着渡劫境的道基，勉强能转动眼珠。</p><p>那股光阴凝固的力量冲刷着他每一根神经、每一缕经脉、每一寸血肉、每一道神魂，转动眼珠，勾动手指已是极限！</p><p>白光人影没有任何动作，却能感受到一道无形的意志，漠然落下，直指龙佑。</p><p>天地寂寂无声，龙佑周身翻腾的人形黑雾，是同样的从容不迫。</p><p>“操纵气运，他说的莫不是我？”</p><p>【应该是。“气运”这个词嘛，它和“概率”也是息息相关的。“运气好”的意思是，经常能碰上小概率的好事。】</p><p>【对方如此强大，你要避一避锋芒吗？】</p><p>“我避他锋芒？”</p><p>龙佑寻思，不过这家伙是怎么找上门来的？</p><p>【他觉察到了“概率”发生剧变。】</p><p>【拥有了炼虚期与合体期经验的你我，能一定程度看到“世界线”的走向，也就是这世间命运概率的变化。】</p><p>【天墟界世间巅峰强者，是可以看到命运之轨迹、世界线变动的。】</p><p>【而你刚才大张旗鼓地修改萧凡叶突破的概率，又修改了整个天墟界人族崛起的概率。】</p><p>【前者是站在世间顶点的修仙者，后者则是整个种族的未来。】</p><p>【在世界巅峰强者眼中，相当于在光天化日下、光明正大地乱调游戏抽卡爆率，还非常嚣张地在WB对基本盘玩家开大。】</p><p>“这就是他找上门来的原因。”</p><p>龙佑眼前的视角被拉升，向着超越三维的维度无限延伸。</p><p>他站在光阴长河之上，或者说以无法形容的方式存在于那里。</p><p>脚下是无数条奔涌向前的世界线，每一条都如同晶莹的丝线，在时空中无穷的维度中无限延伸。</p><p>而无数的丝线，仍然在以超乎想象的速度分裂、增殖、分叉。</p><p>一化二，二化四，四化八，指数级增长，无穷无尽的分裂！</p><p>每条新生的世界线都是一个独立的可能性，每个可能性都是一方真实的天地。</p><p>而在这些世界线深处，龙佑看到了自己做过的事。</p><p>那一道概率为100%的指令，激起了滔天巨浪。</p><p>原本平稳向前、略有起伏的世界线群，此刻正以疯狂的姿态扭曲偏向。</p><p>无数条原本通向黑暗深渊的世界线，在他这道指令影响下，生生扭转了方向，向着另一个终点狂奔而去——</p><p>天墟界人族，走向繁荣昌盛之世。</p><p>那白光人形，此刻也立于时间长河之上。</p><p>他的身形依旧笼罩在无尽清辉中，无穷无尽的灵能从他体内涌出，如亿万条触手般探入那些疯狂分叉的世界线中。</p><p>他在尝试修正。</p><p>每一条世界线中，他的力量都在与龙佑的修改指令对抗。</p><p>他试图将那些扭曲的轨迹扳回原位，让世界线回到原本的“正轨”。</p><p>然而毫无卵用！无论他投入多少灵能，如何拼尽全力，世界线依旧疯狂地扭曲蠕动分叉！</p><p>最终无一例外地涌向同一个终点！</p><p>一个100%注定了的结局！</p><p>那白光人形停止了徒劳的修正，缓缓转过身来。</p><p>龙佑眯了眯眼。</p><p>【对方那层白光主动或被动地撤除，露出真面目：100%】</p><p>他周身笼罩的白色光辉收敛褪去，露出光辉之下的真实面目。</p><p>那是一个老者。须发皆白，面容清瘦。一袭素白道袍，周身萦绕着淡淡道蕴。</p><p>仙风道骨。</p><p>但那双眼睛中，此刻却闪烁着复杂难明的光芒，被道破心思的惊愕，无法扭转局面的震怒，还有些许若有若无的忌惮。</p><p>‘等等……本仙的护体灵光怎么突然自己关了……’</p><p>‘无妨，反正要撕破脸了，此刻露脸也并无大碍。’</p>
