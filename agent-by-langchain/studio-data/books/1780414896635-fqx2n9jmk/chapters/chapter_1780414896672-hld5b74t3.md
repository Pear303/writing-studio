# 只是想成个尊

<p>龙佑很不满眼前这家伙的行径：“你布局十三万年，就为让这个世界成为你的‘丹药’。”</p><p>“十二万九千六百年，而非十三万！况且，修仙之路，本就是逆天而行，顺则凡逆则仙，天地不仁以万物为刍狗，吾不过是顺应天道，取吾所需，只为取得长生，仙尊悔而我不悔……”</p><p>“味太冲，一开口就是修仙文经典语录！”</p><p>龙佑对这个刻板印象的世界实在感到刻板印象。</p><p>时间长河依旧在疯狂奔涌，无数世界线通向那个繁荣的终点。</p><p>天墟真人十二万九千六百年的布局，已成泡影。</p><p>事已至此，便只有一个方法能挽回损失。</p><p>天墟真人抬手，亿万灵光体内涌出，凝聚成一道贯穿时间长河的恐怖攻击，直指龙佑！</p><p>“既然如此，那便让吾看看，你究竟凭什么敢坏吾十二万九千六百年大计！”</p><p>“别瞎惦记你那‘十二万九千六百’了！”</p><p>天墟真人怒道：“大荒囚天指！”</p><p>那道贯穿时间长河的恐怖攻击，携十二万九千六百年积累，轰然袭来！</p><p>龙佑没有躲。他想试试，渡劫巅峰加上超人力量，究竟能扛住什么级别的攻击。</p><p>【渡劫巅峰】【超人力量】</p><p>下一瞬，半个身子炸开！</p><p>从肩膀到腰际，在太乙真仙的一击之下瞬间化为虚无，连渣都不剩。</p><p>龙佑疼得差点骂娘。</p><p>但信息屏蔽全开之下，在萧凡叶和天墟真人眼中，那团人形黑雾依旧静静地悬浮在原地，纹丝不动。</p><p>“半个身子炸开”这一信息，也被屏蔽。</p><p>他们看到的龙佑，似乎毫发无伤，连一丝颤抖都没有。</p><p>事实上，虽然龙佑被拦腰斩断，但他也确实距离死亡还有天堑般的距离。</p><p>【不灭】</p><p>天墟真人瞳孔微缩。</p><p>他清晰地感觉到自己的攻击击中了目标，这绝强一击，足以将一个渡劫巅峰大圆满的修道者轰掉半截身子。</p><p>但为什么，那黑雾依然悬浮在那里？</p><p>依然从容不迫？依然……没有半点变化？</p><p>不对……</p><p>那黑雾的形态确实没变，但他的感知中，对方的气息……似乎正在飙升？！</p><p>龙佑没空理会天墟真人的疑惑。</p><p>“如果我原地突破太乙真仙，会怎么样？”</p><p>【我原地突破太乙真仙：0.00009191%】</p><p>【没想到这概率貌似还挺大的，并不是说绝对的0%！】</p><p>【或许，这与你本身就有‘渡劫巅峰’的修为相关。】</p><p>【就如从5年级跳到6年级，不算很难，但从1年级直接跳级到6年级，那概率才叫渺茫。】</p><p>“好吧。让我看看自己成仙后，会让历史迎来怎样的大变。”</p><p>龙佑意念一动，时间长河在他眼前展开。</p><p>无数条世界线从此刻分叉，每一条都通向概率不同的未来。</p><p>龙佑意念一动，时间长河在他眼前展开。</p><p>无数条世界线从此刻分叉，每一条都通向概率不同的未来。有的线上他成功晋升，有的线上他选择暂缓，有的线上他直接被那道攻击轰碎——不，等等。</p><p>他眯起眼，重新扫了一遍。</p><p>那些分叉的世界线中，没有天墟真人。</p><p>每一条线上，他都能看到自己的身影，看到萧凡叶，看到天柱峰，看到那些翻滚的魔云。但唯独天墟真人，像被人从底片上抠掉了一样，只剩一片空白。</p><p>“潜龙。”</p><p>【看见了。其他世界线里没有这老登，只有眼前这一个。】</p><p>龙佑眉头皱起来：“这就是太乙真仙？”</p><p>【类似。魔法少女伊莉雅成尊以后，在其他世界线中也找不到她的痕迹。】</p><p>话说魔法少女伊天帝踏足时间长河，横击过去现在未来敌，镇压黑暗不详，诸天再无她的绝世身姿，只留下娇小少女的背影，独断万古！</p><p>【这应该是跳出时间长河的副作用——或者说特权。你不再拥有平行自我，也不再被平行自我的可能性所覆盖。】</p><p>“那我怎么对付他？我的能力是修改‘概率’，概率本质上应该是这无穷多条世界线的可能，如果他只存在于这一条线上……”</p><p>龙佑第一次有点慌！</p><p>他横行资本就是操控概率，而世界线分裂，就是不同概率、不同可能性的直观体现。</p><p>如果世界线中再无天墟真人身影，是否说明他无法被龙佑选中……</p><p>【你先别慌。试试看，你能不能突破到太乙真仙。】</p><p>龙佑心念一动，脑海中那个数字跳了出来——</p><p>【龙佑原地突破太乙真仙：0.00009191%】</p><p>熟悉的数字。他意念轻拨，那串数字像拧动旋钮一般开始变化。</p><p>【0.00009191% → 1.00009191%】</p><p>没有卡顿迟滞，没有“目标无法选中”的提示。</p><p>龙佑嘴角微微一扯：“能改。”</p><p>【再试试看，能不能对他动手脚。】</p><p>【天墟真人扑街：0.000000001777%】</p><p>【天墟真人扑街：1.000000001777%】</p><p>天墟老登身形似乎稍微踉跄了一下。</p><p>【看来概率操控能力，可以‘选中’真仙。】</p><p>【但或许是你还未正式达到真仙层次，所以不明白——真仙只能在一条世界线中出现，那他究竟是如何被概率操控左右的？】</p><p>“那等我突破以后，自然就明白了。”</p><p>【正解。】</p><p>天墟真人也注意到，龙佑心神似乎并不集中。</p><p>那团黑雾明明被击中，却在原地一动不动，仿佛在思考什么。天墟真人冷笑一声：</p><p>“怎么，难道你想在此地突破太乙真仙？别做梦了。”</p><p>龙佑抬头看他。居然被猜中了！</p><p>天墟真人负手而立，眼中闪过一丝讥讽：</p><p>“天墟界不过是一方小千世界，资源有限，天道残缺。此界只容得下一个太乙果位——就如尔等凡人世界的泡利不相容原理，同一能级上，不可能存在两个相同的粒子。”</p><p>一个仙风道骨的老仙人是怎么知道“泡利不相容原理”的呀！</p><p>天墟真人声音中带着十二万年积淀的自信：</p><p>“本座在此界经营十二万九千六百年，早已将此界太乙果位炼化入体。</p><p>“除非你在天墟界之外、就已经化作真仙。</p><p>“否则绝无可能、在天墟界内从通过‘渡劫’突破太乙真仙！”</p><p>“这是‘概率为零’的虚无之事！！”</p><p>龙佑：“你刚才是不是说了‘概率为零’？”</p><p>“……本座在十二万九千六百年前，便已将太乙道果炼入……”</p><p>“别转移话题，我问你，你刚刚是不是说了‘概率为零’这四个字？”</p><p>天墟真人有些绷不住：“汝，何意味？”</p><p>龙佑笑道：“没什么，只是想成个尊。”</p>
