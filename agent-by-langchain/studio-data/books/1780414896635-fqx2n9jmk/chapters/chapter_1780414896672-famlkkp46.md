# 血战（大嘘）太乙真仙！

<p>时间长河在他们脚下奔涌，无数世界线依旧如同是这种毛糙的发梢在疯狂分叉延伸。</p><p>“汝……究竟是何方神圣？吾于此界布局十二万九千六百年，眼见功成，却被汝一朝毁去。”</p><p>“没礼貌！问别人是谁之前，你应该先介绍自己是谁。”</p><p>【对方无论是否愿意，都在此刻说出自己的真名：100%】</p><p>“怎可能告知汝、吾乃……天墟真人！”</p><p>那老头子瞪大眼珠。</p><p>不知为何，自己先是没控制住，暴露出真正的面容。</p><p>此刻又控制不住自己嘴巴、暴露真实身份！</p><p>……</p><p>天墟真人看着脚下那些疯狂扭曲的世界线，面色铁青。</p><p>十二万九千六百年。</p><p>这是一「元会」的数字。</p><p>他从蛰伏隐忍，步步为营，耗费了整整一元会的光阴，才布下这盘笼罩整个天墟界的棋局。</p><p>引导人族与异族相互攻讦，让双方始终维持着脆弱的平衡——既不让任何一方彻底消亡，也不让任何一方真正强大。</p><p>暗中扶持那些野心勃勃的枭雄，比如那些总是不开灯，躲在阴暗洞府里集会的家伙。</p><p>也悄悄扼杀那些可能带来和平的天才，展露头角的少年。</p><p>他让正道与魔道势如水火，宗门与家族明争暗斗，散修与世家互相仇视。</p><p>大地之上，乱成一团。</p><p>而他要的，就是这团乱。</p><p>因为只有在混乱中，众生才会相互消耗；只有在消耗中，这个世界的力量才会被最大限度削弱；只有在削弱到极致时，他才能一举发动那准备了十二万九千六百年的【混元炼道炉】——</p><p>将整个天墟界，炼成一枚丹！</p><p>足以让一头猪登临真仙之位、甚至冲击金仙的绝世大丹！</p><p>为此，他设计了无数精妙的环节。</p><p>任由诸多功法就此失传。纵有少数修士冒死将副本秘藏于宗门禁地、悬崖底下、藏经阁隐秘处，终究寥寥无几，无伤大雅。</p><p>将天材地宝、绝世法宝尽数毁作残片，只配被收破烂的按斤论价、摆在地摊上，寻常修士再难窥见其原本神异。</p><p>暗中操纵那些心怀歹毒的族中亲眷、恃强凌弱的同门师长，去打压那些崭露头角的少年天才：扣其资源，逼其退婚，甚至亲手废去修为，令其再无翻身之日。</p><p>将心怀大义、气度不凡的强者尽数轰杀。纵然偶尔会有残魂趁乱遁走、不知所踪，想来也翻不起什么风浪，不足为虑。</p><p>一超多强的格局，被天墟真人一点点瓦解。</p><p>最终变成如今这副模样——无强多弱，群熊搏起！</p><p>谁也压不过谁，谁也灭不了谁。每天都有战争，每刻都有死亡，每息都有力量被消耗。</p><p>快了。</p><p>就快到了。</p><p>再过两千年，不，以现在的消耗速度，一千年就够。一千年后，此界底蕴耗尽，他便可以……</p><p>然后，就在刚才。</p><p>一切都变了。</p><p>天墟真人闭上眼，神识扫过那无数条疯狂扭动的世界线。每一条，每一条，每一条——都通向同一个他从未设想过的终点。</p><p>天墟界人族，走向繁荣昌盛之世。</p><p>繁荣昌盛……繁荣昌盛……</p><p>这四个字落在他感知中，如同诛仙四剑，将他的心脏刺得千疮百孔。</p><p>他看到了什么？</p><p>一个凡间老农，正在田间耕作。他驱使着木牛流马，那是再普通不过的凡物，作用是耕地。</p><p>忽然，老农一锄头落下，锄头撞在一块埋藏的青石上，崩飞的碎石恰好砸在他身上。</p><p>那些碎石击中的穴位，竟分毫不差地对应着人体奇经八脉的三十六个关键窍穴。</p><p>碎石力道极小，却恰好足以震荡经脉而不伤及肉身。</p><p>老农吃痛之下，脑海中闪过儿时听过的一段歌谣，那是他祖母哄他入睡时唱的催眠曲。</p><p>而那段歌谣的音律，竟暗合上古炼气士的呼吸吐纳之法。</p><p>老农顺着本能调整呼吸，体内那被碎石震荡的经脉自行运转起来，一缕微弱灵气从天地间被吸入体内，沿着早已失传的炼气路径缓缓流转。</p><p>一夜之间，老农踏入炼气期一层。</p><p>其他天赋更好、年纪更小的同村人，也已大多步入十层甚至九层。</p><p>而这，只是无数“巧合”中的一个。</p><p>一个被退婚的少年，心灰意冷之下跳崖自尽，却被崖壁上一株枯藤挂住。</p><p>那枯藤不知生长了多少万年，根须扎进崖壁深处，恰好缠绕着一块上古玉简。少年挣扎时，手指被藤刺划破，鲜血渗入玉简。</p><p>一个被家族抛弃的“陨落之星”，在荒野中迷路，误入一处隐蔽洞府。</p><p>洞府内一枚仙丹本应在三万年前就已失效，却因洞府位置隐蔽、天地灵气恰好在此处形成循环，竟完好保存至今。</p><p>一个散修在集市上买了一块废铁，本打算炼制成飞剑上的座椅。</p><p>回家路上遇雨，雨水顺着“废铁”流下，竟在铁面上冲刷出隐约的字迹。</p><p>一个宗门被灭门，只有一名杂役弟子侥幸逃脱。他逃入深山，饥渴交加，昏倒在溪边。</p><p>醒来时，发现溪水中有几尾银鱼游过。他饿极之下生吞了一尾，顿时体内仿佛有岩浆涌出的炽热……</p><p>一个……一个……一个……</p><p>无穷无尽的巧合，正在整个天墟界每一个角落同时上演。</p><p>每一个巧合单独来看，都概率小到可以忽略不计。</p><p>但无数个小概率事件同时发生，彼此叠加，彼此催化，彼此放大！</p><p>正在以摧枯拉朽之势，重塑整个世界！</p><p>天墟真人睁开眼，面色苍白如纸。</p><p>所有曾经被他扼杀的天才，正在以新的面目重生。</p><p>所有曾经被他埋藏的机缘，正在以各种离奇的方式重见天日。</p><p>所有曾经被他引导向仇恨与战争的势力，正在被无数个微不足道的“和解”悄然化解。</p><p>诸如人族不小心把某个妖怪肚子搞大，妖族不小心泡走了灵族公主，灵族也不小心对可爱的蛟龙下手……</p><p>一个……一个……一个……</p><p>天墟真人的力量确实浩瀚无边，太乙真仙修为力压整个世界。</p><p>但与绝对的“概率操控”相比，却如同试图用鞭毛挡住伽马射线暴的细菌。</p><p>天墟真人看向时间长河对岸那团人形黑雾。</p><p>“汝可知，那繁荣昌盛之世，将积累此界多少新生底蕴？将消耗天地多少灵气在此界无用的众生身上！”</p><p>他正义凛然，沉声质问。</p><p>踏马白花花的银子就这么散给了穷人，你羞不羞耻！</p>
