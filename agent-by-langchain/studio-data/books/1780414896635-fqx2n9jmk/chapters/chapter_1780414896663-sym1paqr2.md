# 域外天魔

<p>萧凡叶深吸一口气，擦去嘴角的血迹。</p><p>他想起九百年前，自己还是个程序员时，写过一行代码：</p><p>// TODO: 等一个奇迹</p><p>那时候他写下这行注释，意思是，“啊我不想干了，以后有空再优化”。</p><p>那段代码的优化太难啃，他只能寄希望于以后的自己，又或者是未来接手自己工作的同行。</p><p>说难听点，就是拖延症嘛。</p><p>但此刻，萧凡叶突然又想起了那行注释。</p><p>奇迹，什么叫做奇迹？</p><p>天墟界灵气复苏，所有修士集体突破？那些陨落的前辈死而复生，重返人间？</p><p>这种极小概率的事情，为什么自己会寄希望它们能发生？但也正因为概率极小，所以才能被称作奇迹吧。</p><p>厚重的魔云如同脓疮般粘附在天幕之上，缓缓蠕动，不时垂下漆黑的触手。</p><p>萧凡叶抬起头，看向裂隙，看向裂隙深处那即将降临的天魔先锋。</p><p>“算了。我等了九百年，也没等到奇迹。”</p><p>他只是根骨、悟性，比其他修道者要好亿点点。</p><p>一步一百个脚印，踏踏实实地修炼。</p><p>可终究没有觉醒什么系统、什么金手指。</p><p>他握紧归乡剑，周身灵气疯狂涌动。</p><p>裂隙猛然裂开！无数遮天蔽日的黑影，轰隆隆地从天而降！</p><p>晴空遍布阴霾，白昼化作黑夜。天魔先锋降临了，漆黑之物张牙舞爪，狂魔乱舞。</p><p>若是凡人或低阶修士，只是远远看一眼，都会当场心智崩溃、理智冲垮。</p><p>来不及细想，萧凡叶身形化作一道流光，迎面冲了上去。</p><p>归乡剑出鞘，剑光如雪！天柱峰之巅，白光与黑暗碰撞，天地为之失色！！</p><p>而在更高的九天之上，一道无人察觉的目光正低头注视着这一切。</p><p>龙佑悬停在万米高空，真空泡包裹全身，光学隐形全开。</p><p>“下面乒乒乓乓，五光十色，声光效果这么好，拍电影吗。”</p><p>【你见过哪家电影特效这么逼真。】</p><p>龙佑低头仔细看了看。</p><p>那团从天而降的漆黑之物，正与一道雪白剑光激烈碰撞。</p><p>每一次碰撞，天地都在颤抖，百里外的山峰都在崩碎。那白色剑光的主人是个白发修士，浑身浴血，却一步不退。</p><p>“好像真不是拍电影。”龙佑收起轻佻，“那个白发老爷爷看起来处于劣势。”</p><p>【他快死了。】</p><p>龙佑呼出一口气，活动一下筋骨。</p><p>“好吧。那我去尊老爱幼，帮助当地人民渡劫了。”</p><p>他撤去隐形，身形一闪，直接出现在战场附近，就在萧凡叶身后三丈处。</p><p>……</p><p>萧凡叶此时正处于生死边缘。</p><p>归乡剑已经斩出三千六百剑。每一剑都用尽他全部灵力修为，炼虚巅峰的全力一击，在那团漆黑之物上留下浅浅的伤痕。</p><p>“还是……不够吗……”</p><p>萧凡叶咬紧牙关，准备斩出最后一剑。</p><p>就在这时——身后三丈处，突然出现了一个人。</p><p>萧凡叶的瞳孔猛然收缩。谁？！</p><p>他的目光与神识同时扫向身后，那是一团漆黑的“人形物体”，一看就是邪恶至极之物！</p><p>归乡剑没有任何迟疑，反手一剑斩出！</p><p>轰——！！！</p><p>萧凡叶心惊，完全感受不到利剑入体的切割感。仿佛自己劈中的是一团空气！</p><p>那黑色人影不知是因为被他劈中，还是因为自行飞离，向后横飞数百里，砸穿了二十几座山峰，最后嵌进一座山脉，激起漫天烟尘。</p><p>‘那到底是什么？’</p><p>但萧凡叶已来不及细想，周围的天魔再度一拥而上。</p><p>……</p><p>数百里外，碎石堆中。</p><p>龙佑躺在废墟里，胸口那道剑痕还在往外冒血，整个胸腔几乎被劈成两半，能看到里面跳动的心脏上，都有一道浅浅的剑痕。</p><p>【你还好吗？】</p><p>“你看我像像好的样子吗？”</p><p>【像。你低头看看。】</p><p>胸口的剑痕，正在以肉眼可见的速度愈合。肌肉蠕动，骨骼重生，血管重连，深可见骨的伤口几个呼吸间就缩小了一圈。</p><p>【“不灭”体质果然厉害，任何伤势都会超速恢复。】</p><p>龙佑又吐了一口血——这次是淤血。</p><p>“好像是这么回事……话说那个白毛应该是看错人了。”</p><p>【确实都怪你，不声不响出现在别人身后，然后问了一句‘为什么打架，是立场不同吗’这么招人恨的话。】</p><p>龙佑从碎石堆里坐起来，活动了一下肩膀。胸口的伤口只剩一道浅浅的红痕，几息后连红痕都消失了。</p><p>他站起身，拍了拍身上的灰。</p><p>“行吧，那现在回去找他说清楚。”</p><p>但话音未落，他停住脚步——身后三丈处，无声无息地浮现出一团漆黑。</p><p>那东西像是从虚空中渗出来的，没有固定的形态，像一团蠕动的沥青，表面不断鼓起又破灭的水泡，每个水泡裂开时都会露出一只猩红的眼睛。</p><p>龙佑只是回头看了一眼——仅仅一眼。</p><p>【你闭眼别看好吗！再看一眼，你的潜意识就要爆炸了。】</p><p>“我去，不早说！”</p><p>他感觉自己被全险半挂创飞了灵魂。</p><p>无数疯狂的呓语在脑海中炸开，扭曲的画面疯狂闪烁。无数尸骸堆积成的山峦，正在自我吞噬的巨兽，倒悬在血海中的城市，以及城市中央的湖面——</p><p>祂正在笑。</p><p>龙佑的瞳孔充血，但伤势又很快恢复。</p><p>【啧，忘了这茬。精神攻击。】</p><p>【不过你现在有了不灭，俺寻思，应该包括了物理和精神双层不灭吧？】</p><p>“你说得对，很有道理。”</p><p>【但还是做二手准备吧，“不死”和“不会疼”是两个概念。】</p><p>【你看向不可名状之物时，会自动加载认知滤网：100%！】</p><p>扭曲的画面像被橡皮擦抹得干干净净，疯狂的呓语瞬间消失，一切不干净的声音统统被替换成《国际歌》，认知滤网强大如斯。</p><p>龙佑额头冷汗涔涔，自己刚才竟然差点就HP-1了。</p><p>“话说这是什么东西？”</p><p>【就是刚才那白毛老头子在攻击的怪物。这一只，好像盯上你了。】</p><p>龙佑抬头看向那团漆黑。</p><p>那东西正在缓慢变形，无数触手从主体中延伸出来，每条触手的末端都睁开一只眼睛。</p><p>那些眼睛齐刷刷地盯着龙佑，眼神里没有任何情绪，只有要将一切吞噬的饥饿。</p><p>“行。既然你追过来，那就先拿你试试手。”</p><p>他握紧右拳。</p><p>龙佑脚下被踩出一个直径千米的巨坑，冲击波呈环形扩散，将周围的碎石炸成齑粉。</p><p>而他本人已经出现在那团漆黑的正上方，右拳蓄满了自觉醒以来从未动用过的全力！</p><p>“One…punch!! ”</p>
