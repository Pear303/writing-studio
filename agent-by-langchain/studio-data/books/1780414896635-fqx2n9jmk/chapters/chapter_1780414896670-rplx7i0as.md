# 萧人皇？不对——该叫你萧废人了！

<p>那灰袍老者浑身颤抖：“你……你勾连北方妖族、南方蛮族、东方蛟族、西方灵族，共犯我中原大地三十三州？！”</p><p>贺卢思仰天长笑：“正是！那萧凡叶成了残废，已坐不稳天下了！今日之后，中原易主，本尊便是新的人皇！”</p><p>他身后，一头蛟龙口吐人言，声音阴冷：“阳宗主，别忘了你的承诺——事成之后，中原五成疆域归我等四族。”</p><p>贺卢思笑容微僵，随即点头：“自然，自然。”</p><p>下方，那些重伤的化神期掌门挣扎着站起身，怒视苍穹。</p><p>“妖孽！” “叛徒！”</p><p>“我等便是拼了这条老命，也决不让你得逞！”</p><p>一名中年年轻老妇踉跄着站起，正是那日献灵芝之人——清虚门掌门，化神中期。她抹去嘴角血迹，厉声道：“诸位同道，随我诛杀此獠！”</p><p>话音未落，她率先冲天而起，剑光如虹！</p><p>其余几位化神期掌门紧随其后，各展神通——有祭出本命法宝者，有掐诀施展大神通者，有燃烧精血强行提升修为者。</p><p>五色神光冲天，齐齐杀向贺卢思！</p><p>贺卢思冷哼一声：“螳臂当车，不自量力！”</p><p>他抬手虚按，一只遮天大手印凭空凝聚，携毁天灭地之威狠狠拍下！</p><p>轰！！！五道身影齐齐倒飞而回，砸落地面，溅起漫天烟尘。</p><p>那中年美妇胸口塌陷，气若游丝；灰袍老者右臂齐根断裂，面如金纸。其余三人更是直接昏死过去，不知生死。</p><p>贺卢思收回手，轻描淡写地拂了拂衣袖：“一群蝼蚁，也敢在本尊面前放肆。”</p><p>他俯视着下方那些重伤垂死的化神期掌门，又看向远处那些瑟瑟发抖的低阶修士，眼中满是轻蔑。</p><p>“还有谁？”</p><p>四野死寂。那些从四面八方赶来的修道者，此刻噤若寒蝉，无一人敢出声。</p><p>贺卢思满意地点点头，正要开口。</p><p>“还有我。”</p><p>贺卢思笑容一僵，猛地低头看去。巨坑边缘是一个乌黑长发，年轻面孔，归乡剑插在身侧。</p><p>萧凡叶。</p><p>贺卢思瞳孔骤缩，随即恢复镇定，冷笑道：“萧人皇？不对——该叫你萧废人了。怎么，修为尽失，还想强出头？”</p><p>萧凡叶抬起手，握住了归乡剑的剑柄。</p><p>那一刻，天地色变。</p><p>一股浩瀚如渊海的威压轰然爆发！</p><p>那威压之强，直接将周围百里内的地面压得塌陷三尺，将远处那些低阶修士压得跪伏在地，将天空中那些四方异族压得面色剧变！</p><p>贺卢思的笑容僵在脸上。</p><p>他感受到那股威压，那不是炼虚，更不是化神，而是……</p><p>“合、合体？！”他声音发颤，难以置信地瞪大双眼！</p><p>萧凡叶缓缓抽出归乡剑，剑身嗡鸣，剑气冲霄。</p><p>“你方才说，本座修为尽失？</p><p>“那你便来试试！我说过我还可以激发出几次甚至几十次乃至几百次连续巅峰的战力！</p><p>“如此关键的信息，你居然把它忽略！”</p><p>贺卢思脸色煞白，身形暴退！</p><p>但已经晚了。</p><p>萧凡叶一步迈出，身形消失在原地。</p><p>下一瞬，他已出现在贺卢思面前，归乡剑平平斩出——</p><p>虚空都在颤抖！法则都在哀鸣！</p><p>贺卢思亡魂大冒，拼命运转全身灵力，祭出本命法宝抵挡。然而剑光过处，本命法宝断成两截，根本抵挡不住分毫。</p><p>叛军之首贺卢思胸口炸开一道深可见骨的剑痕，鲜血狂喷，整个人倒飞出数十里，砸穿了三十三座山峰。</p><p>他最后嵌在一处山崖上，身死道消。</p><p>在可预见的未来，这座山崖将作为景点收门票参观，可能会起名叫安卢山什么的。</p><p>萧凡叶并未收剑。</p><p>他抬眼望向天际——那四方异族联军并未因贺卢思的死而退去。</p><p>北方妖族、南方蛮族、东方蛟族、西方灵族，四族大军铺天盖地，已然杀红了眼。</p><p>“杀——！”</p><p>“踏平中原！夺其疆域！掠其资源！”</p><p>喊杀声震天，无数身影如蝗虫过境，从四面八方向中原腹地涌来。</p><p>萧凡叶深吸一口气，握紧归乡剑。</p><p>下一瞬，他的身影消失在原地。</p><p>剑光如雪，斩入敌阵。</p><p>第一剑，妖兵身首异处，第二剑，蛮族战士拦腰折断，第三剑，蛟龙龙首落地！</p><p>第四剑、第五剑、第十剑、第一百剑……一人一剑，在百万联军中纵横穿梭。</p><p>妖兵蛮将的惨叫声、怒吼声、求饶声，混成一片，响彻云霄！哀鸿遍野，血流成河！但这样的声音对于人族来说，格外愉悦呀嘻嘻嘻！！</p><p>不过一炷香工夫，四方异族联军已然七零八落，十去其八。</p><p>剩下那些终于从疯狂中清醒过来，惊恐地丢盔弃甲，四散奔逃。</p><p>萧凡叶收剑而立，周身浴血，皆是敌血。</p><p>他低头看着脚下堆积如山的尸骸，眉头微皱，正要开口。</p><p>“报——！！！”</p><p>一道凄厉的喊声从远处传来。一个元婴期长老御剑疾飞，浑身浴血，右臂齐根断去，残缺的身躯在空中摇摇欲坠。</p><p>他跌跌撞撞落在萧凡叶面前，扑通跪地，声音嘶哑：</p><p>“人皇！大事不好！又有新的来敌！”</p><p>那长老颤抖着指向东南方向，“是……是那些修魔者的残党！他们不知从何处冒了出来，为首的是个合体期大魔头！那魔头手持一幡旗，那幡上冒着黑气，是……是炼魂幡！”</p><p>“炼魂幡”三字一出，在场众人齐齐色变。</p><p>炼魂幡，上古魔道至宝，以生灵魂魄祭炼，每吞噬一道魂魄，幡威便强上一分。传说上古时期曾有魔道巨擘以此幡屠灭三州，最终被天墟界正道联手围杀，炼魂幡也随之失传。</p><p>如今，竟又现世？</p><p>那长老继续道：“那魔头……那魔头将方才战死的异族魂魄尽数纳入幡中！他说、他说……”</p><p>“他说什么？”</p><p>“他说，‘听说那该死的萧人皇终于陨落了，如今终于轮到我魔修崛起！’”</p><p>萧凡叶面色不变，只是握紧了归乡剑。</p><p>幸好搞了“假死”这种智斗巅峰情节，将许多各怀心思的牛鬼蛇神给牵扯了出来，不错。</p><p>但这也太吉儿急了吧！一听人皇变成陨落的废柴，就匆匆忙忙跳出来！</p><p>多观察三五个月都坐不定吗？</p>
