# 地球爆炸！（二）

<p>伽马射线暴轰在龙佑的仙元护盾上，刺目的白光炸开，照亮整片虚空！</p><p>那光芒太盛，以至于太阳在它面前都黯然失色，仿佛宇宙中只剩下这只手掌和这道光。</p><p>超新星爆发，两轴的伽马射线喷流半张角是有波动范围的。</p><p>但即使是目前人类文明观测到最窄的喷流半张角，经过40亿光年的圆锥形膨胀，伽马射线暴射流的覆盖范围，也能达到约3光年直径！</p><p>所以要护太阳系周全，必须将自己膨胀到足够大面积。</p><p>“直径10天文单位的仙力护盾！”</p><p>龙佑是这面护盾的中心，反而是最薄弱的点位。</p><p>根据毛球定理，在二维球面上，任何连续的流动模式都至少会存在一个静止点，即速度为零的点。</p><p>打个比方，就是咖啡在搅拌时中心总会有一个静止的漩涡眼。</p><p>部分伽马射线暴透过这个“漩涡眼”，轰向龙佑本体，他掌心在燃烧。</p><p>太乙真仙的法体，在这道射流面前像被烈焰舔舐的纸张。但那些被焚毁的血肉在下一瞬重新生长，新生的肌纤维比之前更致密，新生的皮肤上仙纹流转。</p><p>【太乙仙体在本宇宙力量被压制，但挡个伽马射线暴还是轻轻松松。】</p><p>双手合拢，将那根致命的细针攥在掌心。射流从指缝间漏出几缕，擦着他的手背轰向更远的虚空。</p><p>光芒渐渐黯淡。</p><p>射流持续了整整三十秒，然后戛然而止。</p><p>蓝超巨星已经耗尽它最后的遗产，化作宇宙中一团稀薄的星云。</p><p>龙佑缩小身形，恢复常态，在虚空中站了一会儿。</p><p>他抬手想整一整被烧坏的袖口，手指碰到焦布，布边就碎了，化成灰飘进真空里。</p><p>‘算了，去趟海X之家吧，蓝人的衣柜。’</p><p>‘呼，今天也拯救了地球，真是有意义的一天呐。’</p><p>乾坤大挪移！回到地球，并在某地球神州某随机公厕里穿梭出来。</p><p>……</p><p>天台上，龙佑衣炔翩翩。</p><p>他的衣服已经重新长出来。</p><p>量子真空并不为真的“空”，每时每刻都有无穷无尽的虚粒子对从中生灭，只要赋予其足够能量，便能让粒子脱实向虚。</p><p>只要运气足够好，就能在恰到好处的位置，量子涨落出一件涤纶材质的短袖。</p><p>这件衣服，就是在量子真空的概率涨落中，「随机」涨落出来的。</p><p>省去他到海X之家花钱。</p><p>【地球爆炸的概率，再看一眼？】</p><p>【地球，在一年内爆炸：98.95%】</p><p>【一个月内爆炸：99.43%】</p><p>【一日内爆炸：99.11%】</p><p>【树欲静而风不止，这地球怎么老想着爆炸？】</p><p>“只能再跑一趟了。”他叹了口气，身形消失在原地。</p><p>这次导致地球爆炸的罪魁祸首，貌似是某高等文明的危险实验。</p><p>银河系，猎户臂，距离地球约八千光年的一片虚空。</p><p>龙佑悬浮在这片虚空中央，看着眼前那个东西。</p><p>那东西不大，大概只有月球大小。表面光滑如镜，反射着远处恒星的冷光。它悬浮在那里，安静得像一颗普通的星际石块——如果忽略它正在做的事情的话。</p><p>它在压缩引力波！</p><p>引力波这种东西，本质是时空的涟漪。</p><p>即使是宇宙中最极端的天气——黑洞，双双合并时激起的涟漪，长也不过以千公里计数。</p><p>但眼前这个文明的思路截然相反，他们试图将引力波的波长，压缩到微米级别！</p><p>众所周知，波长越短，能量越高。</p><p>一根头发丝的直径是七十微米。将黑洞碰撞产生的涟漪，压缩进一根头发丝十分之一的尺度里！</p><p>龙佑盯着那东西，估算它蓄积的能量。</p><p>【嗯……总之能炸掉猎户臂是没得跑了。】</p><p>【这是个卡尔达肖夫指数3.0+级文明！】</p><p>虚空震颤。</p><p>银白舰队从四面八方跳出曲速泡，密密麻麻铺满视野。每艘舰船都有狂野亚洲的大小，将龙佑围在中心！</p><p>舰队中，战术频道的信息流如暴雨倾泻。</p><p>“目标识别异常。无常规能量护盾反应，无推进引擎特征，生命体征读数处于不可解析区间。”</p><p>“能量谱分析失败。该个体能量存在形式不在现有物理模型数据库内。”</p><p>“检索古代文献记录。第三纪元，猎户旋臂外侧，第一接触档案第91号。”</p><p>“难道是仙道同盟……的‘个体伟力者’？”</p><p>“确认是‘个体伟力者’，能以肉身横渡星海，不依赖机械造物，并以意识驾驭基本力……”</p><p>“目标正在观测我们的引力激波阵列。”</p><p>战术官声音压得很低，“推测其目的与‘终极大一统对撞机项目’核心参数有关。是否存在接触冲突风险？”</p><p>“不要与对方起冲突，先发送翻译字典。”</p><p>……</p><p>龙佑寻思异世界都讲普通话，但这个地方的高等文明居然不说普通话，真是不讲道理啊，真搞不清楚谁才是乡毋宁了。</p><p>“潜龙，你说咱该怎么交流？”</p><p>【我突然之间灵光一闪，掌握他们的语言体系：100%】</p><p>【现在你可以用普通话与对方对话了。】</p><p>精通对方语言的同时，也无可避免地获取对方一些常识。</p><p>就像精通了普通话，自然也就明白了老树盘根、观音坐连、佛手拈花、罗汉揽月、霸王推车这些成语是何意味。</p><p>眼前这文明自称“太微无极汰那裂空座”，天知道他们起这个狗屎名字是图什么。</p><p>龙佑就把对方简称为“太微文明”了。</p><p>……</p><p>语言字典包发出已经20秒。</p><p>按照卡尔达肖夫3.0级文明的基准，即便是最简单的语言体系，破译所需平均时耗也以小时计！</p><p>原因无他，就如茴香豆的茴字尚且有四种写法。</p><p>而能够达到3.0+级的文明，语言中早已进化出了更多、更极端复杂、更极端抽象的概念。</p><p>想要将其一一翻译，就需要另一个文明的计算系统和专家团队浸淫多年。</p><p>时间以毫秒流逝。</p><p>此刻距离字典发出，刚过21秒。</p><p>一道反向信息流刺破阵列幽蓝光晕，直抵舰桥！</p><p>太微文明舰队的指挥官，骤然收紧。</p><p>“破译完成？！耗时21秒！？”</p><p>“解析速度，超越我们母星的全量子集群算力池……”</p><p>“这个个体伟力者是怎么回事？他能在拥有超级力量的同时拥有超级智慧！？”</p><p>太微文明指挥官注视着投影上的文字，编码严格遵循罗塞塔协议语法树。</p><p>“我名龙佑。你们是何文明？”</p><p>第三道信息流接踵而至。</p><p>“你们实验的失控概率很高喔，不出半刻，此地将归于虚无，顺便炸毁半个猎户臂。”</p><p>指挥官盯着那行字，那行文字道出了他们内部争论了三个星纪的核心隐患。</p><p>但他们首席科学家“保证”爆炸的概率不到90%，是一起非常具有性价比的实验。</p>
