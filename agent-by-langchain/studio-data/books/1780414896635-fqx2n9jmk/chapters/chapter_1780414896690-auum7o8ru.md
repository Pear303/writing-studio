# 苍天婆婆

<p>姜笙被龙佑先生的力量拉扯到某个地方。</p><p>那种感觉无法形容，像是被人从三维世界猛然拎起，投掷进某个无法言喻的维度！</p><p>通俗点的比喻，就像是一只小鸡崽被直立猿从鸡笼里提溜出来，毫无抵抗之力！</p><p>视野在拉升，无限拉升！</p><p>脚下，是汹涌的光阴长河！无数条世界线如同晶莹的丝线，向四面八方无限延伸，分裂、分叉、交织、重组！</p><p>时间长河之上，龙佑先生身影悬空而立，那团笼罩他的黑雾已散去，露出那张普通得不能再普通的年轻面孔。</p><p>“原来天道真是个‘婆婆’？”龙佑看着对面那逐渐凝实的身影，有些意外。</p><p>在‘天墟界’那一个月，龙佑可不只是在遛鸟逗狗。</p><p>他有一回去了个上古遗迹，那地方藏在苍莽山脉深处，被层层禁制包裹，化神以下进去就是个死。龙佑溜达进去，在里面翻出过几块玉简和几本古籍。</p><p>玉简里记载的是上古修士对“天道”的理解。那些文字晦涩艰深，大意是说——天道非人非物，非神非圣，乃是万物运行之总纲，因果循环的根源之涡。</p><p>修道者修一生，求的便是与天道合一。</p><p>但真正触及那一层才会明白，天道不可求，不可得，不可言，不可说！</p><p>它发生出一切，悬置在一切之上。</p><p>它观察着一切，也将是一切的终末。</p><p>修士修到极致，可与天道共鸣，却不能掌控天道，因为“天道”本身就是此世一切！</p><p>龙佑认为这听起来挺玄乎。但既然人都能修仙了，那再玄乎的事其实也没那么奇怪了。</p><p>他看下自己刚刚“请来”的苍天婆婆。</p><p>【别说人家是婆婆，明明这么漂亮。】</p><p>“但无论是称呼‘苍天姐姐’还是‘苍天妹妹’，都显得有些轻佻了。”</p><p>龙佑打量，那确实是个极美的女子形象，周身笼罩在辉光，看不清具体容。</p><p>“存在本身”就足以让人明白何为完美。</p><p>“不过，祂看起来好眼熟。”龙佑皱眉，“是不是像我认识的人？”</p><p>【你脸盲症也不是一天两天了，连哈利波特和伏地魔这俩，你特么看到最后一部都没认出来有啥不同。】</p><p>【明明只要记住鼻子这个特征就好！你本来就是靠鼻子区分成龙和洪金宝的……】</p><p>‘但龙叔鼻子确实大。’</p><p>苍天婆婆缓缓睁开眼。</p><p>那双眼睛中，倒映着无穷世界线，倒映着汹涌光阴长河，倒映着时间长河上的身影。</p><p>“唤吾何事？”</p><p>龙佑看着那张脸，虽然说自己有脸盲症，但真的是越看越眼熟。</p><p>到底像谁来着？</p><p>……</p><p>姜笙现在有些慌张。</p><p>按理说大方无隅，大器晚成，大音希声，大象无形，道隐无名……凡所有相，皆是虚妄；若见诸相非相，即见如来……太初有道，道与神同在，道就是神……</p><p>天道，本无形无相。</p><p>不过她“天人合一”，有能力凝出人形，甚至有能力化作“姜笙”的模样。</p><p>可姜笙此时此刻，偏偏做不到！</p><p>就像……就像龙佑亲口勒令，要见的是“天道”，而不是“姜笙”！</p><p>不，并不仅仅只是勒令“天道”出面……</p><p>而是勒令一个“女性化的天道”出面……譬如说天道姐姐、天道婆婆、天道仙子……</p><p>一个勒令，强行赋予天道“碳基性别”，这是何等的伟力？！</p><p>这是何等的恐怖！！</p><p>她原本打算很谦卑的，开口说些卑微的话。</p><p>却不料张嘴就是“唤吾何事”，看来是天人合一中「天」的那部分在作怪。</p><p>……</p><p>龙佑看着眼前这尊凝实的苍天身影，越看越觉得眼熟，最后想起来是不是像刘亦菲？</p><p>【你这么一说，确实。不过，我不信任你的脸盲症。】</p><p>他索性不想了，指着战场上一左一右：“苍天婆婆，请问他们为什么打架？”</p><p>天道：“立场不同。”</p><p>龙佑：“不是姐们？”</p><p>天道：战舰的一方叫“天启协约”，而修仙的那一面则自称“仙道同盟”。</p><p>双方都屹立于宇宙的顶点。</p><p>而原本还在酣战中的他们，也当然同时觉察到——时间停止了！</p><p>无数艘战舰停止了开火，三个太乙真仙也停下了手中的动作。</p><p>所有人，所有存在，看向龙佑和苍天婆婆。</p><p>二人凭空出现在战场中央，顺带还来个大范围的时间暂停，怎么看怎么可疑。</p><p>龙佑站在最前面，周身没有气息外露。</p><p>苍天婆婆站在他身后半步，周身笼罩在淡淡辉光中，看不清容貌，却让人忍不住想要跪伏。</p><p>良久，那少年模样的太乙真仙开口：“敢问二位前辈，来自何方星域？”</p><p>龙佑黑着脸：“你们打架我管不着。但你们战斗余波差点害苦了我的家乡。”</p><p>那少年模样的太乙真仙，下意识地想要探查眼前这个“黑着脸”的前辈的底细——</p><p>修为几何？道行多深？来自何方星域？</p><p>会不会是某个科技文明，做了惨绝人寰的实验，制造出来的科学决战兵器？</p><p>但神识探出，却如同泥牛入海，消失得无影无踪！</p><p>没有任何反馈。这个不明来者，是各种意义上的“黑着脸”！</p><p>不，不对。不是“没有反馈”，而是“被选择性屏蔽了”！！</p><p>他能感知到对方的外貌、声音、动作，感知到那些最浅显、最表面的信息。</p><p>但除此之外，任何更深层次的探查，都被一股无形的力量完全隔绝！！</p><p>修为？感知不到。境界？感知不到。灵力波动？感知不到！</p><p>甚至连对方的“存在感”，都若有若无。</p><p>仿佛眼前这个年轻人只是一个全息投影，而非真实存在的生命。</p><p>少年太乙真仙的瞳孔微微收缩。</p><p>他修炼三百万年，见过无数强者，却从未遇到过这种情况。</p><p>已经不是“隐藏修为”的层面了……将自己变成一个“有智慧的绝对黑体”，只向外辐射自己愿意辐射的信息。</p><p>他身后的老者和女子也察觉到了异常，面色微变。</p><p>而另一边，天启协约的战舰群同样陷入了沉默。</p><p>无数种探测手段，引力波扫描、时空探测、时间线追溯……全部失效。</p><p>那个年轻人就站在那里，却仿佛不存在于任何物理背景之中。</p><p>他能被看见，能被听见，能被感知到“他在那里”。</p><p>但除此之外，一无所获。</p><p>一时让他们以为仙道同盟，是不是又靠惨绝人寰的灵能实验，制造出的玄幻决战兵器？</p><p>【并非基于我主观想要暴露的信息，就无法被探测：100%】</p>
