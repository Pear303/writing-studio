# 改革不能太激进嘛

<p>全宇宙的时间，恢复流动。</p><p>街头的大爷继续遛狗，高架桥上的车流继续飞驰，夜风继续吹拂，月光继续洒落。</p><p>稷海市，城中村。</p><p>龙佑蹲在巷子口，手里端着一碗刚出锅的炒河粉，吃得正香。旁边是几棵歪脖子树，树下是几个下棋的老头，不远处是来来往往的行人和电动车。人间烟火，不过如此。</p><p>【现在你已无人能敌，这回的玩起大佬都市隐居的剧本了？】</p><p>龙佑嚼着河粉，含糊地“嗯”了一声。</p><p>【现在，外部的‘灾难’已经交由天道处理。世界碰撞、穿越者泛滥、宇宙大战波及——这些都有‘苍天婆婆’盯着。】</p><p>【但人类社会内部的问题，还得靠自己解决。】</p><p>龙佑咽下嘴里的河粉，用筷子戳了戳碗底。</p><p>“确实。”</p><p>他抬头看向远处那些高楼大厦，看向那些行色匆匆的路人，看向那些为了几毛钱跟小贩讨价还价的大爷大妈。</p><p>“不过，在天墟界的社会学实验大获成功，你看到了。”</p><p>【一个月前，你一句“繁荣昌盛之世”，天墟界未来便100%注定走向遍地开花。】</p><p>【凡人皆可炼气，天才层出不穷，各族和睦共处，人人都有奔头。】</p><p>【效果拔群。】</p><p>“对，我还通过巨量的社会学实验，深刻研究了各种‘概率’的变化，对世界走向的最终影响与干涉。”</p><p>龙佑点点头，又扒了一口河粉。</p><p>【所以，你想怎么做？】</p><p>【将异界试点的成功经验，推广到地球？】</p><p>龙佑又双扒了一口河粉。</p><p>“地球和天墟界不一样，天墟界的阶级固化体现在人与人之间力量差距的天堑，但地球则是软性事物的差距。</p><p>“比如财富，权力，地位，知识，智慧，品性，志向……</p><p>“卷高考，卷考研，卷考公，卷大厂，卷副业，都是为了改变‘软性属性’的差距。</p><p>“但在武力本质上，匹夫一怒亦能令天子血溅五步，改革成功经验，不能如此生搬硬套。”</p><p>【所以你想怎么做？】</p><p>【像天墟界那样，给每个人发“灵气”？】</p><p>龙佑又双叒扒了一口河粉。</p><p>“那不行。地球本来没有灵气，硬塞进去会乱套……你这点子也太不靠谱了。”</p><p>【确实嗷。】</p><p>【龙佑，你随时能让地球进入“太阳朋克”的近未来共产黄金时代，一步到位。】</p><p>【但毕竟地球和天墟界不一样，在天墟界想要磨平人与人的差距，只需每个人发灵气，发灵根，之后的各凭本事。】</p><p>【可在地球，不是单纯的发物质资源就能解决问题。】</p><p>【你需要对人类几千年来建造起的、不尽完美的、但勉强能跑得动的“屎山”动刀。】</p><p>【万一有什么隐藏bug呢？】</p><p>【就像六边形战士，被发现了第7个弱点；成为七边形战士后，又被发现了8个弱点……】</p><p>【根据「N+1边形」定理，一旦你开始修复bug，bug就会无穷无尽。】</p><p>龙佑又双叒叕扒了一口河粉。</p><p>“所以我打算循序渐进。正如一本奇妙的小说所言，‘改革不能太过激进’，一开头先来点温和的变革吧。”</p><p>龙佑笑了笑，意念微动。</p><p>时间长河在他眼前展开，无数条世界线如同繁复的丝网。</p><p>【地球人类文明犯罪率、贫困率、各类腐败发生概率：0%】</p><p>【每个人类个体都拥有社会主流所认可的基本公德心：100%】</p><p>【文明崩溃、扭曲、灭绝：0%】</p><p>话音落下，世界线轻轻震颤了一瞬，然后恢复平静。</p><p>一切都和刚才一样。</p><p>但一切都不一样了。</p><p>……</p><p>萧凡叶归乡后第二个星期，稷海市公安局，刑侦大队。</p><p>张队长端着保温杯走进办公室，打开电脑，查看过去一周的接警记录。</p><p>屏幕上显示的数据让他愣住了。</p><p>“不可能吧？”</p><p>“怎么可能呢，肯定是我打开方式不对……”</p><p>他揉了揉眼睛，刷新了一遍，还是那个数。</p><p>“小王！”他喊来下属，“上个星期怎么回事？报警数量怎么只有平时的五分之一？”</p><p>小王凑过来看了一眼屏幕，也是一脸茫然：“我、我也不知道啊张队。我刚查了全市的接警系统，上星期……上星期报警总数只有平时的两成左右。”</p><p>稷海市，1000万人口的大城市，报警量断崖式下跌。</p><p>连偷电瓶车的都少了十成。</p><p>“是不是系统坏了？”</p><p>“我查过了，系统正常。110那边也说，数据没问题，确实电话少了很多。”</p><p>张队长沉默。他干了三十年警察，从没见过这种事。</p><p>“我们上星期好像都很忙，究竟在忙什么？”</p><p>小王挠了挠头，回忆道：“帮老奶奶找猫，维持漫展秩序，以及呃……负责押送了一百多个主动投案自首的刑犯？”</p><p>……</p><p>市中心某高档写字楼。</p><p>一个西装革履的中年男人坐在办公室里，对着电脑发呆。</p><p>他是某部门的处长，昨晚刚收到笔“孝敬”，共计五十万，存在五百张不记名的购物卡里。</p><p>但今天早上醒来，他忽然觉得这笔钱烫手。</p><p>不，不是忽然觉得。是从灵魂深处涌出一股强烈的厌恶——厌恶这种不劳而获，反感这种见不得光，憎怒自己曾经习以为常的一切，恨极了可恨的自己！</p><p>他拿起手机，拨通了那个下属的电话。我不要了。</p><p>电话那头沉默了两秒，然后传来一个同样如释重负的声音：处长，我正想跟您说这事呢。</p><p>……</p><p>城中村，龙佑楼下。</p><p>包租婆依旧坐在小板凳上看短剧，但今天她看的是法治进行时。</p><p>“这个月收的房租……”她自言自语，“好像有点高？要不给租客们降点？反正我也不差那几百块。”</p><p>她拿起手机，开始给每个租客发微信：</p><p>「下个月开始房租减三百。」</p><p>发完，她忽然觉得浑身舒畅，比看一百集短剧都舒服，减完还想继续往下减。</p><p>真希望减完房租，自己看短剧的时候，能不会再莫名其妙网络卡顿了！</p>
