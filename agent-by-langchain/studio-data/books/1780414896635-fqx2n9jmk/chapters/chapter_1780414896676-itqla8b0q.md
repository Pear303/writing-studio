# 老登晚年欠一屁股债被天道收尸

<p>天墟界，天柱峰。</p><p>萧凡叶正盘膝调息。</p><p>归乡剑横在膝上，剑身微微震颤。周围那些化神期掌门或坐或卧，都在疗伤。</p><p>忽然，天穹裂开！</p><p>一道白光砸落，云层崩碎，罡风倒卷！</p><p>所有人都被惊起，萧凡叶睁眼，握剑暴起！</p><p>白光散去。</p><p>龙佑站在坑底，脚下踩出一个直径十丈的新鲜陨石坑。他右手掐着半截老头，左手把玩一口巴掌大的铜炉，黑发飞扬，衣袂猎猎。</p><p>萧凡叶瞳孔骤缩。</p><p>他认出了龙佑，也认出了龙佑手里提着的那半截身子——</p><p>天墟真人！</p><p>那位十二万年布局、执掌太乙果位、以混元炼道炉炼化万物的太乙真仙！</p><p>此刻像根烂木头，软塌塌地被龙佑掐着，脑袋耷拉，四肢垂落，鲜血顺着龙佑的指缝滴答滴答往下淌。</p><p>“龙佑阁下……这……”</p><p>“新鲜的太乙真仙，交给你了，我留着个老登也没用，他又没有漂亮的白菜给我拱……”</p><p>【你这话也太糙了。】</p><p>龙佑把天墟真人往地上一扔。</p><p>半截身子砸进碎石堆，溅起灰土。天墟真人发出闷哼，气息萎靡到极点，太乙仙力涣散，连自愈都做不到了。</p><p>他连眨眼都做不到了，虽然思想还在运转，意识还在挣扎，但身体、灵力、太乙果位——全都被无可抗拒的力量定在原地！</p><p>事已至此，只剩最后的绝招……</p><p>“唏，可以和解吗？”</p><p>天墟真人低声下气地问。</p><p>昔日高高在上的太乙真仙，此刻如条摇尾乞怜的老狗，这谁看了都会一阵唏嘘，两阵嘘嘘。</p><p>龙佑气笑了。</p><p>“你莫不是在说笑！”他一巴掌扇过去。</p><p>啪！天墟真人身上的气息如同泄气的皮球，疯狂暴跌——</p><p>太乙真仙，跌落！</p><p>渡劫，跌落！合体，跌落！……</p><p>最终气息萎靡至炼气期绝巅大能的水准！</p><p>“行了。”龙佑收回手，像扔垃圾一样把天墟真人丢给萧凡叶，“萧凡叶，你来处置吧。”</p><p>萧凡叶伸手接住那团砸过来的身影，低头看去。</p><p>天墟真人瘫软在他脚边，浑身止不住颤抖。那张仙风道骨的面孔上，满是惊恐与不甘。</p><p>“你……你们……”</p><p>天墟真人挣扎着想说什么，却忽然顿住。</p><p>他低下头，看向自己的双手。</p><p>那双手，正在以肉眼可见的速度干枯、褶皱、老化。原本晶莹如玉的皮肤，此刻如同枯树皮般皲裂！</p><p>饱满丰盈的血肉，此刻正一寸寸塌陷！</p><p>浩瀚如海的灵力，此刻正疯狂外泄，消散于天地之间！</p><p>“这……这是……”</p><p>他惊恐地摸向自己的脸。触手所及，是沟壑纵横的皱纹，松弛下垂的皮肉，脱落的须发。</p><p>凡尘生灵的末路——天人五衰！</p><p>天墟真人瞳孔剧震，猛地抬头看向萧凡叶：“你、你收了神通！老夫认栽！老夫愿为奴为仆啊！饶命！”</p><p>萧凡叶低头看着他，眉头微皱：“不是我。”</p><p>“应该是你的太乙果位被夺，天地便要收回你夺去的因果造化、气运寿元。”</p><p>类似于创业失败，欠一屁股债，银行便要法拍老赖的房子，清仓大甩卖，以资抵债。</p><p>先前享受太乙真仙修为，续了十几万年的命啊，现在境界跌落，寿元便倒欠一笔了。</p><p>萧凡叶看着这个正在急速老化的太乙真仙，眼中没有怜悯：</p><p>“你活了十三万年，其中有多少是借来的、抢来的、偷来的，你自己清楚。如今果位不存，天地自然要连本带利地收回去。”</p><p>天墟真人面色惨白：“不是十三万，而是十二万九千六百……”</p><p>“闭嘴！别特么惦记你的十二万九千六百年了！！”</p><p>“……”</p><p>天墟真人低头，看着自己那双已经干枯如柴的手，感受体内灵力如决堤之水般疯狂流逝，感受着寿元从指缝间飞速消散。</p><p>他狰狞而悲恸地惨笑！</p><p>“哈哈哈哈哈哈哈哈哈哈！！</p><p>“你以为……老夫将这一界炼成一炉丹，很容易吗？！</p><p>“反正这世界已经污了，留着这帮蝼蚁历经生死劫轮的永恒循环，不如由我将此界彻底炼化……炼化整个世界我容易吗……”</p><p>类似于毒贩说“我贩毒走私和杀人，不都是为了养家糊口吗？我有什么错！都是这个社会和世界的错！”</p><p>天墟真人声音中满是疯狂与怨毒，似乎还要说什么，但已经来不及了。</p><p>他的身体如同风化的岩石，从指尖开始，一寸寸化作飞灰。那些灰烬飘散在空中，被风吹走，再无痕迹。</p><p>正如龙佑以渡劫期修为，在世界线视野中所预见的情景一样。</p><p>“你们……什么都不知道……”这是他留在世间的最后一句话。</p><p>有些可憎的人，死前都要谜语。</p><p>然后，形神俱灭。</p><p>萧凡叶静静地看着那团飘散的飞灰，他不知道天墟真人最后想说什么。</p><p>但他隐隐觉得，那句没说完的话背后，藏着某种更深层更可怕的真相。</p><p>他转身看向龙佑。龙佑前辈仍然平静，确实是世外高人的形象。</p><p>然后，萧凡叶愣住了。</p><p>不只是他愣住。整个天墟界，都愣住了！</p><p>那些方才重伤垂死、甚至已经断气的化神期掌门，此刻正一个接一个睁开眼睛，迷茫地看向四周。</p><p>他们身上的伤势，正在以不可思议的速度愈合；他们体内的灵力，正在疯狂涌动、突破、攀升！</p><p>那个胸口塌陷的中年年轻老妇，此刻缓缓坐起，身上爆发出化神巅峰的气息——她原本只是化神中期！</p><p>那个右臂齐根断去的灰袍老者，断臂处血肉蠕动，竟然重新长出一条崭新的手臂，皮肤晶莹如玉，比原来的更强！更劲！更霸！其实狂增五十倍！</p><p>那个被炼魂幡重创、已经气若游丝的元婴期长老，此刻猛地睁开眼，周身气息暴涨——直接突破到化神！</p><p>一个……一个……一个……</p><p>超过九成的“死者”，有些迷茫地爬起。</p><p>萧凡叶的神识扫过整个天墟界，看到了让他终生难忘的景象！</p><p>那些曾经被卡在某个瓶颈数百年的修士，此刻瓶颈如同纸糊，一捅就破。金丹期突破元婴，元婴期突破化神，化神期突破炼虚——甚至连几个炼虚期的老怪物，都在冲击合体！</p><p>他们直到此时此刻终于意识到，这个世界，要变天了！</p>
