# 第70章

<p>走廊尽头又是一道门，里面是一间不大的办公室。</p><p>小蓝坐到一台电脑前，屏幕弹出一个系统界面。</p><p>界面很朴素，白底黑字，写着“神州龙组·人事管理系统”几个字，字体还是小标宋体。</p><p>“姓名龙佑。能力类型，体质强化。力量等级8级申请中。速度等级，8级。持续等级，8级。精密等级，8级。成长等级……”</p><p>他想了想，“先填7级吧，再看情况调整。”</p><p>【信息已录入，等待审批。预计处理时间：7-15个工作日。】</p><p>“那个猫娘呢？”</p><p>“她应该还在测，已经对接给其他人了，不归我管。”</p><p>小蓝盯着电脑屏幕，突然眉毛一挑。</p><p>“龙佑先生，您是不是曾在C省稷海市，以20马赫的速度低空飞行过？”</p><p>潜龙在龙佑脑子里担任吐槽角色。</p><p>【几个月前你觉醒概率操控能力第一天，让自己获得超人之力的时候闹出来的动静，没想到也被神秘的有关部门记录在案了。】</p><p>如果是他主观不想泄露出去的信息，本应无法被探测。</p><p>南方战区能发现那次飞行，只能说明一件事。</p><p>他自己也在隐隐期待，期待有像蓝X社、刹车片、时XX理局之类的组织找上门来。</p><p>毕竟大男孩都喜欢超能力者、超级英雄和超级地球这类以“超”字打头的事物，这个比当大资本家吸血鬼有趣得多。</p><p>小蓝敲了几下键盘，把那段飞行记录归档，抬头看他：“那次飞行轨迹很奇怪，忽上忽下，还在空中画S形。我们当时怀疑是某种新型飞行器，直到萨由迦的影像传回来，才把两件事对上。”</p><p>“第一次飞，不太熟练。”</p><p>小蓝嘴角抽了抽，没接话。</p><p>自龙组成立以来，他们接见的「异人」其实也不在少数。</p><p>而大部分异人，也只能做到类似“控制智齿无限生长”、“操控花生”、“生成香菜”诸如此类危险性不高的安全能力。</p><p>危险性不高，登记在册，定期回访，注意保密。</p><p>每个月领取点养廉银，基本就算完事。</p><p>龙佑这种级别，他们建组以来头一回遇到。</p><p>组织上对高危险性异人只有两个选项：99.5%把握的一击抹杀，或者合作招安。没有中间地带。</p><p>报告翻到第二页，是龙佑的身世调查。</p><p>他的聊天记录被翻个遍，从高中群聊到外卖红包转发，到朋友圈里那些今天又加班的牢骚。</p><p>浏览器浏览痕迹也一条条爬过，技术部门的人一开始还绷着脸干活，后来表情越来越微妙。</p><p>他们没有发现神秘小网站的观看记录，没有那些正常人或多或少都会藏着的小小黑历史。</p><p>最出格的一项，是“网购仅退款”，再往下翻是“公开指导无辜网民制作皮蛋雪糕”。</p><p>心理侧写团队交出一份长达五十页的报告，有一项评估指标，代号斩杀。</p><p>当某个“奇人”的某个值超过80，龙组就必须着手配备斩杀计划。</p><p>龙佑的数值是19。作为对比，普通小市民的平均值是40，小偷小摸在45到55之间。</p><p>一般只有非激情犯罪的故意杀人犯、不发加班费的黑心老板、长期网络暴力的惯犯、断更太监的小说作者，能到75+点数。</p><p>但看龙佑生活的其他方面，在获得超人力量前，又完全是个彻底的普通人。</p><p>就仿佛……是将一个普通人的所有“黑历史”信息彻底屏蔽了。</p><p>‘但在不少案例中，当一个普通人获得了超级力量，他的心性有可能迎来大变。’</p><p>小蓝继续默默观察龙佑。</p><p>……</p><p>三百米外的测试区。</p><p>林云在密闭测试场里待了快两个小时。</p><p>场地四周覆盖着灰白色的复合材料，墙壁上嵌着十几个传感器探头，天花板角落的摄像头亮着红色工作灯。</p><p>她按照指令试了各种方法，深呼吸、冥想、做广播体操、原地转圈。</p><p>但手里都没再出现食盐。</p><p>“再回忆一下，出现食盐时你在做什么？”技术人员的声音从扬声器里传出来。</p><p>林云盘腿坐在地上，尾巴尖焦虑地拍打地面：“……想起来了，我当时在吐槽啊，特别用力地吐槽。”</p><p>“你稍等。”技术人员说。</p><p>林云百无聊赖地晃着腿，盯着对面墙上自己的影子，橘色长发炸成一团。她把猫耳扶正，又叹了口气。</p><p>自己变成猫娘后，似乎获得了太多奇奇怪怪的能力。</p><p>扬声器重新响起：“我们找了个网络小说写手，笔名万能狐狸，写青春恋爱喜剧都市异能，主角叫龙佐。你试着读一段，边读边吐槽。”</p><p>旁边的小门打开，一个研究员走进来，递给她一台平板电脑，屏幕上密密麻麻的字。</p><p>林云接过平板，低头扫了几行，嘴角开始抽搐。</p><p>“这写的什么玩意儿……主角觉醒异能的方式是被雷劈？还精准劈在天灵盖上？这作者是不是对闪电有什么执念……</p><p>“龙佐在异世界随手就给濒死的地球老乡灌顶传功？地球老乡连破两个大境界？辰西都不敢这么乱写……</p><p>“在异世界一拳打穿山脉，回地球后被包租婆赶出出租屋，拿着黑卡去吃三十块的意面还要喝二十杯可乐回本？</p><p>“什么沟槽操作！这作者是不是对‘逼格’这个词有什么误解，有钱人谁会这么干啊……”</p><p>啪嗒，一包海盐落在林云手中。</p><p>技术人员的声音变得兴奋：“继续，别停。”</p><p>猫娘连续吐槽了三十章，平均每章三回啊三回。</p><p>91次吐槽，共计生成了9包盐。</p><p>“每次发出一句吐槽，大概会有百分之十的几率生成食盐……”</p><p>“主角的上下文，形式，内容和属性等并未与食盐生成概率有统计学意义的强关联……”</p><p>林云低头看着膝盖上越堆越高的盐包，突然有点恍惚：“我的超能力……就是用吐槽生成盐？”</p><p>“目前看来是这样。我们还准备了其他更多文艺作品、或是非文艺作品的‘吐槽条目’，你如果有精力……”</p><p>“好累呀喵。”</p><p>“也是，吐槽也是一种脑力活动。”</p><p>“读这个勾作者的书，读得我好累呀喵……”</p><p>技术人员声音里带着压抑不住的笑意：“你先出来吧，我们测一下其他项目。”</p><p>她抱着几包盐走出测试区，被带到另一间更空旷的场地。</p><p>地上画着标尺线，远处立着几个不同材质的靶标——泡沫、木材、钢板、混凝土块。</p><p>“先测力量，全力打这个测力靶。”</p><p>猫娘一拳轰出，发现和未成年青春期人类女性的平均水平差不多，根本是柔弱美少女。</p><p>接着还有短跑，长跑，跳远，引体向上，整得像个高中体测。</p><p>“速度敏捷都远超常人，弹跳力尤其突出。”</p><p>技术人员的笔在纸上刷刷写着，“看来猫科动物的特征不光是外形。”</p><p>最后一项，是防御测试。</p><p>也是在这项测试中，研究人员开始逐渐注意到、这猫娘身上最大的异常……</p><p>不是什么食盐，也不是什么猫娘本身！</p>
