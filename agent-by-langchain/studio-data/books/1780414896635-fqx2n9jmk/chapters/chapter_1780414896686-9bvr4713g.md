# 绝对突破者！

<p>在地球上班上累了，大不了就让器官自己停下休息睡觉，一块转生异世界。</p><p>但在这里，因为灵气入体，又一不小心修炼出了炼虚合体修为，想猝死反倒是难事！</p><p>一界苍生压在他肩上，一干就是九百年！</p><p>“九百年啊！九百年没休过假！没摸过鱼！没躺平过一天！”</p><p>这就是事业型穿越者的悲歌，就算没有什么生死大危机，也停不住卷的脚步。</p><p>但现在呢？现在他死了！死得好！死得妙。</p><p>“从今天起，天墟界的一切破事，跟老子再无关系！”</p><p>宗门扯皮？找别人去。</p><p>天魔入侵？让修道者头疼去。</p><p>弟子刺杀？让他们找拿簪子的大师姐去！反正剑是她捅的。</p><p>‘……我真的开心吗？’</p><p>他已经突破到「太乙真仙」境界，他已经将人皇之位禅让给自己的大徒弟。</p><p>天墟界将走向盛世。</p><p>而自己也将回归故乡，地球。</p><p>那为何心中总有淡淡的失落与怅望？</p><p>‘……不，等等，先别急着失落和怅惘。’</p><p>萧凡叶尽管以是太乙真仙，仍然额冒冷汗。</p><p>有能力杀死自己的，并不是他的大徒弟。</p><p>新一代的人皇，当然不可能用自己的力量杀死萧凡叶！</p><p>少女毕竟只是合体期修为。萧凡叶站着不动让她砍，砍到柯南大结局，砍到宇宙毁灭世界末日，都伤不到自己半管血！</p><p>杀死萧凡叶是他自己的力量，他的誓约。</p><p>‘若你们对弈胜我，便取走我性命吧……’</p><p>不……还是不对……</p><p>如果只是这种唯心的誓约，程度仍然太弱，仍然无法让他临阵突破！！</p><p>究竟是什么，将他在物理现实层面，逼到了“真正的生死关头”？</p><p>萧凡叶在黑暗虚无中猛地睁眼！</p><p>他想起来了！</p><p>在剑尖刺入灵台的那一瞬——五十道恐怖的法术，同时降临！</p><p>它们从虚空中浮现，从四面八方涌来，从过去、现在、未来每一个角落同时轰向他！</p><p>有火。有冰。有雷。有风。</p><p>有金芒万丈，有元光混沌，有寂灭之意，有造化之机——</p><p>每一道都足以重创渡劫巅峰，每一道都足以让他灰飞烟灭！</p><p>正是这五十道法术的压迫，将他逼到了真正的绝境！</p><p>正是这五十道法术的威胁，让他在生死关头彻底打破瓶颈，一步迈入太乙真仙！</p><p>萧凡叶脑海中莫名其妙地冒出几个名词：</p><p>太初烬灭炎，太乙玄清神雷，大寂灭金虹，混沌元磁光……</p><p>瞳孔骤缩。</p><p>这些名字，他从未见过，从未听过，从未在任何古籍中读到过。</p><p>但此刻，它们就这样凭空出现在他脑海中，如同烙印，如同传承，如同某种超越言语的“知识”直接灌入他的意识深处！</p><p>这五十道法术，是「太乙仙术」！</p><p>只有太乙真仙能够释放出来的仙术！</p><p>萧凡叶第一时间想到了天墟真人。</p><p>那个布局十二万九千六百年、想将整个天墟界炼成一炉丹的老疯子，就是太乙真仙境。</p><p>但他随即摇摇头。</p><p>自己如今已是太乙真仙，回头再看那天墟真人，才发现——</p><p>那老登其实就是个菜鸡！</p><p>确实，天墟真人也是太乙真仙。</p><p>但他的太乙果位是“炼”出来的，踩着整个天墟界的尸骨堆出来，靠着十二万九千六百年积累硬生生堆上去的。</p><p>论境界，论根基，论道心，论实战——</p><p>那天墟真人，根本就是个水货！</p><p>这种货色，怎么可能同时释放出五十道太乙仙术？</p><p>怎么可能将这五十道仙术维持这么久？怎么可能精准地掐在他突破的临界点轰过来？</p><p>萧凡叶脑海中闪过一个念头。</p><p>一个让他冷汗直流的念头。</p><p>他获得了“绝对临阵突破”的能力。而这个能力，从何而来？</p><p>他原来猜测，是老天爷的金手指延迟到账。</p><p>可如今在这混沌虚无的状态中，再次整理自己的一生，却猛然惊觉另一种可能！</p><p>——不是老天爷赐给他的金手指。</p><p>——而是从天墟界那场大战而来。</p><p>从龙佑前辈而来！</p><p>在天魔之战，他就已经连续突破合体期、渡劫期两个大境界！</p><p>龙佑前辈赐予了自己绝对临阵突破的能力，而且这个能力……</p><p>他原以为是“临时一次性”的，不曾想，却是永久的！！</p><p>‘0.1折开通SVIP会员，原以为是商家的连续包月套路，结果告诉我是永久会员？！’</p><p>而且，龙佑前辈，难道仅仅是赐予了他这一项「绝对特性」而已吗？</p><p>不……并不是……</p><p>龙佑前辈，他不知何时，预见到自己在渡劫巅峰到太乙真仙的最后一步……会被卡住！</p><p>预见到，自己需要一场真正的“生死关头”来突破。</p><p>所以，他提前留下了这五十道仙术，埋伏在虚空中，埋伏在时间长河里，埋伏在每一个可能的节点上。</p><p>只等这一刻，只等自己迈出最后一步的那一刻——轰然降临！</p><p>萧凡叶在虚空中颤抖。</p><p>内心只余被彻底看透的……敬畏。</p><p>龙佑前辈，究竟是什么人？</p><p>他不仅赐予了自己无限突破的能力，还预知到自己会在哪一步卡住，提前布置好这一切，精确到每一道仙术的落点、每一个时间节点、每一丝力量的强弱……</p><p>这等手段，这等算计，这等……俯瞰时间长河、拨弄命运丝线的伟力！</p><p>“龙佑前辈……”</p><p>萧凡叶喃喃低语，声音里带着说不出的复杂，“您究竟……是何方神圣？”</p><p>……</p><p>地球。稷海市。</p><p>傍晚的城中村，夕阳斜照，炊烟袅袅。</p><p>龙佑正蹲在巷子口，手里端着一碗刚买的炒河粉，吃得满嘴流油。</p><p>“阿嚏——”他打了个喷嚏，差点把筷子从鼻孔里喷出去。</p><p>龙佑揉了揉鼻子，有些莫名其妙地抬起头。</p><p>‘奇怪，太乙真仙了还会打喷嚏？’</p><p>【说不定这感冒病毒也有太乙真仙修为。】</p>
