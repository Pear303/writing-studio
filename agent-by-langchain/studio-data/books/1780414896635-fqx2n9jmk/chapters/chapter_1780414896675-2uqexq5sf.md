# 混元炼道炉

<p>奇物？什么奇物？</p><p>这并不是修仙界的专用术语，龙佑也是第一次听这个词！</p><p>话音未落，思绪未过，铜炉已当头罩下！</p><p>龙佑退无可退，避无可避，黑暗的炉口将他与周遭的光海一并吞入。</p><p>炉内，是另一番景象。</p><p>无处不在、无孔不入的剥离之意，混沌之火从皮肤、血肉、骨骼、经脉开始，烧穿他凝聚太乙仙力护持的每一寸护体仙光，直抵本源！</p><p>龙佑清晰地感觉到，自己以太乙仙力构筑的受肉身，正在崩解！</p><p>比疼痛更深层的虚无感涌现，支撑“龙佑”这个存在结构的一切，都在被拆解炼化！</p><p>神魂亦在消融，他的思维、记忆、情感层层消蚀。他看见无数画面——地球、彩票、概率面板、初次超音速飞行、萧凡叶那一剑、天墟真人的冷笑……</p><p>构成他意识的内容物，也在被那混沌之火无情剥离，化作点点灵光，融入炉内翻涌的混沌。</p><p>‘这……就是只要弱于他，就会被斩杀！’</p><p>龙佑的感知急剧收缩，视野天旋地转，他仿佛从无限广阔的存在，坍缩成一个微点。</p><p>死亡尚存痕迹，炼化则彻底归零。</p><p>太乙仙力、超人体质、不灭特质……</p><p>全成炉中薪柴，遭混沌的火，狂暴吞噬！</p><p>最终，在炉底那混沌翻涌的深处，一粒极其圆润、毫无瑕疵的“丹”，静静跌落。</p><p>没有任何属性的丹丸。</p><p>非金非木，非阴非阳，非生非死。</p><p>不垢不净，不生不灭，不增不减。</p><p>只是存在着，如同一切物质与概念的种子，又如一切终结后的余烬。</p><p>化作丹药的龙佑，意识即将溃散。</p><p>必须都被炼成药了，怎么还会有脑子！</p><p>但就在最后一丝意识即将熄灭的刹那。</p><p>“不能……停……”</p><p>思想不能停！只要还在思考，还在质疑，还在反叛，那他就还是龙佑，而不是一粒死物！</p><p>【龙佑的思想在任何情况下都不被中止或减缓：100%！】</p><p>那粒毫无波澜的丹药，内部骤然震颤，涌现出极度活跃、极度狂暴的思考波纹。</p><p>哪怕没有了大脑，没有灵魂，只剩下一粒微观的质料，龙佑的思绪依然如超频的CPU般疯狂运转！</p><p>“我为什么会输？不，我为什么会被炼化？”</p><p>幸好抓住了最后这一丝丝机会，不然就变成“卡兹停止思考”了！</p><p>既然思想还在，就能修改命运！</p><p>龙佑的意识，开始在虚空中复盘。</p><p>“潜龙，你在吗？”</p><p>极度活跃的思考中，龙佑轻声发问。</p><p>【我？我大概也被炼化了一半，现在只是你残存思想里的自言自语罢了。】</p><p>“那也够了，既然思想不灭，就把这盘死局翻过来！”</p><p>【你也注意到了，概率操控能力有个很大的缺陷，就是我们需要通过“思想”将其激活。】</p><p>修为够高，特质够多，把自己堆成六边形战士就能立于不败？</p><p>并非如此。就算把自己堆成“六边形战士”、“七边形战士”，给自己加了“超人体质”、“不灭”、“太乙真仙”，加了“强运”……就像一个疯狂的氪佬+肝帝玩家，把所有的属性点都点满了，把所有的防御装甲都穿上。</p><p>但仍然，全部木大！</p><p>潜龙早就警告过他，你永远在补漏！</p><p>天墟真人的「混元炼道炉」根本不讲数值！</p><p>就像红橙黄绿青蓝紫，万千斑斓的颜色，最终统统化成一抹灰。</p><p>什么色相、亮度、饱和度，全都没了。</p><p>‘这是……机制怪！！’</p><p>‘虽然我也给自己上了很多层100%概率的「机制」，但似乎总有顾及不到的缺漏。’</p><p>‘譬如我让自己100%「不灭」，结果就成为了一颗不灭的丹药。’</p><p>‘我让自己100%锚定「人性」，却仍然只是让这颗丹药的食用方法更加人性化了……’</p><p>龙佑意念如电。</p><p>无所弔谓，思想还在，就能修改命运！概率能力还在，就能改写现实！</p><p>【我还原为龙佑本体：0% → 100%】</p><p>刹那间，天地未生异象，灵气未起波澜。</p><p>混元炼道炉内，丹药骤停颤抖，静静悬浮，表面混沌灰垢层层剥落，内里璀璨清光迸发！</p><p>从无到有，从零到一，从灰底子到万象斑斓！</p><p>“给我出来！”</p><p>丹药炸裂！无尽清光自微尘中爆发，顷刻填满炉膛！</p><p>轰隆隆！</p><p>铜炉表面流转苍凉道韵的混沌纹路，此刻难承内部重压，纷纷崩出细小裂纹。白光自裂纹喷薄而出，映照得古朴铜壁千疮百孔。</p><p>炉外。</p><p>天墟真人正欲伸手摄取“龙佑丹”，猛然脸色大变。</p><p>枯瘦如柴的手被恐怖反震之力弹开，虎口崩裂，鲜血长流！</p><p>“怎么回事？！”</p><p>天墟真人猛地后退，死死盯着铜炉。</p><p>“不可能，绝对不可能！”</p><p>混元炼道炉乃十二万年布局结晶，炼化一界之力的神器，连天道法则皆可抹除，怎会在刚晋升太乙的小辈手中失控？</p><p>更让他惊恐的，是铜炉内传来的气息。</p><p>龙佑的气息重新出现，灵压澎湃，如观深不见底的黑洞，又如望无边无际的星海。</p><p>“你明明已被我炼化，怎还能保持清醒、强行重塑身躯？这根本说不通！”</p><p>天墟真人厉声怒吼，嗓音发颤。</p><p>“说不通？老登！通通你的！”</p><p>他疯狂催动仙元，压制铜炉暴动，想要强行合上即将炸开的炉盖……可惜晚了！</p><p>轰！铜顶盖子粉碎！</p><p>漫天铜屑与清光中，一道身影从「混元炼道炉」内踏步而出，太乙威压再度席卷光海！</p><p>他一个仙道杀招「抓波龙爪手」，捅破了天墟老登的胸口，缓解老年人的胸闷气短。</p><p>“嗯。我妙手回春，帮你缓解了胸闷气短，肯定得收些报酬的吧。”</p><p>龙佑把那尊破了个顶盖的混元炼道炉，往天外光海里一捞。</p><p>铜炉嗡鸣，乖顺地缩成巴掌大小，溜进他掌心。</p><p>“好东西，这炉子能炼化、烧熔一切比我弱的东西？那以后拿它煮火锅，熟得肯定快。”</p><p>【你特么就这点志向？】</p><p>天墟真人半截身子血肉模糊，胸骨塌陷，肋骨碎茬外翻。</p><p>龙佑伸出右手，五指收拢，掐住天墟真人残存的上半截躯干，指头陷进那干瘪的皮肉里，跟提溜一只褪了毛的老母鸡似的。</p><p>“走，回家。”</p><p>他抬脚一踏，天外光海炸开。</p><p>纯白的混沌与劫灭意志被暴力撕出通道，两道身影沿着那条通道极速坠落，穿过星空，穿过界膜，穿过那层若有若无的天墟界壁。</p>
