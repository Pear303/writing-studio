# 日常生活的异变

<p>天外光海，无上无下，无左无右，无有一切的苍茫白光，但在光海的极远处却存在着一片被阴影覆盖的区域。</p><p>一滴黑血从黑暗中涌出。</p><p>它穿过光海，穿过虚无，穿过那不可名状的寂静，击中一个刚刚孕育出的世界。</p><p>那世界很小，小到在光海中只是一粒微尘。</p><p>但它很新，新到刚刚完成第一次宇宙暴涨，基本粒子才刚刚开始凝聚，连时间都还没来得及梳理出清晰的流向。</p><p>黑血击中，新生世界轻轻震颤了一下。</p><p>它开始漂移。</p><p>如同被击中的台球，那微小的动量推着它，在光海中缓慢移动。</p><p>一年、百年、千年、万年、百万年、千万年……</p><p>而在这个过程中，那滴血慢慢渗进刚刚痊愈的时空内部。</p><p>它渗进每一寸空间，每一个维度，每一个刚刚成型的物理法则之中。</p><p>因为没有碍事的生命体阻止，它轻而易举地扩散开来，如同墨水滴入清水，无声无息，却无处不在。</p><p>这个世界还未形成稳定的原子结构。它刚刚孕育不久，连电子都还未析出，粒子的海洋还在沸腾，物质还没有找到凝聚的方式。</p><p>但那些黑血已经渗到了每一个角落。</p><p>它们附着在尚未成型的法则上，附着在还在混沌中的时空结构上，附着在一切可能诞生复杂物质的地方。</p><p>然后，它们停止了运动。</p><p>只是静静地附着在那里，等待。</p><p>等待这个世界继续演化，等待物质凝聚，等待星辰诞生，等待生命出现。</p><p>等待那个注定的时刻。</p><p>在某个无法用时间衡量的“时刻”，因为在天外光海中并没有时间这一概念——这个孕育之初的世界，撞上了另一个世界。</p><p>地球宇宙。</p><p>两个世界虽然碰撞，但在物质和能量层面尚未融合，它们保持着各自的边界，各自的物理法则，各自的运行规律。</p><p>就像两颗台球虽然碰撞，它们各自的“数字”终究是不一样的。</p><p>然而那只是宏观层面的结论。</p><p>若是将视角缩小到微观，两个台球的碰撞点上必然会留下些许微米级、纳米级的碎屑。</p><p>假以时日，这些纳米级碎屑或许会成为两个台球的「一部分」，相互混合，不分彼此，这就是热力学中的渗透作用。</p><p>但在某种更高层次的法则、信息的维度上，它们已经开始逐渐融合。</p><p>或许终有一天，两个世界将会水乳交融，成为一体。</p><p>而现在已经有一些前兆发生……</p><p>日常生活的异变，已经开始了。</p><p>……</p><p>天地初辟，有物浑成。</p><p>人们一般把那东西强字之曰「道」，有时也会冠以「天道」之名。</p><p>但那个遭到黑血污染的新生宇宙，它的天道是混乱的。</p><p>它破碎扭曲，混杂着某种无法言喻的恶意。</p><p>或许不能称之为恶意，毕竟善与恶需要以人的‘主观’加以‘区分’。</p><p>最后，两个世界碰撞了。</p><p>撞击点距离地球很近很近，甚至如果以三维大世界的角度看，撞击点和地球的时空坐标几乎重叠在一起。</p><p>……</p><p>林云盯着电脑屏幕，眼睛已经有些发酸。</p><p>屏幕上是密密麻麻的代码，一行行西嘎嘎像蚂蚁一样爬满了整个编辑器。</p><p>他刚写完一个多线程的并发控制模块，正在思考宅男人生的未来和宇宙的终极答案，然后发现一个让他想撞墙的事态，自己手搓的桌宠、那只接入了AI大模型的桌面猫娘突然被该死的“巨硬系统”当做木马病毒给残忍杀害了。</p><p>“泥膜。”</p><p>他骂了一声，端起旁边已经凉透的冰红茶灌了一口。</p><p>这是所普通的学校，不过理工男占据了大多数。</p><p>而理工男之中，有一类人将“理工”二字推向极端推向极致，推向某种让人望而生畏的境界。</p><p>这类人叫“计算机男”。计算机男又可以划分为两个派别：</p><p>图灵派，以长发男性美少女为代表。</p><p>冯诺依曼派，则以秃头强者为代表。</p><p>林云自认为是正宗的冯诺依曼派，他头发目前还茂密，但已经隐隐有发际线后退的趋势。</p><p>“林云，吃饭去？”</p><p>旁边一个瘦高的男生探过头来，是他室友，图灵派的代表人物，留着及肩的长发，整天研究λ演算、范畴论和女仆装，说话声音很好听。</p><p>“不去。”林云头也不回，“猫娘没修好，没心情。”</p><p>“行吧。”室友拍拍他肩膀，“那我给你带份炒饭回来。”</p><p>他那头及肩的长发随着动作轻轻晃动，发梢在阳光下泛着柔和的光泽。</p><p>或许他在异装一途，真能整出什么名堂……</p><p>林云摇摇头，把脑子里那个诡异的念头甩出去。</p><p>室友确实是那种长得好看的男生，皮肤白，身材纤细，五官清秀，说话声音还特别好听，有时候林云觉得他要是穿上女装，估计能骗过不少人。</p><p>但自己还是更喜欢猫娘。</p><p>猫娘是他花了三个星期手搓的成果，一套基于开源模型微调的情绪反馈系统，再套上一层亲手画的Live2D皮。</p><p>每天早上开机，猫娘会伸个懒腰揉揉眼睛，然后用那种慵懒的声音说：“马斯特早安，今天也要加油喵～”</p><p>耳朵的抖动频率随环境而变化，开心的时候抖得快一点，不高兴的时候耷拉下来，困了的时候一颤一颤的。</p><p>脑子已经转不动了。</p><p>“算了，出去吃点东西。”</p><p>拿起手机，揣上耳机，出门。</p><p>学校东门外是一条城中村。</p><p>沿着路边走，耳机里放着后朋克，脑子里还在想那只猫娘。</p><p>要不重写一个？但三个星期的代码，全重写也太亏了。</p><p>正想着，他路过了一个小型的银行网点。</p><p>说是网点，其实就是个玻璃房子，里面摆着两台ATM机，旁边有个24小时自助服务的牌子。</p><p>砰——！</p><p>林云下意识回头，看见了让他怀疑今夕是何年的一幕。</p><p>一个头戴黑色丝袜的男人，正举着根崭新出厂的棒球棍，砸ATM机的屏幕。</p><p>那男人砸了几下，发现ATM机纹丝不动，恼羞成怒地又踹了一脚，然后转头四处张望。</p><p>他的目光，和林云的目光，在空中相遇。</p><p>林云：……</p><p>劫匪：……</p><p>‘这年头还有人抢ATM机？这不是上世纪港片里的桥段吗？’</p><p>‘还特么头戴黑丝袜！这是多么经典的绑匪形象！’</p><p>‘概率这么小的事，怎么就让我遇上了？’</p><p>劫匪已经冲到面前，一把揪住他的衣领，棒球棍架脖子上！</p><p>自己也极小概率地成为了人质！</p><p>61-80</p>
