# 退租流和退婚流差不多吧

<p>稷海市，人民公园。</p><p>还是那棵老柳树，还是那片人工湖，还是那些遛弯的老人和牵手的情侣。</p><p>阳光斜斜地洒在湖面上，泛起粼粼波光。一个推着婴儿车的年轻妈妈从湖边走过，几个放学的小学生追逐着跑过小径。</p><p>没人注意到，老柳树下凭空出现了一道身影。</p><p>空气里有青草的味道，有湖水的湿气，还有远处传来的煎饼果子的香味。</p><p>龙佑掏出手机看了看——时间显示，距离他离开地球，刚好过去两个半小时。</p><p>“还行，没耽误太久。”</p><p>天墟界和地球的时间流速比是300:1，他在那儿待了1个月，地球也才过了1坤小时。</p><p>他口袋里的手机就震动起来。</p><p>龙佑掏出，低头一看——信号恢复了。屏幕上弹出一封邮件提醒。</p><p>「发件人：姜笙」</p><p>「主题：关于你上次提到的创业想法」</p><p>关于姜笙所提的创业，可以重温一下第7章开头。龙佑愣了一下，随即想起来。</p><p>穿越之前，他确实和姜笙讨论过创业的事。</p><p>潜龙：</p><p>【差点忘了这茬事儿。记得在穿越之前我和你讨论过，老是通过彩票这种方式搞钱，会被人怀疑和盯上的。】</p><p>【最好的方法还是开个“空壳公司”。】</p><p>【而且这个空壳公司并不是完全空壳，要有实际的业务，否则也会被当做洗钱的“白手套”给盯上。】</p><p>“对。”龙佑在心中回道，“思来想去，和我这能力契合最好的应该是搞个‘金融’类的企业，不涉及‘实产’，不易穿帮。上市不上市不重要，重要的是让爸妈认为我这钱来得不违法。”</p><p>【其实你可以直接洗脑所有地球人，包括爸妈，让他们认为你疯狂中彩票是合理合法又合情的，多简单。】</p><p>龙佑摇摇头。</p><p>“你可能会觉得我这表层意识有些虚伪，但我不想对我亲近的人的思想动手动脚。”</p><p>【行吧。】</p><p>龙佑给姜笙发信息：「刚回家，先等我一阵子[咧嘴笑][咧嘴笑]」</p><p>潜龙嫌弃：【工作上的事情你发表情包，太不严肃了。】</p><p>不严肃的龙佑闪现回自己的出租屋中。</p><p>他祖籍是稷海市远郊的一个小县城，爸妈也一块住在那。</p><p>而他曾经租房和打工的地方，则是稷海市市区内的城中村，距离祖籍不远。</p><p>高中毕业后，他住了三年。</p><p>他拐进那条熟悉的巷道。</p><p>头顶是交错的电线，脚下是积水的路面，两侧是贴满小广告的墙壁。即便是晴朗的傍晚，这里也透不进多少阳光，终日昏暗潮湿。</p><p>龙佑走在其中，莫名有些怀念。</p><p>半个月前，他还只是个普通牛马，每天从这条巷子进进出出，为房租和工作焦虑，今天他已能一巴掌将太乙真仙拍成猪头。</p><p>他感叹了一声天道好轮回风水轮流转，走到自家楼下。</p><p>刷卡。滴——无效。</p><p>龙佑眉头微皱，又刷了一次。滴——无效。</p><p>身后传来一声尖锐的嗓门：“哟，还知道回来啊？”</p><p>龙佑回头。</p><p>一楼，包租婆正翘着腿坐在小板凳上，手里捧着手机，屏幕上正放着什么“霸道总裁爱上我”的短剧。</p><p>她抬起头，那张圆脸上满是黄瓜片。</p><p>“龙佑是吧？之前几天没回来，去干嘛了？”</p><p>龙佑想了想，前几天先是去X省看姜笙，之后又在天墟界打怪升级，戳破无数惊天大阴谋，尽显汗水与努力、智慧与博弈。</p><p>他认真回答：“去异世界打了一架，顺便帮一个老乡突破渡劫期，还把一个想炼化世界的太乙真仙拍成了猪头。”</p><p>包租婆翻了个白眼：“神经病。”</p><p>她放下手机，站起身来，叉着腰：“你听好了，你这个月的房租，四天之前就到期了！我找你人找不着，发你微信你也不回——你那个什么二次元破头像，三天没一条消息，我还以为你死了呢！”</p><p>龙佑掏出手机一看，果然有几条未读消息。</p><p>都是包租婆发的“房租到期了”之类的。</p><p>“所以呢？”</p><p>包租婆冷笑一声：“所以？所以我已经把你房间清空了，租给别人了！你那堆破烂，全堆在走廊上，自己收拾去！”</p><p>龙佑上楼，走到自己那间房门前。</p><p>果然，门开着。里面已经换了一批行李，明显是新租客的。</p><p>而他那些家当，几件衣服、一台旧电脑、几本技术书、一堆杂物，全被堆在走廊上，乱七八糟地躺着。</p><p>龙佑气笑了，想杀她全家怎么办，自己也要染上修仙界的恶习了。</p><p>【冷静。】</p><p>“认真的，以我现在的实力，杀她全家只需要动个念头。之后再将‘其实一切无事发生’的概率调整到100%，这样我又体验了修仙版的快意恩仇，她全家又没有财产和生命的实际损失，简直是双赢。”</p><p>【我知道。但你不是那种人。】</p><p>【不过你要是实在气不过，可以参观一下其他世界线消消气。】</p><p>龙佑：“参观其他世界线？”</p><p>想了想，觉得这个主意不错，这才是修仙境界的真正用法嘛。</p><p>他闭上眼，意念微动——视野拉升！</p><p>脚下，是汹涌的光阴长河，无数条世界线如同晶莹的丝线，向四面八方无限延伸。</p><p>每一条世界线，都是另一种可能性。</p><p>但事实上，在其他世界线里，他看不到自己的身影。</p><p>做减求空得道果，几多回首无伊人……</p><p>潜龙：【……哦是的，成为‘太乙真仙’后，其他世界线中再无你的身影存在。】</p><p>【所以你最多能在其他世界线，看包租婆吃瘪。】</p><p>【但无法在其他世界线，看「你」亲自动手暴打包租婆的场景。】</p><p>唉，不和凡人斤斤计较了。龙佑拎起行李箱准备下楼。</p><p>包租婆那尖锐的嗓门又从身后传来：</p><p>“哎，你磨蹭什么呢？赶紧收拾好东西离开吧！反正你这房租刚好也到期了，我不租给你，你也不能说我违约！”</p><p>龙佑回头看了她一眼。</p><p>目光平静，却让包租婆莫名打了个寒颤，那是种看垃圾蝼蚁的眼神！</p><p>退一步，海阔天空。他必须要用强硬手段，让包租婆退一步了。</p><p></p><p>龙佑缓缓放下30公斤重的行礼箱，手指指向自己的太阳穴：</p><p>“我的名字叫龙佑，龙战于野的龙，庇佑天下的佑，家住在稷海市石牌街区某包租婆的15平米出租蜗居里。</p><p>“性别男，爱好是旅行，未婚，因为我自18岁之前都没出过省，所以对自己生活以外的大千世界充满好奇。</p><p>“曾在知名的‘生物质即时配送企业’中上班，简称送外卖。每天最晚也会在八点前回家，不吸烟，偶尔沾点酒。</p><p>“晚上十一点上床，保证睡足八个小时。睡前绝对不喝水，防止床上躺10分钟就去厕所。</p><p>“然后睡觉，像婴儿一样不留下任何疲劳和压力，就这样迎来第二天的早晨。健康检查结果也显示我很正常。</p><p>“我想说明的是，我是个不论何时都追求内心平稳的人。</p><p>“不拘泥于胜负，不纠结于烦恼，不树立会使我夜不能寐的敌人——这就是我在这社会的生活态度。我也清楚，这就是我的幸福。</p><p>“但如今泥人也有三分火，女人，你成功引起了我的愤怒。”</p><p>脸上贴满黄瓜片的包租婆，后退两步：“你要干什么？”</p><p>“你打不打麻将？吃不吃泡面？是不是经常刷手机？”</p><p>“一三五六日打麻将，不吃泡面但吃挂面，短剧挑‘后宫争宠’类的看……”</p><p>龙佑：“房东，你可听好了！！”</p><p>【你打麻将败率是90%】</p><p>【你煮面忘加盐概率是90%】</p><p>【你看短剧到高潮处突然网络卡顿的概率是90%！】</p><p>41-60</p>
