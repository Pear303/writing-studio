# 你追我逃，实际霸总文学

<p>天墟真人忽然顿住。</p><p>时间长河对岸，那团人形黑雾的气息，正在以一种疯狂的速度飙升！</p><p>渡劫巅峰的瓶颈，在那气息面前如同纸糊，一捅就破！</p><p>天墟真人面色剧变：“不可能！”</p><p>他拼命催动体内太乙果位，试图镇压此界天道，阻止第二个太乙真仙的诞生！</p><p>但无论他如何压制，那气息的攀升都没有丝毫减缓！！</p><p>‘怎么回事？怎么可能？！’</p><p>‘绝对不可能！！’</p><p>‘天墟界法则残缺，虽然天道一直在自行修补，但向来进度缓慢，怎么会在此时突然加速，如此巧合……’</p><p>数十万光年外，无人注意到之地。</p><p>一道三维裂隙悄然绽开。</p><p>空间本身折叠、隆起，被无形的力量从内部剖开。</p><p>光滑截面浮现出不属于此地的天光，来自世界外的天光稀薄透明，携着至高层次的纯粹。</p><p>光，溢出。</p><p>周围时空曲率荡起涟漪。光触及之处，维度法则松脱，天地骨架低吟，根植于世界底部的架构遭到重写。</p><p>仅仅二十秒，质变的临界点便如期而至！</p><p>就像冰晶在零度之上突然熔解，又似临界质量上的裂变链式反应启动，量变积攒到极点后，开始了必然崩塌与重构的辩证运动。一道无声轰鸣穿透所有层级的空间，直抵天墟界最底层的法则基盘，将那些千万年来从未被触动过的基本常数轻轻拨转！</p><p>变化以超越光速的姿态向外扩散。</p><p>无形波纹自裂缝爆发，越过声光震荡，擦过整个天墟界的每一个角落！</p><p>星空中最微弱的尘埃，深渊里最古老的禁制，凡人田间尚未发芽的种子，修士丹田中流转的灵气，一切存在在不可感知的层面同步发生了微妙的偏移。</p><p>天幕上，那些原本恒定运转的星轨错位了一瞬，随即沿着新的轨迹缓缓重启；大地深处，灵脉与地火的涌动路径悄然偏转，流向更加丰沛的节点。</p><p>……</p><p>天墟真人瞳孔骤缩，又放松，又收缩。</p><p>对面人形黑雾的气息彻底越过界限，攀升至他无法否认、无法轻视的高度。</p><p>他感受到了，这片残缺的世界，就在这一刻完成了第二个“太乙果位”的建构。</p><p>第二个太乙真仙，降临！！</p><p>【龙佑现在的修为，立刻提升到太乙真仙，完美掌握对应境界的感悟、道心、神通，并且不可能被非自愿的方式剥夺太乙果位的概率：0% → 100%】</p><p>时间长河剧烈震颤。</p><p>无数世界线同时分叉扭曲、崩溃重组，通向天墟真人“稳居此界唯一太乙真仙”的线，一条接一条湮灭！</p><p>而那些通向“太乙真仙加一”的线，则突然冒出，如雨后春笋般疯狂生长，铺天盖地，笼罩一切！</p><p>萧凡叶眼珠颤动：</p><p>‘龙佑前辈仅仅是一道投影……居然也有突破渡劫巅峰大圆满的修为？！’</p><p>‘这是……仙威！’</p><p>‘他的一道投影，就有媲美太乙真仙的恐怖力量！！’</p><p>萧凡叶抬头看向时间长河对岸的天墟真人。</p><p>那尊太乙真仙，天墟真人，此刻正面色惨白，浑身颤抖。</p><p>对方从渡劫期修为、强制突破至太乙真仙境界了？！怎可能！！！</p><p>龙佑打了个响指。</p><p>啪。时间长河静止，无数条世界线定格在那一瞬。</p><p>天墟真人心脏真要炸了。</p><p>眼前这团黑影，已然实打实展露太乙真仙的强横修为，招式便是覆盖整个世界的砸瓦鲁多。</p><p>只是这门时间暂停的“仙道杀招”本身颇为鸡肋。</p><p>因为时间停滞之时，自身根本无法与静止的外界万物产生任何互动。</p><p>但凡妄图在时停期间，触碰外物。</p><p>便会直接打破停滞，令时间即刻恢复流转。</p><p>所以想要模仿某个肌肉线条凌厉的金发吸血鬼，又或是某个傲娇白毛女仆，在时间暂停期间扔出大量飞刀攻敌，完全是不可行的。</p><p>这个技能，一般是用来光速交流情报，或者喘一口气。</p><p></p><p>龙佑解除了自己对天墟真人的信息屏蔽。</p><p>“既然你也这么礼貌地告知了自己名字，那我也介绍一番，在下龙佑。”</p><p>那位资深太乙真仙，终于得以窥见这团黑影的本体。</p><p>——居然是个看起来二十出头的年轻人？</p><p>面相清秀，眼神清澈，嘴角还挂着一丝似笑非笑的弧度。</p><p>天墟真人瞳孔微震。</p><p>修炼到他们这个境界，骨相面容确实可以轻易改变，十八岁少年还是八百岁老翁不过一念之间。</p><p>但「相由心生」这四字，从来不是虚言。</p><p>他活了一元会，十二万九千六百年，见过无数天骄妖孽，见过无数试图以少年之身登临绝顶的狂徒。</p><p>但那些人，无一例外，都会在漫长岁月中被磨去棱角。</p><p>骨相可以重塑，面容可以捏造，但眼睛骗不了人。</p><p>而眼前这个自称“龙佑”的年轻人……</p><p>那双眼睛里，没有任何被时间打磨过的痕迹。</p><p>清澈得像一汪山泉，张扬得像初生牛犊。</p><p>这不是装出来的年轻，这是真正的、货真价实的「精神年轻」。</p><p>十二万九千六百年了，他见过太多天才，太多妖孽，太多惊才绝艳之辈。</p><p>但从未见过一个人，能以如此年轻的姿态，站在太乙真仙的高度。</p><p>龙佑歪了歪头，似乎对他的震惊毫无自觉：“怎么，没见过年轻人？”</p><p>天墟真人压下翻涌的心绪，眼中闪过复杂的情绪。</p><p>或许是忌惮，不解，甚至是一丝连他自己都不愿承认的……羡慕。</p><p>“汝究竟修行了多少年？”</p><p>龙佑想了想：“算上今天的话……应该有大半天了吧。”</p><p>天墟真人：？</p><p>最终，天墟真人擦去嘴角不知何时渗出的血迹，脸上浮现出一抹苦涩的笑意。</p><p>“呵……红尘护阵之下，你我皆如笼中困兽，何谈尽兴一战？”</p><p>他抬头望向苍穹，那里是无尽星空，星辰黯淡，虚空幽邃。</p><p>“天外光海。那里无天无地，无法无天，才是太乙真仙真正的战场。若阁下敢来，老夫便在那里恭候。”</p><p>龙佑眯了眯眼。</p><p>‘天外光海是啥？’</p><p>【我去，我怎么知道。不过正想试试太乙真仙全力出手是什么感觉，既然他说‘那里’可以发挥全力，那你就赶紧去吧。】</p><p>龙佑握紧右拳，超人力量与太乙仙力在体内交织涌动，发出低沉嗡鸣。</p><p>“但是，我拒绝口牙！！”</p><p>“什、什么？竟然不去！”</p><p>“你以为我和打上头了的卡卡罗特一样蠢、会把仙豆扔给沙鲁吗？你既然提出如此古怪的要求，说明去到那地方再战、必定会对你有利！”</p><p>龙佑一拳轰出！</p><p>拳风未至，天墟真人已化作一道流光。</p><p>向着天外暴退，借着这一拳的推力，加速遁走了！</p><p>老者抚须笑道：“还是太年轻，你以为本座料不到你的心思？这才是本座的逃跑路线啊！”</p><p>“想跑？”龙佑身形一闪，紧追不舍。</p>
