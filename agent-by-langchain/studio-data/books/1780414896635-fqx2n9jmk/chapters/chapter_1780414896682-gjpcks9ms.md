# 创业，潜龙基金

<p>满脸黄瓜的房东绷不住：“你脑子果然秀逗了！”</p><p>她把脸撇过去，再也不管这个脑子奇葩的男性人类租客。</p><p>“啧，天杀的，这播放怎么卡了？老娘刚换的光猫……”</p><p>龙佑拖着行李箱走出巷子，拐上大街。</p><p>夕阳已经完全落下，城市亮起了灯火。他掏出手机看了看时间，又看了看兜里那张还有蛐蛐160多万的黑卡。</p><p>先找家酒店对付两晚吧。现在他这个身价，住五星级酒店倒也不算难事……</p><p>他刚这么想着，一抬头，就看见路边站着个人。</p><p>穿着简单的白衬衫和牛仔裤，相貌清秀，正微笑且略带紧张着看着他。</p><p>“姜笙？”</p><p>龙佑脚步一顿。这货怎么这么快就来了，一直在这程门立雪？</p><p>姜笙似乎已经恭候多时。他见龙佑出来，便迎上前来，笑容温和得体。</p><p>“龙佑，多年不见。”</p><p>她打了个招呼，目光在龙佑拖着的行李箱上停留，“你这是……搬家？”</p><p>龙佑点点头：“哦，刚好我把租了三年的房给退了。听说你之前住院，现在身体如何。”</p><p>但姜笙的眼神微微闪烁了一下，看了眼路边的摄像头，心中了然。</p><p>要演戏，她懂了。</p><p>她压下心中翻涌的思绪，脸上露出恰到好处的笑容：“没事了，小毛病而已。”</p><p>龙佑点点头，似乎对这个回答毫不意外。</p><p>姜笙继续道：“龙佑……先生，我这次来，是想当面和你谈谈，关于‘创业’的事。”</p><p>龙佑挑了挑眉：“分手之后，说话这么正式？”</p><p>姜笙：“哈哈……只是觉得，既然是谈正事，还是正式一点好。”</p><p>她已记下来：在人类的凡俗社会，龙佑先生似乎不希望自己用尊称。</p><p>虽然直呼其名有些冒犯，但她也应该遵从先生的意愿。</p><p>想来一个站在世界顶点的强者，能够随手赐予“天人合一”的存在，也不会在这种礼仪问题上斤斤计较。</p><p>但龙佑拖着行李箱，笑着说道：</p><p>“你以为我攀上中东老土豪是借口？并非。现在先去吃饭，那家平价西餐厅有8元畅饮。”</p><p>他指了指街角那家灯光昏黄的小店。</p><p>姜笙愣住了。</p><p>她看着龙佑那张普通的脸，看着他那随意得不能再随意的表情，忽然有些恍惚。</p><p>这就是那个随手将她从死亡线上拉回来的存在？</p><p>这就是那个让她“天人合一”、让她窥见一丝世界真相的强者？</p><p>……</p><p>潜龙的声音在龙佑脑海中响起：</p><p>【你这根本就不能塑造所谓霸道总裁的形象，本质上还是个屌丝。】</p><p>龙佑在心里回他：“不能因为‘转运’了就忘记来时路嘛。”</p><p>【外边餐厅、饭店的咖啡机里，全是烤焦的蟑螂尸体，你知道吗？】</p><p>“你和我共享同样的记忆和经验，我怎可能不知道？”</p><p>龙佑笑骂，“别扫兴呀！那家的预制菜是真好吃。”</p><p>他想起自己偶尔搞劳自己，就会去那家店。</p><p>那时候每到月中发工资，才去搓一顿。</p><p>一般都是点两份面，一个无限畅饮，摁造七八杯可乐果汁，说是要回本。</p><p>“走吧。”龙佑已经拖起行李箱，向那家店走去。</p><p>姜笙快步跟上。</p><p>【话说她怎么知道我在这儿的？】</p><p>餐厅还是老样子。塑料桌椅，油腻的菜单，墙上贴着褪色的海报。</p><p>龙佑找了个靠窗角落坐下，把行李箱往旁边一放。姜笙坐在他对面，双手放在桌上，坐姿端正像在面试。</p><p>今天这家平价西餐厅出现了「概率极小」的菜品，一道卤水烧鹅，另一道则是明炉烤鸭。</p><p>西餐厅里，龙佑吃了一口卤水烧鹅腿，满意地眯起眼：“还是那个味。”</p><p>姜笙斟酌着词句：“龙佑，你说的‘创业’……具体是什么方向？”</p><p>她的潜台词是，先生您赋予我的“权责”是？</p><p>龙佑咽下鹅腿，喝了口可乐，再吃口蒜瓣，开始说他的构思。</p><p>“我有‘非常信得过的信源’，可以获取大量关于股市的情报。</p><p>“而且还有一笔启动资金，咱们就可以钱生钱，在杠杆上套杠杆，化身华尔街之狼。</p><p>“主要目的呢，是维持这企业在社会中的正常运转。</p><p>“让家人觉得你我这钱来得正当，别整天担心你我是不是去缅北了。”</p><p>姜笙的瞳孔微微收缩。</p><p>【维持企业在社会中的正常运转】</p><p>这句最关键的句子在她脑海中反复回响。</p><p>人类社会。正常运转——潜台词是，这个企业的真实目的，并不是“赚钱”。</p><p>靠金融赚钱只是表象，是“在人类社会中的正常运转”所需要的伪装。</p><p>真正的目的，在“人类社会”之外。</p><p>她脑海中飞速运转，将龙佑的话一字一句拆解、翻译、重构。</p><p>不涉及实业的金融企业。不需要牵扯太多俗世凡人参与，而且资金流动复杂，难以追踪。</p><p>表面上是炒股赚钱，实际上……实际上是什么？她暂时没资格知道。</p><p>【让家人觉得你我这钱来得正当】</p><p>这句话透露出几个重要的新信息。</p><p>在遵守人类社会的规则和法律以外，还需遵守人类文明的“道德”准则！</p><p>维持原有的“社会人际关系”！</p><p>但与此同时要绝对保密，即使是社会关系中最亲近的人，也不能知晓。</p><p>姜笙压下心中翻涌的思绪，郑重地点点头：“我明白了。”</p><p>龙佑看了她一眼，心想这姑娘怎么突然一副如临大敌的表情。</p><p>“至于人事安排……后续也由我来规划吧。”</p><p>龙佑寻思，依靠他概率操控能力，自己定是人中伯乐，伯乐中的伯乐，伯乐中的伯乐中的伯乐！招几个人才，洒洒水的事啦。</p><p>姜笙点点头。</p><p>‘我明明是本地天道，这个世界范围内的最佳人才，我都尽在掌握。’</p><p>‘龙佑先生却不让我来物色人员，而是由他亲自决断。’</p><p>‘难道……他需要的人才，并不存在于‘这个世界’之内？’</p><p>两人各怀心思，吃完30块的昂贵意面。</p><p>龙佑寻思自己都身家过百万了，吃一顿30块也不算太过分吧。</p><p>当然，斤斤计较还是得斤斤计较的。</p><p>他凭借如今太乙真仙修为的体质，连喝了20杯霓虹生可乐才离开，算是狠狠回本。</p><p>临走前，姜笙又叫住正拖着行李箱准备潇洒离去的龙佑。</p><p>“先……龙佑。”她改口很快，神色郑重，“这家企业，您打算起个什么名字？”</p><p>龙佑停下脚步。这倒是个问题。</p><p>起个太霸气的，比如“龙腾寰宇”、“赤霄结社”，容易被当成传销或中二病晚期。</p><p>起个太普通的，比如“顺发贸易”、“兴旺投资”，又感觉有点配不上自己这身本事，也没那个味。</p><p>他突然想到了一直陪伴自己的那个声音。</p><p>名为【潜龙】的潜意识。</p><p>【呵负心汉，终于想起我了？】潜意识龙佑嗷嗷傲娇道。</p><p>掏出手机，在搜索框输入两个字：【潜龙】</p><p>屏幕上立刻跳出了一堆“潜龙物流”、“潜龙养猪”、“潜龙塑料厂”……</p><p>龙佑视线扫过，正好看到“潜龙基金”这个名字似乎还能注册，或许他单纯就是觉得这两个字顺眼。</p><p>“就叫‘潜龙’吧。”</p>
