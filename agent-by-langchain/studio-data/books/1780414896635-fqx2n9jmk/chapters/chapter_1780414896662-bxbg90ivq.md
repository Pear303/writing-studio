# 天墟界的最后三日（一）

<p>九天之上，那道裂隙又扩大了。</p><p>萧凡叶负手而立，站在天墟界最高的那座山峰之巅。罡风猎猎，吹得他破旧的青色道袍猎猎作响，满头白发在风中狂舞。</p><p>他已经在这里站了三天三夜。</p><p>身后千里之外，是修仙界最后的防线。</p><p>二十年前，仙魔之战爆发时，那道防线还在中州。十年前，退到了天南。五年前，退到了苍莽山脉。</p><p>如今，已经退到了这最后的绝境：天柱峰。</p><p>再往后，就是凡人聚居的三十三州。</p><p>那里有八百兆黎民，不懂法术，不知修仙，只会在春种秋收时祈求风调雨顺。</p><p>萧凡叶记得，九百年前自己刚穿越过来时，也是那样的凡人。</p><p>九百年前，那时候他还是一个刚从某酒吧舞高校计算机专业毕业的程序员，在某大厂工位上敲代码敲到凌晨三点，然后——</p><p>然后就猝死穿越了！</p><p>没有系统，金手指，和老爷爷！</p><p>睁开眼时，他躺在一座破庙里，浑身是血，原身是个刚被妖兽咬死的炼气期散修。</p><p>他花了三天时间接受“穿越了”这个事实。</p><p>花了三个月才学会怎么吸收灵气。</p><p>花了三年才筑基。</p><p>花了三百年才金丹。</p><p>但身为地球人的浪漫终究不灭。</p><p>直到筑基期，他还在等金手指。</p><p>直到金丹期，他还在等新手大礼包。</p><p>等到元婴期，他终于认命。这辈子，只能靠自己去肝了。</p><p>他像以前为了赶项目上线一样，没日没夜地打坐、炼丹、悟道。为了抢一株灵草，他能在绝地毒沼里趴上十年；为了参悟一道法则，可以不眠不休地入定半个世纪。</p><p>靠着这股子“修bug”的死磕劲头，他硬生生在毫无背景的情况下，修到炼虚巅峰。</p><p>又花了六百年，才走到今天这一步——炼虚巅峰，天墟界第一修士。</p><p>自穿越而来，共计九百年。</p><p>他曾以为自己的人生轨迹是：读书、工作、买房、结婚、生子、退休、等死。</p><p>没想到穿越后的人生轨迹是：炼气、筑基、金丹、元婴、化神、炼虚、等死。</p><p>对，他才刚900岁，人生中的青葱岁月，结果便只能等死！</p><p>萧凡叶抬起头，看向那道裂隙。</p><p>裂隙深处，隐约能看到无数猩红的眼睛正在窥视着这个世界。</p><p>那是域外天魔的主力，正在等待裂隙扩大到足以让他们全部降临的那一刻。</p><p>上一次天魔降临，是一万年前。</p><p>那一战，天墟界陨落了三位合体大能，十八位炼虚老怪，化神以下不计其数。</p><p>整个修仙界的传承断层，灵气稀薄，一万年过去都未能恢复。</p><p>而这一次，这一次天墟界连一位合体境界的都没有！最强的就是他，炼虚巅峰。</p><p>萧凡叶曾经算过一笔账。</p><p>炼虚之上是合体，合体之上是渡劫。以他的资质，如果没有意外，大概需要再多两千年突破合体，再五千年渡劫。</p><p>一万年太久，只争朝夕，他的资质放在天墟界算是天纵奇才，无论去哪里都有人摆红毯、摆花盆欢迎前辈莅临。</p><p>可惜天魔不给时间。</p><p>身后传来轻微的破空声。</p><p>萧凡叶没有回头，只是淡淡道：“来了？”</p><p>来人是青羽宗的宗主，一位化神高阶的老妪。她拄着拐杖，颤巍巍地落在萧凡叶身后三步处，声音沙哑：</p><p>“萧道友，各派掌门让我来问你……你真要一个人守在这里？”</p><p>老妪叹了口气，“天魔先锋的实力，已堪比炼虚巅峰。你一个人……”</p><p>“我知道，我打不过。”</p><p>萧凡叶转过身，那张看上去只有三十出头、实则已经活了九百年的脸上，没有太多表情，“天魔先锋的实力比我强，人海战术足以将我淹没。</p><p>“但你们更打不过。二十年来，化神以上死了七成。元婴以下十不存一。</p><p>“如今还能站在这里的，不过是一群强弩之末！”</p><p>他顿了顿，抬头看向那道裂隙。所以由萧人皇来，是最理智的抉择。</p><p>老妪的眼眶有些发红：“萧道友，你九百岁便修炼到炼虚巅峰，是天墟界万年不遇的奇才。若是再给你两千年……”</p><p>“我没有两千年。”萧凡叶打断她，“天墟界也没有两千年。”</p><p>他转过身，背对着老妪，也背对着身后那残存的修仙界。</p><p>“裂隙还有三天，就会扩大到足以让先锋降临。这三天，我会守在这里。</p><p>“若是先锋降临，我会和它一战。若是我赢了，你们就还有时间。</p><p>“若是我输了——”他没有说完。</p><p>老妪最终只是深深一拜，化作流光消失在远方。</p><p>罡风依旧，白发依旧。</p><p>九百年来，萧凡叶见过太多离别。</p><p>元婴期时，他收过一个徒弟，那丫头资质普通，但特别刻苦，总是缠着他问东问西。</p><p>到后来，那位徒弟将他视为死敌。</p><p>化神期时，他有过一个道侣，两人相守了二百年，一起游历天下，一起论道参玄。</p><p>后来，他们恰逢几个修仙家族大战，在混乱中得到一块法宝残片。为了补全这块残片，在一次秘境探险中，她被上古秘境的禁制绞碎。</p><p>他们都走了。</p><p>只剩他一个人，站在天墟界最高的地方，等着与天魔一战。</p><p>为了守护这个糟透了的世界。</p><p>这个世界，散修与世家相互攻讦、天地至宝全成了碎片、上古传承十不存一、仙人秘境里的机关考验全奔着屠杀去的。</p><p>但萧凡叶隐约觉得，一切本不该这样。</p><p>……</p><p>第三日。</p><p>裂隙扩大到足以让天魔先锋降临的程度。</p><p>萧凡叶睁开眼，抬手召出自己的本命飞剑。那柄剑名叫“归乡”，是他用一块天外陨铁亲手炼制。</p><p>此剑随他征战无数，斩妖除魔，从未离身。</p><p>为什么叫归乡？萧凡叶有时候也会问自己。</p><p>是因为想回地球吗？没错。</p><p>极想极想，可同时又极怕极怕！九百年过去，地球或许早已物是人非，当年的亲人朋友怕是连骨灰都找不到。</p><p>所谓的“归乡”，大概只是一个执念。</p><p>当然，也有可能两个世界的时间流速不一样，自己在天墟界千年，地上不过三日。</p><p>萧凡叶握紧剑柄，抬头看向裂隙。</p><p>裂隙深处，那无数猩红的眼睛同时亮起！</p><p>一股滔天威压从裂隙中倾泻而下，压得整座天柱峰都在颤抖。</p><p>萧凡叶闷哼一声，嘴角溢出一缕鲜血。</p><p>“好强的魔威！”</p><p>仅仅是威压，就已经让他受了内伤，这就是天魔先锋的实力。</p><p>堪比炼虚巅峰，甚至比炼虚巅峰更强！</p>
