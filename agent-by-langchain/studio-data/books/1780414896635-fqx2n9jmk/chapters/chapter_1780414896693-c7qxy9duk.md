# 潜龙基金（二）

<p>萧凡叶坐在茶室的包厢里，看着窗外的人工湖。</p><p>秋风吹皱水面，几只白鹭在浅滩觅食。</p><p>“……今日上午十时，珠赫国总统府与萨由迦抵抗运动代表团在第三国首都签署和平协议。根据协议，珠赫国将于即日起开始从萨由迦领土撤军，预计在九十天内完成全部撤军行动……”</p><p>“……国际社会对萨由迦和平协议的签署表示欢迎。联合国秘书长发表声明，称这是历史性的一步……”</p><p>门推开，姜笙走进来，一袭素色连衣裙，长发披肩，手里拎着只简单的布包。</p><p>就和先前初次见面一样，萧凡叶从她身上感受到很淡、很淡的威压。</p><p>很淡，并不意味着对方弱，而只能说明对方在极力压制，却仍然忍不住泄露出一点。</p><p>萧凡叶获取合体渡劫修为，暴揍完域外天魔后，也是靠着压制修为、隐藏境界的手法，对其他修仙者说老子要退休。</p><p>如果人家是修为隐藏气息都不会，那最好别说自己是修仙的了。</p><p>姜笙在他对面坐下，微微一笑：“萧先生？幸会。我是潜龙基金的总裁，姜笙。”</p><p>她顿了顿，目光若有若无地扫过包厢角落，确认无人后，压低声音：“你的‘身份’，就是我帮你‘补办’的。”</p><p>萧凡叶郑重道谢：“多谢天……姜姑娘。”</p><p>姜笙摆摆手：“不必客气。龙佑先生交代的事，我自当尽力。还有，称我姜笙便可，我不姓天。”</p><p>她亲手给萧凡叶斟了杯茶。</p><p>“首先是面试环节，请读出卡片上的字母。”</p><p>萧凡叶：“ABCDEFG……XYZ。”</p><p>“然后是专业考试环节，请问‘编程’一词的拼音怎么拼？”</p><p>“biān chéng。”</p><p>“恭喜您通过了面试。萧先生懂得编程和英文，真是极好。我们潜龙基金的‘凡俗事务’是做金融投资的，正需要您这样的人才。”</p><p>她从包里取出一份文件，推到萧凡叶面前：</p><p>“这是聘用合同，技术顾问，月薪税前三万，五险一金齐全。你看一下，没问题就签字。”</p><p>“多谢。”他签下名字。</p><p>很快萧凡叶忍不住低声问：“姜姑娘，冒昧问一句……龙佑先生，是个怎样的人？”</p><p>姜笙看向窗外，目光悠远，仿佛穿透时空，看见了那条汹涌的时间长河，看见那尊悬立于万物之上的存在。</p><p>“龙佑先生……是潜龙的创建者。”</p><p>姜笙缓缓讲述了她的故事。</p><p>萧凡叶听得心惊胆战。</p><p>龙佑前辈随手给点机缘，就能让一个濒死的凡人，达到“天人合一”的境界？！</p><p>这是何等恐怖的手段？他想起自己九百年的苦修，无数次生死边缘的挣扎，一次次突破时的艰难。</p><p>而眼前这个女子，只因为龙佑“随手给点机缘”，就达到了他甚至需要仰望的高度！</p><p>好吧，萧凡叶临战突破合体渡劫，乃至如今这一身上下太乙真仙修为，其实也是龙佑先生出手“给机缘”。</p><p>他受到的恩泽只是比较小而已，不应该为此羡慕嫉妒。</p><p>萧凡叶正色：“话说，姜总裁，‘潜龙’究竟是做什么业务的？”</p><p>“量化金融。”</p><p>“不，我是指某种更深层次的……业务。”</p><p>姜笙也严肃起来：“你应该听说过，‘天行有道，不为尧存不为桀亡’。天道本没有人性，没有悲喜与道德，只是以万物为刍狗。为何龙佑先生要赐予天地以人心——也就是我？”</p><p>天人合一，人触及天道，天融入人道。</p><p>萧凡叶沉吟：“天道不再高，人心第一高。龙佑前辈，他纳天下之百贤，甚至包括……‘天’本身？”</p><p>一个结界将他们所在的位置笼罩起来。</p><p>姜笙挥挥手，隔绝内外所有一切信息流动，声音压得很低：</p><p>“龙佑先生让天道获得人心，是为了让我守护地球。”</p><p>“？！保姆！？”</p><p>“没错。同时，让潜龙和超凡者融入世俗，以及寻找关于‘穿越者’的线索……”</p><p>已经显而易见——潜龙，是个关于穿越者的组织！</p><p>但这个结论，必然也只能算作他真实意图的冰山一角。</p><p>龙佑先生是个信息黑洞，用他们所无法理解的方式屏蔽了自身信息。</p><p>姜笙无法从他那里揣摩到更多。</p><p>她将茶杯轻轻推回桌面。</p><p>“目前可以确定，地球宇宙不仅仅只是与天墟界相撞，空间薄弱点也不止一处。</p><p>“所以目前潜龙基金的‘核心业务’，待定为三大工作方向——处理穿越者的离乡原因，他们去往了何处，以及返乡安顿。</p><p>“龙佑先生探明了你是在什么情况下离开‘老家’，客居‘他乡’——因为世界碰撞。</p><p>“客居的‘他乡’在哪里——你所登记的地点是一个大陆型世界，天墟界。</p><p>“最后是‘返乡安顿’的相关安排——龙佑先生曾对我郑重吩咐过，你来自异乡，要帮你办好一系列‘手续’和‘工作证明’。”</p><p>萧凡叶心中一震。</p><p>离乡原因、去往何处、返乡安顿——这正是龙佑阁下所做过之事！</p><p>看来，这就是潜龙组织的一部分真相。</p><p>他最后问出一个问题，也是所有打工人都关心的疑问。</p><p>“龙佑前辈……他究竟是什么地位的存在？”</p><p>姜笙微微一笑：“我不知道。但如果以‘世俗’的看法评价，他是个圣人。”</p><p>萧凡叶想起这七日以来，发生在地球人类社会的种种，琢磨着这句话。</p><p>犯罪违法，贪污腐败，一切负面的“率”都迎来暴跌腰斩。</p><p>作为太乙真仙，他自然也能看到世界线的极端变动，是龙佑先生的手笔。</p><p>——在天墟界，他就是用相同方法，赐予了一界的机缘与气运。</p><p>姜笙站起身，拿起包：“合同签好了，下周一来公司报到。地址在合同上。”</p><p>她走到门口，忽然回头，眼中含有笑意：“对了，萧先生，欢迎回家。”</p><p>窗外秋阳正好，几只白鹭又飞回来，在湖面上盘旋。</p><p>是啊，回家了。</p><p>“只是有件事让我介怀已久，天道阁下如果不介意……能否为我解答？”</p><p>萧凡叶对某件事思考许久，正好电视上正在播放有关内容。</p><p>“关于萨由迦战场的最新情况，双方已达成进一步和解，但更多细节正在深入交流……”</p><p>以龙佑的手段，要阻止那场战争，有无数种方法。</p><p>修改几个关键人物的决策概率，让珠赫国内部突然“想通”，让国际社会的施压突然“见效”。</p><p>而且这些方法，都不会有任何人察觉，不会留下任何痕迹。</p><p>“但他选择选择用二十马赫的速度撕裂大气层，让「所有人」都看见他。</p><p>“为什么？”</p><p>“龙佑先生说过，凡俗与超凡要分开。这是规矩。但他选择的，是让所有人都看见他……究竟为何？左右脑互搏？”</p><p>姜笙抬起头，看向萧凡叶。她嘴唇抿起，随后才有些不确定地问：“你没发现？”</p><p>“……发现什么？”</p><p>“地球上的原住人类，并不只有毫无超凡力量的凡人。有一类原生的地球人，被称作‘异能者’，或者异人、异人、特异功能者。”</p><p>“……特异功能者？”</p><p>凡人就如一粒细沙，而地球的特异功能者就是砖头。</p><p>细沙与砖头之间的重量差距，极其悬殊。</p><p>但两者在巍峨的山峰前，并没有什么明显的本质区别。</p><p>这也就是为何，萧凡叶回到地球半个多月，才第一次发现地球存在“异能者”。</p>
