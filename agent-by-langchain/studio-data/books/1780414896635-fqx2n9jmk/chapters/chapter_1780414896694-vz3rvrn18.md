# 天降猫娘

<p>林云心想，最近一个月全球犯罪率暴跌，缩减到原本的一成，还有继续减少的趋势。</p><p>自己所住的城市，甚至连续十年被评为文明城市。</p><p>现在他站在ATM机前，脖子上架着根棒球棍。</p><p>警察来得很快。玻璃房外警灯闪烁，扩音器喊话：“里面的人听着，放下武器！”</p><p>劫匪揪着林云的衣领，冲外面吼：“别过来！我有人质！”</p><p>林云感觉到棒球棍在脖子上压得更紧。</p><p>“大哥，你为什么要抢银行？”</p><p>劫匪声音变了，带上哭腔：“小兄弟我容易吗我？我在里面待了二十年，二十年！出来发现外面全变了！</p><p>“手机不会用，扫码不会扫，找工作没人要，租房子没押金。</p><p>“而牢里面多好，个个都是人才，说话又好听，我知道规矩，知道怎么活。</p><p>“外面这世界，我已经不认识了。我是被体制化的人，体制化！institutionalized！”</p><p>林云听得入了神。这故事讲得真好，感情充沛，细节真实。</p><p>“所以你就抢银行？”</p><p>“我现在是‘假释期’，抢个东西，罪加一等，判个无期，这辈子就在里面过了，多好。”</p><p>外面警察还在喊话。劫匪不理他们，继续跟林云诉苦，讲监狱里的事，讲出来后的遭遇，讲他有多想念那个关了二十年的地方。</p><p>林云心里有点复杂。自己是无辜路人，莫名其妙成了人质，现在还要听劫匪倾诉人生。</p><p>劫匪讲完了，叹了口气：“谢谢你听我说这些。”</p><p>林云想说点什么，但没来得及开口。</p><p>“总之让我罪加一等吧！”劫匪说完，抡起棒球棍，一棍子砸在林云脑袋上。</p><p>林云眼前一黑。</p><p>但紧接着，身体里涌出力量！忽觉四肢轻盈有力，像是有什么东西从沉睡中醒来。</p><p>他睁开眼，瞳孔已成金黄色。</p><p>巷子阴暗潮湿，劫匪还愣在原地，棒球棍举在半空。警察正在冲过来。</p><p>林云纵身一跃，跃入巷子深处。</p><p>……</p><p>六楼，阳台门开着。</p><p>林云的室友站在那儿，望着远处的城中村夜景，不知道在想什么。</p><p>“卧槽！”</p><p>防盗网上蹲着个东西！</p><p>橘色头发，金黄瞳孔，身形娇小，穿着件特别宽大的衣服。</p><p>那东西伸出手，抓住防盗网栏杆一掰。</p><p>铁条弯了，像面条一样掰出个可供人钻过的缺口。</p><p>室友正张嘴要叫，那东西从缺口钻进阳台，冲过来，捂住他的嘴。</p><p>“别出声。”声音很轻，“是我。”</p><p>室友瞪大眼睛。那东西离他不到半尺，他能看清那张脸。</p><p>五官是某个看起来很眼熟的熟人轮廓，但变了太多——眼睛大了，睫毛长了，皮肤细得看不见毛孔，嘴角有两颗小小的虎牙。</p><p>还有那股味道，某种说不清的淡淡香味，一直往他鼻子里钻。</p><p>“你难道是？”他闷声问。</p><p>那东西松开手，叹了口气：“没错，我是林云。我知道你很激动但你先别激动。我整天发癫说想要猫娘但从来没想过把自己打扮成猫娘！”</p><p>室友愣了几秒。</p><p>林云？那个秃头预备役林云？</p><p>橘色的长发，金色的瞳孔，小巧的鼻尖，说话时露出的虎牙——</p><p>“你真的是林云？”</p><p>林云点头。</p><p>“警察和导员下午来找过你，”室友压低声音，“说你被劫匪威胁了。你现在这样子……”</p><p>林云撩起额间垂下的头发。那股淡香又飘过来，勾得室友鼻子发痒。</p><p>“我也说不清楚发生了什么，”林云说，“转眼间就变成这样了。”</p><p>他低头看自己。</p><p>原本合身的衣服现在松松垮垮挂在身上，袖子长出一截，裤腿堆在脚踝。</p><p>最惨的是鞋子，两只42码的运动鞋里，塞着一只明显小了好几号的脚，脚趾在鞋尖处空荡荡的。</p><p>“我来找你借套衣服，我的都穿不下了。”</p><p>室友盯着他看了半天。</p><p>大头在疯狂报警：这玩意儿是怪物，你室友变成怪物了，快跑快叫人。</p><p>小头也在疯狂报警：卧槽猫娘卧槽活的猫娘卧槽就在眼前卧槽还带香味的那种。</p><p>“你……你先别动。”室友往后缩了缩，又往前挪了挪，表情很复杂，“我给你找衣服。”</p><p>林云知道，和他同居的室友是个顶级图灵派拥趸。</p><p>别人衣柜是一半夏装一半冬装，而室友则是一半男装一半女装。但优点是，他不会穿着女装出来显摆招摇，而且看起来取向还算正常，也暂时没有嗑药风险。</p><p>有些衣服也确实非常合身，主要是室友的体型极佳，属于是老天爷赏饭。</p><p>“我不知道你身上发生了什么，总之你先随便挑件应付一下，但不要碰我的‘黑猫庄园’……”</p><p>粗重的敲门声传来。</p><p>林云脸上闪过一丝紧张，迅速扯出一件衣服，光速往身上套，边套边往阳台跑，从他刚掰开的缺口又跳出去。</p><p>室友愣在原地，欲哭无泪。</p><p>因为他看清了，林云拿走的正是他花了六百块定制的那套“黑猫庄园”，蕾丝边、蝴蝶结、猫耳兜帽，全套。别问他定制这种衣服干什么，问就是热爱。</p><p>宿舍的不锈钢防盗门被一脚踹飞，门板飞进来三米远，砸在地上，巨响！</p><p>一男一女走进来。黑西装，白手套，夜里戴着墨镜。</p><p>女的短发干练，男的高大沉默。</p><p>他们无视地上那扇门，无视被巨响惊醒、正从床上爬起来的其他人。</p><p>有人刚抬头，睡眼朦胧看向他们，女人就举起一个像录音笔的东西，对准他。</p><p>咔嚓！白色闪光。</p><p>那人重新躺下，呼吸平稳，继续沉浸在婴儿般的睡眠中。</p><p>‘我去！黑衣人照进现实！’</p><p>室友脑子里刚闪过这个念头，就被一道闪光给催眠了，他醒来后将会把这夜的事情忘得一干二净。</p><p>男的先是将不锈钢门重新安装好，随后走到阳台，蹲下查看那几根被掰弯的防盗网栏杆。</p><p>被掰开的口子不大，大约只能供一个小孩、或者体型娇小的少女通过</p><p>他望向远处城中村的夜色。</p><p>女的走过来，站在他身边。</p><p>耳麦微震，通过骨传导传来声音：“该‘新生异人’逃跑方向正是稷海市‘目标’所在方向，不要打草惊蛇。”</p><p>……</p><p>林云慌慌张张匆匆忙忙穿上衣服，在凉爽的夏夜晚风，与温热的楼宇霓虹间跳跃。</p><p>‘这样子目标太明显了，必须私闯个民宅，找地方躲躲，抱歉了。’</p><p>她盯住一个没有防盗网的房间，蹑手蹑脚将门窗打开，跳进去。</p><p>背身靠着水泥墙，微微探出一缕头发漏向窗外，像第三人称卡视角那样看着外面。那两人居然没追上来！</p><p>她松口气，转头。</p><p>一个男人坐在小马扎上，黑发黑眸，端着泡面抬头看她，旁边摆着两枚硬币。</p><p>“嚯，刚设定【天降一个永远不死喵的猫娘概率：99%】，这么快就送上门来了？”</p>
