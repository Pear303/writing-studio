# 多边形强者的讨论

<p>不同的修仙界有不同的境遇。</p><p>龙佑也趁着战斗结束后这短暂的空闲期，更多了解了这位地球老乡的情况。</p><p>他30岁穿越来，在天墟界呆了900年。</p><p>因为没有什么系统，只能靠着1%的汗水努力，和99%的根骨与天赋，一步一百个脚印修炼至天墟界巅峰。</p><p>很快，天墟界其他那些NPC修道者也赶到了。</p><p>“人皇前辈！您无恙否？”</p><p>“天墟界得存，皆赖前辈之功！”</p><p>远处，数十道流光划过天际，八仙过海般各显神通疾速飞来。</p><p>有御剑的，有踏云的，有骑着异兽的，有站在葫芦上的，还有踩着翻涌的浪涛凌空而来的。</p><p>转瞬间，一众修道者落在巨坑边缘，将萧凡叶团团围住。</p><p>当先一灰袍老者躬身长揖，声如洪钟：“前辈力斩天魔，救苍生于倒悬！此恩此德，我辈修士永世不敢忘！”</p><p>其后一中年美妇敛衽一礼，眼含泪光：“人皇前辈，您可有大碍？妾身这里有万年灵芝一株，虽不入前辈法眼，但求尽绵薄之力。”</p><p>“前辈您……这满头霜雪竟复归青丝，容颜重返盛年！”</p><p>一虬髯大汉瞪大双眼，惊呼出声，“莫非、莫非前辈已破而后立，臻至那传说中的——”</p><p>“恭喜人皇！贺喜人皇！”</p><p>众人如梦初醒，齐声恭贺。</p><p>但诡异的是，没有一个人看向龙佑。</p><p>哪怕龙佑就飘浮在三百丈外，哪怕那团人形黑雾在夕阳下如此显眼，那些修道者的目光扫过那片区域时，都会自然而然地略过。</p><p>仿佛那里只是一片普通的空气。</p><p>萧凡叶眉头微皱，疑惑地看向龙佑前辈。</p><p>在他视角中，那团人形黑雾依然飘忽不定。</p><p>龙佑声音在他脑海中响起，毫无感情波动：</p><p>“这是一道投影。若我不允许，他们无法觉察我。”</p><p>一道投影，就能让合体期以下的所有修士完全无法感知，甚至连自己，也不被允许查看龙佑前辈的轮廓。</p><p>这位“龙佑”的真身，究竟是何等存在……</p><p>然而，那青羽宗老妪却忽然身躯一震，浑浊老眼中精芒爆闪，又迅速黯淡下去。</p><p>她盯着萧凡叶，手中龙头拐杖微微颤抖：</p><p>“不，人皇……您白发复黑，容颜复盛，可为何身上怎的无一丝灵力波动了？”</p><p>此言一出，满场俱寂。</p><p>众人齐刷刷看向说话者——那是一个身着青袍的老妪，满头银丝，拄着龙头拐杖，正是青羽宗的宗主，化神高阶修士，眼神很好。</p><p>众人面面相觑，旋即纷纷探出神识查看——</p><p>片刻后，所有人面色剧变。</p><p>那虬髯大汉脸上的狂喜僵住，化作难以置信：“这、这怎可能？前辈方才还一剑斩灭天魔先锋，那等威势……”</p><p>灰袍老者眉头紧锁，沉吟不语。</p><p>中年美妇掩口失声，眼中泪光化作惊疑。</p><p>窃窃私语渐起。</p><p>“莫非是燃烧本源，透支过度？”</p><p>“那一战之惨烈，我等虽未亲见，但百里之外都能感受到那毁天灭地的余波……”</p><p>“若是修为尽失，那如今的人皇……”</p><p>“萧人皇白发复黑，容颜复盛，竟不是因为‘境界突破’，而只是‘回光返照’，如同烛火的最后一道耀光……”</p><p>有人话未说完，但未尽之意已在众人眼神交汇中流转。</p><p>萧凡叶正在应酬。</p><p>他似乎将自己伪装成修为尽失，境界跌落，回归凡人，再无回天之力的皇者。</p><p>与周围一众天墟界大佬谈笑风生。</p><p>“与人打交道”这种事，对传奇地球社恐龙佑而言，简直就是地狱。</p><p>他人即地狱。</p><p>萧凡叶自称曾经是猝死穿越过来的程序员，而众所周知，捣鼓电脑的大多是交际白痴。</p><p>不曾想，如今的萧人皇，却能从容应对天墟界修道者。</p><p>潜龙的声音在龙佑脑海中悠悠响起：</p><p>【九百年磨炼，能让一个大概率是“社恐”的人，变成领袖型的社交达人。】</p><p>龙佑看着应付自如的萧凡叶，若有所思：“确实很励志，可以上读者文摘。”</p><p>【不，你没明白我潜意识中想说的额外之言——】</p><p>“哦？请讲。”</p><p>【你认为一个三十岁的码农，在经历九百年的异世界岁月后，对萧凡叶而言，哪一段的人生更重要？】</p><p>龙佑不假思索：“应该是九百年的。毕竟时间长度摆在那里。”</p><p>【那么，应该是哪一段人生主导了他的心智？】</p><p>“九百年……”龙佑微微一顿。</p><p>【所以，你现在明白了吗？】</p><p>龙佑沉默片刻：“你是说，虽然我有不灭和超人体质，但我的‘心灵’也是一项弱点？”</p><p>【正是。你的潜意识都能记得你曾经看过JOJO第二部，知道无敌的“究极生物”卡兹，是如何被消灭的——用无穷的时间和无穷的单调，让其停止思考！】</p><p>龙佑眉头微皱：“你的意思是，我应该给自己觉醒一个‘绝对心灵防御’的特质？”</p><p>【你只说对了三分之一。】</p><p>“三分之一？”龙佑又想了想，“你是说，我应该询问萧凡叶关于修仙的各种境界划分，然后直接一路攀升到修仙者中的最顶点？”</p><p>【现在你说对了三分之二。】</p><p>龙佑：“所以你的意思是？”</p><p>潜龙的声音变得郑重起来：</p><p>【各种缺陷和漏洞，总是亡羊补牢是不太妥当的。】</p><p>【今日你让自己成为六边形战士，概率调到100%，但明日敌人却从第七个弱点攻击你。】</p><p>【于是你将自变成七边形战士。但而后又出现第八个弱点，你又被动变成八边形战士……】</p><p>【这样下去，你永远在补漏，永远被动。】</p><p>【我称之为「N+1边形」定理。】</p><p>龙佑若有所思：“那我们需要一个将自身短板效应削减到最低的方案。”</p><p>【正是。】</p><p>“所以方案是什么？”</p><p>【我也没想到。有许多潜在的短板，不是靠我们自己想就能想出来的，必须在往后日子的实践中发现，敌人会帮你找到你的弱点。】</p><p>【所以，先用“暂定方案”——你我将自己攀升到修仙境界中的最顶点。】</p><p>【毕竟按照设定，修仙者都是非常标准的六边形战士，攻防力速血蓝，神魂悟性道心……】</p><p>【成为“修仙者”中的顶点，至少能让你在绝大多数情况下立于不败之地。】</p><p>万变不离其宗，修仙是底层密码。</p><p>到头来一切还是需要修仙嘛。</p><p>龙佑看向远处正被众人围着的萧凡叶，又抬头看了看那几道细不可见的空间裂纹。</p><p>“那我先原地成个尊……”</p><p>【不急。你先看看那边——】</p>
