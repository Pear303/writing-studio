# 苍生祸福的根髓

<p>远处，天边涌来一团浓稠如墨的黑云。那黑云所过之处，天光暗淡，草木枯萎，鸡犬不宁，牛羊不安。</p><p>黑云中，一道身影若隐若现。</p><p>那是一个身形魁梧的老者，赤发红须，面如重枣，周身环绕着无数扭曲的魂魄虚影。</p><p>他手中持着一杆大幡，幡面漆黑如墨，上面密密麻麻刻满了诡异的符文。</p><p>无数魂魄在幡中挣扎哀嚎，发出令人头皮发麻的尖啸。</p><p>炼魂幡。</p><p>那魔头咧嘴一笑，露出满口森森白牙：“萧人皇？不对，该叫你萧废人。听说你修为尽失了？那可真是——”</p><p>他话音未落，萧凡叶已经归乡剑出鞘，剑光如虹，直取那魔头咽喉！</p><p>那魔头面色骤变，炼魂幡猛地一挥，无数魂魄蜂拥而出，化作一面漆黑的盾墙。</p><p>轰！！！</p><p>剑光斩在盾墙上，炸开漫天黑雾。那些魂魄在剑意下灰飞烟灭，但那魔头也借着这一挡，暴退百丈。</p><p>“合体？！”他惊怒交加，“你不是修为尽失了吗？！身为正道、为何要行骗！”</p><p>萧凡叶第二剑破空斩出。</p><p>魔头厉声怒吼，炼魂幡疯狂舞动，幡面煞气翻腾，无数魂魄如潮水汹涌而出。那些魂魄面目狰狞，凄厉嘶吼，裹挟无尽怨念与恶意扑来。</p><p>萧凡叶眉头微蹙。</p><p>炼魂幡难缠，非其威力逆天，而是幡中魂魄尽属含冤枉死之人。</p><p>若一剑蛮横斩灭，这些无辜魂魄便会魂飞魄散。他杀伐果断，却不愿对无辜冤魂下此狠手。</p><p>魔头捕捉到他刹那犹豫，脸上泛起狰狞狞笑：“怎么？下不去手？你那点可笑的爱与道义，便是致命弱点。今日你便葬身怨魂之手！”</p><p>话音落下，万千怨魂蜂拥而上，瞬间将他团团围困。</p><p>下方，一众重伤的化神期掌门面色惨白，挣扎着想起身驰援，却被炼魂幡威压压制，动弹不得。</p><p>身处魂潮包围，萧凡叶气定神闲。</p><p>他手腕轻转，长剑泛起温润光华，剑光轻灵洒脱，如清风拂柳，劈向那柄煞气滔天的炼魂幡。</p><p>“砰！”</p><p>炼魂幡应声碎裂，化作残片散落，幡中涌出的万千怨魂未受丝毫损伤。这一剑精准破开邪异禁锢，却未伤及魂体。</p><p>失去操控的怨魂渐渐平息戾气，眼中怨念散去，看向萧凡叶的目光里带着释然。</p><p>魔头目眦欲裂：“你、你敢坏我法宝？身为正道怎么能毁坏他人财物……”</p><p>萧凡叶已出现在他面前。归乡剑扬起，剑身爆发出璀璨光芒。</p><p>“闭嘴啊混蛋！这一剑送你归西！”</p><p>剑落。魔头头颅高高飞起，无头尸身从云端坠落。炼魂幡失去主人轰然炸开，无数魂魄蜂拥而出，一一超度。</p><p>萧凡叶收剑，吐出口浊气。</p><p>低头看向下方溃败的魔道残党，那些人吓得魂飞魄散跪地求饶。他心烦意乱，一剑将其全部斩杀，人头如大雨飞溅。</p><p>龙佑认真学习了这一招大范围AOE。如果由他来面对十万头猪，或许半个月都抓不完。</p><p>那些化神期掌门如蒙大赦，挣扎着起身，将那些魔道残党一一制住。</p><p>“报——！！！”</p><p>又一道身影从远处疾飞而来，又是一个化神期掌门，浑身是血，面色惨白。</p><p>他扑通跪地，声音颤抖：“人皇！巫族……巫族出事了！”</p><p>过春节吗？必事真多！萧凡叶眉头紧锁：“说。”</p><p>“巫族祖地突然爆发出冲天血光！有上古巫族大能的气息复苏！据探子回报……那是上古祖巫的气息！”</p><p>上古巫族十二祖巫，每一尊都是合体巅峰以上的存在，试图要搞什么人族补完计划，当时人族式微，三十三州几乎退守到第三新洛阳。</p><p>如今，祖巫现世？</p><p>“巫族还说，‘那萧人皇终于变作萧废人了！真是千载难逢之机！’”</p><p>还真就是千载难逢，因为萧凡叶修炼已超过九百年，很快就一千载了。</p><p>“报——！！！”</p><p>又一道身影飞来，这次是个金丹期的年轻修士，跌跌撞撞落在萧凡叶面前，连滚带爬：</p><p>“南、南海！南海海妖有异动！无数海妖聚集，似乎在朝拜什么！有巨兽从深海浮现，体型如山，人身章鱼脸，形神不可名状，气息深不可测！”</p><p>“克苏鲁它老鱼家踏马来凑什么热闹？！”</p><p>“急！！！”</p><p>又是一个化神期长老飞来，面色煞白，指着天空：“天、天魔裂隙！那几道裂纹突然剧烈震颤，里面有诡异的波动传出！似乎有什么东西要过来了！”</p><p>萧凡叶闭上眼，深深叹息。</p><p>“九百年来我杀了一波又一波……没完没了，永无止境，就算我是炼虚乃至合体渡劫的超级强者，也想要退休摸鱼啊。”</p><p>他低下头，看着手中的归乡剑，声音低沉：</p><p>“有时候我在想，是不是我走了，这些麻烦才会少一些？是不是我这个‘人皇’的存在，反而成了他们前赴后继的理由？”</p><p>“你走了，他们只会更猖狂。”</p><p>萧凡叶苦笑：“我知道。所以我没走。九百年了，我一直没走。但有时候，我真的累了。”</p><p>……</p><p>潜龙：【你是不是又有新想法了？】</p><p>龙佑：“你我一体，我有好点子时，你也应该知道我有好点子。”</p><p>【所以……你真要尝试？】</p><p>“事实上，我在地球时就想试一试的了，不过总担心有什么我意想不到的副作用。”</p><p>龙佑的潜意识冷笑起来：</p><p>【用异世界的人来做实验，而不伤及地球的老乡，并不会显得你格外高尚。】</p><p>龙佑耸耸肩：“我的潜意识怎么批评我，我都无所弔谓，我心我行皆澄如明镜。”</p><p>以上对话，终究都只是龙佑一个人的脑内思想斗争，左右脑搏击。</p><p>而他思想斗争后所决定要做的“那件事”，却是令天墟界都为之天地色变！</p><p>【天墟界的人族文明，走向富强民主，文明和谐，自由平等，公正法治的繁荣昌盛之世：100%】</p><p>那一瞬，天地似乎轻轻震颤了一下。</p><p>萧凡叶正要开口说些什么，却忽然顿住。他感觉到有什么东西，正在发生变化。</p><p>不，不只是什么东西在发生变化……</p><p>是整个世界，正在走向另一条截然不同的道路。</p><p>走向非凡的命运，未敢设想的未来。</p><p>那种变化无处不在，无孔不入，却又难以言喻。像是清晨醒来时发现自己睡在自己房间，自己竟然躺在自己的床榻上，自己脑袋下居然枕着自己的枕头，身上居然盖着自己的被子。</p><p>虽然明明一切都熟悉，却又一切都不同。</p><p>了。</p>
