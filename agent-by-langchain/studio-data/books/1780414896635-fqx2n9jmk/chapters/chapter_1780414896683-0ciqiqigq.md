# 全能保姆与全能强者

<p>「命运的齿轮开始转动。」</p><p>“潜龙？”姜笙低声重复了一遍。</p><p>易经有云：潜龙勿用。</p><p>何谓潜龙？龙德而隐者也。不易乎世，不成乎名，遁世无闷，不见是而无闷。</p><p>龙佑先生已经不是暗示，而是赤裸裸明示自己了，虽然拥有改天换地的神力，却选择潜伏在世俗的尘埃之中。</p><p>不显山不露水，默默布局！</p><p>“潜龙于渊，待时而动……好名字！极具深意，暗合天道！”</p><p>姜笙在心里疯狂点头，觉得这个名字简直是把“我们在凡间搞大事”这七个字刻在脑门上了，但对外人来说又只是个平平无奇的古风名字，堪称完美的伪装。</p><p>大把企业和商品，都喜欢给自己起玄之又玄的名字，比如什么“玄武玻璃”、“鸿蒙系统”、“本源悟空”。</p><p>他们二人也只是跟上时代潮流罢。</p><p>“行，那就这么定了。后续注册流程你看着办，反正我就挂个名。新人可能过几天才到，到时候你安排一下。”</p><p>说完，他拖着行李箱，摆了摆手，消失在街道尽头。</p><p>“走了，回见。”</p><p>姜笙紧紧攥着拳头，对着那个背影深深鞠了一躬，平价西餐厅里的其他人看着她这前恭后倨的都挺尴尬，有些抠脚趾。</p><p>“潜龙基金，必将不负先生所托。”</p><p>……</p><p>在地球的一个月过去了。</p><p>对时间流速是地球300倍的天墟界而言，则是二十年。</p><p>对世人而言，萧人皇已是二十年前那战后下落去向不知所踪的历史人物。</p><p>有的人坚信他在那一战中只是深受重伤，寻了处清净地在闭关。但更多人暗自感叹，人皇不问世事，想必已是凶多吉少。</p><p>大地奇才跃如鲤，各领风骚三千年。</p><p>但终究不过是一抔黄土，一日不能证道真仙，逍遥界外，便一日不得长生，岁月终有尽！</p><p>昔日西黍霸王无敌天下，最终也自刎于光阴长河边；后有青莲巨士道术通天，最终的结局仍也是投入镜花水月。</p><p>天虚道人此刻正冯虚御风，立于九天罡风层之下。</p><p>他预感到，已经很快了。</p><p>自己距离太乙真仙，只有一步之遥。</p><p>而天墟真人暴毙，又将此世界的太乙果位给空了出来——那枚被他独占了十二万九千六百再加二十年的果位，如今无主！</p><p>此刻正是他一举窃取胜利果实、成就真仙的绝佳时机！</p><p>“哈哈哈哈——”</p><p>天虚道人仰天长笑，须发飞扬，周身气息轰然暴涨！</p><p>渡劫巅峰大圆满的修为，如同一轮大日，将方圆万亿里的星云尽数蒸腾！</p><p>那道困扰了他整整三万年的屏障，那道将渡劫与太乙分隔开来的无形天堑，此刻正在剧烈震颤！</p><p>“破！”他低喝一声，体内法力疯狂涌动，向着那道屏障发起最后的冲击！</p><p>屏障龟裂！</p><p>金光从裂缝中迸射而出，照彻九天十地！</p><p>然后，他面前出现了一个人。</p><p>天虚道人的笑容僵在脸上。</p><p>那是一个青年。乌黑长发，年轻面孔，一袭青色道袍，归乡剑插在身侧。</p><p>他就那样静静地悬浮在天虚道人对面百丈处，面无表情地看着他。</p><p>“萧凡叶？”</p><p>那个二十年前消失的人皇，那个所有人都认为要么已死、最少也是境界跌落的萧凡叶，此刻就站在他面前。</p><p>而且那股气息……渡劫中阶三层。</p><p>天虚道人愣了一息，随即放声大笑：“哈哈哈哈！萧人皇啊萧人皇，你消失了二十年，本座还以为你躲在哪个角落里憋什么大招。结果呢？结果你就憋出来个渡劫中阶三层？你……等等，渡劫中阶三层？！！！”</p><p>二十年前，天虚道人感应到萧人皇突破渡劫期。</p><p>但那时候他还只是初阶一层，仅仅二十年过去，就踏马干到中阶了？！！！</p><p>天虚道人眼神一凛，随后明白。</p><p>二十年前，天墟真人因不明原因暴毙。</p><p>而这萧凡叶，定是继承了天墟真人遗留之机缘！</p><p>否则不可能解释，为何他修为如此迅猛地一日千里！</p><p>此界天地灵气，本就极难支撑第二个修道者迈入渡劫期，更别提在渡劫期有所进步！</p><p>天虚道人完全靠的是给天墟真人当狗，帮他打下手，干苦力。</p><p>这才跟着分到一口汤。</p><p>这才获得跨过渡劫的机会。</p><p>没想到这该死的萧人皇，狗运如此之好，竟能取得那陨落的天墟真人的遗物！</p><p>天虚道人收起笑容：“怎么，想拦本座证道？就凭你这渡劫中阶三层的修为？”</p><p>他抬手，渡劫巅峰大圆满的气息轰然爆发，压得方圆百里的虚空都在颤抖！</p><p>“本座三万年前就是渡劫期！三万年来，本座参悟天道，打磨道基，积蓄法力——为的就是今日！”</p><p>他俯视着萧凡叶，如同俯视一只蝼蚁：“而你，一个才突破渡劫二十年的后辈，靠着一个陨落真仙的遗物才能一日千里的没用废物，也敢拦在本座面前？”</p><p>“反派死于话多。”萧凡叶哼一声，握紧归乡剑，剑身嗡鸣。</p><p>下一瞬，他的身影消失在原地！</p><p>天虚道人眼神一凛，抬手虚按——轰！！！</p><p>两道身影在九天之上轰然碰撞！时空本身都被激荡出冲击波，呈环形扩散，将方圆上千光年的星云尘埃一扫而空！</p><p>天虚道人纹丝不动，萧凡叶倒飞而出，在空中翻了几个跟头，稳住身形。</p><p>“渡劫中阶三层，也敢与本座正面交锋？”天虚道人轻蔑地摇头，“不自量力。”</p><p>萧凡叶擦去嘴角的血迹，没有说话。</p><p>他只是握紧剑，再次冲了上去！</p><p>剑光如雪，斩破虚空！</p><p>天虚道人冷哼一声，抬手一抓，竟徒手接住了那道剑光！五指合拢，剑光在他掌心炸裂，化作漫天光点。</p><p>“太弱了。”</p><p>他反手一掌拍出，遮天大手印轰然落下！</p><p>萧凡叶横剑格挡，整个人被拍飞出去，砸穿了十七层罡风，最后嵌在第十八层罡风的壁障上。</p><p>“咳咳——”</p><p>他咳出一大口血，体内经脉寸寸断裂，又在合体期时取得的不灭道基下，迅速愈合。</p><p>天虚道人一步迈出，出现在他面前，俯视着这个嵌在罡风壁障中的青年。</p><p>下一刻。</p><p>萧凡叶面前闪过极度恐怖的剑光！铺天盖地，砌满视野！</p><p>仿佛整片天地在他面前压塌下来，挟着浩浩荡荡的九天之威！！</p>
