# 

<p>龙佑跳出时间长河，回溯到了两小时前，破庙还没塌的时候。</p><p>【下一个踏进破庙的人，是给的同时，还是个姛：100%】</p><p>设定落下。龙佑隐去身形，蹲在云层里等着。</p><p>雨又下起来了。</p><p>货郎在泥水里摔了一跤。行商被马甩出去。几只野狗夹着尾巴跑过。</p><p>然后那个青衫书生又来了。</p><p>还是那条路，还是那个走法，不急不慢，淋着雨，像饭后散步。</p><p>龙佑眯起眼：“又是他？”</p><p>【看来是的。概率锁定的对象没变，还是同一个人。】</p><p>“但我提的条件变了。上次只是‘给’，这次是‘给的同时还是个姛’。怎么还是他？”</p><p>【也许他本来就是。只是我们没看出来。】</p><p>龙佑盯着那个青衫书生。瘦削的身形，清秀的面孔，头发用木簪束着，喉结若隐若现。</p><p>走路时步子迈得不大，衣摆被雨打湿了贴在腿上，隐约看得出腿型修长。</p><p>怎么看都是个年轻男子。</p><p>书生跨过门槛。木柱子应声而断，破庙轰然倒塌。</p><p>和上次一模一样。</p><p>雨停了。倒塌的破庙里，那个书生从碎木堆里爬了出来。</p><p>他拍了拍身上的灰土，抬头看了看天，然后沿着那条泥泞的小路继续往前走。</p><p>书生在天黑之前进一座小镇。他走进酒肆，跟掌柜的要了间房。</p><p>龙佑蹲在对面屋顶上，掀开一片瓦往下看。</p><p>书生进了房，关上门。点灯。然后开始解衣服。</p><p>龙佑正要移开视线——他看见了一根布条。</p><p>不是腰带。是缠胸的布。</p><p>一圈一圈，缠得很紧，从肋骨一直绕到锁骨。</p><p>书生解布条的动作很熟练，先是松开肩膀上的结，然后一层一层往下拆。</p><p>【哦。】</p><p>“你就一个‘哦’？”</p><p>【不然呢？我一个潜意识还能惊讶到哪去。不过这下就说得通了，她是女扮男装。所以她喜欢女人的话，就是姛。】</p><p>“但她进了破庙。按照我设定的条件，‘进庙的人’必须是‘给’。”</p><p>【对啊。所以她是姛的同时，还得是给。给是男同性恋，她一个女人怎么当给？】</p><p>龙佑皱起眉头，盯着那个正在换衣服的女子。</p><p>她脱掉湿透的青衫，从包袱里拿出一件干净的淡青色衣裙，料子轻薄，颜色鲜亮。</p><p>穿好衣裙后，她把头发散开，用木梳慢慢梳理。雨天水汽让发丝有些打结，她梳得很耐心，一缕一缕地顺。</p><p>烛光映着她的侧脸。眉眼间那股清冷还在，但柔和了许多。</p><p>龙佑正看着，那女子的表情突然变了。</p><p>不是愤怒，不是惊恐。是——空白。</p><p>像有人在她脑子里按了一下暂停键。</p><p>她的眼神从柔和变得锐利。原本微微翘起的嘴角放平了，嘴唇抿成一条线。</p><p>她低头看了看自己身上的紫色衣裙，皱了皱眉，伸手把领口往上拉了拉。</p><p>然后她开口了。声音和刚才不一样，更低沉，更冷。</p><p>“你又穿你的衣服。”</p><p>“？紫霞姐，你要不要听听你在说什么？”</p><p>“我是说，你又用我身体来穿你衣服。”</p><p>那女子的表情又开始变化。柔和回来，盖过锐利。她低头看了看自己的手，嘴角又翘起来，声音也变得轻快。</p><p>“紫霞姐，你的就是我的嘛，而青霞的，也都是你的……”</p><p>锐利再次盖过柔和。这次更用力，眉头皱得更紧。</p><p>“我不是你。你也不是我。说好了白天我出来，晚上你才出来，现在天还没黑。”</p><p>柔和的那个歪了歪头，看了看窗外的天色。</p><p>雨后的黄昏，光线昏暗，确实已经到了昼夜交替的模糊时刻。</p><p>“差不多啦～”</p><p>“差很多。”</p><p>“那紫霞姐现在出来也没关系啊，反正又没人看见。”</p><p>主人格紫霞重新勒上胸布，穿上一件靛蓝色的男装。做完这一切，他吹灭了灯。</p><p>黑暗中传来一声很轻的叹息。</p><p>“青霞，你又抢了我的时间。”</p><p>“……紫霞姐，还在想那个负心汉吗？”</p><p>……</p><p>【原来如此，一个身体，两个人格，一姛一给。】</p><p>“大自然竟能如此奇妙，我就算是想用中文排列出这种句子也比较困难，但老天爷眼都不眨就给我做到了。”</p><p>【所以现在怎么办？还要继续测吗？】</p><p>龙佑从屋顶上站起来，抖了抖衣摆上的雨水。</p><p>“测。当然要测。难得找到一个这么合适的实验体。”</p><p>【用实验体这个词不太好吧，听起来你就像是什么疯狂博士。】</p><p>“‘实验体’这个词和疯狂博士一样贴切，因为假如你称我为疯狂硕士，那我就像是为了写研究生毕业论文而发疯的大学生。”</p><p>龙佑再次跳出时间长河。时间倒流，破庙重新立起来，雨重新下起来。</p><p>他蹲在云层里，开始叠加新的条件。</p><p>【下一个踏进破庙的人，是给，是姛，同时是素食主义者：100%】</p><p>货郎摔跤，行商落马。</p><p>青衫书生书生走进破庙，很快又双叒叕庙塌了。</p><p>……</p><p>“紫霞姐，你不是总把自己当做男人，并且喜欢男人嘛？”</p><p>“嗯，怎么了？”</p><p>“嘿嘿……姐，我喜欢你……”</p><p>“……青霞，既然你是素食主义者，所以应该不吃这颗红烧狮子头对吧？”</p><p>“紫霞姐，我们共用一具身体，我是素食主义者，你也应该受到我一点影响吧。”</p><p>“没事，我肉身是素食主义者，但心理自我认同是异食癖。”</p><p>此庙倒塌后，他们并没有立刻走开，而是在废墟里席地而坐，烧起烤来。</p><p>天知道他们怎么将这么多红烧狮子头带在身上的，揣兜里吗？</p><p>主人格紫霞，歘下一颗烤得流油的狮子头。</p><p>将其放在嘴里，用灵巧的舌头reoreoreo。</p><p>副人格青霞夺过身体控制权，摇了摇头。</p><p>“姐姐，我知道你在用恶心的习惯，故意想引起我的反感。但可别忘了，我们是共用同一个身体，青霞能够接受自己的缺点，自然也就能接受紫霞姐姐的所有缺点。”</p><p>紫霞绷不住了：“混蛋青霞，你为什么就这么喜欢女人？！”</p><p>青霞笑道：“姐姐不也是很奇怪吗？心里认为自己是男人，而且还喜欢男人。”</p><p>……</p><p>龙佑：“……潜龙，我们还是换台吧。”</p><p>【有道理，不想再看这奇怪的伦理剧了。】</p><p>【下一个踏进破庙的人，是给，是姛，同时是素食主义者，同时是福瑞控：100%】</p><p>……</p><p>青霞流泪：“姐姐！你心里果然还装着那个负心汉男人！”</p><p>紫霞躺在黑暗里，冷冷地看向夜空不说话。</p><p>副人格青霞继续啜泣：“那个毛公嘴脸的猴子，不是都已经改名‘至尊宝’不再理你，自己一个人去生活了嘛？”</p><p>“为什么你心里还装着他，我亲爱的姐姐！”</p><p>紫霞说不出话来。如果她说，自己其实是喜欢毛茸茸的人形生物，她妹会不会当场夺走身体的控制权，自刎归天？</p>
