# 老乡见老乡

<p>【你的潜意识里，屏蔽了他人对你大部分信息的感知，以保持神秘感。】</p><p>龙佑：“为何？”</p><p>【潜意识就是想这么做。潜意识的事情，谁说得清？】</p><p>【好比你彩票中了双色球头奖，你没有想着昭告天下，而是想着财不外露。】</p><p>【这便是潜意识在控制你“保持神秘”。】</p><p>（警惕！大脑很可能在操纵你！）</p><p>【现在你不仅被这白胡子老头一剑斩飞几百里，还亲自下场拳打脚踢，已经在他心目中丧失了神秘和威严。】</p><p>龙佑一拳轰飞又一团扑上来的天魔，抽空问道：“那怎么办？”</p><p>【精通鬼谷子、佛伯乐、心理学、识人术、社交手腕、说话艺术的你，其实有一个极其简单的解决方案。】</p><p>“放。”</p><p>【用“我们”来代替“我”。就换个人称代词，这么简单。】</p><p>龙佑沉默：“……就这？”</p><p>【就这。当个体的神秘感消失，你便保持自己“背后群体”的神秘感。】</p><p>他深吸一口气，意念微动。</p><p>解除了对自己“声音”和“语义”的信息屏蔽。</p><p>然后开口：“这只是我在此界的一道投影。此界和‘我们’相隔太远，不能以真身到来。”</p><p>萧凡叶一剑逼退三头天魔，身形暴退数丈，猛然转头。</p><p>那声音……是从人形黑雾中传来的？而且说的是普通话？</p><p>不过，“投影”？“我们”？</p><p>萧凡叶眉头紧锁，一边抵御着不断扑来的天魔，一边沉声问道：“‘你们’是指什么？”</p><p>这次有了充裕的时间。</p><p>龙佑没有立刻回答，而是小声问自己：“我的潜意识，你名字叫什么？”</p><p>【龙佑。】</p><p>“该名字已被占用。”龙佑驳回，“我就叫你潜龙吧，潜意识的龙佑。”</p><p>【也行，听着挺帅。】</p><p>龙佑便对萧凡叶说：“潜龙。”</p><p>萧凡叶一时间听到地球的事物，意识一阵恍惚，顿时回想起曾经在地球的日夜。</p><p>然后不小心说出心里话：“什么乾隆？大清不是早亡了？”</p><p>龙佑：？</p><p>龙佑：“奇变偶不变？”</p><p>萧凡叶瞳孔猛然收缩：“……符号看象限。本座……我是地球D省的程序猿！猝死穿越！”</p><p>龙佑不知能说什么，居然穿越第一站就遇见老乡，只能淡淡地回了一个字：“哦。”</p><p>人类穿越的几率并不算低，姜笙病逝后穿越至异世界的概率是0.00001551%。</p><p>“居然是地球……没想到你也是地球……”</p><p>天墟界第一炼虚大修萧凡叶失态，根本按捺不住震惊。</p><p>他目光和神识全开，锁定那包裹在黑暗中的人形。</p><p>但他无法从龙佑身上，感知到任何情绪。</p><p>自始至终，龙佑所传达出的信息，便只有毫无感情的声音和语义。</p><p>‘这尊强者……就算不是地球人，也至少知道大量地球流行文化，和我熟知的地球有千丝万缕的联系……’</p><p>‘他似乎很冷静，完全没有表露任何情绪，只有纯粹的「语义信息」表达了出来……’</p><p>‘或许他早已知道我是地球穿越者？’</p><p>‘他来此寻我，就是因为我地球穿越者的身份？’</p><p>周围的天魔发出尖啸，疯狂扑来，打断了两人的认亲现场。</p><p>萧凡叶一剑扫开扑上来的黑影，急促道：“其他话以后再说！现在天墟界正在遭遇史上最强的域外天魔入侵狂潮！如果老乡能给予帮助，那就再好不过！”</p><p>“也行，你可以称我龙佑。”</p><p>“炼虚境，萧凡叶。”</p><p>龙佑抬头看向那遮天蔽日的魔云，看向裂隙深处还在涌出的无数黑影，黑影中长满眼睛的墨鱼，触手这玩意简直是一大锅墨鱼汁意面。</p><p>“这东西是什么？”</p><p>“域外天魔，你可以把它理解成什么？旧日支配者的眷族修格斯之类的……事实上，我也不清楚。”</p><p>龙佑双眼亮起炽白光芒，激光扫过，逼退一圈扑上来的天魔，或曰“修格斯”。</p><p>“我好像看过一本COC规则书，物理伤害每次只能造成1点伤害，而闪电、魔法、火焰等等伤害则减半……”</p><p>萧凡叶差点一口老血喷出来：“老乡你当这是跑团呢？是说把他们理解成‘修格斯’，没说它们就是旧日支配者啊！！”</p><p>他一剑斩断三根触手，身形暴退到龙佑身旁，喘着粗气道：“现实和地球人幻想出来的规则书还是不一样的！”</p><p>对付域外天魔，只需大力出奇迹！</p><p>不断磨灭它们的血条，当沙包一样打！</p><p>但前提是——你的当量要足够大！</p><p>话音未落，萧凡叶手中归乡剑猛然扬起，周身残存的灵力疯狂涌动。</p><p>“剑起——吞日焚魔绝剑！”</p><p>刹那间天地变色！归乡剑仿佛释放出煌煌天威，剑身震颤间，一轮虚幻大日从剑尖升起，炽白的光芒刺破魔云。</p><p>紧接着，那大日轰然炸开，化作漫天流火，每一缕流火都裹挟着毁天灭地的剑意。</p><p>火焰燃烧，剑罡咆哮，虚空扭曲！</p><p>萧凡叶立于爆焰与剑罡中央，白发狂舞，道袍猎猎，周身浮现出无数璀璨的异象——上古大能虚影诵经，神兽麒麟踏火而行，星辰银河生灭轮回。</p><p>那是炼虚巅峰燃烧最后的生命本源，才能催动的终极一剑！</p><p>轰——！！</p><p>剑光斩入魔群，数十头修格斯在瞬间被撕成碎片。</p><p>那些碎肉在火焰中挣扎蠕动，却来不及重生就被剑意彻底磨灭。</p><p>但更多的修格斯涌了上来。</p><p>萧凡叶的身形晃了晃，嘴角溢出一缕黑血。</p><p>“我……快坚持不住了……”</p><p>他单膝跪地，归乡剑插在身侧，支撑着摇摇欲坠的身体。抬头看向裂隙深处还在源源不断涌出的黑影，眼中闪过一抹苦涩。</p><p>“若是再给我两千年，我必能灵肉合一、虚神合体，突破至合体境界，届时此战还有希望……”</p><p>他咳出一口淤血，“可是现在……临阵突破的概率实在太低，简直是不可期待的奇迹……”</p><p>“‘临阵突破的概率’？”</p><p>龙佑动了动耳朵，捕捉关键词。</p><p>超人的听力让他捕捉到了萧凡叶每一个细微的音节——哪怕在漫天魔物的尖啸中。</p><p>他转过头，看向那个跪在地上、浑身浴血的白发老者。</p><p>炼虚巅峰。</p><p>只差一步，就能突破到合体。只差两千年。</p><p>但天墟界，已经没有两千年了。</p><p>“我能助你突破至合体境界。”</p><p>萧凡叶苦笑着点头：“阁下愿意相助自然是再好不过……什么？”</p><p>他猛然抬头，震怖地盯着那团人形黑雾。</p><p>“阁下方才说，助我……突破合体？？！”</p>
