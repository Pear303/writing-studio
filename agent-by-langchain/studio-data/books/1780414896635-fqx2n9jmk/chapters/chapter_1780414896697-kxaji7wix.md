# 第68章

<p>疏散开始得很专业，四个黑衣人两两分组，走进海X之家。</p><p>其中一人径直走向各柜台，亮出证件，声音压得极低：“您好，市政演习……请暂时离开本区域，二十分钟后可返回。”</p><p>导购们愣一下：“哦……”</p><p>然后，他们就用神秘银色小钢笔亮出失忆闪光，将在场所有导购、路人和顾客都闪晕倒，然后一人拖着两三个，全部扛上车。</p><p>“所以这有出示证件和通知的必要吗……”林云猫娘无力吐槽。</p><p>附近几个夜市街区都空了后，几个黑衣人最终汇集在海X之家。</p><p>他们在试衣间门前停下。</p><p>“就是这个。”小光的声音从后面传来，她不知何时绕了过来。</p><p>“空间稳定指数？”蹲下的黑衣人又掏出个更精密的仪器，对着门板扫描。</p><p>天知道这么小的仪器，是怎么能测出“空间稳定指数”这种唬人的属性。据林云所知，人类顶尖实验室想要捕捉基本粒子、暗物质信号，都需要动辄几十吨、几万吨的仪器。</p><p>荧绿色数字在小小的显示屏上跳了十秒，最终定格在：</p><p>基础稳定性：18.6%</p><p>异界谐振强度：S-</p><p>“谐振强度S-？”队长挑了下眉。</p><p>谐振强度究竟是什么呀喵？林云发呆ing。</p><p>有关部门的面包人……有关部门的黑衣人队长伸手，缓缓推开试衣间门——</p><p>里面当然没有异界厕所。只有镜子、挂钩、矮凳，地上几颗盐粒还没扫走。</p><p>几番疏散，几番调查。</p><p>那群黑衣人最后围住小光，仪器屏幕上的绿光映得他们像群严肃的萤火虫。</p><p>队长掏出一板正经的记录设备，开始汇报：</p><p>“目标编号CN-44-7-试衣间，空间基础稳定性持续观测值97.4%，异界谐振强度评级S-，这是目前全域检测中第二高的谐振强度，仅次于四个月前凌晨三点某公厕第三坑位的S级……”</p><p>一个发生在公厕，一个发生在男装试衣间，这场景对比未免太过惨烈。</p><p>“持续观测期间，‘稳定性’的波动范围始终收束在18.4%至18.8%之间，标准差极小。</p><p>“这扇门的状态异常稳定……根据近10年的全球异界门样本对比，多数「门」的稳定性数据会在短时内剧烈跳动。</p><p>“越不稳定的门，越可能在某一刻突然达到100%接通率，然后彻底消失……</p><p>“而触发其不稳定的方法，就是‘开门’这一行为。然而现在……”</p><p>小光摆摆手：“直接告诉我，这说明什么？”</p><p>黑衣人：“通俗讲，它根本不需要‘开门’这一行为，就像是‘每时每刻都100%通向异界’一样可靠。”</p><p>“封锁起来。我在那边留下了定时核弹，不知会否影响到这片街区。”</p><p>“……领导，您下次能早点告知么？”</p><p>目前关于“异常折叠空间”的时间流速，和地球的比例，已经研究得比较清楚。</p><p>有关部门预计还有20分钟，定时核装置应该就要爆炸。</p><p>“全员撤离，顺便把外围的封锁线再往外推三个街区。”</p><p>这条情报也被林云猫娘摇摇耳朵听见。</p><p>小蓝面无表情地拎起她的后领，像提溜一只真猫一样把她往车那边带：“出发，上车。”</p><p>林云四肢在半空中扑腾，小声且惊恐地问：“等等等等，这里要被核平了喵……？”</p><p>“放心，影响范围大概率仅限于海X之家。不过这扇门的出现……也确实有些奇怪。”</p><p>小蓝把她塞进面包车后座，顺手关上门。</p><p>面包车一头扎进夜色中。</p><p>车载广播自动切入新闻频道，播音员字正腔圆的声音播报本地情况：</p><p>“……稷海市某商业区因‘煤气泄漏’临时封闭，市民请绕行……”</p><p>轰！！爆炸声很快传出。</p><p>冲击波来得快，去得也快。从海X之家骤然腾起一团不算太大、边缘泛着蓝白色的爆焰。光焰闪烁了一下，随即坍缩熄灭。</p><p>事后统计，爆炸当量约等于一个满载的民用液化气罐在密闭空间内爆燃。对普通人而言是灾难，对动辄用万吨TNT计量的“核装置”来说，却小得可笑。</p><p>煤气爆炸，是经过世界多国共同认证的优秀掩饰手段。据说在东瀛冬木市，“瓦斯泄漏爆炸”已经连续几十年转移民众注意力……</p><p>不过，由于现场核辐射浓度较高，海X之家附近数百米都被封锁起来。</p><p>新闻发布会上的说法是清除泄漏的煤气，修复管道。</p><p>而在暗处，有关部门已经调集了一些优秀异能者，开展了紧锣密鼓的辐射清除工作。</p><p>……</p><p>面包车在高速上跑了整整十四个小时。</p><p>林云猫娘从最初的紧张亢奋，到中途昏昏欲睡，再到后来百无聊赖地数路边经过的广告牌，现在已经放弃思考。</p><p>整只猫瘫在后座上，尾巴垂在座椅边缘，随着车子的颠簸一晃一晃。</p><p>“yue，我晕车了喵。”</p><p>又开了四十分钟，前方出现一片山壁，爬满枯藤和蕨类植物，随后在这隐蔽的小路里出现隧道。</p><p>一条宽阔的隧道向前延伸，穹顶每隔十米嵌着一盏防爆灯，光线冷白，照得混凝土墙面泛着青灰色。</p><p>地面有轨道痕迹，两侧墙壁上每隔一段距离，就有一道密封门，门上刷着编号和警示标志。</p><p>“这……你们真把秘密基地安在深山老林里？虽然从现实层面考虑很合理，但也未免太刻板印象了喵。”</p><p>“刻板印象之所以是刻板印象，就是因为这么做确实好用。”</p><p>龙组总部建于上世纪八十年代，最初是应对第一次异常空间泄露事件而设立的前哨站。</p><p>后来泄露越来越频繁，前哨站扩建、加固、地下化，慢慢就变成现在这样。</p><p>虽然外头看上去很神秘，但内部装饰还是挺温馨的。</p><p>首先是形似发财树的经典绿萝，一旁就是白色塑料饮水机。</p><p>“每个区域都有严格的等级限制，1级是诸如公厕和长时间的公共区域。2级是普通办公区，没事也不要乱闯，你们现在只能算0级人员，要是碰到什么奇怪的地方我也要写检讨书的……”</p><p>小蓝指着一间黑漆漆的房间，“尤其那里，绝对不要进去。”</p><p>“这是几级权限？”</p><p>“0级，不过刚拖完地，进去乱踩会被保洁阿姨追着骂……”</p>
