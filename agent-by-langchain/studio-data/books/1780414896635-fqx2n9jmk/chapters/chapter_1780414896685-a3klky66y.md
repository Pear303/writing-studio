# 天墟界的最后三日：天柱论道

<p>这等胸怀，这等气度，这等……这等格局，简直不像是天墟界该有的存在！</p><p>那青袍修士福至心灵，躬身一拜：</p><p>“人皇圣明！此徽记一出，必能凝聚天下气运，开创万世太平！”</p><p>萧凡叶摆了摆手，示意他们退下。</p><p>众人会意，齐声告退，化作流光散去。</p><p>他站在悬崖边，负手而立，风吹起他的衣袂，猎猎作响。</p><p>办这场什么天柱论道，其实就是为了缅怀自己“在地球看奥运会”的时光！</p><p>他非常挂念地球，挂念到近乎疯魔的地步！</p><p>自己是2023年穿越，错过了2024的高卢奥运会。</p><p>高卢法鸡作为人文和艺术气息浓厚的欧洲国家，举办的「奥运会开幕式」，想必一定也特别有老少皆宜、人人皆爱的普世艺术氛围吧？</p><p>想必，一定比群魔乱舞的2020东瀛奥运会开幕式要好看得多吧！</p><p>可惜自己错过，便只能在异界开一场山寨版的自娱自乐。</p><p>“奥林匹克……”</p><p>“五环……”远处，夕阳正红。晚霞铺满天际，将整座天柱峰染成温暖的橙红色。</p><p>九百年前，他下班时也常常看见这样的晚霞——从写字楼的落地窗望出去，钢筋水泥的森林尽头，太阳缓缓沉入地平线。</p><p>那时候他不知道什么叫修仙，什么叫渡劫，什么叫天魔入侵。他只知道加班很累，房东又要涨房租了。</p><p>如今他是渡劫期大能，一剑能斩星辰，一念能定生死。天墟界八百兆黎民，视他如神明。</p><p>但他还是会想起那个小小的出租屋，想起楼下煎饼果子摊的大爷。</p><p>“快了……”</p><p>他花费20年时间，将渡劫期修为从渡劫初阶一层，推演至渡劫巅峰九层后期大圆满！</p><p>自从天魔一战自己连破两个大境界后，萧凡叶发现自己的境界突破速度简直是逆了天般！</p><p>每每处于生死关头，比如差点被吸进黑洞的事件视界内、直面渡劫巅峰强者的自爆时，他都会莫名其妙突破一个小境界！</p><p>疯狂的临阵突破！</p><p>‘难道是我的穿越金手指延迟到账了？’</p><p>挂太小，很难当成穿越者啊。虽然刚穿越过来的萧凡叶没有觉醒什么系统，但还是一步一百个脚印打拼出今天的成就。</p><p>如今又获得了“绝对临阵突破”的金手指，更是如虎添翼，笑傲天下。</p><p>于是二十年间，他寻便了整个天墟界最爆裂的自然现象，譬如极超新星爆发，类星体爆炸，中子星爆炸，天虚道人爆炸，将自己一次次推到生死边缘。</p><p>疯狂地突破，突破，再突破！！</p><p>如今萧凡叶已是渡劫巅峰九层后期大圆满。</p><p>距离能够横渡世界之外的“太乙真仙境”，还有堪堪一步之遥。</p><p>很快便能回家了。</p><p>但随后他便尴尬地卡住——宇宙内的一切自然现象，一切修道者都已经无法伤到他分毫，无法让他体会到“生死边缘的紧迫”！</p><p>他杀死天虚道人，已经有两年半；他卡在渡劫巅峰九层后期大圆满，已经有一坤年。</p><p>此次若是能集全天墟界修道者，坐而论道。</p><p>或许集结一界的智慧，能助他突破最后一个门槛。</p><p>但自己……真的只是为了突破最后门槛吗？</p><p>萧凡叶又想起了很久很久以前，他元婴期时曾收过的第一个弟子。</p><p>那个无数次在梦中对他举起利剑的丫头。</p><p>……</p><p>天柱峰顶，云雾缭绕。</p><p>数十道身影散落于山巅各处，或盘膝而坐，或负手而立，或斜倚古松，姿态各异。</p><p>他们皆是天墟界各大宗门的精英弟子与长老，修为最低的也有元婴初阶。</p><p>此刻，他们正在论道。</p><p>“天道有常，不为尧存，不为桀亡。”</p><p>一位灰袍老者盘坐于青石之上，声音苍老而悠远，“然则何为‘常’？日月运行，四时交替，草木枯荣——此乃可见之常。但天道之常，远不止于此。”</p><p>对面一位中年美妇微微一笑，抬手轻挥，一道灵光在空中凝聚成太极图，阴阳鱼缓缓旋转：</p><p>“天道之常，在于平衡。阴阳相生，五行相克，万物相制。失衡则乱，乱则变，变则复归平衡。此乃天道自愈之力……”</p><p>“善！”</p><p>一旁虬髯大汉拍手叫好，随即祭出自己的本命法宝，一副麻将。</p><p>“九万。”一位青衣女子打出牌张，同时口中念念有词，“此牌暗合九宫之数，九为极阳，万为众数，九万者，阳极而众，正是天道由盛转衰之象。”</p><p>“碰！”对面一位白面书生推倒两张牌，“七万，七为少阳，我以少阳应和，正是顺势而为，顺应天道。”</p><p>“胡了，清一色！”</p><p>旁边一个胖修士摸到新牌后大笑着推牌，“你们看我这一把，全为条子。条者，长也，连绵不绝、蜿蜒如龙之意，龙，此乃因果绵延不断、国运生生不息的帝王之征！”</p><p>众人纷纷点头，深以为然。</p><p>麻将声中，道法自然。</p><p>而在这纷繁论道的中心，天柱峰最高处。</p><p>萧凡叶没有参与论道，只是静静站在那里，周身无一丝气息外泄。</p><p>却仿佛与整座天柱峰、与整片天地融为一体。</p><p>下方那些论道的修士，时不时抬头看他一眼，眼中满是敬畏。</p><p>人皇在此，道自生焉。</p><p>至于他在做什么，极少人知道。</p><p>萧凡叶在等待。</p><p>山道尽头，一道身影缓缓步来。</p><p>那是一个女子。</p><p>素雅长袍，青丝如瀑，面容清冷如玉。她走得很慢，每一步都踩在某种难以言喻的韵律，仿佛与天地呼吸同步。</p><p>她手中抱着一副棋盘。</p><p>棋盘古朴无华，木质纹理间隐约可见岁月痕迹。</p><p>但当它出现的瞬间，天地气息骤变！</p><p>所有修士的神识，在同一瞬间凝固！如同琥珀中的蚊虫，被生生定格在那一瞬！！</p><p>论道声戛然而止。麻将牌悬在半空。剑光拂影定格如画。</p><p>唯有萧凡叶，依旧负手而立，纹丝不动。</p><p>也唯有那女子，依旧缓步前行，一步步走向山巅。</p><p>从四面八方，从山石之后，从古松之间，甚至从路旁一株不起眼的野草之中——二十余道身影同时暴起！</p><p>他们身着各色服饰，手持各式法宝，刀枪剑戟、符箓灵光，齐刷刷向萧凡叶杀去！</p><p>剑气纵横！刀光如雪！符火纷飞！</p><p>所有攻击，结结实实轰在萧凡叶身上。</p><p>叮叮当当，一阵清脆的碰撞声响起，萧凡叶依旧负手而立，衣衫纹丝不乱。</p><p>发丝未曾飘动，连眼皮都没抬一下。</p><p>那些攻击落在他身上，如同雨打芭蕉，雨打石头，雨打花岗岩。</p><p>除了声响，什么痕迹都没留下。</p><p>那些偷袭者落在地上，面面相觑，眼中满是惊骇，似是惊叹这萧凡叶的修为如此之高！</p>
