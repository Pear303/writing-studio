# 天墟界的最后三日：星河弈道

<p>女子走到萧凡叶面前三丈处，停下脚步。</p><p>她抬起头，露出那张清冷如玉的面孔。那双眼睛中，倒映着萧凡叶的身影，也倒映着九百年的光阴。</p><p>“师尊，你晚来了二十年。”</p><p>“抱歉，这段日子有点忙。”</p><p>山风呼啸，卷动二十余人的衣袂，也拂乱了萧凡叶鬓角的发丝。</p><p>二十余道身影落地后迅疾后撤，与他保持着微妙的距离，似包围，又藏着几分不敢逾越的敬畏。</p><p>远处论道的修士，终于从神识凝固的状态中挣脱，面面相觑间无人敢妄动出声。</p><p>他们认出了这群人的身份：人皇座下。</p><p>传说中极少现世、修为深不可测，且与人皇有着隐秘羁绊的修道者。</p><p>而就在方才，他们竟行刺了人皇！</p><p>即便未伤人皇分毫，这份冒犯已是滔天大罪。懂地球神州历史者，此刻心中只剩风萧萧兮易水寒，壮士一去兮不复还的悲慨，这群大胆逆贼啊！</p><p>可萧凡叶立在原地，神色淡然，全无报复之意。</p><p>沉默被一柄幽冷灵光的刀打破。</p><p>持刀青年上前一步，刀尖斜抵地面，面容冷峻，眼神翻涌着复杂的情绪，开口时字字冰硬：</p><p>“师尊，又见面了。”</p><p>“师尊”二字被他咬得极重，藏着彻骨的恨意。</p><p>萧凡叶目光温和如旧：“二十年不见，你的刀意又精进了，再练两万年，或许便能威胁到我！”</p><p>他硬生生承受着青年的滔天杀意，半步未退。</p><p>这青年是半人半妖的遗孤，其父曾将师门出卖给妖物，致使小宗门被屠。</p><p>萧凡叶寻到他时，年仅十岁的他正躲在噬杀数十人族修士的妖母身后。</p><p>萧凡叶收养了他，亲传刀法，却也成了青年心中不共戴天的仇敌。</p><p>青年握刀的手微微发颤，别过脸沉声道：“下次定取你性命。”</p><p>“刺杀师尊，需徐徐图之，不可冲动。”一旁独臂青年冷声接话。</p><p>他不过弱冠年纪，已是元婴修为，其父母与舅父曾以妖术屠村炼魂，三千冤魂凝于幡上，最后被萧凡叶尽数斩杀。</p><p>他虽随时可重塑右臂，却始终留着空荡荡的袖管，是为时刻提醒自己。</p><p>萧凡叶轻叹：“是为师没教好你，让你误入歧途，失了手臂。”</p><p>独臂青年垂眸盯着袖管，唇瓣翕动，终是无言。</p><p>最后，是一名抱棋盘的女子缓步上前。</p><p>停在萧凡叶三尺之外，与他静静对视。</p><p>她是萧凡叶元婴之时，收的第一个弟子。</p><p>声音清冷如霜，却藏着极淡的波澜：“师尊，二十年了，弟子希望您的棋艺未退。”</p><p>她的眼中，有恨，有怨，有敬，有慕，也许还有藏不住的委屈。</p><p>“不会让你失望的。”他说。</p><p>然后他抬手，一挥。</p><p>化神期神通——乾坤挪移！</p><p>刹那间，天地倒转。</p><p>天柱峰、论道的修士、那二十几个弟子、甚至整片天墟界大陆，都在瞬间远去，缩小，化作视野尽头的一抹光点。</p><p>而当萧凡叶和那女子再次站稳时，他们已经置身于另一片天地。</p><p>星河之上。</p><p>脚下，是璀璨的银汉。无数光点汇聚成浩瀚的河流，在虚空中缓缓流淌。</p><p>那是真正的星河——由亿万颗恒星组成的银汉，在天墟界的宇宙中真实存在。</p><p>头顶，是更加深邃的虚空。</p><p>那里没有星辰，只有剩下诡谲万分的黑暗，以及黑暗中偶尔闪过某种难以名状的光。</p><p>而那女子怀中的棋盘，此刻已经飞出，悬于二人之间。</p><p>它开始扩张。</p><p>一寸，一尺，一丈，百丈，万丈——</p><p>眨眼间，那棋盘已经庞大到足以容纳数百颗恒星。棋盘上的线条纵横交错，每一条都粗如星河，每一条都在虚空中熠熠生辉。</p><p>女子站在棋盘一端，衣袂无风自动。她的气息，正在以恐怖的速度攀升。</p><p>元婴——化神——炼虚——合体——</p><p>天墟界此时此刻、天下第二的合体期！</p><p>天下第一当然就是他最敬爱的敌人，最痛恨的师尊，渡劫巅峰萧凡叶！</p><p>“徒儿，没想到这机缘迸发的二十年，你突破了合体期！”萧凡叶欣慰道。</p><p>“……”女子不语。</p><p>二人威压如同海啸般席卷开来，震动了周围的星河，让无数恒星的光辉都为之黯淡。</p><p>她抬手，向虚空中一抓。</p><p>九十一颗褐矮星被她从星空中摄来，如同九十一颗弹珠，乖乖悬浮在她掌心之上。</p><p>然后她挥手一斩。</p><p>九十一颗褐矮星，整整齐齐拦腰断成两截！</p><p>一百八十二颗半星，每一颗都被削成了规整的半球形，表面光滑如镜，内部翻滚着炽热的星核物质。</p><p>那些半星在她掌中旋转，慢慢变成黑色。</p><p>漆黑如墨，却又隐隐透着深邃的光。</p><p>一百八十二颗黑子！</p><p>萧凡叶微微一笑。</p><p>他也抬手，向虚空中一抓。</p><p>九十颗白矮星被他从另一片星域摄来。</p><p>那些白矮星比褐矮星更加致密，更加炽热，每颗都有数倍于太阳的质量，却只有地球大小。</p><p>他同样挥手一斩。</p><p>九十颗白矮星，整整齐齐断成两半。</p><p>一百八十颗半星，每一颗都被削成了规整的半球形，表面白炽如雪，内部燃烧着亿万年的星核之火。</p><p>那些半星在他掌中旋转，慢慢变成白色。</p><p>洁白如雪，却又透着炽热的光。</p><p>一百八十颗白子！</p><p>两人同时抬手，将手中的星辰棋子掷向棋盘。</p><p>轰——！！！</p><p>黑白两色在半空中相遇，爆发出足以照亮整个星河的璀璨光芒。那些棋子落在棋盘上，一颗颗嵌入那纵横交错的线条之中，每一次落下，都会引发整片星河的震颤。</p><p>星河弈道！</p><p>萧凡叶微微一笑，抬手，又是一抓。</p><p>被他摄来的白矮星随手炼成白子，拍在棋盘上。</p><p>那一子落下，整片星河都剧烈震颤了一下。</p><p>对面的女子面无表情，同样抬手一抓，摄来一颗褐矮星炼成的黑子，稳稳落下。</p><p>两颗棋子碰撞的瞬间，爆发出足以毁灭普通主序星的波动。</p><p>但在这星河之上，在那棋盘之中，那波动只是让周围的星辰微微闪烁几下，便消散于无形。</p><p>黑子与白子交织成复杂的图案，每一片棋形都蕴含着深奥道韵。</p><p>女子落子越来越快，脸上的清冷渐渐褪去。</p><p>萧凡叶始终从容，每一子落下都恰到好处，既不咄咄逼人，也不退让半步，就像这九百年里他对待这些弟子一样。</p><p>时间在星河之上流淌，不知过了多久。</p><p>棋盘上的黑白星辰已经占据了大部分空间，只剩下寥寥几个空位。那些棋子交织成的图案，复杂得让人头晕目眩，却又蕴含着天地浑成的美感。</p><p>终于，女子落下一子。</p><p>那一子落下，棋盘上某片黑棋的气瞬间被切断，三颗黑子从棋盘脱落，化作三颗黯淡星辰，消散在虚空中。</p><p>棋局在最后关头爆发出惊人的激烈。</p><p>那些星辰棋子疯狂碰撞与消亡，每一次落子都伴随着整片星河的震颤。</p><p>直到最后一子落下，棋盘上，黑白星辰定格。</p><p>女子怔怔地看着那盘棋，看着那些交织了九百年恩怨的星辰，看着那最终定格的局面——</p><p>她胜了。胜了半目。</p>
