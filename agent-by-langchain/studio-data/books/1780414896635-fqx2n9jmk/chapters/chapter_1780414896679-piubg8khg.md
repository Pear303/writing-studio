# 修仙界特产，域外天魔！

<p>龙佑只觉得头皮发麻。</p><p>【这污染究竟是啥玩意？】</p><p>但这还不够，他要知道，撞击世界的到底是什么。</p><p>他顺着天墟界最古老的时空，顺着那道贯穿维度的创口，将视线强行“翻”了过去，翻到了世界外壁之外。</p><p>天外光海一片纯白，没有时间，没有空间。</p><p>名副其实，被“光芒”的海洋包围。</p><p>方才与老登战斗，龙佑没空关注周围环境。</p><p>现在闲下心来，他发现自己对“天外光海”的本质是何物，竟然难以形容！</p><p>如果非要加以描摹，此番景象，就似一场急剧扩张的「惊天爆炸」！</p><p>漫无边际的「天外光海」，便是这场爆炸不断向外翻涌延展的炽烈焰浪！</p><p>无数世界，无数宇宙，在爆炸的火焰中被烘烤了不知多少亿年！</p><p>天墟界类似一座水泥小房子，能在这场爆炸中勉强保存，甚至有0.00009191%的巨额概率，能反过来利用界外的“天光”修复自身本源。</p><p>【似乎是因为天墟界的维度、法则、时空结构，让它能够承受「天光」中劫灭与抹杀的意志。】</p><p>“就像结构简单的金属矿物会被氧化。而结构极其复杂的‘碳基生物’，却能反过来利用氧气来呼吸、繁衍。”</p><p>龙佑身形纹丝不动，太乙仙体在他体内轰鸣运转，将那股劫灭之意层层化解。</p><p>他站在纯白虚空中，目光穿透那层层叠叠的毁灭意志，开始搜寻此行的真正目标——</p><p>域外天魔的来源。</p><p>在天墟界外壁上，确实趴着一团……呃，一坨巨大的东西。</p><p>那是一大摊红黑色的不知何物。</p><p>它暗红与漆黑交织，像半凝固的血块，又像一堆正在腐烂却仍有生命的烂肉。这摊红黑色的浆液吸附在天墟界外壁上，表面不断起伏，如同缓慢呼吸。</p><p>无数肉红色的细须从它体内伸出，像树根一样深深扎进世界外壁的裂缝里，正在贪婪地吮吸着从裂缝中逸散的精气。</p><p>它蠕动着，每一次蠕动，都会向世界内部挤出一丝细小的黑色流质。</p><p>流质顺着时间长河流淌，最终成为万年一劫的天魔潮！</p><p>这一团红黑色的粘稠物质，同样被毁灭性的天光冲刷着。</p><p>但其外壳被湮灭的速度，似乎跟不上内腔生长增殖的效率。</p><p>龙佑再次将视线拉高，俯瞰天墟界在光海中的位置，并沿着时间长河观察它诞生以来的运动轨迹。</p><p>他看到了。</p><p>那次撞击，给天墟界带来了微小的“动量”。</p><p>就像一颗台球被另一颗球撞了一角，天墟界在诞生之初，就被这摊红黑色物质撞偏了原本的位置，开始缓缓漂移。</p><p>那动量极小，界内生灵根本无法察觉。但在无尽的岁月中，再微小的偏转，也足以改变命运的轨迹。</p><p>一年，百年，千年，万年，十万年——</p><p>龙佑看着天墟界在光海中缓慢移动，穿过一片又一片虚空，沿着那撞击赋予的动量方向，缓慢而坚定地漂去。</p><p>他眯起眼，看向那个方向。</p><p>那个方向的尽头，是一片由无数星系、星团构成的庞大宇宙。大尺度丝状结构，超星团，河系，恒星系……</p><p>亚洲，神州，担担面，卤水烧鸭……</p><p>……啊？被撞飞的天墟界……撞向了地球所在的宇宙！</p><p>正是这次诞生之初的撞击，正是这摊趴在世界外壁上的红黑色物质，让天墟界获得了漂向地球的“动量”！</p><p>两个世界，正在虚空中缓缓靠近，最终撞在了一起！</p><p>连环追尾！</p><p>‘按照地球与天墟界内部的变化，大致判断相撞的的时间……是地球的3年前，天墟界的900年前。’</p><p>萧凡叶，2023年5月14日子时，穿越。</p><p>就像两个挨得太近的池塘，水面震颤时，就会有水滴溅到对方那边。</p><p>【因为两个世界碰撞，地球人类穿越至天墟界：95.55%】</p><p>龙佑看着那个数字，若有所思。</p><p>95.55%，不是100%，说明还有少数穿越者的出现与这场碰撞无关，或许有其他原因，或许是其他世界的牵引。</p><p>但至少绝大多数穿越者，都源自地球宇宙、天墟界之间的碰撞。</p><p>就像萧凡叶。</p><p>那天晚上，他正在公司加班，眼前一黑，醒来时已经躺在天墟界的破庙里，浑身是血。</p><p>碰撞是双向的。</p><p>地球人穿越到天墟界，那天墟界的土著呢？</p><p>会不会也有“反向穿越者”？</p><p>他停下脚步，时间长河再次展开。</p><p>【天墟界土著穿越至地球宇宙存在：99.99…%】</p><p>龙佑眉头一挑。</p><p>就在此时此刻，地球宇宙深处的某个角落，几乎是‘必然’藏着一位天墟界的土著。</p><p>而在未来，也注定会有新的天墟界来客跨越星河与维度，降临地球。</p><p>“这么多非法偷渡移民啊！”</p><p>【偷渡就偷渡呗，又不是他们主观所为。】</p><p>“但客观上导致两个世界出现穿越者的罪魁祸首，还是袚除了比较好。”</p><p>龙佑站在纯白虚空中，目光落在那层附着于天墟界外壳上的污浊黑血。</p><p>那东西还在蠕动。</p><p>即使经历了无尽岁月，即使被那滴血的源头抛弃了不知多少年，它依然活着，依然在吮吸和增殖。</p><p>“看着碍眼。”龙佑喃喃道。</p><p>如果一个东西能够自发的无限增殖，并且能自行长出眼睛和触手，那它怎么看都是对人体、对环境特别有害。</p><p>他抬手，太乙真仙的浩瀚法力轰然涌出，化作一道炽白火焰——</p><p>【太初烬灭炎】</p><p>那是足以焚尽法则、燃尽时空的仙火。火焰触及那层黑血的瞬间，黑血剧烈扭曲起来，发出刺耳尖啸。</p><p>但在太乙真仙级别的仙火面前，它的反抗如同螳臂当车。</p><p>黑血开始焚化。</p><p>一层层焦黑剥落，化作虚无。</p><p>甚至还发生了类似美拉德反应的东西，总之看起来挺诱人。</p><p>然而！就在黑血即将被彻底焚尽的瞬间，龙佑眉头一皱。</p><p>那火焰，竟然顺着黑血与天墟界的连接处，渗入了世界裂缝！</p><p>“不好。”他连忙收手，但已经晚了。</p><p>一缕太初烬灭炎透过那道细如毫毛的裂缝，钻进了天墟界内部。</p><p>龙佑神识一扫，看见那缕仙火正在天墟界的虚空中游荡，所过之处，空间都在微微扭曲。</p><p>他连忙换了一种神通。</p><p>【太乙玄清神雷】</p><p>雷霆轰鸣，化作亿万道细密的雷光，将那层残余的黑血笼罩其中。</p><p>雷光炸裂，黑血再次被磨灭——</p><p>但雷光同样漏过了裂缝。</p><p>界壁震荡，天墟界内部，无数修士惊恐地抬头，看见天空中凭空炸开一道道惊雷，虚空都在颤抖！</p><p>龙佑收手，站在纯白虚空中，盯着那层顽固的黑血残渣，陷入了沉思。</p><p>这玩意儿还挺倔。</p>
