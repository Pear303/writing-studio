# 概率操控能力

<p>内容很简单，语气也极其平淡，就像是一个普通的多年未见老同学在处理琐事：</p><p>「咳咳，恭喜你获得新生。绝对不是催还钱，我根本不记得这档子事。」</p><p>「只是上个月，我家父的舅舅的养子救了一位阿拉伯老土豪，如今我便继承了百万家产，有些个人创业的小小打算。」</p><p>「如果有合伙打算，便邮件联系我吧，照顾老同学嘛。」</p><p>这一刻，姜笙看着这行字，脑海中的猜想上升到了令她头皮发麻的高度。</p><p>「……恭喜你获得新生。」</p><p>没错，确实是龙佑给予了她新生。</p><p>「……有些个人创业的小小打算。」</p><p>那什么阿拉伯老土豪、继承百万家产，这种一眼假的借口，只有可能是掩人耳目的说辞。</p><p>‘他在给予我力量的同时，也给予了我相应的权责。’</p><p>‘就像大拇指是5个手指中最粗壮的，它的职责便是辅助另外4根手指，握紧水杯……’</p><p>简而言之，姜笙知道，龙佑要她办事。</p><p>自己获得天人合一力量的代价，便是完成工作。</p><p>「……便邮件联系我吧。」</p><p>最后这一句，更是意味深长！</p><p>‘为什么偏偏是邮件！？’</p><p>在这个V信秒回、电话即达的时代，普通人交流谁会用电子邮件！</p><p>先前姜笙找他借钱用的，也是V信。</p><p>除非……这种交流需要具备某种「人类社会的契约效力」。</p><p>姜笙的思维飞速运转。</p><p>“在神州社会的法律体系中，‘电子邮件’是法律认可的书面形式之一，可以作为法庭证据，确立合同关系，构建商业机密。”</p><p>电子邮件，意味着正式的契约、律法。</p><p>姜笙深吸一口气，看穿了龙佑的布局。</p><p>“他强调通过更具‘法律效力’的邮件来联系，意思是……我的‘工作’，必须遵守人类社会的世俗规则。</p><p>“正所谓大隐隐于市，最完美的伪装便是合法。</p><p>“他要创办一个‘组织’。这个组织不会是躲在深山老林里的修仙门派，也不会是见不得光的地下结社。</p><p>“而是一个符合人类法律、有正规执照、纳税经营、甚至可能上市的组织。”</p><p>姜笙握着手机，手心全是冷汗。</p><p>他究竟在布一个怎么样的局？</p><p>而自己，处在什么位置？</p><p>……</p><p>龙佑笑眯眯地看着手机。</p><p>“另一个我，你说我这‘霸道总裁’的人设，有没有在姜笙心里立住？”</p><p>【完全不像，倒像是金发双马尾傲娇。】</p><p>【话说你为何强调电子邮件？】</p><p>龙佑说道：“因为我打算出趟远门。”</p><p>那地方“很远”，手机完全收不到信号，国际漫游也没用，打电话是打不过来的。</p><p>潜意识：【为何不用V信和扣扣？它们也能够延迟接收信息。】</p><p>“你应该记得，有时在办公的时候，手机接收的V信信息，在电脑上显示不出来；电脑上接收的扣扣信息，则在手机上显示不出来。”</p><p>“聊天记录踏马会被卡顿的WiFi给吞了。”</p><p>【V信和扣扣……确实偶尔会抽风。这么看来，电子邮件挺靠谱。】</p><p>【话说你要去哪里？】</p><p>去哪个“远门”？远到连国际漫游都接不到？</p><p>龙佑笑道：“咱打算去异世界看看。”</p><p>【姜笙病逝后去往阴间/冥界/地府：8.112e-79】</p><p>【姜笙病逝后穿越至异世界：0.001551%】</p><p>【姜笙病逝后，重生回自己被高中校霸欺凌的前夜：2.133e-87】</p><p>这是他先前曾看到过的概率。</p><p>龙佑：“这世上真会存在封建迷信的阴曹地府，存在五花八门的异世界？真会有人有概率重生到十年前？”</p><p>【万事皆有可能。看起来去往阴曹地府或者穿越到十年前，难度远远高于“穿越异世界”。】</p><p>“所以，人死也是真有概率穿越异界！”</p><p>【没错，万事皆有可能。】</p><p>【比如你脑海中纷杂的念头，各种无意识也能组成一个能够对你问题回答如流的我。】</p><p>【猴子随机敲键盘，打出一部莎士比亚全集的概率也不为零。】</p><p>龙佑在脑海中咀嚼着这句话。</p><p>让一只猴子在打字机上随机敲击，只要时间足够长，它总有一天会敲出哈姆雷特的全文。</p><p>不是“可能”，是“必然”，因为无限的时间会让所有可能发生的组合都发生一遍。</p><p>当然，现实中没人真这么干过。</p><p>猴子会累，打字机会坏，纸会用完。</p><p>但理论上，它是对的……应该。</p><p>【你明白我想说什么了？】</p><p>“明白。”龙佑点点头，“我看到的‘概率’，本质上就是这种无限可能中的筛选。”</p><p>【没错。姜笙病逝后穿越的概率是0.00001551%，意味着每645万左右的地球死者中，就有一个会穿越。】</p><p>【这不是“运气”，是数学——是宇宙尺度的猴子打字机。】</p><p>龙佑若有所思。</p><p>“在穿越之前，让我先搞明白，我的能力边界在哪里？”</p><p>他低头看向自己的手心，意念微动，一枚硬币凭空凝成——量子真空中随机涨落的粒子，被他用概率操控捏成了实物。</p><p>【想做什么实验？】</p><p>“测试一下，看看‘概率’这个东西，到底有多精确。”</p><p>【正面概率：50.00000000000001222%】</p><p>【反面概率：49.99999999999998776%】</p><p>【其他概率：0.00000000000000002%】</p><p>这里的“其他概率”，大致是通向“硬币侧立在地上”“硬币被鸟叼走”“硬币掉进裂缝消失不见”等等乱七八糟的结果。</p><p>龙佑眨了眨眼。</p><p>【看到偏差了？】</p><p>“嗯。”他盯着那个小数点后十几位的数字，“所以理论上50%的概率，实际上并不是严格的50%？”</p><p>【当然不是。】</p><p>【硬币的形状、质量分布、地面的平整度、空气流动、地球自转、太阳引力……】</p><p>【无数个因素叠加在一起，让每一次抛掷都不是理想状态下的“完美随机”。】</p><p>【还有可能硬币在决胜出正反面前，地球突然爆炸导致硬币被殃及池鱼……】</p><p>【一切都是概率问题。】</p><p>龙佑伸手接住落下的硬币，是正面。</p><p>他又抛了一次，但这次动用了能力。</p><p>【这枚硬币落地时正面朝上：50.00000000000005444% → 50%】</p><p>硬币落下，反面。</p><p>龙佑捡起来，又抛。正面。反面。正面。正面。反面。</p><p>他连续抛了一百次。五十二次正面，四十八次反面。</p><p>然后把数据输入脑海中的虚拟计算——二项分布，期望值50，52次正面大概在正常范围。</p><p>【并不严谨。如果要验证“抛到正面”概率是严格意义的50%，小数点后没有跟几千或者几百亿个零的误差，你抛到世界末日也无法验证。】</p><p>龙佑咧嘴笑了笑：“那我只能‘确信’在我能力的干扰后，这枚硬币在任何情况下抛到正面的概率都是‘严格的50%’。”</p><p>【呵？相信的心就是你的魔法？】</p><p>【行吧。】</p>
