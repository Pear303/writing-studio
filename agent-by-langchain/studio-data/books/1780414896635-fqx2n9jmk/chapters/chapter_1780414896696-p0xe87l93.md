# 这还是国内吗

<p>小蓝活动了一下脖颈，发出咔咔声响：</p><p>“龙佑先生，你拥有的超人力量让我们望尘莫及。</p><p>“但面对诡兽，在下仍然要提醒一句——这种不知能否被称作‘生物’的东西并不简单。</p><p>“它们虽然有常规生物的特征，但不能套用常规生物的常识和知识应对！”</p><p>他顿了顿，目光紧盯着那头蠕动的漆黑之物：“比如眼前这怪物，即使是爆了头也不会死。”</p><p>话音未落！</p><p>林云猫娘根本没反应过来，戴着墨镜的粉毛小光就已经消失在原地。</p><p>下一瞬，她出现在那诡兽身侧！</p><p>双手如刀，切入那怪物扭曲的颈部的瞬间，猛地一拧，那颗布满眼睛的头颅被她生生摘了下来！</p><p>落地，一脚踩爆！汁液四溅，腥臭扑鼻。</p><p>然而，那头无头诡兽还真的没死。</p><p>它庞大的身躯原地狂怒，无数条触手从断裂的颈部疯狂涌出，朝小光扑杀而去！</p><p>小光身形暴退，但那触手速度更快——眼看就要缠上她的脚踝！</p><p>【诡兽的触手即将缠住小光：90.5566%】</p><p>【地球也是有奇人异士的嘛，触手缠上去的概率居然仅仅只有90%】</p><p>【修改！诡兽的触手即将缠住小光：0%】</p><p>触手缠了个空。</p><p>小光在千钧一发之际脚下一滑，滑了一跤，整个人以极其不优雅的姿势仰面倒地，却恰好躲过了那致命一击。</p><p>她躺在地上，墨镜歪到一边，露出那双写满茫然的眼。</p><p>“……我刚才，滑倒了？”</p><p>林云猫娘站在面包车旁，尾巴已经炸成松鼠状：“这玩意没头还能打？！这什么物种！还真不符合生物学啊！”</p><p>龙佑没理会他的吐槽，目光落在那头诡兽身上。</p><p>它没有因为失去头颅而衰弱。</p><p>相反，那些从断颈处长出的触手越来越多，越来越长，在隧道空间里疯狂挥舞！</p><p>每一次挥击，都会在墙壁上留下深深的沟壑，混凝土碎块四处飞溅。</p><p>小蓝已经冲了上去，双手泛起淡淡的蓝光，一拳轰在诡兽躯体上。</p><p>轰！诡兽被轰退数丈，躯体上炸开一个大洞，漆黑的液体喷涌而出。</p><p>但那洞口几乎瞬间就开始愈合。</p><p>“看到了吗？”</p><p>小蓝退到龙佑身边，喘着粗气，“常规物理攻击，效果有限。我们需要找到它的‘核’。”</p><p>“核？”</p><p>小蓝点点头，一拳逼退又一批涌上来的触手，快速解释道：</p><p>“诡兽都有一个‘核’。类似于它们的心脏、大脑、灵魂、动力源——随便你怎么理解。只有击碎那个核，才能将其本体彻底毙杀。</p><p>“击碎‘核’之后，核附近的晶体会留下来。那东西能采集能吸收，能作为异人进化的材料——效果比什么天材地宝都管用。</p><p>“龙组这么多年能稳住局面，靠的就是这些晶体培养出来的异人。”</p><p>林云猫娘站在面包车旁，尾巴本来是炸毛状态。</p><p>听完这话，炸得更厉害了。</p><p>“核？晶体？击杀诡兽掉落材料？还能吸收进化？”</p><p>“这是什么老套都市异能文设定啊喂！！”</p><p>疯狂挥舞的触手抽向小蓝，又抽了个空。</p><p>那些触手在即将碰到他的瞬间，莫名其妙地偏转了方向，抽向空气。</p><p>“小光，别演了，赶紧结束战斗吧。”</p><p>粉毛墨镜的小光在空中翻了个身，那一瞬间，时间仿佛慢了半拍。</p><p>然后她的右腿扫出一道弧线——</p><p>轰！疯狂挥舞的触手，扭曲狰狞的血肉，密密麻麻的眼睛，那头诡兽剩下的一半躯体在小光这一记回旋踢下，直接炸成齑粉。</p><p>这一回旋踢并不止于此！</p><p>能量是会相互转化的。就像香肠加工厂里的搅拌机，刀片高速旋转搅碎肉泥，机械能转化为热能，肉会发热。</p><p>所以工厂得用冰水降温，防止搅拌的肉泥半途就熟了！</p><p>小光这一踢，同样如此！</p><p>庞大的动能踢腿、瞬间转化为巨量热能！</p><p>诡兽连带着空气被急剧加热膨胀，像炸药点燃，隧道里炸开一团炽白火球！</p><p>冲击波呈环形扩散，混凝土墙壁剥落粉碎，那些挤在隧道尽头的诡兽群被掀飞，几十头诡兽像破布娃娃般抛向后方！</p><p>林云猫娘下意识闭上眼睛，但想象中的灼烧感并没有出现。</p><p>她睁眼。小蓝站在原地，一只手插兜，另一只手随意地抬起，激发出淡蓝色的屏障。</p><p>屏障护盾挡在他们身前，将爆炸火焰和冲击波尽数隔绝。</p><p>屏障边缘，火焰像流水般滑过，连一丝热量都没漏进来。</p><p>“这……这就是龙组？”</p><p>从一个普通人变成猫娘，再被卷入这种超自然战斗现场，一共用了不到四小时。</p><p>‘这展开速度是不是有点太快了？！’</p><p>‘正常小说怎么也得铺垫个十几章吧？！’</p><p>猫娘脑子里刚完成吐槽，小光已落回地面，拍了拍手上并不存在的灰，朝这边小跑来。</p><p>爆炸的火光渐渐散去，隧道地面留下一道焦黑的放射状裂纹。</p><p>但隧道尽头露出的景象，让林云猫娘刚刚燃起的“也许能活着出去”的希望熄灭。</p><p>密密麻麻，只能用这个词形容。</p><p>隧道尽头的空间里，挤满了那些东西。</p><p>奇形怪状，浑身流淌着纯黑色的粘液，每一只的身体结构都像是几头，甚至几十头，不同动物强行拼接在一起。</p><p>有的像是熊和章鱼的混合体，有的干脆就是一团不断蠕动的肉，表面时不时睁开几只眼睛。</p><p>它们挤在那里，层层叠叠，密密麻麻，一直延伸到视野尽头。</p><p>“啊我命休矣——”</p><p>林云喃喃道，“中道崩殂，折戟沉沙，壮志未酬身先死，常使英雄泪满襟……”</p><p>“妹子闭嘴。”小光头也没回，但语气里带着点无奈，“还没死呢。”</p><p>小蓝一边后退，一边弯腰捡起地上那扇被踹飞的面包车门，对准面包车的门框按回去。</p><p>“地球的事物有可能卡进异常折叠空间。</p><p>“那么也就说明，异常折叠空间里的这些诡兽，也有可能反过来入侵地球。</p><p>“所以，龙组成员在不慎卡进异常折叠空间后，最好就地将它们解决。</p><p>“幸好，事实证明它们虽然诡异，但还是挺怕核弹的。”</p><p>林云猫娘刚被拎着后脖颈往车上塞，听到这话忍不住回头：“怎么就扯到核弹上了？！”</p><p>啪嗒，她手里多出一包东西。</p><p>林云低头一看，是一包食盐。</p><p>加碘的，净含量400克，生产日期挺新鲜。她愣了一秒，迅速把那包盐塞进衣服口袋里，动作快得像什么都没发生。</p><p>‘什么情况？’</p><p>‘我脑子里刚想吐槽，手里就多出一包盐？’</p><p>‘这是什么能力？吐槽能量实体化？’</p><p>‘而且为什么是盐啊！这能力有什么战斗力可言吗！让敌人高血压吗！’</p>
