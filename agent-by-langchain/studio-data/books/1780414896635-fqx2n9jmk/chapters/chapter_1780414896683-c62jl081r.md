# 天墟界的最后三日：天虚道人

<p>剑光如雪，铺天盖地！</p><p>那一瞬间，萧凡叶眼中只剩白茫茫一片——那是足以斩断星河、碾碎法则的绝世剑意，凝聚了渡劫巅峰大圆满三万年的全部道行！</p><p>天虚道人立于九天之上，白发狂舞，周身环绕着三万年来参悟的无数大道虚影。有星辰生灭，有日月轮转，有混沌初开，有万物归墟。</p><p>这一剑，是他压箱底绝学，大罗天湮灭剑！</p><p>狮子搏兔，亦用全力！</p><p>“能死在本座这一剑下，是你的荣幸！”</p><p>剑光淹没一切，方圆数百光年的星云在这一剑下尽数湮灭。</p><p>无数恒星在这一刻熄灭，无数虚空裂缝如同蛛网般向四面八方蔓延。</p><p>萧凡叶的身影，彻底消失在那白光之中。</p><p>天虚道人收剑而立，目光如炬，死死盯着那片正在缓缓愈合的虚空裂缝。</p><p>他没有放松警惕。</p><p>萧凡叶很有可能继承了天墟真人的遗物——那可是太乙真仙的遗物！难说没有反败为胜的绝世至宝。</p><p>他必须确认对方彻底灰飞烟灭，连一根头发都不剩！</p><p>剑光散去，天虚道人的瞳孔猛然收缩。</p><p>那片虚空中，一道身影静静悬浮。萧凡叶。</p><p>他果然还活着。他居然还活着！</p><p>浑身上下没有一处完整的皮肤，鲜血淋漓，骨骼碎裂，内脏外露，但确实未亡。</p><p>那头乌黑的长发，依旧在虚空中飘扬。</p><p>天虚道人全力一击，足以斩杀同境界的渡劫巅峰！怎可能杀不死一个蛐蛐渡劫中阶三层的后辈？！</p><p>说明对方身上，真有太乙真仙的遗物护体！</p><p>天虚道人眼神一凛，正要再出一剑，然后他愣住了！</p><p>萧凡叶的气息，正在疯狂飙升！</p><p>渡劫中阶三层……渡劫中阶九层……渡劫中阶九层后期……渡劫中阶九层后期巅峰……渡劫中阶九层后期巅峰大圆满！！</p><p>萧凡叶仰天长啸，周身气息暴涨十倍不止！方圆亿万里的天地灵气如同疯了一般向他涌来，在他头顶形成一个巨大的灵气漩涡！</p><p>那漩涡旋转着，咆哮着，将沿途所有星云、尘埃、甚至光线都吞噬其中！</p><p>然后，灵气漩涡猛地收缩，尽数灌入萧凡叶体内！</p><p>萧凡叶睁开眼。</p><p>那双原本漆黑的瞳孔深处，此刻浮现出淡淡的金色光芒。</p><p>渡劫高阶一层！</p><p>天虚道人面色凝重，身形暴退百丈！</p><p>“不可能！这绝不可能！”</p><p>他声音发颤，眼中浮现出震怖，“你、你明明被我重创，怎么可能临阵突破？！”</p><p>萧凡叶低头看了看自己的双手。</p><p>那些狰狞的伤口，正在以肉眼可见的速度愈合。肌肉蠕动，骨骼重生，血管重连——不过几息之间，他的身体已然恢复如初，甚至比之前更强！</p><p>他抬起头，看向天虚道人。</p><p>“你刚才说，我是靠陨落真仙的遗物才能一日千里？”</p><p>萧凡叶握紧归乡剑，剑身嗡鸣，气息也在同步飙升——渡劫高阶的本命道器！</p><p>“那你有没有想过……”他缓缓开口，“那个真仙是怎么陨落的？”</p><p>天虚道人瞳孔剧烈收缩。他当然想过。</p><p>二十年前，天墟真人突然暴毙，太乙果位空悬。</p><p>整个天墟界都在猜测，那位独占了十二万九千六百年果位的老怪物，究竟是怎么死的。</p><p>有人说是走火入魔，有人说是被天道反噬，有人说是触犯了某种禁忌——</p><p>但从来没有人想过，是被杀死的。</p><p>因为天墟真人是此界唯一真仙。</p><p>谁能杀死一个真仙？</p><p>萧凡叶看着他，一字一句道：“天墟真人，是被杀的。”</p><p>“放屁！”天虚道人厉声喝道，“你二十年前才刚突破渡劫！怎么可能杀得了太乙真仙？！”</p><p>萧凡叶没有解释。</p><p>他只是想起二十年前，那团人形黑雾一巴掌将天墟真人拍落太乙真仙境的画面。</p><p>他只是说“被杀的”，又不是“我杀的”。</p><p>而说出此番话，是为了让对方——不要跑！</p><p>果然，那天虚道人闻言，原本瞳孔地震震怖不已的面容上，瞬息切换为冷酷的平静。</p><p>“你在虚张声势，试图狐假虎威——尽管你背后的‘虎’并不存在。</p><p>“萧人皇，我已经嗅到你心虚的味道。</p><p>“以天墟真人倪下的力量，绝对、不可能、是被‘他人杀害’。</p><p>“至于他为何仙逝，已经不甚重要了，此刻我必须将心意拧成一股，全神贯注来屠杀你！</p><p>“你原本是想把我吓跑，可现在我反其道而行之！我反而已不再惧你了！</p><p>“将你这个用不知何等外道邪术、疯狂突破境界的邪道，扼杀于摇篮！”</p><p>萧凡叶没有再说话，只是握紧归乡剑，剑身嗡鸣，剑气冲霄。</p><p>天虚道人眼神一凛，抬手虚按，两道身影在虚空中轰然碰撞！</p><p>两人同时暴退千丈，又在下一瞬同时杀回！</p><p>剑光如雪，掌印如山！</p><p>一息之间，百次碰撞！</p><p>十息之间，万次交锋！</p><p>百息之间，百万回合！</p><p>虚空在他们身后崩塌又重组，星辰在他们脚下湮灭又重生。方圆上千光年的星域，此刻已成一片混沌——没有光，没有暗，没有时间，没有空间，只剩两道身影在其中疯狂厮杀！</p><p>萧凡叶剑势如虹，每一剑都带着渡劫高阶一层的全力一击！</p><p>归乡剑斩出，剑光所过之处，连法则都在颤抖！</p><p>但天虚道人的掌印更猛。</p><p>三万年的积累，三万年的沉淀，三万年的道行——那不是靠机缘能弥补的差距！</p><p>“小辈！”</p><p>天虚道人一掌拍出，遮天大手印轰然落下，“你以为突破到高阶，就能与本座抗衡？！本座在高阶时，你还没出生！”</p><p>萧凡叶横剑格挡，整个人被拍飞万丈，又在下一瞬稳住身形，再次杀回！</p><p>他咬着牙，一言不发。</p><p>对方说的是实话。天虚道人突破高阶，可能是万年前的事情了，而那时，萧凡叶甚至还没形成受精卵。</p><p>九百年来，他经历过无数次生死之战。每一次，他都是用这种死磕到底的劲头，硬生生撑过来的！</p><p>但这一次不同。</p><p>这一次的对手，比他多活了两万九千多年。</p><p>两万九千年的积累，两万九千年的沉淀，两万九千年的道行，不是靠意志能弥补的差距！</p><p>三百万回合后，萧凡叶浑身浴血，大口喘气。</p><p>他的剑势已经乱了，步伐已慢，灵力更是接近枯竭。</p><p>而天虚道人，依旧气息如渊，深不可测！</p>
