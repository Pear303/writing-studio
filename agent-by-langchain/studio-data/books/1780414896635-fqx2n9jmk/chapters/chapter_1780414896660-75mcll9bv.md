# 斩断因果出趟远门～

<p>万米高空。</p><p>龙佑正开启了光学隐形、电磁迷彩，甚至包裹了一层真空泡，以此隔绝音爆和空气摩擦。</p><p>虽然这套“隐身套餐”万无一失，但他总觉得每次飞都要开这么多开关，繁琐得像个刚学会装机的DIY爱好者。</p><p>但这种程度的麻烦只是小事。</p><p>另一种麻烦则在疯狂折磨这个超人的神经。</p><p>“龙先生，钱到了账就是闲钱啊，放在卡里活期利息太低相当于贬值啊！我给您推荐个刚出的理财产品，‘稳赢宝’年化收益率4.5%，起存五万，保本保息……或者您买点储蓄保险？给未来存个养老钱？”</p><p>“不了。这钱我有急用，暂时不动。”</p><p>“龙先生，理财是为了钱生钱……”</p><p>“谢谢，我就喜欢看银行卡余额数字的那种安全感。”</p><p>“没事儿，我们还有‘活期宝’！就是针对您这样需要频繁动用现金流的客户，您的钱存进去后也能够随时取出……”</p><p>“不要……”</p><p>“喂，龙先生吗？我是县里X桂园的置业顾问，恭喜您获得购房……”</p><p>“不买……”</p><p>“龙先生恭喜发财，我是XX理财的，有一款内部基金……”</p><p>“混蛋，咋知道我电话号码的？”</p><p>“喂，龙先生？保险了解一下吗？防癌防意外防老防暴毙……”</p><p>可恶，明明自己前几年打工的时候，打给自己的只有催缴话费、水费、电费和X呗还款的冷冰冰机器人语音。</p><p>如今一朝农奴翻身把歌唱，这世界的恶意就像吃了天竺街边摊窜稀后闻讯而来的苍蝇，蜂拥而至。</p><p>他琢磨了一阵子，直接调出了那个万能的概率面板。</p><p>“既然觉得麻烦，那就一步到位，如果我把自己的‘信息’无法被探测的概率，设为100%……”</p><p>潜意识立刻弹出警告。</p><p>【你确定嘛？如果将“信息无法被探测”设为绝对，您在地球上将成为完全的“黑户”。】</p><p>“这难道不是好事。”</p><p>龙佑烦透了骚扰电话。</p><p>【因为无人能与你发生任何相互作用，包括电磁相互作用。】</p><p>【一切电磁波无法照射你，你无法被任何人目击。】</p><p>【甚至，你将无法与万物包括地球的引力产生相互作用。】</p><p>【这意味着你可能会直接被地球自转的惯性甩向太空，又或是依托其他坐标系，甩出地球，甩出太阳系，甩出银河什么的。】</p><p>【物理世界的四大基本相互作用，从此与你无缘……】</p><p>龙佑听得头大：“好麻烦呐，重新设定。”</p><p>【并非基于我主观想要暴露的信息，就无法被探测：100%】</p><p>何为“主观想要”？这种模糊的指令，居然也能调控概率。</p><p>【您真把这概率操控能力玩成心想事成、言出法随了？】</p><p>龙佑笑着回应：“这才是正确使用方法罢，省心省力。”</p><p>……</p><p>姜笙猛地从那种玄妙的境界中抽离出来，冷汗直流，后背的睡衣都被浸透了。</p><p>“我为什么看不到他的过去未来？为什么看不到他的任何额外‘信息’？为什么在‘天人合一’全知全能的视角里，唯独他是一个黑洞？”</p><p>她回想起龙佑在天上以20马赫狂飙的景象，回想起他在医院外五公里处，那如神明般冷漠的注视。</p><p>最后回想起的，是自己莫名其妙天人合一。</p><p>令人战栗的猜想在她脑海中疯狂生长。</p><p>“手术……根本不是手术。”</p><p>“所谓的‘天人合一’，也不是医学意义上的奇迹。”</p><p>“是他……是他把自己的一部分‘力量’，或者是某种更高层次的‘东西’，分给了我。”</p><p>姜笙手指微颤，死死抓着床单。</p><p>一个在沙滩上玩沙子的幼孩，偶然间踏入了花园。</p><p>巨人只是路过，甚至顺手给了孩子一颗糖。</p><p>巨人继续赶路，消失在孩子无法理解的维度。</p><p>姜笙紧张地咬手指。她一紧张便会下意识做这种小动作，直到如今天人合一，这习惯仍未改变。</p><p>她看向无穷无尽的宇宙。</p><p>以及代表着宇宙的过去，现在和未来的光阴长河。</p><p>她看到长河上方，如同树枝般疯狂蔓延生长分裂的世界线……</p><p>虽然姜笙看不到龙佑额外的“信息”。</p><p>但她俯视这无穷无尽的世界线，仰观无垠无边的光阴长河，仍然靠着敏锐的洞察，发现龙佑留下的蛛丝马迹。</p><p>在极短时间内，就是这几天时间——整个宇宙的世界线，发生了两次大幅变动。</p><p>其中一处变动，她看不清是什么变化——说明与龙佑相关。因为与他有关的信息，绝大部分都被屏蔽。</p><p>‘龙佑大幅修改了世界线，让一个极低概率的世界线成为现实……他做了什么？’</p><p>而另一处世界线的巨变，则与自己有关。</p><p>是她在进行“实验性疗法”前不久发生的。</p><p>“手术失败、我死去的世界线全部被毙掉……”</p><p>“我百年内死亡的世界线同样被枪毙……”</p><p>“以及……只留下我‘天人合一’必定发生的世界线存在。”</p><p>姜笙被龙佑的手段整得有些麻了。</p><p>现有的世界线中，她完全看不到自己“天人合一失败”的世界线存在！</p><p>没有！ZERO！0%的概率失败、100%绝对概率的天人合一！！</p><p>那个神秘的男人，为何要赐予她这般力量？仅仅是因为高中三年的同学情分？</p><p>不！绝不可能！！</p><p>如今已然站在世界之巅、与天地同齐的姜笙，又怎会不懂那些超凡强者的心境？</p><p>姜笙看得透彻——不止是地球。</p><p>在这浩瀚无垠的宇宙深处，在无尽漫长的时间长河里，在无数条交错并行的世界线中，各个种族、无数文明里，都曾诞生过伟力堪比神明的至强者。</p><p>而早已天人合一的她，本身就是天地。</p><p>她曾「亲历」过那些异族强者的一生，也参悟透了全宇宙所有登临绝顶之人的共同心境。</p><p>而全宇宙，有一条出奇一致的铁律。</p><p>“能力与权责对等。”</p><p>姜笙咔嚓一声，将自己的大拇指咬断，又随手大拇指接回原位。</p><p>即便她早已天人合一，可少了一根拇指，握紧水杯的难度，终究还是会多出一丝……</p><p>大拇指的作用，是握紧水杯……</p><p>能力与权责，本就对等。</p><p>龙佑……他赐我无上力量，是要我承担与之对等的「责任」。</p><p>就像智人长出大拇指，就是为了让大拇指能帮助握紧物体。</p><p>‘但他需要我做什么？’</p><p>‘强大如此的他，却不亲手行动。’</p><p>‘而是将力量给予我，同时将权责给予我。’</p><p>‘可为什么是我？我曾只是个手无缚鸡之力的凡人……’</p><p>姜笙手机突兀地响了一声。</p><p>理论上，此刻已达“天人合一”境界的她不需要解锁屏幕，甚至不需要动用感官，仅仅凭籍着与世界信息的同频，就能在一瞬间知晓是谁发来的信息、内容是什么。</p><p>毕竟，这不过是几比特的数据流在基站与终端间的跃迁。</p><p>理应……理应都尽在她掌握之中。</p><p>但这条消息没有。</p><p>——此刻，她无法预见这条信息是什么！</p><p>那短短的一行字，在她此刻那全知全能的视野里，竟然变成了一片虚无的盲区。</p><p>姜笙深吸一口气，带着面对未知深渊的战栗，指尖微微颤抖着划开了屏幕。</p><p>发信人：龙佑！</p>
