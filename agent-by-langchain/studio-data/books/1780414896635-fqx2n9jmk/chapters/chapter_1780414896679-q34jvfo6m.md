# 天魔潮的源头！

<p>龙佑最终没能测试出自己能力的极限。</p><p>无论他所设定事件发生有多么奇葩，概率有多么渺小，都能轻易拉到100%。</p><p>又或是将几乎必然发生的事情拉到0%，必要时让熵倒着流都行，他有这个威能。</p><p></p><p>……</p><p></p><p>岁月荏苒，已是一个月后。</p><p>龙佑悬立天穹之巅，俯瞰着这片熟悉又陌生的大地。</p><p>一个月以来，他都在此界游览大地的名山胜川，遛鸟逗狗，悠哉悠哉。</p><p>自己穿越异世界，主要就是为了旅游。</p><p>毕竟在地球打了这么多年工，早就不想奋特么的斗了。</p><p>同时，他还感受这世界法则的奇异。</p><p>和地球截然不同，此界的天道法则，非常人性化智能化！</p><p>天墟界最底层，是一片广袤无垠的大陆。</p><p>直径数亿公里，悬浮于虚空之中。</p><p>那便是“人间”，天墟界生灵世代居住之地。山川河流，宗门城镇，凡人与修士，都在这片大陆上繁衍生息。</p><p>大陆之外，便是天空。</p><p>无数恒星、行星、星云、黑洞，构成了这片浩瀚的宇宙空间。</p><p>但它的规模远不及地球的可观测宇宙。整个天空的大小，大约只有银河系那么大。</p><p>在天墟界，修士的力量与距离有关。</p><p>离人间界越远，受到的束缚越小。</p><p>天墟界的人间有「红尘护阵」，会限制高修为的大能出手，强力压制高境界者的破坏力。</p><p>那层压制，大概是为了保护脆弱的凡人和低阶修士。</p><p>否则，别说炼虚合体了，就算是化神期的修士随便动动手，就能把整片大陆掀翻。</p><p>而萧凡叶以渡劫修为在天墟界打架时，全力下去就炸出个几百里的坑。</p><p>但如果是远离大地的天空之上，来到没有“红尘护阵”的星海，一旦放开手脚，他们的一举一动都能撕裂恒星！</p><p>“真是非常好的世界法则，有人文关怀，大赞！”</p><p>他感慨地着看着这片大地。</p><p>一个月前，龙佑在这里将整个天墟界的人族气运扭转向繁荣昌盛。</p><p>如今再看，脚下的世界确实在变。灵气的流转更加顺畅，天地的脉络更加清晰，就连那些曾经死气沉沉的角落，也开始焕发出生机。</p><p>但此刻吸引他目光的，不是大地。</p><p>是天空。</p><p>那道曾经撕裂苍穹的巨大裂隙已经闭合，只在虚空中留下几道细如毫毛的漆黑丝线。</p><p>那些丝线极细，细到连化神修士的神识都无法察觉。但在龙佑眼中，它们清晰得如同墨迹。</p><p>这是“天魔”入侵时，留下的空间裂缝。</p><p>【域外天魔究竟从何而来？它们长得既抽象又抽筋的啊。】</p><p>“天知道。待我仔细看一眼。”</p><p>龙佑闭上眼，意识沉入天墟界自身的时间长河。</p><p>时间长河如同一条奔涌的明带，他顺着明带逆流而上，画面飞速倒退，直到源头。</p><p>这里是世界诞生的最初期。</p><p>此时，维度刚刚折叠，时空才凝出雏形，混沌未开。</p><p>突然，混沌的初生世界剧烈震颤！</p><p>【我去！搅什么了？】</p><p>“天墟界的外壁，好像被什么东西撞上了！”</p><p>天外光海本就没有「时间」的概念，龙佑无法看到，“那东西”是如何撞上天墟界的。</p><p>他只能在世界内部，目睹这开天辟地般的撞击结果。</p><p>刚诞生的维度与时空，被轻易肘穿！</p><p>世界外壁，崩裂出巨大的创口！</p><p>那创口并未随着时间流逝愈合，反而顺着时间长河疯狂蔓延！</p><p>龙佑盯着那道最初的伤口。</p><p>创口渗出无数细碎、带着异质的黑色流体。</p><p>这些流体顺着时间长河的流向扩散，如同墨水滴入清水，被水流拉扯成无数条黑色细丝，飘荡在时间轴的各个角落。</p><p>随着时间长河的流淌，这些黑色细丝会在某些特定的节点聚集，缠绕，凝结！</p><p>每过万年，那些散落在时间长河中的黑色流质就会汇聚到一起，在现实层面强行具现。</p><p>化作域外天魔……这就是天魔潮！</p><p>万年一次的魔潮，将顺着时间流淌的污染，具现为蠕动的修格斯和域外天魔！</p>
