# 第34章

<p>拥有双重人格兼双重性取向的异食癖素食主义者福瑞控兼三角恋情敌的紫霞青霞姐妹走进破庙后，这破庙轰然倒塌，似乎预示着他们多舛曲折的命运。</p><p>原来这一体双魂，本是佛前长明灯上两根纠缠的灯芯。千万年佛光中成精，同修共长，却养出了两副截然不同的心性。</p><p>紫霞动了凡心，偏爱那毛脸雷公嘴的孙悟空。青霞却觉得全天下的男人都不如姐姐好看，那猴子更是抢夺姐姐关注的死敌。</p><p>二魂日夜争躯，青霞屡屡夺舍就想一剑捅死那臭猴子。</p><p>紫霞则拼死护他，闹得体内翻天覆地。</p><p>龙佑继续叠加修饰词。</p><p>似乎是天道为了顾及他的面子，看在他概率操控能力的面上，将原本世界线走向强行扭曲到了星爷本人都认不出来。</p><p>无论多么微小的可能性，多么渺茫的概率，都会被老天爷找出来并加以应验。</p><p></p><p>龙佑翻了一条又一条，越翻越离谱，越翻越没边。</p><p>世界线的数量似乎是无穷无尽的。</p><p>每叠加一个条件，世界线就多分叉出无数条支流。而每一条支流，都被天道严丝合缝地编织出了完整的因果——有开头，有过程，有结局，甚至有主题曲。</p><p>龙佑蹲在云层里，看着脚下那团由紫霞青霞引发的世界线风暴，像看一碗煮过头的竹升面般千丝万缕，纠缠不清。</p><p>最终甚至能看到身份buff叠满的紫霞青霞和至尊宝三人合力驾驶暴风赤红对战牛魔王，</p><p>“紫霞姐！左边！左边！你转向灯没打！”</p><p>“闭嘴！我在左转！看清楚了，是你抢方向盘！”</p><p>她们中间，至尊宝抓着金箍棒改装的操作杆，哭丧着脸：“两位仙姑，你们能不能别打了？俺老孙的驾驶本刚考出来啊！”</p><p>机甲踉跄着撞碎一堵云墙，对面牛魔王挺着六甲之腹，护着肚子怒吼：“老孙！你竟敢在老子怀孕时开高达？！”</p><p>“俺这是暴风赤红不是高达！而且谁让你把肚子搞大的！”</p><p>“还不是你那六耳猕猴兄弟——”</p><p>轰！！</p><p>暴风赤红的液压拳砸在牛魔王肚皮上，竟然弹飞了。牛魔王抚摸着坚如神铁的肚皮，狞笑：“老娘这胎是吃了万年玄龟蛋壳炼的护体神功！你打不穿！”</p><p>青霞夺过控制权，怒吼：“最恨这种毛脸雷公嘴的猴子！还有怀孕还打架的妖怪！本姑娘今日替天行道——”</p><p>她按下按钮，机甲背部弹射出数十个高压喷口，喷射的竟然是浓缩青草汁。</p><p>“素食主义净化炮！！”</p><p>青绿色浆液浇了牛魔王一头一脸，他惨叫着摸着肚皮：“我的孩子！要被素食化了！！”</p><p>紫霞夺回控制：“青霞你不喜欢这猴子就算了，干嘛欺负牛魔王。”</p><p>“哼！谁让她肚子里是猴子种！”</p><p>“那是猴子的种！孙悟空的朋友的种！跟我家猴子没关系！”</p><p>“你心里果然还有他！”</p><p>……</p><p>龙佑揉了揉太阳穴：“世界线无穷分裂。每一条线都是一个可能，而我的能力似乎能把所有‘可能’都变成‘现实’——只要我想，哪怕那个‘现实’在逻辑上多么荒谬。”</p><p>他把概率视角拉到最高，俯瞰整张世界线之网。</p><p>密密麻麻，纵横交错，像一棵无限生长的大树，每一片叶子都是一段完整的命运。</p><p>这就是众生命运的具象所化之物，世界线。</p><p>【因果纠缠，爱恨情仇，皆在其中。】</p><p>“但是达到仙人层次，已经跳出了世界线与时间长河。”</p><p>【已经超越世界层次的真仙，却仍然能被你操弄概率。】</p><p>“一种绝对机制怪手段，专克一切力大砖飞的数值怪。”</p><p>龙佑渐渐收起笑意，目光越过疯狂分裂、色彩斑斓的支流，落向更本质的层面。</p><p>“不过……我感觉越往深想，越觉得我自己的概率操控能力没有观测到的上限。”</p><p>【没错，已知你能改真仙之因果，但我们仍然不知道，你的极限究竟能哪到哪？】</p><p>“是啊，摸不到上限。”他喃喃道，“就像我当初站在天台上，只想着调一调概率买彩票，将华尔街杀个片甲不留什么的，哪知道现在能影响一个世界的命运走向？下一次，也许就是多元宇宙……没完没了。”</p><p>【力量的增长往往需要参照物。你在天墟界是无敌的，所以你感觉不到能力的极限。就像人在真空中，听不到自己的声音。】</p><p>【也许，遇见比你更强——或者更诡异、更超越认知的存在，能让你更清晰地明白这能力的潜力与空间在哪。甚至有可能让你摸到上限。】</p><p>【当然，可能你遇见更强的存在后，你发现自己依然能修改对方的概率……】</p><p>【那时候，我们就该考虑，这能力是否根本没有上限，或者说，它的‘上限’本身，就是一个可以被修改的概率了……】</p>
