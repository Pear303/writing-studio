# 

<p>小蓝已经把车门拉开。</p><p>一路上没怎么说过话的龙佑，伸手接过林云，把她塞进车里。</p><p>小光站在车头前，一脚踹向地面！</p><p>轰！！这一脚的威力比刚才那记回旋踢还要夸张！整个隧道地面被踩出一个直径数米的深坑，冲击波呈扇形向前扩散！</p><p>简直像个塞了几百公斤几十公斤TNT的阔剑地雷，这就是传说中的地雷妹吗。</p><p>最前面的几十头诡兽直接被掀飞，撞进后面的兽群轰飞一片。</p><p>趁这个空隙，小光赶紧钻进面包车。</p><p>面包车发动机发出一声怒吼，轮胎在隧道地面剧烈摩擦，冒出一阵青烟，整辆车以一百二十公里的时速，向后倒去！</p><p>林云猫娘被惯性甩得贴在前座，尾巴在空中飘成一条直线。</p><p>她看着车窗外面那些疯狂追逐的诡兽，看着它们狰狞的面孔和流淌着黑液的躯体，心脏砰砰直跳。</p><p>“我、我能问个问题吗？”她声音发颤。</p><p>“放。”小蓝盯着后视镜。</p><p>“为什么你们开关门这么暴力啊？！”</p><p>“身怀异术超能之人，生活中可能会因为一些小细节，卡入‘异常折叠空间’。”</p><p>他猛打方向盘，面包车漂移过弯，车尾撞飞几头挡路的诡兽。</p><p>“我们的研究表明，‘开关门’这一行为本身，似乎是事故高发行为。</p><p>“所以用一些日常极少使用的方式开门——比如直接把门拆下来，能减少卡进‘异常折叠空间’的概率。</p><p>“不过现在已经卡进来了，那就暂时改回正常的开关门方式。”</p><p>异能者在正常的地球时空，普通地“开关门”就有可能卡进“异常折叠空间”？</p><p>龙佑本想放出神识，一观这异常折叠空间的全貌。</p><p>但神识刚探出，便如陷泥沼，寸步难行。仙力运转也凝滞起来，像是从空气里游泳突然扎进黏稠的糖浆。</p><p>【嘿嘿，现在你明白为什么玄幻小说里，总有那种高境界修仙者进不去，反而低境界的小辈能进去求机缘的秘境了吧。】</p><p>【一个极其狭窄的房间，大笨象在里面寸步难行，小老鼠却能纵横天地宽。】</p><p>【你虽然拥有了太乙真仙的修为和境界，但是对宇宙、世界、时空的理解，仍然处于一个普通人类的阶段。】</p><p>【异常折叠空间，就是你之前从未见过的设定。】</p><p>龙佑心想也是。</p><p>这异常折叠空间，本质上是世界碰撞产生的“超级大褶皱”。</p><p>物理规则不完整，空间结构脆弱。</p><p>太乙真仙级别的力量，如果全力释放，说不定直接把这地方撑爆！</p><p>连带着把里面所有东西一起抹掉。</p><p>‘一起抹掉？那不更省事？’</p><p>【你认真的？】</p><p>‘哈，保留选项。这环境破坏与否，还是先观察一段时间再说吧。’</p><p>面包车急速后退，冲出隧道。隧道外却不是他们熟悉的稷海市街景。</p><p>一条荒废的街道在车灯前展开。</p><p>两侧是残破的楼宇，玻璃碎裂，墙体爬满黑色藤蔓状的东西。路灯歪斜，有的折断，有的还亮着，灯光昏黄闪烁。</p><p>地面上散落着生锈的车辆残骸，还有一些看不出原本形状的杂物。</p><p>林云大惊：“干哪来了？这还是国内吗！”</p><p>“很显然，我们不在地球……话说你有没有好好听前面的设定啊笨猫娘！”</p><p>远处隐约能看见高楼轮廓，像是某个城市的中心区，但所有建筑都蒙着层灰败的颜色，像是荒废多年。</p><p>街道上有很多东西在移动。</p><p>那些东西有人类的轮廓，但长得非常随机。有的脖子太长，脑袋垂到胸口。</p><p>有的手臂数量不对，从肋下、后背、甚至膝盖位置伸出来。</p><p>总之一个两个都在废墟间穿行，动作僵硬迟缓，像梦游晚期患者。</p><p>车轮打滑。整辆面包车后轮被抬高，车头向下倾斜，在地上刮出一串火星。</p><p>“魂淡。”小蓝看了眼后视镜，骂了句什么逼鸟。</p><p>竟是一头诡兽，从后面顶起面包车！</p><p>那东西长得像长颈鹿，但脸部又很像人类，五官扭曲着挤在长脸前端，正从车后窗往里看。</p><p>“啊啊啊！！我的理智值！！”猫娘大叫。</p><p>“别嚷嚷，走为上策！龙佑先生，那蠢猫娘就拜托您了。”</p><p>“喂！你们好歹是官方人员吧！为什么要在前面加个‘蠢’字称呼我这个无辜市民！”</p><p>小蓝和小光同时踹开车门跳出去，龙佑拎起林云猫娘，跟着跳车。</p><p>落到地面时猫娘惨叫一声。</p><p>几块碎石被车轮碾飞，划过她脸颊，在细嫩的皮肤上留下几道血痕。</p><p>“呱……”她捂着脸上，金色瞳孔里蓄满泪水。</p><p>没几个人看向她，毕竟现在看起来局势挺紧张，还是得严肃点，蠢猫娘待会儿再管吧。</p><p>猫娘还在咋咋呼呼大叫“人家毁容了”，忽然顿住。</p><p>她摸了摸脸，血痕还在，但已经不疼了。</p><p>再摸一下，伤口已完全消失，皮肤……光滑如初！</p><p>“哇！人家脸上的伤好了！”林云咋咋呼呼。</p><p>小蓝和小光没说什么。</p><p>新生异人刚接触超自然世界时，经常有咋咋呼呼的情况，他们见得多了。</p><p>想必是“猫娘”这个种族，能够急速痊愈吧。</p><p>【天降一个永远不死喵的猫娘概率：……】</p><p>那头长颈鹿脸诡兽甩掉面包车，朝他们冲过来。</p><p>它跑动的姿势很怪，四条腿不像长颈鹿那样交替迈步，而像马一样同侧腿同时向前，简称顺拐。</p><p>“喝呀！！”</p><p>小光脚下发力，地面炸开裂纹，整个人像炮弹般冲向那诡兽。</p><p>半空中扭腰转身，一记回旋踢扫在那东西脸上。</p><p>轰！长颈鹿脸诡兽的脑袋炸开，黑色液体喷溅。无头躯体往前又冲了几步，轰然倒地。</p><p>但街道上那些游荡的人形诡兽被惊动了。它们同时停下脚步，慢慢转过头来。</p><p>那些脸长得随机，但几人都能看出来，它们此刻正盯着这边！</p><p>小蓝退到龙佑身边，喘了口气：“这些东西数量太多，我们得找个有‘门’的掩体。前面那栋楼看见没有？”</p><p>他指向街道尽头一栋相对完整的建筑，像是商场或写字楼。</p><p>小蓝对小光喊：“开路！”</p><p>粉毛双手在身前交错，周身气息骤然提升，脚下地面龟裂！</p><p>轰！！！地面炸开一个直径数十米的巨坑，冲击波呈环形扩散，十几头犀牛大小的诡兽直接被掀飞，撞进后面的兽群，砸倒一片！</p><p>小蓝趁这个机会，一手拎起林云猫娘，朝那栋楼冲去。</p><p>龙佑跟在其后。</p><p>这两位神州龙组成员，展现出惊人的职业素养，从头到尾并未对他开口求助。</p><p>毕竟，现在龙佑仍然是普通“群众”身份。</p><p>小光在前面引路，边跑边回头：“我们刚才说到哪了？没错，核武器对它们效果拔群。”</p><p>林云猫娘被小蓝拎着，在空中晃荡：“那都是多久之前的对话了！现在说这个有什么用！”</p><p>“有用。”</p><p>小光跳过一堆废墟，落地时脚下炸开裂纹。</p><p>“面包车在楼下，我设置了定时自毁程序。30分钟后，相当于1万吨TNT当量的爆炸会把这片区域清空。”</p>
