# 第74章

<p>隔壁测试间。</p><p>西装男人坐在审讯椅上，公文包搁在膝盖上，双手规规矩矩搭着。</p><p>他是在上班路上被请来的，对方挺客气，没敲闷棍，只说了句“有些情况需要您配合了解”。</p><p>至于是什么情况，对面那两个一唱一和的审讯员并没有明说。</p><p>他希望不是什么麻烦的违法犯罪。</p><p>审讯员一男一女，都穿便装。</p><p>男的唱白脸，女的唱红脸，开场白说了一堆“请不要紧张”“只是了解情况”之类的话。</p><p>女生挺好看，一头粉色短发，戴副墨镜。</p><p>“王德发先生，您最近有没有去过什么特别的地方？比如寺庙、道观、武术馆？”红脸问。</p><p>“没有。”</p><p>“有没有遇到过什么奇怪的人？比如路上有人拦住您，说‘我看你骨骼精奇’之类的？”</p><p>“没有。”</p><p>“那您最近有没有感觉自己身体有什么变化？比如力气变大，或者跑得更快？”</p><p>西装男想了好一会儿，说没有。</p><p>白脸和粉毛交换了一个眼神。白脸站起来，说先带您去个地方，放心，您没犯什么事儿。</p><p>“希望您能配合我们的测试。”二人如是说。</p><p>“在你身上，很可能出现了超出我们所能理解的异变。”</p><p>“异变？哪有异变！请问你们到底是谁？无缘无故将老……把我关在看守所，这就是你们的职业素养吗！”</p><p>都市牛马怒了。</p><p>他大声说道，自己这个月全勤奖已经泡汤，真是社畜中的极品社畜。</p><p>审讯员对视一眼，叹了口气：“放心王德发先生，您真没犯什么事，至于你公司那边，我们会派人协调处理……”</p><p>王德发跟在粉毛身后，走廊里的灯管有一半不亮，地面是那种刷了绿色环氧地坪漆的水泥，脚踩上去有点黏。</p><p>他公文包抱在胸前，皮鞋踩出一串咯吱咯吱的响。</p><p>“请问到底要把我带到哪儿？我可说好，就算帮我追回了全勤奖，我也要在下午2点前回公司开会……”</p><p>粉毛小声嘟囔，您真是顶级优质社畜。</p><p>白脸没回头，说王先生到了您就知道。</p><p>拐角处是一扇防火门，推开的瞬间，王德发听见水管震动的声音。</p><p>他还没来得及看清里面有什么，一股水柱从门框侧面喷出来！</p><p>结结实实糊在脸上！水很凉，带着股消毒水的味道，灌进领口，顺着脊背往下淌。</p><p>他往后退，脚底打滑，一屁股坐在地上。公文包飞出去，文件散了一地。</p><p>灯亮了。</p><p>一个穿橡胶围裙的保洁员从门后探出头，手里攥着高压水枪的把手。</p><p>“哎哟不好意思不好意思，厕所搞卫生，水龙头压力调大了。”</p><p>王德发坐在地上，水从头发丝往下滴，裤腿贴在腿上，皮鞋里咕叽咕叽响。</p><p>白脸站在旁边，没伸手扶他，只是弯腰把散落的文件捡起来，摞好，塞回公文包。</p><p>“走吧，快到了。”</p><p>测试场是个空旷的房间，墙面上看不见任何喷头或机关，只有几条细细的缝隙嵌在灰色复合材料里。</p><p>地板中央画了个圈，王德发被要求站进去。</p><p>技术人员的声音从头顶的扬声器传出来，请他尽可能躲开即将喷出的液体。</p><p>王德发环顾四周，手指攥紧公文包把手。</p><p>“这是什么？电锯惊魂？异次元杀阵？！”</p><p>“放心，都是些普通液体，盐水、清水、泥水，糊到身上也不会有伤害。”</p><p>话音落下的同时，左侧墙壁的缝隙里射出一股水柱。</p><p>“我去，老……我就说是异次元杀阵！你们休想诓骗我！”</p><p>西装社畜王德发使出一套强大的身法，左右横跳，结果却是把射出来的清水全部接中。</p><p>“啊！！！我命休矣！”</p><p>“王先生，这是经过过滤的自来水……唉，算了。接下来是第二次测试，请注意规避。”</p><p>第三次测试。</p><p>扬声器再次响起：“王先生，请、再次、站到圆圈里。”</p><p>王德发叹了口气，走到那个圈里站定，双手插兜，仰头看天花板上的灯管。</p><p>“反正躲也是躲不过，我不躲了，你们射吧。”</p><p>“王先生，公共区域请文明发言，在有关部门里也是要遵守公序良俗的。”</p><p>王德发没说话，低头看自己的皮鞋尖。</p><p>左侧墙壁的缝隙里射出一股棕黄色的液体。第一发！</p><p>他本没有躲闪的想法，然而脚下踩到刚才残留的水渍，却是鞋底一滑，整个人往后仰倒。</p><p>后脑勺离地面还剩十公分的时候，他用手撑了一下，屁股结结实实摔在地上。</p><p>那发泥水从他头顶飞过去，啪地糊在对面墙上。</p><p>王德发坐在地上，愣了两秒。他低头看看自己——衬衫是干的，裤子是干的，皮鞋还是湿的但那是之前的水。</p><p>泥水没沾到。</p><p>“老……我躲过去了？”</p><p>第二发紧跟着射出来。他还没站起来，干脆就地一滚，泥水擦着他肩膀飞过去，在身后墙上炸开。</p><p>滚到一半，手肘撞到墙角的公文包，包飞起来，他下意识伸手接住，整个人单膝跪地稳住身形。</p><p>一系列非常诡异的动作和姿势。</p><p>“卧槽这是人类吗？哦，不好意思……我没关麦。王先生，请您继续。”</p><p>第三发，泥水从他腋下钻过去。</p><p>据说好像是那什么运动传感器进水了，有些失灵。</p><p>调整完后，发射了第四发。</p><p>王德发这次角色要被泥水射中，判断枪口方向，往前一跳！</p><p>“哇呀！”他落地时脚绊到自己的裤腿，往前踉跄两步，恰好避开。</p><p>第五发。</p><p>他站稳的时候发现自己在圈子外面，赶紧跨回去，泥水从头顶掠过，头发丝都没沾到。</p><p>“不好意思啊，这个运动传感器貌似又出了点问题。”</p><p>修好后，迎来第六发。</p><p>他索性不跑了，站在原地歪了下头，泥水擦着耳朵飞过去。</p><p>第七发。他低头系鞋带，泥水从背上飞过。</p><p>“你为什么突然蹲下来系鞋带！”</p><p>“为何老……我还不能系鞋带了？”</p><p>第八发，第九发，第十发……各种奇葩的巧合，都没射中。</p><p>“有点神奇，这一次居然没被打中。”</p><p>白脸先开口：“第一次测试，十发清水，他中了七发。”</p><p>“第二次，十发生理盐水，他中了八发。”</p><p>“第三次，十发泥水，他一发都没中。”</p><p>技术员没点头，把刚才的录像调出来，放慢到四分之一速。</p><p>画面里，王德发每一次躲避都狼狈至极，滑倒、绊脚、弯腰系鞋带、伸手扶墙，没有一次像正常人躲东西那样干净利落！</p><p>但每一发泥水，都恰好从他身体轮廓的边缘掠过，误差不超过两厘米！</p>
