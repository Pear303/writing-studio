# 临阵突破、越战越强！！

<p>萧凡叶看到自己初入修仙界时的青涩，看到自己第一次斩杀妖兽时的紧张，看到自己结丹时的狂喜，看到自己元婴出窍时的新奇。</p><p>他看到那些已经死去的人，那些已离开的人，而且他眷恋的人，爱而不得的人……</p><p>“你们……”他伸出手，想要抓住什么，但那些身影都化作光点，消散了。</p><p>走马灯的最后，是他自己。</p><p>九百年后的自己，站在天柱峰之巅，白发苍苍，独自面对遮天蔽日的天魔。</p><p>那时候他想：“我为什么还要坚持？”</p><p>此刻他终于有了答案。</p><p>因为身后，是八百兆凡人，是他守了九百年的天墟界。</p><p>因为他是萧凡叶，他别无选择！</p><p>睁眼，再无迷茫！</p><p>那天魔先锋已经落了下来，无数触手即将刺穿他的身体。</p><p>但就在这时！轰隆隆！！滔天威压从他体内爆发，将那无数触手震得粉碎！</p><p>萧凡叶仰天长啸，啸声穿透云霄，穿透裂隙，穿透整个天墟界！</p><p>他的气息，正在以恐怖的速度飙升！</p><p>合体初阶——合体中阶——合体高阶——合体巅峰——！</p><p>不，还没有停止！</p><p>那气息还在飙升，还在突破，还在冲击那道更高的屏障！</p><p>轰！！！！</p><p>天地变色，大道轰鸣！</p><p>萧凡叶的身体缓缓升空，周身浮现出无数异象。有星辰生灭，有日月轮转，万物生长，天地开辟。</p><p>他的气息，终于稳定下来。</p><p>渡劫期！！</p><p>虽然只是渡劫初阶，但那股威压，已经让那天魔先锋停下了动作！</p><p>那百丈人形剧烈颤抖，无数只眼睛里第一次浮现出恐惧。</p><p>萧凡叶低头看着自己的手，感受着体内那足以撼动天地的力量，嘴角缓缓扬起一个弧度。</p><p>“原来……这就是渡劫。”</p><p>他抬起头，看向那天魔先锋。</p><p>归乡剑自动飞回他手中，剑身上的裂纹瞬间愈合，剑身的光芒比之前璀璨百倍。</p><p>那天魔先锋发出一声凄厉的尖叫，转身就逃。</p><p>但萧凡叶只是轻轻挥了一剑。</p><p>剑光细如发丝，却仿佛切开了天地，切开了时间。</p><p>那天魔先锋的动作定格在原地。</p><p>下一瞬，它的身体从中间裂开，分成两半。两半身体同时开始崩溃，化作漫天黑雾，然后被剑光彻底磨灭，连一丝残渣都没留下！</p><p>裂隙深处，那些还在涌出的天魔小怪，在看到这一剑的瞬间，同时发出惊恐的尖叫，疯狂地向后退去！</p><p>萧凡叶又一剑将空间裂缝劈了个粉碎。</p><p>他只是静静地悬浮在空中，看着那道缓缓弥合的裂隙，看着裂隙深处那无尽的黑暗，看着这片苍茫大地。</p><p>原地只残留一个深不见底的巨坑，坑底翻涌着赤红色的熔岩，无数裂谷从坑边向四周延伸，最长的裂谷绵延到天边，深达万丈。</p><p>天空之上，那道巨大的空间裂隙正在缓缓闭合。但裂隙闭合后，虚空中依然留下几道细得几乎看不见的空间裂纹，像是被撕裂的锦缎上残留的线头，证明着刚才那场战斗的恐怖。</p><p>萧凡叶站在巨坑边缘，背对龙佑。</p><p>他的身影依旧挺拔。</p><p>乌黑长发在风中飘扬，归乡剑插在身侧，剑身还在微微震颤，发出低沉的嗡鸣。</p><p>龙佑慢慢飘浮至三百丈外。</p><p>“结束了？”</p><p>萧凡叶转过身，那张年轻的面孔上写满难以言喻的复杂。</p><p>“结束了……龙佑阁下。”</p><p>沉默了片刻，萧凡叶忽然开口：“龙佑阁下，斗胆问您——请问您是直接从地球过来到天墟界的？”</p><p>“是。”</p><p>“您是刚到天墟界吗？”</p><p>“是。”</p><p>两个字，简短得没有任何修饰，确实很有高人风范。</p><p>事实上，是因为龙佑只允许“声音和语义”这两项信息能够传达到萧凡叶，其他信息则被绝对屏蔽。</p><p>人类在进行交流时，有诸多微小的特征，譬如微表情、小动作，甚至是面相本身，都能够表露出此人此刻的心境、情绪、态度。</p><p>即使是修炼了几百几千年的老怪、强者、大能，因为“相由心生”，也难免会在脸上表露出些许心思。</p><p>萧凡叶感知不到龙佑表情，看不清他任何动作，也听不出他说话之中有何语气。</p><p>他只能想到一种可能。</p><p>境界差距过于悬殊。</p><p>萧凡叶手指微微颤抖。</p><p>合体境界，即使放在天墟界历史上，也不超过五十之数。而能在千年之内抵达这一境界，更是凤毛麟角，前无古人。</p><p>而渡劫期更是三万年未有之，如今他刚入合体，再破渡劫，说他是天道私生子、萧凡叶都踏马相信！</p><p>他声音压得很低，带着连自己都未曾察觉的期冀：“龙佑阁下，您离开的时候……地球是公元几几年？”</p><p>“2026。”</p><p>萧凡叶愣住。仅仅三年。</p><p>他闭上眼睛，任由那股复杂的情绪在胸腔中翻涌。九百年，对于地球来说只是三年。</p><p>那些他以为早已化为黄土的亲人、朋友、同事——他们或许还活着，或许还在原来的轨道上生活着。</p><p>但他没有开口请求龙佑带他回去。</p><p>跨越世界，谈何容易？</p><p>即使是手段通天的龙佑阁下，也只能以“投影”降临此界。</p><p>这已经是惊天动地的手段。</p><p>若要真身跨界，或者带人跨界，那需要的代价恐怕难以估量。</p><p>更何况，对方已经赐给他如此多的机缘……</p><p>永远不要将他人的馈赠当做理所当然。萧凡叶叹了口气。</p><p>龙佑借机套话，搞点情报：“勿躁，虽然助你突破境界，确实对我而言‘透支不少’，但我所行之事确有其意义。首先我且问，此界的境界划分如何？既能让我透支如此之多……”</p><p>萧凡叶让自己脑子冷静了一番。</p><p>随后恭敬回答：“此界的修仙境界划分，不过是最传统的炼气、筑基、金丹、元婴、化神、炼虚、合体、渡劫。每一境又分若干小境界。在下刚入渡劫，已是此界明面上的顶点。但据说上古有渡劫突破、太乙真仙、飞升界外的存在。”</p><p>“渡劫之上还有真仙？”</p><p>“对。不过天墟界已经数百万年没有渡劫。灵气衰微，天道残缺，合体已是极限，但大机遇者，或许有极小极小概率再破渡劫……”</p><p>萧凡叶感受着体内涌动的渡劫期力量，随手一挥就是场万物寂灭的天劫。</p><p>龙佑前辈……究竟赐予了他如何恐怖的机缘……？</p>
