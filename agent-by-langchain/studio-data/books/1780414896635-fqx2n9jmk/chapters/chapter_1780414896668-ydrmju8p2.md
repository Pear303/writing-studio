# 萧人皇啊〒▽〒你不要陨落

<p>龙佑顺着潜龙的指引看去。</p><p>巨坑边缘，那群修道者中，有人开始躁动起来。</p><p>一个身着华服的中年男子，似乎是某个大宗门的长老，上前一步，朝萧凡叶拱手道：</p><p>“人皇前辈，晚辈斗胆一问——您当真修为尽失了吗？”</p><p>萧凡叶神色淡然，目光扫过那人。</p><p>那华服男子被这目光一扫，竟莫名心悸，后退半步。</p><p>但随即想到对方已无灵力波动，又硬着头皮道：“前辈莫怪，晚辈只是关心。毕竟……若前辈真的一身修为化为乌有，那日后天魔再临，天墟界又当如何？”</p><p>此言一出，众人窃窃私语声更大了。</p><p>有人附和：“请人皇陛下给个准话。”</p><p>有人则皱眉：“休得无礼！人皇刚刚浴血奋战，你们这是作甚？”</p><p>萧凡叶依旧不语，只是静静地看着他们。</p><p>那青羽宗老妪开口，声音沙哑：“萧人皇，老身斗胆，以神识探查您体内，不知可否？”</p><p>这是极为冒犯的请求。探查他人丹田经脉，无异于赤裸相见。</p><p>众人哗然，有人面露不忿，有人则眼神闪烁，显然也想确认萧凡叶的真实状态。</p><p>萧凡叶声音平静如水：“可。”</p><p>老妪一怔，随即上前，探出神识。</p><p>片刻后，她面色复杂地收回神识，颤声道：“人皇体内……确实空无一物，如凡人一般。”</p><p>那些恭敬的目光，也变得复杂起来。</p><p>有惋惜，有同情，有惊疑，还有……一丝若有若无的觊觎。</p><p>萧凡叶，天墟界第一人，九百年来镇守天柱峰，手中有无数法宝、丹药、功法典籍。</p><p>若他真的修为尽失……</p><p>道义和利益正在打架。天魔裂缝已经闭合，可以预见未来万年都将暂时是太平。</p><p>天下之势，分久必合合久必分，春天来了冬天不会远，骄兵必败败兵必哀哀兵必胜，医死的人越多医术越高明，鱼肉越多鱼肉越少，风浪越大风浪便越小……</p><p>既然和平了，那说明距离天墟界各大宗门开始搞内斗的日子，也就不远了。</p><p>华服男子上前一步，拱手道：“人皇前辈为苍生付出如此代价，晚辈感佩不已。前辈日后若有需要，尽管来我玄阳宗，晚辈必当供奉前辈终老。”</p><p>这话说得漂亮，但“供奉终老”四字，已是将萧凡叶当作废人看待。</p><p>萧凡叶微微一笑：“多谢好意。”</p><p>他依旧从容，仿佛说的不是自己。</p><p>三百丈外，龙佑看着这一幕，眉头微挑。</p><p>“这些人……变脸真快。”</p><p>【修仙界本就以实力为尊，失了力量的皇者，境遇未必比凡人强上多少。】</p><p>【只是碍于昔日威名与天下格局，修为尽失的萧人皇，虽不会立刻被各大宗门直接清算，却会沦为各方势力彼此攻讦、互相制衡的棋子。】</p><p>“你怎么知道的？”</p><p>【哈哈，我面无表情刷了20遍新三国。】</p><p>“可恶，我明明都把那段记忆忘掉了。”</p><p>【作为你的潜意识，我记住的关于龙佑的黑历史可多了。】</p><p>“话说回来，萧凡叶倒是沉得住气。”</p><p>【他当然沉得住气，因为他力量还在，自己只是将修为“隐藏”了起来。】</p><p>能够打爆全世界的力量很重要，只要底气尚在，威严便可留存。</p><p>龙佑想了想：“那如果我把自己的境界直接调到渡劫期巅峰大圆满，会怎样？”</p><p>【你可能会被此界天道排斥，直接飞升。或者引发天劫，把这里炸平。】</p><p>“无所弔谓，‘完全没有任何动静’的概率即使为零，我也把它强行拉到100%。”</p><p>【好吧。渡劫期也分初中高巅峰，你打算跳到哪个阶段？】</p><p>龙佑沉吟片刻：“既然要追求六边形，那就直接‘渡劫巅峰’！”</p><p>【有没有想过，直接让自己原地化身成什么太乙真仙，干脆什么“混元大罗金仙”？】</p><p>龙佑这回严肃起来。</p><p>“不！”</p><p>“你在做很危险的事。”</p><p>龙佑左脑的表层思维，狠狠搏击右脑的潜意识！</p><p>“我不会做这种带有未知风险的投资。直到15岁，我才第一次知道圣经中的天使并不是穿着白衣、头上有光环、身上有漂亮羽翼的大姐姐，而是一大坨长着眼睛的羽毛聚合物。</p><p>“如果在我知道天使的真面目前，我稀里糊涂让自己原地觉醒成天使的概率是100%……</p><p>“那时，我非但不会成为漂亮大姐姐，反而很有可能变化成一坨面目可憎的克家生物。</p><p>“我必须亲眼见到一个活的‘太乙真仙’、‘混元大罗金仙’，看他们面目是否正常，再决定是否觉醒。</p><p>“同理，我也可以随时将自己全知全能的概率修改成100%，但我无法确定，全知全能会不会让我获得意料之外的副作用。</p><p>“比如全知全能会导致我多长一个脑袋，或者是第四根手指变成永久性油条……”</p><p>【可以，那就渡劫巅峰。】</p><p>【不过你要注意，修仙者的境界不仅仅是力量，还有对天道的感悟、道心的磨砺。你直接用概率跳过去，可能会缺少这些软实力。】</p><p>叽里呱啦说什么呢。</p><p>潜龙：【我是说，首先你应该做那1/3的第一阶段工作。】</p><p>龙佑恍然。</p><p>在可预见的未来，他唯一的弱点，或许就是“身为普通人”的时间，实在太短。</p><p>绝大多数人在骤然获得力量之后，都会无可避免地迷失自我。</p><p>无论有意还是无意，最终都会在客观上，变成另一个人。</p><p>就像那个三十岁的普通程序员，终究抵不过九百年仙界修行——萧凡叶从社恐，一步步蜕变成了从容自若的人。</p><p>这尚且只是正向的蜕变。</p><p>可一旦走向恶的一面呢？</p><p>就像那位不可名状的古月方X老魔，觉醒凤凰之力而失控的琴·葛蕾，背负全宇宙预知重担的保罗·厄崔迪。</p><p>曾经正义、善良的他们，终究被力量重塑了意识。</p><p>就算不曾堕入黑暗，力量的无限膨胀，也会让人格、思想、三观，发生翻天覆地的改写。</p><p>【那不是你想要的结果。你想要的是掌控命运，而不是变成命运的化身。】</p><p>‘你说得对，或许我要为现在的人格与人性做一道保险。’</p><p>【龙佑的人性不可磨灭：100%】</p><p>【人性，或许就是你日后唯一的弱点了。】</p><p>‘现在，给我加点升级！’</p><p>【龙佑现在的修为，立刻提升到天墟界标准的渡劫期巅峰，并且完美掌握所有对应境界的感悟、道心、神通，不引发任何天劫或异常波动，没有被在场任何修道者发现：100%】</p><p>一瞬间，龙佑体内有什么东西轰然炸开！</p>
