# 像凡人一样诗意地栖居

<p>龙佑坐在小马扎上，端着泡面，抬头看她。</p><p>旁边摆着两枚硬币。</p><p>穿越异世界这种事情，只有零次，一次，和无数次。</p><p>有的人终其一生也没能穿越异界，其实这是正常，苍生祸福，冥冥中自有定论。</p><p>穿越异界可不一定是好事，比如穿越到四位勇者大战一尊魔王的世界，然后被黄老汉征兵，那就只能成天戴着痛苦面具了。</p><p>但龙佑怎么也没想到自己现在身在地球，还能看见一个疑似从异世界跑出来的生物跌到自己面前。</p><p>那是一只怎么看都能被称作猫娘的生物，穿着蕾丝边蝴蝶结带猫耳兜帽的黑白色衣服，身形娇小，橘色长发，金黄色瞳孔。</p><p>衣服尺寸居然刚好合身。</p><p>她背靠着墙，探头探脑往窗外看，尾巴已经炸毛了。</p><p>龙佑不情愿地把神识扫描范围从十米切换到一千米。</p><p>他平时不喜欢把感知扩太远，因为会听到很多地方的口水声。</p><p>比如很多人肠胃蠕动的动静，以及排水沟里无数蚊子、蟑螂的嗡嗡声。</p><p>特别是南方的蟑螂，半个巴掌大小，那动静特别恶心人。</p><p>现在他看到了。</p><p>两个一男一女的黑衣人站在某栋楼顶，往这边看。</p><p>没有灵力。都是凡人。</p><p>龙佑收回神识，低头继续吃泡面。</p><p>猫娘终于发现屋里有人，猛地转头，全身绷紧，像受惊的猫。</p><p>龙佑嚼着面，指了指窗外：“那俩人在对面楼顶，没动。”</p><p>林云猫娘没动，警惕是哈基米的天性。</p><p>“吃面吗？”他端起泡面碗，“还有一桶。”</p><p>……</p><p>龙佑拎着她后脖颈，像提着一只炸毛的猫，走过去开门。</p><p>门外站着那两个黑衣人。蓝发男人摘下墨镜，露出张三十出头的脸，眉眼间带着点疲态。</p><p>粉发女人仍戴着墨镜，侧身往楼道方向望风。</p><p>“不用脱鞋。”龙佑说，“这房子刚租，搬进来没多久，还没扫地。”</p><p>蓝发男人点点头，跨进来。粉发女人确认门外无人，跟进屋，关上防盗门。</p><p>林云在龙佑手上扑腾：“你、你原来和他们是一伙的！没想到是如此严密的多方追捕，天要亡我！你们随便把我拿去切片吧，我听说人体切片好像几百甚至几十微米就能切一片，既然已经逃不掉了，那为科学做点贡献也不错……”</p><p>“我们不抓你切片。”蓝发男人说。</p><p>就这么一句，然后他不说话了。</p><p>林云感觉安心了一点。</p><p>粉发女人摘下墨镜，露出张年轻面孔，二十出头，五官精致，眼神却像干这行很久了。她看了眼林云，又看向龙佑。</p><p>蓝发男人朝龙佑伸出手。</p><p>龙佑单手拎林云，另一只手和蓝人握了握。三方的第一次见面非常愉快，氛围融洽。</p><p>“龙先生，初次见面。”蓝发男人说，“我们是神州龙组。”</p><p>林云被提溜在半空，眼睛瞪得溜圆：“什么龙组？卧槽还真有龙组！”</p><p>蓝发男人从内兜掏出张黑色卡片，递给龙佑。卡片上没有字，只有个烫金的龙形图案。</p><p>“我们追踪这位‘新生异人’大半夜。”他看了眼林云，“没想到他会跑进您这儿。”</p><p>事实上他们此次前来，真正的目标，是龙佑本人！</p><p>但没想到这条街区，突然出现个明显不属于晚期智人的生物——猫娘。</p><p>总不能既要又要，他们原打算先把这离奇出现的“猫娘”给逮回去，别打草惊蛇。</p><p>没想到这家伙误打误撞便闯进了目标所在，实在是宇宙级幸运。</p><p>干脆也只能顺水推舟，随机应变，用猫娘作为切入口，和这位龙佑先生正式见面。</p><p>龙佑接过卡片，翻过来看了看，又递回去：“所以？”</p><p>“所以打扰了。”蓝发男人收起卡片，“按规矩，新生异人我们需要登记引导……”</p><p>“异人是什么？”</p><p>这蓝毛男人也并不吝啬透露情报。异人，有时也称为奇人，或超能力者，又或是异能者。</p><p>神州龙组，就是由“异人”组成的组织。</p><p>蓝发男人指了指自己：“小蓝。”</p><p>又指向粉发女人，“小光。”</p><p>林云被提溜在半空，忍不住吐槽：“小蓝小光？你们龙组起名是按颜色来的吗？那她应该叫小粉才对……”</p><p>小蓝继续介绍情况。</p><p>异人是官方文件称法。超能力者，异能者，民间叫法随意。</p><p>神州龙组由异人组成，负责处理这类事务。</p><p>林云听着，脑子还在转。小蓝说话时，小光从内衬抽出份文件，递给龙佑。</p><p>龙佑单手接过，翻开。几张照片，中等距离拍摄。</p><p>第一张，他漂浮在半空，背景是废墟和烟尘。第二张，几颗流弹打在他身上，弹头被弹开，空中留下几道轨迹。第三张，他一拳轰向地面，镜头抓拍到扬起的尘土和那个直径约半米的浅坑。</p><p>拍摄距离不近，画质模糊，但轮廓清晰。</p><p>“龙先生。”小光开口，“我们在‘萨由迦’战场上拍到这些。您漂浮在空中，流弹无法穿透您的身体。您那一拳在地面留下直径半米的浅坑，但事后我们派人测量过——那个坑的实际深度超过五十公里。”</p><p>林云瞪大眼睛，忘了扑腾。</p><p>“五十公里？他一拳打出五十公里的洞？”</p><p>小光点头：“地表浅坑只是表象。地下岩层有贯穿式熔融通道，直抵地幔，并且在地幔层继续贯穿数十公里。常规武器达不到这种效果，而且能将其直径始终控制在半米，更是惊为天人。”</p><p>龙佑把照片翻过来看了看，又翻回去。</p><p>“你确定这图片上是我？”</p><p>小蓝看看照片，又看看龙佑，完全一样。</p><p>眼前这人单手提着四十五公斤的猫娘，气都不喘，甚至看不到手臂肌肉绷紧，怎么看都是个拥有特殊能力的异人，就是他们所要找的。</p><p>小光轻咳两声，走上前。</p><p>“龙先生，我们并无恶意，只是请您到总部走一趟，您身上似乎拥有‘超人体质’。</p><p>“能够通过出拳这一行为，在萨由迦留下直径半米、深度超过五十公里的贯穿伤。您的力量令人敬畏。</p><p>“同时，因为您长期生活在人口聚居区，龙组需要与您订立相关安全合同和协约。</p><p>“以确保广大人民群众的财产与生命安全，更重要的是，隐藏异人在俗世社会中的存在。</p><p>“您在萨由迦战场上制止侵略战争的行为符合基本的人文与道义，但只由道德约束的力量同样危险。”</p><p>龙佑取得超人体质和太乙真仙修为后，很少在地球上将自己的感知铺开超过10米。</p><p>除了偶尔预感到地球将要爆炸，或者其他什么灭世危机，才略微出手。</p><p>其他情况的龙佑，像个凡人一样诗意地栖居在出租屋。</p><p>有天道为地球兜底挡刀，如今他只想过平静的生活，就连穿越异界的兴趣都有些淡薄。</p><p>此刻龙佑也是第一次意识到，地球上居然还有个如此隐蔽的凡人组织。</p><p>他的兴趣死灰复燃，再次被调动起来！</p><p>“彳亍，和你们走一趟，按照规章制度办事儿。”</p>
