# 天墟界的最后三日：奥林匹克

<p>天柱峰上，数道流光自四面八方疾驰而来。</p><p>那是驻扎在此地的巡逻修士——自两年前天魔大劫结束，天墟界百废待兴，各大宗门轮流派人镇守这座象征意义远大于实际意义的山峰，以彰人族永不忘却的决心，或者是其他什么崇高的价值。</p><p>在可预见的未来，如果天墟界发展出了发达的市场经济，想必此地也会商业化，凭票入场。</p><p>而在此时起的建筑封顶，居然出现一股茫庞然的气息。</p><p>当先一人身着青袍，面容清瘦，已突破至化神初阶，能够一巴掌扇飞一座小山头。</p><p>他神识铺开，想要探查那突然出现的气息，然后他的神识撞上了一面墙！</p><p>或者说……撞上了一座高山！</p><p>一座巍峨到让他仰望都觉吃力的山。</p><p>他瞳孔骤缩，抬头看去。</p><p>山巅之上，一道身影负手而立。乌黑长发随风轻扬，周身没有半点灵力波动，却仿佛与整座天柱峰、与整片天地融为一体。</p><p>那张面孔……年轻。太过年轻。</p><p>但那双眼睛，那双倒映着九百年岁月沧桑的眼睛，让他只看一眼便浑身僵直。</p><p>“人……萧人皇？！”</p><p>他声音发颤，几乎不敢相信。</p><p>二十年前那一战，人皇独身一人，斩灭天魔先锋，救苍生于倒悬。</p><p>而后传闻他修为尽失、境界跌落，拼着最后一口气斩杀十万异族、退治祖巫、诛灭叛军、镇压海妖、喝退蛮族之后，再无人知其下落。</p><p>如今，他回来了。</p><p>而且……那年轻修士神识再探，这一次，他感受到。</p><p>那股气息，那股浩瀚如渊海、巍峨如泰山的威压——太过庞大，庞大到他的神识根本无法容纳，只能感知到“那里有一座山”的轮廓！</p><p>合体期！不……合体之上！！</p><p>他猛地躬身，声音因激动而颤抖：“恭迎人皇！”</p><p>身后数道身影同时反应过来，齐刷刷拜倒：“恭迎人皇！”</p><p>萧凡叶转过身，目光扫过这些年轻的面孔。20年过去，天墟界的下一代已经成长起来，化神期的年轻人也开始崭露头角。</p><p>“起来吧。”他淡淡道，“本座只是回来看看。”</p><p>几人起身，却不敢抬头。那位青袍修士犹豫了一下，低声道：“人皇，这二十年来，天墟界一切都好。各大宗门遵循您留下的训诫，共御外敌，同修内政。北方那几个不安分的宗门，也被联手压了下去。”</p><p>萧凡叶微微点头，没有多言。只要手下员工做得够好，就不要多嘴点评，这是每个老板都应该学习的职场PUA。</p><p>“敢问萧人皇……这些年月，您都去了何方？”</p><p>那位修道者问出了所有人的心声，毕竟他们老大走之前，还放狠话说自己准备陨落暴毙，消失二十年，任谁都会心慌慌。</p><p>但如今看来，人皇非但没有陨落，修为更是上了一层楼，这实在是天下人族的气运。</p><p>萧凡叶神色肃穆：“我在准备‘天柱论道’。”</p><p>“天柱论道？”</p><p>那青袍修士一愣，随即恍然大悟：“这二十年，人皇是在闭关筹备此事？”</p><p>萧凡叶微微颔首，目光越过众人，投向远方。</p><p>天柱峰下，千里沃野尽收眼底。</p><p>二十年过去，这片曾经被天魔之血浸透的土地，如今已是郁郁葱葱，灵草丛生。几座新建的城镇点缀其间，炊烟袅袅，人声隐约。</p><p>“本座离开之前，曾与一位‘前辈’论道。</p><p>“那一夜，我们坐在天柱峰顶，看星河流转，谈天地玄机。</p><p>“那位前辈的故乡有一种盛会，每隔四年，天下各族齐聚一堂，不论出身，不论强弱，只论技艺，只论情谊。</p><p>“胜者不骄，败者不馁，各族共襄盛举，名曰——奥林匹克！”</p><p>众人面面相觑，从未听过这个名字。</p><p>“奥林匹克……”那青袍修士咀嚼着这几个字，只觉得玄妙莫测，不知是何意味。</p><p>“敢问人皇，那是何等境界？是哪位上古大能的道场？”</p><p>萧凡叶没有解释，只是继续道：</p><p>“本座思来想去，天墟界万族林立，纷争不断。人族与妖族斗，正道与魔道斗，宗门与宗门斗，万年来从未停歇。</p><p>“从我八百年前出世，到二十年前天魔之战结束，我斩杀了无处妖魔邪祟、人族恶徒和异族侵略者。</p><p>“虽说我思我想皆澄如明镜，我心我行皆为正义，但这种席卷大地的诛杀和镇压，终究是破坏了一点点和气。</p><p>“那位前辈故乡的盛会，若能在此界推行，或许能让各族放下成见，共坐论道。”</p><p>他转过身，看向众人，目光如炬：</p><p>“是以，本座定下规矩——每隔一甲子，天柱峰顶，举办‘天柱论道’。</p><p>“届时，不论人族、妖族、灵族、蛮族，不论正道魔道，不论宗门散修，凡有道心者，皆可前来。</p><p>“论道不论战。论的是天地至理，论的是修行心得，论的是万物玄机。胜者无奖，败者无罚，只为同道共参。”</p><p>众人听得目瞪口呆。</p><p>万年来，天墟界各族各道之间水火不容，见面便是一场血战。</p><p>如今人皇竟要让各族同坐论道？这、这……</p><p>那青袍修士咽了口唾沫，小心翼翼道：“人皇慈悲，心怀天下。只是……妖族灵族那边，怕是未必肯来。”</p><p>萧凡叶淡淡道：“他们会来的。”</p><p>他的语气平静，却透着铺天盖地山崩地裂的威压。</p><p>众人心头一凛，随即反应过来，眼前可是一剑斩灭天魔先锋、一掌镇压四方异族的人皇。</p><p>妖族灵族若是不来，怕是要被请着来。</p><p>你敢不团结，后果是“你”亡，而“团结”存。</p><p>“还有一事。”萧凡叶抬手，一道灵光自袖中飞出，悬于众人面前。</p><p>那是一幅图。</p><p>五色光环，两上三下，相扣相连。蓝、黄、黑、绿、红，五色分明，在虚空中缓缓旋转，散发着柔和的光芒。</p><p>众人仰头看去，只觉得那五色光环之中，仿佛蕴含着天地至理——蓝如苍穹，黄如大地，黑如深渊，绿如生机，红如烈焰。</p><p>五者相扣，浑然一体，缺一不可。</p><p>“此乃天柱论道之徽记。”</p><p>“黄色，代表中央厚土，承载万物，包容一切。”</p><p>“蓝色，代表东方苍天，日出之地，万物始生。”</p><p>“黑色，代表北方玄天，深渊之底，幽深莫测。”</p><p>“绿色，代表南方炎天，生机勃发，万物繁盛。”</p><p>“红色，代表西方昊天，落日之墟，烈火焚尽。”</p><p>他顿了顿，目光落在那五色环上，眼中闪过眷恋之色。</p><p>“五色相扣，五方相连，五族同心。天下大同，莫过于此！”</p>
