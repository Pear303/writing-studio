# 天墟界的最后三日：疯狂突破

<p>“三百万回合。”天虚道人看着他，眼中闪过一丝讥讽，“一个九百岁的小辈，能在本座手下撑三百万回合，确实难得。”</p><p>他顿了顿，笑容狰狞：“但也到此为止了！”</p><p>他一掌拍出！这一掌，凝聚了他全部的道行，全部的法力，全部的杀意！</p><p>萧凡叶咬紧牙关，横剑格挡。</p><p>轰！！归乡剑剧烈震颤，剑身上浮现出无数细密的裂纹！</p><p>那些裂纹如同蛛网般蔓延，从剑尖到剑柄，从剑脊到剑刃——然后，轰然炸裂！</p><p>归乡剑，断成两截！</p><p>萧凡叶瞳孔骤缩，心神剧震！</p><p>那是他亲手炼制的本命飞剑，随他征战数百年，从未离身！</p><p>“噗——！”</p><p>他一口鲜血狂喷而出，整个人如同被泥头车撞飞的凡人，倒飞出去数百万里，砸穿了三十层虚空壁障，最后嵌在第三十一层壁障。</p><p>九天罡风三十三层，再往外便是世界之外的天外天。</p><p>本命道器破碎，反噬之力让他的经脉寸寸断裂，五脏六腑尽数移位，神魂都在剧烈震颤！</p><p>天虚道人一步迈出，出现在他面前。</p><p>他俯视着这个嵌在壁障中的青年，眼中满是快意。</p><p>“九百岁，渡劫高阶，确实是媲美‘天道祂私生子’的天纵奇才。”</p><p>他抬手，掌心凝聚着毁天灭地的光芒。</p><p>“可惜，你遇到的是我。”</p><p>光芒即将落下。</p><p>轰隆隆！萧凡叶脑海中仿佛有亿万道惊雷落下！</p><p>走马灯！回忆杀！归乡剑断。他重伤垂死。天虚道人要杀他。</p><p>“我什么都做不到……”萧凡叶喃喃自语。</p><p>“我什么都守护不了……”眼前这人，简直是无敌！</p><p>无敌……？密码正确！</p><p>走完流程，突破一念起，渡劫巅峰境，顿觉天地宽，万物明如镜！</p><p>萧凡叶睁开眼。</p><p>那双漆黑的瞳孔深处，此刻不再是淡淡的金色光芒，而是璀璨的金光！</p><p>一股滔天威压从他体内爆发，将那天虚道人掌心凝聚的光芒震得粉碎。</p><p>萧凡叶仰天长啸，啸声穿透三十三层罡风，穿透界壁，穿透整个天墟界！</p><p>他的气息，正在以恐怖的速度飙升！</p><p>渡劫高阶一层……渡劫高阶二层……渡劫高阶九层……渡劫高阶九层后期……渡劫高阶九层后期巅峰……渡劫高阶九层后期巅峰大圆满！！！</p><p>无形的屏障轰然碎裂！</p><p>原本要花上数千年打磨突破的桎梏，如同行云流水，顷刻破解！</p><p>【萧凡叶在生死绝境中临阵突破境界：100%】</p><p>天地变色，大道轰鸣！</p><p>萧凡叶的身体从壁障中缓缓升起，周身浮现出无数异象。有星辰生灭，有日月轮转，有万物生长，有天地开辟。</p><p>他的气息，终于稳定下来。</p><p>渡劫巅峰！！</p><p>虽然只是初入巅峰，但那股威压，已经让天虚道人面色剧变！</p><p>“不可能！！！”他暴退万丈，眼中满是难以置信，“你、你怎么可能临阵突破到巅峰？！这不合天道！这不合法理！！这不——”</p><p>话音未落，萧凡叶已经出现在他面前。</p><p>一只手，抓住了他的天灵盖。</p><p>天虚道人的声音戛然而止。</p><p>他浑身僵硬，瞳孔剧烈收缩。那只手不大，甚至可以说是修长好看，但此刻落在他头顶，却如同整个天墟界压了下来！</p><p>“你刚才说。”萧凡叶开口，声音平静如水，“可惜我遇到的是你？”</p><p>他顿了顿，微微一笑：“现在呢？”</p><p>天虚道人浑身颤抖，嘴唇哆嗦，却一个字都说不出来。</p><p>萧凡叶没有再废话。</p><p>意念一动，神魂之力轰然涌入天虚道人识海！</p><p>大记忆恢复术，启动！</p><p>天虚道人的惨叫声响彻虚空，无数记忆碎片如同潮水般涌出。</p><p>三万年前，天墟真人找到还是渡劫初阶的天虚道人，收其为仆，赐下机缘。</p><p>作为代价，天虚道人，要替天墟真人办事！</p><p>具体便是作为特务，进入天墟界人间凡尘，破坏生产，搅乱秩序。</p><p>在各大上古秘境布下杀招陷阱，将那些崭露头角的天才打成废人，逼其被家族退婚，令其一蹶不振！</p><p>在各大洞天福地暗中破坏，将天地所化的至宝统统打成碎片，让后来者只能捡到些残渣！</p><p>在各大宗门之间挑拨离间，让正道与魔道势如水火，让散修与世家互相仇视！</p><p>萧凡叶看着那些画面，眼中没有愤和悲伤，只有一片平静。</p><p>难怪天墟界万年衰微，难怪天才总是陨落，难怪至宝总是残缺，难怪纷争永不停息，一切都是一只黑手，在暗中操纵一切。</p><p>【我只是做了微不足道的工作，把这尊太乙真仙十三万年掠夺的‘气运和因果’，返还给大地众生而已。】</p><p>二十年前，龙佑前辈所说之话他听得迷迷糊糊。</p><p>此刻萧凡叶终于
