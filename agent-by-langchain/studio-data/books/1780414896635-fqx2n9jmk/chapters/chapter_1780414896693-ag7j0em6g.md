# 第59章

<p>“所以，我才先从最‘安全’的犯罪率和腐败率下手。至少这些，社会有共识，有对应的法律和道德框架，修改的副作用……相对可控。”</p><p>龙佑嚼着炒河粉，若有所思。</p><p>【话说，你一句直接走向‘富强民主文明和谐自由平等公正法治’……不就得了？】</p><p>“你提出过的那个理论「N+1边形」定理，不只是对一个个体能生效，对一整个文明而言同样有用。”</p><p>下一瞬，他周身的信息屏蔽一层层剥落，外形调整到“允许被看见”的状态。</p><p>他要让那里的人看见他。</p><p>他要让全世界的人看到他。</p><p>看见一个从天而降、不知道是什么的东西。</p><p>20马赫的速度，撕裂大气层。</p><p>巷子里，只剩下那碗还剩一半的炒河粉，在垃圾桶盖上冒着微微的热气。</p><p>远处，下棋的老头喊了一声：“将军！”</p><p>……</p><p>“将军，我已经摸到他了。”</p><p>萨由迦。</p><p>废墟。</p><p>阳光晒得石头滚烫，空气里混着硝烟、腐肉和某种叫不出名字的香料味儿——后者是从远处那片勉强还算完整的居民区飘来的，晚饭时间到了，活着的人还要吃饭。</p><p>三百米外，一栋四层小楼的楼顶。</p><p>一把M24狙击步枪架在沙袋上，枪管伸出去，藏在几块碎石的阴影里。</p><p>枪托抵着一个男人的肩膀。那男人趴在楼顶，身上披着脏兮兮的吉利服，脸上涂着伪装油彩，只有一只眼睛露在外面。</p><p>呼吸很慢。心跳很慢。整个人像一块长在楼顶的石头。</p><p>耳机里传来刺啦的电流声，是将军沙哑的怒吼：“收手！立刻收手！这是命令！”</p><p>狙击手没动。</p><p>他的瞄准镜里，十字线稳稳地压在一个老人的眉心。</p><p>那老人大约七十岁，满头白发，穿着一件洗得发白的旧军装，站在一栋半坍塌的土楼前。周围站着七八个持枪的年轻人，有的警戒，有的在搬运物资，有的蹲在地上摊开地图。</p><p>老人的脸，狙击手认识。</p><p>整个珠赫占领军都认识。</p><p>阿卜杜拉·卡里姆。萨由迦抵抗游击队的精神领袖，西方媒体叫他“沙海之狐”，珠赫官方叫他“头号恐怖分子”。</p><p>三十年战争，三十年追杀，三十年来他像鬼魂一样在沙漠里游荡，每次围剿都让他逃掉，每次逃掉都会带出新一轮的反击。</p><p>但现在，他在狙击手的瞄准镜里。</p><p>十字线压着他的眉心，距离八百米，风速三级，湿度适中。</p><p>一枪下去，三十年战争就结束了。</p><p>“将军。”狙击手的声音微微发颤，不知道是紧张还是兴奋，“只要这一枪，我们就能结束珠赫的神圣战争！永远夺回萨由迦！”</p><p>耳机里沙沙了几秒。</p><p>然后将军的吼声几乎震破他的耳膜：“你他妈的听不懂人话吗？！收手！这是最高指令！立刻撤——”</p><p>狙击手没听见最后几个字。</p><p>因为他看见了。</p><p>瞄准镜里，那个老人的表情突然变了。</p><p>原本平静的脸，瞬间绷紧。那双浑浊的眼睛瞪大，瞳孔收缩，目光直直地——直直地看向狙击手的方向。</p><p>狙击手的心脏猛地一缩。</p><p>暴露了？</p><p>不对！他藏在这片废墟里已经14个小时，身上盖着伪装网，一动不动，连尿都撒在裤子里。</p><p>800米距离，逆风，对方没有热成像设备，不可能发现他。</p><p>狙击手的手指还搭在扳机上，但他没有扣下去。</p><p>他发现，那些人看的不是他藏身的方向……</p><p>他们看的是更高的地方。</p><p>是天空？是废墟上方？</p><p>狙击手的大脑飞快运转，试图理解发生了什么。无人机？空袭？还是什么……</p><p>“收手！这是命令！！”耳机已经破音了。</p><p>狙击手的手指终于从扳机上移开。</p><p>最后一刻，军人的天职还是占上风，他头脑清醒下来，遵守命令。</p><p>慢慢抬起头，然后他看见了。</p><p>M24狙击步枪，那支陪伴他六年、击杀过三十三个目标的枪，枪管上……</p><p>踮着一个脚尖。</p><p>一个脚尖，就这么轻飘飘地点在枪管上，像一只停在枝头的鸟。</p><p>一个穿着普通T恤和弹力休闲裤的男人，背对着他，双手背在身后，脚尖点在枪管上，整个人悬在半空，纹丝不动。</p><p>像水鸟立在芦苇上般自然。</p>
