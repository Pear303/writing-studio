# 天墟界的最后三日：光荣退休

<p>但那确实是赢，她跟随师尊的八百年来第一次胜。</p><p>她抬起头，看向萧凡叶。</p><p>衣袂在真空中轻轻飘动，长发如墨色云朵般散开，如同古老画卷中走出的仙人。</p><p>周身却没有一丝灵力波动，就那样站着，站在那里等着她。</p><p>女子的眼泪夺眶而出。</p><p>“师尊……”她的声音已经沙哑得几乎听不清，“为什么……为什么你……”</p><p>萧凡叶轻轻闭上眼，而女子也对着亦爱亦恨的师尊刺出最后一剑——这是他们的约定，只要她弈棋胜过师尊一局，萧凡叶便会交出自己的生命，实现他弟子数百年来的夙愿，尽管当这一天到来，他们却发现自己无从下手。</p><p>那一剑刺出时，女子眼中已没有恨。</p><p>只有泪。</p><p>三尺青锋化作一道素白流光，刺向萧凡叶的灵台——那是修仙者神魂汇聚之处，一剑入，神魂灭，再无轮回，再无来世。</p><p>这是他们的约定。</p><p>八百五十年前，萧凡叶收下这些背负血仇的孩子时，便立下此约：</p><p>‘若有朝一日，你们中有人能在弈棋上胜过我，我便将这条命还给你们。’</p><p>‘哦当然了，如果想通过下棋以外的方式，这条命也可以自己来拿。’</p><p>当时无人当真。</p><p>后来，他们将此约刻入骨髓。</p><p>再后来，每一次刺杀，每一次修行，每一次夜深人静时的苦练，都是为了这一天——为了有人能真正胜过师尊，为了那悬了八百五十年的剑，能够落下。</p><p>如今，剑落。</p><p>衣袂依旧在真空中飘动，长发依旧如墨云般散开。</p><p>只是那双眼睛，缓缓闭上。</p><p>二十余道身影从虚空中疾驰而来。</p><p>他们感知到了什么，便从人间界的赶来，却只来得及看见这一幕——</p><p>那柄素白长剑，刺入师尊灵台。</p><p>剑身没入，剑柄在外，女子握剑的手在剧烈颤抖。</p><p>萧凡叶虚弱地笑道：“不要哭，我只是去追寻更高的境界罢了。”</p><p>“更高的……境界？”</p><p>“你我‘星河弈道’，也算是为这场天墟界第一届‘奥林匹克’做了个好的开幕式……但与「那位大人」比起来，你我下棋的场面，简直就像是写在三流志怪小说话本上的无聊情节！”</p><p>大弟子微微震动：“那位大人究竟是……？”</p><p>二人的对话，没有任何旁人发觉。</p><p>而萧凡叶的身形，正在从剑尖处开始，一寸寸化作流光。</p><p>修仙者修行到极致，死后会化作天地灵气，反哺世界。</p><p>这是古籍记载的传说，从未有人真正见过。</p><p>因为能修到那个境界的，早已超脱生死。</p><p>但此刻，他们见到了。</p><p>萧凡叶的身形从灵台开始，化作无数细小的光点。那些光点如同萤火，如同星辰，如同他曾经教给他们的每一道剑光、每一句口诀、每一个道理。</p><p>光点越来越多，越来越密。</p><p>它们从萧凡叶身上剥离，向四面八方飘散，向整个人间界飘散，向整个天墟界飘散。</p><p>化道的过程，持续了整整一炷香。</p><p>萧凡叶的身形越来越淡，越来越模糊，最后完全化作漫天的光点。</p><p>那些光点如同一场无声的星雨，向人间界洒落，向整个天墟界洒落。</p><p>女子已经泣不成声，没有簪子固定的青丝在真空中飘散。</p><p>“魂淡！！为什么你装死去追求更强的力量还要我来给你演戏？！”</p><p>萧凡叶仍然温柔地笑道：“合格的老板，要适合体恤员工。”</p><p>“等等，我当老板！？”</p><p>而当他彻底消散的那一刻——</p><p>天地异变，灵气如潮。</p><p>那些光点落在大地上，落在山川间，落在河流中，落在每一寸土地上。它们所过之处，干涸的灵脉重新涌出甘泉，枯萎的灵草重新焕发生机，停滞的修为重新开始运转。</p><p>自从20年前以来，第二场席卷整个世界的天地机缘！</p><p>整个人间界，都在这一刻剧烈震颤。</p><p>空前威严的人声，伴随渺渺梵音从天而降：</p><p>“本皇此举，与天地奋斗，与万族奋斗，与己身奋斗——九百年矣，其乐无穷！”</p><p>那声音苍茫浩荡，如天道亲临，如大道轰鸣。</p><p>每一个字都化作金芒，烙印在虚空之中，烙印在每一寸山河之上，烙印在每一个生灵的神魂深处。</p><p>“九百年间，本皇斩邪修，诛天魔，平内乱，定四方。尔等所见，不过是本皇剑下尘埃；尔等所享，不过是本皇身后余荫。”</p><p>“然，本皇非为万世不朽而来。”</p><p>“本皇来自凡尘，终归凡尘。今日化道，非陨落，幸乃归乡。”</p><p>“今日此后，人皇之位，禅让于——”</p><p>漫天光点骤然一凝。</p><p>所有洒向人间的流光，所有飘向四方的萤火，所有正在融入天地的灵韵，在这一瞬间齐齐定格。</p><p>它们悬浮在半空，悬浮在山川之上，悬浮在江河之畔。</p><p>悬浮在每一个仰望苍穹的生灵眼前。</p><p>然后，那些光点开始汇聚。</p><p>它们从四面八方涌来，从人间界每一个角落涌来，从天上地下涌来，向着同一个方向涌去。</p><p>刺出最后一剑的女子。</p><p>光点如同朝圣般涌向她，涌入她的眉心，涌入她的灵台，涌入她的神魂深处。</p><p>……</p><p>“哈哈哈哈哈哈——”萧凡叶的意识在虚空中狂笑。</p><p>“九百年了！整整九百年！本座终于不用再当这破人皇了！”</p><p>他想起了什么？</p><p>想起了那些没完没了的宗门扯皮。</p><p>这个宗主要求分配更多灵石，那个世家抱怨被排挤，散修联盟天天闹着要平等地位——他堂堂合体期大能，愣是活成了居委会主任。</p><p>想起了那些层出不穷的危机。</p><p>天魔入侵、异族来犯、魔道复兴、海妖作乱——每次刚打完一场架，还没来得及喘口气，下一波就接踵而至，比打螺丝累。</p><p>想起了那些永远处理不完的政务。</p><p>什么“某某长老偷取某某宗门的灵兽炖了”，什么“某某弟子与某某弟子争风吃醋大打出手”，什么“某某家族想要联姻却被对方嫌弃”——他都快成了天墟界婚姻介绍所所长了，牵过的红绳比吃过的盐还多。</p><p>还有那些弟子。</p><p>二十几个！二十几个天天琢磨着怎么杀他的弟子！</p><p>他得时刻注意着不能伤着他们，还得想办法引导他们别走歪路。</p><p>还得在他们刺杀失败后，装作若无其事。</p><p>“这叫什么事啊！”</p><p>萧凡叶仰天长啸，虽然他现在没有“天”也没有“长”更没有“啸”。</p><p>老子当年在地球九九六的时候都没这么累！</p>
