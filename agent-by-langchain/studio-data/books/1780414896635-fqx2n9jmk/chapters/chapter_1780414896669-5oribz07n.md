# 荷鲁斯大拜寿

<p>……</p><p>萧凡叶最后是沉痛告别了所有修道者。</p><p>无论这些修道者是善意恶意，亦或是中立，亦或是事不关己，亦或是各怀心思……</p><p>那些修道者神色各异。惋惜，暗喜，如释重负，欲言又止。</p><p>但无论心中作何感想，面上皆是一派恭敬，齐声恭送人皇。</p><p>萧凡叶声称他并非修为尽失，还能使出几次炼虚巅峰全力，也有可能是几十次，或者几百次也有可能，所以你们尽量要安分。</p><p>说完一个乾坤大挪移，来到自己早期留下的后手洞府。</p><p>他本是凡俗穿越而来，无逆天机缘，无滔天背景，一步一百个脚印，步步皆是苦修。</p><p>恰逢世道混乱，危机四伏，前路杀机重重。</p><p>他不敢有半分懈怠，便暗中布下多处洞府，藏身留后路。</p><p>龙佑紧跟着这个渡劫期弱者，来到他洞府。</p><p>“为何要谎称自己境界跌落呢？这实在是很奇怪的事情耶。”</p><p>萧凡叶笑了笑，笑容里有九百年风雨，也有三十岁程序员的少年心气。</p><p>“也许是我比较偏执，比较特殊吧……我这样淡泊名利，只想当个门前扫地僧，扮猪吃虎做世外高人的穿越者，是不是很少见？大部分穿越者或许都喜欢打打杀杀，称霸称帝的吧？”</p><p>龙佑寻思，其实我目前为止也就见过你一个穿越者，没有其他例子做对照。</p><p>不过按照前世网文经验来看，穿越者确实能划分成两个大类。其一占据较多的是称王称霸，解放生产力，或是搞阶级固化，总之就是要逐鹿天下。</p><p>其二，就是坑蒙拐骗骗吃骗喝，无心逐鹿，只求小确幸。</p><p>‘其实我挺想知道他心里的真实想法。’</p><p>【嗯……就听一句吧，只能窃听一句哦。】</p><p>【萧凡叶三秒后在完全没意识到的情况下，吐露了一句真实心声：100%】</p><p>萧凡叶看向远方，笑道：“这狗吧人皇我真是一刻也当不下去，破事多得要死……”</p><p>龙佑便只能随口顺势说下去：</p><p>“咳咳，和900年光阴比起来，30岁人生过于短暂，有不少人眷恋冬夏汽水橘子味，春秋蝉鸣少年归，也有人回味童真纯洁的烂漫……”</p><p>萧凡叶也很感慨地叹了口气，目光穿透洞府的石壁，仿佛在看着那九百年来的风风雨雨。</p><p>“九百年……我杀光了那些到处炼制‘冒黑气的紫黑色人皇幡’的邪修。</p><p>“我也提拔了各大家族的‘陨落之星’，他们明明天赋卓绝，只因一时挫折便被家族弃如敝履的年轻人。</p><p>“还有那些被退婚的昔日之天才，也不知怎的，天墟界特别流行退婚，但凡有点天赋的少年少女，十有八九都会被另一方家族退婚。</p><p>“我找了他们，给了他们机缘。如今其中好几个已经是化神期的中流砥柱。</p><p>“我还四处收集那些掉落在‘没落家族’、‘隐蔽洞府’和各大‘宗门禁地’中的戒指、项链。</p><p>“有些戒指项链里，还真确实藏着老爷爷，有些只是普通的储物法宝。</p><p>“不过那些老爷爷老奶奶嘛，多半是上古修士的一缕残魂，执念太深，反倒无益。</p><p>“我将其中一部分超度，再以蕴含高阶心法与无上神通的器灵取而代之，归置原位。”</p><p>所以，天墟界整体力量很快会蒸蒸日上？</p><p>正是。我做的这些事，看似琐碎，其实都是在为天墟界积蓄力量。</p><p>我是地球人，明白你这么做的意义。</p><p>邪修横行时，正道凋零。天才被埋没时，后继无人。</p><p>如今这些隐患都被我一一拔除，再过两千年，不，以这里的灵气浓度，一千年就够了，天墟界就能涌现出一批新生代的化神、炼虚。</p><p>他看向龙佑，眼中带着一丝期待：“阁下若是有空，不妨在天墟界多留几日。这里的风土人情还是挺有意思的。”</p><p>龙佑沉吟片刻，既然萧凡叶都说时间流速既然如此悬殊，那他也打算在此界再留几日。</p><p>1:300的时间流速差，就算他在本地待一年，回去也才过了一天。</p><p>反正自己穿越异界的初衷，就是到处走走，顺带变强。</p><p>然而，当他们一踏出这处布置了隔绝禁制的洞府——</p><p>天变了！！</p><p>苍穹化作血色，如泼了亿万生灵之血，浓稠得几乎要滴落下来。</p><p>大地遍布妖气，黑雾翻涌，腥风扑面，百里之外的群山间隐约可见无数异族旌旗招展！</p><p>萧凡叶、龙佑：？？？</p><p>半空中，一道血雾炸开！</p><p>那青羽宗老妪的残躯四分五裂，龙头拐杖断成两截，从高空坠落，至死都没能发出惨叫。</p><p>紧接着，又是几声闷哼。</p><p>数道身影从云端砸落，如同断了线的纸鸢，轰然砸在萧凡叶与龙佑身前百丈处。</p><p>那是几个化神期的掌门，浑身浴血，胸骨塌陷，口中狂喷鲜血，将地面砸出数丈深坑。</p><p>萧凡叶瞳孔骤缩，怒意勃发：“反了天了！”</p><p>他抬头望去。云端之上，一道身影傲然而立。</p><p>正是那华服中年男子——玄阳宗宗主，贺卢思。</p><p>他拥有炼虚高阶的高深修为，在天魔一战中被萧凡叶任命为战帅。</p><p>没想到此刻居然叛变，这是人族与修道者的悲哀。</p><p>贺卢思双手背负，衣袂猎猎，周身环绕浓郁到近乎凝实的灵力波动，俯瞰众生，放声大笑。</p><p>“哈哈哈哈——！”笑声如雷，滚过天际。</p><p>“本尊困于炼虚高阶，八百载了！八百载！”</p><p>他笑声骤歇，面容狰狞，“奈何那萧人皇压我一头，压得我喘不过气来！我堂堂玄阳宗宗主，却要在他面前俯首帖耳，看他脸色行事！”</p><p>他俯视着下方，那些重伤垂死的化神期掌门，眼中满是快意：</p><p>“如今好了！天魔一战，他修为尽失，境界跌落，成了废人一个！如今大地还有何人能阻挡我了？本尊的好日子终于来了！”</p><p>一名灰袍老者挣扎着从坑中爬起，正是那日当先恭贺萧凡叶的灰袍老者，天罡宗宗主，化神巅峰。</p><p>他指着贺卢思，目眦欲裂：“贺卢思！你、你竟敢勾结外族！”</p><p>贺卢思冷笑：“勾结？本尊这叫借势！”</p><p>他大手一挥，身后云层裂开，露出遮天蔽日的景象——</p><p>北方，无数妖兵妖将踏云而来，兽头人身，煞气冲天。</p><p>南方，蛮族战士赤裸上身，纹满图腾，手持骨棒石斧！</p><p>东方，蛟龙腾云，鳞甲森然，龙威浩荡。</p><p>西方，灵族御风而行，身形缥缈，眼中却满是贪婪！</p><p>四方异族，齐聚中原！</p><p>贺卢思大叛乱，轰轰烈烈地开始了。</p><p>21-40【已阅】</p>
