# 绷不住了，直接激进的改革

<p>龙佑从巷子里走出来，买了两个包子一杯豆浆，边吃边刷手机。</p><p>新闻推送一条接一条：</p><p>「最近数日全国刑事案件数量骤降90%，专家称“极其罕见”」</p><p>「多地官员主动退还受贿款项，纪委：自纠自查效果显著」</p><p>「国际货币基金组织：全球贫困线以下人口出现大幅减少的趋势」</p><p>「股市暴涨，分析师：投资者信心空前高涨……」</p><p>……</p><p>龙佑咬了口包子，面无表情地刷过去。</p><p>【这就是你的温和改革，循序渐进。】潜龙绷不住。</p><p>“这不挺好的嘛。没有副作用，没有动荡，只是让世界变得好了一点点。”</p><p>【那是一点点？犯罪率跌成零，你管这叫不要太激进。】</p><p>【但是！】潜龙突然严肃起来，让龙佑都吓了一跳——他居然能被自己的想法吓一跳！</p><p>【你有没有想过，你设定的“犯罪率0%”，是怎么定义“犯罪”的？】</p><p>龙佑一怔：“……什么意味？”</p><p>【意思就是，不同国家、不同地区、不同文化，对“犯罪”的定义千差万别。】</p><p>【有些地方喝酒是犯罪，有些地方通奸要石刑。】</p><p>【你刚才那一句“犯罪率0%”，是按照哪套法律来的？】</p><p>龙佑张了张嘴，没说出话。</p><p>【还有腐败。你以为腐败就是收红包、拿回扣、公款吃喝？太天真了。】</p><p>【有些国家的政治献金制度，本质上就是合法的贿赂。】</p><p>【企业给候选人捐款，候选人上台后制定有利于企业的政策，这叫票选程序，不叫腐败。】</p><p>【还有一些跨国公司的避税行为，利用法律漏洞把利润转移到避税天堂，让发展中国家每年损失数十数百亿税收。】</p><p>【这算不算腐败？算不算犯罪？】</p><p>【但法律管不着，因为“合法”，没有法律能管得着。】</p><p>【或许你现在即可控制安理会，强制制定国际法，将跨国避税视作违法、政治献金定义为犯罪，侵略战争更是最大的罪恶。】</p><p>【事实上，即便是联合国，也很难无法干涉他国内政，国际法的法律效力……也约等于金圆券和滚木。】</p><p>“所以我说，这确实只是温和的改革了。”</p><p>【道路还得慢慢摸索。】</p><p>龙佑意念微动，时间长河与无穷世界线再次展开。</p><p>这次他没有修改概率，只是看。</p><p>他看到了一些地方。</p><p>那个被称为“萨由迦”的地区，战火已经烧了几十年。沙漠里的城镇被炸成废墟，孩子们在弹坑里玩耍，妇女裹着黑袍在废墟中翻找食物。</p><p>穿着不同制服的武装人员互相射击，迫击炮落在居民区，无人机在头顶嗡嗡作响。</p><p>他看到两个国家的军队在边境对峙，坦克列阵，导弹竖立，士兵们紧张地握着枪。</p><p>只差一个火星，就能引爆新一轮战争。</p><p>他看到一片混乱的地区，政府早已崩溃，黑帮划地为王。</p><p>他们收保护费，贩冰冰，走私人口，互相火并。街上躺着尸体，没人收也没人管，活人从旁边走过，面无表情。</p><p>他看到一艘艘满载难民的船在地中海倾覆，尸体被冲上海滩。他看到干旱的土地上，瘦骨嶙峋的孩子们排队领救济粮，而粮车被武装分子劫走。他看到工厂排放的毒烟遮天蔽日，癌症村里的人默默等死……</p><p>“你说得对……我原以为把犯罪率降到零，把腐败清零，世界就会变好。”</p><p>【一部分人会变好。】</p><p>【原本就生活在法治社会里的人，会过得更舒服。贪污的官员良心发现，小偷小摸消失，邻里关系和谐。】</p><p>【就像你楼下那个包租婆，主动给租客降房租，跟脑子被雷劈了一样。】</p><p>【但那些原本就没有“法治”的地方呢？那些战乱地区、失败国家、法外之地呢？】</p><p>【你的概率操控，是按什么标准执行的？是一国的法律，还是某种超国家的准则？】</p><p>龙佑沉默了。</p><p>【还有战争。你之前阻止了那场宇宙大战，但地球上的战争呢？】</p><p>【两国交战，不是“犯罪”——因为战争行为不受刑法约束。】</p><p>【士兵杀人不是触犯刑法，而是执行命令。轰炸平民区不是故意杀人，是附带损伤——虽然会被国际舆论声讨，但舆论是舆论，道德层面的约束宛如厕纸。】</p><p>【犯罪率0%，似乎管不了这些。】</p><p>龙佑看着时间长河里那些画面，看了很久。</p><p>“我听说过一个问题……如果有一个全知全能且正直善良的神，为什么看着大地的恶，却不出手尽除？”</p><p>【这是个老问题了。神义论，辩经辩了几千年。】</p><p>【有人说是为了给人自由意志，有人说是苦难是考验，有人说是魔鬼在作乱，有人说神自有安排。】</p><p>“但说到底，辩经改变不了现实。”</p><p>龙佑点点头。</p><p>“辩经改变不了现实。”他重复了一遍，“最终的变革，还需要实际行动。”</p><p>他站起身，把手里还剩半碗的炒河粉，轻轻放在巷口的垃圾桶盖上，让吃下这碗炒河粉的流浪猫100%会被阉割。</p><p>【这次打算怎么搞？再改一次概率？把全世界的战争和冲突都调成0%？】</p><p>龙佑摇摇头。</p><p>世界太复杂。即使是电子游戏，他也不一定能做到随便调调概率，就将地球变成乌托邦。</p><p>“犯罪率”、“贫困率”这些，是龙佑经过实验后，确认最不可能因为各种“副作用”导致文明走向崩坏毁灭的「温和改革」。</p><p>没错，对一整个文明的某项概率进行修改，有可能导致文明急剧走向自我毁灭。</p><p>比如，当龙佑通过修改概率的方式，曲线修改一个文明的“贫富差距”时。</p><p>【如同将一条湍急的河流强行堵住所有落差，看似水面平静如镜，实则整条河正在悄无声息地变成一潭死水。】</p><p>社会金字塔被削平，但新的形状没有出现，未来竟是一片混沌模糊。</p><p>没有人能积攒起足够撬动变革的杠杆，实验室永远运转，但只产生安全的、渐进的改良，没人敢押注颠覆性的可能。</p><p>失败成本由集体承担，成功收益也由集体稀释。</p><p>【就像把森林里所有树木修剪成同样高度，杜绝了乔木的雄伟，也扼杀了灌木和地被的生态位。】</p><p>龙佑看着那些世界线的概率可能性里，人类不再互相杀戮，不再极度饥饿，但也不再仰望星空。</p><p>“事实上，我看到人类文明的绝大部分可能性，都是走向灭亡。”</p><p>【大部分都是因为核战争、生化危机、气候灾变和宇宙威胁。】</p><p>【还有的诸如‘终产者’、赛博朋克、硅谷‘黑暗启蒙’等结局……】</p><p>“相比之下，慢性自杀的死水社会，反而是人类最幸福的终局。”</p><p>【所以那些能一念重塑世界的存在，反而更谨慎。】</p><p>【因为在绝对的力量面前，文明脆弱如孩童。】</p>
