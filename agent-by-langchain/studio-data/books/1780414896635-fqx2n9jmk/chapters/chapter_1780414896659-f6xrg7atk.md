# “天人合一的疗效”

<p>这一路走来太依赖外物。</p><p>此刻，龙佑顿悟，潜意识是对的。</p><p>安全感不该来自财富、权力或社会地位、名望这类虚无之物。</p><p>真正的安全感，只能来自对命运的绝对掌控，绝对的力量。</p><p>似乎一夜之间，他对财富、权力、名声、荣誉再提不起兴趣。</p><p>随手救姜笙，让她以最健康姿态重返人间，只为返还一份因果。</p><p>想了想，果然还是达不到太上忘情、坐忘离尘的境界。</p><p>便以20马赫隐身飞回稷海市，抽空买了张双色球头奖，原地兑奖。</p><p>正如潜意识所说，三千公里距离，只是下楼去小卖部买瓶可乐。</p><p>银行办完业务，付完20%个人所得税后剩下的200万奖金，通通塞进神州人民熟悉的黑卡。</p><p>黑卡，刻在神州人记忆里的神秘小卡片。理论上，似乎这卡一亮，酒店经理得跪地迎接，商场保安得90度鞠躬，甚至能调动相当于1145个师的私人军队，必要时能动用核武器给小娇妻放烟花。</p><p>事实上并非如此，黑卡只是较高等级的借记卡。</p><p>【你为什么还对这200万奖金这么执着？果真无法太上忘情？】</p><p>“毕竟生活在人类社会，目前人类文明运转逻辑仍以市场经济为主导。”</p><p>龙佑拿着黑金卡，思索片刻。</p><p>先打20万给父母，连同一份天衣无缝的中奖证明一并寄去。</p><p>钱不能一下子打几百万上千万，人上了年纪就容易心脏病。</p><p>循序渐进地打钱才不会吓着二老，他计划过几个月，又分期打一部分。</p><p>对现在的龙佑而言，钱想要多少也就是动动念头的事。</p><p>不够用，大不了再中几次彩票。</p><p>……</p><p>千里之外的姜笙坐在自家卧室发呆。</p><p>这几个月发生的事情太过离奇，她不敢相信自己就此康复痊愈，简直是把一生的运气都用在了这一回，从鬼门关强行迈回人间！</p><p>她手里捏着枚硬币，想把玩一下。</p><p>还没用力，那枚硬币像摆脱万有引力定律般晃晃悠悠飘起来，在指尖悬浮旋转。</p><p>硬币上旋转的菊花，仿佛在嘲笑牛顿棺材板压不住。</p><p>姜笙看着这违背常识的一幕，第一个念头竟不是恐惧。</p><p>“这超能力……怎么回事？”</p><p>她甚至已掏出手机想拍视频发给龙佑，配文都想好：“龙佑，你高中同学变成超人了！”</p><p>不知为何，自己居然第一个想起了极少交流过的高中同学，龙佑。</p><p>或许，是因为他当时毫不犹豫借了自己两万块，让她得以去下定决心做大手术？</p><p>姜笙知道，龙佑本身家境并不算优渥。她听几个消息灵通的同学说，高中毕业后，龙佑便光速进厂，说是“少走三年四年弯路”。</p><p>但就是他，却毫不犹豫给不太熟的陈年老同学借钱。</p><p>这种男人放在如今的社会，被称作ATM提款机、傻白甜，很容易就会被坏铝银骗去身家。</p><p>但姜笙完全没有嘲笑他的意味，毕竟算是对方救了自己。</p><p>而“变成超人”这一消息太过劲爆，姜笙不太想现场告诉父母。</p><p>不想告诉至亲之人和陌生之人，却反而想分享给认识没几年的网友、同学，这在心理学上叫做“选择性自我披露”。</p><p>那就告诉龙佑吧……她如是想。</p><p>毕竟大男孩都喜欢超能力者、超级英雄和超级地球之类以“超”字打头的事物。</p><p>念头刚起，脑海却是深处炸开白光！</p><p>庞大不讲道理的信息流，蛮横接管她的视觉神经。</p><p>她看到自己昏迷时的景象。</p><p>黑点撕裂大气层，以20马赫极速划破长空。那是流星？不……那是龙佑！！</p><p>她看到医院外五公里处，静静注视着大楼的身影，如神明俯瞰蝼蚁。</p><p>龙佑！！</p><p>那种孤寂与强大，让她心神巨震。</p><p>视野继续拉远，脱离地球。</p><p>她看到这片大地生长的脉络，山脉像蚯蚓隆起塌陷，沧海桑田在眼前快进。</p><p>人类城市像真菌在地球表面蔓延、凋零、再蔓延。地形变幻，生灵迭代，这片土地的过去与未来像翻书在她眼前哗啦啦翻过。</p><p>视角再次拔高。</p><p>宇宙大爆炸火光在视网膜炸裂，星云旋转，恒星燃烧殆尽化作黑洞。黑洞蒸发，宇宙归于热寂，热寂逆转，时光倒流，万物重组回那个极小的奇点。</p><p>宇宙从诞生到灭亡，从灭亡倒流回诞生的全部过程，在一刹那间走完。</p><p>所有画面崩塌、压缩，最后化作冷冰冰、硬邦邦，却又至高无上的概念。</p><p>或许可以称之为概念，但这终究只是勉强比喻。姜笙无法形容那是什么。</p><p>那个勉强可比作概念的东西，狠狠砸进她意识中央。</p><p>【天人合一】</p><p>“该实验性手术取得‘理想中最圆满的完美效果’，便是……【天人合一】？！”</p><p>姜笙感到前所未有的宏大感充斥全身。</p><p>她不再只是那个躺在病床上的虚弱女孩，此刻，她是这片天地，她是这片宇宙，她是万物运行的基石！</p><p>我与天地合为一体，我即是天地！</p><p>我于万物之中！</p><p>在这浩瀚如烟海的信息洪流里，她试图寻找那个熟悉的身影——龙佑。</p><p>“龙……他为什么也能飞……”</p><p>“让我用天人合一的境界，略微一个窥探他的过往……”</p><p>姜笙皱眉。姜笙咬牙。姜笙瞳孔震动。</p><p>除了在极小部分的“时间线”上，在光阴长河的其他绝大部分位置，她都看不到龙佑！</p><p>关于龙佑的信息，尽是触目惊心的空白！</p><p>除高中二人打照面时点点滴滴，以及她做那场实验性手术时，龙佑划破大气飞来的身影清晰可见之外。</p><p>他的过去、未来、出身、归宿……全蒙在浓稠得化不开的黑雾里。</p><p>哪怕调动此刻足以洞察星河的神识，也无法穿透那层迷雾分毫！</p><p>信息，完全被屏蔽！！</p><p>即使是【天人合一】的她，也无法看清！！</p>
