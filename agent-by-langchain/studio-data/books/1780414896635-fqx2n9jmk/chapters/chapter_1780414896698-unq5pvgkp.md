# 第69章

<p>走廊尽头又是一道闸门，小蓝刷了卡，门开后露出一个不大的会议室。</p><p>“先走流程。你们两个要注册为‘在编异人’，之后才能享受龙组的‘福利待遇’。”</p><p>林云猫娘盘起尾巴：“什么福利待遇？”</p><p>“五险一金，补充医疗保险，每年一次免费体检，过年发米面油和坚果礼盒。”</p><p>“……啊？”</p><p>“当然还有高温补贴和低温补贴。外勤人员有额外的危险津贴，按任务等级算，1级任务一次一千，2级三千，3级一万……”</p><p>“等等等等，你们不是神秘组织吗？不是应该发什么灵丹妙药、修炼功法、天材地宝之类的？又或者是做任务得什么贡献点，再用贡献点兑换什么神通秘籍天材地宝……”</p><p>“哦对没错，出差花销可以报销。”</p><p>“不是等等！你们这和政府部门到底有何区别？除了挂着‘有关部门’的神秘头衔，完全就没差别了好吧！”</p><p>小蓝难得正面回答她的吐槽：“还是有区别的，我们不会授予干部等级，也没有五险一金，因为我们的工作，事迹，不会出现在任何向社会公布的资料中……”</p><p>他说这些话的时候，脸上是神圣的悲壮。</p><p>林云猫娘认为他的悲壮来自没有五险一金，而不是因为工作的神圣。</p><p>小光从外面推门进来，手里拿着两个平板电脑，一个递给龙佑，一个递给林云。</p><p>“填表。个人信息、能力类型、预估等级，能填的填，不能填的留空。”</p><p>猫娘叹气，又是典型的填表。</p><p>要是撇开所有奇人异士，这就是个普通的行政部门啊。</p><p>龙佑接过平板，扫了一眼上面的表格。</p><p>【姓名】【年龄】【能力类型】【能力描述】……</p><p>他在能力类型那一栏犹豫了一下，最后只勾了【体质强化】。</p><p>能力描述写了四个字：力气很大。</p><p>小蓝站在他身后，看见这四个字，嘴角抽了抽，但什么也没说。</p><p>林云那边就热闹多了。她捧着平板，尾巴在椅子腿上缠来缠去，表情纠结得像在做高考数学最后一道大题。</p><p>“能力类型……这个怎么填喵？我能变猫娘算不算？还有莫名其妙的手里冒盐的能力……”</p><p>“手里冒盐？把你所有能做的都写上去，哪怕觉得没用的也写，我们见过比‘手里冒盐’更离谱的能力。”</p><p>林云低头在平板上戳戳点点。</p><p>嘴里念念有词：“能力描述……‘突然变猫娘，力气比普通人大一点，恢复速度很快，受伤后能自愈，有时候手里会突然出现一包盐’……”</p><p>她抬起头：“这个‘有时候手里会突然出现一包盐’真的有必要写吗喵？”</p><p>“龙组档案库里有一条备注是‘某异人能力为隔空生成香菜’，后来在一次任务中靠这个能力救了全队的命，你永远不知道哪个能力会在什么时候派上用场。”</p><p>“所以隔空生成香菜是怎么救人的……”</p><p>林云老老实实把“冒盐”写上去了。</p><p>填完表，小蓝带他们去测试场。</p><p>测试场在地下更深处。</p><p>穹顶和墙壁，都覆盖一层灰白色复合材料，上面布满了细密的划痕和灼烧痕迹。</p><p>场地中央立着几台形状各异的设备，有的像举重器械，有的像测力计，还有几个直径数米的圆形靶标挂在远处的墙上。</p><p>“这是基础测试区，先测基础六项，力量、速度、持续、精密、成长。另外还有些‘特殊能力评定’，比如看你那个冒盐的能力。”</p><p>“呃，这六项面板听起来好耳熟，感觉下一秒就要被荒木告上法庭。”</p><p>首先被拉去测试的是龙佑，因为他是小蓝小光此次行动的主要目标，而猫娘只是顺带捡到的罢了。</p><p>而且龙佑先生的“力量”项目还不需要测试，因为已经有现成资料，更重要的是他们也没那宽裕的场地，可以让龙佑挥出全力一击。</p><p>“按照你在萨由迦的表现，破坏力超过7级，唉，真是最麻烦的差事。因为我要长篇大论写报告，去申请一个更高的新等级‘力量8级’作为你的档案记录。”</p><p>龙佑：“这7级8级又是什么概念，我也不是很清楚。”</p><p>“我们用的计量方式其实很简单——里氏地震等级。你听过吧？”</p><p>龙佑点头。</p><p>里氏震级每增加一级，能量释放增加大约32倍。两级之间差大约1000倍。</p><p>6级力量，相当于里氏6级地震，能量释放大约是1.5万吨TNT当量，差不多是广岛那颗。</p><p>1级是普通人到特种兵的范畴，而龙组先前招收过力量等级最高的奇人异士是7级。</p><p>相当于五十万吨TNT当量，大约是广岛那颗的30倍，可以说那是一枚人形自走核武器。</p><p>“那位前辈现在退休了，在海南岛养老，每天钓钓鱼，偶尔帮当地渔民赶赶鲨鱼。”</p><p>“……赶鲨鱼？”</p><p>“他原本是大概史上最强的人吧，直到你出现了。按照你在萨由迦的表现，破坏力已经超出了7级的测量范围。”</p><p>小蓝揉了揉太阳穴，表情苦恼。</p><p>“也就是说，我要写一篇长篇报告，去申请一个新的等级——力量8级，作为龙佑先生你的档案记录。还要附上现场视频、目击者证词，以及至少三位7级评定员联名确认……我们会尽量在一个月内为您安排好……”</p><p>“一个月？”</p><p>“不顺利的话，可能要三个月，毕竟8级是全新标准，力量可达到1500万吨TNT当量……”</p><p>龙佑谦虚至极：“也不是每次都能打出来，那次是情况特殊。”</p><p>“没事，档案按峰值记录。”小蓝叹了口气，“行了，‘力量’一项就这么定了。至于速度、持续、精密这三项，我都给你填到8级上限吧。也不需要测了。”</p><p>“这么随便？”</p><p>“我们这儿也没那设备，你这种级别的，测了也是白测，数据全是溢出。”</p><p>“那走吧。”小蓝转身往外走，“继续走流程。”</p><p>小蓝声称，刚才只是能力评定。</p><p>后面还有背景审查、权限分级、装备申领、紧急联络人登记……龙佑听得头大。</p><p>“所以你们这个组织，真的很像一个有关部门。”</p><p>“其实确实如此，我们是全世界最家大业大的异能者组织，和官方有深层次的合作关系。就这座基地，管理着神州的‘秦岭-淮河’以南大部分异能者，每个月都有不少新人。”</p>
