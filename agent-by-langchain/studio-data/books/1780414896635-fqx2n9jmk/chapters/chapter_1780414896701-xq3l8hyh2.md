# 第73章

<p>每一段描述对应的攻击力都在递增，但她的用词变化揭示了一个恐怖的真相。</p><p>——每次面对新量级的攻击，她都会先“受伤”，哪怕只是短暂的疼痛或红印。</p><p>但只要承受住了这一击，她的身体就会在瞬间完成某种进化！</p><p>防御力狂增暴增猛增劲增！</p><p>直至把“这种力度”彻底免疫！</p><p>他盯着监控画面里那只正低头整理衣服的猫娘。她的尾巴从卷曲状态慢慢松开，在身后轻轻晃着，姿态轻松得可怕。</p><p>“再测一轮。”</p><p>“还测？机炮？”</p><p>“不，回到12.7毫米，同一把反器材步枪，同一批弹药，同一个位置！”</p><p>“快装填！”技术员吼道。</p><p>中年人被他的气势震慑，犹豫了一下，颤抖着重新固定好反器材步枪。</p><p>林云站在场地中央，看着那把枪，尾巴又卷起来：“还来喵？不是打过了吗？”</p><p>“同一级别，确认一下数据。”</p><p>“哦，那来吧。”猫娘有些不情愿地站直了身体。</p><p>砰！枪声再次轰鸣。</p><p>子弹打在她胸口同一个位置。</p><p>没有击飞和后退，这次甚至连晃动都没有。</p><p>弹头在接触她皮肤瞬间，直接碎裂崩飞，像是撞上了一块坚不可摧的强相互作用力板子。</p><p>衣服上留下了个新洞，但皮肤完好无损。</p><p>林云低头看了看，伸手把落在衣领里的弹头碎片捡出来，扔在地上。</p><p>“咦呦，这次不疼了呀。”</p><p>技术员把手里的记录本合上，又打开，翻到防御等级那一页。他颤抖着划掉了之前的问号，写下了几个字，笔尖划破了纸张。</p><p>中年人凑过去看他的屏幕，调出所有数据对比图。</p><p>一条曲线清晰地画在那里——每一轮测试，第一次攻击时防御数值会有短暂的跌落，那是身体在“受击”，然后瞬间弹回。</p><p>第二次攻击时那条线几乎拉成直线，平得没有任何波动。</p><p>第一击有用。之后都没用。</p><p>不管第一击多强，只要没把她打死，第二次就是零！</p><p>中年人的声音发干，像是被人掐住了脖子：“这能力要是继续往上测，她能到什么程度？”</p><p>林云正蹲在地上捡弹头碎片，一枚一枚码在手心里，嘴里数着数，尾巴在身后悠闲地甩动。</p><p>她似乎在习性上也开始向猫逼近了。</p><p>“不知道，但我觉得，我们这儿的设备可能测不到她的上限。”</p><p>技术员说，声音里透着一种深深的无力感。</p><p>她把记录本重新翻开，在防御等级那一栏重重写下几行字：</p><p>「适应进化型防御。机制：首次承受伤害后，对该级别及以下攻击完全免疫。」</p><p>「阈值：未知。上限：未测得。建议：后续测试需更高等级火力及非常规攻击手段。」</p><p>「另，测试用服装损耗严重，请补充库存。」</p><p>「再另，申请启动对异人“林云”抹杀方案的研讨计划。」</p><p>「再再另，实验测试场地局域网极不稳定！建议调拨更多工程建设经费进行修缮！」</p><p>……</p><p>“这里是哪了咧？”</p><p>“女士，这里是我们给你安排的新测试间，划分出了一个新的‘局域网’。”</p><p>穿白大褂的研究人员又在嘀咕什么“局域网崩溃”之类她听不懂的词语。</p><p>无所弔谓，不需要听懂。</p><p>毕竟她是包租婆，在稷海市躺着收租，就能过上滋润的日子。</p><p>说实话，现在她有些后悔，为什么闲着没事去医院检查身体。</p><p>结果惹上这么大摊子，被一群人带到这神秘小房间里，搞各种奇奇怪怪的测试。</p><p>包租婆坐在小房间里，面前摆着部看不出牌子的手机。研究人员让她在这儿刷短剧，说是要测什么数据。</p><p>她倒也配合——反正不用自己交电费。</p><p>包租婆自个平常不是打麻将就是刷短，生活挺滋润的，这项活动对她来说并不算艰难，而是惬意的消遣。</p><p>她面前摆着部看不出牌子的手机，全剧一百集，二倍速播放。</p><p>最终的测试结果：</p><p>共计九十一集都发生了局域网崩溃，画面卡住，进度条转圈，必须关掉路由器重进，才能继续。</p><p>技术人员在档案上记录。</p><p>「实验对象观看短剧时，有大约90%概率导致本地局域网崩溃。」</p><p>包租婆叹了口气：“所以我说我说的都是真的。那个医生还想把我送去精神科。</p><p>“你们愿意相信我是吧？能不能告诉我，我身上到底发生了什么？</p><p>“我现在看短剧每十次就有九次卡顿，真的很痛苦啊啊啊啊！！”</p><p>“你现在的情况很复杂。”技术人员说，“你好好回忆一下出现这种情况的第一天，以及前几天发生的事。”</p><p>包租婆想了一阵子：“好像也没发生什么，就是日常往脸上贴黄瓜、敷面膜、打麻将、煮面、看短剧。哦对了，当时还有个欠房租的租客主动退租走了。”</p><p>技术人员面面相觑。</p><p>“你之前的口供也是如此。”</p><p>其中一个说，“但我们查过摄像头和你的社交媒体记录。那一日没有任何租客离开，只有一个新租客住进了原本就空着的房间。”</p><p>包租婆有些生气：“怎么会？难道一个大活人在网络中的信息会被完全抹掉？难道我的记忆都是假的？”</p><p>“关于那一天，以及前后两周，我们只找到一个退房的人，叫王德发。”</p><p>“不是王德发！那个年轻人姓……烦死了，我忘记他姓什么了，可能姓陆，或者姓刘。我手机上存了记录。”</p><p>“我们确实多次检查过你的手机，你也和我们一同检查过，确实没有找到姓氏L开头、月底欠款退租的租客。”</p><p>包租婆张了张嘴，把要说的话咽回去。</p><p>她低头盯着手机屏幕，手指悬在播放上方，迟迟没按下去。</p><p>“那我刷短剧时总是会断网，这究竟是怎么回事？你们已经用过很多部手机给我测试了……不是我个人体质问题吧？”</p><p>“呃女士，目前我们还不能给出结论……”</p><p>……</p><p>【你看短剧到高潮处突然网络卡顿的概率是90%！】</p>
