# 地球爆炸！（一）

<p>“不要喊前辈。”女子摆摆手，语气随意，“在这‘凡俗’之中，不要涉及‘超凡’之事物。”</p><p>萧凡叶心中一动，当即点头：“明白。”</p><p>入乡随俗，要守规矩，他懂。</p><p>不过也只是三年不见，这地球习俗变得这么奇怪？</p><p>女子看着他，问道：“你就是龙佑先生介绍来的‘异乡人’？”</p><p>萧凡叶心中一震。“异乡人”这个称呼，加上“龙佑先生”四个字——</p><p>果然，龙佑前辈料到他近期就会回到地球！</p><p>但那位前辈不露面见他，必然也有他的深刻理由。</p><p>“是的。”萧凡叶点头，语气恭敬了几分。</p><p>女子从包里取出一张名片，递给他。</p><p>萧凡叶接过。名片设计简约，白底黑字，只有几行信息：</p><p>「姜笙」</p><p>「潜龙基金·首席执行官」</p><p>「地址：稷海市一环XX大厦负二层」</p><p>「面试时间：明日上午10点」</p><p>萧凡叶的目光落在左上角那两个字上——潜龙。</p><p>那位神秘的龙佑前辈果然不凡，能将一位太乙真仙起步的强者，都给收为自己小弟。</p><p>他抬起头，看向姜笙，眼中带着探寻。</p><p>姜笙微微一笑，语气平静：“记住，在凡俗社会就要讲凡俗社会的规矩。不要越界。”</p><p>她将一头长发摘下来，露出才刚刚长出稀疏短毛的光头。</p><p>“如你所见，我在这凡俗社会中的‘人设’是一位刚刚癌症痊愈的女子，所以用的是假发。”</p><p>萧凡叶郑重地点点头。</p><p>他活了九百年，见过无数规矩。宗门的规矩，世家的规矩，皇朝的规矩，天道的规矩——</p><p>但“凡俗社会的规矩”，他还是头一回需要认真遵守。</p><p>就连一个太乙真仙级强者，都不能控制自己的头发快速生长出来，而必须用“假发”这种手段来加以装饰。</p><p>有意思。</p><p>姜笙将那张黑卡递给他：“这里面有500万现金额度，你先用着。尽量低调，别露富。身份的事我会帮你办，大概一周左右。”</p><p>萧凡叶接过黑卡，低头看着那张薄薄的卡片，心中涌起一股复杂的情绪。</p><p>姜笙已经转身走了几步，忽然停下来，回头看了他一眼。</p><p>“还有，我们正好缺一个程序员岗位。龙佑先生说你是个人才，应该能胜任。”</p><p>萧凡叶嘴角微微抽搐。</p><p>九百年了，他从天墟界杀回来——然后回来继续当程序员？</p><p>“没问题。”他点点头，“我当年在某大厂干过年。”</p><p>姜笙笑了笑，戴上墨镜，转身走进人群中。</p><p>萧凡叶低头，又看了一眼那张名片。</p><p>「潜龙基金」</p><p>潜龙是何意味？潜龙勿用，阳在下也。</p><p>意思是力量尚未成长起来，必须先苟着。但这只是最表面意思，萧凡叶知道，其背后还蕴有更深刻的意味。</p><p>但或许除却龙佑前辈，再也无人知道他究竟在布何局。</p><p>“行吧，那就……先当个程序员。”</p><p>萧凡叶想到，他恐怕是这【地球上】的【最强程序员】了。</p><p>强者之中，没人比他更懂编程；而程序员之中，也没人比他力量更强！</p><p>……</p><p>龙佑心情不错。</p><p>他刚接到姜笙消息，没想到【地球最强程序员】这么快就来应聘了，不是外国佬，貌似是个小年轻，而且还是同省老乡！</p><p>果然江山辈有人才出，前浪死在沙滩上啊。</p><p>龙佑忽然顿住。</p><p>【察觉到了？】</p><p>“确实不对……世界线变动了。”</p><p>他静静地站在那里，目光穿透夜空，穿透星辰，穿透无穷维度，看向那汹涌的光阴长河。</p><p>龙佑意念微动，太乙真仙的浩瀚法力瞬间涌出，笼罩整个可观测宇宙。</p><p>光阴冻结！砸瓦鲁多！！</p><p>全宇宙，时间暂停。</p><p>街头的一切都静止了，路边正在遛狗的大爷保持着抬腿的姿势，狗尾巴悬在半空。夜风停止了吹拂，连月光都定格在空气。</p><p>龙佑神色微动。无数条世界线，正在他眼前疯狂闪烁。</p><p>每一条，每一条，每一条。</p><p>都在指向同一个终点——地球原地爆炸！</p><p>【地球，在一年内爆炸：99.99%】</p><p>【一个月内爆炸：99.95%】</p><p>【一日内爆炸：99.91%】</p><p>那几乎已经逼近100%的必然。</p><p>“原因呢？”龙佑问。</p><p>潜龙：【难道你在问我？你在问你自己的潜意识这是怎么回事儿？你觉得会有答案吗？】</p><p>答案浮现在眼前了，太乙真仙修为果然是六边形战士，情报探查能力也一级棒。</p><p>他原地闭目3小时，差点进入快速眼动期，很快便找到了地球爆炸的源头。</p><p>那是一颗恒星，距离地球约40光年，一颗质量是太阳三十倍的蓝超巨星！</p><p>它生命走到尽头，核心坍缩，外壳崩塌，早已在40年前爆发成超新星！！</p><p>而那道从恒星两极喷射而出的伽马射线暴，如同一柄贯穿宇宙的长枪，笔直地指向太阳系的方向！</p><p>40光年的距离，在宇宙尺度下不过咫尺。</p><p>那道伽马射线暴将以光速横扫而来，所过之处，一切生命都将被蒸发殆尽。</p><p>【伽马射线暴。能量聚焦在两极，射束宽度极窄，但精度极高。它在40年前以光速发射，将在23小时47分钟后抵达地球。】</p><p>龙佑叹气，真不想上班啊，但地球又不能放着不救。</p><p>“行吧。”他说，“那就再忙一次。”</p><p>太阳系边缘。</p><p>龙佑悬停在虚空之中，身后250亿公里处，那颗淡蓝色的小点安静地悬浮在黑暗里。</p><p>二百五十亿公里，光要走差不多24小时。</p><p>这个距离足够将太阳系边缘与地球分隔成两个世界，人类目前为止航行最远的航天器旅行者1号，也差不多是这个距离。</p><p>但在伽马射线暴面前，不过是薄纸一张的间隔！</p><p>那道射流从四十光年外轰来。</p><p>一颗恒星倾尽余生积蓄的全部能量，被压缩成一根细到极致的针，笔直地刺向太阳系。若将蓝超巨星比作一把枪，地球便是枪口正对的靶心！</p><p>龙佑闭上眼。</p><p>再睁开时，他的身体开始膨胀！</p><p>太乙真仙级别的法天象地，肌肉纹理化作山脉，血管奔涌如大江，骨骼撑开虚空，皮肤表面浮现出道道仙纹。</p><p>那些仙纹在天墟界足以镇压一方星域，此刻在这片法则截然不同的宇宙中暗淡了大半，却依然清晰可辨。</p><p>【何时来的新设定，怎么就法天象地了？】</p><p>“都成仙了，如果不能膨胀成大只佬，那不是白成仙了吗？”</p><p>龙佑长到十公里高，二十公里，五十公里。</p><p>双脚踩在虚空里，双手张开，十指如栅栏般将那根致命的细针拦在身后。手掌摊开，掌心朝外，每一道掌纹都深如峡谷。</p><p>然后那道伽马射线暴到了！</p><p>“仙元护罩！”</p><p>【完全没听过的仙术啊！你前面能不能有些铺垫！你这样子写小说会被读者达斯的。】</p>
