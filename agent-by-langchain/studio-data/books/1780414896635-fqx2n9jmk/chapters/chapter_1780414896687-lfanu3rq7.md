# 地球最强程序员

<p>稷海市，人民公园。</p><p>初秋的傍晚，阳光斜斜地洒在人工湖面上，泛起粼粼波光。</p><p>没人注意到，湖边那棵老柳树下，凭空出现了一道古色古香的身影。</p><p>萧凡叶愣愣地看着眼前的一切。</p><p>那些穿着普通的路人，那些现代化的建筑，那片他曾经无数次路过的湖面，那条他曾经晨跑时经过的小径。</p><p>九百年前，他就是从这里离开的。</p><p>九百年后，我又回来了！！</p><p>眼泪毫无征兆地涌出。萧凡叶站在那里，泪水滚落，打湿衣襟。</p><p>太乙真仙境界，极道修为，助他穿过野生的空间裂缝来到世界之外的虚无空白之地。</p><p>归乡，归乡……</p><p>按照时间流速推算，他在天墟界的20年，不过是地球的差不多一个月。</p><p>他是如何在茫茫的天外，中找回地球？</p><p>太乙真仙本身就能遨游世界之外的“天外光海”，看到一个个不同宇宙。</p><p>萧凡叶还是比较幸运的，他刚飞升到天墟界外，扭头一看，就看见自家的地球宇宙在一旁，挨得很近！</p><p>就跟撞在一起一样！</p><p>萧凡叶站在柳树下，任眼泪流着。</p><p>半晌，他深吸一口气，抬袖拭去泪痕。</p><p>总之，现在已经拿到了“无敌仙尊回归都市”的剧本，先让他试试这地球能不能施展仙道吧。</p><p>萧凡叶抬手，指尖凝出一缕剑意。</p><p>那剑意悬在指尖轻轻颤动，足以斩碎星辰，是字面意思能够把主序星细细地剁成臊子！</p><p>他试着催动，剑意暴涨三丈。他估算着全力一击，或许能毁掉方圆数百光年的恒星。</p><p>萧凡叶笑笑，收剑，负手而立。</p><p>目前还有些水土不服，力量比在天墟界弱上一筹。这就是近乡情更怯，不敢问来人，连力量都不能恣意地施展出来了吗。</p><p>要发挥自己无敌仙尊100%的实力，或许还要待上一段时间。</p><p>但重要的是，他回来了。</p><p>他再次放开神识，这一次是为了找人。</p><p>龙佑前辈。</p><p>那个第一次出现在天墟界时，整个人笼罩在黑色、连世界都无法承载其「信息」的存在。</p><p>那个随手砸出五十道太乙仙术、精准预判他每一步突破的存在！</p><p>神识漫过城市，漫过大陆，漫过星球，漫过太阳系——没有。</p><p>什么都没有。</p><p>那种感觉太熟悉了。萧凡叶一阵恍惚。</p><p>当年在天墟界，龙佑前辈第一次现身时，他拼尽全力也只能感知到一团模糊的人形轮廓。</p><p>除此之外，位置、速度、气息、修为，一概不知。</p><p>整个世界法则在那道投影面前失效！</p><p>如同老旧手机强行加载3A游戏，能显示的只有满屏错误贴图！</p><p>此刻亦然。</p><p>萧凡叶收回神识，站在柳树下沉默良久。</p><p>龙佑前辈，他就在这个宇宙，就在这颗行星上，甚至可能就在这座名为“稷海”的城市里。</p><p>但他感知不到，如同蚂蚁感知不到人类的存在！</p><p>不是刻意隐藏，而是蚂蚁的感官结构里根本没有“人类”这个维度。</p><p>蚂蚁只能感知到地面上的米粒，和同伴留下的信息素，以及时不时从某个不可名状维度降临的巨大肉柱——简称人类小屁孩碾蚂蚁玩时伸下的手指。</p><p>他想起龙佑前辈说过的话：“那只是我的投影。”</p><p>龙佑前辈的投影，就已经超出了天墟界所能承载的极限。他的本体在这个宇宙中，又将是何等的不可名状之恐怖？</p><p>萧凡叶对着虚空躬身一拜。</p><p>三拜之后，他直起身，望着这座熟悉又陌生的城市。</p><p>前辈没有现身，便是不想见。</p><p>既如此，便不该冒昧强求觐见龙佑前辈。</p><p>萧凡叶抬步，走向公园出口。</p><p>夕阳将他的影子拉得很长，衣袂在晚风中轻轻飘动。路上行人偶尔瞥他一眼，只觉得这穿古装的小伙子挺有气质，大概是哪个剧组的演员下班了。</p><p>萧凡叶回到地球做的第一件事，竟然是去小茶楼搓了一顿。</p><p>虾饺，凤爪，烤馍，铁锅炖，菌子煲，西湖醋鱼，酥油奶茶，皮蛋酸奶，再来一壶榴莲味普洱——这店里啥都能吃到。</p><p>九百年了，他做梦都在想这一口。</p><p>结账的时候，服务员递过来一张单子：“您好，一共388元。”</p><p>萧凡叶看着那张账单，陷入了沉思。</p><p>388元。放在九百年前他能大手大脚付款，眉头都不会皱一下。</p><p>那时候他虽然是个苦逼程序员，但一顿300多块的饭还是请得起的。</p><p>大厂码农虽然要996，但工资也是特别爽。实际上996本来就是指互联网IT行业，高强度加班配上高强度工资。之后才被黑心老板推广到了各行各业，用于PUA员工。</p><p>但现在呢？</p><p>他刚从天墟界回来，身上既没有软妹币，也没有手机支付，甚至连身份证都没有——那玩意早在三年前公安局给他开办死亡证明的时候，就过期八百回了。</p><p>服务员站在那里，保持着职业微笑，但眼神已经开始变得微妙。</p><p>萧凡叶面不改色。</p><p>他可是太乙真仙，渡劫期大能，前·人皇，现·太乙真仙。蛐蛐三百多块钱，能难倒他？</p><p>实在不行，一个空间挪移就走人，或者用幻术让服务员以为他付过钱了，或者直接隐身……</p><p>“我来吧。”</p><p>一只白皙的手伸过来，将一张黑卡递到服务员面前。</p><p>萧凡叶转头看去。</p><p>一个年轻女子站在他身旁，戴着墨镜，一身都市职业女性打扮。白衬衫，黑色西裤，简约干练。长发披肩，气质清冷，像从杂志封面走下来的人。</p><p>服务员接过黑卡，刷了一下，恭敬地递回去：“好了，请慢用。”</p><p>女子点点头，收起黑卡，转身看向萧凡叶。</p><p>萧凡叶下意识地探出神识——</p><p>然后他的神识撞上了一片浩瀚星海！</p><p>神识探进去，如同萤火没入烈焰，瞬间被吞没，连个回响都没听见。</p><p>萧凡叶瞳孔微缩。</p><p>太乙真仙境界，而且是太乙真仙……巅峰？甚至更高？</p><p>他当即收敛气息，微微欠身：“多谢前辈。”</p><p>女子笑了笑，摘下墨镜。</p><p>那是一张年轻的面孔，五官精致，皮肤白皙，看起来也就二十出头。</p><p>但那双眼睛里，却藏着某种难以言喻的深邃——那是萧凡叶在天墟界见过无数次的眼神，属于那些活了成千上万年的老怪物。</p><p>就仿佛，对方不是一个孤立的个子，而是……整片天地本身！！</p>
