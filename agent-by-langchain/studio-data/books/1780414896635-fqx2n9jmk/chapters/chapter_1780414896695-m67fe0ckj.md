# 给我干哪来了

<p>“姜笙前辈……您是说龙佑前辈，他一开始就意识到地球上隐藏着诸如神州龙组、美洲地质监测局、东瀛万事屋这类‘超凡组织’？”</p><p>“显然如此。”</p><p>萧凡叶摩挲着下巴，沉吟道：“我竟把这些‘民间超凡者’忽略了，他们实在太过低调。”</p><p>姜笙：“你离开家乡多年，心底早已将此地视作‘毫无威胁的安稳之地’，再加上潜意识里知道‘有龙佑先生坐镇’，警惕性自然降到极低。”</p><p>哥斯拉从不会留意路边的蝼蚁，蓝鲸亦不会在意身上附着的虾米。</p><p>常人极少会整日提心吊胆、杞人忧天地怀疑自己家中藏着穷凶极恶的杀人犯。</p><p>更何况，那些所谓的“超凡者组织”在萧凡叶眼中，根本算不上危险。</p><p>充其量，不过是蚁群里稍壮硕些的几只大蚂蚁罢了。</p><p>……</p><p>【你眼里看来，“异人”不过是蚁群里稍壮硕些的几只大蚂蚁罢了。】</p><p>潜龙锐评。他是龙佑的潜意识，虽然经常自言自语说怪话，却也往往能反映龙佑内心的真实想法。</p><p>‘怎么能把地球老乡说是蝼蚁呢？你思想觉悟有问题！’</p><p>龙佑也当做是旅游一回，提溜着猫娘林云，跟着蓝毛粉毛走了。</p><p>林云被拎在半空，晃晃悠悠，忍不住小声嘀咕：“这俩人看起来简直是铁心公主和南宫问天呐……”</p><p>龙佑非常想要表扬这个吐槽役的猫娘。</p><p>【林云口头吐槽时，手中生成一袋食盐：1%】</p><p>【将吐槽能量具象化成物质的能力！只不过为啥是盐？】</p><p>他们走到街边一处不起眼的地方，停着辆面包车。银灰色，沾着泥点，车窗贴深色膜，和街上跑的那些没什么两样。</p><p>小蓝笑笑：“大隐隐于市，面包车就是都市的迷彩服。”</p><p>他走到车门前，双手扣住门板边缘，往上一抬，整扇车门被卸下来，露出车厢内部。</p><p>几张折叠椅，几个黑色手提箱，还有台奇怪的圆柱形容器。</p><p>小蓝侧身：“龙先生，请。”</p><p>龙佑拎着林云跨进去，小光跟着上车。小蓝把车门重新安上，严丝合缝，像从来没拆过。</p><p>林云被放到折叠椅上，终于脚沾地。他揉揉脖子，打量车厢内部。</p><p>车门是特殊改造过的，可以方便拆卸。</p><p>当然，前提是你臂力够强，至少得一拳撂倒半个泰森吧，否则拆卸不是那么容易的。</p><p>小蓝在龙佑对面坐下，小光坐到驾驶位，发动车子。</p><p>“龙先生，感谢您的配合。”</p><p>小蓝说，“毕竟在这城区也不好爆发冲突。您一拳打穿地壳，留下严格直径半米的垂直坑洞，实在是惊为天人。”</p><p>龙佑点点头，顺着他说下去：“没错，这已经用了我的全力。”</p><p>他确实没说谎。</p><p>前几日他便托付地球给“苍天婆婆”，本地天道做事效率很高，短短几天就布下类似于天墟界的“红尘护阵”。</p><p>现在他全力一击，确实只能打穿五十公里地壳。</p><p>当然，要是跑到远离地球的外太空，情况就不太一样了，一拳打出就是满屏核爆。</p><p>小蓝沉吟两秒：“您的全力……直径半米，深度五十公里。这个数据我们测算过，能量释放已经超过人类有史以来最强的武器——沙皇氢弹，但杀伤范围控制在极窄的垂直通道内。这种精准控制，比单纯的力量更让人……”</p><p>他斟酌用词。</p><p>“更让人敬畏。”小光接话，虽然戴着墨镜，但还是能感觉到她盯着后视镜。</p><p>林云坐在旁边，听他们说话，脑子嗡嗡的。</p><p>他橘色长发垂下来，金色瞳孔倒映在车窗玻璃上。那个下午之前，自己还是个写课程作业写到秃头的普通学生。</p><p>现在他被拎到一辆神秘面包车上，旁边坐着个一拳能打穿地壳的男人，前面坐着两个自称龙组的异人。</p><p>“我说……大哥大姐的‘目标’是这位龙叔吧？为何要带上我？不如先把我放下了……”</p><p>“不行×2”一蓝一粉同时回答。</p><p>神州龙组收容神州境内的一切异人。</p><p>不管对方能否一拳打穿五十公里地壳，破碎地幔，亦或只是看起来人畜无害的猫娘，一切都应当注册在案。</p><p>“神州龙组宗旨是控制收容保护，其中的‘控制’便是对待异人的态度。”</p><p>林云瞪大眼睛：“喂，你这是不是有些串台了？这宗旨我怎么好像听过？”</p><p>小蓝笑道：</p><p>“听过正常，一种解释是曼德拉效应，似乎有很多人都听说过控制/收容/保护仨词。</p><p>“其二，社会上有许多关于xxx基金会、xx社、xx管理局的设定，甚至是亚文化阴谋论。</p><p>“其中许多信息是由我们传播的。将阴谋论构成阴谋本身的一部分，掩盖效果更好。”</p><p>龙佑望着窗外。</p><p>他对稷海市各个地段都挺熟悉，毕竟逛了很多年。车窗外掠过熟悉的街景，路灯，店铺，夜宵摊。</p><p>然后车开进一条隧道。</p><p>龙佑坐直身体，开始有些认真起来。</p><p>他记得自己住的街区在半个钟头车程内，都没有隧道才对！</p><p>隧道很长，长得不正常。灯光从车窗上一盏盏滑过，没有尽头。</p><p>小蓝不笑了。这隧道不是他们龙组的手段，他们开着开着便闯进了不存在的隧道。</p><p>小光盯着前方：“空间异常折叠。这里不是地球。”</p><p>林云猫娘整个人缩在座椅上：“什么叫空间异常折叠？”</p><p>小光戴着墨镜，语速很快：“把空间当成一张纸，纸的脆弱处很容易会折叠，把不该出现在这里的‘东西’带过来。”</p><p>小蓝把着方向盘：“你们还没注册，但没时间了。这就是龙组每天面对的东西——诡兽，从另一个时空来的生物。”</p><p>龙佑和林云同时看向挡风玻璃。</p><p>隧道尽头，一团像异形和舔食者交媾后生出的杂种，浑身流淌漆黑粘液，站在那儿！</p><p>“地球上很少见到它们，因为它们只出现在‘异常折叠空间’里。普通人能正常过日子，是我们在这里战斗的结果。”</p><p>“这里已经是另一个世界，不是地球了！”</p><p>龙佑心中微动。</p><p>这所谓空间异常折叠，很可能就是地球宇宙时空、与其他世界的碰撞点。</p><p>他们解释为异常折叠空间，倒也贴切。</p><p>小蓝从车里的储物柜掏出两副墨镜，扔给龙佑和林云。</p><p>“自带‘认知滤网’，效果不错，尽量戴上，不然很容易精神疯狂，理智清零。”</p><p>林云惊疑：“原来你们戴墨镜不是耍帅呀，还真有实际功能。”</p><p>刹车，小蓝和小光同时踹开车门下车。</p><p>龙佑拆开车门跟下去。</p><p>林云猫娘本来想缩在面包车里，尾巴都吓直了。但最后看着龙佑先生的背影，咬咬牙，也跟着跳下车。</p>
