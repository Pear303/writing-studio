# 什么事都丢给天道做而自己乐得清闲当甩手掌柜是否有些太过分了

<p>龙佑懒得理会他们的震惊。</p><p>“苍天婆婆，你说他们‘立场不同’，所以就要打架？”</p><p>“没错。天启协约与仙道同盟的战争，并非简单的利益之争或生死之争，而是大道之争。”</p><p>龙佑：“大道之争？什么大道？”</p><p>“秩序与超脱。天启协约认为，宇宙的终极归宿是‘秩序’。</p><p>“一切应该被量化、被计算、被掌控。他们追求的是完美的规则，是万物运行的必然。</p><p>“而仙道同盟认为，宇宙的终极归宿是‘超脱’。一切应该被突破、被超越、被解放。</p><p>“他们追求的是无限的可能，是挣脱规则的自由。”</p><p>双方理想都有些玄乎，但总感觉很老套！</p><p>像是在十年前的小说电影里看过类似的！</p><p>苍天婆婆微微颔首：“总之亿万年来，他们打了无数战争，波及的河系数以万计。”</p><p>龙佑骂道：“吃饱了撑的，你们为了这个，打了亿万年？”</p><p>那少年模样的老登太乙真仙眉头微皱，正要开口，却被龙佑抬手制止。</p><p>“行了，别解释。我不管你们大道之争、中道之争、小道之争。”</p><p>【你们之间的热战永恒结束了，战舰电脑随机播放《永世的摇篮》：100%】</p><p>话音落下的瞬间，时间长河剧烈震颤！</p><p>无数条世界线在这一刻同时分叉扭曲，飞速重组！</p><p>原本通向战争、毁灭、无尽厮杀的未来，如同被无形的大手抹去，一条接一条地消失！</p><p>时间开始恢复流动。</p><p>天启协约的战舰群重新启动引擎，仙道同盟的三位太乙真仙重新催动灵力！</p><p>那少年太乙真仙试探性地抬起手，凝聚出一道足以毁灭行星的仙术光芒，朝对面一艘战舰丢去。</p><p>光芒飞出十万里，然后……</p><p>拐了个弯，绕过战舰，消失在虚空深处。</p><p>对面那艘战舰的指挥官不甘示弱，主炮充能，一道足以蒸发恒星的粒子束轰然射出！</p><p>粒子束精准地瞄准那位赤足女子，然后在距离她三丈的地方自动偏转，同样消失在虚空中。</p><p>再没有人动手了。</p><p>准确说，是动不了手。每次有人想要出手攻击，那股杀意都会在最后一刻莫名其妙地消散，然后变成一句更加刻薄的嘲讽。</p><p>于是，在龙佑离开后的这片星域，出现了一个史无前例的奇观。</p><p>两个屹立宇宙顶点的超级文明，相隔百万里虚空，疯狂地交换着嘴炮！</p><p>“愚蠢的唯心主义-1000！”</p><p>“愚蠢的唯物主义-1000！”</p><p>……</p><p>“行了，收工。”龙佑转身，向地球走去。</p><p>苍天婆婆跟在他身后：“先生，你就这么结束了？”</p><p>龙佑：“不然呢？把他们全杀了？还是把他们洗脑成和平主义者？”</p><p>“这种解决办法……”</p><p>“我只是让他们打不起来而已。至于以后他们想干什么，那是他们的事。我听说‘天行有常，不为尧存，不为桀亡’，苍天婆婆您作为天道化身，应该比我更明白这点。”</p><p>姜笙微愣，感受到了前辈的批评：</p><p>“是的没错，就像宇宙中的战争，无论是解放战争，亦或是灭绝战争，天道都没有加以干涉判断对错的标准，大部分时候都只能说一句‘立场不同’。”</p><p>只不过现在她“天人合一”。</p><p>天道的无情略微染上了人性的有情。</p><p>龙佑摆摆手，示意苍天婆婆跟上。</p><p>两人一前一后，穿过被时间冻结的星域，穿过那些目瞪口呆的战舰和真仙，穿过层层叠叠的时空维度，最终停在一片静谧的虚空之中。</p><p>远处，银河系如同一枚旋转的银盘，静静悬在黑暗中。太阳系只是其中一个不起眼的小点，地球更是连看都看不见。</p><p>“但我这次请您来，是为了和您商量一件事。”</p><p>苍天婆婆微微颔首，周身辉光流转，没有说话。</p><p>“我在异界见过一种法则，叫‘红尘护阵’，那地方挺有意思。</p><p>“修道者在外太空能一巴掌拍碎恒星。而一旦降落到‘人间大地’，力量就会被压制，最多一拳打爆一座山。</p><p>“我热爱故乡地球，我不想看到哪天某个修仙者不小心路过，一巴掌把稷海市拍没了。</p><p>“所以，还请您保护好地球上的凡尘人间，敬爱的本土天道。”</p><p>苍天婆婆郑重点头：“天道誓死守护地球。”</p><p>龙佑愣了一下：“……怎么突然说话这么正式悲壮？”</p><p>【都说天行有常，不为尧存不为桀亡，突然让天道誓死守护人间，确实有些ooc。】</p><p>“对了，此次召您出来，其实还有另外一件事。”</p><p>他抬手一挥，时间长河在两人脚下展开。无数条世界线延伸，通向无穷无尽的可能。</p><p>龙佑指着其中一条，那条线上，一个模糊的身影正在穿过一道裂缝，从某个未知的世界跌入这片宇宙。</p><p>“您看到了吗？”</p><p>苍天婆婆凝神看去，眉头微皱。</p><p>龙佑继续道：“咱们这片宇宙，与其他诸多世界发生过碰撞。就像两个挨得太近的池塘，水面微微震颤时，总会有水滴溅到对方那边。”</p><p>他指了指那条世界线上的身影。</p><p>“那些溅过来的‘水滴’，就是穿越者。”</p><p>姜笙扫过整片宇宙——</p><p>然后她看到了。</p><p>无数道细如毫毛的裂缝，遍布在宇宙的各个角落。</p><p>有的在银河系边缘，有的在某个星系的黑洞附近，有的甚至就在太阳系内部。</p><p>但非常巧合的是，绝大部分裂缝都出在地球上。</p><p>所以可预见，地球极其盛产穿越者——这是有科学与玄学共同依据佐证的。</p><p>那些裂缝极其细微，细微到连太乙真仙的神识都难以察觉。</p><p>但此刻被龙佑点明，她再看时，那些裂缝便如同夜空中的萤火，清晰可见。</p><p>“原来如此……”苍天婆婆喃喃道。</p><p>她见证过无数文明的兴衰，见证过无数生命的轮回，见证过无数奇迹的发生。</p><p>但关于“穿越者”，她一直以为只是极少数的意外，命运的偶然，某种无法解释的玄学。</p><p>真相却只是是两个世界挨得太近，相互渗透，相互影响，相互交换。</p><p>‘萧凡叶这样的穿越者，就是这么来的。’</p><p>苍天婆婆震撼良久，不是因为穿越者本身。</p><p>而是因为——龙佑先生，竟然能洞察到这个层面。</p><p>“您是玄之又玄的天道。还请您能够实时监测本地宇宙的情况。在保护地球之余，也为我找出本宇宙与其他世界碰撞的那些地方。”</p><p>苍天婆婆：“明白。”</p><p>“那就拜托您了，老天妈。”</p>
