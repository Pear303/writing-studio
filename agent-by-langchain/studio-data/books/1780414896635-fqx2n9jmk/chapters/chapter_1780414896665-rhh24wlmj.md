# 战斗，受创，走马灯，回忆杀

<p>他开启超级视力，穿透漫天烟尘和乱流，清晰地看到战场中的每一个细节——</p><p>萧凡叶身影如鬼魅般穿梭，每一剑斩出，都带着毁天灭地的剑意。那天魔先锋的触手疯狂抽打，每一次抽打都能崩碎虚空，但萧凡叶总能险之又险地避开，同时反手一剑斩在它身上。</p><p>一剑，两剑，十剑，百剑——</p><p>萧凡叶的身影从那金光中冲出，周身环绕着无数道剑影。那些剑影每一道都蕴含着合体期的全力一击，铺天盖地般斩向天魔先锋。</p><p>“吞日焚魔绝剑！”</p><p>剑影如暴雨倾盆，斩在那团千丈巨影上，每一剑都能削下一大块漆黑的腐肉。</p><p>那些腐肉在空中挣扎蠕动，但下一瞬就被后续的剑意彻底磨灭。</p><p>天魔先锋发出凄厉尖啸，庞大的身躯剧烈颤抖。</p><p>但是——</p><p>它并没有很明显的伤筋动骨！！</p><p>它身上的无数张人脸同时张开嘴，吐出漆黑的浓烟。</p><p>那浓烟所过之处，连光线都被吞噬，虚空都在腐朽。</p><p>萧凡叶眉头一皱，身形暴退。但那浓烟扩散的速度极快，眨眼间就追上了他。</p><p>“护体剑罡！”</p><p>他周身浮现出三百六十一道剑罡，每一道都如同一面铜墙铁壁。</p><p>但那浓烟触及剑罡的瞬间，剑罡就开始滋滋作响，以肉眼可见的速度被腐蚀。</p><p>“我去这烟有毒！”</p><p>萧凡叶闷哼一声，体内灵力疯狂涌动，强行震开浓烟，继续后退。但他刚退出百丈，那天魔先锋的无数触手就抽了过来。</p><p>每一根触手都粗如千年古木，末端睁着猩红的巨眼，射出的红光能让人心智崩溃。</p><p>萧凡叶一剑斩断三根触手，但更多的触手接踵而至。他身法如电，在触手间穿梭，但触手实在太多太密，终于——</p><p>啪！一根触手狠狠抽在他后背。</p><p>护体剑罡碎裂，萧凡叶整个人如同陨石，被抽飞出去数十里，撞穿了三座山峰，最后嵌在第四座山峰的崖壁上。</p><p>“咳咳——”</p><p>他咳出一大口血，那血里混杂着黑色丝线。天魔之毒已经侵入经脉。</p><p>龙佑一旁看着。</p><p>【合体期修为好像还是不太够看嘛。】</p><p>“那我没办法。他还没告诉我合体之上是什么境界。”</p><p>【需要这么麻烦吗？你直接设定他100%临阵突破不就得了。】</p><p>【就像百分百空手接白刃，而不是百分百空手接屠龙宝刀，“屠龙宝刀”是“白刃”的子集，也被“百分百空手接”包含在内。】</p><p>龙佑眼前一亮，这确实是个好主意。</p><p>毕竟是地球老乡，这种“绝对临阵突破”的外挂送给他，也不是不行。</p><p>【萧凡叶在生死绝境中临阵突破境界：100%】</p><p>……</p><p>那天魔先锋根本不给萧凡叶喘息的机会。</p><p>千丈巨影如同一座移动的黑色大陆，轰隆隆地压了过来，无数触手铺天盖地般抽下！</p><p>萧凡叶咬牙，一剑劈开压下来的山峰碎石，身形冲天而起，险之又险地避过这一轮抽打。</p><p>但他的速度明显慢了，身上的伤口在渗血，灵力的运转也出现了滞涩。</p><p>“还是……不够吗……”</p><p>他在空中稳住身形，看着那越来越盛的天魔威势，眼中闪过一抹苦涩。</p><p>一万年前的那场天魔大劫，陨落了九位合体大能。</p><p>而这次，虽然自己刚刚突破到合体，但面对的这个天魔先锋，实力竟然远超预期。</p><p>那千丈巨影的气息还在攀升，漆黑的躯体上浮现出一道道猩红的纹路。</p><p>那些纹路像是活物，在缓缓蠕动，每蠕动一次，它的气息就强盛一分。</p><p>“吼——！！！”</p><p>天魔先锋仰天咆哮，方圆千里的天空都在震颤。那遮天蔽日的魔云剧烈翻涌，裂隙深处又涌出了无数黑影。</p><p>虽然弱小一些，但数量多得惊人。</p><p>萧凡叶的心沉了下去。</p><p>他环顾四周，天柱峰已经崩塌了大半，身后千里之外就是修仙界最后的防线。</p><p>那些残存的修士们，此刻正拼死抵挡着从裂隙中涌出的天魔小怪。</p><p>如果他挡不住这个先锋……</p><p>“不能退。”萧凡叶握紧归乡剑，剑身震颤，与他共鸣。</p><p>他深吸一口气，强行压下体内翻涌的毒血，周身灵力再次燃烧起来。</p><p>但那天魔先锋根本不给他重整旗鼓的机会。千丈巨影猛然收缩，从一座黑色大陆凝聚成一个只有百丈大小的人形。</p><p>那人形浑身漆黑，表面流动着猩红的纹路，背后伸出无数根触手，每根触手的末端都睁着一只眼。</p><p>它的头部没有五官，只有一张占据了整个面孔的巨嘴，嘴里是密密麻麻的利齿。</p><p>凝聚成人形后，它的速度暴增！</p><p>下一瞬，它已经出现在萧凡叶面前，一拳轰出！</p><p>那一拳，直接打穿了虚空，裹挟着毁天灭地的力量砸向萧凡叶胸口。</p><p>萧凡叶来不及闪避，只能横剑格挡。</p><p>轰！！！</p><p>剑身与拳头碰撞，冲击波呈环形扩散，将方圆百里的云层一扫而空。萧凡叶再次被轰飞，这一次飞得更远，砸进了一座山脉，将整座山脉砸得拦腰折断。</p><p>碎石堆中，萧凡叶挣扎着爬起来。归乡剑插在身侧，剑身上出现了一道细微的裂纹。</p><p>他看着那道裂纹，瞳孔微缩。</p><p>本命道器受损，反噬之力让他再次吐出一口血。</p><p>“这力量……”</p><p>他抬起头，看向那道从天而降的黑影。</p><p>那人形天魔已经追了过来，悬浮在他上方百丈处，无数只眼睛齐刷刷地盯着他，眼神里只有饥饿，只有要将一切吞噬的饥饿。</p><p>萧凡叶苦笑。</p><p>九百年的修炼，又借助那神秘地球老乡的机缘，好不容易突破到合体。</p><p>原以为能逆转战局。</p><p>没想到，还是不够……</p><p>他拄着剑，缓缓站起身。白发再度变成黑发，但此刻那黑发上沾满了血污和泥土。</p><p>年迈的面容上，布满了疲惫和决绝。</p><p>“那就……最后一剑吧。”</p><p>他深吸一口气，体内残存的灵力开始燃烧。归乡剑剧烈震颤，那裂纹在扩散，但剑身的光芒反而更加璀璨。</p><p>这是他最后的底牌——燃烧本命道器，换来一击之力。</p><p>视野开始模糊。是走马灯。</p><p>萧凡叶不受控制地陷入了回忆。</p><p>……</p><p>九百年前，地球。</p><p>睁开眼，是一座破庙，浑身是血。</p><p>筑基期时，他第一次遇到生死危机。</p><p>金丹期时，他结识了第一个真正的朋友，一个叫张屠夫的散修，最后他也不敌天命，寿终正寝……</p><p>元婴期时，他收了第一个徒弟，那丫头资质普通，但特别刻苦，终局却是反目成仇……</p><p>……</p><p>如今，他站在这里，独自面对天魔。</p><p>九百年的岁月，无数次的生死，无数次的离别。</p><p>“我这一生……”</p><p>他喃喃自语，眼前走马灯还在继续。</p><p>现实可不是童话，走马灯不会让他战力突然变强10倍，也不会让刚刚才突破大境界、气息不稳的自己再度突破。</p><p>世上哪有这么戏剧性的低概率之事？</p>
