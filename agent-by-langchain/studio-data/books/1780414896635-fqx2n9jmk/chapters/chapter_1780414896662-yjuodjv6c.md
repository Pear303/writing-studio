# 穿越异界注意事项

<p>自己都拥有「根本探测不到极限」的概率修改能力，连自己亲手调教出来的概率，如果他自己都不相信，那就真没招了。</p><p>龙佑举起硬币，心念一动。</p><p>【连续三次抛掷结果为“正-正-正”，概率……看到了，是12.5%】</p><p>【看起来没问题，0.5^3=0.125。】</p><p>“嗯。”龙佑点点头，“所以概率论中的‘古典概型’成立。”</p><p>他把硬币收起来，忽然想起什么。</p><p>“对了，你刚才说的那个穿越概率——0.00001551%，应该是‘条件概率’吧？”</p><p>【没错。必须先“病逝”，然后才“穿越异界”的概率。严格写法是P(穿越|病逝)。】</p><p>“那如果我不限定‘病逝’这个条件呢？”</p><p>龙佑问，“从农业时代开始，所有活着或死去的智人，平均穿越概率是多少？”</p><p>【稍等。】</p><p>潜龙沉默了几秒——当然，那只是龙佑自己脑内的处理时间。</p><p>【地球智人从发展出农业文明，约公元前10000年至今，智人死后穿越概率：0.006667%，约1:15000】</p><p>【历史上智人总人口约1090亿，所以穿越者总数大约是大约有720万起。】</p><p>龙佑吹了声口哨，720万！</p><p>那是一整座超大城市的人口！</p><p>七百二十万个地球人，在过去的岁月里，因为各种各样的原因，被甩出这个世界，掉进别的宇宙。</p><p>【而且这只是下限。很多穿越发生在史前，没有文字记录，甚至发生在其他人类支系，比如尼安德特人、丹尼索瓦人、佛罗勒斯人，那些早已灭绝的人种里，也可能有穿越者。】</p><p>【如果算上那些，数字可能翻倍。】</p><p>【天知道呢。】</p><p>地球老乡，独自一人漂泊异界，他们过得还好吗？</p><p>最后龙佑叹了口气，把手机揣回兜里。</p><p>“行吧，现在，该去异世界看看了。”</p><p>潜意识笑道：【你之前不是想着‘彩票→赌场→股市’，然后成为都市神豪？】</p><p>龙佑摇摇头：“别笑了，那会我刚觉醒能力没几分钟，眼界确实比较低。”</p><p>无趣的生活和都市神豪，他肯定选择后者。</p><p>但和无穷的知识、与绝对的力量相比，都市神豪又是什么路边一条随脚踹死的东西？</p><p>地球这一亩三分地，又怎能限制得了他的眼界？</p><p>既然异世界真的存在，而穿越也真的存在，现在问题就成了——该怎么穿越。</p><p>按照龙佑的经验，当他想要某个“事件”的发生概率达到100%，通常需要一个“扳机”来触发事件。</p><p>打个比方就是——</p><p>【我下一次喝水后，抛硬币抛出“侧面立起来”：100%】</p><p>下一次喝水，就是龙佑自己设定的“扳机”。</p><p>喝水前，他抛硬币是正常运气；而喝水后，他抛下的硬币则永远是“侧面立起来”。</p><p>潜意识自动组合出逻辑清晰的话：【我先帮你查查。龙佑在下一次喝水后，穿越到异世界：1145e-33】</p><p>“看来也不算很低。”</p><p>至少比自己“原地化身为超人”概率要高啊。</p><p>龙佑：“下一个问题，是哪种穿越方式？胎穿，魂穿，还是肉身直接穿？”</p><p>“那就肉身穿越吧。”</p><p>毕竟带着这副皮囊习惯了，而且万一魂穿过去被人当孤魂野鬼打散了，或者是夺舍个残废、瘫痪、甚至是个将死之人，那多晦气。</p><p>潜意识却十分严肃地泼了一盆冷水：</p><p>【你需要考虑到，根据目前人类天文体系的数据，宇宙空间99.999999%以上的区域都是极度恶劣的外太空环境。真空、极寒、高能辐射，或者是毫无氧气的死寂之地。】</p><p>【即使侥幸能穿越到“非外太空”的环境，你也更可能一头扎在体积更大的恒星，而不是穿越到岩石行星上。】</p><p>【就算没有扎在恒星上，而是落在了拥有大气层的固态岩石行星，按照体积来看，更大概率不是落在大气层，而是传送到地幔、地心！】</p><p>【即使落到了大气层，你仍然有相当大概率是传送到了半空，而不是刚好落在地表！】</p><p>龙佑挑了挑眉：“所以你的意思是，‘魂穿’比较科学一点？”</p><p>根据“人择原理”，混穿一般都会魂穿到人类身上。</p><p>而能够传到人类身上，说明异世界穿越目的地的环境，还挺不错，至少有碳基肉人生存。</p><p>【你目前的“超人之躯”，能够硬抗穿越异世界的外太空环境？】</p><p>【又或者，如果穿越到的是一个物理法则截然不同的世界？】</p><p>【比如那里的光速只有每秒三米，或者基本作用力完全不同，肉体结构会不会当场崩溃？】</p><p>龙佑一怔。</p><p>“呃……也是。”</p><p>他摸了摸下巴，若有所思，“超人终究是有氪石和阳光这两个弱点。如果把我也扔进充满某种克制生物能的环境，这身板还真不一定靠得住。再譬如肉身穿越若是定位到了黑洞内部，没准真得凉。”</p><p>【所以，魂穿？】</p><p>“不。魂穿太麻烦了。要重新练级，要适应新身体，万一穿成个废柴流开局，还得逆天改命——你我改命倒是擅长，但麻烦啊。”</p><p>【那你打算？】</p><p>龙佑想了想。</p><p>【觉醒「不灭」。概率：0% → 100%】</p><p>【存在本身成为绝对。无论物理法则如何变化，无论身处何种环境，无论遭受何种攻击，你的永恒存在不会被抹消。】</p><p>龙佑睁开眼。</p><p>他低头看了看自己的手。</p><p>没什么特别的感觉。没有金光闪闪，没有力量暴涨，甚至连体温都没变化。</p><p>但就在这一瞬间——他知道了。</p><p>变化其实很小很小，肉眼根本无法察觉。</p><p>但他却能清晰地意识到「本质」的跃迁。</p><p>那种感觉就像是……他原本是一块会风化、会粉碎的石头，瞬间变成了一颗永恒的奇点。</p><p>哪怕宇宙热寂，万物归零，他的存在也将不可磨灭。</p><p>不生不灭，不垢不净，不增不减。</p><p>哪怕现在把他扔进黑洞的视界里，他觉得自己也能在里面舒服地睡个午觉，甚至顺手把黑洞给解构了。</p><p>【感觉如何？】</p><p>“没什么感觉。”龙佑笑道，“就是……突然觉得以前担心的那些事，好像都不太重要了。”</p><p>这感觉，还挺好的。</p><p>【龙佑在3秒后，原地肉身穿越至异世界：100%】</p><p>至于穿越到哪个世界？龙佑懒得去指定，甚至懒得去挑选。</p><p>就像玩游戏一样，有时候随机roll点，反而更有乐趣。不管是修仙、魔法还是赛博朋克，先随机一下，看看情况再说。</p><p>倒计时开始。</p><p>3、2、1……</p><p>龙佑感觉自己被某种力量包裹，那是更本源的东西。</p><p>像是宇宙本身伸出了一只手，轻轻捏住了他这只蚂蚁。</p><p>“走你！”龙佑眼前一黑。</p>
