# 圆形的黑色玩意儿

<p>轰！！拳头与空气摩擦产生的热量，在瞬间将周围数百米内的空气电离成等离子体。</p><p>刺目的白光炸开，紧接着是毁天灭地的冲击波。</p><p>那团漆黑被一拳砸进地底。</p><p>冲击波继续扩散，地面被掀翻，方圆几十里的山脉同时崩塌、粉碎、蒸发！</p><p>碎石被抛上高空，又被后续的冲击波碾成更细的粉末！</p><p>大地颤抖！当一切稍微平息时，龙佑低头看去。原本的山脉群已经消失，在原地取而代之的是一个直径超过百里的巨大盆地。</p><p>盆地的正中央，是一个还在冒着烟的岩浆坑，赤红色的熔岩在坑底翻滚沸腾。</p><p>无数放射状裂痕从坑边延伸出去，最长的裂痕绵延到天边。</p><p>一拳将大地撕成破碎的蛛网。</p><p>他提前用超级视力和顺风耳探测过周围，都是毫无人烟的荒野，根本不用计算附带损伤，放开手用全力砸便是。</p><p>龙佑甩了甩发麻的右手。</p><p>“这下总该……”</p><p>岩浆坑中央，那团漆黑缓缓浮了上来。</p><p>它变小了一些，表面眼睛少了三分之一，蠕动的速度也慢了许多。</p><p>但它还活着。那些剩下的眼睛，依然齐刷刷地盯着龙佑。</p><p>眼神里，依然只有饥饿。</p><p>【这世界的武力值高到离谱。】</p><p>【你这一拳放在地球，能把亚欧大陆整个板块轰成渣。】</p><p>【这里却是力量被压到万不存一，砸在这玩意儿身上，也只是让它受了点伤。】</p><p>……</p><p>与此同时，天柱峰之巅。</p><p>萧凡叶单膝跪地，归乡剑插在身侧，大口喘着气。</p><p>刚才那一剑几乎耗尽了他全部灵力，但此刻已经顾不上调息。</p><p>有一团域外天魔，遁去西北方向了。</p><p>域外天魔逃脱出去，都会致使生灵涂炭！毕竟此世除了他，就再没修道者有能力对抗任意一只域外天魔了！</p><p>但随即在西北方向的地平线上，猛然炸开一道白光，大地剧烈颤抖！</p><p>一道冲击波裹挟着狂风呼啸而来，吹得萧凡叶道袍猎猎作响。他眯起眼，看着那个方向——</p><p>那里原本是连绵的苍莽山脉。</p><p>但现在，山脉消失了。</p><p>取而代之的，是一片翻腾着岩浆的巨型盆地。</p><p>萧凡叶的瞳孔微缩。天墟界除了他，还有什么人拥有这般力量？</p><p>这股力量，几乎要摸到天墟界“红尘护阵”的触发界限了。</p><p>红尘护阵，是天道用于限制高阶强者，不要在人间胡作非为的法则。</p><p>就好比萧凡叶，炼虚境巅峰修士，事实上一剑就能将月球劈开轰碎！</p><p>但在人间大陆，全力一击也只能将方圆百里化作焦土罢了！</p><p>这也是天墟界修道者死守人间大陆的原因。一旦天魔脱离人间战场，跑到大地之上的星海，它们的力量将不受“红尘护阵”限制，更难解决！</p><p>幸好有前辈出手了。</p><p>不错……天墟界有很多隐居在秘境或是洞府中的万年老怪，如果这样的隐居老怪能愿意出山助他，或许一切仍有转机。</p><p>目前，已有二千零二十六个自称隐居老怪的修道者，邋里邋遢地从山里跑出来助阵。</p><p>但无一例外都是些化神甚至元婴的老菜头。</p><p>连红尘护阵都无法触发！</p><p>‘但这次，这般威力不会错，绝对是炼虚级数的强者！是隐居修士中的隐居修士！’</p><p>若是天墟界真有这样的隐居老怪愿意出山，哪怕只有一个，这一战的局势都可能扭转。</p><p>千里距离，转瞬即逝。</p><p>西北方的天际，一道流光撕裂了漫天烟尘，带着滚滚热浪极速逼近。</p><p>萧凡叶原本黯淡的眸子亮起。</p><p>那究竟是哪位隐世不出的炼虚大能？</p><p>这等速度，这等气势，即便是在全盛时期的自己之上！</p><p>他心中刚升起一股绝处逢生的希冀。</p><p>然而，当那道流光迫近，停下身形的瞬间，萧凡叶的心瞬间坠入了冰窟！</p><p>悬浮在他面前的，根本不是什么仙风道骨的人族大能。</p><p>仍然，是那个浑身被浓稠黑雾包裹得密不透风的“黑色人形”！</p><p>没有面容，没有气息，甚至无法感知到灵力波动。在这诡异的天墟界，这种形态只能指向一个存在——</p><p>刚刚被他一箭随手砍飞的“人形天魔”！</p><p>方才那人形的域外天魔，突然出现在自己身后，他想都没想就一剑将其砍爆。</p><p>当时他就感觉手感很奇怪，根本没有反馈多少实在的打击感受。</p><p>而后西北方向，又传来炼虚级数的爆炸性战斗。</p><p>萧凡叶原以为是隐世大能出手，万事无忧，不料那“人形天魔”恐怖如斯，杀败了那位未曾谋面的“炼虚大能”！</p><p>“嘶——”</p><p>他喉咙低吼，根本没有思考的余地，手中归乡剑再次爆发出最后的余晖。</p><p>“妖孽！休想通过此地！”</p><p>萧凡叶的思维只用了零点零零一秒就做出了判断，归乡剑出鞘！</p><p>剑光如雪，斩向那团人形黑雾！</p><p>龙佑就是那所谓的黑雾人形。他看着那道劈头盖脸而来的剑光，眉头微挑。</p><p>【有人砍我。】</p><p>【百分百空手接白刃：100%！！】</p><p>哐啷！轰！那足以斩断山河的归乡剑，就这样被两巴掌夹在了中间。</p><p>任凭剑身如何震颤，哪怕剑灵发出尖锐的啸叫，都无法寸进分毫。</p><p>萧凡叶瞳孔剧震，浑身僵硬。</p><p>“这……百分百空手接白刃……不可能……”</p><p>这是什么手段？炼虚巅峰的全力一击，竟然被两掌接住了？</p><p>这绝对是合体期级数的老怪物！</p><p>就在这时，周围那些原本被萧凡叶逼退的域外天魔，敏锐地嗅到了两人之间的僵持，发出了兴奋的尖啸，如蜂群围了上来。</p><p>“吼——！”</p><p>数十只奇形怪状的天魔从四面八方扑咬来。</p><p>【你再不松开，那些怪物就要贴脸了。】</p><p>几十团漆黑已经蠕动着逼近到百丈之内。无数触手从它们身上延伸出来，每条触手的末端都睁着猩红的眼睛，齐刷刷地盯着两人。</p><p>龙佑松开手。</p><p>见状，萧凡叶也顾不上再砍了，猛地抽回剑转身面对天魔。</p><p>无数触手铺天盖地般抽来！</p><p>萧凡叶一剑斩断三根触手，护体神光避过迎面抽来的一根，同时一脚踹开另一团扑上来的黑影。</p><p>余光中，他看到那个人形黑雾也动了——</p><p>龙佑握紧右拳，一拳轰在天魔脸上。</p><p>那团天魔被砸进地底，砸出一个直径百丈的坑。但只过了两息，它又蠕动着爬了出来，身上的眼睛少了几只，却依然活着。</p><p>“这玩意儿真抗揍……”</p><p>龙佑皱眉，双眼亮起两道刺目的光芒——</p><p>超人的成名技，祖国人同款绝招，激光眼！</p><p>炽白光束轰在那团刚爬出来的天魔身上，将它的半边身体灼烧成焦炭。</p><p>但只过了三息，那些焦炭又开始蠕动重生。</p><p>‘激光？这人形玩意甚是古怪。’萧凡叶余光瞥见这一幕，心中惊疑不定。</p><p>总让他想起在地球上看过的各种电影！</p><p>……</p><p>【我好像终于明白，为什么他一见到你我就疯扑上来狠揍，连半句解释都不肯听。】</p><p>“是因为……语言不通？”</p><p>龙佑一拳砸在那头天魔坚韧如铁的皮肤上，表皮瞬间崩碎成漫天黑雾。</p><p>他轻叹了一声：“被重力束缚的灵魂啊……人与人之间，当真就没法相互理解吗？”</p><p>【不，问题出在——】</p><p>【并非基于我主观想要暴露的信息，就无法被探测：100%】</p>
