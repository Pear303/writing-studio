# 潜龙基金

<p>“总之让我吃炒河粉的时候别那么狼狈。”</p><p>【全世界所有人，打喷嚏时将筷子从鼻孔里喷出来，概率：0%】</p><p>龙佑把最后一口炒河粉塞进嘴里。</p><p>就在这时，手机震了。</p><p>他掏出来一看，是姜笙的短信：</p><p>「龙佑先生，潜龙基金的办公和设备地点已经租好，稷海市一环，五十平米的办公间，月租金800元，您要不要过目一下？地址是……」</p><p>龙佑盯着那个数字，愣了三秒。</p><p>一环以内？五十平？月租八百？</p><p>他揉了揉眼睛，又看了一遍，没错，白纸黑字的八百。</p><p>天知道这姑娘怎么做到的，龙佑随手拦了辆出租车，把地址报给司机。</p><p>半小时后，他站在一栋玻璃幕墙写字楼下，仰头看着这座直插云霄的大厦，陷入沉思。</p><p>周围全是高楼大厦，玻璃幕墙反射着夕阳的余晖，整条街充斥着“金融中心”“国际大厦”“商务广场”之类的招牌。</p><p>白领们西装革履进进出出，手里端着咖啡，脸上写着“我很贵”。</p><p>而他要去的，就是其中最高最闪的那一栋。</p><p>龙佑走进大厅，看了看墙上的楼层指引——</p><p>25层到48层，世界五百强企业。</p><p>12层到24层，跨国金融机构。</p><p>6层到11层，科技巨头分公司。</p><p>2层到5层，高端餐饮和咖啡厅。</p><p>1层，大堂。</p><p>负一层，停车场。</p><p>负二层？龙佑眯起眼，终于在指引牌最不起眼的角落，看到了几个小字：</p><p>负二层，潜龙基金，客梯不达，请走货梯。</p><p>龙佑乘着货梯下到负二层。</p><p>电梯门打开，眼前是一条狭长的走廊，头顶的日光灯管有一半不亮，滋滋地响着。墙壁上贴着褪色的消防示意图，脚底下是斑驳的水泥地。</p><p>走廊尽头，一扇半开的门里透出暖黄色的光。</p><p>五十平米的房间，不大不小。墙壁刚刷过，白得发亮。几张办公桌靠墙摆，电脑还没拆封，文件柜空空如也。</p><p>墙角放着一台饮水机，旁边是几盆绿萝，长得挺精神。</p><p>姜笙正站在窗边——如果那扇对着通风井的小窗户能叫窗的话——回头看见他，眼睛一亮。</p><p>“龙佑先生，您来了！”</p><p>龙佑环顾四周，点点头：“挺好的。”</p><p>他是真觉得挺好的。</p><p>五十平米，八百块，一环内，还带装修，姜笙简直是个人才。</p><p>姜笙走过来，开始给他介绍：“这边是办公区，可以放六张工位。那边是会议室，虽然小了点，但开个七八个人的会没问题。角落里可以放个茶水间，我已经买了二十多部饮水机……”</p><p>龙佑一边听一边点头，最后摆摆手：“你自己经营就行，我不过问公司事务。”</p><p>“哦，那请您过目……”</p><p>“不，从今天起，你就是潜龙基金的总裁。一切由你主持，你就是大总裁！我说了我不会过问事物，你‘稍微’给我点分红便可。”</p><p>龙佑的想法很简单：当甩手掌柜。</p><p>一个月前他还在天墟界打太乙真仙，哪有功夫操心什么基金什么办公设备。</p><p>姜笙能干活，那就让她干呗，居然能在市中心一环找到片800块地租的办公室，这业务能力就算给他太乙真仙修为，也一辈子都达不到。</p><p>反正他只需要一个能让爸妈觉得“钱来得正经”的空壳公司。</p><p>至于姜笙——</p><p>她垂下眼睫，脑海中思绪翻涌。</p><p>龙佑先生开的这家公司，当然不是为了搞金融这么简单。</p><p>而他现在让自己全盘操持，意思是——</p><p>将由我来负责“潜龙”的一切凡俗事务？</p><p>姜笙记得龙佑先生暗示过，在俗世社会中，只谈人类社会的工作，不问“超凡”的事物。</p><p>龙佑在屋里转了一圈，忽然想起什么，回头道：“对了，近期会有个‘人才’来应聘，你招收第一个面试者就行。”</p><p>姜笙心中一凛。</p><p>第一个面试者……果然，龙佑先生并非让我瞎猜他的深层目的。</p><p>他将会通过第一个面试者，向我传达信息。</p><p>……</p><p>既然都已经是世界最强者，龙佑想到，那这潜龙基金也应该按照世界五百强、甚至五十强的标准来招人吧！</p><p>‘地球最强程序员……’</p><p>【这个想法不错，但总觉得怪怪的。】</p><p>【近日，这个地球的“最强程序员”将会作为第一位面试者来潜龙基金应聘：100%】</p><p>【地球最强程序员……一个大噱头。程序员还有最强最弱之说吗？你莫不是在搞笑。】</p><p>‘总之搞定。你有这功夫吐槽，不如多给我搞几包盐。’</p><p>‘实际上我这么设置还是挺严谨，如果我说的是【世界最强程序员】，说不定还会整来个外星人，毕竟最强的程序员真不一定是地球人。’</p><p>【所以你强调是「地球最强」。】</p><p>龙佑想到，既然是“地球最强程序员”，而全球80亿人，神州只占14亿。</p><p>那么对方有可能来自异国他乡。</p><p>外国人在神州工作，要走的流程比较多，签证还是比较难办的！</p><p>于是他补充道：“面试者可能是‘异乡人’，所以还请你帮他‘补办各种手续’。”</p><p>姜笙瞳孔一缩。她曾经就有疑惑，自己作为天道，洞悉本世界的所有人才分布！</p><p>但龙佑先生偏偏不让她去“自主选择人才”。</p><p>姜笙当时就已经怀疑过，龙佑先生更需要的人才，是来自于“异界”。</p><p>如今，龙佑先生所说的“异乡人”和“办手续”实锤了她的判断。</p><p>如果是来自于另一个宇宙，另一个世界。</p><p>那姜笙作为本地天道，确实没机会多少接触到这种「异界外来人才」。</p><p>她郑重点头：“明白。”</p><p>龙佑满意地挥挥手，转身走出门，坐着货梯回到地面。</p><p>但心里总归还是有不舒服，毕竟人不是靠考试面试招来的，而是自己大手一挥硬塞进公司。</p><p>姜笙会不会认为，龙佑他是想往公司硬塞了几个侄子侄女，大搞走后门关系户？</p><p>蒜鸟，不管她。</p><p>自己的“人性”果然牢固，即使获得了最强力量，也仍然思前顾后爱面子，怕老同学说闲话。</p><p>他掏出手机，有信号了。</p><p>看着屏幕上那十几条来自父母的未读消息，龙佑叹了口气。</p><p>最上面一条是昨晚发的：</p><p>「儿子，你妈说她卡里又被你转了20万？你可别做违法的事啊！」</p><p>再往上翻：</p><p>「小佑，看到消息回一下，爸妈担心你。」</p><p>再往上：</p><p>「你是不是去缅北了？？」</p><p>龙佑苦笑，手指飞快地敲了一行字发过去：</p><p>「爸，妈，别担心。儿子开公司了！正经生意，金融投资，合法合规。回头给你们看营业执照。」</p><p>“搞定。”</p><p>龙佑收回手机，正准备当个街溜子体验生活。</p>
