# 第75章

<p>白脸把咖啡杯放在桌上：“第一次和第二次的录像呢？”</p><p>技术员调出来，并排播放。</p><p>清水和生理盐水的测试里，王德发动作和第三次几乎一样狼狈，滑倒、绊脚、踉跄、弯腰。</p><p>区别在于，前两次的液体大都落在他身上。第三次却全部擦边而过，无一命中。</p><p>“同样的动作，同样的时机，同样的狼狈。”</p><p>白脸说，“前两次被打中，第三次实验则全躲开，这不是他控制得了的。”</p><p>控制王德发没被泥水击中的，是他站的位置、摔的方向、弯腰的幅度、系鞋带的时间。</p><p>“换言之，在面对‘泥水’时，他运气突然变好了几十几百倍。”</p><p>“你正确定这真不是鸠摩智转世……哦，不好意思，这次麦又忘关了。”</p><p>穿着西装的男人摘下方框眼镜。</p><p>“不用再三番四次暗示了。既然已经暴露，那我也便不再隐瞒，双方坦诚相待也不见得是件坏事。”</p><p>他周身气息陡然一变，眼神都变得如李小龙般凌厉。</p><p>“老衲，便是鸠摩智。”</p><p>测试场的灯管嗡嗡响，像一群困在玻璃管里的苍蝇。</p><p>王德发或者说鸠摩智，站在那个画了圈的测试场中央，双手拢在袖中，微微低头。</p><p>技术员的声音从扬声器里传出来，带着一丝犹豫：“王先生，您刚才说……鸠摩智？”</p><p>“正是。”他抬起头，那张四十来岁的社畜面孔上，浮现出一种与年龄极不相称的平和。</p><p>“老衲鸠摩智，吐蕃大雪山大轮寺旧人。此身此名，已是前尘往事。”</p><p>技术员在记录栏里敲下几行字，又删掉，又敲，又删，和某个思路卡顿的小说作者一样。</p><p>鸠摩智先生，能展开讲讲吗？</p><p>可以吧。</p><p>王德发低头看了看自己的手。那双手保养得不错，指甲修剪整齐，无名指上有圈浅浅的婚戒压痕。</p><p>“大约三月前，我开始做一些梦，梦里是大雪纷飞的雪山，梵唱阵阵的寺庙，火焰刀法破空之声。</p><p>“初时只当是寻常噩梦，醒来便忘。后来梦越来越清晰，越来越长，白日里也时有恍惚。</p><p>“走在街上，看那些钢筋水泥的楼宇，总觉得陌生，仿佛历经轮回、重见天日的陌生。”</p><p>测试场外，几个研究人员交换了一下眼神。</p><p>有没有应对重生者异人的经验？</p><p>没有，正在向总部寻求技术支援。</p><p>当务之急，是搞清楚对方是哪个时期的鸠摩智。</p><p>实验对象王德发态度端正，始终配合，推断是洗心革面、放下斗心之后时期的鸠摩智？</p><p>对这位“重生者”的询问，还在继续。</p><p>“两个月前……”其中一个翻出王德发的档案，“他确实在两个月前请过一周病假，理由是‘头晕，记忆力减退’。”</p><p>“梦境内容呢？除了雪山和寺庙，还有没有其他细节？”</p><p>王德发微微眯起眼睛，像是在回忆很久远的事：</p><p>“老衲梦见自己站在天龙寺，群僧环伺，天下英雄在侧。老衲口若悬河，滔滔不绝，要以少林七十二绝技换取内功心法。”</p><p>他叹了口气，那口气很长，像是要把几十年的执念都叹出去。</p><p>“梦里老衲意气风发，目空一切，觉得天下武功尽在掌中。醒来后冷汗湿透衣背。</p><p>“因为老衲知道，那是真的，不是梦，是真真切切发生过的事。</p><p>“梦里老衲意气风发，目空一切，只道这七十二绝技天下武人梦寐以求，天龙寺岂有不换之理？醒来后冷汗湿透衣背。</p><p>“因为老衲知道，那是真的。真真切切发生过的事。</p><p>“当日枯荣大师焚毁剑谱，老衲怒极，与天龙寺众高僧以指力相拼，终不能得。</p><p>“趁乱掳了段氏那小子北上，想慢慢拷问剑谱口诀，却在姑苏地界被他逃了。</p><p>“那一路追逐，从大理到江南，老衲心心念念的，不过是一套剑谱……当真是痴了。”</p><p>技术员：“王德发先生现在怎么样了？”</p><p>“他啊，王德发小友很好，我和鸠摩智老先生相处还算融洽。”</p><p>“对，没错，老衲与他共享这具躯体，如同室友共处一室。</p><p>“我七分，鸠摩智老先生三分。他管上班、应酬、陪孩子写作业——这些事老衲做不来。”</p><p>说到“陪孩子写作业”时，他眉头微微皱了一下，似乎确实觉得那比练火焰刀难得多。</p><p>“老衲只管偶尔想想从前的事。”</p><p>“那你们怎么切换？”</p><p>“不用切换，老衲一直在，只是不说话。就像办公室里坐着两个人，一个人处理文件，另一个人喝茶看报纸。需要的时候，我就放下报纸，让鸠摩智老先生说几句。”</p><p>人格切换很流畅。研究人员如是写道。</p><p>“鸠摩智先生，我能问几个……关于您前世的问题吗？”</p><p>鸠摩智微微颔首：“但问无妨。”</p><p>“慕容复的头发是天然卷还是黑长直？”</p><p>“微卷。不是天生的，是练斗转星移时内力走岔了经脉，头发慢慢变卷的。他自己很在意这件事，每天要用篦子梳很久。”</p><p>测试场里笔尖划过纸张的声音此起彼伏。</p><p>“段誉呢？他用的什么牌子的洗发水？”</p><p>“段公子不用洗发水，他用大理皇宫特制的桂花胰子，每年秋天采金桂鲜花，配以猪胰、豆粉、冰片手工捶打。他姐姐木婉清教他的。”</p><p>“乔峰的降龙十八掌，您见过几掌？”</p><p>问过诸多问题后，技术人员一致认为，对方是真货的概率很大。</p><p>那么关于“王德发究竟是如何避开泥水”，如果是鸠摩智在操控身体，那倒也不是不可能。</p><p>但为何，鸠摩智老先生会对黄泥水如此上心在意？</p><p>但对清水和生理盐水，则完全没接管王德发身体？</p><p>对于这一点，鸠摩智转世本人也有些疑惑。</p><p>“老衲也并不清楚，在感觉到泥水将近的时候，那股接管身体冲动是怎么回事……</p><p>“有时候，老衲尝试强行反抗身体的本能冲动，主动去碰那溅射来的泥水。</p><p>“然后……最后总会出一些意外，要么是王德发小友突然接管了身体，要么是……‘绊到脚’之类不应该出现在老衲身上的意外。</p><p>“总之，老衲也甚是奇怪，为何所有溅来的泥水，都总是不沾身？”</p><p>……</p><p>【眼镜男被泥水溅到：0%】</p><p>【眼镜男也许会恰到好处使出强大身法。事实上，他是鸠摩智转世的概率并不为零……】</p>
