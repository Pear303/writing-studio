# 卮言日出，和以天倪

<p>每一种都是足以焚天煮海的「太乙仙术」，都能把黑血磨灭大半。</p><p>但就是磨灭不干净。</p><p>每次剩下那么一丁点儿，比头发丝还细，比尘埃还小，却怎么都不肯消失。</p><p>就像扫地时总有一缕灰黏在地上，用扫帚扫不进去，用手抠又嫌脏！或者更高雅的比喻，就是上完大号擦屁股时，最后一张厕纸上残留的淡淡颜色。</p><p>龙佑试了十几种方法，那点残渣依然顽固地附着在天墟界外壳上。</p><p>太初烬灭炎、太乙玄清神雷、大寂灭金虹、混沌元磁光……</p><p>他砸了少说有「五十」道「太乙仙术」。</p><p>还有那么一丁点一丁点微乎其微的一丁点儿仙术余波，顺着裂缝，渗进了天墟界内部。</p><p>龙佑及时收手，不折腾这破破烂烂的世界外壳外壁了。</p><p>‘那就来最直接的。’</p><p>闭上眼，调动自己最核心的力量！</p><p>那从觉醒之初就伴随龙佑，足以改写的「概率操控」！</p><p>【附着于天墟界外壳的污浊黑血，被我完全灭杀、一丝不留：——】</p><p>他等着那个数字浮现。</p><p>等着那个数字从极低值跳转到100%。</p><p>等着这一切麻烦彻底结束。</p><p>以往来说，只需自己心念一动，这个喧嚣的世界就乌泱泱一下哗啦啦被他咆哮地修改了概率和命运，万千世界线一念之间化为虚无，兆亿可能性旱地拔葱而起。</p><p>然而什么都没有发生。</p><p>龙佑睁开眼，看着眼前那片依旧存在的黑血残渣，愣住了。</p><p>他的能力……没有回应。</p><p>他再次尝试。</p><p>【这团域外天魔的源头，被我彻底消灭：——】</p><p>依旧没有回应。</p><p>【这滴血的来源，被我彻底抹除：——】</p><p>没有，什么都没有！</p><p>龙佑站在纯白虚空中。他的能力，选中不了一个域外天魔。</p><p>或者说，选中不了这滴血的源头，无法修改其概率。</p><p>他被那道雷劈中以来，第一次感受到事情发展超出自己的预料。</p><p>‘这域外天魔有些棘手……即使是太乙真仙修为，也必须要慢慢将其消磨才能清除干净。’</p><p>‘但总体来说还是孱弱不已。’</p><p>‘实力上比我弱……哦！炉！’</p><p>龙佑拿出本属于天墟真人的「混元炼道炉」回到那片附着黑血残渣的地方。</p><p>事实上，这炉子也是天墟真人捡来的，并非严格意义上的私有财产。</p><p>龙佑举起鼎炉，对准那层残渣，轻轻一吸。</p><p>呼！一股强大的吸力从鼎炉中涌出，将那片残渣尽数吸入鼎中。</p><p>龙佑低头看向鼎内。那团残渣在鼎底蠕动，似乎想要挣扎，但在鼎炉的镇压下，它根本动弹不得。</p><p>“这下好了。”</p><p>龙佑咧嘴一笑，然后开始研究，怎样正确使用这炉子来杀菌。</p><p>【这符文你哪怕按一按呢？】</p><p>【或者那里可以拍一拍。】</p><p>【这炉子外壳如此圆润，很显然是让你盘它一盘呀。】</p><p>年轻人学新东西就是快，想当年龙佑炸了好几个玻璃杯和葡萄，就学会了微波炉的用法。</p><p>「混元炼道炉」轰然炸开，无数光芒交织，那团残渣终于在多重打击下彻底崩溃，化作一缕青烟，消散于无形。</p><p>龙佑低头看向鼎底。</p><p>本来呈液态状的黑血已经没了，剩下的残渣都凝成了颗球。</p><p>他满意地点点头，将鼎炉收了起来。虽然不知道这东西还有什么用，但能装能炼，留着总没坏处。</p><p>“搞定。”</p><p>龙佑拍了拍手，将那尊鼎炉随手塞进袖子里——这炉子非常人性化，能自己缩小不说，他袖子里还开辟了一个须弥纳芥子空间，专门用来装些乱七八糟的东西，简直就是加强版叮当猫。</p><p>他最后看了一眼那片纯白虚空，看了一眼远处那个正在缓慢漂移的天墟界，看了一眼那些细如毫毛的空间裂纹。</p><p>“事了拂衣去，深藏功与名。”</p><p>龙佑轻轻打了个响指。</p><p>啪。</p><p>下一瞬，身影消失在纯白虚空中。</p><p>……</p><p>【你觉不觉得，我们遗忘了什么至关重要的东西？】</p><p>龙佑眉梢微挑：“你我修炼至这般境界，怎会有健忘一说？”</p><p>【那你袖中藏着的，又是什么？】</p><p>他自衣袖中缓缓几块破碎片。这碎片材质奇异，似铜似金，但似乎并不完整，只能勉强拼出来，像是个“大盖子”的形状。</p><p>龙佑把那几块破碎片翻来覆去看了半天，又捏了捏，敲了敲。</p><p>“这啥？飞碟残骸？”</p><p>【看着像口锅的盖子。】</p><p>“锅盖？”龙佑挠头，“我袖子里怎么会有这种东西，还挺沉，占了起码半个立方米的宝贵空间。”</p><p>【都修仙了，你袖子比机器猫的次元口袋能装的东西多的多。你再仔细想想，这东西哪来的？】</p><p>龙佑闭上眼，努力回忆。</p><p>记忆里一片空白，白得就像……就像那天外光海的纯白虚空。</p><p>等等，天外光海？</p><p>“我刚才……好像去天外光海泡了阵温泉？”</p><p>【好像是的。水……啊不，光很热，泡得挺舒服，就是有点费脑子。】</p><p>“费脑子？”</p><p>【因为泡完之后脑子就空了。】</p><p>龙佑耸耸肩，随手把那几块碎片往袖子里一塞。</p><p>“算了，也许是谁家锅盖坏了，我顺手捡的废品。虽然没什么用，但留着当个纪念也行，毕竟也是异界特产。”</p><p>【说实话，我还是觉得，我们在天外光海看见过什么，甚至是做过什么，只不过被我们遗忘了。】</p><p>“疑神疑鬼，自己吓自己。”</p><p>“总之，这地方算是安顿好了。”龙佑伸了个懒腰，“萧凡叶那资深穿越者现在已是渡劫期大能，剩下的摊子交给他，应该没问题。”</p><p>【那我们呢？】</p><p>“回地球。”龙佑斩钉截铁。</p><p>【这么快？不再多玩几天？异世界深度游，修仙界风情体验，才刚开个头！】</p><p>“没意思！又是打架又是算计，还得给人擦屁股，比上班还累。”</p><p>“回去顺便吃点卤水烧鸭。”</p><p>【不应该是明炉烤鸭？】</p><p>“为什么是明炉烤鸭。”</p><p>潜龙好像很困惑：【我也不清楚，只是脑子里貌似闪过了……“炉”字之类的念头。】</p><p>龙佑笑道：“那就多吃一顿呗，现在咱难道还吃不起吗？那这仙尊也当得太寒碜了。”</p><p>……</p><p>……</p><p>……</p><p>“卮言日出，和以天倪。”</p><p>天外光海，无形之阴影蠢蠢欲动。</p><p>祂身形近乎支离破碎，而周围的天光亦是搅得混乱不堪，像是刚刚经历过一场大战。</p><p>“至少，已取回「混元炼道炉」……”</p><p>“没想到在这处偏僻之地，竟也能蕴藏此等强者……”</p>
