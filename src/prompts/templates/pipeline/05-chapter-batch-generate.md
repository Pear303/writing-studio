# ⚡ 批量写作要求
1. 逐章撰写，每章写完后用 `===第N章结束===` 标记结尾
2. 前章内容在你的上下文中，直接参考保持连贯性
3. 紧扣任务书中的情节点展开，不遗漏关键情节点
4. 正文使用纯文本格式，不要使用 Markdown 标记（如 # 标题、**加粗、*斜体等）
5. 避免任务书中标注的反模式
6. 避免冗余和重复描写，保持紧凑流畅
7. 不要在章节之间停下来，连续撰写直到所有章节完成
